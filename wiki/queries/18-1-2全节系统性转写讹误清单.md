# 18.1.2 全节系统性转写讹误清单

**开放问题**：18.1.2 的文字叙述存在系统性转写讹误（公式本体 18.7–18.14 罕见地完整，复算零讹误），需对原书（约第 1183–1189 页）逐条核验。已识别讹误如下。

## 1. 系统性“千/于”混讹

对千→对于；对应千→对应于；等千→等于；关千→关于；千是→于是。

## 2. 数学符号与“是”字脱落

- “称作 的极端点” → “称作 M 的极端点”；“如果矩阵 中” → “如果矩阵 A 中”
- “如果 的秩是 ，那么 中线性无关列的最大数是 m” → “如果 A 的秩是 m，那么 A 中……”
- “至多拥有 个正分量” / “正好有个正分量” → 均脱 m
- “如果 非空则 至少有一个极端点” → “如果 M 非空则 M 至少有一个极端点”
- “ 上有界” → “在 M 上有界”；“并且是 的极端点” → “并且是 M 的极端点”
- “从 列中选择 个线性无关向量” → “从 n 列中选择 m 个线性无关向量”
- “是指对千所 x₁, x₂ ∈ M” → 疑为“对于所有”
- “即 x 不在连接 任意两不同点的线段的中间” → 疑脱“M 的”

## 3. 编号讹误

- "(18.96)" → (18.9b)（规范形非负性约束行）
- "(18.lb)" → (18.1b)

## 4. 页码与小节号粘连

- “第 118918.1.3.3” → 第 1189 页，18.1.3.3
- “第 1183 18.1.2.1” → 第 1183 页，18.1.2.1

## 5. 脱字与脱词

- “标函数” → “目标函数”
- “2, 5, 6, 列” → “2, 5, 6, 7 列”（构成基的列号）
- “这一极端点的基包含 1, 5, 列，以及 2, 列中的一列” → 复算支持“1, 5, 6 列，以及 2, 4, 7 列中的一列”（详见 [[退化极端点P1基列号脱落之辨]]）
- “用 A_B⁻¹ (18.10)” → 疑脱“左乘”
- “假定基变量组成向最 x_B” → “向量”之讹（最→量）
- “结果就是 A_B = I，而 x_B = b; !_, x_N = 0 是可行极端点” → “!_, x_N” 为乱码，意为 x_B = b、x_N = 0 即得可行极端点
- “在上面的例子中卫；＝（0,1,o,o,1,2,s) 是一个极端点” → 乱码；应为该极端点的扩展坐标 (0,1,0,0,1,2,5)（“卫；”疑为 P₂ 之讹）
- “多面体的极端 P₂” → 疑脱“点”（“极端点 P₂”）
- 18.1.2.1 条目 "3." 缺标题（其余为 “1. 极端点的定义”、“2. 关千极端点的定理”、“4. 标函数取极大值的极端点”）

## 6. 引号乱码

- “带不等号”⁶⁶ ⩾ ^𝔑"" → 不等号 "⩾" 的引文符号乱码。
