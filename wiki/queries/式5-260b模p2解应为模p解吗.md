# 式 (5.260b) 段「模 p² 解」应为「模 p 解」吗？

**源文（5.4.3.9）**：「现在要确定线性同余式 f(x₂)/p² + f′(x₂) t₂ ≡ 0 (p) 的模 p² 解 t₂′。」

**分析**：

- 式 (5.260b) 本身写明是模 p 的同余式，其解 t₂′ 自然是模 p 的剩余类（对照 (5.260a) 段称「唯一解 t₁′」，未加模数限定）；
- 若 t₂′ 真是「模 p² 的解」，则后续 t₂ = t₂′ + p t₃ 的展开结构（只保留 t₂′ 模 p 的信息）就失去意义；
- 算例（x⁴ + 7x + 4 ≡ 0 (27)）中实际求的是 t₂ ≡ 2 (mod 3)，即模 p = 3 的解，与「模 p 解」一致（已复算）。

**假设**：「模 p² 解」为转写讹误，应为「模 p 解」。

**验证途径**：对照原书相应段落措辞（德文原文是否为相当于 „Lösung mod p“ 的表述）。
