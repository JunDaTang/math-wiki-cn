# 20.2.3 全节系统性转写讹误清单

20.2.3「重要算子」一节的转写层讹误逐条清单。讹误模式（千/于之讹、脱字、全角标点、编号连排、隔写）与全书各节所记一致，应汇入 [[queries/20-2全节系统性转写讹误清单]]。知识性疑点另行立案（见文末）。

## 文句层讹误（非知识性）

1. 首句「这一简化记法的完整形式都是表达式 op[symb1, symb20.2 汇集了」：右括号与「表」字连排脱失，应作「op[symb1, symb2]。（表 20.2 汇集了……）」。
2. 「Set 指派值给右手边的表达式 s,如一个数，给左手边的表达式 指派」：语序倒错兼脱字，大意应为「Set 把右手边表达式 s（如一个数）的值指派给左手边的表达式（例如一个变元）」。
3. 「由此开始 表示这个值」：脱变量名，应为「由此开始 x 表示这个值」。
4. 「意思是指表达式 的每个出现将被替换为表达式 V」：脱 u，且「V」应为「v」。
5. 「如果 是恒等的」：脱 u、v。
6. 「／．」：替换算子「/.」的全角讹形。
7. 「w! = v」：Unequal 中置记法 `w != v` 的隔写形。
8. 「对千」「用千」：多处「千」均为「于」之讹。
9. 「Equal 用千如处理方程中」：整句疑有脱讹，大意应为「Equal 用于如处理方程中」或「Equal 用于方程处理」。
10. 「u :-> v」：RuleDelayed 中置记法 `u :> v` 的排版形。
11. 表 20.2 第三行左列「a^b 或 ab」之「ab」为上标排版形（a 的 b 次方）。
12. 「具有头 Rule Set 的表达式」：Rule 与 Set 之间疑脱顿号，应为「具有头 Rule、Set 的表达式」。
13. 表题「20.2 Mathematica 中的重要算子」：疑脱「表」字，应为「表 20.2 Mathematica 中的重要算子」。

## 知识性疑点（另行立案）

- `r ≥ t` 的完全形式原表作 `GreaterThan[r, t]`，疑应为 `GreaterEqual[r, t]`：见 [[queries/r大于等于t之完全形式GreaterThan疑为GreaterEqual之辨]]。
- `Replace[t, u->v]` 与「每个出现」的并称疑为 ReplaceAll：见 [[queries/Replace疑为ReplaceAll之辨]]。
