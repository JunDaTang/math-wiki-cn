# n 等于 l 疑为 1 且脱 3 之辨

19.3.3.1：「对于 n = l, 2, 的情况，有（19.82）」。

## 疑点

- 「l」为「1」的形近讹误（OCR 中 1/l 混淆常见，与「儿乎→几乎」同属形近字讹误家族）。
- 枚举「n = 1, 2, 」后脱「3」：(19.82) 表明确含 n = 1, 2, 3 三档。

## 处理

读作「对于 n = 1, 2, 3 的情况」。
