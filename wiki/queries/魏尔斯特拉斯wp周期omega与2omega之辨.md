# 魏尔斯特拉斯 ℘ 周期 ω 与 2ω 之辨

## 待裁决问题

源文 14.6.4 性质 (1)：“它（℘(z, ω₁, ω₂)）是一个有周期 ω₁ 和 ω₂ 的椭圆函数。”℘ 的周期究竟是 ω₁、ω₂ 还是 2ω₁、2ω₂？

## 证据（均为源内直接证据）

1. 格点定义 (14.117a)：ω_mn = 2(mω₁ + nω₂)——℘ 的极点格由 2ω₁、2ω₂ 生成；
2. (14.124)：ζ 的拟周期平移量为 2ω₁、2ω₂，即 2ωᵢ 是平移行为的自然单位；
3. 极点论证：℘ 的极点集恰为 {ω_mn} = {2(mω₁+nω₂)}（由 (14.117b) 的 (z−ω_mn)⁻² 项可见）。若 ω₁ 是周期，则由极点 0 平移得 ω₁ 也是极点；但方程 2(mω₁+nω₂) = ω₁ 无整数解，ω₁ 不是极点——矛盾。故 ω₁ 不是周期，同理 ω₂。

## 结论（数学事实）与候选解释

℘ 的周期为 2ω₁、2ω₂；ω₁、ω₂ 应称为半周期（标准理论术语，源文未用此词）。性质 (1) 的“周期 ω₁ 和 ω₂”疑为转写丢“2”或原文行文不严格；℘(z, ω₁, ω₂) 记号中的 ω₁、ω₂ 宜理解为半周期。
