# 式 16.168 分布函数首段条件疑为 x<0

**疑点**：式 (16.168) 中 [0,1] 均匀分布的分布函数写作

```
F₀(x) = 0 (0⩽x) / x (0<x⩽1) / 1 (x⩾1)
```

首段条件「0 ⩽ x」与第二段「0 < x ⩽ 1」重叠冲突。

**分析**：按分布函数性质（[[concepts/分布函数]]），F₀ 在负半轴应为 0、在 [0,1] 上为 x，故首段条件应为 **x < 0**。疑为「x<0」在转写中丢失或误作「0⩽」。密度函数部分（f₀=1 于 [0,1]）无误。

**影响**：属条件转写疑点而非数学错误；见 [[findings/式16-168至16-170随机数定义与逆变换转录复算]]、[[concepts/均匀分布随机数]]。

**核对方**：原书式 (16.168) F₀ 首段条件。
