# 式 3.57 的 S₂ₙ 公式内层根号是否漏了「1 −」？

式 3.57 前半转写作 S₂ₙ = (n·R²/√2)·√(1 − √(4·Sₙ²/(n²·R⁴)))。数值检验表明该式按字面不成立：

- n = 4：S₄ = 2R²，代入得 S₈ = (4R²/√2)·√(1 − √1) = 0，而真值 S₈ = 2√2·R² ≈ 2.828R²（见表 3.2）。
- n = 6：S₆ = (3√3/2)R²，代入得 S₁₂ = 6·sin15°·R² ≈ 1.553R²，而真值 S₁₂ = 3R²。

若在内层根号内补「1 −」，即 S₂ₙ = (n·R²/√2)·√(1 − √(1 − 4·Sₙ²/(n²·R⁴)))，则对 n ≥ 4 数值吻合（可由 Sₙ = S₂ₙ·cos(π/n) 与半角公式严格导出）；n = 3 时需取另一支（1 + √(1 − …)）。式 3.57 后半（Sₙ = S₂ₙ·√(1 − S₂ₙ²/(n²·R⁴))）按字面验证自洽；式 3.55 两向亦自洽。

待核：是转写丢失内层「1 −」，还是原书排印如此？
