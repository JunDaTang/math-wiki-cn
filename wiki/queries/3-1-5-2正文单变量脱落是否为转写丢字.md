# 3.1.5.2 正文单变量（n、r、R）脱落是否为转写丢字？

3.1.5.2 正文多处脱落单斜体变量：

- 「具有 条相等的边和 个相等的角」——两处缺 n
- 「半径分别为 的内切圆和外接圆」——缺 r 与 R
- 「分解一个正凸 边形将得到 个……三角形」——两处缺 n
- 「 边形的面积」（式 3.56 前导句）——缺 n

这些均为典型 OCR 单斜体变量脱落。待核：是否据原书补全？是否还有其他被吞掉的符号？
