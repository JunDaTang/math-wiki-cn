# 式 2.294 的变量下标是否错乱？

**问题**：2.19.2 注 (2) 中，正文称「若利用函数标度 $x = f(z_2),\ y = g(z_2)$，**对于变量 $z_1, z_2, z_3$**，形如……的方程能够表示为平行于坐标轴的两族曲线和任意一族直线」，式 (2.294) 写作

$$f(z_2)\,\varphi(z_1) + g(z_2)\,\psi(z_1) + \chi(z_1) = 0.$$

疑点有二：标度句中 $x = f(z_2)$ 与 $y = g(z_2)$ 的自变量都是 $z_2$（重复）；方程 (2.294) 中 $z_3$ 完全缺席——宣称涉及三个变量，实际只出现两个。

**最小修复方案**：第二处标度与方程第二项的 $g(z_2)$ 均应为 $g(z_3)$。修复后的结构为：$z_2$ 载横坐标标度（$x = f(z_2)$，对应竖直直线族），$z_3$ 载纵坐标标度（$y = g(z_3)$，对应水平直线族），$z_1$ 载第三族（任意一族直线，由 $\varphi(z_1), \psi(z_1), \chi(z_1)$ 参数化）。

**支持该修复的内部证据（欧姆定律算例）**：对 $R \cdot I = U$ 取对数得 $\log R + \log I = \log U$；令 $x = \log R,\ y = \log I$ 得 $x + y = \log U$，即 (2.294) 的特殊形式，其中 $z_1 = U$（$\varphi = \psi = 1,\ \chi = -\log U$，载斜率为 $-1$ 的直线族）、$z_2 = R$（载 $x$ 轴标度）、$z_3 = I$（载 $y$ 轴标度）——恰验证上述三变量分工。

**判定倾向**：疑为转写之误（$z_3$ 误作 $z_2$），最小修复如上。最终确认需对照原版。
