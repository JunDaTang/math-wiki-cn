# Fit 数据区大面积乱码之辨

## 疑点

Mathematica 小节 In[1] 数据表之后，出现数十行系统性乱码：重复的「if i_n (i_n) = i_{n−1}(i_{n−1}), … if i_{n−1} (i_{n−1}).」、成片的「(otherwise)」「s.t.」以及大量星号与不等号碎片（`* * * … < < < … >.`），为本源最严重的损坏区域。

## 分析

据上下文推断：In[1] 定义数据表 l（10 个数值，元素对应赋值 1, 2, …, 10），In[2] 随即以 {1,x,x²,x³,x⁴} 拟合并得到 Out[2]。原书此处应仅重复/续排数据表与赋值说明；乱码块不承载可复原的独立数学内容（更像 OCR 对分段条件排版或表格线的系统性误读）。

## 处置

仅编目、不尝试复原。凡依赖该区域正文的论断（尤其「这完全满足给定的数据。e^(1−0.5x) 的级数展开取了前四项」）可靠性存疑，见 [[findings/Mathematica-Fit系数与e的1减0点5x级数之说不符]] 与 [[queries/e的1减0点5x级数前四项之说与拟合系数不符之辨]]。待原书核对。
