# 5.4.2 全节系统性转写讹误清单

**问题**：《数学手册（原书第10版）》5.4.2「线性丢番图方程」的中文转写存在系统性脱字——数学符号（ℤ、b、n、数字）与关键字成段丢失，另有形近字讹误与衍文。本页汇总清单并给出依语义的重构，供与原书核对。此模式与 5.3.4–5.3.8 各节的「全节系统性转写讹误清单」query 一致。

## 脱字清单（[ ] 内为重构）

| 转写原文 | 重构 |
|---|---|
| 「称作 个未知数的丢番图方程」 | 「称作 [n] 个未知数的丢番图方程」 |
| 「系数在整数集 中的多项式」 | 「系数在整数集 [ℤ] 中的多项式」 |
| 「 是一个整常数」 | 「[b] 是一个整常数」 |
| 「迄今只有 个未知数并且至多两次」 | 「只有 [两] 个未知数并且至多两[二]次」 |
| 标题「n = 时的解法」 | 「n [= 2] 时的解法」 |
| 「用 除方程」（两处） | 「用 [gcd(a₁,a₂)] 除方程」；算例处「用 [3] 除方程」 |
| 「gcd(a₁,a₂,⋯,aₙ) 是 的因子」 | 「…是 [b] 的因子」 |
| 「如果 … 有解，而 是变量区域」 | 「而 [ℤ] 是变量区域」 |
| 「千是在解集中有 n−1 个自由变量」 | 「[于] 是在解集中有…」（「千」系「于」之讹） |
| 「对千 的子集，这个命题不正确」 | 「对[于] [ℤ] 的子集，这个命题不正确」 |
| 「因为 gcd(2,4,3)=1 的因子」 | 「因为 gcd(2,4,3)=1 [是 3] 的因子」 |
| 「当且仅当 gcd(2,4) 3z 的因子时可解」 | 「gcd(2,4) [是 3−3z] 的因子」 |

## 衍文与混排

- 「1·(−1)+2·1=1 2以及」——「2」为衍文。
- 「如在第 500 5.4.1.4, 4.中所指出的」「第 503 5.4.2, 4.」（两处）——页码与节号混排，疑为「第 500 页，5.4.1.4, 4.」之类。
- 「入给定方程可以证明」——「入」疑为衍文或「对」之讹。

## 待办

1. 与原书（德文版或中译纸本）逐条核对上述重构是否准确。
2. 「至多两次」是否应为「至多二次」（次数 ≤ 2）。
3. 「对 ℤ 的子集，这个命题不正确」一句的原文精确措辞（涉及该 caveat 的准确范围）。
