# 式 (12.130) 前句唯一性的适用范围

**问题**：(12.130) 前句转录作：「如果 {α_n} 是满足 Σ∣α_n∣² < ∞ 的任一数列，那么存在唯一元 x ∈ H，其傅里叶系数等于 α_n 并且成立帕塞瓦尔等式」。

**分析**：

- 仅就「傅里叶系数等于 α_n」而言，唯一性对一般正交规范系**不真**：若 x₀ = Σα_n e_n（其系数恰为 α_n），则 x₀ + z（任意 z ∈ H₀⊥，H₀ = lin{e_n}‾）有相同系数。
- 但若把帕塞瓦尔等式并入对 x 的要求，则唯一性**成立**：z ≠ 0 时 ‖x₀+z‖² = ‖x₀‖² + ‖z‖² > Σ∣α_n∣² = ‖x₀‖²，破坏帕塞瓦尔。
- 若限定 x ∈ H₀ 或系统完备（H₀ = H），唯一性亦成立。

**待澄清**：原书本意是 (i)「存在 x：系数为 α_n 且帕塞瓦尔成立」（此时唯一性为真但陈述结构特殊），(ii)「存在唯一 x 使系数为 α_n」（此为误述），还是 (iii) 默认系统完备/限定 H₀。复算细节见 [[findings/式12-126至12-131傅里叶理论全链转录复算]]。
