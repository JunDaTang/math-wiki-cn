# 「将向量 a 作为第 n + 1 行添加到矩阵 A」是否应为「第 n + 1 列」？

**问题**：4.5.2.1 定义增广矩阵的句子中，「第 n + 1 行」是否为「第 n + 1 列」之讹？

**证据（支持为「列」）**：

- 记法 (A, a) 表示 a 拼接在 A 的右侧，增广矩阵为 (m, n+1)；
- 式 (4.177b) 明确定义 a 为 m 维列向量；
- 高斯消元的式 (4.185a–b)、(4.186) 中常数项 a_μ 位于矩阵最后一列；
- 同段稍后称 a 为「行向量」亦与 (4.177b) 矛盾，两处疑为同源错误。

**结论倾向**：应为「第 n + 1 列」。本 wiki 相关页面（[[concepts/增广矩阵]]、[[methodology/线性方程组可解性判别流程]]）已按「列」表述；仍需原书最终确认。
