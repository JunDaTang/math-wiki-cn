# 什尔尼科夫情形 a 参数 ε 之辨

## 疑点

源文（17.3.2.3 之 2 情形 a）：“依据图 17.35(a) 中的变化 A, 若在 ε ≠ 0 处分界线环破裂，则在 ε = 0 处恰有一个 (17.67) 的周期轨。”

## 证据

ε=0 时分界线环 γ₀ 本身存在（定理前提即设 ε=0 处有同宿环），周期轨应出现在**环破裂之后**的 ε≠0 参数处，而非 ε=0 处；“在 ε=0 处恰有一个周期轨”与前提自相矛盾。平行句（变化 B）“若在 ε ≠ 0 处分界线环破裂，则没有周期轨”未标参数位置，但语义上同样指破裂后的参数。

## 结论倾向

“在 ε = 0 处”疑为“在 ε ≠ 0 处”之讹（"≠"被脱落或误排）。需对照原书闭合。
