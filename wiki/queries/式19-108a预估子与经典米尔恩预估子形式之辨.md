# 式 (19.108a) 预估子与经典米尔恩预估子形式之辨

**源文形式**：

```latex
(19.108a)  y_{i+1}^{(0)} = y_{i-2} + 9y_{i-1} - 9y_i + 6h(f_{i-1} + f_i)
```

**复算**：对 y = 1, x, x², x³, x⁴ 逐一检验均精确成立 ⟹ 四阶预估子，数学上成立（本维基直接复算证据）。

**问题**：经典米尔恩预估子为 y_{i+1}^{(0)} = y_{i−3} + (4h/3)(2f_{i−2} − f_{i−1} + 2f_i)，形式迥异。源文未给 (19.108) 对冠名，亦未给 (19.108a) 的出处。(19.108a) 是否原书原样？若是，其为哪一族四阶预估子（基于 y 值外推而非 f 值外推）？

**连带问题**：稳定化校正子 (19.109) 的系数 0.9/0.1 与 0.1/6.7/30.7/8.1 亦不对应经典 Hamming 校正子形式（复算同为四阶精确），系数来源待查。

**验证路径**：与原书核对；(19.109) 可与 Hamming 型修改预估—校正格式的系数表比对。见 [[findings/式19-105至19-109预估—校正公式复算]]。
