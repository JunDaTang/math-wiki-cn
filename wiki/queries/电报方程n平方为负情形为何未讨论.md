# 电报方程 n² 为负的情形为何未讨论

## 问题

电报方程约化链中 n² = (b² − ac)/a²（式 9.98b）。当 **ac > b²** 时 n² < 0：

- 自变量代换 (9.98c) 中 n/m 为虚数，ξ、η 变为复变量；
- 黎曼函数 v = I₀(√((ξ−ξ₀)(η−η₀))) 的宗量转负，而 I₀(iz) = J₀(z)，应换为 J₀；
- 解 (9.98j) 中 I₀/I₁ 相应换为 J₀/J₁（或保持 I 记号但宗量取虚）。

n² < 0 对应弱阻尼/过恢复的振荡情形，物理上常见，但手册既未声明 n² > 0 的前提，也未讨论此情形。

## 候选解释

1. 原书有前提假设（如 b² > ac）被转写遗漏；
2. 手册确属省略（只给出一个代表情形）。

## 待办

- 对勘原书确认是否有前提条件。
- 数值复验：对 n² < 0 情形检验 J₀ 形式的黎曼函数是否满足 z_{ξη} − z/4 = 0 的伴随条件与特征线条件。
