# 11.3.4 例题的常数解属于原齐次方程还是伴随齐次方程？

## 问题

11.3.4 的算例（奇异核 (1/π)sin y/(cos y−cos x)，柯西主值）转写所示方程为**原齐次方程**（对 y 积分、未知函数 φ(y)），但其结论「齐次方程仅有解 φ^h = c·√(1/π)」经独立验证应属**伴随**齐次方程。原书此处展示的究竟是哪个方程？

## 证据

1. **所示方程与计算不一致**：所示方程核分子为 sin y（对 y 积分），但 K_i(y) 的计算使用被积函数 sin x·sin(ix)（并取 α_i = √(2/π)sin ix）——变量排布对应的是另一个方程。
2. **独立验证（原齐次方程）**：由 11.3.3 的核矩阵结果 Tβ_j = −α_j（j ⩾ 1）与 {β_j} 在 L²[0,π] 中的完备性，原齐次方程 Tφ = 0 仅有平凡解。
3. **独立验证（伴随齐次方程）**：K₀j = 0 ⟺ T*α₀ = 0，故常数函数 √(1/π) 是伴随齐次方程的解；且按伴随方程标准形式核 (1/π)sin x/(cos x−cos y) 计算应得 K_i(y) = −√(2/π)cos(iy)。
4. **符号差异**：转写的 K_i(y) = +√(2/π)cos(iy) 与上述 −√(2/π)cos(iy) 差一符号（所用分母为 cos y−cos x 而非 cos x−cos y）；正交性与「K₀ 完备化 ⟹ 解为常数」的结论不受符号影响。

## 待确认

- 原书 11.3.4 该算例展示的方程形式（原齐次还是伴随齐次）与变量排布；
- K_i(y) 的符号（±√(2/π)cos(iy)）在原书中的正负；
- 该算例与 11.3.3 算例（同一核）的配对关系：二者合起来恰好演示「原齐次仅平凡解 + 伴随齐次一维常数解」的完整图像。
