# 表 2.7 为何不含 sech 与 csch？

## 现象

表 2.7（「x > 0 时，具有相同自变量的两双曲函数间的关系」）仅给出 sinh、cosh、tanh、coth 四函数的两两互表（4×4，对角线为空），不含 sech 与 csch 的行列。手册未说明省略原因。

## 关联疑点：「x > 0」条件的必要性

表头冠以总条件 x > 0，但部分条目在更大范围成立，条件充分而不必要：

- cosh x = √(sinh²x + 1)：对一切 x 成立（cosh 恒正）。
- tanh x = sinh x/√(sinh²x + 1)、coth x = √(sinh²x + 1)/sinh x：分别对一切 x、一切 x ≠ 0 成立。
- tanh x 与 coth x 互为倒数：对一切 x ≠ 0 成立。
- 真正需要 x > 0 的是含 √(cosh²x − 1)（即 |sinh x|）的条目，如 sinh x = √(cosh²x − 1)。

## 可能解释（待查证）

- sech/csch 的互表可经倒数平凡导出（先查 cosh/sinh 的表达式再取倒数），手册或为省篇幅而省略。
- 也可能原书即如此编排，并非转写遗漏。
