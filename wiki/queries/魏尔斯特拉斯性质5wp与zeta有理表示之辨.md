# 魏尔斯特拉斯性质 (5) ℘ 与 ζ 有理表示之辨

## 待裁决问题

源文 ζ/σ 性质 (5)：“每个椭圆函数是魏尔斯特拉斯函数 ℘(z) 和 ζ(z) 的有理函数。”该断言按字面是否成立？原文的正确表述是什么？

## 反例论证（以 ℘′ 为反例）

℘′ 本身是椭圆函数（℘ 双周期亚纯，求导保持双周期性）。假设 ℘′ = R(℘, ζ)，R 为二元有理函数。

1. **平移约束**：作平移 z ↦ z + 2ωᵢ（取 2ζ(ωᵢ) ≠ 0 者；由 Legendre 关系 η₁ω₂ − η₂ω₁ = πi/2 ≠ 0，ηᵢ = ζ(ωᵢ)，知二者不全为零——此为标准理论背景）。℘ 不变而 ζ 增加 c = 2ζ(ωᵢ)，故 R(x, y) = R(x, y+c) 在像集 {(℘(z), ζ(z))} 上成立。
2. **像集 Zariski 稠密**：若 ℘、ζ 满足多项式关系，则像集含于某代数曲线；但经反复平移，像集中同一 x 对应无穷等差点列 y, y+c, y+2c, …，与代数曲线的性质矛盾。故 ℘、ζ 代数无关，R(x,y) = R(x,y+c) 为恒等式，R 作为 y 的有理函数具非零周期必与 y 无关，即 ℘′ ∈ ℂ(℘)。
3. **奇偶性矛盾**：℘ 偶、℘′ 奇。若 ℘′ = S(℘)，则 −℘′(z) = ℘′(−z) = S(℘(−z)) = S(℘(z)) = ℘′(z)，故 ℘′ ≡ 0，与 ℘ 非常数矛盾。

故按字面断言为假。

## 标准定理（供替换引用）

同一周期格上的每个椭圆函数都是 ℘ 与 ℘′ 的有理函数（ℂ(Λ) = ℂ(℘, ℘′)，后者为 ℂ(℘) 的二次扩张）；等价地可经 σ 的乘积表示写出（与本节 (14.121) 的工具衔接）。
