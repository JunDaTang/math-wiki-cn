# 式 3.110h 左端的 y_N 是否应为 x_N？

## 问题

交会法解算链的式 (3.110h) 转写为：

$$y_N = x_A + s_{AN}\cos t_{AN} = x_B + s_{BN}\cos t_{BN}$$

左端 $y_N$ 与右端（$x$ 分量正算公式、由 $x_A$、$x_B$ 出发、用 $\cos$）是否应为 $x_N$？

## 证据与推理

- 结构平行：(3.110g) 为 y 分量式（$y_A + s_{AN}\sin t_{AN} = y_B + s_{BN}\sin t_{BN}$），(3.110h) 与之逐项对偶（$x \leftrightarrow y$、$\cos \leftrightarrow \sin$），唯一不匹配处是左端的 $y_N$。
- 本节通例：坐标正算恒为 $y = y_0 + s\sin t$、$x = x_0 + s\cos t$（3.106c–d、3.112n–o、3.114h–k），$x$ 分量必配 $\cos$ 与 $x_0$。
- 双路检核设计：(3.110g–h) 应是「y 从两端算、x 从两端算」四式两对；左端作 $y_N$ 则第二对失去意义。

## 疑似正确形式

$$x_N = x_A + s_{AN}\cos t_{AN} = x_B + s_{BN}\cos t_{BN}$$

## 核实途径

对照原书式 (3.110h)；核实前引用该式时应按疑似形式并加注。见 [[findings/交会法两变体公式]]。
