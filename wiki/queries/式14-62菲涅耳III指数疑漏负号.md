# 式 (14.62) 菲涅耳 I_III 指数疑漏负号

## 疑点

源文（14.4.3 例 5）写：

$$I_{III} = e^{i\pi/4}\int_R^0 e^{ir^2}\,\mathrm{d}r = \frac{1}{2}\sqrt{2}\,(1+i)\left[i\int_0^R \sin r^2\,\mathrm{d}r - \int_0^R \cos r^2\,\mathrm{d}r\right]$$

但沿 π/4 射线 z = re^{iπ/4} 时 z² = ir²，被积函数 e^{−z²} 应为 **e^{−ir²}**。

## 内部证据（复算证实）

1. **参数化证据**：z² = (re^{iπ/4})² = r²e^{iπ/2} = ir²，故 e^{−z²} = e^{−ir²}；
2. **括号自洽性**：源文括号展开 [i∫sin r² dr − ∫cos r² dr] = −∫₀^R (cos r² − i sin r²)dr = ∫_R^0 e^{−ir²}dr，仅与 e^{−ir²} 自洽；
3. **反证**：若取 e^{+ir²}，联立 lim I_I = ½√π 与 I_II → 0 只能得出 ∫cos x² dx = +½√(π/2)、∫sin x² dx = −½√(π/2) 的矛盾结果，与 (14.62) 所称两积分相等且均为正不符。

## 判断

判为转写漏负号；修正为 e^{−ir²} 后全链自洽，且与独立已知值 ½√(π/2) 一致（见 [[findings/式14-56至14-62及ez例复积分计算实积分转录复算]]、[[methodology/扇形围道指数估计流程]]）。
