# Part 之 i = 0 脱文之辨

**问题**：《数学手册（原书第10版）》20.2.1 节在描述 Part 语义时作「特别 = 时得到的是该表达式的头」，句中脱「i = 0」——「特别」与「=」之间当有「i 」，即应为「特别 **i = 0** 时得到的是该表达式的头」。

## 证据

- 节内自洽证据：式 (20.4) 后明确「obj₀ 称为表达式的头；对它指派了数 0」，而元素「可以用它们的数 1, …, n 指称」——头对应 0、元素对应 1, …, n 的编号约定正是 `Part[expr, i]` 中 i 的取值依据。
- 同源脱字：紧邻的上句「其中 是对应元的数」同样脱 i（见 [[queries/20-2-1全节系统性转写讹误清单]] 第 4 项），两处脱 i 属同一转写问题。
- 独立可验证背景：`Part[expr, 0]` 返回表达式的头，是标准 Mathematica 语义（与 `Head[expr]` 等价）。

## 影响

若不校勘，读者无法从本节文本得知 `Part[expr, 0]` 的含义，Part 的语义（元素编号 1..n、头编号 0）将缺失一半，直接误导。相关语义页 [[concepts/Part（部件提取与头）]] 已按校勘后的理解撰写并加警示。
