# 公式 1 条件「n ∓ −1」疑为「n ≠ −1」之辨

## 疑点

式 1 转写作（逐字转录）：

```latex
1. \int X ^ { n } \mathrm { d } x = { \frac { 1 } { a ( n + 1 ) } } X ^ { n + 1 } ( n \mp - 1 )
```

条件「$(n\mp-1)$」于义无解：式 1 是幂函数积分，条件只需排除 $n=-1$（其时参见式 2，注文尚存「当 $n = - 1$ 时，参见2.」）。

## 证据

同族公式的条件均以 $\neq$ 转写正常：式 3 之 $(n \neq - 1, \neq - 2)$、式 8 之 $(n \neq 1, 2)$、式 12 之 $(n \neq 1, 2, 3)$。

## 初判

「$\mp$」当为「$\neq$」之误植（OCR 将不等号拆认），条件应为 $(n\neq-1)$。属符号转写讹误，与上标/符号横杠脱落模式（[[findings/21-4转写讹误之纯文本区上标脱落分布]]）同类。待纸本核销。
