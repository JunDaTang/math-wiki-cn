# 12.7 全节系统性转写讹误清单

**开放问题**：12.7 节导入文本存在哪些系统性转写讹误？哪些需要对照原书修订？

与 12.1–12.4、11.4–11.5 各节的转写质量问题同源（如 [[queries/12-4全节系统性转写讹误清单]]、[[queries/12-3全节系统性转写讹误清单]]），本节讹误以「脱字 / 符号丢失」为主。

## 已识别讹误

| 位置 | 转写文本 | 应为 / 疑为 |
|---|---|---|
| 12.7.1 | 「这就是贮九中有界序列」 | ℝⁿ |
| 12.7.1 | 「其极限不必属千 A」 | 属于 |
| 12.7.1 | 「参见第 896 12.7.1」 | 页码残留，应为「参见 12.7.1」 |
| 12.7.2.1 | 「算子 : X -------,.」 | $T: X \to Y$（箭头转写损坏） |
| 12.7.2.2 | 「如果 是巴拿赫空间」 | 缺主语，数学上推断为 $Y$ |
| 12.7.2.2 b) | 「如果 是连续线性算子」 | 缺 $T$ |
| 12.7.2.2 c) | 「如果 $\lambda \neq 0$ 不是 的本征值」 | 缺 $T$ |
| 12.7.2.3 | 强弱收敛箭头全部丢失（均作 →） | 强收敛与弱收敛需区分（⇀ / $\stackrel{w}{\to}$） |
| 12.7.2.3 b) | 「$x_n \to T x_0$」 | $Tx_n \to Tx_0$（脱算子 T） |
| 12.7.2.3 算例 | 「并设 是 $\ell^2$ 中由…给出的算子」 | 缺 $T$；算例标号（A/B）缺失 |
| 12.7.3 b) | 「Im（入 T*）= ker（入 T)」 | $\operatorname{Im}(\lambda I - T^{*}) = \ker(\lambda I - T)^{\perp}$，疑脱 ⊥ |
| 12.7.3 d)β) | 「伴随方程 $\lambda f - T^{*}f =$」 | 缺右端 0 |
| 12.7.4 | 「那么 是有穷维算子列…的极限」 | 缺 $T$ |
| 12.7.4 | 「如果 是一有穷维算子，并且 $T = I - C$」 | 缺 $C$，主语混乱 |
| 12.7.5 | 「I- 的本征值集至多是可数的」 | $T$ 的本征值集 |
| 12.7.5 | 「总有本征值 $\lambda$，$\lvert\lambda\rvert = \|T\|$ I- 的本征值集」 | 疑两句粘连、句读混乱 |
| 12.7.5 | 「这里 $\{e_k\}$ ｝是 的本征向量」 | 多余「｝」与缺 $T$ |
