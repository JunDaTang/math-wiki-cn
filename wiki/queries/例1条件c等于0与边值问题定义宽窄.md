# 例 1「条件 c = 0」的层面问题与边值问题定义宽窄

## 问题一：例 1 的「条件 c = 0」是否为点值条件？

手册 9.1 要点 2 的算例写道：微分方程 −y′ sin x + y cos x = 1 有通解 y = cos x + c sin x，对于条件 c = 0，得到特解 y = cos x。

疑点：「c = 0」是对通解常数本身施加的条件，而本节对「附加条件」的定义是 y 及其导数**在点处**取给定值（初值/边界条件）——两者不属同一层面。可能情形：

- 原书即为「取 c = 0 得一特解」的简写，并非严格意义上的附加条件；
- 或原书本为某点值条件，转写时失真。

复算注记（编者计算，供核对候选点值条件）：对本方程，

- y(0) = cos 0 + c·sin 0 = 1 对**一切** c 成立，故条件 y(0) = 1 不能定出 c = 0；
- 能等价定出 c = 0 的点值条件例如 y′(0) = 0（因 y′(0) = c）或 y(π/2) = 0（因 y(π/2) = c）。

故若原书确为点值条件，更可能是 y′(0) = 0 或 y(π/2) = 0 一类，而非 y(0) = 1。待与原书核对。

## 问题二：边值问题定义以「两端点」还是「几个点」为准？

- 要点 2：「如果在区间的**两个端点**都有给定的值，则求解的问题被称为一个边值问题。」
- 要点 4：「如果一个常微分方程的解和/或其导数在其定义域中的**几个点处**被给出……具有边界条件的一个微分方程被称为边值问题。」

要点 4 的表述更一般。[[concepts/边值问题]] 页暂以要点 4 为准并标注待裁定；最终以 9.1.3 小节为准（见 [[queries/9-1-1至9-1-3子小节未入库回指缺口]]）。
