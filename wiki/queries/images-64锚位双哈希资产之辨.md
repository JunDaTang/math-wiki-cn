# images-64 锚位双哈希资产之辨

## 问题

《数学手册(原书第10版)》书根 `images/` 目录的同一锚位 `images--64` 下，挂接多枚字节级互异的哈希命名图像资产。立题设问：第2章（函数）插图集的 `images--64` 锚位现对应两个不同哈希的图像资产（0a74ffc6 与 0abd8458）——二者系同锚多图、同一原图的重复或分块抽取，抑或编号讹误？

- 立题两枚资产的源页 slug 均含 `6-images--64` 前缀、仅哈希不同：[[10-数学手册原书第10版--6-images--64-0a74ffc61fad45e7409e3dd26e6364d6caaab09381343586f4dbdfe86982bd5b--8r4woa]] 与 [[10-数学手册原书第10版--6-images--64-0abd84587c0492e7b9edaa47a66c843a3cde250659450a2ac5ae7fb491c810de--exsc01]]（证据强度：强，字符串直接比对）；上表五枚源页 slug 亦均具该前缀、仅哈希不同。
- 哈希互异可由文件名直接复核。直接证据：[[images-64锚位哈希资产增至五枚]]。
- 0a74ffc6 源页标题以单数语气占用编号 64（“第2章 images-64 插图资产”），暗示其入库时曾视 64 为该资产的唯一锚位标识（证据强度：中，措辞推断）。
- 0abd8458 为 JPG、7.4 KB 单图；0a74ffc6 的图像规格见其源页。两图是否同页、同图组，待目验比对。

## 证据边界

- 归属状态仅为各 source 页自身记录；锚位相同不构成归属传递。
- 字典序入册、来源位置邻近第2章等均为推断，非直接证据。

## 候选解释

以下候选解释系立题时针对两枚资产（0a74ffc6、0abd8458）所设：

1. 64 为页位或图组锚，同锚可挂多图；
2. 同一原图的重复或分块抽取；
3. 转写或编号讹误。

## 子问题

1. 五枚 0a/0b 哈希资产是**同一插图的不同编码，还是五幅不同插图**？SHA-256 只能证明字节级互异，无法回答图像级异同，宜辅以感知哈希比对。
2. **锚位 “64” 的语义**为何：目录序号、正文引用锚点，还是入库批次位？
3. **同锚异章**作何解释：兄弟页既有暂归第2章者（0abd8458、0a74ffc6），又有关联第21章者（0a6457d5）——锚位与内容归属之间无稳定映射。此前归属是暂定假设，还是锚位 64 本身是跨章的入库聚合位？
4. **序数前缀 `6` 与第2章注记同号**（`--6-第2章-函数--`），是否指示入库来源位置邻近第2章，抑或纯属结构性巧合？
5. 新入册的 `0b1a25d5` 为该锚位群**首枚 `0b` 起头哈希**（此前四枚均 `0a` 起头），资产是否按哈希字典序入册？

## 待验步骤

1. 目验两图（0abd8458、0a74ffc6）内容，判定是否同页、同图组或互为重复（扩展至五枚资产的图像级异同判定，见子问题 1）。
2. 清点语料中 `images--N` 锚位总数与每锚位图数分布，确认“一锚一图”是否为常态（并核对书根 `images/` 目录与 `<部号>-images` slug 前缀之间的作用域歧义）。
3. 与总目录 [[10-数学手册原书第10版--2-目录--1srm7m]] 及第2章正文插图编号对表，定位两图所属小节。
