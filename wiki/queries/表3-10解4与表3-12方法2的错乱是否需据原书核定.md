# 表 3.10 解 4 与表 3.12 方法 2 的括号/分母/编号错乱是否需据原书核定？

## 表 3.10（第三基本问题 SWS）

- **括号错乱**：「tan α − β/2 = sin (a - b/2) / sin (a + b/2) cot γ/2」应为 tan((α−β)/2) = [sin((a−b)/2)/sin((a+b)/2)]·cot(γ/2)；「tan α + β/2 = cos (a - b/2) / cos (a + b/2) cot γ/2」应为 tan((α+β)/2) = [cos((a−b)/2)/cos((a+b)/2)]·cot(γ/2)。此复原与表 3.11 解 3（WSW，转写较完好）经边角对偶一致，本 wiki 亦由纳皮尔类比独立推导核对，置信高。
- **解 4 严重粘连**：Z/N、Z′/N′ 结构无法直接辨读。可辨末两行「cos (c/2) = Z/2 / sin (α + β/2)」「sin (c/2) = Z′/2 / sin (α - β/2)」。候选复原（Delambre 型，推断）：Z = cos((a−b)/2)·cos(γ/2)、Z′ = sin((a−b)/2)·cos(γ/2)，且 cos(c/2) = Z/sin((α+β)/2)、sin(c/2) = Z′/sin((α−β)/2)，tan((α+β)/2) = [cos((a−b)/2)cos(γ/2)]/[cos((a+b)/2)sin(γ/2)]、tan((α−β)/2) = [sin((a−b)/2)cos(γ/2)]/[sin((a+b)/2)sin(γ/2)]。**待据原书核定，不作为公式结论记录。**

## 表 3.11（第四基本问题 WSW）

- 检验行「cos α + cos β cos γ ⩾ 0 → α 在象限 I / α 在象限 II」中的 α 疑均应为 **a**：因 cos a = (cos α + cos β cos γ)/(sin β sin γ) 决定的是边 a 的象限（与「a 可以位于象限 I 或 II」呼应）。

## 表 3.12（第五、六基本问题）

- 「1 0 个解」粘连（应为「1 → 0 个解」等）；案例编号 3.1.2 重复出现；第六问题分支整块重复两行。
- **方法 2 第一 γ 式的分母**：转写为 tan(γ/2) = cot((α+β)/2)·cos((a−b)/2)/sin((a+b)/2)。本 wiki 由纳皮尔类比（极三角形推导）得到标准形 tan(γ/2) = cot((α+β)/2)·cos((a−b)/2)/**cos((a+b)/2)**，且第二 γ 式与两个 c 式均与标准形一致——第一 γ 式分母疑为 sin → cos 之误。此为推断，待据原书核定。

## 建议

优先据德文原书核对表 3.9–3.12 全部公式（尤其解 4 的 Z/N 结构与该 γ 式分母）；在核定前，损坏文本一律不记为公式结论（本 wiki 相关页面已如此处理）。
