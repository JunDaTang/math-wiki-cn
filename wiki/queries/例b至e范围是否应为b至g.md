# 「例 B∼E」范围是否应为「B∼G」

## 问题

12.1.3 断言：「空间 𝔽ⁿ 是 n 维空间，在例 B∼E 中所有其他的空间都是无穷维的空间」。按 12.1.2 序列例子族编号：A = 𝔽ⁿ，B = s，C = φ，D = m，E = c，F = c₀，G = ℓ^p。字面范围 B∼E 涵盖 s、φ、m、c，但 **c₀（例 F）与 ℓ^p（例 G）未被包含**。

## 分析

- 上下文中 𝔽ⁿ 为序列例 A，紧随其后的「所有其他的空间」自然应指同一例子族的全部其余成员，即 B∼G；
- c₀ 与 ℓ^p 无穷维可独立复算证实：{e₁, e₂, …} 在任意序列空间中线性无关（见 [[findings/式12-15至12-18线性无关凸集与锥转录复算]]），故无论正文范围如何，数学事实不受影响；
- 不排除「B∼E」另有所指（如函数空间例 B–E），但该列表以 B(T) 开头且不含 𝔽ⁿ，与「𝔽ⁿ 是 n 维」的对照语境不合。

## 待决事项

对照原书确认「B∼E」是否为「B∼G」之讹（或原书即作 B∼E 而存在编排差异）。
