# 式 5.308 重言式与矛盾式是否应为 f(b)=1 与 f(b)=0？

**问题**：手册 5.7.5 式 (5.308) 转写为

```
恒等 f(b)=b,  否定 f(b)=b̄,  重言 f(b)=b,  矛盾 f(b)=b
```

其中「重言」与「矛盾」的公式是否分别应为 $f(b)=1$ 与 $f(b)=0$？

## 证据

1. 按转写文本，「重言」「矛盾」与「恒等」三者同为 $f(b)=b$，自相矛盾，且与 n=1 时恰有 4 个互异函数的计数冲突。
2. 常值函数 $f_0\equiv 0$、$f_1\equiv 1$ 已由式 (5.307) 定义；(5.308) 列举的四个函数应为恒等、否定、$f_1$（重言）、$f_0$（矛盾）。
3. 同句「存在 个布尔函数」的个数脱落，应为 4（与 $2^{2^1}=4$ 一致，参见 [[queries/布尔函数个数是否应为2的2的n次方]]）。
