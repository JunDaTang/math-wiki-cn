# 19.1 全节系统性转写讹误清单

**问题**：19.1 全节存在系统性 OCR/转写讹误，需逐项核对原书并在此清单上销号。已单独立项的存疑点见 related；本页收录其余全部讹误。

## 系统性字符混淆

- **儿 ↔ 几**：“儿乎不变”、“儿何插值”（多处）应为“几乎”、“几何”。
- **千 ↔ 于**：“对千”、“等千”、“适用千”、“源千”、“远小千”、“千是”（应为“于是”）等，遍布全节。
- **共辄 ↔ 共轭**：“成对的共辄复根”、“包括复共辄根在内”（两处）应为“共轭”。
- **引号残缺**：“传统＇的方法”（后引号讹作 ＇）。

## 符号与下标脱落

- (19.4) 后“其中 为常数”：脱 $K$；“常数 越小”：脱 $K$。
- “第 个近似值的误差”（平方收敛句）：脱 $n$。
- “为通过 次多项式”：脱 $n$。
- “当选取的 使得”（试位法收敛句）：脱选点对象 $x_m$。
- “在 x = x₀ 处的根”（19.1.2.1 首句）：疑为“值”。
- (19.16) 通式表撇号与下标系统性乱码（"xn0an-1" 应为 $x_0 a'_{n-1}$ 等），以算例 F 干净表为复原基准。
- (19.18c) "$r_1 x$" 疑脱下标 0 → 已立项 [[queries/式19-18c之r1x疑为r1x0之辨]]。

## 格式与数字讹误

- "l9.18d" 应为 "19.18d"。
- 页码回指残缺：“第 1249 19.2.2”、“第 57 1.6.3.2”（脱“页”字与节号分隔，见 [[queries/19-1未入库回指缺口]]）。
- 算例 H 正/负根个数数字脱落 → [[queries/笛卡儿算例正负根个数数字脱落之辨]]。
- 算例 D 首行 Δx₁ = "−0.3" 疑为 "−0.03"（小数点脱落；由 $x_1 - x_0 = -0.03$ 与 $\Delta x_1/\Delta y_1 = 0.8798$ 双重反推，入库复算时的补充观察）。
- “在 c 之间至少存在一个实根”：脱“与 d”。
- 算例 I 引句开头衍字符“一”（“一 f(x) = p₄(x) = …”）。
