# 式 (15.96f) 第三段两指数相同之误

**优先级：高（结论级错误，中文版译者注已声明）。**

## 原文（转录，含译者注）

```text
y(t) = { 0,                                    −∞ < t < −t₀,
       { (1/a)[1 − e^{−a(t+t₀)}],              −t₀ ≤ t ≤ +t₀,
       { (1/a)[e^{−a(t−t₀)} − e^{−a(t−t₀)}],   t₀ < t < +∞.   (15.96f) ①

① (15.96f) 中，当 t₀ < t < +∞ 时，y(t) 的表达式是错误的。 译者注
```

## 疑点

第三段两个指数完全相同，相减恒为 0，与图 15.26 的图像及物理直觉（脉冲过后解应指数衰减而非归零）矛盾。

## 证据

1. **直接求解**：$t>t_0$ 段方程为 $y'+ay=0$，初值 $y(t_0)=\frac{1}{a}(1-\mathrm{e}^{-2at_0})$，得 $y(t)=\frac{1}{a}[\mathrm{e}^{-a(t-t_0)}-\mathrm{e}^{-a(t+t_0)}]$，在 $t=t_0$ 处与前段连续。
2. **卷积复核**：$y=f*h$，$h=\mathcal{F}^{-1}\{1/(a+\mathrm{i}\omega)\}=\mathrm{e}^{-at}\mathbf{1}_{t\geqslant0}$，积分得同式。

## 判定建议

正确式为 $\frac{1}{a}[\mathrm{e}^{-a(t-t_0)}-\mathrm{e}^{-a(t+t_0)}]$（第二指数为 $t+t_0$）。译者注已背书，无需再证；剩余问题是原书是否即误（第二个指数的 $+$ 是否在德文/英文原版中即为 $+$，中文排版误排为 $-$）。详见 [[findings/式15-96一阶方程傅里叶求解转录复算]]。
