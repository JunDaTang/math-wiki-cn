# 正文 Artanh 定义域「|x| ≤ 1」是否应为「|x| < 1」？

## 问题

手册 2.10.1.3 正文称 [[concepts/面积正切]] $y = \operatorname{Artanh} x$「仅在 $|x| \leqslant 1$ 时有定义」，而同节表 2.8 与式 2.213 均为 $|x| < 1$。「≤」是否为「<」之误？

## 证据

**支持「<」的一方**：

- 表 2.8：Artanh 的定义域列为 $|x| < 1$。
- 式 2.213：$\operatorname{Artanh} x = \frac{1}{2}\ln\frac{1+x}{1-x}$ 的声明条件为 $|x| < 1$。
- 正文同句即称函数具有铅直渐近线 $x = \pm 1$——$x = \pm 1$ 处对数真数为零/发散，函数无定义。

**支持「≤」的一方**：无独立证据，仅正文一处。

## 初步判断

「≤」应为「<」：$x = \pm 1$ 是铅直渐近线所在，函数在该处无定义。此为正文与表/公式之间的内部矛盾（转写或排版误差），待核对原书纸本确认。
