# 341 算例的基是否为 2 与 3？

**问题**：源文作「341 是对于基 [ ] 的伪素数，341 不是对于基 [ ] 的伪素数」，两处基值被转写脱落。应为哪两个基？

**外部复算证据**（源内脱落，以下为独立可验证背景）：

- 341 = 11·31。
- 基 2：2^10 = 1024 = 3·341 + 1 ⇒ 2^10 ≡ 1 (mod 341) ⇒ 2^340 ≡ 1 (mod 341)，故 341 是对基 2 的伪素数；341 亦是对基 2 的最小伪素数。
- 基 3：3^340 ≡ 56 (mod 341) ≢ 1，故 341 不是对基 3 的伪素数。

**初步结论**：脱落基值为 2 与 3，次序为「是对基 2 的伪素数、不是对基 3 的伪素数」。[[findings/费马检验算例组15-341-561]] 与 [[concepts/伪素数]] 已按此复原并标注。待核对原版确认。
