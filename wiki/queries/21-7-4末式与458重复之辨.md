# 21.7.4 末式与 458 重复之辨

[[sources/10-数学手册原书第10版--13-2174-其他超越函数积分--17odu4w|数学手册 21.7.4.3]] 末尾的脱号式 $\int e^{ax}\ln x\,dx$ 与指数节的 458 逐字全同：它是编号 487 的正常条目（刊本即两处收录），还是转写重复（487 实为他式或不存在）？

## 两式对照

458（21.7.4.2）：

```
∫ e^{ax} ln x dx = (e^{ax} ln x)/a − (1/a) ∫ e^{ax}/x dx  （参见 451）
```

末式（21.7.4.3，脱号）：

```
∫ e^{ax} ln x dx = (1/a) e^{ax} ln x − (1/a) ∫ e^{ax}/x dx  （参见 451）
```

仅书写顺序微异，数学内容与注文完全相同，两式均经微分复算通过。

## 两说并存

1. **刊本重出**：手册确在对数节末尾再次收录该式（编号 487），属编排上的重复；此说与编号重建假说（463–467 + 487 使全节恰 90 号无缝衔接）相容，见 [[queries/对数节编号461疑为467及463至466脱落之辨]]。
2. **转写重复**：OCR 将同一公式录入两次，刊本 487 为另一式（内容未知）或该位置本无公式；此说下 487 的真实内容成谜，需在讹误清单中单列。

## 裁定路径

查刊本 21.7.4.3 末尾：若有编号 487 的独立条目，采说一并更新 [[concepts/对数函数积分族]]；若刊本该处为他式，则本节转写丢失一式，销账于 [[queries/21-7-4全节系统性转写讹误清单]]。
