# 式 (18.142b) 「0 ⩽ j ⩽ K」疑脱 x 之辨

## 疑点

18.3.6.1 重新照录购买问题时，约束行（式 18.142b）印作

```latex
x_0 = x_a, 0 ⩽ j ⩽ K,  j = 1(1)n
```

而其源头 18.3.2.1 的式 (18.127a) 对应行为

```latex
x_0 = x_a, 0 ⩽ x_j ⩽ K,  j = 1(1)n
```

## 证据

1. 两式其余部分（OF、状态变换、决策空间）逐字相同，仅此约束行有异。
2. 「$0\leqslant j\leqslant K$」语义不通：级号 $j$ 取值 $1,\dots,n$，与容量 $K$ 无关；库存约束应为 $0\leqslant x_j\leqslant K$。
3. 算例（$K=10$，状态取 $0,\dots,10$）与 $0\leqslant x_j\leqslant K$ 一致。

## 结论倾向与待办

判定脱 $x$（应为 $0\leqslant x_j\leqslant K$）的置信度高，属系统性脱字噪声的一例（同类的还有脱 $n$、脱 $K$、脱页码等，见 [[queries/18-3全节系统性转写讹误清单]]）。同一照录块中式 (18.144) 的 max/min 之误为另一独立讹误，见 [[queries/式18-144疑为min之辨]]。
