# 式 (5.65b) 有序对相等的连接词应为合取吗？

**问题**：转写本式 (5.65b) 为

$$(a, b) = (c, d) \Leftrightarrow a = c \vee b = d$$

有序对相等的正确刻画应为 $a = c \land b = d$（两个分量**同时**相等）。原文的 $\lor$ 是否为转写讹误？

**内部矛盾证据（倾向「是」）**：

1. 按原文形式，$(1, 2) = (1, 3)$ 成立（第一分量相等即可），这使有序对失去「序」的意义；
2. 同节算例 A 明确给出 $A \times B \neq B \times A$（对 $A = \{1,2,3\}$、$B = \{2,3\}$ 逐一列举比较），若 (5.65b) 原文成立，则 $(1,2) = (2,1)$（第二分量相等），$A \times B = B \times A$，与该算例**直接冲突**；
3. (5.65b) 紧邻的 (5.64b)、(5.42) 也存在连接词讹误（见 [[queries/式5-64b对称差定义连接词讹误]]、[[queries/式5-42补集定义应为合取吗]]），提示系统性转写损伤。

**待办**：对照原书核验式 (5.65b)；若确认为讹误，回填 [[concepts/笛卡儿积]] 与 [[findings/差对称差与笛卡儿积公式组]]，并在 [[queries/5-2全节系统性转写讹误清单]] 销项。
