# 表 2.8 合并单元格转写错位如何修复？

## 问题

表 2.8 原为跨行合并单元格的排版，Markdown 转写后合并单元格被拆散，出现置空单元格与孤立行。如何修复？

## 错位清单

1. **Arcosh 首行**（y = Arcosh x）：定义域单元格与「具有相同意义的双曲函数」单元格（x = cosh y）被置空；仅 −Arcosh 行保留 1 ≤ x < ∞ 与 x = cosh y。原表应为两行共享定义域 $1 \leqslant x < \infty$ 与 $x = \cosh y$（跨行合并）。
2. **Arcoth 第二值域行**（0 < y < ∞）：成为无函数名、无定义域的孤立行；其与定义域分支 $(1, +\infty)$ 的对应关系不可见。
3. 各函数名行（面积正弦/面积余弦/…）与其下公式行之间的分组关系在纯文本表格中需靠空行暗示。

## 修复方案（建议）

按 [[findings/面积函数的定义与定义域值域表]] 中的重构表回填：将 Arcosh 两行的定义域与双曲函数列补齐为 $1 \leqslant x < \infty$ 与 $x = \cosh y$；将 Arcoth 的两行显式标注分支（$-\infty < x < -1 \to -\infty < y < 0$ 与 $1 < x < \infty \to 0 < y < \infty$）。待核对原书纸本表格的合并结构后定稿。
