# 算例二外层积分限是 0 到 2 还是 0 到 4

**状态**：复算判定已给出（应为 $\int_0^4$），归因待裁定。

## 问题

[[sources/10-数学手册原书第10版--7-84-多重积分--kr77tj]] 8.4.1.2.1 算例：$A=\int_S xy^2\,\mathrm{d}S$，$S$ 为抛物线 $y=x^2$ 与直线 $y=2x$ 围成的区域。第二序（先 $x$ 后 $y$）转写为：

$$A=\int_0^4\int_{y/2}^{\sqrt y} xy^2\,\mathrm{d}x\,\mathrm{d}y=\int_0^{\mathbf{2}} y^2\,\mathrm{d}y\left[\frac{x^2}{2}\right]_{y/2}^{\sqrt y}=\frac12\int_0^4 y^2\left(y-\frac{y^2}{4}\right)\mathrm{d}y=\frac{32}{5}.$$

中间步骤的外层积分限 $\int_0^{\mathbf 2}$ 与同一行**首尾两处** $\int_0^4$ 及结果 $\frac{32}{5}$ 直接矛盾。

## 复算判定

- 交点：$x^2=2x\Rightarrow x=0,2$，即 $(0,0)$ 与 $(2,4)$，故 $y\in[0,4]$；中间步骤应为 $\int_0^4 y^2\,\mathrm{d}y\,[\cdots]$。
- 首序（式 8.136a）：$A=\frac13\int_0^2(8x^4-x^7)\,\mathrm{d}x=\frac{32}{5}$。✓
- 第二序复算：$\frac12\int_0^4(y^3-\frac{y^4}{4})\,\mathrm{d}y=\frac12(64-51.2)=\frac{32}{5}$。✓

**结论：外层积分限应为 $\int_0^4$**；$\int_0^2$ 若按其字面计算将得到错误数值。

## 待裁定

$\int_0^2$ 是 **OCR 转写之误**（4 误作 2，或整段抄录错位）还是**原书排印之误**？该归因影响 [[queries/8-4全节系统性转写讹误清单]] 的分类（转写层 vs 原书层），需对照原书纸本裁定。
