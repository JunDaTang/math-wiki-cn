# 式 5.396 的规则数 n 与 N 记号矛盾

**问题**：5.9.6.4 开篇对 Sugeno 控制器的描述（式 5.396 前后）存在多处记号不协调，疑为转写讹误或源文排印问题：

1. 「它有 $n$ 个**输出**变量 $\xi_1,\cdots,\xi_n$」——$\xi_j$ 是法则前提中的输入，输出变量是 $y$；「输出」疑应为「**输入**」。
2. 法则下标注为 $(i=1,2,\dots,n)$，即 $n$ 条法则；但紧随其后的式 5.397 求和上限为 $N$（$\sum_{i=1}^{N}$），且 5.9.6.2 的式 5.390/5.391 又用 $n$ 作法则数。$n$（变量数？法则数？）与 $N$（法则数？结点数？）的角色未协调。
3. 「模糊集 $A_j^{(1)},\cdots,A_j^{(k)}$ 总是分割输入集 $X_j$」中的 $k$ 亦未与 $N/n$ 协调（$k$ 应为第 $j$ 个输入的语言项/模糊集个数）。
4. 式 5.394 的下标 $i_{l,r}$ 中 $l$ 未定义，疑似转写噪声。
5. 一维讨论中「输出在 个结点 $x_1,\cdots,x_N$ 上是固定的」脱数字（应为 $N$ 个结点）。

**影响**：复算 [[sugeno插值三条件与凸组合界-式5-396-400]] 时按「$N$ = 法则/结点数、$n$ = 输入变量数」的意图重构；该重构与式 5.397–5.400 的代数一致，但需原书确认。相关：[[基于知识的插值系统]]、[[5-9-6全节系统性转写讹误清单]]。
