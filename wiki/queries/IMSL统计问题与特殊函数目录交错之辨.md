# IMSL 统计问题与特殊函数目录交错之辨

**问题**：19.8.3.2 IMSL 目录转写中，「统计问题」（20 项）与「特殊函数」（10 项）两表条目为何交错错位？原书版面应如何复原？

## 现象

原转写读序（L＝统计问题，R＝特殊函数）：

L1–L10 → R4 → L11 → R5 → L12–L13 → R3 → L14–L16 → R2 → L17–L18 → R1 → 标题「特殊函数」→ L19–L20 → R6–R10。

要点：
- 「特殊函数」标题夹于「1. Elementare Funktionen」（R1）与「19. Hilfsalgorithmen」（L19）之间；
- R 栏读序为 4、5、3、2、1、6、7、8、9、10，**非单调**——若为简单之双栏逐行拉平，R 序应单调递增，故版面几何尚有未明之处；
- 一般数学方法（12 项）一表转写无交错，交错仅发生于「统计问题／特殊函数」两表之间。

## 拟复原（推断）

「统计问题」与「特殊函数」于原书为并列双栏（或类似并排版式），OCR 逐行读平致两栏条目交错。复原结果（编号、主题双自洽）：

- 统计问题 1–20：Grundlegende Kennzahlen … Mathematische Hilfsmittel（全表见 [[entities/IMSL图书馆]]）；
- 特殊函数 1–10：Elementare Funktionen … Verschiedene Funktionen（全表见 [[entities/IMSL图书馆]]）。

复原依据与置信度详见 [[findings/19-8-3三馆目录与语言清单转录校勘]] 第四节。

## 待核

1. 原书双栏之精确几何（右栏起始之垂直位置、「特殊函数」标题之实际位置、R 栏非单调读序之成因）；
2. 对照原书第 10 版纸本/扫描件逐项核对复原表。
