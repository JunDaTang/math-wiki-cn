# 公式 107 之 C、D 系数脱漏之辨

## 疑点

式 107 转写作（逐字转录，至断裂处止）：

```latex
{\frac {1}{(x + a) (x + b) (x + c) (x + d)}} \equiv {\frac {A}{x + a}} + {\frac {B}{x + b}} + {\frac {C}{x + c}} + {\frac {D}{x + d}},
A = \frac {1}{(b - a) (c - a) (d - a)}, B = \frac {1}{(a - b) (c - b) (d - b)}
```

分解式已列出 $C$、$D$ 两项，但系数只给出 $A$、$B$，$C$、$D$ 的表达式脱漏，恒等式无法核验。

## 按规律的推断

依式 106 所示留数式规律（第 $i$ 个因子的系数为其余因子在其根处取值之积的倒数）：

$$C=\frac{1}{(a-c)(b-c)(d-c)},\qquad D=\frac{1}{(a-d)(b-d)(c-d)}.$$

## 待辨

原书是否即止于 $B$（如以「等等」省略），还是转写截断？105、106、108 三式均完整，独 107 截断，转写截断之嫌较大。待纸本核销。
