# 背包算例 c 与 w 数据行疑互换之辨

## 疑点

18.3.6.2 数值算例的数据行为

```latex
W = 10, n = 6.
c_1=1, c_2=2, c_3=3, c_4=1, c_5=5, c_6=4,
w_1=2, w_2=4, w_3=6, w_4=3, w_5=7, w_6=6.
```

按此原义递推，与文中 $\varphi_j$/$u_j$ 数值表、内联算式及最优解三者均不符。

## 互换假设及证据

若将 $c$ 与 $w$ 两行**互换**（权重 $w=(1,2,3,1,5,4)$、价值 $c=(2,4,6,3,7,6)$），则：

1. **全表相符**：六行 $\varphi_j(x_{j-1});u_j(x_{j-1})$ 逐值复算完全相符。
2. **内联算式相符**：$\varphi_6$ 分段用 $w_6=4$、$c_6=6$；$\varphi_3(2)$ 用 $w_3=3$；$\varphi_3(6)$、$\varphi_3(8)$ 用 $c_3=6$——均为互换后的数值。
3. **最优解相符**：$(0,1,1,1,0,1)$ 的总重量 $2+3+1+4=10\leqslant W$、总价值 $4+6+3+6=19=\varphi_1(10)$。

即互换假设同时消解数据行、表格、内联公式、最优解四方矛盾（复算细节见 [[findings/背包问题算例表复算]]）。

## 结论倾向与待办

判定「数据行 $c$/$w$ 互换」的置信度高，但这是为恢复自洽而作的**推断**，非直接证据；可能情形包括：原书数据行即互换（排印错误）、原书正确而表格按另一组数据计算（编写错误）、或转写引入。待对照原版定谳；定谳前引用该算例数据时须注明互换假设。
