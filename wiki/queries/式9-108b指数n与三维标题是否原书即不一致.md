# 式 9.108b 的指数 n 与“三维热导方程”标题是否原书即不一致

**状态：开放。**

## 问题

9.2.3.3.1 小节标题为“**三维**热导方程”，行文亦称 Δ 是“由位置向量 r⃗ 确定的三个传播方向 x₁, x₂, x₃ 定义的三维拉普拉斯算子”；但式 9.108b、9.108c 的前因子指数为 **n**（一般维数），且积分写为三重积分。公式实为 n 维一般形式（三重积分应为 n 重积分）。标题、行文与公式口径不一致——这是原书即如此，还是转写/翻译折中？

## 证据

- 前因子 1/(2a√(πt))ⁿ = 1/(4πa²t)^{n/2} 是 n 维热核前因子（独立复算，见 [[式9-108a至9-108d热导方程柯西问题复算]]）。
- 源文对波方程同样使用一般 n（“x 表示 n 维问题的所有 n 个变量”，式 9.104a–b），而热导方程节改称“三维”——原书可能在热导方程节作了三维化处理但保留了 n 维公式，或译文混合了两版表述。
- 对照：波方程节标题无“三维”而公式分 n = 3/2/1 三种情形；热导方程节未分维数。

## 待办

对原书 9.2.3.3 处核对：标题是否为“三维”（或对应原文 three-dimensional），公式指数是否为 n。若原书即不一致，在此记录为原书内部口径差异。
