# 17.1.3 全节系统性转写讹误清单

本页汇总《数学手册(原书第10版)》17.1.3 节转写文本中的系统性 OCR 误植与脱文，作为该节的勘误工作清单。讹误密度与 16.3.x、16.4 各节同源相当（巾/千/厌/厂/共辄 等形近误植模式一致，参见 [[queries/16-4全节系统性转写讹误清单]]、[[queries/16-3-4全节系统性转写讹误清单]]）。

## 已识别讹误

### 形近字系统性误植（"于"→"千"、"由"→"巾"）

- "可巾变分方程" → "可由变分方程"
- "类似千微分方程情形" → "类似于微分方程情形"
- "小千 1" → "小于 1"
- "对千 α 极限集" → "对于 α 极限集"
- "对应千特征值" → "对应于特征值"
- "相切千系统" → "相切于系统"
- "千是" → "于是"
- "导出关千 β 展开系数的方程" → "关于"

### 关键术语误植

- "双曲 64" → 疑为"双曲周期轨"（专项辨析：[[queries/双曲64疑为双曲周期轨]]）
- "拓扑共扼"、"拓扑共辄" → "拓扑共轭"（两处）
- "幕级数" → "幂级数"
- "厌可微" → 疑为"$C^r$ 可微"
- "广义 $C^r$ 厂光滑曲面" → "厂"为衍字
- "在匣上" → 疑为"在 $\mathbb{R}$ 上"
- "邻域曲而" → 疑为"邻域。而且"或衍字
- "17.ll(a)" → "17.11(a)"（图号，ll 与 11 形近）

### 脱字与脱文

- "(m,k) 型……在复单位圆周内恰有 个特征值" → 脱 $m$ 字（专项辨析：[[queries/mk型定义脱m与k字之辨]]）
- "分别是 $m$ 维和 维" → 脱 $k$ 字（同上专项辨析）
- β 幂级数系数方程整体脱文，仅存结论 $k<0$（补算：[[queries/β幂级数系数方程脱文之补算]]）
- "若 是横截同宿点" → 脱主语 $y$
- 17.1.3.2 中阿达马—佩龙定理的小节编号"2."脱落
- "$, W^s(x_0)=\{y\in M:\dots\}$" 定义式前衍逗号
- "轨道 $\{\varphi_i(y)\}$ ｝" 衍全角花括号
- "(17.3) (17.24)" 两处并列疑脱"与"字
- "特征 值" 衍空格；"光滑基本曲面若当"句间标点脱落；括号全半角混用

### 记号问题

- 同段混用 $D(x_0)$、$Df(x_0)$、$D\varphi(x_0)$ 三种记号指同一对象（雅可比）
- $W^s$ 定义中"$|i|\to+\infty$"疑为"$i\to+\infty$"（专项辨析：[[queries/稳定流形定义i绝对值疑为i之辨]]）
- 横截同宿点段 $\varphi_i(y)$ 与 $\varphi^i(y)$ 上下标混用
