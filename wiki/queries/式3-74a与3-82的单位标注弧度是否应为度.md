# 式 3.74a 与式 3.82 的单位标注「弧度」是否应为「度」？

## 问题描述

[[sources/10-数学手册原书第10版--11-316-圆和有关的图形--yloqob]] 中，式 3.74a 括注「α以弧度度量」、式 3.82 括注「φ以弧度度量」，但两式的代数结构与近似系数均对应**度制**，标注与公式自相矛盾。

## 证据

1. 式 3.74a：$l = \frac{2\pi r \alpha}{360} \approx 0.01745\,r\alpha$。系数 0.01745 = π/180，仅当 α 以**度**代入成立；若 α 以弧度计，弧长应为 l = rα（无系数）。
2. 式 3.82：$S_\varphi = \frac{\varphi\pi}{360}(R^2 - r^2) = \cdots$ 的结构为「φ/360 × 全圆环面积」；若 φ 以弧度计，正确形式应为 $S_\varphi = \frac{\varphi}{2}(R^2 - r^2)$。
3. 同节印证：式 3.72 括注「α以度度量」；式 3.75 系数 0.00873 = π/360 与 3.74a 同构；式 3.76 精确式中的 πα/180 项同为度制结构。
4. 手册自身在 3.1.1.2（第 168 页，已入库 [[sources/10-数学手册原书第10版--8-311-基本概念--mrusl5]]）区分了 [[concepts/弧度]] 与 [[concepts/度分秒]] 两套角的度量。

## 待决问题

- 标注是否为翻译或转写讹误（「度」误作「弧度」）？
- 还是源书原文即如此（原作者笔误）？宜对照原书核实。
