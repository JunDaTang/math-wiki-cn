# 19.8.1 全节系统性转写讹误清单

《数学手册（原书第10版）》19.8.1「内符号表示」的转写文本存在系统性讹误，延续 19.3–19.7 各节同类问题（对照 [[queries/19-7全节系统性转写讹误清单]] 等）。清单如下，按出现顺序：

## 脱字与讹字

1. 「这是类似**千**十进制的多元数制」——「千」为「于」之讹，应为「类似于十进制」。
2. 「相应**千** 1985 年通过的 IEEE 标准」——同上，应为「相应于」。
3. 「内部数**宇**表示 INR」——「宇」为「字」之讹；「INR」疑为衍文（或原版页眉残留），节题应为「内部数字表示」。
4. 「一个**取的**存储单元（二进制数字）是最小的可代表信息的单元」——「一个取的」语义不通，疑脱字或衍字。

## 脱符号（数学符号整体丢失）

5. 「其中 为基数」——脱 $B$。
6. 「除以 ，则得到」——脱 $B$。
7. 「将其转换为以 为基数的数」「对基数为 的数制」——脱 $B$。
8. 「a) 整数部分 为十进制整数」——脱 $G$。
9. 「数 a 的指数 和尾数 的符号是分别存储的」「这里选取指数 使得尾数」——脱 $E$、$M$。
10. 「特征 来自指数 加上适当的常数 K」——脱 $C$、$E$。

## 数字与算式讹误

11. 「z₀ 的值可为 **O,l,···,B 1**」——应为「0,1,…,B−1」（字母 O 混入、减号脱失）。
12. (19.263) 脱等号：作「a \sum …」，应为「a = \sum …」。
13. 表 19.3 十进制行数码疑脱「7」：转写分析记载原始 HTML 作「0,1,2,3,4,5,6,8,9」；本次入库所见转录文本已含「7」。两处不一致，需核对原始文件定谳。

## 脱例号与标点

14. 「：将十进制数 139 转化为二进制数」「：将小数 0.8125 转化为二进制数」——两处例前脱例号。
15. 「参见第 1237 19.1.2.1)」——脱「页」；括号全半角不一致（「（」配「)」）。
16. 表题「19.3 数制」「19.4 基本形式的参数」——脱「表」字。
17. 句读脱失：「这样的指定称为代码有不同的代码」「定点数和浮点数第一种情况」等处疑脱句号；「故可确定 256符号」疑脱「个」。

## 重大疑点（另立专项）

18. (19.267) 后「因为保存 C = 0, C = 255 这里 C_min = 1, C_max = 256」——残句语义不完整，疑脱「（用于表示零与特殊值）」之类说明；且 C_max = 256 疑为 254 之讹，与 8 位上限、保留约定、表 19.4 三重不合，见 [[queries/式19-267后C-max为256疑为254之辨]]。

## 图形缺口（非讹误，影响完整性）

19. 图 19.15（定点）、图 19.16（半对数形式）、图 19.17（IEEE 格式）仅存图片引用，文字层未转录。

## 待决问题

- 各讹误宜在后续校勘版中统一订正；「INR」是否为原版页眉残留、表 19.3 是否确脱「7」，需核对原书（德文/英文版对应节）。
