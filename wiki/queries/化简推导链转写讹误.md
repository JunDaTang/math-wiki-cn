# 化简推导链的否定号与 B̄/B 是否为转写讹误？

原书对恒等式 A∨B̄ ⇒ AB∨C = B∨C 的验证链转写为：

```latex
A∨B̄∨AB∨C = ĀB̄∨AB∨C = ĀB∨AB∨C = (Ā∨A)B∨C = TB∨C = B∨C
```

**两处疑点**：

1. **首步漏否定号**：化简应自 ¬(A∨B̄)∨AB∨C 出发（经 5.17a 消去 ⇒），转写首项作「A∨B̄∨AB∨C」；
2. **B̄/B 前后不一**：第二项作 ĀB̄∨AB∨C、第三项作 ĀB∨AB∨C。由德摩根法则 ¬(A∨B̄) = ĀB（否定 B̄ 得 B），正确的一步应直接为 ĀB∨AB∨C；ĀB̄ 一步于数学上不通。

**本 wiki 复算**（[[findings/蕴涵公式化简例]]）支持复原版：

```latex
¬(A∨B̄)∨AB∨C = ĀB∨AB∨C = (Ā∨A)B∨C = TB∨C = B∨C
```

**待决**：核对原书该推导链的原始形态，判定是原书排印之误还是转写之误。
