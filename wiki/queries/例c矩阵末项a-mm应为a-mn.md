# 例 C 矩阵末项 a_{mm} 应为 a_{mn} 吗？

## 问题

5.3.8.3 例 C 声称 $\mathbb{R}^n\to\mathbb{R}^m$ 的线性算子由 (m,n) 型实矩阵 $A=(a_{ik})$ 刻画，但所附矩阵（对应线性方程组 4.174a）最后一行写作

```latex
a_{m1}  a_{m2}  …  a_{mm}
```

末项 $a_{mm}$ 与 (m,n) 型声明不符；当 $m\neq n$ 时该元素不应存在，应为 $a_{mn}$。

## 依据

- (m,n) 型矩阵第 m 行第 n 列元素为 $a_{mn}$；末行应为 $(a_{m1},\dots,a_{mn})$。
- 同段「关系式 $\nabla A\underline{x}=\underline{y}$」首符号亦疑为讹形，说明该段转写噪声集中。

## 解决所需

对照原书第 10 版核验例 C 矩阵末项；复原后更新 [[findings/线性算子定义和积与非交换性]] 的矩阵代码块与标注。
