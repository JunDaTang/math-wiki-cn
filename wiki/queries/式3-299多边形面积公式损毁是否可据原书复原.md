# 式 3.299 多边形面积公式损毁是否可据原书复原

## 问题

式 (3.299)（凸多边形面积，给定顶点 P₁(x₁,y₁), …, Pₙ(xₙ,yₙ)）在转写中完全损毁，仅余乱码片段（「S = 1-2 [(x1 一心）如＋如＋（四—邓）伽＋如＋···+（吓— m) 也＋如）］」），无法直接使用。

## 重构假说（推断，非原文）

由 (3.300) 三角形面积公式的**第二等式**（环形求和结构）推断，(3.299) 的原式应为鞋带（shoelace）形式：

```
S = ½[(x₁−x₂)(y₁+y₂) + (x₂−x₃)(y₂+y₃) + … + (xₙ−x₁)(yₙ+y₁)]
```

即对 n 边形把 (3.300) 的三顶点环形求和推广为 n 顶点闭包求和。原文还注明：按反时针顺序计数顶点时 (3.299)(3.300) 得出正的面积，否则为负。

## 待裁定事项

1. 原书确切的求和形式（闭包项、系数记法、下标循环方式）。
2. 该假说是否与原书排式完全一致，还是原书采用另一种等价写法（如 ½Σxᵢ(yᵢ₊₁ − yᵢ₋₁)）。
