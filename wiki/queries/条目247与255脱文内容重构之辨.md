# 条目 247 与 255 脱文内容重构之辨

## 问题

21.7.2.8（$X = ax^2+bx+c$，$\Delta = 4ac-b^2$，$k = \frac{4a}{\Delta}$）中，条目 247 在 246 与 248 之间**无任何残留**，条目 255 在 254 之后**仅存残句**「（参见246).」。二者的原文内容为何？重构式的排版形式是否与原书一致？

## 重构

**247**（由 248 取 $n=2$，结构必然）：

$$\int X^2\sqrt X\,\mathrm{d}x = \frac{(2ax+b)\sqrt{X^5}}{12a} + \frac{5}{6k}\int X\sqrt X\,\mathrm{d}x\quad(\text{参见 246}).$$

**255**（由 256 取 $n=1$，结构必然）：

$$\int x\sqrt{X^3}\,\mathrm{d}x = \frac{\sqrt{X^5}}{5a} - \frac{b}{2a}\int X\sqrt X\,\mathrm{d}x\quad(\text{参见 246}).$$

## 佐证

- 两式经 [[积分表求导还原复算法]] 直接验证闭合。
- 247 与负幂侧 242→243→244 的递推链严格对称（245→246→247 为正幂侧链条）；255 的残句「（参见246)」恰与重构式的回指一致。
- 编号连续性（246 与 248 之间、254 与 256 之间）锁定脱失位置。

## 待决

重构在数学上必然，但**原文的排版形式**（右端是否展开、常数是否显式写出、是否带 $+C$）须纸本确认。置信：重构内容高，排版形式中等。归入 [[21-7-2全节系统性转写讹误清单]]。
