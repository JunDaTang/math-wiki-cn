# 条目 208 与 236 乱码重构之辨

## 问题

21.7.2.6 条目 208 与 21.7.2.7 条目 236（均为 $\int\frac{x^2\,\mathrm{d}x}{\sqrt{X^3}}$）的转录被 HTML 标签与 CJK 噪声严重污染。原文为何？

## 原转录（逐字）

```
208. x2 dx x +<sub>Arsinh</sub> \~ <sub>+</sub> <sub>C=</sub> x (x ＋奴）＋ C1 √X3 √x `+ln
236. x2 dx x Arcosh \~ + x <sub>In</sub> (x ＋汉）＋ C1 √X3 √x a √x
```

## 重构（求导证实）

- **208**（$X = x^2+a^2$）：$\int\frac{x^2\,\mathrm{d}x}{\sqrt{X^3}} = -\frac{x}{\sqrt X} + \operatorname{Arsinh}\frac xa + C = -\frac{x}{\sqrt X} + \ln(x+\sqrt X) + C_1$。
- **236**（$X = x^2-a^2$）：$\int\frac{x^2\,\mathrm{d}x}{\sqrt{X^3}} = -\frac{x}{\sqrt X} + \operatorname{Arcosh}\frac xa + C = -\frac{x}{\sqrt X} + \ln(x+\sqrt X) + C_1$。

## 佐证

1. 两式分别求导均还原 $\frac{x^2}{X^{3/2}}$（直接证据）。
2. [[二次根式三族平行结构]]：同位条目 180（$X = a^2-x^2$，$\frac{x}{\sqrt X} - \arcsin\frac xa$，转录完好）给出符号翻转型，两重构式与之吻合。
3. 乱码中「In」可确认即「ln」；「＋」「）」等为全角噪声。

## 待决

「奴」「汉」二 CJK 噪声对应的原字符（疑为「a」或「$\sqrt X$」类符号的误识）无法从转录推断——仅影响溯源，不影响重构。归入 [[21-7-2全节系统性转写讹误清单]]。
