# 伯努利转移定义行 ρ 疑为 σ 并脱箭头之辨

## 疑点

原文：「映射 $\rho : s = s_0 s_1 s_2 \dots \sigma(s) = s' = s_1 s_2 s_3 \dots$ 称为伯努利转移」。两处讹误：

1. 映射名首字母作 ρ——ρ 已被用作距离函数，疑为 σ（移位映射的标准记号）；
2. $s = s_0 s_1 s_2 \dots$ 与 $\sigma(s) = \dots$ 之间脱映射箭头 $\mapsto$。

修读后应为：$\sigma : s = s_0 s_1 s_2 \dots \mapsto \sigma(s) = s' = s_1 s_2 s_3 \dots$（删去首符号）。

## 论证

- 与 17.2.2 已入库的 [[concepts/伯努利转移映射]] 中移位映射的标准记号 σ 一致（独立背景佐证）。
- 本段 ρ/σ/Σ 混写已有旁证（见 [[queries/完备度量空间σρ疑为Σρ之辨]]）。
