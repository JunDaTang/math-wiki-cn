# 例 C 结论 1−cos x = O(sin x) 是否应为 O(x²)？

## 问题描述

手册 2.1.4.9 (4) 例 C：设 $f(x)=1-\cos x$、$g(x)=x^2$，则当 $x\to0$ 时 $f(x)$ 是 $g(x)$ 的同阶无穷小。事实上 $\lim_{x\to0}\left\lvert\frac{1-\cos x}{x^2}\right\rvert=\frac12$，**即 $1-\cos x=O(\sin x)$**。

## 矛盾证据

1. 例 C 的 $g(x)$ 是 $x^2$，结论却写 $O(\sin x)$，论证与结论脱节。
2. 按手册自己的 $O$ 定义（式 2.27a：$\lim f/g=A\neq0$），$1-\cos x=O(\sin x)$ 为假——例 B 已证 $\lim_{x\to0}\frac{1-\cos x}{\sin x}=0$，属 $o$ 情形而非 $O$ 情形。
3. 与论证一致的正确结论应为 $1-\cos x=O(x^2)$（比值为 $\frac12$，非零常数）。

- 对照原版核实是否为转写或排版错误；若确认，勘误为 $O(x^2)$。
