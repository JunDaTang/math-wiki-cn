# 式 (16.91) 均方根密度疑脱因子 n

**开放问题**：(16.91) 的密度表达式是否脱落了两处因子 n？还是定义式 √((1/n)ΣXᵢ²) 有误？

## 源文逐字转录

```
X = √((1/n)·Σ_{i=1}^{n} Xᵢ²)   有密度函数   f(t) = (2t/σ²)·f_χ²(t²/σ²)        (16.91)
```

（诸 Xᵢ 为参数 (0, σ²) 的独立正态变量；原文「(0,CJ')」为「(0,σ²)」之转写讹误。）

## 复核推导

由 (16.89)，W = (1/σ²)·ΣXᵢ² ~ χ²_n。而 X = √((1/n)ΣXᵢ²) ⟹ W = (n/σ²)·X²，即 w = n·t²/σ²、dw/dt = 2nt/σ²，故

```
f_X(t) = f_χ²(n·t²/σ²)·(2nt/σ²)      (t > 0)
```

与逐字转录的 (2t/σ²)·f_χ²(t²/σ²) 相比两处均缺因子 n。反过来看，转录的密度恰对应 **X = √(ΣXᵢ²)**（定义中无 1/n）的情形（此时 (1/σ²)X² ~ χ²_n）——即定义与密度二者必有一误。

## 判断

疑转写脱落因子 n（或定义中脱落 1/n），无法排除原书错误。
