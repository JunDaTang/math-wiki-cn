# 377 与 379 归属之辨

问题：∫sin³ax dx/cosⁿax 与 ∫sinⁿax dx/cos ax 两式分别占用编号 377 与 379 中的哪一个（抑或编号结构另有安排）？

## 现状

转写文本在 376（∫sin³ax dx/cos ax，标「376I」）与 380（三支递推，显式标签）之间存三条公式：∫sin³/cos²（\tag{378.}）、∫sin³/cosⁿ、∫sinⁿ/cos。另有一组乱序悬挂标签（382、379、383、389、388）堆叠于 378 式之前，其中 379 的归属不足以裁定。

## 读法一：以 \tag{378.} 为锚

378=∫sin³/cos² 成立，则 ∫sin³/cosⁿ 与 ∫sinⁿ/cos 分居 377 与 379；因转写中 ∫sin³/cosⁿ 先于 ∫sinⁿ/cos 出现，暂记 377=∫sin³/cosⁿ、379=∫sinⁿ/cos，但这要求刊本中 377 位于 376 与 378 之间（与转写出现顺序不同）。

## 读法二：以 cos 侧镜像结构为锚

cos 侧 381–391 的排列为 cos/sin^{2,3,n} → cos²/sin^{1,3,n} → cos³/sin^{1,2,n} → cosⁿ/sin → cosⁿ/sinᵐ。镜像到 sin 侧即 sin³/cos^{1,2,n} → sinⁿ/cos → sinⁿ/cosᵐ，对应 376=∫sin³/cos、377=∫sin³/cos²、378=∫sin³/cosⁿ、379=∫sinⁿ/cos、380=递推——此时 \tag{378.} 本身漂移一位（应标于 ∫sin³/cosⁿ），且转写公式顺序与刊本一致。

## 裁定所需

刊本 376–380 段原文。两种读法对本区其余复原（381–391）无影响，仅涉此五条的编号指派与 \tag{378.} 的可信度。
