# 边界条件 y(α)=α 之 α 疑为 a 之辨

**现象**：(19.118)、(19.129)、(19.130)、(19.134) 四处边界条件均写作 y(α) = α、y(β) = β（同一希腊字母既作区间端点又作边值），而：

- 模型区间为 [a, b]，拉丁字母 a、b 才是端点；
- (19.134) 后文明确使用 y(a, s) = α、y(b, s) = β；
- (19.133) 的 g₀(x) = α + (β−α)(x−a)/(b−a) 以 a、b 作端点、α、β 作边值；
- (19.132) 的 g_i(a) = g_i(b) = 0 亦用 a、b。

**辨析**：端点记号在“α”与“a”之间系统性混用，倾向判断为转写时 "a" 误作 "α"（四处公式一致出错，或原书排印如此）。正确形式应为 y(a) = α、y(b) = β（打靶法 (19.134) 相应为 y(a) = α、y′(a) = s）。

**待证**：与原书核对，区分转写讹误与原书排印。见 [[concepts/常微分方程边值问题]]。
