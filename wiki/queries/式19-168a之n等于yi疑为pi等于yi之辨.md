# 式 (19.168a) 之 n=y_i 疑为 p_i=y_i 之辨

**问题**：两步算法初始化语句 (19.168a) 的乱码「$\dot{\mathbb{V}}\; n=y_i$」应如何复原？

**状态**：open（倾向 $p_i=y_i$，高置信）

## 原文（乱码）

```
(1) i = 0, 1, …, n,  Ẇ n = y_i        (19.168a)
```

## 辨析

复原为 $p_i = y_i$ 的依据：

1. **表格对应**：(19.166) 首列即 $y_i = p_i$（n=4 表格推广至一般 n），初始化应把向量 p 的各分量置为 $y_i$。
2. **算法后续引用**：(19.168b) 的更新式直接使用 $p_i$、$p_{i-1}$，且源文紧接着称结束后「元素 $p_n$」为所求函数值——分量记号 p 与初始化对象一致。
3. **上下文**：源文明确「只需引进有 n+1 个分量的向量（见 [19.7]）」，第 (1) 步正是对该向量的赋值。

「$\dot{\mathbb{V}}\;n$」疑为「p_i」的 OCR 变形（下标 i 误作 n，p 误作带装饰的向量记号），与 19.1–19.4 已建档的乱码型讹误同类。

## 判定倾向

复原为 $p_i=y_i$（$i=0,1,\cdots,n$）。置信度高，待原书影印最终确认；复原后的完整算法见 [[艾特肯－内维尔两步就地算法流程]]。
