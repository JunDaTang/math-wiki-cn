# 式 9.147d 前概率密度是否漏乘因子 λx²？λ 的含义是否与 9.143c 冲突？

## 问题

9.147d 前文转录的概率密度为 dw_qu = 2√(λ/π)·e^{−λx²}dx；疑漏乘因子 **λx²**，应为 2√(λ/π)·λx²·e^{−λx²}dx。同时 9.147d 中的 λ 与 9.143c 的 λ = 2E/ℏω 含义冲突。

## 内部依据

- 若密度为 2√(λ/π)e^{−λx²}，其极大在 x = 0，与紧随其后的 x_max,qu = ±1/√λ 矛盾。
- 按 n=1 波函数独立复算：Ψ₁ = N₁e^{−y²/2}·2y（y = √α x，α = mω/ℏ），|Ψ₁|² = 2√(α/π)·αx²·e^{−αx²}——极大在 x = ±1/√α。故公式应为 2√(λ/π)·λx²·e^{−λx²}，且此处 **λ 实为 α = mω/ℏ**，并非 9.143c 的 λ = 2E/ℏω（后者在 n=1 时等于 3）。

## 待核对

对照纸质原书确认；建议按 n=1 波函数完整复算后定稿（复算已见于 [[findings/式9-142至9-147线性谐振子转录复算]]，判其为漏因子 + 记号复用，高置信）。
