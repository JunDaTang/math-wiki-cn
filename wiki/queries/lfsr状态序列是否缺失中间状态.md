# LFSR 状态序列是否缺失 4 个中间状态？

## 源文

5.3.7.4.2：以本原多项式 $f(x) = 1 + x + x^3 \in \mathbb{Z}_2[x]$ 为反馈多项式、长度为 3 的移位寄存器，从初始状态 $100 \widehat{=} 1 \pmod{f(x)}$ 出发，正文只列出（带分隔横线，暗示省略）：

```
111 ≡ x⁵ ≡ 1+x+x²   (mod f(x))
101 ≡ x⁶ ≡ 1+x²     (mod f(x))
100 ≡ x⁷ ≡ 1        (mod f(x))
```

## 问题

完整周期为 7 的状态序列应含 7 个状态；正文缺失 010、001、110、011 四个中间状态（对应 $x, x^2, x^3, x^4$）。是正文转写截断（丢行），还是原书即只列末三行、完整序列存于图 5.18？

## 处理

已按状态转移公式复算补全全序列（见 [[findings/lfsr状态转移与极大周期判据]]），与 GF(2³) 对数表一致；无论原书如何排版，数学内容已闭环。状态：**内容已复算，排版问题待原书核对**。
