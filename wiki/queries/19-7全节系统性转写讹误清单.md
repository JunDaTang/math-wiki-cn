# 19.7 全节系统性转写讹误清单

**状态**：开放（待人工对照原书核验）。延续 19.2–19.6 各节同类清单（[[queries/19-6-1全节系统性转写讹误清单]]、[[queries/19-5全节系统性转写讹误清单]]、[[queries/19-4全节系统性转写讹误清单]]、[[queries/19-3全节系统性转写讹误清单]]）的模式。

## 一、「千」讹「于」（系统性）

由千（由于）、不高千（不高于）、适用千、相应千、千是（于是）、关千（关于）、恒等千、由千在许多实际应用中。

## 二、「入」讹「λ」

「当入很大时」「可适当选取入」（两处）。

## 三、脱字符/脱变量

| 原文 | 应为 |
|---|---|
| 「设给定 个插值点」 | 脱 N |
| 「次数不高千 的多项式」 | 脱 3 |
| 「对大的 ，该方法」 | 脱 N |
| 「这里 为曲线的参数」 | 脱 t |
| 「其中 为曲面参数」 | 脱 u、v |
| 「所谓 阶正规化 样条」 | 脱「4」「B」 |
| 「正则化的 样条／称为 样条曲线／改为 样条／双三次 样条／三次 样条」 | 脱「B」（多处） |
| 「关千第 个节点」 | 脱 i |
| 「 表示关千 的节点个数，表示关千 y 的节点个数」 | 脱 r、p |
| 「要求 上可能简单的光滑曲面」 | 脱 R 与「尽」 |
| 「设给定位置向量 P_ij 凡的点」 | 衍字「凡」 |

## 四、字符与编号讹误

- 「l6mn」应为「16mn」（(19.247) 后）；
- (19.249) 三处 (x_i, y_i) 应为 (x_i, y_j)；
- 例 B 中 B_{2,3} 与 B_{3,3} 两式间脱分隔符；
- 三处「见文献」缺失引文编号 [19.x]（双三次样条系数计算、插值问题求解、逼近问题最优条件各一处）。
