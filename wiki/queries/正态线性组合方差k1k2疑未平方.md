# 正态线性组合方差 k₁、k₂ 疑未平方

**开放问题**：(16.71b) 后未编号公式中 σ 的表达式是否脱落了 k₁、k₂ 的平方上标？

## 源文逐字转录

```
若 X₁、X₂ 互独立，分别服从参数为 μ₁, σ₁² 和 μ₂, σ₂² 的正态分布，则
X = k₁X₁ + k₂X₂（k₁、k₂ 为实常数）也服从正态分布，其参数为
    μ = k₁μ₁ + k₂μ₂ ,   σ = √(k₁σ₁² + k₂σ₂²)
```

## 复核推导

由独立性：

```
Var(k₁X₁ + k₂X₂) = k₁²·Var(X₁) + k₂²·Var(X₂) = k₁²σ₁² + k₂²σ₂²
```

故 σ 应为 √(k₁²σ₁² + k₂²σ₂²)。逐字转录的 √(k₁σ₁² + k₂σ₂²) 仅在 k₁ = k₂ = 1 等特殊值时成立，与「k₁、k₂ 为实常数」的一般陈述矛盾。

## 判断

疑 k₁、k₂ 的平方上标在转写中脱落，与全节上标系统性丢失现象一致（亦与 15.x 各节观察相符）；但不排除原书排印错误。
