# 式 (15.152) 常数 c 双重出现一致性之辨

**问题**：(15.152a) 与 (15.152b) 中出现**同一个**常数 c（「依赖于特殊小波 ψ 的常数」）。若正变换带 c、逆变换又带 c，代入后重建要求 $c^2\iint\cdots = f$，即 $c^2$ 须与容许常数的倒数匹配。标准文献的约定通常是：正变换不带因子，逆变换带 $1/C_\psi$（或把 $1/\sqrt{C_\psi}$ 对称分配到正逆两式）。

**候选解释**：

1. c 对称地取 $1/\sqrt{C_\psi}$（则 $c^2 = 1/C_\psi$，重建自洽）——手册可能采用对称约定。
2. (15.152b) 的 c 实为不同常数（如 $1/C_\psi$），转写时被混同。
3. 与 (15.147) 的幂次疑点联动：容许积分取平方版时，$C_\psi$ 的定义才与 $1/c^2$ 对得上（见 [[queries/式15-147容许条件Ψ模一次幂疑为平方]]）。

**核对方向**：查原书 (15.152) 附近对 c 的定义句；或对哈尔小波显式代入验证哪一约定给出精确重建。此问题直接影响 (15.152b) 作为 [[concepts/逆变换]] 新实例的可用性。
