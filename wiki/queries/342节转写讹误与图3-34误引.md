# 3.4.2 节的成片转写讹误与「图 3.34」误引

## 问题

本节（3.4.2）存在成片系统性转写讹误，与既往章节的转写问题模式一致。原书文本究竟如何？

## 讹误清单

| 类型 | 例子 |
|---|---|
| 「千」代「于」 | 介千、大千、小千、对千、用千、类似千、对应千、鉴千（遍布全节） |
| 形近字误 | 「球面儿何」（几何） |
| 希腊字母误作汉字 | 吕利耶段「已知角 α, β, **社**」（γ 误作「社」） |
| 衍字 | 「球面角盈**丿**」、「它们之间的夹角**？**γ」 |
| 残损 | 「可以借助吕利耶公式 (3.201)**算€**」 |
| 符号脱落 | 「和球半径 [R] 表示」（括号残留、符号丢失） |

另有一处疑似**误引**：正弦—余弦定律与对偶形式两处写「通过量的轮换（**图 3.34**）」，而本节开头声明「本段中所涉及的量的记号与**图 3.89** 中的那些记号一致」，且图 3.89 属 3.4.1（尚未入库）。「图 3.34」或为「图 3.89」之误，或原书另有此图号，待核。

## 待办

- 与原书核对上述各处，确定哪些属转写损坏、哪些原书即如此；
- 「图 3.34」两处需查原书图号。
