# 式 (16.94b) 被积函数疑衍文「− 1」

**开放问题**：(16.94b) 被积函数中的「− 1」是衍文还是原书本有？

## 源文逐字转录

```
F_F(x) = (m₁/2)^{m₁/2}·(m₂/2)^{m₂/2}·Γ((m₁+m₂)/2)/[Γ(m₁/2)·Γ(m₂/2)]
       · ∫_{0}^{x} (t^{m₁/2−1} − 1)·dt / ((m₁/2)·t + (m₂/2))^{(m₁+m₂)/2}   (x > 0)        (16.94b)
```

## 矛盾所在

(16.94b) 是密度 (16.94a) 的积分，被积函数应与 (16.94a) 完全一致，即 t^{m₁/2−1}/((m₁/2)t+(m₂/2))^{(m₁+m₂)/2}；多出的「− 1」使 F_F(x) ≠ ∫f_F，且当 x → ∞ 时分布函数不归一（密度 (16.94a) 已归一）。故「− 1」疑为衍文。

另一处相关疑点（同小节）：(16.95a,b) 的期望与方差未给适用条件，复核表明须分别满足 m₂ > 2 与 m₂ > 4，与 t 分布 (16.98a,b) 显式给出条件的体例不一，疑同为转写脱漏。
