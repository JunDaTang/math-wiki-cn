# 平方取中法算例 z₀² 疑为 z₁²

**疑点**：平方取中法算例（2n=4）第二行写作

```
z = z₁ = 0.5227,   z₀² = 0.27[3215]29
```

左端已是 z₁，平方仍标 z₀²。

**分析**：该行应是对 z₁ = 0.5227 平方（z₁² = 0.27321529，中段四位 3215，复算吻合），故平方记号应为 **z₁²**。数值本身正确，仅标号之误，见 [[findings/平方取中法算例复算]]。

**核对方**：原书 16.3.5.2(1) 算例第二行。
