# 双曲线小节疑似讹误清单

本页汇总 3.5.2 节中以双曲线小节为主（兼及个别相邻公式）的局部转写讹误，供据原书逐条核定。这些讹误不影响数学内容的主体正确性，但涉及公式细节与**实体归属**（如「椭圆」/「双曲线」之混），转述时须谨慎。

## 清单

1. **双曲线准线距离「d = a/c」**（3.332 前文）：与椭圆小节 d = a/e 的体例及标准结果 x = ±a/e 不符，疑为 **a/e** 之讹。
2. **(3.333) 切线方程分母 a₂、b₂**：应为 **a²、b²**（上下标成片脱落）。
3. **(3.340a)「r₁r₂^{3/2}」**：应为 **(r₁r₂)^{3/2}**（括号脱落）。
4. **(3.334) 后文「是该椭圆的切线」**：应为「该**双曲线**」——复制残留，涉及实体归属，**不可跨实体转述**。
5. **圆小节编号 (3.135b)**：应为 **(3.315b)**（编号错排）。
6. **(3.296) 中间式分母「xᵢ − b」**（调和分割，式 3.295–3.297 一带）：由 xᵢxₐ = b² 反推应为 **xₐ − b**。
7. **表 3.19 内「tan2α = 2b/a−c」**：分数线脱落，应为 **tan 2α = 2b/(a−c)**；表注「凶，S」应为「**δ, Δ, S**（(3.353b) 中给出的数）」。
8. **表 3.20 脚注「0=0」**：应为「**δ=0**」（「在 δ=0 的情形，假设系数 a, b, c 都不等于 0」）。
