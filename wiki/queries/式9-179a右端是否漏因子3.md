# 式 (9.179a) 右端是否漏因子 3

## 问题

KP 方程 (9.179a) 按转写为 (u_t + 6uu_x + u_{xxx})_x = u_{yy}；右端是否应为 3u_{yy}？

## 证据（双线性复算，high）

- (9.179b) 的对数宗量 F = 1/k² + (x − 3k²t)² + k²y² 恰好满足双线性方程 (D_xD_t + D_x⁴ − 3D_y²)F·F = 0（D 为广田双线性算子），即 (9.179b) 是 **(u_t + 6uu_x + u_{xxx})_x = 3u_{yy}**（KPI 型）的精确 lump 解；
- 对转写式（右端 u_{yy}）代入，残差 8k²[s² − 2a − k²y² + 3/k²]（复算记号）不恒为零；
- lump 的传播速度 3k²（出现在 |x + iky − 3k²t|² 中）与常数项 1/k² 均只在含因子 3 的版本中自洽。

## 待裁定

- 是否核对德文原书终裁？
- 终裁前，引用 KP-lump 对应关系时应采用 (u_t + 6uu_x + u_{xxx})_x = 3u_{yy}，见 [[findings/式9-172至9-179附加七方程复算]] 与 [[methodology/广田双线性方法]]。
