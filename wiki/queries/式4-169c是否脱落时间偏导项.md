# 式 (4.169c) 是否脱落 ∂w̲/∂t 项？

**待解问题**：《数学手册（原书第10版）》4.4.3.5 的式 (4.169c) 转写为

```latex
D w = ∂w₀/∂t − div w̲ + rot w̲ + grad w₀
```

但由 (4.169a) D = ∂/∂t + ∇_Q 与 (4.169b) w = w₀ + w̲ 直接展开，四元数乘法应给出**五项**：

```latex
D w = ∂w₀/∂t − div w̲ + ∂w̲/∂t + rot w̲ + grad w₀
```

（∂/∂t 作用于向量部分 w̲ 应产生 ∂w̲/∂t；对照已验证成立的 (4.168)：∇_Q v̲ = −div v⃗ + rot v⃗。）

## 证据与推理

- (4.168) 经独立验证成立，其「标量部分 + 向量部分」结构与上式一致。
- (4.170a–c) 均验证成立，不涉及此缺项。
- 缺项为分析者据定义直接展开所得的高置信推断；但**是否原书亦漏、抑或转写脱落**需回查。

## 处置建议

回查原书式 (4.169c)；若原书含 ∂w̲/∂t，更正 [[concepts/四元数微分算子]] 与 [[findings/四元数算子与拉普拉斯分解]] 的记录；若原书确无，则记录为原书的疏漏并保留警示。
