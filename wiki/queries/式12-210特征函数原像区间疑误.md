# 式 (12.210) 特征函数原像区间疑误

## 疑点

原文 (12.210)：

χ_A⁻¹((α, +∞]) = A（α ∈ (−∞, 1)），∅（α ⩾ 1）

## 复算

按定义 χ_A⁻¹((α, +∞]) = {x ∈ X : χ_A(x) > α}，χ_A 取值仅有 0 与 1：

- α < 0：0 > α 与 1 > α 均成立 ⟹ 原像 = X
- 0 ⩽ α < 1：仅 1 > α 成立 ⟹ 原像 = A
- α ⩾ 1：均不成立 ⟹ 原像 = ∅

故原文第一段应为「X，α ∈ (−∞, 0)」与「A，α ∈ [0, 1)」两段，而非「A，α ∈ (−∞, 1)」一段。

## 影响评估

结论「每个 A ∈ 𝒜 的特征函数 χ_A 可测」不受影响：X、A、∅ 均属 σ-代数 𝒜。疑误仅影响公式自身的分段自洽性，但它是 12.9.2.2「基本函数可测」论证与 L^p 构造（|f|ᵖ 可测性回指链）的第一环，值得定谳。

## 可能成因

- 转写漏排 α ∈ (−∞, 0) 一行；
- 或原书即以 (−∞, 1) 为一段并误写值 A。

## 待办

对照德文原书定谳；定谳后在 [[concepts/可测函数]] 与 [[concepts/特征函数与基本函数]] 中标注正误。
