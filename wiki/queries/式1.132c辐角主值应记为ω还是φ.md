# 式 1.132c 辐角主值应记为 ω 还是 φ？

## 问题

手册 1.5.2.3 的式 (1.132c) 定义：

ρ = |z|，φ = arg z = ω + 2kπ，其中 0 ⩽ ρ < ∞，−π < ω ⩽ +π，k = 0, ±1, ±2, …

紧接着正文却写"**φ 称为复数的辐角主值**"。按定义式，随 k 取遍整数而变化的 φ 是（多值的）辐角全体；限制在 (−π, +π] 内的唯一代表是 ω。因此主值应记为 ω 而非 φ，两处表述相互矛盾。

## 可能的解释

1. 原书排印错误：该句应为"ω 称为复数的辐角主值"；
2. 中文版转写时将 ω 误作 φ；
3. 原书另有记号约定（与定义式直接冲突，可能性低）。

## 影响

主值记号影响 [[concepts/复数的模与辐角]] 页的表述；本 wiki 暂按"主值为 ω ∈ (−π, +π]"记录，并在该页标注此疑点。
