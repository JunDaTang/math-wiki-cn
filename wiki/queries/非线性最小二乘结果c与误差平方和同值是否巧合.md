# 非线性最小二乘结果 c = -8.0000916 与误差平方和 0.0000916 同值是否巧合？

手册 2.16.2.12 末段：非线性最小二乘迭代解给出 $c=-8.0000916$，误差平方和为 0.0000916——两者小数部分数值完全相同。

## 两种可能

1. **巧合**：迭代收敛值与残差平方和恰好同数值。
2. **转写讹误**：其一由另一值串抄而来（如误差平方和误抄了 c 的小数部分），或排版时数字重复。

## 待办

- 用表 2.9 数据独立复算非线性最小二乘（初值 a = 364, b = 1.966, c = -7.932），同时核对收敛参数与误差平方和。
- 复算亦可顺带检验“数据由 $y=400x^2\mathrm{e}^{-8x}$ 舍入生成”的推断（见 [[findings/经验拟合数值算例]]）。
