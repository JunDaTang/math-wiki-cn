# 式 (19.18c) 之 r₁x 疑为 r₁x₀ 之辨

**存疑**：(19.18c) 中 "$r_1 x$" 是否脱下标 0？

## 证据链

- (19.18c) 源文：$p_n(x_0) = r_1 x + r_0 = (r_1 u_0 + r_0) + \mathrm{i} r_1 v_0$——左端在 $x_0$ 处取值，中间项 "$r_1 x$" 的 $x$ 无处安放；
- (19.18a) 的余项本是 $r_1 x + r_0$（一般 $x$），代入 $x = x_0$ 应得 $r_1 x_0 + r_0$；
- 随后的实虚部分解 $(r_1 u_0 + r_0) + \mathrm{i} r_1 v_0$ 恰为 $r_1(u_0 + \mathrm{i} v_0) + r_0 = r_1 x_0 + r_0$，可反推中间项应为 $r_1 x_0$；
- 算例 G 的结果式写作 $p_4(x_0) = 34 x_0 - 87$，用的是 $x_0$ 而非 $x$——直接佐证。

## 倾向判断

应为 $r_1 x_0$（本 wiki 分析判断，置信很高：源文内部三处证据一致）。

查原书对应分节；本项可与 [[queries/19-1全节系统性转写讹误清单]] 的“下标脱落”类合并处理。
