# 列梅兹步骤下标 ν 与括注 i 不一致之辨

## 疑点

19.6.3.3 步骤 (1)：「确定交替点 x_ν^{(0)}(i = 1, 2, …, n+2) 的近似值」；步骤 (3)：「确定交替点新的近似值 x_ν^{(1)}(i = 1, 2, …, n+2)」。公式下标用希腊字母 ν，括注却用拉丁字母 i。

## 分析

- 步骤 (2) 的方程组与 (19.202) 均以 **ν = 1, 2, …, n+2** 为交替点编号、**i = 0, 1, …, n** 为系数编号。
- 故括注「(i = 1, 2, …, n+2)」应为「**(ν = 1, 2, …, n+2)**」之讹——OCR 将 ν 误作 i 的可能性大（希腊 ν 与拉丁 i 形近）。
- 该讹不影响数学内容，但转录与引用时应统一为 ν。

## 待办

对照原书确认括注字母；确认后回改 [[列梅兹算法]] 与 [[列梅兹算法迭代流程]] 的「转写注意」段。
