# 式 (3.202i)(3.202j) 本体脱落是否可复原为 cos α = cos a sin β / cos β = cos b sin α？

## 现象

源文 3.4.3.2「专门公式」处，(3.202a)–(3.202h) 完整，随后仅有两个孤立的编号「(3.202i)」「(3.202j)」，公式本体在转写中完全缺失。但表 3.8 的基本问题 (4)(5)(6) 均引用这两式：

- (4) 一直角边和其上的角 a, β：c (3.202e), b (3.202j), α (3.202i)
- (5) 一直角边和其所对的角 a, α：b (3.202h), c (3.202a), β (3.202i)
- (6) 两个角 α, β：a (3.202i), b (3.202j), c (3.202d)

## 复原（推断）

```
cos α = cos a·sin β   (3.202i)
cos β = cos b·sin α   (3.202j)
```

## 一致性证据

1. 与 (3.202f)/(3.202e) 代数一致：如 cos a·sin β = cos a·(sin b/sin c)（由 3.202b）= (cos a cos b)·tan b/(sin c cos b)… 与 tan b/tan c 逐项吻合。
2. 表 3.8 的指派在 (a,b,c,α,β) 互换下完全对称自洽（问题 (6) 与问题 (2)、(5) 与 (1) 的结构对偶成立）。
3. 形式恰为 [[concepts/纳皮尔法则]]「余弦 = 不相邻量正弦积」的另一实例。
