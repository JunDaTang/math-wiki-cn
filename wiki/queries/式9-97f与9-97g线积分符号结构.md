# 式 9.97f 与 9.97g 的线积分符号结构

## 问题

转写的黎曼公式 (9.97f) 两个线积分项**同取负号**并列：

```
− ∫_{P̂Q}[buv + ½(v u_x − u v_x)]dx − [auv + ½(v u_y − u v_y)]dy + ∬_{PMQ}Fv dxdy
```

而独立推导（Lagrange 恒等式 vLu − uL*v = ∂ₓA + ∂_yB，A = auv + ½(vu_y − uv_y)、B = buv + ½(vu_x − uv_x)，逐项展开验证；Green 公式；特征线条件 9.97c 使特征线段上的积分化为全微分）给出：

```
u(ξ,η) = ½(uv)_P + ½(uv)_Q
  + ∫_{P̂Q}{[buv + ½(vu_x − uv_x)]dx − [auv + ½(vu_y − uv_y)]dy}
  + ∬_{PMQ}Fv dxdy
```

即 **dx 项与 dy 项必须反号**。两组数值算例（a, b ≠ 0、c = ab、指数组合精确解、黎曼函数 e^{b(x−ξ)+a(y−η)}）支持推导式；按转写式计算不吻合。

## 候选解释

1. 原书以单一大括号分组 −∫{[…]dx − […]dy}，转写丢失分组致第二项变号；
2. 原书/译本排印误；
3. 端点项 ½(uv)_P + ½(uv)_Q 的归属或 P、Q 的标定方式与推导设定不同（9.97g 的单端点项 (uv)_P 即有此依赖，其两线积分项亦同取负号，存在同类问题）。

## 待办
