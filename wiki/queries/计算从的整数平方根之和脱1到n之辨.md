# 「计算从 的整数平方根之和」脱「1 到 n」之辨

**问题**：例 A 题面作「定义一个程序用来计算从 的整数平方根之和」，「从」与「的」之间脱字。

**拟断**：脱「1 到 n」，即「计算从 1 到 n 的整数平方根之和」。证据：式 20.27 之代码以 `sum = 1.`（√1 项）为初值并配合 `Do[..., {i, 2, n}]`，以及例 B `Table[Sqrt[i], {i, 1, n}]` 的迭代范围，共同确证求和范围为 i = 1, …, n。

**佐证**：`sumq[30]` 之两个结果（112.083、112.0828452）均与 Σ_{i=1}^{30} √i 的独立复算一致（[[findings/式20-27-sumq过程式算例复算]]、[[findings/例B-函数式sumq与Total复算]]）。
