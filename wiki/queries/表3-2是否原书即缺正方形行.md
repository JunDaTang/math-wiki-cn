# 表 3.2 是否原书即缺正方形（n = 4）行？

表 3.2 收录三、五、六、八、十边形（n = 3, 5, 6, 8, 10），唯独缺正方形（n = 4）行。七、九边形无简单根式表达（涉及不可尺规简化的角），缺位属正常；但正方形性质极简（a₄ = R√2、r = R/√2、S₄ = 2R²），缺位反常。

待核：是原书编排即如此（也许正方形性质在别处给出），还是转写丢行？
