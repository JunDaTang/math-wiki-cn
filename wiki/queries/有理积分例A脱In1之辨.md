# 有理积分例 A 脱 In[1] 之辨

## 疑点

20.3.4.2 有理函数积分例 A（也见手册第 648 页 8.1.3.3）仅有输出行，输入行整体脱失：

```
Out[1] = 5/3 Log[-1+x] - 3Log[x]/2 - 1/6 Log[2+x]
```

## 重构假设

对输出求导：

d/dx[5/3·ln(x−1) − 3/2·ln x − 1/6·ln(x+2)] = 5/(3(x−1)) − 3/(2x) − 1/(6(x+2)) = (2x+3)/(x(x−1)(x+2))，

其中通分验证：分子 10x(x+2) − 9(x−1)(x+2) − x(x−1) = 12x+18 = 6(2x+3)。数值点核验吻合，故被积函数重构为 **(2x+3)/(x(x−1)(x+2))**，In[1] 疑为 `Integrate[(2x+3)/(x(x−1)(x+2)), x]`。

- 待 8.1.3.3 入库后核对原题（见 [[queries/20-3未入库回指缺口]]）；或对原书影印件补齐输入行。
