# 公式 498 乱码复原之辨

[[sources/10-数学手册原书第10版--13-2174-其他超越函数积分--17odu4w|数学手册 21.7.4.4]] 公式 498（$\int\arctan\frac{x}{a}dx$ 的基本式）在转写中严重乱码，OCR 层 HTML 标签与汉字「沪」混入。复原假说是否与刊本一致？

## 原文逐字

```
498. arctan <sup>x</sup>— <sub>-</sub>dx = xarctan<sub>-- - ---</sub> <sup>x</sup>  <sub>a</sub> — <sup>a</sup> —-ln(a2 <sub>2</sub> +沪）． a
```

## 复原假说

$$\int\arctan\frac{x}{a}dx = x\arctan\frac{x}{a} - \frac{a}{2}\ln(a^2+x^2)$$

## 支持证据

- **镜像式旁证**：505（$\int\arccot\frac{x}{a}dx = x\arccot\frac{x}{a} + \frac{a}{2}\ln(a^2+x^2)$）经微分复算通过；由 $\arctan + \arccot = \frac{\pi}{2}$，498 复原式与 505 之和恰为 $\frac{\pi x}{2}$，结构自洽。
- **同族系列对齐**：499/500（$\int x\arctan$、$\int x^2\arctan$）均以 $x\cdot(\text{arctan 项}) \mp (\text{初等项})$ 收尾，复原式符合该骨架。
- **双曲平行**：514（$\int\operatorname{Artanh}\frac{x}{a}dx = x\operatorname{Artanh}\frac{x}{a} + \frac{a}{2}\ln(a^2-x^2)$）呈 $\pm\frac{a}{2}\ln$ 的对数型平行（见 [[comparisons/反三角与反双曲函数积分对应比较]]）。
- **微分复算**：复原式微分后还原 $\arctan\frac{x}{a}$（含于 [[findings/21-7-4超越函数积分全表微分复算]] 的反函数积分覆盖中）。

## 开放问题

复原式的逻辑必然性强，但原行的乱码无法自证；需刊本（或其他版本手册）核对 498 原行，特别是系数 $\frac{a}{2}$ 与真数 $a^2+x^2$ 的写法（乱码中「a2 … +沪）」的「沪」疑为「x²」或「)」的误识）。
