# 「1−p 很小」与「p ≤ 0.08」表述之辨

## 现象

同一节内两处关于泊松逼近的适用条件方向相反：

- 16.2.3.1 正态逼近段末尾：「当 **1−p** 很小时二项分布可由泊松分布逼近（参见第 1068 [页] 16.2.3.3(16.68)）」；
- 16.2.3.3 第 4 条：「当 **p ≤ 0.08** 和 n ≥ 1500p 时，即用此公式」。

## 分析

- 对成功次数 X 本身作泊松逼近，要求成功是稀有事件，即 **p 小**——这正是 n→∞、p→0、np=λ 的极限方向；
- 若 1−p 很小（失败稀有），则可用泊松逼近的是**失败次数 n−X**（参数 n(1−p)），而非 X 本身；
- 故 16.2.3.1 处「1−p」疑为「p」之讹；亦不排除原文有意补一句关于 n−X 的说明而在转写中受损。

## 关联疑点

同一段落前文「如果 n 很大，且 1−p 不是太小」也疑脱「p 和」二字（应为「p 和 1−p 都不是太小」），见[[queries/16-2-3全节系统性转写讹误清单]]：该段对 p 与 1−p 的单侧表述系统性可疑；np>4 与 n(1−p)>4 的判据本身亦待核。
