# 表 3.2 八边形面积条目「2a2/8(√2+1)」是否应为 2a₈²(√2+1)？

表 3.2 八边形行的 S₈ 列，以 a₈ 为基准的形式转写作「=2a2/8(√2+1)」。

- 按式 3.56，S₈ = (1/4)·8·a₈²·cot(22.5°) = 2a₈²(√2+1) ≈ 4.828·a₈²。
- 若按字面读作「2a²/8·(√2+1)」≈ 0.6035·a₈²，与 R、r 基准的另两种表达（2R²√2、8r²(√2−1)）换算后完全不符。
- 推测「2a2/8」是「2a₈²」的下标/上标转写讹误（₈ 与 ² 错位，「/」或为 OCR 伪迹）。

待核：原书此格究竟作何式？这是表 3.2 唯一与公式体系数值不符的条目。
