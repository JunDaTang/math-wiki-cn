# 式 (5.154) X₁ 首行是否应为「0 0 0」？

## 疑点
so(3) 基的第一个矩阵按所印为：

$$
X_1=\begin{pmatrix}0&0&1\\0&0&-1\\0&1&0\end{pmatrix}
$$

它**不是反对称矩阵**：(1,3) 位为 1，而 (3,1) 位为 0，不满足 X₁=−X₁ᵀ。

## 证据
1. 同节 (5.171c) 论断：正交旋转矩阵的导数（在 θ=0 处）满足 Ω+Ωᵀ=0，即 so(3) 的元素必须反对称。
2. se(3) 生成元 E₄（式 5.156）的左上 3×3 块为 [[0,0,0],[0,0,−1],[0,1,0]]，与「X₁ 首行应为 0 0 0」的复原完全一致。
3. 同组的 X₂、X₃（及 E₅、E₆ 的相应块）均为标准反对称基，无此问题；E₄–E₆ 与 M₄–M₆（式 5.145b）单位元处导数的交叉印证已复算通过。

## 待决
是否按「首行 0 0 1 → 0 0 0」复原入库？复原后 X₁ 即绕 x 轴旋转的无穷小生成元，与 E₄ 的块一致。
