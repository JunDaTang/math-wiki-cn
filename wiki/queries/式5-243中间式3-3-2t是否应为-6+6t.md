# 式 5.243 中间式 3-3(2t) 是否应为 -6+6t？

**问题**：手册 5.4.2 第 5 小节例题（2x+4y+3z=3）中，转写正文先写「求出可解丢番图方程 2x+4y = 3−3(2t) 或 x+2y = −3+3t（式 5.243c）的解」。中间式「3−3(2t)」与其后的 x+2y = −3+3t 不相容，是否应为 −6+6t（即 3−3(3−2t)）？

## 论证（已确认中间式有误）

- 由条件二元方程 2z′+3z=3 的解集得 z = 3−2t。
- 代回式 (5.243b)：2x+4y = 3−3z = 3−3(3−2t) = 3−9+6t = **−6+6t**。
- 除以 2：x+2y = −3+3t，与式 (5.243c) 一致 ✓。
- 若按转写字面「3−3(2t)」= 3−6t，则除以 2 得 x+2y = 3/2−3t，一般非整值，与 (5.243c) 矛盾。故「3−3(2t)」必为脱字（脱落了「3−」或等价内容），正确应为 3−3(3−2t) 或 −6+6t。

## 影响与状态

- 后续推导（特解 (3−3t, −3+3t)、通解、最终解集）均以 −3+3t 为基点，全部正确且已复算（见 [[findings/三元线性丢番图方程归约算例2x4y3z3]]），故此讹误仅是中间式的转写脱字，不影响结论。
- 待办：与原书核对中间式的准确形式（「3−3(3−2t)」「−6+6t」或其他等价写法），以确定脱落内容。
