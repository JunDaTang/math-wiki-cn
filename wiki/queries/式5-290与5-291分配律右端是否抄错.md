# 式 5.290 与 5.291 分配律右端是否抄错？

**问题**：手册 5.7.1 公理第 (4) 组「分配律」的转写文本

```
(5.290)  (a ⊔ b) ⊓ c = (a ⊓ b) ⊔ (b ⊓ c)
(5.291)  (a ⊓ b) ⊔ c = (a ⊔ b) ⊓ (b ⊔ c)
```

右端是否为转写讹误？正确形式是什么？

## 证据

1. **反例（已复算）**：在 $B=\{0,1\}$ 中，(5.290) 取 $a=b=1,\ c=0$ 得左边 $0$、右边 $1$；(5.291) 取 $a=0,\ b=1,\ c=0$ 得左边 $0$、右边 $1$。两式按转写均为假命题，与公理系统其余部分不自洽（内部矛盾，系转写所致）。
2. **更正（推断）**：正确形式应为
   $$(a\sqcup b)\sqcap c=(a\sqcap c)\sqcup(b\sqcap c),\qquad(a\sqcap b)\sqcup c=(a\sqcup c)\sqcap(b\sqcup c),$$
   即右端是 $c$（而非 $b$）分别与 $a$、$b$ 运算后合并。更正后即标准分配律，与格论通例一致。
