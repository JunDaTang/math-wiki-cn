# RTN 参数 n 疑为 4 之辨

## 疑点

源文（17.3.2.4 之 1(2)）：“在系统 (17.67) 取定 n ≥ l = 1。”

## 证据

1. 分岔序列“平衡点—周期轨—环面 T²—环面 T³”的 T³ 流需要相空间维数至少为 4；若按字面 n≥1（或 n≥l），与 T³ 不容。
2. 平行结构：同节 A-S 定理对 T² 环面取 “n ≥ 3, l = 2”，则 RTN 对 T³ 应取 “n ≥ 4, l = 1”。
3. “l”疑为 (17.67) 的分类参数（平衡点个数或类似），其约定需回查 17.3.1（见 [[queries/17-3-2未入库回指缺口]]）。

## 结论倾向

“n ≥ l = 1”疑为“n ≥ 4, l = 1”之讹（"4"被误读为"l"或排版损坏）。需对照原书与 17.3.1 中 (17.67) 的参数约定后闭合。
