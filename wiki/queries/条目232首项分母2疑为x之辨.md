# 条目 232 首项分母 2 疑为 x 之辨

## 问题

21.7.2.7（$X = x^2-a^2$）条目 232 原文两行首项均作 $-\frac{\sqrt{X^3}}{2}$。此「2」是转写（OCR）之误，还是原书印刷之误？正确形式为何？

## 证据

1. **求导不闭合（直接证伪）**：以 $-\frac{X^{3/2}}{2}$ 为首项、后两项 $\frac32x\sqrt X$、$-\frac32a^2\operatorname{Arcosh}\frac xa$ 不变，对右端求导无法还原被积函数 $\frac{\sqrt{X^3}}{x^2}$。
2. **唯一解重构**：设 $F = -\frac{X^{3/2}}{x} + c_1x\sqrt X + c_2a^2\operatorname{Arcosh}\frac xa$，令 $F' = \frac{\sqrt{X^3}}{x^2}$，比较 $x^4$、$a^2x^2$、$a^4$ 系数得唯一解 $c_1 = \frac32$、$c_2 = -\frac32$——首项必为 $-\frac{\sqrt{X^3}}{x}$，其余两项与原文一致。
3. **族内平行对照**：[[二次根式三族平行结构]] 同位条目 176（$X=a^2-x^2$）与 204（$X=x^2+a^2$）首项均为 $-\frac{\sqrt{X^3}}{x}$，且两者均经求导验证无误。此误**仅属条目 232**，不涉 176、204。

## 结论（数学层）

$$\int\frac{\sqrt{X^3}}{x^2}\,\mathrm{d}x = -\frac{\sqrt{X^3}}{x} + \frac32x\sqrt X - \frac32a^2\operatorname{Arcosh}\frac xa + C = -\frac{\sqrt{X^3}}{x} + \frac32x\sqrt X - \frac32a^2\ln(x+\sqrt X) + C_1.$$

置信：高。复算记录见 [[21-7-2无理函数积分逐式求导复算]]。

## 待决

「2」究竟是 OCR 之误还是原书印刷之误，须对纸本复核方可定谳；若为后者，应记为原书 erratum。
