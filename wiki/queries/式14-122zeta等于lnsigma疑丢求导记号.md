# 式 (14.122) ζ = ln σ 疑丢求导记号

## 待裁决问题

源文 (14.122)：ζ′(z) = −℘(z)，ζ(z) = ln σ(z)。后半句按字面是否成立？

## 证据

**直接证据（由 (14.121b) 逐项求导）**：对乘积式取对数，

ln σ(z) = ln z + Σ′[ln(1 − z/ω_mn) + z/ω_mn + z²/(2ω_mn²)]，

求导得 (ln σ(z))′ = 1/z + Σ′[(z−ω_mn)⁻¹ + ω_mn⁻¹ + ω_mn⁻²z] = ζ(z)（即 (14.121a)）。故正确恒等式为

ζ(z) = (ln σ(z))′ = σ′(z)/σ(z)。

**反证（若按字面 ζ = ln σ）**：求导并代入上式得 ζ′ = ζ；但 (14.122) 前半给出 ζ′ = −℘，于是 ζ = −℘，而 ζ 只有单极点、℘ 有二阶极点，矛盾。

## 状态

开放（倾向转写丢一撇“′”）。待核对原书字句；裁决前引用建议采用 ζ = (ln σ)′ = σ′/σ。相关：[[魏尔斯特拉斯函数]]、[[式14-116至14-125魏尔斯特拉斯函数转录复算]]。
