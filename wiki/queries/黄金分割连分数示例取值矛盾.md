# 黄金分割连分数示例中 x 应取 aφ 还是 a/φ？

## 问题

《数学手册(原书第10版)》1.1.1 节对黄金分割公式 x/a = (a−x)/x 给出两组不相容的取值：

1. **1.1.1.2（二次无理数例）**：a = 1 时 x² + x − 1 = 0，x = (√5−1)/2 ≈ 0.618（即 a/φ）。
2. **1.1.1.4 例 B（连分数例）**：x = a[1;1,1,…] = aφ ≈ 1.618a，及 x = (a/2)(1+√5)。

两值互为倒数，相差因子 φ。例 B 数值自身自洽（[1;1,1,…] = φ；[2;4,4,…] = √5；α₄ = 8/5 误差 0.018a 均正确），矛盾仅在于与所引公式的解不符——x = aφ > a，甚至无法是长度为 a 的线段的一段。

## 待查证

- 是原书错误还是译文问题？
- 是否应将“整段”与“大段”的角色调换（例如 x 实应表示整段而 a 表示大段，或公式记号在两节中含义不同）？
