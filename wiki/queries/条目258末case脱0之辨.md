# 条目 258 末 case 脱 0 之辨

## 问题

21.7.2.8 条目 258 案例表末行条件作「c < , Δ < 0」，「c <」后是否脱「0」？

## 证据

1. 对照同构条目 241 末行「a < 0, Δ < 0」的完整写法。
2. 数理：该行给出 $c<0$ 时的 $\arcsin$ 实形式，条件残缺将使情形无法界定。

## 附带澄清（防误校）

案例表看似缺「$c<0,\ \Delta>0$」情形（241 同样看似缺「$a<0,\ \Delta>0$」），但该情形下 $\Delta = 4ac-b^2 > 0$ 迫使 $ac>0$，从而二次式判别式 $b^2-4ac = -\Delta < 0$ 且开口向下（首项系数与 $c$ 同为负），$X$ 恒负、根式无实值——**覆盖实为完备**，校勘时不应补入。

## 结论

「c <」后脱「0」，应作「c < 0, Δ < 0」。置信：高。归入 [[21-7-2全节系统性转写讹误清单]]。
