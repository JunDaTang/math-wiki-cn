# 表 16.1「有重复」列 (k≤n) 之辨

## 问题

转写版表 16.1 的两列列头分别为「无重复(k≤n)」与「有重复(k≤n)」——「有重复」列的 (k≤n) 标注是否属于该列？

## 与正文矛盾

若「有重复」列确有 k ≤ n 限制，则与正文公式矛盾：

- 式 (16.5) 有重复组合 Cₙ⁽ᵏ⁾ = C(n+k−1,k) 对任意 k ≥ 0 有定义，k 可大于 n。反例：掷 7 颗骰子（n = 6, k = 7），结果数 C₆⁽⁷⁾ = C(12,7) = 792 有限且有意义。
- 式 (16.7) 有重复排列 Vₙ⁽ᵏ⁾ = nᵏ 对任意 k 有定义，k 可大于 n。

## 推断

(k≤n) 条件仅属「无重复」列——与 (16.4)、(16.6) 明示的 0 ≤ k ≤ n 一致；「有重复」列头的标注疑为转写窜入或原书排版跨列之误。

## 特殊情况

「全排列」行的 k 语义特殊：指相同元素的个数，k ≤ n 由构造自动保证，与另两行「取出个数」的 k 不同（记号重载，见 [[comparisons/全排列组合排列无重复有重复公式比较]]）。
