# 3.3 全节变量符号成片脱落是否为转写丢字？

## 现象

3.3 全节的行内数学符号（单字母变量）系统性脱落，而编号公式主体基本完好。已登记的脱落点：

- 3.3.3/3.3.4 引言：「[V] 为体积，[S] 为表面积，[M] 为侧面积，[?] 高，A_G 为底面积」（两处相同）；
- 3.3.2(4) 立体角：「它被记作 [Ω]」「这里 [S] 是指……」；
- 直圆柱：「设底半径为 [R]」；直圆锥：「以 [l] 表示母线长，[R] 表示底圆半径」；
- 棱柱：「[l] 是棱长」；3.120 的 [l] 与 [Q]；
- 棱锥：「当底是 [n] 边形时有 [n] 个侧面」「其中 [p] 表示底的周长」；
- 表 3.7 标题：「棱长为 [a] 的正多面体」；
- 欧拉定理：「如果 [e] 是一个凸多而体的顶点数，[f] 是面数，[k] 是棱数」——对应顺序经表 3.7 验证为 e = 顶点、k = 棱、f = 面（[[findings/欧拉多面体定理公式与验证]]）；
- 柱段（3.145–3.146）：a、b、φ 与图 3.68 的绑定不完整（[[findings/柱体族公式]] 已给出由公式内部一致性反推的绑定）。
