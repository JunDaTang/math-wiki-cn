# 例 C 的差别说明「在 x=1 处无定义」是否应为「仅单侧趋于无穷」？

## 问题

《数学手册》(原书第10版) 2.1.5.3.1 例 C 原文：

> $f(x)=\mathrm{e}^{\frac{1}{x-1}}$，$f(1-0)=0$，$f(1+0)=\infty$，图 2.9 中的点 C 是这种类型的间断点，**不同之处在于函数 $f(x)$ 在点 $x=1$ 处无定义**。

但同型前两例在各自间断点处同样无定义：

- 例 A：$\tan x$ 在 $x=\frac{\pi}{2}$ 处无定义（$f(\frac{\pi}{2}-0)=+\infty$，$f(\frac{\pi}{2}+0)=-\infty$）；
- 例 B：$\frac{1}{(x-1)^2}$ 在 $x=1$ 处无定义（双侧 $+\infty$）。

故“在 $x=1$ 处无定义”不构成例 C 与例 A、B 的差别。三例的真正差别在于单侧行为：例 A 两侧分别为 $+\infty/-\infty$，例 B 两侧均为 $+\infty$，例 C 一侧极限为**有限值 $0$**、另一侧为 $\infty$。

## 待查证

原文（德文原版或英译本）此处想强调的差别是否为“仅单侧趋于无穷（另一侧极限有限）”，中译或转写是否发生了语义漂移。
