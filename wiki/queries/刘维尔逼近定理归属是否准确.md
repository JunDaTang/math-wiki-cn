# 误差估计式 (1.6) 的刘维尔归属是否准确

## 问题

手册 1.1.1.4, 3. 写道：“根据刘维尔逼近定理，下列误差估计式成立”

```latex
|\alpha - \alpha_{k}| = \left|\alpha - \frac{p_{k}}{q_{k}}\right| < \frac{1}{q_{k}^{2}}   (1.6)
```

这一归属存疑：

- 通常文献中，|α − pₖ/qₖ| < 1/qₖ² 是连分数渐近分数的**基本性质**（可由递推 (1.5) 直接导出），一般不冠以刘维尔之名；
- 刘维尔（Liouville）逼近定理给出的通常是**代数数**有理逼近的**下界**：若 α 为代数数，则存在 c > 0 使 |α − p/q| > c/qⁿ 对任意有理数 p/q 成立——方向与 (1.6) 相反，且该定理常被用于构造刘维尔超越数。
