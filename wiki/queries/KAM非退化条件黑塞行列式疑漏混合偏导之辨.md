# KAM 非退化条件黑塞行列式疑漏混合偏导之辨

**疑点**：手册陈述 [[concepts/KAM定理|KAM 定理]]的非退化条件为

```
det(∂²H₀/∂j_k²) ≠ 0
```

按字面这是仅以纯二阶偏导 ∂²H₀/∂j₁²、∂²H₀/∂j₂² 为对角元的行列式，漏掉了混合偏导 ∂²H₀/∂j₁∂j₂。二自由度情形的完整口径应为完整黑塞矩阵的行列式：

```
det [ ∂²H₀/∂j₁²   ∂²H₀/∂j₁∂j₂ ]
    [ ∂²H₀/∂j₂∂j₁ ∂²H₀/∂j₂²   ] ≠ 0
```

（源外注：KAM 文献中的非退化/扭转条件通常即要求黑塞矩阵非退化。）

**判定倾向**：记号 ∂²H₀/∂j_k² 或系 (∂²H₀/∂j_k∂j_l) 之脱漏/误排；本维基按「完整黑塞矩阵行列式」理解并在 [[concepts/KAM定理]] 标注。

**待办**：与原书核对；同时建议一并核对非共振指数 2.5（丢番图指数）的文献口径。
