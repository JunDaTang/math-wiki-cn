# 锥例子空间名残缺与 p = ∞ 正则性存疑

## 疑点一：空间名残缺

12.3.3.1 的跨空间锥例子清单转录残缺严重：

- 实心锥例：「空间政，𝒞([a,b])」——「政」疑为 𝔽ⁿ 或 ℝⁿ；
- 正规锥例：「在空间贮，Φⁿ, m, c, c₀, 𝒞([a,b]), ℓᵖ 和 Lᵖ」——「贮」「Φⁿ」疑为 𝔽ⁿ 类有限维空间；
- 正则锥例：「配，ℓᵖ 和 Lᵖ (1 ≤ p ≤ ∞) 中这些锥是正则的，但在 中则是非正则的」——「配」残缺，「但在 中」缺空间名（据外部复算疑为 m 与/或 c，见下）。

## 疑点二：p = ∞ 正则性

编者复算（外部经典论证）：ℓ^∞ 中 xⁿ = (1, …, 1, 0, 0, …) 单调增、以 (1,1,…) 为上界，但 ‖x^{n+m} − xⁿ‖_∞ = 1，非柯西列；L^∞(0,1) 中 χ_{(0,1−1/n)} 同理。故「ℓᵖ 和 Lᵖ (1 ≤ p ≤ ∞) 锥正则」对 p = ∞ 不成立，疑应为 1 ≤ p < ∞。

## 外部对照（供复原参考，非本源内容）

标准结果：𝔽ⁿ/ℓᵖ(n) 锥实心、正规、正则；m、c 锥正规但非正则（c₀ 正则）；𝒞([a,b]) 锥实心、正规、非正则；ℓᵖ、Lᵖ（p < ∞）锥正规、正则、非实心；ℓ^∞、L^∞ 锥正规、非正则。据此「非正则」句缺失名疑为 m（或 c、𝒞）。
