# 正文 X、Y、n 变量名系统性脱落之辨

[[sources/10-数学手册原书第10版--10-1634-相关和回归--q0qe2u]] 正文中变量名 X、Y、n（斜体单字母）系统性脱落，形成十余处空缺句。公式层未受影响（公式内变量均在），脱落仅发生于中文行文中的行内变量。推测成因：行内斜体变量在 OCR/转写环节丢失。

## 脱落处与拟补方案

| 原转写 | 拟补 |
|---|---|
| 「设 构成二维随机变量 $(X,Y)$」 | 设 X、Y 构成 |
| 「随机变量 称为相互独立」 | 随机变量 X、Y 称为 |
| 「对应千 的基本统计量」 | 对应于 X、Y 的 |
| 「若 是独立随机变量」 | 若 X、Y 是 |
| 「并不能推出 Y 独立」 | 并不能推出 X、Y 独立 |
| 「则由 ρ_XY=0 可得到 独立」 | 可得到 X、Y 独立 |
| 「随机变量 是否可视为相互独立」 | 随机变量 X、Y 是否 |
| 「变量 之间的相关关系」 | 变量 X、Y 之间 |
| 「对于任意定值 ，」 | 对于任意定值 x， |
| 「总体中随机变量 服从正态分布」 | 随机变量 Y 服从 |
| 「(16.155) 即指随机变量 的均值」 | 随机变量 Y 的均值 |
| 「方差为 σ² 与 相互独立」 | 疑为「与 x 相互独立」 |
| 「关于 个独立变量」 | 关于 n 个独立变量 |
| 「即矩阵 的秩等千 s+1」 | 矩阵 G 的秩等于 |

## 待办

1. 依上表拟补各句，并核对是否有遗漏；
2. 「方差为 σ² 与 相互独立」的脱落对象（x？各观测间相互独立？）语义上有歧义，需原书核对后定稿。
