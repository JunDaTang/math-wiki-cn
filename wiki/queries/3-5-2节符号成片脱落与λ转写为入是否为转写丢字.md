# 3.5.2 节符号成片脱落与 λ 转写为「入」是否为转写丢字

## 问题

3.5.2 节存在与前几节（3.2、3.3、3.4.1）同型的**系统性转写噪声**：数学符号成片脱落、希腊字母误识为汉字、页码-节号粘连。本页集中登记，不逐条展开。

## 现象清单

1. **λ 系统性转写为「入」**：贯穿全节（「入＝1」「入<0」「入＝—1」「λ = 5:1」处、(3.312c) 的参数范围、(3.329c)(3.329e) 的 λ 定义等）。
2. **3.5.2.7 节标题「圆」脱落**：目录层只余「3.5.2.7」，正文首条即「1. 圆的定义」。
3. **抛物线离心率数值「1」脱落**：「抛物线的数值离心率等千（参见第 279 3.5.2.11, 4.）」——由上下文及 3.5.2.11 的分类（e=1 抛物线）可确认为 e = 1。
4. **「如果有两个系数 (a c) 等于 0」**：应为 **(a, b, c)**。
5. **「μ 的符号必须和 (3.302) 的符号相反」**：疑脱「**C**」字（μ 与 C 反号）。
6. **页码-节号粘连**：「第 308 3.5.4.1」「第 83 2.3.4」「第 668 8.2.2.2」「第 1823.1.5.3」「第 25(1.67b)」「第 654 8.1.4.3」——与 [[queries/平面三角学节交叉引用页码节号粘连是否为转写通病]] 所记通病一致。
7. **「与图 3.14 类似」图号存疑**：出现在调和分割段（图 3.131 附近），或为图 3.132 之讹，或确指 3.1 章某图（调和平均相关），需据原书核对。
8. **字级噪声遍布**：「千/于」「儿/几（几何/儿何）」「等千」等，不影响数学内容但影响可读性。
9. **虚曲线例 B 的 cosh**：y − ln(1 − x² − cosh x) = 0 经分析确为空实轨迹（cosh x ≥ 1 使真数 1 − x² − cosh x ≤ −x² ≤ 0，处处无定义），与「虚曲线」定义自洽，可照录；但「cosh」一词是否原书如此仍建议核底本一次。

## 判断

上述现象与 3.2–3.4 节已登记的成片脱落（[[queries/3-3全节符号成片脱落是否为转写丢字]]、[[queries/球面几何节行内符号系统性脱落是否为转写丢字]]）同源，应为 OCR/转写丢字，而非原书内容。待据原书核定第 2、3、4、5、7 条的具体脱落内容。
