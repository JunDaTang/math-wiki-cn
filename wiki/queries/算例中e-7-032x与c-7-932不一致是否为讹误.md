# 算例公式 e^(-7.032x) 与 c = -7.932 不一致是否为讹误？

手册 2.16.2.12 算例：由平均值法的分组求和方程解得“b = 1.966, c = -7.932”，但随后正文将所得公式写作

$$y=364x^{1.966}\mathrm{e}^{-7.032x}.$$

指数系数 -7.032 与求得的 c = -7.932 不一致，是否为排版 / 转写讹误？

## 支持讹误判断的证据

1. **求和方程自洽**：分组方程 $-0.292=0.903b+0.2606c$、$-3.392=0.903b+0.6514c$ 可由表 2.9 精确复算，解为 c = -7.932。
2. **y_err 列自洽**：表中 $y_{\text{err}}$ 列与 c = -7.932 一致，如 x = 1.0 处 $364\cdot\mathrm{e}^{-7.932}\approx0.13$，恰为表中值；若取 -7.032 则 $364\cdot\mathrm{e}^{-7.032}\approx0.32$，与表中 0.13 不符。
3. **误差平方和归属**：0.0024 对应 c = -7.932 的模型。

结论倾向：-7.032 为 -7.932 的排版 / 转写讹误（数字 9 误作 0）。待对照原版确认。
