# 积分例 B 被积函数疑为 (x³+1)/(x(x−1)³) 之辨

## 疑点

20.3.4.2 有理函数积分例 B（也见手册第 648 页 8.1.3.3）的输入行转写为乱码：

```
In[1] := Integrate[(x3 + 1)/(x(x 泸）， x]
```

输出（式 20.35）为：

```
Out[1] = -1/(-1+x)² - 1/(-1+x) + 2Log[-1+x] - Log[x]
```

## 重构假设

对输出求导：

d/dx[−(x−1)⁻² − (x−1)⁻¹ + 2ln(x−1) − ln x] = 2/(x−1)³ + 1/(x−1)² + 2/(x−1) − 1/x = (x³+1)/(x(x−1)³)，

其中通分验证：分子 2x + x(x−1) + 2x(x−1)² − (x−1)³ = x³+1。数值点核验（两点）吻合。故被积函数疑为 **(x³+1)/(x(x−1)³)**，「泸」疑为「−1)³」之讹。
