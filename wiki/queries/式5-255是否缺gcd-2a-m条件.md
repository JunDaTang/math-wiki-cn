# 式 (5.255) 是否缺 gcd(2a, m) = 1 条件？

**源文（5.4.3.8 (1)）**：

$$a x^2 + b x + c \equiv 0 \pmod m \Leftrightarrow (2ax+b)^2 \equiv b^2 - 4ac \pmod m. \tag{5.255}$$

**分析**：恒等式 (2ax + b)² − (b² − 4ac) = 4a(ax² + bx + c) 给出：

- 正向（⟹）无条件成立：m | (ax²+bx+c) ⟹ m | 4a(ax²+bx+c)；
- 反向（⟸）需要 4a 模 m 可逆，即 gcd(2a, m) = 1，才能从 m | 4a(ax²+bx+c) 推回 m | (ax²+bx+c)。

源文未陈述任何附加条件即使用双向箭头。

**复核反例（无 gcd 条件时等式失效）**：取 m = 4、a = 1、b = 0、c = 3：x² + 3 ≡ 0 (4) 的解为 x ≡ 1, 3（x 奇）；而 (2x)² ≡ −12 ≡ 0 (4) 对一切 x 成立（4x² ≡ 0 (4) 恒真）。两个解集不同，双向等价不成立。

**两种可能**：

1. 原书为简化叙述而默认了 gcd(2a, m) = 1 的典型情形（二次同余理论中常见约定）；
2. 转写脱落了条件从句。

**影响**：[[concepts/二次剩余]] 与 [[findings/勒让德符号性质组与65-307算例]] 已按「源文如此 + 疑点标注」处理，未采信无条件双向等价。

**验证途径**：对照原书该式是否有前置假设；或与标准数论教材的二次同余化归条款比较。
