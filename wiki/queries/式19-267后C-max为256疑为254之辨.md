# 式 19.267 后 C_max 为 256 疑为 254 之辨

《数学手册（原书第10版）》19.8.1.2(2) 在 (19.267) 后写道：「因为保存 C = 0, C = 255 这里 C_min = 1, C_max = 256」。其中 **C_max = 256** 与三方面证据皆不合：

1. **位数上限**：单精度指数字段 8 位（表 19.4），特征 $C$ 的编码范围为 $[0, 2^8 - 1] = [0, 255]$，**256 不可表示**。
2. **保留约定**：正文自言 $C = 0$ 与 $C = 255$ 被保存（保留），则普通数可用的特征上界应为 **254**（C_min = 1 与此一致）。
3. **表 19.4**：$E_{\max} = +127$、$K = +127$，则 $C_{\max} = E_{\max} + K = 127 + 127 = \mathbf{254}$；且 $E_{\min} = C_{\min} - K = 1 - 127 = -126$ 与表列 $-126$ 一致。

独立推算（非本源所载）：双精度 11 位指数对应 $C \in [1, 2046]$（保留 0 与 2047），$E_{\max} = 2046 - 1023 = +1023$、$E_{\min} = 1 - 1023 = -1022$，均与表 19.4 吻合，进一步佐证单精度应为 $C_{\max} = 254$。

## 初步结论

「256」疑为「254」之转写讹误（如字形误识）。同句「因为保存 C = 0, C = 255」为残句，语义不完整，疑脱「（用于表示零与特殊值）」之类说明。
