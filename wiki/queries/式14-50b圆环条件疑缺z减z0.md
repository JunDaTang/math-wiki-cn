# 式 (14.50b) 圆环条件疑缺 z−z₀

**问题**：原书 (14.50b) 后的圆环条件是 $r_1 < |z| < r_2$ 还是 $r_1 < |z - z_0| < r_2$？

## 证据

- 本节转写文本在 (14.50b) 的说明中写作：“它在圆环 $r_1 < |z| < r_2$ 中，并且半径为 $r_1$ 的圆在其内部”；
- 但洛朗级数 (14.50a) 围绕一般圆心 $z_0$ 展开；14.3.4 开篇也明确“以 $z_0$ 为心，半径分别为 $r_1$ 和 $r_2$ 的两个同心圆周之间的圆环”；
- 本节唯一算例取 $z_0 = 0$（圆环 $1 < |z| < 2$），此时 $|z| = |z - z_0|$，讹误不会被算例暴露。

## 判断

疑为转写/排印层脱落 $-z_0$，正确形式应为 $r_1 < |z - z_0| < r_2$。这与本节成批丢失数学符号（$m$、$G$、$C$、$2\pi\mathrm{i}$ 等）的系统性讹误模式吻合，见 [[queries/14-3全节系统性转写讹误清单]]。
