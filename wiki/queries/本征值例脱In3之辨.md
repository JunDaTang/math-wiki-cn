# 本征值例脱 In[3] 之辨

## 疑点

20.3.3.3 希尔伯特矩阵例中，符号本征值（Root 对象）输出之后，正文称「但使用命令」，随即直接给出：

```
Out[3] = {1.56705, 0.208534, 0.0114075, 0.000305898, 3.28793×10⁻⁶}
```

In[3] 输入行整体脱失。

## 重构假设

按上下文（对 Eigenvalues[h] 数值化），In[3] 疑为 `N[Eigenvalues[h]]`（或 `N[%]`）；正文前段「如果 N[m] 被用来代替 m，那么我们将得到数值特征值」亦支持此重构。数值结果复算吻合，见 [[findings/希尔伯特矩阵本征值与Root系数复算]]。
