# 正文 Artanh 定义域「|x| ≤ 1」是否应为「|x| < 1」？

**问题**：手册 2.10.1.3 称 [[concepts/面积正切函数]]「仅在 |x| ≤ 1 时有定义」，但同一节的表 2.8 与式 2.213 的条件均为 |x| < 1，且正文同时陈述函数具有铅直渐近线 x = ±1。

**证据**：

- 表 2.8：面积正切 y = Artanh x 的定义域为 |x| < 1（见 [[findings/面积函数的定义域与值域]]）。
- 式 2.213：Artanh x = ½ ln((1+x)/(1−x))，条件 |x| < 1。
- tanh y 的值域为开区间 (−1, 1)，±1 处不可达，故反函数在 ±1 处无定义。

**倾向判断**：「≤」应为「<」，疑为原书或中文版转写笔误。
