# 表 5.6 中 XOR 与等价的公式否定号位置是否抄错？

**问题**：手册表 5.6 中「反等价或 XOR」与「等价」两行的记号列，转写为 $\overline{ab}+a\bar b$ 与 $\overline{ab}+ab$；否定号位置是否抄错？

## 证据（值表已复算无误）

- **XOR** 值表为 0, 1, 1, 0（次序 $(a,b)=(0,0),(0,1),(1,0),(1,1)$）。转写公式在 $(0,0)$ 处：$\overline{ab}+a\bar b=1+0=1$，与值表 0 不符；更正为 $\bar ab+a\bar b$ 后逐点吻合。
- **等价** 值表为 1, 0, 0, 1。转写公式在 $(0,1)$、$(1,0)$ 处均得 $\overline{ab}+ab=1$，与值表 0 不符；更正为 $\bar a\bar b+ab$ 后逐点吻合。

即转写把否定号从「仅覆盖首项中的单个变量」误抄为「覆盖整个乘积 $ab$」。NAND、NOR、蕴涵三行的公式转写正确。
