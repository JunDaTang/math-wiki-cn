# 码字是否应为 GF(q) 元素的 n 元组？

## 源文

5.3.7.4.1 末段（编码理论应用）：

> 有限域在编码理论中如线性码是极其重要的，其中考虑 (GF(q))ⁿ 形式的向量空间…线性码的元素（码字）也是有限域 GF(qⁿ) 的元素形成的 组．

（「 组」处脱落字词，疑为「n 元组」。）

## 问题

同一句内两处表述冲突：线性码定义为 (GF(q))ⁿ 的子空间，则码字应为 **GF(q) 中元素的 n 元组**（长度 n 的向量）；「GF(qⁿ) 的元素形成的组」与之不符——GF(qⁿ) 是 qⁿ 元域，其单个元素并非 n 元组。

## 判断

高置信应为「GF(q) 元素的 n 元组」，即码字 ∈ (GF(q))ⁿ；「GF(qⁿ)」疑为「(GF(q))ⁿ」之讹。线性码所属小节 5.4.6.2 未入库，待入库后回核（[[queries/5-3-7未入库依赖缺口]]）。状态：**开放**。
