# 20.1 全节系统性转写讹误清单

《数学手册（原书第10版）》20.1 的转录文本存在与此前各节（如 [[queries/19-8-2全节系统性转写讹误清单]]、[[queries/19-7全节系统性转写讹误清单]]）同型的系统性损伤。本页汇总清单并跟踪各项解决状态。

## 讹误清单

| 位置与原文残迹 | 问题 | 状态 |
|---|---|---|
| 「对千经常出现的错误」「处千不断的开发中」「取决千操作系统」「区别千其他文本部分」「对千 Mathematica」等 | 「于」误作「千」（多处） | 待与原书核对 |
| 「也能够在小型计算机 (PC) 上使甩」 | 「使甩」应为「使用」 | 待与原书核对 |
| 「来“做数学＇成为可能」 | 引号失配（前引号失，仅存后引号 ＇） | 待与原书核对 |
| 「但它有 个实根」「具有一定精度的 个解」 | 两处脱字 | 已由 [[findings/式20-1至20-3c符号与数值求解算例转录复算]] 证实均应为「六」，见 [[queries/它有个实根脱六之辨]] |
| 「并用符号一将它们分开」 | 同行输入输出的分隔符号脱失为「一」 | 见 [[queries/输入输出同行分隔符脱失之辨]] |
| 「（参见第 1318 19.8.4.2, 1.)」 | 疑脱「页」字；括注「1.)」全半角混用；编号本身待核 | 见 [[queries/回指19-8-4-2与第1318页之辨]] |
| 「成为可能它们是些能够……」等 | 多处句间标点缺失 | 待与原书核对 |

## 说明

各讹误集中于自然语言文本与符号排印层面，不影响公式内容——式 (20.1)–(20.3c) 已整体复算无误。回指缺口另见 [[queries/20-1未入库回指缺口]]。
