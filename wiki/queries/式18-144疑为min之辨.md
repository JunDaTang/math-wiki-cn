# 式 (18.144) 疑为 min 之辨

## 疑点

18.3.6.1 由购买问题导出的泛函方程（式 18.144）在转写文本中印作

```latex
φ_j(x_{j-1}) = max_{u_j∈U_j(x_{j-1})} (c_j u_j + φ_{j+1}(x_{j-1} + u_j − v_j)),  j = 1(1)n
```

## 支持 min 的证据

1. 源头模型（式 18.142a/18.127a）为 `→ min!`（总费用最小）。
2. 本小节全部后向计算按 min 进行：$\varphi_6(x_5)=c_6\max\{0,v_6-x_5\}$ 来自 $\min_{u_6}c_6u_6$；$\varphi_4(0)=\min\{28,\dots,30\}=24$。
3. 前向计算亦按 min：$\varphi_1(2)=75=\min_{4\leqslant u_1\leqslant 8}(4u_1+\varphi_2(u_1-4))$。
4. 六行 $\varphi$ 值表逐值复算与 min 语义完全相符（[[findings/购买问题算例六行φ值表复算]]）。

## 结论倾向与待办

证据一致指向 min，判定 `max` 为讹误的置信度高；若按 max 执行，将得到「最昂贵购买策略」，语义完全颠倒。待对照原版确认错误来源。相关：[[queries/式18-129a疑为max之辨]]（同一 min/max 错位家族的另一处，方向相反）。
