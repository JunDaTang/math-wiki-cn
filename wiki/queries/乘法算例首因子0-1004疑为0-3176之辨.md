# 乘法算例首因子 0.1004 疑为 0.3176 之辨

## 疑点

原文乘法算例（19.277 后）：

$$(0.1004\cdot 10^3)\cdot(0.2504\cdot 10^5) = 0.07952704\cdot 10^8 = 0.7953\cdot 10^7.$$

首因子与结果不符。

## 复算证据（直接证据，强度高）

- $0.1004\times 0.2504 = 0.02514016$，与所给尾数 $0.07952704$ 不符；
- $0.3176\times 0.2504 = 0.07952704$，与所给结果**精确**一致；指数 $3+5=8$ 亦合；
- 旁证：紧随其后的除法算例恰为 $(0.3176\cdot 10^3)/(0.2504\cdot 10^5)$，两算例共用操作数 $0.3176\cdot 10^3$ 与 $0.2504\cdot 10^5$ 的可能性大；
- "0.1004"恰为前一减法算例的被减数尾数，疑为串入。

## 倾向判断

首因子应为 $0.3176\cdot 10^3$；本条为全节复算证据最强的转写疑点。
