# 式 (4.21a) 后的矩阵加法算例能否据原书复原？

## 问题

式 (4.21a)（矩阵加减法）之后有一段整体损毁的算例，转写残留为乱码碎片：

```text
.( 1 3 7\ 2 —1 4) + 3( 2 —5 0\ —2 7 0 8) 4) 4
```

## 分析

- 碎片中的「1 3 7 / 2 −1 4」与本节数乘算例 (4.22a 后) 所用矩阵相同，「3(…)」形似数乘，故该算例疑似演示「矩阵 + 数乘矩阵」的加法运算。
- 但碎片维数不明（「3(2 −5 0 / −2 7 0 8) 4) 4」无法解析为合法大小的矩阵），仅凭转写文本不能复原。
