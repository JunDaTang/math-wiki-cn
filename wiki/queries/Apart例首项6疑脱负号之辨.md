# Apart 例首项「6」疑脱负号之辨

## 疑点

20.3.1.4 部分分式分解算例：

```
In[1] := Apart[q/p]
Out[1] = 6/(35(5+x)) + (-55+11x+6x²)/(35(-5+x²+x³))
```

首项分子「6」前疑脱「−」号。复算（部分分式系数 A = [(x²−7)/(x³+x²−5)]|_{x=−5} = −6/35，及 x = 0 处数值核验 7/25 = 0.28）表明正确输出应为 −6/(35(5+x))；第二项无误。详见 [[findings/Apart例首项符号与复算不符]]。

## 待辨

1. 原书影印件中此处是否即为「+6」（原书排印之误），抑或「−6」而在 OCR/转写中丢失负号？
2. 若为原书之误，需在 [[concepts/代数表达式与多项式操作命令]] 与本源页加注勘误，避免讹误随转写扩散。
