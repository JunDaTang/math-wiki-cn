# 4.5.1.1 线性系定义段的下标讹误

**问题**：4.5.1.1 末段（变量归属句）的下标与变量名讹误，原书应为何？

**转写原文**（粗体向量符号脱落为乱码）：「大小为 (m,n) 的矩阵 的元素 a_μν 及列向量 的分量 a_μ (μ = 1, 2, …, n) 是常数…列向量生的分量 x_ν (ν = 1, 2, …, n) 是独立变量，列向量 的分量 x_μ (μ = 1, 2, …, m) 是相关变量」

**据式 (4.174a–b) 的复原**：a_μν 与 a_μ (μ = 1, …, **m**) 是常数；x_ν (ν = 1, …, n) 是独立变量；**y**_μ (μ = 1, …, m) 是相关变量。即两处错误：a_μ 的下标上限 n 应为 m；「相关变量 x_μ」应为 y_μ。

**待决**：复原在数学上确定（与 (4.174b) 的维数一致），但需原书确认措辞。复原后的表述已在 [[findings/线性系与选主元法则]] 采用。
