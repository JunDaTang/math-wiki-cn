# arcsec x 与 arccosec x 的条件 (x>1) 是否应为 (|x|>1)？

源：[[10-数学手册原书第10版--12-612-一元函数微分法则--1l44go8]] 表 6.1（转录见 [[表6-1初等函数导数公式表逐字转录]]）。

## 问题

表 6.1 中 arcsec x 与 arccosec x 的条件记为 (x>1)，而同表其他反函数使用绝对值记法：arcsin x、arccos x、Artanh x 用 (\|x\|<1)，Arcoth x 用 (\|x\|>1)。按通行定义，arcsec 与 arccosec 的定义域应为 $\|x\| \geq 1$（含 $x \leq -1$ 分支），疑“\|”符号在转写中脱漏。

## 影响评估

在 x>1 分支上，所给公式 $\frac{1}{x\sqrt{x^2-1}}$ 与 $-\frac{1}{x\sqrt{x^2-1}}$ 本身正确（已复算）；本问题只涉及条件标注的完整性，不影响已转录公式的正确性。但若按 (x>1) 理解，会遗漏负半轴分支。

## 待办

核对纸质原书表 6.1；若确认为“\|”脱落，按全书系统性符号脱落模式（见 [[6-1-2全节系统性转写讹误清单]]）一并修复。
