# 泊松逼近条件 n ≥ 1500p 之辨

## 现象

16.2.3.3 第 4 条：「实际情况中，由于泊松分布更易于计算，当 $p \le 0.08$ 和 $n \ge 1500p$ 时，即用此公式。」

## 疑点

1. 「n ≥ 1500p」形式罕见：n 的下界正比于 p，p 越小要求越松（p=0.08 → n≥120，此时 np≥9.6；p=0.01 → n≥15，此时 np 仅 0.15），判据强度随 p 漂移，与「n 要大」的直觉不符；
2. 常见文献的经验法则多以 p 的上界（如 p≤0.05 或 0.1）配合 np（或 np 与 n(1−p)）的阈值给出，未见此形式；
3. 本节转写讹误密集（见[[queries/16-2-3全节系统性转写讹误清单]]），数字与关系式是高危对象。

## 可能的原文形式（假设，待核）

- 使 np 具有固定下界的表达（如 n 与 1/p 同阶的某常数倍）；
- 涉及 n(1−p) 或 λ=np 上界的表达；
- 亦不排除原文确为 n ≥ 1500p（含特定推导依据）。
