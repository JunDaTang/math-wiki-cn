# 式 7.86–7.89 编号错位如何复原？

## 现象（转写原文）

- 式 7.86（两个幂级数的积 / Cauchy 卷积）的标签粘连为「{7.8}(7.86)」——多出的「{7.8}」疑为上一标签碎片或 OCR 伪影。
- 「2. 幂级数的方幂的前几项」：先给出 S = a + bx + cx² + ⋯（无标签），随后 S² 与 √S **合并于同一个公式块**，标签为「{7}(7.88)」；紧接着单独一行孤立出现「(7.89)」，其后才是 1/√S 的公式块（标签 7.90）。

## 复原方案（本 wiki 采用）

按内容与标签序列，合理复原为：

| 式号 | 内容 |
|---|---|
| 7.86 | 积（Cauchy 卷积） |
| 7.87 | S = a + bx + cx² + dx³ + ex⁴ + fx⁵ + ⋯（设定） |
| 7.88 | S² |
| 7.89 | √S |
| 7.90 | 1/√S |
| 7.91 | 1/S |
| 7.92 | 1/S² |
| 7.93 | 商 |
| 7.94a–c | 反级数 |

「{7}(7.88)」可解释为排版中 S² 公式的标签 (7.88) 与前式残余「{7}」粘连；孤立的「(7.89)」当属被挤出的 √S 标签。

## 待办

1. 对照原书确认 7.87–7.89 的编号归属（尤其是 √S 是否独立编号为 7.89）。
2. 若原书不同，修订 [[式7-86-7-93幂级数运算系数公式复算]] 的式号映射。
