# 式 (19.160) 后 n=2 方程组之 x₁ 疑为 x₂ 之辨

**问题**：19.6.1.1 中 n=2 方程组第三式的前两处 $x_1$ 是否为 $x_2$ 之转写讹误？

**状态**：open（倾向「是」，待原书影印核对）

## 原文（疑讹）

```
p₂(x₂) = a₀ + a₁(x₁−x₀) + a₂(x₁−x₀)(x₂−x₁) = y₂
```

## 辨析

将 (19.160)（取 n=2）在 $x=x_2$ 处求值，应得

```
p₂(x₂) = a₀ + a₁(x₂−x₀) + a₂(x₂−x₀)(x₂−x₁) = y₂
```

即前两个因子中的 $x_1$ 应为 $x_2$（末项 $(x_2-x_1)$ 不误）。依据：

1. **与 (19.160) 不符**：照原文，第三式并非 $p_2$ 在 $x_2$ 处的取值，插值条件 $p_2(x_2)=y_2$ 无法成立。
2. **破坏三角结构**：源称插值条件导致「三角矩阵的线性方程组」故系数容易计算；照原文则第三式与 (19.160) 脱节，方程组不再由 (19.160) 逐点求值而来。

## 判定倾向

转写讹误（数学不自洽暴露型），复原为 $a_1(x_2-x_0)+a_2(x_2-x_0)(x_2-x_1)$。置信度高，仍需原书影印最终确认；复原后的方程组见 [[牛顿插值公式]]。
