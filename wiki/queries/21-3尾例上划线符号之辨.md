# 21.3 尾例上划线符号之辨

## 问题

21.3「(公制)前缀表」节末尾的单位换算算例块在转写中呈重度 OCR 乱码，且每个复原式之前均带一个上划线字母（依次为 m、u、Ω、u、u）。这些上划线符号的原文究竟为何？

## 原始转写（逐字保存）

```latex
$\begin{array} { r } { \overline { { \mathsf { m } } } 1 0 ^ { 3 } = 1 0 0 0 . } \end{array}$
$\overline { { { \bf { u } } } } 1 0 ^ { - 3 } = 0 . 0 0 1 .$
$\mathrm { \overline { { { \Omega } } } 1 0 ^ { 3 } m = 1 k m } .$
$\overline { { \mathbf { u } } } \mathbf { u } \mathbf { m } = 1 0 ^ { - 6 } \mathbf { m } .$
$\mathbf { \overline { { u } } } \mathbf { 1 } \mathbf { n } \mathbf { m } = 1 0 ^ { - 9 } \mathbf { m }$
```

## 公式本体复原

| 复原式 | 验算 |
|---|---|
| $10^{3} = 1000$ | ✓ |
| $10^{-3} = 0.001$ | ✓ |
| $10^{3}\,\mathrm{m} = 1\,\mathrm{km}$ | ✓ |
| $1\,\mu\mathrm{m} = 10^{-6}\,\mathrm{m}$ | ✓ |
| $1\,\mathrm{nm} = 10^{-9}\,\mathrm{m}$ | ✓ |

源文「um」之 u 为 μ 之 OCR 替身：表内微作词头作「μ」，尾块以「u」代之，同一符号两种形态并存。

## 工作假设与反证

**工作假设**：上划线部分为原文中重复出现的标记词之误读，如中文「例如」或德文原文「z. B.」（zum Beispiel）。

**反证推理**（上划线字母不可能是词头符号本体）：各上划线字母与所配指数不匹配——

- 第二例 u 配 $10^{-3}$：若为 μ 应配 $10^{-6}$；
- 第一例 m 配 $10^{3}$：若为词头 m 应配 $10^{-3}$，与 $10^{3}$ 相配者应为 k；
- 第五例 u 配 nm：与任何词头释义不合。

故上划线部分无法解释为词头符号，属 OCR 噪声之可能性最大；然其原文为何，尚无定论。

## 证据强度

- 公式本体复原：中高（数值自洽，且为标准教科书换算例）。
- 上划线标记之原文：低（未定，仅为假设）。

## 待办

1. 核对原书该页之纸本或高保真扫描，确认上划线处原文（「例如」/「z. B.」/其他标记）。
2. 若原书为德文，核查其例句标记之惯用形式。
