# 换算因子 ϱ 上方的加点是否为转写噪声？

原文在引出式 3.175c 时写作「换算因子 $\dot{\varrho}$ 等于」，ϱ 上方带点；而式 3.175a–c 与式 3.178 中该因子均无点。数值上 ϱ = 1 rad = 57.2958° = 3438′ = 206265″ 复算自洽（见 [[球面距离角度长度换算与换算因子]]）。
