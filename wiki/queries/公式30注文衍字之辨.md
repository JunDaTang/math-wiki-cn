# 公式 30 注文衍字之辨

## 疑点

式 30 附注转写作（逐字转录）：

> 若求和后面中的通项中分母为 0, 则这些项由 $\binom {m + n - 2 } { m - 1 } ( - a ) ^ { m - 1 } \ln { \frac { X } { x } }$ 代替．

「若求和后面中的通项中分母为 0」语序混乱：「求和号后面」「中的通项」「中分母」疑有衍字/脱字，通顺表述当为「若求和号后面的通项中分母为 0」。

## 规则本身核验

替代规则经 $i=m-1$ 情形核验正确：此时分母 $(m-i-1)=0$，该项恰应由对数项替代；将 $m=1,n=1$ 与 $m=2,n=1$ 特化回代，分别与式 18（$-\frac1b\ln\frac Xx$）及式 22（至多差常数）一致（见 [[findings/通用积分公式特化一致性与式28适用域复算]]）。

## 待辨

原书注文文字为何（衍字还是脱字）？待纸本核销；属纯文字问题，不影响数学内容。
