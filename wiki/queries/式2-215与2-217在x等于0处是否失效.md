# 式 2.215/2.217 含 1/x 的表示在 x = 0 处是否失效？

**问题**：

- 式 2.215 中 Arsinh x = Arcoth(√(x²+1)/x) 的条件写作 |x| < ∞，但该表示在 x = 0 处无定义（除零）；
- 式 2.217 中 Artanh x = Arcoth(1/x) 的条件写作 |x| < 1，同样在 x = 0 处无定义。

**分析**：两个恒等式实际仅对 x ≠ 0 成立，手册所给条件未排除 x = 0。此外，式 2.216 的 Arcoth(x/√(x²−1)) 在 x = 1 处同理仅在极限意义下成立。此为条件行疏漏，属原书疏漏还是中文版转写问题待核验（与 [[queries/式2-220减法分支是否缺少x大于等于y条件]] 属同类问题）。

**验证建议**：数值检查 x = 0 附近行为；如有原版（德文/英文）可对照条件行。
