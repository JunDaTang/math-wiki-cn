# 式 (16.75b) 误差函数被积函数疑为 e^{−t²}

**开放问题**：(16.75b) 的被积函数究竟是 e^{−t²/2} 还是 e^{−t²}？是原书之误还是转写之误？

## 源文逐字转录

```
erf(x) = (2/√π)·∫_{0}^{x} e^{−t²/2} dt = 2·Φ₀(√2·x)        (16.75b)
```

## 矛盾所在

由 (16.75a)，Φ₀(x) = (1/√(2π))∫₀ˣ e^{−t²/2}dt。作代换 u = t/√2：

```
2·Φ₀(√2·x) = (2/√(2π))·∫_{0}^{√2·x} e^{−t²/2} dt = (2/√π)·∫_{0}^{x} e^{−u²} du
```

即恒等式 erf(x) = 2Φ₀(√2x) 仅当被积函数为 **e^{−u²}**（标准误差函数定义 erf(x) = (2/√π)∫₀ˣ e^{−t²}dt）时成立。若被积函数确为 e^{−t²/2}，则左端为 2√2·Φ₀(x)，与 2Φ₀(√2x) 不相等——两者必有一误。

## 两种可能

1. 原书即误（排印错误）；
2. 转写之误：指数中的「/2」为衍入——但「多出 /2」与全节「上标系统性丢失」的模式方向相反，不能简单归入该模式。
