# 「若选取 个点」与「足够大的点数 」处脱 N 之辨

## 疑点

19.6.3.4 两处脱落字符 N：

1. 「若选取 个点 x_ν (ν = 1, 2, ⋯, N; N ⩾ n+2)」——「选取」后脱 N；
2. 「对于足够大的点数 及某些进一步的条件」——「点数」后脱 N。

## 分析

- 上下文均以 N 计离散点数：(19.206)–(19.209) 的求极大范围均为 ν = 1, …, N；且 N ⩾ n+2 与交替点定理所需点数要求呼应。
- 两处补 N 后文义完整；疑为斜体或数学体 N 在 OCR 转写中丢失（与本节其他脱字、脱数值同型）。
