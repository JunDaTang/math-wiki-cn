# 338 式乱码复原之辨

问题：条目 338 的转写文本完全乱码，原式为何？

转写原文（逐字）：

```
338. dx t 1 n( π 十 ax ¾ tancosax(l + cosax) a 4 2 a 2
```

## 推测

按 337/339 邻接结构推测应为：

```latex
\int \frac{dx}{\cos ax\,(1+\cos ax)} = \frac{1}{a}\ln\tan\left(\frac{\pi}{4}+\frac{ax}{2}\right) - \frac{1}{a}\tan\frac{ax}{2}
```

依据：

- 乱码可辨片段「cosax(l + cosax)」指明分母为 cos ax(1+cos ax)；「π」「4」「tan」「a 2」等残片与此式逐段对应；
- 邻接结构：336=∫cos/(1+cos)、337=∫cos/(1−cos)、339=∫dx/(cos(1−cos))，则 338 应为 ∫dx/(cos(1+cos))，恰补全 332–343 的 1±cos 族；
- 数学自洽：1/(cos(1+cos)) = 1/cos − 1/(1+cos)，故积分 = ∫sec − ∫dx/(1+cos) = (1/a)ln tan(π/4+ax/2) − (1/a)tan(ax/2)（用 325 与 332）；与 339 的结构（(1/a)ln tan(π/4+ax/2) − (1/a)cot(ax/2)）平行，两式均已独立复算通过。
