# 拉宾-米勒检验式的 n−2 是否应为 n−1？

**问题**：源文检验步骤作「求出表达式 n − 2 = 2^t·u（u 是奇数）」。「n − 2」是否为「n − 1」之讹？

**证据**：

1. 所依据的命题 (＊) 明确作 n − 1 = 2^t·u。
2. 同节算例 A 用 n = 561：n − 1 = 2^4·35（560 的分解），与「n−1」一致。
3. 数学上，素性检验利用的是 n 在模 n 乘法群中的阶整除 n−1（n 素数时），故分解对象必为 n−1。

**初步结论**：应为 n − 1；本 wiki 相关页面（[[methodology/拉宾-米勒素性检验流程]] 等）已按 n−1 转写并标注本疑点。待核对原版确认。
