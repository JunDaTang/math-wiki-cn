# 式 (3.203) 大圆航线方程本体脱落是否可复原为 tan φ = tan φ_N·cos(λ−λ_N)？

## 现象

源文 3.4.3.4「大圆航线的方程」处，正文叙述「可以给出通过 P_N 和运行点 Q(λ_Q, φ_Q) 的大圆航线方程，为」之后紧跟空的公式编号 (3.203)，本体在转写中完全缺失（图片占位符亦未含公式）。

## 复原（推断）

```
tan φ = tan φ_N·cos(λ − λ_N)
```

## 内部引用证据

1. 赤道交点推导明确引用：交点处须满足「tan φ_N cos(λ_E − λ_N) = 0」，由此得 (3.206) λ_Eν = λ_N ∓ 90°——与复原式在 φ = 0 处一致。
2. 与子午线交点 (3.212)：φ_Y = arctan[tan φ_N cos(λ_Y − λ_N)]，即 (3.203) 代入 λ = λ_Y 的直接改写。
3. 两条大圆交点方程组 (3.227a/b)：tan φ_N cos(λ_S − λ_N) = tan φ_S，同一形式。
4. 与平行圆交点 (3.209) 由 (3.203) 解出 λ_X，结构吻合。
