# 标准化叙述脱字疑为 n 之辨

**问题**：18.1.1.1 第 6 条「问题可以在 (18.4a,18.4b) 给出的形式下进行研究这里□是增加了的变量数写成向量形式为」中，「这里」与「是增加了的变量数」之间脱落的主字是什么？

## 证据与推断

- 脱字处应为一个记号，指标准化（自由变量分解与松弛化）之后变量总数增加的结果；
- 式 (18.4a/b) 与 (18.5a/b) 均以 n 记变量个数，而第 6 条开头的 f(x) = c₁x₁ + ⋯ + cₙxₙ 用的是原始 n；若增加后的总数沿用 n，则原文疑为「这里 n 是增加了的变量数」，即标准形式中的 n 已是扩充后的变量总数；
- 亦不排除原书使用带撇记号（如 n′）或其他记号的可能，单凭转录文本无法定谳。

## 核验途径

需对原书（纸质版或高质量扫描）版面核验。若确认，应同步修正 [[concepts/线性规划标准形式]]、[[methodology/线性规划标准化流程]] 与 [[sources/10-数学手册原书第10版--15-1811-问题的提法和几何表达--w8nsz6]] 中的相应表述。

## 影响评估

纯文字讹误，不影响公式结构；标准形式（18.5）本身完整无误。
