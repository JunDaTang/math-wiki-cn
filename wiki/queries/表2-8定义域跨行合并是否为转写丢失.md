# 表 2.8 的定义域跨行合并是否为转写丢失？

**问题**：原表 2.8 将 Arcosh 与 Arcoth 的定义域单元格跨两行合并（HTML rowspan 结构），导致两个值域行各自对应的定义域子区间未在表中显示：

- Arcoth：x < −1 ↔ 值域 −∞ < y < 0；x > 1 ↔ 值域 0 < y < ∞（子区间与值域行的配对在转写后丢失）；
- Arcosh：两行共用 1 ≤ x < ∞（此配对无歧义）。

**分析**：转写后的表格语义不完整；正文 2.10.1.4 的区间叙述（(−∞, −1) 与 (1, +∞)）可补全 Arcoth 的配对。需人工核对原表结构是否本就如此。
