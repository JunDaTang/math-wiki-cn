# 式 (4.144)/(4.149) 末项 p^{1−t}q^t 是否原书如此？

**待解问题**：式 (4.144) 与 (4.149) 把 Slerp 写作三重等式 p(p̄q)^t = p^{1−t}q^t =（三角函数形式）。末项 p^{1−t}q^t 在**非交换**的四元数代数 ℍ 中是记号滥用：它与严格形式 p(p̄q)^t 一般不相等，仅当 p、q 交换时相等。

## 反例（分析者构造并复核）

取 p = i, q = j, t = ½：

- p(p̄q)^t：p̄q = (−i)j = −k；(−k)^{1/2} = (1−k)/√2；故 p(p̄q)^{1/2} = i(1−k)/√2 = (i+j)/√2（用 ik = −j）。这与三角函数形式一致：Slerp(i, j, ½) = i·sin(π/4) + j·sin(π/4) = (i+j)/√2。
- p^{1−t}q^t = i^{1/2}j^{1/2} = (1+i)(1+j)/2 = (1+i+j+k)/2。

两者是不同的单位四元数，等号一般不成立。

## 待裁定

- 若原书即印作 p^{1−t}q^t：属原书记号不严谨（图形学文献中此缩写常见，通常默认 p(p̄q)^t 之意），[[concepts/Slerp]] 保留警示即可。
- 若为转写/排版之误：应更正为 p(p̄q)^t。

推导链 (4.147)–(4.149) 本身正确（见 [[findings/Lerp与Slerp公式组及等价性证明]]），问题仅在末项记号。
