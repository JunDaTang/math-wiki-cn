# 9.1 全节系统性转写讹误清单

**问题**：源文件《数学手册(原书第10版)/9.1 常微分方程.md》存在系统性 OCR 转写讹误，需逐条核对原书并复原。主导模式为**孤立斜体字母 n 的系统性脱漏**（至少 6 处），与已入库的 8.2.1 式 8.52（M 脱漏）、8.2.3 式 8.89a（k 脱漏）同源。

## 待核对事项

1. 逐条与原书（印刷版）核对，确认复原文本；式 9.1 公式本体经核对无讹误。
2. 要点 3 中 y(x₀) 与 y′(x₀) 之间的逗号在转写中仅以空格分隔，是否原书如此待核对。
3. 「斜体 n 脱漏」模式是否延续到 9.1.1–9.1.3（处理顺序建议：9.1.1 → 9.1.2 → 9.1.3）。
4. 例 1 的「条件 c = 0」是否为原书原文、抑或点值条件的转写失真，见 [[queries/例1条件c等于0与边值问题定义宽窄]]。
