# 「PA = LA」疑为「PA = LR」之辨

## 疑点

正文（19.8.4.1 数值线性代数）：「若矩阵 A 是非奇异的方阵，则线性方程组有唯一解。由反斜杠算符用通常的列主元高斯消元法，得三角分解 PA = LA（参见 19.2.1.1）」。其中「PA = LA」与紧随其后的 [L, R, P] = lu(A) 输出（L 单位下三角、R 上三角、P 置换阵）在数学上不能相容。

## 复算

以 [L,R,P]=lu(A)（A=[1 0 3; 2 1 1; 1 2 3]）的输出逐行计算：

- PA = [2 1 1; 1 2 3; 1 0 3]
- LR = [2 1 1; 1 2 3; 1 0 3]

两者相等，故 **PA = LR** 成立；「LA」应为「LR」（详见 [[findings/Matlab线性代数算例复算]]）。

## 状态

复算已证；疑为转写或原书排印讹误（L 与 R 之误植），待原书确认记号。
