# 一维算例第三分量xe⁻¹疑为xe⁻²之辨

## 现象

17.2.7.1.3 一维算例（$\dot x = -x$，$\varphi^t(x) = x\mathrm{e}^{-t}$，$m = 3$）：「对测量函数 $h_1(x) = x$，映射 $x \in (-1,1) \mapsto \Phi_{f,h_1}(x) = (x, x\mathrm{e}^{-1}, x\mathrm{e}^{-1})$ 显然是 $\mathbb{R}^3$ 上一个嵌入」。第三分量与第二分量同为 $x\mathrm{e}^{-1}$。

## 复算

按重构映射 (17.63)（前向坐标，$m = 3$），三个分量应为

$$h_1(\varphi^0(x)) = x,\qquad h_1(\varphi^1(x)) = x\mathrm{e}^{-1},\qquad h_1(\varphi^2(x)) = x\mathrm{e}^{-2}.$$

故第三分量疑脱/讹指数 2。源文两种写法下结论均成立：由第一分量 $x$ 即恢复原像（单射），导数 $(1, \mathrm{e}^{-1}, \mathrm{e}^{-2})^\top$（或源文版 $(1, \mathrm{e}^{-1}, \mathrm{e}^{-1})^\top$）秩为 1（浸入），且是到像的同胚——嵌入结论不受影响。
