# 式 3.352b 首项负号是否为转写错误

## 问题

抛物线弧长公式的第二表达式 (3.352b) 转写为：

```
l_OP = −√(x(x + p/2)) + (p/2)·Arsinh√(2x/p)
```

其首项为**负号**，与第一表达式 (3.352a)：

```
l_OP = (p/2)·[√((2x/p)(1 + 2x/p)) + ln(√(2x/p) + √(1 + 2x/p))]
```

不能同时成立。

## 分析（分析阶段独立推导）

1. (3.352a) 经推导验证成立：l = ∫√(1 + p/(2x)) dx 给出该式。✓
2. 利用 ln(√t + √(1+t)) = Arsinh√t（t = 2x/p）改写 (3.352a)：

```
l_OP = (p/2)·√(t(1+t)) + (p/2)·Arsinh√t = √(x(x + p/2))·(√… 核对) + (p/2)·Arsinh√(2x/p)
```

其中首项应为 **+√(x(x + p/2))**：(p/2)·√((2x/p)(1+2x/p)) = √((p²/4)·(2x/p)·((2x+p)/p)) = √(x(2x+p)/2) = √(x(x+p/2))。✓
3. 若取负号，则 x → 0 时 l_OP → 0 + 0 = 0 尚可，但小 x 时首项线性项为负、弧长可能为负——与弧长的非负性矛盾。

## 结论倾向

(3.352b) 首项负号应为转写错误（或原书排印错误），正确形式为 +√(x(x+p/2)) + (p/2)·Arsinh√(2x/p)。需据原书核定。
