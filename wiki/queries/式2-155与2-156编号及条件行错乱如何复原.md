# 式 2.155–2.156 的编号与孤立条件行错乱如何复原？

## 现象

手册 2.8.5 节的转写文本中存在三处版式错乱：

1. 条件行「(x < 0, y < 0, x² + y² > 1)」先作为**孤立行**出现一次（紧随 $+\pi$ 分支之后、无所属公式），随后又随 $-\pi$ 分支重复出现一次。
2. 编号 (2.155c)、(2.156a)、(2.156b) 漂移到错误位置：(2.155c) 出现在孤立条件行之后，(2.156a)(2.156b) 出现在和公式与差公式之间。
3. 差公式「arcsin x − arcsin y =」的分支与和公式的分支在版面上交错。

## 复原方案（数学核验通过）

原书结构应为**两条公式、各三分支、六个编号**：

- 式 2.155（和）：基本段（$xy\leqslant0$ 或 $x^{2}+y^{2}\leqslant1$）→ (2.155a)；$+\pi$ 段（$x>0,y>0,x^{2}+y^{2}>1$）→ (2.155b)；$-\pi$ 段（$x<0,y<0,x^{2}+y^{2}>1$）→ (2.155c)。
- 式 2.156（差）：基本段（$xy\geqslant0$ 或 $x^{2}+y^{2}\leqslant1$）→ (2.156a)；$+\pi$ 段（$x>0,y<0,x^{2}+y^{2}>1$）→ (2.156b)；$-\pi$ 段（$x<0,y>0,x^{2}+y^{2}>1$）→ (2.156c)。

孤立的「(x < 0, y < 0, x² + y² > 1)」条件行应归入 2.155c（和公式的 −π 分支）。复原后的结构在 $x=\pm1$、$x=1/y=-1$ 等边界点核验通过，已按此登记于 [[arcsin与arccos的和差公式]]。

## 待办

对照原书纸质版核实 2.8.5 节的原始排版（六行三条公式各带编号），确认上述复原。
