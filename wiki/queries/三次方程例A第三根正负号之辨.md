# 三次方程例 A 第三根正负号之辨

## 疑点

20.3.2.2 例 A（x³+6x+2=0，参见手册第 52 页 1.6.2.3）的第三个根转写为：

```
{x -> -(1 - I√3)/2^(2/3) + -(1 + I√3)/2^(1/3)}
```

「+ −」并置疑衍一负号。

## 复算

前两根复算吻合：首根 2^(1/3)−2^(2/3) 经 Cardano 公式验证（u³ = 2、v³ = −4、r₁ = u+v ≈ −0.327480）；第二根 (1−I√3)/2^(1/3) − (1+I√3)/2^(2/3) ≈ 0.163741−2.465853i。第三根应为

**−(1−I√3)/2^(2/3) + (1+I√3)/2^(1/3)**（≈ 0.163741+2.465853i），

即去掉第二个「−」号。验证：修正后的三根之和为 0、三根之积为 −2（x³+6x+2 的 Vieta 关系），均吻合；而按书中转写形式求和 ≠ 0。

## 待辨

- 对原书影印件核对第三根的符号排印。
