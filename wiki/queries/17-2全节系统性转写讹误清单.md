# 17.2 全节系统性转写讹误清单

数学手册 17.2.1–17.2.2 的转写质量显著低于 17.1.x 各节，脱字、错字密集。本页汇总系统性讹误，供据原书校勘时逐项核对；单项已另立 query 者注明。**结论层面可靠，但文字须校勘后方可引用。**

## 系统性字符讹误

| 类型 | 讹误 | 拟改 / 例 |
|---|---|---|
| 字形 | 千 | 于（关千→关于、等千→等于、趋向千、由千、基千、支撑千、依赖千、对应千） |
| 字形 | 嫡 / 墒 | 熵（拓扑嫡、测度墒） |
| 字形 | 共辄 | 共轭 |
| 符号 | 入 | λ（「对入-几乎处处」「概率测度入/2π」） |
| 符号 | 厌 | ℝ（「看作厌或 上的偶函数」） |
| 字形 | 儿乎 | 几乎 |
| 符号 | Λ 误作 1 / A | 「设 1⊂M 为…吸引子」应为「设 Λ⊂M」；「支撑在 上」脱 Λ |
| 符号 | W 误作 w | 「吸引域为 w」应为 W |

## 脱字与衍字

- 脱字符：ε（「ρₙ 九距离不小千 的点」「随 的增加」）、N、τ、t、B、Λ 等多处（「落入集合 的所有时刻」「满足 Λ∩B=∅」等句中集合符号脱落）。
- (17.32a) 与伯克霍夫定理离散公式衍「d t」。
- (17.35a)「2 _0^{i n f t y}」→「$2\int_0^\infty$」。
- 密度变换公式脱导数撇号：|(h⁻¹)(y)| → |(h⁻¹)′(y)|。
- 「当 α = 时」脱「4」（[[queries/当α等于脱4之辨]]）。
- 混合⟹遍历证明「μ(A)=0 1」脱「或」（[[queries/混合蕴含遍历证明脱或字之辨]]）。
- 自然测度 t(T,A,x₀)「集合」疑为时间测度（[[queries/自然测度定义集合疑为时间测度之辨]]）。
- 旋转段两处回指「(17.3)」疑为「(17.31)」（同段开头对离散系统 (17.3) 的回指正确）。

## 页码与标题
