# 式 12.38b 首不等式右端 x₊+x₋ 是否应为 x₊+y₊

## 问题

源文 (12.38b) 首不等式转录为 (x+y)₊ ≤ x₊ + x₋——右端将 x 的正部与 x 的负部相加，而同式次项为 (x+y)₋ ≤ x₋ + y₋（同源配对）。首项右端是否应为 x₊ + y₊？

## 当前证据

[[findings/式12-38b首不等式疑误之反例判定]] 已给出判定：**应为 x₊ + y₊**——

- 按转录形式的显式反例：x = y = 1 时左端 2 > 右端 1，命题为假；
- 修正形式 (x+y)₊ ≤ x₊ + y₊ 有一般证明（x+y ≤ x₊+y₊ 且 0 ≤ x₊+y₊，取上确界）；
- 次项 (x+y)₋ ≤ x₋+y₋ 恰可由修正后的首项作用于 −x−y 导出，佐证配对结构应为「正部对正部、负部对负部」。

## 待决事项

1. 对照原书（或德文原版）确认系排印错误还是转写错误；
2. 若原书确作 x₊+x₋，则属原书数学错误，应在引用该式时统一采用修正形式并注明。
