# 「coth 严格单调故唯一反函数」的表述是否欠严？

## 问题

手册 2.10.1 总述称「函数 $\sinh x$、$\tanh x$ 和 $\coth x$ 均严格单调，因此没有任何限制地具有唯一反函数」。其中对 coth 的表述是否欠严？

## 证据

- **coth 跨间断点不单调**：coth 在 $\mathbb{R}\setminus\{0\}$ 上有间断点 $x = 0$；取 $x_1 = -1 < x_2 = 1$，有 $f(x_1) = \coth(-1) < 0 < f(x_2) = \coth(1)$，即 $x_1 < x_2$ 但 $f(x_1) < f(x_2)$ 不满足递减、也不满足整体递增意义上的「严格单调」表述（coth 在各分支上严格递减，但整体并非单调函数）。
- **手册自身的呈现与总述有张力**：表 2.8 与 2.10.1.4 实际按两个区间分支呈现 [[concepts/面积余切]]（$(-\infty,-1)$ 与 $(1,+\infty)$ 各一支），与「没有任何限制地具有唯一反函数」的措辞存在张力。

## 初步判断

**结论正确，论证欠严**：Arcoth 作为对应关系确实唯一（coth 是单射），但依据应为**单射性**（分段严格单调蕴含整体单射），而非整体的严格单调。属表述精度问题而非数学错误；是否需要更正措辞，待核对原书表述与体例后决定。
