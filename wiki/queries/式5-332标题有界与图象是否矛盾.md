# 式 5.332 标题「左侧和右侧有界」与函数图象是否矛盾？

**状态：待核**。

转写标题：**B: 对应于 (5.332) 的左侧和右侧有界的隶属函数（图 5.66）**，函数为

$$\mu_A(x)=\left\{\begin{array}{ll}1,& x\leqslant a_1\\[2pt]\dfrac{a_2-x}{a_2-a_1},& a_1<x<a_2\\[6pt]0,& a_2\leqslant x\leqslant a_3\\[2pt]\dfrac{x-a_3}{a_4-a_3},& a_3<x<a_4\\[6pt]1,& x\geqslant a_4\end{array}\right.\tag{5.332}$$

**矛盾（读图/复算）**：该函数在 $x\leqslant a_1$ 与 $x\geqslant a_4$ 两端取 1、中部 $[a_2,a_3]$ 取 0，隶属等级大于 0 的点集（支撑）向两侧无限延伸——**支撑无界**，与标题「有界」矛盾。从形状看它是「非中等」型的函数（wiki 推断：适合刻画「不高不低」一类语言值，非手册原文）。

**可能情形**：

1. 标题脱字或错位：或应为「左侧和右侧」（左肩/右肩形式）而无「有界」二字，或「有界」原是对函数中部（取 0 的有界区间）的描述；
2. 函数抄错：标题本意或是中部为 1、两端为 0 的有界支撑型（即式 5.331 的镜像/变形）。

需对照原书图 5.66 与文字。
