# 第9章全节系统性转写讹误清单

## 问题

第9章章级文件（章首定义＋目录）存在系统性转写讹误与脱落，逐字引用前须校改。汇总如下（讹文→拟校改）：

1. 定义 (1)：「等千其中出现的导数最高的阶数」→「等**于**其中出现的导数最高的阶数」（千/于讹替）。
2. 定义 (1)：「这些函数关千所出现的这些变最的导数」→「这些函数关**于**所出现的这些变**量**的导数」（千/于、最/量两组讹替）。
3. 定义 (2)：「相互间的差别在千」→「相互间的差别在**于**」（千/于讹替，第 3 处）。
4. 定义 (2) 句末脱句号「．」。
5. 例 A 之前脱「■」标记（例 B、C 皆有而 A 无）。
6. 例 B LaTeX 排印中 `x \mathrm { d } ^ { 2 } y \mathrm { d } x` 的乘积归属与括号范围含混，「二阶常微分方程」之判读目前仅为推断。

## 判定依据

- 第 1–3 条：讹替致文句语法不通且呈系统性（千/于凡 3 见），校改置信度高，复校详见 [[第9章章首定义形近讹替复校]]。
- 第 4–5 条：标点与标记脱落，不影响数学内容，但影响逐字转写之保真。
- 第 6 条：属排印结构含混而非字面讹误，须对原书核验后方可定谳。
