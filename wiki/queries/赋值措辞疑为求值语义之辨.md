# Do 与 While 之「赋值」措辞疑为「求值」语义之辨

**问题**：20.2.9 三处以「赋值」描述循环体的执行：「第一个命令给表达式 expr 赋值」「第二个命令给表达式赋值，只要 test 具有值 True」，以及概括句「Do 循环按照事先给定的次数对其自变量赋值，而 While 循环赋值直到事先给定的条件失效」。

**拟断**：Mathematica 中 `Do` 与 `While` 的语义是对 expr **重复求值**（repeated evaluation），而非「赋值」；「赋值」疑为德文原版 auswerten（求值）之中译残留，属措辞偏差而非事实错误。若按字面理解为 Set 赋值（[[concepts/Set指派与清除]]），将与本节算例相混淆——式 20.25 与式 20.27 的循环体确含 `sum = sum + ...` 赋值，但那是算例自身的写法，并非 `Do` 的语义。

**佐证**：两算例的循环体均形如 `sum = sum + ...`，可能诱发「Do 即赋值」的转写印象；然 `Do` 亦可执行不含任何赋值的纯表达式（此为语义说明之例，非本来源内容）。

**查证方向**：核对德文原版对应句的动词（auswerten 与 zuweisen 之别）；检查本手册其他章节对「求值」一词的译法是否一致。
