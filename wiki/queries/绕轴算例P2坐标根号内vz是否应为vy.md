# 绕轴算例中 P₂ 坐标根号内的 v_z 是否应为 v_y？

## 问题

3.5.4.5.2 绕任意空间轴旋转构造的第 (2) 步，源文称点 $P_2$ 具有坐标

$$(0,\ \sqrt{v_x^2 + v_z^2},\ v_z)\quad\text{（源文）}$$

按上下文，此处是否应为 $(0,\ \sqrt{v_x^2 + v_y^2},\ v_z) = (0,\ m,\ v_z)$，即根号内的 $v_z$ 为 $v_y$ 之转写讹误？

## 支持改动的证据（本 wiki 分析的独立推证）

1. 第 (2) 步的旋转是 $R_z(\alpha_z)$，其作用面为 $x, y$ 平面：以 $\cos\alpha_z = v_y/m$、$\sin\alpha_z = v_x/m$（$m = \sqrt{v_x^2+v_y^2}$）作用于 $\vec v = (v_x, v_y, v_z)$ 得 $(0,\ m,\ v_z)$——z 分量不参与，根号内出现 $v_z$ 与 $R_z$ 的作用机制矛盾。
2. 第 (3) 步 $P_3 = (0, 0, |\vec v|)$ 依赖第 (2) 步结果为 $(0, m, v_z)$：$R_x(\alpha_x)$ 以 $\cos\alpha_x = v_z/|\vec v|$、$\sin\alpha_x = m/|\vec v|$ 恰把 $(0, m, v_z)$ 映为 $(0, 0, |\vec v|)$；若 $P_2$ 的第二分量为 $\sqrt{v_x^2+v_z^2}$ 则后续全部失效。
3. 最终矩阵 $M_A$ 的第一行 $(v_y/m,\ -v_x/m,\ 0)$ 与第二行 $(v_x v_z/m,\ v_y v_z/m,\ -m)$ 中的 $m$ 均为 $\sqrt{v_x^2+v_y^2}$，与改读一致。
4. 同段 $\cos\alpha_z = v_y/\sqrt{v_x^2+v_y^2}$ 的分母已用 $v_y$，进一步印证根号内容。
