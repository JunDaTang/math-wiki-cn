# 式 (19.168b) 之内层循环 i 下界脱 k 之辨

**问题**：(19.168b) 内层循环写作「$i=n,n-1,\cdots$」后接逗号即断，脱落的下界是什么？

**状态**：open（倾向下界为 k，高置信）

## 原文（脱文）

```
(2) k = 1, 2, …, n 及 i = n, n−1, …, ，计算
    p_i = p_i + (x − x_i)/(x_i − x_{i−k}) · (p_i − p_{i−1})     (19.168b)
```

## 辨析

下界应为 k，即 $i=n,n-1,\dots,k$。依据：

1. **下标意义**：更新式分母含 $x_{i-k}$，要求 $i\ge k$；且源文同段明确第 k 列的元素为 $p_{i-k,i-k+1,\cdots,i}$（$i=k,k+1,\cdots,n$），i 的取值范围与之严格一致。
2. **就地覆盖安全**：分量 i 的更新用到 $p_{i-1}$ 在上一列（第 k−1 列）的旧值；若 i 自小到大递增，$p_{i-1}$ 会先被本列新值覆盖而丢失旧值；自 n 递减至 k 则安全。
3. **终止语义**：源称结束后 $p_n$ 为所求，即第 n 阶段（k=n）只更新分量 n（$i=n=k$），与下界 k 吻合。

## 判定倾向

复原为 $i=n,n-1,\cdots,k$（外层 $k=1,2,\cdots,n$）。置信度高；详细就地覆盖分析见 [[艾特肯－内维尔两步就地算法流程]]，待原书影印最终确认。
