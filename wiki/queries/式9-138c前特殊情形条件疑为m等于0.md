# 式 9.138c 前特殊情形条件 (l=0, m=n) 是否应为 m=0？

## 问题

9.138c 前文称：「作为一个特殊情形 (l = 0, m = n, cosϑ = x)，得到第 748 页的第一类勒让德多项式 (9.60c)」。该条件疑应为 **m = 0（l = n）**。

## 内部依据

- 相伴勒让德多项式 P_l^m 在 **m = 0** 时退化为第一类勒让德多项式 P_l（9.60c 的对象）；l = 0 只给出常数 P₀ = 1，无法得到整个多项式族。
- 9.138c 公式中令 m = 0 即化为 Pₗ 的 Rodrigues 公式；若按「l = 0, m = n」则 |m| ⩽ l（9.138a）被破坏。

合理推测原书为「(m = 0, l = n, cosϑ = x)」，其中 n 为 9.60c 的多项式指标。

## 待核对

对照纸质原书确认；高置信判其为误。
