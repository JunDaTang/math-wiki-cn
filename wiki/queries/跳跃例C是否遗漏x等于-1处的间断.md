# 跳跃例 C 是否遗漏 x = −1 处的间断？

## 问题

手册 2.1.5.3.2 例 C：$f(x)=\lim_{n\to\infty}\frac{1}{1+x^{2n}}$，给出 $f(1-0)=1$，$f(1+0)=0$，$f(1)=\frac12$，仅描述了 $x=1$ 处的跳跃。

## 证据与疑点

- $x^{2n}=(x^2)^n$ 只依赖 $|x|$：$|x|<1$ 时 $f=1$，$|x|>1$ 时 $f=0$，$|x|=1$ 时 $f=\frac12$。
- 故 $x=-1$ 处同样有跳跃：$f(-1)=\frac12$，左极限（$|x|>1$ 侧）为 $0$，右极限（$|x|<1$ 侧）为 $1$。
- 手册只描述 $x=1$，疑遗漏 $x=-1$，或原书本写作 $|x|=1$ 而转写时丢失对称点。

## 待办

对照原书核验例 C 是否列举 $x=\pm1$（或 $|x|=1$）。
