# 5.9.6 全节系统性转写讹误清单

延续 5.9.1–5.9.3 各节的转写讹误模式（见 [[5-9-1全节系统性转写讹误清单]]、[[5-9-2全节系统性转写讹误清单]]、[[5-9-3全节系统性转写讹误清单]]），本节（5.9.6）的系统性讹误如下，需对照原书核实：

| 原文 | 疑似正字 | 类型 |
|---|---|---|
| 用千 / 基千 / 垂直千 / 对千 / 限千 / 应千 | 用于 / 基于 / 垂直于 / 对于 / 限于 / 应于 | 「于」→「千」系统性 OCR 讹误 |
| 聚合模 / 决策模 | 聚合模块 / 决策模块 | 脱「块」 |
| 「模糊算法 对于每个法则 R^i 算出 μᵢ」 | 模糊化算法 | 疑「化」脱落 |
| 选个语言项 | 选七个语言项 | 脱「七」 |
| 正中 (pm) 和正(pl) | 和正大 (pl) | 脱「大」 |
| 控制址 | 控制量 | 「量」→「址」 |
| (图 5.80(£)) | (图 5.80(e))/(f) | 子图标号 OCR 损坏 |
| 儿乎为零 | 几乎为零 | 「几」→「儿」 |
| 限千 维情形 | 限于一维情形 | 「于」「一」双脱 |
| 在此不进行 Mamdani 方法的逆模糊化问题是要得到有效的权参数 p_j^i | 语序损坏（疑为「在此不进行 Mamdani 方法中的逆模糊化；问题是要得到有效的权参数…」） | 句子级损坏 |
| 在高 0.5 的切割 | （疑为「相邻模糊集在高度 0.5 处相交」） | 语义残缺 |
| 「对于第 个法则」「如果 是正小」「作用千摆的下端的力 」等 | 脱变量符号（i、Θ、Θ̇、F） | 公式符号丢失 |
| R₁ 的 α = min{μ⁽¹⁾(Θ), μ⁽¹⁾(Θ̇)} | 第二处疑为 μ⁽²⁾(Θ̇) | 上标讹误 |
| 「第 570 页 …5.9.3.2」「第 572 …5.9.4」 | 页码与既有序列（5.9.1→591、5.9.2→592、5.9.3→593、5.9.6→596）不符 | 页码 OCR 可疑 |
