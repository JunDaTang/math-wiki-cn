# 式 3.180 三边之和的上限是 180° 还是 360°？

## 问题

3.4.2.1(1) 的正文称「三边之和介于 0° 和 **180°** 之间」，但紧随其后的式 (3.180) 写作：

```
0° < a + b + c < 360°
```

正文与公式上限冲突，何者为原书本意？

## 证据

- 数学上正确者为 **360°**：欧拉三角形的周长（以球心角度量）小于 360° 是标准结论；
- 本节其余命题未见类似冲突；
- 正文「介于 0° 和 180° 之间」疑为「介于 0° 和 360° 之间」的转写讹误，也可能与 (4) 三角之和「介于 180° 和 540° 之间」的句式串扰。

## 待办

核对原书 3.4.2.1(1) 的正文数字。若确认原书为 360°，则本条纯属转写讹误，归入 [[queries/342节转写讹误与图3-34误引]] 的讹误清单；公式本身（< 360°）不受影响，[[findings/球面三角形一般命题组]] 已按 360° 收录并标注冲突。
