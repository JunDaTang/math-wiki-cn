# 式 (14.58a) 条件 a 非负与极点位置之辨

## 疑点

源文对例 1 的条件写为 (α > 0, a ⩾ 0)，结论 (14.58c) 亦标注同样条件：

$$\int_0^\infty \frac{x\sin\alpha x}{x^2+a^2}\,\mathrm{d}x = \frac{\pi}{2}e^{-\alpha a}\quad(\alpha>0,\ a\geqslant 0)$$

但推导要求一阶极点 z = ai 严格位于上半平面围道内部（源文亦要求 R > a），即 **a > 0**；a = 0 时极点落在实轴上，所述围道论证失效。

## 分析

- **a > 0**：推导成立，全链复算通过；
- **a = 0**：被积函数化为 x sinαx/x² = sinαx/x，恰为例 2 的 Dirichlet 积分型，需缩进围道另行处理（见 [[methodology/实轴极点缩进围道计算流程]]）；公式取 a→0 极限给出 π/2，与 (14.59) 一致（可视为交叉验证），但源文所述证明不覆盖 a = 0。

## 待决

原书（德文版）中条件究竟为 a > 0 还是 a ⩾ 0？若为后者，则原书意在把结论延拓到极限情形而不区分证明；若为前者，则 a ⩾ 0 系转写之误。需核对原书。
