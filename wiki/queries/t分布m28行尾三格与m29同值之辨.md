# t 表 m=28 行尾三格与 m=29 同值之辨

## 问题

21.20 节表中 $m=28$ 与 $m=29$ 整行六格全同；尾三列（单侧 $\alpha=0.01, 0.001, 0.0005$）在精确值下应各差 0.01，而表中 m=28 行尾三格（2.46 / 3.40 / 3.66）恰与 m=29 行相同。是否 m=28 行尾列整段抄自下行？

## 证据

- 与通行精确 t 分位数比对：m=28 应作 2.47 / 3.41 / 3.67，m=29 应作 2.46 / 3.40 / 3.66（见 [[findings/t分布m28行尾三格与m29同值复算]]）。
- 单调性佐证：精确分位数随 $m$ 严格递减，印表平台（m=18–20 三个 1.73、m=23–27 五个 1.71）各比正确舍入多一格。

## 待办

1. 以不完全 Beta 函数精算 m=28、m=29 全行六格，复核比对值（当前比对值来自标准表，属间接证据）。
2. 对勘原书第 21.20 节 m=28 行：若原书作 2.47 / 3.41 / 3.67 则为转写讹误；若同印 2.46 / 3.40 / 3.66 则为原书排版之误。
