# AKS 条件 r^i ≢ 1 (mod n) 是否应为 n^i ≢ 1 (mod r)？

**问题**：源文 AKS 命题与其后检验流程中两次出现条件「r^i ≢ 1 (mod n)（i = 1, 2, …, ⌊(log₂n)²⌋）」。该方向是否颠倒？

**证据**：

1. 按源文方向，条件的数论作用不明：AKS 证明所需要的是 **n 模 r 的阶**大于 log²n（从而限制 n 的素因子形状、控制批量同余的次数），而非 r 模 n 的性态。
2. 独立可验证的外部标准知识：Agrawal–Kayal–Saxena 2002 年原始 AKS 条件为 n^i ≢ 1 (mod r)（i = 1..⌊log²n⌋），即 n 模 r 的阶超过 log²n。
3. 源文同段的条件 (i)「n 不被 ≤ r 的素数整除」表述亦受损（标准条件为 r 与 n 互素类条件），提示本段整体转写质量低。

**初步结论**：疑为原书误排或转写颠倒，应为 n^i ≢ 1 (mod r)。在对照 2002 年原文之前，[[methodology/aks素性检验流程]] 与 [[findings/aks命题与检验流程]] 均标注为未定稿版本。
