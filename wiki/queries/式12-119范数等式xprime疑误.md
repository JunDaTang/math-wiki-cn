# 式 (12.119) 逼近定理范数等式 ‖x′‖ = ρ(x,H₀) 疑误

**问题**：逼近定理 g) 转录作「方程 ‖x′‖ = ρ(x, H₀) = inf_{y∈H₀}{‖x−y‖} 成立，从而问题 ‖x−y‖ → inf, y ∈ H₀ 在 H₀ 中有唯一解 x′」。

**判定（按字面为误）**：距 x 最近的元是投影 x′，但距离值为 **‖x − x′‖** 而非 ‖x′‖；两者一般不相等（如 x ∈ H₀ 时 ‖x′‖ = ‖x‖ > 0 而 ρ(x,H₀) = 0）。

**候选修正**：

1. ‖x − x′‖ = ρ(x,H₀)（转录脱去「x − 」）；
2. ‖x″‖ = ρ(x,H₀)，其中 x″ = x − x′ 为正交分量（双撇 ″ 误排作单撇 ′，与本节 x = x′+x″ 的记号一致）。

两种修正数学上均正确且等价。
