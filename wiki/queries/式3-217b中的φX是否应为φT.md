# 式 (3.217b) 切点经度公式中的 φ_X 是否应为 φ_T？

## 现象

小圆「切点」小节给出切点纬度 (3.217a) φ_T = arcsin(sin φ_M/cos r)，随后切点经度公式转写为：

```
λ_Tν = λ_M ∓ arccos[(cos r − sin φ_X sin φ_M)/(cos φ_X cos φ_M)]   (ν = 1, 2)
```

其中出现 φ_X，而该式与平行圆交点公式 (3.216) 字面相同（仅 λ_Tν 与 λ_Xν 之别）。

## 推断

切点处 (3.216) 中反余弦的自变量必须是关于 φ_X 的**极值**（= ±1），极值点纬度即 (3.217a) 的 φ_T。因此 (3.217b) 中应代入 φ_T（sin φ_T = sin φ_M/cos r 使自变量化为 ±1），否则 arccos 自变量不为 ±1，与「切点」矛盾。判定：φ_X 为 φ_T 的转写之误，(3.217b) 应为：

```
λ_Tν = λ_M ∓ arccos[(cos r − sin φ_T sin φ_M)/(cos φ_T cos φ_M)]
```

## 一致性证据

(3.217a) 与 (3.218) 的判别式零条件（A²+B² = C² ⟹ 相切于 φ_T）一致，经本 wiki 核验。
