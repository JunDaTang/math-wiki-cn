# 式 16.188 求和上限 n 疑为 N

**疑点**：式 (16.188) 作 v(x,y) ≈ (1/n)·Σ_{i=1}^{n} m_i·f(R_i)，求和上限写作 n。

**分析**：m_i 按边界点编号（i = 1,…,N，N 为边界点个数），n 为游动总次数（m_i ⩽ n）。由 (16.186)（v = Σ_{i=1}^N f(R_i)·p）与 (16.185)（p ≈ m_i/n）代入，应得 v ≈ (1/n)·Σ_{i=1}^{**N**} m_i·f(R_i)，求和上限应为 N 而非 n。另 (16.188) 前句用 m_j、后文用 m_i，记号不一致。

**核对方**：原书式 (16.188) 求和上限；见 [[findings/式16-180至16-188随机游动求解边值问题转录复算]]。
