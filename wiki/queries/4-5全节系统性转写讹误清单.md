# 4.5 全节系统性转写讹误清单

**问题**：4.5 节转写文本存在哪些系统性讹误？哪些已可据上下文复原，哪些必须查原书？

延续 4.1–4.3 节的同类转写质量问题，本节讹误可分五类：

## 1.「千/于」系统性混淆

不等千零、位千、依赖千、对千、等千、千是、适用千、基千——「千」均为「于」之讹，遍布全节。

## 2. 数字与符号成片脱落

- 「一个线性系含 个线性型」（m 脱落）；「实施 次步骤」（n 脱落，4.5.1.4）
- 「(r 1) 次」（应为 (r − 1) 次，4.5.2.4）
- 例 A「系数增广矩阵 (A, a) 的秩是 」、例 B「秩都等千 ．」（秩数脱落，复算支持均为 3，见 [[queries/例A例B脱落的秩数是否为3]]）
- 「大小为 (m,n) 的矩阵 的元素」（粗体 A 脱落）、「列向量 的分量」（向量符号脱落）等多处

## 3. 粗体向量与公式 OCR 乱码

- 竞/竺/生/旦/h_/~ 等替代粗体下划线向量记号；(A,g_) 应为 (A, a)；「A,h\_,\~ 是实的」应为「A, b, x 是实的」
- D=O 应为 D = 0（4.5.2.3）
- 「（乱码公式）斯变换」应为「高斯变换」（4.5.3.1 第 3 条）
- 「如果残差向量 的每个列正交，那么向量生是（4.189) 的解」应为「如果残差向量与 A 的每一列正交，那么向量 x 是 (4.189) 的解」
- 「楚列斯基金」疑为「楚列斯基分解/方法」之讹（第 1245 页标题）
- 式 (4.175) 后表的换轴行标签转写作 x_i，按算例应为 x_k

## 4. 实质性错误（影响语义，需查原书）

- 「将向量 a 作为第 n + 1 **行**添加到矩阵 A，就得到增广矩阵」：按 (A, a) 记法与式 (4.177b) 应为第 n + 1 **列**（[[queries/增广矩阵第n+1行是否应为第n+1列]]）
- 4.5.2.1 称 a 为「行向量」，与式 (4.177b) 的列向量定义矛盾
- 「如果矩阵 A 的秩为 n（因为 m > n，所以 A 的所有列是线性无关的）」：因果颠倒，应为「rank(A) = n 即列线性无关」（m > n 本身不保证列无关）
- 4.5.1.1 末段 a_μ 下标上限误作 n（应为 m）、相关变量误作 x_μ（应为 y_μ）（[[queries/4-5-1-1线性系定义段的下标讹误]]）

## 5. 表述不完整（可能为原书如此）

- 克拉默法则 D = 0 且所有 D_ν = 0 时「方程组可能有解但不唯一」：该情形也可能无解；源自我提示「参见第 417 页注」

**状态**：待据原书核对。第 1–3 类可据上下文复原（本 wiki 各页已按复原后的语义撰写并标注）；第 4–5 类需原书确认。
