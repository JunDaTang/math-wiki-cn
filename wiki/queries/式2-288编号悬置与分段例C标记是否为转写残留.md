# 式 2.288 编号悬置与分段例 C 的 Φ■ 标记是否为转写残留？

**问题**（两处轻微转写痕迹，次要）：

1. 2.18.5.1 波尔查诺零点定理的编号 "(2.288)" 悬置于定理文字（“若 $f(x_1,y_1) > 0$、$f(x_2,y_2) < 0$，则 $f(x_3,y_3) = 0$”）之后；原书或为独立公式行。
2. 2.18.2.4.2 分段例 C 之前转写为 "Φ ■ C:"，其中 "Φ" 疑为残留符号（该处应为与其他算例一致的 "■ C:" 标记）。

**待办**：对照原书版式确认；两处均不影响数学内容，订正后可与 [[findings/连通区域上连续函数的四大定理]]、[[findings/定义域的四类典型形态]] 保持一致。
