# 第一类多项式核化归阶数缺字是否为 n

11.4.2 的化归规则陈述为：“假设核中 x 的最高次是 n，则在关于 x 对积分方程求 n+1 次导数后，在第一类积分方程的情形即得到一个（？）阶微分方程，在第二类积分方程的情形即得到一个 n+1 阶微分方程”——**第一类的阶数处缺字**。

## 支持“n 阶”的证据

1. **算例结构**：算例 (I*) 的核 $2(x-y)^2+1$ 关于 x 为 2 次（n=2），n+1=3 次求导后得二阶 ODE (II*c) $\varphi''+4\varphi=6$——即第一类化为 n 阶（见 [[findings/式11-60a至11-60d微商法与两算例复算]]）。
2. **并列陈述的对称性**：同句中第二类明写 n+1 阶；两类相差一阶正对应第二类方程左端的 φ 本身（求导后 φ′ 项使阶数加一），故第一类为 n 阶在结构上自洽。

## 判定路径

需原书影印页核对缺字。当前判断：**基本可判定为 n**（证据 1 为直接算例证据），待最终确认。状态：**open（倾向 n）**。
