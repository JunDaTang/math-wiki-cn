# RSA 模幂推导应用欧拉-费马定理缺 gcd(N, m) = 1 条件

本源式 (5.276b) 的推导链：

```
R^s ≡ (N^r)^s ≡ N^{1+kφ(m)} ≡ N·(N^{φ(m)})^k ≡ N (mod m)
```

其中第三步直接引用 N^{φ(m)} ≡ 1 (mod m)。但 [[concepts/费马-欧拉定理]]（本源称欧拉-费马定理）的陈述带前提 **gcd(N, m) = 1**；原文（及算例）均未声明明文区组 N 满足此条件。

## 分析

- **算例无恙**：N = 8 与 m = 1073 = 29×37 互素，推导成立（已复算）。
- **推导缺口**：当 N 是 p 或 q 的倍数时，N^{φ(m)} ≡ 1 不真；不过对 m = pq 情形，D(E(N)) ≡ N (mod m) 对**所有** N 仍成立（可经中国剩余定理分别模 p、模 q 验证：N ≢ 0 时用费马小定理，N ≡ 0 时两边同时为 0）——所以是**推导有缺口而结论不假**。
- 待考：原书是否在别处（如区组构造「小于 100 个十进制数位」或消息编码规则处）暗含了 gcd 条件？

此为本源数学陈述的一个严谨性缺口，非转写讹误；[[entities/rsa方法]] 与 [[methodology/rsa加解密流程]] 均已标注。
