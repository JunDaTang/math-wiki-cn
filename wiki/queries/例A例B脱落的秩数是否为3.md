# 例 A 与例 B 脱落的秩数是否为 3？

**问题**：例 A「系数增广矩阵 (A, a) 的秩是 」与例 B「矩阵 A 和 (A, a) 的秩都等千 ．」中脱落的数字是否为 3？

**复算结果（支持为 3）**：

- 例 A：第 3 行系数 = 第 2 行 − 第 1 行，故 rank(A) = 2（与源文字一致）；常数列 8 ≠ 6 − 2 = 4，同一关系不满足，故 rank(A, a) = 3 → 脱落数字应为 **3**；
- 例 B：r = n = 3 且方程组相容，A 与 (A, a) 的秩均为 **3**；唯一解 (10/7, −1/7, −2/7) 回代四方程验证成立。
