# 式 (11.53) 解公式与双对角向前代入的关系

## 问题

11.3.5 的解公式 (11.53) 给出 c_j = f_j/ν_j（当 β_j ∉ (β_n^h)），但按 (11.52) 的双对角结构，无穷方程组的求解一般需要向前代入（递推）。原书 (11.53) 是否含有转写脱落的递推项，或原书是否明确限定于「非常简单」情形？

## 证据

1. **结构复算**：递推 (11.51a–c) 等价于 T*α_j = ν_jβ_j + μ_{j−1}β_{j−1}、Tβ_j = ν_jα_j + μ_jα_{j+1}，故 K_ij = ν_jδ_ij + μ_jδ_{i,j+1}（仅 i = j、i = j+1 非零）——与 (11.52) 一致，复算通过。
2. **向前代入**：按该结构，方程组第 j 行为 ν_jc_j + μ_jc_{j+1} = f_j 型（或等价地 μ_{j−1}c_{j−1} + ν_jc_j = f_j），需递推解出 c_j = (f_j − μ_{j−1}c_{j−1})/ν_j。
3. **不匹配**：转写 (11.53) 的 c_j = f_j/ν_j 缺少 μ_{j−1}c_{j−1} 项，仅在所有 μ_j ≡ 0 的「非常简单」情形（块内只含单个 ν_m）成立。
4. **残句线索**：(11.53) 之前有残句「无穷方程组的解有 f」，疑转写脱落文字（可能恰是递推项或限定语）。
5. **前提条件本身复算通过**：α_j ∈ (α_n^h) ⟹ f_j = 0（由 T*α_j = 0 与 f = Tφ 推出）。

## 待确认

- 原书 (11.53) 的完整形式（是否含 μ_{j−1}c_{j−1} 递推项）；
- 原书是否在「非常简单」情形（μ ≡ 0）的限定下陈述 (11.53)；
- 残句「无穷方程组的解有 f」的原文。
