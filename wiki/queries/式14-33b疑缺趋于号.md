# 式 (14.33b) 疑缺趋于号

14.2.1.1 中式 (14.33b) 之前的条件句转写为「如果当 Δz_i 0 以及 n→∞ 时……」，Δz_i 与 0 之间疑缺趋于号「→」，应为「当 Δz_i → 0」。

依 [[concepts/复定积分]] 的定义（分割无限加细、与选取无关的极限存在），此复原为高置信推断；该处属全节性行内符号丢失的一部分（见 [[queries/14-2全节系统性转写讹误清单]]）。建议对照原书图版确认后定稿。
