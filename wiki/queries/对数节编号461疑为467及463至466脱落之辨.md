# 对数节编号 461 疑为 467 及 463 至 466 脱落之辨

[[sources/10-数学手册原书第10版--13-2174-其他超越函数积分--17odu4w|数学手册 21.7.4]] 的指数节尾与对数节首之间编号倒退与跳缺并存（462 →「461」→ 468）：刊本编号 463–467 的实际归属为何？对数节的「461.」是否为「467」之 OCR 误读？

## 重建假说

| 位置 | 现状 | 推定原编号 |
|---|---|---|
| 21.7.4.2，$\int e^{ax}/x^n\,dx$（n≠1） | 脱号 | 452 |
| 21.7.4.2，$\int dx/(be^{ax}+ce^{-ax})$ | 脱号 | 456 |
| 21.7.4.2，$\int e^{ax}\sin^n x\,dx$（注「参见 447, 459」） | 脱号 | 461 |
| 21.7.4.2 末，$\int xe^{ax}\sin bx\,dx$ 与 $\int xe^{ax}\cos bx\,dx$（混入 462 显示块，「(参」截断） | 脱号 | 463、464 |
| 21.7.4.3 首，$\int\ln x\,dx$、$\int(\ln x)^2 dx$ | 脱号 | 465、466 |
| 21.7.4.3，「461. $\int(\ln x)^3 dx$」 | 编号讹 | 467（OCR 误读） |
| 21.7.4.3，$\int(\ln x)^n/x^m\,dx$（注「参见 474」） | 脱号 | 475 |
| 21.7.4.3，$\int\ln\tan x\,dx$ | 脱号 | 484 |
| 21.7.4.3 末，$\int e^{ax}\ln x\,dx$（与 458 逐字全同） | 脱号/重出 | 487（存疑，另见 [[queries/21-7-4末式与458重复之辨]]） |

## 主证：序列自洽性

若 463–467 依次为 $x\cdot e^{ax}$ 两式、$\int\ln x$、$\int\ln^2 x$、$\int\ln^3 x$（即「461」为「467」之 OCR 讹），则 468 起编号无缝衔接（468 → 469 → … → 486 → 末式 487），全节 90 个编号恰无缺口；反之，任何其他归属都会在 462 与 468 之间留下不可解释的编号倒退。同型旁证：21.7.4.4 的 488/489、497、501、508、511 与 21.7.4.5 的 514 亦为脱号，其推定编号同样由前后衔接唯一确定。

## 裁定路径

需刊本核对 463–467 各行编号及末式编号；若末式实为 487 且与 458 重复，则转入 [[queries/21-7-4末式与458重复之辨]] 的刊本重出一支。
