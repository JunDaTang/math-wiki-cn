# 八元数一词双义之疑（对偶四元数与 4.4.2 的八元数）

**待解问题**：《数学手册（原书第10版）》4.4.3.6 定义的「八元数」是 ĥ = h₀ + εh₁、ε² = 0 的代数——按结构这是标准的**对偶四元数**（dual quaternion）。而 4.4.2 的广义数层级（2ⁿ 维，式 4.105a–c）中的「八元数」若按通常理解是 **Cayley 型八元数**（7 个虚单位、非结合的交错代数）。原书（或中译）是否用同一术语指两个不同的代数？

## 证据

- 4.4.3.6（本源）：「一个八元数 ĥ 有形式 h₀ + εh₁…ε² = 0，与每个四元数交换」——8 维、ε 幂零、**结合**（继承四元数乘法）。可表示刚体运动、双重覆盖 [[entities/SE3]]。
- 4.4.2（见 [[concepts/八元数]]、[[findings/广义数2n层级与克利福德代数分类]]）：2ⁿ 层级中的 8 维成员，若为 Cayley 型则非结合、无 SE(3) 表示能力。

## 影响的页面

- [[concepts/八元数]]：需加术语消歧义段（关键）。
- [[queries/八元数能否描述刚体一般运动]]：本节给出本书的肯定答案（表 4.1、式 4.172–4.173），但答案的主语是**对偶四元数**——若该 query 原指 Cayley 八元数，则本书证词不能直接援引为肯定证据。
- [[queries/八元数是否属克利福德代数特殊情形]]：分析者推断（外部知识，非本书明言）：对偶四元数同构于偶克利福德代数 Cℓ⁺(3,0,1)（motor 代数）；Cayley 八元数则不属于克利福德代数。若 4.4.2 的「八元数」实为对偶四元数，该 query 的答案方向会改变。
- [[findings/四元数刻画旋转的优缺点与八元数补救主张]]：其「补救主张」的具体构造（4.4.3.6）已落地，但主语应改标为对偶四元数。

## 裁定所需

回查原书 4.4.2 的八元数定义原文（是否 Cayley 型：7 个虚单位、非结合），以及 4.4.3.6 的原文术语（对偶四元数 / Dualquaternion 之类）与中译处理；另见 [[queries/4-4-3-6标题规范化四元数与点变换作用式缺失]]（标题「规范化四元数」疑与「对偶」混淆）。
