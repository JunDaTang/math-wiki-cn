# 表 3.1 凸角行度栏缺上界、锐角行弧度栏出现度符号是否为误？

《数学手册(原书第10版)》3.1.1.2 表 3.1（角的名称）存在两处内部不自洽：

1. **凸角行**：度栏印作 $\alpha > 180^{\circ}$（无上界），而弧度栏印作 $\pi < \alpha < 2\pi$（有上界）。两栏应一一对应，度栏疑漏「$< 360^{\circ}$」；且表 3.1 声明适用于 $0^{\circ} \leqslant \alpha \leqslant 360^{\circ}$，凸角作为其中一类理应有上界。
2. **锐角行**：弧度栏印作 $0^{\circ} < \alpha < \pi/2$，弧度不等式中不应出现度符号，疑应为 $0 < \alpha < \pi/2$（同行度栏 $0^{\circ} < \alpha < 90^{\circ}$ 无误）。

## 影响评估

- 六类名称与区间的**实质内容**为标准几何知识，不受影响；疑点仅涉及表格转写或排版。
- 若为原版即如此（而非中文版或转写引入），则属原书的标注疏漏。
