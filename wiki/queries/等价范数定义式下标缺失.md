# 范数等价定义式中 ‖x‖ 是否缺下标 2

## 疑点

转录本将两个范数 ‖·‖₁ 与 ‖·‖₂ 的等价定义为：「存在两个数 γ₁ > 0, γ₂ > 0 使得 γ₁‖x‖ ≤ ‖x‖₁ ≤ γ₂‖x‖」。不等式两端的 ‖x‖ 均无下标，而等价关系应联系 ‖·‖₁ 与 ‖·‖₂ 两个范数。

## 证据

- 本小节前文刚以 X₁ = (X, ‖·‖₁)、X₂ = (X, ‖·‖₂) 定义了两个赋范空间，等价定义自然应为 γ₁‖x‖₂ ≤ ‖x‖₁ ≤ γ₂‖x‖₂。
- 标准理论：两范数等价 ⟺ 双向控制（各自强于对方）；转录式若按字面理解则 ‖x‖ 无定义（第三个范数？）。
- 与「强于」定义（‖x‖₂ ≤ γ‖x‖₁）对照，等价应是两个强弱关系的合取。

## 待办

对照原书 PDF 确认两处下标是否为 2。此项影响 [[concepts/赋范空间]] 中等价定义的准确转录。
