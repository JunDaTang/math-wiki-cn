# 12.4.3.2 例 B 勒让德组起始指标应为 n = 0

**问题**：例 B 称「规范化勒让德多项式组 (12.124)：P̃_n(t)（n = 1, 2, ⋯）在 L²((−1,1)) 中是完备的，因此是一个基」。

**判定**：起始指标应为 **n = 0, 1, 2, ⋯**。若从 n = 1 起，则 P₀ = 1（常数函数）不在组内，而常数函数与其余 P_n（n ⩾ 1，积分为零）正交，组不完备，与「是基」的断言矛盾。按 n 从 0 起理解后论断正确（多项式在 [−1,1] 上的稠密性为标准背景）。

**处置**：按 n = 0 起引用；[[concepts/第一类勒让德多项式]] 已注明。
