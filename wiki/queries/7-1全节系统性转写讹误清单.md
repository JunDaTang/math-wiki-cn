# 7.1 全节系统性转写讹误清单

7.1「数列」的转写文本存在哪些系统性讹误？如何在不动数学内容的前提下逐条复原？本 query 沿用 6.x 各节讹误清单的模式（如 [[queries/6-1-4全节系统性转写讹误清单]]、[[queries/6-2-1全节系统性转写讹误清单]]）集中登记，供原书核对时逐项销号。

## 讹误清单

### 1. 「于→千」形近讹误（近十处）

「对千任意小的 ε」「对千 n > n₀」「对千任意 K > 0」（→对于）；「收敛千 A = 0 / 3 / 3⅓」×4（→收敛于）；「趋千 +∞」（→趋于）；「等千最小上界 / 最大下界」×2（→等于）；「小千任意小的负数」（→小于）。

### 2. 行内数学单字母大量脱落

- 「在数列 中」两处（7.1.1.2 与 7.1.2，应为「在数列 A–J 中」/「在 7.1.1.1 的数列 中」——后者字母亦脱落）。
- 「数列 严格单调递减」→ 重构为 G。
- 有界例句链：「数列 K=4 为界」（→ C）、「数列 D 以 K= 为界」（K 值脱落）、「数列 K=3 为界」（→ E）、「数列 K= 为界」（→ F，字母与 K 值脱落）、「数列 = 为界」（→ G，字母与 K 连值全部脱落）、「数列 K=1 3 为界」（→ J，13 被空格断裂）。
- 收敛例句四处字母脱落（→ C、G、E、F）。
- 「数列 是假发散数列」（→ D/H/I/J，重构）。
- 「若这样的 不存在」（→ K）；「随着 的无限增加」两处（→ n）。
- I 条「aₙ = −(n+1)/2, 为奇数」缺 n；J 条「⋯ 为奇数」「⋯ 为偶数」前缺 n。
- 7.1.1.1 定义段「相同的数可多次出现若按一定的形式法则」句间标点脱落。

### 3. J 项列损坏

源文作「1, 11, 2, 12, 2 12 2 12 2 4 4'」。据奇、偶通项复算应为 1, 11, 2, 12, 2½, 12½, 2¾, 12¾, ⋯（带分数记法；E 条括注 2¾ = 11/4 佐证原书用带分数）。复原过程见 [[findings/数列A至J十例性质分类复算与脱漏字母重构]]。

### 4. 公式与符号讹误

- 式 7.11 假设中第二个 ⩽ 讹为「\~」（应为 aₙ ⩽ cₙ ⩽ bₙ）。
- 「K = 1 3」应为 K = 13。
- 定理 a) 与注中四处多余全角「｝」。

### 5. 标记与格式残片

- C 条双冒号「C: :」；E 条缺「■」标记（十例中唯一）；F 条项列以纯文本「an:」呈现（应为 aₙ:）；7.1.1.2 两条定义句后的多余「...」「·」残片。

## 开放子问题

1. 被脱漏字母的重构（G 严格递减；假发散 = D/H/I/J；有界 = C/D/E/F/G/J；收敛 = C/G/E/F）是否与原书一致？——重构为排除法推断，依据见 [[findings/数列A至J十例性质分类复算与脱漏字母重构]]。
2. D、F、G 的界 K 原值是多少？——见 [[queries/式7-4严格不等号与界K原值问题]]。
3. 原书 7.1 是否止于定理 4c)？柯西收敛准则、子列定理等是否在未转录部分？——见 [[queries/第7章后续小节未入库缺口]]。

## 模式一致性

上述五类讹误（形近字替换、行内字母脱落、公式损坏、数值空格断裂、标记残片）与 6.1.x、6.2.x 各节讹误清单所录模式一致，提示同一转写管线的系统性问题；跨节汇总或可估计脱落字母的分布规律（本节以大写拉丁字母 A–J、K 与指标 n 为主）。
