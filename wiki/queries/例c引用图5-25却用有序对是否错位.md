# 例 C 引用图 5.25 却用有序对是否错位？

**矛盾**：5.8.1 正文将图 5.25 标为无向图示例（「如果指派的是无序对，那么称为无向图（图 5.25）」）、图 5.26 标为有向图示例（「如果指派的是有序对，那么称为有向图（图 5.26）」）。但例 C 声称「对于图 5.25 中的图 G」却指派**有序对**（f₃(e₁″) = (v₂, v₃) 等），且指派内容与例 B（图 5.26 的有向图）**逐条完全相同**（仅边集记号 E″ 与关联函数记号 f₃ 不同）。逐字证据见 [[findings/图与关联函数定义及例ABC指派]]。

## 可能解释

1. 例 C 的图号引用错位（应为 5.26 或另一图），且内容误复制自例 B；
2. 图 5.25 与图 5.26 的图像或标注在原书/转写中互换；
3. 例 C 本欲以另一记号（E″/f₃）重述同一有向图，图号笔误。
