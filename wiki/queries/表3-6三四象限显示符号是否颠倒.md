# 表 3.6 三、四象限的计算器显示符号是否颠倒？

## 问题

表 3.6（「通过径直输入 arctan 的正确符号所得的方位角」）中「计算器中的显示」行的三、四象限符号是否因转写而颠倒？

## 证据（转写表逐字）与推理

| 象限 | I | II | III | IV |
|---|---|---|---|---|
| 计算器中的显示 | + | − | − | + |
| Δy/Δx | tan > 0 | tan < 0 | tan > 0 | tan < 0 |
| 方位角 t | t₀ gon | t₀ + 200 gon | t₀ + 200 gon | t₀ + 400 gon |

在测地左手系（x 朝上、y 朝右、象限顺时针编号，见 [[concepts/测地坐标]]）中：第三象限 $\Delta x < 0, \Delta y < 0$，比值 $> 0$，带符号 arctan 显示应为「+」，$t_0 + 200$ 才落入 200–300 gon；第四象限 $\Delta x > 0, \Delta y < 0$，比值 $< 0$，显示应为「−」，$t_0 + 400$ 才落入 300–400 gon。

表中「Δy/Δx」与「方位角 t」两行均与上述推理自洽，唯独「显示」行的 III、IV 写作「−」「+」，恰与 II、I 相同——疑为转写时三、四两列的符号被错位复制。

## 疑似正确形式

显示行应为 I:+、II:−、III:+、IV:−。

## 核实途径

对照原书表 3.6；若原书如此，则需考虑该书对「显示」的另一种定义（如显示的是 $|t_0|$ 与象限标记的组合），目前无证据支持。见 [[findings/方位角象限判定与反方位角]]。
