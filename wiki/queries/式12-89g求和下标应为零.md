# 式 (12.89g) 求和下标是否应为 ℓ = 0

## 疑点

转录本式 (12.89g)：𝒞^{(k)}([a,b]) 的范数为 ‖x‖ = Σ_{ℓ=1}^{k} max_{t∈[a,b]}|x^{(ℓ)}(t)|，但同句随后解释「这里 x^{(0)}(t) 表示 x(t)」。

## 证据（编者复算）

- 若求和确从 ℓ = 1 开始，则解释 x^{(0)} = x 毫无必要——这是下标应为 0 的直接文本证据。
- 更强证据：从 ℓ = 1 开始将违反公理 N1——任何非零常值函数 x(t) ≡ c 满足 x^{(ℓ)} ≡ 0（ℓ ≥ 1），得 ‖x‖ = 0 而 x ≠ 0，‖·‖ 不是范数。
- 标准理论中 𝒞^{(k)} 的范数为 Σ_{ℓ=0}^{k} max|x^{(ℓ)}(t)|（含函数本身的 sup 项）。
