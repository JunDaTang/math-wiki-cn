# 式 3.111 系列的下标与 Δy_BA 符号是否错乱？

## 问题

交会法不可见变体（经参考方向 D、E）的公式链 (3.111a–j) 存在四处下标/符号疑点，是否为转写讹误？

## 逐项证据与推理

1. **(3.111b)**：$\tan t_{BE} = \Delta y_{EB}/\Delta x_{EB}$——按方位角记号通例（$t_{BE}$ 配 $\Delta y_{BE} = y_E - y_B$，见 3.105c 及本节各式），下标疑应为 **BE** 而非 EB。
2. **(3.111g–h)**：$\tan t_{AN} = \Delta y_{NA}/\Delta x_{NA}$、$\tan t_{BN} = \Delta y_{NB}/\Delta x_{NB}$——N 是待求点，其坐标差未知，以之「计算」$t_{AN}, t_{BN}$ 属角色错位；此两式或是冗余/检验式，或下标有误（疑应为 AN、BN 方向的已知参考式）。
3. **(3.111i)**：$x_N = \frac{\Delta y_{BA} + x_A\tan t_{AN} - x_B\tan t_{BN}}{\tan t_{AN} - \tan t_{BN}}$——由两直线 $y = y_A + (x - x_A)\tan t_{AN}$ 与 $y = y_B + (x - x_B)\tan t_{BN}$ 联立，正确分子应为 $\Delta y_{AB} = y_B - y_A$；转写的 $\Delta y_{BA} = y_A - y_B$ **符号相反**。
4. **(3.111j)**：$y_N = y_B + (x_N - x_B)\tan t_{BN}$ 与上述联立解自洽，未见疑点。

## 疑似正确形式

(3.111b) 用 $\Delta y_{BE}/\Delta x_{BE}$；(3.111i) 分子首项用 $\Delta y_{AB}$；(3.111g–h) 的角色待原书澄清（可能整行属「检核」而非「解」步骤）。
