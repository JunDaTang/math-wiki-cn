# 定义句符号（r、α、R、r）与未定义的 m、b 是否为转写缺失？

## 问题描述

[[sources/10-数学手册原书第10版--11-316-圆和有关的图形--yloqob]] 的定义句与公式之间存在成串的符号缺失：定义句中变量符号丢失，另有两个变量 m、b 在全节正文中从未定义即被使用。

## 证据

1. 3.1.6.2 定义句作「定义量 半径＿和圆心角＿（图 3.29）」——两处符号缺失，据公式组应为 r 与 α。
2. 3.1.6.3 定义句作「圆环的定义量 外环半径＿、内环半径＿和圆心角 φ（图 3.30）」——据式 3.77–3.82 应为 R 与 r。
3. **m**（式 3.58–3.60）：三条幂定理公共值 r² − m² / m² − r² 中的 m 全节未定义；据构型与符号结构推断为「交点（内点或外点）到圆心的距离」。
4. **b**（式 3.74b、3.76）：近似式 l ≈ (8b − a)/3 与 S ≈ (h/15)(6a + 8b) 中的 b 全节未定义；据数值验证推断为「半弧的弦」。
5. 同型既往案例：3.1.3 轴对称与截距定理段的 S、g 缺失（[[queries/轴对称与截距定理段符号S与g是否缺失]]），表明这是全书转写的系统性模式。

## 核验途径

- 本节六幅图像文件齐备：图 3.26、3.27（弦/割线构型）很可能直接标注 m；图 3.29（弓形）很可能标注 b。查图可一举定案。
- 亦可对照原书或外部文献（Huygens 弧长近似式中 b 的标准含义）。
