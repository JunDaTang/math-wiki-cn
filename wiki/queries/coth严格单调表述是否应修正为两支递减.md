# 「coth 严格单调」的表述是否应修正？

**问题**：手册 2.10.1 称「函数 sinh x、tanh x 和 coth x 均严格单调，因此没有任何限制地具有唯一反函数」。但 [[concepts/双曲余切函数]] 在整个定义域 ℝ\{0} 上并非单调：两支各自严格递减，而跨 0 比较时方向反转（如 −1 < 1 而 coth(−1) ≈ −1.31 < coth(1) ≈ 1.31，与递减方向相反），故整体既非递增也非递减。

**分析**：表述与结论之间有缝隙，但结论仍成立：coth 在 (−∞, 0) 与 (0, +∞) 两支上分别严格递减，且两支值域 (−∞, −1) 与 (1, +∞) 不相交，故 coth 仍是单射，唯一反函数（[[concepts/面积余切函数]]，分两支）存在。严谨表述应为「两支分别严格递减、值域不交故为单射」。

**状态**：开放。属表述严谨性问题而非数学错误。
