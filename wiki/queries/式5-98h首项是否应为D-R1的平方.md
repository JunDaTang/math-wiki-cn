# 式 (5.98h) 首项是否应为 D(R₁)·D(R₁)？

**问题**：转写本式 (5.98h) 为「D(R₂) = D(R₁R₂) = D(R₁)D(R₂)，D(R₁)D(R₂) = D(e)」。若首句成立，两边消去 D(R₂) 将得 D(R₁) = D(e) 即 R₁ = e，与 C_3 的定义矛盾。首项是否应为 D(R₁²) = D(R₁)·D(R₁)？

**证据**：

- (5.98d) 给出群关系 R₂ = R₁²、R₁·R₂ = R₁³ = e；按同态性，表示矩阵应满足同样的关系。
- 本 wiki 复算（[[findings/c3二维旋转表示算例]]）：D(R₁)·D(R₁) = D(R₂) ✓；D(R₁)·D(R₂) = D(e) = I ✓。
- 第二句「D(R₁)D(R₂) = D(e)」与矩阵复算一致，无需改动。

**倾向复原**：D(R₂) = D(R₁²) = D(R₁)·D(R₁)，D(R₁)·D(R₂) = D(e)。待原书影印本确认。
