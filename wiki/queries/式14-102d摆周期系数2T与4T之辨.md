# 式 (14.102d) 摆周期系数 2T 与 4T 之辨

## 待裁决问题

源文 (14.102d) 及其前后文同时给出四个断言：

1. T = √(l/g)·F(k, π/2) = √(l/g)·K；
2. ϑ(t) 是周期为 2T 的周期函数；
3. T 表示摆的周期，即两个相继极端位置（dϑ/dt = 0）之间的时间；
4. 振幅小时（sin ϑ ≈ ϑ）T = 2π√(l/g)。

四者能否同真？若不能，原文的正确形式是什么？

## 已确立的数学事实（k→0 极限复算，直接证据）

k→0 时 K→π/2；且由 (14.102c)，从最低位置到极端位置历时 √(l/g)K。故：

- 全程周期 = 4√(l/g)K → 2π√(l/g)（与小振幅谐振周期一致）；
- 两相继极端位置之间的时间 = 2√(l/g)K（半周期）。

以 T = √(l/g)K 衡量：断言 2 的“周期 2T”实为半周期；断言 3 的“T”差一倍；断言 4 的“T”差四倍。

## 候选修正（推断）

- 修正 A：保留 T = √(l/g)K，改“周期为 2T”为“周期为 4T”；断言 3、4 中的时间量分别应为 2T 与 4T（或断言 4 的“T”实指全程周期）。
- 修正 B：(14.102d) 本式应为 T = 2√(l/g)K（缺系数 2），则“周期 2T”与“T = 两极端间隔”均成立，断言 4 应为 2T = 2π√(l/g)。
