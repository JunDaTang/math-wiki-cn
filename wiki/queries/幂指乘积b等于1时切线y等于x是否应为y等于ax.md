# 幂指乘积 b = 1 时切线 y = x 是否应为 y = ax？

手册 2.6.6 称：$y = ax^{b}\mathrm{e}^{cx}$ 在 b > 0 时过原点，且「当 b = 1 时，原点处的切线为 y = x」。

## 疑点

b = 1 时 $y = ax\,\mathrm{e}^{cx}$，$y' = a\,\mathrm{e}^{cx}(1 + cx)$，故 $y'(0) = a$。原点处切线为

$$
y = ax,
$$

仅当 a = 1 时才退化为 y = x。手册通篇按 a > 0 的一般参数讨论（并明言 a < 0 时沿 x 轴反射），故「y = x」疑漏系数 a。相邻两档（b > 1 切线为 x 轴、0 < b < 1 切线为 y 轴）经复核均正确。

## 待决

对照原书原版（或勘误表）确认是转写漏字还是原版即如此；若为后者，应在 [[幂函数与指数函数的乘积]] 页登记勘误。证据见 [[幂指乘积函数的切线渐近线极值与拐点]]。
