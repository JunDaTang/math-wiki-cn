# 式 3.290c 第三象限极角分支是否应为 arctan 减 pi

## 问题

式 (3.290c) 规定 x < 0 时 φ = arctan(y/x) + π。但当 x < 0 **且 y < 0**（第三象限）时，arctan(y/x) ∈ (0, π/2)，故 φ = arctan(y/x) + π ∈ (π, 3π/2)——这违反了 (3.290a) 明确声明的区间约定 −π < φ ≤ π。

## 分析

标准 atan2 在第三象限应取 arctan(y/x) − π ∈ (−π, −π/2)。因此存在两种可能：

1. **转写漏分支**：原书 (3.290c) 可能把 x<0 的情形按 y 的符号分成两支（y≥0 取 +π、y<0 取 −π），转写时丢失了一支；
2. **原书笔误**：原书本身就把 x<0 情形统一写成 +π（则与 (3.290a) 的区间声明自相矛盾）。

## 待裁定事项

需据原书核定 (3.290c) 的分支结构；在核定前，使用该公式时应按 −π < φ ≤ π 的区间约定对第三象限自行修正为 arctan(y/x) − π。
