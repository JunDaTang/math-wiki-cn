# 购买问题与背包问题建模比较

两者是《数学手册(原书第10版)》18.3.2 给出的两个离散决策模型、18.3.6 的两个数值算例，构成同一方法（[[concepts/贝尔曼泛函方程方法]]）下的对照样本。

| 维度 | 购买问题（18.3.2.1 / 18.3.6.1） | 背包问题（18.3.2.2 / 18.3.6.2） |
|---|---|---|
| 优化方向 | 极小化总费用（min） | 极大化总价值（max） |
| 语义来源 | 库存—采购（费用型） | 项目选取（价值型） |
| 状态含义 | 库存水平（可增可减） | 剩余容量（只减不增） |
| 状态变换 | $x_j=x_{j-1}+u_j-v_j$ | $x_j=x_{j-1}-w_j u_j$ |
| 决策变量 | 购买量 $u_j$（连续；算例限整数值搜索） | $u_j\in\{0,1\}$ |
| 驱动数据 | 需求 $v_j$、单价 $c_j$、容量 $K$、（储存费 $\ell$） | 权重 $w_j$、价值 $c_j$、上限 $W$ |
| 决策空间 | $[\max\{0,v_j-x_{j-1}\},\ K-x_{j-1}]$ | $\{0,1\}$（$x_{j-1}\geqslant w_j$ 时）或 $\{0\}$ |
| 泛函方程 | $\varphi_j=\min_{u_j}(c_j u_j+\varphi_{j+1}(x_{j-1}+u_j-v_j))$（原文 18.144 误印 max） | $\varphi_j=\max_{u_j}(c_j u_j+\varphi_{j+1}(x_{j-1}-w_j u_j))$ |
| 时间性 | 天然多周期过程 | 本与时间无关，重新表述为逐级决策 |
| 推荐前向方式 | 方式 2 | 方式 1 |
| 算例结论 | $\varphi_1(2)=75$，$(4,10,1,6,0,3)$ | $\varphi_1(10)=19$，$(0,1,1,1,0,1)$ |

## 要点

- 两模型的 min/max 语义不可混淆：式 (18.129a)（背包印 min）与式 (18.144)（购买印 max）两处讹误正是这种语义错位的体现（[[queries/式18-129a疑为max之辨]]、[[queries/式18-144疑为min之辨]]）。
- 背包问题展示了「静态组合问题 → 动态规划重述」的建模路径：把项目编号当作级、剩余容量当作状态。
- 复算状态不同：购买算例按原文数据完全可复现（[[findings/购买问题算例六行φ值表复算]]）；背包算例须条件于 $c$/$w$ 数据行互换（[[findings/背包问题算例表复算]]）。
