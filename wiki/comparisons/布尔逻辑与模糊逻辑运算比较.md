# 布尔逻辑与模糊逻辑运算比较

《数学手册(原书第10版)》表 5.9（源文标题脱落「表」字）对照两类逻辑的三种基本算子，是连接 5.7 节布尔代数材料与 5.9 节模糊集材料的枢纽：

| 算子 | 布尔逻辑 | 模糊逻辑（μ_A, μ_B ∈ [0,1]） |
|---|---|---|
| AND | C = A ∧ B | μ_{A∩B} = min{μ_A, μ_B} |
| OR | C = A ∨ B | μ_{A∪B} = max{μ_A, μ_B} |
| NOT | C = ¬A | μ_{A^C} = 1 − μ_A（μ_{A^C} 是 μ_A 的补） |

## 解读

- 布尔侧的 AND/OR/NOT 即 5.7 节 [[concepts/布尔代数]]、[[concepts/布尔函数]] 在 [[entities/二元布尔代数b]]（B = {0,1}）上的运算；
- 模糊侧把真值域放宽为 [0,1]，以 [[entities/扎德]] 算子（min/max，见 [[concepts/t-范数]]、[[concepts/s-范数]]）与缺省补 1−x（见 [[concepts/模糊补]]）为对应物；
- 更一般地，AND 侧可取任意 t 范数、OR 侧任意 s 范数（表 5.8 十二对族）、NOT 侧任意满足 EK1–EK4 的补函数；介于两侧之间的情形由 [[concepts/补偿算子]] 填补；
- min↔max、代数积↔代数和的对偶配对与 [[concepts/德摩根法则]]、[[concepts/对偶原理]] 的结构相呼应（维基注记）。
