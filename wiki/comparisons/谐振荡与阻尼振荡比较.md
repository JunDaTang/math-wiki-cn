# 谐振荡与阻尼振荡比较

依据手册 2.7.3（式 2.136–2.138 与式 2.139）比较两种振动描述。

| 方面 | 谐振荡（式 2.136） | 阻尼振荡（式 2.139） |
|---|---|---|
| 表达式 | $u(t)=A\sin(\omega t+\varphi)$ | $u(t)=A\mathrm{e}^{-at}\sin(\omega t+\varphi_0)$，$a,t>0$ |
| 包络 | 常数 $\pm A$ | 指数 $\pm A\mathrm{e}^{-at}$（[[concepts/指数函数]]） |
| 周期性 | 严格周期，$T=2\pi/\omega$ | 非周期；零点与极值仍等间距排布 |
| 零点 | $t=(k\pi-\varphi)/\omega$ | $C_k=((k\pi-\varphi_0)/\omega,\ 0)$——与同相位谐振荡完全相同 |
| 极值 | $t=((k+\tfrac12)\pi-\varphi)/\omega$，幅值恒为 $\lvert A\rvert$ | $t=(k\pi-\varphi_0+\alpha)/\omega$（$\tan\alpha=\omega/a$），幅值按 $\mathrm{e}^{-a\pi/\omega}$ 逐级衰减 |
| 拐点 | 与零点重合 | $t=(k\pi-\varphi_0+2\alpha)/\omega$，相对零点偏移 $2\alpha/\omega$ |
| 叠加性 | 同频叠加仍同频谐振荡（式 2.138a–c） | 手册未给阻尼振荡的叠加定理 |
| 几何工具 | 向量图（图 2.41，旋转时间轴） | 包络曲线（图 2.42） |
| 特征参量 | 振幅、角频率（口径见 [[queries/omega是频率还是角频率]]）、初相位 | 另有衰减常数 a、辅助角 α、对数衰减率 $\delta=a\pi/\omega$ |

## 结构观察

- 阻尼因子 $\mathrm{e}^{-at}$ 不移动零点，只压缩幅值：两者的零点公式形式完全一致（φ 与 φ₀ 之别仅为记法）。
- 谐振荡的拐点与零点重合；阻尼振荡中两者分离，偏移量 $2\alpha/\omega$ 由 $\tan\alpha=\omega/a$ 决定——衰减越快（a 越大），α 越小，拐点越贴近零点。
- 对数衰减率 $\delta=a\pi/\omega$ 只依赖 a 与 ω 之比，与振幅、初相位无关，因此可用相继极值的实测比测衰减。
