# 圆盘与球的格林函数比较

手册给出的两个可显式构造格林函数的情形（式 9.101 / 9.102）的平行对照：

| 维度 | 圆盘（式 9.101） | 球（式 9.102） |
|---|---|---|
| 维数 | 2 | 3 |
| 奇性部分（条件 (2)） | U ln(1/r) + V（对数型） | U/r + V（牛顿型） |
| 镜像关系 | OM · OM₁ = R²（同一射线上的对称点） | OM · OM₁ = R²，M₁ = (Rξ/ρ, Rη/ρ, Rζ/ρ) |
| 格林函数 | G = ln(1/r) + ln(r₁ρ/R) | G = 1/r − R/(r₁ρ) |
| 泊松积分 | (1/2π)∫₀^{2π} (R²−ρ²)/(R²+ρ²−2Rρcos(ψ−φ)) u(φ) dφ | (1/4π)∬_S (R²−ρ²)/(Rr³) u ds |
| 边界度量 | dφ（圆心角） | ds（球面面元） |

共同点：均由 [[格林函数镜像点构造流程]] 生成；边界归零均由镜像关系（相似三角形）保证；产出的 [[泊松积分]] 均经复算与标准泊松核一致（见 [[findings/式9-101至9-102圆盘与球格林函数复算]]）。

差异的本质是二维与三维拉普拉斯方程基本解的维数差异（ln(1/r) 对 1/r），这也是奇性部分条件 (9.99c) 与 (9.100c) 的分别。勘误：球例 ρ 公式的 η² 脱落（ζ² 重复），引用时须改正。
