# 多值函数与其主值表示比较

源文（14.5.2）以“大写多值 / 小写主值”的记法成对给出三类函数，比较如下：

| 函数族 | 多值表示（式号） | 主值表示（式号） | 多值性来源 |
|---|---|---|---|
| 自然对数 | $Ln z = \ln\rho + \mathrm{i}(\varphi + 2k\pi)$（14.74b） | $\ln z = \ln\rho + \mathrm{i}\varphi$，$-\pi < \varphi \leqslant \pi$（14.74d） | $e^z$ 的周期 $2\pi\mathrm{i}$ |
| 一般指数函数 | $a^z = e^{z\,Ln a}$（14.75a） | $a^z = e^{z\,\ln a}$（14.75b） | $Ln a$ 多值 |
| 反正弦/反双曲正弦 | $Arcsin z$（14.83a）；$Arsinh z$（14.83b） | $\arcsin z$（14.87a）；$\operatorname{arsinh} z$（14.87b） | $Ln$ 多值 + 平方根双值 |
| 反余弦/反双曲余弦 | $Arccos z$（14.84a）；$Arcosh z$（14.84b） | $\arccos z$（14.88a）；$\operatorname{arcosh} z$（14.88b） | 同上 |
| 反正切/反双曲正切 | $Arctan z = \frac{1}{2\mathrm{i}}Ln\frac{1+\mathrm{i}z}{1-\mathrm{i}z}$（14.85a）；$Artanh z = \frac{1}{2}Ln\frac{1+z}{1-z}$（14.85b） | $\arctan z$（14.89a）；$\operatorname{artanh} z$（14.89b） | $Ln$ 多值 |
| 反余切/反双曲余切 | $Arccot z = -\frac{1}{2\mathrm{i}}Ln\frac{\mathrm{i}z+1}{\mathrm{i}z-1}$（14.86a）；$Arcoth z = \frac{1}{2}Ln\frac{z+1}{z-1}$（14.86b） | $\operatorname{arccot} z$（14.90a）；$\operatorname{arcoth} z$（14.90b） | $Ln$ 多值 |

（反函数族的具体对数表达式见 [[concepts/反三角函数与反双曲函数]]。）

## 共同结构

1. 主值式与多值式**形式完全相同**，唯一的操作是把 $Ln$ 降级为 $\ln$（辐角限于 $-\pi < \varphi \leqslant \pi$）。
2. 多值性沿“指数周期性 → 对数多值 → 指数/反函数多值”链条传播（见 [[methodology/多值函数主值化流程]]）。
3. 定义域注意：$Ln z$ 在 $z = 0$ 无定义（源文主张）；$a^z$ 要求 $a \neq 0$。

## 转写不一致

(14.74c)、(14.83a)、(14.84a) 在多值语境使用小写 $\ln$，破坏上述成对结构（见 [[queries/式14-83a与14-84a多值式ln疑为Ln]]）。
