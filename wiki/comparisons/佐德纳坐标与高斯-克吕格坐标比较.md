# 佐德纳坐标与高斯—克吕格坐标比较

两者都是大范围测量中把弯曲地球表面映射到平面直角坐标系的坐标系（原文明言「在大范围测量中直角佐德纳 (Soldner) 坐标和高斯—克吕格坐标是重要的」），但保持的几何量与畸变控制策略不同：

| 维度 | [[佐德纳坐标]]（等距系） | [[高斯-克吕格坐标]]（保角系） |
|---|---|---|
| 映射性质 | 纵坐标方向保持距离 | 保角（保形） |
| 构造 | x 轴置于一条子午线（中央子午线）上，原点为测量好的中央点 | 先划分子午线带；每带原点位于中央子午线与赤道的交点 |
| 德国中央子午线 | 按测区选定 | 东经 6°、9°、12°、15° |
| 横坐标伸长系数 | a = Δx/Δx′ = 1 + y²/(2R²)（式 3.176） | 与佐德纳系相同（原文明言共享式 3.176） |
| 纵坐标校正 | 无 | b = y³/(6R²)（式 3.177），以保持保角映射 |
| 横向适用范围 | 中央子午线两侧不超过 64 km | 每带两侧 1°40′（德国约 ±100 km），带间重叠 20′（约 20 km） |

**共性**：横坐标方向的伸长畸变同由式 3.176 刻画（见 [[伸长系数]]）；两者都通过限制横向带宽来控制拉伸。

**差异本质**：佐德纳系以纵坐标方向保距为目标（局部系统、单中央点原点）；高斯—克吕格系以保角性为目标，须以纵坐标校正 b 为代价（分带国家系统）。
