# 六种弧序列比较

5.8.6 第 1 小节在弧序列 $F=(e_1,\cdots,e_s)$ 上定义的六类对象对照。「现代对应」列为分析者依通行图论文献（trail／path／cycle）所作的标注，非原文内容。

| 种类 | 弧不重复 | 顶点限制 | 方向衔接 | 闭合 | 现代对应 |
|---|---|---|---|---|---|
| [[concepts/链\|链]] | ✓ | 无 | 不要求 | 否 | trail（迹） |
| [[concepts/有向链\|有向链]] | ✓ | 无 | ✓ | 否 | directed trail（有向迹） |
| [[concepts/基本链与基本有向链\|基本链]] | ✓ | 每顶点至多一次 | 不要求 | 否 | path（路） |
| [[concepts/基本链与基本有向链\|基本有向链]] | ✓ | 每顶点至多一次 | ✓ | 否 | directed path（有向路） |
| [[concepts/圈\|圈]] | ✓ | 无（顶点可重复） | 不要求 | ✓ | closed trail（闭迹） |
| [[concepts/环道\|环道]] | ✓ | 每顶点恰为两条弧的端点 | ✓ | ✓ | directed circuit（有向圈） |

## 读法

- 「方向衔接」指 $e_i$ 的终点与 $e_{i+1}$ 的始点重合；链允许弧沿任一方向衔接。
- 环道的「每个顶点恰是两条弧的端点」排除闭合有向链中途折返、重复经过顶点的情形，保证其为简单的有向圈。
- 手册命名与现代中文文献的常见惯例（「链／通路／路」用法各异）不完全一致，引用本手册结论时应以本表定义为准。
