# 奇异积分方程与弗雷德霍姆积分方程可解性比较

比较对象：第 11 章的弗雷德霍姆积分方程理论（11.2.1–11.2.3、11.3 各源页）与 11.5.2 的柯西核奇异积分方程理论（[[sources/10-数学手册原书第10版--10-115-奇异积分方程--l25w62]]）。

| 维度 | 弗雷德霍姆积分方程（第二类，11.2.3） | 柯西核奇异积分方程（完全方程 11.74a） |
|---|---|---|
| 核与积分 | 连续（或有界）核，通常意义积分 | 强奇异核 $\frac{1}{y-x}$（柯西主值）＋弱奇异项 |
| 正则性框架 | 连续函数 / $L^2$（[[concepts/L2空间与平方可积函数]]） | 赫尔德连续类（指数 $\beta_1$，核指数 $\beta_2>\beta_1$） |
| 参数结构 | 第二类方程带谱参数 $\lambda$ | 系数 $a,b$ 无谱参数；正规性条件 $a^2-b^2\neq0$ |
| 可解性判据 | 弗雷德霍姆定理：非齐次唯一可解 ⟺ 齐次只有零解；否则正交条件 | (11.75a,b)：与齐次转置方程全部解正交（陈述无证明） |
| 解的构造 | 预解式 / [[concepts/弗雷德霍姆行列式]]；退化核代数化 | 完全方程无显式解；特征方程经希尔伯特问题显式求解 (11.86) |
| 齐次与伴随齐次解计数 | 相同（择一定理的核心对称性） | 特征部分由指数 $\kappa$ 控制：$\kappa>0$ 时齐次特征方程有 $\kappa$ 个线性无关解；$\kappa\neq0$ 时齐次与齐次转置解数一般不同（推断，原书未言明） |
| 额外可解性障碍 | 无（正交条件之外） | $\kappa<0$ 时需 $-\kappa$ 个矩条件 (11.83)/(11.87)（对特征方程） |

## 讨论

1. **形式平行**：(11.75a,b) 复制了弗雷德霍姆定理「非齐次可解 ⟺ 与伴随齐次全部解正交」的骨架，使完全奇异方程在判据层面「像」弗雷德霍姆方程。
2. **实质差异**：对称性被指数打破。特征方程的齐次解计数只依赖 $\kappa$（$\log G$ 的环绕数之和），与转置方程的计数不对称；这在弗雷德霍姆理论中没有对应物。
3. **使用警示**：把 11.2.3 的结论（如「齐次与转置齐次解数相同」）外推到奇异方程是本节最易犯的错误，见 [[queries/可解性条件11-75与指数条件11-83至11-87的关系]]。
