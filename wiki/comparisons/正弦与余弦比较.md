# 正弦与余弦比较

依据 [[sources/10-数学手册原书第10版--10-27-三角函数角函数--a2ypwy]]（式 2.63–2.67），sin 与 cos 的图像要素对照如下：

| 性质 | $\sin x$（式 2.63） | $\cos x$（式 2.65） |
|---|---|---|
| 相互关系 | 基准函数 | $\cos x=\sin\left(x+\frac{\pi}{2}\right)$（相位前移 $\frac{\pi}{2}$） |
| 周期 | $2\pi$ | $2\pi$ |
| 值域 | $-1\le y\le 1$ | $-1\le y\le 1$ |
| 与 x 轴交点（兼拐点） | $B_k=(k\pi,0)$ | $B_k=\left(\left(k+\frac{1}{2}\right)\pi,0\right)$ |
| 拐点切线倾角 | $\pm\frac{\pi}{4}$ | $\pm\frac{\pi}{4}$ |
| 极值点 | $C_k=\left(\left(k+\frac{1}{2}\right)\pi,(-1)^k\right)$ | $C_k=(k\pi,(-1)^k)$ |
| 渐近线 | 无 | 无 |

## 要点

- 两者仅相差相位 $\frac{\pi}{2}$，零点与极值点位置互相交错 $\frac{\pi}{2}$：正弦的零点横坐标即余弦的极值点横坐标，反之亦然。
- 一般形式互化：$A\cos(\omega x+\varphi_0)=A\sin\left(\omega x+\varphi_0+\frac{\pi}{2}\right)$（式 2.66–2.67）；手册对平移量的表述口径存疑（[[queries/一般余弦左移量是否应为π除以2ω]]）。
- 两者均有界、连续、无渐近线，与 tan/cot（无界、有渐近线）和 sec/csc（无界、$\lvert y\rvert\ge1$、无零点）形成对照，见 [[comparisons/六种三角函数性质比较]]。
- 特征点公式分别见 [[findings/标准与一般正弦曲线的周期交点与极值点公式]] 与 [[findings/余弦作为相位平移正弦及其特征点]]。
