# 数系分类层级

本页整理《数学手册(原书第10版)》1.1.1 节给出的数系分类：从自然数逐级扩张到实数，无理数再按是否为代数方程的根二分。整体结构：

```text
ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ
ℝ = ℚ ∪ 无理数
无理数 = 代数无理数 ∪ 超越数（不相交二分）
二次无理数 ⊂ 代数无理数
（ℝ 进一步推广为复数，见手册 1.5 节，尚未编目）
```

## 各层定义与性质对照

| 层级 | 记号/形式 | 定义（手册表述） | 表示与关键性质 |
|---|---|---|---|
| 自然数 | ℕ = {0,1,2,3,…} | 来源于计数和排序；含 0，称“非负整数” | 记号约定与部分文献不同 |
| 整数 | ℤ = {…,−2,−1,0,1,2,…} | 正整数、负整数与零 | 无独立论断，由有理数定义覆盖 |
| 有理数 | ℚ = {x \| x = p/q, q≠0} | 正整数、负整数、分数和零的统称 | 无限、有序、处处稠密；四则封闭（除零例外）；有限/无限循环小数；有限连分数；稠密但不覆盖数轴 |
| 实数 | ℝ = ℚ ∪ 无理数 | 有理数与无理数合起来 | 增加封闭性（数轴每点对应一实数）；正实数任意开方、任意正底（≠1）对数 |
| 无理数 | 无限不循环小数；无限连分数 | 填充数轴上所有非有理点 | 二分见下两行 |
| 代数无理数 | (1.1a) 的非整数实根 | 首项系数为 1 的整系数 n 次（n>1）方程的非整数实根 | 最简例 ⁿ√a 的非有理实根 |
| 二次无理数 | (a+b√D)/c | (1.1b) 的非整数根 | ⟺ 循环连分数；例 √2、(√5−1)/2 |
| 超越数 | π、e、非 10ⁿ 整数的 log₁₀ | 不是代数无理数的无理数 | 手册不附证明 |

## 与代数式分类层级的平行

[[comparisons/代数式分类层级]] 给出式与函数的分类：[[concepts/代数式]]/[[concepts/无理式]]/[[concepts/超越式]]，[[concepts/代数函数]]/[[concepts/超越函数]]。数的“代数/超越”二分与之严格平行：代数无理数之于整系数方程 (1.1a)，如同代数式之于代数运算、代数函数之于代数方程。

**但论断不互通**：数的分类论断（如“非 10ⁿ 整数的常用对数是超越数”“二次无理数 ⟺ 循环连分数”）不可转嫁给式或函数的分类，反之亦然；两套分类的论断各自归属其来源章节。
