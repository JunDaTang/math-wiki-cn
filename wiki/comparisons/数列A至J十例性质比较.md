# 数列 A–J 十例性质比较

7.1.1.1 的十个示例数列 A–J 构成一个覆盖全部敛散分类的教学系统：4 收敛、2 真发散、4 假发散；6 有界、4 无界。本页并排比较其性质；分类依据与脱漏字母的重构见 [[findings/数列A至J十例性质分类复算与脱漏字母重构]]，通项逐字转录见 [[findings/式7-1数列定义与A至J十例逐字转录]]。

## 性质对照表

| 例 | 通项 | 单调性 | 有界性 | 敛散分类 | 极限 / 子列行为 |
|---|---|---|---|---|---|
| A | $a_n = n$ | 严格递增 | 无界 | 真发散 | → +∞ |
| B | $a_n = 4 + 3(n-1)$ | 严格递增 | 无界 | 真发散 | → +∞ |
| C | $a_n = 3(-\tfrac12)^{n-1}$ | 非单调 | 有界（K = 4） | 收敛 | → 0（交替变号、绝对值递减） |
| D | $a_n = (-1)^{n+1}$ | 非单调 | 有界 | 假发散 | 双子列恒 +1 与 −1 |
| E | $a_n = 3 - \tfrac{1}{2^{n-2}}$ | 严格递增 | 有界（K = 3） | 收敛 | → 3（自下方趋最小上界） |
| F | 奇 $3\tfrac13 - \tfrac13\cdot 10^{-\frac{n-1}{2}}$；偶 $3\tfrac13 + \tfrac23\cdot 10^{-\frac n2+1}$ | 非单调 | 有界 | 收敛 | → 3⅓（双侧十进夹逼） |
| G | $a_n = \tfrac1n$ | 严格递减 | 有界 | 收敛 | → 0（自上方趋最大下界） |
| H | $a_n = (-1)^{n+1}n$ | 非单调 | 无界 | 假发散 | 奇子列 → +∞，偶子列 → −∞ |
| I | 奇 $-\tfrac{n+1}{2}$；偶 $0$ | 非单调 | 无界（下方） | 假发散 | 奇子列 → −∞，偶项恒 0 |
| J | 奇 $3 - \tfrac{1}{2^{\frac n2-\frac32}}$；偶 $13 - \tfrac{1}{2^{\frac n2-2}}$ | 非单调 | 有界（K = 13） | 假发散 | 奇子列 → 3，偶子列 → 13 |

## 关键对照

- **收敛 vs 真发散 vs 假发散**：收敛 ⟺ 满足式 7.5a（C/E/F/G）；真发散 ⟺ 趋 +∞ 或 −∞ 且不再回落（A/B）；假发散 = 其余发散情形（D/H/I/J）。见 [[concepts/收敛与发散]]、[[concepts/真发散与假发散]]。
- **有界 ⇏ 收敛**：D 与 J 有界却假发散；十例中所有收敛者均有界、所有无界者均发散，与标准定理「收敛 ⟹ 有界」的指向一致（该命题本身未列入本节四条定理，此处仅为十例的观察）。
- **单调性不预定敛散**：单调 + 无界 ⟹ 真发散（A/B）；单调 + 有界 ⟹ 收敛（E/G，即定理 4c)，见 [[concepts/单调有界收敛定理]]）；非单调者可收敛（C/F）亦可假发散（D/H/I/J）。
- **假发散的两种构造**：有界振荡（D：两子列极限 −1 与 1；J：两子列极限 3 与 13，且 J = 交错(E, E+10)）与无界振荡（H：±∞ 交替；I：奇项 → −∞、偶项恒 0）。
- **E 与 G 成对**：分别为定理 4c) 递增、递减两支的例证（E ↗ 最小上界 3，G ↘ 最大下界 0）。
