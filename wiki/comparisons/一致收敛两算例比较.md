# 一致收敛两算例比较（e^x 级数 vs x(1−x) 级数）

手册 7.3.2.1 用一对算例从正反两面刻画一致收敛。两例均已复算（见 [[式7-79ex级数有界区间一致收敛算例]]、[[式7-80非一致收敛算例与和函数不连续]]）。

| 维度 | 算例 A：e^x 级数（式 7.79） | 算例 B：x + x(1−x) + x(1−x)² + ⋯（式 7.80） |
|---|---|---|
| 逐点收敛性 | 全数轴收敛，和为 e^x | [0,1] 上收敛：x = 0 时 S = 0；0 < x ⩽ 1 时 S = 1 |
| 一致收敛区域 | 任意有界区间 \|x\| < a | 任意 [a,1]，0 < a < 1 |
| 非一致收敛的原因 | 对任意大的 n 可取足够大的 x 使余项超过 ε | 对固定 n，x → 0⁺ 时余项 (1−x)^{n+1} → 1，不小于 ε |
| 论证工具 | 麦克劳林余项估计（式 7.79b，界与 x 无关） | 几何级数求和得显式余项（式 7.80c）+ 达朗贝尔比值审敛法（式 7.80b） |
| 和函数连续性 | 连续（7.3.2.2 的正例） | 在 x = 0 不连续（7.3.2.2「非一致收敛 ⇒ 和可能不连续」的反例印证） |
| 教学作用 | 「内闭一致收敛但非整体一致收敛」 | 「逐点收敛 + 和不连续 ⇒ 必非一致收敛」 |

## 结论

两例合起来展示一致收敛失效的两种模式：A 是「区域无界导致余项上确界失控」，B 是「退化点（参数使公比 → 1 或首项 → 0）导致余项上确界不趋于 0」。B 例同时演示了连续性定理的逆否用法：若和函数不连续而各项连续，则收敛必非一致——这是判非一致收敛的实用手段。两例也都体现「内闭（挖去坏点/有界化）即可恢复一致收敛」的共同结构，与 [[阿贝尔定理]]（幂级数内闭一致收敛）精神一致。
