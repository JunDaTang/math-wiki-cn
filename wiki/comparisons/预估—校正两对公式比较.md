# 预估—校正两对公式比较

依据数学手册 19.4.1.4（式 19.107–19.109）与本维基复算结果：

| 维度 | (19.107a,b) 对 | (19.108a,b) 对与 (19.109) 替换 |
|---|---|---|
| 预估子 | y_i + (h/12)(5f_{i−2} − 16f_{i−1} + 23f_i) | y_{i−2} + 9y_{i−1} − 9y_i + 6h(f_{i−1} + f_i) |
| 校正子 | y_i + (h/12)(−f_{i−1} + 8f_i + 5f_{i+1}^{(μ)}) | (19.108b) 辛普森型 y_{i−1} + (h/3)(f_{i−1} + 4f_i + f_{i+1}^{(μ)})；替换为 (19.109) |
| 阶（复算） | 三阶（标准 Adams 预估—校正对，命名系本维基推断） | (19.108a) 与 (19.109) 均为四阶（对次数 ⩽ 4 的多项式精确） |
| 稳定性 | 源文未评 | 源文明言：辛普森公式作为 (19.108b) 校正子在数值上不稳定，可替换为 (19.109) |
| 涉及节点 | f_{i−2}, f_{i−1}, f_i（预估）＋ f_{i+1}（校正） | y_{i−2}, y_{i−1}, y_i 与 f_{i−2}, …, f_{i+1} |
| 开放问题 | — | (19.108a) 与经典米尔恩预估子形式不同；(19.109) 系数非经典 Hamming 校正子形式，来源待查 |

核心张力：高阶精度（辛普森型校正子四阶）与误差传播稳定性（数值不稳定）的对立，(19.109) 是以同阶（四阶）系数重组换取稳定性的尝试。见 [[concepts/预估—校正法]]、[[queries/式19-108a预估子与经典米尔恩预估子形式之辨]]。
