# 一维三次样条与双三次样条比较

一维三次样条（19.7.1）与其二维推广双三次样条（19.7.2）的比较。

| 维度 | 一维三次样条 | 双三次样条 |
|---|---|---|
| 定义域 | 区间 [x_1, x_N]，节点 x_1 < ⋯ < x_N | 矩形 R，网格节点 (x_i, y_j)（(19.244)） |
| 分片形式 | 每段三次多项式 (19.236)，每段 4 系数 | 每子区域双三次 (19.247)，每片 16 系数，全区域共 16mn 个 |
| 光滑性 | S ∈ C²（S、S′、S″ 连续） | ∂S/∂x、∂S/∂y、∂²S/∂x∂y 连续 (19.248) |
| 边界条件 | 自然/端点导数给定/周期三类 | 边界一阶与混合偏导数值 p_ij、q_ij、r_ij 预先给定 (19.249) |
| 方程组 | 单个三对角组 (19.240)/(19.241)，LR 分解求解 | 2n+m+3 个方程组，系数矩阵三对角，仅右端项不同 |
| 光滑样条版本 | (19.242) 罚化最小二乘，λ 谱系完整 | 可能的最优条件一整列，仅很少特殊情况存在唯一解（caveat） |
| 基函数替代 | 自由节点 B 样条 N_{i,4}（(19.243)） | 张量积 B 样条 N_{i,4}(x)N_{j,4}(y)（(19.251)），带状系数矩阵 |

## 要点

- 双三次样条法 (19.247) 是 [[concepts/张量积方法]] (19.250) 的一个例子；二维系数确定复用一维结果，方程组计数 2n+m+3 可由 (m+1)+(n+1)+(n+1) 复原（假说，见 [[findings/式19-244至19-251双三次样条与张量积转录复算]]）。
- 「三对角/带状结构利于数值求解」的主题与 19.5 的 [[concepts/块三对角矩阵]] 跨节呼应。
- 原书评价：一般对于计算量和精度来说，双三次插值样条是有用的，故对于实际应用它们是合适的。
