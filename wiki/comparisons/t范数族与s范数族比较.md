# t 范数族与 s 范数族比较（表 5.8）

本页承载《数学手册(原书第10版)》表 5.8「t 范数和 s 范数，p ∈ ℝ」的各族归属与比较；完整逐字转录见 [[findings/表5-8十二对范数族与序链]] 与源页。除 [[entities/扎德]] 外，下列署名者均不单独建页。

## 各族归属与要点

| 族 | t 范数 | s 范数 | 备注 |
|---|---|---|---|
| Zadeh | min{x,y} | max{x,y} | 缺省交并；序链中央；min 为最大 t 范数、max 为最小 s 范数 |
| Lukasiewicz | 有界差 t_b = max{0, x+y−1} | 有界和 s_b = min{1, x+y} | 手册命名「有界差」，通行多称「有界积/Łukasiewicz t 范数」 |
| （未署名） | 代数积 t_a = xy | 代数和 s_a = x+y−xy | 作者栏空白；λ/γ 补偿算子的两个端点 |
| （未署名） | 极端积 t_dp | 极端和 s_ds | 作者栏空白；序链两端（最小 t 范数与最大 s 范数） |
| Hamacher（p ≥ 0） | t_h = xy/(p+(1−p)(x+y−xy)) | s_h = (x+y−xy−(1−p)xy)/(1−(1−p)xy) | 序链位置仅对 p∈[0,1] 成立，见 [[queries/范数序链是否隐含hamacher参数限定]] |
| Einstein | t_e = xy/(1+(1−x)(1−y)) | s_e = (x+y)/(1+xy) |  |
| Frank（p>0, p≠1） | t_f = log_p[1+(p^x−1)(p^y−1)/(p−1)] | s_f = 1−log_p[1+(p^{1−x}−1)(p^{1−y}−1)/(p−1)] | 对数型参数族 |
| Yager（p>0） | t_ya = 1−min{1, ((1−x)^p+(1−y)^p)^{1/p}} | s_ya = min{1, (x^p+y^p)^{1/p}} | Yager 补（5.9.2.5）参数区间疑应为 p>0 |
| Schweizer（p>0） | t_s = max{0, x^{−p}+y^{−p}−1}^{−1/p} | s_s = 1−max{0, (1−x)^{−p}+(1−y)^p−1}^{−1/p}〔疑讹〕 | s_s 的 (1−y)^p 疑应为 (1−y)^{−p}，见 [[queries/schweizer-s范数指数是否应为负p]] |
| Dombi（p>0） | t_do = {1+[((1−x)/x)^p+((1−y)/y)^p]^{1/p}}^{−1} | s_do = 1−{1+[(x/(1−x))^p+(y/(1−y))^p]^{1/p}}^{−1} | 互补的比值幂结构 |
| Weber（p ≥ −1） | t_w = max{0, (1+p)(x+y−1)−pxy} | s_w = min{1, x+y+pxy} |  |
| Dubois（0≤p≤1） | t_du = xy/max{x,y,p} | s_du = (x+y−xy−min{x,y,(1−p)})/max{(1−x),(1−y),p} |  |

菅野（Sugeno）与 Yager 的**补函数**不属于表 5.8，另见 [[concepts/模糊补]]。

## 全序链（源文原注）

t_dp ≤ t_b ≤ t_e ≤ t_a ≤ t_h ≤ t ≤ s ≤ s_h ≤ s_a ≤ s_e ≤ s_b ≤ s_ds（链中 t、s 即 Zadeh 的 min/max——维基注记）。

## 对偶一致性（独立复算，推断）

以 s(x,y) = 1−t(1−x,1−y) 检验各族配对：全部一致，唯一例外 Schweizer s_s（(1−y) 的指数）。另有序链对 Hamacher 参数的反例（p=2、x=y=0.5 时 t_h = 0.2 < t_a = 0.25）。详见 [[findings/表5-8十二对范数族与序链]]。

## 术语与转写注

- 同一 t_b 在表 5.8 名为「有界差」、正文一处作「有界差分」、另一处作「有界积」，命名不一；
- 正文「其他聚合有有界聚合、代数聚合、极端和，以及有界差分、代数积和极端积」中「有界聚合、代数聚合」疑为「有界和、代数和」之讹；
- 详见 [[queries/5-9-2全节系统性转写讹误清单]]。
