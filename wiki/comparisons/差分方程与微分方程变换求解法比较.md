# 差分方程与微分方程变换求解法比较

Z变换解差分方程（15.4.2）与拉普拉斯变换解微分方程（15.2.3）在流程与解结构上的系统对照——两者是同一「变换—代数化—反变换」范式的离散/连续实现。

| 方面 | 拉普拉斯变换解微分方程（15.2.3） | Z变换解差分方程（15.4.2） |
|---|---|---|
| 方程 | 常系数线性微分方程 | $a_ky_{n+k}+\dots+a_0y_n=g_n$（15.132，[[concepts/差分与差分方程]]） |
| 核心规则 | 微分规则 $\mathcal{L}\{y^{(k)}\}=p^kY-\text{初值项}$ | 第二移位定理 (15.114) |
| 初值 | 自动包含于变换方程 | 自动包含于变换方程 (15.133)–(15.134) |
| 特征方程 | 特征多项式（[[concepts/特征方程]]） | $p(z)=a_kz^k+\dots+a_0$，根 $\alpha_i$ 决定解形 |
| 根分岔 | 异根 / 重根 / 复根（欧拉式处理） | $\alpha_1\neq\alpha_2$ / $\alpha_1=\alpha_2$（15.138a）；复系数时双曲代换 $a_1=-2a\cosh b,\ a_0=a^2$（15.139–15.140，数值上更有利） |
| 强迫项解 | 卷积 / [[concepts/杜阿梅尔公式]] | 离散卷积 $y_n=\sum_v p_{v-1}g_{n-v}$（15.138d，[[concepts/离散卷积]]） |
| 通解结构 | $Y=\frac{G}{p}+\frac{\text{初值多项式}}{p}$ | $Y=\frac{G(z)}{p(z)}+\frac{1}{p(z)}\sum_i y_i\sum_j a_jz^{j-i}$（15.134） |
| 边值问题 | 由边值条件定积分常数 | 由 $y_N$ 反解 $y_1$（15.141）后代回（15.142）；仅当 $\alpha_1^N\neq\alpha_2^N$ 有一般解，否则出现特征值/特征向量现象——源文自陈与微分方程边值问题类似 |

## 共同优势

变换把递归/微分方程化为代数方程；初值（或边值）自动进入解；解结构显式化——齐次部分由特征根决定，强迫部分呈卷积（核函数分别为 $\mathcal{Z}^{-1}\{z/p(z)\}$ 与脉冲响应）。

## 本质差异

差分方程本身可由初值逐步递推求解（逐值计算平凡可得），变换法的价值在于**闭式与结构**；微分方程则无此逐值递推，变换法同时承担求解与解表示双重职能。此外，Z变换作用于序列（级数型变换），拉普拉斯变换作用于函数（积分型变换），详见 [[comparisons/z变换与拉普拉斯变换关系比较]]。
