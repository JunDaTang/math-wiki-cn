# tan 与 cot 积分小节比较

21.7.3.4（正切，409–417）与 21.7.3.5（余切，418–425）逐条镜像。本比较基于 [[sources/10-数学手册原书第10版--11-2173-三角函数积分--jenyj9]]。

## 逐条对照

| 功能 | tan 侧 | cot 侧 |
|---|---|---|
| 一次 | 409：−(1/a)ln cos | 418：(1/a)ln sin |
| 二次 | 410：(1/a)tan − x | 419：−(1/a)cot − x |
| 三次 | 411：tan²/(2a) + (1/a)ln cos | 420：−cot²/(2a) − (1/a)ln sin |
| n 次递推 | 412：tan^{n−1}/(a(n−1)) − ∫tan^{n−2} | 421：−cot^{n−1}/(a(n−1)) − ∫cot^{n−2} |
| x 因子 | 413：ax³/3 + a³x⁵/15 + 2a⁵x⁷/105 + ⋯（全正） | 422：x/a − ax³/9 − a³x⁵/225 − ⋯（首项后全负） |
| ÷x | 414：ax + (ax)³/9 + 2(ax)⁵/75 + ⋯（全正） | 423：−1/(ax) − ax/3 − (ax)³/135 − ⋯（全负） |
| 乘自身的导函数 | 415：∫tanⁿ/cos² = tan^{n+1}/(a(n+1)) | 424：∫cotⁿ/sin² = −cot^{n+1}/(a(n+1)) |
| 与 1 的和差分式 | 416：∫dx/(tan±1)；417：∫tan/(tan±1) | 425：∫dx/(1±cot) ≡ ∫tan/(tan±1)（明文参见417） |

## 级数的函数方程关联

413 与 422 的通项分别为 2^{2n}(2^{2n}−1)B_n a^{2n−1}x^{2n+1}/(2n+1)! 与 2^{2n}B_n a^{2n−1}x^{2n+1}/(2n+1)!。其系数关系源于恒等式 **tan u = cot u − 2cot 2u**：以 z cot z = 1 − Σ2^{2n}B_n z^{2n}/(2n)! 为基展开，x·cot ax 与 x·tan ax = x·cot ax − 2x·cot 2ax 的积分即分别给出 422 与 413 的通项（相差因子 2^{2n}−1、整体符号及首项 x/a）。414/423 为各自的 ÷x 版，通项分母相差 (2n−1) 因子，同构。

## 结构差异

- **编号量不等**（9 对 8）：cot 侧无 416 的独立对应式，而以 425 通过恒等变形直接回指 417 收束；
- **奇性符号**：tan 为奇函数导致两小节逐项符号翻转；
- **校勘状态**：两小节全部条目复算无误（含四条级数），21.7.3 的讹误集中于 sin/cos 混合小节。
