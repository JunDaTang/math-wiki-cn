# 真实误差与表观误差比较

真实误差与表观误差是测量序列单次测量误差的「不可知/可算」对偶（《数学手册》16.4.1.3）：

| | 真实误差 ε_i | 表观误差 v_i |
|---|---|---|
| 定义 | $x_w-x_i$（16.198） | $\bar{x}-x_i$（16.199） |
| 可知性 | 不可知（真实值 $x_w$ 未知） | 可由测量序列计算 |
| 角色 | 理论量，定义误差分布 | 实用量，构造一切估计量 |
| 求和性质 | $E(\sum\varepsilon_i)=0$ | $\sum v_i\equiv0$（对算术平均） |
| 平方和 | $\varepsilon^2=\sum\varepsilon_i^2$（16.200a，理论） | $v^2=\sum v_i^2$（16.200b，实用） |
| 符号约定 | — | 与常用残差 $x_i-\bar{x}$ 反号，平方后无影响 |

**枢纽地位**：从实用观点看，既然只有 v_i 的值可由测量过程确定，单次测量均方误差以 (16.200c) $\tilde{\sigma}=\sqrt{\sum v_i^2/(n-1)}$ 定义——即 [[concepts/样本方差]] 的 Bessel 修正平方根；σ̃ 是不可知的 σ 的近似值。均值端 $\tilde{\sigma}_{AM}=\tilde{\sigma}/\sqrt{n}$（16.203）同样由 v_i 驱动。

**引用警示**：引用线性关系（偏差方向、Σv_i=0 的符号）时须注明本节 v_i=x̄−x_i 的反号约定；数值复算见 [[findings/式16-196至16-202c单次测量误差转录复算]]。
