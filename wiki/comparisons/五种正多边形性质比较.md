# 五种正多边形性质比较（表 3.2 规范化对比）

将《数学手册(原书第10版)》表 3.2 的三、五、六、八、十边形按同一基准规范化对比（复原读法，均由 [[methodology/正多边形中心三角形分解法]] 与式 3.51–3.56 推出）。

## 数值对比（以 R = 1 为基准；数值为按复原公式独立计算的校验值，非源文所载）

| n | aₙ/R | r/R | Sₙ/R² | 特点 |
|---|---|---|---|---|
| 3 | √3 ≈ 1.7321 | 1/2 = 0.5000 | (3/4)√3 ≈ 1.2990 | r/R 最小（r = R/2）；S₃ = 3r²√3 |
| 5 | (1/2)√(10−2√5) ≈ 1.1756 | (1/4)(√5+1) ≈ 0.8090 | (5/8)√(10+2√5) ≈ 2.3776 | 对角线/边 = 黄金分割；R = r(√5−1) |
| 6 | 1 | (1/2)√3 ≈ 0.8660 | (3/2)√3 ≈ 2.5981 | 唯一 aₙ = R 的情形（6 个等边三角形拼成） |
| 8 | √(2−√2) ≈ 0.7654 | (1/2)√(2+√2) ≈ 0.9239 | 2√2 ≈ 2.8284 | 根式仅含 √2 |
| 10 | (1/2)(√5−1) ≈ 0.6180 | (1/4)√(10+2√5) ≈ 0.9511 | (5/4)√(10−2√5) ≈ 2.9389 | a₁₀/R 为黄金分割倒数 |

## 结构观察（由复原公式可验）

- 随 n 增大：aₙ/R 递减（趋于 0）、r/R 递增（趋于 1）、Sₙ/R² 递增（趋于单位圆面积 π）——正多边形趋近其外接圆。
- 根式内容由 n 决定：√3 只出现于 n = 3、6；√2 只出现于 n = 8；√5 只出现于 n = 5、10（与五等分/十等分圆相关）。
- 五边形与十边形共享 √5 体系：a₁₀ = (R/2)(√5−1) 恰为黄金分割倒数乘 R，呼应 [[concepts/黄金分割]]；五边形的 R = r(√5−1) 与十边形的 R = (a₁₀/2)(√5+1) 互为倒数结构。
- 表 3.2 缺正方形（n = 4）行（a₄ = R√2、r = R/√2、S₄ = 2R² 均极简，缺位反常），见 [[queries/表3-2是否原书即缺正方形行]]。
