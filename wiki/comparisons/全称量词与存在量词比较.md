# 全称量词与存在量词比较

依据《数学手册(原书第10版)》5.1.2：

| 维度 | ∀（全称量词） | ∃（存在量词） |
|---|---|---|
| 读法 | 「对于每个」「对于所有」 | 「对于某个」「存在」 |
| 语义 | P(x) 对 X 中每个 x 真 | X 中存在 x 使 P(x) 真 |
| 否定 | ¬∀xP(x) = ∃x¬P(x)（5.23） | ¬∃xP(x) = ∀x¬P(x)（5.23） |
| 由对方表示 | ∀xP(x) = ¬∃x¬P(x)（5.24） | ∃xP(x) = ¬∀x¬P(x)（5.24） |
| 对 ∧ 的行为 | 等价：∀P∧∀Q = ∀(P∧Q)（5.27） | 仅单向：∃(P∧Q) ⇒ ∃P∧∃Q（5.30） |
| 对 ∨ 的行为 | 仅单向：∀P∨∀Q ⇒ ∀(P∨Q)（5.29） | 等价：∃P∨∃Q = ∃(P∨Q)（5.28） |
| 受限形式 | ∀x∈X P(x) ≜ ∀x(x∈X ⇒ P(x))（5.34，正确） | ∃x∈X P(x)（5.35，⇒ 疑应为 ∧） |

**交换性**：同类量词可交换（5.25/5.26）；∀ 与 ∃ 之间不可交换——(5.33) ∃x∀yP(x,y) ⇒ ∀y∃xP(x,y) 成立而其逆为假，即「∃∀」强于「∀∃」。

**算例**（原书，素数谓词 P 于 ℕ）：∀nP(n) 是假语句，∃nP(n) 是真语句。
