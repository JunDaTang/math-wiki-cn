# 定积分与不定积分比较

| 维度 | 不定积分（8.1.1，式 8.2） | 定积分（8.2.1，式 8.39） |
|------|------|------|
| 本体 | 原函数族 $F(x)+C$（函数） | 黎曼和的极限（一个数） |
| 定义构造 | 求导的逆运算：$F'=f$ | 分点—取点—乘积—求和—取极限 |
| 记号 | $\int f(x)\,\mathrm{d}x$ | $\int_a^b f(x)\,\mathrm{d}x$（积分限承载区间与方向） |
| 存在性 | 连续函数必有原函数；初等函数的原函数未必初等（[[concepts/非初等积分]]） | 连续⇒可积；有界+有限个间断点⇒可积 |
| 哑变量 | 是 | 是（式 8.46） |
| 方向性 | 无 | 有：情形 B（$a>b$）与交换法则（式 8.48） |
| 几何意义 | 原函数图像族（纵坐标平移） | 曲线下带号面积（式 8.42，图 8.5 四情形） |

## 桥梁：微积分基本定理

式 8.40–8.41：$\int_a^b f\,\mathrm{d}x=F(b)-F(a)$，$F'=f$。正向，定积分的计算化归为不定积分（反导数的确定）；反向，[[concepts/变上限积分]] $\int_a^x f(t)\,\mathrm{d}t$ 表明连续函数的原函数可用定积分构造（式 8.43–8.44）。

## 关键区分：可积性与原函数存在性

8.2.1 的明确论断：**可积函数不一定有原函数，但连续函数一定有原函数。** 两个概念的充分条件不同：

| 函数类 | 定积分存在（可积） | 原函数存在 |
|--------|--------------------|------------|
| $[a,b]$ 上连续 | ✓ | ✓（式 8.43–8.44 构造性证明） |
| 有界且有限个间断点 | ✓ | 本节未断言（「可积不一定有原函数」的一般论断即涵盖此类情形） |

## 方法库差异

不定积分失败（非初等）时，定积分仍有独立出路：含参微分（式 8.53）、级数展开（式 8.54–8.56）、图形/机械方法（式 8.57、[[entities/面积仪]]）、数值求积（19.3.1）——见[[methodology/定积分计算方法选择流程]]。反之，定积分特有的性质（区间法则式 8.45、中值定理式 8.49–8.51、估计式 8.52、积分限运算式 8.46–8.48）在不定积分中没有对应物。
