# 笛卡儿、柱面与球面坐标系向量分量表示比较

依据《数学手册(原书第10版)》13.1.3.3–13.1.3.4（表 13.1 与式 13.18–13.21），本页是本节最可复用资产的归档与比较。

## 三系基向量对比

| 维度 | 笛卡儿坐标系 | 柱面坐标系 | 球面坐标系 |
|---|---|---|---|
| 基向量 | $\vec{i}, \vec{j}, \vec{k}$ | $\vec{e}_\rho, \vec{e}_\varphi, \vec{e}_z\,(=\vec{k})$ | $\vec{e}_r\,(=\vec{r}/r), \vec{e}_\vartheta, \vec{e}_\varphi$ |
| 方向 | 全空间固定不变 | 逐点切于坐标线 | 逐点切于坐标线 |
| 正交性与取向 | 右手系 | 两两正交、右手系 | 两两正交、右手系 |
| 分量式 | 式 (13.16b) | 式 (13.17b) | 式 (13.17c) |

关键差异：曲线坐标系中基向量是**位置的函数**——从一点转移到另一点时方向改变但仍保持相互垂直。因此换点时分量必须重新投影，这正是表 13.1 全部公式存在的原因。

## 分量变换公式（经复算全部正确）

$$V_x = V_\rho\cos\varphi - V_\varphi\sin\varphi,\quad V_y = V_\rho\sin\varphi + V_\varphi\cos\varphi,\quad V_z = V_z. \tag{13.18}$$

$$V_\rho = V_x\cos\varphi + V_y\sin\varphi,\quad V_\varphi = -V_x\sin\varphi + V_y\cos\varphi,\quad V_z = V_z. \tag{13.19}$$

$$V_x = V_r\sin\vartheta\cos\varphi - V_\varphi\sin\varphi + V_\vartheta\cos\varphi\cos\vartheta,$$
$$V_y = V_r\sin\vartheta\sin\varphi + V_\varphi\cos\varphi + V_\vartheta\sin\varphi\cos\vartheta,$$
$$V_z = V_r\cos\vartheta - V_\vartheta\sin\vartheta. \tag{13.20}$$

$$V_r = V_x\sin\vartheta\cos\varphi + V_y\sin\vartheta\sin\varphi + V_z\cos\vartheta,$$
$$V_\vartheta = V_x\cos\vartheta\cos\varphi + V_y\cos\vartheta\sin\varphi - V_z\sin\vartheta,$$
$$V_\varphi = -V_x\sin\varphi + V_y\cos\varphi. \tag{13.21}$$

## 柱面 ↔ 球面直换（表 13.1 后三行）

$$V_r = V_\rho\sin\vartheta + V_z\cos\vartheta,\qquad V_\vartheta = V_\rho\cos\vartheta - V_z\sin\vartheta,\qquad V_\varphi = V_\varphi;$$

$$V_\rho = V_r\sin\vartheta + V_\vartheta\cos\vartheta,\qquad V_z = V_r\cos\vartheta - V_\vartheta\sin\vartheta.$$

这些行隐含单位向量投影关系：

$$\vec{e}_r = \sin\vartheta\,\vec{e}_\rho + \cos\vartheta\,\vec{e}_z,\qquad \vec{e}_\vartheta = \cos\vartheta\,\vec{e}_\rho - \sin\vartheta\,\vec{e}_z,\qquad \vec{e}_\rho = \sin\vartheta\,\vec{e}_r + \cos\vartheta\,\vec{e}_\vartheta,$$

且 $\vec{e}_\varphi$ 在柱面系与球面系中相同。

## 复算结论与勘误

- 式 (13.18)–(13.21) 四组公式全部正确（由单位向量点积重建验证）；
- 表 13.1 的柱面列与球面列全部正确；
- 唯一讹误：$V_\vartheta$ 行**笛卡儿列** $-V_z\sin\varphi$ 应为 $-V_z\sin\vartheta$，与式 (13.21) 矛盾，复算支持式 (13.21)（见 [[表13-1的Vϑ行sinφ疑为sinϑ]]）。

## 特殊场的最简表示

- 球面向量场：球面系 $\vec{V} = V(r)\vec{e}_r$（原文下标 $\tau$ 疑为 $r$）；
- 柱面向量场：柱面系 $\vec{V} = \varphi(\rho)\vec{e}_\rho$（正文 $V(\varphi)\vec{e}_\varphi$ 疑误，见 [[柱面向量场坐标形式疑为Vρeρ]]）；
- 平面向量场：式 (13.24)；圆场：式 (13.25)（记号差 $\rho$ 因子，见 [[式13-25圆场标量函数记号差ρ因子疑误]]）。
