# 收敛幂级数与渐近幂级数比较

手册 7.3 以幂级数（小 x 展开）与渐近幂级数（大 x、按 1/x 展开）收尾，构成同一节内两种级数工具的对照。

| 维度 | 收敛幂级数（泰勒/麦克劳林，式 7.95–7.97） | 渐近幂级数（式 7.99–7.100） |
|---|---|---|
| 适用变量尺度 | x 接近展开中心（小邻域） | \|x\| 较大（按 1/x 展开，x → ∞） |
| 收敛性要求 | 要求级数收敛，且须 S = f | **不要求收敛**（发散级数亦可用） |
| 误差控制 | n → ∞ 时余项 R_n → 0（拉格朗日/积分余项） | 固定 n、x → ∞ 时余项 O(1/x^{n+1}) |
| 唯一性 | 收敛幂级数表示唯一 | 存在则唯一，但**不唯一确定函数** |
| 生成方法 | 各阶导数在展开点的值 | 反复分部积分等（见 [[渐近展开分部积分流程]]） |
| 典型正例 | e^x = Σ xⁿ/n!（处处收敛到 e^x） | e^{1/x} ≈ Σ 1/(ν!x^ν)（渐近且收敛） |
| 典型警示例 | e^{−1/x²}：级数收敛但 S = 0 ≠ f | ∫₀^∞ e^{−xt}/(1+t)dt ≈ Σ(−1)^ν ν!/x^{ν+1}：处处发散却完美近似 |
| 失效模式 | 收敛半径不足；或收敛不到 f | 截断超过最小项后误差增大 |

## 结论

两者的可靠性来源不同：收敛幂级数靠「n → ∞ 的极限过程」，渐近幂级数靠「固定 n 时 x → ∞ 的余项阶」。手册的例 B（x = 10 时 0.09152 < f(10) < 0.09164，复算通过）表明：对大 x 的数值计算，一个对每个 x 都发散的级数反而可能优于任何收敛级数（收敛级数在大 x 处可能收敛极慢或收敛半径不够）。使用时的对应守则：前者须验证「收敛到 f」（反例 [[e负x平方分之一麦克劳林级数反例]]），后者须遵守截断规则且只在渐近意义下解释（[[朗道符号]]）。
