# 三角与双曲基本积分平行比较

表 8.1（见 [[findings/表8-1基本积分22式逐字转录与复算]]）中三角函数与双曲函数两栏共 6 对公式完全平行：把三角公式中的 sin、cos、tan、cot 分别换为 sinh、cosh、tanh、coth，多数条目逐字对应，仅个别符号不同。

## 对照表

| # | 三角函数 | 双曲函数 | 差异 |
|---|---|---|---|
| 1 | $\int \sin x \,\mathrm{d}x = -\cos x$ | $\int \sinh x \,\mathrm{d}x = \cosh x$ | 符号相反 |
| 2 | $\int \cos x \,\mathrm{d}x = \sin x$ | $\int \cosh x \,\mathrm{d}x = \sinh x$ | 完全平行 |
| 3 | $\int \tan x \,\mathrm{d}x = -\ln \lvert \cos x\rvert$ | $\int \tanh x \,\mathrm{d}x = \ln \lvert \cosh x\rvert$ | 符号相反 |
| 4 | $\int \cot x \,\mathrm{d}x = \ln \lvert \sin x\rvert$ | $\int \coth x \,\mathrm{d}x = \ln \lvert \sinh x\rvert$ | 完全平行 |
| 5 | $\int \dfrac{\mathrm{d}x}{\cos^2 x} = \tan x$ | $\int \dfrac{\mathrm{d}x}{\cosh^2 x} = \tanh x$ | 完全平行 |
| 6 | $\int \dfrac{\mathrm{d}x}{\sin^2 x} = -\cot x$ | $\int \dfrac{\mathrm{d}x}{\sinh^2 x} = -\coth x$ | 完全平行 |

## 差异的来源

符号差异集中在“余函数”（cos、cosh）参与的条目（第 1、3 对）：

- $(\cos x)^{\prime} = -\sin x$，而 $(\cosh x)^{\prime} = +\sinh x$；
- $(\sin x)^{\prime} = \cos x$ 与 $(\sinh x)^{\prime} = \cosh x$ 同号。

因此凡由 cos 的导数产生的负号，在双曲对应条目中消失；其余条目（2、4、5、6）逐字平行。这一平行性与解析延拓观点一致（独立可验证背景）：$\sinh x = -\mathrm{i}\sin(\mathrm{i}x)$、$\cosh x = \cos(\mathrm{i}x)$，虚因子成对出现时符号相消。

## 用途与局限

- **记忆与校验**：由一栏回忆另一栏，只需检查“余函数导数符号”这一处。
- **复算印证**：该平行结构是表 8.1 逐条求导复算（replicated: true）的交叉印证。
- **局限**：本比较仅覆盖表 8.1 的三角/双曲两栏 6 对；分式有理与无理栏中的 $\operatorname{Artanh}$、$\operatorname{Arcoth}$、$\operatorname{Arsinh}$、$\operatorname{Arcosh}$ 条目虽同属双曲体系，但来自部分分式与根式积分，不在此平行结构之内。概念背景见 [[concepts/初等函数的积分]]。
