# 级数审敛法与广义积分审敛法平行比较

《数学手册(原书第10版)》7.2（数项级数）与 8.2.3（广义积分）给出了两套平行的审敛工具，且经式 8.84 与级数的积分审敛法（7.2.2.4，第 619 页）互相打通。

| 判别法 | 级数版（7.2） | 广义积分版（8.2.3） |
|---|---|---|
| 绝对收敛 | [[concepts/绝对收敛与条件收敛]]：$\sum\lvert a_n\rvert$ 收敛 ⇒ $\sum a_n$ 收敛 | [[concepts/广义积分的绝对收敛]]：$\int\lvert f\rvert$ 收敛 ⇒ $\int f$ 收敛（式 8.81；瑕积分版 8.2.3.3.4(1)） |
| 比较审敛法 | [[concepts/比较审敛法]]：$0<a_n\leqslant b_n$ 的比较 | [[concepts/广义积分的比较审敛法]]：$0<f\leqslant\varphi$（式 8.82a–c） |
| 幂尺度 | 与 $1/n^{\alpha}$ 比较（比较审敛法的特例） | [[concepts/广义积分的幂判敛法]]：与 $1/x^{\alpha}$（式 8.83）、$(b-x)^{-\alpha}$（式 8.89）比较 |
| 收敛必要条件 | 通项 $a_n\to0$（真必要条件） | 原书断言 $f(x)\to0$ 为 (8.77) 收敛必要条件——一般情形**不成立**，见 [[queries/lim-f-x趋于0必要条件的适用前提]] |
| 互相转化 | 积分审敛法（7.2.2.4）：正的单调 $f$，$\sum f(n)$ 与 $\int f$ 同敛散 | 式 8.84：正的 $f$，$\int_a^{+\infty}f$ 与区段积分级数 $\sum\int_{x_{n-1}}^{x_n}f$ 同敛散且收敛时相等 |

要点：

- 式 8.84 与积分审敛法构成**双向桥**（原书明言）：既可把级数的收敛条件用于广义积分，也可用广义积分研究无穷级数的收敛性。见 [[findings/式8-84广义积分与无穷级数互化]]。
- 必要条件的不对称值得注意：级数侧「$\sum a_n$ 收敛 ⇒ $a_n\to0$」恒真（部分和收敛推出通项趋零），积分侧因「质量可藏于尖峰」而失效（尖峰反例见 [[queries/lim-f-x趋于0必要条件的适用前提]]）。
- 级数版另有比值、根值等本节未给积分对应的判别法；广义积分版另有[[concepts/柯西主值]]这一弱化收玫概念。
