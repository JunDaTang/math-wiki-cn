# 标量场与向量场比较

依据《数学手册(原书第10版)》13.1.2 与 13.1.3，两类场的系统对照：

| 维度 | 标量场 | 向量场 |
|---|---|---|
| 定义 | 对每点 $P$ 指定一个数：$U = U(P)$（式 13.6a） | 对每点 $P$ 指定一个向量：$\vec{V} = \vec{V}(P)$（式 13.12a） |
| 位置向量记法 | $U = U(\vec{r})$（式 13.6b） | $\vec{V} = \vec{V}(\vec{r})$（式 13.12b） |
| 坐标表示 | 一个三元函数：$\Phi(x,y,z)$、$\Psi(\rho,\varphi,z)$、$\chi(r,\vartheta,\varphi)$（式 13.8a） | 三个坐标函数（分量）：式 (13.16b)、(13.17b)、(13.17c) |
| 平面特化 | 平面场：二元函数 $\Phi(x,y)$ 或 $\Psi(\rho,\varphi)$（式 13.8b） | 平面向量场：$\vec{r}$ 与 $\vec{V}$ 均位于一个平面（式 13.24） |
| 特殊情形 | [[中心场]]、[[轴向场]] | [[中心向量场与球面向量场]]、[[柱面向量场]] |
| 几何刻画 | [[等值面与等值线]] | [[向量线]] |
| 物理例子 | 物体的温度、密度、位势 | 运动流体的速度场、力场、磁强度场、电强度场 |

## 共同点

- 两者都以"极点 + 位置向量 $\vec{r}$"为基础（$U(\vec{r})$、$\vec{V}(\vec{r})$）；
- 都按对称性选择最方便的坐标系：中心/球面型用球面坐标，轴向/柱面型用柱面坐标；
- 层级关系：借助三个标量变量的三个标量函数即可定义向量场（式 13.16）——向量场的每个分量本身是一个标量场（坐标函数）。
