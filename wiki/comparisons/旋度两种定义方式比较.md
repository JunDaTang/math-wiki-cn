# 旋度两种定义方式比较

《数学手册》13.2.5.1 给出旋度的两种定义，比较如下（平行于 [[comparisons/梯度三种定义方式比较]]）：

| 维度 | 体积导数式（式 13.57） | 环流面密度最大值式（式 13.58a/b） |
|---|---|---|
| 公式 | rot V⃗ = lim_{V→0} (1/V) ∯_Σ dS⃗×V⃗ | l⃗·rot V⃗ = lim_{S→0} (1/S) ∮_C V⃗·dr⃗，模长取方向最大值 |
| 几何对象 | 闭合曲面 Σ 及其围成的体积 V，[[concepts/向量曲面元]] dS⃗ | 过点的曲面片 S、法向 n⃗、正定向边界 C（图 13.12） |
| 手册表述 | 向量场的“负空间导数” | 环流面密度及其方向最大值 |
| 输出方式 | 直接给出整个向量（三分量同时） | 先给出任意方向分量 (13.58b)，再经取最大值得模长与方向 (13.58a) |
| 优点 | 与坐标、方向选择无关；与 [[concepts/体积导数]] 第三类极限统一 | 物理意义直观（环流密度）；与斯托克斯定理直接衔接 |
| 注意点 | 符号依赖叉积书写次序（“负”指 V⃗×dS⃗ 形式）；V 记号重载（体积/向量场） | “先定向取极限、再取最大”被合并为单一极限记号，属手册式非严格写法 |
| 关联 | [[concepts/体积导数]]、[[concepts/向量曲面元]] | [[concepts/向量线]]（旋度线）、13.3.3.2 斯托克斯定理（未入库） |

## 共同点

两者都不依赖坐标系；都通过收缩到一点的极限定义；复算确认二者一致（刚体旋转场 V⃗ = ω⃗×r⃗ 的显式积分验证），见 [[findings/式13-57至13-58b旋度两种定义转录复算]]。

## 与梯度定义族的平行

13.2.2 的梯度同样有体积导数式（第一类极限）与方向导数最大值式两种定义；旋度的 (13.57)/(13.58) 与之结构同构：体积导数式对应极限式，环流分量式对应方向导数式，模长/方向的最大值构造完全平行。参见 [[comparisons/梯度三种定义方式比较]]。
