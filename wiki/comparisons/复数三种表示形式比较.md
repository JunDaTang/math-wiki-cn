# 复数三种表示形式比较

《数学手册》1.5 节将同一[[concepts/复数]]表为三种等价形式，并在各运算中平行给出公式。依据本源（式 1.131–1.141），三种形式在各类运算中的适用性对比如下：

| 维度 | 代数形式 z = a + ib | 三角形式 z = ρ(cos φ + i sin φ) | 指数形式 z = ρ e^{iφ} |
|------|--------------------|--------------------------------|----------------------|
| 定义式 | (1.131a)、(1.132a) | (1.132b)（正文缺失，反推） | (1.134a) |
| 读出实部/虚部 | 直接（a、b 即实虚部） | 需换算 a = ρ cos φ、b = ρ sin φ | 同三角形式 |
| 读出模/辐角 | ρ = √(a² + b²)，φ 分段计算（1.133） | 直接 | 直接 |
| 加减法 | 逐项合并（1.136），最直接 | 不便 | 不便 |
| 乘法 | 二项式展开（1.137a） | 模乘辐角加（1.137b） | 模乘辐角加（1.137c），书写最简 |
| 除法 | 需共轭实数化分母（1.138a、1.139） | 模除辐角减（1.138b） | 模除辐角减（1.138c） |
| n 次幂 | 二项式公式，"非常不便" | 棣莫弗公式（1.140a） | ρⁿ e^{inφ}（由 1.140a 与 1.134b 导出） |
| n 次根 | 不便 | ω_k 公式（1.141b） | ⁿ√ρ·e^{i(φ+2kπ)/n}（由 1.141b 导出） |
| 共轭 | a − ib（1.135c） | 辐角反号 | e^{−iφ} |

注：表中未标注式号的指数形式幂与 n 次根表达，由[[concepts/欧拉公式]]与相应三角形式公式直接导出，非手册原文明示。

## 结论

- **加减法与相等判定**宜用代数形式：实虚部直接读出、逐项合并，相等即实虚部对应相等。
- **乘、除、幂、开方**宜用三角或指数形式：运算化为[[concepts/复数的模与辐角|模与辐角]]的初等运算；指数形式书写最简洁，[[concepts/棣莫弗公式]]与 [[concepts/复数的n次根]] 公式均以三角形式表述。
- **混合运算**（如手册 1.5.3.4 例题）需在形式间切换：先按代数形式展开，除法处用[[concepts/共轭复数|共轭]]实数化分母，或整体化为指数形式。
- 三种形式经欧拉关系式严格等价，选择纯为运算便利。
