# Lerp 与 Slerp 比较

依据《数学手册（原书第10版）》4.4.3.1（图 4.5 的 (a)/(b) 两图即此对比）：

| 维度 | Lerp（式 4.143） | Slerp（式 4.144） |
|---|---|---|
| 插值路径 | ℝ⁴ 中连接 p、q 的**弦线段**（单位球内部） | S³ 上的**大圆弧**（[[concepts/测地线]]） |
| 是否单位四元数 | 否，须归一化 | 是 |
| 等距性 | 归一化后**非等距**（角速度不均匀） | **等角速**（等距四元数） |
| 公式 | p(1−t) + qt | p(p̄q)^t = p·sin((1−t)φ)/sinφ + q·sin(tφ)/sinφ |
| 前置条件 | 无 | 最短连接需 ⟨p, q⟩ > 0（由式 4.147 即 cosφ > 0） |
| 序列推广 | 书未展开 | [[concepts/Squad]] |

## 归属边界（不可混淆的三件事）

1. 「插值点非等距」是 **Lerp＋归一化** 的缺陷（书称 Lerp「几乎是完美的」，仅此一问题）。
2. 「最短连接条件 ⟨p,q⟩ > 0」是 **Slerp** 的前置条件（转写文本该条件疑有讹误，见 [[queries/4-4-3全节转写讹误清单]]）。
3. 「端点区间未定义」是 **Squad** 的问题。
