# 标量积与向量积性质比较

| 维度 | 标量积（3.248） | 向量积（3.249） |
|---|---|---|
| 结果类型 | 标量 | 向量（垂直于两因子） |
| 交换性 | $\vec a\vec b=\vec b\vec a$（3.250） | $\vec a\times\vec b=-(\vec b\times\vec a)$（3.251，反交换） |
| 与标量相乘 | 结合（3.252a） | 结合（3.252b） |
| 分配律 | 成立（3.254a） | 成立（3.254b，两个方向） |
| 结合律（二重积） | 失效（3.253a） | 失效（3.253b） |
| 特殊值 | $\vec a\vec a=a^{2}$（3.257） | $\vec a\times\vec a=\vec 0$（3.257） |
| 退化判据 | $\vec a\vec b=0\iff$ 正交（3.255） | $\vec a\times\vec b=\vec 0\iff$ 共线（3.256） |
| 几何意义 | $\cos\varphi$ 加权的模积；夹角（表 3.18） | 模 = 平行四边形面积（3.249b）；定向由 [[concepts/右手法则]] |
| 不变性 | 是标量不变量（3.5.1.5(3)j 例 C） | 源文未讨论其变换性质 |
| 笛卡儿公式 | 三项和（3.264） | 基向量行列式（3.265） |
| 仿射计算所需 | 六个度量系数（3.273） | 互反基向量与 $\varOmega$（3.275） |
| 多项式展开 | 直接展开（例 A） | 展开后交换因子须变号（例 B） |

**互补结构**：两积共享分配律与数乘结合律，但在交换性上相反；退化判据互补（正交 vs 共线）；自乘行为相反（平方 vs 零）。两者结合生成 [[concepts/混合积]]（体积）与 [[concepts/拉格朗日恒等式]]。经重算验证的算例见 [[findings/向量乘积定义性质与算例]]。
