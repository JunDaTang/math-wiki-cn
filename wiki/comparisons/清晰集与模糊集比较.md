# 清晰集与模糊集比较

（依据：数学手册(原书第10版) 5.9.1，式 5.326–5.327 与性质 E1。）

| 维度 | 清晰（经典）集 | 模糊集 |
| --- | --- | --- |
| 从属关系 | 二值：$x\in A$ 或 $x\notin A$ | 渐变等级：$\mu_A(x)\in[0,1]$ |
| 刻画函数 | 特征函数 $f_A: X\to\{0,1\}$（式 5.326） | 隶属函数 $\mu_A: X\to[0,1]$（式 5.327） |
| 与逻辑的对应 | 经典的布尔集代数同构于二值命题逻辑（本节断言，对象为经典布尔集代数） | 模糊集是多值逻辑的基本数学工具 |
| 特例关系 | 是隶属等级只取 0 与 1 的模糊集（E1） | 以清晰集为特例（含空集、全集、单元素集） |
| 次级结构 | 无 | 支撑、核、高、容许区间、展形、α-切割、相似、模糊子集等 |
| 相等判据 | 元素相同 | 隶属函数逐点相等（式 5.329） |

## 与 5.7 布尔代数的桥接

本节的定义链条与 5.7 直接衔接：[[二元布尔代数b]]（B={0,1}）上的[[布尔代数]]与[[布尔函数]]刻画二值命题逻辑（「经典的布尔集代数同构于二值命题逻辑」）；模糊逻辑把刻画从属关系的取值从 B={0,1} 换成区间 [0,1]，是多值化的推广（此概括为 wiki 分析的表述，非手册原文）。对照 [[模糊逻辑]]。
