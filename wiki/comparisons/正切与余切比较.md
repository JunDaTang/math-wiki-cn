# 正切与余切比较

依据 [[sources/10-数学手册原书第10版--10-27-三角函数角函数--a2ypwy]]（式 2.68–2.69），tan 与 cot 的图像要素对照如下：

| 性质 | $\tan x$（式 2.68） | $\cot x$（式 2.69） |
|---|---|---|
| 相互关系 | 基准函数 | $\cot x=-\tan\left(x+\frac{\pi}{2}\right)$（反射＋左移 $\frac{\pi}{2}$，已代数验证） |
| 周期 | $\pi$ | $\pi$ |
| 值域 | $\mathbb{R}$ | $\mathbb{R}$ |
| 渐近线 | $x=\left(k+\frac{1}{2}\right)\pi$（cos 零点） | $x=k\pi$（sin 零点） |
| 单调性 | 各支 $\left(-\frac{\pi}{2}+k\pi,\frac{\pi}{2}+k\pi\right)$ 内递增 | $(0,\pi)$ 内递减 |
| 与 x 轴交点（兼拐点） | $A_k=(k\pi,0)$ | $A_k=\left(\left(k+\frac{1}{2}\right)\pi,0\right)$ |
| 拐点切线倾角 | $+\frac{\pi}{4}$ | $-\frac{\pi}{4}$ |
| 极值点 | 无 | 无 |

## 要点

- 渐近线与零点互补：tan 的零点横坐标（$k\pi$）是 cot 的渐近线横坐标，cot 的零点横坐标（$\left(k+\frac{1}{2}\right)\pi$）是 tan 的渐近线横坐标。
- 单调方向相反（tan 各支递增、cot 递减），拐点切线倾角逐 $+\frac{\pi}{4}$ 与 $-\frac{\pi}{4}$ 相反。
- 共同点：周期减半为 $\pi$（相对 sin/cos 的 $2\pi$）、无界、无极值、有垂直渐近线（无穷间断点）。
- 完整公式与验证见 [[findings/正切与余切的周期渐近线单调性与拐点]]。
