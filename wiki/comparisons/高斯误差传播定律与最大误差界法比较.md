# 高斯误差传播定律与最大误差界法比较

《数学手册》16.4.1.3.5 明示检测误差的两种方法（第一种运用统计误差分析、通过最小二乘法平滑；第二种确定绝对误差量的上界），16.4.2 将其一阶统计版本冠名高斯误差传播定律：

| | 高斯误差传播定律（16.219） | 最大误差界（16.207)/(16.208) |
|---|---|---|
| 路线 | 统计（平滑，源于 [[concepts/最小二乘法]]） | 最坏情形（上界，不作平滑） |
| 公式 | $\tilde{\sigma}_f^2=\sum a_j^2\tilde{\sigma}_{\bar{x}_j}^2$（平方和） | $\Delta z_{\max}=\sum\|\partial f/\partial x_i\|\Delta x_i$（绝对值和） |
| 输入 | 各变量均值的方差估计 (16.218) | 各变量误差绝对值上界 Δx_i |
| 假设 | 一阶泰勒、变量随机独立、f 可微（分布任意） | 偏导数存在、误差界已知 |
| 产出 | 标准差，可配置信区间 | 保证界（误差不超过的上界） |
| 平滑 | 测量值经平滑，对给定水平确定置信区间（16.4.1.4） | 对测量值没作平滑 |
| 相对形式 | 幂法则 (16.224) $\tilde{\sigma}_f/f=\sqrt{\sum(b_j\tilde{\sigma}_{\bar{x}_j}/\bar{x}_j)^2}$ | $\delta z_{\max}=\Delta z_{\max}/z\approx\Delta z_{\max}/\bar{z}$（16.208） |

**数值关系**：对同样输入，平方和 ≤ 绝对值和（柯西不等式方向），故统计路线的 σ̃_f 通常小于最坏情形的 Δz_max——前者描述典型散布，后者给出硬上界；两者回答的问题不同，不可互相替代。

**源文定位**：16.4.2.1 末「最大误差的差分」一节明确两路线分工：规定最大误差的 (16.207)/(16.208) 指对测量值没作平滑；用传播定律 (16.219)/(16.222) 时，对测量值 x_j 的平滑意味着对给定水平确定置信区间。复算见 [[findings/式16-216至16-224高斯误差传播定律转录复算]]。
