# 一元与多元泰勒公式比较（式 6.31 vs 式 6.49–6.50）

本比较对照一元泰勒公式（6.1.4，式 6.31，见 [[concepts/泰勒定理]]、[[findings/泰勒公式拉格朗日余项-式6-31]]，依据 [[sources/10-数学手册原书第10版--11-614-微分学基本定理--19qkxf6]]）与其多元推广（6.2.2.3，式 6.49–6.50，见 [[concepts/多元函数的泰勒定理]]，依据本源）。

| 维度 | 一元（式 6.31） | 多元（式 6.49–6.50） |
|---|---|---|
| 展开结构 | $f(x) + f'(x)h + \frac{f''(x)}{2!}h^2 + \dots$ | $f + \frac{1}{i!}\left(h\frac{\partial}{\partial x} + k\frac{\partial}{\partial y}\right)^{i} f + \dots$ |
| 增量记号 | 单一增量 $h$（或 $x - x_0$） | 增量向量 $(h, k)$（m 元为 $(h, k, \dots, l)$） |
| 算子记号 | 无显式算子幂 | 核心特色：微分算子幂按二项式定理展开（式 6.49b，源文明说其语义） |
| 交叉项 | 无 | 混合偏导数项，如 $2\,\frac{\partial^2 f}{\partial x\,\partial y}(x-a)(y-b)$；系数 2 依赖 [[concepts/施瓦茨交换定理]] |
| 拉格朗日余项 | $\frac{f^{(n+1)}(x+\Theta h)}{(n+1)!}\,h^{n+1}$ | $\frac{1}{(n+1)!}\left(h\frac{\partial}{\partial x} + k\frac{\partial}{\partial y}\right)^{n+1} f(x+\Theta h, y+\Theta k)$ |
| 中值点 | $x + \Theta h$（区间内一点） | $(x+\Theta h, y+\Theta k)$（基点与目标点连线上，$0<\Theta<1$） |
| 一阶特例 | n=1 弃余项 ⇒ 切线近似（[[concepts/导数的几何意义]]） | n=1 弃余项 ⇒ 切平面方程（式 6.43b，[[concepts/切平面]]） |
| 形式幂结构 | 与二项式定理对应（参见 [[comparisons/莱布尼茨公式与二项式定理比较]]） | 同一思想升维：算子幂 + 多项式展开 |

## 结构平行的本质（本方解释性推导，非源文明文）

多元公式可视为一元公式沿方向 $(h, k, \dots, l)$ 的限制：令 $g(t) = f(x + th, y + tk, \dots)$，对 $g$ 用一元泰勒公式，则 $g'(t) = (h\frac{\partial}{\partial x} + k\frac{\partial}{\partial y})f$，算子 $h\frac{\partial}{\partial x} + k\frac{\partial}{\partial y}$ 恰为方向导数算子，逐次求导即得式 6.49c–d。这解释了二者余项结构的完全平行，以及多元中值点落在两点连线上的原因。

## 记号差异提示

两侧余项的 $\Theta \in (0,1)$ 取值方式一致；多元新增的内容是算子记号（式 6.49b）及其语义说明——源文在此罕见地明确解释了记号的操作含义（二项式展开算子幂、导数在中心取值），这是 6.1.4 一元表述中所没有的。
