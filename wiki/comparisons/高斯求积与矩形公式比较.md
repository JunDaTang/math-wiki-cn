# 高斯求积与矩形公式权衡比较

## 比较对象

在第二类弗雷德霍姆积分方程的求积离散路线（[[methodology/求积半离散化方法]]）中，两种[[concepts/求积公式|求积公式]]的取舍：左矩形公式（原书 19.3.2.1）与[[concepts/高斯求积公式|高斯求积公式]]（原书 19.3.3.3）。

## 并排比较

| 维度 | 左矩形公式 | 高斯求积公式 |
|---|---|---|
| 节点 | 等距 $x_k = a + h(k-1)$，$h=(b-a)/n$ | $x_k = \frac{a+b}{2}+\frac{b-a}{2}t_k$，$t_k$ 为勒让德多项式根（11.28a） |
| 权值 | $\omega_k = h$（均匀） | $\omega_k = (b-a)A_k$，$A_k$ 见表 11.1（注意：为标准权之半） |
| 节点可否自由选取 | 可以 | 不可以（必须取勒让德根） |
| 精度 | "并非足够精确"（原文评价） | 少节点高精度 |
| 提精度的方式 | 增加节点数 $n$ | 增加 $n$ 即引入更高次勒让德多项式的根 |
| 对方程组的影响 | 维数随 $n$ 线性增大（原文指出的代价） | 同样 $n$ 个未知量，但单节点精度更高 |
| 本节中的用法 | (11.26a)–(11.26c) 半离散示例 | [[methodology/尼斯特伦法]] |

## 权衡论证（原文）

原文的论证链是：矩形公式精度不足 → 为更好近似积分须**增加插值节点数目** → 但随之而来的是**方程组维数的增加** → 因而要**寻找另外的求积公式**——即高斯求积。换言之，在"每节点信息量"意义下，高斯求积以更少节点达到给定精度，从而控制系统规模。

## 实证支撑

尼斯特伦法算例（$n=3$，核 $e^{xy}$）：仅 3 个未知量即达约 $1.5\times10^{-3}$ 的节点值误差（见 [[findings/尼斯特伦法算例指数核复算]]）。本 wiki 未做矩形公式的对照算例，原文亦未给出，"矩形公式精度不足"目前为原文的定性评价。
