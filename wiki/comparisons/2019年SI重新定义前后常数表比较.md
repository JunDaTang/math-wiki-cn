# 2019 年 SI 重新定义前后常数表比较

比较对象：本源 21.2 表（2019 年 SI 基本单位重新定义生效**前**的格局）与重新定义后（2019-05-20 起）的现状。后者为可独立核验的公共背景，非出自本 wiki 已导入文献。

| 常数 | 本源 21.2（前 2019 SI） | 2019 年重新定义后 |
|---|---|---|
| c₀（真空中光速） | 精确（米之定义）：299 792 458 m/s | 仍精确（定义未变） |
| μ₀（真空磁导率） | 精确：4π·10⁻⁷ N/A² | 测量量，≈1.256 637×10⁻⁶ N/A²（CODATA 2018/2022 推荐值，带不确定度） |
| ε₀（真空电容率） | 精确：1/(μ₀c₀²) | 测量量 |
| Z₀（真空特性阻抗） | 精确：μ₀c₀ = 376.730 313 461 Ω | 测量量 |
| e（基本电荷） | 测量：1.602 176 565(35)·10⁻¹⁹ C | 精确：1.602 176 634×10⁻¹⁹ C |
| h（普朗克常数） | 测量：6.626 069 57(29)·10⁻³⁴ J·s | 精确：6.626 070 15×10⁻³⁴ J·s |
| k（玻尔兹曼常数） | 测量：1.380 6488(13)·10⁻²³ J/K | 精确：1.380 649×10⁻²³ J/K |
| N_A（阿伏伽德罗常量） | 测量：6.022 141 29(27)·10²³ /mol | 精确：6.022 140 76×10²³ /mol |
| K_J、R_K、Φ₀、G₀ | 测量（e、h 之组合） | 精确（定义值之组合） |
| F = eN_A | 测量：96485.3365(21) As/mol | 精确 |
| α、α⁻¹、G | 测量 | 仍为测量量（与单位定义无涉） |
| g_n | 精确（约定标准值） | 仍为约定标准值 9.80665 m/s² |

## 结论

- 「精确/测量」格局整体反转：本表五个「（精确）」中 μ₀、ε₀、Z₀ 三项失去精确地位，而 e、h、k、N_A 及其组合常数（含 [[concepts/量子电学计量常数族]] 全族）转为精确。
- 本表数值（CODATA 2010 底色）与 CODATA 2018/2022 推荐值已有多处移动，直接引用须注明「2019 年 SI 重新定义前」之时点。
