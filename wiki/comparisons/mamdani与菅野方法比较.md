# Mamdani 与菅野方法比较

两者同为基于知识的模糊控制设计方法（见 [[模糊控制]]），共享「法则基础 + 模糊化」两步；数学手册 5.9.6.2 明言菅野方法「与 Mamdani 概念的差别在于法则基础和逆模糊化方法」。逐项比较（依据：本来源 5.9.6.1–5.9.6.2、5.9.6.4）：

| 维度 | [[mamdani方法]]（5.9.6.1） | [[菅野方法]]（5.9.6.2） |
|---|---|---|
| 法则后件 | 模糊集 $U^i$（式 5.389） | 清晰线性函数 $u_i=p_0^i+p_1^i x_1+\dots+p_k^i x_k$（式 5.390） |
| 前提 | 误差 $e$、误差变化 $\dot e$ 的语言描述 | 各输入 $x_j$ 的语言描述（可含系统动力学信息） |
| 模糊化 | 测量值与 IF–THEN 前提比较，定出起作用法则及权 | 对每条法则算出 $\mu_i\in[0,1]$ |
| 聚合 | 各权法则以代数运算结合（极大-极小复合，式 5.394） | 无独立聚合步（隐含于加权平均） |
| 输出确定 | **必须逆模糊化**（重心法/极大值准则法，见 [[逆模糊化]]） | **加权平均直接输出**（式 5.391），省去「昂贵的」逆模糊化 |
| 参数确定 | 法则与隶属函数来自专家知识/建模 | 权参数 $p_j^i$ 可由机器学习（如 ANN）确定（源文未展开） |
| 在本节的用例 | 5.9.6.3 [[逆摆]] 完整算例（F=3.95/5.0，已复算） | 5.9.6.4 作为插值控制器的理论基础（式 5.396–5.400） |
| 插值视角 | 输出为模糊集，须经逆模糊化方得数值 | 天然是基于法则的插值器（见 [[基于知识的插值系统]]） |

**共同点**：以 [[法则基础]] 为核心、以 [[模糊化]] 为入口、以权（满足等级/实现等级）调节各法则贡献；控制目标都是使偏差及其变化最小。

**边界提示**：上表中关于 ANN 参数学习与插值性质的表述分别仅见于 5.9.6.2 与 5.9.6.4，不宜互相挪用（源文并未把 ANN 参数学习用于 Mamdani 路线，也未对 Mamdani 输出讨论插值性质）。
