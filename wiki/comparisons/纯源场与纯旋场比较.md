# 纯源场与纯旋场比较

《数学手册(原书第10版)》13.4 把向量场的两个规范成分并列处理，两者构成对偶（依据：13.4.1 与 13.4.2 的平行结构）：

| 维度 | 纯源场 $\vec V_1$（13.4.1） | 纯旋场 $\vec V_2$（13.4.2） |
|---|---|---|
| 别名 | pure source field、无旋源场（irrotational source field） | pure rotation（curl）field、螺线管场（solenoidal field）、无散场 |
| 定义条件 | $\operatorname{rot}\vec V_1\equiv\vec 0$，$\operatorname{div}\vec V_1=q(\vec r)$ | $\operatorname{div}\vec V_2\equiv 0$，$\operatorname{rot}\vec V_2=\vec w(\vec r)$ |
| 场的刻划数据 | 源密度 $q$（散度） | 旋度密度 $\vec w$（旋度），见 [[concepts/旋度密度]] |
| 数据约束 | 无代数约束（仅要求可微与大距离衰减） | 必须 $\operatorname{div}\vec w=0$ |
| 位势类型 | 标量位势 $U$，$\vec V_1=\operatorname{grad}U$ | 向量位势 $\vec A$，$\vec V_2=\operatorname{rot}\vec A$，$\operatorname{div}\vec A=0$ |
| 位势方程 | $\Delta U=q$（(13.129a)） | $\Delta\vec A=-\vec w$（(13.130c)） |
| 积分表示 | $U=-\frac{1}{4\pi}\iiint\frac{q}{\|\vec r-\vec r^*\|}\,\mathrm dv$（(13.129b)，负号） | $\vec A=+\frac{1}{4\pi}\iiint\frac{\vec w}{\|\vec r-\vec r^*\|}\,\mathrm dv$（(13.130d)，正号） |
| 推导依赖 | [[concepts/泊松微分方程]] | (13.97) rot rot 恒等式（未入库回指）＋泊松方程 |
| 点源实例 | 库仑场（除点源外，[[entities/库仑场]]）；牛顿场（类比，除质心外，[[entities/牛顿场]]） | ——（源内未给纯旋场具名实例） |

## 结构对偶

两者都是"位势满足泊松方程＋牛顿位势型积分表示"同一模式的标量/向量实现；符号（$-1/4\pi$ 与 $+1/4\pi$、$q$ 与 $-\vec w$）相配，复算确认各自自洽（见 [[findings/式13-128至13-129b纯源场与位势积分转录复算]]、[[findings/式13-130a至13-130d纯旋场与向量位势转录复算]]）。在 [[concepts/向量场的源旋分解]] 的 (13.133c) 中两者相加重建一般向量场。
