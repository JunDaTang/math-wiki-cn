# 流与映射霍普夫分岔比较

同一现象在流（平衡点）与映射（不动点/周期轨）中的平行结构对照：

| 项目 | 安德罗诺夫—霍普夫（流，式 17.71–17.73） | Neimark-Sacker（映射，式 17.85–17.86） |
|---|---|---|
| 触发 | 共轭复特征值 λ₁,₂(ε) 以 ±iω 穿越虚轴 | 共轭复乘子 ρ,ρ̄(ε) 穿越单位圆 |
| 光滑度 | r≥4 | r≥6（流中环面产生） |
| 共振条件 | 无 | 非共振：ρ(0) 非 q 次单位根（q=1,2,3,4），即 ψ∉{0,π/2,2π/3,π} |
| 正规形式 | ṙ=α′(0)εr+a(0)r³，ϑ̇=ω(0)+ω′(0)ε+b(0)r² | (r,ϑ)↦(|ρ(ε)|r+a(ε)r³, ϑ+ω(ε)+b(ε)r²) |
| 超临界判据 | α′(0)>0 下 a(0)<0；可由 ε=0 处焦点渐近稳定识别 | d:=d|ρ|/dε\|₀>0 且 a(0)<0 |
| 超临界产物 | 稳定极限环（ε>0） | 渐近稳定不变圆 r=√(−dε/a(0))（ε>0） |
| 次临界产物 | 不稳定极限环（ε<0） | 源文未展开 |
| 定理保证 | 安德罗诺夫—霍普夫定理 | Neimark-Sacker 定理（[17.18], [17.3]） |
| 冠名者 | [[安德罗诺夫]]、[[霍普夫]] | [[Neimark]]、[[Sacker]] |
| 流中的意义 | 直接产生极限环 | 周期轨的庞加莱映射生不变圆 ⟹ 流中生不变环面 |

要点：

- 源文把 Neimark-Sacker 直接称为“**映射的超临界霍普夫分歧**”——命名上视二者为同一现象的流/映射版本。
- 结构差异：映射情形需要非共振条件（低阶共振会改变正规形式的可化简性），流情形无此要求；映射的光滑度要求更高（r≥6）。
- 霍普夫分岔通有且余维 1 为源文明言；NS 的余维表述源文未给（框架性归纳：亦为余维 1）。
- 广义霍普夫（Bautin）是流的霍普夫在双参数下的余维 2 推广（[[广义霍普夫分岔]]）。
