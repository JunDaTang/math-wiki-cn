# 双纽线与心脏线比较

两者分别是各自族（卡西尼族、蚌线族）中参数比达到临界值的过渡特例，且都被单独命名并单独设节（2.12.6、2.12.4）。

| 维度 | [[concepts/心脏线]]（蜗线 a = l） | [[concepts/双纽线]]（卡西尼 a = c） |
|---|---|---|
| 所属族 | 蚌线族（[[concepts/帕斯卡蜗线]]的特例） | 卡西尼族（[[concepts/卡西尼曲线]]的特例） |
| 临界含义 | 蜗线奇点从二重点（a > l）切换到孤立点（a < l）的尖点情形 | 卡西尼曲线从两条卵形（a < c）切换到单卵形（a > c）的分界 |
| 原点奇点 | 尖点 | 二重点，同时为拐点（切线 y = ±x） |
| 拓扑 | 单环（带尖点） | 双环（在原点相交） |
| 方程 | (x²+y²)² − 2ax(x²+y²) = a²y²（式 2.237a）；ρ = a(1+cos φ) | (x²+y²)² − 2a²(x²−y²) = 0（式 2.241a）；ρ = a√(2 cos 2φ) |
| 特征量 | S = (3/2)πa²；L = 8a | 每环 S = a²；r = 2a²/(3ρ) |
| 退化一致性 | 极值公式 = 蜗线极值公式取 l = a（cos φ = 1/2 处，内部自洽） | r = 2a²/(3ρ) 与极值点坐标均为卡西尼公式取 a = c 的退化（交叉验证） |

## 共同点

- 都是参数比临界值（l/a = 1、a/c = 1）处的形态突变点；
- 都是族内唯一被单独命名的特例；
- 都以原点为关键奇点，但类型不同：尖点 vs 二重点兼拐点——同一“临界”地位在两族中呈现不同的奇点形态（[[concepts/曲线的奇点三型]]）；
- 隐式方程都以 $(x^2+y^2)^2$ 起头的四阶结构。

## 差异的根源

心脏线的临界性在于“曲线是否穿过极点”（蜗线极径零点个数的变化，由蚌线构造的极径平移控制）；双纽线的临界性在于“两焦点卵形是否相连”（距离乘积常数与焦点距的平衡，由乘积定义控制）。
