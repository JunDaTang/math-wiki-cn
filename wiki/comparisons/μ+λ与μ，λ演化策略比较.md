# （μ+λ）与（μ,λ）演化策略比较

依据《数学手册(原书第10版)》18.2.6.3 与 18.2.6.7.1–18.2.6.7.2（见 [[10-数学手册原书第10版--9-1826-演化策略--1jct9ap]]），(μ+λ) 与 (μ,λ) 是仅用突变产生后代的两种演化策略，区别在选择类型。下表逐项对照，各属性严格归属手册对相应策略的陈述：

| 对照维度 | (μ+λ) 演化策略 | (μ,λ) 演化策略 |
|---|---|---|
| 选择池 | 从候选组 $X_O^k \cup X_P^k$（后代 ∪ 亲本）中选最佳 μ 个 | 仅在 λ 个后裔中挑 μ 个作为下一代 |
| 亲本是否存活 | 亲本参与选择（精英式） | 亲本不再活下来 |
| 参数要求 | 无 λ > μ 的硬性要求（以等概率、允许重复地从 μ 个亲本中选 λ 个母体；μ < λ 时重复选择是必须的） | **必须有 λ > μ** |
| 代际质量 | 从一代到下一代的质量不可能更差 | 后代的目标函数值可能大于亲本的目标函数值 |
| 局部最优 | 能保持已经找出的局部最优（远离最优点要求大的突变，其概率非常小） | 程序可以从局部最优点开始（具逃逸可能） |
| 个体寿命 | 个体可能有无限寿命；可对亲本目标函数值加逐代递增的惩罚项模拟变老 | 亲本每代被替换 |
| 选择压力（式 18.94） | $S = (\lambda+\mu)/\mu$ | $S = \lambda/\mu$ |
| 与 (1+1) 的关系 | (μ+λ) 策略是 (1+1) 策略的推广 | — |

## 共同框架

两者共享同一算法骨架（[[演化策略基本迭代流程]]）与突变算子（式 18.87）：从当前一代 μ 个亲本出发，经突变产生 λ 个后代，再按各自的选择池规则选出 μ 个下一代亲本。

## 权衡解读

保持局部最优（+）与允许劣化以逃逸（,）是**设计权衡**而非矛盾，由 [[选择压力]] 概念统摄：S 接近 1 时选择几乎无影响，λ ≫ μ 时当前个体集合中只有少数几个存活到下一代、选择压力很大。带重组的推广为 (μ/ρ+λ)、(μ/ρ,λ)（见 [[中间重组与离散重组]]）。

## 记号疑点

18.2.6.3 与 18.2.6.7.1 主体使用 (μ+λ)/(μ,λ) 顺序，而 18.2.6.7.1 末段与式 18.94 使用 (λ+μ)/(λ,μ)；「$(\lambda+\mu)$ 策略的特点是它能保持已经找出的局部最优」与 18.2.6.7.1 对 (μ+λ) 的描述吻合，同一策略的可能性大，见 [[λ+μ与μ+λ记号顺序之辨]]。
