# 面积函数与反三角函数比较

两类函数同为初等超越函数的反函数：[[concepts/面积函数]]（反双曲函数）反转 [[concepts/双曲函数]]（手册 2.10 节），[[concepts/反三角函数]] 反转 [[concepts/三角函数]]（手册 2.8 节）。本页对照二者的平行与差异；反三角函数一侧的细节依据本维基已入库的 2.8 节相关页面。

## 命名与前缀

| | 面积函数 | 反三角函数 |
|---|---|---|
| 前缀 | Ar-（Arsinh、Arcosh、Artanh、Arcoth） | arc-（arcsin、arccos、arctan、arccot） |
| 前缀含义 | 面积：值为双曲线扇形的面积（2.10 节明言） | 弧：值为圆弧所对的角 |
| 几何载体 | 双曲线 | 圆 |

（前缀的拉丁语源对照为独立可查的背景知识；「双曲线扇形面积」一说则直接出自手册 2.10 节。）

## 多值性的处理口径

- **反三角函数**：按 [[concepts/主值]] 区间取单值（如 arccos 主值取 $[0, \pi]$），其余值经约化公式表出（见 [[findings/约化为主值公式及arccos奇偶分裂]]）。
- **面积函数**：手册对 Arcosh 直接并列两支 $y = \operatorname{Arcosh} x$ 与 $y = -\operatorname{Arcosh} x$（式 2.208），**未称任何一支为主值**；Arcoth 则按定义域的两个区间呈现两分支（式 2.210）。这是两族函数在多值处理上的口径差异，也连带影响和差公式的形态（面积侧仅式 2.220 减法形式带隐藏条件，反三角侧需整套分段补偿，见 [[findings/arcsin与arccos的和差公式]]）。

## 定义域与值域结构

| 函数对 | 反三角（主值） | 面积函数 |
|---|---|---|
| 正弦族 | arcsin: [−1, 1] → [−π/2, π/2] | Arsinh: ℝ → ℝ |
| 余弦族 | arccos: [−1, 1] → [0, π] | Arcosh: [1, ∞) → 两支 |
| 正切族 | arctan: ℝ → (−π/2, π/2) | Artanh: (−1, 1) → ℝ |
| 余切族 | arccot:（主值区间见 [[concepts/反余切函数]]） | Arcoth: (−∞,−1)∪(1,+∞) → y ≠ 0 |

（反三角一侧的区间依据 [[findings/反三角函数单调区间分解与定义域值域表]]；面积函数一侧依据表 2.8。）

值得注意的对偶：arctan 与 Artanh 的定义域/值域角色恰好对调（arctan 定义域 ℝ、值域有界；Artanh 定义域有界、值域 ℝ），源于 tan 与 tanh 的值域对调。

## 表示能力

- **面积函数**有简洁的实自然对数表示（式 2.211–2.214，见 [[findings/面积函数的自然对数表示]]），使其成为 [[concepts/对数函数]] 的直接复合应用实例。
- **反三角函数**：手册 2.8 节未给出对应的对数表示（其代数表示需借助复对数，此为独立可查的背景知识，非手册陈述）。

## 奇性与负角公式

- **面积函数**：Arsinh、Artanh、Arcoth 为奇函数（式 2.222–2.224）；Arcosh 非奇非偶、无对应式。
- **反三角函数**：arcsin、arctan、arccot 的负角公式为奇对称形态，arccos 的负角公式为 π−补形态（$\arccos(-x) = \pi - \arccos x$，见 [[findings/负角公式的奇对称与π补两类形态]]）。

两侧均以「余弦族成员」为例外成员，但例外的方式不同：arccos 有定义域但公式带 π 补偿，Arcosh 则在 $x < 1$ 处直接无定义。

## 覆盖范围

- 双曲函数侧（2.9 节）定义了六个函数（含 sech、csch），但面积函数侧（2.10 节）只定义四个，Arsech/Arcsch 缺席（见 [[queries/表2-8为何不含面积正割与面积余割]]）。
- 反三角函数侧（2.8 节）为四个（arcsin、arccos、arctan、arccot）。

## 总览比较

| | 面积函数 | 反三角函数 |
|---|---|---|
| 反转对象 | 双曲函数 | 三角函数 |
| 命名理据 | 双曲线扇形面积 | 圆弧/角 |
| 多值处理 | 双支并列（Arcosh）、分支呈现（Arcoth），无主值术语 | 主值区间 + 约化公式 |
| 实对数表示 | 有（式 2.211–2.214） | 手册未给 |
| 和差公式 | 无分段补偿（除 2.220 减法形式的隐藏条件） | 需分段体系 |
| 函数个数 | 4 | 4 |
