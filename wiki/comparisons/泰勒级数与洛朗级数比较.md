# 泰勒级数与洛朗级数比较

《数学手册(原书第10版)》14.3.2 与 14.3.4 分别建立解析函数的两种幂级数展开。二者同属“解析函数的级数刻画”，但展开区域、指数范围与系数来源不同。

| 维度 | 泰勒级数 (14.48a–c) | 洛朗级数 (14.50a/b) |
|---|---|---|
| 展开前提 | 区域 $G$ 内解析，任取 $z_0 \in G$ | 以 $z_0$ 为心的两同心圆周之间的圆环内解析 |
| 展开区域形状 | 收敛圆（圆盘）内部 | 收敛圆环 |
| 指数范围 | $n \geq 0$，仅非负幂 | $n \in \mathbb{Z}$，双向无穷 |
| 系数公式 | $a_n = f^{(n)}(z_0)/n!$（14.48b） | $a_n = \frac{1}{2\pi\mathrm{i}}\oint_C \frac{f(\zeta)}{(\zeta-z_0)^{n+1}}\mathrm{d}\zeta$（14.50b，对全体整数 $n$） |
| 唯一性 | 区域内展开唯一 | 圆环内系数由 (14.50b) 唯一确定 |
| 收敛域确定 | 收敛圆（14.3.2 表述见 [[queries/14-3-2泰勒收敛圆与G内切圆仅为下界之辨]]） | 定义域内整个包含的最大圆环 |
| 典型算例 | 几何级数 $1/(1-z)=\sum z^n$；14.5.2 初等函数（前向引用） | $\frac{1}{(z-1)(z-2)}$ 于 $1<\lvert z\rvert<2$ |
| 与奇点的关系 | 收敛圆内部无奇点，刻画解析性 | 主部（负幂部分）刻画奇点性状，是三分类与 [[concepts/留数]] 的基础 |

## 关系

- 泰勒级数是洛朗级数主部为零（$a_n = 0,\ n < 0$）的特例：14.3.5.1 第 1 条正是据此把“无负幂”判为可去奇点；
- 反向地，洛朗级数在不含奇点的子圆盘上退化为泰勒级数；
- 两者的收敛边界都由奇点位置划定（圆或圆环），并通过 [[concepts/解析延拓]] 相互衔接。
