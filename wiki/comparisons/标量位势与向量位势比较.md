# 标量位势与向量位势比较

源内 13.4.2 明确以标量位势为模板命名向量位势（"正如无旋场 $\vec V_1$ 的位势一样，$\vec A$ 形式地满足泊松微分方程，并且这就是为什么它被称为向量位势"）。两者对照（依据：13.4.1 的 (13.129a)(13.129b) 与 13.4.2 的 (13.130b)–(13.130d)）：

| 维度 | 标量位势 $U$ | 向量位势 $\vec A$ |
|---|---|---|
| 所属场 | 纯源场 $\vec V_1$（无旋） | 纯旋场 $\vec V_2$（无散） |
| 场与位势的关系 | $\vec V_1=\operatorname{grad}U$（数学惯例；物理惯例取负，见 [[concepts/位势符号约定]]） | $\vec V_2=\operatorname{rot}\vec A$ |
| 位势方程 | $\Delta U=q(\vec r)$ | $\Delta\vec A=-\vec w$ |
| 规范条件 | 无 | $\operatorname{div}\vec A=0$ |
| 积分表示 | $U=-\frac{1}{4\pi}\iiint\frac{q(\vec r^*)}{\|\vec r-\vec r^*\|}\,\mathrm dv$（(13.129b)） | $\vec A=+\frac{1}{4\pi}\iiint\frac{\vec w(\vec r^*)}{\|\vec r-\vec r^*\|}\,\mathrm dv$（(13.130d)） |
| 数据约束 | $q$ 无代数约束 | $\operatorname{div}\vec w=0$ |
| 推导工具 | 泊松方程＋无旋性 | (13.97) rot rot 恒等式（未入库回指） |
| 叠加性 | $U=\sum U_\nu$（(13.133a)，源内显式） | 源内未显式陈述 $\vec A$ 的叠加（可由积分线性性推出，属推断） |

## 一致性说明

两积分公式符号相反（$-1/4\pi$ 与 $+1/4\pi$），与两方程右端符号相反（$q$ 与 $-\vec w$）相配：复算确认 $\Delta U=q$ 与 $\Delta\vec A=-\vec w$ 均由核的性质（分布意义下 $\Delta(1/|\vec r-\vec r^*|)=-4\pi\delta$，推断性机制，见 [[concepts/狄拉克测度与狄拉克分布]]）成立。
