# 弗雷德霍姆与沃尔泰拉方程诺伊曼级数收敛性比较

诺伊曼级数作为第二类积分方程的解法，在弗雷德霍姆情形（11.2.2）与沃尔泰拉情形（11.4.3）中的收敛条件存在根本差别：前者受 |λ| 型充分条件限制，后者若有解则对任意 λ 收敛。这是《数学手册》原文自觉作出的对照（“与弗雷德霍姆积分方程不同……”）。弗雷德霍姆一侧的主张来自 [[sources/10-数学手册原书第10版--15-1122-逐次逼近法诺伊曼级数--1pfpk9w]]，沃尔泰拉一侧来自 [[sources/10-数学手册原书第10版--12-114-沃尔泰拉积分方程--18y4nui]]。

## 对照表

| 方面 | 第二类弗雷德霍姆方程（11.2.2） | 第二类沃尔泰拉方程（11.4.3） |
|---|---|---|
| 收敛条件 | 需 |λ| 型充分条件（两种估计：|λ|<1/(max\|K\|·(b−a)) 型与 |λ|·max∫\|K\|dy<1 型） | 若方程有解，与 λ 的值无关地收敛 |
| 收敛机理 | 核范数的几何级数型估计 | 迭代核三角递推带来的 $(x-y)^{n-1}/(n-1)!$ 阶乘衰减 |
| 前提 | 级数收敛即给出解 | 命题以“若有解”为条件（[a,∞) 上存在性非自动） |
| 例证 | xy 核算例在 \|λ\|<3 内收敛、λ=3 为本征值处失效（[[findings/xy核算例全链复算与本征值独立验证]]） | $e^{x-y}$ 核：级数为 $e^{(x-y)(\lambda+1)}$，对任何 λ 收敛（[[findings/式11-61至11-62e沃尔泰拉诺伊曼级数与指数核算例复算]]） |
| 理论后果 | λ 落入本征值倒数附近时级数失效，须诉诸 [[concepts/弗雷德霍姆定理]] 的二择一 | 无 λ 限制，与 [[concepts/沃尔泰拉方程的存在唯一性定理]] 的无条件可解性相呼应 |

## 分析

- **差别根源在积分域**：弗雷德霍姆的迭代核在整个方形域上累加，只能做范数估计；沃尔泰拉的迭代核限制在三角域并逐次收缩（$K_n$ 的积分限 $\int_y^x$ 随复合而变窄），产生阶乘衰减。原书对一般情形未给证明，定理为陈述性；$e^{x-y}$ 核算例提供了直接例证。
- **方法分化而非矛盾**：两节的结论各自正确，但适用范围不同——不应把 11.2.2 的 |λ| 条件误加于沃尔泰拉情形，也不应把沃尔泰拉的任意 λ 收敛误推于弗雷德霍姆情形。类似的方法分化也出现在数值解法上：[[concepts/高斯求积公式]] 在 11.2.4（弗雷德霍姆）是高精度首选，在 11.4.5（沃尔泰拉）被结构性排除（见 [[methodology/沃尔泰拉积分方程数值解法]]）。
- **“若有解”的前提不可省略**：沃尔泰拉命题的条件式表述意味着级数收敛不能替代存在性论证，尤其在 $I=[a,\infty)$ 上。
