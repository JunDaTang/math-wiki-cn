# 贝塞尔不等式与帕塞瓦尔等式比较

| 维度 | [[concepts/贝塞尔不等式]] (12.129) | [[concepts/帕塞瓦尔等式]] (12.130) |
|---|---|---|
| 陈述 | Σ∣c_k∣² ⩽ ‖x‖² | Σ∣(x,e_n)∣² = ‖x‖² |
| 成立条件 | 任意正交规范系、任意 x（无条件） | 当且仅当正交规范系完备（等价命题 e)） |
| 方向 | 从 H 到 ℓ² 的上界（系数能量不超过元的能量） | 能量守恒（系数空间与原空间保范对应） |
| 信息 | 保证傅里叶系数自动属于 ℓ² | 配合 [[concepts/里斯-费希尔定理]] 实现 H ≅ ℓ²（完备系时） |
| 退化差距 | ‖x‖² − Σ∣c_k∣² = ‖x − x₀‖²（x₀ 为 x 在 H₀ 上的投影） | 差距为零 ⟺ x ∈ H₀ ⟺ 系完备时对一切 x 成立 |

## 取等的刻画

贝塞尔不等式对给定 x 取等 ⟺ x 属于 H₀ = lin{e_n}‾；对一切 x 取等 ⟺ 系完备 ⟺ 系是基（等价命题 a)–e)，见 [[concepts/完备正交系与希尔伯特基]]）。帕塞瓦尔等式因此可视为「贝塞尔不等式的取等条件被系统整体满足」的陈述。

## 双元形式

帕塞瓦尔有双元推广 (12.131)：(x,y) = Σ c_n d̄_n（广义帕塞瓦尔）；贝塞尔无对应的双元形式（仅有单边估计）。
