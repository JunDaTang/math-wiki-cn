# 中心场与轴向场比较

两类特殊[[标量场]]的对照（依据 13.1.2.2–13.1.2.3）：

| 维度 | 中心场 | 轴向场 |
|---|---|---|
| 又名 | 中心对称场、球面场（central symmetric / central / spherical field） | 柱面对称场、轴对称场、轴向场（cylindrically symmetric / axially symmetric / axial field） |
| 对称元素 | 固定点：中心 $C(\vec{r}_1)$（极点） | 固定直线：场的轴（取为 $z$ 轴） |
| 不变量 | 离中心的距离 $\overline{CP} = \|\vec{r}\|$ | 离轴的距离 $\rho = \sqrt{x^2+y^2}$ |
| 一般公式 | $U = f(\|\vec{r}\|)$（式 13.7a） | $U = U(\rho)$（式 13.9b） |
| 坐标约简 | $U(\sqrt{x^2+y^2+z^2}) = U(\sqrt{\rho^2+z^2}) = U(r)$（式 13.9a） | $U(\sqrt{x^2+y^2}) = U(\rho) = U(r\sin\vartheta)$（式 13.9b） |
| 典型例子 | 点状源的强度场 $U = c/r^2$（式 13.7b，如点光源亮度场） | — |
| 最方便坐标系 | 球面坐标 | 柱面坐标 |
| 等值面 | 同心球面 | 同轴柱面 |
| 向量对应物 | [[中心向量场与球面向量场]] | [[柱面向量场]] |

## 共性

- 两者都是按"等值集为标准曲面族"组织的特殊标量场，坐标表示都约化为**一元函数**；
- 命名上各有三个同义名称（对称性描述 + 简称）；
- 球面坐标与柱面坐标之间的桥梁：$\rho = r\sin\vartheta$（式 13.9b 的末段即体现此关系）。

等值面的例子归档见 [[等值面与等值线]]；复算见 [[式13-6至13-11标量场与等值面线转录复算]]。
