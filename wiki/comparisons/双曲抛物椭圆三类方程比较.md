# 双曲型、抛物型与椭圆型方程比较

依据 [[二阶偏微分方程的分类]]（手册约定 δ = AC − B²），三类方程的对照：

| 维度 | 双曲型 | 抛物型 | 椭圆型 |
|---|---|---|---|
| 判别式（手册约定） | δ < 0 | δ = 0 | δ > 0 |
| 特征线 | 两族实特征 | 一族实特征 | 无实特征（复共轭） |
| 典范形式 | u_ξξ − u_ηη + … = 0，或 u_{ξ₁η₁} + … = 0 | u_ηη + … = 0 | u_ξξ + u_ηη + … = 0 |
| 常系数简单形式 | v_tt − Δv + kv = g（式 9.90） | —（恰一个 κᵢ 为零） | Δv + kv = g（式 9.89） |
| 典型方程 | [[弦振动方程]]、[[电报方程]] | [[热传导方程]] | [[拉普拉斯方程与拉普拉斯算子]]（Δu = 0） |
| 典型定解问题 | 柯西问题（初始曲线上的值与非切向导数） | 初边值问题（初始温度 + 边界条件） | [[狄利克雷问题]]（边界取值） |
| 手册给出的积分法 | [[黎曼方法]]、[[分离变量法]]（算例 A/B/C） | [[分离变量法]]（算例 E，连续谱） | [[格林函数与格林方法]]、[[分离变量法]]（算例 D） |

补充：常系数情形 κᵢ 两种符号各至少出现两次为超双曲型；δ 在区域内变号为混合型（见分类页）。注意判别式符号约定与通行教材方向相反，见 [[comparisons/判别式两种符号约定比较]]；三类方程在算例层面的差异见 [[comparisons/分离变量法五算例比较]]。
