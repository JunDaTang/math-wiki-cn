# 拓扑熵与测度熵比较

数学手册 17.2.2 将两种熵配对给出：[[concepts/拓扑熵]]（17.2.2.1）是**测度无关**的复杂性度量，[[concepts/测度熵]]（柯尔莫哥洛夫—赛奈熵，17.2.2.2）是**依赖不变测度**的信息量增长率。

## 定义口径对照

| | [[concepts/拓扑熵]] | [[concepts/测度熵]] |
|---|---|---|
| 基础对象 | 紧致度量空间上的连续映射 | 支撑在吸引子上的不变概率测度 $\mu$ |
| 构造 | $n$ 步距离 $\rho_n$（式 17.36）下的 $\varepsilon$-**分离集**最大基数 $N(\varepsilon,\rho_n)$ | 方体分割下的**符号序列**信息量 $H_N$（式 17.37） |
| 定义 | $h(\varphi)=\lim_{\varepsilon\to0}\lim_{n\to\infty}\frac{1}{n}\ln N(\varepsilon,\rho_n)$ | $h_\mu=\lim_{\varepsilon\to0}\lim_{N\to\infty}\frac{H_N}{\tau N}$ |
| 直观 | 轨道分离速率（复杂性） | 重复试验中信息量的平均增长率 |
| 依赖性 | [[concepts/拓扑共轭|共轭]]不变、不依赖度量 | 依赖所选不变测度 |

## 关系

- **不等式**：$h_\mu\leqslant h(\varphi)$ 总成立。
- **变分原理**：某些情形下 $h(\varphi)=\sup\{h_\mu\}$（手册措辞偏保守，见 [[queries/变分原理在某些情形下措辞之辨]]）。
- **共同性质**：$h(\varphi^n)=n\,h(\varphi)$；同胚时 $h(\varphi^k)=|k|\,h(\varphi)$；流的熵取 $h(\varphi^t):=h(\varphi^1)$（手册明确对拓扑熵给出，测度熵沿同一时间规范化）。

## 算例对照

| 系统 | $h(\varphi)$ | $h_\mu$ |
|---|---|---|
| [[concepts/伯努利转移映射]]（勒贝格测度） | $\ln 2$ | $\ln 2$（两熵相等） |
| 稳定平衡点吸引子（自然测度） | — | $0$ |

计算流程分别见 [[methodology/ε分离集拓扑熵计算流程]] 与 [[methodology/方体分割测度熵计算流程]]。
