# 五类曲线复参数方程比较

源文 14.5.3 以 $z = x(t) + \mathrm{i}y(t) = f(t)$（式 14.91）统一描述曲线，给出五类：

| 曲线 | 参数方程 | 式号 | 指数形式 | 备注 |
|---|---|---|---|---|
| 直线（过 $z_1$，方向角 $\varphi$） | $z = z_1 + t\,e^{\mathrm{i}\varphi}$ | (14.92a) | 单个 $e^{\mathrm{i}\varphi}$ 作方向向量 | $t$ 为实参数 |
| 直线（过 $z_1, z_2$） | $z = z_1 + t(z_2 - z_1)$ | (14.92b) | — | $t = 0, 1$ 分别给出两端点 |
| 圆周（圆心 $z_0$，半径 $r$） | $z = z_0 + r\,e^{\mathrm{i}t}$ | (14.93a/b) | 单个 $e^{\mathrm{i}t}$ | $|z - z_0| = r$；与 14.2 复积分圆周参数化互证 |
| 椭圆（范式） | $z = a\cos t + \mathrm{i}b\sin t$ | (14.94a) | $c\,e^{\mathrm{i}t} + d\,e^{-\mathrm{i}t}$，$c = \frac{a+b}{2}$、$d = \frac{a-b}{2}$（14.94b/c） | 一般形式加平移 $z_1$ 并允许复 $c, d$（14.95） |
| 双曲线（范式） | $z = a\cosh t + \mathrm{i}b\sinh t$ | (14.96) | $c\,e^{t} + \bar{c}\,e^{-t}$，$c = \frac{a+\mathrm{i}b}{2}$、$\bar{c} = \frac{a-\mathrm{i}b}{2}$（14.97/14.98） | 源文无一般位置形式（开放问题） |
| 对数螺线 | $z = a\,e^{\mathrm{i}bt}$ | (14.99) | 单个 $e^{\mathrm{i}bt}$，$b$ 复 | 限定语缺失，见 [[queries/式14-99对数螺线参数限定语缺失之辨]] |

## 统一视角

- 圆周与椭圆都是 $e^{\mathrm{i}t}$ 与 $e^{-\mathrm{i}t}$ 的**线性组合**：$d = 0$ 退化为圆周，$c = d$ 退化为实轴上的线段振动（$z = 2c\cos t$）。
- 双曲线把 $e^{\mathrm{i}t}$ 换成实指数 $e^{t}$，系数改为共轭对 $c, \bar{c}$：共轭性保证轨迹是实系数双曲线。
- 直线与对数螺线则只用**单个**指数项：直线把 $e^{\mathrm{i}\varphi}$ 当常向量（$t$ 作实参数），螺线把指数作用于参数 $t$ 本身。

## 复算与疑点

系数关系 (14.94c)、(14.98) 经直接展开验证：$c\,e^{\mathrm{i}t} + d\,e^{-\mathrm{i}t} = (c+d)\cos t + \mathrm{i}(c-d)\sin t$；$c\,e^{t} + \bar{c}\,e^{-t} = (c+\bar{c})\cosh t + (c-\bar{c})\sinh t$。疑点集中见 [[queries/式14-94c与14-95椭圆参数说明文字疑损]] 与 [[findings/式14-91至14-99五类曲线复参数方程转录复算]]。
