# 共变坐标与反变坐标比较

| 维度 | 反变坐标 $a^{i}$ | 共变坐标 $a_{i}$ |
|---|---|---|
| 定义（分解） | 关于基 $\vec e_i$ 的系数（3.277） | 关于互反基 $\vec e^{i}$ 的系数（3.278） |
| 标量积表示 | $a^{i}=\vec a\vec e^{i}$（3.280） | $a_{i}=\vec a\vec e_{i}$（3.279） |
| 几何意义 | 沿基方向的分解系数 | 沿基方向的投影（方向系数，3.247） |
| 标量积（对方也反变/共变） | $g_{\alpha\beta}a^{\alpha}b^{\beta}$（3.273） | $g^{\alpha\beta}a_{\alpha}b_{\beta}$（3.282） |
| 标量积（对方为对偶型） | $a^{\alpha}b_{\alpha}$（3.284） | $a_{\alpha}b^{\alpha}$（3.285） |
| 度量系数 | $g_{mn}=\vec e_m\vec e_n$（3.270） | $g^{mn}=\vec e^{m}\vec e^{n}$，经余子式公式与 $g_{mn}$ 互逆（3.283） |

**重合特例**（3.281）：笛卡儿系中 $a_x=\vec a\vec i$、$a_y=\vec a\vec j$、$a_z=\vec a\vec k$，共变 = 反变，因为基自互反（3.272c）。**不得推广**：一般仿射系中两者不同，且「沿轴方向系数 = 坐标」的断言（3.247 后）正因共变 ≠ 反变而失效。

**对偶配对**：3.284/3.285 表明一反变一共变的组合使标量积摆脱度量系数，形式上最简——这是上下指标「配对求和」的效用（见 [[concepts/爱因斯坦求和约定]]）。正文-公式指派的一处张力（3.284）见 [[findings/共变与反变坐标公式组]]。
