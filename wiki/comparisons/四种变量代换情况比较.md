# 四种变量代换情况比较

对照《数学手册(原书第10版)》6.2.4.1 一元变量代换的四种情况（式 6.59–6.62）。源文编号断裂（「la」「lb」后两情况无编号），本表按结构补记为情况 2、情况 3（复原讨论见 [[queries/情况2与情况3编号如何复原]]）。

| 维度 | 情况 1a | 情况 1b | 情况 2 | 情况 3 |
|---|---|---|---|---|
| 代换对象 | 自变量 x → t | 自变量 x → t（隐式） | 因变量 y → u | x、y 同时 → t、u |
| 关系式 | x = φ(t)（6.59a） | Φ(x,t) = 0（6.60） | y = φ(u)（6.61a） | x = φ(t,u), y = ψ(t,u)（6.62a） |
| 一阶导数 | (dy/dt)/φ′(t) | 同 1a | φ′(u)·(du/dx) | A/B（6.62b） |
| 二阶导数 | 式 6.59b 第二式 | 同 1a | 式 6.61b 第二式 | (BA′ − AB′)/B³ |
| 三阶导数 | 式 6.59c（末项因子应为 dy/dt） | 同 1a | 式 6.61c（系数 1, 3, 1） | 源文未给显式公式 |
| 所需条件 | φ′ ≠ 0 | 隐函数定理条件 + φ′ ≠ 0 | u(x) 可导 | B ≠ 0 |
| 数学本质 | 反函数求导 | 隐函数 + 反函数 | 逐阶链式法则 | 参数式求导 + 商法则 |
| 关联概念 | [[concepts/反函数的高阶导数]] | [[concepts/隐函数求导]] | [[concepts/链式法则]] | [[concepts/参数式求导]] |

## 共同点与差异

- 四种情况均把 F 中的各阶导数表为新变量下导数的函数，展至三阶（情况 3 的三阶仅言「类似地可确定」）。
- 1a 与 1b 共用式 6.59，差别只在 φ 的各阶导数如何获得（显式求导 vs 隐函数法则）。
- 情况 2 是唯一不动自变量的代换；情况 3 是唯一同时改两个变量的代换，且已具二元代换（式 6.65）的雏形——后者把「沿曲线的全导数 A、B」推广为「偏导数的线性组合」。
- 极坐标代换（式 6.63）可视作情况 3 的实例：取 t = φ、u = ρ（曲线 ρ = ρ(φ)），则 A = ρ cos φ + ρ′ sin φ、B = ρ′ cos φ − ρ sin φ，A/B 即式 6.63b（此对应关系为复算观察，源文未明言）。
- 复算状态：除式 6.59c 末项因子（应为 dy/dt）外全部一致，见 [[findings/一元变量代换四情况公式-式6-59至6-62]]、[[findings/式6-59c末项因子讹误复算判定]]。
