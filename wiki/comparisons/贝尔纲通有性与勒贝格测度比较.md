# 贝尔纲通有性与勒贝格测度比较

手册 17.1.4.3 明确断言「ℝ 中集合的勒贝格测度 λ 和贝尔纲集之间没有关系」，并给出对照集合。

| 集合 | 稠密 | 贝尔纲（手册口径：余密集） | 勒贝格测度 |
|---|---|---|---|
| ℚ（有理数） | 是 | 否（第一纲） | 0 |
| 𝕀（无理数） | 是 | 是 | 满测（余集 ℚ 零测） |
| B（构造算例） | 是 | 是 | 0 |

**三个论断**：

1. **稠密 ≠ 通有**：ℚ 与 𝕀 都稠密，但只有 𝕀 是余密集——刻画[[concepts/通有性|通有性]]必须用贝尔纲结构而非稠密性。
2. **余密集可以零测**：B = ∩_k B_k（围绕 ℚ 的可缩小区间族之交）为余密集而 λ(B)=0（复算见 [[findings/贝尔纲集零测余密集算例复算]]）。
3. **满测可以第一纲**：由同一构造取余集——ℝ∖B 为第一纲（B 余密集）且满测（λ(B)=0）。此为算例的直接推论（源外推导，非手册显式陈述）。

**在动力系统中的意义**：[[concepts/KAM定理|KAM 定理]]的「大多数环面」用的是**测度**口径（ε→0 时余集测度→0），而结构稳定的通有性用的是**贝尔纲**口径——两者不可混同，见 [[concepts/通有性]]。
