# 偶阶与奇阶勒让德多项式表列行为比较

比较对象：[[sources/10-数学手册原书第10版--14-2112-第一类勒让德多项式--1wsng2s|21.12 节]]数值表（x∈[0,1]、步长 0.05、4 位小数）中偶阶列（P₂、P₄、P₆）与奇阶列（P₃、P₅、P₇）的表列行为；P₁(x)=x 即首列自变量，不另列。两族差异的根源是奇偶性 P_n(−x)=(−1)ⁿP_n(x)（见 [[concepts/第一类勒让德多项式]]）。

## 逐项比较

| 方面 | 偶阶（P₂、P₄、P₆） | 奇阶（P₃、P₅、P₇） |
|---|---|---|
| x=0 处取值 | 非零：−1/2、3/8、−5/16，符号随 k 交替 | 恒为零（首行三格均为 0.0000） |
| (0,1) 内零点数 | n/2，即 1、2、3 | (n−1)/2，即 1、2、3（另含零点 x=0，恰为网格端点，不引起表内符号变化） |
| 表内符号变化数 | 等于零点数 | 等于零点数 |
| 每列「+」标注数 | 1、2、3（合计 6） | 1、2、3（合计 6） |
| x=1 处（末行） | 1.0000 | 1.0000 |
| 由奇偶性外推 x=−1 | +1 | −1 |
| 半单位舍入值分布 | P₂ 列奇数格点集中全部 10 个半单位值 | 无 |

## 成对结构

相邻偶、奇两阶在表列行为上高度成对：

1. **零点数相同**：P_{2k} 在 (0,1) 内有 k 个零点，P_{2k+1} 亦有 k 个，故 (P₂,P₃)、(P₄,P₅)、(P₆,P₇) 每对的「+」标注数两两相等，两族加号总数同为 6、合计 12（[[findings/21-12加号标注零点邻值规律]]）。
2. **原点附近同号出发**：由 21.12 节闭式求导可验 P₃′(0)=−3/2、P₅′(0)=15/8、P₇′(0)=−35/16，且 P₃′(0)=3·P₂(0)、P₅′(0)=5·P₄(0)、P₇′(0)=7·P₆(0)，故表中 P₂ 与 P₃ 皆自负值出发、P₄ 与 P₅ 皆自正值出发、P₆ 与 P₇ 皆自负值出发。
3. **端点归宿相同**：两族在 x=1 处同归 1.0000。

## 与复算的交叉意义

每列符号变化数等于该多项式 (0,1) 内零点数这一关系对两族一致成立，构成 [[methodology/多项式闭式逐点复算法]] 的结构性锚点；P₇(0.95)=+0.0112 为紧邻零点 0.94911 的微小正值，是最高奇阶列的边缘印证（[[findings/21-12数值表全表闭式逐点复算]]）。
