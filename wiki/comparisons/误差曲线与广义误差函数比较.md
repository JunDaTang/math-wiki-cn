# 误差曲线与广义误差函数比较

手册 2.6.5 明言广义误差函数 $y = a\mathrm{e}^{bx+cx^{2}}$（c ≠ 0）的图像「可以看作是误差函数 (2.58) 的推广」。二者的关系是**特例—推广**：误差曲线 $\mathrm{e}^{-(ax)^{2}}$ 是广义误差函数在首系数 a = 1、b = 0、c = −a₀² 处的特例（注意式中两个 a 含义不同：a₀ 是误差曲线自身的参数）。

| 要素 | 误差曲线 $y = \mathrm{e}^{-(ax)^{2}}$ | 广义误差函数 $y = a\mathrm{e}^{bx+cx^{2}}$ |
|---|---|---|
| 参数个数 | 1（a） | 3（a, b, c，c ≠ 0） |
| 对称性 | 关于 y 轴（x = 0） | 关于铅直直线 $x = -\frac{b}{2c}$ |
| 极值 | 极大值 1 于 (0, 1) | c > 0 极小、c < 0 极大，顶点值 $a\mathrm{e}^{-\frac{b^{2}}{4c}}$ |
| 拐点 | $\left(\pm\frac{1}{a\sqrt{2}},\ \frac{1}{\sqrt{\mathrm{e}}}\right)$，恒两个 | 仅 c < 0 时两个：$\left(\frac{-b\pm\sqrt{-2c}}{2c},\ a\mathrm{e}^{\frac{-(b^{2}+2c)}{4c}}\right)$ |
| 渐近线 | x 轴 | c < 0 时 x 轴；c > 0 时无 |
| 与 x 轴交点 | 无 | 无 |

## 退化验证

- 取 b = 0、c = −1、a = 1：广义误差函数退化为 $\mathrm{e}^{-x^{2}}$，顶点值 1、拐点 ±√2/2、拐点值 e^{−1/2}，与 2.6.3 的 a = 1 情形完全吻合；
- 一般地取 a = 1、b = 0、c = −a₀²：广义公式给出拐点横坐标 ±1/(a₀√2)、纵坐标 1/√e（与 a₀ 无关），亦与 2.6.3 一致。

这两次退化核对本身就是「误差曲线 ⊂ 广义误差函数」的证明。

## 术语警示

两名称均为手册内部用语，指 $\mathrm{e}^{(\cdot)}$ 型钟形曲线及其参数化推广，**均与标准特殊函数 erf（误差函数）不同名不同义**（背景知识，可独立查证：$\mathrm{erf}(x) = \frac{2}{\sqrt{\pi}}\int_0^x \mathrm{e}^{-t^{2}}\,\mathrm{d}t$，是曲线的积分而非曲线本身）。另注意手册 (2.61) 两处疑误：[[式2-61配方因子4c平方是否应为4c]]、[[广义误差函数情形a极小值是否漏负号]]（情形 a) 顶点值应与情形 b) 统一为 $a\mathrm{e}^{-\frac{b^{2}}{4c}}$）。
