# 逐次逼近法与第一类迭代法比较

数学手册 11.2.2 的「逐次逼近法」（第二类方程，诺伊曼级数）与 11.3.6 的「迭代法」（第一类方程）名称相近，但机理完全不同；二者的适用范围、收敛条件与结论**不可互相转述**。本页右栏依据 11.3.6（本页 sources），左栏依据已入库的 11.2.2。

## 对照表

| 维度 | 逐次逼近法（11.2.2，第二类） | 迭代法（11.3.6，第一类） |
|---|---|---|
| 适用方程 | 第二类：φ − λKφ = f | 第一类：f = ∫Kφdy（11.54a） |
| 迭代序列 | 解的逼近序列 φ_n（[[concepts/皮卡迭代法]] 型），以 [[concepts/迭代核]] 表达 | 函数系 α_n、β_n（基函数生成序列），**不**产生解的逼近 |
| 起步 | φ₀ = f（由右端出发逼近解） | α₀ = f（由右端生成基） |
| 递推结构 | φ_n = f + λKφ_{n−1} 型；核的迭代 K_n | β_n = ∫K(x,y)α_{n−1}dx、α_n = ∫K(x,y)β_ndy（11.54b,c） |
| 级数对象 | [[concepts/诺伊曼级数]] Σλⁿ⁻¹K_nf → 解 φ | 解级数 φ = Σc_nβ_n^*（11.54f），系数由矩量等式 (11.54d) 与 b_nj 表出（11.54g） |
| 收敛/可解条件 | 核范数型小参数条件（两种收敛估计，式 11.12–11.13d） | 两条充要条件 (11.55a,b)，不含小参数 |
| 产物 | 迭代序列的极限即解 | 系数全由已知数据算出；条件满足时级数即为 L² 解 |

## 机理对比

- **逐次逼近法**的本质是构造 (I − λK)⁻¹ = Σ(λK)ⁿ：把解表示为几何型算子级数，收敛要求 λ 或核范数足够小——小参数是硬前提。
- **迭代法**的本质是由数据 f 生成适配核的函数系（β_n = T*α_{n−1}、α_n = Tβ_n）并把解投影到该系上：不需要小参数，代价是可解性受 (11.55a,b) 限制——(11.55a) 要求 f 落在生成系张成的闭包内，(11.55b) 要求级数在 L² 中收敛。

## 现代对应（分析者注记，非手册内容）

- 11.3.6 迭代法中 α_n = (TT*)ⁿf，span{α_n} 即由 f 生成的 Krylov 子空间；该方法即矩量法（moment method）/Krylov 子空间方法。
- 11.3.5 的双对角化构造（[[methodology/核矩阵双对角化构造流程]]）是 Golub–Kahan 双对角化的无穷维对应；两者结合与现代 LSQR 型算法的思想链相呼应。
- 第一类方程的 Krylov/矩量型方法与正则化理论（如 Tikhonov 正则化）密切相关；手册未提及此联系。
