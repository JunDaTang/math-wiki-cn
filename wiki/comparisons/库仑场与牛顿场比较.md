# 库仑场与牛顿场比较

《数学手册(原书第10版)》13.4.3 把库仑场与牛顿场并列为点状源向量场的两个例子（"无旋场也是螺线管场，除了在源点处"），且都是 [[concepts/中心场]] 型径向 $1/r^2$ 场。但源内对二者的处理详略不对称（依据：13.4.3.1 与 13.4.3.2 的原文）：

| 维度 | 库仑场（13.4.3.1） | 牛顿场（13.4.3.2） |
|---|---|---|
| 力律 | $\vec F_C=\frac{1}{4\pi\varepsilon_0}\frac{q_1q_2}{r^2}\vec e_r=e q_2\frac{\vec r}{r^3}$，$e=\frac{q_1}{4\pi\varepsilon_0}$（(13.131a)） | $\vec F_N=\gamma\frac{m_1m_2}{r^2}\vec e_r$（(13.132)） |
| 常数 | 电常数 $\varepsilon_0$（回指表 21.2） | 引力常数 $\gamma$（回指表 21.2） |
| 源强度记号 | 显式定义 $e=q_1/(4\pi\varepsilon_0)$ | 未定义对应记号 |
| 场强与位势 | 显式给出 $\vec E_C=-\operatorname{grad}U$，$U=e/r$（(13.131b)） | 未给出（仅有类比断言） |
| 通量 | 显式给出 $4\pi e$ / $0$ 二值（(13.131c)） | 未给出（仅有类比断言） |
| 无旋性 | 显式陈述（(13.131d)） | 未单独陈述（由类比断言覆盖） |
| 符号讨论 | 异号相吸、同号相斥 | 无符号讨论 |
| 源量类型 | 电荷 $q$（源内有正负之分的讨论） | 质量 $m$ |

## 类比断言的边界

13.4.3.2 的唯一进一步陈述是："对于库仑场成立的每个关系，类似地对于牛顿场也成立。"这是笼统断言：

- 由类比**可推断**牛顿场同样无旋、除质心外无散、位势为 $1/r$ 型、通量二值等，但这些具体公式源内均未为牛顿场写出，属**推断**而非源断言。
- 类比中 $\varepsilon_0$ 对应 $\gamma$、$q$ 对应 $m$、$e$ 对应 $\gamma m_1$ 之类的对应关系是自然的，但源未明确给出，不应作为源内公式转写。
- 库仑场的正负电荷吸引/排斥讨论在牛顿场侧无对应讨论，类比的适用范围（如质量的符号）源内未界定。
