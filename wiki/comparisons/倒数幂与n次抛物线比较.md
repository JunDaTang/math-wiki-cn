# 倒数幂与 n 次抛物线比较

手册 2.3 的 n 次抛物线（式 2.43–2.44，见 [[concepts/n次抛物线]]，来源 [[sources/10-数学手册原书第10版--6-23-多项式--l0zhnw]]）与 2.4.6 的倒数幂（式 2.50，见 [[concepts/倒数幂]]，来源 [[sources/10-数学手册原书第10版--7-24-有理函数--1pptax7]]）是指数互为相反数的两个幂函数族 y = axⁿ 与 y = ax⁻ⁿ，其图像行为构成系统对照：

| 维度 | n 次抛物线 y = axⁿ（2.3） | 倒数幂 y = a/xⁿ（2.4.6） |
|---|---|---|
| 定义域 | 全体实数 | x ≠ 0 |
| 间断点 | 无 | x = 0（[[concepts/无穷间断点]]） |
| 渐近线 | 无 | 两条坐标轴 |
| 奇偶对称 | n 偶关于 y 轴，n 奇关于原点 | n 偶关于 y 轴，n 奇关于原点（规则完全相同） |
| 极值 | n 偶时在原点处取得极值 | 无极值（源文明示） |
| 远端行为 | x → ±∞ 时按首项发散 | x → ±∞ 时 y → 0 |
| 近原点行为 | 过原点（y(0) = 0） | x → 0 时 y → ±∞ |

核心对偶观察：

- 两族曲线在 x = ±1 处取相同值（y = a），以 |x| = 1 为「交叉带」：|x| > 1 时抛物线升高而倒数幂压向 x 轴，0 < |x| < 1 时正相反。手册对倒数幂的结论「n 越大，趋近 x 轴的速度越快，趋近 y 轴的速度越慢」正是这一对偶的定量表述（见 [[findings/倒数幂的奇偶对称与趋近速度]]）。
- 奇偶对称规则完全同构：n 偶 → [[concepts/偶函数]]（关于 y 轴对称）；n 奇 → [[concepts/奇函数]]（关于原点中心对称）。2.3 对 n 次抛物线记录的伸缩/反射变换（式 2.44）在倒数幂上有平行的结构（|a| 伸缩、a 变号沿 x 轴反射），手册 2.4.6 未单列变换公式。
