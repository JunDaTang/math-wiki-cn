# 样本统计量与总体参数比较

16.3.2.2 开篇的总括性主张：「在总结和分析了给定的样本数据后可推知下述参数是**随机变量分布参数的近似值**」。据此，16.3 的样本统计量（来自数据）与 16.2 的总体/分布参数（来自概率模型）形成系统对照：

| 样本侧（16.3.2，由数据计算） | 总体侧（16.2，由分布定义） | 关系 |
|---|---|---|
| 样本均值 $\bar{x}$，式 (16.126a/b)（[[concepts/样本均值]]） | 期望 $E(X)$（[[concepts/期望]]） | 近似值 |
| 样本方差 $s^2$，除数 $n-1$，式 (16.127a/b)（[[concepts/样本方差]]） | 方差 $\sigma^2$，除数 n / 概率加权（[[concepts/方差与标准差]]） | 近似值；**除数不同** |
| 样本中位数，式 (16.128b)（[[concepts/中位数]]） | 分位数 $p=\tfrac12$（[[concepts/分位数]]） | 特例对应 |
| 极差 $R$，式 (16.129)（[[concepts/极差]]） | （本节未给总体侧对应物） | —— |
| 众数（符号脱落，[[concepts/众数]]） | 「最可能值」的分布侧含义 | 名称对应 |
| 相对频率 $h_j/n$（[[concepts/频数与相对频率]]、[[concepts/直方图]]） | 密度 $f(x)$（[[concepts/密度函数（概率密度）]]） | 实证数值 |
| 累计频率 $F_j$ / 实证分布函数，式 (16.125)（[[concepts/累计频率与实证分布函数]]） | 分布函数 $F(x)$（[[concepts/分布函数]]） | 图形近似 |

## 除数之辨（重点）

样本方差 (16.127a/b) 以 $n-1$ 为除数；16.2.2 入库的总体方差（[[concepts/方差与标准差]]）以 n（或概率加权）为除数。**二者是不同对象的量**（样本统计量 vs 总体参数）：本页仅陈述差异，不将 $n-1$ 性质归于总体方差概念页，反之亦然。

## 前提与边界

- 「近似值」主张的前提：测量序列为无限总体的随机样本（[[concepts/随机样本与无限总体]]）。
- 本节只做描述（给出近似值），不做推断（估计量性质、检验等），推断性内容应在 16.3 后续小节（见 [[queries/16-3-2未入库回指缺口]]）。
