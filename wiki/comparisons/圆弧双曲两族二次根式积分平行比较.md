# 圆弧双曲两族二次根式积分平行比较

## 比较对象

[[数学手册(原书第10版)]] 21.7.2 的三个小节：21.7.2.5（$\sqrt{a^2-x^2}$，157–184）、21.7.2.6（$\sqrt{x^2+a^2}$，185–212）、21.7.2.7（$\sqrt{x^2-a^2}$，213–240）。每族 28 条，第 $i$ 条与第 $i+28$、$i+56$ 条被积函数同形（仅 $X$ 定义不同），构成 28 组一一对应（结构总述见 [[二次根式三族平行结构]]）。本页依据 [[10-数学手册原书第10版--11-2172-无理函数积分--1swy6lt]] 给出代表行对照与符号翻转规律。

## 核函数对应

三个核函数 $\arcsin\frac xa$、$\operatorname{Arsinh}\frac xa$、$\operatorname{Arcosh}\frac xa$ 在各自 $X$ 下导数同为 $\frac{1}{\sqrt X}$，故可在公式中互换换核；符号差异来自 $X' = -2x$（族 5）与 $X' = +2x$（族 6、7）。$\frac1x$ 型条目另有一套核：族 5、6 用 $\ln\frac{a+\sqrt X}{x}$，族 7 用 $\arccos\frac ax$。

## 符号翻转规律

1. $a^2\cdot$核 的符号：157/185/213 为 $+/+/-$（对应 $X' = -2x/+2x/+2x$ 的差异）。
2. 中间两项符号：176/204/232（修正后）为 $(-,-)/(+,+)/(+,-)$；首项 $-\frac{\sqrt{X^3}}{x}$ 三族相同。
3. 整体符号：165/193/221 为 $-/+/+$；178/206/234 为 $+/+/-$。

## 非机械平行处（校勘警示）

- 183 与 211/239 的中间符号不同（各自正确）：平行结构可定位可疑条目，但逐条仍须求导确认。
- 族 7 的 $\frac1x$ 型条目（217、219、224、226、231、233、238、240）用 $\arccos\frac ax$，族 5、6 对应条目（161、163、168、170、175、177、182、184 / 189、191、196、198、203、205、210、212）用 $\ln\frac{a+\sqrt X}{x}$。
