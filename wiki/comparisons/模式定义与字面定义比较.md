# 模式定义与字面定义比较

模式定义与字面定义是 [[entities/mathematica]] 中用 `:=`（SetDelayed，见 [[concepts/延迟赋值（SetDelayed与RuleDelayed）]]）定义函数的两种方式：前者左端含空白（如 `f[x_]`），定义对任意符合结构的实际变元生效；后者左端为字面表达式（如 `f[x]`），仅当输入恰为该符号 x 本身时才符合定义。依据为《数学手册（原书第10版）》20.2.7 节式 (20.21a–e)。

## 对照表

| 方面 | 模式定义 `f[x_] := x^3` | 字面定义 `f[x] := x^3` |
|---|---|---|
| 左端形式 | `f[x_]`，含命名空白 `x_` | `f[x]`，无空白 |
| 符合定义的输入 | 任意 `f[something]`（结构匹配，见 [[concepts/模式（Mathematica）]]） | 仅（固定的、唯一的）输入 `x` 本身 |
| `f[r]` 的结果 | `r^3`（式 20.21b） | `f[r]`（不求值） |
| `f[a] + f[x]` 的结果 | `a^3 + x^3`（式 20.21c） | `f[a] + x^3`（式 20.21e） |
| 依据式号 | (20.21a)(20.21b)(20.21c) | (20.21d)(20.21e) |

## 原文 IO 对照

```mathematica
In[5] := f[x_] := x^3             (* 20.21a：模式定义 *)
In[6] =  f[r]                     →  Out[6] = r^3, 等等   (* 20.21b *)
In[7] := f[a] + f[x]              →  Out[7] = a^3 + x^3   (* 20.21c *)

In[8] := f[x] := x^3              (* 20.21d：字面定义 *)
In[9] := f[a] + f[x]              →  Out[9] = f[a] + x^3  (* 20.21e *)
```

## 会话前提（重要限定）

式 (20.21d–e) 的输出以**新会话**（或先清除 f）为前提：若 `f[x_] := x^3` 与 `f[x] := x^3` 在同一会话中并存，则两条规则同时有效——`f[x]` 命中更特定的字面规则得 `x^3`，而 `f[a]` 仍会经一般模式规则求值为 `a^3`，故相同输入将得 `a^3 + x^3` 而非 `f[a] + x^3`。书中“然而如果”的行文隐含了另起会话的对照实验；复算与引用时应注明此前提（见 [[findings/式20-16至20-21模式定义与替换算例复算]]）。

## 意义

空白的有无决定了定义是“整类表达式的一条规则”还是“单一字面表达式的一条规则”，是 [[concepts/模式（Mathematica）]] 机制在函数定义上的直接体现。在完全形式层面，两者分别为 `SetDelayed[f[Pattern[x, Blank[]]], Power[x, 3]]` 与 `SetDelayed[f[x], Power[x, 3]]`（此为依 Mathematica 语义的推演，非原文转录），可与 [[concepts/Mathematica完全形式与中置算子]] 的记法对照。
