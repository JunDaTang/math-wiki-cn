# 整区、除环与域层级比较

数学手册 5.3.7.1 定义三个层层强化的环类，并在有限情形下合一（韦德伯恩定理）。

## 定义对照

| | 整区 | 除环（斜域） | 域 |
|---|---|---|---|
| 定义 | 有单位元素并且没有零因子的交换环 | $(R \setminus \{0\}, *)$ 是群 | $(R \setminus \{0\}, *)$ 是交换群 |
| 交换 | ✓ | 不要求 | ✓ |
| 有单位元 | ✓ | ✓（群的恒等元） | ✓ |
| 无零因子 | ✓（定义要求） | ✓（非零元可逆 ⟹ 无零因子） | ✓ |
| 非零元皆可逆 | 不要求（如 ℤ） | ✓ | ✓ |

## 包含关系（一般情形）

- 每个域是一个整区，并且也是一个除环（源文明示）；
- 整区与除环互不包含：$\mathbb{Z}$ 是整区但非除环（非零元如 2 在 $\mathbb{Z}$ 中不可逆，由例 A 与定义直接可见）；非交换除环是除环但非整区（不满足交换性）。「四元数体是非交换除环的标准例子」属独立可查的标准背景，本源未给出该例子。

## 有限情形合一

- 反之，每个有限整区以及每个有限除环是一个域（韦德伯恩定理，见 [[findings/韦德伯恩定理陈述与归属]]；手册的归属表述偏宽）；
- 因此在有限情形三类概念重合；无限情形则如上分化。
