# 遍历性与混合性比较

两者都是关于[[concepts/不变测度|不变测度]] $\mu$ 的统计性质（数学手册 17.2.1.2），但强度不同：**混合 ⟹ 遍历**，反之不成立。

## 定义对照

| | [[concepts/遍历性]] | [[concepts/混合性]] |
|---|---|---|
| 判据 | 不变集 $A$（$\varphi^{-t}(A)=A$）满足 $\mu(A)=0$ 或 $\mu(M\setminus A)=0$ | $\lim_{t\to\infty}\mu(A\cap\varphi^{-t}(B))=\mu(A)\mu(B)$（任意博雷尔 $A,B$） |
| 直观 | 系统不可分解为两个正测度不变部分 | 充分长时间后初始集合与目标集合渐近独立 |
| 流的等价形式 | — | $\lim_{t\to\infty}\int[g(\varphi^t)-\bar{g}][h-\bar{h}]\,\mathrm{d}\mu=0$（式 17.33） |

## 蕴含关系

混合 ⟹ 遍历：取混合定义中 $B=A$ 为不变集，得 $\mu(A)^2=\mu(A)$，故 $\mu(A)=0$ 或 $1$。逆命题不成立，标准反例即[[concepts/圆周旋转映射]]（无理旋转遍历而非混合；源文「是混合的」为脱「不」字讹误，见 [[queries/旋转映射是混合的疑脱不字之辨]]）。

## 判据对照

- [[concepts/自相关函数]] $C_h(\tau)$ **不衰减**（周期/拟周期）→ 既非混沌亦不混合；
- $C_h(\tau)$ **快速衰减** → 混沌；
- $C_h(\tau)$ **指数衰减** → 混合（本节判据，故混合强于一般混沌衰减要求）。

## 算例对照

| 系统 | 遍历 | 混合 |
|---|---|---|
| 圆周旋转（$\Phi/2\pi$ 无理，测度 $\lambda/2\pi$） | 是 | **否**（源文断言为讹） |
| [[concepts/伯努利转移映射]] | 是（由混合蕴含） | 是 |
| 稳定平衡点/稳定周期轨（自然测度） | 是 | —（平凡支撑） |

遍历性是[[concepts/伯克霍夫遍历定理]]（时间平均=空间平均）的前提；混合性进一步给出渐近去相关（式 17.33），是混沌吸引子上统计不可预测性的更强表述。
