# 诺伊曼级数两种收敛条件比较

对第二类[[concepts/弗雷德霍姆积分方程]]的 [[entities/诺伊曼级数]]，11.2.2 节给出两个收敛条件：sup 界 (11.13c) 与 L² 界 (11.13d)。

## 对照表

| 维度 | sup 界 (11.13c) | L² 界 (11.13d) |
|---|---|---|
| 条件 | $\vert\lambda\vert<1/(M(b-a))$，M 为 $\vert K\vert$ 的上界 (11.13a) | $\vert\lambda\vert<1/\Vert K\Vert_{L^2([a,b]^2)}$ |
| 依据 | 优级数 $N\sum\vert\lambda M(b-a)\vert^n$ (11.13b)，Weierstrass 判别 | 原文称“对级数项更精确的估计”，未给证明 |
| 收敛结论 | 绝对且一致收敛（明确） | 收敛（原文未明言一致） |
| 收敛域大小 | 较小：因 $\Vert K\Vert_{L^2}\le M(b-a)$，L² 域包含 sup 域 | 较大（更精确） |
| xy 核例（K=xy，[0,1]） | M=1、b−a=1 ⇒ 半径 1（保守） | $\Vert K\Vert_{L^2}^2=1/9$ ⇒ 半径 3，恰为真实收敛半径（此例中最优） |

## 关键结论

1. 两域为包含关系（L² 域 ⊇ sup 域）；xy 例中 3 对 1 直接演示差距可达三倍。
2. xy 例中 L² 界恰好取到真实半径 3，说明该界在此例中最优；但这是一例之验，非一般性证明（原文对 (11.13d) 无推导）。
3. 两界之外解仍可能存在（例中解公式对一切 λ≠3 成立），此时应转核分解法（[[concepts/退化核]]），见 [[methodology/弗雷德霍姆方程逐次逼近求解流程]] 的出口分支。
4. 例题本身只援引了较粗的 (11.13c)（半径 1）并顺带指出几何级数“甚至当 $\vert\lambda\vert<3$ 时都收敛”，未点明 (11.13d) 恰好给出 3——属可补强的衔接点，非矛盾。
