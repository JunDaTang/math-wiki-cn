# 模糊插值与样条插值比较

数学手册 5.9.6.4 的收束性论断：**「在此意义下，除用多项式局部插值（例如用样条）的约束插值方法外，模糊系统是基于法则的插值系统。」** 即把模糊插值与样条式约束插值并列为两类结点插值/约束插值途径。依据本来源（式 5.396–5.400）比较：

| 维度 | 模糊系统（Sugeno 型，见 [[基于知识的插值系统]]） | 多项式局部插值（如样条） |
|---|---|---|
| 插值器的定义方式 | 法则 + 隶属函数加权（式 5.397/5.398） | 分段多项式 + 光滑性/连续性约束 |
| 结点条件 | 每法则存在仅激活自身的结点 ⟹ 精确插值（充分非必要） | 插值条件本身（过结点） |
| 结点间形状 | 仅由隶属函数比值 $\mu_1/\mu_2$ 决定（式 5.398） | 由多项式系数/样条约束决定 |
| 约束 | 输出落在结论的凸组合界内（式 5.399–5.400） | 阶数/光滑度约束 |
| 次数行为 | 线性结论 + 和为常数隶属函数 ⟹ 二次插值多项式；n 次结论 ⟹ (n+1) 次 | 样条次数固定，分段拼接 |
| 知识来源 | 法则（语言/专家知识） | 数据（结点值） |

**异同要点**：两者都在结点处精确、结点间受约束；模糊插值的「约束」来自法则结构与隶属函数，样条的约束来自光滑性。次数提升主张（n 次 ⟹ n+1 次）在源文中为断言，未给证明（复算仅确认其代数自洽，见 [[sugeno插值三条件与凸组合界-式5-396-400]]）。
