# 卡丹角与欧拉角比较

手册 3.5.3.5 与 3.5.3.6 用两种三参数角组刻画绕过原点任意轴的旋转，均以三个绕（动）坐标轴的基本旋转矩阵复合而成，且都注明「文献中定义并不完全相同」。

| 维度 | 卡丹角 | 欧拉角 |
|---|---|---|
| 角度记号 | $\alpha,\beta,\gamma$ | 章动角 $\vartheta$、进动角 $\psi$、旋转角 $\varphi$ |
| 旋转次序（绕动轴） | $z(\gamma)\to y(\beta)\to x(\alpha)$ | $z(\psi)\to x(\vartheta)\to z(\varphi)$ |
| 矩阵分解 | $D_C=D_x(\alpha)D_y(\beta)D_z(\gamma)$（式 3.363a） | $D_E=D_z(\varphi)D_x(\vartheta)D_z(\psi)$（式 3.366a） |
| 轴的使用 | 三个不同的轴 | 首末同轴 $z$、中轴 $x$ |
| 缩写定义 | $c_1=\cos\alpha,\ c_2=\cos\beta,\ c_3=\cos\gamma$（3.364b） | $c_1=\cos\vartheta,\ c_2=\cos\psi,\ c_3=\cos\varphi$（3.367b） |
| 方向余弦组 | (3.364a)，两处与矩阵不符（$n_1$ 符号、$n_3$ 下标） | (3.367a)，与 (3.366c) 九分量完全自洽（已验证） |
| 角度范围 | 书内未给出 | $0\le\vartheta<\pi$，$0\le\psi<\pi$（存疑），$0\le\varphi<2\pi$ |

注意两组的 $c_i$ 下标都按**旋转次序**对应角度而非按字母序，这是读两表方向余弦时的关键约定。

## 共同点

- 都在「坐标变换 vs 对象旋转」的区分（式 3.361，$R=D^{-1}=D^{\mathrm T}$）框架下描述坐标系旋转；
- 矩阵连乘均按 [[concepts/法尔克图式]] 排布计算；
- 中间角（$\beta$ 或 $\vartheta$）为零时均退化为纯绕 $z$ 轴的旋转。

## 差异与证据状况

卡丹角三次绕三个不同的轴，欧拉角首末同轴。背景知识（独立可验证）：前者即通称的 Tait–Bryan 型角，后者为经典 Euler 型角，两种约定在力学与工程文献中并存，与手册「文献中定义并不完全相同」的注记一致。本源内的证据状况不对称：欧拉组经独立验证完全自洽（[[findings/欧拉角旋转矩阵与方向余弦自洽性]]），卡丹组有两处待核定（[[findings/卡丹角旋转矩阵及方向余弦两处不符]]、[[queries/式3-364a的n1符号与n3下标是否与3-363c矛盾]]）。
