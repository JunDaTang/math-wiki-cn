# 第一类线积分与第二类线积分比较

两类线积分共享同一黎曼和构造（分割—取点—乘积—求和—极限），差别集中在「乘什么微元」及其后果。依据 [[sources/10-数学手册原书第10版--6-83-线积分--13ru9gk]]（8.3.1 与 8.3.2）。

| 维度 | 第一类线积分（对弧长的积分） | 第二类线积分（投影积分） |
|---|---|---|
| 记号 | $\int_{(C)} f\,\mathrm{d}s$（式 8.106） | $\int_{(C)} f\,\mathrm{d}x$ / $\mathrm{d}y$ / $\mathrm{d}z$（式 8.110a/b） |
| 微元 | 小弧段弧长 $\Delta s_{i-1}>0$（式 8.107a） | 小弧段在坐标轴上的投影 $\Delta x_{i-1}=x_i-x_{i-1}$ 等（式 8.111） |
| 参数化计算 | 乘 $\sqrt{[x'(t)]^2+[y'(t)]^2(+[z'(t)]^2)}$（式 8.108a/b，微元查 [[entities/表8-7曲线微元表]]） | 乘 $x'(t)$ / $y'(t)$ / $z'(t)$（式 8.116a–e） |
| 显形式 | 乘 $\sqrt{1+[y'(x)]^2(+[z'(x)]^2)}$（式 8.109a/b） | 横坐标 $x$ 直接取代参数 $t$（式 8.117） |
| 参数方向约定 | **必须 $t_0<T$**（显形式 $a<b$），保证 $\mathrm{d}s>0$ | **不要求 $t_0<T$**（显形式不必 $a<b$） |
| 路径反向 | 积分不变（方向无关） | **积分变号** |
| 典型应用 | 标量分布量：弧长、质量、重心、转动惯量（[[entities/表8-6第一类线积分应用表]]） | 有向功、环流（经 [[concepts/一般类型的线积分]] 组合） |
| 存在定理 | 光滑曲线 + 函数沿曲线连续（8.3.1.2） | 函数及曲线沿线段连续 + 连续切线（8.3.2.2，转写有脱漏） |

## 差异的根源

$\mathrm{d}s=\sqrt{[x'(t)]^2+[y'(t)]^2}\,\mathrm{d}t$ 只在 $\mathrm{d}t>0$ 时保持恒正，故第一类必须约定参数沿起点→终点递增；$\mathrm{d}x=x'(t)\,\mathrm{d}t$ 自带符号，方向信息由被积式携带，故第二类既无方向约定、又天然「反向变号」。计算层面的操作细节见 [[methodology/线积分化定积分计算流程]]。

## 组合关系

沿曲线所有投影的第二类积分之和构成 [[concepts/一般类型的线积分]]（式 8.118a/b）；第一类则独立承载曲线上的标量求和问题，且是 [[concepts/弧长与弧微分]] 的积分表述。
