# 单精度与双精度浮点数比较

据《数学手册（原书第10版）》19.8.1.2(2)，IEEE 标准给出两个基本的浮点数表示形式（也有其他表示形式），其参数（表 19.4）对照如下：

| 参数 | 单精度 | 双精度 |
|---|---|---|
| 存储单元字长 | 32 | 64 |
| 最大指数 $E_{\text{max}}$ | +127 | +1023 |
| 最小指数 $E_{\text{min}}$ | −126 | −1022 |
| 常数 $K$ | +127 | +1023 |
| 指数位数 | 8 | 11 |
| 尾数位数 | 24 | 53 |

## 解读

- **位分配**：单精度 1（符号 $v$）+ 8（指数）+ 23（显式尾数）= 32；双精度 1 + 11 + 52 = 64。表列「尾数位数」24 与 53 均含隐含前导 1（由 (19.267) 的 $1.b_1 b_2 \dots b_{t-1}$ 形式，显式位为 $t - 1$）。
- **指数范围**：由 $E = C - K$ 与保留的 $C = 0$、$C_{\max}$ 导出。单精度 $E \in [1 - 127,\ 254 - 127] = [-126, +127]$，与表列一致；双精度对应 $E \in [-1022, +1023]$（双精度一侧为独立推算，原文未列 $C$ 的界）。
- **量级对比**：双精度在字长（32→64）、指数动态范围（$E_{\max}$ 自 +127 增至 +1023）、尾数精度（24→53 位）上均为单精度的扩展。

## 证据

表 19.4 全部参数经独立复算与 IEEE 754 单/双精度公认值一致（比对基于公开常识），见 [[findings/式19-264至19-267定点浮点与IEEE格式转录复算]]；正文 $C_{\max} = 256$ 之疑讹不影响本表，见 [[queries/式19-267后C-max为256疑为254之辨]]。
