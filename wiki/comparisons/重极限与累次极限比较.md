# 重极限与累次极限比较

依据 [[sources/10-数学手册原书第10版--8-218-多元函数--1ycg0a2]] 2.18.3（式 2.284–2.286），二元函数的两种极限概念对照如下：

| 维度 | 重极限 $A$ | 累次极限 $B$、$C$ |
|---|---|---|
| 趋近方式 | $x, y$ 同时、以任意方式趋近 $(a,b)$ | 固定一个变量，逐个先后取极限 |
| 定义式 | $\lim_{\substack{x\to a\\y\to b}} f(x,y) = A$（式 2.284–2.285） | $B = \lim_{y\to b}\lim_{x\to a} f$，$C = \lim_{x\to a}\lim_{y\to b} f$（式 2.286a–b） |
| 与点 $(a,b)$ 处函数值的关系 | $(a,b)$ 可不属于定义域，或 $f(a,b) \ne A$ | 内层极限须对固定的另一变量逐点存在 |
| 精确刻画 | ε-η 方形邻域（图 2.107） | 两次一元极限的复合 |
| 顺序依赖 | 无顺序概念 | 一般 $B \ne C$，即使两者都存在 |
| 存在性的相互关系 | $A$ 存在且 $B, C$ 均存在 ⟹ $B = C = A$ | $B = C$ 不保证 $A$ 存在；$A$ 存在不保证 $B, C$ 存在 |

## 关键反例（式 2.286，已复核）

$$f(x,y) = \frac{x^2 - y^2 + x^3 + y^3}{x^2 + y^2}, \quad (x,y) \to (0,0):\quad B = -1, \quad C = +1.$$

先 $x \to 0$ 得内层极限 $-1 + y$，先 $y \to 0$ 得内层极限 $1 + x$，两条途径的终点不同。**推断（非手册原文）**：沿 $y = 0$ 趋近原点得 $+1$、沿 $x = 0$ 趋近得 $-1$，路径极限不同，故该函数的重极限 $A$ 亦不存在。
