# 克拉默法则与高斯算法比较（计算量与适用性）

依据 [[sources/10-数学手册原书第10版--8-45-线性方程组--1smy1k4]]（4.5.2.3 与 4.5.2.4）：

| 维度 | 克拉默法则（式 4.184） | 高斯算法（式 4.185–4.186） |
|---|---|---|
| 适用前提 | m = n 且 D = det A ≠ 0 | 任意 m × n |
| 解的形式 | 显式公式 x_ν = D_ν/D | 行阶梯形 + 逐行回代 |
| 计算量 | 源断言：维数增加时所要求的运算量很快增加，高维问题不适用 | 实施 (r − 1) 次高斯步骤得阶梯形 |
| 数值解定位 | 源明确不推荐用于数值解 | 源推荐的数值解法之一（与选主元法、迭代程序并列） |
| 理论价值 | 给出唯一性的行列式判据（D ≠ 0 ⇔ 唯一解）与解的显式表示 | 同时给出可解性判读与解的构造 |

## 说明

- 源的运算量断言为定性判断，未给定量数据；按数值线性代数通行估计，克拉默法则需计算 n + 1 个 n 阶行列式，计算代价远劣于消元法的 O(n³) 量级（此为独立背景知识，非源文明言）。
- 源另建议高维问题的数值解用迭代程序（第 1233 页 19.1.1，未入库）。
- 高斯算例见 [[findings/高斯消元行阶梯形与两算例]]；克拉默算例见 [[findings/克拉默法则及算例与高维不适用断言]]。
