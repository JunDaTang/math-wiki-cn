# 压力单位换算链比较

手册 21.4 节以尾注「说明」给出 Pa、bar、atm、Torr、mmHg 五个压力单位的相互换算链，另表 4 收录 bar 与 mmHg 两行。本页将源文各换算式与复算值并列对照；方法见 [[methodology/单位定义量纲复算法]]。

## 源文换算式 vs 复算值

| 换算式（源文如此） | 复算 | 判定 |
|---|---|---|
| 1 Pa = 1 N·m⁻² | 定义 | ✓ |
| 1 Pa = 10⁻⁵ bar | 10⁻⁵ × 10⁵ Pa = 1 Pa | ✓ |
| 1 Pa = 7.52·10⁻³ Torr | 1/133.322 Pa = 7.5006·10⁻³ Torr | ✗ 硬数值错误 |
| 1 Pa = 9.86923·10⁻⁶ atm | 1/101325 = 9.8692·10⁻⁶ atm | ✓ |
| 1 atm = 760 Torr = 101325 Pa | 定义值（101325/760 = 133.322 Pa/Torr） | ✓ |
| 1 Torr = 133.32 Pa | ≈133.322 Pa（截尾） | ✓ |
| 1 Torr = lmmHg | 「l」疑为「1」（转写讹误） | 疑讹 |
| 1 bar = 0.987 atm | 10⁵/101325 = 0.98692 ≈ 0.987 | ✓（舍入） |
| 1 bar = 760.06 Torr | 10⁵/133.322 = 750.06 Torr | ✗ 硬数值错误 |
| 1 mmHg = 133.322 Pa（表 4） | 与 1 Torr 一致 | ✓ |

## 两处错误的一致性分析

- 「7.52·10⁻³ Torr/Pa」与同注记「1 Torr = 133.32 Pa」直接互斥：由后者只能得 7.50·10⁻³。疑「7.52」为「7.50」之讹（[[queries/1pa合7-52e-3Torr疑为7-50e-3之辨]]）。
- 「760.06 Torr/bar」与「1 bar = 0.987 atm」「1 atm = 760 Torr」联立互斥：只能得 ≈750.1 Torr。疑「760.06」为「750.06」之讹（[[queries/1bar等于760-06Torr疑为750-06之辨]]）。
- 两处均为个位数字之误（7↔5），且所在行未见上标脱落等转写损伤迹象，故可能是原书之误而非转写之误——归因待纸本核对（推断）。

## 结论

换算链 10 项关系中 8 项自洽（含 1 项舍入、1 项截尾），2 项硬数值错误且均集中于尾注行；表 4 的 bar、mmHg 两行数值正确。整体复算详见 [[findings/21-4单位定义与换算数值复算]]。
