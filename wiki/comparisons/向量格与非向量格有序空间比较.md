# 向量格与非向量格有序空间比较

《数学手册(原书第10版)》12.1.7.4 例 B 在同一函数空间层级链（式 12.14）内部划出格性质的分界：F([a,b])、C([a,b])、B([a,b]) 是向量格，而 C^(1)([a,b]) 不是。本页对照其机制并明确断言边界。

## 对照表

| 空间 | 有序向量空间？ | 向量格？ | 机制 |
|---|---|---|---|
| F([a,b]) | 是 | **是** | 逐点上确界 (12.34)：任意两函数逐点取 max 仍是函数，无正则性要求 |
| C([a,b]) | 是 | **是** | 逐点 max 保持连续性（复算：max(x,y) = (x+y+\|x−y\|)/2，由四则运算与绝对值保持连续） |
| B([a,b]) | 是 | **是** | 逐点 max 保持有界性（max(‖x‖∞, ‖y‖∞) 为界） |
| C^(1)([a,b]) | 是 | **否** | 两个可微函数的 max/min 在交点处一般产生角点，不可微 |
| ℝ¹ | 是（且全序） | 是 | (o)有界 ⟺ 通常有界**仅在此成立**；上有界集皆有上确界 |

## 机制演示（式 12.35 算例）

取（按 [[findings/式12-35正文xt系数与式内不一致之判定]] 修正后的）x(t) = 1 − (3/2)t、y(t) = t²（[0,1] 上）：x∨y 在 t = 1/2 处两支切换，切换点两侧斜率分别为 −3/2 与 2t = 1，不相等，故 x∨y 在 t = 1/2 不可微——尽管 x、y 本身都是光滑函数。这正说明：**逐点 max 运算会把 C^(1) 中的元素对送到 C^(1) 之外**（落入 C([0,1])），因此 C^(1) 对 ∨ 不封闭。（此为复算补充演示；源文的机制陈述为「两个可微函数的最大或最小在区间上一般是不可微的」。）

## 断言边界（防跨主体转移）

- 「不是向量格」仅关于 C^(1)([a,b])（及更高阶 C^(k)），**不得**外推到同链的 C([a,b])、B([a,b])、F([a,b])——源文明示三者均是向量格。
- 「有序向量空间」是比「向量格」弱的结构：C^(1) 配逐点序仍是有序向量空间，只是上确界未必落回本空间。格性质要求 ∨、∧ 在空间内部封闭。
- (o)有界与通常有界的等价性仅是 ℝ¹ 的事实，与格性质是两回事，勿混。
