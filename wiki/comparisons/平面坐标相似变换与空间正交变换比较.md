# 平面坐标相似变换与空间正交变换比较

3.2 节两直角坐标系之间的相似变换（[[findings/两直角坐标系相似变换]]，式 3.108–3.109）与 3.5.3 的空间正交坐标变换（式 3.359–3.362）是同一主题的二维与三维版本：

| 维度 | 平面（3.2 节） | 空间（3.5.3 节） |
|---|---|---|
| 平移 | 含于相似变换 | 式 (3.359) 独立给出 |
| 旋转参数 | 一个角 | 三个参数：方向余弦九量（带六约束）／卡丹角／欧拉角 |
| 变换矩阵 | $2\times2$ | $3\times3$ 正交矩阵 $D$，$\det D=\Delta=\pm1$（式 3.362c–d） |
| 正交性约束 | 行平方和为 1、行积为 0 | 行、列平方和均为 1，异行（列）对应元乘积和为 0（式 3.362 性质 b/c） |
| 对象旋转 | — | 明确区分并给出 $R=D^{-1}=D^{\mathrm T}$（式 3.361） |
| 不变量 | 距离与角度（相似变换含比例因子问题） | 标量积、向量长等标量不变量（[[concepts/标量不变量]]） |

## 语义差异

平面相似变换允许整体缩放，手册因此在 3.2 节讨论比例因子校正；空间正交变换限定等距，3.5.3 节转而讨论定向（$\Delta$ 的符号，衔接 [[concepts/右手系与左手系]]）与「坐标变换 vs 对象旋转」的区分（[[findings/平移旋转与对象旋转矩阵关系]]）。空间情形特有的展开是三参数化：方向余弦（[[findings/方向余弦旋转与变换行列式性质]]）、[[concepts/卡丹角]] 与 [[concepts/欧拉角]]。
