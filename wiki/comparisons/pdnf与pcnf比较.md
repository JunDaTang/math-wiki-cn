# PDNF 与 PCNF 比较

PDNF（主析取正规形式）与 PCNF（主合取正规形式）是布尔表达式的两种规范化形，手册 5.7.6 称 PCNF 是 PDNF 的「对偶」形式（参见 [[concepts/对偶原理]]）。

| 维度 | PDNF | PCNF |
|---|---|---|
| 积木 | 基本合取（每变量或其否定恰一次） | 基本析取（每变量或其否定恰一次） |
| 联结词 | 用 $\sqcup$ 连接 | 用 $\sqcap$ 连接 |
| 构造基点 | 使 $f=1$ 的赋值 | 使 $f=0$ 的赋值 |
| 变量规则 | 值 1 取本身、值 0 取否定 | 值 1 取否定、值 0 取本身 |
| 唯一性 | 变量序与赋值序（按二进数递增）给定后唯一 | 同左 |
| 长度 | $f$ 的 1 值赋值个数个基本合取 | $f$ 的 0 值赋值个数个基本析取 |

## 长度取舍

$f$ 的 1 值稀少时 PDNF 较短，0 值稀少时 PCNF 较短。手册算例（[[findings/pdnf与pcnf构造算例]]）中 $f=1$ 有 3 个赋值、$f=0$ 有 5 个赋值，故 PDNF 含 3 项（式 5.312）而 PCNF 含 5 项（式 5.313）。

## 共同用途

等价性判定：两个表达式的主正规形式（同一变量序与赋值序）按字母逐个恒等，当且仅当二者语义等价（正向为源明言，反向由唯一性可得）。

## 极端情形

$f\equiv 1$ 或 $f\equiv 0$ 时某一侧赋值集为空，源未讨论对应的空联结约定，套用时需注意。
