# 反三角与反双曲函数积分对应比较

本页比较 [[concepts/反三角函数积分族]]（21.7.4.4，编号 488–511）与 [[concepts/反双曲函数积分]]（21.7.4.5，编号 512–515）两组公式的结构平行，证据均出自 [[sources/10-数学手册原书第10版--13-2174-其他超越函数积分--17odu4w|数学手册 21.7.4]]。

## 四对基本积分

| 圆函数侧 | 双曲侧 | 结构对应 |
|---|---|---|
| 488：$\int\arcsin\frac{x}{a}dx = x\arcsin\frac{x}{a} + \sqrt{a^2-x^2}$ | 512：$\int\operatorname{Arsinh}\frac{x}{a}dx = x\operatorname{Arsinh}\frac{x}{a} - \sqrt{x^2+a^2}$ | $\sqrt{a^2-x^2} \leftrightarrow -\sqrt{x^2+a^2}$ |
| 493：$\int\arccos\frac{x}{a}dx = x\arccos\frac{x}{a} - \sqrt{a^2-x^2}$ | 513：$\int\operatorname{Arcosh}\frac{x}{a}dx = x\operatorname{Arcosh}\frac{x}{a} - \sqrt{x^2-a^2}$ | $\sqrt{a^2-x^2} \leftrightarrow \sqrt{x^2-a^2}$ |
| 498（复原）：$\int\arctan\frac{x}{a}dx = x\arctan\frac{x}{a} - \frac{a}{2}\ln(a^2+x^2)$ | 514：$\int\operatorname{Artanh}\frac{x}{a}dx = x\operatorname{Artanh}\frac{x}{a} + \frac{a}{2}\ln(a^2-x^2)$ | $\ln(a^2+x^2) \leftrightarrow \ln(a^2-x^2)$，系数反号 |
| 505：$\int\arccot\frac{x}{a}dx = x\arccot\frac{x}{a} + \frac{a}{2}\ln(a^2+x^2)$ | 515：$\int\operatorname{Arcoth}\frac{x}{a}dx = x\operatorname{Arcoth}\frac{x}{a} + \frac{a}{2}\ln(x^2-a^2)$ | $\ln(a^2+x^2) \leftrightarrow \ln(x^2-a^2)$ |

## 平行结构分析

- 每对公式均呈 $x\,f(\frac{x}{a}) \pm (\text{初等函数项})$ 的统一骨架：前项为分部积分的直接产物，后项吸收 $\int\frac{x\,dx}{a^2\pm x^2}$ 或 $\int\frac{x\,dx}{\pm(a^2-x^2)}$ 型余项。
- 根号型（arcsin/arccos ↔ Arsinh/Arcosh）与对数型（arctan/arccot ↔ Artanh/Arcoth）的分化，对应被积函数导数 $\frac{1}{\sqrt{a^2-x^2}}$、$\frac{1}{a^2+x^2}$ 与 $\frac{1}{\sqrt{x^2+a^2}}$、$\frac{1}{a^2-x^2}$ 的分母符号翻转。
- 这一 $\pm$ 符号翻转模式与圆函数经虚代换（$x \leftrightarrow ix$）转化为双曲函数的解析关系一致（标准数学背景，可独立核验）。
- 互补关系不对称：圆函数侧有 $\arcsin+\arccos = \frac{\pi}{2}$、$\arctan+\arccot = \frac{\pi}{2}$，使 493/505 可由 488/498 导出（如 488+493 = $\frac{\pi x}{2}$）；双曲侧的 Arsinh/Arcosh、Artanh/Arcoth 无此常数互补，四式各自独立成立。

## 校勘联动

- 498 在转写中严重乱码，其复原假说（上表所列形式）的证据链包括 505 镜像式（微分复算通过）与互补关系求和核验，514 的对数型平行提供旁证，见 [[queries/公式498乱码复原之辨]]。
- 本表各式（含 498 复原式）均经微分复算（[[findings/21-7-4超越函数积分全表微分复算]]）。
- 记法侧：反双曲侧采用 Ar- 记法（Arsinh/Arcosh/Artanh/Arcoth），与 [[concepts/面积函数与Ar-记法]] 一脉相承；圆函数侧用 arcsin 等标准记法。
