# 线性薛定谔方程与非线性薛定谔方程比较

9.2.5.1(6) 将薛定谔方程列为**线性**发展方程的例子（回指 9.2.4.1，见 [[sources/10-数学手册原书第10版--9-924-薛定谔方程--1lweyuj]] 与 [[comparisons/含时与定常薛定谔方程比较]]），而 NLS (9.149/9.158) 是其**非线性**对应物——两者同名而性质截然不同。

| 维度 | 薛定谔方程（线性） | 非线性薛定谔方程 (NLS) |
|---|---|---|
| 形式 | 关于未知函数线性（9.2.4 的 iℏ∂ψ/∂t = Ĥψ 型，据 9.2.4 节） | iu_t + u_{xx} ± 2\|u\|²u = 0，含非线性项 \|u\|²u |
| 叠加原理 | 严格成立 | 失效（仅 N-孤子解在 t → ±∞ 时渐近叠加） |
| 波包行为 | （自由情形）色散致波包扩散 | 离差（色散）与非线性**平衡**，波包保持形状 → 孤子 |
| 物理来源 | 量子力学基本方程（[[concepts/波函数与统计诠释]]） | 非线性光学（克尔效应 n = n₀ + n₂\|E\|²）、自引力圆盘（银河系旋臂） |
| 在 9.2 章中的位置 | 9.2.4（线性发展方程例） | 9.2.5（非线性发展方程、保守孤子支） |

## 注意

- NLS 的「薛定谔」之名来自左端 iu_t + u_{xx} 与线性薛定谔算子的形式类比；两者描述不同物理。
- 源文 9.2.5.1(6) 明确将波方程、热方程、薛定谔方程并列为线性发展方程，而将 (9.148)–(9.152) 列为非线性发展方程——本比较即依此组织；线性薛定谔方程一侧的陈述依据 9.2.4 节源页。
