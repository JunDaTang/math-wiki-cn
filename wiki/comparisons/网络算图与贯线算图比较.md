# 网络算图与贯线算图比较

《数学手册(原书第10版)》2.19.1 把网络算图与贯线算图并列为最常见的两类算图。下表按 2.19.2 与 2.19.3 的材料并排比较（依据 [[sources/10-数学手册原书第10版--7-219-算图法--rdi3]]）。

| 维度 | 网络算图（2.19.2） | 贯线算图（2.19.3） |
|---|---|---|
| 构造载体 | 网格：平行于坐标轴的两族直线（$x$、$y$）加一族等高线（$z$），由曲面 $F(x,y,z)=0$ 经等高线投影（式 2.292，引 2.18.1.2） | 三条[[concepts/标度|标度]]，每变量一条（式 2.295）；满足方程的三变量标度点共线 |
| 理论判据 | 曲面的等高线表示；化直条件为式 2.293（等分标度 → 直线族）与式 2.294（函数标度 → 两族平行曲线 + 一族直线） | 行列式判据式 2.296 = 0；三种构型各对应一种方程型 |
| 读值方式 | 在网格中定位两变量所在曲线的交点，沿第三族曲线读值 | 连接两标度上的已知点，贯线与第三标度的交点即读值 |
| 可表示范围 | 任意三元关系 $F(x,y,z)=0$，通用性最强 | 能化为式 2.296 的关系；构型由方程代数形状决定 |
| 本节算例 | 欧姆定律 $U=RI$：双曲线族（图 2.108），对数标度化直为直线族（图 2.109） | $\frac{1}{a}+\frac{1}{b}=\frac{2}{f}$（2.19.3.1）；$y^2=x^2\tan^2\varphi$（图 2.110）；$z^3+p^*z+q^*=0$（图 2.111） |
| 设计自由度 | 标度选择：改域（$0<I<1$ 时标记变 $U/10$）、化直（对数标度） | 标度函数 $\varphi_i,\psi_i$、分度 $E_1,E_2$（压缩/集中第三标度）、斜率 $m$、反向刻度 |
| 时代注记与延伸 | 计算机时代实验室仍用于近似计算与迭代初值（原文注，联系 2.16 拟合初值） | 三个以上变量公式的分解统一以贯线算图实现（2.19.4 正文） |

## 分析

两类算图的分野在于「把什么搬进图里」：网络算图把整个曲面的等高线族搬进一张图，信息完整、对方程形式几乎无要求，但读值需在网格线之间插值；贯线算图只保留共线判据，图面简洁、读值快（一次贯线一个读数），但要求方程能写成行列式形式，且构型由方程的代数形状决定（见 [[comparisons/贯线算图三种构型比较]]）。

[[concepts/标度|标度]]选择是两者共享的杠杆：它既能在网络算图内部化直（对数标度化欧姆定律）与改域（标记 $U \to U/10$），也是贯线算图构型的核心变量（分度 $E_1, E_2$、反向刻度）。

多变量情形按 2.19.4 正文统一收敛到贯线算图体系：辅助变量分解后所有方程以贯线算图表示、公共标度共用（[[findings/多变量公式的辅助变量分解法]]）——尽管该小节标题仍作「网络算图」（见 [[queries/2-19-4标题网络算图与正文贯线算图是否矛盾]]）。
