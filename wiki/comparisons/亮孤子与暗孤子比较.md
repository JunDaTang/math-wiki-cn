# 亮孤子与暗孤子比较

两者都是 [[concepts/非线性薛定谔方程]] iu_t + u_{xx} ± 2\|u\|²u = 0 的孤子解，但分属聚焦（+）与散焦（−）两支，且背景与参数结构不同。

| 维度 | 亮孤子（光孤子）(9.159) | 暗孤子 (9.160) |
|---|---|---|
| 方程支 | 聚焦 (focusing) NLS，「+」号 | 散焦 (defocusing) NLS，「−」号 |
| 背景 | 零背景（\|u\| → 0） | 常数背景 \|u(x → ±∞)\| = η（平凡/平直相） |
| 形态 | sech 型包络峰 | 在孤子位置处 \|u\|² 相对背景**凹陷** |
| 参数 | 4 个：η, ξ, φ, χ | 3 个：η, v, χ |
| 速度 | 包络速度 v = −4ξ；相速度 2(η²−ξ²)/ξ | v < 2η；背景相梯度 c 可再提升（见 (9.161)） |
| 振幅—速度关系 | 振幅（2η）与速度可**独立**选取 | 凹陷深度受 v 约束（√(η²−v²/4)），v = 0 为最深（黑孤子） |
| 复算状态 | 拟设推导全部复现（high） | v = 0 直接代入验证；一般 v 与文献标准形一致（high）；(9.161) 括号疑误（medium-high） |

来源：9.2.5.3；复算见 [[findings/式9-158至9-161nls亮暗孤子复算]]；(9.161) 疑误见 [[queries/式9-161括号位置与暗孤子伽利略提升]]。
