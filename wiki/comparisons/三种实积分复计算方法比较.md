# 三种实积分复计算方法比较

14.4 节沿三条方法主线组织，比较如下：

| | 柯西积分公式法（14.4.1） | 留数定理法（14.4.2） | 若尔当引理法（14.4.3） |
|---|---|---|---|
| 核心工具 | (14.42) 导数形式 + 圆周参数化 (14.43) | (14.56) + (14.54b) 留数公式 | (14.57a–c) + 留数定理 |
| 积分区间形态 | 有限周期区间 [0, 2π]（三角函数型） | 全实轴 (−∞, +∞)，有理衰减型 | 无穷区间，含振荡因子 e^{iαx} 或需围道旋转 |
| 围道形态 | 闭圆周（无开口弧段） | 上半平面大半圆弧闭合 | 上半平面半圆 + 实轴极点缩进小弧；或扇形围道 |
| 弧段/开口控制 | 不需要 | f(1/z) 在 z=0 重数 ⩾ 2（衰减条件） | 若尔当引理；扇形弧段需 α-分割估计 |
| 本节实例 | ∫₀^{2π} e^{rcosφ}cos(r sinφ − nφ)dφ = 2πrⁿ/n! | ∫dx/(1+x²)³ = 3π/8 | (14.58c)、(14.59)、(14.60)–(14.61)、(14.62) |
| 前置知识 | [[concepts/柯西积分公式]]（14.2 已入库） | 14.3 留数理论（未入库） | 14.3 留数理论 + [[concepts/复积分的绝对值估计]] |

## 递进关系

1. **柯西积分公式法**处理有限区间上的周期积分：围道本身闭合，无须估计弧段；
2. **留数定理法**把区间延拓到全实轴，用衰减条件保证大半圆弧贡献消失；
3. **若尔当引理法**进一步处理振荡因子（e^{iαz} 的衰减替代 f 的衰减）与实轴奇点（缩进围道，小弧段贡献 ±iπ），并在菲涅耳例中展示围道旋转（扇形围道 + α-分割估计）——此时弧段估计已超出若尔当引理的标准形式。

## 围道形态谱系

闭圆周（14.4.1）→ 上半平面半圆闭合（14.4.2、例 1）→ 缩进围道（例 2–4）→ 扇形围道（例 5）。四种形态对应的弧段控制手段依次为：无、衰减条件、若尔当引理 + 小弧段极限、α-分割指数估计。各流程页：[[methodology/复积分圆周参数化计算流程]]、[[methodology/上半平面围道留数计算流程]]、[[methodology/实轴极点缩进围道计算流程]]、[[methodology/扇形围道指数估计流程]]。
