# 分离边界条件与周期边界条件比较

《数学手册》9.1.3 在自伴方程 (9.67a) 上给出两种齐次边值条件：主体理论采用的**分离型** (9.67b) 与 9.1.3.4 引入的**周期型** (9.70)。两者的结构差异直接决定性质 9.68b 的成立与否。

| 维度 | 分离边界条件 (9.67b) | 周期边界条件 (9.70) |
|---|---|---|
| 形式 | A₀y(a)+B₀y′(a)=0；A₁y(b)+B₁y′(b)=0 | y(a)=y(b)；p(a)y′(a)=p(b)y′(b) |
| 结构 | 每个端点各自一个独立的线性关系式（解耦） | 两端点的值相互耦合 |
| 特殊情形 | — | p(a)=p(b) 时表示 y 与 y′ 的周期性 |
| 本征值重数 | 单重（9.68b 成立：同一本征值的本征函数仅差常数因子） | 可退化（重数可达 2），9.68b 失效 |
| 其余性质 | 9.1.3.2 性质 1–6 全部成立 | 除 9.68b 外全部成立 |

## 说明

- 周期条件下本征值可退化的机制（依标准理论，源文未展开）：同一本征值可有两个线性无关本征函数，经典傅里叶级数中 sin nx 与 cos nx 同属一个本征值即为原型，故「仅差常数因子」不再成立。
- 9.1.3.4 同时提到：奇点处以连续性/有限性/有界阶增长条件替代齐次边界条件，这些条件也起着齐次边界条件的作用，见 [[concepts/奇异边值问题]]。
- 周期/奇异情形的进一步讨论原书指引至文献 [9.5]，见 [[queries/9-2-3与9-2-3-3及文献9-5未入库回指缺口]]。
