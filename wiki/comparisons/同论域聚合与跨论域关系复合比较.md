# 同论域聚合与跨论域关系复合比较（5.9.2 vs 5.9.4）

《数学手册(原书第10版)》在 5.9.2（[[sources/10-数学手册原书第10版--12-592-模糊集的连接聚合--wb9q68]]）与 5.9.4 两处使用同一对 Zadeh 算子（min/max）充当 AND/OR，但论域结构与用途不同。本页比较两种用法。

## 对照

| 维度 | 同论域聚合（5.9.2） | 跨论域关系复合（5.9.4） |
|---|---|---|
| 输入 | 同一论域上的模糊集 | 不同论域的模糊集 μ₁: X₁→[0,1]、μ₂: X₂→[0,1]（如「中等压力」与「高温」） |
| 前置步骤 | 无（可直接逐点运算） | **柱面扩充**到 G = X₁×X₂（图 5.76） |
| 运算 | min/max，及更广的 [[concepts/t-范数]]/[[concepts/s-范数]] 族与 [[concepts/补偿算子]] | 逐点 min/max：μ_R(p,T) = min{μ₁(p), μ₂(T)} 或 max{μ₁(p), μ₂(T)} |
| 结果类型 | 原论域上的模糊集 | 乘积空间 G 上的**模糊关系** R: G → [0,1] |
| 对应逻辑连接词 | AND（和）/ OR（或），式 5.350–5.351、表 5.9 | AND（和）/ OR（或），图 5.77 |
| 用途 | 模糊集的连接（聚合） | 构造 IF THEN 法则的关系 R，服务 [[concepts/模糊推理]]（式 5.380、5.381） |

## 相同点

- 算子层面为同一对 Zadeh 算子：min 充当 AND（和）、max 充当 OR（或）。
- min/max 分别是 t-范数与 s-范数的边界元（参见 [[findings/t与s范数公理组及min-max上下界]]）。

## 不同点与实质推进

- 5.9.4 的关键新增是**柱面扩充**这一前置步骤：跨论域模糊集必须先提升到共同乘积空间才能逐点复合（见 [[concepts/柱面扩充]]、[[methodology/柱面扩充与and-or复合构造流程]]）。
- 结果从「模糊集」变为「模糊关系」，从而可直接进入推理链条（式 5.380 的 μ₂ = μ₁ ∘ R）。

## 印证链

5.9.2（式 5.350–5.351，[[findings/zadeh算子与and-or-not对应]]）与 5.9.4（图 5.77，[[findings/min-max算子构成and-or模糊关系-图5-77]]）在不同上下文中一致地使用 min=AND、max=OR，构成跨节互相印证。
