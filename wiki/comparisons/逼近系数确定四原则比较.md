# 逼近系数确定四原则比较

依据数学手册 19.4.2.2（式 19.121–19.133），四原则共用逼近式 (19.121)/(19.131) 与亏量 (19.122)：

| 原则 | 确定条件 | 所得方程组 | 前置要求 |
|---|---|---|---|
| 配置法 (19.123) | 亏量在 n 个配置点 x_ν 上为零 | 线性 | 选取 n 个互异配置点 ∈ (a,b) |
| 最小二乘法 (19.124)–(19.125) | ∫_a^b ε² dx 极小 ⟹ ∂F/∂a_i = 0 | 线性 | 无 |
| 伽辽金法 (19.126) | 亏量与每个基函数正交（误差正交性） | 线性 | 无 |
| 里茨法 (19.127)–(19.128) | 变分积分 I 极小 ⟹ ∂I/∂a_i = 0 | 线性（线性 BVP） | 需变分提法：自伴问题由 (19.129)–(19.130) 得 H(x,y,y′) |

说明：源文将四者并列为确定系数 a_i 的原则，未比较其相互关系或精度差异；里茨法经由 [[concepts/边值问题与变分问题等价性]] 取得被积函数 H，是与伽辽金法在结构上最相近的一条，但源文本节未明言二者等价。四原则对非线性边值问题均给出非线性方程组（用 19.2.2，未入库，求解）。流程见 [[methodology/逼近系数确定四原则流程]]。
