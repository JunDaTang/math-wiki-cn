# 全排列、组合、排列（无重复与有重复）公式比较

本页承载 16.1 节表 16.1 的复原与解读：三类构造方式（全排列＝纯排序、组合＝纯选取、排列＝选取＋排序）× 两种重复情形，构成本节全部计数公式的 2×3 分类框架，也是解题时定位公式的钥匙。

## 复原版表 16.1

（依式 16.1–16.7 复原；转写版记号退化对照见文末。）

| 从 n 个元素中取出 k 个元素的选取类型 | 无重复 (k ≤ n) | 有重复 |
|---|---|---|
| 全排列 | Pₙ = n!（即 k = n） | Pₙ⁽ᵏ⁾ = n!/k!（k 个元素相同） |
| 组合 | Cₙ⁽ᵏ⁾ = C(n, k) | Cₙ⁽ᵏ⁾ = C(n+k−1, k) |
| 排列 | Vₙ⁽ᵏ⁾ = k!·C(n, k) | Vₙ⁽ᵏ⁾ = nᵏ |

## 三类模型的分工

| 模型 | 回答的问题 | 页面 |
|---|---|---|
| 全排列 | n 个元素「怎么排」（全员参与，k = n） | [[concepts/全排列]] |
| 组合 | 「选哪些」（不计顺序） | [[concepts/组合]] |
| 排列 | 「选哪些＋怎么排」（k < n 亦适用） | [[concepts/排列]] |

三者的联系：无重复排列 Vₙ⁽ᵏ⁾ = k!·C(n,k) 是「组合 × 组内全排列」的复合；k = n 时退化为全排列 n!。

## 记号重载警示（同表各格不可互换）

- Cₙ⁽ᵏ⁾：(16.4) 无重复 C(n,k) 与 (16.5) 有重复 C(n+k−1,k)——同一记号、两种公式，仅凭「是否允许重复」消歧。
- Vₙ⁽ᵏ⁾：(16.6) 无重复 k!·C(n,k) 与 (16.7) 有重复 nᵏ——同上。
- Pₙ⁽ᵏ⁾：上标 (k) 指「k 个元素相同」的重数，不是「取出个数」；全排列行的 k 语义与另两行不同。

因此公式不得跨列挪用：有重复组合不可用 C(n,k)，有重复排列不可用 k!·C(n,k)。模型定位流程见 [[methodology/计数模型选用流程]]。

## k 的取值范围

- 无重复列：要求 0 ≤ k ≤ n（(16.4)、(16.6) 明示）。
- 有重复列：除全排列行（k ≤ n 由构造自动成立）外，k 可大于 n——有重复组合 C(n+k−1,k) 与有重复排列 nᵏ 对任意 k 有定义（如掷 7 颗骰子、字节编码）。
- 转写版表 16.1 给「有重复」列也标 (k≤n)，与 (16.5) 矛盾，见 [[queries/表16-1有重复列k小于等于n之辨]]。

## 例题定位

| 例题 | 模型 × 重复情形 | 公式 |
|---|---|---|
| 16 名学生坐 16 个座位 | 全排列 × 无重复 | 16! |
| 16 个书包（4 个相同） | 全排列 × 有重复（单类） | 16!/4! |
| 五位数 4, 4, 5, 5, 5 | 全排列 × 有重复（两类） | 5!/(2!3!) = 10 |
| 30 人选 4 人委员会 | 组合 × 无重复 | C(30,4) = 27405 |
| 掷 2 颗骰子 | 组合 × 有重复 | C(7,2) = 21 |
| 30 人选四职务 | 排列 × 无重复 | 4!·C(30,4) = 657720 |
| Toto 杯（12 场比赛读法） | 排列 × 有重复 | 3¹² |
| 8 位字节（ASCII） | 排列 × 有重复 | 2⁸ = 256 |

## 与中文通用教材记号对照

| 本手册 | 中文通用教材 | 说明 |
|---|---|---|
| Pₙ = n!（全排列） | 全排列 n!／Aₙⁿ | 概念一致 |
| Vₙ⁽ᵏ⁾（排列） | 选排列 Aₙᵏ | 本手册「排列」不含 k = n 的全排列情形，通用「排列」则涵盖之 |
| Cₙ⁽ᵏ⁾（组合） | 组合 Cₙᵏ | 概念一致 |

「全排列／组合／排列」三分编排与 V 记号在中文文献罕见，当源自德文底本 Permutation／Kombination／Variation 三分法（推断；Toto 例的德国博彩背景为旁证）。

## 转写退化对照

源文件表 16.1 的记号已退化（二项式括号、阶乘符号与上标丢失），复原对照如下（详见 [[queries/16-1全节系统性转写讹误清单]]）：

| 转写形式 | 复原形式 |
|---|---|
| Pn=n!(n=k) | Pₙ = n!（k = n） |
| Pn(k)=n/k! | Pₙ⁽ᵏ⁾ = n!/k! |
| Cn(k)=n/k | Cₙ⁽ᵏ⁾ = C(n,k) |
| Cn(k)=n+k-1/k | Cₙ⁽ᵏ⁾ = C(n+k−1,k) |
| Vn(k)=k!n/k | Vₙ⁽ᵏ⁾ = k!·C(n,k) |
| Vn(k)=nk | Vₙ⁽ᵏ⁾ = nᵏ |
