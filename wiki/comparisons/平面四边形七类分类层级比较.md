# 平面四边形七类分类层级比较

本页比较《数学手册》3.1.4 节给出的四边形族分类。源按七个小节组织，隐含三条正交的分类轴：**平行性**（平行四边形／梯形）、**边的度量与角的度量**（等边：菱形；等角：矩形）、**与圆的关系**（内接／外切）。一般四边形为基类，其余七类主体为其特化或附加条件的类。

## 层级图示

```
一般四边形（凸／凹）
├─ 平行四边形（对边平行，四性质等价）
│  ├─ 矩形（等角方向：只具直角 ⟺ 对角线等长）
│  │  └─ 正方形（a = b）
│  └─ 菱形（等边方向：四边等长 ⟺ 对角线垂直 ⟺ 对角线平分对角）
│     └─ 正方形（矩形与菱形的公共特化）
├─ 梯形（一对对边平行）
│  └─ 等腰梯形（c = d）
├─ 内接四边形（⟺ 对角和 180°）
└─ 外切四边形（⟺ a + c = b + d = s）
   └─ 双心四边形 = 内接 ∩ 外切（S = √(abcd)，式 3.41）
```

## 观察

- 矩形／菱形／正方形是平行四边形内部的两个特化方向（等角 vs 等边），正方形居其交（对偶结构详见 [[comparisons/矩形与菱形比较]]）。
- 内接／外切条件与平行性条件正交：任何四边形原则上均可附加圆条件，两类的判据与公式对照见 [[comparisons/内接四边形与外切四边形比较]]。
- 每类刻画均采用「任一条件即足」的充分性结构，是本手册的编排特色。
- 源未讨论平行四边形与梯形的包含关系（即「梯形」是否排除两对对边皆平行的情形），本 wiki 不作推断。
- 一般四边形的式 3.34（欧拉四边形定理）在 $m = 0$ 时退化为平行四边形的式 3.18，体现层级间的公式衔接（见 [[findings/内角和与欧拉四边形定理]]）。
