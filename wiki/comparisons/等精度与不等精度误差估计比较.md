# 等精度与不等精度误差估计比较

《数学手册》16.4.1.5 与 16.4.1.6 给出直接测量误差估计的两种情形：

| | 等精度（16.4.1.5） | 不等精度（16.4.1.6） |
|---|---|---|
| 前提 | n 次测量的标准差 σ_i 相同 | 各 x_i（或其均值）方差 $\tilde{\sigma}_i^2$ 不同 |
| 中心估计 | 算术平均 $\bar{x}=\frac{1}{n}\sum x_i$（16.196a） | 加权平均 $\bar{x}^{(g)}=\sum g_ix_i/\sum g_i$（16.211），$g_i=\tilde{\sigma}^2/\tilde{\sigma}_i^2$（16.212） |
| 单位标准差 | $\tilde{\sigma}=\sqrt{\sum v_i^2/(n-1)}$（16.200c） | $\tilde{\sigma}^{(g)}=\sqrt{\sum g_iv_i^2/(n-1)}$（16.213） |
| 单次测量标准差 | σ̃ 本身 | $\tilde{\sigma}_i^{(g)}=\tilde{\sigma}^{(g)}/\sqrt{g_i}$（16.214） |
| 均值标准差 | $\tilde{\sigma}_{AM}=\tilde{\sigma}/\sqrt{n}$（16.203） | $\tilde{\sigma}_{AM}^{(g)}=\tilde{\sigma}^{(g)}/\sqrt{\sum g_i}$（16.215） |
| 核验 | — | $\tilde{\sigma}^{(g)}<\tilde{\sigma}$，否则存在带系统偏差的 x_i |
| 示范算例 | n=10，x=1.580±0.004（复算全通过，σ̃_AM 精确 0.0042） | 表 16.6，n=5，x=1.585±0.0027（复算三处不一致 + σ̃ 选取疑点） |

**权重的作用**：g_i 逆方差取法使偏差小的测量值权重大（$g_i=\tilde{\sigma}^2/\tilde{\sigma}_i^2$），等价地 $\tilde{\sigma}_i=\tilde{\sigma}$ 时 $g_i=1$；等精度是 $g_i\equiv$ 常数的退化情形，此时加权平均退化为算术平均。

**算例对照的教训**：等精度算例数值全部复算通过，不等精度算例（表 16.6）存在 z̄ 值、最终中心值、σ̃⁽ᵍ⁾ 口径三处内部不一致及 σ̃ 选取疑点（见 [[findings/式16-211至16-215与表16-6加权算例转录复算]] 及其链接的四条查询），引用时须附警示。流程页见 [[methodology/等精度直接测量误差估计流程]] 与 [[methodology/逆方差加权平均误差估计流程]]。
