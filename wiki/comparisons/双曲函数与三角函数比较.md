# 双曲函数与三角函数比较

六个双曲函数（sinh、cosh、tanh、coth、sech、csch，手册 2.9 节）与六个三角函数（sin、cos、tan、cot、sec、csc，手册 2.7 节）在命名与公式结构上成对平行，但定义载体、值域、周期性与符号均有系统差异。两套体系的性质**不得因名称对应而互相转移**。二者经复辐角关系（式 2.199–2.206）相通，可用 [[concepts/三角-双曲代换规则]] 在限制条件下互相推导。

## 定义载体

| | 三角函数 | 双曲函数 |
|---|---|---|
| 定义来源 | 角/圆（[[concepts/三角函数]]） | e^x 与 e^−x 的线性组合与倒数（式 2.166–2.171）；几何定义参见手册 3.1.2.2（与三角类似） |
| 奇偶模式 | sin、tan、cot、csc 奇；cos、sec 偶 | sinh、tanh、coth 奇；cosh 偶（负角公式 2.178–2.181）；sech 偶、csch 奇为推断 |

奇偶模式在两体系间**逐一对应相同**，这是少数可安全平行记忆的性质之一。

## 周期性与值域

| 函数对 | 三角 | 双曲 |
|---|---|---|
| sin / sinh | 值域 [−1, 1]，周期 2π | 值域 ℝ，非周期，ℝ 上严格递增 |
| cos / cosh | 值域 [−1, 1]，周期 2π | 值域 [1, +∞)，最小值 1 于 A(0,1)，非周期，即 [[concepts/悬链线]] |
| tan / tanh | 值域 ℝ，周期 π，竖直渐近线 | 值域 (−1, 1)，非周期，水平渐近线 y = ±1 |
| cot / coth | 值域 ℝ，周期 π，竖直渐近线 x = kπ | 值域 (−∞,−1)∪(1,+∞)，非周期，渐近线 x = 0 与 y = ±1 |
| sec / sech | 绝对值 ≥ 1，无上界，有竖直渐近线 | 0 < sech ≤ 1（推断），水平渐近线 y = 0（推断） |
| csc / csch | 绝对值 ≥ 1，无上界，有竖直渐近线 | 值域 ℝ∖{0}（推断），x = 0 处无定义 |

（三角侧依据本 wiki 已收录的 2.7 节内容；标注「推断」者为由 2.9 节定义与 cosh/sinh 性质直接推得，手册未明言。）

## 恒等式符号差异清单

双曲与三角恒等式结构平行，但以下位置符号不同（三角侧依据 2.7 节已收录内容，双曲侧为式 2.172–2.198）：

| 关系 | 三角 | 双曲 | 差异 |
|---|---|---|---|
| 勾股型 1 | sin²α + cos²α = 1 | cosh²x − sinh²x = 1（2.172） | + 变 − |
| 勾股型 2 | csc²α − cot²α = 1 | coth²x − csch²x = 1（2.173） | 相减方向相反 |
| 勾股型 3 | sec²α − tan²α = 1 | sech²x + tanh²x = 1（2.174） | − 变 + |
| cos 加法定理 | cos(x±y) = cos x cos y ∓ sin x sin y | cosh(x±y) = cosh x cosh y ± sinh x sinh y（2.183） | ∓ 变 ± |
| tan 加法定理 | tan(x±y) = (tan x ± tan y)/(1 ∓ tan x tan y) | tanh(x±y) = (tanh x ± tanh y)/(1 ± tanh x tanh y)（2.184） | 分母 ∓ 变 ± |
| cot 加法定理 | cot(x±y) = (cot x cot y ∓ 1)/(cot x ± cot y) | coth(x±y) = (1 ± coth x coth y)/(coth x ± coth y)（2.185） | 分子构成不同 |
| cos 倍角 | cos 2x = cos²x − sin²x | cosh 2x = sinh²x + cosh²x（2.187） | − 变 + |
| cos 和差化积 | cos x − cos y = −2 sin((x+y)/2) sin((x−y)/2) | cosh x − cosh y = 2 sinh((x+y)/2) sinh((x−y)/2)（2.197） | 无负号 |

结构完全相同、可安全平行记忆的公式：sin 的加法定理（2.182）、sin 的倍角（2.186）、sin/cos 的和差化积正向公式（2.195–2.196）、奇偶性模式。

## 渐近线对比

- 三角函数：无水平渐近线；tan、cot、sec、csc 有竖直渐近线。
- 双曲函数：sinh、cosh 无渐近线；tanh、coth 有水平渐近线 y = ±1；coth 另有竖直渐近线 x = 0（手册设有图像小节的四函数中唯一）；sech、csch 的渐近线（y = 0；csch 另有 x = 0）为推断。

## 桥梁

复辐角关系（式 2.199–2.206）把两套函数联系起来：sin z = −i sinh iz、cos z = cosh iz、sinh z = −i sin iz、cosh z = cos iz 等。据此可用 [[concepts/三角-双曲代换规则]]（sin α → i sinh x、cos α → cosh x）从三角公式导出关于 x 或 ax（但非 ax + b，见 [[queries/代换规则不能得到ax加b的限制含义]]）的双曲关系；sinh 因子成对出现时 i² = −1 被吸收为符号变化，这正是上表符号差异的根源。
