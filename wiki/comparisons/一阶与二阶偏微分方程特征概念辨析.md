# 一阶与二阶偏微分方程特征概念辨析

《数学手册》在三处使用「特征」一词：9.1.2（ODE 的特征方程）、9.2.1（一阶方程的特征组/特征带）与 9.2.2（二阶方程的特征）。三处所指互不相同。本页辨析其中一阶与二阶偏微分方程的「特征」；ODE 与 PDE 之辨已由 [[comparisons/ODE特征方程与PDE特征线辨析]] 覆盖，本页是其向「一阶 PDE vs 二阶 PDE」维度的延伸。

## 对照

| 维度 | 一阶方程的特征（9.2.1） | 二阶方程的特征（9.2.2） |
|---|---|---|
| 定义载体 | 特征组 dx₁/X₁ = … = dxₙ/Xₙ（= dz/Y）（9.72a/9.73b）；非线性情形为 (x, z, p) 空间的特征带组（9.76d） | 由二阶主部系数决定的特征方程/特征曲线，用于分类与化典范形式 |
| 几何意义 | 与向量场 (X₁,…,Xₙ,Y)（两变量时 (P,Q,R)）相切的曲线；特征带还逐点携带切平面 | 使主部二阶导数组合沿之退化的曲线 |
| 所在空间 | 线性/拟线性：n+1 维 (x₁,…,xₙ,z)；非线性：2n+1 维 (x₁,…,xₙ,z,p₁,…,pₙ) | 自变量空间（n 维） |
| 与解的关系 | 积分曲面**由特征组成**：与曲面有一公共点的特征整条落在曲面上 | 解一般不由特征「组成」；特征用于把方程化为典范形式后求解 |
| 方法角色 | 特征线法/特征带法是构造解的基本构件 | 分类（双曲/抛物/椭圆）与约化工具 |
| 柯西问题唯一性 | 初始曲线处处不与特征相切 → 邻域内唯一解（9.75） | 二阶方程另有适定条件（初始数据个数与类型等），见 [[concepts/问题的正确叙述]] |

## 要点

1. **决定因素不同**：一阶特征由方程的一阶系数（向量场）完全决定；二阶特征由主部系数矩阵（二次型）决定。即便对同一自变量组，二者的特征曲线一般不重合，无换算关系。
2. **唯一性条件不可互换**：一阶柯西问题的「初始曲线不与特征相切」是一阶特有的；9.2.3 波方程柯西问题的适定叙述与之一阶情形分属不同机制，二者不得互相移植（见 [[concepts/柯西问题]]）。
3. **特征带是一阶特有的强化**：非线性一阶方程须在 (x, y, z, p, q) 空间追踪切平面（接触几何层面的对象），二阶理论中没有对应物。
4. **辨析入口**：手册行文中，「特征组」「首次积分」「积分曲面」指 9.2.1 意义；「类型」「典范形式」「判别式」指 9.2.2 意义；「特征方程 Pₙ(λ)」指 9.1.2 的 ODE 意义。
