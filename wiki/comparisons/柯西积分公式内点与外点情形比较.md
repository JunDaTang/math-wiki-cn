# 柯西积分公式内点与外点情形比较

《数学手册(原书第10版)》14.2.3 把柯西积分公式的适用点分成区域内点（14.2.3.1）与区域外点（14.2.3.2）两种情形。公式形式完全相同，差异全部落在解析性要求与曲线定向上。

| 维度 | 内点情形（14.2.3.1） | 外点情形（14.2.3.2） |
|---|---|---|
| 解析性要求 | f 在简单闭曲线 C 及其内部的单连通区域上解析 | f 在 C 的整个外部解析 |
| 适用点 | 该单连通区域的每个内点（图 14.37） | 外部区域中的点（图 14.38） |
| 公式 | $f(z) = \frac{1}{2\pi\mathrm{i}}\oint_C \frac{f(\zeta)}{\zeta-z}\,\mathrm{d}\zeta$ (14.42)；$f^{(n)}(z) = \frac{n!}{2\pi\mathrm{i}}\oint_C \frac{f(\zeta)}{(\zeta-z)^{n+1}}\,\mathrm{d}\zeta$ (14.43) | 相同公式 (14.42)、(14.43) |
| 曲线定向 | 逆时针 | 顺时针 |

## 差异的本质

两种情形共用一套公式的条件是：点 z 必须位于「以 C 为边界、f 在其上解析」的那一侧区域。内点情形该区域是 C 的内部；外点情形该区域是 C 的外部，因此 C 需顺时针走过。（此段为依标准复分析背景的解释性说明，非原书原文；原书仅陈述定向差异本身。）

## 推论

无论哪种情形，公式都给出各阶导数的积分表示 (14.43)，从而推出 [[concepts/解析函数的无穷可微性]]。借助柯西积分公式还可以计算某些实积分（回指 14.4，未入库）。
