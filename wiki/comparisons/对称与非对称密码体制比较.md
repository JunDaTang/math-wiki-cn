# 对称与非对称密码体制比较

依据本源 5.5.2 与 5.5.7 的两类体制区分（定义见 [[concepts/对称与非对称密码体制]]）。

| 维度 | 对称密码体制 | 非对称（公开密钥）体制 |
|---|---|---|
| 密钥 | 单一密钥，加密解密共用 | 密钥对：私人密钥 KS（保密）＋公开密钥 KP（可公开传递） |
| 密钥交换 | 通信前须经足够安全的信道交换（非人工通信即有违规之虞） | 公开密钥可与密文同途径传递 |
| 安全性根据 | 密钥的保密性 | 单向函数／陷门单向函数（[[concepts/陷门单向函数]]） |
| 向第三方证明发件人 | 不可能 | 可以（电子签名，[[methodology/电子签名与加密复合流程]]） |
| 设计约束 | 使用者可自由确立协议，但加解密不应太复杂，传输可靠性强制性 | 须满足四条件（D∘E = id、有效可施、KS 不可由 KP 推出、E∘D = id） |
| 本源中的代表 | [[entities/des算法]]、[[entities/idea算法]] | [[entities/rsa方法]] |
| 速度与密钥大小 | 相对快、密钥短 | RSA 密钥相对较大、速度较慢（原书倍数表述脱落，不作断言） |

## 交互与不可转移性

公开密钥概念由 Diffie 与 Hellman 于 1976 年提出；电子签名流程即以非对称运算（E∘D = id）补足对称体制无法向第三方证实发件人的缺陷。注意两类体制的安全根据不同类：RSA 系于分解难度，DES/IDEA 系于密钥长度与混淆扩散结构——任一方的安全结论不得转移给另一方（各声明仅关于各自主体，见 [[findings/des结构要点]]、[[findings/idea结构要点]]、[[findings/rsa方法参数准则与算法]]）。
