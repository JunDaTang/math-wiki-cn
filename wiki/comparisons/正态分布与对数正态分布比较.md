# 正态分布与对数正态分布比较

依据 [[10-数学手册原书第10版--9-1624-连续分布--1ktbozm]]（16.2.4.1 与 16.2.4.3），两种分布构成「加法叠加 ↔ 乘法叠加」的一对：

| 维度 | [[正态分布]] | [[对数正态分布]] |
| --- | --- | --- |
| 构造 | 直接定义（密度 (16.70b)） | Y = log X 服从正态分布（(16.76)） |
| 叠加意义（原文 16.2.4.3 e)） | 大量独立随机变量的**加法叠加** | 大量独立随机变量的**乘法叠加** |
| 支撑集 | 全实数 | (0, ∞)（密度对 t ⩽ 0 取 0，处处连续） |
| 参数含义 | μ、σ² 就是 X 的期望与方差（(16.71)） | μ_L、σ_L² 是 Y = log X 的期望与方差；X 自身的矩须另由 (16.78) 计算 |
| 期望 | μ | exp(μ_L + σ_L²/2) |
| 方差 | σ² | (exp σ_L² − 1)·exp(2μ_L + σ_L²) |
| 密度形态 | 关于 t = μ 对称，在 μ±σ 处有拐点 | 只对正自变量取正值（图 16.6；一般呈右偏，此为标准性质） |
| 概率计算 | 标准化后查 Φ：(16.72) | 取对数后查 Φ：(16.79) |
| 应用（原文） | ——（本节未单列应用，作为误差模型与构造基石） | 经济学、技术、生物过程中的寿命分析 |
| 对数底 | —— | 自然对数或常用对数均可（(16.77a) 的 log e 因子为底换算因子） |

要点：对数正态分布本质上是正态分布在乘法世界中的像——把「和的极限」换成「积的极限」（取对数后回到和），二者的所有计算最终都归结到同一个 [[标准正态分布]] 函数 Φ。
