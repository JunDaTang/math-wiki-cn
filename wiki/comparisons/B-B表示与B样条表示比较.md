# B-B表示与B样条表示比较

伯恩斯坦-贝济埃表示（19.7.3）与 B 样条表示（19.7.1.2、19.7.3.1）在基函数支撑与形状控制上的对照。

| 维度 | B-B 表示 | B 样条表示 |
|---|---|---|
| 基函数 | 伯恩斯坦多项式 B_{i,n}，[0,1] 上全局支撑（(0,1) 内恒正） | 正则化 B 样条 N_{i,4}，局部支撑 |
| 逼近多边形 | —（对照基准） | 更好地逼近多边形（原书优点 1） |
| 顶点/格点改动影响 | 曲面 (19.258) 中每个格点的影响是全局的 | 若改变多边形顶点，仅局部改变 B 样条曲线（原书优点 2） |
| 可微性 | 由次数 n 确定 | 可影响其可微性，因此可能产生间断的点和线段（原书优点 3；宜按节点重数—光滑度关系理解） |
| 端点性质 | P_0、P_n 为插值点；P_0P_1、P_{n−1}P_n 为端点切线 | 原书未并列对应性质 |
| 节点 | 控制多边形顶点（非节点概念） | 节点可自由选取，位置须满足可解性条件 |
| 方程组结构 | — | 样条方法得带状结构系数矩阵 |

## 归属注意

- 三条优点为原书对「B 样条曲线」相对「B-B 曲线」的**定性陈述**，属 B 样条一侧；
- 「每个格点的影响是全局的」为原书对 **B-B 曲面 (19.258)** 的陈述，是伯恩斯坦基全局支撑的直接推论（复算见 [[findings/式19-252至19-258伯恩斯坦多项式与B-B表示转录复算]]），原书由此建议在 (19.258) 中将伯恩斯坦多项式改为 B 样条；
- 原书总评：B 样条曲线的形状「基本相应于」B-B 曲线。
