# C_3 与 D_3 比较

两者同源于等边三角形的对称性（原书 5.3.4 例 A、例 B）：$C_3$ 只含旋转，$D_3$ 另含反射。

| 维度 | C_3（例 A） | D_3（例 B） |
|---|---|---|
| 阶 | 3 | 6 |
| 元素 | 旋转 e, R₁, R₂ | 旋转 e, R₁, R₂ + 反射 S_A, S_B, S_C |
| 交换性 | 阿贝尔（循环群，生成元 R₁，R₁³ = e） | 非阿贝尔（S_A·S_B = R₁ ≠ R₂ = S_B·S_A） |
| 二阶元 | 无 | S_A, S_B, S_C（对合；但不构成子群，因 S_A·S_B = R₁） |
| 二维表示矩阵 | 旋转矩阵，det = +1 | 旋转矩阵（det = +1）+ 反射矩阵（det = −1） |
| 表示来源 | R(φ) 代以 2πk/3（式 5.98e–g） | 群表 + D(S_B) = D(R₂)D(S_A) 等（式 5.99e–g） |
| 相互关系 | C_3 是 D_3 的旋转子群 | D_3 = C_3 ∪ {三个反射} |

**证据**：两例的矩阵与群表均已独立复算（[[findings/c3二维旋转表示算例]]、[[findings/d3群表与二维表示算例]]）。

**推断注记**（非原书主张）：$D_3$ 群表的结构（单位元 + 三个对合 + 两个 3 阶元）表明 $D_3 \cong S_3$（见 [[entities/对称群s-m]]）；例 A + 例 B 的六个二维矩阵即 $S_3$ 的二维不可约表示。
