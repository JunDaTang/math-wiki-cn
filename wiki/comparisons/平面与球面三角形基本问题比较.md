# 平面与球面三角形基本问题比较（4 ↔ 6 问题）

本比较综合 [[sources/10-数学手册原书第10版--12-343-球面三角形的计算--170nm2t]]（3.4.3.3，表 3.9–3.12）与 [[sources/10-数学手册原书第10版--8-32-平面三角学--j56osm]]（3.2，表 3.4），延续 [[comparisons/多边形角和与多面角面角和比较]] 的 2D/3D 对偶模式。球面的六问题体系**扩展而非否定**平面的四问题结论。

| 维度 | 平面三角形（3.2 表 3.4） | 球面三角形（3.4.3.3 表 3.9–3.12） |
|---|---|---|
| 基本问题数目 | 4 | 6 |
| 仅由角求解 | 不可能（[[findings/平面三角形边不可仅由角得到]]） | WWW 可解（第二基本问题）：球面三角形无相似缩放，角决定大小 |
| 已知三边 | 满足边不等式即存在 | 需 0° < a+b+c < 360° 且两边和大于第三边（恰为三面角面角和定理条件） |
| 已知三角 | 不构成约束问题 | 需 180° < α+β+γ < 540° 等四条件 |
| 歧义分支 | SSA 可两解/一解/无解（[[findings/一般三角形四个基本问题与SSA分支]]） | SSW 与 WWS 均可双值（β₁ 锐 / β₂ 钝），分支更细且两组互为对偶（[[findings/SSW与WWS歧义分支]]） |
| 相似性 | 相似三角形边角分离 | 无相似类（相似即全等），这是 WWW 可解的根源 |
| 解法工具 | 正弦/余弦定律、半角公式 | 同左，另有纳皮尔类比、半边公式族（k′ 与 cot(a/2)）、辅助角法、球面垂线分解为两个直角三角形 |
| 检验手段 | 几何一致性 | 检验恒等式（如 tan(α/2)tan(β/2)tan(γ/2)·sin s = k）与同一量的双重计算（[[methodology/球面三角形公式选择与精度规则]]） |

关键差异的机理：平面三角形在相似变换下不变，边长含一个整体尺度因子，故角不能定边；球面三角形的「边」本身是角度，尺度固定为球半径，故六个组合（除歧义分支外）原则上都可解。平面 SSA 的歧义在球面上同时出现在 SSW 与 WWS 两侧，且因正弦函数在第一、二象限均取正，欧拉三角形中正弦定律恒给两个候选值。
