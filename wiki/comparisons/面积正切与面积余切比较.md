# 面积正切与面积余切比较

[[concepts/面积正切]]（Artanh）与 [[concepts/面积余切]]（Arcoth）分别是 [[concepts/双曲正切函数]] 与 [[concepts/双曲余切函数]] 的反函数，经倒数变换 $x \mapsto 1/x$ 互相表示，是四种 [[concepts/面积函数]] 中联系最紧密的一对。

## 枢纽关系

$$\operatorname{Artanh} x = \operatorname{Arcoth} \frac{1}{x} \qquad \text{（式 2.217 中项、式 2.218 首项）}$$

验证：$\operatorname{Arcoth}\frac{1}{x} = \frac{1}{2}\ln\frac{1/x + 1}{1/x - 1} = \frac{1}{2}\ln\frac{1+x}{1-x} = \operatorname{Artanh} x$（$|x| < 1$ 时 $1/x$ 恰落入 Arcoth 的定义域 $|1/x| > 1$）✓。边界保留：该式在 $x = 0$ 处失义（见 [[queries/式2-215与2-217含1除x等式是否应排除x等于0]]）。

## 性质对照

| | Artanh | Arcoth |
|---|---|---|
| 反函数对象 | tanh | coth |
| 定义域 | \|x\| < 1 | \|x\| > 1 |
| 值域 | −∞ < y < ∞ | y ≠ 0（按分支） |
| 定义域结构 | 单连通区间 | 两个不连通区间 |
| 奇偶性 | 奇 | 奇 |
| 单调性 | 严格递增 | 两分支均严格递减 |
| 渐近线 | x = ±1（两条，铅直） | y = 0 与 x = ±1（三条） |
| 对称中心/拐点 | 原点（合一），切线倾角 π/4 | 原点为对称中心，不在定义域内 |
| 对数表示 | ½ln((1+x)/(1−x)) | ½ln((x+1)/(x−1)) |
| 负角公式 | 式 2.223 | 式 2.224 |

## 结构解读

- **定义域互补**：$|x| < 1$ 与 $|x| > 1$ 的并集为 $\mathbb{R} \setminus \{\pm 1\}$——两函数在 $x = \pm 1$ 处均无定义（Artanh 的铅直渐近线、Arcoth 的分支端点）。
- **渐近线的对应**：倒数变换把 $x \to \pm 1^\mp$（Artanh 的发散处）对应到 Arcoth 的 $x = \pm 1$ 渐近线；把 $x \to \pm\infty$（即 $1/x \to 0$）对应到 Arcoth 的水平渐近线 $y = 0$（因 $\operatorname{Artanh}(0) = 0$）。
- **单调性相反**：tanh 递增、coth 各分支递减，故其反函数的单调性亦相反（此对照由双曲侧性质直接继承，见 [[findings/四个双曲函数的图像性质体系]]）。
