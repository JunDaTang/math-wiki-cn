# 第一类与第二类弗雷德霍姆积分方程比较

二者同属 [[concepts/弗雷德霍姆积分方程]]，按未知函数是否同时出现在积分号外而分为两类。本页第一类各栏依据数学手册 11.3（本页 sources）；第二类各栏依据已入库的 11.2 系列页面（见文末依据）。

## 对照表

| 维度 | 第一类（11.3） | 第二类（11.2） |
|---|---|---|
| 标准形式 | f(x) = ∫_a^b K(x,y)φ(y)dy（11.41），未知函数仅在积分号内 | φ(x) − λ∫_a^b K(x,y)φ(y)dy = f(x)，未知函数同时出现于积分号外 |
| 谱参数 λ | 无（11.3 全节） | 有，是本征值理论与 [[concepts/弗雷德霍姆定理]] 的核心 |
| 可解性 | f 必须属于算子值域：退化核时 f ∈ span{α₁,…,α_n}（11.38c）；一般表现为 f ⊥ 伴随齐次解（算例 f₀ = 0、11.3.5 的 f_j = 0） | Fredholm 备择：λ 非本征值时对任意 f 唯一可解；λ 为本征值时需 f 与转置/伴随齐次方程的解正交 |
| 唯一性 | 退化核时**永不唯一**（齐次解集 = 与所有 β_j 正交的函数全体，无穷维，11.40）；非退化核可能唯一（11.3.3/11.3.4 奇异核算例原齐次方程仅平凡解） | λ 非本征值时唯一；本征值时解不唯一或不存在 |
| 齐次方程的地位 | 齐次解刻画解的自由度；伴随齐次解给出可解性障碍 | 齐次方程即本征值问题（[[concepts/积分方程的本征值与本征函数]]） |
| 代表方法 | 退化核待定系数（11.3.1）、规范正交投影/[[concepts/核矩阵]]（11.3.3–11.3.4）、双对角化（11.3.5）、迭代法（11.3.6） | 退化核法（[[methodology/退化核求解流程]]）、[[methodology/逐次逼近法]]（诺伊曼级数/[[entities/预解式]]）、[[methodology/弗雷德霍姆解法]]、数值解法 |
| 解的表示 | 函数级数 φ = Σc_jβ_j，系数由无穷方程组或矩量等式确定 | φ = f + λ∫Γ(x,y;λ)f dy（预解式核表示） |

## 讨论

- **可解性条件的统一观点**：第一类的 f₀ = 0 等正交条件与第二类 Fredholm 备择中的正交条件同源，均为「f ⊥ 伴随齐次解空间」——见 [[concepts/积分方程的正交可解性条件]]。差别在于：第二类只在离散的本征值处受阻，第一类则处处受值域限制。
- **方法论分野**：第二类方法围绕逆算子 (I − λT)⁻¹ 的构造（诺伊曼级数收敛条件）；第一类没有 (I − λT) 结构，只能直接处理 T 本身——投影为核矩阵、构造双对角基对、或由 f 生成函数系（矩量法）。
- **退化核情形的鲜明对照**：同为退化核，第二类按行列式判据分两种情形且一般唯一可解，第一类则可解性受 span{α_j} 限制且齐次方程总有非平凡解——比较 [[methodology/退化核求解流程]] 与 [[methodology/第一类退化核方程求解流程]]。
- 分析者注记（非手册内容）：第一类方程一般是不适定问题（右端小扰动可导致解的大偏差），现代处理依赖正则化理论；手册 11.3 未讨论不适定性，但 11.3.6 的迭代法（矩量/Krylov 型）在现代理论中恰与正则化密切相关。
