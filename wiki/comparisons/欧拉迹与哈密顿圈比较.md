# 欧拉迹与哈密顿圈比较（边覆盖 vs 顶点覆盖）

《数学手册》5.8.2 将两类遍历问题并列于同一节（5.8.2.2 与 5.8.2.3），二者形似而难度悬殊：

| 维度 | [[concepts/欧拉迹与欧拉图]] | [[concepts/哈密顿圈]] |
|---|---|---|
| 覆盖对象 | **每条边**（恰一次） | **所有顶点**（每个恰一次） |
| 结构载体 | [[concepts/边序列路迹与圈]] 中的**迹**（无重复边） | **基本圈**（无重复顶点） |
| 完全刻画 | 有：[[concepts/欧拉-希尔霍尔策定理]]（次数全正偶数 ⟺ 欧拉图）；开欧拉迹 ⟺ 恰两奇次顶点 | 无：仅有充分条件（[[concepts/狄拉克定理]]、[[concepts/奥尔定理]]、[[concepts/波萨定理]]） |
| 判定复杂性 | 次数奇偶统计即可（易） | 经典 NP 完全问题（本源断言，未给引证） |
| 构造 | [[methodology/闭欧拉迹拼接构造流程]]（有限步拼接） | 无有效算法（本源断言） |
| 优化版本 | [[concepts/中国邮递员问题]]：情形 (1) 平凡最优，情形 (2) 有 Edmonds–Johnson 有效算法 | 本源未涉 |

## 关键对照

「每条边恰一次」只受局部奇偶性约束（进出每个顶点配对用边），故次数判据给出完全刻画；「每个顶点恰一次」是全局排列约束，充分条件只能从次数、邻接等局部信息逼近。这一对照是 5.8.2 全节的组织逻辑（推断性总结，非本源明言）。
