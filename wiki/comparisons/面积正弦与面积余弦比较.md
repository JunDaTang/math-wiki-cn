# 面积正弦与面积余弦比较

基于 [[sources/10-数学手册原书第10版--8-210-面积函数--1cebibi]] 2.10.1.1–2.10.1.2。

| 维度 | Arsinh x | Arcosh x（主支） |
|---|---|---|
| 反演对象 | sinh（全域严格递增） | cosh（两个单调区间） |
| 定义域 | −∞ < x < ∞ | 1 ≤ x < ∞ |
| 值域 | −∞ < y < ∞ | 0 ≤ y < ∞（负支 −∞ < y ≤ 0） |
| 奇偶性 | 奇函数 | 无（x < 1 无定义） |
| 对数表示 | ln(x + √(x²+1))，全域成立 | ln(x + √(x²−1))，仅 x ≥ 1 |
| 关键点 | 原点：对称中心 + 拐点 + π/4 切线 | 起点 A(1, 0)：垂直切线 |
| 单调性 | 严格递增 | 主支严格递增、负支严格递减 |
| 渐近线 | 无 | 无（但定义域有下界 1） |
| 和差公式 | 式 2.219，无条件缺陷 | 式 2.220，减法分支需 x ≥ y（手册未注） |

## 平行与差异

二者分别是 [[concepts/双曲正弦函数]] 与 [[concepts/双曲余弦函数]] 的反演，差异根源在于 cosh 非单射：Arsinh 是四函数中性质最「良好」者（全局双射、奇、无条件陷阱），Arcosh 则引入主支选取（[[concepts/主值]]）与和差公式的分支问题。这一平行关系对应反三角函数中 [[concepts/反正弦函数]] 与 [[concepts/反余弦函数]] 的比较（见 [[comparisons/反正弦与反余弦比较]]）。
