# 外摆线与内摆线比较

[[concepts/外摆线]] 与 [[concepts/内摆线]] 是圆滚动基上互为对偶的两支；手册明言内摆线诸公式由外摆线「−a 代换 +a」得到。系统对比如下：

| 项目 | 外摆线（2.13.3） | 内摆线（2.13.4） |
|---|---|---|
| 滚动方式 | 动圆沿定圆**外侧**滚动 | 动圆**内切**于定圆滚动 |
| 方程 | 式 2.244（$+a$ 记法） | 由式 2.244 作 −a 代换 |
| 参数约束 | $m = A/a > 0$ 无限制 | 必须 $m > 1$ |
| 尖点/分支分类 | 整数 m 个分支；有理数有限圈闭合；无理数不闭合 | 相同（手册明言尖点个数与外摆线相同） |
| 单支长 | $\dfrac{8(A+a)}{m}$ | $\dfrac{8(A-a)}{m}$（−a 代换，推导） |
| 整数 m 总长 | $8(A+a)$ | $8(A-a)$（推导；m = 3 时 $16a$、m = 4 时 $24a$ 与手册值吻合） |
| 面积 | 区域 $A_1B_1A_2A_1$（**不含定圆**）$S = \pi a^2\dfrac{3A+2a}{A}$ | **所指歧义**：−a 代换得定圆与曲线之间的区域面积（单支 $\pi a^2\dfrac{3A-2a}{A}$），而手册给出的 $S_{\text{总}}$ 是曲线自围面积 |
| 曲率半径 | $r = \dfrac{4a(A+a)}{2a+A}\sin\dfrac{A\varphi}{2a}$ | $r = \dfrac{4a(A-a)}{A-2a}\sin\dfrac{A\varphi}{2a}$（−a 代换，推导；$A = 2a$ 时退化） |
| 特化点 | $m = 1$：[[concepts/心脏线]] | $m = 2$：退化为定圆直径；$m = 3$：三支曲线（$L_{\text{总}} = 16a$、$S_{\text{总}} = 2\pi a^2$）；$m = 4$：[[concepts/星形线]] |

## 关键差异

1. **退化行为不对称**：内摆线在 $m = 2$ 退化为线段（此时曲率公式分母 $A - 2a$ 为零），外摆线无对应退化；外摆线在 $m = 1$ 特化为心脏线，内摆线因 $m > 1$ 约束无此特化。
2. **面积口径差异**：外摆线面积公式明确注明「不包括定圆部分」；内摆线一节的 −a 代换句与随后给出的 $S_{\text{总}}$ 分属两个不同的量（区域面积 vs 曲线自围面积），是两支之间最重要的未决疑点，见 [[queries/内摆线面积负a代换与S总所指面积是否一致]]。
3. 弧长与曲率的 −a 代换均核验一致，无歧义。

两支共同推广为 [[concepts/长短幅外摆线与内摆线]]（$\lambda \neq 1$）；全族谱系见 [[comparisons/摆线族两轴分类比较]]。
