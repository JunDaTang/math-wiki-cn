# 命题演算与谓词演算表达力比较

依据《数学手册(原书第10版)》5.1：

| 维度 | 命题演算（5.1.1） | 谓词演算（5.1.2） |
|---|---|---|
| 基本对象 | 命题（整句，取 T/F） | 个体、谓词、量词 |
| 表达力 | 只能组合整句的真值，不考虑语句内涵 | 可刻画对象的性质与关系（「n 是素数」「m 小于 n」） |
| 公式构造 | 命题变量 + ¬,∧,∨,⇒,⇔（式 5.6–5.7） | 基本公式 P(x₁,…,xₙ) + 联结词 + ∀x、∃x（式 5.21–5.22） |
| 语义 | 真值表（解释 = 变量的真值指派） | 解释 =（个体区域，谓词符号指派）二元组 |
| 恒真概念 | 重言式（真值函数恒为 T） | 逻辑有效公式（对每个解释恒真） |
| 验证方式 | 真值表机械检验（有限 2^n 行） | 解释族无穷，须语义论证（恒等式 5.24–5.28、单向蕴涵 5.29–5.33） |

**关系**：命题演算可嵌入谓词演算——将命题变量看作零位谓词（[[findings/谓词与量词的语法定义与命题演算嵌入]]）。原书主张谓词演算表达力更强：「为刻画多数数学对象的性质和这些对象间的关系，谓词演算是必须的」。

**方法论差异的后果**：命题演算的等价与有效性可经穷举真值表判定（[[methodology/真值表验证逻辑等价的流程]]）；谓词演算则不能穷举解释，故 5.1.2 只能以语义论证给出定律——这也解释了两子节体例的不同。
