# 垂直切线与尖点两种不可导情形比较（例 A vs 例 C）

比较手册 6.1.1 的两种「双侧差商极限不存在」的不可导情形。二者的结论**各自专属**：f′=±∞ 的刻画仅属例 A 型，尖点刻画仅属例 C 型，不可相互转移。

| 维度 | 例 A：垂直切线 | 例 C：尖点 |
|---|---|---|
| 函数 | f(x)=∛x | f(x)=x/(1+e^(1/x))，补充定义 f(0)=0 |
| 双侧差商极限 (6.1) | 趋于 +∞（广义存在） | 不存在 |
| 左导数 | +∞ | f′(−0)=1（有限） |
| 右导数 | +∞ | f′(+0)=0（有限） |
| 记法 | f′(0)=∞（导数不存在） | f′(−0)=tan α₁，f′(+0)=tan α₂（式 6.3） |
| 几何 | 一条垂直于 x 轴的切线 | 两条斜率不同的单侧切线（尖点/角点） |
| 所属条目 | 3 可微性（「切线垂直于 x 轴」情形） | 4 左、右侧可微性 |
| 图版 | 图 6.2(a) | 图 6.2(c)、图 6.3 |
| 复算状态 | 已验证 | 已验证 |

## 判别口径

- 区分二者的关键在**单侧极限的有限性**：例 A 的左右差商极限同为 +∞（无穷）；例 C 的左右极限均有限且不等（1≠0），据式 (6.3) 判为尖点。
- 两种情形下双侧极限都不存在、函数都在该点连续（补充定义后），但几何形态与记法完全不同。
- 术语背景（独立可查证的通行用法）：例 C 型点通行称角点/折点（corner），尖点（cusp）另指单侧导数为异号无穷的情形，见 [[尖点译名与knee角点术语问题]]。
