# 二项分布、超几何分布与泊松分布比较

《数学手册(原书第10版)》16.2.3 在同一[[concepts/瓮模型]]框架下给出的三种离散分布对照（公式编号均属该节；正文 p^k(n−p)^{n−k} 等转写讹误已修正，方差式按疑议编号 (16.67b) 记）：

| 维度 | [[concepts/二项分布]] | [[concepts/超几何分布]] | [[concepts/泊松分布]] |
|---|---|---|---|
| 试验背景 | 放回抽样 / n 重独立重复试验 | 不放回抽样 | 二项的稀有事件极限；点状事件计数 |
| 独立性 | 各次抽取独立 | 各次抽取不独立 | ——（单参数分布） |
| 分布律 | W_p^n(k)=C(n,k)p^k(1−p)^{n−k}（16.62） | W_{M,N}^n(k)=C(M,k)C(N−M,n−k)/C(N,n)（16.66a） | P(X=k)=λ^k e^{−λ}/k!（16.68） |
| 参数 | n, p | N, M, n | λ>0 |
| 支撑集 | k=0,1,…,n | 0≤k≤n, k≤M, n−k≤N−M（16.66b） | k=0,1,2,… |
| 期望 | np（16.65a） | nM/N（16.67a） | λ（16.69a） |
| 方差 | np(1−p)（16.65b） | n(M/N)(1−M/N)·(N−n)/(N−1)（16.67b） | λ（16.69b） |
| 方差—期望关系 | 方差 < 期望 | 期望同二项（p=M/N），方差再乘 (N−n)/(N−1)≤1 | 方差 = 期望（等散布） |
| 递推 | W(k+1)=((n−k)/(k+1))·(p/q)·W(k)（16.65d） | W(k+1)=((n−k)(M−k))/((k+1)(N−M−n+k+1))·W(k)（16.67c） | P(k+1)=(λ/(k+1))·P(k)（16.69c） |
| 可加性 | 同 p：B(n,p)+B(m,p)=B(n+m,p)（原文未声明独立性） | 手册未给 | 独立：Po(λ₁)+Po(λ₂)=Po(λ₁+λ₂) |
| 手册给出的逼近 | →正态（np>4 且 n(1−p)>4）；→泊松（p≤0.08 且 n≥1500p，待核） | →二项（M 与 N−M 均远大于 n） | ——（作为二项极限出现） |
| 图示 | 图 16.2：n=5, p=0.5/0.25/0.1 | 图 16.3：N=100, n=5, M=50/25/10 | 图 16.4：λ=2.5/1.25/0.5 |

## 要点

1. **抽样方式是分岔点**：放回 → 二项，不放回 → 超几何；两者期望同形（以 p=M/N 代入），差别全在方差的有限总体校正因子 (N−n)/(N−1)。当 M 与 N−M 均远大于 n 时该因子趋于 1，超几何退化为二项——手册图 16.2/16.3 的参数组正是按此设计（N=100, n=5, p=M/N），两图「无明显区别」即其佐证。
2. **参数链自洽**：图 16.2/16.3/16.4 的三组参数满足 M/N=p 与 λ=np（0.5/0.25/0.1 → 2.5/1.25/0.5），使三图可逐幅对照同一成功率下的三种模型。
3. **方差序**：同一期望水平下，超几何方差 ≤ 二项方差 < 期望，而泊松方差 = 期望（等散布）；三者散布结构不同，矩与逼近条件不可互相套用。
4. **递推结构同源**：三条递推均为相邻比值 W(k+1)/W(k) 形式，且泊松的 (16.69c) 即二项 (16.65d) 在 n→∞、p→0、np=λ 下的极限（(n−k)p/((k+1)q) → λ/(k+1)），印证分布间的极限关系。
5. **逼近条件互斥使用**：正态逼近（n 大、p 居中）与泊松逼近（p 小）分属不同适用域；手册两处条件转写均有存疑处，详见[[concepts/二项分布的正态逼近]]、[[concepts/二项分布的泊松逼近]]及[[methodology/二项分布逼近选用流程]]。
