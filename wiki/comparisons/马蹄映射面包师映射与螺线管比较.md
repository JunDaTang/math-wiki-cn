# 马蹄映射、面包师映射与螺线管比较

17.2.4.4 给出三个典型吸引子/不变集例子。三者共享「拉伸—压缩—折叠/缠绕」的混沌机制与康托尔型横向结构，但严格性与可计算性递增。

| 属性 | 例 A 马蹄型映射 | 耗散面包师映射 | 螺线管 |
|---|---|---|---|
| 底空间 | $M=[0,1]^2$ 单位方形 | $M=[0,1]^2$ 单位方形 | 实心环 $T$（局部坐标 $(\Theta,x,y)$） |
| 映射操作 | 一向线性拉长、一向线性压缩、中间弯折 | $x$ 倍增堆叠、$y$ 乘 $\alpha$（式 17.56a） | $\Theta$ 倍增、$(x,y)$ 收缩并平移至 $\tfrac12(\cos\Theta,\sin\Theta)$（式 17.57） |
| 参数 | 源文未给数值 | $\alpha$（源文作 $(1,\tfrac12)$，疑为 $(0,\tfrac12)$，见 [[queries/面包师映射α区间疑为0到二分之一之辨]]） | $\alpha\in(0,\tfrac12)$ |
| 不变集 | $\Lambda=\bigcap_k\varphi^k(M)$（17.55），紧不变 | $\Lambda=\bigcap_k\varphi^k(M)$，不变且吸引 $M$ 中所有点 | $\Lambda=\bigcap_k\varphi^k(T)$，有吸引邻域 |
| 局部结构 | 「直线×康托尔集」（源文，**存疑**，见 [[queries/马蹄例子吸引性与经典构造不符之辨]]） | 「千层酥」层状结构 | 沿长度方向连续曲线（每根在 $\Lambda$ 中稠、不稳定）×康托尔横截面 |
| 豪斯多夫维数 | 未给 | $1+\ln2/(-\ln\alpha)$（**精确**，17.56b） | $1-\ln2/\ln\alpha=1+\ln2/\|\ln\alpha\|\in(1,2)$（**精确**） |
| 李雅普诺夫维数 | 未给 | $=d_H(\Lambda)$（精确，17.56c） | 未给 |
| 测度熵 | 未给 | $h_\mu=\ln2$（佩辛公式，17.56d，源文限定「此时」） | 未给 |
| 不变测度 | 未述 | 存在 $\mu\ne$ 勒贝格测度的不变测度 | 未述 |
| 结构稳定性 | 未述 | 未述 | $C^1$ 小扰动下结构稳定 |
| 双曲性 | 未述 | 未述 | 双曲吸引子之例 |

## 分析

- **可计算性梯度**：例 A 仅给构造与定性断言（且吸引性表述存疑）；面包师的维数、指数、熵构成一条**可完全复核的精确链条**（$d_H=d_L=1+\ln2/|\ln\alpha|$、$h_\mu=\ln2$，见 [[findings/式17-55至17-57马蹄面包师与螺线管吸引子转录复算]]）；螺线管的维数精确、且是三者中唯一被源文赋予结构稳定性与双曲性的；
- **共同横向结构**：康托尔集（[[concepts/康托尔集]]）是三者横向截面的公共构件，也是它们与 17.2.4.1 分形理论的衔接点；
- **结构稳定性语境**：螺线管为 [[concepts/结构稳定性]]（17.1.4）提供高维正例，与该节「结构稳定系统在高维非通有」的论断并置不悖——非通有不等于不存在。例 A 与经典斯梅尔马蹄的关系在 [[queries/马蹄例子吸引性与经典构造不符之辨]] 裁决前，其稳定性属性不应外推。
