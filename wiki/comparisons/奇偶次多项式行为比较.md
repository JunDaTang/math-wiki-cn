# 奇偶次多项式行为比较

依据《数学手册(原书第10版)》2.3.4（式 2.43），按次数 n 的奇偶与最高次项系数 $a_n$ 的符号比较 n 次多项式的图像行为：

| 维度 | n 奇 | n 偶 |
|---|---|---|
| 端部行为（$a_n>0$） | $-\infty \to +\infty$ | $+\infty \to$ 极小 $\to +\infty$ |
| 端部行为（$a_n<0$） | $+\infty \to -\infty$ | $-\infty \to$ 极大 $\to -\infty$ |
| 两端走向 | 异侧 | 同侧 |
| 与 x 轴 | 相交或相切至多 n 次，**至少一个交点** | 相交或相切至多 n 次，可能不交 |
| 极值个数 | 0 或不超过 n−1 的偶数 | 奇数 |
| 拐点个数 | 介于 1 与 n−2 之间的奇数（n ≥ 3） | 偶数或 0 |
| 渐近线/奇点 | 无 | 无 |

两情形共同规律：极大值与极小值**交错出现**。

## 低次印证

- n=1（奇，[[线性函数]]）：极值 0 个（偶数含 0）、恰一个 x 轴交点；「拐点奇数个」规律不适用（n=1 退化，见 [[奇次多项式拐点规律在n等于1时是否失效]]）；
- n=2（偶，[[二次多项式]]）：极值恰 1 个（奇数）、拐点 0 个（偶数或 0）、可无 x 轴交点；
- n=3（奇，[[三次多项式]]）：极值 0 或 2 个（不超过 n−1=2 的偶数）、拐点恰 1 个、至少一个 x 轴交点。

## 结构原因（推断）

$y'$ 为 n−1 次、$y''$ 为 n−2 次，分别给出极值与拐点个数的上界；端部符号由 $a_n x^n$ 主导，其奇偶性决定两端异侧或同侧；奇偶性结论由端部行为与极大极小交错规律联合导出。详见 [[n次多项式奇偶分支行为规律]]。
