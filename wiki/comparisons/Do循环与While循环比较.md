# Do 循环与 While 循环比较

据《数学手册（原书第10版）》20.2.9（式 20.24a/b），`Do` 与 `While` 同为 Mathematica「其他程序设计语言中所熟知的循环结构」的两个基本命令，其分野在于迭代控制方式。

| 维度 | Do | While |
|---|---|---|
| 语法 | `Do[expr, {i, i1, i2, di}]` | `While[test, expr]` |
| 迭代控制 | 事先给定的次数（i 自 i1 至 i2，步长 di） | 条件 test 保持 True |
| 默认值 | 略 di 则步长 1；再略 i1 则自 1 起 | 无（条件必给出） |
| 终止 | i 越过 i2 | test 不再为 True |
| 原文概括 | 「按照事先给定的次数对其自变量赋值」 | 「赋值直到事先给定的条件失效」 |
| 本节算例 | 式 20.25（e² 级数）、例 A（sumq） | 本节未给出算例 |

要点：

- 二者在本节中均以「赋值」措辞描述循环体执行，疑为「求值」之翻译残留（[[queries/赋值措辞疑为求值语义之辨]]）；
- 本节全部算例（e²、sumq）均用 `Do`，`While` 仅有语法定义而无算例，其行为细节不据本来源展开；
- 语法语义之一致性核对见 [[findings/式20-24与20-26循环与模块语法转录复算]]。
