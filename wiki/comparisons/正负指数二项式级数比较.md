# 正负指数二项式级数比较

依据 [[sources/10-数学手册原书第10版--10-215-重要级数展开--1gmcxgd]] 代数函数块，将正指数族 $(1\pm x)^m$（$m>0$）与负指数族 $(1\pm x)^{-m}$（$m>0$）并排比较。

| 比较项 | 正指数族 $(1\pm x)^m$ | 负指数族 $(1\pm x)^{-m}$ |
|---|---|---|
| 通项 | $(\pm1)^n\binom{m}{n}x^n$，分子为下降乘积 $m(m-1)\cdots(m-n+1)$ | $(\mp1)^n\binom{-m}{n}x^n$，分子为上升乘积 $m(m+1)\cdots(m+n-1)$ |
| 首项符号 | $1\pm mx$ | $1\mp mx$ |
| 收敛域 | $\lvert x\rvert\leqslant1$ | $\lvert x\rvert<1$ |
| 端点行为 | $\lvert x\rvert=1$ 绝对收敛（$m>0$；整数 $m$ 截断为多项式） | 端点一般发散；复算注记：个别分数指数在单侧端点可条件收敛（如 $(1+x)^{-1/2}$ 于 $x=1$），表按开区间统一处理 |
| 特例覆盖 | 5 行分数指数（$\tfrac14,\tfrac13,\tfrac12,\tfrac32,\tfrac52$） | 7 行分数指数（$-\tfrac14$ 至 $-\tfrac52$）+ 3 行整数（$-3,-4,-5$，因式化形式） |
| 校勘状态 | $(1\pm x)^{5/2}$ 行尾符号存疑（1 处） | 全部复算吻合 |

## 讨论

- 符号链差异的根源：奇次项在 $(1-x)$ 系列中整体翻转，故两族首项即分别为 $\pm mx$ 与 $\mp mx$；偶次项两系列同号，不带复合号。
- 负指数整数特例采用因式化形式（如 $(1\pm x)^{-3}=1\mp\frac{1}{1\cdot2}(2\cdot3x\mp3\cdot4x^2+\cdots)$），便于手工计算时逐步约简。
- 复算详见 [[findings/21-5全表级数系数与通项复算]]；正指数块的唯一疑点见 [[findings/1±x二分之五次方行尾符号不符复算]]。
