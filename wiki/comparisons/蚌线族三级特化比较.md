# 蚌线族三级特化比较

本比较梳理 2.12 节蚌线材料的层级结构：一个构造、两个母曲线特例、一个参数临界特例。

| 层级 | 对象 | 母曲线（f(φ)） | 蚌线方程 | 参数角色 |
|---|---|---|---|---|
| 构造层 | [[concepts/一般蚌线]]（式 2.234） | 任意 ρ = f(φ) | ρ = f(φ) ± l | l 为极径平移量 |
| 特例 1 | [[concepts/尼科梅德斯蚌线]] | 直线 x = a（f = a/cos φ） | ρ = a/cos φ ± l（式 2.233c） | l 与“极点到直线距离 a”之比驱动奇点 |
| 特例 2 | [[concepts/帕斯卡蜗线]] | 过极点、直径 a 的圆（f = a cos φ） | ρ = a cos φ + l（式 2.235b） | l 与“圆直径 a”之比驱动奇点（方向与特例 1 相反） |
| 特例的特例 | [[concepts/心脏线]] | 蜗线取 a = l | ρ = a(1 + cos φ)（式 2.237c） | 临界比 l/a = 1，原点为尖点 |

## 层级归约的代数依据（已复核）

- 式 2.235b 平方消根可得隐式式 2.235a（$\rho^2 - ax = l\rho$ 两边平方）。
- 式 2.233c 即 f = a/cos φ 代入式 2.234。
- 蜗线隐式取 l = a 时 $a^2x^2$ 相消，得心脏线隐式 2.237a。

## 两特例的关键差异

- **母曲线是否过极点**：直线 x = a 不过极点，圆（原点在圆周上）过极点——这直接导致两族奇点三分律方向相反（见 [[comparisons/尼科梅德斯蚌线与帕斯卡蜗线奇点分类比较]]）。
- **参数 a 的几何意义不同**：极点到直线的距离 vs. 圆的直径。
- **渐近线**：蚌线双支有渐近线 x = a（[[concepts/渐近线]]）；蜗线母曲线有界，无渐近线。
- **面积**：蜗线有有限面积公式 $S = \pi a^2/2 + \pi l^2$；蚌线右支与渐近线围成面积无穷。
- **命名特例**：蜗线的临界情形 a = l 被单独命名为心脏线并独立设节（2.12.4）；蚌线的临界情形 l = a 仅为尖点，未单独命名。
