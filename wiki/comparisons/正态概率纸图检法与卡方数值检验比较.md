# 正态概率纸图检法与 χ² 数值检验比较

《数学手册(原书第10版)》16.3.3.1 将判断"样本是否来自正态分布"的两条路径并列（依据均为 [[sources/10-数学手册原书第10版--9-1633-重要检验--a4awuc]] 本节原文）：

| 维度 | 概率纸图检法 | χ² 数值检验 |
|---|---|---|
| 方法性质 | 图形、直观 | 数值、形式化 |
| 输入 | 累计相对频率（式 16.125）× 组上界 | 分组频数 h_j、理论概率 p_j |
| 判定依据 | 点列是否"大致落在一条直线上（偏差很小）" | χ_S² 与 χ²_{α;m} 的大小比较（16.132d） |
| 判定客观性 | 主观（无显式阈值） | 客观（给定显著性水平 α 与自由度 m） |
| 附加产出 | 可从直线读出 μ（z=0 处）与 σ（z=±1 间距），如图 16.14 读得 μ≈176、σ≈37.5 | 仅接受/拒绝判定 |
| 前提条件 | 组上界与累计频率 | 并组规则 np_j≥5；参数未知时以 x̄、s² 代之并扣自由度 |
| 概率基础 | Φ 的线性化（16.130–16.131c） | χ² 分布近似（16.132c） |
| 手册算例 | 表 16.3 数据（图 16.14） | 同一实例的表 16.4（n=125），接受正态假设 |
| 推广性 | 依赖 Φ 刻度，主要针对正态 | 基本思想适用于其他分布 |

两条路径共用同一实例数据（16.3.2.1），结论一致（正态假设可接受），构成"先图检、后数值"的互补流程。操作细节见 [[methodology/卡方拟合优度检验并组与自由度核算流程]]；复算见 [[findings/式16-130至16-132d概率纸与卡方检验转录复算]]。
