# 五种两变量布尔函数比较（表 5.6）

$n=2$ 时共有 16 个布尔函数；手册表 5.6 列出其中最重要的五种（值表次序为 $(a,b)=(0,0),(0,1),(1,0),(1,1)$；五组值表已全部复算无误）：

```
函数名称          不同的记号                              值表
Sheffer 或 NAND   (a·b) 的否定,  a|b,  NAND(a,b)          1, 1, 1, 0
Peirce 或 NOR     (a+b) 的否定,  a↓b,  NOR(a,b)           1, 0, 0, 0
反等价或 XOR      āb+ab̄ [更正],  a XOR b,  a≠b,  a⊕b      0, 1, 1, 0
等价              āb̄+ab [更正],  a≡b,  a↔b                1, 0, 0, 1
蕴涵              ā+b,  a→b                               1, 1, 0, 1
```

## 记号讹误说明

转写文本中 XOR 的公式为 $\overline{ab}+a\bar b$、等价的公式为 $\overline{ab}+ab$——否定号被误抄为覆盖整个乘积 $ab$，与自身值表不符（XOR 在 $(0,0)$ 处得 1 而值表为 0；等价在 $(0,1)$、$(1,0)$ 处得 1 而值表为 0）。更正为 $\bar ab+a\bar b$ 与 $\bar a\bar b+ab$ 后逐点吻合，详见 [[queries/表5-6中xor与等价的否定号位置是否抄错]]。表 5.6 的「不同的符号」列转写为空，疑为电路符号（原图不可核验）。

## 各函数要点

- **NAND（Sheffer 竖线 $a|b$）／NOR（Peirce 箭头 $a\downarrow b$）**：分别以 Sheffer 与 Peirce 命名；源仅列名称、记号与值表，未讨论其泛函完备性（任一函数可仅由其中之一表出），故不单独立页。
- **XOR（反等价）**：记号 $a\oplus b$ 在 $\{0,1\}$ 上的取值恰与 ℤ₂ 加法一致（推断，源未陈述），参见 [[entities/二元布尔代数b]]。
- **等价**：由值表可见其为 XOR 的逐点否定（互补）。
- **蕴涵**：$\bar a+b$，仅在 $a=1,\,b=0$ 时取 0。

## 计数背景

两变量布尔函数共 $2^{2^2}=16$ 个（转写讹为 $2^n$，见 [[findings/布尔函数计数与两变量函数值表]]）；表 5.6 只是其中「最重要」的五种。
