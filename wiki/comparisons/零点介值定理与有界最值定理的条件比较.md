# 零点介值定理与有界最值定理的条件比较

《数学手册(原书第10版)》2.18.5 的四条定理按条件分为两组，形成“连通区域”与“有界闭区域”的对照（见 [[findings/连通区域上连续函数的四大定理]]）：

| 定理（式号） | 区域条件 | 有界性要求 | 附加条件 | 结论类型 |
|---|---|---|---|---|
| 波尔查诺零点定理（2.288） | 连通区域 | 无 | 两点取值异号 | 零点存在性 |
| 介值定理（2.289） | 连通区域 | 无 | $A \ne B$ | 中间值取到 |
| 有界性定理（2.290） | 有界闭区域 | 有 | 无 | $m \leqslant f \leqslant M$ |
| 魏尔斯特拉斯定理（2.291） | 有界闭区域 | 有 | 无 | 最大值与最小值存在 |

## 对照要点

- **介值类（2.288–2.289）**：前提是函数在连通区域上有定义且连续，并附加两点取值异号（或 $A \ne B$）；结论关乎“取到中间值”，本质依赖区域的连通（直觉上，连通性使两点间的函数值得以连续过渡；手册未给出证明）。有界性不是前提——例如在全平面这一无界连通区域上，只要存在取值异号的两点，零点定理依然适用。
- **最值类（2.290–2.291）**：前提是“有界闭区域”上的连续性；结论关乎上下界的存在与达到，本质依赖区域的有界闭性。

注意：手册对“区域”的定义本身含连通性（开的连通点集为区域，边界属于定义域时为闭区域），故“有界闭区域”同时蕴含连通性与边界归属；而 2.288–2.289 仅需连通，对有界与闭均无要求。这一区分是准确且必要的。
