# 曲率与挠率比较

《数学手册(原书第10版)》3.6.2.3 以对偶的方式引入空间曲线的两个基本不变量：曲率度量偏离直线的程度，挠率度量偏离平面曲线的程度。两者的结构平行但符号约定不同。

| 维度 | 曲率 K | 挠率 T |
|---|---|---|
| 刻画对象 | 曲线偏离直线 | 曲线偏离平面曲线 |
| 定义载体 | 单位切向量 $\vec{t}$ 的变化 | 单位次法向量 $\vec{b}$ 的变化 |
| 定义式 | $K=\mathrm{d}\vec{t}/\mathrm{d}s$（式 3.531） | $T=\mathrm{d}\vec{b}/\mathrm{d}s$（式 3.536） |
| 符号 | 非负（模长，式 3.533 开方即得） | 带号：$T>0$ 右旋、$T<0$ 左旋 |
| 半径 | 曲率半径 $\rho=1/K$（式 3.532） | 挠率半径 $\tau=1/\|T\|$（式 3.537） |
| 弧长参数公式 | $K=\|\vec{r}\,''(s)\|$（式 3.533） | $T=\rho^2(\vec{r}\,'\,\vec{r}\,''\,\vec{r}\,''')$（式 3.538） |
| 一般参数公式 | $K^2=\|\vec{r}\,'\times\vec{r}\,''\|^2/\|\vec{r}\,'\|^6$（式 3.534） | $T=\rho^2(\vec{r}\,'\,\vec{r}\,''\,\vec{r}\''')/\|\vec{r}\,'\|^6$（式 3.539） |
| 弗雷内公式中的角色 | $\mathrm{d}\vec{t}/\mathrm{d}s=\vec{n}/\rho$ | $\mathrm{d}\vec{b}/\mathrm{d}s=-\vec{n}/\tau$ |
| 退化情形 | 直线：$K=0$ | 平面曲线：$T=0$ |
| 螺旋线 (3.535) 上的值 | $K=a/(a^2+b^2)$，常数 | $T_R=b/(a^2+b^2)$、$T_L=-b/(a^2+b^2)$，常数 |

## 对偶与差异

- 两者定义都借助「三面形中某单位向量沿弧长的变化率」，且都通过二阶/三阶导数的行列式计算；
- 关键差异在符号：曲率作为模长天然非负，挠率则携带旋向信息（观察者站在主法线上平行于次法线所见为右旋或左旋）；
- 在 [[concepts/达布向量]] $\vec{d}=\frac{1}{\tau}\vec{t}+\frac{1}{\rho}\vec{b}$ 中两者以对等地位合成，其模即全曲率 $\lambda=\sqrt{1/\rho^2+1/\tau^2}$。

## 存疑点

定义式 (3.531)/(3.536) 均将标量写成向量导数形式，疑原书带角度记号与模/号约定，见 [[queries/式3-531与3-536的定义记号是否为角度增量且K取模T带号]]。详细公式与核验见 [[findings/曲率定义与两种参数公式]]、[[findings/挠率定义公式与符号约定]]；螺旋线算例见 [[findings/螺旋线曲率算例]]、[[findings/螺旋线挠率算例]]。
