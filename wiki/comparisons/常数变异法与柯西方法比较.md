# 常数变异法与柯西方法比较

两者都是"已知齐次基本解组后求非齐次特解"的方法，本源用同一算例（式 9.37d）演示双解，构成天然对照。

| 维度 | 常数变异法（式 9.37） | 柯西方法（式 9.38） |
|---|---|---|
| 核心对象 | 把通解常数换成函数 $C_i(x)$ | 齐次解的单参数族 $\varphi(x,\alpha)$ |
| 约束方程 | n 个方程的方程组（9.37b–c） | 参数点处的 n−1 个零条件 + $y^{(n-1)}=F(\alpha)$ |
| 可解性根据 | 系数行列式 = 朗斯基 ≠ 0 | 齐次方程解的唯一性（初始条件确定） |
| 最后一步 | 解出 $C_i'$ 后逐个积分 | 对参数 α 积分一次（9.38b） |
| 特解性质 | 一般特解（含积分常数） | 特解与其直到 n−1 阶导数在 $x_0$ 处皆为零 |
| 计算量 | n 个一阶方程 + n 次积分 | 一次线性方程组求解 + 一次积分 |
| 适用面 | 方程与方程组皆可（9.47 组版本） | 本源仅见单个方程 |
| 算例 9.37d 结果 | $u_1'=xe^{-x},u_2'=-1$ ⟹ $y=-(1+x^2)+C_1^*e^x+C_2^*x$ | $\varphi=\alpha e^{-\alpha}e^x-x$ ⟹ 同一通解 |

## 算例互验

两法对 $y''+\frac{x}{1-x}y'-\frac{1}{1-x}y=x-1$ 给出**完全一致**的通解 $y=C_1^*e^x+C_2^*x-(x^2+1)$，独立复算均通过。这是"两条独立推导路径交叉验证"的范例。

## 转写注意

柯西方法算例的积分上限印作 $\int_{x_0}^{\infty}$，与公式 9.38b 的 $\int_{x_0}^x$ 矛盾且发散（见 [[柯西方法算例积分上限∞与式9-38b矛盾]]）；按上限 x 复算才与常数变异法结果吻合，进一步支持"∞ 为讹误"的判定。
