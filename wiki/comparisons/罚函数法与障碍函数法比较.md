# 罚函数法与障碍函数法比较

## 比较对象

[[concepts/罚函数法]]（18.2.8.1，外点法）与 [[concepts/障碍函数法]]（18.2.8.2，内点障碍法）。二者出自同一来源（数学手册(原书第10版) 18.2.8），同属"修正目标函数 + 序列无约束化"框架：把约束问题 (18.107) 化为一列无约束子问题，子问题解点列的每个聚点都是原问题的解。以下对照均以该来源为据。

## 框架对照

| 维度 | 罚函数法 | 障碍函数法 |
|---|---|---|
| 修正问题 | $H(x,p_k)=f+p_kS$，$x\in\mathbb{R}^n$（18.108） | $H(x,q_k)=f+q_kB$（18.113） |
| 修正项作用 | 惩罚可行集外偏离：$S=0$ 于 $M$ 内、$S>0$ 于 $M$ 外 | 边界处 $B\to+\infty$，阻止迭代点离开 $M^0$ |
| 迭代点位置 | 可行集外（外点） | 可行集内部（内点，恒可行） |
| 参数列极限 | $p_k\to\infty$ | $q_k\to 0$（方向相反） |
| $f$ 值单调性 | $f(x^k)\geqslant f(x^{k-1})$，递增（18.111） | $f(x^k)\leqslant f(x^{k-1})$，递减（18.115） |
| 前提正则性 | 无特别要求 | 须 $M^0\neq\varnothing$ 且 $\overline{M^0}=M$（18.114） |
| 有限终止判据 | 若 $x^k\in M$ 则 $x^k$ 即原问题解 | 无对应判据 |
| 边界处性态 | $r>1$ 时 $H$ 在边界可微（可用解析法） | $B$ 在边界发散，子问题仅在 $M^0$ 上定义 |
| 典型构造 | max 幂型罚项（18.112a/b） | 对数／逆幂障碍（18.116a/b，符号有转写疑讹） |
| 数值病态来源 | 高阶罚（大 $r$） | 过小障碍参数 |

本库注：两法的"从下方／上方逼近"可由框架直接推出——罚问题解满足 $f(x^k)\leqslant H(x^k,p_k)\leqslant H(x^*,p_k)=f(x^*)$（$x^*$ 为原问题解），故从下方；障碍解点恒可行，故 $f(x^k)\geqslant f(x^*)$，从上方。

## 同一算例的解轨迹对照

问题：$\min x_1^2+x_2^2$，$x_1+x_2\geqslant 1$；真解 $x^*=(\frac{1}{2},\frac{1}{2})$（边界上），$f^*=\frac{1}{2}$。

| | 罚函数法 | 障碍函数法 |
|---|---|---|
| 第 $k$ 个子问题解 | $x_1^k=x_2^k=\dfrac{p_k}{1+2p_k}$ | $x_1^k=x_2^k=\dfrac{1}{4}+\sqrt{\dfrac{1}{16}+\dfrac{q_k}{4}}$ |
| 与边界的关系 | $x_1^k+x_2^k=\dfrac{2p_k}{1+2p_k}<1$，恒在 $M$ 外 | $x_1^k+x_2^k>1$，恒在 $M^0$ 内 |
| $f$ 值轨迹 | $2\left(\dfrac{p_k}{1+2p_k}\right)^2<\dfrac{1}{2}$，随 $p_k\uparrow$ 递增趋 $\dfrac{1}{2}$ | $2\left(\dfrac{1}{4}+\sqrt{\dfrac{1}{16}+\dfrac{q_k}{4}}\right)^2>\dfrac{1}{2}$，随 $q_k\downarrow 0$ 递减趋 $\dfrac{1}{2}$ |
| 极限行为 | $p_k\to\infty$：$x^k\to(\frac{1}{2},\frac{1}{2})$，自外侧 | $q_k\to 0$：$x^k\to(\frac{1}{2},\frac{1}{2})$，自内侧 |

两列解从可行集的两侧夹逼同一个边界最优解，$f$ 值分别自下、上方单调趋近 $f^*$——同一算例直观呈现两法的对偶结构（复算见 [[findings/式18-107至18-112罚函数法框架与算例复算]]、[[findings/式18-113至18-116障碍函数法框架与算例复算]]）。

## 共同点

- 同属序列无约束化：子问题均为[[concepts/无约束优化问题|无约束问题]]，可用 18.2.5 的下降类方法求解（线搜索调 18.2.4 程序）；
- 收敛保证同型：解点列的每个聚点都是原问题 (18.107) 的解；
- 每步子问题的解在数学上不依赖前几步的解；
- 数值实践同理：均宜以第 $k$ 个子问题的解热启动第 $k+1$ 个；均需警惕参数极端化（$r$ 过大／$q_k$ 过小）引发子问题收敛性困难。

## 适用性差异（由框架差异推得）

- 需要迭代点始终可行（内点）的应用只能用障碍法，且须先验证 18.114；
- 可行集无严格内点（如含等式约束）时障碍法不适用，只能用罚函数法；
- 罚函数法有"落入 $M$ 即得精确解"的有限终止判据，障碍法只能随 $q_k\to 0$ 渐近逼近。
