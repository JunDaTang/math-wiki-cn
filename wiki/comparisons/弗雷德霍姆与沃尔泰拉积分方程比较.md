# 弗雷德霍姆与沃尔泰拉积分方程比较

两者都是线性积分方程一般形式 (11.1) 的特例，分类学上的唯一区别是积分限是否依赖自变量 x；再与第一类/第二类正交组合，得到 11.1 节的 2×2 分类框架。

## 分类表（含代表式）

| | 第一类（g ≡ 0） | 第二类（g ≡ 1） |
|---|---|---|
| 弗雷德霍姆型（a(x) ≡ a，b(x) ≡ b） | $0 = f(x) + \lambda \int_{a}^{b} K(x,y)\,\varphi(y)\,\mathrm{d}y$（11.2a） | $\varphi(x) = f(x) + \lambda \int_{a}^{b} K(x,y)\,\varphi(y)\,\mathrm{d}y$（11.2b） |
| 沃尔泰拉型（a(x) ≡ a，b(x) ≡ x） | $0 = f(x) + \lambda \int_{a}^{x} K(x,y)\,\varphi(y)\,\mathrm{d}y$（11.2c） | $\varphi(x) = f(x) + \lambda \int_{a}^{x} K(x,y)\,\varphi(y)\,\mathrm{d}y$（11.2d） |

完整逐字转录与复算见 [[findings/式11-1至11-3定义分类与初值问题积分化转录复算]]。

## 区别要点

| 维度 | 弗雷德霍姆型 | 沃尔泰拉型 |
|---|---|---|
| 积分限 | 固定常数 a、b，与 x 无关 | 下限 a 固定，上限为变元 x |
| 与微分方程的联系（源内证据） | 本节未给出与边值问题的具体转化途径，仅有「连同初值和边值可以变为积分方程」的一般性宣言 | 一阶线性 ODE 初值问题经积分化直接化为第二类方程（(11.3)），见 [[methodology/初值问题积分化流程]] |
| 求解理论 | 属第 11 章后续小节，未入库 | 同左 |

## 共同点

- 均由 (11.1) 通过固定 g 与积分限特化而来（复算一致）。
- 共享核 K(x, y)（[[concepts/积分方程的核]]）、扰动函数 f(x)、复参数 λ 与复值函数约定。
- 均可按 f(x) ≡ 0 与否分为齐次/非齐次。
- 均在第 11 章处理范围内（连同某些奇异积分方程）。
