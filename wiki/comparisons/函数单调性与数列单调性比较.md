# 函数单调性与数列单调性比较

《数学手册(原书第10版)》在第 6 章与第 7 章给出两条平行的单调性路径：函数单调性经导数符号判定（6.1.4，式 6.26），数列单调性以相邻项不等式链直接定义（7.1.1.2，式 7.2–7.3）。本页比较两者；函数一侧的依据来自 6.1.4 的入库内容，数列一侧来自 7.1 的入库内容（见 frontmatter sources）。

## 对照表

| 维度 | 函数单调性（6.1.4，式 6.26） | 数列单调性（7.1.1.2，式 7.2–7.3） |
|---|---|---|
| 对象 | 区间上的函数 f(x) | 数列 {aₙ}（离散指标 n = 1, 2, ⋯） |
| 判定途径 | 导数符号：f′(x) ⩾ 0 / ⩽ 0 | 相邻项不等式链：a₁ ⩽ a₂ ⩽ ⋯ / a₁ ⩾ a₂ ⩾ ⋯ |
| 前提 | 可微（解析条件） | 仅需项之间可比较（无解析条件） |
| 严格化条件 | 与「任意子区间上导数不恒为零」的关系（其充要性为开放问题，见 [[queries/严格单调与导数不恒为零是否充要]]） | (7.2)/(7.3) 中的等号恒不成立 |
| 配套结果 | 单调性用于极值与拐点判定（6.1.5） | 单调 + 有界 ⟹ 收敛（7.1.2.4c，[[concepts/单调有界收敛定理]]） |
| 本章示例 | ——（6.1.4 未附成组示例列） | A/B/E 严格递增、G 严格递减（见 [[comparisons/数列A至J十例性质比较]]） |

## 两点结构观察

- **「非严格 + 严格化」的同构**：两侧都先给非严格版本（允许等号 / 允许导数取零），再以附加条件升级为严格版本。数列侧的升级条件（等号恒不成立）是纯次序表述；函数侧的升级条件依赖导数的零点分布——这是离散与连续的差异在定义层的投影。
- **「先用后定义」的编排结构**：第 6 章的微商定义（6.1.1 式 6.1，差商的极限）已隐含使用极限语言，而极限的严格 ε 定义在本书中迟至第 7 章才出现——7.1 给出的是数列极限的 ε–n₀ 定义（式 7.5a）；函数极限的相应定义按章节顺序应在第 7 章后续小节，尚未入库（[[queries/第7章后续小节未入库缺口]]）。手册采取「运算先行、严格化滞后」的编排，引用第 6 章内容时须注意其极限用法在本套书中直到 7.1 才获得正式定义。
