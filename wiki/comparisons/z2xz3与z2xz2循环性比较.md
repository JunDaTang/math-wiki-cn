# Z₂×Z₃ 与 Z₂×Z₂ 循环性比较

《数学手册(原书第10版)》5.3.3.2 直积小节给出的一对对照算例：同为小阶循环群的直积，循环性截然相反，判据是两因子阶的最大公因子。

| 维度 | $Z_2 \times Z_3$（例 A） | $Z_2 \times Z_2$（例 B） |
|---|---|---|
| 元素 | $(e,e),(e,b),(e,b^2),(a,e),(a,b),(a,b^2)$ | $(e,e),(e,b),(a,e),(a,b)$ |
| 阶 | $2\cdot 3 = 6$（式 5.89b） | $2\cdot 2 = 4$ |
| $\operatorname{ord}(a,b)$ | $\operatorname{lcm}(2,3) = 6$ | $2$（$(a,b)^2 = (e,e)$） |
| 循环？ | 是：由 $(a,b)$ 生成 | 否：无 4 阶元素 |
| 同构类型 | $\cong Z_6$ | 克莱因四元群 |
| 几何刻画 | —（手册未给） | 长方形的覆盖变换 |
| $\gcd$（两因子阶） | $\gcd(2,3) = 1$ | $\gcd(2,2) = 2$ |

要点：

- 判据：两个（有限）循环群的直积循环 $\iff$ 阶的最大公因子为 1；本对算例是该判据两个方向的实例（判据的「有限」限定问题见 [[queries/循环群直积判据是否限定有限]]）。
- $Z_2 \times Z_2$ 说明「阿贝尔」不蕴涵「循环」，它也是有限阿贝尔群基本定理中「素数幂阶循环群直积」的基本块之一（[[concepts/有限阿贝尔群基本定理]]）。
- 两算例的复算记录见 [[findings/群的直积公式与循环性算例]]；实体页见 [[entities/克莱因四元群]]。
