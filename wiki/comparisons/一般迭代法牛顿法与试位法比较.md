# 一般迭代法、牛顿法与试位法比较

依据《数学手册（原书第10版）》19.1.1（式 19.3–19.10）对三种求根迭代法的对照。三者共享同一基准方程族（见 [[concepts/零形式与不动点形式]]）与同一算例背景（$x^2 = \sin x$，根 $x^* \approx 0.8767$）。

| 维度 | 一般迭代法 (19.3) | 牛顿法 (19.6) | 试位法 (19.10) |
|---|---|---|---|
| 基础形式 | 不动点形式 x = φ(x) | 零形式 f(x) = 0 | 零形式 f(x) = 0 |
| 每步计算量 | 一个 φ 值 | f 与 f′ 各一个值 | 两个 f 值（仅需函数值） |
| 收敛条件 | 压缩条件 (19.4)/(19.5)，K < 1 | (19.7a) 必要、(19.7b) 充分 | f(xₙ) 与 f(x_m) 持续异号（夹逼） |
| 收敛速度 | K 越小越快；典型线性（标准理论） | 平方阶，位数成倍增加 | 源文未给阶；m = n−1 变体可加速 |
| 导数需求 | 无（φ 可导时有判据） | 需解析导数 | 无（差商替代） |
| 算例表现 | 6 步至 0.8767（x₀ = 0.87） | 平方根算例 3 步至 8 位（a = 2） | 4 步至 0.876726 |
| 发散区的补救 | φ′(x) < −1 时失效 → 斯特芬森方法 | f′ = 0 或初值差时失效 | 异号条件破坏时失效 |

## 结构性观察

- 三者构成“信息—速度”权衡链：一般迭代法信息最少（仅 φ 值）速度最慢；牛顿法信息最多（导数）速度最快（平方）；试位法以一个额外函数值换掉导数，居于中间。
- 试位法是牛顿法的差商近似（源文明言“源于牛顿法 (19.6)”）；而 [[concepts/斯特芬森方法]] 又是试位法对 $x - \varphi(x)$ 的特化，把不动点形式拉回零形式框架。
- 牛顿法与一般迭代法可互相转化视角：牛顿法即取 $\varphi(x) = x - f(x)/f'(x)$ 的特殊不动点迭代（标准等价观察，源文未明言）。
