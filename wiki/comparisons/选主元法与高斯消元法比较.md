# 选主元法与高斯消元法比较

依据 [[sources/10-数学手册原书第10版--8-45-线性方程组--1smy1k4]]（4.5.1 与 4.5.2）：

| 维度 | 选主元法（式 4.175–4.176） | 高斯消元法（式 4.185–4.186） |
|---|---|---|
| 操作对象 | 线性系的格式（变量角色显式可见） | 增广矩阵 (A, a) 的行运算 |
| 不变量 | 换轴可逆，不改变线性型组的信息 | 行运算不改变 (A, a) 的秩 |
| 可解性判读 | 两情形：全部 y 可换轴有解；y_σ = Σλ_μy_μ + λ₀ 时 λ₀ = 0 定可解（式 4.183） | 三情形：某 a_μ^(r−1) ≠ 0 (μ > r) 无解；r = n 唯一；r < n 自由参数（式 4.186） |
| 多用途 | 同一框架可判线性相关性、求逆矩阵（4.5.1.4）、解方程组，源明言还可用于线性最优化 | 专注于三角形化与回代 |
| 求逆 | n 次换轴直接得 A⁻¹（源给出算例） | 源在本节仅作消元求解，未展开求逆 |
| 源的定位 | 与高斯算法并列的数值解法 | 与选主元法、迭代程序并列的数值解法 |

## 小结

两法在解方程组上等价（可解性判据一致，均为不改变秩的初等变换），差别在框架：选主元法保留变量名的显式追踪，适合教学表算与多用途场景；高斯消元直接操作矩阵，是数值线性代数的主干。算例见 [[findings/选主元法两情形与参数解算例]] 与 [[findings/高斯消元行阶梯形与两算例]]。
