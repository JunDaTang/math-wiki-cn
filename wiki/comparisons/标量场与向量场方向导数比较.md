# 标量场与向量场方向导数比较

《数学手册(原书第10版)》13.2.1.1 与 13.2.1.2 以平行结构分别定义了标量场与向量场的方向导数。本页并排比较两者的异同（依据：数学手册(原书第10版)/13.2.1 方向导数和空间导数.md）。

## 并排对照

| 维度 | 标量场方向导数（13.2.1.1） | 向量场方向导数（13.2.1.2） |
|---|---|---|
| 定义式 | (13.27) 差商极限 | (13.30) 差商极限，形式完全平行 |
| 对象 | $U = U(\vec{r})$（标量场） | $\vec{V} = \vec{V}(\vec{r})$（向量场） |
| 结果类型 | 标量 | 向量 |
| 方向向量记号 | $\vec{c}$（单位向量 $\vec{c}^0$） | $\vec{a}$（单位向量 $\vec{a}^0$） |
| 齐性关系 | (13.28) $\partial U/\partial \vec{c} = \|\vec{c}\|\, \partial U/\partial \vec{c}^0$ | (13.31) $\partial \vec{V}/\partial \vec{a} = \|\vec{a}\|\, \partial \vec{V}/\partial \vec{a}^0$，同构 |
| 笛卡尔分量式 | 不需要（结果为标量，$\vec{c}^0 \cdot \operatorname{grad} U$ 即 (13.29)） | (13.32a) 逐分量作用 $(\vec{a} \cdot \operatorname{grad})V_i$，依赖基向量常值 |
| 一般坐标系 | 不涉及（$\operatorname{grad} U$ 本身坐标不变） | 需 (13.32b) 型恒等式，含 rot、div 混合项，且适用于 $\vec{a}$ 本身为场的情形 |
| 几何性质 | (13.29)：沿等值面法向 $\vec{n}$ 取最大值（隐含可微） | 源文本未给出对应的最大性/几何断言 |
| 单位向量约定 | “此后方向导数总是指关于一个单位向量的方向导数” | 同一约定覆盖两小节 |

## 关键差异

1. **结果类型**：标量 vs 向量。这决定了向量场情形必须处理基向量在一般坐标系中的变化，从而引出 (13.32b) 的不变式。
2. **最大性断言的不对称**：标量场情形有“沿等值面法向方向导数最大”的几何断言（式 13.29，隐含可微性）；向量场情形源文本未陈述类似断言。
3. **前向引用负担**：(13.29) 前向引用梯度定义 (13.34)（13.2.2）；(13.32a)/(13.32b) 则前向使用 $\operatorname{grad}$、$\operatorname{div}$、$\operatorname{rot}$ 三个算子，均未在本节定义（见 [[queries/13-2-1未入库回指缺口]]）。

## 共同点

- 同为差商极限定义，是 Gâteaux 型方向导数在有限维的具体化（跨章推断，见 [[comparisons/方向导数与弗雷歇导数比较]]）。
- 同一齐性关系与单位向量约定。
- 同为 13.2.2 三大算子的构造性前导，与 [[concepts/体积导数]] 的积分式构造汇合。
