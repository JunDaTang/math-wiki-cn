# Z变换与拉普拉斯变换关系比较

Z变换对离散序列的地位相当于拉普拉斯变换对连续函数：连续过程用微分方程描述、离散过程由差分方程描述，而两者由阶梯函数嵌入与代换 $e^p=z$ 显式沟通（《数学手册》15.4.1.4，式 15.123–15.126；中间环节为 [[concepts/离散拉普拉斯变换]]）。

## 对应表

| 方面 | 拉普拉斯变换（连续，[[concepts/拉普拉斯变换]]） | Z变换（离散，[[concepts/z变换]]） |
|---|---|---|
| 原对象 | $f(t)$，$0\leqslant t<\infty$ | 序列 $\{f_n\}$，$f_n=f(nT)$（[[concepts/离散函数与序列]]） |
| 变换 | $F(p)=\int_0^{\infty}f(t)e^{-pt}\,\mathrm{d}t$ | $F(z)=\sum_{n=0}^{\infty}f_n(1/z)^n$ |
| 本质 | 含核 $e^{-pt}$ 的积分变换（在表 15.1 之列） | 关于 $1/z$ 的幂级数（洛朗级数），级数型变换，**不在表 15.1 之列** |
| 变量代换 | — | $z=e^p$（$T=1$；「Z」名称由来） |
| 桥梁公式 | $pF(p)=(1-1/z)F(z)$（15.126a，阶梯函数情形） | 同左 |
| 微分 ↔ 差分 | $\mathcal{L}\{f'\}=pF(p)-f(+0)$ | $\mathcal{Z}\{\Delta f_n\}=(z-1)F(z)-zf_0$（15.117） |
| 积分 ↔ 求和 | $\mathcal{L}\{\int_0^t f\}=\frac{F(p)}{p}$ | $\mathcal{Z}\{\sum_{v=0}^{n-1}f_v\}=\frac{F(z)}{z-1}$（15.115） |
| 初值定理 | $f(+0)=\lim_{p\to\infty}pF(p)$ | $f_0=\lim_{z\to\infty}F(z)$（15.108） |
| 终值定理 | $\lim f(t)=\lim_{p\to0}pF(p)$ | $\lim f_n=\lim_{z\to1+0}(z-1)F(z)$（15.112，单向） |
| 求解对象 | 常系数线性微分方程 | 常系数线性差分方程 |
| 对照表 | 表 21.13（第 1431 页） | 表 21.15（第 1454 页），两表可经 (15.126) 相互转化 |

## 结构对应

代换 $z=e^p$ 把 $p$ 平面映到 $z$ 平面：$p\to0$（终值）对应 $z\to1$，$p\to\infty$（初值）对应 $z\to\infty$。精确桥梁为 $p\leftrightarrow 1-1/z=\frac{z-1}{z}$；在 $z\to1$ 附近 $z=e^p\approx1+p$，故渐近地 $(z-1)\leftrightarrow p$。差分规则中初值项的系数（$z$）与微分规则中的系数（$p$ 或 $1$）之间的细微差别，源于阶梯函数的取值约定。

## 记号警示

桥梁公式 (15.126) 中 $F(p)$（拉普拉斯变换）与 $F(z)$（Z变换）**同字母异义**，须按变量区分——源文原样的记号复用隐患。
