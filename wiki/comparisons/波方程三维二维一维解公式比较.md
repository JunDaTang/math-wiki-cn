# 波方程三维二维一维解公式比较

本页比较 [[波方程]] 齐次与非齐次柯西问题在 n = 3、n = 2、n = 1 三种情形下的解公式（式 9.106a–c 与 9.107a–c），全部依据 [[10-数学手册原书第10版--21-923-自然科学和工程学中的一些偏微分方程--1spsf3b]]。

| 维度 | n = 3 | n = 2 | n = 1 |
|---|---|---|---|
| 齐次解公式 | [[基尔霍夫公式]]（9.106a） | [[泊松公式]]（9.106b） | [[达朗贝尔公式]]（9.106c） |
| 齐次解积分域 | 球面 S_at（等式 \|α−x\| = at） | 圆盘 C_at（不等式 \|α−x\| ⩽ at） | 区间 [x₁ − at, x₁ + at] |
| 权函数 | 1/t（与前因子合并为 1/(4πa²t)） | 1/√(a²t² − \|α−x\|²) | 无（常数前因子） |
| 前因子 | 1/(4πa²) | 1/(2πa) | 1/(2a) |
| ψ 项与 φ 项 | ψ/t 积分 + ∂/∂t 的 φ/t 积分 | ψ 加权积分 + ∂/∂t 的 φ 加权积分 | φ(x₁±at) 平均 + ψ 区间积分 |
| 非齐次附加项 | [[推迟位势]]（9.107a） | 式 9.107b | 式 9.107c |
| 附加项结构 | Q 显式带时滞 t − r/a，核 1/r | 对 (ξ, τ) 的三重积分，核含平方根权 | 对 (ξ, τ) 的二重积分 |
| 附加项积分域 | 后向锥 K：r ⩽ at | 锥域 K：0 ⩽ τ ⩽ t，\|ξ−x\| ⩽ a(t−τ) | 三角形域 T：0 ⩽ τ ⩽ t，\|ξ−x₁\| ⩽ a\|t−τ\| |

## 观察要点（仅限源内证据）

- **积分域的维数依赖**：齐次解从 n = 3 的球面（仅波前曲面）降为 n = 2 的圆盘、n = 1 的区间（含内部点）；n = 2 出现平方根权 1/√(a²t² − \|α−x\|²)，n = 1 无权。三式均已独立复算与标准形式一致（见 [[式9-106a至9-106c三维二维一维齐次解复算]]）。
- **非齐次项的时滞表现**：n = 3 显式写为 Q(ξ, t − r/a)；n = 2、n = 1 改为对 (ξ, τ) 积分，时滞隐含于积分域（见 [[式9-107a至9-107c非齐次附加项复算]]）。
- **φ 项与 ψ 项的平行性**：三个齐次公式中 φ 项均为 ψ 项结构外加 ∂/∂t（n = 1 中表现为 φ 的直接组合而非积分求导，结构上仍对应初位移的贡献）。
- 源未解释上述维数差异的物理含义（标准理论中与 Huygens 原理相关，属独立可验证背景，源未提及）。
