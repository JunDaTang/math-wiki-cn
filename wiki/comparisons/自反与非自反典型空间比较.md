# 自反与非自反典型空间比较

依据：数学手册(原书第10版) 12.5.7（式 (12.176)）。判定标准：标准嵌入 $Jx=F_x,\ F_x(f)=f(x)$ 是否为到上（$J(X)=X^{**}$）。

| 空间 | 自反性 | 依据/注记 |
|---|---|---|
| 有穷维巴拿赫空间 | 自反 | 源 12.5.7 |
| 希尔伯特空间 $H$ | 自反 | 里斯表示 $H^*\cong H$（[[concepts/里斯表示定理与正交补]]） |
| $L^p$，$1<p<\infty$ | 自反 | $(L^p)^*=L^q$ 对偶回环（[[concepts/共轭指数与Lp对偶]]）；⚠️ 源文误作 $1\le p<\infty$，见 [[queries/Lp空间自反性陈述内部矛盾]] |
| $L^1([0,1])$ | 非自反 | 源 12.5.7 例（与上行的 $1\le p$ 表述构成源内矛盾） |
| $\mathcal{C}([a,b])$ | 非自反 | 源 12.5.7 例；[[entities/连续函数空间]] |
| $c_0$ | 非自反 | 源 12.5.7 例（"co" 为 $c_0$ 讹写）；[[entities/c0空间]] |

**结构注记**：自反性经 $J$ 的等距同构（[[concepts/等距同构]]）定义（[[entities/对偶空间]]）；对偶刻画（$(L^p)^*=L^q$ 等）是主要判定工具。复算：[[findings/式12-168至12-176拟范数哈恩巴拿赫与自反性转录复算]]。
