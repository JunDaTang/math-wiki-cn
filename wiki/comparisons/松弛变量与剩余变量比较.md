# 松弛变量与剩余变量比较

依据《数学手册(原书第10版)》18.1.2（式 18.8 算例及其后说明），两类附加变量同为化不等式为等式之用，但符号、适用约束与在求解中的地位不同：

| 比较维度 | 松弛变量 | 剩余变量 |
|---|---|---|
| 对应约束类型 | "⩽" 类不等式约束 | "⩾" 类不等式约束 |
| 在等式系统中的系数符号 | 正号（+1） | 负号（−1） |
| 对右端的要求 | （本节未附加条件） | 相应 b_i > 0 |
| 命名口径 | 松弛变量 | “常常”称剩余变量，以区别于松弛变量 |
| 启动规范形捷径 | 仅含 "⩽" 且 b ⩾ 0 时可全部取作基变量：A_B = I、x_B = b、x_N = 0，立得可行极端点 | 无此捷径；求解中需倍加小心（18.1.3.3） |
| 式 18.8 算例 | x₅、x₆、x₇（三条 "⩽" 约束） | x₄（首约束 x₁+x₂+x₃ ⩾ 1，b₁ = 1 > 0） |

## 关键差异的含义

差异的实质在于能否直接构造初始可行基：全部由松弛变量成基时基矩阵是单位阵，规范形“立即可知”；而剩余变量以负号进入系统，不能以同样方式成基，含 "⩾" 约束的问题因此需要另行处理（本书于 18.1.3.3 展开，未入库）。在阅读 18.1.2 的“启动特例”时，**不可**把该捷径推广到含剩余变量的系统。

## 记录口径

原文先统称“引入松弛变量 x₄,…,x₇”，随后才依据符号与 b_i 区分出剩余变量 x₄；概念页见 [[松弛变量与剩余变量]]。
