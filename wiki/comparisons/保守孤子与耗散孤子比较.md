# 保守孤子与耗散孤子比较

9.2.5.1 以「保守—耗散」二分组织全部非线性现象：保守支给出孤子（弥散结构），耗散支给出周期模式与耗散孤子（耗散结构）。

| 维度 | 保守孤子 | 耗散孤子 |
|---|---|---|
| 所属系统 | 保守系统（无耗散） | 非保守系统 |
| 载体方程 | KdV (9.148)、NLS (9.149)、SG (9.150) | 复金兹堡—兰道方程 (9.151) 等耗散方程 |
| 解族结构 | 通常形成**至少具有一个连续可变参数的解族** | 仅在**参数空间的单个点**处存在 |
| 平衡机制 | 离差（色散）↔ 非线性性 | 双重平衡：离差↔非线性，**以及**能量/粒子流↔耗散 |
| 可积性 | 可积波方程的解 | **不是**可积波方程的解 |
| 稳定性 | 碰撞弹性（形状速度保持，仅相移） | 特殊类型的稳定性（由双重平衡导致） |
| 出现场所 | 浅水波、非谐晶格、等离子体、非线性光学（亮孤子）、约瑟夫森磁通等 | 非线性光学（源文「空化」疑为「腔」）、光学半导体放大器、反应扩散系统（[9.33]） |

## 关联：耗散方程的解谱

GL (9.151) 与 KS (9.152) 除耗散孤子外，还兼具时空周期解与混沌解——「时空模式或结构的出现是变成混沌的特征」（9.2.5.1.4），背景见 [[concepts/周期模式与耗散结构]]。

## 注意

「参数空间单点存在」「需能量流—耗散平衡」仅属于耗散孤子/复 GL，不可外推至 KdV/NLS/SG（源文 9.2.5.1.5 的明确对照）。
