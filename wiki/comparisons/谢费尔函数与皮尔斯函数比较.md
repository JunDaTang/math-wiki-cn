# 谢费尔函数与皮尔斯函数比较（NAND 与 NOR）

依据《数学手册(原书第10版)》5.1.1.6（表 5.2、表 5.3）：

| 维度 | 谢费尔函数（NAND） | 皮尔斯函数（NOR） |
|---|---|---|
| 定义 | A\|B = ¬(A∧B) | A↓B = ¬(A∨B) |
| 经德摩根展开 | Ā∨B̄ | ĀB̄ |
| 取 F 的唯一情形 | A = B = T | A、B 不全为 F |
| 取 T 的唯一情形 | A、B 不全为 T | A = B = F |
| 命名来源 | 谢费尔 (Sheffer) | 皮尔斯 (Peirce) |
| 记号 | "\|"（正文） | ↓（表 5.3；正文「'l'」疑为 ↓ 之 OCR 讹） |
| 单独函数完备 | 是 | 是 |

**共同点**：

- 均为 16 个二元真值函数中的两个，均满足交换律（A\|B = B\|A；A↓B = B↓A，由真值表对称性可见）；
- 均可**单独**表示一切真值函数（原书陈述，未给构造证明）；
- 二者互为对偶：经德摩根法则互换 ∧ 与 ∨ 即可互相转化（本 wiki 依 (5.14) 的推理）。

**差异**：

- NAND 在全真输入处输出 F（NOT AND），NOR 在全假输入处输出 T（NOT OR）；
- 转写问题不同：表 5.2 标题误作「NANO 函数」；NOR 正文记号讹作「'l'」（见 [[queries/5-1全节转写讹误清单]]）。
