# 序列空间包含链与函数空间包含链比较

《数学手册(原书第10版)》12.1.2 给出两条平行的空间层级链（式 12.12 与 12.14）。二者分别按「逐项衰减/收敛性质」与「逐点正则性」对空间分级，并在 T = ℕ 处精确交汇。

## 两条链（转录复算见 [[findings/式12-9至12-14子空间线性包与包含链转录复算]]）

```
序列链：φ ⊂ c₀ ⊂ c ⊂ m ⊂ s；   φ ⊂ ℓ^p ⊂ ℓ^q ⊂ c₀（1 ≤ p < q < ∞）   (12.12)
函数链：C^(k)([a,b]) ⊂ C([a,b]) ⊂ B([a,b]) ⊂ F([a,b])                   (12.14)
```

## 逐层对应

| 结构角色 | 序列链 | 函数链（T = [a,b]） |
|---|---|---|
| 顶层（无约束） | s：全部序列 | F([a,b])：全部函数 |
| 有界性约束 | m = ℓ^∞ | B([a,b]) = M([a,b]) |
| 收敛/衰减约束 | c、c₀、ℓ^p | ——（无对应层） |
| 光滑性约束 | ——（无对应层） | C([a,b])、C^(k)([a,b]) |
| 最小层 | φ = c₀₀（有限支撑） | ——（链止于 C^(k)，可随 k 递降） |

## 关键观察

1. **精确交汇**：T = ℕ 时 B(T) = M(T) = m（源文明示）——有界函数空间取离散指标集即为有界序列空间。这是两族唯一的显式等同点。
2. **分级机制不同**：序列链的 ℓ^p ⊂ ℓ^q（p < q）按**可和强度**插值（p 越大要求越弱、空间越大）；函数链的 C^(k+1) ⊂ C^(k) 按**光滑阶数**递降（k 越大空间越小）。两条链不可互相转译：ℓ^p 在函数链中没有代数对应层，C^(k) 在序列链中没有对应层。
3. **衰减 vs 连续**：ℓ^q ⊂ c₀ 表明可和性强制逐项趋零；函数链中「逐点正则性」（连续、可微）不产生任何衰减约束，两链的约束类型正交。
4. **链的严格性**：源文未逐一证明包含之严格；复算补充可给出分离元（如 {1/n} ∈ c₀∖ℓ¹、{1} ∈ c∖c₀、{1/n} ∈ c∖φ；函数侧 t ↦ 常值函数属于 C∖C^(1) 型分离等）。
