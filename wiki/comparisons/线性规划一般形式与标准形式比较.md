# 线性规划一般形式与标准形式比较

对比《数学手册(原书第10版)》18.1.1 中线性规划的两种表述：作为建模入口的一般形式（式 18.1/18.2）与作为解法接口的标准形式（式 18.4/18.5）。

| 维度 | 一般形式（18.1a/b、18.2a–e） | 标准形式（18.4a/b、18.5a/b） |
|---|---|---|
| 约束形态 | 混合「⩽」与「=」（前 s 行不等式、后 m−s 行等式）；「⩾」约束乘 (−1) 后并入 | 全部为等式 |
| 变量符号 | 前 r 个变量非负，后 n−r 个自由 | 全部非负 |
| 目标方向 | 极大（极小问题经式 18.3 化为极大） | 一律极大 |
| 记号 | 分块 c¹, c², x¹, x², A₁₁, A₁₂, A₂₁, A₂₂, b¹, b² | 紧凑 c, x, A, b |
| 维数假定 | 无 | 一般假定 m ⩽ n |
| 用途 | 实际问题的直接叙述与近似建模 | 后续解法（预期单纯形法类方法）的统一入口 |

## 四步归约映射

1. 「⩾」约束 → 乘 (−1) → 「⩽」约束，并入一般形式的不等式块；
2. f = min! → −f = max!（式 18.3），最优解集不变、最优值变号；
3. 自由变量 xₖ → xₖ¹ − xₖ²（两非负变量之差），变量数增加；
4. 「⩽」约束 + [[concepts/松弛变量]] → 等式；注意「⩾」约束翻号后右端为负（算例中 −x₁ + x₆ = −10）。

归约后变量总数增加（原文此处脱字，见 [[queries/标准化叙述脱字疑为n之辨]]），可行集所处空间相应增维，但解点在非松弛分量上的投影给出原问题的解。

## 语义对照

- 一般形式的可行集定义在原始变量上（满足 (18.2b) 的向量集合）；标准形式的[[concepts/可行集]] M = {x ∈ ℝⁿ : x ⩾ 0, Ax = b} 定义在含松弛变量的增广空间上，二者经上述映射在投影意义下一一对应。
- 目标函数对松弛变量的系数为 0，故两种形式的最优值相等。
