# 四类对称系数公式比较

本页对手册 7.4.2.1 的四类对称（式 7.107–7.111）作并排对照。四种对称刻画两个相互独立的维度：**关于原点的奇偶性**（f(−x) = ±f(x)）与**关于半周期的反号性**（f(x + T/2) = −f(x)）；二者可独立成立，也可组合。

| 维度 | 第一类（7.107） | 第二类（7.108） | 第三类（7.109a/b） | 第四类·奇（7.110） | 第四类·偶（7.111） |
|---|---|---|---|---|---|
| 判定条件 | f(x) = f(−x) | f(x) = −f(−x) | f(x+T/2) = −f(x) | 奇 ∧ 第三类 | 偶 ∧ 第三类 |
| 恒为零的系数 | b_k = 0 | a_k = 0 | a_{2k} = b_{2k} = 0 | a_k = b_{2k} = 0 | b_k = a_{2k} = 0 |
| 保留的系数 | 全部 a_k | 全部 b_k | 仅奇下标 | 仅 b_{2k+1} | 仅 a_{2k+1} |
| 非零系数前置因子 | 4/T | 4/T | 4/T | 8/T | 8/T |
| 积分限 | [0, T/2] | [0, T/2] | [0, T/2] | [0, T/4] | [0, T/4] |
| 核函数 | cos(k·2πx/T) | sin(k·2πx/T) | cos/sin((2k+1)·2πx/T) | sin((2k+1)·2πx/T) | cos((2k+1)·2πx/T) |

## 结构观察

- **独立维度的正交组合**：奇偶性决定「余弦 vs 正弦」；半周期反号性决定「奇下标 vs 全部下标」。第四类是两维度的组合，故零系数与化简效果叠加：只保留奇下标的一种三角函数，积分限减为四分之一、前置因子加倍到 8/T。
- **化简收益排序**：第一/二类（积分减半）< 第三类（积分减半且下标减半）< 第四类（积分减为四分之一且下标减半）。
- **零系数模式互不冲突**：第一类消 b_k、第二类消 a_k、第三类消偶下标——故第四类能同时消两组互不重叠的系数。
- **与展开形式的衔接**：偶延拓 f₂ / 奇延拓 f₃ 分别调用第一类、第二类公式（取 T = 2l），见 [[comparisons/三种傅里叶展开形式比较]]。
