# 投点法与均值逼近法比较

《数学手册(原书第10版)》16.3.5.3 为求 I = ∫₀¹g(x)dx（式 16.171，设 0⩽g⩽1）给出两种蒙特卡罗解法，对照如下。

| 维度 | 运用频率（投点法） | 利用均值逼近 |
|---|---|---|
| 估计对象 | 单位正方形内积分区域的**面积** | 随机变量 g(X) 的**期望** |
| 抽样方式 | 均匀随机数**成对**作为单位正方形内点坐标，得 n 个点 P_i | n 个均匀随机数 ξ₁,…,ξ_n 作为均匀随机变量 X 的实现，计算 g_i = g(ξ_i) |
| 估计量 | m/n（m 为落入区域点数，式 16.172） | (1/n)Σg_i（式 16.173） |
| 理论依据 | 频率逼近面积（16.2.1.2，[[concepts/频数与相对频率]]） | 期望定义 E(g(X)) = ∫g·f₀ = ∫₀¹g（第 1063 页 16.49a,b，[[concepts/期望]]、[[concepts/样本均值]]） |
| 源文评价 | 「欲得到较好的精确度，需要大量随机数」 | 被列为提高精度的方法之一，称「普通蒙特卡罗方法」 |

## 共同点与关系

- 两者都以 [[concepts/均匀分布随机数]] 为输入，前提同为 0⩽g⩽1（可经 [[methodology/积分标准化min-max变换流程]] 保证）。
- 源文未给出两估计量的定量方差比较，仅以「需要大量随机数」暗示投点法的精度成本，并把均值法列为改进方向之一，其余方法见文献 [16.19]（无题录）。
- 从现代视角看，投点法相当于对落入区域的示性变量求样本均值，两法同属样本均值型估计——此为本页编者的背景性说明，非源文陈述。
