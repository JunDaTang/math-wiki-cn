# GF(pⁿ) 与 ℤ_{pⁿ} 比较

数学手册 5.3.7.4.1 以「注意」形式特别提醒：**对于 n > 1，GF(pⁿ) 与 $\mathbb{Z}_{p^n}$ 是不同的**——二者元素个数相同（均为 $p^n$），但代数结构不同。

| | GF(pⁿ) | ℤ_{pⁿ} |
|---|---|---|
| 元素数 | pⁿ | pⁿ |
| 是否域 | 是（伽罗瓦域） | n > 1 时否：$p^n$ 非素数，由例 D 判据 $\mathbb{Z}_{p^n}$ 有零因子，非整区 |
| 构造 | $\mathbb{Z}_p[x]/f(x)$，f 为 n 次不可约多项式（式 5.179） | $\mathbb{Z}/(p^n)$，整数模 $p^n$ 的剩余类环（式 5.174） |
| 加法 | 多项式系数模 p 相加 | 整数模 $p^n$ 相加 |
| 乘法 | 多项式模 f(x) 相乘 | 整数模 $p^n$ 相乘 |
| n = 1 | GF(p) = $\mathbb{Z}_p$（p 素时 $\mathbb{Z}_p$ 本身是域） | 同左，二者一致 |

## 关键区分

GF(pⁿ) 是 $p^n$ 元**域**；$\mathbb{Z}_{p^n}$ 仅是环（n > 1 时含零因子，域必无零因子）。依据：源文 5.3.7.4.1（1）注意事项 + 5.3.7.1 例 D（n 非素 ⟹ $\mathbb{Z}_n$ 有零因子）。
