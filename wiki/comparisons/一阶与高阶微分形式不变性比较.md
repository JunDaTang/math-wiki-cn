# 一阶与高阶微分形式不变性比较

本源 6.2.2 在相邻小节给出一个极具教学价值的对照：**一阶全微分具有形式不变性，高阶微分没有**。两侧陈述均来自本源（6.2.2.1.4 与 6.2.2.2.2–5）。

| 维度 | 一阶全微分 | 高阶微分（d² 及以上） |
|---|---|---|
| 形式不变性 | **有**：与一元公式 (6.38) 类似，全微分关于自变量具有微分形式不变性（6.2.2.1.4） | **无**：源文明确警示 |
| 一元对照 | $\mathrm{d}y = f'\,\mathrm{d}x$ 在 $x = z(v)$ 时形式不变（式 6.38，位于未入库的 6.1.6） | $\mathrm{d}^2 y = \mathrm{d}(\mathrm{d}y) = f''\,\mathrm{d}x^2$ **仅当 x 为自变量时**适用；$x = z(v)$ 时不再适用（6.2.2.2.2） |
| 多元对照 | $\mathrm{d}u = \sum_i \frac{\partial u}{\partial x_i}\mathrm{d}x_i$ 形式不变 | 式 6.46–6.48 仅对自变量成立 |
| 失效原因（通行解释，非源文明文） | [[concepts/链式法则]] 保证一阶公式在变量替换下形式保持 | 「视 dx 为常数」是推导前提；$x = z(v)$ 时 $\mathrm{d}x = z'(v)\mathrm{d}v$ 不再是常数，$\mathrm{d}^2 x \neq 0$ 产生附加项 |
| 复合变元时怎么办 | 直接沿用同一形式 | 须回到「更复杂的公式」（第 606 页 6.2.4，未入库） |
| 实务后果 | 一阶微分运算可安全换元 | 高阶微分记号在复合变量下失效，不能盲目套用 $\mathrm{d}^2 y = f''\,\mathrm{d}x^2$ |

## 归属警示

两条陈述分属同一节的不同小节，**不得互相外推**：

- 不能因一阶有不变性而认为高阶也有（6.2.2.2.2 的警示正是针对此）；
- 也不能因高阶失效而怀疑一阶。
