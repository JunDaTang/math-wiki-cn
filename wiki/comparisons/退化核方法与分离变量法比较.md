# 退化核方法与分离变量法比较

两者同为"无穷维 → 有限维/低维"的化归方法论。左列内容据《数学手册》11.2.1（本 source），右列内容据既有 wiki 的 9.1.3/9.2.2 入库内容（[[methodology/分离变量法解题流程]]、[[methodology/非齐次边值问题齐次化代换]] 及相关 findings）。

| 维度 | 退化核方法（11.2.1） | 分离变量法（9.1.3/9.2.2） |
|---|---|---|
| 对象 | 第二类弗雷德霍姆积分方程 | 偏微分方程（弦振动、热传导、圆膜振动、狄利克雷问题等） |
| 化归方向 | 积分方程 → $n$ 维线性方程组 (11.7d) | PDE → 本征值问题（ODE）+ 本征函数展开 |
| 关键结构 | 核的有限和分解 $K=\sum\alpha_k\beta_k$ | 解按本征函数系展开（傅里叶级数、贝塞尔级数等） |
| 谱的处理 | $D(\lambda)$ 多项式的根，至多 $n$ 个 | 本征值问题给出的（典型为无穷）离散谱 |
| 可解性判据 | $D(\lambda)\neq 0$ 唯一解；$D(\lambda)=0$ 时正交条件 | 初始/边界数据按本征函数展开的相容性 |
| 精确性边界 | 仅对退化核精确；一般核用退化核逼近（近似，无误差分析） | 依赖方程与区域的可分离性 |

## 共同的方法论要素

1. **先解"齐次骨架"、再处理"非齐次数据"**：退化核方法中 $D(\lambda)=0$ 对应齐次方程的非平凡解（本征函数），正交条件处理非齐次可解性；分离变量法中先求本征函数系再展开非齐次数据——与 [[methodology/非齐次边值问题齐次化代换]] 的分层思想一致。
2. **解都表为"数据项 + 齐次解空间的组合"**：积分方程的 $\varphi = f + \lambda\sum A_k\alpha_k$（[[concepts/叠加原理与分解定理]] 的体现）与分离变量解的"特解 + 本征函数级数"结构平行。

## 差异的本质

退化核方法把谱压缩为有限个代数根——以牺牲一般性换取完全的可解性判定；分离变量法保留无穷谱——以依赖本征函数系的完备性与展开定理为代价。11.2.1 结尾"用退化核足够好地逼近一般核"正是这两种策略之间的桥梁。
