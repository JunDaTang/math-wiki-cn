# 任意参数与弧长参数的三面形方程比较

《数学手册(原书第10版)》3.6.2.2 以表 3.27（一般参数 t）与表 3.28（弧长参数 s）给出活动三面形要素的两套方程。两者的关系：四个要素（切线、法平面、密切平面、次法线）形式完全相同，仅 t 换为 s；主法线与从切平面在弧长参数下显著简化。

| 要素 | 一般参数 t（表 3.27） | 弧长参数 s（表 3.27 + 表 3.28） |
|---|---|---|
| 切线 | $\vec{R}=\vec{r}+\lambda\vec{r}\,'$；$(X-x)/x'=(Y-y)/y'=(Z-z)/z'$ | 同形式（t→s），且 $\vec{r}\,'(s)=\vec{t}$ 自动为单位向量 |
| 法平面 | $(\vec{R}-\vec{r})\cdot\vec{r}\,'=0$ | 同形式 |
| 密切平面 | 三向量混合积 $=0$；三阶行列式 $=0$ | 同形式 |
| 次法线 | $\vec{R}=\vec{r}+\lambda(\vec{r}\,'\times\vec{r}\,'')$ | 同形式 |
| 主法线 | $\vec{R}=\vec{r}+\lambda\,\vec{r}\,'\times(\vec{r}\,'\times\vec{r}\,'')$；坐标式含 $l,m,n$ 与 $x',y',z'$ 的行列式 | **$\vec{R}=\vec{r}+\lambda\vec{r}\,''(s)$**；$(X-x)/x''=(Y-y)/y''=(Z-z)/z''$ |
| 从切平面 | 含 $l,m,n$ 的三阶行列式 $=0$ | **$(\vec{R}-\vec{r})\cdot\vec{r}\,''(s)=0$**（点法式） |

其中 $l=y'z''-y''z'$、$m=z'x''-z''x'$、$n=x'y''-x''y'$ 即 $\vec{r}\,'\times\vec{r}\,''$ 的分量。

## 简化的根源

弧长参数化的两个恒等式：$|\vec{r}\,'(s)|=1$（切向量为单位向量）与 $\vec{r}\,'\cdot\vec{r}\,''=0$（由前者求导而来）。由此 $\vec{r}\,''(s)$ 落在法平面内且沿主法线方向（$\vec{r}\,''(s)=K\vec{n}$，与式 3.533 及弗雷内公式一致），故主法线退化为 $\vec{r}\,''(s)$ 的点向式、从切平面退化为以其为法向的点法式。

## 取舍

- **弧长参数**：方程最简，特别适合主法线、从切平面及曲率计算；代价是须求弧长积分并对 s 求导。
- **一般参数**：无需换参，直接用 $\vec{r}\,',\vec{r}\,'',\vec{r}\'''$ 与行列式；适合参数已给定、或弧长反解困难的情形。
