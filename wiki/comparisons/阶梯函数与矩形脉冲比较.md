# 阶梯函数与矩形脉冲比较

| | 阶梯函数 F(t)（14.60） | 矩形脉冲 Ψ(t)（14.61） |
|---|---|---|
| 定义 | 1/(2πi)·∫ e^{itz}/z dz，路径沿实轴向下绕开原点 | 1/(2πi)·∫ e^{i(b−t)z}/z dz − 1/(2πi)·∫ e^{i(a−t)z}/z dz，路径同左 |
| 用阶梯函数表示 | —— | Ψ(t) = F(b−t) − F(a−t) |
| 取值 | t>0: 1；t=0: 1/2；t<0: 0 | a<t<b: 1；t<a 或 t>b: 0；t=a 或 t=b: 1/2 |
| 间断点 | 单个（t=0） | 两个端点（t=a、t=b） |
| 物理背景 | Φ(t) = cF(t−t₀)：时刻 t₀ 处从 0 经 c/2 跳到 c；电工学中描述电压/电流突跳（赫维赛德函数） | 区间 [a,b] 上的矩形波形 |
| 手册一般讨论 | 15.2.1.3（第 1011 页，未入库） | 15.2.1.3（第 1012 页，未入库） |

## 共同点

- 都表示为**同一条缩进路径**（沿实轴、向下绕开原点）上的复积分，大弧段趋零均由 [[concepts/若尔当引理]] 保证；
- 间断点处都取左右极限的平均值 1/2：t=0 时实轴主值部分为 0（奇对称）、小弧段贡献 iπ，除以 2πi 得 1/2（见 [[methodology/实轴极点缩进围道计算流程]]）；
- 都通过「围道是否包含极点 z=0」的分段讨论验证取值（复算见 [[findings/式14-56至14-62及ez例复积分计算实积分转录复算]]）。

## 差异的本质

矩形脉冲是阶梯函数的**线性叠加**（两个移位之差），其三段取值完全由阶梯函数的三段取值组合而来，不引入新的围道技术；两者可视为同一复积分表示在不同参数下的特例。
