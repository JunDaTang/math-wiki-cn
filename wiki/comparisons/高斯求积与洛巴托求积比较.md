# 高斯求积与洛巴托求积比较

同为「节点作为参数」的 Gauss 型求积公式（19.3.3），对比全内部节点与含端点节点两条设计（区间 [−1,1]，一般区间经 (19.83) 仿射变换处理）。

| 方面 | 高斯求积公式 | 洛巴托求积公式 |
|---|---|---|
| 节点构成 | 勒让德多项式之根，全在内部，关于原点对称 | 区间两端点固定 + n−1 个内部待定节点 |
| 自由参数个数 | 2n+2（n+1 节点 + n+1 权） | 2n（n−1 内节点 + n+1 权）⚠源称「多于 2n 个」疑讹 |
| 最高准确多项式次数 | 2n+1 | 2n−1 |
| n=2 实例 | 节点 −√(3/5), 0, √(3/5)；权 5/9, 8/9, 5/9 | 节点 −1, 0, 1；权 1/3, 4/3, 1/3（**即辛普森公式**） |
| n=3 实例 | 节点 ±0.339981043…, ±0.861136311…；权 0.652145154…, 0.347854845…（源表 c₀ 存疑） | 节点 −1, −1/√5, 1/√5, 1；权 1/6, 5/6, 5/6, 1/6 |
| 精度代价 | 同节点数下最高 | 比高斯低 2 阶（两端点不自由） |
| 适用动机（源） | 高精度近似，节点须以特别方式选取 | 「在某些情况下，选取子区间的端点作为插值节点也是合理的」 |

## 要点

1. **自由度—准确度配比**：高斯 2n+2 个自由参数配 2n+2 个准确性条件（⩽2n+1 次多项式）；洛巴托 2n 个配 2n 个（⩽2n−1 次）。端点固定使准确度恰降两阶——源语「多于 2n 个自由参数」与该配比矛盾，为疑点（[[queries/多于2n个自由参数疑为恰有2n个之辨]]）。
2. **与经典公式的衔接**：洛巴托 n=2 即辛普森公式，经典低阶公式被纳入 Gauss 型谱系的端点端；而高斯 n=2 并非辛普森（节点 0, ±0.7746 ≠ 0, ±1）。
3. **算例对照**：算例仅给出高斯结果（n=1,2,3），洛巴托未参与算例（见 [[findings/正弦积分Si(1)算例全表复算]]）。
4. **系数表疑点归属**：(19.82) n=3 c₀ 讹误属于高斯表；洛巴托 (19.84a/b) 两表复算无误（[[findings/式19-81至19-84高斯与洛巴托节点系数表转录复算]]）。
