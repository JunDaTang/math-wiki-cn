# 相关分析与回归分析比较

《数学手册(原书第10版)》16.3.4 开篇以一句对举界定二者的分工：相关分析根据试验数据确定总体两个或两个以上变量之间是否存在某种相关关系；回归分析用于确定变量间相关关系的形式。

| 维度 | 相关分析 | 回归分析 |
|---|---|---|
| 回答的问题 | 变量之间是否存在相关关系 | 相关关系取何种函数形式（$Y=f(X)$） |
| 变量角色 | 对称地看待诸变量 | 区分自变量与因变量，求 $E(Y)$ 对 x 的依赖 |
| 总体工具 | [[concepts/协方差]]（16.150）、[[concepts/相关系数]] $\rho_{XY}$（16.151） | 理论回归函数（16.155、16.160） |
| 样本工具 | 经验相关系数 $r_{xy}$（16.154b） | 最小二乘估计 $\widetilde{a},\widetilde{b}$（16.157a）或 $\underline{\widetilde{\boldsymbol{a}}}$（16.163e） |
| 统计推断 | $H\colon\rho_{XY}=0$ 的 t 检验（16.154a） | [[concepts/回归系数的置信区间]]（16.159a,b）、多元情形 F 分布与等价检验 |
| 前提 | 样本来自二维正态总体（检验前提） | 对定值 x，Y 正态、期望线性、方差不变（16.155） |

## 递进与耦合

二者并非并列而是递进：先由相关分析探明关系存在，再由回归分析确定形式。且两套量互相进入对方公式：$r_{xy}$ 出现在回归方差估计 $\widetilde{\sigma}^2=\frac{n-1}{n-2}s_y^2(1-r_{xy}^2)$（16.157a）与置信区间（16.159a,b）中；回归系数与相关系数存在换算 $\widetilde{b}=r_{xy}\,s_y/s_x$（由 16.154b 与 16.157a 推得，见 [[findings/式16-154a至16-154b相关系数t检验转录复算]]）。
