# 逻辑斯谛映射与埃农映射比较

| 维度 | 逻辑斯谛映射 (17.5) | 埃农映射 (17.6) |
|---|---|---|
| 维数 | 一维（$M=[0,1]$） | 二维（$M=\mathbb{R}^2$） |
| 映射 | $\varphi(x)=\alpha x(1-x)$ | $\varphi(x,y)=(y+1-ax^2,\ bx)$ |
| 参数 | $\alpha\in(0,4]$（保证 $[0,1]$ 不变） | $a>0,\ b\neq0$（$|b|$ 控制耗散/保守） |
| 光滑性 | $C^\infty$（多项式） | $C^\infty$（多项式） |
| 可逆性 | 不可逆：$\varphi(x)=\varphi(1-x)$ 非单射 | 可逆：$b\neq0$，$C^\infty$ 微分同胚 |
| 时间指标 | $t=0,1,\dots$ | $t=0,\pm1,\dots$ |
| 耗散/保守二分 | 不适用（二分限定可逆系统） | 适用：$|b|<1$ 耗散，$|b|=1$ 保守 |
| 角色 | 一维不可逆原型 | 二维可逆原型（伸展—弯曲—压缩—反射） |

## 要点

- 两者同为 $C^\infty$ 映射，但可逆性截然不同：逻辑斯谛只能定义 $t\geqslant 0$ 的半群（负向仅原像记号 $\varphi^{-t}(A)$），埃农可双向迭代。
- 参数范围的由来不同：$\alpha\le 4$ 是相空间不变性要求（$\varphi$ 在 $[0,1]$ 上最大值为 $\alpha/4$）；$b\neq0$ 是可逆性要求。
- 不可将埃农适用的雅可比判据移植给逻辑斯谛（判据前提为 $C^r$ 微分同胚）。复算证据分别见 [[findings/式17-1至17-6流离散系统与三大典型系统转录复算]] 与 [[findings/埃农映射三步分解与雅可比判据复算]]。
