# 平面交会与球面岸对船定向比较

本比较把 [[sources/10-数学手册原书第10版--12-343-球面三角形的计算--170nm2t]] 3.4.3.3 的岸对船定向（[[findings/岸对船定向三步解算链]]，源文自比平面交会「参见第 196 3.2.2.3」）与 [[sources/10-数学手册原书第10版--8-32-平面三角学--j56osm]] 的平面交会体系（[[comparisons/交会定位三法比较]]、[[methodology/交会定位计算流程]]）并列，显示同一「已知—所测—所求—解」范式在平面与球面的平移。

| 维度 | 平面交会（3.2.2.3） | 球面岸对船定向（3.4.3.3） |
|---|---|---|
| 已知 | 两控制点坐标 + 所测方向角 | 两站 P₁(λ₁,φ₁)、P₂(λ₂,φ₂) + 所测方位角 δ₁、δ₂ |
| 所求 | 待定点坐标 | 船位 P₀(λ₀, φ₀) 的地理坐标 |
| 锚定第三点 | 平面控制网中的已知点 | 北极 N：边 90°−φ₁、90°−φ₂，角 Δλ |
| 辅助三角形 | 以两控制点连线为底 | 先解 P₁P₂N，再解 P₁P₂P₀，再解 NP₁P₀ |
| 所用基本问题 | 平面四基本问题 | 球面第三（SWS）与第四（WSW）基本问题 |
| 检验 | 复算/几何一致性 | 在 NP₀P₂ 中复算 NP₀ 与 Δλ₂，λ₀ = λ₁+Δλ₁ = λ₂−Δλ₂ |
| 量的单位 | 长度 | 边为角度（弧），需 πR/180° 换算长度 |

结构结论：两体系同构——三角形链逐级传递已知量，最后用冗余三角形复算检验；球面版本的特有成分是（a）以北极 N 充当普适第三点（其「坐标」即两站的余纬），（b）边以角度度量并依赖 [[concepts/弧度]] 换算，（c）歧义与象限判定须按 [[methodology/球面三角形公式选择与精度规则]] 处理正弦双值。平面三法（交会法、后方交会、弧交会）是否各有严格球面对应物（如球面后方交会），本源未展开，可作开放问题。
