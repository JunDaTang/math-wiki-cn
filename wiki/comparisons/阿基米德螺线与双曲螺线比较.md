# 阿基米德螺线与双曲螺线比较

两者是螺线族中 ρ 与 φ 关系互为「镜像」的一对：一次关系 $\rho = a|\varphi|$（式 2.247）与反比关系 $\rho = a/|\varphi|$（式 2.248）；记法上均使用 $|\varphi|$ 使 ρ 恒正，正文的对称性断言也相同。

## 对照

| 项目 | [[concepts/阿基米德螺线]]（式 2.247） | [[concepts/双曲螺线]]（式 2.248） |
|---|---|---|
| ρ–φ 关系 | ρ 与 φ 成正比（a = v/ω） | ρ 与 φ 成反比（ρφ = a） |
| 生成/名称来源 | 运动学生成：射线匀角速旋转 + 点沿射线匀速移动 | 反比关系类比双曲线 xy = a（通行解释） |
| \|φ\|→∞ 行为 | ρ→∞，曲线向外无限展开 | ρ→0，曲线绕原点缠绕，原点为渐近点 |
| \|φ\|→0 行为 | ρ→0，各支自原点出发 | ρ→∞，正支以 y = a 为渐近线 |
| 射线上的交点 | 沿射线向外等距排列，间距 2πa | 沿射线向原点方向加密排列，向渐近点聚集 |
| 弧长 | L = (a/2)(φ√(φ²+1) + Arsinh φ) | 源文未给 |
| 面积 | S = (a²/6)(φ₂³ − φ₁³)（φ 的三次差） | S = (a²/2)(1/φ₁ − 1/φ₂)（φ 的倒数差）；φ₂→∞ 时 → a²/(2φ₁) |
| 曲率半径 | r = a(φ²+1)^{3/2}/(φ²+2)；原点处 r₀ = a/2 | r = (a/φ)(√(1+φ²)/φ)³ |
| 渐近性态 | 无渐近点、无渐近线 | 原点为渐近点；渐近线 y = a |

## 共同的渐近曲率行为（核验补注）

两者在 $|\varphi|\to\infty$ 时均有 $r \approx \rho$：阿基米德螺线 $r = a\frac{(\varphi^2+1)^{3/2}}{\varphi^2+2} \sim a\varphi = \rho$；双曲螺线 $r = \frac{a(1+\varphi^2)^{3/2}}{\varphi^4} \sim \frac{a}{\varphi} = \rho$。即远离（或绕近）中心时，两者的曲率半径都与极径同阶——这是核验时发现的共同渐近行为，非手册原文记载。

## 共同的转写疑点

两式的 $|\varphi|$ 记法（ρ 恒正）与正文「关于 y 轴对称」「双曲螺线两支公共渐近线 y = a」的断言矛盾；若采用允许负 ρ 的原始记法 ρ = aφ 与 ρ = a/φ，则正文全部断言成立。详见 [[queries/式2-247与2-248取绝对值与y轴对称渐近线y等于a是否矛盾]]。
