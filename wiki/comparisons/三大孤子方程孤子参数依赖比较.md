# 三大孤子方程孤子参数依赖比较

9.2.5 节对 KdV、NLS、SG 三个保守方程的孤子给出了三种**互不相同**的参数依赖定理；三者须严格分属各自对象，不可互推。

| 维度 | KdV 孤子 (9.154) | NLS 亮孤子 (9.159) | SG 扭曲孤子 (9.163) |
|---|---|---|---|
| 方程 | u_t + 6uu_x + u_{xxx} = 0 | iu_t + u_{xx} + 2\|u\|²u = 0（聚焦支） | u_{tt} − u_{xx} + sin u = 0 |
| 参数个数 | 2（v > 0，φ） | 4（η, ξ, φ, χ） | 2（v，x₀） |
| 振幅与速度 | **速度唯一决定振幅与宽度**（高波快于矮波） | **振幅（2η）与速度（−4ξ）可独立选取** | **速度与振幅无关** |
| 速度约束/表达 | v > 0 | 包络速度 v = −4ξ；相速度 2(η²−ξ²)/ξ | \|v\| < 1，γ = 1/√(1−v²) |
| 定位特征 | sech² 钟形，零背景 | 包络孤子（光孤子），零背景 | 从 0 到 2π 的拓扑台阶（kink） |
| 相互作用 | 弹性，N-孤子解渐近叠加 (9.155) | 弹性，4N 参数刻画 N-孤子 | 弹性；kink-kink (9.167)、kink-antikink (9.168)、呼吸子 (9.169) |

## 要点

- KdV 的「耦合」依赖是最典型的非线性效应：不能独立调节振幅；
- NLS 的「独立」依赖源于复包络结构：振幅与群速分别由 η 与 ξ 控制；
- SG 的「无关」依赖来自相对论型因子 γ = 1/√(1−v²)：kink 的台阶高度固定（振幅不变），速度受 |v| < 1 约束；
- 广义 KdV 孤子 (9.174)（A^p = ½\|v\|(p+1)(p+2)）延续 KdV 型耦合依赖；暗孤子 (9.160) 的速度约束为 v < 2η（见 [[comparisons/亮孤子与暗孤子比较]]）。
