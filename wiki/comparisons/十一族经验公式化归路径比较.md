# 十一族经验公式化归路径比较

依据《数学手册(原书第10版)》2.16.2 的修正目录（式 2.255–2.267），比较 11 类经验公式族（按小节计；幂函数与指数函数各含两型，故下表共 13 行）化归为线性关系的路径：

| 小节 | 函数型 | 化归目标 | 关键代换 | 对 x 数据的要求 | 特殊步骤 |
|---|---|---|---|---|---|
| 2.16.2.1 | $y=ax^b$ | 直接线性（双对数型） | $X=\lg x,\ Y=\lg y$ | 无 | — |
| 2.16.2.1 | $y=ax^b+c$ | 直接线性 | b 已知：$X=x^b$；b 未知：先定 c 再 $X=\lg x,\ Y=\lg(y-c)$ | 无 | 三点定 c（$x_3=\sqrt{x_1x_2}$，式 2.256d） |
| 2.16.2.2 | $y=a\mathrm{e}^{bx}$ | 直接线性（半对数型） | $X=x,\ Y=\lg y$ | 无 | — |
| 2.16.2.2 | $y=a\mathrm{e}^{bx}+c$ | 直接线性 | $X=x,\ Y=\lg(y-c_1)$ | 无 | 三点定 c（$x_3=\frac{x_1+x_2}{2}$） |
| 2.16.2.3 | $y=ax^2+bx+c$ | 直接线性 | 2.259b（定点差商）或 2.259c（差分 $\Delta y$） | 2.259c 需等差 | 求和定 c（2.259d） |
| 2.16.2.4 | $y=\frac{ax+b}{cx+d}$ | 直接线性 | $Y=\frac{x-x_1}{y-y_1}$（定点）；特例用倒数或 $x/y$ | 无（需选定点） | 拟合形 (2.260c) |
| 2.16.2.5 | $y^2=ax^2+bx+c$ | 二次多项式 | $Y=y^2$ | 继承二次多项式要求 | — |
| 2.16.2.6 | $y=a\mathrm{e}^{bx+cx^2}$ | 二次多项式 | $Y=\lg y$ | 同上 | — |
| 2.16.2.7 | $y=\frac{1}{ax^2+bx+c}$ | 二次多项式 | $Y=\frac1y$ | 同上 | — |
| 2.16.2.8 | $y=\frac{x}{ax^2+bx+c}$ | 二次多项式 | $Y=\frac{x}{y}$ | 同上 | — |
| 2.16.2.9 | $y=a+\frac bx+\frac c{x^2}$ | 二次多项式 | $X=\frac1x$ | 同上 | — |
| 2.16.2.10 | $y=ax^b\mathrm{e}^{cx}$ | 直接线性（差分型） | 2.266b（$\Delta\lg x$–$\Delta\lg y$）或 2.266c（$x$–$\Delta\lg y$） | 等差或等比（或可配商为常数的数对） | 求和定 $\lg a$（如 2.259d） |
| 2.16.2.11 | $y=a\mathrm{e}^{bx}+c\mathrm{e}^{dx}$ | 两级修正 | 一级 2.267b（$y_1/y$–$y_2/y$）；二级 2.267c（$y\mathrm{e}^{-dx}$–$\mathrm{e}^{(b-d)x}$） | 一级需等差 | 唯一的两级修正族 |

## 模式总结

1. **三条化归路径**：直接线性（对数 / 倒数 / 定点差商）、经二次多项式枢纽（五族，式 2.261–2.265）、两级修正（指数和独有）。
2. **加常数 c 的处理**：幂 / 指数型的 +c 变体需先以三点法估 c（两种取点方式不可互换）；二次多项式枢纽族的 c 由化归后的定参一并解决。
3. **数据结构依赖**：差分型修正（2.259c、2.266b/c、2.267b）要求 x 成等差或等比数列；无结构要求时用定点差商（2.259b、2.260b）或对数代换。
4. **参数数目**：多为三参数；$y=ax^b$ 仅两参数，有理线性函数四字母按齐次性仅三个有效（wiki 分析观察，手册未明言）。
