# 对称/反对称与埃尔米特/反埃尔米特分解比较

原书对方阵给出两套平行的正交分解（式 4.13d 与 4.15c），逐项对比如下：

| 维度 | 实形式（式 4.13d） | 复形式（式 4.15c） |
|---|---|---|
| 分解式 | $A=A_{\mathrm s}+A_{\mathrm{as}}$ | $A=A_{\mathrm h}+A_{\mathrm{ah}}$ |
| 对称/埃尔米特部分 | $A_{\mathrm s}=\tfrac12(A+A^{\mathrm T})$，[[concepts/对称矩阵]] | $A_{\mathrm h}=\tfrac12(A+A^{\mathrm H})$，[[concepts/埃尔米特矩阵]] |
| 反对称/反埃尔米特部分 | $A_{\mathrm{as}}=\tfrac12(A-A^{\mathrm T})$，[[concepts/反对称矩阵]] | $A_{\mathrm{ah}}=\tfrac12(A-A^{\mathrm H})$，[[concepts/反埃尔米特矩阵]] |
| 所用对合 | 转置 $A\mapsto A^{\mathrm T}$ | 共轭转置 $A\mapsto A^{\mathrm H}$ |
| 适用对象 | 每个方阵 | 每个方阵 |
| 实数域关系 | 实方阵上两套分解重合（此时 $A^{\mathrm H}=A^{\mathrm T}$，埃尔米特 = 对称） | 同左 |

## 元素级刻画的差异与疑点

- 反对称：对角元为零、迹为零（4.13b–c）；其中 (4.13b) 元素式印作 $a_{\mu\nu}=-a_{\mu\nu}$ 有讹，应为 $a_{\mu\nu}=-a_{\nu\mu}$（见 [[queries/式4-13b反对称元素式是否应为aμν等于负aνμ]]）。
- 反埃尔米特：(4.15b) 断言 $a_{\mu\mu}=0$、迹为零，与定义 (4.15a) 冲突（对角元应为纯虚数，反例 $\mathrm{i}I$；见 [[queries/式4-15b反埃尔米特对角元为零是否应为纯虚数]]）。

两分解式本身均可直证且不受上述疑点影响，见 [[findings/方阵的对称与埃尔米特分解]]。
