# 指数函数与对数函数比较

手册 2.6.1–2.6.2 将两函数作为互为[[反函数]]的一对给出：对数曲线由指数曲线沿 y = x 反射得到。二者的图像要素呈系统对偶：

| 要素 | 指数函数 $y = a^{x} = \mathrm{e}^{bx}$ | 对数函数 $y = \log_a x$ |
|---|---|---|
| 定义域 / 值域 | (−∞, +∞) / (0, +∞) | (0, +∞) / (−∞, +∞) |
| 定点 | (0, 1) | (1, 0) |
| a > 1 时 | 严格递增，值 0 → +∞ | 严格递增，值 −∞ → +∞ |
| a < 1 时 | 严格递减，值 +∞ → 0 | 严格递减，值 +∞ → −∞ |
| 渐近线 | x 轴（b > 0 左侧、b < 0 右侧趋近） | y 轴（a > 1 向下、a < 1 向上趋近） |
| 自然特例 | y = e^x | y = ln x |

## 速度陈述的「表面反向」（非矛盾）

- 指数函数：|b| 越大，增/减越快，趋近 x 轴越快（两者同向）；
- 对数函数：|ln a| 越小增/减越快，|ln a| 越大趋近 y 轴越快（两者反向）。

方向相反并非错误：增长速度经反射后对应斜率 $\left|y'\right| = \left|\frac{1}{x\ln a}\right|$（随 $|\ln a|$ 增大而减小），而趋近渐近线的速度经反射后对应同高度处横坐标 $x = a^{y}$（$|\ln a|$ 越大越小、曲线越贴近 y 轴）——「越贴近 y 轴」恰是「越贴近 x 轴」的反射像。详见 [[对数函数为指数函数的反射反函数及双速度陈述]]。

## 关键差异

- 指数函数对一切实 x 有定义且恒正；对数函数仅对 x > 0 有定义且取遍一切实数。
- 反射关系落实 [[严格单调保证反函数存在且图像沿y等于x反射]] 与 [[连续严格单调函数的反函数存在且连续]]（指数函数连续且严格单调，故对数反函数存在且连续）——2.1.3/2.1.5 定理的第一个手册内应用实例。
- 在 [[函数的量级]] 意义上二者互补：指数增长快于任何幂，对数增长慢于任何正幂（[[朗道符号定义与指数对数量级结论]]）。
