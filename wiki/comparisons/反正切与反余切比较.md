# 反正切与反余切比较

| 性质 | 反正切函数 $\arctan x$ | 反余切函数 $\operatorname{arccot} x$ |
| --- | --- | --- |
| 原函数 | [[正切函数]] | [[余切函数]] |
| 定义域 | $\mathbb{R}$（全体实数） | $\mathbb{R}$（全体实数） |
| 主值域 | $(-\frac{\pi}{2},\frac{\pi}{2})$（开，关于原点对称） | $(0,\pi)$（开，手册约定） |
| 一般值域 | $k\pi-\frac{\pi}{2}<y<k\pi+\frac{\pi}{2}$ | $k\pi<y<(k+1)\pi$ |
| 约化公式（式 2.143 / 2.144） | 纯 $k\pi$ 平移 | 纯 $k\pi$ 平移 |
| 负角公式（式 2.152 / 2.154） | 奇对称：$\arctan(-x)=-\arctan x$ | π−补：$\operatorname{arccot}(-x)=\pi-\operatorname{arccot}x$ |
| 和差公式 | 式 2.159–2.160（判据 $xy$ 与 $\pm1$ 比较） | 手册未给出（可经 $\operatorname{arccot}x=\frac{\pi}{2}-\arctan x$ 导出） |

## 共同点与差异

二者的原函数周期均为 $\pi$，因此约化公式都是纯 $k\pi$ 平移（与 [[反正弦与反余弦比较]] 中 arcsin 的反转因子、arccos 的奇偶分裂形成对照）。差异集中在主值区间：$\arctan$ 的主值域关于原点对称，故为奇函数；$\operatorname{arccot}$ 的主值域 $(0,\pi)$ 不对称，负角公式为 π−补。

## 约定警示

$\arctan x+\operatorname{arccot}x=\frac{\pi}{2}$（式 2.147/2.149）成立的前提是手册取 arccot 主值域为 $(0,\pi)$；采用 $(-\frac{\pi}{2},\frac{\pi}{2}]$ 约定的其他文献中，相关公式形式不同。详见 [[反余切函数]]。
