# 显函数与隐函数极值判定比较

《数学手册（原书第10版）》6.1.5.3 处理显函数 $y=f(x)$，6.1.5.5 处理隐形式 $F(x,y)=0$ 给出的函数。两条路径的判据形式不同，但经推导复核，隐式判据恰是显式二阶判据的推论（$y''=-F_{xx}/F_y$，见 [[findings/隐函数极值Fy与Fxx符号判据]]）。

| 维度 | 显函数 $y=f(x)$ | 隐函数 $F(x,y)=0$ |
|---|---|---|
| 候选点方程 | $f'(x)=0$（一元方程） | $F(x,y)=0$ 且 $F_x(x,y)=0$（二元方程组） |
| 判定量 | $f''(x_i)$ 的符号（或首个非零高阶导数） | $F_y$ 与 $F_{xx}$ 的符号组合 |
| 极小判据 | $f''(x_i)>0$ | $F_y$ 与 $F_{xx}$ 异号（$\Leftrightarrow y''>0$） |
| 极大判据 | $f''(x_i)<0$ | $F_y$ 与 $F_{xx}$ 同号（$\Leftrightarrow y''<0$） |
| 前提 | $f$ 可微；高阶法需高阶导数存在 | $F$、$F_x$、$F_y$ 连续；隐含 $F_y\neq0$ |
| 退化情形 | $f''(x_i)=0$ 时逐阶上推至首个非零导数 | $F_y$ 或 $F_{xx}$ 取值为 0 时“需用更复杂的方法”，未给出隐式逐阶上推 |
| 不可导点 | 符号改变检验仍适用（图 6.10(b)、(c) 型） | 无对应机制（前提即要求 $F_y\neq0$） |
| 计算负担 | 须求出 $f'$、$f''$ 的表达式并因式分解 | 免显化：只解方程组并在候选点求偏导数值 |

## 结论

- 桥梁是 $y'=-F_x/F_y$（[[concepts/隐函数求导]]）：它把 $F_x=0$ 翻译为驻点、把 $F_{xx}/F_y$ 翻译为二阶导数，故两条路径在共同前提（可微、$F_y\neq0$）下结论一致。
- 选择依据：显化容易用显式路径；显化困难或只需个别点的极值时隐式流程（[[methodology/隐函数极值判定流程]]）计算量更小。
- 隐式路径的退化处理（$F_y=0$、$F_{xx}=0$）是手册留下的空白，对应显式情形的逐阶上推无隐式版本。
