# 即时赋值与延迟赋值比较

《数学手册（原书第10版）》20.2.3 在同一节内先后给出两组求值语义相对的算子：Set/Rule 的**即时求值**与 SetDelayed/RuleDelayed 的**延迟求值**，并明确以「右手边何时第一次算出值来」为分界。以下对照仅就本节所载内容归纳：

| 维度 | 即时：Set / Rule | 延迟：SetDelayed / RuleDelayed |
|---|---|---|
| 中置形式 | `r = s`；`u -> v` | `u := v`；`u :> v`（原书排作 `u :-> v`） |
| 完全形式 | `Set[r, s]`；`Rule[u, v]` | `SetDelayed[u, v]`（式 20.8a）；`RuleDelayed[u, v]`（式 20.8b） |
| 右端首次求值时机 | 进行指派或建立规则之时即刻求值 | 调用左手边的那一刻才第一次求值 |
| 此后每次调用 | 左端被**已求值**的右端取代 | 左端被右端取代，右端于调用时求值 |
| 有效期 | 直到指派/规则被改变 | 同样直到被改变 |
| 机制角色 | 值绑定（Set）；变换规则（Rule） | 延迟值绑定；延迟变换规则 |

## 相同点

- 四者都是具有对应头部的表达式，遵循 `op[symb1, symb2]` 的统一完全形式结构，见 [[concepts/Mathematica完全形式与中置算子]]。
- 指派或规则都持续有效，直到被改变；改变的途径一致（新指派、`x = .` 即 Unset[x]、`Clear[x]`），见 [[concepts/Set指派与清除]]。
- 无论即时或延迟，左手边总是被右手边取代。

## 差异的实质

差异仅在**求值时机**：即时算子在建立之时就固定了右端的值，此后调用看到的都是同一个已求值结果；延迟算子则在每次调用时才对右端求值。本节未展开二者的选用准则（如何时该用 `:=` 定义函数），此为可在后续小节（函数定义、模式匹配等主题）检验的开放点。
