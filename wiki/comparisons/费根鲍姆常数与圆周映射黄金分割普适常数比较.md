# 费根鲍姆常数与圆周映射黄金分割普适常数比较

| 维度 | 费根鲍姆常数 δ | 圆周映射黄金分割普适常数 |
|---|---|---|
| 系统/场景 | 周期倍增级联：一维逻辑斯蒂方程 (17.84) 与连续时间系统 (17.67) | K=1 的标准圆周映射 (17.96)，沿斐波那契序列 rₙ=Fₙ/F_{n+1}（ρ(Ω_n,1)=rₙ） |
| 定义 | 式 (17.89)：lim (ε_{j+1}−ε_j)/(ε_{j+2}−ε_{j+1}) | lim (Ω_n−Ω_{n−1})/(Ω_{n+1}−Ω_n) = −2.8336⋯ |
| 数值符号 | 正 | 负 |
| 普适性表述 | 数值计算表明极限存在（源文明言，对象含洛伦茨型流体方程组） | “对于某些映射类这些常数相等，标准圆周映射也属于这一类” |
| 证据 | 数值 | 数值；源未给出处 |
| 所属路径 | 过渡到混沌之路径一（级联） | 路径四（环面破裂，K>1 圆周映射过渡） |

## 共同点与警示

- 二者同为沿临界/边界参数序列的**间距比极限**，同属 [[concepts/普遍性]] 现象；源文明确以“类似于费根鲍姆常数的情形”作类比。
- **归属警示**：δ 属周期倍增级联，−2.8336 属 K=1 圆周映射的黄金分割过渡，二者分属不同对象，不可互换；两常数的证据均为数值（δ 见 [[findings/式17-89费根鲍姆级联极限转录]]，−2.8336 见 [[findings/黄金分割圆周映射常数-2.8336转录]]）。
