# 指数和四情形比较

[[指数和]] $y = a\mathrm{e}^{bx} + c\mathrm{e}^{dx}$（a, b, c, d ≠ 0）的图像由两组符号关系唯一确定：(a 与 c 是否同号) × (b 与 d 是否同号)。

| 情形 | a 与 c | b 与 d | 极值 | 拐点 | 单调性 | 值的走向 | 渐近线 |
|---|---|---|---|---|---|---|---|
| a) | 同号 | 同号 | 无 | 无 | 严格单调 | 0 ↔ ±∞ | x 轴 |
| b) | 同号 | 异号 | 有 | 无 | 单谷 / 单峰 | +∞→+∞（有极小）或 −∞→−∞（有极大） | 无 |
| c) | 异号 | 同号 | 有 C | 有 D | 极值两侧各自严格单调，变号一次 | 0→极值→±∞ 或反向 | x 轴 |
| d) | 异号 | 异号 | 无 | 有 D | 严格单调 | −∞→+∞ 或 +∞→−∞ | 无 |

## 结构观察

- **极值与拐点由两组符号独立决定**：极值存在 ⇔ sgn(ab) 与 sgn(cd) 异号（由 $-\frac{ab}{cd} > 0$），恰为情形 b)、c)；拐点存在 ⇔ sgn(a) 与 sgn(c) 异号（由 $-\frac{ab^{2}}{cd^{2}} > 0$，平方项不改变符号），恰为情形 c)、d)。四种组合各得其一：a) ∅、b) {C}、c) {C, D}、d) {D}。
- **拐点存在 ⇔ x 轴交点 B 存在 ⇔ 函数变号**（均等价于 a 与 c 异号）：情形 c) 变号一次，情形 d) 单调穿越 x 轴一次；情形 a)、b) 不变号、无 B。
- **渐近线与走向**：b 与 d 同号时（情形 a)、c)）x 轴为渐近线，函数某一端趋于 0；b 与 d 异号时（情形 b)、d)）两端各趋一个无穷，无渐近线。
- 依参数符号不同，图像可能沿坐标轴反射。
