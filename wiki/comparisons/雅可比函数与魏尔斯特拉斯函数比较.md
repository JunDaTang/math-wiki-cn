# 雅可比函数与魏尔斯特拉斯函数比较

椭圆函数理论的两大经典体系，均出自本节：[[雅可比函数]]（14.6.2–14.6.3）与 [[魏尔斯特拉斯函数]]（14.6.4）。

| 维度 | 雅可比体系 | 魏尔斯特拉斯体系 |
|---|---|---|
| 基本函数 | sn、cn、dn | ℘（辅以 ζ、σ） |
| 定义路径 | 第一类椭圆积分 F(k, φ) 之逆（经 [[振幅函数]] am） | 格点级数直接构造；℘ 为 (14.119) 积分之逆 |
| 参数 | 模数 k（0<k<1）、补模数 k′ | 半周期 ω₁、ω₂（比值非实数） |
| 周期 | sn: 4K, 2iK′；cn: 4K, 2(K+iK′)；dn: 2K, 4iK′ | 2ω₁, 2ω₂（源文性质 (1) 作“ω₁, ω₂”，疑误，见 [[魏尔斯特拉斯wp周期omega与2omega之辨]]） |
| 基本方程/恒等式 | sn²+cn²=1、k²sn²+dn²=1；导数公式 (14.112) | ℘′²=4℘³−g₂℘−g₃；不变量 g₂=60Σ′ω⁻⁴、g₃=140Σ′ω⁻⁶ |
| 加法定理 | (14.111a–c) | (14.120)（℘）、(14.125)（ζ） |
| 伴生的非椭圆函数 | am（源文明确“不是椭圆函数”） | ζ、σ（[[拟周期性|拟周期]]，源文明确“不是椭圆函数”） |
| 显式表示 | [[theta函数]] 商表示 (14.115) | 格点级数/乘积 (14.117)、(14.121) |
| 表示定理 | 源文未述 | 性质 (5)（有疑点：应为 ℘、℘′ 的有理函数，见 [[魏尔斯特拉斯性质5wp与zeta有理表示之辨]]） |

## 观察与评论

- 两体系共享同一组织思想：椭圆函数是椭圆积分的反函数（sn 经 F(k, φ)；℘ 经 (14.119)），参见 [[椭圆积分]]。
- 雅可比体系以单个模数 k 参数化，天然衔接应用（如 [[数学摆]] 的周期）；魏尔斯特拉斯体系以任意格参数化，一般性与对称性更强（不变量 g₂、g₃ 刻画格）。
- 各自都有伴生的非椭圆函数：am 与 ζ/σ，恰是各自理论中不可回避的中间对象。
- 性质 (5) 的表述问题只属于魏尔斯特拉斯小节的行文，不应外推到雅可比体系；雅可比一侧的对应工具是 θ 函数表示。
