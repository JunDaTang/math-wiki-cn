# 洛伦兹曲线与误差曲线比较

本页对照两类钟形曲线：[[concepts/洛伦兹曲线]]（含 [[concepts/阿涅西箕舌线]] 特例，出自本源 2.11.2）与 [[concepts/误差曲线]]（出自同书 2.6 节，见 [[sources/10-数学手册原书第10版--12-26-指数函数和对数函数--1wum3pd]]）。二者在物理学中分别对应洛伦兹线型与高斯线型。

| 方面 | 洛伦兹曲线 / 布赖特-维格纳曲线 | 误差曲线 |
|---|---|---|
| 出处 | 2.11.2，式 2.226b（本源） | 2.6 节，式 2.58–2.59 |
| 方程 | $y = \frac{a}{b^{2}+(x-c)^{2}}$ | 高斯型指数曲线（对称性、极值与拐点公式见 [[findings/误差曲线的对称性极值与拐点公式]]） |
| 函数类型 | 有理函数（多项式之比） | 指数函数 |
| 尾部衰减 | 幂律型（$\sim 1/x^{2}$），重尾 | 指数平方衰减，尾部远窄 |
| 与横轴围成面积 | 有限（箕舌线特例为 $\pi a^{2}$） | 有限 |
| 峰值位置 | $x=c$，峰值 $a/b^{2}$ | 对称轴处 |
| 物理角色 | 阻尼振荡的傅里叶变换（2.11 侧注，参见原书 15.3.1.4，待闭环） | 高斯线型 / 误差分布背景 |
| 代数性 | 隐式化为三次方程，为三阶代数曲线（分析推断） | 超越函数，非代数曲线 |

## 观察

- 两者同为钟形、对称、两侧各有一对拐点的曲线，但衰减机制不同：洛伦兹型是多项式倒数，天然重尾；误差曲线是 $e^{-x^{2}}$ 型，尾部按指数平方速度衰减。
- 「阻尼振荡的傅里叶变换是洛伦兹线型」这一侧注使本对照具有物理意义：时间域的阻尼（指数衰减）对应频率域的洛伦兹线型，而误差曲线的高斯线型对应另一类展宽机制。该论断依赖尚未处理的 15.3.1.4，本页仅记录手册侧注，不作推导。
- 注意归属：傅里叶变换论断属于洛伦兹曲线族 (2.226b)；箕舌线仅是其 $c=0$ 特例。

- 误差曲线侧：同书 2.6 节（经 [[sources/10-数学手册原书第10版--12-26-指数函数和对数函数--1wum3pd]] 已入库内容）。
