# ODE 特征方程与 PDE 特征线辨析

「特征方程」一词在本 wiki 覆盖的两个语境中含义不同，须严格区分：

| 维度 | [[特征方程法]]（ODE 语境） | [[偏微分方程的特征]]（PDE 语境） |
|---|---|---|
| 对象 | 常系数线性常微分方程 / 微分算子 Pₙ(D) | 二阶偏微分方程 (9.82a) 的二阶主部 |
| 形式 | 代数方程（如 λ² + pλ + q = 0） | 二次微分形式 A dy² − 2B dxdy + C dx² = 0（式 9.83） |
| 解的意义 | 指数解 e^{λx} 的增长率（算子的谱） | 平面上的曲线族（特征线），沿之二阶导数项退化 |
| 判别式的用途 | 判别解的振荡/衰减模式 | 判别方程类型（双曲两族 / 抛物一族 / 椭圆无实特征） |
| 用途 | 直接写出通解的指数组合 | 选坐标线约化 [[典范形式]]；柯西问题初始曲线不得与之相切 |

两者同名异义：PDE 特征线是几何对象（坐标变换的不变量），ODE 特征值是代数对象（算子的谱）。本 wiki 相关页面互不混用；引用 9.2.2 节的“特征”时一律指 PDE 特征线。
