# 反正弦与反余弦比较

| 性质 | 反正弦函数 $\arcsin x$ | 反余弦函数 $\arccos x$ |
| --- | --- | --- |
| 原函数 | [[正弦函数]] | [[余弦函数]] |
| 定义域 | $[-1,1]$ | $[-1,1]$ |
| 主值域 | $[-\frac{\pi}{2},\frac{\pi}{2}]$（闭，关于原点对称） | $[0,\pi]$（闭，关于 $x=0$ 不对称） |
| 一般值域 | $k\pi-\frac{\pi}{2}\leqslant y\leqslant k\pi+\frac{\pi}{2}$ | $k\pi\leqslant y\leqslant(k+1)\pi$ |
| 约化公式（式 2.141 / 2.142） | $k\pi+(-1)^k\arcsin x$（带反转因子） | 按 $k$ 奇偶分裂为两种平移 |
| 负角公式（式 2.151 / 2.153） | 奇对称：$\arcsin(-x)=-\arcsin x$ | π−补：$\arccos(-x)=\pi-\arccos x$ |
| 和差公式 | 式 2.155–2.156，判据为 $xy$ 符号与 $x^2+y^2$ 是否超过 1 | 式 2.157–2.158，判据为 $x+y$ 符号与 $x,y$ 大小 |
| 倍角关系 | 式 2.161，三段（分段点 $\frac{1}{\sqrt2}$） | 式 2.162，两段（分段点 $0$） |
| 特殊值 | $\arcsin0=0$ | $\arccos\frac12=\frac{\pi}{3}$（算例 C） |

## 核心差异：约化结构不对称

二者定义域相同、主值域互补（$\arcsin x+\arccos x=\frac{\pi}{2}$，式 2.145/2.146），但约化公式结构不同：正弦的单调区间以 $k\pi$ 为中心、交替升降，产生 $(-1)^k$ 反转因子；余弦的单调区间 $[k\pi,(k+1)\pi]$ 按 $k$ 奇偶朝不同方向覆盖主值区间，必须分裂为两种平移。负角公式的两类形态（奇对称 vs π−补）与和差公式判据的差异都源于这一区间结构差别。详见 [[约化为主值公式及arccos奇偶分裂]]。

## 联系

式 2.145/2.146 给出完整互换链：$\arcsin x=\frac{\pi}{2}-\arccos x=\arctan\frac{x}{\sqrt{1-x^{2}}}$ 等（其中 2.146 的分段条件存在转写疑误，见 [[式2-146条件π减1是否应为负1]]）。
