# 单方程与方程组隐函数求导比较

本页比较《数学手册(原书第10版)》6.2.3.2 中约束方程数不同的情形：单方程（式 6.53、6.54）、两个方程（式 6.55、6.57）、n 个方程（式 6.56），考察"方程数/未知函数个数"维度的影响（自变量维度另见 [[comparisons/一元与多元隐函数求导比较]]）。

| 维度 | 单方程（式 6.53、6.54） | 两方程（式 6.55、6.57） | n 个方程（式 6.56） |
|---|---|---|---|
| 方程数 / 未知函数数 | 1 / 1 | 2 / 2 | n / n |
| 未知函数 | y(x) 或 u(x₁, …, xₙ) | y(x), z(x) 或 u(x, y), v(x, y) | y₁(x), …, yₙ(x) |
| 一阶求导产物 | 单个线性方程 | 2×2 线性方程组 | n×n 线性方程组 |
| 一阶显式解 | 给出（6.53c、6.54b） | 一元函数情形给出（6.55c）；二元函数情形未给 | 未给 |
| 解的分母结构 | 单个偏导数（F_y 或 F_u） | 2×2 行列式 F_yΦ_z − F_zΦ_y | n×n 行列式（结构上为雅可比式，推断标注） |
| 高阶导数 | 6.53 给出显式链至三阶 | 文字说明可算，未给公式 | 文字说明可算，未给公式 |

## 观察

- **解方程变解方程组**：方程数增加后，一阶导数不再由移项直接得出，而须解线性方程组；解的分母从单个偏导数变为行列式——6.53c → 6.55c → 6.56b 的分母结构递进清晰可见。
- **"行列式/雅可比/克莱姆"名称均为推断标注**：原书在 6.55c、6.56b 处未使用这些名称，只给出公式或方程组本身；凡以这些术语描述原文结构的表述均属入库者推断，见 [[findings/式6-55两隐函数方程组导数复算]]、[[findings/式6-56n元隐函数方程组线性系统]]。
- **显式解供给递减**：单方程给显式解（且一元情形给到三阶），两方程中仅一元函数情形给显式解，n 方程情形完全不给。
- **条目 (6) 残缺**：一般情形的文字转写脱损且无公式，见 [[queries/第6条一般情形脱漏的n如何复原]]。
