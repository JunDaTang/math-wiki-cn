# 贝尔曼最优性原理与库恩—塔克条件比较

这是跨节比较：贝尔曼最优性原理出自《数学手册(原书第10版)》18.3.4（本 source），库恩—塔克条件出自 18.2.1（[[sources/10-数学手册原书第10版--14-1821-问题的提法理论基础--16xlwe7]]）。两者分别是动态（多级决策）与静态（一次性决策）优化问题中最优性的代表性刻画。

| 维度 | 贝尔曼最优性原理 | 库恩—塔克条件 |
|---|---|---|
| 问题类型 | 离散动态规划（n 级决策过程） | 非线性优化（静态） |
| 条件性质 | 策略的结构性质：最优策略的后缀对子过程仍最优（全局性） | 一阶必要条件：梯度与乘子的方程组（局部性；凸情形有全局形式） |
| 前提假设 | 费用函数可分 + 诸 $H_j$ 极小可交换 | 可微性 + 正则性（约束规格，见 [[concepts/正则性条件]]） |
| 数学载体 | 最优值函数 $\varphi_j$ 与泛函方程 | [[concepts/拉格朗日函数]] 与乘子（对偶变量） |
| 刻画对象 | 整条策略 $(u_1^*,\dots,u_n^*)$ 与状态序列 | 单个最优点 $x^*$ 与主动约束集（[[concepts/主动约束集]]） |
| 使用方式 | 后向递推 + 前向回代（算法性） | 解代数条件/驻点方程（验证性或求解性） |
| 对偶侧面 | 无对偶概念 | 与 [[concepts/优化中的对偶性]]、鞍点（[[concepts/鞍点（拉格朗日函数的）]]）相衔接 |

## 要点

- 两者都是「必要条件的刻画」，但粒度不同：贝尔曼原理刻画的是解在过程结构上的可分解性（每级只须依赖当前状态），库恩—塔克条件刻画的是解在约束边界上的梯度平衡。
- 贝尔曼原理中「子过程最优策略与前 $j-1$ 级决策无关」正是状态作为充分统计量（无后效性）的体现；库恩—塔克条件中对应的「局部信息」是梯度与主动约束。
- 本比较基于两节手册内容并置，属跨 source 综合；两侧论断分别归属于各自 source（18.3 与 18.2.1）。
