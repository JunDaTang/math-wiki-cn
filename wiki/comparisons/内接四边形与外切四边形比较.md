# 内接四边形与外切四边形比较

[[concepts/内接四边形]]与[[concepts/外切四边形]]分别是「四边形与圆」的两种关系：顶点在圆上（边为弦）与边与圆相切。二者在源 3.1.4.6 与 3.1.4.7 中呈平行结构（比较框架为本 wiki 归纳；两列内容分别来自该两小节）。

| 维度 | 内接四边形 | 外切四边形 |
|---|---|---|
| 定义 | 有外接圆，边为该圆的弦 | 有内切圆，边为该圆的切线 |
| 插图 | 图 3.21(a) | 图 3.21(b) |
| 判据（当且仅当） | 对角和 $180^{\circ}$：$\alpha + \gamma = \beta + \delta = 180^{\circ}$（式 3.36） | 对边和相等且等于半周长：$a + c = b + d = s$（式 3.42） |
| 判据类型 | 角的条件 | 边的条件 |
| 冠名定理 | [[concepts/托勒密定理]]：$ac + bd = d_1 d_2$（式 3.37，源已冠名） | 皮托定理（式 3.42，源未冠名） |
| 关联圆的半径 | 外接圆半径 $R = \frac{1}{4S}\sqrt{(ab+cd)(ac+bd)(ad+cb)}$（式 3.38） | 内切圆半径 $r$ |
| 面积公式 | $S = \sqrt{(s-a)(s-b)(s-c)(s-d)}$（式 3.40，婆罗摩笈多公式，源未冠名） | $S = (a+c)r = (b+d)r$（式 3.43） |
| 其他专属公式 | 对角线 $d_1, d_2$（式 3.39a–b） | —（源未给） |

## 交集：双心四边形

内接且外切的四边形为双心四边形，其面积 $S = \sqrt{abcd}$（式 3.41）；由式 3.42 代入式 3.40 立即得到（推导见 [[findings/双心四边形面积与外切判定]]）。

## 对偶观察

- 弦（顶点在圆上）↔ 切线（边与圆相切）。
- 角的条件（对角和）↔ 边的条件（对边和）。
- 两类的公式互不可换用：式 3.37–3.40 仅对内接、式 3.42–3.43 仅对外切成立。
- 术语提示：源在式 3.38 处将内接四边形的外接圆称作「外切圆半径」，与小节首句不一致，见 [[queries/式3-38外切圆半径是否应为外接圆半径]]。
