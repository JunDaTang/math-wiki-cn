# 连续与离散切比雪夫逼近比较

本页对照 19.6.3 内部给出的两条求解路线，两列内容均出自本源（19.6.3.1–19.6.3.3 为连续情形，19.6.3.4 为离散情形）。

| 维度 | 连续切比雪夫逼近 | 离散切比雪夫逼近 |
|---|---|---|
| 问题 | (19.195)/(19.205)：max over [a,b] = min! | (19.206)：max over N 个点 = min!（N ⩾ n+2） |
| 定义域 | 整个区间 [a, b] | 有限点集 a ⩽ x₁ < x₂ < ⋯ < x_N ⩽ b |
| 理论特征 | [[交替点定理]]：n+2 个交替点等幅振荡、逐点变号 | 无交替点表述；转为逐点绝对值约束 (19.208) |
| 求解方法 | [[列梅兹算法]]迭代：解 (19.202) 型方程组（值条件 + 导数条件，需 f、gᵢ 可微），见 [[列梅兹算法迭代流程]] | 消去绝对值 → 线性不等式组 → 线性规划 (19.209)，回指 18.1.1.1（第 1179 页，未入库） |
| 解的形态 | 系数 aᵢ*、交替点 x_ν、最小偏差 ρ 联立确定（2n+4 个未知量） | 极小化变量 (a₀, …, aₙ, γ)；γ > 0 时有极小解 |
| 停机/收敛依据 | 停机判据 (19.204)；收敛性「在某些条件下」（[19.33]） | 线性规划自身的求解理论（本源未展开） |
| 相互关系 | — | 点数足够大及某些进一步的条件时，离散解可视作连续解（条件未具体化） |

## 关键差异

- 连续路线的方程组 (19.202) **同时**以系数、交替点、偏差为未知量，故须迭代（交替点与系数互为未知）；离散路线把 max 改写为单个变量 γ 的线性约束，一次性化为线性规划，**无须交替点概念**。
- 连续路线需要可微性（导数条件）；离散路线只需逐点函数值。
- 两条路线在参数非线性时**同时失效**：本源指出此时化为通常非凸的非线性最优化问题（18.2.2.1，第 1203 页，未入库），数值求解本质性变难——该结论仅针对参数非线性情形，不得外推到参数线性情形。

## 结论

离散化是把一致逼近从「迭代交换」范式转入「线性规划」范式的关键一步；二者在参数线性时各有完整解法，在参数非线性时共同退化为非凸最优化。
