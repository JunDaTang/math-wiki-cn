# 显式三次曲线与隐式三阶曲线比较

手册第 2 章在两处以「三次/三阶」为题：2.3–2.4 节的显式三次曲线（[[concepts/三次多项式]] 及 [[concepts/第I类三次曲线]]、[[concepts/第II类三次曲线]]、[[concepts/第III类三次曲线]]，源自 [[sources/10-数学手册原书第10版--6-23-多项式--l0zhnw]]、[[sources/10-数学手册原书第10版--7-24-有理函数--1pptax7]]）与本源 2.11 节的隐式三阶曲线（[[concepts/三阶代数曲线]] 及其五条成员）。二者是同一阶数下的两类对象，属扩展关系而非矛盾。

| 方面 | 显式三次曲线（2.3–2.4） | 隐式三阶曲线（2.11） |
|---|---|---|
| 表示 | $y = f(x)$，$f$ 为三次多项式或含三次项的显式函数 | $F(x, y) = 0$，$F$ 为三次多项式 |
| 典型成员 | $y = ax^{3}+bx^{2}+cx+d$；第I–III类三次曲线 | 二分之三次抛物线、阿涅西箕舌线、笛卡儿叶形线、蔓叶线、环索线 |
| 多值性 | 每个 $x$ 至多一个 $y$，图形无环部 | 可多值；叶形线、环索线有环部 |
| 奇点 | 函数图像无二重点、尖点 | 尖点（二分之三次抛物线）、二重点（叶形线、环索线） |
| 渐近线 | 由端行为决定（如倒数幂趋于坐标轴） | 水平 / 垂直 / 斜渐近线；可定义「曲线与渐近线围成的面积」 |
| 参数 / 极坐标表示 | 一般不用 | 三重表示是标准配置（叶形线、蔓叶线、环索线） |
| 要素清单 | 极值、拐点、单调区间 | 奇点、渐近线、顶点、环部面积、与渐近线围成面积、曲率、弧长 |

## 观察（分析推断）

- 显式三次函数图像写成 $y - f(x) = 0$ 后左端也是三次多项式，故同为三阶代数曲线；二者的差别在「函数性」而非「阶数」。此桥接观察为分析推断，两处源文本均未明言。
- 2.11 节的要素体系（奇点—渐近线—面积）是隐式曲线特有的：只要放弃「每个 $x$ 对应唯一 $y$」，二重点、尖点、环部等结构就会出现。
- 箕舌线以显式有理函数给出，正处在两类之间：它既是函数图像，又隐式化为三次曲线（隐式形为分析推断）。

## 证据来源

- 隐式三阶曲线侧：本源 2.11 节。
- 显式三次曲线侧：同书 2.3 节（[[concepts/三次多项式]]）与 2.4 节（第I–III类三次曲线，[[sources/10-数学手册原书第10版--7-24-有理函数--1pptax7]]）。
