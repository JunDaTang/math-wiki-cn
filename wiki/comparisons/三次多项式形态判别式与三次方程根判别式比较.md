# 三次多项式形态判别式与三次方程根判别式比较

《数学手册(原书第10版)》在两处对「三次」对象使用「判别式」之名，但两者不是同一对象：

| 维度 | 2.3.3 形态判别式 $\Delta = 3ac - b^2$ | 1.6.3.2 根判别式（式 1.156） |
|---|---|---|
| 所属对象 | 三次**函数** $y = ax^3+bx^2+cx+d$ 的图像形态 | 三次**方程** $ax^3+bx^2+cx+d=0$ 的根 |
| 是否含 d | 否 | 是 |
| 控制什么 | 单调（Δ≥0）vs 双极值（Δ<0） | 实根个数 1/2/3 与重数 |
| 数学本质 | 导数 $y' = 3ax^2+2bx+c$ 的判别式的 $-\tfrac{1}{4}$ 倍：$\mathrm{disc}(y') = -4\Delta$ | 根的重数信息（出现重根时为零） |
| 手册内的用法 | 2.3.3 曲线形状二分 | [[三次方程判别式的三情形]]；2.3.3 的实根 1/2/3 情形即其图像化 |

## 关键辨析

- **Δ 与根数无关**：例如 $y = x^3 - 3x + k$ 对一切 k 有相同的 Δ = −9 与相同的极值形态（极大 $2+k$、极小 $-2+k$），但其根数随 k 变化（k=0 三实根、$|k|=2$ 出现二重根、$|k|>2$ 仅一实根）。
- **根判别式不决定形态**：固定 a、b、c 而改变 d 只将曲线纵向平移，极值点相对位置与 Δ 均不变，但根判别式改变。
- 两者唯一的耦合是间接的：Δ<0（存在极大极小）是「可能有三个实根」的**必要**条件，具体根数还须比较极值与 0 的大小（即依赖 d）。
