# 若尔当引理五种情形比较

源文（14.4.3.1）将 [[concepts/若尔当引理]] 按指数因子与围道取向分为五种情形，比较如下：

| 情形 | 指数因子与参数 | 围道 | 对 f 的条件 | 结论 |
|---|---|---|---|---|
| a) | e^{iαz}，α > 0 | 上半平面半圆 C_R | f(z) 在上半平面及实轴上一致趋于 0 | (14.57b)：积分 → 0 |
| b) | e^{iαz}，α = 0 | 上半平面半圆 C_R | zf(z) 一致趋于 0 | (14.57b) 亦成立 |
| c) | e^{iαz}，α < 0 | 下半平面半圆 | 同 a) 的镜像 | 相应陈述成立 |
| d) | e^{iαz} | 弧段（替代完整半圆） | 源文未重述，推定同 a) | (14.57b) 亦成立 |
| e) | e^{αz}，左半平面 α > 0 或右半平面 α < 0 | 左/右半平面半圆或弧段 C_R* | 源文未重述，推定同 a) | (14.57c)：积分 → 0 |

## 共同机理（标准背景注记，源文未证明）

|e^{iαz}| = e^{−αy}：α > 0 时上半平面（y > 0）衰减，α < 0 时下半平面衰减；|e^{αz}| = e^{αx}：α > 0 时左半平面（x < 0）衰减。五种情形的差别只在「指数因子的衰减半平面」与「围道所处半平面」的配对；情形 b) 退化到 α = 0 时指数因子不再提供衰减，改由 zf(z)→0 补偿弧长 ~πR 增长所需的一个 1/z 阶。

## 各情形的使用

14.4 的算例均使用情形 a)（指数因子 e^{iz} 或 e^{iαz}，α > 0，上半平面）：例 1（f = z/(z²+a²)）、例 2（f = 1/z）、例 3–4（f = 1/z，配缩进围道）。情形 b)–e) 在本节无算例。

## 表述上的保留

情形 d) 的源文表述较宽泛（未指明弧段所处位置与条件细节），仅在陈述层面接受（见 [[findings/式14-56至14-62及ez例复积分计算实积分转录复算]] 断言 3）。
