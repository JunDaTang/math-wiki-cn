# 簇与非簇代数类比较

依伯克霍夫定理（[[concepts/方程类与伯克霍夫定理]]），「是簇」与「可由方程定义」等价。5.6 节给出的示例组可排成如下对照：

| 代数类 | 是否簇 | 关键构造行为（源文依据） | 能否由方程定义 |
|---|---|---|---|
| 半群的类 | 是 | 三种构造封闭（源文断言） | 能 |
| 群的类 | 是 | 三种构造封闭（源文断言） | 能 |
| 阿贝尔群的类 | 是 | 三种构造封闭（源文断言） | 能 |
| 环的类 | 是 | 三种构造封闭（源文断言） | 能 |
| 循环群的类 | 否 | 直接积不封闭：循环群的直接积不是循环群 | 不能 |
| 域的类 | 否 | 直接积不封闭：域的直接积不是域 | 不能 |

## 解读

- 源文中被点名破坏封闭性的构造都是直接积：两个循环群的直积可失去循环性，两个域的直积不再是域。
- 正反结论分属不同的类，不可互移：由「群的类是簇」不能推出其任何子类（如循环群的类）是簇——循环群类恰是反例。
- 背景印证（非源文内容，可独立核实）：$\mathbb{Z}_2 \times \mathbb{Z}_2$ 不是循环群；两个非平凡域的直积含零因子（$(1,0)\cdot(0,1)=(0,0)$），故不是域。
