# 因式分解方法比较

本页对照《数学手册(原书第10版)》1.1.6.2 给出的三种多项式因式分解方法（提取公因式、分组、利用方程的性质），建档模式参照已有的 [[comparisons/证明方法比较]]。方法总述见 [[concepts/因式分解]]。

## 对照表

| 方法 | 操作要点 | 适用情形 | 手册例题 |
|---|---|---|---|
| A 提取公因式 | 提出各项共有的因子 | 各项存在公因式 | $8ax^{2}y - 6bx^{3}y^{2} + 4cx^{5} = 2x^{2}(4ay - 3bxy^{2} + 2cx^{3})$ |
| B 分组解法 | 拆项后分组，使各组出现同一公因式 | 直接提取无效，但可适当分组 | $6x^{2} + xy - y^{2} - 10xz - 5yz = (2x + y)(3x - y - 5z)$ |
| C 利用方程根的性质 | 以 $P(x)=0$ 的根生成线性因子，再检验剩余二次因式 | 已知或可求出方程的根 | $x^{6} - 2x^{5} + 4x^{4} + 2x^{3} - 5x^{2} = x^{2}(x-1)(x+1)(x^{2}-2x+5)$ |

## 分析

- **A 是最基本的一步**，常作为 B、C 的前置操作：手册例 C 中即先提取公因子 $x^{2}$。
- **B 依赖拆项技巧**（例中 $xy = 3xy - 2xy$），手册未给出统一的选取规则。
- **C 把分解问题转化为求根问题**（手册前向引用第 56 页 1.6.3.1，该章节尚未入库），并以 $\frac{p^{2}}{4} - q < 0$ 判定二次因式不可再实分解，从而给出分解终止的判据（见 [[findings/手册以p方除4减q小于零判定二次因式无实分解]]）。
- 手册原文将途径表述为“提取公因式、分组、利用方程的特殊公式和特殊性质”，其中“特殊公式”对应 1.1.6.3 的 [[concepts/乘法公式]]（逆向使用），与 A、B、C 可联合运用。
- 分解的完备性取决于系数域：例 C 的商 $x^{2}-2x+5$ 在实数范围内不可再分解，故最终分解式在实数范围内完备。
