# 莱布尼茨公式与二项式定理比较

《数学手册》6.1.3.3 在给出莱布尼茨公式求和式（式 6.23）时明确指出「它的结构与二项式公式对应（参见第 14 1.1.6.4)」。本页展开这一对应。注意：被引的二项式公式位于（疑）第 1 章 1.1.6.4，未入库，交叉引用文本损坏（见 [[queries/6-1-3全节系统性转写讹误清单]]）；下表中二项式公式的通行形式为背景补写，非本源直接证据。

## 公式对照

| 维度 | 二项式公式（1.1.6.4，未入库） | 莱布尼茨公式（式 6.23） |
|---|---|---|
| 通行形式 | $(u+v)^{n} = \sum_{m=0}^{n}\binom{n}{m} u^{\,n-m} v^{\,m}$ | $D^{n}(uv) = \sum_{m=0}^{n}\binom{n}{m} D^{m}u\, D^{n-m}v$ |
| 作用对象 | 数或变量的幂与乘法（代数运算） | 求导算子 $D = \frac{\mathrm{d}}{\mathrm{d}x}$ 的 n 次作用 |
| 系数 | 二项式系数 $\binom{n}{m}$ | 同为 $\binom{n}{m}$ |
| 指标结构 | 幂次按 $(n-m, m)$ 分配给 $u, v$ | 求导阶数按 $(m, n-m)$ 分配给 $u, v$ |
| 零阶约定 | $u^{0} = v^{0} = 1$（乘法单位） | $D^{0}u = u$，$D^{0}v = v$（算子零次幂为恒等）——手册原文即以「用 $D^{0}u, D^{0}v$ 分别代替 $u, v$」由式 6.22 得到式 6.23 |
| n 的范围 | n 为非负整数（有限和） | n 为非负整数（有限和） |

## 结构对应

把二项式公式中的「乘幂 $m$ 次」替换为「求导 $m$ 次」、乘法单位 $1$ 替换为恒等作用，即由二项式公式的形状得到莱布尼茨公式。手册明确断言这一对应（源文直接证据）；直观上，其根源在于乘积求导法则 $(uv)' = u'v + uv'$ 本身就是 $n = 1$ 的「二项式」型展开，逐次迭代即产生二项式系数。

## 差异

- 二项式公式是关于数与代数乘法的恒等式；莱布尼茨公式是关于求导算子作用的恒等式，其成立依赖乘积求导法则，而非幂运算律。
- 实用行为不同：当一因子为低次多项式时，莱布尼茨和式会在 $d + 1$ 项之外进一步截断（见 [[methodology/莱布尼茨公式截断计算流程]]）；二项式和式在给定 n 下本就是有限的，无此额外截断。
