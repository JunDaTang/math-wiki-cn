# 警告消息与错误消息后果比较

本比较基于《数学手册》20.2.10 节为说明 [[concepts/消息系统（Mathematica）]] 而安排的两个算例（复算见 [[findings/算例A与B消息触发复算]]）。二者同以 symbol::tag 形式呈现，但对计算进程的后果不同：

| 维度 | 例 A（警告型） | 例 B（错误型） |
|---|---|---|
| 输入 | f[0]，其中 f[x_] := 1/x | Log[3, 16, 25] |
| 消息 | Power::infy | Log::argt |
| 消息内容 | Infinite expression 1/0 encountered. | Log called with 3 arguments; 1 or 2 arguments are expected. |
| 计算能否执行 | 能——警告之后计算本身可以执行 | 不能——按定义不允许，Mathematica 对该表达式不能做任何事情 |
| 输出 | Out[2] = ComplexInfinity | Out[1] = Log[3, 16, 25]（原样返回） |
| 语义类别 | 求值得到非有限结果，属警告 | 自变量数目不符，属错误 |

判读要点：消息形式的统一（symbol::tag）并不代表后果的统一；区分「发出警告但仍给出结果」与「拒绝求值并原样返回」是理解 Mathematica 消息系统的关键。该节以两例分别示范两类后果，属刻意安排的对照，非偶然并举。
