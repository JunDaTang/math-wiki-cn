# 经典与量子谐振子概率密度比较

手册 9.2.4.7.3 以 n=1（E = (3/2)ℏω）为例对比量子与经典谐振子的概率密度（9.147d/e）：

## 量子情形

- 粒子在区间 (x, x+dx) 中的量子力学概率 dw_qu = |Ψ(x)|²dx；**在区间（经典转折点）之外也不等于零**。
- n=1 的密度（按源文，疑漏因子，修正后）为 2√(λ/π)·λx²·e^{−λx²}dx，最大出现概率位于

```latex
x_{\max,qu}=\pm\frac{1}{\sqrt{\lambda}}=\pm\sqrt{\frac{\hbar}{m\omega}}   % 9.147d
```

（注：此处 λ 实为 α = mω/ℏ，与 9.143c 的 λ = 2E/ℏω 含义不同，见 [[queries/式9-147d概率密度疑漏因子λx平方]]。）

## 经典情形

- 经典振子的逆向点（转折点）为

```latex
x_{\max,kl}=\pm a=\pm\sqrt{\frac{2E}{m\omega^{2}}}=\pm\sqrt{\frac{3\hbar}{m\omega}}   % 9.147e
```

振幅 a = (1/ω)√(2E/m)，由 E = ½mω²a² 计算。经典粒子在转折点附近速度小、停留时间长，概率密度集中在转折点附近。

## 对比要点

| 维度 | 量子（n=1） | 经典 |
|---|---|---|
| 密度极大的位置 | x = ±√(ℏ/mω) | 转折点 x = ±√(3ℏ/mω) |
| 经典禁区（\|x\| > a） | 概率非零（隧穿式尾部） | 概率恒为零 |
| 分布形态 | 双峰 + 中间节点（Ψ₁ 有一个结点） | 向转折点集中、在转折点发散 |

- 量子极大点位于经典转折点**之内**：|±√(ℏ/mω)| < |±√(3ℏ/mω)|。
- **对应原理**（本源收尾结论）：对大量子数 n，量子力学概率密度函数在均值意义上趋于经典概率密度函数。
