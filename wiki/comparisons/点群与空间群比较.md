# 点群与空间群比较

依据数学手册 5.3.5.2 与 5.3.5.4（式 5.121–5.128）：

| 维度 | 点群 | 空间群 |
|---|---|---|
| 元素形式 | 单个对称运算 $S$（旋转、反射、反演等） | $\{R\mid\vec V(R)+\vec t_{\pmb n}\}$（式 5.127） |
| 不动点 | 至少一个点不动（「点」群之名） | 一般无不动点（含平移成分） |
| 平移成分 | 无 | 本原平移 $\{e\mid\vec t_{\pmb n}\}$ 与非本原平移 $\vec V(R)$（滑动反射、螺旋式旋转） |
| 作用公式 | $S\vec r$（直接映射） | $\{R\mid\vec t_{\pmb n}\}\vec r=R\vec r+\vec t_{\pmb n}$（式 5.128） |
| 晶体学计数 | 32 个晶体学点群 | 230 个空间群 |
| 作用对象 | 分子（无限族）、晶体的格点对称 | 晶体格（「空」格） |
| 交换性 | 一般非交换 | 一般非交换 |

**要点**：

- 空间群的 $\{R\mid 0\}$ 部分就是点群运算；把 $P$ 的元素与本原平移、非本原平移复合即得完整空间群。若所有非本原平移为零（$\vec V(R)=0$），得到所谓对称式（symmorphic）空间群，结构为平移群与点群的半直积（对称群论标准事实，推断；原书本节未展开）。
- 「空」格与真实晶体：空间群 $G$ 是空格的对称群；真实晶体成分的排列引入自身对称性，故 $G_0\subset G$。点群框架下没有这一层区分。
