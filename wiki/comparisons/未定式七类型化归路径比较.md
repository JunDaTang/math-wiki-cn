# 未定式七类型化归路径比较

手册 2.1.4.8 以 [[concepts/洛必达法则]] 为核心组织七类 [[concepts/未定式]]的处理，各类型的化归路径与算例如下（算例均经独立核验）：

| 类型 | 化归路径 | 手册算例 |
| --- | --- | --- |
| $\frac00$ | 直接洛必达（式 2.26），或先适当变形（约分、有理化、化归 $\frac{\sin u}{u}\to1$） | $\frac{x^3-1}{x-1}\to3$；$\frac{\sqrt{1+x}-1}{x}\to\frac12$；$\frac{\sin 2x}{x}\to2$ |
| $\frac\infty\infty$ | 直接洛必达 | $\frac{\ln\sin 2x}{\ln\sin x}\to1$ |
| $0\cdot\infty$ | 取倒数化为 $\frac{\varphi}{1/\psi}$ 或 $\frac{\psi}{1/\varphi}$，归于 $\frac00$ 或 $\frac\infty\infty$ | $(\pi-2x)\tan x\to2$（$x\to\frac\pi2$） |
| $\infty-\infty$ | 通分，如 $\varphi-\psi=\left(\frac1\psi-\frac1\varphi\right)\big/\frac{1}{\varphi\psi}$ | $\frac{x}{x-1}-\frac1{\ln x}\to\frac12$（$x\to1$，两次洛必达） |
| $0^0$ | 取对数 $\ln f=\psi\ln\varphi$ 化为 $0\cdot\infty$，得 $A$ 后 $f\to e^A$ | $x^x\to1$（$x\to+0$） |
| $\infty^0$ | 同上取对数 | 手册称“类似地” |
| $1^\infty$ | 同上取对数 | 手册称“类似地” |

**方法定位**：

- **方法一（适当的变形）**：无须可导性，适用面最广，是首选尝试。
- **方法二（洛必达法则）**：系统化程度最高，可迭代；但须注意失效注记（导数比极限不存在不意味着原式极限不存在），且手册式 2.26 前置条件疑有转写错误（见 [[queries/式2-26前置条件是否应为导数比极限存在]]）。
- **方法三（[[concepts/泰勒展开式]]）**：对 $\frac00$ 型尤为有效，如 $\frac{x-\sin x}{x^3}\to\frac16$；详述待 6.1.4.5（第 594 页）入库。

手册 2.1.4.7 五定理的排除条款使用同一份未定式名单，见 [[findings/极限五定理均附未定式排除条款]]；化归路径的原文收录见 [[findings/七类未定式的化归路径]]。
