# 斜等轴测与斜角立体投影比较

依据 [[sources/10-数学手册原书第10版--8-355-平面投影--yid4ap|数学手册(原书第10版) 3.5.5.6]]，[[concepts/斜投影|斜平行投影]]的两个特例（均为单位立方体算例，已复算验证，见 [[findings/斜平行投影公式与立方体两算例]]）：

| 比较维度 | 斜等轴测投影 | 斜角立体投影 |
|---|---|---|
| 夹角 $\alpha$ | $45^\circ$ | $30^\circ$ |
| 缩放因子 $d$ | $1$ | $\tfrac12$ |
| 对应的 $\beta$ | $45^\circ$ | $\arctan 2\approx63.43^\circ$（原书作 $63.4^\circ$） |
| 垂直于画面的线段 | 不变短 | 被减半 |
| 投影矩阵 (3.480) 第三列 | $(-\tfrac{1}{\sqrt2},-\tfrac{1}{\sqrt2},0,0)^{\mathrm T}$ | $(-\tfrac{\sqrt3}{4},-\tfrac14,0,0)^{\mathrm T}$ |
| 顶点 $(0,0,1)$ 的投影 | $(-\tfrac{1}{\sqrt2},-\tfrac{1}{\sqrt2})$ | $(-\tfrac{\sqrt3}{4},-\tfrac14)$ |
| 手册图示 | 图 3.215 | 图 3.216 |

两者的差异完全由参数对 $(\alpha,d)$ 决定：$d$ 控制垂直于画面方向的缩短比例（$d=1$ 不缩、$d=\tfrac12$ 减半），$\alpha$ 控制该方向投影像与 $x$ 轴的夹角。

（可独立核实的背景：这两类投影在英文计算机图形学文献中通常分别对应 cavalier projection 与 cabinet projection。）
