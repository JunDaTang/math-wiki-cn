# 折旧方法对比

对比《数学手册(原书第10版)》1.3.5 给出的四种折旧方法及混合法。共同记号：折旧基数 A、有效期限 N、残值 $R_n$、年折旧额 $a_n$（手册称"折旧率"）。

## 一览表

| 方法 | 折旧额模式 | 公式 | 首年折旧额（共同算例） | 残值行为 |
|---|---|---|---|---|
| [[直线折旧]] | 常数 $a = \frac{A-R_N}{N}$ | (1.88)–(1.89) | €8000 | 线性递减，可折至 0 |
| [[算术递减折旧]] | 逐年递减固定差 d，$a_1$ 受双界 (1.93) 约束 | (1.90)–(1.93) | €15000（d = €3500） | 递减，末年折旧骤降 |
| 数字递减（算术递减特例） | $a_k = (N-k+1)d$ | (1.94a)–(1.94b) | €13335（d = 2667） | 取整漂移致 $R_5$ = €9995 |
| [[几何递减折旧]] | 每年折旧残值的 p% | (1.95) | 视 p 而定 | 有限 n 内永不为 0 |
| 混合法 | 前段几何 + 后段直线 | (1.96) 判据 $m > N - \frac{100}{p}$ | — | 可在 N 年内折至 0 |

## 共同算例（A = €50000、N = 5、R₅ = €10000）的首年对比

- 直线：a = €8000，首年折旧率 16.0%（8000/50000）；
- 算术递减（a₁ = €15000、d = €3500）：首年折旧率 30.0%；
- 数字递减（d = 2666.67，取整 2667）：首年折旧率 26.7%（13335/50000）。

三张完整分摊表（原文照录）见 [[10-数学手册原书第10版--7-13-商业数学--k55pur]]。

## 评注归属（不可跨方法转述）

- 直线法示例表的评注为"对于实际原价的累积折旧率逐渐增大"（列名口径有疑，见 [[直线折旧表累积折旧率列的口径是什么]]）。
- 算术递减示例表的评注为"除了最后一个数值，折旧率大致相等"。
- 数字递减示例表的评注为"折旧率大致相等"，未提末年折旧率骤降至 21.1%。

## 结构关系

- 直线法是算术递减 d = 0 的特例（手册 1.3.5.3 明示）。
- 数字递减是算术递减 $a_N = d$ 的特例（手册 1.3.5.4 明示）。
- 几何递减残值 $\left(1-\frac{p}{100}\right)^n$ 对有限 n 不为零，故手册建议适时转直线，判据 (1.96)，见 [[几何折旧残值不为零及转直线判据]]。
