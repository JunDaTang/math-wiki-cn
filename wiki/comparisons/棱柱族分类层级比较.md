# 棱柱族分类层级比较

3.3.3 定义的棱柱族特化链（平面情形的对照见 [[comparisons/平面四边形七类分类层级比较]]）：

| 层级 | 定义 | 新增约束 | 公式 |
|---|---|---|---|
| 棱柱 | 两全等底 + 平行四边形侧面 | — | 3.116–3.120 |
| 平行六面体 | 平行四边形底的棱柱 | 底为平行四边形 | 四条空间对角线共点 |
| 长方体 | 矩形底的直角平行六面体 | 直角 + 矩形底 | 3.121–3.123 |
| 立方体 | 等棱长方体 | a = b = c | 3.124–3.126 |

另有正交分支：棱柱 → 直棱柱（棱垂直于底）→ 正棱柱（直棱柱 + 正多边形底，底为 [[concepts/正凸多边形]]）。

## 平行—垂直双轴

- **「平行」轴**（底面形状）：任意多边形 → 平行四边形 → 矩形 → 正方形，对应立体：[[concepts/棱柱]] → [[concepts/平行六面体]] → [[concepts/长方体]] → [[concepts/立方体]]。二维族（[[concepts/平行四边形]] → [[concepts/矩形]] → [[concepts/正方形]]）逐级提升。
- **「垂直」轴**（棱与底的关系）：斜棱柱 → 直棱柱 → 正棱柱。
- 「平行」轴走到尽头且棱垂直于底才得到长方体；两轴同时走到尽头得到立方体。

## 性质逐级增强（均为源内陈述）

- 对角线：平行六面体的全部四条空间对角线交于同一点（即它们的中点）→ 长方体的空间对角线长相等（d² = a²+b²+c²）→ 立方体 d² = 3a²。
- 体积公式从一般的 V = A_G h（式 3.116）逐级具体化为 V = abc（式 3.122）与 V = a³（式 3.125）；侧面积与表面积同理（3.117–3.118 → 3.123 → 3.126）。

公式细节见 [[findings/棱柱族公式]] 与 [[findings/平行六面体至立方体公式]]。
