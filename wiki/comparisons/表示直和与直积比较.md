# 表示直和与直积比较

由已知表示构造新表示的两条途径（原书 5.3.4.3 与 5.3.4.4）：

| 维度 | 直和（式 5.107–5.110） | 直积 / 克罗内克积（式 5.111–5.113） |
|---|---|---|
| 新表示维数 | n₁ + n₂ | n₁ · n₂ |
| 矩阵结构 | 分块对角 [[D⁽¹⁾, 0], [0, D⁽²⁾]] | 克罗内克积 (D)_{ik,jl} = D⁽¹⁾_{ik}·D⁽²⁾_{jl} |
| 表示空间 | 不变子空间的直和 V_{n₁} ⊕ V_{n₂} | 张量积空间 V_{n₁} ⊗ V_{n₂} |
| 特征 | 可加：χ = χ⁽¹⁾ + χ⁽²⁾（式 5.110） | 可乘：χ^{(1×2)} = χ⁽¹⁾·χ⁽²⁾（式 5.113） |
| 与可约性的关系 | 完全可约表示的分块对角形式（式 5.116） | 两个不可约表示之积一般可约，分解为 Clebsch-Gordan 级数（式 5.118） |
| 前置知识 | 不变子空间（式 5.109） | 克罗内克积（第 370 页 4.1.5, 9.，未入库） |

二者常配合使用：先用直积从旧表示生成新表示，再经 Clebsch-Gordan 分解化为不可约成分的直和（见 [[concepts/克勒布施-戈丹级数]]）。特征的两条演算规则（可加、可乘）是手工判定可约性与分解的主要工具（见 [[findings/壳层模型s3三维表示与特征]] 的应用）。
