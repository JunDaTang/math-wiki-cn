# 对数形式与反双曲函数形式比较

## 比较对象

[[数学手册(原书第10版)]] 21.7.2 系统并记的两套等价记法（体系总述见 [[反双曲函数与对数双形式]]）：同一原函数既写作反双曲函数加 $+C$，又写作对数式加 $+C_1$。全部依据 [[10-数学手册原书第10版--11-2172-无理函数积分--1swy6lt]]。

## 恒等对应

| 反双曲形式 | 对数形式 | 出处（21.7.2） |
|---|---|---|
| $\operatorname{Arsinh}\frac xa + C$ | $\ln(x+\sqrt X) + C_1$（$X = x^2+a^2$） | 185、187、190、192、194、199、201、204、208【重构】 |
| $\operatorname{Arcosh}\frac xa + C$ | $\ln(x+\sqrt X) + C_1$（$X = x^2-a^2$） | 213、215、218、220、222、227、229、232、236【重构】 |
| $\operatorname{Artanh}\sqrt{\frac{fX}{aY}}$ | $\ln(\sqrt{aY}+\sqrt{fX})$ | 146 案例 2↔3（$af>0$，等价冗余） |
| $\operatorname{Arcoth}\sqrt{\frac Xb}$ | $\frac12\ln\frac{\sqrt X-\sqrt b}{\sqrt X+\sqrt b}$ | 127（$b>0$） |
| $\operatorname{Arsinh}\frac{2ax+b}{\sqrt\Delta}$ | $\ln(2\sqrt{aX}+2ax+b)$ | 241 案例 1↔2（258 同构） |

## 常数约定

两形式相差仅依赖参数的常数，例如 $\operatorname{Arsinh}\frac xa = \ln(x+\sqrt X) - \ln a$，故 $C_1 = C - \ln a$。手册以 $+C$、$+C_1$ 分别标记；校勘时两形式须分别求导验证，且不可混同两个常数。

## 取舍分析

- **反双曲形式**：紧凑；与族 5 的 $\arcsin$ 严格平行（[[二次根式三族平行结构]]），高次条目（199、201、227、229）的幂次结构清晰。
- **对数形式**：不引入特殊函数记号，数值计算与查表直接；但 $\ln a$ 类常数差易被忽略。
- 146 案例 2/3 为**等价冗余**（相差常数），非矛盾，见 [[21-7-2无理函数积分逐式求导复算]]。

## 易误读点

190/194 用 $\ln(x+\sqrt X)$（Arsinh 核）而 191/196 用 $\ln\frac{a+\sqrt X}{x}$（$\frac1x$ 型核）：两者是被积函数不同所致的正确并存，不可据一方改另一方。同理，族 7 的 $\frac1x$ 型条目（如 224）用 $\arccos\frac ax$ 而非对数核——三套核的分工见 [[圆弧双曲两族二次根式积分平行比较]]。
