# 度分秒与 gon 与 rad 换算比较

手册 21.4 节表 4「平面角」组收录两套非 rad 角度制式：六十进制（度、分、秒）与百分制（gon，新度/新分/新秒），均以 rad 为桥接单位给出精确式与近似值。本页并列两制式并复算；全部数值复算通过（[[findings/21-4单位定义与换算数值复算]]，直接证据）。

## 六十进制（度分秒）

| 单位 | 精确式（源文） | 近似值（源文） | 复算 |
|---|---|---|---|
| 度 1° | π/180 rad | 0.017453293⋯ rad | π/180 = 0.0174532925 ✓ |
| 分 1′ | (1/60)° = π/10800 rad | 0.000290888⋯ rad | π/10800 = 2.9088821·10⁻⁴ ✓ |
| 秒 1″ | (1/60)′ = π/648000 rad | 0.000004848⋯ rad | π/648000 = 4.8481368·10⁻⁶ ✓ |

## 百分制（gon）

| 单位 | 源文 | 复算 |
|---|---|---|
| 新度 1^g | 0.5π·10⁻² rad | 0.0157079633 rad ✓ |
| 新分 1^c | 0.5π·10⁻⁴ rad | 1.5707963·10⁻⁴ rad ✓ |
| 新秒 1^cc | 0.5π·10⁻⁶ rad | 1.5707963·10⁻⁶ rad ✓ |

gon 即百分度（直角 = 100 gon）。「新度/新分/新秒」对应德文 Neugrad/Neuminute/Neusekunde，属母书德文底本术语痕迹（[[entities/数学手册(原书第10版)]]）。源文三行的「符号」列均排作 gon，实际记号应为上标 g/c/cc。

## 两制式与 rad 的关系

- 直角 = 90° = 100 gon = π/2 rad；
- 1° = (200/180) gon = 10/9 gon ≈ 1.111 gon；1 gon = 0.9°；
- 度分秒为六十进（1° = 60′ = 3600″），gon 制为百进（1^g = 100^c = 10⁴^cc）。

## 小结

两组换算数值全部精确复算通过，无任何数值讹误；本组仅存的疑点为符号排印（gon 行上标记号未区分）——属转写层面，见 [[queries/21-4全节系统性转写讹误清单]]。
