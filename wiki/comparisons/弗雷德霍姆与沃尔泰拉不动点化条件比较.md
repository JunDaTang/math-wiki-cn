# 弗雷德霍姆与沃尔泰拉积分方程的不动点化条件比较

本比较基于《数学手册(原书第10版)》12.2.2.4 第 2–3 部分（式 12.66–12.69），并与第 11 章的对应结论（11.2、11.4，均已入库）互证。

## 对照

| | 第二类弗雷德霍姆方程 (12.66) | 第二类沃尔泰拉方程 (12.68) |
|---|---|---|
| 方程 | $\varphi(x)-\int_a^bK(x,y)\varphi(y)\,dy=f(x)$ | $\varphi(x)-\int_a^xK(x,y)\varphi(y)\,dy=f(x)$ |
| 不动点算子 | $(T\varphi)(x)=\int_a^bK\varphi+f$（12.67） | $T=f+V$，$(V\varphi)(x)=\int_a^xK\varphi$（12.69） |
| 舞台 | $(C([a,b]),\sup$ 距离 $(12.48))$ | 同左 |
| 12.2 给出的压缩条件 | $\max_x\int_a^b\lvert K(x,y)\rvert\,dy<1$ ⟹ $T$ 压缩 | **未给出**（仅完成不动点化） |
| $T$ 本身是否压缩 | 条件下是 | 一般**否**（即使 $\max_x\int_a^b\lvert K\rvert\,dy\ge 1$ 方程仍可解） |
| 对应第 11 章结论 | 诺伊曼级数收敛条件（[[entities/诺伊曼级数]]、[[comparisons/压缩映射条件与诺伊曼级数收敛条件比较]]） | 无条件存在唯一（[[concepts/沃尔泰拉方程的存在唯一性定理]]） |

## 论点

1. **核的小性条件角色不同**：弗雷德霍姆情形 $\max_x\int_a^b\lvert K\rvert\,dy<1$ 是 12.2 框架下 $T$ 压缩的充分条件，缺之则可能出现本征值/非唯一现象（11.2 的弗雷德霍姆定理）；沃尔泰拉情形积分上限为 $x$，使 $V$ 的幂迅速衰减——$V^n$ 的核为 $n$ 重迭核，其范数受 $(M(b-a))^n/n!$ 型因子控制（标准结论，非本节原文），故 $T^n$ 对充分大的 $n$ 压缩，存在唯一性**无条件**成立；
2. **一致性**：12.2 沃尔泰拉小节的「仅不动点化、不给条件」与 11.4 的无条件定理并不矛盾——可通过幂压缩版的不动点论证衔接（本节未陈述该版本，属转写缺口，见 [[queries/沃尔泰拉小节压缩条件缺失是否转写截断]]）；
3. **方法启示**：不动点化本身总是可行；关键是选择/构造使算子（或其幂）压缩的距离。弗雷德霍姆用 sup 距离＋核小性，沃尔泰拉靠幂压缩（或加权度量）。

两处（12.2 与 11.2/11.4）结论相容且互补。
