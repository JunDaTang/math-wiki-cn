# 三类三次曲线比较

手册 2.4.3–2.4.5 将三个「次数为 3 的代数曲线」型有理函数并置处理（来源：[[sources/10-数学手册原书第10版--7-24-有理函数--1pptax7]]）。三者都是「二次式 + 低次分子」的分式，但二次式所在位置不同，导致要素结构系统性错开：

| 维度 | 第I类（式 2.47） | 第II类（式 2.48） | 第III类（式 2.49） |
|---|---|---|---|
| 表达式 | y = a + b/x + c/x² | y = 1/(ax²+bx+c) | y = x/(ax²+bx+c) |
| 参数限制 | b ≠ 0, c ≠ 0 | a ≠ 0 | a、b、c ≠ 0 |
| 二次式位置 | 分子（ax²+bx+c） | 分母 | 分母 |
| 水平渐近线 | y = a | y = 0（x 轴） | y = 0（x 轴） |
| 垂直渐近线/间断点 | x = 0（固定，二重极点） | 视 Δ：无 / 一个二重 / 两个一重 | 视 Δ：无 / 一个二重 / 两个一重 |
| 对称性 | 一般无对称轴 | 关于 x = −b/(2a) 对称 | 一般无对称轴，但必过原点 |
| 极值 | 一个（B 点，显式公式） | Δ ≠ 0 时一个极大值 4a/Δ | 视情形：两个 / 一个 / 无 |
| 拐点 | 一个（C 点，显式公式） | Δ > 0 时两个（显式公式及切线斜率） | Δ > 0 时三个，其余情形一个 |
| 形态判据 | b、c 符号（四情形）；x 轴交点按 b²−4ac | Δ = 4ac−b² 三情形 | Δ 三情形 × b 符号 × 根 α, β 符号（共 6 模式） |

结构观察：

- **分母决定间断点**：第I类的分母是 x²，间断点固定在 x = 0 且为二重极点（两侧同号趋于无穷）；第II、III类的分母是二次式，间断点的个数与位置由 Δ = 4ac − b² 控制，且二重极点（Δ = 0）两侧同号、一重极点（Δ < 0）两侧变号——与 [[concepts/极点]] 的重数判据一一对应。
- **对称性来源**：第II类的对称轴 x = −b/(2a) 直接继承自分母二次式关于其顶点横坐标的对称；第I类与第III类的一般表达式破坏这种对称。
- **判别式口径分裂**：只有第I类用标准形式 b² − 4ac（且用于判与 x 轴交点个数），第II、III类用反号的 Δ = 4ac − b² 判形态，见 [[queries/2-4节内二次判别式两种符号约定为何并存]]。
- **特征点显式度**：第I类给出三点组的完整坐标（1:2:3 结构）；第II类给出极值与两拐点坐标及拐点切线斜率；第III类给出极值点公式（± 同号配对）但拐点只给个数。

全部特征点公式均经独立重推导验证（见各发现页：[[findings/第I类三次曲线的1-2-3三特征点与交点判别]]、[[findings/第II类三次曲线按判别式三情形的公式体系]]、[[findings/第III类三次曲线的六种行为模式与极值点配对]]）。相关：[[concepts/有理函数]]、[[methodology/有理函数图像绘制法]]。
