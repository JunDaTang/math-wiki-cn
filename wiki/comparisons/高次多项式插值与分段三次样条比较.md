# 高次多项式插值与分段三次样条比较

高次多项式插值（19.6.1）与分段三次样条（19.7.1）的比较。本表跨源：左列依据 19.6.1 各页（[[concepts/多项式插值]] 等）与 19.7 开篇动机句。

| 维度 | 高次多项式插值（19.6.1） | 分段三次样条（19.7.1） |
|---|---|---|
| 表示 | 单一全局多项式（[[concepts/拉格朗日插值公式]]、[[concepts/牛顿插值公式]]、[[concepts/艾特肯－内维尔插值]]） | 分段次数 ⩽ 3 的多项式 + 节点处光滑过渡 |
| 已知缺陷 | 高次插值逼近多项式通常有并不想要的振荡（19.7 开篇动机） | 以低次分段化解振荡 |
| 确定性 | 插值条件唯一确定多项式 | 四性质（插值 + 分段次数 + C² + 边界条件）唯一确定 |
| 变分意义 | —（19.6.1 未述） | 自然样条最小全曲率（[[concepts/霍拉迪定理]]），弹性细尺类比 |
| 求解结构 | 插值方程组/递推格式 | 三对角方程组 (19.240)，LR 分解高效求解 |
| 数据含误差时 | 插值将误差全部吸收 | 有光滑样条 (19.242) 变体可罚化处理 |

## 要点

- 样条是 19.6.1 缺陷的直接补救：将近似区间用节点分为子区间、每段用相对简单的近似函数，是跨 19.6.1–19.7 的主线；
- 原书开篇即以「 unwanted 振荡」为引入，故此对照是理解 19.7 定位的关键；
- 二者并非互斥：小数据量、光滑被插函数时高次插值仍可用（19.6.1 语境），样条针对振荡问题。
