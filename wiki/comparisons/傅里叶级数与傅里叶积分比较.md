# 傅里叶级数与傅里叶积分比较

本页对照手册 7.4.4 的论点：傅里叶积分（式 7.113a）可看作 l → ∞ 时非周期函数在 (−l, l) 上三角级数展开式的极限——二者是同一表示理论在「周期 / 非周期」两端的形态。

| 维度 | 傅里叶级数 | 傅里叶积分 |
|---|---|---|
| 适用对象 | 周期为 T 的周期函数（或有限区间上的延拓） | 非周期函数 |
| 成立条件 | 狄利克雷条件（逐点收敛）；有界 + 分段连续（均方收敛） | 任意有限区间狄利克雷条件 + ∫_{−∞}^{∞}\|f\| dx 收敛（回指 8.2.3.2） |
| 表示形式 | 离散和：a_0/2 + Σ(a_k cos kωx + b_k sin kωx) | 积分：(1/2π)∫∫ 或 (1/π)∫₀^∞∫（偶/奇函数另有 7.114a/b 单侧形式） |
| 谱结构 | 离散谱：频率 ω_n = n·2π/T（n = 1, 2, …） | 连续谱：频率 ω 连续变化 |
| 频率的权重 | 振幅 A_n = √(a_n² + b_n²)（式 7.103c） | 谱密度 g(ω)（式 7.113c 或 7.115a，两种约定） |
| 间断点行为 | 级数取中值 ½[f(x−0)+f(x+0)] | 积分取中值（式 7.113b），规则相同 |
| 极限关系 | l → ∞ 时 (−l, l) 上的展开过渡为傅里叶积分 | — |
| 最佳性类比 | 傅里叶系数使均方误差最小（式 7.105） | （手册本节未展开；见 19.6，未入库） |
| 算例 | 方波：y = 1 + (4/π)(cos θ − cos 3θ/3 + ⋯)（式 7.116b） | e^{−\|x\|} = (2/π)∫₀^∞ cos ωx/(ω²+1) dω（式 7.115b） |

## 结构观察

- **离散 → 连续**：周期的「时间窗」无限扩大时，相邻谱线间距 2π/T → 0，求和密化为积分；系数 a_k、b_k（或复系数 c_k）的角色由谱密度 g(ω) 接替，见 [[concepts/谱密度]] 与 [[concepts/傅里叶级数的复形式]]。
- **收敛条件平行**：两者都以狄利克雷条件为逐点收敛的充分条件，且间断点都取中值；傅里叶积分额外要求绝对可积。
- **能量/功率类比**：级数有帕塞瓦尔方程（式 7.106b）；积分情形的对应恒等式手册本节未给出（属 19.6 范围，未入库）。
