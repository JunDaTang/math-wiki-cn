# 群同态定理与环同态定理比较

数学手册 5.3.7.3.2 明示两个同态定理的派生关系：「如果在群同态定理中用理想的概念代替正规子群的概念，那么就可得到环同态定理」。

| | 群同态定理（5.3.3） | 环同态定理（5.3.7.3） |
|---|---|---|
| 结构层次 | 群（一个二元运算） | 环（$+$ 与 $*$ 两个二元运算） |
| 同态条件 | 保持群运算 | 同时保持两个运算（式 5.175） |
| 核 | 正规子群 $\ker h$ | 理想 $\ker h = \{a \mid h(a) = 0\}$（式 5.176） |
| 商结构 | 商群 $G/N$，元素为陪集 $gN$ | 商环 $R/I$，元素为**加群**陪集 $a + I$（式 5.177） |
| 定理结论 | $G/\ker h \cong h(G)$ | $R_1/\ker h \cong h(R_1)$ |
| 反向构造 | 每个正规子群给出自然同态 | 每个理想给出 $\mathrm{nat}_I(a) = a + I$ |
| 入库实例 | $\mathrm{GL}(n)/\mathrm{SL}(n) \cong \mathbb{R} \setminus \{0\}$ | $\mathbb{Z}_m = \mathbb{Z}/(m)$（剩余类环） |

## 结构差异的根源

环比群多一个乘法运算，故核不仅是加法子群，还须对环中任意元素的左乘与右乘封闭——这正是**理想**（对 $r * a$、$a * r$ 封闭的特殊子环）取代正规子群的原因；商环的陪集取自加群 $(R, +)$（源引 452 页 5.3.3），乘法的良定义性由理想保证。
