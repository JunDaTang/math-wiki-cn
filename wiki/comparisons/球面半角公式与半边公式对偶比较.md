# 球面半角公式与半边公式对偶比较

《数学手册(原书第10版)》3.4.2.2 的半角公式（式 3.192–3.193）与半边公式（式 3.194–3.195）呈严格的结构对偶：

| 维度 | 半角公式（3.192–3.193） | 半边公式（3.194–3.195） |
|---|---|---|
| 功能 | 由三边求角 | 由三角求边 |
| 未知量出现在 | tan(角/2) | cot(边/2) |
| 辅助半和量 | s = (a+b+c)/2（边和之半） | σ = (α+β+γ)/2（角和之半） |
| 核心三角函数 | sin(s−·) | cos(σ−·) |
| 形式二的辅助量 | k = √[sin(s−a)sin(s−b)sin(s−c)/sin s] | k′ = √[cos(σ−α)cos(σ−β)cos(σ−γ)/(−cos σ)] |
| 实根保证 | 手册未单独说明 | 手册断言「鉴于对欧拉三角形的要求，所有的根都是实数」，且式 3.196 给出 cos σ < 0 恒真 |
| 形式二的用途说明 | 手册明言（3.193 引言）在要从三边确定全部三个角时有用 | 两形式以「或」并列，未作同样的说明 |
| 平面对应 | 平面半角公式（[[findings/半角公式与附加关系]]） | 无（平面三角形不能由角定边，见 [[findings/平面三角形边不可仅由角得到]]） |

## 读法

对应规则为：边 ↔ 角（a↔α 等）、s ↔ σ、tan(x/2) ↔ cot(x/2)、sin ↔ cos，且分母中的 sin s 在半边侧变为 −cos σ（负号由式 3.196 的不等式吸收）。两族公式同具「平方根紧凑式（形式一）+ 辅助量除式（形式二）」的双重结构。

## 说明

这一「边↔角互换」的对应是公式表面结构的直接观察；手册本节未给出极三角形之类的深层解释（该内容属未入库的 3.4.1 及以远），故此处不展开推导来源。
