# 哈尔小波与墨西哥草帽小波比较

**比较依据**：数学手册 15.5.2 的两个小波例子（图 15.28(a)/(b)）及其在 15.5.3–15.5.4 中的使用。

| 维度 | 哈尔小波 (15.144) | 墨西哥草帽小波 (15.145)–(15.146) |
|---|---|---|
| 定义 | [0,1] 上取 +1/−1 的分段常值函数 | −d²/dx² e^{−x²/2} = (1−x²)e^{−x²/2} |
| 光滑性 | 不连续（跳变） | 光滑（解析） |
| 阶 n | 1（μ₁ = −1/4 ≠ 0，已复算） | 2（偶函数 ⟹ μ₁ = 0，μ₂ = −2√(2π) ≠ 0，已复算） |
| 支撑 | 紧支撑 [0,1] | 非紧支撑，指数衰减 |
| 与多项式正交范围 | 次数 ⩽ 0（常数） | 次数 ⩽ 1（线性） |
| 源内正交性断言 | 无（二进族正交为外部事实） | 无 |
| 在源中的使用 | 连续变换算例 (15.153) + 离散哈尔变换 (15.155)–(15.156) | 仅作为阶 n=2 的例证 |

**共性与分工**：两者都满足均值零 (15.148)；手册以哈尔演示可计算性（均值差解释、离散递推），以墨西哥草帽演示光滑小波与偶函数定阶。**注意**：[[concepts/多贝西小波]] 的「正交 + 紧支撑 + 无闭式」断言不可套用于两者中任何一个。
