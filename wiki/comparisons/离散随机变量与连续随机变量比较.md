# 离散随机变量与连续随机变量比较

《数学手册》16.2.2 在分布函数、期望、方差等处均以「a) 离散情形 / b) 连续情形」双轨展开，两轨对照如下：

| 维度 | 离散随机变量 | 连续随机变量 |
|---|---|---|
| 取值集 | 有限或可数多个不同的值 $x_1, x_2, \dots$ | 全体实数或包含一些子区间 |
| 概率刻画 | 点概率 $P(X=x_i)=p_i$ | [[concepts/密度函数（概率密度）]] $f(x)\geqslant 0$ |
| 单点概率 | 可为正 | 恒为 0，只需考虑区间概率（式 16.46） |
| 分布函数 | 阶梯函数：$F(x)=\sum_{x_i\leqslant x} p_i$（16.45） | 处处连续：$F(x)=\int_{-\infty}^{x} f(t)\,\mathrm{d}t$（16.47） |
| 期望 $E(g(X))$ | $\sum_k g(x_k)p_k$，级数绝对收敛（16.49a） | $\int_{-\infty}^{+\infty} g(x)f(x)\,\mathrm{d}x$，绝对可积（16.49b） |
| 期望 $\mu_X$ | $\sum_k x_kp_k$（16.50a） | $\int_{-\infty}^{+\infty} xf(x)\,\mathrm{d}x$（16.50a） |
| 方差 $\sigma_X^2$ | $\sum_k (x_k-\mu_X)^2p_k$（16.52） | $\int_{-\infty}^{+\infty} (x-\mu_X)^2f(x)\,\mathrm{d}x$（16.52） |
| 典型例 | 例 A：基本事件 $A_{11},A_{12},A_{21},A_{22}$ 取值 1–4 | 例 B：灯泡寿命 $T$；[[concepts/均匀分布]]（连续） |

## 共同点

- 两轨共享：[[concepts/分布函数]] 的定义 (16.44) 与三条性质；仿射性质 $E(aX+b)=a\mu_X+b$（16.50b）与 $D^2(aX+b)=a^2D^2(X)$（16.53）；关系式 $D^2(X)=E(X^2)-\mu_X^2$；[[concepts/切比雪夫不等式]]（16.58，不依赖分布形态）。
- 期望的解释差异：离散情形是加权平均（16.54），均匀时退化为算术平均（16.55）；连续情形是密度曲线 [与 x 轴] 围成图形重心的横坐标（措辞待核，见 [[queries/面积解释句疑脱与x轴]]）。
