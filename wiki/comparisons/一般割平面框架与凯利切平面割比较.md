# 一般割平面框架与凯利切平面割比较

18.2.9 分两层陈述同一方法族：第 1 部分「问题的提法和求解原理」给出一般分离框架，第 2 部分「凯利方法」给出具体的割选取。二者常被统称「割平面法」，但手册所给证据的归属边界不同，须分开评价。

| 维度 | 一般分离框架（第 1 部分） | 凯利切平面割（第 2 部分） |
|---|---|---|
| 割的选取 | 未指定：任何把 LP 最优点与 $M$ 分离且保留 $M$ 的超平面（以 $H_1$、半空间 $\underline{\boldsymbol{a}}_{s+1}^{\mathrm T}\underline{\boldsymbol{x}}\leqslant b_{s+1}$ 为例，式 18.122） | 唯一指定：最严重违反约束（式 18.123）在当前点的切平面（式 18.124） |
| 所需信息 | 未限定 | 当前点处各约束函数值与最严重违反约束的梯度 $\nabla g_{j_k}(\underline{\boldsymbol{x}}^k)$ |
| 割保留 $M$ 的保证 | 需作为选取前提 | 由凸性自动保证（切平面为下方逼近） |
| 收敛性论断 | 无 | 有：序列每个聚点都是原问题极小点（陈述级，未给证明） |
| 实用评价 | 无 | 收敛速度较低；约束数量总是不断增加 |
| 转录完整性 | 缺「$M\subseteq P_1$」及分离对象、包含对象的表述 | 相对完整，仅「点竺」等零星讹误 |

## 要点

1. **自由度与保证的交换**：一般框架把割选取留白，只要求分离性；凯利规则把选取具体化为可计算的切平面，并因此获得凸性带来的自动有效性（复算见 [[findings/式18-123至18-124凯利割平面构造复算]]）。
2. **证据归属**：收敛性与缺点论断是手册对凯利方法的评价，不可外推到一般框架——任意割选取下的一般收敛性本节未讨论。
3. **层次关系**：一般框架是 [[concepts/外逼近多面体序列]] 的抽象骨架，凯利方法是其实例化之一；切平面即一阶泰勒线性化，与 18.2.5 各无约束方法对梯度信息的利用相通。
4. **共同前提**：二者都要求可行域凸、$M$ 有界，且目标线性（或经 [[concepts/目标函数线性化变换]] 化为线性）。
