# 黎曼方法与格林方法比较

手册 9.2.2.3.4 末尾自陈两法的同异（原文立场），结合结构对照：

| 维度 | [[黎曼方法]] | [[格林函数与格林方法]] |
|---|---|---|
| 适用问题 | 双曲型柯西问题（式 9.97a） | 椭圆型边值问题（式 9.99a / 9.100a） |
| 辅助函数 | 黎曼函数 v(x, y; ξ, η) | 格林函数 G(x, y; ξ, η) |
| 满足的方程 | 齐次伴随方程 (9.97b) | 除极点外满足齐次伴随方程 (9.99b / 9.100b) |
| 附加条件 | 两条特征线上取规定值 (9.97c) | 奇性部分 U ln(1/r) + V（或 U/r + V）+ 边界条件 |
| 依赖对象 | **仅依赖微分方程左端的形式**（原文） | **还依赖所考虑的区域**（原文） |
| 表示公式 | 黎曼公式 (9.97f/g)（符号结构存疑） | (9.99e/g)、(9.100e)（内法向约定） |
| 显式算例 | [[电报方程]]（黎曼函数 I₀） | 圆盘与球（[[泊松积分]]） |
| 实践地位 | 电报方程等可显式构造 | 求格林函数特别困难，主要用于理论研究（原文） |

**共同想法**（原文）：首先确定微分方程的一个特解型辅助函数，然后用它得到具有任意边界条件的解。

两法的共同数学支柱是 [[伴随微分方程]]；本 wiki 的复算记录分别为 [[findings/式9-97黎曼方法独立推导与符号核对]] 与 [[findings/式9-99至9-100格林方法条件组转录]]、[[findings/式9-101至9-102圆盘与球格林函数复算]]。
