# 积分次序交换正反两例比较（正例 $x^y$ 与反例 $(y^2-x^2)/(x^2+y^2)^2$）

两算例同出 8.2.4.3，用以展示式 8.94（[[concepts/积分符号下的积分]]）连续性条件的正反两面。转录与复算细节见 [[findings/式8-94积分次序交换与AB两算例复算]]。

| 维度 | 算例 A（正例） | 算例 B（反例） |
|---|---|---|
| 函数 | $f(x,y)=x^y$ | $f(x,y)=\dfrac{y^2-x^2}{(x^2+y^2)^2}$ |
| 矩形 | $0\leqslant x\leqslant 1,\ a\leqslant y\leqslant b$ | $0\leqslant x\leqslant 1,\ 0\leqslant y\leqslant 1$ |
| 麻烦点 | $(0,0)$（$0^0$ 型）——以 $a>0$ 收缩矩形避开 | $(0,0)$——被矩形包含，无法避开 |
| 连续性 | $a>0$ 时在闭矩形上连续 → 式 8.94 适用 | 在 $(0,0)$ 不连续 → 式 8.94 不适用 |
| 先 $x$ 后 $y$ | $\int_a^b\frac{\mathrm{d}y}{1+y} = \ln\frac{1+b}{1+a}$ | $\int_0^1\frac{\mathrm{d}y}{1+y^2} = \frac{\pi}{4}$ |
| 先 $y$ 后 $x$ | $\int_0^1\frac{x^b-x^a}{\ln x}\,\mathrm{d}x$（被积函数非初等） | $-\int_0^1\frac{\mathrm{d}x}{1+x^2} = -\frac{\pi}{4}$ |
| 换序结论 | 相等：$\int_0^1\frac{x^b-x^a}{\ln x}\mathrm{d}x = \ln\frac{1+b}{1+a}$（$0<a<b$） | 不相等：$+\frac{\pi}{4} \neq -\frac{\pi}{4}$，符号相反 |
| 教训 | 收缩定义域救活定理；非初等定积分获得初等值 | 单点不连续即可倾覆结论；条件核查必须逐点 |

## 共同点与差异要点

- 两例的麻烦都在角点 $(0,0)$，差别只在**矩形是否包含它**：A 以 $a>0$ 将其排除，B 的矩形含它。
- A 展示换序的收益（难侧的非初等定积分由易侧确定）；B 展示条件的代价（结论可翻转至符号相反）。
- 两例结论各自绑定其函数与条件，不可互换：不能由 B 推广「$x^y$ 不可换序」，也不能由 A 推广「换序总可行」。条件判定流程见 [[methodology/含参积分运算选择流程]]。
