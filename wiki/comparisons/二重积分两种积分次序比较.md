# 二重积分两种积分次序比较

《数学手册(原书第10版)》8.4.1.2.1 以同一算例演示二重积分的两种积分次序：**先 $y$ 后 $x$**（式 8.136a，图 8.32(a)，先沿小矩形垂直边、再沿水平边求和）与**先 $x$ 后 $y$**（式 8.136c，图 8.32(b)，逆向进行）。算例：$A=\int_S xy^2\,\mathrm{d}S$，$S$ 为抛物线 $y=x^2$ 与直线 $y=2x$ 围成的区域（图 8.33）。

## 逐项对照

| | 先 $y$ 后 $x$（式 8.136a） | 先 $x$ 后 $y$（式 8.136c） |
|---|---|---|
| 外层变量与积分限 | $x$: $0\to 2$（常数） | $y$: $0\to 4$（常数） |
| 内层积分限 | $y$: $x^2\to 2x$ | $x$: $y/2\to\sqrt y$ |
| 边界曲线的角色 | $y=x^2$ 为下界、$y=2x$ 为上界 | 同一对曲线反解为 $x=y/2$、$x=\sqrt y$ |
| 关键中间步 | $\int_0^2 x\,\mathrm{d}x\,[y^3/3]$ | $\int_0^4 y^2\,\mathrm{d}y\,[x^2/2]$ |
| 最终一元积分 | $\frac13\int_0^2(8x^4-x^7)\,\mathrm{d}x$ | $\frac12\int_0^4 y^2\left(y-\frac{y^2}{4}\right)\mathrm{d}y$ |
| 结果 | $32/5$ | $32/5$ |

## 结论与要点

1. **两序结果相同**：被积函数连续、区域正规（由两条连续曲线围成、$\varphi_1\le\varphi_2$）时换序合法，本例两序均得 $32/5$（已复算，[[findings/式8-136累次积分两序与抛物线围域算例复算]]）。
2. **外层限必为常数、内层限只含外侧变量**：换序时须把边界函数反解（$\varphi\leftrightarrow\psi$），区域的描述方式随之整体改变。
3. **两序难度可能不同**：内层原函数与最终一元积分的复杂度随次序变化，这是次序选择的实操依据（[[methodology/多重积分坐标系与积分次序选择流程]] 第五步）。
4. **与含参积分换序的区别**：本条换序只需连续性 + 区域正规；[[concepts/积分符号下的积分]]（8.2.4，式 8.94）的换序对象是含参变量积分，需一致收敛型条件。
5. 转写注记：第二序中间步骤外层限误作 $\int_0^2$（应为 $\int_0^4$），见 [[queries/算例二外层积分限是0到2还是0到4]]。
