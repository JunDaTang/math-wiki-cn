# 悬链线与曳物线比较

手册 2.15 将 [[concepts/悬链线]]（2.15.1，式 2.252）与 [[concepts/曳物线]]（2.15.2，式 2.253）作为一对由[[concepts/渐屈线与渐伸线]]对偶联结的特殊曲线并列给出。二者共用点 $A(0,a)$ 与参数 $a$，但几何行为几乎处处相反。

## 对照表

| 项目 | 悬链线（2.15.1） | 曳物线（2.15.2） |
|---|---|---|
| 生成方式 | 均匀柔韧不可伸粗链两端悬挂 | 长 a 不可伸绳一端系质点、另一端沿 x 轴拖拽 |
| 方程 | $y = a\cosh\frac{x}{a}$（式 2.252） | $x = \pm\bigl(a\,\mathrm{Arcosh}\frac{a}{y} - \sqrt{a^2-y^2}\bigr)$（式 2.253 的重建形式） |
| 所用双曲函数 | cosh / sinh（指数式亦给出） | Arcosh / ln |
| 特殊点 | 顶点 $A(0,a)$ | 尖点 $A(0,a)$ |
| 对称性 | 关于 y 轴 | 关于 y 轴 |
| 渐近线 | 无（指数增长，无直线渐近线） | x 轴 |
| 弧长 $\widehat{AP}$ | $L = a\sinh\frac{x}{a}$ | $L = a\ln\frac{a}{y}$ |
| 面积 | $S = aL = a^2\sinh\frac{x}{a}$ | 手册未给 |
| 曲率半径 | $r = \frac{y^2}{a} = a\cosh^2\frac{x}{a} = a+\frac{L^2}{a}$；随 $y$ 增大，顶点处最小（$r=a$） | 重建 $r = a\frac{\sqrt{a^2-y^2}}{y}$；尖点处 $\to 0$、沿渐近线 $\to\infty$（原文 $a\cot\frac{x}{y}$ 辐角疑误） |
| 极限性质 | — | $L - x \to a(1-\ln 2) \approx 0.307a$ |
| 渐屈线/渐伸线 | 是曳物线的渐屈线；自顶点 A 展开的渐伸线为曳物线 | 渐屈线为悬链线 (2.252)；是悬链线（自顶点 A 展开）的渐伸线 |

## 关键观察

1. **共用 $A(0,a)$**：悬链线的顶点即曳物线的尖点，也是渐伸线展开的起始点——对偶关系的锚点。
2. **两条 r 公式方向相反且不可互转**：悬链线 $r = \frac{y^2}{a}$（$y \geq a$，为其自身纵坐标）随纵坐标增大而增大；曳物线 $r = a\frac{\sqrt{a^2-y^2}}{y}$（$0 < y \leq a$，为其自身纵坐标）在尖点处趋于 0、沿渐近线趋于无穷。两式同用 $a$、$y$ 记号但所指不同。
3. **对偶是成对而非对称的**：「悬链线是曳物线的渐屈线」与「曳物线是自顶点展开的悬链线之渐伸线」是同一事实的两种说法；反方向不成立。见 [[findings/曳物线的渐屈线是悬链线]]。
4. **函数视角互补**：悬链线是 [[concepts/双曲余弦函数]] 的图像（[[concepts/双曲函数]]，2.9）；曳物线方程以 [[concepts/面积余弦函数]]（Arcosh，2.10 记号）表出——一条用双曲函数，一条用其反函数。
