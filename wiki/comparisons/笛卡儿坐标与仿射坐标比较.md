# 笛卡儿坐标与仿射坐标比较

源文 3.5.1.3(2) 明言「仿射是笛卡儿坐标的一般化」。两者的系统差异如下（式号均为 3.5.1 节内）：

| 维度 | 笛卡儿坐标 | 仿射坐标 |
|---|---|---|
| 基向量 | $\vec i,\vec j,\vec k$（规范正交，式 3.235–3.236） | $\vec e_1,\vec e_2,\vec e_3$（线性无关、不必正交） |
| 坐标记号 | 下标 $a_x,a_y,a_z$（式 3.240） | 上标 $a^{1},a^{2},a^{3}$，**上标不是指数**（式 3.244） |
| 线性组合坐标 | 逐分量（式 3.241） | 逐分量（式 3.245）——线性律不依赖正交性 |
| 和与差 | 逐分量（式 3.242） | 逐分量（式 3.246） |
| 方向系数=坐标 | 成立（3.247 后断言） | 通常不成立 |
| 标量积 | $a_xb_x+a_yb_y+a_zb_z$（3.264） | $g_{\alpha\beta}a^{\alpha}b^{\beta}$，需六个度量系数（3.270/3.273） |
| 向量积 | 基向量行列式（3.265） | 需互反基向量与 $\varOmega$（3.271/3.275） |
| 混合积 | 坐标行列式（3.266） | 坐标行列式 × $\vec e_1\vec e_2\vec e_3$（3.276） |
| 共变 vs 反变 | 一致（3.281） | 一般不一致（3.277/3.278） |

**退化通道**（3.272a–c）：当仿射基取为 $\vec i,\vec j,\vec k$ 时，$g_{mn}$ 退化为单位阵、$\varOmega=1$、基向量组自互反（表 3.15/3.16），于是 3.273→3.264、3.275→3.265、3.276→3.266。笛卡儿公式因此可作仿射计算的自检基准：一套仿射实现若在正交基上不退化为笛卡儿公式，即有错误（见 [[methodology/仿射坐标系下向量乘积计算流程]]）。

**分界线**：坐标的线性运算（和、差、数乘、线性组合）在两系中形式相同，而**乘积**运算在两系中形式不同——分界正在于基向量的两两乘积是否退化（对角为 1、非对角为 0 的特殊值 vs 一般的 $g_{mn}$）。
