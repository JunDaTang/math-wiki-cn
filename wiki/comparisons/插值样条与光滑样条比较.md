# 插值样条与光滑样条比较

三次插值样条（19.7.1.1）与三次光滑样条（19.7.1.2）的比较：二者是同一 λ 谱系的两端，λ=0 时光滑样条退化为插值样条。

| 维度 | 三次插值样条 | 三次光滑样条 |
|---|---|---|
| 数据假设 | f_i 精确 | f_i 为含误差的测量值（σ_i 为误差标准差） |
| 数学刻画 | 四性质（插值条件 + 分段次数 ⩽ 3 + C² + 边界条件），唯一确定 | 罚化最小二乘 (19.242)：Σ[(f_i−S(x_i))/σ_i]² + λ∫[S″]²dx = min，保持 S、S′、S″ 连续 |
| 待选参数 | 边界条件类型（自然/端点导数给定/周期） | 光滑参数 λ（可机屏对话选取）与 σ_i |
| 求解 | 三对角方程组 (19.240)/(19.241)，LR 分解 | 带方程形式条件的约束最优化，拉格朗日函数；细节外推文献 [19.34][19.35] |
| 变分意义 | 自然样条最小全曲率（霍拉迪定理） | 目标泛函含同一曲率罚项 ∫[S″]²dx |
| 谱系位置 | λ = 0 的退化终点 | λ 很大 → 光滑但不贴数据；λ = ∞ → 逼近回归线 |

## 要点

- λ = ∞ 的「回归线」为极限陈述：严格说 λ→∞ 时趋于加权最小二乘直线，原书措辞偏松（见 [[findings/式19-242至19-243光滑样条与B样条基转录]]）。
- 光滑样条可视为 19.6.2 加权最小二乘族（[[concepts/线性最小二乘问题]]、[[concepts/权函数与加权内积]]）与霍拉迪变分泛函的组合。
- 二维对照：双三次插值样条有完整系数确定流程，而二维光滑样条「仅有很少特殊情况可能存在唯一解」（原书 caveat）。
