# 正割与余割比较

依据 [[sources/10-数学手册原书第10版--10-27-三角函数角函数--a2ypwy]]（式 2.70–2.71），sec 与 csc 的图像要素对照如下：

| 性质 | $\sec x$（式 2.70） | $\csc x$（式 2.71） |
|---|---|---|
| 定义 | $\frac{1}{\cos x}$ | $\frac{1}{\sin x}$ |
| 相互关系 | 基准函数 | csc 图像由 sec 向右平移 $\frac{\pi}{2}$ 得到（$\csc x=\sec\left(x-\frac{\pi}{2}\right)$，已验证） |
| 周期 | $2\pi$ | $2\pi$ |
| 值域 | $\lvert y\rvert\ge 1$ | $\lvert y\rvert\ge 1$ |
| 渐近线 | $x=\left(k+\frac{1}{2}\right)\pi$（cos 零点） | $x=k\pi$（sin 零点） |
| 局部极大值点 | $A_k=((2k+1)\pi,-1)$ | $A_k=\left(\frac{4k+3}{2}\pi,-1\right)$ |
| 局部极小值点 | $B_k=(2k\pi,+1)$ | $B_k=\left(\frac{4k+1}{2}\pi,+1\right)$ |
| 与 x 轴交点 | 无 | 无 |

## 要点

- 两者均无零点、值域分为 $y\ge1$ 与 $y\le-1$ 两支，故均呈现「**局部极大值 −1 < 局部极小值 +1**」现象——局部极大在负支顶部、局部极小在正支底部取得。该现象专属 sec/csc，不可迁移到其他三角函数。
- 渐近线分别继承自分母的零点：sec 在 cos 零点处，csc 在 sin 零点处。
- 极值点横坐标互相错位 $\frac{\pi}{2}$（与平移关系一致）：如 $\sec$ 的局部极小 $B_0=(0,+1)$ 对应 $\csc$ 的局部极小 $B_0=\left(\frac{\pi}{2},+1\right)$。
- 完整公式与验证见 [[findings/正割与余割的局部极值点与平移关系]]。
