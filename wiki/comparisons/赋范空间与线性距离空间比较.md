# 赋范空间与线性距离空间比较

本源 12.3.1 在两种结构之间建立了单向导出关系与反向判据（反向句转录有讹误，见 [[queries/12-3全节系统性转写讹误清单]] 第 3 项）。

| 方面 | 线性距离空间 | 赋范空间 |
|---|---|---|
| 结构 | 向量空间 + 任意距离 ρ | 向量空间 + 范数 ‖·‖（N1–N3） |
| 距离性质 | 无附加要求 | 诱导距离 ρ(x,y) = ‖x−y‖ 自动满足平移不变 (12.82a) 与正齐次 (12.82b) |
| 反向判据 | 距离满足 (12.82a)(12.82b) 时可赋范：‖x‖ = ρ(x,0)（转录误作 ‖x−y‖ = ρ(x,0)，编者更正） | — |
| 局部研究 | 一般无单位结构 | 一切球由单位球平移伸缩生成：B(x;r) = x + rB(0;1)（12.84） |
| 运算连续性 | 不保证 | 自动成立（12.85） |
| 收敛刻画 | ρ(xₙ, x) → 0 | ‖xₙ − x‖ → 0（12.86） |
| 有限维刚性 | 无对应陈述 | 所 有范数彼此等价（12.3.1.2 定理） |
| 同构概念 | 等距同构 | 范数同构（双射线性 + 保范） |

## 编者注记

- 赋范空间是线性距离空间的特例（附加齐性）；可赋范性判据即 (12.82a)(12.82b)，本源以「可赋范的」一词提及。
- 有限维范数等价定理使 ℓᵖ(n) 的各 p 范数拓扑相同（该推论为编者注记），这是 [[methodology/求积半离散化方法]] 中 𝔽ⁿ 离散系统的理论背景（推断）。
