# 一元线性回归与多元回归比较

16.3.4 以一元线性回归（16.3.4.2）与多元回归（16.3.4.3）两步展开回归分析，后者是前者的矩阵化推广。

| 维度 | 一元线性回归 | 多元回归 |
|---|---|---|
| 模型 | $E(Y)=a+bx$（16.155），对 x 线性 | $y=\sum_{j=0}^{s}a_j g_j(\underline{\boldsymbol{x}})$（16.160），对系数线性、$g_j$ 任意 |
| 「线性」含义 | 对 x 与系数均线性 | 仅对系数线性（完全二次多项式亦属线性回归） |
| 误差假设 | 对定值 x，Y 正态、方差 $\sigma^2$ 不变 | 未重述正态性，仅言「由于随机测量存在误差」 |
| 数据 | $(x_i,y_i)$，$i=1,\dots,n$（n 为样本容量） | $(\underline{\boldsymbol{x}}^{(i)},f_i)$，$i=1,\dots,N$（N 为测量次数，n 为自变量个数——记号有别） |
| 最小二乘 | (16.156) | (16.163c) |
| 求解 | 闭式 (16.157a) | [[concepts/正则方程组（法方程）]] $G^TG\widetilde{\boldsymbol{a}}=G^T\boldsymbol{f}$（16.163e），用 [[concepts/楚列斯基方法]] 或 [[concepts/豪斯霍尔德法]] |
| 推断 | t 分布置信区间 (16.158a,b)、(16.159a,b) | F 分布置信区间；[[concepts/等价检验]] 判断较少项模型是否充分 |
| 方差估计 | $\widetilde{\sigma}^2=\frac{n-1}{n-2}s_y^2(1-r_{xy}^2)$ | 由 (16.163c) 的残差平方和给出（原文未写显式公式） |

## 特例关系

取 $s=1$、$g_0=1$、$g_1=x_1$，多元回归即化为一元线性回归的矩阵形式：$G$ 的两列分别为全 1 列与 $(x_i)$ 列，正则方程组等价于 (16.156) 求偏导所得的正规方程（复算见 [[findings/式16-155至16-159b线性回归与置信区间转录复算]] 与 [[findings/式16-160至16-163e多元回归与正则方程组转录复算]]）。
