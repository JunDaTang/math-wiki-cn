# 二维与三维图形选项比较

《数学手册（原书第10版）》以表 20.16（2D）与表 20.17（3D）分别列举图形选项，并明确二者的适用关系：「3D 图形选项的数目庞大。表 20.17 中仅列举了少数几个，其中已知的 2D 图形选项没有包括在内。它们可以在类似的意义下被应用。」

## 对照表

| 维度 | 二维（表 20.16） | 三维（表 20.17） |
|---|---|---|
| 高宽比/视角 | `AspectRatio -> w`（默认 1:GoldenRatio；Automatic 由绝对坐标确定） | 无 AspectRatio 条目；代之以 **ViewPoint**：指定观察点 (x, y, z)，默认 `{1.3, -2.4, 2}`，「特别重要」，可选取非常不同的观察视角 |
| 坐标轴与框 | `Axes -> True/False/{True, False}`、`Frame -> True` | `Boxed`：默认 True，描绘环绕曲面的三维框 |
| 网格与刻度 | `GridLines -> Automatic`、`Ticks -> Automatic` 或显式节点列表 | 未列出（2D 对应项「类似意义下」可用） |
| 轴标注 | `AxesLabel -> {x_symbol, y_symbol}` | 未列出（同上） |
| 曲面外观 | — | `HiddenSurface`（不透明度，默认 True）、`Shading`（默认 True 加阴影；False 得白色曲面）——均为 pre-v6 遗留选项 |
| 值域 | PlotRange 未入表 20.16 | `PlotRange`：可取 All、{za, ze} 或 {{xa, xe}, {ya, ye}, {za, ze}}，默认 Automatic——即 3D 可按**三轴**分别限定 |

## 语义要点

- 二维选项在三 维中「类似的意义下被应用」，故 20.4.7.1 抛物面例直接使用 `PlotRange -> {0, 25}` 限定 z 值（「这个立体是在 z = 25 时切割的」，[[式20-46至20-49a三维绘图复算]]）。
- ViewPoint 是 3D 特有的观察手段，其默认值 `{1.3, -2.4, 2}` 具版本依赖性；HiddenSurface/Shading 与 GraphicsRow 等 v6+ 特征并存于本节，版本基线问题见 [[GraphicsArray与GraphicsRow比较]]。
- 2D 的 AspectRatio 默认 1:GoldenRatio 在 3D 情形由三维盒与 ViewPoint 共同决定视觉比例，故表 20.17 不再列 AspectRatio。
