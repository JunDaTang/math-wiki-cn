# 中心投影与平行投影比较

依据 [[sources/10-数学手册原书第10版--8-355-平面投影--yid4ap|数学手册(原书第10版) 3.5.5.1 与 3.5.5.7]]，平面投影二分如下：

| 比较维度 | 中心投影（透视投影） | 平行投影 |
|---|---|---|
| 投影线几何 | 从一个公共中心点发出（图 3.210） | 相互平行（图 3.211） |
| 远近物体的像 | 距中心较远的物体成像较小 | 不因远近改变 |
| 不平行于画面的平行线 | 不再平行，相交于 [[concepts/没影点|没影点]] | 保持平行 |
| 度量性质 | 长度和角度之间的关系不再保持 | 不平行于画面的线段变短，角通常被扭曲 |
| 尺寸比例 | 一般不保持 | 有时保持 |
| 视觉效果 | 给出物体的实际印象 | 似乎不如透视表示真实 |
| 映射的数学性质 | 非线性；经 [[concepts/齐次坐标|齐次坐标]]化为 $4\times4$ 线性矩阵（式 3.481） | 线性，直接写成 $4\times4$ 矩阵（式 3.474–3.480） |
| 子类 | 按主点个数分一点、两点、三点透视（图 3.218） | 正交（[[concepts/正投影|正投影]]、[[concepts/轴测投影|轴测投影]]）与 [[concepts/斜投影|斜投影]]（斜等轴测、斜角立体） |

## 归属注意

“线段变短”的总述与斜等轴测投影（$d=1$，垂直线段不变短）存在表述张力：垂直于画面线段的缩放由 $d=1/\tan\beta$ 控制，总述应理解为限于正交投影或需加“通常”限定。相关验证见 [[findings/斜平行投影公式与立方体两算例]]、[[findings/透视投影齐次坐标矩阵]]。
