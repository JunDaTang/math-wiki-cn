# 分离变量法五算例比较

手册 9.2.2.3.1 的五个算例沿同一流程（[[分离变量法解题流程]]）展开，差异集中在边界条件类型与所得本征函数系：

| 算例 | 方程与类型 | 边界条件 | 本征函数系（谱型） | 系数公式要点 |
|---|---|---|---|---|
| A 弦振动 (9.92) | u_tt = a²u_xx，双曲 | x = 0, l 双端 Dirichlet | sin(nπx/l)，n ≥ 1，离散 | a_n = (2/l)∫f sin；b_n 含因子 1/(naπ) |
| B 棒纵向振动 (9.93) | 同方程，边界非齐次 → 齐次化后方程非齐次 | x = 0 Neumann 齐次；x = l Neumann 非齐次 | cos(nπx/l)，n ≥ 0，离散（含 n = 0） | 余弦系数；n = 0 项给 (aπ/l)b₀t；n ≥ 1 项含 bₙ/n 因子 |
| C 圆膜振动 (9.94) | 极坐标波动方程，双曲 | ρ = R Dirichlet + φ 周期 + ρ = 0 有界 | Jₙ(μ_nk ρ/R)，带权 ρ，二重指标 (n, k) | 2/(πR²J²_{n−1}(μ_nk))；n = 0 时分子 2 改为 1 |
| D 矩形狄利克雷 (9.95) | Δu = 0，椭圆 | 四边取给定值（拆两个半问题叠加） | sin(nπx/a) × sinh 组合，离散 | 2/(a·sinh(nπb/a)) |
| E 半无限杆热传导 (9.96) | u_t = a²u_xx，抛物 | x = 0 Dirichlet + 无穷远趋零 | sin λx，λ ∈ (0, ∞) 连续 | C(λ) = (2/π)∫f sin（傅里叶正弦积分） |

**共性**：谱的离散/连续由区域有界性决定（E 例连续谱是关键分野）；B 例先做 [[非齐次边值问题齐次化代换]]，D 例靠 [[叠加原理与分解定理]] 合成两半问题；所有解均为需验证收敛与可微性的形式解；C 例的径向本征值问题是带权 ρ 的奇异 [[斯图姆-刘维尔问题]]。
