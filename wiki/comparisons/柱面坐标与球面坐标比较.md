# 柱面坐标与球面坐标比较

《数学手册(原书第10版)》8.4.2.2.2–8.4.2.2.3 并列给出三重积分在柱面坐标（式 8.144a–b，图 8.40）与球面坐标（式 8.145a–b，图 8.42）下的计算法，并明示两者都是任意曲线坐标一般式 8.147b 的特殊情况。两者的系统对照如下。

## 逐项对照

| | 柱面坐标 $(\rho,\varphi,z)$ | 球面坐标 $(r,\varphi,\vartheta)$ |
|---|---|---|
| 坐标含义 | $\rho$ 到 $z$ 轴距离、$\varphi$ 方位角、$z$ 高度 | $r$ 到原点距离、$\varphi$ 方位角、$\vartheta$ 极角（自 $z$ 轴量起） |
| 体积微元 | $\mathrm{d}V=\rho\,\mathrm{d}z\,\mathrm{d}\rho\,\mathrm{d}\varphi$（式 8.144a） | $\mathrm{d}V=r^2\sin\vartheta\,\mathrm{d}r\,\mathrm{d}\vartheta\,\mathrm{d}\varphi$（式 8.145a） |
| 雅可比 $D$ | $\rho$ | $r^2\sin\vartheta$ |
| 坐标曲面 | 同心圆柱面、过 $z$ 轴的半平面、水平面 | 同心球面、过 $z$ 轴的半平面、锥面 |
| 适用区域 | 侧面为圆柱面（$x^2+y^2=ax$ 型）、旋转体 | 球心在原点的球面、以原点为顶点的锥面 |
| 书中算例 | $xOy$ 面、$zOx$ 面、柱面 $x^2+y^2=ax$ 与球面 $x^2+y^2+z^2=a^2$ 围域：$\int\mathrm{d}V=\frac{a^3}{18}(3\pi-4)$ | 顶点原点、$z$ 轴对称、顶角 $2\alpha$、高 $h$ 的圆锥：$\int\frac{\cos\vartheta}{r^2}\mathrm{d}V=2\pi h(1-\cos\alpha)$ |
| 与一般式关系 | 式 8.147b 的特例 | 式 8.147b 的特例 |

两算例均已独立复算通过：[[findings/式8-144柱面坐标与球柱围域体积算例复算]]、[[findings/式8-145球面坐标与圆锥算例复算]]。

## 要点

1. **$D$ 的差异决定度量收缩方向**：球面坐标的 $r^2\sin\vartheta$ 在原点附近与 $\vartheta\to 0,\pi$ 方向同时收缩；柱面坐标的 $\rho$ 只在轴线附近收缩。选择坐标系时实质是在选择「微元因子与边界方程谁更简单」。
2. **积分限的依赖结构**：柱面算例中 $z$ 上限 $\sqrt{a^2-\rho^2}$ 依赖 $(\rho,\varphi)$；球面算例中 $r$ 上限 $h/\cos\vartheta$ 依赖 $\vartheta$——都是「内层限只含外侧变量」的实例（[[concepts/累次积分]]）。
3. **区域形状定坐标系**：柱面 $x^2+y^2=ax$ 化为 $\rho=a\cos\varphi$ 极简，而圆锥顶角直接给出 $\vartheta\le\alpha$——准则实例见 [[methodology/多重积分坐标系与积分次序选择流程]] 第一步。
4. **书写约定不一致**：表 8.11 坐标列记「球坐标 r,θ,φ」，正文用 $(r,\varphi,\vartheta)$ 且 $\vartheta$ 为极角，内容一致、顺序不一（[[concepts/面积微元与体积微元]] 注记 4）。
