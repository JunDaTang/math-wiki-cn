# 正交多项式三族正交性比较（Pₙ / Lₙ⁽ᵅ⁾ / Heₙ）

本源给出三大正交多项式族的正交关系（式 9.61d、9.65e、9.66f），三者分别对应三种经典权函数与区间。

| 维度 | $P_n(x)$ | $L_n^{(\alpha)}(x)$ | $He_n(x)$ |
|---|---|---|---|
| 方程 | $(1-x^2)y''-2xy'+n(n+1)y=0$（9.60a） | $xy''+(\alpha+1-x)y'+ny=0$（9.65a） | $y''-xy'+ny=0$（9.66a） |
| 区间 | $[-1,1]$ | $[0,\infty)$ | $(-\infty,\infty)$ |
| 权函数 | $1$ | $e^{-x}x^\alpha$（$\alpha>-1$） | $e^{-x^2/2}$ |
| 正交式 | $\int_{-1}^1P_nP_m\,\mathrm{d}x=\frac{2}{2n+1}\delta_{mn}$（9.61d） | $\int_0^\infty e^{-x}x^\alpha L_m^{(\alpha)}L_n^{(\alpha)}\mathrm{d}x=\binom{n+\alpha}{n}\Gamma(1+\alpha)\delta_{mn}$（9.65e） | $\int_{-\infty}^\infty e^{-x^2/2}He_mHe_n\,\mathrm{d}x=n!\sqrt{2\pi}\,\delta_{mn}$（9.66f） |
| 范数 | $\frac{2}{2n+1}$ | $\frac{\Gamma(n+\alpha+1)}{n!}$ | $n!\sqrt{2\pi}$ |
| Rodrigues | $\frac{1}{2^nn!}\frac{\mathrm{d}^n(x^2-1)^n}{\mathrm{d}x^n}$（9.60c） | $\frac{e^xx^{-\alpha}}{n!}\frac{\mathrm{d}^n}{\mathrm{d}x^n}(e^{-x}x^{n+\alpha})$（9.65b） | $(-1)^ne^{x^2/2}\frac{\mathrm{d}^n}{\mathrm{d}x^n}e^{-x^2/2}$（9.66c） |
| 递推 | $(n+1)P_{n+1}=(2n+1)xP_n-nP_{n-1}$（9.61b） | $(n+1)L_{n+1}^{(\alpha)}=(-x+2n+\alpha+1)L_n^{(\alpha)}-(n+\alpha)L_{n-1}^{(\alpha)}$（9.65c） | $He_{n+1}=xHe_n-nHe_{n-1}$（9.66d） |
| 参数 | 无（n 唯一） | 带指标 α | 无 |
| 典型语境 | 球面调和（9.2.4.6） | ——（9.2 物理章节待入库） | 概率论 |

## 结构观察

- 三者的权函数恰好对应三类典型测度：紧区间均匀、半直线 Gamma 型、全直线 Gauss 型——正交多项式理论的三大经典族（Jacobi/Laguerre/Hermite）在本源中各以最简参数形式出现（$P_n$ 是 Jacobi 的 $\alpha=\beta=0$ 特款）。
- 范数公式中 $L_n^{(\alpha)}$ 的 $\binom{n+\alpha}{n}\Gamma(1+\alpha)=\frac{\Gamma(n+\alpha+1)}{n!}$ 显式使用 [[伽马函数]]（回指第 682 页 8.2.5, 6），与 [[贝塞尔函数]] 级数归一化（9.53a、9.54a）构成 $\Gamma$ 在本源中的三处应用。
- Rodrigues 公式结构平行：母函数乘积求 n 阶导数再除以规范化常数；三族的"母函数"分别为 $(x^2-1)^n$、$e^{-x}x^{n+\alpha}$、$e^{-x^2/2}$。
