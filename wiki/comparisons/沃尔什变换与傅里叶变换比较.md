# 沃尔什变换与傅里叶变换比较

依《数学手册（原书第 10 版）》15.6 节：「构建沃尔什变换与构建傅里叶变换类似，其中三角函数的作用被沃尔什函数取代」。本页整理这一平行关系，并说明两处谱系框定的差异。

## 平行结构

| 构造要素 | 傅里叶侧 | 沃尔什侧 |
|---|---|---|
| 基函数 | 三角函数（光滑、足够多次可微） | 沃尔什函数（阶梯、只取 +1 与 −1） |
| 基函数适用对象 | 光滑对象 | 粗糙图像点等光滑函数不适合数学描述的情形 |
| 级数展开 | 傅里叶级数 | 沃尔什级数 |
| 函数逼近工具 | 三角多项式（本页推断的对应项，原文未列举） | 沃尔什多项式（原文列举） |
| 正弦/余弦变体 | 傅里叶正弦变换、傅里叶余弦变换 | 沃尔什正弦变换、沃尔什余弦变换 |
| 积分构造 | [[concepts/傅里叶积分]] | 沃尔什积分 |
| 快速算法 | 快速傅里叶变换 | 快速沃尔什变换 |

注：沃尔什侧各项均为 15.6 原文的名称列举，原文未给出任何定义或公式；傅里叶侧除「三角多项式」行为本页推断外，其余为手册 15.1、15.3 节已入库内容。

## 实现特性

沃尔什函数只取两个函数值、对应两状态，故可由计算机轻松实现（15.6 原文断言）。原文未对三角函数的实现难度作对称陈述，不应据此类比反推。

## 谱系框定差异（非矛盾）

15.1 节表 15.1 所列十二种单变量积分变换（拉普拉斯族、傅里叶族、梅林、汉克尔、斯蒂尔切斯等，见 [[comparisons/表15-1十二种积分变换核与记号比较]]、[[findings/表15-1十二种单变量积分变换综述转录复算]]）不含沃尔什变换；15.6 在该谱系之外以「三角函数被沃尔什函数取代」的类比另立一族。两处对「积分变换」的框定不同——表 15.1 限于连续核的积分变换，沃尔什变换以阶梯函数为基——属谱系口径差异，不构成矛盾。
