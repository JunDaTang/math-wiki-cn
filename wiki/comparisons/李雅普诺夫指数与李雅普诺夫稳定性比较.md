# 李雅普诺夫指数与李雅普诺夫稳定性比较

两者均以数学家 [[entities/李雅普诺夫]] 命名（本源 17.2.3 与已入库的 17.1.2 分别载之），但属**同名不同物**的两套概念，极易混淆：

| 维度 | 李雅普诺夫指数（17.2.3） | 李雅普诺夫稳定性（17.1.2） |
|---|---|---|
| 回答的问题 | 轨道邻域沿各方向以多快的**指数速率**拉伸/压缩（定量） | 平衡点/解附近轨道是否**留在附近**（定性） |
| 对象 | 支撑在吸引子上的遍历不变测度的几乎处处轨道 | 个别平衡点或特解 |
| 定义载体 | $D\varphi^t(x)$ 奇异值的对数平均 $\frac{1}{t}\ln\sigma_i(t,x)$ | ε-δ 语言；或 [[concepts/李雅普诺夫函数]] 判据 |
| 存在性依据 | [[concepts/Oseledec定理]]（乘性遍历定理） | 皮卡—林德勒夫存在唯一性 + 直接估计 |
| 适用范围 | 含混沌吸引子的一般情形（谱刻画） | 主要用于平衡点、周期轨等特定不变集 |
| 输出形态 | 一列实数谱 $\lambda_1 \geqslant \cdots \geqslant \lambda_n$ | 分级性质：稳定 / 渐近稳定 / 不稳定 |

## 交汇点

平衡点处两者相遇：特例 A 给出 $\lambda_i = \mathrm{Re}\,\alpha_i$（[[findings/平衡点与周期轨李雅普诺夫指数特例复算]]），而特征值实部正是线性化系统稳定性的判据（$\mathrm{Re}\,\alpha_i < 0\ \forall i$ ⇔ 渐近稳定，即 [[concepts/双曲平衡点]] 与 [[concepts/双曲平衡点与汇源鞍分类]] 的分类依据）。可以说：**指数谱是稳定性判据从平衡点向一般轨道的推广**——最大指数为正对应某方向的不稳定。〔此推广性表述为编者注。〕
