# J 族与 Y 族零点交错与显式符号分布比较

比较对象：手册 21.11 贝塞尔函数表中第一类 J₀、J₁ 与第二类 Y₀、Y₁ 的零点结构，及其在表中的显式符号标注分布。比较目的：以零点交错结构核验符号承袭约定的复原，并为振荡列的讹误定位提供结构基准。

## 零点对照

| 函数 | 类别 | 表域（0–10）内零点 | 起始行为 |
|---|---|---|---|
| J₀ | 第一类 | 2.4048、5.5201、8.6537 | J₀(0)=+1，正起 |
| J₁ | 第一类 | 3.8317、7.0156 | J₁(0)=0，正起 |
| Y₀ | 第二类 | 0.8936、3.9577、7.0861 | Y₀(0⁺)=−∞，负起 |
| Y₁ | 第二类 | 2.1971、5.4297、8.5960 | Y₁(0⁺)=−∞，负起 |

## 交错结构

- J₀ 与 J₁：2.4048 < 3.8317 < 5.5201 < 7.0156 < 8.6537
- J₀ 与 Y₀：0.8936 < 2.4048 < 3.9577 < 5.5201 < 7.0861 < 8.6537
- J₁ 与 Y₁：2.1971 < 3.8317 < 5.4297 < 7.0156 < 8.5960

同阶两类函数、相邻阶同类函数的零点均两两相间，与贝塞尔函数零点交错的通行理论一致。

## 显式符号分布与零点的对应

- 0.5 整倍数行：J、Y 四列全部显式标号（如 x=2.5 行：−0.0484、+0.4971、+0.4981、+0.1459）。
- 零点两侧的行显式标号：Y₁（2.1 行 −0.0517、2.2 行 +0.0015）夹零点 2.1971；J₁（3.8 行 +0.0128、3.9 行 −0.0272）夹零点 3.8317；Y₀（0.8 行 −0.0868、0.9 行 +0.0056）夹零点 0.8936；J₀（8.6 行 +0.0146、8.7 行 −0.0125）夹零点 8.6537。
- 其余行承袭：如 J₀ 2.6–2.9 行承袭 2.5 行负号（−0.0968…−0.2243），与真值相符。
- 一处例外：J₀(2.4) 行 0.0025 未带显式「+」（详见 [[concepts/数值表符号承袭与前缀记法]]）。
- 对照组：I、K 列恒正、从不变号，故全表无符号标注——J、Y 列的显式符号完全由半整行与零点位置决定。

## 结构的校勘意义

- 变号标注位置与零点一一对应，构成对零点位置的表内独立证据。
- Wronskian 恒等式 J₁Y₀−J₀Y₁=2/(πx) 将四列耦合：Y₀(2.7) 一处讹误同时破坏该列单调段（0.4813→0.4359）与恒等式，两重异常互相印证（[[findings/Y0于x2-7值0-2605与复算不符]]）。
