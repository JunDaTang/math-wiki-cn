# 大圆航线与斜航线比较

本比较基于 [[sources/10-数学手册原书第10版--12-343-球面三角形的计算--170nm2t]] 3.4.3.4 对两类球面曲线的公式组（[[findings/大圆航线公式组]]、[[findings/斜航线对数方程与极点渐近]]）。

| 维度 | [[concepts/大圆航线]] | [[concepts/斜航线]] |
|---|---|---|
| 定义 | 球面测地线，连接两点的最短曲线 | 以相同航向角与所有子午线相交 |
| 方程类型 | 三角形式：tan φ = tan φ_N·cos(λ−λ_N)（3.203） | 对数形式：λ−λ_A = tan α·ln[tan(45°+φ/2)/tan(45°+φ_A/2)]·180°/π（3.219b） |
| 参数化 | 由最接近北极的点 P_N(λ_N, φ_N) 唯一确定（该处 α_N = 90°） | 由航向角 α 与一个通过点（或赤道交点 P_E）确定 |
| 航向角 | 沿线连续变化；|α| 在赤道交点处最小 = 90°−φ_N（3.211） | 常数 |
| 弧长 | d = arccos[...]·πR/180°（3.207b），最短 | s = |φ_B−φ_A|/cos α·πR/180°（3.220b），一般更长 |
| 与子午线交点 | 至多 2 个，φ_Y = arctan[tan φ_N cos(λ_Y−λ_N)]（3.212） | 无穷多，含 ν·360° 周期项（3.225） |
| 极点行为 | 可到达不超过 φ_N 的最高纬度 | 螺旋环绕极点，渐近而不达 |
| 特例 | 赤道、子午线 | 纬线（α = 90°）、子午线（α = 0°） |
| 交点性质（两两相交） | 交点恒为对径点对（3.228–3.229） | 交点有无穷多（3.231） |

两者是航海中「最短航程」与「等角航行（操舵简单）」两种目标各自的解；源中把航向角的选择明确列为航海应用的基本问题。共同的计算惯例是角的简化 (3.205) 与 πR/180° 的弧长换算。[[concepts/小圆]] 居间：r → 90° 时退化为大圆（(3.214) → (3.207b) 得 s = d）。
