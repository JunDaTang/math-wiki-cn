# 平均逼近与切比雪夫逼近比较

本页对照 19.6 与其两个子节给出的两种函数逼近范式。左列内容依据 19.6.2（见 [[10-数学手册原书第10版--9-1962-平均逼近--zr0sw4]]），右列内容依据 19.6.3（本 wiki 所录子节）。

| 维度 | 平均逼近（19.6.2，L²） | 切比雪夫逼近 / 一致逼近（19.6.3，L∞） |
|---|---|---|
| 优化范数 | 误差平方的（加权）积分或求和 | sup-范数：区间上最大绝对误差 |
| 目标函数 | [[残量平方和]]最小 | (19.195)：max\|f−g\| = min! |
| 最佳性特征 | [[正规方程（平均逼近）]]：残量与基函数（加权）正交 | [[交替点定理]]：误差在 n+2 个交替点达最大模且变号 |
| 权函数 | 有（[[权函数与加权内积]]，表 19.2） | 无权函数概念 |
| 连续问题求解 | 正规方程（[[连续最小二乘逼近求解流程]]） | [[列梅兹算法]]（[[列梅兹算法迭代流程]]） |
| 离散问题求解 | [[正规方程与高斯变换]] 或 [[QR分解与正交化方法]]（[[离散最小二乘豪斯霍尔德求解流程]]） | 消绝对值化为线性规划 (19.209)（回指 18.1.1.1） |
| 参数非线性情形 | [[非线性最小二乘线性化三步迭代流程]]：线性化 + 迭代 | 归为非凸非线性最优化（18.2.2.1），不走线性化路线 |
| [[切比雪夫多项式]]的角色 | 加权正交基（权 1/√(1−x²)） | 极值多项式（xⁿ 最佳一致逼近的误差函数） |

## 方法论分野：对非线性参数的处置

两种范式对参数非线性的态度形成鲜明对照：19.6.2 对非线性最小二乘采用**线性化三步迭代**（在近似点展开、解线性最小二乘、迭代）；19.6.3 对非线性一致逼近则明确指出化为**通常非凸**的非线性最优化问题、数值求解本质性变难，且未提出任何线性化路线。这是「平方结构可线性化、绝对值结构不可」的深层差异在方法论上的体现（此句为对照分析，非原文陈述）。

## 误差度量哲学

- 平均逼近将误差**平方后均匀分摊**，个别点的大误差可被多数点的小误差稀释。
- 一致逼近**控制最坏情形**，保证全区间误差上界，代价是最佳性条件（交替点等幅振荡）更难求解。

## 结论

二者共享「n+1 个线性无关基函数的线性组合」这一逼近函数设定，但范数选择决定了完全不同的最佳性条件（正交性 vs 交替）与数值路线（线性代数 vs 迭代交换 / 线性规划）。[[切比雪夫多项式]]在两种范式中各司其职（正交基 vs 极值多项式），两节内容互补而无冲突。
