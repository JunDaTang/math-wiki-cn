# 解析求导与图解微分比较

依据《数学手册（原书第10版）》6.1.2：解析求导对应式 6.4–6.19 的法则体系（详见 [[微分法则]]），图解微分法对应 6.1.2.2 第 11 条（详见 [[图解微分法]]）。两者解决同一问题——求 $y = f(x)$ 的导数——但输入条件与产出形式不同，互为补充。

| 维度 | 解析求导（式 6.4–6.19） | 图解微分法（第 11 条） |
|---|---|---|
| 输入 | 函数的解析表达式 | 区间 (a, b) 上的曲线（图像） |
| 依据 | 微分法则体系 + 表 6.1 导数表 | 割线中点定切点 + 极点标度法 |
| 输出 | 导数的解析表达式 | 导数曲线 $y = a f'(x)$（图形） |
| 精度 | 精确 | 近似（受作图与读数精度限制） |
| 误差控制 | — | 用平行割线取中点替代肉眼估计切线；可作第三条平行割线自检 |
| 后处理 | 无 | a ≠ 1 时纵坐标须乘 $1/a$ 还原 |
| 适用场景 | 有表达式且可逐级套用法则 | 无表达式、仅有实验曲线或图像 |

## 定位

手册把图解微分法列为微分法则节的第 11 条（末条），其定位是“函数仅以曲线给出、解析法则无法直接使用时的图形途径”。割线中点法与极点标度法的几何原理见 [[图解微分法构造流程]] 与 [[图解微分法极点法标度关系的几何复核]]。

## 存疑

原文“线段 PO = a 越长曲线越平缓”与 $y = a f'(x)$ 的纵向拉伸关系矛盾，若“平缓”另有所指（如读数分辨率），可能影响上表中“误差控制”一栏的理解，见 [[极点距a越长越平缓与y等于af是否矛盾]]。
