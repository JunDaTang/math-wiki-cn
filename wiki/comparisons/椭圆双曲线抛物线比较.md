# 椭圆双曲线抛物线比较

三大圆锥曲线在本源（3.5.2.8–3.5.2.10）中的系统对照。**注意：以下各命题严格绑定各自实体，不得互换**——最典型的例子是切线判别式的符号差：椭圆 (3.326) 为 A²a² + B²b² = C²，双曲线 (3.334) 为 A²a² − B²b² = C²；原文 (3.334) 之后误书「是该椭圆的切线」，应属双曲线（见 [[queries/双曲线小节疑似讹误清单]]）。

| 维度 | 椭圆（3.320–3.329） | 双曲线（3.330–3.342） | 抛物线（3.343–3.352） |
|---|---|---|---|
| 定义（焦点性质） | r₁ + r₂ = 2a（距离**和**） | r₂ − r₁ = ±2a（距离**差**） | PF = PK（距离**相等**） |
| 数值离心率 | e = c/a < 1 | e = c/a > 1 | e = 1 |
| 标准方程 | x²/a² + y²/b² = 1 | x²/a² − y²/b² = 1 | y² = 2px |
| 焦半径 | r₁ = a − ex, r₂ = a + ex | r₁ = ±(ex − a), r₂ = ±(ex + a) | x + p/2 |
| 准线 | 与短轴平行，d = a/e | 与实轴垂直（原文 d = a/c 疑为 a/e） | 距顶点 p/2，与轴垂直 |
| 切线判别 | A²a² + B²b² = C²（3.326） | A²a² − B²b² = C²（3.334） | p = 2bk（3.349） |
| 共轭直径 | kk′ = −b²/a²（3.323） | kk′ = +b²/a²（反号），\|k\| < b/a 者与曲线相交 | 直径是平行于轴的直线 y = p/k（3.346） |
| 阿波罗尼奥斯定理 | 和式型：a₁b₁sin(α+β) = ab，a₁²+b₁² = a²+b²（3.324） | 差式型：a₁²−b₁² = a²−b²，ab = a₁b₁sin(α−β)（3.339） | —（本源未述） |
| 渐近线 | 无 | y = ±(b/a)x；面积不变量 ab、ab/2（3.335–3.337） | 无 |
| 顶点曲率半径 | 长轴顶点 b²/a = p，短轴顶点 a²/b（3.327） | p = b²/a（3.340b） | p（3.350b） |
| 面积 | S = πab；扇形/弓形 (3.328) | S_OAPG = ab/4 + (ab/2)ln(2d/c)（3.341b）；弓形公式 (3.341a) 脱落 | 弓形 = 平行四边形的 2/3；S = 2xy/3（3.351） |
| 弧长 | **初等不可积**，需第二类椭圆积分（3.329） | **初等不可积**，需第二类椭圆积分 | **初等可积**：(p/2)[√((2x/p)(1+2x/p)) + ln(…)]（3.352a） |

## 结构性观察

1. **和↔差对偶**：定义（和/差）、焦半径（a∓ex / ±(ex∓a)）、阿波罗尼奥斯（a₁²+b₁² / a₁²−b₁²）、sin(α+β) / sin(α−β) 构成椭圆与双曲线的系统对偶。
2. **符号翻转的传递**：标准方程的一处符号差（+y²/b² ↔ −y²/b²）逐级传导到切线判别式、共轭直径斜率积与阿波罗尼奥斯定理——这正是「命题绑定实体」的原因。
3. **抛物线的极限地位**：e=1 时第二焦点与准线退向无穷远，故抛物线无中心、无渐近线、直径退化为平行于轴的直线族，但弧长反而初等可积。
4. 曲率半径三者共享 p/sin³u 形式（3.327 / 3.340a / 3.350a），u 为切线与焦半径的夹角。

各曲线的完整公式组见 [[findings/椭圆理论公式组]]、[[findings/双曲线理论公式组]]、[[findings/抛物线理论公式组]]。
