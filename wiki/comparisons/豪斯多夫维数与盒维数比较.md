# 豪斯多夫维数与盒维数比较

《数学手册》17.2.4.1 并置给出两种集合维数：豪斯多夫维数（覆盖**体积**思想，式 17.41）与盒维数/容量（覆盖**计数**思想，式 17.42）。二者在光滑对象上一致，在分形与可数集上可能分离。

| 维度 | 豪斯多夫维数 $d_H$ | 盒维数（容量）$d_B$ |
|---|---|---|
| 定义 | $\mu_d$ 的临界指标：$\inf\{d:\mu_d(A)=0\}$ | $\ln N_\varepsilon(A)/\ln(1/\varepsilon)$ 的 limsup/liminf |
| 覆盖口径 | 任意子集、直径 $d$ 次幂之和取下确界 | 尺寸 $\le\varepsilon$ 集合的最小个数；$\mathbb{R}^n$ 中可网格计数 |
| 相互关系 | $d_H(A)\le d_B(A)$（BD1） | 同左 |
| 可数稳定性 | 成立（HD4：$d_H(\cup A_i)=\sup_id_H(A_i)$） | 一般不成立（BD4；前句疑脱对照，见 [[queries/BD4前句疑脱豪斯多夫可数稳定性之辨]]） |
| 取闭包 | 可有 $d_H(A)<d_H(\bar A)$ | $d_B(A)=d_B(\bar A)$（BD3） |
| 光滑 $m$ 维曲面 | $=m$（BD2） | $=m$（BD2） |
| $A=\{0,1,\tfrac12,\tfrac13,\dots\}$ | $0$（可数，HD5） | $\tfrac12$（$N_\varepsilon\asymp\varepsilon^{-1/2}$） |
| $\mathbb{Q}\cap[0,1]$ | $0$ | $1$（闭包 $=[0,1]$） |
| [[concepts/康托尔集]] | $\ln2/\ln3\approx0.6309$ | 同值（自相似集） |

## 分析

- **稳健 vs 可算**：$d_H$ 对可数并稳定（HD4）、是双利普希茨不变量（HD6），理论性质好；$d_B$ 可由网格计数直接估计（[[methodology/盒维数网格计数流程]]），实操性强。
- **分离来源**：两例（$A$ 与 $\mathbb{Q}\cap[0,1]$）表明盒维数会把聚点结构的「计数账」计入，而 $d_H$ 因覆盖形状自由而能抹平稀疏性；BD3 的闭包不变性正是这一差别的体现（$d_H$ 在闭包处可跳升）。
- **汇合条件**：源文对自相似四例断言 $d_B=d_H=\ln p/\ln q$（[[concepts/自相似性]]）；光滑曲面上两者同为整数维（BD2）。
- **测度侧延伸**：盒维数还以 $d_0=d_C(\operatorname{supp}\mu)$ 进入瑞尼谱（[[concepts/广义维数（瑞尼维数谱）]]），豪斯多夫维数则延伸为 $d_H(\mu)$（[[concepts/点维数与测度的豪斯多夫维数]]）。
