# Ci、Li、Ei 三函数级数结构比较

## 比较表（依据式 8.96a、8.97、8.98a）

| 函数 | 积分定义 | 级数表示 | 定义域/主值约定 |
|---|---|---|---|
| Ci(x) | −∫ₓ^∞ (cos t)/t dt | C + ln x + Σ_{n≥1}(−1)ⁿ x^{2n}/(2n·(2n)!) | 0 < x < ∞ |
| Li(x) | ∫₀ˣ dt/ln t | C + ln\|ln x\| + Σ_{n≥1}(ln x)ⁿ/(n·n!) | 0 < x < 1；1 < x < ∞ 为柯西主值 |
| Ei(x) | ∫₋∞ˣ eᵗ/t dt | C + ln\|x\| + Σ_{n≥1} xⁿ/(n·n!) | −∞ < x < 0；0 < x < ∞ 为柯西主值 |

## 共同骨架

三者的级数均为「常数项 C（欧拉常数，见 [[欧拉常数]]）＋ 对数项 ln|·| ＋ 幂级数项 Σuⁿ/(n·n!)」的结构。级数部分满足 d/du Σuⁿ/(n·n!) = (e^u − 1)/u，即它是 ∫₀^u (e^s − 1)/s ds 的级数形式（复算验证）。

## 相互关系

- Ei(ln x) = Li(x)（式 8.98b，原书给出，代换复算一致）：Li 是 Ei 与对数函数的复合，两者的级数逐项对应。
- 复算观察（推导，非原书原文）：Ci(x) 的级数恰为 Ei(ix) 的实部——因 (ix)^{2n} = (−1)ⁿx^{2n}，偶次项与 Ci 完全吻合，即 Ci 与 Ei 经复变量相通；Si 相应为 Ei(ix) 的虚部同类结构。
- 三者的主值约定都源于被积函数在单点的奇性（Li 在 t = 1、Ei 在 t = 0），详见 [[柯西主值]]。

## 结论

原书把三组级数排成平行条目并非巧合：它们是同一「对数＋指数型」非初等积分族在实轴不同代入下的成员，公共常数 C 与公共级数骨架使三者可互相换算。复算记录见 [[式8-95至8-96正弦余弦积分级数复算]] 与 [[式8-97至8-98对数指数积分与Ei-Li关系复算]]。
