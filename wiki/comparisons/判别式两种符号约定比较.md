# 判别式两种符号约定比较

关于二阶偏微分方程 (9.82a) 的分类判别式，手册与通行教材采用方向相反的约定：

| 约定 | 手册（本源） | 通行教材 |
|---|---|---|
| 判别式定义 | δ = AC − B²（式 9.82b） | Δ = B² − AC（或对一般二次型取 B² − 4AC） |
| 双曲型 | δ < 0 | Δ > 0 |
| 抛物型 | δ = 0 | Δ = 0 |
| 椭圆型 | δ > 0 | Δ < 0 |

两者只差一个整体符号（δ = −Δ），分类判据完全等价；但引用本源公式时**必须先换算**，防止把“双曲 ⇔ 正号”的通行直觉误用于手册记号。特征方程的解 dy/dx = (B ± √(−δ))/A 在手册记号下于双曲型（δ < 0）给出两实根，与“双曲有两族实特征”一致。

同类的手册特有约定还有：[[格林函数与格林方法]] 的表示公式 (9.99e) 使用**指向区域内部的法向导数**（与常见外法向约定符号相反但自洽）。两处约定均已在本 wiki 相应页面标注，防止跨源迁移时出错。
