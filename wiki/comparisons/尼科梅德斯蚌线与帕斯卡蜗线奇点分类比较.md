# 尼科梅德斯蚌线与帕斯卡蜗线奇点分类比较

两族蚌线的原点奇点都由 l 与 a 之比三分，但方向**相反**——仅看“l < a / l > a”的字面极易张冠李戴。

| 条件 | 尼科梅德斯蚌线（式 2.233） | 帕斯卡蜗线（式 2.235） |
|---|---|---|
| l < a | 孤立点；左支两拐点 E, F | 二重点；tan α = ±√(a²−l²)/l，r₀ = ½√(a²−l²) |
| l = a | 尖点 | 尖点（即心脏线） |
| l > a | 二重点；tan α = ±√(l²−a²)/a，r₀ = l√(l²−a²)/(2a)；左支在 x = a − ∛(al²) 有极大极小 | 孤立点 |

## 方向相反的机制（极径零点分析）

奇点类型取决于曲线是否以及几次经过极点，即极径 ρ(φ) 的零点个数：

- 蜗线 $\rho = a\cos\varphi + l = 0 \Rightarrow \cos\varphi = -l/a$：l < a 时有两解（两个极角过极点 → 二重点），l = a 时一解（尖点），l > a 时无解（孤立点）。
- 尼科梅德斯蚌线（取“−”的支）$\rho = a/\cos\varphi - l = 0 \Rightarrow \cos\varphi = a/l$：l > a 时有两解（二重点），l = a 时一解（尖点），l < a 时无解（孤立点）。

两式中 a 的位置互换（cos φ = −l/a 与 cos φ = a/l），正是三分律方向相反的代数根源；几何上对应母曲线是否过极点（见 [[comparisons/蚌线族三级特化比较]]）。

## 独立核验（两族 r₀ 均经极点曲率公式复推吻合）

极点曲率半径公式 $r_0 = |\rho'(\varphi_0)|/2$（φ₀ 为过极点的极角）：

- 蜗线：$\rho' = -a\sin\varphi$，$|\rho'(\varphi_0)| = \sqrt{a^2-l^2}$，故 $r_0 = \frac{1}{2}\sqrt{a^2-l^2}$；
- 蚌线：$\rho' = a\sec\varphi\tan\varphi$，$|\rho'(\varphi_0)| = l\sqrt{l^2-a^2}/a$，故 $r_0 = l\sqrt{l^2-a^2}/(2a)$。

## 使用警示

引用“l 与 a 之比决定奇点”的结论时必须同时说明所属曲线族，两族的公式不可互相移用。l = a 是两族共同的尖点汇合形态：蜗线的尖点情形即 [[concepts/心脏线]]（单独命名），蚌线的尖点情形未单独命名。完整分类语言见 [[concepts/曲线的奇点三型]]。
