# 矩形与菱形比较

[[concepts/矩形]]与[[concepts/菱形]]同为[[concepts/平行四边形]]的特化，分别沿「角」与「边」两个方向；其刻画条件呈对偶结构（比较框架为本 wiki 归纳；两列内容分别来自源 3.1.4.2 与 3.1.4.3）。

| 维度 | 矩形 | 菱形 |
|---|---|---|
| 前提 | 平行四边形 | 平行四边形 |
| 特化方向 | 等角：只具直角 | 等边：四边等长 |
| 对角线刻画 | 对角线等长 | 对角线相互垂直；且为角平分线 |
| 刻画的等价性 | 只具直角 ⟺ 对角线等长（任一即足） | 四边等长 ⟺ 对角线垂直 ⟺ 对角线平分对角（任一即足） |
| 对角线性质汇总 | 等长、互相平分（未必垂直） | 互相垂直、互相平分、平分对角（未必等长） |
| 对角线公式 | 源未单列通式（正方形特例 $d = a\sqrt{2}$，式 3.22） | $d_1 = 2a\cos\frac{\alpha}{2}$，$d_2 = 2a\sin\frac{\alpha}{2}$，$d_1^2 + d_2^2 = 4a^2$（式 3.25–3.27） |
| 面积 | $S = ab$（式 3.21b） | $S = ah = a^2\sin\alpha = \frac{d_1 d_2}{2}$（式 3.28，三种表示） |
| 周长 | $U = 2(a+b)$（式 3.21a） | 源未单列（由四边等长立得 $U = 4a$，此为直接推论） |

## 公共特化

[[concepts/正方形]]：$a = b$ 的矩形；由四边等长，它同时满足菱形的全部刻画条件，居于两类之交。

## 对偶结构

把「等角 ↔ 等边」「对角线等长 ↔ 对角线垂直（平分对角）」互换，即可从一个刻画得到另一个——这一对偶是本节编排上最显著的结构。相应地，两类的专属公式也互不对称：菱形享有以对角线表达的一组公式（式 3.25–3.28，见 [[findings/菱形对角线与面积公式]]），矩形的公式则以边为主（式 3.21，见 [[findings/矩形与正方形公式]]）。
