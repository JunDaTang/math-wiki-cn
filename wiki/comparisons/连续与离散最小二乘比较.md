# 连续与离散最小二乘比较

《数学手册（原书第 10 版）》19.6.2 将平均逼近分为连续（19.6.2.1）与离散（19.6.2.2）两种情形，二者是同一高斯最小二乘原理的两种数据形态。逐项对照如下：

| 维度 | 连续情形（19.6.2.1） | 离散情形（19.6.2.2） |
|---|---|---|
| 被逼近对象 | 已知函数 $f(x)$，$x\in[a,b]$ | $N$ 对测量值 $(x_\nu,y_\nu)$ |
| 目标泛函 | $F=\int_a^b\omega(x)[f(x)-g(x)]^2\,\mathrm{d}x$（19.169） | $F=\sum_\nu[y_\nu-g(x_\nu)]^2$（19.179，残量平方和） |
| 度量的来源 | 权函数 $\omega(x)>0$ 决定带权内积 | 节点集 $\{x_\nu\}$ 决定求和（高斯求和符号） |
| 正规方程 | $\sum_i a_i(g_i,g_k)=(f,g_k)$（19.172） | $\sum_i a_i[g_ig_k]=[yg_k]$（19.180） |
| 系数矩阵 | Gram 矩阵（积分型），对称 | $\boldsymbol{G}^{\mathrm{T}}\boldsymbol{G}$（求和型），对称 |
| 正交化收益 | 有四族经典正交多项式现成可用（表 19.2），系数 $a_i=(f,g_i)$ 直接可解 | 理论上同样对角化，本源未给离散正交基构造 |
| 数值解法 | 楚列斯基方法（矩阵对称） | 楚列斯基方法，或（原文推荐）豪斯霍尔德方法直接解超定 $\boldsymbol{G}\underline{\boldsymbol{a}}=\underline{\boldsymbol{y}}$ |
| 与插值的关系 | ——（无插值对应物） | $n<N-1$ 时插值方程组 (19.183) 超定、通常无解；最小二乘是其「折中」 |
| 唯一性前提 | 基函数线性无关（原文明言） | 需 $\boldsymbol{G}$ 列满秩（原文仅以 $n\ll N$ 暗示，内部缺口） |

## 统一性

- 两型的正规方程结构完全平行：$(g_i,g_k)$ 之于 $[g_ig_k]$，恰如加权积分之于节点求和；$\boldsymbol{G}^{\mathrm{T}}\boldsymbol{G}$ 就是离散 Gram 矩阵。
- 驻点条件在两型中同为 $\partial F/\partial a_i=0$，且都把二次泛函极小化为线性方程组求解。
- 这一平行性正是 [[comparisons/最小二乘法（已知函数逼近）与线性最小二乘问题辨析]] 所追踪的「同一原理、不同对象」格局的最直接证据：连续加权积分 ↔ 离散残量平方和，本节是二者的统一理论。
