# 一元导数与偏导数比较

本比较综合《数学手册(原书第10版)》6.1.1（[[concepts/微商]]）与 6.2.1（[[concepts/偏导数]]）两处表述，从定义、几何意义、计算法则三方面对照一元导数与偏导数。

## 对比表

| 方面 | 一元导数（6.1.1，式 6.1–6.2） | 偏导数（6.2.1，式 6.35–6.36） |
|---|---|---|
| 定义 | f′(x) = lim_{Δx→0} [f(x+Δx)−f(x)]/Δx，唯一变量 x 变化 | ∂u/∂x₁ = lim_{Δx₁→0} [f(x₁+Δx₁, x₂, …, xₙ)−f(x₁, …, xₙ)]/Δx₁，仅一个变量变化、其余 n−1 个视为常数 |
| 个数 | 每点一个导数（以及 [[concepts/高阶导数]] 的序列） | n 元函数有 n 个一阶偏导数 ∂u/∂x₁, …, ∂u/∂xₙ |
| 几何意义 | 曲线切线斜率 = tan 切线倾角（式 6.2） | 曲面被平行于坐标面的平面所截，截曲线切线倾角的正切：∂u/∂x = tan α、∂u/∂y = tan β（式 6.36，图 6.14） |
| 计算法则 | [[concepts/微分法则]] 全套（和差积商、链式、对数微分等） | 明确声明「可利用与一元函数相同的求导法则」，其余变量作常数处理 |
| 记号 | f′(x)、y′、dy/dx 等 | ∂u/∂x、u′ₓ、∂f/∂x、f′ₓ |

## 要点

- 结构平行：n = 1 时式 6.35 退化为式 6.1；式 6.36 是式 6.2 的「截曲线」推广。
- 操作差异：偏导数计算多一步「冻结其余变量」，这正是 [[methodology/偏导数计算流程]] 的第一步。
- 覆盖范围差异：一元节还讨论了单侧导数与不可导情形（[[concepts/左导数与右导数]]、[[concepts/尖点]]），本节对偏导数的对应问题（如某变元偏导的存在性、各方向导数）未展开；沿任意方向的导数（方向导数）被推迟到向量分析（13.2.1.3）。
