# KdV 方程（科尔泰沃赫—德弗里斯方程）

**KdV 方程**（科尔泰沃赫—德弗里斯方程，Korteweg de Vries；源文译名「科尔泰沃赫」，通译「科特韦格—德弗里斯」）是无耗散的非线性发展方程（9.2.5.2）：

```latex
u_t + 6 u u_x + u_{xxx} = 0        (9.148) = (9.153)
```

它是孤子现象的原型方程。

## 出现场所

- 浅水中的表面波；
- 非线性格中的非谐振动；
- 等离子体物理学中的问题；
- 非线性电网。

## 单孤子解与参数依赖

```latex
u(x,t) = (v/2) sech^2[ (1/2)√v (x − v t − φ) ],   v > 0     (9.154)
```

KdV 孤子由两个无量纲参数 v > 0（速度）与 φ（相，描述 t = 0 时最大值位置）唯一确定。典型的非线性效应是：**孤子的速度决定了它的振幅和宽度**——较大振幅、较小宽度的孤子行进快于较小振幅、较大宽度的孤子（较高的波行进快于较矮的波）。图 9.22 取 v = 1。

## N-孤子解与弹性相互作用

方程有一些 N-孤子解，当 t → ±∞ 时渐近表示为单个孤子的线性叠加：

```latex
u(x,t) ~ Σ_{n=1}^{N} u_n(x,t)     (9.155)
```

每个 u_n 由速度 v_n 与相 φ_n^± 刻画；碰撞前后相不同、速度不变（弹性相互作用）。对 N = 2 有双孤子解 (9.156)（按转写形式存在指数定义与系数配对双重疑误，见 [[queries/式9-156指数定义与系数交叉配对疑误]]；渐近速度 v_n = 4k_n²）。

## 位势形式与非线性叠加

引入位势 w = F_x/F（且 2w_x = u）时，KdV 化为

```latex
w_t + 6 (w_x)^2 + w_{xxx} = 0,   w = F_x/F,   2 w_x = u     (9.157a)
```

对 F 取特定形式可得单孤子 (9.157b) 与 N-孤子 (9.157c)——但 (9.157b)、(9.157c) 中 F 的具体表达式在转写中丢失（[[queries/式9-157b至9-157c公式内容缺失]]）。方程 (9.156) 与由 (9.157c) 得到的表达式是**非线性叠加**的例子；其方法实质即 [[methodology/广田双线性方法]]。

## 反孤子

如果在 (9.153) 中以 −6uu_x 代替 +6uu_x，那么 (9.154) 的右端必须乘以 (−1)；此情形用记号**反孤子** (antisoliton)。

## 复算状态

(9.154)、(9.157a) 的位势关系、反孤子换号陈述均经直接代入独立验证成立；(9.156) 按转写形式不能自洽退化为 (9.154)（修正形式见 [[findings/式9-153至9-157kdv单孤子双孤子复算]]）。KdV 孤子与 NLS/SG 孤子的参数依赖对比见 [[comparisons/三大孤子方程孤子参数依赖比较]]。
