# 三角恒等式

三角恒等式是连接六个三角函数在同一角或不同角取值间的恒等公式体系。《数学手册(原书第10版)》2.7.2 节（式 2.82–2.135）将其组织为八个族：

| 公式族 | 式号 | 内容 |
|---|---|---|
| 同角关系 | 2.82–2.89 | 平方关系（勾股恒等式）、倒数关系、商关系 |
| 加法定理 | 2.90–2.95 | 两角和/差、三角和 |
| 倍角公式 | 2.96–2.107 | 2、3、4 倍角 |
| 倍角通式 | 2.108–2.109 | 棣莫弗公式＋二项式定理；编号 2.110 空缺 |
| 半角公式 | 2.111–2.114 | 根号符号依半角象限定 |
| 和差化积 | 2.115–2.122 | 两函数的和/差化为积 |
| 积化和差 | 2.123–2.129 | 含三函数积四式 |
| 降幂公式 | 2.130–2.135 | 二、三、四次幂化为倍角和 |

## 同角关系（式 2.82–2.89，完整）

$$\sin^2\alpha+\cos^2\alpha=1,\qquad \sec^2\alpha-\tan^2\alpha=1,\qquad \csc^2\alpha-\cot^2\alpha=1,$$
$$\sin\alpha\cdot\csc\alpha=1,\qquad \cos\alpha\cdot\sec\alpha=1,\qquad \tan\alpha\cdot\cot\alpha=1,$$
$$\frac{\sin\alpha}{\cos\alpha}=\tan\alpha,\qquad \frac{\cos\alpha}{\sin\alpha}=\cot\alpha.$$

## 各族代表公式

- **加法定理**：$\sin(\alpha\pm\beta)=\sin\alpha\cos\beta\pm\cos\alpha\sin\beta$（2.90）等四式，另有三角和公式（2.94–2.95）。
- **倍角**：$\sin 2\alpha=2\sin\alpha\cos\alpha$（2.96）、$\cos 3\alpha=4\cos^3\alpha-3\cos\alpha$（2.99）等，覆盖 $\sin/\cos/\tan/\cot$ 的 2–4 倍角。
- **倍角通式**：$n$ 较大时利用 [[concepts/棣莫弗公式]] 与二项式定理得 $\cos n\alpha$、$\sin n\alpha$ 的展开（2.108–2.109）；源文编号 (2.110) 空缺（见 [[queries/式2-110编号空缺的公式内容是否转写丢失]]）。
- **半角**：$\sin\frac{\alpha}{2}=\sqrt{\frac{1}{2}(1-\cos\alpha)}$（2.111）等；平方根符号必须依半角所处象限确定。
- **和差化积**：$\sin\alpha+\sin\beta=2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$（2.115）等八式（2.115–2.122）。
- **积化和差**：$\sin\alpha\sin\beta=\frac{1}{2}[\cos(\alpha-\beta)-\cos(\alpha+\beta)]$（2.123）等，含三个函数乘积的四式（2.126–2.129）。
- **降幂**：$\sin^2\alpha=\frac{1}{2}(1-\cos 2\alpha)$（2.130）至 $\cos^4\alpha$（2.135）；$n$ 很大时可用 $\cos n\alpha$、$\sin n\alpha$ 表示 $\sin^n\alpha$、$\cos^n\alpha$。

## 同角互换表（表 2.5）

限定 $0<\alpha<\frac{\pi}{2}$ 时，任一函数可用其余三个表示（如 $\sin\alpha=\sqrt{1-\cos^2\alpha}=\frac{\tan\alpha}{\sqrt{1+\tan^2\alpha}}$ 等），其他区间平方根符号依象限决定。全表逐字保留于源摘要页 [[sources/10-数学手册原书第10版--10-27-三角函数角函数--a2ypwy]]。
