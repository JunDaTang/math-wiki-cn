# 函数的相关性

函数的相关性描述具有相同定义域的多个函数之间是否存在函数关系。设 $m$ 个 $n$ 元函数 $u_1, \cdots, u_m$ 在同一区域 $G$ 上定义：若其中一个函数可作为其他函数的函数表示出来，即对 $G$ 中每个点有（《数学手册(原书第10版)》2.18.2.6，式 2.282）

$$u_i = f(u_1, \cdots, u_{i-1}, u_{i+1}, \cdots, u_m) \quad \text{或} \quad \Phi(u_1, u_2, \cdots, u_m) = 0,$$

则称它们为**相依函数**；若不存在这样的函数关系，则称为**独立函数**。两个二元函数的特殊情形为 $f(x,y) = F(\varphi(x,y))$ 或 $\Phi(f, \varphi) = 0$（式 2.281）。

**实例**：

- $u = (x^2+y^2)^2$ 与 $v = \sqrt{x^2+y^2}$（定义域为全平面 $x^2 + y^2 \geqslant 0$）因 $u = v^4$ 而相依；
- $u = \sum_i x_i$、$v = \sum_i x_i^2$、$w = \sum_{i<j} x_i x_j$ 因恒等式 $v = u^2 - 2w$ 而相依。

独立性的解析判据由 [[concepts/雅可比行列式]]（函数行列式）与偏导数矩阵的秩给出，详见 [[findings/函数相关性的定义与相依判据]] 与 [[findings/函数独立性的雅可比判别与秩]]。
