# 向量格与 K 空间（康托洛维奇空间）

向量格（线性格、里斯空间）是任意两个元素都有上确界的有序向量空间；戴德金完备的向量格——每个序上有界的非空子集都有上确界——称作 K 空间（康托洛维奇空间）。正部、负部与模给出向量格中的基本演算工具。

## 动机与定义（12.1.7.4）

在 ℝ¹ 中，(o)有界与通常有界等价，且每个上有界数集都有上确界（lub）与下确界（glb）。在一般的有序向量空间中，上确界与下确界**即使对有穷集也无法保证**，必须以公理方式给出。

有序向量空间 V 称作向量格，是指对任意 x, y ∈ V，存在 z ∈ V 满足：(1) x ≤ z 且 y ≤ z；(2) 若 u 使 x ≤ u 且 y ≤ u，则 z ≤ u。这样的 z 唯一确定，记作 x∨y，称作 x、y 的上确界。向量格中也存在任意两元的下确界 x∧y。

向量格称作**戴德金完备的**，或称作 **K 空间（康托洛维奇空间）**，是指每一个序上有界的非空子集都有上确界（等价地，每一个序下有界的非空子集都有下确界）。

## 逐点计算与算例（式 12.34–12.35）

在向量格 F([a,b]) 中，两个函数的上确界逐点计算：

$$(x \vee y)(t) = \max\{x(t), y(t)\}, \quad \forall t \in [a,b]. \tag{12.34}$$

在 [a,b] = [0,1]、y(t) = t² 的情形下（正文设 x(t) = 1 − (1/3)t，与式内系数矛盾，判定见 [[findings/式12-35正文xt系数与式内不一致之判定]]）：

$$(x \vee y)(t) = \begin{cases} 1 - \frac{3}{2}t, & 0 \leq t \leq \frac{1}{2}, \\ t^2, & \frac{1}{2} < t \leq 1. \end{cases} \tag{12.35}$$

## 谁是向量格、谁不是（防跨主体转移）

- F([a,b])、C([a,b])、B([a,b]) **都是**向量格（12.1.7.4 例 B；见 [[entities/连续函数空间]]、[[entities/函数空间层级]]）。
- **C^(1)([a,b]) 不是向量格**：两个可微函数的最大或最小在 [a,b] 上一般是不可微的——该断言仅关于 C^(1)，不得外推。机制演示见 [[comparisons/向量格与非向量格有序空间比较]]（(12.35) 的上确界在 t = 1/2 处两支斜率不同，产生角点）。

## 格同态（式 12.36）

从向量格 X 到向量格 Y 的线性算子 T 称作向量格同态，是指对所有 x, y ∈ X：

$$T(x \vee y) = Tx \vee Ty \;\;\text{和}\;\; T(x \wedge y) = Tx \wedge Ty. \tag{12.36}$$

## 正部、负部与模（式 12.37–12.39）

对向量格中任意元 x：

$$x_+ = x \vee 0, \qquad x_- = (-x) \vee 0, \qquad |x| = x_+ + x_- \tag{12.37}$$

分别称作 x 的正部、负部和模；三个元都是正的，且

$$x \leq x_+ \leq |x|,\quad x = x_+ - x_-,\quad x_+ \wedge x_- = 0,\quad |x| = x \vee (-x), \tag{12.38a}$$
$$(x+y)_+ \leq x_+ + y_+,\quad (x+y)_- \leq x_- + y_-,\quad |x+y| \leq |x| + |y|, \tag{12.38b*}$$
$$x \leq y \Rightarrow x_+ \leq y_+,\; x_- \geq y_-, \tag{12.38c}$$
$$(\alpha x)_+ = \alpha x_+,\; (\alpha x)_- = \alpha x_-,\; |\alpha x| = \alpha|x| \quad (\alpha \geq 0). \tag{12.38d}$$

（⚠️ 转写注：源文 (12.38b) 首不等式转录为 (x+y)₊ ≤ x₊ + x₋，该命题为假，正确形式为 (x+y)₊ ≤ x₊ + y₊，反例判定见 [[findings/式12-38b首不等式疑误之反例判定]] 与 [[queries/式12-38b首不等式正部相加对象疑误]]；此处按判定结果以 (12.38b*) 标注。）
