# 伯恩斯坦-贝济埃表示

伯恩斯坦-贝济埃表示（Bernstein-Bézier 表示，简记 **B-B 表示**）是以 [[concepts/伯恩斯坦多项式]] 为基、以控制多边形/控制网格顶点位置向量为系数的曲线曲面表示（19.7.3），冠名者 [[entities/伯恩斯坦]] 与 [[entities/贝济埃]]。

## 向量表示（记号铺垫）

```latex
(19.255)  r(t) = x(t)e_x + y(t)e_y + z(t)e_z           （t 为曲线参数）
(19.256)  r(u,v) = x(u,v)e_x + y(u,v)e_y + z(u,v)e_z   （u、v 为曲面参数）
```

## B-B 曲线（19.7.3.1）

设给定位置向量为 P_i 的三维多边形的 n+1 个顶点 P_i（i = 0,…,n），引入向量值函数

```latex
(19.257)  r(t) = Σ_{i=0}^{n} B_{i,n}(t) P_i
```

由这些点确定的空间曲线称为 B-B 曲线。重要性质：

1. P_0 与 P_n 为插值点；
2. 向量 P_0P_1 与 P_{n−1}P_n 为 r(t) 在点 P_0 与 P_n 处的切线（图 19.14）；
3. 由单位分解 (19.254)，公式 (19.257) 可看作给定点的「变量凸组合」。

B-B 表示可用来设计曲线：通过改变多边形的顶点容易改变曲线的形状。

## B-B 曲面（19.7.3.2）

设给定位置向量为 P_ij 的点 P_ij（i = 0,…,n; j = 0,…,m），沿曲面参数曲线考虑网格节点，类似 B-B 曲线 (19.257)：

```latex
(19.258)  r(u,v) = Σ_{i=0}^{n} Σ_{j=0}^{m} B_{i,n}(u) B_{j,m}(v) P_ij
```

改变网格节点就能改变曲面，故 (19.258) 对于曲面设计是有用的。**但每个格点的影响是全局的**，故应该将伯恩斯坦多项式改为 B 样条（[[concepts/B样条（基样条）]]）——全局影响是伯恩斯坦基全局支撑（(0,1) 内恒正）的直接推论。
