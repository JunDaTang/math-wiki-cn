# 贝塞尔不等式

贝塞尔不等式断言：在（可分）希尔伯特空间中，对任意正交规范系 {e_n} 与任意元 x，其傅里叶系数 c_n = (x, e_n) 满足

$$
\sum_{k=1}^{\infty} |c_k|^2 \leqslant \|x\|^2. \tag{12.129}
$$

（转录本将求和指标误排为 n，与求和项 c_k 不一致，见 [[queries/式12-129求和指标不一致]]；上式为校正后形式。）

## 要点

- **适用范围宽**：对任意正交规范系成立，不要求该系完备（见 [[concepts/正交系与正交规范系]]）。
- **证明骨架**：对部分和 σ_n（(12.128)）用毕达哥拉斯定理（(12.117)，见 [[concepts/正交性与正交补]]）得 ‖x‖² = ‖σ_n‖² + ‖x − σ_n‖² ⩾ Σ_{k=1}^n ∣c_k∣²，令 n → ∞。
- **取等条件**：对给定 x 取等当且仅当 x 属于 H₀ = lin{e_n}‾；对一切 x 取等当且仅当系完备，此时即为 [[concepts/帕塞瓦尔等式]]。两者对照见 [[comparisons/贝塞尔不等式与帕塞瓦尔等式比较]]。
