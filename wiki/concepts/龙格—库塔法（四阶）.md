# 龙格—库塔法（四阶）

龙格—库塔法是一族单步法：方程 y′ = f(x,y) 在每点确定解曲线的切线方向；与欧拉法沿该方向直接推进不同，龙格—库塔法在 (x₀, y₀) 与下一可能的点 (x₀+h, y₁) 之间考虑更多的“辅助点”，适当选取附加点以得到更准确的 y₁。依赖辅助点的数目与排列有不同阶的龙格—库塔法；欧拉法即一阶龙格—库塔法（源文明言）。冠名者 [[entities/龙格]]、[[entities/库塔]]。

四阶计算格式 (19.99)：

| x | y | k = h·f(x, y) |
|---|---|---|
| x₀ | y₀ | k₁ |
| x₀ + h/2 | y₀ + k₁/2 | k₂ |
| x₀ + h/2 | y₀ + k₂/2 | k₃ |
| x₀ + h | y₀ + k₃ | k₄ |
| x₁ = x₀ + h | y₁ = y₀ + 1/6(k₁ + 2k₂ + 2k₃ + k₄) | |

**性质**（归属本方法）：每步误差为 h⁵ 阶；四阶收敛 p = 4、四阶相容 p = 4；对特殊方程 y′ = f(x) 化为辛普森公式（19.3.2.3，未入库）；步长加倍误差估计 R₂(h) ≈ (1/15)[y₂(h) − y₂(2h)]（式 19.100，系数 1/(2⁴−1) 复算吻合）；高阶方程化为一阶方程组后可并行计算。

**已验证算例**（复算通过）：y′ = ¼(x²+y²)，y(0)=0，h=0.5 单步得 y₁ = 0.01041858（准确值 0.01041860），见 [[findings/式19-99四阶龙格—库塔格式与算例复算]]。与欧拉法比较见 [[comparisons/欧拉多边形法与四阶龙格—库塔法比较]]；流程见 [[methodology/四阶龙格—库塔法单步计算流程]]、[[methodology/步长加倍精度检验流程]]。
