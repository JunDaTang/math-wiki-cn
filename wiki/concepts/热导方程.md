# 热导方程

热导方程（源用名；中文文献通称“热传导方程”，此为独立可验证的通行别称）是描述均匀介质中热的传播的二阶线性抛物型偏微分方程，一般形式为式 9.108a：∂u/∂t − a²Δu = Q(x, t)，其中 Δ 为 [[拉普拉斯算子]]（该处称“由位置向量 r⃗ 确定的三个传播方向 x₁, x₂, x₃ 定义的三维拉普拉斯算子”）；热流既无源又无汇时右端 Q 为零。

## 柯西问题与唯一性

源提出的柯西问题为：对 t > 0 确定满足 u|_{t=0} = f(x) 的**有界解** u(x, t)；**有界性的要求保证了解的唯一性**（源明示；对照 [[波方程]] 柯西问题无须此附加要求，见 [[三类典型二阶线性偏微分方程比较]]）。

## 齐次问题的解（高斯核）

式 9.108b：u(x₁,x₂,x₃,t) = 1/(2a√(πt))ⁿ ⋅ ∭ f(α₁,α₂,α₃) exp(−|x−α|²/(4a²t)) dα₁dα₂dα₃，积分限均为 −∞ 到 +∞。前因子 (2a√(πt))ⁿ = (4πa²t)^{n/2}，即标准热核（高斯核；源未命名该核，“热核/高斯核”为通行术语，独立可验证背景）。源在此处称得到“波函数 (wave function)”，疑为波方程节语句误植（见 [[热导方程的解为何被称为波函数]]）。

## 非齐次问题的附加项

式 9.108c：∫₀ᵗ [以 (t − τ) 为时间参数的热核对 Q 的卷积] dτ，属杜哈梅尔型卷积结构（源未用“杜哈梅尔”之名，见 [[非齐次线性偏微分方程的齐次化与杜哈梅尔型代换]]）。源印作 Q(α₁, α₂, α₃)，数学上须为 Q(α₁, α₂, α₃, τ)，疑缺 τ 变元（见 [[式9-108c的Q是否缺tau变元]]）。

## 时间不可逆性

源明示：如果给出值 u(x, 0)，用这个方法不能解确定 t < 0 时 u(x, t) 的问题，因为在此情形不能正确形成柯西问题——即 t < 0 方向不适定（时间不可逆）。**此性质仅属热导方程**，不可外推到波方程。

## 温度场形式

由于温度差正比于热量，引进 u = T(r⃗, t)（温度场）与 a² = D_W（源称“热扩散常数或热导率”；严格而言 D_W 是热扩散率，与热导率是不同物理量，中译并称有不确之嫌），得式 9.108d：∂T/∂t − D_W ΔT = Q_W(r⃗, t)。

## 同构方程

[[扩散方程]]（式 9.109）与热导方程由相同的线性偏微分方程描述：浓度传播与热传导数学同构，将 D_W 换为 D_C 即得其解。

## 转写疑点

- 9.2.3.3.1 标题为“三维热导方程”，而式 9.108b/c 的前因子指数为 n（n 维一般形式）、积分为三重积分，两者不一致（见 [[式9-108b指数n与三维标题是否原书即不一致]]）。
- 9.2.3.3.2 称“在波方程的解 (9.108b)(9.108c) 中改变记号即得到 (9.109) 的解”，“波方程”疑为“热导方程”之误（见 [[式9-108b与9-108c是否被误称为波方程的解]]）。
