# 线性规划标准形式

线性规划标准形式是变量全部非负、约束全部为等式、目标一律求极大的统一形式（式 18.5a/b）：

```text
OF:  f(x) = cᵀx = max!
CT:  Ax = b,  x ⩾ 0
```

坐标形式（式 18.4a/b）为 f(x) = c₁x₁ + ⋯ + cₙxₙ = max!，约束 a_{i,1}x₁ + ⋯ + a_{i,n}xₙ = bᵢ（i = 1,…,m），x_j ⩾ 0（j = 1,…,n）。

## 由来与用途

标准形式由一般形式（式 18.1/18.2）经四步归约得到（详见 [[methodology/线性规划标准化流程]]）：「⩾」约束乘 (−1)；极小问题化为 −f = max!（式 18.3）；自由变量分解 xₖ = xₖ¹ − xₖ²；不等式加[[concepts/松弛变量]]化为等式。手册特别指出，「在应用某些解法时」仅考虑非负变量与等式约束——标准形式是后续解法（预期为 18.1.2 及以后的单纯形法类方法）的统一入口，见 [[queries/18-1-1未入库回指缺口]]。

## 维数假定

一般可假定 m ⩽ n，否则方程组 Ax = b 会包含线性相关或相互矛盾的方程。（手册把「线性相关」与「矛盾」并列为仅有的两种可能，表述略粗：相关方程仍可能相容。）

## 转录疑点

原文「问题可以在 (18.4a,18.4b) 给出的形式下进行研究这里□是增加了的变量数」脱一主字（疑为 n，指标准化后增加的变量总数），见 [[queries/标准化叙述脱字疑为n之辨]]。
