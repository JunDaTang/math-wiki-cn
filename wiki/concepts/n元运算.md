# n 元运算

n 元运算是从笛卡儿幂 Aⁿ 到 A 的映射 φ，它对 A 中元素的每个 n 元组指派 A 中的一个元素。《数学手册(原书第10版)》5.3.1 节将其作为运算定义链的第一级：代数结构即「在其上定义了（n 元）运算的集合」。

## 定义

$$
\varphi : A^{n} \to A
$$

即对每个 n 元组指派 A 的一个元素；运算的「元数」即 n。

## 特例与后续

- n = 2：[[concepts/二元运算]]，本节称这一情形「特别重要」，是本章（5.3）多数场合使用的情形。
- n = 1：一元运算（本节未单独展开）。

## 转写注记

原文作「$\varphi : A^{n} A$」，映射箭头 → 脱落；「它对千每个 的元素的 组指派 的一个元素」中「对千」应为「对于」，n 与 A 脱落。复原详见 [[queries/5-3-1全节转写讹误清单]]。
