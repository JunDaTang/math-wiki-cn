# 汉明距离与最小距离

两个码字的（汉明）距离是指两码字数字不同的位置的个数。码 C 的**最小距离** d_min(C) 是其码字间距离的最小值，是衡量检错/纠错能力的核心参数。

## t-纠错判据

如果 d_min(C) ≥ 2t+1，那么 C 是 t-纠错码（可纠正 t 个传输差错）。据此：

- C1 = {0000, 1111}：d_min = 4 ⇒ [1]-纠错码；
- C2 = {000, 011, 101, 110}：d_min = 2 ⇒ [0]-纠错码（不能纠错）；
- C3 = {00000, 01101, 10111, 11010}：d_min = 3 ⇒ [1]-纠错码。

（源文中三个 t 值均被转写脱落；三个 d_min 已全部复算，见 [[findings/三码例最小距离与纠错能力]]。）

## 在线性码中的简化

线性码（[[concepts/线性码]]）的最小距离等于零向量与非零码字间的最小距离，即非零码字的最小重量（非零数字的个数），因此无需两两比较即可求 d_min。
