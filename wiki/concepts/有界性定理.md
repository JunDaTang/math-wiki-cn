# 有界性定理

有界性定理（手册称“函数有界性定理”）断言：若函数 $f(x)$ 在有限闭区间 $[a,b]$ 上连续，则它在该区间上有界，即存在两个数 $m$、$M$，使得

```
m ⩽ f(x) ⩽ M,   a ⩽ x ⩽ b.    (2.34)
```

## 与相关概念、定理的关系

- 这是 [[concepts/有界函数]] 概念在闭区间连续情形下的自动保证：连续性 + 有限闭区间 ⟹ 有界，无需另行验证。
- [[concepts/魏尔斯特拉斯定理]]（式 2.35）更强：不仅存在这样的 $m$、$M$，且它们作为函数值被实际取得（分别为绝对最小值与绝对最大值）。
- 定理依赖“有限闭区间”这一条件；各定理条件的对照见 [[comparisons/闭区间上连续函数定理比较]]。
