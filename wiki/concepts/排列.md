# 排列

排列（本手册中指部分排列：源文引言作「部分排列或排列」）是从 n 个不同元素中任取 k 个元素并依一定顺序排成一列的构造——源文将其表述为「考虑元素顺序的组合」，即在同一模型中兼顾选取与排序，k < n 亦适用。这是「从 n 个元素中取出 k 个」框架中「选取＋排序」的情形。

## 无重复排列

从 n 个不同元素中选取 k 个不同元素并依不同顺序排列，排列数为

$$\mathrm{V}_n^{(k)} = k!\binom{n}{k} = n(n-1)(n-2)\cdots(n-k+1), \quad 0 \leqslant k \leqslant n \tag{16.6}$$

两个表达式等价：k!·C(n,k) = n!/(n−k)!，显示「排列 = 组合 × 组内全排列」。

例：从 30 位候选人中选出一名主席、一名副主席以及第一助理和第二助理各一名，共有 C(30,4)·4! = 657720 种选举方法（等价于 V₃₀⁽⁴⁾ = 30·29·28·27）。

## 有重复排列

从 n 个不同元素中选取 k 个按照一定顺序排成一列，每个元素可取任意多次，排列数为

$$\mathrm{V}_n^{(k)} = n^k \tag{16.7}$$

即 k 个位置各自独立地在 n 个元素中选择。此时 k 可大于 n。

例 A：一场 Toto 杯足球赛共有 3¹² 种不同比赛结果（每场比赛胜/平/负三态；源文题面「12 支队伍」与公式不相容，见 [[queries/托托杯例十二支队伍疑为十二场比赛]]）。
例 B：使用 8 位数字单元（一个字节）可表示 2⁸ = 256 个不同字符（源文提及 ASCII 表；严格说标准 ASCII 为 7 位 128 字符，2⁸ 对应 8 位扩展编码）。

## 记号与术语考按

- 记号警示：Vₙ⁽ᵏ⁾ 在 (16.6) 与 (16.7) 中一号两义，仅凭「是否允许重复」消歧。
- 术语对照：本手册「排列」相当于中文通用教材的「选排列」Aₙᵏ；通用语境的「排列」概念涵盖 k = n 的情形，而本手册将其单列为独立概念（[[concepts/全排列]]）。
- V 记号在中文文献罕见；「全排列／组合／排列」三分的编排当源自德文底本 Permutation／Kombination／Variation 三分法（推断：Toto 例的德国足球博彩背景为旁证，非源文明言）。
