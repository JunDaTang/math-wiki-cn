# 宇称（奇偶性）

宇称（parity，手册称「奇偶性」）是刻画波函数在空间反演 r⃗ → −r⃗（手册 4.3.5.1，未入库）下行为的性质。反演通过反演算子（奇偶性算子）P 实行：PΨ(r⃗,t) = Ψ(−r⃗,t)；作用两次必定产生原来的波函数，故

```latex
P^{2}=1,\qquad P=\pm 1   % 9.141b
```

在空间反演下不改变符号的波函数称为偶波函数，改变符号的称为奇波函数。

## 中心对称场中的宇称（9.140b–9.141a）

径向量关于原点反射时 (ϑ, φ) → (π−ϑ, φ+π)，球面调和函数满足

```latex
Y_l^{m}(\pi-\vartheta,\varphi+\pi)=(-1)^{l}Y_l^{m}(\vartheta,\varphi)   % 9.140b
P=(-1)^{l}                                                              % 9.141a
```

即中心场波函数的宇称由角量子数 l 的奇偶性决定（推导链见 [[entities/球面调和函数]]、[[concepts/中心对称场中的粒子运动]]）。

## 记号注记

源文 9.141b 前文将奇偶性算子 P 与其本征值 P 连写为「PPΨ(r⃗,t) = PPΨ(r⃗,t) = Ψ(r⃗,t)」，两处 P 含义不同（算子/本征值），阅读时须区分。
