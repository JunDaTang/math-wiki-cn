# 沃尔泰拉积分方程

沃尔泰拉积分方程（Volterra integral equation）是积分上限为变元 x（a(x) ≡ a 且 b(x) ≡ x）的线性 [[concepts/积分方程]]，是数学手册(原书第10版)第 11 章的两大基本类型之一，也是 11.1 节中唯一被显式建立「与微分方程初值问题直接转化」关系的类型。按第一类/第二类之分，其代表式为

$$
0 = f(x) + \lambda \int_{a}^{x} K(x, y)\, \varphi(y) \,\mathrm{d}y, \tag{11.2c}
$$

$$
\varphi(x) = f(x) + \lambda \int_{a}^{x} K(x, y)\, \varphi(y) \,\mathrm{d}y. \tag{11.2d}
$$

其中 (11.2c) 为第一类，(11.2d) 为第二类。

## 与初值问题的转化

对 x ⩾ x₀、y(x₀) = y₀ 的始值问题 y′(x) = f(x, y)，从 x₀ 积分到 x 得

$$
y(x) = y_{0} + \int_{x_{0}}^{x} f(\xi, y(\xi)) \,\mathrm{d}\xi, \tag{11.3}
$$

这是变上限的积分方程（属沃尔泰拉型结构；被积函数非线性时为 (11.2d) 的非线性推广）。当 f(ξ, y(ξ)) = a(ξ)y(ξ) + b(ξ)（即原 ODE 线性）时，(11.3) 化为第二类沃尔泰拉积分方程：g ≡ 1、下限 x₀、扰动函数 y₀ + ∫b(ξ)dξ、λ = 1、核 a(ξ)。推导与复算见 [[methodology/初值问题积分化流程]] 与 [[findings/式11-1至11-3定义分类与初值问题积分化转录复算]]。

## 要点与注意事项

- 判定特征：a(x) ≡ a，b(x) ≡ x（变上限）。
- K(x, y) 为核，f(x) 为扰动函数，均可取复值；λ 通常为复参数。
- 若 f(x) ≡ 0 则为齐次方程，否则非齐次。
- 第一类方程采用 `0 = f(x) + λ∫…` 符号约定，见 [[queries/第一类积分方程符号约定]]。
- 命名源自数学家 Volterra，本源未提供人物背景；求解理论属第 11 章后续小节，尚未入库（见 [[queries/11-1未入库回指缺口]]）。
