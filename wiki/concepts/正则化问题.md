# 正则化问题

正则化问题是源（4.5.3.2 第 3 条）在秩亏情形（rank(A) < n，源作「秩亏格」，用语存疑见 [[queries/秩亏格用语是否原文如此]]）代替线性最小二乘问题 (4.189) 而考虑的问题（式 4.191）：

```
rᵀr + α xᵀx = min!      (α > 0)                                    (4.191)
```

其中 α > 0 称为正则化参数。其正规方程为（式 4.192）：

```
(AᵀA + αI) x = Aᵀb                                                   (4.192)
```

当 α > 0 时该线性方程组的系数矩阵正定并且正则；但源指出，**选取合适的正则化参数是一个困难的问题**（引文献 [4.7]，信息不透明）。

## 引入动机

秩亏时（rank(A) < n）：正规方程组 AᵀA x = Aᵀb（见 [[concepts/正规方程组与高斯变换]]）不再有唯一解（AᵀA 不再正定），并且正交化方法（[[concepts/豪斯霍尔德方法]]）给出无用的结果；于是代替 (4.189) 考虑附加 αxᵀx 项的问题 (4.191)，使极小问题重新良定。

## 命名说明

式 (4.191)–(4.192) 在数学上即 Tikhonov 正则化（岭回归的线性代数形式）的标准形态；**源中未使用该名称**，本页以源用词「正则化问题」为主标题，Tikhonov 正则化仅作辨义别名（独立背景知识，非源文内容）。记录见 [[findings/正则化与数值方法建议]]。
