# 线性丢番图方程

线性丢番图方程是 [[concepts/丢番图方程]] 的线性特例：未知数只以一次整系数形式出现，标准形为（式 5.240）

a₁x₁ + a₂x₂ + ⋯ + aₙxₙ = b，其中 aᵢ ∈ ℤ、b ∈ ℤ，

且只求整数解 (x₁,…,xₙ) ∈ ℤⁿ。由于解被限定在整数上，可解性由系数的最大公约数决定，解集则呈「特解 + 自由参数格」的结构。

## 可解性判据

系数 aᵢ 不全为零时，方程可解**当且仅当 gcd(a₁, a₂, …, aₙ) 整除 b**。详见 [[findings/线性丢番图方程可解性判据与无穷解结构]]。

环论表述（推断性旁注）：方程有解 ⟺ b ∈ a₁ℤ + ⋯ + aₙℤ = (gcd(a₁,…,aₙ))，即 b 属于系数生成的主理想；ℤ 是主理想环（参见 [[concepts/理想]]、[[concepts/主理想]]）。

## 解集结构

- n > 1 且 ℤ 为变量区域：有解则有无穷多解，解集含 **n−1 个自由变量**；结构为「任一特解 + 齐次部分的整数参数化」。
- **限定（勿泛化）**：n−1 自由变量的命题只对变量区域 ℤ 成立；对 ℤ 的子集（例如 ℕ），手册明示该命题不正确。
- 形式上，这与线性映射的「特解 + 核」分解（[[concepts/核与象]]）平行：整数解集是仿射格 {x : a·x = b} = x⁰ + {x : a·x = 0}（类比层面）。

## 解法

- **n = 2**：用 gcd(a₁,a₂) 除方程得 a₁′x₁+a₂′x₂=b′（gcd(a₁′,a₂′)=1），由贝祖组合 a₁′c₁′+a₂′c₂′=1（整数版扩展欧几里得算法，原书 5.4.1.4, 4.，未入库；与 5.3.7 的多项式版 [[concepts/带余除法与欧几里得算法]] 平行）得特解 (c₁′b′, c₂′b′)；若 (x₁⁰, x₂⁰) 是任一特解，则全部解为

  {(x₁⁰ + t·a₂′, x₂⁰ − t·a₁′) | t ∈ ℤ}（式 5.241b）

  ——注意通解步长是**约化后**的系数 a₁′, a₂′。算例与一处已验证的书中解集讹误见 [[findings/二元线性丢番图方程通解与114x315y6算例]]。
- **n > 2**：逐次降元的归约方法——固定 xₙ 后的可解条件等价于二元方程 gcd(a₁,…,aₙ₋₁)·c + aₙ·cₙ = b 的可解性（式 5.242d），递归至 n=2 封闭。流程与理据见 [[methodology/多元线性丢番图方程归约求解流程]]，全程复算的算例见 [[findings/三元线性丢番图方程归约算例2x4y3z3]]。
