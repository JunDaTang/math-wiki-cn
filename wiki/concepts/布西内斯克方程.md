# 布西内斯克方程

**布西内斯克方程**（Boussinesq，9.2.5.5.3）为

```latex
u_{xx} − u_{tt} + (u^2)_{xx} + u_{xxxx} = 0        (9.176)
```

源文称它出现在非线性电网络中，作为电荷—电压关系的一种连续逼近的描述。本源对这一方程仅有一句陈述，未给出解式（形式核对见 [[findings/式9-172至9-179附加七方程复算]]）。
