# 全排列

全排列是把给定集合的全部元素按一定顺序排成一列的构造，对应「从 n 个元素中取出 k 个」框架中 k = n 的纯排序情形——所有元素都参与，唯一的变化自由度是次序。16.1 节按元素是否含重复类给出三个公式。

## 无重复全排列

n 个互异元素的不同全排列数是

$$\mathrm{P}_n = n! \tag{16.1}$$

例：16 名学生坐到教室的 16 个座位上，共有 16! = 20922789888000 种不同坐法。

## 有重复全排列（单类重复）

若 n 个元素中有 k（k ≤ n）个元素相同，则不同的全排列数为

$$\mathrm{P}_n^{(k)} = \frac{n!}{k!} \tag{16.2}$$

例：把 16 个学生的书包放到教室的 16 把椅子上，其中 4 个书包相同，共有 16!/4! = 871782912000 种放置方式。

注意：该式隐含「其余 n−k 个元素互异」的前提，源文未明示；它是 (16.3) 的单类特例。

## m 类重复的推广（多项式系数）

n 个元素包含 m 类不同元素，各类重数为 k₁, k₂, …, kₘ（k₁ + k₂ + ⋯ + kₘ = n），则不同的全排列数为

$$\mathrm{P}_n^{(k_1,\dots,k_m)} = \frac{n!}{k_1!\, k_2! \cdots k_m!} \tag{16.3}$$

例：用数字 4, 4, 5, 5, 5 构造五位数，可组成 P₅^(2,3) = 5!/(2!·3!) = 10 个不同的数（源文数字列表疑脱一「5」，见 [[queries/五位数例数字列表疑脱第五个数字]]）。

## 与相关概念的界线

- 与 [[concepts/组合]] 的区别：组合不计顺序，全排列纯讲顺序（且全员参与）。
- 与 [[concepts/排列]] 的区别：排列只取部分元素（k < n 亦适用）再排序；全排列要求 k = n。
- 记号警示：本手册 Pₙ⁽ᵏ⁾ 的上标 (k) 表示「k 个元素相同」的重数，与 Cₙ⁽ᵏ⁾、Vₙ⁽ᵏ⁾ 中「取 k 个」的含义不同；同一字母 k 在表 16.1 各行语义不一，见 [[comparisons/全排列组合排列无重复有重复公式比较]]。
