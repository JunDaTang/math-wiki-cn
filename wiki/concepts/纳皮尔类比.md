# 纳皮尔类比

纳皮尔等式（也称纳皮尔类比，Napier's analogies）是连接半差/半和量的四个等式：

```
tan((α−β)/2) = [sin((a−b)/2) / sin((a+b)/2)] · cot(γ/2)    (3.199a)
tan((α+β)/2) = [cos((a−b)/2) / cos((a+b)/2)] · cot(γ/2)    (3.199b)
tan((a−b)/2) = [sin((α−β)/2) / sin((α+β)/2)] · tan(c/2)    (3.199c)
tan((a+b)/2) = [cos((α−β)/2) / cos((α+β)/2)] · tan(c/2)    (3.199d)
```

以纳皮尔冠名（John Napier，对数的发明者——此身份为可独立验证的背景知识，非出自本手册；本节原文拼作 Neper）。

从这些公式可以推出与平面正切定律类似的 [[concepts/球面正切定律]]（式 3.200）。手册将它们与 [[concepts/德朗布尔等式]] 一同归入 3.4.2.3「更多的公式」小节。
