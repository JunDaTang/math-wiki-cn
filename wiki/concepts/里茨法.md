# 里茨法

里茨法是边值问题逼近系数确定四原则中的变分型方法，冠名者 [[entities/里茨]]：解 y(x) 常有使得变分积分极小化的性质

```latex
(19.127)  I[y] = \int_a^b H(x, y, y')\, dx        （见 (10.4)，未入库）
(19.128)  \frac{\partial I}{\partial a_i} = 0   (i = 1, 2, \dots, n)
```

若函数 H(x, y, y′) 已知，则将 y(x) 换为 (19.121) 中的近似函数 g(x)（I[y] = I(a₁, a₂, …, a_n)）极小化；由必要条件 (19.128) 得到系数 a_i 的 n 个方程。

H 的来源：对自伴边值问题 (19.129)，由变分问题 (19.130) 立即得到 H(x,y,y′)，见 [[concepts/边值问题与变分问题等价性]]。四原则比较见 [[comparisons/逼近系数确定四原则比较]]。
