# 热传导方程

**热传导方程**（本手册亦写作“热导方程”）描述温度场随时间的演化。手册在两处涉及该方程：

- **9.2.2**：给出一维形式（式 9.96a），是描述均匀介质中温度传播的二阶线性抛物型偏微分方程；
- **13.3.3 定理例 C**：从热平衡出发推导三维形式，是高斯积分定理（见 [[高斯积分定理]]）的一个典型物理应用，描述不含热源的空间区域中温度场 $T(x,y,z,t)$ 随时间的演化。

## 一维形式与分类（9.2.2）

一维热传导方程：

$$\frac{\partial u}{\partial t} = a^{2} \frac{\partial^{2} u}{\partial x^{2}} \tag{9.96a}$$

（C = 0 → 判别式 δ = 0，抛物型。）

## 三维形式的物理推导（13.3.3 例 C）

1. 区域 $v$ 中热量随时间的变化：

$$\frac{\mathrm{d}Q}{\mathrm{d}t} = \iiint_{v} c\varrho\,\frac{\partial T}{\partial t}\,\mathrm{d}v,$$

其中 $c$ 为比热容、$\varrho$ 为密度、$T$ 为温度。

2. 热流通过边界曲面 $S$ 的相应依赖时间的变化：

$$\frac{\mathrm{d}Q}{\mathrm{d}t} = \oiint_{S}\lambda\operatorname{grad}T\cdot\mathrm{d}\vec{S},$$

其中 $\lambda$ 为热导率。

3. 对面积分应用高斯积分定理 (13.120a)，得

$$\iiint_{v}\left[c\varrho\,\frac{\partial T}{\partial t} - \operatorname{div}(\lambda\operatorname{grad}T)\right]\mathrm{d}v = 0,$$

从而逐点推出热导方程

$$c\varrho\,\frac{\partial T}{\partial t} = \operatorname{div}(\lambda\operatorname{grad}T).$$

4. 均匀物体（$c,\varrho,\lambda$ 均为常数）时化为

$$\frac{\partial T}{\partial t} = a^{2}\triangle T.$$

一维情形下（$\triangle$ 化为 $\partial^{2}/\partial x^{2}$）即式 (9.96a) 的形式。

## 半无限杆算例（9.2.2 例 E）

区域 0 ≤ x < +∞、t ≥ 0，初始与边界条件 u|_{t=0} = f(x)、u|_{x=0} = 0，并设无穷远处温度趋于零。分离变量 u = X(x)T(t) 给出 T(t) = C_λ e^{−λ²a²t} 与 X = C sin λx，其中 λ 为任意实数——**连续谱**。解为傅里叶正弦积分：

$$u(x,t) = \int_0^{\infty} C(\lambda)\,e^{-\lambda^{2}a^{2}t}\sin\lambda x\,\mathrm{d}\lambda,\qquad C(\lambda) = \frac{2}{\pi}\int_0^{\infty} f(s)\sin\lambda s\,\mathrm{d}s$$

利用 sin·sin 化余弦差并求内层积分（手册回指表 21.8.2 公式 (21.27) 与式 (2.122)，均未入库），得热核镜像组合：

$$u(x,t) = \int_0^{\infty} f(s)\,\frac{1}{2a\sqrt{\pi t}}\left[\exp\!\left(-\frac{(x-s)^{2}}{4a^{2}t}\right) - \exp\!\left(-\frac{(x+s)^{2}}{4a^{2}t}\right)\right]\mathrm{d}s \tag{9.96l}$$

复算：1/(2a√(πt)) = 1/√(4πa²t)，两项分别为热核在 s 与 −s（奇延拓镜像）处的取值，与 9.96k 的推导一致 ✓。

完整转录复算见 [[式9-96半无限杆热传导复算]]。

## 转写疑误

**9.2.2**

- 转写将式号 9.96l 误作“9.961”（l→1 讹误）。

**13.3**

- 转写正文把结果式左端系数写作 $c\lambda$，与推导链（及第 1 步的 $c\varrho$）矛盾，应为 $c\varrho$，见 [[热导方程例中cλ疑为cρ]]。
- $a^2$ 未在 13.3 本节定义；由常数情形 $c\varrho\,\partial_t T=\lambda\triangle T$ 可推出 $a^2=\lambda/(c\varrho)$（此为推断，非原文明示），见 [[热导方程a²未定义]]。
