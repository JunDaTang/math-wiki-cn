# 拉普拉斯变换的运算规则

拉普拉斯变换的运算规则是从原始域（时域）内的运算到变换空间（像域）内运算的映射。《数学手册(原书第10版)》15.2.1.2 共给出 11 条规则（式 15.9–15.24），是 [[concepts/拉普拉斯变换]] 操作体系的主体；本页照录全表。

| 式号 | 规则 | 公式 |
|---|---|---|
| (15.9) | 1. 线性法则 | $\mathcal{L}\{\sum\lambda_i f_i\}=\sum\lambda_i F_i$ |
| (15.10a/b) | 2. 相似法则 | $\mathcal{L}\{f(at)\}=\frac1aF(p/a)$；$\mathcal{L}^{-1}\{F(ap)\}=\frac1a f(t/a)$ $(a>0)$ |
| (15.11a) | 3. 右平移 | $\mathcal{L}\{f(t-a)\}=e^{-ap}F(p)$ |
| (15.11b) | 3. 左平移 | $\mathcal{L}\{f(t+a)\}=e^{ap}[F(p)-\int_0^a e^{-pt}f(t)\,dt]$ |
| (15.12) | 4. 频移定理 | $\mathcal{L}\{e^{-bt}f(t)\}=F(p+b)$ |
| (15.13) | 5. 原空间微分 | $\mathcal{L}\{f^{(n)}\}=p^nF(p)-f(+0)p^{n-1}-f'(+0)p^{n-2}-\cdots-f^{(n-1)}(+0)$ |
| (15.14) | 5 之推论（展开式） | $\mathcal{L}\{f\}=\frac{f(+0)}p+\frac{f'(+0)}{p^2}+\cdots+\frac{f^{(n-1)}(+0)}{p^{\,n-1}}+\frac1{p^n}\mathcal{L}\{f^{(n)}\}$ |
| (15.15/15.16) | 6. 像空间微分 | $\mathcal{L}\{t^nf\}=(-1)^nF^{(n)}(p)$；$\mathcal{L}\{(-1)^nt^nf\}=F^{(n)}(p)$ |
| (15.17a/b) | 7. 原空间积分 | $n$ 重积分 $\mapsto F(p)/p^n$；单积分 $\mathcal{L}\{\int_0^t f\,d\tau\}=F(p)/p$ |
| (15.18) | 8. 像空间积分 | $\mathcal{L}\{f/t^n\}=\frac{1}{(n-1)!}\int_p^\infty(z-p)^{n-1}F(z)\,dz$ |
| (15.19) | 9. 除法法则 | $\mathcal{L}\{f/t\}=\int_p^\infty F(z)\,dz$ |
| (15.20a/b) | 10. 参数微分/积分 | $\mathcal{L}$ 与 $\partial/\partial\alpha$、$\int d\alpha$ 可交换 |
| (15.21–15.22) | 11. 单侧卷积及代数律 | $f_1*f_2=\int_0^t f_1(\tau)f_2(t-\tau)\,d\tau$，满足交换、结合、分配律 |
| (15.23) | 11. 卷积定理 | $\mathcal{L}\{f_1*f_2\}=F_1(p)F_2(p)$，见 [[concepts/卷积与卷积定理]] |
| (15.24) | 11. 复卷积 | 见 [[concepts/复卷积]] |

## 使用注记

- **(15.11a) 的隐含约定**：右平移记法依赖因果零延拓 $f(t)\equiv0\ (t<0)$（源书图 15.4 支持），否则 $f(t-a)$ 在 $(0,a)$ 上的取值无定义。
- **(15.14) 疑点**：倒数第二项分母 $p^{n-1}$ 与 (15.13) 反解结果及通项规律 $f^{(k)}(+0)/p^{k+1}$ 冲突，疑应为 $p^n$，见 [[queries/式15-14倒数第二项分母p的n-1次疑为n次]]。
- **(15.13) 在跳跃情形的修正**：分段函数套用 (15.13) 时初值应取左极限，见 [[queries/δ方法初值句应该用何值代替疑为左极限f减0系列]] 与 [[methodology/分段函数拉普拉斯变换的δ导数法]]。
- **(15.18) 的路径条件**：积分路径可以是始于 $p$ 点、与实轴正半轴成锐角的任意射线。
- **(15.17a) 的卷积核形式**：$n$ 重积分等于与 $\frac{(t-\tau)^{n-1}}{(n-1)!}$ 的卷积，是卷积 ([[concepts/卷积与卷积定理]]) 在积分规则中的体现。
- 相似法则算例（源书）：由 $\mathcal{L}\{\sin t\}=1/(p^2+1)$ 得 $\mathcal{L}\{\sin\omega t\}=\omega/(p^2+\omega^2)$，复算一致。

转写缺损（规则编号 5、6、8 丢失，(15.17b)、(15.18) 后条件句缺损等）汇总于 [[queries/15-2-1全节系统性转写讹误清单]] 与 [[queries/式15-17b与15-18后条件句缺损之辨]]。
