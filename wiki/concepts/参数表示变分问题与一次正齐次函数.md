# 参数表示变分问题与一次正齐次函数

**利用参数表达式的变分问题**（10.3.6）：对某些变分问题，不以显式 y = y(x) 而以参数形式 x = x(t)、y = y(t)（t₁ ⩽ t ⩽ t₂，正文该节 ẋ 多处讹作「土」）确定极值是有帮助的。简单变分问题化为

$$I[x, y] = \int_{t_1}^{t_2} F(x(t), y(t), \dot x(t), \dot y(t))\,\mathrm{d}t = \text{极值!} \quad (10.39a)$$

边界条件为 x(t₁) = a、x(t₂) = b、y(t₁) = A、y(t₂) = B（10.39b）。

## 一次正齐次函数（10.40）

参数式变分问题仅当积分值与极值曲线的参数表示无关时才有意义。为此 F 须是**一次正齐次函数**（positive homogeneous function）：

$$F(x, y, \mu\dot x, \mu\dot y) = \mu\,F(x, y, \dot x, \dot y) \quad (\mu > 0) \quad (10.40)$$

## 欧拉微分方程与魏尔斯特拉斯形式

把 (10.39a) 视为数个未知函数情形的特例，得两个欧拉微分方程（10.41）：

$$\frac{\partial F}{\partial x} - \frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial F}{\partial \dot x} = 0, \qquad \frac{\partial F}{\partial y} - \frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial F}{\partial \dot y} = 0$$

这两个方程并非相互独立，它们等价于欧拉微分方程的**魏尔斯特拉斯形式**（Weierstrass form）：

$$\frac{\partial^2 F}{\partial x\,\partial \dot y} - \frac{\partial^2 F}{\partial \dot x\,\partial y} + M(\dot x\ddot y - \ddot x\dot y) = 0 \quad (10.42a)$$

其中（由一次正齐次性，三个二阶导数表达式相等）

$$M = \frac{1}{\dot y^2}\frac{\partial^2 F}{\partial \dot x^2} = -\frac{1}{\dot x\dot y}\frac{\partial^2 F}{\partial \dot x\,\partial \dot y} = \frac{1}{\dot x^2}\frac{\partial^2 F}{\partial \dot y^2} \quad (10.42b)$$

## 极值曲线的曲率半径

结合参数曲线曲率半径的计算（参见 3.6.1.1,1.，第3章）并考虑到 (10.42a)：

$$R = \left|\frac{(\dot x^2 + \dot y^2)^{3/2}}{\dot x\ddot y - \ddot x\dot y}\right| = \left|\frac{M(\dot x^2 + \dot y^2)^{3/2}}{F_{\dot x y} - F_{x\dot y}}\right| \quad (10.42c)$$

## 算例：参数式等周问题

[[等周问题]]以参数表述（10.43a–b），取 H = yẋ + λ√(ẋ²+ẏ²)（10.43c）；H 满足 (10.40)，故为一次正齐次函数。算得 M = λ/(ẋ²+ẏ²)^{3/2}、H_{ẋy} = 1、H_{xẏ} = 0（10.43d），代入 (10.42c) 得 R = |λ|：λ 是常数，故极值曲线是圆周。复算通过，见 [[findings/第10章诸算例闭式复算通过清单]]。
