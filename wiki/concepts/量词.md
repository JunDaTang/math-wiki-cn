# 量词（∀ 与 ∃）

量词是谓词逻辑的特色工具，作用于谓词得到语句：

- **全称量词** ∀（「对于每个」）：∀xP(x) 表示「P(x) 对于 X 中的每个 x 真」；
- **存在量词** ∃（「对于某个」）：∃xP(x) 表示「在 X 中存在使 P(x) 真的 x」。

主要定律（式 5.23–5.33）：

- 否定律 (5.23) 使 ∀ 与 ∃ 可互相由对方表示 (5.24)；
- 同类量词可交换 (5.25–5.26)；∀ 与 ∃ 之间**不可交换**——(5.33) 之逆为假；
- ∀ 对 ∧、∃ 对 ∨ 有分配**等价** (5.27–5.28)；交错方向仅为**单向蕴涵** (5.29–5.30)，逆不成立。
