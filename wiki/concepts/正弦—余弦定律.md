# 正弦—余弦定律

正弦—余弦定律是球面三角学中同时含正弦与余弦的五量关系式（式 3.189），连同其对偶形式（式 3.191）：

```
sin a cos β = cos b sin c − sin b cos c cos α    (3.189a)
sin a cos γ = cos c sin b − sin c cos b cos α    (3.189b)
```

对偶正弦—余弦定律：

```
sin α cos b = cos β sin γ + sin β cos γ cos a    (3.191a)
sin α cos c = cos γ sin β + sin γ cos β cos a    (3.191b)
```

每组通过量的轮换还可再得四个等式，故各共 6 式。原文两处注「通过量的轮换（图 3.34）」，而本节声明记号依图 3.89，图号疑为误引（见 [[queries/342节转写讹误与图3-34误引]]）。

## 用途定位

手册明确指出：正弦—余弦定律对应平面三角学的**投影法则**；因为每一式包含球面三角形的**五个量**，所以并不直接用于解球面三角形问题，而是用于推导更多的等式。对偶形式（3.191）同样「通常也不直接用于球面三角形的计算，而是用于推导更多的公式」。手册未具体说明由它们推导出哪些等式；按经典球面三角学的通常路径，半角/半边公式与各类类比式多由余弦定律与正弦—余弦定律联合导出（此为背景性说明，非本节明言），相关下游见 [[concepts/球面半角与半边公式]]、[[concepts/纳皮尔类比]]。
