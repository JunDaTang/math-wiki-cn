# 余切函数

余切函数是六种[[concepts/三角函数]]之一：

$$y = \cot x = -\tan\left(x + \frac{\pi}{2}\right) \tag{2.69}$$

其图像可由正切曲线沿 x 轴反射并向左平移 $\frac{\pi}{2}$ 个单位得到。

## 性质

- 周期 $T = \pi$；渐近线 $x = k\pi$（k = 0, ±1, ±2, …），为 [[concepts/无穷间断点]]（[[concepts/极点]]）；
- 在 $(0, \pi)$（及每个周期区间）内单调递减，取值由 +∞ 到 −∞（值域 ℝ）；
- 与 x 轴交点 $A_k = \left(\left(k+\frac{1}{2}\right)\pi,\ 0\right)$（k = 0, ±1, ±2, …），均为[[concepts/拐点]]，切线倾斜角为 $-\frac{\pi}{4}$（斜率 −1）。

## 关联

- 恒等式核验：$-\tan\left(x+\frac{\pi}{2}\right) = -\frac{\cos x}{-\sin x} = \cot x$，成立；
- 商关系 $\cot\alpha = \frac{\cos\alpha}{\sin\alpha}$（式 2.89）；
