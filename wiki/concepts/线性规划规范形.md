# 线性规划规范形

线性规划规范形（本节中“规范形或标准形”同义并用）是标准等式系统经变量重排后、使基变量居于末 m 个位置且其系数矩阵呈单位阵形态的表述；此时基本解可直接读出，且当右端 b ⩾ 0 时基本解即为可行[[极端点]]。它是[[单纯形法]]迭代所依托的工作形态。

## 规范形的表述（式 18.9a, 18.9b）

```text
OF: f(x) = c₁x₁ + ⋯ + c_{n−m}x_{n−m} + c₀ = max!
CT: a_{1,1}x₁ + ⋯ + a_{1,n−m}x_{n−m} + x_{n−m+1}             = b₁,
    ⋮                                                          ⋮
    a_{m,1}x₁ + ⋯ + a_{m,n−m}x_{n−m}                   + xₙ   = b_m,
    x₁, …, x_{n−m}, x_{n−m+1}, …, xₙ ⩾ 0.
```

（末行编号在转写中讹作 "(18.96)"，应为 (18.9b)。）线性规划问题 (18.4a, 18.4b) 总能通过适当的变量重新排序转换成该形式。

## 基本解

- 系数矩阵的最后 m 列（单位阵）显然线性无关，从而形成一个基（见 [[基与基矩阵]]）：x_{n−m+1},…,xₙ 为基变量，x₁,…,x_{n−m} 为非基变量。
- **基本解**为 (x₁,…,xₙ) = (0,…,0,b₁,…,b_m)，可直接从方程组确定；若 b ⩾ 0 不成立，则它不是可行解。
- 若 b ⩾ 0，则 (18.9a, 18.9b) 称作线性规划问题的规范形或标准形；此时基本解也是可行解，即是 M 的极端点，且目标函数在其上取值 c₀（非基变量等于零）。

## 由已知极端点确定规范形（式 18.10–18.11）

```text
Ax = A_N x_N + A_B x_B = b                                    (18.10)
OF: f(x) = c_N^T x_N + c₀                                     (18.11a)
CT: A_B⁻¹A_N x_N + x_B = A_B⁻¹b,   x_N ⩾ 0,   x_B ⩾ 0.        (18.11b)
```

若 M 的极端点已知，则按 [[由极端点确定线性规划规范形流程]]：由其正分量选定基，构造基矩阵 A_B 与 A_N，以基逆 A_B⁻¹ 变换即得规范形；变换后目标函数中的常数 c₀ 等于目标函数在该极端点的取值（算例中 c₀ = 3 = f(0,1,0)，见 [[式18-12至18-14基变换与目标函数复算]]）。
