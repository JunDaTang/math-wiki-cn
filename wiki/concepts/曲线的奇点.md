# 曲线的奇点

奇点是曲线上各种特殊点的总称。手册 3.6.1.3 只讨论在坐标变换下仍保持不变的点（极大值和极小值的确定见手册 6.1.5.3）。奇点分为十类（对应图 3.231 的 a)–j)）：

| 类型 | 名称 | 特征 |
|---|---|---|
| a) | 二重点 | 曲线与自己相交 |
| b) | 孤立点 | 满足曲线的方程，但与该曲线分离 |
| c), d) | 第一类/第二类尖点 | 曲线方向在此发生改变；按切线的位置区分两类 |
| e) | 密切点 | 曲线与自身接触 |
| f) | 角点 | 曲线突然改变方向，但两支具有两条不同的切线（与尖点的区别所在） |
| g) | 终点 | 曲线在此终止 |
| h) | 渐近点 | 曲线任意趋近它时通常将环绕无限次 |
| i), j) | 组合 | 曲线在同一点处具有两个或更多的上述奇点 |

## 密切点、角点、终点与渐近点的确定

这些类型的奇点仅在超越函数的曲线上出现：

- **角点**相应于导数 $\mathrm{d}y/\mathrm{d}x$ 的有限跳跃。例：$y=\dfrac{x}{1+\mathrm{e}^{1/x}}$ 的原点是一个角点（手册图 6.2c）。
- **终点**相应于 $y=f(x)$ 具有有限跳跃的间断点或函数直接终止。例：点 $(1,0)$ 与 $(1,1)$ 是 $y=\dfrac{1}{1+\mathrm{e}^{1/(x-1)}}$ 的间断点（手册图 2.8）。
- **渐近点**在曲线由极坐标 $\rho=f(\varphi)$ 给出时最容易确定：若当 $\varphi\to\pm\infty$ 时 $\lim\rho=0$，则极点是一个渐近点。例：对数螺线 $\rho=a\mathrm{e}^{k\varphi}$ 在原点处具有一个渐近点（主定义见手册第 138 页 2.14.3，实体页待该节导入）。
