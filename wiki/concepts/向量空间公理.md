# 向量空间公理 (V1)–(V8)

向量空间公理是定义向量空间（线性空间）的八条公理：四条关于加法（结合律、零元、负元、交换律），四条关于标量乘法与加法及标量域结构的相容性（单位元、结合律、两种分配律）。一个非空集 V 配备这两种运算且满足全部八条公理时，称为标量域 𝔽（实数域 ℝ 或复数域 ℂ）上的向量空间。

## 公理列表（式 12.1–12.8）

```
(V1) x + (y + z) = (x + y) + z                     (12.1)
(V2) 存在零元 0 ∈ V，使得 x + 0 = x                (12.2)
(V3) 对任意 x ∈ V，存在 −x 使得 x + (−x) = 0        (12.3)
(V4) x + y = y + x                                 (12.4)
(V5) 1·x = x，0·x = 0                              (12.5)
(V6) α(βx) = (αβ)x                                 (12.6)
(V7) (α + β)x = αx + βx                            (12.7)
(V8) α(x + y) = αx + αy                            (12.8)
```

## 导出性质

从公理 (V1)–(V8) 可进一步推出（复算验证见 [[findings/式12-1至12-8向量空间公理与导出性质转录复算]]）：

- 零元是唯一确定的；
- αx = βx 且 x ≠ 0 蕴涵 α = β；
- αx = αy 且 α ≠ 0 蕴涵 x = y；
- −(αx) = α·(−x)。

差定义为 x − y = x + (−y)；由此方程 x + y = z 对任意 y, z ∈ V 都可求解，解为 x = z − y。V 的元素可称点，或按线性代数习惯称向量；在泛函分析中一般不使用向量箭头记号。

## 转写注记

转录文本中 (V2)、(V3) 缺「∀x」量词（属转写不完整）；式 (12.8) 出现 `V8` 与 `12.8` 双重标签。标量域 𝔽 与实数域 ℝ 在转写中分别乱码为「IF」「叹」。汇总见 [[queries/12-1全节系统性转写讹误清单]]。
