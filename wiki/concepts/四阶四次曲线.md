# 四阶(四次)曲线

四阶(四次)曲线是隐式方程 $F(x, y) = 0$ 中多项式总次数为 4 的平面代数曲线。《数学手册(原书第10版)》2.12 节以此为主题，按两条特化链收录六条曲线：蚌线族（一般蚌线 ⟶ 尼科梅德斯蚌线 / 帕斯卡蜗线 ⟶ 心脏线）与卡西尼族（卡西尼曲线 ⟶ 双纽线）。

## 收录曲线与层级

| 曲线 | 定义要点 | 方程编号 |
|---|---|---|
| [[concepts/一般蚌线]] | 构造：极径延长/缩短定长 ±l，ρ = f(φ) ± l | 式 2.234 |
| [[concepts/尼科梅德斯蚌线]] | 直线（渐近线 x = a）的蚌线 | 式 2.232–2.233 |
| [[concepts/帕斯卡蜗线]] | 过极点、直径 a 的圆的蚌线 | 式 2.235 |
| [[concepts/心脏线]] | 蜗线 a = l 的特例（亦为同径外摆线特例） | 式 2.236–2.237 |
| [[concepts/卡西尼曲线]] | 到两焦点距离之积为常数 a² 的轨迹 | 式 2.238–2.239 |
| [[concepts/双纽线]] | 卡西尼曲线 a = c 的特例 | 式 2.240–2.241 |

隐式方程 (2.233a)、(2.235a)、(2.237a)、(2.239a)、(2.241a) 的总次数均为 4，可逐条核对其四阶属性。

## 共同组织原则

- **参数比驱动形态**：蚌线族由 l/a、卡西尼族由 a/c 决定曲线形状，手册为每个情形区间单独给出特征点公式（如 [[findings/卡西尼曲线按a与c之比的五种形态]]）。
- **原点奇点分类**：六条曲线中原点的角色反复使用孤立点、二重点、尖点三分语言（[[concepts/曲线的奇点三型]]）。
- **渐近线**：蚌线双支共享渐近线 x = a，是 [[concepts/渐近线]] 概念在四阶曲线中的再现。
- **特化链回溯**：每条命名曲线都作为“某构造/某族的特例”被引入，层级对照见 [[comparisons/蚌线族三级特化比较]]。

本节的分情形公式体系与低一阶的三次曲线处理方式同构（[[concepts/第I类三次曲线]]、[[concepts/第II类三次曲线]]、[[concepts/第III类三次曲线]]），是同一“按参数比分情形”方法论的延伸（见 [[methodology/四阶曲线图像绘制法]]）。
