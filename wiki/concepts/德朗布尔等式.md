# 德朗布尔等式

德朗布尔等式（Delambre's equations）是半量之间的四个比例等式：

```
cos((α−β)/2) / sin(γ/2) = sin((a+b)/2) / sin(c/2)    (3.198a)
sin((α−β)/2) / cos(γ/2) = sin((a−b)/2) / sin(c/2)    (3.198b)
cos((α+β)/2) / sin(γ/2) = cos((a+b)/2) / cos(c/2)    (3.198c)
sin((α+β)/2) / cos(γ/2) = cos((a−b)/2) / cos(c/2)    (3.198d)
```

对每个等式通过量的轮换还可以再得到两个等式，故共有 **12 个**德朗布尔等式。

手册指出它们「类似于平面三角学中的莫尔韦德公式」。平面侧的对应物在 wiki 中尚未定名：3.2 节的「附加关系」（式 3.93–3.95，见 [[findings/半角公式与附加关系]]）疑即莫尔韦德公式，待核对原书确认。
