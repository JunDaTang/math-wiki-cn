# 霍纳格式

霍纳格式（19.1.2.1，冠名自 [[entities/霍纳]]）是通过逐次综合除法、由 $n$ 次多项式

$$p_n(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0 \tag{19.11}$$

的系数同时得到其在 $x = x_0$ 处的**值、全部导数值与 Taylor 展开系数**的系统格式，是多项式方程数值求解的核心工具。

## 递推结构

第一步分解（综合除法）：

$$p_n(x) = (x - x_0)\, p_{n-1}(x) + p_n(x_0), \tag{19.12}$$

其中 $p_{n-1}(x) = a'_{n-1} x^{n-1} + \dots + a'_1 x + a'_0$（19.13），系数由递推

$$a'_{k-1} = x_0\, a'_k + a_k \qquad (k = n, n-1, \dots, 0;\ a'_n = 0;\ a'_{-1} = p_n(x_0)) \tag{19.14}$$

给出（注意 $a'_{n-1} = a_n$，由 (19.12) 对比 $x^k$ 系数可得）。对 $p_{n-1}$ 重复同一分解（19.15），得多项式序列 $p_n, p_{n-1}, \dots, p_1, p_0$，全部计算组织为通式表 (19.16)（注：源文该表撇号与下标系统性乱码，结构由算例 F 的干净表唯一确定）。

## 导数公式

$$p'_n(x_0) = 1!\, p_{n-1}(x_0),\quad p''_n(x_0) = 2!\, p_{n-2}(x_0),\ \dots,\ p_n^{(n)}(x_0) = n!\, p_0(x_0). \tag{19.17}$$

由此 $p_n$ 关于 $x - x_0$ 的 Taylor 展开系数即 $p_{n-k}(x_0)/k!$。算例 F：$p_4(x) = x^4 + 2x^3 - 3x^2 - 7$ 在 $x_0 = 2$ 处得 $p_4(2)=13$、$p'_4(2)=44$、$p''_4(2)=66$、$p'''_4(2)=60$、$p^{(4)}_4(2)=24$，且 $p_4(x) = (x-2)^4 + 10(x-2)^3 + 33(x-2)^2 + 44(x-2) + 13$（全部独立复算验证通过）。

## 适用范围

- 复系数 $a_k$：按 (19.16) 分别计算实部与虚部（源文注记）。
- 实系数、复求值点 $x_0$：用 [[concepts/双列霍纳格式]]。
- 下游应用：[[concepts/牛顿法（非线性方程求根）]] 用于多项式方程时 $f(x_n)$、$f'(x_n)$ 均以霍纳格式计算；根定位的均匀节点扫描亦然（见 [[methodology/多项式根定位流程]]）。
