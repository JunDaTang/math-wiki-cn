# 泊松积分

**泊松积分**是用边界值表示圆盘（或球）内调和函数值的积分公式，即 [[拉普拉斯方程与拉普拉斯算子|拉普拉斯方程]] 的 [[狄利克雷问题]] 在圆盘/球上的显式解，由格林函数代入表示公式 (9.99e) 并经计算而来。

**圆盘**（式 9.101d）：

$$u(\xi,\eta) = \frac{1}{2\pi}\int_0^{2\pi} \frac{R^{2}-\rho^{2}}{R^{2}+\rho^{2}-2R\rho\cos(\psi-\varphi)}\, u(\varphi)\,\mathrm{d}\varphi$$

其中 ξ = ρcos ψ、η = ρsin ψ，u(φ) 为边界圆周上的已知值。

**球**（式 9.102c）：

$$u(\xi,\eta,\zeta) = \frac{1}{4\pi}\iint_S \frac{R^{2}-\rho^{2}}{R\,r^{3}}\, u\,\mathrm{d}s$$

复算核对：9.101d 与 9.102c 均与标准泊松核一致 ✓；推导链（圆盘格林函数外法向导数 (ρ² − R²)/(Rr²) 代入内法向的 9.99e）复算通过，见 [[findings/式9-101至9-102圆盘与球格林函数复算]]。两公式的平行比较见 [[comparisons/圆盘与球的格林函数比较]]。
