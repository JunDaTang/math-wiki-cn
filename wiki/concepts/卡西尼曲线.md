# 卡西尼曲线

卡西尼曲线是与两焦点 $F_1(c, 0)$、$F_2(-c, 0)$ 的距离乘积为常数 $a^2$ 的点 P 的轨迹：

$$\overline{F_1P}\cdot\overline{F_2P} = a^2 \tag{2.238}$$

冠名于 Cassini（手册仅作冠名；独立可查的背景：天文学家 Giovanni Domenico Cassini）。它与蚌线族平行，构成 2.12 节的第二条四阶曲线链：[[concepts/双纽线]] 是其 $a = c$ 特例。

## 方程

- 隐式：$(x^2+y^2)^2 - 2c^2(x^2-y^2) = a^4 - c^4$（式 2.239a，$a > 0, c > 0$）；
- 极坐标：$\rho^2 = c^2\cos 2\varphi \pm \sqrt{c^4\cos^2 2\varphi + (a^4 - c^4)}$（式 2.239b）。

## 五情形形态

曲线形状由 $a$ 与 $c$ 之比决定：

| 条件 | 形态 | 要点 |
|---|---|---|
| $a > c\sqrt{2}$ | 类椭圆卵形 | A, C(±√(a²+c²), 0)；B, D(0, ±√(a²−c²)) |
| $a = c\sqrt{2}$ | 过渡形态 | A, C(±c√3, 0)；B, D(0, ±c) 处曲率为 0，与直线 y = ±c“紧密接触” |
| $c < a < c\sqrt{2}$ | 压卵形 | 交点同上；极值点另有 E, G, K, I(±√(4c⁴−a⁴)/(2c), ±a²/(2c))；四拐点 P, L, M, N(±√((m−n)/2), ±√((m+n)/2))，$n = \frac{a^4-c^4}{3c^2},\ m = \sqrt{\frac{a^4-c^4}{3}}$ |
| $a = c$ | 双纽线 | 见 [[concepts/双纽线]] |
| $a < c$ | 两条卵形 | x 轴交点 A, C(±√(a²+c²), 0) 与 P, Q(±√(c²−a²), 0)；极值点 E, G, K, I 同上公式；曲率半径 $r = \frac{2a^2\rho^3}{c^4-a^4+3\rho^4}$ |

逐情形要点与验证状态见 [[findings/卡西尼曲线按a与c之比的五种形态]]。

## 转写注记

- 定义句“常数 $a^2 \neq 0$”与后文 $(a > 0, c > 0)$ 约束冗余（无害）。
- “与直线 y = ±c 存在紧密接触”疑为 osculation（密切/相切）的非常规译法。
- 各情形以“边缘标签 + 句内重复”形式出现（如“$a > c\sqrt{2}$ 当 $a > c\sqrt{2}$ 时”），系双栏版式转写产物，内容无损。
