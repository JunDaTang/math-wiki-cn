# 数学摆

数学摆（mathematical pendulum）是质量为 m 的质点挂在长为 l、几乎无重量、非弹性绳索上在重力场中摆动的力学模型（源文图 14.54），其运动由非线性二阶微分方程 d²ϑ/dt² + (g/l) sin ϑ = 0、ϑ(0) = ϑ₀、ϑ̇(0) = 0（(14.102a)）描述，其中 ϑ 为偏离正常位置的角度，g 为重力加速度（源文回指第 1368 页表 21.2，未入库）。它是本节从力学通向 [[椭圆积分]] 与 [[椭圆函数]] 的中心算例。

## 推导（14.6.1）

弧长 s = lϑ，故 ṡ = lϑ̇、s̈ = lϑ̈。重力 F = mg 分解为法向分量 F_N = mg cos ϑ（被绳索张力平衡，不影响运动方程）与切向分量 F_T；切向分量产生运动加速度：F_T = ms̈ = mlϑ̈ = −mg sin ϑ，总指向正常位置。以 2ϑ̇ 乘运动方程积分得 (ϑ̇)² = (2g/l)(cos ϑ − cos ϑ₀)，分离变量：

```latex
t-t_0=\sqrt{\frac{l}{g}}\int_0^{\vartheta}
\frac{d\Theta}{\sqrt{2(\cos\Theta-\cos\vartheta_0)}}\tag{14.102b}
```

（t₀ 为摆首次位于最低位置的时刻，ϑ(t₀) = 0。）经代换 sin(Θ/2) = k sin ψ、k = sin(ϑ₀/2)（源文代换式中 θ 疑为 Θ 之误）化为第一类椭圆积分：

```latex
t-t_0=\sqrt{\frac{l}{g}}\int_0^{\varphi}
\frac{d\psi}{\sqrt{1-k^2\sin^2\psi}}=\sqrt{\frac{l}{g}}\,F(k,\varphi)\tag{14.102c}
```

## 周期与系数疑点

源文 (14.102d)：T = √(l/g)·F(k, π/2) = √(l/g)·K（K 为第一类完全椭圆积分，数值见第 1424 页表 21.9，未入库），并称 ϑ(t) 是周期为 2T 的周期函数、T 为两个相继极端位置（dϑ/dt = 0）之间的时间、小振幅（sin ϑ ≈ ϑ）时 T = 2π√(l/g)。

复算表明这四个断言不能同真：k→0 时 K→π/2，全程周期应为 4√(l/g)K → 2π√(l/g)，两相继极端位置的间隔为 2√(l/g)K。疑“2T”应为“4T”（或 T 的表达式缺系数），详见 [[式14-102d摆周期系数2T与4T之辨]]；复算记录见 [[式14-100至14-102d椭圆积分反函数与数学摆转录复算]]。

## 意义

线性化给出谐振子与小振幅周期 2π√(l/g)；精确处理则自然导出完全椭圆积分 K 与（经反函数）[[椭圆函数]]——这是“椭圆函数作为椭圆积分之逆”思想的物理实例。
