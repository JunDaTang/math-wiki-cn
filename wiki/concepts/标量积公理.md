# 标量积公理 (H1)–(H4)

标量积公理是定义内积（标量积）的四条公理：域 𝔽（多为 ℂ）上的向量空间 V 称作标量积空间、内积空间或准希尔伯特空间，是指对每一对元 x, y ∈ V 指定一数 (x,y) ∈ 𝔽，使得对任意 x, y, z ∈ V 和 α ∈ 𝔽 满足：

```text
(H1) (x,x) ⩾ 0（即 (x,x) 是实数），并且 (x,x) = 0 当且仅当 x = 0    (12.103)
(H2) (αx, y) = α(x, y)                                             (12.104)
(H3) (x + y, z) = (x, z) + (y, z)                                  (12.105)
(H4) (x, y) = (y,x)‾                                               (12.106)
```

即：**定正性**（H1）、**第一变元的齐次性**（H2）与**可加性**（H3）（合称第一变元的线性性），以及**共轭对称性**（H4）。

## 记号

ω̄ 表示复数 ω 的共轭；手册在 (12.133c)（超出本节公式范围，见 [[queries/12-4未入库回指缺口]]）中记作 ω*。标量积有时也记作 ⟨x, y⟩。

## 导出性质 (12.107)

由四条公理可得第二变元的共轭齐次性与可加性：

$$
(x, \alpha y) = \bar\alpha (x,y), \qquad (x, y+z) = (x,y) + (x,z).
$$

在 𝔽 = ℝ 情形，(H4) 意味着标量积的可交换性（对称性）。

## 与 12.1 的平行

本公理组与 [[concepts/向量空间公理]]（(V1)–(V8)）同属「公理 + 编号导出性质」的手册体例。(12.107) 可由 (H2)–(H4) 严格导出（对第二变元取共轭转置），复算见 [[findings/式12-103至12-107标量积公理与导出性质转录复算]]。
