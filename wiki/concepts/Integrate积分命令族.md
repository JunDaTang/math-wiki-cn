# Integrate 积分命令族（不定积分、定积分与重积分）

## 概念内涵

Integrate 是 [[entities/mathematica]] 的积分命令族，对应《数学手册（原书第10版）》20.3.4.2–20.3.4.3，覆盖三种调用形式：

- `Integrate[f, x]` — 不定积分 ∫f(x)dx；
- `Integrate[f, {x, xa, xe}]` — 积分下限 xa、上限 xe 的定积分；
- `Integrate[f[x, y], {x, xa, xe}, {y, ya, ye}]` — 二重定积分（式 20.36）。

## 行为约定

1. 若 Mathematica 知道该积分，则给出不带积分常数的表达式；每个不包含积分变元的表达式被假定不依赖于它。
2. 一般来说，若不定积分能用初等函数（有理函数、指数函数和对数函数、三角函数及其反函数等）表示成封闭形式，Mathematica 将会把它找出；若找不出，则返回原来的输入（例：`∫x^x dx` 原样返回）。Mathematica 认识某些由非初等积分定义的特殊函数，如椭圆函数等。
3. 重积分求值过程从右到左进行：先关于 y 求积分值；积分限 ya、yb 可以是 x 的函数，它们被代入原函数中，然后再关于 x 求积分值。
4. 积分区域可由不等式限定：`Integrate[Boole[x² + y² ≤ 1], {x, -1, 1}, {y, -1, 1}]` 得 π（单位圆盘面积；转写「Tntegrate」「得到兀」为讹）。
5. 发散的定积分触发消息并说明不收敛（见下）。

## 消息实例

```
Integrate::idiv: Integral of 1/x² does not converge on {-1, 1}.
```

例 B（`Integrate[1/x², {x, -1, 1}]`）是 [[concepts/消息系统（Mathematica）]] 的真实实例。书中随即告诫：在定积分的计算中应小心谨慎；如果被积函数的性质未知，则建议积分前在所考虑的区域内寻求该函数的一个图形表示。

## 典型算例（均经复算，见 [[findings/微分与积分算例复算]]）

- **有理函数**（例题取自手册 8.1，也见 8.1.3.3）：例 A 输入行整体脱失，由输出逆导重构被积函数为 (2x+3)/(x(x−1)(x+2))，见 [[queries/有理积分例A脱In1之辨]]；例 B 被积函数转写为「(x3 + 1)/(x(x 泸」乱码，重构为 (x³+1)/(x(x−1)³)，见 [[queries/积分例B被积函数疑为x三次方加1比x乘x减1三次方之辨]]。
- **三角函数**（取自 8.1.5）：∫sin²x cos⁵x dx = 5Sin[x]/64 − Sin[3x]/192 − 3Sin[5x]/320 − Sin[7x]/448；∫sinx/√cosx dx = −2√cosx。
- **定积分**：∫₀^∞ e^(−x²)dx = √π/2（书注：见第 1418 页表 21.8, 25., a=1）。
- **重积分**（取自 8.4.1.2）：`Integrate[x y², {x, 0, 2}, {y, x², 2x}]` = 32/5；书中措辞称「计算抛物线和与它相交两次的直线之间的面积」，但被积函数为 xy²，实为区域上的二重积分而非面积（见 [[queries/20-3全节系统性转写讹误清单]]）。
- **非初等积分**：∫x^x dx 返回原输入 — 与书中评论「在非初等积分的情形下，Mathematica 可能什么也不做」一致。

## 交互注记

书中提到：在屏幕上可以看到下一个单元左边角落处的一个加号，点击它可以选择自由格式输入或 Wolfram-Alpha 查询；将积分键入两者之一，能够查看积分过程的所有细节。（Wolfram|Alpha 为顺带提及，未展开。）
