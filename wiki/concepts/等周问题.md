# 等周问题

**等周问题**（general isoperimetric problem）：在给定周长的平面区域中确定一个面积最大者；其解是具有给定周长的圆。据传说源于黛多女王（Queen Dido）：她被允许用一张牛皮所围面积之地建立迦太基城，遂把牛皮剪成细条构成一个圆周（正文拉丁括注作「(Carthego)」，与通行拉丁地名 Carthago 拼写有异）。

## 特殊情形的数学表述（10.2.1）

在笛卡儿坐标系中求有给定长度 l、连接两点 A(a,0) 与 B(b,0) 的曲线 y = y(x)，使由直线段 AB 与该曲线所围的面积最大（图 10.1）：

$$I[y] = \int_a^b y(x)\,\mathrm{d}x = \max \quad (10.8a)$$

$$G[y] = \int_a^b \sqrt{1 + y'^2(x)}\,\mathrm{d}x = l \quad (10.8b)$$

$$y(a) = y(b) = 0 \quad (10.8c)$$

其中 (10.8b) 为附加条件（弧长约束），(10.8c) 为边界条件。这是带积分型附加条件的变分问题的原型，用[[附加条件变分问题与拉格朗日乘子|拉格朗日乘子法]]求解。

## 显式解（10.3.3）

取 H = y + λ√(1+y′²)（10.29a）。因 x 不显含于 H，用 F = F(y,y′) 情形的首次积分（10.22c 型）得

$$y + \lambda\sqrt{1+y'^2} - \frac{\lambda y'^2}{\sqrt{1+y'^2}} = c_1\ \text{（即 } y + \frac{\lambda}{\sqrt{1+y'^2}} = c_1\text{）} \quad (10.29b)$$

其解为一族圆周

$$(x - c_2)^2 + (y - c_1)^2 = \lambda^2 \quad (10.29c)$$

常数 c₁、c₂ 与 λ 由边界条件及「y(a)=0、y(b)=0 之间的弧长是 l」的要求确定；对 λ 得一非线性方程，可用适当的迭代方法求解。

**疑讹提示**：印本 (10.29b) 第二式作 y′² = √(λ²−(c₁−y)²)/(c₁−y)，与圆族解不自洽；闭式复算表明应为 y′² = (λ²−(c₁−y)²)/(c₁−y)²，详见 [[findings/10-29b第二式根号与圆解不自洽复算]] 与 [[queries/10-29b第二式根号分母乘方之辨]]。

## 参数式解（10.3.6）

以参数形式 x = x(t)、y = y(t) 表述（10.43a–b），取 H = yẋ + λ√(ẋ²+ẏ²)（10.43c，一次正齐次）。由魏尔斯特拉斯形式算得 M = λ/(ẋ²+ẏ²)^{3/2}、H_{ẋy} = 1、H_{xẏ} = 0（10.43d），代入极值曲线曲率半径公式 (10.42c) 得 **R = |λ|**：曲率半径为常数，故极值曲线是圆周，与 (10.29c) 互证。复算通过，见 [[findings/第10章诸算例闭式复算通过清单]]。
