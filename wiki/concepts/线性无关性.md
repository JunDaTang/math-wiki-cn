# 线性无关性

线性无关性刻画一组向量之间不存在非平凡的线性关系：向量空间 V 的有穷子集 {x₁, …, xₙ} 称作线性无关的，是指系数全为零的线性组合才能得到零元；否则称作线性相关的。它是定义基与维数的前提。

## 定义（式 12.15）

$$\alpha_1 x_1 + \alpha_2 x_2 + \dots + \alpha_n x_n = 0 \;\text{蕴涵}\; \alpha_1 = \alpha_2 = \dots = \alpha_n = 0. \tag{12.15}$$

一个无穷子集 E ⊂ V 称作线性无关的，是指 E 的**每个有穷子集**都是线性无关的；否则称作线性相关的。

## 例证（本节给出）

- **单位序列**：第 k 个分量为 1、其余分量为 0 的序列 e_k 属于 φ（[[entities/典型序列空间]]），从而属于任意序列空间；{e₁, e₂, …} 在任意序列空间中线性无关。（复算：有穷组合 Σα_k e_k = 0 逐分量给出每个 α_k = 0。）
- **C([0,π]) 中的无关组**：函数组 1, sin nt, cos nt（n = 1, 2, 3, …）线性无关（源回指式 (2.97)，未入库）。
- **C([0,π]) 中的相关组**：1, cos 2t, cos²t 线性相关。复算验证：cos 2t = 2cos²t − 1，故 cos²t − ½·cos 2t − ½·1 = 0，存在非零系数组合。见 [[entities/连续函数空间]]。

## 在本库中的位置

- 该概念在线性代数中熟知（源回指 5.3.8.2，未入库），并被用于线性齐次微分方程的基本解组（回指 9.1.2.3，未入库，见 [[queries/12-1未入库回指缺口]]）。
- [[concepts/规范正交系与完全性]]（11.3）中规范正交系的线性无关性是本概念在带内积结构空间中的特例。
- 无关性是 [[concepts/哈梅尔基与维数]] 的定义要素。
