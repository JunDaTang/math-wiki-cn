# 准线

准线是与圆锥曲线配对的定直线，曲线上每个点 P 到焦点的距离与到准线的距离之比为常数，即数值离心率 e：r₁/d₁ = r₂/d₂ = e。这一性质（椭圆 (3.322)、双曲线 (3.332)）也可反过来作为圆锥曲线的定义，并统一给出椭圆（e<1）、抛物线（e=1）、双曲线（e>1）。

各曲线中准线的位置（按本节原文）：

- **椭圆**：与短轴平行、与它距离 d = a/e 的直线（原书图 3.152）
- **双曲线**：与实轴垂直、与虚轴距离 d = a/c 的直线（原书图 3.157；d = a/c 疑为 a/e 之讹，与椭圆小节体例及标准结果 x = ±a/e 不符，见 [[queries/双曲线小节疑似讹误清单]]）
- **抛物线**：在与焦点相对的一侧、距原点 p/2 处与轴垂直相交的直线；抛物线的定义本身就是 PF = PK（到焦点与到准线距离相等，3.345）
