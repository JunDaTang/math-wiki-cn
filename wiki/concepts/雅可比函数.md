# 雅可比函数

雅可比函数（Jacobian functions）sn u、cn u、dn u 是以第一类椭圆积分 F(k, φ) 的反函数——[[振幅函数]] am(k, u)——定义的三个椭圆函数：sn u = sin am(k, u)、cn u = cos am(k, u)、dn u = √(1 − k²sn²u)，其中 0 < k < 1 为模数（(14.105a–c)）。经[[解析延拓]]到 z 平面后，它们是[[亚纯函数|亚纯]]的[[双周期函数]]，因而按定义是 [[椭圆函数]]；源文称其“类似于三角函数，并且可以被考虑为三角函数的推广”（参见 [[椭圆函数与三角函数比较]]）。

## 定义链

由 (14.103) dF/dφ = (1 − k²sin²φ)^{−1/2} > 0（0 < k < 1），F(k, φ) 关于 φ 严格单调，故反函数 φ = am(k, u) 存在（(14.104a)），u = F(k, φ)（(14.104b)）。于是：

```latex
\operatorname{sn}u=\sin\operatorname{am}(k,u)\ \text{（振幅正弦）}
\operatorname{cn}u=\cos\operatorname{am}(k,u)\ \text{（振幅余弦）}
\operatorname{dn}u=\sqrt{1-k^2\operatorname{sn}^2u}\ \text{（振幅 delta）}
```

## 周期、零点、极点（表 14.3）

记号依 (14.109)：k′² = 1 − k²、K = F(k, π/2)、K′ = F(k′, π/2)（参见 [[椭圆积分]]）。

| 函数 | 周期 ω₁, ω₂ | 零点 | 极点 |
|---|---|---|---|
| sn z | 4K, 2iK′ | 2mK + 2niK′ | 2mK + (2n+1)iK′ |
| cn z | 4K, 2(K+iK′) | (2m+1)K + 2niK′ | 2mK + (2n+1)iK′ |
| dn z | 2K, 4iK′ | (2m+1)K + (2n+1)iK′ | 2mK + (2n+1)iK′ |

（m、n 为任意整数；极点一栏三函数共用；原表表头“根”应为“零点”。）逐项对照见 [[sn-cn-dn周期零点极点比较]]。

## 恒等式（(14.110)–(14.112)）

```latex
% 基本恒等式
\operatorname{sn}^2z+\operatorname{cn}^2z=1,\qquad
k^2\operatorname{sn}^2z+\operatorname{dn}^2z=1
% 加法定理（分母同为 1-k^2 sn^2 u sn^2 v）
\operatorname{sn}(u+v)=
\frac{\operatorname{sn}u\operatorname{cn}v\operatorname{dn}v
+\operatorname{sn}v\operatorname{cn}u\operatorname{dn}u}
{1-k^2\operatorname{sn}^2u\operatorname{sn}^2v}
\operatorname{cn}(u+v)=
\frac{\operatorname{cn}u\operatorname{cn}v
-\operatorname{sn}u\operatorname{dn}u\operatorname{sn}v\operatorname{dn}v}
{1-k^2\operatorname{sn}^2u\operatorname{sn}^2v}
\operatorname{dn}(u+v)=
\frac{\operatorname{dn}u\operatorname{dn}v
-k^2\operatorname{sn}u\operatorname{cn}u\operatorname{sn}v\operatorname{cn}v}
{1-k^2\operatorname{sn}^2u\operatorname{sn}^2v}
% 导数公式
(\operatorname{sn}z)'=\operatorname{cn}z\,\operatorname{dn}z,\quad
(\operatorname{cn}z)'=-\operatorname{sn}z\,\operatorname{dn}z,\quad
(\operatorname{dn}z)'=-k^2\operatorname{sn}z\,\operatorname{cn}z
```

## 表示与性质要点

- [[theta函数]] 商表示：(14.115a–c) 给出 sn/cn/dn 的 ϑ 显式表达式，参数 q = exp(−πK′/K)。
- k→0 退化（由定义直接可得）：F(0, φ) = φ，故 sn u → sin u、cn u → cos u、dn u → 1；此时 K → π/2，sn/cn 的实周期 4K → 2π，与三角函数周期吻合（[[退化极限与原点展开检验法]]）。
- 源文断言“雅可比函数 (14.105a)(14.105b) 是椭圆函数”漏列 (14.105c)：dn 同为椭圆函数（表 14.3 载其周期 2K、4iK′）。
- 其他性质与另一些椭圆函数见源文文献 [14.10]、[14.18]（未入库，见 [[14-6未入库回指缺口]]）。
