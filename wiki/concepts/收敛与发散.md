# 收敛与发散

收敛与发散是数列按极限存在性的一级二分。若数列 {aₙ} 满足 (7.5a)（对任意 ε > 0 存在 n₀(ε)，使 n > n₀ 时 |aₙ − A| < ε），则称该数列收敛于 A，记为 lim\_{n→∞} aₙ = A 或 aₙ → A（式 7.6）；不收敛的数列称为发散数列。

发散数列再按极限是否为 ±∞ 二分：极限为 +∞ 或 −∞（式 7.7）者称为真发散，其余发散数列称为假发散——该二级二分为手册特有术语，详见 [[concepts/真发散与假发散]]。

A–J 十例的分类（复算，源文明示部分已标注）：

- **收敛**：C、G 收敛于 0，E 收敛于 3，F 收敛于 3⅓（源文收敛例句的四个极限值 0、3、3⅓、0 完整保留，但序列字母脱漏）。
- **真发散**：A、B 趋于 +∞（源文明示：「数列 A,B 趋千 +∞，为真发散数列」，「趋千」为「趋于」之讹）。
- **假发散**：D、H、I、J（源文例句字母脱漏，复算假说，见 [[queries/假发散例句脱漏字母是哪些]]）。
