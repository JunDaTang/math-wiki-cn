# 面积余切函数

面积余切函数 y = Arcoth x（式 2.210）是 [[concepts/双曲余切函数]] coth 的反函数，为奇函数，等价表达式为 x = coth y。定义域为 |x| > 1，分两支：在区间 (−∞, −1) 上值域为 −∞ < y < 0，在区间 (1, +∞) 上值域为 0 < y < ∞。原函数 coth「严格单调」的表述并不严谨——coth 在 ℝ\{0} 整体上不单调，仅两支分别严格递减，但两支值域不相交故仍为单射——见 [[queries/coth严格单调表述是否应修正为两支递减]]。

## 基本表示

$$
\operatorname{Arcoth} x = \frac {1}{2} \ln \frac {x + 1}{x - 1} \quad (| x | > 1) \tag{2.214}
$$

## 图像与单调性（图 2.56）

- 在区间 (−∞, −1) 上，函数从 0 到 −∞ 严格单调递减；
- 在区间 (1, +∞) 上，函数从 +∞ 到 0 严格单调递减；
- 有三条渐近线：y = 0 与 x = ±1。

## 关系式

- 互表：Arcoth x = Artanh(1/x) = (sign x)·Arsinh(1/√(x²−1)) = (sign x)·Arcosh(|x|/√(x²−1))（|x| > 1），见 [[findings/四种面积函数的互表关系]]。
- 奇性：Arcoth(−x) = −Arcoth x（式 2.224）。
- 手册未给出 Arcoth 的和差公式（式 2.219–2.221 仅覆盖 Arsinh、Arcosh、Artanh）。
