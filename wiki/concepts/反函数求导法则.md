# 反函数求导法则

反函数求导法则给出互为反函数的两函数导数之间的关系：若 $y = \varphi(x)$ 是原函数 $y = f(x)$ 的反函数，即 $y = f(x) \Leftrightarrow x = \varphi(y)$ 等价，f 关于 x 可微、φ 关于 y 可微，且各导数都不等于零，则（式 6.15）

$$f'(x) = \frac{1}{\varphi'(y)} \quad\text{或}\quad \frac{\mathrm{d}y}{\mathrm{d}x} = \frac{1}{\mathrm{d}x/\mathrm{d}y}.$$

即互为反函数的两函数在对应点处的导数互为倒数。

## 算例（已复算）

当 $-1 < x < 1$ 时，$y = f(x) = \arcsin x$ 与 $-\frac{\pi}{2} < y < \frac{\pi}{2}$ 时的 $x = \varphi(y) = \sin y$ 等价；因该区间上 $\cos y \neq 0$，由式 6.15：

$$(\arcsin x)' = \frac{1}{(\sin y)'} = \frac{1}{\cos y} = \frac{1}{\sqrt{1-\sin^2 y}} = \frac{1}{\sqrt{1-x^2}}.$$

## 转写注记

源文此条的条件句损坏：“当每个导数都不等时”疑应为“都不等于零时”，“满足 关千 可微”脱落变量名（x、y），见 [[6-1-2全节系统性转写讹误清单]]。逐字转录与复算见 [[反函数与隐函数求导式6-15至6-16]]。
