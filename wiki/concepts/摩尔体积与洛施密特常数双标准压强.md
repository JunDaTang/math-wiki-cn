# 摩尔体积与洛施密特常数的双标准压强

「标准状态」中压强的取值有两套并存的标准：p₀ = 100 kPa（较新的标准压强）与 p₁ = 101.325 kPa（旧标准大气压），温度同取 T₀ = 273.15 K。因此（理想）气体的摩尔体积与数密度各对应两个数值，本源 21.2 表以双行并列给出（IUPAC 自 1982 年起改以 100 kPa 为标准压强，旧值仍广为沿用——此为公共背景）。

## 本源数值（并经复算验证）

| 量 | p₀ = 100 kPa | p₁ = 101.325 kPa |
|---|---|---|
| 摩尔体积 V_m | V_m0 = 22.710 953(21)·10⁻³ m³/mol | V_m1 = 22.413 968(20)·10⁻³ m³/mol |
| 洛施密特常数 n₀ | n₀0 = 2.651 6462(24)·10²⁵ /m³ | n₀1 = 2.686 7805(24)·10²⁵ /m³ |

- 定义式：V_m = R₀T₀/p；n₀ = N_A/V_m（两条 p₁ 行数值均复算吻合，见 [[findings/21-2常数表定义式恒等复算]]）。
- 换算关系：V_m1/V_m0 = 100/101.325 ≈ 0.986 923；n₀1/n₀0 = 101.325/100 = 1.013 25。
- 22.414 L/mol 为旧标准下的经典教科书值。
