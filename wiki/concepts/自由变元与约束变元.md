# 自由变元与约束变元

谓词演算公式中，个体变量的出现分为两类：若 x 是 ∀x 或 ∃x 中的变量，或 x 出现在这类量词的辖域（范围）之内，则 x 在该公式中的出现是**约束的**；不然，x 在这个公式中的出现是**自由的**。判定依据即公式归纳构造条款 (5.22)：凡经 (∀xA)、(∃xA) 构造引入的变量出现皆为约束出现。

原书算例（个体区域 ℕ，P(x,y) 表示 x ≤ y）：

- P(x,y)：x、y 皆自由；
- ∀yP(x,y)：x 自由，y 约束；
- ∃x∀yP(x,y)：x、y 皆约束。

不含任何自由出现的个体变量的公式称 [[concepts/闭公式]]。
