# 正规方程组与高斯变换

正规方程组是由超定线性方程组 A x = b（式 4.187）导出的方阵线性方程组（式 4.190）：

```
Aᵀ(Ax − b) = 0   ⇔   AᵀA x = Aᵀb                                    (4.190)
```

其维数为 n（未知数个数）。源将由 (4.187) 到 (4.190) 的转化称作**高斯变换**（转写中「高斯」二字讹为乱码公式，见 [[queries/4-5全节系统性转写讹误清单]]）。

## 推导与性质

若残差向量 r = Ax − b 与 A 的每一列正交，则 x 是最小二乘问题 (4.189) 的解，此即式 (4.190)。矩阵 AᵀA 是对称的（见 [[concepts/对称矩阵]]）；当 rank(A) = n（实矩阵、m > n 下即 A 的所有列线性无关）时，AᵀA 是正定的，因而是正则的——即若 A 的秩等于未知数的个数，正规方程组有唯一解。

## 转写提示

源句「如果矩阵 A 的秩为 n（因为 m > n，所以 A 的所有列是线性无关的）」因转写脱落导致因果颠倒：m > n 本身并不保证列线性无关，正确逻辑应为「rank(A) = n，即 A 的所有列线性无关（列满秩）」。见 [[queries/4-5全节系统性转写讹误清单]]。

## 求解与退化

- rank(A) = n：可用 [[concepts/楚列斯基方法]]（AᵀA 对称正定）求解，或改用源推荐的 [[concepts/豪斯霍尔德方法]]（A = QR 正交化）；
- rank(A) < n（秩亏，源作「秩亏格」）：正规方程组不再有唯一解，且正交化方法给出无用的结果，须转用 [[concepts/正则化问题]]（式 4.191–4.192）。
