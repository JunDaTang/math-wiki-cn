# 正弦定律

正弦定律是平面三角形的基本定理：任一边与其对角的正弦之比为常数，且该常数等于外接圆半径的两倍。本源式 (3.88)：

$$\frac{a}{\sin\alpha} = \frac{b}{\sin\beta} = \frac{c}{\sin\gamma} = 2R$$

等价形式 $a/b = \sin\alpha/\sin\beta$ 经轮换（图 3.34）得 $b/c = \sin\beta/\sin\gamma$ 与 $c/a = \sin\gamma/\sin\alpha$。比例常数的几何意义即 $2R$，与外接圆半径公式 (3.99) 一致（见 [[concepts/外接圆]]）。

在本源中的角色：

- 表 3.4 基本问题 (1)、(3) 的边长换算基础（$b = a\sin\beta/\sin\alpha$ 等）；
- 交会法 (3.110c–d) 由基线 $s_{AB}$ 求待定点边长 $s_{AN}, s_{BN}$（见 [[concepts/交会法]]）；
- 斯涅耳后方交会 (3.112h) 建立 $\sin\varphi/\sin\delta_1 = s_{CN}/a$ 等关系（见 [[concepts/后方交会法]]）。
