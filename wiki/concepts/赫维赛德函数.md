# 赫维赛德函数 Θ

赫维赛德函数（阶跃函数）定义为 Θ(x) = 1（x ⩾ 0）、0（x < 0）(12.230)。它显然（勒贝格）可和，其正则分布的分布导数是狄拉克分布：DΘ = δ。

## 定义 (12.230)

Θ(x) = { 1, x ⩾ 0; 0, x < 0 }

## DΘ = δ

Θ 在 x = 0 处有单位跳跃而无经典导数，但按 [[concepts/广义导数]] 作为分布求导，得到 [[concepts/狄拉克测度与狄拉克分布]]。手册表述为：非正则分布 δ 可以看作赫维赛德函数（显然是可和的）产生的正则分布的导数。这是「分布导数捕捉跳跃奇性」的最小例子。

## 应用：冲击算例（12.9.5.4 例 B）

技术与物理建模中作用集中于一点（理想化意义下）的情形——「点」作用、针偏转、碰撞等——可用 δ 或 Θ 描述。设弦质量系统在 t₀ 时刻存在瞬间外作用力 F，则运动方程为

ẍ + ω²x = F δ_{t₀}，初始条件 x(0) = ẋ(0) = 0

其解为 x(t) = (F/ω) sin(ω(t − t₀)) θ(t − t₀)。复算核验（速度在 t₀ 处跳跃量恰为 F，与 δ 冲击匹配）通过，见 [[findings/式12-222至12-230分布理论与狄拉克赫维赛德算例转录复算]]。
