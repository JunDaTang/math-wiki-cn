# 倒数幂

倒数幂是负整数指数的幂函数

```latex
y = a/xⁿ = ax⁻ⁿ,  a ≠ 0, n 为大于零的整数    (2.50)
```

其图像为双曲型曲线：两条坐标轴为 [[concepts/渐近线]]，x = 0 为间断点，函数无极值。n = 1 时即 [[concepts/反比例函数]]（真双曲线）；n ≥ 2 时隐式方程（如 x²y = a）为三次及更高次代数曲线，不再是双曲线。

关键性质（详见 [[findings/倒数幂的奇偶对称与趋近速度]]）：

- **奇偶对称**：n 为偶数时曲线关于 y 轴对称（[[concepts/偶函数]]）；n 为奇数时关于原点中心对称（[[concepts/奇函数]]）；
- **趋近速度**：n 越大，曲线趋近 x 轴的速度越快、趋近 y 轴的速度越慢（分别对 |x| > 1 与 |x| < 1 的区域成立）；
- **符号行为**：a > 0 且 n 偶时恒正，函数值由 0 增至 +∞ 再减至趋于 0；a > 0 且 n 奇时由 0 减至 −∞、跳跃到 +∞ 后减至趋于 0；a < 0 时两种情形整体反号。

它与 [[concepts/n次抛物线]] y = axⁿ 在奇偶对称性与伸缩、反射变换上结构平行，见 [[comparisons/倒数幂与n次抛物线比较]]。式 2.47（[[concepts/第I类三次曲线]]）在 b = 0 时退化为 y = a + c/x²，即倒数幂的平移型。
