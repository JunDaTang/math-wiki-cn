# 诱导公式

诱导公式是把任意角的三角函数化简为锐角三角函数的整套规则体系（2.7.1.2.3），由四部分构成：

1. **周期化简**（式 2.72–2.75）：$\sin(360^\circ n + \alpha) = \sin\alpha$、$\cos(360^\circ n + \alpha) = \cos\alpha$、$\tan(180^\circ n + \alpha) = \tan\alpha$、$\cot(180^\circ n + \alpha) = \cot\alpha$（n 为整数）；
2. **负角公式**（式 2.76–2.79）：$\sin(-\alpha) = -\sin\alpha$、$\cos(-\alpha) = \cos\alpha$、$\tan(-\alpha) = -\tan\alpha$、$\cot(-\alpha) = -\cot\alpha$；
3. **象限关系（简化公式）**（表 2.4）：相差 90°、180°、270° 的角之间函数值的关系，涵盖 $x = 90^\circ \pm \alpha$、$180^\circ \pm \alpha$、$270^\circ \pm \alpha$、$360^\circ - \alpha$ 四列；
4. **余角与补角公式**（式 2.80a–b、2.81a–b）：$\cos\alpha = \sin(90^\circ - \alpha)$、$\sin\alpha = \cos(90^\circ - \alpha)$；$\sin\alpha = \sin(180^\circ - \alpha)$、$-\cos\alpha = \cos(180^\circ - \alpha)$（余角与补角的定义属第 168 页 3.1.1.2，未导入）。

## 算例（源文）

$$\sin(-1000^\circ) = -\sin 1000^\circ = -\sin(360^\circ\cdot 2 + 280^\circ) = -\sin 280^\circ = +\cos 10^\circ = +0.9848$$

锐角（$0^\circ < x < 90^\circ$）的函数值查表 2.3，「当今常用计算机计算」（源文原话）。
