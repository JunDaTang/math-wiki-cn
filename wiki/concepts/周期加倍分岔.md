# 周期加倍分岔

**周期加倍分岔**（period-doubling bifurcation，又称 flip 分岔）指周期轨乘子 ρ₁=−1 时周期轨道分裂出双倍周期轨道的分岔。条件：n≥2、r≥4、l=1，|ρ_i|≠1（i=2,…,n−1）、ρ_n=1。正规形式（式 17.82）：

```latex
x \mapsto \tilde{F}(x, \alpha) = (-1 + \alpha) x + x^{3}
```

## 动力学（复算核验通过）

- α≥0 小时不动点 x=0 稳定（|(−1+α)|<1）；α<0 时不稳定。
- α<0 时二次迭代 F̃² 另有两个稳定不动点 x_{1,2}=±√(−α)+o(|α|)——且对 (17.82) 它们是**精确的** 2-周期点（F̃(x)=−x 精确成立），故为映射的周期 2 点，对应流的双周期轨。
- (F²)′≈1+4α，α<0 时双周期轨稳定。

## 一般条件（式 17.83，逐字）

```latex
F(0,0)=0,\ \frac{\partial F}{\partial x}(0,0)=-1,\ \frac{\partial F^{2}}{\partial \varepsilon}(0,0)=0,\ \frac{\partial^{2} F^{2}}{\partial x \partial \varepsilon}(0,0)\neq 0,\ \frac{\partial^{2} F^{2}}{\partial x^{2}}(0,0)=0,\ \frac{\partial^{3} F^{2}}{\partial x^{3}}(0,0)\neq 0
```

**结构性论断**：因 ∂F²/∂x(0,0)=1（即 ∂F/∂x(0,0)=−1），**叉型分岔条件对 F² 成立**——flip 即二次迭代的 [[叉型分岔]]。对微分方程：α=0 处具有近似双周期的轨 γ 分裂出稳定周期 2 轨 γ_α，γ 失去稳定性（图 17.30(c)）。

## 通向混沌

逻辑斯谛映射（式 17.84）的级联 α₁=3、α₂=1+√6、…、α_q→α_∞≈3.570 是 flip 的典型实例（α₁=3 处该不动点导数 2−α=−1，复算一致）；倍周期 2^q 居 [[沙可夫斯基定理]] 序首段。见 [[逻辑斯谛映射]]、[[费根鲍姆吸引子]]、[[式17-81至17-83映射鞍结点与Flip条件复算]]。
