# 倍角公式

倍角公式是用角 α 的[[concepts/三角函数]]表示 2α、3α、4α 乃至 nα 的三角函数的恒等式组（2.7.2.3），由[[concepts/加法定理]]反复应用导出。

## 2α、3α、4α（式 2.96–2.107）

$$\sin 2\alpha = 2\sin\alpha\cos\alpha,\qquad \sin 3\alpha = 3\sin\alpha - 4\sin^3\alpha$$
$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha,\qquad \cos 3\alpha = 4\cos^3\alpha - 3\cos\alpha$$
$$\sin 4\alpha = 8\cos^3\alpha\sin\alpha - 4\cos\alpha\sin\alpha,\qquad \cos 4\alpha = 8\cos^4\alpha - 8\cos^2\alpha + 1$$
$$\tan 2\alpha = \frac{2\tan\alpha}{1-\tan^2\alpha},\quad \tan 3\alpha = \frac{3\tan\alpha-\tan^3\alpha}{1-3\tan^2\alpha},\quad \tan 4\alpha = \frac{4\tan\alpha-4\tan^3\alpha}{1-6\tan^2\alpha+\tan^4\alpha}$$
$$\cot 2\alpha = \frac{\cot^2\alpha-1}{2\cot\alpha},\quad \cot 3\alpha = \frac{\cot^3\alpha-3\cot\alpha}{3\cot^2\alpha-1},\quad \cot 4\alpha = \frac{\cot^4\alpha-6\cot^2\alpha+1}{4\cot^3\alpha-4\cot\alpha}$$

## n 倍角通式（式 2.108–2.109）

当 n 较大时，利用棣莫弗公式（第 48 页 1.5.3.5，未导入）与二项式定理（第 14 页 1.1.6.4，未导入）：

$$\cos n\alpha + \mathrm{i}\sin n\alpha = \sum_{k=0}^{n}\binom{n}{k}\mathrm{i}^k\cos^{n-k}\alpha\sin^k\alpha = (\cos\alpha + \mathrm{i}\sin\alpha)^n \tag{2.108}$$

分离实虚部即得 cos nα 与 sin nα 的幂级数表达式（式 2.109）。
