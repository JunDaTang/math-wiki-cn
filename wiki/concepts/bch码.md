# BCH 码

BCH 码是一类重要的循环码（[[concepts/循环码]]）：可对其极小距离的下界以及码能够纠正差错的个数提出要求。设 α 为本原 [n] 次单位根（参见 [[concepts/分圆域]] 与 [[findings/分圆域单位根性质]]），b 为整数，m_{α^j}(x) 为 α^j 的极小多项式（[[concepts/极小多项式]]），则 BCH 码由生成多项式

```
g(x) = lcm(m_{α^b}(x), m_{α^{b+1}}(x), …, m_{α^{b+δ−2}}(x))              (5.272)
```

定义，其中 δ 称为码的**设计距离**。对极小距离，BCH 关系式 d_min(C) ≥ δ 必定成立。

（源文「本原 [n] 次单位根」缺 n、「[b] 是一个整数」缺 b、设计距离句残缺，见 [[queries/5-4-5至5-4-6全节系统性转写讹误清单]]。）

BCH 码是 5.3.7 抽象理论（有限域、极小多项式、单位根）在编码理论中的直接应用，详见 [[findings/bch码生成多项式与设计距离]]。
