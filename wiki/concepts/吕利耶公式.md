# 吕利耶公式

吕利耶公式（本节拼作 L'Huilier）由球面三角形的三条边直接计算球面角盈，无需先求出三个角：

```
tan(ε/4) = √[ tan(s/2) · tan((s−a)/2) · tan((s−b)/2) · tan((s−c)/2) ]    (3.201)
```

其中 s = (a+b+c)/2 为三边之和的一半。手册指出「这个等式对应于平面三角学中的海伦公式」——平面侧见 [[concepts/海伦公式]]。

## 在面积计算中的位置

手册给出的球面三角形面积计算路径有两条：

1. 已知三个角：直接由 [[concepts/球面角盈]] ε = α+β+γ−180°（式 3.184）与 [[concepts/吉拉尔定理]]（式 3.186a）求面积；
2. 已知三条边：先用半角公式（式 3.193a–e，见 [[concepts/球面半角与半边公式]]）求出角，再按路径 1 计算；或者**直接**用本公式由边算角盈，再代入面积公式。

## 记号

本段原文将角盈记作 E，与本节其余部分的 ε 不一致，是否原书如此待核（见 [[queries/两算例ab指派与角盈符号E是否原书如此]]）。
