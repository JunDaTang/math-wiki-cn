# 索伯列夫空间

索伯列夫空间（Sobolev space，得名于数学家 Sobolev）在本源 12.3.2.3 中经**完备化构造**定义。设 Ω ⊂ ℝⁿ 是有界区域，即具有充分光滑边界 ∂Ω 的开连通集（n = 1 时可想象成区间 (a, b)，n = 2, 3 时可想象成有界凸集）。函数 f: Ω̄ → ℝ 称作在闭区域 Ω̄ 上 k 次连续可微，指 f 在 Ω 内 k 次连续可微且每阶偏导数在边界上都有有限极限，从而可连续延拓为 Ω̄ 上的连续函数。在该向量空间上（p ∈ [1, ∞)），取 ℝⁿ 中的勒贝格测度 λ（回指第 906 页 12.9.1 例 C，未入库），定义范数（式 12.90）：

‖f‖_{k,p} = ( ∫_Ω̄ |f(x)|ᵖ dλ + Σ_{1≤|α|≤k} ∫_Ω̄ |D^α f(x)|ᵖ dλ )^{1/p}

如此得到的赋范空间记作 $\tilde W^{k,p}(Ω)$ 或 $\tilde W_p^k(Ω)$。

## 多重标号记号

α = (α₁, …, αₙ) 为非负整数组成的有序 n 数组，|α| = α₁ + ⋯ + αₙ；对 f(x) = f(ξ₁, …, ξₙ)，式 12.90 使用简记（式 12.91）：

D^α f = ∂^{|α|}f / (∂ξ₁^{α₁}⋯∂ξₙ^{αₙ})

（转录本分子误作 D^{|α|} 且缺少函数符号，见 [[queries/式12-91分子应为偏导数]]。）

## 完备化定义与注意点

赋范空间 $\tilde W^{k,p}(Ω)$ **不完备**；其完备化空间记作 W^{k,p}(Ω)，p = 2 时记作 H^k(Ω)，称作索伯列夫空间。需注意：

- 不完备性只属于 $\tilde W^{k,p}$ 这一以 C^k 函数类构造的具体原型，不属 W^{k,p} 本身（后者按构造完备）。
- 本源特别提醒：空间 𝒞^{(k)}（配式 12.89g 的范数）与 $\tilde W^{k,p}$ 使用「完全不同的范数」，见 [[comparisons/典型函数空间范数比较]]。
- 本源的「完备化」定义路线与常见的「弱导数/分布」定义路线属不同约定（后者为外部经典背景，非本源内容）；在标准理论中对光滑边界区域两条路线给出同一空间（外部经典结果，本源未涉及）。
- 范数在 Ω̄ 上积分而非 Ω 上：因光滑边界勒贝格测度为零，二者等价（外部注记）。
