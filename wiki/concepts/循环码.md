# 循环码

循环码是对循环右移封闭的 (n,k) 线性码（[[concepts/线性码]]）：c_0c_1…c_{n−1} ∈ C ⇒ c_{n−1}c_0c_1…c_{n−2} ∈ C。源文称其为「研究得最多」的线性码，提供有效的编码和译码。例：C = {000, 110, 101, 011} 是循环 (3,2) 线性码（已复核）。

## 多项式刻画

将码字表示为次数 ≤ n−1、系数属于 GF(2) 的多项式后（参见 [[concepts/多项式环]]），循环性等价于对「乘 x 再模 x^n−1」封闭：

```
c(x) ∈ C ⇒ c(x)·x (mod x^n − 1) ∈ C                                     (5.270)
```

## 生成多项式与控制多项式

循环 (n,k) 线性码由 n−k 次生成多项式 g(x) 刻画（k ∈ {1, 2, …, n−1}）：g(x) 是 x^n − 1 的一个因子；满足 g(x)h(x) = x^n − 1 的多项式 h(x) 称为控制多项式（即通常所说的校验多项式）。编码为

```
a(x) ↦ a(x)·g(x)                                                        (5.271)
```

码字判定：d(x) 是码中元素 ⇔ g(x) | d(x) ⇔ d(x)h(x) ≡ 0 (mod x^n − 1)。
