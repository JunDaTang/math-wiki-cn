# 线性函数

线性函数是一次多项式，一般式为

$$y = a x + b \tag{2.39}$$

图像是一条直线，a 称为比例因子（《数学手册(原书第10版)》2.3.1，图 2.11(a)）。

## 单调性

- a > 0：函数单调递增（单调性概念见 [[单调函数]]）；
- a < 0：函数单调递减；
- a = 0：退化为零次多项式，即**常函数** y = b，图像为水平直线。

## 截距点

| 点 | 坐标 | 所在轴 |
|---|---|---|
| A | $\left(-\dfrac{b}{a},\ 0\right)$ | x 轴（要求 a ≠ 0） |
| B | $(0,\ b)$ | y 轴 |

原文的具体分析参见其第 262 页 3.5.2.6,1（尚未入库）。注意 a=0 时 A 点无定义，原文叙述顺序略有张力。

## 特例：正比例函数

b = 0 时化为 $y = ax$（式 2.40），图像为过原点的直线，详见 [[正比例函数]]。

## 在多项式谱系中的位置

线性函数是 [[多项式]] 家族中 n = 1 的情形，其行为符合 [[n次多项式]] 的奇次规律：a>0 时 y 从 $-\infty$ 变到 $+\infty$，与 x 轴恰有一个交点（a≠0 时），无极值、无拐点、无渐近线。仅保留最高次项（b=0）时即 [[n次抛物线]] 的 n=1 情形。

原文「直线与坐标轴的交点为 b」与后文 $B(0,b)$ 口径不一，见 [[2-3-1与坐标轴交点为b是否应为纵截距]]。
