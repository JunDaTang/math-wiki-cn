# 表格

「表格」是 [[entities/数学手册原书第10版]] 第21章的主题，指以数值表与函数表汇编形式呈现的数学参考资料：从常用数学常数、单位制换算、级数展开，到积分表、特殊函数表、积分变换表，再到统计分布数值表与随机数表。第21章将散见于正文章节的方法与公式转化为可直接查取的数值形态，与正文章节构成「正文/表格」两翼——正文讲方法，表格供查取。完整小节名册见 [[sources/10-数学手册原书第10版--7-第21章-表格--1tctcum]]。

## 主题群结构

第21章共 21 个小节（21.1–21.21 编号连续、无跳空），按内容划分为七个主题群：

| 主题群 | 小节 | 覆盖内容 |
|---|---|---|
| 常数 | 21.1–21.2 | 常用数学常数、重要自然常数 |
| 单位制 | 21.3–21.4 | (公制)前缀表、国际物理单位制(SI单位) |
| 级数 | 21.5–21.6 | 重要级数展开、傅里叶级数 |
| 积分 | 21.7–21.9 | 不定积分、定积分、椭圆积分 |
| 特殊函数 | 21.10–21.12 | 伽马函数、贝塞尔函数(柱面函数)、第一类勒让德多项式 |
| 变换 | 21.13–21.15 | 拉普拉斯变换、傅里叶变换、Z变换 |
| 统计数值表 | 21.16–21.21 | 泊松分布、标准正态分布、χ² 分布、费希尔F分布、学生t分布、随机数 |

## 与正文章节的两翼对应

表格章各主题群与正文章节互为对应物：21.5–21.6 对应第7章 无穷级数；21.7–21.9 对应第8章 积分学；21.13–21.15 对应第15章 积分变换（见 [[concepts/积分变换]]）；21.16–21.21 对应第16章 概率论与数理统计（见 [[concepts/概率论与数理统计]]）。此对应为依 [[concepts/表源考证]] 框架的推断，章级目录页本身未直接陈述。
