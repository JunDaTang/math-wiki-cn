# 方位角

方位角 $t$ 是有向线段的方向角：在一点处，有向线段相对于一条穿过该点且平行于 x 轴的直线的方向（图 3.39 中点 A 处的方位角 $t_{AB}$）。由于大地测量学中角按顺时针度量（见 [[concepts/测地坐标]]），象限以与平面三角右手笛卡儿坐标系相反的顺序列出（表 3.6），但平面三角中的公式仍然成立而无须改变。

**反方位角**（式 3.105d）：

$$t_{BA} = t_{AB} \pm 200\ \mathrm{gon}$$

**计算**（式 3.105a–c）：

$$\tan t_{AB} = \frac{\Delta y_{AB}}{\Delta x_{AB}},\qquad s_{AB} = \sqrt{\Delta y_{AB}^2 + \Delta x_{AB}^2}$$

若以 $\Delta y$、$\Delta x$ 的正确符号输入计算器并按 arctan 键，得角 $t_0$，再按表 3.6 的象限加上相应的新度值（0 / 200 / 400 gon）。表 3.6 的三、四象限显示符号疑有转写颠倒，见 [[queries/表3-6三四象限显示符号是否颠倒]] 与 [[findings/方位角象限判定与反方位角]]。

方位角传递（$t_{AN} = t_{AB} - \alpha$、$t_{BN} = t_{BA} + \beta$ 等）是交会定位各法的枢纽步骤，见 [[methodology/交会定位计算流程]]。
