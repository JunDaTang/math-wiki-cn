# 费希尔F分布

**费希尔F分布**（F 分布）是数理统计中的连续概率分布，自由度 m₁、m₂：它是两个独立 χ² 变量各自除以自由度后之比的分布——若随机变量 X₁、X₂ 相互独立，分别服从自由度为 m₁ 和 m₂ 的 [[卡方分布]]，则随机变量

```
F_{m₁,m₂} = (X₁/m₁) / (X₂/m₂)        (16.93)
```

的分布是自由度为 m₁、m₂ 的费希尔分布或 F 分布。

> **背景注**（可独立核查的背景知识，非引自手册原文）：F 分布以统计学家 R. A. Fisher 命名，在方差分析等统计推断中居于基础地位，常用于方差分析与方差齐性检验。

## 密度函数与分布函数

手册 16.2.4.7 给出的密度函数为

```
f_F(t) = (m₁/2)^{m₁/2}·(m₂/2)^{m₂/2}·Γ((m₁+m₂)/2) / [Γ(m₁/2)·Γ(m₂/2)]·t^{m₁/2−1} / ((m₁/2)·t + (m₂/2))^{(m₁+m₂)/2}
         (t > 0；t ⩽ 0 时为 0)        (16.94a)
```

当 x ⩽ 0 时 F_F(x) = P(F_{m₁,m₂} ⩽ x) = 0；当 x > 0 时

```
F_F(x) = (16.94a) 同一常数 · ∫_{0}^{x} (t^{m₁/2−1} − 1)·dt / ((m₁/2)·t + (m₂/2))^{(m₁+m₂)/2}        (16.94b)
```

（疑点：(16.94b) 被积函数中的「− 1」与密度 (16.94a) 对照疑为衍文，见 [[式16-94b被积函数疑衍文负一]]。）

## 期望和方差

```
E(F_{m₁,m₂}) = m₂/(m₂−2)        (16.95a)
D²(F_{m₁,m₂}) = 2·m₂²·(m₁+m₂−2) / [m₁·(m₂−2)²·(m₂−4)]        (16.95b)
```

（复核补注：两式须分别满足 m₂ > 2 与 m₂ > 4 方有意义；原文未给出该适用条件，与 [[学生t分布]] 显式给出 m>1、m>2 的体例不一，疑脱。）

## 与其他分布的关系

### 抽样分布构造链

在 16.2.4 一节中，F 分布是 [[卡方分布]] 之上的第二级抽样分布：由两个独立 χ² 变量构造；与 [[学生t分布]] 同属由标准正态变量出发的构造链，见 [[卡方F与t分布的构造关系比较]]。

### 分位数约化式（21.19 材料复算所用）

- $f_{\alpha,m_1,\infty} = \chi^2_{\alpha,m_1}/m_1$（分母自由度无穷时约化为 χ² 上侧分位数除以 $m_1$）。
- $f_{\alpha,\infty,m_2} = m_2/\chi^2_{1-\alpha,m_2}$（分子自由度无穷时约化为 $m_2$ 除以 χ² 下侧 α 点）。
- $f_{\alpha,1,m_2} = [t_{\alpha/2}(m_2)]^2$（分子自由度为 1 时为 t 双侧分位数之平方）。
- 倒数关系 $f_{1-\alpha}(m_2,m_1) = 1/f_{\alpha}(m_1,m_2)$：手册两表仅载上侧分位数，此式在本源中无从直接核验。

完整恒等式族见 [[F分布分位数交叉复算法]]。21.19 材料另记：χ² 分布与 t 分布的概念页暂未建立，待 21.17/21.18（疑为其表）入库时再立，见 [[21-17与21-18缺位之辨]]。
