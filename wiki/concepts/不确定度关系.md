# 不确定度关系

不确定度关系（uncertainty relation）是量子力学对「两个物理量可以同时确知到何种程度」的本质限制：对由非对易算子表示的两个可观察量 A、B，不存在联合本征函数系，不可能找到使两个不确定度 ΔA、ΔB 同时任意小的物理态；其乘积有由对易式期望值给出的下界（9.129，罗伯逊不等式）：

```latex
\Delta A\,\Delta B \geqslant \Big|\frac{1}{2\mathrm{i}}\overline{[\hat{A},\hat{B}]}\Big|   % 9.129
```

## 位置-动量对的特例（9.130–9.131）

同一方向的位置算符与动量算符满足对易关系

```latex
[\hat{p}_x,\hat{x}] = \frac{\hbar}{\mathrm{i}}   % 9.130
\Delta p_x\,\Delta x \geqslant \frac{\hbar}{2}   % 9.131
```

9.131 即海森伯（Heisenberg）不确定度关系：一个粒子的位置和动量在何种确切程度上可以被同时知晓，存在本质的限制。复算：9.130 代入 9.129 直接给出 9.131（✓）；9.130 本身由 [∂ₓ, x] = 1 直接验证（✓）。

## 归属限定

9.131 只对同一方向的位置-动量算符对成立；对任意算符对的一般形式是 9.129（编者注，防止将 ℏ/2 下界过度外推到任意可观察量对）。
