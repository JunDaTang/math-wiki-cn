# 正态概率纸

**正态概率纸**是一种特殊刻度的坐标纸：数据轴取等距刻度，另一轴对 z 等距分割、但按 y=Φ(z) 标注刻度，其中 Φ 为 [[concepts/标准正态分布|标准正态分布]] 的分布函数：

$$y=\Phi(z)=\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{z}\mathrm{e}^{-t^{2}/2}\,\mathrm{d}t.\ \tag{16.130}$$

## 原理（式 16.131a–c）

若随机变量 X 服从期望 μ、方差 σ² 的 [[concepts/正态分布|正态分布]]，则其分布函数满足 F(x)=Φ((x−μ)/σ)=Φ(z)，即 z=(x−μ)/σ，故 z 与 x 之间有线性关系：

| z | x |
|---|---|
| 0 | μ |
| 1 | μ+σ |
| −1 | μ−σ |

因此正态总体的分布函数曲线在概率纸上呈直线，且由直线与刻度的三个对应点可直接读出参数。

## 应用（图检法）

对样本数据，把按式 (16.125)（未入库，见 [[queries/16-3-3未入库回指缺口]]）计算的**累计相对频率**作为纵坐标、组上界作为横坐标，将对应点描绘到概率纸上。若这些点大致落在一条直线上（偏差很小），则随机变量可视为正态随机变量。

《数学手册(原书第10版)》图 16.14 的算例：表 16.3 数据对应的点列大致呈直线，进一步读得 μ≈176、σ≈37.5（由 z=0 与 z=±1 对应的 x 值得到）。该读数依赖表 16.3 原始数据（不在本节文档内，无法复算），但 σ≈37.5 与 16.3.3.1 χ² 检验算例所用的 s=36.70 相符（见 [[queries/方差s方3670疑为标准差s之辨]]）。

手册另注（原文轴名符号脱落）：若某一轴改取等距刻度，则累计相对频率值 F_i 更易描绘到概率纸上，这同时意味着纵坐标取非等距刻度。
