# 复数的模与辐角

在[[concepts/高斯平面]]上，一个点的位置向量的长度 ρ = |z| 称为复数的绝对值或复数的模；角 φ 称为复数的辐角，用弧度度量，记为 arg z（式 1.132c）：

ρ = |z|，φ = arg z = ω + 2kπ，其中 0 ⩽ ρ < ∞，−π < ω ⩽ +π，k = 0, ±1, ±2, …

ω 是辐角在 (−π, +π] 内的代表值（辐角以 2π 为周期）。z = 0 的绝对值等于 0，其辐角 arg 0 无定义。

注意：源文在该定义之后写"φ 称为复数的辐角主值"，与定义式矛盾——按定义，随 k 变化的 φ 是多值的辐角全体，主值应是 ω。此疑点追踪于 [[queries/式1.132c辐角主值应记为ω还是φ]]，本页暂按"主值为 ω ∈ (−π, +π]"记录。

## 与代数形式的换算

ρ、φ 与 a、b 的关系同笛卡儿坐标与极坐标的关系（式 1.133a/b）：

a = ρ cos φ，b = ρ sin φ，ρ = √(a² + b²)

辐角 φ 的分段计算公式有两套（式 1.133c 用 arccos，式 1.133e 用 arctan）：

```
(1.133c)  φ = { arccos(a/ρ),    b ⩾ 0, ρ > 0
              { −arccos(a/ρ),   b < 0,  ρ > 0
              { 无定义,          ρ = 0

(1.133e)  φ = { arctan(b/a),             a > 0
              { π/2,                      a = 0, b > 0
              { −π/2,                     a = 0, b < 0
              { arctan(b/a) + π,          a < 0, b ⩾ 0
              { arctan(b/a) − π,          a < 0, b < 0
```

两套公式在边界情形（b = 0、a < 0 且 b = 0）给出一致结果（φ = 0 或 π），与主值区间 (−π, +π] 自洽；分段计算依赖[[concepts/反三角函数]]的主值约定。（源文中 ρ = √(a² + b²) 无编号，编号 (1.133d) 空悬于 arctan 分段式之前，归属存疑。）

模与辐角是复数三角形式与指数形式（见 [[concepts/欧拉公式]]）的坐标，"模相乘除、辐角相加减"的乘除规则即建立在其上。
