# 等差级数

等差级数是其项构成等差数列的有限级数，即相邻项之间存在恒定差值的求和结果。《数学手册(原书第10版)》1.2.2 将其分为一阶与 k 阶两种情形。

## 一阶等差级数（式 1.52）

相邻两项的差是常数 $d$：

$$\Delta a_i = a_{i+1} - a_i = d = \text{常数}, \quad \text{故} \quad a_i = a_0 + id \tag{1.52a}$$

部分和为

$$s_n = a_0 + (a_0 + d) + (a_0 + 2d) + \dots + (a_0 + nd) \tag{1.52b}$$

$$s_n = \frac{a_0 + a_n}{2}(n+1) = \frac{n+1}{2}(2a_0 + nd) \tag{1.52c}$$

## k 阶等差级数（式 1.53）

k 阶等差级数是序列 $a_0, a_1, \dots, a_n$ 的 k 阶差分 $\Delta^k a_i$ 为常数的有限级数（差分的定义、递推与差分表见 [[concepts/差分]]）。通项与前 n 项和由 Newton 前向差分型公式给出（式 1.53c–d）：

$$a_i = a_0 + \binom{i}{1}\Delta a_0 + \binom{i}{2}\Delta^2 a_0 + \dots + \binom{i}{k}\Delta^k a_0 \quad (i = 1, 2, \dots, n)$$

$$s_n = \binom{n+1}{1}a_0 + \binom{n+1}{2}\Delta a_0 + \binom{n+1}{3}\Delta^2 a_0 + \dots + \binom{n+1}{k+1}\Delta^k a_0$$

## 相关公式与概念

- 式 1.55–1.58（自然数、一般起点 $p$、奇数、偶数之和）是一阶等差求和的特例，完整目录见 [[concepts/幂和公式]]。
- 算术平均 $x_A = \frac{a+b}{2}$ 使三数 $a, x_A, b$ 构成等差数列，见 [[concepts/均值]]。
- 与 [[concepts/等比级数]] 相对：差为常数 vs 比为常数。
