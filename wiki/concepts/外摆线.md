# 外摆线

**外摆线**是一个动圆沿着一个定圆的**外侧**做无滑动滚动时，动圆圆周上一点的轨迹；其整体形态由定圆与动圆半径之商 $m = A/a$ 完全决定。在 [[concepts/摆线族|摆线族]] 中它是圆外滚动、$\lambda = 1$ 的成员，与 [[concepts/内摆线]] 经「−a 代换」互为对偶。

## 方程

$$x = (A + a) \cos \varphi - a \cos \tfrac{A + a}{a} \varphi, \qquad y = (A + a) \sin \varphi - a \sin \tfrac{A + a}{a} \varphi \quad (-\infty < \varphi < \infty),\tag{2.244}$$

其中 $A$ 为定圆半径，$a$ 为动圆半径，$\varphi$ 为角 $\angle C_0x$。

## 按 m = A/a 的三分类

- **m = 1**：曲线为 [[concepts/心脏线]]（手册指参见第 129 页 2.12.4）。
- **m 为整数**：曲线由围绕定圆的 $m$ 个形状相同的分支组成；尖点 $(\rho = A,\ \varphi = 2k\pi/m)$、顶点 $(\rho = A + 2a,\ \varphi = \tfrac{2\pi}{m}(k+\tfrac12))$，$k = 0, 1, \dots, m-1$。
- **m 为非整有理数**：相同分支依次绕定圆并逐一与前一分支相交，动点经有限次循环后回到起点（闭合）。
- **m 为无理数**：动点往返无穷多次，永不回到起点（不闭合）。

## 几何量

- 单支长 $L_{A_1B_1A_2} = \dfrac{8(A+a)}{m}$；整数 m 时封闭曲线总长 $L_{\text{总}} = 8(A+a)$。
- 区域 $A_1B_1A_2A_1$ 的面积（**不包括定圆部分**）$S = \pi a^2\dfrac{3A+2a}{A}$；对整数 m，各支区域面积与定圆面积之和即曲线围成的全面积。
- 曲率半径 $r = \dfrac{4a(A+a)}{2a+A}\sin\dfrac{A\varphi}{2a}$；顶点处 $r_B = \dfrac{4a(A+a)}{2a+A}$。

特化核验（推导，非手册明文）：m = 1（A = a）时总长 $16a$、区域面积 $5\pi a^2$（全面积 $6\pi a^2$）、$r_B = 8a/3$，均与经典心脏线结果一致；详见 [[findings/外摆线按m的三分类与几何量]]。
