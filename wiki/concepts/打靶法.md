# 打靶法

打靶法将边值问题的解化为初值问题的解。**单目标打靶法**：以初始斜率参数 s 构造初值问题

```latex
(19.134)  y'' + p(x)y' + q(x)y = f(x),   y(\alpha)=\alpha,\ y'(\alpha)=s   [记号疑为 y(a)=\alpha,\ y'(a)=s]
(19.135)  F(s) = y(b, s) - \beta = 0
```

关联于边值问题 (19.118)。初值问题 (19.134) 的解依赖参数 s：y = y(x, s)；根据 (19.134)，y(x,s) 满足第一个边界条件 y(a,s) = α；参数 s 应由第二个边界条件 y(b,s) = β 确定，即求解方程 (19.135)。

源文明确指出：**试位法（割线法）就是适当的求解方法**——这是 [[concepts/试位法]]（19.1 节）应用域向边值问题参数方程的扩展；只需要求出函数 F(s) 的值，但对每一个特别的参数 s，计算函数值都需要求解初值问题 (19.134) 直到 x = b（计算方法即 19.4.1）。

**多目标打靶法**：积分区间 [a,b] 被分为子区间，在每个子区间上用单目标打靶法；要求的解由子区间上的解构成，必须保证在子区间的端点连续过渡，这就要求更多的条件；大多用于非线性边值问题的数值实现见 [19.31]。流程见 [[methodology/打靶法求解边值问题流程]]；与其他两类边值方法比较见 [[comparisons/边值问题三类方法比较]]。
