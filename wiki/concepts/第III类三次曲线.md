# 第III类三次曲线

第III类三次曲线是手册 2.4.5 对函数

```latex
y = x/(ax² + bx + c),  a ≠ 0, b ≠ 0, c ≠ 0    (2.49)
```

的图像的称呼：其隐式方程 y(ax² + bx + c) = x 含 x²y 项，为三次代数曲线。图像过原点，x 轴为一条 [[concepts/渐近线]]。

性状除与 a 及 Δ = 4ac − b² 的符号有关外，Δ = 0 时还与 b 的符号有关、Δ < 0 时还与方程 ax² + bx + c = 0 的根 α, β 的符号有关；a < 0 情形经沿 x 轴反射化为 a > 0。手册共给出 6 种行为模式（详见 [[findings/第III类三次曲线的六种行为模式与极值点配对]]）：

- **Δ > 0**：处处连续，函数值由 0 减到极小、增到极大、再减到 0；[[concepts/极值]]点 A, B = (±√(c/a), (−b ± 2√(ac))/Δ)（± 为同号配对），曲线有三个[[concepts/拐点]]；
- **Δ = 0, b > 0**：间断点 x = −b/(2a)（二重极点，两侧均趋于 −∞）；函数值由 0 减到 −∞，过间断点后由 −∞ 增至极大值再减到 0；极大值点 A(√(c/a), 1/(2√(ac)+b))；一个拐点；
- **Δ = 0, b < 0**：函数值由 0 减到极小值，经原点增至 +∞，过间断点 x = −b/(2a)（二重极点，两侧均趋于 +∞）后由 +∞ 减到 0；极小值点 A(−√(c/a), −1/(2√(ac)−b))；一个拐点；
- **Δ < 0, α、β 符号互异**：两个一重间断点，曲线过原点，无极值，一个拐点；
- **Δ < 0, α、β 均为负 / 均为正**：两个一重间断点，各有一个极小值与一个极大值（用情形 Δ > 0 的极值点公式计算），一个拐点。

源文的双重 ± 未明示配对方向，经推导应为同号配对（+√(c/a) 对应 −b + 2√(ac)）；此转写模式与 [[queries/三次极值点横坐标公式的负号位置是否转写有误]] 类似。另见 [[comparisons/三类三次曲线比较]]。
