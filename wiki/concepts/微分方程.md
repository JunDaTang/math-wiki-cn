# 微分方程

微分方程（differential equation）是这样一个方程：它联系一个或多个变量、这些变量的一个或多个函数、以及这些函数关于这些变量的导数。本定义出自《数学手册(原书第10版)》第9章章首定义 (1)（章首文字存在形近讹替，此处引校改读法，见 [[第9章章首定义形近讹替复校]]）。括注英文为通行术语背景，手册原文仅于「阶」一处附英文 (order)。

## 阶

一个微分方程的阶（order）等于其中出现的导数最高的阶数。依此判阶，《数学手册》第9章章首三例中，例 A 为一阶，例 B 判读为二阶（推断），例 C 为二阶。

## 常微分方程与偏微分方程之分

依第9章定义 (2)，二者的差别在于自变量的数目：只有一个自变量者为 [[常微分方程]]，有几个自变量者为 [[偏微分方程]]。手册分别以 9.1、9.2 两小节论之。

## 微分形式记法

微分方程可用 dx、dy 的齐次微分式书写。手册例 B 即采此记法（原文 LaTeX 逐字）：

$x \mathrm { d } ^ { 2 } y \mathrm { d } x - \mathrm { d } y ( \mathrm { d } x ) ^ { 2 } = \mathrm { e } ^ { y } ( \mathrm { d } y ) ^ { 3 }$

以 (dx)³ 通除各项，可化为导数形式 x y″ − y′ = e^y (y′)³；因原文排印中 d²y 与 dx 的乘积归属含混，此转化属判读（见 [[第9章全节系统性转写讹误清单]]）。

## 手册例式

第9章章首给出 A、B、C 三例（原文与逐字 LaTeX 见 [[10-数学手册原书第10版--8-第9章-微分方程--1j96pxc]]）：例 A 为一阶常微分方程，例 B 为微分形式书写（判读为二阶常微分方程），例 C 为二阶偏微分方程。三例为示意性数学对象，其阶数判读为依定义之推断。
