# 二次多项式

二次多项式（二次函数）是形如

$$y = a x^{2} + b x + c \tag{2.41}$$

的二次整有理函数，其图像是一条以 $x = -\dfrac{b}{2a}$ 为垂直对称轴的**抛物线**（详见 [[抛物线]]；原文对抛物线的详细说明置于第 275 页 3.5.2.10）。

## 单调性与极值

- a > 0：先单调递减、取得最小值，再单调递增；顶点为极小值点；
- a < 0：先单调递增、取得最大值，再单调递减；顶点为极大值点。

极值概念见 [[极值]]；顶点坐标为 $C\left(-\dfrac{b}{2a},\ \dfrac{4ac - b^2}{4a}\right)$。

## 与坐标轴的交点：判别式三分类

记 $D = b^2 - 4ac$（即 [[二次方程]] 的判别式，见 [[判别式]]）：

| 条件 | 与 x 轴的交点 |
|---|---|
| $D > 0$ | 两个交点 $A_{1,2}\left(\dfrac{-b \pm \sqrt{b^2-4ac}}{2a},\ 0\right)$ |
| $D = 0$ | 一个交点（切点，即二重根） |
| $D < 0$ | 无交点 |

与 y 轴的交点恒为 $B(0,\ c)$。本节采用正向约定（$b^2-4ac$ 与 0 比较）；与 1.6 处所记「反号约定」是否一致，见 [[2-3-2与1-6的二次判别式符号约定是否一致]]。

## 关联

- 三分类与 [[二次方程]] 的求根公式一一对应：交点横坐标即根，切点即二重根；与 [[二次不等式]] 的配方解法共享同一判别式骨架。
- 二次多项式是 [[多项式]] 家族中 n = 2 的情形，符合 [[n次多项式]] 的偶次规律：两端同向、极值个数恰为奇数（1 个）、拐点 0 个。
- 仅保留最高次项时即 [[n次抛物线]] $y = ax^2$（n=2）。
