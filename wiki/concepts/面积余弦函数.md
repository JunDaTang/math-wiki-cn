# 面积余弦函数

面积余弦函数（式 2.208）是 [[concepts/双曲余弦函数]] cosh 的反函数。由于 cosh 有两个单调区间，存在两支反函数：

$$
y = \operatorname{Arcosh} x \quad {\text {和}} \quad y = - \operatorname{Arcosh} x \tag{2.208}
$$

主支 y = Arcosh x 的定义域为 1 ≤ x < ∞、值域为 0 ≤ y < ∞；负支 y = −Arcosh x 的值域为 −∞ < y ≤ 0。等价表达式为 x = cosh y。主支的选取（y ≥ 0）是 [[concepts/主值]] 概念的直接体现，与 arccos 的主值讨论完全平行。

## 基本表示（仅对 x ≥ 1 有定义）

$$
\operatorname{Arcosh} x = \ln \left(x + \sqrt {x ^ {2} - 1}\right) = \ln \left(\frac {1}{x - \sqrt {x ^ {2} - 1}}\right) (x \geqslant 1) \tag{2.212}
$$

第二个等式（倒式表示）经有理化核验恒等。

## 图像要素（图 2.54）

- 仅当 x ≥ 1 时有定义；
- 曲线起点 A(1, 0)，此处有一条垂直切线；

## 关系式

- 互表：Arcosh x = Arsinh √(x²−1) = Artanh(√(x²−1)/x) = Arcoth(x/√(x²−1))（|x| ≥ 1），见 [[findings/四种面积函数的互表关系]]。
- 和差：Arcosh x ± Arcosh y = Arcosh(xy ± √((x²−1)(y²−1)))（式 2.220）——其减法分支仅在 x ≥ y 时成立，手册未注明该条件，见 [[queries/式2-220减法分支是否缺少x大于等于y条件]]。
- 无奇偶性：当 x < 1 时 Arcosh x 无定义。
