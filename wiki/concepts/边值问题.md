# 边值问题

**边值问题**（boundary value problem）是附加条件分布在定义域中若干点处的一类常微分方程定解问题：解及/或其导数在若干点处取给定的值（**边界条件**），用以确定通解的任意常数（手册 9.1 要点 4 的表述）。手册 9.1.3 的一般表述为：所求之解必须在自变量一个区间的**端点**处满足事先给定的关系。边值问题区别于所有附加条件集中于同一点的 [[初值问题]]（平行比较见 [[初值问题与边值问题比较]]）。《数学手册》指出这类问题「在不同的应用中，例如，在数学物理中」经常出现。

## 定义

手册 9.1 对边值问题的定义存在宽窄两种表述，9.1.3 则给出逐层收窄的定义分层。

### 手册 9.1 的两种宽窄表述

- **要点 2（简述）**：如果在区间的**两个端点**都有给定的值，则求解的问题被称为一个边值问题。
- **要点 4（详述）**：如果一个常微分方程的解和/或其导数在其定义域中的**几个点处**被给出，那么这些值被称为**边界条件 (boundary conditions)**；具有边界条件的一个微分方程被称为**边值问题 (boundary value problem)**。

要点 4 的表述更一般；暂以要点 4 为准，最终以 9.1.3「边值问题」小节的讨论为准（见下）。相关讨论见 [[例1条件c等于0与边值问题定义宽窄]] 与 [[9-1-1至9-1-3子小节未入库回指缺口]]。

### 手册 9.1.3 的定义分层

手册 9.1.3 将讨论逐层收窄：

1. **一般边值问题**：解在自变量区间的端点处满足事先给定的关系；
2. **线性边值问题**（特殊情形）：线性微分方程的解满足线性边值条件；
3. **讨论范围**：具有线性边值（条件）的**二阶**微分方程，且进一步限于自伴形式 (9.67a)（见 [[自伴微分方程]]）配**齐次分离**线性边值条件 (9.67b)；
4. 一般二阶方程经 [[二阶线性方程自伴化代换流程]] 化入自伴形式；非齐次条件 (9.67e) 经 [[非齐次边值问题齐次化代换]]（y = z + u）归结为齐次条件。

这一「由一般到特殊」的收窄策略，为 [[例1条件c等于0与边值问题定义宽窄]] 中「附加条件属于哪一层」的讨论提供了语境。

## 齐次与非齐次

- 当 f = 0 时，方程 (9.67a) 称为与非齐次边值问题（inhomogeneous boundary value problem）相伴的**齐次边值问题**（homogeneous boundary value problem）。
- 非齐次边值条件形如 (9.67e)（端点关系式右端为 C₀、C₁）。

## 可解性与本征值

对给定参数 λ 存在**可解性二分法**：

- 或者非齐次问题对任意 f 有唯一解（齐次问题仅有平凡解）；
- 或者齐次问题有非平凡解（此时非齐次问题对任意右端未必可解、解不唯一）。

后一情形的 λ 即**本征值**，由此引出 [[斯图姆-刘维尔问题]] 与 [[本征值与本征函数]]；与初值问题的对照维度见 [[初值问题与边值问题比较]]。

## 变体

- **奇异边值问题**：在端点奇性（如 p(x) = 0）处，以连续性/有限性/有界阶增长条件替代齐次边界条件，见 [[奇异边值问题]]。
- **周期型条件** (9.70)：耦合两端点值的条件，见 [[周期边界条件]]、[[分离边界条件与周期边界条件比较]]。

## 手册算例（9.1）：端点固定、均匀负载的细棒

端点固定和均匀负载的细棒形成的曲线由具有边界条件 y(0) = 0, y(1) = 0 的微分方程 y″ = x − x²（0 ≤ x ≤ 1）所描述，其解为

y = x³/6 − x⁴/12 − x/12。

复算：两次积分得 y = x³/6 − x⁴/12 + c₁x + c₂；由 y(0) = 0 得 c₂ = 0，由 y(1) = 0 得 1/6 − 1/12 + c₁ = 0，即 c₁ = −1/12。见 [[9-1三算例复算]]。

> **注**：此解只属于该特定方程与边界条件，描述该算例本身的曲线，不应外推。
