# 共轭条件（二次问题有限步终止）

共轭条件是 [[concepts/可行方向方法]] 应用于 [[concepts/二次优化]] 问题 $f(x)=x^{\mathrm{T}}Cx+p^{\mathrm{T}}x=\min!,\ Ax\leqslant b$ 时，为**在有限步内解得**而在方向搜索程序中追加的线性条件（式 18.104）：

```
d^{k−1 T} C d = 0                                      (18.104)
```

左端方向为上一步方向 $d^{k-1}$；原书右端印作无上标的 $d$，疑脱上标 $k$（见 [[queries/式18-104第二个d疑脱上标k之辨]]；另一解读是 $d$ 为程序变量、与式 18.100/18.103 的记法一致）。

## 启用与移除规则

- 若在某步成立 $\alpha_{k-1}=\alpha'_{k-1}$（上一步步长由一维极小决定，即 $x^k$ 是一「内」点），则在方向搜索程序中**加上**条件 (18.104)；
- 此前各步骤中已加入的相应条件均保留不变；
- 若往后某一步有 $\alpha_k=\alpha_k''$（步长被可行集边界截断），则把条件 (18.104) **去掉**。

## 机理（背景注记）

原书仅陈述规则与「有限步内解决」的结论，未给出证明。按共轭方向法的标准理论（此为可独立验证的背景知识，非源内证据），相继方向满足 $d^{k-1\mathrm{T}}Cd^k=0$ 时方向序列关于目标函数的 Hessian 矩阵 $C$ 互相共轭，张成的搜索子空间逐步扩大而不重复，故二次问题有限步可解。

## 证据

原书算例的步长类型序列为 ″、″、′，无连续 ′ 型步；进入第 4 步方向搜索时程序直接以 $\sigma=0$ 终止，共轭条件对迭代轨迹无实际影响（[[findings/可行方向法算例四步复算]]）。即源内未提供该条件实际发挥作用的数值演示。
