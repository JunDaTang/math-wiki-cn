# 完全图 K_n

**完全图（complete graph）**：如果一个（有限）简单图的顶点集中任何两个顶点都被一条边连接，则将它称为完全图。顶点集有 n 个元素的完全图记为 K_n。

手册以图 5.28 给出图例，图注（转写残缺）称「5.28 表示有 n 个顶点的完全图」。

## 转写疑点

原文定义作「对于顶点集为 … 的**无限**简单图，若 … 中任何两个顶点都被一条边连接，则将它称为完全图」，但紧接「顶点集有 n 个元素的完全图记为 K_n」，语义不协调——「无限」疑为「有限」之讹，见 [[queries/完全图定义无限是否应为有限]]。
