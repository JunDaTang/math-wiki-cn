# 广义微分中值定理

广义微分中值定理（柯西定理，通行的柯西中值定理，Cauchy 中值定理）是《数学手册(原书第10版)》6.1.4.6 的定理：若两函数 y=f(x) 和 y=φ(x) 在闭区间 [a,b] 连续、至少在区间内部可微，且在该区间上 φ′(x) ≠ 0，则 a、b 间至少存在一点 c，使得两函数差商之比等于该点导数之比：(f(b)−f(a))/(φ(b)−φ(a)) = f′(c)/φ′(c)（式 6.32）。

## 几何解释（参数曲线）

广义中值定理的几何意义与第一个中值定理（[[concepts/微分中值定理]]）相对应：设图 6.9 曲线的参数方程为 x=φ(t)、y=f(t)，点 A、B 分别对应参数 t=a、t=b 的函数值，则在点 C 处

```latex
(6.33)  \tan\alpha = \frac{f(b)-f(a)}{\varphi(b)-\varphi(a)} = \frac{f'(c)}{\varphi'(c)}
```

## 退化关系

当 φ(x)=x 时，广义中值定理简化成了第一个中值定理（来源明言；经代入核验成立：φ(b)−φ(a)=b−a、φ′(c)=1，式 6.32 化为式 6.29a）。
