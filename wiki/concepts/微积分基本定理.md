# 微积分基本定理

**微积分基本定理**指出：若被积函数 $f(x)$ 在区间 $[a,b]$ 上连续，$F(x)$ 为其[[concepts/原函数]]，则

$$\int_a^b f(x)\,\mathrm{d}x = \int_a^b F'(x)\,\mathrm{d}x = F(x)\Big|_a^b = F(b)-F(a),\tag{8.40}$$

即**定积分的计算可以化成相应的不定积分的计算**，也就是确定反导数：

$$F(x)=\int f(x)\,\mathrm{d}x + C.\tag{8.41}$$

表 8.5 将其列为定积分重要性质之首，条件标注为「$f(x)$ 连续」。

## 意义

- 沟通 8.1 章[[concepts/不定积分]]与 8.2 章[[concepts/定积分]]：微分与积分互逆；
- 是计算定积分的**主要方法**（8.2.1.4.1）：实际计算时可利用表 21.7（p. 1382 积分表）或计算机代数系统（第 20 章），两者均未入库；
- **告诫**：作积分限的代换之前，要事先检查原积分是否为广义积分（8.2.3）。

## 可积性与原函数存在性的区分

本节明确论断：**可积函数不一定有原函数，但连续函数一定有原函数**。连续函数原函数的存在性由[[concepts/变上限积分]]构造性地证明（式 8.43–8.44）。

## 算例（均独立复算通过）

- A：$\int_0^\pi\sin x\,\mathrm{d}x = -\cos x\big|_0^\pi = 2$ ✓
- B：$\int_0^{2\pi}\sin x\,\mathrm{d}x = -\cos x\big|_0^{2\pi} = 0$ ✓
- 代换法：$\int_0^a\sqrt{a^2-x^2}\,\mathrm{d}x = \pi a^2/4$（四分之一圆面积）✓
- 分部积分：$\int_0^1 xe^x\,\mathrm{d}x = [xe^x]_0^1-\int_0^1 e^x\,\mathrm{d}x = e-(e-1)=1$ ✓

详见[[findings/式8-40至8-42基本定理几何意义与两算例复算]]与[[findings/定积分的变换两算例复算]]。
