# 多步法（线性多步法）

多步法是利用多个已算节点值推进的初值问题数值方法，与仅由 y_i 计算 y_{i+1} 的单步法（欧拉法、龙格—库塔法）相对。一般线性多步法形式 (19.101)：

```latex
(19.101)  y_{i+k} + \alpha_{k-1} y_{i+k-1} + \dots + \alpha_1 y_{i+1} + \alpha_0 y_i
          = h(\beta_k f_{i+k} + \beta_{k-1} f_{i+k-1} + \dots + \beta_1 f_{i+1} + \beta_0 f_i),  \alpha_k = 1
```

其中 f_{i+j} = f(x_{i+j}, y_{i+j})。要点：

- **显式/隐式**：β_k = 0 时右端仅含已知值 y_i,…,y_{i+k−1}，为显式；β_k ≠ 0 时两端都需求新值 y_{i+k}，为隐式。
- **起步值**：k 步法中 k 个初值 y₀,…,y_{k−1} 必须已知，可由单步法求得。
- **推导路线**：导数由差分公式代替（参见 9.1.1.5，未入库），或积分 (19.95) 由求积公式近似（参见 19.3.1，未入库）。
