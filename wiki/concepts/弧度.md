# 弧度

**弧度**（radian，单位符号 rad）是角的一种度量：任意一个圆的圆心角 $\alpha$ 的大小，由它所对应的弧长 $l$ 与圆的半径 $r$ 之比给定：

$$\alpha = \frac{l}{r}.$$

单位 **1 rad** 定义为与弧长等于半径（$l = r$）的弧对应的圆心角。弧度本质上是弧长与半径之比（无量纲量）；当文中明显可看出数值指角的弧度时，标记 rad 通常被省略。

## 与度制的换算

$$\alpha^{\circ} = \varrho\alpha = 180^{\circ}\frac{\alpha}{\pi}, \qquad \alpha = \frac{\alpha^{\circ}}{\varrho} = \frac{\pi}{180^{\circ}}\alpha^{\circ}, \qquad \varrho = \frac{180^{\circ}}{\pi}.$$

常用常数：1 rad = 57°17′44.8″ = 57.2958°；1° = 0.017453 rad；1′ = 0.000291 rad；1″ = 0.000005 rad。特殊值：$360^{\circ} = 2\pi$，$180^{\circ} = \pi$，$90^{\circ} = \pi/2$，$270^{\circ} = 3\pi/2$。
