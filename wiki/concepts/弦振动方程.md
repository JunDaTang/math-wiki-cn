# 弦振动方程

**弦振动方程**（一维波动方程）是描述被拉紧的弦的振动的二阶线性双曲型偏微分方程：

$$\frac{\partial^{2} u}{\partial t^{2}} = a^{2} \frac{\partial^{2} u}{\partial x^{2}} \tag{9.92a}$$

按手册判别式 δ = AC − B²（A = a², C = −1, B = 0 → δ = −a² < 0）属双曲型。

## 定解问题（算例 A）

两端固定弦的边界与初始条件（式 9.92b）：

```
u|_{t=0} = f(x)，∂u/∂t|_{t=0} = φ(x)，u|_{x=0} = 0，u|_{x=l} = 0
```

分离变量 u = X(x)T(t) 得 X″ + λ²X = 0 与 T″ + a²λ²T = 0；边界条件强制分离常数为负（非负常数只给平凡解 u ≡ 0），并由 sin(λl) = 0 得本征值 λ_n = nπ/l (n = 1, 2, …)。解为正弦级数：

$$u = \sum_{n=1}^{\infty}\left(a_n \cos\frac{na\pi t}{l} + b_n \sin\frac{na\pi t}{l}\right)\sin\frac{n\pi x}{l}$$

系数由初始条件展为傅里叶正弦级数确定（式 9.92k）：

$$a_n = \frac{2}{l}\int_0^l f(x)\sin\frac{n\pi x}{l}\,\mathrm{d}x,\qquad b_n = \frac{2}{na\pi}\int_0^l \varphi(x)\sin\frac{n\pi x}{l}\,\mathrm{d}x$$

（b_n 的因子 1/(naπ) 来自对 ∂u/∂t|_{t=0} 的正弦展开反解，复算通过。）
