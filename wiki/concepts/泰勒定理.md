# 泰勒定理

泰勒定理（泰勒公式/泰勒展开式，Taylor 定理）是微分学中的多项式逼近定理：《数学手册(原书第10版)》6.1.4.5 表述为——若函数 y=f(x) 在区间 [a, a+h] 上 n−1 次连续可微（具有连续导数），且在区间内部存在 n 阶导数，则 f(a+h) 可展开为 f(a) 处各阶导数构成的 n−1 次多项式加上拉格朗日余项 (hⁿ/n!)·f⁽ⁿ⁾(a+Θh)，其中 0 < Θ < 1（式 6.31）。

完整转录与题设两条件见 [[findings/泰勒公式拉格朗日余项-式6-31]]。

## 与微分中值定理的关系

来源明确断言：微分中值定理（式 6.29b）是泰勒公式在 n=1 时的特例。该断言经代入核验成立（n=1 时式 6.31 的多项式部分仅剩 f(a)，余项恰化为 h·f′(a+Θh)），见 [[findings/泰勒公式拉格朗日余项-式6-31]]。

## 转写注记

原文「其中 0 < Θ < 1, 可正可负」疑在「可正可负」前脱落 h 字（应为 h 可正可负）；「n-l 次连续可微」「存在 阶导数」「n=l 时」均为 OCR 讹误，订正意见见 [[queries/6-1-4全节系统性转写讹误清单]]。
