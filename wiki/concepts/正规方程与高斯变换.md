# 正规方程与高斯变换

正规方程是由线性最小二乘问题（19.40）经必要条件 ∂F/∂x_k=0 导出的线性方程组：

$$A^{\mathrm T}A\,\underline{x} = A^{\mathrm T}\underline{b}. \tag{19.42}$$

从超定方程组 Ax=b（19.38）到（19.42）的变换称为**高斯变换**，因为该方程组是由高斯最小二乘法得到的（本源回指第 611 页 6.2.5.5，未入库，见 [[queries/19-2未入库回指缺口]]）。当 A 列满秩时 AᵀA 为 n×n 正定矩阵，故正规方程可由 [[concepts/楚列斯基分解]] 数值求解。

关键限制（仅属于正规方程路线，不得外推到最小二乘问题本身）：若 AᵀA 的条件数（本源外引文献 [19.31]，未入库）过大，数值求解正规方程便有困难，其解的相对误差也大。因此本源建议改用正交化方法（[[concepts/QR分解与正交化方法]]），系统比较见 [[comparisons/正规方程法与正交化方法比较]]。

译名提示：同一 normal equations 在 19.2.1.3 译作“正规方程”、在 19.2.2.3（19.66 处）译作“正则方程”，两处指同一对象，见 [[queries/正规方程与正则方程译名不一致之辨]]。
