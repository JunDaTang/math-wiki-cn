# 韦伯微分方程（简单形式）

韦伯微分方程的简单形式指二阶线性常微分方程

```latex
\frac{d^{2}\Psi}{dy^{2}}+(\lambda-y^{2})\Psi=0   % 9.143d
```

属抛物柱面型方程（parabolic cylinder equation）一类；线性谐振子的薛定谔方程经无量纲代换 y = x√(mω/ℏ)、λ = 2E/ℏω（9.143b/c，λ 是参数而不是波长）后即化为此形式。

## 求解路径

- 设 Ψ = e^{−y²/2}H(y)（9.144a），求导代入（9.144b）后化为埃尔米特型方程 H″ − 2yH′ + (λ−1)H = 0（9.144c）。
- 幂级数解与截止条件（λ = 2n+1，9.146b）使 H 成为埃尔米特多项式（[[entities/埃尔米特多项式]]），完整流程见 [[methodology/谐振子幂级数解与截止条件流程]] 与 [[concepts/量子线性谐振子]]。

## 与韦伯函数 Yₙ(x) 的辨析

此「韦伯微分方程」与库内 [[entities/韦伯函数]] Yₙ(x)（贝塞尔微分方程的第二解族）同名不同物，仅共享人名 Weber：前者是抛物柱面/埃尔米特型，后者是贝塞尔型。两页已互加辨析，避免混淆。
