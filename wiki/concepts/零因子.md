# 零因子（奇异元素）

零因子（奇异元素）是环 R 中的非零元 a：若存在环的非零元 b 使得 a * b = 0，则称 a（对称地，b）为零因子。零因子的存在意味着「乘积为零 ⇒ 某因子为零」这一消去推理在环中失效。

## 定义与失效的蕴涵

源文：环的非零元称为零因子或奇异元素，如果存在环的非零元使得它们的积等于零。在有零因子的环中，下列蕴涵关系一般是错误的：

$$
a * b = 0 \Rightarrow (a = 0 \lor b = 0).
$$

## 本源中的零因子实例

- **[[entities/矩阵环mn]]**：当 n = 2 时 $\begin{pmatrix}1&0\\1&0\end{pmatrix}\begin{pmatrix}0&0\\1&1\end{pmatrix} = \begin{pmatrix}0&0\\0&0\end{pmatrix}$（已复算 ✓）；
- **[[entities/剩余类环zn]]（n 为合数）**：ℤ₆ 中 $[3]_6 \odot [2]_6 = [0]_6$（已复算 ✓）；
- **ℤ_{pⁿ}（n > 1）**：因 pⁿ 为合数而有零因子，这正是 GF(pⁿ) ≠ ℤ_{pⁿ} 的原因（见 [[comparisons/gfpn与zpn比较]]）。

## 与整区的对立

「没有零因子」是 [[concepts/整区]] 的定义条件；无零因子的环正是使上述蕴涵关系成立的环。域（见 [[concepts/除环与域]]）作为整区必无零因子。
