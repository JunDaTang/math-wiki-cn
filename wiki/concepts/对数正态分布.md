# 对数正态分布

**对数正态分布**（参数 μ_L, σ_L²）是「取对数后服从正态分布」的正值随机变量的分布：称连续随机变量 X 服从参数为 μ_L、σ_L² 的对数正态分布，若 X 全部取正值，且由

```
Y = log X        (16.76)
```

定义的随机变量 Y 服从期望为 μ_L、方差为 σ_L² 的 [[正态分布]]。

## 密度函数与分布函数

```
f(t) = { 0,  t ⩽ 0;
       (log e)/(t·σ_L·√(2π)) · exp(−(log t − μ_L)²/(2σ_L²)),  t > 0 }        (16.77a)
F(x) = { 0,  x ⩽ 0;
       1/(σ_L·√(2π)) · ∫_{−∞}^{log x} exp(−(t−μ_L)²/(2σ_L²)) dt,  x > 0 }        (16.77b)
```

实际应用中主要使用自然对数或常用对数（(16.77a) 中的因子 log e 是对数底换算因子：自然对数时 log e = 1，公式退化为标准形式）。

## 期望和方差

```
μ = exp(μ_L + σ_L²/2),   σ² = (exp σ_L² − 1)·exp(2μ_L + σ_L²)        (16.78)
```

（已复核：与标准对数正态矩公式一致。）

## 性质

- 密度函数处处连续，且只对正的自变量取正值（图 16.6 给出 μ_L、σ_L 取不同值时的密度图，使用自然对数）；
- μ_L、σ_L² 不是 X 本身的期望和方差，而是 Y = log X 的期望和方差；X 自身的期望和方差即 (16.78)；
- 分布函数值可经 [[标准正态分布]] 计算：

```
F(x) = Φ((log x − μ_L)/σ_L)        (16.79)
```

- 正态分布可用于大量独立随机变量的加法叠加，对数正态分布可用于大量独立随机变量的乘法叠加；
- 常应用于经济学、技术、生物过程中的寿命分析。
