# 梯度算子的运算法则

梯度算子的运算法则是数学手册(原书第10版) 13.2.6.2 给出的两条形式规则——线性性与乘积法则——以及配套的「↓ 标记」记号法，使 ∇ 可像向量一样参与代数运算。它与 13.2.2 中单个算子 grad 的运算法则（[[concepts/梯度的运算法则]]）平行成对。

## 线性性

∇ 置于系数 aᵢ 与点函数 Xᵢ 的线性组合之前时，与这些函数是标量函数还是向量函数无关：

$$\nabla\left(\sum a_i X_i\right) = \sum a_i \nabla X_i. \tag{13.69}$$

## 乘积法则与 ↓ 标记法

∇ 作用于标量函数或向量函数的乘积时，必须**顺次作用在每个函数上**，其结果是它们之和；函数符号上带 ↓ 者为当前被 ∇ 作用的函数：

$$\nabla(XYZ) = \nabla(\overset{\downarrow}{X}YZ) + \nabla(X\overset{\downarrow}{Y}Z) + \nabla(XY\overset{\downarrow}{Z}) = (\nabla X)YZ + X(\nabla Y)Z + XY(\nabla Z). \tag{13.70}$$

在每一项中，乘积必须根据**向量代数**进行变化（因为 ∇ 只作用于带 ↓ 标记的一个函数），经过计算后就删去 ↓ 标记。

## 例 A：标量 × 向量的乘积

转写作

$$\operatorname{grad}(U\vec V) = \vec V\cdot\operatorname{grad}U + U\operatorname{div}\vec V,$$

脚注称「原文将此式最左端的 grad 误为 div」。⚠ 类型检验表明右端为标量，左端应为 **div(UV⃗)**——标准乘积法则 $\operatorname{div}(U\vec V) = \vec V\cdot\operatorname{grad}U + U\operatorname{div}\vec V$ 恰好成立，而 grad(UV⃗)（并向量型梯度）与右端类型不符；转写中间步骤 $\vec V\cdot\nabla U + U\,\nabla\cdot\vec V$ 中的显式点乘亦与 div 读法一致。译者「更正」的正确性存疑，见 [[queries/例A左端算子grad与div之辨]]。

## 例 B：标量积的梯度

$$\operatorname{grad}(\vec V_1\vec V_2) = (\vec V_2\operatorname{grad})\vec V_1 + \vec V_2\times\operatorname{rot}\vec V_1 + (\vec V_1\operatorname{grad})\vec V_2 + \vec V_1\times\operatorname{rot}\vec V_2,$$

其中 V⃗₁V⃗₂ 并置按手册惯例为标量积，推导利用三重积分解 $\vec b(\vec a\vec c) = (\vec a\vec b)\vec c + \vec a\times(\vec b\times\vec c)$。此即标准恒等式 grad(A·B) 的四项展开，复算无误（[[findings/式13-67至13-71c梯度算子与运算法则转录复算]]）。
