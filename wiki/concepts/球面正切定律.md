# 球面正切定律

球面正切定律把两边的半差/半和的正切之比与两角的半差/半和的正切之比联系起来：

```
tan((a−b)/2) / tan((a+b)/2) = tan((α−β)/2) / tan((α+β)/2)    (3.200a)
tan((b−c)/2) / tan((b+c)/2) = tan((β−γ)/2) / tan((β+γ)/2)    (3.200b)
tan((c−a)/2) / tan((c+a)/2) = tan((γ−α)/2) / tan((γ+α)/2)    (3.200c)
```

手册指出这组公式可以从纳皮尔等式推出，且与平面三角学中的正切定律类似。平面正切定律见 [[concepts/正切定律]]；球面侧的推导源头见 [[concepts/纳皮尔类比]]（式 3.199）。
