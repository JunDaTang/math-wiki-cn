# n次抛物线

n 次抛物线（n 阶抛物线）是函数

$$y = a x^{n} \quad (n \text{ 为大于零的整数}) \tag{2.44}$$

的图像（《数学手册(原书第10版)》2.3.5，图 2.15），是 [[n次多项式]] 只保留最高次项的特殊情形。

## 特殊情形 a = 1

曲线 $y = x^n$ 过点 $(0,0)$ 与 $(1,1)$，原点是它与 x 轴的切点或交点：

| n 奇偶 | 对称性 | 原点处的性质 |
|---|---|---|
| 偶 | 关于 **y 轴**对称 | 原点取得**极小值**（切点） |
| 奇 | 关于**原点**对称 | 原点为**拐点** |

曲线无渐近线。

## 一般情形 a ≠ 0

- 将曲线 $y = x^n$ 的坐标拉伸 $|a|$ 倍，得 $y = ax^n$；
- a < 0 时，再沿 x 轴反射。

原文末句「当 a < 0 时, 曲线 $y = |a|x^n$ 可由原图像沿 x 轴反射得到」主语疑错位，见 [[2-3-5反射句主语是否错位]]。

## 与低次特例的关系

- n = 1：过原点直线，即 [[正比例函数]]；
- n = 2：标准抛物线 $y = ax^2$（[[抛物线]]、[[二次多项式]] 的最简形）；
- n = 3：最简三次抛物线 $y = ax^3$（[[三次多项式]] 的最简形，原点为对称中心）。

注意：对称性结论（y 轴/原点对称）仅对 $y = ax^n$ 这一特例成立，不可移至一般的 [[n次多项式]]；n=1 时「奇 n 原点为拐点」亦退化失效。
