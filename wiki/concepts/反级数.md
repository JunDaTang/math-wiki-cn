# 反级数

反级数（级数反演）是幂级数反函数的级数表示：若 y = f(x) = ax + bx² + cx³ + dx⁴ + ex⁵ + fx⁶ + ⋯（a ≠ 0），则其反函数可展开为 x = φ(y) = Ay + By² + Cy³ + Dy⁴ + Ey⁵ + Fy⁶ + ⋯（式 7.94a–b）。反级数的存在由一次项系数 a ≠ 0 保证（与反函数微分法则中的条件一致）。

## 系数公式（式 7.94c，已复算）

```latex
A = \frac{1}{a},\quad B = -\frac{b}{a^3},\quad C = \frac{2b^2 - ac}{a^5},\quad D = \frac{5abc - a^2d - 5b^3}{a^7},
E = \frac{6a^2bd + 3a^2c^2 + 14b^4 - a^3e - 21ab^2c}{a^9},
F = \frac{7a^3be + 7a^3cd + 84ab^3c - a^4f - 28a^2b^2d - 28a^2bc^2 - 42b^5}{a^{11}}
```

推导方法为 [[系数比较法]]：把 x = φ(y) 代入原级数，展开 y 的各次幂并比较系数。系数 A–E 已手工推导核对，F 与标准级数反演公式一致，详见 [[式7-94反级数系数公式复算]]。

## 重要告诫

手册明确指出：「反级数的收敛性必须在各种情况下分别验证」——系数公式的推导是形式的，不保证所得级数在所需的 y 范围内收敛到反函数。
