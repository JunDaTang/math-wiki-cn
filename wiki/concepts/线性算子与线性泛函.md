# 线性算子与线性泛函

线性算子（同态）是同一标量域上两个向量空间之间保持线性组合的映射；当值域为标量域 𝔽 时称为线性泛函。核、值域、逆、自同态、同构等配套概念构成《数学手册(原书第10版)》12.1.5 的内容，是包括第 11 章积分算子在内的一切算子理论的抽象框架。

## 映射术语（12.1.5.1）

从 D ⊂ X 到 Y 的映射 T: D → Y 称作：

- **内射**：T(x) = T(y) ⟹ x = y（12.19）；
- **满射**：∀y ∈ Y，存在 x ∈ D 使得 T(x) = y（12.20）。

D 称作定义域（记 D_T 或 D(T)）；{y ∈ Y : ∃x ∈ D_T, T(x) = y} 称作值域，记 R(T) 或 Im(T)（转写中 R(T) 乱码为「冗(T)」）。

## 线性算子（12.1.5.2）

设 X、Y 是同一域 𝔽 上的向量空间，D 是 X 的线性子集。T: D → Y 称作线性的（线性变换、线性算子或同态），是指对任意 x, y ∈ D 和 α, β ∈ 𝔽：

$$T(\alpha x + \beta y) = \alpha T x + \beta T y. \tag{12.21}$$

对线性算子习惯使用记号 Tx。**值域** R(T) 是使方程 Tx = y 至少有一个解的所有 y 的全体。**核（零空间）**

$$N(T) = \{x \in X : Tx = 0\}$$

有时也记作 ker(T)。（复算注：由 (12.21) 直接可得 N(T) 是 X 的线性子空间、R(T) 是 Y 的线性子空间。）

> ⚠️ **一词多义消歧**：本节的「核」N(T) = ker(T) 是**算子的零空间**；与第 11 章 [[concepts/积分方程的核]] 中的**核函数** K(x,y) 同词异义，勿混淆。

X 到其自身的映射称作**自同态**。如果 T 是一个线性内射，那么由关系 y ↦ x（使 Tx = y），y ∈ R(T)（12.22）确定的 R(T) 上的映射是线性的，记作 T⁻¹: R(T) → X，称作 T 的**逆**。若 Y = 𝔽，线性映射 f: X → 𝔽 称作**线性泛函**或线性型。

## 同构（12.1.5.3）

一个「双内射」T: X → Y 称作向量空间 X、Y 的同构（映射）；两个向量空间称作同构的，是指它们之间存在同构映射。（转写疑误：「双内射」应为「双射」——同构按定义须是线性双射，见 [[queries/双内射是否应为双射]]。）
