# 内接四边形

内接四边形是有外接圆的四边形，其四条边均为该圆的弦（图 3.21(a)）。《数学手册》3.1.4.6 给出判定定理：一个四边形是内接四边形，当且仅当它的对角之和是 $180^{\circ}$（式 3.36）：

$$\alpha + \gamma = \beta + \delta = 180^{\circ}$$

## 度量公式（均仅在内接前提下成立）

- [[concepts/托勒密定理]]（式 3.37）：$ac + bd = d_1 d_2$
- 外接圆半径（式 3.38）：$R = \frac{1}{4S}\sqrt{(ab+cd)(ac+bd)(ad+cb)}$（源此处作「外切圆半径」，与小节首句「外接圆」不一致，见 [[queries/式3-38外切圆半径是否应为外接圆半径]]）
- 对角线（式 3.39a–b）：$d_1 = \sqrt{\frac{(ac+bd)(ab+cd)}{ad+bc}}$，$d_2 = \sqrt{\frac{(ac+bd)(ad+bc)}{ab+cd}}$
- 面积（式 3.40，婆罗摩笈多公式，源未冠名）：$S = \sqrt{(s-a)(s-b)(s-c)(s-d)}$，其中 $s = \frac{1}{2}(a+b+c+d)$ 为半周长
- 双心特例（式 3.41）：若内接四边形同时是外切四边形，则 $S = \sqrt{abcd}$
