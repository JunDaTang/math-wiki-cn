# 高斯误差函数

**高斯误差函数**是围绕 [[标准正态分布]] 函数 Φ(x) 的一族误差积分记号。手册 16.2.4.2 将积分 Φ(x) 称为**概率积分**或**高斯误差积分**，并给出文献中常见的另外两种记号：

```
Φ₀(x) = 1/√(2π) · ∫_{0}^{x} e^{−t²/2} dt = Φ(x) − 1/2        (16.75a)
erf(x) = 2/√π · ∫_{0}^{x} e^{−t²/2} dt = 2·Φ₀(√2·x)        (16.75b)
```

其中 erf 表示误差函数。

## 记号换算关系

- Φ₀ 是 Φ 的中心化：Φ₀(x) = Φ(x) − 1/2，即标准正态变量落在 [0, x] 内的概率；
- (16.75b) 给出 erf 与 Φ₀ 的换算。

## 转写疑点

(16.75b) 按源逐字转录的被积函数为 e^{−t²/2}，但其自附恒等式 erf(x) = 2·Φ₀(√2·x) 经复核仅当被积函数为 e^{−t²} 时成立（作代换 u = t/√2 可证 2Φ₀(√2x) = (2/√π)∫₀ˣ e^{−u²}du）。e^{−t²/2} 与该等式自相矛盾，疑为原书之误或转写之误，详见 [[式16-75b误差函数被积函数疑为e负t平方]]。疑点澄清前，引用 (16.75b) 时应同时注明两种可能。
