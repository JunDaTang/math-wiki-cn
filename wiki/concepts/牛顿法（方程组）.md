# 牛顿法（方程组）

牛顿法求解非线性方程组 F_i(x₁,…,x_n)=0（19.55）：从初始近似值出发，将 F_i 按泰勒公式展开（本源回指第 630 页 7.3.3.3，未入库）并在线性项后终止，得每步需求解的线性方程组

$$F_i(x^{(\mu)}) + \sum_{k=1}^{n}\frac{\partial F_i}{\partial x_k}(x^{(\mu)})\,\big(x_k^{(\mu+1)}-x_k^{(\mu)}\big) = 0\quad (i=1,\dots,n), \tag{19.61}$$

其系数矩阵即 [[concepts/雅可比矩阵]] F′(x^(μ))（19.62）。本源的核心论断：**若雅可比矩阵在解的邻域内可逆，牛顿法是局部平方收敛的**，即收敛基本上依赖于是否适当选取了初始近似值。

写成校正形式（代入 x_k^(μ+1)−x_k^(μ)=d_k^(μ)，原文此处脱减号）：

$$x_k^{(\mu+1)} = x_k^{(\mu)} + d_k^{(\mu)}. \tag{19.63}$$

为降低对初值的依赖性，**与松弛法类似**引入阻尼（步长）参数 γ>0（阻尼法）：

$$x_k^{(\mu+1)} = x_k^{(\mu)} + \gamma\, d_k^{(\mu)}\quad (\gamma>0), \tag{19.64}$$

γ 的确定方法本源外引 [19.31]（未入库，见 [[queries/19-2未入库回指缺口]]）。

语境消歧：此处的阻尼牛顿法是**方程组求根**语境；维基已有 [[concepts/阻尼牛顿法]] 建于 18.2.5 **无约束优化**语境（目标函数下降），两者为同一思想的不同应用，比较见 [[comparisons/牛顿法（无约束优化）与牛顿法（方程组）比较]]。步长 γ 与 [[concepts/线搜索]] 思想相通。超定情形（m>n）的推广为 [[concepts/高斯—牛顿法]]。
