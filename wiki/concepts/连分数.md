# 连分数

连分数是具有套式结构的分数，一般形如 a₀ + 1/(a₁ + 1/(a₂ + ⋱ + 1/aₙ))，缩写为 [a₀; a₁, a₂, …, aₙ]；有理数和无理数都可以用它来表示，并获得比十进小数更好的逼近。它是《数学手册(原书第10版)》1.1.1 节的最大子节（1.1.1.4），也是全节的技术核心。

## 有理数：有限连分数

大于 1 的正有理数的连分数形如 (1.2)：

```latex
\frac{p}{q} = a_{0} + \frac{1}{a_{1} + \frac{1}{a_{2} + \frac{1}{\ddots + \frac{1}{a_{n-1} + \frac{1}{a_{n}}}}}},
缩写为 [a_{0}; a_{1}, a_{2}, \cdots, a_{n}], 其中 a_{k} \geqslant 1 (k=1,2,\cdots,n)
```

数 aₖ 可借助欧几里得算法逐次计算（见 [[concepts/辗转相除法]]）：

```latex
(1.3a)  \frac{p}{q} = a_{0} + \frac{r_{1}}{q}  \left(0 < \frac{r_{1}}{q} < 1\right)
(1.3b)  \frac{q}{r_{1}} = a_{1} + \frac{r_{2}}{r_{1}}  \left(0 < \frac{r_{2}}{r_{1}} < 1\right)
(1.3c)  \frac{r_{1}}{r_{2}} = a_{2} + \frac{r_{3}}{r_{2}}  \left(0 < \frac{r_{3}}{r_{2}} < 1\right)
(1.3d)  \frac{r_{n-2}}{r_{n-1}} = a_{n-1} + \frac{r_{n}}{r_{n-1}}  \left(0 < \frac{r_{n}}{r_{n-1}} < 1\right)
(1.3e)  \frac{r_{n-1}}{r_{n}} = a_{n}  (r_{n+1} = 0)
```

算例：61/27 = 2 + 7/27 = 2 + 1/(3 + 6/7) = 2 + 1/(3 + 1/(1 + 1/6)) = [2; 3, 1, 6]。

注：(1.2) 声明针对“大于 1 的正有理数”，而“每个有理数都有有限连分数”的一般论断覆盖全体有理数（a₀=0 的情形未显式说明）。

## 无理数：无限连分数

无理数的连分数是不中断的，称为**无限连分数**，记作 [a₀; a₁, a₂, …]。如果表示式中某个 aₖ 重复出现，则称为**循环连分数**（循环链分数，recurring chain fraction）。**每个循环连分数都表示一个二次无理数，反之，每个二次无理数都可以表示为循环连分数**（见 [[findings/二次无理数与循环连分数一一对应]]、[[concepts/二次无理数]]）。例：√2 = 1.4142135… = [1; 2, 2, 2, …]。

## 实数的逼近：渐近分数

若 α = [a₀; a₁, a₂, …] 是任一实数，则每个有限连分数 (1.4) 表示 α 的一个逼近，称为 α 的 **k 阶逼近**（渐近分数）：

```latex
(1.4)  \alpha_{k} = [a_{0}; a_{1}, a_{2}, \dots, a_{k}] = \frac{p}{q}
(1.5)  \alpha_{k} = \frac{p_{k}}{q_{k}} = \frac{a_{k}p_{k-1} + p_{k-2}}{a_{k}q_{k-1} + q_{k-2}}
       (k \geqslant 1; p_{-1} = 1, p_{0} = a_{0}; q_{-1} = 0, q_{0} = 1)
(1.6)  |\alpha - \alpha_{k}| = \left|\alpha - \frac{p_{k}}{q_{k}}\right| < \frac{1}{q_{k}^{2}}
```

其中 (1.6) 被手册归于“刘维尔逼近定理”，该归属存疑（见 [[queries/刘维尔逼近定理归属是否准确]]）。递推与误差估计的完整陈述见 [[findings/渐近分数的递推公式与误差估计]]。

进一步：近似式以渐增的精度**上下交替**地逼近 α；当 aᵢ 具有大数值时迅速收敛，而对 [1;1,1,…]（黄金数）收敛最差（见 [[findings/连分数部分商全为1时收敛最慢]]）。

## 算例

- **π**：通过 (1.3a)–(1.3e) 从十进小数表示可得 π = [3; 7, 15, 1, 292, …]；渐近分数 22/7、333/106、355/113 优于同位数小数（见 [[findings/π的渐近分数优于同位数小数]]）。
- **黄金分割**（手册例 B）：x = a[1;1,1,…] 与 x = (a/2)(1+√5) = (a/2)(1+[2;4,4,4,…])；第一个表示式 α₄ 精确度为 0.018a，第二个达 0.000001a。注意此例与 1.1.1.2 黄金分割方程的解相差因子 φ（见 [[findings/黄金分割连分数示例与方程解相差因子φ]]、[[queries/黄金分割连分数示例取值矛盾]]、[[concepts/黄金分割]]）。
