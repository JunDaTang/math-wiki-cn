# 超定线性方程组

超定线性方程组是方程个数多于未知数个数（m > n）的线性方程组 A x = b（式 4.187），系数矩阵 A = (a_ij)（i = 1,…,m；j = 1,…,n）为 (m,n) 长方矩阵，b 为给定右端向量，x 为未知向量。源指出：可以讨论其解的存在性和唯一性，并且有时还可用（例如）选主元法求解。

## 从精确解到最小二乘

若式 (4.187) 是表示实际问题（测量数据）的数学模型（A、b、x 为实的），那么因为测量或其他误差，一般不可能求出满足所有方程的精确解；代入任何向量 x 都会产生残差向量 r = Ax − b ≠ 0（式 4.188）。于是转而确定 x 使残差向量的模尽可能小，即[[concepts/线性最小二乘问题]]（式 4.189）；其求解途径为[[concepts/正规方程组与高斯变换]]（式 4.190）——rank(A) = n 时正规方程组有唯一解；当 rank(A) < n（秩亏，源作「秩亏格」）时须转用[[concepts/正则化问题]]（式 4.191–4.192）。
