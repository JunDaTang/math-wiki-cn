# 解释（谓词演算公式的语义）

谓词演算公式的一个**解释**是由以下二者组成的对：

- 一个集合（个体区域，或全域）；
- 一个指派：对每个 n 位谓词符号派定该个体区域上的一个 n 位谓词。

对自由变量每个预先指定的值，公式的真值计算概念与命题情形类似；[[concepts/闭公式]] 的真值由解释唯一确定。这一「论域 + 符号指派」的语义构造是塔尔斯基式语义的雏形（本 wiki 的定性判断）。

原书算例：个体区域取自然数集 ℕ，谓词符号指派为 ℕ 上的二元关系 ≤，则：

- P(x,y) 刻画满足 x ≤ y 的自然数对 (x,y) 之集合（x、y 自由）；
- ∀yP(x,y) 刻画 ℕ 的仅由（其最小元）组成的子集（一元关系）——转写中该元素脱落，为 0 抑或 1 牵涉 ℕ 是否含 0 的约定（[[queries/5-1全节转写讹误清单]]）；
- ∃x∀yP(x,y) 对应语句「存在最小的自然数」，真值为真（x、y 皆约束）。

对每个解释恒真的公式即 [[concepts/逻辑有效公式]]。
