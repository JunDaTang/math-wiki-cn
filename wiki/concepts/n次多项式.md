# n次多项式

n 次多项式（原文称「n 次整有理函数」，[[多项式]] 的一般情形）是形如

$$y = a_{n} x^{n} + a_{n-1} x^{n-1} + \dots + a_{1} x + a_{0} \tag{2.43}$$

的函数，其图像称为**抛物型 n 次或 n 阶曲线**（《数学手册(原书第10版)》2.3.4，图 2.14；原文第 261 页 3.5.2.5）。

## 奇偶二分的图像规律

| n 奇偶 | 端部行为（$a_n>0$） | 端部行为（$a_n<0$） | 与 x 轴 | 极值个数 | 拐点个数 |
|---|---|---|---|---|---|
| 奇 | $-\infty \to +\infty$ | $+\infty \to -\infty$ | 相交或相切至多 n 次，**至少一个交点** | 0 或不超过 n−1 的**偶数** | 介于 1 与 n−2 之间的**奇数** |
| 偶 | $+\infty \to$ 极小 $\to +\infty$ | $-\infty \to$ 极大 $\to -\infty$ | 相交或相切至多 n 次，可能不交 | **奇数** | **偶数**或 0 |

两情形的共同规律：

1. 极大值与极小值**交错出现**；
2. 曲线**不存在渐近线，也不存在奇点**。

奇次「至少一个交点」即 [[奇次实系数方程至少有一个实根]] 的图像表述（n 次方程求解见原文 1.6.3.1 与第 1237 页 19.1.2）。规律的证据与结构原因见 [[n次多项式奇偶分支行为规律]]。

## 低次特例

- n = 1：[[线性函数]]；
- n = 2：[[二次多项式]]；
- n = 3：[[三次多项式]]；
- 仅最高次项非零：[[n次抛物线]] $y = ax^n$。

## 边界疑点

「拐点个数为介于 1 和 n−2 之间的奇数个」在 n = 1 时空集失效（n−2 = −1，直线无拐点），该规律应视为对 n ≥ 3 方适用，见 [[奇次多项式拐点规律在n等于1时是否失效]]。
