# 指数积分与对数积分（Ei(x) 与 Li(x)）

指数积分 Ei(x) 与对数积分 Li(x) 是 [[sources/10-数学手册原书第10版--13-2174-其他超越函数积分--17odu4w|数学手册 21.7.4]] 在 21.7.4.2 与 21.7.4.3 定义段引入的一对特殊函数：Ei(x) 定义为反常积分 $\int_{-\infty}^{x}\frac{e^t}{t}dt$（x>0 时在奇点 t=0 处取主值），Li(x) 定义为 $\int_0^x\frac{dt}{\ln t}$（x>1 时在奇点 t=1 处取主值），二者以 $\operatorname{Li}(x) = \operatorname{Ei}(\ln x)$ 相联系。手册将二者的定义与主值论述置于第 681 页 8.2.5，本节为积分表语境下的引用与展开（回指缺口见 [[queries/21-7-4未入库回指缺口]]）。

## 级数表示

$$\operatorname{Ei}(x) = \int_{-\infty}^{x}\frac{e^t}{t}dt = C + \ln|x| + \frac{x}{1\cdot 1!} + \frac{x^2}{2\cdot 2!} + \frac{x^3}{3\cdot 3!} + \dots + \frac{x^n}{n\cdot n!} + \dots$$

其中 C 为欧拉常数（[[concepts/欧拉常数C]]；手册回指 8.2.5, 2.）。

## 在 21.7.4 积分表中的出现位置

- 451 注文：$\int\frac{e^{ax}}{x}dx$ 的级数 $\ln x + \sum\frac{(ax)^n}{n\cdot n!}$ 即 Ei(ax) 去常数项后的不定积分版本；
- 458：$\int e^{ax}\ln x\,dx$ 分部积分后余 $\int\frac{e^{ax}}{x}dx$，回指 451；
- 476：$\int\frac{x^m dx}{\ln x}$ 经代换 $y = -(m+1)\ln x$ 化为 $\int\frac{e^{-y}}{y}dy$（回指 451）；
- 469 注文与 Li 定义段：$\int\frac{dx}{\ln x}$ 的级数即 Li 的被积函数级数，Li(x) = Ei(ln x) 给出二者关系。

（可独立核验的背景：Ei(x) 与 Li(x) 为通用数学文献中的标准特殊函数，其主值定义与上述级数展开可在手册 8.2.5 及外部文献中交叉核对。）

## 校勘状态

本节两段定义注文均有转写语义损坏：「x>0 时，积分在 t=0 收敛……这种情况下，我们考虑反常积分 Ei(x) 的主值」——既随即取主值，奇点处必为发散，「收敛」疑为「发散」之讹或整句句式损坏（[[queries/Ei与Li注文收敛疑为发散之辨]]）；Li 段为同构损坏。连带讹误：欧拉常数句脱主语「C」（「表示欧拉常数」前疑脱「C」或「其中 C」）；Li 段「作对数积分」疑脱「称」字；四处回指（681 8.2.5、6818.2.5, 4.、681 8.2.5, 2.、623 7.2.4.2）均脱「页」字。
