# Mathematica 列表与向量矩阵表示

在 Mathematica 中，向量与矩阵没有专门的独立数据类型：**一维列表即向量，二维列表即矩阵**。这是 Mathematica 线性代数的表示基础，由《数学手册（原书第10版）》20.2.5.1「创建适当的列表」系统阐述。列表本身是[[表达式（Mathematica）]]，故向量、矩阵也是表达式，可经 [[Part（部件提取与头）]] 提取部件；元素符号 `v[i]`、`b[i,j]` 的命名与 [[Mathematica符号命名规则]] 相通。

## 向量：一维列表（式 20.11）

形如 `v = {v1, v2, …, vn}` 的一维列表总可以看成 n 维空间中具有分量 v1, v2, …, vn 的一个向量。

特殊运算 `Array[v, n]` 产生列表（向量）`{v[1], v[2], …, v[n]}`。用这种形式定义的向量可以进行符号向量运算。

## 矩阵：二维列表（式 20.12）

二维列表 l1（20.2.4.2，第 1334 页）、l2（20.2.4.3）可以看成具有 i 行 j 列的矩阵，b_ij 就是该矩阵第 i 行第 j 列处的元素；l1 定义 (6,5) 型长方矩阵，l2 定义 (5,5) 型方阵。

运算 `Array[b, {n, m}]` 产生一个 (n,m) 型矩阵，其元素记作 `b[i,j]`：行数用 i 标记（i 变到 n），列数用 j 标记（j 变到 m）。按这种符号形式可将 l1 建成：

```text
l1 = Array[b, {6, 5}]                        (20.12a)
b[i, j] = b_ij  (i = 1,…,6; j = 1,…,5)       (20.12b)
```

经 `Array` 构造的符号矩阵可作形式运算（转置、乘积、求逆等），见 [[Mathematica矩阵与向量运算]] 与 [[算例A四阶符号矩阵转置与矩阵向量积复算]]。

## 构造方式一览

| 途径 | 命令/写法 | 说明 |
|---|---|---|
| 枚举 | `{9, -2, 7}`、`{{2,1,3},{1,-2,1},{3,2,2}}` | 直接写出元素 |
| 符号构造 | `Array[v,n]`、`Array[b,{n,m}]` | 元素为 `v[i]`、`b[i,j]` |
| 序列 | `Range` | 生成数值序列 |
| 函数式 | `Table[f[i,j], {i,n}, {j,m}]` | f(i,j) 是 i 和 j 的函数，生成 (n,m) 型矩阵 |
| 单位矩阵 | `IdentityMatrix[n]` | n 阶单位矩阵 |
| 对角矩阵 | `DiagonalMatrix[list]` | 主对角线元素即列表元素 |
| 尺寸查询 | `Dimensions[list]`（原书作 `Dimension`，疑脱 s） | 给出矩阵的大小（行列数） |
| 排版显示 | `MatrixForm[list]` | 矩阵型表示 |

（`Table` 与 `Dimension` 两行的原文转写讹误见 [[20-2-5全节系统性转写讹误清单]]。）

## 列表与集合之别

原书强调：**列表不同于数学中的集合**——列表有序且可重复，集合无序不重复。正因如此，列表才能承担向量分量与矩阵元素的位置语义。
