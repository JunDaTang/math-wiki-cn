# 模糊补（补函数）

**模糊补**是满足四条公理（EK1–EK4）的函数 c: [0,1]→[0,1]（《数学手册(原书第10版)》式 5.357），充当模糊集补运算的隶属度变换；在布尔—模糊运算对照（表 5.9）中对应 NOT：μ_{A^C} = 1 − μ_A。

## 公理组（式 5.357a–d）

| 编号 | 名称 | 内容 |
|---|---|---|
| EK1 | 边界条件 | c(0) = 1，c(1) = 0〔源文讹作 c(0)=c(1)=0，见下〕 |
| EK2 | 单调性 | x < y ⇒ c(x) ≥ c(y) |
| EK3 | 对合性 | c(c(x)) = x |
| EK4 | 连续性 | c 在每个 x∈[0,1] 处连续 |

**EK1 转写讹误**：源文印作「c(O) = c(l) = 0」（O/l 为 0/1 的 OCR 讹形）。若 c(1)=0，则由对合性 c(c(1)) = c(0) 应等于 1，与「c(0)=0」矛盾；故边界条件必为 c(0)=1、c(1)=0。

## 三种补函数

- **缺省补**（式 5.358）：c(x) := 1 − x，手册称其为「最常用的（连续且对合的）补函数」；
- **菅野（Sugeno）补**：c_λ(x) := (1−x)(1+λx)^{−1}，λ∈(−1,∞)。源文译名讹作「管野」，应为「菅野」；
- **Yager 补**（源文译作「耶格尔」）：c_p(x) := (1−x^p)^{1/p}，p∈(0,1)。参数区间疑应为 p>0（对合性与单调性对一切 p>0 成立），见 [[queries/yager补参数区间是否应为p大于0]]。
