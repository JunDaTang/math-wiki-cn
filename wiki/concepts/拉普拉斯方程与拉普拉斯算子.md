# 拉普拉斯方程与拉普拉斯算子

**拉普拉斯算子**（Laplace 算子）Δ 是各二阶偏导数之和：

$$\Delta u = \frac{\partial^{2} u}{\partial x_1^{2}} + \frac{\partial^{2} u}{\partial x_2^{2}} + \dots + \frac{\partial^{2} u}{\partial x_n^{2}}$$

**拉普拉斯方程** Δu = 0 是其齐次方程，解称为调和函数；它是椭圆型方程的代表（δ = AC − B² > 0）。手册在常系数方程的简单形式 (9.89)/(9.90) 中以 Δ 记拉普拉斯算子（回指 13.2.6.5，未入库）。

## 本节中的出现

- 矩形狄利克雷问题（式 9.95a）：Δu = 0 于长方形 0 ≤ x ≤ a、0 ≤ y ≤ b，四边取给定值，经 sinh 型级数求解。
- 圆盘狄利克雷问题（式 9.101a）：经镜像格林函数 G = ln(1/r) + ln(r₁ρ/R) 得 [[泊松积分]] (9.101d)。
- 球狄利克雷问题（式 9.102a）：G = 1/r − R/(r₁ρ)，球面泊松积分 (9.102c)。

三例均属 [[狄利克雷问题]]，解法走 [[格林函数与格林方法]] 路径（矩形例走 [[分离变量法]]）。转录复算见 [[findings/式9-95矩形狄利克雷问题复算]]、[[findings/式9-101至9-102圆盘与球格林函数复算]]。
