# 二次无理数

二次无理数是整系数二次方程 (1.1b) 的非整数根；它们都具有 (a+b√D)/c 的形式（a、b、c 均为整数，c≠0；D>0 且为非平方数）。

## 定义

```latex
(1.1b)  x^{2}+a_{1}x+a_{0}=0  (a_{1}, a_{0} 为整数)
        —— 非整数根为二次无理数, 形如 \frac{a+b\sqrt{D}}{c}
```

## 与循环连分数的对应

二次无理数是本节最强结构性论断的载体：**每个循环连分数都表示一个二次无理数，反之，每个二次无理数都可以表示为循环连分数**（见 [[findings/二次无理数与循环连分数一一对应]]）。例：√2 = 1.4142135… 是二次无理数，有循环连分数表示式 √2 = [1; 2, 2, 2, …]（见 [[concepts/连分数]]）。

## 例子

- 一条线段按黄金比例 x/a = (a−x)/x 分割，当 a=1 时导出方程 x² + x − 1 = 0，解 x = (√5−1)/2 是一个二次无理数，包含无理数 √5（见 [[concepts/黄金分割]]；注意该例在手册 1.1.1.4 的连分数表述存在数值矛盾）。
- 黄金分割线段因比值含 √5 而不可公度，推及正五边形边与对角线（见 [[concepts/可公度性]]）。

## 在分类中的位置与关联

二次无理数是代数无理数的子类（[[concepts/无理数]]），与 [[concepts/超越数]] 互斥；层级见 [[comparisons/数系分类层级]]。它与 [[findings/手册以p方除4减q小于零判定二次因式无实分解]] 共享同一判别式线索：二次方程/二次因式的实根与实分解性均由判别式的符号决定（前者来自 1.1.1 节，后者来自 1.1.6 节，两处论断各自归属，不互通）。
