# 拉宾-米勒素数检验

拉宾-米勒素数检验（Rabin-Miller 素性检验；源文作「拉滨米勒」，「滨」为 OCR 讹字，本 wiki 依源内拉丁名 Rabin-Miller 修正，源形记为别名）是基于下列命题 (＊) 的随机性强伪素数检验：

```
设 n > 2 是素数，n − 1 = 2^t·u（u 是奇数），gcd(a,n) = 1。那么
对于某个 j ∈ {0, 1, …, t−1}，a^u ≡ 1 (mod n) 或 a^(2^j·u) ≡ −1 (mod n)    (＊)
```

每个奇自然数 n > 1 都可用它检验素性：将 n−1 分解为 2^t·u，由重复模 n 平方算出序列 a^u, a^(2u), …, a^(2^(t−1)u) (mod n)，若无任何值满足 (＊)，则 n 确定地是合数；否则通过对基 a 的检验（须换基复检）。流程见 [[methodology/拉宾-米勒素性检验流程]]（源文检验步骤误作「n − 2 = 2^t·u」，见 [[queries/检验式中n减2是否应为n减1]]）。

## 误差界

随机且独立地选取 k 个不同的基值且全部通过检验时，第一类误差率 ≤ 1/4^k——**对一切合数无条件成立**，不似费马检验受卡迈克尔数限制。实用中取 k = 25。算例 B：仅有一个数 ≤ 2.5·10^10 通过基 a = 2,3,5,7 的检验但不是素数（源未给数值；独立可验证背景：该数为 3,215,031,751）。

## 算例

n = 561（= 3·11·17，卡迈克尔数）：n − 1 = 2^4·35，a = 2 时序列 263, 166, 67, [1] 中无任何项满足 (＊)，故 561 不是素数——与其在费马检验下通过一切互素基的表现相反（见 [[findings/561拉宾-米勒算例与2的280次方讹误]]、[[comparisons/费马检验与拉宾-米勒检验比较]]）。

## 实践地位

《数学手册》在 AKS 检验的评注中指出：尽管 AKS 无错误概率，**在密码学中拉宾-米勒检验更合适**。
