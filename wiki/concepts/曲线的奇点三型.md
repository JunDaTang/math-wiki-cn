# 曲线的奇点三型（孤立点、二重点、尖点）

曲线的奇点三型是《数学手册(原书第10版)》2.12 节用于分类代数曲线原点奇点的语言：孤立点、二重点、尖点。三种类型的标准含义（独立可查的代数曲线背景知识）：孤立点是方程的孤立实解，曲线没有任何支经过它；二重点是两条支以两条不同切线穿过的点；尖点是两条支以公共切线相触的点。手册本节未给出一般定义，但其用法与标准含义一致，并可在每条曲线上逐例核对。

## 本节中的判定证据

手册在六条四阶曲线上一贯地用参数比（l/a 或 a/c）来切换奇点类型：

- **二重点伴随两条切线斜率**：[[concepts/尼科梅德斯蚌线]] l > a 时 $\tan\alpha = \pm\sqrt{l^2-a^2}/a$；[[concepts/帕斯卡蜗线]] a > l 时 $\tan\alpha = \pm\sqrt{a^2-l^2}/l$——两支以不同斜率穿过原点。
- **尖点为两族的共同临界情形**：蚌线 l = a 与蜗线 a = l（即 [[concepts/心脏线]]）都在原点形成尖点，两支在此相切。
- **孤立点无切线信息**：蚌线 l < a 与蜗线 a < l 时原点仅为方程的孤立实解。
- **奇点与拐点不互斥**：[[concepts/双纽线]] 的原点同时是二重点与拐点。

判定手段上，隐式方程在奇点处的最低次项给出切线信息：双纽线方程最低次项为 $x^2 - y^2 = (x-y)(x+y)$，分解出两条切线 $y = \pm x$，直接确认二重点；蚌线 l < a 时最低次项 $(a^2-l^2)x^2 + a^2y^2$ 正定，仅剩孤立解，确认孤立点。

## 跨族对照

两族蚌线的三分律方向相反，是“同一套语言、相反的相图”：

| 条件 | [[concepts/尼科梅德斯蚌线]] | [[concepts/帕斯卡蜗线]] |
|---|---|---|
| l < a | 孤立点 | 二重点 |
| l = a | 尖点 | 尖点（心脏线） |
| l > a | 二重点 | 孤立点 |

详证与警示见 [[comparisons/尼科梅德斯蚌线与帕斯卡蜗线奇点分类比较]]。极点曲率半径公式 $r_0 = |\rho'(\varphi_0)|/2$ 可对二重点处的 r₀ 作独立核验（见 [[methodology/四阶曲线图像绘制法]]）。
