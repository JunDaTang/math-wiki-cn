# 并集、交集与补集

借助集合运算，可以用不同方式由给定集合形成新的集合。本页汇总本源定义的三种基本运算（式 5.39–5.42）。

**并集**：$A \cup B$ 定义为

$$A \cup B = \{x \mid x \in A \lor x \in B\} \tag{5.39}$$

如果 $A$、$B$ 分别由性质 $E_1$ 和 $E_2$ 定义，那么并集 $A \cup B$ 含有至少具有其中一个性质的元素。例：$\{1,2,3\} \cup \{2,3,5,6\} = \{1,2,3,5,6\}$。

![图 5.2 并集](media/10-数学手册原书第10版--5-52-集论--1emkee6/002-62707539a8c5da2d1ed9bc92fa1d5c0259d3d1a90f3b31d37fa4a144c55b3b32.jpg)

**交集**：$A \cap B$ 定义为

$$A \cap B = \{x \mid x \in A \land x \in B\} \tag{5.40}$$

交集含有同时具有 $E_1$ 和 $E_2$ 的元素。例：两数的因子集合之交定义最大公因子——$T(12) = \{1,2,3,4,6,12\}$，$T(18) = \{1,2,3,6,9,18\}$，$T(12) \cap T(18)$ 含公因子，$\gcd(12,18) = 6$（参见未入库的 5.4.1.4）。

![图 5.3 交集](media/10-数学手册原书第10版--5-52-集论--1emkee6/003-0896be783d7d3f725f9b1048bc262a4bad66aa373dbf09645383b1b51d2105f0.jpg)

**不相交集**：若两个集合没有公共元素，则称它们是不相交的，即

$$A \cap B = \varnothing \tag{5.41}$$

例：奇数集和偶数集不相交。

**补集**：如果只考虑一个给定集合 $M$ 的子集，那么 $A$ 对于 $M$ 的补集 $C_M(A)$ 含有 $M$ 的所有不属于 $A$ 的元素：

$$C_{M}(A) = \{x \mid x \in M \lor x \notin A\} \tag{5.42}$$

$M$ 称为**基本集**（有时也称泛集）；若基本集自然来自所考虑的问题，也用记号 $\overline{A}$。

![图 5.4 补集](media/10-数学手册原书第10版--5-52-集论--1emkee6/004-6e64c275cd90e60d3ab12c2c3b6279c1783bb41b42ce3a1d8dfe530d18a17f3e.jpg)

⚠️ **转写讹误**：式 (5.42) 的连接词疑应为 $\land$ 而非 $\lor$（见 [[queries/式5-42补集定义应为合取吗]]）；交集段正文「交集 $A \cup B$ 具有性质 $E_1$ 和 $E_2$」应为 $A \cap B$，与式 (5.40) 冲突。

这些运算满足 [[concepts/集代数基本律]]（含 [[concepts/德摩根律]]），图形表示见 [[concepts/维恩图]]；差集与对称差见 [[concepts/差集]]、[[concepts/对称差]]。
