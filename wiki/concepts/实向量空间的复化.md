# 实向量空间的复化

复化是把每一个实向量空间 V 扩张成复向量空间 Ṽ 的显式构造：Ṽ 由所有偶对 (x, y)（x, y ∈ V）组成，加法按分量、复标量乘法按 (12.23b) 定义。这一程序使得实空间上的理论可以在复域中使用，且维数保持不变。

## 构造（式 12.23）

$$
(x_1, y_1) + (x_2, y_2) = (x_1 + x_2,\, y_1 + y_2), \tag{12.23a}
$$
$$
(a + \mathrm{i}b)(x, y) = (ax - by,\, bx + ay). \tag{12.23b}
$$

## 与记号 x + iy 的等同（式 12.24）

由特殊关系

$$
(x, y) = (x, 0) + (0, y) \;\;\text{和}\;\; \mathrm{i}(y, 0) = (0 + \mathrm{i}1)(y, 0) = (0, y), \tag{12.24}
$$

偶对 (x, y) 也可以写成 x + iy。集合 Ṽ 是一个复向量空间，其中 V 等同于线性子空间 Ṽ₀ = {(x, 0) : x ∈ V}，即 x ∈ V 可看作 (x, 0) 或 x + i0。

## 维数保持

V 中线性无关子集在 Ṽ 中也是线性无关的；同样的论述对 V 中的基也成立，从而 dim(V) = dim(Ṽ)。（复算验证见 [[findings/式12-19至12-24线性算子与复化转录复算]]：若 Σα_k(x_k, 0) = 0，α_k = a_k + ib_k，则按分量得 Σa_k x_k = 0 与 Σb_k x_k = 0，由实无关性得一切系数为零；又 (x, y) = (x, 0) + i(y, 0) 给出生成性。）

## 复算注

(12.23b) 与复数乘法完全相容：对 (a₁+ib₁)[(a₂+ib₂)(x,y)] 逐次应用 (12.23b) 可得 ((a₁a₂−b₁b₂) + i(a₁b₂+b₁a₂))(x,y)，与复乘 (a₁+ib₁)(a₂+ib₂) 一致；i(y,0) = (0,y) 亦可由 (12.23b) 取 a=0, b=1 直接得出。
