# 单纯形表

单纯形表是把线性规划规范形 (18.9a,b) 的系数按行列重排后得到的计算表格，是单纯形法一切计算的载体。《数学手册(原书第10版)》18.1.3.1 以式 (18.15a,b) 给出对应关系：表的第 $k$ 行对应约束

$$x_{n-m+k} + a_{k,1}x_1 + \dots + a_{k,n-m}x_{n-m} = b_k, \tag{18.15a}$$

最末行对应目标函数

$$c_1x_1 + \dots + c_{n-m}x_{n-m} = f(\underline{\boldsymbol x}) - c_0. \tag{18.15b}$$

## 表结构（表 18.2）

| | $x_1$ | $\cdots$ | $x_{n-m}$ | |
|---|---|---|---|---|
| $x_{n-m+1}$ | $a_{1,1}$ | $\cdots$ | $a_{1,n-m}$ | $b_1$ |
| $\vdots$ | $\vdots$ | | $\vdots$ | $\vdots$ |
| $x_n$ | $a_{m,1}$ | $\cdots$ | $a_{m,n-m}$ | $b_m$ |
| | $c_1$ | $\cdots$ | $c_{n-m}$ | $-c_0$ |

- 行标为现时基变量 $x_{n-m+1},\dots,x_n$，列标为非基变量 $x_1,\dots,x_{n-m}$，右端列为 $\underline{\boldsymbol b}$。
- 把 $-c_0$ 放到表的右下端「有利于进行单纯形方法的计算」：换基时按 (18.16d) 直接更新 $-\tilde c_0=-c_0+b_p\tilde c_q$。
- 从表可直接读出极端点 $(\underline{\boldsymbol x}_N,\underline{\boldsymbol x}_B)=(\underline{\boldsymbol 0},\underline{\boldsymbol b})$ 及目标值 $f(\underline{\boldsymbol x})=c_0$。

## 表的判读

每张表必属三情形之一（a 最优 / b 无界 / c 可换基前进），详见 [[concepts/单纯形法]]；换基操作见 [[concepts/主元选择与比值检验]]。

## 其他表格形态

- 辅助规划的表（表 18.5、18.6）在约束行之下同时保留原目标行 OF 与辅助目标行 OF*（后者为引入人工变量的各行系数之和），见 [[concepts/人工变量与辅助规划]]。
- 修正单纯形表（表 18.7）不存整表，只存现时基逆 $A^*$ 与当前主列 $\underline{\boldsymbol r}$，见 [[concepts/修正单纯形法]]。
