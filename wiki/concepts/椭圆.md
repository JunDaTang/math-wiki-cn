# 椭圆

## 定义

依《数学手册(原书第10版)》3.5.2（平面解析几何），椭圆是平面上与两个给定点（焦点）的距离之和等于常数 $2a$ 的点的轨迹，即数值离心率 $e = c/a < 1$ 的二次曲线；$a = b$（从而 $c = 0$）时退化为圆（原书 3.5.2.11 将圆列为椭圆的特殊情形）。

> [!note] 识别用背景知识
> 椭圆是圆锥曲线之一，可由与轴斜交且不截底的平面截圆锥面得到。此为可独立验证的公共背景知识，此处仅作识别，非本 wiki 已录入来源所给定义。

## 要素

长轴 $2a$、短轴 $2b$、顶点 $A, B, C, D$、焦点 $F_1, F_2$（与中心距离 $c = \sqrt{a^2 - b^2}$）、数值离心率 $e = c/a < 1$、半焦弦 $p = b^2/a$（过焦点平行于短轴的弦的一半）。

## 公式体系（式 3.320–3.329，标准位置）

以下公式体系录自《数学手册(原书第10版)》3.5.2（平面解析几何）；原书关于椭圆更详尽的说明见其 3.5.2.8 小节。

- **方程与参数式**：$\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$；$x = a\cos t,\ y = b\sin t$（3.320）
- **焦半径**：$r_1 = a - ex$，$r_2 = a + ex$，$r_1 + r_2 = 2a$（3.321；按本书约定 $F_1$ 为右侧焦点，体系自洽）
- **准线**：与短轴平行、距离 $d = a/e$ 的直线，$r_1/d_1 = r_2/d_2 = e$（3.322），此性质亦可作定义
- **共轭直径**：$kk' = -b^2/a^2$（3.323）；[[阿波罗尼奥斯定理]] 和式型（3.324）
- **切线**：$\dfrac{xx_0}{a^2} + \dfrac{yy_0}{b^2} = 1$（3.325）；切线判别 $A^2a^2 + B^2b^2 = C^2$（3.326）；切线与法线是焦半径所成内、外角的平分线
- **曲率半径**：$R = a^2b^2\left(\dfrac{x_0^2}{a^4} + \dfrac{y_0^2}{b^4}\right)^{3/2} = \dfrac{(r_1 r_2)^{3/2}}{ab} = \dfrac{p}{\sin^3 u}$（3.327，三式等价已验证）；顶点处 $R_A = R_B = b^2/a = p$、$R_C = R_D = a^2/b$
- **面积**：$S = \pi ab$；扇形 $S_{BOP} = \dfrac{ab}{2}\arccos\dfrac{x}{a}$（3.328b）；弓形 $S_{PBN} = ab\arccos\dfrac{x}{a} - xy$（3.328c）
- **弧长与周长**：弧长需第二类不完全椭圆积分；周长 $L = 4aE(e)$ 及级数/近似式（3.329）

详见 [[椭圆理论公式组]] 与 [[椭圆面积周长级数与算例]]。与[[双曲线]]、[[抛物线]]的系统对照见 [[椭圆双曲线抛物线比较]]。

## 作为无理函数的图像（原书 2.5.2）

在《数学手册(原书第10版)》2.5.2 中，椭圆作为二次多项式平方根的联立曲线出现：当 $a<0$ 且 $\Delta = 4ac - b^2 < 0$ 时，

$$
y = \pm \sqrt {a x ^ {2} + b x + c} \quad (a \neq 0,\ \Delta \neq 0)\tag{2.52}
$$

的图像是椭圆（当 $a<0$ 而 $\Delta>0$ 时根号下二次式恒负，函数仅取虚值，无实曲线）。

- **对称轴**：$x$ 轴与直线 $x = -\dfrac{b}{2a}$；
- **顶点**：$A, C\left(-\dfrac{b \pm \sqrt{-\Delta}}{2a},\, 0\right)$（在 $x$ 轴上）与 $B, D\left(-\dfrac{b}{2a},\, \pm\sqrt{\dfrac{\Delta}{4a}}\right)$；椭圆情形下 $-\Delta>0$ 且 $\Delta/(4a)>0$，四个顶点均为实点。

注意：本节（2.5.2）对顶点字母的指派（$A, C$ 在 $x$ 轴上）与上文 3.5.2 公式体系中的顶点字母约定不一致，请勿混用。

> [!warning] 记号警告
> 此处 $\Delta = 4ac - b^{2}$ 与通行判别式 $b^{2}-4ac$ 符号相反。

分类结论的依据见 [[二次多项式平方根曲线为椭圆或双曲线]]。
