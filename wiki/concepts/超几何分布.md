# 超几何分布

**超几何分布**是不放回抽样下成功次数的概率分布：与二项分布同样考虑含 N 个元素的两阶段总体（M 个具性质 A、N−M 个不具），但在摸下一个球之前，已摸到的球不再放回。从瓮中不放回地摸 n 个球（要求 n ≤ M 且 n ≤ N−M），其中黑球（具性质 A 的元素）个数 X 的分布为

$$P(X=k) = W_{M,N}^n(k) = \frac{\binom{M}{k}\binom{N-M}{n-k}}{\binom{N}{n}}, \qquad (16.66a)$$

取值范围为（式 16.66b）：

$$0 \le k \le n, \qquad k \le M, \qquad n-k \le N-M.$$

分子计有利情形（从 M 个黑球中取 k 个、从 N−M 个白球中取 n−k 个的组合数乘积），分母为样本总数 C(N,n)，直接应用[[concepts/组合]]；归一化由 Vandermonde 恒等式 Σ_k C(M,k)C(N−M,n−k)=C(N,n) 保证。

## 期望与方差

$$\mu = E(X) = n\,\frac{M}{N}, \qquad (16.67a)$$

$$\sigma^2 = D^2(X) = n\,\frac{M}{N}\left(1-\frac{M}{N}\right)\frac{N-n}{N-1}. \qquad (16.67b)$$

期望与二项分布同形（以 p=M/N 代入 np），但方差多出因子 (N−n)/(N−1)（0 < 该因子 ≤ 1）：不放回抽样使方差减小，此即有限总体校正；n≪N 时该因子趋于 1，方差与二项情形趋于一致。手册德式记号：**D(X) 为标准差、D²(X) 为方差**。

**转写注**：原文 (16.67a) 与方差公式两处求和式的分母均误作 C(N,k)，与 (16.66a) 的 C(N,n) 矛盾，可证为转写错误；且方差公式的编号原文作 (16.67)，疑应为 (16.67b)。详见[[queries/式16-67a与16-67分母Cnk疑为Cnn]]。

## 递推公式

$$W_{M,N}^n(k+1) = \frac{(n-k)(M-k)}{(k+1)(N-M-n+k+1)}\, W_{M,N}^n(k). \qquad (16.67c)$$

该递推已经代数推导独立验证（见[[findings/式16-66至16-67c超几何分布定义矩与递推转录复算]]）。

## 与二项分布的关系

当总体中黑球数 M 与白球数 N−M 都远大于样本容量 n 时（原文句子疑有脱字），超几何分布可由参数 p=M/N（式 16.63）的[[concepts/二项分布]]很好地逼近。手册以图 16.3（N=100, n=5, M=50/25/10）与图 16.2（n=5, p=0.5/0.25/0.1）对照佐证：这些例子中两分布无明显区别。
