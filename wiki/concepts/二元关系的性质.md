# 二元关系的性质

集合 $A$ 中的二元关系 $R$ 可以具有下列特殊的重要性质（$R$ 称为）：

$$
\begin{aligned}
\text{自反的，如果} && \forall a \in A\ a R a \tag{5.71a}\\
\text{非自反的，如果} && \forall a \in A\ \neg a R a \tag{5.71b}\\
\text{对称的，如果} && \forall a, b \in A\ (a R b \Rightarrow b R a) \tag{5.71c}\\
\text{反对称的，如果} && \forall a, b \in A\ (a R b \land b R a \Rightarrow a = b) \tag{5.71d}\\
\text{传递的，如果} && \forall a, b, c \in A\ (a R b \land b R c \Rightarrow a R c) \tag{5.71e}\\
\text{线性的，如果} && \forall a, b \in A\ (a R b \lor b R a) \tag{5.71f}
\end{aligned}
$$

**关系积刻画**：这些性质还可以用关系积刻画——例如，如果 $R \circ R \subseteq R$，则二元关系 $R$ 是传递的（见 [[concepts/关系积与逆关系]]）。

**识别方法**：在有限二元关系情形，可从 [[concepts/箭头图]] 或 [[concepts/关系矩阵]] 容易地识别这些性质：自循环圈 / 主对角元 ⇔ 自反；双向箭头 / 对称矩阵 ⇔ 对称。例如整除关系是自反的但不是对称关系（见 [[findings/整除关系与关系矩阵算例]]）。

这六条性质的两条经典组合构成本源 5.2.4 的主题：**自反 + 对称 + 传递** ⇒ [[concepts/等价关系]]；**自反 + 反对称 + 传递**（再加线性）⇒ [[concepts/偏序与线性序]]。传递性不足时可用 [[concepts/传递闭包]] 补足。公式记录见 [[findings/二元关系性质与传递闭包定义]]。
