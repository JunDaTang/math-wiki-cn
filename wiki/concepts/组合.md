# 组合

组合是从 n 个不同元素中任取 k 个元素、不考虑所取元素顺序的取法（源文亦称 k 阶组合）；它对应「从 n 个元素中取出 k 个」框架中「纯选取、不计序」的情形。按每个元素是否可被重复选取，分为无重复组合与有重复组合。

## 无重复组合

从 n 个不同元素中取出 k 个（每个元素最多取一次），不考虑顺序，不同取法数为

$$\mathrm{C}_n^{(k)} = \binom{n}{k}, \quad 0 \leqslant k \leqslant n \tag{16.4}$$

即二项式系数；源文回指手册第 15 页 1.1.6.4 第 3 小节（该小节尚未入库，见 [[queries/16-1未入库回指缺口]]）。

例：从 30 位参会者中挑出 4 位组成选举委员会，共有 C(30,4) = 27405 种可能取法。

## 有重复组合

从 n 个不同元素中取出 k 个，每个元素可重复选取且不计顺序，不同取法数为

$$\mathrm{C}_n^{(k)} = \binom{n+k-1}{k} \tag{16.5}$$

即多重集选取（隔板型计数问题）。此时 k 可以大于 n。

例：掷 2 颗骰子，可能的不同点数结果是 C₆⁽²⁾ = C(7,2) = 21 种（骰子不加区分、点数可重复）。

## 记号警示

同一记号 Cₙ⁽ᵏ⁾ 在 (16.4) 与 (16.5) 中一号两义（C(n,k) 与 C(n+k−1,k)），仅凭「是否允许重复」消歧；公式不得跨情形挪用，见 [[comparisons/全排列组合排列无重复有重复公式比较]]。

## 与相关概念的界线

- 与 [[concepts/排列]] 的区别：排列在选取之上还要排序，无重复情形 Vₙ⁽ᵏ⁾ = k!·Cₙ⁽ᵏ⁾，即「排列数 = 组合数 × 组内全排列数」。
- 与 [[concepts/全排列]] 的区别：全排列全员参与、纯讲次序。
