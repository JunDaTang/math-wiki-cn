# 1/5 成功法则

**1/5 成功法则**（五分之一成功法则）是 [[1+1突变—选择策略]] 的经典步长控制规则：用上一步中成功突变数目与突变总数之比确定成功的比值 q，再依 q 与 1/5 的相对大小调节突变步长 α（式 18.93）：

```latex
\alpha_{k+1} =
\begin{cases}
c\cdot\alpha_k, & q < 1/5,\\
\dfrac{1}{c}\cdot\alpha_k, & q > 1/5,
\end{cases}
\quad c = 0.8,\dots,0.85
\tag{18.93}
```

## 动机

若这种突变多半导致后代改善，则可以增加步长；若突变导致后代的改善较小，则应减少 α 值。步长的选择对演化方法的收敛性具有重要影响：太小导致滞止，太大引起过调。

## 分支方向核验

按式 18.93 转录：q < 1/5 时 α 乘以 c（c = 0.8…0.85 < 1，步长缩小）；q > 1/5 时 α 乘以 1/c > 1（步长放大）。这与正文「如果 q > 1/5，则步长可以增加；而如果成功比值较小，则步长 α 应该减少」的叙述一致。注意公式未给出 q 恰为 1/5 时的分支（自然解释为保持 α 不变，待与原书核对）。

## 扩展模型（自适应步长）

手册指出 1/5 法则「是一种粗略的选择」，在考虑某个具体问题时并不会总是令人满意。在一个扩展模型中，步长 α 和标准差 $\sigma_i$（i = 1,2,…,n）总是在不断修正中：α 和 $\sigma_i$ 以**等概率**的方式乘以三个因子 c、1、1/c 中的某一个，其中 c = 1.1,…,1.5。进一步的信息见 [18.9]（源中未具名的参考文献，无法定位，见 [[18-2-6未入库回指缺口]]）。

## 证据强度

公式 18.93 为手册性陈述，与演化策略标准文献中的 1/5 法则一致；参数取值 c = 0.8…0.85（及扩展模型的 c = 1.1…1.5）为经验取值。复算记录见 [[式18-91至18-93（1+1）策略与1-5法则复算]]。
