# 赋范空间

赋范空间是同时携带代数结构与距离结构且两者相容的空间：设 X 是域 𝔽（ℝ 或 ℂ）上的向量空间，映射 ‖·‖: X → ℝ₊¹ 称作范数，偶对 (X, ‖·‖) 称作 𝔽 上的赋范空间，是指满足三条赋范空间公理（本源 12.3.1.1，式 12.78–12.80）：

- **N1（正定性）**：‖x‖ ≥ 0，且 ‖x‖ = 0 当且仅当 x = 0；
- **N2（齐次性）**：‖αx‖ = |α|·‖x‖，对任意标量 α ∈ 𝔽；
- **N3（三角不等式）**：‖x + y‖ ≤ ‖x‖ + ‖y‖。

（转录本中 N2、N3 的括注为乱码，据内容推断应分别为「齐次性」「三角不等式」，见 [[queries/12-3全节系统性转写讹误清单]]。）

## 范数诱导的距离与结构相容性

在任意赋范空间中，ρ(x, y) = ‖x − y‖（式 12.81）诱导一个距离，且与向量空间结构相容：

- 平移不变性：ρ(x+z, y+z) = ρ(x, y)，∀z ∈ X（式 12.82a）；
- 正齐次性：ρ(αx, αy) = |α|ρ(x, y)，∀α ∈ 𝔽（式 12.82b）。

由于这种相容性，大多数局部研究可以限制在单位球 B(0;1) = {x : ‖x‖ < 1} 或闭单位球 B̄(0;1) = {x : ‖x‖ ≤ 1}（式 12.83）上进行，因为任意球都可由单位球平移伸缩生成：B(x; r) = x + rB(0;1)（式 12.84）。此外代数运算连续：xₙ→x、yₙ→y、αₙ→α 蕴涵 xₙ+yₙ→x+y、αₙxₙ→αx、‖xₙ‖→‖x‖（式 12.85）；收敛可用范数刻画为 ‖xₙ − x‖ → 0（式 12.86，回指未入库的 (12.53)）。

## 范数同构、范数强弱与等价

- **范数同构**：两个赋范空间称作范数同构的，指存在双射线性映射 T: X → Y 使 ‖Tx‖ = ‖x‖ 对一切 x ∈ X 成立。
- **范数强弱**：‖·‖₁ 比范数 ‖·‖₂ 强，指存在 γ > 0 使 ‖x‖₂ ≤ γ‖x‖₁ 对一切 x 成立；此时按强范数收敛蕴涵按范数 ‖·‖₂ 收敛。
- **范数等价**：两个范数称作等价的，指存在 γ₁, γ₂ > 0 使 γ₁‖x‖ ≤ ‖x‖₁ ≤ γ₂‖x‖（转录本两处 ‖x‖ 疑缺下标 2，见 [[queries/等价范数定义式下标缺失]]）。

**核心定理（本节唯一普适性定理）**：在有穷维向量空间中，所有范数彼此等价。这为 [[methodology/求积半离散化方法]] 等 11.2.4 数值方法中 𝔽ⁿ 上离散系统的范数讨论提供框架（此联系为编者推断）。

## 子空间

转录本称「赋范空间的子空间是该空间的一个闭线性子空间」，与标准理论矛盾（线性子空间不必闭），且与本节内部 $\tilde W^{k,p}$ 不完备的事实相冲突，疑「闭」为衍文或误译，见 [[queries/赋范空间子空间闭性陈述疑误]]。
