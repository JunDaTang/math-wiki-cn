# 双线性映射与双线性型

双线性映射可以看作向量间不同的积的一般化：在这种情形，双线性型用于相应的积对于向量加法的分配性。

## 定义（5.3.8.6.1）

设 $U,V,W$ 是同一个域 $K$ 上的向量空间。映射 $f:U\times V\to W$ 称为**双线性的**，如果对每个 $u\in U$，映射 $v\mapsto f(u,v)$ 是线性的，并且对每个 $v\in V$，映射 $u\mapsto f(u,v)$ 是线性的（式 5.208）。展开为：对每个 $k\in K$、$u,u'\in U$、$v,v'\in V$，

```latex
f(u+u', v) = f(u,v) + f(u',v)     f(ku, v) = k f(u,v)
f(u, v+v') = f(u,v) + f(u',v)     f(u, kv) = k f(u,v)     % 式 5.209
```

（第三式右端第二项 $f(u',v)$ 按双线性性应为 $f(u,v')$，疑为转写讹误，见 [[queries/式5-209第三式右端讹误]]。）如果用点积、向量积或域中的乘法代替 $f$，那么这些关系刻画了该乘法对于向量加法的左侧和右侧分配性。

## 双线性型

特别地，若 $U=V$ 且 $W=K$（基域），则 $f$ 称为**双线性型**。本手册只考虑实（$K=\mathbb{R}$）和复（$K=\mathbb{C}$）的情形。

### 例子

- **例 A**：$U=V=\mathbb{R}^n$、$W=\mathbb{R}$，$f$ 为 $\mathbb{R}^n$ 的点积 $f(u,v)=u^{\mathrm T}v=\sum_{i=1}^n u_iv_i$。
- **例 B**：$U=V=W=\mathbb{R}^3$，$f$ 为叉积 $f(u,v)=u\times v=(u_2v_3-u_3v_2,\; v_1u_3-u_1v_3,\; u_1v_2-v_1u_2)^{\mathrm T}$。

（两例的双线性性已复算，见 [[findings/双线性定义与点积叉积实例]]。）

## 特殊的双线性型（5.3.8.6.2）

$f:V\times V\to\mathbb{R}$ 称作：

- **对称的**：对每个 $v,v'\in V$，$f(v,v')=f(v',v)$；
- **斜对称的**：$f(v,v')=-f(v',v)$；
- **正定的**：对每个 $v\in V$，$v\neq 0$，$f(v,v)>0$。

于是 $\mathbb{R}^n$ 中的欧几里得点积可以刻画为**对称正定的双线性型**（$\mathbb{R}^n$ 中标准欧几里得点积定义为 $f(u,v)=u^{\mathrm T}v$；原书交叉引用 5.3.8.5，页码作 492）。

## 矩阵表示（有限维）

若 $f:V\times V\to\mathbb{R}$ 是双线性型且 $B=(b_1,\dots,b_n)$ 是 $V$ 的基，则矩阵

```latex
A_B(f) = (f(b_i, b_j))_{i,j}                    % 式 5.210
f(v, v') = v^T A_B(f) v'                        % 式 5.211
```

其中 $v,v'$ 对于基 $B$ 给出（坐标）。若双线性型对称，则表示矩阵对称。

## 复域的失效与替代

原书指出：在复向量空间中（因 $z^2$ 可以是负数），对称的以及正定的双线性型没有太大的意义；文献 [5.6] 用所谓**半双线性型**的概念代替双线性型，以此定义酉点积以及距离和角——见 [[concepts/半双线性型与埃尔米特型]] 与 [[findings/复域上对称正定双线性型失效与半双线性替代]]。操作规程见 [[methodology/由基构造双线性型表示矩阵流程]]，比较见 [[comparisons/双线性型与半双线性型比较]]。
