# 动态规划标准形

动态规划标准形（式 18.126a）是《数学手册(原书第10版)》18.3.1.2 给出的 n 级决策问题的规范表述：在全部约束下确定策略 $(u_1,\dots,u_n)$，把过程从 $x_a$ 驱动至 $x_e$，并使目标函数（费用函数）$f(f_1(x_0,u_1),\dots,f_n(x_{n-1},u_n))$ 达到极小。其约束分为动态约束与静态约束两类。

```latex
OF: f(f_1(x_0,u_1), …, f_n(x_{n-1},u_n)) → min!
CT: x_j = g_j(x_{j-1},u_j),  j = 1(1)n
    x_0 = x_a,  x_n = x_e ∈ X_e,  x_j ∈ X_j ⊆ ℝ^m,  j = 1(1)n
    u_j ∈ U_j(x_{j-1}) ⊆ ℝ^m,  j = 1(1)n
```

## 约束的两分

- **动态约束**：状态变换 $x_j=g_j(x_{j-1},u_j)$（第一种类型的约束），刻画过程随级演化。
- **静态约束**：其余约束，即 $x_0=x_a$、$x_n=x_e\in X_e$、$x_j\in X_j$、$u_j\in U_j(x_{j-1})$，不随级演化而改变形式。

## 相关约定

- 函数 $f_j(x_{j-1},u_j)$ 称作**阶段费用函数**，是总费用函数 $f$ 的分级成分。
- 与 (18.126a) 类似，可以考虑极大问题（对称处理，如 [[concepts/背包问题（0-1背包）]]）。
- 满足所有约束条件的策略称作**可行策略**（原文误作「可行约束」）。
- 只有当目标函数满足某些附加要求（可分性与极小可交换性，见 18.3.3）时，才能应用动态规划法。

## 记法渊源与疑点

OF/CT（目标函数/约束条件）的记法与 18.2.2 特殊非线性优化问题（[[sources/10-数学手册原书第10版--14-1822-特殊非线性优化问题--1d674j5]]，式 18.43–18.46）一脉相承。转写疑点：末行决策空间 $U_j(x_{j-1})\subseteq\mathbb{R}^m$ 与 18.3.1.1 的 $U_j(x_{j-1})\subseteq\mathbb{R}^s$ 矛盾，疑为 $\mathbb{R}^s$；正文 $X_e\subseteq\mathbb{R}_m$ 的下标疑为上标，见 [[queries/18-3全节系统性转写讹误清单]]。
