# 列表元素选取命令

列表元素选取命令是 Mathematica 中从一个 [[列表（Mathematica）]] 里选取一个或多个元素的命令族，即《数学手册(原书第10版)》表 20.3 所列的 First、Last、Most、Rest、Part、Take、Drop 七个命令（Part 计三种形式）；其输出是一个「子列表」或单个元素。转写文本中表题及正文「20.3 表示的是」均脱「表」字。

## 表 20.3 选取列表元素的命令（逐字转录）

| 命令 | 说明 |
|---|---|
| First[l], Last[l] | 选取第一个/最后一个元素 |
| Most[l], Rest[l] | 选取除最后一个/第一个元素以外的元素 |
| Part[l, n] 或 l[[n]] | 选取第 n 个元素 |
| Part[l, {n1, n2,···}] | 给出具有给定数目的元素的一个列表 |
| l[[{n1, n2,···}]] | 等价于前面的运算 |
| Take[l, m] | 给出 l 的前 m 个元素构成的列表 |
| Take[l, {m, n}] | 给出从第 m 个元素到第 n 个元素构成的列表 |
| Drop[l, n] | 给出没有前 n 个元素的列表 |
| Drop[l, {m, n}] | 给出没有从第 m 个元素到第 n 个元素的列表 |

## 算例

对于式 (20.10) 定义的列表 l1（源文讹作「对于 (20.9) 中的列表 ll」）：

```text
In[2] := First[l1]        → Out[2] = a1
In[3] := l1[[3]]          → Out[3] = a3
In[4] := l1[[{2, 4, 6}]]  → Out[4] = {a2, a4, a6}
In[5] := Take[l1, 2]      → Out[5] = {a1, a2}
```

复算全部通过，见 [[式20-9至20-10列表构造与选取算例复算]]。带双重指标的选取形式 `l[[i, j]]`、`l[[{i1,···}, {j1,···}]]` 见 [[嵌套列表]]。

## 释义疑点

`Part[l, {n1, n2,···}]` 行的释义「给出具有给定数目的元素的一个列表」疑当作「给出具有给定位置（号）的元素的一个列表」：算例 `l1[[{2, 4, 6}]] = {a2, a4, a6}` 表明语义是按位置号选取而非按数目。此点归入 [[20-2-4全节系统性转写讹误清单]]。
