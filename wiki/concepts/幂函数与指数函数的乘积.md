# 幂函数与指数函数的乘积

幂函数与指数函数的乘积指函数

$$
y = a\,x^{b}\,\mathrm{e}^{cx} \quad (c \neq 0) \tag{2.62}
$$

手册两处涉及该函数：2.6.1 以式 (2.62) 给出初级定义，图 2.31 给出任意参数下曲线的性状（第 96–97 页）；2.16.2.10 将其开列为经验公式族 (2.266a)，典型曲线形状见图 2.90（不同参数值对应的多条曲线）。它也是 2.16.2.12 数值算例的最终选定公式。

手册仅讨论 a > 0 的情形，a < 0 时只需将图形沿 x 轴反射。

## 定义域与原点行为

- b 不是整数时，仅在 x > 0 时给出定义；b 是整数时，x < 0 处曲线形状可归入同样情况。
- **b > 0**：曲线过原点，原点处切线按 b 分档：
  - b > 1：切线为 x 轴；
  - b = 1：手册作切线 y = x，⚠️ 疑漏系数 a，应为 y = ax（见 [[幂指乘积b等于1时切线y等于x是否应为y等于ax]]）；
  - 0 < b < 1：切线为 y 轴。
- **b < 0**：y 轴为曲线的一条[[渐近线]]。

## 增减与极值、拐点（已复核）

- **c > 0**：函数不断增加且超过任何给定的值；**c < 0**：函数渐近趋近于 0。
- **极值**：b, c 异号时在 $x = -\dfrac{b}{c}$（曲线上点 A）有极值（由 $y'/y = b/x + c = 0$ 解出）。
- **拐点**：在 $x = \dfrac{-b\pm\sqrt{b}}{c}$ 有 0 个、1 个或 2 个拐点（图 2.31(c)(e)(f)(g) 中的点 C, D；由 $y''/y = (b/x+c)^{2} - b/x^{2} = 0$ 即 $c^{2}x^{2} + 2bcx + b^{2} - b = 0$ 解出，b < 0 时判别式 $4c^{2}b < 0$，无拐点）。

详见 [[幂指乘积函数的切线渐近线极值与拐点]]。

## 修正（差分型）

作为 2.16.2.10 的经验公式族，该族的修正全部取差分形式，且依 x 数据的数列结构分三种情形：

- **x 成公差 h 的等差数列**（式 2.266b）：$X=\Delta\log x,\ Y=\Delta\log y$，得 $Y=hc\log\mathrm{e}+bX$；
- **x 成公比 q 的等比数列**（式 2.266c）：$X=x,\ Y=\Delta\log y$，得 $Y=b\log q+c(q-1)X\log\mathrm{e}$；
- **x 非等比但可选出商恒为常数 q 的数对**：作代换 $Y=\Delta_1\log y$（商为 q 的两个 x 值所对应两个 $\log y$ 之差）后，按等比情形的方法修正。

b、c 确定之后，对给定方程取对数，并像 (2.259d) 那样用求和方程算出 $\log a$。推导与验证见 [[幂指乘积的差分修正]]。

## 在数值算例中的地位

表 2.9 的 12 组数据最终以该族拟合：平均值法得 $y=364x^{1.966}\mathrm{e}^{-7.932x}$（误差平方和 0.0024），以此为初值的非线性最小二乘得 $y=396.601986x^{1.998098}\mathrm{e}^{-8.0000916x}$（误差平方和 0.0000916）。全过程见 [[经验拟合数值算例]]。
