# 运输问题

运输问题（transportation problem）是一类具有双指标等式约束结构的[[concepts/线性规划|线性规划]]问题：$m$ 个生产者 $E_1,\dots,E_m$ 各生产数量为 $a_1,\dots,a_m$ 的同一种产品，需运往需求量分别为 $b_1,\dots,b_n$ 的 $n$ 个消费者 $V_1,\dots,V_n$；从 $E_i$ 到 $V_j$ 的单位运输成本为 $c_{ij}$，运输量为 $x_{ij}$，求使总运输成本最小的运输方案（分布矩阵 $X=(x_{ij})$）。《数学手册》(原书第10版) 18.1.4.1 以「建模—平衡化—初始解—迭代」的完整链条处理该问题，并以它作为同节其余特殊问题的比较基准。

## 模型

```latex
% (18.26a)
OF: f(X) = \sum_{i=1}^{m}\sum_{j=1}^{n} c_{ij}x_{ij} = min!
CT: \sum_{j=1}^{n} x_{ij} = a_i  (i=1,\dots,m),
    \sum_{i=1}^{m} x_{ij} = b_j  (j=1,\dots,n),  x_{ij} >= 0
```

数据以成本矩阵 $C=(c_{ij})$ 与分布矩阵 $X=(x_{ij})$ 组织（18.25a/b）：行标生产者、列标消费者，$X$ 的行和为 $a_i$、列和为 $b_j$。这正是「等式约束＋非负变量」的[[concepts/线性规划标准形式|线性规划标准形式]]的自然实例。

## 平衡条件与虚构节点平衡化

模型假定系统平衡，即供给等于需求：

```latex
% (18.24)（原文如此；首和上限 n 疑为 m，见 queries/18-30求和上限互换之辨）
\sum_{i=1}^{n} a_i = \sum_{j=1}^{n} b_j
```

若 (18.24) 不满足，则以零成本虚构节点恢复平衡：
- $\sum a_i>\sum b_j$：引入虚构消费者 $V_{n+1}$，需求 $b_{n+1}=\sum a_i-\sum b_j$，成本 $c_{i,n+1}=0$；
- $\sum a_i<\sum b_j$：引入虚构生产者 $E_{m+1}$，产能（原文印作 $a_{n+1}$，疑为 $a_{m+1}$）$=\sum b_j-\sum a_i$，成本 $c_{m+1,j}=0$。

这一技巧与 18.1.1 中引入[[concepts/松弛变量|松弛变量]]的思想同构，可直接验证恢复 (18.24)。

## 约束秩与基结构

$m+n$ 个供需约束中仅 $m+n-1$ 个线性无关（供需总和相等导致一次相关），故非退化基本可行解恰含 $m+n-1$ 个正分量。约束矩阵每列恰有两个等于 1 的元，故一般单纯形大表 $(m+n)\times(m\cdot n)$ 极稀疏——这正是位势法的动机（见下）。

## 顶点最优性

该问题的极小出现在可行集的某个顶点（回指 18.1.1 的几何结论，[[concepts/可行集]]）。

## 求解算法（运输算法）

原文称「为了确定最优解，使用下列所谓的运输算法」，分两步：
1. 以西北角规则确定初始基本可行解：[[methodology/西北角规则初始基本可行解流程]]；
2. 以位势法（修正成本矩阵迭代，原文称「潜在乘子或单纯形乘子」，通行作位势/MODI/u-v 法）迭代至最优：[[methodology/运输问题位势法迭代流程]]。

另有考虑运输成本的初始解方法，如 Vogel 近似法（引 [18.15]），「通常会得到更好的初始解」——此为经验断言，仅属 Vogel 近似法，不可移用于西北角规则。

完整 3×4 算例复算见 [[findings/运输算例西北角初始解与位势法两轮迭代复算]]。

## 在问题谱系中的位置

配置问题（指派问题）是它在 $m=n$、$a_i=b_j=1$ 下的 0-1 特例；分配问题（产品—机器分配）把列约束换成带系数的容量不等式，是它的推广。谱系与五类问题对照见 [[comparisons/五类特殊线性规划问题比较]]。
