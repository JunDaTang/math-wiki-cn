# 勒贝格测度 λ

勒贝格测度是 ℝⁿ (n ⩾ 1) 上由四条性质唯一确定的测度 λ：它把 n 维长方体的测度指定为其体积、包含全部博雷尔集、对零测集的子集完备、且平移不变。可测 σ-代数 𝒜 中的元称作 ℝⁿ 的勒贝格可测子集。

## 长方体体积 (12.206)

Q = {x ∈ ℝⁿ : a_k ⩽ x_k ⩽ b_k} 的体积为 ∏_{k=1}^n (b_k − a_k)。（转录本括号内作 (k = 1, 2, …)，疑漏上标 n。）

## 唯一刻画（12.9.1 例 C）

使用扩张方法，存在唯一确定的 ℝⁿ 子集 σ-代数 𝒜 及其上唯一确定的测度 λ，满足：

- a) ℝⁿ 的每个开集属于 𝒜，即 B(ℝⁿ) ⊂ 𝒜
- b) 完备性：A ∈ 𝒜, λ(A) = 0, B ⊂ A ⟹ B ∈ 𝒜 且 λ(B) = 0
- c) Q 为长方体 ⟹ Q ∈ 𝒜 且 λ(Q) = ∏_{k=1}^n (b_k − a_k)
- d) 平移不变性：对每个向量 x ∈ ℝⁿ 与 A ∈ 𝒜，有 x + A = {x + y : y ∈ A} ∈ 𝒜 且 λ(x + A) = λ(A)

「唯一确定 σ-代数 𝒜 与测度 λ」是 12.9 节最强的刻画性断言。引入测度的原始动机正是推广区间长度、平面区域面积与立体体积，让尽可能多的集合可度量、尽可能多的函数可积。

## 遍历论中的角色（17.2.1 吸引子上的概率测度）

在数学手册 17.2.1 中，勒贝格测度 λ 被隐含地用作实直线（及其区间、圆周）上标准的「长度」测度。该节三大一维算例的[[不变测度|不变测度]]均为勒贝格测度：

| 映射 | 不变测度 |
|---|---|
| [[伯努利转移映射]] (17.28) | [0,1] 上勒贝格测度 |
| [[帐篷映射]] (17.29) | [0,1] 上勒贝格测度 |
| [[圆周旋转映射]] (17.31) | 圆周上规范化概率测度 λ/2π |

此外，勒贝格测度在 SRB 理论中担任「初值采样的基准」：[[SRB测度]]的判据 (17.32a) 要求时间平均收敛到 ∫ h dμ 的初值集具有**正勒贝格测度**；[[自然测度]]的口径也是「对 λ-几乎处处的初值」（与[[米尔诺吸引子]]定义同构）。以勒贝格测度为不变测度时，[[伯努利转移映射]]的[[测度熵]] h_μ = ln 2。

## 关联

- 构造出发点是 [[博雷尔σ代数与博雷尔集]]（含所有开集的最小 σ-代数），回指 12.2 的 [[开集与闭集]]。
- λ 是 [[勒贝格积分]] 在 X = ℝⁿ 情形所用的测度；n = 1、A = [a, b] 时得到与黎曼积分可比较的勒贝格积分。
- 零测集概念支撑 [[几乎处处]]。
- 在遍历论语境中，λ 作为一维算例的[[不变测度|不变测度]]，并充当 SRB 理论中初值采样的基准（见上节）。
