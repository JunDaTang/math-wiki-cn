# 几乎处处（μ-a.e.）

在测度论和积分理论中，称某个命题（性质、条件）相对于测度 μ 在 X 的一个集上几乎处处或 μ 几乎处处成立，是指命题不成立的点集的测度为零，记作 a.e. 或 μ-a.e.。

## 例（手册原文）

设 λ 是 ℝ 上的勒贝格测度，A、B 为使 ℝ = A ∪ B 的不相交集合，f 是 ℝ 上的函数：f(x) = 1 对 ∀x ∈ A，f(x) = 0 对 ∀x ∈ B。则在 ℝ 上 f(x) = 1（λ-a.e.）当且仅当 λ(B) = 0。

## 在本节中的作用

- 可积函数 a.e. 有穷（积分性质 (1)）。
- 积分性质 (6)：a.e. 相等的函数在任一可测集上积分相等。
- [[concepts/莱维单调收敛定理]] 与 [[concepts/勒贝格控制收敛定理]] 的条件均以 a.e. 形式陈述。
- 𝓛^p 中两函数等价 ⟺ f = g μ-a.e.；拟范数 N_p 的零空间恰为 a.e. 为零的函数集（见 [[concepts/拟范数]] 与 L^p 商构造，[[comparisons/数学Lp与商空间Lp比较]]）。
- 本质有界与 [[concepts/本质上确界与L∞]] 的定义 |f(x)| ⩽ a μ-a.e.。
- 正则分布相等的判据：ℓ_f = ℓ_g ⟺ f = g λ-a.e.（见 [[concepts/分布空间]]）。

## 与库内疑问的呼应

12.4 节出现过的「几乎处处稠」表述疑误（[[queries/12-4-2-1d几乎处处稠表述疑误]]）可参照本节的严格定义重新审视：µ-a.e. 是关于零测集的修饰语，与稠密性（拓扑概念）属不同范畴，二者叠加使用需要专门界定。
