# 一致搜索

## 概念

一致搜索（均匀网格搜索）是《数学手册(原书第10版)》18.2.4.1 给出的第一种一维极小搜索方法：在 [[concepts/单峰函数|单峰]]前提下，以等距格点采样函数值，用最小格点定位极小点 x\* 的所在区间。它与区间套缩式的 [[concepts/黄金分割法]]、[[concepts/斐波那契法]] 构成对照。

## 方法

选择正整数 n 使得 δ = (b − a)/(n + 1) < ε/2，计算格点函数值 f(x^k)，其中 x^k = a + kδ（k = 1, …, n）。若 f(x̄) 是这些函数值中的最小值（x̄ 为取得最小值的格点），则极小点 x\* 就在区间 [x̄ − δ, x̄ + δ] 上，该区间长度 2δ < ε 满足精度要求。

对给定精度，所需函数值数目可估计为（式 18.67）：

```text
n > 2(b − a)/ε − 1
```

即函数值数目随 1/ε **线性**增长。复算核验见 [[findings/式18-67一致搜索函数值数目估计复算]]。

## 归属与限定

式 18.67 的估计仅关于一致搜索本身；源文「黄金分割与斐波那契相比至多多一个函数值」的比较论断不涉及一致搜索。三方复杂度对比（线性 vs 对数级）为本维基推演而非源文论断，见 [[comparisons/三种一维极小搜索方法比较]]。

## 转写说明

源文将最小格点误写为 f(x)、定位区间误写为 [x − δ, x + δ]，应为 f(x̄)、[x̄ − δ, x̄ + δ]；「选择一正整数」后脱字符 n。见 [[queries/18-2-4全节系统性转写讹误清单]]。
