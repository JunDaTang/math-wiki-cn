# 第II类三次曲线

第II类三次曲线是手册 2.4.4 对函数

```latex
y = 1/(ax² + bx + c),  a ≠ 0    (2.48)
```

的图像的称呼：其隐式方程 y(ax² + bx + c) = 1 含 x²y 项，为三次代数曲线。图像关于铅直直线 x = −b/(2a) 对称，且因 x → ±∞ 时 y → 0，x 轴是它的 [[concepts/渐近线]]。

形状取决于 a 与 Δ = 4ac − b² 的符号；a < 0 情形可由 a > 0 情形沿 x 轴反射得到（将 a、b、c 全部变号再取反射，恒等式 −1/((−a)x² − bx − c) = 1/(ax² + bx + c) 成立）。取 a > 0，按 Δ 三情形（详见 [[findings/第II类三次曲线按判别式三情形的公式体系]]）：

- **Δ > 0**（分母无实根）：函数处处为正的连续函数，在 (−∞, −b/(2a)) 上单调递增并取得[[concepts/极值|极大值]] 4a/Δ，极值点 A(−b/(2a), 4a/Δ)，再单调递减；[[concepts/拐点]] B, C = (−b/(2a) ± √Δ/(2a√3), 3a/Δ)，拐点处切线斜率（源文称「角系数」）tan φ = ∓a²(3/Δ)^{3/2}；
- **Δ = 0**：x₀ = −b/(2a) 为二重[[concepts/极点]]（间断点），lim(x→x₀) y = +∞，两侧均正；
- **Δ < 0**：两个一重间断点 x = (−b ± √(−Δ))/(2a)；函数值先由 0 增至 +∞、跳跃到 −∞，在两间断点之间递增取得极大值 4a/Δ（负值）后又减小到 −∞，再跳跃到 +∞ 减小到 0。

判别式符号约定与 2.4.3 相反的问题见 [[queries/2-4节内二次判别式两种符号约定为何并存]]。另见 [[concepts/第I类三次曲线]]、[[concepts/第III类三次曲线]]、[[comparisons/三类三次曲线比较]]。
