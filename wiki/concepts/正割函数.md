# 正割函数

正割函数是六种[[concepts/三角函数]]之一，为余弦的倒数：

$$y = \sec x = \frac{1}{\cos x} \tag{2.70}$$

周期 $T = 2\pi$，渐近线 $x = \left(k+\frac{1}{2}\right)\pi$（cos x 的零点，即[[concepts/无穷间断点]]/[[concepts/极点]]），且显然 $|y| \geqslant 1$。

## 极值反转

- 局部极大值点 $A_k = \left((2k+1)\pi,\ -1\right)$（k = 0, ±1, ±2, …）；
- 局部极小值点 $B_k = (2k\pi,\ +1)$。

「极大值为 −1、极小值为 +1」初看与 $|y| \geqslant 1$ 矛盾，实为按局部[[concepts/极值]]定义的正确陈述：在 $\cos x < 0$ 的分支上 $\sec x \leqslant -1$ 且支内先增后减，故峰值 −1 是局部极大；在 $\cos x > 0$ 的分支上 $\sec x \geqslant 1$，谷值 +1 是局部极小（见 [[findings/正割与余割的值域约束与极值反转]]，已按分支符号分析验证）。**这不是手册笔误，不应开勘误。**
