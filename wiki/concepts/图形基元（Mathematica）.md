# 图形基元（Mathematica）

图形基元是 Mathematica 中构成图形对象的基本元素。按《数学手册（原书第10版）》20.4.1 的表述，Mathematica 由内置图形基元构建图形对象，这些基元既包括点（Point）、线（Line）和多边形（Polygon）这类「对象」，也包括规定这些对象诸如粗细度和颜色这类「性质」的图形命令（后者另立 [[图形命令与相对绝对尺寸]] 专述）。

## 二维图形对象清单（表 20.14）

| 条目 | 释义 |
|---|---|
| `Point[{x, y}]` | 位置 x,y 处的点 |
| `Line[{{x1,y1},{x2,y2},···}]` | 通过已知点的折线 |
| `Rectangle[{xlu,ylu},{xro,yro}]` | 填充具有给定的左下,右上坐标的矩形 |
| `Polygon[{{x1,y1},{x2,y2},···}]` | 填充具有给定顶点的多边形 |
| `Circle[{x,y},r]` | 以 x,y 为中心、半径为 r 的圆 |
| `Circle[{x,y},r,{α1,α2}]` | 以给定角为界限的圆弧 |
| `Circle[{x,y},{a,b}]` | 具有半轴 a 和 b 的椭圆 |
| `Circle[{x,y},{a,b},{α1,α2}]` | 椭圆弧 |
| `Disk[{x,y},r]`、`Disk[{x,y},{a,b}]` | 填充圆或椭圆 |
| `Text[text,{x,y}]` | 以点 x,y 为中心写入文字 |

即 `Circle` 一族覆盖圆、圆弧、椭圆、椭圆弧四种形态，`Disk` 为其填充版本；`Text` 用于在图形中书写文字（如式 20.37a–b 的 `Text[Style["Example","Helvetica",Bold,25],{5,6}]` 以 (5,6) 为中心，以及 20.4.5.1 末句指出可用 Text 在曲线上书写文字）。

## 用法要点

- 基元通过 `Graphics[list]` 组装为图形对象（[[Graphics与Show图形对象]]）；list 中对象本身可以是图形对象的列表（嵌套，式 20.38a），见 [[式20-37至20-38b图形对象构建算例复算]]。
- 专用绘图命令内部同样以基元成图：`Plot` 由内部算法产生函数表后「利用图形基元从这个表产生图形」，`InputForm[%]` 证实所用基元为 `Line`（[[Plot函数绘图与内部函数表]]）。
- 三维图形基元同样存在，原书未展开，详见其所引文献 [20.5]（[[20-4未入库回指缺口]]）。
