# 伴随微分方程

**伴随微分方程**是与给定线性微分方程（算子 L）相伴的方程：设 u 满足 Lu = F，则伴随算子 L* 的齐次方程 L*v = 0 的解 v 可通过与 L 的配对（Lagrange 恒等式 / Green 公式）产生关于 u 的积分恒等式，从而把 u 用其边界（或初始曲线）数据表示出来。

手册给出两个层面的形式。两变量双曲主部情形（式 9.97a 的伴随，式 9.97b）：

$$\frac{\partial^{2} v}{\partial x \partial y} - \frac{\partial (av)}{\partial x} - \frac{\partial (bv)}{\partial y} + cv = 0$$

一般 n 变量情形（式 9.97d/e）：若 Lu = Σ_{i,k} a_{ik} u_{x_i x_k} + Σ_i b_i u_{x_i} + cu = f，则

$$L^{*}v = \sum_{i,k} \frac{\partial^{2} (a_{ik} v)}{\partial x_i \partial x_k} - \sum_i \frac{\partial (b_i v)}{\partial x_i} + cv = 0$$

结构要点：伴随算子把系数并入求导（分部求逆）——二阶项系数被吸收进 ∂²(a_{ik}v)，一阶项反号并吸收系数。

## 作用

- [[黎曼方法]]：黎曼函数 v(x, y; ξ, η) 是双曲方程 (9.97a) 的伴随方程 (9.97b) 满足特征线上条件 (9.97c) 的解。
- [[格林函数与格林方法]]：格林函数除极点外满足椭圆方程的齐次伴随方程（式 9.99b / 9.100b）。

与常微分方程情形的 [[自伴微分方程]]（L = L*）相衔接：自伴是伴随的特款。推导黎曼公式所用的 Lagrange 恒等式 vLu − uL*v = ∂ₓA + ∂_yB（A = auv + ½(vu_y − uv_y)，B = buv + ½(vu_x − uv_x)）已逐项展开验证，见 [[findings/式9-97黎曼方法独立推导与符号核对]]。
