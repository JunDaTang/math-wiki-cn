# 尖点分岔

**尖点分岔**（cusp bifurcation）是余维 2 的平衡点分岔。条件：(17.67) 中 r≥4、l=2，λ₁=0 其余特征值双曲，且约化方程满足 F(0,0)=∂F/∂x(0,0)=∂²F/∂x²(0,0)=0、l₃:=∂³F/∂x³(0,0)≠0。含参截尾正规形式（式 17.76，引 [17.1]）：

```latex
\dot{x} = \alpha_1 + \alpha_2 x + \operatorname{sign}(l_3)\, x^{3}
```

集合 {(α₁,α₂,x): α₁+α₂x+sign(l₃)x³=0} 为扩充相空间中的一张曲面，称为**尖点**（图 17.26(a)）。

## 折叠曲线（l₃<0 情形）

非双曲平衡点由 α₁+α₂x−x³=0、α₂−3x²=0 定义，位于 27α₁²−4α₂³=0 确定的曲线 S₁,S₂ 上（复算核验通过：由 x²=α₂/3 代入得 α₁²=4α₂³/27，见 [[式17-76尖点折叠曲线复算]]）。两曲线形成尖点；(α₁,α₂)=(0,0) 时平衡点 x=0 稳定（此时 (17.76) 化为 ẋ=−x³）。n=2、λ₁=0 时：λ₂<0 为三重结点（图 17.26(c)），λ₂>0 为三重鞍点（图 17.26(d)，引 [17.14]）。

## 尖点内的超临界叉型

从 (0,0) 进入尖点区域内部：复合结点分裂成三个双曲平衡点（两稳结点+一鞍点），即超临界 [[叉型分岔]]；S_i\{(0,0)}（i=1,2）的参数对从一区域横截进入另一区域时形成双鞍结点型平衡点，最终消失留下一个稳定双曲平衡点（转录两处脱落区域名）。
