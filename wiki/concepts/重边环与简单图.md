# 重边、环与简单图

**重边（multiple edges）**：如果多个边或弧被指派给同一个顶点的有向对或无向对，那么它们称为重边。**环（loop）**：具有相同端点（即两端点为同一顶点）的边称为环。**简单图（simple graph）**：没有环、没有重边及重弧的图称为简单图。

手册例 A（[[findings/图与关联函数定义及例ABC指派]]）给出实例：f₁(e₁) = f₁(e₂) = {v₁, v₂} 与 f₁(e₄) = f₁(e₅) = {v₃, v₄} 为两组重边，f₁(e₇) = {v₅, v₅} 为环。

## 与矩阵表示的联动

环与重边的计数约定直接决定 [[concepts/邻接矩阵]] 与 [[concepts/关联矩阵]] 的取值：

- 无向图邻接矩阵中环在对角线记 2，有向图邻接矩阵中环记 1；
- 关联矩阵中无向环记 2、有向环记 0；
- 重边/重弧使邻接矩阵元可以超过 1（算例 A₁ 中 (3,4) = 3，见 [[findings/邻接矩阵算例a1a2-式5-317]]）。

构造流程与环计数理由固化于 [[methodology/邻接矩阵与关联矩阵构造流程]]。
