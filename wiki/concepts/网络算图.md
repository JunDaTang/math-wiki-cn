# 网络算图

**网络算图**（network chart）是最常见的算图类型之一，用一族网格曲线同时载入三个变量：平行于坐标轴的两族直线分别表示变量 $x$ 与 $y$，第三族曲线——曲面 $F(x, y, z) = 0$ 的[[concepts/等高线|等高线]]——表示变量 $z$。三元关系由此投影为平面网格，任意两变量的取值经网格交点或沿等高线读出第三变量。

构造原理（式 2.292）与欧姆定律算例（图 2.108：以 $R, I$ 为笛卡儿坐标时 $U = $ 常数的等高线为双曲线族，定义域 $0 < R < 10$、$0 < I < 10$、$0 < U < 100$；换域 $0 < I < 1$ 时标记变为 $U/10$）见 [[findings/网络算图的等高线构造与欧姆定律算例]]。

[[concepts/标度|标度]]选择是网络算图的化直杠杆：等分标度下形如 $x\,\varphi(z) + y\,\psi(z) + \chi(z) = 0$ 的方程（式 2.293，原文首项系数作「r」，疑为「x」之讹，见 [[queries/式2-293的r是否应为x]]）可表示成由直线组成的算图；函数标度下形如式 (2.294) 的方程可表示为平行于坐标轴的两族曲线加任意一族直线（[[findings/标度化直原理与对数直线算图]]）。对数标度即把欧姆定律化为 $\log R + \log I = \log U$ 的直线网络算图（图 2.109）。

手册的时代注记：即使在计算机时代，实验室还常用网络算图计算近似值或作迭代时的初始推断——后者恰可为 2.16 的非线性拟合（如 [[findings/指数和的两级修正]] 所处理的指数和）提供初值，两节构成「图解初值 → 解析拟合」的互补工作流。

与贯线算图的系统比较见 [[comparisons/网络算图与贯线算图比较]]。
