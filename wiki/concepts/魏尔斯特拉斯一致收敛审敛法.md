# 魏尔斯特拉斯一致收敛审敛法

魏尔斯特拉斯一致收敛审敛法（又称强级数法、M-判别法）是判别函数项级数一致收敛的基本充分条件：若存在一个正项收敛级数 Σc_n（称为强级数），使得在所考察区域上对每个 n 都有 |f_n(x)| ⩽ c_n，则级数 Σf_n(x) 在该区域上一致收敛。

## 手册陈述（式 7.81a–c，逐字转录）

```latex
f_1(x) + f_2(x) + \dots + f_n(x) + \dots        % (7.81a) 待判级数
c_1 + c_2 + \dots + c_n + \dots                  % (7.81b) 强级数（正项收敛）
|f_n(x)| \leqslant c_n                            % (7.81c) 逐项控制
```

手册为陈述式给出、不附证明；这是经典标准结果。逐字转录与判读见 [[式7-81魏尔斯特拉斯强级数审敛法]]。

## 机理与用法

判别法把「无穷多个 x 上同时控制余项」的问题归结为「一个数项级数的收敛」：由 |f_n(x)| ⩽ c_n 与 Σc_n 收敛，可通过柯西准则同时对一切 x 控制 Σ_{k>n} f_k(x)。注意它给出的是充分条件，且附带绝对收敛；非一致收敛的级数自然无法找到强级数（如 [[式7-80非一致收敛算例与和函数不连续]] 中余项上确界为 1）。
