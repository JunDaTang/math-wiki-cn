# 数列的极限

数列的极限刻画数列项随下标无限增大而稳定趋近某值的行为。手册先给出直观说法——若对无限增加的指标 n，恒有 aₙ − A 任意小，则称无穷数列 (7.1) 有极限 A——随后给出 ε–n₀ 精确定义：

若对于任意小的 ε > 0，总存在指标 n₀(ε)，使得对于 n > n₀ 时的一切 aₙ，恒有

|aₙ − A| < ε　(7.5a)

（源文两处「对于」均误转为「对千」，属本节系统性的「于→千」别字。）

极限为无穷的情形单列：若对于任意 K > 0 总存在指标 n₀(K)，使得对于 n > n₀ 时的一切 aₙ 恒有 aₙ > K（相应地 aₙ < −K），则称数列 (7.1) 的极限为 +∞（−∞）(7.5b)。注意 (7.5b) 要求「一切 aₙ」：I 例的奇子列趋于 −∞ 但偶项恒为 0，不满足该条件，故只归入假发散而非真发散（见 [[concepts/真发散与假发散]]）。

满足 (7.5a) 的数列称为收敛数列，记为 lim\_{n→∞} aₙ = A 或 aₙ → A（式 7.6），分类见 [[concepts/收敛与发散]]。逐字转录见 [[findings/式7-5至7-7极限定义与真假发散判定]]。
