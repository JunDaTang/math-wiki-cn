# 解的基本系

解的基本系（基本解，fundamental system of solutions）是齐次线性方程组 A x = 0 的 l 个线性无关非平凡解 α₁, …, α_l 所构成的组（式 4.179b）。齐次方程组的平凡解 x = 0 恒存在（式 4.179a，因 rank(A) = rank(A, 0) 总成立）；非平凡解的任何线性组合仍是解。当系数矩阵的秩 r < n（未知数个数）时，恰有 l = n − r 个线性无关非平凡解，此时一般解为

x = k₁α₁ + k₂α₂ + … + k_l α_l（k₁, …, k_l 为任意常数）。

若 r = n，则解唯一，即齐次方程组仅有平凡解。

## 基本解的构造

在 r < n 情形，选取 n − r 个未知数作为自由参数，通过它们表示其余未知数（式 4.180：重排方程与未知数使左上角 r 阶子行列式非零后，x_ρ = x_ρ(x_{r+1}, …, x_n)）；依次令一个自由参数为 1、其余为 0，即得形如式 (4.181) 的基本解。算例 E（4 方程、4 未知数、rank = 2）给出基本解 α₁ = (−3/2, 7/2, 1, 0)ᵀ 与 α₂ = (−1, −2, 0, 1)ᵀ，见 [[findings/齐次基本解系与算例E]]。
