# 模糊控制

**模糊控制**是以模糊法则基础为核心的闭环控制范式：将清晰测量值**模糊化**为前提隶属等级，据此判定起作用的法则及其权；把各法则的结果**聚合**；再经**逆模糊化**得到清晰控制量；整个过程迭代进行，直至偏差及其变化达到最小。数学手册 5.9.6 将其表述为「量和特征数的模糊化 → 通过适当的知识基础与运算聚合 → 必要时将模糊结果集逆模糊化」这一一般概念在控制上的落地。

## 构成模块

以 [[mamdani方法]] 的四步为典型（式 5.389）：

1. **法则基础**（见 [[法则基础]]）：IF–THEN 模糊法则集合；Mamdani 后件为模糊集，Sugeno 后件为函数；
2. **模糊化**（见 [[模糊化]]）：判定哪些法则起作用及其权有多大；
3. **聚合**：不同权的起作用法则以代数运算结合（Mamdani 用极大-极小复合，见 [[模糊关系的复合]]）；
4. **决策/逆模糊化**（见 [[逆模糊化]]）：对控制量给出清晰值，使系统偏差及其变化保持极小。

模糊控制意味着 (1)–(4) 重复执行直至偏差最小；源文注记：迭代最终抵达分区空间的中心，即得到零控制量。

## 两条实现路线

- [[mamdani方法]]：模糊后件 + 逆模糊化；[[逆摆]] 算例为完整示范（F=3.95/5.0，已复算）。
- [[菅野方法]]：函数后件 + 加权平均，省去逆模糊化；并可视为基于法则的插值器（见 [[基于知识的插值系统]]）。

系统比较见 [[mamdani与菅野方法比较]]。模糊控制的知识载体是 [[语言变量]]（nl, nm, ns, z, ps, pm, pl 等语言项）与 [[模糊逻辑]]；「基于人类控制专家语言法则」的建模路线见 [[认知系统]]。
