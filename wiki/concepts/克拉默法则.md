# 克拉默法则

克拉默法则是线性方程组一个重要特殊情形的显式解法：当方程个数等于未知数个数（m = n，式 4.184a）且系数行列式 D = det A ≠ 0（式 4.184b）时，方程组的唯一解可用明显且唯一的形式给出：

```
x_ν = D_ν / D    (ν = 1,…,n)                                        (4.184c)
```

其中 D_ν 表示用常数项 a_μ 替换 D 的第 ν 列元素 a_μν 所得的行列式（式 4.184d）。

## 退化情形

源给出：若 D = 0（转写讹作 D=O）且至少有一个 D_ν ≠ 0，方程组无解；若 D = 0 且所有 D_ν = 0，方程组「可能有解但不唯一」。注意后一表述不完整——该情形下方程组也可能无解（如退化的不相容系统）；源自我提示「参见第 417 页注」（未入库，见 [[queries/4-5节前向引用未入库缺口]]）。

## 适用性限制（源的关键断言）

源明确断言：**从实用性考虑，克拉默法则对于高维问题不适用**，因为问题的维数增加时所要求的运算量很快增加；因此对于线性方程组的数值解应改用高斯算法或选主元法以及迭代程序（参见第 1233 页 19.1.1，未入库）。该断言仅针对克拉默法则，见 [[comparisons/克拉默法则与高斯算法比较]]。

## 算例

2x₁ + x₂ + 3x₃ = 9；x₁ − 2x₂ + x₃ = −2；3x₁ + 2x₂ + 2x₃ = 7：D = 13，D₁ = −13，D₂ = 26，D₃ = 39，唯一解 (−1, 2, 3)，已复算，见 [[findings/克拉默法则及算例与高维不适用断言]]。
