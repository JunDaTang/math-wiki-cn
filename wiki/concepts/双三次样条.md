# 双三次样条

双三次样条 S(x,y) 是矩形区域上分片双三次、整体适当光滑的样条，用于逼近矩形网格节点上给定的函数值。矩形 R: a ⩽ x ⩽ b, c ⩽ y ⩽ d 被节点 (x_i, y_j)（i = 0,…,n; j = 0,…,m）剖分为子区域 R_ij，网格分割为 (19.244)：a = x_0 < ⋯ < x_n = b，c = y_0 < ⋯ < y_m = d；节点处给定 f(x_i, y_j) = f_ij (19.245)，要求以尽可能简单的光滑曲面逼近这些点。

## 定义性质（19.7.2.2）

```latex
(19.246) 插值条件：S(x_i, y_j) = f_ij   (i = 0,…,n; j = 0,…,m)
(19.247) 分片双三次：S(x,y) = S_ij(x,y) = Σ_{k=0}^{3} Σ_{l=0}^{3} a_ijkl (x−x_i)^k (y−y_j)^l
          ——每个 S_ij 由 16 个系数确定；S(x,y) 共需 16mn 个系数（原文「l6mn」为 OCR 讹误）
(19.248) ∂S/∂x、∂S/∂y、∂²S/∂x∂y 在区域上连续，从而在整个曲面上保证某种光滑性
(19.249) 边界条件（p_ij、q_ij、r_ij 预先给定；原文三处 (x_i, y_i) 应为 (x_i, y_j)）：
         ∂S/∂x(x_i, y_j) = p_ij,     i = 0,n;  j = 0,…,m
         ∂S/∂y(x_i, y_j) = q_ij,     i = 0,…,n;  j = 0,m
         ∂²S/∂x∂y(x_i, y_j) = r_ij,  i = 0,n;  j = 0,m
```

四条性质唯一确定 S(x,y)。

## 系数确定

一维三次样条插值的结果可用来确定系数 a_ijkl：

1. 线性方程组的个数 2n+m+3 非常大，但其系数矩阵是三对角矩阵；
2. 各线性方程组仅右端项不同。

原书未给计数推导；可由 (m+1)+(n+1)+(n+1) 的可行算法复原（数据行沿 x 的样条、数据列沿 y 的样条、边界导数 p 沿 y 的样条），未必是讹误，但属复原假说——见 [[findings/式19-244至19-251双三次样条与张量积转录复算]]。计算系数的实际方法原书外推至文献（编号缺失）。

原书评价：一般对于计算量和精度来说，双三次插值样条是有用的，故对于实际应用它们是合适的。

## 双三次光滑样条（19.7.2.3）

一维情形以最优条件 (19.242)（见 [[concepts/光滑样条]]）为特征；二维情况可能有一整列相应的最优条件，但**仅有很少特殊的情况可能存在唯一解**——原书自设的重要 caveat。适当的最优条件和算法见文献（编号缺失）。
