# 生成矩阵与校验矩阵

生成矩阵与校验矩阵是刻画 (n,k) 线性码（[[concepts/线性码]]）的一对矩阵工具：前者以行向量张成码并给出编码，后者以伴随式实现译码。

## 生成矩阵 G

```
G = (g_ij)_{k×n}，行向量为 g_1, …, g_k                                 (5.267)
C = {aG | a ∈ GF(2)^k}；a_1a_2…a_k ↦ a_1g_1 + a_2g_2 + … + a_kg_k (= aG)  (5.268)
```

码由生成矩阵唯一确定；编码即信息字的线性组合（aG）。

## 校验矩阵 H

```
H = (h_ij)_{(n−k)×n}                                                    (5.269)
```

- 若 H 的[列]两两不同且非零，则该（二元）线性码为 [1-]纠错码（源文作「行」，与 H 的形状 (n−k)×n 及 Hd^T 的维数矛盾，应为「列」，见 [[queries/校验矩阵的行是否应为列]]）。
- 伴随式译码：对收到的字 d 算 Hd^T；为零则 d 是码字；否则若 Hd^T 是 H 的第 i [列]，译为 d + e_i（e_i 为第 i 位是 1 的单位向量）。流程见 [[methodology/伴随式译码流程]]。
