# 菲涅耳积分

菲涅耳积分（Fresnel integral）在手册中呈现于两处，形式不同：

- **14.4 用复积分计算实积分**：作为 $\int \sin x^2$、$\int \cos x^2$ 型振荡反常积分，例 5 用扇形围道求出无穷区间上的值（式 14.62）。
- **21.14 傅里叶变换**：作为一对由 $\frac{\cos t}{\sqrt t}$、$\frac{\sin t}{\sqrt t}$ 的半轴累积积分定义的特殊函数 $C(x)$、$S(x)$，带 $\frac{1}{\sqrt{2\pi}}$ 规范化因子。

两处约定不同，不可混用；详见下文「规范化要点（复算前提）」。

## 无穷区间上的值（14.4.3 例 5）

在 14.4 中，菲涅耳积分是 $\int \sin x^2$、$\int \cos x^2$ 型振荡反常积分，名称源于物理学家 Fresnel（14.4 一节仅以其命名）。14.4.3 例 5 给出其在无穷区间上的值：

$$\int_0^\infty \sin(x^2)\,\mathrm{d}x = \int_0^\infty \cos(x^2)\,\mathrm{d}x = \frac{1}{2}\sqrt{\pi/2} \tag{14.62}$$

## 推导要点（扇形围道 + 指数估计）

取张角 π/4 的扇形闭围道（图 14.48）：实轴段 [0, R]（I_I）、半径 R 的大弧段（I_II）、沿 π/4 射线的返回段（I_III）。因 e^{−z²} 在全平面解析，由 [[柯西积分定理]] 得

$$I = I_I + I_{II} + I_{III} = 0$$

![图 14.48 扇形围道（张角 π/4）](media/10-数学手册原书第10版--13-144-用复积分计算实积分--sa2nfv/003-dd2bb666f2a17d33330712ee2357eae734e955bc4cd4c74d76d78e2ed799b559.jpg)

- **I_I** = ∫₀^R e^{−x²}dx → ½√π（高斯积分，R→∞）；
- **I_II**：大弧段上 |e^{−z²}| = e^{−R²cos2φ} 在弧段两端不小，需 α-分割估计（流程见 [[扇形围道指数估计流程]]）：

$$|I_{II}| < \frac{\alpha R}{2}\,e^{-R^2\cos\alpha} + \frac{1-e^{-R^2\cos\alpha}}{2R\sin\alpha} \quad \left(0<\alpha<\frac{\pi}{2}\right) \to 0$$

- **I_III**：沿 π/4 射线 z = re^{iπ/4} 有 z² = ir²，故 e^{−z²} = e^{−ir²}。修正后的表达式为

$$I_{III} = e^{i\pi/4}\int_R^0 e^{-ir^2}\,\mathrm{d}r = \frac{1}{2}\sqrt{2}\,(1+i)\left[i\int_0^R \sin r^2\,\mathrm{d}r - \int_0^R \cos r^2\,\mathrm{d}r\right]$$

（源文此处写 e^{ir²}，指数疑漏负号，见 [[式14-62菲涅耳III指数疑漏负号]]；其后括号展开 [i∫sin r² dr − ∫cos r² dr] 恰等于 ∫_R^0 e^{−ir²}dr，仅与 e^{−ir²} 自洽。）

令 R→∞，由 I_I + I_III → 0 分离实部与虚部，解得两个积分相等且均为 ½√(π/2)，即 (14.62)。全链复算通过，与独立已知值一致（见 [[式14-56至14-62及ez例复积分计算实积分转录复算]]）。

## 方法定位

本例围道内无奇点、不用留数，而是柯西积分定理（闭路积分为零）+ 绝对值估计的组合，展示了区别于上半平面围道与缩进围道的第三种围道形态（扇形），见 [[三种实积分复计算方法比较]]。

## 傅里叶变换中的规范化定义（21.14）

在 21.14 傅里叶变换一节中，菲涅耳积分是一对由 $\frac{\cos t}{\sqrt t}$、$\frac{\sin t}{\sqrt t}$ 的半轴累积积分定义的特殊函数（独立可验证的背景：常见于波动衍射理论与 chirp 信号分析）。手册 21.14 采用如下规范化（照录，回指第 988 页 14.4.3.2,5.）：

$$C(x)=\frac{1}{\sqrt{2\pi}}\int_0^x\frac{\cos t}{\sqrt t}\,dt,\qquad S(x)=\frac{1}{\sqrt{2\pi}}\int_0^x\frac{\sin t}{\sqrt t}\,dt.$$

### 规范化要点（复算前提）

- 带 $\frac{1}{\sqrt{2\pi}}$ 因子，故 $C(\infty)=S(\infty)=\frac12$（而非无因子约定的 $\sqrt{\pi/8}$ 量级）。
- 表值中变元常取平方量 $\frac{\omega^2}{4a}$ 或 $\frac{a^2}{4\omega}$（如 21.14.1-58/59/69/71/72 号、21.14.2-58–61 号），而非直接以 $x$ 出现。

任何照搬其他 Fresnel 约定的复算都会得出假阳性差异；这是解读 21.14 相关表值的前提（见 [[10-数学手册原书第10版--10-2114-傅里叶变换--12suskw]] 的内在注意事项）。58 号表值系数 $\sqrt{2a}$ 疑为 $\sqrt{\pi a}$ 的判定即在此规范化下作出，见 [[21-14-1之58系数根号2a疑为根号πa复算]]。
