# 正态分布

**正态分布**（参数 (μ, σ²)）是连续概率分布中最重要的基准分布之一：若连续随机变量 X 的分布函数为

```
P(X ⩽ x) = F(x) = 1/(σ√(2π)) · ∫_{−∞}^{x} e^{−(t−μ)²/(2σ²)} dt        (16.70a)
```

则称 X 服从正态分布（X 称为正态变量），其密度函数为

```
f(t) = 1/(σ√(2π)) · e^{−(t−μ)²/(2σ²)}        (16.70b)
```

密度在 t = μ 处取得最大值，在 μ ± σ 处有拐点（图 16.5(a)）。

## 期望与方差

```
E(X) = μ        (16.71a)
D²(X) = E[(X−μ)²] = σ²        (16.71b)
```

即正态分布的期望和方差就是其两个参数。

## 独立正态变量的线性组合

若 X₁、X₂ 相互独立，分别服从参数为 (μ₁, σ₁²)、(μ₂, σ₂²) 的正态分布，则 X = k₁X₁ + k₂X₂（k₁、k₂ 为实常数）仍服从正态分布，参数为

```
μ = k₁μ₁ + k₂μ₂ ,   σ = √(k₁σ₁² + k₂σ₂²)
```

（疑点：按方差可加性 Var(k₁X₁ + k₂X₂) = k₁²σ₁² + k₂²σ₂²，σ 的表达式疑脱 k₁、k₂ 的平方上标，见 [[正态线性组合方差k1k2疑未平方]]。）

## 标准化与查表

经变量代换 τ = (t−μ)/σ，一般正态分布函数值的计算可转化为 [[标准正态分布]] 函数值的计算，概率由下式给出：

```
P(a ⩽ X ⩽ b) = Φ((b−μ)/σ) − Φ((a−μ)/σ)        (16.72)
```

具体查表流程见 [[连续分布标准化与查表流程]]。

## 在构造其他分布中的角色

16.2.4 节中其余多种分布以正态分布为构造基石：

- [[标准正态分布]] 是 μ=0、σ²=1 的特例；
- [[对数正态分布]] 是 Y = log X 服从正态分布时 X 的分布；
- [[卡方分布]] 是 n 个独立标准正态变量平方和的分布，而 [[费希尔F分布]] 与 [[学生t分布]] 又由 χ²（及标准正态）构造，见 [[卡方F与t分布的构造关系比较]]。
