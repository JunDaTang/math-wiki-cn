# 选主元法

选主元法是一种表格式算法：在线性系 y = Ax + a（式 4.174a–b，含 m 个线性型：A 为 (m,n) 矩阵，x_ν 是独立变量，y_μ 是相关变量）的格式（tableau）中，若某元素 a_ik ≠ 0（称为主元，位于主行 y_i 与主列 x_k 的交点），则可在一步选主元步骤中将 y_i 调换为独立变量、将 x_k 调换为相关变量（换轴）。源明言选主元步骤是主元法的基本组成部分，应用它可以解（例如）线性方程组和线性最优化问题。

## 换轴法则（式 4.175–4.176）

格式以行为 y₁, …, y_m、以列为 x₁, …, x_n 与常数列 1。一步换轴后，主行位置改标 x_k、主列位置改标 y_i，新元素 α_μν、α_μ 按四条法则计算：

```
(1) α_ik = 1/a_ik                                                   （4.176a，转写脱落，据算例复原）
(2) α_μk = a_μk / a_ik                     (μ = 1,…,m; μ ≠ i)        (4.176b)
(3) α_iν = −a_iν / a_ik,  α_i = −a_i/a_ik  (ν = 1,…,n; ν ≠ k)        (4.176c)
(4) α_μν = a_μν − a_μk(a_iν/a_ik) = a_μν + a_μk·α_iν,
    α_μ  = a_μ + a_μk·α_i                   (ν ≠ k, μ ≠ i)           (4.176d)
```

其中 (2) 给出换轴后 y_i 列（原 x_k 列位置）在其余各行的元素，(3) 给出新 x_k 行在其余各列与常数列的元素。为便于法则 (4)，源建议将新主行元素 α_iν 写在格式的第 m + 1 辅助行（最低行）。复原与核验见 [[findings/线性系与选主元法则]]；逐步操作流程见 [[methodology/选主元法换轴计算流程]]。

## 三类应用

1. **线性相关性判定**（4.5.1.3）：若每个 y_μ 都可换轴为某个 x_ν，则线性型组线性无关（可用于确定矩阵的秩，与 [[methodology/矩阵秩的初等变换判定流程]] 互为等价途径）；否则由终表直接读出相关关系。算例：[[findings/选主元法判别线性相关性算例]]。
2. **逆矩阵的计算**（4.5.1.4）：对 n 阶正则矩阵 A，对方程组 y = Ax 实施 n 次换轴，再按 y_i 的下标重排列、按 x_k 的下标重排行，即得 A⁻¹。算例：[[findings/选主元法求逆矩阵算例]]；此为 [[concepts/逆矩阵]] 补上具体算法（对照 [[findings/逆矩阵与除法不可定义]]）。
3. **解线性方程组**（4.5.2.2）：将 A x = a 改写为 y = Ax − a = 0（式 4.182a–b），完成换轴后代入 y = 0。两情形判据（式 4.183）：所有 y 可换轴（情形 1，线性无关）则可解；存在不可换轴的 y_σ 时 y_σ = λ₁y₁ + … + λ_m y_m + λ₀，当且仅当 λ₀ = 0 时可解，λ₀ ≠ 0 则无解（方程组中有互相矛盾的方程）。算例：[[findings/选主元法两情形与参数解算例]]。
