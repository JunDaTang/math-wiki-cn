# 正交性

在欧几里得向量空间中，若 $v\cdot w=0$，则称 $v,w$ 互相**正交**（此时按式 5.203 定义的夹角 $\alpha$ 满足 $\cos\alpha=0$）。正交性是标量积结构（见 [[concepts/欧几里得向量空间与标量积]]）诱导的核心几何关系。

## 三角函数的正交性

在傅里叶级数论（7.4.1.1，第 634 页）中，$\sin kx$、$\cos kx$ 形式的函数可看作函数空间 $C[0,2\pi]$ 的元素。在 $C[a,b]$ 的标量积（式 5.204）下：

```latex
∫_0^{2π} sin kx · sin lx dx = 0   (k ≠ l)      % 式 5.205
∫_0^{2π} cos kx · cos lx dx = 0   (k ≠ l)      % 式 5.206
∫_0^{2π} sin kx · cos lx dx = 0                % 式 5.207
```

因此函数 $\sin kx$ 与 $\cos lx$ 对每个 $k,l\in\mathbb{N}$ 是两两互相正交的（积分已复算，见 [[findings/三角函数正交性算例]]）。原书指出，这个三角函数的正交性在调和分析（7.4.1.1）中用来计算傅里叶系数。
