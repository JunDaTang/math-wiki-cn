# 多元链式法则

多元链式法则是多元复合函数求导的基本规则：当多元函数 u = f(x₁, x₂, …, xₙ) 的各中间变量 xᵢ 又是若干参数变量的函数时，u 对某一参数的导数等于 u 对各中间变量的偏导数与该中间变量对此参数的导数的乘积之和。《数学手册(原书第10版)》在 6.2.3.1（式 6.51–6.52）给出它的两种形式，并以此作为 6.2.3.2 全部隐函数求导条目的理论引擎；它是 [[concepts/链式法则]]（6.1.2 的一元版本）向多元的推广。

## 形式一：全导数（式 6.51）

设各中间变量都是同一个参数 ξ 的一元函数：u = f(x₁, …, xₙ)，xᵢ = xᵢ(ξ)，则

$$\frac{\partial u}{\partial \xi} = \frac{\partial u}{\partial x_1}\frac{\mathrm{d}x_1}{\mathrm{d}\xi} + \frac{\partial u}{\partial x_2}\frac{\mathrm{d}x_2}{\mathrm{d}\xi} + \dots + \frac{\partial u}{\partial x_n}\frac{\mathrm{d}x_n}{\mathrm{d}\xi}. \tag{6.51b}$$

注记：原书左端用偏导记号 ∂u/∂ξ，尽管此时 u 最终只是 ξ 的一元函数——记号选择，非讹误。6.2.3.2 的条目 (1)(3)(4)（一元隐函数与一元隐函数方程组）以此为求导依据。

## 形式二：偏导数（式 6.52）

设各中间变量是多个参数 ξ, η, …, τ 的多元函数：xᵢ = xᵢ(ξ, η, …, τ)，则对每个参数各有一行同构的展开式（原书以大括号联立）：

$$\frac{\partial u}{\partial \xi} = \sum_{i=1}^{n}\frac{\partial u}{\partial x_i}\frac{\partial x_i}{\partial \xi},\qquad \frac{\partial u}{\partial \eta} = \sum_{i=1}^{n}\frac{\partial u}{\partial x_i}\frac{\partial x_i}{\partial \eta},\qquad \dots,\qquad \frac{\partial u}{\partial \tau} = \sum_{i=1}^{n}\frac{\partial u}{\partial x_i}\frac{\partial x_i}{\partial \tau}. \tag{6.52b}$$

6.2.3.2 的条目 (2)(5)（多元隐函数与二元隐函数方程组）以此为求导依据。转写注记：源文件中式 6.52a 的标签孤立成行置于公式块之前，定义式与导数方程组被并入同一大括号块（标 6.52b），标签归属错乱，见 [[queries/6-2-3全节系统性转写讹误清单]]。
