# Slerp（球面线性插值）

Slerp（spherical linear interpolation，球面线性插值；书中拆解为「球面 (s) 线性 (l) 插值 (erp)」）是把线性插值从欧氏弦线推广到球面大圆的算法：给定单位四元数 p, q ∈ ℍ₁ ≅ S³ 与 t ∈ [0,1]，Slerp(p, q, t) 沿 S³ 上连接 p、q 的大圆（球面上的 [[concepts/测地线]]）取插值点，从而以恒定角速度遍历旋转。它由《数学手册（原书第10版）》4.4.3.1 作为 [[concepts/Lerp]] 的修正算法引入，是计算机绘图学中 3D 旋转插值的核心算法，也是 [[concepts/Squad]] 的构造基元。

## 公式

设 φ（0 < φ < π）为 p、q 之间的角：

```latex
Slerp(p, q, t) = p(\bar{p} q)^t = p^{1-t} q^t
               = p · sin((1-t)φ)/sinφ + q · sin(tφ)/sinφ                   (4.144)

Slerp(1, q, t) = cos(tφ) + n̲_q sin(tφ)    (p = 1, q = cosφ + n̲_q sinφ)    (4.145)

q_k := Slerp(p, q, k/n) = (1/sinφ)(sin(φ - kψ) p + sin(kψ) q),
       ψ = φ/n,   k = 0, 1, …, n                                           (4.146)
```

三种表达式的等价性由式 (4.147)–(4.149) 的推导给出（详见 [[findings/Lerp与Slerp公式组及等价性证明]]）：Q = p̄q 的标量部分 Q₀ = Sc(p̄q) = ⟨p,q⟩ = cosφ，故 Q(t) = cos(tφ) + n⃗_Q sin(tφ) = e^{t log Q} = Q^t，而 q(t) = p Q(t)。(4.146) 是等距网格特殊情形：ψ = φ/n 时 q_k 把大圆弧 n 等分。

## 最短连接条件

书中要求「选取最短连接，⟨p, q⟩ > 0 必须成立」（⟨·,·⟩ 为 ℝ⁴ 点积）。由式 (4.147)，⟨p, q⟩ = cosφ，故该条件即 φ < π/2。注意：转写文本把条件写作「−Sc(p, q) = ⟨p,q⟩ > 0」，与式 (4.147) 不一致，负号与逗号疑为转写讹误，标准条件应为 Sc(p̄q) = ⟨p, q⟩ > 0（见 [[queries/4-4-3全节转写讹误清单]]）。（分析者注：因 q 与 −q 表示同一旋转，取 ⟨p,q⟩ > 0 的代表即走较短的旋转路径。）

## 记号警示：p^{1−t}q^t

式 (4.144) 末项 p^{1−t}q^t 在非交换的 ℍ 中是记号缩并：严格形式为 p(p̄q)^t，两者仅当 p、q 交换时相等（反例见 [[findings/Lerp与Slerp公式组及等价性证明]]）。是否原书如此，待回查（[[queries/式4-144末项非交换记号是否原书如此]]）。

## 移植到旋转矩阵

4.4.3.2 把 Slerp 完全类似地移植到 [[entities/SO3]] 上（式 4.151）：R(t) = R₀(R₀⁻¹R₁)^t = R₀ exp(t log(R₀⁻¹R₁))，需 SO(3) 元素的对数（满足 e^r = R 的斜对称矩阵）。书中评注：一般而言先做四元数插值再转旋转矩阵更简单——该评注只针对插值的实现路径，不适用于 4.4.3.4 的推导（见 [[findings/旋转矩阵的Slerp插值公式]]）。

## 与 Lerp 的对比

见 [[comparisons/Lerp与Slerp比较]]：Lerp 在弦上取点、归一化后非等距；Slerp 沿大圆等角速。
