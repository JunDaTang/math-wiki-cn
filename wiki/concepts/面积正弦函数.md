# 面积正弦函数

面积正弦函数 y = Arsinh x（式 2.207）是 [[concepts/双曲正弦函数]] sinh 的反函数，记作 Arsinh x，是从 ℝ 到 ℝ 的双射：严格单调递增的奇函数，定义域 −∞ < x < ∞，值域 −∞ < y < ∞，等价表达式为 x = sinh y。它是四个面积函数中性质最「良好」者——全局双射、奇、无任何条件陷阱。

## 基本表示

$$
\operatorname{Arsinh} x = \ln \left(x + \sqrt {x ^ {2} + 1}\right) \tag{2.211}
$$

该对数表示对全部实数成立，无需分支讨论。

## 图像要素（图 2.53）

- 严格递增的奇函数，原点为对称中心与拐点；
- 原点处切线倾角 φ = π/4（转写后分析核验：导数 1/√(x²+1) 在 x = 0 处取值 1，与之一致）。

## 关系式

- 互表：Arsinh x = (sign x)·Arcosh √(x²+1) = Artanh(x/√(x²+1)) = Arcoth(√(x²+1)/x)，其中末项在 x = 0 处失效，见 [[findings/四种面积函数的互表关系]]。
- 和差：Arsinh x ± Arsinh y = Arsinh(x√(1+y²) ± y√(1+x²))（式 2.219），无分支问题。
- 奇性：Arsinh(−x) = −Arsinh x（式 2.222）。
