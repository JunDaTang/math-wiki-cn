# 可去间断点

可去间断点是一类可以通过补充或修改单点定义而消除的间断点：设 $\lim_{x\to a}f(x)$ 存在，即 $f(a-0)=f(a+0)$，但函数在 $x=a$ 处或者没有定义，或者 $f(a)\neq\lim_{x\to a}f(x)$（图 2.9 中的点 D 即此型）。

## 可去性

因为只需定义 $f(a)=\lim_{x\to a}f(x)$——在曲线上添加一个点，或移动原有点的位置——函数即在该点连续，故称“可去”。

## 与未定式的联系

当 $x=a$ 时函数呈[[concepts/未定式]]，若利用[[concepts/洛必达法则]]或其他方法判断其具有有限极限，则 $x=a$ 为可去间断点。这使未定式求极限成为识别可去间断点的标准工具。

## 典型例

当 $x\to0$ 时 $f(x)=\frac{\sqrt{1+x}-1}{x}$ 是 $\frac00$ 型未定式，但 $\lim_{x\to0}f(x)=\frac12$；函数

```
f(x) = { (√(1+x) − 1)/x,   x ≠ 0
       { 1/2,                x = 0
```

是连续函数。

## 在有理函数中的判据

对有理函数 $\frac{P(x)}{Q(x)}$：若 $P(a)=Q(a)=0$ 且 $a$ 作为分子根的重数不低于其作为分母根的重数（参见 [[concepts/重根]]），则该间断点是可去间断点而非[[concepts/极点]]。
