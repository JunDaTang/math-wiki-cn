# 可公度性

可公度性描述两个数能否被同一个量来量度：若一个表示式中的两个数 a 和 b 分别是第三个数 c 的整数倍（a = mc，b = nc，m、n ∈ ℤ），则称它们为可公度的；否则称为不可公度的。它是《数学手册(原书第10版)》1.1.1 节的独立子节（1.1.1.5）。

## 判据

```latex
由 a = mc, b = nc (m, n \in \mathbb{Z}) 可得
\frac{a}{b} = x  (x 是有理数)   (1.7)
```

严谨性注记：手册 (1.7) 仅单向陈述（可公度 ⟹ 比值为有理数）；各例子实际使用其逆否命题（比为无理数 ⟹ 不可公度），完整的等价判据（比值为有理数 ⟹ 可公度）未显式给出。

## 例子

- ■A：一个正方形边长与其对角线长是不可公度的，因为它们的比是无理数 √2。
- ■B：黄金分割线段是不可公度的，因为它们的比包含有无理数 √5（见 [[concepts/黄金分割]]、第 260 页 3.5.2.3 前向引用）；因此，一个正五边形的边长与其对角线长是不可公度的（第 182 页 3.1.5.3 前向引用）。

详见 [[findings/正方形对角线与黄金分割线段不可公度]]。

## 历史注记（弱证据）

手册称“现在认为”梅塔蓬图姆的希帕索斯（Hippasos of Metapontum，公元前 450 年）正是通过正五边形（黄金分割）这一例子发现了无理数。该归因带“现在认为”的保留限定，且传统叙事多与 √2（正方形对角线）相连——手册本节例 A 恰以正方形对角线作不可公度算例，历史归因却附于例 B。两说不构成数学矛盾，但归因应保持保留态度（见 [[findings/正方形对角线与黄金分割线段不可公度]] 的证据分层）。
