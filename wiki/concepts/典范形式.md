# 典范形式

**典范形式**（canonical form，手册亦称“正规形式”）是 [[二阶线性偏微分方程]] 经自变量变换 ξ = φ(x,y)、η = ψ(x,y)（式 9.84a）约化后得到的标准形状，其二阶主部只含最少的项。按判别式符号分三种（式 9.84b–d）：

```
u_ξξ − u_ηη + … = 0   （δ < 0，双曲型）
u_ηη + … = 0          （δ = 0，抛物型）
u_ξξ + u_ηη + … = 0   （δ > 0，椭圆型）
```

（省略号代表不含未知函数二阶偏导数的项。）

## 约化途径

- **双曲型**：取两族 [[偏微分方程的特征|特征]] 作坐标线 ξ₁ = φ(x,y)、η₁ = ψ(x,y)（φ、ψ 为常数即特征方程），得第一典范形式 u_{ξ₁η₁} + … = 0（式 9.84e）；再经线性代换 ξ = ξ₁ + η₁、η = ξ₁ − η₁（式 9.84f）化为 9.84b。两种典范形式互通。
- **抛物型**：唯一一族特征取为 ξ = 常数；η 取任一不依赖于 ξ 的函数，得 9.84c。
- **椭圆型**：当系数 A, B, C 解析时，特征定义两族复共轭曲线 φ(x,y) = 常数、ψ(x,y) = 常数；作代换 ξ = φ + ψ、η = i(φ − ψ) 得 9.84d。

## 常系数方程的简单形式

常系数方程先经线性齐次变换化为 Σ κᵢ ∂²u/∂xᵢ² + … = 0（κᵢ ∈ {−1, 0, +1}），再作消一阶导代换 u = v exp(−½ Σ (b_k/κ_k) x_k)（式 9.88，对 κ_k ≠ 0 求和），得到：

- 椭圆型：Δv + kv = g（式 9.89）
- 双曲型：v_tt − Δv + kv = g（式 9.90）

消一阶导机制可用单变量模型核验：κv″ + bv′ = 0 经代换化为 v″ − (b²/4κ²)v = 0，一阶项确被消去 ✓。

[[电报方程]] 是典范形式约化的完整算例：经未知函数代换与自变量代换化为 z_{ξη} − z/4 = 0（双曲第一典范形式）。操作流程见 [[二阶偏微分方程分类与典范形式约化流程]]；转录复算见 [[findings/式9-82至9-85分类特征与典范形式转录复算]]、[[findings/式9-86至9-90多变量与常系数约化复算]]。
