# 变量代换

**变量代换**是指在含自变量、函数及其各阶（偏）导数的微分表达式中，用新变量替换原有的自变量或因变量，并把表达式中的各阶导数系统改写为新变量之下导数的运算。《数学手册(原书第10版)》6.2.4 给出其完整操作规则：一元情形按代换对象分四种情况（式 6.59–6.62），二元情形经 2×2 线性方程组与算子递推完成（式 6.65–6.66）。

## 一元情形的四种情况

设 y = f(x)，F = F(x, y, dy/dx, d²y/dx², d³y/dx³, …)（式 6.58a–b）。

1. **情况 1a（自变量的显式代换）**：x = φ(t)（式 6.59a），导数按式 6.59b–c 变换。这正是反函数观点下的求导，与 6.1.3 的 [[concepts/反函数的高阶导数]]（式 6.24–6.25）同源；要求 φ′(t) ≠ 0。
2. **情况 1b（自变量的隐式代换）**：x 与 t 的关系由 Φ(x,t) = 0（式 6.60）给出，仍用式 6.59，但 φ′, φ″, φ‴ 须按隐函数法则计算（见 [[concepts/隐函数求导]]）；式 6.58b 中残留的 x 借式 6.60 消去。
3. **情况 2（因变量的代换）**：y = φ(u)（式 6.61a），导数按式 6.61b–c 变换——即逐阶展开的 [[concepts/链式法则]]，三阶系数为 1, 3, 1。
4. **情况 3（自变量与因变量同时代换）**：x = φ(t,u), y = ψ(t,u)（式 6.62a），一阶导数为 A/B，二阶为 (BA′ − AB′)/B³，其中 A、B 为沿曲线的全导数（式 6.62e–f）——是 [[concepts/参数式求导]] 带辅助变量 u(t) 的推广。

四种情况的逐项对照见 [[comparisons/四种变量代换情况比较]]。源文情况编号存在断裂（1a/1b 之后两个情况无编号），复原讨论见 [[queries/情况2与情况3编号如何复原]]。

## 坐标变换作为特例

当新变量取为另一坐标系（如极坐标 ρ, φ）时，变量代换即坐标变换：曲线导数的变换（式 6.63）与拉普拉斯算子的变换（式 6.67）为两个实例，见 [[concepts/坐标变换]] 与 [[concepts/极坐标]]。

## 证据与边界

- 本页公式均出自 [[sources/10-数学手册原书第10版--20-624-微分表达式中的变量代换与坐标变换--7e64k0]]，并经复算核验（[[findings/一元变量代换四情况公式-式6-59至6-62]]、[[findings/二元代换偏导数方程组与系数-式6-65]]、[[findings/二阶偏导数算子递推-式6-66]]）。
- 式 6.59c 存在一处公式级讹误（末项因子应为 dy/dt），引用时须修正，见 [[findings/式6-59c末项因子讹误复算判定]]。
- 源文对含两个以上变量的情形仅有「可得到类似的代换公式」的断言，无具体公式与证明。
- 正则性条件（φ′ ≠ 0、B ≠ 0、J ≠ 0、隐函数定理条件等）为复算识别，源文未声明。
