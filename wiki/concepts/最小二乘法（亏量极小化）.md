# 最小二乘法（亏量极小化）

本概念是边值问题逼近系数确定四原则之一：依赖系数的积分

```latex
(19.124)  F(a_1, a_2, \dots, a_n) = \int_a^b \varepsilon^2(x; a_1, a_2, \dots, a_n)\, dx
```

应该最小；必要条件

```latex
(19.125)  \frac{\partial F}{\partial a_i} = 0   (i = 1, 2, \dots, n)
```

给出系数 a_i 的线性方程组。其中 ε 为 [[concepts/亏量（残量）]] (19.122)。命名辨析：此处特指边值问题函数逼近语境下的亏量平方积分极小化，区别于一般数据拟合意义的最小二乘法。与其他三原则的比较见 [[comparisons/逼近系数确定四原则比较]]。
