# 里茨方法

**里茨方法**（Ritz method）是变分问题数值解的直接法（direct method）中最流行的、也许是最古老的方法（10.5）：**从变分问题直接产生**，不利用欧拉微分方程，属于用来获得微分方程逼近解的所谓逼近方法（参见 19.4.2.2 与 19.5.2，第19章未入库）。

## 算例（10.52a–j）：数值解等周型问题

数值地解

$$\int_0^1 y'^2(x)\,\mathrm{d}x = \text{极值!} \quad (10.52a)$$

约束与边界为

$$\int_0^1 y^2(x)\,\mathrm{d}x = 1, \qquad y(0) = y(1) = 0 \quad (10.52b)$$

按[[附加条件变分问题与拉格朗日乘子|拉格朗日乘子法]]（10.3.3）化为无约束问题

$$I[y] = \int_0^1 [y'^2(x) - \lambda y^2(x)]\,\mathrm{d}x = \text{极值!} \quad (10.52c)$$

起始逼近取

$$y(x) = a_1 x(x-1) + a_2 x^2(x-1) \quad (10.52d)$$

（两个逼近函数线性无关且满足边界条件）。代入 (10.52c) 得

$$I(a_1, a_2) = \frac{1}{3}a_1^2 + \frac{2}{15}a_2^2 + \frac{1}{3}a_1 a_2 - \lambda\left(\frac{1}{30}a_1^2 + \frac{1}{105}a_2^2 + \frac{1}{30}a_1 a_2\right) \quad (10.52e)$$

必要条件 ∂I/∂a₁ = ∂I/∂a₂ = 0 给出齐次线性方程组 (10.52f)，其系数矩阵行列式为零导出

$$\lambda^2 - 52\lambda + 420 = 0, \quad \text{即} \quad \lambda_1 = 10,\ \lambda_2 = 42 \quad (10.52g)$$

对 λ = λ₁ = 10 得 a₂ = 0、a₁ 任意，正规化（∫₀¹y²dx = 1）后

$$y = 5.48\,x(x-1) \quad (10.52h)$$

（a₁ = √30 ≈ 5.48）。

## 与精确解的对照

相应的欧拉微分方程边值问题为

$$y'' + \lambda y = 0, \qquad y(0) = y(1) = 0 \quad (10.52i)$$

本征值 λ_k = k²π²、解 y_k = c_k sin kπx；k = 1 时 λ₁ = π² ≈ 9.87，正规化解为

$$y = \sqrt{2}\sin\pi x \quad (10.52j)$$

与逼近解 (10.52h) 非常接近。里茨值 10 大于精确本征值 π²，符合里茨型逼近给出本征值上界的性质。全链复算逐项吻合，见 [[findings/第10章里茨方法算例全链闭式复算]]。

## 在数值解谱系中的位置

10.5 将变分数值解分为两条路线：解欧拉微分方程并使解满足边界条件（通常数值解边值问题，参见 19.5 与 20.3.4），与直接法。里茨方法是直接法的代表。手册并称在当今计算机和科学的水平下，把**有限元方法**（finite element method, FEM）应用于变分问题的数值解是第一位的（其基本想法见 19.5.3：利用微分方程和变分方程之间的相似性，例如欧拉微分方程，或者 (19.146a)、(19.146b) 的双线性型——此处正文一句文气断裂，疑有脱讹）；此外，作为对非线性最优化问题的有效数值方法，梯度方法也被用于变分问题的数值解。
