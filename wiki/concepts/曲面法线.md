# 曲面法线

曲面法线是过曲面上一点且垂直于该点 [[切平面]] 的直线（图 3.247）。切平面的两个张成向量 $\vec r_u$ 与 $\vec r_v$ 的向量积 $\vec r_u\times\vec r_v$ 给出法线方向，其单位向量

$$\vec N_0=\frac{\vec r_u\times\vec r_v}{|\vec r_u\times\vec r_v|}\tag{3.549b}$$

称为法向量。其指向取决于参数 $(u,v)$ 中哪一个变量作为第一个坐标——交换 u、v 次序会翻转法向量方向（[[向量积]] 的反交换性）。

四种方程表示下的法线方程（表 3.29）：

| 方程类型 | 曲面法线 |
|---|---|
| 隐式 (3.544) | $\dfrac{X-x}{F_x}=\dfrac{Y-y}{F_y}=\dfrac{Z-z}{F_z}$ |
| 显式 (3.545) | $\dfrac{X-x}{p}=\dfrac{Y-y}{q}=\dfrac{Z-z}{-1}$ |
| 参数 (3.546) | $\dfrac{X-x}{\begin{vmatrix}y_u&z_u\\y_v&z_v\end{vmatrix}}=\dfrac{Y-y}{\begin{vmatrix}z_u&x_u\\z_v&x_v\end{vmatrix}}=\dfrac{Z-z}{\begin{vmatrix}x_u&y_u\\x_v&y_v\end{vmatrix}}$ |
| 向量 (3.547) | $\vec R=\vec r+\lambda(\vec r_1\times\vec r_2)$ 或 $\vec R=\vec r+\lambda\vec N$ |

球面算例（式 3.550b,d）：$X/x=Y/y=Z/z$；参数形式 $X/\cos u\sin v=Y/\sin u\sin v=Z/\cos v$。已独立核验与隐式形式一致。

曲面法线是 [[法截线]]、[[默尼耶定理]]、[[第二基本形式]]（系数定义中的单位法向量，记号疑点见 [[式3-563c的向量R是否应为单位法向量N]]）与 [[测地线]]（主法线与曲面法线同向）的定义支点。
