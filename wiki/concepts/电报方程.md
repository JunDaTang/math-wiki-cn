# 电报方程

**电报方程**（报务员方程）是描述导线中电流的二阶线性双曲型偏微分方程：

$$a\frac{\partial^{2} u}{\partial t^{2}} + 2b\frac{\partial u}{\partial t} + cu = \frac{\partial^{2} u}{\partial x^{2}} \tag{9.98a}$$

（a > 0，b、c 为常数。）它是 [[弦振动方程]] 加入阻尼项 2b u_t 与恢复项 cu 的推广。

## 约化链（手册算例，全部复算通过）

1. **消阻尼**：u = z e^{−(b/a)t} 化为 z_tt = m²z_xx + n²z，其中 m² = 1/a、n² = (b² − ac)/a²（式 9.98b）✓
2. **化典范形式**：ξ = (n/m)(mt + x)、η = (n/m)(mt − x) 得双曲第一典范形式 z_{ξη} − z/4 = 0（式 9.98d）✓
3. **求黎曼函数**：设 w = (ξ−ξ₀)(η−η₀)、v = f(w)，得 w f″ + f′ − f/4 = 0；代换 w = α² 化为 f″ + (1/α)f′ − f = 0（式 9.98g），解为

$$v = I_0\!\left[\sqrt{(\xi-\xi_0)(\eta-\eta_0)}\right] \tag{9.98h}$$

4. **代入黎曼公式**回到原变量得解 (9.98j)；其中 I₀/I₁ 的宗量 (n/m)√(m²t² − (s−x)²) 与 (ξ−ξ₀)(η−η₀) 的变量换算一致 ✓，且与经典电报方程解形式相符。

## 两点警示

- **称谓**：式 (9.98g) 实为**零阶变形贝塞尔方程**（解为 I₀），原文称其为“零阶贝塞尔微分方程”，与 [[贝塞尔微分方程]] 页的称谓需辨析；I₀/I₁ 见 [[变形贝塞尔函数与麦克唐纳函数]]。
- **隐含假设**：n² = (b² − ac)/a² 可为负（ac > b² 时），此时代换与 I₀ 失效（应换 J₀），原文未讨论，见 [[queries/电报方程n平方为负情形为何未讨论]]。
