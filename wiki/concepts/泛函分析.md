# 泛函分析

泛函分析（Functional Analysis）是数学的一个分支，以无穷维空间及其上定义的线性算子与线性泛函为研究对象，典型的空间层级由距离空间、赋范空间而希尔伯特空间逐级加强。此句为独立可查证的学科背景常识，仅作页面定位之用；本页所据源为章节目录页，只载章题与小节标题，并未给出该学科的任何定义文本。

## 在《数学手册(原书第10版)》中的位置

「泛函分析」为该手册第12章章题（母书实体见 [[entities/数学手册原书第10版]]），下分九个小节，编号 12.1–12.9 连续无跳号：

12.1 向量空间；12.2 距离空间；12.3 赋范空间；12.4 希尔伯特空间；12.5 连续线性算子和泛函；12.6 赋范空间中的伴随算子；12.7 紧集和紧算子；12.8 非线性算子；12.9 测度和勒贝格积分。

目录页源见 [[sources/10-数学手册原书第10版--9-第12章-泛函分析--5oxql2]]。小节排序呈「代数结构 → 距离 → 范数 → 内积 → 算子与泛函 → 伴随 → 紧性 → 非线性 → 测度积分」的递进骨架；其中 12.9 将测度与勒贝格积分纳入本章，系本手册的编排特征（是否与 Taschenbuch der Mathematik 原版一致属待验问题）。
