# 表示的直和

**由维数 $n_1$ 与 $n_2$ 的两个表示 $D^{(1)}(G)$、$D^{(2)}(G)$ 可以复合产生维数 $n = n_1 + n_2$ 的新表示：表示矩阵的直和（分块对角化）**（式 5.107）：

$$D(a) = D^{(1)} \oplus D^{(2)}(a) = \begin{pmatrix} D^{(1)} & 0 \\ 0 & D^{(2)} \end{pmatrix}.$$

分块对角形蕴涵表示空间 $V_n$ 是两个**不变子空间**（见 [[concepts/不变子空间]]）的直和（式 5.108）：

$$V_n = V_{n_1} \oplus V_{n_2}, \quad n = n_1 + n_2.$$

## 特征的可加性（式 5.110）

直和表示的特征等于各分量特征之和：

$$\chi(a) = \chi^{(1)}(a) + \chi^{(2)}(a),$$

这直接由分块对角矩阵的迹等于各块迹之和得出（见 [[findings/表示直和与特征可加性]]）。与 [[concepts/表示的张量积]] 的特征可乘性（式 5.113）对照见 [[comparisons/表示直和与直积比较]]；完全可约表示的分块对角形式见 [[concepts/可约与不可约表示]]（式 5.116）。
