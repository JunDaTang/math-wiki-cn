# 欧几里得向量空间与标量积

为了能够在抽象向量空间中应用长度、角度、正交性这样的概念，原书引进欧几里得向量空间。设 $V$ 是实向量空间，$\varphi:V\times V\to\mathbb{R}$ 是具有下列性质的映射（代替 $\varphi(v,w)$ 写作 $v\cdot w$；对所有 $u,v,w\in V$ 及 $r\in\mathbb{R}$）：

```latex
(S1) v·w = w·v                              % 式 5.198
(S2) (u+v)·w = u·w + v·w                    % 式 5.199
(S3) r(v·w) = (rv)·w = v·(rw)               % 式 5.200
(S4) v·v > 0 当且仅当 v ≠ 0                 % 式 5.201
```

那么 $\varphi$ 称为 $V$ 上的**标量积**；如果 $V$ 上定义有标量积，则 $V$ 称为**欧几里得向量空间**。这些性质也用来在更一般的空间上定义具有类似性质的标量积（原书指向 12.4.1.1，第 879 页，未入库）。

## 欧几里得范数与夹角

```latex
‖v‖ = √(v·v)                                 % 式 5.202（欧几里得范数，长度）
cos α = (v·w)/(‖v‖·‖w‖)                     % 式 5.203（v,w 间的夹角）
```

若 $v\cdot w=0$，则称 $v,w$ 互相**正交**（见 [[concepts/正交性]]）。

## 函数空间上的标量积

在 $C[a,b]$ 中，公式 $f\cdot g=\int_a^b f(x)g(x)\,dx$（式 5.204）定义一个标量积，见 [[entities/c-a-b-连续函数空间]]。
