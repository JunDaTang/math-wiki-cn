# 正比例函数

正比例函数是线性函数 $y = ax + b$ 在 b = 0 时的特例：

$$y = a x \tag{2.40}$$

其图像是一条过原点的直线（《数学手册(原书第10版)》2.3.1，图 2.11(b)）。函数值与自变量成固定比例 a，a 的符号决定走向：a>0 单调递增，a<0 单调递减。

正比例函数同时是 [[n次抛物线]] $y = ax^n$ 在 n = 1 的情形（此时原点既非极值点也非拐点，「奇 n 原点为拐点」的规律退化，见 [[奇次多项式拐点规律在n等于1时是否失效]]），也是 [[线性函数]] 与 [[多项式]] 家族的最简成员。
