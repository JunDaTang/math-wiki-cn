# 广义模糊推理格式

**广义模糊推理格式**是 [[concepts/模糊推理]] 中多前提法则的一般形式：法则的前提由多个模糊集 A₁, …, Aₙ（可分属不同论域 X₁, …, Xₙ）经 AND（和）连接，结论为模糊集 B。

## 法则形式（逐字保留）

```
IF（若 A₁ 和 A₂ 和 A₃ ⋯ 和 Aₙ）THEN（则）B
其中 Aᵢ: μᵢ: Xᵢ → [0,1]  (i = 1, 2, …, n)
```

结论 B 的隶属函数 μ: Y → [0,1]（转录「结论 的隶属函数」脱 B；即式 5.381b 中的 μ_B）由一个 (n+1) 元关系刻画（转录作「(n+1)－值关系」，「值」疑应为「元」）：

```
R: X₁ × X₂ × ⋯ × Xₙ × Y → [0,1]        (5.381a)
```

对于具有清晰值 x₁′, x₂′, …, xₙ′ 的确实输入，法则 (5.381a) 通过下式定义确实的模糊输出：

```
μ_{B′}(y) = μ_R(x₁′, x₂′, …, xₙ′, y)
          = min{μ₁(x₁′), μ₂(x₂′), …, μₙ(xₙ′), μ_B(y)}   (y ∈ Y)   (5.381b)
```

## 满足等级

```
min{μ₁(x₁′), μ₂(x₂′), ⋯, μₙ(xₙ′)}
```

称为**法则的满足等级**，即法则被（当前输入）满足的程度。

转录疑点：紧随其后的「并且量 min{μ₁(x₁′), μ₂(x₂′), ⋯, μₙ(xₙ′)} 表示模糊值输入量」与满足等级为**同一公式重复出现**，疑第二处应为不同内容（涉及模糊值输入情形的表述）或为 OCR 重复，见 [[queries/满足等级注释两个min公式是否重复]]。

## 结构说明

- 式 5.381b 以 **min** 同时聚合各前提的隶属度与结论隶属函数 μ_B(y)——min 即 AND（和）所用的 Zadeh 算子，与 5.9.2 的 [[findings/zadeh算子与and-or-not对应]]、[[concepts/t-范数]] 一致。
- 输入为**清晰值** x₁′, …, xₙ′，输出为**模糊**集 B′——「清晰输入 → 模糊输出」的方向。
- 单前提情形即 [[concepts/模糊蕴涵]] 的 IF THEN 法则。
