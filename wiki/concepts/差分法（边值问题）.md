# 差分法（边值问题）

将边值问题 (19.118) 的区间 [a,b] 以等距节点 x_ν = x₀ + νh（ν = 0,…,n；x₀ = a, x_n = b）等分，在内部插值点以有限差分代替 (19.119) 中的导数值：

```latex
(19.120a)  y'(x_\nu) \approx y'_\nu = \frac{y_{\nu+1} - y_{\nu-1}}{2h}
(19.120b)  y''(x_\nu) \approx y''_\nu = \frac{y_{\nu+1} - 2y_\nu + y_{\nu-1}}{h^2}
```

两个逼近均有 O(h²) 阶误差。考虑到边界条件 y₀ = α、y_n = β，得到关于 n−1 个内部插值 y_ν ≈ y(x_ν) 的 n−1 个线性方程；边界条件包含导数时也必须由有限差分代替。微分方程组的特征值问题（参见 9.1.3.2，未入库）可类似处理，得到矩阵特征值问题（参见 4.6，未入库）。

**特征值算例**（复算通过）：y″ + λ²y = 0，y(0) = y(1) = 0，三个内点 h = 1/4 ⟹ 三对角矩阵（对角元 −2 + λ²/16）；λ₁² = 9.37、λ₂² = 32、λ₃² = 54.63。源文自身告警：这些特征值中只有最小的一个接近相应的真值 9.87（π²），高阶离散特征值偏差甚大（32 对 39.48、54.63 对 88.83）。

**精度改进三途径**：(1) 减小步长 h；(2) 应用导数的高阶逼近；(3) 应用多步法（参见 19.4.1.3）。非线性边值问题的差分法导致非线性方程组（参见 19.2.2，未入库）。流程见 [[methodology/边值问题差分离散化流程]]；与其他两类边值方法比较见 [[comparisons/边值问题三类方法比较]]。
