# 变分法的欧拉微分方程

**变分法的欧拉微分方程**（Euler differential equation of the calculus of variations）是变分问题解的必要条件，为手册第10章的核心定理族。对简单变分问题（式 10.11），其基本形式为

$$\frac{\partial F}{\partial y} - \frac{\mathrm{d}}{\mathrm{d}x}\left(\frac{\partial F}{\partial y'}\right) = 0 \quad (10.19)$$

当 $F_{y'y'} \neq 0$ 时这是 y 的二阶常微分方程，展开形式为

$$\frac{\partial F}{\partial y} - \frac{\partial^2 F}{\partial x\,\partial y'} - \frac{\partial^2 F}{\partial y\,\partial y'}y' - \frac{\partial^2 F}{\partial y'^2}y'' = 0 \quad (10.20)$$

## 推导链（10.3.2）

在[[泛函与极值曲线|极值曲线]] y₀(x) 上引入辅助曲线或可比较曲线（comparable curve）

$$y(x) = y_0(x) + \varepsilon\,\eta(x) \quad (10.13)$$

其中 η(a) = η(b) = 0。代入 (10.11) 得依赖 ε 的函数 I(ε)（10.14）；泛函极值化归为必要条件 dI/dε = 0（ε = 0 时，式 10.15）。借助泰勒展开（7.3.3.3）得 (10.16)–(10.17)，分部积分并利用 η 的边界条件得

$$\int_a^b \eta\left(\frac{\partial F}{\partial y} - \frac{\mathrm{d}}{\mathrm{d}x}\frac{\partial F}{\partial y'}\right)\mathrm{d}x = 0 \quad (10.18)$$

由 η 的任意性与连续性假设即得 (10.19)。同一化归手续贯穿高阶、多函数、多自变量与参数诸情形。

## 特例（10.3.2）

- **F = F(y′)**（不显含 y）：(10.21b) d/dx F_{y′} = 0，积分一次即 F_{y′} = c。算例 (10.23)：最短连线 ⟹ y″ = 0，即直线。
- **F = F(y, y′)**（不显含 x）：(10.22c) F − y′·F_{y′} = c。此即通称的 Beltrami 型恒等式，**手册未命名**。算例 (10.24)：旋转面最小面积 ⟹ 悬链线 y = c₁cosh(x/c₁ + c₂)（参见 2.15.1 悬链线）。

## 诸推广形式

（完整谱系与复算结论见 [[sources/10-数学手册原书第10版--8-第10章-变分法--1dc33ev]] 与 [[findings/第10章诸算例闭式复算通过清单]]）

- **积分型附加条件**（10.3.3，拉格朗日）：对 H = F + λG 有 H_y − d/dx H_{y′} = 0（10.28），详见[[附加条件变分问题与拉格朗日乘子]]。
- **含高阶导数**（10.3.4）：F_y − d/dx F_{y′} + d²/dx² F_{y″} = 0（10.31，四阶方程，通解含 4 个任意常数——正文「包含 个任意常数」脱「4」）；n 阶通式 $\sum_k (-1)^k \frac{\mathrm{d}^k}{\mathrm{d}x^k}F_{y^{(k)}} = 0$（10.33）。算例 (10.32)：F = y″² − αy′² − βy² ⟹ y⁽⁴⁾ + αy″ − βy = 0。
- **数个未知函数**（10.3.5）：F_{yᵢ} − d/dx F_{yᵢ′} = 0（i = 1..n，式 10.37），共 n 个方程的方程组。
- **参数表示**（10.3.6）：F_x − d/dt F_ẋ = 0 与 F_y − d/dt F_ẏ = 0（10.41），两方程不独立，等价于魏尔斯特拉斯形式，详见[[参数表示变分问题与一次正齐次函数]]。
- **多个自变量**（10.4）：二重积分为 F_u − ∂/∂x F_{u_x} − ∂/∂y F_{u_y} = 0（10.48）；含二阶偏导数时为 (10.50)；n 个自变量通式为 F_u − Σₖ ∂/∂xₖ F_{u_{xₖ}} = 0（10.51）。代表算例为[[狄利克雷变分问题]] ⟹ 拉普拉斯方程 Δu = 0（10.49f）。
