# 公式操作

公式操作是计算机代数系统两大基本应用领域之一，指**在最广泛意义上的变换数学表达式**：简化表达式或将其变换成某种有用的形式，用代数表达式表示方程或方程组的解，将函数微分或确定不定积分，解微分方程，构造无穷级数，等等（《数学手册（原书第10版）》20.1.1.3）。其对象域由“封闭形式”界定——CAS 形式地处理那些能以封闭形式来处理的数学表达式。

## 范例：二次方程的符号求解（式 20.2）

对带实参数的二次方程 x² + ax + b = 0（a, b ∈ ℝ），在 Mathematica 中键入 `Solve[x² + a x + b == 0, x]`，按下 ENTER / SHIFT+ENTER 后，系统将这一行回显替换为 `In[1]:= …` 并启动求值，答案显示在新行：

`Out[1] = {{x -> 1/2 (-a - √(a² - 4b))}, {x -> 1/2 (-a + √(a² - 4b))}}`

Mathematica 将两个解表示成由两个子列表组成的列表形式，每条解为一条替换规则 `x -> …`。该输出与标准求根公式逐项一致（见 [[findings/式20-1至20-3c符号与数值求解算例转录复算]]）。

## 符号输出的数值求值风险（wiki 观察，非源文主张）

式 (20.2d) 给出的根 1/2(−a−√(a²−4b)) 正是 [[methodology/二次方程稳定求根流程]] 要规避的相消求值形式：当 4b ≪ a²（两根相近）时，按此符号表达式直接做浮点代入会因 a 与 √(a²−4b) 相减而触发 [[concepts/减法相消]]。20.1 自己引用的 19.8.2 数值警示与本符号示例之间的这一张力，书中未点破，见 [[queries/符号解浮点代入的相消风险]]。
