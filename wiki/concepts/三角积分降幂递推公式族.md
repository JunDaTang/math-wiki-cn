# 三角积分降幂递推公式族

三角积分降幂递推公式族是《数学手册(原书第10版)》21.7.3 中把高幂次三角积分化为低幂次的一组递推公式，是三角积分表的结构主干：当被积函数幂次超出初等直接可积范围时，表内一律以「边界项 + 低二次幂积分」的递推形式给出，并常提供降低不同指数的多个平行支路。

## 单函数幂次的代表形式

```latex
% 278（正弦，降 n）
\int \sin^{n} ax\,dx = -\frac{\sin^{n-1} ax\cos ax}{na} + \frac{n-1}{n}\int \sin^{n-2} ax\,dx
% 317（余弦）
\int \cos^{n} ax\,dx = \frac{\cos^{n-1} ax\sin ax}{na} + \frac{n-1}{n}\int \cos^{n-2} ax\,dx
% 289 / 328（倒数幂）
\int \frac{dx}{\sin^{n} ax} = -\frac{1}{a(n-1)}\frac{\cos ax}{\sin^{n-1} ax} + \frac{n-2}{n-1}\int \frac{dx}{\sin^{n-2} ax}
\int \frac{dx}{\cos^{n} ax} = \frac{1}{a(n-1)}\frac{\sin ax}{\cos^{n-1} ax} + \frac{n-2}{n-1}\int \frac{dx}{\cos^{n-2} ax}
```

其他成员：358（sinⁿcosᵐ 双支）、367–369（1/(sinⁿcosᵐ) 三条）、380（sinⁿ/cosᵐ 三支）、391（cosⁿ/sinᵐ 三支）、282/321（xⁿ·sin/cos 互换）、285/324（sin/cos 除 xⁿ）、292/331、375/386、412/421（tanⁿ/cotⁿ）等。

## 三支式的结构（以 380 订正后为例）

三支分别实现「只降 m」「只降 n」「n 与 m 同降」：

```latex
\int \frac{\sin^{n} ax}{\cos^{m} ax}\,dx =
\frac{\sin^{n+1} ax}{a(m-1)\cos^{m-1} ax} - \frac{n-m+2}{m-1}\int\frac{\sin^{n} ax}{\cos^{m-2} ax}\,dx \quad (m\neq 1)
= -\frac{\sin^{n-1} ax}{a(n-m)\cos^{m-1} ax} + \frac{n-1}{n-m}\int\frac{\sin^{n-2} ax}{\cos^{m} ax}\,dx \quad (m\neq n)
= \frac{\sin^{n-1} ax}{a(m-1)\cos^{m-1} ax} - \frac{n-1}{m-1}\int\frac{\sin^{n-2} ax}{\cos^{m-2} ax}\,dx \quad (m\neq 1)
```

## 校勘意义

本族是 21.7.3 五处数学性讹误中三处（~369、380、~391）的所在：递推式系数与指数密集，是转写最易出错的位置。检验方式为对右端整体求导，利用 sin²+cos²=1 化简后应恰还原被积函数（见 [[methodology/逐项求导复算法]] 与各专项复算页）。
