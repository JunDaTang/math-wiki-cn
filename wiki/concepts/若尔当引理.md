# 若尔当引理

若尔当引理（Jordan lemma）断言：满足一定条件的函数 f 沿半径趋于无穷的大圆弧（半圆或弧段）上、带指数因子的积分趋于零。它用于计算无穷区间上的实反常积分时免去对闭合弧段的反复估计，名称来源于数学家 Jordan（本来源仅以其命名，无生平内容）。源文仅陈述而无证明；其本质是 [[concepts/复积分的绝对值估计]] 对指数因子衰减性的精细应用。

## 陈述（14.4.3.1，式 14.57a–c）

C_R 为复平面上半平面中以原点为中心、半径为 R 的半圆弧。若尔当引理区分五种情形（逐情形比较见 [[comparisons/若尔当引理五种情形比较]]）：

a) **α > 0**：若在上半平面以及实轴上，当 |z|→∞ 时 f(z) 一致趋于零，则

$$\int_{C_R} f(z)\,e^{i\alpha z}\,\mathrm{d}z \to 0 \quad (R\to\infty) \tag{14.57b}$$

b) **α = 0**：若 |z|→∞ 时表达式 zf(z) 一致趋于零，则 (14.57b) 对 α = 0 亦成立。

c) **α < 0**：若半圆 C_R 取在实轴之下，则相应于 (14.57b) 的陈述对 α < 0 亦成立。

d) **弧段替代**：若用弧段代替完整的半圆，陈述 (14.57b) 亦成立。（源文对情形 d) 的适用范围表述较宽泛，未指明弧段位置与条件细节。）

e) **左/右半平面情形**：C_R* 是左半平面中的半圆或一个弧段而 α > 0，或在右半平面而 α < 0，则对于形如

$$\int_{C_R^*} f(z)\,e^{\alpha z}\,\mathrm{d}z \to 0 \quad (R\to\infty) \tag{14.57c}$$

的积分，相应于 (14.57b) 的陈述成立。

注：源文 (14.57c) 之后紧随一整段 ν 向量符号串，为大规模转写噪声，无数学内容（见 [[queries/14-4全节系统性转写讹误清单]]，可类比 [[queries/式13-99b波浪号V疑为转写噪声]]）。

## 机理注记（标准背景，源文未证明）

|e^{iαz}| = e^{−αy}：α > 0 时上半平面（y > 0）衰减，α < 0 时下半平面衰减；|e^{αz}| = e^{αx}：α > 0 时左半平面（x < 0）衰减。五种情形的差别只在「指数因子的衰减半平面」与「围道所处半平面」的配对；情形 b) 退化到 α = 0 时指数因子不再提供衰减，改由 zf(z)→0 补偿弧长 ~πR 的增长所需的一个 1/z 阶。
