# 局部离散误差与相容性

局部离散误差度量增长函数 F(x,y,h) 逼近导数 y′ = f(x,y) 的程度（与度量近似解优劣的 [[concepts/整体离散误差与收敛性]] 相对）：

```latex
(19.112)  l(x,h) = \frac{y(x+h) - y(x)}{h} - F(x,y,h) = O(h^p)
(19.113)  \lim_{h\to 0} F(x,y,h) = f(x,y)
```

若 p 是满足 (19.112) 的最大的自然数，称单步法 (19.110) **p 阶相容**。由 (19.112) 直接得到：相容的单步法满足 (19.113)。

**阶的归属**：欧拉法 (19.97) 一阶相容 p = 1；龙格—库塔法 (19.99) 四阶相容 p = 4。

观察：本节并列收敛性、相容性、稳定性三性质，但未陈述“相容+稳定 ⟹ 收敛”型等价定理（Lax 型），原书是否于他处补足待查。
