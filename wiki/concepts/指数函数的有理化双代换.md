# 指数函数的有理化双代换

**指数函数的有理化双代换**是把形如

$$\int R\left(\mathrm{e}^{mx},\ \mathrm{e}^{nx},\ \dots,\ \mathrm{e}^{px}\right)\mathrm{d}x \tag{8.36a}$$

的积分（$R$ 为其变元的有理函数，$m, n, \dots, p$ 为有理数）化归为**有理函数积分**的两次连环代换，出自数学手册(原书第10版) 8.1.6.1（[[sources/10-数学手册原书第10版--11-816-超越函数的积分--12iqp2r]]）。它是该节唯一给出编号公式的核心构造性结果。

## 两次代换

**第一代换 $t = \mathrm{e}^{x}$**：由 $\mathrm{d}t = \mathrm{e}^{x}\mathrm{d}x = t\,\mathrm{d}x$ 得 $\mathrm{d}x = \mathrm{d}t/t$，且 $\mathrm{e}^{mx} = t^{m}$ 等，积分化为

$$\int \frac{1}{t}\, R\left(t^{m},\ t^{n},\ \dots,\ t^{p}\right)\mathrm{d}t. \tag{8.36b}$$

**第二代换（根式代换）**：令

$$z = \sqrt[e]{t},$$

其中根指数字母 $e$ 是分数 $m, n, \cdots, p$ 的分母的最小公倍数（原文如此：该字母与欧拉常数 $\mathrm{e}$ 同形，是否原书记号待查，见 [[queries/根指数字母e是否原书记号]]；转写文本「其中」后该字母脱字）。于是 $t = z^{e}$，每个分数幂 $t^{m} = z^{em}$ 化为整幂，$1/t = z^{-e}$ 亦为整幂，被积函数成为 $z$ 的有理函数，转入 [[concepts/有理函数的积分]] 的标准流程。

## 化归链条

指数型被积函数 →（$t = \mathrm{e}^{x}$）→ 含分数幂的 $t$ 的有理式 →（$z = \sqrt[e]{t}$）→ $z$ 的有理函数 → [[methodology/有理函数积分五步流程]]

两次代换各司其职、不可合并：第一次消去指数结构，第二次消去分数幂。

## 方法定位

- 它是 [[concepts/换元积分法]]（式 8.8）的连环实例。
- 与 [[concepts/分部积分的循环法]] 互补：本方法处理「有理函数 $R$ 复合指数」结构，后者处理「指数 × 三角」乘积结构。
- 在 [[methodology/超越函数积分化归流程]] 中位于第 2 步，是双曲函数积分（[[concepts/双曲函数的积分]] 路线一）的下游出口。

## 复算

见 [[findings/式8-36指数函数积分双代换复算]]：代换链逐步复算通过；$t = z^{e}$ 时 $\mathrm{d}t = e\,z^{e-1}\mathrm{d}z$，式 8.36b 化为 $e\int \frac{1}{z}R(z^{em},\dots)\mathrm{d}z$，被积函数确为 $z$ 的有理函数。
