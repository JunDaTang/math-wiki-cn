# 中国剩余定理

中国剩余定理给出联立线性同余式组

$$x \equiv b_1\ (m_1),\quad x \equiv b_2\ (m_2),\quad \dots,\quad x \equiv b_t\ (m_t) \tag{5.253}$$

在模数 m₁, …, m_t 两两互素时的完整解理论：解存在、模 m = m₁m₂⋯m_t 唯一，并给出显式构造。

## 构造（式 5.254）

令 m = m₁·m₂⋯m_t，a_j = m/m_j（5.254a）。对每个 j 选取 x_j 满足线性同余式 a_j x_j ≡ b_j (m_j)（因 gcd(a_j, m_j) = 1，唯一可解），则

$$x' = a_1 x_1 + a_2 x_2 + \dots + a_t x_t \tag{5.254b}$$

是同余式组的一个解；且 x″ 也是解当且仅当 x″ ≡ x′ (mod m)。

## 算例（已复算）

解 x ≡ 1 (2)、x ≡ 2 (3)、x ≡ 4 (5)：m = 30，a₁ = 15、a₂ = 10、a₃ = 6；15x₁ ≡ 1 (2)、10x₂ ≡ 2 (3)、6x₃ ≡ 4 (5) 有特解 x₁ = 1、x₂ = 2、x₃ = 4；x ≡ 15·1 + 10·2 + 6·4 = 59 ≡ 29 (mod 30)。验证：29 mod 2 = 1、29 mod 3 = 2、29 mod 5 = 4。✓

## 作用

源文指出：应用联立线性同余式组，可以把解模 m（非线性）同余式的问题归结为解模素数幂同余式的问题——这正是 [[concepts/多项式同余与素数幂提升法|多项式同余]]（5.4.3.9）两级归约（互素模分解 + 素数幂提升）的入口。构造流程见 [[methodology/中国剩余定理构造解流程]]。

## 代数视角（关联，非本源直接陈述）

两两互素时 CRT 等价于环同构 ℤ_m ≅ ℤ_{m₁} × ⋯ × ℤ_{m_t}，即 [[entities/剩余类环zn|剩余类环]] 的直积分解；此表述与 5.3.7 的商环理论相合，但 5.4.3 源文未以环论语言陈述。
