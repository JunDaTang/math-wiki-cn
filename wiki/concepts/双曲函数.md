# 双曲函数

**双曲函数**是由 [[concepts/指数函数]] e^x 与 e^−x 的线性组合及倒数所定义的六类初等函数的总称：[[concepts/双曲正弦函数]] sinh x、[[concepts/双曲余弦函数]] cosh x、[[concepts/双曲正切函数]] tanh x、[[concepts/双曲余切函数]] coth x、[[concepts/双曲正割函数]] sech x 与 [[concepts/双曲余割函数]] csch x。其中前三个直接由 e^±x 定义（式 2.166–2.168），后三个定义为相应函数的倒数（式 2.169–2.171）；手册并注明其几何定义（参见手册 3.1.2.2）与三角函数类似。

## 六个函数一览

| 函数 | 定义（式） | 奇偶 | 手册记载的图像性质 |
|---|---|---|---|
| sinh x | (e^x − e^−x)/2（2.166） | 奇 | 严格递增，值域 ℝ，原点对称中心兼拐点，切线角 π/4，无渐近线（图 2.49） |
| cosh x | (e^x + e^−x)/2（2.167） | 偶 | 最小值 1 于 A(0,1)，位于 y = 1 + x²/2 上方，无渐近线，即 [[concepts/悬链线]]（图 2.50） |
| tanh x | sinh x/cosh x（2.168） | 奇 | 从 −1 到 1 严格递增，渐近线 y = ±1，原点拐点切线角 π/4（图 2.51） |
| coth x | 1/tanh x（2.169） | 奇 | x = 0 不连续，两支递减，渐近线 x = 0 与 y = ±1，无拐点无极值（图 2.52） |
| sech x | 1/cosh x（2.170） | 偶（推断） | 手册未设图像小节 |
| csch x | 1/sinh x（2.171） | 奇（推断） | 手册未设图像小节 |

（sech/csch 的奇偶为依据定义与 cosh 偶、sinh 奇的直接推断，手册未明言。）

## 基本特征

- 与 [[concepts/三角函数]] 不同，双曲函数不是周期函数：sinh 在整个 ℝ 上严格单调递增，cosh 仅有一个最小值点，曲线两端呈指数行为。
- 双曲函数之间存在着与三角函数类似的关系（[[concepts/双曲恒等式]]，式 2.172–2.198），但存在系统性的符号差异（如 cosh²x − sinh²x = 1 对应 sin²α + cos²α = 1），两套体系的性质不得因名称对应而互相转移（见 [[comparisons/双曲函数与三角函数比较]]）。
- 借助复辐角关系（式 2.199–2.206），可用 [[concepts/三角-双曲代换规则]] 从已知的三角公式导出双曲公式（有限制）。
- 结构性事实：cosh x + sinh x = e^x、cosh x − sinh x = e^−x，这一分解是双曲棣莫弗公式（式 2.190）的基础。
