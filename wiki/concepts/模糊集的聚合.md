# 模糊集的聚合（连接）

**模糊集的聚合（连接）**是把经典集合运算（并、交、补）推广到模糊集的一类运算的总称。其总纲是《数学手册(原书第10版)》5.9.2.1 的**逐点局部性原理**：A∪B 与 A∩B 中任意元素 x∈X 的隶属等级只与 μ_A(x)、μ_B(x) 有关。模糊并/交借助两个函数 s, t: [0,1]×[0,1]→[0,1]（式 5.343）定义：

- μ_{A∪B}(x) := s(μ_A(x), μ_B(x))（式 5.344）；
- μ_{A∩B}(x) := t(μ_A(x), μ_B(x))（式 5.345）。

即两个隶属真值被聚合为新的隶属真值。取 t 为 [[concepts/t-范数]]、s 为 [[concepts/s-范数]] 即得系统的聚合族；手册节首指出，关于如何推广通常的集合运算「有几个不同的建议」，本节给出其目录。

## 手册给出的聚合目录

- **缺省（Zadeh）交并**：min / max（式 5.350–5.351，图 5.72–5.75）；
- **代数积 / 代数和**：xy / x+y−xy（式 5.352b / 5.352a）；
- **有界差 / 有界和、极端积 / 极端和**（表 5.8）；
- **参数族**：Hamacher、Einstein、Frank、Yager、Schweizer、Dombi、Weber、Dubois（表 5.8）；
- **[[concepts/补偿算子]]**：介于 t/s 范数之间的 λ 算子与 γ 算子（式 5.353–5.356）；
- **[[concepts/模糊补]]**：补运算（式 5.357–5.358）；
- **[[concepts/扩张原理]]**：一般映射向模糊区域的推广。
