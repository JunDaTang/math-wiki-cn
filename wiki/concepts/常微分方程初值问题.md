# 常微分方程初值问题

常微分方程初值问题是只在自变量一个点处给定条件的定解问题，是数学手册 19.4.1 全部初值方法的公共框架：

```latex
(19.93)  y' = f(x, y),   y(x_0) = y_0
(19.94)  x_i = x_0 + i h   (i = 0, 1, 2, \dots)
```

数值求解在预先给定步长的等距插值节点 (19.94) 上进行，求未知函数 y(x) 的近似值 y_i。源文指出：在许多情况下解不能表示成已知基本函数的表达式，解在更一般情形的存在性参见 9.1.1.1（未入库），必须用数值方法确定。

初值方法按“欧拉多边形法（一阶，即一阶龙格—库塔法）→ 四阶龙格—库塔法（单步高阶）→ 多步法 → 预估—校正法（隐式的实用化）”的层级组织。理论性质见 [[concepts/整体离散误差与收敛性]]、[[concepts/局部离散误差与相容性]]、[[concepts/对初值扰动的稳定性与绝对稳定性]]、[[concepts/刚性微分方程]]。与 [[concepts/常微分方程边值问题]] 相对：高于一阶的微分方程可能构成两类问题之一。

转录注：源文在 (19.95) 前将初值问题误引为 "(19.33)"，应为 (19.93)，见 [[queries/式19-95前回指19-33疑为19-93之辨]]。
