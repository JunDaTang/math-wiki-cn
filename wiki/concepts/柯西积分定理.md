# 柯西积分定理

柯西积分定理（Cauchy integral theorem）是复分析的基本定理，断言：在单连通区域中解析的函数，沿区域内任意一条闭曲线的积分为零，且其积分值与路径无关；该定理可推广到多连通区域——沿外围闭曲线的积分等于沿诸内围闭曲线积分之和。它把「解析性」（[[concepts/复函数的可微性]] 的强化前提）与积分行为直接联系起来，是 [[concepts/柯西积分公式]] 与 [[concepts/解析函数的无穷可微性]] 的基础。

## 单连通区域的表述（14.2.2.1）

如果在一个单连通区域 G 中函数 f(z) 是解析的，则成立两个等价的陈述：

- a) 沿着 G 中任意一条闭曲线 C，积分等于零：

$$(C)\oint f(z)\,\mathrm{d}z = 0; \tag{14.40}$$

- b) 积分 $\int_A^B f(z)\,\mathrm{d}z$ 的值与连接点 A、B 的、位于 G 中的曲线无关，即它仅依赖于 A、B。

同一结论在 14.2.1.2.5 已先行以 (14.39) 陈述（「根据柯西积分定理，这个积分的值为零」），14.2.2.1 为正式重述，属手册式冗余。

**单连通区域的工作定义**（本节给出）：如果一个区域由一条简单闭曲线所围，那么这个区域是单连通的（simply connected）。

## 多连通区域的表述（14.2.2.2）

如果 $C, C_1, C_2, \dots, C_n$ 是一些简单闭曲线，使得曲线 C 包围了所有的 $C_\nu$（$\nu = 1, 2, \dots, n$），诸曲线 $C_\nu$ 互不包含和相交，并且函数 f(z) 在包含诸曲线以及诸 $C_\nu$ 之间区域的区域 G（图 14.35 中的阴影区域）中是解析的，以及诸曲线 $C, C_1, \dots, C_n$ 有相同的定向（如都是逆时针方向），则

$$\oint_C f(z)\,\mathrm{d}z = \oint_{C_1} f(z)\,\mathrm{d}z + \oint_{C_2} f(z)\,\mathrm{d}z + \dots + \oint_{C_n} f(z)\,\mathrm{d}z. \tag{14.41}$$

**定向约定是关键前提**：诸曲线必须同向（如均逆时针）。经 $f = 1/z$ 等简单情形验证，该「同向求和」形式正确。两种表述的对照见 [[comparisons/单连通与多连通区域柯西积分定理比较]]。

## 用途与例题

当一条闭曲线 C 还包含了函数 f(z) 的一些奇点在内时（回指 14.3.5.5 留数定理，未入库），多连通形式对于沿 C 计算 f(z) 的积分很有用：把外围积分化为只围单个奇点的诸小圆积分之和。标准流程见 [[methodology/多连通区域积分部分分式分解流程]]。

例（14.2.2.2）：计算 $\oint_C \frac{z-1}{z(z+1)}\,\mathrm{d}z$，其中 C 是包含原点和点 $z=-1$ 的一条简单闭曲线。取以原点为心、半径 $1/2$ 的圆周 $C_1$ 与以 $z=-1$ 为心、半径 $1/2$ 的圆周 $C_2$，被积函数分解为部分分式 $\frac{z-1}{z(z+1)} = -\frac{1}{z} + \frac{2}{z+1}$，逐圆求值得 $0 + 4\pi\mathrm{i} - 2\pi\mathrm{i} - 0 = 2\pi\mathrm{i}$（复算通过，见 [[findings/式14-33a至14-43复积分定义定理与例题转录复算]]）。
