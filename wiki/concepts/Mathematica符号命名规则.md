# Mathematica符号命名规则

**Mathematica 中的符号（symbol）是基本对象的表示法**，其命名遵循一组词法规则：任意一列字母和数字、不得以数字开始、允许专门记号 $、区分大小写；由此形成保留符号与用户符号的大小写约定（《数学手册（原书第10版）》20.2.1 节）。

| 规则 | 内容 |
|------|------|
| 构成 | 可以是任何一列字母和数字，但一定不能以数字开始；也允许使用专门记号 $ |
| 大小写 | 字母区分大写和小写 |
| 保留符号 | 留作专用的符号要么以大写字母开始，要么以记号 $ 开始；在复合词中，如果第二个词具有单独意义，那么它也以大写字母开始 |
| 用户约定 | 建议用户创建他们自己的符号时以小写字母开始 |

## 说明

- **大小写区分 + 保留符号以大写或 $ 开头**的组合，使用户以小写开头的符号不会与系统保留符号冲突——这是「建议用户符号以小写字母开始」这一约定的动因。
- 本节出现的内置名均符合保留符号规则：FullForm 为复合词，第二个词 Form 具有单独意义，故以大写开始；Part、Plus、Times、Power 为单词，以大写开始。
- 待校勘：「留作专用的符号」是否对应原书「保留符号」（reservierte Symbole）之表述，见 [[queries/20-2-1全节系统性转写讹误清单]]。
