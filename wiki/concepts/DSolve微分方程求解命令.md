# DSolve 微分方程求解命令（表 20.13）

## 概念内涵

DSolve 是 [[entities/mathematica]] 求解微分方程的命令族（20.3.4.4）。如果可以给出封闭形式的解，则 Mathematica 可以符号地处理常微分方程并给出一般解。表 20.13 原文转录：

| 命令 | 释义 |
|---|---|
| `DSolve[deq, y[x], x]` | （如果有可能）对于 y[x] 求解微分方程；y[x] 可以用隐式给出 |
| `DSolve[deq, y, x]` | 以纯函数的形式给出微分方程的解 |
| `DSolve[{deq1, deq2,···}, y, x]` | 解常微分方程组 |

## 通解、任意常数与初边值条件

解（参见手册 9.1）表示为具有任意常数 C[i] 的通解；初始值和边界条件可以在包含方程或方程组的列表部分引入，在这一情形的回答是一个特解。

## 纯函数输出的价值（例 A，取自手册 9.1.1.2）

对方程 y′(x) − y(x)tanx = cosx：

```
In[1] := DSolve[y'[x] - y[x] Tan[x] == Cos[x], y, x]
Out[1] = {{y -> Function[x, C[1] Sec[x] + Sec[x] (x/2 + Sin[2x]/4)]}}
```

随后 `y[x] /. %1` 即得解值；也可对其他的量做替换，例如 y′[x] 或 y[1]。书中点明「这里使用纯函数的优点是显然的」，直接体现 [[concepts/纯函数（Mathematica）]]。

## 隐式解与 ProductLog（例 B，取自手册 9.1.1.2, 2.）

对方程 y′(x)·x·(x − y(x)) + y²(x) = 0：

```
Out[1] = {{y[x] -> -x ProductLog[-E^(-C[1])/x]}}
```

书中注明 ProductLog[z] 给出的是 z = w e^w 中 w 的主解（即 Lambert W 函数主支），且此解由隐式给出。转写「C[i]」为「C[1]」之讹（[[queries/20-3全节系统性转写讹误清单]]）。两例复算见 [[findings/DSolve两例复算]]。

## 失败行为与回退

- 如果 Mathematica 不能解一个微分方程，那么它将返回到输入而没有任何评论。
- 在这种情形下，或者如果符号解过于复杂，则可以求数值解（回指手册第 1321 页 19.8.4.2, 5.）。
- 书中告诫：也和求不定积分一样，在求微分方程符号解的情形中 Mathematica 能力不应被高估；如果结果不能用初等函数的一个代数表达式来表示，那么唯一的方法就是寻求数值解。

## 偏微分方程评论

书中评论：甚至在复杂的多维区域，Mathematica 也能求某些偏微分方程的符号解和数值解。
