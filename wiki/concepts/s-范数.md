# s 范数（余范数）

**s 范数**是 [0,1] 上的二元函数 s: [0,1]×[0,1]→[0,1]，满足与 [[concepts/t-范数]] 对偶的公理（E1）–（E4）：交换、结合、单调，但以 0 为中性元素、1 为零元素（《数学手册(原书第10版)》式 5.348–5.349）。在 [[concepts/模糊集的聚合]] 框架中，s 范数充当模糊**并**的聚合函数：μ_{A∪B}(x) := s(μ_A(x), μ_B(x))，对应逻辑 OR 一侧。又称 **t 余范数（t-conorm）**——源文残句「函数 称作 范数和 余范数；后者也称为 范数」脱落 t/s 字母，疑应为「函数 t 称作 t 范数，s 称作 t 余范数；后者也称为 s 范数」。

## 公理组（式 5.349a–d）

| 编号 | 名称 | 内容 |
|---|---|---|
| E1 | 交换性 | s(x,y) = s(y,x) |
| E2 | 结合性 | s(x, s(y,z)) = s(s(x,y), z) |
| E3 | 中性元与零元 | s(x,0) = s(0,x) = x；s(x,1) = s(1,x) = 1 |
| E4 | 单调性 | x ≤ v 且 y ≤ w ⇒ s(x,y) ≤ s(v,w) |

## 上下界

max{x,y} ≤ s(x,y) 对一切 s 范数成立（式 5.349f）：[[entities/扎德]] 的 max 是最小的 s 范数；表 5.8 序链中极端和 s_ds 为最大端（就表列各族而言）。

## 主要实例（表 5.8）

- Zadeh 并：max{x,y}（缺省）；
- 有界和（Lukasiewicz）：s_b(x,y) = min{1, x+y}；
- 代数和：s_a(x,y) = x+y−xy；
- 极端和：s_ds(x,y) = max{x,y} 若 x=0 或 y=0，否则 1；
- 参数族：Hamacher s_h、Einstein s_e、Frank s_f、Yager s_ya、Schweizer s_s、Dombi s_do、Weber s_w、Dubois s_du。

完整公式与序链见 [[comparisons/t范数族与s范数族比较]]、[[findings/表5-8十二对范数族与序链]]。

## 与 t 范数的对偶

通行关系 s(x,y) = 1 − t(1−x, 1−y)（源文未显式给出）；独立复算确认表 5.8 中除 Schweizer s_s（疑转写讹误，见 [[queries/schweizer-s范数指数是否应为负p]]）外全部配对与之相符。
