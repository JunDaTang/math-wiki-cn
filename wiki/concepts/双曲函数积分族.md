# 双曲函数积分族（426–446）

双曲函数积分族是 [[sources/10-数学手册原书第10版--13-2174-其他超越函数积分--17odu4w|数学手册 21.7.4.1]] 收录的一组以 sinh、cosh、tanh、coth 为被积函数的不定积分公式，编号 426–446 共 21 式，是 21.7.4「其他超越函数积分」的第一主题。该族在本节转写中编号连续完整、无讹误，全部公式经微分复算通过（[[findings/21-7-4超越函数积分全表微分复算]]）。

## 公式构成

1. **基本积分与平方积分**（426–429）：$\int\sinh ax\,dx = \frac{1}{a}\cosh ax$、$\int\cosh ax\,dx = \frac{1}{a}\sinh ax$；平方积分 $\int\sinh^2 ax\,dx = \frac{1}{2a}\sinh ax\cosh ax - \frac{x}{2}$ 与 $\int\cosh^2 ax\,dx = \frac{1}{2a}\sinh ax\cosh ax + \frac{x}{2}$ 的符号差异源于 $\cosh^2 - \sinh^2 = 1$。
2. **幂次双向递推**（430/431）——本族最复杂的结构：
   $$\int\sinh^n ax\,dx = \frac{1}{an}\sinh^{n-1}ax\cosh ax - \frac{n-1}{n}\int\sinh^{n-2}ax\,dx \quad (n>0)$$
   $$\int\sinh^n ax\,dx = \frac{1}{a(n+1)}\sinh^{n+1}ax\cosh ax - \frac{n+2}{n+1}\int\sinh^{n+2}ax\,dx \quad (n<0,\ n\neq -1)$$
   cosh 的对应式（431）同构：降阶分支第二项为「+」，升阶分支首项为「−」。n>0 分支每次降二阶，n<0 分支每次升二阶，两分支均排除 n=−1——该例外情形即倒数积分 432/433（对数型与 arctan 型），不可由幂式递推到达。
3. **倒数积分**（432/433）：$\int\frac{dx}{\sinh ax} = \frac{1}{a}\ln\tanh\frac{ax}{2}$、$\int\frac{dx}{\cosh ax} = \frac{2}{a}\arctan e^{ax}$。
4. **x 的一次因子与 tanh/coth 族**（434–439）：434/435 分部积分；436/437 对数型；438/439 由 $1-\tanh^2 = 1$、$1-\coth^2 = -1$ 化为 $x - \frac{\tanh ax}{a}$ 型。
5. **双曲乘积积分**（440–442）：$\int\sinh ax\sinh bx\,dx$ 等三式，公共系数 $\frac{1}{a^2-b^2}$，条件 $a^2\neq b^2$。
6. **双曲—三角混合积分**（443–446）：$\int\sinh ax\sin ax\,dx$ 等四式，公共系数 $\frac{1}{2a}$，覆盖 sinh/cosh 与 sin/cos 的全部两两组合。

## 结构要点

- 双向递推与 [[concepts/二次因子有理函数积分族与递推降阶]] 中的递推不同：后者向低幂单向化归，本族对负幂（升阶）同样给出封闭递推，两分支以 n=−1 为公共不可达点。
- 433 的 $\arctan e^{ax}$ 与 436/437 的对数型结果，是双曲函数经代换 $u = e^{ax}$ 化为 $u$ 的有理函数后积分的典型产物。
- 本族与 [[concepts/双曲函数级数展开]] 同属手册双曲函数知识链，前者为积分侧、后者为级数侧。
