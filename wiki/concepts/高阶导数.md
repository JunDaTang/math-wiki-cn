# 高阶导数

高阶导数是把函数的一阶导数再求导、并逐层递推得到的导数：$y' = f'(x)$ 的导数 $\left(y'\right)'$（即 $\frac{\mathrm{d}}{\mathrm{d}x}\left(\frac{\mathrm{d}y}{\mathrm{d}x}\right)$）称为 $y = f(x)$ 的二阶导数；对低阶导数继续求导，即得三阶、四阶直至 n 阶导数。它是微分学中刻画函数变化率各阶细致结构的基本对象。

## 定义与记号（式 6.21）

函数 $y = f(x)$ 的 n 阶导数记为

$$
y^{(n)} = \frac{\mathrm{d}^{n} y}{\mathrm{d} x^{n}} = f^{(n)}(x) = \frac{\mathrm{d}^{n} f(x)}{\mathrm{d} x^{n}} \quad \left(n = 0, 1, \dots ;\; y^{(0)}(x) = f^{(0)}(x) = f(x)\right),
$$

其中包含 $n = 0$ 的约定：零阶导数即函数自身。二阶导数的记号（依《数学手册》6.1.3.1）为 $y'' ,\ \ddot y ,\ \frac{\mathrm{d}^{2} y}{\mathrm{d} x^{2}} ,\ f''(x)$ 或 $\frac{\mathrm{d}^{2} f(x)}{\mathrm{d} x^{2}}$。

> 注意：点记号 $\ddot y$ 通常专指对时间（或指定参数）求导；手册将其列为通用二阶导数记号之一，疑原版限定语在转写中脱落，见 [[queries/6-1-3全节系统性转写讹误清单]]。

完整定义链与逐字转录见 [[findings/高阶导数定义与n阶记号-式6-21]]。

## 计算途径

按函数的给定方式，高阶导数的计算分为四类（对应手册 6.1.3.2–6.1.3.5）：

1. **初等函数的封闭形式**：幂、对数、指数、三角、双曲函数的 n 阶导数有显式公式，汇总于表 6.3，见 [[findings/表6-3初等函数高阶导数逐字转录]]。
2. **乘积函数**：用 [[concepts/莱布尼茨公式]]（式 6.22–6.23）展开；当一因子为低次多项式时可截断计算，见 [[methodology/莱布尼茨公式截断计算流程]]。
3. **参数形式**：$x = x(t),\ y = y(t)$ 时直接由参数导数计算，见 [[concepts/参数形式函数的高阶导数]]（式 6.24）。
4. **反函数**：由反函数 $\varphi$ 的各阶导数表示，见 [[concepts/反函数的高阶导数]]（式 6.25）。
