# 复定积分

复定积分（definite complex integral）是复变函数沿复平面中一条曲线所取的定积分：设 f(z) 在区域 G 中连续、连接点 A、B 的曲线 C 完全位于 G 中，把 C 任意分割为 n 个子弧段并在每段上任取中间点 ζ_i，作黎曼型和式；当诸 Δz_i → 0 且 n → ∞ 时，若极限存在且与分点及中间点的选取无关，则该极限称为 f(z) 沿曲线 C 的复定积分。它是复分析积分理论的载体：[[concepts/柯西积分定理]]、[[concepts/柯西积分公式]] 与 [[concepts/复不定积分]] 均以其为对象。

## 定义（式 14.33a–c）

$$\sum_{i=1}^{n} f(\zeta_i)\,\Delta z_i, \qquad \Delta z_i = z_i - z_{i-1}, \tag{14.33a}$$

$$\lim_{n\to\infty} \sum_{i=1}^{n} f(\zeta_i)\,\Delta z_i, \tag{14.33b}$$

$$I = \int_{\widehat{AB}} f(z)\,\mathrm{d}z = (C)\int_{A}^{B} f(z)\,\mathrm{d}z. \tag{14.33c}$$

记号 $(C)\int_A^B$ 与 $\int_{\widehat{AB}}$ 含义相同，均指积分沿 A、B 之间的曲线 C 计算。

## 基本性质

- **路径依赖性**：该积分的值通常依赖于积分路径（区别于实区间上的定积分）；何时与路径无关见 [[concepts/积分路径无关性]]。
- **与第二型线积分共有的性质**：a) 颠倒积分路径的方向，积分改变符号；b) 把积分路径分解成几个部分，总积分值等于这些部分积分值之和。

## 参数化求值（式 14.37–14.38b）

设积分路径由 $x = x(t),\, y = y(t)$（t 的可微函数）给出，起终点参数值为 $t_A$、$t_B$，且 $f(z) = u(x,y) + \mathrm{i}\,v(x,y)$，$z = x + \mathrm{i}y$，则复定积分可用两个实积分计算：

$$
\begin{aligned}
(C)\int_A^B f(z)\,\mathrm{d}z
&= \int_A^B (u\,\mathrm{d}x - v\,\mathrm{d}y) + \mathrm{i}\int_A^B (v\,\mathrm{d}x + u\,\mathrm{d}y)\\
&= \int_{t_A}^{t_B} \bigl[u(t)x'(t) - v(t)y'(t)\bigr]\,\mathrm{d}t
 + \mathrm{i}\int_{t_A}^{t_B} \bigl[v(t)x'(t) + u(t)y'(t)\bigr]\,\mathrm{d}t.
\end{aligned} \tag{14.38a}
$$

即复积分分解为两个实的第二型线积分，详见 [[comparisons/复定积分与第二型线积分比较]]；圆周路径上的标准计算流程见 [[methodology/复积分圆周参数化计算流程]]（例：$\oint_{|z-z_0|=r_0}(z-z_0)^n\,\mathrm{d}z = 0$（$n\neq-1$），$2\pi\mathrm{i}$（$n=-1$））。
