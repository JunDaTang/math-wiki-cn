# 隐函数方程组求导

隐函数方程组求导是指当多个未知函数不是由单个方程、而是由若干约束方程联立定义时求其（偏）导数的方法：对每个约束方程按 [[concepts/多元链式法则]] 求导，得到一个以未知函数的导数为未知量的线性方程组，解之即得各导数；对上一阶方程组重复求导可逐阶升阶。《数学手册(原书第10版)》6.2.3.2 的条目 (3)–(6)（式 6.55–6.57）按方程数与函数元数给出这一方法的三种已展开情形与一个残缺的一般情形。

## 情形一：两方程、两个一元函数（式 6.55）

y = f(x), z = φ(x) 由 F(x, y, z) = 0 与 Φ(x, y, z) = 0 给出。用式 6.51b 微分得 2×2 线性方程组（式 6.55b），解出：

$$y' = \frac{F_z \Phi_x - \Phi_z F_x}{F_y \Phi_z - F_z \Phi_y},\qquad z' = \frac{F_x \Phi_y - F_y \Phi_x}{F_y \Phi_z - F_z \Phi_y}. \tag{6.55c}$$

分母 F_yΦ_z − F_zΦ_y 在结构上即约束组对 (y, z) 的雅可比行列式——原书未使用该名称，此为复算层面的推断标注（复算用克莱姆法则逐项核对通过，见 [[findings/式6-55两隐函数方程组导数复算]]）。原书说明二阶导数由 y′, z′ 经"(6.55b) 的微分"求得，未给显式公式。

## 情形二：n 个方程、n 个一元函数（式 6.56）

y₁ = f(x), …, yₙ = ψ(x) 由 F = Φ = ⋯ = Ψ = 0（各为 x, y₁, …, yₙ 的函数）给出。用式 6.51b 微分得关于 y₁′, …, yₙ′ 的 n×n 线性方程组（式 6.56b）。原书未给显式解，只说明由 (6.56b)"可得要求的导数"且"用类似的方法可计算高阶导数"。结构上其系数矩阵即约束组对 (y₁, …, yₙ) 的雅可比矩阵（推断标注，原书未名），见 [[findings/式6-56n元隐函数方程组线性系统]]。

## 情形三：两方程、两个二元函数（式 6.57）

u = f(x, y), v = φ(x, y) 由 F(x, y, u, v) = 0 与 Φ(x, y, u, v) = 0 给出。用式 6.52b 分别对 x 与 y 微分，得到两组 2×2 线性方程组（式 6.57b、6.57c）。原书说明分别解出 (∂u/∂x, ∂v/∂x) 与 (∂u/∂y, ∂v/∂y) 即得一阶偏导数，但**未给显式解公式**——不得凭与 6.55c 的结构类推补写为原文内容，见 [[findings/式6-57两个二元隐函数偏导数方程组]]。

## 一般情形（条目 (6)，转写残缺）

源文作"(6) 个方程构成的方程组给出的 元函数 利用与前面类似的方法可计算一阶和高阶偏导数"：两处脱漏 n，且无任何公式。按 (1)–(5) 递进逻辑推测应为 n 个方程给出的 n 元函数，但需对照原书，见 [[queries/第6条一般情形脱漏的n如何复原]]。

## 与单方程情形的关系

方程数 = 1 时退化为 [[concepts/隐函数求导]]（式 6.53–6.54）：一阶导数由单个线性方程直接解出（y′ = −F_x/F_y），无需解方程组。两个维度的系统比较见 [[comparisons/单方程与方程组隐函数求导比较]] 与 [[comparisons/一元与多元隐函数求导比较]]；操作流程见 [[methodology/隐函数逐阶求导流程]]。

## 注意事项

- 6.55c、6.56b 的解在结构上即克莱姆法则与雅可比行列式，但原书未使用这些名称——凡涉及"克莱姆/雅可比"的表述均为录入层面的推断，不得归于原文。
- 6.55c、6.56b 均未标明分母（行列式）非零的条件（对比 6.53c 标明 F_y ≠ 0），见 [[queries/式6-54b是否应补Fu不等于0条件]]。
