# 有序向量空间与锥诱导偏序

有序向量空间（偏序向量空间）是配备了与线性结构相容的偏序的向量空间。《数学手册(原书第10版)》12.1.7 的核心结果是**等价定理**：由凸锥诱导的序与满足序公理 (O1)–(O4) 的序一一对应，因而在同一向量空间中引入序的两种方法等价。

## 锥诱导的序

给定向量空间 V 中一个锥 C（[[concepts/凸锥]]），对 x, y ∈ V 规定

$$x \geq y \iff x - y \in C,$$

偶对 (V, C) 称作由锥 C 形成的有序向量空间。元 x 称作正的，是指 x ≥ 0，等价于 x ∈ C；且

$$C = \{x \in V : x \geq 0\}. \tag{12.25}$$

## 偏序现象

ℝ² 中由第一象限锥 C = ℝ₊² 产生的序是典型的「偏序」（半序）：只有某些向量对可比较。例如 x = (1, −1) 与 y = (0, 2)：x − y = (1, −3) 与 y − x = (−1, 3) 都不在 C 中，故 x ≥ y 与 x ≤ y 均不成立。（复算注：「由锥生成的序只能是一种偏序」在 ℝ¹ 情形实为全序，表述宜弱化为「一般仅为偏序」。）

## 序公理 (O1)–(O4) 与等价定理

$$
\text{(O1)}\; x \geq x \;\;(\text{自反性}) \tag{12.26}
$$
$$
\text{(O2)}\; x \geq y \,\&\, y \geq z \Rightarrow x \geq z \;\;(\text{传递性}) \tag{12.27}
$$
$$
\text{(O3)}\; x \geq y \,\&\, \alpha \geq 0 \Rightarrow \alpha x \geq \alpha y \tag{12.28}
$$
$$
\text{(O4)}\; x_1 \geq y_1 \,\&\, x_2 \geq y_2 \Rightarrow x_1 + x_2 \geq y_1 + y_2 \tag{12.29}
$$

反之，若 V 上存在满足 (O1)–(O4) 的序关系，令 V₊ = {x : x ≥ 0}（12.30），则 V₊ 是一个锥，且由 V₊ 诱导的序等同于原始的序——两种引入序的方法等价。（复算注：由 (O1)–(O4) 推出 V₊ 的**尖性**需反对称性 x ≥ y ∧ y ≥ x ⟹ x = y，而转录的公理列表未显式包含之；(O1) 的注释在转写中为乱码，可能佚失相关内容，见 [[queries/12-1全节系统性转写讹误清单]]。其余部分均可由锥的封闭性直接复算，见 [[findings/式12-25至12-33锥序等价与正算子转录复算]]。）

## 生成锥

锥 C ⊂ V 称作生成的或再生的，是指每一元 x ∈ V 可表示成 x = u − v（u, v ∈ C），即 V = C − C。

## 序区间与序有界集（12.1.7.2）

对满足 x ≤ y 的任意两元，集合

$$[x, y] = \{v \in V : x \leq v \leq y\} \tag{12.32}$$

称作序区间或 (o) 区间；x、y 分别是 [x,y] 的下界与上界且属于该集合。集合 E 称作**序有界**（(o)有界），是指 E 是某个序区间的子集（存在 u, z 使 u ≤ x ≤ z ∀x ∈ E）。上有界/下有界按上界/下界的存在定义。注意：「(o)有界 ⟺ 通常意义有界」**仅在 ℝ¹ 成立**，不得外推。

## 典型序结构

- **序列空间**：自然逐坐标序通过与锥 C = {{ξₙ} : ξₙ ≥ 0 ∀n}（12.31，转写缺下标 n）之交诱导；正元即具非负分量的序列（涉及 12.1.7.1 例 A，其空间名转写缺录，见 [[queries/12-1全节系统性转写讹误清单]]）。不同锥可定义不同序（源引 [12.20], [12.22]）。
- **函数空间**：F(T)、B(T)、C([a,b])、C^k([a,b]) 中自然序为逐点序 x ≥ y ⟺ x(t) ≥ y(t) ∀t；正锥分别记 F₊(T)、B₊(T) 等，且 C₊ = F₊(T) ∩ C(T)（T = [a,b]）。见 [[entities/典型序列空间]]、[[entities/函数空间层级]]。
