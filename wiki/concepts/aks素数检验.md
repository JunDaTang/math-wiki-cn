# AKS 素数检验

AKS 素数检验是基于「确定一个数是素数还是合数的多项式算法」的**确定性**素性检验，由 Agrawal、Kayal、Saxena 于 2002 年发表（源文第三作者被 OCR 讹作「导xena」，见 [[queries/aks第三作者是否应为saxena]]），可以有效地检验任何自然数的素性。

## 核心命题（转写受损）

n > 1，r 为素数，满足：(i) [n] 不被 ≤ r 的素数整除；(ii) i = 1,…,⌊(log₂n)²⌋ 时 r^i ≢ 1 (mod n)；(iii) 对每个 1 ≤ a ≤ √r·log n，(x+a)^n ≡ x^n + a (mod x^r−1, n)——则 n 是一个素数幂。

⚠ 条件 (ii) 疑为 n^i ≢ 1 (mod r)（即 n 模 r 的阶超过 log²n）之倒置，按源文方向数学意义不合；见 [[queries/aks条件r的i次方模n是否应为n的i次方模r]]。在对照 Agrawal–Kayal–Saxena 2002 原文之前，本 wiki 的 AKS 流程页应视为未定稿版本。

## 检验流程

见 [[methodology/aks素性检验流程]]。要点：m := ⌊(log₂n)^5⌋；n < 5,690,034 时查已知素数表；对更大的 n 有 n > m（已复算：5,690,034 是 x = (log₂x)^5 的不动点）。先核验 n 是否被 [3,m] 中自然数整除；再取素数 r 使上述阶条件成立；核验批量同余式 (x+a)^n ≡ x^n + a (mod x^r−1, n)；全部成立则 n 为素数幂，最后排除 n = q^k (k>1) 即得素数结论。

## 与随机性检验的对比

与随机性算法不同，AKS 的结果可信，甚至没有可忽略的小错误概率。但源文评注：**在密码学中拉宾-米勒检验（[[concepts/拉宾-米勒素数检验]]）更合适**。系统比较见 [[comparisons/概率性与确定性素性检验比较]] 与 [[findings/aks命题与检验流程]]。
