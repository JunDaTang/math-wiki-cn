# 双曲余弦函数

**双曲余弦函数** cosh x 是六个 [[concepts/双曲函数]] 之一，由 [[concepts/指数函数]] 定义为 e^x 与 e^−x 之和的一半：

$$
\cosh x = \frac {\mathrm{e} ^ {x} + \mathrm{e} ^ {- x}}{2}.\tag{2.167}
$$

其倒数函数为 [[concepts/双曲正割函数]] sech x（式 2.170）。

## 图像性质（手册 2.9.2.2，图 2.50）

- y = cosh x 为**偶函数**：cosh(−x) = cosh x（式 2.180），曲线关于 y 轴对称。
- **单调性**：若 x < 0，函数值从 +∞ 到 1 严格单调递减；若 x > 0，函数值从 1 到 +∞ 严格单调递增。
- **最小值**：当 x = 0 时取最小值 1（点 A(0,1)）。
- **无渐近线**（手册设有图像小节的四个双曲函数中，仅 cosh 与 sinh 无渐近线）。
- **与抛物线的位置关系**：曲线恒位于二次抛物曲线 y = 1 + x²/2（图中虚线）的上方——在 x = 0 处两曲线相切于 A(0,1)，故「上方」应理解为含等号。
- 该曲线即**悬链线**：因函数表现为一条悬链曲线而得名（详见 [[concepts/悬链线]]；手册 2.15.1 有详细讨论）。

## 在公式体系中的位置

- 基本恒等式：cosh²x − sinh²x = 1（式 2.172）。
- 加法定理：cosh(x ± y) = cosh x cosh y **±** sinh x sinh y（式 2.183）——注意与三角的 cos(x±y) = cos x cos y **∓** sin x sin y 符号相反。
- 倍角：cosh 2x = sinh²x + cosh²x（式 2.187，为**加号**，与 cos 2x 的减号不同）。
- 半角：cosh(x/2) = √(½(cosh x + 1))，恒取正（式 2.192）。
- 和差化积：cosh x − cosh y = 2 sinh((x+y)/2) sinh((x−y)/2)，**无负号**（式 2.197）。
- 复角关系：cosh z = cos iz（式 2.204）。

完整公式体系见 [[concepts/双曲恒等式]]。

## 与 [[concepts/余弦函数]] 的对照

二者同为偶函数，但性质不可互换：cos 有界（[−1,1]）、周期 2π、无最小值只有极小值振荡；cosh 值域 [1, +∞)、非周期、仅在 x = 0 取得唯一最小值 1、无渐近线。系统性符号差异见 [[comparisons/双曲函数与三角函数比较]]。
