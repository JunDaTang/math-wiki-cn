# 有理函数的积分

有理函数的积分指求 ∫P(x)/Q(x) dx 型的不定积分，其中 P(x)、Q(x) 为多项式。有理函数分两类：**整有理函数**（多项式，即 Q 为常数）与**分数有理函数**（一般商式）。据 [[sources/10-数学手册原书第10版--11-813-有理函数的积分--1lrte2m]]（8.1.3 节）的总纲断言：**有理函数的积分总可由初等函数表示**——这是一个构造性结果：固定算法把任意有理函数化归为有限类、每类都有闭式原函数的部分分式，而不只是存在性断言。

## 两个基本术语

- **整部**：分数有理函数的多项式部分。当分子次数 m ≥ 分母次数 n 时，用 Q(x) 除 P(x)（带余除法）把 P(x)/Q(x) 分离为"整部 + 真分式"。
- **真分式**：分子次数低于分母次数的既约分式；它是 [[concepts/部分分式分解]] 的输入。

## 整有理函数（多项式）的积分

逐项积分（式 8.13）：

```latex
\int (a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0)\,\mathrm{d}x
= \frac{a_n}{n+1} x^{n+1} + \frac{a_{n-1}}{n} x^n + \dots + \frac{a_1}{2} x^2 + a_0 x + C
```

## 分数有理函数的积分

分母在实数域上分解为线性与不可约二次因式之积（式 8.14a–b）：

```latex
Q(x) = a_n (x-\alpha)^k (x-\beta)^l \dots (x^2+px+q)^r (x^2+p'x+q')^s \dots,
\qquad \frac{p^2}{4} - q < 0,\; \frac{p'^2}{4} - q' < 0
```

随后按分母根的结构分四种情形做部分分式分解并逐项积分；完整操作流程见 [[methodology/有理函数积分五步流程]]，四情形对照见 [[comparisons/四种部分分式分解情形比较]]。

## 原函数只涉及四类初等函数

1. **多项式**（整部，式 8.13）；
2. **对数** ln|x−α| 与 ln(x²+px+q)（一次因式与二次因式的一次部分）；
3. **有理函数**（重根的高次部分，式 8.16c 第二式与式 8.18d）；
4. **arctan**（二次因式的常数余项，式 8.17d）。

算法的每一步都不越出这四类，这正是"总可由初等函数表示"的构造性证据。
