# 渐近线

## 定义

渐近线是一条直线：当曲线上的点沿该曲线无限远离原点时，点到这条直线的距离趋于零（原书 3.6.1.4，第 338 页；图 3.232）。曲线可以从一侧趋近于该直线，或在趋近的过程中与它不断相交。并不是任何一条曲线在无限地远离原点时（曲线的无穷分支）都有一条渐近线。

渐近线是刻画无界分支行为的核心工具——水平渐近线对应 x → ±∞ 时的函数极限（参见 [[函数的极限]]），垂直渐近线对应 [[无穷间断点]]（函数在某点单侧或两侧趋于无穷，即 [[极点]]）。

本页汇总手册中三处讨论渐近线的内容：3.6.1 节（平面曲线的一般定义与求法）、2.4 节（有理函数图像）与 3.5.2 节（双曲线）。

## 三种求法（3.6.1 节）

### 参数形式 $x=x(t),\ y=y(t)$（式 3.515）

先确定使 $t\to t_i$ 时 $x(t)\to\pm\infty$ 或 $y(t)\to\pm\infty$（或两者）的值 $t_i$：

- a) $x(t)\to\infty$ 而 $y(t_i)=a\neq\infty$：水平渐近线 $y=a$；
- b) $y(t)\to\infty$ 而 $x(t_i)=a\neq\infty$：垂直渐近线 $x=a$；
- c) 两者都趋向 $\pm\infty$：计算 $k=\lim\limits_{t\to t_i}\dfrac{y(t)}{x(t)}$ 与 $b=\lim\limits_{t\to t_i}[y(t)-kx(t)]$，若两者都存在，则渐近线为 $y=kx+b$。

### 显式 $y=f(x)$（式 3.516）

垂直渐近线位于 $f(x)$ 的无穷跳跃间断点处；水平渐近线和斜渐近线具有方程 $y=kx+b$，其中

$$k=\lim_{x\to\infty}\frac{f(x)}{x},\qquad b=\lim_{x\to\infty}[f(x)-kx].$$

### 隐式多项式 $F(x,y)=0$（式 3.517–3.519）

1. 水平/垂直渐近线：从多项式表达式中选取最高次项，分离为函数 $\varPhi(x,y)$，对 $y$（或 $x$）求解方程 $\varPhi(x,y)=0$ 得 $x=\varphi(y)$、$y=\psi(x)$（式 3.517）；$x\to\infty$ 时 $y_1=\lim\psi(x)$（若极限存在）给出水平渐近线 $y=a$，$y\to\infty$ 时 $x_1=\lim\varphi(y)$ 给出垂直渐近线 $x=b$。（构成句在源文中符号脱落，见 [[式3-517前Φ构成句符号脱落]]。）
2. 斜渐近线：将 $y=kx+b$ 代入 $F$，按 $x$ 的幂次排列：
   $$F(x,kx+b)\equiv f_1(k,b)x^m+f_2(k,b)x^{m-1}+\cdots\tag{3.518}$$
   从方程
   $$f_1(k,b)=0,\qquad f_2(k,b)=0\tag{3.519}$$
   解出参数 $k$、$b$（如果它们存在）。

### 算例（均已复核）

- $x=\dfrac{m}{\cos t},\ y=n(\tan t-t)$，$t_1=\dfrac{\pi}{2},\ t_2=-\dfrac{\pi}{2}$：$k=\dfrac{m}{n}$ 的倒数关系即 $k=\dfrac nm$，$b=-\dfrac{n\pi}{2}$，渐近线 $y=\dfrac nm x-\dfrac{n\pi}{2}$；第二条类似地得 $y=-\dfrac nm x+\dfrac{n\pi}{2}$。
- [[笛卡儿叶形线]] $x^3+y^3-3axy=0$：渐近线 $y=-x-a$。

> 详见 [[渐近线三法与两算例]]。渐近线是曲线一般讨论流程的第 g) 步（见 [[显式曲线作图流程]]、[[隐式曲线讨论流程]]）。

## 有理函数的渐近线（2.4 节）

在手册 2.4 节（[[10-数学手册原书第10版--7-24-有理函数--1pptax7]]）中，渐近线是贯穿全部五类有理函数的首要图像要素（本节出现的均为垂直渐近线与水平渐近线两类）：

| 函数族 | 渐近线 |
|---|---|
| 反比 y = a/x | 两条坐标轴 |
| 线性分式函数（式 2.46） | x = −b₂/a₂ 与 y = a₁/a₂ |
| 第I类三次曲线（式 2.47） | x = 0 与 y = a |
| 第II类三次曲线（式 2.48） | x 轴（另有对称轴 x = −b/(2a)，非渐近线；垂直渐近线视 Δ 而定） |
| 第III类三次曲线（式 2.49） | x 轴（垂直渐近线视 Δ 而定） |
| 倒数幂 y = a/xⁿ | 两条坐标轴 |

从该节可归纳的规律：分母的零点及其重数决定垂直渐近线与间断点类型；x → ±∞ 时分子与分母的次数之差决定水平渐近线（次数相等时为首项系数之比，分子次数更低时为 y = 0）。这一判别框架与 2.1.5 的极点重数判据直接衔接。

## 双曲线的渐近线（3.5.2 节）

在手册 3.5.2 节（平面解析几何）中，渐近线指 |x| → ∞ 时被 [[双曲线]] 的两支无限趋近的直线。双曲线 x²/a² − y²/b² = 1 的渐近线为

```
y = ±(b/a)·x    （斜率 k = ±tan δ = ±b/a）    (3.335)
```

### 切线与渐近线的度量性质

该节给出三条与渐近线相关的面积/中点性质（均属双曲线自身的命题）：

1. 切线被渐近线截出的**切线段 TT₁ 以切点 P 为中点**（TP = T₁P）；
2. 对任何切点，切线与渐近线之间的三角形 TOT₁ 面积恒为 **S_TOT₁ = ab**（3.336）；
3. 对任何切点 P，由渐近线和两条过 P 且平行于渐近线的直线确定的平行四边形 OFPG 面积恒为 **S_OFPG = ab/2**（3.337）。

### 共轭双曲线与等边双曲线

- 共轭双曲线（3.338）共享同一对渐近线；
- **等边双曲线** x² − y² = a² 的渐近线 y = ±x 互相垂直；以渐近线为坐标轴时，其方程为 xy = a²/2（3.342b）。
