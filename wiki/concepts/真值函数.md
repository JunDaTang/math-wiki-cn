# 真值函数

真值函数是对每个（n 元）真值组指派一个真值（T 或 F）的函数。每个含 n 个命题变量的公式确定一个 n 位（n 项）真值函数；对公式中变量的每个解释即一组真值指派，依 [[concepts/真值表]] 可算出公式的真值。

**计数结果**：存在 2^(2^n) 个 n 位真值函数；特别地，二元真值函数共 16 个（转写中计数句两处「n」字脱落）。

**表示（函数完备性）**：每个真值函数都可以表示为命题逻辑中一个适当公式的真值表——依据 (5.17) 消去蕴涵与等价、再用德摩根法则 (5.14)，仅 {¬,∨} 或 {¬,∧} 即可表示每个公式；进一步，[[concepts/谢费尔函数]]（NAND）与 [[concepts/皮尔斯函数]]（NOR）各自单独完备。

原书将真值函数与布尔函数相联系（参见 5.7.5，页 530，未入库；见 [[queries/5-7与5-9-1等未入库对5-1节的依赖缺口]]）。相关发现见 [[findings/真值函数计数与NAND-NOR真值表]]。
