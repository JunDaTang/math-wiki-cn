# 后方交会法

后方交会法是三角测量的第二基本问题：通过三个已知点 A、B、C 确定待定点 N——在 N 处向已知点测角，而不是在已知点处向 N 测角。已知三点的坐标，所测 N 处的 $\delta_1, \delta_2$，所求 $y_N, x_N$。本源给出两个变体：

**斯涅耳问题**（式 3.112a–o，图 3.44）：经辅助角 $\varphi, \psi$ 解算。第一条件为内角和式 (3.112f)：$(\varphi+\psi)/2 = 180^\circ - (\gamma+\delta_1+\delta_2)/2$；第二条件来自正切半角恒等式 (2.115)(2.116)（3.3 节，未摄入），结合 [[concepts/正弦定律]] (3.112h) 导出 $\tan\frac{\varphi-\psi}{2} = \tan\frac{\varphi+\psi}{2}\cdot\frac{b\sin\delta_1 - a\sin\delta_2}{b\sin\delta_1 + a\sin\delta_2}$ (3.112i)；解出 $\varphi, \psi$ 后求 $s_{AN}, s_{B N}, s_{CN}$ 与坐标，并从 A、B 两端复算 (3.112n–o)。见 [[findings/斯涅耳后方交会解算]]。

**卡西尼法**（式 3.113a–h，图 3.45）：用到两个参考点 P、Q，它们分别位于穿过 A、C、P 与 B、C、Q 的参考圆上；圆 $H_1$、$H_2$ 的中心分别是 $\overline{AC}$、$\overline{BC}$ 的中垂线与线段 PC、QC 的交点；在 N 处所测的 $\delta_1, \delta_2$ 也作为圆周角出现在 P 和 Q 处。由 P、Q 定直线后求交点得 N。其失效条件为危险圆，见 [[concepts/危险圆]]；公式疑点见 [[queries/卡西尼法式3-113符号与cot是否转写有误]] 与 [[findings/卡西尼后方交会与危险圆]]。
