# 集合

集合是由某些原因归在一起的某些不同的事物（个体、观念等）的总体，这些个体称为集合的**元素**。集论的基本概念是**从属关系**：用 $a \in A$ 表示「$a$ 是 $A$ 的一个元素」，$a \notin A$ 表示「$a$ 不是 $A$ 的一个元素」。集论由 [[entities/georg-cantor]]（1845–1918）创立。

集合的给出方式有两种：

1. **列举**：在花括号中列出其元素，如 $M = \{a, b, c\}$ 或 $U = \{1, 2, 3, \dots\}$；
2. **性质刻画**：借助恰由该集合的元素所满足的规定性质，如奇自然数集 $U = \{x \mid x \text{ 是奇自然数}\}$。

对数集，本书采用标准记号 ℕ、ℤ、ℚ、ℝ、ℂ（见 [[entities/数集记号]]）。

元素的归属完全由外延性原则决定（见 [[concepts/外延性原则]]）：$\{3, 1, 3, 7, 2\}$ 与 $\{1, 2, 3, 7\}$ 是同一集合，即一个集合的每个元素仅「含有一次」，即使它被多次列举。由此派生的结构见 [[concepts/子集与真子集]]、[[concepts/空集]]、[[concepts/幂集]]。
