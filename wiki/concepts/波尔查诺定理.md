# 波尔查诺定理

波尔查诺定理是闭区间上连续函数的零点存在定理：若函数 $f(x)$ 在有限闭区间 $[a,b]$ 上连续且 $f(a)f(b)<0$（即区间两端点函数值异号），则该区间上至少有 $f(x)$ 的一个根——至少存在一个内点 $c$ 满足

```
f(c) = 0,   a < c < b.    (2.32)
```

定理以 Bernard Bolzano 命名（据公开可查的数学史背景，独立于本节内容；本手册仅以其名标注定理）。

## 几何意义

若连续函数的图像可以从 $x$ 轴的一侧走向另一侧，则曲线与 $x$ 轴至少有一个交点。

## 在定理族中的位置

- 对 $g(x)=f(x)-C$ 应用本定理即得 [[concepts/介值定理]]（式 2.33）（此为标准推导，非本节原文）。
- 本定理与 [[concepts/魏尔斯特拉斯定理]]、[[concepts/柯西收敛准则]] 同属实数完备性的等价现象家族（此归类为通行分析背景，非本节原文）。
- 定理条件为“有限闭区间 + 连续 + 端点异号”，各定理条件的对照见 [[comparisons/闭区间上连续函数定理比较]]。
