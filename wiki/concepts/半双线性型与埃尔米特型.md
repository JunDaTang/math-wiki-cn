# 半双线性型与埃尔米特型

半双线性型是复向量空间上替代双线性型的概念（据原书指认为文献 [5.6]）：由于在 $\mathbb{C}$ 上对称正定双线性型失效（$z^2$ 可为负），改用半双线性型定义酉点积以及距离和角。

## 定义（5.3.8.6.3）

映射 $f:V\times V\to\mathbb{C}$ 称为**半双线性型**，如果对每个 $v,v'\in V$、$u,u'\in V$ 和每个 $k\in\mathbb{C}$：

```latex
f(u+u', v) = f(u,v) + f(u',v)     f(ku, v) = k f(u,v)
f(u, v+v') = f(u,v) + f(u,v')     f(u, kv) = k* f(u,v)     % 式 5.212
```

其中 $k^*$ 表示 $k$ 的复共轭函数（原文作「共辄」，为「共轭」之讹）。即 $f$ 对第一个自变量是线性的，而对第二个自变量是「半线性的」（共轭线性）。

## 埃尔米特型

半双线性型 $f:V\times V\to\mathbb{C}$ 称为**埃尔米特的**，如果对每个 $v,v'\in V$，

$$f(v,v') = f(v',v)^*$$

（「对称性」在复情形的对应物。）于是（酉）点积可以通过**埃尔米特正定半双线性型**来刻画；$\mathbb{C}^n$ 中标准酉点积定义为 $f(u,v)=u^{\mathrm T}v^*$。

## 矩阵表示

如果 $V$ 有限维且 $B=(b_1,\dots,b_n)$ 是一组基，那么 $A_B(f)=(f(b_i,b_j))_{i,j}$ 是 $f$ 对于基 $B$ 的表示矩阵，且

```latex
f(v, v') = v^T A_B(f) v'      % 式 5.213（疑脱落 v' 的共轭星号，应为 v^T A_B(f) v'*）
```

表示矩阵是埃尔米特的，当且仅当半双线性型是埃尔米特的。式 (5.213) 原文未带共轭星号，与式 (5.212) 的半线性条件矛盾，见 [[queries/式5-213是否脱落共轭星号]]。

## 约定注记（重要）

本手册取「**第一自变量线性、第二自变量半线性**」的约定（配 $f(u,v)=u^{\mathrm T}v^*$），这与数学界常见的「第一共轭线性」约定以及物理 bra-ket 记号的约定不同；跨页、跨资料引用时必须显式标注本手册口径，见 [[queries/半双线性型自变量线性约定之归属]] 与 [[comparisons/双线性型与半双线性型比较]]。构造表示矩阵的操作规程见 [[methodology/由基构造双线性型表示矩阵流程]]；命题组见 [[findings/半双线性型埃尔米特型与矩阵表示]]。
