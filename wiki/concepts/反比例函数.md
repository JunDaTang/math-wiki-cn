# 反比例函数

反比例函数是形如

```latex
y = a/x    (a ≠ 0)    (2.45)
```

的有理函数；手册 2.4.1 称之为「反比」（小节标题为「特殊的分式线性函数(反比)」）。其图像是一条以两条坐标轴为 [[concepts/渐近线]]、中心在原点的 [[concepts/等轴双曲线]]：a > 0 时两支位于一、三象限，a < 0 时位于二、四象限。

关键性质（详见 [[findings/反比函数的等轴双曲线要素]]）：

- 间断点 x = 0（[[concepts/无穷间断点]]），此处 y = ±∞；
- a > 0 时在 (−∞, 0) 与 (0, +∞) 上均严格单调递减；a < 0 时均严格单调递增（参见 [[concepts/单调函数]]）；
- 顶点：a > 0 时为 (√a, √a) 与 (−√a, −√a)；a < 0 时为 (−√|a|, √|a|) 与 (√|a|, −√|a|)；
- 无极值。

它是 [[concepts/线性分式函数]]（式 2.46）平移中心后的基准形（参数对应 a ↦ −Δ/a₂²），也是 [[concepts/倒数幂]] 在 n = 1 时的特例。手册注明关于双曲线的更详细说明见第 271 页 3.5.2.9（该节尚未采集）。与 [[concepts/正比例函数]] y = ax 构成「反比—正比」的对偶。
