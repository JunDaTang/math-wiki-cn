# 分配问题（产品—机器分配）

分配问题是《数学手册》(原书第10版) 18.1.4.3 定义的一类生产安排问题：$m$ 种产品 $E_1,\dots,E_m$ 各需生产数量 $a_1,\dots,a_m$；每一种产品可以在 $n$ 台机器 $M_1,\dots,M_n$ 的任一台上生产，在机器 $M_j$ 上生产一件产品 $E_i$ 需耗时 $b_{ij}$、成本 $c_{ij}$；机器 $M_j$ 的时间容量为 $b_j$。以 $x_{ij}$ 表示机器 $M_j$ 生产产品 $E_i$ 的数量，求总生产成本最小的安排。注意与 18.1.4.2「配置问题」（通行指派问题）区分：二者中文名近同而模型迥异（见 [[queries/配置与分配译名冲突之辨]]）。

## 模型

```latex
% (18.30a)（原文如此；CT 两行求和上限 m/n 疑互换，见 queries/18-30求和上限互换之辨；
% 原文另有标签「(18.3Gb)」，应为 (18.30b)）
OF: f(x) = \sum_{i=1}^{m}\sum_{j=1}^{n} c_{ij}x_{ij} = min!
CT: \sum_{j=1}^{m} x_{ij} = a_i  (i=1,\dots,m),
    \sum_{i=1}^{n} b_{ij}x_{ij} <= b_j  (j=1,\dots,n),  x_{ij} >= 0, ∀i,j
```

## 与运输问题的关系

分配问题是[[concepts/运输问题|运输问题]]的推广：行约束仍为等式（产量 $\sum_j x_{ij}=a_i$），但列约束由「列和等于 $b_j$」推广为带系数 $b_{ij}$ 的时间容量不等式 $\sum_i b_{ij}x_{ij}\leqslant b_j$。它可以用单纯形法求解；如果所有 $b_{ij}=1$，则可以在引入虚构产品 $E_{m+1}$ 后使用更有效的运输算法（原文以「参见第 1194/1195 页 18.1.4.1」回指平衡化与运输算法，页码格式残缺，见 [[queries/18-1-4全节系统性转写讹误清单]]）。
