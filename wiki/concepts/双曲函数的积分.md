# 双曲函数的积分

**双曲函数的积分**指被积函数含有 $\sinh x,\ \cosh x,\ \tanh x,\ \coth x$ 的不定积分（数学手册(原书第10版) 8.1.6.2，[[sources/10-数学手册原书第10版--11-816-超越函数的积分--12iqp2r]]）。原书给出两条计算路线；本小节无编号公式，均为文字陈述。

## 路线一：化为指数函数的积分

原文：「双曲函数的积分……若双曲函数能用相应的指数函数来代替，则可利用指数函数的积分来计算。」

背景补充（独立可验证的数学事实，非本节原文）：$\sinh x = \frac{\mathrm{e}^{x}-\mathrm{e}^{-x}}{2}$、$\cosh x = \frac{\mathrm{e}^{x}+\mathrm{e}^{-x}}{2}$、$\tanh x = \frac{\mathrm{e}^{x}-\mathrm{e}^{-x}}{\mathrm{e}^{x}+\mathrm{e}^{-x}}$、$\coth x = \frac{\mathrm{e}^{x}+\mathrm{e}^{-x}}{\mathrm{e}^{x}-\mathrm{e}^{-x}}$，即四个双曲函数都是 $\mathrm{e}^{x}$ 与 $\mathrm{e}^{-x}$ 的有理函数。因此「能代替」的条件几乎恒成立——原书的条件式措辞疑为翻译保留原文的谨慎表述。代换后即进入 [[concepts/指数函数的有理化双代换]] 的流程。

## 路线二：与三角函数积分类比

原文：对最常见的积分

$$\int \sinh^{n} x\,\mathrm{d}x,\qquad \int \cosh^{n} x\,\mathrm{d}x,\qquad \int \sinh^{n} x\,\cosh^{m} x\,\mathrm{d}x$$

「可用与三角函数积分类似的方法进行计算」（回指第 654 页 8.1.5「三角函数的积分」，该节尚未入库，类比基础暂无法交叉验证）。
