# σ-代数与测度

σ-代数（集代数）是定义在任意集合 X 上的一组非空子集族 𝒜，要求对补集与可数并封闭；测度是定义在 σ-代数上、取值于 ℝ̄₊ = ℝ₊ ∪ {+∞} 的集函数，满足非负性、零空集与 σ-可加性三条公理。二者合成测度空间 (X, 𝒜, μ)，是全部测度论与勒贝格积分理论的公理起点。

## σ-代数公理 (12.207)

- a) A ∈ 𝒜 ⟹ X\A ∈ 𝒜
- b) A₁, A₂, … ∈ 𝒜 ⟹ ⋃_{n=1}^∞ A_n ∈ 𝒜

## 测度公理 (12.208)

μ: 𝒜 → ℝ̄₊ 满足：

- a) μ(A) ⩾ 0, ∀A ∈ 𝒜
- b) μ(∅) = 0
- c) A_k ∩ A_ℓ = ∅ (k ≠ ℓ) ⟹ μ(⋃_{n=1}^∞ A_n) = Σ_{n=1}^∞ μ(A_n)（σ-可加性）

三重组 (X, 𝒜, μ) 称作测度空间，𝒜 中的集合称作可测集（或 μ-可测集）。

## 由公理直接导出的性质

- 单调性：A, B ∈ 𝒜, A ⊂ B ⟹ μ(A) ⩽ μ(B)
- （下方）连续性：A₁ ⊂ A₂ ⊂ … ⟹ μ(⋃_{n=1}^∞ A_n) = lim_{n→∞} μ(A_n)

## 例 A：计数测度

设有穷集 {x₁, …, x_N} 的所有子集构成 σ-代数，并对每个 x_k 指定非负数 p_k。对 A = {x_{n₁}, …, x_{n_k}} 令 μ(A) = p_{n₁} + … + p_{n_k}，则 μ 是只取有穷多个值的测度（μ(X) = Σp_k < ∞），称作计数测度。
