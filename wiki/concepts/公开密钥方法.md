# 公开密钥方法（非对称密码）

公开密钥方法是为克服对称体制三点不足（密钥保密压力、须预经安全信道交换密钥、无法向第三方证实发件人）而建立的非对称密码框架。用公开密钥加密的概念由迪菲 (Diffie) 与赫尔曼 (Hellman) 于 1976 年提出（本源 5.5.7.1；该小节标题为「迪菲赫尔曼密钥交换」，但内容是公钥加密概念与电子签名流程，并未给出 DH 密钥交换协议本身，见 [[queries/5-5-7-1标题密钥交换与内容不符]]）。

## 密钥结构与四条件

每个参与者 i 拥有两个密钥：公布在一般容易接受的寄存器中的**公开密钥 KP_i**（控制加密步骤 E_i），和只有参与者本人知道并绝对保密的**私人密钥 KS_i**（控制解密步骤 D_i）。下列条件必须满足：

1. D_i ∘ E_i 成恒等映射（接收者可解密）。
2. E_i 与 D_i 的有效实施方法是知道的。
3. 私人密钥 KS_i 不能由公开密钥 KP_i 在可预见的未来时日推出。
4. E_i ∘ D_i 也产生恒等映射（支撑电子签名）。

## 加密与电子签名

基本加密：A 从寄存器取 B 的公开密钥，计算 c = E_B(m) 并发送；B 以私人密钥恢复 D_B(c) = D_B(E_B(m)) = m。电子签名：A 先以私人密钥作 d = D_A(m)，附签名「A」后再以 E_B 对总体加密；B 解密得 (d,「A」)，据此证实 A 是发送者，并以 E_A(d) = E_A(D_A(m)) = m 复原消息（原文引号处转写为「Ω*A*Ω」等乱码）。完整流程见 [[methodology/电子签名与加密复合流程]]。

条件 (3) 的实现依赖 [[concepts/陷门单向函数]]；最普及的实例是 [[entities/rsa方法]]。与对称体制的逐项对照见 [[comparisons/对称与非对称密码体制比较]]。
