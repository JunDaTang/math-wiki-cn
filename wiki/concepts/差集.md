# 差集

两个集合 $A$、$B$ 的**差集或差** $A \backslash B$ 是 $A$ 的不属于 $B$ 的元素的集合：

$$A \backslash B = \{x \mid x \in A \land x \notin B\} \tag{5.64a}$$

如果 $A$ 由性质 $E_1$、$B$ 由性质 $E_2$ 定义，那么 $A \backslash B$ 含有具有性质 $E_1$ 但不具有性质 $E_2$ 的元素。

![图 5.5 差集](media/10-数学手册原书第10版--5-52-集论--1emkee6/005-4d991b4aa911e9b6771879fdeb74b1811b631b01d9a7e3aa205e8dc34d975cff.jpg)

**例**（已核对）：$\{1, 2, 3, 4\} \backslash \{3, 4, 5\} = \{1, 2\}$。

差集是构造 [[concepts/对称差]] 的原料：$A \triangle B = (A \backslash B) \cup (B \backslash A)$（式 5.64c）。补集（[[concepts/并集交集与补集]]）可视为以基本集为全域的差。公式组与算例记录见 [[findings/差对称差与笛卡儿积公式组]]。
