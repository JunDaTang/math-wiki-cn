# 圆锥曲线

圆锥曲线（二次曲线）是由一般二次方程

```
ax² + 2bxy + cy² + 2dx + 2ey + f = 0    (3.353a)
```

所定义的曲线族：椭圆（其特殊情形为圆）、双曲线、抛物线，以及退化为两条直线的奇异情形。注意 (3.353a) 中的系数并非各特殊圆锥曲线的参数（a、b 此处是一般方程系数，不是椭圆/双曲线的半轴）。

本节给出圆锥曲线的三种等价刻画：

1. **代数刻画**：一般二次方程 + [[concepts/二次曲线不变量]]（Δ、δ、S）分类（表 3.19/3.20），化简流程见 [[methodology/二次曲线一般方程化简流程]]。
2. **圆锥截线刻画**：对顶直圆锥被平面所截即得圆锥曲线；平面不过顶点时，按平面平行于两条/一条/零条母线分别得双曲线、抛物线、椭圆；平面过顶点时得奇异圆锥曲线（Δ = 0）；圆柱（顶点在无穷远的圆锥）的截线是平行线。
3. **焦点-准线刻画**：到定点（焦点）的距离与到定直线（准线）的距离之比为常数 e 的点的轨迹，e<1 椭圆、e=1 抛物线、e>1 双曲线（见 [[concepts/数值离心率]]、[[concepts/准线]]）。

其他一般性质：**过平面上五个给定的点有且仅有一条二次曲线**（若三点共线则为奇异/退化圆锥曲线）；统一极坐标方程 ρ = p/(1 + e cos φ)（3.354，极点在焦点、极轴指向较近顶点；对双曲线只定义一支）。详见 [[findings/圆锥曲线统一定义与极坐标方程]] 与 [[findings/二次曲线不变量分类与化简流程]]。
