# 黄金分割

黄金分割是把一条线段分为两段的一种分割比，使整段、较长段与较短段之间保持同一比例关系——把线段 a 分成两部分 x 与 a−x，使较短部分与较长部分之比等于较长部分与整个线段之比。《数学手册(原书第10版)》多处涉及它：

- **1.1.1（数）**：三次以之为例证——二次无理数（1.1.1.2）、连分数表示（1.1.1.4 例 B）、不可公度（1.1.1.5）。
- **3.1.5.3（平面上的多边形）**：在正五边形语境下给出实质论断——正五边形对角线与边之比正是这一比例，其连分数展开与该书 1.1.1.4 第 3 点中的黄金分割完全相同，即它导致一个无理数。
- **3.5.2（平面解析几何）**：给出正式定义、公式（式 3.298）与几何作图（图 3.133(a)），并给出正十边形边长与黄金矩形两点推论；正式定义位于 3.5.2.3（第 260 页，前向引用所指）。

## 定义与表述

| 出处 | 表述 |
| --- | --- |
| 1.1.1（数） | 把一条线段分为两段的比例关系 x/a = (a−x)/x |
| 3.1.5.3（平面上的多边形，正五边形语境） | 由比例关系 a₀:a₁ = a₁:(a₀ − a₁) 所确定的分割比：整体与较大部分之比等于较大部分与较小部分之比 |
| 3.5.2（平面解析几何；正式定义位于其 3.5.2.3 小节，第 260 页，前向引用所指） | 把线段 a 分成两部分 x 与 a−x，使较短部分与较长部分之比等于较长部分与整个线段之比（公式组见“方程与解”）；该定义为裁决两种表述取向及下文数值矛盾的关键 |

注意两种比例式取向相反、互为倒数：1.1.1 与 3.5.2 的方程给出 0.618…，3.1.5.3 的“整体与较大部分之比”则为 1.618…（见下文“数值取向与内部矛盾”）。

## 方程与解

当 a = 1 时，x/a = (a−x)/x 导出方程

```latex
x^{2} + x - 1 = 0,  解 x = \frac{\sqrt{5}-1}{2} \approx 0.618
```

该解是一个[[二次无理数]]，包含无理数 √5。

3.5.2 对线段 a 给出公式组：

```
x/a = (a−x)/x                (3.298a)
x = √(a(a−x))  （x 是 a 与 a−x 的几何平均）   (3.298b)
x = a(√5 − 1)/2 ≈ 0.618·a    (3.298c)
```

## 3.5.2（平面解析几何）中的作图与推论

在上述定义与公式（式 3.298）之外，3.5.2 还指出：x 可由几何作图给出（原书图 3.133(a)），并有两点推论（均经分析复算验证，见 [[黄金分割公式与正十边形边长]]）：

1. 线段 x 也是**外接圆半径为 a 的正十边形的边长**（= 2a·sin 18°；原书此处交叉引用 3.1.5.3，即 [[正凸多]] 所在节——见 [[正凸多边形]]）。
2. **黄金矩形**问题——求矩形边长 a 与 a−x，使面积 a(a−x) 等于以 x 为边长的正方形面积 x²——导致同一二次方程。

相邻主题：[[定比分割]]、[[调和分割]]。

## 在 1.1.1 节的三次出现

1. **1.1.1.2**：作为二次无理数的例（方程与解如上；3.1.5 的跨章引用亦指向此处——无理数，涉及希帕索斯的传说性归因）。
2. **1.1.1.4 例 B**：作为连分数表示的例——手册称黄金分割公式可由 x = a[1;1,1,…] 与 x = (a/2)(1+√5) = (a/2)(1+[2;4,4,4,…]) 表示；第一个表示式 α₄ 精确度为 0.018a，第二个达 0.000001a。
3. **1.1.1.5**：作为不可公度的例——黄金分割线段之比含 √5，故不可公度（见 [[可公度性]]），推及正五边形边与对角线。

## 连分数性质

- 数 [1;1,1,…] 是收敛最差的连分数（部分商全为 1，见 [[连分数部分商全为1时收敛最慢]]）。
- [2;4,4,4,…] = √5。

此二者即 1.1.1.4 例 B 中出现的两个展开。

## 正五边形中的黄金分割（3.1.5.3）

3.1.5.3 在正五边形语境下给出实质论断：正五边形对角线与边之比正是这一比例，其连分数展开与该书 1.1.1.4 第 3 点中的黄金分割完全相同，即它导致一个无理数。（“第 3 点”与 1.1.1 节自编的“例 B”是否同一处，待核。1.1.1.5 亦从不可公度的角度推及正五边形边与对角线，见上文。）

### 几何来源

正五边形的对角线构成内接 [[五角星形]]，五角星形的边围成更小的正五边形，嵌套序列 a₀, a₁, a₂ = a₀ − a₁, a₃ = a₁ − a₂, ……保持同一比例（见 [[正五边形对角线与边不可公度]]）。由 [[欧几里得算法]] 商恒为 1、永不终止可知该比不可有理化——商序列全为 1 正对应其连分数展开中各项恒为 1。

> [!info] 可独立验证的背景知识
> 该比值即黄金比 (1 + √5)/2 ≈ 1.6180…，其连分数展开为 [1; 1, 1, 1, …]。

## 数值取向与内部矛盾（勘误候选）

[1;1,1,…] = φ ≈ 1.618 与方程解 (√5−1)/2 ≈ 0.618 互为倒数，相差因子 φ：手册 1.1.1.4 例 B 的取值与 1.1.1.2 的方程解不符（例 B 数值自身自洽，疑将“整段”与“大段”角色调换，或原书/译文之误）。如“定义与表述”所述，各节的比例式本身即取相反取向：3.1.5.3 的整体与较大部分之比（≈ 1.618）与连分数 [1;1,1,…] 的值一致，而 1.1.1.2 的方程解为其倒数（≈ 0.618）。裁决关键为 3.5.2.3 的正式定义：式 3.298c 给出 x = a(√5−1)/2 ≈ 0.618·a，与 1.1.1.2 的方程解同取 0.618 取向。详见 [[黄金分割连分数示例与方程解相差因子φ]] 与 [[黄金分割连分数示例取值矛盾]]。
