# Z变换表

**Z变换表**是《数学手册(原书第10版)》21.15 节所载的结构化公式表：31 条变换对排为四列「编号／原始序列 $f_n$／变换 $F(z)=Z(f_n)$／收敛域」，每条构成「序列—变换—收敛域」三元组；全节无正文推导，表前仅一行将定义、计算法则与逆变换回指 15.4.1.2／15.4.1.3／15.4.1.5。全表逐字转录见 [[sources/10-数学手册原书第10版--8-2115-z变换--1rzu5i4]]，变换之数学内容见 [[concepts/Z变换]]。

## 结构特征

- 编号 1–31 连续，无脱落、无行缺位（[[findings/21-15Z变换全表级数复算]]）。
- 收敛域（ROC）列在本项目已处理的第 21 章各表中首次出现，分极点型 $\|z\|>\|a\|$（含 $\max$ 复合）与整函数型 $\|z\|>0$（条目 8、12、21、30、31）两族。
- 条目按「基序列 → 乘 $a^n$ 或 $e^{an}$ 推广 → 特化与极限」组织，形成互证网络（见下）。

## 条目族结构网络

| 关系 | 条目 | 机制 |
|---|---|---|
| 尺度代换 $z\to z/a$ | 3/4 → 9/10；17/18 → 19/20 | 序列乘 $a^n$ |
| 尺度代换 $z\to z/e^{a}$ | 13/14 → 15/16 | 序列乘 $e^{an}$ |
| 参数特化 | 2 = 7（$a=-1$）；6 = 7（参数取 $e^{a}$）；25 = 14（$b=\pi/2$） | 直接代入 |
| 极限退化 | 26 = 27（$b\to a$） | 洛必达，序列与变换两侧极限一致 |
| 奇指标族 | 22/23/24 | 同支架 $f_{2n+1}=2(2n+1)^{p}$，$p=0,+1,-1$ |
| 代换归约 | 30/31 | $t=1/\sqrt z$ 化归 $\frac{\sin t}{t}$、$\cos t$ 级数 |
| 组合归约 | 28 → 11 族 | $\binom{n+1}{3}=\binom n3+\binom n2$ |

各关系之复算见 [[findings/21-15条目族结构与特化退化复算]]。

## Eulerian 数之出现（复算中辨识）

条目 3/4/5 之分子依次为 $z$、$z(z+1)$、$z(z^{2}+4z+1)$，其系数

$$1;\quad 1,\,1;\quad 1,\,4,\,1$$

为 Eulerian 数（Eulerian 多项式 $A_1=1$、$A_2=1+x$、$A_3=1+4x+x^{2}$ 之系数），由恒等式 $\sum_{n\ge1}n^{m}x^{n}=\frac{xA_m(x)}{(1-x)^{m+1}}$ 取 $x=1/z$ 而来。注意：此为排列数型之 Eulerian 数，**非** 21.5 节之 Euler 数，两者不得混同（参见 [[concepts/伯努利数与欧拉数（手册紧缩编号约定）]]）。

## 体例位置

与 [[concepts/定积分表]]、[[concepts/不定积分表]] 同位同格，为第 21 章表格序列之一；且是库内首个「变换表」类小节，把已入库的第 21 章表格类型谱扩充为：单位表（21.4）→ 级数表（21.5–21.6）→ 积分表（21.7–21.9）→ 函数值表（21.10–21.11）→ 变换表（21.15）。

## 已知讹误

条目 24 变换列 $\ln\frac{z-1}{z+1}$ 与其序列之级数 $\ln\frac{z+1}{z-1}$ 互为相反数，为全表唯一不符项：见 [[findings/条目24变换与级数展开不符复算]]、[[queries/条目24对数变换分子分母倒置之辨]]、[[comparisons/条目24与29对数型变换符号比较]]。
