# 双曲余切函数

**双曲余切函数** coth x 是六个 [[concepts/双曲函数]] 之一，定义为 [[concepts/双曲正切函数]] 的倒数：

$$
\coth x = \frac {1}{\tanh x} = \frac {\mathrm{e} ^ {x} + \mathrm{e} ^ {- x}}{\mathrm{e} ^ {x} - \mathrm{e} ^ {- x}}.\tag{2.169}
$$

## 图像性质（手册 2.9.2.4，图 2.52）

- y = coth x 为**奇函数**：coth(−x) = −coth x（式 2.181）。
- **在 x = 0 处不连续**（手册未按 2.1.5 的分类命名间断点类型；按该分类属无穷间断/极点，此为推断，参见 [[concepts/间断点]]、[[concepts/无穷间断点]]）。
- **单调性**：当 −∞ < x < 0 时，函数从 −1 到 −∞ 严格单调递减；当 0 < x < +∞ 时，函数从 +∞ 到 1 严格单调递减（两支均严格递减）。
- **无拐点和极值**。
- **渐近线**为 x = 0（竖直）和 y = ±1（水平）——手册设有图像小节的四个双曲函数中唯一具有竖直渐近线者。

## 在公式体系中的位置

- 基本恒等式：coth²x − csch²x = 1（式 2.173）。
- 加法定理：coth(x ± y) = (1 ± coth x coth y)/(coth x ± coth y)（式 2.185）——分子的构成与次序和三角 cot(x±y) = (cot x cot y ∓ 1)/(cot x ± cot y) 均不同。
- 倍角：coth 2x = (1 + coth²x)/(2 coth x)（式 2.189）。
- 半角：coth(x/2) = sinh x/(cosh x − 1) = (cosh x + 1)/sinh x（式 2.194）。
- 复角关系：coth z = i cot iz（式 2.206；原文「icot」疑为「i cot」粘连）。

完整公式体系见 [[concepts/双曲恒等式]]。

## 与 [[concepts/余切函数]] 的对照

二者同为奇函数且在各支上递减，但性质不可互换：cot 周期 π、渐近线为竖直 x = kπ；coth 非周期、除竖直渐近线 x = 0 外还有水平渐近线 y = ±1，且由单调区间端点可知 coth x > 1（x > 0）、coth x < −1（x < 0）。系统性符号差异见 [[comparisons/双曲函数与三角函数比较]]。
