# 广田方程

**广田方程**（Hirota 方程，9.2.5.5.4）为

```latex
u_t + i 3α |u|^2 u_x + β u_{xx} + i σ u_{xxx} + δ |u|^2 u = 0,   αβ = σδ     (9.177)
```

其中参数满足约束 αβ = σδ。它列于「更多具有孤子解的非线性发展方程」目录中，统一地容纳 KdV 型与 NLS 型动力学。

## 转写疑点：i 的位置

按转写形式，NLS 极限（α = σ = 0）给出**实系数**方程 u_t + βu_{xx} + δ|u|²u = 0，不支持包络孤子，与本节标题「具有孤子解」矛盾。标准文献中虚单位 i 应落在 u_t 项（或经实时间重标后落在 u_{xx}、|u|²u 项上）。约束 αβ = σδ 的正确性亦待与德文原书核对。详见 [[queries/式9-177广田方程i的位置与参数约束]] 与 [[findings/式9-172至9-179附加七方程复算]]（该项复算置信度为 medium）。修正终裁前，(9.177) 不宜作为可积性陈述的引用源。
