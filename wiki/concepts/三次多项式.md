# 三次多项式

三次多项式（三次函数）是形如

$$y = a x^{3} + b x^{2} + c x + d \tag{2.42}$$

的三次整有理函数，其图像称为**三次抛物线**（《数学手册(原书第10版)》2.3.3，图 2.13）。曲线形状与函数性质由 a 与「判别式」

$$\Delta = 3ac - b^2$$

共同决定。

## 形态二分（按 Δ）

- **Δ ≥ 0**：函数单调——a>0 单调递增，a<0 单调递减，无极值；
- **Δ < 0**：恰有一个局部极大值与一个局部极小值。a>0 时 y 由 $-\infty$ 增至极大、减至极小、再增至 $+\infty$；a<0 时由 $+\infty$ 减至极小、增至极大、再减至 $-\infty$。

**术语警示**：此 $\Delta = 3ac-b^2$ 不含 d，控制的是单调/极值形态，与 [[三次方程]] 求根意义下含 d 的根判别式（原文 1.6.3.2 式 1.156，见 [[三次方程判别式的三情形]]）不是同一对象，辨析见 [[三次多项式形态判别式与三次方程根判别式比较]] 与 [[三次多项式判别式与三次方程根判别式口径冲突]]。

## 与 x 轴的交点（实根）

交点为 y=0 时式 (2.42) 的实根，可能有 1、2（此时存在一点，x 轴在该点为曲线的切线，即二重根）或 3 个——与 1.6.3.2 三次方程判别式的三情形图像化对应。

## 关键点坐标

| 点 | x 坐标 | y 坐标 | 含义 |
|---|---|---|---|
| B | $0$ | $d$ | 与 y 轴交点 |
| C, D | $-\dfrac{b}{3a} \pm \dfrac{\sqrt{-\Delta}}{3a}$ | $\dfrac{d + 2b^{3} - 9abc \pm (6ac - 2b^{2})\sqrt{-\Delta}}{27a^{2}}$ | 极值点（Δ<0 时存在），± **同号配对** |
| E | $-\dfrac{b}{3a}$ | $\dfrac{2b^{3} - 9abc}{27a^{2}} + d$ | 拐点 = 曲线对称中心 |

E 处切线斜率 $\tan\varphi = \left(\dfrac{\mathrm{d}y}{\mathrm{d}x}\right)_E = \dfrac{\Delta}{3a}$。极值点关于拐点横坐标 $-\frac{b}{3a}$ 对称分布；原文将横坐标转写为 $-\frac{b \pm \sqrt{-\Delta}}{3a}$（负号在分式之外），该形式下须改为异号配对方能得到正确点对，歧义详见 [[三次极值点横坐标公式的负号位置是否转写有误]]。坐标公式已经数值与代数双重验证，见 [[三次多项式极值点与对称中心坐标公式]]。

## 在多项式谱系中的位置

三次多项式是 [[多项式]] 家族中 n = 3 的情形，符合 [[n次多项式]] 的奇次规律：端部行为异侧、至少一个 x 轴交点、极值 0 或 2 个（不超过 n−1 的偶数）、拐点恰 1 个（奇数）即 E。仅保留最高次项时即 [[n次抛物线]] $y = ax^3$（n=3，原点为对称中心）。
