# 期望值与不确定度

量子力学期望值 Ā 定义为对 N → ∞ 个全同系统测量结果的平均值，有三种等价表达（9.122）：频率极限、概率加权和波函数积分。不确定度 ΔA 借助标准误差定义，度量一般态中可观察量 A 的测量结果围绕 Ā 的分布宽度。

## 期望值（9.122）

```latex
\bar{A} = \lim_{N\to\infty}\frac{1}{N}\sum_i a_iN_i = \sum_i a_iW_i = \iiint_V \psi^{*}\hat{A}\psi\,\mathrm{d}V   % 9.122
```

- 期望值通常与任何单次可能的测量结果不同。
- 位置期望值的例子：x̄ = ∭x|ψ(r⃗,t)|²dV——说明波函数被解释为概率振幅，|ψ|² 为概率密度；dW = |ψ|²dV 即粒子在时刻 t 位于 r⃗ 处体积元 dV 中的概率（位置概率）。

## 不确定度（9.123–9.125）

```latex
(\Delta A)^{2} = \lim_{N\to\infty}\frac{1}{N}\sum_i N_i(a_i-\bar{A})^{2} = \sum_i W_i(a_i-\bar{A})^{2}                     % 9.123
(\Delta A)^{2} = \overline{(A-\bar{A})^{2}} = \overline{A^{2}}-\bar{A}^{2} = \iiint_V \psi^{*}(\hat{A}-\bar{A})^{2}\psi\,\mathrm{d}V   % 9.124
```

- 9.124 给出用离开平均值的根方偏差的期望值确定 ΔA 的方式（A²‾ − Ā² 的形式经复算 ✓）。
- 若系统处于 Â 的本征态 φᵢ，则所有测量给出相同值：Ā = aᵢ，ΔA = 0（9.125），期望值附近不出现分布。

两个可观察量能否同时具有零不确定度，取决于算子是否对易，见 [[concepts/不确定度关系]]。
