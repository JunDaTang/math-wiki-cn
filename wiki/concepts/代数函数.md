# 代数函数

**代数函数**（algebraic function）是这样一种函数：自变量与函数由一个代数（多项式）方程联系起来，该方程一般只能**隐式**地定义函数。《数学手册(原书第10版)》在两处阐述这一概念：实变量情形见 2.2.1，复变量情形见 14.5.1。在 2.2 的分类中，代数函数是初等函数的两大分支之一。

## 实变量情形（2.2.1）

依据《数学手册(原书第10版)》2.2.1（见 [[10-数学手册原书第10版--7-22-初等函数--slrafi]]），自变量 $x$ 和函数 $y$ 由如下代数方程联系起来：

$$
p_{0}(x) + p_{1}(x) y + p_{2}(x) y^{2} + \dots + p_{n}(x) y^{n} = 0,\tag{2.36}
$$

其中 $p_{0}, p_{1}, \cdots, p_{n}$ 是关于 $x$ 的多项式。

**示例**：$3xy^{3} - 4xy + x^{3} - 1 = 0$，即 $p_0(x) = x^3 - 1$，$p_1(x) = -4x$，$p_2(x) = 0$，$p_3(x) = 3x$。

### 最简代数函数的三个层级

手册指出："若能够解出关于 $y$ 的代数方程 (2.36)，则存在一个以下类型的最简代数函数。"

1. **多项式**（2.2.1.1，见 [[多项式]]）：仅对自变量 $x$ 作加、减、乘法运算；
2. **有理函数**（2.2.1.2，见 [[有理函数]]）：总能表示成两个多项式的比值；
3. **无理函数**（2.2.1.3）：除有理函数的运算外，自变量还可出现在开方符号中（开方运算对应 [[根]]）。

#### 无理函数（2.2.1.3）

手册给出的例子：

- $\mathbf{A}\colon y = \sqrt{2x + 3}$
- $\mathbf{B}\colon y = \sqrt[3]{(x^{2} - 1)\sqrt{x}}$

> 无理函数在手册 2.2.1.3 仅给出此两例，内容单薄，故作为本页小节收录，不单独建页。

## 复变量情形（14.5.1）

依据《数学手册(原书第10版)》14.5.1，代数函数是对自变量 $z$——也许还对有限多个常数——施行有限多次代数运算所得到的函数。与实情形一样，一个复代数函数 $w(z)$ 一般用一个多项式方程**隐式**定义（式 14.63）：

$$
a_1 z^{m_1} w^{n_1} + a_2 z^{m_2} w^{n_2} + \dots + a_k z^{m_k} w^{n_k} = 0,\tag{14.63}
$$

### 五个典型例子（式 14.64–14.68）

| 名称 | 表达式 | 式号 |
|---|---|---|
| 线性函数 | $w = az + b$ | (14.64) |
| 反函数（倒数） | $w = 1/z$ | (14.65) |
| 二次函数 | $w = z^2$ | (14.66) |
| 平方根函数 | $w = \sqrt{z^2 - a^2}$ | (14.67) |
| 分式线性函数 | $w = \dfrac{z + \mathrm{i}}{z - \mathrm{i}}$ | (14.68) |

每个例子都满足形如 (14.63) 的多项式方程，例如 $w = \sqrt{z^2 - a^2}$ 满足 $w^2 - (z^2 - a^2) = 0$，$w = (z+\mathrm{i})/(z-\mathrm{i})$ 满足 $(z-\mathrm{i})w - (z+\mathrm{i}) = 0$（复算见 [[式14-63至14-68代数函数定义与例转录复算]]）。

## 隐式定义与显式可解性

两处定义均为隐式，且都不保证函数总能显式解出：

- **实变量情形（2.2.1）**：定义 (2.36) 是隐式的，并不保证关于 $y$ 的方程总能显式解出。因此代数函数的外延严格大于多项式、有理函数、无理函数三层列举的并集——手册行文容易让读者误以为三层列举即为全部代数函数，实际上"最简代数函数"仅覆盖能解出显式表达式的部分。
- **复变量情形（14.5.1）**：源文明确指出，$w$ 不能被显式地表示的情况时有发生。

## 与其他概念的关系

### 与超越函数的对偶

- 在实变量框架（2.2）下，[[超越函数]]是与本概念对偶的分类：不能由形如 (2.36) 的代数方程得到的函数。
- 在复变量框架（14.5）下，源文以"代数函数 / 初等超越函数"二分法组织 14.5 节；与之相对，由 $e^z$ 出发定义的函数族（见 [[自然指数函数]]、[[复三角函数与双曲函数]]）属初等超越函数。

### 复变语境下的关联

- $w = 1/z$（式 14.65）此前已在本手册 14.2、14.3 中作为被积函数与洛朗展开对象出现（见 [[柯西积分公式]]、[[洛朗级数]]、[[亚纯函数]]），14.5 节将其归入代数函数的例。
- $w = \sqrt{z^2 - a^2}$（式 14.67）天然双值，源文未展开其多值性；系统处理见 [[多值函数与主值]]。

### 函数层与表达式层的区分

- 注意区分函数层的代数函数与表达式层的 [[代数式]]。
- 定义中出现的 $p_i(x)$ 为多项式，与 [[方程]] 概念相衔接。
