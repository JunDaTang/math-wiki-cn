# 自然指数函数

**自然指数函数** $e^z$ 由幂级数定义（《数学手册(原书第10版)》14.5.2 第 1 条，式 14.69）：

$$e^z = 1 + \frac{z}{1!} + \frac{z^2}{2!} + \frac{z^3}{3!} + \dots$$

源文断言此级数**在整个 $z$ 平面中绝对收敛**，即收敛半径为 $\infty$——这是 [[concepts/复项幂级数]] 与 [[concepts/收敛圆与收敛半径]] 理论（14.3 节）的典型实例，也是 $e^z$ 的 [[concepts/泰勒级数]] 展开。

## 基本性质（源文逐条给出）

1. **纯虚指数**（[[concepts/欧拉关系式]]，式 14.70）：$e^{\mathrm{i}y} = \cos y + \mathrm{i}\sin y$，且 $e^{\pi\mathrm{i}} = -1$。
2. **一般情形** $z = x + \mathrm{i}y$（式 14.71a/b）：$e^z = e^x(\cos y + \mathrm{i}\sin y)$，从而 $\operatorname{Re}(e^z) = e^x\cos y$、$\operatorname{Im}(e^z) = e^x\sin y$、$|e^z| = e^x$、$\arg(e^z) = y$。
3. **周期性**（式 14.71c）：$e^z = e^{z + 2k\pi\mathrm{i}}$（$k = 0, \pm1, \pm2, \dots$），即周期为 $2\pi\mathrm{i}$。⚠ 转写文本将周期值排作“忒”，系 $2\pi\mathrm{i}$ 之讹（见 [[queries/14-5全节系统性转写讹误清单]]）。
4. **特殊值**（式 14.71d）：$e^0 = e^{2k\pi\mathrm{i}} = 1$，$e^{(2k+1)\pi\mathrm{i}} = -1$。

## 作为初等超越函数的生成元

源文以 $e^z$ 为 14.5.2 全部内容的起点：自然对数 $w = Ln z$ 定义为它的反函数（式 14.74a，见 [[concepts/自然对数]]）；一般指数函数 $a^z = e^{z\,Ln a}$（式 14.75a，见 [[concepts/一般指数函数]]）；三角函数与双曲函数由 $e^{\pm z}$、$e^{\pm\mathrm{i}z}$ 的线性组合定义（式 14.76a–14.77b，见 [[concepts/复三角函数与双曲函数]]）；反三角与反双曲函数则全部借 $Ln$ 表示（式 14.83a–14.86b，见 [[concepts/反三角函数与反双曲函数]]）。

由于 $e^z$ 的周期性（同一 $w$ 对应无穷多个相差 $2k\pi\mathrm{i}$ 的 $z$），其反函数 $Ln z$ 必然多值——这是 [[concepts/多值函数与主值]] 主题在初等函数层面的根源。
