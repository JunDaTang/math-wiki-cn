# 留数

## 定义

**洛朗系数定义（14.3）**：留数（residue）是函数在孤立奇点处的洛朗展式中 $(z - z_0)^{-1}$ 项的系数 $a_{-1}$：设 $z_0$ 为函数 $f(z)$ 的一个孤立奇点，则在 $z_0$ 的邻域中成立的洛朗展式中，系数 $a_{-1}$ 称为 $f(z)$ 在点 $z_0$ 处的留数，记作 $\operatorname{Res} f(z)\big|_{z=z_0}$。

**积分形式的一般定义**：留数是解析函数在孤立奇点处的一个局部量：$f$ 在奇点 $z_0$ 的去心邻域内沿环绕 $z_0$ 的正向小闭曲线的积分除以 $2\pi\mathrm{i}$，其值与小曲线的选取无关。（此一般定义属标准复分析内容，为便于理解而补足；其手册源头为 14.3，尚未入库，见 [[14-4未入库回指缺口]]。）

## 三种计算公式（14.3）

由洛朗系数公式 (14.50b)：

$$a_{-1} = \operatorname{Res} f(z)\big|_{z=z_0} = \frac{1}{2\pi\mathrm{i}} \oint_K f(\zeta)\,\mathrm{d}\zeta \tag{14.54a}$$

（$K$ 为包围 $z_0$ 的闭曲线。）属于一个 $m$ 阶极点的留数可由

$$\operatorname{Res} f(z)\big|_{z=z_0} = \lim_{z \to z_0} \frac{1}{(m-1)!} \frac{\mathrm{d}^{m-1}}{\mathrm{d}z^{m-1}} \left[ f(z)(z - z_0)^m \right] \tag{14.54b}$$

计算。若函数可表示为商 $f(z) = \varphi(z)/\psi(z)$，其中 $\varphi$、$\psi$ 在 $z_0$ 处解析，且 $z_0$ 是 $\psi$ 的单根（$\psi(z_0) = 0$，$\psi'(z_0) \neq 0$），则 $z_0$ 是 $f$ 的一阶极点，且从 (14.54b) 即得

$$\operatorname{Res}\left[\frac{\varphi(z)}{\psi(z)}\right]_{z=z_0} = \frac{\varphi(z_0)}{\psi'(z_0)}. \tag{14.54c}$$

**译者注**（中译本增补）：要使 $z_0$ 是 $f(z)$ 的一阶极点，还需加上条件 $\varphi(z_0) \neq 0$。如果 $z_0$ 是 $\psi(z)$ 的一个 $m$ 重的根，即 $\psi(z_0) = \psi'(z_0) = \cdots = \psi^{(m-1)}(z_0) = 0$ 且 $\psi^{(m)}(z_0) \neq 0$，则 $z = z_0$ 是 $f(z)$ 的一个 $m$ 阶极点。

三式的适用条件分流见 [[留数三公式选用流程]]，比较见 [[留数三种计算公式比较]]。留数是 [[留数定理]] 的计算基础；复算见 [[式14-54a至14-55留数公式与留数定理算例转录复算]]。

## 在 14.4（用复积分计算实积分）中的应用

在 14.4 中，留数通过极点处的求值公式被反复使用，是 [[留数定理]] 的计算载体。

### 极点处的求值公式（14.3 式 (14.54b) 之应用）

14.4 的算例用到两种形式。

一阶极点（极限式，14.4.3 例 1 与例 2 使用）：

$$\operatorname{Res} f(z)\Big|_{z=z_0} = \lim_{z\to z_0} (z-z_0) f(z)$$

m 阶极点（导数式，14.4.2 例使用，源文标注依 (14.54b)）：即 (14.54b)。

### 三个留数计算链

1. **三阶极点 z = i，f = 1/(1+z²)³（14.4.2）**：

$$\operatorname{Res}\frac{1}{(1+z^2)^3}\Big|_{z=i} = \frac{1}{2!}\frac{\mathrm{d}^2}{\mathrm{d}z^2}\left[\frac{(z-i)^3}{(1+z^2)^3}\right]_{z=i} = \frac{1}{2!}\frac{\mathrm{d}^2}{\mathrm{d}z^2}(z+i)^{-3}\Big|_{z=i} = 6(2i)^{-5} = -\frac{3}{16}\mathrm{i}$$

2. **一阶极点 z = ai，f = z e^{iαz}/(z²+a²)（14.4.3 例 1）**：

$$\operatorname{Res} = \lim_{z\to ai} \frac{z\,e^{i\alpha z}}{z+ai} = \frac{1}{2}e^{-\alpha a}$$

3. **一阶极点 z = 0，f = e^{iz}/z（14.4.3 例 2）**：

$$\operatorname{Res} = \lim_{z\to 0} e^{iz} = 1$$

三个计算链均经独立复算通过，见 [[式14-56至14-62及ez例复积分计算实积分转录复算]]。极点阶数的判定见 [[解析函数的奇点]]。
