# 高斯消元法

高斯消元法（又称高斯算法）是求解线性方程组的**直接法**。《数学手册（原书第10版）》在 4.5.2.4（线性方程组）与 19.2（方程组的数值解）两处给出表述：

- **4.5.2.4**（方程组记作 Ax = a）：借助一个方程从所有其他方程中消去某个未知数，得到含 n − 1 个未知数的方程组；重复应用直到得到**行阶梯形**方程组（式 4.186），于是容易从这一形式确定解的存在性和唯一性，并且若解存在则可从最后一行开始逐次确定（回代）。
- **19.2**（方程组记作 Ax = b）：通过行变换把方程组经 n − 1 步“消元”化为上三角方程组 Rx = c（19.27），再由**向后代换法**（19.28）按倒序解出。

> **两节侧重**：4.5.2.4 就含 m 个方程的一般方程组讨论，并以秩 r 刻画解的存在性与唯一性；19.2 就 n×n 方程组给出逐步消元与回代的数值公式。

## 行变换与等价性

消元借助三种行变换实现（19.2）：

1. 交换行；
2. 某一行乘以非零数；
3. 将某一行乘以非零数加到另一行。

由于行变换均为等价变换，消元所得的 Rx = c 与原方程组同解（19.2）。从秩的角度看，高斯算法步骤基本上是行运算，不影响增广矩阵 (A, a) 的秩，从而解的存在性和唯一性以及解本身都不会改变（4.5）。

## 消元过程

### 高斯步骤（4.5，式 4.185）

设 a₁₁ ≠ 0（不然将另一方程调换为第一个方程），在增广矩阵 (A, a) 上用 −a₂₁/a₁₁, …, −a_m1/a₁₁ 乘第一行并分别加到第 2, …, m 行，使第一列除主元外全为零（式 4.185a–b）。

实施 (r − 1) 次高斯步骤后得到行阶梯矩阵（式 4.186）：前 r 行具有非零对角主元 a_ρρ^(ρ−1)，其下各行仅在常数列可能有非零元 a_{r+1}^(r−1), …, a_m^(r−1)。

### 第 k 步消元的数值公式（19.2，式 19.29–19.30）

第 k 步消元先选取主元 a_{rk} ≠ 0（若无则矩阵奇异、停止），交换相应行得 Ā，再用乘数

$$l_{i}=\bar a_{i1}/\bar a_{11}$$

把该列下方元素消为零，更新公式为

$$a_{ik}^{(1)}=\bar a_{ik}-l_{i1}\bar a_{1k},\qquad b_i^{(1)}=\bar a_i-l_{i1}\bar a_1$$

（19.29–19.30），并对所得 (n−1)×(n−1) 子矩阵递归进行。整个消元共 n − 1 步，最终把方程组化为上三角方程组 Rx = c（19.27）。

## 回代求解

若解存在，可从最后一行开始逐次确定各未知数（4.5，回代）。对上三角方程组 Rx = c（19.27），向后代换法（19.28）按倒序解出：

$$x_n = \frac{c_n}{r_{nn}},\qquad x_i = \frac{1}{r_{ii}}\Big(c_i - \sum_{k=i+1}^{n} r_{ik}x_k\Big)\quad (i=n-1,\dots,1).$$

## 解的存在性与唯一性（4.5）

由行阶梯形（式 4.186）：

- **情形 1**：若 a_{r+1}^(r−1), …, a_m^(r−1) 中有不为零者，方程组无解；
- **情形 2**：若它们全为零，方程组有解；其中 r = n 时解唯一，r < n 时解不唯一、n − r 个未知数可选作自由参数。

该判据与式 (4.178) 的秩判据一致，参见 [[矩阵的秩]]、[[增广矩阵]]。

## 算例

### 例 A（4×4，4.5）

阶梯形（各行未知数系数 ‖ 常数项）：

| x₁ | x₂ | x₃ | x₄ | ‖ | 常数项 |
|---:|---:|---:|---:|:--:|---:|
| 1 | 2 | 3 | 4 | ‖ | −2 |
| 0 | −1 | −2 | −7 | ‖ | 6 |
| 0 | 0 | −4 | 4 | ‖ | −4 |
| 0 | 0 | 0 | 40 | ‖ | −40 |

唯一解 (0, 1, 0, −1)。

### 例 B（5×3，4.5）

三行化为零行，r = 2 < 3；x₃ = t，x₂ = 7/5 − (17/5)t，x₁ = 4/5 − (9/5)t。

## 转写勘误

- **4.5**：源文将「(r − 1) 次」误作「(r 1) 次」；
- **19.2**：本小节行变换定义句脱去“变换为 Rx=c”关键式（见 [[行变换定义句脱变换式之辨]]）；“变换从 经过 n−1 步”脱矩阵符号 A、“第 次消元/第 行”脱序号 k、r（见 [[19-2全节系统性转写讹误清单]]）。
