# 米尔恩法则

隐式线性多步法 (19.103)：积分表达式 (19.95) 中的积分由辛普森公式（19.3.2.3，未入库）在 [x_i, x_{i+2}] 上近似：

```latex
(19.103)  y_{i+2} - y_i = \frac{h}{3}(f_i + 4f_{i+1} + f_{i+2})
```

因右端含 f_{i+2} = f(x_{i+2}, y_{i+2})，对 y_{i+2} 为隐式，须与显式预估子配合使用，见 [[concepts/预估—校正法]]。冠名者 [[entities/米尔恩]]；与辛普森公式的关系见 [[entities/辛普森]]。

注意：预估—校正对 (19.108b) 的校正子即本法则平移指标后的形式（y_{i+1} = y_{i−1} + (h/3)(f_{i−1}+4f_i+f_{i+1})）；源文称辛普森公式作为该校正子在数值上是不稳定的，并给出替换格式 (19.109)——该告警针对误差传播，非本法则作为多步法的收敛性论断。相关辨析见 [[queries/式19-108a预估子与经典米尔恩预估子形式之辨]]。
