# 一维热传导方程

一维热传导方程是描述均匀介质内沿单一方向热传导的**抛物型**偏微分方程。手册 15.2.3.3 采用的形式为

$$u_{xx} - a^{-2} u_t = 0$$

（等价于 u_t = a²u_xx），并经时间代换写成 u_xx − u_y = 0。手册指出它与三维热传导方程（9.2.2.3，第 763 页，本 wiki 未入库）同为抛物型方程。

## 定解问题与解的结构（手册 15.2.3.3）

- 区域 0 < t < ∞、0 < x < l（源文「0 < x < t」疑为「0 < x < l」）；初始条件 u(x,+0) = u₀(x)，边界条件 u(+0,t) = a₀(t)、u(l−0,t) = a₁(t)。
- 对时间作拉普拉斯变换后（[[methodology/偏微分方程的单变量拉普拉斯变换流程]]）得像空间 ODE：U″ = pU − u₀(x)；零初始温度 u₀ = 0 时通解为 c₁e^{x√p} + c₂e^{−x√p}。
- 一般边界条件的解由两个单位边界特解 U₁ = sinh((l−x)√p)/sinh(l√p) 与 U₂ = sinh(x√p)/sinh(l√p) 线性叠加（15.62）。
- l→∞（半无限）时 U = A₀(p)e^{−x√p}，逆变换得 Poisson 型积分（15.63b）：

$$u(x,t) = \frac{x}{2\sqrt{\pi}} \int_0^t \frac{a_0(t-\tau)}{\tau^{3/2}} \exp\!\left(-\frac{x^2}{4\tau}\right) \mathrm{d}\tau.$$

## 疑点

- 源文称时间代换为「y = a t」，但 u_xx − a⁻²u_t = u_xx − u_y 要求 y = a²t，指数疑脱漏，且 (15.60a) 实为对替换后变量 y 变换的结果：见 [[queries/式15-59a时间代换y等于at疑为a平方t]]。
- 逐式转录与复算见 [[findings/式15-56至15-63一维热传导方程拉普拉斯求解转录复算]]。
