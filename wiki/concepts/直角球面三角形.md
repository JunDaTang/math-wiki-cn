# 直角球面三角形

直角球面三角形是至少有一个角为 90° 的球面三角形（[[concepts/球面三角学]] 的基本计算对象）。其边和角的记法类似平面 [[concepts/直角三角形]]：当 γ 是直角时，边 c 称为**斜边**，a、b 称为**直角边**，α、β 称为**侧角**。

令 γ = 90°，可从斜球面三角形的基本公式 (3.187d)–(3.191b) 推出十条**专门公式** (3.202a)–(3.202j)，其中 (3.202i)(3.202j) 在本源的转写中本体脱落、经复原（推断）补全：

```
sin a = sin α sin c   (3.202a)      tan a = cos β tan c    (3.202e)
sin b = sin β sin c   (3.202b)      tan b = cos α tan c    (3.202f)
cos c = cos a cos b   (3.202c)      tan b = sin a tan β    (3.202g)
cos c = cot α cot β   (3.202d)      tan a = sin b tan α    (3.202h)
【复原·推断】cos α = cos a sin β   (3.202i)
【复原·推断】cos β = cos b sin α   (3.202j)
```

完整公式组与六个基本问题（表 3.8）见 [[findings/直角球面三角形十公式与表3-8六基本问题]]：计算通常从 γ = 90° 与另外两个已知量出发；若给定其他的边角组合，可通过量的轮换得到所需等式。十条公式可由 [[concepts/纳皮尔法则]] 统一概括。

除独立求解外，直角球面三角形还是斜球面三角形的分解工具：[[concepts/球面三角形六基本问题]] 中的问题 3–6 可以通过球面垂线把一般三角形分解为两个直角三角形来解（源图 3.100–3.102）。[[concepts/子午线收敛角]] 的推导（直角球面三角形 QPN）与 [[concepts/大圆航线]] 方程的推导都是它的应用实例。
