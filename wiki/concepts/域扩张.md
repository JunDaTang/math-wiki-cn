# 域扩张

域扩张是域 K 与其扩域 L（K ⊆ L）构成的关系：L 称为 K 的扩域（扩张域），此时 L 可看作 K 上的向量空间；若 L 是 K 上的有限维空间，则称有限扩域，维数 n 称为扩张次数，记 [L : K] = n。

## 基本概念

- **有限扩张与次数**：[L : K] = n；
- **K(M)**：含域 K 及集合 M ⊆ L 的最小的域（K 的一个扩域）；
- **单代数扩张 K(α)**：α ∈ L 是 K[x] 中某多项式的根；其规模由 α 的 [[concepts/极小多项式]] 次数决定——若极小多项式次数为 n，则 K(α) 是 n 次扩张，即极小多项式的次数等于 K(α) 作为 K 上向量空间的维数；
- **分裂域**：K 的含某多项式所有根的最小的扩张；ℤ_p(α) 是 f(x) 的分裂域；Xⁿ − 1 的分裂域即 [[concepts/分圆域]]。

## 本源例子

- $\mathbb{C} = \mathbb{R}(\mathrm{i})$：i 是 $x^2 + 1 \in \mathbb{R}[x]$ 的根，故 ℂ 是 ℝ 的单代数扩张且 $[\mathbb{C} : \mathbb{R}] = 2$，{1, i} 是基；
- ℝ 是 ℚ 上的**无限维**空间（无限扩张的例子）；
- GF(pⁿ) = ℤ_p(α)，其中 α = x（见 [[entities/伽罗瓦域gf-pn]]）。
