# 面积正切

**面积正切** $\operatorname{Artanh} x$（式 2.209）是 [[concepts/双曲正切函数]] $\tanh$ 的反函数：$y = \operatorname{Artanh} x$ 等价于 $x = \tanh y$，定义域为开区间 $|x| < 1$，值域为整个实轴。

## 基本性质（手册 2.10.1.3）

- **定义域**：$|x| < 1$（表 2.8 与式 2.213）。注意：正文 2.10.1.3 写「仅在 $|x| \leqslant 1$ 时有定义」，与表 2.8 及式 2.213 矛盾——$x = \pm 1$ 正是铅直渐近线所在，函数在该处无定义，「≤」应为「<」，见 [[queries/正文Artanh定义域绝对值小于等于1是否应为小于1]]。
- **值域**：$-\infty < y < \infty$。
- **奇偶性**：奇函数（式 2.223）。
- **单调性**：严格单调递增（$\tanh$ 严格递增，反函数保持单调性）。
- **对称中心与 [[concepts/拐点]]**：原点，此处切线的倾斜角 $\varphi = \pi/4$。
- **渐近线**：两条铅直 [[concepts/渐近线]] $x = \pm 1$。

## 对数表示

$$\operatorname{Artanh} x = \frac {1}{2} \ln \frac {1 + x}{1 - x} \quad (| x | < 1) \tag{2.213}$$

见 [[findings/面积函数的自然对数表示]]。

## 与面积余切的互换

枢纽关系 $\operatorname{Artanh} x = \operatorname{Arcoth} \dfrac{1}{x}$（式 2.217 中项）：两者经 $x \mapsto 1/x$ 互换，定义域互补（$|x| < 1$ 对 $|x| > 1$），详见 [[comparisons/面积正切与面积余切比较]] 与 [[findings/面积函数间的互表关系]]（含 $x = 0$ 边界保留）。

## 和差公式

$\operatorname{Artanh} x \pm \operatorname{Artanh} y = \operatorname{Artanh} \dfrac{x \pm y}{1 \pm xy}$（式 2.221），见 [[findings/面积函数的和差公式]]。
