# 球面半角与半边公式

球面半角公式与半边公式是两组「紧凑的平方根公式」：半角公式由三条边确定角，半边公式由三个角确定边。半角公式是平面三角学半角公式（见 [[findings/半角公式与附加关系]]）的球面对应；半边公式则为球面特有（平面三角形不存在「由角求边」问题，见 [[findings/平面三角形边不可仅由角得到]]）。

## 半角公式（由边求角，用 tan(α/2)）

形式一（式 3.192）：

```
tan(α/2) = √[ sin(s−b) sin(s−c) / (sin s · sin(s−a)) ]    (3.192a)
tan(β/2) = √[ sin(s−c) sin(s−a) / (sin s · sin(s−b)) ]    (3.192b)
tan(γ/2) = √[ sin(s−a) sin(s−b) / (sin s · sin(s−c)) ]    (3.192c)
s = (a+b+c)/2                                              (3.192d)
```

形式二（式 3.193，手册说明在要从三边确定全部三个角时有用）：

```
tan(α/2) = k / sin(s−a)    (3.193a)
tan(β/2) = k / sin(s−b)    (3.193b)
tan(γ/2) = k / sin(s−c)    (3.193c)
k = √[ sin(s−a) sin(s−b) sin(s−c) / sin s ]    (3.193d)
s = (a+b+c)/2                                   (3.193e)
```

手册说明：若只要由边确定一个角，可直接使用 [[concepts/球面边的余弦定律]]；半角公式的价值在于**通过角的正切**来计算它们，这类似于平面三角学的半角公式。

## 半边公式（由角求边，用 cot(a/2)）

形式一（式 3.194）：

```
cot(a/2) = √[ cos(σ−β) cos(σ−γ) / (−cos σ · cos(σ−α)) ]    (3.194a)
cot(b/2) = √[ cos(σ−γ) cos(σ−α) / (−cos σ · cos(σ−β)) ]    (3.194b)
cot(c/2) = √[ cos(σ−α) cos(σ−β) / (−cos σ · cos(σ−γ)) ]    (3.194c)
σ = (α+β+γ)/2                                                (3.194d)
```

形式二（式 3.195，以「或」与形式一并列）：

```
cot(a/2) = k′ / cos(σ−α)    (3.195a)
cot(b/2) = k′ / cos(σ−β)    (3.195b)
cot(c/2) = k′ / cos(σ−γ)    (3.195c)
k′ = √[ cos(σ−α) cos(σ−β) cos(σ−γ) / (−cos σ) ]    (3.195d)
σ = (α+β+γ)/2                                       (3.195e)
```

## 根为实数的保证

由三角之和命题（式 3.183）得 180° < 2σ < 540°，即

```
90° < σ < 270°  ⟹  cos σ < 0 恒真    (3.196)
```

故 −cos σ > 0 恒成立；手册断言「鉴于对欧拉三角形的要求，所有的根都是实数」（欧拉三角形的定义属尚未入库的 3.4.1）。

两组公式的结构对偶（s↔σ、sin↔cos、tan(α/2)↔cot(a/2)）见 [[comparisons/球面半角公式与半边公式对偶比较]]。
