# 零点能

零点能是量子系统处于最低能态时仍具有的非零能量，是与经典力学截然不同的量子效应标志。手册 9.2.4 给出**两个相互独立**的零点能结论，分别属于两个模型，不可互相挪用或合并陈述：

## 1. 零点平移能（方盒，9.134h）

```latex
E_0=\frac{\hbar^{2}}{2m}\Big(\frac{1}{a^{2}}+\frac{1}{b^{2}}+\frac{1}{c^{2}}\Big)
```

粒子能量必定保持有限值，即使温度达到绝对零度——对一个方块的零点平移能量（zero-point translational energy）。属 [[concepts/无限深方势阱]]；来源是量子数只能取非零正整数（n = 0 意味着波函数恒为零，盒子任何地方都没有粒子），最低态 (nₓ,n_y,n_z) = (1,1,1)。

## 2. 零点振动能（线性谐振子，9.147c）

```latex
E_n=\hbar\omega\Big(n+\frac{1}{2}\Big)\quad(n=0,1,2,\dots)
```

括号中的被加数 +1/2 意味着与经典情形不同，量子力学振子在 n = 0 的最深能级仍有能量——零点振动能（zero-point vibration energy）。属 [[concepts/量子线性谐振子]]；来源是幂级数截止条件 λ = 2n+1（9.146b），n = 0 时给出 E₀ = ½ℏω。

两条结论的模型归属互不相同：平移零点能不得移用于振子，振动零点能亦不得移用于方盒。
