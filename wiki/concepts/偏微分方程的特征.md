# 偏微分方程的特征

**偏微分方程的特征**（特征线）是与二阶偏微分方程 (9.82a) 相伴的一阶常微分方程——特征方程——的积分曲线。特征方程为（式 9.83）：

$$A\,\mathrm{d}y^{2} - 2B\,\mathrm{d}x\,\mathrm{d}y + C\,\mathrm{d}x^{2} = 0,\qquad\text{即}\quad \frac{\mathrm{d}y}{\mathrm{d}x} = \frac{B \pm \sqrt{-\delta}}{A}$$

复算：把 9.83 视为 dy/dx 的二次方程 A(dy/dx)² − 2B(dy/dx) + C = 0，其判别式为 4(B² − AC) = −4δ，解出上式 ✓。

## 各类型的特征性态

- 双曲型（δ < 0）：存在两族实特征；
- 抛物型（δ = 0）：只存在一族实特征；
- 椭圆型（δ > 0）：不存在实特征（系数解析时存在两族复共轭“特征”曲线）。

## 特征的用途

- 取特征为新坐标线的变量变换，可使相应的二阶导数项从方程中消失——这是约化 [[典范形式]] 的基础：双曲型取两族特征得第一典范形式 u_{ξ₁η₁} + … = 0；抛物型取唯一特征族为 ξ = 常数；椭圆型用复共轭特征实化（ξ = φ + ψ，η = i(φ − ψ)）。
- 坐标变换前后的方程具有相同的特征；若一族特征与一族坐标线一致，则方程中不含未知函数关于相应自变量的二阶导数项；抛物型方程不存在混合导数项。
- 在 [[黎曼方法]] 中，过点 (ξ, η) 的两条特征线 x = ξ、y = η 是黎曼函数取值条件 (9.97c) 的载体；柯西问题的初始曲线必须不与特征相切。

## 与 ODE 特征方程的辨析

本条目的“特征方程”是二阶 PDE 主部系数构成的二次微分形式，与常微分方程中求指数解 e^{λx} 的特征方程（[[特征方程法]]）同名异义，系统对照见 [[comparisons/ODE特征方程与PDE特征线辨析]]。
