# 初值问题

初值问题是附加条件集中给定在同一点处的一类常微分方程定解问题：对于 n 阶方程的解 y = y(x)，在 x₀ 处给定 n 个值 y(x₀), y′(x₀), …, y⁽ⁿ⁻¹⁾(x₀)，用以确定通解的 n 个任意常数。

## 定义（手册 9.1 要点 3）

如果对于一个 n 阶常微分方程的解 y = y(x)，在 x₀ 处给定了 n 个值

y(x₀), y′(x₀), …, y⁽ⁿ⁻¹⁾(x₀)，

那么就给出了一个**初值问题 (initial value problem)**。这些值被称为**初值 (initial value)** 或**初始条件 (initial conditions)**。对于 n 阶常微分方程通解的 n 个未知常数 c₁, c₂, …, cₙ，它们形成了 n 个方程的一个方程组。

## 要点 2 的简述版本

手册要点 2 亦给出简述：如果 y 及其直至 n−1 阶导数的值在区间 [a, b] 的一个端点处被指定，那么求解的问题被称为一个初值问题。两处措辞略异（「一个端点」与「x₀ 处」），实质一致：n 个条件集中在同一点。

## 手册算例：弹性弹簧—质量系统的谐运动

方程 y″ + y = 0，初始条件 y(0) = y₀, y′(0) = 0，其解为 y = y₀ cos x。

复算：y″ + y = 0 的通解为 y = A cos x + B sin x；由 y(0) = y₀ 得 A = y₀；由 y′ = −A sin x + B cos x 与 y′(0) = 0 得 B = 0。见 [[findings/9-1三算例复算]]。

注：该系统的固有频率为 1（解以 2π 为周期），此性质只属于方程 y″ + y = 0 本身，不应外推到其他方程。

## 适用条件（待回填）
