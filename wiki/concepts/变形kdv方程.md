# 变形 KdV 方程与广义 KdV 方程

**变形 KdV 方程**（modified KdV，mKdV，9.2.5.5.1）为

```latex
u_t ± 6 u^2 u_x + u_{xxx} = 0        (9.172)
```

其更一般的**广义 KdV 方程**

```latex
u_t + u^p u_x + u_{xxx} = 0          (9.173)
```

有孤子解

```latex
u(x,t) = [ (½|v|(p+1)(p+2)) / cosh²(½ p √|v| (x − v t − φ)) ]^{1/p}     (9.174)
```

（源文此处后接错位的译者注「也即 4K snx 的一个周期」，该注应属 (9.171) 段，见 [[queries/9-2-5全节系统性转写讹误清单]]。）

## 复算状态

(9.174) 经 p = 1、p = 2 直接代入 (9.173) 独立验证成立：振幅满足 A^p = ½|v|(p+1)(p+2)，宽度参数 B = ½p√|v|（[[findings/式9-172至9-179附加七方程复算]]）。(9.172) 的「+」号情形对应 (9.173) 的 p = 2（经因变量标度 u → u/√6 与之相一致）。

同节的 9.2.5.5.2 还给出**双曲正弦戈登方程** u_{tt} − u_{xx} + sinh u = 0 (9.175)，仅一行陈述，未展开。
