# 正五边形

正五边形是 n = 5 的正凸多边形，为《数学手册(原书第10版)》3.1.5.3 的论证主体。其特殊性在于：对角线与边不可公度，两者之比即黄金分割比；对角线在形内交出一个内接 [[concepts/五角星形]]，五角星形的边又围成更小的正五边形，形成无限嵌套的自相似结构（图 3.24）。

## 根式性质（表 3.2，复原读法）

- a₅ = (R/2)·√(10 − 2√5) = 2r·√(5 − 2√5)
- R = (a₅/10)·√(50 + 10√5) = r·(√5 − 1)
- r = (a₅/10)·√(25 + 10√5) = (R/4)·(√5 + 1)
- S₅ = (a₅²/4)·√(25 + 10√5) = (5R²/8)·√(10 + 2√5) = 5r²·√(5 − 2√5)

（转写中根号横线与括号丢失；上列复原读法经数值复核与式 3.51–3.56 一致。）这是表 3.2 中根式最复杂的行，详见 [[findings/表3-2五种正多边形根式性质]]。

## 不可公度性

由嵌套比例 a₀:a₁ = a₁:(a₀ − a₁) 出发，[[concepts/欧几里得算法]] 永不终止（商恒为 1），故对角线 a₀ 与边 a₁ 不可公度；其连分数与 [[concepts/黄金分割]]（源文指向 1.1.1.4 第 3 点）完全相同，导致无理数。完整论证见 [[findings/正五边形对角线与边不可公度]]。源文并以「据信」的保留措辞将无理数的认识归因于梅塔蓬图姆的希帕索斯（约公元前 450，指向 1.1.1.2），属传说性归因，不应写成定论。
