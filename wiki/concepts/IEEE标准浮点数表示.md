# IEEE 标准浮点数表示

IEEE 标准浮点数表示是浮点数的第二种（目前使用的）内部形式，相应于 1985 年通过的 IEEE 标准（见 [[entities/ieee标准]]）；与第一种「正规化半对数形式」（见 [[concepts/浮点数表示]]）相对，其特征是**偏移特征编码**与**隐含前导 1 的尾数**。

## 表示式

$$
a = (-1)^v \cdot 2^E \cdot 1.b_1 b_2 \dots b_{t-1}, \quad \text{其中 } E = C - K \tag{19.267}
$$

- **尾数**：形如 $1.b_1 b_2 \dots b_{t-1}$，有隐含的前导 1，即尾数 $\in [1, 2)$（显式存储的是 $b_1 b_2 \dots b_{t-1}$ 共 $t-1$ 位）。
- **指数**：特征 $C$ 来自指数 $E$ 加上适当的常数 $K$（偏移编码），这样的选取使得特征只是正数；实际指数由 $E = C - K$ 恢复。

## 保留的特征值

原文：「因为保存 $C = 0$、$C = 255$，这里 $C_{\min} = 1$、$C_{\max} = 256$」。其中 $C = 0$ 与 $C = 255$ 被保存（保留）不用于普通数；但 $C_{\max} = 256$ 一值与三方面皆不合（8 位指数字段上限为 255；$C = 0/255$ 既被保留则可用上界应为 254；表 19.4 给 $E_{\max} = +127$、$K = +127$，则 $C_{\max} = E_{\max} + K = 254$），疑为 254 之转写讹误，且该句语义不完整、疑脱关于保留值用途的说明，见 [[queries/式19-267后C-max为256疑为254之辨]]。

## 基本形式的参数（表 19.4）

| 参数 | 单精度 | 双精度 |
|---|---|---|
| 存储单元字长 | 32 | 64 |
| 最大指数 $E_{\text{max}}$ | +127 | +1023 |
| 最小指数 $E_{\text{min}}$ | −126 | −1022 |
| 常数 $K$ | +127 | +1023 |
| 指数位数 | 8 | 11 |
| 尾数位数 | 24 | 53 |

该标准给出单精度和双精度两个基本表示形式，也有其他表示形式。表列「尾数位数」含隐含前导 1（单精度 1+8+23 = 32 位、双精度 1+11+52 = 64 位），全部参数经独立复算与公认值一致，见 [[comparisons/单精度与双精度浮点数比较]] 与 [[findings/式19-264至19-267定点浮点与IEEE格式转录复算]]。

## 范围归属

本形式的可表示范围由 (19.267) 与表 19.4 参数决定（如单精度 $E \in [-126, +127]$），**不可套用**半对数形式的 (19.266)，详见 [[comparisons/正规化半对数形式与IEEE标准形式比较]]。
