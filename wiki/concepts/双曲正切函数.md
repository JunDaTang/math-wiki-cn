# 双曲正切函数

**双曲正切函数** tanh x 是六个 [[concepts/双曲函数]] 之一，定义为双曲正弦与双曲余弦之比：

$$
\tanh x = \frac {\mathrm{e} ^ {x} - \mathrm{e} ^ {- x}}{\mathrm{e} ^ {x} + \mathrm{e} ^ {- x}} = \frac {\sinh x}{\cosh x}.\tag{2.168}
$$

其倒数函数为 [[concepts/双曲余切函数]] coth x（式 2.169）。

## 图像性质（手册 2.9.2.3，图 2.51）

- y = tanh x 为**奇函数**：tanh(−x) = −tanh x（式 2.179）。
- 在 −∞ 到 +∞ 上，函数**从 −1 到 1 严格单调递增**。
- **原点**既为对称中心，又为 [[concepts/拐点]]，且此处切线的倾斜角 φ = π/4（核验注：对应原点处斜率为 1，即 tanh′(0) = sech²(0) = 1，属由定义可得的推断）。
- **渐近线**为 y = ±1（水平渐近线，无竖直渐近线）。

## 在公式体系中的位置

- 基本恒等式：sech²x + tanh²x = 1（式 2.174）。
- 加法定理：tanh(x ± y) = (tanh x ± tanh y)/(1 **±** tanh x tanh y)（式 2.184）——分母为加号，与三角 tan(x±y) 分母的 ∓ 号不同。
- 倍角：tanh 2x = 2 tanh x/(1 + tanh²x)（式 2.188）。
- 半角：tanh(x/2) = (cosh x − 1)/sinh x = sinh x/(cosh x + 1)（式 2.193）。
- 和差化积：tanh x ± tanh y = sinh(x±y)/(cosh x cosh y)（式 2.198）。
- 复角关系：tanh z = −i tan iz（式 2.205）。

完整公式体系见 [[concepts/双曲恒等式]]。

## 与 [[concepts/正切函数]] 的对照

二者同为奇函数，但性质不可互换：tan 值域为 ℝ、有竖直渐近线 x = π/2 + kπ、周期 π；tanh 值域为 (−1, 1)、无竖直渐近线、水平渐近线 y = ±1、非周期且在整个 ℝ 上严格递增。系统性符号差异见 [[comparisons/双曲函数与三角函数比较]]。
