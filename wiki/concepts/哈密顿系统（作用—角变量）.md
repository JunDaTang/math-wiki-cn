# 哈密顿系统（作用—角变量）

以**作用—角变量** (j₁, j₂, θ₁, θ₂) 表示的二自由度**哈密顿系统**是 ℝ⁴ 中的系统：

```
ĵ₁ = 0,  ĵ₂ = 0,  θ̇₁ = ∂H₀/∂j₁,  θ̇₂ = ∂H₀/∂j₂    （H₀(j₁,j₂) 解析）
```

它属于 [[concepts/耗散系统与保守系统|保守系统]]类：相体积保持、作用变量守恒，无吸收性。

## 解与不变环面

系统显然可解：j₁ = c₁, j₂ = c₂（作用变量守恒），θ₁ = ω₁t + c₃, θ₂ = ω₂t + c₄，其中 ω₁, ω₂ 依赖于 c₁, c₂。每个 (j₁,j₂) = (c₁,c₂) 确定一个**不变环面 T²**，其上的流为角变量的线性流：

- 若 ω₁/ω₂ 为有理数，轨道是周期性的（环面版 [[concepts/周期轨道|周期轨]]）；
- 若 ω₁/ω₂ 为无理数，轨道为**拟周期轨**——在环面上稠密铺开、永不闭合（源外补注）。

## 扰动与 KAM

考虑扰动的哈密顿函数 H₀(j₁,j₂) + εH₁(j₁,j₂,θ₁,θ₂)（H₁ 解析，ε>0 小参数）。[[concepts/KAM定理|KAM 定理]]断言：H₀ 非退化时，大多数**非共振**环面（|ω₁/ω₂ − p/q| ≥ c/q^{2.5}）在 ε 充分小时不消失、仅轻微变形。这解释了保守系统中拟周期行为的刚性。

## 口径辨析：「非通有」的两个层面

- KAM 的「大多数环面保持」是**哈密顿类内**扰动（H₀+εH₁）下的结论；
- 本节断言「哈密顿系统不是通有的」，是在**全体光滑向量场空间**中陈述——哈密顿系统在其中并非典型（通有的向量场行为另循 [[concepts/通有性]] 的口径）。

两个「扰动/通有」口径不同但逻辑自洽，阅读时须区分：拟周期轨在哈密顿类内小扰动下可保持，恰恰说明哈密顿系统在全空间中非典型。
