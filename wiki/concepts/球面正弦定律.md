# 球面正弦定律

球面正弦定律给出球面三角形中边的正弦与所对角的正弦之间的比例关系：

```
sin a / sin α = sin b / sin β = sin c / sin γ    (3.187d)
```

手册先给出三个两两之比（式 3.187a：sin a/sin b = sin α/sin β；3.187b：sin b/sin c = sin β/sin γ；3.187c：sin c/sin a = sin γ/sin α），再合并为连比形式。由本节命题 (1)–(3) 可见边 a、b、c 以角度量（大圆弧对球心的张角），因此「边取正弦」与「角取正弦」在量纲上一致。

本定律对应平面三角学的正弦定律 [[concepts/正弦定律]]。

## 适用警示

手册在本节算例后评注：**只有当问题中的角明显是锐角或钝角时，应用正弦定律确定边和角才有意义**。这是 SSA 二义性（见 [[findings/一般三角形四个基本问题与SSA分支]]）在球面情形的同类警示——由 sin 反解角时必须先判断象限。
