# 子午线收敛角

子午线收敛角 γ 是 [[entities/高斯—克吕格坐标系]] 中**地理北向**（真实子午线像 m′ 在 P′ 处切线的向上方向）与**坐标系北向**（格网子午线 k′ 的向上方向）之间的夹角，即真方位角与格网方位角换算时的改正量。

推导（[[concepts/纳皮尔法则]] 的应用例）：在 c = 90°−φ、b = η、α = 90°−γ 的 [[concepts/直角球面三角形]] QPN 中，cos α = tan b/tan c 给出 cos(90°−γ) = tan η/tan(90°−φ)，即 sin γ = tan η·tan φ。因 η 极小，sin γ ≈ γ、tan η ≈ η，且对小距离 η 圆柱体图的长度偏差极小，可取 η = y/R（y 为点的纵坐标），故

```
γ = (y/R)·tan φ
算例：φ = 50°, y = 100 km ⇒ γ = 0.018706 rad = 1°04′19″
```

该近似式与算例已经独立数值复算验证，见 [[findings/子午线收敛角近似式与算例]]。该应用段在源中无标签无编号，见 [[queries/高斯—克吕格段落是否为脱标应用例]]。γ 与 [[concepts/方位角]] 的关系：格网北向与真北向之别正是两类方位角系统的差异来源。
