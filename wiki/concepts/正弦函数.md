# 正弦函数

正弦函数是六种[[concepts/三角函数]]之一，标准形式为

$$y = \sin x \tag{2.63}$$

是周期 $T = 2\pi$ 的连续曲线，值域 $[-1, 1]$。一般正弦函数为

$$y = A\sin(\omega x + \varphi_0) \tag{2.64}$$

其中 $|A|$ 为振幅、ω 为频率（称谓口径见 [[queries/ω称频率与角频率口径不一]]）、$\varphi_0$ 为相位移，周期 $T = \frac{2\pi}{\omega}$。

## 图像要素

- 与 x 轴交点 $B_k = (k\pi, 0)$（k = 0, ±1, ±2, …），均为[[concepts/拐点]]，切线关于 x 轴的倾斜角为 $\pm\frac{\pi}{4}$；
- [[concepts/极值]]点 $C_k = \left(\left(k+\frac{1}{2}\right)\pi,\ (-1)^k\right)$。

一般正弦可由标准正弦经三步变换得到：沿 y 轴方向拉伸 $|A|$ 倍、沿 x 轴方向压缩 $\frac{1}{\omega}$ 倍、再向左平移 $\frac{\varphi_0}{\omega}$ 个单位；其与 x 轴交点 $B_k = \left(\frac{k\pi-\varphi_0}{\omega},\ 0\right)$，极值点 $C_k = \left(\frac{(k+\frac{1}{2})\pi-\varphi_0}{\omega},\ (-1)^k A\right)$。

## 与振动的联系

正弦函数是 [[concepts/谐振荡]] 的载体：$u(t) = A\sin(\omega t + \varphi)$（式 2.136）描述工程与物理中的正弦量；乘以指数衰减因子后成为 [[concepts/阻尼振荡]]。
