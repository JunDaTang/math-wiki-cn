# 整除性

**整除性**是整数环 $\mathbb{Z}$ 上的二元关系：整数 $b$ 可被整数 $a$ 无余数整除，当且仅当存在整数 $q$ 使 $qa=b$（式 5.214）。此时 $a$ 称为 $b$ 的**因子**，$q$ 称为 $a$ 的**余因子**，$b$ 称为 $a$ 的**倍数**，记作 $a\mid b$；否则记 $a\nmid b$。本源将其归为 $\mathbb{Z}$ 中的二元关系（引 5.2.3，未入库，见 [[queries/5-4-1对5-2-3及1-1-1-4的未入库依赖缺口]]），并指出类似地在自然数集中定义。

## 基本整除法则 DR1–DR12（式 5.215–5.226）

| 法则 | 内容 |
|---|---|
| DR1 | $\forall a:\ 1\mid a,\ a\mid a,\ a\mid 0$ |
| DR2 | $a\mid b \Rightarrow (-a)\mid b \wedge a\mid(-b)$ |
| DR3 | $a\mid b \wedge b\mid a \Rightarrow a=\pm b$ |
| DR4 | $a\mid 1 \Rightarrow a=\pm 1$（结论脱落，按标准结果复原） |
| DR5 | $a\mid b \wedge b\neq 0 \Rightarrow \lvert a\rvert\leqslant\lvert b\rvert$ |
| DR6 | $a\mid b \Rightarrow a\mid(zb)$（$\forall z\in\mathbb{Z}$） |
| DR7 | $a\mid b \Rightarrow a^z\mid b^z$（$z$ 域存疑） |
| DR8 | $a^z\mid b^z \wedge b\neq 0 \Rightarrow a\mid b$（$z$ 域存疑） |
| DR9 | $a\mid b \wedge b\mid c \Rightarrow a\mid c$（结论脱落，复原） |
| DR10 | $a\mid b \wedge c\mid d \Rightarrow ac\mid bd$（结论脱落，复原） |
| DR11 | $a\mid b \wedge a\mid c \Rightarrow a\mid(z_1 b+z_2 c)$ |
| DR12 | 整条脱落，仅存 $a\mid b$ |

完整转写状态与式号见 [[findings/整除定义与dr1-dr12法则组]]；DR4/DR12 复原问题见 [[queries/dr4与dr12结论脱落之复原]]，DR7/DR8 量词域见 [[queries/dr7与dr8的z量词域是否应为自然数]]。
