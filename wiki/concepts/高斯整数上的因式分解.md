# 高斯整数上的因式分解（GaussianIntegers 选项）

Factor 命令配合 GaussianIntegers -> True 选项，可将多项式在高斯整数环 ℤ[i] 上完全因式分解。源文：「如果一个多项式能够在高斯整数环上被完全分解，那么这可以通过选择 GaussianIntegers 而得到。」

## 源例

```text
In[1] := Factor[x^2 - 2x + 5] → Out[1] = 5 - 2x + x²
In[2] := Factor[x^2 - 2x + 5, GaussianIntegers -> True]
Out[2] = (-1 - 2I + x)(-1 + 2I + x)
```

x²−2x+5 = (x−1)²+4，判别式 4−20 = −16 < 0，在有理数域上不可约（Out[1] 原样返回）；在 ℤ[i] 上分解为共轭因式 (x−(1+2i))(x−(1−2i))，与源输出一致，经独立复算验证成立（见 [[findings/20-3-1代数与多项式算例复算]]）。

注意：源印刷块存在括号脱失讹误——印作「In[2] := FactorGaussianIntegers -> True」，复原应为 Factor[x²−2x+5, GaussianIntegers -> True]，见 [[queries/FactorGaussianIntegers括号脱失之辨]]。

## 定位

这是表 20.9 因式分解能力在数环扩张上的单一技术点：默认整数环/有理数域，可选高斯整数环。关联 [[concepts/代数表达式与多项式操作命令]]。
