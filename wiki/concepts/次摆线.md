# 次摆线（长摆线与短摆线）

**次摆线**是当圆沿一条直线做无滑动滚动时，固定在以圆心为始点的半直线上的圆外或圆内一定点所经过的轨迹：追踪点在圆外（$\lambda > 1$）时为**长摆线**，在圆内（$\lambda < 1$）时为**短摆线**。它是 [[concepts/摆线]] 在「追踪点位置」轴上的推广；$\lambda = 1$（点回到圆周上）时退化为标准摆线。

## 方程与参数含义

$$x = a (t - \lambda \sin t), \qquad y = a (1 - \lambda \cos t),\tag{2.243a–b}$$

其中 $a$ 为滚动圆半径，$t$ 为角 $\angle PC_1M$，$\lambda a = \overline{C_1P}$（追踪点到圆心的距离）。

## 周期与特征点

- 周期：$\overline{O_0O_1} = 2\pi a$（与标准摆线相同）。
- 极大点：$A_{k+1} = ((2k+1)\pi a,\ (1+\lambda)a)$；极小点：$B_k = (2k\pi a,\ (1-\lambda)a)$。
- **长摆线的二重点**：$D_k = (2k\pi a,\ a(1-\sqrt{\lambda^2 - t_0^2}))$，其中 $t_0$ 为方程 $t = \lambda\sin t$ 的最小正根（二重点位于标准摆线尖点的正上方，即拱的接合处）。
- **短摆线的拐点**：$E_{k+1} = [\,a(\operatorname{arc}_k\cos\lambda - \lambda\sqrt{1-\lambda^2}),\ a(1-\lambda^2)\,]$（$\operatorname{arc}_k\cos$ 为多值反余弦分支记法）。

## 几何量

- 一周期曲线长：$L = a\displaystyle\int_0^{2\pi}\sqrt{1+\lambda^2 - 2\lambda\cos t}\,dt$（手册未给闭式）。
- 一周期阴影面积：$S = \pi a^2(2 + \lambda^2)$；$\lambda = 1$ 时回退为标准摆线的 $3\pi a^2$。
- 曲率半径：$r = a\dfrac{(1+\lambda^2 - 2\lambda\cos t)^{3/2}}{\lambda(\cos t - \lambda)}$；极大点处 $r_A = -a\dfrac{(1+\lambda)^2}{\lambda}$，极小点处 $r_B = a\dfrac{(1-\lambda)^2}{\lambda}$。该式为**带符号**曲率半径：分母 $\cos t - \lambda = 0$ 恰为短摆线拐点处（$r \to \infty$），与拐点条件自洽。

## 疑点

- 符号约定：$\lambda = 1$ 时 $|r| = 4a\sin(t/2)$、$|r_A| = 4a$，与 [[concepts/摆线]] 一节量值相同但符号相反，两小节的曲率符号约定疑似不统一，见 [[queries/次摆线曲率半径符号约定与2-13-1是否统一]]。
