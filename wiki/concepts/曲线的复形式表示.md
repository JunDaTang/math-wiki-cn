# 曲线的复形式表示

一个实变量 $t$ 的复函数可以表示为参数形式（《数学手册(原书第10版)》14.5.3，式 14.91）：

$$z = x(t) + \mathrm{i}y(t) = f(t)$$

当 $t$ 变动时，点 $z(t)$ 画出一条曲线。源文给出五类曲线的方程与图形表示（图 14.49–14.53）。

## 直线（式 14.92a/b）

- 过点 $z_1$、与实轴夹角 $\varphi$：$z = z_1 + t\,e^{\mathrm{i}\varphi}$；
- 过两点 $z_1, z_2$：$z = z_1 + t(z_2 - z_1)$。⚠ 转写“通过两个点 Zl 五”应为 $z_1, z_2$。

## 圆周（式 14.93a/b）

- 圆心在原点、半径 $r$：$z = r\,e^{\mathrm{i}t}$（$|z| = r$）；⚠ 转写“圆心在点 $z_0 =$”处缺"0"。
- 圆心在 $z_0$、半径 $r$：$z = z_0 + r\,e^{\mathrm{i}t}$（$|z - z_0| = r$）。

圆周参数式正是 [[methodology/复积分圆周参数化计算流程]]（源自 14.2 节）所用的形式，两处直接互证。

## 椭圆（式 14.94a–c，14.95）

- 范式 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$：$z = a\cos t + \mathrm{i}b\sin t$，或 $z = c\,e^{\mathrm{i}t} + d\,e^{-\mathrm{i}t}$，其中 $c = \frac{a+b}{2}$、$d = \frac{a-b}{2}$；
- 一般形式（中心 $z_1$，轴被旋转一个角度）：$z = z_1 + c\,e^{\mathrm{i}t} + d\,e^{-\mathrm{i}t}$，$c$、$d$ 决定椭圆轴的长度和旋转角度。

⚠ 转写疑损：(14.94c) 后“即 $c$ 是任意实数”与 $c = (a+b)/2$ 相矛盾；(14.95) 的说明“这里 $c$ 是任意复数”丢失了 $d$（见 [[queries/式14-94c与14-95椭圆参数说明文字疑损]]）。

## 双曲线（式 14.96–14.98）

范式 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$：$z = a\cosh t + \mathrm{i}b\sinh t$，或 $z = c\,e^{t} + \bar{c}\,e^{-t}$，其中 $c = \frac{a+\mathrm{i}b}{2}$、$\bar{c} = \frac{a-\mathrm{i}b}{2}$。⚠ 转写“其中 $c$ 是共辄复数”应为“$\bar{c}$ 是 $c$ 的共轭复数”（“共辄”为“共轭”之讹）。

注意：椭圆有“一般形式”（14.95），双曲线在源文中只有范式表示——是否存在被转写丢失的一般形式双曲线方程，属开放问题。

## 对数螺线（式 14.99）

$$z = a\,e^{\mathrm{i}bt}$$

⚠ 转写文本缺失参数限定语（“其中 ___ 是任意复数”处符号丢失）。复算指出名实矛盾：若 $b$ 为实数，则 $|z| = |a|$ 恒定，轨迹是圆周而非螺线；仅当 $b$ 为具有非零实部与非零虚部的复数时，$|z| = |a|e^{-\operatorname{Im}(b)\,t}$ 随 $t$ 指数变化，方为对数螺线（见 [[queries/式14-99对数螺线参数限定语缺失之辨]]）。
