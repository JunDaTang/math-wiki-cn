# 光滑样条

光滑样条（三次）是以罚化最小二乘定义的样条：当已知函数值 f_i 通常是含误差的测量值时，插值要求并不合理，故将三次插值样条中的插值要求替换为 (19.242) 的极小化问题，同时保持 S、S′、S″ 连续性的要求。

```latex
(19.242)  Σ_{i=1}^{N} [ (f_i − S(x_i)) / σ_i ]² + λ ∫_{x_1}^{x_N} [S''(x)]² dx = min!
```

## 参数与谱系

- **λ > 0**：事先给定的光滑参数。λ = 0 → 三次插值样条；λ 很大 → 得到光滑的近似曲线，但回到测量值不准确；λ = ∞ → 逼近回归线（此为极限陈述：严格说 λ→∞ 时趋于加权最小二乘直线，原书措辞偏松）。λ 可适当选取，例如通过机屏对话。
- **σ_i > 0**：数值 f_i 测量误差的标准差（原书回指第 1109 页 16.4.1.3,2.），充当数据权——与 [[concepts/权函数与加权内积]] 的加权思想同构。

## 求解与证据强度

确定系数的问题是带方程形式条件的**约束最优化**问题，使用拉格朗日函数（原书回指第 611 页 6.2.5.6）即可得到解；**细节原书完全外推至文献 [19.34]、[19.35]**，本源自含证据弱。

## 二维推广

二维情形（双三次光滑样条，19.7.2.3）可能有一整列相应的最优条件，但**仅有很少特殊情况可能存在唯一解**——原书自设的重要限定；适当的最优条件和算法亦外推至文献（编号缺失）。
