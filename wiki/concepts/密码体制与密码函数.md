# 密码体制与密码函数

密码体制是本源（5.5.2–5.5.3）为保密学建立的形式化骨架：一个抽象密码体制由消息集 M、密文集 C、密钥集 K 与 K′、函数集 𝔼 与 𝔻 组成（原文多处符号脱落）；消息 m ∈ M 经 E ∈ 𝔼 与密钥 k ∈ K 译成密文 c ∈ C 并经信道发送，接收者以 D ∈ 𝔻 与相应密钥 k′ ∈ K′ 恢复原消息。

## 密码函数

设 A、B 为字母表（有限非空全序集），S 为有限集。**密码函数**是映射 t : Aⁿ × S → Bᵐ，使得对所有 s ∈ S，映射 t_s : Aⁿ → Bᵐ, w ↦ t(w, s) 是单射。t_s 称为**加密函数**，t_s⁻¹ 称为**解密函数**；w 称为**明码**，t_s(w) 称为**密码**。给定密码函数 t，单参数族 {t_s}_{s∈S} 构成密码体制：

```
T_S = { t_s : Aⁿ → Aⁿ | s ∈ S }                    (5.273)
```

属于一个密码体制的所有密钥的集合称为**密钥空间**。口径差异：式 (5.273) 限定 Aⁿ → Aⁿ，而密码函数的一般定义允许 Aⁿ → Bᵐ。

## 流密码与区组密码

若 T_S 是 Aⁿ 上的密码体制且 n = 1，则 t_s 称为**流密码**；不然称为**区组密码**。（以 n = 1 / n > 1 区分流与区组是本手册的简化口径，并非通行定义。）Aⁿ 上的密码函数适用于任意长度明码：明码先分裂为长度 n 的区组，逐组应用函数；最后区组可能需以**填充符号**加长，填充符号必须不导致明文的曲解。

## 上下文无关与上下文敏感加密

**上下文无关加密**：密文区组只是对应明文区组和密钥的函数。**上下文敏感加密**：密文区组与消息的其他区组有关。理论上，区组的每个密文数字与对应明文区组的所有数字以及密钥的所有数字有关；明文或密钥的小改动会引起密文的显著变化（[[concepts/雪崩效应]]）。
