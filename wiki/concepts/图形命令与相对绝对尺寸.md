# 图形命令与相对绝对尺寸

图形命令（图形指示）是 Mathematica 中用于控制图像显示的一类基元，它们规定图形对象「应该如何表示」。按《数学手册（原书第10版）》20.4.2（表 20.15），它们与 Point、Line 等图形对象并列，共同构成 `Graphics[list]` 的列表内容。

## 命令清单（表 20.15）

| 条目 | 释义 |
|---|---|
| `PointSize[a]` | 描绘半径为 a 的一个点作为整个图像的一部分 |
| `AbsolutePointSize[b]` | （以美制度量单位 pt（0.3515mm））表示该点的绝对半径 b |
| `Thickness[a]` | 描绘相对粗细度为 a 的线 |
| `AbsoluteThickness[b]` | 描绘绝对粗细度为 b（也以 pt 度量）的线 |
| `Dashing[{a1,a2,a3,...}]` | 描绘由一系列具有给定长度（按相对单位度量）的线条构成的线 |
| `AbsoluteDashing[{b1,b2,...}]` | 和前面一样但按绝对单位度量 |
| `GrayLevel[p]` | 指定灰度水平（p=0 表示黑, p=1 表示白） |

## 相对/绝对双轨制

本节独有的知识点是三对命令的「相对/绝对」双轨制：`PointSize`/`AbsolutePointSize`、`Thickness`/`AbsoluteThickness`、`Dashing`/`AbsoluteDashing`。相对形式的参数以整个图像的比例为度量（随图像缩放），绝对形式以 pt 绝对单位度量（原书注 1 pt = 0.3515 mm——此换算与通行 PostScript 点 1/72 英寸 ≈ 0.3528 mm 不符，而接近传统排版点 1/72.27 英寸 ≈ 0.3515 mm，见 [[pt换算0点3515毫米之辨]] 与 [[相对与绝对图形尺寸命令比较]]）。`GrayLevel[p]` 为无量纲灰度（0 黑、1 白），无绝对变体；另有规模广泛的颜色可供选择，原书不做讨论。

## 作用域规则

「这个命令对于对应花括号中的所有对象都成立，也对嵌套对象成立，但对列表中花括号以外的对象不成立。」直接证据是式 20.38a–b 的构建算例：`o3 = {Thickness[0.01], o2}`，则 `g2 = Graphics[{o1, o3}]` 中仅 o3 花括号内的圆变粗，括号外的 o1（椭圆与水平线）不受影响（[[式20-37至20-38b图形对象构建算例复算]]）。这与 [[图形选项（Mathematica）]] 影响整幅图像的作用层次形成对照。

## 应用与现代形态

- 指数函数族算例以 `PlotStyle->Dashing[{0.001, 0.02}]`、`Dashing[{0.005, 0.02, 0.001, 0.02}]` 区分曲线（[[式20-39至20-43函数绘图与Show复算]]）。
- 在当代版本的 `InputForm` 输出中，图形命令被纳入复合指示：`Directive[Opacity[1.], RGBColor[0.368417, 0.506779, 0.709798], AbsoluteThickness[1.6]]`（[[InputForm图形对象内部结构转录校勘]]）。
