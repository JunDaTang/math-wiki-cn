# 里斯–费希尔定理

里斯–费希尔定理（手册与 (12.130) 合并陈述）断言：设 {e_n} 是（可分）希尔伯特空间 H 中的正交规范系。若 {α_n} 是满足 Σ_{n=1}^∞ ∣α_n∣² < ∞ 的任一数列（即 {α_n} ∈ ℓ²，见 [[entities/lp空间]]），则存在元 x ∈ H，其傅里叶系数等于 α_n，并且成立 [[concepts/帕塞瓦尔等式]]：

$$
\sum_{n=1}^{\infty} |(x, e_n)|^2 = \sum_{n=1}^{\infty} |\alpha_n|^2 = \|x\|^2. \tag{12.130}
$$

## 内容解读

- **方向**：从系数空间 ℓ² 到希尔伯特空间 H——每个 ℓ² 数列都可实现为某个元的傅里叶系数且能量守恒。与 [[concepts/贝塞尔不等式]]（从 H 到 ℓ² 的方向：系数自动属于 ℓ²）合成双向对应。
- **唯一性**：转录本作「存在唯一元 x∈H」。按独立复算：仅满足「傅里叶系数 = α_n」的元一般不唯一（可加 H₀ = lin{e_n}‾ 的正交补中任一向量而系数不变）；若把帕塞瓦尔等式并入对 x 的要求，或限定 x ∈ H₀，或系统完备，则唯一。原书本意待核，见 [[queries/式12-130前句唯一性的适用范围]]。
- **与分类定理的联系**：定理说明傅里叶系数映射在完备正交规范系下实现 H 与 ℓ² 的保积对应，是 [[concepts/等距希尔伯特空间]] 中「每个（无穷维）可分希尔伯特空间与 ℓ² 等距」的构造性内核。
