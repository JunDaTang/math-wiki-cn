# 本原多项式（有限域意义）

有限域语境下的本原多项式是这样的不可约多项式 f(x) ∈ K[x]：x 的幂表示 L := K[x]/f(x) 的所有非零元素，即 L 的乘法群 L* 可由 x 生成。本源仅在有限域计算意义下使用「本原」一词。

## 与乘法群循环性的联系

有限域 K 的乘法群 K* = K \ {0} 是循环群（见 [[findings/有限域乘法群循环性与本原多项式]]）。于是：不可约 f 本原 ⇔ x 是 L* 的生成元 ⇔ x 在 L 中的阶为 pⁿ − 1。

## 应用

- **对数表**：应用 n 次本原多项式 f(x) 可从 GF(p)[x] 构造 GF(pⁿ) 的对数表，把域元素乘法化为对数（模 pⁿ − 1）加法（见 [[methodology/gf对数表构造与运算流程]]）；
- **LFSR 极大周期**：长度 r 的线性反馈移位寄存器给出极大周期 2ʳ − 1 的状态序列 ⇔ 反馈多项式是 r 次本原多项式（见 [[entities/线性反馈移位寄存器]]）。

## 例子

f(x) = 1 + x + x³ ∈ ℤ₂[x] 是本原的：x 的阶为 7 = 2³ − 1（已复算 ✓，见 [[findings/gf23构造与对数表算例]]）。
