# 余弦函数

余弦函数是六种[[concepts/三角函数]]之一，标准形式为

$$y = \cos x = \sin\left(x + \frac{\pi}{2}\right) \tag{2.65}$$

即正弦函数向左平移 π/2 的结果；周期 $T = 2\pi$，值域 $[-1, 1]$。一般余弦函数

$$y = A\cos(\omega x + \varphi_0) \tag{2.66}$$

可变换为

$$y = A\sin\left(\omega x + \varphi_0 + \frac{\pi}{2}\right) \tag{2.67}$$

即相位增加 π/2 的一般正弦（原文「向左平移 φ = π/2 个单位」的表述存在相位与 x 向平移量混同的疑点，见 [[queries/一般余弦平移π除2个单位是否应为π除2ω]]）。

## 图像要素

与正弦的要素恰好按 π/2 平移对调：

- 与 x 轴交点 $B_k = \left(\left(k+\frac{1}{2}\right)\pi,\ 0\right)$（k = 0, ±1, ±2, …），均为[[concepts/拐点]]，切线倾斜角 $\pm\frac{\pi}{4}$；
- [[concepts/极值]]点 $C_k = (k\pi,\ (-1)^k)$。
