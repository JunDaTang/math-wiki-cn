# 对称运算与对称元素

**对称运算**是空间到自身的映射，它保持线段长度不变，并将所考察的空间个体变到与自身相适应的位置（即与原个体重合）；其不动点的集合 $\operatorname{Fix}(S)$——所有对于 $S$ 保持不变的空间点——称为 $S$ 的**对称元素**。对称运算用 Schoenflies 记号表示（原文译名「申弗利斯／申弗莱斯」前后不一，本 wiki 统一作 Schoenflies）。

## 两类对称运算

1. **无不动点对称运算**：空间中没有一点保持不变，典型例子是平移。对有界的空间个体这种运算不可能出现（原文「但现在只考虑这种个体」一句转写残缺，疑为「但现在只考虑这种（有界）个体」）。
2. **至少有一个不动点的对称运算**：如旋转与反射。这是点群（[[concepts/点群]]）的来源。

## Schoenflies 记号（5.3.5.1 原文）

| 记号 | 含义 |
|---|---|
| $C_n$ | 绕轴旋转角 $\varphi=2\pi/n$；旋转轴与旋转本身都记作 $C_n$，轴称 $n$ 阶（原文「称作 阶的」脱落 $n$） |
| $\sigma$ | 对平面的反射；反射平面与反射本身记作 $\sigma$ |
| $\sigma_h$ | 垂直于（画成直立的）主旋转轴的反射平面（h = horizontal，水平） |
| $\sigma_v$ | 通过旋转轴的反射平面（v = vertical，垂直） |
| $\sigma_d$ | 过轴且平分某些角的反射平面（d = dihedral，二面体） |
| $S_n$ | 非正常正交映射：旋转 $C_n$ 后紧接 $\sigma_h$；轴称 $n$ 阶非正常旋转轴（实施 $S_n$ 时只有对称中心保持不变） |
| $i$ | $n=2$ 时的 $S_2$：点反射／反演（参见原书 4.3.5.1，未入库） |

注意：旋转与反射交换，故 $S_n$ 中「先旋转后反射」的次序不敏感。$S_n$ 的「轴」被称作对称元素，尽管实施运算时只有对称中心不动——这是 $S_n$ 记号的一个语义特例。

## 与群构造的关系

一族空间个体的对称运算对相继实施形成一个群（一般非交换），即对称群／点群；逆运算的存在由式 (5.121) 保证（见 [[concepts/点群]]）。平移作为无不动点运算单独发展出 [[concepts/平移群]]，并在晶体学中与点群运算复合成 [[entities/空间群]]。
