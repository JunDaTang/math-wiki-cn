# evalf 与 evalhf

evalf 与 evalhf 是 Maple 中对（包含内置和用户定义函数的）实值表达式作数值求值的两个算子（19.8.4.3），分别代表「任意精度软件浮点」与「硬件双精度」两条路线，构成 Maple 小节速度—精度权衡的核心。

## evalf（式 19.293）

evalf(expr, n) 能作为实数求值的表达式的数值：expr 为其值待定的表达式，参数 n 可选，估计达到 n 位精度；默认的精度由全局变量 Digits 确定。计算要求的节点数可由规定 Digits 的任意值确定，但应记住选取比规定值大的 Digits 会导致计算速度降低。

## evalhf

用法类似于 evalf，变量也是实值表达式；使用计算机上可行的硬件浮点双精度计算，求符号表达式的数值。回到 Maple 浮点值时，大多数情况下使用 evalhf 加速计算，但同时相对 evalf 损失 Digits 定义的精度——例如在 19.8.2 的问题中，可能产生相当大的误差（该小节尚未入库，见 [[queries/19-8-4未入库回指缺口]]）。

## 算例

```txt
> f := z -> sqrt(z) + ln(z);
> for x from 1 by 0.2 to 4 do print(f[x] = evalf(f(x), 12)) od
```

输出为形如 f[3.2] = 2.95200519181 的函数值表（要求 12 位计算；步长 0.2，自 1 至 4）。复算证实 sqrt(3.2)+ln(3.2) = 2.95200519181；源文「2095200519181」为小数点转写讹误（[[queries/f3-2输出2095200519181疑脱小数点之辨]]）。
