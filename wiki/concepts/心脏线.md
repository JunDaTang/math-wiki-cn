# 心脏线

**心脏线**是恰有一个尖点（回流点）的四阶（四次）平面代数曲线，形如心形。它在手册中以双重身份出现：在四阶曲线体系中，它是 [[帕斯卡蜗线]] 在 $a = l$ 时的特例，等价地定义为定圆与动圆具有相同直径 $a$ 时的外摆线特例（2.12.4）；在 [[摆线族|摆线族]] 中，它是 $m = 1$ 的外摆线（2.13.3），即动圆与定圆半径相等、动圆沿定圆外侧无滑动滚动时圆周上一点的轨迹。此外，$\lambda = 1$ 且 $A = a$ 的外旋轮线（2.13.5）退化为心脏线，构成同一对象的第三种刻画。因此，心脏线是蚌线族与摆线族两个体系的公共成员。

## 在四阶曲线体系中（2.12.4）

心脏线在 2.12.4 中作为 [[帕斯卡蜗线]] 的特例给出，是蚌线族三级特化链（一般蚌线 → 尼科梅德斯蚌线 → 帕斯卡蜗线 → 心脏线）的终点，参见 [[蚌线的一般构造与三级特化]] 与 [[心脏线的两种定义与特征量]]（式 2.236–2.237）。手册在此给出两种定义：

1. **蜗线特例**：帕斯卡蜗线取 $a = l$ 的情形，即满足 $\overline{OP} = \overline{OM} \pm a$（式 2.236）的蜗线，其中 $a$ 为圆直径；
2. **外摆线特例**：定圆与动圆具有相同直径 $a$ 时的外摆线。该定义涉及的摆线族内容在 2.12.4 中未展开，仅以「第 136 页 (2.246c)」作前向引用；摆线族一侧的表述见下文「在摆线族中」一节。

### 方程

- 隐式：$(x^2+y^2)^2 - 2ax(x^2+y^2) = a^2y^2$（式 2.237a，$a > 0$）；
- 参数式：$x = a\cos\varphi(1+\cos\varphi),\ y = a\sin\varphi(1+\cos\varphi)$（式 2.237b，$0 \le \varphi < 2\pi$）；
- 极坐标：$\rho = a(1+\cos\varphi)$（式 2.237c）。

### 特征量

- 原点为尖点，属于 [[曲线的奇点三型]] 中的尖点型；顶点 A(2a, 0)；
- 极值点：$\cos\varphi = \frac{1}{2}$ 处的 C, D，坐标 $\left(\frac{3}{4}a, \pm\frac{3\sqrt{3}}{4}a\right)$；
- 面积 $S = \frac{3}{2}\pi a^2$（手册文字「即为圆的面积与直径 a 乘积的六倍」量纲不符，疑应为「以 a 为直径的圆面积的六倍」，见 [[心脏线面积文字圆的面积与直径a乘积的六倍是否为误]]）；
- 曲线长 $L = 8a$。

验证与自洽性检查见 [[心脏线的两种定义与特征量]]。作为蜗线族的临界特例，其地位与卡西尼族中的 [[双纽线]] 平行，对照见 [[双纽线与心脏线比较]]。

## 在摆线族中（2.13）

手册 2.13 从两个入口得到心脏线：$m = 1$ 的外摆线（2.13.3）与 $\lambda = 1$ 外旋轮线的退化（2.13.5）。

### 作为 $m = 1$ 的外摆线（2.13.3）

手册原文：「当 $m = 1$ 时，曲线为心脏线(参见第129页2.12.4)」。即式 2.244 中取 $A = a$：

$$x = 2a\cos\varphi - a\cos 2\varphi, \qquad y = 2a\sin\varphi - a\sin 2\varphi \quad (\text{式 2.244 取 } A = a).$$

在此参数化（以滚动圆半径 a 为尺度）下，由外摆线通用公式可推得（推导，非手册明文，均与经典结果一致）：

- 全曲线总长 $L_{\text{总}} = 8(A+a) = 16a$；
- 区域 $A_1B_1A_2A_1$（不含定圆部分）面积 $S = \pi a^2\dfrac{3A+2a}{A} = 5\pi a^2$，加定圆面积 $\pi a^2$ 得曲线围成的全面积 $6\pi a^2$；
- 顶点处曲率半径 $r_B = \dfrac{4a(A+a)}{2a+A} = \dfrac{8a}{3}$。

### 作为外旋轮线的退化（2.13.5）

$\lambda = 1$ 且 $A = a$ 的外旋轮线（式 2.246a / 2.246c）退化为 $m = 1$ 外摆线，即心脏线——同一对象的第三种刻画。

## 跨章参数换算（未决）

手册对帕斯卡蜗线给出了两章参数的显式换算注（见 [[帕斯卡蜗线]]），对心脏线只写「参见 2.12.4」而未给换算；两章坐标系不同、参数 a 含义不同。

> [!warning] 两组特征量不可直接对照
> 「在四阶曲线体系中」与「在摆线族中」两节的特征量以含义不同的参数 $a$ 表出（如 $L = 8a$ 与 $L_{\text{总}} = 16a$、$S = \frac{3}{2}\pi a^2$ 与全面积 $6\pi a^2$），须先完成参数换算方可比较。

换算关系的推导与面积陈述的核对见 [[心脏线在2-12-4与2-13-3的参数换算]]。
