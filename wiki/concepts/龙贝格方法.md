# 龙贝格方法

龙贝格方法是为提高数值积分精度而设计的外推加速方法：从梯形求和序列出发，反复对分积分步长，再对相继步长的梯形值做逐阶外推，按三角格式组织。

三个构件：

1. **步长折半序列** (19.85)：$h_i = (b-a)/2^i$（i = 0,1,…,m）。
2. **梯形和递归** (19.86)：$T(h_i) = \frac{1}{2}T(h_{i-1}) + \frac{h_{i-1}}{2}\sum_{j=0}^{n-1} f\!\left(a + \frac{h_{i-1}}{2} + j h_{i-1}\right)$（n = 2^{i−1}）——由 T(h_{i−1}) 计算 T(h_i) **仅需在新增插值节点计算函数值**，旧值全部复用。
3. **外推** (19.87)：$T_{k,i} = T_{k-1,i} + \dfrac{T_{k-1,i} - T_{k-1,i-1}}{4^k - 1}$（k = 1,…,m；i = k, k+1, ⋯），元素按**三角格式** (19.88) 逐列计算，直到右下角数值几乎相同为止。

性质：第二列 $T_{1,i}$ 相应于由辛普森公式计算得到的值（算例强验证）；第 k 列误差阶 2k+2，即 $T_{k,i} = I + O(h_i^{2k+2})$ (19.92)。理论基础是 [[concepts/外推原理]]（梯形和误差的偶次幂渐近展开）。算法细节见 [[methodology/龙贝格方法算法流程]]；算例见 [[findings/正弦积分Si(1)算例全表复算]]。源引言「龙贝(Romberg) 方法」疑脱「格」字，规范名取「龙贝格」（[[queries/龙贝疑脱格字之辨]]）。
