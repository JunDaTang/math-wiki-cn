# ε-主动约束集

ε-主动约束集是 [[concepts/主动约束集]] 的推广：在迭代点 $x^k$ 处，把满足 $-\varepsilon_k\leqslant g_i(x^k)\leqslant 0$（$\varepsilon_k\geqslant 0$）的**近主动约束**也纳入标号集（式 18.101），用于 [[concepts/可行方向方法]] 的方向搜索程序中替代 $I_0(x^k)$，以抑制迭代序列贴可行集边界振荡的锯齿形行为。

## 定义（式 18.101）

```
I_{ε_k}(x^k) = {i ∈ {1,…,m} : −ε_k ⩽ g_i(x^k) ⩽ 0},   ε_k ⩾ 0
```

$\varepsilon_k=0$ 时 $I_{\varepsilon_k}(x^k)=I_0(x^k)$，退化为通常的主动约束标号集。

## 作用机制

- 采用 $I_{\varepsilon_k}$ 后，从 $x^k$ 出发的局部下降方向被排除，迭代越来越接近由 $\varepsilon_k$-主动约束组成的可行集边界（原书图 18.7）；
- 平稳性判定随之修正：若修正后的方向搜索程序仍得 $\sigma=0$，仅当 $I_0(x^k)=I_{\varepsilon_k}(x^k)$ 时 $x^k$ 才是平稳点；否则必须**减小 $\varepsilon_k$** 并重解方向搜索程序。

## 开放细节

原书未给出 $\varepsilon_k$ 的初始取值与减小策略的具体规则，仅给出上述定性与修正机制；其实现细节是本概念的操作性缺口。在线性约束情形，式 (18.103a) 允许用 $I_0(x^k)$ 或 $I_{\varepsilon_k}(x^k)$ 两种标号集建立程序。
