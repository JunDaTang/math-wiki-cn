# 对称函数的傅里叶系数

**对称函数的傅里叶系数**指利用周期函数的对称性化简后得到的系数公式（手册 7.4.2.1，式 7.107–7.111）：对称性使一部分系数恒为零，并使非零系数的积分限从 [0, T] 减半到 [0, T/2]，甚至减为 [0, T/4]（第四类对称，即「四分之一波对称」quarter-wave）。手册分四类陈述：

| 类型 | 判定条件 | 恒为零的系数 | 非零系数公式 | 积分限 |
|---|---|---|---|---|
| 第一类（式 7.107，图 7.2） | f(x) = f(−x)（偶函数） | b_k = 0 | a_k = (4/T)∫₀^{T/2} f(x)cos(k·2πx/T)dx | [0, T/2] |
| 第二类（式 7.108，图 7.3） | f(x) = −f(−x)（奇函数） | a_k = 0 | b_k = (4/T)∫₀^{T/2} f(x)sin(k·2πx/T)dx | [0, T/2] |
| 第三类（式 7.109a/b，图 7.4） | f(x+T/2) = −f(x) | a_{2k} = b_{2k} = 0 | a_{2k+1}、b_{2k+1} = (4/T)∫₀^{T/2} f(x){cos/sin}((2k+1)·2πx/T)dx | [0, T/2] |
| 第四类·奇（式 7.110，图 7.5(a)） | 奇函数 ∧ 第三类 | a_k = b_{2k} = 0 | b_{2k+1} = (8/T)∫₀^{T/4} f(x)sin((2k+1)·2πx/T)dx | [0, T/4] |
| 第四类·偶（式 7.111，图 7.5(b)） | 偶函数 ∧ 第三类 | b_k = a_{2k} = 0 | a_{2k+1} = (8/T)∫₀^{T/4} f(x)cos((2k+1)·2πx/T)dx | [0, T/4] |

（k = 0, 1, 2, …）
