# 亥姆霍兹微分方程

亥姆霍兹微分方程（Helmholtz differential equation）是

```latex
\Delta\Psi + \lambda\Psi = 0,\qquad \lambda=\frac{2mE}{\hbar^{2}}   % 9.114a,b
```

它在此处是定常薛定谔方程 (9.113a) 在位势 U = 0 时的特殊情形，本征值 λ = 2mE/ℏ²；手册称 (9.114a)「表示有限区域内声振荡的初始数学方程」（该表述疑为「出发方程」之误译或转写问题，见 [[queries/9-2-4全节系统性转写讹误清单]]）。

## 边界条件与角色

- 这里经常要求 Ψ = 0 作为边界条件（第一边界条件问题，参见 [[concepts/狄利克雷问题]]）。
- 桥接作用：同一方程是 9.2.2 中膜振动本征值问题（圆膜振动的贝塞尔本征函数，见 [[findings/式9-94圆膜振动贝塞尔本征函数复算]]）与方盒问题（9.132a 即其三维直角坐标形式，[[concepts/无限深方势阱]]）的共同母体；拉普拉斯算子 Δ 的各坐标展开见 [[concepts/拉普拉斯方程与拉普拉斯算子]]（9.135b 补充了球坐标形式）。
- 在量子力学语境中，其本征值对应自由粒子的能量；若所考虑区域有限，本征值由边界条件离散化。
