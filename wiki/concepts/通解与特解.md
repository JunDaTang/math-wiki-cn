# 通解与特解

通解与特解刻画常微分方程解的两个层级：通解（通积分）是包含 n 个任意常数 c₁, c₂, …, cₙ 的解；当这些常数的值被确定时，就得到特别积分（特解）。二者是第 9 章一切定解问题的出发点。

## 定义（手册 9.1 要点 2）

- **解或积分**：在一个区间 a ≤ x ≤ b（此区间也可以是无限的）上满足微分方程的每个函数。
- **通解 (general solution) / 通积分 (general integral)**：一个包含 n 个任意常数 c₁, c₂, …, cₙ 的解。
- **特别积分 (particular integral) / 特解 (particular solution)**：这些常数的值被确定后所得的解。
- 这些常数的值可以被 **n 个附加条件** 所确定——由此引出 [[concepts/初值问题]] 与 [[concepts/边值问题]]，定常数的操作流程见 [[methodology/附加条件确定通解常数流程]]。

## 与第 8 章的术语衔接

「通积分」「特别积分」直接沿用第 8 章积分学语言：n = 1 时通解 y = F(x) + c 正是带积分常数的不定积分（参见 [[comparisons/定积分与不定积分比较]]）。通解的 n 个任意常数是单一积分常数 +C 向高阶方程的自然推广。

## 手册算例

微分方程 −y′ sin x + y cos x = 1 有通解 y = cos x + c sin x；对于条件 c = 0，得到特解 y = cos x。复算（含「左端 = −sin²x·(y/sin x)′」的化归推导）见 [[findings/9-1三算例复算]]。

注：此处的「条件 c = 0」是对常数本身施加的条件，与初值/边值条件在某点给定 y 值的定义不属同一层面，见 [[queries/例1条件c等于0与边值问题定义宽窄]]。

## 经典定义的局限（背景注）

「含 n 个任意常数的解即通解」的经典表述未覆盖**奇解** (singular solution) 情形，即某些方程存在不含于通解族中的解。此点为本页编者依据通行理论补充的背景注，非手册 9.1 原文内容；手册是否讨论奇解，需待 9.1.1 入库后核对（见 [[queries/9-1-1至9-1-3子小节未入库回指缺口]]）。
