# 阿波罗尼奥斯定理

本源中的阿波罗尼奥斯定理是关于圆锥曲线**共轭直径**的定理（冠名人在原文中转写为「阿波𝒢尼奥斯」）。（独立可查的背景：平面几何中另有关于三角形中线长度的同名「阿波罗尼奥斯定理」，与本文所述定理不同，勿混淆。）

设 2a₁、2b₁ 为两条共轭直径的长，α、β 为它们与长轴（椭圆）或实轴（双曲线）所夹的锐角：

- **椭圆（和式型，(3.324)）**：

```
a₁·b₁·sin(α + β) = ab,    a₁² + b₁² = a² + b²
```

- **双曲线（差式型，(3.339)，其中 β < α）**：

```
a₁² − b₁² = a² − b²,    ab = a₁·b₁·sin(α − β)
```

二者的对偶结构（和↔差、α+β↔α−β）是椭圆与双曲线在共轭直径理论上的系统对应之一，见 [[concepts/共轭直径]] 与 [[comparisons/椭圆双曲线抛物线比较]]。注意两式分别绑定椭圆与双曲线，不得互换使用。
