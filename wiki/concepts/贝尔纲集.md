# 贝尔纲集

**贝尔纲集**（Baire category set，词源人名 Baire，本维基未为其单独立页）在本手册 17.1.4.3 中的口径为：度量空间 M 的子集 B 称为**第二贝尔纲集**，若 B = ∩_{m=1,2,…} B_m，其中每个 B_m 是开集且在 M 中稠密。

口径差异：这一口径等价于标准术语中的**余密集**（residual set，可数个开稠密集之交）；而标准术语的「第二纲集」仅指「非第一纲集」，两者不等价。引用手册该术语时应读作余密集，见 [[queries/第二贝尔纲集定义口径疑为余密集之辨]]。

## 基本例（手册给出）

- 无理数集 𝕀 ⊂ ℝ 是第二贝尔纲集；有理数集 ℚ 不是（ℚ 为可数个无处稠密单点集之并，属第一纲——此展开为源外补注）。
- ℚ 与 𝕀 都在 ℝ 中稠密，但并非都通有，故稠密性不足以刻画[[concepts/通有性|通有性]]。

## 通有却勒贝格零测的算例

```
B = ∩_{k=1,2,…} B_k，B_k = ∪_{n≥0} (a_n − 1/(k·2ⁿ), a_n + 1/(k·2ⁿ))，ℚ = {a_n}_{n=0}^∞
λ(B) = lim_{k→∞} λ(B_k) ≤ lim_{k→∞} (2/k)·(1/(1−1/2)) = 0
```

B 是第二贝尔纲集（各 B_k 开且稠密）但 λ(B)=0：贝尔纲意义下的「大」与勒贝格测度意义下的「大」互不蕴含（原文「λ(B) = lim B_k」疑脱漏 λ；λ 在原文多处 OCR 作「入」）。复算见 [[findings/贝尔纲集零测余密集算例复算]]，构造流程见 [[methodology/贝尔纲余密集构造与测度上界估计流程]]，与测度的系统比较见 [[comparisons/贝尔纲通有性与勒贝格测度比较]]。
