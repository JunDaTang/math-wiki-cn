# 折旧

折旧是把资产因陈旧过时或物质因素而下降的服务潜能加以计量的方法：将报告年度开始时的原值（原价）减少到年末残值（手册 1.3.5.1）。

## 基本记号

- A：折旧基数（原价/购置成本）；
- N：有效期限（以年计）；
- $R_n$：n 年后的残值（$n \leqslant N$）；
- $a_n$（n = 1, 2, …, N）：第 n 年的折旧额（手册称"折旧率"）。

## 方法谱系

手册把折旧法分为两大族，并给出四种方法及一种混合法：

- **直线法**（年折旧额相等）：[[直线折旧]]，式 (1.88)–(1.89)；
- **递减分摊法**（年折旧额递减）：[[算术递减折旧]]（含数字递减特例），式 (1.90)–(1.94)；[[几何递减折旧]]，式 (1.95)；
- **混合法**：前段几何递减、适时转直线，判据为 $m > N - \frac{100}{p}$ (1.96)。

各方法的并排对比见 [[折旧方法对比]]。手册共同算例为 A = €50000、N = 5、R₅ = €10000 的机器；图 1.4 另以 A = €1000、n = 1,…,10 对比三种方法的残值曲线（见 [[10-数学手册原书第10版--7-13-商业数学--k55pur]]）。

## 与其他内容的联系

- 直线法是算术递减 d = 0 的特例；数字递减是算术递减 $a_N = d$ 的特例（手册明示）。
- 几何递减由 $R_N, p, N$ 三量知二求一时需用[[对数]]（ln）求解。
- 几何递减折旧残值对有限 n 永不为零，由此引出转直线判据 (1.96)，见 [[几何折旧残值不为零及转直线判据]]。
