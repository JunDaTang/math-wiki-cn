# 期望

**期望**（记号 $\mu$ / $\mu_X$ / $E(\cdot)$）是随机变量按概率（或按密度）加权的平均值，是粗糙描述随机变量分布时最常用的位置参数。若用力学术语解释，期望指由密度函数曲线 $f(x)$ [与 $x$ 轴] 围成的曲面重心的横坐标（源文措辞待核，见 [[queries/面积解释句疑脱与x轴]]）。

## 定义

若 $g(X)$ 是随机变量 $X$ 的函数，则 $g(X)$ 也是随机变量，其期望值或期望定义为：

a) **离散情形**

$$E(g(X)) = \sum_k g(x_k)p_k, \tag{16.49a}$$

条件为级数 $\sum_{k=1}^{\infty}|g(x_k)|p_k$ 收敛（源文此处「凇」为衍字，见 [[queries/式16-49a凇字衍文之辨]]）。

b) **连续情形**

$$E(g(X)) = \int_{-\infty}^{+\infty} g(x)f(x)\,\mathrm{d}x, \tag{16.49b}$$

条件为 $\int_{-\infty}^{+\infty}|g(x)|f(x)\,\mathrm{d}x$ 存在。

当 $g(X) = X$ 时得到随机变量自身的期望：

$$\mu_X = E(X) = \sum_k x_kp_k \quad \text{或} \quad \int_{-\infty}^{+\infty} xf(x)\,\mathrm{d}x, \tag{16.50a}$$

只要对应的级数或积分绝对收敛。随机变量 $g(X)$ 的期望也可能不存在。

## 仿射性质

$$E(aX + b) = a\mu_X + b \quad (a, b \text{ 是常数}). \tag{16.50b}$$

注意：平移不变性 $D^2(aX+b) = a^2D^2(X)$ 属于 [[concepts/方差与标准差]]；两条性质归属不同概念对象，不得混引。

## 加权平均与算术平均解释

在离散情形下，期望显然是数值 $x_1, \dots, x_n$ 以概率 $p_k\ (k = 1, \dots, n)$ 作为权重的**加权平均**：

$$E(X) = p_1x_1 + \dots + p_nx_n. \tag{16.54}$$

均匀分布（$p_1 = p_2 = \dots = p_n = 1/n$）时，$E(X)$ 是 $x_k$ 的**算术平均**：

$$E(X) = \frac{x_1 + x_2 + \dots + x_n}{n}. \tag{16.55}$$
