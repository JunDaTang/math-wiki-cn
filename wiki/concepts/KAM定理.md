# KAM 定理

**KAM 定理**（柯尔莫哥洛夫—阿诺德—莫泽定理，Kolmogorov-Arnold-Moser；冠名人见 [[entities/柯尔莫哥洛夫]]、[[entities/阿诺德]]、[[entities/莫泽]]）是本节引用的最重要外部定理，处理[[concepts/哈密顿系统（作用—角变量）|哈密顿系统]]在小扰动下拟周期运动的存续问题：

> 若 H₀(j₁,j₂) 是**非退化**的解析哈密顿函数，即 det(∂²H₀/∂j_k²) ≠ 0，则在扰动的哈密顿系统 H₀ + εH₁（H₁ 解析，ε>0 小）中，当 ε 充分小时，**大多数**不变非共振环面不会消失，但会有轻微的变形。「大多数环面」指：当 ε 趋于 0 时，这些环面余集的勒贝格测度趋于 0。

转录疑点：非退化条件中的 det(∂²H₀/∂j_k²) 只写了纯二阶偏导，疑漏混合偏导，标准口径应为完整黑塞矩阵的行列式，见 [[queries/KAM非退化条件黑塞行列式疑漏混合偏导之辨]]。

## 非共振（丢番图型）条件

由频率 ω₁, ω₂ 描述的环面称为**非共振**的，如果存在常数 c>0 使得对任意正整数 p, q：

```
|ω₁/ω₂ − p/q| ≥ c/q^{2.5}
```

即频率比以 q^{−2.5} 的速率远离一切有理数（源外注：此即丢番图型条件，指数 2.5 的具体取值属手册口径）。共振环面上的轨道为周期轨，非共振环面上的轨道为**拟周期轨**（环面上的多频线性流，见 [[concepts/哈密顿系统（作用—角变量）]]）。

## 适用范围与解读

- 定理仅针对非退化、解析的二自由度哈密顿系统与小哈密顿扰动，**不可推广**至任意哈密顿或耗散系统。
- 「大多数环面保持」是测度意义上的结论，与「哈密顿系统在全体光滑向量场空间中非通有」（[[concepts/通有性]]）口径不同：前者是哈密顿类内扰动，后者是全空间陈述，二者逻辑自洽。
- 与保守系统知识的关系：KAM 表明保守系统中拟周期行为在小扰动下具有某种刚性，见 [[concepts/耗散系统与保守系统]]（待补注记）。
