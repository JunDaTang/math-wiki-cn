# 选择压力

**选择压力** S 是 [[演化策略]] 中量化选择强度的量，定义为参与选择的个体与种群大小之比（式 18.94）：

```latex
S = \begin{cases}
\dfrac{\lambda+\mu}{\mu}, & \text{对于 } (\lambda+\mu) \text{ 策略},\\[6pt]
\dfrac{\lambda}{\mu}, & \text{对于 } (\lambda,\mu) \text{ 策略},
\end{cases}
\quad 1 \leqslant S < \infty
\tag{18.94}
```

即：对「+」型策略（亲本参与选择，候选集为 λ 个后代 ∪ μ 个亲本）S = (λ+μ)/μ；对「,」型策略（仅 λ 个后代参与选择）S = λ/μ。

## 行为主张（经验断言，源中无证明）

- 如果选择压力接近 1（原文此处脱「1」，作「接近千 ，」），则这种选择方式几乎没有影响。
- 大量的后代，即 λ ≫ μ，会导致很大的选择压力，因为当前个体集合中只有少数几个会存活到下一代。

## 记号疑点

式 18.94 及 18.2.6.7 相应段落使用 (λ+μ)/(λ,μ) 记号顺序，而 18.2.6.3 与 18.2.6.7.1 主体用 (μ+λ)/(μ,λ)；疑为同一策略族的两种写法，是否原书如此待核，见 [[λ+μ与μ+λ记号顺序之辨]]。

## 与两类策略的关系

选择压力统摄 (μ+λ) 与 (μ,λ) 的权衡：(μ+λ) 亲本参与选择、代际质量不降、保持局部最优；(μ,λ) 亲本不存活、允许后代劣于亲本、可自局部最优逃逸。系统对照见 [[μ+λ与μ，λ演化策略比较]]；转录与一致性核验见 [[式18-94选择压力公式转录]]。
