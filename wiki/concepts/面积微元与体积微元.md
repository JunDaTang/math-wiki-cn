# 面积微元与体积微元（表 8.8 与表 8.11）

面积微元 $\mathrm{d}S$ 与体积微元 $\mathrm{d}V$ 是多重积分在各坐标系下的无穷小度量。《数学手册(原书第10版)》8.4 将其收列于两张小表：**表 8.8 平面面积微元**（正文两处回指「699 页的表 8.8」）与**表 8.11 体积微元**（正文回指「第 705 页表 8.11」）。两表内容分别与式 8.136b/8.137a/8.140b、式 8.144a/8.145a/8.147b 完全一致，故不单独立实体页，由本概念页收编。

## 平面面积微元（表 8.8）

| 坐标 | 面积微元 |
|---|---|
| 笛卡儿坐标 x,y | dS = dy dx |
| 极坐标 ρ,φ | dS = ρ dρ dφ |
| 任意曲线坐标 u,v | dS = \|D\| du dv（D 为雅可比行列式） |

## 体积微元（表 8.11）

| 坐标 | 体积微元 |
|---|---|
| 笛卡儿坐标 x,y,z | dV = dx dy dz |
| 柱面坐标 ρ,φ,z | dV = ρ dρ dφ dz |
| 球坐标 r,θ,φ | dV = r² sin θ dr dθ dφ |
| 任意曲线坐标 u,v,w | dV = \|D\| du dv dw（D 为雅可比行列式） |

## 语义注记

1. **统一来源**：各行微元均为 [[concepts/雅可比行列式]] 的特例值——$\rho$（极、柱面）、$r^2\sin\vartheta$（球面）、$|D|$（一般曲线坐标），见 [[concepts/曲线坐标系下的积分换元]]。
2. **平移不变 vs 位置依赖**：笛卡儿小矩形面积 $\Delta x\Delta y$ 与位置无关；极坐标小扇区面积 $\rho\,\mathrm{d}\rho\,\mathrm{d}\varphi$ 随离原点距离增大而增大（原书 8.4.1.2.2 括注即为此对比；转写「与 x 的值无关」疑脱 y 字）。
3. **正文与表不吻合**：8.4.1.3 文字称表 8.8 给出「笛卡儿坐标系和极坐标系」两种微元，而表实含任意曲线坐标第三行。
4. **坐标列序不一致**：表 8.11 记「球坐标 r,θ,φ」，正文（式 8.145a–b）用 $(r,\varphi,\vartheta)$ 且 $\vartheta$ 为极角——内容一致、书写顺序不一。
5. 上述 3、4 两条连同「表」字脱漏等转写问题见 [[queries/8-4全节系统性转写讹误清单]]。

## 与微元法的关系

$\mathrm{d}S$、$\mathrm{d}V$ 是 [[concepts/微元法]]「以不变代变」在二维、三维的度量实现；以其为被积「权」的成表应用见 [[entities/表8-9二重积分的应用]] 与 [[entities/表8-10三重积分的应用]]。
