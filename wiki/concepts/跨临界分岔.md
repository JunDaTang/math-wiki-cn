# 跨临界分岔

**跨临界分岔**（transcritical bifurcation）是余维 1 的平衡点分岔，截尾正规形式（无高阶项）：

```latex
\dot{x} = \alpha x - x^{2}
```

由来：在鞍结点分岔的非退化条件中，以 ∂F/∂ε(0,0)=0 与 ∂²F/∂x∂ε(0,0)≠0 取代 ∂F/∂ε(0,0)≠0，由约化方程 (17.69) 即得。对正规形式的直接分析：平衡点为 0 与 α，F′(0)=α、F′(α)=−α，故 α 变号时两平衡点稳定性互换（n=2、λ₂<0 情形相图见图 17.23）。鞍结点分岔与跨临界分岔的余维数均为 1；跨临界需附加结构（如 x=0 恒为平衡点）方在无约束族中出现。比较见 [[余维一平衡点分岔正规形式比较]]。
