# 自然数

自然数是来源于计数和排序概念的数；《数学手册(原书第10版)》在 1.1.1.1 约定自然数集为 ℕ = {0, 1, 2, 3, …}（含 0），并称自然数为“非负整数”。

## 定义与记号

```latex
\mathbb{N} = \{0,1,2,3,\dots\}
```

## 记号约定

手册取 ℕ∋0，这一约定与部分文献（ℕ 从 1 开始）不同，属本书的记号决定（见 [[findings/数学手册记号约定-数系与区间]]）。手册注明相关符号参见第 439 页 5.2.1 的记号表（前向引用，未编目）。

## 在数系中的位置

ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ（见 [[comparisons/数系分类层级]]）。[[concepts/数学归纳法]]（手册 1.1.2 节）依赖 ℕ 的这一记号约定。本页内容较为单薄，主要作为数系层级中的一层，详细性质见 [[concepts/有理数]]。
