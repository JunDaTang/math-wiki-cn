# 赋范代数与巴拿赫代数

赋范代数（完备时称巴拿赫代数）是在 [[concepts/赋范空间]]（[[concepts/巴拿赫空间]]）上附加与范数相容的乘法运算的代数结构。据本源 12.3.4：

## 代数与代数公理

𝔽 上的向量空间 X 称作一个**代数**，指除向量空间公理 (V1)–(V8)（第 855–856 页 12.1.1，未入库）外，还对任意 x, y ∈ X 定义乘积 xy，使得对任意 x, y, z ∈ X 和 α ∈ 𝔽 满足：

- (A1) x(yz) = (xy)z　（式 12.95，结合律）
- (A2) x(y + z) = xy + xz　（式 12.96，左分配律）
- (A3) (x + y)z = xz + yz　（式 12.97，右分配律）
- (A4) α(xy) = (αx)y = x(αy)　（式 12.98，标量相容）

代数称作**交换的**，指对任意 x, y 有 xy = yx。代数 X 到代数 Y 的线性算子 T 称作**代数同态**，指 T(x₁·x₂) = Tx₁·Tx₂（式 12.99）。

## 赋范代数

一个代数称作**赋范代数**（为巴拿赫空间时称**巴拿赫代数**），指它是赋范空间（巴拿赫空间）且范数具有次乘性：

‖x·y‖ ≤ ‖x‖·‖y‖　（式 12.100）

在赋范代数中所有运算连续：除式 12.85 外，xₙ→x、yₙ→y 蕴涵 xₙyₙ→xy（援引 [12.23]）。每个赋范代数都可完备化成为巴拿赫代数，根据式 12.100 可把乘积延拓至完备化空间。注意：次乘性是赋范代数的**定义要求**，不是任意赋范空间的性质。

## 四个例子

- **例 A**：𝒞([a,b])，赋以「(12.80e)」范数（疑应为式 12.89e 的上确界范数，见 [[queries/12-3-4例A回指12-80e应为12-89e]]），乘积为连续函数通常的逐点相乘。
- **例 B**：[0, 2π] 上所有连续且具有绝对收敛傅里叶级数展开的复值函数组成的向量空间 W([0, 2π])（通常称维纳代数）。若 x(t) = Σ_{n=−∞}^{∞} cₙe^{int}（式 12.101），则范数为 ‖x‖ = Σ_{n=−∞}^{∞}|cₙ|，乘积为通常的函数相乘。（转录本正文作「[O, 兀]」即 [0, π]，与 W([0, 2π]) 记法冲突，见 [[queries/12-3-4例B区间不一致]]。）
- **例 C**：赋范空间 X 上所有有界线性算子组成的空间 L(X)，取算子范数和通常的代数运算，两个算子的乘积定义为 TS(x) = T(S(x))。（转录本缺失标签「C」。）
- **例 D**：实轴上可测且绝对可积函数的空间 L¹(−∞, ∞)（回指第 905 页 12.9，未入库），赋以范数 ‖x‖ = ∫_{−∞}^{∞}|x(t)|dt（式 12.102），乘积为卷积，源文明言「是一巴拿赫代数」，见 [[concepts/卷积]]。

四例异同见 [[comparisons/赋范代数四例比较]]。
