# 定比分割

定比分割是按分割比 λ = m/n = P₁P/PP₂ 在直线 P₁P₂ 上确定点 P 的方法，坐标公式为

```
x = (n·x₁ + m·x₂)/(n + m) = (x₁ + λ·x₂)/(1 + λ)   (3.294a)
y = (n·y₁ + m·y₂)/(n + m) = (y₁ + λ·y₂)/(1 + λ)   (3.294b)
```

线段 P₁P₂ 的中点对应 λ = 1，得 x = (x₁+x₂)/2、y = (y₁+y₂)/2 (3.294c,d)。

对 P₁P 与 PP₂ 采用有向线段约定（符号取决于方向是否与 P₁P₂ 一致）后：λ < 0 给出线段之外的外分点；λ > 0 为内分。三个退化情形：λ = 0 ⟺ P = P₁；λ = ∞ ⟺ P = P₂；λ = −1 ⟺ P 是直线 g 上的无穷远点（反常点）。另一个常用值：若 P₂ 是线段 P₁P 的中点，则 λ = P₁P/PP₂ = −2（已坐标复算验证，见 [[findings/距离质心与定比分割公式组]]）。

内分与外分绝对值相等（λᵢ + λₐ = 0）的特殊情形是 [[concepts/调和分割]]；按几何比例分割线段的另一经典情形是 [[concepts/黄金分割]]。
