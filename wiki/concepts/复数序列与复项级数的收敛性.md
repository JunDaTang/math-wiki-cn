# 复数序列与复项级数的收敛性

复数序列 $z_1, z_2, \dots, z_n, \dots$ 收敛于极限 $z$（记作 $z = \lim_{n\to\infty} z_n$）的定义是：对每个任意给定的正数 $\varepsilon$，存在 $n_0$，使得对每个 $n > n_0$ 成立不等式 $|z - z_n| < \varepsilon$。几何上，即从某个 $n_0$ 开始，诸数 $z_n, z_{n+1}, \dots$ 所表示的点都落在以 $z$ 为圆心、半径为 $\varepsilon$ 的圆内（图 14.39）。这是复项级数理论的起点，与 [[concepts/复函数的极限]]（14.1.1）中的极限概念一脉相承。

## 根式极限

如果表达式 $\{\sqrt[n]{a}\}$ 表示取最小非负辐角的根，那么对任意复数 $a \neq 0$，极限等式 $\lim_{n\to\infty}\{\sqrt[n]{a}\} = 1$ 成立（图 14.39）。（本节原书此处定义句在转写中残缺，见 [[queries/14-3全节系统性转写讹误清单]]。）

## 复项无穷级数

具有复项 $a_i$ 的级数 $a_1 + a_2 + \cdots$ 收敛到和 $s$，指部分和

$$s_n = a_1 + a_2 + \cdots + a_n \quad (n = 1, 2, \dots) \tag{14.44}$$

构成的序列收敛到 $s$。几何上，用折线依次连接相应于诸 $s_n$ 的点，收敛性意味着折线的末端趋近于点 $s$（图 14.40）。

**绝对收敛与条件收敛**：如果绝对值级数 $|a_1| + |a_2| + |a_3| + \cdots$ 也收敛，则称级数绝对收敛；如果级数收敛但不是绝对收敛，则称条件收敛。原书算例：

- 例 A：$\mathrm{i} + \frac{\mathrm{i}^2}{2} + \frac{\mathrm{i}^3}{3} + \frac{\mathrm{i}^4}{4} + \cdots$ 条件收敛（各项模 $1/n$ 成调和发散，而级数本身收敛）；
- 例 B：$\mathrm{i} + \frac{\mathrm{i}^2}{2} + \frac{\mathrm{i}^3}{2^2} + \cdots$ 绝对收敛。

## 函数项级数

如果级数的诸项是函数 $f_i(z)$：

$$f_1(z) + f_2(z) + \cdots + f_n(z) + \cdots \tag{14.45}$$

那么其和是一个函数，它对于使得函数值级数收敛的那些 $z$ 值有定义。这一视角引出 [[concepts/复项幂级数]] 及其 [[concepts/收敛圆与收敛半径]] 结构。
