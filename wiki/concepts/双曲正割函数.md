# 双曲正割函数

**双曲正割函数** sech x 是六个 [[concepts/双曲函数]] 之一，定义为 [[concepts/双曲余弦函数]] 的倒数：

$$
\operatorname{sech} x = \frac {1}{\cosh x} = \frac {2}{\mathrm{e} ^ {x} + \mathrm{e} ^ {- x}}.\tag{2.170}
$$

## 手册中的记载范围

手册 2.9 节对 sech 仅给出定义（式 2.170）及其参与的基本恒等式

$$
\operatorname{sech} ^ {2} x + \tanh ^ {2} x = 1,\tag{2.174}
$$

未像 sinh、cosh、tanh、coth 那样设置图像小节（2.9.2 无 sech/csch 的讨论）。手册称双曲函数曲线「如图 2.48~图 2.52 所示」，其中图 2.48 的内容未说明，可能即 sech/csch 的曲线（见 [[queries/图2-48是否为sech与csch的曲线]]）。

## 由定义可推知的性质（推断，手册未明言）

由 cosh 的性质（偶、cosh x ≥ 1、最小值 1 于 x = 0、x → ±∞ 时 cosh x → +∞）可直接推知：sech 为偶函数，0 < sech x ≤ 1，在 x = 0 取最大值 1，且 x → ±∞ 时趋于 0（水平渐近线 y = 0）。

## 与 [[concepts/正割函数]] 的对照

二者互为名义对应（sec α = 1/cos α 对 sech x = 1/cosh x），但性质不可互换：sec 有竖直渐近线、绝对值 ≥ 1 且无上界；sech 有界（上界 1，推断）。在恒等式中的符号差异：sec²α − tan²α = 1 对 sech²x + tanh²x = 1（减号变加号）。详见 [[comparisons/双曲函数与三角函数比较]]。
