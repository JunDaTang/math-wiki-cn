# 关于角的余弦定律

关于角的余弦定律（角的余弦定律）给出球面三角形一个角的余弦与另两个角及其所夹边的关系：

```
cos α = −cos β cos γ + sin β sin γ cos a    (3.190a)
cos β = −cos γ cos α + sin γ sin α cos b    (3.190b)
cos γ = −cos α cos β + sin α sin β cos c    (3.190c)
```

与 [[concepts/球面边的余弦定律]]（式 3.188）相比，结构上发生「边↔角互换、首项变号」：每一式包含球面三角形的**三个角和一条边**。

## 关键推论：每条边都可以用角来表示

手册强调：借助这个定律，可以很容易地将一个角用它的对边和夹对边的角来表示，或者用角表示边；**因此每条边都可以用角来表示**。相比之下，对于平面三角形来说第三个角是从 180° 内角和计算得出的，且——如手册评注所言——**平面三角形的任何一条边都不可能由角来确定，因为存在着无穷多相似三角形**。

这构成球面与平面三角学的本质差异之一：使平面三角形无法由角定边的「无穷多相似形」障碍在球面上不出现。平面侧证据见 [[findings/平面三角形边不可仅由角得到]]，球面侧证据见 [[findings/球面三角学基本定律组]] 与 [[comparisons/平面与球面三角学公式对应比较]]。
