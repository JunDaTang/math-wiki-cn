# 标量积（点积）

两个 [[concepts/向量]] $\vec a$ 和 $\vec b$ 的**标量积**或**点积**定义为
$$\vec a\cdot\vec b=\vec a\vec b=(\vec a\vec b)=\lvert\vec a\rvert\lvert\vec b\rvert\cos\varphi,\tag{3.248}$$
其中 $\varphi$ 是 $\vec a$ 和 $\vec b$ 具有共同出发点时它们之间的夹角。标量积的值是标量。

## 代数性质

| 性质 | 公式 |
|---|---|
| 交换律 | $\vec a\vec b=\vec b\vec a$（式 3.250） |
| 与标量相乘满足结合律 | $\alpha(\vec a\vec b)=(\alpha\vec a)\vec b$（式 3.252a） |
| 分配律 | $\vec a(\vec b+\vec c)=\vec a\vec b+\vec a\vec c$（式 3.254a） |
| 二重标量积不满足结合律 | $\vec a(\vec b\vec c)\neq(\vec a\vec b)\vec c$（式 3.253a） |
| 自乘 | $\vec a\vec a=\vec a^{2}=a^{2}$（式 3.257） |
| 正交判据 | $\vec a\vec b=0\iff\vec a\perp\vec b$（$\vec a,\vec b\neq\vec 0$，式 3.255） |

## 不变性与坐标公式

标量积是 [[concepts/标量不变量]]（坐标系平移和旋转下不变）。坐标公式随坐标系而异：
- 笛卡儿：$\vec a\vec b=a_xb_x+a_yb_y+a_zb_z$（式 3.264）；
- 仿射（双反变坐标）：$\vec a\vec b=g_{\alpha\beta}a^{\alpha}b^{\beta}$（式 3.273，用 [[concepts/度量系数]]）；
- 仿射（双共变坐标）：$\vec a\vec b=g^{\alpha\beta}a_{\alpha}b_{\beta}$（式 3.282）；
- 混合形式：$a^{\alpha}b_{\alpha}=a_{\alpha}b^{\alpha}$（式 3.284/3.285）。

[[concepts/方向系数]] 是标量积取单位向量为因子的特例；[[concepts/混合积]] 与 [[concepts/拉格朗日恒等式]] 建立在标量积之上。与 [[concepts/向量积]] 的系统对照见 [[comparisons/标量积与向量积性质比较]]；算例（例 A）与验证见 [[findings/向量乘积定义性质与算例]]。
