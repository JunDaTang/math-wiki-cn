# 双列霍纳格式

双列霍纳格式（two-row Horner scheme，19.1.2.1“复数情况”，源文明确指称由 [[entities/科拉茨]] 引进）用于计算**实系数**多项式 $p_n(x)$ 在**复数值** $x_0 = u_0 + \mathrm{i} v_0$ 处的值，全程仅用实数运算。

## 分解与余项

以二次因子 $x^2 - px - q$ 除 $p_n$：

$$p_n(x) = (x^2 - px - q)(a'_{n-2} x^{n-2} + \dots + a'_0) + r_1 x + r_0, \tag{19.18a}$$

其中

$$x^2 - px - q = (x - x_0)(x - \bar{x}_0),\ \text{即}\ p = 2u_0,\ q = -(u_0^2 + v_0^2), \tag{19.18b}$$

于是

$$p_n(x_0) = r_1 x_0 + r_0 = (r_1 u_0 + r_0) + \mathrm{i}\, r_1 v_0. \tag{19.18c}$$

（注：源文 (19.18c) 中 "$r_1 x$" 疑脱下标 0，应为 $r_1 x_0$，见 [[queries/式19-18c之r1x疑为r1x0之辨]]。）

## 格式表 (19.18d)

```text
         a_n      a_{n−1}      a_{n−2}    …    a_3      a_2      a_1      a_0
q  |                   q·a′_{n−2}   …   q·a′_3   q·a′_2   q·a′_1   q·a′_0
p  |        p·a′_{n−2}   p·a′_{n−3}   …            p·a′_2   p·a′_1   p·a′_0
────────────────────────────────────────────────────────────────────
         a′_{n−2}   a′_{n−3}     a′_{n−4}   …   a′_1     a′_0     r_1      r_0
        （其中 a′_{n−2} = a_n）
```

q 行、p 行交替累加（源文标签 "19.18d" 转写讹作 "l9.18d"）。

## 算例（p₄ 在 x₀ = 2 − i）

$p_4(x) = x^4 + 2x^3 - 3x^2 - 7$，$x_0 = 2 - \mathrm{i}$ ⇒ $p = 4$、$q = -5$：

```text
         1     2    −3     0    −7
 −5 |               −5   −30   −80
  4 |           4    24    64
        ————————————————————————
         1     6    16   [34]   −87     ⇒ p₄(x₀) = 34·x₀ − 87 = −19 − 34i
```

本 wiki 两条途径独立验证通过：双列表复算一致；直接复数代入 $p_4(2-\mathrm{i}) = -19 - 34\mathrm{i}$；分解式 $(x^2 - 4x + 5)(x^2 + 6x + 16) + 34x - 87$ 亦成立。见 [[findings/式19-18a至d双列霍纳格式与复数算例复算]]。
