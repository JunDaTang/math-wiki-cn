# 同余法

同余法是一类以线性同余递推生成随机数的方法，《数学手册(原书第10版)》16.3.5.2(2) 称其「应用广泛」：整数序列 z_i（i = 0, 1, 2, …）由递推公式

$$z_{i+1} \equiv c\cdot z_i \pmod{m} \tag{16.169}$$

生成，其中 z₀ 是任意正数（初值），c（原文该符号脱落）表示正整数，必须合理选取。对于 z_{i+1}，可取满足同余式 (16.169) 的最小非负整数；z_i/m 位于 0 与 1 之间（原文「位于 之间」脱 0 与 1），可作为均匀分布随机数。

## 参数选取（16.3.5.2(3)）

- **模数**：选取 m = 2^r，其中 r（原文脱落）是计算机语言中的二进制数（位数），例如 r = 40。
- **乘数**：依 √m 的次序选取数 c——「次序」疑为「数量级」之误，c 与 m 的确切选取规则属开放问题，见 [[queries/依根号m的次序疑为数量级之辨]]。
- **伪随机数**：随机数生成器使用特定算法，可产生所谓伪随机数（源文仅此一句，不单独建页，并入本页与 [[concepts/随机数]]）。
- **计算器以及计算机中的 ran、rand 键用于生成随机数。**
