# 球面角盈

球面角盈（spherical excess）是球面三角形三个内角之和超出 180° 的量，记作 ε：

```
ε = α + β + γ − 180°    (3.184)
```

由于球面三角形的三内角之和介于 180° 与 540° 之间（式 3.183），球面角盈恒为正。它是《数学手册(原书第10版)》3.4.2 公式体系的枢纽量，联结三处内容：

- [[findings/球面三角形一般命题组]] 中的三角之和命题（式 3.183）；
- [[concepts/吉拉尔定理]]：球面三角形面积正比于角盈（式 3.186a–b）；
- [[concepts/吕利耶公式]]：由三条边直接计算角盈（式 3.201）。

与平面情形对照：平面三角形的内角和恒为 180°，即「角盈恒为零」；球面角盈因此是球面几何偏离欧氏几何的直接度量。手册在半边公式中还引入角和之半 σ = (α+β+γ)/2，并证明 90° < σ < 270°、cos σ < 0 恒成立（式 3.196，见 [[concepts/球面半角与半边公式]]）。

## 记号

3.4.2 全节使用 ε；仅在吕利耶等式段落一处出现「角盈 E」，疑为原书符号不一致或转写讹误（见 [[queries/两算例ab指派与角盈符号E是否原书如此]]）。

## 推断性联系（源未明言）

由面积公式 A_T = R²·ε(rad)（式 3.186a）可以读出：角盈的弧度值等于球面三角形在球心所张的立体角（单位球面度），这与 [[concepts/立体角]] 的定义（立体角 = 面积/R²，见 [[findings/立体角定义与球面度]]）相接。此等价性为本 wiki 的推断，本手册该节未明言，立综合页前需另找来源支持。
