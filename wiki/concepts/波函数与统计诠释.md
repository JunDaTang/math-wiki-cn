# 波函数与统计诠释

波函数 ψ(r⃗,t) 是描述量子力学系统状态的复值函数，是薛定谔方程的解；统计诠释（玻恩诠释）将其模平方 |ψ|² 理解为概率密度：粒子位于体积元 dV 中的概率 dω = |ψ|²dV = ψψ*dV（9.112c）。量子力学假设：时刻 t 单粒子系统的完全描述由作为状态函数、薛定谔方程正规化解的复波函数给出，波函数包含由该系统测量所能得到的全部实验信息。

## 波函数的条件（9.2.4.2）

a) ψ 有界且连续；b) 三个一阶偏导连续；c) |ψ|² 可积：

```latex
\iiint_V |\psi(x_1,x_2,x_3,t)|^{2}\,\mathrm{d}V < \infty   % 9.112a
```

归一化条件要求粒子位于所考虑区域中的概率等于 1；9.112a 足以保证此条件，因为用适当常数乘 ψ 可使积分值为 1。

## 概率振幅与本征值测量（9.116–9.119）

- 可观察量 A 的可能测量值限于其算子的诸实本征值 aᵢ；相伴本征函数 φᵢ 形成完备正交系（9.116）。
- 对 N → ∞ 个处于相同态 ψ 的相同系统测量，值 aᵢ 出现的概率 Wᵢ = lim Nᵢ/N（9.117）。
- 将 ψ 按本征函数展开（9.118）：ψ = Σcᵢφᵢ，cᵢ = ∭φᵢ*ψdV；展开系数的绝对值平方给出测量值 aᵢ 的概率：

```latex
W_i = |c_i|^{2},\qquad \sum_i W_i = \iiint_V \psi^{*}\psi\,\mathrm{d}V = 1   % 9.119
```

这一展开正是 [[concepts/按本征函数的傅里叶展开]] 在量子力学中的版本，9.119 的求和恒等式与 [[concepts/帕塞瓦尔方程]] 平行，整体框架与 9.1.3 的 [[concepts/斯图姆-刘维尔问题]]、[[concepts/本征值与本征函数]] 严格平行。

## 定态（平稳态）

能量取固定值 E 时，解具有形式 ψ = Ψe^{−iEt/ℏ}（9.112b，角频率 ω = E/ℏ）；此时粒子位于空间元 dV 中的概率与时间无关，即为粒子的平稳态（stationary state，定态）。

## 隐藏参量断言的限定注记

9.2.4.4 开头断言：量子力学理论「不存在可以消去量子力学的主要统计特性的隐藏子结构和隐藏参量」。这是无保留的强陈述，未区分定域/非定域隐变量理论（编者注：非定域的玻姆力学即为常见反例），宜作限定理解，不宜作为定论照抄。
