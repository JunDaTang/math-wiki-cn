# 特征函数与基本函数

集合 A ⊆ X 的特征函数是取值于 {0,1} 的函数 χ_A：x ∈ A 处取 1，所有别的点取 0 (12.209b)。基本函数（简单函数）是有穷个两两不相交可测集上特征函数的线性组合 f = Σ_{k=1}^n α_k χ_{A_k}；二者构成从可测集到可积函数的构造桥梁。

## 特征函数 (12.209b)

χ_A(x) = 1（x ∈ A）；0（其他）。特征函数把集合运算转化为函数运算，例如 δ_a(A) = χ_A(a)（见 [[concepts/狄拉克测度与狄拉克分布]]）。

## 基本函数

f: X → ℝ 称作基本的或简单的，是指存在有穷个两两不相交的集合 A₁, …, Aₙ ∈ 𝒜 和实数 α₁, …, αₙ 使 f = Σ α_k χ_{A_k}（χ_k 表示 A_k 的特征函数）。由于每个可测集的特征函数都可测（依据 (12.210)，该式分段本身疑误，见 [[queries/式12-210特征函数原像区间疑误]]），每个基本函数都可测。

## 单调逼近定理

手册断言：每个可测函数 f ⩾ 0 可用基本函数任意逼近——存在单调递增的非负基本函数列点点收敛于 f。这是勒贝格积分第一步定义（基本函数积分）得以出发的技术核心，构造流程见 [[methodology/简单函数单调逼近流程]]。

## 在积分构造中的地位

- 第 (1) 步 (12.211)：∫ f dμ = Σ α_k μ(A_k)，直接由测度给出。
- 第 (2) 步 (12.212)：非负函数积分定义为被下方基本函数控制的积分之上确界。
- 第 (5) 步 (12.215)：∫_A f dμ := ∫ f χ_A dμ，特征函数实现「限制在集 A 上」。
