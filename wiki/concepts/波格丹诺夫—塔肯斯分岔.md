# 波格丹诺夫—塔肯斯分岔

**波格丹诺夫—塔肯斯分岔**（Bogdanov-Takens 分岔，冠名者见 [[波格丹诺夫]]、[[塔肯]]）是余维 2 的平衡点分岔，以雅可比矩阵双零特征值 λ₁=λ₂=0（其余双曲）为特征。条件 n≥2、l=2、r≥2；二维约化方程拓扑等价于平面系统（式 17.77）：

```latex
\dot{x} = y, \quad \dot{y} = \alpha_1 + \alpha_2 x + x^{2} - xy
```

## 三条分岔曲线（引 [17.1], [17.17]）

- **S₁ = {(α₁,α₂): α₂²−4α₁=0}**：鞍结点分岔（平衡点方程 α₁+α₂x+x²=0 的判别式条件；复算通过）。
- **S₂ = {(α₁,α₂): α₁=0, α₂<0}**：霍普夫分岔——平衡点 (x*,0) 处迹 = −x*（原点分支上 x*≈−α₁/α₂），从区域 α₁<0 进入 α₁>0 时产生极限环（复算通过；极限环的稳定侧取决于三次项系数，源文未展开）。
- **S₃ = {(α₁,α₂): α₁=−kα₂²+⋯}（常数 k>0）**：分界线环（同宿轨）曲线，环在相邻区域中分岔形成稳定极限环（曲线位置与 k 值未复算）。

## 全局属性

S₃ 上的分岔具有全局属性：由鞍点的同宿轨产生单一周期轨道，或称分界线环消失（见 [[同宿轨与异宿轨]]）。这是该分岔区别于纯局部分岔之处。复算详情见 [[式17-77波格丹诺夫—塔肯斯三曲线复算]]。
