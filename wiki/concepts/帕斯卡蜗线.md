# 帕斯卡蜗线

**帕斯卡蜗线**是一类四阶（四次）平面曲线：在手册 2.12.3 中，它作为一般蚌线三级特化中的一级（作用于圆的蚌线）给出；在 2.13.5 中，它又以 $A = a$ 的外旋轮线身份出现——动圆与定圆半径相等、沿定圆外侧无滑动滚动时，从动圆圆心出发的射线上一点的轨迹。因此蜗线是蚌线族（2.12）与摆线族（2.13）两个体系的公共成员。

蜗线冠名于 Pascal（手册仅作冠名；独立可查的背景：通常指 Étienne Pascal）。手册 2.12.3 以其作为四阶（四次）曲线的第二个命名实例，并注明「也可参见第 136 页 (2.246c)」——该前向引用指向摆线族章节（2.13），见下文「在 2.13.5 中的刻画」。

## 在 2.12.3 中的刻画（圆的蚌线）

蜗线是过极点（原点在圆周上）、直径为 $a$ 的圆的蚌线，即把该圆每点极径延长/缩短定长 $l$ 后所得的曲线；极坐标方程为 $\rho = a\cos\varphi + l$（式 2.235b，$a, l > 0$）。它是 [[一般蚌线]]（式 2.232、2.234；定义句所引编号的争议见 [[帕斯卡蜗线定义引用式2-232还是式2-234]]）的又一特例，其方程、极值点、拐点、二重切线、奇点分类与面积公式由式 2.235 给出。

### 方程

| 形式 | 方程 | 编号 |
|---|---|---|
| 隐式（笛卡儿） | $(x^2+y^2-ax)^2 = l^2(x^2+y^2)$ | (2.235a) |
| 极坐标 | $\rho = a\cos\varphi + l$ | (2.235b) |
| 参数式 | $x = a\cos^2\varphi + l\cos\varphi,\quad y = a\cos\varphi\sin\varphi + l\sin\varphi$，$0 \le \varphi < 2\pi$ | (2.235c) |

其中 $a$ 是圆的直径。顶点 A, B 为 $(a \pm l, 0)$；曲线形状随 $a$ 与 $l$ 之比变化（图 2.63、图 2.64）。

### 几何要素

- **极值点**：$a > l$ 时四个（C, D, E, F）；$a \le l$ 时两个，位于 $\cos\varphi = \frac{-l \pm \sqrt{l^2+8a^2}}{4a}$ 处。
- **拐点**：仅当 $a < l < 2a$，在 $\cos\varphi = -\frac{2a^2+l^2}{3al}$ 处有两点 G, H。
- **二重切线**：$l < 2a$ 时在点 $I, K\left(-\frac{l^2}{4a}, \pm\frac{l\sqrt{4a^2-l^2}}{4a}\right)$ 处（复推确认为竖直线 $x = -l^2/(4a)$）。
- **面积**：$S = \frac{\pi a^2}{2} + \pi l^2$；$a > l$ 时内部环形的面积要计算两次（图 2.63(c)）。

以上要素的复推与验证见 [[帕斯卡蜗线的极值拐点与二重切线]]、[[帕斯卡蜗线的奇点分类与面积公式]]。

### 原点奇点三分律

| 条件 | 原点类型 | 附加特征 |
|---|---|---|
| $a < l$ | 孤立点 | — |
| $a = l$ | 尖点 | 即 [[心脏线]] |
| $a > l$ | 二重点 | $\tan\alpha = \pm\frac{\sqrt{a^2-l^2}}{l}$，$r_0 = \frac{1}{2}\sqrt{a^2-l^2}$ |

与 [[尼科梅德斯蚌线]] 的三分律方向相反，见 [[尼科梅德斯蚌线与帕斯卡蜗线奇点分类比较]]。

## 在 2.13.5 中的刻画（外旋轮线）

$A = a$ 时外旋轮线（式 2.246a）化为帕斯卡蜗线：

$$x = a (2 \cos \varphi - \lambda \cos 2 \varphi), \qquad y = a (2 \sin \varphi - \lambda \sin 2 \varphi),\tag{2.246c}$$

其中 $\lambda a = \overline{CP}$（追踪点到动圆圆心的距离）：$\lambda > 1$ 为长幅、$\lambda < 1$ 为短幅；$\lambda = 1$ 时退化为 [[心脏线]]，与 2.13.3 的 $m = 1$ 外摆线刻画一致。

## 跨章参数换算注（手册原文照录）

> 注：对于 128 页 2.12.3 中的帕斯卡蜗线，用 a 表示的量此处用 $2a\lambda$ 表示，l 是此处的直径 2a。另外坐标系不同。

即（$A = a$ 情形，此处定圆与动圆的直径均为 $2a$）：$a_{2.12.3} \leftrightarrow 2a\lambda$，$l \leftrightarrow 2a$，且两章坐标系不同。这是手册中罕见的跨章显式换算，可作为 [[帕斯卡蜗线定义引用式2-232还是式2-234]] 的旁证：借 2.13 的记号体系（$A$、$a$、$\lambda$）可反推 2.12.3 各参数的几何含义。由该注还可看出 $\lambda = 1$ 时 $a_{2.12.3} = l = 2a$，这与「心脏线为蜗线两参数相等之特例」的经典刻画相容（相容性观察，非手册明文）。
