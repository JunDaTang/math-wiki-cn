# 卡方分布

**卡方分布**（χ² 分布，自由度 n）是 n 个相互独立的标准正态随机变量平方和的分布：设 X₁, X₂, …, Xₙ 为相互独立的标准正态随机变量，则随机变量

```
χ² = X₁² + X₂² + ⋯ + Xₙ²        (16.86)
```

的分布称为自由度 n 的 χ² 分布，分布函数记 F_χ²(x)，密度函数记 f_χ²(t)：

```
f_χ²(t) = { 1/(2^{n/2}·Γ(n/2)) · t^{n/2−1}·e^{−t/2},  t > 0;   0,  t ⩽ 0 }        (16.87a)
F_χ²(x) = P(χ² ⩽ x) = 1/(2^{n/2}·Γ(n/2)) · ∫_{0}^{x} t^{n/2−1}·e^{−t/2} dt   (x > 0)        (16.87b)
```

## 期望和方差

```
E(χ²) = n        (16.88a)
D²(χ²) = 2n        (16.88b)
```

## 可加性（独立 χ² 变量之和）

若 X₁、X₂ 相互独立，分别服从自由度为 n 和 m 的 χ² 分布，则 X = X₁ + X₂ 也服从 χ² 分布，自由度为 n + m。

## 独立正态变量平方和的标度形式

如果 X₁, …, Xₙ 是参数为 (0, σ²) 的独立正态随机变量，则

```
X = Σ_{i=1}^{n} Xᵢ²            有密度函数  f(t) = (1/σ²)·f_χ²(t/σ²)        (16.89)
X = (1/n)·Σ_{i=1}^{n} Xᵢ²      有密度函数  f(t) = (n/σ²)·f_χ²(n·t/σ²)        (16.90)
X = √((1/n)·Σ_{i=1}^{n} Xᵢ²)   有密度函数  f(t) = (2t/σ²)·f_χ²(t²/σ²)        (16.91)
```

（疑点：(16.91) 与其定义不一致，复核推导应得 f(t) = (2nt/σ²)·f_χ²(n·t²/σ²)，疑脱两处因子 n，见 [[式16-91均方根密度疑脱因子n]]。原文小节第 4 条标题作「独立正态随机变量之和」而内容为平方和，属体例问题。）

## 分位数

对自由度为 m 的 χ² 分布（图 16.10），分位数 χ²_{α,m} 满足

```
P(X > χ²_{α,m}) = α        (16.92)
```

其数值可查阅第 1460 页表 21.18（分位数的一般定义见 16.2.2.2 第 3 条，未入库，见 [[16-2-4未入库回指缺口]]）。注意：密度 (16.87) 中自由度记号用 n，分位数 (16.92) 中用 m，原文前后不一。

## 在抽样分布链中的位置

χ² 分布是 16.2.4 节三大抽样分布之根：[[费希尔F分布]] 由两个独立 χ² 变量标准化之比构造（(16.93)），[[学生t分布]] 由标准正态变量与 χ² 变量构造（(16.96)），见 [[卡方F与t分布的构造关系比较]]。
