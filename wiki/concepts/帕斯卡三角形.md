# 帕斯卡三角形

帕斯卡三角形是把 [[concepts/二项式系数]] $\binom{n}{k}$ 按 $n$ 分行排成的数字三角形，用于直观读出 [[concepts/二项式定理]] 展开式的系数。其得名源于 Pascal；本手册仅以其作为名称来源，未涉及人物性内容。

## 构造规则

《数学手册(原书第10版)》1.1.6.4 第 3 点：每行的第一个数和最后一个数等于 1；其余各数是其上一行左、右两数之和。这正是加法公式 (1.39f) $\binom{n+1}{k+1} = \binom{n}{k+1} + \binom{n}{k}$ 的直观形态。

## 标准形态（$n = 0$ 至 $6$，按构造规则补全）

| n | k=0 | k=1 | k=2 | k=3 | k=4 | k=5 | k=6 |
|---|---|---|---|---|---|---|---|
| 0 | 1 | | | | | | |
| 1 | 1 | 1 | | | | | |
| 2 | 1 | 2 | 1 | | | | |
| 3 | 1 | 3 | 3 | 1 | | | |
| 4 | 1 | 4 | 6 | 4 | 1 | | |
| 5 | 1 | 5 | 10 | 10 | 5 | 1 | |
| 6 | 1 | 6 | 15 | 20 | 15 | 6 | 1 |

## 转录问题

手册表 1.2 的转录版本在 $n=5$、$n=6$ 行疑被截断（$n=5$ 行缺末项 1；$n=6$ 行缺 6 与 1），与“每行首末为 1、左右对称”的构造规则自相矛盾，底部标注亦仅索引到 $\binom{6}{4}$。详见 [[queries/手册表1-2帕斯卡三角形是否截断]]；转录原表见 [[sources/10-数学手册原书第10版--8-116-整有理式--zl7wib]]。
