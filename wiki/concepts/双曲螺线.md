# 双曲螺线

双曲螺线是极坐标方程

$$
\rho = \frac {a}{| \varphi |} \quad (a > 0, - \infty < \varphi < 0, 0 < \varphi < \infty)\tag{2.248}
$$

所定义的平面螺线：极径与极角成反比（ρφ = a，形式上类比双曲线的直角坐标方程 xy = a，此为通行解释，非手册原文）。它是手册 2.14.2 节的主题曲线。

## 分支与渐近行为

手册称曲线「在关于 y 轴对称位置有两个分支」，且「直线 y = a 为两个分支的渐近线，原点为渐近点」。

- **渐近线**：正支在 φ→0⁺ 时 x→+∞、y→a，确以 y = a 为渐近线；
- **渐近点**：φ→±∞ 时 ρ→0，曲线绕原点无限缠绕，原点为 [[concepts/渐近点]]；
- **记法矛盾**：在 ρ 恒正的 $|\varphi|$ 记法下，负支在 φ→0⁻ 时趋于 (+∞, −a)，其渐近线应为 y = −a，且分支的对称轴应为 x 轴而非 y 轴——见 [[queries/式2-247与2-248取绝对值与y轴对称渐近线y等于a是否矛盾]]。

## 几何量

- 面积（区域 $P_1OP_2$）：$S = \frac{a^{2}}{2}\left(\frac{1}{\varphi_{1}} - \frac{1}{\varphi_{2}}\right)$，且 $\lim_{\varphi_{2} \to \infty} S = \frac{a^{2}}{2\varphi_{1}}$；
- 曲率半径：$r = \frac{a}{\varphi}\left(\frac{\sqrt{1 + \varphi^{2}}}{\varphi}\right)^{3}$。

手册未给出本曲线的弧长公式。以上各式及正支渐近线的核验见 [[findings/双曲螺线的方程渐近线与几何量]]。
