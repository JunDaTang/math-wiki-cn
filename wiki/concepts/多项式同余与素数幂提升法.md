# 多项式同余与素数幂提升法

多项式同余式 f(x) ≡ 0 (mod m)（f(x) = a_n xⁿ + ⋯ + a₀）的求解理论由两级归约组成：先把模 m 分解为互素模（[[concepts/中国剩余定理|中国剩余定理]] 归约），再把素数幂模归结为素数模并逐级提升。第二级即通称的 Hensel 提升——源文未命名该算法，仅给操作步骤。

## 第一级：互素模分解（式 5.259）

若 m₁, …, m_t 两两互素，则

$$f(x) \equiv 0 \pmod{m_1 m_2 \cdots m_t} \Leftrightarrow f(x) \equiv 0\ (m_j),\ j = 1, \dots, t, \tag{5.259}$$

且若 f(x) ≡ 0 (m_j) 各有 k_j 个解，则 f(x) ≡ 0 (m₁⋯m_t) 有 k₁k₂⋯k_t 个解。于是 f(x) ≡ 0 (p₁^{α₁}⋯p_t^{α_t}) 的求解归结为各 f(x) ≡ 0 (p^α)。

## 第二级：素数幂提升（式 5.260）

- a) f(x) ≡ 0 (p^α) 的解也是 f(x) ≡ 0 (p) 的解。
- b) 当且仅当 p 不整除 f′(x₁) 时，f(x) ≡ 0 (p) 的解 x ≡ x₁ (p) 由模 p^α 的解唯一确定。

提升步骤：设 f(x₁) ≡ 0 (p)。令 x = x₁ + p t₁，解线性同余式

$$\frac{f(x_1)}{p} + f'(x_1)\, t_1 \equiv 0 \pmod p \tag{5.260a}$$

得唯一解 t₁′；代回 t₁ = t₁′ + p t₂ 得 x = x₂ + p² t₂，再解

$$\frac{f(x_2)}{p^2} + f'(x_2)\, t_2 \equiv 0 \pmod p \tag{5.260b}$$

得 t₂′，继续迭代即得 f(x) ≡ 0 (p^α) 的解。源文 (5.260b) 段称「模 p² 解 t₂′」，疑应为「模 p 解」，见 [[queries/式5-260b模p2解应为模p解吗]]。

每一级求解的都是模 p 的[[concepts/线性同余式|线性同余式]]；完整流程见 [[methodology/素数幂逐级提升流程]]。

## 算例（已复算）

解 x⁴ + 7x + 4 ≡ 0 (mod 27)：模 3 得唯一解 x ≡ 1 (3)；f′(x) = 4x³ + 7，f′(1) = 11，3 ∤ 11；解 f(1)/3 + f′(1)t₁ ≡ 4 + 11t₁ ≡ 0 (3) 得 t₁ ≡ 1 (3)，x = 4 + 9t₂；解 f(4)/9 + f′(4)t₂ ≡ 0 (3)（f(4) = 288、f′(4) = 263）得 t₂ ≡ 2 (3)，x = 22 + 27t₃。故 x = 22 是解且模 27 唯一；验证 f(22) = 234414 = 27·8682。✓ 详见 [[findings/多项式同余分解与提升法算例]]。
