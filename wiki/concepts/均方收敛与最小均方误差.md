# 均方收敛与最小均方误差

**最小均方误差性质**：在所有形如式 7.105a 的 n 阶三角和

$$s_n(x)=\frac{a_0}{2}+\sum_{k=1}^{n}a_k\cos k\omega x+\sum_{k=1}^{n}b_k\sin k\omega x$$

之中，当且仅当系数取 f 的 [[concepts/傅里叶系数]] 时，均方误差

$$F=\frac{1}{T}\int_0^T[f(x)-s_n(x)]^2\,\mathrm{d}x$$

最小（式 7.105a/b；这样的三角和称为**傅里叶和**）。**均方收敛**：若 f 有界且在 0 < x < T 上分段连续，则 n → ∞ 时

$$\int_0^T[f(x)-s_n(x)]^2\,\mathrm{d}x\to 0$$

（式 7.106a），并由此导出 [[concepts/帕塞瓦尔方程]]。

## 机理（为什么）

三角函数系 {1, cos ωx, sin ωx, …, cos nωx, sin nωx} 在 [0, T] 上正交。因此傅里叶和是 f 到该 2n+1 维子空间的**正交投影**，而投影使距离（均方误差）最小。对 F 关于每个系数求偏导并置零，所得方程恰为欧拉公式（式 7.102）——「使均方误差最小的系数」与「傅里叶系数」是同一回事。最小值为 F_min = (1/T)∫f² − a_0²/4 − ½Σ_{k=1}^n(a_k² + b_k²) ≥ 0（本 wiki 复算所得，兼得 Bessel 型不等式）。见 [[findings/最小均方误差与帕塞瓦尔方程-式7-105至7-106]]。

## 意义与关联

- 「最佳近似」是均方意义下的刻画性性质，不依赖逐点收敛。
- 均方收敛 + 正交性 ⟹ 帕塞瓦尔方程（式 7.106b）。
- 手册在 7.4.1.1 即前向引用该性质说明 s_n(x) 是 f(x) 的最佳近似；转写回指「635 7.4.2.1」疑应为 7.4.1.2.1，见 [[queries/7-4全节系统性转写讹误清单]]。
- 均方误差的进一步展开在手册 19.6.2.1（第 1278 页）与 19.6.4（第 1288 页），未入库。
