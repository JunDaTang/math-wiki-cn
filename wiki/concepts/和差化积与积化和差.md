# 和差化积与积化和差

和差化积与积化和差是[[concepts/三角函数]]的和差与乘积之间互相转化的两组恒等式（式 2.115–2.129）：前者把同名函数的和差化为乘积，后者把乘积化为和差（含三变量积的四个公式）。

## 和差化积（式 2.115–2.122）

$$\sin\alpha + \sin\beta = 2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2},\qquad \sin\alpha - \sin\beta = 2\cos\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$$
$$\cos\alpha + \cos\beta = 2\cos\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2},\qquad \cos\alpha - \cos\beta = -2\sin\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$$
$$\tan\alpha \pm \tan\beta = \frac{\sin(\alpha\pm\beta)}{\cos\alpha\cos\beta},\qquad \cot\alpha \pm \cot\beta = \pm\frac{\sin(\alpha\pm\beta)}{\sin\alpha\sin\beta}$$
$$\tan\alpha + \cot\beta = \frac{\cos(\alpha-\beta)}{\cos\alpha\sin\beta},\qquad \cot\alpha - \tan\beta = \frac{\cos(\alpha+\beta)}{\sin\alpha\cos\beta}$$

## 积化和差（式 2.123–2.129）

$$\sin\alpha\sin\beta = \frac{1}{2}[\cos(\alpha-\beta) - \cos(\alpha+\beta)],\qquad \cos\alpha\cos\beta = \frac{1}{2}[\cos(\alpha-\beta) + \cos(\alpha+\beta)]$$
$$\sin\alpha\cos\beta = \frac{1}{2}[\sin(\alpha-\beta) + \sin(\alpha+\beta)]$$

三变量积（式 2.126–2.129）把 $\sin\alpha\sin\beta\sin\gamma$、$\sin\alpha\cos\beta\cos\gamma$、$\sin\alpha\sin\beta\cos\gamma$、$\cos\alpha\cos\beta\cos\gamma$ 各表示为四个单角三角函数的 $\frac{1}{4}$ 倍线性组合，完整公式见 [[findings/和差化积与积化和差公式组]]。

- 转写疑点：cos α − cos β 一式在源文中缺编号（按序应为 2.118），见 [[queries/式2-118缺编号是否为转写遗漏]]。
