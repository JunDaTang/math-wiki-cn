# 线性算子

设 $V,W$ 是两个实线性空间。从 $V$ 到 $W$ 的映射 $f:V\to W$ 称为**线性映射**、**线性变换**或**线性算子**（原书另见 12.1.5.2，第 861 页），如果

```latex
f(u+v) = f(u)+f(v)   对所有 u,v ∈ V      % 式 5.191
f(λu)  = λf(u)       对所有实数 λ        % 式 5.192
```

在特殊情形 $W=\mathbb{R}^1$，线性变换称为**线性泛函**。

## 三个例子（5.3.8.3）

- **例 A**：$fu := \int_\alpha^\beta u(t)\,dt$，将连续实函数空间 $C[\alpha,\beta]$ 变换到实数空间，是线性的（线性泛函）。
- **例 B**：$V=\mathbb{R}^n$，$W$ 为次数至多为 $n-1$ 的实多项式空间；映射 $f(a_0,a_1,\dots,a_{n-1}) := a_0 + a_1x + \dots + a_{n-1}x^{n-1}$ 是线性的，每个 n 元素向量对应一个次数 $\le n-1$ 的多项式。
- **例 C**：$V=\mathbb{R}^n$、$W=\mathbb{R}^m$ 时，所有从 $\mathbb{R}^n$ 到 $\mathbb{R}^m$ 的线性算子可用 (m,n) 型实矩阵 $A=(a_{ik})$ 刻画；关系式 $A\underline{x}=\underline{y}$ 对应线性方程组 (4.174a)。矩阵末项 $a_{mm}$ 与 (m,n) 型声明不符，疑应为 $a_{mn}$（[[queries/例c矩阵末项a-mm应为a-mn]]）。

## 和与积（算子代数）

设 $f:V\to W$、$g:V\to W$、$h:W\to U$ 是线性算子。和 $f+g:V\to W$ 定义为 $(f+g)u = fu+gu$（式 5.193）；积 $hf:V\to U$ 定义为 $(hf)u = h(fu)$（式 5.194），表示相继应用这些算子。

- 若 $f,g$ 线性，则 $f+g$ 与 $hf$ 也线性（原文作「$f\,h$」，疑为「$h\,f$」之讹，见 [[queries/正文fh应为hf之讹]]）。
- 两个线性算子之积通常**非交换**，即使两个积都有定义也有 $hf\neq fh$（式 5.195a）；当 $hf-fh=0$（式 5.195b）时称可换。在量子力学中，$hf-fh$ 称作**交换子**（呼应 [[concepts/量子力学中的对称群]]）。
- 对应实矩阵的和与积是算子和、积的例子。

## 术语注记

本手册称线性单射为「正则的」（见 [[concepts/核与象]]），这是本手册的特殊术语，与外部资料中「正则」的其他用法可能不同。
