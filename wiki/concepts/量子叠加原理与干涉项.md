# 量子叠加原理与干涉项

量子叠加原理指：由薛定谔方程的线性性，若已知一个物理系统的两个状态 ψ₁、ψ₂，则叠加 ψ = ψ₁ + ψ₂（9.120）也表示一个可能的物理态。这是量子力学的基本原理，其可观察的推论是概率密度中出现带符号的干涉项：

```latex
|\psi|^{2} = |\psi_1+\psi_2|^{2} = |\psi_1|^{2}+|\psi_2|^{2}+2\,\mathrm{Re}(\psi_1\psi_2^{*})   % 9.121
```

## 论述要点

- 除两个单个概率 |ψ₁|²、|ψ₂|² 外，还出现了附加项 2Re(ψ₁ψ₂*)——它解释了量子力学惊人的干涉效应，例如波粒二象性。
- 干涉项的存在说明：量子概率不是经典概率的简单相加，因为概率幅（而非概率本身）做线性叠加。
- 与常微分方程语境的 [[concepts/叠加原理与分解定理]]（线性方程解的叠加与分解）数学上同源，但物理内涵不同：此处强调态的叠加与概率幅干涉，是量子力学区别于经典物理的标志。

复算核对：9.121 为 |ψ₁+ψ₂|² 的直接代数展开（✓）。
