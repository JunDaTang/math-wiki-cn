# 复数

复数是形如 z = a + ib（式 1.131a）的数，其中 a、b 取遍所有实数值，i 为[[concepts/虚数单位]]（i² = −1）。a 称为 z 的实部，b 称为虚部（式 1.131b）：

a = Re(z)，b = Im(z)

复数集用 ℂ 表示。实数是复数的子集：b = 0 时 z = a 即为实数；a = 0 时 z = ib 称为"纯虚数"。因此在[[comparisons/数系分类层级]]中，ℂ 是位于 ℝ 之上的最顶层。

## 相等与无序性

两个复数相等当且仅当实部与虚部对应相等；几何上即对应的位置向量相等，反之则不相等。对复数而言，"大于"和"小于"的概念是无意义——复数之间只能判定相等与否，不存在大小序，因而[[concepts/数区间]]这类依赖顺序的概念不适用于 ℂ。

## 三种表示形式

手册给出互相等价、可互换的三种形式（详见 [[comparisons/复数三种表示形式比较]]）：

1. 代数形式：z = a + ib；
2. 三角形式：z = ρ(cos φ + i sin φ)，其中 ρ、φ 为[[concepts/复数的模与辐角]]；
3. 指数形式：z = ρ e^{iφ}，由[[concepts/欧拉公式]]（欧拉关系式）与三角形式沟通。

## 几何表示

复数可表示为[[concepts/高斯平面]]上的点（横坐标 a、纵坐标 b），也可表示为起点在原点、指向该点的位置向量。

## 运算概要

- 加减法：按二项式逐项合并实部与虚部（式 1.136）。
- 乘除法：代数形式下按二项式法则展开并计入 i² = −1，除法借助[[concepts/共轭复数]]将分母实数化（式 1.137–1.139）；三角/指数形式下模相乘除、辐角相加减。
- 幂：实用算法为[[concepts/棣莫弗公式]]（式 1.140a）。
- n 次根：ⁿ√z 有 n 个不同值，几何上为正 n 边形顶点（见 [[concepts/复数的n次根]]）。

手册强调：加、减、乘、除和整数次幂都有唯一结果，而 n 次方根有 n 个不同的解。
