# 位势方程（泊松微分方程）

位势方程（potential equation）或泊松微分方程（Poisson differential equation，式 9.110a）是确定由标量点函数 ρ(x) 决定的标量场位势 u(x) 的二阶线性偏微分方程：Δu = −4πρ，其中 x 有坐标 x₁, x₂, x₃，Δ 为 [[拉普拉斯算子]]。−4πρ 的系数归一化与位势论中的标准泊松方程一致（独立可验证背景）。源还提到“在点〔M〕处的位势 u_M(x₁, x₂, x₃)”（M 在转写中丢失）；(9.110a) 的解在原书第 951 页 13.5.2 讨论（未入库，见开放缺口）。

## 与方程类型的匹配

按 9.2.3.1 的原则，椭圆型微分方程（出现在连续介质中定态问题和平衡问题的研究中）的正确问题形式是[[边值问题]]；若所考虑区域无界，未知函数在自变量无限增长时必须满足某些给定性质。源 9.2.3.4 未明示位势方程属椭圆型，椭圆归类为标准分类（独立可验证背景），见 [[二阶偏微分方程的类型]]。

## 齐次情形

当 ρ ≡ 0 时得到齐次微分方程——[[拉普拉斯微分方程]]（式 9.110b）：Δu = 0。

## 消歧

“泊松微分方程”与本库实体页 [[泊松公式]]（波方程 n = 2 柯西问题解公式，式 9.106b）同名异指，两者在本源中同时出现，须按上下文区分。

## 转写疑点

源文“它确定了有一个可能的标量点函数 ρ(x) 决定的标量场的位势 u(x)”语义不通，疑为“由一个给定的标量点函数 ρ(x) 决定的”之译文讹误；“这里〔x〕有坐标”中符号 x 被丢（见 [[9-2-3全节系统性转写讹误清单]]）。
