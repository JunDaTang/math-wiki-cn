# 数学归纳法

数学归纳法（手册亦称数学或算术归纳法）是证明**依赖于自然数 $n$ 的定理**的标准方法。其原理为：若命题对自然数 $n_0$ 成立，并且若命题对某个自然数 $n \geqslant n_0$ 成立可推出其对 $n + 1$ 也成立，那么命题对任意自然数 $n \geqslant n_0$ 均成立。

## 证明步骤

据《数学手册(原书第10版)》1.1.2.3，数学归纳法证明按以下四步进行：

1. **归纳的基础**：证明命题对 $n = n_0$ 成立，在多数情况下可以选取 $n_0 = 1$。
2. **归纳假设**：设命题对某个整数 $n$ 成立（前提 $p$）。
3. **归纳结论**：形成对 $n + 1$ 的命题（结论 $q$）。
4. **蕴涵证明**：证明 $p \Rightarrow q$。

步骤 (3) 和 (4) 一起称为**归纳步骤**，或从 $n$ 到 $n + 1$ 的逻辑演绎。

## 例：裂项求和公式

（手册 1.1.2.3 例题，推导原文保留）证明

$$s_n = \frac{1}{1 \cdot 2} + \frac{1}{2 \cdot 3} + \frac{1}{3 \cdot 4} + \cdots + \frac{1}{n(n+1)} = \frac{n}{n+1}.$$

1. $n = 1$：$s_1 = \frac{1}{1 \cdot 2} = \frac{1}{1 + 1}$，公式显然成立。
2. 假设 $s_n = \frac{1}{1 \cdot 2} + \frac{1}{2 \cdot 3} + \frac{1}{3 \cdot 4} + \cdots + \frac{1}{n(n+1)} = \frac{n}{n+1}$ 对某个 $n \geqslant 1$ 成立。
3. 假设 (2) 成立，要证明 $s_{n+1} = \frac{n + 1}{n + 2}$。
4. 证明：

```
s_{n+1} = 1/(1·2) + 1/(2·3) + 1/(3·4) + … + 1/(n(n+1)) + 1/((n+1)(n+2))
        = s_n + 1/((n+1)(n+2))
        = n/(n+1) + 1/((n+1)(n+2))
        = (n² + 2n + 1)/((n+1)(n+2))
        = (n+1)²/((n+1)(n+2))
        = (n+1)/(n+2)
```

## 与其他证明方法的关系

数学归纳法与 [[concepts/直接证明法]]、[[concepts/反证法]] 并列为手册列举的三种标准证明方法。其归纳步骤本质上是 [[concepts/直接证明法]] 中蕴涵式证明 $p \Rightarrow q$ 的一个特例：归纳基础提供为真的前提，归纳步骤完成从 $n$ 到 $n+1$ 的蕴涵。横向比较见 [[comparisons/证明方法比较]]。
