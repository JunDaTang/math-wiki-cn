# 指数分布

**指数分布**（参数 λ > 0）是定义在 [0, ∞) 上、密度按指数衰减的连续分布：称连续随机变量服从参数为 λ（λ > 0）的指数分布，如果其密度函数是（图 16.7）

```
f(t) = { 0,  t < 0;   λ·e^{−λt},  t ⩾ 0 }        (16.80a)
```

其分布函数为

```
F(x) = ∫_{−∞}^{x} f(t) dt = { 0,  x < 0;   1 − e^{−λx},  x ⩾ 0 }        (16.80b)
```

## 期望和方差

```
μ = 1/λ,   σ² = 1/λ²        (16.81)
```

## 应用

下述问题常用指数分布描述：电话的通话时间，放射性粒子的寿命，某些过程中机器在两次故障之间的工作时间，灯泡或某建筑构件的寿命等。

## 在分布谱系中的位置

- 指数分布是 [[韦布尔分布]] 在形状参数 α=1、λ=1/β 时的特例（见 [[指数分布与韦布尔分布比较]]）；
- 自由度为 2 的 [[卡方分布]] 密度 (16.87a) 在 n=2 时为 (1/2)e^{−t/2}，即 λ=1/2 的指数分布（此为复核时的对照观察，非原文陈述）。
