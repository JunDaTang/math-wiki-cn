# 复数的 n 次根

求复数的 n 次方根是幂的逆运算。对于 z = ρ(cos φ + i sin φ) ≠ 0，记号（式 1.141a）

z^{1/n} = ⁿ√z　（n > 0，n 是整数）

是 **n 个不同值**的简单记法（式 1.141b）：

ω_k = ⁿ√ρ [cos((φ + 2kπ)/n) + i sin((φ + 2kπ)/n)]，k = 0, 1, 2, …, n−1

## 多值性：唯一的例外

手册强调：复数的加、减、乘、除和整数次幂都有唯一结果，而 n 次方根有 n 个不同的解 ω_k。这是 1.5 节中唯一的多值运算，与四则运算及整数幂的唯一性形成对比。

## 几何解释

点 ω_k 是中心在原点的正 n 边形的顶点：n 个根均匀分布在半径 ⁿ√ρ 的圆上（[[concepts/高斯平面]]）。手册图 1.11 给出了 ⁿ√z 的 6 个值（正六边形顶点）。

## 与棣莫弗公式的关系

[[concepts/棣莫弗公式]]（模取 n 次幂、辐角乘 n）的逆问题：模取 n 次根、辐角除以 n；辐角的周期性（相差 2kπ）产生 n 个分支，即得上式。
