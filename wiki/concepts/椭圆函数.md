# 椭圆函数

椭圆函数是双周期的复变函数，其奇点都是极点，即具有两个独立周期的 [[concepts/亚纯函数|亚纯函数]]。如果两个周期 $\omega_1$、$\omega_2$ 不是实相关的，则

$$f(z + m\omega_1 + n\omega_2) = f(z) \quad \left(m, n = 0, \pm 1, \pm 2, \dots;\ \operatorname{Im}\left(\frac{\omega_1}{\omega_2}\right) \neq 0\right). \tag{14.53}$$

## 基本周期平行四边形

在顶点为 $0, \omega_1, \omega_1 + \omega_2, \omega_2$ 的原始（基本）周期平行四边形中，$f(z)$ 已遍及其值域——由双周期性，函数在全平面的行为由该平行四边形完全决定。
