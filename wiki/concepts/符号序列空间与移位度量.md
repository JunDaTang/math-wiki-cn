# 符号序列空间与移位度量

《数学手册(原书第10版)》17.2.5 第 3 部分为表述伯努利转移而引入的符号动力学框架。原文「考虑 (0, 1) 序列空间」指取值于 $\{0,1\}$ 的序列空间（非开区间）：

```latex
\Sigma = \{ s = s_0 s_1 s_2 \dots,\ s_i \in \{0, 1\}\ (i = 0, 1, \dots) \}
```

对 $s = s_0 s_1 s_2 \dots$ 及 $s' = s'_0 s'_1 s'_2 \dots$，定义二者距离为

```latex
\rho(s, s') = \begin{cases} 0, & s = s', \\ 2^{-j}, & s \neq s', \end{cases}
```

其中 $j$ 为满足 $s_j \neq s_{j'}$ 的最小指标——下标疑为 $s'_j$ 之讹（见 [[queries/Σ距离最小指标下标撇误之辨]]）；在此修读下，$j$ 即两序列的**首个不同位**，距离随分歧位后移而指数式减小。

原文断言：**则 $(\sigma, \rho)$（疑为 $(\Sigma, \rho)$，见 [[queries/完备度量空间σρ疑为Σρ之辨]]）是一个完备度量空间，且是紧的**。复算：完备性与紧性均成立（$\rho$ 为超度量；完全有界 + 完备 ⟹ 紧），见 [[findings/式17-59与Σ空间伯努利转移德瓦尼混沌复算]]。

据可独立核验的公开背景（非本源内容）：此即符号动力学的标准 $2^{-j}$ 型度量；$(\Sigma, \rho)$ 同胚于经典康托尔集，是紧、全不连通、无孤立点的完备度量空间。

## 移位映射（伯努利转移）

删去首符号的映射 $s = s_0 s_1 s_2 \dots \mapsto \sigma(s) = s' = s_1 s_2 s_3 \dots$ 称为**伯努利转移**（原文定义行首字母误作 ρ 且脱箭头，见 [[queries/伯努利转移定义行ρ疑为σ并脱箭头之辨]]）。

- 与 17.2.2 已入库的 [[concepts/伯努利转移映射]]（方体分割、测度熵视角）互补：本节补充了其定义域 $\Sigma$ 与度量的完整表述，两页应互加回指。
- 原文断言：**伯努利转移在德瓦尼意义下是混沌的**，见 [[concepts/德瓦尼混沌]] 与 [[findings/式17-59与Σ空间伯努利转移德瓦尼混沌复算]]。
