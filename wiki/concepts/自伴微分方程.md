# 自伴微分方程

**自伴微分方程**（self-adjoint differential equation）是形如

$$[p\,y']' - q\,y + \lambda\,\varrho\,y = f \tag{9.67a}$$

的重要的特殊二阶微分方程，其中 λ 为常数参数。它是《数学手册》9.1.3 线性边值问题理论的标准载体：斯图姆–刘维尔本征值理论（见 [[concepts/斯图姆-刘维尔问题]]）的全部定理都在这一形式上陈述。

## 正则性假设

手册假设 p(x)、p′(x)、q(x)、ϱ(x) 与 f(x) 在**有限区间** a ≤ x ≤ b 上连续，且

$$p(x) > p_0 > 0, \qquad \varrho(x) > \varrho_0 > 0$$

（p 与 ϱ 一致为正）。在无穷区间的情形，「结果有很大差异」（原书将此情形指引至文献 [9.5]）——这是后续所有本征值性质的适用边界。

## 与一般二阶方程的关系

任何形如 (9.67c) A y″ + B y′ + C y + λR y = F（A ≠ 0 于 [a,b]）的二阶方程，乘以 p/A 并施行代换 (9.67d) 后都可化为自伴形式，见 [[methodology/二阶线性方程自伴化代换流程]]。注意：转写文本中 (9.67d) 的指数 R/A 与 (9.67c) 的系数结构存在内部矛盾（标准推导要求 B/A），见 [[queries/式9-67d指数是R-A还是B-A]]。

## 相关概念

- 齐次与非齐次：当 f = 0 时，(9.67a) 称为与非齐次边值问题（inhomogeneous boundary value problem）相伴的齐次边值问题（homogeneous boundary value problem），见 [[concepts/边值问题]]。
- 权函数 ϱ(x) 的结构性作用见 [[concepts/权函数]]。
