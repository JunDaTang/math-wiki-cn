# 介值定理

介值定理断言连续函数取尽中间值：若函数 $f(x)$ 在区间 $[a,b]$ 上连续，且

```
f(a) = A,  f(b) = B,  A ≠ B,                      (2.33a)
```

则对于任意介于 $A$、$B$ 之间的数 $C$，存在 $c\in(a,b)$ 使得

```
f(c) = C   (a < c < b,  A < C < B 或 B < C < A).   (2.33b)
```

## 等价表述

对于介于 $A$、$B$ 的每个值，函数 $f(x)$ 在 $(a,b)$ 内至少能取得该值一次；或者说，**一个区间的连续像仍为一个区间**。

## 与相关定理的关系

- 取 $C=0$（对 $g(x)=f(x)-C$ 用 [[concepts/波尔查诺定理]]）即见两定理的派生关系（标准推导，非本节原文）。
- 定理要求闭区间上连续；闭区间连续函数定理族的对照见 [[comparisons/闭区间上连续函数定理比较]]。
