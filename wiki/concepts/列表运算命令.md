# 列表运算命令

列表运算命令是 Mathematica 提供的对 [[列表（Mathematica）]] 进行检验、扩展或缩短的命令族，即《数学手册(原书第10版)》表 20.4 所列的 Position、MemberQ、Select、Cases、FreeQ、Prepend、Append、Insert、Delete、ReplacePart 十个命令；「检验、扩展或缩短」的三分法为源文自身的表述。

## 表 20.4 列表的运算（逐字转录）

| 命令 | 说明 |
|---|---|
| Position[l, a] | 给出 a 在该列表中出现的位置的一个列表 |
| MemberQ[l, a] | 检验 a 是否是该列表的一个元素 |
| Select[l, crit] | 挑出该列表中满足特定条件的所有元素 |
| Cases[l, pattern] | 给出匹配该模式的元素的一个列表 |
| FreeQ[l, a] | 检验 a 是否不出现在该列表中 |
| Prepend[l, a] | 将 a 添加到前面改变该列表 |
| Append[l, a] | 将 a 添加到末尾改变该列表 |
| Insert[l, a, i] | 在该列表的第 i 个位置插入 a |
| Delete[l, {i, j,···}] | 从该列表删除位置 i, j, ··· 处的元素 |
| ReplacePart[l, a, i] | 将位置 i 处的元素替换为 a |

## 三类操作

- 检验：Position、MemberQ、Select、Cases、FreeQ；
- 扩展：Prepend、Append、Insert；
- 缩短与替换：Delete、ReplacePart。

## 算例

应用 Delete 可以删除 a6 而将原来的列表 l1 (20.10) 缩短：

```text
In[1] := l2 = Delete[l1, 6]  →  Out[1] = {a1, a2, a3, a4, a5}
```

复算见 [[嵌套列表Part与Delete算例复算]]。此输出以符号 a1–a5 显示，与源文紧随其后的「在输出中 ai 显示为它们的值，它们本身是列表」之说相矛盾，见 [[Out1符号显示与ai显示为值之说矛盾之辨]]。

## 释义疑点（与 Mathematica 实际语义疑似冲突，待实测）

1. `Delete[l, {i, j,···}]` 释为删除多个位置——实际 `Delete[expr, {i, j}]` 删除嵌套位置 {i, j} 处的单一部件，删多个独立位置须 `Delete[l, {{i}, {j}, ...}]`。见 [[Delete多重位置括号语义之辨]]。
2. Prepend/Append「改变该列表」——实际二者返回新列表、不修改 l，就地修改须 PrependTo/AppendTo。见 [[Prepend与Append改变该列表之辨]]。
