# 二阶线性偏微分方程

**二阶线性偏微分方程**是未知函数 u 的最高阶偏导数为二阶、且方程对 u 及其各阶偏导数均为一次（线性）的偏微分方程。两个自变量 x, y 情形的一般形式为（手册式 9.82a）：

$$A \frac{\partial^{2} u}{\partial x^{2}} + 2B \frac{\partial^{2} u}{\partial x \partial y} + C \frac{\partial^{2} u}{\partial y^{2}} + a \frac{\partial u}{\partial x} + b \frac{\partial u}{\partial y} + cu = f$$

其中系数 A, B, C, a, b, c 与右端 f 是 x, y 的已知函数。n 个自变量情形的一般形式为（式 9.86）Σ_{i,k} a_{ik} ∂²u/∂x_i∂x_k + … = 0，省略号代表不含二阶导数的项。

## 关键性质

- 方程的性态由二阶主部系数决定：两个自变量时按判别式 δ = AC − B² 的符号分为双曲型、抛物型、椭圆型（及混合型），见 [[二阶偏微分方程的分类]]。
- 类型在自变量的（非退化）变换下不变，因而可通过变量变换约化为[[典范形式]]。
- 若主部与低阶项系数全为常数，可经线性齐次变换与消一阶导代换 (9.88) 化为 Δv + kv = g（椭圆）或 v_tt − Δv + kv = g（双曲）的简单形式。

## 典型方程

三类代表方程构成本节五个分离变量算例的主体：[[弦振动方程]]（双曲）、[[热传导方程]]（抛物）、[[拉普拉斯方程与拉普拉斯算子]]（椭圆）；[[电报方程]]是弦振动方程带阻尼与恢复项的推广。若把二阶主部保持线性而允许低阶项 F 对 u 及一阶导数非线性，得一般化形式 (9.85)，分类与约化陈述仍然成立。
