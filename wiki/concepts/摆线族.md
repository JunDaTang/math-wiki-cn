# 摆线族

**摆线族**是以「无滑动滚动生成」为统一定义机制的一族平面曲线：当一个圆（或固定在从圆心出发的射线上的定点）沿滚动基——一条直线、另一个圆的外侧或内侧——做无滑动滚动时，追踪点描绘的轨迹统称摆线族曲线。手册 2.13 节按**滚动基**与**追踪点位置**两轴把全族组织为五小节，完整对应表见 [[comparisons/摆线族两轴分类比较]]。

## 两轴分类

**第一轴：滚动基**

- 直线（2.13.1、2.13.2）；
- 定圆外侧（2.13.3 外摆线；2.13.5 外旋轮线）；
- 定圆内侧（2.13.4 内摆线；2.13.5 内旋轮线）。

**第二轴：追踪点位置**，以 $\lambda$（追踪点到动圆圆心的距离与动圆半径之比，$\lambda a = \overline{CP}$）度量：

- $\lambda = 1$：点在圆周上 → 标准 [[concepts/摆线]]、[[concepts/外摆线]]、[[concepts/内摆线]]；
- $\lambda > 1$：点在圆外（长幅）→ 长摆线、长短幅外/内摆线；
- $\lambda < 1$：点在圆内（短幅）→ 短摆线、长短幅外/内摆线。

对圆滚动基还有**第三根形态轴**：商 $m = A/a$（定圆与动圆半径之比）的算术性质（整数 / 非整有理数 / 无理数）决定分支数与闭合性（见 [[concepts/外摆线]]、[[concepts/内摆线]]）。

## 族内特化关系

- $m = 1$ 的外摆线 = [[concepts/心脏线]]（2.13.3）；
- $A = a$ 的外旋轮线 = [[concepts/帕斯卡蜗线]]（式 2.246c）；
- $A = 2a$、$\lambda \neq 1$ 的内旋轮线 = 椭圆（式 2.246b）；
- $m = 2$ 的内摆线 = 定圆的直径（退化）；
- $m = 4$ 的内摆线 = [[concepts/星形线]]。

## 与代数曲线体系的关系

摆线族曲线多为超越曲线，但与 2.11–2.12 的 [[concepts/代数曲线]] 体系有三个（外加椭圆共四个）代数交点：[[concepts/星形线]] 为六次代数曲线，[[concepts/心脏线]] 与 [[concepts/帕斯卡蜗线]] 为四次代数曲线（蚌线族成员），椭圆为二次。它们是两族曲线的公共成员，构成 2.11–2.12 与 2.13 两部分叙事的交汇。
