# 谓词

谓词是定义在个体区域（或全域）X 上的真值指派：X 上的 n 位谓词是一个映射 P: Xⁿ → {F,T}，它对每个 n 元个体组派定一个真值。个体的性质（如「n 是素数」）对应一位（一元）谓词；个体间的关系（如「m 小于 n」、ℕ 上的 ≤ 关系）对应二位（二元）谓词。

原书算例取个体区域为自然数集 ℕ：设 P 表示一元谓词「n 是素数」，则 ∀nP(n) 是假语句，而 ∃nP(n) 是真语句——量词作用于谓词即得到语句（见 [[concepts/量词]]）。

谓词符号本身没有固定语义，须经 [[concepts/解释]] 中的指派才获得具体谓词；其语法地位由式 (5.21) 的基本公式条款确立（[[findings/谓词与量词的语法定义与命题演算嵌入]]）。
