# 等比级数

等比级数是其项构成等比数列的有限级数，即相邻两项比值恒定的求和结果。《数学手册(原书第10版)》1.2.3（式 1.54）：相邻两项的比值为常数

$$\frac{a_{i+1}}{a_i} = q = \text{常数}, \quad \text{故} \quad a_i = a_0 q^i \tag{1.54a}$$

## 有限和（式 1.54b–c）

$$s_n = a_0 + a_0 q + a_0 q^2 + \dots + a_0 q^n = a_0\,\frac{q^{n+1} - 1}{q - 1} \quad (q \neq 1) \tag{1.54b}$$

$$s_n = (n+1)\,a_0 \quad (q = 1) \tag{1.54c}$$

## 无穷极限（式 1.54d）

当 $n \to \infty$ 时上式成为无穷等比级数；若 $|q| < 1$，级数有极限，极限值称为和 $s$：

$$s = \frac{a_0}{1 - q} \tag{1.54d}$$

手册注明无穷情形参见其 7.2.1.1, 2.（未入库）。这一极限是从 [[concepts/有限级数]] 通向无穷级数的桥接点。

## 与均值的联系

两正数的几何平均 $x_G = \sqrt{ab}$ 使三数 $a, x_G, b$ 构成等比数列，见 [[concepts/均值]]。

## 补充注记（可独立验证的背景，非手册原文）

式 1.64（$1 + 2x + 3x^2 + \dots + nx^{n-1} = \frac{1-(n+1)x^n + nx^{n+1}}{(1-x)^2}$，$x \neq 1$，见 [[concepts/幂和公式]]）可由等比级数求和公式逐项求导得到；手册未指出这一联系。
