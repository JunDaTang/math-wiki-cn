# 因式分解

因式分解（多项式的因式分解）是把一个多项式恒等地改写为若干单项式与多项式乘积的 [[concepts/恒等变换]]。它与“把 [[concepts/整有理式]] 展开为多项式形式”互为逆过程：前者由和化为积，后者由积化为和。

## 定义与途径

《数学手册(原书第10版)》1.1.6.2 指出：多项式通常可分解成单项式和多项式的乘积，可通过**提取公因式**、**分组**、**利用方程的特殊公式和特殊性质**完成分解。其中“特殊公式”对应同节 1.1.6.3 的乘法公式 (1.28)–(1.35)（见 [[concepts/乘法公式]]），“特殊性质”对应方程根的性质（方法 C）。

## 方法 A：提取公因式

$$
8ax^{2}y - 6bx^{3}y^{2} + 4cx^{5} = 2x^{2}(4ay - 3bxy^{2} + 2cx^{3}).
$$

## 方法 B：分组解法

$$
6x^{2} + xy - y^{2} - 10xz - 5yz = 6x^{2} + 3xy - 2xy - y^{2} - 10xz - 5yz = 3x(2x + y) - y(2x + y) - 5z(2x + y) = (2x + y)(3x - y - 5z).
$$

关键步骤是拆项（$xy = 3xy - 2xy$）后分组，使各组出现同一个公因式 $(2x+y)$。

## 方法 C：利用方程根的性质

若 $\alpha$ 是方程 $P(x) = 0$ 的根，则 $(x - \alpha)$ 是 $P(x)$ 的因子（手册前向引用第 56 页 1.6.3.1）。手册例题：对 $P(x) = x^{6} - 2x^{5} + 4x^{4} + 2x^{3} - 5x^{2}$，先提取公因子 $x^{2}$；由 $\alpha_{1} = 1$、$\alpha_{2} = -1$ 是根，除以 $x^{2}(x-1)(x+1) = x^{4} - x^{2}$ 得商 $x^{2} - 2x + 5$；因 $p = -2,\ q = 5,\ \frac{p^{2}}{4} - q < 0$，商不能再分解为实因子（见 [[findings/手册以p方除4减q小于零判定二次因式无实分解]]），故

$$
x ^ {6} - 2 x ^ {5} + 4 x ^ {4} + 2 x ^ {3} - 5 x ^ {2} = x ^ {2} (x - 1) (x + 1) (x ^ {2} - 2 x + 5).
$$

## 与其他概念的关系

- 三种方法的对照分析见 [[comparisons/因式分解方法比较]]。
- [[concepts/乘法公式]] (1.28)–(1.35) 既可用于展开，也可逆向用于分解（如平方差公式 (1.32) 的逆向使用）。
- 手册 1.1.6.5 指出，两个多项式的 [[concepts/最大公因式]] 可由 [[concepts/辗转相除法]] 求出，原书接语为“需把它们分解成因式”。
- 因式分解的结果不唯一到什么程度取决于系数域：方法 C 的例题中，$x^{2} - 2x + 5$ 在实数范围内不可再分解，但在复数范围内可分解为共轭线性因子。
