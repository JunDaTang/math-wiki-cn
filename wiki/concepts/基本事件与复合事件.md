# 基本事件与复合事件

**基本事件**（简单事件）是试验中两两互斥的所有可能结果。按表 16.2(6) 的形式定义：若 $E = A + B$ 可推出 $E = A$ 或 $E = B$，即 $E$ 不能分解为两个不同事件之和，则 $E$ 为基本事件。**复合事件**是非基本事件（表 16.2(7)）。

## 例 A（硬币；枚数在转写中脱落，疑为两枚）

以 $A_{ij}$ 记第 $i$ 枚硬币第 $j$ 种结果（1=正面，2=反面）：

- 基本事件（第 1 枚正面、第 2 枚反面）：$A_{11}A_{22}$；
- 复合事件（第 1 枚正面）：$A_{11}A_{21} + A_{11}A_{22}$；
- 同一试验中 $A_{11}+A_{12} = I$，且 $A_{11}A_{12} = O$（互斥）。

## 例 B（灯泡寿命）

基本事件 $A_n$：寿命 $t$ 满足 $(n-1)\Delta t < t \leqslant n\Delta t$（$n = 1, 2, \dots$，$\Delta t > 0$ 为任意时间单位）；复合事件「寿命不超过 $n\Delta t$」即 $A = \sum_{\nu=1}^{n} A_\nu$。

## 与等可能事件的联系

[[concepts/等可能事件]]（古典概率，式 16.37–16.38）建立在「有限完备事件组中每个基本事件等可能」之上；基本事件的不可分解性正是古典计数 $m/n$ 的计数对象。
