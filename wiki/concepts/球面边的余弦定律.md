# 球面边的余弦定律

关于边的余弦定律给出球面三角形一条边的余弦与另两条边及其夹角的关系：

```
cos a = cos b cos c + sin b sin c cos α    (3.188a)
cos b = cos c cos a + sin c sin a cos β    (3.188b)
cos c = cos a cos b + sin a sin b cos γ    (3.188c)
```

手册指出：从记号可以看出该定律的每一式包含球面三角形的**三条边**（及一条边所对的角），因此是解球面三角形的基本工具。本节两个导航算例均用式 3.188c 从两点的经纬度求大圆距离（式 3.197，见 [[findings/大圆航程与航向角算例]]、[[methodology/大圆航程与航向角计算流程]]）。

本定律对应平面三角学的余弦定律 [[concepts/余弦定律]]。

与之对照的还有 [[concepts/关于角的余弦定律]]（式 3.190），其结构为三条边↔三个角互换、首项变号，使每条边都能由角表出——这是平面三角形不具备的能力。
