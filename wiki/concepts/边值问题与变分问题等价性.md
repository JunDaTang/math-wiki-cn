# 边值问题与变分问题等价性

源文断言：在关于函数 p, q, f, y 的一定条件下，自伴边值问题

```latex
(19.129)  -[p(x)y'(x)]' + q(x)y(x) = f(x),   y(\alpha)=\alpha,\ y(\beta)=\beta
(19.130)  I[y] = \int_a^b [p(x)y'^2(x) + q(x)y^2(x) - 2f(x)y(x)]\, dx = \min   （边界条件同上）
```

与其变分问题等价；对于边值问题 (19.129)，由 (19.130) 立即得到 H(x, y, y′)（即 [[concepts/里茨法]] 所需的被积函数）。边界条件记号疑为 y(a)=α、y(b)=β，见 [[queries/边界条件yα等于α之α疑为a之辨]]。

**基函数构造**：代替逼近 (19.121)，常考虑

```latex
(19.131)  g(x) = g_0(x) + \sum_{i=1}^{n} a_i g_i(x)
(19.132)  g_i(a) = g_i(b) = 0   (i = 1,\dots,n)
(19.133)  g_0(x) = \alpha + \frac{\beta-\alpha}{b-a}(x-a)
```

其中 g₀ 满足边值，g_i 满足齐次边界条件；对问题 (19.118) 适当的选择是线性函数 (19.133)。该等价性是 [[concepts/里茨法]] 的理论基础；与 [[concepts/伽辽金法]] 的关系见 [[comparisons/逼近系数确定四原则比较]]。
