# 反双曲函数与对数双形式

**反双曲函数与对数双形式**是 [[数学手册(原书第10版)]] 21.7.2 全节系统采用的记法体系：凡积分结果中出现 $\operatorname{Arsinh}$、$\operatorname{Arcosh}$、$\operatorname{Artanh}$、$\operatorname{Arcoth}$ 之处，手册通常并排给出等价的对数表达式，并以 $+C$ 与 $+C_1$ 区分两形式的积分常数（如式 185、192、213、220，及分段条目 127、146）。

## 基本恒等式

$$\operatorname{Arsinh} t = \ln\left(t+\sqrt{t^2+1}\right),\quad \operatorname{Arcosh} t = \ln\left(t+\sqrt{t^2-1}\right)\ (t\ge 1),$$
$$\operatorname{Artanh} t = \frac12\ln\frac{1+t}{1-t},\quad \operatorname{Arcoth} t = \frac12\ln\frac{t+1}{t-1}.$$

## 在 21.7.2 中的对应

- $\operatorname{Arsinh}\frac xa + C = \ln(x+\sqrt X) + C_1$（$X = x^2+a^2$）：见 185、187、190、192、194、199、201、204、208【重构】。
- $\operatorname{Arcosh}\frac xa + C = \ln(x+\sqrt X) + C_1$（$X = x^2-a^2$）：见 213、215、218、220、222、227、229、232、236【重构】。
- $\operatorname{Artanh}\sqrt{\frac{fX}{aY}}$ 与 $\ln(\sqrt{aY}+\sqrt{fX})$（146 的 $af>0$ 两案例，等价冗余）。
- $\operatorname{Arcoth}\sqrt{\frac Xb} = \frac12\ln\frac{\sqrt X-\sqrt b}{\sqrt X+\sqrt b}$（127，$b>0$）。
- $\operatorname{Arsinh}\frac{2ax+b}{\sqrt\Delta}$ 与 $\ln(2\sqrt{aX}+2ax+b)$（241 案例 1↔2；258 同构）。

## 常数约定

两形式相差仅依赖参数的常数，如 $\operatorname{Arsinh}\frac xa = \ln(x+\sqrt X) - \ln a$，故 $C_1 = C - \ln a$。手册以不同下标提醒此点；校勘时两形式须**分别**求导验证，且不可混同 $C$、$C_1$。

## 结构意义

反双曲形式与族 5 的 $\arcsin$ 严格平行（见 [[二次根式三族平行结构]]），使三族公式外观一致；对数形式则不引入特殊函数记号、便于直接查用。两套形式的取舍与易误读点分析见 [[对数形式与反双曲函数形式比较]]；转录与复算记录见 [[10-数学手册原书第10版--11-2172-无理函数积分--1swy6lt]]。
