# 凸锥

凸锥是实向量空间中同时满足凸性、正齐次性和尖性三个条件的非空子集；它在《数学手册(原书第10版)》12.1.4.2 引入，是 12.1.7 中整个序结构理论（[[concepts/有序向量空间与锥诱导偏序]]）的生成器。

## 定义（三条件）

（实）向量空间 V 的非空子集 K 称作凸锥，是指：

1. K 是凸集；
2. x ∈ K 且 λ ≥ 0 蕴涵 λx ∈ K（正齐次性）；
3. x ∈ K 且 −x ∈ K 蕴涵 x = 0（尖性）。

## 等价刻画

一个锥也可用条件 (3) 再加上如下性质刻画：

$$x, y \in K \;\text{和}\; \lambda, \mu \geq 0 \;\text{推出}\; \lambda x + \mu y \in K. \tag{12.17}$$

即「尖性 + 对非负系数加法封闭」等价于「凸 + 正齐次 + 尖」。

## 译者注约定（比较时须注明）

译者注明确：本章中作者并未区分锥和凸锥，**下面所谓的锥都是指凸锥**。与其他文献区分「锥/凸锥」的惯例不同，跨来源比较时须注明此约定。

## 例证

- **例 A**：所有具有非负分量的向量 x = (ξ₁, …, ξₙ) 的集合 ℝ₊ⁿ 是 ℝⁿ 中的一个锥（转写「配｝是民中的一个锥」即此处乱码）。
- **例 B**：[a,b] 上非负值连续函数的集合 C₊ 是 [[entities/连续函数空间]] 中的一个锥。
- **例 C**：所有具非负分量（ξₙ ≥ 0 ∀n）的实数列组成序列空间中的锥（该例所属空间名在转写中缺录，见 [[queries/12-1全节系统性转写讹误清单]]）。
- **例 D（反例）**：给定 a > 0，满足 Σ|ξₙ|^p ≤ a（12.18）的序列组成的集合 C ⊂ ℓ^p（1 ≤ p < ∞）是**凸集但显然不是锥**——该断言仅关于此球集，不可外推至 ℓ^p 空间本身（见 [[entities/lp空间]]）。
