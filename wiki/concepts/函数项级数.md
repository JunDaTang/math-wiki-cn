# 函数项级数

函数项级数是各项均为同一自变量 x 的函数的无穷级数，形如 Σ_{n=1}^∞ f_n(x)（式 7.74）。它在每一点 x = a 处退化为一个数项级数 Σ f_n(a)，因此其收敛性逐点定义：使该数项级数收敛的点全体构成收敛域，逐点极限 S(x) 称为和函数。

## 基本要素（式 7.74–7.78）

```latex
\sum_{n=1}^{\infty} f_n(x)                                   % 级数 (7.74)
S_n(x) = \sum_{k=1}^{n} f_k(x)                               % 部分和 (7.75)
\lim_{n\to\infty} S_n(a) = S(a)                              % 收敛点 (7.76–7.77)
R_n(x) = S(x) - S_n(x) = \sum_{k=n+1}^{\infty} f_k(x)        % 余项 (7.78)
```

- **收敛域**：所有使 Σ f_n(a) 收敛的点 x = a 构成的集合（式 7.76–7.77）。
- **和函数**：收敛域上 S(x) = lim S_n(x)，也称级数收敛于函数 S(x)。
- **余项**：R_n(x) = S(x) − S_n(x)，度量部分和逼近和的程度。

逐字转录见 [[式7-74-7-78函数项级数定义组逐字转录]]。

## 核心问题

逐点收敛不足以继承各项的解析性质（连续性、可积性、可微性），由此引出 [[一致收敛]] 的概念——这也是本节（7.3.2）的中心区分。典型反例见 [[式7-80非一致收敛算例与和函数不连续]]：级数 x + x(1−x) + x(1−x)² + ⋯ 在 [0,1] 上逐点收敛，但其和在 x = 0 不连续。

## 重要特例

- [[幂级数]]（式 7.83a–b）：系数与中心为常数的级数，手册称为「最重要的函数项级数」。
- [[泰勒级数]] / [[麦克劳林级数]]（式 7.95–7.97）：由函数各阶导数生成的幂级数。
- [[渐近幂级数]]（式 7.99）：按 1/x 展开且不要求收敛的级数。
