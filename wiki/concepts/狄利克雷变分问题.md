# 狄利克雷变分问题

**狄利克雷变分问题**（Dirichlet variational problem，10.4.1）：确定函数 u = u(x, y)，使泛函

$$I[u] = \iint_G (u_x^2 + u_y^2)\,\mathrm{d}x\,\mathrm{d}y \quad (10.49e)$$

有极值，并且 u 在平面区域 G 的边界 Γ 上为零（正文 Γ 两处讹作「I'」）。

## 物理来源：膜形变算例（10.49a–f）

考虑固定在 x,y 平面中一区域 G 边界 Γ 上的自由膜，其面积为

$$I_1 = \iint_G \mathrm{d}x\,\mathrm{d}y \quad (10.49a)$$

若膜因负载而形变，以致在每个点处产生一伸长 u = u(x,y)（正文「在 方向」处脱一方向符号），面积按

$$I_2 = \iint_G \sqrt{1 + u_x^2 + u_y^2}\,\mathrm{d}x\,\mathrm{d}y \quad (10.49b)$$

计算。把 (10.49b) 中的被积函数线性化并利用泰勒公式（参见 6.2.2.3，第6章）得

$$I_2 \approx I_1 + \frac{1}{2}\iint_G (u_x^2 + u_y^2)\,\mathrm{d}x\,\mathrm{d}y \quad (10.49c)$$

形变膜的势能为

$$U = \sigma(I_2 - I_1) = \frac{\sigma}{2}\iint_G (u_x^2 + u_y^2)\,\mathrm{d}x\,\mathrm{d}y \quad (10.49d)$$

其中常数 σ 表示膜的张力。用这种方式产生了狄利克雷变分问题。

## 欧拉微分方程

对 F = u_x² + u_y² 用多自变量欧拉微分方程（10.48）：F_u = 0、F_{u_x} = 2u_x、F_{u_y} = 2u_y，得

$$\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0 \quad (10.49f)$$

即两个变量的**拉普拉斯微分方程**（参见 13.5.1，第13章未入库）。复算通过，见 [[findings/第10章诸算例闭式复算通过清单]]。
