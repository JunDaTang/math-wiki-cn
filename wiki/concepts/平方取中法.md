# 平方取中法

平方取中法是 [[entities/冯·诺伊曼]] 提出的一种产生随机数的简便方法（《数学手册(原书第10版)》16.3.5.2(1)）。它从一个 2n 位小数 z∈(0,1) 开始：首先构造 z²，得到一个 4n 位小数；去掉其前 n 位数字和后 n 位数字（原文「去掉其前 位数字」脱 n，按对称性应为前 n 位），再次得到一个 2n 位数；重复上述程序产生新数。通过这种方式产生了 [0,1] 区间上的 2n 位小数，可视为服从均匀分布的随机数。

2n 的值根据计算机可表示的最大数选取，比如 2n = 10。

## 算例（2n=4）

```
z = z₀ = 0.1234,   z₀² = 0.01[5227]56
z = z₁ = 0.5227,   z₁² = 0.27[3215]29（原文误标 z₀²）
z = z₂ = 0.3215 等
```

复算：0.1234² = 0.01522756（中段四位 5227）、0.5227² = 0.27321529（中段四位 3215），数值全部吻合；仅第二行平方记号 z₀² 疑为 z₁²，见 [[queries/平方取中法算例z0平方疑为z1平方]] 与 [[findings/平方取中法算例复算]]。

## 源文评价

「由千（由于）该程序产生了比它更小的数字，故很少使用，目前已发展了其他一些不同的方法」——弃用理由的原文表述语句不通，存疑待查（记于 [[queries/16-3-5全节系统性转写讹误清单]]）。现行主流方法是 [[concepts/同余法]]，两者比较见 [[comparisons/平方取中法与同余法比较]]；产物即 [[concepts/均匀分布随机数]]。
