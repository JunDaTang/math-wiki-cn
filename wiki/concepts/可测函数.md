# 可测函数

设 𝒜 是集合 X 的子集的 σ-代数。函数 f: X → ℝ̄ 称作（𝒜-）可测的，是指对任意 α ∈ ℝ，集合 f⁻¹((α, +∞]) = {x ∈ X : f(x) > α} 属于 𝒜。可测性是勒贝格积分的前提；它只依赖 σ-代数而不依赖测度。

## 复值情形

复值函数 g + ih 称作可测的，是指 g 与 h 都可测。（转录本此处漏「和 h」二字，见 [[queries/12-9全节系统性转写讹误清单]]。）

## 特征函数与连续函数的可测性

- 每个 A ∈ 𝒜 的特征函数 χ_A 可测，依据 (12.210)——但该式分段疑有数学性讹误（α < 0 时原像应为 X 而非 A），见 [[queries/式12-210特征函数原像区间疑误]] 与 [[concepts/特征函数与基本函数]]。
- 若 𝒜 是 ℝⁿ 中勒贝格可测集的 σ-代数且 f: ℝⁿ → ℝ 连续，则由第 874 页 12.2.3（连接 [[concepts/开集与闭集]]），f⁻¹((α, +∞]) = f⁻¹((α, +∞)) 是开集，从而 f 可测。

## 可测函数类的闭包性质（12.9.2.2）

设 f, g, fₙ: X → ℝ̄ 可测，则下列函数也可测（回指第 863 页 12.1.7.4，即 [[concepts/向量格与K空间]] 的运算）：

- a) αf (α ∈ ℝ)、fg
- b) f₊、f₋、|f|、f ∨ g、f ∧ g
- c) f + g（当其在 X 中各点处的值不出现 (±∞) + (∓∞)）
- d) supₙ fₙ、infₙ fₙ、limsupₙ fₙ、liminfₙ fₙ
- e) 点点极限 lim fₙ（当它存在时）
- f) f ⩾ 0 且 p ∈ ℝ, p > 0 时，fᵖ 可测

这一闭包性质是 [[concepts/勒贝格积分]] 中 |f|ᵖ 可测性（12.9.4 依据）与收敛定理的代数基础。
