# 认知系统

**认知系统**是数学手册 5.9.6.3 对一条模糊建模路线的命名：不写被控对象的数学模型，而是把系统建立在人类「控制专家」的能动性之上（**认知问题**）——专家用**语言法则**表述知识，每条法则由前提（对测量值的说明）与结论（给出适当的控制值）组成，即以 [[法则基础]] 与 [[语言变量]] 为载体的知识库。

## 方法论要点

- 对每个被测量值的集合 $X_1,\dots,X_n$ 与控制量 $Y$ 定义适当语言项（「几乎为零」「小的正数」等）；同一语言项对不同测量（如 $\xi_1$ 与 $\xi_2$）可以有不同的意义。
- 为每个语言项设定一个模糊集（源文回指「如同我们对模糊推理所指出的（参见 5.9.4）」；该节未入库，见 [[5-9-4及5-9-5未入库缺口]]，图 5.77 亦在彼处）。
- 控制按 [[mamdani方法]] 的四步迭代执行。

## 示范算例

5.9.6.3 以 [[逆摆]]（活动底座上的摆的校准）演示该路线：分区 → 19 法则表 → 模糊化 → α-切割 → 聚合 → 逆模糊化，得控制量 $F=3.95$（重心法）或 $F=5.0$（极大值准则法）。详见 [[逆摆mamdani算例-式5-392-395]] 与 [[mamdani模糊控制计算流程]]。

与之并列的另一条路线是 [[基于知识的插值系统]]（5.9.6.4）：不强调「专家知识」，而强调模糊系统作为插值器的数学性质。源文注记：基于知识的路线以法则偏差最小为中心。
