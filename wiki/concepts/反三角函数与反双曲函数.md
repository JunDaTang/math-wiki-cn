# 反三角函数与反双曲函数

复**反三角函数**与**反双曲函数**都是多值函数，《数学手册(原书第10版)》14.5.2 第 5 条借助对数函数表示它们。八个多值函数（大写首字母，用 $Ln$）：

$$Arcsin\,z = -\mathrm{i}\,Ln(\mathrm{i}z + \sqrt{1-z^2}), \quad Arsinh\,z = Ln(z + \sqrt{z^2+1}) \tag{14.83a/b}$$

$$Arccos\,z = -\mathrm{i}\,Ln(z + \sqrt{z^2-1}), \quad Arcosh\,z = Ln(z + \sqrt{z^2-1}) \tag{14.84a/b}$$

$$Arctan\,z = \frac{1}{2\mathrm{i}}Ln\frac{1+\mathrm{i}z}{1-\mathrm{i}z}, \quad Artanh\,z = \frac{1}{2}Ln\frac{1+z}{1-z} \tag{14.85a/b}$$

$$Arccot\,z = -\frac{1}{2\mathrm{i}}Ln\frac{\mathrm{i}z+1}{\mathrm{i}z-1}, \quad Arcoth\,z = \frac{1}{2}Ln\frac{z+1}{z-1} \tag{14.86a/b}$$

⚠ 转写文本中 (14.83a)、(14.84a) 记作小写 $ln$，与多值语境不符，疑应为 $Ln$（见 [[queries/式14-83a与14-84a多值式ln疑为Ln]]）。

八个**主值**（小写首字母，用 $\ln$，式 14.87a–14.90b）与上组形式完全相同，仅把 $Ln$ 换为 $\ln$：

$$\arcsin z = -\mathrm{i}\ln(\mathrm{i}z + \sqrt{1-z^2}), \quad \operatorname{arsinh} z = \ln(z + \sqrt{z^2+1}) \tag{14.87a/b}$$

$$\arccos z = -\mathrm{i}\ln(z + \sqrt{z^2-1}), \quad \operatorname{arcosh} z = \ln(z + \sqrt{z^2-1}) \tag{14.88a/b}$$

$$\arctan z = \frac{1}{2\mathrm{i}}\ln\frac{1+\mathrm{i}z}{1-\mathrm{i}z}, \quad \operatorname{artanh} z = \frac{1}{2}\ln\frac{1+z}{1-z} \tag{14.89a/b}$$

$$\operatorname{arccot} z = -\frac{1}{2\mathrm{i}}\ln\frac{\mathrm{i}z+1}{\mathrm{i}z-1}, \quad \operatorname{arcoth} z = \frac{1}{2}\ln\frac{z+1}{z-1} \tag{14.90a/b}$$

## 复算结论

十六个公式全部通过复算（代入 $z = 0$、$z = 1$ 等特值验证），包括 Arccot 的等价变形：由 $\frac{\mathrm{i}z+1}{\mathrm{i}z-1} = \frac{z-\mathrm{i}}{z+\mathrm{i}} = \left(\frac{z+\mathrm{i}}{z-\mathrm{i}}\right)^{-1}$ 得 $-\frac{1}{2\mathrm{i}}Ln\frac{\mathrm{i}z+1}{\mathrm{i}z-1} = \frac{1}{2\mathrm{i}}Ln\frac{z+\mathrm{i}}{z-\mathrm{i}}$。见 [[findings/式14-83a至14-90b反三角反双曲函数对数表示转录复算]]。

## 结构

- 每个多值函数与其主值公式形式完全相同，仅 $Ln \to \ln$——这是 [[concepts/多值函数与主值]] 记法约定的系统应用（见 [[comparisons/多值函数与其主值表示比较]]、[[methodology/多值函数主值化流程]]）。
- 多值性的根源在于 $Ln$ 自身的无穷多值性与平方根的双值性（此为标准理论解释，源文未展开）；三角/双曲函数的周期性使反函数的多值结构进一步叠加。
