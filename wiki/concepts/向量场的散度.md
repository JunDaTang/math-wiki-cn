# 向量场的散度

向量场的散度（divergence，记作 $\operatorname{div}\vec{V}$ 或 $\nabla\cdot\vec{V}$）是作用于向量场 $\vec{V}(\vec{r})$ 而得到的一个标量场：它定义为向量场在点 $\vec{r}$ 处的**空间导数（[[concepts/体积导数]]）**，即穿过包围该点、体积趋于零的闭曲面 $\Sigma$ 的通量与体积之比的极限。在流场中，散度度量单位体积、单位时间内的净流出量：为正处称**源**，为负处称**汇**。散度与梯度（13.2.2）、旋度（13.2.3）并列为手册 13.2“空间的微分算子”中的基本算子；本页全部定义与公式来自《数学手册》(原书第10版) 13.2.4。

## 定义（式 13.48）

$$\operatorname{div}\vec{V} = \lim_{V \to 0} \frac{\iint_{\Sigma} \vec{V} \cdot \mathrm{d}\vec{S}}{V}$$

记号说明：

- 式中的 $V$ **同时**表示向量场 $\vec{V}$ 本身与极限中收缩到零的体积 $V$，属原书记号复用（与 13.2.1 体积导数定义一致），非转写错误。
- 被积式 $\vec{V}\cdot\mathrm{d}\vec{S}$ 使用 [[concepts/向量曲面元]]；该极限即 [[concepts/体积导数]] 中曲面积分型（第二类）极限的具体化——散度就是给这一极限命名的结果。

## 物理意义：流场、源与汇

若 $\vec{V}$ 是流场（stream field），则 $\operatorname{div}\vec{V}$ 给出在单位体积、单位时间内流经所考虑点处的流体的量：

- $\operatorname{div}\vec{V} > 0$：该点称为**源**（source）；
- $\operatorname{div}\vec{V} < 0$：该点称为**汇**（sink）。

## 坐标表示（式 13.49–13.52）

### 笛卡儿坐标系（式 13.49）

$$\operatorname{div}\vec{V} = \frac{\partial V_x}{\partial x} + \frac{\partial V_y}{\partial y} + \frac{\partial V_z}{\partial z}$$

其中 $\vec{V}(x,y,z) = V_x\vec{i} + V_y\vec{j} + V_z\vec{k}$。散度可表示为梯度算子 $\nabla$（nabla）与向量 $\vec{V}$ 的点积：

$$\operatorname{div}\vec{V} = \nabla \cdot \vec{V}$$

（$\nabla$ 的正式定义见手册 13.2.2，尚未入库。）

### 柱面坐标系（式 13.50）

$$\operatorname{div}\vec{V} = \frac{1}{\rho}\frac{\partial(\rho V_\rho)}{\partial \rho} + \frac{1}{\rho}\frac{\partial V_\varphi}{\partial \varphi} + \frac{\partial V_z}{\partial z}$$

其中 $\vec{V}(\rho,\varphi,z) = V_\rho\vec{e}_\rho + V_\varphi\vec{e}_\varphi + V_z\vec{e}_z$。

### 球面坐标系（式 13.51）

$$\operatorname{div}\vec{V} = \frac{1}{r^2}\frac{\partial(r^2 V_r)}{\partial r} + \frac{1}{r\sin\vartheta}\frac{\partial(\sin\vartheta\, V_\vartheta)}{\partial \vartheta} + \frac{1}{r\sin\vartheta}\frac{\partial V_\varphi}{\partial \varphi}$$

其中 $\vec{V}(r,\vartheta,\varphi) = V_r\vec{e}_r + V_\vartheta\vec{e}_\vartheta + V_\varphi\vec{e}_\varphi$。

### 一般坐标系（式 13.52）

$$\operatorname{div}\vec{V} = \frac{1}{D}\left\{ \frac{\partial}{\partial\xi}\!\left(\left|\frac{\partial\vec{r}}{\partial\eta}\right|\left|\frac{\partial\vec{r}}{\partial\zeta}\right| V_\xi\right) + \frac{\partial}{\partial\eta}\!\left(\left|\frac{\partial\vec{r}}{\partial\zeta}\right|\left|\frac{\partial\vec{r}}{\partial\xi}\right| V_\eta\right) + \frac{\partial}{\partial\zeta}\!\left(\left|\frac{\partial\vec{r}}{\partial\xi}\right|\left|\frac{\partial\vec{r}}{\partial\eta}\right| V_\zeta\right) \right\}$$

其中 $\vec{r}(\xi,\eta,\zeta) = x(\xi,\eta,\zeta)\vec{i} + y(\xi,\eta,\zeta)\vec{j} + z(\xi,\eta,\zeta)\vec{k}$，$\vec{V}(\xi,\eta,\zeta) = V_\xi\vec{e}_\xi + V_\eta\vec{e}_\eta + V_\zeta\vec{e}_\zeta$，且

$$D = \left|\left(\frac{\partial\vec{r}}{\partial\xi}\ \frac{\partial\vec{r}}{\partial\eta}\ \frac{\partial\vec{r}}{\partial\zeta}\right)\right| = \left|\frac{\partial\vec{r}}{\partial\xi}\right| \cdot \left|\frac{\partial\vec{r}}{\partial\eta}\right| \cdot \left|\frac{\partial\vec{r}}{\partial\zeta}\right|$$

两点注意：

- 来源小节标题为“一般直角坐标系”，但 $D$ 的第二个等号（混合积之模等于模长之积）仅对相互正交的基向量成立，公式实为**一般正交（曲线）坐标系**的散度通式，见 [[queries/一般直角坐标系疑为一般正交坐标系]]。
- 混合积记号 $(\vec{a}\ \vec{b}\ \vec{c})$ 属早期向量代数章节回指，未入库，见 [[queries/13-2-4未入库回指缺口]]。

## 不变性

标量场 $\operatorname{div}\vec{V}$ 是**平移和旋转不变的**，即标量不变量（原书回指第 379 页 4.3.3.2；该回指内容未入库）。

## 运算法则（式 13.53–13.55）

常向量场的散度为零，散度算子具有线性性：

$$\operatorname{div}\vec{c} = 0,\qquad \operatorname{div}(\vec{V}_1 + \vec{V}_2) = \operatorname{div}\vec{V}_1 + \operatorname{div}\vec{V}_2,\qquad \operatorname{div}(c\vec{V}) = c\,\operatorname{div}\vec{V}$$

标量函数与向量场乘积的散度满足乘积法则（$\operatorname{grad}$ 的定义见 13.2.2，未入库）：

$$\operatorname{div}(U\vec{V}) = U\operatorname{div}\vec{V} + \vec{V}\cdot\operatorname{grad}U$$

特别地 $\operatorname{div}(\vec{r}\,\vec{c}) = \dfrac{\vec{r}\cdot\vec{c}}{r}$（来源排印为 $\operatorname{div}(r\vec{c})$，$r$ 疑漏向量箭头；复算支持 $\vec{r}$ 的读法，见 [[queries/13-2-4全节系统性转写讹误清单]]）。

两向量场叉积的散度通过旋度（$\operatorname{rot}$，定义见 13.2.3，未入库）表示：

$$\operatorname{div}(\vec{V}_1 \times \vec{V}_2) = \vec{V}_2\cdot\operatorname{rot}\vec{V}_1 - \vec{V}_1\cdot\operatorname{rot}\vec{V}_2$$

## 中心场的散度（式 13.56）

对位置向量场与一般中心场 $\varphi(r)\vec{r}$（见 [[concepts/中心向量场与球面向量场]]）有闭式结果：

$$\operatorname{div}\vec{r} = 3,\qquad \operatorname{div}\big(\varphi(r)\,\vec{r}\big) = 3\varphi(r) + r\,\varphi'(r)$$

后者可由乘积法则与 $\nabla r = \vec{r}/r$ 独立推出（复算见 [[findings/式13-48至13-56散度定义坐标系公式与运算法则转录复算]]）。
