# 多边形

多边形（一般多边形）是由直线段作为边所围成的封闭平面图形。按《数学手册(原书第10版)》3.1.5.1 的论述，任一这样的 n 边图形都可以分解成 n − 2 个三角形（三角剖分，图 3.22），由此立得三条基本量：外角和恒为 360°、内角和为 180°·(n − 2)、对角线数为 n(n − 3)/2。

## 基本公式

```
Σ_{i=1}^{n} β_i = 360°              (3.44)  外角和
Σ_{i=1}^{n} γ_i = 180°·(n − 2)      (3.45)  内角和
D = n(n − 3)/2                       (3.46)  对角线数
```

其中 βᵢ 为外角、γᵢ 为内角、D 为对角线数。详见 [[findings/一般多边形角和对角线公式]]。

## 与相关条目的关系

- 当 n 条边相等且 n 个角相等时，得到 [[concepts/正凸多边形]]，其度量由 [[concepts/内切圆与外接圆]] 的半径 R 与 r 刻画。
- 内角与外角的概念承接 [[concepts/角]]（3.1.1）；内角的取值可按 [[findings/角的六类名称与区间]] 分类。
