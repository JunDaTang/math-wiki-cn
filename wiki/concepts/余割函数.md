# 余割函数

余割函数是六种[[concepts/三角函数]]之一，为正弦的倒数：

$$y = \csc x = \frac{1}{\sin x} \tag{2.71}$$

其图像可由[[concepts/正割函数]]图像向右平移 π/2 个单位得到（源文作「向右平移 x = π/2 个单位」，「x =」疑为衍文，见 [[queries/余割平移x等于π除2是否衍文]]；恒等式 $\csc x = \sec\left(x-\frac{\pi}{2}\right)$ 成立）。

## 性质

- 周期 $T = 2\pi$；渐近线 $x = k\pi$（sin x 的零点，即[[concepts/无穷间断点]]/[[concepts/极点]]）；$|y| \geqslant 1$；
- 局部极大值点 $A_k = \left(\frac{4k+3}{2}\pi,\ -1\right)$（k = 0, ±1, ±2, …）；
- 局部极小值点 $B_k = \left(\frac{4k+1}{2}\pi,\ +1\right)$。

极值反转的解释与正割相同：负支中心处 −1 为局部极大、正支中心处 +1 为局部极小（见 [[findings/正割与余割的值域约束与极值反转]]）。
