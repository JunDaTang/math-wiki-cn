# 吉拉尔定理

吉拉尔定理给出球面三角形的面积公式：面积正比于球面角盈 ε，比例系数为球表面积的 1/720：

```
A_T = (A_S/720°)·ε    (3.186b)
```

其中 A_S 为球的表面积（球面几何见 [[concepts/球]]）。它与另一形式

```
A_T = εR²·π/180° = R²ε/ρ = R² arc ε    (3.186a)
```

完全等价：把角盈化为弧度后，A_T = R²·ε(rad)，即面积恰为「角盈弧度值 × 半径平方」。ρ 是 3.4.1 节的换算因子（式 3.175c，尚未入库）。

定理以吉拉尔冠名（Albert Girard，16–17 世纪数学家——此身份为可独立验证的背景知识，非出自本手册）。

## 与其他公式的关系

- 若三边已知而非角盈，手册指明可先借助 [[concepts/吕利耶公式]]（式 3.201）由边直算 ε，再代入面积公式——这是命题 (8) 中明确给出的路径。
- 平面对照：平面三角形面积由边经 [[concepts/海伦公式]] 计算；球面三角形面积则由角经 [[concepts/球面角盈]] 计算，见 [[comparisons/平面与球面三角学公式对应比较]]。
