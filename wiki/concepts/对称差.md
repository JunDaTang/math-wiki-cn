# 对称差

**对称差** $A \triangle B$ 是所有恰好属于集合 $A$、$B$ 之一的元素的集合。本源给出的定义式为

$$A \triangle B = \{x \mid (x \in A \lor x \notin B) \land (x \in B \lor x \notin A)\} \tag{5.64b}$$

⚠️ 式 (5.64b) 的连接词疑为转写讹误：按原文形式，$x \in A \cap B$ 与 $x \notin A \cup B$ 时该条件均为真，与 (5.64c) 的正确刻画矛盾；正确形式应为 $(x \in A \land x \notin B) \lor (x \notin A \land x \in B)$（见 [[queries/式5-64b对称差定义连接词讹误]]）。

由定义可知等价刻画：

$$A \triangle B = (A \backslash B) \cup (B \backslash A) = (A \cup B) \backslash (A \cap B) \tag{5.64c}$$

即对称差含有恰好具有定义性质 $E_1$（对于 A）和 $E_2$（对于 B）之一的元素。
