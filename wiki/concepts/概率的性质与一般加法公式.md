# 概率的性质与一般加法公式

由 [[concepts/概率的公理化定义]] 的三条公理，手册推出概率的下列性质：

1. **单调性**：$B \subseteq A$ 可得 $P(B) \leqslant P(A)$（式 16.33）；
2. **补事件**：$P(A) + P(\bar A) = 1$（式 16.34）；
3. **有限加法**：对 $n$ 个两两互斥事件（$A_iA_k = O$，$i \neq k$），

$$P(A_1 + A_2 + \dots + A_n) = P(A_1) + P(A_2) + \dots + P(A_n) \tag{16.35a}$$

$n=2$ 时 $P(A+B) = P(A) + P(B)$（式 16.35b）；

4. **一般加法公式**（容斥原理）：对任意事件 $A_i$（$i = 1, \dots, n$），

$$P(A_1 + \dots + A_n) = \sum_i P(A_i) - \sum_{i<j} P(A_iA_j) + \sum_{i<j<k} P(A_iA_jA_k) - \dots + (-1)^{n-1} P(A_1A_2\dots A_n) \tag{16.36a}$$

$n=2$ 时 $P(A_1+A_2) = P(A_1)+P(A_2)-P(A_1A_2)$（式 16.36b）。

式 16.36a 原文以逐项枚举的长式给出，此处归并为求和记号；逐项照录与复算见 [[findings/式16-30至16-38概率公理性质与等可能事件转录复算]]。

## 应用

- $P(A)+P(\bar A)=1$ 是 [[concepts/生日问题]] 补集法计算的基础；
- 一般加法公式在事件不互斥时替代有限加法，是容斥计数的概率版本。
