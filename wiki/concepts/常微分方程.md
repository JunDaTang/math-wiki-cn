# 常微分方程

常微分方程是只有一个自变量的 [[微分方程]]。此为《数学手册(原书第10版)》第9章章首定义 (2) 之一支：常微分方程与偏微分方程相互间的差别在于自变量的数目，第一种情形（常微分方程）只有一个自变量。（通行英文术语 ordinary differential equation，属背景补充，手册原文未附。）

在同书 9.1 节的表述中，常微分方程是联系一个自变量 x、未知函数 y(x) 及其各阶导数的方程，其中出现的最高阶导数的阶数 n 称为方程的阶。9.1 节的这一定义框架是第 9 章全部内容的地基，本页的隐式/显式形式、解、定解问题分类诸节均依该框架建立。

## 第9章章首例式

章首例 A 为一阶常微分方程（y 为 x 的函数，最高阶导数为一阶；原文 LaTeX 逐字）：

$\left( { \frac { \mathrm { d } y } { \mathrm { d } x } } \right) ^ { 2 } - x y ^ { 5 } { \frac { \mathrm { d } y } { \mathrm { d } x } } + \sin y = 0 .$

章首例 B 以微分形式书写（原文 LaTeX 逐字）：

$x \mathrm { d } ^ { 2 } y \mathrm { d } x - \mathrm { d } y ( \mathrm { d } x ) ^ { 2 } = \mathrm { e } ^ { y } ( \mathrm { d } y ) ^ { 3 }$

判读：各项除以 (dx)³ 后形式上对应二阶常微分方程 x y″ − y′ = e^y (y′)³；因原文排印归属含混，此判读属推断（见 [[第9章全节系统性转写讹误清单]]）。

## 隐式形式与显式形式

一般的 n 阶常微分方程的隐式 (implicit form) 形式为式 9.1：

```latex
F \big [ x, y (x), y ^ {\prime} (x), \dots , y ^ {(n)} (x) \big ] = 0.\tag{9.1}
```

如果从这个方程中解出了 y⁽ⁿ⁾(x)，那么它就是一个 n 阶常微分方程的显式 (explicit form)。本节只以文字给出显式形式的这一定义，未另行编号。

## 解

一个微分方程的**解或积分**是在一个区间 a ≤ x ≤ b（此区间也可以是无限的）上满足这个方程的每个函数。解的层级（通解→特解）见 [[通解与特解]]。

## 定解问题的分类

- [[初值问题]]：附加条件集中在区间一端（同一点 x₀ 处给定 y 及其直至 n−1 阶导数的值）。
- [[边值问题]]：附加条件分布在定义域中若干点处。
- 两者定常数的统一机制见 [[附加条件确定通解常数流程]]。

## 与第 8 章积分学的关系

通解中的 n 个任意常数是第 8 章不定积分单一积分常数 +C 的推广；「通积分」「特别积分」术语直接沿用第 8 章语言（参见 [[定积分]]、[[定积分与不定积分比较]] 所在的第 8 章体系）。

## 术语与范围注记

- 背景注（可独立验证的通行含义）：「常」(ordinary) 限定未知函数只依赖一个自变量；含多个自变量偏导数的方程为偏微分方程，不在本节范围内。
- 方程的进一步分类（线性/非线性、一阶/高阶、齐次/非齐次等）在本节未展开，预计由 9.1.1 起的小节给出（未入库，见 [[9-1-1至9-1-3子小节未入库回指缺口]]）。
- 本节原文存在斜体字母 n 的系统性转写脱漏，转录校正见 [[式9-1与解概念定义组逐字转录]] 与 [[9-1全节系统性转写讹误清单]]。
