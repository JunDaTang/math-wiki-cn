# 指数函数

**指数函数**是最简单的初等超越函数之一：**底为常数，指数为变量 $x$ 或 $x$ 的代数函数**。定义出自《数学手册(原书第10版)》2.2.2.1（见 [[10-数学手册原书第10版--7-22-初等函数--slrafi]]）；在手册 2.6.1 中给出其一般形式：

$$
y = a^{x} = \mathrm{e}^{bx} \quad (a > 0,\ b = \ln a)
$$

（式 2.54），其中底数 $a$ 为正数，$b = \ln a$；其图像称为**指数曲线**。当 $a = \mathrm{e}$（$\mathrm{e}$ 为自然对数的底）时得到自然指数函数 $y = \mathrm{e}^{x}$（式 2.55）。

手册 2.2.2.1 给出的例子：

- $\mathbf{A}\colon y = \mathrm{e}^{x}$
- $\mathbf{B}\colon y = a^{x}$
- $\mathbf{C}\colon y = 2^{3x^{2} - 5x}$

## 基本性质（手册 2.6.1，已复核）

- **定义域与值域**：定义域 (−∞, +∞)，只取正值，值域 (0, +∞)。
- **单调性**：a > 1（即 b > 0）时严格单调递增，值由 0 到 +∞；a < 1（即 b < 0）时严格单调递减，值由 +∞ 到 0。
- **定点**：曲线过点 (0, 1)。
- **渐近行为**：b > 0 时在左侧渐近趋近 x 轴，b < 0 时在右侧渐近趋近 x 轴（水平[[渐近线]]）。
- **速度**：|b| 越大，函数增加或减小的速度越快，趋近 x 轴也越快。
- **倒底变换**：$a^{-x} = (1/a)^{x}$，故 a < 1 时 y = a^{−x} 是增函数，a > 1 时是减函数（增减性反转）。

## 与幂的区分

指数函数与 [[幂]] 的变量方向相反：幂 $x^{a}$ 中底为变量、指数为常数；指数函数 $a^{x}$ 中底为常数、指数为变量。两者在初等函数定义中同属"方幂"类构造要素，但函数归类不同：幂式经有限运算通常落入代数函数，指数函数则属超越函数。

进一步，在 [[函数的量级]] 与 [[朗道符号]] 意义下，指数增长快于任何幂增长——手册 2.1.4 的量级结论（[[朗道符号定义与指数对数量级结论]]）即以本函数为对象。

## 在函数族体系中的地位

指数函数是 [[数学手册原书第10版]] §2.6 中后续各函数族的基元：[[误差曲线]] $y = \mathrm{e}^{-(ax)^2}$、[[指数和]] $y = a\mathrm{e}^{bx} + c\mathrm{e}^{dx}$、[[广义误差函数]] $y = a\mathrm{e}^{bx+cx^2}$ 与 [[幂函数与指数函数的乘积]] $y = ax^b\mathrm{e}^{cx}$ 均以 $\mathrm{e}^{(\cdot)}$ 为骨架。

其反函数为 [[对数函数]]（对数曲线 = 指数曲线沿 $y = x$ 的反射像）。要素细节见 [[指数函数的单调性与渐近行为]]，对偶关系见 [[指数函数与对数函数比较]]。
