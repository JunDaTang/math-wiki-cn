# 尼科梅德斯蚌线

尼科梅德斯蚌线是一条直线的蚌线：取定渐近线 $x = a$（$a > 0$），过极点 O 的每条射线与该直线交于 M，满足

$$\overline{OP} = \overline{OM} \pm l \tag{2.232}$$

的点 P 的轨迹（$l > 0$；相对渐近线，右分支取"+"、左分支取"−"）。它是 [[concepts/一般蚌线]]（式 2.234）在母曲线为直线时的特例，冠名于古希腊数学家 Nicomedes（手册仅作冠名，无人物论述）。手册 2.12.1 以其作为四阶(四次)曲线的首个实例。

## 三种方程

| 形式 | 方程 | 编号 |
|---|---|---|
| 隐式（笛卡儿） | $(x-a)^2(x^2+y^2) - l^2x^2 = 0$ | (2.233a) |
| 参数式 | $x = a + l\cos\varphi,\quad y = a\tan\varphi + l\sin\varphi$ | (2.233b) |
| 极坐标 | $\rho = \dfrac{a}{\cos\varphi} \pm l$ | (2.233c) |

参数域按分支选取：右支 $-\pi/2 < \varphi < \pi/2$，左支 $\pi/2 < \varphi < 3\pi/2$。

## 几何要素

- **渐近线**：两支均以 $x = a$ 为 [[concepts/渐近线]]（$\varphi \to \pm\pi/2$ 或 $3\pi/2$ 时 $x \to a$、$|y| \to \infty$）。
- **顶点**：A(a+l, 0)（右支）、D(a−l, 0)（左支）。
- **面积**：右支与渐近线围成的面积 $S = \infty$。
- **拐点**：横坐标由三次方程 $x^3 - 3a^2x + 2a(a^2-l^2) = 0$ 的根给出——右支拐点 B, C 取最大根；l < a 时左支拐点 E, F 取第二大根。

## 原点奇点三分律

原点为奇点，类型由 l 与 a 之比决定（详见 [[findings/尼科梅德斯蚌线的奇点三分律与特征点]]）：

| 条件 | 原点类型 | 附加特征 |
|---|---|---|
| l < a | 孤立点（图 2.62(a)） | 左支两拐点 E, F |
| l = a | 尖点（图 2.62(c)） | — |
| l > a | 二重点（图 2.62(b)） | $\tan\alpha = \pm\sqrt{l^2-a^2}/a$，$r_0 = l\sqrt{l^2-a^2}/(2a)$；左支在 $x = a - \sqrt[3]{al^2}$ 处有一极大一极小 |

该三分律与 [[concepts/帕斯卡蜗线]] 的方向**相反**（蜗线在 l < a 时为二重点、l > a 时为孤立点），两族结论不可互相移用，对照见 [[comparisons/尼科梅德斯蚌线与帕斯卡蜗线奇点分类比较]]。
