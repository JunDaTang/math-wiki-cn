# 霍拉迪定理

霍拉迪定理是自然三次样条的最小全曲率性质：设 S(x) 为自然三次插值样条，则对任意满足同样插值条件 g(x_i) = f_i（i = 1,…,N）的二次连续可微函数 g(x)，有

```latex
(19.235)  ∫_{x_1}^{x_N} [S''(x)]² dx ⩽ ∫_{x_1}^{x_N} [g''(x)]² dx
```

## 内容与解释

- 由曲率的首次逼近 κ ≈ S″（原书回指第 331 页 3.6.1.2,4.），(19.235) 表明 S 具有**最小全曲率**；
- 弹性细尺类比：若称为样条的细弹性尺穿过点 (x_i, f_i)，则其弯曲线沿三次样条 S(x)。注意 κ ≈ S″ 仅是一次近似（小斜率情形），弹性尺类比是启发性论证而非严格证明。

## 归属与适用范围

- 定理冠名者见 [[entities/霍拉迪]]。
- **归属注意**：极小性属于满足边界条件 a（S″(x_1) = S″(x_N) = 0）的**自然样条**。原书在并列列出三类边界条件（自然、端点导数给定、周期）之后陈述「由这些性质可得」，指代略含糊；对端点导数给定型样条与周期样条是否成立相应变体，原书未言，勿外推。
