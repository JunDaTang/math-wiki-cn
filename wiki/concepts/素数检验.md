# 素数检验

素数检验（素性检验）是判定一个自然数是否为素数的方法总称。《数学手册》5.4.5 将其分为两条路线：

1. **随机性（概率性）路线**：费马素数检验（[[concepts/费马素数检验]]）与拉宾-米勒素数检验（[[concepts/拉宾-米勒素数检验]]）。源文总论断：它们对检验大数的素数性质有用、出错概率足够小，且**可在不知道素因子的情形下证明一个数不是素数**——找到任一「失败基」即得确定性的合数结论，只有「可能素数」的正面结论带有误差。
2. **确定性路线**：AKS 素数检验（[[concepts/aks素数检验]]），2002 年发表的多项式时间算法，无错误概率。

## 与既有检验的关系

此前入库的 Lucas-Lehmer 检验（[[methodology/卢卡斯-莱默素性检验流程]]，见 [[findings/梅森数与lucas-lehmer判别法]]）是只适用于梅森数 M_p 的特殊用途确定性检验；本节将素性检验扩展为对一般自然数的方法谱系。埃拉托色尼筛法（[[methodology/埃拉托色尼筛法流程]]）是枚举路线；AKS 流程中对 n < 5,690,034 的数直接查素数表，即承认表驱动路线。

## 误差语义（关键区分）

- 费马检验：k 个互素基的错误水平 ≤ 1/2^k，**仅当 n 为非卡迈克尔合数**。
- 拉宾-米勒检验：k 个随机独立基的第一类误差率 ≤ 1/4^k，对**一切合数**成立；实用取 k = 25。
- AKS 检验：零误差。

详见 [[findings/随机素数检验误差界组]] 与 [[comparisons/概率性与确定性素性检验比较]]。三者的论断互不可转移（归属隔离）。
