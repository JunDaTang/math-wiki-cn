# 法则基础

**法则基础**（rule base）是模糊系统中 IF–THEN 模糊法则的集合，是基于知识的模糊系统的共同支点：每条法则由**前提**（对测量值的语言说明）与**结论**（给出适当的控制值或输出）组成，前提中的量以 [[语言变量]] 的语言项（模糊集）表示。数学手册 5.9.6 给出两种后件形式：

**模糊后件（Mamdani，式 5.389）：**

$$
R^{i}:\ \text{如果 } e \text{ 是 } E^{i} \text{ 并且 } \dot{e} \text{ 是 } \Delta E^{i},\ \text{那么 } u \text{ 是 } U^{i}.
$$

**函数后件（Sugeno，式 5.390）：**

$$
R^{i}: \text{如果 } x_1 \text{ 是 } A_1^{i},\ \dots,\ \text{并且 } x_k \text{ 是 } A_k^{i},\ \text{那么 } u_i = p_0^i + p_1^i x_1 + \dots + p_k^i x_k.
$$

## 法则权（前提满足等级）

清晰测量值与前提比较后，每条法则获得一个**权**（满足等级 / 实现等级）$\alpha_i\in[0,1]$：Mamdani 逆摆算例中取前提隶属等级的 min（一般可为 [[t-范数]]）；权为零的法则不起作用。这一「比较—赋权」机制即 [[模糊化]]，后续推理与 [[模糊逻辑推理]] 及 [[模糊关系的复合]] 相衔接。
