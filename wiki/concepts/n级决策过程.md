# n 级决策过程

n 级决策过程是离散动态规划的基本过程模型（《数学手册(原书第10版)》18.3.1.1）：过程从初始状态 $x_0=x_a$ 出发，经中间状态 $x_1,\dots,x_{n-1}$，最终进入终止状态 $x_n=x_e\in X_e\subseteq\mathbb{R}^m$。

## 组成要素

- **状态与状态空间**：状态向量 $x_j$ 属于状态空间 $X_j\subseteq\mathbb{R}^m$（$m$ 维）。
- **决策与决策空间**：为把状态 $x_{j-1}$ 驱动到 $x_j$，须选取决策向量 $u_j$；在状态 $x_{j-1}$ 处所有可能的决策向量构成决策空间 $U_j(x_{j-1})\subseteq\mathbb{R}^s$（$s$ 维）。
- **状态变换**（式 18.125）：

$$x_j = g_j(x_{j-1}, u_j), \quad j = 1(1)n.$$

过程的链式结构见手册图 18.14（n 级决策过程示意图，媒体文件已随本 source 保存）。

## 说明

- 决策空间维数记作 $s$，故 18.3.1.2 标准形（式 18.126a）末行将 $U_j(x_{j-1})$ 写作 $\subseteq\mathbb{R}^m$ 应为 $\mathbb{R}^s$ 之误，见 [[queries/18-3全节系统性转写讹误清单]]。
- n 级决策过程是 [[concepts/动态规划标准形]] 的载体；对其费用函数附加可分性与极小可交换性后，即可建立 [[concepts/贝尔曼泛函方程]]。
