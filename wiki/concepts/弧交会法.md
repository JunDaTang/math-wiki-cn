# 弧交会法

弧交会法是以两条距离弧的交点确定新点 N 的定位方法：环绕两个具有已知坐标的点 A、B，各测半径 $s_{AN}$、$s_{BN}$，两条弧的交点即 N（图 3.46）。

![图 3.46 弧交会法](media/10-数学手册原书第10版--8-32-平面三角学--j56osm/016-ddfdcf5d1a7c5359fdcb59c65bc2f2845682f96235fa0ad1b373cff898964355.jpg)

**已知**：$y_A, x_A; y_B, x_B$。**所测**：$s_{AN}; s_{BN}$。**所求**：$s_{AB}, y_N, x_N$。

解算链 (3.114)：先由坐标算 $s_{AB}$ 与 $t_{AB}$（$t_{BA} = t_{AB} + 200\ \mathrm{gon}$）；此时三角形 ABN 三边已知，用 [[concepts/余弦定律]] 反解角：

$$\cos\alpha = \frac{s_{AN}^2 + s_{AB}^2 - s_{BN}^2}{2 s_{AN} s_{AB}},\qquad \cos\beta = \frac{s_{BN}^2 + s_{AB}^2 - s_{AN}^2}{2 s_{BN} s_{AB}}$$

再经方位角传递 $t_{AN} = t_{AB} - \alpha$、$t_{BN} = t_{BA} - \beta$，坐标正算并从 A、B 两端复算检核 (3.114h–k)。

源文提到第二种解法（将一般三角形分解为两个直角三角形）但明确「这里不作讨论」。公式全文见 [[findings/弧交会法解算]]；与其他定位法的比较见 [[comparisons/交会定位三法比较]]。
