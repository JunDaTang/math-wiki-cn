# 整除性判别法

**整除性判别法**（本源 5.4.1.3）是不经除法运算、利用十进制表示判断小素数（及 $2^k$、$5^k$）是否整除 $n$ 的法则。为此引入按 1/2/3 位分组的（交错）数字和记号。设

$$n=(a_k a_{k-1}\dots a_1 a_0)_{10}=a_k 10^k+\dots+a_1 10+a_0\tag{5.229a}$$

则：

- $Q_1(n)=a_0+a_1+\dots+a_k$（一阶数字和，5.229b）；$Q_1'(n)=a_0-a_1+a_2-+\dots+(-1)^k a_k$（一阶数字交错和，5.229c）
- $Q_2(n),\ Q_2'(n)$：按两位分组（$(a_1a_0)_{10},(a_3a_2)_{10},\dots$）的求和与交错和（5.229d,e）
- $Q_3(n),\ Q_3'(n)$：按三位分组（$(a_2a_1a_0)_{10},(a_5a_4a_3)_{10},\dots$）的求和与交错和（5.229f,g；源文 g 式标号误作 $Q_2'$，应为 $Q_3'$，见 [[queries/式5-229g标号是否应为q3撇]]）

## 判别法表 DC-1–DC-11（式 5.230a–k）

| 编号 | 判别法 |
|---|---|
| DC-1 | $3\mid n \Leftrightarrow 3\mid Q_1(n)$ |
| DC-2 | $7\mid n \Leftrightarrow 7\mid Q_3'(n)$ |
| DC-3 | $9\mid n \Leftrightarrow 9\mid Q_1(n)$ |
| DC-4 | $11\mid n \Leftrightarrow 11\mid Q_1'(n)$ |
| DC-5 | $13\mid n \Leftrightarrow 13\mid Q_3'(n)$ |
| DC-6 | $37\mid n \Leftrightarrow 37\mid Q_3(n)$ |
| DC-7 | $101\mid n \Leftrightarrow 101\mid Q_2'(n)$ |
| DC-8 | $2\mid n \Leftrightarrow 2\mid a_0$ |
| DC-9 | $5\mid n \Leftrightarrow 5\mid a_0$ |
| DC-10 | $2^k\mid n \Leftrightarrow 2^k\mid (a_{k-1}\dots a_1 a_0)_{10}$ |
| DC-11 | $5^k\mid n \Leftrightarrow 5^k\mid (a_{k-1}\dots a_1 a_0)_{10}$ |

## 原理（本 wiki 推断补充，非源文本）

判别法等价于 $10,10^2,10^3$ 的模同余：$10\equiv 1\ (\mathrm{mod}\ 3,9)$；$10\equiv-1\ (\mathrm{mod}\ 11)$；$10^2\equiv-1\ (\mathrm{mod}\ 101)$；$10^3\equiv-1\ (\mathrm{mod}\ 7,13)$；$10^3\equiv 1\ (\mathrm{mod}\ 37)$；以及 $10^k\equiv 0\ (\mathrm{mod}\ 2^k,5^k)$ 使整除归结为末 $k$ 位。算例（$123456789$、$91619$、$99994096$，均已复算）与完整复核见 [[findings/q记号与dc判别法组]]。
