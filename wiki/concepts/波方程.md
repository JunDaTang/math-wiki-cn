# 波方程

波方程（wave equation，又称波动方程）是描述均匀介质中振荡（扰动）传播的二阶线性双曲型偏微分方程，其一般形式为式 9.104a：∂²u/∂t² − a²Δu = Q(x, t)，其中 a 为扰动的波速，Δ 为 [[拉普拉斯算子]]，x 表示 n 维问题的全部变量 x₁, x₂, ⋯, xₙ；没有扰动时右端 Q 为零。源明言微分方程（9.104a）是双曲型的，其解称为波函数（wave function）u。

## 定义与初始条件

```latex
(9.104a)  \frac{\partial^{2} u}{\partial t^{2}} - a^{2}\Delta u = Q(x, t)
(9.104b)  \Delta u = \frac{\partial^{2} u}{\partial x_{1}^{2}} + \frac{\partial^{2} u}{\partial x_{2}^{2}} + \dots + \frac{\partial^{2} u}{\partial x_{n}^{2}}
(9.105)   u\big|_{t=0} = \varphi(x), \quad \left.\frac{\partial u}{\partial t}\right|_{t=0} = \psi(x)
```

按 9.2.3.1 的原则，双曲型方程（振动过程）的正确定解形式是柯西问题——[[初值问题]] 的 PDE 推广：在初始流形（曲线或曲面）上给出所求函数及其沿非切向（通常是法向）导数的值（式 9.105 即其典型形态）。源回指原书第 756 页 9.2.1.1, 5（未入库）。

## 齐次问题的解（Q = 0）

n = 3/2/1 分别由三个积分公式给出（详见 [[波方程三维二维一维解公式比较]]）：

- n = 3：[[基尔霍夫公式]]（式 9.106a），球面 S_at 上积分；
- n = 2：[[泊松公式]]（式 9.106b），圆盘 C_at 上加权积分；
- n = 1：[[达朗贝尔公式]]（式 9.106c），区间 [x₁ − at, x₁ + at] 上积分。

## 非齐次问题（Q ≠ 0）

须在 (9.106a, b, c) 的右端添加正确的项：n = 3 为 [[推迟位势]]（式 9.107a，Q 带时滞 t − r/a）；n = 2 为式 9.107b（锥域 K 上的三重积分）；n = 1 为式 9.107c（三角形域 T 上的二重积分）。

## 注意事项

- 本源中“波函数”指波方程的解 u（经典意义），与量子力学 [[薛定谔方程]] 语境的波函数是不同用法，源未作区分说明。
- 9.2.3.3.2 有“在波方程的解 (9.108b)(9.108c) 中改变记号即得到 (9.109) 的解”一语，但 9.108b/c 实为 [[热导方程]] 的解，“波方程”疑为“热导方程”之误（见 [[式9-108b与9-108c是否被误称为波方程的解]]）。
- 源仅对热导方程声明 t < 0 方向不适定，未讨论波方程的反向问题；波方程本身在 t → −t 下不变（独立可验证的数学背景，见 [[三类典型二阶线性偏微分方程比较]]）。
