# 三角与复数变换命令（Trig 选项与 ComplexExpand）

Mathematica 对含三角函数与复变元的表达式进行变换的命令族：Expand 与 Factor 配选项 Trig->True，可用具有倍自变量的三角函数表达三角函数的乘幂，反之亦然；另有 TrigExpand、TrigFactor、TrigFactorList、TrigReduce、ExpToTrig、TrigToExp 可供选择。

## 源例

```text
In[1] := TrigExpand[Sin[2x] Cos[2y]]
Out[1] = 2 Cos[x] Cos[y]² Sin[x] - 2 Cos[x] Sin[x] Sin[y]²
In[2] := Factor[Sin[4x] - 8Cos[x]³Sin[x] + 4Cos[x]Sin[x], Trig->True]
Out[2] = 0
In[3] := Factor[Cos[5x], Trig->True]
Out[3] = Cos[x](1 - 2Cos[2x] + 2Cos[4x])
```

（In[2] 源印「Factor[sin[4x], Trig-> True] - 8Cos[x]³Sin[x] + 4Cos[x]Sin[x]」，逗号错位且 sin 小写，复原如上；复原式恒等于 0 已经由恒等式 sin4x = 4 sinx cosx cos2x = 8cos³x sinx − 4cosx sinx 验证，见 [[queries/Factor-sin-4x逗号错位与小写sin之辨]]。三例经独立复算全部成立，见 [[findings/20-3-1代数与多项式算例复算]]。）

## ComplexExpand 与变元虚实假设

- ComplexExpand[expr] 假定了一个实变元 expr（变元视为实）；
- ComplexExpand[expr, {x1, x2, ···}] 中所列变元假定为复变元。

```text
In[1] := ComplexExpand[Sin[2x], {x}]
Out[1] = Cosh[2 Im[x]] Sin[2 Re[x]] + I Cos[2 Re[x]] Sinh[2 Im[x]]
```

（与 sin(2z) = sin(2xᵣ)cosh(2xᵢ) + i cos(2xᵣ)sinh(2xᵢ) 一致。源印「Complex-Expand」词中断裂、「{xl,x2}」为 {x1,x2} 之讹。）
