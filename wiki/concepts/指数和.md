# 指数和

指数和是两个 [[指数函数]] 的加权和

$$
y = a\,\mathrm{e}^{bx} + c\,\mathrm{e}^{dx} \tag{2.60}
$$

（式 2.60）。在《数学手册(原书第10版)》2.16.2.11 中，该函数族又被开列为经验公式族（式 2.267a），典型曲线形状见图 2.91；其初级定义与图像讨论见 2.6.1 的 (2.60) 与图 2.29（第 94–95 页）。

## 定义与图像（2.6.1）

指数和的图像通过把两曲线 $y_1 = a\mathrm{e}^{bx}$ 与 $y_2 = c\mathrm{e}^{dx}$ 的坐标相加得到；因两连续函数之和为连续函数（[[连续函数的和差积商与复合均连续]]，式 2.31），指数和处处连续。当 a, b, c, d 均不为零时，其图像是四种形式之一（图 2.29 (a)–(d)），依参数符号不同可能沿坐标轴反射。

## 特征点公式（a, b, c, d ≠ 0，已复核）

- **y 轴交点** $A(0,\ a+c)$；
- **x 轴交点** $B\left(\dfrac{\ln(-a/c)}{d-b},\ 0\right)$；
- **极值点 C** 的横坐标 $x = \dfrac{1}{d-b}\ln\left(-\dfrac{ab}{cd}\right)$；
- **拐点 D** 的横坐标 $x = \dfrac{1}{d-b}\ln\left(-\dfrac{ab^{2}}{cd^{2}}\right)$。

四式分别由 y = 0、y′ = 0、y″ = 0 直接解出，复核通过。

## 符号判别法（本族核心方法）

- **极值存在性**：看 $\operatorname{sgn}(ab)$ 与 $\operatorname{sgn}(cd)$ 是否异号（异号时 $-\frac{ab}{cd} > 0$，对数有定义）；
- **拐点存在性**：看 $\operatorname{sgn}(a)$ 与 $\operatorname{sgn}(c)$（因 $ab^{2}$、$cd^{2}$ 分别承 $a$、$c$ 之号），此条件亦等价于 x 轴交点 B 的存在与函数变号。

由此得四情形分类（a 与 c 同/异号 × b 与 d 同/异号），详见 [[指数和四情形分类与特征点公式]] 与 [[指数和四情形比较]]。

## 作为经验公式族（2.16.2.11）

在《数学手册(原书第10版)》2.16 经验曲线的确定中，指数和（式 2.267a）是 2.16.2.11 开列的经验公式族之一，其典型曲线形状见图 2.91。

### 两级修正

指数和是 11 类经验公式族中唯一采用**两级修正**的族：

1. **第一级（式 2.267b）**：设 x 的值构成公差 h 的等差数列，$y, y_1, y_2$ 为已知函数的任意三个连续值，取 $X=\frac{y_1}{y},\ Y=\frac{y_2}{y}$，手册给出（按转写字面）$Y=(\mathrm{e}^{bh+dh})X-\mathrm{e}^{bh}\mathrm{e}^{dh}$。该式斜率系数存疑：由二阶线性递推推导应为 $\mathrm{e}^{bh}+\mathrm{e}^{dh}$，见 [[式2-267b系数e-bh-dh是否应为e-bh加e-dh]]。
2. **第二级（式 2.267c）**：b、d 确定之后，取 $\overline{Y}=y\mathrm{e}^{-dx},\ \overline{X}=\mathrm{e}^{(b-d)x}$，得 $\overline{Y}=a\overline{X}+c$，再次修正（并以平均值法或最小二乘法定 a、c）。

手册 2.16.1.3 明确以 (2.267b)、(2.267c) 为“当某些参数出现在近似公式的非线性关系中时，修正和平均值法都会用到”的例证。详细分析见 [[指数和的两级修正]]。
