# 中心对称场中的粒子运动

中心对称场中的粒子运动是粒子在球对称位势场 V(r) 中运动的量子力学模型，再现一个电子在带正电荷原子核的静电场中的运动（类氢模型；手册另见第 916 页 13.1.2.2，未入库）。因是球面对称问题，采用球坐标（9.135a，图 9.20）：r、ϑ（极角）、φ（方位角）。

## 方程与分离变量（9.135–9.136）

- 拉普拉斯算子的球坐标展开（9.135b，与标准形式一致 ✓）；定常薛定谔方程为 9.135c（其极角项分母疑误，见 [[queries/式9-135c极角项分母疑误]]）。
- 求形如 Ψ(r,ϑ,φ) = R_l(r)·Y_l^m(ϑ,φ) 的解（9.136a）；代入后除以 R_lY_l^m 并乘 r²（9.136c），两端各仅依赖 r 或 (ϑ,φ)，取分离常数 l(l+1)：
  - **径向方程**（9.136d）：仅依赖 r 与位势 V(r)；
  - 角部分再分离 Y_l^m = Θ(ϑ)Φ(φ)（9.136e），以 m² 为分离常数，得**极方程**（9.136g，缔合勒让德型，见 [[concepts/勒让德微分方程]]）与**方位方程**（9.136h）。这两个方程与位势无关，对每个有心对称位势场都成立。

## 径向方程：离心位势与有效位势（9.137）

```latex
u_l(r)=r\,R_l(r),\qquad
V_{\mathrm{eff}}=V(r)+V_{l},\qquad V_{l}(r)=V_{\mathrm{rot}}(l)=\frac{l(l+1)\hbar^{2}}{2mr^{2}}   % 9.137a,c,d
```

- 代换 u_l = rR_l 的理由：|u_l|²dr = |R_l|²r²dr 是粒子出现在 r 与 r+dr 之间球壳中的概率；代换后化为一维薛定谔方程（9.137b，系数疑漏 ℏ 的平方，见 [[queries/式9-137b径向方程系数疑漏ℏ平方]]）。
- 离心位势 V_l 与经典转动能类比（9.137e）：E_rot = l⃗²/(2Θ)，Θ = μr²；轨道角动量本征值 l⃗² = l(l+1)ℏ²（9.137f，见 [[entities/角动量算子]]）——分离常数 l(l+1) 的物理来源。

## 角方程的解（9.138–9.140）

- 极方程仅当 l(l+1) = 0, 2, 6, 12, … 时存在有限、单值、连续解：l = 0,1,2,…，|m| ⩽ l（9.138a/b）；解为相伴勒让德多项式（9.138c/d，[[entities/相伴勒让德多项式]]）。
- 方位方程解 Φ_m = (1/√(2π))e^{imφ}（9.139d）；单值性要求 m = 0, ±1, ±2, …，m 称磁量子数。即使在由一个磁场对一个空间方向以物理赋值的情形，运动也与方位角无关。
- 完全角解为球面调和函数 Y_l^m（9.140a，[[entities/球面调和函数]]）；由此得宇称 P = (−1)^l（9.140b–9.141b，[[concepts/宇称]]）。

## 记号张力

Θ 同时用作极角函数（9.136e）与转动惯量（9.137e）；V_l(l) 与 V_l(r) 记号不一致；源文 9.137f 的 |l⃗| 原书误为 |l⃗²|（译者注已证实）。
