# 希尔伯特空间中的傅里叶级数

希尔伯特空间中的傅里叶级数是把经典三角傅里叶级数（手册 7.4.1.1，未入库）推广到任意正交规范系的展开理论。设 H 是可分的希尔伯特空间，

$$
\{e_n : n = 1, 2, \dots\} \tag{12.126}
$$

是一给定的正交规范系。对元 x ∈ H，数 c_n = (x, e_n) 称作 x 相对于正交系 (12.126) 的**傅里叶系数**；（形式）级数

$$
\sum_{n=1}^{\infty} c_n e_n \tag{12.127}
$$

称作元 x 相对于正交系 (12.126) 的**傅里叶级数**。

## 最佳逼近性质

对固定 n，傅里叶级数的 n 阶部分和

$$
\sigma_n = \sum_{k=1}^{n} (x, e_k) e_k \tag{12.128}
$$

使得 ‖x − Σ_{k=1}^n α_k e_k‖ 在 H_n = lin({e₁, …, e_n}) 的所有向量中达到最小值；此外 x − σ_n 与 H_n 正交。该性质正是 [[concepts/投影定理与逼近定理]] 在有限维子空间 H_n 上的直接实现，操作化见 [[methodology/正交投影最佳逼近求解流程]]。

## 收敛性（12.4.3.2）

任意元 x ∈ H 的傅里叶级数**总是收敛的**，其和是元 x 在 H₀ = lin({e_n}ₙ₌₁^∞)‾ 上的投影。如果元 x 有表达式 x = Σ_{n=1}^∞ α_n e_n，那么 α_n 是 x 的傅里叶系数（n = 1, 2, …）。
