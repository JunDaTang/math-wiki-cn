# 三次插值样条

三次插值样条 S(x) 是分段三次、整体二次连续可微（S、S′、S″ 连续）、且满足插值条件与边界条件的样条函数，由手册 19.7.1.1 的四条性质唯一确定。其动机是高次插值逼近多项式通常有并不想要的振荡，故将近似区间用节点分为子区间，每段用次数不高于 3 的多项式，并要求在节点处光滑过渡。

## 定义四性质（19.7.1.1）

```latex
(1) S(x_i) = f_i   (i = 1, 2, …, N)
(2) S(x) 在任一子区间 [x_i, x_{i+1}] (i = 1, 2, …, N−1) 内为次数不高于 3 的多项式
(3) S(x) 在整个插值区间 [x_1, x_N] 上是二次连续可微的
(4) 特殊边界条件：
    a) S''(x_1) = S''(x_N) = 0                 （自然样条）
    b) S'(x_1) = f'_1,  S'(x_N) = f'_N         （f'_1, f'_N 为已知值）
    c) f_1 = f_N；S(x_1) = S(x_N), S'(x_1) = S'(x_N), S''(x_1) = S''(x_N)   （周期样条）
```

边界条件 b 型（端点一阶导数给定）原书未命名；a 型称自然样条，c 型称周期样条。

## 唯一性与变分意义

四条性质**唯一确定** S(x)（原书定义性陈述）。自然样条另满足 [[concepts/霍拉迪定理]]（最小全曲率），由此获得变分意义与弹性细尺解释。

## 系数确定

每段形式为 (19.236)：S(x) = S_i(x) = a_i + b_i(x−x_i) + c_i(x−x_i)² + d_i(x−x_i)³。系数经四步流程确定（a→d→b→c），核心是关于 c_2,…,c_{N−1} 的三对角线性方程组 (19.240)/(19.241)，用 LR 分解（[[concepts/三角分解与LU因子分解]]）求解——见 [[methodology/三次插值样条系数确定四步流程]]，推导复算见 [[findings/式19-235至19-241插值样条与系数确定转录复算]]。
