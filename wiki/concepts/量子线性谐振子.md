# 量子线性谐振子

量子线性谐振子是恢复力（手册称「拉力」）满足胡克（Hooke）定律 F = −kx 的量子力学模型（手册 9.2.4.7「线性谐振子」）：频率 ν = (1/2π)√(k/m)（9.142a）、ω = √(k/m)（9.142b）、势能 E_pot = kx²/2（9.142c；源文末式 (ω²/2)x² 疑漏因子 m，见 [[queries/式9-142c势能末式疑漏因子m]]）。

## 方程的化归（9.143–9.144）

代入定常薛定谔方程（源文称代入 9.114a，疑应为 9.113a，见 [[queries/谐振子一节代入9-114a还是9-113a]]）得 9.143a；作无量纲代换

```latex
y=x\sqrt{\frac{m\omega}{\hbar}},\qquad \lambda=\frac{2E}{\hbar\omega}   % 9.143b,c（λ 是参数而非波长）
```

化为 [[concepts/韦伯微分方程]] 的简单形式 Ψ″ + (λ−y²)Ψ = 0（9.143d）。再设 Ψ = e^{−y²/2}H(y)（9.144a）得埃尔米特型方程 H″ − 2yH′ + (λ−1)H = 0（9.144c）。

## 量子化：截止条件（9.145–9.146）

幂级数 H = Σaᵢyⁱ 代入得递推公式 (j+2)(j+1)a_{j+2} = [2j−(λ−1)]a_j（9.145c；9.145b 转写疑多乘因子 i，见 [[queries/式9-145b第三和疑多乘因子i]]）。物理解要求波函数平方可积、对大 y 值趋于零：指数因子 e^{−y²/2} 保证这一点，当且仅当 H(y) 截止为多项式——从某个 n 开始 a_j = 0。由递推公式，这等价于

```latex
2n-(\lambda-1)=0,\qquad \lambda=\frac{2E}{\hbar\omega}=2n+1   % 9.146b
```

取 aₙ = 2ⁿ、aₙ₋₁ = 0 即得埃尔米特多项式（9.146c，[[entities/埃尔米特多项式]]）。截止条件为何等价于量子化的完整说明见 [[methodology/谐振子幂级数解与截止条件流程]]。

## 本征函数与等距谱（9.147）

```latex
\Psi_n=N_n\,\mathrm{e}^{-y^{2}/2}H_n(y),\qquad
N_n^{2}=\frac{1}{2^{n}n!}\sqrt{\frac{\alpha}{\pi}},\quad \sqrt{\alpha}=\sqrt{\frac{m\omega}{\hbar}}   % 9.147a,b
E_n=\hbar\omega\Big(n+\frac{1}{2}\Big)\quad(n=0,1,2,\dots)                                          % 9.147c
```

- 能级谱是等距的；n 称振动量子数；+½ 项即零点振动能（见 [[concepts/零点能]]）。
- 图 9.21 展示等距谱、Ψ₀–Ψ₅ 波函数与势能抛物线；抛物线上的点表示经典振子的逆向点（转折点），振幅 a = (1/ω)√(2E/m)。
- 经典-量子对比（9.147d/e）：n=1（E = (3/2)ℏω）时量子最大概率位置 x_max,qu = ±√(ℏ/mω) 在经典转折点 x_max,kl = ±√(3ℏ/mω) 之内，且量子概率在经典禁区非零；大量子数 n 时量子概率密度在均值意义上趋于经典——对应原理。详见 [[comparisons/经典与量子谐振子概率密度比较]]。9.147d 前文的概率密度公式与 λ 记号疑误见 [[queries/式9-147d概率密度疑漏因子λx平方]]、[[queries/谐振子对n等于l疑为n等于1]]。
