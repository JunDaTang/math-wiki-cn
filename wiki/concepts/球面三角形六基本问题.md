# 球面三角形六基本问题

球面三角形六基本问题是按三个已知量的类型对斜球面三角形求解所做的标准分类（[[concepts/球面三角学]] 3.4.3.3），记法中 S 表示边、W 表示角：

| 问题 | 已知 | 存在条件 |
|---|---|---|
| 第一（SSS） | 3 边 a, b, c | 0° < a+b+c < 360°，a+b > c，a+c > b，b+c > a |
| 第二（WWW） | 3 角 α, β, γ | 180° < α+β+γ < 540°，α+β < 180°+γ，α+γ < 180°+β，β+γ < 180°+α |
| 第三（SWS） | 2 边及其夹角 | 无 |
| 第四（WSW） | 1 边及两邻角 | 无 |
| 第五（SSW） | 2 边及其中一边所对之角 | 分情况（歧义分支） |
| 第六（WWS） | 2 角及其中一角所对之边 | 分情况（与 SSW 对偶） |

解法体系（源表 3.9–3.12）包括：边的余弦定律直接求解；**半角/半边公式族**（第一问题用 k 与 tan(α/2)，第二问题用 k′ 与 cot(a/2)，均带检验恒等式）；**纳皮尔类比**（半和半差公式，如第三、四问题的解 3 与第五、六问题的方法 2）；**辅助角法**（第三问题解 2 的 u、第四问题解 2 的 μ、第五六问题方法 1 的 u, v, φ, ψ）；以及用**球面垂线**把斜三角形分解为两个 [[concepts/直角球面三角形]]（问题 3–6）。公式细节见 [[findings/球面六基本问题条件体系与半角半边公式族]]，歧义分支见 [[findings/SSW与WWS歧义分支]]，数值算例（四面体棱间夹角，第二问题解 2）见 [[findings/四面体棱间夹角算例]]。

这是平面三角形四个基本问题（[[findings/一般三角形四个基本问题与SSA分支]]）的球面推广，两者对照见 [[comparisons/平面与球面三角形基本问题比较]]；其与 [[concepts/交会法]] 体系的结合见 [[findings/岸对船定向三步解算链]] 与 [[comparisons/平面交会与球面岸对船定向比较]]。注意：表 3.9–3.12 在本源转写中多处损坏（分数线、括号、编号脱落），损坏文本不应径直记为公式结论，待核定问题集中于 [[queries/表3-9中k撇公式的分数线是否在转写中脱落]] 与 [[queries/表3-10解4与表3-12方法2的错乱是否需据原书核定]]。
