# 第I类三次曲线

第I类三次曲线是手册 2.4.3 对函数

```latex
y = a + b/x + c/x² = (ax² + bx + c)/x²,  b ≠ 0, c ≠ 0    (2.47)
```

的图像的称呼：其隐式方程 x²y = ax² + bx + c 含 x²y 项，为三次代数曲线，故名。

图像要素：

- 两条 [[concepts/渐近线]]：x = 0（垂直，二重极点）与 y = a（水平）；
- 两个分支：一支上 y 在 a 与 +∞（或 −∞）之间单调变化；另一支穿过横坐标呈 **1:2:3 比例**的三个特征点——与渐近线 y = a 的交点 A(−c/b, a)、[[concepts/极值]]点 B(−2c/b, a − b²/(4c))、[[concepts/拐点]] C(−3c/b, a − 2b²/(9c))；
- 分支位置取决于 b、c 的符号，共四种情形（图 2.18）；
- 与 x 轴的交点按 b² − 4ac 分类：a ≠ 0 时为 ((−b ± √(b²−4ac))/(2a), 0)，b²−4ac 大于/等于/小于 0 分别给出两个交点/一个切点（x 轴为切线）/无交点；a = 0 时唯一交点 (−c/b, 0)。

退化情形：b = 0 时化为 y = a + c/x²（[[concepts/倒数幂]]平移型，参见图 2.21）；c = 0 时化为单应函数 y = (ax+b)/x，是 [[concepts/线性分式函数]]（式 2.46）的特例。

口径注意：本小节判交点个数使用标准形式 b² − 4ac，而同节 2.4.4/2.4.5 使用反号的 Δ = 4ac − b²，见 [[queries/2-4节内二次判别式两种符号约定为何并存]]。详见 [[findings/第I类三次曲线的1-2-3三特征点与交点判别]] 与 [[comparisons/三类三次曲线比较]]。
