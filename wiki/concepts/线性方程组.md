# 线性方程组

线性方程组是由 m 个含 n 个未知数 x₁, …, x_n 的线性方程构成的组，矩阵记法为 **A x = a**（式 4.177a–b），其中 A = (a_μν) 为 (m,n) 系数矩阵，a 为常数项列向量（绝对项），x 为未知数列向量。方程个数 m 未必等于未知数个数 n。当 a = 0 时称为齐次方程组，否则称为非齐次方程组；有解（至少存在一个 x = α 使 (4.177a) 成为恒等式）时称为可解的（相容的、协调的），否则称为不相容的。

## 可解性与唯一性

解的存在性与唯一性依赖于[[concepts/增广矩阵]] (A, a) 的秩（式 4.178）：

- rank(A) = rank(A, a) 时至少有一个解；
- 若 r = rank(A) = n，解唯一；
- 若 r < n，有无穷多解，n − r 个未知数的值可作为参数自由选取。

齐次方程组总有平凡解 x = 0（因 rank(A) = rank(A, 0) 恒成立）；当 r < n 时还存在由 n − r 个线性无关非平凡解构成的[[concepts/解的基本系]]，若 r = n 则仅有平凡解。

## 求解途径

源（4.5 节）给出四条途径：

1. [[concepts/选主元法]]：将方程组改写为线性函数组 y = Ax − a 并换轴，解的存在性与唯一性可直接从最终格式读出（式 4.182–4.183）；
2. [[concepts/克拉默法则]]：m = n 且 D = det A ≠ 0 时的显式公式（源断言高维不适用）；
3. [[concepts/高斯消元法]]：将 (A, a) 化为行阶梯形后回代，源推荐的数值解法之一（与选主元法、迭代程序并列，后者见第 1233 页 19.1.1，未入库）；
4. m > n 时的[[concepts/超定线性方程组]]，一般无精确解，转由[[concepts/线性最小二乘问题]]处理。
