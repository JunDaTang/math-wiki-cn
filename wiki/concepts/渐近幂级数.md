# 渐近幂级数

渐近幂级数是按 1/x 的幂展开、用于计算 |x| 较大时函数值的级数；它不要求收敛——即使是发散级数也可用于函数值的计算。其基础是渐近相等概念：若 lim_{x→∞} f(x)/g(x) = 1，即 f(x) = g(x) + o(g(x))，则记 f(x) ~ g(x)（式 7.98a–b）。

## 定义（式 7.99）

```latex
f(x) = \sum_{\nu=0}^{n}\frac{a_\nu}{x^\nu} + O\!\left(\frac{1}{x^{n+1}}\right),\quad n = 0,1,2,\dots
```

若对每个 n 都成立，则称 Σ a_ν/x^ν 为 f 的渐近幂级数，记 f(x) ≈ Σ a_ν/x^ν。其中 O(·) 为[[朗道符号]]「大 O」。

## 性质

- **唯一性**：若 f 的渐近幂级数存在，则唯一；但一个渐近级数并不能唯一确定函数（不同函数可有同一渐近展开）。
- **收敛性**：不要求收敛。

## 两个典型算例（已复算）

- 例 A：e^{1/x} ≈ Σ_{ν=0}^∞ 1/(ν! x^ν)，既是渐近级数，又对满足 |x| > x₀（x₀ > 0）的每个 x 收敛（渐近且收敛）。
- 例 B：f(x) = ∫₀^∞ e^{−xt}/(1+t) dt 经反复分部积分得渐近级数 Σ(−1)^ν ν!/x^{ν+1}（式 7.100），其相邻项比趋于无穷、对每个 x 发散，却完美近似 f：x = 10 时 0.09152 < f(10) < 0.09164。推导流程见 [[渐近展开分部积分流程]]，数值验证见 [[式7-98-7-100渐近幂级数与x10数值验证]]。

与收敛幂级数的系统比较见 [[收敛幂级数与渐近幂级数比较]]。
