# 正凸多边形

正凸多边形是具有 n 条相等的边和 n 个相等的角的凸多边形（《数学手册(原书第10版)》3.1.5.2，图 3.23）。其各边中垂线交于公共中心 M，即内切圆（半径 r）与外接圆（半径 R）的圆心；每条边既是内切圆的切线，又是外接圆的弦——因此正凸多边形对内切圆而言是外切（切线）多边形，对外接圆而言是内接多边形。

## 结构与推导根基

分解一个正凸 n 边形将得到 n 个环绕中心的等腰全等三角形（顶角即中心角 φₙ，底角即 αₙ），这是其全部角量与度量公式的推导根基（见 [[methodology/正多边形中心三角形分解法]]）。

## 角量体系

中心角 φₙ = 360°/n；底角 αₙ = (1 − 2/n)·90°；外角 βₙ = 360°/n；内角 γₙ = 180° − βₙ。两条结构关系值得注意：βₙ = φₙ（外角等于中心角）、γₙ = 2αₙ（内角等于两底角之和）。详见 [[findings/正凸多边形角量体系]]。

## 度量体系

外接圆半径 R、内切圆半径 r、边长 aₙ、周长 U = n·aₙ 与面积 Sₙ 由式 3.51–3.54、3.56 联系（核心关系 R² = r² + aₙ²/4，四种面积表达互相等价），并有倍边、倍面积递推（式 3.55、3.57）。详见 [[findings/正凸多边形半径边长面积公式]]、[[findings/正多边形倍边与倍面积递推]]。
