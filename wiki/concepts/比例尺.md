# 比例尺（比例因子）

比例尺在本源中出现于两个相关语境。

**制图学中的比例尺**（3.2.2.1.3）：比例因子是坐标系 $K_1$ 中的线段 $s_{K_1}$ 关于另一坐标系 $K_2$ 中对应线段 $s_{K_2}$ 之比。设 $m$ 为模数（尺度），$K$ 为地图指标、$N$ 为自然指标，则式 (3.103a)–(3.104b)：

$$M = 1:m = s_K : s_N,\qquad s_{K_1}:s_{K_2} = m_2:m_1$$

$$F_N = F_K m^2,\qquad F_{K_1}:F_{K_2} = m_2^2:m_1^2$$

即**面积按模数的平方换算**。

**坐标变换中的比例因子 q**：局部测量距离与由坐标反算距离之差通过乘因子 q 考虑，q 应非常接近 1（式 3.107a）：

$$q = \frac{\text{计算出的距离}}{\text{测量出的距离}} = \frac{\sqrt{\Delta y_{AB}^2 + \Delta x_{AB}^2}}{s_{AB}}$$

在两坐标系相似变换中 q 亦为整体缩放因子 $q = s_{AB}/s'_{AB}$（3.108c），并以 (3.108i–j) 缩放坐标增量。见 [[findings/比例尺换算公式]]、[[findings/坐标互化与比例因子校正]]、[[findings/两直角坐标系相似变换]]。
