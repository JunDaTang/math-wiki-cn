# 完全码与汉明界

汉明界（球填充界）给出 t-纠错码 C ⊆ GF(2)^n 的规模约束：

```
Σ_{i=0}^{t} C(n,i) · |C| ≤ 2^n
```

直观含义：以每个码字为中心、半径 t 的球（各含 Σ_{i=0}^{t} C(n,i) 个字）在 GF(2)^n 中两两不交，故总字数不超过 2^n。**等号成立时称 C 为 t-完全码**——此时球完美铺满整个空间，冗余的使用达到最优。

## 重复码完全性

数字重复码 C = {00…0, 11…1} ⊆ GF(2)^{2t+1} 是 t-完全码（已复算：|C|·Σ_{i=0}^{t} C(2t+1,i) = 2·2^{2t} = 2^{2t+1} ✓）。见 [[findings/汉明界与重复码完全性]]。
