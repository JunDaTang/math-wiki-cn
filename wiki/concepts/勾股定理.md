# 勾股定理（毕达哥拉斯定理）

勾股定理（本源作「毕达哥拉斯（勾股）定理」）断言：直角三角形两直角边的平方和等于斜边的平方。式 (3.85)：

$$a^2 + b^2 = c^2 \quad (\gamma = 90^\circ)$$

在本源中的位置与联系：

- 属直角三角形基本公式组 (3.83)–(3.87)（见 [[findings/直角三角形基本公式与表3-3定义量]]、[[concepts/直角三角形]]）。
- 是 [[concepts/余弦定律]] (3.90) 在 $\gamma = 90^\circ$ 时的特例（源文即以「一般三角形的毕达哥拉斯定理」称呼余弦定律）。
- 与 [[concepts/欧几里得定理]] (3.86) 同组：由 $a^2 = pc$、$b^2 = qc$ 相加即 $a^2+b^2 = (p+q)c = c^2$，回到勾股定理。
- 弧交会法的第二种解法（将一般三角形分解为两个直角三角形）以此为基础，但源文明言不作讨论（见 [[concepts/弧交会法]]）。
