# 摆线（常见/标准摆线）

**摆线**是当一个圆沿一条直线做无滑动滚动时，圆周上一个固定点所经过的轨迹：它由无穷多个形状相同的拱组成，每拱两端为尖点，周期为 $2\pi a$（$a$ 为滚动圆半径）。在 [[concepts/摆线族|摆线族]] 的两轴分类中，它是滚动基为直线、追踪点位于圆周上（$\lambda = 1$）的基准成员。

## 生成与方程

设 $t$ 为角 $\angle PC_1B$ 的弧度，参数方程为

$$x = a (t - \sin t), \quad y = a (1 - \cos t) \quad (a > 0,\ -\infty < t < \infty),\tag{2.242a}$$

笛卡儿坐标方程为

$$x + \sqrt {y (2 a - y)} = a\,\mathrm{arc}_{k}\cos \frac{a - y}{a} \quad (a > 0,\ k = 0, \pm 1, \pm 2, \dots).\tag{2.242b}$$

其中 $\operatorname{arc}_k\cos$ 为多值反余弦的第 k 支（手册未明说取法，按上下文应为 $2k\pi \pm \arccos$，属解读性注释），参见 [[concepts/主值]] 与 [[concepts/反三角函数]]。

## 几何量

| 量 | 公式 |
|---|---|
| 周期 | $\overline{O_0O_1} = 2\pi a$ |
| 尖点 | $O_k = (2k\pi a,\ 0)$ |
| 最高点 | $A_{k+1} = ((2k+1)\pi a,\ 2a)$ |
| $O_0P$ 弧长 | $L = 8a\sin^2(t/4)$ |
| 单拱长 | $L_{O_0A_1O_1} = 8a$ |
| 单拱面积 | $S = 3\pi a^2$ |
| 曲率半径 | $r = 4a\sin(t/2)$ |
| 最高点处 | $r_A = 4a$（手册称「曲率」，实为曲率半径） |

## 在族中的位置

- 把追踪点移到圆外或圆内（$\lambda \neq 1$）得到 [[concepts/次摆线]]；其面积公式 $S = \pi a^2(2+\lambda^2)$ 与曲率公式在 $\lambda = 1$ 时分别回退为 $3\pi a^2$ 与 $|r| = 4a\sin(t/2)$（符号约定差异见 [[queries/次摆线曲率半径符号约定与2-13-1是否统一]]）。
- 把滚动基换成定圆的外侧或内侧，得到 [[concepts/外摆线]] 与 [[concepts/内摆线]]。
- 完整公式核验记录见 [[findings/标准摆线的方程与几何量]]。
