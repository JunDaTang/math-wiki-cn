# 直线束

直线束（平面束）是过两条给定直线交点 P₀(x₀, y₀) 的全部直线构成的族。本节给出三个等价刻画：

1. **行列式判据**：第三条直线 A₃x + B₃y + C₃ = 0 过前两条直线的交点，当且仅当

```
| A₁  B₁  C₁ |
| A₂  B₂  C₂ |  = 0        (3.312b)
| A₃  B₃  C₃ |
```

2. **束方程**：

```
(A₁x + B₁y + C₁) + λ(A₂x + B₂y + C₂) = 0   (−∞ < λ < +∞)   (3.312c)
```

覆盖过交点 P₀ 的全部直线（第二条直线 A₂x + B₂y + C₂ = 0 本身除外）。

3. **角平分线特例**：若两条基线以[[concepts/黑塞法式]]（法线式）给出，则 λ = ±1 时得到交点处角的平分线方程。

相关公式（交点的克莱姆行列式解 (3.311)、两线夹角 (3.313)）见 [[findings/直线交点直线束与夹角公式]]。
