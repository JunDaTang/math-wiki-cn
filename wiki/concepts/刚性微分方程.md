# 刚性微分方程

包括化学动力学问题在内的许多应用问题可归结为这样的微分方程：其解由递减收敛到零的不同的指数项组成，称为刚性微分方程。例如

```latex
(19.117)  y(x) = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}   (C_i, \lambda_i 为常数)
```

其中 λ₁ < 0、λ₂ < 0 而且 |λ₁| ≪ |λ₂|（例如 λ₁ = −1, λ₂ = −1000）。

源文断言（定性、未给证明）：含 λ₂ 的项对解函数并无显著影响，但在数值方法中影响步长 h 的选取；在这种情况下选取适当的数值方法特别重要（见 [19.29], [19.6]）。

机理关联：快衰减分量要求 h 满足方法的绝对稳定条件（如欧拉法 −2 ⩽ λh ⩽ 0，见 [[concepts/对初值扰动的稳定性与绝对稳定性]]），即使慢分量本身允许大步长。
