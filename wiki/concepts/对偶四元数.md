# 对偶四元数（本书称「八元数」）

对偶四元数是形如 ĥ = h₀ + εh₁ 的数：h₀, h₁ ∈ ℍ 为四元数，ε 是**对偶单位**——ε² = 0 且与每个四元数交换，乘法为通常的四元数乘法按 ε 展开（结合）。它是把四元数的系数扩张到对偶数所得的 8 维代数；其**单位**元素可同时表示 ℝ³ 的旋转与平移，从而刻画刚体运动，并给出刚体运动群 [[entities/SE3]] 的双重覆盖（式 4.171–4.173、表 4.1）。

**术语警示**：《数学手册（原书第10版）》4.4.3.6 把此代数称为**「八元数」**。这可能与 4.4.2 广义数层级（2ⁿ 维，式 4.105a–c）中的八元数——若按通常理解为 Cayley 型八元数（7 个虚单位、非结合的交错代数，见 [[concepts/八元数]]）——发生混淆：两者是**不同的对象**。本页依其结构（ε² = 0）采用标准名称「对偶四元数」（dual quaternion）；术语冲突的裁定见 [[queries/八元数一词双义之疑]]。

## 定义与单位条件

```latex
ĥ = h₀ + ε h₁,    h₀, h₁ ∈ ℍ,   ε² = 0, ε 与每个四元数交换                 (4.171)

ĥ ĥ‾ = (h₀ + ε h₁)(h̄₀ + ε h̄₁) = 1
  ⇔  h₀ h̄₀ = 1  且  h₀ h̄₁ + h₁ h̄₀ = 0                                     (4.172)
```

复核（分析者）：令 u = h₀⁻¹h₁（即 h₁ = h₀u），则 h₀h̄₁ + h₁h̄₀ = h₀(u + ū)h̄₀，故 (4.172) ⟺ h₀ ∈ ℍ₁ 且 u = h₀⁻¹h₁ 为**纯四元数**。(4.173) 中 h₁ = ½t̲r 满足之：h₀⁻¹h₁ = ½r̄t̲r 为纯四元数（纯四元数经单位四元数共轭保持纯性）。

## 刚体运动的表示（表 4.1）

| 元素 | 表示 |
|---|---|
| 空间中点 p̲ = (p_x, p_y, p_z) | p̌ = 1 + p̲ε，其中 p̲ = p_x **i** + p_y **j** + p_z **k** |
| 旋转 | r ∈ ℍ₁，单位四元数 |
| 平移 t̲ = (t_x, t_y, t_z) | 1 + ½ t̲ε，其中 t̲ = t_x **i** + t_y **j** + t_z **k** |

```latex
ĥ = h₀ + h₁ ε = (1 + ½ t̲ ε) r = r + ½ t̲ r ε,    t̲ ∈ ℍ₀, r ∈ ℍ₁        (4.173)
```

平移可加：(1 + ½t̲ε)(1 + ½t′ε) = 1 + ½(t̲ + t′)ε（用 ε² = 0，分析者复核）。

## SE(3) 的双重覆盖

因 ĥ 与 −ĥ 刻画相同的刚体运动（转写中该句的 ±ĥ 符号脱落），单位对偶四元数按 (4.173) 参数化后给出 ℝ³ 刚体运动群 [[entities/SE3]] 的**双重覆盖**（核 {±ĥ}）。勿与 4.4.2 的 S³ → SO(3) 双重覆盖混同：那是单位四元数对**旋转群**的覆盖，此处是对**刚体运动群**的覆盖。

## 缺失内容：点变换作用式

表 4.1 给出点 p̌ = 1 + p̲ε 的表示，但单位对偶四元数**如何作用于点**（旋转的 h a⃗h̄ 型三明治作用如何推广）在转写中完全缺失。标准约定下 p̌′ = ĥ p̌ ĥ̄ᵉ（四元数共轭后再取对偶共轭）给出 p′ = Rp + t̲，与表中 ½ 因子吻合（分析者复核：对偶部分取 αt̲r 时作用产生 2αt̲ 的平移，α = ½ 恰给出 t̲）；但需回查原书确认其写法，见 [[queries/4-4-3-6标题规范化四元数与点变换作用式缺失]]。

## 与克利福德代数的可能联系（分析者推断，非本书明言）

对偶四元数代数同构于偶克利福德代数 Cℓ⁺(3,0,1)（motor 代数）；而 Cayley 型八元数不属于克利福德代数。该线索与 [[queries/八元数是否属克利福德代数特殊情形]] 相关。
