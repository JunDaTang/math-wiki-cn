# C¹ 度量

**C¹ 度量**是本手册为严格化[[concepts/结构稳定性]]定义而引入的向量场（映射）间距离，由「函数值之差的上确界」与「一阶导数（雅可比）之差的上确界」两部分构成（式 17.25）：

```
ρ(f, g) = sup_{x∈U} ‖f(x) − g(x)‖ + sup_{x∈U} ‖Df(x) − Dg(x)‖
```

第一项 ‖·‖ 为向量的欧几里得范数，第二项 ‖·‖ 为算子范数（原文「欧儿里得」系 OCR 讹误）。它把 X¹(U)（U 上全体光滑向量场）与 Diff¹(U)（离散情形的映射空间）装备成度量空间。

## 配套的边界横截内向条件

仅有 C¹ 度量还不够：结构稳定性的定义限定在子空间 X₊¹(U) ⊂ X¹(U)，其元素沿边界 ∂U 横截内向：

- grad h(x)ᵀ f(x) ≠ 0（x ∈ ∂U，其中 ∂U = {x : h(x) = 0}，h 为 C¹ 且 grad h ≠ 0 于 ∂U 邻域）；
- φᵗ(x) ∈ U（x ∈ ∂U, t > 0）。

这保证流不穿出 U、扰动系统与原系统在同一有界区域内比较，是 [[concepts/吸收集]] 思想的强化。离散情形对应 Diff₊¹(U)：满足 φ(Ū) ⊂ U 的微分同胚（原文写作 Diff₊¹(U) ⊂ Diff(U)，右端疑脱上标 1，见 [[queries/Diff¹同胚与微分同胚表述之辨]]）。

## 应用与算例

- 结构稳定 = C¹ 度量球内所有（满足边界条件的）系统彼此拓扑等价/共轭。
- 式 17.26 算例中 ρ(g(·,0), g(·,α)) = |α|(√2+1)：差向量场为 α(x,y)，其欧几里得范数在半径 √2 的边界上取 sup = √2|α|；雅可比之差为 αI，算子范数 |α|。核算流程见 [[methodology/C¹度量距离与边界内向横截核算流程]]，复算见 [[findings/式17-25至17-26C¹度量与平面算例转录复算]]。
