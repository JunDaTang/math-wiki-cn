# 函数的表示形式

多元函数可以像一元函数一样按不同方式定义。《数学手册(原书第10版)》2.18.2.4–2.18.2.5 给出如下形式：

1. **显形式**（式 2.277）：$u = f(x_1, x_2, \cdots, x_n)$，函数值（因变量）由独立变量直接表出。
2. **隐形式**（式 2.278）：$F(x_1, \cdots, x_n, u) = 0$，且有唯一的 $u$ 满足此等式。
3. **参数形式**（式 2.279a–b）：函数和它的 $n$ 个自变量由 $n$ 个新变量（参数）以显形式定义，参数和自变量之间一一对应。二元函数：$x = \varphi(r,s)$、$y = \psi(r,s)$、$u = \chi(r,s)$；三元函数：$x = \varphi(r,s,t)$、$y = \psi(r,s,t)$、$z = \chi(r,s,t)$、$u = \kappa(r,s,t)$。
4. **数表定义**：表的顶部和左侧给出独立变量的值，函数值位于相应行和列的交叉位置，称为复式表；手册以椭圆函数积分数表（21.9，第 1424 页）为例。
5. **分段公式**：用一个或多个公式分段定义，例如按象限分段的四段表示（实为 $|x| + |y|$）。

此外，手册在“函数解析表示的各种形式”名下还列入齐次性（式 2.280），见 [[concepts/齐次函数]]。

参数形式是本 wiki 已收录平面曲线参数方程的一般化框架：[[concepts/摆线]]（式 2.242–2.246）、[[concepts/圆的渐伸线]]（式 2.250）、[[concepts/螺线]]（式 2.247–2.251）等的参数方程即以曲线坐标为参数的显式表示，而式 2.279a 把自变量与函数值一并参数化。详见 [[findings/函数的四种表示形式]]。
