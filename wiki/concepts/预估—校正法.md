# 预估—校正法

预估—校正法是隐式多步法的实用化机制。源文断言：隐式多步法相较于显式多步法有很大的优越性，因为相同精度下隐式法允许大得多的步长；但隐式法通常需要求解非线性方程来得到近似值 y_{i+k}。

**机制**：由 (19.101) 解出

```latex
(19.105)  y_{i+k} = h \sum_{j=0}^{k} \beta_j f_{i+j} - \sum_{j=0}^{k-1} \alpha_j y_{i+j} = F(y_{i+k})
(19.106)  y_{i+k}^{(\mu+1)} = F(y_{i+k}^{(\mu)})   (\mu = 0,1,2,\dots)
```

求解 (19.105) 需要迭代：先按显式公式确定初值 y_{i+k}^{(0)}，称之为预估子；然后用迭代公式校正，称为由隐式法得到的校正子。迭代结构即 [[concepts/一般迭代法]] 的不动点迭代；(19.105) 将 y_{i+k} 的确定化为 [[concepts/零形式与不动点形式]] 的方程——19.1 框架向微分方程数值解语境的延伸。

**两对特殊公式**：

- (19.107a,b)：预估子 y_{i+1}^{(0)} = y_i + (h/12)(5f_{i−2} − 16f_{i−1} + 23f_i)，校正子 y_{i+1}^{(μ+1)} = y_i + (h/12)(−f_{i−1} + 8f_i + 5f_{i+1}^{(μ)})；复算确认为标准 Adams 三阶对。
- (19.108a,b)：预估子 (19.108a) 与辛普森型校正子 (19.108b)（即 [[concepts/米尔恩法则]] 平移指标）。源文明言辛普森公式作为 (19.108b) 中的校正在数值上是不稳定的，可替换为 (19.109)；复算表明 (19.108a) 与 (19.109) 均为四阶格式。
