# 购买问题（库存—采购模型）

购买问题是《数学手册(原书第10版)》18.3.2.1 给出的离散动态规划基本算例（库存—采购模型）：一时间区间分成 $n$ 个周期，第 $j$ 个周期内工场需要某种原材料 $v_j$ 个单位；周期开始时可得到的数量记作 $x_{j-1}$（$x_0=x_a$ 给定）；工场以单位价格 $c_j$ 购买 $u_j$ 个单位，储存容量 $K$ 不可超过（$x_{j-1}+u_j\leqslant K$）。目标是确定购买策略 $(u_1,\dots,u_n)$ 使总费用最小。

## 模型（式 18.127a）

```latex
OF: f(u_1,…,u_n) = Σ_{j=1}^n f_j(u_j) = Σ_{j=1}^n c_j u_j → min!
CT: x_j = x_{j-1} + u_j − v_j,  j = 1(1)n
    x_0 = x_a,  0 ⩽ x_j ⩽ K,  j = 1(1)n
    U_j(x_{j-1}) = {u_j : max{0, v_j − x_{j-1}} ⩽ u_j ⩽ K − x_{j-1}},  j = 1(1)n
```

决策空间的下界 $\max\{0, v_j - x_{j-1}\}$ 保证周期需求得到满足，上界 $K - x_{j-1}$ 保证储存容量不被超过。

## 含储存费的修正（式 18.128）

若每周期还须为单位储存费用 $\ell$ 付费，则第 $j$ 周期的中间费用为 $(x_{j-1}+u_j-v_j/2)\cdot\ell$，修正的费用函数为

$$f(x_0,u_1,\dots,x_{n-1},u_n) = \sum_{j=1}^n \left(c_j u_j + (x_{j-1}+u_j-v_j/2)\cdot\ell\right).$$

## 泛函方程（18.3.6.1）

由模型导出 $\varphi_{n+1}(x_n)=0$ 与

$$\varphi_j(x_{j-1}) = \min_{u_j\in U_j(x_{j-1})} \big(c_j u_j + \varphi_{j+1}(x_{j-1}+u_j-v_j)\big),\quad j=1(1)n$$

（原文式 (18.144) 误印 max，见 [[queries/式18-144疑为min之辨]]；式 (18.142b) 的「$0\leqslant j\leqslant K$」疑脱 $x$，见 [[queries/式18-142b疑脱x之辨]]）。

## 算例与疑点

18.3.6.1 的数值算例（$n=6,K=10,x_a=2$）经全表复算完全可复现，最优策略 $(4,10,1,6,0,3)$、$\varphi_1(2)=75$，见 [[findings/购买问题算例六行φ值表复算]]。叙述称「每个周期结束时购买」，但储存费用公式、容量约束与决策下界三处证据均与「周期开始时购买」一致，疑「结束」为「开始」之误，见 [[queries/18-3全节系统性转写讹误清单]]。与 [[concepts/背包问题（0-1背包）]] 的建模对照见 [[comparisons/购买问题与背包问题建模比较]]。
