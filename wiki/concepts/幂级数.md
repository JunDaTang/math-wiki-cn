# 幂级数

幂级数是各项为常数系数乘以 (x − x₀) 整数次幂的函数项级数，手册称其为「最重要的函数项级数」。形如

```latex
a_0 + a_1 x + a_2 x^2 + \dots + a_n x^n + \dots = \sum_{n=0}^{\infty} a_n x^n          % (7.83a)
a_0 + a_1 (x-x_0) + a_2 (x-x_0)^2 + \dots = \sum_{n=0}^{\infty} a_n (x-x_0)^n          % (7.83b)
```

其中系数 a_i 与展开中心 x₀ 为常数。

## 收敛结构：三情形定理

幂级数的收敛行为只有三种情形（详见 [[式7-83-7-85幂级数收敛半径与算例复算]]）：

1. 仅在 x = x₀ 收敛；
2. 对所有 x 值均收敛；
3. 存在收敛半径 r > 0，使 |x − x₀| < r 时绝对收敛、|x − x₀| > r 时发散；端点 x = x₀ ± r 处须另行检验。

收敛半径的计算见 [[收敛半径]]（式 7.84）；内闭一致收敛性见 [[阿贝尔定理]]。

## 运算与反演

- 和与积（Cauchy 卷积，式 7.86）：收敛幂级数可在公共收敛域内相加、相乘或乘以常因子。
- 方幂与倒数（式 7.87–7.92）：S²、√S、1/√S、1/S、1/S² 的系数公式。
- 商（式 7.93）：由 [[系数比较法]] 推得。
- [[反级数]]（式 7.94）：反函数的级数展开（级数反演）。

全部系数公式已逐系数复算，见 [[式7-86-7-93幂级数运算系数公式复算]]、[[式7-94反级数系数公式复算]]。
