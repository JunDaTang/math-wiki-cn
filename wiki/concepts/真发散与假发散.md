# 真发散与假发散

真发散与假发散是本手册对发散数列的二级分类术语（手册特有，通行教材罕用；属译名／术语问题，可比照 [[queries/施瓦茨交换定理译名问题]]、[[queries/尖点译名与knee角点术语问题]] 的术语类查询惯例）。

**真发散**：发散且极限为 +∞ 或 −∞ 的数列，即 (7.5b) 的情形——随着 n 的无限增加，aₙ 超过任意大的正数 K（K > 0）且一直不会变小（极限 +∞）；或 aₙ 小于任意小的负数 −K（K > 0）且一直不会变大（极限 −∞）。记号见式 (7.7)：lim aₙ = ∞（aₙ > K, ∀ n > n₀）或 lim aₙ = −∞（aₙ < −K, ∀ n > n₀）。

**假发散**：发散但极限不为 ±∞ 的数列（源文：「否则数列称为假发散」）。

判别关键在 (7.5b)/(7.7) 的「一切 n > n₀」量词：只看子列趋势不够，须整列自某项起单向超越任意大的界。

- A、B：趋于 +∞，真发散（源文明示；「趋千」为「趋于」之讹）。
- D：在 1、−1 间振荡，假发散（复算）。
- H：奇项 → +∞、偶项 → −∞，两个方向都不满足「一切 n」条件，假发散（复算）。
- I：奇子列 → −∞ 但偶项恒为 0，不满足 (7.5b)，假发散（复算）。
- J：奇子列 → 3、偶子列 → 13（两个聚点），假发散（复算；印值佐证见 [[queries/例J数列值转写损坏如何复原]]）。

源文假发散例句的字母整体脱漏（「数列 是假发散数列」），D、H、I、J 的归属是复算假说，见 [[queries/假发散例句脱漏字母是哪些]]。三分总表见 [[comparisons/收敛真发散假发散三分比较]]。
