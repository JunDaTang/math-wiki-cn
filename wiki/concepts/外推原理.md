# 外推原理

外推原理是龙贝格方法的理论基础：若被积函数在积分区间上 2m+2 次连续可微，则梯形和的误差有关于 h 的渐近展开 (19.89a)：

$$R(h) = I - T(h) = a_1 h^2 + a_2 h^4 + \dots + a_m h^{2m} + O(h^{2m+2})$$

（系数 $a_1,\dots,a_m$ 为与 h 无关的常数；等价形式 (19.89b) 对 T(h) 写出。）

**机制**：取两个步长的梯形值的线性组合 $T_1(h) = \alpha_1 T(h) + \alpha_2 T(h/2)$ (19.90)，要求 $\alpha_1+\alpha_2 = 1$（保持对 I 的逼近）且 $\alpha_1 + \frac{\alpha_2}{4} = 0$（消去 $h^2$ 项），解得 $\alpha_1 = -\frac{1}{3}$、$\alpha_2 = \frac{4}{3}$，得 (19.91)：

$$T_1(h) = -\tfrac{1}{3}T(h) + \tfrac{4}{3}T(h/2) = T(h/2) + \frac{T(h/2)-T(h)}{3}$$

恰为 k=1 时的外推公式 (19.87)（$4^1-1=3$）；$T_1$ 的 [[concepts/误差阶]] 由 2 提升到 4。对 (19.87) 重复应用该过程，得 $T_{k,i} = I + O(h_i^{2k+2})$ (19.92)：每外推一列消去下一个偶次幂误差项。

源疑点：19.3.4.2 称「当 k = 1 时通过推导 (19.86) 证明之」——外推的推导依据是渐近展开 (19.89)（及 (19.90)/(19.91)），与梯形递归 (19.86) 无直接关系，回指疑讹（[[queries/外推证明回指式19-86疑讹之辨]]）。
