# 多项式

## 定义

**多项式**（多项式函数；原书称「整有理函数」）是最简的代数函数。依据《数学手册(原书第10版)》2.2.1.1（见 [[10-数学手册原书第10版--7-22-初等函数--slrafi]]），它仅对自变量 $x$ 进行加、减、乘法运算（不含除法与开方）得到，一般形式为

$$
y = a_{n} x^{n} + a_{n-1} x^{n-1} + \dots + a_{0}.\tag{2.37}
$$

从构成上看，多项式由变量 $x$ 的非负整数次幂与系数 $a_{0}, \dots, a_{n}$（$a_{n} \neq 0$）经加法与数乘组成，$n$ 称为**次数**；次数为 0 的多项式是**常函数** $y = a$。

## 按次数的分论（2.3 节结构）

《数学手册(原书第10版)》2.3 节即以「多项式」为章名，按次数由低到高讨论其图像：

| 情形 | 页面 | 一般式 | 图像名称 |
|---|---|---|---|
| n = 1 | [[线性函数]] | $y = ax + b$ | 直线 |
| n = 2 | [[二次多项式]] | $y = ax^2 + bx + c$ | 抛物线 |
| n = 3 | [[三次多项式]] | $y = ax^3 + bx^2 + cx + d$ | 三次抛物线 |
| 一般 n | [[n次多项式]] | 式 2.43 | 抛物型 n 次（n 阶）曲线 |
| 仅最高次项 | [[n次抛物线]] | $y = ax^n$ | n 次（n 阶）抛物线 |

2.2.1.1 在式 (2.37) 之下列出的特例——$y = a$ **常函数**、$y = ax + b$ **线性函数**、$y = ax^{2} + bx + c$ **二次函数**——分别对应次数 0、1、2 的情形。

## 在函数分类中的位置

多项式位于代数函数层级（[[代数函数]]）的最底层：

- [[有理函数]]是两个多项式的比值；
- 代数函数定义式 (2.36) 中的系数 $p_0(x), \dots, p_n(x)$ 均为多项式。

## 一般性质（由 2.3.4 归纳）

- 多项式处处连续、无渐近线、无奇点（连续性见 [[初等函数的连续性]]）；
- 极值与拐点个数受次数奇偶约束（系统比较见 [[奇偶次多项式行为比较]]）；
- 多项式方程 $y = 0$ 即 [[代数方程]]，其实根就是曲线与 x 轴交点的横坐标（求解理论见已入库的 1.6 节）。

## 与表达式层的区分

本页讨论函数意义下的多项式；表达式意义下的多项式属于 [[代数式]] 的范畴，两者分层对待、互链区分。
