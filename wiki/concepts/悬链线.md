# 悬链线

**悬链线**（catenary）是一条质地均匀、柔韧但不能伸展的粗链悬挂两端时自然形成的连续曲线，其方程为 $y = a\cosh\frac{x}{a}$（$a>0$），即 [[双曲余弦函数]] 图像的相似变换。在手册体系中它有两个互补的视角：2.9 节（[[双曲函数]]）将其作为双曲余弦的几何载体（函数图像视角）引入；2.15.1 节则从力学定义出发给出全套几何量，并揭示它是 [[曳物线]] 的渐屈线。本页综合两个视角。

## 方程与几何量（式 2.252）

2.15.1 节给出悬链线的一般方程与全套几何量：

```latex
y = a \cosh {\frac {x}{a}} = a \frac {\mathrm{e} ^ {\frac {x}{a}} + \mathrm{e} ^ {- \frac {x}{a}}}{2} (a > 0) \tag{2.252}
```

| 量 | 公式 |
|---|---|
| 顶点 | $A(0, a)$，由参数 $a$ 确定 |
| 对称性 | 关于 $y$ 轴对称 |
| 弧长 $\widehat{AP}$ | $L = a\sinh\frac{x}{a} = a\,\frac{\mathrm{e}^{x/a}-\mathrm{e}^{-x/a}}{2}$ |
| 区域 $OAPM$ 的面积 | $S = aL = a^2\sinh\frac{x}{a}$ |
| 曲率半径 | $r = \frac{y^2}{a} = a\cosh^2\frac{x}{a} = a + \frac{L^2}{a}$ |

其中「面积 = $a\times$ 弧长」（$S = aL$）为原文明示的结构性关系；$r$ 的三种表示等价，顶点处取最小值 $r=a$，随 $|x|$ 增大而增大。全部公式可由方程直接复核，详见 [[悬链线的方程与几何量]]。

## 函数图像视角：2.9 节的记载

2.9 节将悬链线作为双曲余弦的几何载体引入：悬链线即 [[双曲余弦函数]] $y = \cosh x = \frac{\mathrm{e}^{x} + \mathrm{e}^{-x}}{2}$（式 2.167）的图像，亦即上节一般方程取 $a = 1$ 的情形。手册 2.9.2.2 指出，因为该函数表现为一条悬链曲线，因此该曲线也称为悬链线。（「悬链曲线」即自由悬挂的链在其自身重量下自然下垂所呈的形状——此为该名称的通行含义，属可独立核实的背景。）

2.9 节所载要点：

- 为偶函数曲线，关于 $y$ 轴对称。
- 最低点为 $A(0, 1)$（$\cosh$ 在 $x = 0$ 取最小值 1），即一般情形顶点 $A(0, a)$ 在 $a = 1$ 时的位置。
- 曲线恒位于二次抛物线 $y = 1 + \frac{x^2}{2}$ 的上方（两曲线在 $A(0,1)$ 处相切，「上方」含等号；详见下节）。
- 无渐近线。
- 2.9 节前向引用第 139 页 2.15.1 对悬链线的详细讨论（悬链线的物理背景与方程推导）。

## 与顶点密切抛物线的关系

悬链线始终位于抛物线 $y = a + \frac{x^2}{2a}$（图 2.78 虚线）的上方；取 $a = 1$ 时此即 2.9 节所载的 $y = 1 + \frac{x^2}{2}$（图 2.50 虚线），两曲线在 $A(0,1)$ 处相切，「上方」含等号。

分析注记（原文未如此命名）：该抛物线正是悬链线在顶点处的密切抛物线——二者在顶点处 $y(0)=a$、$y'(0)=0$、$y''(0)=\frac{1}{a}$ 三者吻合（二阶切触）；「恒在上方」由 $\cosh u \geq 1 + \frac{u^2}{2}$（仅 $u=0$ 取等）保证。这一相切（二阶切触）关系可作为以二次抛物线逼近悬链线的背景。

## 与曳物线的渐屈线/渐伸线对偶

悬链线是曳物线的渐屈线（曳物线各点曲率中心 C 的轨迹）；反过来，顶点为 $A(0,a)$ 的悬链线，其渐伸线是曳物线。注意这是**成对而非对称**的关系：曳物线不是悬链线的渐屈线。机制：从悬链线顶点 A 展开缠绕线，端点轨迹为 $x = a(t-\tanh t)$、$y = a\,\mathrm{sech}\,t$（曳物线的参数形式，复核所得），且曳物线的曲率半径恒等于对应悬链线弧长。详见 [[曳物线的渐屈线是悬链线]]、[[渐屈线与渐伸线]]；系统对照见 [[悬链线与曳物线比较]]。

## 归属警示

悬链线的曲率半径公式 $r = \frac{y^2}{a}$（此处 $y \geq a$ 为悬链线自身的纵坐标）**不可**转用于曳物线：曳物线的曲率半径为 $r = a\frac{\sqrt{a^2-y^2}}{y}$（其 $y \in (0,a]$ 为曳物线自身的纵坐标），在尖点处趋于 0、沿渐近线趋于无穷——两式同用 $a$、$y$ 记号但所指不同且变化方向相反。
