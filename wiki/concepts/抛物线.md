# 抛物线

抛物线是圆锥曲线之一。按《数学手册(原书第10版)》3.5.2 平面解析几何的表述，抛物线是平面上到给定点（焦点）的距离与到给定直线（准线）的距离相等的点的轨迹，是数值离心率 $e = 1$ 的二次曲线（该数值「1」在转写中脱落，见 [[3-5-2节符号成片脱落与λ转写为入是否为转写丢字]]）。

> [!note] 背景知识
> 抛物线可由平行于圆锥母线的平面截圆锥面得到。此为可独立验证的公共背景知识，非本 wiki 已录入来源所载，此处仅作识别。

在本 wiki 已录入的《数学手册(原书第10版)》材料中，抛物线以三种形式出现：3.5.2 中圆锥曲线意义下的系统讨论（式 3.343–3.352）、二次多项式 $y = ax^2 + bx + c$（式 2.41）的图像（2.3.2），以及方程 $y^2 = ax + b$ 所表示的、关于 $x$ 轴对称的曲线（2.5.1）。下文按「圆锥曲线视角」与「函数图像视角」两种口径分别整理。

## 圆锥曲线视角（3.5.2）

原书在 3.5.2.10（原文第 275 页）载有抛物线在圆锥曲线意义下更详尽、系统的讨论；已录入的要素与公式体系如下。

### 要素

顶点 $O$（原点）、焦点 $F$（在 $x$ 轴上、距原点 $p/2$）、准线 $NN'$（与焦点相对一侧、距原点 $p/2$、垂直于轴）、半焦弦 $p$（过焦点与轴垂直的弦长的一半）。

### 公式体系（式 3.343–3.352，标准位置）

- **方程**：$y^2 = 2px$（3.343）；竖轴式 $y = ax^2 + bx + c$，其中 $p = \dfrac{1}{2|a|}$，$a>0$ 开口朝上、$a<0$ 朝下，顶点 $\left(-\dfrac{b}{2a},\ \dfrac{4ac-b^2}{4a}\right)$（3.344，复算成立）
- **定义性质**：$PF = PK = x + \dfrac{p}{2}$（3.345）
- **直径**：平行于轴的直线 $y = \dfrac{p}{k}$（$k$ 为被平分弦的斜率，3.346；这是抛物线版的「共轭直径」结构，见 [[共轭直径]]）
- **切线**：$yy_0 = p(x + x_0)$（3.347）；切线与法线是焦点径向量与直径所夹角的平分线；**顶点切线平分切线段**：$TS = SP$、$TO = OM = x_0$、$TF = FP$（3.348，三式均复算验证成立）
- **切线判别**：$p = 2bk$（3.349，判别式复算成立）
- **曲率半径**：$R = \dfrac{(p+2x_0)^{3/2}}{\sqrt{p}} = \dfrac{p}{\sin^3 u} = \dfrac{l_n^3}{p^2}$（3.350a，等价性已验证；$l_n$ 为法线长）；顶点处 $R = p$（3.350b）
- **面积**：弓形 $OPN$ = 平行四边形 $MQNP$ 的 $2/3$（3.351a）；曲线下面积 $S_{OPR} = \dfrac{2xy}{3}$（3.351b，积分验证成立）
- **弧长**：$l_{OP} = \dfrac{p}{2}\left[\sqrt{\dfrac{2x}{p}\left(1+\dfrac{2x}{p}\right)} + \ln\left(\sqrt{\dfrac{2x}{p}} + \sqrt{1+\dfrac{2x}{p}}\right)\right]$（3.352a，独立推导验证成立）；近似式 $l_{OP} \approx y\left[1 + \dfrac{2}{3}\left(\dfrac{x}{y}\right)^2 - \dfrac{2}{5}\left(\dfrac{x}{y}\right)^4\right]$（3.352c）。与椭圆、双曲线不同，抛物线弧长**初等可积**。

详见 [[抛物线理论公式组]] 与 [[抛物线面积弧长公式]]。

## 函数图像视角：二次多项式的图像（2.3.2）

《数学手册(原书第10版)》2.3.2 仅从**函数图像视角**使用抛物线：抛物线是二次多项式

$$
y = ax^2 + bx + c \tag{2.41}
$$

的图像，即一条以 $x = -\dfrac{b}{2a}$ 为垂直对称轴、顶点（极值点）在 $\left(-\dfrac{b}{2a},\ \dfrac{4ac - b^2}{4a}\right)$ 的曲线（详见 [[二次多项式]] 与 [[二次多项式的抛物线要素与判别式三分类]]）。

抛物线与 $x$ 轴交点的横坐标即相应 [[二次方程]] 的根，交点个数由判别式 $b^2 - 4ac$ 三分类决定。

式 3.344（见上节）在圆锥曲线视角下处理同一「竖轴式」，并给出半焦弦 $p = \dfrac{1}{2|a|}$。

## $y^2 = ax + b$ 的形式（2.5.1）

在《数学手册(原书第10版)》2.5.1 中，抛物线以方程 $y^2 = ax + b$ 的形式出现：线性二项式平方根的联立曲线

$$
y = \pm \sqrt {a x + b} \quad (a \neq 0)\tag{2.51}
$$

两边平方即得 $y^2 = ax + b$，这是关于 $x$ 轴对称的一条抛物线。

- **顶点**：$A\left(-\dfrac{b}{a},\, 0\right)$（对 $a>0$ 与 $a<0$ 两种情形均适用；图2.22 中分别标注为 $A$ 与 $A'$）；
- **半焦弦**：$p = \dfrac{a}{2}$（有符号约定：$a<0$ 时 $p$ 取负值，与部分教材取正的约定不同）；
- **开口方向与定义域**：$a>0$ 时开口向右，定义域为 $x \ge -\dfrac{b}{a}$；$a<0$ 时开口向左，定义域为 $x \le -\dfrac{b}{a}$。

## 命名延伸

更高次多项式的图像也沿「抛物线」命名：

- [[n次抛物线]]：$y = ax^n$ 的图像沿「抛物线」命名（n 次或 n 阶抛物线）；
- 三次抛物线：三次多项式的图像（[[三次多项式]]）；
- 抛物型 n 次（n 阶）曲线：一般 [[n次多项式]] 图像的名称。

## 相关概念

- [[椭圆]]、[[双曲线]]：另外两类圆锥曲线，在 2.5.2 中作为二次多项式平方根的曲线出现。
