# 伯恩斯坦多项式

伯恩斯坦多项式是定义在 [0,1] 上的多项式族 (19.252)，以冠名者 [[entities/伯恩斯坦]] 命名，是曲线曲面 B-B 表示（[[concepts/伯恩斯坦-贝济埃表示]]）的基函数。

```latex
(19.252)  B_{i,n}(t) = C(n,i) t^i (1−t)^{n−i}   (i = 0, 1, …, n)
(19.253)  0 ⩽ B_{i,n}(t) ⩽ 1,   0 ⩽ t ⩽ 1      （非负性）
(19.254)  Σ_{i=0}^{n} B_{i,n}(t) = 1            （单位分解；由二项式定理直接得到，原书回指第 14 页 1.1.6.4）
```

## 原书两例

- 例 A：B_{0,1}(t) = 1−t，B_{1,1}(t) = t（图 19.12）
- 例 B：B_{0,3} = (1−t)³，B_{1,3} = 3t(1−t)²，B_{2,3} = 3t²(1−t)，B_{3,3} = t³（图 19.13；原文 B_{2,3} 与 B_{3,3} 两式间脱分隔符）

## 作用与特点

由 (19.253)(19.254)，B-B 曲线 (19.257) 成为控制多边形顶点的「变量凸组合」。但伯恩斯坦基在 (0,1) 内恒正（全局支撑），导致 B-B 曲面 (19.258) 中每个格点的影响是全局的——这是原书建议改用 B 样条（[[concepts/B样条（基样条）]]）的根据。

与既有维基中的 [[concepts/切比雪夫多项式]]、[[concepts/勒让德多项式]] 等以正交性为要点的多项式族不同，伯恩斯坦多项式的要点是非负性与单位分解。

全部性质的复算验证见 [[findings/式19-252至19-258伯恩斯坦多项式与B-B表示转录复算]]。
