# 麦克劳林级数

麦克劳林级数是泰勒级数在展开点 a = 0 时的特例：函数 f(x) 在原点处的幂级数展开式（式 7.97a）。手册指出，最重要的初等函数幂级数展开式（通常可由泰勒展开式得到）汇集于第 1373 页表 21.5（未入库）。

## 公式与余项（式 7.97）

```latex
f(x) = f(0) + \frac{x}{1!}f'(0) + \frac{x^2}{2!}f''(0) + \dots + \frac{x^n}{n!}f^{(n)}(0) + \dots   % (7.97a)
R_n = \frac{x^{n+1}}{(n+1)!}f^{(n+1)}(\Theta x)\quad(0<\Theta<1)                                    % (7.97b) 拉格朗日余项
R_n = \frac{1}{n!}\int_0^x (x-t)^n f^{(n+1)}(t)\,\mathrm{d}t                                         % (7.97c) 积分余项
```

余项估计 (7.97b) 正是一致收敛算例 [[式7-79ex级数有界区间一致收敛算例]] 的工具（e^x 级数的 |S − S_n| = |x^{n+1}e^{Θx}/(n+1)!|）。

## 收敛到 f 的条件

麦克劳林级数收敛且等于 f 要求余项 R_n → 0；仅确定收敛半径不够。著名反例（已复算）：f(x) = exp(−1/x²)（x ≠ 0；f(0) = 0）在原点各阶导数全为 0，麦克劳林级数各项全为 0，故 S(x) = 0 ≠ f(x)，见 [[e负x平方分之一麦克劳林级数反例]]。
