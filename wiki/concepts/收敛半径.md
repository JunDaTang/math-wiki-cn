# 收敛半径

收敛半径是刻画幂级数收敛结构的特征数 r：当 |x − x₀| < r 时级数绝对收敛，当 |x − x₀| > r 时发散（式 7.83–7.84 与图 7.1）。它是三情形定理中「非平凡情形」的分界半径，端点 x = x₀ ± r 处的收敛性须逐点另行检验。

## 计算公式（式 7.84）

```latex
r = \lim_{n\to\infty}\left|\frac{a_n}{a_{n+1}}\right| \quad\text{或}\quad r = \frac{1}{\lim_{n\to\infty}\sqrt[n]{|a_n|}}
```

即比值极限与根值极限两种形式。若这些极限不存在，须改用上极限代替通常的极限（本源此处转写损坏为「面面」，出处引文「参见 [7.8] 卷」亦损坏，复原追踪见 [[上极限与文献7-8卷句如何复原]]）。

## 算例（式 7.85，已复算）

级数 1 + x/1 + x²/2 + ⋯ + xⁿ/n + ⋯（系数 a_n = 1/n）：r = lim (n+1)/n = 1；−1 < x < 1 绝对收敛；x = −1 条件收敛（交错级数，回指级数 7.34）；x = 1 发散（调和级数 7.16）。据此由 [[阿贝尔定理]]，对任意 0 < r₁ < 1，级数在 [−r₁, r₁] 上一致收敛。
