# 线性最小二乘问题

线性最小二乘问题（第 19.2 节又称**线性拟合问题**）源于超定线性方程组 A x = b（m > n）：确定 x，使残差的平方和极小。《数学手册（原书第 10 版）》在第 4.5 节（线性方程组）与第 19.2 节（方程组的数值解）两处论述该问题，分别采用向量形式与分量形式。

## 问题形式

### 向量形式（第 4.5 节，式 4.187–4.189）

对超定线性方程组 A x = b（m > n，式 4.187，见 [[超定线性方程组]]），确定 x 使残差平方和极小（式 4.189）：

```
Σᵢ rᵢ² = rᵀr = (Ax − b)ᵀ(Ax − b) = min!                              (4.189)
```

其中 r = Ax − b（式 4.188）为**残差向量**；残差向量的模 ‖r‖ = √(rᵀr) 称为**残差**。若考虑欧氏模（见 [[范数]]），则即要求残差平方和极小。

### 分量形式（第 19.2 节，式 19.37–19.40）

超定方程组（19.37–19.38，m > n）中，A 为 (m×n) 矩阵且满秩为 n（即列线性无关）。由于超定方程组通常无解，以**误差方程组**代替原方程：

$$r_i = \sum_{k=1}^{n} a_{ik}x_k - b_i\quad (i=1,\dots,m;\ m>n), \tag{19.39}$$

其中 r_i 为**残量**，并使其平方和最小：

$$\sum_{i=1}^{m} r_i^2 = \sum_{i=1}^{m}\Big[\sum_{k=1}^{n}a_{ik}x_k - b_i\Big]^2 = F(x_1,\dots,x_n) = \min! \tag{19.40}$$

## 解的刻画与正规方程组

解可由两条途径刻画，均导出正规方程组：

- **正交性条件（第 4.5 节）**：若残差向量与 A 的每一列正交，则 x 是 (4.189) 的解，由此得[[正规方程组与高斯变换]] AᵀA x = Aᵀb（式 4.190）。
- **极值必要条件（第 19.2 节）**：使 F 最小的必要条件为 ∂F/∂x_k = 0（k = 1..n，19.41），由此导出线性方程组——[[正规方程与高斯变换]]（19.42）。

## 数值求解

第 4.5 节给出的数值解建议（4.5.3.2）：

- **正规方程组路径**：用 [[楚列斯基方法]] 解正规方程组。该路径数值上相当不稳定，但在大残差 ‖r‖ 与小解 ‖x‖ 的情形实施尚可。
- **正交化路径（推荐）**：推荐基于 A = QR 的正交化方法，即 [[豪斯霍尔德方法]]。第 19.2 节亦给出数值上更稳健的另一条路线——[[QR分解与正交化方法]]。
- **秩亏情形**：秩亏时转用 [[正则化问题]]。

相关比较见 [[楚列斯基与豪斯霍尔德方法比较]]、[[正规方程法与正交化方法比较]]；详见 [[最小二乘与正规方程]]、[[正则化与数值方法建议]]。
