# 曲面的面积微元

曲面的面积微元 $\mathrm{d}S$ 是曲面上无穷小面积的度量，是 [[concepts/第一类曲面积分]] 的积分微元；它把 [[concepts/微元法]] 从平面区域延拓到曲面。《数学手册(原书第10版)》8.5.1.2 第 3 条以「表 8.12 曲面面积微元」给出四种坐标下的形式：

| 坐标 | 面积微元 |
|---|---|
| 笛卡儿坐标 $x, y, z = z(x,y)$ | $\mathrm{d}S = \sqrt{1 + \left( \frac{\partial z}{\partial x} \right)^2 + \left( \frac{\partial z}{\partial y} \right)^2}\,\mathrm{d}x\,\mathrm{d}y$ |
| 柱面侧面，$R$（常数，半径），坐标 $\varphi, z$ | $\mathrm{d}S = R\,\mathrm{d}\varphi\,\mathrm{d}z$ |
| 球面 $R$（常数，半径），坐标 $\vartheta, \varphi$ | $\mathrm{d}S = R^2 \sin\vartheta\,\mathrm{d}\vartheta\,\mathrm{d}\varphi$ |
| 任意曲线坐标 $u, v$（$E, F, G$ 参见 354 页弧微分） | $\mathrm{d}S = \sqrt{EG - F^2}\,\mathrm{d}u\,\mathrm{d}v$ |

出处与逐行复算（四行均确认无误 ✓）→ [[findings/表8-12曲面面积微元逐字转录与复算]]。注意：源文该表标题脱「表」字作「8.12」，且与文献引用 [8.12] 撞号。

## 与其他页面的衔接

- 显式形式 $\sqrt{1+z_x^2+z_y^2}\,\mathrm{d}x\,\mathrm{d}y$ 即式 8.150a 的根号因子；参数形式 $\sqrt{EG-F^2}\,\mathrm{d}u\,\mathrm{d}v$ 即式 8.151c，其中 $E,F,G$ 为 [[concepts/第一基本形式]] 的系数（源回指 354 页弧微分，衔接 [[concepts/弧长与弧微分]]）。
- 柱面微元 $R\,\mathrm{d}\varphi\,\mathrm{d}z$ 与球面微元 $R^2\sin\vartheta\,\mathrm{d}\vartheta\,\mathrm{d}\varphi$ 与 [[concepts/旋转曲面的面积]]（8.2.2 遗产）中的旋转侧面计算同源。
- $\mathrm{d}S$ 恒为正、与定向无关——这是第一类积分与第二类积分所用有向投影的本质区别 → [[comparisons/三类曲面积分比较]]。
