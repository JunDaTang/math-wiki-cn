# 线性代换密码

线性代换密码是本源 5.5.4.2 给出的单一字母代换密码：设 A = {a₀, a₁, …, a_{n−1}} 为字母表，k, s ∈ {0, 1, …, n−1} 且 gcd(k, n) = 1，将每个字母 a_i 映为

```
t_s^k(a_i) = a_{ki+s}   （ki+s 按模 n 约化；原文印作 a_{ki+1}，「1」疑为「s」之讹）
```

的置换 t_s^k 称为线性代换密码。条件 gcd(k, n) = 1 保证 k 在模 n 下可逆（k ∈ ℤₙˣ，见 [[entities/互素剩余类群zmx]]），从而 t_s^k 是 A 上的双射。

## 计数

存在 n·φ(n) 个线性代换密码（n 个移位参数 s × φ(n) 个可逆斜率 k，用 [[concepts/欧拉函数]]）；ℤ₂₆ 上为 26·φ(26) = 26·12 = 312 个（已核）。见 [[findings/线性代换密码计数与凯撒特例]]。

## 特例：移位密码与凯撒密码

- **移位密码**：k = 1 的线性代换密码（原文「移位密码是 = 的线性代换密码」脱落「k = 1」），即纯移位 a_i ↦ a_{i+s}。
- **凯撒密码**：s = 3 的移位密码；尤利乌斯·凯撒 (Julius Caesar, 公元前 100 年—前 44 年) 使用过，故得名。

## 弱点

线性代换是单一字母（单表）代换：同一明文字母总映射为同一密文字母，故给定足够长密文即可被 [[concepts/频率分析]] 破译。多字母化的方向是 [[entities/vigenere密码]] 与 [[entities/hill密码]]（对照见 [[comparisons/单一字母与多字母代换密码比较]]）。
