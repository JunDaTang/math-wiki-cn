# 模糊蕴涵（IF THEN 法则）

**模糊蕴涵**是 [[concepts/模糊推理]] 的基本单元。在最简单的情形，模糊蕴涵含有一个 **IF THEN 法则**：

- **IF 部分**称为**前提**，并且表示条件；
- **THEN 部分**是**结论**。

## 计算规定（式 5.380）

```
μ₂ = μ₁ ∘ R        (5.380)
```

μ₂ 是 μ₁ 在模糊关系 R 下的**模糊推理象**，即对于 IF THEN 法则（或对于一组法则）的计算规定。
