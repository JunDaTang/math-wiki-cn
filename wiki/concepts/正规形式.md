# 正规形式

**正规形式**（normal form）指分岔的约化方程经含参非线性坐标变换后化为的多项式右端标准形态；变换保持所考虑平衡点附近相图的拓扑结构不变。**正规形式无法被唯一决定**：一般来讲，一个分岔能被不同的正规形式等价地描述。

## 本节给出的正规形式

| 分岔 | 正规形式 | 编号 |
|---|---|---|
| 鞍结点 | ẋ = α ± x² + … | (17.70) |
| 跨临界 | ẋ = αx − x²（截尾） | — |
| 霍普夫 | ṙ = α′(0)εr + a(0)r³ | (17.73) |
| 尖点 | ẋ = α₁ + α₂x + sign(l₃)x³ | (17.76) |
| 波格丹诺夫—塔肯斯 | ẋ = y, ẏ = α₁ + α₂x + x² − xy | (17.77) |
| 广义霍普夫 | ṙ = ε₁r + ε₂r³ − r⁵ | — |
| 对称破缺例 | ẋ = εx − x³ | — |
| 映射鞍结点 | x ↦ α + x ± x² | (17.81) |
| flip | x ↦ (−1+α)x + x³ | (17.82) |
| Neimark-Sacker | (r,ϑ) ↦ (|ρ(ε)|r + a(ε)r³, ϑ+ω(ε)+b(ε)r²) | (17.86) |

截尾正规形式由系数函数的泰勒展开得到（如 (17.73) 由 (17.72)），其合法性由相应非退化条件（如鞍结点的 ∂²F/∂x²(0,0)≠0、∂F/∂ε(0,0)≠0）保证；各形式的比较见 [[余维一平衡点分岔正规形式比较]]。
