# 有限级数

有限级数是有限个被加数（称为级数的项）相加得到的和式。依《数学手册(原书第10版)》1.2.1（式 1.51）：

$$s_n = a_0 + a_1 + a_2 + \dots + a_n = \sum_{i=0}^{n} a_i$$

其中项 $a_i$（$i = 0, 1, 2, \dots, n$）由一定的公式给出，它们是数。

## 术语辨析

本手册将"级数"用作"和式"的同义词：有限级数指有限和，等差级数/等比级数分别指等差数列/等比数列的求和结果（级数 = 和式，数列 = 项的序列）。这与中文数学教材的常见用法存在张力——后者通常把"级数"保留给无穷级数。手册在其 7.2.1.1 节（未入库）讨论无穷级数；该节入库后需回头统一处理这一术语差异，必要时建立"数列 vs 级数"的对比或辨析页。

## 主要类别

- [[concepts/等差级数]]：一阶（相邻项差为常数 $d$）或 k 阶（k 阶差分为常数），见 [[concepts/差分]]。
- [[concepts/等比级数]]：相邻项比值为常数 $q$。
- [[concepts/幂和公式]]：自然数（或正奇数）各次幂之和等特殊有限级数的闭式目录。

## 记号与关联

本定义直接使用 [[concepts/求和号]] $\sum$。[[concepts/均值]] 以有限级数定义：算术均值是项的有限和取平均，调和均值是倒数的算术均值的倒数。
