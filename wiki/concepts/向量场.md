# 向量场

如果对于空间一个子集的每个点 $P$ 都指定一个向量 $\vec{V}$，则记为

$$\vec{V} = \vec{V}(P), \tag{13.12a}$$

并称其为一个**向量场**（vector field，向量点函数）。运动中流体的速度场、力场、磁强度场和电强度场都是向量场的例子。写为

$$\vec{V} = \vec{V}(\vec{r}), \tag{13.12b}$$

其中 $\vec{r}$ 是具有给定极点的点 $P$ 的位置向量。如果 $\vec{r}$ 以及 $\vec{V}$ 的所有值都位于一个平面中，则称此场为**平面向量场**（原书 3.5.2，未入库）。

## 特殊情形

- [[中心向量场与球面向量场]]（含牛顿力场、库仑力场及圆场）；
- [[柱面向量场]]。

## 坐标表示

向量场可由标量场 $V_1(\vec{r}), V_2(\vec{r}), V_3(\vec{r})$（坐标函数）定义，即 $\vec{V}$ 分解为任意三个非共面基向量的系数：

$$\vec{V} = V_1\vec{e}_1 + V_2\vec{e}_2 + V_3\vec{e}_3. \tag{13.16a}$$

笛卡儿坐标系：

$$\vec{V} = V_x(x,y,z)\,\vec{i} + V_y(x,y,z)\,\vec{j} + V_z(x,y,z)\,\vec{k}. \tag{13.16b}$$

即借助三个标量变量的三个标量函数定义向量场。柱面与球面坐标系中，坐标单位向量

$$\vec{e}_\rho,\ \vec{e}_\varphi,\ \vec{e}_z\,(=\vec{k})\quad\text{和}\quad \vec{e}_r\left(=\frac{\vec{r}}{r}\right),\ \vec{e}_\vartheta,\ \vec{e}_\varphi \tag{13.17a}$$

在各点处切于坐标线，且按此次序总是构成右手坐标系；系数表示为相应坐标的函数：

$$\vec{V} = V_\rho(\rho,\varphi,z)\,\vec{e}_\rho + V_\varphi(\rho,\varphi,z)\,\vec{e}_\varphi + V_z(\rho,\varphi,z)\,\vec{e}_z, \tag{13.17b}$$

$$\vec{V} = V_r(r,\vartheta,\varphi)\,\vec{e}_r + V_\varphi(r,\vartheta,\varphi)\,\vec{e}_\varphi + V_\vartheta(r,\vartheta,\varphi)\,\vec{e}_\vartheta. \tag{13.17c}$$

**关键性质**：从一点转移到另一点时，曲线坐标系的坐标单位向量改变其方向，但仍保持相互垂直（见 [[笛卡儿柱面与球面坐标系向量分量表示比较]]）。因此三系分量的换算须按点进行，操作流程见 [[向量分量坐标系变换流程]]。

向量场的几何刻画是[[向量线]]；与[[标量场]]的系统对照见 [[标量场与向量场比较]]。
