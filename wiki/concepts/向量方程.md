# 向量方程

**向量方程**是以向量 $\vec x$ 为未知量（或以标量 $x,y,z$ 为未知量）的方程。源文表 3.17 概括了八类最简向量方程及其解（$\vec a,\vec b,\vec c,\vec d$ 为已知向量，$\alpha,\beta,\gamma$ 为已知标量）：

| 方程 | 解 |
|---|---|
| (1) $\vec x+\vec a=\vec b$ | $\vec x=\vec b-\vec a$ |
| (2) $\alpha\vec x=\vec a$ | $\vec x=\vec a/\alpha$ |
| (3) $\vec x\vec a=\alpha$ | 不定方程；解的终点构成垂直于 $\vec a$ 的平面——**平面的向量方程** |
| (4) $\vec x\times\vec a=\vec b$（$\vec b\perp\vec a$） | 不定方程；解的终点构成平行于 $\vec a$ 的直线——**直线的向量方程** |
| (5) (3) 与 (4) 联立 | $\vec x=\dfrac{\alpha\vec a+\vec a\times\vec b}{a^{2}}$（$a=\lvert\vec a\rvert$，唯一解） |
| (6) $\vec x\vec a=\alpha$，$\vec x\vec b=\beta$，$\vec x\vec c=\gamma$ | $\vec x=\alpha\tilde{\vec a}+\beta\tilde{\vec b}+\gamma\tilde{\vec c}$（[[concepts/互反基向量]]） |
| (7) $\vec d=x\vec a+y\vec b+z\vec c$ | [[concepts/混合积]] 之比给出 $x,y,z$ |
| (8) $\vec d=x(\vec b\times\vec c)+y(\vec c\times\vec a)+z(\vec a\times\vec b)$ | 混合积（点积）之比给出 $x,y,z$ |

完整公式与重算验证见 [[findings/向量方程解集八类]]；求解范式见 [[methodology/向量方程求解流程]]。其中平面与直线的向量方程（(3)(4)）将在 3.5.3.10 空间解析几何中展开（源文前向引用，该节尚未入库）。
