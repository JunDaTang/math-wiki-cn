# 正切函数

正切函数是六种[[concepts/三角函数]]之一：

$$y = \tan x \tag{2.68}$$

周期 $T = \pi$，渐近线为 $x = \left(k + \frac{1}{2}\right)\pi$（k = 0, ±1, ±2, …）。

## 性质

- 在每个区间 $\left(-\frac{\pi}{2}+k\pi,\ +\frac{\pi}{2}+k\pi\right)$ 内严格单调递增，取值由 −∞ 到 +∞（值域 ℝ）；
- 与 x 轴交点 $A_k = (k\pi, 0)$（k = 0, ±1, ±2, …），均为[[concepts/拐点]]，切线倾斜角为 $\frac{\pi}{4}$（斜率 +1）；
- 渐近线 $x = \left(k+\frac{1}{2}\right)\pi$ 是 [[concepts/无穷间断点]]（[[concepts/极点]]），属 [[concepts/渐近线]] 概念页的竖直渐近线情形。
