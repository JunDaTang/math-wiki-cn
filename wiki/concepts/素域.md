# 素域

素域是没有真子域的域；每个域都含有一个最小的子域，即它的素域。素域由域的特征（[[concepts/环的特征]]）完全决定。

## 分类

除同构外，素域只有两类：

- $\mathbb{Q}$——特征 0 的域的素域；
- $\mathbb{Z}_p$（p 是素数）——特征 p 的域的素域。

（源文作「单素域」，疑为「唯一的素域」之译误，见 [[queries/5-3-7全节系统性转写讹误清单]]。）

## 与有限域的联系

GF(p) = ℤ_p 是素域（见 [[entities/剩余类环zn]]）；GF(pⁿ) 是 ℤ_p 的 n 次扩张（见 [[entities/伽罗瓦域gf-pn]]、[[concepts/域扩张]]）。
