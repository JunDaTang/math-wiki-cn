# Lerp（线性插值）

Lerp（linear interpolation，线性插值；书中拆解为「线性 (l) 插值 (erp)」）是把欧氏空间的线性插值直接类推到四元数的最简单插值算法：对单位四元数 p, q ∈ ℍ₁ 与参数 t ∈ [0,1]，直接取 ℝ⁴ 中连接 p、q 的线段上的点。它是《数学手册（原书第10版）》4.4.3.1 的基准算法，也是理解 [[concepts/Slerp]]（为修正其缺陷而设计）的出发点。

## 公式

```latex
Lerp(p, q, t) = p(1 - t) + q t                                             (4.143)
```

## 性质与缺陷

- 所得点位于 ℝ⁴ 中连接 p ∈ ℍ₁ ∼ S³ 与 q ∈ ℍ₁ ∼ S³ 的**线段**上，该线段在单位球内部，不表示单位球面上的任何连通曲线，因而**不是单位四元数**；旋转须由所求四元数的**规范化**（归一化）确定。
- 归一化后所得单位四元数**不是等距四元数**：插值点在球面上非等距分布，即随 t 变化的角速度不均匀。书称该简单算法「几乎是完美的」，仅此一问题。

## 归属边界

「插值点非等距」的缺陷属于 **Lerp＋归一化**，不属于 Slerp；端点区间未定义的问题属于 [[concepts/Squad]]；最短连接条件属于 [[concepts/Slerp]]——三者不可互相转移。图 4.5(a) 展示 Lerp，与图 4.5(b) 的 Slerp 对照，见 [[comparisons/Lerp与Slerp比较]] 与 [[findings/Lerp与Slerp公式组及等价性证明]]。
