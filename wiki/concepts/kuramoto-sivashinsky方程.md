# Kuramoto-Sivashinsky 方程 (KS)

**Kuramoto-Sivashinsky 方程**（KS）在 9.2.5.1.4 中与复金兹堡—兰道方程并列为描述周期模式与非线性波现象的重要方程例子：

```latex
u_t + u_{xx} + u_{xxxx} + u_x^2 = 0        (9.152)
```

它是**非线性耗散方程**：与无耗散的 KdV、NLS、SG 诸方程不同，(9.151) 与 (9.152) 除了时空周期解外，还有时空无序（混沌）解——时空模式或结构的出现是变成混沌的特征。其非线性项 u_x² 正是 9.2.5.1(6) 所列非线性项之一（该处枚举疑漏「(9.151)、(9.152)」，见 [[queries/9-2-5全节系统性转写讹误清单]]）。

式 (9.152) 经与标准 KS 方程对照核验一致（[[findings/式9-148至9-152五大典型方程与保守耗散二分转录]]）。相关：[[concepts/周期模式与耗散结构]]、[[concepts/金兹堡-兰道方程]]。
