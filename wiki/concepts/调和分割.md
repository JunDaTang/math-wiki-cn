# 调和分割

调和分割是一个线段的内分与外分具有相同绝对值 |λ| 时所产生的分割：设 Pᵢ、Pₐ 分别为内分点与外分点，λᵢ、λₐ 为内分比与外分比，则

```
P₁Pᵢ/PᵢP₂ = λᵢ = P₁Pₐ/PₐP₂ = −λₐ   (3.295a)
即  λᵢ + λₐ = 0                     (3.295b)
```

若 M 是线段 P₁P₂ 的中点、|MP₁| = b，Pᵢ、Pₐ 与 M 的（带符号）距离为 xᵢ、xₐ，则

```
(b + xᵢ)/(b − xᵢ) = (xₐ + b)/(xᵢ − b)，或 xᵢ/b = b/xₐ，即 xᵢ·xₐ = b²   (3.296)
```

（(3.296) 中间式的分母「xᵢ − b」疑为「xₐ − b」之转写讹误，见 [[queries/双曲线小节疑似讹误清单]]。）

名称来自**调和平均**：线段 P₁Pᵢ = p 与 P₁Pₐ = q 的调和平均 r = 2pq/(p+q) = 2b（(3.297)，与原书 1.67b 一致，前向引用第 25 页）。原书图 3.131 以 λ = 5:1 展示调和分割，并称「与图 3.14 类似」（图号存疑）。推导与验证见 [[findings/调和分割公式组]]。相邻主题：[[concepts/定比分割]]（一般理论）、[[concepts/黄金分割]]。
