# 等值面与等值线

**等值面**是空间中所有使标量场 (13.6a) 取常数值的点 $P$ 的集合：

$$U = U(P) = \text{常数}. \tag{13.10a}$$

不同的常数 $U_0, U_1, U_2, \dots$ 定义不同的等值面；对每个（函数有定义的）点都存在一个等值面通过该点。三种坐标系中的等值面方程为

$$U = \Phi(x,y,z) = \text{常数},\quad U = \Psi(\rho,\varphi,z) = \text{常数},\quad U = \chi(r,\vartheta,\varphi) = \text{常数}. \tag{13.10b}$$

**等值线**：在平面场中等值线替代等值面，满足

$$U = \text{常数}. \tag{13.11}$$

通常对 $U$ 的相等间隔绘制等值线，每条标以相应的值（原书第 915 页图 13.3，未入库）。

## 等值面的典型例子

| 场 | 等值面 |
|---|---|
| A：$U = \vec{c}\vec{r} = c_x x + c_y y + c_z z$ | 平行平面 |
| B：$U = x^2 + 2y^2 + 4z^2$ | 处于相同位置的相似椭球面 |
| C：[[中心场]] | 同心球面 |
| D：[[轴向场]] | 同轴柱面 |

## 等值线的典型例子

熟知的例子有天气图上的**等压线**和地形图上的**等高线**。原书图 13.4 展示了四个平面场的等值线：(a) $U = xy$；(b) $U = y/x^2$；(c) $U = x^2+y^2 = \rho^2$；(d) $U = 1/\rho$。

## 退化情形

在一些特别的情形，等值面退化为一些点或线，等值线退化为一些分离的点。

两者的系统对照见 [[等值面与等值线比较]]；等值面/线是[[标量场]]的几何刻画，与[[向量场]]的[[向量线]]相对应。
