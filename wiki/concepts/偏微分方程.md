# 偏微分方程

## 定义

**手册定义（第 9 章章首）**：偏微分方程是有几个自变量（即自变量数目多于一个）的 [[微分方程]]。此为《数学手册(原书第10版)》第 9 章章首定义 (2) 之一支：第二种情形（偏微分方程）有几个自变量（源文件 `第9章 微分方程.md`，source 页 [[10-数学手册原书第10版--8-第9章-微分方程--1j96pxc]]）。通行英文术语 partial differential equation 属背景补充，手册原文未附。

**标准含义**：偏微分方程（partial differential equation，PDE）是包含多元未知函数及其偏导数的方程：当未知函数依赖于多个自变量、方程中出现沿各自变量方向的一阶或更高阶导数时，即得偏微分方程。它是 [[常微分方程]]（未知函数仅依赖一个自变量）从一元情形向多元情形的自然推广。

> 说明：「标准含义」段为本页建立时给出的**独立可验证的标准含义**；9.2 目录页源文件（《数学手册(原书第10版)》`9.2 偏微分方程.md`）未提供任何定义，待 9.2.1 等子小节文件入库后，应以原文定义为准校正本段。

## 记法与例式

偏微分方程涉及函数关于多个自变量的偏导数，使用偏导数记号 ∂。手册章首例 C（原文 LaTeX 逐字）：

$$\frac { \partial ^ { 2 } z } { \partial x \partial y } = x y z \frac { \partial z } { \partial x } \frac { \partial z } { \partial y } .$$

判读：z 为 x、y 两个自变量的函数，方程含二阶混合偏导数 ∂²z/∂x∂y，故为二阶偏微分方程（依「阶」之定义推得）。
