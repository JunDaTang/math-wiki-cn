# 偶奇分解

偶奇分解是把定义域关于原点对称的函数表示为一个[[concepts/偶函数]]与一个[[concepts/奇函数]]之和的标准技术：$f(x) = g(x) + u(x)$，其中偶部 $g(x) = \frac{1}{2}[f(x) + f(-x)]$，奇部 $u(x) = \frac{1}{2}[f(x) - f(-x)]$。

## 公式（《数学手册(原书第10版)》2.1.3.6，式 2.11）

$$f(x) = g(x) + u(x), \quad g(x) = \frac{1}{2}[f(x) + f(-x)], \quad u(x) = \frac{1}{2}[f(x) - f(-x)]$$

前提是定义域对称：$x \in D \Rightarrow -x \in D$。

## 示例

$$f(x) = e^{x} = \frac{1}{2}(e^{x} + e^{-x}) + \frac{1}{2}(e^{x} - e^{-x}) = \cosh x + \sinh x$$

即 $e^{x}$ 的偶部为 $\cosh x$、奇部为 $\sinh x$；手册前向引用第 115 页 2.9.1（双曲函数），该处待处理后应回链本页。

## 可验算性质

- $g(-x) = g(x)$、$u(-x) = -u(x)$、$g(x) + u(x) = f(x)$：逐项代入即可验证；
- 分解唯一：若 $f = g + u$ 且 $g$ 偶、$u$ 奇，联立可解出 $g, u$ 必由式 (2.11) 给出——此为两步推导；手册仅言“可写成”并给出公式，未显式主张唯一性。

## 方法论地位

偶奇分解是 2.1 章“函数的表示”主题下的又一种表示技术，与 [[concepts/显函数]]、[[concepts/隐函数]]、[[concepts/参数方程]] 并列：后三者给出函数的解析载体，偶奇分解给出对称结构下的标准分解，与 2.1.2 的表示形式体系（见 [[findings/函数定义的四种载体与缺省最大定义域约定]]、[[findings/实函数解析表示三形式及其成立条件]]）互补。
