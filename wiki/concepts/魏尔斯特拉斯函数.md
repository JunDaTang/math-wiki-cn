# 魏尔斯特拉斯函数

魏尔斯特拉斯函数指由周期格点级数定义的三个函数：℘ 函数（魏尔斯特拉斯椭圆函数）、ζ 函数（魏尔斯特拉斯 zeta 函数）与 σ 函数（魏尔斯特拉斯 sigma 函数），均以两个比值非实数的复数 ω₁、ω₂ 为参数（(14.116a–c)）。其中 ℘ 是 [[椭圆函数]]（[[双周期函数|双周期]]的[[亚纯函数]]），而 ζ 与 σ 仅具[[拟周期性]]——源文明确断言它们“不是双周期的，因而不是椭圆函数”。

## 格点与定义（(14.117)、(14.121)）

```latex
\omega_{mn}=2(m\omega_1+n\omega_2)\quad(m,n\in\mathbb{Z})
\wp(z)=z^{-2}+\sum_{m,n}'\Big[(z-\omega_{mn})^{-2}-\omega_{mn}^{-2}\Big]
\zeta(z)=z^{-1}+\sum_{m,n}'\Big[(z-\omega_{mn})^{-1}
+\omega_{mn}^{-1}+\omega_{mn}^{-2}z\Big]
\sigma(z)=z\exp\!\left(\int_0^z[\zeta(t)-t^{-1}]\,dt\right)
=z\prod_{m,n}'\Big(1-\frac{z}{\omega_{mn}}\Big)
\exp\!\left(\frac{z}{\omega_{mn}}+\frac{z^2}{2\omega_{mn}^2}\right)
```

求和号后的撇表示忽略 m = n = 0 项；级数对每个 z ≠ ω_mn 收敛（源文性质 (2)）。

## ℘ 的微分方程、不变量与加法定理（(14.118)–(14.120)）

```latex
\wp'^2=4\wp^3-g_2\wp-g_3
g_2=60\sum_{m,n}'\omega_{mn}^{-4},\qquad
g_3=140\sum_{m,n}'\omega_{mn}^{-6}
z=\int_u^{\infty}\frac{dt}{\sqrt{4t^3-g_2t-g_3}}
\wp(u+v)=\frac{1}{4}\left[\frac{\wp'(u)-\wp'(v)}{\wp(u)-\wp(v)}\right]^2
-\wp(u)-\wp(v)
```

g₂、g₃ 称为 ℘ 的不变量（invariants）；℘ 是积分 (14.119) 的反函数。

## ζ 与 σ 的关系式（(14.122)–(14.125)）

```latex
\zeta'(z)=-\wp(z)
\zeta(-z)=-\zeta(z),\qquad \sigma(-z)=-\sigma(z)
\zeta(z+2\omega_1)=\zeta(z)+2\zeta(\omega_1),\qquad
\zeta(z+2\omega_2)=\zeta(z)+2\zeta(\omega_2)
\zeta(u+v)=\zeta(u)+\zeta(v)
+\frac{1}{2}\frac{\wp'(u)-\wp'(v)}{\wp(u)-\wp(v)}
```

## 源文三处实质疑点

复算 (14.117)–(14.125) 各式与标准理论一致，但本小节行文有三处疑点：

1. 性质 (1) 称 ℘ “有周期 ω₁ 和 ω₂”，与格点定义 ω_mn = 2(mω₁+nω₂) 及拟周期关系中的 2ωᵢ 矛盾：℘ 的周期应为 2ω₁、2ω₂（ω₁、ω₂ 为半周期）。见 [[魏尔斯特拉斯wp周期omega与2omega之辨]]。
2. (14.122) 记 “ζ(z) = ln σ(z)”，疑丢求导号：正确恒等式为 ζ(z) = (ln σ(z))′ = σ′(z)/σ(z)，可由 (14.121b) 的乘积式逐项求导直接证明。见 [[式14-122zeta等于lnsigma疑丢求导记号]]。
3. 性质 (5) “每个椭圆函数是 ℘(z) 和 ζ(z) 的有理函数”按字面为假（℘′ 即为反例）；标准定理应为“每个椭圆函数是 ℘ 与 ℘′ 的有理函数”。见 [[魏尔斯特拉斯性质5wp与zeta有理表示之辨]]。
