# 四元数最小二乘姿态确定

四元数最小二乘姿态确定是《数学手册（原书第10版）》4.4.3.4（标题「卫星导航」）给出的方法：当两个坐标系（地球固定系与卫星星载系）对若干恒星方向的测量存在误差时，以单位四元数 h 刻画两坐标系间的相对旋转（b⃗ᵢ = h a⃗ᵢ h̄），求使残差平方和 Q² = Σᵢ |b⃗ᵢ − h a⃗ᵢ h̄|² 最小的 h。其求解关键是：经李群切向导数与叉乘斜对称矩阵 K(a⃗) 把四元数约束下的极小化化为矩阵方程 RP = PᵀRᵀ，再用极分解 P = R_pᵀS 闭式解出。

## 物理设定

环绕地球运行的人造卫星的姿态确定：恒星视为无穷远，故恒星方向相对于地球与相对于卫星相同（图 4.6）；任何测量差别都可由两坐标系的相对旋转推出。设 a⃗ᵢ、b⃗ᵢ 分别为地球系与卫星系中指向第 i 颗恒星的单位向量，则相对旋转由单位四元数 h ∈ ℍ₁ 刻画：b⃗ᵢ = h a⃗ᵢ h̄（式 4.153）。

## 求解路线（式 4.154–4.165）

1. **目标泛函**：Q² = Σᵢ(2 − b̲ᵢ h āᵢ h̄ − h a̲ᵢ h̄ b̄ᵢ)（式 4.154）。
2. **李群导数**：ℍ₁ 是李群，切向导数 ∂_v h = vh（式 4.155）把临界点条件化为 ∂_v̲Q² = −4v̲·(Σᵢ h a⃗ᵢ h̄ × b̲ᵢ) = 0（式 4.156–4.157），即 Σᵢ Ra⃗ᵢ × b⃗ᵢ = 0（式 4.158，R 为 h 对应的旋转矩阵）。
3. **叉乘矩阵**：K(a⃗)b⃗ = a⃗×b⃗、K(K(a⃗)b⃗) = b⃗a⃗ᵀ − a⃗b⃗ᵀ（式 4.159–4.160），把临界点条件化为 **RP = PᵀRᵀ**，其中 P = Σᵢ a⃗ᵢb⃗ᵢᵀ（式 4.161）。
4. **极分解**：P = R_pᵀS（S 对称、R_p 旋转矩阵），得解 R = R_p（式 4.162–4.163），另有三个解 R = R_jR_p（R_j 绕 S 的第 j 个特征向量旋转 π，式 4.164）。
5. **极小解选取**：det P > 0 时 R = R_p；det P < 0 时 R = R_{j₀}R_p（j₀ 对应 S 的绝对值最小特征值的特征向量）（式 4.165）。

完整公式链与复核见 [[findings/卫星导航最小二乘姿态确定解全链]]，操作流程见 [[methodology/卫星姿态确定的极分解求解流程]]。

## 与标准问题的对应（分析者识别，书未命名）

数学上，该问题即**正交 Procrustes 问题**（orthogonal Procrustes problem）/ **Wahba 问题**的姿态确定形式，上述解法是其极分解（SVD 型）解法。本书未使用这些名称、未给数值例，亦未讨论 det P = 0 的退化情形。
