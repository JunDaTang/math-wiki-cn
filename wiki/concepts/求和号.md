# 求和号（Σ）

求和号 $\sum$ 是缩写 $n$ 个被加项之和的数学记号：把 $a_1 + a_2 + \dots + a_n$ 写作 $\sum_{k=1}^{n} a_k$，其中 $k$ 称为变动指标或求和变量。它是处理重复加法的基本缩写记号。本页的定义与法则依据《数学手册(原书第10版)》1.1.3.1，公式编号 (1.8) 与 (1.9a–1.9f) 为手册内部的引用锚点。

## 定义

$$
a_1 + a_2 + \dots + a_n = \sum_{k=1}^{n} a_k.\tag{1.8}
$$

借助这一符号可以表示 $n$ 个被加项 $a_k\ (k=1,2,\dots,n)$ 的和；$k$ 称为**变动指标**或**求和变量**。

## 计算法则

| 编号 | 法则 | 公式 |
|---|---|---|
| (1.9a) | 相等各项（$a_k = a$）之和 | $\sum_{k=1}^{n} a_k = na$ |
| (1.9b) | 各项与一常数相乘 | $\sum_{k=1}^{n} c\,a_k = c \sum_{k=1}^{n} a_k$ |
| (1.9c) | 分部求和 | $\sum_{k=1}^{n} a_k = \sum_{k=1}^{m} a_k + \sum_{k=m+1}^{n} a_k \quad (1 < m < n)$ |
| (1.9d) | 相同长度的和相加 | $\sum_{k=1}^{n} (a_k + b_k + c_k + \dots) = \sum_{k=1}^{n} a_k + \sum_{k=1}^{n} b_k + \sum_{k=1}^{n} c_k + \dots$ |
| (1.9e) | 重新编号 | $\sum_{k=1}^{n} a_k = \sum_{k=m}^{m+n-1} a_{k-m+1}$；$\sum_{k=m}^{n} a_k = \sum_{k=l}^{n-m+l} a_{k+m-l}$ |
| (1.9f) | 双重和中变换求和次序 | $\sum_{i=1}^{n} \left(\sum_{k=1}^{m} a_{ik}\right) = \sum_{k=1}^{m} \left(\sum_{i=1}^{n} a_{ik}\right)$ |

## 说明与联系

- 手册未给出证明；各条法则均为标准恒等式，可由 [[数学归纳法]] 直接证得（证明方法的分类见 [[10-数学手册原书第10版--9-112-证明的方法--qkzev6]]）。
- (1.9b) 与 (1.9d) 是分配律在有限和上的直接推广，参见 [[10-数学手册原书第10版--9-11-基本运算法则--1yit8sw]]。
- (1.9c) 分部求和与 (1.9e) 重新编号是级数处理与指标变量替换的基础操作。
- (1.9f) 表明有限双重和可以交换求和次序，是后续无穷级数换序结论（Fubini 型定理）的有限原型。
- 求和号与 [[求积号]] 的法则 (1.11a–1.11f) 逐条对偶；唯一系统性差异在常数法则——和中提取 $c$，积中提出 $c^{n}$。
