# 二元关系

关系定义一个或不同集合的元素间的对应。集合 $A_1, \dots, A_n$ 间的 **n 元（n 位）关系** $R$ 是这些集合的笛卡儿积的子集：

$$R \subseteq A_{1} \times \dots \times A_{n}$$

如果所有 $A_i$ 全是同一个集合 $A$，那么 $R \subseteq A^{n}$，称为集合 $A$ 中的 n 元关系。

**二元关系**（二位关系）具有特殊的重要性。在二元关系情形，经常使用记号 $a R b$ 代替 $(a, b) \in R$。

**典型算例——整除关系**（见 [[findings/整除关系与关系矩阵算例]]）：集合 $A = \{1, 2, 3, 4\}$ 中的整除关系是二元关系

$$T = \{(a, b) \mid a, b \in A \land a \text{ 是 } b \text{ 的因子}\} = \{(1,1),(1,2),(1,3),(1,4),(2,2),(2,4),(3,3),(4,4)\} \tag{5.67a,b}$$
