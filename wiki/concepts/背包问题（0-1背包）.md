# 背包问题（0-1背包）

背包问题是《数学手册(原书第10版)》18.3.2.2 用动态规划求解的组合优化问题：设有 $n$ 个项目 $A_1,\dots,A_n$，权重与价值分别为 $w_1,\dots,w_n$ 与 $c_1,\dots,c_n$，要从中选取一些项目，使总权重不超过给定上限 $W$ 而总价值最大。

## 动态规划重述

该问题本与时间无关；手册按如下方式重新表述为多级决策：每一阶段对项目 $A_j$ 作选取决策 $u_j$（选取则 $u_j=1$，否则 $u_j=0$），每阶段开始时可用的容量记作 $x_{j-1}$，从而（式 18.129a/b；a 式的 `→ min!` 疑为 `→ max!`，见 [[queries/式18-129a疑为max之辨]]）：

```latex
OF: f(u_1,…,u_n) = Σ_{j=1}^n c_j u_j → max!
CT: x_j = x_{j-1} − w_j u_j,  j = 1(1)n
    x_0 = W,  0 ⩽ x_j ⩽ W,  j = 1(1)n
    u_j ∈ {0,1}  若 x_{j-1} ⩾ w_j；  u_j = 0  若 x_{j-1} < w_j
```

（18.3.6.2 以式 18.145a 重新照录此模型，明确为 `→ max!`。）

## 泛函方程与决策规则（18.3.6.2）

因是极大问题，贝尔曼泛函方程取极大形式：

$$\varphi_{n+1}(x_n)=0,\qquad \varphi_j(x_{j-1}) = \max_{u_j\in U_j(x_{j-1})} \big(c_j u_j + \varphi_{j+1}(x_{j-1}-w_j u_j)\big),\quad j=1(1)n.$$

由于 $u_j$ 只可能是 0 或 1，决策规则化为分段形式：若 $x_{j-1}\geqslant w_j$ 且 $c_j+\varphi_{j+1}(x_{j-1}-w_j)>\varphi_{j+1}(x_{j-1})$ 则 $u_j=1$，否则 $u_j=0$；相应地 $\varphi_j$ 取 $c_j+\varphi_{j+1}(x_{j-1}-w_j)$ 与 $\varphi_{j+1}(x_{j-1})$ 中的较大者。正因 $u_j\in\{0,1\}$，应用泛函方程方法的**方式 1**（逐状态存决策）比较切合实际。

## 算例与疑点

18.3.6.2 的数值算例（$W=10,n=6$）按原文数据行 $c=(1,2,3,1,5,4)$、$w=(2,4,6,3,7,6)$ 复算与表格不符；将 $c$ 与 $w$ 两行互换后全表完全相符，最优策略 $(0,1,1,1,0,1)$、$\varphi_1(10)=19$，见 [[findings/背包问题算例表复算]] 与 [[queries/背包算例c与w数据行疑互换之辨]]。
