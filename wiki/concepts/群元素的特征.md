# 群元素的特征

**在表示 $D(a)$ 中，群元素 $a$ 的特征 $\chi(a)$ 定义为表示矩阵 $D(a)$ 的迹（主对角线元素之和）**（式 5.105）：

$$\chi(a) = \operatorname{Tr}(D) = \sum_{i=1}^{n} D_{ii}(a).$$

- 单位元的特征等于表示的维数：$\chi(e) = n$；
- 由于矩阵的迹在 [[concepts/相似变换]] 下不变，**等价表示**（见 [[concepts/等价表示]]）中同一群元有相同的特征。

## 术语警示

表示论中的「特征」（character）是矩阵的迹，与线性代数中的「特征值」（eigenvalue，见 [[concepts/特征值与特征向量]]）是不同概念，仅字面相近。

## 算例

- 壳层模型 [[entities/对称群s-m]] 三维表示 (5.106c)：$\chi(e) = 3$，$\chi(p_1) = \chi(p_2) = \chi(p_3) = 1$，$\chi(p_4) = \chi(p_5) = 0$（式 5.106d）；且 $3 = 1+2$、$1 = 1+0$、$0 = 1+(-1)$，恰为恒等表示与二维表示特征之和，印证可约性（见 [[findings/壳层模型s3三维表示与特征]]）。
- 由例 A、例 B 的矩阵直接计算（本 wiki 复算）：[[entities/d-3二面角群]] 二维表示中 $\chi(e) = 2$、$\chi(R_1) = \chi(R_2) = -1$、$\chi(S_A) = \chi(S_B) = \chi(S_C) = 0$。

## 运算性质

- 直和：特征**相加**（式 5.110，见 [[concepts/表示的直和]]）；
- 张量积：特征**相乘**（式 5.113，见 [[concepts/表示的张量积]]）。
