# 特征方程

特征方程是与常系数线性微分方程相伴的多项式方程。对方程

$$y^{(n)} + c_{n-1}y^{(n-1)} + \dots + c_1 y' + c_0 y = f(t)$$

其特征方程为

$$G(p) = \sum_{k=0}^{n} c_k p^k = 0 \qquad (c_n = 1).$$

在拉普拉斯变换解法中，G(p) 恰为像方程 (15.47b) 的分母：Y(p) = [F(p) + 初始值多项式]/G(p)，因此特征方程无需另行构造，从变换方程中直接读出。

## 在拉普拉斯解法中的角色

- **核函数**：q(t) = L⁻¹{1/G(p)} 完全由 G 的根决定；二阶方程三种判别情形的显式核见 [[comparisons/二阶方程三种判别情形核函数比较]]。
- **解的指数模式**：G 的根 α_v 给出齐次解的 e^{α_v t} 模式；部分分式分解的极点即特征根。
- **阶跃响应闭式**：特征根全为单根且均非零时，(15.54b) 中出现 G(0) 与 G′(α_v)，即 y(t) = 1/G(0) + Σ e^{α_v t}/[α_v G′(α_v)]。

## 出处与交叉引用

手册 15.2.3.1 在 (15.47b) 之后指出 G(p) = 0 即微分方程的特征方程，并回指 4.6.2.1（第 421 页，本 wiki 未入库，见 [[queries/15-2-3未入库回指缺口]]）。特征方程的经典理论（以 e^{λt} 代入齐次方程导出同一多项式）属常微分方程一般理论，为可独立核实的背景；本页仅记录其在拉普拉斯变换语境下的读出方式与用法。
