# 双曲正弦函数

**双曲正弦函数** sinh x 是六个 [[concepts/双曲函数]] 之一，由 [[concepts/指数函数]] 定义为 e^x 与 e^−x 之差的一半：

$$
\sinh x = \frac {\mathrm{e} ^ {x} - \mathrm{e} ^ {- x}}{2}.\tag{2.166}
$$

其倒数函数为 [[concepts/双曲余割函数]] csch x（式 2.171）；它与 [[concepts/双曲余弦函数]] cosh x 一起构成双曲函数体系的基干（cosh²x − sinh²x = 1，式 2.172；cosh x + sinh x = e^x）。

## 图像性质（手册 2.9.2.1，图 2.49）

- y = sinh x 是**严格单调递增的奇函数**：sinh(−x) = −sinh x（式 2.178）。
- **值域**为 −∞ 到 +∞。
- **原点**既为对称中心，又为 [[concepts/拐点]]，且此处切线的倾斜角 φ = π/4（核验注：这对应原点处斜率为 1，即 sinh′(0) = cosh(0) = 1，属由定义可得的推断）。
- **无渐近线**（手册设有图像小节的四个双曲函数中，仅 sinh 与 cosh 无渐近线）。

## 在公式体系中的位置

- 负角公式（奇性）：式 2.178。
- 加法定理：sinh(x ± y) = sinh x cosh y ± cosh x sinh y（式 2.182）。
- 倍角：sinh 2x = 2 sinh x cosh x（式 2.186）。
- 半角定号规则：sinh(x/2) = ±√(½(cosh x − 1))，x > 0 取正、x < 0 取负（式 2.191）。
- 和差化积：式 2.195。
- 复角关系：sinh z = −i sin iz（式 2.203）。

完整公式体系见 [[concepts/双曲恒等式]]。

## 与 [[concepts/正弦函数]] 的对照

二者同为奇函数，且加法定理形式完全相同（sin(x±y) = sin x cos y ± cos x sin y 对 sinh(x±y)），但性质不可互换：sin 有界、周期 2π、非单调；sinh 无界、非周期、在整个 ℝ 上严格递增、无渐近线。系统性符号差异见 [[comparisons/双曲函数与三角函数比较]]。
