# 代数表达式与多项式操作命令（表 20.9–20.10）

Mathematica 对代数表达式进行变换的基础命令集，是 [[concepts/公式操作]] 在多项式与有理式上的核心操作。源文语境：实践中的代数表达式通常在整数环（回指第 483 5.3.7）或实数域（回指第 484 5.3.7.1, 3.）上考虑，有理数域上多项式的代数运算特别重要；亦可通过菜单项「面板 其他 代数操作」调用。

## 表 20.9 用于操作代数表达式的命令

| 命令 | 释义 |
|---|---|
| Expand[p] | 用乘法展开一个多项式 p 的幂和积 |
| Expand[p,r] | 仅乘开 p 中包含 r 的部分 |
| PowerExpand[a] | 也展开积的幂以及幂的幂 |
| Factor[p] | 将一个多项式完全因式分解 |
| Collect[p,x] | 将多项式按 x 的幂排序 |
| Collect[p,{x,y,···}] | 与前面一个相同,针对多个变元 |
| ExpandNumerator[r] | 仅展开一个有理表达式的分子 |
| ExpandDenominator[r] | 仅展开分母 |
| ExpandAll[r] | 将分子和分母都完全展开 |
| Together[r] | 将表达式中具有同分母的项合并 |
| Apart[r] | 将表达式表示成部分分式 |
| Cancel[r] | 消去分式中的公因式 |

## 表 20.10 代数多项式的运算

| 命令 | 释义 |
|---|---|
| PolynomialGCD[p1,p2] | 确定 p1 和 p2 的最大公因式 |
| PolynomialLCM[p1,p2] | 确定 p1 和 p2 的最小公倍式 |
| PolynomialQuotient[p1,p2,x] | 用 p2 除 p1 (作为 x 的函数),略去余式 |
| PolynomialRemainder[p1,p2,x] | 确定 p2 除 p1 时的余式 |
| MonomialList[p] | 给出多项式 p 中所有单项式的列表 |

## 语义要点

- **展开**：表达式的乘法运算总是可以进行的，系数也可以是未定义的表达式（例：Expand[(x+y−z)⁴]、Expand[(ax+by²)(cx³−dy²)]）。
- **因式分解**：如有可能，Mathematica 在整数环或有理数域上进行，否则返回原来的表达式；分解出的因式在有理数域上不可约（源例 p = (5+x)(1+x+x²)(−5+x²+x³)）。高斯整数环上的完全分解见 [[concepts/高斯整数上的因式分解]]。
- **商余关系**：PolynomialQuotient 与 PolynomialRemainder 满足 p/q = 商 + 余/q（源例：p/q = x²+6x+12 + (37x³+96x²+96x+59)/q）。
- **部分分式**：Apart 将两多项式组成的分式分解为部分分式（有理数域上），「任何部分的分子的次数，总是小于分母的次数」。源例 Apart[q/p] 存在首项分子符号讹误（应为 −6 而非 6），见 [[findings/20-3-1代数与多项式算例复算]] 与 [[queries/Apart首项分子符号之辨]]。
- **非多项式表达式**：Simplify 常可化简复杂的非多项式表达式；无论符号的性质如何，Mathematica 总是试图对代数表达式进行操作，应用某种内置知识（如乘幂规则 a^n/a^m → a^(−m+n)，式 20.28，回指第 1.1.4.1）。三角/指数/复数变换见 [[concepts/三角与复数变换命令]]。
