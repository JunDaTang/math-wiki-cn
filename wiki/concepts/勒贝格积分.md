# 勒贝格积分

勒贝格积分是以集合的测度、测度空间、可测函数等测度论概念为基础定义的积分，是黎曼积分的推广之一（《数学手册(原书第10版)》8.2.3.1.3）。一般地，它是定义在测度空间 (X, 𝒜, μ) 上可测函数的积分，经五个步骤构造：基本函数 → 非负函数 → 正负部分解 → 复值函数 → 限制于可测集；当 X = ℝⁿ 且 μ 为勒贝格测度 λ 时得到（n 维）勒贝格积分，它严格扩张黎曼积分（12.9）。泛函分析中的勒贝格积分正是以这些概念为基础（文献 [8.10]）定义的。

## 定义与构造

### 可积性

可测函数 f: X → ℝ̄ 称作可积或可和，是指它可测且 ∫ |f| dμ < ∞。

### 五步定义 (12.211)–(12.215)

1. **基本函数** f = Σ α_k χ_{A_k}：∫ f dμ = Σ α_k μ(A_k)
2. **非负函数** f ⩾ 0：∫ f dμ = sup{∫g dμ : g 基本函数，0 ⩽ g ⩽ f}
3. **正负部分解**：∫ f dμ = ∫f₊ dμ − ∫f₋ dμ（右端至少一个有穷，避免 ∞ − ∞）
4. **复值函数** f = g + ih（g, h 可积）：∫ f dμ = ∫g dμ + i∫h dμ
5. **限制于可测集**：∫_A f dμ := ∫ f χ_A dμ

逐步细节与构造理由见 [[勒贝格积分五步构造流程]]。

## 基本性质 (1)–(6)

设 f, g 可测，α, β ∈ ℝ：

- (1) f 可积 ⟹ |f| < ∞ 于 μ-a.e.（即 μ({x : |f(x)| = +∞}) = 0）
- (2) |∫f dμ| ⩽ ∫|f| dμ
- (3) f 可积且 f ⩾ 0 ⟹ ∫f dμ ⩾ 0
- (4) 0 ⩽ g ⩽ f 且 f 可积 ⟹ g 可积且 ∫g dμ ⩽ ∫f dμ
- (5) f, g 可积 ⟹ αf + βg 可积且 ∫(αf + βg) dμ = α∫f dμ + β∫g dμ
- (6) f, g 在 A ∈ 𝒜 上可积且 f = g a.e. ⟹ ∫_A f dμ = ∫_A g dμ

## 与黎曼积分的关系

作为黎曼积分的推广，勒贝格积分可以把积分区域推广到 ℝ 的更一般的子集上，把积分区域划分成可测子集（8.2.3.1.3）。n = 1、A = [a, b] 时（12.9）：[a, b] 上每个连续函数的黎曼积分与勒贝格积分都有定义、有穷且彼此相等；[a, b] 上有界黎曼可积函数也勒贝格可积且两值相等。但勒贝格可积函数集比黎曼可积函数集大得多。

系统对照见 [[黎曼积分与勒贝格积分比较]]；与其他推广路径的对照见 [[黎曼积分斯蒂尔切斯积分与勒贝格积分比较]]。
