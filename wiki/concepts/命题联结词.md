# 命题联结词

命题联结词是把命题组合成复合命题的运算。《数学手册(原书第10版)》5.1.1 给出五种（式 5.1–5.5）：

| 记号 | 名称 | 读法 |
|---|---|---|
| ¬A | 否定 | 「非 A」 |
| A∧B | 合取 | 「A 且 B」 |
| A∨B | 析取 | 「A 或 B」（包括或，即「和/或」） |
| A⇒B | 蕴涵 | 「若 A，则 B」 |
| A⇔B | 等价 | 「A 当且仅当 B」 |

要点：

- 「逻辑或」总意味**包括或**，也就是「和/或」。
- 蕴涵的词语形式：B 对于 A 是必须的，A 对于 B 是充分的（转写中 A、B 字母脱落）。
- 五种运算的语义由表 5.1 的真值表唯一确定（[[findings/命题联结词真值表定义]]）。
- 约束强度（优先级）序列：¬, ∧, ∨, ⇒, ⇔——序列中每个运算都比下一个约束更强，据此可省略圆括号。
- 蕴涵与等价并非必需：经式 (5.17) 可消去（A⇒B = Ā∨B；A⇔B = AB∨ĀB̄），故 {¬,∨} 或 {¬,∧} 已函数完备；更可仅用 [[concepts/谢费尔函数]]（NAND）或 [[concepts/皮尔斯函数]]（NOR）单独表示一切真值函数。
