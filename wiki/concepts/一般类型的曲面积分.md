# 一般类型的曲面积分

一般类型的曲面积分是三个第二类曲面积分之和：设 $P(x,y,z), Q(x,y,z), R(x,y,z)$ 为定义在连通区域上的三个三元函数，$S$ 为该区域内的有向曲面，则在三个坐标面上投影的第二类积分之和称为一般类型的曲面积分：

$$\int_S (P\,\mathrm{d}y\,\mathrm{d}z + Q\,\mathrm{d}z\,\mathrm{d}x + R\,\mathrm{d}x\,\mathrm{d}y) = \int_S P\,\mathrm{d}y\,\mathrm{d}z + \int_S Q\,\mathrm{d}z\,\mathrm{d}x + \int_S R\,\mathrm{d}x\,\mathrm{d}y \tag{8.161}$$

## 化算

化为二重积分（式 8.162）：

$$\int_S (P\,\mathrm{d}y\,\mathrm{d}z + Q\,\mathrm{d}z\,\mathrm{d}x + R\,\mathrm{d}x\,\mathrm{d}y) = \int_\Delta \Big[P\frac{D(y,z)}{D(u,v)} + Q\frac{D(z,x)}{D(u,v)} + R\frac{D(x,y)}{D(u,v)}\Big]\mathrm{d}u\,\mathrm{d}v \tag{8.162}$$

其中三个 [[concepts/雅可比行列式]] 与 $\Delta$ 的意义同前。向量值函数的曲面积分在向量场理论一章讨论（源回指第 942 页 13.3.2，未入库 → [[queries/8-3线积分8-4重积分及3-6-3-3与13-3-2未入库回指缺口]]）。

## 性质（式 8.163–8.165）

1. **可加性**：$S$ 分成 $S_1$、$S_2$，则积分分块相加（式 8.163，图 8.47）。
2. **反向变号**：$\int_{S^+}(\cdots) = -\int_{S^-}(\cdots)$，$S^+$、$S^-$ 为同一曲面的两个方向（式 8.164）。
3. **曲面依赖**：曲面积分通常与曲面区域的边界及曲面本身有关——由相同闭曲线张成的两个不同非闭曲面区域 $S_1$、$S_2$ 的积分往往不同（式 8.165）。此性质是 Stokes 型定理适用条件的前奏。

## 体积应用（式 8.166–8.168b）

以闭曲面 $S$（外侧为正的有向曲面）为边界的立体体积 $V$：

- $V = \dfrac{1}{3}\displaystyle\int_S (x\,\mathrm{d}y\,\mathrm{d}z + y\,\mathrm{d}z\,\mathrm{d}x + z\,\mathrm{d}x\,\mathrm{d}y)$（式 8.166；**与 8.167b 逐字相同**，疑点见 [[queries/式8-166与8-167b完全重复是否原书原文]]）
- $V = \displaystyle\int_S x\,\mathrm{d}y\,\mathrm{d}z = \int_S y\,\mathrm{d}z\,\mathrm{d}x = \int_S z\,\mathrm{d}x\,\mathrm{d}y$（式 8.167a）

球体算例（$x^2+y^2+z^2=R^2$，球坐标）已复算：$D(x,y)/D(\vartheta,\varphi) = R^2\cos\vartheta\sin\vartheta$（式 8.168a）✓，$V = \tfrac{4}{3}\pi R^3$（式 8.168b）✓ → [[findings/式8-166至8-168体积公式与球体算例复算]]。
