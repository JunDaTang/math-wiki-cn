# 伽辽金法

伽辽金法是边值问题逼近系数确定四原则之一，冠名者 [[entities/伽辽金]]：需要满足所谓**误差正交性**

```latex
(19.126)  \int_a^b \varepsilon(x; a_1, a_2, \dots, a_n)\, g_i(x)\, dx = 0   (i = 1, 2, \dots, n)
```

即亏量与每个基函数 g_i 正交；由此得到未知系数的线性方程组。ε 为 [[concepts/亏量（残量）]] (19.122)。

对自伴边值问题，变分问题 (19.130) 的提法与本法经由 [[concepts/边值问题与变分问题等价性]] 相联系（源文将四原则并列给出，未明言伽辽金与里茨的等价关系）。四原则比较见 [[comparisons/逼近系数确定四原则比较]]。
