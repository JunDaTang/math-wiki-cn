# 交会法

交会法是三角测量的第一基本问题：通过两个已知点 A、B，借助三角形 ABN 确定待定点 N（图 3.42），即经由两条定向直线的交点定位。

![图 3.42 交会法](media/10-数学手册原书第10版--8-32-平面三角学--j56osm/012-0baf0eaeb2000ff2e3915e76192230d91f3e334da43f3c5441a842c4e2e1fdec.jpg)

**已知**：$y_A, x_A; y_B, x_B$。**所测**：$\alpha, \beta$（如果可能的话还有 $\gamma$，或 $\gamma = 200\ \mathrm{gon} - \alpha - \beta$）。**所求**：$y_N, x_N$。

解算链 (3.110a–h)：由坐标反算 $t_{AB}$、$s_{AB}$（含检验恒等式 $s_{AB} = |\Delta y_{AB}\sin t_{AB}| + |\Delta x_{AB}\cos t_{AB}|$）；用 [[concepts/正弦定律]] 求 $s_{BN} = s_{AB}\sin\alpha/\sin(\alpha+\beta)$、$s_{AN} = s_{AB}\sin\beta/\sin(\alpha+\beta)$；方位角传递 $t_{AN} = t_{AB} - \alpha$、$t_{BN} = t_{BA} + \beta$；坐标正算并从 A、B 两端复算检核 (3.110g–h)。

**不可见变体**（式 3.111）：若从 A 处不能看见点 B，则方位角 $t_{AN}$、$t_{BN}$ 通过关于其他坐标已知的可见点 D、E 的参考方向来确定（图 3.43），化为第一基本问题求解。该系列的转写疑点多，见 [[queries/式3-111系列下标与符号是否错乱]]。

公式全文见 [[findings/交会法两变体公式]]；与其他定位法的比较见 [[comparisons/交会定位三法比较]]。
