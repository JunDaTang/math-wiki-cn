# 二阶偏微分方程的分类

**二阶偏微分方程的分类**指依据二阶主部系数的符号模式将方程划分为双曲型、抛物型、椭圆型（以及混合型、超双曲型）的理论。它是 [[二阶线性偏微分方程]] 理论的总纲：类型决定[[偏微分方程的特征]]的实性、[[典范形式]]的形状与适用的积分方法。

## 两变量情形：判别式

对方程 (9.82a)，判别式 δ = AC − B²（式 9.82b）：

- δ < 0：双曲型（Hyperbolic type）
- δ = 0：抛物型（Parabolic type）
- δ > 0：椭圆型（Elliptic type）
- δ 在所考虑区域内改变符号：混合型（Mixed type）

判别式的符号在自变量的（非退化）变换下不变，故方程类型与自变量选取无关；手册原文表述为“任意变换”，复算提示应限定为非退化变换。

**约定警示**：手册取 δ = AC − B² 且双曲型对应 δ < 0；通行教材多用 B² − AC（或 B² − 4AC）且双曲型为正，两者方向相反。这是约定差异而非错误，详见 [[comparisons/判别式两种符号约定比较]]。

## 多变量常系数情形：κᵢ 符号模式

常系数方程经线性齐次变换化为 Σ κᵢ ∂²u/∂xᵢ² + … = 0（式 9.87），κᵢ ∈ {−1, 0, +1}：

- 所有 κᵢ 非零同号：椭圆型；
- 恰一个 κᵢ 与其余异号：双曲型；
- 两种符号各至少出现两次：超双曲型（ultra-hyperbolic）；
- 恰一个 κᵢ = 0 且其余同号：抛物型。

n ≥ 3 的变系数方程一般不能化为单一典范形式，但仍存在类似的分类理论（手册回指文献 [9.5]，未入库）。

## 类型判据示例（复算核对）

- 弦振动方程 u_tt = a²u_xx：A = a², C = −1, B = 0 → δ = −a² < 0，双曲型 ✓
- 热传导方程 u_t = a²u_xx：C = 0 → δ = 0，抛物型 ✓
- 拉普拉斯方程 u_xx + u_yy = 0：δ = 1 > 0，椭圆型 ✓

三类方程的系统比较见 [[comparisons/双曲抛物椭圆三类方程比较]]；分类操作流程见 [[二阶偏微分方程分类与典范形式约化流程]]；转录复算见 [[findings/式9-82至9-85分类特征与典范形式转录复算]]、[[findings/式9-86至9-90多变量与常系数约化复算]]。
