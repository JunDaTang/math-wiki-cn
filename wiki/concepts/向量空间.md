# 向量空间

域 $K$ 上的向量空间由三部分组成：(1) 「向量」的阿贝尔群 $V=(V,+)$（写成加法形式）；(2) 「标量」域 $K=(K,+,*)$；(3) 外乘法 $K\times V\to V$，对每个有序对 $(k,v)$（$k\in K$，$v\in V$）确定一个向量 $kv\in V$。这些运算满足公理 V1–V8（式 5.182–5.189）；当 $K=\mathbb{R}$ 时称**实向量空间**。

## 公理 V1–V8

```latex
(V1) (u+v)+w = u+(v+w)        (V2) 存在 0∈V: v+0 = v
(V3) v+(-v) = 0               (V4) v+w = w+v
(V5) 1v = v  (1 为 K 的单位元)  (V6) r(sv) = (rs)v
(V7) (r+s)v = rv+sv           (V8) r(v+w) = rv+rw
```

完整表述与转写复原注记见 [[findings/向量空间公理组v1-v8与三例]]。

## 三个初始例子（5.3.8.1）

- **例 A**：(1,n) 与 (n,1) 型的单行和单列实矩阵，对于加法和与实数的外乘法分别形成实向量空间 $\mathbb{R}^n$（行向量空间与列向量空间；原书另见 4.1.3，第 364 页）。
- **例 B**：所有 (m,n) 型实矩阵形成实向量空间。
- **例 C**：区间 $[a,b]$ 上的连续实函数按式 (5.190) 形成实向量空间，即 [[entities/c-a-b-连续函数空间]]；函数空间在泛函分析中起基本作用（第 12 章）。
