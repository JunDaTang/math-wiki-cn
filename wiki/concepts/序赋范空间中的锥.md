# 序赋范空间中的锥

锥是实赋范空间 X 中用于诱导序结构的正元素子集 X₊ ⊂ X（其原始定义在第 859 页 12.1.4.2，该节尚未入库；外部经典背景：锥对加法与非负标量乘封闭，并由此定义序 x ≤ y ⟺ y − x ∈ X₊）。本源 12.3.3.1 讨论锥与范数的相容性，给出三种性质：

## 实心锥

X₊ 称作**实心的**，指它包含一个正半径的球，等价地至少含有一个内点。源文例子：𝔽ⁿ 类空间（转录空间名残缺为「政」）与 𝒞([a,b]) 中常用的锥都是实心的；但 Lᵖ((a,b)) 与 ℓᵖ 中的自然锥不是实心的。

## 正规锥

X₊ 称作**正规的**，指 X 中的范数是半单调的：存在正常数 M > 0 使

0 ≤ x ≤ y ⟹ ‖x‖ ≤ M‖y‖　（式 12.92）

**定理**：若 X 是巴拿赫空间且序由锥 X₊ 给出，则每个序区间相对范数有界当且仅当 X₊ 是正规的。源文例子：𝔽ⁿ 类空间（转录残缺为「贮」/「Φⁿ」）、m、c、c₀、𝒞([a,b])、ℓᵖ、Lᵖ 中由非负分量/非负函数组成的锥都是正规的。

## 正则锥

X₊ 称作**正则的**，指每个单调增且上有界的序列

x₁ ≤ x₂ ≤ ⋯ ≤ xₙ ≤ ⋯ ≤ z　（式 12.93）

都是柯西列（转录本定义句缺「都是」二字）。源文例子：ℓᵖ 与 Lᵖ（1 ≤ p ≤ ∞）中的锥是正则的（p = ∞ 情形存疑：编者按外部标准结果复算出 ℓ^∞ / L^∞ 自然锥的反例，见下）；「但在 中则是非正则的」一句空间名缺失。

**编者复算（外部经典论证）**：在 ℓ^∞ 中取 xⁿ = (1, …, 1, 0, 0, …)（前 n 个分量为 1），则 {xⁿ} 单调增且以 (1,1,…) 为上界，但 ‖x^{n+m} − xⁿ‖_∞ = 1，不是柯西列；L^∞(0,1) 中取 χ_{(0,1−1/n)} 同理。故 p = ∞ 的正则性疑为转写或原文讹误，正确范围疑为 1 ≤ p < ∞。
