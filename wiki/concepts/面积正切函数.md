# 面积正切函数

面积正切函数 y = Artanh x（式 2.209）是 [[concepts/双曲正切函数]] tanh 的反函数，为奇函数，等价表达式为 x = tanh y。按表 2.8 与式 2.213，其定义域为 |x| < 1、值域为 −∞ < y < ∞；正文 2.10.1.3 中「仅在 |x| ≤ 1 时有定义」的「≤」与表格、公式条件矛盾，疑为笔误，见 [[queries/正文Artanh定义域小于等于1是否应为小于1]]。

## 基本表示

$$
\operatorname{Artanh} x = \frac {1}{2} \ln \frac {1 + x}{1 - x} \quad (| x | < 1) \tag{2.213}
$$

## 图像要素（图 2.55）

- 奇函数，原点为对称中心与拐点，此处切线倾角 φ = π/4；
- 铅直渐近线 x = ±1。

## 关系式

- 互表：Artanh x = Arsinh(x/√(1−x²)) = Arcoth(1/x) = (sign x)·Arcosh(1/√(1−x²))（|x| < 1），其中 Arcoth(1/x) 一项在 x = 0 处失效，见 [[findings/四种面积函数的互表关系]]。
- 和差：Artanh x ± Artanh y = Artanh((x ± y)/(1 ± xy))（式 2.221），定义域内闭包良好、无分支问题。
- 奇性：Artanh(−x) = −Artanh x（式 2.223）。
