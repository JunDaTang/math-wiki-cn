# 学生t分布

**学生 t 分布**（Student's t-distribution）是以自由度 m 为参数的连续型概率分布，在数理统计中用作小样本均值统计量的抽样分布，m→∞ 时收敛于标准正态分布（以上为可独立核验的公共背景知识，非本手册 21.20 节所载）。本手册在两处承载该分布：

- **第 16 章 16.2.4.8**：给出 t 分布的构造、密度函数与分布函数、期望与方差、分位数定义。
- **第 21 章数值表 21.20 节**：不载公式，仅以一行回指把概率公式寄于第 16 章 16.2.4.8（第 1076 页，未入库，见 [[21-20未入库回指缺口]]），节内只给分位数记法 t_{α,m}（或 t_{α/2,m}）与一张分位数表。

## 构造与概率公式（16.2.4.8）

学生 t 分布（自由度 m）是由标准正态变量与独立 χ² 变量构造的抽样分布：如果随机变量 X 是 (0, 1) 正态随机变量，Y 与 X 相互独立且服从自由度 m = n−1 的 [[卡方分布]]，则随机变量

```
T = X / √(Y/m)        (16.96)
```

的分布称为自由度 m 的学生 t 分布或 t 分布，分布函数记 F_S(x)，密度函数记 f_S(t)：

```
f_S(t) = 1/√(m·π) · Γ((m+1)/2)/Γ(m/2) · 1/(1 + t²/m)^{(m+1)/2}        (16.97a)
F_S(x) = P(T ⩽ x) = ∫_{−∞}^{x} f_S(t) dt
       = 1/√(m·π) · Γ((m+1)/2)/Γ(m/2) · ∫_{−∞}^{x} dt/(1 + t²/m)^{(m+1)/2}        (16.97b)
```

## 期望和方差

```
E(T) = 0        (m > 1)        (16.98a)
D²(T) = m/(m−2)        (m > 2)        (16.98b)
```

注意本分布显式给出了矩存在的条件（m>1、m>2），而 [[费希尔F分布]] 的 (16.95a,b) 未给条件，体例不一（疑 F 处脱条件）。

## 分位数

### 定义（16.2.4.8）

t 分布的分位数 t_{α,m} 和 t_{α/2,m}（图 16.12(a)、(b)）满足

```
P(T > t_{α,m}) = α        (16.99a)
P(|T| > t_{α/2,m}) = α        (16.99b)
```

分别对应单侧与双侧临界值；其数值由第 1463 页表 21.20 给出（分位数的一般定义见 16.2.2.2 第 3 条，未入库，见 [[16-2-4未入库回指缺口]]）。

### 数值表（21.20 节）

- **记法**：t_{α,m} 为上侧分位数（单侧问题），t_{α/2,m} 用于双侧问题；表值一律为上侧分位数。双列标读法与表结构详见 [[学生t分位数表与双侧单侧双列标记法]]。
- **自由度网格**：m=1 至 30 逐值，继以 40、60、120、∞，共 34 行 × 6 列。
- **表族位置**：在第 21 章数值表族中，t 分布表继正态（21.17 Φ 表）、χ²（21.18）、泊松（21.16）之后，为又一张概率分布数值表。

## 提出者与适用场景

t 分布由 [[戈赛特]] 以笔名「学生」发表，适用于当样本容量较小时、且只能给出均值和标准差的估计的情形；其标准差 (16.98b) 不再依赖于从中取出样本的总体标准差。

## 自由度特例与极限（复算所得性质）

以下性质由 [[t分布m1m2闭式锚点与∞行Φ表互证复算]] 对 21.20 表逐格复算证实：

- **m=1：标准 Cauchy 特例**。t_{p,1}=cot(πp)，可精确复算首行（六格中五格吻合，唯 637.0 一格与闭式冲突，见 [[t表637-0疑为636-6之辨]]）。
- **m=2：有理闭式**。t_{p,2}=(1−2p)/√(2p(1−p))，可精确复算第二行。
- **m→∞：正态极限**。∞ 行即标准正态分位数 z_{0.05}、z_{0.025}、z_{0.01}、z_{0.005}、z_{0.001}、z_{0.0005}，与 [[标准正态分布数值表]]（21.17 节 Φ 表）互证；此极限也是 t 分布收敛于 [[标准正态分布]] 的表列体现。

## 与相邻分布的关系

- 与 [[χ²分布]] 的分位数记法 χ²_{α,m} 同族（均为「上侧概率 + 自由度」双下标记法），但 t 表另设双侧/单侧双列标，结构比较见 [[t分位数表与χ²分位数表列标结构比较]]。
- 复算锚点与 χ² 表的策略平行而位置互为镜像：χ² 表借 m=1 行（χ²_{α,1}=(z_{α/2})²）与 Φ 表互证（见 [[卡方m1m2闭式锚点与Φ表互证复算]]），t 表则借 m=∞ 行直接给出正态分位数。

## 已发现的表值问题
