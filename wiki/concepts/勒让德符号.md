# 勒让德符号 (a/p)

勒让德符号 (a/p) 是以奇素数 p 为「分母」、整数 a 为「分子」的取值 ±1 的数论记号，用来标记 a 是模 p 的[[concepts/二次剩余|二次剩余]]还是二次非剩余：a 是模 p 二次剩余时记 (a/p) = 1，是二次非剩余时记 (a/p) = −1（设置语境为 gcd(a, p) = 1）。它与性质组 E1–E6（特别是 [[concepts/二次互反律|二次互反律]]）构成一个完整的符号演算系统，是判定一般二次同余式可解性的核心工具。

## 性质组（式 5.257）

| 编号 | 内容 | 式号 |
|---|---|---|
| E1 | a ≡ b (p) ⟹ (a/p) = (b/p) | 5.257a |
| E2 | (1/p) = 1 | 5.257b |
| E3 | (−1/p) = (−1)^{(p−1)/2} | 5.257c |
| E4 | (ab/p) = (a/p)(b/p)；特别 (ab²/p) = (a/p) | 5.257d |
| E5 | (2/p) = (−1)^{(p²−1)/8} | 5.257e |
| E6 | 二次互反律：(p/q)(q/p) = (−1)^{((p−1)/2)·((q−1)/2)}（p、q 为不同奇素数） | 5.257f |

E1–E2 是良好定义与平凡值；E3、E5 是两条补充定律；E4 是完全乘性；E6 允许把分母与分子对换。演算流程见 [[methodology/勒让德符号化简流程]]。

## 演算算例（已复算）

$$(65/307) = (5/307)\cdot(13/307) = (2/5)\cdot(8/13) = (-1)^{\frac{5^2-1}{8}}\left(\tfrac{2^3}{13}\right) = -\left(\tfrac{2}{13}\right) = -(-1)^{\frac{13^2-1}{8}} = 1.$$

即 65 是模 307 的二次剩余。逐步复算见 [[findings/勒让德符号性质组与65-307算例]]。

## 用途

在式 (5.258b) 中，一般模 m = 2^α·p₁^{α₁}⋯p_t^{α_t}（gcd(a, m) = 1）的二次同余 x² ≡ a (m) 的可解性判据由条件组 a ≡ 1 (4)／a ≡ 1 (8) 与 (a/p₁) = … = (a/p_t) = 1 构成；解数公式见 [[findings/模2幂与一般模二次同余解数公式]]。
