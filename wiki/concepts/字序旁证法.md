# 字序旁证法

字序旁证法是利用**参考文献目按姓氏字顺排列**这一结构约束，为转写中脱落前缀的姓氏提供复原旁证的方法。原理：若某条目姓氏残段为 X，其在目录中的前后邻条目分别为 A 与 B，则完整姓氏必满足字典序 A < 姓氏 < B，从而把候选集约束到很小的区间。

## 判例（均出自本手册文献目）

- [21.6] "BNER, W." 夹于 GRADSTEIN 与 ISO 之间 → **GRÖBNER**（配书名 *Integraltafel* 佐证）。
- [4.6][14.9] "NICH, K." 分别夹于 FADDEJEW–KIELBASINSKI 与 JAHNKE–KNOPP 之间 → **JÄNICH**。
- [2.8] "CKER, H." 位于 SMIRNOW 之后 → **STÖCKER**（另有 [7.15] 同书 "STOCKER, H." 自证）。
- [10.3] "TZLER, R." 夹于 KLINGBEIL–KOSMOL 之间 → **KLÖTZLER**。
- [16.6] "Frsz, M." 夹于 BEYER–FRIEDRICH 之间 → **FISZ**（疑）。
- [14.16] "画， F." 夹于 ROTHE–SCHARK 之间、[19.24] "LIG, H." 夹于 LOCHER–MULANSKY 之间：区间已定而姓氏未定，转为待辨问题（[[queries/14-16作者画F身份之辨]]、[[queries/19-24作者LIG与STEFAN身份之辨]]）。

## 方法要点与局限

1. 字序仅约束**区间**，不唯一确定姓氏；最终复原须辅以书目学旁证（书名、出版社、年份、合作者）。
2. 值得注意的经验规律：本目脱落的前缀段几乎全部含变音符（GRÖ、JÄ、FÄ、KLÖ、PRÖ、MÜ、STÖ），提示变音符字符在转写环节整段丢失（[[findings/文献目姓氏前缀系统性脱落复算]]）。
3. 该方法可推广到任何按字顺编排的目录、索引与译名表的转写复原。
