# 向量积（叉积）

两个 [[concepts/向量]] $\vec a$ 和 $\vec b$ 的**向量积**或**叉积**是一个向量 $\vec c$，使得它垂直于 $\vec a$ 和 $\vec b$，并且 $\vec a,\vec b,\vec c$ 按顺序形成右手系（[[concepts/右手法则]]，图 3.119）。其模为
$$\lvert\vec c\rvert=\lvert\vec a\rvert\lvert\vec b\rvert\sin\varphi,\tag{3.249b}$$
即 $\vec c$ 的长度在数值上等于由 $\vec a$ 和 $\vec b$ 定义的**平行四边形的面积**。

（式 3.249a 转写为 $\vec a\times\vec b=\lvert\vec a\vec b\rvert=\vec c$，中间项与 3.249b 的关系不明，疑衍文，见 [[queries/式3-249a中间项与轴向量句是否原书损坏]]。）

## 代数性质

| 性质 | 公式 |
|---|---|
| 反交换律 | $\vec a\times\vec b=-(\vec b\times\vec a)$（式 3.251） |
| 与标量相乘满足结合律 | $\alpha(\vec a\times\vec b)=(\alpha\vec a)\times\vec b$（式 3.252b） |
| 分配律 | $\vec a\times(\vec b+\vec c)=\vec a\times\vec b+\vec a\times\vec c$（式 3.254b） |
| 二重向量积不满足结合律 | $\vec a\times(\vec b\times\vec c)\neq(\vec a\times\vec b)\times\vec c$（式 3.253b，展开见 [[concepts/二重向量积]]） |
| 自乘 | $\vec a\times\vec a=\vec 0$（式 3.257） |
| 共线判据 | $\vec a\times\vec b=\vec 0\iff\vec a\parallel\vec b$（$\vec a,\vec b\neq\vec 0$，式 3.256） |

## 坐标公式

- 笛卡儿：$\vec a\times\vec b=(a_yb_z-a_zb_y)\vec i+(a_zb_x-a_xb_z)\vec j+(a_xb_y-a_yb_x)\vec k=\begin{vmatrix}\vec i&\vec j&\vec k\\ a_x&a_y&a_z\\ b_x&b_y&b_z\end{vmatrix}$（式 3.265）；
- 仿射：需 [[concepts/互反基向量]]，$\vec a\times\vec b=\vec e_1\vec e_2\vec e_3\begin{vmatrix}\vec e^{1}&\vec e^{2}&\vec e^{3}\\ a^{1}&a^{2}&a^{3}\\ b^{1}&b^{2}&b^{3}\end{vmatrix}$（式 3.275）。

[[concepts/线性组合]] 的向量积可按多项式展开但交换因子须变号（例 B，经重算验证，见 [[findings/向量乘积定义性质与算例]]）。与 [[concepts/标量积]] 的对照见 [[comparisons/标量积与向量积性质比较]]；平行四边形面积应用见 [[findings/向量代数几何应用公式]]。
