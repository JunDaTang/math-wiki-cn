# 柯西积分公式

柯西积分公式（Cauchy integral formulas）是用解析函数在闭曲线边界上的值表示该函数在区域内点的值及其各阶导数值的一组积分表示式：若 f(z) 在一条简单闭曲线 C 及其内部的单连通区域上解析，则对每个内点 z，$f(z) = \frac{1}{2\pi\mathrm{i}}\oint_C \frac{f(\zeta)}{\zeta - z}\,\mathrm{d}\zeta$（C 逆时针）。它把「内部值」完全编码于「边界值」，并直接推出 [[concepts/解析函数的无穷可微性]]。

## 区域内点情形（14.2.3.1）

$$f(z) = \frac{1}{2\pi\mathrm{i}} \oint_C \frac{f(\zeta)}{\zeta - z}\,\mathrm{d}\zeta, \tag{14.42}$$

其中曲线 C 逆时针地被走过。利用这个公式，解析函数在一个区域内部的值被该函数在区域边界上的值所表示。从 (14.42) 即得该函数的 n 次导数的存在性及其积分表达式：

$$f^{(n)}(z) = \frac{n!}{2\pi\mathrm{i}} \oint_C \frac{f(\zeta)}{(\zeta - z)^{n+1}}\,\mathrm{d}\zeta. \tag{14.43}$$

推论：如果一个复函数是可微的（即解析的），那么它是无穷多次可微的——见 [[concepts/解析函数的无穷可微性]]。

## 区域外点情形（14.2.3.2）

如果一个函数 f(z) 在平面上一条闭积分曲线 C 的整个外部是解析的，那么 f(z) 在此外部区域中一点处的值及其各阶导数的值可以用相同的柯西公式 (14.42)、(14.43) 来给出，但是曲线 C 现在是顺时针方向（图 14.38）。两种情形的对照见 [[comparisons/柯西积分公式内点与外点情形比较]]。
