# 标量场

如果对于空间一个子集的每个点 $P$ 都指定一个数（标量值），则记为

$$U = U(P), \tag{13.6a}$$

并称其为**标量场**（scalar field）或标量点函数/标量函数。一个物体的温度、密度、位势等都是标量场的例子。把 $P$ 换为其相对于给定极点（原书 3.5.1.1，未入库）的位置向量，可写为

$$U = U(\vec{r}). \tag{13.6b}$$

## 特殊情形

- **平面场**：所论函数仅对空间中一个平面上的点有定义；
- **中心场**（见 [[中心场]]）：$U = f(|\vec{r}|)$；
- **轴向场**（见 [[轴向场]]）：值仅依赖离轴距离。

## 坐标表示

用点的坐标表示，一般地由一个三元函数给出：

$$U = \Phi(x,y,z),\qquad U = \Psi(\rho,\varphi,z)\qquad\text{或}\qquad U = \chi(r,\vartheta,\varphi), \tag{13.8a}$$

平面场用二元函数即可：$U = \Phi(x,y)$ 或 $U = \Psi(\rho,\varphi)$（13.8b）。一般假设这些函数连续，可能在个别点、曲线或曲面上间断。

中心场（坐标系原点取为场的极点）与轴向场（$z$ 轴取为场的轴）的约化形式：

$$U = U\big(\sqrt{x^2+y^2+z^2}\big) = U\big(\sqrt{\rho^2+z^2}\big) = U(r), \tag{13.9a}$$

$$U = U\big(\sqrt{x^2+y^2}\big) = U(\rho) = U(r\sin\vartheta). \tag{13.9b}$$

标量场的几何刻画见 [[等值面与等值线]]；与 [[向量场]] 的系统对照见 [[标量场与向量场比较]]。
