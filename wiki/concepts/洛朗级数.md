# 洛朗级数

洛朗级数（Laurent series）是同时含正幂项与负幂项的双向无穷幂级数展开。《数学手册》中，14.3「解析函数的幂级数展开」给出其在圆环域上的一般理论；15.4「Z变换」则在离散拉普拉斯变换与 Z变换的语境下，用该词指关于 $1/z$ 的幂级数（见下文「在 Z 变换中的角色」一节）。

## 圆环域上的展开定理

洛朗级数是在圆环域上解析的函数的双向无穷幂级数展开：每个在以 $z_0$ 为心、半径分别为 $r_1$ 和 $r_2$ 的两个同心圆周之间的圆环内部解析的函数，都可以被展开为一个广义幂级数

$$f(z) = \sum_{n=-\infty}^{\infty} a_n (z - z_0)^n = \cdots + \frac{a_{-k}}{(z - z_0)^k} + \cdots + \frac{a_{-1}}{z - z_0} + a_0 + a_1(z - z_0) + a_2(z - z_0)^2 + \cdots \tag{14.50a}$$

诸系数 $a_n$ 通常是复的，由公式

$$a_n = \frac{1}{2\pi\mathrm{i}} \oint_C \frac{f(\zeta)}{(\zeta - z_0)^{n+1}} \mathrm{d}\zeta \quad (n = 0, \pm 1, \pm 2, \dots) \tag{14.50b}$$

唯一确定，其中 $C$ 是圆环中一条任意的闭曲线，半径为 $r_1$ 的圆在其内部，方向逆时针（图 14.43）。

> **转写注记**：转写文本此处圆环条件作 $r_1 < |z| < r_2$，疑缺 $-z_0$，见 [[式14-50b圆环条件疑缺z减z0]]。

在一般复分析教材中，洛朗级数亦指这类在环形域上展开、同时含正幂项与负幂项的二重级数 $\sum_{n=-\infty}^{\infty}c_n(z-z_0)^n$，用于处理解析函数在孤立奇点附近的展开。

## 收敛域

如果函数 $f(z)$ 的定义域大于该圆环，那么其洛朗级数的收敛域是以 $z_0$ 为心、整个包含在定义域中的最大圆环。

## 圆环算例：$f(z) = \frac{1}{(z-1)(z-2)}$

在围绕 $z_0 = 0$ 的圆环 $1 < |z| < 2$ 中（$f$ 在此解析），先分解部分分式 $f(z) = \frac{1}{z-2} - \frac{1}{z-1}$；由 $|1/z| < 1$ 与 $|z/2| < 1$，两项都可写为在整个圆环中绝对收敛的几何级数之和：

$$f(z) = -\sum_{n=1}^{\infty} \frac{1}{z^n} - \frac{1}{2}\sum_{n=0}^{\infty} \left(\frac{z}{2}\right)^n = \sum_{n=-\infty}^{\infty} a_n z^n, \quad a_n = \begin{cases} -1, & n = -1, -2, \dots \\ -\dfrac{1}{2^{n+1}}, & n = 0, 1, 2, \dots \end{cases}$$

求解流程见 [[圆环上洛朗展开的部分分式几何级数法]]。

## 与奇点、留数的联系

洛朗级数的负幂部分（主部）是孤立奇点分类的判据（[[解析函数的奇点]]，式 (14.51)–(14.52)）；$(z - z_0)^{-1}$ 的系数 $a_{-1}$ 即 [[留数]]。与 [[泰勒级数]] 的系统比较见 [[泰勒级数与洛朗级数比较]]；复算见 [[式14-50a至14-50b洛朗级数及圆环算例转录复算]]。

## 在 Z 变换中的角色（15.4）

### 术语用法：关于 $1/z$ 的幂级数

在《数学手册》15.4 中，「洛朗级数」指**关于 $1/z$ 的幂级数**（即以 $z$ 的负幂出现的级数）：离散拉普拉斯变换 $\mathcal{D}\{f_n\}=\sum f_ne^{-np}$ 经代换 $e^p=z$ 后「表示关于 $1/z$ 的幂级数，即所谓的洛朗级数」（源文回指第 981 页 14.3.4）。

### Z变换作为洛朗级数

Z变换 $F(z)=\sum_{n=0}^{\infty}f_n(1/z)^n$（式 15.105）本质上是洛朗级数（在区域 $|z|>1/R$ 上收敛），其收敛理论整体移植自复幂级数（14.3.1.3，见 [[复项幂级数]]、[[收敛圆与收敛半径]]）。

### Z逆变换方法之二：由 $1/z$ 的展开式读出原序列

若 $F(z)$ 关于 $1/z$ 的级数展开式已知或可求出，则可按定义 (15.105) 直接读出原序列。例（式 15.129）：

$$F(z)=\frac{2z}{(z-2)(z-1)^2}=\frac{2}{z^2}+\frac{8}{z^3}+\frac{22}{z^4}+\frac{52}{z^5}+\frac{114}{z^6}+\dots$$

读出 $f_0=f_1=0,\ f_2=2,\ f_3=8,\ f_4=22,\dots$（但一般项无闭式表达）。
