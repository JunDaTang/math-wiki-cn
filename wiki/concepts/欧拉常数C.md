# 欧拉常数C

欧拉常数 C 是《数学手册(原书第10版)》21.1 节常用数学常数表中的一个条目：本手册以大写拉丁字母 C 为记号，表载值 C = 0.577215665···，名称栏标注「欧拉常数 (C)」。

独立可验证背景：现代数学文献通称该常数为 Euler–Mascheroni 常数，记作希腊字母 γ，其值约为 0.5772156649…；本源文档仅使用 C 记号，未出现 γ。下文的记号对照即为此背景与源文档记法之间的衔接而设。

## 表载值与核对

C = 0.577215665···。复算参考值为 0.57721566490153…，表载 9 位小数舍入正确，见 [[21-1常用数学常数数值转录复算]]。该条目所属全表见 [[常用数学常数]]。

## 记号对照：本手册之 C 与通行之 γ

本手册记 C，现代通行记 γ。这是记号差异而非数值矛盾。待手册后续章节（级数、Γ 函数等主题）入库时，若出现 γ 记法或对该常数的其他表述，应回指本页并注明两记号同指一常数，避免与使用 γ 记法的其他来源发生表面冲突。

## 与欧拉数 e 之区分

「欧拉数 (e)」与「欧拉常数 (C)」是两个不同的常数，仅共享命名人欧拉之名：

- 欧拉数 e = 2.718281828···，自然对数的底；
- 欧拉常数 C = 0.577215665···，即本页所述常数。

任何关于其中一个常数的数值或性质主张，不得转移或混称至另一个。
