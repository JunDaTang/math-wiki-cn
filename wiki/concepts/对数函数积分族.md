# 对数函数积分族（465–487）

对数函数积分族是 [[sources/10-数学手册原书第10版--13-2174-其他超越函数积分--17odu4w|数学手册 21.7.4.3]] 收录的一组含 $\ln x$ 的不定积分公式，编号 465–487，涵盖 $(\ln x)^n$ 的幂次递推、$\frac{1}{\ln x}$ 的级数、$x^m(\ln x)^n$ 全族、$\ln\sin/\cos/\tan$ 的伯努利级数积分以及 $\sin\ln x$、$\cos\ln x$，并在 469 注文引出对数积分 Li(x)（[[concepts/指数积分与对数积分]]）。

## 公式构成

1. **$(\ln x)^n$**（465–468）：前三式显式（465/466 脱号；第三式原文误标「461」，疑为 467，见 [[queries/对数节编号461疑为467及463至466脱落之辨]]）；递推
   $$\int(\ln x)^n dx = x(\ln x)^n - n\int(\ln x)^{n-1}dx \quad (n\neq -1).$$
2. **$\frac{1}{\ln x}$**（469–470、478–481）：级数 $\ln\ln x + \ln x + \frac{(\ln x)^2}{2\cdot 2!}+\cdots$（469）；递推 470；478 $\int\frac{dx}{x\ln x} = \ln\ln x$；479 $\int\frac{dx}{x^n\ln x}$ 的交错级数；480/481 幂次递推。
3. **$x^m(\ln x)^n$**（471–477）：471 显式（$m\neq -1$）；472 双参数递推（$m\neq -1,\ n\neq -1$）；473 $\int\frac{(\ln x)^n}{x}dx = \frac{(\ln x)^{n+1}}{n+1}$（转写脱条件 $n\neq -1$，$n=-1$ 情形即 478）；474/475（475 脱号）负幂递推；476 代换式 $y = -(m+1)\ln x$ 回指 451；477 递推。
4. **$\ln\sin/\cos/\tan$ 的伯努利级数积分**（482–484）：
   $$\int\ln\sin x\,dx = x\ln x - x - \frac{x^3}{18} - \frac{x^5}{900} - \cdots - \frac{2^{2n-1}B_n x^{2n+1}}{n(2n+1)!} - \cdots$$
   $$\int\ln\cos x\,dx = -\frac{x^3}{6} - \frac{x^5}{60} - \frac{x^7}{315} - \cdots - \frac{2^{2n-1}(2^{2n}-1)B_n}{n(2n+1)!}x^{2n+1} - \cdots$$
   $$\int\ln\tan x\,dx = x\ln x - x + \frac{x^3}{9} + \frac{7x^5}{450} + \cdots + \frac{2^{2n}(2^{2n-1}-1)B_n}{n(2n+1)!}x^{2n+1} + \cdots$$
5. **$\sin\ln x$ / $\cos\ln x$**（485/486）：$\frac{x}{2}(\sin\ln x \mp \cos\ln x)$。
6. **末式 $e^{ax}\ln x$**（疑 487，与 458 逐字全同，见 [[queries/21-7-4末式与458重复之辨]]）。

## 伯努利系数与紧缩编号约定

482–484 的通项系数（$x^3/18$、$x^5/900$；$x^3/6$、$x^5/60$、$x^7/315$；$x^3/9$、$7x^5/450$）恰在手册紧缩伯努利编号约定（$B_1 = 1/6$、$B_2 = 1/30$、$B_3 = 1/42$，见 [[concepts/伯努利数与欧拉数（手册紧缩编号约定）]]）下自洽，构成该约定在积分侧的反向印证（[[findings/21-7-4超越函数积分全表微分复算]]）。三式分别是 [[concepts/对数函数级数展开]] 中 $\ln\sin x$、$\ln\cos x$、$\ln\tan x$ 级数的逐项积分，级数与积分两个方向互为印证；482 注文回指第 623 页 7.2.4.2（伯努利数出处，转写「示」脱「表」字）。

## 校勘状态

本族是 21.7.4 转写讹误最密集的小节：首两式脱号、「461」编号讹、475/484 脱号、末式疑重出；另 473 脱条件。各式数学内容（含复原编号后的归属）经微分复算通过。
