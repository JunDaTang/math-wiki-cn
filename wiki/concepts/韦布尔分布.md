# 韦布尔分布

**韦布尔分布**（参数 α, β，α > 0, β > 0）是可靠性理论中的核心连续分布：称连续随机变量服从参数为 α 和 β 的韦布尔分布，如果其密度函数是

```
f(t) = { 0,  t < 0;
       (α/β)·(t/β)^{α−1}·exp[−(t/β)^α],  t ⩾ 0 }        (16.82a)
```

其分布函数为

```
F(x) = { 0,  x < 0;   1 − exp[−(x/β)^α],  x ⩾ 0 }        (16.82b)
```

## 参数 taxonomy

- **α 是形状参数**，**β 是尺度参数**（图 16.8、16.9）；
- 引入**位置参数 γ** 后得到三参数形式，其分布函数为

```
F(x) = 1 − exp[−((x−γ)/β)^α]        (16.85)
```

## 期望和方差

```
μ = β·Γ(1 + 1/α),   σ² = β²·[Γ(1 + 2/α) − Γ²(1 + 1/α)]        (16.83)
```

其中 Γ(x) 即 [[Γ函数]]：

```
Γ(x) = ∫_{0}^{∞} t^{x−1}·e^{−t} dt,   x > 0        (16.84)
```

（已复核：(16.83) 与标准韦布尔矩公式一致。原文此处「r(x) 表示 函数」为「Γ(x) 表示 Γ 函数」之转写讹误；Γ 函数一节的原文回指「第 682 8.2.5, 6.」未入库，见 [[16-2-4未入库回指缺口]]。）

## 与指数分布的关系

α=1 且 λ=1/β 时，韦布尔分布即为 [[指数分布]]（原文此处转写作「a=l」，系「α=1」之讹；已复核 (16.82a) 在 α=1 时退化为 (1/β)e^{−t/β}）。

## 应用

韦布尔分布在可靠性理论中特别有用，比如可以极灵活地描述建筑构件的系统寿命。
