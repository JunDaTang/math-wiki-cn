# 线性方程组求解命令（Array、Thread、LinearSolve、NullSpace、RowReduce）

Mathematica 将 [[concepts/Mathematica列表与向量矩阵表示]] 的矩阵概念应用于线性方程组理论（理论背景回指第 412 4.5.2）。源称矩阵概念定义于「第 1333 20.2.4」，但按本书结构矩阵作为列表应为 20.2.5（见 [[queries/20-3两处回指错位之辨]]）。以下命令中 m、n 表示已知整数而非变元。

## 符号矩阵与向量（式 20.30–20.32）

```text
P = Array[p, {m, n}]                  元素 pij = p[[i,j]] 的 (m,n) 型矩阵
X = Array[x, {n}],  B = Array[b, {m}]   n 维与 m 维向量
P.X == B   P.X == 0   或   Thread[P.X == B]   Thread[P.X == 0]
```

Array 生成以 p[i,j] 等符号为元素的矩阵/向量，一般的齐次或非齐次线性方程组由此写成矩阵—向量形式。

## 特殊情形 n = m, det P ≠ 0

非齐次方程组具有唯一解，可直接由 X = Inverse[P].B（式 20.33）确定；LinearSolve[P, B] 将**更快地**得到一个等价的解。源断言：Mathematica 可以在合理的时间内（依赖于计算机系统）处理具有最多约 5000 个左右未知数的这种方程组（版本时代断言，源内不可检验）。

## 一般情形

使用命令 LinearSolve 与 NullSpace 可以处理所有可能的情形：可以首先确定是否存在任何解，如果存在，则将它计算出来。RowReduce 用于了解有几个方程左边是独立的（判秩）。

- 例 A（齐次，非平凡解）：NullSpace[p] 给出零空间基 {{−1,−2,0,1},{−3,7,2,0}}，通解为基向量的任意线性组合；Det[p] = 0。
- 例 B（无解）：LinearSolve[m1, b1] 回答 LinearSolve::nosol（Linear equation encountered which has no solution），于是输入作为输出显示。
- 例 C（唯一解）：RowReduce[m2] = {{1,0,0},{0,1,0},{0,0,1},{0,0,0}}（秩 3），LinearSolve[m2, b2] = {10/7, −1/7, −2/7}。
