# 代数式

**代数式**（原文亦称**项**）是把一个或多个代数量（如数字或符号）用 +、-、·、:、√ 等运算符号连接起来，并通过各类括号确定运算顺序所得到的式子。该定义出自《数学手册(原书第10版)》1.1.5 节，是初等代数中最基础的表达式概念；[[concepts/恒等式]]、[[concepts/方程]] 与 [[concepts/恒等变换]] 均以它为基底。

## 分类

代数式的分类取决于对**基本量**（见 [[concepts/基本量]]）进行运算的类型，由紧到宽分为四级：

| 类别 | 允许对基本量的运算 |
|------|--------------------|
| 整有理式 | 加法、减法、乘法、非负整数次幂 |
| 有理式 | 上述运算，另加除法（除以整有理式），基本量的指数也可为负整数 |
| 无理式 | 包含根式，即整有理式的非整有理次幂 |
| 超越式 | 包含基本量的指数式、对数式或三角式 |

四类的逐维对比与层级关系见 [[comparisons/代数式分类比较]]。

## 相关概念

- [[concepts/恒等式]] 与 [[concepts/方程]]：两个代数式之间相等关系的两种情形，判定标准是等式成立的取值范围。
- [[concepts/恒等变换]]：把代数式变换为与之恒等的代数式，是贯穿后续计算的变形手段。
