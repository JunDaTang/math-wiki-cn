# 矩阵树定理

矩阵树定理（本手册称「矩阵生成树定理」）是用行列式计算图的生成树个数的定理：设 G = (V, E) 是一个图，其中 V = {v₁, v₂, …, v_n}（n > 1）、E = {e₁, e₂, …, e_m}，构造次数矩阵 D 与容许矩阵 L = D − A，则去掉 L 的第 i 行和第 i 列得到矩阵 L_i，L_i 的行列式等于图 G 的生成树的个数。

## 次数矩阵与容许矩阵

定义 (n, n) 型矩阵 D = (d_ij)（式 5.323a）：

```
d_ij = 0        (i ≠ j)
d_ij = d_G(v_i) (i = j)
```

称它为**次数矩阵**（对角元为各顶点的次数 d_G(v_i)，见 [[concepts/顶点次数与正则图]]）。次数矩阵和邻接矩阵（[[concepts/邻接矩阵]]）的差是 G 的**容许矩阵** L（式 5.323b）：

```
L = D − A
```

**译名注记**：「容许矩阵」并非通行术语；矩阵 L = D − A 通称为图的拉普拉斯矩阵（Laplacian matrix）或基尔霍夫矩阵，本定理因此也常称基尔霍夫定理 / Matrix-Tree 定理。（此段为可独立验证的通行背景；本节原文未提基尔霍夫之名，仅称「矩阵生成树定理」。）译名来源待查，见 [[queries/容许矩阵译名是否应为拉普拉斯矩阵]]。

（通行的陈述为：删去任意的第 i 行及对应列，所得行列式都相等且等于生成树个数；手册只写「第 i 行和第 i 列」，此差别为通行背景注记。）

## 地位

本定理是 5.8.3 定量结果中最重的一条：[[concepts/凯莱定理]] 只覆盖完全图，而矩阵树定理把生成树计数化为一次 (n−1)×(n−1) 行列式，适用于按多重图约定（自环、重边）理解的一般图。
