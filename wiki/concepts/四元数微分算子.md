# 四元数微分算子（∇_Q 与 D）

四元数微分算子是把向量分析的 ∇ 算子嵌入四元数演算所得的微分算子：空间版 ∇_Q = i ∂/∂x + j ∂/∂y + k ∂/∂z（式 4.166）与时空版 D = ∂/∂t + ∇_Q（式 4.169a）。其核心功效有二：一次四元数乘法同时给出向量场的散度与旋度——∇_Q v̲ = −div v⃗ + rot v⃗（式 4.168）；∇_Q 与 D 和各自的共轭复合可分解三维与四维拉普拉斯算子（∇_Q∇̄_Q = Δ₃、DD̄ = Δ₄，式 4.170）。《数学手册（原书第10版）》4.4.3.5 称 ∇_Q 恰如 ∇ 一样，常称为**狄拉克（Dirac）**或**柯西–黎曼（Cauchy–Riemann）算子**。

## 公式

```latex
∇_Q = i ∂/∂x + j ∂/∂y + k ∂/∂z                                             (4.166)

v̲(x,y,z) = v₁(x,y,z) i + v₂(x,y,z) j + v₃(x,y,z) k                        (4.167)

∇_Q v̲ = −∇·v⃗ + ∇×v⃗ = −div v⃗ + rot v⃗                                      (4.168)

D = ∂/∂t + i ∂/∂x + j ∂/∂y + k ∂/∂z                                        (4.169a)

w(t,x,y,z) = w₀ + w₁ i + w₂ j + w₃ k = w₀ + w̲        (转写误标为 "(4.16)") (4.169b)

D w = ∂w₀/∂t − div w̲ + rot w̲ + grad w₀          [疑脱落 ∂w̲/∂t 项]        (4.169c)

∇_Q ∇̄_Q f = ∇̄_Q ∇_Q f = Δ₃ f                                              (4.170a)
∇_Q ∇_Q f = −Δ₃ f                                                         (4.170b)
D D̄ f = D̄ D f = ∂²f/∂t² + Δ₃ f = Δ₄ f                                     (4.170c)
```

（rot 即旋度 curl；Δ₃、Δ₄ 分别为 ℝ³、ℝ⁴ 的拉普拉斯算子。）

## 关键性质

- **统一散度与旋度**：式 (4.168) 表明 ∇_Q 作用于纯四元数向量场时，标量部分给出 −div、向量部分给出 rot——由四元数乘法法则 (4.109b) 直接展开。
- **拉普拉斯分解**：∇_Q∇̄_Q = ∇̄_Q∇_Q = Δ₃（带符号版本 ∇_Q∇_Q = −Δ₃）；DD̄ = D̄D = ∂ₜ² + Δ₃ = Δ₄。拉普拉斯算子由此可「开方」为一次四元数一阶算子。
- 式 (4.168)、(4.170a–c) 经分析者独立验证成立；**唯一例外**是 (4.169c)：由 (4.169a)/(4.169b) 直接展开应得 Dw = ∂ₜw₀ − div w̲ + **∂ₜw̲** + rot w̲ + grad w₀，疑转写脱落 ∂w̲/∂t 项（见 [[queries/式4-169c是否脱落时间偏导项]]）。
