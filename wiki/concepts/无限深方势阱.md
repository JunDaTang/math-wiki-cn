# 无限深方势阱（方块中的自由运动）

无限深方势阱（手册 9.2.4.5 称「粒子在一方块中的自由运动」）是质量 m 的粒子在边长分别为 a、b、c 且墙壁不可穿透的方块（三维长方体盒）中自由运动的模型：因墙壁不可穿透，如同三个方向都是无穷高的盒壁——粒子出现在盒子外的概率为零，波函数在盒子外亦为零。

## 问题的表述（9.132）

```latex
\frac{\partial^{2}\Psi}{\partial x^{2}}+\frac{\partial^{2}\Psi}{\partial y^{2}}+\frac{\partial^{2}\Psi}{\partial z^{2}}+\frac{2m}{\hbar^{2}}E\Psi=0   % 9.132a（亥姆霍兹型）
\Psi=0\quad(x=0,a;\ y=0,b;\ z=0,c)   % 9.132b
```

## 分离变量与量子化（9.133–9.134）

- 设 Ψ = Ψₓ(x)Ψ_y(y)Ψ_z(z)（9.133a），每一项仅依赖一个独立变量，归结为三个常微分方程（9.133c），分离常数满足 kₓ²+k_y²+k_z² = B 且 E = (ℏ²/2m)(kₓ²+k_y²+k_z²)（9.133d,e）。
- 边界条件要求 sin kₓa = sin k_yb = sin k_zc = 0（9.134b），故 kₓ = πnₓ/a 等（9.134c），n 为整数；能级

```latex
E_{n_x,n_y,n_z}=\frac{\hbar^{2}}{2m}\Big[\Big(\frac{n_x}{a}\Big)^{2}+\Big(\frac{n_y}{b}\Big)^{2}+\Big(\frac{n_z}{c}\Big)^{2}\Big]   % 9.134d
\Psi_{n_x,n_y,n_z}=\sqrt{\frac{8}{abc}}\sin\frac{\pi n_xx}{a}\sin\frac{\pi n_yy}{b}\sin\frac{\pi n_zz}{c}                            % 9.134f
```

（归一化复算：∫₀ᵃsin²(πnₓx/a)dx = a/2，三重积分为 abc/8，故系数 √(8/abc)，✓。）
- 由此，粒子通过与其他粒子交换能量导致的能量改变是不连续的——只在量子系统中发生；nₓ、n_y、n_z 属于能量的本征值，称为量子数。
- 结点平面（9.134g）：存在垂直于 x/y/z 轴的 nₓ−1、n_y−1、n_z−1 个 Ψ = 0 平面。

## 立方体的特殊情形：退化（简并）

a = b = c 时，不同的线性无关本征函数可描述相同能量的态（当 nₓ²+n_y²+n_z² 相同）——退化态（degenerate states，通行译「简并态」）；i 个态有相同能量称 i 折叠退化（i-fold degeneracy，i 重简并）。源文称量子数「跑遍除了零之外的所有实数」，按 9.134c 上下文应为整数，见 [[queries/方盒量子数应为整数而非实数]]。

## 零点平移能（9.134h）

E₀ = (ℏ²/2m)(1/a² + 1/b² + 1/c²)——即使温度达到绝对零度粒子能量仍保持有限，见 [[concepts/零点能]]。
