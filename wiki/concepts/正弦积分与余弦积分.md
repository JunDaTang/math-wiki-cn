# 正弦积分与余弦积分

正弦积分与余弦积分是由 $\frac{\sin t}{t}$ 与 $\frac{\cos t}{t}$ 定义的半轴特殊函数。《数学手册(原书第10版)》在两处给出其定义：21.7.3 三角函数积分表（条目 283、322）与 21.14 傅里叶变换。

## 定义

### 21.7.3 三角函数积分表（条目 283、322）

21.7.3 在条目 283、322 处顺带给出其定义与幂级数：

```latex
% 283：正弦积分（原文记作 si(x)）
\mathrm{si}(x) = \int_0^x \frac{\sin t}{t}\,\mathrm{d}t = x - \frac{x^{3}}{3\cdot 3!} + \frac{x^{5}}{5\cdot 5!} - \frac{x^{7}}{7\cdot 7!} + \cdots

% 322：余弦积分
\operatorname{Ci}(x) = -\int_x^\infty \frac{\cos t}{t}\,\mathrm{d}t = C + \ln x - \frac{x^{2}}{2\cdot 2!} + \frac{x^{4}}{4\cdot 4!} - \frac{x^{6}}{6\cdot 6!} + \cdots
```

其中不定积分的原函数级数为 ∫sin ax/x dx = ax − (ax)³/(3·3!) + (ax)⁵/(5·5!) − ⋯ 与 ∫cos ax/x dx = ln(ax) − (ax)²/(2·2!) + ⋯；C 为 [[欧拉常数C]]（原文注明「参见第 681 8.2.5, 2.」，脱「页」字）。

### 21.14 傅里叶变换中的照录定义

手册 21.14 的定义（照录，回指第 681 页 8.2.5, 1.、2.，本转录两处脱「页」字）：

$$\mathrm{Si}(x)=\int_0^x\frac{\sin t}{t}\,dt,\qquad \mathrm{si}(x)=-\int_x^\infty\frac{\sin t}{t}\,dt=\mathrm{Si}(x)-\frac{\pi}{2},$$

$$\mathrm{Ci}(x)=-\int_x^\infty\frac{\cos t}{t}\,dt.$$

两处给出的 $\operatorname{Ci}(x)$ 定义一致；正弦积分的记法在两处有出入——21.7.3 条目 283 将 $\int_0^x\frac{\sin t}{t}\,dt$ 记作小写 $\mathrm{si}(x)$，而 21.14 的定义区分大小写（见下节「记法之辨」）。

## 记法之辨

各记号的积分定义与出处汇总：

| 记号 | 积分定义 | 出处 / 约定 |
| --- | --- | --- |
| $\mathrm{Si}(x)$ | $\int_0^x \frac{\sin t}{t}\,dt$ | 21.14 照录定义；外部通行约定相同 |
| $\mathrm{si}(x)$ | $-\int_x^\infty \frac{\sin t}{t}\,dt=\mathrm{Si}(x)-\frac{\pi}{2}$ | 21.14 照录定义；外部通行约定（补余积分）相同 |
| $\mathrm{si}(x)$（21.7.3 条目 283） | $\int_0^x \frac{\sin t}{t}\,dt$ | 21.7.3 原文记法；对应通行约定的大写 $\mathrm{Si}(x)$，与第 681 页 8.2.5 原书记法是否一致待查 |
| $\operatorname{Ci}(x)$ | $-\int_x^\infty \frac{\cos t}{t}\,dt$ | 21.7.3 条目 322 与 21.14，两处一致 |

### si 与 Si：相差 π/2 的大小写

小写 $\mathrm{si}$ 与大写 $\mathrm{Si}$ 相差常数 $\frac{\pi}{2}$，这一记号差别承载实际数值。21.14 约二十条表值用到 $\mathrm{Si},\mathrm{si},\mathrm{Ci}$（如 21.14.1 的 3、7、8、26、28–31 号，21.14.2 的 4、5、10、11、13、31、34、35、37、39、41、43、44 号）。

### 21.7.3 条目 283 的记法疑点

原文将 $\int_0^x \frac{\sin t}{t}\,dt$「写作 si(x)」（小写）。可独立查证的外部通行约定为：大写 $\mathrm{Si}(x)=\int_0^x \frac{\sin t}{t}\,dt$，小写 $\mathrm{si}(x)$ 指补余积分 $\mathrm{Si}(x)-\frac{\pi}{2}$。本源定义对应大写 $\mathrm{Si}(x)$ 却记作小写，与第 681 页 8.2.5 原书记法是否一致待查（[[si与Si记法之辨]]）。

### 21.14 表值转写中的 sin 与 si 形近并存

> 转写中 $\sin$ 与 $\mathrm{si}$ 形近，而 7/8/28/29 号又确有 $\sin(a\omega)\,\mathrm{Ci}(a\omega)$ 型真值、21.14.2-38 号的 $\frac{\pi}{\omega}\sin(a\omega)$ 亦真——**同形异义并存，须逐条裁定**：35 号 $-2\pi\sin(a\omega)$ 疑为 $-2\pi\,\mathrm{si}(a\omega)$，见 [[21-14-1之35负2πsin疑为si复算]]、[[21-14-1之35sin与si之辨]]。

## 关联与回指

### 与级数族的关联（21.7.3）

$\mathrm{si}(x)$ 与 $\operatorname{Ci}(x)$ 的幂级数是 [[三角函数幂级数展开]] 级数族在 21.7.3 中的新增成员；$\operatorname{Ci}(x)$ 的常数项 $C$ 使 [[欧拉常数C]] 在积分表中再次出现。二者与 290/329/413/414/422/423 六条以特殊数通项表出的级数积分同属 21.7.3 本节的「级数积分」层（[[伯努利与欧拉数级数积分比较]]）。
