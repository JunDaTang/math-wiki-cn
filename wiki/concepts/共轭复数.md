# 共轭复数

两个复数 z 与 z* 称为共轭复数，若其实部相等、虚部互为相反数（式 1.135a）：

Re(z*) = Re(z)，Im(z*) = −Im(z)

通常也使用记号 z̄ 代替 z*。在三种表示形式下（式 1.135b/c）：

z = a + ib = ρ(cos φ + i sin φ) = ρ e^{iφ}
z* = a − ib = ρ(cos φ − i sin φ) = ρ e^{−iφ}

## 几何解释

共轭复数对应的点在[[concepts/高斯平面]]上关于实轴对称；两者有相同的绝对值，[[concepts/复数的模与辐角|辐角]]仅相差一个符号。

## 代数性质

- z + z* 总是实数；z − z* 是纯虚数（手册 1.5.3.1 的表述。严格地说，当 Im(z) = 0 时 z − z* = 0，并非纯虚数——手册为宽松表述）。
- zz* = |z|² = a² + b²，依据是乘积 (a + ib)(a − ib) = a² + b² 为实数（式 1.139）。源文此处写作 "zz* = p² = |z|² = a² + b²"，其中 p 与全节统一的模记号 ρ 不符，疑为排印之误，见 [[queries/式1.137节zz星号等于p平方中p是否为ρ排印之误]]。

## 主要应用：分母实数化

两个复数相除时，对分子分母同乘除数的共轭复数，即可把分母的虚部去掉——其依据正是 (1.139)：分母化为实数 a² + b²（手册 1.5.3.4）。
