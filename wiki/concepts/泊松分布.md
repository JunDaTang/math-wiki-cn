# 泊松分布

**泊松分布**（Poisson distribution）是取值于非负整数的离散概率分布：若随机变量 X 的可能取值为 k=0,1,2,…，且

$$P(X=k) = \frac{\lambda^k}{k!}\,e^{-\lambda}, \qquad k = 0,1,2,\dots;\ \lambda > 0, \qquad (16.68)$$

则称 X 服从参数为 λ 的泊松分布（原文「参数为入」之「入」为 λ 的转写讹误，见[[16-2-3全节系统性转写讹误清单]]）。分布以法国数学家 Siméon Denis Poisson 命名（此为通行命名背景，本手册源文件中未出现其人）。

## 基本性质

### 期望与方差（等散布性）

$$E(X) = \lambda, \qquad (16.69a) \qquad D^2(X) = \lambda. \qquad (16.69b)$$

期望与方差相等且同为 λ（**等散布性**），这是泊松分布的标志性特征，也是判断经验数据是否适用泊松模型的常用判据。手册德式记号：**D(X) 为标准差、D²(X) 为方差**。

### 递推公式

$$P(X=k+1) = \frac{\lambda}{k+1}\, P(X=k). \qquad (16.69c)$$

从 P(X=0)=e^{−λ} 出发可逐点算出整个分布列；该递推已经独立验证（见[[式16-68至16-69c泊松分布定义性质与二项联系转录复算]]）。手册 21.16 数值表内部亦验证：k=0 行 P(0;λ)=e^{−λ} 于全部 18 列吻合，列内递推 P(k+1)/P(k)=λ/(k+1) 自洽。

### 众数（整数 λ 时双众数）

相邻比值在 k = λ−1 处等于 1，故 λ 为正整数时 P(λ−1) = P(λ)，分布呈双众数；21.16 数值表 λ=1…9 九列全部验证成立（详见[[整数λ双众数恒等式与k0行e负λ复算]]）。λ 非整数时唯一众数位于 ⌊λ⌋（标准性质，非本表检验对象）。

### 归一性

Σ_k P(k;λ) = 1。21.16 表截尾后各列和应在舍入误差内逼近 1——此为[[概率分布表交叉复算法]]新启用的检验维度。

### 与伽马函数的关系

k! = Γ(k+1)，故 P(k;λ) = λ^k e^{−λ}/Γ(k+1)，与[[伽马函数]]在阶乘值上相通。

### 独立随机变量之和（可加性）

若 X₁ 与 X₂ 相互独立，分别服从参数为 λ₁、λ₂ 的泊松分布，则 X=X₁+X₂ 服从参数为 λ=λ₁+λ₂ 的泊松分布。注意：此处手册明确声明了独立性，而[[二项分布]]的可加性条目未声明，体例不一致。

## 与二项分布的联系

对参数为 (n,p) 的二项分布，当 n→∞、p→0 且乘积 np=λ 保持常数时，其极限即为泊松分布；故对满足 λ=np 的大 n 与小 p，泊松分布是二项分布的良好逼近（[[二项分布的泊松逼近]]），实际中因泊松分布更易于计算而常被采用。手册给出的实用判据为 p ≤ 0.08 且 n ≥ 1500p（转写存疑，见[[泊松逼近条件n不小于1500p之辨]]）。

## 应用

连续情形下点状不连续事件独立发生的次数通常可用泊松分布描述，手册举例：特定时间段内到商店的顾客人数、一本书中印刷错误的个数、放射性衰变率等。
