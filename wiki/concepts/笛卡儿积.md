# 笛卡儿积

两个集合的**笛卡儿积**定义为

$$A \times B = \{(a, b) \mid a \in A \land b \in B\} \tag{5.65a}$$

$A \times B$ 的元素 $(a, b)$ 称为**有序对**，本源给出的刻画为

$$(a, b) = (c, d) \Leftrightarrow a = c \vee b = d \tag{5.65b}$$

⚠️ 式 (5.65b) 的 $\lor$ 疑应为 $\land$：按原文则 $(1,2) = (1,3)$ 成立，与同节 $A \times B \neq B \times A$ 的算例直接冲突（见 [[queries/式5-65b有序对相等应为合取吗]]）。

两个有限集的笛卡儿积的元素个数满足乘法公式：

$$\operatorname{card}(A \times B) = (\operatorname{card} A)(\operatorname{card} B) \tag{5.65c}$$

**例 A**（已核对）：对 $A = \{1,2,3\}$、$B = \{2,3\}$，

$$A \times B = \{(1,2),(1,3),(2,2),(2,3),(3,2),(3,3)\},$$
$$B \times A = \{(2,1),(2,2),(2,3),(3,1),(3,2),(3,3)\},$$

且 $\operatorname{card} A = 3$、$\operatorname{card} B = 2$、$\operatorname{card}(A \times B) = \operatorname{card}(B \times A) = 6$——基数相同但两集合不相等。

**例 B**：$x, y$ 平面的每个点可用笛卡儿积定义：$\mathbb{R}^2 = \mathbb{R} \times \mathbb{R} = \{(x,y) \mid x \in \mathbb{R}, y \in \mathbb{R}\}$（见 [[entities/数集记号]]）。

**n 元组与 n 重积**：固定序列的一种次序，可由 $n$ 个元素定义有序 $n$ 元组 $(a_1, a_2, \dots, a_n)$，$a_i$ 称为第 $i$ 个分量；$n = 3, 4, 5$ 时分别称为三元组、四元组、五元组。$n$ 项笛卡儿积及其计数为

$$A_{1} \times \dots \times A_{n} = \{(a_{1}, \dots, a_{n}) \mid a_{i} \in A_{i}\ (i = 1, \dots, n)\} \tag{5.66a}$$
$$\operatorname{card}(A_{1} \times \dots \times A_{n}) = \operatorname{card} A_{1} \operatorname{card} A_{2} \dots \operatorname{card} A_{n} \tag{5.66b}$$

集合 $A$ 与其自身的 $n$ 次笛卡儿积记作 $A^{n}$。笛卡儿积是 [[concepts/二元关系]] 与 [[concepts/映射]] 的定义域载体（关系是笛卡儿积的子集）。公式组与算例记录见 [[findings/差对称差与笛卡儿积公式组]]。
