# 非线性薛定谔方程 (NLS)

**非线性薛定谔方程**（NLS）是无耗散的非线性发展方程（9.2.5.3）：

```latex
i u_t + u_{xx} ± 2 |u|^2 u = 0        (9.149) = (9.158)
```

其中 u(x,t) 为复发展函数；「+」号情形称为聚焦 (focusing) NLS，「−」号情形称为散焦 (defocusing) NLS。它是线性薛定谔方程的非线性对应物（对比见 [[comparisons/线性薛定谔方程与非线性薛定谔方程比较]]）。

## 出现场所

- 非线性光学：折射率依赖于电场强度 E⃗，例如克尔 (Kerr) 效应 n(E⃗) = n₀ + n₂|E⃗|²，n₀ 与 n₂ 为常数；
- 自引力 (self-gravitating) 圆盘的流体动力学，可描述银河系旋臂。

## 亮孤子（聚焦支）

```latex
u(x,t) = 2η · exp(−i[2ξx + 4(ξ² − η²)t − χ]) / cosh[2η(x + 4ξt − φ)]     (9.159)
```

NLS 亮孤子由 4 个无量纲参数 η, ξ, φ, χ 刻画。波包的包络以速度 v = −4ξ 行进；波包的相速度为 2(η² − ξ²)/ξ。(9.159) 形的解常称为**光孤子** (light soliton)。与 KdV 孤子 (9.154) 不同，**NLS 孤子的振幅和速度可以互相独立地被选取**。图 9.23 展示了 η = 1/2、ξ = 4 时 (9.159) 的实部（ξ = 4 疑为 1/4 之讹，见 [[queries/9-2-5全节系统性转写讹误清单]]）。

经相位/包络拟设推导复算：(9.159) 的载波系数条件、包络速度 −4ξ、相速度 2(η²−ξ²)/ξ 全部复现（[[findings/式9-158至9-161nls亮暗孤子复算]]）。

## 暗孤子（散焦支）

散焦 NLS 给出在孤子位置处 |u|² 相对常数背景 |u(x → ±∞)| = η 凹陷的孤子：

```latex
u(x,t) = ( i v/2 + √(η² − v²/4) · tanh[√(η² − v²/4)(x − v t)] ) · exp[−i(2η² t + χ)]     (9.160)
```

暗孤子依赖 3 个参数 η, v, χ，在平凡（平直）相的背景下以速度 v < 2η 传播（源文引 [9.41]、[9.39]）。v = 0 黑孤子经直接代入散焦 NLS 验证成立。此外，通解可带一个相梯度，解释为背景速度 c（式 (9.161)，转写疑括号位置错置，见 [[queries/式9-161括号位置与暗孤子伽利略提升]]）。亮/暗孤子对比见 [[comparisons/亮孤子与暗孤子比较]]。

## 周期解与 N-孤子

除指数位置的孤子波外，NLS 还有可解释为孤子波包的周期解：通过要求稳定并积分余下的常微分方程可找到，一般为雅可比椭圆函数（源文回指第 997 页 14.6.2，见 [[concepts/雅可比椭圆函数]]；相关解见 [9.34]）。

有 N 个相互作用孤子的情形由 4N 个任意选取的参数 η_n, ξ_n, φ_n, χ_n (n = 1, …, N) 刻画；若诸孤子速度不同，N-孤子解当 t → ±∞ 时渐近分裂为形如 (9.159) 的 N 个单独孤子之和。
