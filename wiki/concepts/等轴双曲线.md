# 等轴双曲线

等轴双曲线（又称直角双曲线）是两条 [[concepts/渐近线]]互相垂直的双曲线，其典型标准型之一为 xy = a：a > 0 时两支位于一、三象限，a < 0 时位于二、四象限，顶点位于两渐近线夹角的平分线上。

在手册 2.4 节（[[sources/10-数学手册原书第10版--7-24-有理函数--1pptax7]]）中，等轴双曲线是两类有理函数的图像类型：

- [[concepts/反比例函数]] y = a/x（式 2.45）：中心在原点，渐近线为两条坐标轴，顶点 (√a, √a)、(−√a, −√a)（a > 0）或 (−√|a|, √|a|)、(√|a|, −√|a|)（a < 0）；
- [[concepts/线性分式函数]]（式 2.46）：中心在 C(−b₂/a₂, a₁/a₂)，渐近线与坐标轴平行，顶点由 Δ = a₁b₂ − b₁a₂ 表出（见 [[findings/线性分式函数的中心顶点与参数对应]]）。

手册在 2.4.1 注明关于双曲线的更详细说明见第 271 页 3.5.2.9（尚未采集）。相关辨析：[[concepts/倒数幂]] y = a/xⁿ 的图像被手册称为「双曲型曲线」，但仅 n = 1 时是真双曲线；n ≥ 2 时隐式方程（如 x²y = a）为三次及更高次代数曲线。
