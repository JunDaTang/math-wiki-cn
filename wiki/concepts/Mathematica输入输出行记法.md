# Mathematica 输入输出行记法

Mathematica 输入输出行记法是《数学手册（原书第10版）》第 20 章全部会话示例的记法基础：在 Mathematica 中，输入和输出总是**按行**并以区别于其他文本部分的形式表示，行首分别冠以 `In[n]:=` 与 `Out[n]=`（20.1.1.2；源文回指“第 1318 19.8.4.2, 1.”为其规范出处，页码与编号待核，见 [[queries/回指19-8-4-2与第1318页之辨]]）。

## 约定要素

- 键入命令行并按下 ENTER 或 SHIFT+ENTER（取决于操作系统）后，系统将这一行替换回显为 `In[1]:= …` 并启动求值；答案显示在新的一行 `Out[1]= …`。
- 系统专门符号（命令、类型符号等）用**打字机字体**表示，如 Solve、NSolve。
- 方程中的相等关系写作 `==`（双等号），如 `3 x - 5 == 0`。
- 解表示为**替换规则** `x -> …` 的嵌套列表：外层列表对应多个解，每个解为一个子列表，如 `{{x -> …}, {x -> …}}`（式 20.2d）；数值解亦然（式 20.3c，该处排版为 `x →`）。
- 为节省空间，书中常把输入和输出写在同一行，并用一个专门符号将它们分开（该符号在本转录中脱失为“一”，见 [[queries/输入输出同行分隔符脱失之辨]]）。

## 示例

式 (20.1) `In[1] := Solve[3 x - 5 == 0, x]` 为本约定的首个展示；式 (20.2c)–(20.2d) 与 (20.3b)–(20.3c) 的完整会话转录与复算见 [[findings/式20-1至20-3c符号与数值求解算例转录复算]]。第 20 章后续小节的全部示例均依赖本记法，其转录保真度直接影响全章内容的可读性。
