# 整数

整数由正整数、负整数和零组成，手册（1.1.1.1,1.）将其记为

$$\mathbb{Z} = \{\cdots, -2, -1, 0, 1, 2, \cdots\}$$

在手册 1.1.1 中，整数作为量词约束在多处复现，是定义链上的关键节点：

- **有理数的定义**：$\mathbb{Q} = \{x \mid x = p/q,\ p\in\mathbb{Z},\ q\in\mathbb{Z},\ q\neq 0\}$（→ [[concepts/有理数]]）；
- **可公度性**：$a=mc,\ b=nc\ (m,n\in\mathbb{Z})$（→ [[concepts/可公度性]]）；
- **代数无理数与二次无理数**：式 (1.1a)、(1.1b) 中“方程系数均为整数”的条件（→ [[concepts/代数无理数]]、[[concepts/二次无理数]]）。

层级位置：$\mathbb{N}\subset\mathbb{Z}\subset\mathbb{Q}\subset\mathbb{R}$（→ [[comparisons/数系分类层级]]）。
