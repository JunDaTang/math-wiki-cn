# 帕塞瓦尔方程

**帕塞瓦尔方程**（Parseval equation）是把函数平方的积分（区间平均或带权平方积分）与其傅里叶系数平方和联系起来的能量恒等式。《数学手册（原书第10版）》在两个框架下给出该方程：

- **三角傅里叶级数框架**（7.4 节，式 7.106b）：函数平方的区间平均 = 三角傅里叶系数平方和；
- **按本征函数展开框架**（9.1.3 节，式 9.69c）：带权平方积分 = 广义傅里叶系数平方和。

## 三角傅里叶级数中的形式（式 7.106b）

在该框架下，帕塞瓦尔方程是联系函数平方的区间平均与其 [[傅里叶系数]] 平方和的恒等式（式 7.106b）：

$$\frac{2}{T}\int_0^T[f(x)]^2\,\mathrm{d}x=\frac{a_0^2}{2}+\sum_{k=1}^{\infty}(a_k^2+b_k^2).$$

成立前提：f 有界且在 (0, T) 上分段连续——此时傅里叶级数均方收敛（式 7.106a），见 [[均方收敛与最小均方误差]]。

### 解读

- 两端同除以 2，得平均功率分解：(1/T)∫₀^T f² dx = a_0²/4 + ½Σ(a_k² + b_k²)。常数项 a_0/2 贡献其平方 a_0²/4；第 k 次谐波 a_k cos kωx + b_k sin kωx 的均方值为 (a_k² + b_k²)/2 = A_k²/2（A_k 为振幅）。即「时间域总功率 = 各谐波功率之和」。
- 它是均方收敛的推论：展开 ∫f² = ∫s_n² + 2∫s_n(f − s_n) + ∫(f − s_n)²，用正交性可知交叉项为零、∫s_n² 给出部分和，令 n → ∞ 即得。
- 复算抽查：f = 1（a_0 = 2，其余为零）两端均为 2；f = cos ωx（a_1 = 1，其余为零）两端均为 1。均通过，见 [[最小均方误差与帕塞瓦尔方程-式7-105至7-106]]。

### 用途

系数平方和收敛性的快速判据；功率谱分析的理论基础。手册将均方误差主题指向 19.6.2.1（第 1278 页）与 19.6.4（第 1288 页），均未入库（见 [[表21-6及19-6与8-2-3-2未入库回指缺口]]）。

## 按本征函数展开中的形式（式 9.69c）

在按本征函数展开理论中，帕塞瓦尔方程 (9.69c) 是能量恒等式：函数 g 的带权平方积分等于其广义傅里叶系数的平方和：

$$\int_a^b [g(x)]^2\,\varrho(x)\,\mathrm{d}x = \sum_{n=0}^{\infty} c_n^2 \tag{9.69c}$$

条件是 (9.69b)（见 [[按本征函数的傅里叶展开]]）中右端的积分存在。

### 平均收敛（式 9.69d）

在帕塞瓦尔方程成立的情形，g 的傅里叶级数**平均收敛**于 g，即

$$\lim_{N\to\infty} \int_a^b \Big[g(x) - \sum_{n=0}^{N} c_n\,\varphi_n(x)\Big]^2 \varrho(x)\,\mathrm{d}x = 0 \tag{9.69d}$$

### 解释

以权函数 ϱ(x) 加权的平方积分即加权 L² 范数（L² 框架参见 [[勒贝格积分]]），帕塞瓦尔方程与平均收敛合起来正是本征函数系在加权 L² 意义下**完备**的陈述。它与展开定理的强收敛（绝对且一致）前提不同：后者要求 g 有连续导数并满足边界条件，前者仅要求诸积分存在。
