# 量词恒等式与单向蕴涵、∀/∃ 不可交换（式 5.25–5.33）

《数学手册(原书第10版)》5.1.2.5 的量词演算公式组：

```latex
∀x∀y P(x,y) = ∀y∀x P(x,y)                 % (5.25) 同类量词可交换
∃x∃y P(x,y) = ∃y∃x P(x,y)                 % (5.26) 同类量词可交换
∀x P(x) ∧ ∀x Q(x) = ∀x(P(x) ∧ Q(x))       % (5.27) 等价（双向）
∃x P(x) ∨ ∃x Q(x) = ∃x(P(x) ∨ Q(x))       % (5.28) 等价（双向）
∀x P(x) ∨ ∀x Q(x) ⇒ ∀x(P(x) ∨ Q(x))       % (5.29) 单向蕴涵
∃x(P(x) ∧ Q(x)) ⇒ ∃x P(x) ∧ ∃x Q(x)       % (5.30) 单向蕴涵
∀x(P(x) ⇒ Q(x)) ⇒ (∀x P(x) ⇒ ∀x Q(x))     % (5.31) 单向蕴涵
∀x(P(x) ⇔ Q(x)) ⇒ (∀x P(x) ⇔ ∀x Q(x))     % (5.32) 单向蕴涵
∃x∀y P(x,y) ⇒ ∀y∃x P(x,y)                 % (5.33) 单向蕴涵, 其逆为假
```

原书明言：「这些蕴涵的逆并不成立，特别，我们要注意量词 ∀ 和 ∃ 不交换的事实（最后给出的蕴涵其逆是假）」——即「∃∀」强于「∀∃」（转写中 ∀/∃ 符号讹作「和日」）。

**补充例证**（本 wiki 推理，非原书内容）：取 ℕ 上 P(x) =「x 是偶数」、Q(x) =「x 是奇数」，则 ∀x(P(x)∨Q(x)) 真而 ∀xP(x)∨∀xQ(x) 假，示 (5.29) 之逆不成立；∃xP(x)∧∃xQ(x) 真而 ∃x(P(x)∧Q(x)) 假，示 (5.30) 之逆不成立。

**证据类型**：原书为语义论证之标准结果；上述例证为本 wiki 补充的推理。比较分析见 [[comparisons/量词等价式与单向蕴涵比较]]、[[comparisons/全称量词与存在量词比较]]。
