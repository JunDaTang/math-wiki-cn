# 零阶贝塞尔方程像空间降阶求解转录复算

## 发现内容

手册 15.2.3.2 以零阶贝塞尔微分方程为例演示变系数方程的像空间降阶法（源文标题缺「0」字）：

```latex
零阶贝塞尔微分方程（参见 (9.52a) n=0，第 743 页）:
  t d^2f/dt^2 + df/dt + t f = 0

变换到像空间（用 (15.16): L{t f(t)} = -dF/dp）:
  -d/dp[p^2 F(p) - p f(0) - f'(0)] + pF(p) - f(0) - dF/dp = 0
  <=>  dF/dp = -p/(p^2+1) F(p)

变量分离、积分:
  log F(p) = -\int p dp/(p^2+1) = -log sqrt(p^2+1) + log C
  F(p) = C/sqrt(p^2+1)        (C 为积分常数)

结论行（源文讹损为「J(t) = CJ (t)」，重建为）:
  f(t) = C * J_0(t)
  （J_0 为 0 阶贝塞尔函数，参见 15.2.2.3，第 1019 页）
```

## 复算核验（独立推导）

- **像方程化简**：展开 −d/dp[p²F − pf(0) − f′(0)] = −(2pF + p²F′ − f(0))，与 pF − f(0) − F′ 相加，f(0) 项恰好相消，得 (p²+1)F′ = −pF，与源文化简结果一致 ✓。
- **分离变量**：dF/F = −p dp/(p²+1) 积分得 ln F = −(1/2)ln(p²+1) + ln C，即 F = C/√(p²+1) ✓。
- **逆变换**：依赖 L{J₀(t)} = 1/√(p²+1)，该条目列于手册 15.2.2.3 变换表（第 1019 页，本 wiki 未入库，见 [[queries/15-2-3未入库回指缺口]]）；此变换对是标准结果（可独立核实），故 f(t) = C·J₀(t) 成立 ✓。

## 证据说明

- 直接证据：像方程与 F(p) 的求解过程（源文完整，复算通过）。
- 推断（高置信）：结论行源文讹损为「J(t) = CJ (t)」，重建为 f(t) = C·J₀(t)，依据为同书 15.2.2.3 的交叉引用与标准变换对；待 15.2.2.3 入库后可完全闭合。
