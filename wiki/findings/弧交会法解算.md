# 弧交会法的解算链（式 3.114）

**发现内容（直接证据，公式逐字保留）：**弧交会法确定新点 N——它是环绕具有已知坐标的两点 A、B、以所测半径 $s_{AN}, s_{BN}$ 画出的两条弧之交点（图 3.46）。计算未知线段长度 $s_{AB}$ 后，从三角形 ABN 已知的三边即可计算角。已知 $y_A, x_A; y_B, x_B$；所测 $s_{AN}; s_{BN}$；所求 $s_{AB}, y_N, x_N$。解：

$$s_{AB} = \sqrt{\Delta y_{AB}^2 + \Delta x_{AB}^2} \tag{3.114a}$$

$$\tan t_{AB} = \frac{\Delta y_{AB}}{\Delta x_{AB}},\qquad t_{BA} = t_{AB} + 200\ \mathrm{gon} \tag{3.114b,c}$$

$$\cos\alpha = \frac{s_{AN}^2 + s_{AB}^2 - s_{BN}^2}{2 s_{AN} s_{AB}},\qquad \cos\beta = \frac{s_{BN}^2 + s_{AB}^2 - s_{AN}^2}{2 s_{BN} s_{AB}} \tag{3.114d,e}$$

$$t_{AN} = t_{AB} - \alpha,\qquad t_{BN} = t_{BA} - \beta \tag{3.114f,g}$$

$$y_N = y_A + s_{AN}\sin t_{AN},\qquad x_N = x_A + s_{AN}\cos t_{AN} \tag{3.114h,i}$$

$$y_N = y_B + s_{BN}\sin t_{BN},\qquad x_N = x_B + s_{BN}\cos t_{BN} \tag{3.114j,k}$$

第二种解法（始于将一般三角形分解为两个直角三角形）源文明言「这里不作讨论」。

**结构要点：**(3.114d–e) 是 [[concepts/余弦定律]] 的反解形式（三边求角）；(3.114h–k) 为从 A、B 两端的双路复算检核；解算顺序「坐标反算 → 余弦定律解角 → 方位角传递 → 坐标正算」是 [[methodology/交会定位计算流程]] 的典型实例。

**证据类型：**直接证据；分析层核验全链数学自洽（中高）。
