# 表 7.3 常用函数近似公式与容许区间（复算与 0.451 勘误）

手册 7.3.4（原转写错置于 7.3.5.2 内部）：若仅考虑展开中心足够小的一个邻域，借助泰勒展开式可为几种函数引入恰当的近似公式。表 7.3 给出函数前几项的近似公式、下一项（误差首项）与三档精度（0.1%、1%、10%）下对 x 的容许区间。原文表格逐字转录（表格记号的 OCR 粘连如「1/a + x」→「1/(a+x)」已按数学意义复原）：

| 近似公式 | 下一项 | 0.1% 从/到 | 1% 从/到 | 10% 从/到 |
|---|---|---|---|---|
| sin x ≈ x | −x³/6 | −0.077 / 0.077（∓4.4°） | −0.245 / 0.245（∓14.0°） | −0.786 / 0.786（∓45.0°） |
| sin x ≈ x − x³/6 | +x⁵/120 | −0.580 / 0.580（∓33.2°） | −1.005 / 1.005（∓57.6°） | −1.632 / 1.632（∓93.5°） |
| cos x ≈ 1 | −x²/2 | −0.045 / 0.045（∓2.6°） | −0.141 / 0.141（∓8.1°） | −0.415† / 0.415†（∓25.8°） |
| cos x ≈ 1 − x²/2 | +x⁴/24 | −0.386 / 0.386（∓22.1°） | −0.662 / 0.662（∓37.9°） | −1.036 / 1.036（∓59.3°） |
| tan x ≈ x | +x³/3 | −0.054 / 0.054（∓3.1°） | −0.172 / 0.172（∓9.8°） | −0.517 / 0.517（∓29.6°） |
| tan x ≈ x + x³/3 | +2x⁵/15 | −0.293 / 0.293（∓16.8°） | −0.519 / 0.519（∓29.7°） | −0.895 / 0.895（∓51.3°） |
| √(a²+x) ≈ a + x/(2a) = ½(a + (a²+x)/a) | −x²/(8a³) | −0.085a² / 0.093a² | −0.247a² / 0.328a² | −0.607a² / 1.545a² |
| 1/√(a²+x) ≈ 1/a − x/(2a³) | +3x²/(8a⁵) | −0.051a² / 0.052a² | −0.157a² / 0.166a² | −0.488a² / 0.530a² |

| ln(1+x) ≈ x | −x²/2 | −0.002 / 0.002 | −0.020 / 0.020 | −0.176 / 0.230 |

## 复算方法与结论

复算采用：以**近似值为基准**的相对误差定义（|真值 − 近似|/|近似| ⩽ δ），并建立含全部高阶项的精确界（流程提炼见 [[近似公式容许区间估计流程]]）。

- **除 cos x ≈ 1 的 10% 界「0.415」外，全部数值复算通过**（含不对称界各行：√(a²+x)、1/√(a²+x)、eˣ、ln(1+x)，其上下界不对称源于下一项符号与高阶项贡献）。
- **† 勘误判定**：0.451 rad = arccos 0.9 ≈ 25.84°，与同格的 25.8° 相容；而 0.415 rad ≈ 23.8° 不相容。故「0.415」应为「0.451」之误（数字换位）。是原书排印之误还是转写之误，见 [[表7-3之0-415是排印还是转写之误]]。

## 定位

表 7.3 将一阶微分近似（衔接 [[微分近似计算流程]]、[[全微分误差估计流程]]）推进到高阶泰勒近似并给出系统的容许区间；手册另指出 19.6（第 1276 页）、19.7（第 1293 页）用插值法、拟合多项式和样条函数给出函数近似表示的其他可能性（未入库）。
