# 数学手册记号约定：数系与区间

《数学手册(原书第10版)》1.1.1 节（1.1.1.1 与 1.1.1.3）引入的记号与图示约定：

1. **数系记号**：ℕ = {0,1,2,3,…}（自然数含 0，称“非负整数”——与部分文献 ℕ 从 1 起的约定不同）；ℤ = {…,−2,−1,0,1,2,…}；ℚ = {x | x = p/q, p∈ℤ, q∈ℤ, q≠0}；ℝ。手册注明相关符号参见第 439 页 5.2.1 记号表（前向引用，未编目）。
2. **区间记号**：方括号表示闭区间、圆括号表示开区间；端点 a 允许为 −∞、b 允许为 +∞；开区间 (a, b)（有时也用 “a, b” 标记）；半开（半闭）区间 [a, b) 或 (a, b]（[a, b) 有时写作 “[a, b”）；闭区间 [a, b]。
3. **区间图示**：以圆箭头表示区间的开端，以实点表示其闭端。
4. **无穷大记号**：a:0 = ∞ 仅为记号，不表示除法可行（见 [[findings/除以零无意义且无穷大仅为记号]]）。

**译注**：数区间一段中文表述生硬（“属内”等疑为直译痕迹），但约定本身明确。本条与 [[findings/数学手册记号约定-基本量参数指标字母分段]]（1.1.5 节的字母分段约定）互补，共同构成手册的记号约定层；性质为约定而非经验论断，replicated 记为 null。
