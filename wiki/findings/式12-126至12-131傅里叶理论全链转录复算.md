# 式 12.126–12.131 傅里叶理论全链转录复算

## 转录内容

- (12.126) 正交规范系 {e_n : n = 1, 2, …}；(12.127) 傅里叶级数 Σ_{n=1}^∞ c_n e_n；(12.128) 部分和 σ_n = Σ_{k=1}^n (x,e_k)e_k，具最佳逼近性质且 x−σ_n ⊥ H_n；
- (12.129) 贝塞尔不等式（转录作 Σ_{n=1}^∞ ∣c_k∣² ⩽ ‖x‖²，c_n = (x,e_n)）；
- (12.130) 帕塞瓦尔等式/里斯–费希尔定理：Σ∣(x,e_n)∣² = Σ∣α_n∣² = ‖x‖²；
- (12.131) 广义帕塞瓦尔等式 (x,y) = Σ c_n d̄_n；
- 等价命题 a)–e)：基本集 ⟺ 完备 ⟺ 基 ⟺ (12.131) ⟺ (12.130)。

## 复算

- **最佳逼近性质**：对 y = Σ_{k⩽n} α_k e_k ∈ H_n，‖x−y‖² = ‖x‖² − Σ_{k⩽n}∣c_k∣² + Σ_{k⩽n}∣α_k−c_k∣² ⩾ ‖x−σ_n‖²，等号当且仅当 α_k = c_k。✓
- **贝塞尔**：舍去上式中的非负项并令 n → ∞ 得 Σ∣c_k∣² ⩽ ‖x‖²。✓（求和指标校正后；见 [[queries/式12-129求和指标不一致]]。）
- **帕塞瓦尔/里斯–费希尔**：部分和为柯西列（‖Σ_{k=m}^n α_k e_k‖² = Σ_{k=m}^n ∣α_k∣² → 0），由 H 的完备性收敛于某 x′ ∈ H₀ = lin{e_n}‾；系数经内积连续性等于 α_n；‖x′‖² = Σ∣α_n∣²。✓ 唯一性限定见 [[queries/式12-130前句唯一性的适用范围]]。
- **(12.131)**：对 x+y、x−y（及复情形 x±iy）的帕塞瓦尔等式作极化组合可得 (x,y) = Σ c_n d̄_n。✓
- **等价命题 a)–e)**：a) ⟺ b)（正交补为零 ⟺ 闭线性包为全空间）、b) ⟺ c) 与 c) ⟺ e)、d) ⟺ e)（极化）可环状推出。✓

## 转写讹误

(12.129) 求和指标 n 与项 c_k 不一致；「儿个命题」应为「几个命题」；例 B 指标起始（见 [[queries/12-4-3-2例b勒让德组起始指标]]）；回指「第 633 7.4.1.1, 1.」页码粘连。已并入 [[queries/12-4全节系统性转写讹误清单]]。
