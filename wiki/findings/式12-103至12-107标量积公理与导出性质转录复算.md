# 式 12.103–12.107 标量积公理与导出性质转录复算

## 转录内容

```text
(H1) (x,x) ⩾ 0（即 (x,x) 是实数），并且 (x,x) = 0 当且仅当 x = 0    (12.103)
(H2) (αx, y) = α(x, y)                                             (12.104)
(H3) (x + y, z) = (x, z) + (y, z)                                  (12.105)
(H4) (x, y) = (y,x)‾                                               (12.106)
导出：(x, αy) = ᾱ(x, y)  且  (x, y+z) = (x, y) + (x, z)            (12.107)
```

## 复算

- (H1)–(H4) 构成标准内积公理组：定正 + 第一变元线性 + 共轭对称。✓
- (12.107) 第一式：(x, αy) = (αy, x)‾ = α(y,x)‾... 逐步为 (x, αy) = (αy, x)‾ = (α(y,x))‾ = ᾱ(x,y)，仅用 (H4) 与 (H2)。✓
- (12.107) 第二式：(x, y+z) = (y+z, x)‾ = (y,x)‾ + (z,x)‾ = (x,y)+(x,z)，仅用 (H4) 与 (H3)。✓
- 𝔽 = ℝ 时 (H4) 化为对称性 (x,y) = (y,x)，即手册所称「可交换性」。✓

## 转写讹误

「对于」系统性误作「对千」；「共轭」误作「共辄」；公理编号 (H1) 排作「(Hl)」（小写 L）；ω̄ 说明中提及的 (12.133c)（ω* 记号）为超出本节公式范围的前向引用（本节公式止于 12.131）。已并入 [[queries/12-4全节系统性转写讹误清单]]。

## 结论

数学内容无误，转录层有可识别的系统性 OCR 讹误；公理组与导出性质均经独立复算确认。
