# 式 12.19–12.24 线性算子与复化转录复算

## 转录内容

```
T(x) = T(y) ⟹ x = y                                             (12.19)  内射
∀y ∈ Y, 存在 x ∈ D 使 T(x) = y                                   (12.20)  满射
T(αx + βy) = αTx + βTy                                          (12.21)  线性
y ↦ x 使 Tx = y, y ∈ R(T)                                        (12.22)  逆
(x₁,y₁)+(x₂,y₂) = (x₁+x₂, y₁+y₂)                                (12.23a)
(a+ib)(x,y) = (ax − by, bx + ay)                                 (12.23b)
(x,y) = (x,0)+(0,y)  且  i(y,0) = (0+i1)(y,0) = (0,y)            (12.24)
```

## 复算验证（复化构造）

- **i(y,0) = (0,y)**：在 (12.23b) 中取 a = 0, b = 1, (x,y) := (y,0)，得 (0·y − 1·0, 1·y + 0·0) = (0, y)。✓
- **分解 (12.24)**：由 (12.23a)，(x,0) + (0,y) = (x,y)；再由上式 (0,y) = i(y,0)，故 (x,y) = x + iy 记号合法。✓
- **与复数乘法相容**：对 (a₁+ib₁)[(a₂+ib₂)(x,y)] 逐次应用 (12.23b) 可得 ((a₁a₂−b₁b₂) + i(a₁b₂+b₁a₂))(x,y)，与复乘 (a₁+ib₁)(a₂+ib₂) 的展开一致。✓
- **维数保持 dim V = dim Ṽ**：设 {x_k} 为 V 的实线性无关组。若 Σα_k(x_k,0) = 0 且 α_k = a_k + ib_k，则按分量 Σa_k x_k = 0 与 Σb_k x_k = 0，由实无关性得 a_k = b_k = 0，故 {(x_k,0)} 复线性无关；又任意 (x,y) = (x,0) + i(y,0)，故 V 的基在 Ṽ 中生成。✓
- **逆的线性性 (12.22)**：T 线性内射时，T⁻¹(αy₁ + βy₂) = αT⁻¹y₁ + βT⁻¹y₂ 可由 T 的线性性与单射性直接验证。✓

## 转写问题

1. 12.1.5.3「一个双内射 T: X → Y 称作向量空间的同构」：「双内射」非标准术语，同构按定义须为线性**双射**，疑为「双射」之讹，见 [[queries/双内射是否应为双射]]。
2. 值域记号 R(T) 转写乱码为「冗(T)」；12.1.5.1 段落中定义域/值域句式有粘连脱字。
3. 「核」N(T) = ker(T) 与第 11 章 [[concepts/积分方程的核]] 的核函数同词异义，已在新概念页加消歧注。

## 结论

(12.19)–(12.24) 转录忠实且全部复算通过；复化构造的维数保持断言获得独立证明。概念页：[[concepts/线性算子与线性泛函]]、[[concepts/实向量空间的复化]]。
