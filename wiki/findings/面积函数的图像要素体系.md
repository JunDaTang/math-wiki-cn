# 面积函数的图像要素体系（图 2.53–2.56）

**发现**：手册逐一给出四个面积函数的图像要素（各归属其函数，不合并）：

- **Arsinh**（图 2.53）：严格递增的奇函数；原点为对称中心与拐点，此处切线倾角 φ = π/4。
- **Arcosh / −Arcosh**（图 2.54）：仅 x ≥ 1 有定义；起点 A(1, 0) 处有垂直切线；两支分别严格递增 / 递减。
- **Artanh**（图 2.55）：奇函数；原点为对称中心与拐点，φ = π/4；铅直渐近线 x = ±1。
- **Arcoth**（图 2.56）：奇函数；(−∞, −1) 上由 0 严格递减至 −∞，(1, +∞) 上由 +∞ 严格递减至 0；三条渐近线 y = 0 与 x = ±1。

**证据强度**：强。各要素均可由对数表示（式 2.211–2.214）求导核验（转写后分析的推断性核验，非原文陈述）：例如 Arsinh 与 Artanh 在原点的 π/4 切线对应导数 1/√(x²+1)|ₓ₌₀ = 1 与 1/(1−x²)|ₓ₌₀ = 1。

**版式疑点（次要）**：图 2.53（Arsinh 的图）出现在 2.10.1.2 段落之后而非 2.10.1.1 内，与手册既往各节的图题错位模式一致，待核验。

**方法论提炼**：见 [[methodology/面积函数图像绘制法]]——对称性 + 渐近线 + 特征点三要素法。
