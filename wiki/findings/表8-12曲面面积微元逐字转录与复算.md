# 表 8.12 曲面面积微元逐字转录与复算

《数学手册(原书第10版)》8.5.1.2 第 3 条「曲面的面积微元」以表 8.12 给出四种坐标下的 $\mathrm{d}S$。**标题脱字注记**：源文作「8.12 给出了曲面的面积微元／8.12 曲面面积微元」，脱「表」字，且编号与 8.5.2.1.1 中文献引用 [8.12]（单侧曲面文献）撞号——两处所指完全不同。

## 逐字转录

| 坐标 | 面积微元 |
|---|---|
| 笛卡儿坐标 $x, y, z = z(x, y)$ | $\mathrm{d}S = \sqrt{1 + \left( \frac{\partial z}{\partial x} \right)^2 + \left( \frac{\partial z}{\partial y} \right)^2}\,\mathrm{d}x\,\mathrm{d}y$ |
| 柱面侧面，$R$（常数，半径），坐标 $\varphi, z$ | $\mathrm{d}S = R\,\mathrm{d}\varphi\,\mathrm{d}z$ |
| 球面 $R$（常数，半径），坐标 $\vartheta, \varphi$ | $\mathrm{d}S = R^2 \sin\vartheta\,\mathrm{d}\vartheta\,\mathrm{d}\varphi$ |
| 任意曲线坐标 $u, v$（$E, F, G$ 参见 354 页弧微分） | $\mathrm{d}S = \sqrt{EG - F^2}\,\mathrm{d}u\,\mathrm{d}v$ |

## 复算（独立完成，四行均确认无误 ✓）

1. **笛卡儿坐标行**：即显式公式 8.150a 的根号因子，与式 8.152 的复算结果 $1+p^2+q^2$ 一致（→ [[findings/式8-149至8-152第一类曲面积分化算复算]]）。
2. **柱面侧面**：$x = R\cos\varphi,\,y = R\sin\varphi,\,z = z$，取 $u=\varphi,\,v=z$，则 $E = R^2\sin^2\varphi + R^2\cos^2\varphi = R^2$，$F = 0$，$G = 1$，故 $\mathrm{d}S = \sqrt{R^2\cdot 1}\,\mathrm{d}\varphi\,\mathrm{d}z = R\,\mathrm{d}\varphi\,\mathrm{d}z$ ✓
3. **球面**：$x = R\sin\vartheta\cos\varphi,\,y = R\sin\vartheta\sin\varphi,\,z = R\cos\vartheta$，则 $E = R^2$，$F = 0$，$G = R^2\sin^2\vartheta$，故 $\mathrm{d}S = \sqrt{R^2\cdot R^2\sin^2\vartheta}\,\mathrm{d}\vartheta\,\mathrm{d}\varphi = R^2\sin\vartheta\,\mathrm{d}\vartheta\,\mathrm{d}\varphi$ ✓
4. **任意曲线坐标行**：即式 8.151c 本身 ✓
