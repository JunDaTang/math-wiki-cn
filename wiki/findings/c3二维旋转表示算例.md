# C_3 二维旋转表示算例（式 5.98，已复算）

**来源**：[[sources/10-数学手册原书第10版--7-534-群表示--x5kmh9]]（5.3.4.1 例 A）。

等边三角形（$n = 3$，中心为原点）绕中心旋转 $\varphi_0 = 0$、$\varphi_1 = 2\pi/3$、$\varphi_2 = 4\pi/3$（式 5.98b），顶点轮换 $R_0 = e$: A→A, B→B, C→C；$R_1$: A→B, B→C, C→A；$R_2$: A→C, B→A, C→B（式 5.98c），满足 $R_2 = R_1^2$、$R_1\cdot R_2 = R_1^3 = e$（式 5.98d），构成循环群 $C_3$（见 [[entities/c-n循环点群]]）。

二维旋转矩阵 $R(\varphi) = \begin{pmatrix}\cos\varphi & -\sin\varphi\\ \sin\varphi & \cos\varphi\end{pmatrix}$（式 5.98e，引用第 308 页 (3.432)）代以上述角度，给出 $C_3$ 的表示（式 5.98f–g）：

```text
D(e)  = R(0)    = [[1, 0], [0, 1]]
D(R₁) = R(2π/3) = [[-1/2, -√3/2], [√3/2, -1/2]]
D(R₂) = R(4π/3) = [[-1/2,  √3/2], [-√3/2, -1/2]]
```

**独立复算**（本 wiki）：

- 三个矩阵行列式均为 +1（纯旋转）；
- $D(R_1)\cdot D(R_1) = D(R_2)$ ✓；$D(R_1)\cdot D(R_2) = D(e) = I$ ✓，与群关系 (5.98d) 一致；
- 指派一一，故为**忠实表示**。

**转写警示**：式 (5.98c) 第三行标签「R₃」应为 $R_2$；式 (5.98h)「D(R₂) = D(R₁R₂) = D(R₁)D(R₂)」内部不一致（将迫使 $R_1 = e$），按 (5.98d) 首项应为 $D(R_2) = D(R_1^2) = D(R_1)\cdot D(R_1)$，第二句 $D(R_1)D(R_2) = D(e)$ 正确。见 [[queries/式5-98h首项是否应为D-R1的平方]]。
