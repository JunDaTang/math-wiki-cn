# 式 19.1–19.5 零形式、不动点形式与一般迭代法转录复算

对 19.1 开篇与 19.1.1.1（式 19.1–19.5）的逐式转录与独立复算。

## 转录

```text
(19.1) 零形式      f(x) = 0
(19.2) 不动点形式  x = φ(x)
(19.3) 一般迭代法  x_{n+1} = φ(x_n)   (n = 0,1,…; x_0 给定)
(19.4) |(φ(x) − φ(x*)) / (x − x*)| ≤ K < 1   （x* 邻域内 ⇒ 收敛）
(19.5) φ′(x) ≤ K < 1                          （φ 可导时；疑脱绝对值）
```

## 复算内容与结果

- **算例 A（图解分离）**：$x^2 - \sin x = 0$ 由 $y = x^2$ 与 $y = \sin x$ 交点得 $x_1^* = 0$、$x_2^* \approx 0.87$——数值上与后续算例 B–E 收敛值 0.8767 相容，自洽。
- **算例 B（一般迭代法）**：$x_{n+1} = \sqrt{\sin x_n}$、$x_0 = 0.87$，源表逐项复算通过（如 $\sin 0.87 = 0.7643$、$\sqrt{0.7643} = 0.8742$、$\sin 0.8742 = 0.7670$ 等，至 $x_5 = 0.8767$）。
- **压缩常数核查**：$\varphi(x) = \sqrt{\sin x}$ 在 $x^* \approx 0.8767$ 处 $\varphi'(x^*) = \cos x^*/(2\sqrt{\sin x^*}) \approx 0.365 < 1$，满足 (19.4)(19.5) 型条件，与“6 步收敛、误差约按 0.365 比例缩减”的表观行为一致。

## 转写讹误（直接证据）

- (19.5) 疑脱绝对值：与 (19.4) 不平行，见 [[queries/式19-5脱绝对值之辨]]。
- “其中 为常数”、“常数 越小”：常数 $K$ 符号脱落（两处）。
- “迭代法求解非线性方程组可以参见第 1249 19.2.2”：页码回指格式残缺（见 [[queries/19-1未入库回指缺口]]）。

## 结论

公式链 19.1–19.5 结构完整、算例复算通过，构成 [[concepts/一般迭代法]] 的可靠转录基线；唯 (19.5) 绝对值问题待原书核对。
