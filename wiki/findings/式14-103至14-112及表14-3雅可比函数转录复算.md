# 式 14.103–14.112 及表 14.3 雅可比函数转录复算

对 14.6.2 全部公式、表 14.3 与相关断言逐条转录并与标准理论对照复算（来源：[[10-数学手册原书第10版--8-146-椭圆函数--3vhx9i]]）。

## 复算结果

| 对象 | 内容 | 结论 |
|---|---|---|
| (14.103) | dF/dφ = (1−k²sin²φ)^{−1/2} > 0（0<k<1） | 正确；F(k, φ) 关于 φ 严格单调 |
| (14.104a)(14.104b) | am(k, u) 为 F(k, φ) 之反函数 | 正确；存在性由 (14.103) 保证 |
| (14.105a–c) | sn = sin am、cn = cos am、dn = √(1−k²sn²) | 正确 |
| (14.106)–(14.107) | 双周期性及整数平移公式 | 正确 |
| (14.108) | 周期平行四边形集合定义 | 正确 |
| (14.109) | k′² = 1−k²、K = F(k, π/2)、K′ = F(k′, π/2) | 正确 |
| 表 14.3 | 周期/零点/极点表 | 与标准理论一致；原表头“根”应为“零点”，极点栏三函数共用 |
| (14.110) | sn²+cn²=1、k²sn²+dn²=1 | 正确 |
| (14.111a–c) | sn/cn/dn 加法定理 | 正确 |

## 文本疑点

1. 定义句“全纯的双周期函数被称为椭圆函数”疑为“亚纯”之误——否则紧随其后的“有界⟹常数”命题使该定义无非常数实例，且与“sn/cn/dn 是亚纯的且是椭圆函数”自相矛盾。见 [[椭圆函数定义句全纯疑为亚纯之辨]]。
2. 正文“雅可比函数 (14.105a)(14.105b) 是椭圆函数”漏列 (14.105c)：dn 亦为椭圆函数（表 14.3 载其周期 2K、4iK′）。
3. 断言“振幅函数 (14.104a) 不是椭圆函数”本身正确，保留为对照（见 [[振幅函数]]）。

## 内部一致性交叉核验

cn 的零点 (2m+1)K+2niK′ 恰为 sn = ±1 之处、dn 的零点 (2m+1)K+(2n+1)iK′ 恰为 sn² = 1/k² 之处，与恒等式 (14.110) 完全吻合；k→0 时 K→π/2，sn/cn 的实周期 4K→2π 与 sin/cos 的周期一致（[[退化极限与原点展开检验法]]）。
