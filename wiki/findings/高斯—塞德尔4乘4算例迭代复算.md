# 高斯—塞德尔4乘4算例迭代复算

**发现**：19.2.1.4 的 4×4 高斯—塞德尔算例中，迭代表 x⁽¹⁾、x⁽⁴⁾、x⁽⁵⁾ 各分量经独立复算**全部吻合（至 4 位小数）**；但第 4 个迭代式的常数项印作 −20，与表格矛盾——按 −20 计算得 x₄⁽¹⁾≈−1.55，按 **+20** 计算方得 ≈1.7861 与表格吻合，属转写符号讹误，表格为内证（详见 [[queries/高斯塞德尔算例x4式负20疑为正20之辨]]）。

方程组与精确解（按原样转录）：

```
10x₁ − 3x₂ − 4x₃ + 2x₄ = 14
−3x₁ + 26x₂ + 5x₃ − x₄ = 22
−4x₁ + 5x₂ + 16x₃ + 5x₄ = 17
2x₁ + 3x₂ − 4x₃ − 12x₄ = −20
精确解 x = (1.5, 1, 0.5, 2)
```

迭代表（原样转录）：

| | x⁽⁰⁾ | x⁽¹⁾ | x⁽⁴⁾ | x⁽⁵⁾ | x |
|---|---|---|---|---|---|
| x₁ | 0 | 1.4 | 1.5053 | 1.5012 | 1.5 |
| x₂ | 0 | 1.0077 | 0.9946 | 0.9989 | 1 |
| x₃ | 0 | 1.0976 | 0.5059 | 0.5014 | 0.5 |
| x₄ | 0 | 1.7861 | 1.9976 | 1.9995 | 2 |

**复算验证（直接证据）**：第 1 步 x₁⁽¹⁾=14/10=1.4；x₂⁽¹⁾=(22+3·1.4)/26≈1.0077；x₃⁽¹⁾=(17+4·1.4−5·1.0077)/16≈1.0976；x₄⁽¹⁾=(20+2·1.4+3·1.0077−4·1.0976)/12≈1.7861（按 −20 则 ≈−1.55，与表格矛盾）。x⁽⁴⁾、x⁽⁵⁾ 各分量与表格吻合至 4 位小数，且收敛于精确解。

**对角占优验证（直接证据）**：行和 9<10、9<26、14<16、9<12；列和 9<10、11<26、13<16、8<12——该矩阵行、列均严格对角占优，同时满足（19.49）（19.50），与“雅可比/高斯—塞德尔对任意初值收敛”的论断一致。

**直接证据与推断的区分**：迭代表数值与对角占优为直接复算结果；“原书排印 vs 转写引入”的符号讹误来源属推断，待对照原书（见查询页）。
