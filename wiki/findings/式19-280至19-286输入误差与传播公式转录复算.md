# 式 19.280–19.286 输入误差与传播公式转录复算

## 转录（按原文）

```latex
% 输入误差界（泰勒线性余项）(19.280)
|\Delta y| = |f(x_1,\dots,x_n)-f(\tilde{x}_1,\dots,\tilde{x}_n)|
  = \Big|\sum_{i=1}^{n}\frac{\partial f}{\partial x_i}(\xi_1,\dots,\xi_n)(x_i-\tilde{x}_i)\Big|
  \leqslant \sum_{i=1}^{n} \Big(\max_{x}\Big|\frac{\partial f}{\partial x_i}(\underline{x})\Big|\Big)|\Delta x_i|

% 四则运算误差传播 (19.281–19.286)
\varepsilon(x \pm y) = \varepsilon(x) \pm \varepsilon(y)                                     (19.281)
\varepsilon(xy) = y\,\varepsilon(x) + x\,\varepsilon(y) + \varepsilon(x)\varepsilon(y)       (19.282)
\varepsilon(x/y) = \tfrac{1}{y}\varepsilon(x) - \tfrac{x}{y^2}\varepsilon(y) + 高阶项          (19.283)
\varepsilon_{\mathrm{rel}}(x \pm y) = \frac{\varepsilon_{\mathrm{rel}}(x) \pm \varepsilon_{\mathrm{rel}}(y)}{x \pm y}    (19.284)
\varepsilon_{\mathrm{rel}}(xy) = \varepsilon_{\mathrm{rel}}(x) + \varepsilon_{\mathrm{rel}}(y) + \varepsilon_{\mathrm{rel}}(x)\varepsilon_{\mathrm{rel}}(y)  (19.285)
\varepsilon_{\mathrm{rel}}(x/y) = \varepsilon_{\mathrm{rel}}(x) + \varepsilon_{\mathrm{rel}}(y) + 高阶项                     (19.286)
```

## 复算（直接证据：精确代数展开；推断：符号约定假说）

设按 (19.270) 记号 $x\tilde{}=x-\varepsilon(x)$，$\tilde{y}=y-\varepsilon(y)$：

- **(19.281)** ✓：$\tilde{x}\pm\tilde{y}=(x\pm y)-(\varepsilon(x)\pm\varepsilon(y))$，两符号约定下形式相同。
- **(19.282)**：$\tilde{x}\tilde{y}=xy-y\varepsilon(x)-x\varepsilon(y)+\varepsilon(x)\varepsilon(y)$，故精确应为 $\varepsilon(xy)=y\varepsilon(x)+x\varepsilon(y)\,\mathbf{-}\,\varepsilon(x)\varepsilon(y)$；转录的"+"号与 (19.270) 约定矛盾。
- **关键观察（推断，待原书裁定）**：若原书采用异号约定 $\varepsilon(x)=\tilde{x}-x$，则 (19.281)、(19.282)（"+"精确成立）、(19.283)（首阶两项符号不变）、(19.285) 全部**精确自洽**——疑点集中收敛到 (19.270) 的转写方向。
- **(19.283)** ✓（一阶）：$\varepsilon(x/y)\approx\varepsilon(x)/y-x\varepsilon(y)/y^2$。
- **(19.284)**：由 $\varepsilon(x)=x\,\varepsilon_{\mathrm{rel}}(x)$，应得 $\varepsilon_{\mathrm{rel}}(x\pm y)=\dfrac{x\,\varepsilon_{\mathrm{rel}}(x)\pm y\,\varepsilon_{\mathrm{rel}}(y)}{x\pm y}$；转录分子**脱 $x,y$ 乘子**，且在 $x,y$ 量纲不同时不可加。
- **(19.285)**：二阶项符号问题同 (19.282)。
- **(19.286)**：带符号约定下一阶项应为 $\varepsilon_{\mathrm{rel}}(x)\,\mathbf{-}\,\varepsilon_{\mathrm{rel}}(y)$（两种符号约定下皆然）；"+"仅在误差限（绝对值相加）意义下成立，疑原书本为误差限表述或转录讹。

上述三点分别立有专页：[[queries/式19-282与19-285二阶项符号之辨]]、[[queries/式19-284分子疑脱x与y乘子之辨]]、[[queries/式19-286商的相对误差符号之辨]]。

## 结论（与原文一致部分）

即便符号存疑，本组公式承载的**定性结论**复算成立且为直接证据：乘除的相对误差传播良性（相对误差近似相加）；加减在 $|x\pm y|\ll|x|+|y|$ 时相对误差可能非常大——这是 [[concepts/减法相消]] 的传播论根据。概念整理见 [[concepts/输入误差与误差传播]]。
