# 算例：x + x(1−x) + x(1−x)² + ⋯ 的非一致收敛与和函数不连续（式 7.80，已复算）

手册 7.3.2.1 的第二个算例：级数

```latex
x + x(1-x) + x(1-x)^2 + \dots + x(1-x)^n + \dots                                             % (7.80a)
```

在 [0,1] 上的每个 x 都收敛：由达朗贝尔比值审敛法（参见 7.2.2.2，未入库）

```latex
\rho = \lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right| = |1-x| < 1,\quad 0<x\leqslant 1\;(\text{当 } x=0 \text{ 时},\, S=0)   % (7.80b)
```

该级数非一致收敛，因为余项

```latex
S(x) - S_n(x) = x\big[(1-x)^{n+1} + (1-x)^{n+2} + \dots\big] = (1-x)^{n+1}                   % (7.80c)
```

对每个 n 都存在使 (1−x)^{n+1} 无限趋近 1 的 x（即 x → 0⁺），故不会小于给定的 ε。当 0 < a < 1 时，在区间 [a,1] 上级数一致收敛。

## 独立复算（通过）

- **逐点收敛与和函数**：对 0 < x ⩽ 1，几何级数求和得 S(x) = x/(1−(1−x)) = 1；x = 0 时各级项均为 0，S = 0。故和函数在 x = 0 不连续 —— 7.3.2.2 连续性定理「非一致收敛 ⇒ 和可能不连续」的反例印证，复算通过。
- **非一致收敛**：固定 n，sup_{x∈(0,1)} R_n(x) = 1（x → 0⁺ 时 (1−x)^{n+1} → 1），故不存在统一的 N —— 通过。
- **内闭一致收敛**：在 [a,1]（0 < a < 1）上 R_n ⩽ (1−a)^{n+1} → 0 与 x 无关 —— 通过。
- **指标差一**：按「S_n 含至 x(1−x)^n 项」（n+1 项）的约定，S_n = 1 − (1−x)^{n+1}，R_n = (1−x)^{n+1} 与式 7.80c 一致；若严格按式 7.75 的「前 n 项」约定则应为 (1−x)^n。约定混用问题见 [[式7-80c余项指数差一与Sn指标约定]]。
- 转写注意：源文用「e」「己」代 ε。
