# 多边形与三角形面积公式（式 3.299–3.301，式 3.299 转写损毁）

## 凸多边形面积（3.299）——转写完全损毁

给定凸多边形顶点 P₁(x₁,y₁), …, Pₙ(xₙ,yₙ)，原文公式被 OCR 打碎为乱码（「S = 1-2 [(x1 一心）如＋…」），本体不可读。**重构假说（推断，非原文）**：由 (3.300) 第二等式的环形求和结构推断，原式应为鞋带（shoelace）形式

```
S = ½[(x₁−x₂)(y₁+y₂) + (x₂−x₃)(y₂+y₃) + … + (xₙ−x₁)(yₙ+y₁)]
```

待据原书核定，见 [[queries/式3-299多边形面积公式损毁是否可据原书复原]]。

## 三角形面积（3.300）——三种等价形式（已代数验证）

```
S = ½ |x₁ y₁ 1; x₂ y₂ 1; x₃ y₃ 1|
  = ½[x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)]
  = ½[(x₁−x₂)(y₁+y₂) + (x₂−x₃)(y₂+y₃) + (x₃−x₁)(y₃+y₁)]
```

行列式形式、按顶点展开式与环形（梯形差）展开式三者互相等价——分析阶段代数验证成立（视为已复算）。

## 共线判别（3.301）

三点 P₁, P₂, P₃ 共线 ⟺ 上述三阶行列式为零。

## 定向约定

按**反时针**顺序计数顶点时，(3.299)(3.300) 得出正的面积，否则为负。
