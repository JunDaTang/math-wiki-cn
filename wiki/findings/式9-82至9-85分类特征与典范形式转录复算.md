# 式 9.82–9.85 分类、特征与典范形式转录复算

## 逐字转录

```
A ∂²u/∂x² + 2B ∂²u/∂x∂y + C ∂²u/∂y² + a ∂u/∂x + b ∂u/∂y + cu = f   (9.82a)
δ = AC − B²                                                            (9.82b)
(1) δ < 0 双曲型；(2) δ = 0 抛物型；(3) δ > 0 椭圆型；(4) δ 改变符号：混合型
```

特征方程及其解（式 9.83）：

```
A dy² − 2B dx dy + C dx² = 0，或 dy/dx = (B ± √(−δ))/A
```

特征性态：(1) 双曲型存在两族实特征；(2) 抛物型只存在一族实特征；(3) 椭圆型不存在实特征；(4) 坐标变换前后的方程有相同的特征；(5) 一族特征与一族坐标线一致 ⇒ 相应二阶导数项不存在；抛物型不存在混合导数项。

典范形式（ξ = φ(x,y)、η = ψ(x,y)，式 9.84a）：

```
u_ξξ − u_ηη + … = 0   δ < 0 双曲型    (9.84b)
u_ηη + … = 0          δ = 0 抛物型    (9.84c)
u_ξξ + u_ηη + … = 0   δ > 0 椭圆型    (9.84d)
u_{ξ₁η₁} + … = 0（双曲第一典范形式）   (9.84e)
ξ = ξ₁ + η₁，η = ξ₁ − η₁              (9.84f)
```

抛物型：唯一特征族取 ξ = 常数，η 取不依赖 ξ 的任意函数（转写脱字为“它必定不依赖千 e”）。椭圆型：系数解析时特征定义两族复共轭曲线，代换 ξ = φ + ψ、η = i(φ − ψ)。一般化形式（式 9.85）：A u_xx + 2B u_xy + C u_yy + F(x, y, u, u_x, u_y) = 0，F 对 u 及一阶导数可非线性，分类与约化陈述仍成立。

## 复算核验

1. **9.83 解出**：视为 dy/dx 的二次方程 A(dy/dx)² − 2B(dy/dx) + C = 0，判别式 4(B² − AC) = −4δ，解得 dy/dx = (B ± √(−δ))/A ✓。
2. **类型示例**：弦振动（A = a², C = −1, B = 0 → δ = −a² < 0 双曲）；热传导（C = 0 → δ = 0 抛物）；拉普拉斯（δ = 1 > 0 椭圆）✓。
3. **典范形式组**：双曲 9.84b 与第一典范形式 9.84e 经线性代换 9.84f 互通，核验一致 ✓。

## 结论

分类理论为标准结果，复算通过。保留问题：判别式约定 δ = AC − B²（双曲 < 0）与通行教材 B² − AC 方向相反（约定差异，非错误，见 [[comparisons/判别式两种符号约定比较]]）；“判别式符号在自变量的任意变换下不变”应限定为**非退化**变换（表述宽松处）。转写讹误：本段四次将 (9.82a)/(9.82b) 误引为 (9.28a)/(9.28b)（见 [[queries/式9-28a与9-28b回指是否应为9-82a与9-82b]]）；“抛物线 只存在一族实特征”应为“抛物型”（见 [[queries/9-2-2全节系统性转写讹误清单]]）。
