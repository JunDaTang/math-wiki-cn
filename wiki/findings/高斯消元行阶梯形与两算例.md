# 高斯消元的行阶梯形与两算例（式 4.185–4.186，已复算）

高斯步骤（4.5.2.4 (2)）：设 a₁₁ ≠ 0（不然将另一方程调换为第一个方程），在增广矩阵 (A, a) 上用 −a₂₁/a₁₁, …, −a_m1/a₁₁ 乘第一行并分别加到第 2, …, m 行（式 4.185a–b），使第一列除主元外全为零。实施 (r − 1) 次高斯步骤（转写误作「(r 1) 次」）后得行阶梯矩阵（式 4.186）。高斯步骤基本上是行运算，不影响 (A, a) 的秩，从而解的存在性、唯一性与解本身都不改变：

- 情形 1：若 a_{r+1}^(r−1), …, a_m^(r−1) 中每个数都不为零（即有非零者）→ 无解；
- 情形 2：若它们全为零 → 有解；其中 r = n 时解唯一，r < n 时不唯一、n − r 个未知数可选作自由参数。

例 A（4×4，方程组见 [[sources/10-数学手册原书第10版--8-45-线性方程组--1smy1k4]]）：阶梯形与解

```
[ 1   2   3   4 |  −2 ]
[ 0  −1  −2  −7 |   6 ]
[ 0   0  −4   4 |  −4 ]
[ 0   0   0  40 | −40 ]   →   x₄ = −1,  x₃ = 0,  x₂ = 1,  x₁ = 0
```

例 B（5×3）：实施高斯步骤后三行化为零，r = 2 < 3

```
[ −1  −3  −12 | −5 ]
[  0   5   17 |  7 ]
[  0   0    0 |  0 ]（三行零行）
   →  x₃ = t,  x₂ = 7/5 − (17/5)t,  x₁ = 4/5 − (9/5)t
```

## 核验

两个阶梯形均按行运算逐步复算吻合（例 B 的第 3–5 行确为零行，如第 5 行 = −2·第 1 行 − 5·第 2 行），回代验证解无误。属直接证据且已复算。
