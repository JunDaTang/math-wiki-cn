# 四元数算子与拉普拉斯分解（式 4.166–4.170）

**发现**：《数学手册（原书第10版）》4.4.3.5 表明：把 ∇ 与向量场嵌入四元数演算后，一次四元数乘法同时给出 −div 与 rot（式 4.168）；∇_Q 与 D 和各自共轭复合得到 Δ₃ 与 Δ₄（式 4.170）；∇_Q 被称为狄拉克或柯西–黎曼算子。除 (4.169c) 疑缺一项外，全部公式经独立验证成立。

## 公式组（照录）

```latex
∇_Q = i ∂/∂x + j ∂/∂y + k ∂/∂z                                             (4.166)

v̲(x,y,z) = v₁(x,y,z) i + v₂(x,y,z) j + v₃(x,y,z) k                        (4.167)

∇_Q v̲ = −∇·v⃗ + ∇×v⃗ = −div v⃗ + rot v⃗                                      (4.168)

D = ∂/∂t + i ∂/∂x + j ∂/∂y + k ∂/∂z                                        (4.169a)

w(t,x,y,z) = w₀ + w₁ i + w₂ j + w₃ k = w₀ + w̲        (转写误标为 "(4.16)") (4.169b)

D w = ∂w₀/∂t − div w̲ + rot w̲ + grad w₀          [疑脱落 ∂w̲/∂t 项]        (4.169c)

∇_Q ∇̄_Q f = ∇̄_Q ∇_Q f = Δ₃ f                                              (4.170a)
∇_Q ∇_Q f = −Δ₃ f                                                         (4.170b)
D D̄ f = D̄ D f = ∂²f/∂t² + Δ₃ f = Δ₄ f                                     (4.170c)
```

（rot 即旋度 curl；Δ₃、Δ₄ 分别为 ℝ³、ℝ⁴ 的拉普拉斯算子，书引自第 13 章式 13.75。）

## 复核结论

- (4.168)：由四元数乘法法则 (4.109b) 直接展开成立——标量部分 −div v⃗、向量部分 rot v⃗。
- (4.170a)：∇_Q∇̄_Q f = ∇̄_Q∇_Q f = Δ₃ f，成立。
- (4.170b)：∇_Q∇_Q f = −Δ₃ f，成立（i, j, k 的平方为 −1）。
- (4.170c)：DD̄ f = D̄D f = ∂ₜ²f + Δ₃f = Δ₄f，成立。
- **(4.169c) 例外**：由 (4.169a)/(4.169b) 直接展开应得

```latex
D w = ∂w₀/∂t − div w̲ + ∂w̲/∂t + rot w̲ + grad w₀
```

转写文本缺少 ∂w̲/∂t 项，疑为脱落（见 [[queries/式4-169c是否脱落时间偏导项]]）。

## 直接证据与推断的区分

(4.166)–(4.170) 为书中直接陈述；「∇_Q 常称为狄拉克或柯西–黎曼算子」为书中原话；缺项判断为分析者据 (4.169a/b) 展开所得的高置信推断，需回查原书裁定。
