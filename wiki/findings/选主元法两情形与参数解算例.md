# 选主元法两情形判据与参数解算例（式 4.182–4.183，已复算）

将 A x = a 改写为 y = Ax − a = 0（式 4.182a–b；A 为 m×n 矩阵，方程个数未必等于未知数个数），完成选主元后作代换 y = 0，解的存在性和唯一性可直接从最终格式读出：

- **情形 1**：所有 y_μ (μ = 1,…,m) 都可与某个 x_ν 调换（对应线性函数组线性无关）→ 有解；
- **情形 2**：至少有一个 y_σ 不可能与任何 x_ν 调换，即 y_σ = λ₁y₁ + λ₂y₂ + … + λ_my_m + λ₀（式 4.183，对应线性函数组线性相关）→ 当且仅当 λ₀ = 0 时有解（该方程冗余）；若 λ₀ ≠ 0 则无解（方程组中有互相矛盾的方程）。

算例（4.5.2.2）初始格式（y = Ax − a）：

|      | x₁ | x₂ | x₃ | x₄ | 1 |
|------|----|----|----|----|---|
| y₁ | 1 | −2 | 4 | −1 | −2 |
| y₂ | −3 | 3 | −3 | 4 | −3 |
| y₃ | 2 | −3 | 5 | −3 | 1 |

三次换轴（y₁→x₁、y₃→x₄、y₂→x₂）后的终表：

|      | y₁ | y₂ | x₃ | y₃ | 1 |
|------|----|----|----|----|---|
| x₁ | 3/2 | −3/2 | 2 | −5/2 | 1 |
| x₂ | −1/2 | −1/2 | 3 | −1/2 | −2 |
| x₄ | 3/2 | −1/2 | 0 | −3/2 | 3 |

属情形 1：y₁、y₂、y₃ 与 x₃ 是独立变量。代入 y₁ = y₂ = y₃ = 0 及 x₃ = t（−∞ < t < ∞），得参数解

```
x₁ = 2t + 1,   x₂ = 3t − 2,   x₃ = t,   x₄ = 3
```

## 核验

终表已逐步复算吻合；参数解回代原方程组三个方程全部成立（如第 1 式：(2t + 1) − 2(3t − 2) + 4t − 3 = 2）。属直接证据且已复算。
