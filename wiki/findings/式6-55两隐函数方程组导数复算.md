# 两隐函数方程组的一阶导数（式 6.55a–c，克莱姆复算）

《数学手册(原书第10版)》6.2.3.2 条目 (3)：两个一元函数 y = f(x), z = φ(x) 由两个方程联立给出。

## 逐字转录

$$F(x, y, z) = 0 \quad \text{和} \quad \Phi(x, y, z) = 0 \tag{6.55a}$$

"根据 (6.51b)，(6.55a) 的微分为"

$$F_x + F_y\, y' + F_z\, z' = 0,\quad \Phi_x + \Phi_y\, y' + \Phi_z\, z' = 0, \tag{6.55b}$$

"故"

$$y' = \frac{F_z \Phi_x - \Phi_z F_x}{F_y \Phi_z - F_z \Phi_y},\quad z' = \frac{F_x \Phi_y - F_y \Phi_x}{F_y \Phi_z - F_z \Phi_y}. \tag{6.55c}$$

原文续作："由 y′, z′，利用 (6.55b) 的微分，用同样的方法可计算二阶导数 y″ 和 z″"（未给显式公式）。

## 克莱姆法则复算

6.55b 是关于 (y′, z′) 的 2×2 线性方程组：

```
F_y·y′ + F_z·z′ = −F_x
Φ_y·y′ + Φ_z·z′ = −Φ_x            系数行列式 Δ = F_y·Φ_z − F_z·Φ_y
```

按克莱姆法则：

```
y′ = │ −F_x   F_z │ / Δ  =  (F_z·Φ_x − Φ_z·F_x) / Δ
     │ −Φ_x   Φ_z │

z′ = │  F_y  −F_x │ / Δ  =  (F_x·Φ_y − F_y·Φ_x) / Δ
     │  Φ_y  −Φ_x │
```

与 6.55c 的分子、分母逐项核对**完全一致**。✓ 复算通过。

## 推断标注（不属于原文）

- 复算所用工具为克莱姆法则，分母 Δ 在结构上即约束组 (F, Φ) 对 (y, z) 的雅可比行列式——**原书未使用"克莱姆法则""雅可比行列式"等名称**，此为复算者标注。
- 6.55c 未标明 Δ ≠ 0 的条件（对比 6.53c 标明 F_y ≠ 0），见 [[queries/式6-54b是否应补Fu不等于0条件]]。
- 归属：6.55c 仅属于"两方程、两个一元函数"情形；两个二元函数情形（式 6.57）原书未给显式解，不得由本式类推补写，见 [[findings/式6-57两个二元隐函数偏导数方程组]]。
