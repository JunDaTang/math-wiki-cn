# 布尔代数公理组与分配律转写讹误（式 5.284–5.297）

手册 5.7.1 以六组公理定义布尔代数 $B=(B,\sqcap,\sqcup,\bar{\ },0,1)$。除分配律外，各组转写核对无误；**式 (5.290)、(5.291) 按转写文本是数学上为假的命题**，为本节最严重的数学性转写讹误。

## 转写原文（假命题）

```
(5.290)  (a ⊔ b) ⊓ c = (a ⊓ b) ⊔ (b ⊓ c)
(5.291)  (a ⊓ b) ⊔ c = (a ⊔ b) ⊓ (b ⊔ c)
```

## 反例复算（在 B = {0,1} 中，直接验证）

- **(5.290)** 取 $a=b=1,\ c=0$：左边 $(1\sqcup 1)\sqcap 0=1\sqcap 0=0$；右边 $(1\sqcap 1)\sqcup(1\sqcap 0)=1\sqcup 0=1$；$0\neq 1$，命题为假。
- **(5.291)** 取 $a=0,\ b=1,\ c=0$：左边 $(0\sqcap 1)\sqcup 0=0$；右边 $(0\sqcup 1)\sqcap(1\sqcup 0)=1\sqcap 1=1$；命题为假。

## 更正（对原文形式的推断）

$$(a\sqcup b)\sqcap c=(a\sqcap c)\sqcup(b\sqcap c),\qquad(a\sqcap b)\sqcup c=(a\sqcup c)\sqcap(b\sqcup c),$$

即右端应为「$c$ 分别与 $a$、$b$ 运算后再合并」，而非「$b$ 分别与 $a$、$c$ 运算」。更正后即为标准分配律，与公理系统其余部分相容。

## 其余公理组（核对无误）

| 公理组 | 式号 | 内容 |
|---|---|---|
| (1) 结合律 | (5.284)–(5.285) | $(a\sqcap b)\sqcap c=a\sqcap(b\sqcap c)$；$(a\sqcup b)\sqcup c=a\sqcup(b\sqcup c)$ |
| (2) 交换律 | (5.286)–(5.287) | $a\sqcap b=b\sqcap a$；$a\sqcup b=b\sqcup a$ |
| (3) 吸收律 | (5.288)–(5.289) | $a\sqcap(a\sqcup b)=a$；$a\sqcup(a\sqcap b)=a$ |
| (5) 中性元素 | (5.292)–(5.295) | $a\sqcap 1=a$；$a\sqcup 0=a$；$a\sqcap 0=0$；$a\sqcup 1=1$ |
| (6) 补律 | (5.296)–(5.297) | $a\sqcap\bar a=0$；$a\sqcup\bar a=1$ |

## 附带观察

- 第 (6) 组标题在转写中脱落，据内容（$a\sqcap\bar a=0$、$a\sqcup\bar a=1$）应为「补律」。
- 式 (5.294)、(5.295)（$a\sqcap 0=0$、$a\sqcup 1=1$）可由其余公理导出，但手册将其与 (5.292)、(5.293) 并列于「中性元素」名下——是刻意将其列为公理（享廷顿式系统）还是编排处理，源未说明，待核。
- 式 (5.289) 中的「$\cap$」为「$\sqcap$」之转写混用。

## 证据性质

反例计算为直接复算（本 wiki 维护者执行）；更正形式为对原文的推断（高置信：与格论标准分配律一致）。
