# 卡西尼曲线按 a 与 c 之比的五种形态（式 2.238–2.239）

**主张。** 卡西尼曲线（$\overline{F_1P}\cdot\overline{F_2P} = a^2$，焦点 $(\pm c, 0)$）的形状由 a/c 分五情形：

| 条件 | 形态 | 要点 |
|---|---|---|
| a > c√2 | 类椭圆卵形 | A, C(±√(a²+c²), 0)；B, D(0, ±√(a²−c²)) |
| a = c√2 | 过渡形态 | A, C(±c√3, 0)；B, D(0, ±c) 处曲率为 0，与直线 y = ±c“紧密接触” |
| c < a < c√2 | 压卵形 | 交点同 a > c√2；极值点另有 E, G, K, I(±√(4c⁴−a⁴)/(2c), ±a²/(2c))；拐点 P, L, M, N(±√((m−n)/2), ±√((m+n)/2))，n = (a⁴−c⁴)/(3c²)，m = √((a⁴−c⁴)/3) |
| a = c | 双纽线 | 见 [[findings/双纽线的方程奇点与几何量]] |
| a < c | 两条卵形 | x 轴交点 A, C(±√(a²+c²), 0) 与 P, Q(±√(c²−a²), 0)；极值点 E, G, K, I 同上公式；曲率半径 r = 2a²ρ³/(c⁴−a⁴+3ρ⁴) |

**验证（部分已验证）。**
- 已复推吻合：坐标轴交点——隐式方程取 y = 0 得 $x^2 = c^2 \pm a^2$，取 x = 0 得 $y^2 = a^2 - c^2$，与各情形交点坐标一致；腰部极值点 E, G, K, I——极值处切线竖直 ⟹ $F_x = 4x(x^2+y^2-c^2) = 0$，非平凡解 $x^2+y^2 = c^2$，代回隐式方程解出 $x = \pm\sqrt{4c^4-a^4}/(2c)$、$y = \pm a^2/(2c)$。
- 一致性检查（未完整推导）：四拐点公式已验证落在曲线上，且存在性条件为 a < c√2；曲率通式在 a = c 退化为 r = 2a²/(3ρ)，与双纽线公式一致。
- 未完整复推：拐点 m/n 公式与曲率通式的符号推导。

**注记。** a = c√2 情形的“紧密接触”疑为 osculation 的非常规译法；2.12.4 末尾孤立的“a < c”疑为本节情形标签错位（见 [[queries/2-12-4末尾孤立a小于c是否为错位残留]]）。
