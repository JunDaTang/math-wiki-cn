# 式 17.53–17.54 杜阿迪—厄斯特勒定理与洛伦茨上界复算

## 转录

```latex
% 一般版本：σ_1≥…≥σ_n 为 DΦ(x)（Φ=φ^{t_0}）奇异值，d=d_0+s，d_0∈{0,…,n−1}，s∈[0,1]
% 若 sup_{x∈A}[σ_1…σ_{d_0}·σ_{d_0+1}^s] < 1，则 d_H(Λ) < d
% 微分方程版本：α_1≥…≥α_n 为对称化雅可比矩阵特征值
% 若 sup_{x∈A}[α_1+…+α_{d_0}+s·α_{d_0+1}] < 0，则 d_H(Λ) < d_Ω【d_Ω 疑为 d】
d_DO = { 0, α_1 ≤ 0;  sup{ d : 0≤d≤n, α_1+…+α_[d] + (d−[d])α_[d]+1 ≥ 0 } }      (17.53)
% 结论：d_H(Λ) ≤ sup_{x∈Λ} d_DO(x)
d_H(Λ) ≤ 3 − (σ+b+1)/κ                                                          (17.54a)
κ = ½[σ+b+√((σ−b)² + (b/√(b−1)+2)σr)]                                            (17.54b)
```

## 复算

**洛伦茨上界**（$\sigma=10,\ b=8/3,\ r=28$，式 17.54）：

- $\sigma-b=22/3=7.3333$，$(\sigma-b)^2=53.778$；
- $b-1=5/3$，$\sqrt{b-1}=1.29099$，$b/\sqrt{b-1}=2.66667/1.29099=2.06559$；
- $(2.06559+2)\times\sigma r=4.06559\times280=1138.37$；
- 根号内合计 $53.778+1138.37=1192.14$，$\sqrt{}=34.527$；
- $\kappa=\tfrac12(12.6667+34.527)=23.597$；
- 上界 $=3-\dfrac{\sigma+b+1}{\kappa}=3-\dfrac{13.6667}{23.597}=3-0.5792=\mathbf{2.421}$。

**有效性核验**：$2.421>2.06$（源文数值 $d_H(\Lambda)\approx2.06$；文献值 ≈2.062），故上界成立且不自相矛盾；上界对任意 $b>1,\sigma>0,r>0$ 断言（源文）。

**自洽性限度**：$\kappa$ 公式（17.54b）源文称「由杜阿迪—厄斯特勒定理……可得」，但未给推导路径；本复算仅验证了代入自洽与上界有效性，**无法**从本节文字独立重建 $\kappa$ 的来源，需对照印本与所引文献（见 [[queries/17-2-4未入库回指缺口]]）。

## 判定

数值代入与上界有效性复算通过；$\kappa$ 公式出处存疑，故整体置信 medium；本复算为单次，无独立第二来源复核（replicated: false）。
