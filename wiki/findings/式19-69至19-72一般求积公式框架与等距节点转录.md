# 式 19.69–19.72 一般求积公式框架与等距节点转录

转录《数学手册(原书第10版)》19.3.1 与 19.3.2 开篇的框架性公式，并核对转录疑点。

## 转录（verbatim）

```latex
I(f) = ∫_a^b f(x) dx                                              (19.69)
Q(f) = Σ_{ν=0}^n c_{0ν} y_ν + Σ_{ν=0}^n c_{1ν} y_ν^{(1)} + ⋯ + Σ_{ν=0}^n c_{pν} y_ν^{(p)}   (19.70)
      （y_ν^{(μ)} = f^{(μ)}(x_ν), y_ν = f(x_ν), c_{μν} 为常数）
I(f) = Q(f) + R                                                    (19.71)
x_ν = x_0 + νh (ν = 0,1,…,n),  x_0 = a,  x_n = b,  h = (b−a)/n      (19.72)
```

## 内容核对

- (19.69) 为定积分定义；(19.71) 为误差恒等式（定义性）；(19.72) 为等距节点约定，均与标准理论一致。
- 分类断言：仅用到节点值的公式称为「均值公式」，用到导数值的公式称为埃尔米特求积公式。「均值公式」术语是否忠实于原书用语待查（德文原版用词不明，登记于 [[queries/19-3全节系统性转写讹误清单]]）。

## 转录疑点

1. (19.70) 求和范围写 ν = 0,…,n，但源括注为「v = 1,2,⋯,n」——v/ν 记号混用且取值范围矛盾；按 (19.73)–(19.80) 均用到 ν = 0 的事实，应以 ν = 0,1,…,n 为准。
2. 「其中 为求积公式的误差」脱符号 R。
3. 19.3.2 引言「可用千大多数实际情况」中「千」为「于」之讹（系统性，见 [[queries/千字疑为于字系统性之辨]]）。
