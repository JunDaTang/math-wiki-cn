## (12.210) 的复算（疑误定位）

原文分段：χ_A⁻¹((α, +∞]) = A（α ∈ (−∞, 1)）、∅（α ⩾ 1）。

按原像定义逐段计算（χ_A 取值仅有 0 与 1）：

- α < 0：{x : χ_A(x) > α} = X（x ∉ A 处 0 > α 亦成立）
- 0 ⩽ α < 1：{x : χ_A(x) > α} = A
- α ⩾ 1：{x : χ_A(x) > α} = ∅

正确分段应为 X（α < 0）、A（0 ⩽ α < 1）、∅（α ⩾ 1）；原文将 α ∈ (−∞, 1) 整段映到 A，遗漏 α < 0 时应得 X。结论「χ_A 可测」不受影响（X、A、∅ 均属 𝒜），但公式本身不自洽。详见 [[queries/式12-210特征函数原像区间疑误]]。
