# 式 17.23 埃农映射平衡点与不变流形转录复算

对手册 17.1.3.2 埃农映射算例 (17.23) 的全部数值断言作独立复算，结果**全部核验通过**；另补出原文脱文的系数方程与两处分型信息。

## 原文断言与复算对照

| 断言 | 原文 | 复算 | 判定 |
|---|---|---|---|
| 平衡点 | $P_1=(\sqrt2,\sqrt2)$，$P_2=(-\sqrt2,-\sqrt2)$ | $x=x^2+x-2\Rightarrow x^2=2\Rightarrow x=\pm\sqrt2$ | ✓ |
| 平移后系统 | $\xi_{i+1}=\xi_i^2+2\sqrt2\xi_i+\eta_i$，$\eta_{i+1}=\xi_i$ | 展开 $(\xi+\sqrt2)^2+\eta+\sqrt2-2$ 后平移 | ✓ |
| 特征值 | $\lambda_{1,2}=\sqrt2\pm\sqrt3$ | $\lambda^2-2\sqrt2\lambda-1=0$ 之根，$\approx 3.1463$ 与 $-0.3178$ | ✓ |
| 特征向量 | $a_1=(\sqrt2+\sqrt3,1)$，$a_2=(\sqrt2-\sqrt3,1)$ | 雅可比第二行给出 $v_1=\lambda v_2$ | ✓ |
| $E^s,E^u$ | $E^s=\{ta_2\}$，$E^u=\{ta_1\}$ | $a_2$ 方向特征值模 $0.318<1$，$a_1$ 方向 $3.146>1$ | ✓ |
| $\beta$ 线性项 | $\beta(\xi)=(\sqrt3-\sqrt2)\xi+k\xi^2+\cdots$ | $1/\lambda_1=1/(\sqrt2+\sqrt3)=\sqrt3-\sqrt2\approx 0.3178$ | ✓ |
| $k<0$ | 断言 $k<0$（系数方程脱文） | $k=-b_1^3/(1+b_1^3)$，$b_1=\sqrt3-\sqrt2$，$k\approx-0.0311<0$ | ✓（结论成立，方程补全） |

## 复算补充（原文未明言，属推导补全）

- $P_1$ 一个特征值模小于 1、一个大于 1，为 $(1,1)$ 型鞍点；$P_2$ 处 $Df(P_2)=\begin{pmatrix}-2\sqrt2&1\\1&0\end{pmatrix}$，特征值 $-\sqrt2\pm\sqrt3\approx 0.318,\ -3.146$，同为 $(1,1)$ 型鞍点。
- $\det Df\equiv-1$，映射可逆，满足 $W^u$ 负向定义的可逆性前提。
- 手册形式 $(x^2+y-2,\ x)$ 经 $(x,y)\mapsto(-x,-y)$ 共轭于经典参数 $a=2,\ b=1$（取 $x_{t+1}=a-x_t^2+b\,y_t$ 形式）的 $(2-x^2+y,\ x)$：确属埃农映射族，但符号约定与经典式不同。

## 复算方法

手工代数推导加数值核验（特征方程求根、幂级数系数比对；流程见 [[methodology/双曲平衡点局部不变流形的幂级数确定流程]] 步骤 5）。证据分两类：原文数值断言的逐条核对（直接证据）与脱文系数方程的推导补全（推断，已标注）。
