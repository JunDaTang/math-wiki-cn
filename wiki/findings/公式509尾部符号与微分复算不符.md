# 公式 509 尾部符号与微分复算不符

[[sources/10-数学手册原书第10版--13-2174-其他超越函数积分--17odu4w|数学手册 21.7.4.4]] 公式 509 的尾部符号（$x^7$ 项起）与微分复算结果不符，且与其自身前几项的交替规律矛盾。原文逐字：

```
509. ∫ (arccot(x/a)/x) dx = (π/2) ln x − x/a + x³/(3²a³) − x⁵/(5²a⁵) − x⁷/(7²a⁷) − …
```

## 复算推导

由 $\operatorname{arccot}\frac{x}{a} = \frac{\pi}{2} - \arctan\frac{x}{a}$ 及 502（经复算正确）：

$$\int\frac{\arctan\frac{x}{a}}{x}dx = \frac{x}{a} - \frac{x^3}{3^2a^3} + \frac{x^5}{5^2a^5} - \frac{x^7}{7^2a^7} + \cdots \quad (|x|<|a|)$$

逐项积分应得

$$\int\frac{\arccot\frac{x}{a}}{x}dx = \frac{\pi}{2}\ln x - \frac{x}{a} + \frac{x^3}{3^2a^3} - \frac{x^5}{5^2a^5} + \frac{x^7}{7^2a^7} - \cdots$$

即自 $x^7$ 项起应**交替变号**（+、−、+、…）；转写中 $x^7$ 项起全为「−」。原文前段 $-\frac{x}{a} + \frac{x^3}{\cdots} - \frac{x^5}{\cdots}$ 本已呈交替规律，尾部符号破坏了该规律，故为强内证。

## 旁证

- 同构的 496（arccos 系列，$\frac{\pi}{2}\ln x$ 后全负号）与 502（arctan 系列，交替号）均与复算相符，唯 509 尾部不符。
- 互补求和核验：502 与 509（修正后）之和应为 $\int\frac{\pi/2}{x}dx = \frac{\pi}{2}\ln x$，与修正形式相合。

## 附带脱漏

509 脱漏了 502 所附的收敛条件 $(|x|<|a|)$。

## 归属与证据类型

- 此讹仅归于公式 509；502、496 复算无误，不可将 509 之讹外推至二者，反之亦然。
- 证据类型：直接证据（级数逐项积分）加同构式旁证，两条独立路径一致，故记 replicated: true。刊本核对之悬案见 [[queries/公式509尾部符号疑应交替之辨]]。
