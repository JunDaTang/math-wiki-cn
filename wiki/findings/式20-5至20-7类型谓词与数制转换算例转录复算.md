## 复算注记

**注 1（PrimeQ[1075643]）**：完整素性验证需试除全部不超过 √1075643 ≈ 1037.1 的素数，本次未完成；抽样试除至 211 未见因子。作为旁证，其对照组 1075641 已完全分解为 3·7·17·23·131（验算：3·7 = 21，21·17 = 357，357·23 = 8211，8211·131 = 1075641），故 (20.5c) 之 False 为直接证据，(20.5b) 之 True 暂以源稿输出为准、待机验收口。

**注 2（N[E, 20]）**：e = 2.718281828459045235360…，取 20 位有效数字（第 21 位为 6，进位）得 2.7182818284590452354，与源稿一致。

**注 3（Rationalize[E, 10^-5]）**：1071/394 = 2.718274111675…，|E − 1071/394| ≈ 7.72×10⁻⁶ < 10⁻⁵。由 e 的连分数展开 [2; 1, 2, 1, 1, 4, 1, 1, 6, …] 知：收敛元 193/71（误差 ≈ 2.80×10⁻⁵）与 1264/465（分母 465）之间的中间分数（semiconvergent）依次为 299/110、492/181、685/252、878/323（误差 ≈ 1.56×10⁻⁵）、1071/394；1071/394 是分母最小且误差 ≤ 10⁻⁵ 的分数，与 Mathematica「给出该精度下可能的最佳逼近」的叙述吻合。

**注 4（BaseForm[N[E, 10], 8]）**：对小数部分 0.718281828… 逐位乘 8 取整，得数字序列 5, 5, 7, 6, 0, 5, 2, 1, 3, 0, …，即 E 的八进制表示 2.5576052130…₈，取 10 位有效数字与源稿一致。

## 叙述性论断的复算状态

「`5.731 + 0 I` 为 Real 类型而 `5.731 + 0. I` 为 Complex 类型」：源稿未印出 Head 检验算例，属叙述性论断（推断层面）。按 Mathematica 语义可自洽：`0 I` 化简为精确整数 0，故 5.731 + 0 I 即 5.731（Real）；`0. I` 中的 `0.` 为近似零并被保留，故结果为 Complex。列为待机验项。
