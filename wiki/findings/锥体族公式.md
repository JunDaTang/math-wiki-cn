# 锥体族公式（式 3.148–3.155）

**直接证据**（源文 3.3.4(8)–(10)，图 3.71–3.73）。

**一般锥**（封闭准线锥面 + 一个平面截出的底）：

$$V = \frac{h A_G}{3} \tag{3.148}$$

**直圆锥**（底为圆、顶点在该圆上方正对着圆心；l 母线长、R 底圆半径，两符号转写脱落）：

$$V = \frac{1}{3}\pi R^{2}h \tag{3.149}$$
$$M = \pi R l = \pi R\sqrt{R^{2} + h^{2}} \tag{3.150}$$
$$S = \pi R(R + l) \tag{3.151}$$

**直锥台（截锥）**（R、r 为两底半径）：

$$l = \sqrt{h^{2} + (R - r)^{2}} \tag{3.152}$$
$$M = \pi l(R + r) \tag{3.153}$$
$$V = \frac{\pi h}{3}\left(R^{2} + r^{2} + Rr\right) \tag{3.154}$$
$$H = h + \frac{hr}{R - r} \tag{3.155}$$

**独立核验（已复核）**：

- 3.150 中 l = √(R²+h²) 为轴截面半勾股（独立可核）。
- 3.154 端点退化自洽：r → 0 退化为 3.149（锥）、r → R 退化为柱 V = πR²h ✓；结构为「两端点 + 几何平均项」，与 [[findings/棱锥与截棱锥公式]] 的 3.131 同型。
- 3.155 为延长回完整锥的高：由轴截面相似三角形得 H = hR/(R−r)，而 hR/(R−r) = h + hr/(R−r) ✓。

**归属警示**：3.148 属任意锥（任意底形状）；3.149–3.151 仅属直圆锥；3.152–3.155 仅属直锥台（平行于底的截断）。
