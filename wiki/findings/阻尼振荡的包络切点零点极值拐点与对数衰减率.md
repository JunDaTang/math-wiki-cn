# 阻尼振荡的包络切点零点极值拐点与对数衰减率（式 2.139）

**结论**：手册 2.7.3.4 给出阻尼振荡 $u(t)=A\mathrm{e}^{-at}\sin(\omega t+\varphi_0)$（$a,t>0$）的完整特征点体系：正弦曲线介于指数包络 $u(t)=\pm A\mathrm{e}^{-at}$ 之间并与之相切，随曲线渐近趋近 t 轴而衰减。

## 特征点（$k=0,1,2,\cdots$）

```latex
% 与包络 ±A·e^{-at} 的切点
A_k = ( ((k+1/2)π - φ₀)/ω ,  (-1)^k A·exp(-a·((k+1/2)π - φ₀)/ω) )
% 与坐标轴的交点
B = (0, A·sin φ₀),   C_k = ( (kπ - φ₀)/ω , 0 )
% 极值点 D_k:  t_k = (kπ - φ₀ + α)/ω
% 拐点  E_k:  t_k = (kπ - φ₀ + 2α)/ω,   其中 tan α = ω/a
% 对数衰减率（y_i、y_{i+1} 为相继极值的纵坐标）
δ = ln|y_i / y_{i+1}| = a·π/ω
```

## 证据与验证

**直接证据**：手册 2.7.3.4 原文（图 2.42）。

**独立验证（符号推导复算，全部吻合）**：

- 极值条件 $u'(t)=0$ 化为 $\tan(\omega t+\varphi_0)=\frac{\omega}{a}$，解得 $t_k=\frac{k\pi-\varphi_0+\alpha}{\omega}$（$\tan\alpha=\frac{\omega}{a}$），与手册一致；
- 拐点条件化为 $\tan 2(\omega t+\varphi_0)=\frac{2a\omega}{a^2-\omega^2}$，解得 $t_k=\frac{k\pi-\varphi_0+2\alpha}{\omega}$，与手册一致；
- 对数衰减率：相继极值时间差 $\frac{\pi}{\omega}$，纵坐标比含因子 $\mathrm{e}^{a\pi/\omega}$，故 $\delta=a\frac{\pi}{\omega}$，与手册一致。
