# 式 14.48a–14.48c 泰勒级数转录复算

对 14.3.2 泰勒级数公式 (14.48a–c) 的转录与自洽性复算。

## 转录内容

```latex
(14.48a) f(z) = Σ_{n=0}^∞ a_n (z - z_0)^n        （泰勒级数）
(14.48b) a_n = f^{(n)}(z_0) / n!
(14.48c) f(z) = f(z_0) + f'(z_0)/1!·(z - z_0) + f''(z_0)/2!·(z - z_0)^2 + ...
               + f^{(n)}(z_0)/n!·(z - z_0)^n + ...
```

## 独立复算

- **系数公式自洽**：以 $f(z) = 1/(1-z)$、$z_0 = 0$ 验证：$f^{(n)}(0) = n!$，故 $a_n = n!/n! = 1$，与几何级数 $\sum_{n\ge0} z^n$ 一致。✓
- **“每个幂级数在其收敛圆内部是其和函数的泰勒展式”**：由 14.3.1.3.3 逐项求导合法，代入 $z = z_0$ 逐次得 $P^{(n)}(z_0) = n!\,a_n$，即 $a_n = P^{(n)}(z_0)/n!$。✓
- **与 14.3.3 延拓例的相容性**：$\frac{1}{1-z} = \frac{1}{1-\mathrm{i}}\sum_{n\ge0}\left(\frac{z-\mathrm{i}}{1-\mathrm{i}}\right)^n$ 正是围绕 $z_1 = \mathrm{i}$ 的泰勒展式（$b_n = 1/(1-\mathrm{i})^{n+1} = f^{(n)}(\mathrm{i})/n!$）。✓

## 结论

公式转录与独立复算一致，confidence: high，replicated: true。
