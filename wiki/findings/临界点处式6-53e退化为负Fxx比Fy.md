# 临界点处式 6.53e 退化为 y″ = −F_xx/F_y（跨节综合推断）

**证据类型**：直接证据为下述代数退化（可独立复推）；"由此解释 6.1.5 判据"一层为跨节综合推断——《数学手册(原书第10版)》6.2.3 与 6.1.5 两处均未明言此联系。

## 推导

隐函数 y(x) 的临界点处 y′ = 0，由式 6.53c（y′ = −F_x/F_y，F_y ≠ 0）即 F_x = 0。代入式 6.53e：

```
y″|_{F_x=0} = [2·0·F_y·F_xy − (F_y)²·F_xx − 0²·F_yy] / (F_y)³
            = −(F_y)²·F_xx / (F_y)³
            = −F_xx / F_y
```

即临界点处 y″ = −F_xx/F_y。此代入退化为纯代数运算，可独立复推。✓

## 与 6.1.5 隐函数极值判据的联系

[[findings/隐函数极值Fy与Fxx符号判据]]（源自 6.1.5「极值和拐点的确定」）以 F_y 与 F_xx 的符号判定隐函数极值。上式表明其根源：临界点处

sign(y″) = −sign(F_xx) · sign(F_y)，

例如 F_y > 0 且 F_xx < 0 时 y″ > 0（极小值型），F_y > 0 且 F_xx > 0 时 y″ < 0（极大值型）；F_y < 0 时方向反转。这与 6.1.5 判据以 F_y、F_xx 两个符号为判据完全吻合——该判据可视为式 6.53e 在 F_x = 0 处的退化形式。判据的具体方向（极大/极小对应的符号组合）应以 [[findings/隐函数极值Fy与Fxx符号判据]] 页的转录为准。
