# 圆的解析方程组（式 3.314–3.319）

圆是与给定点（圆心）有相同给定距离（半径）的点的轨迹。本源 3.5.2.7（节题「圆」在转写中脱落）给出其解析处理：

```
圆心在原点:    x² + y² = R²                                   (3.314a)
圆心在 C(x₀,y₀): (x − x₀)² + (y − y₀)² = R²                    (3.314b)
一般二次方程 ax²+2bxy+cy²+2dx+2ey+f=0 为圆 ⟺ b=0 且 a=c，
可化为:        x² + y² + 2mx + 2ny + q = 0                     (3.315b；编号被误排为 (3.135b))
半径与圆心:    R = √(m² + n² − q),  x₀ = −m,  y₀ = −n           (3.316)
参数式:        x = x₀ + R·cos t,  y = y₀ + R·sin t              (3.317)
极坐标一般式:  ρ² − 2ρρ₀cos(φ − φ₀) + ρ₀² = R²                  (3.318a)
圆心在极轴上且过极点:  ρ = 2R·cos φ                            (3.318b)
切线（圆 (3.314a) 在 P(x₀,y₀) 处）:  x·x₀ + y·y₀ = R²           (3.319)
```

退化情形（复算成立，视为已复算）：q > m² + n² 时该方程定义一条虚曲线（无实点）；q = m² + n² 时曲线退化为单独一个点 P(x₀, y₀)。

## 与 3.1.6 综合几何圆页的关系

本组公式与 [[concepts/圆]]（源自 3.1.6，弦定理/割线定理/切割线定理等综合几何语言）是同一对象的两种语言：综合定理刻画交点比例关系，解析方程刻画整体轨迹，二者互补、互不隶属。编号讹误 (3.135b)→(3.315b) 见 [[queries/双曲线小节疑似讹误清单]]。
