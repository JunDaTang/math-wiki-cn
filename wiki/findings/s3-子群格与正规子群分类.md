# S₃ 的子群格与正规子群分类（已复核）

《数学手册(原书第10版)》5.3.3.2 例 C 给出 $S_3$ 的全部子群，并断言除平凡正规子群外仅有 $U_4$ 正规。本发现对该分类逐项复核，确认成立；同时记录原文的一处关键脱字。

## 子群列表（依本节）

$$E = \{\varepsilon\},\quad U_1 = \{\varepsilon, p_1\},\quad U_2 = \{\varepsilon, p_2\},\quad U_3 = \{\varepsilon, p_3\},\quad U_4 = \{\varepsilon, p_4, p_5\},\quad S_3$$

依据拉格朗日定理，6 阶群的非平凡子群只可能有 2 或 3 个元素（原文「有 个元素的群 $S_3$ 可能仅有 个或 元素的子群」脱落 6、2、3）。

## 复核记录（直接证据）

- $p_1, p_2, p_3$ 为对换（阶 2），故 $U_1, U_2, U_3$ 封闭且为 2 阶子群。✓
- $p_4$ 为 3 循环：$p_4^2 = p_5$、$p_4^3 = \varepsilon$，故 $U_4 = \{\varepsilon, p_4, p_5\}$ 为 3 阶子群。✓
- 2 与 3 均为素数，故 $U_1, \dots, U_4$ 都是循环的（素数阶有限群必循环，见 [[concepts/循环群与生成子群]]）。✓
- $U_4$ 的指标为 $6/3 = 2$，指标 2 的子群必正规（见 [[concepts/正规子群]]），故 $U_4 \trianglelefteq S_3$。✓
- $U_1, U_2, U_3$ 不正规：例如 $p_4 U_1 = \{p_4, p_2\} \neq \{p_4, p_3\} = U_1 p_4$。✓ 与「除平凡正规子群外仅有 $U_4$」一致。

## 关键讹误（须注意）

原文：「非平凡子群 $U_1, U_2, U_3$ 及 $U_4$ 是循环的，因为它们的元素个数是素数，**但群 $S_3$ 是循环的**」。

最后一句必为「但群 $S_3$ **不是**循环的」——$S_3$ 非交换（$p_1\circ p_2 \neq p_2\circ p_1$，见 [[findings/s3-凯莱表与置换记号算例]]），非交换群不可能循环，且与其自身群表矛盾。这是全节最严重的转写讹误，单独立题跟踪：[[queries/s3循环性断言是否脱落不字]]。
