# 式 19.118–19.120 差分法与特征值算例复算

**转录**（源文逐字保留）：

```latex
(19.118)  y'' + p(x)y' + q(x)y = f(x)  (a \leqslant x \leqslant b),  y(\alpha)=\alpha,\ y(\beta)=\beta
(19.119)  y''(x_\nu) + p(x_\nu)y'(x_\nu) + q(x_\nu)y(x_\nu) = f(x_\nu)  (\nu = 1,\dots,n-1)
(19.120a) y'(x_\nu) \approx \frac{y_{\nu+1} - y_{\nu-1}}{2h}
(19.120b) y''(x_\nu) \approx \frac{y_{\nu+1} - 2y_\nu + y_{\nu-1}}{h^2}
```

特征值算例（源文）：y″ + λ²y = 0，y(0) = y(1) = 0，三内点 h = 1/4，差分方程 y_{ν+1} − 2y_ν + y_{ν−1} + h²λ²y_ν = 0 给出

```latex
(-2 + \lambda^2/16) y_1 + y_2 = 0
y_1 + (-2 + \lambda^2/16) y_2 + y_3 = 0
y_2 + (-2 + \lambda^2/16) y_3 = 0
```

系数行列式为零 ⟹ λ₁² = 9.37, λ₂² = 32, λ₃² = 54.63；源文称这些特征值中只有最小的一个接近相应的真值 9.87。

**复算（独立验证，通过）**：

- 该三对角矩阵的特征值为 64sin²(νπ/8)：9.3726、32、54.627，与源文 9.37 / 32 / 54.63 一致。
- 真值 (νπ)²：最小者 π² ≈ 9.8696，与源文“真值 9.87”一致；第二、三个真值约 39.48、88.83，与离散值 32、54.63 偏差甚大——印证源文“仅最小特征值接近真值”的自身告警。
- 中心差分 (19.120a,b) 均为 O(h²) 逼近，与源文一致。

**记号疑误**：(19.118) 的边界条件 y(α)=α、y(β)=β 疑为 y(a)=α、y(b)=β，见 [[queries/边界条件yα等于α之α疑为a之辨]]。见 [[concepts/差分法（边值问题）]]。
