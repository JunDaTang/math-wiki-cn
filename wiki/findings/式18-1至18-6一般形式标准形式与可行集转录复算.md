# 式 18.1–18.6 一般形式、标准形式与可行集转录复算

对《数学手册(原书第10版)》18.1.1.1 的式 18.1–18.6 进行逐条转录并复算其内部一致性。结论：公式体系自洽，未发现推导或数值错误；转录文本存在若干 OCR 讹误（不影响公式结构），已单列 [[queries/18-1-1全节系统性转写讹误清单]]。完整 verbatim 转录见源页。

## 关键公式（转录）

```text
(18.3)   −f(x) = max!
(18.5a)  f(x) = cᵀx = max!
(18.5b)  Ax = b,  x ⩾ 0
(18.6a)  M = {x ∈ ℝⁿ : x ⩾ 0, Ax = b}
(18.6b)  f(x*) ⩾ f(x),  ∀x ∈ M  ⟹  x* 为极大点（解点）
```

一般形式（18.1a/b）与分块向量形式（18.2a–e）的完整展开见 [[sources/10-数学手册原书第10版--15-1811-问题的提法和几何表达--w8nsz6]]。

## 复算

1. **18.2a 与 18.1a 的对应**：分块 c = (c¹; c²)、x = (x¹; x²) 按前 r 个非负变量与后 n−r 个自由变量切分，(c¹)ᵀx¹ + (c²)ᵀx² 展开即 18.1a 的目标函数；A₁₁、A₁₂ 承载前 s 行「⩽」约束，A₂₁、A₂₂ 承载后 m−s 行等式约束，与 18.1a 的约束排列一致 ✓
2. **极小→极大（18.3）**：min f(x) ⟺ max(−f(x))，最优解集合不变，最优值相差一个符号 ✓
3. **自由变量分解**：任意实数 xₖ 均可写成两个非负数之差（如取 xₖ¹ = max(xₖ, 0)、xₖ² = max(−xₖ, 0)），分解不改变可行域在原变量上的投影 ✓
4. **松弛化**：a_{i,·}x ⩽ bᵢ ⟺ 存在 x_s ⩾ 0 使 a_{i,·}x + x_s = bᵢ（取 x_s = bᵢ − a_{i,·}x），等价性成立 ✓
5. **可行集（18.6a）**：M 为有限个闭半空间与超平面之交（加非负卦限限制），是闭凸多面体集；二维情形即诸半平面之交 ✓
6. **解点（18.6b）**：f(x*) ⩾ f(x) ∀x ∈ M 为极大点的标准定义；由第 4 条的等价性，x* 的非松弛分量满足原问题的全部不等式且目标值不变，故构成原问题的解 ✓
7. **m ⩽ n 假定**：若 m > n，则 m 个方程对 n 个变量超定，方程组或不相容（矛盾）或含可由其余方程表出的方程（线性相关）——手册断言成立，但「相关」与「矛盾」并列的表述偏粗（相关方程仍可能相容，此时问题仍有意义）。
