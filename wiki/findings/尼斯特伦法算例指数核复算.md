# 尼斯特伦法算例指数核复算

## 算例陈述（转录）

用尼斯特伦法对 $n=3$ 解积分方程（$\lambda=1$ 隐含，$[a,b]=[0,1]$，故 $\omega_k = A_k$）：

$$
\varphi(x) = \cos\pi x + \frac{x}{x^2+\pi^2}\left(\mathrm{e}^x + 1\right) + \int_0^1 \mathrm{e}^{xy}\,\varphi(y)\,\mathrm{d}y.
$$

原文数据：$A_1=0.2778$，$A_2=0.4444$，$A_3=0.2778$；$x_2=0.5$，$x_3=0.8873$（**$x_1$ 未列出**）；$f_1=0.96214$，$f_2=0.13087$，$f_3=-0.65251$；$K_{11}=1.01278$，$K_{22}=1.28403$，$K_{33}=2.19746$，$K_{12}=K_{21}=1.05797$，$K_{13}=K_{31}=1.10517$，$K_{23}=K_{32}=1.55838$；系统解 $\varphi_1=0.93651$，$\varphi_2=-0.00144$，$\varphi_3=-0.93950$；精确解在节点处 $0.93797$，$0$，$-0.93797$。

## 独立复算（全部通过）

- **隐含精确解验证**：设 $\varphi(x)=\cos\pi x$。由 $\int \mathrm{e}^{ay}\cos(by)\,\mathrm{d}y = \mathrm{e}^{ay}\frac{a\cos by + b\sin by}{a^2+b^2}$ 逐项计算得
  $$\int_0^1 \mathrm{e}^{xy}\cos\pi y\,\mathrm{d}y = \frac{\mathrm{e}^x(x\cos\pi + \pi\sin\pi)}{x^2+\pi^2} - \frac{x}{x^2+\pi^2} = -\frac{x(\mathrm{e}^x+1)}{x^2+\pi^2},$$
  故 $f(x)=\cos\pi x + \frac{x}{x^2+\pi^2}(\mathrm{e}^x+1)$ 恰使 $\varphi=\cos\pi x$ 为精确解。✓
- **节点**：$x_1 = 0.5(1-0.7746) = 0.1127$（原文缺录，由 (11.28a) 重建）。✓
- **$f$ 值**：$f(0.1127)=0.96215$、$f(0.5)=0.13087$、$f(0.8873)=-0.65249$，与表值一致（末位 $\pm10^{-5}$）。✓
- **$K$ 值**：$K_{jk}=\mathrm{e}^{x_jx_k}$ 逐项复算一致（如 $\mathrm{e}^{0.1127^2}=1.01278$、$\mathrm{e}^{0.25}=1.28403$、$\mathrm{e}^{0.1127\times0.8873}=\mathrm{e}^{0.10000}=1.10517$）。✓
- **系统系数**：$1-\omega_1K_{11}=0.71865$、$-\omega_2K_{12}=-0.47016$、$-\omega_3K_{13}=-0.30702$ 等逐项一致。✓
- **解与误差**：解 $(0.93651, -0.00144, -0.93950)$ 对精确节点值 $(0.93797, 0, -0.93797)$，误差约 $1.5\times10^{-3}$。✓

## 末位出入记录

- 第 2 行对角元：原文 $0.42938$，用表值 $A_2=0.4444$ 复算得 $0.42938$，用精确权 $4/9$ 得 $0.42932$——出入可用权的四舍五入解释（推断）；
- 第 3 行对角元：原文 $0.38955$，复算 $0.38951$（同量级末位出入）。

此类 $10^{-4}\sim10^{-5}$ 级出入是否原书即如此，待对原书核对，见 [[queries/尼斯特伦法算例x1缺录]]。

## 结论

算例数值整体可信：精确解隐含结构、全部函数值/核值/系统系数/解均通过独立复算；转写存在一处节点缺录（$x_1=0.1127$）与个别末位出入。$n=3$ 即达 $10^{-3}$ 量级精度，支持"高斯求积以少量节点获得高精度"的论断（见 [[comparisons/高斯求积与矩形公式比较]]）。
