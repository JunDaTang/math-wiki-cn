# 多项式同余分解与提升法算例（式 5.259–5.260，x = 22 已复算）

**来源**：[[sources/10-数学手册原书第10版--10-543-同余和剩余类--n0ce67]]（5.4.3.9）。

**陈述一（互素模分解，5.259）**：m₁, …, m_t 两两互素时，f(x) ≡ 0 (m₁⋯m_t) ⟺ 各 f(x) ≡ 0 (m_j)；若后者各有 k_j 个解，则前者有 k₁⋯k_t 个解。于是 f(x) ≡ 0 (p₁^{α₁}⋯p_t^{α_t}) 归结为各 f(x) ≡ 0 (p^α)。

**陈述二（提升，5.260）**：a) f(x) ≡ 0 (p^α) 的解也是 f(x) ≡ 0 (p) 的解；b) 当且仅当 p 不整除 f′(x₁) 时，f(x) ≡ 0 (p) 的解 x ≡ x₁ (p) 由模 p^α 的解唯一确定。操作：令 x = x₁ + p t₁，解线性同余式 f(x₁)/p + f′(x₁)t₁ ≡ 0 (p)（5.260a）得 t₁′；代回迭代至模 p^α。

**复算（算例全程通过）**：解 f(x) = x⁴ + 7x + 4 ≡ 0 (mod 27)：

1. 模 3：f(x) ≡ x⁴ + x + 1 (3)；f(0) = 1、f(1) = 3 ≡ 0、f(2) = 19 ≡ 1，唯一解 x ≡ 1 (3)。
2. f′(x) = 4x³ + 7，f′(1) = 11，3 ∤ 11，提升唯一。
3. f(1) = 12，f(1)/3 = 4：4 + 11t₁ ≡ 0 (3) ⟹ 1 + 2t₁ ≡ 0 (3) ⟹ t₁ ≡ 1 (3)（4 + 11 = 15 ≡ 0 ✓）。x = 1 + 3(1 + 3t₂) = 4 + 9t₂。
4. f(4) = 288，f(4)/9 = 32；f′(4) = 263 ≡ 2 (3)、32 ≡ 2 (3)：2 + 2t₂ ≡ 0 (3) ⟹ t₂ ≡ 2 (3)（32 + 263·2 = 558 = 3·186 ✓）。x = 4 + 9(2 + 3t₃) = 22 + 27t₃。
5. 验算：f(22) = 22⁴ + 7·22 + 4 = 234256 + 154 + 4 = 234414 = 27·8682 ✓。故 x = 22 是模 27 唯一解。

**证据类型**：直接证据（算法 + 算例逐步复算）。

**转写备注**：(5.260b) 段「模 p² 解 t₂′」疑应为「模 p 解」（该线性同余式本身是模 p 的），见 [[queries/式5-260b模p2解应为模p解吗]]；b) 条件「当且仅当 不整除 f′(x₁)」脱落 p。本算法即通称的 Hensel 提升，源文未命名。
