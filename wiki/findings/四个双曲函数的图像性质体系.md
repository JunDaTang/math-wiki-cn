# 四个双曲函数的图像性质体系

手册 2.9.2 仅为 sinh、cosh、tanh、coth 四个函数设置图像小节，逐函数给出奇偶、单调、渐近线、拐点与切线角等性质；sech 与 csch 无图像讨论。各函数的性质归属如下（不得跨函数转移）：

## sinh（2.9.2.1，图 2.49）

奇函数；严格单调递增；值域 −∞ 到 +∞；原点既为对称中心又为拐点，该处切线倾斜角 φ = π/4；无渐近线。

## cosh（2.9.2.2，图 2.50）

偶函数；x < 0 时从 +∞ 递减至 1，x > 0 时从 1 递增至 +∞；x = 0 取最小值 1（点 A(0,1)）；无渐近线；曲线关于 y 轴对称，恒位于抛物线 y = 1 + x²/2（虚线）上方（两曲线在 A(0,1) 相切，「上方」含等号）；曲线即 [[concepts/悬链线]]（参见 2.15.1）。

## tanh（2.9.2.3，图 2.51）

奇函数；在 ℝ 上从 −1 到 1 严格单调递增；原点既为对称中心又为拐点，该处切线倾斜角 φ = π/4；渐近线 y = ±1。

## coth（2.9.2.4，图 2.52）

奇函数；x = 0 处不连续；−∞ < x < 0 时从 −1 递减至 −∞，0 < x < +∞ 时从 +∞ 递减至 1（两支均严格递减）；无拐点和极值；渐近线 x = 0 与 y = ±1（手册设有图像小节的四个函数中唯一有竖直渐近线者）。

## 核验与推断说明

- 上述陈述均可由式 2.166–2.169 的定义导出，自洽；属直接证据。
- 切线角 φ = π/4 等价于原点处斜率为 1：sinh′(0) = cosh(0) = 1，tanh′(0) = sech²(0) = 1（此为核验时引入的导数推断，手册未用导数表述）。
- coth 在 x = 0 的不连续，按 2.1.5 的间断点分类属无穷间断（极点）——手册本身未作此归类，此为依据 [[concepts/间断点]] 体系的推断。
- 手册称曲线「如图 2.48~图 2.52 所示」共五图，而 2.9.2 仅覆盖四函数（图 2.49–2.52）；图 2.48 内容待确认（[[queries/图2-48是否为sech与csch的曲线]]）。
