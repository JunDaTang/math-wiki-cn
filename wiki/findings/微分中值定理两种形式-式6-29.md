# 微分中值定理两种形式（式 6.29）

## 断言

**对象**：微分中值定理（6.1.4.4）。**题设**：函数 y=f(x) 在闭区间 [a,b] 连续，开区间 (a,b) 可微。**结论**：a、b 间至少存在一点 c，满足

```latex
(6.29a)  \frac{f(b)-f(a)}{b-a} = f'(c)                (a < c < b)
(6.29b)  f(a+h) = f(a) + h\,f'(a+\Theta h)            (0 < \Theta < 1)
```

式 6.29b 由 6.29a 令 b=a+h、Θ 为介于 0 与 1 之间的一个数改写而得（原文「θ 为介千 之间的一个数」脱落数字，订正见 [[queries/6-1-4全节系统性转写讹误清单]]）。

## 几何意义

若函数满足定理条件，则函数图像 A、B 间至少有一点 C，使得该点处的切线与线段 AB 平行（图 6.9）；也可能存在多个这样的点（原文作「图 6.S(b)」，所指待核，见 [[queries/图6-S-b所指何图]]）。通过例子以及图 6.8(c)、(d) 可以看出，连续性与可微性的性质非常重要。

## 证据强度与备注

- 标准结果，表述正确；两种形式的改写关系明确。
- 几何断言依赖图 6.9 内容，未独立核验（replicated: null）。
