# 阶乘推广与斯特林公式复算（式 8.103）

## 逐字转录

```latex
x! = \Gamma(x+1) \tag{8.103a}

x \text{ 为正整数}: \; x! = 1\cdot 2\cdot 3 \cdots x; \qquad 0! = \Gamma(1) = 1; \qquad x \text{ 为负整数}: \; x! = \pm\infty \tag{8.103b--d}

\left(\frac{1}{2}\right)! = \Gamma\!\left(\frac{3}{2}\right) = \frac{\sqrt{\pi}}{2}; \quad
\left(-\frac{1}{2}\right)! = \Gamma\!\left(\frac{1}{2}\right) = \sqrt{\pi}; \quad
\left(-\frac{3}{2}\right)! = \Gamma\!\left(-\frac{1}{2}\right) = -2\sqrt{\pi} \tag{8.103e--g}

n! \approx \left(\frac{n}{\mathrm{e}}\right)^{n} \sqrt{2\pi n}\left(1 + \frac{1}{12n} + \frac{1}{288n^{2}} + \dots\right) \tag{8.103h}

\ln(n!) \approx \left(n+\frac{1}{2}\right)\ln n - n + \ln\sqrt{2\pi} \tag{8.103i}
```

## 复算记录（直接证据：独立重推导，全部一致）

- (1/2)! = Γ(3/2) = (1/2)Γ(1/2) = √π/2 ✓。
- (−1/2)! = Γ(1/2) = √π ✓；(−3/2)! = Γ(−1/2) = Γ(1/2)/(−1/2) = −2√π ✓。
- 0! = Γ(1) = 1 ✓；负整数处 Γ 为单极点，x! 两侧异号发散（±∞）✓。
- 斯特林公式：与标准渐近展开 n! ~ (n/e)ⁿ√(2πn)(1 + 1/(12n) + 1/(288n²) − ⋯) 的前三项一致 ✓；对数形式为取主导渐近后取对数的等价写法 ✓。
- 适用条件：原书「当数 n 大于 10 或为分数时」——分数 n 的阶乘经 x! = Γ(x+1) 有意义，条件自洽。

## 转写讹误

- 「当前阶乘的概念仅限千正整数」「千是有下面等式成立」中「千」应为「于」；「当数 n 大千 10 为分数时」应复原为「当数 n 大于 10 或为分数时」（误「于」为「千」并脱「或」）。
- 回指「第 15 1.1.6.4,3.」应为「第 15 页 1.1.6.4, 3.」。
