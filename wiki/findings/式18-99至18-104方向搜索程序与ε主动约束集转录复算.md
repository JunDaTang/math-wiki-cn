# 式 18.99–18.104 方向搜索程序与 ε 主动约束集转录复算

## 转录内容

一般情形的方向搜索程序：

```
σ = min!,                                               (18.99)
∇g_i(x^k)^T d ⩽ σ,   i ∈ I_0(x^k),                      (18.100a)
∇f(x^k)^T d ⩽ σ,                                        (18.100b)
‖d‖ ⩽ 1                                                 (18.100c)
```

反锯齿修正的标号集：

```
I_{ε_k}(x^k) = {i ∈ {1,…,m} : −ε_k ⩽ g_i(x^k) ⩽ 0},   ε_k ⩾ 0   (18.101)
```

线性约束特殊情形（$g_i(x)=a_i^{\mathrm{T}}x-b_i$）：

```
σ = ∇f(x^k)^T d = min!,                                 (18.102)
∇a_i^T d ⩽ 0,   i ∈ I_0(x^k) 或 i ∈ I_{ε_k}(x^k)        (18.103a)
‖d‖ ⩽ 1                                                 (18.103b)
d^{k−1 T} C d = 0                                       (18.104)
```

## 复算与验证

- $\sigma<0 \Rightarrow$ 可行性（a）与下降性（b）：由约束式直接读出；规格化 (c) 使程序可行集有界（紧），最优解存在；
- $\varepsilon_k=0$ 时 $I_{\varepsilon_k}(x^k)=I_0(x^k)$，与 [[concepts/主动约束集]] 一致；修正后 $\sigma=0$ 仅当 $I_0=I_{\varepsilon_k}$ 时判平稳，否则减小 $\varepsilon_k$ 重解——逻辑自洽；
- $\ell_\infty$ 范数下程序 (18.102–18.103) 为线性规划：$\|d\|_\infty\leqslant 1\Leftrightarrow -1\leqslant d_i\leqslant 1$，可用 [[concepts/单纯形法]]；$\ell_2$ 范数下目标含二次项 $\sqrt{d^{\mathrm{T}}d}$ 相关结构，程序非线性——与源内「计算量更大」的论断一致；
- 原书算例第 1、2、3 步的方向搜索程序均为相应线性规划的顶点最优解，独立验证通过（见 [[findings/可行方向法算例四步复算]]）。

- 式 (18.103a) 冠于 $a_i^{\mathrm{T}}$ 的 $\nabla$ 疑为衍文（$g_i$ 线性时 $\nabla g_i=a_i$），见 [[queries/式18-103a冠于ai梯度算子疑为衍文之辨]]；

- $\sigma=0$ 平稳点的源内理由句疑脱否定词，见 [[queries/σ为零平稳点理由句脱否定词之辨]]；
- 字级讹误（「共辄」＝「共轭」、“(18.lOOa)”＝“(18.100a)”等）汇总于 [[queries/18-2-7全节系统性转写讹误清单]]。
