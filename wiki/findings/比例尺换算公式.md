# 比例尺与面积的换算公式（式 3.103–3.104）

**发现内容（直接证据，公式逐字保留）：**在制图学中，比例因子是坐标系 $K_1$ 中的线段 $s_{K_1}$ 关于另一坐标系 $K_2$ 中对应线段 $s_{K_2}$ 之比。

(1) 线段的换算（$m$ 为模数或尺度，$K$ 为地图指标，$N$ 为自然指标）：

$$M = 1:m = s_K : s_N \tag{3.103a}$$

$$s_{K_1}:s_{K_2} = m_2:m_1 \tag{3.103b}$$

(2) 面积的换算（$F_K = a_K b_K$，$F_N = a_N b_N$）：

$$F_N = F_K m^2 \tag{3.104a}$$

$$F_{K_1}:F_{K_2} = m_2^2:m_1^2 \tag{3.104b}$$

即**长度按模数一次换算、面积按模数平方换算**，两个不同模数的图之间长度比反比于模数比、面积比反比于模数平方比。

**与坐标变换语境的衔接：**同一「比例因子」概念在 3.107–3.109 中以 q 的形式用于校正局部测量与坐标反算距离之差（$q = \sqrt{\Delta y^2+\Delta x^2}/s$，应非常接近 1）及两坐标系相似变换的整体缩放（$q = s_{AB}/s'_{AB}$），见 [[concepts/比例尺]]、[[findings/坐标互化与比例因子校正]]。

**转写备注：**定义句中「是模数或尺度， 是自然指标」等符号缺失，见 [[queries/平面三角学记号段符号缺失是否为讹误]]。**证据类型：**直接证据，强度高。
