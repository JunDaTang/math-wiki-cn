# 式 12.89a–12.89g 七类典型赋范空间转录复算

## 转录内容

- **A**：𝔽ⁿ，‖x‖ = (Σ_{k=1}^{n}|ξ_k|ᵖ)^{1/p}（1 ≤ p < ∞）；max_{1≤k≤n}|ξ_k|（p = ∞）；通常记作 ℓᵖ(n)（1 ≤ p ≤ ∞）。转录称 1 ≤ p < ∞ 时 𝔽 = ℝ 情形「称作欧儿里得空间」、𝔽 = ℂ 情形「称作酉空间」。
- **B**：m，‖x‖ = sup_k|ξ_k|（12.89b）。
- **C**：c₀，范数与 m 的相同（12.89c，转录缺「m」字）。
- **D**：ℓᵖ，‖x‖_p = (Σ_{n=1}^{∞}|ξₙ|ᵖ)^{1/p}，1 ≤ p < ∞（12.89d）。
- **E**：𝒞([a,b])，‖x‖ = max_{t∈[a,b]}|x(t)|（12.89e）。
- **F**：Lᵖ((a,b))，1 ≤ p < ∞（12.89f，范数未转录，回指第 905 页 12.9）。
- **G**：𝒞^{(k)}([a,b])，‖x‖ = Σ_{ℓ=1}^{k} max_{t∈[a,b]}|x^{(ℓ)}(t)|，文中并解释 x^{(0)}(t) 表示 x(t)（12.89g）。

## 复算（编者直接推导，经典内容）

- A、D 的三角不等式即 Minkowski 不等式（经典）；B 为有界序列的上确界范数（m 为有界序列空间、c₀ 为趋于零序列空间、c 为收敛序列空间，均为外部通行识别，本节未定义）；E 为连续函数上确界范数；c₀ ⊂ m 承袭同一范数。各例满足 N1–N3。✔
- **12.89g 下标必须为 0 的内部证明**：若求和从 ℓ = 1 开始，则任何非零常值函数 x(t) ≡ c 满足 x^{(ℓ)} ≡ 0（ℓ ≥ 1），得 ‖x‖ = 0，违反 N1。故求和应从 ℓ = 0 起（包含 max|x(t)| 项），与文中解释 x^{(0)} = x 一致。详见 [[queries/式12-89g求和下标应为零]]。
- **欧几里得/酉空间命名**：标准用法仅限 p = 2（范数来自内积的情形）；p ≠ 2 时 ℓᵖ(n) 不承载内积（平行四边形等式失败，外部经典判据）。转录的「1 ≤ p < ∞」疑应为「p = 2」，详见 [[queries/欧几里得空间命名p范围疑误]]。

## 发现的讹误

1. 12.89c「范数与 的范数相同」缺「m」。
2. 12.89f 范数公式未转录（仅回指 12.9）。
3. 「欧儿里得」为「欧几里得」之 OCR 错字。
4. 12.89g 求和下标 ℓ = 1 疑应为 ℓ = 0（如上证明）。

## 置信度与复算状态

各例为经典空间且已按公理复算，置信度高；命名条件与下标的更正有强内部/外部证据，仍需对照原书确认。尚无第二来源独立复算。
