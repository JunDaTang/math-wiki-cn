# 式 18.71a–c 坐标下降迭代格式与停机准则转录

## 转录

```text
(18.71a) x = x¹,  k = 1   （x¹ 为 x* 的适当初始近似）
(18.71b) φ(α_r) = f(x₁^{k+1}, …, x_{r−1}^{k+1}, x_r^k + α_r, x_{r+1}^k, …, x_n^k) = min!,  α_r ∈ ℝ
         ᾱ_r 为第 r 个一维问题的（精确或近似）极小点 ⇒ x_r^{k+1} = x_r^k + ᾱ_r
(18.71c) ‖x^{k+1} − x^k‖ < ε₁   或   |f(x^{k+1}) − f(x^k)| < ε₂
```

源文补充：若 18.71c 不满足，则以 k+1 代替 k 重复步骤 b)；b) 中的一维问题可用 18.2.4.1 的方法求解。源文标题为「n 维欧几里得向量空间中的极小搜索」（源文脱字符 n），问题为 f(x) = min!、x ∈ ℝⁿ（源文误作 ℝ，两处；18.71b 中 α_r ∈ ℝ 为标量自变量、不误）。

## 结构核验

- **Gauss–Seidel 式更新**：18.71b 中第 r 个坐标**之前**的分量带上标 k+1（本轮已更新），**之后**的分量带上标 k（尚未更新）——逐坐标即时更新。此细节原样保留，是辨识该格式为坐标下降（而非整体更新）的关键。
- **停机准则双重性**：向量范数准则（‖x^{k+1} − x^k‖ < ε₁，「在某种向量范数下」）与函数值准则（|f(x^{k+1}) − f(x^k)| < ε₂）二者任一满足即停。
- **子问题精度弹性**：ᾱ_r 允许是精确**或近似**极小点，格式不要求子问题精确求解。

## 理论覆盖缺口（推断，非源文论断）

源文对 [[concepts/坐标下降法]] **无任何收敛性论断**：未给出收敛条件、收敛速率，也未讨论一维子问题近似极小化误差的累积影响；停机准则为启发式。本节的陈述层面（格式定义自洽）与理论层面（无收敛保证）之间存在覆盖缺口，引用时不得声称该格式有收敛保证。
