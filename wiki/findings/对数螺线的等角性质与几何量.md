# 对数螺线的等角性质与几何量（式 2.249）

手册 2.14.3 节以等角性质定义[[concepts/对数螺线]]并给出弧长与曲率公式；本小节存在两处内部不自洽，须与本 finding 一并阅读。

## 内容

**定义性性质**：对数螺线与从原点 O 出发的所有射线的交角均相等，为 α。

**方程**：

$$
\rho = a ^ {k \varphi} (a > 0, - \infty < \varphi < \infty),\tag{2.249}
$$

其中 $k = \cot \alpha$。

**渐近点**：原点。

**几何量**：

- 弧长（$\widehat{P_1P_2}$）$L = \frac{\sqrt{1 + k^{2}}}{k} (\rho_{2} - \rho_{1})$；从原点到 P 的曲线 $\widehat{OP}$ 弧长的极限 $L_{0} = \frac{\sqrt{1 + k^{2}}}{k} \rho$；
- 曲率半径 $r = \sqrt{1 + k^{2}} \rho = L_{0} k$。

**圆的特例**：α = π/2 时 k = 0，曲线为圆（源文该段落重复出现两次且首条作 α = π/4，见下）。

## 核验与不自洽

1. **底数问题**：若按字面取 $\rho = a^{k\varphi}$（a 为任意正底数），则 $\rho' = k\rho\ln a$，恒定交角条件给出 $\cot\alpha = k\ln a$，仅当 a = e 时才与正文 $k = \cot\alpha$ 一致；且 L、L₀、r 三式均要求 $\rho' = k\rho$。若原式为 $\rho = a\,e^{k\varphi}$（乘号在转写中丢失，a 为比例常数），则以上全部公式自洽，且 k = 0 时 ρ = a 为半径 a 的圆，与「圆的特例」自然衔接。见 [[queries/式2-249底数a与k等于cotα是否自洽]]。
2. **特例重复**：「圆的特例」段落出现两次；首条作「若 α = π/4，则 k = 0」，但 $k = \cot(\pi/4) = 1 \neq 0$，为数学错误，疑为转写残留；第二条「若 α = π/2，则 k = 0」正确。见 [[queries/对数螺线圆的特例重复且首条α等于四分之π是否为误]]。
3. 等角性质本身以及 L、L₀、r 在「ρ′ = kρ」前提下的推导均可复核成立；**未复现的仅是式 2.249 的字面底数写法**（此即 replicated: false 的确切范围）。
4. 注：各公式默认 k > 0（α ∈ (0, π/2)）；k < 0 时的符号约定源文未说明。
