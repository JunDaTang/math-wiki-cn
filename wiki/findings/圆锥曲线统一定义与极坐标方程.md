# 圆锥曲线统一定义与极坐标方程（焦点-准线、五点确定、式 3.354 双曲线单支限制）

本源 3.5.2.11 给出二次曲线（圆锥曲线）的三条统一性质：

## 1. 圆锥截线刻画

一个对顶直圆锥被一个平面所截即得圆锥曲线。若该平面不通过圆锥的顶点，则结果是双曲线、抛物线或椭圆，取决于该平面平行于圆锥的两条、一条或不平行于任何母线；若平面通过顶点，则得奇异圆锥曲线，并有 Δ = 0；圆柱（顶点在无穷远处的奇异圆锥）的圆锥曲线是平行线。

## 2. 焦点-准线统一定义

到定点（焦点）的距离与到定直线（准线）的距离之比为常数 e 的点的轨迹是具有数值离心率 e 的二次曲线（原书图 3.169）：e<1 椭圆、e=1 抛物线、e>1 双曲线。

## 3. 五点确定

过平面上五个给定的点有且仅有一条二次曲线；如果其中三个点位于同一条直线上，则它是奇异或退化圆锥曲线。

## 4. 统一极坐标方程

```
ρ = p/(1 + e·cos φ)    (3.354)
```

其中 p 是半焦弦，e 是离心率；极点位于焦点处，极轴从焦点指向较近的顶点。**对双曲线来说这个方程只定义了它的一支**——这是使用 (3.354) 时的重要限制。
