# 式 13.84–13.98 空间微分算子运算法则转录复算

对《数学手册(原书第10版)》13.2.7.1 小节给出的 15 条空间微分算子运算法则与恒等式（式 13.84–13.98）逐条独立复算，结论：**全部与标准向量分析一致，未发现数学讹误**。

## 复算方法

在笛卡儿坐标系下按分量直接展开验证：取 $\operatorname{grad}U=\vec{\mathrm{e}}_{x}\frac{\partial U}{\partial x}+\vec{\mathrm{e}}_{y}\frac{\partial U}{\partial y}+\vec{\mathrm{e}}_{z}\frac{\partial U}{\partial z}$，$\operatorname{div}\vec{V}=\frac{\partial V_{x}}{\partial x}+\frac{\partial V_{y}}{\partial y}+\frac{\partial V_{z}}{\partial z}$，$\operatorname{rot}\vec{V}$ 按表 13.2 笛卡儿列展开，逐条核对等式两边。复合恒等式（式 13.94–13.95、13.97）依赖混合偏导可交换，在偏导连续的常规假设下成立。

## 逐条结论

| 式号 | 法则 | 结论 |
|---|---|---|
| 13.84–13.85 | grad 线性、数乘 | 正确 |
| 13.86 | grad 乘积法则 | 正确 |
| 13.87 | 链式法则 grad F(U)=F′(U) grad U | 正确（引言未声明 F，见附注） |
| 13.88–13.89 | div 线性、数乘 | 正确 |
| 13.90 | div(UV⃗) 乘积法则 | 正确 |
| 13.91–13.92 | rot 线性、数乘 | 正确 |
| 13.93 | rot(UV⃗) 乘积法则 | 正确 |
| 13.94 | div rot V⃗ ≡ 0 | 正确 |
| 13.95 | rot grad U ≡ 0⃗ | 正确 |
| 13.96 | div grad U = ΔU | 正确（Δ 的定义性恒等式） |
| 13.97 | rot rot V⃗ = grad div V⃗ − ΔV⃗ | 正确（逐分量展开验证） |
| 13.98 | div(V⃗₁×V⃗₂) | 正确 |

直接展开验证属推导性复算，证据强；复算为独立重推，视为已复现。
