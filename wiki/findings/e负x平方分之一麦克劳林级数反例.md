# 反例：e^{−1/x²} 的麦克劳林级数恒为零（S(x) ≠ f(x)，已复算）

手册 7.3.3.3 末尾给出的反例，说明「确定收敛半径」不足以保证幂级数收敛到原函数。函数

```latex
f(x) = \begin{cases} \exp\!\left(-\dfrac{1}{x^2}\right), & x \neq 0,\\[4pt] 0, & x = 0 \end{cases}
```

的麦克劳林级数中各项都等于 0（因 f 在原点的各阶导数 f^{(n)}(0) = 0），故其和 S(x) = 0 ≠ f(x)（对一切 x ≠ 0）。

## 复算

- f 在 x ≠ 0 处无穷次可微、在 x = 0 处连续；由归纳法可得 f^{(n)}(x) = P_n(1/x)·e^{−1/x²}（P_n 为多项式），而 x → 0 时 e^{−1/x²} 衰减快于任何幂，故 f^{(n)}(0) = 0 对所有 n 成立 ✓。
- 于是麦克劳林级数 ≡ 0，处处收敛（收敛半径 r = ∞），但和函数恒为 0，仅在 x = 0 处等于 f ✓。

## 意义

这是「级数收敛但 S ≠ f」的标准反例：该函数是著名的非解析光滑函数。它说明泰勒级数表示（式 7.95a/7.97a）必须以余项 R_n → 0 为前提，仅有任意阶可导性不够。判读与关联见 [[麦克劳林级数]]、[[式7-95-7-97泰勒级数与余项公式]]。
