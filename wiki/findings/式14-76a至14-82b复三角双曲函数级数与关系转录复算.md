# 式 14.76a–14.82b 复三角双曲函数级数与关系转录复算

## 转录内容

```latex
\sin z = \frac{e^{\mathrm{i}z} - e^{-\mathrm{i}z}}{2\mathrm{i}} = z - \frac{z^3}{3!} + \frac{z^5}{5!} - \dots    (14.76a)
\cos z = \frac{e^{\mathrm{i}z} + e^{-\mathrm{i}z}}{2\mathrm{i}} = 1 - \frac{z^2}{2!} + \frac{z^4}{4!} - \dots    (14.76b)  ⚠ 分母 2i 疑为 2
\sinh z = \frac{e^z - e^{-z}}{2} = z + \frac{z^3}{3!} + \frac{z^5}{5!} + \dots                                    (14.77a)
\cosh z = \frac{e^z + e^{-z}}{2} = 1 + \frac{z^2}{2!} + \frac{z^4}{4!} + \dots                                    (14.77b)
\sin \mathrm{i}z = \mathrm{i}\sinh z    (14.78a)    \cos \mathrm{i}z = \cosh z      (14.78b)
\sinh \mathrm{i}z = \mathrm{i}\sin z    (14.79a)    \cosh \mathrm{i}z = \cos z      (14.79b)
\cos(x + \mathrm{i}y) = \cos x\cos\mathrm{i}y - \sin x\sin\mathrm{i}y = \cos x\cosh y - \mathrm{i}\sin x\sinh y   (14.80)
Re(\cos z) = \cos Re(z)\cosh Im(z)      (14.81a)
Im(\cos z) = -\sin Re(z)\sinh Im(z)     (14.81b)
\tan z = \frac{\sin z}{\cos z},   \cot z = \frac{\cos z}{\sin z}                (14.82a)
\tanh z = \frac{\sinh z}{\cosh z},   \coth z = \frac{\cosh z}{\sinh z}          (14.82b)
```

## 复算过程与结论

- **(14.76a) 正弦**：由 (14.73a)−(14.73b)，$e^{\mathrm{i}z} - e^{-\mathrm{i}z} = 2\mathrm{i}\sin z$，分母 $2\mathrm{i}$ ✓；级数部分由 $e^{\pm\mathrm{i}z}$ 展开相减逐项验证 ✓。
- **(14.76b) 余弦**：⚠ **判定为讹误（高置信）**。由 (14.73a)+(14.73b) 得 $e^{\mathrm{i}z} + e^{-\mathrm{i}z} = 2\cos z$，分母应为 $2$；若作 $2\mathrm{i}$，则该式右端等于 $-\mathrm{i}\cos z$，与其后正确的 cos z 级数自相矛盾。记法模式上：(14.76a) 用 $2\mathrm{i}$、(14.77b) 用 $2$，本式夹在中间独作 $2\mathrm{i}$。详见 [[queries/式14-76b余弦分母2i疑为2]]。
- **(14.77a/b) 双曲正弦/余弦**：定义与级数均 ✓（$e^{z} \mp e^{-z}$ 展开逐项验证）。
- **周期句**：⚠ 三重讹误。复算：$\sin(z+\pi) = -\sin z$（如 $z = \pi/2$ 反例），故 sin/cos 的周期是 $2\pi$ 而非转写之“兀”（π）；$\sinh(z+\pi\mathrm{i}) = -\sinh z$、$\sinh(z+2\pi\mathrm{i}) = \sinh z$，故 sinh/cosh 的周期为 $2\pi\mathrm{i}$，该值在转写中整个缺失；正文引用编号 (14.76c),(14.76d) 不存在（实际为 14.77a/b）。详见 [[queries/式14-76周期句数值与编号引用讹误]]。
- **(14.78a–14.79b) 纯虚自变量关系**：由定义直接验证，如 $\sin\mathrm{i}z = \frac{e^{-z} - e^{z}}{2\mathrm{i}} = \mathrm{i}\,\frac{e^{z} - e^{-z}}{2} = \mathrm{i}\sinh z$ ✓；四式均 ✓（另见 [[comparisons/三角函数与双曲函数纯虚自变量关系比较]]）。
- **(14.80)**：转写原为下标乱码（“■ COS (X + iy …”样式的残缺文本）。依据上下文（示范如何计算 cos z 的值）复原为 $\cos(x+\mathrm{i}y) = \cos x\cos\mathrm{i}y - \sin x\sin\mathrm{i}y = \cos x\cosh y - \mathrm{i}\sin x\sinh y$，经 (14.78b)、加法公式与欧拉关系三条路径交叉验证 ✓。
- **(14.81a/b)**：由 (14.80) 直接读出 ✓。
- **(14.82a/b)**：商定义，形式 ✓。

## 证据强度与归属

- 判定为讹误的部分是对**转写文本**（而非数学本身）的判定，基于逐式复算与记法模式交叉比对，置信度高。
- “排印源误还是 OCR 转写讹误”的归因需对照原书，属开放问题。
- “全平面收敛”“周期性”断言仅覆盖 (14.76a/b)、(14.77a/b) 四式，源文未对 tan 类作此断言。
