# 式 11.4–11.6 退化核定义与解结构转录复算

**结论**：式 (11.4a)–(11.6c) 的转写在数学上自洽，"退化核 → 解结构"的化归推导经独立复算吻合。

## 逐字转录

```latex
% (11.4a)
\varphi(x) = f(x) + \lambda \int_a^b K(x,y)\,\varphi(y)\,\mathrm{d}y

% (11.4b)
K(x,y) = \alpha_1(x)\beta_1(y) + \alpha_2(x)\beta_2(y) + \dots + \alpha_n(x)\beta_n(y)

% (11.5) 线性无关
\sum_{k=1}^{n} c_k\,\alpha_k(x) \equiv 0
% 对每个 x∈[a,b] 成立，仅当 c_1=…=c_n=0 时

% (11.6a)
\varphi(x) = f(x) + \lambda\alpha_1(x)\int_a^b \beta_1(y)\varphi(y)\,\mathrm{d}y + \dots
+ \lambda\alpha_n(x)\int_a^b \beta_n(y)\varphi(y)\,\mathrm{d}y

% (11.6b)
A_k = \int_a^b \beta_k(y)\,\varphi(y)\,\mathrm{d}y,\quad k=1,\dots,n

% (11.6c)
\varphi(x) = f(x) + \lambda A_1\alpha_1(x) + \lambda A_2\alpha_2(x) + \dots + \lambda A_n\alpha_n(x)
```

## 独立复算

- 将 (11.4b) 代入 (11.4a)，按 $\alpha_k$ 归并积分即得 (11.6a)；诸积分 $\int\beta_k(y)\varphi(y)\,\mathrm{d}y$ 在积掉变元后是不含 $x$ 的常数（转写原文"不再是变量 的函数"漏 "x"），记作 $A_k$ 即 (11.6b)、(11.6c)。推导无缺口。
- 假设条件：诸 $\alpha_k$、$\beta_k$ 在 $[a,b]$ 上给定且连续；诸 $\alpha_k$ 线性无关 (11.5)。
- 解结构 (11.6c) 是线性叠加（[[concepts/叠加原理与分解定理]]）的直接体现：扰动项 $f$ 加齐次部分的有限维组合。

## 转写问题

- (11.5) 的定义句被一段错位译者注拦腰打断且句式错乱（"仅当…时否则…"），见 [[queries/式11-5后错位译者注的归属]] 与 [[queries/11-2-1全节系统性转写讹误清单]]；不影响数学内容。

## 直接证据与推断

化归推导为直接证据（逐步独立复算）。此处解的存在性仅为条件性陈述（"如果存在"），存在性由后续 $D(\lambda)$ 判据（[[findings/式11-8行列式判据与两情形转录复算]]）落实。
