# 式 17.28–17.30 转移映射、帐篷映射与自然测度转录复算

本条目记录数学手册 17.2.1.1 中式 (17.28a/b)、(17.29)、密度变换关系、周期轨狄拉克测度与式 (17.30) 自然测度定义的转录与独立复算。

## 转录

```latex
x_{l+1} = 2 x_l (mod 1)                                          % (17.28a)
phi(x) = { 2x, 0<=x<=1/2 ; 2x-1, 1/2<x<=1 }                      % (17.28b)
Psi(y) = { 2y, 0<=y<1/2 ; 2(1-y), 1/2<=y<=1 }                    % (17.29)
h(x) = (2/pi) arcsin(sqrt(x)),  rho(x) = 1/(pi sqrt(x(1-x)))     % 逻辑斯谛 alpha=4
rho_1(y) = rho(h^{-1}(y)) |(h^{-1})'(y)|                         % 密度变换（源文脱撇号）
mu = (1/T) sum_{i=0}^{T-1} delta_{phi^{i}(x_0)}                  % 稳定周期轨自然测度
mu(A; x_0) := lim_{T->infty} t(T, A, x_0)/T                      % (17.30)
```

## 复算验证

1. **倍增映射勒贝格不变**：两支斜率均为 2 且各映满 $[0,1]$，任一博雷尔集在每支下的原像测度为其一半，两支合计等于原测度。✓
2. **二进制移位语义**：$x=0.a_1a_2a_3\cdots$ 在 $2x\bmod 1$ 下变为 $0.a_2a_3\cdots$（左移去首位）。✓
3. **帐篷映射勒贝格不变**：两支斜率 $\pm 2$、各映满 $[0,1]$，同法验证。✓
4. **共轭 $h\circ f=T\circ h$**：令 $x=\sin^2 u$，$f(x)=4x(1-x)=\sin^2 2u$；$u\leq\pi/4$（$h(x)\leq 1/2$）时 $h(f(x))=4u/\pi=2h(x)$，$u\geq\pi/4$ 时 $h(f(x))=2-4u/\pi=2(1-h(x))$，逐支吻合帐篷映射。✓
5. **$h'=\rho$ 恒等式（关键捷径）**：$h'(x)=\frac{2}{\pi}\cdot\frac{1}{2\sqrt{x}}\cdot\frac{1}{\sqrt{1-x}}=\frac{1}{\pi\sqrt{x(1-x)}}=\rho(x)$。代入密度变换公式：$\rho_1(y)=h'(h^{-1}(y))\cdot\frac{1}{h'(h^{-1}(y))}=1$，与帐篷映射均匀密度 $\rho_1\equiv 1$ 自洽闭环。✓
6. **周期轨狄拉克平均**：直接验证其为不变概率测度且遍历（支撑在单条周期轨上，无非平凡不变子集）。✓
7. **式 (17.30) 定义结构**：频率极限口径正确；但 $t(T,A,x_0)$ 的文字表述有内在不自洽（见下）。

## 转写差异（不影响数学结论）

- 密度变换公式脱导数撇号：源文「|(h⁻¹)(y)|」应为「|(h⁻¹)′(y)|」。
- 「当 α = 时」脱「4」字（[[queries/当α等于脱4之辨]]）。
- $t(T,A,x_0)$ 被述为「所有时刻构成的**集合**」，但在 (17.30) 中作比值使用，应为总时长（[[queries/自然测度定义集合疑为时间测度之辨]]）。
- 其余 OCR 噪声并入 [[queries/17-2全节系统性转写讹误清单]]。

## 结论

全部数学论断（勒贝格不变性、移位语义、共轭、$\alpha=4$ 不变密度、周期轨自然测度）经独立复算成立；发现的 $h'=\rho$ 恒等式为验证此类共轭换元的捷径，已编入 [[methodology/共轭换元求不变密度流程]]。
