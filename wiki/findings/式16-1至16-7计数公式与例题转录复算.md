# 式 16.1–16.7 计数公式与例题转录复算

## 主张

16.1 节主张：「从 n 个元素中取 k 个」的全部经典情形可归入三类构造方式（全排列＝纯排序、组合＝纯选取、排列＝选取＋排序），各按是否允许重复给出计数公式（式 16.1–16.7），汇总于表 16.1。

## 公式核验（直接证据）

| 式 | 内容 | 核验 |
|---|---|---|
| (16.1) | Pₙ = n! | n 个互异元素的全排列数，标准结果 ✓ |
| (16.2) | Pₙ⁽ᵏ⁾ = n!/k! | n 个元素中 k 个相同时的全排列数；为 (16.3) 中一类重数 k、其余 n−k 个单元素互异的特例 ✓（前提「其余元素互异」源文未明示） |
| (16.3) | Pₙ^(k₁,…,kₘ) = n!/(k₁!⋯kₘ!)，Σkᵢ = n | 多重集排序／多项式系数，标准结果 ✓ |
| (16.4) | Cₙ⁽ᵏ⁾ = C(n,k)，0 ≤ k ≤ n | 二项式系数，标准结果 ✓ |
| (16.5) | Cₙ⁽ᵏ⁾ = C(n+k−1,k) | 多重集选取（隔板型），标准结果 ✓ |
| (16.6) | Vₙ⁽ᵏ⁾ = k!·C(n,k) = n(n−1)⋯(n−k+1) | 选排列；两表达式等价：k!·C(n,k) = n!/(n−k)! ✓ |
| (16.7) | Vₙ⁽ᵏ⁾ = nᵏ | k 个独立位置各 n 种选择 ✓ |

## 例题复算（直接证据：算术）

| 例题 | 源文声称 | 复算 | 判定 |
|---|---|---|---|
| 16 名学生坐 16 个座位 | 16! | 16! = 20922789888000，由 (16.1) 直接成立 | ✓ |
| 16 个书包入 16 把椅子，[4] 个相同 | 16!/4! | 16!/24 = 871782912000，与 (16.2) 一致 | ✓（「4」为补值） |
| 用数字 4, 4, 5, 5, [5] 构造五位数 | P₅^(2,3) = 5!/(2!3!) = 10 | 120/12 = 10；以「两个 4 在五个数位中的位置」枚举 C(5,2) = 10 二次验证 | ✓（数字列表缺第五个数字） |
| 30 位参会者选 [4] 位委员会 | C(30,4) = 27405 | 30·29·28·27/24 = 657720/24 = 27405 | ✓（「4」为补值） |
| 掷 [2] 颗骰子 | C₆⁽²⁾ = C(7,2) = 21 | 7·6/2 = 21 | ✓（「2」为补值） |
| 30 人选四职务 | C(30,4)·4! = 657720 | 27405×24 = 657720 = 30·29·28·27，与 (16.6) 一致 | ✓ |
| Toto 杯（源文作「12 支队伍」） | 3¹² | 3¹² = 531441 本身无误，但 12 支队伍单轮只有 12/2 = 6 场（→ 3⁶ = 729）；单循环为 C(12,2) = 66 场（→ 3⁶⁶）。题面与公式不相容 | ✗ 题面与公式矛盾 |
| 8 位数字单元（字节） | 2⁸ = 256 | 256 | ✓（「8」为补值） |

## 直接证据与推断的区分

- **直接证据**：七条公式的内容与全部例题算术（16!、16!/4!、10、27405、21、657720、256 的复算）均由本节文本与独立计算直接支持。
- **推断**：源文系统性丢字导致的补值——书包例「4」、委员会例「4」、骰子例「2」、字节例「8」均由例题所引公式唯一反推；五位数例脱落的第五个数字推断为「5」（重数 2+3 = 5，且上标 (2,3) 的类序表明 4 的重数 2 在前）。补值推断强，但需对照纸本原书确认。
- **Toto 例的矛盾在题面而非算术**：3¹² 作为「12 场比赛、每场三态」的计数是对的；「12 支队伍」的读法无法产生 12 场比赛。见 [[queries/托托杯例十二支队伍疑为十二场比赛]]。
