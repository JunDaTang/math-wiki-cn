# 式 12.216–12.219 收敛定理与拉东–尼科迪姆定理转录复算

## (12.216) 莱维定理

原文条件：「取值于 ℝ̄ 的 a.e. 单调递增非负可积函数列」，结论 lim∫fₙ dμ = ∫lim fₙ dμ。

复算：单调递增保证 ∫fₙ 递增故极限存在；结论对「非负可测」即成立（极限积分可取 +∞）。「可积」是不必要的强条件，且与法图定理（仅要求可测）的表述层级不一致。疑转写讹误或原书非标准表述，见 [[queries/莱维定理条件可积疑为可测]]。

## (12.217) 法图定理

∫ liminf fₙ dμ ⩽ liminf ∫ fₙ dμ，仅要求非负可测。✓

不等式可严格的反例核验：取 (ℝ, λ) 上 fₙ = χ_{[n, n+1]}，则 liminf fₙ = 0 而 ∫fₙ dλ = 1，两端 0 < 1，确认一般情形等式不成立。

## (12.218) 控制收敛定理

条件：a.e. 收敛 + 存在可积 g 使 |fₙ| ⩽ g a.e.；结论：f = lim fₙ 可积且 lim∫fₙ dμ = ∫f dμ。与标准形式一致。✓

## (12.219) 拉东–尼科迪姆定理

- 正命题复算：φ(A) = ∫_A f dμ 的 σ-可加性由积分对不相交并的线性性给出；μ(A) = 0 ⟹ f χ_A = 0 a.e. ⟹ φ(A) = 0，即 φ ≺ μ。✓
- 逆命题（定理本体）为存在性结果，依赖 σ-有限性假设；手册陈述与标准形式一致。✓
- 唯一性「相对等价类的范畴」即 f 在 μ-a.e. 等价意义下唯一；φ 非负 ⟺ f ⩾ 0 μ-a.e. 的双向蕴涵复算通过。✓
