# 椭圆理论公式组（式 3.320–3.327，含焦半径、准线、阿波罗尼奥斯、曲率）

要素：长轴 2a、短轴 2b、c = √(a²−b²)、数值离心率 e = c/a < 1、半焦弦 p = b²/a。

```
标准方程:  x²/a² + y²/b² = 1                                   (3.320a)
参数式:    x = a·cos t,  y = b·sin t                            (3.320b)
焦半径:    r₁ = a − e·x,  r₂ = a + e·x,  r₁ + r₂ = 2a           (3.321)
准线（与短轴平行, d = a/e）:  r₁/d₁ = r₂/d₂ = e                  (3.322)
共轭直径斜率:  k·k′ = −b²/a²                                    (3.323)
阿波罗尼奥斯定理（和式型）:
  a₁·b₁·sin(α+β) = ab,  a₁² + b₁² = a² + b²                    (3.324)
切线:      x·x₀/a² + y·y₀/b² = 1                                (3.325)
切线判别:  A²a² + B²b² = C²                                     (3.326)
曲率半径:  R = a²b²(x₀²/a⁴ + y₀²/b⁴)^{3/2} = (r₁r₂)^{3/2}/(ab) = p/sin³u   (3.327)
顶点曲率:  R_A = R_B = b²/a = p（长轴顶点）,  R_C = R_D = a²/b（短轴顶点）
```

## 已验证项（分析阶段复算，视为已复算）

- 焦半径 r₁ = a − ex、r₂ = a + ex 与 r₁+r₂ = 2a 在「F₁ 为右侧焦点」的本书约定下内自洽。
- 曲率半径三种形式的等价性：(r₁r₂)^{3/2}/ab 与 a²b²(x₀²/a⁴+y₀²/b⁴)^{3/2} 一致（利用 r₁r₂ = a² − e²x² 与椭圆方程）；顶点值 b²/a = p、a²/b 直接代入成立。
- 切线与法线是焦半径所成内、外角的平分线（反射性质）。

## 备注

切线判别 (3.326) 属椭圆自身的命题，与双曲线的 (3.334) 仅一个符号之差，不可互换，见 [[comparisons/椭圆双曲线抛物线比较]]。面积与周长见 [[findings/椭圆面积周长级数与算例]]。
