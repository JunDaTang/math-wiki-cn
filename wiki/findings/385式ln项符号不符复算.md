# 385 式 ln 项符号不符复算

条目 385 转写原文：

```latex
\int\frac{\cos^{2} ax\,dx}{\sin^{3} ax} = -\frac{1}{2a}\left(\frac{\cos ax}{\sin^{2} ax} - \ln\tan\frac{ax}{2}\right)
```

## 复算

记 u = ax。d/du[cos u/sin²u] = −1/sin u − 2cos²u/sin³u；d/du[ln tan(u/2)] = 1/sin u。代入原文右端求导得 1/sin³u，而非被积函数 cos²u/sin³u——即原文右端实为 ∫dx/sin³ax 的原函数，与条目 288 右端逐项雷同（288 = −cos/(2a sin²) + (1/2a)ln tan(ax/2) = −(1/2a)[cos/sin² − ln tan(ax/2)]）。不同被积函数不可能共享原函数，而 288 复算无误，故错在 385。

订正（括内取 +）：

```latex
\int\frac{\cos^{2} ax\,dx}{\sin^{3} ax} = -\frac{1}{2a}\left(\frac{\cos ax}{\sin^{2} ax} + \ln\tan\frac{ax}{2}\right)
```

求导验证：−(1/2)[−1/sin − 2cos²/sin³ + 1/sin] = cos²/sin³ ✓。

## 证据

两条独立证据：① 直接求导（上式）；② 原文右端与 288 逐项雷同的结构性矛盾。二者均指向括内减号应为加号。
