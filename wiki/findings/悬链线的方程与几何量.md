# 悬链线的方程与几何量（式 2.252）

**发现**：手册 2.15.1 给出悬链线（见 [[concepts/悬链线]]）的方程与全套几何量，全部公式均可由方程直接复核，完全自洽。来源：[[sources/10-数学手册原书第10版--10-215-各种其他曲线--pzek1r]]（2.15.1）。

## 原文公式（逐字保留）

```latex
y = a \cosh {\frac {x}{a}} = a \frac {\mathrm{e} ^ {\frac {x}{a}} + \mathrm{e} ^ {- \frac {x}{a}}}{2} (a > 0) \tag{2.252}
```

## 几何量清单

| 量 | 公式/陈述 |
|---|---|
| 顶点 | $A(0, a)$，由参数 $a$ 确定 |
| 对称性 | 关于 y 轴对称 |
| 位置 | 恒在抛物线 $y = a + \frac{x^2}{2a}$（图 2.78 虚线）上方 |
| 弧长 $\widehat{AP}$ | $L = a\sinh\frac{x}{a} = a\,\frac{\mathrm{e}^{x/a}-\mathrm{e}^{-x/a}}{2}$ |
| 区域 $OAPM$ 的面积 | $S = aL = a^2\sinh\frac{x}{a}$ |
| 曲率半径 | $r = \frac{y^2}{a} = a\cosh^2\frac{x}{a} = a + \frac{L^2}{a}$ |

## 直接证据与复核（推导验证）

- $L$：由 $\mathrm{d}s = \sqrt{1+y'^2}\,\mathrm{d}x = \cosh\frac{x}{a}\,\mathrm{d}x$ 积分即得。
- $S$：$S = \int_0^x y\,\mathrm{d}x' = a^2\sinh\frac{x}{a} = aL$。**$S = a\times$ 弧长**这一结构性关系为原文明示，是本条目的亮点。
- $r$：$r = \frac{(1+y'^2)^{3/2}}{|y''|} = \frac{\cosh^3\frac{x}{a}}{\frac{1}{a}\cosh\frac{x}{a}} = a\cosh^2\frac{x}{a} = \frac{y^2}{a}$；又 $a + \frac{L^2}{a} = a\left(1+\sinh^2\frac{x}{a}\right) = a\cosh^2\frac{x}{a}$，三种表示等价。
- 「恒在抛物线上方」：由 $\cosh u \geq 1 + \frac{u^2}{2}$（仅 $u=0$ 取等）保证；分析注记：该抛物线为顶点处密切抛物线（$y(0)=a$、$y'(0)=0$、$y''(0)=\frac{1}{a}$ 三者吻合，二阶切触），原文未如此命名。

**结论**：强度强，完全自洽。相关对偶论断（悬链线为曳物线之渐屈线）另见 [[findings/曳物线的渐屈线是悬链线]]；与曳物线的系统对照见 [[comparisons/悬链线与曳物线比较]]。
