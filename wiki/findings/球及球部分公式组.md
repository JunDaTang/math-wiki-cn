# 球及球部分公式组（式 3.156–3.169）

**直接证据**（源文 3.3.4(12)–(15)，图 3.74–3.78）。

**球**（半径 R、直径 D = 2R）的封闭公式组：

$$S = 4\pi R^{2} \approx 12.57 R^{2} \tag{3.156a}$$
$$S = \pi D^{2} \approx 3.142 D^{2} \tag{3.156b}$$
$$S = \sqrt[3]{36\pi V^{2}} \approx 4.836 \sqrt[3]{V^{2}} \tag{3.156c}$$
$$V = \frac{4}{3}\pi R^{3} \approx 4.189 R^{3} \tag{3.157a}$$
$$V = \frac{\pi D^{3}}{6} \approx 0.5236 D^{3} \tag{3.157b}$$
$$V = \frac{1}{6}\sqrt{\frac{S^{3}}{\pi}} \approx 0.09403 \sqrt{S^{3}} \tag{3.157c}$$
$$R = \frac{1}{2}\sqrt{\frac{S}{\pi}} \approx 0.2821 \sqrt{S} \tag{3.158a}$$
$$R = \sqrt[3]{\frac{3V}{4\pi}} \approx 0.6204 \sqrt[3]{V} \tag{3.158b}$$

**球心角体**（球半径 R、冠高 h、底半径 a）：

$$S = \pi R(2h + a) \tag{3.159}$$
$$V = \frac{2\pi R^{2}h}{3} \tag{3.160}$$

**球冠**：

$$a^{2} = h(2R - h) \tag{3.161}$$
$$V = \frac{1}{6}\pi h(3a^{2} + h^{2}) = \frac{1}{3}\pi h^{2}(3R - h) \tag{3.162}$$
$$M = 2\pi Rh = \pi(a^{2} + h^{2}) \tag{3.163}$$
$$S = \pi(2Rh + a^{2}) = \pi(h^{2} + 2a^{2}) \tag{3.164}$$

**球层**（两底半径 a、b，高 h）：

$$R^{2} = a^{2} + \left(\frac{a^{2} - b^{2} - h^{2}}{2h}\right)^{2} \tag{3.165}$$
$$V = \frac{1}{6}\pi h(3a^{2} + 3b^{2} + h^{2}) \tag{3.166}$$
$$M = 2\pi Rh \tag{3.167}$$
$$S = \pi(2Rh + a^{2} + b^{2}) \tag{3.168}$$

球层与内接截锥（母线长 l）的体积差：

$$V - V_{1} = \frac{1}{6}\pi h l^{2} \tag{3.169}$$

**独立核验（已复核，自洽）**：

- **系数互推**：12.57 = 4π；3.142 = π；4.836 = ∛(36π)；4.189 = 4π/3；0.5236 = π/6；0.09403 = 1/(6√π)；0.2821 = 1/(2√π)；0.6204 = ∛(3/(4π)) ✓。3.156c 由 3.156a 与 3.157a 消去 R 而得；九式构成 S、V、R、D 中任取两量解其余的封闭组。
- **球冠内部转换**：3.161 ⟹ 2Rh = a² + h²，故 3.163 的两形式、3.164 的两形式、3.162 的两形式互相转换 ✓；球层取 b = 0 时 3.166 退化为 3.162 ✓。
- **球心角体的合成**：3.159 = 球冠曲面积 2πRh + 以球心为顶点的锥侧面 πaR（母线长 = R，因冠沿在球面上）✓；3.160 = 3.162 的球冠体积 + 同锥体积 ⅓πa²(R−h)，用 3.161 化简后恰为 ⅔πR²h ✓。

**大圆性质**（正文）：球与任一平面截线皆圆；过球心的平面截出大圆；非直径端点的两点恰有一个大圆通过；球面最短连线为大圆弧。两处「参见第 213 3.4.1.1」页码脱落。
