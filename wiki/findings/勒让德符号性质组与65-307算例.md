# 勒让德符号性质组与 (65/307) 算例（式 5.255–5.257，已复算）

**来源**：[[sources/10-数学手册原书第10版--10-543-同余和剩余类--n0ce67]]（5.4.3.8）。

**陈述一（判别式化归，5.255）**：ax² + bx + c ≡ 0 (m) ⟺ (2ax + b)² ≡ b² − 4ac (m)。源文无条件使用双向箭头；反向需 gcd(2a, m) = 1（由恒等式 (2ax+b)² − (b²−4ac) = 4a(ax²+bx+c) 反向除以 4a），见 [[queries/式5-255是否缺gcd-2a-m条件]]。

**陈述二（素因子分解归约，5.256）**：m = ∏ p_i^{α_i} 时，a 是模 m 二次剩余，当且仅当对每个 i 是模 p_i^{α_i} 二次剩余。

**陈述三（勒让德符号性质组，5.257a–f）**：E1 同余不变性；E2 (1/p) = 1；E3 (−1/p) = (−1)^{(p−1)/2}；E4 完全乘性及 (ab²/p) = (a/p)；E5 (2/p) = (−1)^{(p²−1)/8}；E6 二次互反律 (p/q)(q/p) = (−1)^{((p−1)/2)((q−1)/2)}（p、q 为不同奇素数）。

**复算（(65/307) = 1 的演算链逐步核验）**：

1. 65 = 5·13，由 E4：(65/307) = (5/307)·(13/307)。
2. 5 ≡ 1 (mod 4)，E6 翻转无符号修正：(5/307) = (307/5)；307 ≡ 2 (mod 5)，由 E1 得 (2/5)。
3. 13 ≡ 1 (mod 4)：(13/307) = (307/13)；307 = 13·23 + 8，由 E1 得 (8/13)。
4. E5：(2/5) = (−1)^{(25−1)/8} = (−1)³ = −1。
5. E4：(8/13) = (2³/13) = (2/13)³ = (2/13)；E5：(2/13) = (−1)^{(169−1)/8} = (−1)²¹ = −1。
6. 乘积：(−1)·(−1) = 1。✓（307 为素数：不被 2、3、5、7、11、13、17 整除。）

结论：65 是模 307 二次剩余。

**证据类型**：直接证据（性质组 + 演算链复算）。

**转写备注**：源文示例「1,4, 是模 二次剩余」模数与列表脱落、无法复原，见 [[queries/二次剩余示例模数与列表脱落]]；二次剩余定义中「存在 a ∈ ℤ 使得 x² ≡ a (m)」应为「存在 x ∈ ℤ」。
