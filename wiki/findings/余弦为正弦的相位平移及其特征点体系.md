# 余弦为正弦的相位平移及其特征点体系（式 2.65–2.67）

## 手册主张

$$y = \cos x = \sin\left(x + \frac{\pi}{2}\right) \tag{2.65}$$

- 与 x 轴交点 $B_k = \left(\left(k+\frac{1}{2}\right)\pi,\ 0\right)$（k = 0, ±1, ±2, …），均为拐点，切线倾斜角 $\pm\frac{\pi}{4}$；
- 极值点 $C_k = (k\pi,\ (-1)^k)$。

一般余弦函数

$$y = A\cos(\omega x + \varphi_0) \tag{2.66}$$

可变换成

$$y = A\sin\left(\omega x + \varphi_0 + \frac{\pi}{2}\right) \tag{2.67}$$

「即由一般正弦函数向左平移 $\varphi = \frac{\pi}{2}$ 个单位」。

## 验证与疑点

- 恒等式 $\cos x = \sin(x+\frac{\pi}{2})$ 与特征点坐标均可直接核验：与正弦的要素恰按 $\frac{\pi}{2}$ 平移对调。验证通过。
- 平移表述疑欠严谨：相位增加 $\frac{\pi}{2}$ 对应的 x 向平移量为 $\frac{\pi}{2\omega}$（比较：式 2.64 的平移量写作 $\frac{\varphi_0}{\omega}$，已除以 ω），仅当 ω = 1 时两者相等。数学内容（式 2.67）本身无误，见 [[queries/一般余弦平移π除2个单位是否应为π除2ω]]。
