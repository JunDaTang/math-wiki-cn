# 式 20.24 与 20.26 循环与模块语法转录复算

**结论**：式 20.24a/b（`Do`、`While`）与式 20.26（`Module`）的语法形式及文字所述默认值、作用域语义，与 Mathematica 实际语义一致，转录可靠；唯一系统性偏差是「赋值」措辞（见文末）。

## 转录原文

```
Do[expr, {i, i1, i2, di}]              (20.24a)
While[test, expr]                      (20.24b)
Module[{t1, t2, ...}, procedure]       (20.26)
```

## 逐项核对

| 原文表述 | Mathematica 实际语义 | 核对结果 |
|---|---|---|
| Do 之 i 以步长 di 自 i1 取值至 i2 | `Do[expr, {i, i1, i2, di}]` 迭代子句语义一致 | 一致 |
| 略去 di 则步长为 1 | `{i, i1, i2}` 即步长 1 | 一致 |
| 再略去 i1 则从 1 开始 | `{i, imax}` 自 1 起至 imax | 一致 |
| While 只要 test 为 True 即执行 | `While[test, expr]` 语义一致 | 一致 |
| Module 列表内变元局部可用、模块内指派对外无效 | `Module` 局部化语义一致 | 一致 |

注：此表为语义比对而非运行复算；比对依据 Mathematica 公开语义，属可独立验证的背景知识，非本来源内容。

## 「赋值」措辞偏差（非事实错误）

原文两处以「赋值」描述循环体执行（「第一个命令给表达式 expr 赋值」「While 循环赋值直到事先给定的条件失效」），而 Mathematica 语义为**重复求值**；「赋值」疑为德文原版 auswerten 的翻译残留。此为措辞偏差，不影响语法正确性，详见 [[queries/赋值措辞疑为求值语义之辨]]。

## 直接证据与推断之别

- 直接证据：式 20.24a/b、20.26 之逐字转录（见 [[sources/10-数学手册原书第10版--9-2029-程序设计--l13hq7]]）；
- 比对推断：与 Mathematica 实际语义之一致性判断（上表），依据公开语义而非本来源。
