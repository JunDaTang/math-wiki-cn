# 向量空间公理组 V1–V8 与三例（式 5.182–5.190）

## 陈述

5.3.8.1 以「阿贝尔群 + 域 + 外乘法」三元结构公理化向量空间：域 $K$ 上的向量空间由「向量」的阿贝尔群 $V=(V,+)$（加法形式）、「标量」域 $K=(K,+,*)$、以及外乘法 $K\times V\to V$ 组成，满足公理 V1–V8；$K=\mathbb{R}$ 时称实向量空间。

```latex
(V1) 对所有 u,v,w ∈ V: (u+v)+w = u+(v+w)          % 5.182
(V2) 存在向量 0 ∈ V 使得对每个 v ∈ V: v+0 = v      % 5.183
(V3) 对每个 v ∈ V 存在 -v 使得 v+(-v) = 0          % 5.184
(V4) 对每个 v,w ∈ V: v+w = w+v                     % 5.185
(V5) 对每个 v ∈ V: 1v = v   (1 为 K 的单位元)      % 5.186
(V6) 对每个 r,s ∈ F 及 v ∈ V: r(sv) = (rs)v        % 5.187
(V7) 对每个 r,s ∈ F 及 v ∈ V: (r+s)v = rv+sv       % 5.188
(V8) 对每个 r ∈ F 及 v,w ∈ V: r(v+w) = rv+rw       % 5.189
```

三个例子：

- 例 A：(1,n)/(n,1) 型单行、单列实矩阵分别形成实向量空间 $\mathbb{R}^n$（行／列向量空间；另见 4.1.3，第 364 页）。
- 例 B：所有 (m,n) 型实矩阵形成实向量空间。
- 例 C：区间 $[a,b]$ 上连续实函数按式 (5.190) 形成实向量空间；函数空间在泛函分析中起基本作用（第 12 章）。

```latex
(f+g)(x) = f(x)+g(x),  (kf)(x) = k·f(x)      % 5.190
```

## 证据性质与复原注记

- 这是手册性定义内容，非经验性主张；证据强度高，但转写须复原后方可引用。
- V2 原文「存在向量 EV 使得对每个 E V,v+O = v」脱落 $0\in V$ 与 $v\in V$；V3 原文「存在向量—使得 v+（—V) = 0」脱落 $-v$——均按阿贝尔群公理文意复原。
- V6–V8（及 5.3.8.2）域记号原作 $F$，与定义所用 $K$ 不一致（[[queries/域记号f与k混用问题]]）。
- V1–V4 即阿贝尔群公理，衔接 [[concepts/群]]；外乘法是 [[concepts/外运算]]（5.3.1）的典范实例，落实 [[findings/外运算定义与前向引用5-3-8]] 的前向引用。
