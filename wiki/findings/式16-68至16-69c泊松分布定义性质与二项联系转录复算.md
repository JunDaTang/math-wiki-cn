# 式 16.68–16.69c 泊松分布定义、性质与二项联系转录复算

对《数学手册(原书第10版)》16.2.3.3「泊松分布」的全部编号公式及无编号性质（可加性、二项联系、应用）作转录与独立复算。

## 转录

```latex
(16.68)   P(X=k) = \frac{\lambda^k}{k!}\,e^{-\lambda},   k = 0,1,2,\dots;  \lambda > 0
(16.69a)  E(X) = \lambda
(16.69b)  D^2(X) = \lambda
(16.69c)  P(X=k+1) = \frac{\lambda}{k+1}\, P(X=k)
无编号：   X_1, X_2 相互独立, X_i ~ Po(\lambda_i)  ⇒  X_1 + X_2 ~ Po(\lambda_1+\lambda_2)
无编号：   np = \lambda 常数, n→∞, p→0 时二项分布 → 泊松分布
```

## 复算

1. **归一化**：$\sum_{k=0}^{\infty} \lambda^k/k! = e^{\lambda}$，故 (16.68) 总和为 1。✔
2. **矩 (16.69a–b)**：$E(X)=\lambda$（用 $k\lambda^k/k! = \lambda\cdot\lambda^{k-1}/(k-1)!$），$E(X^2)=\lambda+\lambda^2$，故 $D^2(X)=\lambda$——期望与方差相等（等散布性）。✔
3. **递推 (16.69c)**：$P(k+1)/P(k) = \lambda/(k+1)$，验证正确；从 $P(0)=e^{-\lambda}$ 出发可生成全分布列。✔
4. **可加性（无编号）**：独立 Po(λ₁) 与 Po(λ₂) 之和服从 Po(λ₁+λ₂)（卷积或母函数可证），标准结果，且原文明确声明了独立性（与二项分布处体例不同）。✔
5. **二项 → 泊松极限（无编号）**：$np=\lambda$ 常数时 $\binom{n}{k}p^k(1-p)^{n-k} \to \frac{\lambda^k}{k!}e^{-\lambda}$（用 $\binom{n}{k}\sim n^k/k!$、$p^k=(\lambda/n)^k$、$(1-p)^{n-k}\to e^{-\lambda}$），稀有事件律成立。✔
6. **实用判据转写**：原文「当 $p \le 0.08$ 和 $n \ge 1500p$ 时即用此公式」，其中「n ≥ 1500p」形式罕见且判据强度随 p 漂移，待核原书，见[[queries/泊松逼近条件n不小于1500p之辨]]；另原文「参数为入」之「入」为 λ 的转写讹误。⚠
7. **图表回指**：第 1456 页表 21.16（泊松分布数值表）与图 16.4（λ=2.5/1.25/0.5，对应 λ=np 参数链）均存在，但表 21.16 未入库，见[[queries/16-2-3未入库回指缺口]]。

## 证据强度

定义、矩、递推、可加性与极限关系为可复算的确定性数学内容（直接证据，强）；实用判据 p≤0.08、n≥1500p 属手册经验法则且转写可疑（间接证据，中），核对原书前不应作为定论引用。
