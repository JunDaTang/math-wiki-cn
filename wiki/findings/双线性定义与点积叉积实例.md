# 双线性定义与点积／叉积实例（式 5.208–5.209，已复算，含讹误标注）

## 陈述（5.3.8.6.1）

$f:U\times V\to W$（同一域 $K$ 上的向量空间）是双线性的，如果对每个 $u\in U$，$v\mapsto f(u,v)$ 线性，且对每个 $v\in V$，$u\mapsto f(u,v)$ 线性（式 5.208），即对每个 $k\in K$、$u,u'\in U$、$v,v'\in V$：

```latex
f(u+u', v) = f(u,v) + f(u',v)     f(ku, v) = k f(u,v)
f(u, v+v') = f(u,v) + f(u',v)     f(u, kv) = k f(u,v)     % 5.209
```

若用点积、向量积或域中乘法代替 $f$，这些关系刻画该乘法对向量加法的左右分配性。实例：

```latex
% 例 A（ℝⁿ 点积）
f(u,v) = u^T v = Σ_{i=1}^n u_i v_i
% 例 B（ℝ³ 叉积）
f(u,v) = u × v = (u₂v₃-u₃v₂, v₁u₃-u₁v₃, u₁v₂-v₁u₂)^T
```

## 复算说明（已复算）

- 点积 $u^{\mathrm T}v=\sum u_iv_i$ 对两个自变量显然线性（坐标的线性组合）。
- 叉积各分量（如 $u_2v_3-u_3v_2$）是坐标的双线性函数，故 $u\times v$ 对 $u$、对 $v$ 分别线性；且 $u\times v = -(v\times u)$（斜对称），与分量公式一致。

## 讹误标注（关键）

式 (5.209) 第三式右端第二项原文作 $f(u',v)$，按双线性性（固定 $u$、对第二自变量线性）应为 $f(u,v')$，否则与式 (5.208) 自相矛盾——疑为转写讹误，见 [[queries/式5-209第三式右端讹误]]。在对照原书复原前，本式不应作为定义引用。
