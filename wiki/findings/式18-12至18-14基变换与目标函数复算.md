# 式 18.12 至 18.14 基变换与目标函数复算

对 18.1.2 算例（式 18.8）的基变换链条 18.12–18.14 逐矩阵独立复算：**全部通过，公式零讹误**。本节的转写讹误全部集中在文字叙述，公式本体罕见地完整可核。

## 基本设定（由扩展系统逐行读出）

```text
A（列 x₁ … x₇）= ⎛ 1  1  1 −1  0  0  0⎞        b = ⎛1⎞
                ⎜ 0  1  0  0  1  0  0⎟            ⎜2⎟
                ⎜−1  0  2  0  0  1  0⎟            ⎜2⎟
                ⎝ 2 −3  2  0  0  0  1⎠            ⎝2⎠
```

## 核验 1：极端点 P₂ 与基列选取

P₂ = (0,1,0) ↔ 扩展坐标 (0,1,0,0,1,2,5)；正分量 x₂=1、x₅=1、x₆=2、x₇=5 恰 m = 4 个，非退化。基列 {2,5,6,7}，非基列 {1,3,4}；式 18.12 的 A_B、A_B⁻¹、A_N 与扩展系统相应列逐项相符（另核 A_B·A_B⁻¹ = I）。

## 核验 2：A_B⁻¹A_N

```text
           ⎛  1   1  −1⎞
A_B⁻¹A_N = ⎜ −1  −1   1⎟   (列: x₁ x₃ x₄)
           ⎜ −1   2   0⎟
           ⎝  5   5  −3⎠
```

第 4 行 = 3×(A_N 第 1 行) + (A_N 第 4 行) = 3·(1,1,−1) + (2,2,0) = (5,5,−3)，核验通过；其余行逐项相符。

## 核验 3：A_B⁻¹b

A_B⁻¹b = (1,1,2,5)，与 P₂ 中基变量取值 (x₂,x₅,x₆,x₇) = (1,1,2,5) 一致（且 A_B⁻¹b ⩾ 0，可行性成立）。

## 核验 4：式 18.13

变换后系统四行与 A_B⁻¹A_N x_N + x_B = A_B⁻¹b 逐行相符：

```text
 x₁ + x₂ + x₃ − x₄          = 1,
−x₁     − x₃ + x₄ + x₅     = 1,
−x₁     + 2x₃     + x₆     = 2,
 5x₁     + 5x₃ − 3x₄ + x₇  = 5.
```

## 核验 5：式 18.14 与常数 c₀

原文“减去第一个约束的〔3〕倍”中倍数脱字，复算确认倍数为 3：

```text
2x₁ + 3x₂ + 4x₃ − 3·(x₁ + x₂ + x₃ − x₄) = −x₁ + x₃ + 3x₄；再加 3×1 得
f(x) = −x₁ + x₃ + 3x₄ + 3.
```

双重印证：f(0,1,0) = 3 = c₀，与“目标函数在该极端点取值 c₀”的论断一致。

## 核验 6：退化极端点 P₁ 的多基性

P₁ = (1,0,0) ↔ (1,0,0,0,2,3,0)：正分量 x₁、x₅、x₆ 共 3 个 < m = 4，退化。基必含列 {1,5,6}；补第 4 列可取第 2、4 或 7 列：

```text
det[1,5,6,2] = −5,   det[1,5,6,4] = 2,   det[1,5,6,7] = 1   （均 ≠ 0，线性无关）
```

三个基对应的基本解同为 P₁：基 {1,5,6,2} 给出 x₁=1、x₂=0、x₅=2、x₆=3；基 {1,5,6,4} 给出 x₁=1、x₄=0、x₅=2、x₆=3；基 {1,5,6,7} 给出 x₁=1、x₅=2、x₆=3、x₇=0——全坐标均为 (1,0,0,0,2,3,0)。这与“退化的极端点就可能选定几个基”的论断相印证，也支持对脱落列号的补全（见 [[退化极端点P1基列号脱落之辨]]）。

## 结论

式 18.12–18.14 转录公式经独立复算全部通过、零讹误；A_B⁻¹b = (1,1,2,5) 与 c₀ = 3 构成相互独立的双重印证。文字叙述中的脱字与乱码（倍数"3"、列号、点坐标等）均已由复算补定，详见 [[18-1-2全节系统性转写讹误清单]]。
