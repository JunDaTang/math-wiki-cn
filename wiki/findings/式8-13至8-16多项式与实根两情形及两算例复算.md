# 多项式积分与实根两情形公式及两算例（式 8.13–8.16，已复算）

**来源**：[[sources/10-数学手册原书第10版--11-813-有理函数的积分--1lrte2m]] 之 8.1.3.1（整有理函数）、8.1.3.2（五步流程中的分母分解）与 8.1.3.3 情形 1–2（实根两情形）。

## 式 8.13：整有理函数（多项式）的逐项积分

```latex
\int (a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0)\,\mathrm{d}x
= \frac{a_n}{n+1} x^{n+1} + \frac{a_{n-1}}{n} x^n + \dots + \frac{a_1}{2} x^2 + a_0 x + C
```

复算：逐项套用幂函数积分公式 ∫x^k dx = x^{k+1}/(k+1)（k ≠ −1），显然成立。✅

## 式 8.14a–b：分母的标准分解与不可约条件

```latex
Q(x) = a_n (x-\alpha)^k (x-\beta)^l \dots (x^2+px+q)^r (x^2+p'x+q')^s \dots \tag{8.14a}
\frac{p^2}{4} - q < 0,\quad \frac{p'^2}{4} - q' < 0,\; \dots \tag{8.14b}
```

复算：p²/4 − q < 0 ⟺ 判别式 p² − 4q < 0，即二次因式无实根、在实数域不可约——这正是实系数多项式因式分解的完备形式（线性 + 不可约二次）。✅

## 情形 1：分母的所有根均为实单根（式 8.15a–d）

```latex
Q(x) = (x-\alpha)(x-\beta)\dots(x-\lambda) \tag{8.15a}
\frac{P(x)}{Q(x)} = \frac{A}{x-\alpha} + \frac{B}{x-\beta} + \dots + \frac{L}{x-\lambda} \tag{8.15b}
A = \frac{P(\alpha)}{Q'(\alpha)},\quad B = \frac{P(\beta)}{Q'(\beta)},\quad \dots,\quad L = \frac{P(\lambda)}{Q'(\lambda)} \tag{8.15c}
\int\frac{A\,\mathrm{d}x}{x-\alpha} = A\ln|x-\alpha| \tag{8.15d}
```

**归属限定**：式 8.15c 的 P(α)/Q′(α)（Heaviside 覆盖法型公式）隐含"单根"前提——在单根处 Q(x) = (x−α)R(x) 且 Q′(α) = R(α) ≠ 0。该公式仅在情形 1 语境下成立，**不可外推至重根**（重根处 Q′(α) = 0，公式失效）。

## 情形 2：分母的所有根均为实数，但其中一些为多重根（式 8.16a–c）

```latex
Q(x) = (x-\alpha)^l (x-\beta)^m \dots \tag{8.16a}
```

```latex
\frac{P(x)}{Q(x)} = \frac{A_1}{x-\alpha} + \frac{A_2}{(x-\alpha)^2} + \dots + \frac{A_l}{(x-\alpha)^l}
+ \frac{B_1}{x-\beta} + \frac{B_2}{(x-\beta)^2} + \dots + \frac{B_m}{(x-\beta)^m} + \dots \tag{8.16b}
```

```latex
\int\frac{A_1\,\mathrm{d}x}{x-\alpha} = A_1\ln|x-\alpha|,\qquad
\int\frac{A_k\,\mathrm{d}x}{(x-\alpha)^k} = -\frac{A_k}{(k-1)(x-\alpha)^{k-1}}\quad(k>1) \tag{8.16c}
```

复算（式 8.16c 第二式）：d/dx[−A_k/((k−1)(x−α)^{k−1})] = A_k(x−α)^{−k}。✅

## 算例 1（情形 1）：I = ∫(2x+3)dx/(x³+x²−2x)

分解设定（原文逐字）：

```latex
\frac{2x+3}{x(x-1)(x+2)} = \frac{A}{x} + \frac{B}{x-1} + \frac{C}{x+2}
```

系数（原文数值逐字）：

```latex
A = \frac{P(0)}{Q'(0)} = \left(\frac{2x+3}{3x^2+2x-2}\right)_{x=0} = -\frac{3}{2},\quad
B = \left(\frac{2x+3}{3x^2+2x-2}\right)_{x=1} = \frac{5}{3},\quad
C = \left(\frac{2x+3}{3x^2+2x-2}\right)_{x=-2} = -\frac{1}{6}
```

结果（原文逐字）：

```latex
I = -\frac{3}{2}\ln|x| + \frac{5}{3}\ln|x-1| - \frac{1}{6}\ln|x+2| + C_1
  = \ln\left|\frac{C(x-1)^{5/3}}{x^{3/2}(x+2)^{1/6}}\right|
```

复算：Q′(x) = 3x²+2x−2；Q′(0) = −2 → A = 3/(−2) = −3/2 ✅；Q′(1) = 3 → B = 5/3 ✅；Q′(−2) = 6 → C = −1/6 ✅。对合并形式求导：(5/3)/(x−1) − (3/2)/x − (1/6)/(x+2) 通分得 (2x+3)/(x(x−1)(x+2)) ✅。**通过**。

## 算例 2（情形 2）：I = ∫(x³+1)dx/(x(x−1)³)

待定系数法方程组与解（原文逐字）：

```latex
A + B_1 = 1,\quad -3A - 2B_1 + B_2 = 0,\quad 3A + B_1 - B_2 + B_3 = 0,\quad -A = 1
```

```latex
A = -1,\; B_1 = 2,\; B_2 = 1,\; B_3 = 2
```

积分结果（原文逐字）：

```latex
I = \int\left[-\frac{1}{x} + \frac{2}{x-1} + \frac{1}{(x-1)^2} + \frac{2}{(x-1)^3}\right]\mathrm{d}x
= -\ln|x| + 2\ln|x-1| - \frac{1}{x-1} - \frac{1}{(x-1)^2} + C
= \ln\left|\frac{(x-1)^2}{x}\right| - \frac{x}{(x-1)^2} + C
```

复算：
- 方程组：设 (x³+1) = A(x−1)³ + B₁x(x−1)² + B₂x(x−1) + B₃x，展开比较系数得 x³: A+B₁，x²: −3A−2B₁+B₂，x: 3A+B₁−B₂+B₃，常数: −A，与原文方程组一致；✅
- 系数回代：−(x−1)³ + 2x(x−1)² + x(x−1) + 2x = x³ + 1；✅
- 结果合并：−1/(x−1) − 1/(x−1)² = −x/(x−1)²，逐项积分无误。✅ **通过**。
