# 可约性分块化简与 S_3 基变换算例（式 5.114–5.117，已复算）

**来源**：[[sources/10-数学手册原书第10版--7-534-群表示--x5kmh9]]（5.3.4.5）。

- **式 (5.114)**：存在真不变子空间 $V_m$ 时，经基变换 $T$ 可将表示矩阵化为分块三角形 $T^{-1} D(a) T = \begin{pmatrix} D_1(a) & A \\ 0 & D_2(a) \end{pmatrix}$，$D_1$、$D_2$ 分别为 $m$ 维与 $n-m$ 维表示（转写本「a∈G 维」脱落「m」）。
- 无真（非平凡）不变子空间 ⇒ 不可约；**一个有限群的不等价的不可约表示的个数是有限的**。
- **式 (5.115)–(5.116)**：$V_n = V_1 \oplus \dots \oplus V_{n_j}$ 时，表示矩阵化为分块对角形（$A = 0$），即**完全可约**。

## S_3 算例（式 5.117，已复算）

对 (5.106c) 的三维表示（基 $\psi_i = e_i$），取基变换：

$$e_1' = e_1 + e_2 + e_3, \quad e_2' = e_2, \quad e_3' = e_3,$$

则置换 $p_3$ 的表示矩阵形式不变，且呈分块结构：

```text
D(p₃) = [[1,0,0],[0,0,1],[0,1,0]] = [[D₁(p₃), 0], [A, D₂(p₃)]]
D₁(p₃) = 1 （S₃ 的恒等表示，1×1 块）
A      = (0, 0)ᵀ
D₂(p₃) = [[0,1],[1,0]]
```

**独立复算**（本 wiki）：在新基下 $p_3(e_1') = e_1'$（故 $\mathrm{span}\{e_1'\}$ 为一维不变子空间）、$p_3(e_2') = e_3'$、$p_3(e_3') = e_2'$，因此新基下矩阵确为上式，分块解读成立。原书仅对 $p_3$ 展示分块形式。此算例与特征分解 $3 = 1+2$ 相互印证（见 [[findings/壳层模型s3三维表示与特征]]）。
