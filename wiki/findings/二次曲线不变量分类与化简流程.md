# 二次曲线不变量分类与化简流程（式 3.353 + 表 3.19/3.20，分类已抽查验证）

## 一般方程与不变量

```
ax² + 2bxy + cy² + 2dx + 2ey + f = 0                            (3.353a)
Δ = |a b d; b c e; d e f|,  δ = |a b; b c|,  S = a + c          (3.353b)
```

三个量在坐标系的**旋转**下保持不变。(3.353a) 中的系数并非特殊圆锥曲线中的参数。

## 表 3.19（有心曲线，δ≠0）

| 条件 | 曲线形状 |
|---|---|
| δ>0，Δ≠0，Δ·S<0 | 实椭圆 |
| δ>0，Δ≠0，Δ·S>0 | 虚椭圆 |
| δ>0，Δ=0 | 一对具有实公共点的虚直线 |
| δ<0，Δ≠0 | 双曲线 |
| δ<0，Δ=0 | 一对相交直线 |

化简：① 平移原点至中心 x₀=(be−cd)/δ、y₀=(bd−ae)/δ；② 旋转 α 角，tan 2α = 2b/(a−c)（转写中分数线脱落），sin 2α 符号须与 2b 一致；新 x′ 轴斜率 k = [c−a+√((c−a)²+4b²)]/(2b)；标准形 **a′x′² + c′y′² + Δ/δ = 0**，a′、c′ 为 u²−Su+δ=0 之根（即 a′=(a+c+√((a−c)²+4b²))/2，c′=(a+c−√((a−c)²+4b²))/2）。

## 表 3.20（抛物型，δ=0）

| 条件 | 曲线形状 |
|---|---|
| δ=0，Δ≠0 | 抛物线 |
| δ=0，Δ=0，d²−af>0 | 一对平行实直线 |
| δ=0，Δ=0，d²−af=0 | 二重直线 |
| δ=0，Δ=0，d²−af<0 | 一对虚直线 |

化简（Δ≠0）：① 平移至顶点，x₀、y₀ 由 a·x₀+b·y₀+(ad+be)/S=0 与 (d+(dc−be)/S)·x₀+(e+(ae−bd)/S)·y₀+f=0 给出；② 旋转 α 角，tan α = −a/b（sin α 符号与 a 相异）；标准形 **y′² = 2px′，p = (ae−bd)/(S·√(a²+b²))**。Δ=0 时仅旋转：S·y′² + 2(ad+be)/√(a²+b²)·y′ + f = 0，可化为 (y′−y₀′)(y′−y₁′)=0。脚注：δ=0 情形假设 a、b、c 均不为 0（转写讹作「0=0」）。

## 验证（分析阶段抽查，视为已复算）

- 试例分类全部正确：x²+y²−1=0（δ=1>0，Δ=−1，Δ·S=−2<0 → 实椭圆）；x²+y²+1=0（Δ·S>0 → 虚椭圆）；x²−y²−1=0（δ=−1<0，Δ≠0 → 双曲线）；xy=1（δ<0 → 双曲线）；y²−x=0（δ=0，Δ≠0 → 抛物线）。✓
- 中心坐标公式、新轴斜率 k、a′、c′ 为特征值（u²−Su+δ=0 之根）复算成立。✓
- 对旋转 45° 的抛物线试例复核 tan α = −a/b（因 b²=ac，等价于 −b/c）与 p = (ae−bd)/(S√(a²+b²)) 均正确。✓

## 备注

不变量文中仅声明「旋转下不变」，而表 3.19 标准形在平移+旋转后仍用原 Δ，隐含平移不变性——属 understatement（保守表述），非矛盾。流程的「为什么」见 [[methodology/二次曲线一般方程化简流程]]；圆锥截线刻画与极坐标方程见 [[findings/圆锥曲线统一定义与极坐标方程]]。
