# 式 13.40–13.46 梯度运算法则与中心场梯度转录复算

## 转录

```latex
% 以下假设 c 为常数（原文此处脱符号 c）
(13.40)  grad c = 0⃗,  grad(U₁+U₂) = grad U₁ + grad U₂,  grad(cU) = c grad U
(13.41)  grad(U₁U₂) = U₁ grad U₂ + U₂ grad U₁,  grad φ(U) = (dφ/dU) grad U
(13.42)  grad(V⃗₁·V⃗₂) = (V⃗₁·grad)V⃗₂ + (V⃗₂·grad)V⃗₁ + V⃗₁ × rot V⃗₂ + V⃗₂ × rot V⃗₁
(13.43)  grad(r⃗·c⃗) = c⃗
(13.44)  dU = grad U·dr⃗ = ∂U/∂x dx + ∂U/∂y dy + ∂U/∂z dz
(13.45)  dU/dt = ∂U/∂x·dx/dt + ∂U/∂y·dy/dt + ∂U/∂z·dz/dt
(13.46a) grad U(r) = U′(r) r⃗/r   （球面场）
(13.46b) grad r = r⃗/r            （单位向量场）
```

## 复算

**式 (13.40)、(13.41)**：逐分量验证即偏导数的线性、乘积与链式法则，与 [[concepts/向量函数的微分法则]] 平行。**正确**。

**式 (13.42)**：与标准向量分析恒等式一致。特例复算：取 $\vec{V}_1 = \vec{V}_2 = \vec{r}$，左端 $\operatorname{grad}|\vec{r}|^2 = \operatorname{grad}(x^2+y^2+z^2) = 2\vec{r}$；右端 $(\vec{r} \cdot \operatorname{grad})\vec{r} = \vec{r}$ 两项共 $2\vec{r}$，而 $\operatorname{rot}\,\vec{r} = \vec{0}$ 使叉积项消失，恰为 $2\vec{r}$。✓ **正确**。注意此式提前引用 rot（旋度），该概念属后续小节（见 [[queries/13-2-2未入库回指缺口]]）。

**式 (13.43)**：$\vec{r} \cdot \vec{c} = c_1 x + c_2 y + c_3 z$，逐分量求偏导得 $\vec{c}$。**正确**。

**式 (13.44)**：以 (13.36) 与 $\mathrm{d}\vec{r} = \mathrm{d}x\,\vec{i} + \mathrm{d}y\,\vec{j} + \mathrm{d}z\,\vec{k}$ 点积即得。**正确**。

**式 (13.45)**：沿 $\vec{r}(t)$ 的链式法则，或以 $\mathrm{d}\vec{r}/\mathrm{d}t$ 代入 (13.44) 后除以 $\mathrm{d}t$。**正确**。

**式 (13.46a)**：链式法则 $\operatorname{grad} U(r) = U'(r)\operatorname{grad} r$，结合 (13.46b) 即得。**正确**。

**式 (13.46b)**：$\operatorname{grad} r = \operatorname{grad}(x^2+y^2+z^2)^{1/2} = \frac{1}{2}(x^2+y^2+z^2)^{-1/2} \cdot 2(x,y,z) = \vec{r}/r$。**正确**。

## 讹误标记

- 13.2.2.6 开头「以下假设 为常数」脱符号 $c$。

## 结论

全部恒等式复算无误，与标准向量分析一致；(13.42) 的 rot 为前向引用；13.46a/b 宜同步补入既有 [[concepts/中心场]]、[[concepts/中心向量场与球面向量场]] 页（见建议审查）。
