# 三台机器次品率全概率与贝叶斯算例转录复算

## 算例设定（转录）

某工厂三台机器生产同一类产品：第一台产量占全厂总产量的 20%，第二、三台分别占 30% 和 50%；由过去的经验可知，每台机器的次品率分别为 5%、[4]%（转写脱落，内证复原）和 2%。

符号化：

- 事件 $A_i$：随机挑出的产品由第 $i$ 台机器生产（$i = 1, 2, 3$）——$P(A_1) = 0.2$，$P(A_2) = 0.3$，$P(A_3) = 0.5$；
- $A_i$ 构成完备事件组：$A_iA_j = O$，$A_1 + A_2 + A_3 = I$；
- 事件 $A$：挑出的产品是次品——$P(A|A_1) = 0.05$，$P(A|A_2) = 0.04$，$P(A|A_3) = 0.02$。

## 两问与转录结果

**a) 全概率（任取一件是次品的概率）：**

$$P(A) = 0.2\times0.05 + 0.3\times0.04 + 0.5\times0.02 = 0.032$$

**b) 贝叶斯（次品由第一台机器生产的概率）：**

$$P(A_1 \mid A) = P(A_1)\cdot\frac{P(A \mid A_1)}{P(A)} = 0.2 \times \frac{0.05}{0.032} = 0.31$$

## 复算核验（直接证据）

- a) $0.2\times0.05 = 0.010$；$0.3\times0.04 = 0.012$；$0.5\times0.02 = 0.010$；合计 $0.032$ ✓。
- b) $P(A_1|A) = P(AA_1)/P(A) = 0.010/0.032 = 0.3125$，手册舍入为 0.31 ✓。
- 交叉验证其余后验：$P(A_2|A) = 0.012/0.032 = 0.375$，$P(A_3|A) = 0.010/0.032 = 0.3125$；三者之和 $0.3125 + 0.375 + 0.3125 = 1$ ✓（完备事件组的归一化自洽检查）。
- 次品率 4% 的复原：后文明示 $P(A|A_2) = 0.04$，与「5%、［？］%和 2%」的空位对应 ✓（内证，非直接证据）。

## 转写讹误

- 「第 台机器」的 $i$、「事件 表示挑出的产品是次品」的 $A$ 符号脱落。
- 「次品率分别 5%, ％和 2%」缺数字 4。
- 「于是」转写为「千是」。

## 结论

算例数值全部复算通过；0.032 与 0.31（精确 0.3125）可信。本例同时是 [[methodology/全概率与贝叶斯算例求解流程]] 的原型。
