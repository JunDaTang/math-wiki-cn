# 式 14.116–14.125 魏尔斯特拉斯函数转录复算

对 14.6.4 各式逐条转录并复算（来源：[[10-数学手册原书第10版--8-146-椭圆函数--3vhx9i]]）。

## 复算结果

| 对象 | 内容 | 结论 |
|---|---|---|
| (14.117a) | ω_mn = 2(mω₁+nω₂) | 正确；由此 ℘ 的周期格由 2ω₁、2ω₂ 生成 |
| (14.117b) | ℘ 格点级数（撇号求和忽略 m=n=0） | 正确；z→0 主项 z⁻²（二阶极点），双周期性成立 |
| (14.118a)(14.118b) | ℘′² = 4℘³−g₂℘−g₃；g₂ = 60Σ′ω_mn⁻⁴、g₃ = 140Σ′ω_mn⁻⁶ | 正确；系数 60、140 与标准理论一致 |
| (14.119) | ℘ 为 z = ∫_u^∞ dt/√(4t³−g₂t−g₃) 的反函数 | 正确 |
| (14.120) | ℘ 加法定理 | 正确 |
| (14.121a) | ζ 级数 | 正确；逐项求导得 ζ′ = −℘ |
| (14.121b) | σ 的积分式与乘积式 | 两式等价，正确；由积分式立得 σ′/σ = ζ |
| (14.122) | ζ′ = −℘；ζ = ln σ | 前半正确；后半疑丢求导号（疑点 2） |
| (14.123) | ζ 奇、σ 奇 | 正确 |
| (14.124) | ζ 的拟周期关系 | 正确 |
| (14.125) | ζ 加法定理 | 正确 |

## 三处文本疑点（均属本小节行文，不影响上表已列公式的正确性）

1. ℘ 性质 (1) 称“有周期 ω₁ 和 ω₂”，与 (14.117a)、(14.124) 隐含的 2ω₁、2ω₂ 矛盾（ω₁ 本身不是 ℘ 的极点，故不可能是周期）。见 [[魏尔斯特拉斯wp周期omega与2omega之辨]]。
2. (14.122) “ζ(z) = ln σ(z)”疑丢求导号：由 (14.121b) 乘积式逐项求导可得 ζ(z) = (ln σ(z))′ = σ′(z)/σ(z)。见 [[式14-122zeta等于lnsigma疑丢求导记号]]。
3. ζ/σ 性质 (5) “每个椭圆函数是 ℘(z) 和 ζ(z) 的有理函数”按字面为假（℘′ 即为反例）；标准定理为 ℘ 与 ℘′ 的有理函数。见 [[魏尔斯特拉斯性质5wp与zeta有理表示之辨]]。
