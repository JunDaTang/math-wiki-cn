# 球面三角形一般命题组（式 3.180–3.186）

《数学手册(原书第10版)》3.4.2.1 给出球面三角形的八条一般命题（边、角均以角度量）：

```
(1) 三边之和    0° < a + b + c < 360°             (3.180)
(2) 两边之和    a + b > c                         (3.181)
(3) 两边之差    |a − b| < c                       (3.182)
(4) 三角之和    180° < α + β + γ < 540°           (3.183)
(5) 球面角盈    ε = α + β + γ − 180°              (3.184)
(6) 两角之和    α + β < γ + 180°                  (3.185)
(7) 对边和角    较大的边所对的角也较大，反之亦然
(8) 面积        A_T = εR²·π/180° = R²ε/ρ = R² arc ε   (3.186a)
                A_T = (A_S/720°)·ε                (3.186b)
```

要点：

- 边的命题 (1)–(3) 是平面三角不等式（见 [[findings/三角不等式与内角和]]）的球面版，但增加了周长上限 360°；两角关系 (6) 为球面特有。
- 角的命题 (4)–(5) 与平面内角和恒为 180° 形成本质对照：球面三角形角和有 360° 的活动范围，超出 180° 的部分即 [[concepts/球面角盈]]。
- 面积命题 (8) 即 [[concepts/吉拉尔定理]]；若已知边而非角盈，手册指明借助 [[concepts/吕利耶公式]]（式 3.201）先算角盈。

## 内部矛盾

命题 (1) 的正文称「三边之和介于 0° 和 180° 之间」，而式 (3.180) 为 0° < a+b+c < 360°。数学上正确者为 **360°**（欧拉三角形周长小于 360°），正文疑为转写讹误，详见 [[queries/式3-180三边之和上限是否为360度]]。

## 复核状态

公式经入库分析独立核验全部正确，命题体系与教科书标准球面三角学一致；证据为经典数学理论（非实验结果），replicated 指公式经独立符号/数值复核。
