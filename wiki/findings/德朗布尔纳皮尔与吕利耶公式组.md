# 德朗布尔、纳皮尔与吕利耶公式组（式 3.198–3.201）

3.4.2.3「更多的公式」给出三组公式，代表式如下（轮换形式见各概念页）：

```
德朗布尔等式    cos((α−β)/2)/sin(γ/2) = sin((a+b)/2)/sin(c/2)          (3.198a)
                （4 式，轮换共 12 式）
纳皮尔等式      tan((α−β)/2) = [sin((a−b)/2)/sin((a+b)/2)]·cot(γ/2)    (3.199a)
                （4 式，也称纳皮尔类比）
球面正切定律    tan((a−b)/2)/tan((a+b)/2) = tan((α−β)/2)/tan((α+β)/2)  (3.200a)
                （及轮换共 3 式）
吕利耶等式      tan(ε/4) = √[tan(s/2)·tan((s−a)/2)·tan((s−b)/2)·tan((s−c)/2)]  (3.201)
```

各概念页：[[concepts/德朗布尔等式]]、[[concepts/纳皮尔类比]]、[[concepts/球面正切定律]]、[[concepts/吕利耶公式]]。

## 平面对应

手册逐条声明平面对应物：德朗布尔等式 ↔ 莫尔韦德公式；纳皮尔等式/球面正切定律 ↔ 平面正切定律（[[concepts/正切定律]]）；吕利耶等式 ↔ 海伦公式（[[concepts/海伦公式]]）。对应总表见 [[comparisons/平面与球面三角学公式对应比较]]。

## 面积计算的路径重申

手册在本条重申：已知三角 → 角盈（3.184）→ 面积（3.186a）；已知三边 → 先由半角公式（3.193a–e）求角，或**直接**由吕利耶等式（3.201）算角盈。

## 复核状态

四组代表式经入库分析独立核验正确，均为经典球面三角学公式；replicated 指公式经独立符号核验。
