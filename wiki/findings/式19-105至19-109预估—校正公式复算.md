# 式 19.105–19.109 预估—校正公式复算

**转录**（源文逐字保留）：

```latex
(19.105)  y_{i+k} = h \sum_{j=0}^{k} \beta_j f_{i+j} - \sum_{j=0}^{k-1} \alpha_j y_{i+j} = F(y_{i+k})
(19.106)  y_{i+k}^{(\mu+1)} = F(y_{i+k}^{(\mu)})   (\mu = 0,1,2,\dots)
(19.107a) y_{i+1}^{(0)} = y_i + \frac{h}{12}(5f_{i-2} - 16f_{i-1} + 23f_i)
(19.107b) y_{i+1}^{(\mu+1)} = y_i + \frac{h}{12}(-f_{i-1} + 8f_i + 5f_{i+1}^{(\mu)})   (\mu = 0,1,\dots)
(19.108a) y_{i+1}^{(0)} = y_{i-2} + 9y_{i-1} - 9y_i + 6h(f_{i-1} + f_i)
(19.108b) y_{i+1}^{(\mu+1)} = y_{i-1} + \frac{h}{3}(f_{i-1} + 4f_i + f_{i+1}^{(\mu)})   (\mu = 0,1,\dots)
(19.109)  y_{i+1}^{(\mu+1)} = 0.9 y_{i-1} + 0.1 y_i + \frac{h}{24}(0.1 f_{i-2} + 6.7 f_{i-1} + 30.7 f_i + 8.1 f_{i+1}^{(\mu)})
```

**复算（独立验证，通过）**：

- **(19.107a,b)**：与标准 Adams 三阶预估—校正对系数逐项一致（预估子系数 5/12、−16/12、23/12；校正子系数 −1/12、8/12、5/12）。
- **(19.108a)**：对 y = 1, x, x², x³, x⁴ 逐一检验均精确成立 ⟹ **四阶**预估子。注意其形式与经典米尔恩预估子 y_{i+1}^{(0)} = y_{i−3} + (4h/3)(2f_{i−2} − f_{i−1} + 2f_i) 不同，见 [[queries/式19-108a预估子与经典米尔恩预估子形式之辨]]。
- **(19.109)**：同样对次数 ⩽ 4 的多项式精确 ⟹ **四阶**稳定化校正子；其系数组合不对应经典 Hamming 校正子形式，来源待查（同上查询页）。
- (19.108b) 为辛普森型校正子（即米尔恩法则平移指标），源文明言其数值不稳定并建议以 (19.109) 替换——此为源内定性断言，未附证明。

**证据性质区分**：系数精确性检验为直接复算证据；“该对为 Adams 对/米尔恩对”的命名归属为本维基推断（源文未冠名）；“辛普森校正子数值不稳定”与“隐式法允许大得多的步长”为源内无证明断言。见 [[concepts/预估—校正法]]。
