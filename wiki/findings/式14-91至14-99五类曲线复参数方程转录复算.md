# 式 14.91–14.99 五类曲线复参数方程转录复算

## 转录内容

```latex
z = x(t) + \mathrm{i}y(t) = f(t)                                               (14.91)
直线（过 z_1，与实轴夹角 \varphi）:  z = z_1 + t\,e^{\mathrm{i}\varphi}           (14.92a)
直线（过 z_1, z_2）:                  z = z_1 + t(z_2 - z_1)                     (14.92b)
圆周（半径 r，圆心 z_0 = 0）:         z = r\,e^{\mathrm{i}t}   (|z| = r)          (14.93a)
圆周（半径 r，圆心 z_0）:             z = z_0 + r\,e^{\mathrm{i}t}  (|z - z_0| = r)  (14.93b)
椭圆（范式）:   z = a\cos t + \mathrm{i}b\sin t                                 (14.94a)
                z = c\,e^{\mathrm{i}t} + d\,e^{-\mathrm{i}t},  c = (a+b)/2,  d = (a-b)/2  (14.94b)(14.94c)
椭圆（一般形式，中心 z_1）:  z = z_1 + c\,e^{\mathrm{i}t} + d\,e^{-\mathrm{i}t}   (14.95)
双曲线（范式）: z = a\cosh t + \mathrm{i}b\sinh t                               (14.96)
                z = c\,e^{t} + \bar{c}\,e^{-t},  c = (a+\mathrm{i}b)/2,  \bar{c} = (a-\mathrm{i}b)/2  (14.97)(14.98)
对数螺线:       z = a\,e^{\mathrm{i}bt}                                        (14.99)
```

## 复算过程与结论

- **(14.91)**：一般参数式，定义性陈述 ✓。
- **(14.92a/b)**：直线验证——(14.92a) 方向为 $e^{\mathrm{i}\varphi}$（单位向量），$t = 0$ 时过 $z_1$ ✓；(14.92b) $t = 0, 1$ 分别给出 $z_1, z_2$ ✓。
- **(14.93a/b)**：圆周验证——$|r\,e^{\mathrm{i}t}| = r$ ✓；$|z_0 + r\,e^{\mathrm{i}t} - z_0| = r$ ✓。⚠ (14.93a) 圆心说明“$z_0 =$”处转写缺"0"。
- **(14.94a–c)**：椭圆验证——$c\,e^{\mathrm{i}t} + d\,e^{-\mathrm{i}t} = (c+d)\cos t + \mathrm{i}(c-d)\sin t$，代入 $c = \frac{a+b}{2}$、$d = \frac{a-b}{2}$ 得 $a\cos t + \mathrm{i}b\sin t$ ✓；且 $x = a\cos t$、$y = b\sin t$ 满足 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ ✓。
- **(14.95)**：一般椭圆为范式加平移 $z_1$，$c, d$ 取复数时实现轴的旋转 ✓（复算附注）。⚠ 转写说明文字丢失 $d$。
- **(14.96–14.98)**：双曲线验证——$c\,e^{t} + \bar{c}\,e^{-t} = (c+\bar{c})\cosh t + (c-\bar{c})\sinh t$，代入 $c = \frac{a+\mathrm{i}b}{2}$ 得 $a\cosh t + \mathrm{i}b\sinh t$ ✓；且 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = \cosh^2 t - \sinh^2 t = 1$ ✓。共轭系数对保证轨迹为实系数双曲线。
- **(14.99)**：⚠ **名实矛盾（高置信）**。若 $b$ 为实数，$|z| = |a|\,|e^{\mathrm{i}bt}| = |a|$ 恒定，轨迹是圆周（同 14.93a）而非螺线；仅当 $b = b_1 + \mathrm{i}b_2$（$b_1, b_2 \neq 0$）时 $|z| = |a|e^{-b_2 t}$、$\arg z = b_1 t$，方为对数螺线。转写文本的参数限定语（“其中 ___ 是任意复数”）符号缺失。见 [[queries/式14-99对数螺线参数限定语缺失之辨]]。

**结论**：数学内容全部复算通过；转写疑点集中于说明文字（另见 [[queries/式14-94c与14-95椭圆参数说明文字疑损]]）。

## 附带的转写噪声

“Zl 五”应为 $z_1, z_2$；“共辄”应为“共轭”；“3. 椭圆 3. 椭圆”重复；引言曲线列举顺序（双曲线在椭圆前）与正文呈现顺序相反；14.5.3 引言多处符号（$t$、$z(t)$、$x$ 轴之 $x$）缺失。集中清单见 [[queries/14-5全节系统性转写讹误清单]]。

## 证据强度

系数关系经直接展开验证，证据强度高。双曲线一般形式是否存在、(14.99) 限定语原文，需对照原书。
