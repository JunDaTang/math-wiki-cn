# 式 12.1–12.8 向量空间公理与导出性质转录复算

## 转录内容

```
(V1) x + (y + z) = (x + y) + z                     (12.1)
(V2) 存在零元 0 ∈ V，使得 x + 0 = x                (12.2)
(V3) 对任意 x ∈ V，存在 −x 使得 x + (−x) = 0        (12.3)
(V4) x + y = y + x                                 (12.4)
(V5) 1·x = x，0·x = 0                              (12.5)
(V6) α(βx) = (αβ)x                                 (12.6)
(V7) (α + β)x = αx + βx                            (12.7)
(V8) α(x + y) = αx + αy                            (12.8)
```

标量域 𝔽 为实数域 ℝ 或复数域 ℂ（转写分别乱码为「IF」「叹」）。差定义 x − y = x + (−y)；方程 x + y = z 对任意 y, z 可解，解 x = z − y。

## 复算验证

- **零元唯一**：设 0、0′ 均满足 (V2)，则 0 = 0 + 0′ = 0′（交替使用 (V2) 与 (V4)）。✓
- **αx = βx ∧ x ≠ 0 ⟹ α = β**：否则 (α−β)x = 0（由 V7）而 α−β ≠ 0，结合「α ≠ 0 时 αx = 0 ⟹ x = 0」（由 V5/V6/V7 导出）得 x = 0，矛盾。✓
- **αx = αy ∧ α ≠ 0 ⟹ x = y**：α(x−y) = 0，同上。✓
- **−(αx) = α·(−x)**：二者均为 αx 的加法逆，由 (V3) 给出元的逆的唯一性（由 V1/V4 导出）相等。✓

四条导出性质均成立，转录与标准理论一致。

## 转写问题

1. (V2)、(V3) 的表述缺「∀x ∈ V」量词（(V2) 尤其明显：「存在元素 0 ∈ V, 即零元, 使得 x + 0 = x」未绑定 x），属转写不完整，语义按公理惯例复原。
2. 式 (12.8) 在源中带双重标签 `\tag{V8}\tag{12.8}`。
3. 「取决千」「对千」等「千」代「于」的系统讹误贯穿本段。

## 结论

公理体系转录忠实（除上述量词与标签问题），导出性质全部复算通过。相关页面：[[concepts/向量空间公理]]；讹误汇总见 [[queries/12-1全节系统性转写讹误清单]]。
