# 八种逆模糊化方法定义与公式（式 5.382–5.388，逐字转录）

《数学手册(原书第10版)》5.9.5 断言逆模糊化「有多种方法得以达到此目的」，并列举 8 种；其中 7 种给出公式（式 5.382–5.388），方法 8 无公式。本页逐字转录全部公式（保留 OCR 讹误），作为后续勘误与复核的底本。

## 公式转录

```latex
(5.382)  sup(μ^{输出}_{x₁,…,xₙ}) := { y ∈ Y | μ_{x₁,…,xₙ}(y) ⩾ μ_{x₁,…,xₙ}(y*), ∀y* ∈ Y }

(5.383)  η_MOM = [ ∫_{y ∈ sup(μ^{输出}_{x₁,…,xₙ})} y dy ] / [ ∫_{y ∈ sup(μ^{输出}_{x₁,…,xₙ})} dy ]

(5.384)  η_COG = [ ∫_{y_inf}^{y_sup} μ(y)·y dy ] / [ ∫_{y_inf}^{y_sup} μ(y) dy ]

(5.385)  η_PCOG = [ ∫_{y_inf}^{y_sup} μ(y)^γ·y dy ] / [ ∫_{y_inf}^{y_sup} μ(y)^γ dy ]

(5.386)  η_GCOG = [ ∫_{y_inf}^{y_sup} μ(y)^{γ(y)}·y dy ] / [ ∫_{y_inf}^{y_sup} μ(y)^{γ(y)} dy ]

(5.387)  ∫_{y_inf}^{η} μ(y) dy = ∫_{η}^{y_sup} μ(y) dy

(5.388)  ∫_{y_inf}^{η_PB} μ(y)^γ dy = ∫_{η_PF}^{y_sup} μ(y)^γ dy
```

## 方法—公式对应与证据强度

| 方法 | 公式 | 证据强度 |
|---|---|---|
| 1. 极大值准则法 | 无 | 定义可用，仅一句话 |
| 2. MOM | 5.382（集合定义）+ 5.383 | 公式骨架可信；sup 记号非标准 |
| 3. COG | 5.384 | 公式骨架可信，与通行文献一致 |
| 4. PCOG | 5.385 + 两条退化断言 | 公式骨架可信；断言之二存疑（见下） |
| 5. GCOG | 5.386 | 公式骨架可信；「是 PCOG 的一般化」显然成立 |
| 6. COA | 5.387 | 公式骨架可信，与通行文献一致 |
| 7. PCOA | 5.388 | 公式骨架可信；η_PB/η_PF 记号内部不一致 |
| 8. LA | 无 | 描述过简（「有效子集合」未定义） |

## 直接证据与推断的区分

- **直接证据**（原书原文）：上表全部定义与公式；PCOG 的两条退化断言；「GCOG 是 PCOG 的一般化」。
- **复核/推断**（非原文）：γ=1 ⇒ COG 的代入验证；γ→0 断言与公式矛盾的分析（[[findings/PCOG参数退化端点]]）；「极大值集合是区间」对多峰 μ 不成立的观察；「COG=均值、COA=中位数」的统计解读。
- 全节**无算例**，无经验性证据。MOM、COG、COA 的定义与通行文献一致；PCOG/GCOG/PCOA 在通行英文文献中较少见（疑源自德文文献传统——待核）。
