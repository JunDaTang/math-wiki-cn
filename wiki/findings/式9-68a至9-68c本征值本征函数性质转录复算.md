# 式 9.68a–9.68c 本征值与本征函数性质转录复算

## 性质组转录（9.1.3.2，讹误已标注）

**1)** 边值问题的本征值形成一个单调增的、趋向千（于）无穷的实数序列

```latex
\lambda_{0} < \lambda_{1} < \lambda_{2} < \dots < \lambda_{n} < \dots. \tag{9.68a}
```

**2)** 与本征值 λₙ 相伴的本征函数在区间 a < x < b 中恰有 [n] 个根．（转写脱「n」，依标准理论复原，待印刷本核对。）

**3)** 如果 y(x) 和 z(x) 是属千（属于）同一个本征值入（λ）的两个本征函数，那么它们仅相差一个常数因子 c，即

```latex
z(x) = c\,y(x). \tag{9.68b}
```

**4)** 与不同本征值 λ₁ 和 λ₂ 相伴的两个本征函数 y₁(x) 和 y₂(x) 具有权函数 (weight function) ϱ(x) 时是相互正交的 (orthogonal)

```latex
\int_{a}^{b} y_{1}(x)\, y_{2}(x)\, \varrho(x)\, \mathrm{d}x = 0. \tag{9.68c}
```

**5)** 如果在 (9.67a) 中系数 p(x) 和 q(x) 被 p̃(x) 和 q̃(x) 所代替，这里 p̃(x) ⩾ p(x)、q̃(x) ⩾ q(x)，则本征值不减，即 λ̃ₙ ⩾ λₙ（这[里] λ̃ₙ 和 λₙ 分别是改动后方程和原来方程的**第 [n] 个**本征值；转写脱「n」）。但是如果系数 ϱ(x) 被 ϱ̃(x) ⩾ ϱ(x) 所代替，则本征值不增，即 λ̃ₙ ⩽ λₙ．**第 [n] 个**本征值连续依赖千（于）方程诸系数，即诸系数的小变动将导致**第 [n] 个**本征值的小变动．（「第 个本征值」两处脱「n」。）

**6)** 区间 [a, b] 缩小为一个较小的区间并不导致本征值的减小．

## 复算：9.68c 的独立推导（Lagrange 恒等式）

设 y₁、y₂ 分别是本征值 λ₁ ≠ λ₂ 的本征函数（f = 0）。由两方程交叉相乘相减可得 Lagrange 恒等式

$$\big[p\,(y_1 y_2' - y_2 y_1')\big]_a^b = (\lambda_2 - \lambda_1)\int_a^b y_1 y_2\,\varrho\,\mathrm{d}x$$

分离齐次条件 (9.67b) 使边界项为零（若 B₀ ≠ 0，则 yᵢ′(a) = −(A₀/B₀)yᵢ(a)，代入组合式即消去；若 B₀ = 0 则 y₁(a) = y₂(a) = 0，同样消去；b 端同理），而 λ₂ − λ₁ ≠ 0，于是 ∫ₐᵇ y₁y₂ϱ dx = 0，与 (9.68c) 一致。

## 复算：与经典理论的一致性

- 性质 1–6 与经典正则 Sturm–Liouville 理论完全一致；手册为断言式陈述、无证明，属权威二手来源。
- 性质 5 中 p̃、q̃ 增大 ⇒ 本征值**不减**与 ϱ̃ 增大 ⇒ 本征值**不增**方向相反，不可混同（与 Rayleigh 商的标准结论一致）。
- 9.68b（单重性）依赖**分离**齐次条件；周期条件 (9.70) 下失效，见 [[concepts/周期边界条件]]。

## 适用边界

性质 1–6 仅属于有限区间、p 与 ϱ 一致为正、分离齐次线性边值条件的正则自伴问题；无穷区间情形原书自陈「结果有很大差异」（见文献 [9.5]）。
