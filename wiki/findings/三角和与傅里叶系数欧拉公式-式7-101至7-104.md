# 三角和与傅里叶系数欧拉公式（式 7.101–7.104）

## 主张（依源转录）

周期为 T 的周期函数 f(x) 可精确或近似地表示为三角和 s_n(x)（式 7.101），基频 ω = 2π/T（T = 2π 时 ω = 1）；从最佳近似（见 [[findings/最小均方误差与帕塞瓦尔方程-式7-105至7-106]]）的角度讲，系数 a_k、b_k（k = 0, 1, …, n）取傅里叶系数，由欧拉公式（式 7.102a/b）确定，也可由调和分析法近似确定（回指 19.6.4）。若 n → ∞ 时 s_n(x) → s(x)，则存在收敛的傅里叶级数（式 7.103a/b），振幅–相位关系为式 7.103c；复形式为式 7.104a/b。

```latex
% (7.101)
s_n(x) = a_0/2 + a_1 cos omega x + a_2 cos 2 omega x + ... + a_n cos n omega x
              + b_1 sin omega x + b_2 sin 2 omega x + ... + b_n sin n omega x

% (7.102a/b)
a_k = (2/T) Int_0^T f(x) cos k omega x dx = (2/T) Int_{x_0}^{x_0+T} f(x) cos k omega x dx
    = (2/T) Int_0^{T/2} [f(x) + f(-x)] cos k omega x dx
b_k = (2/T) Int_0^T f(x) sin k omega x dx = (2/T) Int_{x_0}^{x_0+T} f(x) sin k omega x dx
    = (2/T) Int_0^{T/2} [f(x) - f(-x)] sin k omega x dx

% (7.103a/b/c)
s(x) = a_0/2 + a_1 cos omega x + ... + a_n cos n omega x + ...
              + b_1 sin omega x + ... + b_n sin n omega x + ...
s(x) = a_0/2 + A_1 sin(omega x + phi_1) + ... + A_n sin(n omega x + phi_n) + ...
A_k = sqrt(a_k^2 + b_k^2),   tan phi_k = a_k/b_k

% (7.104a/b)
s(x) = Sum_{k=-inf}^{+inf} c_k e^{i k omega x}
c_k = (1/T) Int_0^T f(x) e^{-i k omega x} dx = { a_0/2, k=0;  (a_k - i b_k)/2, k>0;  (a_{-k} + i b_{-k})/2, k<0 }
```

## 复算（通过）

1. **欧拉公式第三形式（半区间形式）**：被积函数 f(x)cos kωx（或 sin）以 T 为周期（kωT = 2πk），故 ∫ 可取任意长度 T 的区间；取对称区间 [−T/2, T/2]，再把负半区间经 x → −u 并入 [0, T/2]：余弦（偶核）合并出 [f(x)+f(−x)]，正弦（奇核）合并出 [f(x)−f(−x)]。✅
2. **c_k 换算（式 7.104b）**：e^{−ikωx} = cos kωx − i sin kωx，与 a_k = (2/T)∫f cos、b_k = (2/T)∫f sin 对照：k > 0 时 c_k = ½a_k − i·½b_k；k = 0 时 c_0 = (1/T)∫f = a_0/2；k < 0 时 c_{−k} = ½a_k + i·½b_k。实值 f 时 c_{−k} = c̄_k。✅
3. **振幅–相位（式 7.103c）**：A_k sin(kωx + φ_k) = (A_k cos φ_k)sin kωx + (A_k sin φ_k)cos kωx，令 A_k cos φ_k = b_k、A_k sin φ_k = a_k，解得 A_k = √(a_k²+b_k²)、tan φ_k = a_k/b_k。✅
