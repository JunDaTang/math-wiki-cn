# 阿基米德螺线的机械生成与几何量（式 2.247）

手册 2.14.1 节以运动学生成定义[[concepts/阿基米德螺线]]，并给出弧长、面积、曲率半径的完整公式体系。

## 内容

**机械生成**：射线以固定角速度 ω 绕原点旋转，一个点同时从原点沿射线以匀速 v 移动，其轨迹即阿基米德螺线；由此 $a = v/\omega$ 具有速度比值的物理意义。

**方程与分支**：

$$
\rho = a | \varphi |, \quad a = \frac {v}{\omega} \quad (a > 0, - \infty < \varphi < \infty).\tag{2.247}
$$

曲线在关于 y 轴对称位置有两个分支（φ < 0 与 φ > 0）——此对称性断言与 $|\varphi|$ 记法的矛盾见 [[queries/式2-247与2-248取绝对值与y轴对称渐近线y等于a是否矛盾]]。

**射线等距**：每条射线与曲线交于 $O, A_1, A_2, \cdots$，相邻交点距离 $\overline{A_iA_{i+1}} = 2\pi a$。

**几何量**：

- 弧长 $L = \frac{a}{2}\left(\varphi\sqrt{\varphi^{2}+1} + \operatorname{Arsinh}\varphi\right)$，当 φ 很大时 $\frac{2L}{a\varphi^{2}} \to 1$；
- 面积（区域 $P_1OP_2$）$S = \frac{a^{2}}{6}(\varphi_{2}^{3} - \varphi_{1}^{3})$；
- 曲率半径 $r = a\frac{(\varphi^{2}+1)^{3/2}}{\varphi^{2}+2}$，原点处 $r_{0} = \frac{a}{2}$。

## 核验

以上 L、S、r、r₀ 各式均经极坐标通用公式（$L = \int\sqrt{\rho^{2}+\rho'^{2}}\,\mathrm{d}\varphi$、$S = \frac{1}{2}\int\rho^{2}\,\mathrm{d}\varphi$ 及极坐标曲率公式）独立推导复核，全部成立。此处 replicated 指该独立推导复核，而非独立第三方来源的再现。

## 限定与注记

- 「每条射线交点等距 2πa」严格成立于单一分支；两支并存时，同一射线上的交点交错排列，相邻间距不再恒为 2πa；
- 弧长公式中的 $\operatorname{Arsinh}\varphi$ 是 [[concepts/面积正弦]]（2.10 节 [[concepts/面积函数]]）在后续章节的实质应用。
