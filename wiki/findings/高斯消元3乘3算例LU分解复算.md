# 高斯消元3乘3算例LU分解复算

**发现**：19.2.1.1 以增广矩阵形式演示的 3×3 高斯消元算例，其 P、L、R 分解与解向量经独立复算**全部正确**。

算例数据（按原样转录）：

```
A = [[3, 1, 6],
     [2, 1, 3],
     [1, 1, 1]],   b = (2, 7, 4)ᵀ

P = [[1, 0, 0],
     [0, 0, 1],
     [0, 1, 0]]

L = [[1,    0,   0],
     [1/3,  1,   0],
     [2/3,  1/2, 1]]

R = [[3,  1,    6],
     [0,  2/3, -1],
     [0,  0,   -1/2]]

解：x₁ = 19, x₂ = −7, x₃ = −8
```

**复算验证（直接证据）**：

1. LR 逐行乘回恰为 PA=[[3,1,6],[1,1,1],[2,1,3]]（如第 2 行 (1/3)·(3,1,6)+1·(0,2/3,−1)=(1,1,1)）；
2. 向后代换链：Lc=Pb 得 c=(2,10/3,4)ᵀ，再解 Rx=c 回代得 (19,−7,−8)；
3. 代入原方程验算：3·19−7+6·(−8)=2；2·19−7+3·(−8)=7；19−7−8=4，均与 b 吻合。

**转写自洽性（推断性解读，内证一致）**：消元中间矩阵第一列的 2/3、1/3 为消元乘数 l₂₁、l₃₁ 就地存储的占位显示，与第二步 l₃₂=1/2 一致；主元（3、2/3、−1/2）在原书增广矩阵中以方框标示，列主元策略与（19.33）相符（第二步 |2/3|>|1/3| 故交换第 2、3 行）。

**结论**：本算例是本源数学内容正确性的最强实证之一，可作为 [[methodology/高斯消元与LU三步求解流程]] 的标准验证用例。
