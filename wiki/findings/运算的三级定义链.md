# 运算的三级定义链

《数学手册(原书第10版)》5.3.1 节以递进结构定义「运算」：**代数结构（在其上定义了运算的集合）→ n 元运算 → 二元运算 → 外运算**。各级映射签名（含转写复原）如下：

| 层级 | 映射签名 | 原文说明 |
|---|---|---|
| [[concepts/n元运算]] | φ: Aⁿ → A | 对 A 的元素的每个 n 元组指派 A 的一个元素 |
| [[concepts/二元运算]] | *: A × A → A | n = 2 的特例，「特别重要」；本章多用中缀记号 a * b 代替 *(a, b) |
| [[concepts/外运算]] | K × A → A | K 为「外部的」「多数是已经构造的」集合；展开见 5.3.8（前向引用） |

- 原文列举的二元运算实例：数或矩阵的加法和乘法、集合的并和交。
- 二元运算之上再定义三条性质（[[concepts/结合律]]、[[concepts/交换律]]、[[concepts/中性元素]]，式 5.80–5.82），另见 [[findings/二元运算三性质公式]]。

## 证据说明

定义链为直接证据（原文明文陈述，仅含转写复原）；内容为标准抽象代数定义，与通行文献一致，可独立验证。属定义性内容而非计算结果，无复算验证之需（replicated: null）。

## 转写注记

- 小节标题「l. 元运算」应为「1. n 元运算」（n 脱落）。
- 「$\varphi : A^{n} A$」应为 φ: Aⁿ → A（箭头脱落）。
- 外运算定义中「到 A」疑脱落。
