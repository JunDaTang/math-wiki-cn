# 旋转矩阵的 Slerp 插值公式（式 4.151）

**发现**：《数学手册（原书第10版）》4.4.3.2 把 Slerp 完全类似地移植到旋转矩阵：对旋转矩阵 R₀, R₁（[[entities/SO3]] 的元素），以 SO(3) 元素的对数（满足 e^r = R 的斜对称矩阵）定义插值。

## 公式（照录）

```latex
R(t) = R₀ (R₀⁻¹ R₁)^t = R₀ exp( t log(R₀⁻¹ R₁) )                           (4.151)
```

## 书中评注及其适用边界

书中评注：「一般地说，应用四元数基本算法并且依据单位四元数转换为旋转矩阵的计算，由四元数 q(t) 确定 R(t) 要简单些。」

**归属边界**：该评注只针对**插值的实现路径**（先做四元数插值再转矩阵 vs 直接矩阵插值），不可转用于 4.4.3.4 卫星导航——在那里矩阵（K(a⃗)、极分解）是推导工具而非与四元数竞争的实现方案。

## 复核状态

公式为 (4.144) 的矩阵类比（p ↔ R₀，p̄q ↔ R₀⁻¹R₁），结构上由已复核的四元数情形支持；书中未给复杂度或精度比较，分析者亦未独立复核矩阵对数的分支性质。另注意本节正文把 so(3) 误称为「李群」（实为李代数），见 [[entities/SO3]]。
