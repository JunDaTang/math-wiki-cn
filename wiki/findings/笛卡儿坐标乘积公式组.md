# 笛卡儿坐标乘积公式组（式 3.263–3.266）

设 $\vec a=\{a_x,a_y,a_z\}$、$\vec b=\{b_x,b_y,b_z\}$、$\vec c=\{c_x,c_y,c_z\}$（3.263），则：

- **标量积**（3.264）：$\vec a\vec b=a_xb_x+a_yb_y+a_zb_z$；
- **向量积**（3.265）：$\vec a\times\vec b=(a_yb_z-a_zb_y)\vec i+(a_zb_x-a_xb_z)\vec j+(a_xb_y-a_yb_x)\vec k=\begin{vmatrix}\vec i&\vec j&\vec k\\ a_x&a_y&a_z\\ b_x&b_y&b_z\end{vmatrix}$；
- **混合积**（3.266）：$\vec a\vec b\vec c=\begin{vmatrix}a_x&a_y&a_z\\ b_x&b_y&b_z\\ c_x&c_y&c_z\end{vmatrix}$。

**观察**：
- 三个公式的复杂度阶梯（内积 = 三项和；叉积 = 三个 2×2 子行列式；混合积 = 3×3 行列式）与几何量维度阶梯（长度与角 → 面积 → 体积）对应，在表 3.18 中被直接用于几何应用（见 [[findings/向量代数几何应用公式]]）；
- 混合积的 3×3 行列式与 [[findings/四面体行列式体积公式]]（3.3 节式 3.133）同构：两者都以坐标行列式表达体积，形成「综合几何 vs 向量方法」的对照——向量方法把几何量归结为代数对象的多线性函数；
- 本组公式是仿射公式组（3.273/3.275/3.276）的退化特例，见 [[findings/仿射坐标乘积公式与互反基]] 与 [[comparisons/笛卡儿坐标与仿射坐标比较]]。
