# 式 9.93 棒纵向振动（非齐次 Neumann 边界）转录复算

## 逐字转录（关键式）

```
u_tt = a²u_xx                                                       (9.93a)
u|_{t=0} = f(x)，u_t|_{t=0} = φ(x)                                  (9.93b)
u_x|_{x=0} = 0（自由端），u_x|_{x=l} = kp                            (9.93c/d)
z_x|_{x=0} = z_x|_{x=l} = 0                                         (9.93e)
z = u − kpx²/(2l)                                                   (9.93f)
z_tt = a²z_xx + a²kp/l                                              (9.93g)
z|_{t=0} = f(x) − kpx²/2 [sic!]，z_t|_{t=0} = φ(x)                   (9.93h)
w = ka²pt²/(2l)
X″/X = T″/(a²T) = −λ²                                               (9.93j)
X_n = cos(nπx/l)，λ_n² = n²π²/l² (n = 0,1,2,…)                       (9.93k/l，转写式号 9.931)
u = ka²pt²/(2l) + kpx²/(2l) + a₀ + (aπ/l)b₀t
  + Σ_{n≥1}(a_n cos(anπt/l) + (b_n/n) sin(anπt/l))cos(nπx/l)        (9.93m)
```

（9.93m 系数说明：a_n 与 b_n 分别是 f(x) − kpx²/2 [sic!] 与 (l/(aπ))φ(x) 在 (0, l) 上傅里叶余弦级数的系数。）

## 复算核验

1. **齐次化代换**：z = u − kpx²/(2l) ⇒ z_x = u_x − kpx/l，在 x = 0 与 x = l 处分别为 0 与 kp − kp = 0，边界条件齐次化 ✓；z_xx = u_xx − kp/l 代入 (9.93a) 得 (9.93g) ✓。此为 [[非齐次边值问题齐次化代换]] 的 PDE 实例。
2. **特解 w**：w = ka²pt²/(2l) 满足 w_tt = ka²p/l = a²·0 + a²kp/l（w_xx = 0）✓。
3. **余弦级数与 n = 0 项**：在“b_n 为 (l/(aπ))φ(x) 的余弦系数”的约定下：n ≥ 1 时 T′(0) = (b_n/n)(anπ/l) = b_n·aπ/l = (2/l)∫φ cos，恰为 φ 的余弦系数 ✓；n = 0 时 T″ = 0 给 T = a₀ + βt，β = b₀·(aπ/l) = (1/l)∫φ dx ✓。9.93m 的 (aπ/l)b₀t 项与 bₙ/n 因子核验**自洽** ✓。

## 异常（重要）

9.93h 与 9.93m 的系数说明两处写作 `f(x) − kpx²/2`，与 9.93f 的 `kpx²/(2l)` 不一致：按 9.93f 初始条件应为 f(x) − kpx²/(2l)，且 `kpx²/2` 量纲不符。两处同错，疑原书误或转写系统性脱漏“/l”，见 [[queries/式9-93h系数说明是否漏除以l]]。

## 结论

除 /l 问题外复算通过；解结构（齐次化 + 特解 + 本征展开）与 [[叠加原理与分解定理]] 一致。
