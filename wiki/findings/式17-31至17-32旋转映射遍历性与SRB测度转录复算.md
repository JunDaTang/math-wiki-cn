# 式 17.31–17.32 旋转映射遍历性与 SRB 测度转录复算

本条目记录数学手册 17.2.1.2 中圆周旋转映射 (17.31) 与 SRB 测度 (17.32a/b) 的转录与独立复算，并记录本源唯一一处**实质数学讹误**。

## 转录

```latex
x_{t+1} = x_t + Phi (mod 2 pi),  t = 0, 1, ...                   % (17.31)
lim_{n->+infty} (1/n) sum_{i=0}^{n-1} h(phi^{i}(x_0)) = int_M h d mu   % (17.32a，源文衍 "d t")
mu_n := (1/n) sum_{i=0}^{n-1} delta_{phi^{i}(x)}                 % (17.32b)
```

## 复算验证

1. **$\lambda/2\pi$ 不变性**：旋转保持弧长，勒贝格测度不变。✓
2. **无理旋转遍历**：$\Phi/2\pi$ 无理时轨道在圆周上一致分布，不变可测集测度非 0 即满——遍历论标准结论。✓
3. **「是混合的」断言——被复算否定**：旋转为等距映射，取小弧段 $A$ 可见 $\mu(A\cap\varphi^{-t}(A))$ 随 $t$ 振荡而不收敛于 $\mu(A)^2$；等价地[[concepts/自相关函数|相关函数]]不衰减。**旋转绝不混合**，且该断言与本节「$C_h$ 指数衰减 ⟹ 混合」判据自相矛盾。判定：源文「是混合的」脱「**不**」字（[[queries/旋转映射是混合的疑脱不字之辨]]，最高优先）。
4. **SRB 判据 (17.32a/b)**：时间平均收敛于 $\int h\,\mathrm{d}\mu$ 的初值集具正勒贝格测度；经验测度 $\mu_n$ 弱收敛。两种刻画互为补充，表述为标准结果。✓
5. **埃农吸引子 SRB 存在性**：手册转述「已被证明」，未给出处（引 [17.6] 仅用于命名），证据强度：中，未独立复算。

## 转写差异

- 遍历判据句重复：「如果 Φ/2π 为无理数，则…遍历的；如果 Φ/2π 为无理数，则…遍历的」，前句疑为「**有理数**…**不是**遍历的」（[[queries/旋转遍历句重复且有理情形脱文之辨]]）。
- 两处回指「(17.3)」疑为「(17.31)」（同段开头对离散系统 (17.3) 的回指则正确，指向 17.1.1）。
- (17.32a) 衍「d t」。

## 结论

除「旋转是混合的」这一脱字讹误外，本区间论断均成立；SRB 概念刻画标准、正确。相关流程见 [[methodology/经验测度判别SRB流程]]。
