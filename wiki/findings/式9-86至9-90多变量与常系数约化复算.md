# 式 9.86–9.90 多变量分类与常系数约化转录复算

## 逐字转录

```
Σ_{i,k} a_ik ∂²u/∂x_i∂x_k + … = 0                       (9.86)
Σ_i κ_i ∂²u/∂x_i² + … = 0，κ_i ∈ {−1, 0, +1}            (9.87)
u = v exp(−½ Σ_k (b_k/κ_k) x_k)   （对 κ_k ≠ 0 求和）    (9.88)
椭圆型：Δv + kv = g                                       (9.89)
双曲型：∂²v/∂t² − Δv + kv = g                             (9.90)
```

分类（常系数）：所有 κᵢ 非零同号 → 椭圆型；恰一个与其他异号 → 双曲型；两种符号各至少出现两次 → 超双曲型（ultra-hyperbolic）；恰一个 κᵢ = 0 且其余同号 → 抛物型。n ≥ 3 的变系数方程一般不能化为单一典范形式，但存在类似分类（手册回指文献 [9.5]，未入库）。Δ 为拉普拉斯算子（回指 13.2.6.5，未入库）。

## 复算核验

消一阶导代换 (9.88) 的机制用单变量模型核验：κv″ + bv′ = 0 中作代换（取 v = u·e^{−bx/(2κ)} 方向）得 v″ − (b²/4κ²)v = 0，一阶导项确被消去 ✓。由此 (9.87) 经 (9.88) 化为 (9.89)/(9.90) 的结构合理；椭圆/双曲简单形式中 k 由零阶项与系数组合决定。

## 结论

复算通过。转写讹误：9.87 后“诸系数 κ_i 是 ±1 0”应为“±1 或 0”；“必须区别儿个特别的情形”应为“几个”（见 [[queries/9-2-2全节系统性转写讹误清单]]）。超双曲型与混合型作为分类特款并入 [[二阶偏微分方程的分类]]。
