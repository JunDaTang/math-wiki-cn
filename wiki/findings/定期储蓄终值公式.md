# 定期储蓄终值公式（式 1.78–1.80）

《数学手册(原书第10版)》1.3.2.2 给出定期储蓄（相等时间间隔内存入相同数量资金 $E$，投资周期等于利息支付周期，可在周期开始或结尾储蓄）的余额公式，$q = 1+\frac{p}{100}$：

```latex
K_n = Eq\,\frac{q^n - 1}{q - 1} \tag{1.78a}
K_n = E\,\frac{q^n - 1}{q - 1} \tag{1.78b}
K_1 = E\left[m + \frac{(m+1)p}{200}\right] \tag{1.79a}
K_1 = E\left[m + \frac{(m-1)p}{200}\right] \tag{1.79b}
K_n = E\left[m + \frac{(m+1)p}{200}\right]\frac{q^n - 1}{q - 1} \tag{1.80a}
K_n = E\left[m + \frac{(m-1)p}{200}\right]\frac{q^n - 1}{q - 1} \tag{1.80b}
```

- (1.78a)/(1.78b)：期初/期末储蓄在第 $n$ 个利息周期末的余额——[[concepts/等比级数]] 部分和 $\frac{q^n-1}{q-1}$ 的直接套用，期初储蓄多乘一个 $q$。
- (1.79a)/(1.79b)：一年（或一个利息周期）分成 $m$ 个等周期、每期储蓄 $E$、年末计算利息后的一年余额；因子 $\left[m+\frac{(m\pm1)p}{200}\right]$ 来自年内比例单利（每子周期利息 $E\frac{p}{100m}$）的结构。
- (1.80a)/(1.80b)：$n$ 年后的余额——第 2 年起整个 $K_1$ 产生复利，故为 (1.79) 与 (1.78) 的乘积组合，即“年内单利、年度间复利”的混合结构。

## 手册数值例子（导入时独立复核吻合）

储户以 $p = 5.2\%$ 的年利率每月末储蓄 €1000，问多少年后可增至 €500000？根据 (1.80b)：

$$500000 = 1000\left(12 + \frac{11\cdot 5.2}{200}\right)\cdot\frac{1.052^n - 1}{0.052} \;\Rightarrow\; n = 22.42\ \text{年}.$$

## 证据说明

直接证据：手册原文。公式结构自洽（(1.80) 为 (1.79) 与 (1.78) 的组合），数值例子经导入时独立算术复核吻合。确定性推导，非经验性结果。式 (1.80b) 取 $E=a$ 后成为还款公式 (1.82) 的第二项，见 [[findings/等额本金还款与等额年金公式]]。
