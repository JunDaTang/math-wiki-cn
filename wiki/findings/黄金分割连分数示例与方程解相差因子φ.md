# 黄金分割连分数示例与方程解相差因子 φ（勘误候选）

《数学手册(原书第10版)》1.1.1 节内部存在数值矛盾（勘误候选）：

- **1.1.1.2**：黄金分割 x/a = (a−x)/x（a = 1）导出方程 x² + x − 1 = 0，解 **x = (√5−1)/2 ≈ 0.618**。
- **1.1.1.4 例 B**：称“黄金分割公式 x/a = (a−x)/x”可由 **x = a[1;1,1,…] = (a/2)(1+√5) ≈ 1.618a** 表示。

两值互为倒数，**相差因子 φ**。例 B 的数值自身是自洽的：[1;1,1,…] = φ、[2;4,4,…] = √5、α₄ = 8/5 对 φ 的误差 0.018a 均正确（已独立复核）；矛盾仅在于这些数值与所引公式的解不符——疑将“整段”与“大段”的角色调换，或为原书/译文之误。

**记录原则**：两个数值不可混同记录。**裁决关键**：3.5.2.3（第 260 页）黄金分割的正式定义，待该章编目后回填（见 [[queries/黄金分割连分数示例取值矛盾]]）。本条与既有勘误工作流衔接：[[findings/译者订正有理式节三处原文错误]] 表明本手册存在译者订正原文错误的先例。
