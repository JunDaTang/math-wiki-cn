# 一致收敛级数的逐项积分与逐项微分（式 7.82a–b，含条件张力）

手册 7.3.2.2 第 2 条：在区域 [a,b] 上一致收敛的级数在该区域上逐项可积，「同样」逐项可微，即

```latex
\int_{x_0}^{x} \sum_{n=1}^{\infty} f_n(t)\,\mathrm{d}t = \sum_{n=1}^{\infty} \int_{x_0}^{x} f_n(t)\,\mathrm{d}t,\quad x_0,x\in[a,b]   % (7.82a)
\left(\sum_{n=1}^{\infty} f_n(x)\right)' = \sum_{n=1}^{\infty} f_n'(x),\quad x\in[a,b]                                                 % (7.82b)
```

同页第 1 条（连续性）：各项连续 + 一致收敛 ⇒ 和 S(x) 连续；非一致收敛时和可能不连续。手册以 [[式7-80非一致收敛算例与和函数不连续]]（和在 x = 0 不连续）为反例、[[式7-79ex级数有界区间一致收敛算例]]（和为 e^x，连续）为正例。

## ⚠ 条件张力（本源最重要的数学性问题）

按本转写，式 7.82b 的前提仅有「原级数在 [a,b] 上一致收敛」，这在数学上不足：

- 标准定理要求 (i) 各项可微；(ii) 导数级数 Σf_n′ 在 [a,b] 上一致收敛；(iii) 原级数至少在一点收敛。此时和可微且 (Σf_n)′ = Σf_n′。
- 仅原级数一致收敛不能保证和可微（例如可用光滑各项构造一致收敛而和不可微的级数）。

这可能是原书的简化表述或转写脱漏假设，须对照原书核查，追踪见 [[式7-82b逐项可微条件是否脱漏]]。式 7.82a（逐项积分）的条件（一致收敛 + 各项可积）则是标准且正确的。

## 判读

- 式 7.82b 单独标记为 medium 置信度；式 7.82a 与连续性定理为高置信度标准结果。
- 对幂级数的推论（收敛区间内部可逐项微分）不受此转写问题影响，因其可由导数级数的收敛半径不变性独立保证。
