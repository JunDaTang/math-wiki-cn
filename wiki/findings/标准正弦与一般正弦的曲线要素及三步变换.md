# 标准正弦与一般正弦的曲线要素及三步变换（式 2.63–2.64）

## 手册主张

标准正弦函数

$$y = \sin x \tag{2.63}$$

是周期 $T = 2\pi$ 的连续曲线：

- 与 x 轴交点 $B_k = (k\pi, 0)$（k = 0, ±1, ±2, …），均为拐点，切线关于 x 轴的倾斜角为 $\pm\frac{\pi}{4}$；
- 极值点 $C_k = \left(\left(k+\frac{1}{2}\right)\pi,\ (-1)^k\right)$；
- 对任意函数值 y 有 $-1 \leqslant y \leqslant 1$。

一般正弦函数

$$y = A\sin(\omega x + \varphi_0) \tag{2.64}$$

振幅为 $|A|$、频率为 ω（口径见 [[queries/ω称频率与角频率口径不一]]）、$\varphi_0$ 为相位移，可由标准正弦经三步变换得到：

1. 沿 y 轴方向拉伸 $|A|$ 倍；
2. 沿 x 轴方向压缩 $\frac{1}{\omega}$ 倍；
3. 向左平移 $\frac{\varphi_0}{\omega}$ 个单位。

由此周期 $T = \frac{2\pi}{\omega}$，与 x 轴交点 $B_k = \left(\frac{k\pi-\varphi_0}{\omega},\ 0\right)$，极值点 $C_k = \left(\frac{(k+\frac{1}{2})\pi-\varphi_0}{\omega},\ (-1)^k A\right)$。

## 独立验证

特征点坐标直接核验：$\sin(k\pi) = 0$、$\sin'(k\pi) = \cos(k\pi) = \pm 1$（斜率 ±1，倾斜角 ±π/4）、$\sin''(k\pi) = 0$（拐点）；极值处 $|\sin| = 1$。一般式的特征点由代换 $X = \omega x + \varphi_0$ 还原为标准情形；三步变换的复合与式 2.64 逐项一致。验证通过。
