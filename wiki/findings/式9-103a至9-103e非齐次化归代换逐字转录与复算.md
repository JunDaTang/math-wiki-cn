# 式 9.103a–e 非齐次化归代换逐字转录与复算

本 finding 记录 9.2.3.1.3 非齐次化归公式组（式 9.103a–e）的逐字转录与独立复算结论。公式组全文见 [[非齐次线性偏微分方程的齐次化与杜哈梅尔型代换]] 与源页。

## 逐字转录

```latex
(9.103a)  \frac{\partial^{2} u}{\partial t^{2}} - L[u] = g(x, t)
(9.103b)  u\big|_{t=0} = 0, \quad \left.\frac{\partial u}{\partial t}\right|_{t=0} = 0
(9.103c)  u = \int_{0}^{t} \varphi(x, t; \tau)\, \mathrm{d}\tau
(9.103d)  \frac{\partial^{2} u}{\partial t^{2}} - L[u] = 0
(9.103e)  u\big|_{t=\tau} = 0, \quad \left.\frac{\partial u}{\partial t}\right|_{t=\tau} = g(x, \tau)
```

条件说明（OCR 丢符处以〔〕补注）：在这个方程中，〔x〕符号地表示〔n〕维问题的所有〔n〕个变量 x₁, x₂, ⋯, xₙ；L[u] 表示一个线性微分表达式，它也许包含导数 ∂u/∂t 但是不包含关于〔t〕的高阶导数。

## 复算结论（直接证据为独立推导，非源文内容）

- 对式 9.103c 作代换 u = ∫₀ᵗ φ(x, t; τ)dτ 并对上限求导：u_t = φ(x, t; t) + ∫₀ᵗ φ_t dτ，由 (9.103e) 的 u|_{t=τ} = 0 知第一项为零；再求一次导并利用 φ_t|_{t=τ} = g(x, τ)，可验证 (9.103a) 与 (9.103b) 成立。代换经上下限求导验证成立。
- **“L[u] 不含关于 t 的高阶导数”的限制恰为必要条件**：若 L 含 u_tt 以外的 t 高阶导数（或一般地对上限求导产生的附加项结构），其附加项无法被式 9.103e 的两项条件吸收。源未作此论证，此为复算所得。

## 转写缺损

“在这个方程中， 符号地表示 维问题的所有 个变量”中 x、n 两符号被 OCR 整体丢弃；“不包含关千 的高阶导数”中“于”讹为“千”、t 被丢（见 [[9-2-3全节系统性转写讹误清单]]）。
