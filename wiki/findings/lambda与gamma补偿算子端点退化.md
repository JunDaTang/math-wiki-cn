# λ 与 γ 补偿算子的端点退化方向相反

《数学手册(原书第10版)》5.9.2.3 给出两个 [[concepts/补偿算子]]，其端点退化方向**相反**，是易混点。

## 直接证据（式 5.353–5.356 照录）

```text
μ_{AλB}(x) = λ[μ_Aμ_B] + (1−λ)[μ_A+μ_B−μ_Aμ_B]，λ∈[0,1]                (5.353)
μ_{AγB}(x) = [μ_Aμ_B]^{1−γ}·[1−(1−μ_A)(1−μ_B)]^γ，γ∈[0,1]              (5.354)
μ(x) = [∏_{i=1}^n μ_i(x)]^{1−γ}·[1−∏_{i=1}^n(1−μ_i(x))]^γ              (5.355)
μ(x) = [∏_{i=1}^n μ_i(x)^{δ_i}]^{1−γ}·[1−∏_{i=1}^n(1−μ_i(x))^{δ_i}]^γ，
       Σ_{i=1}^n δ_i = 1，γ∈[0,1]                                      (5.356)
```

## 端点退化（代入复算确认）

| 算子 | 参数取 0 | 参数取 1 |
|---|---|---|
| λ 算子（式 5.353） | λ=0 → 代数和（OR 侧） | λ=1 → 代数积（AND 侧） |
| γ 算子（式 5.354） | γ=0 → 代数积（AND 侧） | γ=1 → 代数和（OR 侧） |

即 λ 随参数增大趋向 AND、γ 随参数增大趋向 OR，方向相反。源文自身的表述与此一致（λ 算子：一情形「产生称作代数和的形式……属于 OR 算子」、另一情形「产生称作代数积的形式……属于 AND 算子」；γ 算子：「，=1 产生代数和表达式」「γ=0 产生代数积表达式」）。

## 转写复原（推断）

源文 λ 算子两处「情形入＝」的 λ 值在转写中脱落；由式 5.353 代入 λ=0、λ=1 即可复原上表（λ=0 对应代数和、λ=1 对应代数积）。γ 的两处端点值保留（其一讹作「，=1」）。
