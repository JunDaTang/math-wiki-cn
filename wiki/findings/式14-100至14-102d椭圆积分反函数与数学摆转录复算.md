# 式 14.100–14.102d 椭圆积分反函数与数学摆转录复算

对 14.6.1 各式逐条转录并复算（来源：[[10-数学手册原书第10版--8-146-椭圆函数--3vhx9i]]）。

## 复算结果

| 式号 | 内容 | 结论 |
|---|---|---|
| (14.100) | ∫₀ᵘ(1−t²)^{−1/2}dt = x（|u| ≤ 1） | 正确，积分值即 arcsin u |
| (14.101) | u = sin x ⟺ x = arcsin u（主值区间） | 正确 |
| (14.102a) | 摆方程 ϑ̈ + (g/l) sin ϑ = 0 及等价的一阶积分形式 | 正确；由切向力平衡 −mg sin ϑ = mlϑ̈ 直接可得 |
| (14.102b) | t − t₀ = √(l/g)∫₀^ϑ dΘ/√(2(cos Θ − cos ϑ₀)) | 复算一致：以初条件积分 (ϑ̇)² = (2g/l)(cos ϑ − cos ϑ₀) 即得 |
| (14.102c) | 代换 sin(Θ/2) = k sin ψ、k = sin(ϑ₀/2) 后 t − t₀ = √(l/g)F(k, φ) | 复算一致（cos Θ − cos ϑ₀ = 2k²cos²ψ 与 dΘ = 2k cos ψ dψ/√(1−k²sin²ψ) 恰好约去）；源文代换式中 θ 疑为 Θ 之误 |
| (14.102d) | T = √(l/g)K 及周期诸断言 | 公式本身成立，但周期断言系数不自洽（见下） |

## (14.102d) 周期断言的不自洽（直接证据：k→0 极限复算）

源文四个断言：(i) T = √(l/g)·K；(ii) ϑ(t) 是周期为 2T 的周期函数；(iii) T 为两个相继极端位置（dϑ/dt = 0）之间的时间；(iv) 小振幅时 T = 2π√(l/g)。

k→0 时 K→π/2，且由 (14.102c)，从最低点到极端位置历时 √(l/g)K。故数学事实为：

- 全程周期 = 4√(l/g)K → 2π√(l/g)（与小振幅谐振周期一致）；
- 两相继极端位置之间的时间 = 2√(l/g)K（半周期）。

若 T = √(l/g)K，则断言 (ii)(iii)(iv) 分别差因子 2、2、4，四断言不能同真。推断（非直接证据）：转录或原文缺系数——或“周期为 2T”应为“4T”，或 T 的表达式应为 2√(l/g)K。详见 [[式14-102d摆周期系数2T与4T之辨]]。

## 组织性思想

本小节以 arcsin ↔ sin 类比确立“椭圆函数 = 椭圆积分之逆”，该思想贯穿 [[椭圆积分]] → [[振幅函数]] → [[雅可比函数]] 的定义链，并与 [[魏尔斯特拉斯函数|℘ 作为 (14.119) 之逆]] 平行（参见 [[椭圆函数与三角函数比较]]）。
