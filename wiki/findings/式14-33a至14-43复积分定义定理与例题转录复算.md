# 式 14.33a–14.43 复积分定义、定理与例题转录复算

对《数学手册(原书第10版)》14.2 节全部编号公式（14.33a–14.43）逐字转录，并对三道例题从参数化出发独立重算。**结论：数学内容全部复算通过；所有表面数学错误均为转写损坏所致，复原后数值正确。** 证据强度：高。

## 例题独立复算

### 例 1：圆周上 (z − z₀)^n 的积分（14.2.1.2 第 3 条）

求 $I = \int_{(C)} (z-z_0)^n\,\mathrm{d}z$（$n\in\mathbb{Z}$），C 为半径 $r_0$、圆心 $z_0$ 的圆周（逆时针）。独立重算：

1. 参数化 $z = z_0 + r_0(\cos t + \mathrm{i}\sin t)$，$0\leqslant t\leqslant 2\pi$，故 $\mathrm{d}z = r_0(-\sin t + \mathrm{i}\cos t)\,\mathrm{d}t$。
2. 代入并用棣莫弗（de Moivre）公式化简幂：$I = r_0^{n+1}\int_0^{2\pi}(\cos nt + \mathrm{i}\sin nt)(-\sin t + \mathrm{i}\cos t)\,\mathrm{d}t$。
3. 乘开：$(\cos nt + \mathrm{i}\sin nt)(-\sin t + \mathrm{i}\cos t) = \mathrm{i}\cos[(n+1)t] - \sin[(n+1)t]$——复算无误。
4. 逐项积分：$n\neq-1$ 时两项三角积分均为零；$n=-1$ 时被积式恒为 $\mathrm{i}$，积分值为 $2\pi\mathrm{i}$。

结果 $I = 0$（$n\neq-1$）；$2\pi\mathrm{i}$（$n=-1$）。**与原文一致，复算通过。**

### 例 2：f(z) = 1/(z − a)（14.2.1.2.5）

C 为以逆时针方向围绕 $a$ 的闭曲线（图 14.34）：

$$(C)\oint \frac{1}{z-a}\,\mathrm{d}z = 2\pi\mathrm{i}\,\operatorname{Res} f(z)\big|_{z=a} = 2\pi\mathrm{i}$$

数值复算通过（由例 1 的 $n=-1$ 情形直接得出）。**但转写文本丢失分式分子**（「(C)∮ z − a ~ dz」），复原讨论见 [[queries/例题1z-a分式分子丢失]]；Res 记号在本节未定义即使用（定义在 14.3.5.5，未入库）。

### 例 3：∮_C (z−1)/(z(z+1)) dz（14.2.2.2）

C 为包含原点与 $z=-1$ 的简单闭曲线；$C_1$、$C_2$ 为分别以 $0$、$-1$ 为心、半径 $1/2$ 的圆周。独立重算：

1. 部分分式：$\frac{z-1}{z(z+1)} = -\frac{1}{z} + \frac{2}{z+1}$——复算无误（$A=-1,\ B=2$ 满足 $A(z+1)+Bz = z-1$）。
2. 由 (14.41)：$\oint_C = \oint_{C_1}\frac{2\,\mathrm{d}z}{z+1} + \oint_{C_2}\frac{2\,\mathrm{d}z}{z+1} - \oint_{C_1}\frac{\mathrm{d}z}{z} - \oint_{C_2}\frac{\mathrm{d}z}{z}$。
3. 逐圆求值：$0 + 4\pi\mathrm{i} - 2\pi\mathrm{i} - 0 = 2\pi\mathrm{i}$。

**与原文一致，复算通过**；且与 14.2.1.2 第 3 条例中的积分相互印证（原文注明「与第 975 14.2.1.2, 3. 例中的积分比较」）。

## 原书表述注意事项（非转写讹误）

- **正则性条件被省略**：路径无关的充要条件被表述为「函数满足柯西—黎曼微分方程」，忽略正则性条件（仅 C-R 方程不足以保证解析性）。应记为 caveat，使用时补充偏导数连续等前提。
- **「包含」疑为「蕴含」**：「可微性并不包含反复的可微性」中「包含」应为「蕴含」的生硬翻译。
- **教学顺序冗余**：(14.34) 复不定积分的定义以「路径无关」为前提，而路径无关直到 14.2.2 才建立（正文两处前向回指「参见第 976 14.2.2」）；(14.39) 在 14.2.1.2.5 先行陈述、14.2.2.1 以 (14.40) 正式重述。均为手册式编排，非错误。
