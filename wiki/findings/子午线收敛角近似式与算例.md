# 子午线收敛角近似式 γ ≈ (y/R)tan φ 及算例（数值已验证）

## 直接证据（源文推导链）

在 [[entities/高斯—克吕格坐标系]] 中求 [[concepts/子午线收敛角]] γ：在 c = 90°−φ、b = η、α = 90°−γ 的 [[concepts/直角球面三角形]] QPN 中，[[concepts/纳皮尔法则]] 给出

```
cos α = tan b/tan c
⟹ cos(90°−γ) = tan η/tan(90°−φ)
⟹ sin γ = tan η·tan φ
```

因 η 极小（源文「计砌」为 η 的 OCR 讹误），sin γ ≈ γ、tan η ≈ η；对很小的距离 η，圆柱体图的长度偏差也非常小，故可替换 η = y/R（y 为 P 的纵坐标，R 为球半径）：

```
γ = η·tan φ = (y/R)·tan φ
算例：φ = 50°, y = 100 km ⇒ γ = 0.018706 rad = 1°04′19″
```

## 独立复算验证（本 wiki 分析）

取 R ≈ 6371 km：η = y/R = 0.015697 rad，γ = 0.015697 × tan 50° = 0.015697 × 1.19175 ≈ 0.018706 rad；换算为角度 0.018706 × 180°/π ≈ 1.0719° = 1°04′19″。与源文算例吻合。

## 说明

- 该段落在源中位于纳皮尔例 A、B 之后，以「：」开头、无标签无编号，疑为原书「应用」例框（相当于例 C）脱标，见 [[queries/高斯—克吕格段落是否为脱标应用例]]。
- 推导是三步近似的链条（sin γ ≈ γ、tan η ≈ η、η = y/R），属小量线性化；源文未给出适用范围（η 的小量界），使用时应注意其为近似式。
