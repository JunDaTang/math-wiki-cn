# 380 第三支指数 n-1 疑为 n-2 复算

条目 380 为 ∫sinⁿax dx/cosᵐax 的三支递推。第一、二支复算无误；第三支转写原文：

```latex
= \frac{\sin^{n-1} ax}{a(m-1)\cos^{m-1} ax} - \frac{n-1}{m-1}\int\frac{\sin^{n-1} ax\,dx}{\cos^{m-2} ax} \quad (m\neq 1)
```

## 复算

对边界项 p = sin^{n−1}x/cos^{m−1}x 求导：p′ = (n−1)·sin^{n−2}x/cos^{m−2}x + (m−1)·sinⁿx/cosᵐx。移项积分得第三支应为 **n、m 同降 2**：

```latex
\int\frac{\sin^{n} ax}{\cos^{m} ax}\,dx = \frac{\sin^{n-1} ax}{a(m-1)\cos^{m-1} ax} - \frac{n-1}{m-1}\int\frac{\sin^{n-2} ax\,dx}{\cos^{m-2} ax}
```

即积分号内应为 sin^{n−2}ax/cos^{m−2}ax；转写原文误作 sin^{n−1}ax（只降 n 一次）。

## 数值抽查（n=2, m=4）

订正式给出 ∫sin²x/cos⁴x dx = sin x/(3cos³x) − (1/3)tan x + C，求导恰还原 sin²/cos⁴；按原文指数的路线求导不还原（复算对照：原文路线得 2/3，订正值 4/9）。

## 结构旁证

第三支的「同降 2」结构与其镜像式 ∫cosⁿ/sinᵐ（条目 ~391）第三支 ∫cos^{n−2}/sin^{m−2} 完全一致——391 第三支复算无误，佐证 380 第三支应为同型。
