# 式 16.168–16.170 随机数定义与逆变换转录复算

对《数学手册(原书第10版)》16.3.5.2 中均匀分布随机数定义（16.168）、同余法递推（16.169）与逆变换推导（16.170）的逐式转录与复算。

## 转录

```
(16.168)  f₀(x) = 1 (0⩽x⩽1), 0 其他；
          F₀(x) = 0 (0⩽x) / x (0<x⩽1) / 1 (x⩾1)
(16.169)  z_{i+1} ≡ c·z_i (mod m)
(16.170)  P(η_i⩽x) = P(F⁻¹(ξ_i)⩽x) = P(ξ_i⩽F(x)) = ∫₀^{F(x)} f₀(t)dt = F(x)
```

## 复算

- **(16.168)** 密度部分正确：[0,1] 上均匀密度为 1。分布函数首段条件原文作「0 ⩽ x」，与第二段「0 < x ⩽ 1」重叠冲突；按分布函数性质应为「x < 0」（x<0 时 F₀=0，0⩽x⩽1 时 F₀=x，x⩾1 时 F₀=1）。属条件转写疑点而非数学错误，见 [[queries/式16-168分布函数首段条件疑为x小于0]]。
- **(16.169)** 递推形式正确；正文伴随多处符号脱落（c、r、「0 与 1」），见 [[concepts/同余法]]。
- **(16.170)** 推导链逐步核验：η_i⩽x ⇔ F⁻¹(ξ_i)⩽x ⇔ ξ_i⩽F(x)（此步需 F 连续或广义逆约定，源文未声明）；ξ_i 服从 U[0,1]，故 P(ξ_i⩽F(x)) = ∫₀^{F(x)} f₀(t)dt = F(x)（当 0⩽F(x)⩽1）。数学内容正确。

## 结论

三式的数学内容均正确（(16.168) 存在一处条件转写疑点）；(16.170) 为全节唯一带完整证明链的公式，是 [[concepts/逆变换抽样]] 的依据。
