# 双曲线面积弧长与等边双曲线（式 3.340–3.342，式 3.341a 本体脱落）

## 曲率半径（3.340）

```
R = a²b²(x₀²/a⁴ + y₀²/b⁴)^{3/2} = (r₁r₂)^{3/2}/(ab) = p/sin³u   (3.340a)
顶点:  R_A = R_B = p = b²/a                                      (3.340b)
```

与椭圆 (3.327) 同构；原文第二等式「r₁r₂^{3/2}」应为 (r₁r₂)^{3/2}（括号在转写中脱落）。

## 面积（3.341）

- **弓形 APN 面积公式 (3.341a) 本体整段脱落**，仅存编号，见 [[queries/式3-341a双曲线弓形面积公式本体脱落是否可复原]]。
- 保留完整的 (3.341b)：

```
S_OAPG = ab/4 + (ab/2)·ln(2d/c)
```

其中线段 PG 平行于下面的渐近线，c 是焦距，d = OG。其对数结构与双曲线积分（∫dx/x 型）相符。

## 弧长

与抛物线、椭圆一样，双曲线上两点间的弧长不能用初等方法计算，需第二类不完全椭圆积分 E(k, φ)（前向引用原书 8.1.4.3、第 654 页；椭圆对应内容见 [[findings/椭圆面积周长级数与算例]]）。

## 等边双曲线（3.342）

```
x² − y² = a²        （轴长相等；渐近线 y = ±x 互相垂直）   (3.342a)
以渐近线为坐标轴:  x·y = a²/2                              (3.342b)
```

## 置信说明

因 (3.341a) 脱落、(3.340a) 有括号疑点，本组整体置信降为 medium；保留部分均为标准结构。
