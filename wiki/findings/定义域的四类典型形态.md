# 定义域的四类典型形态（例 A–D）

**来源**：[[sources/10-数学手册原书第10版--8-218-多元函数--1ycg0a2]] 2.18.2.4.3 与 2.18.2.1–2.18.2.2（图 2.102–2.103、2.106）。

## 原则

由公式给出的函数，其定义域为使解析表达式有意义——即取得唯一、有限实值——的所有数组的并。定义域通常是点的有界或无界连通集；按边界归属分开集/闭集，开的连通点集称为区域（见 [[concepts/区域与连通性]]）。

## 四类典型形态（直接证据，已逐项复核）

| 例 | 函数 | 约束 | 几何形态 |
|---|---|---|---|
| A | $u = x^2 + y^2$ | 无 | 全平面 |
| B | $u = 1/\sqrt{16 - x^2 - y^2}$ | $x^2 + y^2 < 16$ | 圆的内部（图 2.103(a)），开区域 |
| C | $u = \arcsin(x+y)$ | $-1 \leqslant x + y \leqslant 1$ | 两平行线之间的长条形闭区域（图 2.103(b)） |
| D | $u = \arcsin(2x-1) + \sqrt{1-y^2} + \sqrt{y} + \ln z$ | $0 \leqslant x \leqslant 1,\ 0 \leqslant y \leqslant 1,\ z > 0$ | 边长为 1 的正方形上方的所有三维点（图 2.103(c)） |

各项不等式与 $\arcsin$（输入须在 $[-1,1]$，见 [[concepts/反正弦函数]]）、平方根（被开方数非负）、对数（真数为正）的定义域逐一吻合。

## 分段公式例

手册 2.18.2.4.2 的分段例 C（原文式前的“Φ ■ C:”标记疑为转写残留，见 [[queries/式2-288编号悬置与分段例C标记是否为转写残留]]）：

```latex
u = \begin{cases}
x + y, & x \geqslant 0,\ y \geqslant 0,\\
x - y, & x \geqslant 0,\ y < 0,\\
-x + y, & x < 0,\ y \geqslant 0,\\
-x - y, & x < 0,\ y < 0.
\end{cases}
```

四段展开恰为 $u = |x| + |y|$（按四个象限分段的直接验证）。

## 验证与置信

直接证据：各不等式可由初等函数定义域逐项推出，复核无误。证据强度：强。相关：[[findings/多元函数的定义与曲面表示]]、[[concepts/区域与连通性]]。
