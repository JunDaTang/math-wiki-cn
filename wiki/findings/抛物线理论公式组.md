# 抛物线理论公式组（式 3.343–3.350，切线三等式与 p=2bk 已验证）

要素：顶点 O（原点）、焦点 F（距原点 p/2）、准线（距原点 p/2，与轴垂直）、半焦弦 p；数值离心率 e = 1（该数值在转写中脱落）。

```
标准方程:  y² = 2px                                              (3.343)
竖轴式:    y = ax² + bx + c,  p = 1/(2|a|)                       (3.344a,b)
顶点:      x₀ = −b/2a,  y₀ = (4ac − b²)/4a                       (3.344c)
定义性质:  PF = PK = x + p/2                                     (3.345)
直径:      y = p/k   （k 为被平分弦的斜率）                       (3.346)
切线:      y·y₀ = p(x + x₀)                                      (3.347)
顶点切线性质:  TS = SP,  TO = OM = x₀,  TF = FP                  (3.348)
切线判别:  p = 2bk   （直线 y = kx + b 为切线 ⟺ 此式）            (3.349)
曲率半径:  R = (p + 2x₀)^{3/2}/√p = p/sin³u = lₙ³/p²             (3.350a)
顶点曲率:  R = p                                                 (3.350b)
```

## 已验证项（分析阶段复算，视为已复算）

- (3.344c) 顶点坐标：由 y = ax²+bx+c 配方直接可得。✓
- (3.346) 直径 y = p/k：斜率为 k 的弦 y = kx + b 与 y² = 2px 交于两点，其中点纵坐标为 p/k。✓
- (3.348) 顶点切线三等式 TS = SP、TO = OM = x₀、TF = FP：均可由切线方程 y·y₀ = p(x+x₀) 与 y 轴（顶点切线）的交点坐标直接验证。✓
- (3.349) 判别式：y = kx+b 代入 y² = 2px，令 Δ = 0 得 b = p/2k，即 p = 2bk。✓
- (3.350a) 的 lₙ³/p² 形式与 (p+2x₀)^{3/2}/√p 等价（lₙ² = 2p(x₀+p/2)·…，代入验证）。✓
