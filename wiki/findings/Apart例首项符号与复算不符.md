# Apart 例首项符号与复算不符

## 书中结果（20.3.1.4）

对 20.3.1.3 的多项式 p、q（p = (5+x)(1+x+x²)(−5+x²+x³)，q = (1+x+x²)(x²−7)）：

```
In[1] := Apart[q/p]
Out[1] = 6/(35(5+x)) + (-55+11x+6x²)/(35(-5+x²+x³))
```

## 复算结果

消去公因式 (1+x+x²) 后 q/p = (x²−7)/((5+x)(−5+x²+x³))。按部分分式

(x²−7)/((x+5)(x³+x²−5)) = A/(x+5) + (Bx²+Cx+D)/(x³+x²−5)，

其中 A = [(x²−7)/(x³+x²−5)]|_{x=−5} = 18/(−105) = **−6/35**。

故首项应为 **−6/(35(5+x))**，与书中「+6」符号相反。第二项经数值核验无误：组合验证 −6(x³+x²−5) + (6x²+11x−55)(x+5) = 35(x²−7)，即第二项 (−55+11x+6x²)/(35(−5+x²+x³)) 与重构首项合成的恰为 q/p。

数值核验（x = 0 处）：q/p = (0−7)/(5·(−5)) = 7/25 = 0.28；书中两式之和为 61/175 ≈ 0.349，不吻合；以 −6 代之则 −6/175 + 55/175 = 49/175 = 7/25，吻合。

## 判定

这是本源中唯一经复算推翻的数学结果：Mathematica 的实际输出应为负号，疑为转写/排印脱「−」号。是原书即误还是 OCR/转写所致，需对原书影印件核对（[[queries/Apart例首项6疑脱负号之辨]]）。

## 证据性质

直接证据（部分分式系数的留数式计算 + 数值点核验）；书中结果未能复现。
