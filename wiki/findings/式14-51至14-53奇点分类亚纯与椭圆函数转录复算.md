# 式 14.51–14.53 奇点分类、亚纯与椭圆函数转录复算

对 14.3.5.1–14.3.5.3 中孤立奇点三分类 (14.51)–(14.52)、亚纯函数与椭圆函数周期性 (14.53) 的转录与复算。

## 转录内容

```latex
(14.51)  f(z) = Σ_{n=-∞}^∞ a_n (z - z_0)^n
(14.52)  a_n = (1/2πi) ∮_K (ζ - z_0)^{-n-1} f(ζ) dζ = f^{(n)}(z_0)/n!   (n = 0, 1, 2, ...)
(14.53)  f(z + mω_1 + nω_2) = f(z)   (m, n = 0, ±1, ±2, ...; Im(ω_1/ω_2) ≠ 0)
```

三分类判据：洛朗级数 (14.51) 不含负幂（$a_n = 0,\ n<0$）⟹ 可去奇点（且 $f(z_0) = a_0$）；含有限 $m$ 个负幂（$a_{-m} \neq 0$，$a_{-n} = 0,\ n>m$）⟹ $m$ 阶极点；含无穷多负幂 ⟹ 本质奇点。趋近行为：趋近于极点 $|f(z)| \to \infty$；趋近于本质奇点 $f(z)$ 任意接近于任一复数 $c$。

## 独立复算

- **三分类判据自洽**：负幂个数 $\in \{0, \text{有限 } m, \infty\}$ 的三分与 (14.50b) 系数唯一性相容；泰勒级数即主部为零的洛朗级数。✓
- **$\frac{1}{2}(z + 1/z)$ 在 $z = 0$**：洛朗展式 $= \frac{1}{2z} + \frac{z}{2}$，负幂仅 $z^{-1}$ 一项且系数 $\frac12 \neq 0$ ⟹ 一阶极点。✓（用 (14.54b) 复核：$\lim_{z\to0} z\cdot\frac12(z+1/z) = \frac12$。）
- **$e^{1/z} = \sum_{n\ge0} \frac{1}{n!} z^{-n}$ 在 $z = 0$**：以 $w = 1/z$ 代入 $e^w$ 的展开，负幂无穷多 ⟹ 本质奇点。✓
- **(14.52) 与 (14.50b) 的一致性**：$n \ge 0$ 时 (14.52) 即 (14.50b) 的左端等式。✓ 但原书称系数“由柯西积分定理给出”，术语存疑，见 [[queries/式14-52柯西积分定理与积分公式术语之辨]]。
- **(14.53) 双周期条件**：$\operatorname{Im}(\omega_1/\omega_2) \neq 0$ 等价于 $\omega_1, \omega_2$ 非实相关，此时基本平行四边形面积 $|\operatorname{Im}(\overline{\omega_1}\omega_2)| \neq 0$，周期格为二维。✓

## 结论

分类判据与全部算例复算一致，confidence: high，replicated: true。亚纯函数的“两解析函数之商”表示及 $\tan z$、$\cot z$ 例随文转录，未见矛盾。

## 附注

- “一个 阶极点”“一个 重的根”等处阶数 $m$ 成批脱落；$e^{1/z}$ 例中“z=O”应为 $z=0$，见 [[queries/14-3全节系统性转写讹误清单]]；
- 本节“奇点”明确指孤立奇点，为 [[queries/奇点术语双重用法之辨]] 追加证据。
