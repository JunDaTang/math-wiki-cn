# AKS 命题与检验流程（转写受损）

《数学手册》5.4.5 记录了 AKS 素性检验（Agrawal、Kayal、Saxena，2002）——基于确定素数/合数判定的多项式算法，可有效地检验任何自然数的素性。

## 命题（按源文转写）

n > 1 是自然数，r 是素数，满足：

- [n] 不被 ≤ r 的素数整除；
- i = 1, 2, …, ⌊(log₂n)²⌋ 时 r^i ≢ 1 (mod n)；
- 对每个 1 ≤ a ≤ √r·log n：(x+a)^n ≡ x^n + a (mod x^r−1, n)；

则 n 是一个素数幂。

⚠ 第二条按源文方向（r^i mod n）数学意义不合：AKS 的证明需要的是 n 模 r 的阶大于 log²n（从而限制 n 的素因子形状），标准条件为 n^i ≢ 1 (mod r)。疑原书误排或转写颠倒（源内两处出现），见 [[queries/aks条件r的i次方模n是否应为n的i次方模r]]。

## 检验流程（按源文转写）

m := ⌊(log₂n)^5⌋；n < 5,690,034 时查素数表；对 n > 5,690,034 有 n > m。核验 n 是否被 [3,m] 中自然数整除（是 ⇒ 非素数）；取素数 r < n 使 r^i ≢ 1 (mod n)（i = 1..⌊(log₂n)²⌋，存在性可证）；核验 a = 1..⌊√r·log₂n⌋ 的批量同余 (x+a)^n ≡ x^n + a (mod x^r−1, n)；不成立 ⇒ 非素数；成立 ⇒ n 为素数幂，再检验是否存在 k > 1 使 n = q^k，不存在则 n 是素数。流程页见 [[methodology/aks素性检验流程]]。

## 评注（源文）

与随机性算法不同，AKS 结果可信、甚至没有可忽略的小错误概率；但密码学中拉宾-米勒检验更合适。

## 复算与置信

- 已复算：阈值 5,690,034 是 x = (log₂x)^5 的不动点（(log₂ 5690034) ≈ 22.442，其 5 次幂 ≈ 5.69×10^6 ✓），故 n > 5,690,034 ⇒ n > m 成立。
- 未复算/受损：命题与流程主干依赖上述 r/n 疑点，按源文无法直接复算；作者名「导xena」为 OCR 讹误（见 [[queries/aks第三作者是否应为saxena]]）。整体置信度低，待对照 2002 年原文后修订。
