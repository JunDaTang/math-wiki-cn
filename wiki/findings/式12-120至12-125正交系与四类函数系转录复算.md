# 式 12.120–12.125 正交系与四类函数系转录复算

## 转录内容

- (12.120) 克罗内克符号 δ_ξζ；
- (12.121) 实三角函数系 1/√(2π), (1/√π)cos t, (1/√π)sin t, (1/√π)cos 2t, (1/√π)sin 2t, …；
- (12.122) 复三角函数系 e^{int}/√(2π)（n = 0, ±1, ±2, …）；
- (12.123) P_n(t) = dⁿ/dtⁿ[(t²−1)ⁿ]，n = 0, 1, 2, …；
- (12.124) P̃_n(t) = √(n+½)·P_n(t)/(2n)!!；
- (12.125) H_n(t) = e^{t²} dⁿ/dtⁿ e^{−t²}（n = 0, 1, …）；
- 例 D：拉盖尔多项式构成 L²((0,∞)) 中的一个正交系（无公式）。

## 复算

- **三角系**：∫₋π^π cos mt·cos nt dt = πδ_{mn}（m,n ⩾ 1）、∫ sin·cos = 0、∫ 1² dt = 2π、复系 ∫ e^{i(m−n)t}dt = 2πδ_{mn}，归一化常数 √π、√(2π) 与之精确匹配。✓
- **勒让德归一化（关键复算）**：取 (12.123) 无因子形式，P_n = 2ⁿn!·P_n^std，而 (2n)!! = 2ⁿn!，故 P̃_n = √((2n+1)/2)·P_n^std，∫₋₁¹ P̃_n²dt = ((2n+1)/2)·(2/(2n+1)) = 1。**两式按转录联立自洽**；但标准罗德里格斯式含 1/(2ⁿn!)，故 (12.123) 与 (12.124) 必有一处偏离原书，见 [[queries/式12-123与12-124勒让德归一化因子归属]]。
- **埃尔米特**：按 (12.125)，H_0 = 1, H_1 = −2t, H_2 = 4t²−2, …（奇数次与通行定义反号，疑漏 (−1)ⁿ）；多项式在 ℝ 上非平方可积，正交性须带权 e^{−t²} 方成立，见 [[queries/式12-125埃尔米特因子与例c例d权函数疑误]]。
- **正交系必线性无关**：排除零向量后，对含零系数的线性组合取与自身的内积即得各系数为零。✓
- **拉盖尔**：仅单句断言，无公式可复算；同理须权 e^{−t}。

## 转写讹误

「实空间炉 L²(⋯)」衍字「炉」（两处）；例 C 标签「■ C:」脱落；页码—节号粘连回指（第 362 4.1.2、第 749/750/751 9.1.2.6、第 793 9.2.4）。已并入 [[queries/12-4全节系统性转写讹误清单]]。

## 结论

三角系复算完全通过；勒让德两式转录自洽但因子归属存疑；埃尔米特/拉盖尔的宿主空间陈述按字面不成立。综合置信度：中。
