# 式 8.131–8.133 原函数折线构造与两算例复算

**结论**：8.3.4.4 的原函数折线构造公式（式 8.131、8.132a/b、8.133）转录如下；两算例经偏导回代复算**全部吻合**；转写本式 8.133 哑变量不一致（$\xi$ 应为 $\zeta$）。

## 逐字转录

**二维（图 8.28）**：若满足可积条件 (8.127)，则在 (8.127) 成立的区域内，沿着连接任意固定点 $A(x_0,y_0)$ 和动点 $P(x,y)$ 的积分路径，都有原函数 $U(x,y)$ 等于线积分

$$U = \int_{\widehat{AP}} (P\,\mathrm{d}x + Q\,\mathrm{d}y). \tag{8.131}$$

事实上，为方便起见，可在 (8.127) 成立的区域内选择平行于坐标轴的积分路径，即折线 $AKP$ 或 $ALP$，故此存在两个计算原函数和全微分的公式：

$$U = U(x_0, y_0) + \int_{\overline{AK}} + \int_{\overline{KP}} = C + \int_{x_0}^{x} P(\xi, y_0)\,\mathrm{d}\xi + \int_{y_0}^{y} Q(x, \eta)\,\mathrm{d}\eta, \tag{8.132a}$$

$$U = U(x_0, y_0) + \int_{\overline{AL}} + \int_{\overline{LP}} = C + \int_{y_0}^{y} Q(x_0, \eta)\,\mathrm{d}\eta + \int_{x_0}^{x} P(\xi, y)\,\mathrm{d}\xi, \tag{8.132b}$$

其中 $C$ 为任意常数。

**三维（图 8.29）**：若满足条件 (8.129c)，由积分路径 $AKLP$，可得原函数计算公式：

$$U = U(x_0, y_0, z_0) + \int_{\overline{AK}} + \int_{\overline{KL}} + \int_{\overline{LP}} = \int_{x_0}^{x} P(\xi, y_0, z_0)\,\mathrm{d}\xi + \int_{y_0}^{y} Q(x, \eta, z_0)\,\mathrm{d}\eta + \int_{z_0}^{z} R(x, y, \zeta)\,\mathrm{d}\zeta + C, \tag{8.133}$$

（$C$ 为任意常数。）沿着平行坐标轴的方向还有其他 5 条可能的积分路径（转写本脱数字），由此又可进一步得到公式。

## 例 A 复算（二维）

$$P\,\mathrm{d}x + Q\,\mathrm{d}y = -\frac{y\,\mathrm{d}x}{x^2+y^2} + \frac{x\,\mathrm{d}y}{x^2+y^2}.$$

书中称「满足条件 (8.129c)」（引用指称存疑，二维实际验证的是 (8.127)，见 [[queries/例A引用式8-129c而非8-127]]）：

$$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = \frac{y^2 - x^2}{(x^2+y^2)^2}.$$

**复算**：$\frac{\partial}{\partial y}\left(-\frac{y}{x^2+y^2}\right)=\frac{-(x^2+y^2)+2y^2}{(x^2+y^2)^2}=\frac{y^2-x^2}{(x^2+y^2)^2}$；$\frac{\partial}{\partial x}\left(\frac{x}{x^2+y^2}\right)=\frac{(x^2+y^2)-2x^2}{(x^2+y^2)^2}$，两者相同 ✓。

利用 (8.132b)，令 $x_0=0,\ y_0=1$（因为函数 $P$、$Q$ 在点 $(0,0)$ 不连续，故不选 $x_0=0,\ y_0=0$），得

$$U = \int_{1}^{y} \frac{0\cdot\mathrm{d}\eta}{0^2+\eta^2} + \int_{0}^{x} \frac{-y\,\mathrm{d}\xi}{\xi^2+y^2} + U(0,1) = -\arctan\frac{x}{y} + C = \arctan\frac{y}{x} + C_1.$$

**复算**：$U_x = -\frac{1/y}{1+x^2/y^2} = -\frac{y}{x^2+y^2} = P$ ✓；$U_y = \frac{x/y^2}{1+x^2/y^2} = \frac{x}{x^2+y^2} = Q$ ✓；$-\arctan\frac{x}{y}$ 与 $\arctan\frac{y}{x}$ 相差常数（象限内为 $\frac{\pi}{2}$），两种写法相容 ✓。

## 例 B 复算（三维）

$$P\,\mathrm{d}x + Q\,\mathrm{d}y + R\,\mathrm{d}z = z\left(\frac{1}{x^2 y} - \frac{1}{x^2+z^2}\right)\mathrm{d}x + \frac{z}{xy^2}\,\mathrm{d}y + \left(\frac{x}{x^2+z^2} - \frac{1}{xy}\right)\mathrm{d}z.$$

满足条件 (8.129c)。利用 (8.133)，令 $x_0=1,\ y_0=1,\ z_0=0$，得

$$U = \int_{1}^{x} 0\cdot\mathrm{d}\xi + \int_{1}^{y} 0\cdot\mathrm{d}\eta + \int_{0}^{z} \left(\frac{x}{x^2+\zeta^2} - \frac{1}{xy}\right)\mathrm{d}\zeta + C = \arctan\frac{z}{x} - \frac{z}{xy} + C.$$

**复算**（逐项偏导回代）：

- $U_x = \frac{-z/x^2}{1+z^2/x^2} + \frac{z}{x^2 y} = -\frac{z}{x^2+z^2} + \frac{z}{x^2 y} = z\left(\frac{1}{x^2y}-\frac{1}{x^2+z^2}\right) = P$ ✓
- $U_y = 0 + \frac{z}{xy^2} = Q$ ✓
- $U_z = \frac{1/x}{1+z^2/x^2} - \frac{1}{xy} = \frac{x}{x^2+z^2} - \frac{1}{xy} = R$ ✓

前两个积分为 0 的核验：基点处 $P(\xi,1,0)=0$、$Q(1,\eta,0)=0$，与书中「$\int_1^x 0\cdot\mathrm{d}\xi$、$\int_1^y 0\cdot\mathrm{d}\eta$」一致 ✓。

## 转写讹误记录

式 8.133 第三积分哑变量转写为 $R(x,y,\xi)\,\mathrm{d}\xi$，例 B 实用 $\zeta$（与 [[queries/式8-11哑变量x与t是否原书排印之误]] 同型问题）；「其中 为任意常数」脱 $C$；「还有其他 条可能的积分路径」脱数字 5；「因为函数 在点 (0,0) 不连续」脱函数记号 $P$、$Q$。汇总见 [[queries/8-3全节系统性转写讹误清单]]。
