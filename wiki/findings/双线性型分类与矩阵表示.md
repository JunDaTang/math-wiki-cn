# 双线性型三分类与矩阵表示（式 5.210–5.211，ℝⁿ 欧氏点积刻画）

## 陈述（5.3.8.6.2）

双线性型 $f:V\times V\to\mathbb{R}$ 称作：

- **对称的**：$f(v,v')=f(v',v)$（对所有 $v,v'\in V$）；
- **斜对称的**：$f(v,v')=-f(v',v)$；
- **正定的**：$f(v,v)>0$（对所有 $v\neq 0$）。

**ℝⁿ 中的欧几里得点积可以刻画为对称正定的双线性型**；$\mathbb{R}^n$ 中标准欧几里得点积定义为 $f(u,v)=u^{\mathrm T}v$。

在有限维空间中，双线性型可用矩阵表示：若 $B=(b_1,\dots,b_n)$ 是 $V$ 的基，则

```latex
A_B(f) = (f(b_i, b_j))_{i,j}          % 5.210（f 对基 B 的表示矩阵）
f(v, v') = v^T A_B(f) v'              % 5.211（v, v' 对基 B 给出）
```

若双线性型是对称的，那么表示矩阵是对称的。

## 归属与边界

- 「对称正定双线性型刻画欧氏点积」**仅关于 ℝⁿ**；复向量空间上对称、正定双线性型失效（$z^2$ 可为负），改由埃尔米特半双线性型刻画酉点积，见 [[findings/复域上对称正定双线性型失效与半双线性替代]] 与 [[concepts/半双线性型与埃尔米特型]]。两者不可互换。
- 原书未展开基变换下表示矩阵的变换公式（本源边界）。
