# 柯西-施瓦茨不等式的四种形式（式 1.114–1.117）

《数学手册(原书第10版)》1.4.2.9 在四个层次上陈述柯西-施瓦茨不等式，各附成立条件：

1. **实数形式 (1.114a/b)**：$\left(\sum a_i b_i\right)^2 \le \left(\sum a_i^2\right)\left(\sum b_i^2\right)$；等号当且仅当 $a_1:b_1 = a_2:b_2 = \cdots = a_n:b_n$。
2. **复数形式 (1.115)**：利用 $\lvert z\rvert^2 = z^* z$，(1.114b) 对复数序列成立。
3. **无穷级数形式 (1.116)**：对无穷收敛级数成立。
4. **积分形式 (1.117)**：$\left[\int_a^b f\varphi\,dx\right]^2 \le \int_a^b f^2\,dx \cdot \int_a^b \varphi^2\,dx$。

几何解释（手册原文）：$n=3$ 时两组数视为笛卡儿坐标系中的向量，不等式即两向量内积的绝对值小于等于两向量绝对值之积；$n>3$ 时扩展到 n 维欧几里得空间的向量。

## 评估

- **证据类型**：直接证据（手册原文，未附证明）。
- **等号条件的覆盖范围**：手册仅对实数形式 (1.114) 给出等号条件；复数 (1.115)、级数 (1.116)、积分 (1.117) 三种形式未单独陈述等号条件。
- **置信度**：高，标准结果。
