# 式 20.46–20.49a 三维绘图复算

## 命令签名与转录（原样）

```mathematica
Plot3D[f[x, y], {x, xa, xe}, {y, ya, ye}]                                    (20.46)
ParametricPlot3D[{fx[t,u], fy[t,u], fz[t,u]}, {t, ta, te}, {u, ua, ue}]      (20.47)
ParametricPlot3D[{fx[t], fy[t], fz[t]}, {t, ta, te}]                         (20.48)
In[1] := Plot3D[x^2 + y^2, {x, -5, 5}, {y, -5, 5}, PlotRange > {0, 25}]
In[2] := Plot3D[(1 - Sin[x]) (2 - cos[2 y]), {x, -2, 2}, {y, -2, 2}]
In[3] := ParametricPlot3D[{Cos[t] Cos[u], Sin[t] Cos[u], Sin[u]},
         {t, 0, 2 Pi} {u, -Pi/2, Pi/2}]
In[4] := ParametricPlot3D[{Cos[t], Sin[t], t/4}, {t, 0, 20}]           (20.49a)
```

## 校勘

- In[1] `PlotRange > {0, 25}`：脱箭头，应为 `PlotRange -> {0, 25}`（[[PlotRange大于号疑为箭头之辨]]）。
- In[2] `cos[2 y]`：Mathematica 区分大小写，应为 `Cos[2 y]`；原样输入时 `cos` 为未定义头，表达式无法数值化，Plot3D 不能成图。
- In[3] 两迭代器 `{t, 0, 2 Pi}` 与 `{u, -Pi/2, Pi/2}` 间脱逗号。
- 式 20.49 仅有 a 无 b：In[3] 与 In[4] 共用标签 20.49a（[[式20-49无b之编号之辨]]）。
- 正文「这个立体是= 25 时切割的」脱 z（应为「这个立体是在 z = 25 时切割的」）；「对于值域」之「域」疑为「值 All」之转写残缺。

## 复算结论（修正后）

- In[1] 抛物面 z = x² + y²（x,y∈[−5,5]）：PlotRange 限定 z∈[0,25]，即立体在 z = 25 处被切割（图 20.8a）。
- In[2] 曲面 (1−Sin[x])(2−Cos[2y])（x,y∈[−2,2]）：修正大小写后有效（图 20.8b）。
- In[3] 球面参数化 {Cos[t]Cos[u], Sin[t]Cos[u], Sin[u]}（t∈[0,2π]，u∈[−π/2,π/2]）：补逗号后有效（图 20.9a）。
- In[4] 螺旋线 {Cos[t], Sin[t], t/4}（t∈[0,20]）：原样有效（图 20.9b）。

## 证据强度

四条算例均需（或无需）小幅修正后即可复算；三维选项语义（ViewPoint 默认 {1.3, -2.4, 2} 等）具版本依赖性，作为默认值陈述置信中等（[[图形选项（Mathematica）]]、[[二维与三维图形选项比较]]）。
