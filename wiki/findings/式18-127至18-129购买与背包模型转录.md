# 式 18.127–18.129 购买问题与背包问题模型转录

## 转录内容（逐字）

```latex
% (18.127a) 购买问题
OF: f(u_1,…,u_n) = Σ_{j=1}^n f_j(u_j) = Σ_{j=1}^n c_j u_j → min!
CT: x_j = x_{j-1} + u_j − v_j,  j = 1(1)n
    x_0 = x_a,  0 ⩽ x_j ⩽ K,  j = 1(1)n
    U_j(x_{j-1}) = {u_j : max{0, v_j − x_{j-1}} ⩽ u_j ⩽ K − x_{j-1}},  j = 1(1)n

% (18.128) 含单位储存费用 ℓ 的修正费用函数
f(x_0,u_1,…,x_{n-1},u_n) = Σ_{j=1}^n (c_j u_j + (x_{j-1} + u_j − v_j/2)·ℓ)

% (18.129a/b) 背包问题
OF: f(u_1,…,u_n) = Σ_{j=1}^n c_j u_j → min!
CT: x_j = x_{j-1} − w_j u_j,  j = 1(1)n
    x_0 = W,  0 ⩽ x_j ⩽ W,  j = 1(1)n
    u_j ∈ {0,1}  若 x_{j-1} ⩾ w_j；  u_j = 0  若 x_{j-1} < w_j
```

（18.127b 的式号在转写中悬空。）

## 转录核对与讹误记录

- **式 (18.129a)**：目标函数印作 `→ min!`，但题设明确为「总价值最大」，且 18.3.6.2 重新照录的 (18.145a) 为 `→ max!`、其泛函方程亦取极大形式——三处证据均指向 max，见 [[queries/式18-129a疑为max之辨]]。
- **购买时机叙述**：「在每个周期结束时工场将……购买」与三处证据不一致：储存费用公式 $(x_{j-1}+u_j-v_j/2)\ell$、容量约束 $x_{j-1}+u_j\leqslant K$、决策下界 $\max\{0,v_j-x_{j-1}\}$ 均与「周期开始时购买」一致，疑「结束」为「开始」之误。
- (18.127a) 决策空间两界保证「需求满足且容量不超」，与正文陈述一致。
