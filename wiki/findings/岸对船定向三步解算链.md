# 岸对船定向（无线电定向）的三步解算链

## 问题（直接证据）

两个固定站点 P₁(λ₁, φ₁) 和 P₂(λ₂, φ₂) 接收一条船通过无线电波发射的方位角 δ₁ 和 δ₂，确定船的位置 P₀ 的地理坐标。该问题在航海学中以**岸对船定向**著称，是球上的一种交会问题，解法上与平面中的交会问题类似（源交叉引用「第 196 3.2.2.3」，页码-节号粘连，印证 [[queries/平面三角学节交叉引用页码节号是否粘连]]）。

## 三步解算链（直接证据，程序性描述）

1. **三角形 P₁P₂N**：边 P₁N = 90°−φ₁、P₂N = 90°−φ₂ 与角 ∠P₁NP₂ = λ₂−λ₁ = Δλ 已知；角 ε₁、ε₂ 和线段 e = P₁P₂ 的计算对应第三基本问题（SWS）。
2. **三角形 P₁P₂P₀**：ξ₁ = δ₁−ε₁，ξ₂ = 360°−(δ₂+ε₂)，故边 e 及其上的角 ξ₁、ξ₂ 已知；边 e₁、e₂ 的计算对应第四基本问题（WSW）解 3（纳皮尔类比）。P₀ 的坐标可从方位角和它到 P₁ 或 P₂ 的距离计算。
3. **三角形 NP₁P₀**：已知两边 NP₁ = 90°−φ₁、P₁P₀ = e₁ 及夹角 δ₁，按第三基本问题解 2 计算 NP₀ = 90°−φ₀ 和角 Δλ₁。**检验**：在三角形 NP₀P₂ 中再次计算 NP₀ 与 Δλ₂。于是 λ₀ = λ₁+Δλ₁ = λ₂−Δλ₂，纬度 φ₀ 亦得。

## 评估

结构上与平面交会体系（[[methodology/交会定位计算流程]] 的「已知—所测—所求—解」范式、三角形链、复算检验）完全同构，北极 N 起到平面交会中第三控制点的作用；所用工具换为 [[concepts/球面三角形六基本问题]] 的第三、四问题。源中为程序性描述，无算例数值，故本 wiki 未做数值复算（区别于 [[findings/四面体棱间夹角算例]] 与 [[findings/子午线收敛角近似式与算例]] 两个已验证算例）。与平面三法的逐项对照见 [[comparisons/平面交会与球面岸对船定向比较]]。
