# 式 20.1–20.3c 符号与数值求解算例转录复算

对《数学手册（原书第10版）》20.1 三组会话示例的逐字转录与独立复算：二次方程符号解 (20.2d) 与标准求根公式逐项一致；六次方程数值解 (20.3c) 经精确整数变号分析证实为恰有六个互异单实根情形下的正确转录。结论：本节算例转录无误，两处脱“六”字应予坐实。

## 转录文本

```text
(20.1)    In[1] := Solve[3 x - 5 == 0, x]

(20.2a)   x² + a x + b = 0,  其中 a, b ∈ ℝ
(20.2b)   Solve[x² + a x + b == 0, x]
(20.2c)   In[1] := Solve[x² + a x + b == 0, x]
(20.2d)   Out[1] = {{x -> 1/2 (-a - √(a² - 4b))}, {x -> 1/2 (-a + √(a² - 4b))}}

(20.3a)   x⁶ - 2x⁵ - 30x⁴ + 36x³ + 190x² - 36x - 150 = 0
(20.3b)   In[1] := NSolve[x⁶ - 2x⁵ - 30x⁴ + 36x³ + 190x² - 36x - 150 == 0, x]
(20.3c)   Out[1] = {{x → -4.42228}, {x → -2.14285}, {x → -0.937347},
                   {x → 0.972291}, {x → 3.35802}, {x → 5.17217}}
```

## 复算一：二次方程符号解（式 20.2d，直接代数复核）

x² + ax + b = 0 的求根公式为 x = (−a ± √(a² − 4b))/2。Out[1] 所给两条替换规则 1/2(−a−√(a²−4b)) 与 1/2(−a+√(a²−4b)) 与之逐项一致；解以“由两个子列表组成的列表”表示、每子列表含一条替换规则 `x -> …`，与源文对表示法的描述吻合。

## 复算二：六次方程数值解（式 20.3c，精确整数变号分析）

记 p(x) = x⁶ − 2x⁵ − 30x⁴ + 36x³ + 190x² − 36x − 150。端点值全部按整数精确计算：

| 变号区间 | 端点函数值（精确整数） | (20.3c) 对应根 |
|---|---|---|
| (−5, −4) | p(−5)=3405 > 0，p(−4)=−806 < 0 | −4.42228 |
| (−3, −2) | p(−3)=−519 < 0，p(−2)=42 > 0 | −2.14285 |
| (−1, 0) | p(−1)=13 > 0，p(0)=−150 < 0 | −0.937347 |
| (0, 1) | p(0)=−150 < 0，p(1)=9 > 0 | 0.972291 |
| (3, 4) | p(3)=237 > 0，p(−4)=−582 < 0 | 3.35802 |
| (5, 6) | p(5)=−455 < 0，p(6)=6474 > 0 | 5.17217 |

六个互不相交区间各经介值定理含至少一个实根，故至少有 6 个互异实根；p 为六次多项式，根数（计重数）至多 6，故恰有这六个根且皆为单根。(20.3c) 每个列出值均落在对应区间内；代入抽检的残差与 |p′|·（半 ulp）同阶，处于 6 位有效数字舍入所能解释的范围。

**结论**：式 (20.3c) 转录正确；源文两处脱字——“但它有 个实根”“具有一定精度的 个解”——所脱之字均为“六”（见 [[queries/它有个实根脱六之辨]]）。

## 警示：−2.14285 不是 −15/7

显示值 −2.14285 形似 −15/7 = −2.142857…，但 p(−15/7) = −195/7⁶ ≈ −0.00166 ≠ 0；且首一整系数多项式的有理根必为整数，−15/7 不可能是根。真根为无理数 ≈ −2.142852（略大于 −15/7）。勿将 6 位显示值误作精确分数。

## 证据性质说明

- **直接证据**：上表十二个端点值与区间归属为可独立重算的精确整数算术（本 finding 已全部复核）。
- **推断成分**：残差的舍入量级解释为阶估计；“所脱之字为六”是由六实根结论反推的编辑判断，与源文语义吻合。
