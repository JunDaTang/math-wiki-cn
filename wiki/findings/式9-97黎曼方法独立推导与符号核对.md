# 式 9.97 黎曼方法：转录、独立推导与符号核对

## 逐字转录

```
u_xy + a u_x + b u_y + cu = F                                        (9.97a)
v_xy − (av)_x − (bv)_y + cv = 0（伴随方程）                           (9.97b)
v(x,η;ξ,η) = exp(∫_ξ^x b(s,η)ds)，v(ξ,y;ξ,η) = exp(∫_η^y a(ξ,s)ds)   (9.97c)
Σ_{i,k} a_ik u_{x_ix_k} + Σ_i b_i u_{x_i} + cu = f                   (9.97d)
Σ_{i,k} (a_ik v)_{x_ix_k} − Σ_i (b_i v)_{x_i} + cv = 0               (9.97e)
```

黎曼公式（转写形式，9.97f）：

```
u(ξ,η) = ½(uv)_P + ½(uv)_Q
  − ∫_{P̂Q}[buv + ½(v u_x − u v_x)]dx − [auv + ½(v u_y − u v_y)]dy
  + ∬_{PMQ} Fv dxdy
```

（P 在直线 y = η 上、Q 在直线 x = ξ 上，曲线自 P 至 Q 且不与特征相切，PMQ 为曲线与两条特征线段围成的区域；转写此处两个线积分项**同取负号**。）另一形式（9.97g，柯西数据以偏导数给出时）：

```
u(ξ,η) = (uv)_P − ∫_{Q̂P}(buv − u v_x)dx − (auv + v u_y)dy + ∬_{PMQ} Fv dxdy
```

## 独立推导（复算）

由 Lagrange 恒等式 vLu − uL*v = ∂ₓA + ∂_yB，其中

```
A = auv + ½(v u_y − u v_y)，B = buv + ½(v u_x − u v_x)
```

（逐项展开核验 ✓）。在由曲线 P̂Q 与两条特征线段围成的区域上积分并用 Green 公式；特征线段上的积分因条件 (9.97c) 化为全微分，整理得

```
u(ξ,η) = ½(uv)_P + ½(uv)_Q
  + ∫_{P̂Q}{[buv + ½(vu_x − uv_x)]dx − [auv + ½(vu_y − uv_y)]dy}
  + ∬_{PMQ} Fv dxdy
```

**即 dx 项与 dy 项必须反号。**

## 数值验证（两组算例）

- 算例一：a, b ≠ 0、c = ab，取 u 为指数组合的精确解，黎曼函数 v = e^{b(x−ξ)+a(y−η)}，按推导式计算与 u(ξ, η) 精确值比较，通过。
- 算例二：另取一组系数与解，同样通过。
- 按转写的 9.97f（两线积分项同负号）计算则不等于 u(ξ, η)。

## 结论与保留

- 伴随方程 (9.97b/e) 与特征条件 (9.97c) 的转录无疑问；黎曼公式 (9.97f) 的**线积分符号结构**与独立推导矛盾：推导要求 dx 项与 dy 项反号，转写均为负号并列。候选解释：原书以单一大括号分组 −∫{[…]dx − […]dy} 而转写丢失分组致第二项变号；或原书/译本排印误。
- 9.97g 存在同类符号结构问题，且 (uv)_P 端点项的归属取决于 P、Q 的标定方式。
- 本 finding 为直接证据（推导 + 数值验证）与转写文本的冲突记录，置信中等：待对勘原书裁定，见 [[queries/式9-97f与9-97g线积分符号结构]]。在解决前，wiki 内引用黎曼公式以推导式为准并标注存疑。
