# 外接圆半径、内切圆半径与面积公式（式 3.99–3.102，含海伦公式）

**发现内容（直接证据，公式逐字保留）：**

外接圆半径（[[concepts/外接圆]]）：

$$R = \frac{a}{2\sin\alpha} = \frac{b}{2\sin\beta} = \frac{c}{2\sin\gamma} \tag{3.99}$$

内切圆半径（[[concepts/内切圆]]）：

$$r = \sqrt{\frac{(s-a)(s-b)(s-c)}{s}} = s\tan\frac{\alpha}{2}\tan\frac{\beta}{2}\tan\frac{\gamma}{2} \tag{3.100}$$

$$r = 4R\sin\frac{\alpha}{2}\sin\frac{\beta}{2}\sin\frac{\gamma}{2} \tag{3.101}$$

面积（含 [[concepts/海伦公式]]）：

$$S = \frac{1}{2}ab\sin\gamma = 2R^2\sin\alpha\sin\beta\sin\gamma = rs = \sqrt{s(s-a)(s-b)(s-c)} \tag{3.102}$$

源文明言末式称为海伦公式。

**内部一致性核验（分析层，非源文直述）：**

- $S$ 的四形式一致：由 [[concepts/正弦定律]] $a = 2R\sin\alpha$ 等代入 $\frac{1}{2}ab\sin\gamma$ 即得 $2R^2\sin\alpha\sin\beta\sin\gamma$；$rs$ 与海伦式的一致性经 (3.100) 第一式平方相乘直接验证。
- $r$ 的三形式一致：(3.100) 第一式与第二式之等价由 $S = rs$ 与海伦式衔接；(3.101) 由 (3.100) 第一式与 (3.95a,b) 型半角关系导出。
- (3.99) 与正弦定律 (3.88) 的比例常数 $2R$ 互为印证。

**证据类型：**直接证据，强度高；互证属同源代数核验，非独立复现。
