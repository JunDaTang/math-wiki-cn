# 式 13.67–13.71c 梯度算子与运算法则转录复算

对 13.2.6.1–13.2.6.3 的公式逐一复算（范围限于本节，不外推至其他节）：

| 式号 | 内容 | 判定 |
|---|---|---|
| (13.67) | ∇ 的笛卡儿定义 | ✓ 正确 |
| (13.68a–d) | 四算子的 ∇ 形式 | ✓ 正确（记号约定） |
| (13.69)(13.70) | 线性性、乘积法则 | ✓ 形式法则正确 |
| 例 A | grad(UV⃗) = V⃗·grad U + U div V⃗ | ⚠ 左端算子疑应为 div |
| 例 B | grad(V⃗₁V⃗₂) 四项展开 | ✓ 即标准恒等式 grad(A·B) 四项展开 |
| (13.71a) | grad V⃗ = ∇V⃗ | ✓ |
| (13.71b) | 2(a⃗·∇)V⃗ 六项展开 | ✓ 独立重推逐项吻合 |
| (13.71c) | (a⃗·∇)r⃗ = a⃗ | ✓ |

## 直接证据

- **例 B**：与标准恒等式 $\nabla(\vec A\cdot\vec B) = (\vec A\cdot\nabla)\vec B + (\vec B\cdot\nabla)\vec A + \vec A\times(\nabla\times\vec B) + \vec B\times(\nabla\times\vec A)$ 逐项对照吻合（V⃗₁V⃗₂ 并置按手册惯例为标量积）。
- **(13.71b)**（本页 replicated: true 的依据）：经 $\operatorname{rot}(\vec V\times\vec a)$ 与 $\operatorname{grad}(\vec a\vec V)$ 两个标准恒等式相加**独立重推**，逐项吻合。
- **(13.71c)**：对 r⃗ = x i⃗ + y j⃗ + z k⃗ 逐分量计算 (a⃗·∇)r⃗ = a⃗，显然成立。

## 存疑项（例 A，另立 query 跟踪）

类型检验：右端 $\vec V\cdot\operatorname{grad}U + U\operatorname{div}\vec V$ 为标量，左端必须是 $\operatorname{div}(U\vec V)$；标准乘积法则 div(UV⃗) = V⃗·grad U + U div V⃗ 恰好成立，而 grad(UV⃗) 与右端类型不符。脚注称「原文将此式最左端的 grad 误为 div」，由此产生译者改动是否误改之疑，详见 [[queries/例A左端算子grad与div之辨]]。此疑点为文本考据问题，不计入本页复算置信度评定。
