# 网络算图的等高线构造与欧姆定律算例

**发现内容**（《数学手册(原书第10版)》2.19.2，式 2.292 与图 2.108）：三元关系

$$F(x, y, z) = 0 \tag{2.292}$$

（多数情形可直接表示成 $z = f(x, y)$）把变量视为空间坐标后定义一个曲面；利用等高线（2.18.1.2）可在二维平面上将其直观化。构造网络算图时，平行于坐标轴的两族直线分别载变量 $x$ 与 $y$，等高线族载变量 $z$，三者合成一个网；任意两变量的取值经网格交点或沿等高线读出第三个变量。

**欧姆定律算例** $U = R \cdot I$：电压 $U$ 用依赖于两个变量的等高线表示；把 $R, I$ 选为笛卡儿坐标时，对任意常数，$U = $ 常数对应一条双曲线（图 2.108）。由图可读出：

- 每对 $(I, R)$ 对应的 $U$；
- 每对 $(R, U)$ 对应的 $I$；
- 每对 $(I, U)$ 对应的 $R$。

研究范围限于定义域 $0 < R < 10$、$0 < I < 10$、$0 < U < 100$。注 (1)：改变标度可将算图用于其他区域——若定义域变为 $0 < I < 1$（$R$ 不变），双曲线标记变为 $U/10$。

**时代注记**：即使在计算机时代，实验室仍常用网络算图计算近似值或作迭代时的初始推断。后者与 2.16 的非线性拟合初值选取（如 [[findings/指数和的两级修正]]、[[findings/经验拟合数值算例]]）构成「图解初值 → 解析拟合」的互补工作流。

**证据与复核**：构造性说明加标准算例；双曲线族由 $RI = $ 常数直接得出，可靠。本发现未含需独立数值复核的计算；算图的化直改进见 [[findings/标度化直原理与对数直线算图]]。
