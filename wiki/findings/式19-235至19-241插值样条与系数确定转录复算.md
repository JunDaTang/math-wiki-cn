# 式 19.235–19.241 插值样条与系数确定转录复算

对 19.7.1.1 三次插值样条的定义四性质、霍拉迪定理 (19.235) 与系数确定链 (19.236)–(19.241) 的逐字转录，并对推导链做了独立复算。

## 逐字转录

```latex
定义四性质：
(1) S(x_i) = f_i   (i = 1, 2, …, N)
(2) S(x) 在任一子区间 [x_i, x_{i+1}] (i = 1,…,N−1) 内为次数不高于 3 的多项式
(3) S(x) 在整个插值区间 [x_1, x_N] 上是二次连续可微的
(4) 边界条件 a) S''(x_1)=S''(x_N)=0（自然样条）；b) S'(x_1)=f'_1, S'(x_N)=f'_N（已知值）；
    c) f_1=f_N 且 S、S'、S'' 在两端点匹配（周期样条）

(19.235)  ∫_{x_1}^{x_N} [S''(x)]² dx ⩽ ∫_{x_1}^{x_N} [g''(x)]² dx   （霍拉迪定理）
(19.236)  S(x) = S_i(x) = a_i + b_i(x−x_i) + c_i(x−x_i)² + d_i(x−x_i)³   (i = 1,…,N−1)
(19.237)  a_i = f_i   (i = 1,…,N−1)；附加引入 a_N = f_N
(19.238)  d_{i−1} = (c_i − c_{i−1}) / (3h_{i−1})   (i = 2,…,N−1)；
          自然条件 c_1 = 0，引入 c_N = 0 后 i = N 亦成立
(19.239)  b_{i−1} = (a_i − a_{i−1})/h_{i−1} − (2c_{i−1} + c_i)·h_{i−1}/3   (i = 2,…,N)
(19.240)  c_{i−1}h_{i−1} + 2(h_{i−1}+h_i)c_i + c_{i+1}h_i
                = 3[ (a_{i+1}−a_i)/h_i − (a_i−a_{i−1})/h_{i−1} ]   (i = 2,…,N−1)
(19.241)  三对角矩阵 × (c_2, …, c_{N−1})ᵀ，首行 [2(h_1+h_2), h_2]，
          末行 [h_{N−2}, 2(h_{N−2}+h_{N−1})]；用 LR 分解求解
```

## 复算验证（直接证据）

1. **(19.239) 的推导**：在节点 x_i 处要求左段取值 S_{i−1}(x_i) = a_i，即 a_{i−1} + b_{i−1}h_{i−1} + c_{i−1}h_{i−1}² + d_{i−1}h_{i−1}³ = a_i；代入 (19.238) 的 d_{i−1} = (c_i−c_{i−1})/(3h_{i−1})，解出 b_{i−1} = (a_i−a_{i−1})/h_{i−1} − (2c_{i−1}+c_i)h_{i−1}/3，与 (19.239) 一致。✓
2. **(19.240) 的推导**：S′ 连续性 S′_{i−1}(x_i) = S′_i(x_i) 即 b_{i−1} + 2c_{i−1}h_{i−1} + 3d_{i−1}h_{i−1}² = b_i；代入 (19.238)(19.239) 的 b_{i−1}、b_i、d_{i−1} 并整理，恰得 (19.240)。✓
3. **计数核对**：未知量 c_2,…,c_{N−1} 共 N−2 个；方程 (19.240) 取 i = 2,…,N−1 共 N−2 个。✓
4. **矩阵 (19.241) 端行核对**：i = 2 时 (19.240) 为 c_1h_1 + 2(h_1+h_2)c_2 + c_3h_2 = 右端；c_1 = 0 吸收首项，得首行 [2(h_1+h_2), h_2]。i = N−1 时同理 c_N·h_{N−1} 项消失，得末行 [h_{N−2}, 2(h_{N−2}+h_{N−1})]。与转录矩阵一致。✓
5. **(19.235)** 为霍拉迪定理的陈述，原书直接断言、无推导可复算；其归属自然样条、κ ≈ S″ 一次近似与弹性细尺类比等问题见 [[concepts/霍拉迪定理]]。
