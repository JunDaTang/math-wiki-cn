# RSA 方法参数准则与算法（式 5.277a–b）

本源 5.5.7.3 之 2 称 RSA 方法为「最普及的非对称加密方法」，给出：

## 算法

```
设 p、q 为素数，n = pq；e > 1 与 (p−1)(q−1) 互素；d 满足 d·e ≡ 1 (mod (p−1)(q−1))。
公开密钥含 n 与 e；私人密钥为 d。

加密:  E : {0,1,…,n−1} → {0,1,…,n−1},  E(x) := x^e mod n          (5.277a)
解密:  D : {0,1,…,n−1} → {0,1,…,n−1},  D(x) := x^d mod n          (5.277b)

于是对消息 m：D(E(m)) = E(D(m)) = m
```

正确性与 [[findings/rsa算法与算例]] 的复算同源（该处以 e = r = 5、d = s = 605、n = 1073 验证了 D(E(N)) = N）。

## 参数选取准则（原书版次年代观点，多处表述脱落/存疑）

- p 与 q 数位相近：原文「p 的十进制数位相差应该是一个小的数」「相差不太大」两句均有脱落，且「相差不太大」若按字面与抗 Fermat 分解的通行准则相反，疑转写有误（见 [[queries/pq约10-2048与n大于10-200量级问题]]）。
- p−1 与 q−1 应含相当大的素因子，且 gcd(p−1, q−1) 应相当小。
- 原文「pq ≈ 10²⁰⁴⁸」（疑为 2²⁰⁴⁸ 即 2048 比特之误植）与「n > 10²⁰⁰」量级不一致。
- 当 n > 10²⁰⁰ 时，E 成为候选的陷门单向函数（[[concepts/陷门单向函数]]）；所要求的附加信息是怎样分解 n 的知识。

## 时效性与脱落警示

「迫使窃密者花费大约 74 年」「RSADES 1000」（疑为「RSA 比 DES 慢约 1000 倍」之截断）等性能声明均为原书版次年代的过时估计且数字脱落，未对照原书前不入库为断言。RSA 的安全性系于分解 n 的难度，与 DES 的密钥穷尽问题不同类。置信度取 medium：准则部分原文表述多处脱落；算法部分（式 5.277a–b）陈述清楚且已经算例支持。
