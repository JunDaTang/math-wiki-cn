# n 元隐函数方程组的线性系统（式 6.56a–b）

《数学手册(原书第10版)》6.2.3.2 条目 (4)：n 个一元函数 y₁ = f(x), y₂ = φ(x), …, yₙ = ψ(x) 由 n 个方程构成的方程组给出（源文此句转写脱损，见下）。

## 逐字转录

$$F(x, y_1, y_2, \dots, y_n) = 0,\quad \Phi(x, y_1, y_2, \dots, y_n) = 0,\quad \dots,\quad \Psi(x, y_1, y_2, \dots, y_n) = 0 \tag{6.56a}$$

"由 (6.51b)，可得 (6.56a) 的微分"

$$\left.\begin{array}{c}
F_x + F_{y_1} y_1' + F_{y_2} y_2' + \dots + F_{y_n} y_n' = 0, \\
\Phi_x + \Phi_{y_1} y_1' + \Phi_{y_2} y_2' + \dots + \Phi_{y_n} y_n' = 0, \\
\vdots\ +\ \vdots\ +\ \vdots\ +\ \vdots\ +\ \vdots\ = 0, \\
\Psi_x + \Psi_{y_1} y_1' + \Psi_{y_2} y_2' + \dots + \Psi_{y_n} y_n' = 0
\end{array}\right\}. \tag{6.56b}$$

原文续作："(6.56b)，可得要求的导数 y₁′, y₂′, ⋯, yₙ′ 用类似的方法可计算高阶导数"（脱漏介词/动词；未给显式解）。

## 结构验证

- 6.56b 是关于 (y₁′, …, yₙ′) 的 **n×n 线性方程组**：n 个方程、n 个未知量，每个方程由式 6.51b 应用于一个约束函数而得。结构与条目 (3) 的 2×2 情形（[[findings/式6-55两隐函数方程组导数复算]]）完全同型，仅维数推广。✓（仅结构验证，未对一般 n 做显式数值复算，故 replicated 记 null。）
- 推断标注：其系数矩阵在结构上即约束组 (F, Φ, …, Ψ) 对 (y₁, …, yₙ) 的雅可比矩阵，显式解在结构上可由克莱姆法则给出——**原书未使用这些名称、也未给出显式解**，此为录入层面推断，不得归于原文。

## 转写脱损（条目 (4) 引语）

源文开头作"(4) 个一元函数令 y₁ = f(x), y₂ = φ(x), ⋯, yₙ = ψ(x) 个方程"：疑脱漏"若 n"（应为"若 n 个一元函数"）、"令"字疑为衍文、"个方程"前疑脱漏"n"。待对照原书，见 [[queries/6-2-3全节系统性转写讹误清单]]。
