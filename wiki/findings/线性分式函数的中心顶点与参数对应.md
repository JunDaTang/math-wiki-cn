# 线性分式函数的中心、顶点与参数对应 a = −Δ/a₂²（式 2.46）

手册 2.4.2 给出 [[concepts/线性分式函数]] y = (a₁x+b₁)/(a₂x+b₂)（Δ = a₁b₂ − b₁a₂ ≠ 0）的图像要素（直接证据）：

- **中心**：C(−b₂/a₂, a₁/a₂)，即两渐近线 x = −b₂/a₂ 与 y = a₁/a₂ 的交点；
- **与反比的化归**：将中心平移至原点后，函数恰化为 [[concepts/反比例函数]]（式 2.45），参数对应 **a ↦ −Δ/a₂²**；
- **顶点**：A = ((−b₂ ± √|Δ|)/a₂, (a₁ + √|Δ|)/a₂) 与 B = ((−b₂ ± √|Δ|)/a₂, (a₁ − √|Δ|)/a₂)，Δ < 0 时取相同符号、Δ > 0 时取相反符号；
- **间断点**：x = −b₂/a₂；
- **单调性**：Δ < 0 时两支均递减（函数值由 a₁/a₂ 到 −∞、由 +∞ 到 a₁/a₂）；Δ > 0 时两支均递增；
- **极值**：无。

**验证状态（独立重推导）**：

- 参数对应 a = −Δ/a₂² 经代数推导确认：平移后恒有 x′y′ = −Δ/a₂²；
- 顶点 ± 配对规则经两例核对无误，并可写成显式形式：
  - Δ < 0（同号配对）：A = ((−b₂ + √|Δ|)/a₂, (a₁ + √|Δ|)/a₂)，B = ((−b₂ − √|Δ|)/a₂, (a₁ − √|Δ|)/a₂)；
  - Δ > 0（异号配对）：A = ((−b₂ − √|Δ|)/a₂, (a₁ + √|Δ|)/a₂)，B = ((−b₂ + √|Δ|)/a₂, (a₁ − √|Δ|)/a₂)；
  - 例：y = 1/x（a₁=0, b₁=1, a₂=1, b₂=0, Δ = −1 < 0）得顶点 (1, 1)、(−1, −1) ✓；y = −1/x（b₁=−1, Δ = 1 > 0）得顶点 (−1, 1)、(1, −1) ✓。

参数对应 a = −Δ/a₂² 是本源最有复用价值的结果之一：任何线性分式函数的图像都可经「求中心 → 平移 → 按反比画等轴双曲线」三步得到。

**疑点**：源文「双曲线顶点 A ≠ 0, B」中的「≠ 0」疑为转写残留，应为「顶点 A, B」，见 [[queries/2-4-2顶点A不等于0是否为转写残留]]。
