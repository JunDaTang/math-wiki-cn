# 朗道符号定义与指数、对数函数的量级结论（式 2.27–2.29）

**发现**：手册 2.1.4.9 以朗道符号建立函数量级比较。

**定义（式 2.27a–2.27b，原文逐字）**：

```text
f(x) = O(g(x))  表示  lim_{x→a} f(x)/g(x) = A ≠ 0,  A 为常数
f(x) = o(g(x))  表示  lim_{x→a} f(x)/g(x) = 0
（a 也可为 ±∞；朗道符号仅在 x 趋于给定的 a 时才有意义）
```

**手册算例**：A：$x\to0$ 时 $\sin x=O(x)$（$\lim\frac{\sin x}{x}=1\neq0$）。B：$1-\cos x=o(\sin x)$（$\lim_{x\to0}\left\lvert\frac{1-\cos x}{\sin x}\right\rvert=0$）。C：设 $g(x)=x^2$，$\lim_{x\to0}\left\lvert\frac{1-\cos x}{x^2}\right\rvert=\frac12$（同阶），结论却写作 $1-\cos x=O(\sin x)$——按手册自己的 $O$ 定义此结论为假，应为 $O(x^2)$，见 [[queries/例C结论O-sinx应为O-x平方]]。

**量级结论**：

- **多项式**（(5)）：$\pm\infty$ 处的量级由次数表示，$f(x)=x$ 的阶为 1，$n+1$ 次多项式比 $n$ 次多项式高 1 阶。
- **指数函数**（式 2.28a–b）：$\lim_{x\to\infty}\left\lvert\frac{e^x}{x^n}\right\rvert=\infty$（$n$ 为固定正数）；以洛必达迭代证明 $\lim\frac{e^x}{x^n}=\lim\frac{e^x}{nx^{n-1}}=\dots=\lim\frac{e^x}{n!}=\infty$。
- **对数函数**（式 2.29）：$\lim_{x\to\infty}\left\lvert\frac{\log x}{x^{\alpha}}\right\rvert=0$（$\alpha$ 为固定正数），可用洛必达证明。

**定义分歧与内部矛盾（重要）**：手册 $O$ 的口径与通行有界性定义冲突（见 [[queries/手册大O定义是否偏离通行有界性定义]]）；(1) 的“低阶（速度更快）”疑为“高阶”之误（见 [[queries/手册2.1.4.9低阶速度更快是否应为高阶]]）。两处问题已单独立查询追踪，不影响其余结论的自洽性。概念页见 [[concepts/朗道符号]]、[[concepts/函数的量级]]。
