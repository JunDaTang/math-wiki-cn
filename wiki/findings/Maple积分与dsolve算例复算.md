# Maple 积分与 dsolve 算例复算

## 摘要

Maple 小节的关键数值结果经级数展开独立复算证实：∫₋₂² e^(−x³) dx = 277.745841695583（15 位）；'evalf/int'(…, _NCrule) 给出 1.772453851 = √π（10 位）；dsolve 数值解 y(0.5) = 0.01041860472；另 evalf 精度算例 f[3.2] = 2.95200519181。

## 算例 1：evalf(int(exp(−x³), x=−2..2), 15) = 277.745841695583

```txt
> int(exp(-x^3), x = -2..2);              （原样返回，原函数未知）
> evalf(int(exp(-x^3), x = -2..2), 15);   277.745841695583
```

复算：∫₋₂² e^(−x³) dx = ∫₀² e^(u³) du + ∫₀² e^(−u³) du（x=−u 代换）。
- ∫₀² e^(u³) du = Σ_{n≥0} 2^(3n+1)/((3n+1)·n!) ≈ 276.8529（逐项求和至收敛）；
- ∫₀² e^(−u³) du ≈ 0.892952（≈ Γ(4/3)=0.892980 减去 [2,∞) 尾项）；
- 合计 ≈ 277.7458，与书中 277.745841695583 在手算精度内一致。**证实**。

## 算例 2：'evalf/int' 与 _NCrule

```txt
> evalf(int(exp(-x^2), x = -1000..1000));        （误差信息）
> readlib('evalf/int'):
> 'evalf/int'(exp(-x^2), x = -1000..1000, 10, _NCrule);   1.772453851
```

复算：√π = 1.772453850905516，截断至 10 位为 1.772453851。**证实**。第三个参数规定精度，最后一个规定逼近法的内部记号 _NCrule；正文称该程序「使用自适应牛顿法」，与 _NCrule（Newton–Cotes）存在张力（[[queries/自适应牛顿法疑为牛顿柯特斯法之辨]]）。

## 算例 3：dsolve numeric 与 r(0.5)

```txt
> r := dsolve({diff(y(x), x) = (1/4)*(x^2 + y(x)^2), y(0) = 0}, y(x), numeric);
      r := proc 'dsolve/numeric/result2'(x, 1592392, [1]) end
> r(0.5);      {x(.5) = 0.5000000000, y(x)(.5) = 0.01041860472}
```

复算：y′=¼(x²+y²)、y(0)=0 的级数解（Picard 逐次逼近）
y = x³/12 + x⁷/4032 + x¹¹/1064448 + …；
x=0.5 处：0.0104166667 + 0.0000019375 + 0.0000000005 = 0.0104186047，与书中 y(x)(.5) = 0.01041860472 一致至第 9 位。**证实**。此题与 19.4.1.2 及 [[findings/式19-99四阶龙格—库塔格式与算例复算]] 同题，提供软件端印证。

机制（据本源）：dsolve(…, numeric) 返回一个程序对象 r，r(t) 给出独立变量在 t 处的解函数值；Maple 应用龙格—库塔法；相对误差和绝对误差的默认精度为 10^(−Digits+3)，可经整体符号 _RELERR 与 _ABSERR 修改。

## 附：evalf 精度算例

f := z → sqrt(z)+ln(z)；sqrt(3.2)+ln(3.2) = 1.788854382 + 1.163150810 = 2.95200519181（12 位）。源文「f[3.2]=2095200519181」为小数点转写讹误（[[queries/f3-2输出2095200519181疑脱小数点之辨]]）。**证实**。
