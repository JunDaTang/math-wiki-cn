# 式 12.9–12.14 子空间、线性包与包含链转录复算

## 转录内容与修复

- **仿射子空间 (12.9)**：转写作「{x₀ + y ∈ V₀ : y ∈ V₀}」，集合构造式讹误；按定义复原为 {x₀ + y : y ∈ V₀}，其中 x₀ ∈ V 给定，V₀ 为线性子空间。
- **线性包 (12.10)**：lin(E) = [E] = 有穷线性组合 α₁x₁ + α₂x₂ + … + αₙxₙ 全体；标量列表转写作「α₁, α₁」，应为「α₁, α₂」。
- **𝔽ⁿ 运算 (12.11a/b)**：逐分量加法与数乘，转录无误。
- **F(T) 运算 (12.13a/b)**：(x+y)(t) = x(t)+y(t)，(αx)(t) = α·x(t)，逐点定义，转录无误。
- **两条包含链 (12.12)/(12.14)**：

```
φ ⊂ c₀ ⊂ c ⊂ m ⊂ s，   φ ⊂ ℓ^p ⊂ ℓ^q ⊂ c₀，   1 ≤ p < q < ∞    (12.12)
C^(k)([a,b]) ⊂ C([a,b]) ⊂ B([a,b]) ⊂ F([a,b])                      (12.14)
```

## 复算验证（链的每一环）

- φ ⊂ c₀：有限支撑序列必收敛于零。✓
- c₀ ⊂ c：收敛于零是收敛的特例。✓
- c ⊂ m：收敛序列必有界（取 n₀ 后尾段有界，前段有限个值有界）。✓
- m ⊂ s：定义使然。✓
- φ ⊂ ℓ^p：有限和必收敛。✓
- ℓ^p ⊂ ℓ^q（p < q）：由 ξₙ → 0，故最终 |ξₙ| ≤ 1，从而 |ξₙ|^q ≤ |ξₙ|^p，可和性传递（标准论证，源未证）。✓
- ℓ^q ⊂ c₀：Σ|ξₙ|^q < ∞ ⟹ |ξₙ|^q → 0 ⟹ ξₙ → 0。✓
- C^(k) ⊂ C ⊂ B ⊂ F：可微性 ⟹ 连续性 ⟹ 闭区间上连续必有界 ⟹ 是函数。✓（各环严格包含为复算补充：如 {1/n} ∈ c₀∖ℓ¹，{1} ∈ c∖c₀，t ↦ 1/(t−c) 型无界函数连续等。）

## 其他转录注记

- 正文「放射子空间/放射流形」系统性地为「仿射」之讹（含节标题）。
- 例 D（m = ℓ^∞）、例 G（ℓ^p 封闭性引闵可夫斯基不等式，回指 1.4.2.13）转录基本完好。
- 「在 T=N 的情形下，得到空间 M(T) = m」一句中「即上节例 的空m」为粘连乱码，语义已按上下文复原。

## 结论

包含链 (12.12)/(12.14) 全链复算通过，是可复用的结构化数据（详见 [[comparisons/序列空间包含链与函数空间包含链比较]]）；(12.9) 与 (12.10) 各有一处可复原的转写讹误。相关实体页：[[entities/典型序列空间]]、[[entities/函数空间层级]]、[[entities/lp空间]]、[[entities/c0空间]]。
