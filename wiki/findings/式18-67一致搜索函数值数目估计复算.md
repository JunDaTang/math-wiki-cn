# 式 18.67 一致搜索函数值数目估计复算

## 转录

```text
(18.67)  n > 2(b−a)/ε − 1
```

源文语境：选择正整数 n 使 δ = (b−a)/(n+1) < ε/2，格点 x^k = a + kδ（k = 1, …, n）；若 f(x̄) 为最小格点值，则 x\* ∈ [x̄−δ, x̄+δ]（源文误作 f(x) 与 [x−δ, x+δ]，讹误见 [[queries/18-2-4全节系统性转写讹误清单]]）。

## 复算（直接证据）

由 δ = (b−a)/(n+1) < ε/2 出发：

- 两侧乘 (n+1)：b − a < ε(n+1)/2；
- 整理得 n + 1 > 2(b−a)/ε，即 **n > 2(b−a)/ε − 1**，与式 18.67 一致。

定位区间 [x̄−δ, x̄+δ] 的长度为 2δ < ε，与问题提法要求的 d − c < ε 吻合，自洽。

## 证据强度

强：纯代数等价变形，直接复算即得，无隐藏假设（除单峰性保证最小格点的邻域必含全局极小点外）。

## 结论

式 18.67 成立；该估计刻画 [[concepts/一致搜索]] 的函数值数目随 1/ε **线性**增长，是 [[comparisons/三种一维极小搜索方法比较]] 中复杂度对比的基准。
