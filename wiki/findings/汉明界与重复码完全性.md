# 汉明界与重复码的完全性

《数学手册》5.4.6.2.2 给出 t-纠错码的规模约束（汉明界／球填充界）与完全码概念：

```
Σ_{i=0}^{t} C(n,i) · |C| ≤ 2^n
```

对每个 t-纠错码 C ⊆ GF(2)^n 成立；等式成立时 C 称为 t-完全码。

## 重复码完全性（已复算 ✓）

数字重复码 C = {00…0, 11…1} ⊆ GF(2)^{2t+1} 是 t-完全码：

|C| · Σ_{i=0}^{t} C(2t+1, i) = 2 · 2^{2t} = 2^{2t+1} = 2^n ✓

（其中用到 Σ_{i=0}^{t} C(2t+1,i) = 2^{2t}，由二项式系数对称性立得。）

## 意义

汉明界说明纠错冗余的几何极限：以码字为中心、半径 t 的球必须两两不交；完全码是达到该极限（球铺满整个空间）的最优码。重复码是奇数长度下最简单的完全码实例。
