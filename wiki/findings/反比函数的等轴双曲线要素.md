# 反比函数 y = a/x 的等轴双曲线要素（式 2.45）

手册 2.4.1 给出 [[concepts/反比例函数]] y = a/x 的完整图像要素（直接证据）：

- **曲线类型**：中心在原点的 [[concepts/等轴双曲线]]，两条 [[concepts/渐近线]] 为坐标轴（图 2.16）；
- **间断点**：x = 0，此处 y = ±∞（[[concepts/无穷间断点]]）；
- **单调性**：a > 0 时在 (−∞, 0) 上函数值由 0 严格递减到 −∞，在 (0, +∞) 上由 +∞ 严格递减到 0，两支位于一、三象限；a < 0 时在两个区间上均严格递增（一支由 0 到 +∞，另一支由 −∞ 到 0），两支位于二、四象限；
- **顶点**：a > 0 时为 A(√a, √a) 与 B(−√a, −√a)；a < 0 时为 A′(−√|a|, √|a|) 与 B′(√|a|, −√|a|)；
- **极值**：无。

**验证状态（独立重推导）**：顶点公式验证通过——顶点即双曲线 xy = a 与直线 y = ±x（两渐近线夹角的平分线）的交点，代数求解与手册公式一致；单调性与间断点描述经直接分析确认。未发现数学错误。

手册注明「关于双曲线的更详细说明参见 271 页 3.5.2.9」，该节尚未采集。本要素表是式 2.46（[[findings/线性分式函数的中心顶点与参数对应]]）的基准形：任何线性分式函数经中心平移后都回到此处。
