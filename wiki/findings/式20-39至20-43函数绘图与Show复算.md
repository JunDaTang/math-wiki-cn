# 式 20.39–20.43 函数绘图与 Show 复算

## 命令签名转录

```mathematica
Plot[f[x], {x, xmin, xmax}]                          (20.39)
Plot[{f1[x], f2[x], ...}, {x, xmin, xmax}]           (20.41)
Show[plot, options]                                  (20.42)
Show[GraphicsArray[list]]                            (20.43)
```

## Sin[2x] 算例（20.4.4.2）

```mathematica
In[1] := Plot[Sin[2 x], {x, -2 Pi, 2 Pi}]
In[2] := Plot[Sin[2 x], {x, -2 Pi, 2 Pi}, AspectRatio -> 1]   (20.40)
```

复算有效：图 20.3 中可观察默认 AspectRatio（宽高比 1:0.618）；式 20.40 令 x、y 轴等长。`InputForm[%]` 的输出块另立校勘（[[InputForm图形对象内部结构转录校勘]]）。

## 指数函数族算例（20.4.5.1）

```mathematica
In[1] := f[x_] := 2^x; g[x_] := 10^x;
In[2] := h[x_] := (1/2)^x; j[x_] := (1/E)^x; k[x_] := (1/10)^x
In[3] := p1 = Plot[{f[x], h[x]}, {x, -4, 4}, PlotStyle->Dashing[{0.001, 0.02}]]
In[4] := p2 = Plot[{Exp[x], j[x]}, {x, -4, 4}]
In[5] := p3 = Plot[{g[x], k[x]}, {x, -4, 4},
         PlotStyle->Dashing[{0.005, 0.02, 0.001, 0.02}]]
In[6] := Show[{p1, p2, p3}, PlotRange -> {0, 18}, AspectRatio -> 1.2]
```

复算有效：模式定义（[[模式（Mathematica）]]）与三图合并皆成立；`Exp[x]` 内置无需定义；两组 `PlotStyle->Dashing` 以不同虚线样式区分底数不同的曲线（[[图形命令与相对绝对尺寸]]）。

## y = x + ArcCoth[x] 算例（20.4.5.2）

```mathematica
In [1] := f1 = Plot[x + ArcCoth[x], {x, 1.000000000005, 7}]
In [2] := f2 = Plot[x + ArcCoth[x], {x, -7, -1.000000000005}]
In [3] := Show[{f1, f2}, PlotRange → {-10, 10}, AspectRatio → 1.2,
         Ticks → {{{-6, -6}, {-1, -1}, {1, 1}, {6, 6}}}, {{2.5, 2.5}, {10, 10}}},
         AxesOrigin → 0, 0]
```

复算结论：In[1]、In[2] 有效（右支与左支分别避开奇点 x = ±1，端点取法见 [[奇点邻域高精度端点绘图法]]）；In[3] 需先修正两处转写讹误——Ticks 的 x 列表多一闭括号（应为 `Ticks -> {{{-6,-6},{-1,-1},{1,1},{6,6}}, {{2.5,2.5},{10,10}}}`）与 `AxesOrigin → 0, 0` 脱花括号（应为 `AxesOrigin -> {0, 0}`）；全角箭头「→」为原书排版记法，纯文本复算需作 `->`。修正后 Show 合并重显成立。

## 校勘与版本注记

- 「如果要把函数 x ↦ sin 2x 的图形表示在－加与加之间的定义域上」：「加」疑为「π」之讹，且代码定义域为 {x, -2 Pi, 2 Pi}，与「−π 与 π」不符（[[加号疑为π之辨]]）。
- 「函数 的图形」脱 f；「相应的 的值」脱 x；「等长的 轴和 轴」脱 x/y。
- 式 20.43 之 `GraphicsArray` 为 Mathematica 5 时代命令（v6 起弃用），与本节 20.4.5.3 所用 `GraphicsRow`（v6+）构成版本张力（[[GraphicsArray与GraphicsRow比较]]）。

## 证据强度

除 In[3]（ArcCoth 例）需修正两处括号/花括号讹误外，其余算例原样可复算；属强证据。
