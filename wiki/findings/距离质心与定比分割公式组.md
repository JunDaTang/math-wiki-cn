# 距离质心与定比分割公式组（式 3.291–3.294）

本源 3.5.2.3 给出的特殊点公式：

```
两点距离（笛卡儿）:  d = √((x₂−x₁)² + (y₂−y₁)²)                    (3.291)
两点距离（极坐标，余弦定理形式）:
  d = √(ρ₁² + ρ₂² − 2ρ₁ρ₂cos(φ₂−φ₁))                              (3.292)
质心坐标:  x = Σmᵢxᵢ/Σmᵢ,  y = Σmᵢyᵢ/Σmᵢ                            (3.293)
定比分割（λ = m/n = P₁P/PP₂）:
  x = (n·x₁ + m·x₂)/(n+m) = (x₁ + λ·x₂)/(1+λ)                     (3.294a)
  y = (n·y₁ + m·y₂)/(n+m) = (y₁ + λ·y₂)/(1+λ)                     (3.294b)
中点（λ=1）:  x = (x₁+x₂)/2,  y = (y₁+y₂)/2                        (3.294c,d)
```

## 定比分割的三分支约定

在有向线段约定下：λ<0 得外分点（线段之外）；λ>0 为内分。退化情形：λ=0 ⟺ P=P₁；λ=∞ ⟺ P=P₂；λ=−1 ⟺ P 为直线 g 上的无穷远点（反常点）。

## 附加命题（已验证）

**若 P₂ 是线段 P₁P 的中点，则 λ = P₁P/PP₂ = −2。** 分析阶段坐标复算验证成立：取 P₁=(0,0)、P=(2,0)，则 P₂=(1,0)，P₁P = 2、PP₂ = 1，方向相反故 λ = −2。✓

## 验证与置信

公式为标准结果；λ=−2 命题经独立复算（视为已复算）。概念展开见 [[concepts/定比分割]]；调和与黄金分割的后续公式组见 [[findings/调和分割公式组]]、[[findings/黄金分割公式与正十边形边长]]。
