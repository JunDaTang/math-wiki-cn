# 量词否定与互相表示（式 5.23–5.24）

《数学手册(原书第10版)》5.1.2.5：谓词演算公式的否定由下列恒等式刻画：

```latex
¬∀x P(x) = ∃x ¬P(x),   ¬∃x P(x) = ∀x ¬P(x)    % (5.23)
```

应用 (5.23)，量词 ∀ 与 ∃ 可以互相由对方表示：

```latex
∀x P(x) = ¬∃x ¬P(x),   ∃x P(x) = ¬∀x ¬P(x)    % (5.24)
```

**语义论证**（推理，非原书原文）：若 ∀xP(x) 为假，则存在反例 x₀ 使 P(x₀) 假，故 ∃x¬P(x) 真，反之亦然——这给出 (5.23) 的直观依据。

**证据类型**：标准结果，原书以语义论证陈述；本 wiki 未另行构造形式证明。相关：[[findings/量词恒等式与单向蕴涵]]、[[concepts/量词]]。
