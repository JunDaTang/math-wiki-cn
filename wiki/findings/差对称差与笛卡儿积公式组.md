# 差集、对称差与笛卡儿积公式组及算例（式 5.64–5.66）

本源 5.2.2(4) 定义三种「其他集运算」：

$$A \backslash B = \{x \mid x \in A \land x \notin B\} \tag{5.64a}$$
$$A \triangle B = (A \backslash B) \cup (B \backslash A) = (A \cup B) \backslash (A \cap B) \tag{5.64c}$$
$$A \times B = \{(a, b) \mid a \in A \land b \in B\} \tag{5.65a}$$
$$(a, b) = (c, d) \Leftrightarrow a = c \vee b = d \tag{5.65b}$$
$$\operatorname{card}(A \times B) = (\operatorname{card} A)(\operatorname{card} B) \tag{5.65c}$$

以及 n 重积公式 (5.66a–b) 与 $A^n$ 记号。

**算例（均已核对）**：

- $\{1,2,3,4\} \backslash \{3,4,5\} = \{1,2\}$；
- $\{1,2,3,4\} \triangle \{3,4,5\} = \{1,2,5\}$（按 5.64c 刻画复算一致）；
- $A = \{1,2,3\}$、$B = \{2,3\}$：$A \times B$ 与 $B \times A$ 的六元列举正确，$\operatorname{card}(A \times B) = \operatorname{card}(B \times A) = 6 = 3 \times 2$，且 $A \times B \neq B \times A$；
- $\mathbb{R}^2 = \mathbb{R} \times \mathbb{R}$。

**讹误记录（引用前必读）**：

1. 式 (5.64b) 对称差定义的连接词错乱：$(x \in A \lor x \notin B) \land (x \in B \lor x \notin A)$ 在 $x \in A \cap B$ 与 $x \notin A \cup B$ 时均为真，与 (5.64c) 矛盾；正确形式应为 $(x \in A \land x \notin B) \lor (x \notin A \land x \in B)$（见 [[queries/式5-64b对称差定义连接词讹误]]）。
2. 式 (5.65b) 有序对相等的 $\lor$ 疑应为 $\land$：按原文则 $(1,2) = (1,3)$，与同节 $A \times B \neq B \times A$ 算例直接冲突（见 [[queries/式5-65b有序对相等应为合取吗]]）。

**证据强度**：算例高置信（已独立核对）；公式 (5.64a)、(5.64c)、(5.65a)、(5.65c)、(5.66) 转写正确，(5.64b)、(5.65b) 须按上述勘误后引用。
