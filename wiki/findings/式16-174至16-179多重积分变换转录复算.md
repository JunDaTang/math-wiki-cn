# 式 16.174–16.179 多重积分变换转录复算

对《数学手册(原书第10版)》16.3.5.4 第 1 条「估计多重积分」的逐式转录与复算。

## 转录

```
(16.174a) I* = ∫_a^b h(x)dx
(16.174b) I = ∫₀¹ g(x)dx  且 0⩽g(x)⩽1
(16.175)  x = a+(b-a)u,  m = min_{x∈[a,b]} h(x),  M = max_{x∈[a,b]} h(x)
(16.176)  I* = (M-m)(b-a)∫₀¹ [h(a+(b-a)u)-m]/(M-m) du + (b-a)m
(16.177)  V = ∬_S h(x,y)dxdy  且 h(x,y)⩾0
(16.178)  V* = ∬_{S*} g(u,v)dudv  且 0⩽g(u,v)⩽1
(16.179)  V* ≈ m/n
```

## 复算

- **(16.176)** 代换复算：令 x = a+(b−a)u，则 I* = (b−a)∫₀¹ h(a+(b−a)u)du；写 h = m + (M−m)·[h−m]/(M−m)，其中 g(u) := [h(a+(b−a)u)−m]/(M−m) ∈ [0,1]，展开即得 I* = (b−a)m + (M−m)(b−a)∫₀¹ g(u)du。**通过**。
- **(16.177)–(16.178)** 类比复算：体积 V 经同样的平移缩放与区域标准化后化为三维立方体内柱体 K* 的体积 V*，被积函数归一到 [0,1]。结构自洽。
- **(16.179)** 三元均匀随机数作为立方体内点坐标，m 点落入 K*，则 V* ≈ m/n，与 (16.172) 同为频率估计。正确。

## 转写疑点

- 「参见第 1103 (16.175)」——页码与式号粘连。
- 正文「 表示由不等式…所围成的平面区域」脱 S；「则可视为…圆柱体的体积」脱 V；「柱体 K*＊」有衍文符号；区间「[O,1]」为 O/0 混淆。

## 结论

变换链数学内容全部正确；源文建议一维定积分用第 1252 页 19.3 节方法，估计多重积分仍常推荐蒙特卡罗方法（19.3 未入库，见 [[queries/16-3-5未入库回指缺口]]）。
