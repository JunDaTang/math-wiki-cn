# 单调性导数符号判据（式 6.26）

## 断言

**对象**：单调性判据（6.1.4.1）。**题设**：函数 f(x) 在一连通区间上有定义且连续，并对该区间的每个内点都可微。**结论**（充要判据）：

```latex
(6.26a)  f(x) 为单调递增函数, 当且仅当 f'(x) ⩾ 0
(6.26b)  f(x) 为单调递减函数, 当且仅当 f'(x) ⩽ 0
```

## 严格单调的必要条件（来源仅述必要方向）

若函数严格单调递增或递减，则在给定区间的任意子区间上导函数 f′(x) 不恒等于 0。例如图 6.6(b) 上的线段 BC 不满足该条件。充分方向的讨论见 [[queries/严格单调与导数不恒为零是否充要]]（注：题设下的充要性为推断，非来源内容）。

## 几何意义

单调递增函数的曲线不会随自变量的增加而下降（或者上升或者沿水平方向移动，图 6.6(a)），因此曲线任意一点的切线或者与 x 轴正半轴的夹角为锐角，或者与 x 轴平行；单调递减时（图 6.6(b)）叙述类似。若函数严格单调，则具有平行于 x 轴的切线仅在某些点取得（例如图 6.6(a) 中的点 A），不可能在图 6.6(b) 那样的子区间 BC 上取得。
