# 表 3.2 五种正多边形根式性质（含复原读法）

《数学手册(原书第10版)》表 3.2「一些正多边形的性质」汇集三、五、六、八、十边形（n = 3, 5, 6, 8, 10）的 aₙ、R、r、Sₙ 根式表达。转写中根号横线与括号系统性丢失、上下标常脱落，下列为经数值复核的复原读法（每条均与式 3.51–3.56 一致）：

| n | aₙ | R | r | Sₙ |
|---|---|---|---|---|
| 3 | a₃ = R√3 = 2r√3 | R = (a₃/3)√3 = 2r = (2/3)h | r = (a₃/6)√3 = R/2 = (1/3)h | S₃ = (a₃²/4)√3 = (3R²/4)√3 = 3r²√3；高 h = (a₃/2)√3 = (3/2)R |
| 5 | a₅ = (R/2)√(10−2√5) = 2r√(5−2√5) | R = (a₅/10)√(50+10√5) = r(√5−1) | r = (a₅/10)√(25+10√5) = (R/4)(√5+1) | S₅ = (a₅²/4)√(25+10√5) = (5R²/8)√(10+2√5) = 5r²√(5−2√5) |
| 6 | a₆ = (2/3)r√3 = R | R = (2/3)r√3 | r = (R/2)√3 | S₆ = (3a₆²/2)√3 = (3R²/2)√3 = 2r²√3 |
| 8 | a₈ = R√(2−√2) = 2r(√2−1) | R = (a₈/2)√(4+2√2) = r√(4−2√2) | r = (a₈/2)(√2+1) = (R/2)√(2+√2) | S₈ = 2a₈²(√2+1)（存疑）= 2R²√2 = 8r²(√2−1) |
| 10 | a₁₀ = (R/2)(√5−1) = (2r/5)√(25−10√5) | R = (a₁₀/2)(√5+1) = (r/5)√(50−10√5) | r = (a₁₀/2)√(5+2√5) = (R/4)√(10+2√5) | S₁₀ = (5a₁₀²/2)√(5+2√5) = (5R²/4)√(10−2√5) = 2r²√(25−10√5) |

## 存疑与缺口

- **八边形面积的 a₈² 形式**：转写作「2a2/8(√2+1)」；按式 3.56 应为 2a₈²(√2+1) ≈ 4.828·a₈²，疑为下标/上标转写讹误，见 [[queries/表3-2八边形面积条目2a2是否为a8平方之误]]。
- **无正方形（n = 4）行**：三、五、六、八、十皆有而 n = 4 缺位，是原书即缺还是转写丢行待查，见 [[queries/表3-2是否原书即缺正方形行]]。
- 复原读法经数值复核与式 3.51–3.56 全部一致，但最终保真度需据原书核定（见 [[queries/表3-2根号与括号复原读法是否需据原书核定]]）；故 confidence 记为 medium、replicated 记为 null（数学内容本身已验证，转写保真度未核）。
