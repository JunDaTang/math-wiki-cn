# 式 16.62–16.65d 二项分布定义、矩、逼近与递推转录复算

对《数学手册(原书第10版)》16.2.3.1「二项分布」的全部编号公式及两条无编号性质作转录与独立复算。

## 转录

```latex
(16.62)   W_p^n(k) = \binom{n}{k} p^k (1-p)^{n-k},   k = 0,1,2,\dots,n
(16.63)   P(A) = M/N = p,   P(\bar A) = (N-M)/N = 1-p = q
(16.64)   \binom{n}{k} = \frac{n!}{k!\,(n-k)!}
(16.65a)  E(X_n) = \mu = np
(16.65b)  D^2(X_n) = \sigma^2 = np(1-p)
(16.65c)  \lim_{n\to\infty} P\!\left(\frac{X_n - E(X_n)}{D(X_n)} \le \lambda\right)
              = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{t} \exp\!\left(-\frac{t^2}{2}\right) \mathrm{d}t
(16.65d)  W_p^n(k+1) = \frac{n-k}{k+1} \cdot \frac{p}{q} \cdot W_p^n(k)
无编号：   X_n ~ B(n,p), X_m ~ B(m,p)  ⇒  X_n + X_m ~ B(n+m, p)
```

## 复算

1. **归一化**：$\sum_{k=0}^n \binom{n}{k} p^k q^{n-k} = (p+q)^n = 1$（二项定理），与分布名称相印证。✔
2. **矩 (16.65a–b)**：与标准结果 E=np、Var=np(1−p) 一致。✔
3. **递推 (16.65d)**：$W(k+1)/W(k) = \frac{\binom{n}{k+1}}{\binom{n}{k}}\cdot\frac{p}{q} = \frac{n-k}{k+1}\cdot\frac{p}{q}$，代数推导验证正确。✔
4. **正态逼近 (16.65c)**：命题本身成立（标准化二项变量依分布收敛于 N(0,1)），但原文左端「≤ λ」与右端积分上限 t 不一致，左端疑为 t——属转写问题而非数学错误，见[[queries/式16-65c左端λ与右端t不一致之辨]]。⚠
5. **正文单项概率**：原文推导段作 $p^k(n-p)^{n-k}$，与 (16.63) 的 $q=1-p$ 直接矛盾（0<p<1 时 n−p 可大于 1，不能作概率底数），可证为讹误，应为 $p^k(1-p)^{n-k}$，见[[queries/正文p的k次n减p之n减k次疑为1减p]]。⚠
6. **可加性（无编号）**：B(n,p)+B(m,p)=B(n+m,p) 为标准结果，但须以 X_n、X_m 相互独立为前提；原文未声明独立性（泊松分布对应条目则明确声明），引用时应补此条件。⚠

## 证据强度

定义、矩、递推为可复算的确定性数学内容（直接证据，强）；正态逼近的适用条件（n 大、np>4、n(1−p)>4 等）属手册经验法则且转写可疑（间接证据，中），核对原书前不应作为定论引用。
