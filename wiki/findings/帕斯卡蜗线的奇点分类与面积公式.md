# 帕斯卡蜗线的奇点分类与面积公式（式 2.235）

**主张。**
- a < l：原点为孤立点；
- a > l：原点为二重点，切线斜率 $\tan\alpha = \pm\frac{\sqrt{a^2-l^2}}{l}$，曲率半径 $r_0 = \frac{1}{2}\sqrt{a^2-l^2}$；
- a = l：原点为尖点，该曲线即心脏线；
- 面积 $S = \frac{\pi a^2}{2} + \pi l^2$，其中 a > l 时内部环形的面积要计算两次（图 2.63(c)）。

**验证（已验证，独立复推）。**
- 切线斜率：隐式方程 $(x^2+y^2-ax)^2 = l^2(x^2+y^2)$ 在原点的最低次项为 $a^2x^2 - l^2(x^2+y^2) = 0$，给出 $y = \pm x\sqrt{a^2-l^2}/l$，吻合 tan α。
- r₀：极点曲率公式 $r_0 = |\rho'(\varphi_0)|/2$，$\rho = a\cos\varphi + l$ 过极点于 $\cos\varphi_0 = -l/a$（a > l 时两解，即二重点），$|\rho'(\varphi_0)| = |{-a}\sin\varphi_0| = \sqrt{a^2-l^2}$，故 $r_0 = \frac{1}{2}\sqrt{a^2-l^2}$。
- 面积：$S = \frac{1}{2}\int_0^{2\pi}(a\cos\varphi + l)^2\,d\varphi = \frac{1}{2}(\pi a^2 + 2\pi l^2) = \frac{\pi a^2}{2} + \pi l^2$。
- 内环注记：a > l 时 $\rho$ 在 $\varphi = \pi$ 附近变号，曲线自交形成内环；极坐标面积积分按环绕次数计权，把内环区域计入两次，手册因此注明。

**奇点方向。** 与尼科梅德斯蚌线相反（那里 l > a 才是二重点），机制见 [[comparisons/尼科梅德斯蚌线与帕斯卡蜗线奇点分类比较]] 的极径零点分析。
