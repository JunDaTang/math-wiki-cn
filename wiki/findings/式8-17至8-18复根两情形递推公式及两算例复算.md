# 复根两情形公式与降阶递推及两算例（式 8.17–8.18，已复算）

**来源**：[[sources/10-数学手册原书第10版--11-813-有理函数的积分--1lrte2m]] 之 8.1.3.3 情形 3–4。前提：Q(x) 的系数均为实数，故复根成共轭对出现，每对合并为一个不可约二次因式。

## 情形 3：分母的某些根为单复根（式 8.17a–d）

分母形状与不可约条件：

```latex
Q(x) = (x-\alpha)^l (x-\beta)^m \dots (x^2+px+q)(x^2+p'x+q') \dots \tag{8.17a}
\frac{p^2}{4} < q,\quad \frac{p'^2}{4} < q',\; \dots \tag{8.17b}
```

分解形式：

```latex
\frac{P(x)}{Q(x)} = \frac{A_1}{x-\alpha} + \frac{A_2}{(x-\alpha)^2} + \dots + \frac{A_l}{(x-\alpha)^l}
+ \frac{B_1}{x-\beta} + \frac{B_2}{(x-\beta)^2} + \dots + \frac{B_m}{(x-\beta)^m}
+ \frac{Cx+D}{x^2+px+q} + \frac{Ex+F}{x^2+p'x+q'} + \dots \tag{8.17c}
```

积分公式：

```latex
\int\frac{(Cx+D)\,\mathrm{d}x}{x^2+px+q}
= \frac{C}{2}\ln|x^2+px+q|
+ \frac{D - Cp/2}{\sqrt{q - p^2/4}} \arctan\frac{x + p/2}{\sqrt{q - p^2/4}} \tag{8.17d}
```

复算（式 8.17d）：令 u = x + p/2，则 x²+px+q = u² + a²（a² = q − p²/4 > 0），Cx+D = Cu + (D − Cp/2)；逐项积分得 (C/2)ln(u²+a²) + (D−Cp/2)·(1/a)arctan(u/a)。✅

## 情形 4：分母中某些根为多重复根（式 8.18a–e）

分母形状：

```latex
Q(x) = (x-\alpha)^k (x-\beta)^l \dots (x^2+px+q)^m (x^2+p'x+q')^n \dots \tag{8.18a}
```

分解形式：

```latex
\frac{P(x)}{Q(x)} = \frac{A_1}{x-\alpha} + \frac{A_2}{(x-\alpha)^2} + \dots + \frac{A_k}{(x-\alpha)^k}
+ \frac{B_1}{x-\beta} + \frac{B_2}{(x-\beta)^2} + \dots + \frac{B_l}{(x-\beta)^l}
+ \frac{C_1 x + D_1}{x^2+px+q} + \frac{C_2 x + D_2}{(x^2+px+q)^2} + \dots + \frac{C_m x + D_m}{(x^2+px+q)^m}
+ \frac{E_1 x + F_1}{x^2+p'x+q'} + \frac{E_2 x + F_2}{(x^2+p'x+q')^2} + \dots + \frac{E_n x + F_n}{(x^2+p'x+q')^n} \tag{8.18b}
```

m > 1 时按三步计算 (C_m x + D_m)/(x²+px+q)^m 的积分（子步骤编号原文损坏为 "a) / 6) / Y)"，应为 α) / β) / γ)，见 [[queries/8-1-3全节系统性转写讹误清单]]）：

```latex
C_m x + D_m = \frac{C_m}{2}(2x+p) + \left(D_m - \frac{C_m p}{2}\right) \tag{8.18c}
\int \frac{C_m}{2}\frac{(2x+p)\,\mathrm{d}x}{(x^2+px+q)^m} = -\frac{C_m}{2(m-1)}\frac{1}{(x^2+px+q)^{m-1}} \tag{8.18d}
\int\frac{\mathrm{d}x}{(x^2+px+q)^m} = \frac{x+p/2}{2(m-1)(q-p^2/4)(x^2+px+q)^{m-1}}
+ \frac{2m-3}{2(m-1)(q-p^2/4)}\int\frac{\mathrm{d}x}{(x^2+px+q)^{m-1}} \tag{8.18e}
```

**递推公式 8.18e 的独立推导**（复算核心）：令 u = x + p/2、a² = q − p²/4 > 0，则左端化为 ∫du/(u²+a²)^m。由 d/du[u/(u²+a²)^{m−1}] = [a² − (2m−3)u²]/(u²+a²)^m 整理可得标准降阶公式：

```latex
\int\frac{\mathrm{d}u}{(u^2+a^2)^m} = \frac{u}{2a^2(m-1)(u^2+a^2)^{m-1}}
+ \frac{2m-3}{2a^2(m-1)}\int\frac{\mathrm{d}u}{(u^2+a^2)^{m-1}}
```

代回 u = x+p/2、a² = q−p²/4 即得 8.18e，**确认无误**。✅ 递推每用一次 m 降 1，有限步后落到 m = 1（情形 3 的式 8.17d），故算法对任意重复度的复根封闭。

## 算例 3（情形 3）：I = ∫4dx/(x³+4x)

分解与待定系数（原文数值逐字）：

```latex
\frac{4}{x^3+4x} = \frac{A}{x} + \frac{Cx+D}{x^2+4},\qquad
A + C = 0,\; D = 0,\; 4A = 4 \;\Rightarrow\; A = 1,\; C = -1,\; D = 0
```

结果（原文逐字）：

```latex
I = \int\left(\frac{1}{x} - \frac{x}{x^2+4}\right)\mathrm{d}x
= \ln|x| - \frac{1}{2}\ln(x^2+4) + \ln|C_1|
= \ln\left|\frac{C_1 x}{\sqrt{x^2+4}}\right|
```

手册指出："在这种特殊情况中，arctan 这一项为 0。"复算：此处 p = 0、q = 4，式 8.17d 的 arctan 项系数 D − Cp/2 = 0 − 0 = 0，故该项消失；因式分解 x(x²+4) 与系数回代均无误。✅ **通过**。

## 算例 4（情形 4）：I = ∫(2x²+2x+13)dx/((x−2)(x²+1)²)

分解设定（原文逐字）：

```latex
\frac{2x^2+2x+13}{(x-2)(x^2+1)^2} = \frac{A}{x-2} + \frac{C_1 x + D_1}{x^2+1} + \frac{C_2 x + D_2}{(x^2+1)^2}
```

待定系数方程组（原文逐字）：

```latex
A + C_1 = 0,\quad -2C_1 + D_1 = 0,\quad 2A + C_1 - 2D_1 + C_2 = 2,\\
-2C_1 + D_1 - 2C_2 + D_2 = 2,\quad A - 2D_1 - 2D_2 = 13
```

解得 A = 1, C₁ = −1, D₁ = −2, C₂ = −3, D₂ = −4。递推（p = 0、q = 1、m = 2 用式 8.18e，原文逐字）：

```latex
\int\frac{\mathrm{d}x}{(x^2+1)^2} = \frac{x}{2(x^2+1)} + \frac{1}{2}\int\frac{\mathrm{d}x}{x^2+1} = \frac{x}{2(x^2+1)} + \frac{1}{2}\arctan x
```

最终结果（原文逐字）：

```latex
I = \frac{3-4x}{2(x^2+1)} + \frac{1}{2}\ln\frac{(x-2)^2}{x^2+1} - 4\arctan x + C
```

复算：
- 方程组：通分后分子为 A(x²+1)² + (C₁x+D₁)(x−2)(x²+1) + (C₂x+D₂)(x−2)，比较系数即得上述五式；✅
- 系数回代：A=1, C₁=−1, D₁=−2, C₂=−3, D₂=−4 时分子 = (x⁴+2x²+1) + (−x⁴+3x²+4) + (−3x²+2x+8) = 2x²+2x+13；✅
- 积分：I = ∫[1/(x−2) − (x+2)/(x²+1) − (3x+4)/(x²+1)²]dx = ln|x−2| − ½ln(x²+1) − 2arctan x + 3/(2(x²+1)) − 2x/(x²+1) − 2arctan x + C，合并即得最终结果。✅ **通过**。

## 复算方法与状态

- 复算手段：对最终结果求导回代、分解式通分回代、递推公式独立推导（配平方 u = x+p/2）。
- 本页两算例与式 8.17d、8.18c–e 均通过，未发现数学错误。
