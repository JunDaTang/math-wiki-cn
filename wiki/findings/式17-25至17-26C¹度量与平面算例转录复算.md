# 式 17.25–17.26 C¹ 度量与平面算例转录复算

**结论**：手册 17.1.4.1 的式 (17.25)（C¹ 度量）与式 (17.26)（平面算例 g(·,α)）转录无误，且关键数值断言经独立复算全部通过。

## 转录内容

```
(17.25)  ρ(f, g) = sup_{x∈U} ‖f(x) − g(x)‖ + sup_{x∈U} ‖Df(x) − Dg(x)‖
X₊¹(U)：grad h(x)ᵀ f(x) ≠ 0 (x ∈ ∂U) 且 φᵗ(x) ∈ U (x ∈ ∂U, t > 0)
(17.26)  ẋ = −y + x(α − x² − y²),  ẏ = x + y(α − x² − y²),  |α| < 1
         U = {(x,y) : x² + y² < 2}；ρ(g(·,0), g(·,α)) = |α(√2 + 1)|
```

## 复算过程（直接证据）

1. **极坐标化**：x = r cos θ, y = r sin θ 时 ṙ = r(α − r²) = −r³ + αr，θ̇ = 1（原文角变量作 v，疑为 θ，见 [[queries/式17-26极坐标角变量v疑为theta之辨]]）。
2. **C¹ 距离**：g(·,α) − g(·,0) = (αx, αy)，故 sup_{x²+y²<2} ‖(αx,αy)‖ = √2|α|（在半径 √2 的边界处取到上确界）；雅可比之差为 αI，算子范数 |α|；合计 ρ = √2|α| + |α| = |α|(√2+1)。与手册一致。
3. **边界内向**：∂U 上 r = √2，ṙ = √2(α−2) < 0（因 |α|<1），流沿边界严格向内，故 g(·,α) ∈ X₊¹(U)。
4. **极限环**：ṙ = 0 给出 r = 0 或 r = √α（α>0）；r<√α 时 ṙ>0、r>√α 时 ṙ<0，故 r=√α 为稳定极限环，θ̇=1 使轨道绕行。
5. **结构不稳定机制**：α=0 时原点雅可比 [[0,−1],[1,0]] 的特征值为 ±i（纯虚，非双曲）；α 由 0 变正时原点变为不稳定焦点并产生极限环，轨道拓扑改变，故存在任意靠近 g(·,0) 却与之不拓扑等价的向量场（g(·,α) 即为其一）。

## 与 AP 定理的交叉验证

g(·,0) 违反 [[concepts/安德罗诺夫—蓬特里亚金定理|AP 定理]]条件 a（平衡点非双曲），与「结构不稳定」的结论一致——定义层面与定理层面互相印证。

复算方法复用 [[methodology/自治微分方程极坐标化求解与极限集核算流程]] 与 [[methodology/C¹度量距离与边界内向横截核算流程]]。
