# 式 11.47 与 sin 权奇异核算例对角化与反演公式复算

## 转录

算例（11.3.3）：在柯西主值意义上理解积分

$$
f(x)=\frac{1}{\pi}\int_0^{\pi}\frac{\sin y}{\cos y-\cos x}\,\varphi(y)\,\mathrm{d}y,\quad 0\leqslant x\leqslant\pi
$$

取规范正交系：α₀(x) = 1/√π，α_i(x) = √(2/π)cos ix（i = 1,2,…）；β_j(y) = √(2/π)sin jy（j = 1,2,…）。核矩阵系数经内积分（枢纽恒等式）

$$
\int_0^{\pi}\frac{\cos ix}{\cos y-\cos x}\,\mathrm{d}x=-\pi\frac{\sin iy}{\sin y}\tag{11.47}
$$

得 K₀j = 0，K_ij = 0（i ≠ j）、−1（i = j）。可解条件 f₀ = (1/√π)∫₀^π f(x)dx = 0；此时 c_j = −f_j，并且

$$
\varphi(y)=-\sqrt{\tfrac{2}{\pi}}\sum_{j=1}^{\infty}f_j\sin jy=\frac{1}{\pi}\int_0^{\pi}\frac{\sin y}{\cos y-\cos x}\,f(x)\,\mathrm{d}x
$$

## 复算（独立验证，全部通过）

- **(11.47) 恒等式**：数值抽查通过（如 i = 1、y = π/2 时两侧均为 −π；i = 2、y = π/2 时两侧均为 0）；它是有限区间希尔伯特变换型核的经典主值积分恒等式，是本算例全部计算的枢纽。
- **K₀j = 0**：即 (11.47) 取 i = 0 的情形（右端 sin 0 = 0）。✓
- **K_ij = −δ_ij**：K_ij = (2/π²)∫₀^π sin y sin(jy)·[−π sin(iy)/sin y]dy = −(2/π)∫₀^π sin(iy)sin(jy)dy = −δ_ij（用 ∫₀^π sin(iy)sin(jy)dy = (π/2)δ_ij）。✓
- **可解条件与系数**：无穷方程组第一行 0 = f₀ 给出 f₀ = 0；第 i 行 −c_i = f_i 给出 c_j = −f_j。✓
- **反演公式**：f_j = √(2/π)∫₀^π f(x)cos(jx)dx，故 φ(y) = −(2/π)∫₀^π f(x)Σ_{j⩾1}sin(jy)cos(jx)dx；由恒等式 Σ_{j⩾1}sin(jy)cos(jx) = −sin y/(2(cos y − cos x))（可由 Σsin 与 Σcos 的经典公式导出）得 φ(y) = (1/π)∫₀^π [sin y/(cos y − cos x)]f(x)dx。**独立推导确认**。✓

## 发现与注记

1. 可解条件 f₀ = 0 即 f 与常数正交，而常数正是该核**伴随**齐次方程的解（零行 K₀j = 0 ⟺ T*α₀ = 0）——[[concepts/积分方程的正交可解性条件]] 的第一类体现；同时由 K_ij = −δ_ij 与 {β_j} 完备可推得**原齐次方程仅有平凡解**（详见 [[findings/式11-48a至11-50e齐次与伴随齐次解法及算例转录复算]]）。
2. 转写疑误：矩阵显示式中右端向量有 4 个分量（f₀,…,f₃）而矩阵仅显示 3 行；「(其 i, j = 1, 2, ⋯)®」含残字；规范正交系定义后有孤行「1, 2, …)」——均录入 [[queries/11-3全节系统性转写讹误清单]]。
