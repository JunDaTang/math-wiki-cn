# 式 19.99 四阶龙格—库塔格式与算例复算

**转录**（源文计算格式表逐字保留）：

| x | y | k = h·f(x, y) |
|---|---|---|
| x₀ | y₀ | k₁ |
| x₀ + h/2 | y₀ + k₁/2 | k₂ |
| x₀ + h/2 | y₀ + k₂/2 | k₃ |
| x₀ + h | y₀ + k₃ | k₄ |
| x₁ = x₀ + h | y₁ = y₀ + 1/6(k₁ + 2k₂ + 2k₃ + k₄) | |

源文算例：y′ = ¼(x² + y²)，y(0) = 0，单步 h = 0.5 求 y(0.5)：

| x | y | k = (1/8)(x² + y²) |
|---|---|---|
| 0 | 0 | 0 |
| 0.25 | 0 | 0.00781250 |
| 0.25 | 0.00390625 | 0.00781441 |
| 0.5 | 0.00781441 | 0.03125763 |
| 0.5 | y₁ = 0.01041858（源文称准确值 0.01041860） | |

**复算（独立验证，通过）**：

- k₂ = (1/8)(0.25² + 0) = 0.0078125；k₃ = (1/8)(0.25² + 0.00390625²) = 0.0078144074；k₄ = (1/8)(0.5² + 0.00781441²) = 0.0312576331。
- y₁ = (0 + 2×0.0078125 + 2×0.0078144074 + 0.0312576331)/6 = 0.06251145/6 = 0.010418575，与源文 0.01041858 一致。
- “准确值”经幂级数独立验证：真解 y(x) = x³/12 + x⁷/4032 + ⋯，y(0.5) ≈ 0.010418605，与源文 0.01041860 一致。

**归属结论**：四阶龙格—库塔法每步误差 h⁵ 阶、四阶收敛与四阶相容；对 y′ = f(x) 化为辛普森公式（19.3.2.3，未入库）——源文断言，结构上可直接验证。见 [[concepts/龙格—库塔法（四阶）]]。
