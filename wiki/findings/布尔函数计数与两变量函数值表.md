# 布尔函数计数与两变量函数值表（表 5.6）

## 计数（含更正）

$n$ 重布尔函数（$B^n\to B$，$B=\{0,1\}$）共有 $2^{2^n}$ 个。

**转写讹误**：正文转写为「$2^n$ 个 $n$ 重布尔函数」，但源自证 $n=2$ 时存在 16 个（$2^2=4\neq 16$，$2^{2^2}=16$ ✓），且 $n=1$ 时式 (5.308) 列出 4 个函数（$2^{2^1}=4$ ✓）。故原文必为 $2^{2^n}$，详见 [[queries/布尔函数个数是否应为2的2的n次方]]。

## n=1 的四个函数（式 5.308，含更正）

恒等 $f(b)=b$；否定 $f(b)=\bar b$；重言 $f(b)=1$；矛盾 $f(b)=0$。

**转写讹误**：重言与矛盾两式均被讹抄为 $f(b)=b$，与「恒等」重复且自相矛盾；另「存在 个布尔函数」的个数 4 亦脱落。详见 [[queries/式5-308重言与矛盾式是否应为1与0]]。

## n=2 的 16 个函数与表 5.6（值表已全部复算无误）

```
函数名称          不同的记号                              值表 (a,b) = (0,0),(0,1),(1,0),(1,1)
Sheffer 或 NAND   (a·b) 的否定,  a|b,  NAND(a,b)          1, 1, 1, 0
Peirce 或 NOR     (a+b) 的否定,  a↓b,  NOR(a,b)           1, 0, 0, 0
反等价或 XOR      āb+ab̄ [更正],  a XOR b,  a≠b,  a⊕b      0, 1, 1, 0
等价              āb̄+ab [更正],  a≡b,  a↔b                1, 0, 0, 1
蕴涵              ā+b,  a→b                               1, 1, 0, 1
```

XOR 与等价两行的转写公式分别为 $\overline{ab}+a\bar b$ 与 $\overline{ab}+ab$，否定号位置抄错（与自身值表不符）；更正为 $\bar ab+a\bar b$ 与 $\bar a\bar b+ab$ 后逐点吻合，详见 [[queries/表5-6中xor与等价的否定号位置是否抄错]]。表 5.6 的「不同的符号」列在转写中为空（疑为电路符号，原图不可核验）。系统对照见 [[comparisons/五种两变量布尔函数比较]]。

## 逐点运算与常值函数（式 5.304–5.307，转写基本完整）

$(f\sqcap g)(b)=f(b)\sqcap g(b)$、$(f\sqcup g)(b)=f(b)\sqcup g(b)$、$\bar f(b)=\overline{f(b)}$；$n$ 重布尔函数集合成布尔代数；$f_0(b)=0$、$f_1(b)=1$ 对所有 $b\in B^n$。

## 证据性质

- 五组值表全部逐点复算无误（直接复算，replicated: true）。
- 计数更正与否定号更正为对原文的推断，但均有源内自证（「16 个」、值表本身）支撑。
