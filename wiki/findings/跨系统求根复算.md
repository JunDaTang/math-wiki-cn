# 跨系统求根复算

## 摘要

手册在 Matlab（roots、fzero）、Mathematica（NSolve）、Maple（fsolve）三小节对同一组方程求根；本发现转录三方输出并独立复算，证实三系统结果一致。这是三系统同题互证的核心证据（[[comparisons/Matlab-Mathematica-Maple同题数值比较]]）。

## 问题 1：x⁶ + 3x² − 5 = 0

```txt
Matlab:        >> p = [1 0 0 0 3 0 -5];  roots(p)
               ans = 0.8673+1.1529i, 0.8673-1.1529i, 1.0743,
                    -0.8673+1.1529i, -0.8673-1.1529i, -1.0743
               >> polyval(p,1)  ans = -1      >> polyder(p)  ans = 6 0 0 0 6 0
Mathematica:   In[1] := NSolve[x^6 + 3x^2 - 5 == 0]
               Out[1] = {x -> -1.07432}, {x -> -0.867262 - 1.15292 I},
                    {x -> -0.867262 + 1.15292 I}, {x -> 0.867262 - 1.15292 I},
                    {x -> 0.867262 + 1.15292 I}, {x -> 1.07432}
Maple:         > eq := x^6 + 3*x^2 - 5 = 0
               > fsolve(eq, x);                 -1.074323739, 1.074323739
               > fsolve(eq, x, complex);        -1.074323739, -0.8672620244 ± 1.152922012 I, …
```

复算：令 t=x²，方程化为 t³+3t−5=0。实根 t₁≈1.1542，故 x=±√t₁=±1.0743；另两根 t₂,₃=−0.5771±1.9998i，x=±√t₂ 得 ±(0.867±1.153i)——与三系统输出在手算精度内一致。polyval(p,1)=1+3−5=−1 ✓；polyder 对应 6x⁵+6x → [6 0 0 0 6 0] ✓。**三系统互证、复算证实**。

注：Matlab 的 roots 将根作为系数向量对应伴随矩阵的特征值确定（据本源）；Maple 例 A 正文作「x⁶+3x³−5=0」，与命令 x^6+3*x^2−5 矛盾，三系统根值证实为 3x²（[[queries/Maple例A之3x3疑为3x2之辨]]）。

## 问题 2：e^(−x³) − 4x² = 0

```txt
Matlab:   >> fzero(@(x)exp(-x^3) - 4*x^2, 1)    ans = 0.4741
          >> fzero(@(x)exp(-x^3) - 4*x^2, 0)    ans = -0.5413
          >> fzero(@(x)exp(-x^3) - 4*x^2, -1)   ans = -1.2085
Maple:    > eq := exp(-x^3) - 4*x^2 = 0
          > fsolve(eq, x);                0.4740623572
          > fsolve(eq, x, x = -2..0);     -0.5412548544
```

复算（逐一代入）：
- x=0.4741：e^(−0.10658)=0.89891，4x²=0.89908，相对偏差约 2×10⁻⁴ ✓；
- x=−0.5413：e^(0.15860)=1.17188，4x²=1.17200 ✓；
- x=−1.2085：e^(1.76458)=5.8394，4x²=5.8419，相对偏差约 4×10⁻⁴（与手册只给 4 位的舍入一致）✓。

两系统结果相互一致（0.4741 ↔ 0.4740623572；−0.5413 ↔ −0.5412548544）；Maple 本例仅求两解，Matlab fzero 自三个初值得三解（每次一解、依赖初值）。**复算证实**。
