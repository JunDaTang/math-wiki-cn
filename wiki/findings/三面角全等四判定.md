# 三面角全等四判定

**直接证据**（源文 3.3.2(3)）：两个三面角如果有下列元素重合就是全等的：

1. **两个面和对应的二面角**（SAS 型）；
2. **一个面和属于它的两个二面角**（ASA 型）；
3. **按相同顺序排列的三个对应的面**；
4. **按相同顺序排列的三个对应的二面角**。

**与平面三角形全等定理的对照**（[[findings/三角形全等定理四条]]：SSS/SAS/ASA/SSA）：前三条与 SSS/SAS/ASA 逐条平行，但第 3 条「同序三面」在平面的对应物 AAA **不能**判定三角形全等。**独立可核背景**：三维中三面角的三个面角互相制约（任一面角小于其余两面角之和，且面角和 < 360°），故「三面」足以锁定三面角；平面上三个内角仅受内角和 = 180° 约束、可自由变动，AAA 不能锁定三角形。第 4 条（同序三二面角）在平面无对应物（平面角没有「二面角」构件）。

**转写注**：本段「属千它的两个二面角」即「属于它的两个二面角」（千/于讹变）。本条为定理陈述，未做独立重推。
