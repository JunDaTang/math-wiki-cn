# 循环分部积分与多项式降次两情形（8.1.6.3）

## 原文转录（8.1.6.3，无编号公式，讹误按语义复原并以方括号标注）

1. 普通情形：「若被积函数为对数函数、反三角函数、反双曲函数、$x^{m}$ 与 $\ln x$、$\mathrm{e}^{\alpha x}$、$\sin ax$、$\cos ax$ 及其反函数的乘积，则可利用一次或多次分部积分进行计算。」
2. 循环情形：「有些情况下反复分部积分会得到与原积分相同类型的积分，此时必须解关[于]该表达式的代数方程。例如对[于]积分 $\int \mathrm{e}^{ax}\cos bx\,\mathrm{d}x$、$\int \mathrm{e}^{ax}\sin bx\,\mathrm{d}x$ 可利用这种方法计算，要用两次分部积分。不论指数函数还是三角函数，在上述两步中都要根据因子选择相同类型的函数。」
3. 多项式情形：「对[于]形如 $\int P(x)\mathrm{e}^{ax}\mathrm{d}x$、$\int P(x)\sin bx\,\mathrm{d}x$ 和 $\int P(x)\cos bx\,\mathrm{d}x$ 的积分，其中 $P(x)$ 为多项式，也可用分部积分来计算（令 $u = P(x)$，在每一步多项式都会降次）。」

（「对千」=「对于」、「解关千」=「解关于」；「代数方程例如」「分部积分不论」两处标点丢失，见 [[queries/8-1-6全节系统性转写讹误清单]]。）

## 复算：循环情形

设 $I = \int \mathrm{e}^{ax}\cos bx\,\mathrm{d}x$（$a \neq 0$）。两步均取 $\mathrm{d}v = \mathrm{e}^{ax}\mathrm{d}x$（指数因子，一致选择）。

第一次（$u = \cos bx$）：

$$I = \frac{1}{a}\mathrm{e}^{ax}\cos bx + \frac{b}{a}\int \mathrm{e}^{ax}\sin bx\,\mathrm{d}x$$

第二次（对 $\int\mathrm{e}^{ax}\sin bx\,\mathrm{d}x$ 取 $u = \sin bx$）：

$$\int \mathrm{e}^{ax}\sin bx\,\mathrm{d}x = \frac{1}{a}\mathrm{e}^{ax}\sin bx - \frac{b}{a}I$$

代回并移项，解关于 $I$ 的代数方程 $(a^{2}+b^{2})\,I = \mathrm{e}^{ax}(a\cos bx + b\sin bx)$，得

$$I = \frac{\mathrm{e}^{ax}\left(a\cos bx + b\sin bx\right)}{a^{2}+b^{2}} + C \qquad (\text{复算补充，非原文内容})$$

同法得 $\int \mathrm{e}^{ax}\sin bx\,\mathrm{d}x = \frac{\mathrm{e}^{ax}(a\sin bx - b\cos bx)}{a^{2}+b^{2}} + C$。

**一致性规则的复算印证**：若第二次改取 $\mathrm{d}v$ 为三角因子（与第一次不一致），则第二次分部恰好抵消第一次的作用，得 $I = I$，无信息增益——与原文「两步中都要根据因子选择相同类型的函数」一致。

## 复算：多项式降次情形

对 $\int P(x)\mathrm{e}^{ax}\mathrm{d}x$ 取 $u = P(x)$、$\mathrm{d}v = \mathrm{e}^{ax}\mathrm{d}x$：

$$\int P(x)\mathrm{e}^{ax}\mathrm{d}x = \frac{1}{a}\mathrm{e}^{ax}P(x) - \frac{1}{a}\int P'(x)\,\mathrm{e}^{ax}\mathrm{d}x$$

多项式每步降次一次，$\deg P$ 步后导数为零、积分终止（可整理为 $\frac{\mathrm{e}^{ax}}{a}\left[P(x) - \frac{P'(x)}{a} + \frac{P''(x)}{a^{2}} - \cdots\right] + C$，复算补充）。对 $\int P(x)\sin bx\,\mathrm{d}x$、$\int P(x)\cos bx\,\mathrm{d}x$ 同理：$u = P(x)$，分部后同型积分以降次一次的多项式重现，有限步终止。

## 判定

- 三段陈述与标准结果一致，证据强度高；但本节无编号公式，循环法「一致性规则」的精确表述因转写标点丢失需查原书复原。
- 上述闭式结果均为**复算补充**，仅用于验证方法有效性，非原文内容。
- 归属边界：降次终止性只属于多项式因子情形；循环法属于 $\mathrm{e}^{ax}\times$ 三角乘积情形；两类条件不可互挪。
