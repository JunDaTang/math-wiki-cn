# 三元线性丢番图方程归约算例 2x+4y+3z=3

**主张**：方程 2x+4y+3z=3（式 5.243a）可用归约方法完整求解，解集为 {(3−3t+2s, −3+3t−s, 3−2t) | s,t∈ℤ}。本页对该算例全程独立复算，全部通过，参数化完备。

## 归约过程复算

1. **可解性**：gcd(2,4,3)=1 ∣ 3，方程可解。✓
2. **固定 z**：把 z 看作整常数，2x+4y = 3−3z（式 5.243b）当且仅当 gcd(2,4)=2 是 3−3z 的因子时可解，即 2 ∣ 3−3z ⟺ 3z 为奇 ⟺ **z 为奇数**。
3. **条件二元方程**：手册解 2z′+3z=3（z′ 扮演式 (5.242d) 中的 c），给出解集 {(−3+3t, 3−2t) | t∈ℤ}。复算：2(−3+3t)+3(3−2t) = (−6+6t)+(9−6t) = 3 ✓；且 z = 3−2t 当 t 遍历 ℤ 时恰遍历**全部奇整数**，与第 2 步的可解性条件严丝合缝。✓
4. **代回**：以 z = 3−2t 代入 (5.243b) 得 2x+4y = 3−3(3−2t) = −6+6t。⚠️ 转写正文此处作「2x+4y = 3−3(2t)」，与其后的 x+2y=−3+3t 不相容，正确中间式应为 −6+6t（即 3−3(3−2t)）；见 [[queries/式5-243中间式3-3-2t是否应为-6+6t]]。
5. **除以 2**：x+2y = −3+3t（式 5.243c）。gcd(1,2)=1 ∣ −3+3t，故对每个 t 可解。✓
6. **贝祖组合与特解**：1·(−1)+2·1 = 1（转写「=1 2以及」中的「2」为衍文），乘以 b′=−3+3t 得特解 (3−3t, −3+3t)。复算：1·(3−3t)+2·(−3+3t) = (3−3t)+(−6+6t) = −3+3t ✓（与书中验证式一致）。
7. **通解**：按 (5.241b)（a₁′=1, a₂′=2，此处约化系数使用正确）：{(3−3t+2s, −3+3t−s) | s∈ℤ}。

## 最终解集与完备性验证

- **解集**：{(3−3t+2s, −3+3t−s, 3−2t) | s,t∈ℤ}。
- **代入恒等**：2(3−3t+2s) + 4(−3+3t−s) + 3(3−2t) = (6−6t+4s) + (−12+12t−4s) + (9−6t) = 3 ✓（s、t 项全部消去）。
- **参数化完备**：第三个分量 3−2t 恰遍历全部奇整数（即可解性要求的 z 的全部容许值，无一遗漏）；对每个固定的 z，方程化为 x+2y = (3−3z)/2，其全部整数解由参数 s 给出。自由参数个数 2 = n−1 ✓。

## 备注

本算例同时充当两件事的实证：(i) 归约方法（[[methodology/多元线性丢番图方程归约求解流程]]）的可行性演示；(ii) 式 (5.241b) 使用**约化系数**的正确范例——对照 114x+315y=6 例题的解集讹误（[[findings/二元线性丢番图方程通解与114x315y6算例]]）。
