# 式 14.63–14.68 代数函数定义与例转录复算

## 转录内容

```latex
a_1 z^{m_1} w^{n_1} + a_2 z^{m_2} w^{n_2} + \dots + a_k z^{m_k} w^{n_k} = 0   (14.63)
线性函数:     w = az + b                            (14.64)
反函数:       w = 1/z                               (14.65)
二次函数:     w = z^2                               (14.66)
平方根函数:   w = \sqrt{z^2 - a^2}                  (14.67)
分式线性函数: w = (z + \mathrm{i})/(z - \mathrm{i})  (14.68)
```

## 复算过程与结论

- **(14.63)**：隐式定义的一般形式，与实情形一致，为定义性陈述。
- **(14.64)**：$w = az + b$ 满足 $w - az - b = 0$，属 (14.63) 型（$m = 1, n = 1$ 及常数项）✓。
- **(14.65)**：$w = 1/z$ 满足 $zw - 1 = 0$ ✓。
- **(14.66)**：$w = z^2$ 满足 $w - z^2 = 0$ ✓。
- **(14.67)**：$w = \sqrt{z^2 - a^2}$ 满足 $w^2 - (z^2 - a^2) = 0$，即 $z^2 - a^2 - w^2 = 0$，属 (14.63) 型（两项 $z^2 w^0$ 与 $z^0 w^2$ 加常数项）✓。该函数双值（两个平方根分支）。
- **(14.68)**：$w = (z+\mathrm{i})/(z-\mathrm{i})$ 满足 $(z-\mathrm{i})w - (z+\mathrm{i}) = 0$ ✓。

**结论**：转录与复算全部一致，本组未发现数学性讹误。

## 证据强度与归属

- 本组为标准初等内容，可独立推导，证据强度高。
- “$w$ 不能被显式地表示时有发生”是源文对一般代数函数的断言，不针对五个例子。
- 直接证据与推断之分：14.67 的双值性、14.68 的映射性质（如将实轴映为单位圆周）为复算附注（标准理论），源文未展开讨论。
