# 生产计划算例解点 (25, 35) 复算

对 18.1.1.2 生产计划算例进行复算，确认手册给出的解点 (x₁, x₂) = (25, 35) 与水平线 20x₁ + 60x₂ = 2600 正确无误，算例数值自洽。

## 算例数据（verbatim）

表 18.1（每单位产品的原材料消耗，末行为可利用总数）：

| | R₁/Eᵢ | R₂/Eᵢ | R₃/Eᵢ |
|---|---|---|---|
| E₁ | 12 | 8 | 0 |
| E₂ | 6 | 12 | 10 |
| 总数 | 630 | 620 | 350 |

利润（PR）：每单位 E₁ 为 20、E₂ 为 60；要求 x₁ ⩾ 10。

```text
max  20x₁ + 60x₂
s.t. 12x₁ +  6x₂ ⩽ 630     (R₁)
      8x₁ + 12x₂ ⩽ 620     (R₂)
     10x₂        ⩽ 350     (R₃，E₁ 不消耗 R₃)
      x₁         ⩾ 10
```

**系数核对**：约束系数与表 18.1 逐项对应——E₁ 消耗 R₁/R₂/R₃ 为 12/8/0，E₂ 为 6/12/10，总数 630/620/350 ✓

## 解点复算

**目标值**：20·25 + 60·35 = 500 + 2100 = 2600，与手册水平线 20x₁ + 60x₂ = 2600 一致 ✓

**约束核验**（在 (25, 35) 处）：

- (R₂) 8·25 + 12·35 = 200 + 420 = 620 = 620，紧约束 ✓
- (R₃) 10·35 = 350 = 350，紧约束 ✓
- (R₁) 12·25 + 6·35 = 300 + 210 = 510 ⩽ 630，松弛量 120 ✓
- x₁ = 25 ⩾ 10 ✓

**最优性核验**（候选顶点比较）：

- (R₁)∩(R₂)：第一式乘 2 得 24x₁ + 12x₂ = 1260，与 8x₁ + 12x₂ = 620 相减得 16x₁ = 640，故 x₁ = 40、x₂ = 25；目标值 20·40 + 60·25 = 2300 < 2600；
- x₁ = 10 与 (R₃)（x₂ = 35）的交点 (10, 35)：目标值 200 + 2100 = 2300 < 2600；
- 沿 (R₃) 即 x₂ = 35 增大 x₁，受 (R₂) 8x₁ ⩽ 620 − 420 = 200 限制，x₁ ⩽ 25，恰封顶于解点；
- 其余交点均不可行或目标值更低：(R₁)∩(R₃) 得 (35, 35)，但 8·35 + 12·35 = 700 > 620 不可行；x₁ = 10 与 (R₂) 交点 (10, 45) 违反 (R₃)；坐标轴上顶点（如 (10, 0)、(52.5, 0)）目标值分别为 200 与 1050。

**结论**：(25, 35) 为可行域顶点，目标值 2600 严格优于其余候选顶点（最高 2300），确为最优解点。
