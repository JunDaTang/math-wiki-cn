# 式 16.171–16.173 蒙特卡罗积分两法转录复算

对《数学手册(原书第10版)》16.3.5.3 积分近似两法的逐式转录与复算。

## 转录

```
(16.171)  I = ∫₀¹ g(x)dx
(16.172)  ∫₀¹ g(x)dx ≈ m/n
(16.173)  E(g(X)) = ∫_{-∞}^{∞} g(x)f₀(x)dx = ∫₀¹ g(x)dx ≈ (1/n)∑_{i=1}^{n} g_i
```

## 复算

- **(16.171)–(16.172)** 投点法：在 0⩽g⩽1 前提下，积分等于单位正方形内积分区域的面积；n 个均匀随机点中 m 个落入区域，m/n 为面积的频率估计（依据第 1057 页 16.2.1.2，[[concepts/频数与相对频率]]）。逻辑正确；源文同时指出其精度依赖大量随机数。
- **(16.173)** 均值逼近：因 f₀ 的支撑为 [0,1]，E(g(X)) = ∫g·f₀ = ∫₀¹g(x)dx 成立；以样本均值 (1/n)Σg_i 估计期望（依据第 1063 页 (16.49a, 16.49b)，[[concepts/期望]]、[[concepts/样本均值]]）。数学内容正确，源文称此为「普通蒙特卡罗方法」。

## 转写瑕疵

- ξ 序列旁有「＆」衍文；「可得到 个点」「用 表示区域 内点的数量」「作为均匀分布随机变量 的实现」等处 n、m、X 脱落。
- 「这正是人们探究有可能提高精度的原因方法之一是下述蒙特卡罗方法」一句脱误，可辨读为「均值逼近法是提高精度的方法之一」。

## 结论

两法公式均正确；精度对比源文仅作方向性暗示（投点法需大量随机数、均值法为改进方向之一），定量比较属开放问题（见 [[comparisons/投点法与均值逼近法比较]]）。
