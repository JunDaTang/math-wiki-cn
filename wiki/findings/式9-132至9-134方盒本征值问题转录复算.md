# 式 9.132–9.134 方盒本征值问题转录复算

## 转录

```latex
\frac{\partial^{2}\Psi}{\partial x^{2}}+\frac{\partial^{2}\Psi}{\partial y^{2}}+\frac{\partial^{2}\Psi}{\partial z^{2}}+\frac{2m}{\hbar^{2}}E\Psi=0            % 9.132a
\Psi=0\quad(x=0,a;\ y=0,b;\ z=0,c)                                                                                                                            % 9.132b
\Psi=\Psi_x(x)\Psi_y(y)\Psi_z(z),\quad
\frac{1}{\Psi_x}\frac{d^2\Psi_x}{dx^2}+\frac{1}{\Psi_y}\frac{d^2\Psi_y}{dy^2}+\frac{1}{\Psi_z}\frac{d^2\Psi_z}{dz^2}=-\frac{2m}{\hbar^2}E=-B                   % 9.133a,b
\frac{d^2\Psi_x}{dx^2}=-k_x^2\Psi_x,\ \frac{d^2\Psi_y}{dy^2}=-k_y^2\Psi_y,\ \frac{d^2\Psi_z}{dz^2}=-k_z^2\Psi_z                                               % 9.133c
k_x^2+k_y^2+k_z^2=B,\qquad E=\frac{\hbar^2}{2m}(k_x^2+k_y^2+k_z^2)                                                                                            % 9.133d,e
\Psi_x=A_x\sin k_xx,\ \Psi_y=A_y\sin k_yy,\ \Psi_z=A_z\sin k_zz                                                                                               % 9.134a
\sin k_xa=\sin k_yb=\sin k_zc=0,\qquad k_x=\frac{\pi n_x}{a},\ k_y=\frac{\pi n_y}{b},\ k_z=\frac{\pi n_z}{c}                                                  % 9.134b,c
E_{n_x,n_y,n_z}=\frac{\hbar^2}{2m}\Big[\Big(\frac{n_x}{a}\Big)^2+\Big(\frac{n_y}{b}\Big)^2+\Big(\frac{n_z}{c}\Big)^2\Big]\ (n_x,n_y,n_z=\pm1,\pm2,\dots)      % 9.134d
\Psi_{n_x,n_y,n_z}=\sqrt{\frac{8}{abc}}\sin\frac{\pi n_xx}{a}\sin\frac{\pi n_yy}{b}\sin\frac{\pi n_zz}{c}                                                     % 9.134f
E_0=\frac{\hbar^2}{2m}\Big(\frac{1}{a^2}+\frac{1}{b^2}+\frac{1}{c^2}\Big)                                                                                     % 9.134h
```

（源文另有 9.134e 归一化积分、9.134g 结点平面坐标表。）

## 复算与核对

- **9.133 分离链**：代入、每项仅依赖一个变量、各项为常数的标准论证 ✓；9.133d,e 与 9.132a 的 B 定义一致 ✓。
- **9.134b→9.134c**：sin(πnₓ) = 0 ⟹ kₓ = πnₓ/a ✓。
- **9.134d**：把 9.134c 代入 9.133e ✓；量子数取 ± 值冗余（正弦函数在 ±n 下仅差符号，物理态相同）但非错误。
- **9.134f 归一化复算**：∫₀ᵃ sin²(πnₓx/a)dx = a/2（nₓ 为正整数），三重积分为 abc/8，故 (AₓA_yA_z)² = 8/abc，系数 √(8/abc) ✓。
- **9.134h**：nₓ = n_y = n_z = 1 代入 9.134d 即得 ✓。

## 疑点

- 9.2.4.5.4 称量子数「可以跑遍除了零之外的所有实数」——与 9.134c 的整数条件矛盾，应为整数：[[queries/方盒量子数应为整数而非实数]]。
- 源文 9.2.4.5.3 标题编号与「三」等字符有 OCR 丢失；「结点平面」段轴名丢失，见 [[queries/9-2-4全节系统性转写讹误清单]]。

## 结论

直接推导复算全部通过（含归一化系数的独立计算）；方盒模型结论载于 [[concepts/无限深方势阱]]，零点平移能归属见 [[concepts/零点能]]。
