# e 级数余项的几何强级数估计（式 7.71–7.72）

## 主张

一般收敛级数的余项满足三角不等式上界，可用强级数（几何级数）控制；$e$ 级数的余项有 $R_n<\frac{1}{n\cdot n!}$。

## 逐字转录（7.2.5.1）

为了判断收敛级数的 $n$ 项部分和与级数和的逼近程度，必须估计级数 $\sum_{k=1}^{\infty}a_k$ 的余项的绝对值：

$$|S-S_n| = |R_n| = \left|\sum_{k=n+1}^{\infty}a_k\right| \leqslant \sum_{k=n+1}^{\infty}|a_k| \qquad (7.71)$$

为此，需要利用 $\sum_{k=n+1}^{\infty}|a_k|$ 的强级数，强级数通常为一个几何级数或者为另一个比较容易求和并估计的级数。

**算例**：估计级数 $\mathrm e=\sum_{n=0}^{\infty}\frac{1}{n!}$ 的余项。当 $m\geqslant n+1$ 时，比较该级数相邻两项的比值 $\frac{a_{m+1}}{a_m}$，有 $\frac{a_{m+1}}{a_m} = \frac{m!}{(m+1)!} = \frac{1}{m+1} \leqslant \frac{1}{n+2} = q < 1$。因此余项 $R_n = \frac{1}{(n+1)!}+\frac{1}{(n+2)!}+\frac{1}{(n+3)!}+\cdots$ 可用首项 $a=\frac{1}{(n+1)!}$、公比为 $q=\frac{1}{n+2}$ 的几何级数 (7.15) 来强化，有

$$R_n < \frac{a}{1-q} = \frac{1}{(n+1)!}\cdot\frac{n+2}{n+1} < \frac{1}{n!}\cdot\frac{n+2}{n^2+2n} = \frac{1}{n\cdot n!} \qquad (7.72)$$

## 复算校验（通过）

- 比值控制：$m\geq n+1\Rightarrow\frac{1}{m+1}\leq\frac{1}{n+2}$ ✓；
- 几何求和：$\frac{a}{1-q} = \frac{1}{(n+1)!}\cdot\frac{1}{1-\frac{1}{n+2}} = \frac{1}{(n+1)!}\cdot\frac{n+2}{n+1}$ ✓；
- 末步化简：$\frac{n+2}{n^2+2n} = \frac{n+2}{n(n+2)} = \frac1n$，故右端 $=\frac{1}{n\cdot n!}$ ✓；
- 不等式方向：$\frac{1}{(n+1)!}\cdot\frac{n+2}{n+1}$ 与 $\frac{1}{n\cdot n!}$ 之比 $= \frac{n(n+2)}{(n+1)^2} = \frac{n^2+2n}{n^2+2n+1} < 1$ ✓。

## 证据强度

推导链每一步复算通过；结论为标准估计。交错级数余项 (7.73) 与特殊级数回指见 [[级数余项估计]]。
