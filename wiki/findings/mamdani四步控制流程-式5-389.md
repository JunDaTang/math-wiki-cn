# Mamdani 方法的四步控制流程（式 5.389）

**主张**：模糊控制过程由四个模块构成并迭代运行——(1) 法则基础、(2) 模糊化、(3) 聚合、(4) 决策（逆模糊化）；误差与误差变化在区域 $E\times\Delta E\times U$ 中以语言描述模糊化；重复 (1)–(4) 直至取得最小的偏差及其变化。典型法则形式为：

$$
R^{i}:\ \text{如果 } e \text{ 是 } E^{i} \text{ 并且 } \dot{e} \text{ 是 } \Delta E^{i},\ \text{那么 } u \text{ 是 } U^{i}.\tag{5.389}
$$

其中 $e$ 刻画误差、$\dot e$ 刻画误差的变化、$u$ 刻画（非模糊值的）输出值的变化。

**证据类型**：直接证据——源文 5.9.6.1 的教科书式定义性陈述，无实证或推导；属模糊控制的标准内容，内部自洽。

**复算/复现状态**：无法则级数值可直接复算；四步流程在 5.9.6.3 逆摆算例中被完整走通（间接验证，见 [[逆摆mamdani算例-式5-392-395]]）。置信度 medium：定义性主张本身可靠，但源文未给证明或文献出处。
