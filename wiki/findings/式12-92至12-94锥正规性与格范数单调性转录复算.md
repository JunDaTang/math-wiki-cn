# 式 12.92–12.94 锥正规性与格范数单调性转录复算

## 转录内容

- 正规锥定义：X₊ 正规 ⟺ 范数半单调，∃M > 0 使 0 ≤ x ≤ y ⟹ ‖x‖ ≤ M‖y‖（12.92）。
- 定理：X 为巴拿赫空间（序由 X₊ 给出）时，每个序区间相对范数有界 ⟺ X₊ 正规。
- 正则锥定义：每个单调增且上有界的序列 x₁ ≤ x₂ ≤ ⋯ ≤ xₙ ≤ ⋯ ≤ z（12.93）都是柯西列。
- 格范数单调性：|x| ≤ |y| ⟹ ‖x‖ ≤ ‖y‖（12.94）；完备的赋范格称巴拿赫格。

## 复算（编者直接推导与外部经典核对）

- 12.92 半单调性与序区间有界性的等价是经典 Krein 型定理（外部可核对）✔；本源无证明。
- 12.93 经柯西列表述正则性是标准定义的变体（文献中常表述为「单调有界序列收敛」；在巴拿赫空间中两种表述等价——外部注记）。
- **p = ∞ 正则性反例（编者复算）**：ℓ^∞ 中 xⁿ = (1, …, 1, 0, 0, …)（前 n 个分量 1）单调增且以 (1,1,…) 为上界，但 ‖x^{n+m} − xⁿ‖_∞ = 1，非柯西列；L^∞(0,1) 中 χ_{(0,1−1/n)} 同理。故转录句「ℓᵖ 和 Lᵖ (1 ≤ p ≤ ∞) 中这些锥是正则的」对 p = ∞ 不成立，正确范围疑为 1 ≤ p < ∞（p < ∞ 时由逐分量控制收敛可证正则性，经典）。
- 12.94 格范数单调性为标准定义 ✔；𝒞、Lᵖ、ℓᵖ、𝓑([a,b]) 为巴拿赫格的断言与标准理论一致（外部核对）。

## 发现的讹误

1. 12.93 定义句缺「都是」二字（「中的柯西列」应为「都是柯西列」）。
2. 实心锥例中空间名残缺为「政」（疑为 𝔽ⁿ 或 ℝⁿ）；正规锥例中「空间贮」「Φⁿ」残缺（疑为 𝔽ⁿ 及另一空间）。
3. 正则锥例「配，ℓᵖ 和 Lᵖ …」中「配」残缺，且「但在 中则是非正则的」缺空间名（据上下文与外部复算，疑为 m 与/或 c）。
4. 锥的原始定义回指第 859 页 12.1.4.2（未入库），页码引用缺「页」字。

## 置信度与复算状态

定义与定理为经典内容（外部可核对），但例子清单转录残缺严重且 p = ∞ 断言与编者复算冲突，故整体置信度中等；校对前例子清单不宜作为可靠事实引用，详见 [[queries/锥例子空间名残缺与p无穷正则性]] 与 [[comparisons/锥三性质跨空间比较]]。
