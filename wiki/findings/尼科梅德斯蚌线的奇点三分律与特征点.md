# 尼科梅德斯蚌线的奇点三分律与特征点

**主张。** 尼科梅德斯蚌线原点的奇点类型由 l 与 a 之比三分，且伴随确定的特征点公式：

- l < a：孤立点（图 2.62(a)）；左支有两拐点 E, F，横坐标为三次方程的最大根之外的次大根（见下）；
- l = a：尖点（图 2.62(c)）；
- l > a：二重点（图 2.62(b)）；原点切线斜率 $\tan\alpha = \pm\sqrt{l^2-a^2}/a$，曲率半径 $r_0 = l\sqrt{l^2-a^2}/(2a)$；左支在 $x = a - \sqrt[3]{al^2}$ 处有一个极大值和一个极小值。

右支拐点 B, C 的横坐标恒为三次方程 $x^3 - 3a^2x + 2a(a^2 - l^2) = 0$ 的最大根；l < a 时左支拐点 E, F 取该方程的第二大根。

**验证（已验证，独立复推）。**
- 极值条件：$\dot{y} = a\sec^2\varphi + l\cos\varphi = 0 \Rightarrow \cos^3\varphi = -a/l$（仅 l > a 时有解），代回 $x = a + l\cos\varphi$ 得 $x = a - \sqrt[3]{al^2}$，与手册一致。
- r₀：用极点曲率公式 $r_0 = |\rho'(\varphi_0)|/2$（$\varphi_0$ 为 $\rho = 0$ 的极角，即 $\cos\varphi_0 = a/l$，两解对应二重过极点），$\rho = a\sec\varphi - l \Rightarrow |\rho'(\varphi_0)| = l\sqrt{l^2-a^2}/a$，故 $r_0 = l\sqrt{l^2-a^2}/(2a)$，吻合。
- 切线斜率：隐式方程在原点的最低次项 $(a^2-l^2)x^2 + a^2y^2 = 0$ 给出 $y = \pm x\sqrt{l^2-a^2}/a$，吻合 tan α；l < a 时该二次型正定，仅剩孤立解，印证孤立点。
- 拐点三次方程：曲率分子 $\dot{x}\ddot{y} - \dot{y}\ddot{x} = 0$ 化简为 $l\cos^3\varphi + 3a\cos^2\varphi - 2a = 0$，代换 $u = x - a = l\cos\varphi$ 后即 $u^3 + 3au^2 - 2al^2 = 0$，展开回 x 正是手册的 $x^3 - 3a^2x + 2a(a^2-l^2) = 0$。
- 根分布（数值验证，a = 1, l = 0.5）：三实根 ≈ 1.38、0.56、−1.94；最大根 1.38 落在右支 x 区间 $(a, a+l] = (1, 1.5]$，第二大根 0.56 落在左支区间 $[a-l, a) = [0.5, 1)$，与手册“最大根给右支、第二大根给左支”的规则一致；第三根 −1.94 不落在任何一支上，为方程的多余根，不影响手册规则。

**警示。** 该三分律与 [[concepts/帕斯卡蜗线]] 的方向相反（蜗线 l < a 时为二重点），机制与对照见 [[comparisons/尼科梅德斯蚌线与帕斯卡蜗线奇点分类比较]]。
