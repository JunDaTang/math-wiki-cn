# 算术基本定理与 1533312 指数序列算例

## 内容（5.4.1.2.8–9）

- **初等数论基本定理**：每个正整数 $n>1$ 可以表示为素数的乘积；这种表示除因子次序外是唯一的。因此称 $n$ 恰有一个素因子分解式。
- 例：$360 = 2\cdot2\cdot2\cdot3\cdot3\cdot5 = 2^3\cdot3^2\cdot5$。
- **推广**：类似地，整数（除 $-1,0,1$）可表示为素元素之积，除因子的次序和符号外表示是唯一的。
- **标准素因子分解**：因子按大小排列、相同因子组成幂；规定不出现的素数指数为 0 后，每个正整数由指数序列唯一确定。

## 复算（通过）

- $360 = 2^3\cdot3^2\cdot5$ ✓
- $1533312 = 2^7\cdot3^2\cdot11^3$ ✓（$128\cdot9\cdot1331 = 1{,}533{,}312$）；对素数序列 $2,3,5,7,11,\dots$ 的指数序列为 $(7,2,0,0,3,0,0,\dots)$ ✓
