# 希尔伯特矩阵本征值与 Root 系数复算

## 复算对象

20.3.3.3 中 5×5 希尔伯特矩阵 `h = Table[1/(i+j-1), {i,5}, {j,5}]` 的 Eigenvalues 符号输出（Root 对象）与数值化结果。

## 书中结果

- 符号本征值（书中评语：「答案可能是没用的」）：

```
{Root[-1 + 307505 #1 - 1022881200 #1^2 + ...]}
```

- 数值化（转写脱 In[3] 输入行，见 [[queries/本征值例脱In3之辨]]）：

```
Out[3] = {1.56705, 0.208534, 0.0114075, 0.000305898, 3.28793×10⁻⁶}
```

## 复算结论

1. **数值本征值与已知的 H₅ 本征值一致**：五个正本征值按量级分布 {1.56705, 0.208534, 0.0114075, 0.000305898, 3.28793×10⁻⁶} 为经典已知结果。
2. **Root 多项式系数交叉验证**：设本征值为 λᵢ，所示多项式（以 #1 为变元）前三个系数 −1、307505、1022881200 满足 307505 = e₄/e₅ = Σᵢ 1/λᵢ = tr(H₅⁻¹)。而 H₅⁻¹ 为已知的显式整数矩阵（对角元 25、4800、79380、179200、44100），其迹恰为 307505。系数关系吻合，佐证 Root 对象确为 H₅ 特征多项式的正确表示。

## 语境意义

此例将 [[concepts/希尔伯特矩阵与条件数警告]] 从 19.8.4 的 Matlab 数值警告语境扩展为 Mathematica 符号/数值双语境：同一病态矩阵在符号系统中以 Root 对象出现（「可能是没用的」），数值化后最小本征值 3.28793×10⁻⁶ 揭示其病态性，可与 [[findings/NIntegrate峰值丢失与递归选项复算]] 的数值病态案例互证。书中主张 n > 4 时特征多项式次数大于四、无代数表达式，应求数值本征值 — 与 [[concepts/本征值命令与Root对象]] 一致。

## 证据性质

数值对照 + 整矩阵迹的交叉验证，属直接证据。
