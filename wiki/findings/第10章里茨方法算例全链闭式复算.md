# 第10章里茨方法算例全链闭式复算

对 10.5 里茨方法算例 (10.52a–j) 作全链闭式复算（规程见 [[methodology/变分算例闭式复算法]]），**全部逐项吻合**：

1. **积分系数**（由 y = a₁x(x−1) + a₂x²(x−1) 逐项展开积分）：
   - ∫₀¹(2x−1)²dx = 1/3，∫₀¹(3x²−2x)²dx = 2/15，交叉项 2∫₀¹(2x−1)(3x²−2x)dx = 1/3——与 (10.52e) 前半（系数 1/3、2/15、1/3）吻合；
   - ∫₀¹(x²−x)²dx = 1/30，∫₀¹(x³−x²)²dx = 1/105，交叉项 2∫₀¹(x²−x)(x³−x²)dx = 1/30——与 (10.52e) 后半（λ 括号内系数 1/30、1/105、1/30）吻合。
2. **方程组 (10.52f)**：由 ∂I/∂a₁ = ∂I/∂a₂ = 0 重新求导，两式系数 (2/3 − λ/15, 1/3 − λ/30) 与 (1/3 − λ/30, 4/15 − 2λ/105) 吻合。
3. **特征方程**：行列式 (2/3 − λ/15)(4/15 − 2λ/105) − (1/3 − λ/30)² = 0 化简恰为 λ² − 52λ + 420 = 0，根 λ₁ = 10、λ₂ = 42，吻合 (10.52g)。
4. **λ = 10 的解**：系数矩阵化为 [[0, 0], [0, 8/105]]，降秩，给出 a₂ = 0、a₁ 任意，吻合正文（印本 (10.52f) 两处讹作「(10.52£)」）。
5. **归一化**：a₁²·∫₀¹x²(x−1)²dx = a₁²/30 = 1 ⟹ a₁ = √30 ≈ 5.477 ≈ 5.48，吻合 (10.52h)。
6. **精确对照**：边值问题 (10.52i) 的本征值 λ_k = k²π²、λ₁ = π² ≈ 9.87，正规化解 y = √2·sin πx，吻合 (10.52j)；里茨值 10 > π²，符合里茨逼近给出本征值上界的性质，结构自洽。

证据强度：高（全闭式、可复算，特征方程与降秩解两环节独立互证）。此为直接证据（对印本公式的独立重算），非推断。
