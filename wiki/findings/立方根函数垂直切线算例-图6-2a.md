# 立方根函数垂直切线算例（图 6.2(a)）

手册 6.1.1 算例 A：立方根函数在原点处差商极限趋于无穷，导数不存在，切线垂直于 x 轴。

## 逐字转录

```latex
% 例 A（垂直切线）
f(x) = \sqrt[3]{x}:\quad f'(x) = \frac{1}{3\sqrt[3]{x^2}},\quad f'(0) = \infty
```

原文表述：在点 x=0 处极限 (6.1) 趋于无穷，因此在该点导数不存在（图 6.2(a)）。

## 复算（已验证）

- f(x)=x^(1/3) ⇒ f′(x)=(1/3)x^(−2/3) = 1/(3∛(x²))，与手册公式一致；
- x→0 时 x^(−2/3)→+∞，左、右双侧差商极限同为 +∞，故 f′(0)=∞、导数不存在；
- 几何上曲线在原点有垂直于 x 轴的切线，属「连续但切线垂直于 x 轴」情形。

## 归属与边界

- 本算例专属结论：「f′=±∞ 型不可导」仅刻画本类情形（双侧极限同为无穷），**不可转移**至例 B（无极限）或例 C（尖点）情形，见 [[垂直切线与尖点两种不可导情形比较]]。
- 转写讹误：「趋千无穷」应为「趋于无穷」。
