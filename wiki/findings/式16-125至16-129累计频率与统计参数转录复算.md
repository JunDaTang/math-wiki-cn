# 式 16.125–16.129 累计频率与统计参数转录复算

对数学手册 16.3.2 节五组公式 (16.125)–(16.129) 的逐式转录与核对。**结论：五组公式均为标准定义，逐式核对未发现公式本体错误。**

## 逐式核对（直接证据）

| 式号 | 内容 | 核对结论 |
|---|---|---|
| (16.125) | 累计（相对）频率 $F_j=(h_1+\cdots+h_j)/n\,\%$ | 与逐组累加定义一致；在表 16.3 上复算通过（[[findings/表16-3频率表转录复算]]）✓ |
| (16.126a) | 样本均值（原始数据）$\bar{x}=\frac1n\sum x_i$ | 标准算术平均定义 ✓ |
| (16.126b) | 样本均值（分组）$\bar{x}=\frac1n\sum h_j\bar{x}_j$ | 以频数加权组均值，$\sum_j h_j=n$ 时与 (16.126a) 相容 ✓ |
| (16.127a) | 样本方差（原始数据），除数 $n-1$ | 标准样本方差定义 ✓ |
| (16.127b) | 样本方差（分组），除数 $n-1$ | 与 (16.127a) 在 $\sum_j h_j=n$ 下相容 ✓ |
| (16.128a) | 分布中位数 $P(X<\tilde{x})=\frac12$ | 标准中位数定义（严格不等号形式）✓ |
| (16.128b) | 样本中位数（奇偶分况） | 标准定义；隐含排序前提，正文未注明（见注记） |
| (16.129) | 极差 $R=x_{\max}-x_{\min}$ | 标准定义 ✓ |

## 注记与疑点（区分证据与推断）

- **隐含前提（推断）**：(16.128b) 成立需 $x_1\le x_2\le\cdots\le x_n$，正文未说明。
- **表述疑点（推断）**：正文「分位数元」「样本分位数」疑为「中位数」「样本中位数」之讹，见 [[queries/分位数元与样本分位数疑为中位数]]。
- **记号问题（直接观察）**：组距 h 与绝对频率 $h_j$ 符号过载（[[queries/等组距h20与分组端点宽度之辨]]）；表 16.3 表头下标 i 与正文 j 不一致（[[queries/表16-3下标i与正文j不一致之辨]]）。
- **缺失（直接观察）**：众数一节无公式，其表示符号在转写中脱落，不猜测。
- **严格不等号（直接观察）**：(16.128a) 用 $P(X<\tilde{x})=\frac12$ 且原文承认「可能并非唯一确定的点」，与 [[concepts/分位数]] 页定义表述需互相注记。
