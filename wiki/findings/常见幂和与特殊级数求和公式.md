# 常见幂和与特殊级数求和公式（式 1.55–1.64）

手册 1.2.4 以编号公式列出十条特殊有限级数的求和结果（下表逐字保留）：

| 编号 | 级数 | 和 |
|---|---|---|
| (1.55) | $1+2+3+\cdots+(n-1)+n$ | $\frac{n(n+1)}{2}$ |
| (1.56) | $p+(p+1)+(p+2)+\cdots+(p+n)$ | $\frac{(n+1)(2p+n)}{2}$ |
| (1.57) | $1+3+5+\cdots+(2n-3)+(2n-1)$ | $n^2$ |
| (1.58) | $2+4+6+\cdots+(2n-2)+2n$ | $n(n+1)$ |
| (1.59) | $1^2+2^2+3^2+\cdots+(n-1)^2+n^2$ | $\frac{n(n+1)(2n+1)}{6}$ |
| (1.60) | $1^3+2^3+3^3+\cdots+(n-1)^3+n^3$ | $\frac{n^2(n+1)^2}{4}$ |
| (1.61) | $1^2+3^2+5^2+\cdots+(2n-1)^2$ | $\frac{n(4n^2-1)}{3}$ |
| (1.62) | $1^3+3^3+5^3+\cdots+(2n-1)^3$ | $n^2(2n^2-1)$ |
| (1.63) | $1^4+2^4+3^4+\cdots+n^4$ | $\frac{n(n+1)(2n+1)(3n^2+3n-1)}{30}$ |
| (1.64) | $1+2x+3x^2+\cdots+nx^{n-1}$ | $\frac{1-(n+1)x^n+nx^{n+1}}{(1-x)^2}$（$x \neq 1$） |

## 验证状态

- 证据类型：直接陈述（手册编号公式），无证明。
- 入库分析阶段的抽查：(1.56) 取 $p=1, n=2$ 得 $1+2+3=6$，与公式一致；(1.61) 取 $n=2$ 得 $1^2+3^2=10$，与公式一致；(1.62) 取 $n=2$ 得 $1^3+3^3=28$，与公式一致；(1.64) 可由等比级数有限和 (1.54b) 对 $x$ 求导得到。
- 数值抽查（直接代入，非本源内容）：(1.63) 取 $n=2$：$1^4+2^4=17$，公式给 $\frac{2\cdot 3\cdot 5\cdot 17}{30}=17$，一致。

## 指标约定注意

(1.55)–(1.63) 采用 **1 起指标**（前 n 项），其中 (1.56) 自 $p$ 加到 $p+n$ 共 $n+1$ 项；而本节 1.2.1–1.2.3 的级数定义与差分公式采用 0 起指标（$a_0, \cdots, a_n$ 共 $n+1$ 项）。混用时须注意项数差异。

## 关联

- (1.55)–(1.58) 是 [[concepts/等差级数]] 的特例；(1.59)–(1.63) 为幂和，属 k 阶等差级数，可用 [[findings/k阶等差级数的差分表示公式]] 统一处理；(1.64) 与 [[concepts/等比级数]] 的有限和公式相关。
