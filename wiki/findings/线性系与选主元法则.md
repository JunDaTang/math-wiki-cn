# 线性系与选主元法则（式 4.174–4.176，4.176a 复原）

本 finding 记录 4.5.1 的形式体系：线性系的定义（式 4.174）、选主元格式（式 4.175）与四条选主元法则（式 4.176）。其中第 (1) 条（式 4.176a）在转写中整体脱落，本 wiki 据算例复原为 α_ik = 1/a_ik。

## 线性系（式 4.174a–b）

一个线性系含 m 个线性型 y = Ax + a：A 为 (m,n) 矩阵，其元素 a_μν 与列向量 a 的分量 a_μ (μ = 1,…,m) 是常数（转写误作 μ = 1,…,n，见 [[queries/4-5-1-1线性系定义段的下标讹误]]）；x_ν (ν = 1,…,n) 是独立变量；y_μ (μ = 1,…,m) 是相关变量（转写误作 x_μ）。

## 选主元法则

主元 a_ik ≠ 0 位于主行 y_i 与主列 x_k 的交点。一步选主元步骤将 y_i 调换为独立变量、x_k 调换为相关变量：格式中主行位置改标 x_k、主列位置改标 y_i（转写的式 4.175 后表将换轴行标作 x_i，按算例应为 x_k）。新元素按四条法则计算：

```
(1) α_ik = 1/a_ik                                                   （4.176a，转写脱落，据算例复原）
(2) α_μk = a_μk / a_ik                     (μ = 1,…,m; μ ≠ i)        (4.176b)
(3) α_iν = −a_iν / a_ik,  α_i = −a_i/a_ik  (ν = 1,…,n; ν ≠ k)        (4.176c)
(4) α_μν = a_μν − a_μk(a_iν/a_ik) = a_μν + a_μk·α_iν,
    α_μ  = a_μ + a_μk·α_i                   (ν ≠ k, μ ≠ i)           (4.176d)
```

其中 (2) 给出换轴后 y_i 列（原 x_k 列位置）在其余各行的元素，(3) 给出新 x_k 行（原 y_i 行位置）在其余各列与常数列的元素，(4) 给出其余交叉元素。为使法则 (4) 的计算容易，源将新主行元素 α_iν 写在格式的第 m + 1 辅助行。

## 复原依据与核验

α_ik = 1/a_ik（新表中 x_k 行与 y_i 列交点元素）在三个算例中逐一得到验证：

- [[findings/选主元法求逆矩阵算例]]：三次换轴的主元 1、1、−1，对应交点元素分别为 1、1、−1；
- [[findings/选主元法判别线性相关性算例]]：y₄→x₄（主元 1）后 x₄ 行 y₄ 列元素为 1；
- [[findings/选主元法两情形与参数解算例]] 的换轴终表亦吻合。

三例换轴表均已逐步复算吻合，故本 finding 标记为已复算；式 (4.176a) 的原书确切表述仍需核对（见 [[queries/式4-176a是否脱落且可否复原]]）。
