# 式 19.287–19.290 扰动方程与梯形辛普森稳定性转录复算

## 转录（按原文）

```latex
y' = f(x,y),\quad f(x,y) = ay                                              (19.287)
u(x) = y(x) + \varepsilon\,\eta(x)                                         (19.288a)
u'(x) = f(x,y) + \varepsilon\,\eta(x) f_y(x,y) + \text{高阶项}              (19.288b)
\eta'(x) = f_y(x,y)\,\eta(x)                                               (19.288c)
\eta(x) = \eta_0 e^{a(x-x_0)}                                              (19.288d)

y(x) = y_0 e^{a(x-x_0)}                                                    (19.289a)
\int_{x_i}^{x_{i+1}} y\,dx \approx \frac{y_i + y_{i+1}}{2}h                (19.289b)
\tilde{y}_{i+1} = \tilde{y}_i - \frac{\tilde{y}_i + \tilde{y}_{i+1}}{2}h,\quad
\tilde{y}_{i+1} = \frac{2-h}{2+h}\tilde{y}_i,\quad \tilde{y}_i = \Big(\frac{2-h}{2+h}\Big)^i \tilde{y}_0   (19.289c)
\tilde{y}_i = \Big(\frac{2-h}{2+h}\Big)^{(x_i-x_0)/h}\tilde{y}_0 = \tilde{y}_0 e^{c(h)(x_i-x_0)},\quad
c(h) = \frac{\ln(\frac{2-h}{2+h})}{h} = -1 - \frac{h^2}{12} - \frac{h^4}{80} - \dots   (19.289d)

(\tilde{y}_{i+1} - y_{i+1}) \leqslant \Big(\frac{2-h}{2+h}\Big)^{i+1}(\tilde{y}_0 - y_0)   (19.290a)
\tilde{y}_i = C_1 e^{-x_i} + C_2 (-1)^i e^{x_i/3}                          (19.290b)
```

## 复算（直接证据）

- **(19.288c,d)**：$f_y=a$ 时 $\eta'=a\eta\Rightarrow\eta=\eta_0 e^{a(x-x_0)}$ ✓；$a>0$ 时扰动无限增长（天然不稳定）✓。
- **(19.289c)**：梯形格式代入 $y'=-y$：$\tilde{y}_{i+1}=\tilde{y}_i-\frac{h}{2}(\tilde{y}_i+\tilde{y}_{i+1})\Rightarrow(1+\tfrac{h}{2})\tilde{y}_{i+1}=(1-\tfrac{h}{2})\tilde{y}_i\Rightarrow\tilde{y}_{i+1}=\frac{2-h}{2+h}\tilde{y}_i$ ✓。
- **(19.289d)**：由 $\ln(1-u)-\ln(1+u)=-2(u+\tfrac{u^3}{3}+\tfrac{u^5}{5}+\cdots)$，$u=h/2$，得 $\ln\frac{2-h}{2+h}=-h-\frac{h^3}{12}-\frac{h^5}{80}-\cdots$，除以 $h$ 即 $c(h)=-1-\frac{h^2}{12}-\frac{h^4}{80}-\cdots$ ✓（两个系数均通过）。
- **$0\leqslant h<2$ 之限**（复算注记，属推断）：$|\frac{2-h}{2+h}|<1$ 对一切 $h>0$ 成立；$h<2$ 来自 $\ln\frac{2-h}{2+h}$ 需 $2-h>0$ 才能写成实的 $c(h)$。
- **(19.290a)**：误差方程同乘放大因子，逐次递推得上界 ✓；$\varepsilon_{i+1}$ 最多与 $\varepsilon_0$ 同阶，方法关于初值稳定 ✓。
- **(19.290b)**：辛普森格式的寄生特征根 $\lambda_2\approx-(1+h/3)$，$(\lambda_2)^i\approx(-1)^i e^{ih/3}=(-1)^i e^{x_i/3}$（取 $x_0=0$，$x_i=ih$）；一阶展开代入特征方程验证为零 ✓。故通解 $C_1e^{-x_i}+C_2(-1)^ie^{x_i/3}$ 成立，寄生模态论断复算通过。

## 文本疑点

- (19.289a) 在已固定 $a=-1$ 的语境下仍以一般参数形式 $y_0 e^{a(x-x_0)}$ 书写，与后文 $e^{-(x_i-x_0)}$ 数学等价但行文欠连贯。
- “趋向千”为“趋向于”的系统性 OCR 替换。
- 记入 [[queries/19-8-2全节系统性转写讹误清单]]。

## 结论

扰动—稳定性链条（19.287→19.288→19.289→19.290）复算全部通过；**辛普森法则**承担“人为不稳定/寄生模态”论断，**梯形公式**承担“$0\leqslant h<2$ 稳定、关于初值稳定”论断，二者不可互相移植（见 [[comparisons/梯形公式与辛普森法则稳定性比较]]）。
