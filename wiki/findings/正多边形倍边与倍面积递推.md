# 正多边形倍边与倍面积递推（式 3.55、3.57）

《数学手册(原书第10版)》3.1.5.2 给出将正多边形边数加倍（n → 2n，外接圆半径 R 保持不变）时边长与面积的递推公式，两向皆可（由 aₙ 求 a₂ₙ，或反向）：

```
a_{2n} = R·√(2 − 2√(1 − (a_n/(2R))²))
a_n    = a_{2n}·√(4 − a_{2n}²/R²)                            (3.55)

S_{2n} = (n·R²/√2)·√(1 − √(4·S_n²/(n²·R⁴)))     [转写字面，见复核]
S_n    = S_{2n}·√(1 − S_{2n}²/(n²·R⁴))                      (3.57)
```

## 复核（分项）

- **式 3.55 两向均自洽**：由半角公式 sin(θ/2) = √((1 − cos θ)/2) 严格导出。数值检验：a₄ = R√2 → a₈ = R·√(2 − 2√(1 − 1/2)) = R√(2 − √2)，与表 3.2 一致；反向 a₈ → a₄ 亦吻合。
- **式 3.57 后半自洽**：由 Sₙ = S₂ₙ·cos(π/n) 与 √(1 − S₂ₙ²/(n²R⁴)) = cos(π/n) 即得（数值检验 n = 3：S₆·0.5 = S₃ ✓）。
- **式 3.57 前半按转写字面不自洽**：n = 4 时代入得 S₈ = 0（真值 2√2·R²）；n = 6 时得 6·sin15°·R² ≈ 1.553R²（真值 3R²）。若在内层根号内补「1 −」，即 S₂ₙ = (n·R²/√2)·√(1 − √(1 − 4·Sₙ²/(n²·R⁴)))，则对 n ≥ 4 正确（n = 3 需取另一支 1 + √(1 − …)）。疑为转写丢失内层「1 −」或原书排印之误，见 [[queries/式3-57的S2n式内层是否漏了1减]]。

综合上述，本 finding 的 confidence 记为 medium：递推结构本身成立，但式 3.57 前半的转写字面存疑。

## 备注（分析者旁注）

源文未言明该递推与用内接/外切多边形逼近圆周率（阿基米德多边形法）的经典联系；此为分析者旁注，待 3.1 关于圆的小节入库后再作正式关联。
