# 最小二乘问题与正规方程组（式 4.187–4.190）

超定线性方程组 A x = b（m > n，式 4.187）一般无满足所有方程的精确解；代入任何向量 x 都产生残差向量 r = Ax − b（式 4.188）。线性最小二乘问题即（式 4.189）：

```
Σᵢ rᵢ² = rᵀr = (Ax − b)ᵀ(Ax − b) = min!
```

（欧氏模下残差平方和极小；残差向量的模 ‖r‖ = √(rᵀr) 称为残差。源称「高斯就已经有这样的思想」。）

解的刻画：若残差向量与 A 的每一列正交（转写该句严重乱码，应为「残差向量与 A 的每一列正交」），则 x 是 (4.189) 的解，即正规方程组（式 4.190）：

```
Aᵀ(Ax − b) = 0   ⇔   AᵀA x = Aᵀb
```

它是系数矩阵为方阵的线性方程组，维数为 n；由 (4.187) 到 (4.190) 的转化称为高斯变换。AᵀA 是对称的；若 rank(A) = n（实矩阵、m > n 下即 A 的所有列线性无关），则 AᵀA 正定因而正则，正规方程组有唯一解。

## 证据强度

推导链完整，且为数值线性代数的标准结果；但源内**无数值算例**，本 finding 的公式属直接转录、推导属标准数学事实，未做数值复算。转写脱落后致因果颠倒的句子「因为 m > n，所以 A 的所有列是线性无关的」见 [[queries/4-5全节系统性转写讹误清单]]；数值解建议另记于 [[findings/正则化与数值方法建议]]。
