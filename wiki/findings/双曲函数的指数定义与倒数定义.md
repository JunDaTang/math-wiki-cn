# 双曲函数的指数定义与倒数定义

手册 2.9.1 以两种方式定义六个双曲函数：sinh、cosh、tanh 直接由 e^x 与 e^−x 的线性组合（及商）定义（式 2.166–2.168）；coth、sech、csch 定义为相应函数的倒数（式 2.169–2.171）。手册并注明几何定义（参见第 172 页 3.1.2.2）与三角函数类似。

$$
\sinh x = \frac {\mathrm{e} ^ {x} - \mathrm{e} ^ {- x}}{2},\qquad
\cosh x = \frac {\mathrm{e} ^ {x} + \mathrm{e} ^ {- x}}{2},\qquad
\tanh x = \frac {\mathrm{e} ^ {x} - \mathrm{e} ^ {- x}}{\mathrm{e} ^ {x} + \mathrm{e} ^ {- x}},
$$

$$
\coth x = \frac {1}{\tanh x} = \frac {\mathrm{e} ^ {x} + \mathrm{e} ^ {- x}}{\mathrm{e} ^ {x} - \mathrm{e} ^ {- x}},\qquad
\operatorname{sech} x = \frac {1}{\cosh x} = \frac {2}{\mathrm{e} ^ {x} + \mathrm{e} ^ {- x}},\qquad
\operatorname{csch} x = \frac {1}{\sinh x} = \frac {2}{\mathrm{e} ^ {x} - \mathrm{e} ^ {- x}}.
$$

## 核验（直接证据）

六条定义均可由 [[concepts/指数函数]]（2.6 节）的性质直接理解：sinh 与 cosh 分别是 e^x 与 e^−x 的半差与半和，tanh 为二者之商。结构性事实：cosh x + sinh x = e^x、cosh x − sinh x = e^−x，这一分解是双曲棣莫弗公式（式 2.190）与整套恒等式代数核验的基础。本次收录对六条定义及由其派生的全部公式逐条核验，未发现数学错误。

## 备注（推断）

- 定义域：sinh、cosh、tanh、sech 在整个 ℝ 上有定义；coth 与 csch 在 x = 0 处无定义（由 tanh 0 = 0、sinh 0 = 0 可知）。
- 手册未给 sech、csch 设置图像小节（见 [[queries/图2-48是否为sech与csch的曲线]]、[[queries/表2-7为何不含sech与csch]]）。
