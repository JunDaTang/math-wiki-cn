# 式 9.92 弦振动方程分离变量解转录复算

## 逐字转录

```
u_tt = a²u_xx                                                       (9.92a)
u|_{t=0} = f(x)，u_t|_{t=0} = φ(x)，u|_{x=0} = 0，u|_{x=l} = 0      (9.92b)
u = X(x)T(t)                                                        (9.92c)
T″/(a²T) = X″/X                                                     (9.92d)
X″ + λ²X = 0                                                        (9.92e)
T″ + a²λ²T = 0                                                      (9.92f)
X = C sin λx，sin λl = 0，λ = nπ/l = λ_n (n = 1,2,…)                (9.92g)
u_n = (a_n cos(naπt/l) + b_n sin(naπt/l)) sin(nπx/l)                (9.92h)
a_n = (2/l)∫₀^l f(x)sin(nπx/l)dx                                    (9.92k)
b_n = (2/(naπ))∫₀^l φ(x)sin(nπx/l)dx
```

（9.92i/j 为 t = 0 时 u 与 u_t 的正弦级数展开条件，回指 7.4.1.1 傅里叶级数，未入库。）

## 复算核验

1. **分离常数必为负**：非负常数值给出平凡解 u ≡ 0，与 Dirichlet 边界条件相符 ✓。
2. **本征值问题**：X″ + λ²X = 0、X(0) = X(l) = 0 即 [[斯图姆-刘维尔问题]]，λ_n = nπ/l ✓。
3. **系数反解**：u(x, 0) 的正弦展开给 a_n；∂u/∂t|_{t=0} = Σ (naπ/l)·b_n sin(nπx/l) 的正弦展开给 b_n = (2/l)·(l/(naπ))∫φ sin = (2/(naπ))∫φ sin ✓（因子 1/(naπ) 核验通过）。

## 结论

复算通过，无实质问题。手册声明：级数在 f、φ 满足关于二阶导数连续性等条件时收敛（形式解警示）。概念页 [[弦振动方程]]；流程页 [[分离变量法解题流程]]。
