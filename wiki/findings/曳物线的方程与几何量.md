# 曳物线的方程与几何量（式 2.253）

**发现**：手册 2.15.2 给出曳物线（见 [[concepts/曳物线]]）的方程与几何性质。核心内容（ln 形式方程、弧长、极限值、尖点、渐近线）均可独立复核；唯曲率半径一行与第一行 Arcosh 形式的符号配对存在两处疑点，经重建后方能自洽。来源：[[sources/10-数学手册原书第10版--10-215-各种其他曲线--pzek1r]]（2.15.2）。

## 原文公式（逐字保留）

```latex
\begin{array}{r l} & {x = a \mathrm{Arcosh} \frac {a}{y} \pm \sqrt {a ^ {2} - y ^ {2}}} \\ & {\qquad = a \ln \frac {a \pm \sqrt {a ^ {2} - y ^ {2}}}{y} \mp \sqrt {a ^ {2} - y ^ {2}} \quad (a > 0, 0 < y \leqslant a).} \end{array}\tag{2.253}
```

## 几何量清单

| 量 | 公式/陈述 |
|---|---|
| 定义 | 切线段 $\overline{PM} = a$（常数）；长 a 不可伸绳拖拽质点的轨迹 |
| 渐近线 | x 轴 |
| 奇点 | $A(0, a)$ 为尖点 |
| 对称性 | 关于 y 轴对称 |
| 弧长 $\widehat{AP}$ | $L = a\ln\frac{a}{y}$ |
| 极限 | L 增大时 $L - x \to a(1-\ln 2) \approx 0.307a$ |
| 曲率半径 | 原文作 $r = a\cot\frac{x}{y}$（辐角疑误） |
| 反比律 | 曲率半径 $\overline{PC}$ 与线段 $\overline{PE} = b$ 成反比：$rb = a^2$ |
| 渐屈线 | 曲率中心 C 的轨迹为悬链线 (2.252)（图 2.79 虚线） |

## 复核与两处疑点

- **已复核**：第二行 ln 形式可由切线条件 $\frac{\mathrm{d}y}{\mathrm{d}x} = -\frac{y}{\sqrt{a^2-y^2}}$ 积分复原；$L = a\ln\frac{a}{y}$、极限值 $a(1-\ln 2) \approx 0.3069a$、尖点与渐近线行为均可独立验证。
- **疑点一（曲率半径辐角）**：$x/y$ 未在文中定义且结构上不可能是角度；以切线倾角参数（$y = a\sin t$）重建得 $r = a\cot t = a\frac{\sqrt{a^2-y^2}}{y}$，此时 $b = a\tan t$（E 推测为 P 处法线与 x 轴之交点），$rb = a^2$ 完全自洽，尖点处 $r\to 0$、沿渐近线 $r\to\infty$ 亦自洽。见 [[queries/式2-253曲率半径cot辐角x比y是否为误]]。
- **疑点二（第一行符号配对）**：主支 $\mathrm{Arcosh}\frac{a}{y} = \ln\frac{a+\sqrt{a^2-y^2}}{y}$ 内部已含「+√」，第一行按字面「+√」得到不在曲线上的点（数值反例：$a=1$、$y=0.5$ 时字面给出 $x\approx 2.183$，而曲线上该高度右支 $x\approx 0.451$、左支 $x\approx -0.451$）；疑漏 Arcosh 前的 ±，正确形式 $x = \pm\left(a\,\mathrm{Arcosh}\frac{a}{y} - \sqrt{a^2-y^2}\right)$。见 [[queries/式2-253第一行Arcosh形式的符号配对是否失配]]。

**结论**：整体强度强，唯上述两处印刷/转写疑点待对照原书确认（故置信度记为 medium）。渐屈线论断另见 [[findings/曳物线的渐屈线是悬链线]]。
