# 等额本金还款与等额年金公式（式 1.81–1.84）

《数学手册(原书第10版)》1.3.3 给出两种还款结构的公式。记号：债务 $S$（每期末以 $p\%$ 利息还款）、$T = \frac{S}{mN}$ 本金还款、$m$ 为一个利息周期内的还款次数、$N$ 为利息周期数、$a$ 为单次分期付款额、$q = 1+\frac{p}{100}$：

```latex
Z_n = \frac{pS}{100}\left[1 - \frac{1}{N}\left(n - \frac{m+1}{2m}\right)\right] \tag{1.81a}
Z = \sum_{n=1}^{N} Z_n = \frac{pS}{100}\left[\frac{N-1}{2} + \frac{m+1}{2m}\right] \tag{1.81b}
S_n = Sq^n - a\left[m + \frac{(m-1)p}{200}\right]\frac{q^n - 1}{q - 1} \tag{1.82}
A = a\left[m + \frac{(m-1)p}{200}\right] \tag{1.83}
A = Sq^N\frac{q-1}{q^N - 1} = S\frac{q-1}{1 - q^{-N}} \tag{1.84}
```

- (1.81)：等额本金还款（$T$ 为常数、年内不计算中期复利）的年利息与总利息——支付的利息随还款期限逐渐减少。
- (1.82)：等额年金情形 $n$ 个周期后的剩余债务。$Sq^n$ 为债务经 $n$ 次复利后的值（参见 (1.76)）；第二项为中期还款 $a$ 经复利计算的值（参见 (1.80b)，取 $E = a$）——**储蓄与还款公式结构同源**。
- (1.83)：年金 $A$ 与单次还款 $a$ 的关系，由此可推出 $A \geqslant ma$。
- (1.84)：由 $S_N = 0$ 与 (1.83) 导出；对 $A, S, q, N$ 知道其中任意三个可计算另一个。

## 手册数值例子（导入时独立复核吻合）

- 等额本金：债务 €60000、年利率 8%、60 个月每月还本 €1000（$S=60000$、$p=8$、$N=5$、$m=12$）——各年利息 $Z_1\dots Z_5$ = 4360 / 3400 / 2440 / 1480 / 520，总利息 $Z = €12200$（与 (1.81b) 直接计算 $\frac{8\cdot60000}{100}\left(\frac{5-1}{2}+\frac{13}{24}\right)$ 一致）。
- 等额年金例 A：贷款 €60000、年利率 8%、5 年等额还清——$A = 60000\,\frac{0.08}{1-1.08^{-5}} = €15027.39$，$a = \frac{15027.39}{12+\frac{11\cdot 8}{200}} = €1207.99$。注：原文“$\frac{11.8}{200}$”系 $\frac{11\cdot 8}{200} = 0.44$ 的排版错误（乘号误排为小数点），代入后结果正确。
- 等额年金例 B：贷款 €100000、7.5%、8 年、每年末额外还款 €5000——$A = €17072.70$；由 $A = a\left(12+\frac{11\cdot 7.5}{200}\right)+5000$ 得月还款额 $a = €972.62$。

## 证据说明

直接证据：手册原文。公式可由等比级数部分和与比例单利假设推导，结构自洽；全部数值经导入时独立算术复核吻合（例 A 的排版错误不影响结果）。确定性推导，非经验性结果。
