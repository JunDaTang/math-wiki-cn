# 多元隐函数的一阶偏导数公式（式 6.54a–b）

《数学手册(原书第10版)》6.2.3.2 条目 (2)：多元函数 u = f(x₁, x₂, …, x_i, …, xₙ) 由方程 F(x₁, …, x_i, …, xₙ, u) = 0 给出，"可用类似前面的方法来计算偏导数"。

## 逐字转录

$$F(x_1, x_2, \dots, x_i, \dots, x_n, u) = 0 \tag{6.54a}$$

$$\frac{\partial u}{\partial x_1} = -\frac{F_{x_1}}{F_u},\quad \frac{\partial u}{\partial x_2} = -\frac{F_{x_2}}{F_u},\quad \dots,\quad \frac{\partial u}{\partial x_n} = -\frac{F_{x_n}}{F_u}, \tag{6.54b}$$

原文续作："但是此处将会用到 (6.52b)．按同样的方法可计算高阶导数．"——即求导依据由全导数形式（6.51b）换成偏导数形式链式法则（6.52b）；高阶偏导数只给方法、未给公式。

## 复算记录

对 6.54a 关于 x_i 求偏导（u = u(x₁, …, xₙ) 与各 x_j 相互依赖）：

```
F_{x_i} + F_u · ∂u/∂x_i = 0   ⇒   ∂u/∂x_i = −F_{x_i}/F_u,   i = 1, …, n
```

与 6.54b 逐项一致，直接求导验证通过。✓

## 严谨性注记

- 6.53c 标明 (F_y ≠ 0)，而 6.54b 未标 (F_u ≠ 0)；数学上该条件是解出 ∂u/∂x_i 所必需的。属原书省略还是转写脱漏待对照原书，见 [[queries/式6-54b是否应补Fu不等于0条件]]。
- 归属：6.54b 仅属于"单方程多元隐函数"情形；方程组情形见 [[findings/式6-55两隐函数方程组导数复算]]、[[findings/式6-56n元隐函数方程组线性系统]]、[[findings/式6-57两个二元隐函数偏导数方程组]]。
