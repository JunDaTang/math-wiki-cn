# 柯西中值定理与参数曲线解释（式 6.32–6.33）

## 断言

**对象**：广义微分中值定理（柯西定理，6.1.4.6）。**题设**：两函数 y=f(x) 和 y=φ(x) 在闭区间 [a,b] 连续，至少在区间内部可微，且在该区间上 φ′(x) ≠ 0。**结论**：a、b 间至少存在一点 c，使得

```latex
(6.32)  \frac{f(b)-f(a)}{\varphi(b)-\varphi(a)} = \frac{f'(c)}{\varphi'(c)}   (a < c < b)
```

## 参数曲线几何解释

广义中值定理的几何意义与第一个中值定理（[[concepts/微分中值定理]]）相对应：设图 6.9 曲线的参数方程为 x=φ(t)、y=f(t)，则点 A、B 分别对应参数 t=a、t=b 的函数值，因此在点 C：

```latex
(6.33)  \tan\alpha = \frac{f(b)-f(a)}{\varphi(b)-\varphi(a)} = \frac{f'(c)}{\varphi'(c)}
```

## 退化断言（已核验）

**当 φ(x)=x 时，广义中值定理简化成了第一个中值定理**（来源明言）。核验：φ(b)−φ(a)=b−a、φ′(c)=1，式 6.32 恰化为式 6.29a。断言成立。

## 证据强度与备注

- 定理为标准结果；参数曲线解释与退化断言均正确，其中退化断言经代入核验通过（replicated: true）。
- 题设要求 φ′(x) ≠ 0 以排除分母退化（φ′(x)≠0 保证 φ(b)−φ(a)≠0 的说法为通行解释，非原文内容）。
