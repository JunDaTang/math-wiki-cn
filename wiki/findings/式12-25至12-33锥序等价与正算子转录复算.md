# 式 12.25–12.33 锥序等价、序有界与正算子转录复算

## 转录内容

```
C = {x ∈ V : x ≥ 0}                                             (12.25)
(O1) x ≥ x  ∀x ∈ V（自反性；转写注释为乱码）                      (12.26)
(O2) x ≥ y 和 y ≥ z 蕴涵 x ≥ z（传递性）                         (12.27)
(O3) x ≥ y 和 α ≥ 0 蕴涵 αx ≥ αy                                (12.28)
(O4) x₁ ≥ y₁ 和 x₂ ≥ y₂ 蕴涵 x₁+x₂ ≥ y₁+y₂                      (12.29)
V₊ = {x ∈ V : x ≥ 0}                                            (12.30)
C = {x = {ξₙ} : ξ ≥ 0 ∀n}   （ξ 缺下标 n）                       (12.31)
[x, y] = {v ∈ V : x ≤ v ≤ y}                                    (12.32)
T(X₊) ⊂ Y₊，即 Tx ≥ 0, ∀x ≥ 0                                    (12.33)
```

## 复算验证（锥 ↔ 序等价定理）

**由锥得 (O1)–(O4)**（设 x ≥ y ⟺ x−y ∈ C）：

- (O1)：x − x = 0 ∈ C（锥非空且正齐次取 λ = 0）。✓
- (O2)：x−y, y−z ∈ C ⟹ x−z = (x−y)+(y−z) ∈ C（式 12.17 取 λ = μ = 1）。✓
- (O3)：α(x−y) ∈ C（α ≥ 0，正齐次性）。✓
- (O4)：(x₁−y₁)+(x₂−y₂) = (x₁+x₂)−(y₁+y₂) ∈ C。✓

**平移等价性**：x ≥ y ⟺ x−y ∈ V₊——正向由 (O4) 加 −y（(O1) 给出 y ≥ y ⟹ −y ≥ −y）得 x−y ≥ 0；反向由 (x−y) ≥ 0 与 (O4) 加 y 得 x ≥ y。✓

**由序得锥**：V₊ 的凸性由 (O3)+(O4)（λx + (1−λ)y ≥ λ·0 + (1−λ)·0 = 0）、正齐次性由 (O3) 直接给出。⚠️ 但**尖性**（x ≥ 0 ∧ −x ≥ 0 ⟹ x = 0）需要反对称性 x ≥ y ∧ y ≥ x ⟹ x = y，而转录的 (O1)–(O4) 未显式包含该公理；「序关系」一词可能隐含之，或 (O1) 处乱码注释佚失了内容。此为复算中发现的一处潜在缺口，已记入 [[queries/12-1全节系统性转写讹误清单]]。

## 其他复算

- **ℝ² 不可比较例**：x = (1,−1), y = (0,2)，锥 C = ℝ₊²：x−y = (1,−3) ∉ C，y−x = (−1,3) ∉ C。✓ 故锥序一般仅为偏序（ℝ¹ 情形为全序——复算注：源文「只能是一种偏序」宜弱化）。
- **(o)有界 ⟺ 有界仅在 ℝ¹**：源文明确限定于 ℝ¹，不得外推。✓
- **(12.31) 修复**：ξ ≥ 0 应为 ξₙ ≥ 0 ∀n。✓（按上下文复原）
- **(12.33) 正算子**：定义式转录无误，见 [[concepts/正算子]]。

## 结论

等价定理的可复算部分全部通过；唯一潜在缺口是 (O1)–(O4) 是否隐含反对称性以支撑 V₊ 的尖性。概念页：[[concepts/有序向量空间与锥诱导偏序]]、[[concepts/凸锥]]。
