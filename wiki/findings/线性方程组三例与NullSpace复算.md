# 线性方程组三例与 NullSpace 复算

## 例 A：齐次方程组与 NullSpace（手册 4.5.2.1, 2. 之例）

p = {{1,−1,5,−1},{1,1,−2,3},{3,−1,8,1},{1,3,−9,7}}，Det[p] = 0。书中输出：

```
In[2] := NullSpace[p]
Out[2] = {{-1, -2, 0, 1}, {-3, 7, 2, 0}}
```

**复算成立**：两基向量对四行逐行代入均为零 —
- (−1,−2,0,1)：行内积依次 −1+2−1 = 0、−1−2+3 = 0、−3+2+1 = 0、−1−6+7 = 0；
- (−3,7,2,0)：依次 −3−7+10 = 0、−3+7−4 = 0、−9−7+16 = 0、−3+21−18 = 0。

两向量线性无关，构成四维空间中二维零空间的一组基；其任意线性组合均为该齐次方程组的解，与手册 4.5.2.1, 2. 中找到的解一致。（转写「NullSpace炉]」为讹。）

## 例 B：不相容方程组与 LinearSolve::nosol（手册 4.5.2.1, 2. 之例）

m1 = {{1,−2,3,−1,2},{3,−1,5,−3,−1},{2,1,2,−2,−3}}，b1 = {2,6,8}。

**复算成立**：第三行 = −第一行 + 第二行（逐分量 2 = −1+3、1 = 2−1、2 = −3+5、−2 = 1−3、−3 = −2−1），而右端 −2+6 = 4 ≠ 8，故确不相容；LinearSolve[m1,b1] 触发消息并原样返回输入：

```
LinearSolve::nosol: Linear equation encountered which has no solution.
```

## 例 C：超定但可解的方程组（手册 4.5.2.1, 2. 之例）

m2 = {{1,−1,2},{1,−2,−1},{3,−1,5},{−2,2,3}}，b2 = {1,2,3,−4}。

RowReduce[m2] = {{1,0,0},{0,1,0},{0,0,1},{0,0,0}} 显秩 3；LinearSolve[m2,b2] = {10/7, −1/7, −2/7}。

**复算成立**：解向量回代四个方程 — 10/7+1/7−4/7 = 1；10/7+2/7+2/7 = 2；30/7+1/7−10/7 = 3；−20/7−2/7−6/7 = −4，逐一吻合。
