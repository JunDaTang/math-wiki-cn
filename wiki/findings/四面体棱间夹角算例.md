# 四面体棱间夹角算例（表 3.9 第二基本问题解 2，数值已验证）

## 问题

一个四面体具有底 ABC 和顶点（顶点名在转写中脱落，由面名 ABS、BCS、CAS 可知为 S）。面 BCS 与 CAS 相互交成角 α = 80°00′，CAS 与 ABS 交成角 β = 74°18′，ABS 与 BCS 交成角 γ = 63°40′。求 AS、BS、CS 每两条棱之间的夹角。

## 方法：三面角 ↔ 球面三角形

以棱锥顶点 S 为球心的球面从三面角截出一个球面三角形：**面之间的二面角就是球面三角形的三个角，所求棱之间的夹角是球面三角形的边**。于是已知三角、求三边，对应 [[concepts/球面三角形六基本问题]] 的第二基本问题（WWW），按表 3.9 解 2（半边公式族）求解。

## 结果（直接证据，源文数值）

```
σ = 108°59′,  σ−α = 28°59′,  σ−β = 34°41′,  σ−γ = 45°19′
k′ = 1.246983,  cot(a/2) = 1.425514,  cot(b/2) = 1.516440,  cot(c/2) = 1.773328
```

## 独立复算验证（本 wiki 分析）

以 k′ = √[cos(σ−α)cos(σ−β)cos(σ−γ)/(−cos σ)] 复算：σ 的四个分值及 k′、三个 cot 值全部与源文吻合（6 位有效数字）。例如 cot(a/2) = k′/cos(σ−α) = 1.246983/cos(28°59′) ≈ 1.42551。

## 附带裁决（推断，但高置信）

转写中表 3.9 的 k′ 公式作「k′ = √cos(σ−α)cos(σ−β)cos(σ−γ)−cos σ」（减号），与本算例矛盾；仅在**除法**形式 k′ = √[cos(σ−α)cos(σ−β)cos(σ−γ)/(−cos σ)] 下数值复现。判定：分数线在转写中脱落，见 [[queries/表3-9中k撇公式的分数线是否在转写中脱落]]。同理「解 1: cosα = cosα+cosβcosγ」应为 cos a = (cos α + cos β cos γ)/(sin β sin γ)。

本算例同时是 [[concepts/多面角]]/[[concepts/二面角]] 与 [[concepts/四面体]] 到球面三角学的桥梁：SSS 存在条件（0° < a+b+c < 360° 且两边和大于第三边）恰是三面角面角和定理（[[findings/多面角全等对称与面角和]]）的条件，为 2D/3D 对偶的又一实例。
