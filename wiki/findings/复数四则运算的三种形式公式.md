# 复数四则运算的三种形式公式（式 1.136–1.138）

《数学手册》1.5.3 按[[comparisons/复数三种表示形式比较|三种形式]]平行给出[[concepts/复数]]的四则运算公式：

**加减法**（式 1.136）：逐项合并实部与虚部，与一般二项式处理方式相同；几何解释为[[concepts/高斯平面]]上向量的加减（图 1.8）：

z₁ + z₂ − z₃ + … = (a₁ + a₂ − a₃ + …) + i(b₁ + b₂ − b₃ + …)

**乘法**（式 1.137a–c）：

- 代数形式：z₁z₂ = (a₁a₂ − b₁b₂) + i(a₁b₂ + b₁a₂)
- 三角形式：模相乘、辐角相加，z₁z₂ = ρ₁ρ₂[cos(φ₁ + φ₂) + i sin(φ₁ + φ₂)]
- 指数形式：z₁z₂ = ρ₁ρ₂ e^{i(φ₁ + φ₂)}

**除法**（式 1.138a–c，定义为乘法的逆运算）：

- 代数形式：z₁/z₂ = (a₁a₂ + b₁b₂)/(a₂² + b₂²) + i(a₂b₁ − a₁b₂)/(a₂² + b₂²)（借[[concepts/共轭复数]]实数化分母）
- 三角形式：模相除、辐角相减
- 指数形式：z₁/z₂ = (ρ₁/ρ₂) e^{i(φ₁ − φ₂)}
- 注：除以零向量不存在。

**几何解释**：乘 z₂ 即把向量 z₁ 旋转 arg z₂ 并伸展 |z₂| 倍；除以 z₂ 即旋转 −arg z₂ 并收缩 |z₂| 倍；乘 i 即旋转 π/2 且模不变。

## 验证（直接证据）

1.5.3.4 综合例题逐步核算无误：

```
((3 − 4i)(−1 + 5i)²)/(1 + 3i) + (10 + 7i)/(5i)
(−1 + 5i)² = 1 − 10i − 25 = −2(12 + 5i)
(3 − 4i)(12 + 5i) = 56 − 33i
(56 − 33i)(1 − 3i) = −43 − 201i
−2(−43 − 201i)/10 = 8.6 + 40.2i
(10 + 7i)/(5i) = (7 − 10i)/5 = 1.4 − 2i
合计 = 10 + 38.2i ✓
```

属定义性/公式性内容；代数展开已逐项核算正确，例题独立复算一致。
