# 选主元法求逆矩阵的算例（已复算）

4.5.1.4：若 A 是 n×n 正则矩阵，则对方程组 y = Ax 应用选主元法实施 n 次步骤即可得到逆矩阵 A⁻¹；重排规则为「按 y_i 的下标重排矩阵的列，按 x_k 的下标重排矩阵的行」。

A = [[3, 5, 1], [2, 4, 5], [1, 2, 2]]，三次换轴（主元依次为第 3 行第 1 列的 1、第 2 行第 3 列的 1、第 1 行第 2 列的 −1）：

|      | x₁ | x₂ | x₃ |
|------|----|----|----|
| y₁ | 3 | 5 | 1 |
| y₂ | 2 | 4 | 5 |
| y₃ | **1** | 2 | 2 |

|      | y₃ | x₂ | x₃ |
|------|----|----|----|
| y₁ | 3 | −1 | −5 |
| y₂ | 2 | 0 | **1** |
| x₁ | 1 | −2 | −2 |

|      | y₃ | x₂ | y₂ |
|------|----|----|----|
| y₁ | 13 | **−1** | −5 |
| x₃ | −2 | 0 | 1 |
| x₁ | 5 | −2 | −2 |

|      | y₃ | y₁ | y₂ |
|------|----|----|----|
| x₂ | 13 | −1 | −5 |
| x₃ | −2 | 0 | 1 |
| x₁ | −21 | 2 | 8 |

按 y₁, y₂, y₃ 的下标顺序重排列、按 x₁, x₂, x₃ 的下标顺序重排行，得

```
A⁻¹ = [[2, 8, −21], [−1, −5, 13], [0, 1, −2]]
```

## 核验

已独立核验 A·A⁻¹ = I（逐元素复算，如第 1 行点第 1 列：3·2 + 5·(−1) + 1·0 = 1），且四张换轴表均按四条法则逐步复算吻合。属直接证据且已复算。
