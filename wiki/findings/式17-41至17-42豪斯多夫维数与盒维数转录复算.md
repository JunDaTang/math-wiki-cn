# 式 17.41–17.42 豪斯多夫维数与盒维数转录复算

## 转录

```latex
mu_{d,eps}(A) = inf{ sum_i (diam B_i)^d : A subset cup_i B_i, diam B_i <= eps }   (17.41a)
mu_d(A)       = lim_{eps->0} mu_{d,eps}(A) = sup_{eps>0} mu_{d,eps}(A)            (17.41b)
d_H(A)        = { +inf, 若 mu_d(A) != 0 对一切 d >= 0;  inf{ d >= 0 : mu_d(A) = 0 } }  (17.41c)
% HD1 d_H(空集)=0；HD2 0≤d_H(A)≤n；HD3 单调；HD4 可数稳定 sup；HD5 有限/可数集 0；
% HD6 利普希茨不增、双利普希茨不变

d̄_B(A) = limsup_{eps->0} ln N_eps(A) / ln(1/eps)                                (17.42a)
d_B(A)  = liminf_{eps->0} ln N_eps(A) / ln(1/eps)                                (17.42b)
% BD1 d_H ≤ d_B；BD2 光滑 m 维曲面二者皆为 m；BD3 d_B(A)=d_B(闭包)；
% BD4 可数稳定性对盒维数一般不成立【前句疑脱 HD4 对照】
```

## 复算

- **康托尔集**：$d_H(C)=\ln2/\ln3=0.63093$（源文 ≈0.6309 ✓）。构造核验：$G_n$ 由 $2^n$ 个长 $3^{-n}$ 闭区间组成，$C=\bigcap_nG_n$；$\lambda(C)=\lim(2/3)^n=0$（源文脱「0」）。
- **$A=\{0,1,\tfrac12,\tfrac13,\dots\}$**：可数 ⟹ $d_H=0$（HD5）✓。盒维数：点 $1/n$（$n\le\varepsilon^{-1/2}$）两两间距 $\ge\varepsilon$，需 $\ge\varepsilon^{-1/2}$ 个 $\varepsilon$-区间；其余点全部落于 $[0,\varepsilon^{1/2}]$，覆盖需 $O(\varepsilon^{1/2}/\varepsilon)=O(\varepsilon^{-1/2})$ 个区间。故 $N_\varepsilon\asymp\varepsilon^{-1/2}$，$d_B=\tfrac12$ ✓。
- **$\mathbb{Q}\cap[0,1]$**：闭包 $=[0,1]$，由 BD3 与 BD2（一维光滑）得 $d_B=1$；可数 ⟹ $d_H=0$（HD5）✓。此例与上例共同展示 $d_H<d_B$ 的差距来自聚点结构。
- **豪斯多夫测度构造的体积动机**：$\mu_{3,\varepsilon}$（球的 $\tfrac43\pi r^3$ 之和的下确界）当 $\varepsilon\to0$ 给出勒贝格外测度——转录自源文引言，与标准理论一致。

## 判定

定义、性质与三例数值全部复算通过；转录层面有两处脱字疑点（见下）。
