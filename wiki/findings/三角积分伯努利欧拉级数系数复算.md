# 三角积分伯努利欧拉级数系数复算

21.7.3 共六条积分以 Bernoulli 数或 Euler 数通项的无穷级数表出。对每条的通项取 n=0,1,2,… 与表列显式系数逐项交叉核对，全部严格相符（编号约定见 [[concepts/伯努利数与欧拉数（手册紧缩编号约定）]]：B₁=1/6, B₂=1/30, B₃=1/42, B₄=1/30；E₀=1, E₁=1, E₂=5, E₃=61, E₄=1385）：

| 条目 | 积分 | 通项 | 显式系数核对 |
|---|---|---|---|
| 290 | ∫x dx/sin ax | 2(2^{2n−1}−1)B_n(ax)^{2n+1}/(2n+1)! | n=1..4：(ax)³/18、7(ax)⁵/1800、31(ax)⁷/105840、127(ax)⁹/5443200 ✓ |
| 329 | ∫x dx/cos ax | E_n(ax)^{2n+2}/((2n+2)(2n)!) | n=0..4：(ax)²/2、(ax)⁴/8、5(ax)⁶/144、61(ax)⁸/5760、1385(ax)^{10}/3628800 ✓ |
| 413 | ∫x·tan ax dx | 2^{2n}(2^{2n}−1)B_n a^{2n−1}x^{2n+1}/(2n+1)! | ax³/3、a³x⁵/15、2a⁵x⁷/105、17a⁷x⁹/2835 ✓ |
| 414 | ∫tan ax dx/x | 2^{2n}(2^{2n}−1)B_n(ax)^{2n−1}/((2n−1)(2n)!) | ax、(ax)³/9、2(ax)⁵/75、17(ax)⁷/2205 ✓ |
| 422 | ∫x·cot ax dx | 2^{2n}B_n a^{2n−1}x^{2n+1}/(2n+1)! | x/a、−ax³/9、−a³x⁵/225 ✓ |
| 423 | ∫cot ax dx/x | 2^{2n}B_n(ax)^{2n−1}/((2n−1)(2n)!) | −1/(ax)、−ax/3、−(ax)³/135、−2(ax)⁵/4725 ✓ |

示例（290 之 n=2 项）：2(2³−1)B₂(ax)⁵/5! = 2·7·(1/30)(ax)⁵/120 = 7(ax)⁵/1800，与显式项 7(ax)⁵/(3·5·5!) 一致。

## 附带发现

329 与 414 通项中的「(2n!)」按显式系数核对应为 **(2n)!**——转写疑脱外括号（并入 [[queries/21-7-3全节系统性转写讹误清单]]，不影响按显式系数复原的数学内容）。

## 意义

六条级数积分使手册紧缩编号约定在积分表中得到全量再验证，与 21.5 级数表处的验证相互印证；六式的对偶结构见 [[comparisons/伯努利与欧拉数级数积分比较]]。
