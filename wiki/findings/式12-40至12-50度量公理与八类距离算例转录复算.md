# 式 12.40–12.50 度量公理与八类距离算例转录复算

## 转录内容

```
(M1) ρ(x,y) ⩾ 0 且 ρ(x,y) = 0 ⟺ x = y   （非负性）        (12.40)
(M2) ρ(x,y) = ρ(y,x)                     （对称性）        (12.41)
(M3) ρ(x,y) ⩽ ρ(x,z) + ρ(z,y)            （三角形不等式）  (12.42)
```

八类距离算例：(12.43) 欧几里得、(12.44) 最大、(12.45) 绝对值距离（均在 $\mathbb{R}^n/\mathbb{C}^n$）；汉明距离（0-1 字）；(12.46) sup 距离（$m$ 及 $c_0$）；(12.47) $\ell^p$；(12.48) $C([a,b])$ 上确界距离；(12.49) $C^{(k)}$；(12.50) $L^p(\Omega)$。完整表格见 [[sources/10-数学手册原书第10版--8-122-距离空间--4k304g]]。

## 复算

1. **汉明算例**：$\rho((1110),(0100))$：第 1 位 $1\ne 0$、第 2 位 $1=1$、第 3 位 $1\ne 0$、第 4 位 $0=0$，相异位数 $=2$ ✓
2. **$n=1$ 退化**：$\sqrt{(\xi_1-\eta_1)^2}=\lvert\xi_1-\eta_1\rvert$、$\max\lvert\cdot\rvert=\lvert\cdot\rvert$、$\sum\lvert\cdot\rvert=\lvert\cdot\rvert$，三距离均退化为绝对值 $\lvert x-y\rvert$ ✓
3. **公理验证**：M1/M2 对各例逐条直接成立；M3 对 (12.43)–(12.45) 由一维三角形不等式（平方和/取 max/求和）得出；(12.47)/(12.50) 的 M3 即 Minkowski 不等式（本节未证明，属标准结论）✓
4. **术语小瑕**：源文称 $\sum\lvert\xi_k\rvert^p$「绝对收敛」，因项非负，「收敛」即足。

## 结论

度量公理与八类距离的转录在数学内容上无误（OCR 讹字另计，见 [[queries/12-2全节系统性转写讹误清单]]）。直接证据（源文公式）+ 本页复算，可信度高。
