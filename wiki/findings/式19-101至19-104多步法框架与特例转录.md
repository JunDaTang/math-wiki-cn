# 式 19.101–19.104 多步法框架与特例转录

**转录**（源文逐字保留）：

```latex
(19.101)  y_{i+k} + \alpha_{k-1} y_{i+k-1} + \alpha_{k-2} y_{i+k-2} + \dots + \alpha_1 y_{i+1} + \alpha_0 y_i
          = h(\beta_k f_{i+k} + \beta_{k-1} f_{i+k-1} + \dots + \beta_1 f_{i+1} + \beta_0 f_i),  \alpha_k = 1
(19.102)  y_{i+2} - y_i = 2h f_{i+1}
(19.103)  y_{i+2} - y_i = \frac{h}{3}(f_i + 4f_{i+1} + f_{i+2})
(19.104)  y_{i+k} - y_{i+k-1} = \sum_{j=0}^{k-1}\Big[\int_{x_{i+k-1}}^{x_{i+k}} L_j(x)\,dx\Big] f(x_{i+j}, y_{i+j})
          = h \sum_{j=0}^{k-1} \beta_j f(x_{i+j}, y_{i+j})
```

**评注**：

- (19.102) 中点法则：以 x_i 与 x_{i+2} 之间的割线斜率代替 y′(x_{i+1})，显式跳跃格式。
- (19.103) 米尔恩法则：积分由辛普森公式近似，隐式。
- (19.104) 亚当斯—巴什福思法则：基于插值节点 x_i,…,x_{i+k−1} 的拉格朗日插值多项式（19.6.1.2，未入库），在 x_{i+k−1} 与 x_{i+k} 之间积分，对 y_{i+k} 显式；系数 β_j 计算见 [19.4]。
- 三式形式均为标准格式，本维基仅作转录比对，未做逐系数复算。
- 转写脱文：源文“若 α₀+β₀≠0 公式 (19.101)步法”一句脱字，疑为“则公式 (19.101) 为 k 步法”；“步法中，k 个初值…”疑脱“在 k”，见 [[queries/式19-101后k步法判据句脱文之辨]]。
