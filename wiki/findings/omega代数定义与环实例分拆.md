# Ω代数定义与环实例分拆

**发现**：5.6.1 以运算符号集 Ω 按元数的分拆（型／标志）定义 Ω代数，并给出环作为 Ω代数的四运算分拆实例与子代数定义。

## 直接证据（源文转写，Ω 符号脱落已按上下文复原）

- Ω 划分为两两不相交的 Ωₙ（n ∈ ℕ）：Ω₀ 含常数，Ωₙ（n > 0）含 n 元运算符号；族 $(\Omega_n)_{n\in\mathbb{N}}$ 称为型或标志。
- Ω代数：$A = (A, \{\omega^A \mid \omega \in \Omega\})$，其中每个 ω ∈ Ωₙ 指派 A 中的 n 元运算 ω^A；Ω 有限时可记 $A = (A, \omega_1^A, \dots, \omega_k^A)$。
- 环实例：Ω₀ = {ω₁} ↦ 常数 0；Ω₁ = {ω₂} ↦ 取加法逆；Ω₂ = {ω₃, ω₄} ↦ 加法、乘法。
- 子代数：B ⊆ A 且 ω^B 是 ω^A（ω ∈ Ω）限制在 B 上的运算。

## 复核与推断（区分说明）

- 定义性内容为直接证据。环分拆与已入库环公理（[[findings/环公理与特征性质组]]：含 0 与加法逆的加法交换群、乘法结合、分配律）的一致性已人工核对：四个运算符号恰好覆盖环公理所需的 0、加法逆、加法、乘法，无多余运算。
- 源转写中 Ω 与若干「n 元」字样脱落（如「含 重运算符号」），复原属推断，需对照原书（[[queries/5-6全节系统性转写讹误清单]]）。
