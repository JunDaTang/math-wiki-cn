# 增量与折扣的相对百分比换算

同一增减量相对于变化后新值的百分比（"含量"）不等于原百分比：涨价 p% 后含量为 $\frac{100p}{100+p} < p$（式 (1.72)），降价 p% 后含量为 $\frac{100p}{100-p} > p$（式 (1.74)）。涨价使含量缩小、降价使含量放大。

## 证据

手册 1.3.1.2 与 1.3.1.3 给出两例：

- €200 加 15% 附加费 → €230，对消费者而言价格包含 $\tilde{p} = \frac{15\cdot100}{115} = 13.04\%$ 的增量；
- €300 打 10% 折扣 → €270，对消费者而言价格包含 $\tilde{p} = \frac{10\cdot100}{90} = 11.11\%$ 的折扣。

两式均可由比例式 $K\frac{p}{100} : \widetilde{K} = \tilde{p} : 100$ 直接导出，算例数值经独立复算一致。概念背景见 [[百分率计算]]。

## 适用范围

该换算针对"增量/折扣占新值的比例"这一非平凡口径；若以原值为基数，则百分比仍是 p 本身。
