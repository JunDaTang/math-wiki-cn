# 式 16.8–16.29 事件布尔代数运算法则转录复算

## 转录内容（十一组法则，编号 16.8–16.27；组名为编者归纳，原文仅编号 (1)–(10)）

| 组 | a | 编号 | b | 编号 |
|---|---|---|---|---|
| (1) 交换 | $A+B = B+A$ | 16.8 | $AB = BA$ | 16.9 |
| (2) 幂等 | $A+A = A$ | 16.10 | $AA = A$ | 16.11 |
| (3) 结合 | $A+(B+C) = (A+B)+C$ | 16.12 | $A(BC) = (AB)C$ | 16.13 |
| (4) 互补 | $A+\bar{A} = I$ | 16.14 | $A\bar{A} = O$ | 16.15 |
| (5) 分配 | $A(B+C) = AB+AC$ | 16.16 | $A+BC = (A+B)(A+C)$ | 16.17 |
| (6) De Morgan | $\overline{A+B} = \bar{A}\bar{B}$ | 16.18 | $\overline{AB} = \bar{A}+\bar{B}$ | 16.19 |
| (7) 差与补 | $B-A = B\bar{A}$ | 16.20 | $\bar{A} = I-A$ | 16.21 |
| (8) 差集分配 | $A(B-C) = AB-AC$ | 16.22 | $AB-C = (A-C)(B-C)$ | 16.23 |
| (9) 极元 | $O \subseteq A$ | 16.24 | $A \subseteq I$ | 16.25 |
| (10) 包含等价 | $A \subseteq B \Rightarrow A = AB$ | 16.26 | $A \subseteq B \Rightarrow B = A + B\bar{A}$（反之亦然） | 16.27 |

**完备事件组（11）**：事件组 $A_\alpha$（$\alpha \in \theta$，$\theta$ 为有限或无限指标集）满足 $A_\alpha A_\beta = O$（$\alpha \neq \beta$，式 16.28）且 $\sum_{\alpha\in\theta} A_\alpha = I$（式 16.29），则称 $A_\alpha$ 为完备事件组。

## 复算核验（直接证据，集合代数推演）

- 交换、幂等、结合、分配 (1)–(5)：集合并/交的标准布尔律，成立 ✓。
- De Morgan 律 (6a)(6b)：$x \in \overline{A+B} \iff x \notin A \cup B \iff x \in \bar A \cap \bar B$ ✓。
- (7a) $B - A = B\bar A$：差集定义直接给出 ✓；(7b) $\bar A = I - A$：由 (7a) 取 $B = I$ ✓。
- (8a) $A(B-C) = AB - AC$：两边均等于 $AB\bar C$ ✓。
- (8b) $AB - C = (A-C)(B-C)$：左边 $= AB\bar C$；右边 $= (A\bar C)(B\bar C) = AB\bar C$ ✓。
- (9)(10) 极元与包含等价式：$A \subseteq B \iff A = AB$、$\iff B = A + B\bar A$ 均为集合包含的标准刻画 ✓。
- 完备事件组 16.28–16.29 即样本空间的两两不交划分，定义自洽 ✓。

## 转写说明

- 法则 (1)–(10) 公式本体转录完整；(10) 的文字「反之亦然」表明 16.26–16.27 为等价刻画，符合原文。
- 散文中 $I$、$O$ 记号脱落，但式 16.14、16.15、16.24、16.25 交叉内证其含义。

## 结论

式 16.8–16.27 十一组法则经集合代数逐条复算全部成立，转录内容可靠。事件域的布尔代数结构（对有限运算封闭）成立，但其与公理 16.32 可数加性的 σ-代数张力另见 [[queries/事件域称布尔代数与可数加性之辨]]。
