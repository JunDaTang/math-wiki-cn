# 魏尔斯特拉斯一致收敛审敛法（强级数法，式 7.81a–c）

手册 7.3.2.1 第 3 条给出的判别法：级数 (7.81a) 在一已知区域上一致收敛，若存在正项收敛级数 (7.81b)，使对该区域每个 x 都有不等式 (7.81c) 成立：

```latex
f_1(x) + f_2(x) + \dots + f_n(x) + \dots        % (7.81a) 待判级数
c_1 + c_2 + \dots + c_n + \dots                  % (7.81b) 强级数（正项收敛）
|f_n(x)| \leqslant c_n                            % (7.81c) 逐项控制
```

(7.81b) 称为级数 (7.81a) 的**强级数**。

## 判读

- 手册为陈述式给出、不附证明；此为经典标准结果（Weierstrass M-判别法），证据强度：高。
- 判别法为充分条件，且附带区域上的绝对收敛。
- 应用印证：[[式7-79ex级数有界区间一致收敛算例]] 中 e^x 级数在 |x| < a 上可取 c_n = a^n/n!（Σa^n/n! 收敛）为强级数；[[阿贝尔定理]]（幂级数内闭一致收敛）亦可用此法立刻得到（取 c_n = |a_n| r₀ⁿ，r₀ < r）。
- 转写注意：源文该条变量符号脱落严重（如「不存在数 ，使得对千收敛域中的每个 上述关系成立」），此处按数学上下文补全。
