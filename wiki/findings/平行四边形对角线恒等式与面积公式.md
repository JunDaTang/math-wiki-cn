# 平行四边形对角线恒等式与面积公式（式 3.18–3.20）

对平行四边形（邻边 $a, b$，对角线 $d_1, d_2$，$a, b$ 的夹角 $\alpha$，底 $a$ 上的高 $h$，图 3.15），《数学手册》给出：

$$d_1^2 + d_2^2 = 2(a^2 + b^2) \tag{3.18}$$

$$h = b\sin\alpha \tag{3.19}$$

$$S = ah \tag{3.20}$$

## 注记

- 式 3.18 通称平行四边形定律（parallelogram law，源未冠名）。
- 式 3.19 中 $h$ 为相对于底 $a$ 的高；式 3.20 的面积即底乘高，两式合起来给出 $S = ab\sin\alpha$。

## 复核（本 wiki 补充推导，与导入分析的代数复核一致）

设两边向量为 $\vec{u}, \vec{v}$（$|\vec{u}| = a$，$|\vec{v}| = b$），对角线对应 $\vec{u}+\vec{v}$ 与 $\vec{u}-\vec{v}$，展开即得

$$d_1^2 + d_2^2 = |\vec{u}+\vec{v}|^2 + |\vec{u}-\vec{v}|^2 = 2|\vec{u}|^2 + 2|\vec{v}|^2 = 2(a^2+b^2)$$

特例检验：正方形（$a = b$）时 $d_1 = d_2 = a\sqrt{2}$，两边均为 $4a^2$。

## 适用范围

仅对[[concepts/平行四边形]]成立；对一般四边形应改用式 3.34（欧拉四边形定理）与式 3.35（见 [[findings/内角和与欧拉四边形定理]]、[[findings/对角线夹角面积公式]]）。
