# 式 9.110a–b 位势方程与拉普拉斯微分方程逐字转录

本 finding 记录 9.2.3.4 位势方程小节（式 9.110a、9.110b）的逐字转录。

## 逐字转录

```latex
(9.110a)  \Delta u = -4\pi\varrho   % 位势方程 / 泊松微分方程
(9.110b)  \Delta u = 0              % 拉普拉斯微分方程（ρ ≡ 0 时的齐次微分方程）
```

源文要点：二阶线性偏微分方程 (9.110a) 被称为位势方程（potential equation）或泊松微分方程（Poisson differential equation）（参见原书第 951 页 13.5.2，未入库），它确定了由一个标量点函数 ρ(x) 决定的标量场的位势 u(x)，这里〔x〕有坐标 x₁, x₂, x₃，Δ 是拉普拉斯算子；在原书第 951 页 13.5.2 讨论了 (9.110a) 的解，以及“在点〔M〕处的位势 u_M(x₁, x₂, x₃)”；当 ρ ≡ 0 时得到齐次微分方程的拉普拉斯微分方程 (Laplace differential equation) (9.110b)。

## 复算与核验

- Δu = −4πρ 的系数归一化与位势论中的标准泊松方程一致（对应高斯单位制/牛顿位势的 4π 约定；独立可验证背景）。
- ρ ≡ 0 的齐次化与式 9.110b 一致；椭圆归类与边值问题提法见 [[位势方程]]、[[二阶偏微分方程的类型]]。
- 解法内容不在本源内（回指未入库的 13.5.2），本源对该方程只给定义不给解。

## 转写缺损与译文疑点

- “它确定了有一个可能的标量点函数 ρ(x) 决定的标量场的位势 u(x)”语义不通，疑为“由一个给定的标量点函数 ρ(x) 决定的”之译文讹误。
- “这里 有坐标 x₁, x₂, x₃”中 x 被丢；“在点 处的位势 u_M”中 M 被丢。
- 详见 [[9-2-3全节系统性转写讹误清单]]。
