# 测地左手坐标系定则与「平面三角公式无须改变」断言

**发现内容（直接证据）：**在几何学中通常使用右手坐标系确定平面或空间中的点；与之相反，大地测量学中使用左手坐标系，具体定则：

1. 平面左手系（图 3.37）：横坐标 x 轴朝上，纵坐标 y 轴朝右；象限按**顺时针**方向列出（图 3.37、3.38）。
2. x 轴的定向出于实际考虑；测量长距离时大都使用佐德纳或高斯—克吕格坐标系，正向是格网北向（前向引用 3.4.1.2，未摄入）。
3. 三维左手直角坐标 $(y, x, z)$：z 轴指向天顶（图 3.36）。
4. 测地极坐标中角（方位）的正向是顺时针方向；高度用天顶角或仰角（该句为残句）。
5. **关键断言**：由于象限以和平面三角中右手笛卡儿坐标系相反的顺序列出，「平面三角中的公式仍然成立而无须改变」。

**内部佐证（分析层）：**本节其后所有坐标正算公式 $y = y_B + s\sin t$、$x = x_B + s\cos t$（3.106c–d、3.107b–c、3.110g–h、3.112n–o、3.114h–k）均与顺时针 t 的左手系约定自洽；表 3.6 的象限编号亦按顺时针。该定则延伸 [[concepts/图形的定向]] 与 [[findings/角的方向约定与反角关系]]。

**转写备注：**记号段（点的记号、天顶角句）符号缺失，见 [[queries/平面三角学记号段符号缺失是否为讹误]]；左右手坐标系的一般讨论位于 3.5.3.1（未摄入）。

**证据类型：**直接证据（约定性陈述），且获本节全部后续公式的结构性印证。
