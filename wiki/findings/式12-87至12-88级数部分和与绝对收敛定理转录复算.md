# 式 12.87–12.88 级数部分和与绝对收敛定理转录复算

## 转录内容

部分和递推 s₁ = x₁，s_k = s_{k−1} + x_k（12.87）；级数和 s = lim_{k→∞} Σ_{n=1}^{k} xₙ（12.88）；绝对收敛定义为数项级数 Σ‖xₙ‖ 收敛。定理：在巴拿赫空间中每个绝对收敛的级数都收敛，并且 ‖s‖ ≤ Σ‖xₙ‖（s 为其和）。

## 复算（编者直接推导，经典论证）

- 收敛性：若 Σ‖xₙ‖ 收敛，则 ‖s_{k+m} − s_k‖ = ‖x_{k+1} + ⋯ + x_{k+m}‖ ≤ Σ_{n=k+1}^{k+m}‖xₙ‖ → 0，部分和为柯西列，由完备性得收敛。✔
- 范数估计：‖s_k‖ ≤ Σ_{n=1}^{k}‖xₙ‖，令 k → ∞ 用范数连续性（式 12.85）得 ‖s‖ ≤ Σ‖xₙ‖。✔
- **完备性前提不可去**：在不完备赋范空间中，取非收敛柯西列的子列 {u_{n_k}} 使 Σ‖u_{n_{k+1}} − u_{n_k}‖ < ∞，则级数 x₁ = u_{n₁}、x_k = u_{n_k} − u_{n_{k−1}} 绝对收敛但其部分和 telescope 至不存在的极限，故不收敛。归属注意：定理只在巴拿赫空间成立。

## 发现的讹误

1. 「则就定义 $\vec{\mathsf{J}}-$ 个收敛级数」——乱码，疑应为「则就定义为一个收敛级数」。
2. 「$s_1, s_2, \cdots, s_k, \cdots$ 称作级数的部分和极限」——语序混乱，疑应为「称作级数的部分和，（其）极限」。
3. 「这里 为其和」——缺符号 s。
4. 「收敛千」「对于」等 OCR 错字；12.3.2 开头「完备化成一个巴拿赫空间 x.」句尾衍字 x。
