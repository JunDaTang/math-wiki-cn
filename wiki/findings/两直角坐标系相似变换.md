# 两直角坐标系之间的相似变换（式 3.108–3.109）

**发现内容（直接证据，公式逐字保留）：**为在国家地图上定位一个给定点，需将本地坐标系 $y', x'$ 变换为地图坐标系 $y, x$（图 3.41）：将 $y', x'$ 旋转角 $\varphi$、平移 $y_0, x_0$，并以比例因子 $q$ 缩放（$\vartheta_{AB}$ 为 $y', x'$ 系中的方位角）。变换关系：

$$s_{AB} = \sqrt{\Delta y_{AB}^2 + \Delta x_{AB}^2},\qquad s'_{AB} = \sqrt{\Delta y_{AB}^{\prime 2} + \Delta x_{AB}^{\prime 2}},\qquad q = \frac{s_{AB}}{s'_{AB}} \tag{3.108a–c}$$

$$\varphi = t_{AB} - \vartheta_{AB},\qquad \tan t_{AB} = \frac{\Delta y_{AB}}{\Delta x_{AB}},\qquad \tan\vartheta_{AB} = \frac{\Delta y'_{AB}}{\Delta x'_{AB}} \tag{3.108d–f}$$

$$y_0 = y_A - q x_A \sin\varphi - q y_A \cos\varphi \tag{3.108g}$$

$$x_0 = x_A + q y_A \sin\varphi - q x_A \cos\varphi \tag{3.108h}$$

$$y_C = y_A + q\sin\varphi\,(x_C' - x_A') + q\cos\varphi\,(y_C' - y_A') \tag{3.108i}$$

$$x_C = x_A + q\cos\varphi\,(x_C' - x_A') - q\sin\varphi\,(y_C' - y_A') \tag{3.108j}$$

评论：下面两个公式可用作检验：

$$y_C = y_A + q s'_{AC}\sin(\varphi + \vartheta_{AC}) \tag{3.108k}$$

$$x_C = x_A + q s'_{AC}\cos(\varphi + \vartheta_{AC}) \tag{3.108l}$$

如果线段 AB 在 $x'$ 轴上，公式简化为：

$$a = \frac{\Delta y_{AB}}{y_B'} = q\sin\varphi,\qquad b = \frac{\Delta x_{AB}}{x_B'} = q\cos\varphi \tag{3.109a,b}$$

$$y_C = y_A + a x_C' + b y_C',\qquad x_C = x_A + b x_C' - a y_C' \tag{3.109c,d}$$

$$y_C' = \Delta y_{AC} b - \Delta x_{AC} a,\qquad x_C' = \Delta x_{AC} b + \Delta y_{AC} a \tag{3.109e,f}$$

**疑点（采信前须核对，详见 [[queries/式3-109a分母与3-109ef是否遗漏分母]]）：**

- (3.109a)：前提「AB 在 $x'$ 轴上」意味着 $y_B' = 0$，分母疑应为 $x_B'$。
- (3.109e–f)（分析层推导）：正变换矩阵 $M = \begin{pmatrix} a & b \\ b & -a \end{pmatrix}$ 满足 $M^2 = (a^2+b^2)I = q^2 I$，故反解式应带分母 $\frac{1}{a^2+b^2}$，转写式疑遗漏该分母。
- (3.108g–h) 中 $x_A, y_A$ 疑应加撇（$x_A', y_A'$，即本地系坐标）。

**证据类型：**(3.108a–l) 为直接证据且数学自洽（含检验式 k–l）；(3.109) 系列含疑点，整体采信度 medium。
