# 直线交点直线束与夹角公式（式 3.311–3.313）

## 两条直线的交点（克莱姆行列式解）

```
A₁x + B₁y + C₁ = 0,  A₂x + B₂y + C₂ = 0        (3.311a)
x₀ = |B₁ C₁; B₂ C₂| / |A₁ B₁; A₂ B₂|
y₀ = |C₁ A₁; C₂ A₂| / |A₁ B₁; A₂ B₂|           (3.311b)
```

判据：|A₁ B₁; A₂ B₂| = 0 ⟺ 两直线平行；A₁/A₂ = B₁/B₂ = C₁/C₂ ⟺ 两直线重合。

## 直线束

第三条直线过前两条的交点 ⟺ 三阶系数行列式为零 (3.312b)；束方程

```
(A₁x + B₁y + C₁) + λ(A₂x + B₂y + C₂) = 0   (−∞ < λ < +∞)   (3.312c)
```

给出过交点的全部直线（第二条直线除外）。若两条基线以法线式（[[concepts/黑塞法式]]）给出，λ = ±1 时得到交点处角的平分线。展开见 [[concepts/直线束]]。

## 两条直线的夹角（一般式与斜率式两套）

```
tan φ = (A₁B₂ − A₂B₁)/(A₁A₂ + B₁B₂)                    (3.313b)
cos φ = (A₁A₂ + B₁B₂)/(√(A₁²+B₁²)·√(A₂²+B₂²))          (3.313c)
sin φ = (A₁B₂ − A₂B₁)/(√(A₁²+B₁²)·√(A₂²+B₂²))          (3.313d)
tan φ = (k₂ − k₁)/(1 + k₁k₂)                            (3.313e)
cos φ = (1 + k₁k₂)/(√(1+k₁²)·√(1+k₂²))                  (3.313f)
sin φ = (k₂ − k₁)/(√(1+k₁²)·√(1+k₂²))                   (3.313g)
```

角 φ 按从第一条直线到第二条直线的逆时针方向度量。平行：A₁/A₂ = B₁/B₂ 或 k₁ = k₂；垂直（正交）：A₁A₂ + B₁B₂ = 0 或 k₂ = −1/k₁。

本组为标准结果，强度高；分析阶段未逐条数值复算，replicated 标记为 null。
