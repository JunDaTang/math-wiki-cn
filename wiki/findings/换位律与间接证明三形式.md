# 换位律与间接证明三形式（式 5.19–5.20，已复算）

《数学手册(原书第10版)》5.1.1.7「重言式、数学中的推理」：

```latex
A ⇒ B ⇔ B̄ ⇒ Ā,   A ⇒ B = B̄ ⇒ Ā                          % (5.19a/b) 换位律
A ⇒ B = A B̄ ⇒ Ā,   A ⇒ B = A B̄ ⇒ B,   A ⇒ B = A B̄ ⇒ F   % (5.20a/b/c) 间接证明
```

**换位律**（5.19a）是重言式；解释：证明 B 是 A 的推论，与证明 Ā 是 B̄ 的推论是一回事（原书解释句中命题字母转写脱落）。

**间接证明**原理：为了证明 B 是 A 的推论，假设 B 错误，并在 A 正确的假设下导出矛盾；命题演算中可用 (5.20a–c) 三种方式形式化（原书参见 1.1.2.2，未入库）。

**复算结论**：本 wiki 已独立复算三式——右边皆可化归为 Ā∨B（例如 AB̄⇒F = ¬(A∧B̄)∨F = Ā∨B∨F = Ā∨B），与 (5.17a) 一致；换位律亦经真值表/化简核验成立。均为直接证据 + 独立复算。
