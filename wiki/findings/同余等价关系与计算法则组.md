# 同余等价关系与计算法则组（式 5.244–5.245）

**来源**：[[sources/10-数学手册原书第10版--10-543-同余和剩余类--n0ce67]]（5.4.3.1–5.4.3.2）。

**陈述**：设 m > 1 为正整数，a ≡ b (mod m) 当且仅当 m | (a − b)。模 m 同余满足：

$$a \equiv a \pmod m\ (\forall a \in \mathbb{Z});\quad a \equiv b \Rightarrow b \equiv a;\quad a \equiv b \land b \equiv c \Rightarrow a \equiv c \pmod m, \tag{5.244a–c}$$

即模 m 同余是 ℤ 上的等价关系。计算法则：

$$a \equiv b \land c \equiv d \Rightarrow a+c \equiv b+d,\ a\cdot c \equiv b\cdot d \pmod m; \tag{5.245a–b}$$
$$a c \equiv b c \land \gcd(c,m)=1 \Rightarrow a \equiv b \pmod m; \tag{5.245c}$$
$$a c \equiv b c \land c \neq 0 \Rightarrow a \equiv b \pmod{m/\gcd(c,m)}. \tag{5.245d}$$

**示例复算**：3 ≡ 13 ≡ 38 ≡ −2 (mod 5)——3、13、38、−2 除以 5 的余数均为 3（−2 = 5·(−1) + 3）。✓ 直接验算。

**证据类型**：直接证据（源文公式 + 算例复算）。式 (5.245d) 的减弱消去律（消去时模数按 gcd 缩小）是本组中最易被忽略的一条；[[concepts/线性同余式|线性同余式]] 的解数结构依赖同类的模缩机理。

**转写备注**：源文首段「如果当除以 时两个整数 有相同的余数」「是差 a − b 的因子」等处脱落 m、a、b 等变量名，依数学重构补全（见 [[queries/5-4-3全节系统性转写讹误清单]]）。
