# 三次多项式按 Δ=3ac−b² 的单调/双极值二分及实根 1/2/3 情形（式 2.42）

2.3.3 以 $\Delta = 3ac - b^2$ 为形态判据，给出三次多项式 $y = ax^3 + bx^2 + cx + d$（式 2.42）的二分：

- **Δ ≥ 0**：函数单调——a>0 时单调递增，a<0 时单调递减；
- **Δ < 0**：恰有一个局部极大值与一个局部极小值。a>0 时 y 由 $-\infty$ 增至极大、减至极小、再增至 $+\infty$；a<0 时相反（$+\infty \to$ 极小 $\to$ 极大 $\to -\infty$）。

与 x 轴的交点（即实根）可能有 1、2（此时存在一点，x 轴在该点为曲线的切线，即二重根）或 3 个。

## 术语辨析（重要）

此 $\Delta = 3ac - b^2$ 控制的是**单调性与极值形态**，与 [[三次方程判别式的三情形]]（原文 1.6.3.2 式 1.156）中含 d 的**根**判别式不是同一对象：后者决定根数与重数，前者不含 d、不可能决定根数。事实上 $\Delta$ 是导数 $y' = 3ax^2 + 2bx + c$ 判别式的 $-\tfrac{1}{4}$ 倍：

$$\mathrm{disc}(y') = 4b^2 - 12ac = -4\Delta$$

即它衡量 y′ 有无实零点（原函数有无驻点）。详见 [[三次多项式形态判别式与三次方程根判别式比较]] 与 [[三次多项式判别式与三次方程根判别式口径冲突]]。

## 证据评估

- **独立验证**（ingest 时完成）：
  - $y = x^3 - 3x$（a=1, b=0, c=−3, d=0，Δ=−9<0）确有极大点 (−1, 2) 与极小点 (1, −2)（由 $y' = 3x^2 - 3$ 直接验证）；
  - $y = x^3 - 3x^2$（Δ=−9）确有极大点 (0, 0) 与极小点 (2, −4)（由 $y' = 3x^2 - 6x$ 直接验证）；
  - $y = x^3$（Δ=0）单调，$y = x^3 + x$（Δ=3>0）严格递增。均与原文一致。
- **论证**（推断）：$y' = 3ax^2 + 2bx + c$ 为二次，其判别式 $-4\Delta \leqslant 0$ 时 y′ 不变号（符号由首项系数 3a 决定），故 Δ≥0 时单调；Δ<0 时 y′ 有两个实零点，构成一极大一极小。
- **直接证据**：原书 2.3.3 原文（式 2.42 与图 2.13(a)(b)(c)）。
