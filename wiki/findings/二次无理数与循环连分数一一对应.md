# 二次无理数与循环连分数互相表示

《数学手册(原书第10版)》1.1.1.4, 2. 给出双向论断：**每个循环连分数都表示一个二次无理数，反之，每个二次无理数都可以表示为循环连分数。**

- 手册以“某个 aₖ 重复出现”定义循环连分数（循环链分数，recurring chain fraction）。
- **例**：√2 = 1.4142135… 是二次无理数，它有循环连分数表示式 √2 = [1; 2, 2, 2, …]。
- **证据分层**：手册为参考工具书，未附证明；该论断属经典数论结果，外部文献可佐证（直接证据为手册原文，外部佐证为独立可验证背景）。
- **关联**：黄金分割的解 (√5−1)/2 是二次无理数，故应有循环连分数表示（手册 1.1.1.4 例 B 给出 [1;1,1,…] 与 [2;4,4,4,…] 两个相关表示，但该例与方程解的对应存在数值矛盾，见 [[findings/黄金分割连分数示例与方程解相差因子φ]]）。

本论断是 1.1.1 节最强的结构性结果，连接 [[concepts/二次无理数]] 与 [[concepts/连分数]]。
