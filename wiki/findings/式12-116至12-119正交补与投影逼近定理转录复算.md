# 式 12.116–12.119 正交补与投影逼近定理转录复算

## 转录内容

- (12.116) A⊥ = {x ∈ H : (x,y) = 0 ∀y ∈ A}，为 H 的（闭线性）子空间；
- (12.117) 毕达哥拉斯定理：两两正交的 x₁,…,x_n 满足 ‖Σ_{k=1}^n x_k‖² = Σ_{k=1}^n ‖x_k‖²；
- (12.118) 投影定理：H₀ 为子空间时每个 x ∈ H 可唯一写成 x = x′+x″，x′ ∈ H₀，x″ ⊥ H₀；
- (12.119) 逼近定理：转录作「方程 ‖x′‖ = ρ(x,H₀) = inf_{y∈H₀}{‖x−y‖} 成立，从而问题 ‖x−y‖ → inf, y ∈ H₀ 在 H₀ 中有唯一解 x′」；H₀ 可换成凸闭非空子集；H = H₀ ⊕ H₀⊥。

## 复算

- A⊥ 线性：由性质 a)（与正交组正交的向量对线性组合封闭）；A⊥ 闭：由性质 b) 与标量积连续性 (12.112)。✓
- (12.117)：展开 ‖Σx_k‖² = Σ‖x_k‖² + Σ_{j≠k}(x_k,x_j)，交叉项全为零。✓
- (12.118) 唯一性：若 x = x′+x″ = u′+u″，则 x′−u′ = u″−x″ ∈ H₀ ∩ H₀⊥，与自身正交故为零；存在性依赖完备性（闭子空间中极小化序列收敛）。✓
- (12.119)：对任意 y ∈ H₀，x−x′ ⊥ H₀ 给出 ‖x−y‖² = ‖x−x′‖² + ‖x′−y‖² ⩾ ‖x−x′‖²，等号当且仅当 y = x′。故正确陈述为 **‖x−x′‖ = ρ(x,H₀)**。⚠ 转录的 ‖x′‖ = ρ(x,H₀) 按字面为误（x ∈ H₀ 时 ‖x′‖ = ‖x‖ > 0 而 ρ = 0），疑脱「x −」或一撇（x″ 误作 x′），见 [[queries/式12-119范数等式xprime疑误]]。凸集情形：平行四边形等式 (12.111) 用于证明极小化序列的柯西性。✓

## 转写讹误

正文大量变量脱漏（「与 中每个向量」「如果 由单个元 组成」「H₀ 是 子空间」等脱 x/A/B/H₀）；d)「几乎处处稠」误植。已并入 [[queries/12-4全节系统性转写讹误清单]]。

## 结论

四式数学内容按修正形式全部复算通过；投影/逼近定理对完备性的依赖确认（存在性用完备性，唯一性用正交性）。
