# 数学手册记号约定：自然数集包含 0

手册 1.1.1.1,1. 定义

$$\mathbb{N} = \{0, 1, 2, 3, \dots\}$$

并明确称自然数为“**非负整数**”，即手册采用自然数集**包含 0** 的约定（符号参见第 439 页 5.2.1,1.）。

## 影响与差异

- 与部分教材“自然数从 1 起”的约定存在**外部约定差异**；引用本 wiki 中涉及 $\mathbb{N}$ 的结论时，以手册的含 0 约定为准。
- 同处给出的 $\mathbb{Q}=\{x \mid x=p/q,\ p\in\mathbb{Z},\ q\in\mathbb{Z},\ q\neq 0\}$ 写法一并记录于 [[concepts/有理数]]。
