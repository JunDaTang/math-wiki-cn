# 式 9.94 圆膜振动（贝塞尔本征函数）转录复算

## 逐字转录（关键式）

```
u_xx + u_yy = (1/a²)u_tt                                            (9.94a)
u_ρρ + (1/ρ)u_ρ + (1/ρ²)u_φφ = (1/a²)u_tt                           (9.94b)
u|_{t=0} = f(ρ, R) [sic!]，u_t|_{t=0} = F(ρ, φ)，u|_{ρ=R} = 0       (9.94c/d/e)
u = U(ρ)Φ(φ)T(t)                                                    (9.94f)
U″/U + U′/(ρU) + Φ″/(ρ²Φ) = T″/(a²T) = −λ²                         (9.94g)
T″ + a²λ²T = 0                                                      (9.94h)
(ρ²U″ + ρU′)/U + λ²ρ² = −Φ″/Φ = ν²                                 (9.94i)
Φ″ + ν²Φ = 0                                                        (9.94j)
Φ = a_n cos nφ + b_n sin nφ，ν² = n² (n = 0,1,2,…)                   (9.94k)
z²U″ + zU′ + (z² − n²)U = 0，U(ρ) = J_n(z) = J_n(μρ/R)              (9.94l，转写式号 9.941)
U_nk(ρ) = J_n(μ_nk ρ/R) (k = 1,2,…)                                 (9.94m)
a_nk = 2/(πR²J²_{n−1}(μ_nk)) ∫₀^{2π}dφ ∫₀^R f(ρ,φ)cos nφ · J_n(μ_nkρ/R) ρdρ   (9.94q)
```

（9.94n 为二重级数解；9.94o/p 为 t = 0 时 f、F 的展开；9.94r 为 b_nk 同型公式。原文注：“n = 0 的情形，分子 2 要改为 1”——转写脱落“2”。c_nk、d_nk 由 a_nk、b_nk 公式中以 F 代 f 再乘 R/(aμ_nk) 得到。）

## 复算核验

1. **周期条件**：Φ(0) = Φ(2π)、Φ′(0) = Φ′(2π) ⇒ ν² = n²（[[周期边界条件]]）✓。
2. **径向方程**：由 9.94i 得 [ρU′]′ − (n²/ρ)U = −λ²ρU ✓；代换 λρ = z 化为标准贝塞尔方程 z²U″ + zU′ + (z² − n²)U = 0 ✓。
3. **带权正交与范数**：U(R) = 0 ⇒ J_n(μ) = 0，μ = μ_nk 为 J_n 的第 k 个正零点；∫₀^R J_n²(μ_nkρ/R)ρdρ = (R²/2)J²_{n−1}(μ_nk)（零点处 J²_{n−1} = J²_{n+1}），结合角向 ∫₀^{2π}cos²nφ dφ = π（n ≥ 1）核验 9.94q/r 的因子 2/(πR²J²_{n−1}(μ_nk)) ✓。
4. **n = 0 规则**：n = 0 时角向积分 = 2π，故归一因子中分子 2 改为 1，数学上正确 ✓（转写脱落“2”字）。
5. **本征函数系地位**：{J_n(μ_nk ρ/R)} 是带权 ρ 的自伴 [[斯图姆-刘维尔问题]] 本征函数完全系（[[权函数]]；ρ = 0 处有界性条件属 [[奇异边值问题]]）✓。

## 异常

9.94c 初始条件写作 f(ρ, R)，而 9.94d 与 9.94o/p 均用 f(ρ, φ)；圆膜初位移是 (ρ, φ) 的二元函数，R 为边界半径。判定 f(ρ, R) 为 f(ρ, φ) 之误，见 [[queries/式9-94c初始条件疑为fρφ之误]]。

## 结论

除 9.94c 讹误外复算通过；本例是 [[贝塞尔函数]] 零点与带权正交性的典型 PDE 应用场景。
