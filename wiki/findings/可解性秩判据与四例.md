# 可解性秩判据与四例（式 4.177–4.178，已复算）

非齐次线性方程组 A x = a 的一般法则（式 4.178）：rank(A) = rank(A, a) 时至少有一个解；记 r = rank(A)，则 r = n 时唯一解，r < n 时有无穷多解（n − r 个未知数的值可作自由参数）。4.5.2.1 的四个算例已全部复算（方程组原始数据见 [[sources/10-数学手册原书第10版--8-45-线性方程组--1smy1k4]]）：

- **例 A（不相容）**：rank(A) = 2（第 3 行系数 = 第 2 行 − 第 1 行），而 rank(A, a) = 3（常数 8 ≠ 6 − 2 = 4，同一关系不满足）→ 无解。转写脱落的增广秩数已复算补为 3（见 [[queries/例A例B脱落的秩数是否为3]]）。
- **例 B（唯一解）**：r = n = 3，唯一解 x = (10/7, −1/7, −2/7)，回代四个方程全部成立。
- **例 C（r < n）**：r = 2 < n = 4，方程组相容但解不唯一，n − r = 2 个自由参数：x₂ = x₁ − 1/2，x₃ = x₄ + 1/2（x₁、x₄ 任意）。
- **例 D（无解）**：第 3 行 = 第 1 行 + 第 2 行（含常数项），第 4 行系数 = 第 2 行 − 第 1 行但常数 0 ≠ 2 − 1 = 1，故 rank(A) = 2 < rank(A, a) = 3 → 无解。

## 核验说明

四个例子的秩、解与参数化均经独立复算确认，属直接证据。判别流程整理见 [[methodology/线性方程组可解性判别流程]]。
