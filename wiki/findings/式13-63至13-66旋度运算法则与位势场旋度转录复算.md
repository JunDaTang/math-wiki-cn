# 式 13.63–13.66 旋度运算法则与位势场旋度转录复算

对《数学手册》13.2.5.3–13.2.5.4 的运算法则与位势场无旋性的逐项复算。结论：全部成立，逐项与标准恒等式一致。

## 转录

```latex
(13.63) rot(V⃗₁ + V⃗₂) = rot V⃗₁ + rot V⃗₂ ;  rot(cV⃗) = c rot V⃗
(13.64) rot(U V⃗) = U rot V⃗ + grad U × V⃗
(13.65) rot(V⃗₁ × V⃗₂) = (V⃗₂·grad)V⃗₁ − (V⃗₁·grad)V⃗₂ + V⃗₁ div V⃗₂ − V⃗₂ div V⃗₁
(13.66) rot V⃗ = rot(grad U) = 0⃗
```

## 复算

1. **(13.63) 线性与数乘 ✓**：由定义式直接得出。
2. **(13.64) 标量乘积法则 ✓**：与标准恒等式一致；对照 [[concepts/梯度的运算法则]] 的乘积法则，旋度版的第二项为叉积 grad U × V⃗，次序固定。
3. **(13.65) 叉积旋度展开 ✓**：四项结构（两个方向导数项 + 两个散度项）与标准恒等式一致。本式依赖 div V⃗——13.2.3 散度节尚未入库，属回指缺口（见 [[queries/13-2-5未入库回指缺口]]）。
4. **(13.66) 位势场无旋 ✓**：
   - 斯托克斯路线（推理，回指 13.3.3.2，未入库）：位势场沿闭曲线环流为零 ⇒ 环流面密度为零。
   - 直接验证（推理，回指 6.2.2.2 施瓦茨互换定理，未入库）：混合偏导相等条件下，由 (13.59a) 各分量成对相消。
5. **中心场特例 ✓**（直接计算 + 推理）：rot r⃗ = 0⃗；rot(φ(r) r⃗) = 0⃗，因 φ(r) r⃗ = grad(∫φ(r) r dr) 为梯度场。与 [[findings/式13-40至13-46梯度运算法则与中心场梯度转录复算]] 配套：[[concepts/中心场]] 既是中心场又是位势场（无旋场），梯度侧与旋度侧结论互相印证。
