# 大圆航线公式组（式 3.203–3.212，含 3.203 复原与角的简化）

[[concepts/大圆航线]] 由最接近北极的点 P_N(λ_N, φ_N)（φ_N > 0°，该处航向角 α_N = 90°）唯一确定；方程与各量公式如下。(3.202a)–(3.212) 中除 (3.203) 外为直接证据；(3.203) 本体在转写中缺失，为复原·推断：

```
【(3.203) 复原·推断：据 (3.227a)、(3.212) 同形关系与赤道交点条件】
tan φ = tan φ_N·cos(λ − λ_N)                                        (3.203)
φ_N = arccos(sin|α_A|·cos φ_A)                                       (3.204a)
λ_N = λ_A + sign(α_A)·|arccos(tan φ_A/tan φ_N)|                      (3.204b)
λ_red = 2 arctan(tan(λ/2))    （λ ≠ ±k·180°，角的简化）               (3.205)
λ_Eν = λ_N ∓ 90°    (ν = 1, 2)                                       (3.206)
d = arccos[sin φ_A sin φ_B + cos φ_A cos φ_B cos(λ_B−λ_A)]            (3.207a)
d = arccos[同上]·πR/180°                                              (3.207b)
α_A = arctan[cos φ_A cos φ_B sin(λ_B−λ_A)/(sin φ_B − sin φ_A cos d)]  (3.208)
λ_Xν = λ_N ∓ arccos(tan φ_X/tan φ_N)    (ν = 1, 2)                    (3.209)
|α_Xν| = arcsin(cos φ_N/cos φ_X)    (ν = 1, 2)                        (3.210)
|α_X min| = 90° − φ_N    （在赤道交点处最小）                          (3.211)
φ_Y = arctan[tan φ_N cos(λ_Y − λ_N)]                                  (3.212)
```

## 要点

- **复原依据**：(3.203) 被正文（赤道交点条件 tan φ_N cos(λ_E−λ_N) = 0 ⟹ (3.206)）与 (3.227a)、(3.212)（均为 tan φ = tan φ_N cos(λ−λ_N) 的同形式）隐含引用，复原高置信，见 [[queries/式3-203本体脱落是否可复原]]。
- **最接近北极的点**：在点 A(λ_A, φ_A)（φ_A ≠ 90°）处具有航向角 α_A（α_A ≠ 0°）的大圆，其 P_N 坐标按 (3.204a)(3.204b) 用 [[concepts/纳皮尔法则]] 计算，须考虑 P_N 的相对位置与 α_A 的符号；由两点给出的大圆可经 (3.207a)、(3.208) 反算 P_N。
- **弧长**（3.207a/b）：由边的余弦定律得出球面距离（圆心角），乘 πR/180° 换算长度（[[concepts/弧度]] 换算）。
- **航向角**（3.208）：由边的正弦定律与余弦定律分别算 sin α_A 与 cos α_A，相除后给出。
- **与平行圆的交点**（3.209）：仅当 |φ_X| ⩽ φ_N 时存在；交点航向角 (3.210)；最小航向角在赤道交点处取得（3.211），与 (3.210) 在 φ_X = 0 处一致。
- **角的简化**（3.205）：λ_red = 2 arctan(tan(λ/2)) 把经度化回 −180° < λ ⩽ 180°，多处计算后需要执行。
- **与子午线的交点**（3.212）：直接由方程 (3.203) 代入 λ = λ_Y 得出。

两条大圆的交点公式见 [[findings/球面曲线交点对径点与无穷交点]]。
