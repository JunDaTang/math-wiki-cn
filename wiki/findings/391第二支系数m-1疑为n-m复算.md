# 391 第二支系数 m-1 疑为 n-m 复算

∫cosⁿax dx/sinᵐax 的三支递推（转写无编号，按 381–391 区结构复原约为条目 391；380 有显式锚点）转写原文第二支：

```latex
= \frac{\cos^{n-1} ax}{a(n-m)\sin^{m-1} ax} + \frac{n-1}{m-1}\int\frac{\cos^{n-2} ax\,dx}{\sin^{m} ax} \quad (m\neq n)
```

## 复算

对边界项 w = cos^{n−1}x/sin^{m−1}x 求导：w′ = −(n−1)·cos^{n−2}x/sin^{m−2}x − (m−1)·cosⁿx/sinᵐx。利用 sin^{−m} − sin^{−(m−2)} = sin^{−m}cos² 可证：

```latex
\int\frac{\cos^{n} ax}{\sin^{m} ax}\,dx = \frac{\cos^{n-1} ax}{a(n-m)\sin^{m-1} ax} + \frac{n-1}{n-m}\int\frac{\cos^{n-2} ax\,dx}{\sin^{m} ax}
```

即第二支系数应为 (n−1)/(n−m)，与边界项分母 (n−m) 相呼应；原文作 (n−1)/(m−1)，仅当 m−1 = n−m 时巧合成立。第一、三支复算无误。

数值验证（n=4, m=2）：原文给 2，正确值 1/2。

## 结构旁证

本式与 380（∫sinⁿ/cosᵐ）呈 sin↔cos 镜像：380 第二支系数 (n−1)/(n−m) 复算无误，恰为本条订正后的形态；380 第三支的镜像（cos^{n−2}/sin^{m−2}，同降 2）在本式第三支亦复算无误——镜像对照将错位唯一地定位于本式第二支系数。
