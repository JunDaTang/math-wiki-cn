# 式 19.195–19.200 切比雪夫逼近定义与 T_n 性质转录复算

## 转录内容

**一致逼近的定义（19.195）**：函数 f(x) 在区间 [a,b] 内被 g(x) = g(x; a₀, a₁, …, aₙ) 逼近，使

$$
\max_{a\leqslant x\leqslant b}\bigl|f(x)-g(x;a_0,a_1,\dots,a_n)\bigr|=\Phi(a_0,a_1,\dots,a_n)\tag{19.195}
$$

定义的误差对适当选取的参数 aᵢ (i = 0, 1, …, n) 尽可能小。

**交替点陈述**：若最佳近似函数存在，误差的绝对值至少在区间的 n+2 个点 x_ν 上取得极大，且误差在这些交替点上变号。

**xⁿ 特例**：f(x) = xⁿ 在 [−1, 1] 上在切比雪夫意义下被次数 ⩽ n−1 的多项式近似时，T_n(x) 可作为最大模为（**转录脱落数值**）的误差函数；交替点位于区间端点和区间内 n−1 个点（原文「n-l」疑为「n−1」），恰相应于 T_n(x) 的极值点。

**T_n 的性质**：

$$
T_n(x)=\cos(n\arccos x),\tag{19.196a}
$$

$$
T_n(x)=\frac{1}{2}\Bigl[\bigl(x+\sqrt{x^2-1}\bigr)^n+\bigl(x-\sqrt{x^2-1}\bigr)^n\Bigr],\tag{19.196b}
$$

$$
T_n(x)=\begin{cases}\cos nt, & x=\cos t,\ |x|<1,\\ \cosh nt, & x=\cosh t,\ |x|>1\end{cases}\quad(n=1,2,\dots),\tag{19.196c}
$$

$$
x_\mu=\cos\frac{(2\mu-1)\pi}{2n}\ (\mu=1,\dots,n)\ \text{（根）},\qquad
x_\nu=\cos\frac{\nu\pi}{n}\ (\nu=0,1,\dots,n)\ \text{（极值点）},\tag{19.197/19.198}
$$

$$
T_{n+1}(x)=2xT_n(x)-T_{n-1}(x)\quad(T_0=1,\ T_1=x),\tag{19.199}
$$

$$
\begin{aligned}
&T_2=2x^2-1,\ T_3=4x^3-3x,\ T_4=8x^4-8x^2+1,\ T_5=16x^5-20x^3+5x,\\
&T_6=32x^6-48x^4+18x^2-1,\ T_7=64x^7-112x^5+56x^3-7x,\\
&T_8=128x^8-256x^6+160x^4-32x^2+1,\ T_9=256x^9-576x^7+432x^5-120x^3+9x,\\
&T_{10}=512x^{10}-1280x^8+1120x^6-400x^4+50x^2-1.\tag{19.200}
\end{aligned}
$$

## 复算与验证

1. **(19.196a)**：以 x = cos t 代入即 T_n = cos nt，定义自洽 ✓。
2. **(19.196b)**：注意 (x+√(x²−1))(x−√(x²−1)) = 1，两根式互为倒数。当 x = cosh t 时 √(x²−1) = sinh t，x ± √(x²−1) = e^{±t}，故 (19.196b) = ½(e^{nt}+e^{−nt}) = cosh nt；当 |x| < 1 时取 x = cos t、√(x²−1) = i sin t，同理得 cos nt。验证无误，且 (19.196b) ⟹ (19.196c) ✓。
3. **(19.197) 根**：T_n(x_μ) = cos((2μ−1)π/2) = 0 ✓，恰 n 个根且全落 (−1, 1)。
4. **(19.198) 极值点**：T_n(x_ν) = cos νπ = ±1 ✓，ν = 0, …, n 共 n+1 个（含两端点 ±1；区间内 ν = 1, …, n−1 共 n−1 个），与 xⁿ 特例「两端点 + 区间内 n−1 点」的表述吻合 ✓。
5. **(19.199) 递推**：由 cos(n+1)t + cos(n−1)t = 2 cos t · cos nt 直接得出 ✓；初值 T₀ = 1、T₁ = x ✓。首项系数归纳为 2^{n−1}（T₁ 首项 2⁰ = 1，每步乘 2x）✓。
6. **(19.200a–g) 显式 T₂–T₁₀**：由递推逐项展开复算，九个多项式**全部正确** ✓。
7. **xⁿ 极值性质复算**：误差函数 e(x) = xⁿ − p(x)（p 次数 ⩽ n−1）恰为首一 n 次多项式，反之亦然。2^{1−n}T_n 首一，且在 n+1 个极值点 (19.198) 上取值 ±2^{1−n}、逐点变号；逼近族含 n 个参数，按[[交替点定理]]需 n+1 个交替点——恰为其全部极值点，故 2^{1−n}T_n 为最小偏差多项式，**最小偏差 = 2^{1−n}**。自洽检验：n = 1 时 x 被常数 0 逼近，max_{[−1,1]}|x| = 1 = 2^{1−1} ✓；n = 2 时取 p = x² − ½，误差 ½ = 2^{−1} 在 x = −1, 0, 1 三点等幅交替 ✓。故原文「最大模为」后脱落之数值应即 2^{1−n}（或原书作「乘以因子 2^{1−n} 的 T_n」，见 [[最大模为后脱数值疑为2的1减n次幂之辨]]）。

## 结论

(19.195)–(19.200) 的数学内容全部复算无误；唯一实质缺损是「最大模为」后脱落的数值 2^{1−n}（另「n-l」疑为「n−1」）。交替点个数与参数个数的计数对应（n+1 参数 → n+2 点；xⁿ 情形 n 参数 → n+1 点）完全自洽。
