# 式 18.136–18.141 贝尔曼泛函方程与前向方程转录

## 转录内容（逐字）

```latex
% (18.136) 最优值函数定义
φ_j(x_{j-1}) = min_{u_k∈U_k(x_{k-1}), k=j(1)n} F_j(f_j(x_{j-1},u_j), …, f_n(x_{n-1},u_n)),  j = 1(1)n

% (18.137) 边界条件
φ_{n+1}(x_n) = 0

% (18.138) 递推式（贝尔曼泛函方程）
φ_j(x_{j-1}) = min_{u_j∈U_j(x_{j-1})} H_j(f_j(x_{j-1},u_j), φ_{j+1}(g_j(x_{j-1},u_j)))

% (18.139) 求解泛函方程（同 18.138 的中间形式）
φ_j(x_{j-1}) = min_{u_j∈U_j(x_{j-1})} H_j(f_j(x_{j-1},u_j), φ_{j+1}(x_j))

% (18.140) 子过程 P_j 的费用函数极小化
F_j(f_j(x_{j-1},u_j), …, f_n(x_{n-1},u_n)) → min!

% (18.141) 方式 2 的前向方程
φ_j(x*_{j-1}) = min_{u_j∈U_j(x*_{j-1})} H_j(f_j(x*_{j-1},u_j), φ_{j+1}(g_j(x*_{j-1},u_j)))
```

## 转录核对

- (18.138) 之前的推导中间显示在转写中严重乱码（出现「if f_j…」等非数学内容），但首尾两式（分离 $F_j$、合并 $\varphi_{j+1}$）与 (18.130)、(18.131) 的推导链条逻辑一致，末式 (18.138) 清晰无误。
- 约定：不可行状态置 $\varphi_j(x_{j-1})=\infty$；$\varphi_1(x_0)$ 为费用函数的最优值。
- (18.139) 与 (18.138) 同式（以 $x_j$ 代 $g_j(x_{j-1},u_j)$），用于引出 18.3.4 的最优性原理；(18.141) 是 18.3.5.2 方式 2 在最优轨线上的同式。
