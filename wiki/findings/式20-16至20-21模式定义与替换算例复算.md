# 式 20.16–20.21 模式定义与替换算例复算

对 20.2.7 节式 (20.16)–(20.21e) 的整段 IO 会话依 Mathematica 语义逐项复算。复算方式为**解析推演**（依 Mathematica 模式匹配与求值语义推演，非实机执行）；各输出结果与原文全部吻合，惟原文对式 (20.20) 的 FullForm 陈述有讹（见下）。

## 复算对象

见 [[sources/10-数学手册原书第10版--7-2027-模式--125ne2w]] 之逐字转录。

## 复算结果

**式 20.17–20.19（结构匹配）**：`l = {1, y, y^a, y^Sqrt[x], {f[y^(r/q)], 2^y}}`，`l /. y^_ -> yes` 复算得 `{1, y, yes, yes, {f[yes], 2^y}}`，与 Out[3] 完全一致。逐项核验：

- `1`、`y` 不替换：二者不含 Power 头，不具有 `Power[y, 任意]` 结构；y^0=1、y^1=y 属数学等价，而模式匹配不作数学等价判断——证实 [[concepts/模式（Mathematica）]] 的“结构匹配而非数学相等”。
- `y^a`、`y^Sqrt[x]` 替换为 yes：结构一致。
- `f[y^(r/q)]` → `f[yes]`：替换穿透嵌套层级，证实 `/.` 替换所有出现、所有层级，为 [[queries/Replace疑为ReplaceAll之辨]] 提供佐证。
- `2^y` 不替换：底数为 2，结构不同。

**式 20.20（FullForm 比较）**：`b/y /. y^_ -> yes` 复算得 `b yes`，与 Out[4] 一致。成因：`b/y` 即 b·y^(−1)，FullForm 为 `Times[b, Power[y, -1]]`，第二个因子与 `y^_` 结构等同而被替换为 yes。**原文所称 FullForm `Times[b, Power[y, 1]]` 与数学事实矛盾**：`Power[y, 1]` 会自动化简为 `y`，`Times[b, Power[y, 1]]` 即 `b y`，无从作为 `b/y` 的内部形式存在；应系脱负号之讹，详见 [[queries/Power-y-1疑为Power-y-负1之辨]]。

**式 20.21a–e（模式定义与字面定义）**：

- `f[x_] := x^3` 后：`f[r]` → `r^3`（式 20.21b）；`f[a] + f[x]` → `a^3 + x^3`（式 20.21c）。复算一致：模式定义对任意变元生效。
- `f[x] := x^3` 后，相同输入 `f[a] + f[x]` → `f[a] + x^3`（式 20.21e）。复算一致，但**隐含新会话前提**（推断）：若与模式定义同会话并存，`f[a]` 将经一般规则求值为 `a^3`，得 `a^3 + x^3`；书中“然而如果”的行文表明这是另起会话（或先清除 f）的对照实验，详见 [[comparisons/模式定义与字面定义比较]]。

## 直接证据与推断之别

- 直接证据：Out[3]、Out[4]、Out[6]、Out[7] 的替换行为均为 Mathematica 模式匹配与 `/.` 的标准语义，可直接核验。
- 推断：① Out[9] 的新会话前提（原文未明言，由行文与规则并存行为推得）；② `Power[y, 1]` 为转写讹误的判定（由 `b/y` 的数学定义与自动化简行为推得）。
