# 球面曲线交点：大圆航线的对径点对与斜航线的无穷交点（式 3.227–3.232）

## 两条大圆航线的交点（直接证据）

设两条大圆的最接近北极的点为 P_N1(λ_N1, φ_N1) 与 P_N2(λ_N2, φ_N2)（P_N1 ≠ P_N2）。在两个大圆方程中代入交点 S(λ_S, φ_S) 得方程组 (3.227a/b)：tan φ_N1 cos(λ_S−λ_N1) = tan φ_S 与 tan φ_N2 cos(λ_S−λ_N2) = tan φ_S。消去 φ_S 并利用余弦加法定律：

```
tan λ_S = −[tan φ_N1 cos λ_N1 − tan φ_N2 cos λ_N2]/[tan φ_N1 sin λ_N1 − tan φ_N2 sin λ_N2]   (3.228)
φ_Sν = arctan[tan φ_N1 cos(λ_Sν − λ_N1)]    (ν = 1, 2)    (3.229)
```

(3.228) 在 −180° < λ ⩽ 180° 内有两个解 λ_S1、λ_S2，相应纬度由 (3.229) 得出。**交点 S₁ 与 S₂ 是对径点**，即它们彼此是关于球心的镜像。

## 两条斜航线的交点（直接证据）

设两条斜航线的赤道交点为 P_E1(λ_E1, 0°) 与 P_E2(λ_E2, 0°)、航向角 α₁ ≠ α₂。代入交点 S 得方程组 (3.230a/b)，消去 λ_S 并解出 φ_S，得**有无穷多解**的方程：

```
φ_Sν = 2 arctan exp[(λ_E1 − λ_E2 + ν·360°)/(tan α₂ − tan α₁)·π/180°] − 90°   (ν ∈ ℤ)   (3.231)
λ_Sν = λ_E1 + tan α₁·ln tan(45°+φ_Sν/2)·180°/π   (ν ∈ ℤ)    (3.232)
```

## 要点

- 大圆交点公式是纯代数消元的结果；对径点结论为球面几何基本事实（两大圆的交点必成对径对），与本 wiki 对 [[concepts/大圆航线]] 方程 (3.203) 的复原互为印证。
- 斜航线交点的无穷性对应其螺旋环绕极点的周期结构（见 [[findings/斜航线对数方程与极点渐近]]）。
- 多处情形需按 (3.205) 做**角的简化**（λ_red = 2 arctan(tan(λ/2))），源在多个交点公式后反复提醒。
