# 赛奈定理正熵与德瓦尼混沌等价转录核验

## 转录原文

```text
赛奈 {Sinai) 定理 $\varphi : I  I$ 为紧区间 $I = [ 0 , 1 ]$ 到自身的连续映射，则上系统 $\{ \varphi ^ { t } \}$ 在德瓦尼意义下是混沌的当且仅当 $\varphi$ 在 上的拓扑嫡 $h ( \varphi )$ ）是正的．
```

## 订正读法

设 $\varphi: I\to I$（$I=[0,1]$）连续，则该系统 $\{\varphi^{t}\}$ 在德瓦尼意义下是混沌的，当且仅当 $\varphi$ 在 $I$ 上的拓扑熵 $h(\varphi)$ 是正的。

转录讹误：「则**上**系统」疑脱字（该/上述）；「在 上的拓扑**嫡**」脱 $I$ 且「嫡」为「熵」之形讹；「$h(\varphi)\,)$」衍一右括号；「$\varphi : I\ \ I$」脱箭头；「{Sinai)」括号体例混乱。

## 核验结论

- **转录层面（高置信）**：讹误已识别并列于 [[queries/17-2-6全节系统性转写讹误清单]]。
- **数学层面（无法闭合核验）**：本手册转录本未给出德瓦尼混沌的定义（见 [[concepts/德瓦尼混沌]]），等价式两端之一无定义可查。
- **内部张力**：若按字面理解为「在整个 $I$ 上德瓦尼混沌」，则正向（$h>0\Rightarrow$ 混沌）可疑——正拓扑熵不必蕴含全区间的拓扑传递性（例如由两个互不相交混沌块之并构成的映射可有正熵而非传递，推断性反例思路）。结合节首「保证存在混沌的**不变集合**」，原意或为「在某个不变子集上混沌」，或手册措辞不严。须查原书，见 [[queries/赛奈定理当且仅当与德瓦尼混沌措辞之辨]]。

## 判定

转录订正可落定；「当且仅当」的确切原文与适用口径**待原书裁定**，裁定前等价链（[[concepts/一维映射的混沌]]）中相应一环须带存疑标记。
