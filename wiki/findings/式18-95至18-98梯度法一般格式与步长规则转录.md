# 式 18.95–18.98 梯度法一般格式与步长规则转录

## 转录内容

```
f(x) = min!,  约束条件为 g_i(x) ⩽ 0                     (18.95)
x^{k+1} = x^k + α_k d^k,  k = 1, 2, …                    (18.96)
α_k'' = {α ∈ R : x^k + α d^k ∈ M}                        (18.97)
α_k = min{α_k', α_k''}                                   (18.98)
```

其中 $\alpha_k'$ 从 $f(x^k+\alpha d^k)=\min!,\ \alpha>0$ 确定（一维搜索，回指 18.2.4）。

## 直接证据（源内陈述）

- 由于有界可行集，必须考虑两条附加规则：(1) 方向 $d^k$ 必须是 $x^k$ 的可行下降方向；(2) 步长 $\alpha_k$ 必须使得 $x^{k+1}\in M$；
- 如果在某一步没有可行方向 $d^k$，则 $x^k$ 是平稳点；
- 方法分类学论断：基于公式 (18.96) 的各种方法的差别仅在于构造方向 $d^k$ 的不同。

## 转写疑点（推断，非源内证据）

- 式 (18.97) 将 $\alpha_k''$ 定义为**集合** $\{\alpha\in\mathbb{R}: x^k+\alpha d^k\in M\}$ 而非其（正）最大值，但式 (18.98) 的 $\min\{\alpha_k',\alpha_k''\}$ 用法要求 $\alpha_k''$ 为数；疑缺 $\max$，见 [[queries/式18-97疑缺max之辨]]；
- 规则 (2) 句末原文「必须使得 $x^{k+1}$ 中」疑脱「$\in M$」，见 [[queries/多处脱M符号及乱码疑为u之辨]]。
