# 对偶四元数表示刚体运动与 SE(3) 双重覆盖（式 4.171–4.173 与表 4.1）

**发现**：《数学手册（原书第10版）》4.4.3.6（标题「规范化四元数和刚体运动」）定义了 ε² = 0、与四元数交换的对偶单位 ε 上的代数——书中称「八元数」，按结构为**对偶四元数**——并断言：其单位元素可表示 ℝ³ 的刚体运动（旋转与平移交替复合），且按式 (4.173) 参数化后给出刚体运动群 [[entities/SE3]] 的双重覆盖。结构经分析者复核自洽，且为机器人学/机构学的标准结果。

## 公式（照录）

```latex
ĥ = h₀ + ε h₁,    h₀, h₁ ∈ ℍ,   ε² = 0, ε 与每个四元数交换                 (4.171)

ĥ ĥ‾ = (h₀ + ε h₁)(h̄₀ + ε h̄₁) = 1
  ⇔  h₀ h̄₀ = 1  且  h₀ h̄₁ + h₁ h̄₀ = 0                                     (4.172)

ĥ = h₀ + h₁ ε = (1 + ½ t̲ ε) r = r + ½ t̲ r ε,    t̲ ∈ ℍ₀, r ∈ ℍ₁        (4.173)
```

## 表 4.1（照录；转写中下标被压平，此处复原）

| 元素 | 表示 |
|---|---|
| 空间中点 p̲ = (p_x, p_y, p_z) | p̌ = 1 + p̲ε，其中 p̲ = p_x **i** + p_y **j** + p_z **k** |
| 旋转 | r ∈ ℍ₁，单位四元数 |
| 平移 t̲ = (t_x, t_y, t_z) | 1 + ½ t̲ε，其中 t̲ = t_x **i** + t_y **j** + t_z **k** |

## 复核结论

- (4.172) 单位条件：令 u = h₀⁻¹h₁，则 h₀h̄₁ + h₁h̄₀ = h₀(u + ū)h̄₀，故条件 ⟺ h₀ ∈ ℍ₁ 且 u 为纯四元数。(4.173) 的 h₁ = ½t̲r 满足之（h₀⁻¹h₁ = ½r̄t̲r 为纯四元数）。
- 平移可加：(1 + ½t̲ε)(1 + ½t′ε) = 1 + ½(t̲+t′)ε（用 ε² = 0）✓，与表 4.1 的 ½ 因子配套。
- 双重覆盖核：转写中「因为 [ĥ] 和 [−ĥ] 刻画相同刚体运动」一句符号脱落；据此单位对偶四元数 → SE(3) 为二对一覆盖，核 {±ĥ}。

## 缺失与存疑

- **点变换作用式缺失**：点 p̌ = 1 + p̲ε 如何被 ĥ 作用（三明治作用的推广）在转写中完全没有。分析者复核：标准约定 p̌′ = ĥ p̌ ĥ̄ᵉ（四元数共轭后再取对偶共轭）展开给出 p̌′ = 1 + ε(rp̲r̄ + t̲)，即 p′ = Rp + t̲，与表中 ½ 因子吻合；但这是推断，需回查原书（见 [[queries/4-4-3-6标题规范化四元数与点变换作用式缺失]]）。
- **标题不符**：小节标题「规范化四元数」与其内容（对偶单位 ε、对偶四元数）不匹配，疑为「对偶四元数」之误或中译问题。
- **术语冲突**：「八元数」一词与 4.4.2 广义数层级中的八元数（若为 Cayley 型）指代不同对象，见 [[queries/八元数一词双义之疑]]。本发现中的全部能力（表示刚体运动、双重覆盖 SE(3)）归属于 ε-代数（对偶四元数），**不可**转授予 Cayley 型八元数。

## 与既有发现的衔接

本发现把 [[findings/四元数刻画旋转的优缺点与八元数补救主张]] 中的「八元数补救主张」落到具体构造（表 4.1 与式 4.172–4.173）；但该主张的主语应标为对偶四元数。
