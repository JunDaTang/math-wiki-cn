# 公式 10.29b 第二式根号与圆解不自洽复算

**结论**：印本 (10.29b) 第二式与圆族解 (10.29c) 代数上不自洽，疑为原书印刷之讹或转写之讹。

**推导**：由 (10.29a) H = y + λ√(1+y′²)，因 x 不显含于 H，用 (10.22c) 型首次积分：

H − y′H_{y′} = y + λ√(1+y′²) − λy′²/√(1+y′²) = y + λ/√(1+y′²) = c₁

（中间一步用 λ[(1+y′²) − y′²]/√(1+y′²) = λ/√(1+y′²) 化简，与印本第一式一致。）令 u = c₁ − y，则 λ/√(1+y′²) = u ⟹ √(1+y′²) = λ/u ⟹

$$y'^2 = \frac{\lambda^2 - (c_1 - y)^2}{(c_1 - y)^2}$$

**与圆解互证**：对圆族 (x−c₂)² + (y−c₁)² = λ² 隐函数求导得 y′ = −(x−c₂)/(y−c₁)，故 y′² = (λ² − (c₁−y)²)/(c₁−y)²，与上式一致。

**不自洽点**：印本第二式作

$$y'^2 = \frac{\sqrt{\lambda^2 - (c_1 - y)^2}}{c_1 - y}$$

其右端恰为正确右端的**平方根**（即给出 |y′| 而非 y′²），与圆解矛盾。可能的复原：其一，左端「²」为衍文（如此该式给出 |y′|，自洽）；其二，根号位置与分母乘方为转写之讹（正确式应为分母平方、分子不取根号）。

证据强度：高（代数推导自洽性判定；首次积分与圆族隐函数求导两条独立路线互相印证）。此为对印本内部矛盾的直接复算证据；是否原书印刷如此，需对扫描原页，见 [[queries/10-29b第二式根号分母乘方之辨]]。
