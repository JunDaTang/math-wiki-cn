# 黄金分割公式与正十边形边长（式 3.298，已验证）

本源给出的黄金分割公式：

```
x/a = (a−x)/x                            (3.298a)
x = √(a(a−x))   （x 为 a 与 a−x 的几何平均）   (3.298b)
x = a(√5 − 1)/2 ≈ 0.618·a                 (3.298c)
```

## 两条评论（均已独立复算验证）

1. **正十边形边长**：线段 x 是外接圆半径为 a 的正十边形的边长。验证：边长 = 2a·sin(π/10) = 2a·sin 18° = 2a·(√5−1)/4 = a(√5−1)/2 = x。✓（原文交叉引用原书 3.1.5.3，即 [[concepts/正凸多边形]] 所在节；转写中页码-节号粘连为「第 1823.1.5.3」。）
2. **黄金矩形**：求边长 a（常数）与 a−x（变量）的矩形，使面积 a(a−x) 等于以 x 为边长的正方形面积 x²，即 a(a−x) = x² —— 这与 (3.298a) 是同一方程。✓

x 可由几何作图给出（原书图 3.133(a)）。原书 1.1.1.2（前向引用）另述黄金分割。概念展开见 [[concepts/黄金分割]]。
