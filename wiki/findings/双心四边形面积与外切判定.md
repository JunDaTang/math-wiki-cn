# 双心四边形面积与外切判定（式 3.41–3.43）

《数学手册》3.1.4.6–3.1.4.7 给出三条结果。

**双心四边形的面积**——如果内接四边形也是一个外切四边形（即双心四边形），则：

$$S = \sqrt{abcd} \tag{3.41}$$

**外切四边形的判定**——一个四边形具有一个内切圆，当且仅当对边长度之和相等，并且这个和也等于半周长：

$$s = \frac{1}{2}(a+b+c+d) = a+c = b+d \tag{3.42}$$

该判据通称皮托定理（Pitot，源未冠名）。

**外切四边形的面积**：

$$S = (a+c)r = (b+d)r \tag{3.43}$$

其中 $r$ 是内切圆的半径（源文「其中 是内切圆的半径」中符号 $r$ 转写脱落）。

## 复核（导入分析代数复核通过，本 wiki 复述）

式 3.41 可由式 3.40 与 3.42 直接导出：双心时 $a + c = b + d = s$，故 $s - a = c$，$s - b = d$，$s - c = a$，$s - d = b$，代入式 3.40：

$$S = \sqrt{(s-a)(s-b)(s-c)(s-d)} = \sqrt{c\,d\,a\,b} = \sqrt{abcd}$$

## 适用范围

- 式 3.41 需同时内接且外切（双心）。
- 式 3.42–3.43 仅需外切（有内切圆），不要求内接。
- 三式互不可换用：式 3.42–3.43 不能用于仅内接的四边形，式 3.40（见 [[findings/内接四边形半周长面积公式]]）不能用于仅外切的四边形。
