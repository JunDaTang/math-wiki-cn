# 帕斯卡蜗线的极值拐点与二重切线（式 2.235）

**主张。** 帕斯卡蜗线 $\rho = a\cos\varphi + l$ 的特征点公式：

- 极值点：$\dot{y} = 0 \Leftrightarrow 2a\cos^2\varphi + l\cos\varphi - a = 0$，即 $\cos\varphi = \frac{-l \pm \sqrt{l^2+8a^2}}{4a}$；a > l 时有四个极值点 C, D, E, F，a ≤ l 时有两个。
- 拐点：仅当 a < l < 2a，在 $\cos\varphi = -\frac{2a^2+l^2}{3al}$ 处有两点 G, H。
- 二重切线：l < 2a 时在点 $I, K\left(-\frac{l^2}{4a}, \pm\frac{l\sqrt{4a^2-l^2}}{4a}\right)$ 处，为竖直线 $x = -l^2/(4a)$。

**证据（原式）。** 手册 2.12.3 的 a)、b) 两条。

**验证（已验证，独立复推）。**
- 极值条件：参数式 $y = a\cos\varphi\sin\varphi + l\sin\varphi$ 求导，$\dot{y} = a\cos 2\varphi + l\cos\varphi = 0$ 即上述二次方程。
- 拐点条件：极坐标曲率分子 $\rho^2 + 2\rho'^2 - \rho\rho'' = 2a^2 + 3al\cos\varphi + l^2$，令其为零得 $\cos\varphi = -(2a^2+l^2)/(3al)$；该值仅在 $a < l < 2a$ 内满足 $|\cos\varphi| < 1$（l = a 与 l = 2a 时 cos φ = −1 恰为边界），与“仅当 a < l < 2a 有拐点”一致。
- 二重切线：$\dot{x} = -\sin\varphi(2a\cos\varphi + l) = 0$ 的非顶点解 $\cos\varphi = -l/(2a)$（需 l < 2a），代回得 $x = -l^2/(4a)$、$y = \pm l\sqrt{4a^2-l^2}/(4a)$；该处 $\dot{y} = -a \neq 0$（竖直切线），上下两点对称共线，故 $x = -l^2/(4a)$ 为二重切线。

**边界与注记。** 拐点条件与二重切线条件的适用区间不同（a < l < 2a 与 l < 2a）；a = l 时拐点条件退化为 cos φ = −1（尖点，即心脏线），与 [[findings/心脏线的两种定义与特征量]] 的极值公式自洽。
