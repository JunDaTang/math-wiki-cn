# Matlab 线性代数算例复算

## 摘要

19.8.4.1 数值线性代数四组命令行算例的转录与独立复算：A\b 求解与残量、lu 三角分解（PA=LR）、hilb(13) 病态警告、超定方程组最小二乘解与 qr 分解。除 hilb 的 RCOND 值为软件输出转录外，其余均已复算证实。

## 算例 1：A\b 与残量

```txt
>> A = [1 0 3; 2 1 1; 1 2 3];  b = [-2; 3; 2];  x = A\b, norm(A*x - b)
x = (1.0000, 2.0000, -1.0000)ᵀ      ans = 8.8818e-016
```

复算：x=(1,2,−1)ᵀ 代入 Ax 逐行得 (−2, 3, 2)ᵀ = b，解精确满足方程组；残量的欧几里得范数 8.8818e-016 为机器精度量级，与正文「以允许的计算机浮点数表示的精度满足方程组」一致。**证实**。

## 算例 2：lu 与 PA=LR

```txt
>> [L, R, P] = lu(A)
L = [1.0000       0        0        R = [2.0000 1.0000 1.0000     P = [0 1 0
     0.5000  1.0000       0             0      1.5000 2.5000          0 0 1
     0.5000 -0.3333  1.0000]            0      0      3.3333]         1 0 0]
```

复算：PA = [2 1 1; 1 2 3; 1 0 3]；LR 逐行计算：
第 1 行 = R 第 1 行 = (2, 1, 1)；第 2 行 = 0.5·(2,1,1) + (0,1.5,2.5) = (1, 2, 3)；第 3 行 = 0.5·(2,1,1) − 0.3333·(0,1.5,2.5) + (0,0,3.3333) = (1, 0, 3)。两者相等，故 **PA = LR 成立**；正文「PA = LA」为讹误（[[queries/PA等于LA疑为PA等于LR之辨]]）。**证实**。

## 算例 3：hilb(13) 与 RCOND 警告

```txt
>> x = hilb(13)\ones(13,1)
Warning: Matrix is close to singular or badly scaled.
Results may be inaccurate. RCOND = 2.409320e-017.
```

希尔伯特矩阵 h_{ik}=1/(i+k−1)（[[concepts/希尔伯特矩阵与条件数警告]]）。RCOND = 2.409320e-017 为软件输出转录，未独立复算；对应条件数量级 10^16，量级合理。

## 算例 4：超定方程组与 qr

```txt
>> A = [1 0 3; 2 1 1; 1 2 3; 1 1 -1];  b = [-2; 3; 2; 1];
>> x = A\b, norm(A*x - b)
x = (0.4673, 1.4393, -0.4953)ᵀ      ans = 2.0508
>> [Q, R] = qr(A)
Q = [-0.3780 -0.4583  0.6466  0.4785      R = [-2.6458 -1.8898 -2.6458
     -0.7559 -0.2750 -0.2321 -0.5469            0       1.5584  0.6417
     -0.3780  0.8250  0.4145 -0.0684            0       0       3.5480
     -0.3780  0.1833 -0.5969  0.6836]           0       0       0      ]
```

复算（正规方程 AᵀAx = Aᵀb）：
AᵀA = [7 5 7; 5 6 6; 7 6 20]，Aᵀb = (7, 8, 2)ᵀ；解得 x = (0.46729, 1.43925, −0.49533)ᵀ，与书中 (0.4673, 1.4393, −0.4953)ᵀ 一致；残量 Ax−b = (0.98131, −1.12150, −0.14019, 1.40187)ᵀ，‖Ax−b‖₂ = 2.0508，与书中 ans 一致。**证实**。

qr 输出复算（列向量 a₁=(1,2,1,1)ᵀ、a₂=(0,1,2,1)ᵀ、a₃=(3,1,3,−1)ᵀ 逐列正交化）：
- R(1,1) = −‖a₁‖ = −√7 = −2.6458 ✓；R(1,2) = −5/√7 = −1.8898 ✓；R(1,3) = −7/√7 = −√7 = −2.6458 ✓；
- R(2,2) = ‖a₂ 去 a₁ 分量‖ = √(17/7) = 1.5584 ✓；R(2,3) = 0.6417 ✓；
- R(3,3) 复算值 = √(3638/289) = 3.5483，书中作 3.5480，**末位有微差**（疑书中舍入或转写讹误，已记入 [[queries/19-8-4全节系统性转写讹误清单]]）；
- Q 各列正交，A = QR。**基本证实（R(3,3) 末位除外）**。
