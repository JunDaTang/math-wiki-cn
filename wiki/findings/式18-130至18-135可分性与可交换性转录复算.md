# 式 18.130–18.135 可分性与极小可交换性转录复算

## 转录内容（逐字，18.130 为链式定义）

```latex
% (18.130) 可分性
f(f_1(x_0,u_1), …, f_n(x_{n-1},u_n))
  = F_1(f_1(x_0,u_1), …, f_n(x_{n-1},u_n)),
F_1(f_1,…,f_n) = H_1(f_1, F_2(f_2,…,f_n)),
… …
F_{n-1}(f_{n-1}, f_n) = H_{n-1}(f_{n-1}, F_n(f_n)),
F_n(f_n) = f_n.

% (18.131) 极小可交换性
min_{(a,b)∈A×B} H(f̃(a), F̃(b)) = min_{a∈A} H(f̃(a), min_{b∈B} F̃(b))

% (18.132) 充分条件：H 对第二变元单调不减
H(f̃(a), F̃(b_1)) ⩽ H(f̃(a), F̃(b_2)),  若 F̃(b_1) ⩽ F̃(b_2)

% (18.133) 和式与最大值型费用函数
f^sum = Σ_{j=1}^n f_j(x_{j-1},u_j)，或 f^max = max_{j=1(1)n} f_j(x_{j-1},u_j)

% (18.134) 和式型的 H_j
H_j^sum = f_j(x_{j-1},u_j) + Σ_{k=j+1}^n f_k(x_{k-1},u_k)

% (18.135) 最大值型的 H_j
H_j^max = max{ f_j(x_{j-1},u_j), max_{k=j+1(1)n} f_k(x_{k-1},u_k) }
```

## 复算验证

- **可分性结构**：按 (18.130) 的链式定义逐层代入 $H_j$，确实还原出 $f$ 对全部 $f_1,\dots,f_n$ 的依赖，且每层只新增一个 $f_j$——结构自洽。
- **(18.131) 与 (18.132)**：若 $H$ 对第二变元单调不减，则对每个固定 $a$，$\min_b H(\tilde f(a),\tilde F(b)) = H(\tilde f(a),\min_b\tilde F(b))$，再对 $a$ 取极小即得 (18.131)。验证成立。
- **(18.133)–(18.135)**：和式型的 $H_j^{\mathrm{sum}}$ 显然满足链式定义且对第二变元（其余费用之和）单调不减；最大值型的 $H_j^{\mathrm{max}}$ 对第二变元（其余费用的最大值）亦单调不减。故两类费用函数均同时满足可分性与极小可交换性，与原文断言一致。
