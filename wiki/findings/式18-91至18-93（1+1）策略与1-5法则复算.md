# 式 18.91–18.93（1+1）策略与 1/5 法则复算

对 18.2.6.6 的 (1+1) 突变—选择策略三式作转录与复算。来源：[[10-数学手册原书第10版--9-1826-演化策略--1jct9ap]]（18.2.6.6）。

## 突变（式 18.91）

```latex
\underline{x}_O^k = \underline{x}_P^k + \alpha \underline{d}^k
\tag{18.91}
```

复算要点：若 $\underline{d}^k$ 的分量为独立的 $Z(0,1)\cdot\sigma_i$（式 18.87），则 $\alpha\underline{d}^k$ 的分量标准差为 $\alpha\sigma_i$，即 α 直接缩放突变幅度，与「把 α 看作突变的步长」一致。

## 选择（式 18.92）

```latex
\underline{x}_P^{k+1} =
\begin{cases}
\underline{x}_O^k, & f(\underline{x}_O^k) < f(\underline{x}_P^k),\\
\underline{x}_P^k, & \text{其他},
\end{cases}
\tag{18.92}
```

复算要点：贪心接受使 $f(\underline{x}_P^{k+1}) \leqslant f(\underline{x}_P^k)$，迭代点目标函数值单调不增；严格小于号与 18.2.1–18.2.2 的极小化框架一致（平局时保留亲本）。

## 1/5 成功法则（式 18.93）

```latex
\alpha_{k+1} =
\begin{cases}
c\cdot\alpha_k, & q < 1/5,\\
\dfrac{1}{c}\cdot\alpha_k, & q > 1/5,
\end{cases}
\quad c = 0.8,\dots,0.85
\tag{18.93}
```

复算要点：q < 1/5（成功偏少）时乘 $c = 0.8\ldots0.85 < 1$，步长缩小；q > 1/5（成功偏多）时乘 $1/c \approx 1.18\ldots1.25$，步长放大——与正文叙述方向一致。注意：公式未覆盖 $q = 1/5$ 的情形（自然解释为保持 α 不变，原文未言明）。

## 参数证据强度

公式为手册性陈述，与演化策略标准文献一致（间接印证）；但 c = 0.8…0.85 为经验取值，且文中自承 1/5 法则「是一种粗略的选择」；扩展模型（α 与 $\sigma_i$ 以等概率乘 c、1、1/c，c = 1.1…1.5）细节仅见未具名的 [18.9]（见 [[18-2-6未入库回指缺口]]）。置信度：高（公式）／中（参数推荐值）。
