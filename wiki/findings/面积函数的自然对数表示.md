# 面积函数的自然对数表示（式 2.211–2.214）

## 发现陈述

手册 2.10.2 指出，四种 [[concepts/面积函数]] 均可由自然对数表出：

```latex
\operatorname{Arsinh} x = \ln \left(x + \sqrt {x ^ {2} + 1}\right)                                                          (2.211)
\operatorname{Arcosh} x = \ln \left(x + \sqrt {x ^ {2} - 1}\right) = \ln \left(\frac {1}{x - \sqrt {x ^ {2} - 1}}\right) (x \geqslant 1)   (2.212)
\operatorname{Artanh} x = \frac {1}{2} \ln \frac {1 + x}{1 - x} \quad (| x | < 1)                                                                            (2.213)
\operatorname{Arcoth} x = \frac {1}{2} \ln \frac {x + 1}{x - 1} \quad (| x | > 1)                                                                            (2.214)
```

## 推导依据与意义

- **推导依据**：[[concepts/双曲函数]] 的指数定义（式 2.166–2.171，第 115 页 2.9.1，见 [[findings/双曲函数的指数定义与倒数定义]]）。以 Arsinh 为例：$x = \sinh y = (e^y - e^{-y})/2$ 化为 $e^y$ 的二次方程，解之取正根得 $e^y = x + \sqrt{x^2+1}$，取对数即得式 2.211。
- **式 2.212 的第二形式**利用恒等式 $(x + \sqrt{x^2-1})(x - \sqrt{x^2-1}) = 1$。
- **意义**：对数表示是双曲函数（经指数定义）与 [[concepts/对数函数]] 之间的计算桥梁——面积函数的数值计算与极限行为（如 Artanh 在 $x \to \pm 1$ 时对数发散）均可由此读出；同时真数为正的条件直接给出各面积函数的存在范围。

## 验证

逐式符号验证均成立（将右边对数式代入 sinh/cosh/tanh/coth 还原为 $x$）。证据类型：直接证据（原文公式）+ 独立符号验证。
