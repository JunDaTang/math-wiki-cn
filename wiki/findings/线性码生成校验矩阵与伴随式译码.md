# 线性码的生成矩阵、校验矩阵与伴随式译码（式 5.267–5.269）

《数学手册》5.4.6.2.3 给出 (n,k) 线性码的矩阵刻画，公式原文照录：

```
G = (g_ij)_{k×n}，行向量为 g_1, …, g_k                                 (5.267)
C = {aG | a ∈ GF(2)^k}；a_1a_2…a_k ↦ a_1g_1 + a_2g_2 + … + a_kg_k (= aG)  (5.268)
H = (h_ij)_{(n−k)×n}                                                    (5.269)
```

要点：

- 码由生成矩阵唯一确定；信息字 a_1a_2…a_k 的码字为 a_1g_1 + … + a_kg_k（即 aG）。
- 若 H 的[列]两两不同且非零，则该（二元）线性码为 [1-]纠错码。
- 伴随式译码：算 Hd^T；结果为零向量 ⇒ d 是码字；不然，若 Hd^T 是校验矩阵 H 的第 i [列]，对应码字为 d + e_i（e_i 在第 i 个位置为 1）。

## 转写疑点

源文两处作「H 的第 i **行**」「H 的**行**两两不同」：H 是 (n−k)×n 矩阵，其行是 n 维而列是 n−k 维；Hd^T 是 n−k 维向量，只能与 H 的**列**匹配，且单错纠错的标准条件正是「H 的列两两不同且非零」（单比特差错 e_i 的伴随式恰为 H 的第 i 列）。见 [[queries/校验矩阵的行是否应为列]]。本 finding 按修正后的「列」理解，置信度因此记为中等。
