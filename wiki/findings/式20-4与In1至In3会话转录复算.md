# 式20-4与In1至In3会话转录复算

对《数学手册（原书第10版）》20.2.1 节的式 (20.4) 及三个会话示例 In[1]–In[3] 做了逐字复算：**三例均可在 Mathematica 中逐字复现，本节无数值讹误**。与 19.6–19.8 各节不同，本节属「语法描述」而非「数值算例」，讹误集中在转写脱漏与形近字（见 [[queries/20-2-1全节系统性转写讹误清单]]），不在数值。

## 复算对象（逐字转录）

```
In[1] := x^2 + 2x + 1
Out[1] = 1 + 2x + x^2

In[2] := FullForm[%]
Out[2] = Plus[1, Times[2, x], Power[x, 2]]

In[3] := Part[%, 3] 为 Out[3] = x^2
```

（In[3] 行之「为」疑为「则」，属转写疑点，不影响数值。）

## 逐例结论

1. **In[1] / Out[1]**：键入 `x^2 + 2x + 1` 并将 SHIFT 与 ENTER 一起按下，输出 `1 + 2x + x^2`；Mathematica 分析输入后将其复原为数学标准形式（由例可见多项式按升幂排列）。直接证据，任何 Mathematica 版本可复现。
2. **In[2] / Out[2]**：`FullForm[%]` 以 % 引用上一次输出，返回 `Plus[1, Times[2, x], Power[x, 2]]`。直接证据，逐字复现。
3. **In[3] / Out[3]**：`Part[%, 3]` 取上一次输出的第 3 个元素，得 x²，即 `Power[x, 2]` 的显示形式，仍是表达式。直接证据，逐字复现。

## 直接证据与推断的区分

- 直接证据：上述三例的输入—输出对应关系，属标准 Mathematica 语义，可逐字复现。
- 推断：源文「特别 = 时得到的是该表达式的头」脱「i = 0」，`Part[expr, 0]` 取头的语义在本节文本中需靠上下文（头指派数 0、元素以 1, …, n 编号）推断补全，详见 [[queries/Part之i等于0脱文之辨]] 与 [[concepts/Part（部件提取与头）]]。
