# 运输网络与流的定义（式 5.325a–b）

《数学手册（原书第10版）》5.8.7 节以定义形式给出运输网络、流、流的强度与容量相容性。公式本身为定义性内容，证据仅为定义文本自身；本条置信度评为「中」，因为转录严重残缺，关键结构（回弧 u₁ 的方向）依赖重构假设。

## 逐字转录（含脱落标注）

```
运输网络：一个连通有向图称为运输网络，如果它有两个加标号的顶点 Q（称为源点）和 S（称为汇点），具有下列性质：
a) 存在一条从 Q 的弧 u₁，其中 u₁ 是仅有的以 [?] 为始点及仅有的以 Q 为终点的弧
b) 每个与 u₁ 不同的弧 uᵢ 被指派一个实数 c(uᵢ) ⩾ 0。这个数称为它的容量。弧 u₁ 有容量 ∞。

流：若函数 φ 对每条弧指派一个实数，并且对于每个顶点 v，等式
    Σ_{(u,v)∈G} φ(u,v) = Σ_{(v,w)∈G} φ(v,w)        (5.325a)
成立，则称它为 [G] 上的流。将和
    Σ_{(Q,v)∈G} φ(Q,v)                             (5.325b)
称为流的强度。如果对于 [G] 的每条弧 uᵢ 有 0 ⩽ φ(uᵢ) ⩽ c(uᵢ)，那么称 φ 是与容量相容的。
```

## 重构假设及其内部一致性

原文定义 a)「存在一条从 Q 的弧 u₁」与「u₁ 是仅有的以 Q 为终点的弧」方向矛盾，且始点符号脱落（另有「$Q\iota$」乱码）。重构假设 **u₁ = (S,Q)**（S→Q 回弧，即「仅有的以 S 为始点及仅有的以 Q 为终点的弧」）得到三处内部一致性支持：

1. 守恒式 5.325a 对**所有**顶点（含 Q、S）成立——只有借助回弧把流送回源点，源点与汇点处的守恒才可能非平凡地成立（若没有任何弧以 Q 为终点，守恒将强制流出 Q 的流量为 0，强度恒为 0）。
2. 在 Q 处应用守恒式：流入 Q 的流量（因 u₁ 是唯一以 Q 为终点的弧，即 φ(u₁)）等于流出 Q 的流量（即式 5.325b 的强度），故 φ(u₁) = 流的强度；这也解释了 u₁ 容量取 ∞ 的必要性。
3. 算法步骤 c) 明确排除 u₁（uᵢ ≠ u₁）——仅当 u₁ 以未标号的 S 为始点、已标号的 Q 为终点时，该排除才是必要的，否则 S 会被后向标号立即标出，判定失效。
