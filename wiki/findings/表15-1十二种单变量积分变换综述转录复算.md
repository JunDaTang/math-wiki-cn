# 表 15.1 十二种单变量积分变换综述转录复算

表 15.1（含续表）逐行清点共 **十二种** 变换：拉普拉斯族 4 种（单侧、双侧、有限、卡森）+ 傅里叶族 5 种（全轴、单侧、有限、余弦、正弦）+ 梅林 + 汉克尔 + 斯蒂尔切斯。完整逐字三栏转录（核/符号/注）见 [[sources/10-数学手册原书第10版--11-151-积分变换的概念--1a68qg0]]。

## 紧凑转录

| 变换 | 核（$t>0$ 段；全轴者另注） | 符号 |
|---|---|---|
| [[concepts/拉普拉斯变换]] | $e^{-pt}$ | $\mathcal{L}\{f(t)\}=\int_0^{\infty}e^{-pt}f(t)\,\mathrm{d}t$ |
| [[concepts/双侧拉普拉斯变换]] | $e^{-pt}$（全轴） | $\mathcal{L}_{\mathrm{II}}\{f(t)\}=\int_{-\infty}^{+\infty}e^{-pt}f(t)\,\mathrm{d}t$ |
| [[concepts/有限拉普拉斯变换]] | $e^{-pt}$（$0<t<a$） | $\mathcal{L}_a\{f(t)\}=\int_0^a e^{-pt}f(t)\,\mathrm{d}t$ |
| [[concepts/拉普拉斯-卡森变换]] | $pe^{-pt}$ | $\mathcal{C}\{f(t)\}=\int_0^{\infty}pe^{-pt}f(t)\,\mathrm{d}t$ |
| [[concepts/傅里叶变换]] | $e^{-\mathrm{i}\omega t}$（全轴） | $\mathcal{F}\{f(t)\}=\int_{-\infty}^{+\infty}e^{-\mathrm{i}\omega t}f(t)\,\mathrm{d}t$ |
| [[concepts/单侧傅里叶变换]] | $e^{-\mathrm{i}\omega t}$ | $\mathcal{F}_{\mathrm{I}}\{f(t)\}=\int_0^{\infty}e^{-\mathrm{i}\omega t}f(t)\,\mathrm{d}t$ |
| [[concepts/有限傅里叶变换]] | $e^{-\mathrm{i}\omega t}$（$0<t<a$） | $\mathcal{F}_a\{f(t)\}=\int_0^a e^{-\mathrm{i}\omega t}f(t)\,\mathrm{d}t$ |
| [[concepts/傅里叶余弦变换]] | $\mathrm{Re}[e^{\mathrm{i}\omega t}]=\cos\omega t$ | $\mathcal{F}_c\{f(t)\}=\int_0^{\infty}f(t)\cos\omega t\,\mathrm{d}t$ |
| [[concepts/傅里叶正弦变换]] | $\mathrm{Im}[e^{\mathrm{i}\omega t}]=\sin\omega t$ | $\mathcal{F}_s\{f(t)\}=\int_0^{\infty}f(t)\sin\omega t\,\mathrm{d}t$ |
| [[concepts/梅林变换]] | $t^{p-1}$ | $\mathcal{M}\{f(t)\}=\int_0^{\infty}t^{p-1}f(t)\,\mathrm{d}t$ |

## 复算核验

- **核–积分式一致性**：每行核的分段定义与同行积分限一致（核在 $t<0$ 取 0 ↔ 积分下限 0；有限变体核在 $t>a$ 取 0 ↔ 积分上限 $a$；双侧拉普拉斯与全轴傅里叶核不分段 ↔ 积分限 $(-\infty,+\infty)$）。
- **余弦/正弦核**：$\mathrm{Re}[e^{\mathrm{i}\omega t}]=\cos\omega t$、$\mathrm{Im}[e^{\mathrm{i}\omega t}]=\sin\omega t$ 为 [[concepts/欧拉关系式]] 的直接应用，与同行积分式严格一致。
- **卡森 = $p$ 倍拉普拉斯**：$\mathcal{C}\{f(t)\}=\int_0^\infty pe^{-pt}f(t)\,\mathrm{d}t=p\,\mathcal{L}\{f(t)\}$（$p$ 与积分变量 $t$ 无关）。
- **注栏归属**：$p=\sigma+\mathrm{i}\omega,\ \sigma=0$ 仅属傅里叶族五行；$\omega=0$ 仅属汉克尔行（此时 $p$ 退化为实变量 $\sigma$）；“卡森变换也可以是双侧变换和有限变换”仅属卡森行；$1(t)$ 关系式仅连接双侧与单侧拉普拉斯。十二种核与记号均与通行文献一致。
