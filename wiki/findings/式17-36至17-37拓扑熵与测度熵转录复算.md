# 式 17.36–17.37 拓扑熵与测度熵转录复算

本条目记录数学手册 17.2.2（拓扑熵 17.2.2.1、测度熵 17.2.2.2）中式 (17.36)、(17.37) 及相关性质的转录与独立复算。

## 转录

```latex
rho_n(x, y) := max_{0<=i<=n} rho(phi^{i}(x), phi^{i}(y))         % (17.36)
h(phi) = lim_{eps->0} lim_{n->infty} (1/n) ln N(eps, rho_n)      % 拓扑熵
H_N = - sum_{(i_1,...,i_N)} p(i_1,...,i_N) ln p(i_1,...,i_N)     % (17.37)
h_mu = lim_{eps->0} lim_{N->infty} H_N / (tau N)                 % 柯尔莫哥洛夫—赛奈熵
h(phi^n) = n h(phi);  同胚时 h(phi^k) = |k| h(phi);  流取 h(phi^t) := h(phi^1)
h_mu <= h(phi) 恒成立；某些情形下 h(phi) = sup{ h_mu }
```

## 复算验证

1. **(17.36) 与分离集定义**：$\rho_n$ 为前 $n$ 步最大分离距离，$N(\varepsilon,\rho_n)$ 为两两 $\varepsilon$-分离点集最大基数，双重极限定义自洽（源文「ρₙ 九距离不小千 的点」脱 ε，「千」为「于」之讹）。✓
2. **共轭不变性**：共轭同胚把 $\rho_n$-分离集一一对应（相差度量的连续变形），基数增长率不变，故拓扑熵相等且不依赖度量。✓
3. **迭代律**：$\varphi^n$ 的一步分离对应 $\varphi$ 的 $n$ 步分离，$N$ 按 $n$ 倍速增长，$h(\varphi^n)=n\,h(\varphi)$；同胚时负迭代对称给出 $|k|$。流取 $h(\varphi^1)$ 与时间一致性相容。✓
4. **方体分割信息量 (17.37)**：长度 $N$ 符号序列的香农熵口径正确；$h_\mu=\lim_{\varepsilon\to0}\lim_{N\to\infty}H_N/(\tau N)$ 为单位时间信息增长率，离散情形（$\tau=1$、分割固定）省略 $\varepsilon\to0$ 合理。✓
5. **稳定平衡点 $h_\mu=0$**：轨道恒定，唯一符号序列 $p=1$，$H_N=-\ln 1=0$。✓
6. **倍增映射 $h(\varphi)=h_\mu=\ln 2$**：每步二进制左移一位，$\varepsilon$-分离点数每步翻倍（$N\sim 2^n$），$h(\varphi)=\ln 2$；以勒贝格测度看，每步产生 1 比特信息，$H_N=N\ln 2$，$h_\mu=\ln 2$，两者相等。✓
7. **$h_\mu\leqslant h(\varphi)$ 与变分原理**：不等式为标准结果；手册将 $h(\varphi)=\sup_\mu h_\mu$ 限定于「某些情形」，措辞偏保守——一般紧致空间连续映射即成立变分原理，疑原文另有所指（如 sup 可达性），见 [[queries/变分原理在某些情形下措辞之辨]]。

## 结论

熵的两组定义、全部性质与两个算例（$h_\mu=0$、$\ln 2$）经独立复算成立。计算流程编入 [[methodology/ε分离集拓扑熵计算流程]] 与 [[methodology/方体分割测度熵计算流程]]；两熵对照见 [[comparisons/拓扑熵与测度熵比较]]。
