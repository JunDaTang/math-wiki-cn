# t 分布 m=1、m=2 闭式锚点与 ∞ 行 Φ 表互证复算

对 21.20 节 t 分位数表增设三类精确锚点并逐格复算，方法上扩展 [[methodology/概率分布数值表交叉复算法]]（此前 χ² 表已有 $m=1,2$ 闭式锚点先例，见 [[findings/卡方m1m2闭式锚点与Φ表互证复算]]）。此处 $p$ 均为单侧上侧概率（即表底行读数）。

## 锚点一：m=1，Cauchy 闭式 $t_{p,1}=\cot(\pi p)$

$t$ 分布 $m=1$ 即标准 Cauchy 分布，上侧分位数有闭式 $t_{p,1}=\cot(\pi p)$：

| 单侧 $p$ | $\cot(\pi p)$ | 表值 | 判定 |
|---|---|---|---|
| 0.05 | 6.3138 | 6.31 | ✓ |
| 0.025 | 12.706 | 12.7 | ✓（3 位有效数字） |
| 0.01 | 31.821 | 31.82 | ✓ |
| 0.005 | 63.657 | 63.7 | ✓（3 位有效数字） |
| 0.001 | 318.31 | 318.3 | ✓ |
| 0.0005 | 636.62 | 637.0 | ✗（偏差 0.38） |

五格证实闭式成立；唯末格 637.0 与闭式冲突，构成行内自相矛盾，专论见 [[findings/t分布m1α0-0005表值637-0疑为636-6复算]]。

## 锚点二：m=2，有理闭式 $t_{p,2}=(1-2p)/\sqrt{2p(1-p)}$

| 单侧 $p$ | 闭式值 | 表值 | 判定 |
|---|---|---|---|
| 0.05 | 2.9200 | 2.92 | ✓ |
| 0.025 | 4.3027 | 4.30 | ✓ |
| 0.01 | 6.9646 | 6.97 | 边界（直接两位舍入应 6.96；三位值 6.965 再舍入则 6.97） |
| 0.005 | 9.9248 | 9.92 | ✓ |
| 0.001 | 22.327 | 22.33 | ✓ |
| 0.0005 | 31.599 | 31.6 | ✓ |

## 锚点三：m=∞，正态极限

∞ 行应为标准正态上侧分位数：$z_{0.05}=1.6449$、$z_{0.025}=1.9600$、$z_{0.01}=2.3263$、$z_{0.005}=2.5758$、$z_{0.001}=3.0902$、$z_{0.0005}=3.2905$，对应表值 1.64 / 1.96 / 2.33 / 2.58 / 3.09 / 3.29 **全 ✓**。该行与 21.17 节 Φ 表互证（如 $\Phi(1.96)=0.975$），复用 [[findings/21-17标准正态分布全表复算]] 的既有结果，构成跨节闭环，也构成本 finding 的独立复核来源（故 replicated 记 true）。

## 结论

三类锚点证实：21.20 表按「上侧分位数 + 双侧/单侧双列标」读法成立，主体数值可信；唯一闭式可证的讹误为 m=1 行 637.0。与 χ² 表的锚点布局互为镜像——χ² 锚在 $m=1$（$\chi^2_{\alpha,1}=(z_{\alpha/2})^2$），t 锚在 $m=\infty$（直接即 $z$ 分位数）。
