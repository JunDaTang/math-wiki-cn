# 式 15.25–15.32 特殊函数与例题转录复算

对《数学手册(原书第10版)》15.2.1.3 的阶梯函数、矩形脉冲、δ 函数、分段可微函数及周期函数诸式与例 A–D、周期两例转录并逐例复算；每例均以"直接分段积分"与"δ 导数法"两条独立路径交叉验证。

## 逐例复算（直接证据：源书照录；复算：双法一致）

| 例 | 函数 | 结果 | 复算 |
|---|---|---|---|
| A | $at+b$ 于 $(0,t_0)$ | $\mathcal{L}\{f\}=\frac1p\left[\frac ap+b-e^{-t_0p}\left(\frac ap+at_0+b\right)\right]$ | ✓ 直接积分与 $f'=a\,u_{t_0}(t)+b\delta(t)-(at_0+b)\delta(t-t_0)$ 两法一致 |
| B | 文字段整段损毁 | 残迹 $\mathcal{L}\{f''\}=1-2e^{-t_0p}+e^{-2t_0p}$、$\mathcal{L}\{f\}\propto1/p^2$ | 复原为三角形函数：$f=t$ 于 $(0,t_0)$、$2t_0-t$ 于 $(t_0,2t_0)$；$f''=\delta(t)-2\delta(t-t_0)+\delta(t-2t_0)$；$\mathcal{L}\{f\}=(1-e^{-t_0p})^2/p^2$，复原自洽 ✓（推断，见 [[queries/例B三角形函数段落损毁之复原]]） |
| C | 梯形脉冲 | $\mathcal{L}\{f\}=\frac{E}{t_0}\frac{(1-e^{-t_0p})(1-e^{-(T-t_0)p})}{p^2}$ | ✓ 四个 δ 系数 $\frac{E}{t_0}(1,-1,-1,+1)$ 与因式分解 $1-e^{-t_0p}-e^{-(T-t_0)p}+e^{-Tp}=(1-e^{-t_0p})(1-e^{-(T-t_0)p})$ 一致 |
| D | $t-t^2$ 于 $(0,1)$ | $\mathcal{L}\{f\}=\frac{1+e^{-p}}{p^2}-\frac{2(1-e^{-p})}{p^3}$ | ✓ $\delta(t)$、$\delta(t-1)$ 分别源自 $f'(+0)=1$ 与 $f'$ 在 $t=1$ 的跃度 $-1$ |
| 周期 A | 例 B 的周期延拓，$T=2t_0$ | $\frac{(1-e^{-t_0p})^2}{p^2}\cdot(1-e^{-2t_0p})^{-1}=\frac{1-e^{-t_0p}}{p^2(1+e^{-t_0p})}$ | ✓ 单周期结果乘周期因子 (15.32) |
| 周期 B | 例 C 的周期延拓 | $\frac{E(1-e^{-t_0p})(1-e^{-(T-t_0)p})}{t_0p^2(1-e^{-Tp})}$ | ✓ 同上 |

阶梯函数例 A/B（$u(t-t_0)\sin\omega t$ 与 $u(t-t_0)\sin\omega(t-t_0)$）亦经直接积分复算一致 ✓。

## 推导结论（非源书显式陈述，引用须区分）

**纯阶梯函数的变换 $\mathcal{L}\{u(t-t_0)\}=e^{-t_0p}/p$ 源书未显式给出**，仅可由 (15.30)（$\delta=du/dt$）与 (15.13) 推出。此为推断而非转录。

## 转录缺损

(15.26) 前"高度为[缺 1]、宽度为[缺 T]"数值缺失；(15.31) 后"$f_s'(t)$ [是] $f(t)$ 的一般导数"（"J(t)"为 f(t) 之讹）；"数值 $f(+0),f'(+0),\cdots$ 应该用[缺]代替"（见 [[queries/δ方法初值句应该用何值代替疑为左极限f减0系列]]）；周期例"由例[缺 B/C]，以周期[缺 T]"。

## 置信度评估

A、C、D、周期两例及阶梯函数两例：confidence: high，replicated: true（双法一致）。例 B 复原为高置信推断（三条独立证据链自洽），正文措辞待比对原书。
