# 式 16.180–16.188 随机游动求解边值问题转录复算

对《数学手册(原书第10版)》16.3.5.4 第 2 条随机游动求解拉普拉斯狄利克雷问题的逐式转录与复算（全节数学密度最高的部分）。

## 转录

```
(16.180a) Δu = ∂²u/∂x² + ∂²u/∂y² = 0,  (x,y)∈G
(16.180b) u(x,y) = f(x,y),  (x,y)∈Γ
(16.181)  u(R_i) = f(R_i)  (i=1,2,…,N)
(16.182)  p(P,R_i) = p((x,y),R_i)
(16.183)  p(R_i,R_i)=1,  p(R_i,R_j)=0  (i≠j)
(16.184)  p((x,y),R_i) = (1/4)[p((x-1,y),R_i)+p((x+1,y),R_i)+p((x,y-1),R_i)+p((x,y+1),R_i)]
(16.185)  p((x,y),R_i) ≈ m_i/n
(16.186)  v(P) = v(x,y) = ∑_{i=1}^{N} f(R_i)·p((x,y),R_i)
(16.187)  v(x,y) = (1/4)[v(x-1,y)+v(x+1,y)+v(x,y-1)+v(x,y+1)]
(16.188)  v(x,y) ≈ (1/n)∑_{i=1}^{n} m_i·f(R_i)
```

## 复算

- **(16.183)** 吸收态边界条件：从 R_i 出发的游动已终止于 R_i（概率 1），不可能终止于其他 R_j（概率 0）。正确，即 [[concepts/吸收状态]] 性质。
- **(16.184)** 一步分解（全概率）：从 (x,y) 出发先以 1/4 移至四邻点之一，再从那里命中 R_i，故 p((x,y),R_i) 为四邻点命中概率的平均。正确——p 是离散调和函数。
- **(16.186)** v = Σf·p 为命中概率的线性组合；边界值 v(R_j) = Σᵢ f(R_i)·p(R_j,R_i) = f(R_j)·1 = f(R_j)，据 (16.183)。正确。
- **(16.187)** 以 f(R_i) 乘 (16.184) 并对 i 求和：v(x,y) = 四邻点 v 的平均。正确——v 与 p 满足同一离散调和方程，v 为狄利克雷问题 (16.180a,b) 的离散解。
- **(16.185)/(16.188)** 以频率 m_i/n 估计 p((x,y),R_i)，代入 (16.186) 得 v ≈ (1/n)Σᵢ m_i f(R_i)。推导自洽，但 **(16.188) 求和上限原文作 n，按 m_i 以边界点编号 i=1,…,N，应为 N**，见 [[queries/式16-188求和上限n疑为N]]。

## 转写疑点

- 两处回指式号疑误：「(16.185) 给出了差分方程 (16.180a) 的近似解」（p 满足的是 (16.184)）；「根据 (16.184)，有 v(R_j)=f(R_j)」（取值依据是 (16.183)），见 [[queries/随机游动两处回指式号疑误之辨]]。
- (16.188) 前句用 m_j、后文用 m_i，记号不一致。
- 「以概率 终止」「都将以及率到达」等处数字 1 脱落；「二次格」疑为「正方形网格」（[[queries/二次格疑为正方形网格]]）；「G 是 xy 平面内的单连通区域 I' 表示 的边界」处 Γ 脱落（「I'」为 Γ 之转写残迹）。

## 结论

数学内容全部复算通过；随机游动—吸收马尔可夫链—离散调和方程的结构对应（(16.184) 与 (16.187) 同形）是本节与 16.2.6 [[concepts/马尔可夫链]] 概念群的最佳综合点。
