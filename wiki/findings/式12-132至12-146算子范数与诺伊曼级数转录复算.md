# 式 12.132–12.146 算子范数、算子空间与诺伊曼级数转录复算

## 逐字转录

```
‖T(x)‖ ⩽ λ‖x‖, ∀x∈X                                        (12.132)
‖T‖ := inf{λ>0 : ‖Tx‖ ⩽ λ‖x‖, ∀x∈X}                        (12.133)
‖T‖ = sup_{‖x‖⩽1}‖Tx‖ = sup_{‖x‖<1}‖Tx‖ = sup_{‖x‖=1}‖Tx‖  (12.134)
‖Tx‖ ⩽ ‖T‖·‖x‖, ∀x∈X                                        (12.135)
(Tx)(s) = ∫_a^b K(s,t)x(t)dt  (s∈[a,b])                      (12.136)
‖T‖ = max_{s∈[a,b]} ∫_a^b |K(s,t)|dt                         (12.137)
U(x)=S(x)+T(x),  (αT)(x)=α·T(x)                              (12.138)
(ST)(x)=S(Tx)                                                (12.139)
T⁰=I,  Tⁿ=Tⁿ⁻¹T  (n=1,2,…)                                    (12.140)
‖Tⁿ‖ ⩽ ‖T‖ⁿ  (n=1,2,…)                                        (12.141)
r(T) = lim_{n→∞} ⁿ√‖Tⁿ‖                                      (12.142)
r(T)⩽‖T‖, r(Tⁿ)=[r(T)]ⁿ, r(αT)=|α|r(T), r(T)=r(T*)           (12.143)
(λI−T)⁻¹ = λ⁻¹I + λ⁻²T + … + λ⁻ⁿTⁿ⁻¹ + …  (|λ|>r(T))          (12.144)
T_n x → Tx 在 Y 中, ∀x∈X            （点点收敛）               (12.145) ※
‖T_n − T‖ = sup_{‖x‖⩽1}‖T_nx − Tx‖ → 0  （一致收敛）           (12.146) ※
```

※ 源文两式均误排 $T_n$ 为 $T^n$（OCR 上下标混淆），此处按文意（“线性连续算子序列 $T_n$”）校正转录。

## 复算判定

- **(12.134) 复算无误**：由线性算子的齐次性，$\sup_{\|x\|\le1}$、$\sup_{\|x\|<1}$、$\sup_{\|x\|=1}$ 三者在 $X\ne\{0\}$ 时一致。
- **(12.137) 复算无误**：$\|Tx\|_C=\max_s\left|\int K(s,t)x(t)dt\right|\le\max_s\int|K(s,t)|dt\cdot\|x\|_C$；反向在最大值点 $s^*$ 附近取尖峰连续函数逼近取等。
- **(12.141) 复算无误**：由 (12.139) 与范数相容性 $\|ST\|\le\|S\|\|T\|$ 归纳即得。
- **(12.144) 复算无误**：$(\lambda I-T)^{-1}=\lambda^{-1}(I-\lambda^{-1}T)^{-1}=\sum_{n\ge1}\lambda^{-n}T^{n-1}$，收敛由 $|\lambda|>r(T)$ 保证。
- (12.142)–(12.143) 为标准结果，转录无误（$r(T)=r(T^*)$ 一项涉及未入库的 12.6 伴随算子）。
- 转写噪声：12.5.1.1–12.5.1.2 多处主语（$T$、$Y$、$X$、$I$、$\lambda$）脱落；12.5.1.3.3“应用”段（求积公式收敛性、求和方法等）转写后无实质内容。汇总见 [[queries/12-5全节系统性转写讹误清单]]。
