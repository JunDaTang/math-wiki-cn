# 泊松方程粗网格三内点算例复算

19.5.1 例 1：$\Delta u=-1$ 于矩形 $|x|<1,\ |y|<2$，边界 $|x|=1,|y|=2$ 上 $u=0$；步长 $h=1$ 的正方形网格，内点仅 $(0,-1),(0,0),(0,1)$ 三个。

## 转录（源印）

```text
4u_{0,1}  = 0 + 0 + 0 + u_{0,0} + 1
4u_{0,0}  = 0 + u_{0,1} + 0 + u_{0,-1} + 1
4u_{0,-1} = 0 + u_{0,0} + 0 + 0 + 1
解：u_{0,0} = 3/7 ≈ 0.429,  u_{0,1} = u_{0,-1} = 5/14 ≈ 0.357
```

## 复算

由对称性 $u_{0,1}=u_{0,-1}=:B$，$u_{0,0}=:A$。方程组化为 $4B=A+1$、$4A=2B+1$。将 $B=(A+1)/4$ 代入第二式：$4A=(A+1)/2+1$，即 $8A=A+3$，故 $A=3/7$；$B=(3/7+1)/4=10/28=5/14$。

**与源值完全一致**：$u_{0,0}=3/7\approx0.429$，$u_{0,1}=u_{0,-1}=5/14\approx0.357$。

## 备注

源文「…+ 1 2$4u_{0,0}…」中的「1 2」疑为「$1^{2}$」（$h^{2}=1^{2}=1$），见 [[queries/例1末项1与2疑为1平方之辨]]；该疑点不影响数值。本算例与 [[findings/边界配置法算例复算]] 解同一问题（配置法：$v(0,0)=0.4562$、$v(0,1)=0.3919$），源未评判优劣。
