# 式 12.15–12.18 线性无关、凸集与锥转录复算

## 转录内容

```
α₁x₁ + α₂x₂ + … + αₙxₙ = 0 蕴涵 α₁ = α₂ = … = αₙ = 0            (12.15)
{λx + (1−λ)y : 0 ≤ λ ≤ 1}                                       (12.16)
x, y ∈ K 和 λ, μ ≥ 0 推出 λx + μy ∈ K                            (12.17)
Σ|ξₙ|^p ≤ a                                                     (12.18)
```

## 复算验证

- **单位序列无关性**：有穷组合 Σα_k e_k = 0 的第 k 个分量为 α_k，逐分量得 α_k = 0。✓ 故 {e₁, e₂, …} 在任意序列空间线性无关，从而 s、φ、m、c、c₀、ℓ^p 均无穷维（独立于正文「例 B∼E」表述的复算证据，参见 [[queries/例b至e范围是否应为b至g]]）。
- **1, cos 2t, cos²t 线性相关**：cos 2t = 2cos²t − 1 ⟹ cos²t − ½·cos 2t − ½·1 = 0，系数 (−½, −½, 1) 非全零。✓
- **(12.16) 括号错位**：正文定义处「λx + (1−λ y)」应为 λx + (1−λ)y；按修正后定义，线段封闭性与凸包 = 有穷凸组合全体（λᵢ ∈ [0,1]，Σλᵢ = 1）的表述自洽。✓
- **锥的等价刻画**：(凸 + 正齐次 + 尖) ⟹ (12.17)：λx + μy 中 λ+μ > 0 时可写 (λ+μ)·[λ/(λ+μ)·x + μ/(λ+μ)·y]，方括号内由凸性属 K，再由正齐次性得结论；λ = μ = 0 时得 0 = 0·x ∈ K（正齐次性取 λ=0）。反向亦直接。✓
- **球集 (12.18) 凸但非锥**（仅关于 C = {{ξₙ} ∈ ℓ^p : Σ|ξₙ|^p ≤ a}，a > 0，1 ≤ p < ∞）：
  - 凸性：对 x, y ∈ C 与 λ ∈ [0,1]，逐项 |λξₙ + (1−λ)ηₙ| ≤ λ|ξₙ| + (1−λ)|ηₙ|，再由 t ↦ t^p 的凸性得 |λξₙ + (1−λ)ηₙ|^p ≤ λ|ξₙ|^p + (1−λ)|ηₙ|^p，求和 ≤ a。✓
  - 非锥：取 x ∈ C 使 Σ|ξₙ|^p = a（如单点支撑 a^{1/p}），则 Σ|2ξₙ|^p = 2^p a > a，正齐次性失效。✓

## 维数断言转录注记

正文「空间 𝔽ⁿ 是 n 维空间，在例 B∼E 中所有其他的空间都是无穷维」——按序列例子编号，字面涵盖 s(B)、φ(C)、m(D)、c(E)；c₀(F) 与 ℓ^p(G) 未在内，疑「B∼E」应为「B∼G」，见 [[queries/例b至e范围是否应为b至g]]。

## 结论

四组公式中 (12.16) 有一处括号错位（可复原），其余转录忠实；三角函数相关性与球集「凸非锥」均复算通过。概念页：[[concepts/线性无关性]]、[[concepts/凸集与凸包]]、[[concepts/凸锥]]。
