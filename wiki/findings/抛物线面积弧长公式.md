# 抛物线面积弧长公式（式 3.351–3.352，式 3.352a/c 已验证、3.352b 存疑）

## 面积（3.351）

```
抛物线弓形 OPN:  S_OPN = (2/3)·S_MQNP   （MQNP 为平行四边形）   (3.351a)
曲线下面积 OPR:  S_OPR = 2xy/3                                  (3.351b)
```

(3.351b) 已经积分验证成立：∫₀^x y dx = ∫₀^x √(2px) dx = (2/3)x·√(2px) = 2xy/3（视为已复算）。

## 弧长（3.352）——初等可积（与椭圆、双曲线不同）

```
l_OP = (p/2)·[√((2x/p)(1 + 2x/p)) + ln(√(2x/p) + √(1 + 2x/p))]          (3.352a)
     = −√(x(x + p/2)) + (p/2)·Arsinh√(2x/p)      （(3.352b)，首项负号存疑）
近似式（x/y 较小）:  l_OP ≈ y·[1 + (2/3)(x/y)² − (2/5)(x/y)⁴]            (3.352c)
```

## 验证情况

- (3.352a)：由 l = ∫√(1 + (dy/dx)²) dx，dy/dx = p/y = √(p/(2x))，被积函数 √(1+p/2x) = √((2x+p)/2x)，积分得 (p/2)[√((2x/p)(1+2x/p)) + ln(√(2x/p)+√(1+2x/p))]，独立推导验证成立。✓
- (3.352c)：对 (3.352a) 在 x/y 小时展开，前两项与近似式一致，验证成立。✓
- (3.352b)：第二表达式的首项符号为负，与 (3.352a) 不等价——推导表明应为 **+√(x(x+p/2))**；负号下弧长在 x 小时甚至可能为负。存疑见 [[queries/式3-352b首项负号是否为转写错误]]。

整体置信 high（(3.352a)(3.352c)(3.351b) 均已独立验证），唯 (3.352b) 一处待核。
