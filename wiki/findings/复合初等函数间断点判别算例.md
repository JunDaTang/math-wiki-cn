# 复合初等函数间断点判别算例（2.1.5.4）

《数学手册》(原书第10版) 2.1.5.4 末给出判别算例：求 $y=\dfrac{\mathrm{e}^{1/(x-2)}}{x\sin\sqrt[3]{1-x}}$ 的间断点。手册解法转写如下：

```
x = 2：是 1/(x−2) 的无穷间断点；又 (e^{1/(x−2)})|_{x=2−0} = 0、
       (e^{1/(x−2)})|_{x=2+0} = ∞；此时 y 的分母为有限值
       （2·sin ∛(−1) = −2 sin 1 ≠ 0），故 x = 2 是与图 2.9 点 C
       相同的无穷间断点。

x = 0 及 sin ∛(1−x) = 0 的根：其根为 ∛(1−x) = nπ，即
       x = 1 − n³π³（n 为任意整数）；当 x 为上述数时分子不等于 0，
       因此 x = 0, 1, 1±π³, 1±8π³, 1±27π³, … 也是函数的间断点，
       且与图 2.9 中的点 E 类似（无穷间断）。
```

## 复核结论

来源分析阶段对该算例独立复核：分母零点集合 $\{0\}\cup\{1-n^3\pi^3:n\in\mathbb{Z}\}$、$x=2$ 处“左 $0$、右 $\infty$”的单侧行为及各点的无穷间断类型均正确。

## 疑点

手册原文在 $x=0$ 处的推理为“当 $x=0$ 时 $\sin\sqrt[3]{1-x}=\sin 1$，故分母为 0”。但 $\sin 1\neq0$（1 弧度不是 $\pi$ 的整数倍），在 $x=0$ 处为零的是因子 $x$：$x\sin\sqrt[3]{1-x}=0\cdot\sin 1=0$。推理疑脱漏“$x\cdot\sin 1=0$”一步，见 [[queries/算例x等于0处分母为零的推理是否脱漏]]。结论本身无误，故本条 confidence 定为 medium 仅为标记该表述疑点。
