# 方尖形与楔形体积公式（式 3.134–3.135）

**直接证据**（源文 3.3.3(9)–(10)，图 3.61–3.62）。

**方尖形**：所有侧面都是**不规则四边形**的多面体；在图 3.61 的特殊情形中，两平行的底是矩形，相对的棱与底成相同的倾角但没有公共点。设 a、b 与 a₁、b₁ 是两个底的边，h 是它的高：

$$V = \frac{h}{6}\left[(2a + a_1)b + (2a_1 + a)b_1\right] = \frac{h}{6}\left[ab + (a + a_1)(b + b_1) + a_1b_1\right] \tag{3.134}$$

**名称脱落的立体（疑为楔形）**：底为矩形、侧面是两个相对的等腰三角形和两个相对的等腰梯形（图 3.62）的多面体——**名称在转写中整体脱落**（「(10) 是底为矩形的一个多面体」）：

$$V = \frac{1}{6}(2a + a_1)\,bh \tag{3.135}$$

其身份待据原书核定，见 [[queries/3-3-3-10无名立体名称是否为楔形]]。

**独立核验（已复核）**：

- 3.134 两形式代数恒等：展开右式得 2ab + ab₁ + a₁b + 2a₁b₁，与左式展开完全一致 ✓。
- 极限检验：3.134 取 a₁ = a、b₁ = b（两底全等）得 V = abh（长方体）✓；取 a₁ = b₁ = 0 得 V = abh/3（退化为锥）✓。
- 3.135 极限检验：a₁ = 0 时 V = abh/3（锥）✓；a₁ = a 时 V = abh/2（退化为底 a×b、高 h 的三棱柱状楔体）✓——与「矩形底楔形」的几何预期一致，支持楔形（德文 Keil）候选身份。

**归属警示**：3.134 属方尖形、3.135 属该无名立体，两者记号相似但立体不同，不可混用。两式同呈 h/6[端项组合] 的拟柱体（Prismatoid）结构——独立可核背景：一般拟柱体公式 V = h/6(A₁ + 4A_m + A₂)。
