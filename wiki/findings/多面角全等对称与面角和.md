# 多面角全等、对称与面角和定理（3.3.2）

**直接证据**（源文 3.3.2(2)）：

1. **全等**：如果两个多面角可以重叠，则它们彼此相等（全等）；此时对应的元素——棱和顶点处的平面角——一定重合。
2. **对称隅角**：如果两个隅角在顶点处对应的元素相等但具有**相反的顺序**，则不能重叠；称它们为对称隅角，因为可将它们放在彼此对称的位置（图 3.51）。
3. **凸性**：凸多面角完全位于它的每个面的一侧。
4. **面角和定理**：对每个凸多面角，平面角之和

$$A O B + B O C + \cdots + E O A < 360^{\circ}$$

**核验与说明**：面角和定理为标准结果（源文按字面读为「凸多面体的平面角之和……于 360°」，其中「小于」二字脱落、且「多面体」疑为「多面角」之讹，见 [[queries/3-3-2-2正文三处多面体是否应作多面角]]）。定理的边界情形恰为「压平」：面角和趋近 360° 时多面角退化为平面区域。本条为定理陈述，未做独立重推。

**2D/3D 对偶**：凸多边形的外角和**恰为** 360°（[[findings/一般多边形角和对角线公式]]），凸多面角的面角和**严格小于** 360°——「等号」与「严格不等号」的差别是两个维度间的本质区别，详见 [[comparisons/多边形角和与多面角面角和比较]]。
