# 式 19.291–19.296 命令格式与表 19.5–19.8 转录

## 摘要

本源含六个编号命令格式（Mathematica 两个、Maple 四个）与四张命令表；以下逐字转录，供回指与校勘。转录与各小节算例上下文互证一致。

## 编号公式

```txt
(19.291)  Fit[{y1, y2, ...}, funkt, x]                 （Mathematica，曲线拟合）
(19.292)  NIntegrate[fun, {x, xa, x1, x2, ..., xe}]    （Mathematica，积分限中列出奇点）
(19.293)  evalf(expr, n)                               （Maple，表达式数值求值）
(19.294)  fsolve(eqn, var, option)                     （Maple，方程数值解）
(19.295)  evalf(int(f(x), x = a..b), n)                （Maple，定积分）
(19.296)  dsolve(deqn, var, numeric)                   （Maple，微分方程数值解）
```

注：(19.291) 中数值 y_i 组成数据表，funkt 为用于数据拟合的可选函数表，x 表示独立变量的相应区域；若 funkt 选定为 Table[x^i, {i, 0, n}]，则是用 n 次多项式进行拟合。(19.292) 给出积分上下限间的奇点 x_i，可使结果更准确。

## 表 19.5 数值运算（Mathematica）

| 算子 | 功能 |
|---|---|
| NIntegrate | 计算定积分 |
| NSum | 计算和 Σ_{i=1}^{n} f(i) |
| NProduct | 计算积 |
| NSolve | 数值计算求解代数方程 |
| NDSolve | 数值计算求解微分方程 |

## 表 19.6 插值命令（Mathematica）

| 命令 | 说明 |
|---|---|
| Interpolation[{y1, y2, ···}] | 对 i 为整数，x_i 取 y_i 值，给出近似函数 |
| Interpolation[{{x1, y1}, {x2, y2}, ···}] | 对点列 (x_i, y_i) 给出近似函数 |

## 表 19.7 微分方程数值解命令（Mathematica）

| 命令 | 说明 |
|---|---|
| NDSolve[dgl, y, {x, xa, xe}] | 在 xa 和 xe 之间的区域计算微分方程数值解 |
| InterpolatingFunction[liste][x] | 给出点 x 处的解 |
| Plot[Evaluate[y[x] /. lös], {x, xa, xe}] | 解的图形表示 |

（dgl、liste、lös 为德文原词残留：DGL=Differentialgleichung（微分方程）、Lösung（解）、Liste（表）。）

## 表 19.8 命令 fsolve 的选择（Maple）

| 选项 | 说明 |
|---|---|
| complex | 确定一个复根（或多项式的所有根） |
| maxsols = n | 确定至少 n 个根（仅对多项式方程） |
| fulldigits | 保证不减少计算中用到的位数 |
| intervall | 在给定区间内求根 |

（intervall 为源文拼写。）

## 校勘注

- 式 (19.291) 正文处「funkt 为用千数据拟合的可选函数表， 表示独立变量的相应区域」：「千」为「于」之讹，且 x 前脱符号。
- 表 19.7 的 Plot 行中 /. 为 Mathematica 替换算子，源文排版正常。
