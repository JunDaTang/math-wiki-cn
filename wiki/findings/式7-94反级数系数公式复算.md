# 反级数的系数公式（式 7.94a–c，已复算）

手册 7.3.3.2 第 4 条「幂级数的反级数」：若设级数

```latex
y = f(x) = ax + bx^2 + cx^3 + dx^4 + ex^5 + fx^6 + \dots \quad (a \neq 0)                      % (7.94a)
```

则其反函数为级数

```latex
x = \varphi(y) = Ay + By^2 + Cy^3 + Dy^4 + Ey^5 + Fy^6 + \dots                                 % (7.94b)
```

考虑 y 的方幂、比较系数（即 [[系数比较法]]：把 x = φ(y) 代入 y = f(x) 展开），得

```latex
A = \frac{1}{a},\quad B = -\frac{b}{a^3},\quad C = \frac{2b^2 - ac}{a^5},\quad D = \frac{5abc - a^2d - 5b^3}{a^7},
E = \frac{6a^2bd + 3a^2c^2 + 14b^4 - a^3e - 21ab^2c}{a^9},
F = \frac{7a^3be + 7a^3cd + 84ab^3c - a^4f - 28a^2b^2d - 28a^2bc^2 - 42b^5}{a^{11}}           % (7.94c)
```

手册并告诫：「反级数的收敛性必须在各种情况下分别验证」。

## 复算结论

- **A–E：手工推导核对通过**（代入 φ(y) 于 f，展开至 y⁵ 逐系数验证）。低阶抽查：A = 1/a ✓；B = −b/a³ ✓；C = (2b² − ac)/a⁵ ✓。
- **F：与标准级数反演（拉格朗日反演）公式一致**。
- 转写注意：源文 (7.94c) 中 E 的标签独立成行、F 无标签；x⁶ 项系数记号 f 与函数名 f(x) 撞名，为原书记号选择（此处保留）。

## 可复用性

这组公式是可直接复用的查表级工具（已知级数求反函数展开的前六项系数），与 [[式7-86-7-93幂级数运算系数公式复算]] 共同构成本节「幂级数代数」的工具箱。概念页见 [[反级数]]。
