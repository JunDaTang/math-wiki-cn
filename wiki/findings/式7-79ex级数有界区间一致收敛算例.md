# 算例：e^x 级数在任意有界区间上一致收敛（式 7.79，已复算）

手册 7.3.2.1 的第一个算例：级数

```latex
1 + \frac{x}{1!} + \frac{x^2}{2!} + \dots + \frac{x^n}{n!} + \dots = \mathrm{e}^x             % (7.79a)
```

（展开式参见第 1373 页表 21.5）对每个 x 均收敛，且在任意有界区间 |x| < a 上一致收敛。论证用麦克劳林公式的余项（参见 7.3.3.3）：

```latex
|S(x) - S_n(x)| = \left|\frac{x^{n+1}}{(n+1)!}\mathrm{e}^{\Theta x}\right| < \frac{a^{n+1}}{(n+1)!}\mathrm{e}^a \quad (0<\Theta<1)   % (7.79b)
```

因为 (n+1)! 的增长速度远快于 a^{n+1}，故 n 足够大时上式右端与 x 无关且小于 ε。但该级数并非在整个数轴上一致收敛：对任意大的 n，总存在值 x 使 |x^{n+1}e^{Θx}/(n+1)!| 大于预先给定的 ε。

## 独立复算

- 余项公式与 e^x 的麦克劳林余项（式 7.97b）一致：R_n = x^{n+1}e^{Θx}/(n+1)!，在 |x| < a 上被 a^{n+1}e^a/(n+1)!（与 x 无关）控制，且右端 → 0 ——「有界区间上一致收敛」复算通过。
- 「全轴非一致」：固定 n，取 x → ∞ 可使 |R_n| 任意大 —— 通过。
- **指标差一**：按式 7.75 的「前 n 项」约定，余项应为 x^n e^{Θx}/n!；式 7.79b 的 x^{n+1}/(n+1)! 对应「S_n 含至 x^n/n! 项」（n+1 项）的约定。定性结论不受影响，详见 [[式7-80c余项指数差一与Sn指标约定]]。

## 关联

此例是「内闭一致收敛但非整体一致收敛」的典型；其和 e^x 连续（7.3.2.2 连续性的正例）。与反例对照见 [[一致收敛两算例比较]]。
