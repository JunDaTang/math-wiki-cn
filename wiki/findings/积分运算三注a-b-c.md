# 积分运算三注 a–c

源文（8.1.1.2“2. 一般积分”末尾）称“在积分中下面的注有着重要作用”（“下而”为“下面”之讹），随后给出三注。本页逐注转录并评估证据强度。

## 注 a（积分常数的忽略规则）

> 通常可以忽略积分常数，除非某些积分在不同形式时可用不同的任意常数来表示。

- 类型：操作性规则；证据强度：高。
- 表述拗口，疑有转写损伤，原意待复原（见 [[queries/8-1-1全节系统性转写讹误清单]]）。

## 注 b（ln 绝对值替换规则）

> 若原函数中存在一个含 $\ln f(x)$ 的表达式，$\ln f(x)$ 必须用 $\ln\left|f(x)\right|$ 代替。

- 类型：操作性规则，安全使用积分表的硬规则；证据强度：高。
- 依据（独立可验证背景）：在 $f(x) \neq 0$ 的区间上 $\dfrac{\mathrm{d}}{\mathrm{d}x}\ln\left|f(x)\right| = f^{\prime}(x)/f(x)$ 与 $f$ 的符号无关，故替换后仍是原函数，且适用范围扩大到 $f$ 变号的各区间。表 8.1 中 $\int \mathrm{d}x/x = \ln\lvert x\rvert$、$\int \tan x\,\mathrm{d}x = -\ln\lvert\cos x\rvert$ 等条目即体现此规则（见 [[findings/表8-1基本积分22式逐字转录与复算]]）。

## 注 c（初等可积性判据）

> 若原函数以幕级数的形式给出，则函数不能按初等方法积分。（“幕级数”为“幂级数”之讹）

- 类型：实质性断言；证据强度：方向正确但表述含混，medium。
- **表述张力**：字面过强——任何（解析的）函数的原函数原则上都可“以幂级数形式”写出；原意应为“若原函数**只能**以幂级数的形式给出，则函数不能按初等方法积分”。原文是否含“只能”（德文 nur）一词待查（见 [[queries/8-1-1全节系统性转写讹误清单]]）。
- **与第 7 章的口径差异**：在已入库的 7.3（函数项级数，[[sources/10-数学手册原书第10版--8-73-函数项级数--1itytmq]]）语境中，幂级数作为**和函数**的表示出现（如 $\mathrm{e}^{-1/x^2}$ 的麦克劳林级数恒为零的反例，见 [[findings/e负x平方分之一麦克劳林级数反例]]）；本注则把幂级数用作**原函数**的表示。两处口径不同，引用 [[concepts/幂级数]] 时需注意限定。
- 标准例证（独立可验证背景）：$\mathrm{e}^{-x^2}$、$\dfrac{\sin x}{x}$ 等无初等原函数（Liouville 理论），其原函数只能以幂级数等形式表示，与注 c 的原意一致。

## 总体评估

- 注 a、b 为高置信操作规则；注 c 为方向正确但表述含混的断言；本页整体 confidence: medium。
- 注 b 可由求导直接验证；注 c 属理论断言，未做数值复算，replicated: null。
