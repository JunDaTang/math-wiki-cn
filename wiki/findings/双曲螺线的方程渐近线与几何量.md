# 双曲螺线的方程渐近线与几何量（式 2.248）

手册 2.14.2 节给出[[concepts/双曲螺线]]的极坐标方程、渐近行为与几何量公式。

## 内容

**方程**：

$$
\rho = \frac {a}{| \varphi |} \quad (a > 0, - \infty < \varphi < 0, 0 < \varphi < \infty).\tag{2.248}
$$

曲线在关于 y 轴对称位置有两个分支（φ < 0 与 φ > 0）。

**渐近行为**：直线 y = a 为两个分支的渐近线；原点为渐近点。

**几何量**：

- 面积（区域 $P_1OP_2$）$S = \frac{a^{2}}{2}\left(\frac{1}{\varphi_{1}} - \frac{1}{\varphi_{2}}\right)$，且 $\lim_{\varphi_{2} \to \infty} S = \frac{a^{2}}{2\varphi_{1}}$；
- 曲率半径 $r = \frac{a}{\varphi}\left(\frac{\sqrt{1 + \varphi^{2}}}{\varphi}\right)^{3}$。

手册未给出本曲线的弧长公式。

## 核验

- S、r 两式经极坐标通用公式独立推导复核，成立；
- 正支渐近线经直接取极限核验：φ→0⁺ 时 $x = \rho\cos\varphi \to +\infty$、$y = \rho\sin\varphi \to a$，确为 y = a；
- **负支例外**：在 ρ 恒正的 $|\varphi|$ 记法下，负支 φ→0⁻ 时趋于 (+∞, −a)，渐近线应为 y = −a，且两支的对称轴应为 x 轴而非 y 轴。正文「y 轴对称 + 公共渐近线 y = a」只有在允许负 ρ 的原始记法 ρ = a/φ 下才全部成立——见 [[queries/式2-247与2-248取绝对值与y轴对称渐近线y等于a是否矛盾]]。

此处 replicated 指分析者的独立推导复核（负支渐近线一项为唯一未复现的正文断言）。
