# 一元隐函数各阶导数公式（式 6.53a–f，逐字转录与复算）

《数学手册(原书第10版)》6.2.3.2 条目 (1)：一元函数 y = f(x) 由方程 F(x, y) = 0 给出，"利用 (6.51b) 可对 (6.53a) 进行微分"，得到一阶至三阶导数公式链。

## 逐字转录

$$F(x, y) = 0 \tag{6.53a}$$

$$F_x + F_y\, y' = 0, \tag{6.53b}$$

故

$$y' = -\frac{F_x}{F_y} \quad (F_y \neq 0). \tag{6.53c}$$

"用同样的方法可得 (6.53b) 的微分"：

$$F_{xx} + 2F_{xy}\, y' + F_{yy}\,(y')^2 + F_y\, y'' = 0. \tag{6.53d}$$

源文此处作"(6.53b) ，有"（脱漏动词，且引用编号疑应为 6.53d，见 [[queries/式6-53e前引用6-53b是否应为6-53d]]）：

$$y'' = \frac{2F_x F_y F_{xy} - (F_y)^2 F_{xx} - (F_x)^2 F_{yy}}{(F_y)^3}. \tag{6.53e}$$

"利用类似的方法可计算三阶导数"：

$$F_{xxx} + 3F_{xxy}\, y' + 3F_{xyy}\,(y')^2 + F_{yyy}\,(y')^3 + 3F_{xy}\, y'' + 3F_{yy}\, y' y'' + F_y\, y''' = 0, \tag{6.53f}$$

源文续作"巾此可把 y‴ 表示出来"（"巾此"为"由此"之讹）。

## 复算记录

**6.53b**：对 6.53a 应用式 6.51b（中间变量取 x 与 y = y(x)），F 沿曲线的全导数为零：F_x + F_y y′ = 0。✓

**6.53d**：以全导算子 D = ∂ₓ + y′∂_y 作用于 6.53b：

```
D(F_x) + D(F_y)·y′ + F_y·y″
= (F_xx + y′F_xy) + (F_xy + y′F_yy)·y′ + F_y y″
= F_xx + 2F_xy y′ + F_yy (y′)² + F_y y″ = 0     ✓ 与 6.53d 一致
```

系数 (1, 2, 1) 呈二项式模式。

**6.53e**：由 6.53d 解出 y″，代入 y′ = −F_x/F_y：

```
y″ = −[F_xx + 2F_xy·y′ + F_yy·(y′)²] / F_y
   = −[F_xx·F_y² − 2F_xF_yF_xy + F_x²·F_yy] / F_y³
   = [2F_xF_yF_xy − (F_y)²F_xx − (F_x)²F_yy] / (F_y)³     ✓ 与 6.53e 逐项一致
```

分子三项的符号与排列逐项核对**完全一致**。复算通过。

**6.53f**：以 D 再作用于 6.53d（即沿曲线 D³F = 0）：

```
D(F_xx)      = F_xxx + y′F_xxy
D(2F_xy y′)  = 2F_xxy y′ + 2F_xyy (y′)² + 2F_xy y″
D(F_yy y′²)  = F_xyy (y′)² + F_yyy (y′)³ + 2F_yy y′y″
D(F_y y″)    = F_xy y″ + F_yy y′y″ + F_y y‴
```

合并：F_xxx + **3**F_xxy y′ + **3**F_xyy (y′)² + F_yyy (y′)³ + **3**F_xy y″ + **3**F_yy y′y″ + F_y y‴ = 0，与 6.53f 逐项核对**完全一致**。✓ 复算通过。y′ 各幂次系数 (1, 3, 3, 1) 与 [[concepts/莱布尼茨公式]] 的二项式系数同源——此为结构观察，非原书表述。

## 归属与下游

- 式 6.53c 是本节唯一标明非零条件（F_y ≠ 0）的公式；6.53d–f 的成立同样要求 F_y ≠ 0（及相应高阶偏导存在），原书未逐一标明，见 [[queries/式6-54b是否应补Fu不等于0条件]]。
- 式 6.53e 仅属于"单方程一元隐函数"情形，不可移用于方程组情形。
- 下游综合：临界点 F_x = 0 处 6.53e 退化为 y″ = −F_xx/F_y，见 [[findings/临界点处式6-53e退化为负Fxx比Fy]]。
