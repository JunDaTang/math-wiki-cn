# 倒数幂的奇偶对称与趋近速度（式 2.50）

手册 2.4.6 给出 [[concepts/倒数幂]] y = a/xⁿ = ax⁻ⁿ（a ≠ 0，n 为正整数）的图像要素（直接证据）：

- **曲线类型**：双曲型曲线，两条坐标轴为 [[concepts/渐近线]]，间断点 x = 0；
- **符号行为**：a > 0 且 n 偶时函数恒正，值由 0 增至 +∞ 再减至趋于 0；a > 0 且 n 奇时值由 0 减至 −∞、跳跃到 +∞ 后减至趋于 0；a < 0 且 n 偶时恒负，值由 0 减至 −∞ 再增至趋于 0；a < 0 且 n 奇时值由 0 增至 +∞、跳跃到 −∞ 后增至趋于 0；
- **对称性**：n 为偶数时曲线关于 y 轴对称（[[concepts/偶函数]]）；n 为奇数时关于原点中心对称（[[concepts/奇函数]]）；
- **趋近速度**：n 越大，曲线趋近 x 轴的速度越快、趋近 y 轴的速度越慢（分别对 |x| > 1 与 |x| < 1 的区域成立）；
- **极值**：无。

手册附 a = 1 时 n = 2 与 n = 3 的对照图（图 2.21）。

**验证状态（独立分析）**：奇偶对称性与趋近速度结论经直接分析 x⁻ⁿ 的性质确认，无矛盾。趋近速度结论与 [[concepts/n次抛物线]] 的对偶解读见 [[comparisons/倒数幂与n次抛物线比较]]。
