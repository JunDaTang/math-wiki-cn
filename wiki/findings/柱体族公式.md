# 柱体族公式（式 3.137–3.147）

**直接证据**（源文 3.3.4(2)–(6)，图 3.65–3.69）。

**一般柱体**（封闭准线柱面 + 两平行平面截出的平行底；p 底周长，s、Q 垂直于母线的横截面周长与面积，l 母线长）：

$$V = A_G h = Q\,l \tag{3.137}$$
$$M = p\,h = s\,l \tag{3.138}$$

**直圆柱**（底为圆、母线垂直于圆面；R 底半径，转写中 R 脱落）：

$$V = \pi R^{2}h \tag{3.139}$$
$$M = 2\pi Rh \tag{3.140}$$
$$S = 2\pi R(R + h) \tag{3.141}$$

**斜截圆柱**（两端高 h₁、h₂）：

$$V = \pi R^{2}\,\frac{h_1 + h_2}{2} \tag{3.142}$$
$$M = \pi R(h_1 + h_2) \tag{3.143}$$
$$S = \pi R\left[h_1 + h_2 + R + \sqrt{R^{2} + \left(\frac{h_2 - h_1}{2}\right)^{2}}\right] \tag{3.144}$$

**柱段**（图 3.68 记号；α = φ/2 取弧度制）：

$$V = \frac{h}{3b}\left[a(3R^{2} - a^{2}) + 3R^{2}(b - R)\alpha\right] = \frac{hR^{3}}{b}\left(\sin\alpha - \frac{\sin^{3}\alpha}{3} - \alpha\cos\alpha\right) \tag{3.145}$$
$$M = \frac{2Rh}{b}\left[(b - R)\alpha + a\right] \tag{3.146}$$

其中当 b > R、φ > π 时公式仍成立。

**空心圆柱**（R 外半径、r 内半径、δ = R − r、ρ = (R+r)/2）：

$$V = \pi h(R^{2} - r^{2}) = \pi h\delta(2R - \delta) = \pi h\delta(2r + \delta) = 2\pi h\delta\rho \tag{3.147}$$

**独立核验（已复核）**：

- 3.147 四形式均为 R² − r² = (R−r)(R+r) 的改写：δ(2R−δ) = (R−r)(R+r) ✓、δ(2r+δ) = (R−r)(R+r) ✓、2πhδρ = πh(R−r)(R+r) ✓。
- 3.144 端点退化：h₁ = h₂ = h 时修正项化为 R，公式退化为 3.141 ✓。**归属警示**：√(R² + ((h₂−h₁)/2)²) 的椭圆底修正项**仅属斜截圆柱**，不可移植到直圆柱。
- 3.145 两形式恒等**反推记号绑定**：令 a = R sinα（半弦）、b = R(1 − cosα)（弓形矢高），则 a(3R²−a²) = R³sinα(3−sin²α)、3R²(b−R)α = −3R³αcosα，两形式逐项一致；且此时 b > R ⟺ cosα < 0 ⟺ φ = 2α > π，与源文「当 b > R、φ > π 时公式仍成立」的条件自洽。
- 3.145 几何模型重推：柱段为以弓形（半弦 a、矢高 b）为底、上方被一张过底弦、在弓形顶点处高达 h 的斜平面所截的立体（蹄形）；对此模型积分得 V = (h/b)∬y dA = hR³/b(sinα − sin³α/3 − αcosα)，与源文第二形式一致 ✓。

**记号绑定缺口**：a、b、φ 与图 3.68 的对应因正文符号脱落而不完整，上述绑定系由公式内部一致性反推，引用前宜据图或原书确认（[[queries/3-3全节符号成片脱落是否为转写丢字]]）。
