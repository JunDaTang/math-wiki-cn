# 式 15.33–15.38 δ函数近似与性质转录复算

对《数学手册(原书第10版)》15.2.1.4 的 δ 函数近似族与五条性质转录并复算。

## 近似族复算（式 15.33a–c 与共性 15.34a–c）

| 近似 | 归一性复算 | 偶性 | 极限集中 |
|---|---|---|---|
| 矩形脉冲 $1/\varepsilon$ 于 $|t|<\varepsilon/2$ | $\int_{-\varepsilon/2}^{\varepsilon/2}\frac{dt}{\varepsilon}=1$ ✓ | ✓ | ✓ |
| 高斯（误差曲线）$\frac{1}{\varepsilon\sqrt{2\pi}}e^{-t^2/2\varepsilon^2}$ | $\int=1$ ✓ | ✓ | ✓ |
| 洛伦兹函数 $\frac{\varepsilon/\pi}{t^2+\varepsilon^2}$ | $\int\frac{\varepsilon/\pi}{t^2+\varepsilon^2}dt=\frac\varepsilon\pi\cdot\frac\pi\varepsilon=1$ ✓ | ✓ | ✓ |

三共性 (15.34a–c)（归一、偶、$\varepsilon\to0$ 时极限集中）对三者均验证成立。比较讨论见 [[comparisons/δ函数三种近似比较]]。

## 五条性质复算（式 15.35–15.38b）

1. 筛选（区间形式）(15.35) ✓；2. 缩放 (15.36) ✓——**限定 $\alpha>0$，故右端无绝对值，不是讹误**；3. 复合 (15.37) ✓（单根条件与 $|g'(x_i)|$ 分母为标准结果）；4. 作用导数 (15.38a) ✓；5. δ 导数法则 (15.38b) $(−1)^n f^{(n)}(x)=\int f(t)\delta^{(n)}(x-t)dt$ ✓（分部积分 $n$ 次的符号与标准分布理论一致）。

## 理论主张（归属分布框架）

源书自我声明：$u(t)$ 不连续、$\delta(t)$ 不可经典定义的困难由施瓦兹的连续实线性泛函（分布）解决。该论证成立且与例题方法自洽，但依赖未入库的 12.9.5（第 911–912 页）；对 2.6.3（误差曲线）、2.11.2（洛伦兹函数）、7.4（周期分布与傅里叶级数）的回指亦未入库，见 [[queries/15-2-1未入库回指缺口]]。
