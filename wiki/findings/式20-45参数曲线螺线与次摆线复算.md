# 式 20.45 参数曲线螺线与次摆线复算

## 命令签名与转录（原样）

```mathematica
ParametricPlot[{fx(t), fy(t)}, {t, t1, t2}]                       (20.45)
In[1] := ParametricPlot[{t   Cos[t], t   Sin[t]}, {t, 0, 3 Pi}, AspectRatio->Automatic]
In[2] := ParametricPlot[{Exp[0.1 t] Cos[t], Exp[0.1 t] Sin[t]}, {t, 0, 3 Pi},
         AspectRatio->Automatic]
In[3] := ParametricPlot[{t - 2 Sin[t], 1 - 2 Cos[t]}, {t, -Pi, 11 Pi}, AspectRatio -> 0.3]
```

## 复算结论

- **In[1] 阿基米德螺线**（r = t 型，t∈[0,3π]，回指第 136 页 2.14.1）：有效；`AspectRatio->Automatic` 令螺线以自然（不变形）形态显示（图 20.6a）。
- **In[2] 对数螺线**（r = e^{0.1t} 型，t∈[0,3π]，回指第 137 页 2.14.3）：有效（图 20.6b）。
- **In[3] 次摆线**（{t−2Sin[t], 1−2Cos[t]}，t∈[−π,11π]，回指第 132 页 2.13.2）：有效；此处显式取 `AspectRatio -> 0.3` 压扁纵横比，与 In[1]/In[2] 的 Automatic 形成对照，说明选项应按曲线形态取舍（图 20.7）。

## 校勘

- 原文选项转写作 `AspectRatio_lutomatic_1`，系 `AspectRatio->Automatic` 之讹（下划线与 `1` 为 `->` 及代码字体的转写残迹）。
- In[1] 之「t   Cos[t]」多空格：Mathematica 中空格即乘法（相邻因子相乘），故未必是脱乘号之讹，但转录宜规范化为 `t Cos[t]` 或 `t*Cos[t]`。
- 「类似千 2D 图形」（千→于）、「巾参数表示」（巾→由）等同节系统性讹误见 [[20-4全节系统性转写讹误清单]]。

## 证据强度

三条算例代码完整、无破坏语法的讹误，属可逐条复算的强证据；所引手册前部章节（2.13.2、2.14.1、2.14.3）未入库，数学对象的定义细节暂无法对勘（[[20-4未入库回指缺口]]）。
