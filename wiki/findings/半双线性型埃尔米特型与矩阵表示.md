# 半双线性型—埃尔米特型与矩阵表示（式 5.212–5.213，含脱星疑点）

## 陈述（5.3.8.6.3）

映射 $f:V\times V\to\mathbb{C}$ 称为半双线性型，如果对每个 $u,u',v,v'\in V$ 和每个 $k\in\mathbb{C}$：

```latex
f(u+u', v) = f(u,v) + f(u',v)     f(ku, v) = k f(u,v)
f(u, v+v') = f(u,v) + f(u,v')     f(u, kv) = k* f(u,v)     % 5.212
```

其中 $k^*$ 表示 $k$ 的复共轭（原文讹作「共辄」）；即对第一个自变量线性、对第二个自变量「半线性」。**埃尔米特**条件：$f(v,v')=f(v',v)^*$（对所有 $v,v'$）。于是（酉）点积可通过**埃尔米特正定半双线性型**刻画；$\mathbb{C}^n$ 中标准酉点积定义为 $f(u,v)=u^{\mathrm T}v^*$。有限维时表示矩阵 $A_B(f)=(f(b_i,b_j))_{i,j}$，且

```latex
f(v, v') = v^T A_B(f) v'      % 5.213（疑脱落 v' 的共轭星号）
```

表示矩阵是埃尔米特的，当且仅当半双线性型是埃尔米特的。概念的出处原书指认为文献 [5.6]。

## 讹误标注（关键）

式 (5.213) 与式 (5.212) 矛盾：按「第二自变量半线性」，矩阵形式应为 $f(v,v')=v^{\mathrm T}A_B(f)\,v'^{*}$；原文脱星后退化为双线性形式（式 5.211）。见 [[queries/式5-213是否脱落共轭星号]]。在复原前，式 (5.213) 不应作为定义引用。

## 一致性核验（推断，非原文逐句）

按本手册约定检验标准酉点积 $f(u,v)=u^{\mathrm T}v^*$：$f(ku,v)=k\,u^{\mathrm T}v^*=kf(u,v)$（第一变量线性 ✓）；$f(u,kv)=u^{\mathrm T}(kv)^*=k^*u^{\mathrm T}v^*=k^*f(u,v)$（第二变量半线性 ✓）；$f(v,v)=v^{\mathrm T}v^*=\sum|v_i|^2\in\mathbb{R}_{\ge0}$，正定性可定义 ✓。可见标准例与式 (5.212) 自洽，进一步支持式 (5.213) 脱星之说。
