# 克罗内克积公式与算例（式 4.41–4.43，已复算）

## 定义（4.41）

$(m,n)$ 型矩阵 $A=(a_{\mu\nu})$ 与 $(p,r)$ 型矩阵 $B=(b_{\mu\nu})$ 的克罗内克积：

$$A\otimes B=(a_{\mu\nu}B),$$

以 $A$ 的每个元素乘整个矩阵 $B$ 并按原位置排布，得 $(m\cdot p,\ n\cdot r)$ 型新矩阵。

## 公式（4.42–4.43）

$$(A\otimes B)^{\mathrm T}=A^{\mathrm T}\otimes B^{\mathrm T},\qquad \operatorname{Tr}(A\otimes B)=\operatorname{Tr}(A)\cdot\operatorname{Tr}(B).$$

## 已复算算例

$A=\begin{pmatrix}3&-5&0\\2&1&3\end{pmatrix}$（(2,3) 型），$B=\begin{pmatrix}1&3\\2&-1\end{pmatrix}$（(2,2) 型）：

```text
A⊗B = ( 3·B  −5·B   0·B )   = (  3   9  −5 −15   0   0 )
      ( 2·B   1·B  3·B )     (  6  −3 −10   5   0   0 )
                             (  2   6   1   3   3   9 )
                             (  4  −2   2  −1   6  −3 )   → (4,6) 型
```

逐块复算（$3B$、$-5B$、$0B$、$2B$、$1B$、$3B$ 共六块）全部正确；转置与迹公式亦直证通过。
