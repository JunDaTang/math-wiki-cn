# 手册以 p²/4 − q < 0 判定二次因式无实分解

## 判据内容

《数学手册(原书第10版)》以判别条件

$$
\frac{p^{2}}{4} - q < 0 \qquad \left(\text{即 } \left(\frac{p}{2}\right)^{2} - q < 0\right)
$$

判定二次因式 $x^{2} + px + q$ 无实（一次）分解。该条件等价于常用判别式 $p^{2} - 4q < 0$（对应求根公式根号内为负），故该二次式无实根、在实数域上不可约（不可再分解为实因子）。此判据首见于 1.1.6 的 [[因式分解]] 内容，用于区分二次式"可分解为实一次因式"与"不可再分"两种情形。

## 1.1.6 中的判定应用（方法 C 例题）

在 1.1.6.2 方法 C（利用方程根的性质做 [[因式分解]]，对照见 [[因式分解方法比较]]）的例题中，手册以判别条件 $\frac{p^{2}}{4} - q < 0$（二次因式形如 $x^{2} + px + q$，例中 $p = -2,\ q = 5$）断定商 $x^{2} - 2x + 5$ 不能再分解为实因子，从而终止分解并给出最终分解式：

$$
x^{6} - 2x^{5} + 4x^{4} + 2x^{3} - 5x^{2} = x^{2}(x - 1)(x + 1)(x^{2} - 2x + 5).
$$

例中 $p = -2,\ q = 5$：$\frac{4}{4} - 5 = -4 < 0$，判定成立。

## 1.1.7 中的应用（部分分式分解的前提条件）

同一条件在 1.1.7"有理式"一节中两度出现，成为 [[部分分式分解]] 理论的组成部分：

- **式 (1.44b)**：最简分式的第二种基本形态 $\frac{Dx+E}{(x^{2}+px+q)^{m}}$ 以 $\left(\frac{p}{2}\right)^{2}-q<0$ 为前提，保证分母二次因式无实根。
- **式 (1.47)**：分母 $Q(x)$ 分解中的每个二次因式 $x^{2}+p_{i}x+q_{i}$（对应 $r$ 对共轭复根）均满足 $\left(\frac{p_{i}}{2}\right)^{2}-q_{i}<0$（$p_{i},q_{i}$ 为实数）。

也就是说，在部分分式分解的第三种情况（分母含复根）中，该判别条件刻画了哪些因式只能以二次因式幂的身份进入分母，从而贡献 $\frac{Cx+D}{(x^{2}+px+q)^{m}}$ 型最简分式。

## 证据与验证

- **直接证据**：手册 1.1.6 例题原文；1.1.7 的 (1.44b)、(1.47) 式亦为手册直接陈述。该条件在 1.1.6（判定用途）与 1.1.7（(1.44b)、(1.47) 的前提条件）中被一致使用。
- **独立验算**：stage-1 分析独立验算，方法 C 例题右端乘积展开与左端一致。
- **推理验证**（非手册原文）：条件 $\frac{p^{2}}{4} - q < 0$ 等价于判别式 $p^{2} - 4q < 0$（即 $\left(\frac{p}{2}\right)^{2} - q < 0$，对应求根公式根号内为负），故二次式无实根，在实数范围内不可再分解。
- **待核验**：(1.168) 式对该分解的支撑关系待核验，见 [[式1-168二次因式分解内容]]。

## 归属与适用范围

- 在 1.1.6 中，该判据属于方法 C 的终止条件，服务于多项式的实因式分解；不涉及复数域上的分解。
- 在 1.1.7 中，该判据转而作为部分分式分解理论的前提条件，刻画分母中对应共轭复根、只能以二次因式幂出现的因式。
