# 函数项级数的定义组（式 7.74–7.78，逐字转录）

《数学手册（原书第10版）》7.3.1 以五条定义引入函数项级数的基本框架：级数本身、部分和、收敛域、和、余项。以下为逐字转录（变量符号 x 在转写中大面积脱落，此处按上下文补全）：

```latex
f_1(x) + f_2(x) + \dots + f_n(x) + \dots = \sum_{n=1}^{\infty} f_n(x)                       % (7.74) 函数项级数
S_n(x) = f_1(x) + f_2(x) + \dots + f_n(x) = \sum_{k=1}^{n} f_k(x)                            % (7.75) 部分和（前 n 项）
f_1(a) + f_2(a) + \dots + f_n(a) + \dots = \sum_{n=1}^{\infty} f_n(a)                        % (7.76) x=a 处的常数值级数
\lim_{n\to\infty} S_n(a) = \lim_{n\to\infty} \sum_{k=1}^{n} f_k(a) = S(a)                    % (7.77) 收敛判据
R_n(x) = S(x) - S_n(x) = f_{n+1}(x) + f_{n+2}(x) + \dots + f_{n+m}(x) + \dots                % (7.78) 余项
```

## 判读

- 定义性内容，无需证明；证据强度为定义性。
- (7.75) 明确 S_n 为「前 n 项和」——但 7.3.2.1 的两个算例（式 7.79b、7.80c）实际采用「含至指数 n 项」（共 n+1 项）的约定，两套约定混用相差一，见 [[式7-80c余项指数差一与Sn指标约定]]。
- (7.78) 末尾的「f_{n+m}(x)」按求和意义应为「⋯」或 f_{n+m} → ∞ 的省略写法，属转写之讹（原书应为省略号）。
- 概念归属：[[函数项级数]]；收敛域上极限行为引出 [[一致收敛]]。
