# 任意角化简的完整规则体系与算例（式 2.72–2.81、表 2.4）

## 手册主张

任意角 x 的三角函数值按四步化简为锐角：

1. **周期化简**（$x > 360^\circ$ 或 $x > 180^\circ$，n 为整数）：

$$\sin(360^\circ n + \alpha) = \sin\alpha,\qquad \cos(360^\circ n + \alpha) = \cos\alpha \tag{2.72--2.73}$$
$$\tan(180^\circ n + \alpha) = \tan\alpha,\qquad \cot(180^\circ n + \alpha) = \cot\alpha \tag{2.74--2.75}$$

2. **负角**：

$$\sin(-\alpha) = -\sin\alpha,\quad \cos(-\alpha) = \cos\alpha,\quad \tan(-\alpha) = -\tan\alpha,\quad \cot(-\alpha) = -\cot\alpha \tag{2.76--2.79}$$

3. **象限关系**（$90^\circ < x < 360^\circ$）：用表 2.4 把角化为锐角 α；相差 90°、180°、270° 的角之间函数值的关系称为象限关系（表 2.4 覆盖 $x = 90^\circ \pm \alpha$、$180^\circ \pm \alpha$、$270^\circ \pm \alpha$、$360^\circ - \alpha$ 四列，完整表格见源页）。

4. **余角与补角公式**：

$$\cos\alpha = \sin x = \sin(90^\circ - \alpha),\qquad \sin\alpha = \cos x = \cos(90^\circ - \alpha) \tag{2.80a--b}$$
$$\sin\alpha = \sin x = \sin(180^\circ - \alpha),\qquad -\cos\alpha = \cos x = \cos(180^\circ - \alpha) \tag{2.81a--b}$$

锐角（$0^\circ < x < 90^\circ$）的函数值查表 2.3，「当今常用计算机计算」。

## 算例（源文）

$$\sin(-1000^\circ) = -\sin 1000^\circ = -\sin(360^\circ\cdot 2 + 280^\circ) = -\sin 280^\circ = +\cos 10^\circ = +0.9848$$

## 独立验证

表 2.4 全部 16 格逐格抽验成立；算例复核：$1000^\circ = 720^\circ + 280^\circ$，$\sin 280^\circ = \sin(270^\circ + 10^\circ) = -\cos 10^\circ$，故 $-\sin 280^\circ = +\cos 10^\circ \approx 0.9848$。✓ 验证通过。
