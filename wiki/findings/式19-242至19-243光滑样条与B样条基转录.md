# 式 19.242–19.243 光滑样条与 B 样条基转录

对 19.7.1.2 两条公式 (19.242)(19.243) 的逐字转录，并作逻辑核对；解法细节原书外推至未具名文献，无法复算。

## 逐字转录

```latex
(19.242)  Σ_{i=1}^{N} [ (f_i − S(x_i)) / σ_i ]² + λ ∫_{x_1}^{x_N} [S''(x)]² dx = min!
          λ > 0 为事先给定的光滑参数；λ = 0 → 三次插值样条；λ 很大 → 光滑的近似曲线，
          但回到测量值不准确；λ = ∞ → 逼近回归线；
          σ_i > 0 为 f_i (i = 1,…,N) 测量误差的标准差（回指第 1109 页 16.4.1.3,2.）
          ——求解：带方程形式条件的约束最优化，使用拉格朗日函数（回指第 611 页 6.2.5.6），
          详情见 [19.34], [19.35]

(19.243)  S(x) = Σ_{i=1}^{r+2} a_i N_{i,4}(x)
          r 为自由选取节点的个数；N_{i,4} 为 4 阶正规化 B 样条（基样条），
          即关于第 i 个节点的三次多项式；详情见 [19.8], [19.6]
```

## 逻辑核对（区分直接证据与推断）

- **λ = 0 退化**（直接推论）：罚项消失，若插值可行则目标可取最小值 0，最小解即三次插值样条——与原书陈述一致。
- **λ → ∞ 极限**（推断）：迫使 ∫[S″]²dx → 0，即 S″ ≡ 0，S 退化为线性函数，对应加权最小二乘直线；原书措辞「当 λ = ∞ 时结果是逼近回归线」为极限陈述，偏松。
- **σ_i 的作用**：测量误差标准差充当数据权（误差大者权重低），与 [[concepts/权函数与加权内积]] 的加权思想同构。
- **(19.243) 的 r+2 计数**：无法自源内核验；按标准 B 样条理论，r 个内部单节点的三次样条空间维数为 r+4，r+2 仅当 r 计入两端节点时自洽——见 [[queries/式19-243之r加2与三次B样条基个数之辨]]。

## 转写讹误记录

- 「当入很大时」「可适当选取入」：「入」为「λ」之讹（两处）；
- 「对大的 ，该方法」脱 N；「由千在许多实际应用中」之「千」为「于」；
- 「这里 表示自由选取的节点的个数」脱 r；「所谓 阶正规化 样条」脱「4」「B」；「关千第 个节点」脱 i 且「千」为「于」。

## 证据状态

公式转录本身可靠；但光滑样条的求解（约束最优化、拉格朗日函数）与 B 样条细节完全外推至 [19.34][19.35][19.8][19.6]，本源自含证据弱，故置信度记为中等、复算状态记为未知。
