# t 与 s 范数的公理组及 min/max 上下界

《数学手册(原书第10版)》5.9.2.1 以两组对偶公理定义 [[concepts/t-范数]] 与 [[concepts/s-范数]]，并断言 min/max 分别是两类的上/下界。

## 直接证据（源文照录）

```text
t 范数：t: [0,1] × [0,1] → [0,1]                                      (5.346)
(E1) 交换性   t(x,y) = t(y,x)                                         (5.347a)
(E2) 结合性   t(x, t(y,z)) = t(t(x,y), z)                             (5.347b)
(E3) 中性元/零元  t(x,1) = t(1,x) = x；t(x,0) = t(0,x) = 0             (5.347c)
(E4) 单调性   x ≤ v 且 y ≤ w ⇒ t(x,y) ≤ t(v,w)                        (5.347d)

s 范数：s: [0,1] × [0,1] → [0,1]                                      (5.348)
(E1) 交换性   s(x,y) = s(y,x)                                         (5.349a)
(E2) 结合性   s(x, s(y,z)) = s(s(x,y), z)                             (5.349b)
(E3) 中性元/零元  s(x,0) = s(0,x) = x；s(x,1) = s(1,x) = 1             (5.349c)
(E4) 单调性   x ≤ v 且 y ≤ w ⇒ s(x,y) ≤ s(v,w)                        (5.349d)

min{x,y} ≥ t(x,y)，∀t∈T，∀x,y∈[0,1]                                 (5.349e)
max{x,y} ≤ s(x,y)，∀s∈S，∀x,y∈[0,1]                                 (5.349f)
```

## 断言与独立验证

- 上下界断言（式 5.349e–f）在源文中**未给证明**。独立推导（推断，非源文内容）：由 (E3) 与 (E4)，t(x,y) ≤ t(x,1) = x 且 t(x,y) ≤ t(1,y) = y，故 t(x,y) ≤ min{x,y}；对偶地 s(x,y) ≥ max{x,y}。故该断言为标准结果。
- 公理组本身为约定性定义，无需复现。

## 转写注

- 5.9.2.1 两处小节标题「范数的定义」均脱落 t/s 字母；正文「它以 作为零元素，以 作为中性元素」脱落 0 与 1，由 (E3) 复原：t 范数以 0 为零元素、1 为中性元素（s 范数反之）。
- 残句「函数 称作 范数和 余范数；后者也称为 范数」脱落 t/s，疑应为「函数 t 称作 t 范数，s 称作 t 余范数；后者也称为 s 范数」（与通行术语一致）。
