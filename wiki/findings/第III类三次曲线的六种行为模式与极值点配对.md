# 第III类三次曲线的六种行为模式与极值点配对（式 2.49，± 同号配对已验证）

手册 2.4.5 给出 [[concepts/第III类三次曲线]] y = x/(ax² + bx + c)（a、b、c ≠ 0）的图像要素（直接证据）：图像过原点，x 轴为 [[concepts/渐近线]]；性状除 a 与 Δ = 4ac − b² 外，Δ = 0 时还与 b 的符号有关、Δ < 0 时还与方程 ax² + bx + c = 0 的根 α, β 的符号有关；a < 0 经沿 x 轴反射化为 a > 0。共 6 种行为模式：

| 情形 | 条件 | 行为要点 | 极值点 | 拐点 |
|---|---|---|---|---|
| a) | Δ > 0 | 处处连续；值由 0 减到极小、增到极大、再减到 0 | A, B = (±√(c/a), (−b ± 2√(ac))/Δ) | 三个 |
| b₁) | Δ = 0, b > 0 | 间断点 x = −b/(2a)（二重极点，两侧均 → −∞）；值由 0 减到 −∞，过间断点后由 −∞ 增至极大值再减到 0 | A(√(c/a), 1/(2√(ac)+b)) | 一个 |
| b₂) | Δ = 0, b < 0 | 值由 0 减到极小值，经原点增至 +∞；过间断点 x = −b/(2a)（二重极点，两侧均 → +∞）后由 +∞ 减到 0 | A(−√(c/a), −1/(2√(ac)−b)) | 一个 |
| c₁) | Δ < 0, αβ 异号 | 两个一重间断点 x = α, β；曲线过原点 | 无极值 | 一个 |
| c₂) | Δ < 0, α、β 均负 | 两个一重间断点；α、β 之间一极小，β 右侧一极大 | 用情形 a) 公式 | 一个 |
| c₃) | Δ < 0, α、β 均正 | 两个一重间断点；α 左侧一极小，α、β 之间一极大 | 用情形 a) 公式 | 一个 |

**验证状态（独立重推导）**：

- 极值点公式 (±√(c/a), (−b ± 2√(ac))/Δ) 经一般推导验证，且**双重 ± 应同号配对**（+√(c/a) ↔ −b + 2√(ac)），源文未明示配对方向；
- 情形 b 的两个特殊极值点公式均验证等于 1/(2b)（利用 Δ = 0 即 4ac = b² 化简）；
- 「三个拐点」（Δ > 0）经证明恒成立：拐点方程的三次项判别式 = (27c²/a⁴)·Δ > 0；
- 「一个拐点」（Δ ≤ 0 各情形）经数值例确认。

**口径注意**：源文情形 c) 两处写「与 2.4.5 中的情形 a) 类似的公式」，属节内自引（公式确来自本节情形 a)），措辞怪异但不影响实质。± 配对方向未明示的转写模式与 [[queries/三次极值点横坐标公式的负号位置是否转写有误]] 类似。
