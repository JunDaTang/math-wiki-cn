# 渐近分数的递推公式与误差估计

《数学手册(原书第10版)》1.1.1.4, 3. 给出：若 α = [a₀; a₁, a₂, …] 是任一实数，则每个有限连分数 αₖ = [a₀; …; aₖ] = p/q 表示 α 的一个逼近（k 阶逼近），它满足递推公式 (1.5) 与误差估计 (1.6)：

```latex
(1.5)  \alpha_{k} = \frac{p_{k}}{q_{k}} = \frac{a_{k}p_{k-1} + p_{k-2}}{a_{k}q_{k-1} + q_{k-2}}
       (k \geqslant 1; p_{-1} = 1, p_{0} = a_{0}; q_{-1} = 0, q_{0} = 1)
(1.6)  |\alpha - \alpha_{k}| = \left|\alpha - \frac{p_{k}}{q_{k}}\right| < \frac{1}{q_{k}^{2}}
```

手册进一步指出：近似式以渐增的精度**上下交替**地逼近 α；当 aᵢ 具有大数值时迅速收敛（见 [[findings/连分数部分商全为1时收敛最慢]]）。

- **归属存疑**：手册将 (1.6) 归于“刘维尔逼近定理”；通常文献中 |α−pₖ/qₖ| < 1/qₖ² 是渐近分数的基本性质，而刘维尔定理给出的是代数数逼近的**下界**，方向相反。跟踪于 [[queries/刘维尔逼近定理归属是否准确]]。
- **复核**：以 π 的渐近分数 22/7、333/106、355/113 验证，误差均满足上界且实际更小（见 [[findings/π的渐近分数优于同位数小数]]）。
