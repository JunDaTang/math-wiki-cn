# 式 15.143–15.148 信号与小波定义容许条件转录复算

**范围**：15.5.1 信号定义与傅里叶对 (15.143a/b)、哈尔小波 (15.144)、墨西哥草帽小波 (15.145)–(15.146)、容许性积分 (15.147)、均值零 (15.148)。逐字转录见 source 页结构化数据块。

## 复算

1. **(15.143a/b)**：与 15.3 的指数型傅里叶变换约定一致（正变换无前置因子、逆变换 1/2π），构成分析–合成对。✓
2. **(15.144)**：分段定义中自变量 x 与 t 混用（第一段用 x、第二三段用 t），系转写不一致；以 t 统一读之数学内容自洽。△
3. **(15.145)→(15.146)**：$-\frac{\mathrm{d}^2}{\mathrm{d}x^2}e^{-x^2/2} = \frac{\mathrm{d}}{\mathrm{d}x}\big(x e^{-x^2/2}\big) = (1 - x^2)e^{-x^2/2}$。✓
4. **哈尔均值**：$\int_0^{1/2} 1\,\mathrm{d}t - \int_{1/2}^1 1\,\mathrm{d}t = \tfrac12 - \tfrac12 = 0$，满足 (15.148)。✓
5. **墨西哥草帽均值**：$\int (1-x^2)e^{-x^2/2}\,\mathrm{d}x = \sqrt{2\pi}\,(1-1) = 0$（偶函数矩关系 $\int x^2 e^{-x^2/2}dx = \sqrt{2\pi}$）。✓
6. **(15.147)**：源式为 $|\Psi(\omega)|/|\omega|$ 一次幂；标准容许性条件为平方版 $C_\psi = \int |\Psi(\omega)|^2/|\omega|\,\mathrm{d}\omega < \infty$。一次幂版本与 (15.152b) 重建常数难以自洽，疑 OCR 丢上标。⚠ 待核，见 [[queries/式15-147容许条件Ψ模一次幂疑为平方]]。

## 结论

定义类公式转录基本可靠，(15.145)–(15.146) 导数展开、哈尔与墨西哥草帽的均值条件均经独立复算成立；唯 (15.147) 的幂次存疑（高置信的转录结论 + 一处待核数学疑点）。
