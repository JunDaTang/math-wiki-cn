# 齐次方程组基本解系与算例 E（式 4.179–4.181，已复算）

理论（4.5.2.1 (2)）：齐次方程组 A x = 0 总有平凡解（式 4.179a）；非平凡解的任何线性组合仍是解；若系数矩阵的秩 r < n，则恰有 l = n − r 个线性无关非平凡解，构成解的基本系，一般解为 x = k₁α₁ + … + k_l α_l（式 4.179b）。构造法：选取 n − r 个未知数作自由参数并以它们表示其余未知数（式 4.180），依次令一个自由参数为 1、其余为 0（式 4.181）。

算例 E（4 方程、4 未知数，方程组见 [[sources/10-数学手册原书第10版--8-45-线性方程组--1smy1k4]]）：rank(A) = 2，解出

```
x₁ = −(3/2)x₃ − x₄,   x₂ = (7/2)x₃ − 2x₄   （x₃, x₄ 任意）
```

基本解为

```
α₁ = (−3/2, 7/2, 1, 0)ᵀ,   α₂ = (−1, −2, 0, 1)ᵀ
```

## 核验

将 α₁、α₂ 分别代入全部四个方程，左边均为零（如第 3 式对 α₁：3·(−3/2) − 7/2 + 8·1 = 0，对 α₂：3·(−1) − (−2) + 0 + 1 = 0；第 4 式对 α₂：−1 + 3·(−2) − 0 + 7·1 = 0），复算通过。属直接证据且已复算。
