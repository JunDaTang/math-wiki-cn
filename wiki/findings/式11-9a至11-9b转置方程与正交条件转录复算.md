# 式 11.9a–11.9b 转置方程与正交条件转录复算

**结论**：(11.9a)、(11.9b) 转录正确；正交条件的退化核推导经独立复算吻合；"转置方程共享本征值"在退化核情形可补全证明；条件对一般核的推广为本节未证的引用性断言。

## 逐字转录

```latex
% (11.9a) 转置积分方程（复情形：伴随积分方程）
\psi(x) = g(x) + \lambda \int_a^b K(y,x)\,\psi(y)\,\mathrm{d}y

% (11.9b)
\int_a^b \varphi(x)\psi(x)\,\mathrm{d}x
= \int_a^b f(x)\psi(x)\,\mathrm{d}x
+ \int_a^b \Bigl(\lambda\int_a^b K(x,y)\psi(x)\,\mathrm{d}x\Bigr)\varphi(y)\,\mathrm{d}y

% 齐次伴随方程与结论
\psi(y) = \lambda\int_a^b K(x,y)\psi(x)\,\mathrm{d}x
\;\Longrightarrow\; \int_a^b f(x)\psi(x)\,\mathrm{d}x = 0
```

## 独立复算

- **正交条件推导**：以 $\psi(x)$ 乘 (11.4a) 两端并在 $[a,b]$ 上积分得 (11.9b)；代入齐次伴随方程后，右端末项化为 $\int\psi(y)\varphi(y)\,\mathrm{d}y$，与左端相消，得 $\int f\psi=0$。逐步吻合。
- **共享本征值（补全证明）**：文中称"容易证明"而未证。退化核情形：转置方程对应的系数 $c'_{kj}=\int\alpha_k(x)\beta_j(x)\,\mathrm{d}x=c_{jk}$，即原系数矩阵的转置；由 $\det(c_{jk})=\det(c_{kj})$（转置矩阵行列式不变）得 $D'(\lambda)=D(\lambda)$，故 $\lambda$ 为原方程本征值 $\iff$ 为转置方程本征值。
- **陈述定位**：本征值处（非齐次）方程可解 $\iff$ $f$ 与齐次伴随方程属于同一 $\lambda$ 的每个非零解正交。

## 开放疑点

第 4 小节两处"齐次积分方程"疑为"非齐次"之误（开头问句与末尾陈述），但同句"齐次伴随积分方程"的"齐次"正确、不可一并改；详见 [[queries/转置方程段两处齐次是否应为非齐次]]。本页按"非齐次"意图转录复算。

## 证据强度分层

- 退化核情形的推导与共享本征值的补全：直接复算 — 高。
- **对一般核的推广**（"这个陈述不仅对于具有退化核的积分方程成立，而且对于具有一般核的积分方程也成立"）：引用性断言，本节未证 — 中。
