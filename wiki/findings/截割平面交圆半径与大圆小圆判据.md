# 截割平面交圆半径与大圆、小圆、切平面判据（式 3.174）

球面上重要的球面曲线（大圆和小圆）是穿过球的平面（截割平面）截出的相交圆。若半径为 R 的球被与球心 M 距离为 h 的平面 Γ 所截，则相交圆的半径满足

$$
r = \sqrt{R^{2} - h^{2}}, \quad 0 \leqslant h \leqslant R. \tag{3.174}
$$

三种情形（判据）：

| h | 相交圆 | 说明 |
|---|---|---|
| h = 0 | 大圆 | 截割平面穿过球心，r 取最大可能的值 R |
| 0 < h < R | 小圆 | 例如地球上的平行纬线 |
| h = R | 切平面 | 平面 Γ 与球只有一个公共点 |

在地球上，赤道和子午线及其相对子午线（它们是子午线关于地球自转轴的反射）表示大圆；平行的纬线是小圆。

**证据类型**：参考手册的定理性陈述（直接证据）。式 3.174 可由「球心—垂足—交点」直角三角形按[[勾股定理]]直接得出，属平凡推导而非独立复算，故 replicated 记为 null。

**转写存疑**：原文「如果半径为 的球被与球心 距离为 的平面 所截」中 R、M、h、Γ 均脱落（见 [[球面几何节行内符号系统性脱落是否为转写丢字]]）。
