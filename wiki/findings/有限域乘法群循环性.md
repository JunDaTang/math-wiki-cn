# 有限域乘法群的循环性

数学手册 5.3.7.4.1（6）断言：有限域 $K$ 的乘法群 $K^* = K \setminus \{0\}$ 是**循环的**，即存在元素 $a \in K$ 使得 $K^*$ 的每个元素都是 $a$ 的幂：

$$K^* = \{1, a, a^2, \cdots, a^{q-1}\} \quad (\text{若 } K \text{ 有 } q \text{ 个元素}).$$

（源文集合若如字面所列含 $1, a, \ldots, a^{q-1}$ 共 q 个元素，与 $|K^*| = q - 1$ 矛盾，末项上标疑应为 $q - 2$，见 [[queries/乘法群循环式末项上标是否应为q-2]]。）

## 与本原多项式的联系

源文随即定义：不可约多项式 $f(x) \in K[x]$ 称为**本原的**，如果 $x$ 的幂表示 $L := K[x]/f(x)$ 的所有非零元素，即 $L$ 的乘法群 $L^*$ 可由 $x$ 生成。因此本原多项式的概念完全建立在乘法群循环性之上：$L^*$ 循环保证生成元存在，而 $f$ 本原 ⟺ 剩余类 $x$ 恰是这样一个生成元。详见 [[concepts/本原多项式]]。

## 实例验证

✓ 在 GF(2³) $= \mathbb{Z}_2[x]/(1+x+x^3)$ 中，$x$ 的幂 $1, x, x^2, \ldots, x^6$ 恰好遍历全部 7 个非零元（对数表逐行验证，见 [[findings/gf23对数表与分式算例]]），即 $K^* = \langle x \rangle$，循环性在该实例中成立，且 $f = 1 + x + x^3$ 本原。

## 意义

循环性使有限域乘法可化为「对数模 $p^n - 1$ 的加法」，是对数表（[[methodology/由对数表执行gf运算流程]]）与 LFSR 极大周期判据（[[findings/lfsr状态转移与极大周期判据]]）的理论基础。循环群的一般概念见 [[concepts/循环群与生成子群]]；载体实体页：[[entities/伽罗瓦域gf-pn]]。
