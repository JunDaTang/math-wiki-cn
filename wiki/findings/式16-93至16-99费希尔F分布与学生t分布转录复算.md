# 式 16.93–16.99 费希尔 F 分布与学生 t 分布转录复算

对 [[10-数学手册原书第10版--9-1624-连续分布--1ktbozm]] 16.2.4.7–16.2.4.8 的编号公式逐字转录并手工复算。结论：(16.93)、(16.94a)、(16.96)–(16.99) 与标准结果一致；(16.94b) 被积函数疑含衍文「− 1」；(16.95a,b) 疑脱适用条件。

## 费希尔 F 分布（16.2.4.7）

```
(16.93)   F_{m₁,m₂} = (X₁/m₁)/(X₂/m₂)   （X₁、X₂ 独立，分别服从自由度 m₁、m₂ 的 χ² 分布）
(16.94a)  f_F(t) = (m₁/2)^{m₁/2}·(m₂/2)^{m₂/2}·Γ((m₁+m₂)/2)/[Γ(m₁/2)·Γ(m₂/2)]
                 ·t^{m₁/2−1}/((m₁/2)·t + (m₂/2))^{(m₁+m₂)/2}   (t > 0；t ⩽ 0 时为 0)
(16.94b)  F_F(x) = 同上常数 · ∫_{0}^{x} (t^{m₁/2−1} − 1)·dt/((m₁/2)·t + (m₂/2))^{(m₁+m₂)/2}   (x > 0)
(16.95a)  E(F_{m₁,m₂}) = m₂/(m₂−2)
(16.95b)  D²(F_{m₁,m₂}) = 2·m₂²·(m₁+m₂−2)/[m₁·(m₂−2)²·(m₂−4)]
```

复算：

- (16.94a)：利用 (m₁/2)t + (m₂/2) = (m₂/2)·(1 + (m₁/m₂)t)，常数部分化为

```
(m₁/2)^{m₁/2}·(m₂/2)^{m₂/2} / (m₂/2)^{(m₁+m₂)/2} = (m₁/m₂)^{m₁/2}
```

  故 f_F(t) = (m₁/m₂)^{m₁/2}·Γ((m₁+m₂)/2)/[Γ(m₁/2)Γ(m₂/2)]·t^{m₁/2−1}·(1+(m₁/m₂)t)^{−(m₁+m₂)/2}，即标准 F 密度——验证成立；
- (16.94b) 存疑：被积函数中的「− 1」与 (16.94a) 的被积函数 t^{m₁/2−1} 不符；且若被积函数确为「密度 − 常数」，则 x → ∞ 时 F_F(x) = 1 − (正的常数项) 不归一（密度 (16.94a) 已归一）。「− 1」疑为衍文，已立 [[式16-94b被积函数疑衍文负一]] 追踪；
- (16.95a,b)：与标准结果 E = m₂/(m₂−2)（m₂>2）、D² = 2m₂²(m₁+m₂−2)/[m₁(m₂−2)²(m₂−4)]（m₂>4）一致；但原文未标注两条件，与 t 分布 (16.98) 显式给出 m>1、m>2 的体例不一，疑脱。

## 学生 t 分布（16.2.4.8）

```
(16.96)   T = X/√(Y/m)   （X 为 (0,1) 正态变量，Y ~ χ²(m)，m = n−1，相互独立）
(16.97a)  f_S(t) = 1/√(m·π)·Γ((m+1)/2)/Γ(m/2)·1/(1+t²/m)^{(m+1)/2}
(16.97b)  F_S(x) = 1/√(m·π)·Γ((m+1)/2)/Γ(m/2)·∫_{−∞}^{x} dt/(1+t²/m)^{(m+1)/2}
(16.98a)  E(T) = 0  (m > 1)
(16.98b)  D²(T) = m/(m−2)  (m > 2)
(16.99a)  P(T > t_{α,m}) = α
(16.99b)  P(|T| > t_{α/2,m}) = α
```

复算：

- (16.97a)：与标准 t 密度 f(t) = Γ((m+1)/2)/(√(mπ)·Γ(m/2))·(1+t²/m)^{−(m+1)/2} 完全一致；
- (16.97b)：为 (16.97a) 的积分，一致；
- (16.98a,b)：与标准结果一致，条件 m>1、m>2 显式给出（与 F 分布形成对照）；
- (16.99a,b)：单侧与双侧分位数定义——一致（分位数一般定义在 16.2.2.2 第 3 条，未入库）。

## 转写讹误记录

- 16.2.4.7、16.2.4.8 标题与正文中「t/F」字母系统性脱落：「费希尔分布或 分布」「学生 分布或 分布」「分布的分位数」「发表的 分布」等；
- 16.2.4.8 首句「如果随机变量 (0, 1) 正态随机变量， 相互独立」脱变量符号 X、Y；「样本容量 较小」脱符号 n；
- 「对千费希尔分布」「适用千当样本容量」「依赖千」等「千/于」混淆。

## 复现状态

复算为一次性手工推导；一致性结论可交叉验证，视为已复现；(16.94b) 衍文与 (16.95) 条件缺失待原书核验。
