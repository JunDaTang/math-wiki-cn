# 伽马函数两种定义与六条性质复算（式 8.101–8.102）

## 逐字转录

```latex
\Gamma(x) = \int_{0}^{\infty} \mathrm{e}^{-t} t^{x-1}\,\mathrm{d}t \quad (x>0) \qquad \text{或} \tag{8.101a}
\Gamma(x) = \lim_{n\to\infty} \frac{n^{x} \cdot n!}{x(x+1)(x+2)\cdots(x+n)} \quad (x \neq 0,-1,-2,\dots) \tag{8.101b}

\Gamma(x+1) = x\Gamma(x) \tag{8.102a}
\Gamma(n+1) = n! \quad (n=0,1,2,\dots) \tag{8.102b}
\Gamma(x)\Gamma(1-x) = \frac{\pi}{\sin \pi x} \quad (x \neq 0,\pm 1,\pm 2,\dots) \tag{8.102c}
\Gamma\!\left(\frac{1}{2}\right) = 2\int_{0}^{\infty} \mathrm{e}^{-t^{2}}\,\mathrm{d}t = \sqrt{\pi} \tag{8.102d}
\Gamma\!\left(n+\frac{1}{2}\right) = \frac{(2n)!\sqrt{\pi}}{n! \, 2^{2n}} \quad (n=0,1,2,\dots) \tag{8.102e}
\Gamma\!\left(-n+\frac{1}{2}\right) = \frac{(-1)^{n} n! \, 2^{2n} \sqrt{\pi}}{(2n)!} \quad (n=0,1,2,\dots) \tag{8.102f}
```

原书另注（转写）：当自变量为复数 z 时只要 Re(z) > 0，公式 (8.102a)(8.102c) 也成立。

## 复算记录（直接证据：独立重推导，全部一致）

- 8.102a：分部积分 Γ(x+1) = ∫₀^∞ e^{−t}tˣ dt = [−e^{−t}tˣ]₀^∞ + x∫₀^∞ e^{−t}t^{x−1}dt = xΓ(x)。
- 8.102b：Γ(1) = ∫₀^∞ e^{−t}dt = 1，再由 8.102a 递推得 Γ(n+1) = n!。
- 8.102c：反射公式，与标准结果一致。
- 8.102d：代换 t = u² 得 Γ(1/2) = 2∫₀^∞ e^{−u²}du = √π（高斯积分）。
- 8.102e：数值核对 n = 0,1,2 得 √π、√π/2、3√π/4，与 (2n)!√π/(n!·4ⁿ) 一致。
- 8.102f：数值核对 n = 0,1,2 得 √π、−2√π、4√π/3，与公式一致（符号交替来自负半整数点的极点跨越）。
- 8.101b：欧拉型极限定义，与标准结果一致（适用于除 0 与负整数外的点）。

## 存疑点（数学性张力）

「Re(z) > 0 时 (8.102a)(8.102c) 也成立」：Re(z) > 0 是积分定义 8.101a 的收敛条件；函数方程与反射公式经解析延拓对全体非极点复数成立，不应限于 Re(z) > 0。已立 [[式8-102复数条件Re-z大于0是否原书原文]] 跟踪。

## 转写讹误（排版/OCR）

- (8.101b) 在原书中无独立编号，转写以行外标注补记。
- 「伽 $\frac{\pi}{\surd J}$ 函数」应为「伽马函数」；「函数 r(x)」应为「函数 Γ(x)」；「是除了 和负整数之外包含复数在内的任意数 」脱 0 与 x，应为「是除了 0 和负整数之外包含复数在内的任意数 x」；「当自变量为复数 时」脱 z。
