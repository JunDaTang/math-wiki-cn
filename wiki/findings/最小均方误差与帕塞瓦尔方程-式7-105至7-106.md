# 最小均方误差与帕塞瓦尔方程（式 7.105–7.106）

## 主张（依源转录）

区间 [0, T]（T = 2π/ω）上函数 f(x) 用三角和（傅里叶和）近似（式 7.105a），则当 a_k、b_k 为 f 的傅里叶系数时，均方误差（式 7.105b）最小（回指 19.6.2.1、19.6.4）。若 f 有界且在 0 < x < T 上分段连续，则傅里叶级数在 [0, T] 上均方收敛到该函数（式 7.106a），其重要结果为帕塞瓦尔方程（式 7.106b）。

```latex
% (7.105a/b)
s_n(x) = a_0/2 + Sum_{k=1}^n a_k cos k omega x + Sum_{k=1}^n b_k sin k omega x
F = (1/T) Int_0^T [f(x) - s_n(x)]^2 dx

% (7.106a/b)
Int_0^T [f(x) - s_n(x)]^2 dx -> 0    (n -> inf)
(2/T) Int_0^T [f(x)]^2 dx = a_0^2/2 + Sum_{k=1}^inf (a_k^2 + b_k^2)
```

## 复算（通过）

1. **最小性（变分/正交投影）**：对任意系数 α_k、β_k 展开 F = (1/T)∫f² − 2[α_0a_0/4 + Σ(α_ka_k + β_kb_k)/2] + [α_0²/4 + Σ(α_k² + β_k²)/2]（利用三角函数系在 [0, T] 上的正交性）。每个变量独立成二次式，最小点恰为 α_k = a_k、β_k = b_k——即欧拉公式给出的傅里叶系数。最小值 F_min = (1/T)∫f² − a_0²/4 − ½Σ_{k=1}^n(a_k²+b_k²) ≥ 0（顺带得到 Bessel 型不等式，本 wiki 复算推论）。✅
2. **帕塞瓦尔方程（式 7.106b）**：由均方收敛 F → 0 与上式取 n → ∞ 即得。抽查：f = 1 时 a_0 = 2、其余系数为零，左端 (2/T)∫1² = 2，右端 a_0²/2 = 2；f = cos ωx 时 a_1 = 1、其余为零，左端 (2/T)∫cos²ωx = 1，右端 a_1² = 1。✅
3. **功率解读**：两端除以 2 得 (1/T)∫f² = a_0²/4 + ½Σ(a_k²+b_k²)，即平均功率按谐波分解（常数项 a_0/2 的功率 a_0²/4，第 k 次谐波功率 (a_k²+b_k²)/2）。✅
