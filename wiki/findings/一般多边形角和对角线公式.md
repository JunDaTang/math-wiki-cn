# 一般多边形角和对角线公式（式 3.44–3.46）

《数学手册(原书第10版)》3.1.5.1 给出一般 n 边形的三条基本量，均可由「分解成 n − 2 个三角形」的三角剖分（图 3.22）直接推出：

```
Σ_{i=1}^{n} β_i = 360°              (3.44)  外角和
Σ_{i=1}^{n} γ_i = 180°·(n − 2)      (3.45)  内角和
D = n(n − 3)/2                       (3.46)  对角线数
```

- 外角和与 n 无关，恒为 360°（一周角）；内角和随 n 线性增长。
- 对角线数：每个顶点可引 n − 3 条对角线，n 个顶点计数每条两次，故 D = n(n − 3)/2。

## 复核与限定

本条数学内容为标准初等几何结果，经独立复核（由三角剖分直接推出）自洽。注意表述张力：源文 3.1.5.1 只称「封闭平面图形」未限定凸性，而式 3.44 的外角和 360° 严格地说对凸多边形（或采用有向外角约定）成立，见 [[queries/外角和360度是否限于凸多边形]]。
