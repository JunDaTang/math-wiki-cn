# 幂函数与指数函数族的修正公式（式 2.255–2.258，含三点定 c 法）

**发现**：手册 2.16.2.1–2.16.2.2 给出幂函数与指数函数两族（各含 +c 变体）的完整修正方案；含加常数 c 的两型共用同一“三点定 c”公式，但第三点的取法**依函数型而异且不可互换**。

## 修正代换

（log 为常用对数 lg，log e = lg e ≈ 0.4343。）

| 编号 | 函数型 | 修正代换 | 线性关系 |
|---|---|---|---|
| 2.255b | $y=ax^b$ | $X=\log x,\ Y=\log y$ | $Y=\log a+bX$ |
| 2.256b | $y=ax^b+c$（b 已知） | $X=x^b,\ Y=y$ | $Y=aX+c$ |
| 2.256c | $y=ax^b+c$（b 未知，先定 c） | $X=\log x,\ Y=\log(y-c)$ | $Y=\log a+bX$ |
| 2.257b | $y=a\mathrm{e}^{bx}$ | $X=x,\ Y=\log y$ | $Y=\log a+b\log\mathrm{e}\cdot X$ |
| 2.258b | $y=a\mathrm{e}^{bx}+c$ | $X=x,\ Y=\log(y-c_1)$ | $Y=\log a+b\log\mathrm{e}\cdot X$ |

注：(2.258b) 中 $c_1$ 为 c 的先估値（“对 c 确定出 $c_1$ 后可做如下修正”）。曲线形状上，$y=ax^b+c$ 与 $y=a\mathrm{e}^{bx}+c$ 分别是 $y=ax^b$、$y=a\mathrm{e}^{bx}$ 沿 y 轴平移 c 个单位（图 2.82、图 2.83）。

## 三点定 c 法（式 2.256d 及 2.258 节内）

任选两个横坐标 $x_1,x_2$ 及相应纵坐标 $y_1,y_2$，再取第三个横坐标 $x_3$ 及 $y_3$，则

$$c=\frac{y_1y_2-y_3^2}{y_1+y_2-2y_3}.$$

- **幂函数型 $y=ax^b+c$**：取 $x_3=\sqrt{x_1x_2}$（几何均值）；
- **指数型 $y=a\mathrm{e}^{bx}+c$**：取 $x_3=\frac{x_1+x_2}{2}$（算术均值）。

两种取点方式是各自函数型的专属性质（几何均值对应幂函数的乘性结构，算术均值对应指数函数的加性结构），**不可互换**。

c 的确定次序：先用三点法估计 c（记 $c_1$），做修正定 a、b；随后可用“残差均值”得到更正确的 c——幂函数型为量 $y-ax^b$ 的均值。手册 2.16.2.2（指数型）末句亦写作“$y-ax^b$ 的均值”，疑自幂函数型小节串文，应为 $y-a\mathrm{e}^{bx}$ 的均值，见 [[queries/2-16-2-2的y-ax-b均值是否应为y-ae-bx均值]]。

## 验证与评估

- **直接证据**：上表五行代换均为恒等变形（如 2.255b 即 $\lg y=\lg a+b\lg x$）。
- **推导复核**：三点定 c 公式可由代数恒等式导出——记 $u_i=y_i-c$（幂函数型 $u_i=ax_i^b$），则 $x_3=\sqrt{x_1x_2}$ 时 $u_3=\sqrt{u_1u_2}$，即 $y_3-c=\sqrt{(y_1-c)(y_2-c)}$，展开即得 c 的闭式；指数型同理用 $x_3$ 的等差中点性质。入库分析已独立复核，公式成立（replicated: true）。
- **限制**：三点法假设三个数据点严格满足函数型；对含噪声的实测数据，c 的估计对点的选取敏感，故手册随后以残差均值改进。
