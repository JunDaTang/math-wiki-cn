# 式 15.56–15.63 一维热传导方程拉普拉斯求解转录复算

## 发现内容

手册 15.2.3.3 给出偏微分方程的单变量拉普拉斯变换流程，并以一维热传导方程为例完成求解（% 注为讹误标注）：

```latex
(15.56)  L{u(x,t)} = \int_0^\infty e^{-pt} u(x,t) dt = U(x,p)
(15.57)  L{u_t}   = p L{u} - u(x,+0)
         L{u_{tt}} = p^2 L{u} - u(x,+0) p - u_t(x,+0)
(15.58)  L{u_x} = \partial/\partial x L{u} = \partial U/\partial x

(15.59a)  u_{xx} - a^{-2} u_t = u_{xx} - u_y = 0
          % 源文「时间坐标用 y = a t 代替」，复算表明应为 y = a^2 t
          % 区域 0 < t < \infty, 0 < x < t（疑为 0 < x < l）
(15.59b)  u(x,+0)=u_0(x),  u(+0,t)=a_0(t),  u(l-0,t)=a_1(t)

(15.60a)  d^2U/dx^2 = pU - u_0(x)
(15.60b)  U(+0,p)=A_0(p),  U(l-0,p)=A_1(p)
(15.60c)  u_0(x)=0 时: U = c_1 e^{x\sqrt{p}} + c_2 e^{-x\sqrt{p}}
(15.61a)  U_1(0,p)=1, U_1(l,p)=0;   (15.61b)  U_2(0,p)=0, U_2(l,p)=1
(15.61c)  U_1 = [e^{(l-x)\sqrt{p}} - e^{-(l-x)\sqrt{p}}]/[e^{l\sqrt{p}} - e^{-l\sqrt{p}}]
(15.61d)  U_2 = [e^{x\sqrt{p}} - e^{-x\sqrt{p}}]/[e^{l\sqrt{p}} - e^{-l\sqrt{p}}]
(15.62)   U = A_0(p) U_1(x,p) + A_1(p) U_2(x,p)

l \to \infty:
(15.63a)  U = a_0(p) e^{-x\sqrt{p}}       % 小写 a_0(p) 疑应作 A_0(p)
(15.63b)  u(x,t) = (x/2\sqrt{\pi}) \int_0^t a_0(t-\tau) \tau^{-3/2} \exp(-x^2/(4\tau)) d\tau
```

## 复算核验（独立推导）

- **(15.57)、(15.58)**：为 15.2.1.2 导数法则与「对参数 x 求导可与积分交换」假设的直接转写 ✓。
- **(15.59a) 自洽性检验**：若 y = a·t，则 u_t = a·u_y，a⁻²u_t = a⁻¹u_y ≠ u_y；若 y = a²·t，则 u_t = a²u_y，u_xx − a⁻²u_t = u_xx − u_y ✓。故源文指数疑脱漏（[[queries/式15-59a时间代换y等于at疑为a平方t]]）。
- **变换变量含混**：(15.56) 定义对 t 变换，而 (15.60a) 的 U″ = pU − u₀(x) 只有对替换后的变量 y 作变换（L{u_y} = pU − u(x,+0)）时才成立；若直接对 t 变换应得 U″ = (p/a²)U − u₀(x)/a²。手册未加区分，属表述含混而非实质错误。
- **(15.60c)**：u₀(x)=0 时 (15.60a) 齐次，通解 c₁e^{√p·x} + c₂e^{−√p·x} ✓。
- **(15.61c)(15.61d)**：U₁ = sinh((l−x)√p)/sinh(l√p)、U₂ = sinh(x√p)/sinh(l√p)；代入 (15.61a)(15.61b) 边界条件均满足 ✓；(15.62) 由线性叠加得到 ✓。
- **(15.63a)**：l→∞ 时 U₁ → e^{−x√p}、U₂ → 0，故 U = A₀(p)e^{−x√p} ✓。
- **(15.63b) 核的推导**：由标准对 L{t^{−1/2}e^{−a²/4t}} = √(π/p)·e^{−a√p} 两边对 a 求导，得 L{t^{−3/2}e^{−a²/4t}} = (2√π/a)·e^{−a√p}，即 L⁻¹{e^{−a√p}} = a/(2√π)·t^{−3/2}·e^{−a²/4t}；取 a = x 与 a₀ 作 [[concepts/卷积]] 即得 (15.63b) ✓（Poisson 型积分核）。

## 适用范围

- (15.60c) 起仅关于零初始温度 u₀(x)=0；(15.63) 仅关于 l→∞ 的半无限情形；一般区间 (15.62) 的逆变换手册未展开。
