# 高阶导数的定义与 n 阶记号（式 6.21）

《数学手册》6.1.3.1 以递推方式定义高阶导数：$y' = f'(x)$ 的导数，即 $\left(y'\right)'$ 与 $\frac{\mathrm{d}}{\mathrm{d}x}\left(\frac{\mathrm{d}y}{\mathrm{d}x}\right)$（原文此处两记号间的连接符转写损坏，孤立全角「＇」，见 [[queries/6-1-3全节系统性转写讹误清单]]），称为函数 $y = f(x)$ 的二阶导数，记为 $y'' ,\ \ddot y ,\ \frac{\mathrm{d}^{2}y}{\mathrm{d}x^{2}} ,\ f''(x)$ 或 $\frac{\mathrm{d}^{2}f(x)}{\mathrm{d}x^{2}}$。类似地定义更高阶导数，n 阶导数记为（逐字转录）：

$$
y^{(n)} = \frac{\mathrm{d}^{n} y}{\mathrm{d} x^{n}} = f^{(n)}(x) = \frac{\mathrm{d}^{n} f(x)}{\mathrm{d} x^{n}} \quad \left(n = 0, 1, \dots ;\; y^{(0)}(x) = f^{(0)}(x) = f(x)\right).\tag{6.21}
$$

## 要点

- **n = 0 约定**：零阶导数即函数自身，$y^{(0)} = f^{(0)} = f$，使莱布尼茨公式（式 6.23）的求和可从 $m = 0$ 起统一书写。
- **记号族**：上标记号 $f^{(n)}$ 与 Leibniz 记号 $\frac{\mathrm{d}^{n}y}{\mathrm{d}x^{n}}$ 并用。
- **点记号疑点**：$\ddot y$ 被列为二阶导数通用记号之一；点记号通常专指对时间求导，疑原版限定语脱落（低优先级，不影响公式本身）。

## 证据性质

本条目为定义与记号约定的直接转录（直接证据），不涉及数值复算；概念展开见 [[concepts/高阶导数]]。
