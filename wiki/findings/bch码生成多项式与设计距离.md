# BCH 码的生成多项式与设计距离（式 5.272）

《数学手册》5.4.6.2.4 末定义一类重要循环码——BCH 码：可对其极小距离的下界以及码能纠正差错个数的下界提出要求。生成多项式公式原文照录：

```
g(x) = lcm(m_{α^b}(x), m_{α^{b+1}}(x), …, m_{α^{b+δ−2}}(x))              (5.272)
```

其中 α 是本原 [n] 次单位根，[b] 是一个整数，多项式 m_{α^j}(x) 是 α^j 的极小多项式。δ 称为码的**设计距离**；对极小距离，BCH 关系式 d_min(C) ≥ δ 必定成立。

## 概念依赖

- α 的本原 n 次单位根性质：[[concepts/分圆域]]、[[findings/分圆域单位根性质]]；
- 极小多项式 m_{α^j}(x)：[[concepts/极小多项式]]；
- lcm 与生成多项式框架：[[concepts/循环码]]、[[findings/循环码多项式刻画]]。

这是 5.3.7 抽象理论（有限域/分圆域）在编码理论中的第一个入库应用。

## 转写疑点

「本原 [n] 次单位根」缺 n、「[b] 是一个整数」缺 b、设计距离句残缺（「其中 称作码的设计距离」缺 δ），见 [[queries/5-4-5至5-4-6全节系统性转写讹误清单]]。置信度中等。
