# 式 19.252–19.258 伯恩斯坦多项式与 B-B 表示转录复算

对 19.7.3 伯恩斯坦多项式与 B-B 表示全部公式 (19.252)–(19.258) 的逐字转录，并对全部断言作了独立复算。

## 逐字转录

```latex
(19.252)  B_{i,n}(t) = C(n,i) t^i (1−t)^{n−i}   (i = 0, 1, …, n)
(19.253)  0 ⩽ B_{i,n}(t) ⩽ 1,   0 ⩽ t ⩽ 1
(19.254)  Σ_{i=0}^{n} B_{i,n}(t) = 1    （由二项式定理，回指第 14 页 1.1.6.4）
例 A:  B_{0,1}(t) = 1−t,  B_{1,1}(t) = t                            （图 19.12）
例 B:  B_{0,3} = (1−t)³,  B_{1,3} = 3t(1−t)²,  B_{2,3} = 3t²(1−t),  B_{3,3} = t³  （图 19.13）
(19.255)  r(t) = x(t)e_x + y(t)e_y + z(t)e_z           （t 为曲线参数）
(19.256)  r(u,v) = x(u,v)e_x + y(u,v)e_y + z(u,v)e_z   （u、v 为曲面参数）
(19.257)  r(t) = Σ_{i=0}^{n} B_{i,n}(t) P_i   （B-B 曲线）
(19.258)  r(u,v) = Σ_{i=0}^{n} Σ_{j=0}^{m} B_{i,n}(u) B_{j,m}(v) P_ij   （B-B 曲面）
```

## 复算验证（直接证据）

1. **非负性 (19.253)**：0 ⩽ t ⩽ 1 时 t^i ⩾ 0、(1−t)^{n−i} ⩾ 0、C(n,i) > 0；再由单位分解 (19.254) 与非负性即得各项 ⩽ 1。✓
2. **单位分解 (19.254)**：Σ_{i=0}^{n} C(n,i)t^i(1−t)^{n−i} = (t + (1−t))^n = 1（二项式定理）。✓
3. **例 B 展开**：C(3,1) = 3、C(3,2) = 3，故 B_{1,3} = 3t(1−t)²、B_{2,3} = 3t²(1−t)。✓
4. **端点插值**：t = 0 时仅 i = 0 项非零（约定 0⁰ = 1），即 B_{i,n}(0) = δ_{i0}；同理 B_{i,n}(1) = δ_{in}。代入 (19.257) 得 r(0) = P_0、r(1) = P_n，即 P_0、P_n 为插值点。✓
5. **端点切线**：利用导数恒等式 B′_{i,n}(t) = n[B_{i−1,n−1}(t) − B_{i,n−1}(t)]（复算所用标准恒等式，原书未列），得 r′(0) = n(P_1 − P_0)、r′(1) = n(P_n − P_{n−1})，故 P_0P_1、P_{n−1}P_n 为端点切线。✓
6. **变量凸组合**：由 (19.253)(19.254)，r(t) 的系数非负且和为 1，是给定点的「变量凸组合」。✓
7. **B-B 曲面格点全局影响**：0 < t < 1 时 B_{i,n}(t) > 0，故 (19.258) 中任一格点 P_ij 的变动影响参数域 (0,1)² 内所有曲面点——原书「每个格点的影响是全局的」是伯恩斯坦基全局支撑的直接推论。✓

## 转写讹误记录

- 例 B 中 B_{2,3} 与 B_{3,3} 两式间脱分隔符；
- 「这里 为曲线的参数」脱 t；「其中 为曲面参数」脱 u、v；
- 「设给定位置向量 P_ij 凡的点」衍字「凡」；
- 「常用正则化的 样条代替伯恩斯坦多项式」「相应的空间曲线称为 样条曲线」「改为 样条」等处脱「B」；
- 「其形状基本相应千有如下优点的 B-B 曲线」之「千」为「于」。

## 结论

伯恩斯坦多项式两条基本性质与 B-B 曲线、曲面全部断言均复算通过，证据强度高。
