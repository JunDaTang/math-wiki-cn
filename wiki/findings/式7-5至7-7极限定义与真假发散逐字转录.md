# 式 7.5–7.7 极限定义与真假发散逐字转录

本 finding 逐字转录 7.1.2.1「数列的极限」、7.1.2.2「收敛数列」、7.1.2.3「发散数列」三小节（式 7.5a/b、7.6、7.7），并登记术语约定与转写噪音。内容为标准 ε–N 定义，复算无误。

## 逐字转录（已清理「于→千」等形近讹误与脱落的 n）

```text
1. 数列的极限

若对无限增加的指标 n，恒有 aₙ − A 任意小，则称无穷数列 (7.1) 有极限 A。
其精确定义为：若对于任意小的 ε > 0 总存在指标 n₀(ε)，使得对于 n > n₀ 时
的一切 aₙ，恒有
    |aₙ − A| < ε                                    (7.5a)
若对于任意 K > 0 总存在指标 n₀(K)，使得对于 n > n₀ 时的一切 aₙ，恒有
    aₙ > K  (aₙ < −K)                               (7.5b)
则称数列 (7.1) 的极限为 +∞ (−∞)。

2. 收敛数列

若数列 {aₙ} 满足 (7.5a)，则称该数列收敛于 A，记为
    lim_{n→∞} aₙ = A   或   aₙ → A                   (7.6)

3. 发散数列

不收敛的数列称为发散数列。(7.5b) 的情况称为真发散，即随着 n 的无限增加
aₙ 超过任意大的正数 K (K > 0)，且一直不会变小；或者若随着 n 的无限增加，
aₙ 小于任意小的负数 −K (K > 0)，且一直不会变大。若数列有极限 ±∞，记为
    lim_{n→∞} aₙ = ∞  (aₙ > K, ∀n > n₀)
    或  lim_{n→∞} aₙ = −∞  (aₙ < −K, ∀n > n₀)        (7.7)
否则数列称为假发散。
```

## 术语约定（手册自洽但易误读）

7.5b 与 7.7 把 ±∞ 也称作「极限」（「则称数列 (7.1) 的极限为 +∞ (−∞)」「若数列有极限 ±∞」），但「收敛」仅指满足 (7.5a) 的有限极限；±∞ 情形归入发散，且是其中的「真发散」。引用本节时须区分「有（无穷）极限」与「收敛」两个说法，详见 [[concepts/数列的极限]] 与 [[concepts/真发散与假发散]]。

## 转写噪音登记

- 「于→千」形近讹误在本三小节最密集：「对千」×4、「收敛千」×4、「趋千」「小千」各 1 处，已按上下文复原。
- 「随着 的无限增加」两处 n 脱落（已补）。
- 真发散释义中「且一直不会变小 / 一直不会变大」为源文原文，强调 (7.5b) 的「对一切 n > n₀」逐项成立、不再回落。
- 其余讹误见 [[queries/7-1全节系统性转写讹误清单]]。
