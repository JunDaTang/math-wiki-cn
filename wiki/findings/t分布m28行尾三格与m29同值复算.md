# t 表 m=28 行尾三格与 m=29 同值复算

## 现象

21.20 节表中，$m=28$ 与 $m=29$ 两行六格**完全相同**（1.70 / 2.05 / 2.46 / 2.76 / 3.40 / 3.66）。

## 复算比对

与通行精确 t 分位数比对（按单侧读数）：

| 单侧 α | m=28 精确值 → 应印 | m=29 精确值 → 应印 | m=28 表值 | m=29 表值 |
|---|---|---|---|---|
| 0.05 | 1.7011 → 1.70 | 1.6991 → 1.70 | 1.70 | 1.70 |
| 0.025 | 2.0484 → 2.05 | 2.0452 → 2.05 | 2.05 | 2.05 |
| 0.01 | 2.4671 → 2.47 | 2.4620 → 2.46 | 2.46 | 2.46 |
| 0.005 | 2.7633 → 2.76 | 2.7564 → 2.76 | 2.76 | 2.76 |
| 0.001 | 3.4082 → 3.41 | 3.3962 → 3.40 | 3.40 | 3.40 |
| 0.0005 | 3.6739 → 3.67 | 3.6591 → 3.66 | 3.66 | 3.66 |

前三列（0.05、0.025、0.005）两行同值属**合法舍入**；但尾三列（0.01、0.001、0.0005）在精确值下应各差 0.01，而表中 m=28 行尾三格恰与 m=29 行逐格相同——疑 m=28 行尾列整段抄自下行。

## 单调性佐证

精确 t 分位数随 $m$ 严格递减；印表中尚有同类「平台超长」现象：m=18–20 三个 1.73（1.7341、1.7291→1.73，1.7247→1.72，正确舍入应仅两格）、m=23–27 五个 1.71（1.7139、1.7109、1.7081、1.7056→1.71，1.7033→1.70，应仅四格），平台各多出一格，与 m=28 行现象同向。

## 证据强度与限定

比对值来自标准精确 t 分位数（标准表与级数展开），**非闭式直接证明**，故置信记 medium；应在 wiki 工作流中以不完全 Beta 函数精算复核后再定谳。开放问题与对勘待办见 [[queries/t分布m28行尾三格与m29同值之辨]]。
