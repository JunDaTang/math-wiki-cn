# 式 20.44a–b 贝塞尔函数绘图复算

## 转录（原样）

```mathematica
In[1] := bj0 = Plot[{BesselJ[0, z], BesselJ[2, z],
    BesselJ[4, z]}], {z, 0, 10}, PlotLabel->
    TraditionalForm[{BesselJ[0, z], BesselJ[2, z], BesselJ[4, z]}]     (20.44a)
In[2] := bj1 = Plot[{BesselJ[1, z], BesselJ[3, z],
    BesselJ[5,z]}, {z, 0, 10}, PlotLabel->
    TraditionalForm[{BesselJ[1,z], BesselJ[3,z], BesselJ[5,z]}]]       (20.44b)
In[3] := GraphicsRow[{bj0, bj1}]
```

## 校勘

- **In[1] 括号错位**：`BesselJ[4, z]}],` 处 `]` 提前闭合 Plot，导致其后 `{z, 0, 10}` 落在括号外且 TraditionalForm 未闭合。应为 `Plot[{BesselJ[0, z], BesselJ[2, z], BesselJ[4, z]}, {z, 0, 10}, PlotLabel->TraditionalForm[{BesselJ[0, z], BesselJ[2, z], BesselJ[4, z]}]]`（删去多余 `]`、补末尾 `]`，详见 [[BesselJ绘图括号错位与n值列表讹误之辨]]）。
- **正文 n 值列表残缺**：「将产生贝塞尔函数 J_n(z) 关于 n = 0, 2, 4 = l, 3, 的图形」疑为「关于 n = 0, 2, 4 和 n = 1, 3, 5 的图形」（l 为 1 之讹、脱「和」与「5」）。

## 复算结论

- In[2] 原样有效：奇数阶 BesselJ[1,z]、BesselJ[3,z]、BesselJ[5,z] 于 z∈[0,10] 绘图，`PlotLabel->TraditionalForm[...]` 以传统数学记法标注（图 20.5b）。
- In[1] 按上述校勘修正后有效（图 20.5a）；In[3] `GraphicsRow[{bj0, bj1}]` 将两图接连横排显示，为 v6+ 命令（与式 20.43 `GraphicsArray` 构成版本张力，[[GraphicsArray与GraphicsRow比较]]）。

## 证据强度

数学内容（贝塞尔函数 J_n(z)，回指第 743 页 9.1.2.6，未入库——[[20-4未入库回指缺口]]）与命令语义清楚；In[1] 之讹误可据 In[2] 的平行结构无歧义地复原，修正后整组算例可复算。
