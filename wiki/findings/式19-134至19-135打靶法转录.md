# 式 19.134–19.135 打靶法转录

**转录**（源文逐字保留）：

```latex
(19.134)  y'' + p(x)y' + q(x)y = f(x),  y(\alpha)=\alpha,\ y'(\alpha)=s
(19.135)  F(s) = y(b, s) - \beta
```

**评注**：

- 机制：初值问题 (19.134) 的解 y = y(x, s) 依赖参数 s，且满足第一个边界条件 y(a, s) = α；s 由第二个边界条件 y(b, s) = β 确定，即求 F(s) = 0。
- 求根方法：源文明确指出**试位法（割线法）就是适当的求解方法**——[[concepts/试位法]]（19.1 节）应用域的跨节扩展；每个 s 的函数值计算都需求解初值问题 (19.134) 直到 x = b（用 19.4.1 方法）。
- 多目标打靶法：[a,b] 分为子区间，逐段单目标打靶，须保证子区间端点连续过渡（更多条件）；数值实现见 [19.31]。源文该段句读脱失，见 [[queries/19-4全节系统性转写讹误清单]]。
- 记号疑误：(19.134) 的 y(α)=α、y′(α)=s 疑为 y(a)=α、y′(a)=s，见 [[queries/边界条件yα等于α之α疑为a之辨]]。

本条为机制转录，未做数值复算。见 [[concepts/打靶法]]。
