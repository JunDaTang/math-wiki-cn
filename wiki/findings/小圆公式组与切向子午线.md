# 小圆公式组与切向子午线（式 3.213–3.218）

[[concepts/小圆]]（球面上与定点 M(λ_M, φ_M) 球面距离 r < 90° 的点的轨迹）的公式组（直接证据，个别符号脱落处另注）：

```
cos r = sin φ sin φ_M + cos φ cos φ_M cos(λ − λ_M)                    (3.213a)
cos r = sin φ sin(φ_N − r) + cos φ cos(φ_N − r) cos(λ − λ_N)          (3.213b)
s = sin r·arccos[(cos d − cos²r)/sin²r]·πR/180°                      (3.214)
α_Orth = arctan[cos φ_A cos φ_M sin(λ_M−λ_A)/(sin φ_M − sin φ_A cos r)]   (3.215a)
α_A = (|α_Orth| − 90°)·sign(α_Orth)                                   (3.215b)
λ_Xν = λ_M ∓ arccos[(cos r − sin φ_X sin φ_M)/(cos φ_X cos φ_M)]      (3.216)
φ_T = arcsin(sin φ_M/cos r)                                           (3.217a)
λ_Tν = λ_M ∓ arccos[(cos r − sin φ_X sin φ_M)/(cos φ_X cos φ_M)]      (3.217b)【φ_X 疑应为 φ_T】
φ_Yν = arcsin[(−AC ± B√(A²+B²−C²))/(A²+B²)]    (ν = 1, 2)             (3.218a)
A = sin φ_M,   B = cos φ_M cos(λ_Y − λ_M),   C = −cos r               (3.218b)
```

## 要点

- **方程**（3.213a/b）：以 (λ_M, φ_M, r) 或 (λ_N, φ_N, r)（φ_M = φ_N − r，λ_M = λ_N）为定义参数，由边的余弦定律得出。例：φ_M = 90° 时得平行圆（φ = 常数）；r → 90° 时由 (3.213b) 退化为 [[concepts/大圆航线]]。
- **弧长**（3.214）：由 s/σ = 2πr₀/360°、cos d = cos²r + sin²r cos σ 与平面半径 r₀ = R sin r 计算；r → 90° 时由 (3.214) 与 (3.207b) 得 s = d。
- **航向角**：过 A 与 M 的大圆与小圆**垂直相交**；先按 (3.215a)（即大圆航向角公式 3.208 中以 M 为终点、r 为距离）求 α_Orth，再由 (3.215b) 得小圆在 A 处的航向角。
- **切向子午线与切点**：在切点 T₁、T₂ 处小圆与两条子午线相切；因 (3.216) 中反余弦的自变量必须是关于 φ_X 的极值，得 (3.217a) φ_T = arcsin(sin φ_M/cos r)。切点经度公式 (3.217b) 转写中作 φ_X，经推导切点处应代入 φ_T（否则 arccos 自变量不为 ±1），见 [[queries/式3-217b中的φX是否应为φT]]；该式与 (3.218) 的判别式零条件（相切）一致（经本 wiki 核验）。
- **与子午线的交点**（3.218）：A²+B² > C² 时两个不同解；若极点在小圆上则丢掉一个；A²+B² = C² 且无极点在圆上时，子午线在纬度 φ_Y1 = φ_Y2 = φ_T 的切点处与小圆相切。「极点在小圆上丢一解」的几何细节源中未展开。

小圆平面是高为 h 的 [[concepts/球冠]] 的底（源交叉引用「第 207 3.3.4」）。
