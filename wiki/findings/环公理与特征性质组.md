# 环公理与特征性质组（式 5.173）

数学手册 5.3.7.1 以三条公理定义环，并随之给出交换环、有单位元素环、整区、零因子与特征的概念。本 finding 汇总该定义组。

## 环的公理

带两个二元运算 $+$ 与 $*$ 的集合 $R$ 称为**环** $(R, +, *)$，如果：

1. $(R, +)$ 是阿贝尔群；
2. $(R, *)$ 是半群；
3. 分配律成立：

$$a * (b + c) = (a * b) + (a * c), \quad (b + c) * a = (b * a) + (c * a). \tag{5.173}$$

若 $(R, *)$ 交换则称**交换环**；若 $(R, *)$ 有中性元素则称**有恒等元素环（有单位元素环）**。有单位元素并且没有零因子的交换环称作**整区**（见 [[concepts/整区]]）。

## 零因子与蕴涵关系

环的非零元 $a$ 称为**零因子或奇异元素**，如果存在环的非零元 $b$ 使得它们的积等于零（源文该句脱落符号 $a$、$b$，语义如上复原）。在有零因子的环中，蕴涵关系 $a * b = 0 \Rightarrow (a = 0 \lor b = 0)$ 一般是错误的。详见 [[concepts/零因子]]。

## 特征

若 $R$ 是有单位元素环，则使 $k \cdot 1 = 1 + 1 + \cdots + 1 = 0$ 的最小自然数 $k$ 称为环 $R$ 的**特征** $\operatorname{char} R = k$；若这样的 $k$ 不存在，则 $\operatorname{char} R = 0$。源文给出三条推论：

- $\operatorname{char} R = k$ 意味着加群 $(R, +)$ 中由 $1$ 生成的循环子群 $\langle 1 \rangle$ 有阶 $k$，因而每个元素的阶都是 $k$ 的因子；
- $\operatorname{char} R = k$ 时，对所有 $r \in R$，$r + r + \cdots + r$（$k$ 项）等于零；
- 整区的特征是零或素数。

详见 [[concepts/环的特征]] 与 [[concepts/循环群与生成子群]]。
