# 式 9.99–9.100 格林方法条件组与表示公式转录

## 逐字转录

两变量（式 9.99）：

```
u_xx + u_yy + a u_x + b u_y + cu = f                                 (9.99a)
G_xx + G_yy − (aG)_x − (bG)_y + cG = 0（极点除外）                     (9.99b)
G = U ln(1/r) + V，r = √((x−ξ)²+(y−η)²)，U 在极点处取值 1              (9.99c/d)
边界上 G = 0（狄利克雷型）或 ∂G/∂n − (a cosα + b cosβ)G = 0（第三类）  (9.99f)
u(ξ,η) = (1/2π)∫_S u ∂G/∂n ds − (1/2π)∬_D fG dxdy                    (9.99e)
u(ξ,η) = −(1/2π)∫_S ∂u/∂n G ds − (1/2π)∬_D fG dxdy                   (9.99g，第三类情形)
```

三变量（式 9.100）：

```
Δu + a u_x + b u_y + c u_z + eu = f                                  (9.100a)
ΔG − (aG)_x − (bG)_y − (cG)_z + eG = 0                               (9.100b)
G = U/r + V，r = √((x−ξ)²+(y−η)²+(z−ζ)²)                             (9.100c/d)
u(ξ,η,ζ) = (1/4π)∬_S u ∂G/∂n ds − (1/4π)∭_D fG dxdydz                (9.100e)
```

## 复算与核对

1. 格林函数条件组结构（除极点外满足齐次 [[伴随微分方程]]、奇性部分二维对数型/三维 1/r 型、边界条件随问题类型改变）内部自洽 ✓。
2. **法向约定（重要）**：9.99e 中 ∂/∂n 为**指向区域内部的法向导数**，与常见外法向约定符号相反。复算圆盘例（[[findings/式9-101至9-102圆盘与球格林函数复算]]）：外法向 ∂G/∂n_out = (ρ² − R²)/(Rr²) 为负值，代入内法向的 9.99e（即取其相反数）恰得正核的泊松积分 ✓，说明手册约定自洽。
3. 手册对比论点（原文立场）：黎曼方法与格林方法共同点是先确定方程的一个特解型辅助函数再用于任意边界条件；本质不同在于前者仅依赖方程左端，后者还依赖区域；找格林函数特别困难，故格林方法主要用于理论研究（见 [[comparisons/黎曼方法与格林方法比较]]）。

## 结论

条件组与表示公式转录自洽；引用时必须注意内法向约定。转写讹误：9.99g 前“在此情形』犀巾下述公式给出”含乱码（见 [[queries/9-2-2全节系统性转写讹误清单]]）。概念页 [[格林函数与格林方法]]。
