# 罗尔定理及假设反例（式 6.28）

## 断言

**对象**：罗尔定理（6.1.4.3）。**题设**：函数 y=f(x) 在闭区间 [a,b] 连续，开区间 (a,b) 可微，且 f(a)=0, f(b)=0（a<b）。**结论**：a、b 间至少存在一点 c，使得

```latex
(6.28a)  f(a) = 0,  f(b) = 0        (a < b)
(6.28b)  f'(c) = 0                   (a < c < b)
```

## 假设失效反例（依赖图像，未独立核验）

- 图 6.8(c)：函数在 x=d 处不连续；
- 图 6.8(d)：函数在 x=e 处不可微。

在这两种情况下，对于任意导数存在的点都有 f′(x) ≠ 0。

## 几何意义

若区间 (a,b) 上连续函数的图像与 x 轴交于 A、B 两点且在每一点都没有垂直切线，则 A、B 间至少存在一点 C，使得该点处的切线与 x 轴平行（图 6.8(a)）；在此区间可能有多个这样的点，如图 6.8(b) 中的点 C、D、E。

## 证据强度与备注

- 定理强、为标准结果；直接证据为原文逐字转录。
- 反例断言依赖查图（图 6.8(c)(d)），文字部分无法独立核验。
- 手册版假设 f(a)=f(b)=0 较通行版（f(a)=f(b)）强，见 [[queries/罗尔与费马表述与通行版差异]]。
- 「每一点都没有垂直切线」为可微性的几何直观转述，不严格（角点处无切线亦不可微）；垂直切线算例参见 [[findings/立方根函数垂直切线算例-图6-2a]]，可微与连续的关系参见 [[comparisons/可微与连续关系比较]]。
