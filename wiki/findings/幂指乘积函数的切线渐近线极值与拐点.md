# 幂指乘积函数的切线、渐近线、极值与拐点（式 2.62）

手册 2.6.6 对 $y = ax^{b}\mathrm{e}^{cx}$（c ≠ 0，仅讨论 a > 0，a < 0 沿 x 轴反射）给出：

- **定义域**：b 非整数时仅 x > 0 有定义；b 为整数时 x < 0 处形状可归入同样情况（图 2.31 给出任意参数下曲线的性状）。
- **原点与切线（b > 0 时过原点）**：b > 1 原点切线为 x 轴；b = 1 手册作 y = x；0 < b < 1 原点切线为 y 轴。
- **渐近线**：b < 0 时 y 轴为渐近线。
- **走向**：c > 0 时函数不断增加且超过任何给定的值；c < 0 时渐近趋近于 0。
- **极值**：b, c 异号时在 $x = -\frac{b}{c}$（点 A）有极值。
- **拐点**：在 $x = \frac{-b\pm\sqrt{b}}{c}$ 有 0、1 或 2 个拐点（图 2.31(c)(e)(f)(g) 中的点 C, D）。

## 复核结果

**通过**：极值横坐标由 $y'/y = b/x + c = 0$ 解出 ✓；拐点横坐标由 $y''/y = (b/x+c)^{2} - b/x^{2} = 0$ 即 $c^{2}x^{2} + 2bcx + b^{2} - b = 0$ 解出，根为 $\frac{-b\pm\sqrt{b}}{c}$ ✓；b < 0 时判别式 $4c^{2}b < 0$ 故无拐点，「0/1/2 个」成立 ✓；切线分档中 b > 1 与 0 < b < 1 两档 ✓。

**疑误（一处）**：b = 1 时原点切线应为 **y = ax** 而非手册所写的 y = x——$y' = a\mathrm{e}^{cx}(1+cx)$，$y'(0) = a \neq 1$（除非 a = 1）（[[幂指乘积b等于1时切线y等于x是否应为y等于ax]]）。

判定：**大体成立**（极值、拐点与两档切线验证通过；b = 1 切线句疑漏系数 a）。
