# 等比级数部分和贯穿商业数学公式体系

等比级数部分和 $\frac{q^n-1}{q-1}$（$q = 1+\frac{p}{100}$）是手册 1.3 中 (1.78)–(1.87) 全部复利类公式的公共骨架：定期储蓄 (1.78)、年内储蓄 (1.80)、等额年金剩余债务 (1.82)、年金终值 (1.85)、支付后余额 (1.87a) 都以该因子（或乘以调整因子/累积因子 q）出现。

## 直接证据与推断的区分

- **直接证据**：手册开篇明示商业数学的计算基础是等差级数和等比级数的公式 (1.52a)–(1.52c)、(1.54a)–(1.54d)；上列各式均含 $\frac{q^n-1}{q-1}$ 因子，可逐式核对。
- **推断（分析重构，非手册原文）**：手册未明说该因子是"公共骨架"。此观察的一个数值印证：月度年金算例中，所需月储蓄 R = €604.19 恰等于 $\frac{2000}{1.005^{240}}$，正是因为 (1.87d) 与 (1.85) 中的公共因子 $\frac{1.005^{240}-1}{0.005}$ 相消。

## 意义

该结构把 1.3 的金融公式统一挂接到 [[等比级数]] 与 [[有限级数]] 的求和公式上，说明 1.2 节级数公式是本节的首要应用场景。相关概念：[[复利]]、[[定期储蓄]]、[[年金]]。
