# 正割与余割的值域约束与极值反转（式 2.70–2.71）

## 手册主张

$$y = \sec x = \frac{1}{\cos x} \tag{2.70}$$

周期 $T = 2\pi$，渐近线 $x = \left(k+\frac{1}{2}\right)\pi$，显然 $|y| \geqslant 1$；「与函数的极大值相对应的极值点」$A_k = \left((2k+1)\pi,\ -1\right)$，「与函数极小值相对应的极值点」$B_k = (2k\pi,\ +1)$。

$$y = \csc x = \frac{1}{\sin x} \tag{2.71}$$

图像由正割向右平移 π/2 得到，渐近线 $x = k\pi$；极大值点 $A_k = \left(\frac{4k+3}{2}\pi,\ -1\right)$，极小值点 $B_k = \left(\frac{4k+1}{2}\pi,\ +1\right)$。

## 独立验证：极值反转为何正确

表面上看「极大值 −1 / 极小值 +1」与 $|y| \geqslant 1$ 矛盾，但按[[concepts/极值]]的局部定义这是正确陈述：

- 在 $\cos x < 0$ 的分支上（含 $x = (2k+1)\pi$），$\sec x \leqslant -1$，且在该支内于中心处取到分支最大值 −1、向两侧趋于 −∞——故 −1 是局部**极大**值；
- 在 $\cos x > 0$ 的分支上（含 $x = 2k\pi$），$\sec x \geqslant 1$，于中心取到分支最小值 +1——故 +1 是局部**极小**值。

csc 同理（负支中心 $x = \frac{4k+3}{2}\pi$ 处局部极大 −1，正支中心 $x = \frac{4k+1}{2}\pi$ 处局部极小 +1）。经分支符号分析验证，全部结论成立。**此表述不是手册错误，不应据此开勘误 query。**
