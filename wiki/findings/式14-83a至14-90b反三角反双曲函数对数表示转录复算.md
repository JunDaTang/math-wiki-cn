# 式 14.83a–14.90b 反三角反双曲函数对数表示转录复算

## 转录内容

十六个公式：多值式 (14.83a)–(14.86b)（用 $Ln$；⚠ (14.83a)、(14.84a) 转写作小写 $ln$）与主值式 (14.87a)–(14.90b)（用 $\ln$），完整转录见 [[sources/10-数学手册原书第10版--15-145-代数函数和初等超越函数--1sg4gs3]] 与 [[concepts/反三角函数与反双曲函数]]。

## 复算过程与结论

以特值代入与恒等变形逐式验证（主值支取 $\ln$ 的 $-\pi < \varphi \leqslant \pi$ 约定）：

- **arcsin**：$\arcsin 0 = -\mathrm{i}\ln(\mathrm{i}\cdot 0 + \sqrt{1}) = -\mathrm{i}\ln 1 = 0$ ✓；$\arcsin 1 = -\mathrm{i}\ln(\mathrm{i}) = -\mathrm{i}\cdot\mathrm{i}\pi/2 = \pi/2$ ✓。多值式正确性另由恒等式验证：设 $u = \mathrm{i}z + \sqrt{1-z^2}$，则 $1/u = \sqrt{1-z^2} - \mathrm{i}z$（由 $(\sqrt{1-z^2})^2 + z^2 = 1$），故 $\sin(-\mathrm{i}\,Ln\,u) = \frac{u - 1/u}{2\mathrm{i}} = z$ ✓。
- **arctan**：$\arctan 0 = \frac{1}{2\mathrm{i}}\ln 1 = 0$ ✓；$\arctan 1 = \frac{1}{2\mathrm{i}}\ln\mathrm{i} = \pi/4$ ✓；一般地由 $e^{2\mathrm{i}w} = \frac{1+\mathrm{i}z}{1-\mathrm{i}z}$ 反解得 $\tan w = z$ ✓。
- **arccot**：等价变形 $-\frac{1}{2\mathrm{i}}\ln\frac{\mathrm{i}z+1}{\mathrm{i}z-1} = \frac{1}{2\mathrm{i}}\ln\frac{z+\mathrm{i}}{z-\mathrm{i}}$（利用 $\frac{\mathrm{i}z+1}{\mathrm{i}z-1} = \frac{z-\mathrm{i}}{z+\mathrm{i}}$）✓；特值 $\operatorname{arccot} 1 = \pi/4$（代入得 $-\frac{1}{2\mathrm{i}}\ln(-\mathrm{i}) = \pi/4$，与 $\cot(\pi/4) = 1$ 一致）✓、$\operatorname{arccot} 0 = -\pi/2$（与 $\cot(-\pi/2) = 0$ 一致）✓。
- **arsinh / arcosh / artanh / arcoth**：$\operatorname{arsinh} 0 = \ln 1 = 0$ ✓；$\operatorname{arcosh} 1 = \ln 1 = 0$ ✓；$\operatorname{artanh} 0 = 0$ ✓；各多值式与主值式成对结构一致 ✓。

**结论**：十六个公式全部复算通过；唯一的系统性问题是 (14.83a)、(14.84a) 多值语境的小写 $\ln$ 记号（疑应为 $Ln$，见 [[queries/式14-83a与14-84a多值式ln疑为Ln]]）——若按字面 $\ln$ 理解，该二式只是主值式 (14.87a)、(14.88a) 的重复，与源文“这些函数都是多值函数”的引语矛盾。

## 证据强度

本组为标准对数表示式，特值验证与恒等变形双重交叉，证据强度高。复算为一次性验证；公式本身可独立重推。
