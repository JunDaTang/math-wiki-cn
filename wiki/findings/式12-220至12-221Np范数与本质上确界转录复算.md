# 式 12.220–12.221 N_p 范数与本质上确界转录复算

## 转录

```latex
N_p(f) = (∫ |f|^p dμ)^{1/p}（可能等于 ∞），1 ⩽ p < ∞     (12.220)
N_∞(f) = ess sup f = inf{a ∈ ℝ : |f(x)| ⩽ a μ-a.e.}       (12.221)
```

## 复算

- (12.220)：|f|ᵖ 的可测性由可测函数闭包性质 f)（f ⩾ 0, p > 0 ⟹ fᵖ 可测）保证，N_p 定义合法。✓
- p 次幂可积 ⟺ N_p(f) < ∞ ⟺ |f|ᵖ 可积，等价性复算通过。✓
- (12.221)：{a : |f| ⩽ a μ-a.e.} 为向下封闭的集合，inf 在 ℝ̄ 中存在；N_∞(f) = 0 ⟺ f = 0 μ-a.e.。✓
- N_p 在 𝓛^p 上是准范数（拟范数）：绝对齐次与三角不等式依赖积分的闵可夫斯基不等式（回指第 41 页 1.4.2.13，未入库）；N_p(f) = 0 仅得 f = 0 μ-a.e.，零空间 N_p^{-1}(0) 为 a.e. 为零函数全体（非平凡），故非真范数。✓
- 商空间化：𝓛^p / N_p^{-1}(0) 上 ‖f̂‖_p = N_p(f) 成为真范数；(L^p(μ), ‖·‖_p) 为巴拿赫格；p = 2 时 (f, g) = ∫ f ḡ dμ 使 L²(μ) 成为希尔伯特空间。结构断言复算限于自洽性核对（范数与序相容、K 空间断言回指 12.1.7.4）。✓
- 有限测度嵌入：μ(X) < ∞、1 ⩽ p₁ < p₂ ⩽ ∞ 时 L^{p₂} ⊂ L^{p₁} 且 ‖x‖_{p₁} ⩽ C‖x‖_{p₂}，C 与 x 无关。复算（推断性核对，非手册原文）：由 |f|^{p₁} ⩽ 1 + |f|^{p₂}（Young 不等式思路）积分即得，常数 C 依赖 p₁, p₂, μ(X)。✓
- 完备化视角：L^p(Ω, λ) 是赋积分范数 ‖x‖_p = (∫|x|ᵖ dλ)^{1/p} (1 ⩽ p < ∞) 的不完备赋范空间 𝒞(Ω) 的完备化，与 12.2.2.5/12.3.2 完备化理论衔接。✓

## 疑点

- 稠密性段落开头限定 1 ⩽ p ⩽ ∞，但 𝒞^k(Ω̄)、𝒞_0^∞(Ω) 在 L^p 中稠密仅对 p < ∞ 成立（p = ∞ 情形连续函数不一致逼近本质有界函数）。见 [[queries/Ck稠密性是否应限定p小于无穷]]。
