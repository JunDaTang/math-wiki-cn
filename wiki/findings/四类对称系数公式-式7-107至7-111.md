# 四类对称系数公式（式 7.107–7.111）

## 主张（依源转录）

周期为 T 的周期函数 f(x) 按对称类型使部分傅里叶系数恒为零（k = 0, 1, 2, …）：

```latex
% (7.107) 第一类对称：偶函数 f(x) = f(-x)，图 7.2
a_k = (4/T) Int_0^{T/2} f(x) cos(k·2pi x/T) dx,   b_k = 0

% (7.108) 第二类对称：奇函数 f(x) = -f(-x)，图 7.3
a_k = 0,   b_k = (4/T) Int_0^{T/2} f(x) sin(k·2pi x/T) dx

% (7.109a/b) 第三类对称：f(x + T/2) = -f(x)，图 7.4
a_{2k+1} = (4/T) Int_0^{T/2} f(x) cos((2k+1)·2pi x/T) dx,   a_{2k} = 0
b_{2k+1} = (4/T) Int_0^{T/2} f(x) sin((2k+1)·2pi x/T) dx,   b_{2k} = 0

% (7.110) 第四类对称（奇函数 且 第三类），图 7.5(a)
a_k = b_{2k} = 0,   b_{2k+1} = (8/T) Int_0^{T/4} f(x) sin((2k+1)·2pi x/T) dx

% (7.111) 第四类对称（偶函数 且 第三类），图 7.5(b)
b_k = a_{2k} = 0,   a_{2k+1} = (8/T) Int_0^{T/4} f(x) cos((2k+1)·2pi x/T) dx
```

## 复算（结构确认，全部通过）

1. **第一/二类**：a_k = (2/T)∫_{−T/2}^{T/2} f cos（偶×偶 = 偶）= (4/T)∫₀^{T/2} f cos；b_k = (2/T)∫f sin（偶×奇 = 奇）= 0。奇函数对偶。✅
2. **第三类**：∫₀^T = ∫₀^{T/2} + ∫_{T/2}^T，第二项经 x = u + T/2，用 f(u+T/2) = −f(u) 与 cos/sin(kω(u+T/2)) = (−1)^k cos/sin(kωu)（因 kωT/2 = kπ），合并得因子 [1 − (−1)^k]：k 偶为零（a_{2k} = b_{2k} = 0），k 奇为 2 倍（故前 4/T、积分限 [0, T/2]、只含奇下标）。✅
3. **第四类·奇（7.110）**：奇 ∧ 第三类 ⟹ 在 [0, T/2] 上 f(T/2 − x) = f(x)（关于 x = T/4 偶）；而 sin((2k+1)·2πx/T) 关于 T/4 亦偶（sin((2k+1)(π − θ)) = sin((2k+1)θ)）。乘积关于 T/4 偶，∫₀^{T/2} = 2∫₀^{T/4}，故前 8/T、积分限 [0, T/4]。✅
4. **第四类·偶（7.111）**：偶 ∧ 第三类 ⟹ f(T/2 − x) = −f(x)（关于 T/4 奇）；cos((2k+1)·2πx/T) 关于 T/4 奇（cos((2k+1)(π − θ)) = −cos((2k+1)θ)）。乘积关于 T/4 偶，同样 ∫₀^{T/2} = 2∫₀^{T/4}。✅
