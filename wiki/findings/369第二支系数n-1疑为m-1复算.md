# 369 第二支系数 n-1 疑为 m-1 复算

∫dx/(sinⁿax cosᵐax) 的双支递推（转写无编号，按 359–369 区复原约为条目 369，见 [[findings/21-7-3编号脱落与359至369错乱复原]]）转写原文：

```latex
% 第一支（降低指数 n）——复算无误
= -\frac{1}{a(n-1)}\cdot\frac{1}{\sin^{n-1} ax\cos^{m-1} ax} + \frac{n+m-2}{n-1}\int\frac{dx}{\sin^{n-2} ax\cos^{m} ax}
% 第二支（降低指数 m）——系数疑误
= \frac{1}{a(m-1)}\cdot\frac{1}{\sin^{n-1} ax\cos^{m-1} ax} + \frac{n+m-2}{n-1}\int\frac{dx}{\sin^{n} ax\cos^{m-2} ax}
```

## 复算

对边界项 g = 1/(sin^{n−1}x cos^{m−1}x) 求导：g′ = −(n−1)/(sinⁿx cos^{m−2}x) + (m−1)/(sin^{n−2}x cosᵐx)；结合恒等式 1/(sinⁿcosᵐ) = 1/(sin^{n−2}cosᵐ) + 1/(sinⁿcos^{m−2})（由 sin²+cos²=1 除以 sinⁿcosᵐ 而得）可证第一支成立。第二支由同一 g′ 对称导出，系数必为：

```latex
= \frac{1}{a(m-1)}\cdot\frac{1}{\sin^{n-1} ax\cos^{m-1} ax} + \frac{n+m-2}{m-1}\int\frac{dx}{\sin^{n} ax\cos^{m-2} ax}
```

按原文系数 (n+m−2)/(n−1) 求导，右端化简后须满足 (n+m−2)/(n−1) = (n+m−2)/(m−1)，仅当 n=m 等退化情形巧合成立，一般情况下不能还原被积函数；且分母 n−1 与本支「降 m」的语义不相称（第一支已用 n−1）。
