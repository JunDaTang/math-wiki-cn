# 式 9.77–9.78 典范组与克莱罗 PDE 转录复算

本条目逐字转录 [[concepts/典范微分方程组]] 的理论组（式 9.77a–e）与克莱罗微分方程的偏微分方程推广（式 9.78a–b），并对 Jacobi 定理与克莱罗完全积分作独立复算。注意：9.77a–b 的化归叙述在转写稿中残缺，本条的复算属结构性验证（与标准理论一致），文本忠实度存疑。

## 逐字转录

```latex
V(x₁,…,xₙ, z) = C                                              (9.77a)
p + H(x₁,…,xₙ, x, p₁,…,pₙ) = 0,  p = ∂V/∂x,  pᵢ = ∂V/∂xᵢ        (9.77b)
dxᵢ/dx = ∂H/∂pᵢ,  dpᵢ/dx = −∂H/∂xᵢ   (i = 1,…,n)               (9.77c)
dV/dx = p₁∂H/∂p₁ + … + pₙ∂H/∂pₙ − H,  dp/dx = −∂H/∂x           (9.77d)
V = φ(x₁,…,xₙ, x, a₁,…,aₙ) + a                                 (9.77e)

z = x₁p₁ + … + xₙpₙ + f(p₁,…,pₙ),  pᵢ = ∂z/∂xᵢ                 (9.78a)
z = a₁x₁ + … + aₙxₙ + f(a₁,…,aₙ)                               (9.78b)
```

源文断言：(9.77c) 是相应于 2n+1 个变量的任意函数 H 的 2n 个常微分方程的方程组，称为典范组（canonical system）或正规组（normal system）；知道 (9.77b) 的一个完全积分 (9.77e)，即可由 ∂φ/∂aᵢ = bᵢ 与 pᵢ = ∂φ/∂xᵢ（i = 1,…,n）确定典范组含 2n 个任意参数的通解。

## 复算

1. **Jacobi 定理核对**：设 V = φ(x₁,…,xₙ, x, a₁,…,aₙ) + a 为 (9.77b) 的完全积分，代入 pᵢ = φ_{xᵢ} 得恒等式 φ_x + H(x₁,…,xₙ, x, φ_{x₁},…,φ_{xₙ}) = 0。
   - 关于 aᵢ 求导：φ_{xaᵢ} + Σⱼ H_{pⱼ}φ_{xⱼaᵢ} = 0；
   - 对 ∂φ/∂aᵢ = bᵢ 沿解关于 x 作全导数：φ_{xaᵢ} + Σⱼ φ_{xⱼaᵢ}·dxⱼ/dx = 0。
   
   两式相减得 Σⱼ(H_{pⱼ} − dxⱼ/dx)φ_{xⱼaᵢ} = 0（对一切 i）；矩阵 (φ_{xⱼaᵢ}) 正是完全积分雅可比条件对应的矩阵，可逆，故 dxⱼ/dx = H_{pⱼ}，即 (9.77c) 第一组。✅
   - 再由 pᵢ = φ_{xᵢ} 的全导数与上述恒等式关于 xᵢ 的偏导数比较，得 dpᵢ/dx = −H_{xᵢ}，即 (9.77c) 第二组。✅
   - (9.77d) 第一式核对：dV/dx = Σᵢpᵢ·dxᵢ/dx + p = ΣᵢpᵢH_{pᵢ} + p，而由 (9.77b) 有 p = −H，故 dV/dx = ΣpᵢH_{pᵢ} − H。✅
2. **克莱罗 PDE 完全积分 (9.78b) 验证**：z = Σaᵢxᵢ + f(a₁,…,aₙ) 给出 z_{xᵢ} = aᵢ = pᵢ，代回 (9.78a) 两端恒等；且 ∂(φₓ₁,…,φₓₙ)/∂(a₁,…,aₙ) = ∂(a₁,…,aₙ)/∂(a₁,…,aₙ) = 1 ≠ 0，满足完全积分条件 (9.76c)。✅
3. **与 ODE 克莱罗方程的平行**：通解均为「以参数直接替换导数」（直线族 y = Cx + f(C) ↔ 平面族 z = Σaᵢxᵢ + f(a)），且均伴生包络型奇异积分，见 [[concepts/克莱罗微分方程]]。

## 转写疑点（9.77a–b 化归叙述残缺——数学内容可信，文本忠实度存疑）

1. 「有时考虑一个不显式地包含未知函数 的方程」缺 z。
2. 「通过引进一个附加的自变量 x_{n+1} = z 和一个用方程 (9.77a) 来定义函数 z(x₁,…,xₙ) 的未知函数 V(x₁,…,xₙ,x_{n+1})」句读与逻辑断裂：附加自变量记 x_{n+1} 而 (9.77a) 中却写作 z；用 −(∂V/∂xᵢ)/(∂V/∂x_{n+1}) 替代 ∂z/∂xᵢ 的化归步骤叙述不完整。
3. 「相应的自变量将记作 X」（大写）与 (9.77b) 中的小写 x 不一致，且与 (9.76e) 的 Xᵢ = ∂F/∂xᵢ 记号冲突。
4. 本条对化归细节只作结构性复算（结果与标准理论一致），细节待原书核对，见 [[queries/9-2-1全节系统性转写讹误清单]]。

## 意义

式 9.77 是连接力学与理论物理的枢纽：完全积分 ⟷ 典范组通解（Jacobi 定理）。标准文献称 (9.77b) 型方程为哈密顿-雅可比方程（源文本节未使用该名称），二体问题算例完整演示了该链条，见 [[findings/式9-79哈密顿二体问题算例复算]]。
