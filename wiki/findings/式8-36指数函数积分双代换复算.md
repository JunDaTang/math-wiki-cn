# 式 8.36 指数函数积分双代换（逐字转录与复算）

## 逐字转录

数学手册(原书第10版) 8.1.6.1（转写文本原样）：

```latex
\int R (\mathrm{e} ^ {m x}, \mathrm{e} ^ {n x}, \dots , \mathrm{e} ^ {p x}) \mathrm{d} x\tag{8.36a}

\int \frac {1}{t} R (t ^ {m}, t ^ {n}, \dots , t ^ {p}) \mathrm{d} t.\tag{8.36b}

z = { \sqrt [ { e } ] { t } } , 其中 是分数 m, n, \cdots, p 的分母的最小公倍数
```

配套原文：「形如 (8.36a) 的指数函数的积分可以化简成有理函数的积分，其中 $m, n, \cdots, p$ 为有理数。计算该积分需要作两个代换：(1) $t = \mathrm{e}^{x}$，有积分 (8.36b)；(2) $z = \sqrt[{e}]{t}$，其中 [脱字] 是分数 $m, n, \cdots, p$ 的分母的最小公倍数，可以将其化为有理函数积分。」

注意两点：①「其中」后的根指数字母在转写中脱字，且根指数记作 $e$，与欧拉常数 $\mathrm{e}$ 同形（见 [[queries/根指数字母e是否原书记号]]）；②原书指数函数一律用正体 $\mathrm{e}^{mx}$，根指数用斜体 $e$，正斜体之别或即原书的区分方式（待查证）。

## 复算验证

**第一代换**：设 $t = \mathrm{e}^{x}$，则 $\mathrm{d}t = \mathrm{e}^{x}\,\mathrm{d}x = t\,\mathrm{d}x$，即 $\mathrm{d}x = \mathrm{d}t/t$；且 $\mathrm{e}^{mx} = (\mathrm{e}^{x})^{m} = t^{m}$，同理 $\mathrm{e}^{nx} = t^{n}$ 等。代入式 8.36a，确得式 8.36b。✓

**第二代换**：记根指数字母为 $e$（按原文记号）。由 $e$ 为各分数分母的最小公倍数知 $em, en, \dots, ep$ 均为整数（$m$ 等可为负有理数，负整幂即 $1/z^{k}$，仍属有理函数）。令 $z = t^{1/e}$，即 $t = z^{e}$，则：

- $t^{m} = z^{em}$ 为整幂；$1/t = z^{-e}$ 为整幂；
- $\mathrm{d}t = e\,z^{e-1}\,\mathrm{d}z$。

代入式 8.36b：

$$\int \frac{1}{t}R(t^{m},\dots,t^{p})\,\mathrm{d}t = \int z^{-e}\,R(z^{em},\dots,z^{ep})\cdot e\,z^{e-1}\,\mathrm{d}z = e\int \frac{1}{z}\,R(z^{em},\dots,z^{ep})\,\mathrm{d}z$$

右端是 $1/z$ 与整幂的有理组合，即 $z$ 的有理函数积分。✓ 论断「可以将其化为有理函数积分」成立。

## 判定

- 式 8.36a→8.36b 及根式代换的有理化作用**均通过复算**；方法为标准结果，证据强度高。
- 复算补充说明：第二次代换后积分仍呈式 8.36b 的形态（系数 $1/z$），只是幂次全部变为整数——即两次代换的分工是「消指数结构」与「消分数幂」，与原文表述一致。
- 转写问题（「其中」后脱字、根指数字母与欧拉常数撞名）不影响数学内容，归入 [[queries/8-1-6全节系统性转写讹误清单]] 与 [[queries/根指数字母e是否原书记号]]。
