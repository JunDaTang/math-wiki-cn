# 式17-61至17-66重构公式转录复算

## 转录（已修复纯 OCR 括号/空格噪声；实质疑讹保留原样）

```latex
(17.61) 阶为 m、方向 κ ∈ {−1,1}、步长 τ > 0 的时间序列：
{ h(φ^{kτ}(p)), h(φ^{(k+κ)τ}(p)), …, h(φ^{(k+(m−1)κ)τ}(p)) }_{k=m−1}^{∞}

(17.62) 微分同胚版重构映射（前向坐标）：
p ∈ U ↦ Φ_{φ,h}(p) = ( h(p), h(φ¹(p)), …, h(φ^{m−1}(p)) )

(17.63) 向量场版重构映射（前向坐标）：
p ∈ U ↦ Φ_{f,h}(p) = ( h(p), h(φ¹(p)), …, h(φ^{m−1}(p)) )

(17.64) SYC 重构函数（逆时序书写）：
p ∈ U ↦ Φ_{f,h,τ}(p) = ( h(φ^{(m−1)τ}(p)), h(φ^{(m−2)τ}(p)), …, h(p) )

(17.65) 重构向量（嵌入维数为 m+1），y_i = h(φ^i(p))：
x_i = ( y_i, y_{i+1}, …, y_{i+m} ) ∈ ℝ^{m+1}

(17.66) 相关积分与相关维数估计（源文左端记号 C^m(φ) 疑为 C^m(ε)）：
dist(x_i, x_j) = max_{0 ≤ s ≤ m} | y_{i+s} − y_{j+s} |
C^m(ε) = limsup_{N→∞} (1/N²) · #{ (x_i, x_j) : i, j ∈ {1,…,N}, dist(x_i, x_j) < ε }
d_K(m) = lim_{ε→0} ln C^m(ε) / ln ε
```

## 复算与核验

- **(17.61)**：下标 $k$ 从 $m-1$ 起始，保证每个时滞窗口满长 $m$；$\kappa$ 控制时间方向；$\tau$ 为步长。源文 $h(\varphi^{k\tau(p)})$ 括号错位（应为 $h(\varphi^{k\tau}(p))$，式内三处同）。
- **(17.62)/(17.63)**：两式逐字相同，区别仅在参数（微分同胚 $\varphi$／向量场 $f$，后者 $\varphi^t$ 为流）；前向坐标、单位步长。
- **(17.64)**：SYC 版按逆时序书写（分量从 $h(\varphi^{(m-1)\tau}(p))$ 递降到 $h(p)$），与 $\kappa = -1$ 的逆向坐标一致；步长 $\tau$ 显式出现在指数中。
- **(17.65)–(17.66)**：$x_i$ 由 $m+1$ 个连续观测组成，阶数参数为 $m$ 而**嵌入维数为 $m+1$**；距离取 max 范数；$C^m(\varepsilon)$ 以 $\limsup$ 与 $1/N^2$ 归一（计数含 $i = j$ 的对角项，贡献 $N/N^2 \to 0$，不影响极限）；$\ln \varepsilon < 0$ 且 $C^m(\varepsilon) \to 0$，故 $d_K(m) = \ln C^m(\varepsilon)/\ln\varepsilon$ 的符号自洽（非负维数）。
- **阈值调和（关键）**：17.2.7.1.3 的 $m \ge 2n+1$ 与 17.2.7.2.3 的 $m \ge 2n$ 通过 (17.65) 的 $x_i \in \mathbb{R}^{m+1}$ 调和：$m + 1 \ge 2n+1 \iff m \ge 2n$。表面不一致不构成实质矛盾，但引用时必须显式说明**嵌入维数是 $m+1$**，以免误传。
- **一维算例复算**：$\dot x = -x$，$\varphi^t(x) = x\mathrm{e}^{-t}$，$m = 3$。
  - $h_1(x) = x$：按 (17.63) 应有 $\Phi_{f,h_1}(x) = (x,\, x\mathrm{e}^{-1},\, x\mathrm{e}^{-2})$；源文第三分量作 $x\mathrm{e}^{-1}$（疑讹，见 [[queries/一维算例第三分量xe⁻¹疑为xe⁻²之辨]]）。两种写法下映射均由第一分量恢复原像（单射），导数 $(1, \mathrm{e}^{-1}, \mathrm{e}^{-2})^\top$（或源文版 $(1, \mathrm{e}^{-1}, \mathrm{e}^{-1})^\top$）秩为 1，且是到像的同胚——「$\mathbb{R}^3$ 上嵌入」的结论不受影响。
  - $h_2$：源文定义脱文；由像 $(x^2, x^2\mathrm{e}^{-2}, x^2\mathrm{e}^{-4})$ 反推 $h_2(x) = x^2$（三分量逐一吻合）。$h_2(-x) = h_2(x)$，非单射 → 非嵌入，与源文结论一致（见 [[queries/h₂定义脱文之辨]]）。

## 结论

各式在修复 OCR 噪声后数学自洽；三处实质疑讹（第三分量 $x\mathrm{e}^{-2}$、$h_2$ 定义、$C^m(\varepsilon)$ 记号）不改变定理与算例结论的方向，但精确表述（尤其 SYC 定理的条件结构）须对照原书核验——见 [[queries/17-2-7全节系统性转写讹误清单]] 及其分查询。
