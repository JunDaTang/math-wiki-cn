# 谓词与量词的语法定义与命题演算的嵌入（式 5.21–5.22）

《数学手册(原书第10版)》5.1.2 的语法骨架：

- **个体区域（全域）X**：被研究对象的集合，例取自然数集 ℕ。
- **n 位谓词**：指派 P: Xⁿ → {F,T}，对每个 n 元个体组派定一个真值；「n 是素数」为一位谓词、「m 小于 n」为二位谓词。
- **量词语义**：∀xP(x) ⇔「P(x) 对于 X 中的每个 x 真」；∃xP(x) ⇔「在 X 中存在 P(x) 真的 x」。对一元谓词应用量词就给出一个语句；例（素数谓词 P 于 ℕ）：∀nP(n) 是假语句，∃nP(n) 是真语句。

**公式的归纳定义**：

```latex
(1) 若 x₁,…,xₙ 是个体变量, P 是 n 位谓词符号, 则 P(x₁,…,xₙ) 是公式（基本公式）  % (5.21)
(2) 若 A, B 是公式, 则 (¬A), (A∧B), (A∨B), (A⇒B), (A⇔B), (∀x A), (∃x A) 也是公式  % (5.22)
```

**嵌入主张**：将命题变量看作零位谓词，命题演算可以看作谓词演算的一个部分。

**证据类型**：直接证据（定义性与结构性内容，无复算之需）。转写注记：(5.22) 条款及自由/约束变元定义句中存在「\/」等乱码（见 [[queries/5-1全节转写讹误清单]]）。
