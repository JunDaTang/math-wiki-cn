# 式 9.73–9.75 非齐次特征组、积分曲面与柯西问题转录复算

本条目逐字转录非齐次线性和拟线性方程的化归组（式 9.73a–b）、两变量情形的几何表示（式 9.74a–b）与 [[concepts/柯西问题]] 的定义组（式 9.75a–c），并复算源文给出的两个算例（旋转曲面、指数曲面）。

## 逐字转录

```latex
X₁ ∂V/∂x₁ + … + Xₙ ∂V/∂xₙ + Y ∂V/∂z = 0                        (9.73a)
dx₁/X₁ = … = dxₙ/Xₙ = dz/Y                                      (9.73b)

P(x,y,z) ∂z/∂x + Q(x,y,z) ∂z/∂y = R(x,y,z)                     (9.74a)
dx/P(x,y,z) = dy/Q(x,y,z) = dz/R(x,y,z)                        (9.74b)

xᵢ = xᵢ(t₁,…,tₙ₋₁)                                              (9.75a)
z = φ(x₁,…,xₙ)                                                  (9.75b)
φ[x₁(t₁,…,tₙ₋₁), …, xₙ(t₁,…,tₙ₋₁)] = ψ(t₁,…,tₙ₋₁)              (9.75c)
```

## 化归与几何解释

- 非齐次/拟线性方程 (9.71a)：尝试求隐形式 V(x₁,…,xₙ,z) = C 的解 z，归结为 n+1 个自变量的线性齐次方程 (9.73a)；其特征组 (9.73b)（比齐次情形多一维 dz/Y）被称为原方程的特征组。
- 两变量情形 (9.74a)：解 z = f(x,y) 是 x,y,z 空间中的积分曲面；在曲面每点处法向量 (z_x, z_y, −1) 垂直于该点给定的向量 (P, Q, R)；组 (9.74b) 的积分曲线（特征）与 (P, Q, R) 相切；与积分曲面有一个公共点的特征完全落在该曲面上，积分曲面由特征组成。积分曲线概念回指 13.1.3.5（未入库，见 [[queries/9-2-1未入库回指缺口]]）。

## 柯西问题的适定条件（一阶特有）

沿 (n−1) 维参数化初始流形 (9.75a) 要求解取给定值 ψ（9.75c）。两变量情形归结为求过给定曲线的积分曲面：若初始曲线具有连续（转动）的切线，且在任何点都不与特征相切，则柯西问题在该曲线的一个邻域中有唯一解；积分曲面由与初始曲线相交的所有特征组成。

注意：此唯一性条件是**一阶方程特有的**，与 9.2.3 波方程柯西问题的适定条件（[[concepts/问题的正确叙述]]）分属不同机制，不可互相移植。存在性定理的进一步讨论回指文献 [9.26]。

## 算例 A：旋转曲面（复算通过）

方程 (mz−ny)z_x + (nx−lz)z_y = ly−mx（l, m, n 为常数），特征组 dx/(mz−ny) = dy/(nx−lz) = dz/(ly−mx)。源文给出积分 lx+my+nz = C₁ 与 x²+y²+z² = C₂，并断言特征为圆、圆心位于过原点且方向余弦与 (l,m,n) 成比例的直线上、积分曲面为以该直线为轴的旋转曲面。

复算：
1. d/dt(lx+my+nz) = l(mz−ny) + m(nx−lz) + n(ly−mx) = 0（六项两两相消）。✅
2. d/dt(x²+y²+z²) = 2[x(mz−ny) + y(nx−lz) + z(ly−mx)] = 0。✅
3. 特征是平面 lx+my+nz = C₁（法向 (l,m,n)）与球面 x²+y²+z² = C₂（球心为原点）的交线，即圆；圆心为原点到该平面的垂足，位于过原点、方向 (l,m,n) 的直线上。✅
4. 由这些圆织成的积分曲面即以该直线为轴的旋转曲面；隐式通解为 Φ(lx+my+nz, x²+y²+z²) = 0。✅

## 算例 B：指数曲面（复算通过）

方程 z_x + z_y = z，求过曲线 x = 0, z = φ(y) 的积分曲面。特征组 dx/1 = dy/1 = dz/z；过点 (x₀, y₀, z₀) 的特征为 y = x − x₀ + y₀, z = z₀e^{x−x₀}。置换 x₀ = 0, z₀ = φ(y₀) 得参数式 y = x + y₀, z = eˣφ(y₀)；消去 y₀ 得 z = eˣφ(y−x)。

复算：z_x + z_y = eˣφ(y−x) − eˣφ′(y−x) + eˣφ′(y−x) = eˣφ(y−x) = z。✅ 初始线上 x = 0 给出 z = φ(y)。✅ 通解形状为 z = eˣΨ(y−x)，柯西数据即选取 Ψ = φ。✅

## 转写疑点

- 「连续依赖的切线」疑为「连续转动的切线」（原文疑为 stetig drehende Tangente）之误译。
- (9.75a) 前「给定 个自变量」缺数目词 n−1。
- 「函数 n+1 个自变量的线性齐次微分方程的一个解」语序错乱（应为「n+1 个自变量的（函数的）线性齐次微分方程的一个解」类表述）。
- 「与柯西问题解的存在性有关的一些定理更多的数学讨论见 [9.26]」语序不通，疑有脱文。
- 「垂直千」「由千」「对千」等「千」讹「于」。
