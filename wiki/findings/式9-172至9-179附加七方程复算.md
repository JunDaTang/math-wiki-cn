# 式 9.172–9.179 附加七方程转录复算

## 转录内容（逐字）

```latex
(9.172)  变形 KdV:       u_t ± 6 u^2 u_x + u_{xxx} = 0
(9.173)  广义 KdV:       u_t + u^p u_x + u_{xxx} = 0
(9.175)  双曲正弦戈登:   u_{tt} − u_{xx} + sinh u = 0
(9.176)  布西内斯克:     u_{xx} − u_{tt} + (u^2)_{xx} + u_{xxxx} = 0
(9.177)  广田方程:       u_t + i 3α |u|^2 u_x + β u_{xx} + i σ u_{xxx} + δ |u|^2 u = 0,
                          αβ = σδ
(9.178)  伯格斯方程:     u_t − u_{xx} + u u_x = 0
(9.179a) KP:             (u_t + 6 u u_x + u_{xxx})_x = u_{yy}
(9.179b) KP lump:        u = 2 ∂²/∂x² ln[ 1/k² + |x + i k y − 3k² t|² ]
(9.174)  广义 KdV 孤子:  u = [ (½|v|(p+1)(p+2)) / cosh²(½ p √|v| (x − v t − φ)) ]^{1/p}
```

## 复算结论

- **(9.174)**（high）：p = 1、p = 2 直接代入 (9.173) 验证成立；振幅满足 A^p = ½|v|(p+1)(p+2)，宽度参数 B = ½p√|v|。
- **(9.179a) 疑漏因子 3**（high）：双线性计算表明 (9.179b) 的 F = 1/k² + (x − 3k²t)² + k²y² 恰满足 (D_xD_t + D_x⁴ − 3D_y²)F·F = 0，即 (9.179b) 是 **(u_t + 6uu_x + u_{xxx})_x = 3u_{yy}**（KPI 型）的精确 lump 解；对转写式「…_x = u_{yy}」代入则得到不恒为零的残差（复算记号下为 8k²[s² − 2a − k²y² + 3/k²]）。lump 速度 3k² 与常数项 1/k² 均只在含 3 的版本中自洽。见 [[queries/式9-179a右端是否漏因子3]]。
- **(9.178)**（high）：为 ν = 1 情形的标准 Burgers 方程；Hopf-Cole 变换线性化为扩散方程的陈述正确，见 [[methodology/霍普夫-科尔变换线性化]]。
- **(9.177)**（medium）：按转写，NLS 极限（α = σ = 0）为实系数方程 u_t + βu_{xx} + δ|u|²u = 0，不支持包络孤子，与本节标题「具有孤子解」矛盾；标准文献中 i 应落在 u_t 项（或实时间形式下移至 u_{xx}、|u|²u 项）。约束 αβ = σδ 的正确性待核对德文原书。见 [[queries/式9-177广田方程i的位置与参数约束]]。
- **(9.172)、(9.175)、(9.176)**：形式与标准 mKdV、sinh-Gordon、Boussinesq 方程一致；源文仅给出方程与一句出现场景，无解式可复算。
