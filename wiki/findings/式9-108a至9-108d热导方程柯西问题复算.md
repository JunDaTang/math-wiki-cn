# 式 9.108a–d 热导方程柯西问题复算

本 finding 记录 9.2.3.3.1 三维热导方程组（式 9.108a–d）的逐字转录与独立复算结论。

## 逐字转录

```latex
(9.108a)  \frac{\partial u}{\partial t} - a^{2}\Delta u = Q(x, t)
(9.108b)  u(x_{1}, x_{2}, x_{3}, t) = \frac{1}{(2a\sqrt{\pi t})^{n}}
            \iiint f(\alpha_{1}, \alpha_{2}, \alpha_{3}) \cdot
            \exp\!\left(-\frac{(x_{1}-\alpha_{1})^{2} + (x_{2}-\alpha_{2})^{2} + (x_{3}-\alpha_{3})^{2}}{4a^{2}t}\right)
            \mathrm{d}\alpha_{1}\mathrm{d}\alpha_{2}\mathrm{d}\alpha_{3}
(9.108c)  \int_{0}^{t} \left[ \iiint \frac{Q(\alpha_{1}, \alpha_{2}, \alpha_{3})}{[2a\sqrt{\pi(t-\tau)}]^{n}}
            \cdot \exp\!\left(-\frac{(x_{1}-\alpha_{1})^{2} + (x_{2}-\alpha_{2})^{2} + (x_{3}-\alpha_{3})^{2}}{4a^{2}(t-\tau)}\right)
            \mathrm{d}\alpha_{1}\mathrm{d}\alpha_{2}\mathrm{d}\alpha_{3} \right] \mathrm{d}\tau
(9.108d)  \frac{\partial T}{\partial t} - D_{W}\Delta T = Q_{W}(\vec{r}, t)   % u = T(温度场), a^2 = D_W
```

（9.108b、9.108c 中的三重积分限均为 −∞ 到 +∞。）

源文要点：均匀介质中热的传播由二阶线性抛物型偏微分方程（9.108a）描述；热流既无源又无汇时 Q = 0；柯西问题为对 t > 0 确定满足 u|_{t=0} = f(x) 的**有界解**，有界性的要求保证了解的唯一性；如果给出值 u(x, 0)，用这个方法不能解确定 t < 0 时 u(x, t) 的问题，因为在此情形不能正确形成柯西问题。

## 复算结论（独立推导，非源文内容）

- **式 9.108b 前因子**：1/(2a√(πt))ⁿ 中 (2a√(πt))ⁿ = 2ⁿaⁿ(πt)^{n/2} = (4πa²t)^{n/2}，故前因子即 1/(4πa²t)^{n/2}——标准 n 维热核（高斯核）的前因子；指数项 −|x−α|²/(4a²t) 亦与标准热核一致。
- **式 9.108c 结构**：∫₀ᵗ [热核(t−τ) ∗ Q] dτ 的杜哈梅尔型卷积，结构正确；但被积函数印作 Q(α₁, α₂, α₃)，卷积结构数学上要求 Q(α₁, α₂, α₃, τ)，**疑缺 τ 变元**（对照式 9.107b、9.107c 中 Q(ξ₁, ξ₂, τ)、Q(ξ, τ) 均带 τ），见 [[式9-108c的Q是否缺tau变元]]。
- t < 0 方向不适定：与热核在 t → 0⁻ 时发散/无界一致（结构性佐证）；该结论源明示，仅属热导方程。

- 小节标题“三维热导方程”与指数 n、三重积分的口径不一致：[[式9-108b指数n与三维标题是否原书即不一致]]。
- 9.2.3.3.2 称 9.108b/c 为“波方程的解”：[[式9-108b与9-108c是否被误称为波方程的解]]。
- D_W 并称“热扩散常数或热导率”：严格而言热扩散率（thermal diffusivity）与热导率（thermal conductivity）是不同物理量，中译并称有不确之嫌。
