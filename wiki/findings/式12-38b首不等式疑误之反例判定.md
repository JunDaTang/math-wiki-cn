# 式 12.38b 首不等式疑误之反例判定

## 问题

源文 (12.38b) 转录为三条不等式：

```
(x+y)₊ ≤ x₊ + x₋,    (x+y)₋ ≤ x₋ + y₋,    |x+y| ≤ |x| + |y|        (12.38b 转录原文)
```

首不等式右端出现 x₊ 与 x₋ 相加，形式反常（正部与负部混加）。

## 判定：首不等式按转录为假命题，应为 (x+y)₊ ≤ x₊ + y₊

**显式反例**：在 ℝ（任何向量格中取正元亦同）取 x = y = 1：

- 左端：(x+y)₊ = 2∨0 = 2；
- 右端：x₊ + x₋ = 1 + 0 = 1；
- 2 ≤ 1 不成立。✗

**正确形式及其证明**：(x+y)₊ ≤ x₊ + y₊。由 x ≤ x₊、y ≤ y₊ 得 x + y ≤ x₊ + y₊；又 0 ≤ x₊ + y₊；故 (x+y)∨0 ≤ x₊ + y₊。✓（反例中 2 ≤ 2 成立。）

**次项与末项无误**：

- (x+y)₋ ≤ x₋ + y₋：由 (−x−y)₊ ≤ (−x)₊ + (−y)₊（即修正后的首不等式）立得；数值抽检 x = y = −1 时左 2 = 右 2，x = 1, y = −1 时左 0 ≤ 右 1。✓
- |x+y| ≤ |x| + |y|：向量格中的三角不等式，标准成立。✓

## 结论

(12.38b) 仅首不等式右端下标误植（x₋ 应为 y₊），属实质性数学讹误而非单纯转写噪声；判定由显式反例与一般证明双重支撑，置信度高。待对照原版确认系排印错误还是转写错误，见 [[queries/式12-38b首不等式正部相加对象疑误]]。已在 [[concepts/向量格与K空间]] 中以 (12.38b*) 标注修正形式。
