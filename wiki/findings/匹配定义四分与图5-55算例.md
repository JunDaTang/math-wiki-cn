# 匹配定义四分与图 5.55 算例

《数学手册(原书第10版)》5.8.4 条目 1 用四个定义界定匹配家族，并借图 5.55 的 M₁/M₂ 区分「饱和」与「极大」。定义组为手册式定义、内部自洽；算例经本维基复算核验。

## 定义组（逐字重构，▯ 表示转写脱落的变元，依上下文分别应为 M、G）

```text
▯(⊆E) 称为 ▯ 中的一个匹配，当且仅当 ▯ 不含环，并且 ▯ 的任何两条不同的边都没有公共端点。
G 的匹配 M* 称作饱和匹配，如果 ▯ 中不存在匹配 M 使得 M* ⊂ M。
G 的匹配 M** 称作极大匹配，如果 ▯ 中不存在匹配 M 使得 |M| > |M**|。
如果 ▯ 的匹配 ▯ 使得 ▯ 的每个顶点都是 ▯ 的一条边的端点，那么 ▯ 称为完全匹配。
```

## 图 5.55 算例（已复算）

![图 5.55](media/10-数学手册原书第10版--6-584-匹配--fcxne8/001-862d174ec67481ba41409d4cc629c7f46bb13d9d35dd56e373b3721081894f74.jpg)

```text
M₁ = {{2,3},{5,6}}         —— 饱和匹配
M₂ = {{1,2},{3,4},{5,6}}   —— 极大匹配，并且也是完全匹配
```

复算（直接证据：按定义逐一核验；前提为图 5.55 的隐含边集假设——至少含 {1,2}、{2,3}、{3,4}、{5,6}，且不含以 1、4 为两端点的边）：

- M₁ 是匹配：无环、无边共享端点 ✓
- M₁ 饱和：未被 M₁ 覆盖的顶点仅 1、4，而图中没有两端均未被覆盖的边，无法再添 ✓
- M₁ 非极大（基数意义）：M₂ 是匹配且 |M₂| = 3 > 2 = |M₁| ✓ —— **「饱和 ⇏ 极大」的教学点**
- M₂ 完全：{1,2}、{3,4}、{5,6} 覆盖全部 6 个顶点 ✓，且 |M₂| = |V|/2 = 3 达到基数上界 ✓

## 推论（推断，非源明言）

由四定义可直接推出蕴含链：

```text
完全匹配 ⟹ 极大匹配（基数意义）⟹ 饱和匹配；两个反向蕴含均不成立。
```

## 判定

- 定义组：内部自洽，强度**强**。
- 算例：全部核验通过，强度**强**（依赖例图边集假设）。
- 转写损伤：四条定义中的变元（M、G、M*）在中文正文全部脱落；M₁ 集合后多出一个全角「｝」。详见 [[queries/5-8-4全节系统性转写讹误清单]]。
