# 式 9.96 半无限杆热传导转录复算

## 逐字转录（关键式）

```
u_t = a²u_xx                                                         (9.96a)
u|_{t=0} = f(x)，u|_{x=0} = 0（无穷远处温度趋于零）                    (9.96b)
u = X(x)T(t)                                                         (9.96c)
T′/(a²T) = X″/X = −λ²                                                (9.96d)
T(t) = C_λ e^{−λ²a²t}                                                (9.96e)
X = C sin λx（λ 为任意实数，连续谱）                                  (9.96f/g)
u(x,t) = ∫₀^∞ C(λ)e^{−λ²a²t}sin λx dλ                               (9.96h)
f(x) = ∫₀^∞ C(λ)sin λx dλ                                           (9.96i)
C(λ) = (2/π)∫₀^∞ f(s)sin λs ds                                      (9.96j)
u(x,t) = (2/π)∫₀^∞ f(s)[∫₀^∞ e^{−λ²a²t}sin λs sin λx dλ]ds          (9.96k)
u(x,t) = ∫₀^∞ f(s)(1/(2a√(πt)))[e^{−(x−s)²/(4a²t)} − e^{−(x+s)²/(4a²t)}]ds   (9.96l，转写式号 9.961)
```

## 复算核验

1. **连续谱**：半无限区域无离散本征值，级数换为反常积分；C(λ) 与 f 构成傅里叶正弦积分的反演对（回指 7.4.1.1，未入库）✓。
2. **内层积分**：sin λs·sin λx = ½[cos λ(s−x) − cos λ(s+x)]（手册回指式 (2.122)），且 ∫₀^∞ e^{−a²tλ²}cos(qλ)dλ = ½√(π/(a²t))·e^{−q²/(4a²t)}（回指表 21.8.2 公式 (21.27)，均未入库）；故内层积分 = (√π/(4a√t))[e^{−(x−s)²/(4a²t)} − e^{−(x+s)²/(4a²t)}]，再乘外层因子 2/π 得 1/(2a√(πt))·[…] ✓。
3. **热核识别**：1/(2a√(πt)) = 1/√(4πa²t)，两项即热核在 s 与 −s（奇延拓镜像）处的取值，与 x = 0 零边界条件相符 ✓。

## 结论

复算通过。转写讹误：式号 9.96l 误作“9.961”（l→1），同类讹误还有 9.931、9.941（见 [[queries/9-2-2全节系统性转写讹误清单]]）。概念页 [[热传导方程]]。
