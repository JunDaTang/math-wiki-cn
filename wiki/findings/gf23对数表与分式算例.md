# GF(2³) 对数表与分式算例（式 5.181，全表已复算）

数学手册 5.3.7.4.1 以 $f(x) = 1 + x + x^3$ 为例构造 GF(2³) 并编制对数表，使域运算简化。

## 构造

$f(x) = 1 + x + x^3$ 在 $\mathbb{Z}_2[x]$ 上不可约（源文记号作 $\mathbb{Z}[x]$，下标 2 疑脱落），因为无论 $0$ 还是 $1$ 都不是它的根：

$$\mathrm{GF}(2^3) = \mathbb{Z}_2[x]/f(x) = \{a_0 + a_1 x + a_2 x^2 \mid a_0, a_1, a_2 \in \mathbb{Z}_2 \wedge x^3 = 1 + x\}. \tag{5.181}$$

$f(x)$ 是本原的，所以可以从 GF(2³) 中产生对数表。$\mathbb{Z}_2[x]/f(x)$ 中每个多项式 $a_0 + a_1 x + a_2 x^2$ 都可以确定两个表达式：系数向量 $a_0, a_1, a_2$（KV），以及所谓**对数**——使得对于模 $1 + x + x^3$ 有 $x^i = a_0 + a_1 x + a_2 x^2$ 的自然数 $i$（Log）。

## 对数表（原样转录，已逐行复算 ✓）

| KE（域元素） | KV（$a_0\ a_1\ a_2$） | Log |
|---|---|---|
| 1 | 1 0 0 | 0 |
| x | 0 1 0 | 1 |
| x² | 0 0 1 | 2 |
| x³ | 1 1 0 | 3 |
| x⁴ | 0 1 1 | 4 |
| x⁵ | 1 1 1 | 5 |
| x⁶ | 1 0 1 | 6 |

**复算** ✓：由 $x^3 \equiv 1 + x$，依次 $x^4 \equiv x + x^2$、$x^5 \equiv 1 + x + x^2$、$x^6 \equiv 1 + x^2$、$x^7 \equiv 1 \pmod{f}$，与 KV 列逐行一致；$x$ 的幂遍历全部 $2^3 - 1 = 7$ 个非零元，印证 $f$ 的本原性（[[findings/有限域乘法群循环性]]、[[concepts/本原多项式]]）。

## 运算法则

- **加法**：GF(8) 中域元素（KE）的加法 = 按分量模 2（一般情形模 p）坐标向量（KV）的加法；
- **乘法**：GF(8) 中域元素（KE）的乘法 = 对数（Log）（一般情形模 $p^n - 1$，此处 7）的加法。

## 分式算例（已复算 ✓）

$$\frac{x^2 + x^4}{x^3 + x^4} = \frac{x}{x^6} = x^{-5} = x^2.$$

复算：分子按 KV 相加 $(0,0,1) + (0,1,1) = (0,1,0) = x$；分母 $(1,1,0) + (0,1,1) = (1,0,1) = x^6$；于是 $x^{1-6} = x^{-5} = x^{-5+7} = x^2$。✓
