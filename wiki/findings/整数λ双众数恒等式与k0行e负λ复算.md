# 整数 λ 双众数恒等式与 k=0 行 e^{−λ} 复算

对《数学手册(原书第10版)》21.16 节泊松分布数值表执行两类边界恒等式检验（方法承 [[methodology/数值表边界恒等式交叉复算法]]，属 [[methodology/概率分布表交叉复算法]] 之恒等式环节），全部成立。

## 整数 λ 双众数恒等式 P(λ−1) = P(λ)

由相邻比值 P(k+1)/P(k) = λ/(k+1)，比值在 k = λ−1 处等于 1，故 λ 为正整数时分布呈双众数。表内 λ=1…9 九个整数列全部验证成立：

| λ | P(λ−1) = P(λ)（表值） |
|---|---|
| 1 | P(0) = P(1) = 0.367879 |
| 2 | P(1) = P(2) = 0.270671 |
| 3 | P(2) = P(3) = 0.224042 |
| 4 | P(3) = P(4) = 0.195367 |
| 5 | P(4) = P(5) = 0.175467 |
| 6 | P(5) = P(6) = 0.160623 |
| 7 | P(6) = P(7) = 0.149003 |
| 8 | P(7) = P(8) = 0.139587 |
| 9 | P(8) = P(9) = 0.131756 |

## k=0 行 = e^{−λ}

P(0;λ) = e^{−λ}，18 列全部吻合：0.904837 = e^{−0.1}、0.818731 = e^{−0.2}、…、0.367879 = e^{−1}、…、0.000123 = e^{−9}。

**附带成果**：表二下段源文件无 λ 表头行且 k 回卷至 0；其 k=0 行六值与 e^{−4}、e^{−5}、e^{−6}、e^{−7}、e^{−8}、e^{−9} 逐位吻合（0.018316、0.006738、0.002479、0.000912、0.000335、0.000123），是复原该段表头 λ = 4.0–9.0 的主要依据。详见 [[queries/表二下段λ表头4至9脱落之辨]]。

## 证据性质

两类恒等式均为解析恒等式与表值的交叉比对，属直接证据；与全表逐格复算（[[findings/21-16泊松分布表全表闭式列和复算]]）互证。
