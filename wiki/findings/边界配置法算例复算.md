# 边界配置法算例复算

19.5.2 的边界配置算例，对 19.5.1 例 1 的同一问题（$\Delta u=-1$ 于 $|x|<1,|y|<2$，边界 $u=0$）：

$$v(x,y;a_{1},a_{2},a_{3})=-\tfrac{1}{4}(x^{2}+y^{2})+a_{1}+a_{2}(x^{2}-y^{2})+a_{3}(x^{4}-6x^{2}y^{2}+y^{4})$$

配置点 $(1,0.5),(1,1.5),(0.5,2)$（均在边界上）。

## 转录（源印方程组与解）

```text
-0.3125 + a1 + 0.75*a2  - 0.4375*a3  = 0
-0.8125 + a1 - 1.25*a2  - 7.4375*a3  = 0
-1.0625 + a1 - 3.75*a2  + 10.0625*a3 = 0
解：a1 = 0.4562,  a2 = -0.200,  a3 = -0.0143
    v(0,1) = 0.3919,  v(0,0) = 0.4562
```

## 复算

1. **$\Delta v=-1$ 对任意 $a_{i}$ 成立**：$-\frac14(x^{2}+y^{2})$ 的 Laplace 为 $-1$；$x^{2}-y^{2}$ 与 $x^{4}-6x^{2}y^{2}+y^{4}$ 为调和函数（$\Delta=0$）✓——属情形 (1)，边界配置。
2. **三方程系数逐项核对**：如 $(1,0.5)$ 处 $-\frac14(1+0.25)=-0.3125$、$x^{2}-y^{2}=0.75$、$x^{4}-6x^{2}y^{2}+y^{4}=1-1.5+0.0625=-0.4375$ ✓；$(1,1.5)$、$(0.5,2)$ 两点同样吻合 ✓。
3. **精确解**：消元解得 $a_{1}=73/160=0.45625$，$a_{2}=-1/5$，$a_{3}=-1/70\approx-0.014286$；与源值（舍入到四位）一致。
4. **函数值**：$v(0,1)=-\frac14+\frac{73}{160}+\frac15-\frac1{70}=0.39196$（源值 0.3919 系用舍入系数计算）；$v(0,0)=a_{1}=0.4562$ ✓。

## 结论

算例**完全复现**。与差分法同题结果（$u_{0,0}=3/7\approx0.429$、$u_{0,1}=5/14\approx0.357$）并列给出，源未评判优劣。
