# 指数和四情形分类与 A/B/C/D 特征点公式（式 2.60）

手册 2.6.4 对 [[指数和]] $y = a\mathrm{e}^{bx} + c\mathrm{e}^{dx}$（a, b, c, d ≠ 0）给出四个特征点与按参数符号的四情形分类，是全节验证最完整的公式体系。

## 特征点公式

- y 轴交点 $A(0,\ a+c)$；
- x 轴交点 $B\left(\dfrac{\ln(-a/c)}{d-b},\ 0\right)$；
- 极值点 C 的横坐标 $x = \dfrac{1}{d-b}\ln\left(-\dfrac{ab}{cd}\right)$；
- 拐点 D 的横坐标 $x = \dfrac{1}{d-b}\ln\left(-\dfrac{ab^{2}}{cd^{2}}\right)$。

## 四情形（原文结构化数据）

| 情形 | a 与 c | b 与 d | 单调性 | 值的走向 | 极值 | 拐点 | 渐近线 |
|---|---|---|---|---|---|---|---|
| a) | 同号 | 同号 | 严格单调 | 0 ↔ ±∞ | 无 | 无 | x 轴 |
| b) | 同号 | 异号 | 单谷 / 单峰 | +∞→+∞（有极小）或 −∞→−∞（有极大） | 有 | 无 | 无 |
| c) | 异号 | 同号 | 极值两侧各自严格单调，变号一次 | 0→极值→±∞ 或反向 | 有 C | 有 D | x 轴 |
| d) | 异号 | 异号 | 严格单调 | −∞→+∞ 或 +∞→−∞ | 无 | 有 D | 无 |

依参数符号不同，图像可能沿坐标轴反射。

**复核（全部通过）**：

1. A、B、C、D 四公式分别由 y = 0、y′ = ab·e^{bx} + cd·e^{dx} = 0、y″ = ab²·e^{bx} + cd²·e^{dx} = 0 直接解出，代数验证成立；
2. 四情形由符号分析证实——**极值存在性**由 $-\frac{ab}{cd} > 0$（即 sgn(ab) 与 sgn(cd) 异号）决定，**拐点存在性**由 $-\frac{ab^{2}}{cd^{2}} > 0$（即 sgn(a) 与 sgn(c) 异号，因 ab²、cd² 分别承 a、c 之号）决定，与表中 a)–d) 的有无配置逐一吻合（极值属情形 b)、c)，拐点属情形 c)、d)，且拐点存在 ⇔ 交点 B 存在 ⇔ 函数变号）。

判定：**成立**。该符号判别法可迁移（见 [[指数对数类函数图像绘制法]]）。对照 [[指数和四情形比较]]。
