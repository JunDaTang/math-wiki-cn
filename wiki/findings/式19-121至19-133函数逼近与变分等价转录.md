# 式 19.121–19.133 函数逼近与变分等价转录

**转录**（源文逐字保留）：

```latex
(19.121)  y(x) \approx g(x) = \sum_{i=1}^{n} a_i g_i(x)
(19.122)  \varepsilon(x; a_1,\dots,a_n) = g''(x) + p(x)g'(x) + q(x)g(x) - f(x)
(19.123)  \varepsilon(x_\nu; a_1,\dots,a_n) = 0  (\nu = 1,\dots,n),\ a < x_1 < \dots < x_n < b
(19.124)  F(a_1,\dots,a_n) = \int_a^b \varepsilon^2(x; a_1,\dots,a_n)\,dx
(19.125)  \frac{\partial F}{\partial a_i} = 0  (i = 1,\dots,n)
(19.126)  \int_a^b \varepsilon(x; a_1,\dots,a_n)\, g_i(x)\,dx = 0  (i = 1,\dots,n)
(19.127)  I[y] = \int_a^b H(x, y, y')\,dx   （见 (10.4)，未入库）
(19.128)  \frac{\partial I}{\partial a_i} = 0  (i = 1,\dots,n)
(19.129)  -[p(x)y'(x)]' + q(x)y(x) = f(x),  y(\alpha)=\alpha,\ y(\beta)=\beta
(19.130)  I[y] = \int_a^b [p(x)y'^2(x) + q(x)y^2(x) - 2f(x)y(x)]\,dx = \min
(19.131)  g(x) = g_0(x) + \sum_{i=1}^{n} a_i g_i(x)
(19.132)  g_i(a) = g_i(b) = 0  (i = 1,\dots,n)
(19.133)  g_0(x) = \alpha + \frac{\beta-\alpha}{b-a}(x-a)
```

**评注**：

- (19.122) 亏量是四原则（配置/最小二乘/伽辽金/里茨）的公共对象；四者对线性边值问题均给出线性方程组。
- (19.129)–(19.130)：源文断言在关于 p, q, f, y 的一定条件下自伴边值问题与其变分问题等价，且由 (19.130) 立即得到 H(x,y,y′)；等价性条件未明列（源内定性断言）。
- (19.131)–(19.133)：基函数构造——g₀ 满足边值、g_i 满足齐次边界条件；对 (19.118) 取线性 g₀。
- 非线性边值问题所得非线性方程组用 19.2.2（未入库）方法求解。
- 转写脱文：(19.121) 前有衍文 "n"；(19.128) 后“得到系数 a_i 个方程”疑脱 "n"；见 [[queries/19-4全节系统性转写讹误清单]]。

本条为公式转录比对，未做数值复算。见 [[concepts/边值问题与变分问题等价性]]。
