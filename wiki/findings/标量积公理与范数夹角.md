# 标量积公理 S1–S4 与范数—夹角（式 5.198–5.203）

## 陈述（5.3.8.5）

设 $V$ 是实向量空间，$\varphi:V\times V\to\mathbb{R}$（写作 $v\cdot w$）满足：

```latex
(S1) v·w = w·v                              % 5.198
(S2) (u+v)·w = u·w + v·w                    % 5.199
(S3) r(v·w) = (rv)·w = v·(rw)               % 5.200
(S4) v·v > 0 当且仅当 v ≠ 0                 % 5.201
```

则 $\varphi$ 称为 $V$ 上的标量积，$V$ 称为欧几里得向量空间。由此定义：

```latex
‖v‖ = √(v·v)                                 % 5.202 欧几里得范数（长度）
cos α = (v·w)/(‖v‖·‖w‖)                     % 5.203 v,w 间的夹角
```

若 $v\cdot w=0$ 则称互相正交。这些性质也用来在更一般的空间上定义具有类似性质的标量积（原书指向 12.4.1.1，第 879 页，未入库）。函数空间实例 $f\cdot g=\int_a^b f(x)g(x)\,dx$（式 5.204）见 [[entities/c-a-b-连续函数空间]] 与 [[findings/三角函数正交性算例]]。

## 复原注记

原文 S4 作「$v\cdot v>0$，当且仅当 $v\neq 0$」；S3 首项排版为 $r\cdot(v\cdot w)$，按数乘记法应为 $r(v\cdot w)$。「影射」为「映射」之讹（见 [[queries/5-3-8全节系统性转写讹误清单]]）。

## 证据性质

标准公理化定义；与 [[concepts/半双线性型与埃尔米特型]] 的复域对应物构成 ℝ／ℂ 的对偶结构，二者归属不可互换（见 [[comparisons/双线性型与半双线性型比较]]）。
