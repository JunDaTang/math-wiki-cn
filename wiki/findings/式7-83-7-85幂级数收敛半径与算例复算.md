# 幂级数三情形定理、收敛半径与 Σxⁿ/n 算例（式 7.83–7.85，已复算）

## 定义与三情形定理（式 7.83–7.84）

```latex
a_0 + a_1 x + a_2 x^2 + \dots + a_n x^n + \dots = \sum_{n=0}^{\infty} a_n x^n                 % (7.83a)
a_0 + a_1 (x-x_0) + a_2 (x-x_0)^2 + \dots = \sum_{n=0}^{\infty} a_n (x-x_0)^n                 % (7.83b)
r = \lim_{n\to\infty}\left|\frac{a_n}{a_{n+1}}\right| \quad\text{或}\quad r = \frac{1}{\lim_{n\to\infty}\sqrt[n]{|a_n|}}       % (7.84)
```

幂级数或者仅在 x = x₀ 收敛，或者对所有 x 值均收敛，或者存在收敛半径 r > 0 使得 |x−x₀| < r 时绝对收敛、|x−x₀| > r 时发散（图 7.1）；端点 x = x₀ ± r 处级数或收敛或发散，须另行检验。若 (7.84) 的极限不存在，要选取**上极限**代替通常的极限（源文此处转写损坏为「面面」，出处「（参见 [7.8] 卷）」亦损坏，见 [[上极限与文献7-8卷句如何复原]]）。

## 阿贝尔定理（7.3.3.1 第 3 条）

幂级数在收敛域的每个子区间 |x − x₀| ⩽ r₀ < r 上一致收敛。

## 算例（式 7.85，复算通过）

级数 1 + x/1 + x²/2 + ⋯ + xⁿ/n + ⋯（系数 a_n = 1/n）：

```latex
r = \lim_{n\to\infty}\frac{n+1}{n} = 1
```

因此 −1 < x < 1 时级数绝对收敛；x = −1 时条件收敛（回指第 620 页级数 7.34，即交错调和型）；x = 1 时发散（回指第 616 页调和级数 7.16）。根据阿贝尔定理，当 r₁ 为介于 0 与 1 之间的任意数时，级数在 [−r₁, r₁] 上均一致收敛。

**复算**：r = lim|a_n/a_{n+1}| = lim (n+1)/n = 1 ✓；x = 1 为调和级数发散 ✓；x = −1 为交错级数收敛（非绝对）✓。
