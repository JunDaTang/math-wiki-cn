# 式 9.95 矩形狄利克雷问题转录复算

## 逐字转录（关键式）

```
Δu = 0                                                               (9.95a)
u(0,y) = φ₁(y)，u(a,y) = φ₂(y)，u(x,0) = ψ₁(x)，u(x,b) = ψ₂(x)      (9.95b)
u = X(x)Y(y)                                                         (9.95c)
X″/X = −Y″/Y = −λ²                                                   (9.95d)
X = C sin λx，λ = nπ/a = λ_n (n = 1,2,…)                              (9.95e)
Y″ − (n²π²/a²)Y = 0                                                  (9.95f)
Y = a_n sinh((nπ/a)(b−y)) + b_n sinh((nπ/a)y)                        (9.95g)
u = Σ_{n≥1}[a_n sinh((nπ/a)(b−y)) + b_n sinh((nπ/a)y)]sin((nπ/a)x)  (9.95j)
a_n = 2/(a·sinh(nπb/a)) ∫₀^a ψ₁(x)sin(nπx/a)dx                       (9.95k)
b_n = 2/(a·sinh(nπb/a)) ∫₀^a ψ₂(x)sin(nπx/a)dx
```

## 复算核验

1. **两步解法**：先解 φ₁ = φ₂ = 0 的半问题（x 方向 Dirichlet 本征值问题 → sin(nπx/a)）；Y 取 sinh((nπ/a)(b−y)) 与 sinh((nπ/a)y) 的组合，使 y = 0 与 y = b 两边的边界条件**解耦**（前者在 y = b 处为零，后者在 y = 0 处为零）✓。
2. **系数公式**：在 y = 0 处 u = Σ a_n sinh(nπb/a)sin(nπx/a) = ψ₁(x)，正弦展开归一给 a_n = 2/(a·sinh(nπb/a))∫ψ₁ sin ✓；b_n 同理（在 y = b 处）✓。
3. **通解**：另一半问题（ψ₁ = ψ₂ = 0）同法求解后与 (9.95j) 叠加，得 (9.95a)(9.95b) 的通解——[[叠加原理与分解定理]] 的应用 ✓。

## 结论

复算通过，无实质问题。概念页 [[狄利克雷问题]]、[[拉普拉斯方程与拉普拉斯算子]]；流程页 [[分离变量法解题流程]]。
