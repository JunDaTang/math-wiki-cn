# 对称群不可约表示由分拆刻画与维数公式（式 5.119–5.120，已复算）

**来源**：[[sources/10-数学手册原书第10版--7-534-群表示--x5kmh9]]（5.3.4.8.1）。

**主结果**：$S_M$ 的不等价的不可约表示由 $M$ 的分拆 $[\lambda] = [\lambda_1, \dots, \lambda_M]$（$\lambda_1 + \dots + \lambda_M = M$，$\lambda_1 \geqslant \dots \geqslant \lambda_M \geqslant 0$，式 5.119）**唯一刻画**；分拆图示化为杨氏图。表示 $[\lambda]$ 的维数（式 5.120）：

$$n^{[\lambda]} = M!\,\frac{\prod_{i<j\leq k}(\lambda_i - \lambda_j + j - i)}{\prod_{i=1}^{k}(\lambda_i + k - i)!}$$

**独立复算**（本 wiki）：

| 群 | 分拆 [λ] | 维数 |
|---|---|---|
| S_3 | [3] | 1 |
| S_3 | [2,1] | 2 |
| S_3 | [1,1,1] | 1 |
| S_4 | [4] | 1 |
| S_4 | [3,1] | 3 |
| S_4 | [2,2] | 2 |
| S_4 | [2,1,1] | 3 |
| S_4 | [1,1,1,1] | 1 |

全部与公式一致；$S_4$ 各维数平方和 $1+9+4+9+1 = 24 = 4!$ 亦相互印证（此平方和检验为本 wiki 补充的标准事实）。原书仅给出 $S_4$ 杨氏图之图示；上表维数均按公式复算。

**转写注意**：原书下标 $\prod_{i<j<k}$ 应为 $\prod_{i<j\leq k}$（否则维数不能复现，如 $S_3$ 的 $[2,1]$）；「对于群 S_4 我们得到 □ 个杨氏图」脱落「五」（4 的分拆恰有 5 个）；「[入]」应为 $[\lambda]$。见 [[queries/5-3-4全节系统性转写讹误清单]] 与 [[queries/恒等表示维数与s4杨氏图个数的脱落字复原]]。
