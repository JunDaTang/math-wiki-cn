# 坐标变换公式组（式 3.286–3.290，含 R=D⁻¹）

本源 3.5.2.2 给出的坐标变换公式组：

```
平移（新原点 O′ 的旧坐标为 a, b）:
  x = x′ + a,  y = y′ + b                    (3.286a)
  x′ = x − a,  y′ = y − b                    (3.286b)
旋转（转角 φ）:
  x′ = x cos φ + y sin φ
  y′ = −x sin φ + y cos φ                    (3.287a)
  x = x′ cos φ − y′ sin φ
  y = x′ sin φ + y′ cos φ                    (3.287b)
旋转矩阵:
  D = [cos φ  sin φ; −sin φ  cos φ]
  (x′,y′)ᵀ = D(x,y)ᵀ,  (x,y)ᵀ = D⁻¹(x′,y′)ᵀ      (3.287c)
对象的旋转（几何变换）:
  (x′_P, y′_P)ᵀ = R(x_P, y_P)ᵀ,  R = D⁻¹           (3.288–3.289)
笛卡儿→极坐标:
  x = ρ cos φ,  y = ρ sin φ  (−π < φ ≤ π, ρ ≥ 0)  (3.290a)
  ρ = √(x² + y²)                                    (3.290b)
  φ = arctan(y/x)+π (x<0); arctan(y/x) (x>0); π/2 (x=0,y>0);
     −π/2 (x=0,y<0); 未定义 (x=y=0)                 (3.290c)
```

## 核心主张

1. 一般笛卡儿→笛卡儿变换 = 坐标轴平移 + 旋转两步。
2. **坐标变换**（改系不动对象）与**几何变换**（动对象不动系）通过 R = D⁻¹ 相联系；几何变换的详细展开前向引用原书 3.5.4.1（第 308 页，待入库）。对照分析见 [[comparisons/坐标变换与几何变换比较]]。
3. 笛卡儿↔极坐标互化采用区间约定 −π < φ ≤ π、ρ ≥ 0。

## 验证与置信

- 直接证据：公式照录自本源。矩阵关系 D·D⁻¹ = I 与 (3.287a)(3.287b) 互逆可直接验证（复算，视为已复算）。
- 存疑点：(3.290c) 的 x<0 且 y<0 分支给出 arctan(y/x)+π ∈ (π, 3π/2)，违反 (3.290a) 声明的区间，标准 atan2 应取 arctan(y/x)−π，见 [[queries/式3-290c第三象限极角分支是否应为arctan减pi]]。

与 3.2 节 [[findings/两直角坐标系相似变换]]（含比例因子的相似变换，式 3.108–3.109）互相印证：本组是无比例因子的纯刚体情形。
