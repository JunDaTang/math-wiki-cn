# 式 14.69–14.75 指数、对数与一般指数函数转录复算

## 转录内容

```latex
e^z = 1 + z/1! + z^2/2! + z^3/3! + \dots                                     (14.69)
e^{iy} = \cos y + \mathrm{i}\sin y,   e^{\pi\mathrm{i}} = -1                 (14.70)
e^z = e^x e^{iy} = e^x(\cos y + \mathrm{i}\sin y)                            (14.71a)
Re(e^z) = e^x\cos y,  Im(e^z) = e^x\sin y,  |e^z| = e^x,  arg(e^z) = y      (14.71b)
e^z = e^{z + 2k\pi\mathrm{i}}   (k = 0, \pm1, \pm2, \dots)                   (14.71c)
e^0 = e^{2k\pi\mathrm{i}} = 1,   e^{(2k+1)\pi\mathrm{i}} = -1                (14.71d)
a + \mathrm{i}b = \rho e^{\mathrm{i}\varphi}                                 (14.72)
e^{\mathrm{i}z} = \cos z + \mathrm{i}\sin z                                  (14.73a)
e^{-\mathrm{i}z} = \cos z - \mathrm{i}\sin z                                 (14.73b)
w = Ln z   当且仅当   z = e^w                                                 (14.74a)
Ln z = \ln\rho + \mathrm{i}(\varphi + 2k\pi)                                 (14.74b)
Re(\ln z) = \ln\rho,   Im(\ln z) = \varphi + 2k\pi   (k = 0,\pm1,\pm2,\dots) (14.74c)
\ln z = \ln\rho + \mathrm{i}\varphi   (-\pi < \varphi \leqslant \pi)          (14.74d)
a^z = e^{z\,Ln a}    (a \neq 0)                                               (14.75a)
a^z = e^{z\,\ln a}                                                             (14.75b)
```

## 复算过程与结论

- **(14.69)**：比值判别给出收敛半径 $\infty$，与源文“整个 $z$ 平面绝对收敛”断言一致 ✓。此式是收敛半径为 $\infty$ 的 [[concepts/复项幂级数]] 实例。
- **(14.70)**：代入 $y = \pi$：$e^{\pi\mathrm{i}} = \cos\pi + \mathrm{i}\sin\pi = -1$ ✓。
- **(14.71a/b)**：$e^{x+\mathrm{i}y} = e^x e^{\mathrm{i}y}$ 拆分 ✓；$|e^z| = e^x\,|\cos y + \mathrm{i}\sin y| = e^x$ ✓；$\arg(e^z) = y$（mod $2\pi$）✓。
- **(14.71c)**：$e^{z+2k\pi\mathrm{i}} = e^z\,e^{2k\pi\mathrm{i}} = e^z$ ✓。⚠ 正文“其周期为 忒”为 $2\pi\mathrm{i}$ 之转写讹误（见 [[queries/14-5全节系统性转写讹误清单]]）。
- **(14.71d)**：$e^{2k\pi\mathrm{i}} = \cos 2k\pi + \mathrm{i}\sin 2k\pi = 1$；$e^{(2k+1)\pi\mathrm{i}} = -1$ ✓。
- **(14.72)**：由 $a + \mathrm{i}b = \rho(\cos\varphi + \mathrm{i}\sin\varphi)$ 与 (14.70) 即得 ✓。
- **(14.73a/b)**：复变量的欧拉关系，以级数代入可独立验证 ✓（与 (14.76a/b) 互为推论——注意 (14.76b) 的分母存疑，见 [[queries/式14-76b余弦分母2i疑为2]]）。
- **(14.74a/b)**：设 $w = u + \mathrm{i}v$，$z = e^w = e^u e^{\mathrm{i}v}$，故 $u = \ln\rho$、$v = \varphi + 2k\pi$，即 $Ln z = \ln\rho + \mathrm{i}(\varphi + 2k\pi)$ ✓。
- **(14.74c)**：数学内容 ✓；⚠ 多值语境（含 $k$）却转写作小写 $\ln$，疑应为 $Ln$（见 [[queries/式14-83a与14-84a多值式ln疑为Ln]]）。
- **(14.74d)**：主值约定 $-\pi < \varphi \leqslant \pi$ ✓；$z \neq 0$ 时 $\rho > 0$、$\ln\rho$ 有定义，与源文“除 $z = 0$ 外都有定义”一致 ✓。
- **(14.75a/b)**：$a^z = e^{z\,Ln a}$ 定义式 ✓；主值将 $Ln$ 换 $\ln$ ✓；多值性由 $Ln a$ 继承 ✓。

**结论**：本组公式数学内容全部复算通过；两处记号问题（“忒”、(14.74c) 之 ln）属转写讹误范畴。

## 证据强度

本组为标准初等复函数恒等式，可独立推导验证，证据强度高。复算为一次性验证；对讹误的判定基于逐式复算与记法比对，置信度高，但“排印源误还是 OCR 转写讹误”的归因需对照原书。
