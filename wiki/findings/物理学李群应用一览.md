# 物理学中的李群应用一览（5.3.5.6 清单）

5.3.5.6 以清单形式引述特殊连续群（李群）在物理学中的应用（原文为陈述性目录，无推导）。原文 OCR 讹形已按上下文复原并在注记中标明：

| 群 | 应用（原文，讹误已复原） |
|---|---|
| U(1) | 电动力学中的规范变换（原文作「度规变换」，疑为「规范变换」之讹，见 [[queries/u1应用是度规变换还是规范变换]]） |
| SU(2) | 粒子物理学中的自旋和同位旋（原文「同位旋转」疑为「同位旋」之讹） |
| SU(3) | 粒子物理学中重子和介子的分类；核物理学中的多体问题 |
| SO(3) | 量子力学中的角动量代数；原子和核多体问题 |
| SO(4) | 氢光谱的退化 |
| SU(4) | 核壳层模型中的维格纳（Wigner）超多重谱线（由自旋和同位旋自由度的统一产生）；夸克模型中味（flavor）多重谱线（包括粲（charm）自由度）的描述 |
| SU(6) | 夸克模型中由味自由度和自旋自由度组合产生的多重谱线；核结构模型 |
| U(n) | 原子和核物理学中的壳层模型 |
| SU(n)、SO(n) | 核物理学中的多体问题 |
| SU(2)⊗U(1) | 电弱相互作用标准模型（原文「电弱交互效应」疑为「电弱相互作用」） |
| SU(5) ⊃ SU(3)⊗SU(2)⊗U(1) | 基本相互作用的统一（GUT） |

原文末句：SU(n)、SO(n) 是李群，即连续群（参见原书 5.3.6 及 [5.14]，均未入库）。
