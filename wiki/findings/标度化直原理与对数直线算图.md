# 标度化直原理与对数直线算图

**发现内容**（《数学手册(原书第10版)》2.19.2 注 (2)，式 2.293–2.294 与图 2.109）：利用标度（2.17.1）有可能把复杂曲线的算图转换成直线算图。

1. **等分标度**下，每个形如

$$r\,\varphi(z) + y\,\psi(z) + \chi(z) = 0 \tag{2.293}$$

的方程都能表示成由直线组成的算图。对固定的 $z$，这是 $(x, y)$ 平面上的一条直线，故 $z$ 的曲线族为直线族。（原文首项系数作 $r$，而前句明言「利用 $x, y$ 的等分标度」，疑应为 $x$，见 [[queries/式2-293的r是否应为x]]。）

2. **函数标度** $x = f(z_2),\ y = g(z_2)$ 下，对于变量 $z_1, z_2, z_3$，形如

$$f(z_2)\,\varphi(z_1) + g(z_2)\,\psi(z_1) + \chi(z_1) = 0 \tag{2.294}$$

的方程能够表示为平行于坐标轴的两族曲线和任意一族直线。（原文 $g$ 的自变量与方程中 $z_3$ 的缺席存在转写疑点，最小修复为 $g(z_3)$，见 [[queries/式2-294变量下标是否错乱]]。）

**算例（对数标度化直欧姆定律，图 2.109）**：对 $R \cdot I = U$ 取对数得 $\log R + \log I = \log U$；令 $x = \log R,\ y = \log I$，有 $x + y = \log U$，即 (2.294) 的特殊形式（$z_1 = U$，$\varphi = \psi = 1$，$\chi = -\log U$，载斜率为 $-1$ 的直线族；$z_2 = R$ 载横坐标标度、$z_3 = I$ 载纵坐标标度），得到由平行直线组成的算图。

**证据与复核**：化直原理本身标准且可靠；但 (2.293) 的「r」与 (2.294) 的变量下标均有转写疑点，故本条发现的置信度记为中等，修复方案需对照原版确认。本发现的主题是标度变换方法本身——其机制是**标度变换**（坐标映射），区别于 2.16 的**变量代换**式化归（[[findings/修正的线性化原理与判定]]），欧姆定律仅为算例载体。
