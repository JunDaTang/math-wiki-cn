# 式 16.86–16.92 卡方分布转录复算

对 [[10-数学手册原书第10版--9-1624-连续分布--1ktbozm]] 16.2.4.6 的编号公式逐字转录并手工复算。结论：(16.86)–(16.90)、(16.92) 与标准结果一致；(16.91) 定义与密度不一致，疑脱两处因子 n。

## 逐字转录与复算

```
(16.86)   χ² = X₁² + X₂² + ⋯ + Xₙ²   （X₁,…,Xₙ 相互独立的标准正态随机变量）
(16.87a)  f_χ²(t) = 1/(2^{n/2}·Γ(n/2))·t^{n/2−1}·e^{−t/2} (t > 0);  0 (t ⩽ 0)
(16.87b)  F_χ²(x) = 1/(2^{n/2}·Γ(n/2))·∫_{0}^{x} t^{n/2−1}·e^{−t/2} dt (x > 0)
(16.88a)  E(χ²) = n
(16.88b)  D²(χ²) = 2n
(16.89)   X = Σ_{i=1}^{n} Xᵢ² 有密度函数 f(t) = (1/σ²)·f_χ²(t/σ²)
(16.90)   X = (1/n)·Σ_{i=1}^{n} Xᵢ² 有密度函数 f(t) = (n/σ²)·f_χ²(n·t/σ²)
(16.91)   X = √((1/n)·Σ_{i=1}^{n} Xᵢ²) 有密度函数 f(t) = (2t/σ²)·f_χ²(t²/σ²)
(16.92)   P(X > χ²_{α,m}) = α
```

（诸 Xᵢ 为参数 (0, σ²) 的独立正态变量；原文「(0,CJ')」为「(0,σ²)」之转写讹误。）

复算：

- (16.86)–(16.88)：χ²_n 即 Gamma(n/2, 尺度 2) 分布，密度、E = n、D² = 2n 均与标准结果一致；
- 可加性（未编号）：独立 χ²(n) 与 χ²(m) 之和服从 χ²(n+m)——一致；
- (16.89)：ΣXᵢ² = σ²·χ²_n，密度 f(t) = (1/σ²)f_χ²(t/σ²)——一致；
- (16.90)：(1/n)ΣXᵢ² = (σ²/n)·χ²_n，密度 f(t) = (n/σ²)f_χ²(nt/σ²)——一致；
- (16.91) 存疑：由 (16.89)，W = (1/σ²)·ΣXᵢ² ~ χ²_n。而 X = √((1/n)ΣXᵢ²) ⟹ W = (n/σ²)·X²，即 w = n·t²/σ²、dw/dt = 2nt/σ²，故

```
f_X(t) = f_χ²(n·t²/σ²)·(2nt/σ²)      (t > 0)
```

  即应得 f(t) = (2nt/σ²)·f_χ²(n·t²/σ²)，而逐字转录为 (2t/σ²)·f_χ²(t²/σ²)，两处均缺因子 n。反过来看，转录的密度恰对应 X = √(ΣXᵢ²)（定义中无 1/n）的情形——定义与密度二者必有一误。已立 [[式16-91均方根密度疑脱因子n]] 追踪；
- (16.92)：分位数定义形式 P(X > q) = α——一致（定义本身在 16.2.2.2 第 3 条，未入库）。

## 体例与记号问题

- 小节第 4 条标题作「独立正态随机变量之和」，内容却是平方和 ΣXᵢ²；
- 自由度记号：(16.87) 用 n，(16.92) 分位数 χ²_{α,m} 用 m，前后不一；
- 「X₁ 和劝 X₂」的「劝」为衍字（另两处衍字作「凡」）；「分别服从自由度为 的 χ² 分布」脱自由度记号 n、m；「随机变最」应为「随机变量」。

## 直接证据与推断的区分

- 直接证据：公式为源文逐字转录；
- 复算：上述独立推导；
- 推断：(16.91) 的两个 n 疑为转写脱落而非原书之误（与上标/因子系统性丢失一致），属推断，须纸质原书核验。

## 复现状态

复算为一次性手工推导；一致性结论可交叉验证，视为已复现；(16.91) 疑点待原书核验。
