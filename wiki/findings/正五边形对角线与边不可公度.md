# 正五边形对角线与边不可公度（3.1.5.3）

《数学手册(原书第10版)》3.1.5.3（无编号公式）给出本节最具思想分量的论证：正五边形的对角线 a₀ 与边 a₁ 不可公度，其比即黄金分割。论证链如下（图 3.24）：

1. 正五边形的对角线构成一个内接 [[concepts/五角星形]]；五角星形的边又围成一个（更小的）正五边形。
2. 比例关系：对角线与边之比等于边与（对角线 − 边）之比，即 a₀:a₁ = a₁:(a₀ − a₁) = a₁:a₂，其中 a₂ = a₀ − a₁。
3. 嵌套递推：考虑越来越小的嵌套五边形，a₃ = a₁ − a₂，a₄ = a₂ − a₃，……且 a₂ < a₁，a₃ < a₂，a₄ < a₃，……于是 a₀:a₁ = a₁:a₂ = a₂:a₃ = a₃:a₄ = ……
4. [[concepts/欧几里得算法]] 判定：a₀ = 1·a₁ + a₂，a₁ = 1·a₂ + a₃，a₂ = 1·a₃ + a₄，……商 qₙ = 1 恒定，算法永不终止，故 a₀ 与 a₁ 不可公度。
5. 结论：由 a₀:a₁ 所确定的连分数与 1.1.1.4 第 3 点中的 [[concepts/黄金分割]] 完全相同，即它导致一个无理数。

## 历史归因（弱证据，应弱记录）

源文以「据信」的保留措辞称：梅塔蓬图姆的希帕索斯（Hippasus of Metapontum，约公元前 450）通过这些多边形（正五边形/五角星形）的性质认识到无理数（源文指向 1.1.1.2）。此为传说性归因，属传说级证据，不宜写成定论。
