# 卡方 m=1、m=2 闭式锚点与 Φ 表互证复算

## m=2 行：χ²_{α,2} = −2 ln α

六列全部满足精确闭式：

| α | −2 ln α | 表值 |
|---|---|---|
| 0.99 | 0.0201 | 0.020 |
| 0.975 | 0.0506 | 0.051 |
| 0.95 | 0.1026 | 0.103 |
| 0.05 | 5.9915 | 6.0 |
| 0.025 | 7.3778 | 7.4 |
| 0.01 | 9.2103 | 9.2 |

## m=1 行：χ²_{α,1} = [Φ⁻¹(1−α/2)]²，与 Φ 表互证

| Φ 表锚点 | z = Φ⁻¹ | z² | χ² 表值 |
|---|---|---|---|
| Φ(1.96) = 0.9750 | 1.96 | 3.8416 | 3.8（α=0.05） |
| Φ(2.24) = 0.9875 | 2.2414 | 5.0239 | 5.0（α=0.025） |
| Φ(2.58) = 0.9951 | 2.5758 | 6.6349 | 6.6（α=0.01） |

即 21.18 表 m=1 行与同文件 21.17 表在数据层面相互印证：Φ 表给出的 0.9750、0.9875、0.9951 恰可经 z² 恒等式导出 χ² 表的 3.8、5.0、6.6。

## 意义与边界

- 这组闭式既验证了表义（上侧 α 记法的唯一自洽读法），又构成两表互证，是 [[methodology/概率分布数值表交叉复算法]] 中「锚点行 + 跨表互证」手段的直接体现。
- 互证结论**仅限本源两张表之间**，不外推至手册其他数表。
- 数值复算为确定性计算，尚无独立第二来源复算记录（replicated: null）。
