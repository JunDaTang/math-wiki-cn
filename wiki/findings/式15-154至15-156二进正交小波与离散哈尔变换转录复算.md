# 式 15.154–15.156 二进正交小波与离散哈尔变换转录复算

**范围**：二进基函数 (15.154)、正交小波与多贝西小波断言、离散哈尔变换 (15.155)–(15.156)。

## 复算

1. **(15.154) 保范**：取 a = 2^i、b = 2^i j 代入 (15.151) 型换元，$\int \frac{1}{2^i}\big|\psi\big(\frac{t-2^i j}{2^i}\big)\big|^2 \mathrm{d}t = \|\psi\|_2^2$，即「宽度加倍或减半 + 平移宽度的整数倍」生成保范基函数族。✓
2. **能量守恒**：$s_i^2 + d_i^2 = \tfrac12(f_{2i-1}+f_{2i})^2 + \tfrac12(f_{2i-1}-f_{2i})^2 = f_{2i-1}^2 + f_{2i}^2$（交叉项相消）。✓ 1/√2 因子使 (s_i, d_i) 变换为正交矩阵作用。
3. **递推结构 (15.156)**：把 (15.155) 中的 f 替换为 s^{(n)}，形式不变，可逐层执行，每层 d^{(n)} 先存储。✓
4. **可逆性（直接推论，源内未明言）**：由能量守恒配对可反解 $f_{2i-1} = \tfrac{1}{\sqrt2}(s_i + d_i)$、$f_{2i} = \tfrac{1}{\sqrt2}(s_i - d_i)$，递推可逆、信号可重建。

## 源内断言的边界

- 哈尔二进族 $\psi_{i,j}$ 是否正交，源内**未明言**（外部标准事实：正交）；源内明言的正交小波实例仅为 [[concepts/多贝西小波]]（正交、紧支撑、无闭式，外引 [15.10]）。
- 「当数值 N 较大时，离散小波变换收敛于积分小波变换 (15.152a)」为启发式断言，未证。△（源文「当数值 较大时」脱 N，「收敛千」为「收敛于」之讹。）
- 「具体数值/具体向量」疑为「细节数值/细节向量」之讹，见 [[queries/具体数值具体向量疑为细节之辨]]。

## 结论

(15.154)–(15.156) 转录无误，保范与能量守恒经独立复算成立；正交性与收敛性两条断言需按上述边界理解，勿将外部事实混作源内断言。
