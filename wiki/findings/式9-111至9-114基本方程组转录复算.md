# 式 9.111–9.114 基本方程组转录复算

## 转录

```latex
\mathrm{i}\hbar \frac{\partial\psi}{\partial t} = -\frac{\hbar^{2}}{2m}\Delta\psi + U(x_1,x_2,x_3,t)\psi = \hat{H}\psi   % 9.111a
\hat{H} \equiv \frac{\hat{p}^{2}}{2m} + U(\vec{r},t),\quad \hat{p} \equiv \frac{\hbar}{\mathrm{i}}\nabla                   % 9.111b
\iiint_V |\psi|^{2}\,\mathrm{d}V < \infty                                                                                   % 9.112a
\psi = \Psi\exp(-\mathrm{i}Et/\hbar)                                                                                        % 9.112b
\mathrm{d}\omega = |\psi|^{2}\,\mathrm{d}V = \psi\psi^{*}\,\mathrm{d}V                                                       % 9.112c
\Delta\Psi + \frac{2m}{\hbar^{2}}(E-U)\Psi = 0                                                                              % 9.113a
E = \frac{p^{2}}{2m}\quad(p=h/\lambda,\ h=2\pi\hbar)                                                                        % 9.113b
\Delta\Psi + \lambda\Psi = 0,\qquad \lambda=\frac{2mE}{\hbar^{2}}                                                           % 9.114a,b
```

## 复算与核对

- **9.111a**：结构核对——时间一阶、空间二阶、虚系数，与正文描述一致 ✓。
- **9.111b**：Ĥ = p̂²/2m + U 与经典哈密顿函数的结构对应 ✓；p̂ = (ℏ/i)∇ 展开即 −(ℏ²/2m)Δ ✓。
- **9.112b → 9.113a**（关键复算）：对 9.112b 求时间导数 ∂ψ/∂t = −(iE/ℏ)ψ，代入 9.111a，约去公共因子 e^{−iEt/ℏ}，得 EΨ = −(ℏ²/2m)ΔΨ + UΨ，整理即 9.113a ✓。
- **9.113a → 9.114a**：U = 0 直接给出 ✓；9.114b 量纲核对 ✓。
- **9.112c**：概率元定义与 |ψ|² = ψψ* 一致 ✓。

## 疑点

- 9.2.4.7.1 称把谐振子势「代入 (9.114a)」——9.114a 是 U = 0 的亥姆霍兹方程，容纳不了势能项，应为 9.113a：[[queries/谐振子一节代入9-114a还是9-113a]]。
- 本组公式本身未发现公式级错误；OCR 层面「9.llla→9.111a」「千→于」等见 [[queries/9-2-4全节系统性转写讹误清单]]。

## 结论

本组为直接推导复算（非推断），全部通过；构成 [[entities/薛定谔方程]]、[[entities/哈密顿算子]]、[[concepts/亥姆霍兹微分方程]] 三页的公式基础。
