# 式 14.49a–14.49b 解析延拓与几何级数例转录复算

对 14.3.3 解析延拓原理 (14.49a/b) 的转录，及对几何级数算例的独立复算。

## 转录内容

```latex
(14.49a) f_0(z) = Σ_{n=0}^∞ a_n (z - z_0)^n ,   f_1(z) = Σ_{n=0}^∞ b_n (z - z_1)^n
(14.49b) f_0(z) = f_1(z)        （在收敛圆 K_0 与 K_1 的公共区域内）
```

## 独立复算

- $f_0(z) = \sum_{n\ge0} z^n = \frac{1}{1-z}$（$|z| < 1$）：几何级数，$r_0 = 1$。✓
- $f_1(z) = \frac{1}{1-\mathrm{i}}\sum_{n\ge0}\left(\frac{z-\mathrm{i}}{1-\mathrm{i}}\right)^n$：公比 $\frac{z-\mathrm{i}}{1-\mathrm{i}}$，收敛条件 $|z - \mathrm{i}| < |1 - \mathrm{i}| = \sqrt{2}$，即 $r_1 = \sqrt{2}$。✓
- 和函数：$\frac{1}{1-\mathrm{i}} \cdot \frac{1}{1 - \frac{z-\mathrm{i}}{1-\mathrm{i}}} = \frac{1}{(1-\mathrm{i})-(z-\mathrm{i})} = \frac{1}{1-z}$。✓ 与原书“两者都以 $f(z) = 1/(1-z)$ 为和”一致。
- 公共区域非空：如 $z = 0$ 满足 $|0| < 1$ 且 $|0-\mathrm{i}| = 1 < \sqrt{2}$；而 $z = 1$ 恰在两圆周上（$|1-0|=1$，$|1-\mathrm{i}|=\sqrt2$），不属于开公共区域，与原书括注 $(z \neq 1)$ 相容。✓

## 结论

算例复算全部通过，confidence: high，replicated: true。本算例同时说明泰勒收敛圆半径可超出区域 G 的内切圆，支撑 [[queries/14-3-2泰勒收敛圆与G内切圆仅为下界之辨]] 的分析。
