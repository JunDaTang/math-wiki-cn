# 直角三角形基本公式与定义量计算（式 3.83–3.87 与表 3.3）

**发现内容（直接证据，公式逐字保留）：**

$$\alpha + \beta + \gamma = 180^\circ,\quad \gamma = 90^\circ \tag{3.83}$$

$$a = c\sin\alpha = c\cos\beta = b\tan\alpha = b\cot\beta \tag{3.84}$$

$$a^2 + b^2 = c^2 \tag{3.85}$$

$$h^2 = pq,\quad a^2 = pc,\quad b^2 = qc \tag{3.86}$$

$$S = \frac{ab}{2} = \frac{a^2}{2}\tan\beta = \frac{c^2}{4}\sin 2\beta \tag{3.87}$$

（3.85）即 [[concepts/勾股定理]]，（3.86）即 [[concepts/欧几里得定理]]。式 (3.83) 为 [[findings/三角不等式与内角和]] 内角和定理的 $\gamma = 90^\circ$ 特例。

**定义量论证：**直角三角形有六个定义量（三个角及其对边），其中一个角已知为 $90^\circ$，故只能再给定两个量；剩下的三个量可由 3.3 节（三角函数，尚未摄入）以及 (3.15)、(3.83) 确定。表 3.3 给出四种情形：已知 (a, α)、(b, α)、(c, α) 时 $\beta = 90^\circ-\alpha$ 并按 (3.84) 换算；已知 (a, b) 时由 $a/b = \tan\alpha$ 先解角。

**内部一致性核验（分析层）：**$S = \frac{c^2}{4}\sin 2\beta = \frac{c^2}{2}\sin\beta\cos\beta$，代入 $a = c\sin\alpha = c\cos\beta$、$b = c\cos\alpha = c\sin\beta$ 得 $\frac{ab}{2}$，与 (3.87) 第一形式一致。

**证据类型：**直接证据（教科书级经典公式组，且经代数互证自洽）。
