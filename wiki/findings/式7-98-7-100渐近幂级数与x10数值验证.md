# 渐近幂级数的定义、性质与 x=10 数值验证（式 7.98–7.100，已复算）

## 渐近性与定义（式 7.98–7.99）

设两函数 f(x)、g(x) 在 x₀ < x < ∞ 上有定义。若

```latex
\lim_{x\to\infty}\frac{f(x)}{g(x)} = 1 \iff f(x) = g(x) + o(g(x)) \quad (x\to\infty)          % (7.98a,b)
```

则称它们在 x → ∞ 时渐近相等，记 f(x) ~ g(x)，其中 o(·) 为[[朗道符号]]「小 o」（定义见 2.1.4.9，未入库）。当 x > x₀ 时若对每个 n = 0,1,2,⋯ 都有

```latex
f(x) = \sum_{\nu=0}^{n}\frac{a_\nu}{x^\nu} + O\!\left(\frac{1}{x^{n+1}}\right)                  % (7.99)
```

则级数 Σ a_ν/x^ν 为 f(x) 的渐近幂级数，记 f(x) ≈ Σ a_ν/x^ν。

渐近相等三例（转录）：A：√(x²+1) ~ x；B：e^{1/x} ~ 1；C：(3x+2)/(4x³+x+2) ~ 3/(4x²)。

## 性质

- **唯一性**：若 f 的渐近幂级数存在，则唯一；但渐近幂级数并不能唯一确定一个函数。
- **收敛性**：渐近幂级数不要求收敛。

例 A：e^{1/x} ≈ Σ_{ν=0}^∞ 1/(ν!x^ν) 是一渐近级数，且对满足 |x| > x₀（x₀ > 0）的每个 x 均收敛。

## 例 B：发散级数完美近似（式 7.100，数值复算确认）

当 x > 0 时积分 f(x) = ∫₀^∞ e^{−xt}/(1+t) dt 收敛，反复分部积分（流程见 [[渐近展开分部积分流程]]）得

```latex
f(x) = \frac{1}{x} - \frac{1!}{x^2} + \frac{2!}{x^3} - \frac{3!}{x^4} \pm \dots + (-1)^{n-1}\frac{(n-1)!}{x^n} + R_n(x),
R_n(x) = (-1)^n\frac{n!}{x^n}\int_0^\infty \frac{e^{-xt}}{(1+t)^{n+1}}\,\mathrm{d}t,
|R_n(x)| \leqslant \frac{n!}{x^n}\int_0^\infty e^{-xt}\,\mathrm{d}t = \frac{n!}{x^{n+1}},
\int_0^\infty \frac{e^{-xt}}{1+t}\,\mathrm{d}t \approx \sum_{\nu=0}^{\infty}(-1)^\nu\frac{\nu!}{x^{\nu+1}}                    % (7.100)
```

渐近幂级数 (7.100) 相邻项商的绝对值随项数与 x 之比增大（源文作 n/x；按项指标为 (n+1)/x），故该级数对每个 x 发散，然而它却完美地近似于 f(x)：当 x = 10 时用部分和 S₄(10) 与 S₅(10) 可估计出

```latex
0.09152 < \int_0^\infty \frac{e^{-10t}}{1+t}\,\mathrm{d}t < 0.09164
```

## 独立复算（通过）

- 余项界：|(1+t)^{n+1}| ⩾ 1 ⇒ |R_n| ⩽ n!/x^{n+1}，即 R_n = O(1/x^{n+1})，与式 7.99 的定义吻合 ✓。
- 发散性：相邻项比 |a_{ν+1}/a_ν| = (ν+1)/x → ∞ ✓。
- 数值：S₄(10) = 0.1 − 0.01 + 0.002 − 0.0006 + 0.00024 = 0.09164；S₅(10) = 0.09152；由交错型余项单调性得 0.09152 < f(10) < 0.09164 ✓。另按公开特殊函数值核验（独立背景知识）：f(10) = e^{10}E₁(10) ≈ 0.091563，落于界内 ✓。
