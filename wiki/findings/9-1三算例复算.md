# 9.1 三算例复算

手册 9.1 节给出三个算例，本页记录独立于手册的复算过程与结论。三例均复算通过。

## 例 1：通解 → 特解

**手册原文（校正后）**：微分方程 −y′ sin x + y cos x = 1 有通解 y = cos x + c sin x；对于条件 c = 0，得到特解 y = cos x。

**复算**：对 y = cos x + c sin x 求导得 y′ = −sin x + c cos x。代入左端：

−(−sin x + c cos x) sin x + (cos x + c sin x) cos x = sin²x − c sin x cos x + cos²x + c sin x cos x = sin²x + cos²x = 1。

对任意 c 成立，故确为通解；c = 0 时特解 y = cos x。✓

**补充推导注记**：(y/sin x)′ = (y′ sin x − y cos x)/sin²x，故方程左端恒等于 −sin²x·(y/sin x)′，方程即 (y/sin x)′ = −csc²x，积分得 y/sin x = cot x + c，即 y = cos x + c sin x——与第 8 章 [[concepts/换元积分法]] 的化归思路同构。

## 例 2：弹性弹簧—质量系统的谐运动（初值问题）

**手册原文（校正后）**：一个特殊的弹性弹簧—质量系统的谐运动可以通过初值问题——具有初始条件 y(0) = y₀, y′(0) = 0 的 y″ + y = 0——进行建模，其解为 y = y₀ cos x。

**复算**：y″ + y = 0 的通解为 y = A cos x + B sin x。y(0) = A = y₀；y′ = −A sin x + B cos x，故 y′(0) = B = 0。得 y = y₀ cos x。代回：y″ = −y₀ cos x，y″ + y = 0。✓

**注**：该系统固有频率为 1，此性质只属于方程 y″ + y = 0，不应外推。

## 例 3：端点固定、均匀负载的细棒（边值问题）

**手册原文（校正后）**：端点固定和均匀负载的细棒形成的曲线由具有边界条件 y(0) = 0, y(1) = 0 的微分方程 y″ = x − x²（0 ≤ x ≤ 1）所描述，其解为 y = x³/6 − x⁴/12 − x/12。

**复算**：两次积分：

y′ = x²/2 − x³/3 + c₁，
y = x³/6 − x⁴/12 + c₁x + c₂。

由 y(0) = 0 得 c₂ = 0；由 y(1) = 0 得 1/6 − 1/12 + c₁ = 0，即 1/12 + c₁ = 0，c₁ = −1/12。得 y = x³/6 − x⁴/12 − x/12。代回验证 y″ = x − x²。✓

**注**：本例求解即两次使用第 8 章的不定积分运算加边界定常数（参见 [[comparisons/定积分与不定积分比较]] 所依托的第 8 章体系），构成与第 8 章的直接技术衔接。

## 复算结论汇总

| 算例 | 手册结果 | 复算结论 |
|---|---|---|
| 例 1 | 通解 y = cos x + c sin x；c = 0 ⇒ y = cos x | ✓（代入得 sin²x + cos²x = 1） |
| 例 2 | y = y₀ cos x | ✓（A = y₀, B = 0） |
| 例 3 | y = x³/6 − x⁴/12 − x/12 | ✓（c₁ = −1/12, c₂ = 0） |

三例均可由直接代换 / 求导 / 积分独立验证，属强证据；复算独立于手册完成且结果一致，replicated: true。
