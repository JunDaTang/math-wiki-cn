# 14.1.2 解析与非解析算例复算

以下算例分属各例证函数，逐一复算；直接证据为手册断言，复算为独立验证。

## w = z²（14.1.2.2 例 A）

$u = x^2 - y^2,\ v = 2xy$：

- $\partial u/\partial x = 2x = \partial v/\partial y$ ✓
- $\partial u/\partial y = -2y = -\partial v/\partial x$ ✓
- $\Delta u = 2 - 2 = 0$，$\Delta v = 0$ ✓

**处处解析——与原文一致**。

## u = 2x + y, v = x + 2y（14.1.2.2 例 B）

- $\partial u/\partial x = 2 = \partial v/\partial y$ ✓
- $\partial u/\partial y = 1$，而 $-\partial v/\partial x = -1$，第二柯西–黎曼方程处处失败 ✗

**在任意点都不解析——与原文一致**。

## f(z) = z³ 与 f(z) = sin z（14.1.2.1 例 A/B；14.1.2.2 例 C/D 为重复）

$f'(z) = 3z^2$ 与 $f'(z) = \cos z$，初等函数导数公式与相应实函数一致，两者解析。14.1.2.2 的例 C、D 与 14.1.2.1 的例 A、B 逐字重复（转录层结构冗余，见 [[queries/14-1-2全节系统性转写讹误清单]]）。

## w = 1/(z−a)（14.1.2.4 例 A）

在 $z = a$ 的去心邻域解析且 $z \to a$ 时 $|f| \to \infty$，按三分类为**极点**——与原文一致，与三分类定义相符。

## w = e^(1/z)（14.1.2.4 例 B）

在 $z = 0$ 的去心邻域解析；$|e^{1/z}| = e^{\operatorname{Re}(1/z)} = e^{x/(x^2+y^2)}$，沿 $y = 0,\ x \to 0^+$ 时趋于 $\infty$、沿 $y = 0,\ x \to 0^-$ 时趋于 $0$，故既非邻域有界（排除可去）、亦非 $|f| \to \infty$（排除极点），按三分类为**本质奇点**——与原文一致（路径分析为补充验证，属推断）。
