# 半角公式与附加关系（式 3.93–3.95）

**发现内容（直接证据，公式逐字保留）：**

半角公式：

$$\tan\frac{\alpha}{2} = \sqrt{\frac{(s-b)(s-c)}{s(s-a)}} \tag{3.93}$$

正切公式：

$$\tan\alpha = \frac{a\sin\beta}{c - a\cos\beta} = \frac{a\sin\gamma}{b - a\cos\gamma} \tag{3.94}$$

附加关系：

$$\sin\frac{\alpha}{2} = \sqrt{\frac{(s-b)(s-c)}{bc}} \tag{3.95a}$$

$$\cos\frac{\alpha}{2} = \sqrt{\frac{s(s-a)}{bc}} \tag{3.95b}$$

其中 $s = (a+b+c)/2$ 为半周长。经轮换可得关于 $\beta, \gamma$ 的对应公式。

**用途：**表 3.4 基本问题 (4)（三边已知）以 $\tan\frac{\alpha}{2} = r/(s-a)$ 的形式（配合内切圆半径 $r$）解角；基本问题 (2) 亦用半角结构。见 [[findings/一般三角形四个基本问题与SSA分支]]。

**内部一致性核验（分析层）：**$\tan\frac{\alpha}{2} = \sin\frac{\alpha}{2}/\cos\frac{\alpha}{2}$，以 (3.95a)/(3.95b) 代入恰得 (3.93)，三式自洽。

**备注：**更系统的三角恒等式讨论位于 3.3 节（三角函数，尚未摄入）；表 3.4(2)(3) 中的半角用法待该节摄入后再深入。**证据类型：**直接证据，强度高。
