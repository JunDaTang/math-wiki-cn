# 等额本金利息逐年递减且总利息有闭式

等额本金还款（$T = \frac{S}{mN}$ 为常数、年内还款不计算中期复利）下，第 n 个利息周期的利息关于 n 线性递减（式 (1.81a)），且 N 个周期的总利息存在闭式（式 (1.81b)）：

$$
Z_n = \frac{pS}{100}\left[1-\frac{1}{N}\left(n-\frac{m+1}{2m}\right)\right], \qquad
Z = \sum_{n=1}^{N} Z_n = \frac{pS}{100}\left[\frac{N-1}{2}+\frac{m+1}{2m}\right].
$$

## 证据

手册 1.3.3.2 算例：债务 €60000、年利率 8%、60 个月本金还款（每月末还本金 €1000），S = 60000、p = 8、N = 5、m = 12。逐年利息为 €4360、€3400、€2440、€1480、€520（公差 −€960 的等差数列），逐项求和与闭式 (1.81b) 均给出总利息 Z = €12200。分析对逐年利息与总额独立复算，结果一致；逐年递减的本质是[[等差级数]]求和。方法背景见 [[等额本金还款]]、[[分期付款]]。
