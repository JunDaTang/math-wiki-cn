# 式 9.148–9.152 五大典型方程与保守—耗散二分转录

## 转录内容

9.2.5.1.2 给出的五个典型方程（逐字）：

```latex
(9.148) = (9.153)  KdV:  u_t + 6 u u_x + u_{xxx} = 0
(9.149) = (9.158)  NLS:  i u_t + u_{xx} ± 2 |u|^2 u = 0
(9.150) = (9.162)  SG:   u_{tt} − u_{xx} + sin u = 0
(9.151)              GL:  u_t − u − (1 + i b) u_{xx} + (1 + i c) |u|^2 u = 0
(9.152)              KS:  u_t + u_{xx} + u_{xxxx} + u_x^2 = 0
```

配套约定：下标记偏导；一维情形 u = u(x,t)；自变量为无量纲标量，实际应用须乘以具有相应量纲并反映问题特征的量（对速度亦然）。

## 复算结论（直接证据）

- (9.148)、(9.149)、(9.150) 与 KdV/NLS/SG 的标准形式一致（iu_t + u_{xx} ± 2|u|²u = 0 为 NLS 的常见标准化约定之一）。
- (9.151) 与标准复 Ginzburg–Landau 方程（μ = 1 情形）一致，参数 b、c 为线性/非线性频移参数。
- (9.152) 为标准 Kuramoto–Sivashinsky 方程。
- 保守—耗散二分成立：KdV/NLS/SG 无耗散项；GL/KS 含耗散机制，且源文明言两者兼有时空周期解与混沌解——「时空模式或结构的出现是变成混沌的特征」。

## 转写注意点

1. 9.2.5.1(6) 列举的非线性项 u∂u/∂x、|u|²u、sin u、u_x² 中，u_x² 属 KS (9.152)，但随后的枚举只写 (9.148)–(9.150)；「这些方程（除了(9.151)是例外）不含参数」只有在枚举包含 (9.151)、(9.152) 时才通顺——疑转写丢失「(9.151)、(9.152)」。
2. 源文 GL 拼法「Ginsburg-Landau」、译名「兰道」照录；标准为 Ginzburg–Landau、朗道。
