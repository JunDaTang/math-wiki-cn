# 正则化问题与数值方法建议（式 4.191–4.192）

4.5.3.2 对最小二乘问题数值解的三条建议（各断言的归属须严格区分）：

1. **楚列斯基方法**：因 AᵀA 对称且（rank(A) = n 时）正定，可用楚列斯基方法解正规方程组（参见第 1245 页 19.2.1.2，转写作「楚列斯基金」，未入库）。源断言该路径「虽然在『大』残差 ‖r‖ 和『小』解 ‖x‖ 的情形实施得还算不错，但在数值上是相当不稳定的」——此断言针对**用楚列斯基方法解正规方程组这一路径**，非对楚列斯基方法本身的一般评价。
2. **豪斯霍尔德方法**：适用于解最小二乘问题的数值方法是正交化方法，基于分解 A = QR（Q 为 (m,m) 正交矩阵，R 为 (m,n) 三角矩阵；参见第 364 页 4.1.2 第 11 条，未入库），特别适用的是豪斯霍尔德方法。
3. **正则化问题**：秩亏情形（rank(A) < n，源作「秩亏格」，见 [[queries/秩亏格用语是否原文如此]]）下，正规方程组不再有唯一解，并且正交化方法给出无用的结果；于是代替 (4.189) 考虑：

```
rᵀr + α xᵀx = min!   (α > 0)          (4.191)
(AᵀA + αI) x = Aᵀb                     (4.192)
```

α > 0 时 (4.192) 的系数矩阵正定并且正则，但选取合适的正则化参数是一个困难的问题（源引文献 [4.7]，信息不透明）。

## 证据强度

属权威手册的定性断言：数值稳定性与正则化建议与数值线性代数常识一致（如正规方程化的条件数平方效应——此为独立背景知识，非源文明言），但源内未给定量证据、无数值算例，故置信中等、未复算。比较见 [[comparisons/楚列斯基与豪斯霍尔德方法比较]]。
