# 式 17.27 非游荡点定义与 Ω 集性质转录复算

**结论**：式 (17.27)（非游荡点定义）与 Ω(φᵗ) 的性质清单转录一致、内部自洽；其中「Ω(φᵗ) 是闭的不变集并包括所有周期轨和所有 Ū 中点的 ω 极限集」为手册断言，本次仅作转录级核对，未独立证明。

## 转录内容

```
(17.27)  ∀T > 0  ∃t, |t| ≥ T：φᵗ(U_p) ∩ U_p ≠ ∅
稳态解和周期轨仅含有非游荡点
Ω(φᵗ)：闭、{φᵗ} 的不变集，包括所有周期轨和所有 Ū 中点的 ω 极限集
```

## 核对说明

- 定义以「对任意邻域 U_p 与任意大 T，存在 |t|≥T 使 φᵗ(U_p) ∩ U_p ≠ ∅」刻画回返性，时向取 |t|≥T（双向回返），与流的可逆性匹配，转录无歧义。
- 「稳态解和周期轨仅含非游荡点」可由定义直接验证：平衡点恒驻任意邻域，周期轨上的点经周期整数倍时刻回返（平凡直接验证，通过）。
- Ω(φᵗ) 的闭性与不变性为标准结果，本次未复证（复算状态 null）。
- 转写问题：原文「包括所有周期轨和所有 中点的 ω 极限集」脱字，应为「所有 Ū 中点」；「设 {φᵗ} 是 维紧致的可定向流形 上的动力系统」中「n 维」「M」符号脱落。汇总见 [[queries/17-1-4全节系统性转写讹误清单]]。

该定义是 [[concepts/莫尔斯—斯梅尔系统]]条件 (3) 的基础。
