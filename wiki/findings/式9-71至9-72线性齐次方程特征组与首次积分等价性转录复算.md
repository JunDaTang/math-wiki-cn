# 式 9.71–9.72 线性齐次方程、特征组与首次积分等价性转录复算

本条目逐字转录 [[concepts/一阶线性偏微分方程]] 的定义组（式 9.71a–b）与 [[concepts/特征组（特征线法）]] 的求解理论组（式 9.72a–e），并对全节基石性等价定理——「线性齐次偏微分方程的解 ⟺ 特征组的首次积分」——作独立复算。

## 逐字转录

```latex
X₁ ∂z/∂x₁ + X₂ ∂z/∂x₂ + … + Xₙ ∂z/∂xₙ = Y                    (9.71a)
Y ≡ 0                                                           (9.71b)

dx₁/X₁ = dx₂/X₂ = … = dxₙ/Xₙ                                   (9.72a)
dxⱼ/dxₖ = Xⱼ/Xₖ   (j = 1,…,n)                                   (9.72b)
dxⱼ/dt = Xⱼ        (j = 1,2,…,n)                                (9.72c)
φᵢ(x₁,…,xₙ) = 0   (i = 1,2,…,n−1)                              (9.72d)
z = Φ(φ₁,…,φₙ₋₁)                                                (9.72e)
```

术语判定（源文原话）：系数 X₁,…,Xₙ,Y 仅依赖自变量时方程称线性；亦依赖 z 时称拟线性；Y ≡ 0（9.71b）时称齐次。

## 等价性定理的独立复算

设 φ(x₁,…,xₙ) 沿特征组（取参数形式 9.72c）为常数，则

dφ/dt = Σᵢ φ_{xᵢ}·dxᵢ/dt = Σᵢ φ_{xᵢ}Xᵢ = 0，

而 Σᵢ φ_{xᵢ}Xᵢ = 0 正是 Y ≡ 0 时的方程 (9.71a)。反之，齐次方程的任一解 z 满足 Σᵢ Xᵢz_{xᵢ} = 0，即 z 沿特征组为常数，故为首次积分。等价性成立。✅

## 通解结构的复算

若 φ₁,…,φₙ₋₁ 为 n−1 个无关首次积分，则对任意函数 Φ：

z = Φ(φ₁,…,φₙ₋₁) ⟹ Σᵢ Xᵢ ∂z/∂xᵢ = Σₖ Φ′(φₖ)·(Σᵢ Xᵢ ∂φₖ/∂xᵢ) = 0。✅

两种解法——把某个使 Xₖ ≠ 0 的 xₖ 取为自变量得 (9.72b)，或引入新参数 t 保持对称得 (9.72c)——只是同一特征组的两种参数化，彼此等价。

## 转写疑点

1. 源文称「方程组 (9.72a) 的每个首次积分都是线性齐次偏微分方程 (9.72a, b) 的解」——(9.72a, b) 是特征组本身而非偏微分方程，回指疑应为 (9.71a, b)，见 [[queries/式9-72a-b回指是否应为9-71a-b]]。
2. (9.72d) 将首次积分写作 φᵢ = 0 而非惯常的 φᵢ = Cᵢ，见 [[queries/式9-72d首次积分记法等于0还是等于常数]]。
3. (9.72b) 的标号 (j = 1,…,n) 未排除 j = k（此时为恒等式）。
4. (9.72c) 前的叙述「引进一个新变量 ，得到」缺变量名 t；其后「这里中是 n−1 个变元 φᵢ 的一个任意函数」缺任意函数记号 Φ。
5. 系统性 OCR 讹误：「依赖千」→「依赖于」等（「千」讹「于」）；「拟线性偏微分方」缺「程」字。

## 意义

该等价性使 [[concepts/首次积分]]（原 9.1.2 的 ODE 概念）成为 ODE 与 PDE 之间的双向桥梁：解一阶线性齐次 PDE 完全归结为解其特征组。注意此等价性**仅属齐次线性情形**；非线性方程须经 [[concepts/特征带]] 化归（见 [[findings/式9-76完全积分与特征带转录复算]]），不可移用本条等价性。全部讹误汇总见 [[queries/9-2-1全节系统性转写讹误清单]]。
