# 连续的 ε-δ 定义及单侧连续与终点约定（式 2.30）

《数学手册》(原书第10版) 2.1.5.2 给出连续性的定义体系，以下为直接证据（原文转写）。

## 三条件定义

函数 $y=f(x)$ 称为在点 $x=a$ 连续，若：

1. $f(x)$ 在 $a$ 点有定义；
2. $\lim_{x\to a}f(x)$ 存在且 $\lim_{x\to a}f(x)=f(a)$。

## ε-δ 刻画

```
对任意 ε > 0，存在 δ(ε) > 0，使得当 |x − a| < δ 时，
对一切 x 有 |f(x) − f(a)| < ε。                          (2.30)
```

**关键细节（与极限定义的对照）**：这里的邻域 $|x-a|<\delta$ 含 $a$ 点本身；而 2.1.4 函数极限定义使用去心邻域 $0<|x-a|<\eta$，且 $a$ 点无需有定义（见 [[findings/函数极限的精确定义及a点无需有定义]] 与 [[comparisons/连续定义与极限定义比较]]）。连续性恰好补上“$a$ 点有定义且极限等于函数值”这一环。

## 单侧连续、区间连续与处处连续

- **单侧连续**：若不管 $\lim_{x\to a}f(x)=f(a)$ 与否，只考虑一侧极限 $\lim_{x\to a-0}f(x)$（或 $\lim_{x\to a+0}f(x)$）且其等于 $f(a)$，则称为单侧（左侧或右侧）连续。记号 $f(a\mp0)$ 沿用 2.1.4.5（[[concepts/左极限与右极限]]）。
- **区间连续**：函数在 $a$ 到 $b$ 区间内每一点连续（区间可为开、半开或闭）。
- **处处连续**：函数在数轴上每一点都有定义且连续。

## 间断点与“终点”之辨

$x=a$ 为间断点，当且仅当下列情形之一：$f$ 在 $a$ 无定义；有定义但 $\lim_{x\to a}f(x)\neq f(a)$；极限不存在。间断点可能是定义域的内点或端点。但若函数仅在 $a$ 的一侧有定义（$\sqrt{x}$ 于 $0$、$\arccos x$ 于 $1$），则 $a$ 不是间断点，而是**终点**。
