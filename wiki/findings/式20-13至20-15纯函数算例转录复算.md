# 式20-13至20-15纯函数算例转录复算

本 finding 复算手册 20.2.6.3 的三个纯函数算例，并区分**直接证据**（源文所载会话）与**推断**（版本显示形态考据）。

## 直接证据（源文转录）

```text
In[1] := Function[x, x^3 + x^2]  ⟶  Out[1] = Function[x, x^3 + x^2]   (20.13)
In[2] := Function[x, x^3 + x^2][c]  给出  Out[2] = c^2 + c^3           (20.14)
In[3] := (#^3 + #^2)&[c]   Out[3] = c^2 + c^3                          (20.15)
```

## 复算结论（式 20.14、20.15：一致）

- **式 20.14**：`Function[x, x^3 + x^2][c]` 即以 c 代 x，得 c^3 + c^2；手册 Out[2] = c^2 + c^3 为升幂项序，恰合 Mathematica 对 Plus 内多项式项的 canonical 排序。**复算一致**。
- **式 20.15**：`(#^3 + #^2)&[c]` 中 `#` 为变元占位符，代入 c 同得 c^2 + c^3。**复算一致**。
- 两式输出相同，直接印证完整形式与简写形式的语义等价（[[comparisons/纯函数完整形式与简写形式比较]]）。
- Out 的升幂项序是转录忠实性的有力旁证：若系随意誊写，不易恰与 canonical 排序吻合。

## 式 20.13 的 Out 形态（推断性存疑）

印刷的 Out[1] = `Function[x, x^3 + x^2]` 保留了输入的项序（x^3 在前），与 Out[2] 所示的系统升幂规范序不一致；按此，朴素复算预期的显示应为规范序形态。可能的解释：旧版本显示行为，或作者理想化誊写（照录输入式）。关于现代版本的确切显示形态，有考据意见认为求值 `Function[x, x^3 + x^2]` 会规约为 Slot 形式（形如 `#1^2 + #1^3 &`），亦有可能是保留 `Function` 形式而仅将主体重排为规范序——两种机制的孰是孰非需以实际版本复核，本源内不可检验。故此条立为**版本考据问题，不径断为转写讹误**；其断代意义可与 [[queries/与第10版兼容的各版本所指之辨]] 并观。
