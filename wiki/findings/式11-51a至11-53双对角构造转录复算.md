# 式 11.51a–11.53 双对角构造转录复算

## 转录

递推（逐字保留）：

$$
\nu_1\beta_1(y)=\int_c^d K(x,y)\alpha_1(x)\,\mathrm{d}x\tag{11.51a}
$$
$$
\nu_j\beta_j(y)=\int_c^d K(x,y)\alpha_j(x)\,\mathrm{d}x-\mu_{j-1}\beta_{j-1}(y)\quad(j\neq1)\tag{11.51b}
$$
$$
\mu_j\alpha_{j+1}(x)=\int_a^b K(x,y)\beta_j(y)\,\mathrm{d}y-\nu_j\alpha_j(x)\tag{11.51c}
$$

核矩阵分块双对角形式（11.52）：块 K^m 为下双对角（ν 对角、μ 次对角）；零行与零列的数目相应于 (α_n^h) 与 (β_n^h) 中函数的数目；块内只含单个 ν₁^(m) = ν_m 时「非常简单」。解公式（11.53，在 α_j ∈ (α_n^h) ⟹ f_j = 0 的假设下）：

$$
c_j=\begin{cases}\dfrac{f_j}{\nu_j},&\beta_j(y)\notin\big(\beta_n^h(y)\big),\\[4pt]\text{任意},&\beta_j(y)\in\big(\beta_n^h(y)\big).\end{cases}\tag{11.53}
$$

## 复算

- **递推的算子形式**：(11.51a–c) 等价于 T*α₁ = ν₁β₁、T*α_j = ν_jβ_j + μ_{j−1}β_{j−1}（j ⩾ 2）、Tβ_j = ν_jα_j + μ_jα_{j+1}。✓
- **正交性归纳**：设 α_j ⊥ 此前所有 α 及 (α_n^h)、β_j ⊥ 此前所有 β 及 (β_n^h)，则由构造（每步取残差再归一化）得 α_{j+1}、β_j 满足相应正交性——归纳核对通过。✓
- **核矩阵结构**：K_ij = ⟨α_i, Tβ_j⟩ = ν_jδ_ij + μ_jδ_{i,j+1}，即仅 i = j、i = j+1 非零，与 (11.52) 一致。✓
- **零行/零列论断**：α_i ∈ (α_n^h) 时 T*α_i = 0，故行 i 全零（K_ij = ⟨T*α_i, β_j⟩ = 0）；β_j ∈ (β_n^h) 时 Tβ_j = 0，故列 j 全零。✓
- **假设条件的验证**：α_j ∈ (α_n^h) ⟹ f_j = ⟨f, α_j⟩ = ⟨Tφ, α_j⟩ = ⟨φ, T*α_j⟩ = 0。✓
- **⚠️ 解公式 (11.53) 与结构不匹配**：双对角块的无穷方程组 ν_jc_j + μ_jc_{j+1} = f_j 型（按 (11.52) 的排列）需**向前代入** c_j = (f_j − μ_{j−1}c_{j−1})/ν_j 逐个解出；转写的 c_j = f_j/ν_j 仅在 μ ≡ 0 的「非常简单」情形成立。(11.53) 之前尚有残句「无穷方程组的解有 f」，疑转写脱落递推项或原书限于简单情形——已立 [[queries/式11-53解公式与双对角向前代入的关系]]。

## 结论

双对角化构造的递推、正交性与结构论断复算全部通过；解公式存疑待原文核对，故 confidence 取 medium、replicated 取 null。构造的整体流程见 [[methodology/核矩阵双对角化构造流程]]。

## 转写疑误

情形 (b) 的两个子情形标签均残为「伽）」；「正交千…贮再对 j=1,2,…」含残字「贮」；「用函 β_n^h」脱「数」；「在 中零行」脱「K」——见 [[queries/11-3-5情形b子情形标签残缺]] 与 [[queries/11-3全节系统性转写讹误清单]]。
