# 式 8.161–8.165 一般类型曲面积分与性质转录

转录 8.5.3.1「一般类型的曲面积分的概念」（式 8.161–8.162）与 8.5.3.2「曲面积分的性质」前三条（式 8.163–8.165）。

## 定义与化算

若 $P(x,y,z), Q(x,y,z), R(x,y,z)$ 为定义在一连通区域上的三个三元函数，$S$ 为该区域内的有向曲面，则在三个坐标面上投影的第二类积分之和称为一般类型的曲面积分：

$$\int_{S} (P\,\mathrm{d}y\,\mathrm{d}z + Q\,\mathrm{d}z\,\mathrm{d}x + R\,\mathrm{d}x\,\mathrm{d}y) = \int_{S} P\,\mathrm{d}y\,\mathrm{d}z + \int_{S} Q\,\mathrm{d}z\,\mathrm{d}x + \int_{S} R\,\mathrm{d}x\,\mathrm{d}y \tag{8.161}$$

该公式可化为二重积分：

$$\int_{S} (P\,\mathrm{d}y\,\mathrm{d}z + Q\,\mathrm{d}z\,\mathrm{d}x + R\,\mathrm{d}x\,\mathrm{d}y) = \int_{\Delta} \Big[P\frac{D(y,z)}{D(u,v)} + Q\frac{D(z,x)}{D(u,v)} + R\frac{D(x,y)}{D(u,v)}\Big]\mathrm{d}u\,\mathrm{d}v \tag{8.162}$$

其中三个 [[concepts/雅可比行列式]] 与 $\Delta$ 与前面的意义相同。向量场理论一章讨论了向量值函数的曲面积分（源回指第 942 页 13.3.2，「页」字脱漏）。

## 性质（8.5.3.2）

**(1) 可加性（式 8.163，图 8.47）**：若积分区域即曲面 $S$ 能分成两部分 $S_1$ 和 $S_2$，则

$$\int_{S} (\cdots) = \int_{S_1} (\cdots) + \int_{S_2} (\cdots)$$

（其中 $(\cdots)$ 代 $P\,\mathrm{d}y\,\mathrm{d}z + Q\,\mathrm{d}z\,\mathrm{d}x + R\,\mathrm{d}x\,\mathrm{d}y$，下同。）

**(2) 反向变号（式 8.164）**：若曲面改变方向，即内外侧互换，则积分变号：

$$\int_{S^+} (\cdots) = -\int_{S^-} (\cdots)$$

其中 $S^+$ 和 $S^-$ 表示同一曲面的两个不同方向。

**(3) 曲面依赖（式 8.165）**：通常曲面积分与曲面区域的边界及曲面本身有关，因此对于（源文讹「对千」）由相同闭曲线张成的两个不同的非闭曲面区域 $S_1$ 和 $S_2$，它们的积分往往不同（图 8.47）：

$$\int_{S_1} (\cdots) \neq \int_{S_2} (\cdots)$$

## 分析注记

- 性质 (3) 是 Stokes 型定理适用条件的前奏：积分一般不只依赖边界闭曲线，还依赖曲面本身；何种条件下只依赖边界（通量/环流量与所张曲面无关）需附加旋度/散度类条件，源文未展开。
- 性质 (2) 与 [[concepts/有向曲面]] 的投影符号规则一致；性质 (1)–(3) 均针对一般类型（即第二类）积分，**不可迁移**到与定向无关的 [[concepts/第一类曲面积分]] → [[comparisons/三类曲面积分比较]]。
