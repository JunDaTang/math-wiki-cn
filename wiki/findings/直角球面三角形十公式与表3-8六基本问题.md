# 直角球面三角形十公式与表 3.8 六基本问题

## 十条专门公式（(3.202a)–(3.202h) 为直接证据；(3.202i)(3.202j) 为复原·推断）

由 γ = 90° 从 (3.187d)–(3.191b) 推出：

```
sin a = sin α sin c   (3.202a)      tan a = cos β tan c    (3.202e)
sin b = sin β sin c   (3.202b)      tan b = cos α tan c    (3.202f)
cos c = cos a cos b   (3.202c)      tan b = sin a tan β    (3.202g)
cos c = cot α cot β   (3.202d)      tan a = sin b tan α    (3.202h)
【复原·推断】cos α = cos a sin β   (3.202i)
【复原·推断】cos β = cos b sin α   (3.202j)
```

复原依据：(3.202i)(3.202j) 本体在转写中缺失（仅剩编号），但被表 3.8 问题 (4)(5)(6) 引用；其形式与 (3.202f)/(3.202e) 经 (3.202b)/(3.202a)、(3.202c) 代数一致（如 cos a·sin β = cos a·sin b/sin c = tan b/tan c·cos... 逐项可验证），且使表 3.8 全部指派自洽。详见 [[queries/式3-202i与3-202j本体脱落是否可复原]]。

## 表 3.8 六基本问题（直接证据，公式指派经逐项核验自洽）

| 基本问题 | 已知的确定量 | 所需公式编号 |
|---|---|---|
| (1) | 斜边和一直角边 c, a | α (3.202a), β (3.202e), b (3.202c) |
| (2) | 两直角边 a, b | α (3.202h), β (3.202g), c (3.202c) |
| (3) | 斜边和一个角 c, α | a (3.202a), b (3.202f), β (3.202d) |
| (4) | 一直角边和其上的角 a, β | c (3.202e), b (3.202j), α (3.202i) |
| (5) | 一直角边和其所对的角 a, α | b (3.202h), c (3.202a), β (3.202i) |
| (6) | 两个角 α, β | a (3.202i), b (3.202j), c (3.202d) |

若给定其他的边或角（例如 b, γ, α 而非 α, β, γ），可通过量的轮换得到必需的等式；计算通常从 γ = 90° 与两个其他已知量开始。十条公式由 [[concepts/纳皮尔法则]] 统一概括（见 [[findings/纳皮尔法则两条规则]]）。
