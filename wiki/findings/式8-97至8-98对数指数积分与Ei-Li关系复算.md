# 对数积分与指数积分及 Ei–Li 关系复算（式 8.97–8.98）

## 逐字转录

```latex
\operatorname{Li}(x) = \int_{0}^{x} \frac{\mathrm{d}t}{\ln t}
= C + \ln|\ln x| + \ln x + \frac{(\ln x)^{2}}{2 \cdot 2!} + \dots + \frac{(\ln x)^{n}}{n \cdot n!} + \dots \tag{8.97}

\operatorname{Ei}(x) = \int_{-\infty}^{x} \frac{\mathrm{e}^{t}}{t}\,\mathrm{d}t
= C + \ln|x| + x + \frac{x^{2}}{2 \cdot 2!} + \dots + \frac{x^{n}}{n \cdot n!} + \dots \tag{8.98a}

\operatorname{Ei}(\ln x) = \operatorname{Li}(x). \tag{8.98b}
```

## 复算记录（直接证据：独立重推导，全部一致）

- Ei 级数：由 eᵗ/t = 1/t + Σ_{n≥1} t^{n−1}/n! 积分得 ln|x| + Σ xⁿ/(n·n!) + 常数，常数恰为欧拉常数（标准结果 Ei(x) = γ + ln|x| + ⋯，本书记 C），与原书一致。
- Ei–Li 桥梁：在 ∫₀ˣ dt/ln t 中作代换 t = e^u（dt = e^u du）得 ∫_{−∞}^{ln x} e^u/u du = Ei(ln x)，即式 8.98b 成立（在相应的收敛/主值约定下）。
- Li 级数：在 Ei 的级数中以 ln x 代 x 即得 Li 的级数，与式 8.97 一致。
- 绝对值：ln|ln x| 与 ln|x| 的绝对值与奇点两侧的取值相符。

## 定义域括注的复原（推理，非直接证据）

- 转写原文「(0<x<1, 1<x<∞ 时为柯西主值)」「(−∞<x<0 当 0<x<∞ 时为柯西主值)」标点与连词错乱。
- 按数学事实复原：Li 仅当积分穿越奇点 t = 1（即 1 < x < ∞）时需柯西主值；Ei 仅当穿越奇点 t = 0（即 0 < x < ∞）时需柯西主值。
- 复原读法：「0<x<1；当 1<x<∞ 时为柯西主值」「−∞<x<0；当 0<x<∞ 时为柯西主值」，待原书核对，见 [[8-2-5全节系统性转写讹误清单]] 与 [[柯西主值]]。
