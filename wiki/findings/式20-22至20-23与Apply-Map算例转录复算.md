# 式 20.22–20.23 与 Apply-Map 算例转录复算

## 转录（verbatim，已清除 OCR 空格讹误；存疑处以注标出）

定义式：

```
Apply[f, {a, b, c, ...}]  →  f[a, b, c, ...]          (20.22)
Map[f,   {a, b, c, ...}]  →  {f[a], f[b], f[c], ...}  (20.23)
```

Apply 会话：

```
In[1] := Apply[Plus, {u, v, w}]                → Out[1] = u + v + w
In[2] := Apply[List, a + b + c]                → Out[2] = {a, b, c}
In[3] := FullForm[Apply[List, Plus[a, b, c]]]  → Out[3] = List[a, b, c]
```

Map 会话：

```
In[1] := f[x_] := x^2
In[2] := Map[f, {u, v, w}]      → Out[2] = {u^2, v^2, w^2}
In[3] := Map[f, Plus[a, b, c]]  → Out[3] = a^2 + b^2 + c^2
```

## 复算（符号推演，独立进行）

1. `Apply[Plus, {u,v,w}]`：`{u,v,w}` 即 `List[u,v,w]`，头 List 替换为 Plus → `Plus[u,v,w]` = `u+v+w` ✓
2. `Apply[List, a+b+c]`：`a+b+c` 即 `Plus[a,b,c]`，头 Plus 替换为 List → `List[a,b,c]` = `{a,b,c}` ✓
3. `FullForm[Apply[List, Plus[a,b,c]]]`：同上替换后再取完整形式 → `List[a,b,c]` ✓
4. `Map[f, {u,v,w}]`：保 List 头，f 施于各元素 → `{f[u], f[v], f[w]}` = `{u²,v²,w²}` ✓
5. `Map[f, Plus[a,b,c]]`：保 Plus 头，f 施于各变元 → `Plus[f[a],f[b],f[c]]` = `a²+b²+c²` ✓

两条定义式与五条算例全部复算通过，与 Mathematica 的头替换/逐元映射语义一致。属直接证据（源文载完整会话）；复算为符号层面推演，非数值实验。
