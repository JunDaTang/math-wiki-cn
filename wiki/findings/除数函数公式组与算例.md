# 除数函数 τ、P、σ 公式组与算例

## 公式组（式 5.228a–d，原样保留）

$$t=\prod_{k=1}^{m} p_k^{\tau_k},\quad \tau_k\in\{0,1,2,\dots,\alpha_k\},\quad k=1,2,\dots,n\ (\text{应为 } m)\tag{5.228a}$$

$$\tau(n)=\prod_{k=1}^{m}(\alpha_k+1)\tag{5.228b}$$

$$P(n)=n^{\frac{1}{2}\tau(n)}\tag{5.228c}$$

$$\sigma(n)=\prod_{k=1}^{m}\frac{p_k^{\alpha_k+1}-1}{p_k-1}\tag{5.228d}$$

## 算例（本次独立复算，全部通过）

- $\tau(5040)=\tau(2^4\cdot3^2\cdot5\cdot7)=(4+1)(2+1)(1+1)(1+1)=60$ ✓
- 两两不同素数 $p_1,\dots,p_r$：$\tau(p_1\cdots p_r)=2^r$ ✓
- $P(20)=20^3=8000$ ✓（因子 $1,2,4,5,10,20$ 之积）
- $P(p^3)=p^6$ ✓；$P(pq)=p^2q^2$ ✓
- $\sigma(120)=\sigma(2^3\cdot3\cdot5)=15\cdot4\cdot6=360$ ✓
- $\sigma(p)=p+1$ ✓

## 记号与讹误注意

- 源文 (5.228a) 末尾「$k=1,2,\dots,n$」应为 $k=1,2,\dots,m$（$m$ 为互异素因子个数），见 [[queries/式5-228a末尾上标是否应为m]]。
- 源文用 $\tau_k$ 记因子指数，与因子个数 $\tau(n)$ 撞名，引用时须区分。
