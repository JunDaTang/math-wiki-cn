# 式 8.118–8.121 一般线积分三性质与两算例复算

**结论**：8.3.3.1–8.3.3.2 的一般类型线积分定义、三条性质转录如下；两算例（螺旋线、抛物线）经独立复算**全部吻合**。

## 定义与三性质（逐字转录）

平面曲线：

$$\int_{(C)} (P\,\mathrm{d}x + Q\,\mathrm{d}y) = \int_{(C)} P\,\mathrm{d}x + \int_{(C)} Q\,\mathrm{d}y, \tag{8.118a}$$

空间曲线：

$$\int_{(C)} (P\,\mathrm{d}x + Q\,\mathrm{d}y + R\,\mathrm{d}z) = \int_{(C)} P\,\mathrm{d}x + \int_{(C)} Q\,\mathrm{d}y + \int_{(C)} R\,\mathrm{d}z. \tag{8.118b}$$

1. **积分路径的分解**（用 $\widehat{AB}$ 上一点 $M$、甚至 $\widehat{AB}$ 外一点 $M$，图 8.26）：

$$\int_{\widehat{AB}} (P\,\mathrm{d}x + Q\,\mathrm{d}y) = \int_{\widehat{AM}} (P\,\mathrm{d}x + Q\,\mathrm{d}y) + \int_{\widehat{MB}} (P\,\mathrm{d}x + Q\,\mathrm{d}y). \tag{8.119}$$

2. **积分路径反向，积分变号**：

$$\int_{\widehat{AB}} (P\,\mathrm{d}x + Q\,\mathrm{d}y) = -\int_{\widehat{BA}} (P\,\mathrm{d}x + Q\,\mathrm{d}y). \tag{8.120}$$

3. **路径的相关性**（图 8.27）：

$$\int_{\widehat{AMB}} (P\,\mathrm{d}x + Q\,\mathrm{d}y) \neq \int_{\widehat{ADB}} (P\,\mathrm{d}x + Q\,\mathrm{d}y). \tag{8.121}$$

对三元函数也有类似公式成立。

## 例 A 复算（螺旋线一圈）

$$I = \int_{(C)} (xy\,\mathrm{d}x + yz\,\mathrm{d}y + zx\,\mathrm{d}z),$$

其中 $C$ 为螺旋线 $x=a\cos t,\ y=a\sin t,\ z=bt$（参见第 348 页螺旋线，未入库）从 $t_0=0$ 到 $T=2\pi$ 的一圈：

$$I = \int_{0}^{2\pi} (-a^3\sin^2 t\cos t + a^2bt\sin t\cos t + ab^2t\cos t)\,\mathrm{d}t = -\frac{\pi a^2 b}{2}.$$

**复算**（代入 $\mathrm{d}x=-a\sin t\,\mathrm{d}t$、$\mathrm{d}y=a\cos t\,\mathrm{d}t$、$\mathrm{d}z=b\,\mathrm{d}t$，三项系数核验无误）：

- $\int_0^{2\pi}\sin^2 t\cos t\,\mathrm{d}t = \left[\frac{\sin^3 t}{3}\right]_0^{2\pi} = 0$；
- $\int_0^{2\pi} t\sin t\cos t\,\mathrm{d}t = \frac{1}{2}\int_0^{2\pi} t\sin 2t\,\mathrm{d}t = \frac{1}{2}\left[-\frac{t\cos 2t}{2}\right]_0^{2\pi} = -\frac{\pi}{2}$，乘 $a^2b$ 得 $-\frac{\pi a^2b}{2}$；
- $\int_0^{2\pi} t\cos t\,\mathrm{d}t = \left[t\sin t+\cos t\right]_0^{2\pi} = 0$。

合计 $I = 0 - \frac{\pi a^2 b}{2} + 0 = -\frac{\pi a^2 b}{2}$，**吻合** ✓

## 例 B 复算（抛物线弧）

$$I = \int_{(C)} \left[y^2\,\mathrm{d}x + (xy - x^2)\,\mathrm{d}y\right],$$

其中 $C$ 为抛物线 $y^2=9x$ 上位于点 $(0,0)$ 和 $B(1,3)$ 间的弧段：

$$I = \int_{0}^{3} \left[\frac{2}{9}y^3 + \left(\frac{y^3}{9} - \frac{y^4}{81}\right)\right]\mathrm{d}y = 6\frac{3}{20}.$$

**复算**（以 $y$ 为参数：$x=\frac{y^2}{9}$，$\mathrm{d}x=\frac{2y}{9}\,\mathrm{d}y$，$y:0\to 3$；$y^2\,\mathrm{d}x=\frac{2}{9}y^3\,\mathrm{d}y$，$xy-x^2=\frac{y^3}{9}-\frac{y^4}{81}$，被积式核验无误）：

$$I = \int_0^3\left(\frac{y^3}{3} - \frac{y^4}{81}\right)\mathrm{d}y = \frac{27}{4} - \frac{3}{5} = \frac{123}{20} = 6\frac{3}{20},$$

**吻合** ✓
