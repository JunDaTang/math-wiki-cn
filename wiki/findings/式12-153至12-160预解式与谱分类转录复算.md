# 式 12.153–12.160 预解式与谱分类转录复算

## 逐字转录

```
(I−T)x = y                                                   (12.153)
(λI−T)x = y,  x∈X, λ∈ℂ                                       (12.154)
|λ−λ₀| ⩽ 1/‖R_{λ₀}‖                                           (12.155) ⚠️
R_λ = R_{λ₀} + (λ−λ₀)R_{λ₀}² + (λ−λ₀)²R_{λ₀}³ + … = Σ_{k=1}^∞ (λ−λ₀)^{k−1} R_{λ₀}^k   (12.156)
R_λ = −1/λ − T/λ² − T²/λ³ − …                                 (12.157) ⚠️
R_λR_μ = R_μR_λ = (R_λ−R_μ)/(λ−μ)  (λ,μ∈ϱ(T), λ≠μ)            (12.158)
r(T) = sup_{λ∈σ(T)}|λ|                                        (12.159)
σ(T) = σ_p(T) ∪ σ_c(T) ∪ σ_r(T)  （两两不交）                    (12.160)
```

## 复算判定

- **(12.156) 复算无误**：由 $R_\lambda=R_{\lambda_0}\bigl(I-(\lambda-\lambda_0)R_{\lambda_0}\bigr)^{-1}$ 作几何级数展开即得。
- **(12.155) 不等号疑误**：展开 (12.156) 的几何优控要求 $\|(\lambda-\lambda_0)R_{\lambda_0}\|<1$；当 $|\lambda-\lambda_0|=\frac1{\|R_{\lambda_0}\|}$ 取等时，通项范数为常数 $\|R_{\lambda_0}\|$、不趋于零，级数收敛无保障。标准陈述应为**严格不等号**。见 [[queries/式12-155预解式邻域不等号应为严格]]。
- **(12.157) 与 (12.144) 矛盾（源内）**：由 $(\lambda I-T)^{-1}=\lambda^{-1}\bigl(I-\lambda^{-1}T\bigr)^{-1}$ 展开应为**正**号 $\lambda^{-1}I+\lambda^{-2}T+\lambda^{-3}T^2+\cdots$，与 (12.144) 及 12.5.2.9-b)（$\lambda=1$ 正号级数）一致；(12.157) 全负号且首项缺 $I$，二者必有一误（判定 (12.157) 误）。见 [[queries/式12-157与式12-144诺伊曼级数符号矛盾]]。
- **(12.158) 复算无误**：$(\lambda I-T)-(\mu I-T)=(\lambda-\mu)I$，左乘 $R_\lambda$、右乘 $R_\mu$ 即得第一预解式恒等式。
- **(12.160) 复算无误**：按 $\lambda I-T$ 的内射性与值域稠密性分类，$\sigma_c$（内射 + 值域稠）与 $\sigma_r$（内射 + 值域不稠）互斥，加上点谱（非内射），三分穷尽谱且两两不交。
- (12.159) 为谱半径与谱的关系式，标准结果，转录无误。
