# 费马-欧拉定理与 9^(9^9) 末三位算例（式 5.262，全链复算得 289）

**发现**：手册 5.4.4.2 给出的费马-欧拉定理及 9^(9^9) 十进制末三位算例成立，末三位为 289；本库分析者对整条推理链逐步复算，结果一致。

定理（式 5.262）：

```latex
a^{\varphi(m)} \equiv 1 \pmod{m} \quad (\gcd(a,m)=1)
```

源文算例（原样保留，求 x 使 x ≡ 9^(9^9) (mod 1000)，0 ⩽ x ⩽ 999）：

```latex
\varphi(1000)=400, \qquad 9^{400} \equiv 1 \pmod{1000}
```

```latex
9^{9} = (80+1)^4\cdot 9 \equiv (1 + 4\cdot 80)\cdot 9 \equiv -79\cdot 9 \equiv 89 \pmod{400}
```

```latex
9^{9^9} \equiv 9^{89} = (10-1)^{89} \equiv -1 + 89\cdot 10 - \binom{89}{2}\cdot 100 \equiv -1 - 110 + 400 = 289 \pmod{1000}
```

**复算记录**（分析者逐步验证，直接证据为源文算例本身）：
- φ(1000) = φ(2³·5³) = 1000·(1/2)·(4/5) = 400。✓
- (80+1)⁴ ≡ 1 + 4·80 = 321 (mod 400)（80² = 6400 ≡ 0 (mod 400)，高次项截断）；321·9 = 2889 = 7·400 + 89 ≡ 89 (mod 400)。源文以 −79·9 = −711 ≡ 89 (mod 400) 表述，同一结果。✓
- 9^9 = 387420489 = 968551·400 + 89 ≡ 89 (mod 400)。✓
- C(89,2) = 89·88/2 = 3916。✓
- (10−1)^89 ≡ −1 + 890 − 391600 (mod 1000)：其中 890 ≡ −110、−391600 ≡ 400 (mod 1000)，故 −1 − 110 + 400 = 289；直接合并亦得 −390711 + 391·1000 = 289。✓
- 结论：9^(9^9) 的十进制表示以 289 结尾。

**证据强度**：强——定理为经典结果，算例全链复算一致。

**保留事项**：算例正文「依据费马定理 9^400 ≡ 1 (1000)」的表述：m=1000 为合数，适用的应为费马-欧拉定理（欧拉形式），疑脱落「－欧拉」二字，见 [[queries/正文费马定理是否应为费马欧拉定理]]。
