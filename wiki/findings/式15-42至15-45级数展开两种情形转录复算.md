# 式 15.42–15.45 级数展开两种情形转录复算

## 编号公式转录

```latex
(15.42)  F(p) = Σ_{n=0}^{∞} aₙ/p^{λₙ},   0 < λ₀ < λ₁ < ⋯ < λₙ < ⋯ （句末疑为 λₙ → ∞）
(15.43)  f(t) = Σ_{n=0}^{∞} aₙ t^{λₙ−1}/Γ(λₙ)
(15.44)  (1/2πi)∫_{c−iyₙ}^{c+iyₙ} e^{tp}F(p)dp = Σ_{v=1}^{n} b_v e^{p_v t} − (1/2πi)∫_{(Kₙ)} e^{tp}F(p)dp
(15.45)  f(t) = Σ_{v=1}^{∞} b_v e^{p_v t},   若 (1/2πi)∫_{(Kₙ)} e^{tp}F(p)dp → 0
```

特例句：$\lambda_n=n+1$ 时 $F(p)=\sum a_{n+1}/p^{n+1}$ ⟹ $f(t)=\sum\frac{a_{n+1}}{n!}t^n$，对任意实数和复数 $t$ 收敛（源文「敛」疑脱「收」），且 $|f(t)|<Ce^{c|t|}$（$C,c$ 实常数）。

## 情形 1 算例转录（$J_0$）

$F(p)=\frac{1}{\sqrt{1+p^2}}=\frac{1}{p}\left(1+\frac{1}{p^2}\right)^{-1/2}=\sum_{n=0}^{\infty}\binom{-\frac12}{n}\frac{1}{p^{2n+1}}$（源文首行 binom 脱「n」）；逐项变换到原始空间（源文讹作「原始土 间」）后

$$f(t)=\sum_{n=0}^{\infty}\binom{-\tfrac12}{n}\frac{t^{2n}}{(2n)!}=\sum_{n=0}^{\infty}\frac{(-1)^n}{(n!)^2}\left(\frac{t}{2}\right)^{2n}=J_0(t)\quad(0\ \text{阶贝塞尔函数}).$$

## 情形 2（亚纯函数）要点转录

$F(p)$ 亚纯（两个没有共同根的整函数之商，源文「幕级数」应为「幂级数」）⟹ 可写为整函数与无穷部分分式之和 ⟹ 式 15.44；$p_v$ 为一阶极点、$b_v$ 为相应留数（第 983 页 14.3.5.4）；$K_n$ 为特定曲线（图 15.19 半圆）。条件「$(K_n)$ 上积分 $\to0$」成立时得式 15.45；「当 $y_n\to\infty$ 时这一点通常不容易证明」。末句「当亚纯函数 $F(p)$ 的有理部分一致为 [?] 时，上述结果是赫维赛德展开定理对亚纯函数的正式应用」存在脱文。

## 复算

- 恒等式 $\binom{-1/2}{n}=\frac{(-1)^n(2n)!}{4^n(n!)^2}$，故 $\binom{-1/2}{n}/(2n)!=\frac{(-1)^n}{(n!)^2}\cdot\frac{1}{4^n}$，即逐项求逆结果与 $J_0$ 的标准级数 $\sum\frac{(-1)^n}{(n!)^2}(t/2)^{2n}$ 一致。**通过**。
- 式 15.43 依赖 $\mathcal{L}^{-1}\{p^{-\lambda}\}=t^{\lambda-1}/\Gamma(\lambda)$，标准且一致；特例 $\lambda=n+1$ 用 $\Gamma(n+1)=n!$。**通过**。
- 式 15.44–15.45 的结构（竖直线积分 = 留数指数和 − 辅助曲线积分）与[[concepts/留数定理]]的围道论证相容；本 finding 未对一般亚纯情形另行构造算例，其收敛条件属源文自认的难点。**结构自洽**。

## 直接证据与推断

- 直接证据：四式编号、$J_0$ 例、特例句、「通常不容易证明」与「正式应用」句均源文原载。
- 推断（复算）：binom 恒等式与 $\Gamma$ 对应为复算者补写验证；两处脱文的拟补（「Γ」与数值「0」）为推测，已另立查询追踪。

## 转录疑点

「表示 函数」疑脱「Γ」（[[queries/式15-43后表示函数疑脱gamma]]）、「一致为 时」疑脱数值（[[queries/亚纯函数句有理部分一致为疑脱数值]]）、式 15.44 说明句下标 $y_v/K_v$ 与公式的 $y_n/K_n$ 不一致且句式错乱、「l.」应为「1.」。完整清单见[[queries/15-2-2全节系统性转写讹误清单]]。
