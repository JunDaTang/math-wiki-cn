# 色彩–成熟等级模糊关系矩阵算例（式 5.365–5.366，已复算）

本算例出自 5.9.3.1.4：色彩 $x$ 与水果成熟等级 $y$ 间的对应关系用二元关系矩阵建模，$X=\{$绿, 黄, 红$\}$，$Y=\{$未成熟, 半成熟, 成熟$\}$。

**清晰情形（式 5.365）**：单位阵——绿色→未成熟、黄色→半成熟、红色→成熟一一对应：

$$R=\begin{pmatrix}1&0&0\\0&1&0\\0&0&1\end{pmatrix}$$

**模糊化情形（式 5.366）**：若要表述「绿色水果可以以某个百分比看作半成熟的」，列出九个离散隶属值，得到 $\mu_R\in[0,1]$ 的关系矩阵：

| | 未成熟 | 半成熟 | 成熟 |
|---|---|---|---|
| 绿 | 1.0 | 0.5 | 0.0 |
| 黄 | 0.25 | 1.0 | 0.25 |
| 红 | 0.0 | 0.5 | 1.0 |

$$R=\begin{pmatrix}1.0&0.5&0.0\\0.25&1.0&0.25\\0.0&0.5&1.0\end{pmatrix}$$

## 复核

- **直接证据**：矩阵 (5.366) 与文中九个隶属值（$\mu_R(\text{绿},\text{未成熟})=1.0$、$\mu_R(\text{绿},\text{半成熟})=0.5$、…、$\mu_R(\text{红},\text{成熟})=1.0$）逐项对应。
- **复算**：入库时已将矩阵每一元素与九个隶属值逐项比对，全部吻合（replicated: true 指此项算术复核）。清晰情形（对角阵）是模糊情形在隶属值取 $\{0,1\}$ 时的特例；对角元全为 1，非对角元按 0.5/0.25/0.0 递减，且**不对称**（如 $\mu_R(\text{绿},\text{半成熟})=0.5$ 而 $\mu_R(\text{黄},\text{未成熟})=0.25$），系原文数据如此。
- 该算例说明模糊关系矩阵是清晰关系矩阵（$\{0,1\}$ 值）的 [0,1] 值推广，见 [[comparisons/模糊关系矩阵与邻接矩阵比较]]。

原文此处有「X=｛绿黄，红｝」缺顿号的转写讹误，见 [[queries/5-9-3全节系统性转写讹误清单]]。
