# 凯莱定理断言 K_n 恰有 n^(n−2) 个生成树（来源未给证明）

手册 5.8.3.2 第 2 部分以小节「凯莱定理」断言：每个有 n 个顶点（n > 1）的完全图恰有 n^(n−2) 个生成树。未附证明（「n」在转写中脱落，据公式重构）。

## 小例核验（独立验证）

- n = 3（K₃，三角形）：生成树为删去任一边所得的 3 条路，共 3 = 3^(3−2) ✓
- n = 4（K₄，6 条边）：生成树是 3 条边的连通无圈子图，即 C(6,3) = 20 个三元边组中除去 4 个三角形（每个三角形对应被孤立的一个顶点），共 20 − 4 = 16 = 4^(4−2) ✓

小例与断言一致；一般情形的证明手册未给。

## 证据性质

直接证据仅为手册断言；上述 n = 3、4 的枚举为入库时的独立验证。定理本身是图论标准结果（通行称 Cayley 公式，此为背景注记）。
