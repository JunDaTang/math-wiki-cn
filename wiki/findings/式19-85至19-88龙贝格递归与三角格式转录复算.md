# 式 19.85–19.88 龙贝格递归与三角格式转录复算

转录 19.3.4.1 龙贝格方法的递归与三角格式并核对。

## 转录（verbatim）

```latex
h_i = (b−a)/2^i   (i = 0,1,…,m)                                       (19.85)
T(h_i) = T(h_{i−1}/2) = (h_{i−1}/2)[½f(a) + f(a + h_{i−1}/2) + f(a + h_{i−1}) + f(a + (3/2)h_{i−1})
        + f(a + 2h_{i−1}) + ⋯ + f(a + (2n−1)/2·h_{i−1}) + ½f(b)]
      = ½T(h_{i−1}) + (h_{i−1}/2) Σ_{j=0}^{n−1} f(a + h_{i−1}/2 + j·h_{i−1})
        (i = 1,…,m;  n = 2^{i−1})                                     (19.86)
T_{k,i} = T_{k−1,i} + (T_{k−1,i} − T_{k−1,i−1})/(4^k − 1)
        (k = 1,…,m;  i = k, k+1, ⋯)                                   (19.87)
三角格式:  T(h_0)=T_{00};  T(h_1)=T_{01} T_{11};  T(h_2)=T_{02} T_{12} T_{22}; ⋯   (19.88)
```

## 复算与核对结论

- **(19.86) 递归关系代数核对**：步长从 $h_{i-1}$ 折半到 $h_i = h_{i-1}/2$ 时，新梯形和 = 旧梯形和的一半 + 半步长 × 新增（半格点）函数值之和——展开式与封闭求和形式一致 ✓；新增节点计数 n = 2^{i−1} 正确 ✓。
- **(19.86) 首行**「T(h_i) = T(h_{i−1}/2)」为恒等改写（$h_i = h_{i-1}/2$），核对无误，疑为多行公式排版的转写痕迹。
- **(19.87) 与外推一致性**：k=1 时 $4^1-1 = 3$，与 (19.91) 的 $T_1(h) = T(h/2) + (T(h/2)-T(h))/3$ 一致 ✓（详见 [[findings/式19-89至19-92外推原理与误差阶转录复算]]）。
- **(19.88) 三角格式排列**：第 i 行第 k 列元素 $T_{k,i}$，逐列计算约定一致 ✓。
- 数值验证（对 Si(1) 算例三角表全部 10 项）见 [[findings/正弦积分Si(1)算例全表复算]]。

## 转录疑点

- 「直到在右边最下面的数值儿乎相同」：「儿乎」疑为「几乎」（[[queries/19-3多处脱字脱数字之辨]]）。
- 「第二列的值 T_{1,i} 相应千由辛普森公式计算得到的值」：「千」为「于」之讹；该断言经算例强验证。
