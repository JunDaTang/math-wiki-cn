# 全微分的梯度—标量积表示（式 6.42a–d）

**发现**：源文把全微分写成坐标和式（式 6.42a），再借助梯度向量与微分向量的标量积压缩为一式（式 6.42d）；表示为定义的直接改写，经复算自洽。

## 逐字转录（6.2.2.1.2）

若 $u$ 为可微函数，则和式 (6.41b) 称为函数的**全微分**，记为

```latex
\mathrm{d}u = \frac{\partial u}{\partial x_1}\,\mathrm{d}x_1 + \frac{\partial u}{\partial x_2}\,\mathrm{d}x_2 + \dots + \frac{\partial u}{\partial x_n}\,\mathrm{d}x_n. \tag{6.42a}
```

n 维向量（梯度）：

```latex
\mathbf{grad}\,u = \left(\frac{\partial u}{\partial x_1}, \frac{\partial u}{\partial x_2}, \dots, \frac{\partial u}{\partial x_n}\right)^{\mathrm{T}}, \tag{6.42b}
```

```latex
\mathbf{d}\boldsymbol{r} = (\mathrm{d}x_1, \mathrm{d}x_2, \dots, \mathrm{d}x_n)^{\mathrm{T}}, \tag{6.42c}
```

则全微分可以表示为标量积：

```latex
\mathrm{d}\boldsymbol{u} = (\mathbf{grad}\,\boldsymbol{u})^{\mathrm{T}} \cdot \mathbf{d}\boldsymbol{r}. \tag{6.42d}
```

源文注：(6.42b) 中含 n 个变元的向量为**梯度**，其定义见第 926 页 13.2.2（未入库）。

## 复算与讹误

- 复算：$(\mathbf{grad}\,u)^{\mathrm{T}} \cdot \mathbf{d}\boldsymbol{r} = \sum_i \frac{\partial u}{\partial x_i}\,\mathrm{d}x_i = \mathrm{d}u$，与式 6.42a 完全一致。✔
- 转写讹误（见 [[queries/6-2-2全节系统性转写讹误清单]]）：
  - 式 6.42d 源文作粗体 $\mathrm{d}\boldsymbol{u}$；du 为标量，粗体疑为排印/转写讹误（grad u 与 dr 的粗体合理，因其为向量）。
  - 正文「维向量」「含 个变元」脱字，应为「n 维向量」「含 n 个变元」。
  - 源文 grad 与 u 带下划线样式（\underline），疑为粗体的 OCR 伪影。
  - 「为可微函数，则和式……」句首疑脱主语（如「设 u」）。
