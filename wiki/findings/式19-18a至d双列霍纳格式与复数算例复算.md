# 式 19.18a–d 双列霍纳格式与复数算例复算

对 19.1.2.1“复数情况”（式 19.18a–d）与算例 G 的转录与双重独立复算。

## 转录

```text
(19.18a) p_n(x) = (x² − px − q)(a′_{n−2}xⁿ⁻² + … + a′₀) + r₁x + r₀
(19.18b) x² − px − q = (x − x₀)(x − x̄₀)，即 p = 2u₀, q = −(u₀² + v₀²)
(19.18c) p_n(x₀) = r₁x₀ + r₀ = (r₁u₀ + r₀) + i·r₁v₀   [源文作 "r₁x"，疑脱下标 0]
(19.18d) 双列霍纳格式表（q 行、p 行交替累加；源文标签讹作 "l9.18d"）
```

## 复算内容与结果（算例 G）

$p_4(x) = x^4 + 2x^3 - 3x^2 - 7$，$x_0 = 2 - \mathrm{i}$ ⇒ $p = 2u_0 = 4$、$q = -(u_0^2 + v_0^2) = -(4+1) = -5$：

```text
         1     2    −3     0    −7
 −5 |               −5   −30   −80
  4 |           4    24    64
        ————————————————————————
         1     6    16   [34]   −87     ⇒ p₄(x₀) = 34·x₀ − 87 = −19 − 34i
```

两条独立途径均验证通过：

1. **双列表复算**：逐列累加（−5 行、4 行交替）与源表一致，得 $r_1 = 34$、$r_0 = -87$。
2. **直接复数代入**：$(2-\mathrm{i})^4 = -7-24\mathrm{i}$、$2(2-\mathrm{i})^3 = 4-22\mathrm{i}$、$-3(2-\mathrm{i})^2 = -9+12\mathrm{i}$，合计 $p_4(2-\mathrm{i}) = -19 - 34\mathrm{i}$，与 (19.18c) 读出值 $(r_1 u_0 + r_0) + \mathrm{i} r_1 v_0 = (68-87) - 34\mathrm{i}$ 一致。

补充验证：分解式 $p_4(x) = (x^2 - 4x + 5)(x^2 + 6x + 16) + 34x - 87$ 成立（展开回代一致），即 (19.18a) 在本例中的具体化。

## 归属断言

源文明确指称双列霍纳格式由科拉茨 (Collatz) 引进（见 [[entities/科拉茨]]）——此为具名归属断言，可独立核查。

## 转写讹误（直接证据）

- (19.18c) "$r_1 x$" 疑脱下标 0（算例 G 结果式用 34·x₀ 可佐证），见 [[queries/式19-18c之r1x疑为r1x0之辨]]；
- "l9.18d" 应为 "19.18d"；
- “千是”（两处，千↔于是）、“等千”等 OCR 混淆。

## 结论

公式链 19.18a–d 与算例 G 构成可靠转录基线，且经双途径独立验证；本算例可作为复数求值的跨页复用验证基准。
