# 平方取中法算例复算

对《数学手册(原书第10版)》16.3.5.2(1) 平方取中法算例（2n=4）的转录与复算。

## 转录（原文）

```
2n = 4
z = z₀ = 0.1234,   z₀² = 0.01[5227]56
z = z₁ = 0.5227,   z₀² = 0.27[3215]29
z = z₂ = 0.3215 等
```

（最初的三个随机数是 z₀、z₁ 和 z₂；[ ] 标出被截取的中段 2n 位。）

## 复算

- 0.1234² = 0.01522756：去掉前 2 位「01」与后 2 位「56」，中段 4 位为 **5227** ✓
- 0.5227² = 0.27321529：去掉前 2 位「27」与后 2 位「29」，中段 4 位为 **3215** ✓

数值全部吻合；唯一问题在记号——第二行平方应记 z₁² 而原文仍作 z₀²，见 [[queries/平方取中法算例z0平方疑为z1平方]]。另正文「去掉其前 位数字」脱 n（按对称应为前 n 位），见 [[concepts/平方取中法]]。

## 结论

算例数值可完全复现，[[concepts/平方取中法]] 的机制描述自洽。
