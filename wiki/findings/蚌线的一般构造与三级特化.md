# 蚌线的一般构造与三级特化（式 2.232、2.234）

**主张。** 2.12 节的蚌线材料构成一条三级特化链：一般蚌线构造（式 2.234：对母曲线 $\rho = f(\varphi)$ 取 $\rho = f(\varphi) \pm l$）产生两个命名特例——尼科梅德斯蚌线（母曲线为直线 $x = a$）与帕斯卡蜗线（母曲线为过极点、直径 a 的圆）；蜗线再取 $a = l$ 退化为心脏线。

**证据（原式）。**

```text
(2.232)  OP = OM ± l        （M 为射线与渐近线 x = a 的交点；+ 右支，− 左支）
(2.233c) ρ = a/cos φ ± l    （直线 ρ = a/cos φ 代入蚌线构造）
(2.234)  ρ = f(φ) ± l       （一般蚌线）
(2.235b) ρ = a cos φ + l    （圆 ρ = a cos φ 代入蚌线构造）
(2.236)  OP = OM ± a        （心脏线：蜗线取 l = a）
```

**验证（已验证，代数复核）。** 由式 2.235b 可平方消根得到隐式式 2.235a：$\rho - l = a\cos\varphi = ax/\rho$，得 $\rho^2 - ax = l\rho$，两边平方即 $(x^2+y^2-ax)^2 = l^2(x^2+y^2)$。式 2.233c 中 $f(\varphi) = a/\cos\varphi$ 正是直线 $x = a$ 的极坐标方程，印证“尼科梅德斯蚌线是直线的蚌线”。蜗线隐式取 l = a 时两边 $a^2x^2$ 相消，直接得到心脏线隐式 2.237a（见 [[findings/心脏线的两种定义与特征量]]）。

**意义。** 该层级说明 2.12.1–2.12.4 四节材料不是并列的曲线清单，而是同一构造的逐级具体化；心脏线处于链条末端，同时是蜗线参数比 $l/a = 1$ 的临界点。层级对照见 [[comparisons/蚌线族三级特化比较]]。

**边界。** 一般蚌线构造本身不限于四阶曲线；四阶性来自手册所选母曲线（直线、圆）代入后的隐式化结果（式 2.233a、2.235a 总次数均为 4）。
