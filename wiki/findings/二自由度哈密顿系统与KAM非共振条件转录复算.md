# 二自由度哈密顿系统与 KAM 非共振条件转录复算

**结论**：作用—角变量下二自由度哈密顿系统及其解、不变环面与扰动形式的转录一致；解的形式经平凡代入验证通过；KAM 定理陈述本身为权威引用（无证明），复算状态 null。

## 转录内容

```
ĵ₁ = 0, ĵ₂ = 0, θ̇₁ = ∂H₀/∂j₁, θ̇₂ = ∂H₀/∂j₂        （H₀(j₁,j₂) 解析）
解：j₁ = c₁, j₂ = c₂, θ₁ = ω₁t + c₃, θ₂ = ω₂t + c₄，ω_i 依赖于 (c₁,c₂)
(j₁,j₂) = (c₁,c₂) 确定不变环面 T²
扰动：H₀(j₁,j₂) + εH₁(j₁,j₂,θ₁,θ₂)，ε > 0 小参数
非退化：det(∂²H₀/∂j_k²) ≠ 0（疑漏混合偏导）
非共振：∃c>0，∀正整数 p,q：|ω₁/ω₂ − p/q| ≥ c/q^{2.5}
```

## 核对说明

1. **解的验证（直接）**：ĵ=0 ⟹ j 为常值；θ̇ = ∂H₀/∂j 在固定 (c₁,c₂) 处为常数 ω ⟹ θ 关于 t 线性。通过。
2. **不变环面**：j 固定的集合 {(c₁,c₂)} × T² 为环面，且因 j 守恒而不变。通过。
3. **KAM 断言**（ε 充分小时大多数非共振环面不消失仅轻微变形；「大多数」＝ ε→0 时环面余集勒贝格测度→0）为权威引用，无法转录级复证。
4. **疑点**：非退化条件 det(∂²H₀/∂j_k²) 按字面只含纯偏导 ∂²H₀/∂j₁²、∂²H₀/∂j₂²，漏混合项 ∂²H₀/∂j₁∂j₂，标准口径应为完整黑塞矩阵行列式，见 [[queries/KAM非退化条件黑塞行列式疑漏混合偏导之辨]]。
5. **转写噪声**：原文「当 ε 趋千 时」脱「0」；「ω₁、ω₂ 依赖与 c₁、c₂ 关系」的「与」疑为「于」。汇总见 [[queries/17-1-4全节系统性转写讹误清单]]。
