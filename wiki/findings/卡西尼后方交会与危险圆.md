# 卡西尼后方交会法的参考圆构造与危险圆（式 3.113）

**发现内容（直接证据）：**卡西尼后方交会法（图 3.45）用到两个参考点 P、Q，它们分别位于穿过 A、C、P 与 B、C、Q 的参考圆上；圆 $H_1$、$H_2$ 的中心分别是 $\overline{AC}$、$\overline{BC}$ 的中垂线与线段 PC、QC 的交点；在 N 处所测的 $\delta_1, \delta_2$ 也作为圆周角出现在 P 和 Q 处。已知三点坐标；所测 N 处的 $\delta_1, \delta_2$；所求 $y_N, x_N$。解（公式逐字保留）：

$$y_P = y_A + (x_C - x_A)\cot\delta_1,\qquad x_P = x_A + (y_C - y_A)\cot\delta_1 \tag{3.113a,b}$$

$$y_Q = y_B + (x_B - x_C)\cot\delta_2,\qquad x_Q = x_B + (y_B - y_C)\cot\delta_2 \tag{3.113c,d}$$

$$\cot t_{PQ} = \frac{\Delta y_{PQ}}{\Delta x_{PQ}} \tag{3.113e}$$

$$x_N = x_P + \frac{y_C - y_P + (x_C - x_P)\cot t_{PQ}}{\tan t_{PQ} + \cot t_{PQ}} \tag{3.113f}$$

$$y_N = y_P + (x_N - x_P)\tan t_{PQ}\quad (\tan t_{PQ} < \cot t_{PQ}) \tag{3.113g}$$

$$y_N = y_C - (x_N - x_C)\cot t_{PQ}\quad (\cot t_{PQ} < \tan t_{PQ}) \tag{3.113h}$$

**危险圆（直接证据，源文原句，归属卡西尼法）：**

> 在选取点时要保证它们不位于一个圆上，因为那时将不存在解；我们这里谈论的就是所谓的危险圆。点越靠近危险圆该方法的精确性就越低。

见 [[concepts/危险圆]]。

**疑点（分析层推导，采信前须核对，详见 [[queries/卡西尼法式3-113符号与cot是否转写有误]]）：**

- **垂直性矛盾：**按源文构造（圆心位于线段 PC 上，即 CP 为参考圆直径），由 [[concepts/泰勒斯定理]] $\angle CAP = 90^\circ$，故 AP 应垂直于 AC，且直角三角形中 $|AP| = |AC|\cot\delta_1$——与 (3.113a–b) 的量值一致但方向需一个负号；而转写公式给出 AP 平行于 $(\Delta y_{AC}, \Delta x_{AC})$（分量互换而无符号差），一般不垂直。数值反例：$A=(0,0), C=(3,4), \delta_1 = 45^\circ$ 时按转写式得 $P=(4,3)$，$\angle CAP \approx 16.3^\circ \neq 90^\circ$。两式中疑有一处符号应为负。
- **cot/tan 不自洽：**(3.113e) 用 $\cot t_{PQ} = \Delta y/\Delta x$ 与本节通例 $\tan t = \Delta y/\Delta x$（3.105c 等）矛盾，疑应为 tan；(3.113f) 同时使用 $\tan t_{PQ}$ 与 $\cot t_{PQ}$ 的交点式亦待核。

**证据类型：**构造叙述与危险圆断言为直接证据（叙述位于卡西尼小节）；公式链含可证伪的内部矛盾，整体采信度 medium，待对照原书。
