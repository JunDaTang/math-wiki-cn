# 式 17.60 沙可夫斯基序与周期强制转录复算

## 转录原文

$$3 \succ 5 \succ 7 \succ \dots \succ 2\cdot 3 \succ 2\cdot 5 \succ \dots \succ 2^{2}\cdot 3 \succ 2^{2}\cdot 5 \succ \dots \succ 2^{3} \succ 2^{2} \succ 2 \succ 1.\tag{17.60}$$

```text
设 $\varphi : I  I$ 为紧区间到自身的连续映射， $\{ \varphi ^ { k } \}$ 在 上有一个 周期轨道，则对 $n \succ m$， $\{ \varphi ^ { k } \}$ 也有一个 周期轨道．
```

## 复算内容

**序结构（无误）**：式 17.60 的排列为——奇数升序在前（$3\succ5\succ7\succ\cdots$）；继以 $2^{k}\cdot$（奇数）各块（$k=1,2,\dots$，块内按奇因子升序）；纯 $2$ 的幂降序殿后（$\cdots\succ2^{3}\succ2^{2}\succ2$）；$1$ 居末。与通行的沙可夫斯基序一致，转录无结构性讹误。

**定理陈述（有脱落）**：「在 上有一个 周期轨道」「也有一个 周期轨道」两处脱落周期字母（$m$ 或 $n$）与区间符号 $I$，且「$\varphi : I\ \ I$」脱箭头。脱落使「则对 $n\succ m$」产生方向歧义：

- 读法 (a)：前提 $m$ 周期，结论为序中 $m$ 之后（$m\succ n$）的一切周期——与通行标准形式一致；
- 读法 (b)：按字面「对 $n\succ m$」取前提 $m$、结论 $n$——则结论周期在序中位于前提周期**之前**，与标准定理方向相反。

**周期强制算例（按标准读法 (a)）**：

| 前提周期 | 强制出的周期 |
|---|---|
| $3$ | 一切周期（$3$ 居序首） |
| $5$ | 除 $3$ 外的一切周期 |
| $6=2\cdot3$ | $2\cdot5=10,\ 2\cdot7=14,\dots$，$2^{2}\cdot3=12$，$\dots$，$8,4,2,1$；不强制 $3,5,7$ |

## 判定

- 序结构：高置信无误。
- 定理字母与不等号方向：**待原书裁定**，见 [[queries/沙可夫斯基定理脱落周期字母与不等式方向之辨]]；裁定前，[[concepts/沙可夫斯基定理]] 的订正读法须标注为推断。
