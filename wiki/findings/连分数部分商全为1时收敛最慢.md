# 连分数部分商越大收敛越快，全为 1 时收敛最差

《数学手册(原书第10版)》1.1.1.4, 3.：当 (1.4) 中的 aᵢ（i = 1, 2, …, k）具有大数值时，近似式迅速收敛于 α；**因此，对于数 [1;1,1,…] 而言，收敛是最差的**。

手册例 B 给出对照：

- x = a[1;1,1,…]：近似值 α₄ 的精确度为 0.018a；
- x = (a/2)(1+√5) = (a/2)(1+[2;4,4,4,…])：精确度达到 0.000001a。

**复核**（分析阶段独立计算）：

- [1;1,1,1,1] = 8/5，对 φ = [1;1,1,…] 的误差 |φ − 8/5| ≈ 0.018，与“0.018a”吻合；
- [2;4,4,…] = √5，其 α₄ 的误差约 2.4·10⁻⁶，与“0.000001a”量级吻合。

注：黄金分割例 B 的取值与 1.1.1.2 方程解相差因子 φ，存在手册内部矛盾（见 [[findings/黄金分割连分数示例与方程解相差因子φ]]）；但本条所述“部分商大小与收敛速度”的对照关系本身不受该矛盾影响（两组数值各自自洽）。
