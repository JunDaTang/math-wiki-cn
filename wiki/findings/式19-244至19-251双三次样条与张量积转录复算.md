# 式 19.244–19.251 双三次样条与张量积转录复算

对 19.7.2 双三次样条与张量积方法全部公式 (19.244)–(19.251) 的逐字转录，并作计数复算与讹误辨正。

## 逐字转录

```latex
(19.244)  a = x_0 < x_1 < ⋯ < x_n = b,   c = y_0 < y_1 < ⋯ < y_m = d
(19.245)  f(x_i, y_j) = f_ij   (i = 0,…,n; j = 0,…,m)
(19.246)  S(x_i, y_j) = f_ij
(19.247)  S(x,y) = S_ij(x,y) = Σ_{k=0}^{3} Σ_{l=0}^{3} a_ijkl (x−x_i)^k (y−y_j)^l
          ——每片 16 系数；全区域共 16mn 个系数（原文「l6mn」为 OCR 讹误）
(19.248)  ∂S/∂x、∂S/∂y、∂²S/∂x∂y 在区域上连续
(19.249)  ∂S/∂x(x_i, y_j) = p_ij,    i = 0,n;  j = 0,…,m
          ∂S/∂y(x_i, y_j) = q_ij,    i = 0,…,n;  j = 0,m
          ∂²S/∂x∂y(x_i, y_j) = r_ij,  i = 0,n;  j = 0,m    （p_ij、q_ij、r_ij 预先给定）
          ——系数确定：线性方程组个数 2n+m+3，系数矩阵三对角，各方程组仅右端项不同
(19.250)  S(x,y) = Σ_{i=0}^{n} Σ_{j=0}^{m} a_ij g_i(x) h_j(y)    （张量积方法）
(19.251)  S(x,y) = Σ_{i=1}^{r+2} Σ_{j=1}^{p+2} a_ij N_{i,4}(x) N_{j,4}(y)
          ——r、p 分别为关于 x、y 的节点个数；节点位置须满足可解性条件；带状系数矩阵
```

## 复算与辨正

1. **系数计数**（直接证据）：(19.247) 中 k、l 各取 0–3，每子区域 4×4 = 16 个系数；子区域共 mn 个，故 S(x,y) 需 **16mn** 个系数——原文「l6mn」为「16mn」的 OCR 讹误（l→1）。✓
2. **(19.249) 指标辨正**（直接证据）：三处求值点原文作 (x_i, y_i)，但其指标域为 i = 0,n; j = 0,…,m 等，第二个坐标应随 j 变动，故应为 **(x_i, y_j)**。✓
3. **边界数据计数**：p_ij 需 2(m+1) 个（i ∈ {0,n}，j = 0,…,m），q_ij 需 2(n+1) 个，r_ij 需 4 个（i ∈ {0,n}，j ∈ {0,m}）。
4. **方程组个数 2n+m+3 的复原（推断，非原书内容）**：原书未给推导。一种自洽复原：(m+1)（数据行沿 x 的一维样条）+ (n+1)（数据列沿 y 的一维样条）+ (n+1)（边界导数 p 沿 y 的一维样条）= 2n+m+3，与「系数矩阵三对角、各方程组仅右端项不同」的陈述相容，但属复原假说。
5. **唯一性传递（直接证据）**：原书陈述——g_i、h_j 两个一维插值问题均唯一可解 ⇒ 二维插值问题 (19.246) 用 (19.250) 唯一可解。此为张量积方法的标准论证，原书以定义性陈述给出。
6. **带状结构归属**：(19.251) 的带状系数矩阵属样条实例（局部支撑基），非一般张量积方法必有。

## 转写讹误记录

- 「要求 上可能简单的光滑曲面逼近点 (19.245)」脱「R」与「尽」（应为「要求 R 上尽可能简单的光滑曲面」）；
- 「恒等千」「适用千」「相应千」之「千」均为「于」；
- (19.251) 后「函数 N_{i,4}(x) 和 N_{j,4}(y) 阶正规化 样条」脱「4」「B」；「 表示关千 的节点个数，表示关千 y 的节点个数」脱 r、p；
- 「用双三次 样条求解不同的插值问题见文献」「用双三次 样条解逼近问题……见文献」脱「B」且缺引文编号。

## 结论

转录自洽；「l6mn」与 (19.249) 两处讹误经复算辨正；2n+m+3 的计数属复原假说，留待核验（[[queries/19-7全节系统性转写讹误清单]]）。
