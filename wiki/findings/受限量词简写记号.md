# 受限量词简写记号（式 5.34–5.35，含疑误注记）

《数学手册(原书第10版)》5.1.2.6「约束谓词」：将谓词限制于给定集合的子集常常是有用的，例如将

```latex
∀x∈X P(x) 看作 ∀x(x∈X ⇒ P(x)) 的简短记号    % (5.34)
∃x∈X P(x) 看作 ∃x(x∈X ⇒ P(x)) 的简短记号    % (5.35) — 转写如此
```

**评估**：

- (5.34) 与受限全称量词的标准定义一致。
- **(5.35) 疑误**：受限存在量词的标准定义为 ∃x∈X P(x) ≜ ∃x(x∈X **∧** P(x))。⇒ 版本在数学上错误——若个体区域中存在不属于 X 的元素 x₀，则 x₀∈X 为假而蕴涵为真，整个存在式恒真，与「X 中存在使 P 为真的元素」的本义不符；且与 (5.34) 的对偶形态不对称（∀ 用 ⇒ 正确，∃ 的镜像位置应为 ∧）。

**证据类型**：(5.34) 为直接证据；(5.35) 之疑点属与标准语义的对照推理。究竟是原书排印/中译之误还是转写之误，待核对原书（见 [[queries/式5-35受限存在量词是否应为合取]]）。
