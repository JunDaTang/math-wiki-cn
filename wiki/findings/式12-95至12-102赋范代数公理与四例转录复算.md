# 式 12.95–12.102 赋范代数公理与四例转录复算

## 转录内容

代数公理：(A1) x(yz) = (xy)z（12.95）、(A2) x(y+z) = xy+xz（12.96）、(A3) (x+y)z = xz+yz（12.97）、(A4) α(xy) = (αx)y = x(αy)（12.98）；交换代数定义；代数同态 T(x₁·x₂) = Tx₁·Tx₂（12.99）；赋范代数/巴拿赫代数定义含次乘性 ‖x·y‖ ≤ ‖x‖·‖y‖（12.100）；运算连续性与完备化定理；四例：A（𝒞([a,b]) 逐点乘，回指「(12.80e)」）、B（W([0,2π])，x(t) = Σcₙe^{int}，‖x‖ = Σ|cₙ|，12.101）、C（L(X) 算子范数，TS = T∘S，标签缺失）、D（L¹(−∞,∞) 卷积，‖x‖ = ∫|x(t)|dt，12.102，「是一巴拿赫代数」）。

## 复算（编者直接推导）

- (A1)–(A4) 为标准代数公理（结合、双侧分配、标量相容）✔。
- 例 A 次乘性：‖xy‖ = max|x(t)y(t)| ≤ max|x|·max|y| ✔。
- 例 B 次乘性：逐点乘积的傅里叶系数为卷和 (c*d)ₙ = Σ_k c_{n−k}d_k，故 Σ|(c*d)ₙ| ≤ (Σ|cₙ|)(Σ|dₙ|)（经典，即维纳代数）✔。
- 例 C 次乘性：‖TS‖ = sup_{‖x‖≤1}‖T(Sx)‖ ≤ ‖T‖·sup_{‖x‖≤1}‖Sx‖ ≤ ‖T‖‖S‖ ✔。
- 例 D 次乘性：‖x*y‖₁ ≤ ∫∫|x(t−s)||y(s)|dsdt = ‖x‖₁‖y‖₁（Fubini 与变量替换，经典）✔。

## 发现的讹误

1. 例 A 回指「(12.80e)」——(12.80) 是公理 N3，应回指 (12.89e)（𝒞 的上确界范数），详见 [[queries/12-3-4例A回指12-80e应为12-89e]]。
2. 例 B 正文「[O, 兀]上所有连续……」与记号 W([0, 2π]) 区间不一致（「O」= 0、「兀」= π 之 OCR 错字），详见 [[queries/12-3-4例B区间不一致]]。
3. 例 C 的标签「C」缺失（正文作「：赋范空间 上所有有界线性算子空间…」）。
4. 「代数 到代的线性算子」疑应为「代数 X 到代数 Y 的线性算子」，句尾衍文「X~」。
5. 例 D 回指「第 905 12.9」缺「页」字；向量空间公理回指「第 855~856 12.1.1」同。

## 置信度与复算状态

公理与四例的次乘性均已编者直接复证（经典内容），置信度高；回指与区间疑误需对照原书。尚无第二来源独立复算。
