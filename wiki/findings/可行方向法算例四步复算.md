# 可行方向法算例四步复算

## 题设（源内原文转录）

```
f(x) = x₁² + 4x₂² − 10x₁ − 32x₂ = min!
g₁ = −x₁ ⩽ 0,  g₂ = −x₂ ⩽ 0,  g₃ = x₁ + 2x₂ − 7 ⩽ 0,  g₄ = 2x₁ + x₂ − 8 ⩽ 0
C = diag(1, 4)
α_k′ = − d^{kT}∇f(x^k) / (2 d^{kT}C d^k)
α_k″ = min{ −g_i(x^k) / (a_i^T d^k) : a_i^T d^k > 0 }
```

起点 $x^1=(3,0)^{\mathrm{T}}$，范数取 $\|\cdot\|_\infty$（每步方向搜索程序为线性规划）。

## 迭代记录（源内数值）

| k | x^k | ∇f(x^k) | I_0 | d^k | α_k′ | α_k″ | α_k | x^{k+1} |
|---|---|---|---|---|---|---|---|---|
| 1 | (3, 0) | (−4, −32) | {2} | (1, 1) | 18/5 | 2/3 | 2/3（″） | (11/3, 2/3) |
| 2 | (11/3, 2/3) | (−8/3, −80/3) | {4} | (−1/2, 1) | 152/51 | 4/3 | 4/3（″） | (3, 2) |
| 3 | (3, 2) | (−4, −16) | {3,4} | (−1, 1/2) | 1 | 3 | 1（′） | (2, 5/2) |
| 4 | (2, 5/2) | (−6, −12)* | — | σ = 0 | — | — | — | x* = (2, 5/2) |

\* 第 4 步梯度为复算补充值（源内该步仅给出 σ = 0 与极小点结论）。

各步方向搜索程序（源内形式）：

```
第1步: −4d₁ − 32d₂ = min!,  −d₂ ⩽ 0,  ‖d‖∞ ⩽ 1   ⟹ d¹ = (1, 1)
第2步: −(8/3)d₁ − (80/3)d₂ = min!,  2d₁ + d₂ ⩽ 0,  ‖d‖∞ ⩽ 1   ⟹ d² = (−1/2, 1)
第3步: −4d₁ − 16d₂ = min!,  d₁ + 2d₂ ⩽ 0,  2d₁ + d₂ ⩽ 0,  ‖d‖∞ ⩽ 1   ⟹ d³ = (−1, 1/2)
第4步: 结果 σ = 0,  极小点 x* = x⁴
```

## 独立复算结论（direct evidence）

- 三个迭代点的梯度、主动约束标号集、三个方向搜索程序的 LP 顶点最优解（逐一比较顶点目标值确认最优性）、各 $\alpha_k'$、$\alpha_k''$ 与迭代点 $x^{k+1}$ 全部复算无误；
- 步长类型核验：$\alpha_1=\alpha_1''$（$\alpha_1'=18/5>2/3$）、$\alpha_2=\alpha_2''$（$\alpha_2'=152/51\approx 2.98>4/3$）、$\alpha_3=\alpha_3'$（$1<3$）；
- 终止处 KKT 验证：$\nabla f(x^*)=(-6,-12)$，$-\nabla f(x^*)=(6,12)=6\,a_3$，即 $u_3=6\geqslant 0$，$I_0(x^*)=\{3\}$（$g_3(x^*)=0$，$g_4(x^*)=-3/2<0$），[[concepts/库恩—塔克条件]] 成立，可按 [[methodology/库恩—塔克条件验证流程]] 检验；
- 目标值单调下降：$-21\to -385/9\ (\approx -42.78)\to -69\to -71$；
- 共轭条件注记：步长类型序列为 ″、″、′，无连续 ′ 型步；进入第 4 步方向搜索时程序直接以 $\sigma=0$ 终止，故式 (18.104) 对迭代轨迹无实际影响。
