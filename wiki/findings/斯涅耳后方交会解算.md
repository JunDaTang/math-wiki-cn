# 斯涅耳后方交会问题的解算链（式 3.112）

**发现内容（直接证据，公式逐字保留）：**后方交会法的斯涅耳问题（三角测量第二基本问题，图 3.44）——通过三个已知点 A、B、C 确定点 N。已知三点坐标；所测 N 处的 $\delta_1, \delta_2$；所求 $y_N, x_N$。解：

$$\tan t_{AC} = \frac{\Delta y_{AC}}{\Delta x_{AC}},\qquad \tan t_{BC} = \frac{\Delta y_{BC}}{\Delta x_{BC}} \tag{3.112a,b}$$

$$a = \frac{\Delta y_{AC}}{\sin t_{AC}} = \frac{\Delta x_{AC}}{\cos t_{AC}},\qquad b = \frac{\Delta y_{BC}}{\sin t_{BC}} = \frac{\Delta x_{BC}}{\cos t_{BC}} \tag{3.112c,d}$$

$$\gamma = t_{CA} - t_{CB} = t_{AC} - t_{BC} \tag{3.112e}$$

$$\frac{\varphi+\psi}{2} = 180^\circ - \frac{\gamma + \delta_1 + \delta_2}{2} \tag{3.112f}$$

等式 (3.112f) 是确定 $\varphi$、$\psi$ 的第一个条件；从第 106 页 (2.115)(2.116)（3.3 节，未摄入）得第二个条件：

$$\frac{\sin\varphi + \sin\psi}{\sin\varphi - \sin\psi} = \tan\frac{\varphi+\psi}{2}\cdot\cot\frac{\varphi-\psi}{2} \tag{3.112g}$$

利用 [[concepts/正弦定律]] (3.88) 推出 $\frac{\sin\varphi}{\sin\delta_1} = \frac{s_{CN}}{a}$、$\frac{\sin\psi}{\sin\delta_2} = \frac{s_{CN}}{b}$ (3.112h)，代入 (3.112g) 得：

$$\tan\frac{\varphi-\psi}{2} = \tan\frac{\varphi+\psi}{2}\cdot\frac{b\sin\delta_1 - a\sin\delta_2}{b\sin\delta_1 + a\sin\delta_2} \tag{3.112i}$$

由 (3.112i) 得 $\frac{\varphi-\psi}{2}$，连同 (3.112f) 解出 $\varphi = \frac{\varphi+\psi}{2} + \frac{\varphi-\psi}{2}$、$\psi = \frac{\varphi+\psi}{2} - \frac{\varphi-\psi}{2}$ (3.112j)，进而：

$$s_{AN} = \frac{a}{\sin\delta_1}\sin(\delta_1 + \varphi),\qquad s_{BN} = \frac{b}{\sin\delta_2}\sin(\delta_2 + \psi) \tag{3.112k,l}$$

$$s_{CN} = \frac{a}{\sin\delta_1}\sin\varphi = \frac{b}{\sin\delta_2}\sin\psi \tag{3.112m}$$

$$x_N = x_A + s_{AN}\cos t_{AN} = x_B + s_{BN}\cos t_{BN} \tag{3.112n}$$

$$y_N = y_A + s_{AN}\sin t_{AN} = y_B + s_{BN}\sin t_{BN} \tag{3.112o}$$

**结构要点：**双条件定 $\varphi, \psi$（内角和 + 半角恒等式）；(3.112m) 与 (3.112n–o) 为双路检核（$s_{CN}$ 双式、A/B 两端复算）。源文未对本法陈述失效条件（危险圆断言位于卡西尼小节，见 [[concepts/危险圆]]）。

**证据类型：**直接证据；分析层核验 (3.112c–d) 为 $a = \Delta y/\sin t = \Delta x/\cos t$ 的距离恒等式、全链数学自洽（中高）。
