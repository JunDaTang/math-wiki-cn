# 方位角的象限判定与反方位角（表 3.6 与式 3.105）

**发现内容（直接证据，公式与表逐字保留）：**对直角坐标系中两点 $A(y_A, x_A)$、$B(y_B, x_B)$ 及有向线段 $s_{AB}$ 与方位角 $t_{AB}, t_{BA}$：

$$\frac{y_B - y_A}{x_B - x_A} = \frac{\Delta y_{AB}}{\Delta x_{AB}} \tag{3.105a}$$

$$s_{AB} = \sqrt{\Delta y_{AB}^2 + \Delta x_{AB}^2} \tag{3.105b}$$

$$\tan t_{AB} = \frac{\Delta y_{AB}}{\Delta x_{AB}} \tag{3.105c}$$

$$t_{BA} = t_{AB} \pm 200\ \mathrm{gon} \tag{3.105d}$$

$t_{AB}$ 的象限依赖于 $\Delta y_{AB}$、$\Delta x_{AB}$ 的符号；以正确符号输入 $\Delta y/\Delta x$ 并按 arctan 键得角 $t_0$，再按表 3.6 加新度值：

| 象限 | I | II | III | IV |
|---|---|---|---|---|
| 计算器中的显示 | + | − | − | + |
| Δy/Δx | tan > 0 | tan < 0 | tan > 0 | tan < 0 |
| 方位角 t | t₀ gon | t₀ + 200 gon | t₀ + 200 gon | t₀ + 400 gon |

**疑点（采信前须核对）：**按带符号 arctan，第三象限（$\Delta x<0, \Delta y<0$，比值 > 0）应显示「+」（$t_0+200$ 才落入 200–300 gon），第四象限（$\Delta x>0, \Delta y<0$，比值 < 0）应显示「−」（$t_0+400$ 才落入 300–400 gon）。转写表中三、四象限的显示符号疑颠倒；「方位角 t」一行本身与带符号 arctan 自洽。详见 [[queries/表3-6三四象限显示符号是否颠倒]]。

**证据类型：**公式链 (3.105) 为直接证据、数学自洽（中高）；表 3.6 的显示行含疑似转写讹误，整体采信度降为 medium。
