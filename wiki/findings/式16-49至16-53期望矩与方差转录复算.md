# 式 16.49–16.53 期望、矩与方差转录复算

**结论**：式 (16.49)–(16.53) 经转录复算，数学上全部无误；(16.49a) 收敛条件句中有一处衍字「凇」。

## 转录与逐条复核

**式 (16.49a) 离散情形期望**

$$E(g(X)) = \sum_k g(x_k)p_k, \quad \text{若级数 } \sum_{k=1}^{\infty}|g(x_k)|p_k \text{ 收敛}$$

复核：✓ 绝对收敛条件保证期望的良定义（与求和次序无关）。源文条件句作「若级数 … 凇存在」，「凇」为衍字（见 [[queries/式16-49a凇字衍文之辨]]）。

**式 (16.49b) 连续情形期望**

$$E(g(X)) = \int_{-\infty}^{+\infty} g(x)f(x)\,\mathrm{d}x, \quad \text{若 } \int_{-\infty}^{+\infty}|g(x)|f(x)\,\mathrm{d}x \text{ 存在}$$

复核：✓ 同上的绝对可积条件。

**式 (16.50a) 随机变量自身的期望**

$$\mu_X = E(X) = \sum_k x_kp_k \quad \text{或} \quad \int_{-\infty}^{+\infty} xf(x)\,\mathrm{d}x$$

复核：✓ 取 $g(X)=X$ 的特例，绝对收敛要求继承自 (16.49)。

**式 (16.50b) 仿射性质**

$$E(aX+b) = a\mu_X + b \quad (a, b \text{ 是常数})$$

复核：✓ 由 (16.49a/b) 的线性直接推出。注意此条归 [[concepts/期望]]；方差侧的 $D^2(aX+b)=a^2D^2(X)$ 归 [[concepts/方差与标准差]]，两条性质不得混引。

**式 (16.51a/b) 矩与中心矩**

$$\text{a) } E(X^n); \qquad \text{b) } E((X-\mu_X)^n)$$

复核：✓ 定义。源文标题「2. 阶矩」及「a) 阶矩」「b) 阶中心矩」中的 $n$ 均脱落。

**式 (16.52) 方差**

$$E((X-\mu_X)^2) = D^2(X) = \sigma_X^2 = \begin{cases} \sum_k (x_k-\mu_X)^2p_k, \\ \text{或} \\ \int_{-\infty}^{+\infty}(x-\mu_X)^2f(x)\,\mathrm{d}x \end{cases}$$

复核：✓ 二阶中心矩的双轨定义。「特别地 阶中心矩称为方差或离差」中脱「二」。

**式 (16.53) 方差关系式**

$$D^2(X) = \sigma_X^2 = E(X^2)-\mu_X^2, \qquad D^2(aX+b) = a^2D^2(X)$$

复核：✓ 展开 $E((X-\mu)^2)=E(X^2)-2\mu E(X)+\mu^2=E(X^2)-\mu^2$；仿射代入 $\mathrm{Var}(aX+b)=a^2\mathrm{Var}(X)$。均通过。

## 本区间转写损伤

- 「在粗糙描述随机变量 的分布时」——脱 $X$。
- 「期望指由密度函数曲线 $f(x)$ 轴围成的曲面重心的横坐标方差是……」——疑脱「与 $x$」及句读（见 [[queries/面积解释句疑脱与x轴]]）；「曲面重心」措辞待对照原书核实。
- 「若 $g(X)$ 是随机变量 的函数」——脱 $X$。
- 「特别地 阶中心矩称为方差或离差」——脱「二」。

## 证据强度

高：标准结果，复算全部通过；唯一存疑处是 (16.49a) 条件句的原文措辞（绝对收敛？）。
