# 多元可微性的定义与偏导数邻域连续的充分非必要条件（式 6.41a–c）

**发现**：源文以「全增量—偏微分之和—高阶无穷小」三件套定义多元可微性，并附偏导数邻域连续的充分非必要条件；定义链条自洽，附随条件与通行标准结果一致，但「事实上」一句的逻辑衔接存在错位（见下）。

## 定义（逐字转录，6.2.2.1.1）

多元函数 $u = f(x_1, \dots, x_n)$ 称为在点 $P_0(x_{10}, \dots, x_{n0})$ 可微，若对任意小量 $\Delta x_1, \dots, \Delta x_n$，在点 $P(x_{10}+\Delta x_1, \dots, x_{n0}+\Delta x_n)$ 与点 $P_0$ 处函数的全增量

```latex
\begin{array}{c}
\Delta u = f(x_{10} + \Delta x_1, x_{20} + \Delta x_2, \dots, x_{i0} + \Delta x_i, \dots, x_{n0} + \Delta x_n) \\
 - f(x_{10}, x_{20}, \dots, x_{i0}, \dots, x_{n0})
\end{array} \tag{6.41a}
```

与所有变量的偏微分之和

```latex
\left(\frac{\partial u}{\partial x_1}\,\mathrm{d}x_1 + \frac{\partial u}{\partial x_2}\,\mathrm{d}x_2 + \dots + \frac{\partial u}{\partial x_n}\,\mathrm{d}x_n\right)_{x_{10}, x_{20}, \dots, x_{n0}} \tag{6.41b}
```

相差为距离

```latex
\overline{P_0 P} = \sqrt{\Delta x_1^2 + \Delta x_2^2 + \cdots + \Delta x_n^2} = \sqrt{\mathrm{d}x_1^2 + \mathrm{d}x_2^2 + \cdots + \mathrm{d}x_n^2} \tag{6.41c}
```

的高阶无穷小。式 6.41c 表明 $\Delta x_i$ 与 $\mathrm{d}x_i$ 在距离表达式中通用（二者等同使用）。

## 附随论断（关于偏导数连续性条件）

源文：若多元连续函数的偏导数作为多元函数在一点的邻域内连续，则该多元函数在这一点可微——这是可微的**充分非必要**条件；事实上，即使偏导数在一点存在，函数在该点也未必连续。三条断言均为标准结果（陈述级，源文未证明）：

1. **充分性**：偏导数在邻域内连续 ⇒ 该点可微。
2. **非必要性**：可微 ⇏ 偏导数在邻域内连续。
3. **补充警示**：偏导数在一点存在 ⇏ 该点连续（因而更不足以可微）。

## 本方辨析（推断，非源文明文）

- **「事实上」句的逻辑错位**：断言 3 实际支撑的是「偏导数存在不足以保证连续」，而**不是**断言 2 的非必要性；非必要性需要「可微但偏导数不连续」型反例。源文以「事实上」把两者直接衔接，逻辑链有松动，疑为翻译行文问题。
- **通行反例**（独立可验证的标准结果，非本源内容）：
  - 非必要性：$u = (x^2+y^2)\sin\frac{1}{\sqrt{x^2+y^2}}$（原点补定义 0）在原点可微，但偏导数在原点不连续。
  - 偏导数存在不保证连续：$u = \frac{xy}{x^2+y^2}$（原点补定义 0）在原点两个偏导数均存在，但函数在原点不连续。
- **疑似衍文**：「多元**连续**函数的偏导数……」中前置的「连续」疑为衍文——偏导数在邻域内连续本身已蕴涵函数连续。已录入 [[queries/6-2-2全节系统性转写讹误清单]]。

## 复算与证据强度

- 定义链（式 6.41a–c）内部自洽：可微性即 $\Delta u - \sum_i \frac{\partial u}{\partial x_i}\mathrm{d}x_i = o(\overline{P_0P})$，与通行定义一致。✔
- 附随条件为陈述级标准结果，源文未证明；上述反例为本方补充（直接证据仅覆盖陈述本身）。
- confidence: high；replicated: true（定义复算 + 与标准结果比对）。
