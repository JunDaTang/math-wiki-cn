# 正凸多边形角量体系（式 3.47–3.50）

《数学手册(原书第10版)》3.1.5.2 给出正凸 n 边形的四个角量，由 n 个环绕中心的等腰全等三角形（顶角 φₙ、底角 αₙ）推出：

```
φ_n = 360°/n                          (3.47)  中心角
α_n = (1 − 2/n)·90°                   (3.48)  底角
β_n = 360°/n                          (3.49)  外角
γ_n = 180° − β_n                      (3.50)  内角
```

## 结构关系

- **βₙ = φₙ**：外角恒等于中心角（两者同为 360°/n）。
- **γₙ = 2αₙ**：内角等于两个底角之和（由 φₙ + 2αₙ = 180° 与 n·φₙ = 360° 直接验证）。
- 数值示例：n = 3 时 γ₃ = 60°；n = 4 时 γ₄ = 90°；n = 5 时 γ₅ = 108°；n = 6 时 γ₆ = 120°；n = 8 时 γ₈ = 135°；n = 10 时 γ₁₀ = 144°；n → ∞ 时 γₙ → 180°。

## 复核

由等腰三角形内角和（φₙ + 2αₙ = 180°）与全周角（n·φₙ = 360°）直接验证，全部自洽（独立复核）。
