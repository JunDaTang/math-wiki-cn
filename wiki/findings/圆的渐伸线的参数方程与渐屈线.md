# 圆的渐伸线的参数方程与渐屈线（式 2.250）

手册 2.14.4 节以细绳展开生成定义[[concepts/圆的渐伸线]]，给出参数方程、奇点、几何量与渐屈线命题；本小节全部断言经独立推导复核无误，是 2.14 节中最严密的小节。

## 内容

**生成**：细绳绕在定圆上，拉开一端并拉直，绳端点轨迹满足 $\widehat{AB} = \overline{BP}$（圆上弧长等于拉直绳段）。

**参数方程**：

$$
x = a \cos \varphi + a \varphi \sin \varphi , y = a \sin \varphi - a \varphi \cos \varphi ,\tag{2.250}
$$

其中 a 为圆半径，$\varphi = \angle BOx$（源文「$\varphi = \not\leq BOx$」为「∠」的转写残损）。

**要素**：

- 两分支关于 x 轴对称；
- $A(a,0)$ 为尖点；
- 与 x 轴交点 $x = \frac{a}{\cos\varphi_0}$，其中 $\varphi_0$ 为 $\tan\varphi = \varphi$ 的根；
- 弧长（$\widehat{AP}$）$L = \frac{1}{2} a\varphi^{2}$；
- 曲率半径 $r = a\varphi = \sqrt{2aL}$；
- 曲率中心 B 在圆上，即圆是曲线的[[concepts/渐屈线]]。

## 核验

以上各条均经独立推导复核：对称性（φ 取负的镜像）、尖点（P→A 时 $\mathrm{d}x/\mathrm{d}\varphi$ 与 $\mathrm{d}y/\mathrm{d}\varphi$ 同时为零）、x 轴交点条件（$\sin\varphi_0 = \varphi_0\cos\varphi_0$ 与 $\cos^2\varphi_0(1+\varphi_0^2) = 1$ 等价）、L、r、以及「曲率中心落在圆上」。此处 replicated 指该独立推导复核，而非独立第三方来源的再现。
