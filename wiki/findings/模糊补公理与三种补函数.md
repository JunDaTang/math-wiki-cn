# 模糊补公理 EK1–EK4 与三种补函数

《数学手册(原书第10版)》5.9.2.5 公理化补函数 c: [0,1]→[0,1] 并给出三种实例。

## 直接证据（照录）

```text
补函数 c: [0,1]→[0,1]：
(EK1) 边界条件 c(O) = c(l) = 0〔O/l 为 0/1 的 OCR 讹形〕             (5.357a)
(EK2) 单调性   x < y ⇒ c(x) ≥ c(y)                                    (5.357b)
(EK3) 对合性   c(c(x)) = x                                            (5.357c)
(EK4) 连续性   c(x) 对每个 x∈[0,1] 连续                                (5.357d)

c(x) := 1 − x                                                         (5.358)
管野(Sugeno)补〔译名应为「菅野」〕：c_λ(x) := (1−x)(1+λx)^{−1}，λ∈(−1,∞)
耶格尔(Yager)补：c_p(x) := (1−x^p)^{1/p}，p∈(0,1)
```

## EK1 转写讹误（独立推导）

源文 EK1 印作「c(O) = c(l) = 0」，与 EK3 矛盾：若 c(1)=0，则 c(c(1)) = c(0) 应等于 1。故边界条件必为 **c(0)=1, c(1)=0**。此为从公理组内部一致性推出的更正，非源文明文。

## Yager 补参数区间疑点（独立验证）

对合性 c_p(c_p(x)) = (1−(1−x^p))^{1/p} = x 与单调递减性对一切 p>0 成立，且 p=1 时 c_1(x) = 1−x 即缺省补；区间 (0,1) 反而排除了该情形，疑应为 p>0，见 [[queries/yager补参数区间是否应为p大于0]]。

## 译名更正

Sugeno 的中文译名应为「菅野」，源文讹作「管野」；Yager 源文译作「耶格尔」。
