# 式 17.76 尖点折叠曲线 27α₁²−4α₂³=0 复算

对尖点分岔（式 17.76）的非双曲点条件与折叠曲线方程作独立复算，**通过**。

## 复算

l₃<0（故 sign l₃=−1）时正规形式 ẋ=α₁+α₂x−x³。非双曲点条件（平衡且切退化）：

```latex
\alpha_1 + \alpha_2 x - x^3 = 0, \qquad \alpha_2 - 3x^2 = 0
```

由第二式 x²=α₂/3（要求 α₂≥0）；代回第一式：α₁ = x³−α₂x = x(x²−α₂) = −(2/3)α₂x，故

```latex
\alpha_1^2 = \frac{4}{9}\alpha_2^2 x^2 = \frac{4}{9}\alpha_2^2 \cdot \frac{\alpha_2}{3} = \frac{4\alpha_2^3}{27} \quad\Longleftrightarrow\quad 27\alpha_1^2 - 4\alpha_2^3 = 0
```

与源文曲线 S₁,S₂ 的定义一致。✓

## 附带核验

- (α₁,α₂)=(0,0) 时 (17.76) 化为 ẋ=−x³：x=0 从两侧单调趋近，稳定。✓ 与源文“平衡点 x=0 是稳定的”一致（转录“则 (17.76)平衡点 是稳定的”脱落 x=0）。
- λ₂<0 三重结点、λ₂>0 三重鞍点（n=2、λ₁=0，图 17.26(c),(d)，引 [17.14]）为源文图示断言，未独立复算。
- 尖点内侧的超临界叉型（复合结点分裂为两稳结点+一鞍点）为源文断言（图 17.26(b)），未独立复算。
