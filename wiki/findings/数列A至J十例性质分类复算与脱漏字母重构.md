# 数列 A–J 十例性质分类复算与脱漏字母重构

本 finding 对 7.1.1.1 的十个示例数列 A–J 逐一复算单调性、有界性与敛散性，据以重构源文例句中脱漏的字母，并记录派生构造 J = 交错(E, E+10)。通项与首几项的逐字转录另见 [[findings/式7-1数列定义与A至J十例逐字转录]]；并排比较见 [[comparisons/数列A至J十例性质比较]]。

## 分类总表（「明示」为直接证据；「重构」为排除法推断）

| 例 | 单调性 | 有界性 | 敛散性 |
|---|---|---|---|
| A | 严格递增（明示） | 无界（复算） | 真发散 → +∞（明示） |
| B | 严格递增（明示） | 无界（复算） | 真发散 → +∞（明示） |
| C | 非单调（复算） | 有界，K = 4（K 明示、字母重构） | 收敛于 0（极限值明示、字母重构） |
| D | 非单调（复算） | 有界（D 明示、K 值脱落） | 假发散（字母重构） |
| E | 严格递增（明示） | 有界，K = 3（K 明示、字母重构） | 收敛于 3（明示） |
| F | 非单调（复算） | 有界（字母与 K 值均脱落） | 收敛于 3⅓（明示） |
| G | 严格递减（字母脱落，复算唯一候选） | 有界（K 脱落） | 收敛于 0（明示） |
| H | 非单调（复算） | 无界（复算） | 假发散（字母重构） |
| I | 非单调（复算） | 无界，下方（复算） | 假发散（字母重构） |
| J | 非单调（复算） | 有界，K = 13（明示，源文讹作「K = 1 3」） | 假发散（字母重构） |

## 重构依据（排除法）

- **严格递减例句**「数列 严格单调递减」：十例中唯一严格递减者为 G（1, ½, ⅓, ¼, ⋯）；C、D、F、H、I、J 经复算均非单调。
- **假发散例句**「数列 是假发散数列」：十例三分后余 D、H、I、J——D 双子列恒 ±1；H 奇子列 → +∞、偶子列 → −∞；I 奇子列 → −∞、偶项恒 0；J 双子列 → 3 与 13。四者均无极限且不满足 (7.5b)。
- **有界例句**：「K = 4」→ C（|aₙ| ≤ 3 < 4）；「K = 3」→ E（aₙ < 3 严格成立）；「K = 13」→ J（偶子列 13 − 2^{2−m} < 13 严格成立）。D、F 的 K 值与 G 的字母、K 值在源文脱落，原值待核（[[queries/式7-4严格不等号与界K原值问题]]）。
- **收敛例句**：「A = 0」两处 → C 与 G；「A = 3」→ E；「A = 3⅓」→ F。
- **顺序佐证**：各例句的列举顺序与字母序一致——有界句为 C, D, E, F, G, J；收敛句为 C, E, F, G；单调句为 A, B, E（递增）后接 G（递减）——进一步支持上述重构。

## 派生发现（复算所得，直接证据）

- **J = 交错(E, E+10)**：J 的奇子列通项为 $3 - 2^{2-m}$，与 E 的通项 $3 - 1/2^{m-2}$ 完全一致；偶子列 = 对应 E 项 + 10。故 J 是「两个不同极限（3 与 13）的交错子列」这一假发散情形的标准构造。
- **F 是 10/3 的十进逼近**：奇子列自下方（3, 3.3, 3.33, ⋯）、偶子列自上方（4, 3.4, 3.34, ⋯）双侧夹逼 3⅓。
- **E 与 G 恰为定理 4c) 的例证**：E 递增收敛于其最小上界 3，G 递减收敛于其最大下界 0（[[concepts/单调有界收敛定理]]、[[concepts/上确界与下确界]]）。
- **十例穷举自洽**：4 收敛（C/E/F/G）+ 2 真发散（A/B）+ 4 假发散（D/H/I/J）= 10；6 有界 + 4 无界 = 10；4 严格单调（A/B/E 递增、G 递减）+ 6 非单调 = 10。

## J 项列的复原

源文 J 的项列损坏为「1, 11, 2, 12, 2 12 2 12 2 4 4'」。据奇、偶通项复算：

```text
奇（n = 1, 3, 5, 7, ⋯）：3 − 2^(2−m)，m = 1, 2, 3, 4, ⋯
     = 3 − 2, 3 − 1, 3 − ½, 3 − ¼, ⋯ = 1, 2, 2½, 2¾, ⋯
偶（n = 2, 4, 6, 8, ⋯）：13 − 2^(2−m)
     = 11, 12, 12½, 12¾, ⋯
交错排成：aₙ = 1, 11, 2, 12, 2½, 12½, 2¾, 12¾, ⋯
```

损坏残片中的「2 12 2 12」段与带分数 2½/12½ 相合；E 条括注「2¾ = 11/4」佐证原书使用带分数记法。

## 证据强度分层

- 直接证据（高置信）：十个通项公式；明示的分类句（A/B/E 严格递增，A/B 真发散，E 收敛于 3、F 收敛于 3⅓、两处收敛于 0，K = 4/3/13）；全部复算结论（极限值、单调性、有界性的数学判定）。
- 推断（中高置信，需原书核对）：脱漏字母的重构——G 严格递减；假发散 = D/H/I/J；有界 = C/D/E/F/G/J；收敛句字母 = C/G/E/F。
