# 壳层模型 S_3 三维表示与特征（式 5.106，已复算）

**来源**：[[sources/10-数学手册原书第10版--7-534-群表示--x5kmh9]]（5.3.4.2.5）。

原子/核物理壳层模型中，组态 $\alpha^2\beta$ 的系统波函数是三个单粒子波函数之积 $\psi = \varphi_\alpha\varphi_\alpha\varphi_\beta$；依粒子 1、2、3 对波函数的分布得到三个函数（式 5.106a）：

```text
ψ₁ = φ_α(r₁)·φ_α(r₂)·φ_β(r₃)
ψ₂ = φ_α(r₁)·φ_β(r₂)·φ_α(r₃)
ψ₃ = φ_β(r₁)·φ_α(r₂)·φ_α(r₃)
```

实施置换时（依据 5.3.3.1, 2.，未入库）它们中一个变换为另一个，故 $\psi_1, \psi_2, \psi_3$ 张成 $S_3$ 的三维表示。矩阵元由群元 (5.84) 对基元坐标下标的作用求出（式 5.106b；方法见 [[methodology/由群作用构造表示矩阵流程]]），例如 $p_1\psi_1 = D_{21}(p_1)\psi_2$。总结果（式 5.106c）：

```text
D(e)  = [[1,0,0],[0,1,0],[0,0,1]]
D(p₁) = [[0,1,0],[1,0,0],[0,0,1]]
D(p₂) = [[0,0,1],[0,1,0],[1,0,0]]
D(p₃) = [[1,0,0],[0,0,1],[0,1,0]]
D(p₄) = [[0,1,0],[0,0,1],[1,0,0]]
D(p₅) = [[0,0,1],[1,0,0],[0,1,0]]
```

特征（式 5.106d）：

```text
χ(e) = 3,  χ(p₁) = χ(p₂) = χ(p₃) = 1,  χ(p₄) = χ(p₅) = 0
```

**独立复算**（本 wiki）：六个置换矩阵与全部特征均复算一致——前提是把 $p_1, p_2, p_3$ 识别为粒子坐标交换 $(23), (13), (12)$，$p_4, p_5$ 为 3-循环。**注意**：$p_1$–$p_5$ 的正式定义在 5.3.3 的 (5.84)（未入库），上述识别是本 wiki 的推断，待 5.3.3 入库后锚定（见 [[queries/5-3-2与5-3-3未入库对5-3-4的依赖缺口]]）。

**可约性印证**（本 wiki 复算）：$\chi$ 恰为恒等表示与二维表示特征之和——$\chi = \chi^{(\text{恒等})} + \chi^{(\text{二维})}$：$3 = 1+2$、$1 = 1+0$、$0 = 1+(-1)$（二维表示的特征取 $2/0/-1$，为依标准表示补充的计算）。显式基变换分解见 [[findings/可约性分块化简与s3基变换算例]]。
