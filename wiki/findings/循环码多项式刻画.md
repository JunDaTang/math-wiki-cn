# 循环码的多项式刻画（式 5.270–5.271）

《数学手册》5.4.6.2.4 将循环码（对循环右移封闭的线性码）转入多项式框架：码字以次数 ≤ n−1、系数属于 GF(2) 的多项式表示，公式原文照录：

```
c(x) ∈ C ⇒ c(x)·x (mod x^n − 1) ∈ C                                     (5.270)
```

- （二元）(n,k) 线性码 C 是循环的，当且仅当对每个 c(x) 满足 (5.270)。
- n−k 次生成多项式 g(x) 是 x^n − 1 的一个因子（k ∈ {1, 2, …, n−1}）；满足 g(x)h(x) = x^n − 1 的多项式 h(x) 称为控制多项式（即校验多项式）。
- 编码：a(x) ↦ a(x)·g(x)（式 5.271）。
- 码字判定：d(x) 是码中元素 ⇔ g(x) | d(x) ⇔ d(x)h(x) ≡ 0 (mod x^n − 1)。

## 算例（已复核 ✓）

C = {000, 110, 101, 011} 是一个循环 (3,2) 线性码：每个码字的右向循环移位（110 → 011 → 101 → 110）仍是码字。

## 转写疑点

本小节乱码密集：「( = T̄ L̄)」应为「（二元）」、「Π ≡ R̄」应为「码 C」、「∇_y(x)」应为「g(x)」、「子向量」应为「子向量空间」，详见 [[queries/5-4-5至5-4-6全节系统性转写讹误清单]]。
