# 式 8.124–8.130 路径无关等价链与功的表述复算

**结论**：8.3.4.1–8.3.4.3 给出「路径无关 ⇔ 原函数存在 ⇔ 全微分 ⇔ 偏导条件」的等价链（二维）及其三维推广，转录如下；式 8.130 的功表述为 [[concepts/微积分基本定理]] 的线积分类比；转写本式 8.130 存在单位向量下标讹误。

## 二维等价链（逐字转录）

设 $P$ 和 $Q$ 是定义在**单连通区域**上的连续函数，若积分

$$\int_{(C)} [P(x,y)\,\mathrm{d}x + Q(x,y)\,\mathrm{d}y] \tag{8.124}$$

仅与积分路径的起点 $A$ 和终点 $B$ 有关，而与连接这两点的曲线无关，即对任意 $A,B$ 及积分路径 $\widehat{ACB}$、$\widehat{ADB}$（图 8.27），都有等式

$$\int_{\widehat{ACB}} (P\,\mathrm{d}x + Q\,\mathrm{d}y) = \int_{\widehat{ADB}} (P\,\mathrm{d}x + Q\,\mathrm{d}y), \tag{8.125}$$

以上成立的充分必要条件为存在二元函数 $U(x,y)$，其全微分是线积分的被积函数：

$$P\,\mathrm{d}x + Q\,\mathrm{d}y = \mathrm{d}U, \tag{8.126a}$$

即

$$P = \frac{\partial U}{\partial x}, \qquad Q = \frac{\partial U}{\partial y}. \tag{8.126b}$$

函数 $U(x,y)$ 是全微分 (8.126a) 的原函数。在物理学中，原函数 $U(x,y)$ 是向量场的势能（参见第 941 页 13.3.1.6）。

**原函数的存在性（8.3.4.2）**：原函数存在的充分必要条件，即表达式 $P\,\mathrm{d}x+Q\,\mathrm{d}y$ 可积的充要条件为偏导数

$$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}, \tag{8.127}$$

且偏导数连续。

## 三维推广（逐字转录）

与二维的情况类似，积分

$$\int [P(x,y,z)\,\mathrm{d}x + Q(x,y,z)\,\mathrm{d}y + R(x,y,z)\,\mathrm{d}z] \tag{8.128}$$

与积分路径无关的条件是：存在原函数 $U(x,y,z)$，满足

$$P\,\mathrm{d}x + Q\,\mathrm{d}y + R\,\mathrm{d}z = \mathrm{d}U, \tag{8.129a}$$

即

$$P = \frac{\partial U}{\partial x}, \quad Q = \frac{\partial U}{\partial y}, \quad R = \frac{\partial U}{\partial z}. \tag{8.129b}$$

可积条件是：若偏导数连续，则它们同时满足如下三个方程

$$\frac{\partial Q}{\partial z} = \frac{\partial R}{\partial y}, \quad \frac{\partial R}{\partial x} = \frac{\partial P}{\partial z}, \quad \frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}. \tag{8.129c}$$

## 功的表述（式 8.130，逐字转录并订正）

功 $W$（参见第 670 页 8.2.2.3, 2.）可定义为 $\vec F(\vec r)$ 与位移 $\vec s$ 的点积。在守恒场中功仅与位置 $\vec r$ 有关而与速度 $\vec v$ 无关。设 $\vec F = P\vec e_x + Q\vec e_y + R\vec e_z = \mathrm{grad}\,V$，$\mathrm{d}\vec s = \mathrm{d}x\,\vec e_x + \mathrm{d}y\,\vec e_y + \mathrm{d}z\,\vec e_z$（转写本误作 $\mathrm{d}z\,\vec e_x$，应为 $\vec e_z$），则势能 $V(\vec r)$ 满足关系 (8.129a)、(8.129b)，且有等式 (8.129c) 成立。功与点 $P_1$ 和 $P_2$ 间的积分路径无关：

$$W = \int_{P_1}^{P_2} \vec F(\vec r)\cdot\mathrm{d}\vec s = \int_{P_1}^{P_2} [P\,\mathrm{d}x + Q\,\mathrm{d}y + R\,\mathrm{d}z] = V(P_2) - V(P_1). \tag{8.130}$$

## 复算与评注

1. **等价链结构核验**：(8.124/8.125)（路径无关）⇒ 沿闭路积分为 0 ⇒ 沿折线构造 $U$（见 [[methodology/原函数折线构造法]]）⇒ (8.126a/b) ⇒ 混合偏导相等 $\frac{\partial^2 U}{\partial x\partial y}=\frac{\partial^2 U}{\partial y\partial x}$ 给出 (8.127)；反向由 (8.127)+单连通+偏导连续恢复 $U$。链条自洽。
2. **(8.129c) 为旋度型条件**：三方程即 $\operatorname{rot}\vec F=\vec 0$ 的分量形式（向量表示见手册 13.3.1.1，未入库；此对照为本 wiki 的独立注记）；二维条件 (8.127) 是其第三方程（$z$ 分量）在 $R=0$、$P$、$Q$ 不依赖 $z$ 时的特殊情形，对照见 [[comparisons/二维与三维可积条件比较]]。
3. **式 8.130 = 微积分基本定理的线积分类比**：$\int_{P_1}^{P_2}\mathrm{d}V = V(P_2)-V(P_1)$，与 [[concepts/微积分基本定理]] $\int_a^b F'(x)\,\mathrm{d}x=F(b)-F(a)$ 同构。
4. **单连通前提的显隐不一致**：8.3.4.1 明示单连通，8.3.4.3 未重申；该前提在例 A（去心平面）上的失效见 [[queries/单连通前提与例A去心平面的失效边界]]。

## 转写讹误记录

「仅与积分路径的起点 和终点 有关」脱 $A$、$B$；「即对任意 A,及积分路径 ACB ADB」脱 $B$ 及路径记号；「则势能 $V(\vec r)$ 门满足关系」衍字「门」。汇总见 [[queries/8-3全节系统性转写讹误清单]]。
