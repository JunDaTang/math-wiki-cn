# 式 15.47–15.55 常系数方程拉普拉斯求解转录复算

## 发现内容

手册 15.2.3.1 给出常系数线性常微分方程初值问题的完整拉普拉斯变换解法链：一般原理 (15.47a)→(15.47b)、一阶 (15.48)–(15.49)、二阶三种判别情形 (15.50)–(15.53)、一个完整算例、n 阶单根情形的阶跃响应闭式 (15.54b) 与一般扰动公式 (15.55)。逐式转录如下（% 注为讹误标注）：

```latex
(15.47a)  y^{(n)} + c_{n-1} y^{(n-1)} + ... + c_1 y' + c_0 y = f(t),
          y(+0)=y_0, y'(+0)=y_0', ..., y^{(n-1)}(+0)=y_0^{(n-1)}
(15.47b)  \sum_{k=0}^{n} c_k p^k Y - \sum_{k=1}^{n} c_k \sum_{v=0}^{k-1} p^{k-v-1} y_0^{(v)} = F  (c_n=1)
          特征方程 G(p) = \sum_{k=0}^{n} c_k p^k = 0

(15.48a)  y' + c_0 y = f,  y(+0)=y_0
(15.48b)  (p+c_0) Y - y_0 = F
(15.48c)  Y = [F + y_0]/(p+c_0)
          f = \lambda e^{\mu t}, F = \lambda/(p-\mu)        % (15.49a) 编号处无公式行
(15.49b)  Y = \lambda/[(p-\mu)(p+c_0)] + y_0/(p+c_0)
(15.49c)  y = \lambda/(\mu+c_0) e^{\mu t} + (y_0 - \lambda/(\mu+c_0)) e^{-c_0 t}

(15.50a)  y'' + 2a y' + b y = f,  y(+0)=y_0, y'(+0)=y_0'
(15.50b)  (p^2+2ap+b) Y - 2a y_0 - (p y_0 + y_0') = F
(15.50c)  Y = [F + (2a+p) y_0 + y_0']/(p^2+2ap+b)

(15.51b)  q(t) = (e^{\alpha_1 t} - e^{\alpha_2 t})/(\alpha_1-\alpha_2)      % b<a^2
(15.52b)  q(t) = t e^{\alpha t}                                              % b=a^2
(15.53b)  q(t) = e^{-at} \sin(\sqrt{b-a^2}\,t)/\sqrt{b-a^2}                 % b>a^2

% 算例 y''+2y'+10y = 37cos3t+9e^{-t}, y_0=1, y_0'=0:
Y = (p+2)/(p^2+2p+10) + 37p/[(p^2+9)(p^2+2p+10)] + 9/[(p+1)(p^2+2p+10)]
  = -p/(p^2+2p+10) - 19/(p^2+2p+10) + p/(p^2+9) + 18/(p^2+9) + 1/(p+1)
y(t) = (-cos3t - 6 sin3t) e^{-t} + cos3t + 6 sin3t + e^{-t}

(15.54a)  u(t) = 1 (t>0); 0 (t<0)
(15.54b)  y(t) = 1/G(0) + \sum_{v=1}^{n} e^{\alpha_v t}/[\alpha_v G'(\alpha_v)]   % 单根且均非零
(15.55)   \tilde{y}(t) = d/dt \int_0^t y(t-\tau) f(\tau) d\tau = d/dt [y*f]      % 源称「达朗贝尔公式」
```

## 复算核验（独立推导）

- **(15.47b)**：对每一项用导数变换法则 L{y^{(k)}} = p^k Y − Σ_{v=0}^{k−1} p^{k−v−1} y_0^{(v)}，逐项相加与 (15.47b) 相符；n=1、n=2 分别退化为 (15.48b)、(15.50b) ✓。
- **(15.49c)**：代入初始值 y(+0) = λ/(μ+c₀) + y_0 − λ/(μ+c₀) = y_0 ✓；代入方程亦满足 ✓。注意 μ = −c₀（共振）时分母为零，源文未讨论该情形。
- **三个核函数互为解析延拓**：b→a²⁻ 时 (15.51b) 洛必达极限趋于 t·e^{−at}（α = −a），与 (15.52b) 一致；b→a²⁺ 时 (15.53b) 因 sin(εt)/ε → t 趋于同一极限 ✓。
- **算例完整复算通过**：部分分式分解通分核对，分解前后分子同为 p⁴+3p³+57p²+64p+99 ✓；配方 p²+2p+10 = (p+1)²+9 后逐项逆变换得源文结果 ✓；y(0) = 1 ✓，y′(0) = 0 ✓；y″(0) = 36，代入 y″+2y′+10y|₀ = 36+10 = 46 = 37+9，与右端 f(0) 一致 ✓。
- **(15.54b)**：对 1/(pG(p)) 作部分分式，p=0 处系数 1/G(0)，p=α_v 处系数 1/(α_v G′(α_v)) ✓；n=1 退化为 (1−e^{−c₀t})/c₀，与一阶方程零初始条件的阶跃响应一致 ✓。
- **(15.55)**：L{d/dt[y∗f]} = p·Y·F = p·(1/(pG))·F = F/G，恰为零初始条件下一般扰动的像解 ✓（同时说明 (15.54b)、(15.55) 隐含零初始条件，见 [[queries/式15-54b隐含零初始条件之辨]]）。
