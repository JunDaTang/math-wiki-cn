# 式 17.50–17.52 李雅普诺夫维数与埃农吸引子转录复算

## 转录

```latex
% k 为满足 sum_{i<=k} λ_i >= 0 且 sum_{i<=k+1} λ_i < 0 的最大指标
d_L(mu) = k + (sum_{i=1}^k λ_i) / |λ_{k+1}|                                      (17.50)
% 若 sum_{i=1}^n λ_i >= 0，则 d_L = n；若 λ_1 < 0，则 d_L = 0
% 勒德拉皮耶定理（C² 离散系统、吸引子上遍历不变概率测度）：d_H(mu) ≤ d_L(mu)
d_B ≈ 1 − ln σ_1/ln σ_2 = 1 + λ_1/|λ_2|        （σ_1>1>σ_2，源文明示「启发式的估计」）(17.51)
d_L(mu) ≈ 1 + 0.42/1.62 ≈ 1.26                  （埃农吸引子 a=1.4, b=0.3）          (17.52)
```

## 复算

- **式 17.51 代数核验**：$\lambda_i=\ln\sigma_i$（每次迭代的平均对数伸长）⟹ $-\ln\sigma_1/\ln\sigma_2=-\lambda_1/\lambda_2=\lambda_1/|\lambda_2|$（$\lambda_2<0$）✓。覆盖论证（$\varepsilon$-方形映为 $\sigma_1\varepsilon\times\sigma_2\varepsilon$ 平行四边形、$N_{\sigma_2\varepsilon}\simeq N_\varepsilon\sigma_1/\sigma_2$、$N_\varepsilon\varepsilon^{d_B}\simeq N_{\sigma_2\varepsilon}(\varepsilon\sigma_2)^{d_B}$）代数自洽。
- **埃农吸引子（$a=1.4,\ b=0.3$）**：$|\det D\varphi|=b$（与既有 [[methodology/离散映射耗散性雅可比行列式判据流程]] 的埃农判据一致）⟹ $\lambda_1+\lambda_2=\ln b=\ln0.3=-1.20397$（源文 ≈−1.204 ✓）。数值 $\lambda_1\approx0.42$ ⟹ $\lambda_2=-1.20397-0.42=-1.624$（源文 ≈−1.62 ✓）。$k=1$（$\lambda_1\ge0$，$\lambda_1+\lambda_2<0$）⟹ $d_L=1+0.42/1.62=1.259\approx1.26$（源文式 17.52 ✓）。
- **文献对照**（独立可查背景）：文献载 $\lambda_1\approx0.418$、$d_L\approx1.258$，与源文数值一致；$d_B\approx1.26$ 亦相符。
- **$d_L\approx d_B$ 的口径**：源文将 $d_B\simeq1.26$（数值）与 $d_L\simeq1.26$（数值）并列，未表述为定理；该吻合是数值层面的，不得外推为一般等式。
- **式 17.50 边界情形**：$\sum_i\lambda_i\ge0$ 时不存在满足条件的 $k$（一切部分和非负），源文直接规定 $d_L=n$；$\lambda_1<0$ 时 $k$ 不存在，规定 $d_L=0$——按源文转录。
- **勒德拉皮耶定理**：手册式断言，无证明；$d_H(\mu)\le d_L(\mu)$ 与本 wiki 既有 [[concepts/SRB测度]] 框架（埃农吸引子上存在 SRB 测度，源文断言「可证」）相容。

## 判定

代数与数值复算全部通过；唯一须保留的口径限定是 $d_L\approx d_B$ 仅数值层面。

## 讹误登记

「入₁」等 →「$\lambda_1$」（入→λ 系统性讹）；17.50 处「为满足…的最大指标」前脱「k」字。汇总见 [[queries/17-2-4全节系统性转写讹误清单]]。
