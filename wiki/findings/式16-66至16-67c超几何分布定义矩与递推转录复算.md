# 式 16.66–16.67c 超几何分布定义、矩与递推转录复算

对《数学手册(原书第10版)》16.2.3.2「超几何分布」的全部编号公式及逼近条件作转录与独立复算。

## 转录

```latex
(16.66a)  P(X=k) = W_{M,N}^n(k) = \frac{\binom{M}{k}\binom{N-M}{n-k}}{\binom{N}{n}}
(16.66b)  0 \le k \le n,   k \le M,   n-k \le N-M
(16.67a)  \mu = E(X) = \sum_{k=0}^{n} k\,\frac{\binom{M}{k}\binom{N-M}{n-k}}{\binom{N}{k}} = n\,\frac{M}{N}
          % 原文分母作 \binom{N}{k}
(16.67)   \sigma^2 = D^2(X) = \sum_{k=0}^{n} k^2\,\frac{\binom{M}{k}\binom{N-M}{n-k}}{\binom{N}{k}}
               - \left(n\,\frac{M}{N}\right)^2
               = n\,\frac{M}{N}\left(1-\frac{M}{N}\right)\frac{N-n}{N-1}
          % 原文分母作 \binom{N}{k}；编号疑为 (16.67b)
(16.67c)  W_{M,N}^n(k+1) = \frac{(n-k)(M-k)}{(k+1)(N-M-n+k+1)}\, W_{M,N}^n(k)
```

## 复算

1. **归一化**：$\sum_k \binom{M}{k}\binom{N-M}{n-k} = \binom{N}{n}$（Vandermonde 恒等式），故 (16.66a) 为合法分布列。✔
2. **期望 (16.67a)**：用 $k\binom{M}{k} = M\binom{M-1}{k-1}$ 得 $\sum_k k\,\binom{M}{k}\binom{N-M}{n-k} = M\binom{N-1}{n-1}$，而 $\binom{N}{n} = \frac{N}{n}\binom{N-1}{n-1}$，故 $E = nM/N$。✔（此推导亦反证求和分母应为 $\binom{N}{n}$：若分母随流动指标 k 变化，矩的求和式失去意义。）
3. **方差 (16.67)**：$n\frac{M}{N}(1-\frac{M}{N})\frac{N-n}{N-1}$ 与标准结果（含有限总体校正因子）一致。✔
4. **递推 (16.67c)**：$W(k+1)/W(k) = \frac{\binom{M}{k+1}}{\binom{M}{k}}\cdot\frac{\binom{N-M}{n-k-1}}{\binom{N-M}{n-k}} = \frac{(M-k)(n-k)}{(k+1)(N-M-n+k+1)}$，验证正确。✔
5. **分母讹误**：原文 (16.67a) 与 (16.67) 两处求和分母作 $\binom{N}{k}$，与 (16.66a) 的 $\binom{N}{n}$ 直接矛盾（k 为流动指标），可证为转写错误；方差公式编号原文作 (16.67)，疑应为 (16.67b)。见[[queries/式16-67a与16-67分母Cnk疑为Cnn]]。⚠
6. **由二项逼近的条件**：原文「如果 N−M 也比 [?] 大很多，则超几何分布可由二项分布很好地逼近」句子疑脱 M 与 n，按上下文应理解为 M 与 N−M 均远大于 n。图 16.3（N=100, n=5, M=50/25/10）与图 16.2（n=5, p=M/N=0.5/0.25/0.1）对照显示两分布无明显区别，与该条件相容。✔

## 证据强度

定义、矩、递推为可复算的确定性数学内容（直接证据，强）；分母讹误与编号疑点属转写层面（可由内部矛盾证明）；逼近条件为手册经验性陈述（间接证据，中）。
