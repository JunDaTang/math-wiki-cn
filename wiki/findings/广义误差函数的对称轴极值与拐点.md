# 广义误差函数的对称轴、极值与拐点（式 2.61）

手册 2.6.5 给出 [[广义误差函数]] $y = a\mathrm{e}^{bx+cx^{2}}$（c ≠ 0，仅讨论 a > 0，a < 0 沿 x 轴反射）的图像要素：

- **对称轴**：铅直直线 $x = -\frac{b}{2c}$；
- **截距**：与 x 轴无交点；与 y 轴交点 D(0, a)；
- **情形 a) c > 0**：先由 +∞ 减小到极小值再增至 +∞，取值恒为正；极小值点 $A\left(-\frac{b}{2c},\ a\mathrm{e}^{\frac{b^{2}}{4c}}\right)$；无拐点和渐近线；
- **情形 b) c < 0**：x 轴为渐近线；极大值点 $A\left(-\frac{b}{2c},\ a\mathrm{e}^{-\frac{b^{2}}{4c}}\right)$；拐点 $B, C\left(\frac{-b\pm\sqrt{-2c}}{2c},\ a\mathrm{e}^{\frac{-(b^{2}+2c)}{4c}}\right)$。

## 复核结果

**已验证正确的部分**：对称轴与 D(0, a) ✓；情形 b) 全部公式 ✓——取 b = 0、c = −1、a = 1 退化为误差曲线 $\mathrm{e}^{-x^{2}}$，顶点值 1、拐点 ±√2/2、拐点值 e^{−1/2}，与 2.6.3 完全吻合。这一退化关系本身就是「误差曲线 ⊂ 广义误差函数」的证明（对照 [[误差曲线与广义误差函数比较]]）。

**两处高置信度疑误（仅涉及本族，不影响其他族）**：

1. **式 (2.61) 中间因子 $\mathrm{e}^{-\frac{b^{2}}{4c^{2}}}$ 应为 $\mathrm{e}^{-\frac{b^{2}}{4c}}$**：配方 $bx + cx^{2} = c\left(x+\frac{b}{2c}\right)^{2} - \frac{b^{2}}{4c}$，原式展开后多出 $\frac{b^{2}}{4c} - \frac{b^{2}}{4c^{2}} \neq 0$（除非 c = 1 或 b = 0），代数上不自洽（[[式2-61配方因子4c平方是否应为4c]]）。
2. **情形 a) 极小值 $a\mathrm{e}^{\frac{b^{2}}{4c}}$ 应为 $a\mathrm{e}^{-\frac{b^{2}}{4c}}$**：顶点函数值与 c 的符号无关，恒为 $a\mathrm{e}^{-\frac{b^{2}}{4c}}$（情形 b) 书写正确）；且 c > 0 时 $\mathrm{e}^{b^{2}/(4c)} \geq 1$，若 a > 0 则该「极小值」≥ y(0) = a，与「先由 +∞ 减小到极小值」（x = 0 处 y = a 应位于极小值上方）自相矛盾（[[广义误差函数情形a极小值是否漏负号]]）。

判定：**部分成立**——对称轴、截距与情形 b) 成立；情形 a) 的极小值及 (2.61) 配方因子存疑，需对照原版确认。
