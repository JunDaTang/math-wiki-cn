# 式 16.39–16.43 条件概率、独立性与贝叶斯定理转录复算

## 转录内容

$$P(B \mid A) = \frac{P(AB)}{P(A)},\quad P(A) \neq 0 \tag{16.39}$$

若 $P(A) \neq 0$ 且 $P(B) \neq 0$：

$$\frac{P(B \mid A)}{P(B)} = \frac{P(A \mid B)}{P(A)} \tag{16.40a}$$

若 $P(A_1A_2\cdots A_n) \neq 0$：

$$P(A_1 A_2 \dots A_n) = P(A_1) P(A_2 \mid A_1) \dots P(A_n \mid A_1 A_2 \dots A_{n-1}) \tag{16.40b}$$

独立事件：

$$P(A \mid B) = P(A)\ \text{和}\ P(B \mid A) = P(B) \iff P(AB) = P(A)P(B) \tag{16.41a/b}$$

全概率定理与贝叶斯定理（前提：$B_i \in {\cal A}$ 构成完备事件组，$P(B_i) > 0$；贝叶斯另需 $P(A) > 0$）：

$$P(A) = \sum_{i} P(A \mid B_i) P(B_i) \tag{16.42}$$

$$P(B_k \mid A) = \frac{P(A \mid B_k) P(B_k)}{\sum_{i} P(A \mid B_i) P(B_i)} \tag{16.43}$$

## 复算核验（直接证据）

- 16.40a：由 16.39，$P(B|A)/P(B) = P(AB)/(P(A)P(B)) = P(A|B)/P(A)$ ✓（对称的 Bayes 雏形）。
- 16.40b：对 $n$ 归纳，逐次以 16.39 展开 $P(A_2|A_1) = P(A_1A_2)/P(A_1)$ 等即得 ✓。
- 16.41：若 $P(A|B) = P(A)$，代入 16.39 得 $P(AB) = P(A)P(B)$；反向亦然（需 $P(A), P(B) \neq 0$）✓。手册以「当且仅当」表述，与等价性一致。
- 16.42：$A = A(B_1 + \dots + B_n) = \sum_i AB_i$，诸 $AB_i$ 互斥，用有限加法（16.35a）与 16.39 ✓。
- 16.43：分子 $P(A|B_k)P(B_k) = P(AB_k)$，对 $k$ 求和即 16.42 的 $P(A)$，故 16.43 即 16.39 的重排 ✓。

## 转写讹误

- 条件概率引导段的 $A$、$B$ 符号多处脱落（「当已知某个事件 已发生时事件 发生的概率」）。
- 独立性段「则称事件 和事件 是独立事件」同样脱落。
- 16.42/16.43 前提句「$B_i \in {\cal A}$ 构成一个完备事件组，且 $P(B_i) > 0\ (i = 1, 2, \cdots, n)$」中断行处 $n$ 转写不完整，不影响语义。
- 16.39 的读法注（「读作：A 发生条件下 B 发生的概率」）中事件符号脱落。

## 结论

式 16.39–16.43 五组公式转录完整、数学复算全部成立；脱落仅限散文符号，公式本体无损。
