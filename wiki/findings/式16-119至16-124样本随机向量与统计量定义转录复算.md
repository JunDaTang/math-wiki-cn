# 式 16.119–16.124 样本随机向量与统计量定义转录复算

对 16.3.1 全部编号公式 (16.119a)–(16.124b) 逐字转录（转录全文见 [[sources/10-数学手册原书第10版--15-1631-统计量函数或样本函数--nz89xo]]），并对可验证的代数关系复算。

## 复算结论

| 对象 | 结论 | 判定 |
|---|---|---|
| (16.119a/b) 样本随机向量及其实现 | 记号自洽：$\underline{\mathbf{X}}$ 为随机向量、$\underline{\mathbf{x}}$ 为其一个实现 | 成立 |
| (16.120) 多组样本平均值列表 | 内容自洽（$x_{ij}$ 双下标记法与 $\bar{x}_k$ 定义互洽），但排版异常：编号挂于文字列表中段、各行「第 1/2/m 组」序数脱落 | 成立（转写异常另计） |
| (16.121a–d) 均值及 $x_0$ 平移 | $\bar{x} = x_0 + \bar{z}$：由 $z_i = x_i - x_0$ 求和取平均即得，代数恒等 | 成立 |
| (16.122a/b) 方差 n−1 定义 | 与 (16.121a/b) 平行的「定义—实现」配对，形式自洽 | 成立 |
| (16.122c) 方差 $x_0$ 形式 | 两支恒等：$\bar{z}\sum z_i = n\bar{z}^2 = n(\bar{x}-x_0)^2$（展开 $z_i = (x_i-\bar{x}) + (\bar{x}-x_0)$ 可证）；$x_0 = \bar{x}$ 时 $\bar{z}=0$ 交叉项消失 | 成立 |
| (16.123) 中位数奇偶分段 | 标准形式：$n = 2m+1$ 取第 $m+1$ 项、$n = 2m$ 取第 $m$ 与 $m+1$ 项平均，与正文「第 (n+1)/2 项」表述一致 | 成立 |
| (16.124a/b) 极差 | 标准形式且自洽 | 成立 |

## 直接证据与推断

- 以上均为**直接证据**：公式为代数定义或恒等式，经手工展开验证，无需实验数据。
- 数值层面的验证由 [[findings/扬声器气隙感应样本统计量算例复算]] 提供（n = 15 数据集，四统计量全部复现）。
- 转写异常（「元」字残迹、行内符号脱落、(16.120) 排版等）不属数学内容，集中记录于 [[queries/16-3-1全节系统性转写讹误清单]] 与 [[queries/元字疑为均值中位数符号脱漏之辨]]。

## 局限

本 finding 验证的是公式的内部一致性与标准形式，不涉及「除以 n−1 更精确」这一引证主张——该主张属 [[concepts/样本方差]]，本节未给证明。
