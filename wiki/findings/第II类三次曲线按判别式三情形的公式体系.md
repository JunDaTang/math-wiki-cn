# 第II类三次曲线按判别式三情形的公式体系（式 2.48，已数值验证）

手册 2.4.4 给出 [[concepts/第II类三次曲线]] y = 1/(ax² + bx + c)（a ≠ 0）的图像要素（直接证据）：图像关于 x = −b/(2a) 对称，x 轴为 [[concepts/渐近线]]，形状由 a 与 Δ = 4ac − b² 的符号决定；a < 0 情形可经「a、b、c 全部变号再沿 x 轴反射」化为 a > 0。取 a > 0，按 Δ 三情形：

- **Δ > 0**（分母无实根）：函数处处为正的连续函数，在 (−∞, −b/(2a)) 上单调递增并取得极大值 4a/Δ，再单调递减。极值点 A(−b/(2a), 4a/Δ)；[[concepts/拐点]] B, C = (−b/(2a) ± √Δ/(2a√3), 3a/Δ)；拐点处切线斜率（源文称「角系数」）tan φ = ∓a²(3/Δ)^{3/2}（图 2.19(a)）。
- **Δ = 0**：函数恒正，先由 0 增至 +∞；x₀ = −b/(2a) 为间断点（二重[[concepts/极点]]），lim(x→x₀) y = +∞；再由 +∞ 减至 0（图 2.19(b)）。
- **Δ < 0**：函数值先由 0 增至 +∞，在间断点跳跃到 −∞，递增取得极大值 4a/Δ（负值）后又减小到 −∞，在另一间断点跳跃到 +∞ 再减小到 0。极值点仍为 A(−b/(2a), 4a/Δ)；间断点为 x = (−b ± √(−Δ))/(2a)（图 2.19(c)）。

**验证状态（独立重推导 + 数值例）**：

- 数值例：取 a = 1, b = 0, c = 1（Δ = 4），手册公式给出拐点 (±1/√3, 3/4)、斜率 ∓3√3/8；对 y = 1/(x²+1) 直接求导核对，全部吻合；
- 反射化归的恒等式 −1/((−a)x² − bx − c) = 1/(ax² + bx + c) 经推导确认；
- 极大值 4a/Δ = 1/(c − b²/(4a)) 与分母最小值的倒数一致，推导吻合。

**与极点重数判据的呼应**：Δ = 0（二重极点，两侧同号趋于 +∞）与 Δ < 0（两个一重极点，两侧变号跳跃）正是 [[concepts/极点]] 重数判据的两个标准实例，与 2.1.5 的间断点分类互相印证。
