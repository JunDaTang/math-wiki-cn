# 式 12.168–12.176 拟范数、哈恩—巴拿赫与自反性转录复算

## 逐字转录

```
(NH1) p(x) ⩾ 0                                                (12.168)
(NH2) p(αx) = |α|·p(x)                                        (12.169)
(NH3) p(x+y) ⩽ p(x) + p(y)                                    (12.170)
|f₀(x)| ⩽ p(x), ∀x∈X₀                                         (12.171)
f(x)=f₀(x) (∀x∈X₀);  |f(x)| ⩽ p(x) (∀x∈X)                      (12.172)
f(x)=0 (∀x∈X₀);  f(x₀)=1;  ‖f‖ = 1/d,  d = inf_{x∈X₀}‖x−x₀‖    (12.173)
sup_{x∈A} f(x) ⩽ inf_{y∈B} f(y)                               (12.174)
A ⊂ {x: f(x)⩽α},  B ⊂ {x: f(x)⩾α},  α = sup_A f                (12.175)
J: X→X**,  Jx = F_x,  F_x(f) = f(x), ∀f∈X*                     (12.176)
```

## 复算判定

- **(12.171)–(12.173) 复算无误**：推论 (2) 中 $\|f\|=\frac1d$ 与受控延拓一致（$f$ 在距 $X_0$ 为 $d$ 的点 $x_0$ 处取 1）。
- **(12.174)–(12.176) 复算无误**：分离定义与半空间刻画自洽；$J$ 的等距性 $\|F_x\|=\sup_{\|f\|\le1}|f(x)|=\|x\|$ 的后一等号恰由哈恩—巴拿赫推论 (1) 保证——源内自洽。
- **几何形式哈恩—巴拿赫定理（12.5.6.2）疑误（强证据，反例）**：源结论为“存在一闭的**超子空间** $H$ 使 $x_0+L\subset H$ 且 $H\cap K=\varnothing$”。反例（$\mathbb{R}^2$）：$L=\{0\}$、$x_0=(1,0)$、$K=$ 以 $(0.5,0.4)$ 为心、$0.42$ 为半径的开圆。$x_0+L=\{x_0\}$ 与 $K$ 不交；含 $x_0$ 的超子空间（过原点的 $x$ 轴）与 $K$ 相交（点 $(0.5,0)$ 到圆心距离 $0.4<0.42$）；而闭**超平面** $\{x=1\}$ 含 $x_0$ 且与 $K$ 不交（圆上点横坐标 $<0.92<1$）。故 $H$ 应为闭超平面，与该节自身“超子空间（过原点）/超平面（仿射）”的术语区分冲突。见 [[queries/几何形式哈恩巴拿赫闭超子空间疑为闭超平面]]。
- **自反性陈述内部矛盾**：源 12.5.7 先称“$L^p\ (1\le p<\infty)$ 都是自反的”，随后列 $L^1([0,1])$ 为非自反例子；$L^1$ 非自反是标准定理，前者应为 $1<p<\infty$。见 [[queries/Lp空间自反性陈述内部矛盾]]。另 "co" 为 $c_0$ 讹写。
- 术语噪声：“准范数/拟范数”混用、“放射线性流形”应为“仿射线性流形”，见 [[queries/准范数与仿射线性流形术语辨析]]。
