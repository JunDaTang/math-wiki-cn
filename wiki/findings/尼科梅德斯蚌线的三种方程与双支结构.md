# 尼科梅德斯蚌线的三种方程与双支结构（式 2.233）

**主张。** 尼科梅德斯蚌线具有等价的隐式、参数、极坐标三种表述；曲线由共享渐近线 $x = a$ 的左右两支组成，顶点为 A(a+l, 0)（右支）与 D(a−l, 0)（左支），右支与渐近线围成的面积 $S = \infty$。

**证据（式 2.233 原样）。**

```text
(2.233a) (x − a)²(x² + y²) − l²x² = 0            (a > 0, l > 0)
(2.233b) x = a + l cos φ,  y = a tan φ + l sin φ
         右支：−π/2 < φ < π/2；左支：π/2 < φ < 3π/2
(2.233c) ρ = a/cos φ ± l                          （+：右支，−：左支）
```

**验证（已验证，代数复核）。**
- 右支上参数 φ 即极角，式 2.233b 与 2.233c 直接互代（$x = \rho\cos\varphi$、$y = \rho\sin\varphi$，配合直线 $\rho\cos\varphi = a$）；左支由同一参数公式在区间 $(\pi/2, 3\pi/2)$ 上给出，对应构造中取“−”的一侧（P 位于 M 向极点方向退 l 处）。
- 隐式方程总次数为 4（$(x-a)^2(x^2+y^2)$ 为四次项），确认其四阶属性。
- 渐近线行为：$\varphi \to \pi/2$ 或 $3\pi/2$ 时 $x \to a$ 而 $|y| \to \infty$，两支均以 $x = a$ 为 [[concepts/渐近线]]，与手册陈述一致。

**分支结构要点。** 参数域按支拆分（右支取 +、左支取 −），这是绘制蚌线时必须分支处理的原因（见 [[methodology/四阶曲线图像绘制法]]）；原点奇点随 l/a 切换的问题另见 [[findings/尼科梅德斯蚌线的奇点三分律与特征点]]。
