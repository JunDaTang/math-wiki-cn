# 式 20.8a–20.8b 延迟赋值完全形式转录复算

## 转录（源文档）

```
u := v  的 FullForm 是 SetDelayed[u, v]     (20.8a)
u :-> v 的 FullForm 是 RuleDelayed[u, v]    (20.8b)
```

## 复算结论

- 式 (20.8a)：`u := v` 的 FullForm 确为 `SetDelayed[u, v]`，无误。
- 式 (20.8b)：`u :> v` 的 FullForm 确为 `RuleDelayed[u, v]`，无误。原书左端排作 `u :-> v`，系 `u :> v`（RuleDelayed 的中置记法）与 `u -> v`（Rule 的中置记法）混排的排版形，标准输入形式为 `u :> v`。
- 语义表述亦与官方语义一致：指派或变换规则持续有效直到被改变；左手边总是被右手边取代，但右端只在调用左手边的那一刻才第一次求值。
