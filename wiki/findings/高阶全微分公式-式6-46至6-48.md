# 高阶全微分的算子幂公式（式 6.46–6.48）与一元二阶微分的适用限制

**发现**：源文给出二元二阶、n 阶与 m 元 n 阶全微分的算子幂公式；由 du 出发视 dx、dy 为常数逐项微分、并引用施瓦茨交换定理合并交叉项，可复算得式 6.46a。✔ 同小节明确警示：一元 d²y = f″dx² 仅当 x 为自变量时适用——高阶微分不具形式不变性。

## 一元二阶微分的适用限制（6.2.2.2.2，逐字要点）

一元函数 $y = f(x)$ 的一阶微分的微分称为二阶微分，记 $\mathrm{d}^2 y, \mathrm{d}^2 f(x)$，其中

$$\mathrm{d}^2 y = \mathrm{d}(\mathrm{d}y) = f''(x)\,\mathrm{d}x^2$$

**仅当 x 为自变量时**，才适于采用这样的符号；若以 $x = z(v)$ 的形式给出，上述符号就不再适用。类似地可以定义高阶微分。若变元 $x_1, \dots, x_n$ 本身是其他变元的函数，可得到更复杂的公式（源文前引第 606 页 6.2.4，未入库）。

## 二元二阶全微分（式 6.46，逐字转录）

```latex
\mathrm{d}^2 u = \mathrm{d}(\mathrm{d}u) = \frac{\partial^2 u}{\partial x^2}\,\mathrm{d}x^2 + 2\,\frac{\partial^2 u}{\partial x\,\partial y}\,\mathrm{d}x\,\mathrm{d}y + \frac{\partial^2 u}{\partial y^2}\,\mathrm{d}y^2, \tag{6.46a}
```

或象征性地写为

```latex
\mathrm{d}^2 u = \left(\frac{\partial}{\partial x}\,\mathrm{d}x + \frac{\partial}{\partial y}\,\mathrm{d}y\right)^2 u. \tag{6.46b}
```

## n 阶与 m 元推广（式 6.47–6.48，逐字转录）

```latex
\mathrm{d}^n u = \left(\frac{\partial}{\partial x}\,\mathrm{d}x + \frac{\partial}{\partial y}\,\mathrm{d}y\right)^n u, \tag{6.47}
```

```latex
\mathrm{d}^n u = \left(\frac{\partial}{\partial x_1}\,\mathrm{d}x_1 + \frac{\partial}{\partial x_2}\,\mathrm{d}x_2 + \dots + \frac{\partial}{\partial x_m}\,\mathrm{d}x_m\right)^n u. \tag{6.48}
```

## 复算（本方推导）

由 $\mathrm{d}u = u_x\,\mathrm{d}x + u_y\,\mathrm{d}y$ 出发，视 $\mathrm{d}x, \mathrm{d}y$ 为常数，逐项微分：

$$\mathrm{d}^2 u = \mathrm{d}(u_x)\,\mathrm{d}x + \mathrm{d}(u_y)\,\mathrm{d}y = (u_{xx}\,\mathrm{d}x + u_{xy}\,\mathrm{d}y)\,\mathrm{d}x + (u_{yx}\,\mathrm{d}x + u_{yy}\,\mathrm{d}y)\,\mathrm{d}y$$
$$= u_{xx}\,\mathrm{d}x^2 + (u_{xy} + u_{yx})\,\mathrm{d}x\,\mathrm{d}y + u_{yy}\,\mathrm{d}y^2.$$

引用施瓦茨交换定理（式 6.45，$u_{xy} = u_{yx}$）合并交叉项，恰得式 6.46a；对式 6.46b 的算子平方按二项式定理展开，结果相同。✔ 一般 n 阶（式 6.47–6.48）为同一机制的归纳推广，展开产生全部 n 阶偏导数组合（含多项式系数）。

## 归属与限制

- 式 6.46–6.48 **仅对自变量成立**——「视 dx 为常数」正是一元警示在多元侧的对应物；高阶全微分不具一阶那样的形式不变性，见 [[concepts/微分形式不变性]] 与 [[comparisons/一阶与高阶微分形式不变性比较]]。
- 算子幂的「形式幂」结构与 [[concepts/莱布尼茨公式]] 同源，参见 [[comparisons/莱布尼茨公式与二项式定理比较]]。
