# 式 12.34–12.39 向量格、正负部与模转录复算

## 转录内容

```
(x∨y)(t) = max{x(t), y(t)}, ∀t ∈ [a,b]                          (12.34)
(x∨y)(t) = { 1 − (3/2)t,  0 ≤ t ≤ 1/2；  t²,  1/2 < t ≤ 1 }      (12.35)
T(x∨y) = Tx∨Ty  且  T(x∧y) = Tx∧Ty                              (12.36)
x₊ = x∨0,  x₋ = (−x)∨0,  |x| = x₊ + x₋                           (12.37)
x ≤ x₊ ≤ |x|,  x = x₊ − x₋,  x₊∧x₋ = 0,  |x| = x∨(−x)           (12.38a)
(x+y)₊ ≤ x₊ + x₋,  (x+y)₋ ≤ x₋ + y₋,  |x+y| ≤ |x|+|y|           (12.38b)
x ≤ y ⟹ x₊ ≤ y₊, x₋ ≥ y₋                                        (12.38c)
(αx)₊ = αx₊, (αx)₋ = αx₋, |αx| = α|x|  (α ≥ 0)                  (12.38d)
x₊(t), x₋(t), |x|(t) 的分段公式                                  (12.39a–c)
```

## 复算验证

- **(12.35) 自洽性**：在 t = 1/2 处，1 − (3/2)(1/2) = 1/4 = (1/2)²，两支连续相接。✓（正文 x(t) = 1 − (1/3)t 与式内系数矛盾，专项判定见 [[findings/式12-35正文xt系数与式内不一致之判定]]。）
- **(12.38a)**：在函数逐点模型下逐项验证——x = x₊ − x₋（每点 t：x(t) = max(x(t),0) − max(−x(t),0)）✓；x₊ ∧ x₋ = 0（每点至少一侧为零）✓；|x| = x∨(−x)（max(x,−x) = |x|）✓；x ≤ x₊ ≤ |x| ✓。
- **(12.38b)**：首不等式按转录为**假**（反例 x = y = 1：左 2 > 右 1），正确形式 (x+y)₊ ≤ x₊ + y₊，专项判定见 [[findings/式12-38b首不等式疑误之反例判定]]；次项 (x+y)₋ ≤ x₋ + y₋ 与三角不等式 |x+y| ≤ |x|+|y| 复算无误。✓
- **(12.38c)/(12.38d)**：函数逐点模型下直接成立（α ≥ 0 时正齐次）。✓
- **(12.39a–c)**：分段公式与定义一致；(12.39b) 在 x(t) = 0 处两支给出相同值 0，无歧义。✓
- **格判定**：F([a,b])、C([a,b])、B([a,b]) 是向量格（逐点 max 保持各自空间封闭性；复算：连续函数的逐点 max 可写 (x+y+|x−y|)/2，由四则运算保持连续性）✓；C^(1)([a,b]) 不是向量格——(12.35) 的上确界本身即为例证：两支在 t = 1/2 处斜率分别为 −3/2 与 2t = 1，不相等，产生角点不可微（复算补充）。✓

## 结论

本块含全节两处实质数学讹误之一的 (12.38b)（另一处为 (12.35) 正文系数）；其余公式复算通过。概念页：[[concepts/向量格与K空间]]；比较见 [[comparisons/向量格与非向量格有序空间比较]]。
