# 双纽线的方程奇点与几何量（式 2.240–2.241）

**主张。** 双纽线是卡西尼曲线 a = c 的特例（$\overline{F_1P}\cdot\overline{F_2P} = (\overline{F_1F_2}/2)^2$，焦点 $(\pm a, 0)$）：隐式 $(x^2+y^2)^2 - 2a^2(x^2-y^2) = 0$（式 2.241a），极坐标 $\rho = a\sqrt{2\cos 2\varphi}$（式 2.241b）。原点为二重点且同时为拐点，切线 $y = \pm x$；与 x 轴交点 A, C(±a√2, 0)；极值点 E, G, K, I(±a√3/2, ±a/2)，极角 $\varphi = \pm\pi/6$；曲率半径 $r = \frac{2a^2}{3\rho}$；每个环形的面积 $S = a^2$。

**验证（已验证，独立复推与交叉验证）。**
- 切线：隐式方程在原点的最低次项 $x^2 - y^2 = (x-y)(x+y) = 0$ 给出两条切线 $y = \pm x$，确认二重点。
- 面积：每环 $S = \frac{1}{2}\int_{-\pi/4}^{\pi/4} 2a^2\cos 2\varphi\,d\varphi = a^2$。
- 曲率交叉验证：$r = 2a^2/(3\rho)$ 恰为卡西尼曲率通式 $r = 2a^2\rho^3/(c^4-a^4+3\rho^4)$ 取 a = c 的退化（见 [[findings/卡西尼曲线按a与c之比的五种形态]]）。
- 极值点交叉验证：卡西尼 E, G, K, I 公式取 a = c 给出 $(\pm\sqrt{4a^4-a^4}/(2a), \pm a^2/(2a)) = (\pm a\sqrt{3}/2, \pm a/2)$，一致。

**地位。** 双纽线是卡西尼族“两条卵形 ↔ 单卵形”的形态分界，与蚌线族中心脏线（尖点临界）的平行地位见 [[comparisons/双纽线与心脏线比较]]。
