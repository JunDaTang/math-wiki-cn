# n 次抛物线的对称性与伸缩/反射变换（式 2.44）

2.3.5 讨论 $y = ax^n$（n 为大于零的整数，式 2.44）的图像：

**(1) 特殊情形 a = 1**：曲线 $y = x^n$ 过点 $(0,0)$ 与 $(1,1)$，原点为与 x 轴的切点或交点；n 偶时关于 **y 轴**对称且在原点取得**极小值**；n 奇时关于**原点**对称且原点为**拐点**；曲线无渐近线。

**(2) 一般情形 a ≠ 0**：将 $y = x^n$ 的坐标拉伸 $|a|$ 倍得 $y = ax^n$；a < 0 时再沿 x 轴反射。

## 疑点

原文 (2) 末句「当 a < 0 时, 曲线 $y = |a|x^n$ 可由原图像沿 x 轴反射得到」主语疑错位：按数学事实，应由 $y = |a|x^n$（拉伸结果）沿 x 轴反射得到 $y = ax^n$；直接反射 $y = x^n$ 只得 $y = -x^n$。见 [[2-3-5反射句主语是否错位]]。

## 证据评估

- **直接证据**：原书 2.3.5 原文（式 2.44 与图 2.15(a)(b)）。
- **论证**（推断）：偶 n 时 $(-x)^n = x^n$（y 轴对称），奇 n 时 $(-x)^n = -x^n$（原点对称）；n 偶时 $x^n \geq 0$ 在原点取极小，n 奇（≥3）时两侧凹凸翻转故原点为拐点。
- **边界**：n=1 时 $y = ax$ 为直线，「奇 n 原点为拐点」退化失效，见 [[奇次多项式拐点规律在n等于1时是否失效]]。
