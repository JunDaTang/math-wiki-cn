# 式 13.26 向量线微分方程与两例转录复算

## 复算对象

13.1.3.5 节：式 (13.26a,b)（向量线微分方程）、向量线不相交性质、例 A（中心场）与例 B（$\vec{V} = \vec{c}\times\vec{r}$）。

## 复算过程与结果

1. **方程推导**：曲线切向量 $(\mathrm{d}x, \mathrm{d}y, \mathrm{d}z)$ 与 $(V_x, V_y, V_z)$ 共线 $\Leftrightarrow$ (13.26a)；平面场去掉 $z$ 分量得 (13.26b)。通过。
2. **例 A（中心场 $\vec{V} = f(\vec{r})\vec{r}$，分量 $(fx, fy, fz)$）**：方程化为 $\mathrm{d}x/x = \mathrm{d}y/y = \mathrm{d}z/z$，积分得 $y = c_1 x$、$z = c_2 x$——过中心（极点）的直线族，即从中心出发的射线。**复算通过**。
3. **例 B（$\vec{V} = \vec{c}\times\vec{r}$）**：取 $\vec{c} = c\,\vec{k}$，则 $\vec{V} = c(-y, x, 0)$。方程 $\mathrm{d}x/(-cy) = \mathrm{d}y/(cx)$ 给出 $x\,\mathrm{d}x + y\,\mathrm{d}y = 0$，即 $x^2 + y^2 = $ 常数（圆周）；$V_z = 0$ 给出 $z = $ 常数（垂直于 $\vec{c}$ 的平面）。故向量线为位于垂直于 $\vec{c}$ 的平面中的圆周，圆心在平行于 $\vec{c}$ 的轴上。**复算通过**，与原书结论一致。
4. **性质复算**：在 $\vec{V}$ 有定义且非零的点处，过每点存在唯一向量线（ODE 局部存在唯一性），故向量线互不相交；例外点为 $\vec{V}$ 无定义点与零向量点。与原文陈述一致。

## 转写讹误记录

"一个 向量的点"缺"零"；"平行千 的轴"缺 $\vec{c}$；"位千垂直千向量 $\vec{c}$"为"位于垂直于"之讹；例 A/B 条目符号前的编号丢失（详见 [[13-1全节系统性转写讹误清单]]）。

## 结论

(13.26) 及两个例子均经独立积分复算验证正确。求解方法回指原书 9.1.1.2 与 9.2.1.1（未入库）。置信度高。
