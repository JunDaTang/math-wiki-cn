# 共轭复数的性质（式 1.135、1.139）

《数学手册》1.5.2.5 与 1.5.3.2 给出[[concepts/共轭复数]]的如下性质：

**定义**（式 1.135a）：Re(z*) = Re(z)，Im(z*) = −Im(z)；记号 z* 或 z̄。

**三种形式下的表达**（式 1.135b/c）：

- z = a + ib = ρ(cos φ + i sin φ) = ρ e^{iφ}
- z* = a − ib = ρ(cos φ − i sin φ) = ρ e^{−iφ}

即共轭把辐角变号而模不变；几何上对应点关于实轴对称。

**和差性质**（1.5.3.1）：z + z* 总是实数；z − z* 是纯虚数。（宽松表述：Im(z) = 0 时 z − z* = 0，严格说并非纯虚数。）

**模的性质**（1.5.3.2 与式 1.139）：

zz* = |z|² = a² + b²

依据是乘积 (a + ib)(a − ib) = a² + b² 为实数（式 1.139）。源文该处写作 "zz* = p² = |z|² = a² + b²"，p 与全节统一的模记号 ρ 不符，疑为排印之误（见 [[queries/式1.137节zz星号等于p平方中p是否为ρ排印之误]]）。

**应用**：复数除法中分子分母同乘除数的共轭，使分母实数化（1.5.3.4）。

验证：以 z = 1 + i√3 核算，zz* = 1 + 3 = 4 = |z|²，成立。属定义性内容，核算无误。
