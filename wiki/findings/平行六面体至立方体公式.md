# 平行六面体至立方体公式（式 3.121–3.126）

**直接证据**（源文 3.3.3(3)–(5)，图 3.55–3.56）。

**平行六面体**（平行四边形底的棱柱）：全部四条空间对角线彼此交于同一点，即它们的中点。

**长方体**（矩形底的直角平行六面体）：空间对角线长相等；设 a、b、c 为棱长、d 为对角线长（转写中 b、c、d 的符号脱落）：

$$d^{2} = a^{2} + b^{2} + c^{2} \tag{3.121}$$
$$V = abc \tag{3.122}$$
$$S = 2(ab + bc + ca) \tag{3.123}$$

**立方体**（正六面体，a = b = c）：

$$d^{2} = 3a^{2} \tag{3.124}$$
$$V = a^{3} \tag{3.125}$$
$$S = 6a^{2} \tag{3.126}$$

**独立核验（已复核）**：3.121 为勾股定理的两次叠加（独立可核）；3.124–3.126 由 3.121–3.123 取 a = b = c 直接得出，且与表 3.7 立方体行（S/a² = 6、V/a³ = 1、d = a√3）一致（[[findings/表3-7五种正多面体数据]]）。
