# 式 19.110–19.113 收敛性与相容性转录

**转录**（源文逐字保留）：

```latex
(19.110)  y_{i+1} = y_i + h F(x_i, y_i, h)   (i = 0,1,2,\dots; y_0 给定)
(19.111)  g(x,h) = y(x,h) - y(x) = O(h^p)
(19.112)  l(x,h) = \frac{y(x+h) - y(x)}{h} - F(x,y,h) = O(h^p)
(19.113)  \lim_{h\to 0} F(x,y,h) = f(x,y)
```

**评注**：

- F(x,y,h) 称为单步法的增长函数或顺向函数；y(x,h) 为依赖步长的近似解；g 为整体离散误差，l 为局部离散误差。
- 若 p 是满足 (19.111)/(19.112) 的最大自然数，分别称 p 阶收敛 / p 阶相容；(19.112) 直接给出相容方法的极限性质 (19.113)。
- 阶的归属（源文结论）：欧拉法 (19.97) 一阶收敛、一阶相容；龙格—库塔法 (19.99) 四阶收敛、四阶相容。
- 收敛性表述：h→0（h = (x−x₀)/n）时，对初值问题区域内每一 x，y(x,h) 收敛到 y(x)。
- 观察（本维基注）：本节并列收敛、相容、稳定三性质，但未陈述“相容+稳定 ⟹ 收敛”的等价定理；“阶”一词与 19.1 迭代收敛阶同名不同义，见 [[comparisons/迭代收敛阶与步长收敛阶辨析]]。

本条为定义与结论的转录比对，未做数值复算。见 [[concepts/整体离散误差与收敛性]]、[[concepts/局部离散误差与相容性]]。
