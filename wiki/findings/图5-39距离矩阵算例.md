# 图 5.39 距离矩阵算例（对称性与三角不等式已复算）

《数学手册》5.8.2.1 图 5.39 给出一个加权图及其距离矩阵 $\boldsymbol{D}$（式编号标签转录残缺为「(•6)」）。矩阵原始数据（逐字转录）：

```text
D = [ 0  2  3  5  6  ∞]
    [ 2  0  1  3  4  ∞]
    [ 3  1  0  2  3  ∞]
    [ 5  3  2  0  1  ∞]
    [ 6  4  3  1  0  ∞]
    [ ∞  ∞  ∞  ∞  ∞  0]
```

## 复算结论（直接证据）

- **对称性**成立（$d_{ij} = d_{ji}$）；
- **对角为零**成立；
- 抽验**三角不等式**全部成立；
- 第 6 行/列除对角外全为 $\infty$：顶点 6 是**孤立点**。

## 进一步推断

- $\boldsymbol{D}$ 与「五顶点路 $1\!-\!2\!-\!3\!-\!4\!-\!5$，边权依次为 $2, 1, 2, 1$，外加孤立点 6」的加权图完全相容（所有点对距离均按路上权之和给出，无更短路）；
- 该 $\boldsymbol{D}$ **无法**由 6 顶点的单位权图实现：$d(1,2)=2$ 需要一个与 1、2 均相邻的中间顶点 $k$（即 $d(1,k)=1$），但对每个候选（$k=3,4,5$ 时 $d(1,k) \neq 1$；$k=6$ 时 $d(1,6)=\infty$）均不成立——故原图必为非单位权的加权图。

## 证据强度

矩阵内部自洽性已复算（replicated: true）；但原图的边权无法从转录文本读出，距离数值与图形的对应关系未经图片核对，故整体 confidence: medium。单位权情形的对照算例见 [[findings/图5-40邻接矩阵幂算例]]。
