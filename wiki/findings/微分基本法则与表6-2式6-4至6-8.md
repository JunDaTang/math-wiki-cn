# 微分基本法则与表 6.2 汇总（式 6.4–6.8，逐字转录与复算）

**断言**：《数学手册（原书第10版）》6.1.2.2 给出一元函数微分基本法则（式 6.4–6.8），并以表 6.2（14 行）汇总全节法则。设 u, v, w, y 为 x 的函数，$u', v', w', y'$ 为关于 x 的导数，微分为 du, dv, dw, dy。

## 编号公式（逐字转录）

- (6.4) $c' = 0$
- (6.5) $(cu)' = cu'$，$\mathrm{d}(cu) = c\,\mathrm{d}u$
- (6.6a) $(u+v-w)' = u'+v'-w'$
- (6.6b) $\mathrm{d}(u+v-w) = \mathrm{d}u+\mathrm{d}v-\mathrm{d}w$
- (6.7a) $(uv)' = u'v+uv'$，$\mathrm{d}(uv) = v\,\mathrm{d}u+u\,\mathrm{d}v$
- (6.7b) $(uvw)' = u'vw+uv'w+uvw'$，$\mathrm{d}(uvw) = vw\,\mathrm{d}u+uw\,\mathrm{d}v+uv\,\mathrm{d}w$
- (6.7c) $(u_1u_2\cdots u_n)' = \sum_{i=1}^{n} u_1u_2\cdots u_i'\cdots u_n$
- (6.8) $\left(\frac{u}{v}\right)' = \frac{vu'-uv'}{v^2}$，$\mathrm{d}\left(\frac{u}{v}\right) = \frac{v\,\mathrm{d}u-u\,\mathrm{d}v}{v^2}$

## 表 6.2（逐字转录，14 行）

| 表达式 | 求导数公式 |
|---|---|
| 常函数 | $c' = 0$（c 为常数） |
| 常数倍 | $(cu)' = cu'$（c 为常数） |
| 和 | $(u \pm v)' = u' \pm v'$ |
| 两函数乘积 | $(uv)' = u'v + uv'$ |
| n 个函数的乘积 | $(u_1 u_2 \cdots u_n)' = \sum_{i=1}^{n} u_1 \cdots u'_i \cdots u_n$ |
| 商 | $\left(\frac{u}{v}\right)' = \frac{vu' - uv'}{v^2}\ (v \neq 0)$ |
| 两函数的链式法则 | $y = u(v(x)):\ y' = \frac{\mathrm{d}u}{\mathrm{d}v}\frac{\mathrm{d}v}{\mathrm{d}x}$ |
| 三个函数的链式法则 | $y = u(v(w(x))):\ y' = \frac{\mathrm{d}u}{\mathrm{d}v}\frac{\mathrm{d}v}{\mathrm{d}w}\frac{\mathrm{d}w}{\mathrm{d}x}$ |
| 幂 | $(u^\alpha)' = \alpha u^{\alpha-1}u'\ (\alpha \in \mathbb{R}, \alpha \neq 0)$；特别地 $\left(\frac{1}{u}\right)' = -\frac{u'}{u^2}\ (u \neq 0)$ |
| 对数微分 | $\frac{\mathrm{d}(\ln y(x))}{\mathrm{d}x} = \frac{1}{y}y' \Rightarrow y' = y\frac{\mathrm{d}(\ln y)}{\mathrm{d}x}$；特别地 $(u^v)' = u^v\left(v'\ln u + \frac{vu'}{u}\right)\ (u > 0)$ |
| 反函数可微 | 设 φ 为 f 的反函数，即 $y = f(x) \Leftrightarrow x = \varphi(y)$：$f'(x) = \frac{1}{\varphi'(y)}$ 或 $\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{1}{\mathrm{d}x/\mathrm{d}y}$ |
| 隐函数微分 | $F(x,y) = 0:\ F_x + F_y y' = 0$ 或 $y' = -\frac{F_x}{F_y}\ (F_y \neq 0)$ |
| 参数形式函数可微 | $x = x(t), y = y(t)$：$y' = \frac{\dot{y}}{\dot{x}}$ |
| 极坐标形式函数可微 | $\rho = \rho(\varphi):\ y' = \frac{\dot{\rho}\sin\varphi + \rho\cos\varphi}{\dot{\rho}\cos\varphi - \rho\sin\varphi}$ |

## 复算结论

式 6.4–6.8 及其微分形式全部复算无误；tan x 经商法则的推导（$y' = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{1}{\cos^2 x}$）复算无误。表 6.2 中幂法则限定 α≠0 为保守条件（α=0 时公式在 u≠0 处亦给出 0），非矛盾。

## 附带注记（手册原文强调）

“和的导数”“乘积的导数”“链式法则”三处均注明：可能每个被加式/每项因子/内外函数都不可微，但其和/乘积/复合函数可微，此时导数必须用定义中的公式 (6.1) 来计算——即各法则为充分条件而非必要条件（见 [[微分法则]]）。

## 证据类型

直接证据（逐字转录）+ 独立复算（按导数定义与代数恒等式验证）。
