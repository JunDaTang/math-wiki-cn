# 式 12.78–12.86 范数公理与诱导距离转录复算

## 转录内容

N1 正定性（12.78）、N2 齐次性（12.79）、N3 三角不等式（12.80）三条公理；诱导距离 ρ(x,y) = ‖x−y‖（12.81）及其平移不变性（12.82a）与正齐次性（12.82b）；单位球（12.83）与球生成公式 B(x;r) = x + rB(0;1)（12.84）；代数运算与范数的连续性（12.85）；收敛的范数刻画 ‖xₙ−x‖ → 0（12.86，回指未入库的 (12.53)）。

## 复算（编者直接推导，经典内容）

- ρ 确为距离：非负性与零点条件由 N1；对称性由 N2 取 α = −1；三角不等式由 N3 直接得到。✔
- 12.82a：ρ(x+z, y+z) = ‖x+z−y−z‖ = ‖x−y‖ ✔；12.82b：ρ(αx, αy) = |α|‖x−y‖ ✔。
- 12.84：{y : ‖y−x‖ < r} = {x + rz : ‖z‖ < 1} = x + rB(0;1) ✔。
- 12.85：加法与数乘的连续性以及范数的连续性（|‖xₙ‖−‖x‖| ≤ ‖xₙ−x‖，由 N3 与反向三角不等式）均为标准结果 ✔。

## 发现的讹误

1. N2、N3 的括注为乱码（「F̊F̊Ẽ」「≡##FT→T̄」），据公理内容推断应分别为「齐次性」「三角不等式」。
2. 12.3.1.2 中「可赋范的（即范数可以由距离引入，‖x−y‖ = ρ(x,0)）」：疑应为 **‖x‖ = ρ(x,0)**（用距离在零点处的值定义范数）。
3. 式 12.86 回指的 (12.53) 位于未入库的 12.2。
4. 「欧儿里得」「对千」「收敛千」等系统性 OCR 错字贯穿全节（应为「欧几里得」「对于」「收敛于」）。

## 置信度与复算状态

公理与推导均为可直接复核的经典内容，置信度高；乱码括注的还原为合理推断，需对照原书 PDF 确认。尚无第二来源独立复算。
