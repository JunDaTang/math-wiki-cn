# x·sin(1/x) 连续不可导算例（图 6.2(b)）

手册 6.1.1 算例 B：x·sin(1/x) 补充定义 f(0)=0 后在原点连续，但差商极限不存在——手册内「连续不蕴含可微」的直接反例。

## 逐字转录

```latex
% 例 B（连续但差商极限不存在）
f(x) = x\sin\frac{1}{x}\ (x \neq 0),\quad 补充定义 f(0)=0
```

原文表述：在点 x=0 处函数无定义，但极限为 0，因此写成 f(0)=0；然而 x=0 处极限 (6.1) 不存在（图 6.2(b)）。

## 复算（已验证）

- 连续性：|x·sin(1/x)| ≤ |x| → 0（夹逼），故 lim_{x→0} f(x)=0，补充定义 f(0)=0 后连续；
- 差商：[f(0+h)−f(0)]/h = sin(1/h)，当 h→0 时无极限，故导数不存在。

## 归属与边界

- 本算例属「连续但无切线」情形（差商极限不存在），区别于例 A 的垂直切线与例 C 的尖点；「连续⇏可微」的总结性比较见 [[可微与连续关系比较]]。
- 手册本节未对该函数给出导函数公式。
