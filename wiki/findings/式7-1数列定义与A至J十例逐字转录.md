# 式7-1数列定义与A至J十例逐字转录

**定义（式 7.1，逐字）**：按一定顺序排列的无穷多个数

a₁, a₂, …, aₙ, …　或简记为　{aₙ}, n = 1, 2, …

称为无穷数列（以后简称数列）。数列中的数称为数列的项，在数列的项中，相同的数可多次出现。若按一定的形式法则即已知规则定义一个数列，则该数列中的每一项能唯一确定。通常存在通项 aₙ 的公式。

**数列举例（逐字，含损坏处标注）**：

```text
A: aₙ = n:                     1, 2, 3, 4, 5, …
B: aₙ = 4 + 3(n − 1):          4, 7, 10, 13, 16, …
C: aₙ = 3(−1/2)ⁿ⁻¹:            3, −3/2, 3/4, −3/8, 3/16, …   （源文 "C: :" 双冒号为衍文）
D: aₙ = (−1)ⁿ⁺¹:               1, −1, 1, −1, 1, …
E: aₙ = 3 − 1/2ⁿ⁻²:            1, 2, 2½, 2¾, 2⅞, …   (2¾ = 11/4)
F: n 为奇数: aₙ = 3⅓ − (1/3)·10^(−(n−1)/2)
   n 为偶数: aₙ = 3⅓ + (2/3)·10^(−n/2 + 1)
   aₙ: 3; 4; 3.3; 3.4; 3.33; 3.34; 3.333; 3.334; …
G: aₙ = 1/n:                   1, ½, ⅓, ¼, ⅕, …
H: aₙ = (−1)ⁿ⁺¹ n:             1, −2, 3, −4, 5, −6, …
I: n 为奇数: aₙ = −(n + 1)/2（源文「为奇数」前脱漏 n）
   n 为偶数: aₙ = 0
   aₙ: −1, 0, −2, 0, −3, 0, −4, 0, …
J: n 为奇数: aₙ = 3 − 1/2^(n/2 − 3/2)
   n 为偶数: aₙ = 13 − 1/2^(n/2 − 2)
   印值行（源文严重损坏，逐字）:
   "<sup>1</sup>\~,<sub>2</sub> 1 3 3 an: 1, 11, 2, 12, 2 12 2 12 2 4 4'"
```

## 复算

十例公式逐项代入复算，全部自洽：

- A–I 的印值与通项公式逐项一致；E 的括注 (2¾ = 11/4) 复算无误。
- F、I、J 为按奇偶分段的通项：同一规则唯一确定每一项，印证定义中「每一项能唯一确定」的陈述。
- J 的印值行损坏，但存留前缀「1, 11, 2, 12」与公式复算值完全一致；完整复原假说为 1, 11, 2, 12, 2½, 12½, 2¾, 12¾, …（奇子列 → 3，偶子列 → 13），见 [[queries/例J数列值转写损坏如何复原]]。

## 意义

A–J 十例是全节反复回引的判定素材（单调性、有界性、收敛、发散各小节均以此为例），构成本 wiki 可跨页复用的 fixture 集；后续 finding 页（[[findings/式7-2至7-3单调数列定义与分类复算]]、[[findings/式7-4有界数列定义与K值复算]]、[[findings/式7-5至7-7极限定义与真假发散判定]]）的分类均为对该 fixture 的逐例复算。
