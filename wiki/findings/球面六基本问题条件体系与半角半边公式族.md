# 球面六基本问题的存在条件体系与半角/半边公式族（含检验恒等式）

## 存在条件（直接证据）

- 第一基本问题（SSS）：0° < a+b+c < 360°，a+b > c，a+c > b，b+c > a。
- 第二基本问题（WWW）：180° < α+β+γ < 540°，α+β < 180°+γ，α+γ < 180°+β，β+γ < 180°+α。
- 第三（SWS）、第四（WSW）：无条件。
- 第五（SSW）、第六（WWS）：分情况（见 [[findings/SSW与WWS歧义分支]]），两组条件互为（极）对偶。

注意：SSS 条件恰是三面角面角和定理的条件（[[findings/多面角全等对称与面角和]]），印证球面三角形与三面角的对偶。

## 半角/半边公式族

```
第一问题（SSS），s = (a+b+c)/2：
k  = √[sin(s−a)sin(s−b)sin(s−c)/sin s]
tan(α/2) = k/sin(s−a)   （β、γ 同理）
检验：(s−a)+(s−b)+(s−c) = s；  tan(α/2)tan(β/2)tan(γ/2)·sin s = k

第二问题（WWW），σ = (α+β+γ)/2：
k′ = √[cos(σ−α)cos(σ−β)cos(σ−γ)/(−cos σ)]   【转写作减号；除法形式经四面体算例裁决】
cot(a/2) = k′/cos(σ−α)   （b、c 同理）
检验：(σ−α)+(σ−β)+(σ−γ) = σ；  cot(a/2)cot(b/2)cot(c/2)·(−cos σ) = k′
```

k′ 的分数线脱落问题见 [[queries/表3-9中k撇公式的分数线是否在转写中脱落]]（已由 [[findings/四面体棱间夹角算例]] 数值裁决）；其数值应用见该算例页。

## 纳皮尔类比与辅助角法（结构证据）

第三/四问题（SWS/WSW）的解 3 与第五/六问题的方法 2 使用半和半差（纳皮尔类比）公式，例如第三问题解 3：tan((α+β)/2) = [cos((a−b)/2)/cos((a+b)/2)]·cot(γ/2)，tan((α−β)/2) = [sin((a−b)/2)/sin((a+b)/2)]·cot(γ/2)，随后 α、β 由和差合成。辅助角法（第三问题解 2 的 u、第四问题解 2 的 μ、第五/六问题方法 1 的 u, v, φ, ψ）给出另一条路径。转写损坏的表 3.10 解 4 与表 3.12 方法 2 见 [[queries/表3-10解4与表3-12方法2的错乱是否需据原书核定]]，损坏文本不在此记为公式结论。

## 验证状态

两个检验恒等式（tan(α/2)tan(β/2)tan(γ/2)·sin s = k 与 cot(a/2)cot(b/2)cot(c/2)·(−cos σ) = k′）经本 wiki 独立代数核验成立；k′ 数值形式经四面体算例复算验证。与平面四个基本问题的对照见 [[comparisons/平面与球面三角形基本问题比较]]。
