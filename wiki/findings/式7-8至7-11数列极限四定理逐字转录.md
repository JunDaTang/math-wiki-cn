# 式 7.8–7.11 数列极限四定理逐字转录

本 finding 逐字转录 7.1.2.4「数列极限的定理」全条：a) 四则运算法则（式 7.8–7.10 及「有界 × 无穷小」注记）、b) 夹逼定理（式 7.11）、c) 单调有界收敛定理。四条均为标准实分析定理，复算无误。

## 逐字转录（已清理「等千→等于」、多余「｝」、式 7.11 的「\~」讹误等）

```text
4. 数列极限的定理

a) 若数列 {aₙ} 与 {bₙ} 均收敛，则
    lim (aₙ + bₙ) = lim aₙ + lim bₙ                  (7.8)
    lim (aₙ·bₙ)  = (lim aₙ)·(lim bₙ)                (7.9)
若对每个 n，bₙ ≠ 0，且 lim bₙ ≠ 0，则
    lim (aₙ/bₙ) = lim aₙ / lim bₙ                    (7.10)
注：若 lim bₙ = 0，{aₙ} 有界，即使 {aₙ} 没有有限极限，仍有
    lim (aₙ·bₙ) = 0。

b) lim aₙ = lim bₙ = A，且至少从一个指标 n₁ 之后，恒有不等式
    aₙ ⩽ cₙ ⩽ bₙ，
则有
    lim cₙ = A                                      (7.11)

c) 单调有界数列有有限极限。若单调递增数列 a₁ ⩽ a₂ ⩽ a₃ ⩽ ⋯ 有上界，
即对所有 n，aₙ ⩽ K₁，则该数列收敛，且极限等于最小上界，即所有可能 K₁
的最小值。若单调递减数列 a₁ ⩾ a₂ ⩾ a₃ ⩾ ⋯ 有下界，即对所有 n，
aₙ ⩾ K₂，则该数列收敛，且极限等于最大下界，即所有可能的 K₂ 的最大值。
```

## 转写噪音登记

- 式 7.11 假设中第二个 ⩽ 在源文讹为「\~」（「aₙ ⩽ cₙ \~ bₙ」），据夹逼定理标准形式复原为 aₙ ⩽ cₙ ⩽ bₙ。
- 定理 a) 与注中四处多余全角花括号「｝」（如「{aₙ} ｝与 {bₙ} ｝均收敛」）。
- 「等千」→「等于」两处。
- 其余见 [[queries/7-1全节系统性转写讹误清单]]。

## 内容核验与交叉联系

- a) 的条件结构（商法则双条件、有界 × 无穷小注记）详见 [[concepts/数列极限四则运算法则]]。
- b) 即夹逼定理（数列版）的原始出处，见 [[concepts/夹逼定理]]。
- c) 的「最小上界 / 最大下界」即上确界 / 下确界的可操作刻画（「所有可能 K₁ 的最小值」），见 [[concepts/单调有界收敛定理]] 与 [[concepts/上确界与下确界]]；其例证为数列 E（递增收敛于最小上界 3）与 G（递减收敛于最大下界 0），见 [[findings/数列A至J十例性质分类复算与脱漏字母重构]]。
- 注意 c) 中界用非严格不等号（aₙ ⩽ K₁、aₙ ⩾ K₂），与式 7.4 的严格不等号形成对照——见 [[queries/式7-4严格不等号与界K原值问题]]。
