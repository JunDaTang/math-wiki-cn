# 等额年金知三求一且还款额有下界

等额年金公式 (1.84) 中四个量 A（年金）、S（债务）、q（累积因子）、N（利息周期数）构成封闭关系，知道任意三个即可解出第四个——手册明示这是解决商业数学问题的方法论要点。同时由 (1.83) $A = a\left[m+\frac{(m-1)p}{200}\right]$ 可推出 $A \geqslant ma$（每周期还款 m 次、每次 a；因 $\frac{(m-1)p}{200} \geqslant 0$）。

## 证据

手册 1.3.3.3 两例（均经独立复算一致）：

- 例 A：贷款 €60000、8%、5 年 → $A = 60000\cdot\frac{0.08}{1-1.08^{-5}} = €15027.39$，$a = \frac{15027.39}{12+0.44} = €1207.99$；
- 例 B：贷款 €100000、7.5%、8 年、每年末额外还款 €5000 → $A = €17072.70$，$a = \frac{17072.70-5000}{12+0.4125} = €972.62$。

## 归属限定

"A ≥ ma" 与"知三求一"仅属于等额年金语境（(1.83)、(1.84)），不可转述到[[等额本金还款]]等其他还款模式。概念背景见 [[等额年金]]、[[分期付款]]。
