# 倍角公式体系与棣莫弗–二项式通式（式 2.96–2.109）

## 手册主张（2.7.2.3）

$$\sin 2\alpha = 2\sin\alpha\cos\alpha \tag{2.96}$$
$$\sin 3\alpha = 3\sin\alpha - 4\sin^3\alpha \tag{2.97}$$
$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha \tag{2.98}$$
$$\cos 3\alpha = 4\cos^3\alpha - 3\cos\alpha \tag{2.99}$$
$$\sin 4\alpha = 8\cos^3\alpha\sin\alpha - 4\cos\alpha\sin\alpha \tag{2.100}$$
$$\cos 4\alpha = 8\cos^4\alpha - 8\cos^2\alpha + 1 \tag{2.101}$$
$$\tan 2\alpha = \frac{2\tan\alpha}{1-\tan^2\alpha},\qquad \tan 3\alpha = \frac{3\tan\alpha-\tan^3\alpha}{1-3\tan^2\alpha},\qquad \tan 4\alpha = \frac{4\tan\alpha-4\tan^3\alpha}{1-6\tan^2\alpha+\tan^4\alpha} \tag{2.102--2.104}$$
$$\cot 2\alpha = \frac{\cot^2\alpha-1}{2\cot\alpha},\qquad \cot 3\alpha = \frac{\cot^3\alpha-3\cot\alpha}{3\cot^2\alpha-1},\qquad \cot 4\alpha = \frac{\cot^4\alpha-6\cot^2\alpha+1}{4\cot^3\alpha-4\cot\alpha} \tag{2.105--2.107}$$

当 n 较大时，利用棣莫弗公式（第 48 页 1.5.3.5，未导入）与二项式定理（第 14 页 1.1.6.4，未导入）：

$$\cos n\alpha + \mathrm{i}\sin n\alpha = \sum_{k=0}^{n}\binom{n}{k}\mathrm{i}^k\cos^{n-k}\alpha\sin^k\alpha = (\cos\alpha + \mathrm{i}\sin\alpha)^n \tag{2.108}$$

（右端逐项展开为 $\cos^n\alpha + \mathrm{i}n\cos^{n-1}\alpha\sin\alpha - \binom{n}{2}\cos^{n-2}\alpha\sin^2\alpha - \mathrm{i}\binom{n}{3}\cos^{n-3}\alpha\sin^3\alpha + \cdots$），由此得到

$$\cos n\alpha = \cos^n\alpha - \binom{n}{2}\cos^{n-2}\alpha\sin^2\alpha + \binom{n}{4}\cos^{n-4}\alpha\sin^4\alpha - \cdots$$
$$\sin n\alpha = n\cos^{n-1}\alpha\sin\alpha - \binom{n}{3}\cos^{n-3}\alpha\sin^3\alpha + \binom{n}{5}\cos^{n-5}\alpha\sin^5\alpha - \cdots \tag{2.109}$$

## 转写疑点

式 2.109 之后出现孤立的空编号「(2.110)」，其后直接进入半角小节，见 [[queries/式2-110空编号是否为转写残留]]。
