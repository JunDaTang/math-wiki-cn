# 式 15.149–15.153 矩阶小波变换与哈尔算例转录复算

**范围**：矩 (15.149)、阶的定义、基函数族 (15.150)–(15.151)、小波变换及其逆 (15.152a/b)、哈尔算例 (15.153)。

## 复算

1. **哈尔定阶**：μ₀ = 0；μ₁ = ∫₀^{1/2} t dt − ∫_{1/2}^1 t dt = 1/8 − 3/8 = −1/4 ≠ 0 ⟹ n = 1，与源文「对于哈尔小波 (15.144), n = 1」一致。✓
2. **墨西哥草帽定阶**：偶函数 ⟹ μ₁ = 0；μ₂ = ∫ t²(1−t²)e^{−t²/2} dt = √(2π)·1 − √(2π)·3 = −2√(2π) ≠ 0 ⟹ n = 2，与源文一致。✓
3. **(15.150)/(15.151) 保范**：换元 u = t/a（及平移），$\int \frac{1}{|a|}|\psi(t/a)|^2\,\mathrm{d}t = \int |\psi(u)|^2\,\mathrm{d}u$，故 $\|\psi_{a,b}\|_2 = \|\psi\|_2$。✓
4. **(15.152a) 两表达式等价**：代入 $\psi_{a,b}(t) = |a|^{-1/2}\psi((t-b)/a)$ 即得第二等号。✓
5. **(15.153) 第二等号**：a > 0 时 $\tfrac{\sqrt{|a|}}{2}\cdot\tfrac{2}{a} = \tfrac{1}{\sqrt{|a|}}$，与第一式系数一致；哈尔基函数在 [b, b+a/2] 取 +1、[b+a/2, b+a] 取 −1 的代入亦直接验证。✓（a < 0 时符号需调整，源文未论及。）
6. **(15.153) 解释句**：「在长度为 |a|/2、在 点处连接的两个相邻区间」——脱字应为 b；两区间 [b, b+a/2] 与 [b+a/2, b+a] 实际衔接于 b+a/2 而非 b。△

## 存疑

- (15.152b) 中 𝓛_ψ f 的宗量排作 t，应为 (a,b)；常数 c 在正逆两式双重出现，见 [[queries/式15-152常数c双重出现一致性之辨]]。
- (15.150) 后「在 |a|>0 的情况下初始函数 ψ(t) 可压缩」疑应为 |a|<1，见 [[queries/式15-150压缩条件疑为绝对值a小于1]]。

## 结论

矩–阶断言、保范性与哈尔算例经独立复算全部成立；逆变换式 (15.152b) 的宗量与常数约定存在转写疑点，不影响 (15.152a)/(15.153) 的正确性。
