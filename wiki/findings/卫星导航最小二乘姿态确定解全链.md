# 卫星导航最小二乘姿态确定解全链（式 4.153–4.165）

**发现**：《数学手册（原书第10版）》4.4.3.4 给出完整的四元数最小二乘姿态确定推导：恒星视为无穷远 ⇒ 两坐标系对恒星方向的相对旋转由单位四元数 h 刻画；测量带误差时极小化 Q²，临界点经李群切向导数与叉乘矩阵恒等式化为矩阵方程 RP = PᵀRᵀ，由极分解 P = R_pᵀS 解出，极小解按 det P 的符号选取。全链经分析者独立复核自洽。

## 公式链（照录；转写脱落的符号已按上下文复原）

```latex
b⃗ᵢ = h a⃗ᵢ h̄                                                            (4.153)

Q² = Σᵢ |b⃗ᵢ − h a⃗ᵢ h̄|² = Σᵢ (2 − b̲ᵢ h āᵢ h̄ − h a̲ᵢ h̄ b̄ᵢ)                 (4.154)

∂_v h = lim_{θ→0} (e^{θv} h − h)/θ = v h     (v 为四元数, θ 为实数)        (4.155)

∂_v Q² = −Σᵢ ( b̲ᵢ v̲ h āᵢ h̄ + b̲ᵢ h āᵢ (vh)‾ + v̲ h a̲ᵢ h̄ b̄ᵢ + h a̲ᵢ (vh)‾ b̄ᵢ ) = 0
                                                                        (4.156)

∂_v̲ Q² = −4 v̲ · ( Σᵢ h a⃗ᵢ h̄ × b̲ᵢ ) = 0                                  (4.157)

Σᵢ h a⃗ᵢ h̄ × b̲ᵢ = 0                                                       (4.158)

K(a⃗) = [  0   −a_z  a_y ]
        [ a_z   0   −a_x ]
        [−a_y  a_x   0  ]                                                  (4.159)

K(a⃗) b⃗ = a⃗ × b⃗,    K(K(a⃗) b⃗) = b⃗ a⃗ᵀ − a⃗ b⃗ᵀ                            (4.160)

Σᵢ K(R a⃗ᵢ × b⃗ᵢ) = O ⇔ Σᵢ (b⃗ᵢ a⃗ᵢᵀ Rᵀ − R a⃗ᵢ b⃗ᵢᵀ) = O
                  ⇔ R P = Pᵀ Rᵀ,      P = Σᵢ a⃗ᵢ b⃗ᵢᵀ                       (4.161)

P = R_pᵀ S  (S 对称, R_p 旋转矩阵)  ⟹  R R_pᵀ S = S R_p Rᵀ                 (4.162)

R = R_p                                                                  (4.163)

R = R_j R_p   (j = 1,2,3),   R_j S R_j = S  (绕 S 的第 j 个特征向量旋转 π)   (4.164)

R = R_p          若 det P > 0
R = R_{j₀} R_p   若 det P < 0    (j₀: S 的绝对值最小特征值对应的特征向量)    (4.165)
```

## 复核结论

- (4.154)：展开式成立（单位向量模平方与四元数共轭展开）。
- (4.155)–(4.158)：ℍ₁ 的切向导数 ∂_v h = vh；利用 v̲、b̲ᵢ、h a̲ᵢ h̄ 均为纯四元数（共轭取负）把 (4.156) 化简为 (4.157)；v̲ 任意 ⟹ (4.158)。
- (4.160)：即恒等式 [a⃗×b⃗]× = b⃗a⃗ᵀ − a⃗b⃗ᵀ，成立。
- (4.161)：两次等价转换成立。
- (4.162)–(4.164)：R = R_p 是解（由 R_pR_pᵀ = E）；R_jR_p 满足方程的验证链 R_jR_pR_pᵀS = SR_pR_pᵀR_jᵀ ⇔ R_jS = SR_jᵀ ⇔ R_jSR_j = S 成立。
- (4.165)：极小解按 det P 符号选取；书中未讨论 det P = 0 的退化情形。

## 外部对应（分析者识别，书未命名）

该问题即正交 Procrustes / Wahba 问题的姿态确定形式；上述解法是标准的极分解（SVD 型）解法。书中未使用这些名称、未给数值例。
