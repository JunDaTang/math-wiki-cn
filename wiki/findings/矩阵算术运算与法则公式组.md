# 矩阵算术运算与法则公式组（式 4.20–4.40）

本节算术运算（4.1.4）与运算法则（4.1.5）的完整公式组，全部复核无误；四组数值算例已复算通过。

## 运算定义

- **相等**（4.20）：大小相同且对应元素相等。
- **加减**（4.21a）：$A\pm B=(a_{\mu\nu}\pm b_{\mu\nu})$，仅当大小相同才可施行；交换律（4.21b）、结合律（4.21c）成立。
- **数乘**（4.22a）：$\alpha A=(\alpha a_{\mu\nu})$；交换、结合、分配律（4.22b–d）成立，可提出元素共有的常数因子。除以标量即乘 $\alpha=1/\gamma$（$\gamma\ne0$）。
- **乘积**（4.23）：$AB=(\sum_{\nu=1}^n a_{\mu\nu}b_{\nu\lambda})=(c_{\mu\lambda})$（$\mu=1,\dots,m$；$\lambda=1,\dots,p$）；仅当左因子列数等于右因子行数时可行，$(m,n)\times(n,p)\to(m,p)$。一般 $AB\ne BA$（交换律不成立）；$AB=BA$ 时称矩阵**可换**（互相交换）。

## 法尔克格式乘法

$AB=C$ 可借助 [[concepts/法尔克图式]] 实现（图 4.1 一般布局，图 4.2 为 $A_{(3,3)}\times B_{(3,2)}$ 实例）：积矩阵元素 $c_{\mu\nu}$ 恰好出现在 $A$ 的第 $\mu$ 行与 $B$ 的第 $\nu$ 列的交点（原书「的第入列」为 λ→入 转写讹误）。

## 运算法则（4.33–4.40）

- $AI=IA=A$（4.33、4.34b；左右 $I$ 大小可不同，非交换性仍一般成立）。
- $AS=SA=cA$（4.34a，$S=cI$ 标量矩阵）。
- $A\mathbf 0=\mathbf 0A=\mathbf 0$（4.35）；**逆命题不成立**：由 $AB=\mathbf 0$ 推不出 $A=\mathbf 0$ 或 $B=\mathbf 0$。
- **零因子**（4.36）：两个非零矩阵之积可以是零矩阵——无消去律（算例见下）。
- 结合律 $(AB)C=A(BC)$（4.37）。
- 转置法则（4.38a）：$(A+B)^{\mathrm T}=A^{\mathrm T}+B^{\mathrm T}$，$(AB)^{\mathrm T}=B^{\mathrm T}A^{\mathrm T}$，$(A^{\mathrm T})^{\mathrm T}=A$；对可逆方阵 $(A^{\mathrm T})^{-1}=(A^{-1})^{\mathrm T}$（4.38b）。
- $(AB)^{-1}=B^{-1}A^{-1}$（4.39）。
- 幂（4.40a–d）：$A^p$ 为 $p$ 个因子之积；$A^0=I$（附 $\det A\ne0$ 条件——按惯例方阵 $A^0=I$ 无需此条件，该条件实为负幂一致性而设，轻微过强而非错误）；$A^{-p}=(A^{-1})^p$；$A^{p+q}=A^pA^q$。
- 微分（4.44）：$\mathrm{d}A/\mathrm{d}t=(a'_{\mu\nu}(t))$，逐元素求导。

## 已复算算例

（1）矩阵乘积（4.23 后）：$A=\begin{pmatrix}1&3&7\\2&-1&4\end{pmatrix}$，$B=\begin{pmatrix}3&2\\-5&1\\0&3\end{pmatrix}$，$c_{22}=2\cdot2-1\cdot1+4\cdot3=15$。

（2）数乘（4.22a 后）：$3\begin{pmatrix}1&3&7\\0&-1&4\end{pmatrix}=\begin{pmatrix}3&9&21\\0&-3&12\end{pmatrix}$。

（3）复矩阵恒等式：$(A+\mathrm{i}B)(A-\mathrm{i}B)=A^2+B^2+\mathrm{i}(BA-AB)$（交叉项因不可交换保留）。

（4）零因子（4.36，Falk 布局）：

```text
        1 1
        0 0
  -------------
  0 1  |  0 0
  0 1  |  0 0
```

## 注意

式 (4.23) 前正文称 $c_{\mu\nu}$ 等于「左边因子的第 μ 行与右边因子的第 μ 列」的标量积，与公式的列指标 λ 不符，疑应为「第 λ 列」，见 [[queries/式4-23正文右边因子第μ列是否应为第λ列]]。复矩阵乘法的实虚分解流程见 [[methodology/复矩阵乘法的实虚分解法]]。
