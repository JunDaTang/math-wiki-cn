# 命题演算基本定律组（式 5.8–5.18）

《数学手册(原书第10版)》5.1.1.6 给出命题演算的基本定律，均为逻辑等价式（记法从原书：Ā 代 ¬A、AB 代 A∧B）：

```latex
% (1) 结合律
(A B) C = A (B C),   (A ∨ B) ∨ C = A ∨ (B ∨ C)          % (5.8a/b)
% (2) 交换律
A B = B A,   A ∨ B = B ∨ A                              % (5.9a/b)
% (3) 分配律
(A ∨ B) C = A C ∨ B C,   A B ∨ C = (A ∨ C)(B ∨ C)       % (5.10a/b)
% (4) 吸收律
A (A ∨ B) = A,   A ∨ A B = A                            % (5.11a/b)
% (5) 幂等律
A A = A,   A ∨ A = A                                     % (5.12a/b)
% (6) 排中律（原书标题；5.13a 通常称矛盾律）
A Ā = F,   A ∨ Ā = T                                     % (5.13a/b)
% (7) 德摩根法则
¬(A B) = Ā ∨ B̄,   ¬(A ∨ B) = Ā B̄                        % (5.14a/b)
% (8) 关于 T/F 的定律
A T = A,  A ∨ F = A,  A F = F,  A ∨ T = T,  T̄ = F,  F̄ = T  % (5.15a–f)
% (9) 双重否定
Ā̄ = A                                                    % (5.16)
% 蕴涵与等价的消去
A ⇒ B = Ā ∨ B,   A ⇔ B = A B ∨ Ā B̄                       % (5.17a/b)
% (10) 其他变换
A (Ā ∨ B) = A B,   A ∨ Ā B = A ∨ B                       % (5.18a/b)
(A ∨ C)(B ∨ C̄)(A ∨ B) = (A ∨ C)(B ∨ C̄)                   % (5.18c)
A C ∨ B C̄ ∨ A B = A C ∨ B C̄                              % (5.18d)
```

**注记**：

- (5.13a) AĀ = F 在通行术语中称矛盾律，「排中律」通常专指 (5.13b)；原书两式共用「排中律」标题，疑合并或漏译（[[queries/式5-13a应称矛盾律还是排中律]]）。
- (5.15) 组标题转写作「对于 的定律」，T/F 字母脱落，应为「对于 T 与 F 的定律」。
- (5.18c/d) 即共识律（consensus law），原书未命名。
- (5.17a/b) 由蕴涵与等价的真值表直接得出，用于改述命题公式，是函数完备性论证的关键一步（[[findings/蕴涵与等价的消去恒等式]]）。

**证据与复算**：直接证据为真值表/代数推导；本 wiki 已独立复算 (5.18c/d)（共识律）成立，其余为标准等价式。应用见 [[methodology/命题公式化简流程]]。
