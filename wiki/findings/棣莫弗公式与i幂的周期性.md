# 棣莫弗公式与 i 幂的周期性（式 1.140）

《数学手册》1.5.3.5 给出：

**[[concepts/棣莫弗公式|棣莫弗公式]]**（式 1.140a）：

[ρ(cos φ + i sin φ)]ⁿ = ρⁿ(cos nφ + i sin nφ)

即幂的模是 ρ 的 n 次幂，辐角是 φ 的 n 倍。

**[[concepts/虚数单位|i 幂的周期性]]**（式 1.140b/c）：i² = −1，i³ = −i，i⁴ = +1；一般地 i^{4n+k} = i^k（i 的幂以 4 为周期）。

**动机**：手册指出复数的 n 次幂可用[[concepts/二项式定理|二项式公式]]计算但"非常不便"，出于实际原因经常使用三角形式，即棣莫弗公式。

验证（推断性核验）：以 z = 1 + i√3 = 2 e^{iπ/3} 为例，z² = 4 e^{i2π/3} = 4(cos 2π/3 + i sin 2π/3) = −2 + 2i√3，与代数展开 (1 + i√3)² = 1 + 2i√3 − 3 = −2 + 2i√3 一致。属定义性内容，核算无误。
