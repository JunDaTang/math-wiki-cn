# 正则二元树的顶点数为奇数且有 (n+1)/2 个 1 次顶点（已复推）

手册 5.8.3.1 第 3 部分断言：正则二元树的顶点个数是奇数；具有 n 个顶点的正则（二元）树有 (n+1)/2 个 1 次顶点（次数「1」在转写中脱落，据公式重构）。

## 独立复推

设正则二元树中 1 次、2 次、3 次顶点的个数分别为 n₁、n₂、n₃；按定义 n₂ = 1（见 [[concepts/正则二元树]]）。

- 顶点计数：n = n₁ + n₂ + n₃，树有 n − 1 条边。
- 握手计数：n₁ + 2n₂ + 3n₃ = 2(n − 1) = 2(n₁ + n₂ + n₃ − 1)。

整理得 n₁ = n₃ + 2（1 次顶点恰比 3 次顶点多 2 个）。于是：

- n = n₃ + 2 + 1 + n₃ = 2n₃ + 3，必为**奇数** ✓
- n₁ = n₃ + 2 = (n − 3)/2 + 2 = **(n+1)/2** ✓

两条断言均由标准计数独立推出，成立。

## 直接证据与推断的区分

手册原文为断言式陈述（无推导）；上述推导为入库时的独立复算，与手册结论一致。
