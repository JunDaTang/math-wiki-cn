# 式 9.135–9.141 中心场与球面调和函数转录复算

## 转录

```latex
r=\sqrt{x^2+y^2+z^2},\ \vartheta=\arccos\frac{z}{r},\ \varphi=\arctan\frac{y}{x};\quad
x=r\sin\vartheta\cos\varphi,\ y=r\sin\vartheta\sin\varphi,\ z=r\cos\vartheta                   % 9.135a
\Delta\Psi = \frac{\partial^{2}\Psi}{\partial r^{2}}+\frac{2}{r}\frac{\partial\Psi}{\partial r}
 +\frac{1}{r^{2}}\frac{\partial^{2}\Psi}{\partial\vartheta^{2}}+\frac{\cos\vartheta}{r^{2}\sin\vartheta}\frac{\partial\Psi}{\partial\vartheta}
 +\frac{1}{r^{2}\sin^{2}\vartheta}\frac{\partial^{2}\Psi}{\partial\varphi^{2}}                                                                                 % 9.135b
\frac{1}{r^{2}}\frac{\partial}{\partial r}\Big(r^{2}\frac{\partial\Psi}{\partial r}\Big)
 +\frac{1}{r^{2}\sin^{2}\vartheta}\frac{\partial}{\partial\vartheta}\Big(\sin\vartheta\frac{\partial\Psi}{\partial\vartheta}\Big)   % ⚠ 9.135c
 +\frac{1}{r^{2}\sin^{2}\vartheta}\frac{\partial^{2}\Psi}{\partial\varphi^{2}}+\frac{2m}{\hbar^{2}}[E-V(r)]\Psi=0
\Psi(r,\vartheta,\varphi)=R_l(r)Y_l^{m}(\vartheta,\varphi)                                     % 9.136a
\frac{1}{R_l r^{2}}\frac{d}{dr}\Big(r^{2}\frac{dR_l}{dr}\Big)+\frac{2m}{\hbar^{2}}\Big[E-V(r)-\frac{l(l+1)\hbar^{2}}{2mr^{2}}\Big]=0                          % 9.136d
Y_l^{m}=\Theta(\vartheta)\Phi(\varphi)                                                         % 9.136e
\frac{1}{\varTheta\sin\vartheta}\frac{d}{d\vartheta}\Big(\sin\vartheta\frac{d\varTheta}{d\vartheta}\Big)+l(l+1)-\frac{m^{2}}{\sin^{2}\vartheta}=0              % 9.136g
\frac{d^{2}\varPhi}{d\varphi^{2}}+m^{2}\varPhi=0                                               % 9.136h
u_l(r)=r\,R_l(r),\qquad
\frac{d^{2}u_l}{dr^{2}}+\frac{2m}{\hbar}\Big[E-V(r)-\frac{l(l+1)\hbar^{2}}{2mr^{2}}\Big]u_l=0        % ⚠ 9.137b
V_{\mathrm{eff}}=V(r)+V_l(l),\qquad V_l(r)=V_{\mathrm{rot}}(l)=\frac{l(l+1)\hbar^{2}}{2mr^{2}}                                                                 % 9.137c,d
E_{\mathrm{rot}}=\frac{1}{2}\Theta\vec{\omega}^{2}=\frac{\vec{l}^{2}}{2\Theta}=\frac{\vec{l}^{2}}{2mr^{2}},\quad \Theta=\mu r^{2}                              % 9.137e
\vec{l}^{2}=l(l+1)\hbar^{2},\quad |\vec{l}|=\hbar\sqrt{l(l+1)}                                                                                                 % 9.137f
l=0,1,2,\dots,\ |m|\leqslant l                                                                                                                                  % 9.138a
P_l^{m}(\cos\vartheta)=\frac{(-1)^{m}}{2^{l}l!}(1-\cos^{2}\vartheta)^{m/2}\frac{d^{l+m}(\cos^{2}\vartheta-1)^{l}}{(d\cos\vartheta)^{l+m}}                       % 9.138c
\varTheta_l^{m}=\sqrt{\frac{2l+1}{2}\cdot\frac{(l-m)!}{(l+m)!}}\,P_l^{m}(\cos\vartheta)=N_l^{m}P_l^{m}(\cos\vartheta)                                           % 9.138d
\varPhi_m(\varphi)=\frac{1}{\sqrt{2\pi}}e^{\mathrm{i}m\varphi}\ (m=0,\pm1,\pm2,\dots)                                                                           % 9.139d
Y_l^{m}=\frac{1}{\sqrt{2\pi}}N_l^{m}P_l^{m}(\cos\vartheta)e^{\mathrm{i}m\varphi}                                                                                % 9.140a
Y_l^{m}(\pi-\vartheta,\varphi+\pi)=(-1)^{l}Y_l^{m}(\vartheta,\varphi)                                                                                           % 9.140b
P=(-1)^{l},\qquad P^{2}=1,\ P=\pm1                                                                                                                              % 9.141a,b
```

## 复算与核对

- **9.135a**：球坐标换元关系 ✓。**9.135b**：拉普拉斯算子球坐标展开与标准形式逐项一致 ✓（补充载于 [[concepts/拉普拉斯方程与拉普拉斯算子]] 语境）。
- **9.136 分离链**：9.136a 代入 → 9.136b → 除以 RY 乘 r² → 9.136c；取分离常数 l(l+1) 得 9.136d；角部分再分离得 9.136g/h ✓。
- **9.137a**：u = rR 代换把 (1/r²)d/dr(r²dR/dr) 化为 d²u/dr² ✓。
- **9.137c/d**：离心位势表达式 ✓；与 9.137e 经典转动能类比一致 ✓。
- **9.137f**：l⃗² = l(l+1)ℏ² 与径向方程中的分离常数项自洽 ✓。
- **9.138c**：与含 Condon–Shortley 相因子 (−1)^m 的标准 Rodrigues 公式一致 ✓；**9.138d** 归一化系数与标准一致 ✓；**9.139d**：∫₀^{2π}|Φ|²dφ = 1 ✓。
- **9.140b**（关键独立复算）：P_l^m(−x) = (−1)^{l+m}P_l^m(x)（由 9.138c 直接推出）与 e^{imπ} = (−1)^m 联乘，得 (−1)^{l+m}·(−1)^m = (−1)^l ✓。
- **9.141b**：P² = 1 ⟹ P = ±1 ✓。

## 疑点（均高置信，依据为内部矛盾或量纲分析）

1. **9.135c 第二项分母 r²sin²ϑ 疑应为 r²sinϑ**：与 9.135b 的正确展开及 9.136b 中该项（1/(r²sinϑ)）直接矛盾 → [[queries/式9-135c极角项分母疑误]]。
2. **9.137b 系数 2m/ℏ 疑应为 2m/ℏ²**：量纲分析；9.136d、9.143a 同类项均为 ℏ² → [[queries/式9-137b径向方程系数疑漏ℏ平方]]。
3. **9.138c 前文特殊情形条件「(l=0, m=n)」疑应为 m=0** → [[queries/式9-138c前特殊情形条件疑为m等于0]]。
4. **9.137f |l⃗| 原书误为 |l⃗²|**：源内译者注已证实（原书印刷错误）。
5. 记号：Θ 兼作极角函数与转动惯量；V_l(l)/V_l(r) 不一致；9.137e 中 l⃗ = Θω⃗ 处有「®」杂字符。

## 结论

除上述疑点外全部复算通过；中心场模型的完整结论载于 [[concepts/中心对称场中的粒子运动]]。
