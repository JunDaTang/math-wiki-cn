# 式 14.54a–14.55 留数公式与留数定理算例转录复算

对 14.3.5.4–14.3.5.5 中留数三公式 (14.54a/b/c)、留数定理 (14.55) 及其算例的转录与独立复算。

## 转录内容

```latex
(14.54a) Res f(z)|_{z=z_0} = a_{-1} = (1/2πi) ∮_K f(ζ) dζ
(14.54b) Res f(z)|_{z=z_0} = lim_{z→z_0} [1/(m-1)!]·d^{m-1}/dz^{m-1} [f(z)(z - z_0)^m]
(14.54c) Res [φ(z)/ψ(z)]|_{z=z_0} = φ(z_0)/ψ'(z_0)     （ψ(z_0)=0, ψ'(z_0)≠0）
(14.55)  ∮_C f(z) dz = 2πi Σ_{k=0}^n Res f(z)|_{z=z_k}

【算例】K 为以原点为心、半径 r > 1 的圆周，z_{1,2} = ±i：
∮_K e^z/(z^2+1) dz = 2πi (e^{z_1}/(2z_1) + e^{z_2}/(2z_2))
                   = 2πi (e^i/(2i) - e^{-i}/(2i)) = 2πi sin 1
```

## 独立复算

- **(14.54c) 的推导**：$f = \varphi/\psi$，$\psi(z_0) = 0$、$\psi'(z_0) \neq 0$、$\varphi(z_0) \neq 0$，则 $f(z)(z - z_0) = \frac{\varphi(z)}{\psi(z)/(z-z_0)} \to \frac{\varphi(z_0)}{\psi'(z_0)}$（$z \to z_0$），即 (14.54b) 在 $m = 1$ 的特例。✓ 原书“从 (14.54b) 即得”成立。
- **算例**：$f(z) = e^z/(z^2+1)$，$\psi(z) = z^2 + 1$ 有单根 $z_{1,2} = \pm\mathrm{i}$，$\varphi(\pm\mathrm{i}) = e^{\pm\mathrm{i}} \neq 0$，满足译者注条件。
  - $\operatorname{Res}\big|_{z=\mathrm{i}} = \dfrac{e^{\mathrm{i}}}{2\mathrm{i}}$；
  - $\operatorname{Res}\big|_{z=-\mathrm{i}} = \dfrac{e^{-\mathrm{i}}}{2(-\mathrm{i})} = -\dfrac{e^{-\mathrm{i}}}{2\mathrm{i}}$；
  - 和 $= \dfrac{e^{\mathrm{i}} - e^{-\mathrm{i}}}{2\mathrm{i}} = \sin 1$。✓
- **留数定理**：$K$（$|z| = r > 1$）包围两奇点，$\oint_K \frac{e^z}{z^2+1}\,\mathrm{d}z = 2\pi\mathrm{i}\sin 1$。✓ 与原书一致。

## 结论

复算全部通过，confidence: high，replicated: true。
