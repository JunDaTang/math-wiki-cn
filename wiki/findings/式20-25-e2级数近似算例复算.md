# 式 20.25 e² 级数近似算例复算

**结论**：式 20.25 之输出 7.38899 经独立复算验证**正确**（机器精度 6 位显示）。

## 原文转录

```
In[1] := sum = 1.0;
        Do[sum = sum + (2^i/i!), {i, 1, 10}];
        sum
Out[1] = 7.38899
```

## 复算

程序计算的是 e² 之级数部分和 Σ_{i=0}^{10} 2^i/i!（初值 `1.0` 即 i = 0 项，`Do` 自 i = 1 累加至 10）：

Σ_{i=0}^{10} 2^i/i! = 7.3889947…

6 位显示为 **7.38899**，与 Out[1] 一致。参照 e² = 7.3890561…，截断误差约 6.1×10⁻⁵（弃去的首项为 2^11/11! ≈ 5.13×10⁻⁵，尾项合计约 6.1×10⁻⁵），属级数近似的固有截断而非显示舍入问题。

## 说明

- 该算例为 20.2.9 引入 `Do` 循环的第一个应用（据指数函数级数展开求 e² 近似）；
- 输入输出行记法见 [[concepts/Mathematica输入输出行记法]]；语法转录核对见 [[findings/式20-24与20-26循环与模块语法转录复算]]；
- 本复算为直接证据（数值重算），非仅语义比对。
