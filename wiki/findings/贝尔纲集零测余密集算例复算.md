# 贝尔纲集零测余密集算例复算

**结论**：手册 17.1.4.3 的算例——存在勒贝格测度为零的第二贝尔纲集（余密集）B ⊂ ℝ——复算通过，确认「贝尔纲意义的大」与「测度意义的大」互不蕴含。

## 算例构造（转录）

```
B = ∩_{k=1,2,…} B_k，  B_k = ∪_{n≥0} (a_n − 1/(k·2ⁿ), a_n + 1/(k·2ⁿ))，  ℚ = {a_n}_{n=0}^∞
λ(B) = lim_{k→∞} λ(B_k) ≤ lim_{k→∞} (2/k)·(1/(1−1/2)) = 0
```

（原文「λ(B) = lim B_k」疑脱漏 λ；第二式区间半径为 1/(k·2ⁿ)。）

## 复算过程（直接证据）

1. **B_k 开且稠密**：每个 B_k 是开区间之并（开），且包含 ℚ（稠密）→ B_k 稠密。故 B = ∩B_k 按手册口径为第二贝尔纲集（余密集）。
2. **测度上界**：λ(B_k) ≤ Σ_{n≥0} 2·(1/(k·2ⁿ)) = (2/k)·(1/(1−1/2)) = 4/k。
3. **嵌套与有限测度**：B_k ⊃ B_{k+1}（区间半径随 k 增大而缩小）且 λ(B₁) ≤ 4 < ∞，由测度的从上连续性得 λ(B) = lim_{k→∞} λ(B_k) ≤ lim 4/k = 0。
4. **对照**：ℚ 稠密但第一纲、零测；𝕀 余密集且满测；B 余密集但零测——三种「大/小」组合互不相同，支撑「稠密 ≠ 通有」与「贝尔纲与测度无关」两个论断。
