# 正凸多边形半径边长面积公式（式 3.51–3.54、3.56）

《数学手册(原书第10版)》3.1.5.2 建立正凸 n 边形的「半径—边长—周长—面积」度量体系。推导根基是中心 M、边中点与相邻顶点构成的直角三角形：斜边为 R、一直角边为 r、另一直角边为 aₙ/2，故有勾股关系 R² = r² + aₙ²/4。

```
R = a_n / (2·sin(180°/n)),  R² = r² + a_n²/4                 (3.51)
r = (a_n/2)·cot(180°/n) = R·cos(180°/n)                      (3.52)
a_n = 2√(R² − r²) = 2R·sin(φ_n/2) = 2r·tan(φ_n/2)            (3.53)
U = n·a_n                                                    (3.54)
S_n = (1/2)·n·a_n·r = n·r²·tan(φ_n/2)
    = (1/2)·n·R²·sin φ_n = (1/4)·n·a_n²·cot(φ_n/2)           (3.56)
```

## 四种面积表达的等价性

Sₙ 的四种形式分别以（aₙ, r）、r、R、aₙ 为基准：(1/2)·n·aₙ·r 是 n 个底为 aₙ、高为 r 的三角形面积之和；n·r²·tan(φₙ/2) 按内切圆半径分解每个三角形；(1/2)·n·R²·sin φₙ 用外接圆表示；(1/4)·n·aₙ²·cot(φₙ/2) 纯以边长表示。经换算四种表达互相等价（已独立验证）。

## 复核

以半角公式与中心直角三角形关系独立复核，式 3.51–3.54、3.56 全部自洽。特例检验：六边形 a₆ = 2R·sin(30°) = R；表 3.2 各根式条目（复原读法后）均与本组公式一致（见 [[findings/表3-2五种正多边形根式性质]]）。
