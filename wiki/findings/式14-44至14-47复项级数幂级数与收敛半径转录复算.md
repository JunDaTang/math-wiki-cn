# 式 14.44–14.47 复项级数、幂级数与收敛半径转录复算

对《数学手册(原书第10版)》14.3.1 中公式 (14.44)–(14.47) 的转录，及对相关算例的独立复算。复算与原书结果全部一致，属直接推导证据。

## 转录内容

```latex
(14.44)  s_n = a_1 + a_2 + ... + a_n                     (n = 1, 2, ...)
(14.45)  f_1(z) + f_2(z) + ... + f_n(z) + ...
(14.46a) P(z - z_0) = a_0 + a_1(z - z_0) + a_2(z - z_0)^2 + ... + a_n(z - z_0)^n + ...
(14.46b) P(z) = a_0 + a_1 z + a_2 z^2 + ... + a_n z^n + ...
(14.47)  r = 1 / lim_{n→∞} ⁿ√|a_n|    或    r = lim_{n→∞} |a_n / a_{n+1}|
```

## 独立复算

- **例 A（条件收敛）**：$\sum_{n\ge1} \mathrm{i}^n/n$。各项模 $|\mathrm{i}^n/n| = 1/n$，绝对值级数为调和级数，发散。级数本身：实部 $= \sum_n \cos(n\pi/2)/n = -\frac{1}{2}\ln 2$，虚部 $= \sum_n \sin(n\pi/2)/n = \pi/4$，均为交错收敛，故级数收敛 ⟹ 条件收敛。✓
- **例 B（绝对收敛）**：$\sum_{n\ge1} \mathrm{i}^n/2^{n-1} = 2\sum_{n\ge1}(\mathrm{i}/2)^n$，几何级数，公比模 $1/2 < 1$ ⟹ 绝对收敛。✓
- **根式极限**：$a = |a|e^{\mathrm{i}\varphi}$（$\varphi$ 取最小非负辐角），则最小非负辐角根为 $|a|^{1/n}e^{\mathrm{i}\varphi/n} \to 1\cdot e^0 = 1$。✓
- **$\sum_{n\ge1} z^n/n$ 的收敛半径与边界**：$r = \lim |a_n/a_{n+1}| = \lim\frac{1/n}{1/(n+1)} = 1$。$z=1$：调和级数发散；$z=-1$：交错调和级数收敛（莱布尼茨准则，回指第 621 页 7.2.3.3）；$|z|=1,\ z\neq 1$：部分和 $\sum_{k\le n} z^k$ 有界且 $1/n$ 单调趋零，由 Dirichlet 判别法收敛。与原书“除 $z=1$ 外单位圆上均收敛”一致。✓

## 结论

公式转录与独立复算一致，confidence: high，replicated: true（复算重现原书全部算例结论）。
