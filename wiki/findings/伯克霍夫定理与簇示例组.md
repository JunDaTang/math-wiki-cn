# 伯克霍夫定理与簇示例组

**发现**：5.6 节压轴陈述伯克霍夫定理——由方程式定义的类恰为簇——并给出正反示例组：半群、群、阿贝尔群、环的类是簇；循环群的类与域的类不是簇，故不能由方程定义。

## 直接证据（源文转写）

> 「伯克霍夫定理 由方程式定义的类恰为簇
> • 例如，分别由所有半群、群、阿贝尔群，以及环组成的类都是簇但是，例如循环群的直接积不是循环群，域的直接积不是域因此循环群或域不形成簇，并且不能由方程定义」

（5.6.5 正文中先行预告：「伯克霍夫 (Birkhoff) 定理（参见第 527 5.6.6) 将簇刻画为能够用方程方式定义的 Ω代数组成的类」，页码与节号粘连。）

## 示例组拆分（正反结论分属不同的类，不可互移）

| 类 | 是否簇 | 源文依据 |
|---|---|---|
| 半群的类 | 是 | 直接断言 |
| 群的类 | 是 | 直接断言 |
| 阿贝尔群的类 | 是 | 直接断言 |
| 环的类 | 是 | 直接断言 |
| 循环群的类 | 否 | 循环群的直接积不是循环群 |
| 域的类 | 否 | 域的直接积不是域 |

由伯克霍夫定理，「不是簇」蕴含「不能由方程定义」。

## 背景印证（非源文内容，可独立核实）

- 循环群反例的标准实例：$\mathbb{Z}_2 \times \mathbb{Z}_2$（Klein 四元群）不是循环群——已独立复算核实。
- 域反例的标准论证：两个非平凡域的直接积含零因子（如 $(1,0)\cdot(0,1) = (0,0)$），故不是域——已独立复算核实。
- 定理归属：即经典 HSP 定理，通常归于 Garrett Birkhoff（1935）；源文仅以「伯克霍夫 (Birkhoff)」冠名。

## 置信度

高：定理与示例均为标准结果；源文未给出证明，反例细节为背景印证（一般性断言本身未在源中证明）。
