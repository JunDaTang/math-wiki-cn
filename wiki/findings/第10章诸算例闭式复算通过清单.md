# 第10章诸算例闭式复算通过清单

对第10章除 (10.29b) 一处疑讹外的全部算例作闭式复算（规程见 [[methodology/变分算例闭式复算法]]），**全部通过**：

| 算例 | 内容 | 复算要点 | 结论 |
|---|---|---|---|
| (10.23a–b) | 最短连线 | F = √(1+y′²) = F(y′)，由 (10.21b) 得 y″/(1+y′²)^{3/2} = 0 ⟹ y″ = 0，即直线 | 通过 |
| (10.24a–b) | 旋转面最小面积 | F = 2πy√(1+y′²)，由 (10.22c) 得 2πy/√(1+y′²) = c ⟹ y′² = (y/c₁)² − 1，可分离变量积分解出 y = c₁cosh(x/c₁ + c₂)（悬链线） | 通过 |
| (10.32a–b) | F = y″² − αy′² − βy² | F_y = −2βy、d/dx F_{y′} = −2αy″、d²/dx² F_{y″} = 2y⁽⁴⁾，代入 (10.31) 除以 2 得 y⁽⁴⁾ + αy″ − βy = 0 | 通过 |
| (10.43a–d) | 参数式等周问题 | H = yẋ + λ√(ẋ²+ẏ²)：H_ẋẋ = λẏ²/(ẋ²+ẏ²)^{3/2} ⟹ M = H_ẋẋ/ẏ² = λ/(ẋ²+ẏ²)^{3/2}；H_ẋy = 1、H_xẏ = 0；代入 (10.42c) 得 R = |λ|，极值曲线为圆，与 (10.29c) 互证；H(μẋ,μẏ) = μH，一次正齐次性验证通过 | 通过 |
| (10.49a–f) | 膜形变 / 狄利克雷变分问题 | F = u_x² + u_y² 代入 (10.48)：−2u_xx − 2u_yy = 0 ⟹ Δu = 0（拉普拉斯方程）；线性化 (10.49b)→(10.49c) 的泰勒展开亦核对无误 | 通过 |

(10.52) 里茨算例的全链复算另录于 [[findings/第10章里茨方法算例全链闭式复算]]；(10.29b) 之不自洽另录于 [[findings/10-29b第二式根号与圆解不自洽复算]]。

证据强度：高（全闭式、可复算；等周问题经显式与参数式两条独立路线互证）。此为直接证据（对印本公式的独立重算），非推断。
