# 两个二元隐函数的偏导数方程组（式 6.57a–c）

《数学手册(原书第10版)》6.2.3.2 条目 (5)：两个二元函数 u = f(x, y), v = φ(x, y) 由两个方程联立给出；"利用 (6.52b)"对 x、y 分别微分。

## 逐字转录

$$F(x, y, u, v) = 0 \quad \text{和} \quad \Phi(x, y, u, v) = 0 \tag{6.57a}$$

源文作"(6.57a) 的关千 x, y 的微分"（"关千"为"关于"之讹）：

$$\left.\begin{array}{l}
\dfrac{\partial F}{\partial x} + \dfrac{\partial F}{\partial u}\dfrac{\partial u}{\partial x} + \dfrac{\partial F}{\partial v}\dfrac{\partial v}{\partial x} = 0, \\
\dfrac{\partial \Phi}{\partial x} + \dfrac{\partial \Phi}{\partial u}\dfrac{\partial u}{\partial x} + \dfrac{\partial \Phi}{\partial v}\dfrac{\partial v}{\partial x} = 0
\end{array}\right\} \tag{6.57b}$$

$$\left.\begin{array}{l}
\dfrac{\partial F}{\partial y} + \dfrac{\partial F}{\partial u}\dfrac{\partial u}{\partial y} + \dfrac{\partial F}{\partial v}\dfrac{\partial v}{\partial y} = 0, \\
\dfrac{\partial \Phi}{\partial y} + \dfrac{\partial \Phi}{\partial u}\dfrac{\partial u}{\partial y} + \dfrac{\partial \Phi}{\partial v}\dfrac{\partial v}{\partial y} = 0
\end{array}\right\} \tag{6.57c}$$

原文续作："分别从方程组 (6.57b) (6.57c) 中解出 ∂u/∂x, ∂v/∂x 和 ∂u/∂y, ∂v/∂y 即得一阶偏导数利用同样的方法可计算高阶偏导数"（两句间标点脱漏；未给显式解公式）。

## 设定验证

- 6.57b 与 6.57c 分别是关于 (∂u/∂x, ∂v/∂x) 与 (∂u/∂y, ∂v/∂y) 的 2×2 线性方程组，结构与 [[findings/式6-55两隐函数方程组导数复算]] 的 6.55b 同型；每个方程由式 6.52b 应用于一个约束函数而得。✓（仅设定验证；原书未给显式解，故 replicated 记 null。）
- **边界**：原书未给显式解，不得凭与 6.55c 的结构类推补写解公式为原文内容；如需解式，应显式标注为入库者的推导而非原文。
