# 二次多项式的抛物线要素与判别式三分类（式 2.41）

2.3.2 给出二次多项式 $y = ax^2 + bx + c$（式 2.41）的完整图像要素：

- **对称轴** $x = -\dfrac{b}{2a}$；a>0 时先减后增取最小值，a<0 时先增后减取最大值；
- **与 y 轴交点** $B(0,\ c)$；**极值点（顶点）** $C\left(-\dfrac{b}{2a},\ \dfrac{4ac-b^2}{4a}\right)$；
- **与 x 轴交点由 $b^2 - 4ac$ 三分类**：>0 时两个交点 $A_{1,2}\left(\dfrac{-b \pm \sqrt{b^2-4ac}}{2a},\ 0\right)$；=0 时一个交点（切点）；<0 时无交点。

## 与 1.6 的对应

- 该三分类是 [[二次方程判别式三分类与手册反号约定]] 的**图像化复述**：交点横坐标即二次方程的根，切点即二重根。
- 本节采用标准正向约定（$b^2-4ac$ 与 0 比较）；若既有 finding 所记 1.6 的「反号约定」属实，则同书两节符号约定不一致，待回查裁决，见 [[2-3-2与1-6的二次判别式符号约定是否一致]]。
