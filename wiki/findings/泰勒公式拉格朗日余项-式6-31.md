# 泰勒公式拉格朗日余项（式 6.31）

## 断言

**对象**：泰勒定理/泰勒公式（6.1.4.5）。**题设**（两条）：函数 y=f(x) 在区间 [a, a+h] 上 n−1 次连续可微（具有连续导数）；且在区间内部存在 n 阶导数。**结论**（泰勒公式或泰勒展开式）：

```latex
(6.31)  f(a+h) = f(a) + \frac{h}{1!}f'(a) + \frac{h^{2}}{2!}f''(a) + \dots
              + \frac{h^{n-1}}{(n-1)!}f^{(n-1)}(a) + \frac{h^{n}}{n!}f^{(n)}(a+\Theta h),
        其中 0 < \Theta < 1, h 可正可负
```

（原文「可正可负」前疑脱 h 字；「n-l 次」「存在 阶导数」为转写讹误，见 [[queries/6-1-4全节系统性转写讹误清单]]。）

## 特例断言（已核验）

来源明确断言：**微分中值定理（式 6.29b）是泰勒公式在 n=1 时的特例**。核验：n=1 时式 6.31 的多项式部分仅剩 f(a)，余项为 (h/1!)·f′(a+Θh)，恰化为式 6.29b。断言成立。

## 证据强度

定理为标准结果；n=1 特例断言经直接代入核验通过（replicated: true）。
