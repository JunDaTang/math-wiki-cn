# 因式分解与多项式运算算例复算

## 复算对象

《数学手册（原书第10版）》20.3.1 中多项式 p = x⁶+7x⁵+12x⁴+6x³−25x²−30x−25 与 q = x⁴+x³−6x²−7x−7 之上的 Factor、GaussianIntegers、PolynomialGCD/LCM/Quotient/Remainder 诸算例，及 Expand 两例。

## 复算结论（均吻合）

1. **Factor[p] = (5+x)(1+x+x²)(−5+x²+x³)**：三因式乘法还原为 p 逐项吻合；三因式在有理数域上不可约（x³+x²−5 的候选有理根 ±1、±5 均非根）。
2. **GaussianIntegers**：Factor[x²−2x+5] 平凡返回 5−2x+x²；加选项后得 (−1−2I+x)(−1+2I+x) — 判别式 4−20 = −16，根 1±2i，吻合。转写脱方括号问题见 [[queries/GaussianIntegers例脱方括号之辨]]。
3. **PolynomialGCD[p,q] = 1+x+x²**：q = (1+x+x²)(x²−7) 恰含该公因式，p 的其余因式与 x²−7 互素，吻合。
4. **PolynomialLCM[p,q] // Factor = (5+x)(−7+x²)(1+x+x²)(−5+x²+x³)**：LCM = p·q/GCD = p·(x²−7)，吻合。
5. **PolynomialQuotient[p,q,x] = 12+6x+x²；PolynomialRemainder[p,q,x] = 59+96x+96x²+37x³**：多项式长除逐项复算吻合；书中随之给出的恒等式 p/q = x²+6x+12 + (37x³+96x²+96x+59)/q 经 q·(x²+6x+12) + 余式 = p 交叉验证成立。
6. **Expand[(x+y−z)⁴]**（四元齐次展开 15 项）与 **Expand[(ax+by²)(cx³−dy²)] = acx⁴−adxy²+bcx³y²−bdy⁴**：多项式定理/逐项相乘复算吻合。

## 证据性质

直接证据（手工长除、因式乘法还原、有理根检验），非推断。同一对 p、q 上的 Apart 部分分式算例为首项符号反例，单独立案：[[findings/Apart例首项符号与复算不符]]。
