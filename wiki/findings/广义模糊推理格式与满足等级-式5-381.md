# 广义模糊推理格式与满足等级（式 5.381a–b）

**断言**（《数学手册(原书第10版)》5.9.4，第 594 页，逐字转录）：

法则形式：

```
IF（若 A₁ 和 A₂ 和 A₃ ⋯ 和 Aₙ）THEN（则）B
其中 Aᵢ: μᵢ: Xᵢ → [0,1]  (i = 1, 2, …, n)
```

结论 B 的隶属函数 μ: Y → [0,1] 由一个 (n+1) 元关系（转录「(n+1)－值关系」）刻画：

```
R: X₁ × X₂ × ⋯ × Xₙ × Y → [0,1]        (5.381a)
```

对于具有清晰值 x₁′, x₂′, …, xₙ′ 的确实输入：

```
μ_{B′}(y) = μ_R(x₁′, x₂′, …, xₙ′, y)
          = min{μ₁(x₁′), μ₂(x₂′), …, μₙ(xₙ′), μ_B(y)}   (y ∈ Y)   (5.381b)
```

定义确实的模糊输出。min{μ₁(x₁′), μ₂(x₂′), ⋯, μₙ(xₙ′)} 称为**法则的满足等级**。

## 证据与核验状态

- 定义性陈述，无算例可复算（replicated: null）。
- 公式转录完整自洽：第二个等号把 (5.381a) 的关系 R 在清晰输入点取值后展开为逐点 min。
- 算子层面与 5.9.2 交叉一致：min 即 AND（和）的 Zadeh 算子（[[findings/zadeh算子与and-or-not对应]]、[[concepts/t-范数]]）。

## 转写疑点

- 「注量」疑为「注：量」；「并且量 min{μ₁(x₁′), …, μₙ(xₙ′)} 表示模糊值输入量」与满足等级为**同一公式重复出现**，疑第二处应为不同内容或为 OCR 重复，见 [[queries/满足等级注释两个min公式是否重复]]。
- 「结论 的隶属函数」脱 B；「(n+1)－值关系」的「值」疑应为「元」；「吐确实的输入」衍字「吐」；「·和 Aₙ」有杂点。
