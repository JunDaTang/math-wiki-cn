# 逆摆 Mamdani 算例（式 5.392–5.395，已复算）

**主张**：在 [[逆摆]] 的分区（$X_1=[-90^\circ,90^\circ]$、$X_2=[-45^\circ\mathrm{s}^{-1},45^\circ\mathrm{s}^{-1}]$、$Y=[-10\mathrm{N},10\mathrm{N}]$，各七个语言项）与 19 法则表下，初值 $(\theta,\dot\theta)=(36^\circ,-2.25^\circ\mathrm{s}^{-1})$ 仅激发两条法则，经 α-切割与极大聚合得输出集（式 5.395），逆模糊化得 $F=3.95$（重心法）或 $F=5.0$（极大值准则法）。

## 法则表（19/49，逐字转录）

| Θ\Θ̇ | nl | nm | ns | z | ps | pm | pl |
|---|---|---|---|---|---|---|---|
| nl | | | ps | pl | | | |
| nm | | | | pm | | | |
| ns | nm | | ns | ps | | | |
| z | nl | nm | ns | z | ps | pm | pl |
| ps | | | | ns | ps | | pm |
| pm | | | | nm | | | |
| pl | | | | nl | ns | | |

**注意**：按表头「行=Θ、列=Θ̇」查 $(\Theta,\dot\Theta)=(\mathrm{ps},z)$ 得 ns、$(\mathrm{pm},z)$ 得 nm，与正文 $R_1/R_2$ 的结论 ps/pm 矛盾；若行列对调则一致。本条复算**以正文与公式链为准**（见 [[逆摆法则表行列是否与r1r2转置]]）。

## 激发与输出集

$\mu_{ps}(36^\circ)=0.4$、$\mu_{pm}(36^\circ)=0.6$、$\mu_z(-2.25^\circ\mathrm{s}^{-1})=0.8$（由正文 $\min\{\cdot,\cdot\}$ 数值反推的自然读法）；$R_1$（ps∧z→ps）权 $\alpha=\min\{0.4,0.8\}=0.4$，$R_2$（pm∧z→pm）权 $\alpha=\min\{0.6,0.8\}=0.6$，其余 17 条法则权为零。以 [[α切割]] 得

$$
\mu^{\text{输出}(R_1)}_{36;-2.25}(y) = \left\{ \begin{array}{ll} \frac{2}{5}y, & 0 \le y < 1, \\ 0.4, & 1 \le y \le 4, \\ 2 - \frac{2}{5}y, & 4 < y \le 5, \\ 0, & \text{其他}; \end{array} \right.\tag{5.392}
$$

$$
\mu^{\text{输出}(R_2)}_{36;-2.25}(y) = \left\{ \begin{array}{ll} \frac{2}{5}y - 1, & 2.5 \le y < 4, \\ 0.6, & 4 \le y \le 6, \\ 3 - \frac{2}{5}y, & 6 < y \le 7.5, \\ 0, & \text{其他}; \end{array} \right.\tag{5.393}
$$

聚合（极大-极小复合，见 [[模糊关系的复合]]）：

$$
\mu^{\text{输出}}_{x_1,\dots,x_n}(y) = \max_{r\in\{1,\dots,k\}}\Big\{\min\{\mu^{(1)}_{i_{l,r}}(x_1),\dots,\mu^{(n)}_{i_{l,r}}(x_n),\mu_{i_r}(y)\}\Big\},\tag{5.394}
$$

$$
\mu^{\text{输出}}_{36;-2.25}(y) = \left\{ \begin{array}{ll} \frac{2}{5}y, & 0 \le y < 1, \\ 0.4, & 1 \le y < 3.5, \\ \frac{2}{5}y - 1, & 3.5 \le y < 4, \\ 0.6, & 4 \le y < 6, \\ 3 - \frac{2}{5}y, & 6 \le y \le 7.5, \\ 0, & \text{其他}. \end{array} \right.\tag{5.395}
$$

## 复算记录（全部通过）

1. **法则计数**：表中非空格数 = 19 ✓（49 个可能法则）。
2. **划分一致性**：$\mu_{ps}(36^\circ)+\mu_{pm}(36^\circ)=0.4+0.6=1$，与相邻模糊集划分的互补性吻合（推断）✓。
3. **未激发法则数**：19 − 2 = 17 ✓，与正文「其余 17 个法则」一致。
4. **聚合公式**：式 5.395 逐段确为式 5.392 与 5.393 的逐点最大值；交点 $y=3.5$ 处 $\tfrac{2}{5}\cdot3.5-1=0.4$，衔接无误 ✓。
5. **重心法**：分母 $\int\mu\,dy$ 分段为 $0.2+1.0+0.25+1.2+0.45=3.10$；分子 $\int y\mu\,dy$ 分段为 $\tfrac{2}{15}+2.25+0.9417+6.0+2.925=12.25$；$12.25/3.10\approx3.9516$，与手册 $F=3.95$ 完全吻合 ✓。
6. **极大值准则法**：$F=5.0$ 与平台段 $[4,6]$（高 0.6）的中点一致（推断；源文未指明具体变体）。

**证据强度**：高——这是 5.9 章入库内容中少见的可完全数值复核的结果，且独立复算通过。唯一内部矛盾是法则表方向（不影响数值链本身，也不构成对 [[mamdani方法]] 的评价）。

**开放问题**：图 5.79 的具体分区几何（使 0.4/0.6/0.8 成立的隶属函数峰值位置无法由文本唯一复原）；「极大值准则法」取 5.0 的具体变体。逐步操作模板见 [[mamdani模糊控制计算流程]]。
