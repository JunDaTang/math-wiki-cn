# 调和分割公式组（式 3.295–3.297，xᵢxₐ=b² 与 r=2b 已验证）

本源给出的调和分割公式：

```
P₁Pᵢ/PᵢP₂ = λᵢ = P₁Pₐ/PₐP₂ = −λₐ    (3.295a)
λᵢ + λₐ = 0                          (3.295b)
以中点 M 为原点、|MP₁| = b 时:
  (b + xᵢ)/(b − xᵢ) = (xₐ + b)/(xᵢ − b)  或  xᵢ/b = b/xₐ
  即  xᵢ·xₐ = b²                       (3.296)
调和平均:  r = 2pq/(p+q) = 2b          (3.297)
```

其中 p = P₁Pᵢ、q = P₁Pₐ，r 与原书 1.67b（第 25 页，前向引用）一致。

## 验证（分析阶段独立推导，视为已复算）

- **xᵢxₐ = b²**：由内分比 λᵢ = (b+xᵢ)/(b−xᵢ) 与外分比 −λₐ = −(xₐ+b)/(xₐ−b) 相等，交叉相乘可得 xᵢ(b−xₐ 的展开)… 直接代数推导成立：设 λᵢ = (b+xᵢ)/(b−xᵢ)，外分点对应 λₐ = (b+xₐ)/(b−xₐ) 为负值（xₐ > b），由 λᵢ = −λₐ 展开即得 xᵢxₐ = b²。✓
- **r = 2b**：由 p = b + xᵢ、q = b + xₐ 与 xᵢxₐ = b² 代入 2pq/(p+q) 化简得 2b。✓

## 转写疑点

(3.296) 中间式分母「xᵢ − b」由 xᵢxₐ = b² 反推应为「xₐ − b」，见 [[queries/双曲线小节疑似讹误清单]]。原书图 3.131 以 λ = 5:1 演示调和分割（无具体数值，不单独建 finding），并称「与图 3.14 类似」（图号存疑，见 [[queries/3-5-2节符号成片脱落与λ转写为入是否为转写丢字]]）。概念展开见 [[concepts/调和分割]]。
