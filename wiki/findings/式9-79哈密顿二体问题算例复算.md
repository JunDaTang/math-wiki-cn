# 式 9.79 哈密顿二体问题算例复算

本条目逐字转录「带哈密顿函数的二体问题」算例（式 9.79a–g），并对全链条——牛顿运动方程 → 哈密顿函数 → 典范组 → 偏微分方程 → 极坐标分离 → 完全积分 → 通解——逐步复算，含极坐标分离与符号约定核对。

## 逐字转录

```latex
d²x/dt² = ∂V/∂x,  d²y/dt² = ∂V/∂y；  V = k²/√(x²+y²)           (9.79a)
H = ½(p²+q²) − k²/√(x²+y²)                                     (9.79b)
dx/dt = ∂H/∂p,  dy/dt = ∂H/∂q,  dp/dt = −∂H/∂x,  dq/dt = −∂H/∂y (9.79c)
x, y, p = dx/dt, q = dy/dt                                     (9.79d)
∂z/∂t + ½[(∂z/∂x)² + (∂z/∂y)²] − k²/√(x²+y²) = 0               (9.79e)
z = −at − bφ + c − ∫_{ρ₀}^{ρ} √(2a + 2k²/r − b²/r²) dr         (9.79f)
∂z/∂a = −t₀,  ∂z/∂b = −φ₀                                      (9.79g)
```

## 求解链条

平面中依牛顿场（回指 13.4.3.2，未入库）相互引力作用下运动的两粒子，取其一初始位置为原点：运动方程 (9.79a) →（引进哈密顿函数 9.79b）→ 正规组/典范组 (9.79c，变量 9.79d) → 偏微分方程 (9.79e) →（极坐标 ρ, φ）→ 含参数 a, b, c 的解 (9.79f) →（9.79g）→ 典范组 (9.79c) 的通解。

## 复算

1. **典范组与牛顿方程的一致性**：dx/dt = ∂H/∂p = p（与 9.79d 的变量约定一致）；dp/dt = −∂H/∂x = −k²x/(x²+y²)^{3/2}；而 (9.79a) 给 d²x/dt² = ∂V/∂x = −k²x/(x²+y²)^{3/2}。两者一致（y 分量同理）。✅ 记号约定：此处 V = k²/r 为物理位能 U = −k²/r 的负值，H = T − V = T + U 为物理总能量，内部自洽。
2. **(9.79e) 的类型**：即 (9.77b) 型方程（时间型自变量为 t，H = ½(p²+q²) − k²/√(x²+y²)）。标准文献称此类方程为哈密顿-雅可比方程；源文本节未使用该名称。
3. **(9.79f) 代入 (9.79e) 恒为零**：z_t = −a，z_φ = −b，z_ρ = −√(2a + 2k²/ρ − b²/ρ²)；由 z_x² + z_y² = z_ρ² + z_φ²/ρ² = (2a + 2k²/ρ − b²/ρ²) + b²/ρ² = 2a + 2k²/ρ，得

   z_t + ½(z_x² + z_y²) − k²/ρ = −a + (a + k²/ρ) − k²/ρ = 0。✅

4. **物理量识别（推断，源外对照）**：根号内 2a + 2k²/r − b²/r² 正是能量守恒 ½ρ̇² + L²/(2ρ²) − k²/ρ = a 与角动量守恒联立所得的 ρ̇²；a 为总能量，z_φ = −b 为与极角共轭的动量，故 |b| 为角动量大小。✅
5. **参数计数**：z 含 a、b 与可加常数 c，正合 (9.77e) 完全积分的形状（n = 2 个本质参数 + 可加常数）；典范组 (9.79c) 为 2n = 4 阶，其通解的四个任意常数恰由 a、b 与 t₀、φ₀（由 9.79g 引入）给出。✅
6. **符号分支核对**：由 ∂z/∂a = −t₀，即 t + ∫_{ρ₀}^ρ dr/√(2a + 2k²/r − b²/r²) = t₀，关于 t 求导得 ρ̇ = −√(…)。(9.79f) 的负号支对应 ρ 随 t 减小的向内分支；若积分前取正号则得 ρ̇ = +√(…) 的向外分支——由于 (9.79e) 只含 z_x、z_y 的平方，两支都是解。源文仅给负号支，正号支是否原书给出待核（见 [[queries/9-2-1全节系统性转写讹误清单]]）。

## 转写疑点

- 算例标记「·」在转写稿中脱落为孤立符号（「·带哈密顿函数的二体问题」）。
- 极角记号 φ 与 (9.75b)/(9.76b) 的解/任意函数记号 φ 混用。
- 牛顿场回指 13.4.3.2（第 950 页），未入库（见 [[queries/9-2-1未入库回指缺口]]）。

## 意义

本算例是式 9.77 理论（[[findings/式9-77至9-78典范组与克莱罗PDE转录复算]]）的完整演示：牛顿方程 → Hamilton 正规组 → 哈密顿-雅可比型方程 → 分离变量完全积分 → 通解，即 Jacobi 定理在力学中的标准应用。
