# 傅里叶积分与谱密度（式 7.113–7.115）

## 主张（依源转录）

若 f(x) 在任意有限区间上满足狄利克雷条件（回指 7.4.1.2.3），且 ∫_{−∞}^{+∞}|f(x)|dx 收敛（回指 8.2.3.2），则傅里叶积分公式成立；间断点处取中值。傅里叶级数把周期函数展开成离散谱（频率 ω_n = n·2π/T、振幅 A_n）；傅里叶积分把非周期函数展开成连续频谱，频率 ω 对应谱密度 g(ω)。偶/奇函数有更简单的形式；算例为 e^{−|x|}。

```latex
% (7.113a/b/c)
f(x) = (1/2pi) Int_{-inf}^{+inf} e^{i omega x} d omega Int_{-inf}^{+inf} f(t) e^{-i omega t} dt
     = (1/pi) Int_0^{inf} d omega Int_{-inf}^{+inf} f(t) cos omega(t - x) dt
f(x) = [f(x-0) + f(x+0)]/2                                     % 间断点
g(omega) = (1/2pi) Int_{-inf}^{+inf} f(t) e^{-i omega t} dt    % 谱密度（复、双侧约定）

% (7.114a/b) 偶 / 奇函数的化简
f(x) = (2/pi) Int_0^{inf} cos omega x d omega Int_0^{inf} f(t) cos omega t dt    % 偶
f(x) = (2/pi) Int_0^{inf} sin omega x d omega Int_0^{inf} f(t) sin omega t dt    % 奇

% (7.115a/b) 算例 f(x) = e^{-|x|}（偶）
g(omega) = (2/pi) Int_0^{inf} e^{-t} cos omega t dt = (2/pi) · 1/(omega^2 + 1)
e^{-|x|} = (2/pi) Int_0^{inf} cos omega x/(omega^2 + 1) d omega
```

## 复算（通过）

1. **复形式 ↔ 余弦形式（7.113a）**：对复形式取实部，cos ω(t−x) = cos ωt·cos ωx + sin ωt·sin ωx，按 ω ↔ −ω 的偶/奇宇称合并正负半轴，得 (1/π)∫₀^∞ 的单侧余弦形式。✅
2. **偶函数化简（7.114a）**：f 偶 ⟹ sin 项积分为零、cos 项积分加倍：(1/2π)·2∫₀^∞ = (1/π)，再并入 (1/π)∫₀^∞ 的外侧因子得 (2/π)。奇函数对偶（7.114b）。✅
3. **算例（7.115）**：∫₀^∞ e^{−t}cos ωt dt = Re[1/(1 − iω)] = 1/(1+ω²)；反演 ∫₀^∞ cos ωx/(1+ω²) dω = (π/2)e^{−|x|}（标准结果）。代入验证：(2/π)·(π/2)e^{−|x|} = e^{−|x|}。✅
4. **谱密度的两种约定（内部张力，非讹误）**：式 7.113c 为复、双侧约定（g₃ = (1/2π)∫_{−∞}^{∞}，反演 f = ∫_{−∞}^{∞}g₃e^{iωx}dω）；式 7.115a 为偶函数单侧约定（g₅ = (2/π)∫₀^∞，反演 f = ∫₀^∞g₅cos ωx dω）。对偶 f 有 g₅ = 2g₃（(1/2π)·2 = 1/π vs 2/π），二者各自与其反演式配套、自洽，但同一符号 g(ω) 承载两种归一化，引用时必须辨明，见 [[queries/谱密度gω两种归一化约定]]。
