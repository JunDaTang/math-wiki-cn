# 费马定理极值必要条件（式 6.27）

## 断言

**对象**：费马定理（6.1.4.2）。**题设**：函数 y=f(x) 在一连通区间上有定义，在该区间的内点 x=c 处有极大值或极小值（即对该区间的任一点 x，f(c) > f(x) 或 f(c) < f(x)），且函数在点 c 可导。**结论**：在点 c 导数一定等于 0：

```latex
(6.27a)  f(c) > f(x)        （c 为区间内点, 对该区间的任一点 x）
(6.27b)  f(c) < f(x)
(6.27c)  f'(c) = 0
```

## 两则反向讨论

1. **必要非充分**：由图 6.6(a)，在点 A 处 f′(x)=0，但该处无极大值或极小值——导数等于 0 不是函数取得极值的充分条件。
2. **可微非必要**：图 6.8(d) 中点 e 具有极大值，但该点导数不存在（呼应 [[concepts/尖点]]、[[findings/左右导数尖点算例-式6-3]]）。

## 几何意义

若函数满足定理假设条件，则曲线在点 c 具有平行于 x 轴的切线（图 6.7）。

## 证据强度与备注

- 定理本身为标准结果，表述正确；直接证据为原文逐字转录。
- 两则反向讨论依赖插图（图 6.6(a)、图 6.8(d)）内容，纯文字无法独立核验（replicated: null）。
- 极值定义为全书区间意义下的严格极值（对区间任一点），强于通行教材的局部极值表述；手册版假设更强、结论不变，见 [[queries/罗尔与费马表述与通行版差异]]。
