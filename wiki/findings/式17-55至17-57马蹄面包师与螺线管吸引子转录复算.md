# 式 17.55–17.57 马蹄、面包师与螺线管吸引子转录复算

## 转录

```latex
Λ = ∩_{k=0}^inf φ^k(M)                                                           (17.55)
φ(x,y) = { (2x, αy), 0≤x≤1/2;  (2x−1, αy+1/2), 1/2<x≤1 }       【α 区间源文作 (1,1/2)，疑为 (0,1/2)】(17.56a)
d_H(Λ) = 1 + ln2/(−ln α)                                                         (17.56b)
d_L(mu) = 1 + ln2/(−ln α) = d_H(Λ)                                               (17.56c)
h_mu = sum_{λ_i>0} λ_i = ln 2                 （佩辛熵公式，源文以「此时」限定）  (17.56d)
Θ_{k+1} = 2Θ_k,  (x,y)_{k+1} = ½(cos Θ_k, sin Θ_k) + α(x,y)_k,  α∈(0,1/2)       (17.57)
% 螺线管：d_H(Λ) = 1 − ln2/ln α
```

## 复算

- **面包师映射耗散性与 α 区间**：$\det D\varphi=2\alpha$（$x$ 向倍增、$y$ 向乘 $\alpha$），耗散 ⟺ $2\alpha<1$ ⟺ $\alpha<\tfrac12$；且 $d_H(\Lambda)=1+\ln2/(-\ln\alpha)<2\iff\ln2<-\ln\alpha\iff\alpha<\tfrac12$。源文区间 $\alpha\in(1,\tfrac12)$ 为**空区间**，两条独立证据（耗散性、$d_H<2$）连同螺线管的 $\alpha\in(0,\tfrac12)$ 均指向订正为 $(0,\tfrac12)$ → [[queries/面包师映射α区间疑为0到二分之一之辨]]。
- **面包师李雅普诺夫维数（17.56c）**：奇异值 $2^k,\alpha^k$ ⟹ $\lambda_1=\ln2>0$、$\lambda_2=\ln\alpha<0$；$k=1$ 满足 $\lambda_1\ge0$、$\lambda_1+\lambda_2=\ln(2\alpha)<0$ ⟹ $d_L=1+\ln2/|\ln\alpha|=1+\ln2/(-\ln\alpha)$，与 $d_H(\Lambda)$（17.56b）**精确相等** ✓。注意：$d_L$ 是关于不变测度 $\mu$（$\mu\ne$ 勒贝格测度）的测度维数，$d_H(\Lambda)$ 是集合维数，此例两口径重合。
- **佩辛熵公式（17.56d）**：唯一正指数 $\lambda_1=\ln2$ ⟹ $h_\mu=\ln2$ ✓（源文限定「此时」，即对该系统成立）。
- **螺线管维数（17.57 后）**：$d_H=1-\ln2/\ln\alpha=1+\ln2/|\ln\alpha|$；$\alpha\in(0,\tfrac12)$ ⟹ $|\ln\alpha|>\ln2$ ⟹ $\ln2/|\ln\alpha|\in(0,1)$ ⟹ $d_H\in(1,2)$ ✓。$\Theta$ 倍增 ⟹ 沿长度方向的曲线在 $\Lambda$ 中稠（源文作「在 $T$ 中稠」，疑讹）；横截面为康托尔集与 $\alpha<\tfrac12$ 的压缩一致。
- **例 A 马蹄（17.55）**：$\Lambda=\bigcap_k\varphi^k(M)$ 紧不变——转录无误；但其「吸引 $M$ 中除一点外所有点」与「直线×康托尔集」两断言与经典构造冲突（经典马蹄 $\varphi(M)\not\subset M$、非吸引、Cantor×Cantor），见 [[queries/马蹄例子吸引性与经典构造不符之辨]]；本复算对例 A 仅确认转录与紧不变性。

## 判定

面包师与螺线管的维数、指数、熵公式全部代数复算通过（精确结果）；例 A 维数源文未给，吸引性表述存疑待印本裁决。

## 讹误登记

「耗散的 μ 包映射／面包映射」→「面包师映射」；$D\varphi((x,y))=\binom{2^k\ 0}{0\ \alpha^k}$ 疑为 $D\varphi^k(x,y)$；「7.20(b)(c)」→「17.20(b)(c)」；「每根曲线在 T 中稠」疑为「在 Λ 中稠」；「更迚一步地」→「更进一步地」。汇总见 [[queries/17-2-4全节系统性转写讹误清单]]。
