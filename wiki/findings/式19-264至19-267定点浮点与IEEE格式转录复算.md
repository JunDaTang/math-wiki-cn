# 式 19.264–19.267 定点浮点与 IEEE 格式转录复算

对《数学手册（原书第10版）》19.8.1.2「内部数字表示」的式 (19.264)–(19.267) 与表 19.4 作逐字转录并独立复算；除 C_max = 256 一处硬性矛盾外全部吻合。

## 转录

$$
0 \leqslant |a| \leqslant 2^t - 1 \tag{19.264}
$$

$$
a = \pm M B^{\pm E} \tag{19.265a} \qquad \frac{1}{B} \leqslant M < 1 \tag{19.265b}
$$

$$
2^{-2^p} \leqslant |a| \leqslant (1 - 2^{-t}) \cdot 2^{(2^p - 1)} \tag{19.266}
$$

$$
a = (-1)^v \cdot 2^E \cdot 1.b_1 b_2 \dots b_{t-1}, \quad \text{其中 } E = C - K \tag{19.267}
$$

(19.267) 后原文残句：「因为保存 C = 0, C = 255 这里 C_min = 1, C_max = 256」。

表 19.4 基本形式的参数（IEEE 单/双精度）：

| 参数 | 单精度 | 双精度 |
|---|---|---|
| 存储单元字长 | 32 | 64 |
| 最大指数 $E_{\text{max}}$ | +127 | +1023 |
| 最小指数 $E_{\text{min}}$ | −126 | −1022 |
| 常数 $K$ | +127 | +1023 |
| 指数位数 | 8 | 11 |
| 尾数位数 | 24 | 53 |

## 复算验证

- **(19.264)**：$t$ 位表示下 $|a|$ 的上界为无符号整数最大值 $2^t - 1$ ✓。
- **(19.265)–(19.266)**：半对数形式中指数符号与尾数符号分存，指数幅值以 $p$ 位编码（最大 $2^p - 1$）、尾数以 $t$ 位编码（最大 $1 - 2^{-t}$、最小 $1/B$），代入 $|a| = M \cdot B^E$ 即得 (19.266)，参数约定自洽 ✓。
- **表 19.4 逐项核对（与 IEEE 754 单/双精度公认值比对，该比对基于公开常识而非本源所载）**：
  - 单精度：1（符号 $v$）+ 8（指数）+ 23（显式尾数）= 32 位 ✓；尾数位数 24 含隐含前导 1 ✓；$K = 127$ 时 $E \in [1 - 127,\ 254 - 127] = [-126, +127]$，与表列 $E_{\min}, E_{\max}$ 一致 ✓。
  - 双精度：1 + 11 + 52 = 64 位 ✓；尾数位数 53 含隐含位 ✓；$K = 1023$ 时 $E \in [-1022, +1023]$ ✓。
- **C_max 异常（本段唯一未通过项）**：正文「C_min = 1, C_max = 256」三重不合——
  1. 8 位指数字段的编码上限为 $2^8 - 1 = 255$，256 不可表示；
  2. 正文自言 $C = 0$ 与 $C = 255$ 被保存（保留），则可用特征上界应为 254；
  3. 表 19.4 给 $E_{\max} = +127$、$K = +127$，则 $C_{\max} = E_{\max} + K = 254$。
  独立推算（非本源所载）：双精度 11 位指数对应 $C \in [1, 2046]$（保留 0 与 2047），$E_{\max} = 2046 - 1023 = +1023$ ✓，佐证单精度应为 $C_{\max} = 254$。故 256 疑为 254 之转写讹误，详见 [[queries/式19-267后C-max为256疑为254之辨]]。

## 直接证据与推断之区分

- 直接证据：式 (19.264)–(19.267)、残句与表 19.4 为原文转录。
- 推断：C_max = 254 之订正、双精度 C 范围之平行推算、表 19.4 与「IEEE 754 公认值」之比对（后者基于可独立核实的公开背景）。

## 结论

表 19.4 全部 12 项参数核验无误；式 (19.264)–(19.267) 在订正 C_max 后自洽。另「因为保存 C = 0, C = 255」为残句，疑脱关于零与特殊值的说明。
