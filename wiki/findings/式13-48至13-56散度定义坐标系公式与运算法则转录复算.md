# 式 13.48–13.56 散度定义、坐标系公式与运算法则转录复算

## 结论

对 13.2.4 全部公式（式 13.48–13.56）的解析复算**全部通过**：转录的公式与标准散度公式逐项一致，未发现公式层面的实质错误。本节唯一的实质性疑点是 13.2.4.2 第 4 条的标题术语（“一般直角坐标系”），不涉及公式正确性。

## 复算方法

解析推导：将各坐标公式与标准结果逐项对照；对特例（式 13.54 特例、式 13.56）用乘积法则独立重推。

## 逐式复算结果

| 式号 | 复算方式 | 结果 |
|---|---|---|
| (13.49a)/(13.49c) | 与笛卡儿散度标准式 $\partial_x V_x + \partial_y V_y + \partial_z V_z$ 及 $\nabla\cdot\vec{V}$ 记法对照 | 一致 |
| (13.50a) | 与柱面坐标散度标准式对照 | 一致 |
| (13.51a) | 与球面坐标散度标准式对照 | 一致 |
| (13.52a) | 在 $D = |\vec{r}_\xi||\vec{r}_\eta||\vec{r}_\zeta|$ 的正交前提下，与正交曲线坐标系散度的尺度因子通式对照 | 一致 |
| (13.53) | 常向量场散度为零、线性性 | 成立（显然） |
| (13.54) | 乘积法则；特例由 $\nabla r = \vec{r}/r$ 得 $\operatorname{div}(\vec{r}\,\vec{c}) = \vec{c}\cdot\nabla r = \vec{r}\cdot\vec{c}/r$ | 一致 |
| (13.55) | 与恒等式 $\operatorname{div}(\vec{V}_1\times\vec{V}_2) = \vec{V}_2\cdot\operatorname{rot}\vec{V}_1 - \vec{V}_1\cdot\operatorname{rot}\vec{V}_2$ 对照 | 一致 |
| (13.56) | 由 (13.54)：$\operatorname{div}(\varphi\vec{r}) = \varphi\operatorname{div}\vec{r} + \vec{r}\cdot\operatorname{grad}\varphi = 3\varphi + \vec{r}\cdot(\varphi'(r)\,\vec{r}/r) = 3\varphi + r\varphi'$ | 一致 |

## 证据强度与边界

- **直接证据**：上表全部为解析等价性验证，强度强；结论限于“转录公式正确”这一层面。
- **推断成分**：(13.52a) 的复算以 (13.52c) 的正交性为前提——该前提正是标题术语疑点的来源（见下）。
- **主题边界**：所有断言均关于“散度”这一概念本身，未涉及对其他实体或方法的评价转移。
- **未覆盖**：式 (13.48) 与体积导数框架的一致性属概念层陈述，由 [[concepts/体积导数]] 与 [[concepts/向量场的散度]] 承担，非本页公式复算对象。

## 遗留疑点（非公式错误）

1. 13.2.4.2 第 4 条标题“一般直角坐标系”与公式内容不符：式 (13.52c) 第二个等号仅对正交基成立，故该小节实为一般正交（曲线）坐标系——见 [[queries/一般直角坐标系疑为一般正交坐标系]]。
2. 式 (13.54) 特例来源排印为 $\operatorname{div}(r\vec{c})$，$r$ 疑漏向量箭头；复算结果 $\vec{r}\cdot\vec{c}/r$ 支持 $\vec{r}$ 的读法——见 [[queries/13-2-4全节系统性转写讹误清单]]。
3. 正文层面另有若干系统性转写讹误（“对千”、“di V”、“(diver-gence)” 连字符残留、“第 379 4.3.3.2” 疑脱“页”字等），均不影响公式，清单见 [[queries/13-2-4全节系统性转写讹误清单]]。
