# 心脏线的两种定义与特征量（式 2.236–2.237）

**主张。** 心脏线有两种等价定义：

1. 帕斯卡蜗线的特例 a = l，即满足 $\overline{OP} = \overline{OM} \pm a$（式 2.236，a 为圆直径）的蜗线；
2. 定圆与动圆具有相同直径 a 时的外摆线特例。

其方程为 $(x^2+y^2)^2 - 2ax(x^2+y^2) = a^2y^2$（式 2.237a）、参数式 2.237b、极坐标 $\rho = a(1+\cos\varphi)$（式 2.237c）。原点为尖点；顶点 A(2a, 0)；$\cos\varphi = \frac{1}{2}$ 时有极值点 $C, D\left(\frac{3}{4}a, \pm\frac{3\sqrt{3}}{4}a\right)$；面积 $S = \frac{3}{2}\pi a^2$；曲线长 $L = 8a$。

**验证（已验证，积分与内部自洽）。**
- 面积：$S = \frac{1}{2}\int_0^{2\pi} a^2(1+\cos\varphi)^2\,d\varphi = \frac{1}{2}a^2(2\pi + \pi) = \frac{3}{2}\pi a^2$。
- 极值点：蜗线极值公式 $\cos\varphi = \frac{-l \pm \sqrt{l^2+8a^2}}{4a}$ 取 l = a 给出 $\cos\varphi = \frac{1}{2}$（及退化解 cos φ = −1，即尖点），坐标与直接计算一致——蜗线公式与心脏线数据内部自洽。
- 隐式归约：蜗线隐式 $(x^2+y^2-ax)^2 = l^2(x^2+y^2)$ 取 l = a，展开后 $a^2x^2$ 两边相消，得 $(x^2+y^2)^2 - 2ax(x^2+y^2) = a^2y^2$，即式 2.237a。
- 未独立验证：弧长 L = 8a（手册给出值）。

**文字疑点。** 手册“即为圆的面积与直径 a 乘积的六倍”量纲不符，疑应为“以 a 为直径的圆面积的六倍”（$6 \cdot \pi(a/2)^2 = \frac{3}{2}\pi a^2$），见 [[queries/心脏线面积文字圆的面积与直径a乘积的六倍是否为误]]。外摆线定义的交叉引用待摆线族章节入库后回填；心脏线与双纽线作为两族临界特例的平行地位见 [[comparisons/双纽线与心脏线比较]]。
