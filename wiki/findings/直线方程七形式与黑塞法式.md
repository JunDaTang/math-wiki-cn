# 直线方程七形式与黑塞法式（式 3.302–3.310）

本源的基本命题：每个坐标线性方程都表示一条直线，反之每条直线的方程都是坐标线性方程。七种形式：

```
(1) 一般式:      Ax + By + C = 0   （A=0 平行于 x 轴；B=0 平行于 y 轴；C=0 过原点）  (3.302)
(2) 斜截式:      y = kx + b   （k = tan δ 为斜率/角系数，b 为 y 轴截距）          (3.303)
(3) 点斜式:      y − y₁ = k(x − x₁),  k = tan δ                                (3.304)
(4) 两点式:      (y − y₁)/(y₂ − y₁) = (x − x₁)/(x₂ − x₁)                       (3.305)
(5) 截距式:      x/a + y/b = 1   （a、b 为两轴截距，带符号）                     (3.306)
(6) 黑塞法式:    x·cos α + y·sin α − p = 0   (p > 0, 0 ≤ α < 2π)                (3.307)
    正规化因子:  μ = ±1/√(A² + B²)   （μ 符号与 C 相反）                          (3.308)
(7) 极坐标式:    ρ = p/cos(φ − α)                                               (3.309)
```

点线距离（带符号，由黑塞法式直接读出）：

```
d = x₁·cos α + y₁·sin α − p    (3.310)
```

P₁ 与原点位于直线两侧时 d > 0，否则 d < 0。

## 备注

- (3.308) 后原文「μ 的符号必须和 (3.302) 的符号相反」疑脱「C」字，见 [[queries/3-5-2节符号成片脱落与λ转写为入是否为转写丢字]]。
- 黑塞法式的概念展开见 [[concepts/黑塞法式]]；点线距离是后续交点/直线束/夹角公式的基础。
