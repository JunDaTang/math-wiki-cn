# 柱面扩充的定义与图 5.76 图示

**断言**（《数学手册(原书第10版)》5.9.4，第 594 页，逐字转录）：为形成连接「中等」压力与「高」温间的模糊关系（图 5.76），

```
μ̃₁(p, T) = μ₁(p)  ∀T ∈ X₂   (μ₁: X₁ → [0,1])
```

是模糊集「中等压力」（图 5.76(a)）的柱面扩充（图 5.76(c)）。类似地，

```
μ̃₂(p, T) = μ₂(T)  ∀p ∈ X₁   (μ₂: X₂ → [0,1])
```

是模糊集「高温」（图 5.76(b)）的柱面扩充（图 5.76(d)）。这里

```
μ̃₁, μ̃₂: G = X₁ × X₂ → [0,1]
```

## 解读

柱面扩充把 X₁（或 X₂）上的模糊集提升到乘积空间 G = X₁ × X₂，隶属函数对另一变量恒常；这是逐点 min/max 复合（图 5.77，见 [[findings/min-max算子构成and-or模糊关系-图5-77]]）的前置步骤。

## 证据与核验状态

- 公式定义自洽，可按定义直接验证（μ̃₁ 只依赖 p，μ̃₂ 只依赖 T）。
- **图示内容未复算**：转录仅含图像，像素层面的隶属函数形状无法核验；图 5.76(c) 的分图标签在转录中脱落（按 (a)(b)(d) 顺序推断为 (c)）。

## 转写疑点

- 「形成连接量”中等“压力与“高“温间」衍字「量」且引号方向错乱；「（图 5.76(c)）」处有多余右括号。
