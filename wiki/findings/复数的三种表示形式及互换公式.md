# 复数的三种表示形式及互换公式（式 1.131–1.134）

《数学手册》1.5.1–1.5.2 给出[[concepts/复数]]的三种等价形式及其互换公式：

1. **代数形式**（式 1.131a、1.132a）：z = a + ib，其中 a = Re(z)、b = Im(z)（式 1.131b）。
2. **三角形式**（式 1.132b）：z = ρ(cos φ + i sin φ)。源文此处公式正文缺失，仅存编号与图 1.7；内容由式 (1.135b) 反推，见 [[queries/式1.132b三角形式公式正文是否转写缺失]]。
3. **指数形式**（式 1.134a）：z = ρ e^{iφ}，经欧拉关系式 e^{iφ} = cos φ + i sin φ（式 1.134b，见 [[concepts/欧拉公式]]）与三角形式等价。

## 互换公式

由[[concepts/复数的模与辐角]]的换算（式 1.133a–e）：a = ρ cos φ，b = ρ sin φ，ρ = √(a² + b²)，辐角 φ 按 arccos 分段式（1.133c）或 arctan 分段式（1.133e）计算。

## 验证（直接证据）

- 手册示例（1.5.2.4）：z = 1 + i√3 = 2(cos π/3 + i sin π/3) = 2 e^{iπ/3}，核算正确（ρ = √(1 + 3) = 2，φ = arctan √3 = π/3）。
- 指数形式对非主值辐角同样成立：z = 2 exp[i(π/3 + 2kπ)]，k = 0, ±1, ±2, …。
- 两套辐角分段公式在边界情形（b = 0 时 φ = 0 或 π）给出一致结果，与主值区间 (−π, +π] 自洽。

本条目属工具书的定义性/公式性内容，非实证主张；证据强度取决于公式核算，已逐项验证无误。
