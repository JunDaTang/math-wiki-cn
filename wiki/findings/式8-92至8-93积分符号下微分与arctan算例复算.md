# 式 8.92–8.93 积分符号下的微分与变限推广（含 arctan 算例复算）

## 转录内容（8.2.4.2 积分符号下的微分）

**定理（式 8.92）**：若函数 (8.90) 在区间 $c \leqslant y \leqslant e$ 上有定义，函数 $f(x,y)$ 在矩形区域 $a \leqslant x \leqslant b,\ c \leqslant y \leqslant e$ 连续，且 $f(x,y)$ 关于 $y$ 有连续偏导数，则对 $\forall y \in [c,e]$，有

```latex
\frac{\mathrm{d}}{\mathrm{d}y}\int_{a}^{b} f(x,y)\,\mathrm{d}x
= \int_{a}^{b}\frac{\partial f(x,y)}{\partial y}\,\mathrm{d}x        % 式 8.92
```

称之为**积分符号下的微分**。

**变限推广（式 8.93）**：若假设条件同 (8.92)，函数 $\alpha(y)$ 和 $\beta(y)$ 在区间 $[c,e]$ 上有定义、连续、可微，且曲线 $x=\alpha(y)$ 和 $x=\beta(y)$ 包含在矩形 $a \leqslant x \leqslant b,\ c \leqslant y \leqslant e$ 范围内，则 (8.92) 可推广为

```latex
\frac{\mathrm{d}}{\mathrm{d}y}\int_{\alpha(y)}^{\beta(y)} f(x,y)\,\mathrm{d}x
= \int_{\alpha(y)}^{\beta(y)}\frac{\partial f(x,y)}{\partial y}\,\mathrm{d}x
+ \beta'(y)f(\beta(y),y) - \alpha'(y)f(\alpha(y),y)                  % 式 8.93
```

（式 8.93 即通称的 Leibniz 积分法则：除积分号下求导外，附上、下限随参数移动产生的边界项 $\beta'(y)f(\beta(y),y)-\alpha'(y)f(\alpha(y),y)$。源文以「条件同 (8.92)」指代定理条件，指代方式松散，见 [[queries/8-2-4全节系统性转写讹误清单]] 第 6 项。）

## arctan 算例（归于式 8.92）

源文：对 $\forall y>0$，

$$\frac{\mathrm{d}}{\mathrm{d}y}\int_0^1 \arctan\frac{x}{y}\,\mathrm{d}x = \int_0^1 \frac{\partial}{\partial y}\left(\arctan\frac{x}{y}\right)\mathrm{d}x = -\int_0^1 \frac{x\,\mathrm{d}x}{x^2+y^2} = \frac{1}{2}\ln\frac{y^2}{1+y^2}$$

验证（源文）：$\int_0^1 \arctan\frac{x}{y}\,\mathrm{d}x = \arctan\frac{1}{y} + \frac{1}{2}y\ln\frac{y^2}{1+y^2}$，且

$$\frac{\mathrm{d}}{\mathrm{d}y}\left(\arctan\frac{1}{y} + \frac{1}{2}y\ln\frac{y^2}{1+y^2}\right) = \frac{1}{2}\ln\frac{y^2}{1+y^2}$$

当 $y=0$ 时，$f(x,y)$ 不满足连续性，因此不可导。

## 独立复算

1. $\partial_y \arctan(x/y) = \frac{-x/y^2}{1+(x/y)^2} = -\frac{x}{x^2+y^2}$ ✓
2. $-\int_0^1 \frac{x}{x^2+y^2}\,\mathrm{d}x = -\frac{1}{2}\ln\frac{1+y^2}{y^2} = \frac{1}{2}\ln\frac{y^2}{1+y^2}$ ✓
3. 分部积分：$\int_0^1 \arctan\frac{x}{y}\,\mathrm{d}x = \left[x\arctan\frac{x}{y} - \frac{y}{2}\ln(x^2+y^2)\right]_{x=0}^{x=1} = \arctan\frac{1}{y} + \frac{y}{2}\ln\frac{y^2}{1+y^2}$ ✓（与源文闭式一致）
4. 对闭式求导：$\frac{\mathrm{d}}{\mathrm{d}y}\arctan\frac{1}{y} = -\frac{1}{1+y^2}$；$\frac{\mathrm{d}}{\mathrm{d}y}\left[\frac{y}{2}\ln\frac{y^2}{1+y^2}\right] = \frac{1}{2}\ln\frac{y^2}{1+y^2} + \frac{1}{1+y^2}$；两项中 $\mp\frac{1}{1+y^2}$ 相消，余 $\frac{1}{2}\ln\frac{y^2}{1+y^2}$ ✓（闭合验证成立）
5. $y=0$ 处 $\arctan(x/y)$ 无定义／不连续，定理条件确不满足，源文自洽 ✓

**复算结论：式 8.92–8.93 及 arctan 算例全部无误。**
