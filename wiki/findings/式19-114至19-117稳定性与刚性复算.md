# 式 19.114–19.117 稳定性与刚性复算

**转录**（源文逐字保留）：

```latex
(19.114)  |\tilde y(x) - y(x)| \leqslant |\tilde y_0 - y_0|
(19.115)  y' = \lambda y,  y(x_0) = y_0   (\lambda \leqslant 0 为常数)
(19.116)  |y_i| \leqslant |y_0|
(19.117)  y(x) = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}   (\lambda_1, \lambda_2 < 0,\ |\lambda_1| \ll |\lambda_2|)
```

**复算与评注**：

- **欧拉绝对稳定区间（复算通过，直接证据）**：将欧拉法 (19.97) 用于 (19.115)：y_{i+1} = y_i + h·λy_i = (1+λh)y_i，故 y_i = (1+λh)^i y₀；|y_i| ⩽ |y₀| 对一切 i 成立 ⟺ |1+λh| ⩽ 1 ⟺ −2 ⩽ λh ⩽ 0（λ ⩽ 0）。与源文结论一致。
- 问题稳定性 (19.114)：ỹ 为扰动初值下的解，估计表明解差的绝对值不大于初值的扰动；源文称因其难以检验，故退而考虑线性试验问题 (19.115) 并定义方法的绝对稳定性 (19.116)。
- 舍入—离散权衡（源文明言）：舍入误差 O(1/h) 加到整体离散误差 O(h^p) 上，因此需要选择一个不太小的有限步长。
- 刚性 (19.117)：源文示例 λ₁ = −1, λ₂ = −1000；断言“含 λ₂ 的项对解函数并无显著影响，但在数值方法中影响步长 h 的选取”，属无证明的定性断言（证据强度中等），特殊方法见 [19.29], [19.6]。

见 [[concepts/对初值扰动的稳定性与绝对稳定性]]、[[concepts/刚性微分方程]]。
