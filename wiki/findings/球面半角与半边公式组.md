# 球面半角与半边公式组（式 3.192–3.196）

3.4.2.2 第 6–7 条给出由边求角的半角公式（两形式）与由角求边的半边公式（两形式），公式全文见 [[concepts/球面半角与半边公式]]。分组结构：

```
半角公式（一）  tan(α/2) = √[sin(s−b)sin(s−c)/(sin s·sin(s−a))]，s=(a+b+c)/2        (3.192a–d)
半角公式（二）  tan(α/2) = k/sin(s−a)，k = √[sin(s−a)sin(s−b)sin(s−c)/sin s]       (3.193a–e)
半边公式（一）  cot(a/2) = √[cos(σ−β)cos(σ−γ)/(−cos σ·cos(σ−α))]，σ=(α+β+γ)/2      (3.194a–d)
半边公式（二）  cot(a/2) = k′/cos(σ−α)，k′ = √[cos(σ−α)cos(σ−β)cos(σ−γ)/(−cos σ)] (3.195a–e)
σ 的范围        90° < σ < 270° ⟹ cos σ < 0 恒真                                     (3.196)
```

要点：

- 半角公式「类似于平面三角学的半角公式」，平面侧见 [[findings/半角公式与附加关系]]；半边公式则为球面特有（平面三角形无「由角求边」问题，见 [[findings/平面三角形边不可仅由角得到]]）。
- 形式二引入辅助量 k、k′；手册明言半角公式形式二（3.193）「如果要从球面三角形的三条边确定全部三个角」时有用，半边公式的两形式则以「或」并列、未作同样的用途说明。
- 式 3.196 由三角之和（式 3.183）直接推出，保证 −cos σ > 0；手册并断言「鉴于对欧拉三角形的要求，所有的根都是实数」。欧拉三角形定义属尚未入库的 3.4.1。

## 复核状态

公式经入库分析独立核验正确（含以孟买—达累斯萨拉姆算例的三边代入 3.192a 复算 α ≈ 51.247°，与手册给出的 51.248° 在舍入范围内一致）。半角/半边的结构对偶见 [[comparisons/球面半角公式与半边公式对偶比较]]。
