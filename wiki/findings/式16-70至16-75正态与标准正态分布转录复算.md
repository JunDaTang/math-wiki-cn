# 式 16.70–16.75 正态与标准正态分布转录复算

对 [[10-数学手册原书第10版--9-1624-连续分布--1ktbozm]] 16.2.4.1–16.2.4.2 的编号公式逐字转录并手工复算。结论：除两处疑点外全部与标准结果一致；两处疑点均为「公式正确性」级别，须纸质原书核验。

## 逐字转录与复算

### 正态分布（16.2.4.1）

```
(16.70a)  P(X ⩽ x) = F(x) = 1/(σ√(2π)) · ∫_{−∞}^{x} e^{−(t−μ)²/(2σ²)} dt
(16.70b)  f(t) = 1/(σ√(2π)) · e^{−(t−μ)²/(2σ²)}
(16.71a)  E(X) = 1/(σ√(2π)) · ∫_{−∞}^{+∞} x·e^{−(x−μ)²/(2σ²)} dx = μ
(16.71b)  D²(X) = E[(X−μ)²] = 1/(σ√(2π)) · ∫_{−∞}^{+∞} (x−μ)²·e^{−(x−μ)²/(2σ²)} dx = σ²
(16.72)   P(a ⩽ X ⩽ b) = Φ((b−μ)/σ) − Φ((a−μ)/σ)
```

复算：(16.70a,b)、(16.71a,b)、(16.72) 与标准正态分布结果一致；密度在 t=μ 取最大值、在 μ±σ 处有拐点，与密度函数二阶导数的符号变化相符。

(16.71b) 后未编号线性组合公式（逐字转录）：

```
μ = k₁μ₁ + k₂μ₂ ,   σ = √(k₁σ₁² + k₂σ₂²)
```

复算：均值部分正确；方差部分由独立性得 Var(k₁X₁ + k₂X₂) = k₁²σ₁² + k₂²σ₂²，故 σ 应为 √(k₁²σ₁² + k₂²σ₂²)。疑 k₁、k₂ 的平方上标在转写中脱落（与全节上标系统性丢失现象一致），已立 [[正态线性组合方差k1k2疑未平方]] 追踪。

### 标准正态分布与误差积分（16.2.4.2）

```
(16.73a)  Φ(x) = 1/√(2π) · ∫_{−∞}^{x} e^{−t²/2} dt = ∫_{−∞}^{x} φ(t) dt
(16.73b)  φ(t) = 1/√(2π) · e^{−t²/2}
(16.74)   Φ(−x) = 1 − Φ(x)
(16.75a)  Φ₀(x) = 1/√(2π) · ∫_{0}^{x} e^{−t²/2} dt = Φ(x) − 1/2
(16.75b)  erf(x) = 2/√π · ∫_{0}^{x} e^{−t²/2} dt = 2·Φ₀(√2·x)
```

复算：(16.73a,b)、(16.74)、(16.75a) 与标准结果一致。

(16.75b) 存疑：作代换 u = t/√2，

```
2·Φ₀(√2·x) = 2/√(2π) · ∫_{0}^{√2·x} e^{−t²/2} dt = 2/√π · ∫_{0}^{x} e^{−u²} du
```

即恒等式右端对应被积函数 e^{−u²}（标准误差函数定义 erf(x) = (2/√π)∫₀ˣ e^{−t²}dt），而非逐字转录的 e^{−t²/2}；若被积函数确为 e^{−t²/2}，则 (2/√π)∫₀ˣ e^{−t²/2}dt = 2√2·Φ₀(x)，与 2Φ₀(√2x) 不相等。二者必有一误，已立 [[式16-75b误差函数被积函数疑为e负t平方]] 追踪。

## 直接证据与推断的区分

- 直接证据：上列公式为源文逐字转录；
- 复算（独立推导）：上述各标准性核对与两处疑点的推导；
- 推断：两处疑点更可能是转写脱上标或衍入字符而非原书之误（依据是全节存在系统性上标/因子丢失），此为推断而非定论。

## 复现状态

复算为一次性手工推导；一致性结论可在任意概率论教材交叉验证，视为已复现；两处疑点待纸质原书核验。
