# 闭区间上连续函数有界且取得最值（式 2.34–2.35）

《数学手册》(原书第10版) 2.1.5.5.6–7 载两条有界性/最值定理（直接证据，原文转写）。

## 函数有界性定理（式 2.34）

若函数 $f(x)$ 在有限闭区间 $[a,b]$ 上连续，则它在该区间有界，即存在两个数 $m,M$，使得

```
m ⩽ f(x) ⩽ M,   a ⩽ x ⩽ b.    (2.34)
```

## 魏尔斯特拉斯定理（式 2.35）

若函数 $f(x)$ 在有限闭区间 $[a,b]$ 连续，则 $f(x)$ 有一个绝对极大值 $M$ 和一个绝对极小值 $m$：该区间至少存在一点 $c$ 和一点 $d$，使得当 $a\leqslant x\leqslant b$ 时

```
m = f(d) ⩽ f(x) ⩽ f(c) = M.    (2.35)
```

## 变化量

连续函数最大值与最小值之差称为函数在给定区间的**变化量**；变化量的概念可以推广到函数没有最大值和最小值的情形。
