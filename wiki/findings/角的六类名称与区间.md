# 角的六类名称与区间（表 3.1）

原书 3.1.1.2 指出，角依照边的不同位置具有不同名称；表 3.1 给出的名称用于区间 $0^{\circ} \leqslant \alpha \leqslant 360^{\circ}$ 中的角 $\alpha$（原文转写）：

| 角的名称 | 度 | 弧度 |
|---|---|---|
| 周(全)角 | $\alpha = 360^{\circ}$ | $\alpha = 2\pi$ |
| 凸角 | $\alpha > 180^{\circ}$ | $\pi < \alpha < 2\pi$ |
| 平角 | $\alpha = 180^{\circ}$ | $\alpha = \pi$ |
| 直角 | $\alpha = 90^{\circ}$ | $\alpha = \pi/2$ |
| 锐角 | $0^{\circ} < \alpha < 90^{\circ}$ | $0^{\circ} < \alpha < \pi/2$ |
| 钝角 | $90^{\circ} < \alpha < 180^{\circ}$ | $\pi/2 < \alpha < \pi$ |

## 要点

- 六类名称覆盖全区间：周(全)角、平角、直角为等式边界；锐角、钝角、凸角为开区间。
- 两处转写疑点：凸角行度栏 $\alpha > 180^{\circ}$ 疑缺上界 $< 360^{\circ}$（与弧度栏 $\pi < \alpha < 2\pi$ 不匹配）；锐角行弧度栏 $0^{\circ} < \alpha < \pi/2$ 中不应出现度符号。见 [[表3-1凸角缺上界与锐角弧度栏度符号是否为误]]。

## 证据性质

分类本身为标准几何知识（直接证据）；表格转写的两处疑点不影响分类实质，但提示引用时需对照原版。
