# RSA 算法与算例（式 5.276a–b，含 1037→1073 讹误判定）

本源 5.5.7.3 之 1（RSA 码）：接收者 B 选取两个非常大的素数 p、q，算出 m = pq，选取 r 与 φ(m) = (p−1)(q−1) 互素且 1 < r < φ(m)，公布 m 与 r。消息文本转为数字串并分裂成若干相同长度的区组（每区组小于 100 个十进制数位）：

```
加密:  N^r ≡ R (mod m)                                              (5.276a)
解密:  解线性同余式 rs ≡ 1 (mod φ(m)) 得 s，则
       R^s ≡ (N^r)^s ≡ N^{1+kφ(m)} ≡ N·(N^{φ(m)})^k ≡ N (mod m)      (5.276b)
```

式 (5.276b) 应用了欧拉-费马定理（[[concepts/费马-欧拉定理]]）及 N^{φ(m)} ≡ 1 (mod m)；注意后者需前提 gcd(N, m) = 1，原文未声明（见 [[queries/rsa模幂需gcd条件缺失]]）。

## 算例复算（本 wiki 全链独立核验）

原文设定：p = 29，q = 37（原文明言「实际上这对于实用目的太小了」），r = 5，明文 N = 8。

| 步骤 | 原文值 | 复算 | 结果 |
|---|---|---|---|
| m = pq | 29·37 | 29×37 = 1073 | **1073**（原文正文印 1037，讹） |
| φ(m) | 1008 | 28×36 = 1008 | ✓ |
| gcd(1008, 5) | 1 | 1008 = 2⁴·3²·7，不含因子 5 | ✓ |
| 8⁵ mod m | 578 | 8⁵ = 32768 = 30·1073 + 578 | ✓ |
| s（5s ≡ 1 mod 1008） | 605 | 5×605 = 3025 = 3·1008 + 1 | ✓ |
| 578⁶⁰⁵ mod 1073 | 8 | gcd(8,1073)=1；578⁶⁰⁵ = 8^{5·605} = 8^{1+3·1008} = 8·(8¹⁰⁰⁸)³ ≡ 8（欧拉-费马） | ✓ |

## 1037 → 1073 讹误判定（算术可证伪）

- 29 × 37 = 1073 ≠ 1037（1037 系数字倒置）。
- 若 m = 1037：1037 = 17×61，φ(1037) = 16×60 = 960 ≠ 1008，与原文 φ 值矛盾。
- 若 m = 1037：8⁵ = 32768 = 31·1037 + 621 ≡ 621 ≠ 578，与原文密文矛盾。
- 算例内部两处运算（8⁵ ≡ 578 与 578⁶⁰⁵ ≡ 8）均只对 1073 成立。

**结论**：原文「m = 29·37 = 1037」及「φ(1037) = 1008」中的 1037 为 1073 之讹（本 wiki 判定）；待对照纸质原书确认是原书排印还是转写引入，见 [[queries/rsa算例模数1037是否应为1073]]。
