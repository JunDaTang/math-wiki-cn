# 四种折旧方法的公式与切换条件（式 1.88–1.96）

《数学手册(原书第10版)》1.3.5 给出折旧的四种方法及“几何递减转直线”的切换条件。记号：$A$ 折旧基数、$N$ 有效期限、$R_n$ 为 $n$ 年后残值、$a_n$ 为第 $n$ 年折旧率、$d$ 为算术递减的“倍数”、$p\%$ 为几何递减的年折旧百分率：

```latex
a_n = \frac{A - R_N}{N} = a \tag{1.88}
R_n = A - n\,\frac{A - R_N}{N} \quad (n = 1,2,\dots,N) \tag{1.89}
a_n = a_1 - (n-1)d \quad (n = 2,3,\dots,N+1) \tag{1.90}
d = \frac{2[Na_1 - (A - R_N)]}{N(N-1)} \tag{1.91}
a_1 > \frac{A - R_N}{N} = a \tag{1.92}
\frac{A - R_N}{N} < a_1 < 2\,\frac{A - R_N}{N} \tag{1.93}
d = \frac{2(A - R_N)}{N(N+1)} \tag{1.94a}
a_1 = Nd,\; a_2 = (N-1)d,\; \dots,\; a_N = d \tag{1.94b}
R_n = A\left(1 - \frac{p}{100}\right)^n \quad (n = 1,2,\dots) \tag{1.95}
m > N - \frac{100}{p} \tag{1.96}
```

- 直线法 (1.88)/(1.89)：年折旧为常数；$R_N = 0$ 时完全折旧。
- 算术递减法 (1.90)–(1.93)：折旧额逐年减少 $d$；$d = 0$ 退化为直线法；(1.93) 可由 $d>0$ 与 $a_N>0$ 经 (1.91) 反推得出。
- 数字递减法 (1.94)：算术递减取 $a_N = d$ 的特例，折旧额为等差序列 $Nd, (N-1)d, \dots, d$。
- 几何递减法 (1.95)：残值为公比 $\left(1-\frac{p}{100}\right)$ 的等比序列；$R_N$、$p$、$N$ 知二求一。
- 切换条件 (1.96)：几何递减对有限 $n$ 残值不能为 0；$m > N-\frac{100}{p}$ 后几何递减折旧率小于直线折旧率，转换为直线折旧合理（$m$ 为几何递减的最后一年，$N$ 为残值为 0 时线性折旧的最后一年）。

## 手册数值例子（导入时独立复核）

- 几何折旧例 A：€50000 以 10% 年率几何折旧，首次降至 €10000 以下需 $N = \frac{\ln(10000/50000)}{\ln(1-0.1)} = 15.27$ 年——吻合。
- 切换条件例：购买价 €50000、15 年内折旧到 0、前 $m$ 年按残值的 14% 几何递减——手册由 (1.96) 得 $m > 15-\frac{100}{14} = 7.76$，即 m = 8 年后转直线折旧合理。**勘误候选**：$15-\frac{100}{14} \approx 7.86$（$100/14 \approx 7.143$），手册中间数值 7.76 有误，但结论 m = 8 不受影响，见 [[queries/式1-96示例中15减100除14的数值7-76是否勘误]]。
- 数字递减表舍入误差：手册表中取整折旧额之和为 40005（精确值应为 13333.33 / 10666.67 / 8000 / 5333.33 / 2666.67），导致末年残值 9995 ≠ 目标 $R_5 = 10000$。属数值表精度问题，不影响公式。

## 证据说明

直接证据：手册原文。推导链自洽：(1.93) 由 $d>0$ 与 $a_N>0$ 反推；(1.96) 由“几何递减折旧率 < 剩余直线折旧率”推出；直线法残值序列为 [[concepts/等差级数]]、几何递减残值序列为 [[concepts/等比级数]]。数值经导入时独立算术复核，除上述两处勘误候选外全部吻合。确定性推导，非经验性结果。
