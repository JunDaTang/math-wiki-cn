# 式 9.101–9.102 圆盘与球的格林函数与泊松积分复算

## 逐字转录

```
圆盘：Δu = 0（半径 R）                                                (9.101a)
G(x,y;ξ,η) = ln(1/r) + ln(r₁ρ/R)                                     (9.101b)
OM · OM₁ = R²（M₁ 为 M 关于圆周的对称点，同射线）                      (9.101c)
u(ξ,η) = (1/2π)∫₀^{2π} (R²−ρ²)/(R²+ρ²−2Rρcos(ψ−φ))·u(φ)dφ           (9.101d)

球：Δu = 0（半径 R）                                                  (9.102a)
G(x,y,z;ξ,η,ζ) = 1/r − R/(r₁ρ)                                       (9.102b)
ρ = √(ξ²+ζ²+ζ²) [sic!]，M₁ = (Rξ/ρ, Rη/ρ, Rζ/ρ)
u(ξ,η,ζ) = (1/4π)∬_S (R²−ρ²)/(Rr³)·u ds                             (9.102c)
```

（记号：ξ = ρcos ψ、η = ρsin ψ；u(φ) 为边界上的已知值。）

## 复算核验

1. **9.101b 边界为零**：P 在圆周上时由相似三角形（OM·OM₁ = R²）得 r₁/r = R/ρ，故 r₁ρ/R = r，G = ln(1/r) + ln r = 0 ✓。
2. **泊松积分（圆盘）**：外法向导数 ∂G/∂n_out = (ρ² − R²)/(Rr²)；代入内法向的 (9.99e)（取 −∂G/∂n_out = (R² − ρ²)/(Rr²)），配合边界弧元 ds = R dφ 与 r² = R² + ρ² − 2Rρcos(ψ − φ)，恰得 (9.101d) ✓。
3. **球**：9.102b 由同一镜像关系在球面上为零；(9.102c) 与标准球泊松核 (R² − ρ²)/(4πRr³) 一致 ✓（r 为边界点至内点 M 的距离）。

## 勘误

9.102b 处 ρ = √(ξ² + ζ² + ζ²) 显为 √(ξ² + η² + ζ²) 之误（η² 脱落、ζ² 重复），见 [[queries/9-2-2全节系统性转写讹误清单]]。
