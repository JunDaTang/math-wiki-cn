# 平衡点与周期轨李雅普诺夫指数特例复算

## 转录（源文逐字）

**A**〔源文脱标签「A」〕：设 $x_0$ 为流 (17.1) 的一个平衡点，$\alpha_i$ 为雅可比矩阵在 $x_0$ 的特征值。对支撑在 $x_0$ 点的测度，李雅普诺夫指数为 $\lambda_i = \mathrm{Re}\,\alpha_i\ (i = 1, 2, \cdots, n)$。

**B**：$\gamma(x_0) = \{\varphi^t(x_0), t \in [0, T]\}$ 为 (17.1) 周期轨，$\rho_i$ 为 $\gamma(x_0)$ 点的相应乘子，则对支撑在 $\gamma(x_0)$ 的测度有 $\lambda_i = \frac{1}{T}\ln|\rho_i|,\ i = 1, 2, \cdots, n$。

## 复算（编者推演，非源文所载）

1. **特例 A 的核验**：平衡点处 $f(x_0) = 0$，[[concepts/变分方程]] 化为常系数线性方程 $\dot{y} = Ay$，$A = Df(x_0)$，其解算子 $\varPhi_x(t) = e^{At} = D\varphi^t(x_0)$。$e^{At}$ 的特征值为 $e^{\alpha_i t}$，其奇异值的对数增长率为 $\mathrm{Re}\,\alpha_i$（$t$ 的多项式因子在 $\frac{1}{t}\ln$ 下消失），故谱 $\{\lambda_i\}$ 与 $\{\mathrm{Re}\,\alpha_i\}$ 作为多重集相等。〔排序口径注：$\lambda_i$ 按降序定义而 $\alpha_i$ 无序，严格应作谱多重集相等；此为对源文表述的口径澄清。〕
2. **特例 A 的数值示例**：[[concepts/洛伦茨系统]] 原点平衡点（编者取标准参数 $\sigma = 10,\ r = 28,\ b = 8/3$，请以该页所载参数复核）：$A = \begin{pmatrix}-\sigma & \sigma & 0\\ r & -1 & 0\\ 0 & 0 & -b\end{pmatrix}$，特征方程 $(\lambda + b)(\lambda^2 + 11\lambda - 270) = 0$，特征值 $\approx 11.83,\ -22.83,\ -8/3$，故指数谱（降序）$\approx \{11.83,\ -2.67,\ -22.83\}$——含一个正指数，与该平衡点的鞍型分类（[[concepts/双曲平衡点]]、[[concepts/双曲平衡点与汇源鞍分类]]）一致。
3. **特例 B 的核验**：沿周期轨，$D\varphi^t(x_0)$ 由 [[concepts/弗洛凯定理与乘子]] 支配：增长率为 $|\rho_i|^{t/T}$，故 $\frac{1}{t}\ln\sigma_i \to \frac{1}{T}\ln|\rho_i|$，即特例 B（与 [[concepts/周期轨乘子与安德罗诺夫—维特定理]] 衔接）。
4. **与 (17.39a) 的一致性**：对特例 B 求和，$\sum_i\lambda_i = \frac{1}{T}\sum_i\ln|\rho_i| = \frac{1}{T}\ln\left|\prod_i\rho_i\right|$；而由 [[findings/式17-17乘子公式与17-9a周期轨双法复算]] 的乘子—散度公式 $\prod_i|\rho_i| = \exp\int_0^T \mathrm{div}\,f\,\mathrm{d}s$，得 $\sum_i\lambda_i = \frac{1}{T}\int_0^T \mathrm{div}\,f(\varphi^s(x_0))\,\mathrm{d}s$，恰为 (17.39a) 在周期轨上的取值。特例 A、B 与和公式三者互相印证。
5. **零指数备注**：流情形沿轨道方向恒有一个乘子 $\rho = 1$（对应指数 $0$），这解释了源文「吸引子不是平衡点且至少有一个李雅普诺夫指数为零」的简化条件对流略显叠床架屋的表述。〔编者注：属口径 nuance，非矛盾。〕
