# 表 6.3 初等函数高阶导数逐字转录

《数学手册》6.1.3.2 给出「某些初等函数的高阶导数」表（表 6.3），共 12 行，全部已逐行独立复算无误。逐字转录如下（表头「n阶函数」为转写讹误，疑应为「n 阶导数」，见 [[queries/6-1-3全节系统性转写讹误清单]]）：

| 函数 | n阶函数（原文表头，疑应为「n 阶导数」） |
|---|---|
| $x^{m}$ | $m(m-1)(m-2)\cdots(m-n+1)x^{m-n}$（当 m 为整数,且 n>m 时,n 阶导数为 0） |
| $\ln x\ (x>0)$ | $(-1)^{n-1}(n-1)! \dfrac{1}{x^{n}}$ |
| $\log_{a} x\ (x>0)$ | $(-1)^{n-1} \dfrac{(n-1)!}{\ln a} \dfrac{1}{x^{n}}$ |
| $e^{kx}$ | $k^{n} e^{kx}$ |
| $a^{x}$ | $(\ln a)^{n} a^{x}$ |
| $a^{kx}$ | $(k \ln a)^{n} a^{kx}$ |
| $\sin x$ | $\sin\left(x + \dfrac{n\pi}{2}\right)$ |
| $\cos x$ | $\cos\left(x + \dfrac{n\pi}{2}\right)$ |
| $\sin kx$ | $k^{n}\sin\left(kx + \dfrac{n\pi}{2}\right)$ |
| $\cos kx$ | $k^{n}\cos\left(kx + \dfrac{n\pi}{2}\right)$ |
| $\sinh x$ | 当 n 为偶数时为 $\sinh x$，当 n 为奇数时为 $\cosh x$ |
| $\cosh x$ | 当 n 为偶数时为 $\cosh x$，当 n 为奇数时为 $\sinh x$ |

## 复算要点（独立推导验证）

- **幂函数**：逐次求导得下降阶乘乘积 $m(m-1)\cdots(m-n+1)$；注记「当 m 为整数且 n>m 时为 0」仅在 m 为非负整数时成立——若 m 为负整数（如 $m = -1$），各阶导数永不归零，$(x^{-1})^{(n)} = (-1)^{n}n!\,x^{-n-1} \neq 0$。疑为原版「自然数」之误，追踪于 [[queries/表6-3的m为整数条件是否应为非负整数]]。
- **对数**：$(\ln x)' = 1/x$，归纳得交替符号与阶乘；$\log_{a}x = \ln x / \ln a$，整体除以 $\ln a$。
- **指数**：$a^{x} = e^{x\ln a}$、$a^{kx} = e^{kx\ln a}$，每求导一次乘 $\ln a$ 或 $k\ln a$。
- **三角**：$\sin,\cos$ 每求导一次相移 $\pi/2$；$kx$ 情形另乘链式因子 $k^{n}$。
- **双曲**：$\sinh,\cosh$ 互相交替，偶数阶回到自身、奇数阶互换。

## 复算状态

12 行全部复算无误（独立推导，非仅转写核对）。该表是莱布尼茨公式算例中「另一因子各阶导数通项」的来源（见 [[methodology/莱布尼茨公式截断计算流程]]）。
