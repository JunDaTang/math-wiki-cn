# 式 9.122–9.131 期望值、不确定度与对易关系转录复算

## 转录

```latex
\bar{A} = \lim_{N\to\infty}\frac{1}{N}\sum_i a_iN_i = \sum_i a_iW_i = \iiint_V \psi^{*}\hat{A}\psi\,\mathrm{d}V                                          % 9.122
(\Delta A)^{2} = \lim_{N\to\infty}\frac{1}{N}\sum_i N_i(a_i-\bar{A})^{2} = \sum_i W_i(a_i-\bar{A})^{2}                                                   % 9.123
(\Delta A)^{2} = \overline{(A-\bar{A})^{2}} = \overline{A^{2}}-\bar{A}^{2} = \iiint_V \psi^{*}(\hat{A}-\bar{A})^{2}\psi\,\mathrm{d}V                      % 9.124
\bar{A}=a_i,\qquad \Delta A=0                                                                                                                            % 9.125
\hat{C}=[\hat{A},\hat{B}]=\hat{A}\hat{B}-\hat{B}\hat{A}=0                                                                                                 % 9.126
\hat{A}\varphi_{i,\nu}=a_i\varphi_{i,\nu},\qquad \hat{B}\varphi_{i,\nu}=b_\nu\varphi_{i,\nu}                                                              % 9.127
\Delta A\,\Delta B \geqslant \Big|\frac{1}{2\mathrm{i}}\overline{[\hat{A},\hat{B}]}\Big|                                                                  % 9.129
[\hat{p}_x,\hat{x}] = \frac{\hbar}{\mathrm{i}}                                                                                                            % 9.130
\Delta p_x\,\Delta x \geqslant \frac{\hbar}{2}                                                                                                            % 9.131
```

（源文另有 9.128：Ā = aᵢ, B̄ = b_ν, ΔA = ΔB = 0。）

## 复算与核对

- **9.122**：三种平均的等价性——频率平均 ↔ 概率加权（用 9.117 Wᵢ = Nᵢ/N）↔ 积分（用 9.118 展开与 9.116 正交性，Σaᵢ|cᵢ|² = ∭ψ*ÂψdV）✓。
- **9.123/9.124**：标准差两种写法的等价（A²‾ − Ā² 展开）✓；积分形式为 (Â−Ā)² 的期望 ✓。
- **9.125**：本征态中分布退化为单点 ✓。
- **9.126–9.128**：相容可观察量的定义链，条件充分必要性以联合本征函数系表述 ✓。
- **9.129**：结构与标准的罗伯逊（Robertson）不等式一致 ✓。
- **9.130**：直接计算 [p̂ₓ, x̂]ψ = (ℏ/i)(∂ₓ(xψ) − x∂ₓψ) = (ℏ/i)ψ，故 [p̂ₓ,x̂] = ℏ/i ✓。
- **9.131**：把 9.130 的 Ĉ = ℏ/i 代入 9.129，|(1/2i)·(ℏ/i)‾| = ℏ/2 ✓。

## 疑点

- 9.130 的对易关系在源文中被表述为「位置算符和动量算符之间的对易关系 (9.130)」且顺序写作 [p̂ₓ, x̂]；此处 (ℏ/i) = −iℏ，与通行记号 [x̂,p̂ₓ] = iℏ 等价（仅差整体符号），非错误，但阅读时须注意次序约定。
- 归属限定：9.131 仅由 9.130 导出，属位置-动量对；一般算符对的形式是 9.129。

## 结论

直接推导复算全部通过；本组是 9.2.4 最重要的定性结论（不确定度关系）的完整证据链。
