# 式 18.68–18.70 黄金分割区间套缩复算

## 转录

```text
(18.68a) λ₁ = a₁ + (1−τ)(b₁−a₁),   μ₁ = a₁ + τ(b₁−a₁)
(18.68b) τ = ½(√5−1) ≈ 0.618

(18.69a) f(λ₁) < f(μ₁)  ⇒  a₂ = a₁, b₂ = μ₁, μ₂ = λ₁
(18.69b) f(λ₁) ⩾ f(μ₁)  ⇒  a₂ = λ₁, b₂ = b₁, λ₂ = μ₁

(18.70)  ε > bₙ − aₙ = τⁿ⁻¹(b₁ − a₁)
```

## 复算（直接证据）

1. **τ 的恒等式**：τ = ½(√5−1) 是方程 x² + x − 1 = 0 的正根，故 τ² = 1 − τ。由此 λ₁ + μ₁ = a₁ + b₁，两试探点关于区间中点对称放置。
2. **情形 a) 的缩短因子**：新区间 [a₂, b₂] = [a₁, μ₁]，长度 μ₁ − a₁ = τ(b₁ − a₁)。
3. **情形 b) 的缩短因子**：新区间 [a₂, b₂] = [λ₁, b₁]，长度 b₁ − λ₁ = (b₁ − a₁) − (1−τ)(b₁ − a₁) = τ(b₁ − a₁)。
4. **归纳得式 18.70**：每步区间按因子 τ 缩短，故 bₙ − aₙ = τⁿ⁻¹(b₁ − a₁)；由 ε > τⁿ⁻¹(b₁ − a₁) 可反解步数 n（对数形式 n > 1 + ln((b₁−a₁)/ε)/ln(1/τ) 为本维基推演，源文仅给原始形式）。
5. **函数值计数**：首步需算 f(λ₁)、f(μ₁) 两个值；其后每步只新算一个试探点的值——情形 a) 复用 f(μ₂) = f(λ₁)，情形 b) 复用 f(λ₂) = f(μ₁)。故确定 [aₙ, bₙ] 恰需 n 次函数值计算，与源文「需要一起计算 n 个函数值」自洽。

## 内部矛盾：正文与式 18.69 对调

源文正文称，从第 2 步起已知的函数值「在情形 a) 下是 f(λ₂)，而在情形 b) 下是 f(μ₂)」，与式 18.69 对调：按 18.69a（μ₂ = λ₁），情形 a) 的已知值应为 **f(μ₂)**；按 18.69b（λ₂ = μ₁），情形 b) 的已知值应为 **f(λ₂)**。本复算的函数值计数按式 18.69 的替换规则采信。疑为原文或转写讹误，详见 [[queries/黄金分割已知函数值情形ab对调之辨]]。

## 证据强度

- 式 18.68–18.70 与函数值计数：**强**（恒等式与区间长度的直接计算，复算通过）。
- 同节「黄金分割与斐波那契相比至多多一个函数值」：**中**（源文未给推导，属手册引述的标准结果，采信但标注为无证明论断；该论断同时约束 [[concepts/黄金分割法]] 与 [[concepts/斐波那契法]]）。
