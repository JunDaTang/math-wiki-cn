# 线性代换密码计数 nφ(n) 与凯撒特例

本源 5.5.4.2：设 A = {a₀,…,a_{n−1}}，k, s ∈ {0,…,n−1}，gcd(k, n) = 1，则映射 a_i ↦ a_{ki+s} 的置换 t_s^k 称为线性代换密码，**存在 nφ(n) 个**线性代换密码。移位密码是 k = 1 的情形；s = 3 的移位密码即凯撒密码（Julius Caesar，公元前 100 年—前 44 年使用过）。

## 复算（本 wiki 独立核验）

- 计数自洽性：参数 s 有 n 种取值；参数 k 须在模 n 下可逆，恰有 φ(n) 种取值（[[concepts/欧拉函数]]，k ∈ ℤₙˣ）。二者独立，故总数 n·φ(n)。
- ℤ₂₆ 实例：φ(26) = φ(2)·φ(13) = 1·12 = 12，故 26·12 = **312** 个。✓
- 斜率条件的必要性：gcd(k, n) = 1 保证 i ↦ ki+s 为模 n 双射；否则不同明文字母映到同一密文字母，加密函数不再单射，与 [[findings/密码体制形式化定义]] 的单射要求冲突。

## 转写讹误（不影响结论）

- 原文将映射印作 t_s^k(a_i) = a_{ki+1}：若下标真为 ki+1，则 t 与 s 无关且总数应为 φ(n)，与正文 nφ(n) 矛盾——故「1」应为「s」之讹（见 [[queries/线性代换映射下标ki加1是否应为ki加s]]）。
- 原文「移位密码是 = 的线性代换密码」脱落「k = 1」。
