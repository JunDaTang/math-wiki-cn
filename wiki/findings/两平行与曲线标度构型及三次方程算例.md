# 两平行与曲线标度构型及三次方程算例

**发现内容**（《数学手册(原书第10版)》2.19.3.3，式 2.302–2.303c，图 2.111）：一个直线标度在 $y$ 轴，另一个直线标度与它的距离为 $d$，第三个为曲线标度，此时判据 (2.296) 化为

$$\begin{vmatrix} 0 & \psi_1(z_1) & 1 \\ d & \psi_2(z_2) & 1 \\ \varphi_3(z_3) & \psi_3(z_3) & 1 \end{vmatrix} = 0, \tag{2.302}$$

即

$$\psi_1(z_1) + \psi_2(z_2)\frac{\varphi_3(z_3)}{d - \varphi_3(z_3)} - d\,\frac{\psi_3(z_3)}{d - \varphi_3(z_3)} = 0. \tag{2.303a}$$

设第一个标度分度为 $E_1$、第二个为 $E_2$（$\psi_1 = E_1 f,\ \psi_2 = E_2 g$），则化为

$$E_1 f(z_1) + E_2 g(z_2)\,\frac{E_1}{E_2} h(z_3) + E_1 k(z_3) = 0, \tag{2.303b}$$

且曲线标度由

$$\varphi_3(z_3) = \frac{d E_1 h(z_3)}{E_2 + E_1 h(z_3)}, \quad \psi_3(z_3) = -\frac{E_1 E_2 k(z_3)}{E_2 + E_1 h(z_3)} \tag{2.303c}$$

给出。即：**线性组合 + 双变量项型** $E_1 f(z_1) + E_2 g(z_2)\frac{E_1}{E_2} h(z_3) + E_1 k(z_3) = 0$ 的三元关系可用「两平行直线标度 + 曲线标度」的贯线算图表示。

**算例（简化的三次方程，图 2.111）**：$z^3 + p^* z + q^* = 0$（参见 1.6.2.3）的形式为 (2.303b)。经代换 $E_1 = E_2 = 1,\ f(z_1) = q^*,\ g(z_2) = p^*,\ h(z_3) = z$ 后，计算曲线标度坐标的公式为

$$x = \varphi_3(z) = \frac{dz}{1 + z}, \quad y = \psi_3(z) = -\frac{z^3}{1 + z}.$$

（原文未明写 $k(z) = z^3$，但由 $z^3 + p^* z + q^* = 0$ 与 (2.303b) 的对照可知隐含此取法。）图 2.111 仅示 $z > 0$ 的曲线标度；负根经以 $-z$ 代替 $z$ 读出（原文该句语序疑有错乱，见 [[queries/2-19-3-3负根句的表述是否错乱]]）。复根 $u + iv$ 亦可由算图确定：实根总存在，记为 $z_1$，复根实部 $u = -\dfrac{z_1}{2}$，虚部 $v$ 由

$$3u^3 - v^2 + p^* = \frac{3}{4}z_1^2 - v^2 + p^* = 0$$

给出（原文首项作 $3u^3$；由 $u = -z_1/2$ 蕴含 $3u^2 = \frac{3}{4}z_1^2$，故应为 $3u^2$，见 [[queries/复根公式的3u3是否应为3u2]]）。算例：$y^3 + 2y - 5 = 0$，即 $p^* = 2,\ q^* = -5$，有 $z_1 \approx 1.3$。

**复核与注记**（非原文部分已标注）：

- 全部代数关系（(2.302)→(2.303a–c) 与曲线标度公式）经独立复核一致；数值复核：$y^3 + 2y - 5 = 0$ 的真根 $\approx 1.328$，复根 $\approx -0.664 \pm 1.823i$（与 $v^2 = \frac{3}{4}z_1^2 + p^* \approx 3.32$ 一致），算图读数 $1.3$ 符合其精度，故 replicated: true。
- （注，非原文）复根确定式隐含「单实根 + 共轭复根」情形；若三根皆实，则 $v^2 = \frac{3}{4}z_1^2 + p^* \le 0$，公式不再给出实值 $v$——原文未言明此限制。
