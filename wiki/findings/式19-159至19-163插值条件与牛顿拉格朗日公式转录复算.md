# 式 19.159–19.163 插值条件与牛顿、拉格朗日公式转录复算

对源文 19.6.1 开篇至 19.6.1.2 的插值条件 (19.159)、牛顿形式 (19.160)、n = 2 方程组展示、拉格朗日公式 (19.161)–(19.163) 与三点算例做逐式转录与复算。完整转录见 [[10-数学手册原书第10版--10-1961-多项式插值--fy5ml4]]。

## 转录（直接证据）

$$
g(x_\nu)=y_\nu\quad(\nu=0,1,2,\dots,n)\tag{19.159}
$$

$$
p_n(x)=a_0+a_1(x-x_0)+a_2(x-x_0)(x-x_1)+\dots+a_n(x-x_0)(x-x_1)\dots(x-x_{n-1})\tag{19.160}
$$

n = 2 方程组（原文第三式前两个 $x_1$ 疑讹，应为 $x_2$）：

```
p₂(x₀) = a₀ = y₀
p₂(x₁) = a₀ + a₁(x₁−x₀) = y₁
p₂(x₂) = a₀ + a₁(x₁−x₀) + a₂(x₁−x₀)(x₂−x₁) = y₂   ← 原文如此
```

$$
p_n(x)=\sum_{\mu=0}^{n}y_\mu L_\mu(x),\qquad
L_\mu(x_\nu)=\delta_{\mu\nu},\qquad
L_\mu=\prod_{\substack{\nu=0\\ \nu\neq\mu}}^{n}\frac{x-x_\nu}{x_\mu-x_\nu}\tag{19.161–19.163}
$$

## 复算结果

1. **拉格朗日基函数与算例（复算通过，直接证据）**：对节点表（x: 0, 1, 3；y: 1, 3, 2），
   - $L_0(x)=\frac13(x-1)(x-3)$、$L_1(x)=-\frac12x(x-3)$、$L_2(x)=\frac16x(x-1)$ 与 (19.163) 代入结果逐项一致；
   - 展开 $1\cdot L_0+3\cdot L_1+2\cdot L_2$：x² 系数 $\frac13-\frac32+\frac13=-\frac56$，x 系数 $-\frac43+\frac92-\frac13=\frac{17}6$，常数项 1，即 $p_2(x)=-\frac56x^2+\frac{17}6x+1$；
   - 插值条件校验：$p_2(0)=1$、$p_2(1)=-\frac56+\frac{17}6+1=3$、$p_2(3)=-\frac{15}2+\frac{17}2+1=2$，全部通过。
2. **拉格朗日公式满足插值条件（复算通过，直接证据）**：$\nu\neq\mu$ 时 $L_\mu(x_\nu)$ 分子含零因子 $(x_\nu-x_\nu)$；$\nu=\mu$ 时分子分母逐项相消为 1；故 (19.162) 成立，(19.161) 满足 (19.159)。
3. **n = 2 牛顿方程组（发现转写讹误）**：原文第三式 $a_1(x_1-x_0)+a_2(x_1-x_0)(x_2-x_1)$ 与 (19.160) 在 $x=x_2$ 处的取值不符，前两个 $x_1$ 应为 $x_2$；照原文则方程组亦不再保持源所声称的三角结构。数学不自洽暴露转写讹误，见 [[式19-160后n等于2方程组之x1疑为x2之辨]]。
4. **唯一性断言（推断补注，非源文）**：源称 $p_n(x)$ 由 (19.159) 唯一确定但未证；标准证法（差多项式次数 ≤ n 而有 n+1 个互异根，必为零多项式）为本 wiki 外部补注，属可独立复证的标准定理。

## 结论

(19.161)–(19.163) 及三点算例转录复算通过（replicated: true 指本 wiki 独立重算通过）；唯一性为源之断言式陈述；n = 2 方程组含一处数学不自洽型转写讹误。
