# 式 19.81–19.84 高斯与洛巴托节点系数表转录复算

转录 19.3.3 高斯与洛巴托求积的形式、区间变换与节点系数表，并逐档核对。**本 finding 含全节唯一发现的数值讹误。**

## 转录（verbatim）

```latex
∫_a^b f(x) dx ≈ Σ_{ν=0}^n c_ν y_ν,  y_ν = f(x_ν)                    (19.81)
∫_a^b f(t) dt ≈ (b−a)/2 · Σ_{ν=0}^n c_ν f((b−a)/2·x_ν + (a+b)/2)     (19.83)
```

(19.82) Gauss–Legendre 节点与系数（[−1,1]）：

| n | 节点 x_ν | 系数 c_ν |
|---|---|---|
| 1 | x₀ = −x₁；x₁ = 1/√3 = 0.577350269… | c₀ = 1；c₁ = 1 |
| 2 | x₀ = −x₂；x₁ = 0；x₂ = √(3/5) = 0.774596669… | c₀ = 5/9；c₁ = 8/9；c₂ = c₀ |
| 3 | x₀ = −x₃；x₁ = −x₂；x₂ = 0.339981043…；x₃ = 0.861136311… | c₀ = 0.347854854…；c₁ = 0.652145154…；c₂ = c₁；c₃ = c₀ |

(19.84a/b) Lobatto 节点与系数：

| n | 节点 x_ν | 系数 c_ν |
|---|---|---|
| 2 | x₀ = −1；x₁ = 0；x₂ = 1 | c₀ = 1/3；c₁ = 4/3；c₂ = c₀（即辛普森公式） |
| 3 | x₀ = −1；x₁ = −x₂；x₂ = 1/√5 = 0.447213595…；x₃ = 1 | c₀ = 1/6；c₁ = 5/6；c₂ = c₁；c₃ = c₀ |

## 复算与核对结论

- **高斯 n=1**：节点 ±1/√3 = ±0.577350269…，权 1, 1——与标准值一致 ✓。
- **高斯 n=2**：节点 0, ±√(3/5) = ±0.774596669…，权 5/9, 8/9, 5/9——与标准值一致 ✓。
- **高斯 n=3**：源 c₀ = 0.347854854… 与标准值 **0.3478548451…** 不符（末两位 45/54 疑互换）✗。**内部佐证**：对常函数准确要求权系数和等于区间长度（[−1,1] 上 Σc_ν = 2，对称情形即 c₀+c₁ = 1）；按源值 0.347854854 + 0.652145154 = 1.000000008 ≠ 1，破坏该恒等式。节点 ±0.339981043…、±0.861136311… 与标准值一致 ✓。
- **洛巴托 n=2**：节点 −1, 0, 1，权 1/3, 4/3, 1/3——即辛普森公式，「n=2 的情况表示辛普森公式」断言成立 ✓。
- **洛巴托 n=3**：节点 ±1/√5 = ±0.447213595… 加端点 ±1，权 1/6, 5/6, 5/6, 1/6——与标准值一致 ✓。
- **仿射变换 (19.83)**：$t=\frac{b-a}{2}x+\frac{a+b}{2}$ 将 [−1,1] 映到 [a,b]，因子 (b−a)/2 正确 ✓。

## 疑点

- (19.82) n=3 c₀ 讹误是本节最硬的一处数值矛盾，是原书排印讹误还是转写讹误待对照原书（[[queries/式19-82中n等于3系数c0末两位疑互换之辨]]）。
- 19.3.3.2「在 (19.81) 中有多于 2n 个的自由参数」疑为「恰有 2n 个」（[[queries/多于2n个自由参数疑为恰有2n个之辨]]）。
