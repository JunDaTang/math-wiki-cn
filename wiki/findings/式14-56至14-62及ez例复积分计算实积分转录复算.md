# 式 14.56–14.62 及 e^z 例复积分计算实积分转录复算

对《数学手册(原书第10版)》14.4 节的七项断言逐一进行独立代数复算。结论：**全部通过**（其中两处数学级转写疑误经复算定位并修正，见「转写修复记录」）。各断言仅归属其命名对象，不跨对象转移。

## 断言清单与验证

1. **e^z 例（14.4.1，无编号公式）**：∫₀^{2π} e^{rcosφ}cos(r sinφ − nφ)dφ = 2πrⁿ/n!。推导：将 e^z 代入 (14.42) 导数形式，参数化 ζ = z + re^{iφ}（(14.43)），约去 e^z 后右端积分的实部给出结论、虚部因左端为实而为零。逐步复算通过。**直接证据**。
2. **[[concepts/留数定理]] (14.56) 及算例**：Res[1/(1+z²)³]|_{z=i} = 1/2!·d²/dz²[(z+i)^{−3}]|_{z=i} = 6/(2i)⁵ = −3i/16，故 ∫dx/(1+x²)³ = 2πi·(−3i/16) = 3π/8。留数链复算通过，且与独立已知结果 3π/8 一致（**复现**）。源文两处缺字（六重根、三阶极点句），见修复记录。
3. **[[concepts/若尔当引理]] (14.57a–c)**：仅陈述，无证明。与标准定理一致；情形 d) 的适用范围表述较宽泛。**陈述层面接受，证据强度中**。
4. **(14.58c)**：经 (14.58b) 偶/奇函数分解、围道 C 含 C_R 与 [−R, R]（R > a）、留数 2πi·lim_{z→ai} z e^{iαz}/(z+ai) = πi e^{−αa}、若尔当引理取极限，得 (π/2)e^{−αa}。全链复算通过；a = 0 退化为 π/2，与 (14.59) 一致（交叉验证）。**直接证据**；条件 a ⩾ 0 与极点位置存在内部张力，见 [[queries/式14-58a条件a大于等于0与极点位置之辨]]。
5. **[[concepts/正弦积分]] (14.59)**：缩进围道（向下绕开原点，极点在围道内部，I = 2πi），小弧段 r→0 时关于 φ 一致趋于 iπ，大弧段由若尔当引理趋于零，得 2i∫sinx/x dx + iπ = 2πi。复算通过；即 Dirichlet 积分，与独立已知值 π/2 一致（**复现**）。
6. **[[concepts/阶梯函数]] (14.60) 与 [[concepts/矩形脉冲]] (14.61)**：F(t) 三段取值按围道闭合方向与极点归属验证；Ψ(t) = F(b−t) − F(a−t) 三段取值逐段验证。均通过（**直接证据**）。
7. **[[concepts/菲涅耳积分]] (14.62)**：I_I → ½√π（高斯积分）；I_II 的 α-分割估计 |I_II| < αR/2·e^{−R²cosα} + (1−e^{−R²cosα})/(2R sinα) 复算通过（含换元 2φ→φ 与原函数 ∫sinφ·e^{−R²cosφ}dφ = [e^{−R²cosφ}/R²]）；I_III 指数疑漏负号，修正为 e^{−ir²} 后全链自洽，分离实虚部得两积分相等且为 ½√(π/2)，与独立已知值一致（**复现**）。

## 转写修复记录（依数学上下文的推断，已逐处标注）

- 「有一个 重根」→ **六重根**（f(1/z) = z⁶/(1+z²)³ 在 z = 0）；
- 「一个 阶极点因为 和— 分别是……三重根」→ **三阶极点，因 z = i 与 z = −i 分别是 (1+z²)³ = 0 的三重根**；
- (14.62) I_III 指数 e^{ir²} → **e^{−ir²}**（数学内部证据：π/4 射线上 z² = ir²；括号展开仅与 e^{−ir²} 自洽；取 e^{+ir²} 将导出 sin 积分为负的矛盾结果）；
- 14.4.1 例中 n 的取值（非负整数）源文未显式说明，按 (14.42) 导数形式的适用范围推定。

## 复制状态
