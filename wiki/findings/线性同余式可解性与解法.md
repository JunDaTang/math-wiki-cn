# 线性同余式可解性与解法（式 5.251–5.252，两例已复算）

**来源**：[[sources/10-数学手册原书第10版--10-543-同余和剩余类--n0ce67]]（5.4.3.6）。

**陈述**：线性同余式 ax ≡ b (mod m)（5.251）可解，当且仅当 gcd(a, m) 是 b 的因子；此时模 m 解数等于 gcd(a, m)；特别地 gcd(a, m) = 1 时模 m 有唯一解。解法：转为丢番图方程 ax + my = b，对约化形式 a′x + m′y = b′（a′ = a/g、m′ = m/g、b′ = b/g，g = gcd(a, m)）取特解 (x⁰, y⁰)，则全部解为

$$x \equiv x^0 \pmod{m'};\qquad x^0,\ x^0+m,\ \dots,\ x^0+(g-1)m \pmod m. \tag{5.252a–b}$$

**复算（两例均通过）**：

- 114x ≡ 6 (mod 315)：g = gcd(114, 315) = 3（114 = 2·3·19，315 = 3²·5·7），3 | 6 可解，模 315 有 3 解。约化：38x ≡ 2 (mod 105)；38·94 = 3572 = 105·34 + 2，故 x ≡ 94 (mod 105)，模 315 的解为 94、199、304。验算：114·94 = 10716 = 315·34 + 6 ✓；114·199 = 22686 = 315·72 + 6 ✓；114·304 = 34656 = 315·110 + 6 ✓。源文「94, 199304」为「94, 199, 304」的连写讹误。
- 38x ≡ 2 (mod 105)：gcd(38, 105) = 1，唯一解 x ≡ 94 (mod 105)（如上验算 38·94 = 3572 ≡ 2）。✓

**证据类型**：直接证据（定理 + 两算例复算）。

**转写备注**：源文「因为 gcd(114,315) 的因子」脱落「= 3 是 6」；「模 315 个解」脱落「有 3」；「同余式 (5.251) 可解，当且仅当 gcd(a, m) 的因子」脱落「是 b」；解法段「因为 gcd(a, m) = 1」应为 gcd(a′, m′) = 1（约化后的互素性）；「为求 (5.259) 的所有解」应为 (5.251)。丢番图方程方法依赖未入库的 5.4.2（第 502/503 页），见 [[queries/5-4-3未入库依赖缺口]]。
