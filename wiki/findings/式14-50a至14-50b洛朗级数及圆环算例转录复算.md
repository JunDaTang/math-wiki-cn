# 式 14.50a–14.50b 洛朗级数及圆环算例转录复算

对 14.3.4 洛朗展开式 (14.50a/b) 的转录，及对圆环算例 $\frac{1}{(z-1)(z-2)}$ 的独立复算。

## 转录内容

```latex
(14.50a) f(z) = Σ_{n=-∞}^∞ a_n (z - z_0)^n
(14.50b) a_n = (1/2πi) ∮_C f(ζ)/(ζ - z_0)^{n+1} dζ     (n = 0, ±1, ±2, ...)

【算例】圆环 1 < |z| < 2，z_0 = 0：
f(z) = 1/((z-1)(z-2)) = -Σ_{n=1}^∞ 1/z^n - (1/2)Σ_{n=0}^∞ (z/2)^n
     = Σ_{n=-∞}^∞ a_n z^n,
其中 a_n = -1 (n = -1, -2, ...),  a_n = -1/2^{n+1} (n = 0, 1, 2, ...)
```

## 独立复算

1. 部分分式：$\frac{1}{(z-1)(z-2)} = \frac{1}{z-2} - \frac{1}{z-1}$（通分核验：分子 $(z-1)-(z-2) = 1$）。✓
2. $\frac{1}{z-1} = \frac{1}{z}\cdot\frac{1}{1-1/z} = \sum_{n\ge1} z^{-n}$，收敛条件 $|1/z| < 1$ 即 $|z| > 1$。✓
3. $\frac{1}{z-2} = -\frac{1}{2}\cdot\frac{1}{1-z/2} = -\frac{1}{2}\sum_{n\ge0}\left(\frac{z}{2}\right)^n$，收敛条件 $|z| < 2$。✓
4. 合并：$f(z) = -\sum_{n\ge1} z^{-n} - \frac{1}{2}\sum_{n\ge0}\left(\frac{z}{2}\right)^n$，即 $a_n = -1$（$n \le -1$）、$a_n = -1/2^{n+1}$（$n \ge 0$）。与原书一致。✓
5. 收敛域：两级数均在 $1 < |z| < 2$ 中绝对收敛，恰为含于定义域 $\mathbb{C}\setminus\{1,2\}$、围绕 0 的最大圆环，与原书“收敛域是整个包含在定义域中的最大圆环”一致。✓

## 结论

复算与原书完全一致，confidence: high，replicated: true。
