# 式 13.36–13.39 各坐标系梯度公式转录复算

## 转录

```latex
(13.36)  grad U = ∂U(x,y,z)/∂x i⃗ + ∂U(x,y,z)/∂y j⃗ + ∂U(x,y,z)/∂z k⃗
% 柱面坐标系 (x = ρ cos φ, y = ρ sin φ, z = z)
(13.37a) grad U = grad_ρ U e⃗_ρ + grad_φ U e⃗_φ + + grad_z U e⃗_z   % 「+ +」疑重复加号
(13.37b) grad_ρ U = ∂U/∂ρ,  grad_φ U = (1/ρ) ∂U/∂φ,  grad_z U = ∂U/∂z
% 球面坐标系 (x = r sin ϑ cos φ, y = r sin ϑ sin φ, z = r cos ϑ)；原文「sin fJ」为 ϑ 之 OCR 误读
(13.38a) grad U = grad_r U e⃗_r + grad_ϑ U e⃗_ϑ + grad_φ U e⃗_φ
(13.38b) grad_r U = ∂U/∂r,  grad_ϑ U = (1/r) ∂U/∂ϑ,  grad_φ U = (1/(r sin ϑ)) ∂U/∂φ
% 一般直角坐标系 (ξ, η, ζ)：r⃗(ξ,η,ζ) = x(ξ,η,ζ) i⃗ + y(ξ,η,ζ) j⃗ + z(ξ,η,ζ) k⃗
(13.39a) grad U = grad_ξ U e⃗_ξ + grad_η U e⃗_η + grad_ζ U e⃗_ζ
(13.39b) grad_ξ U = (1/|∂r⃗/∂ξ|) ∂U/∂ξ,  grad_η U = (1/|∂r⃗/∂η|) ∂U/∂η,
         grad_ζ U = (1/|∂r⃗/∂ζ|) ∂U/∂ζ
```

## 复算

**式 (13.36)**：梯度的标准笛卡儿表示，逐分量即偏导数。**正确**。

**式 (13.37a/b)**：度规因子 $h_\rho = 1,\ h_\varphi = \rho,\ h_z = 1$。链式法则复算：$\frac{\partial U}{\partial \rho} = \cos\varphi\, U_x + \sin\varphi\, U_y$，恰为梯度在 $\vec{e}_\rho = \cos\varphi\,\vec{i} + \sin\varphi\,\vec{j}$ 上的分量；$\frac{\partial U}{\partial \varphi} = -\rho\sin\varphi\, U_x + \rho\cos\varphi\, U_y$，除以 $\rho$ 后恰为在 $\vec{e}_\varphi = -\sin\varphi\,\vec{i} + \cos\varphi\,\vec{j}$ 上的分量；$z$ 分量显然。**正确**。(13.37a) 原文「+ +」为转写讹误，应删一个加号（见 [[queries/式13-37a柱面梯度公式疑重复加号]]）。

**式 (13.38a/b)**：度规因子 $h_r = 1,\ h_\vartheta = r,\ h_\varphi = r\sin\vartheta$。链式法则复算各分量与 $\vec{e}_r, \vec{e}_\vartheta, \vec{e}_\varphi$ 上的投影一致。**正确**。原文坐标定义中「sin fJ」为 $\vartheta$ 的 OCR 误读，与 [[queries/表13-1的Vϑ行sinφ疑为sinϑ]] 指向同一 $\vartheta$ 转写问题。

**式 (13.39a/b)**：与一般正交坐标系的度规因子公式 $\operatorname{grad}_i U = \frac{1}{h_i} \frac{\partial U}{\partial q_i}$（$h_i = \left| \partial \vec{r} / \partial q_i \right|$）一致。**正确，但隐含坐标系正交性**：非正交系下梯度分量含交叉项，不等于各坐标偏导数的简单缩放。已立 [[queries/一般直角坐标系是否限于正交坐标系]] 追踪。

## 结论

四套坐标公式本身复算全部正确；(13.37a) 的重复加号与「sin fJ」为转写讹误；(13.39b) 的适用范围（正交性前提）需在引用时注明。
