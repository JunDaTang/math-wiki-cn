# 等腰梯形面积公式（式 3.32）

对等腰梯形（源文「对千（于）等腰梯形有 $d = c$」，即两腰 $c = d$）：

$$S = (a - c\cos\gamma)c\sin\gamma = (b + c\cos\gamma)c\sin\gamma \tag{3.32}$$

其中 $\gamma$ 为腰 $c$ 与底 $a$ 的夹角（底角，依图 3.19 标注；正文未显式定义该角）。

## 复核（本 wiki 补充推导，与导入分析的代数复核一致）

等腰梯形中底与腰的几何关系为 $a = b + 2c\cos\gamma$，高 $h = c\sin\gamma$。代入式 3.30：

$$S = \frac{(a+b)h}{2} = \frac{(2b + 2c\cos\gamma)\,c\sin\gamma}{2} = (b + c\cos\gamma)c\sin\gamma$$

再用 $b = a - 2c\cos\gamma$ 即得另一半形式 $(a - c\cos\gamma)c\sin\gamma$。两形式相等即 $a = b + 2c\cos\gamma$ 的重述。

## 适用范围

仅对等腰梯形成立（依赖 $c = d$ 的对称性）；一般梯形应使用式 3.29–3.30（见 [[findings/梯形中位线面积与质心]]）。
