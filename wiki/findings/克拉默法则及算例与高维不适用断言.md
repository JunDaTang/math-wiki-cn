# 克拉默法则、算例与高维不适用断言（式 4.184，已复算）

克拉默法则（4.5.2.3）：当方程个数等于未知数个数且系数行列式 D = det A ≠ 0（式 4.184a–b）时，唯一解为 x_ν = D_ν/D（式 4.184c），D_ν 为以常数项 a_μ 替换 D 的第 ν 列元素 a_μν 所得的行列式（式 4.184d）。退化情形：D = 0 且至少一个 D_ν ≠ 0 → 无解；D = 0 且所有 D_ν = 0 → 「方程组可能有解但不唯一」（源的原表述；该情形也可能无解，表述不完整，源自我提示「参见第 417 页注」，见 [[concepts/克拉默法则]]）。

算例（2x₁ + x₂ + 3x₃ = 9；x₁ − 2x₂ + x₃ = −2；3x₁ + 2x₂ + 2x₃ = 7）：

```
D = 13,  D₁ = −13,  D₂ = 26,  D₃ = 39   →   x = (−1, 2, 3)
```

四个行列式与解均已独立复算吻合，并回代原方程组验证成立。

## 高维不适用断言（源的定性断言）

源明确断言：从实用性考虑，克拉默法则对于高维问题不适用，因为问题的维数增加时所要求的运算量很快增加；因此对于线性方程组的数值解应应用高斯算法或选主元法以及迭代程序（参见第 1233 页 19.1.1，未入库）。该断言为权威手册的定性判断，源内未给运算量的定量数据；比较见 [[comparisons/克拉默法则与高斯算法比较]]。
