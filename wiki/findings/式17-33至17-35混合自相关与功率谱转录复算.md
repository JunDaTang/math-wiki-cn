# 式 17.33–17.35 混合、自相关与功率谱转录复算

本条目记录数学手册 17.2.1.2 中混合定义 (17.33)、自相关函数 (17.34a/b)、功率谱 (17.35a/b) 及周期/拟周期谱算例的转录与独立复算。

## 转录

```latex
lim_{t->+infty} int_M [g(phi^{t}(x)) - g_bar][h(x) - h_bar] d mu = 0        % (17.33)
C_h(tau) = lim_{T->infty} (1/T) int_0^T h(phi^{t+tau}(x)) h(phi^{t}(x)) dt - h_bar^2   % (17.34a)
C_h(tau) = lim_{n->infty} (1/n) sum_{i=0}^{n-1} h(phi^{i+tau}(x)) h(phi^{i}(x)) - h_bar^2 % (17.34b)
P_h(omega) = int C_h(tau) e^{-i omega tau} d tau = 2 int_0^infty C_h(tau) cos(omega tau) d tau  % (17.35a)
P_h(omega) = C_h(0) + 2 sum_{k=1}^{+infty} C_h(k) cos(omega k)              % (17.35b)
% 周期轨（omega_0 = 2 pi / T）：
C_h(tau) = sum_k |alpha_k|^2 cos(k omega_0 tau),  P_h(omega) = 2 pi sum_k |alpha_k|^2 delta(omega - k omega_0)
% 拟周期轨（双频率）：
C_h(tau) = sum_{k1,k2} |alpha_{k1 k2}|^2 cos((k1 omega_1 + k2 omega_2) tau)
P_h(omega) = 2 pi sum_{k1,k2} |alpha_{k1 k2}|^2 delta(omega - k1 omega_1 - k2 omega_2)
```

## 复算验证

1. **混合 ⟹ 遍历**：不变集 $A$（$\varphi^{-t}(A)=A$）满足 $\mu(A)^2=\lim_t\mu(A\cap\varphi^{-t}(A))=\mu(A)$，故 $\mu(A)\in\{0,1\}$。✓（证明正确；源文结尾「μ(A)=0 1」脱「或」字，[[queries/混合蕴含遍历证明脱或字之辨]]。）
2. **(17.33) 与集合式定义的相容性**：取示性型函数时 $L^2$ 形式化为 $\mu(A\cap\varphi^{-t}(B))\to\mu(A)\mu(B)$，两定义口径一致。✓
3. **(17.34a/b) 平移减 $\bar h^2$**：标准协方差口径，偶性延拓正确（源文「厌」为 $\mathbb{R}$ 之讹）。✓
4. **周期轨谱公式**：$h(\varphi(t))=\sum_k\alpha_k e^{\mathrm{i}k\omega_0 t}$，时间平均乘积中交叉项因 $\frac{1}{T}\int e^{\mathrm{i}(k-j)\omega_0 t}\mathrm{d}t=\delta_{kj}$ 消去，得 $C_h(\tau)=\sum_k|\alpha_k|^2e^{\mathrm{i}k\omega_0\tau}$；实值性 $|\alpha_{-k}|=|\alpha_k|$ 使虚部成对消去，化为 $\sum_k|\alpha_k|^2\cos(k\omega_0\tau)$。取傅里叶变换：$\cos(k\omega_0\tau)\to\pi[\delta(\omega-k\omega_0)+\omega+k\omega_0]$，经 $k\leftrightarrow-k$ 换名合并得 $P_h=2\pi\sum_k|\alpha_k|^2\delta(\omega-k\omega_0)$。✓
5. **拟周期双频公式**：结构同理（双指标、和频差频整系数组合）。✓
6. **(17.35a) 等式**：$C_h$ 偶 ⟹ 虚部积分为零，$2\int_0^\infty C_h\cos(\omega\tau)\,\mathrm{d}\tau$ 成立（源文「2 _0^{i n f t y}」为「$2\int_0^\infty$」之讹）。✓
7. **例证归属**：[[concepts/伯努利转移映射]]「是混合的」成立（标准结果）；[[concepts/圆周旋转映射]]「是混合的」不成立（见 [[findings/式17-31至17-32旋转映射遍历性与SRB测度转录复算]]）。

## 转写差异

- 「在宽带谱中出现奇异峰值可被认为混沌行为标志」疑有脱讹（常规判据为宽带连续谱标志混沌），措辞待查原文。
- 判据句「$C_h(\tau)$ 随 的增加」脱 $\tau$；多处同类脱字并入 [[queries/17-2全节系统性转写讹误清单]]。
