# 双曲线理论公式组（式 3.330–3.339，含渐近线面积不变量 ab、ab/2）

要素：实轴 2a、虚轴 2b = 2√(c²−a²)、数值离心率 e = c/a > 1、半焦弦 p = b²/a。

```
标准方程:  x²/a² − y²/b² = 1                                   (3.330a)
参数式:    x = ±a·cosh t,  y = b·sinh t                         (3.330b)
          x = ±a/cos t,  y = b·tan t  (−π/2 < t < π/2)          (3.330c)
焦半径:    r₁ = ±(e·x − a),  r₂ = ±(e·x + a),  r₂ − r₁ = ±2a    (3.331，右支取正号)
准线:      r₁/d₁ = r₂/d₂ = e（原文 d = a/c，疑为 a/e 之讹）      (3.332)
切线:      x·x₀/a² − y·y₀/b² = 1（转写误作 a₂、b₂）              (3.333)
切线判别:  A²a² − B²b² = C²                                     (3.334)
渐近线:    y = ±(b/a)·x                                         (3.335)
渐近三角形面积:  S_TOT₁ = ab（与切点无关）                        (3.336)
渐近平行四边形面积:  S_OFPG = ab/2（与切点无关）                  (3.337)
共轭双曲线:  x²/a² − y²/b² = 1 与 y²/b² − x²/a² = 1              (3.338)
共轭直径:  k·k′ = +b²/a²（与椭圆反号），|k| < b/a 者与曲线相交
阿波罗尼奥斯定理（差式型, β < α）:
  a₁² − b₁² = a² − b²,  ab = a₁·b₁·sin(α − β)                   (3.339)
```

## 已验证项

- 焦半径符号体系（右支 r₂ − r₁ = 2a 取正号，左支取负号）复算自洽（视为已复算）。
- 切线段 TT₁ 以切点为中点（TP = T₁P）及面积不变量 ab、ab/2 属双曲线自身的命题，与渐近线斜率 ±b/a 相容。

## 转写疑点（集中清单见 [[queries/双曲线小节疑似讹误清单]]）

- 准线距离「d = a/c」疑为 a/e 之讹（与椭圆小节 d = a/e 体例及标准结果 x = ±a/e 不符）。
- (3.333) 分母 a₂、b₂ 应为 a²、b²。
- (3.334) 之后原文「是该**椭圆**的切线」应为「该**双曲线**」——复制残留，涉及实体归属，不得跨实体转述。

与椭圆的系统对照（和↔差、−b²/a²↔+b²/a²）见 [[comparisons/椭圆双曲线抛物线比较]]；面积、弧长与等边双曲线见 [[findings/双曲线面积弧长与等边双曲线]]。
