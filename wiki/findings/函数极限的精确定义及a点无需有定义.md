# 函数极限的 ε-η 精确定义及 a 点无需有定义（式 2.14–2.15b）

**发现**：《数学手册(原书第10版)》2.1.4.1 以 $\varepsilon$-$\eta$ 语言给出函数极限的精确定义，并明确极限存在不要求函数在该点有定义。

直观记号（式 2.14）：$\lim_{x\to a}f(x)=A$ 或 $f(x)\to A\ (x\to a)$。

精确定义（原文逐字，式 2.15a 为 $\lvert x-a\rvert<\eta$，式 2.15b 为 $\lvert f(x)-A\rvert<\varepsilon$，图 2.7 给出图示）：

```text
若对任意正数 ε，都存在正数 η，使得对定义域中的每个 x，
当 x ≠ a 且 |x − a| < η 时，|f(x) − A| < ε 恒成立，
则称极限 lim_{x→a} f(x) = A 存在。
```

**要点**：

1. $f(x)$ 在 $a$ 点不一定有定义；即便有定义，$f(a)$ 也未必等于 $A$。
2. 手册以 $\eta$ 代通行教材的 $\delta$，是该书的记号特色。
3. 若 $a$ 是区间的端点，$\lvert x-a\rvert<\eta$ 可简化为 $a-\eta<x$ 或 $x<a+\eta$（手册自注“也可参见第 70 页 2.1.4.5”，与单侧极限衔接）。
4. 定义限定“对定义域中的每个 $x$”，与 $x\neq a$ 的去心要求配合，保证只考察趋近行为本身。

此为标准教科书理论，证据为直接转写，与后续小节的算例体系自洽。概念页见 [[concepts/函数的极限]]。
