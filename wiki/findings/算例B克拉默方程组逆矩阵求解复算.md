# 算例 B 克拉默方程组逆矩阵求解复算

**结论**：数值链条全部复算通过——Det[p] = 13；解 t = {−1, 2, 3} 经三条独立路径（逆矩阵、直接回代、Cramer 分子行列式）交叉验证一致。但转录的 In[4]（`Inverse[p]`）与 Out[4]（解向量）内部不对应，疑脱「.b」，详见 [[In4之Inverse-p与Out4解向量不对应疑脱点b之辨]]。

## 会话转录

```text
In[1]:= MatrixForm[p = {{2,1,3},{1,-2,1},{3,2,2}}]
Out[1]=    2   1   3
           1  -2   1
           3   2   2

In[2]:= t = Array[x, 3]
Out[2]= {x[1], x[2], x[3]}

In[3]:= b = {9, -2, 7}
Out[3]= {9, -2, 7}

In[4]:= Inverse[p]          （原文如此，疑脱 ".b"）
Out[4]= {-1, 2, 3}
```

## 复算

方程组 p·t = b，其中 p = {{2,1,3},{1,−2,1},{3,2,2}}，b = {9,−2,7}。

1. **行列式**：Det[p] = 2·(−4−2) − 1·(2−3) + 3·(2+6) = −12 + 1 + 24 = **13** ✓（与原文 Det[p] == 13 ≠ 0 吻合，故 t = p⁻¹b 存在）。
2. **逆矩阵**（伴随法）：Inverse[p] = (1/13)·{{−6,4,7},{1,−5,1},{8,−1,−5}}；验算 p·Inverse[p] = I₃。✓
3. **解向量**：Inverse[p].b = (1/13)·{−13, 26, 39} = **{−1, 2, 3}** ✓
   （逐分量：−6·9+4·(−2)+7·7 = −13；1·9+(−5)·(−2)+1·7 = 26；8·9+(−1)·(−2)+(−5)·7 = 39。）
4. **直接回代**：p.{−1,2,3} = {2·(−1)+1·2+3·3, 1·(−1)+(−2)·2+1·3, 3·(−1)+2·2+2·3} = {9, −2, 7} = b ✓
5. **Cramer 交叉验证**：分子行列式 det(b,p₂,p₃) = −13、det(p₁,b,p₃) = 26、det(p₁,p₂,b) = 39，除以 Det[p]=13 得 t = {−1, 2, 3} ✓

## 内部不一致（重要）

转录 In[4] 作 `Inverse[p]`，而 Out[4] = {−1, 2, 3} 为解向量：`Inverse[p]` 单独求值的输出应为逆矩阵 (1/13){{−6,4,7},{1,−5,1},{8,−1,−5}}；解向量对应 `Inverse[p].b`（Mathematica 中亦可用 `LinearSolve[p,b]`，此为可独立验证的背景）。三种可能：转写脱「.b」（最可能——同句 `Ln[4]`/`0ut[4]` 亦有字符之讹）、原书行文从简、原书即误。需原书核对。

## 证据评估

直接证据（转录原文）+ 三路独立复算交叉一致。置信度：高。
