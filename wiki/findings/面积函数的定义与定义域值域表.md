# 面积函数的定义、单调性与定义域值域（式 2.207–2.210、表 2.8）

## 发现陈述

手册 2.10.1 定义四种 [[concepts/面积函数]]（反双曲函数）并给出定义域与值域总表（表 2.8）：

- [[concepts/面积正弦]] $y = \operatorname{Arsinh} x$（式 2.207）：$\mathbb{R} \to \mathbb{R}$ 双射，严格单调递增的奇函数；原点为对称中心与拐点，该处切线倾角 $\varphi = \pi/4$。
- [[concepts/面积余弦]] $y = \pm\operatorname{Arcosh} x$（式 2.208）：仅当 $x \geqslant 1$ 有定义；$+\operatorname{Arcosh}$ 支严格递增、$-\operatorname{Arcosh}$ 支严格递减；起点 $A(1, 0)$ 处有垂直切线。
- [[concepts/面积正切]] $y = \operatorname{Artanh} x$（式 2.209）：奇函数，定义域 $|x| < 1$；原点为对称中心与拐点，切线倾角 $\pi/4$；铅直渐近线 $x = \pm 1$。
- [[concepts/面积余切]] $y = \operatorname{Arcoth} x$（式 2.210）：奇函数，定义域 $|x| > 1$；$(-\infty, -1)$ 上从 $0$ 递减至 $-\infty$，$(1, +\infty)$ 上从 $+\infty$ 递减至 $0$；三条渐近线 $y = 0$ 与 $x = \pm 1$。

## 表 2.8 的重构（补出分支对应）

转写后的表 2.8 因合并单元格拆散而丢失部分对应关系（见 [[queries/表2-8合并单元格转写错位如何修复]]）。依据正文 2.10.1.4 的分支陈述与表结构，重构如下（**此为推断性重构，非原文逐字**）：

| 面积函数 | 定义域 | 值域 | 具有相同意义的双曲函数 |
|---|---|---|---|
| y = Arsinh x | −∞ < x < ∞ | −∞ < y < ∞ | x = sinh y |
| y = Arcosh x | 1 ≤ x < ∞ | 0 ≤ y < ∞ | x = cosh y |
| y = −Arcosh x | 1 ≤ x < ∞ | −∞ < y ≤ 0 | x = cosh y |
| y = Artanh x | \|x\| < 1 | −∞ < y < ∞ | x = tanh y |
| y = Arcoth x（左分支） | −∞ < x < −1 | −∞ < y < 0 | x = coth y |
| y = Arcoth x（右分支） | 1 < x < ∞ | 0 < y < ∞ | x = coth y |

关键补正：Arcoth 的两行值域分别对应两个定义域分支——$(-\infty, -1) \to (-\infty, 0)$ 与 $(1, +\infty) \to (0, +\infty)$，此对应关系在合并表格结构中被掩盖。

## 验证

独立求导验证（与手册陈述对照）：

- Arsinh：$y' = 1/\sqrt{x^2+1}$，$y'(0) = 1$（倾角 $\pi/4$ ✓）；$y'' = -x/(x^2+1)^{3/2}$ 在 $x = 0$ 变号（原点为拐点 ✓）。
- Arcosh（递增支）：$y' = 1/\sqrt{x^2-1} \to \infty$（$x \to 1^+$，起点垂直切线 ✓）。
- Artanh / Arcoth 的定义域由对数表示（式 2.213/2.214）的真数条件直接读出 ✓。

证据类型：定义与表格为直接证据（原文）；分支对应重构为推断（依据 2.10.1.4 正文陈述）。

## 保留与疑点

1. 总定义句「$\sinh x$、$\tanh x$ 和 $\coth x$ 均严格单调，因此没有任何限制地具有唯一反函数」——就 coth 而言论证欠严：coth 在 $\mathbb{R}\setminus\{0\}$ 上跨间断点不单调（$x_1 = -1 < x_2 = 1$ 但 $f(x_1) < f(x_2)$），唯一反函数的真正依据是单射性，见 [[queries/coth严格单调故唯一反函数的表述是否欠严]]。
2. 正文 2.10.1.3 称 Artanh 定义域为 $|x| \leqslant 1$，与表 2.8、式 2.213 的 $|x| < 1$ 矛盾，见 [[queries/正文Artanh定义域绝对值小于等于1是否应为小于1]]。
