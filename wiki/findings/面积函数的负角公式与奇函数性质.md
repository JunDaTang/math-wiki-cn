# 面积函数的负角公式与奇函数性质（式 2.222–2.224）

## 发现陈述

手册 2.10.5 给出：

```latex
\operatorname{Arsinh} (- x) = - \operatorname{Arsinh} x    (2.222)
\operatorname{Artanh} (- x) = - \operatorname{Artanh} x    (2.223)
\operatorname{Arcoth} (- x) = - \operatorname{Arcoth} x    (2.224)
```

三条均为奇函数性质 $f(-x) = -f(x)$。它们与双曲函数侧的奇性（sinh、tanh、coth 为奇）互为镜像：奇函数的反函数仍为奇。

**Arcosh 无对应式**：$x < 1$ 时 $\operatorname{Arcosh} x$ 无定义（手册正文明确此句），且 $-\operatorname{Arcosh}$ 支与 $+\operatorname{Arcosh}$ 支关于 $x$ 轴对称而非原点对称，故 Arcosh 非奇非偶。

## 验证

由对数表示直接验证，例：

$$\operatorname{Arsinh}(-x) = \ln\left(\sqrt{x^2+1} - x\right) = \ln\frac{1}{\sqrt{x^2+1} + x} = -\operatorname{Arsinh} x \quad \checkmark$$

其中用到 $(\sqrt{x^2+1}+x)(\sqrt{x^2+1}-x) = 1$。三条验证一致。

## 术语与转写注记

- **标题名不副实**：「负角公式」沿用 2.7–2.9 的平行标题样式，但面积函数的自变量并非角——实为奇性公式 $f(-x) = -f(x)$。
- 正文末句「函数 Arsinh x, Artanhx 和 Arcothx 为奇函数」中「Artanhx」「Arcothx」为转写粘连残留（应为 Artanh x、Arcoth x），与 [[queries/式2-206的icot-iz是否为i-cot-iz粘连]] 同类现象。

证据类型：直接证据（原文公式）+ 独立验证。
