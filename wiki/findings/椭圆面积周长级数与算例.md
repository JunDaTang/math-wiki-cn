# 椭圆面积周长级数与算例（式 3.328–3.329，L≈7.932721 已复算）

## 面积（3.328）

```
椭圆:      S = πab                                    (3.328a)
扇形 BOP:  S_BOP = (ab/2)·arccos(x/a)                 (3.328b)
弓形 PBN:  S_PBN = ab·arccos(x/a) − x·y               (3.328c)
```

弓形公式（对称帽区）已经积分验证成立（视为已复算）。

## 周长（3.329）：第二类完全椭圆积分及四种计算途径

椭圆弧长不能用初等方法计算，需第二类（不完全）椭圆积分 E(k, φ)；周长由第二类完全椭圆积分给出：

```
L = 4a·E(e) = 4a·∫₀^{π/2} √(1 − e²sin²ψ) dψ,  e = √(a²−b²)/a        (3.329a)
级数（e 幂级数）:
L = 2πa[1 − (1/2)²e² − ((1·3)/(2·4))²·e⁴/3 − ((1·3·5)/(2·4·6))²·e⁶/5 − …]   (3.329b)
级数（λ 幂级数）:
L = π(a+b)(1 + λ²/4 + λ⁴/64 + λ⁶/256 + 25λ⁸/16384 + …),  λ = (a−b)/(a+b)  (3.329c)
近似式:
L ≈ π[1.5(a+b) − √(ab)]                                              (3.329d)
L ≈ π(a+b)·(64 − 3λ⁴)/(64 − 16λ²)                                    (3.329e)
```

另两条途径：查原书第 1424 页表 21.9（第二类完全椭圆积分表）；对 (3.329a) 数值积分。前向引用：8.1.4.3（第 654 页）、8.2.2.2（第 668 页）。

## 算例（a = 1.5, b = 1）——数值自洽（已复算）

| 途径 | 结果 |
|---|---|
| (3.329e) | L ≈ 7.9327 |
| 查表 21.9 | L ≈ 7.94 |
| 数值积分 | L ≈ 7.932721 |

独立复算 (3.329e)：λ = (1.5−1)/2.5 = 0.2，比值 (64 − 3·0.2⁴)/(64 − 16·0.2²) = 63.9952/63.36 = 1.0100253，L = 2.5π × 1.0100253 = 7.93274 ✓ 与原文 7.9327 一致；级数 (3.329c) 展开至 λ⁴ 亦与 (3.329e) 吻合。计算流程的系统讨论见 [[methodology/椭圆周长的实用计算]]。
