# 误差曲线的对称性、极值与拐点公式（式 2.58–2.59）

手册 2.6.3 给出 [[误差曲线]] $y = \mathrm{e}^{-(ax)^{2}}$（高斯误差分布曲线）的图像要素：

- **对称性**：偶函数，关于 y 轴对称；
- **极大值**：x = 0 处取得极大值 1，极值点 A(0, 1)；
- **拐点**：B, C 在 $\left(\pm\frac{1}{a\sqrt{2}},\ \frac{1}{\sqrt{\mathrm{e}}}\right)$，拐点处切线斜率 $\tan\varphi = \mp a\sqrt{2/\mathrm{e}}$；
- **渐近**：|a| 越大，渐近趋近 x 轴的速度越快。

**复核（通过）**：由 y″ = 0 代数求解得 $x = \pm\frac{1}{a\sqrt{2}}$；数值代入 a = 1（即 y = e^{−x²}）得拐点横坐标 ±1/√2、纵坐标 e^{−1/2}，均吻合。小瑕疵（非错误）：横坐标 ±1/(a√2) 隐含 a > 0，而速度句使用 |a|。

**与正态分布的连接**：手册随即给出观测误差正态分布的密度（式 2.59）$\varphi(x) = \frac{1}{\sigma\sqrt{2\pi}}\exp\left(-\frac{x^{2}}{2\sigma^{2}}\right)$，即 (2.58) 乘以归一化常数并取 a = 1/(σ√2)；(2.59) 未声明 σ > 0。完整论述见第 16 章（16.2.4.1、16.4.1.2,3），待该章摄入后回链。

判定：**成立**（公式全部验证通过）。
