# 贝格定理翻转构造与 M₁→M₂ 算例

《数学手册(原书第10版)》5.8.4 条目 4 给出 [[concepts/贝格定理]]（极大性 ⟺ 无递增路）及递增路翻转构造，并回到图 5.55 演示 M₁ → M₂。翻转构造经本维基复算核验。

## 原文（逐字重构，▯ 为转写脱落处）

```text
▯ 中匹配 ▯ 是极大的，当且仅当 ▯ 中不存在递增交错路。
如果 ▯ 是一条递增交错路，并且对应的遍历边的集合是 E(W)，那么
  M′ = (M ∖ E(W)) ∪ (E(W) ∖ M) 形成 ▯ 中一个匹配，并且 |M′| = |M₁| + 1。

• 在图 5.55 中，（｛ 1,2},{2,3},{3,4}）是对于匹配 M₁ 的递增交错路，
  如上面所述得到匹配 M₂，并且 |M₂| = |M₁| + 1。
```

## 复算（图 5.55；直接证据）

设 M₁ = {{2,3},{5,6}}，W = ({1,2},{2,3},{3,4})：

- W 关于 M₁ **交错**：非 M₁ 边 {1,2} → M₁ 边 {2,3} → 非 M₁ 边 {3,4} ✓
- W **递增**：端点 1、4 均不与 M₁ 的边关联（M₁ 仅覆盖 2、3、5、6）✓
- **翻转**：E(W)∖M₁ = {{1,2},{3,4}}，M₁∖E(W) = {{5,6}}，故 M′ = {{1,2},{3,4},{5,6}} = M₂ ✓
- **基数**：|M₂| = 3 = |M₁| + 1 ✓；且 M₂ 覆盖全部 6 个顶点，为完全匹配 ✓

## 讹误判定

- 定理句的 |M′| = |M₁| + 1：定理语境中 M₁ 无定义，应为 **|M| + 1**；紧随的算例句 |M₂| = |M₁| + 1 正确。判断为**算例下标窜入定理**所致（转写或原书排印层面待查）。追踪页：[[queries/贝格翻转公式m1是否应为m]]。
- 括号全半角混用「（｛ 1,2},{2,3},{3,4}）」、「对千」→「对于」。见 [[queries/5-8-4全节系统性转写讹误清单]]。

## 判定

- 定理陈述与通行结果一致，翻转构造经算例复算验证，强度**强**。
- 本算例同时演示「饱和 ⇏ 极大」的机制：M₁ 饱和却存在递增路，翻转后基数增一（参见 [[findings/匹配定义四分与图5-55算例]]）。
