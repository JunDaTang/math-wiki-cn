# 指数函数的单调性与渐近行为（式 2.54–2.55）

手册 2.6.1 给出 [[指数函数]] $y = a^{x} = \mathrm{e}^{bx}$（a > 0，b = ln a）的完整图像要素：

- **定义域 / 值域**：(−∞, +∞) / (0, +∞)，只取正值。
- **单调性**：a > 1（b > 0）严格递增，值 0 → +∞；a < 1（b < 0）严格递减，值 +∞ → 0。
- **定点**：(0, 1)。
- **渐近线**：b > 0 时左侧趋近 x 轴；b < 0 时右侧趋近 x 轴。
- **速度**：|b| 越大，增/减越快，趋近 x 轴越快。
- **倒底变换**：$a^{-x} = (1/a)^{x}$，a < 1 时增、a > 1 时减（增减性反转）。

令 a = e 得自然指数曲线 y = e^x（式 2.55）。

**复核（通过）**：以上均为标准结论，直接验证成立——y′ = b·e^{bx} 与 b 同号定单调性；y(0) = 1；b > 0 时 $\lim_{x\to-\infty}\mathrm{e}^{bx} = 0$（b < 0 时对称）。判定：**成立**。

**意义**：本 finding 为 [[对数函数]]（其反函数）及 §2.6 其余四族的渐近与量级分析提供基元；[[朗道符号定义与指数对数量级结论]] 中指数函数的量级结论至此有了正式定义的函数本体。
