# 式 19.93–19.98 初值问题与欧拉多边形法转录复算

**转录**（源文公式逐字保留）：

```latex
(19.93)  y' = f(x, y),  y(x_0) = y_0
(19.94)  x_i = x_0 + i h  (i = 0,1,2,\dots)
(19.95)  y(x) = y_0 + \int_{x_0}^{x} f(x, y(x))\, dx
(19.96)  y(x_1) = y_0 + \int_{x_0}^{x_0+h} f(x,y(x))\,dx \approx y_0 + h f(x_0, y_0) = y_1
(19.97)  y_{i+1} = y_i + h f(x_i, y_i)  (i = 0,1,2,\dots; y(x_0) = y_0)
(19.98)  y(x_1) = y_0 + f(x_0,y_0)h + \frac{y''(\xi)}{2}h^2,  x_0 < \xi < x_0+h
```

**验证与评注**：

- 推演自洽性（直接证据）：对比 (19.96) 与泰勒展开 (19.98)，矩形近似恰好舍弃 y″(ξ)h²/2 项，故“近似值 y₁ 具有 h² 阶误差”成立；本条为解析推演，未做数值复算。
- “步长减半可使近似值 y_i 的误差减半”为源文的实际计算经验陈述（与一阶方法整体误差 O(h) 的量级一致），系源内断言，未独立复算。
- 转写疑误：源文在 (19.95) 前将初值问题引作 "(19.33)"，本节初值问题编号为 (19.93)，见 [[queries/式19-95前回指19-33疑为19-93之辨]]。

见 [[concepts/常微分方程初值问题]]、[[concepts/欧拉多边形法]]。
