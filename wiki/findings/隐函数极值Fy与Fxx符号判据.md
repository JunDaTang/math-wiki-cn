# 隐函数极值的 $F_y$ 与 $F_{xx}$ 符号判据（含推导复核）

## 手册原文（直接证据）

6.1.5.5：若函数由隐形式 $F(x,y)=0$ 给出，且函数本身及其偏导数 $F_x$、$F_y$ 连续，则其极大值和极小值可按如下方式确定：

1. 解方程组 $F(x,y)=0$、$F_x(x,y)=0$，把得到的结果 $(x_1,y_1),(x_2,y_2),\dots,(x_i,y_i),\dots$ 代入到 $F_y$、$F_{xx}$；
2. 对比 $F_y$、$F_{xx}$ 在点 $(x_i,y_i)$ 的符号：**异号 ⇒ 极小值；同号 ⇒ 极大值**。若 $F_y$ 或 $F_{xx}$ 在 $(x_i,y_i)$ 取值为 0，则需要用更复杂的方法去研究。

## 独立推导复核（推断，方向一致）

由 [[concepts/隐函数求导]]，$y'=-F_x/F_y$；在候选点处 $F_x=0$，故 $y'=0$（驻点）。沿曲线对 $x$ 再求导：

$$y''=-\frac{(F_{xx}+F_{xy}\,y')F_y-F_x\,(F_{yx}+F_{yy}\,y')}{F_y^2}\ \xrightarrow[\ y'=0,\ F_x=0\ ]{}\ -\frac{F_{xx}}{F_y}.$$

于是：

- $F_y$ 与 $F_{xx}$ **异号**（$F_yF_{xx}<0$）⇒ $y''>0$ ⇒ **极小值**，与手册一致 ✓
- $F_y$ 与 $F_{xx}$ **同号**（$F_yF_{xx}>0$）⇒ $y''<0$ ⇒ **极大值**，与手册一致 ✓

即隐式判据是显函数二阶判据（[[concepts/高阶导数法]]）在隐式坐标下的表达，判据方向复算无误。

## 张力

- 判据隐含前提 $F_y\neq0$（隐函数存在且可求导）；手册仅以“$F_y$ 取值为 0 则需更复杂的方法”带过，未明示其与隐函数存在性的关系。
- 退化情形（$F_y=0$ 或 $F_{xx}=0$）手册未展开，对应显函数情形的“逐阶上推”无隐式版本。
- 操作流程见 [[methodology/隐函数极值判定流程]]，与显函数路径的比较见 [[comparisons/显函数与隐函数极值判定比较]]。
