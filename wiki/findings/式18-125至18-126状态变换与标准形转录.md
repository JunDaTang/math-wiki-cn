# 式 18.125–18.126 状态变换与动态规划标准形转录

## 转录内容（逐字）

```latex
% (18.125) 状态变换
x_j = g_j(x_{j-1}, u_j),  j = 1(1)n

% (18.126a) 动态规划标准形
OF: f(f_1(x_0,u_1), …, f_n(x_{n-1},u_n)) → min!
CT: x_j = g_j(x_{j-1},u_j),  j = 1(1)n
    x_0 = x_a,  x_n = x_e ∈ X_e,  x_j ∈ X_j ⊆ ℝ^m,  j = 1(1)n
    u_j ∈ U_j(x_{j-1}) ⊆ ℝ^m,  j = 1(1)n
```

（18.126b 的式号在转写中悬空，无对应内容。）

## 转录核对与讹误记录

- 式 (18.125) 与正文一致，无讹误。
- 式 (18.126a) 末行 $U_j(x_{j-1})\subseteq\mathbb{R}^m$ 与 18.3.1.1 正文 $U_j(x_{j-1})\subseteq\mathbb{R}^s$ 矛盾，疑为 $\mathbb{R}^s$。
- 正文 $X_e\subseteq\mathbb{R}_m$ 的下标 $m$ 疑应为上标 $\mathbb{R}^m$。
- 「满足所有约束条件的策略称作可行约束」疑为「可行策略」。
- 静态约束中 $x_n=x_e\in X_e$：终态属于给定集合 $X_e$（允许终态不唯一）。
