# 式 9.76 完全积分与特征带转录复算

本条目逐字转录一阶非线性偏微分方程的一般形式、[[concepts/完全积分]] 的定义与雅可比条件、以及 [[concepts/特征带]] 的特征方程组（式 9.76a–f），并作结构核对与守恒性复算。

## 逐字转录

```latex
F(x₁,…,xₙ, z, ∂z/∂x₁, …, ∂z/∂xₙ) = 0                           (9.76a)
z = φ(x₁,…,xₙ, a₁,…,aₙ)                                        (9.76b)
∂(φₓ₁,…,φₓₙ)/∂(a₁,…,aₙ) ≠ 0                                    (9.76c)
dx₁/P₁ = … = dxₙ/Pₙ = dz/(p₁P₁+…+pₙPₙ)
   = −dp₁/(X₁+p₁Z) = … = −dpₙ/(Xₙ+pₙZ)                          (9.76d)
Z = ∂F/∂z,  Xᵢ = ∂F/∂xᵢ,  pᵢ = ∂z/∂xᵢ,  Pᵢ = ∂F/∂pᵢ             (9.76e)
F(x₁,…,xₙ, z, p₁,…,pₙ) = 0                                     (9.76f)
```

## 复算与结构核对

1. **完全积分的雅可比条件 (9.76c)**：∂(φₓ₁,…,φₓₙ)/∂(a₁,…,aₙ) ≠ 0 保证映射 a ↦ (p₁,…,pₙ) = ∇ₓφ 局部可逆，即 n 个参数 a₁,…,aₙ 本质独立、不能以更少参数重写；这正是「完全」二字的含义。
2. **Charpit 组结构核对**：(9.76d) 与标准 Lagrange–Charpit 特征方程组一致——dxᵢ 的分母为 Pᵢ = ∂F/∂pᵢ；dz 的分母 ΣpᵢPᵢ 来自带条件 dz = Σpᵢdxᵢ（切平面方程）；dpᵢ 的分母为 −(Xᵢ + pᵢZ)。✅
3. **约束守恒（关键自洽性）**：以参数 t 写 (9.76d) 为 ẋᵢ = Pᵢ、ż = ΣpᵢPᵢ、ṗᵢ = −(Xᵢ + pᵢZ)，则沿流

   dF/dt = ΣᵢXᵢPᵢ + Z·ΣᵢpᵢPᵢ + ΣᵢPᵢ·[−(Xᵢ + pᵢZ)] = 0。

   故约束 (9.76f) 沿特征组之解保持，「满足附加条件 F = 0 的解 = 特征带」这一定义自洽。✅
4. 特征带的几何解释（曲线 + 逐点切平面）在两变量情形由式 9.80 展开，见 [[findings/式9-80至9-81两变量特征带包络与全微分可积条件转录复算]]。

## 转写疑点

- 「是依赖千 个参数 a₁,…,aₙ 的解」缺数目词 n，且「千」讹「于」。
- 函数行列式（雅可比行列式）回指 2.18.2.6（第 159 页），未入库（见 [[queries/9-2-1未入库回指缺口]]）。

## 意义

非线性一阶方程不能沿用首次积分组合（[[findings/式9-71至9-72线性齐次方程特征组与首次积分等价性转录复算]] 的等价性仅限齐次线性情形），必须在 (x₁,…,xₙ, z, p₁,…,pₙ) 空间同时追踪未知函数及其偏导数——特征带正是这一追踪的载体。它向上衔接 [[concepts/典范微分方程组]]（方程不显含 z 时的对称化）与克莱罗特款（见 [[findings/式9-77至9-78典范组与克莱罗PDE转录复算]]）。
