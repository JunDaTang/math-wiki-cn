# 三种展开形式（式 7.112a–7.112c）

## 主张（依源转录）

区间 [0, l] 上满足狄利克雷条件（回指 7.4.1.2.3）的每个函数 f(x) 都可在该区间展成如下收敛级数：

```latex
% (7.112a) f1：周期延拓，周期 T = l，基频 2pi/l，系数由欧拉公式 (7.102a/b) 确定（omega = 2pi/l）
f_1(x) = a_0/2 + a_1 cos(2pi x/l) + a_2 cos(2·2pi x/l) + ... + a_n cos(n·2pi x/l) + ...
              + b_1 sin(2pi x/l) + b_2 sin(2·2pi x/l) + ... + b_n sin(n·2pi x/l) + ...

% (7.112b) f2：偶延拓，周期 T = 2l，基频 pi/l，具有第一类对称性
f_2(x) = a_0/2 + a_1 cos(pi x/l) + a_2 cos(2·pi x/l) + ... + a_n cos(n·pi x/l) + ...

% (7.112c) f3：奇延拓，周期 T = 2l，基频 pi/l，具有第二类对称性
f_3(x) = b_1 sin(pi x/l) + b_2 sin(2·pi x/l) + ... + b_n sin(n·pi x/l) + ...
```

连续点处各 f_i(x) 与 f(x) 相同；间断点处 f_i(x) = ½[f(x−0)+f(x+0)]。f₂ 的展开式系数由第一类对称公式（T = 2l）确定；f₃ 的系数由第二类对称公式（T = 2l）确定。

## 复算（通过）

1. **f₂ 的系数公式**：式 7.107 取 T = 2l：a_k = (4/(2l))∫₀^{l} f(x)cos(k·2πx/(2l))dx = **(2/l)∫₀^l f(x)cos(kπx/l)dx**，b_k = 0。基频核对：周期 2l ⟹ 基频 2π/(2l) = π/l，与式 7.112b 的 cos(kπx/l) 一致。✅
2. **f₃ 的系数公式**：式 7.108 取 T = 2l：b_k = **(2/l)∫₀^l f(x)sin(kπx/l)dx**，a_k = 0。基频同上核对一致。✅
3. **f₁ 的系数**：欧拉公式（式 7.102）取 T = l、ω = 2π/l。✅
4. **端点行为（解读性注记）**：手册对 f₂ 用闭区间 [0, l]、对 f₁/f₃ 用开区间 (0, l) 表述「与 f 相同」——与延拓性质一致：偶延拓在 x = 0, l 处保持单侧值连续，奇延拓在端点处强制取 0。
