# LFSR 状态转移与极大周期判据（7 状态已复算）

数学手册 5.3.7.4.2 说明多项式的计算可以由线性反馈移位寄存器（LFSR，图 5.18）很好地实施。

## 状态转移公式

对于基于反馈多项式

$$f(x) = f_0 + f_1 x + \cdots + f_{r-1} x^{r-1} + x^r$$

的线性反馈移位寄存器，由状态多项式 $s(x) = s_0 + s_1 x + \cdots + s_{r-1} x^{r-1}$ 可得到（下一）状态多项式

$$s(x) \cdot x - s_{r-1} \cdot f(x) = s(x) \cdot x \pmod{f(x)}.$$

特别地，如果 $s(x) = 1$，i 步（应用 i 次）后状态多项式是 $x^i \pmod{f(x)}$。

## 状态序列算例（f = 1 + x + x³，已复算 ✓）

选取本原多项式 $f(x) = 1 + x + x^3 \in \mathbb{Z}_2[x]$ 作为反馈多项式，长度为 3 的移位寄存器从初始状态 $100 \widehat{=} 1 \pmod{f(x)}$ 出发的状态序列为：

```
100 ≡ 1 → 010 ≡ x → 001 ≡ x² → 110 ≡ x³ ≡ 1+x → 011 ≡ x⁴ ≡ x+x²
→ 111 ≡ x⁵ ≡ 1+x+x² → 101 ≡ x⁶ ≡ 1+x² → 100 ≡ x⁷ ≡ 1 (mod f(x))
```

这些状态可以看作状态多项式 $s_0 + s_1 x + s_2 x^2$ 的系数向量。**复算** ✓：逐态执行 $s \mapsto s \cdot x \bmod f$（如 $x^2 \mapsto x^3 \equiv 1 + x$；$1 + x + x^2 \mapsto x + x^2 + x^3 \equiv 1 + x^2$），7 步后回到 1，周期 $7 = 2^3 - 1$，与 GF(2³) 对数表（[[findings/gf23对数表与分式算例]]）完全一致。

**注意**：源文正文仅存末尾三个状态（$111 \widehat{=} x^5$、$101 \widehat{=} x^6$、回到 $100 \widehat{=} x^7 \equiv 1$，以横线分隔暗示省略），中间四个状态（010、001、110、011）疑被截断或仅存于图 5.18，见 [[queries/lfsr状态序列是否缺失中间状态]]。

## 极大周期判据

一般地，长度为 r 的线性反馈移位寄存器给出具有极大周期长度 $2^r - 1$ 的状态序列，**当且仅当**反馈多项式是 r 次本原多项式（[[concepts/本原多项式]]）。

流程化描述见 [[methodology/lfsr状态多项式演化流程]]；载体概念见 [[entities/线性反馈移位寄存器]]。
