# 式 8.94 积分次序交换与 A、B 两算例复算

## 转录内容（8.2.4.3 积分符号下的积分）

若函数 $f(x,y)$ 在矩形区域 $a \leqslant x \leqslant b,\ c \leqslant y \leqslant e$ 上连续，则函数 (8.90) 在区间 $[c,e]$ 上有定义且

```latex
\int_{c}^{e}\left[\int_{a}^{b} f(x,y)\,\mathrm{d}x\right]\mathrm{d}y
= \int_{a}^{b}\left[\int_{c}^{e} f(x,y)\,\mathrm{d}y\right]\mathrm{d}x   % 式 8.94
```

这种积分次序的交换称为**积分符号下的积分**。

## 算例 A（正例，$f(x,y)=x^y$）

源文：函数 $f(x,y)=x^y$ 在矩形区域 $0\leqslant x\leqslant 1,\ a\leqslant y\leqslant b$ 上积分。函数在 $x=0,\ y=0$ 处不连续（表述含混，疑指点 $(0,0)$，见 [[queries/8-2-4全节系统性转写讹误清单]] 第 7 项），但当 $a>0$ 时连续，因此可改变积分次序：

$$\int_a^b\left[\int_0^1 x^y\,\mathrm{d}x\right]\mathrm{d}y = \int_0^1\left[\int_a^b x^y\,\mathrm{d}y\right]\mathrm{d}x$$

左边 $= \int_a^b \frac{\mathrm{d}y}{1+y} = \ln\frac{1+b}{1+a}$，右边 $= \int_0^1 \frac{x^b-x^a}{\ln x}\,\mathrm{d}x$。尽管相应的不定积分无法用初等函数来表示，但定积分已知，因此有

$$\int_0^1 \frac{x^b - x^a}{\ln x}\,\mathrm{d}x = \ln\frac{1+b}{1+a} \quad (0<a<b)$$

## 算例 B（反例，$f(x,y)=\frac{y^2-x^2}{(x^2+y^2)^2}$，仅此函数）

源文：函数在矩形区域 $0\leqslant x\leqslant 1,\ 0\leqslant y\leqslant 1$ 上积分，在点 $(0,0)$ 处不连续，因此不能利用公式 (8.94)。经判断有（措辞可疑，疑为「经计算有」，见讹误清单第 8 项）：

$$\int_0^1 \frac{y^2-x^2}{(x^2+y^2)^2}\,\mathrm{d}x = \left.\frac{x}{x^2+y^2}\right|_{x=0}^{x=1} = \frac{1}{1+y^2}, \quad \int_0^1 \frac{\mathrm{d}y}{1+y^2} = \arctan y\Big|_0^1 = \frac{\pi}{4}$$

$$\int_0^1 \frac{y^2-x^2}{(x^2+y^2)^2}\,\mathrm{d}y = -\left.\frac{y}{x^2+y^2}\right|_{y=0}^{y=1} = -\frac{1}{x^2+1}, \quad -\int_0^1 \frac{\mathrm{d}x}{x^2+1} = -\arctan x\Big|_0^1 = -\frac{\pi}{4}$$

## 独立复算

**算例 A**：

1. $\int_0^1 x^y\,\mathrm{d}x = \frac{1}{1+y}$（$y>-1$）✓
2. $\int_a^b \frac{\mathrm{d}y}{1+y} = \ln\frac{1+b}{1+a}$ ✓
3. $\int_a^b x^y\,\mathrm{d}y = \frac{x^b-x^a}{\ln x}$（$0<x<1$，$\ln x\neq 0$）✓
4. 条件核查：$a>0$ 时 $x^y$ 在闭矩形 $[0,1]\times[a,b]$ 上连续（$0^y=0$ 对 $y\geqslant a>0$ 良定），式 8.94 条件满足 ✓
5. 结论为经典结果，数值抽验一致（如 $a=1,\ b=2$ 时两边同为 $\ln\frac{3}{2}$）✓

**算例 B**：

1. $\frac{\partial}{\partial x}\left[\frac{x}{x^2+y^2}\right] = \frac{y^2-x^2}{(x^2+y^2)^2}$ ✓；$\frac{\partial}{\partial y}\left[-\frac{y}{x^2+y^2}\right] = \frac{y^2-x^2}{(x^2+y^2)^2}$ ✓（两个原函数分别核验）
2. 先对 $x$ 积分（$y>0$ 固定）：$\int_0^1 = \frac{1}{1+y^2}$，再对 $y$：$\int_0^1\frac{\mathrm{d}y}{1+y^2} = \frac{\pi}{4}$ ✓
3. 先对 $y$ 积分（$x>0$ 固定）：$\int_0^1 = -\frac{1}{x^2+1}$，再对 $x$：$-\frac{\pi}{4}$ ✓
4. 两累次积分各自存在但符号相反（$+\pi/4$ 与 $-\pi/4$），式 8.94 在 $(0,0)$ 不连续时确失效——连续性条件必要性的经典（柯西型）反例 ✓

**复算结论：式 8.94 与 A、B 两算例全部无误。**

## 主张归属

- **换序可行**的结论绑定 $f(x,y)=x^y$ 与条件 $a>0$；
- **换序失败**的结论绑定 $f(x,y)=\frac{y^2-x^2}{(x^2+y^2)^2}$（仅在点 $(0,0)$ 不连续）；
- 两个结论不可互换：不能由 A 推出「换序总可行」，也不能由 B 推出「$x^y$ 不可换序」。
