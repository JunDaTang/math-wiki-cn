# 密码体制形式化定义（式 5.273）

本源 5.5.2–5.5.3 给出保密学的形式化骨架（定义性内容，非经验结果）：

```
密码函数:  t : Aⁿ × S → Bᵐ，使得对所有 s ∈ S，映射 t_s : Aⁿ → Bᵐ, w ↦ t(w, s) 是单射
          t_s 称为加密函数，t_s⁻¹ 称为解密函数；w 称为明码，t_s(w) 称为密码

密码体制:  T_S = { t_s : Aⁿ → Aⁿ | s ∈ S }                        (5.273)
          密钥的集合称为密钥空间；n = 1 时 t_s 称为流密码，否则称区组密码
```

配套要素：字母表 A = {a₀,…,a_{n−1}}（有限非空全序集）、字与 Aⁿ；长明文分裂为长度 n 的区组、必要时以填充符号补齐；上下文无关加密（密文区组仅依赖本区组与密钥）与上下文敏感加密之别。

## 直接证据与口径注记

- 单射性要求保证 t_s 可逆，即每个密钥下解密良定义——这是「体制」成立的最小条件。
- **口径差异**：式 (5.273) 将密码体制限定为 Aⁿ → Aⁿ 的单参数族，而密码函数的一般定义允许 Aⁿ → Bᵐ；明密文母表不同时的关系原文未说明。
- **非通行口径**：以 n = 1 / n > 1 区分流密码与区组密码是本手册的简化口径。
- 原文转写多处符号脱落（五元组的 𝔼、𝔻 记号、「凶是字母表的长」应为「n 是字母表的长」等），不影响上述定义结构。
