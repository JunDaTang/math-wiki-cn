# 面积函数的定义域与值域（表 2.8）

**发现**：手册表 2.8 给出四个面积函数的定义域与值域（括注为转写后分析的澄清）：

| 面积函数 | 定义域 | 值域 | 具有相同意义的双曲函数 |
|---|---|---|---|
| 面积正弦 y = Arsinh x | −∞ < x < ∞ | −∞ < y < ∞ | x = sinh y |
| 面积余弦 y = Arcosh x | 1 ≤ x < ∞（原表跨两行合并） | 0 ≤ y < ∞ | x = cosh y |
| y = −Arcosh x | （同上） | −∞ < y ≤ 0 | x = cosh y |
| 面积正切 y = Artanh x | \|x\| < 1 | −∞ < y < ∞ | x = tanh y |
| 面积余切 y = Arcoth x | \|x\| > 1（原表跨两行合并） | −∞ < y < 0（对应 x < −1） | x = coth y |
| | | 0 < y < ∞（对应 x > 1） | |

**证据强度**：强。各行均与对应双曲函数的值域一致（反函数定义域 = 原函数值域），可由 2.9 节性质直接核对。

**转写疑点**：原表将 Arcosh 与 Arcoth 的定义域单元格跨两行合并，使两个值域行各自对应的定义域子区间（Arcoth：x < −1 ↔ y ∈ (−∞, 0)；x > 1 ↔ y ∈ (0, ∞)）未在表中显示，疑为排版/转写信息丢失，见 [[queries/表2-8定义域跨行合并是否为转写丢失]]。

**内部矛盾**：正文 2.10.1.3 称 Artanh「仅在 |x| ≤ 1 时有定义」，与本表及式 2.213 的 |x| < 1 矛盾，见 [[queries/正文Artanh定义域小于等于1是否应为小于1]]。
