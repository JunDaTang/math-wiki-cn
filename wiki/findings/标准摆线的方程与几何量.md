# 标准摆线的方程与几何量（式 2.242a–b）

## 结论

圆沿直线无滑动滚动时圆周上一定点的轨迹（标准摆线）由下式给出：

$$x = a (t - \sin t), \quad y = a (1 - \cos t) \quad (a > 0,\ -\infty < t < \infty),\tag{2.242a}$$

$$x + \sqrt {y (2 a - y)} = a\,\mathrm{arc}_{k}\cos \frac{a - y}{a} \quad (a > 0,\ k = 0, \pm 1, \pm 2, \dots).\tag{2.242b}$$

几何量：周期 $2\pi a$；尖点 $O_k = (2k\pi a, 0)$；最高点 $A_{k+1} = ((2k+1)\pi a, 2a)$；弧长 $L = 8a\sin^2(t/4)$；单拱长 $8a$；单拱面积 $S = 3\pi a^2$；曲率半径 $r = 4a\sin(t/2)$，最高点处 $r_A = 4a$；渐屈线为全等的摆线（前向引用第 340 页 3.6.1.6）。

## 证据与核验

- **直接证据**：手册 2.13.1 原文（式 2.242a–b 及随文几何量，图 2.67）。
- **交叉核验**（独立于手册的经典结果）：周期、尖点与最高点坐标、单拱长 $8a$、单拱面积 $3\pi a^2$、$r = 4a\sin(t/2)$、「渐屈线为全等摆线」均与经典摆线结果一致。
- **族内一致性**：[[concepts/次摆线]] 的 $S = \pi a^2(2+\lambda^2)$ 在 $\lambda = 1$ 时回退为 $3\pi a^2$；其曲率公式在 $\lambda = 1$ 时量化为 $4a\sin(t/2)$（仅符号相反，见 [[queries/次摆线曲率半径符号约定与2-13-1是否统一]]）。

## 备注

- $\operatorname{arc}_k\cos$ 为多值反余弦分支记法，手册未明说取法；按上下文应为 $2k\pi \pm \arccos$（解读性注释）。
- 手册称最高点处「曲率 $r_A = 4a$」，按量纲与记号实为**曲率半径**。
