# 式 20.37–20.38b 图形对象构建算例复算

## 转录（原样）

```mathematica
In[1] := g = Graphics[{Line[{{0, 0}, {5, 5}, {10, 3}}], Circle[{5, 5}, 4],
        Text[Style["Example","Helvetica",Bold,25],{5,6}]},
        AspectRatio->Automatic]                                     (20.37a–b)
```

```mathematica
{object1, object2, ...}                                          (20.38a)
In[1] := o1 = {Circle[{5, 5}, {5, 3}], Line[{{0, 5}, {10, 5}}]}
In[2] := o2 = {Circle[{5, 5}, 3]}
In[3] := o3 = {Thickness[0.01], o2}
In[4] := g1 = Graphics[{o1, o2}]; g2 = Graphics[{o1, o3}]
Show[g1]  和  Show[g2, Axes -> True]                             (20.38b)
```

## 复算结论

- 式 20.37a–b 语法有效：折线 (0,0)→(5,5)→(10,3)、以 (5,5) 为圆心半径 4 的圆、以 (5,6) 为中心的粗体 Helvetica 文字 "Example" 三基元构成图形对象，`Show[g]` 显示图 20.1；`AspectRatio->Automatic` 确保圆不变形。
- 式 20.38a–b 语法有效：g1 与 g2 的差异仅在第二个对象——g2 中 `Thickness[0.01]` 只作用于 o3 花括号内的圆（嵌套成立），o1（半轴 {5,3} 的椭圆与水平线段）不受影响，直接证实图形命令作用域规则（[[图形命令与相对绝对尺寸]]）；`Show[g2, Axes -> True]` 激活坐标轴，产生带 Mathematica 自动选取刻度的轴（图 20.2b）。
- `g = Graphics[...]`、`g1 = ...; g2 = ...` 的赋值语义与 [[Set指派与清除]] 一致。

## 校勘

- b) 句「(5,5) 为圆心、 为半径画圆」脱「以」「4」，应为「以 (5,5) 为圆心、4 为半径画圆」（与代码 `Circle[{5, 5}, 4]` 对勘可定谳）。
- 「Mathematica 对千规定绘图环境」之「千」为「于」之讹；「千是如同在图 20.1 中那样」之「千是」为「于是」（系统性「千→于」讹误，[[20-4全节系统性转写讹误清单]]）。
- 「它相应千沿 方向的长度与沿 方向的长度之比」脱 x/y 且「千」为「于」。

## 证据强度

代码块完整、无破坏语法的讹误，属可逐条复算的强证据；文字脱失不影响复算，但影响引文可信度。
