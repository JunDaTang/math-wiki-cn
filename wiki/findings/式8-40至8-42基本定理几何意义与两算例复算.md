# 式 8.40–8.42 基本定理、几何意义与 A、B 算例复算

## 逐字转录

若被积函数 $f(x)$ 在区间 $[a,b]$ 上连续，$F(x)$ 为其原函数，则

$$\int_a^b f(x)\,\mathrm{d}x = \int_a^b F'(x)\,\mathrm{d}x = F(x)\Big|_a^b = F(b)-F(a),\tag{8.40}$$

即定积分的计算可以化成相应的不定积分的计算，也就是确定反导数：

$$F(x)=\int f(x)\,\mathrm{d}x+C.\tag{8.41}$$

可积函数不一定有原函数，但连续函数一定有原函数。

几何意义（曲线下的面积）：设对 $\forall x\in[a,b]$ 都有 $f(x)\geqslant 0$，则和 (8.38) 可看作所有小矩形的总面积，即曲线下方面积的近似值；因此和的极限，即函数 $f(x)$ 的定积分等于曲线 $y=f(x)$、$x$ 轴以及平行线 $x=a$、$x=b$ 所围成的区域的面积：

$$A=\int_a^b f(x)\,\mathrm{d}x \quad (a<b,\ \text{且当 } a\leqslant x\leqslant b \text{ 时 } f(x)\geqslant 0).\tag{8.42}$$

符号法则：若函数 $y=f(x)$ 在积分区间上分段正负（图 8.5），则相应子区间上的积分，即各部分面积也有正有负，故总区间上的积分等于各部分面积的代数和。图 8.5(a)–(d) 给出了面积符号可能出现的四种不同情况。

## 算例独立复算

**A**：$\int_0^\pi\sin x\,\mathrm{d}x = -\cos x\big|_0^\pi = (-\cos\pi+\cos 0) = 1+1 = 2$ ✓

**B**：$\int_0^{2\pi}\sin x\,\mathrm{d}x = -\cos x\big|_0^{2\pi} = (-\cos 2\pi+\cos 0) = -1+1 = 0$ ✓（正负半周期面积相消，符号法则示例）

**判定**：两算例复算无误；「可积不一定有原函数，连续一定有原函数」为标准定理；confidence: high；replicated: true。
