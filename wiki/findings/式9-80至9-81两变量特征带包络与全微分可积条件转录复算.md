# 式 9.80–9.81 两变量特征带、包络与全微分可积条件转录复算

本条目逐字转录两变量一阶方程（式 9.80）与全微分形式方程及其可积条件（式 9.81a–d），复算两个算例（pq = 1 的特征带法、克莱罗方程的包络法），并核对两个可积条件的结构（其一恰为 Frobenius 条件的分量形式）。

## 逐字转录

```latex
F(x, y, z, ∂z/∂x, ∂z/∂y) = 0                                   (9.80)

dz = f₁dx₁ + f₂dx₂ + … + fₙdxₙ                                 (9.81a)
∂fᵢ/∂xₖ + fₖ ∂fᵢ/∂z = ∂fₖ/∂xᵢ + fᵢ ∂fₖ/∂z   (i,k = 1,…,n)      (9.81b)
f₁dx₁ + f₂dx₂ + … + fₙdxₙ = 0                                  (9.81c)
fᵢ(∂fₖ/∂xⱼ − ∂fⱼ/∂xₖ) + fⱼ(∂fᵢ/∂xₖ − ∂fₖ/∂xᵢ)
  + fₖ(∂fⱼ/∂xᵢ − ∂fᵢ/∂xⱼ) = 0                                  (9.81d)
```

## 两变量特征带的几何解释（9.80）

特征带可几何地解释为一条曲线，在曲线的每个点 (x, y, z) 处，与该曲线相切的平面 p(ξ−x) + q(η−y) = ζ−z 是预先给定的。求 (9.80) 过给定曲线的积分曲面（柯西问题）化为：求通过初始曲线各点的特征带，使每条带相应的切平面与该曲线相切。初始曲线上 p、q 的值由 F(x, y, z, p, q) = 0 与 pdx + qdy = dz 确定；**非线性情形可以有多个解**，故为得唯一解，柯西问题中须假设沿初始曲线有两个满足上述关系的连续函数 p 和 q。存在性见文献 [9.26]（未明，见 [[queries/9-2-1未入库回指缺口]]）。

包络解法：单参数积分曲面族的包络也是积分曲面；据此可用一个完全积分解柯西问题——找到与初始曲线各点处给定平面相切的解的单参数族，再确定该族的包络。

## 算例 C：pq = 1（特征带法，复算通过）

初始曲线 y = x³, z = 2x²，沿初始曲线取 p = x, q = 1/x。特征组：

```latex
dx/dt = q,  dy/dt = p,  dz/dt = 2pq,  dp/dt = 0,  dq/dt = 0
x = x₀ + t/x₀,  y = x₀³ + tx₀,  z = 2t + 2x₀²
z² = 4xy
```

复算：
1. 带条件核对：沿初始曲线 pq = x·(1/x) = 1；p dx + q dy = x dx + (1/x)·3x² dx = 4x dx = d(2x²) = dz。✅
2. 特征组来源：F = pq − 1 时 (9.76e) 给 P₁ = ∂F/∂p = q、P₂ = ∂F/∂q = p、Xᵢ = Z = 0，代入 (9.76d) 即得上组（dz/dt = p·q + q·p = 2pq）。✅
3. 消参：xy = (x₀ + t/x₀)(x₀³ + tx₀) = x₀⁴ + 2tx₀² + t² = (x₀² + t)²，而 z = 2(x₀² + t)，故 z² = 4xy。✅
4. 代回验证：z = 2√(xy) 支上 z_x = y/√(xy)、z_y = x/√(xy)，z_x z_y = 1；初始曲线上 4xy = 4x⁴ = (2x²)² = z²。✅
5. 源文指出：对沿初始曲线 p、q 的别的取值可得到不同的解——非线性多解性的体现，须额外指定连续的 p、q 方得唯一解。

## 算例 D：克莱罗方程 z − px − qy + pq = 0（包络法，复算通过）

初始曲线 y = x, z = x²。完全积分为 z = ax + by − ab。

复算：
1. 完全积分验证：p = a、q = b，代回得 (ax + by − ab) − ax − by + ab = 0；雅可比 ∂(φₓ, φ_y)/∂(a, b) = 1 ≠ 0。✅
2. 带条件强制唯一 (p, q)：沿初始曲线 dz = 2x dx、dy = dx 给 p + q = 2x；F = 0 给 x² − (p+q)x + pq = 0 即 pq = x²。联立得 (p−q)² = (p+q)² − 4pq = 0，故 p = q = x（唯一）。✅ 与源文「沿着初始曲线有 p = q = x」一致。
3. 单参数族：过初始曲线点 (x₀, x₀, x₀²) 且切平面匹配的完全积分成员须 a = b（且 a = x₀），即族 z = a(x+y) − a²。
4. 包络：令 ∂z/∂a = (x+y) − 2a = 0 得 a = (x+y)/2，代回得 z = (x+y)²/2 − (x+y)²/4 = ¼(x+y)²。✅
5. 验证：p = q = (x+y)/2，z − px − qy + pq = ¼(x+y)² − ½(x+y)² + ¼(x+y)² = 0；初始曲线上 y = x 时 z = ¼(2x)² = x²。✅

## 全微分形式方程与完全可积条件（9.81）复算

- **定义与唯一性**：若存在 x₁,…,xₙ,z 间含一个任意常数的关系导出 (9.81a)，则称完全可积（或恰当微分方程）；此时对初值 (x₁⁰,…,xₙ⁰)，方程有取给定值 z₀ 的唯一解；n = 2 时过每点有唯一的积分曲面。
- **(9.81b) 复算**：若 z(x) 满足 dz = Σfᵢdxᵢ，则 z_{xᵢ} = fᵢ，且 ∂fᵢ/∂xₖ + fₖ∂fᵢ/∂z = ∂/∂xₖ[z_{xᵢ}]（对 z 的依赖经链式法则以全导数出现）= z_{xᵢxₖ}，关于 (i, k) 对称，故 (9.81b) 成立；反之 (9.81b) 的 n(n−1)/2 个独立等式保证局部势函数存在。即 (9.81b) 是二阶偏导数可交换性的全导数形式。✅
- **(9.81d) 复算（推断，源外对照）**：令 ω = Σfᵢdxᵢ，外积 ω∧dω 中 dxᵢ∧dxⱼ∧dxₖ（i<j<k）的系数经三项置换求和恰为 (9.81d) 左端。故 (9.81d) 即 Frobenius 可积性条件 ω∧dω = 0 的分量展开。✅
- **结论**：完全可积时，(9.81a) 的解归结为含 n−1 个参数的常微分方程的解。
- **层级关系**：这是 9.1.1 二维恰当微分方程（[[concepts/恰当微分方程]]）的 n 维推广，源文本节自身亦使用「恰当微分方程」一词；理论页见 [[concepts/全微分形式方程与完全可积条件]]。

## 转写疑点

- 「x₁⁰,…,xₙ⁰ 式」衍「式」字；「关千」讹「关于」。
- 「可以把特征带…儿何地解释为一条曲线在曲线的每个点…」：「儿何」讹「几何」，且「一条曲线在曲线的每个点」处疑脱标点（应为「一条曲线，在曲线的每个点…」）。
- 「对于沿着初始曲线 p 和 q 别的取值」语序不通（应为「别的取值」）。
