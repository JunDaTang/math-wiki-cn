# 式 17.43–17.46 点维数、信息维数与杨氏定理转录复算

## 转录

```latex
b̄_mu(x) = limsup_{δ->0} ln mu(B_δ(x)) / ln δ                                    (17.43a)
b_mu(x)  = liminf_{δ->0} ln mu(B_δ(x)) / ln δ                                    (17.43b)
% 杨氏定理：若对 mu-几乎处处 x 有 d_mu(x)=α，则 α = d_H(mu) := inf{ d_H(X) : X⊂Λ, mu(X)=1 }
mu(B_δ(x)) ~ δ^n 且 d_H(mu) = n                                                  (17.44)
H(eps) = − sum_i p_i(eps) ln p_i(eps),  p_i(eps) = mu(Q_i(eps))                  (17.45)
d_I(mu) = lim_{eps->0} H(eps)/ln eps        【源文无负号，疑脱】
α = d_H(mu) = d_I(mu)                                                            (17.46)
```

## 复算

- **平衡点例**：$\mu$ 支撑在 $\{x_0\}$，$\varepsilon$-覆盖中只有一个非空方体，$p=1$，$H(\varepsilon)=-1\cdot\ln1=0$ ⟹ $d_I=0$ ✓（与符号约定无关）。
- **极限环例**：长 $L$ 的环被 $\approx L/\varepsilon$ 个 $\varepsilon$-方体覆盖，各 $p_i\approx\varepsilon/L$ ⟹ $H(\varepsilon)\approx\ln(L/\varepsilon)=-\ln\varepsilon+\ln L$，与源文 $H(\varepsilon)=-\ln\varepsilon$ 相符（差常数 $\ln L$，不影响标度）✓。**但**按字面公式 $d_I=\lim(-\ln\varepsilon)/\ln\varepsilon=-1\ne1$，与源文断言 $d_I(\mu)=1$ 矛盾；订正 $d_I=-\lim H(\varepsilon)/\ln\varepsilon$ 后得 $d_I=1$ ✓，且与 (17.48b) 的负号一致。此即 [[queries/信息维数定义式脱负号之辨]] 的核心证据。
- **式 17.44 例**：$\mu_\Lambda=\lambda/\lambda(\Lambda)$、$\lambda(\Lambda)>0$ ⟹ $\mu(B_\delta(x))=\lambda(B_\delta\cap\Lambda)/\lambda(\Lambda)\asymp\delta^n$（源文作 $\sim\delta^n$，常因子不影响点维数指数）⟹ 点维数 a.e. 为 $n$ ⟹ 由杨氏定理 $d_H(\mu)=n$ ✓。
- **杨氏定理两条**为手册式断言（无证明），内容与点态维数理论的标准结果一致；命名者身份见 [[queries/杨氏定理之杨为何人之辨]]。

## 判定

数学内容复算全部通过；**信息维数定义式的负号为数学实质疑点**，强烈倾向脱字（极限环例矛盾 + 17.48b 对照双重证据），待印本确认。

## 讹误登记

点维数记号 $\bar b_\mu/\underline b_\mu$ 与杨氏定理中 $d_\mu(x)$ 不一致；例 A/B 中 $H_\varepsilon(\mu)$ 与 $H(\varepsilon)$ 记号混用；「儿乎处处」→「几乎处处」；「杨氏 {Young)」括号讹；「紧球体」疑为「紧集」（若作紧球体亦自洽）。汇总见 [[queries/17-2-4全节系统性转写讹误清单]]。
