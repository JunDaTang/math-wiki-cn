# 斜三角形边角定律集（式 3.88–3.92）

**发现内容（直接证据，公式逐字保留）：**

正弦定律（[[concepts/正弦定律]]）：

$$\frac{a}{\sin\alpha} = \frac{b}{\sin\beta} = \frac{c}{\sin\gamma} = 2R \tag{3.88}$$

投影法则（图 3.35）：

$$c = a\cos\beta + b\cos\alpha \tag{3.89}$$

余弦定律或一般三角形的毕达哥拉斯定理（[[concepts/余弦定律]]）：

$$c^2 = a^2 + b^2 - 2ab\cos\gamma \tag{3.90}$$

莫尔韦德等式：

$$(a+b)\sin\frac{\gamma}{2} = c\cos\frac{\alpha-\beta}{2} \tag{3.91a}$$

$$(a-b)\cos\frac{\gamma}{2} = c\sin\frac{\alpha-\beta}{2} \tag{3.91b}$$

正切定律（[[concepts/正切定律]]）：

$$\frac{a+b}{a-b} = \frac{\tan\frac{\alpha+\beta}{2}}{\tan\frac{\alpha-\beta}{2}} \tag{3.92}$$

**轮换原理（源文直述）：**斜三角形不具有特殊的边或角，故从每个包含边和角的公式出发，可按图 3.34 通过边和角的轮换得到另外两个公式。

**互证（分析层核验，非源文直述）：**将 (3.91b) 除以 (3.91a)，并利用 $(\alpha+\beta)/2 = 90^\circ - \gamma/2$（即 $\tan\frac{\alpha+\beta}{2} = \cot\frac{\gamma}{2}$），即得 (3.92)，故莫尔韦德等式与正切定律恒等价；(3.89) 是 c 方向上的投影分量式，与 3.105b 的坐标距离式同构。

**证据类型：**直接证据，强度高（经典结果且内部自洽）。
