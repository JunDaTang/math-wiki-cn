# 式 9.153–9.157 KdV 单孤子、双孤子与位势形式转录复算

## 经复算验证成立

- **(9.154) 单孤子** u = (v/2) sech²[½√v(x − vt − φ)]（v > 0）直接代入 (9.153) 成立；参数陈述（v、φ 两参数；速度决定振幅与宽度，高波快于矮波）与解式一致。
- **(9.157a) 位势关系**：w = F_x/F、u = 2w_x 时，由 w_t + 6(w_x)² + w_{xxx} = 0 导出 KdV (9.153) 成立。
- **反孤子陈述**：以 −6uu_x 代 +6uu_x 时解乘 (−1)，成立。
- **(9.155) 渐近叠加**与弹性相互作用叙述（φ_n^- ≠ φ_n^+、速度不变）为标准结论。

## (9.156) 双孤子解的双重疑点（转写疑误，非源书结论）

按转写 k_n = ½√v_n、α_n = ½√v_n(x − v_n t − φ_n)：

```latex
u = 8 { k_1^2 e^{α_1} + k_2^2 e^{α_2}
      + (k_1 − k_2)^2 e^{(α_1+α_2)} [ 2 + (k_1^2 e^{α_1} + k_2^2 e^{α_2}) / (k_1 + k_2)^2 ] }
  / [ 1 + e^{α_1} + e^{α_2} + ((k_1 − k_2)/(k_1 + k_2))^2 e^{(α_1+α_2)} ]^2
```

1. **指数因子疑误**：按上述 α_n 定义，(9.156) 在 t → ±∞ 不能退化为 (9.154) 型单孤子（sech 宗量相差因子 2），与文中 (9.155) 的渐近叙述自相矛盾；需 α_n = √v_n(x − v_n t − φ_n)（即 k_n = ½√v_n 而 α_n 宗量用 √v_n）才自洽。
2. **系数配对疑误**：取正确指数后，将 u = 2∂²ₓ ln F（F = 1 + e^{α₁} + e^{α₂} + Ae^{α₁+α₂}，A = ((k₁−k₂)/(k₁+k₂))²）展开，分子中三次指数项应为**交叉配对** A(k₂²e^{2α₁+α₂} + k₁²e^{α₁+2α₂})，而转写为同侧配对 (k₁²e^{α₁} + k₂²e^{α₂})。数值抽查（k₁ = 1，k₂ = 2，e^{α₁} = 2，e^{α₂} = 4）：真值 u ≈ 5.742，转写式给出 ≈ 6.428。分母与系数 A 本身无误。

## (9.157b)/(9.157c) 缺失

F 的具体表达式（单孤子与 N-孤子情形）在转写中丢失，仅余残句「1a) 对于 F(x,t)=1+…」。见 [[queries/式9-157b至9-157c公式内容缺失]]。
