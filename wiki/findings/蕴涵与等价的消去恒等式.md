# 蕴涵与等价的消去恒等式（式 5.17）

《数学手册(原书第10版)》5.1.1.6：应用对蕴涵和等价的真值表可得到恒等式

```latex
A ⇒ B = Ā ∨ B        % (5.17a)
A ⇔ B = A B ∨ Ā B̄    % (5.17b)
```

**意义**：蕴涵和等价可以通过其他命题运算表示，故可从公式中消去。定律 (5.17a/b) 被用于改述命题公式；这一事实连同德摩根法则 (5.14a/b) 蕴涵：仅通过否定和析取、或否定和合取，即可表示每个公式、因而表示每个真值函数（函数完备性，原书参见 5.7，页 528，未入库）。

**证据类型**：直接证据（由表 5.1 的蕴涵/等价列直接读出；属定义性推论，未另行独立复算）。相关：[[findings/真值函数计数与NAND-NOR真值表]]、[[methodology/命题公式化简流程]]。
