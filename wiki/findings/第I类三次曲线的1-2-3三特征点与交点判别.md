# 第I类三次曲线的 1:2:3 三特征点与交点判别（式 2.47）

手册 2.4.3 给出 [[concepts/第I类三次曲线]] y = a + b/x + c/x²（b ≠ 0, c ≠ 0）的图像要素（直接证据）。最引人注目的结构是：非单调分支依次穿过横坐标呈 **1:2:3 比例**的三个特征点：

- 与渐近线 y = a 的交点 A(−c/b, a)；
- [[concepts/极值]]点 B(−2c/b, a − b²/(4c))；
- [[concepts/拐点]] C(−3c/b, a − 2b²/(9c))。

其余要素：[[concepts/渐近线]] x = 0 与 y = a；另一支上 y 在 a 与 +∞（或 −∞）之间单调变化；分支位置由 b、c 的符号决定，共四种情形（图 2.18）。

与 x 轴的交点（若存在）：

- a ≠ 0 时为 D, E = ((−b ± √(b² − 4ac))/(2a), 0)，按 b² − 4ac 大于/等于/小于 0 分别有两个交点、一个切点（x 轴为切线）、无交点；
- a = 0 时唯一交点为 (−c/b, 0)。

退化：b = 0 → y = a + c/x²（[[concepts/倒数幂]]平移型）；c = 0 → 单应函数 y = (ax+b)/x（[[concepts/线性分式函数]]的特例）。

**验证状态（独立重推导）**：三个特征点坐标经求导全部复核无误——y′ = −b/x² − 2c/x³ 与 y″ = 2b/x³ + 6c/x⁴ 的零点分别给出 B、C 的横坐标，回代纵坐标亦吻合；交点判别直接解 ax² + bx + c = 0 得到。1:2:3 横坐标结构是本源最有复用价值的结果之一。

**口径注意**：本小节判别式用标准形式 b² − 4ac，与同节 2.4.4/2.4.5 的 Δ = 4ac − b² 反号，见 [[queries/2-4节内二次判别式两种符号约定为何并存]]。
