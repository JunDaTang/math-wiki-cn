# 表示直和与特征可加性（式 5.107–5.110）

**来源**：[[sources/10-数学手册原书第10版--7-534-群表示--x5kmh9]]（5.3.4.3）。

- **式 (5.107)**：$D(a) = D^{(1)} \oplus D^{(2)}(a) = \begin{pmatrix} D^{(1)} & 0 \\ 0 & D^{(2)} \end{pmatrix}$，由维数 $n_1$、$n_2$ 的表示复合出维数 $n = n_1 + n_2$ 的新表示。
- **式 (5.108)**：分块对角形蕴涵 $V_n = V_{n_1} \oplus V_{n_2}$，为两个不变子空间的直和（不变子空间定义见式 5.109 与 [[concepts/不变子空间]]）。
- **式 (5.110)**：$\chi(a) = \chi^{(1)}(a) + \chi^{(2)}(a)$（特征可加）。

**证据评估**：标准结果，直接由分块对角矩阵的迹等于各块迹之和得出；属结构性直接推论而非数值算例，故 replicated 记为 null。与克罗内克积的特征可乘性（[[findings/克罗内克积表示与特征乘性]]）构成一对演算规则，比较见 [[comparisons/表示直和与直积比较]]。此构造是完全可约表示（式 5.116）的矩阵形式。
