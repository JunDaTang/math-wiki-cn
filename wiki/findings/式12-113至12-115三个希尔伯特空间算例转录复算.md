# 式 12.113–12.115 三个希尔伯特空间算例转录复算

## 转录内容

- (12.113) 例 A：ℓ²(n)、ℓ²、L²((a,b)) 的标量积分别为 (x,y) = Σ_{k=1}^n ξ_k η̄_k、(x,y) = Σ_{k=1}^∞ ξ_k η̄_k 与 (x,y) = ∫ₐᵇ x(t)ȳ(t)dt。
- (12.114) 例 B：空间（正文排作 H²(Ω)）的标量积
  (f,g) = ∫_Ω̄ f(x) ḡ(x)dx + Σ_{1⩽∣α∣⩽k} ∫_Ω̄ D^α f(x) · D^α ḡ(x)dx。
- (12.115) 例 C：设 φ(t) 是 [a,b] 上正可测函数，所有相对于权函数 φ 二次可积的复可测函数空间 L²((a,b),φ) 的标量积 (x,y) = ∫ₐᵇ x(t)ȳ(t)φ(t)dt。

## 复算

- (12.113)：三个标量积均满足 (H1)–(H4)；无穷和与积分的定正性分别由级数/积分项的非负性给出，完备性即 ℓ² 与 L² 的完备性。✓（与 [[entities/lp空间]]、[[concepts/L2空间与平方可积函数]] 一致。）
- (12.114)：标量积各项非负、共轭对称、第一变元线性；含多重指标导数项后按索伯列夫型范数完备（以 W^{k,2} 的完备性为独立可查证背景）。⚠ 正文空间名 H²(Ω) 与求和上界 k 矛盾，应为 H^k(Ω)，见 [[queries/式12-114空间名h2与指标k矛盾]] 与 [[entities/hk索伯列夫型空间]]。
- (12.115)：φ 正可测 ⇒ (x,x) = ∫∣x(t)∣²φ(t)dt ⩾ 0 且为零当且仅当 x 为（加权测度意义下的）零元；共轭对称与第一变元线性显然。✓ 该加权构造与 11.3 中 sin 权奇异核算例（[[concepts/L2空间与平方可积函数]]）相呼应。

## 转写讹误

12.4.1.3 例 C 的标签「■ C:」脱落（正文以「：设 φ(t)…」起句）。已并入 [[queries/12-4全节系统性转写讹误清单]]。

## 结论

例 A、C 数学内容复算通过；例 B 公式自洽但空间名转写有误。三例共同支撑希尔伯特空间定义的实例库。
