# 模糊集的基本性质 E1–E5 与离散表示（式 5.328–5.330，表 5.7）

**发现**：本节从模糊集定义直接推出五条性质 (E1)–(E5)。

- (E1) 清晰集可以解释为具有隶属等级（只取 0 与 1）的模糊集（转写脱落该二值）。
- (E2) 隶属等级大于零的自变量 x 的集合称作模糊集 A 的**支撑**；隶属等级等于 1 的点的集合称作**柱芯**（后文 5.9.1.3 改称「核」，译名不一致见 [[依扎德与柱芯译名问题]]）：

$$\operatorname{supp}(A)=\{x\in X\mid \mu_A(x)>0\}\tag{5.328}$$
$$\ker(A)=\{x\in X\mid \mu_A(x)=1\}$$

- (E3) 全域 X 上两个模糊集相等，当且仅当它们的隶属函数的值相等：

$$\text{若对于每个 } x\in X,\ \mu_A(x)=\mu_B(x)\ \text{成立，则 } A=B\tag{5.329}$$

- (E4) 离散表示 / 有序对表示：有限全域 $X=\{x_1,\dots,x_n\}$ 上用值表定义隶属函数是适宜的，表格表示见表 5.7（逐字保留），也可写成

$$A:=\mu_A(x_1)/x_1+\dots+\mu_A(x_n)/x_n=\sum_{i=1}^{n}\mu_A(x_i)/x_i\tag{5.330}$$

分数线和加号**仅有符号意义**。

| $x_1$ | $x_2$ | $\cdots$ | $x_n$ |
| --- | --- | --- | --- |
| $\mu_A(x_1)$ | $\mu_A(x_2)$ | $\cdots$ | $\mu_A(x_n)$ |

- (E5) **超模糊集**（[[依扎德]] / Zadeh 的定义）：如果模糊集的隶属函数本身也是一个模糊集，那么它称为超模糊集（见 [[超模糊集]]）。

**证据强度**：直接由定义推出，无需独立证明。结构概念展开见 [[支撑与核]]。
