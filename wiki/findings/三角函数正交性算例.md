# 三角函数正交性算例（式 5.204–5.207，已复算）

## 陈述（5.3.8.5）

在函数空间 $C[a,b]$ 中，标量积由

```latex
f·g = ∫_a^b f(x) g(x) dx      % 5.204
```

定义。在 $C[0,2\pi]$ 中：

```latex
∫_0^{2π} sin kx · sin lx dx = 0   (k ≠ l)      % 5.205
∫_0^{2π} cos kx · cos lx dx = 0   (k ≠ l)      % 5.206
∫_0^{2π} sin kx · cos lx dx = 0                % 5.207
```

因此 $\sin kx\in C[0,2\pi]$ 与 $\cos lx\in C[0,2\pi]$ 对每个 $k,l\in\mathbb{N}$ 两两互相正交。原书指出该正交性在调和分析（7.4.1.1，第 634 页）中用来计算傅里叶系数。

## 复算说明（已复算）

由积化和差公式，对 $k\neq l$（$k,l$ 为正整数）：

- $\sin kx\sin lx = \tfrac12[\cos(k-l)x - \cos(k+l)x]$，两余弦在 $[0,2\pi]$ 上积分均为零，故式 5.205 成立。
- $\cos kx\cos lx = \tfrac12[\cos(k-l)x + \cos(k+l)x]$，同理式 5.206 成立。
- $\sin kx\cos lx = \tfrac12[\sin(k+l)x + \sin(k-l)x]$，正弦在整周期上积分为零，故式 5.207 成立（此式对 $k=l$ 亦成立：$\int_0^{2\pi}\sin kx\cos kx\,dx=\tfrac12\int_0^{2\pi}\sin 2kx\,dx=0$）。

复算与原文一致；注意 5.205/5.206 须限定 $k\neq l$（$k=l$ 时 $\int_0^{2\pi}\cos^2kx\,dx=\pi\neq0$），原文已正确标注。

## 证据性质

直接计算可验证的解析事实，非经验性主张；复算通过。傅里叶系数的应用依赖未入库的 7.4.1.1（见 [[queries/5-3-8对5-3-6及未入库章节依赖缺口]]）。
