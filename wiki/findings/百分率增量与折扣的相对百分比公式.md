# 百分率增量与折扣的相对百分比公式（式 1.70–1.74）

《数学手册(原书第10版)》1.3.1 给出百分率的定义式，以及增量、折扣情形下“新值中所含增/折扣百分比”的换算公式：

```latex
p\% = \frac{p}{100} \quad\text{或}\quad 1\% = 0.01 \tag{1.70}
\widetilde{K} = K\left(1 + \frac{p}{100}\right) \tag{1.71}
\tilde{p} = \frac{p \cdot 100}{100 + p} \tag{1.72}
\widetilde{K} = K\left(1 - \frac{p}{100}\right) \tag{1.73}
\tilde{p} = \frac{p \cdot 100}{100 - p} \tag{1.74}
```

- (1.72) 由比例式 $K\frac{p}{100} : \widetilde{K} = \tilde{p} : 100$ 导出：增量 $K\frac{p}{100}$ 占新值 $\widetilde{K}$ 的百分比。
- (1.74) 为对应的折扣情形：折扣 $K\frac{p}{100}$ 占折后价 $\widetilde{K}$ 的百分比。

## 手册数值例子（导入时独立复核吻合）

- 定价 €200 增加 15% 附加费 → €230；该价格包含 $\tilde{p} = \frac{15\cdot100}{115} = 13.04\%$ 的增量。
- 定价 €300 给出 10% 折扣 → €270；该价格包含 $\tilde{p} = \frac{10\cdot100}{90} = 11.11\%$ 的折扣。

## 证据说明

直接证据：手册原文的公式与例子。式 (1.72)/(1.74) 可由比例式直接推导，例子算术经导入时复核吻合。本发现为确定性数学推导，非经验性结果，故不涉及独立研究的重复验证。
