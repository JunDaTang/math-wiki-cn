# 交会法及其不可见变体的解算公式（式 3.110–3.111）

**发现内容（直接证据，公式逐字保留）：**经由两条定向直线的交会法（三角测量第一基本问题，图 3.42）：已知 $y_A, x_A; y_B, x_B$；所测 $\alpha, \beta$（如果可能的话还有 $\gamma$，或 $\gamma = 200\ \mathrm{gon} - \alpha - \beta$）；所求 $y_N, x_N$。解：

$$\tan t_{AB} = \frac{\Delta y_{AB}}{\Delta x_{AB}} \tag{3.110a}$$

$$s_{AB} = \sqrt{\Delta y_{AB}^2 + \Delta x_{AB}^2} = |\Delta y_{AB}\sin t_{AB}| + |\Delta x_{AB}\cos t_{AB}| \tag{3.110b}$$

$$s_{BN} = s_{AB}\frac{\sin\alpha}{\sin\gamma} = s_{AB}\frac{\sin\alpha}{\sin(\alpha+\beta)},\qquad s_{AN} = s_{AB}\frac{\sin\beta}{\sin\gamma} = s_{AB}\frac{\sin\beta}{\sin(\alpha+\beta)} \tag{3.110c,d}$$

$$t_{AN} = t_{AB} - \alpha \tag{3.110e}$$

$$t_{BN} = t_{BA} + \beta = t_{AB} + \beta \pm 200\ \mathrm{gon} \tag{3.110f}$$

$$y_N = y_A + s_{AN}\sin t_{AN} = y_B + s_{BN}\sin t_{BN} \tag{3.110g}$$

$$y_N = x_A + s_{AN}\cos t_{AN} = x_B + s_{BN}\cos t_{BN} \tag{3.110h}$$

**内部核验（分析层）：**(3.110b) 第二等式是恒等式——代入 $\Delta y = s\sin t$、$\Delta x = s\cos t$ 即 $s(\sin^2 t + \cos^2 t) = s$；(3.110g–h) 的双路并列（从 A、B 两端各算一遍）是嵌入式检核。

**疑点（采信前须核对）：**(3.110h) 左端 $y_N$ 与右端的 x 分量公式矛盾，疑应为 $x_N$，见 [[queries/式3-110h左端是否应为xN]]。

**不可见变体（式 3.111，图 3.43）：**若从 A 处不能看见点 B，方位角 $t_{AN}$、$t_{BN}$ 通过关于其他坐标已知的可见点 D、E 的参考方向确定。已知 $y_A, x_A; y_B, x_B; y_D, x_D; y_E, x_E$；所测 $\delta, \varepsilon_i$（转写残缺）；所求 $y_N, x_N$。化为第一基本问题后依次计算 $\tan t_{AD}$、$\tan t_{BE}$，$t_{AN} = t_{AD} + \delta$、$t_{BN} = t_{BE} + \varepsilon$，$\alpha = t_{AB} - t_{AN}$、$\beta = t_{BN} - t_{BA}$，最后由两直线交点式 (3.111i–j) 求 $x_N, y_N$。该系列多处下标与符号疑错乱（(3.111b) 的 $\Delta y_{EB}$、(3.111g–h) 引用未知的 $\Delta y_{NA}$、(3.111i) 分子 $\Delta y_{BA}$），见 [[queries/式3-111系列下标与符号是否错乱]]。

**证据类型：**(3.110a–g) 直接证据且自洽（中高）；(3.110h) 与 (3.111) 含疑点，整体 medium。
