# 式 17.47–17.49 相关维数与瑞尼维数谱转录复算

## 转录

```latex
% dist_m(x_i,x_j) = max_{0<=s<=m} ‖y_{i+s} − y_{j+s}‖；Θ 为赫维赛德函数
C^m(eps) = limsup_{N->inf} (1/N^2) card{(x_i,x_j) : dist(x_i,x_j) < eps}
         = limsup_{N->inf} (1/N^2) sum_{i,j} Θ(eps − dist(x_i,x_j))              (17.47a)
d_K = lim_{eps->0} ln C^m(eps) / ln eps                                          (17.47b)

H_q(eps) = 1/(1−q) ln sum_{i=1}^{n(eps)} p_i(eps)^q                              (17.48a)
d_q = − lim_{eps->0} H_q(eps)/ln eps                                             (17.48b)
q=0: d_0 = d_C(supp mu);  q=1: d_1 = lim_{q->1} d_q = d_I(mu);  q=2: d_2 = d_K   (17.49a–c)
```

## 复算

- **$q\to1$ 极限（17.49b）**：$\sum_ip_i^q=\sum_ip_i e^{(q-1)\ln p_i}=1+(q-1)\sum_ip_i\ln p_i+o(q-1)$，故 $H_q=\tfrac1{1-q}\ln\sum_ip_i^q\to-\sum_ip_i\ln p_i=H(\varepsilon)$（标准极限）⟹ $d_1=d_I(\mu)$ 自洽 ✓。
- **$q=0$（17.49a）**：$\sum_ip_i^0=\mu$-非空方体个数 $=n(\varepsilon)$ ⟹ $H_0=\ln n(\varepsilon)$，$d_0=-\lim\ln n(\varepsilon)/\ln\varepsilon=\lim\ln n(\varepsilon)/\ln(1/\varepsilon)$，即支撑的容量 $d_C(\operatorname{supp}\mu)$ ✓。
- **$q=2$（17.49c）**：$H_2=-\ln\sum_ip_i^2$；点对落入同一方体的概率 $\approx\sum_ip_i^2$，与相关积分 (17.47a) 的计数同构 ⟹ $d_2=d_K$ 的断言框架自洽（源文为断言，未证）。
- **负号对照**：(17.48b) $d_q=-\lim H_q/\ln\varepsilon$ 带负号，而 (17.45) 无 ⟹ 为 [[queries/信息维数定义式脱负号之辨]] 提供第二重证据（连同极限环例为双重佐证）。
- **赫维赛德函数**：$\Theta(x)=0\ (x\le0);\ 1\ (x>0)$——(17.47a) 的 card 形式用「dist$<\varepsilon$」而 Θ 形式为 $\Theta(\varepsilon-\mathrm{dist})$（含等号），边界口径略有出入，不影响标度指数。

## 判定

谱系统（$d_0/d_1/d_2$ 特例与统一公式）复算自洽；唯一数学实质疑点仍是 (17.45) 的负号（本组公式反而坐实其脱漏）。
