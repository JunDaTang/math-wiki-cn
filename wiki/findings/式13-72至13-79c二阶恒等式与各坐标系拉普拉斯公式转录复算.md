# 式 13.72–13.79c 二阶恒等式与各坐标系拉普拉斯公式转录复算

对 13.2.6.4 与 13.2.6.5（定义及各坐标系公式）逐一复算：

| 式号 | 内容 | 判定 |
|---|---|---|
| (13.72)(13.74) | div rot ≡ 0；div grad = ΔU | ✓ 内容正确，转写疑漏点乘「·」 |
| (13.73)(13.75) | rot grad ≡ 0⃗；Δ = ∇·∇ = ∇² | ✓ |
| (13.76) | 笛卡儿 Δ | ✓（(13.79a) 特化核验） |
| (13.77) | 柱面 Δ | ✓（(13.79a) 特化核验，逐项吻合） |
| (13.78) | 球面 Δ | **✗ 末项 sin ϑ 应为 sin²ϑ** |
| (13.79a–c) | 一般直角坐标 Δ | ✓（仅对正交系成立，D 相当于 h₁h₂h₃） |

## 核心结果：(13.78) 球面拉普拉斯末项疑缺平方

转写本 (13.78) 末项系数为 $\frac{1}{r^2\sin\vartheta}\frac{\partial^2 U}{\partial\varphi^2}$，应为 $\frac{1}{r^2\sin^2\vartheta}\frac{\partial^2 U}{\partial\varphi^2}$。双重独立证据：

1. **标准公式**：球面坐标系拉普拉斯算子的 φ 项系数为 $\frac{1}{r^2\sin^2\vartheta}$。
2. **内部一致性检验（直接证据）**：将 (13.79a) 取球面度规 h_r = 1, h_ϑ = r, h_φ = r sin ϑ 特化（此时 D = r² sin ϑ，D/h_φ² = 1/sin ϑ），r 项与 ϑ 项均与 (13.78) 吻合，唯 φ 项得 $\frac{1}{r^2\sin^2\vartheta}$。

两种独立方法指向同一结论，故本页 replicated: true、confidence: high。疑为上标 2 的转写丢失或印刷脱漏，需核对纸质书，见 [[queries/式13-78球面拉普拉斯末项sinϑ疑缺平方]]。

## 影响范围限定

- 该错误仅属 (13.78)，**不得归咎于** 13.2.2 已复算无误的球面梯度公式 (13.38)（见 [[findings/式13-36至13-39各坐标系梯度公式转录复算]]）。
- (13.76)(13.77) 经同一特化法核验逐项吻合，不受影响。
