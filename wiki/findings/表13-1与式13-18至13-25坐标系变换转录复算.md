# 表 13.1 与式 13.18–13.25 坐标系变换转录复算

## 复算对象

13.1.3.4 节：表 13.1（笛卡儿、柱面、球面坐标系中向量分量的关系）与式 (13.18)–(13.25)。

## 复算方法

以单位向量的点积（投影）重建全部公式：

- 柱面系：$\vec{e}_\rho = \cos\varphi\,\vec{i} + \sin\varphi\,\vec{j}$，$\vec{e}_\varphi = -\sin\varphi\,\vec{i} + \cos\varphi\,\vec{j}$，$\vec{e}_z = \vec{k}$；
- 球面系：$\vec{e}_r = \sin\vartheta\cos\varphi\,\vec{i} + \sin\vartheta\sin\varphi\,\vec{j} + \cos\vartheta\,\vec{k}$，$\vec{e}_\vartheta = \cos\vartheta\cos\varphi\,\vec{i} + \cos\vartheta\sin\varphi\,\vec{j} - \sin\vartheta\,\vec{k}$，$\vec{e}_\varphi = -\sin\varphi\,\vec{i} + \cos\varphi\,\vec{j}$。

## 复算结果

1. **式 (13.18)–(13.21) 四组公式全部正确**（含 (13.20) 中不寻常的项序 $-V_\varphi\sin\varphi + V_\vartheta\cos\varphi\cos\vartheta$，数学上与标准排列等价）。
2. **表 13.1 柱面列全部正确**。
3. **表 13.1 球面列全部正确**，且各行隐含单位向量投影关系：$\vec{e}_\rho = \sin\vartheta\,\vec{e}_r + \cos\vartheta\,\vec{e}_\vartheta$、$\vec{e}_r = \sin\vartheta\,\vec{e}_\rho + \cos\vartheta\,\vec{e}_z$、$\vec{e}_\vartheta = \cos\vartheta\,\vec{e}_\rho - \sin\vartheta\,\vec{e}_z$，$\vec{e}_\varphi$ 两系相同——这些即柱面 ↔ 球面直换公式。
4. **唯一疑误**：倒数第二行（$V_\vartheta$ 行）**笛卡儿列**作 $V_x\cos\vartheta\cos\varphi + V_y\cos\vartheta\sin\varphi - V_z\sin\varphi$，其中 $-V_z\sin\varphi$ 应为 $-V_z\sin\vartheta$，与式 (13.21) 第二式直接矛盾；复算判定式 (13.21) 正确（见 [[表13-1的Vϑ行sinφ疑为sinϑ]]）。该行的柱面列与球面列不受影响。
5. **(13.22)/(13.23)**：球面/柱面向量场的笛卡儿表示；与 (13.13a)/(13.15a) 相比，标量函数 $\varphi$ 为同名异义的重新定义（分别差 $r$ 或 $\rho$ 因子）。
6. **正文句疑误**：对球面向量场"球面坐标系，即形式 $\vec{V} = V(r)\vec{e}_\tau$ 最易于进行研究"（$\tau$ 疑为 $r$）；对柱面向量场"柱面坐标系，即形式 $\vec{V} = V(\varphi)\vec{e}_\varphi$ 最方便"疑为 $V(\rho)\vec{e}_\rho$ 之讹（与 (13.15a)、(13.25) 矛盾，见 [[柱面向量场坐标形式疑为Vρeρ]]）。
7. **(13.24)**：平面向量场两种表示一致。通过。
8. **(13.25)**：$\varphi(\sqrt{x^2+y^2})(x\vec{i}+y\vec{j}) = \varphi(\rho)\cdot\rho\cdot\vec{e}_\rho$，与右端 $\varphi(\rho)\vec{e}_\rho$ 相差 $\rho$ 因子——第二个 $\varphi$ 须理解为重新定义的函数（见 [[式13-25圆场标量函数记号差ρ因子疑误]]）。

## 结论

表 13.1 与式 (13.18)–(13.21) 是本节最可复用的资产；除表内一处讹误与三处记号疑点外全部复算通过。公式可由单位向量投影独立重建，置信度高。
