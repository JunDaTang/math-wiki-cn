# 大圆航程与航向角算例（式 3.197 及两例）

3.4.2.2 第 8 条「球面几何基本公式的应用」给出两个导航算例，全部数值原样保留如下。

## 距离公式（式 3.197）

对地理坐标 (λ₁, φ₁)、(λ₂, φ₂) 与北极 N 组成的球面三角形 P₁P₂N，两条子午线边与经度差夹角由余弦定律 (3.188c) 给出：

```
cos e = sin φ₁ sin φ₂ + cos φ₁ cos φ₂ cos(λ₂ − λ₁)    (3.197)
```

## 例 1：德累斯顿—阿拉木图的大圆距离

```
德累斯顿 (Dresden):   λ₁ = 13°46′, φ₁ = 51°16′
阿拉木图 (Alma Ata):  λ₂ = 76°55′, φ₂ = 43°18′
（本例指派：a = 90°−φ₂, b = 90°−φ₁, γ = λ₂−λ₁）
cos e = 0.53498 + 0.20567 = 0.74065,   e = 42.213°
应用 (3.175a)：大圆弧段 P₁P₂ 的长 = 4694 km
```

## 例 2：孟买—达累斯萨拉姆的航程与航向角

```
孟买 (Bombay):              λ₁ = 72°48′, φ₁ = 19°00′
达累斯萨拉姆 (Dar es Salaam): λ₂ = 39°28′, φ₂ = −6°49′
（本例指派：a = 90°−φ₁ = 71°00′, b = 90°−φ₂ = 96°49′, γ = λ₁−λ₂ = 33°20′）
由 (3.188c)：e = 41.777°
按 1′ ≈ 1 n mile：P₁P₂ ≈ 2507 n mile
由 (3.188a/b)：
  α = arccos[(cos a − cos b cos c)/(sin b sin c)] = 51.248°
  β = arccos[(cos b − cos a cos c)/(sin a sin c)] = 125.018°
航向角：
  δ₁ = 360° − β = 234.982°
  δ₂ = 180° + α = 231.248°
```

两例的 a/b 指派相反（见 [[queries/两算例ab指派与角盈符号E是否原书如此]]）；因所用公式对 a、b 对称，距离结果不受影响。

## 复核状态（独立复算）

入库分析对两例独立复算全部吻合：

- arccos 0.74065 ≈ 42.2°；42.213° × (π/180) × 6371 km ≈ 4694 km；
- 例 2 的 cos e、α、β 复算一致（例如以 a、b、e 代入半角公式 3.192a 得 α ≈ 51.247°，与手册的 51.248° 在舍入内一致）；e = 41.777° = 2506.6′ ≈ 2507 n mile。

## 评注

手册提醒：**只有当问题中的角明显是锐角或钝角时，应用正弦定律确定边和角才有意义**——即 SSA 二义性的球面版警示（对照 [[findings/一般三角形四个基本问题与SSA分支]]）。

计算流程的抽象见 [[methodology/大圆航程与航向角计算流程]]；δ₁、δ₂ 的换算与 [[findings/方位角象限判定与反方位角]] 的反方位角处理同族，海里换算则用到 [[concepts/度分秒]] 的 1′≈1 n mile 约定。
