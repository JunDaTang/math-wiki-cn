# 坐标变换等价于逆几何变换（式 3.444–3.447、3.459–3.463）

## 内容

**定理**：坐标系的变换等价于对象的逆变换。二维推导（源文直接给出）：若借助向量 $\vec t$ 将坐标系移位，则点 $P(x_P, y_P)$ 的坐标成为 $x_P - t_x,\ y_P - t_y$，即坐标系沿 $\vec t$ 平移的结果与点沿 $-\vec t$ 平移的结果相同；旋转与缩放同理（图 3.205）。矩阵层面，坐标变换矩阵 $\bar T, \bar R, \bar S$ 与几何变换矩阵（式 3.440–3.442）的关系为：

$$\bar T(t_x, t_y) = T(-t_x, -t_y) = T^{-1}(t_x, t_y),\tag{3.444}$$

$$\bar R(\alpha) = R(-\alpha) = R^{-1}(\alpha),\tag{3.445}$$

$$\bar S(s_x, s_y) = S\!\left(\frac{1}{s_x}, \frac{1}{s_y}\right) = S^{-1}(s_x, s_y),\tag{3.446}$$

一般形式 $\underline{\boldsymbol x}'_P = \bar M\, \underline{\boldsymbol x}_P$（式 3.447，矩阵结构同式 3.439）。三维同理（式 3.459–3.463）：

$$\bar T = T^{-1},\qquad \bar R_x = R_x^{-1},\qquad \bar R_y = R_y^{-1},\qquad \bar R_z = R_z^{-1},\qquad \bar S = S^{-1}.$$

## 评估

- **证据强度：强**（初等代数可复算）：平移情形由坐标减法直接可见；旋转／缩放情形由 $R(-\alpha) = R(\alpha)^{-1}$、$S(1/s) = S(s)^{-1}$ 的矩阵代数立即得出。
- 这是[[concepts/几何变换]]（主动）与[[concepts/坐标变换]]（被动）两大主线的对偶枢纽，系统对照见 [[comparisons/几何变换与坐标变换比较]]。
- 该对偶在三维绕轴旋转构造中闭合：把空间直线主动变换到 z 轴的矩阵 $M_A$ 数值上等同于世界系→局部系的坐标变换矩阵（式 3.464），见 [[findings/世界与局部坐标系变换矩阵与绕轴旋转构造]]。
