# 式 19.274–19.279 浮点四则与误差限转录复算

## 转录（按原文）

```latex
x = m_1 B^{E_1},\quad y = m_2 B^{E_2}                                    (19.274a)
m_i = \sum_{k=1}^{t} a_{-k}^{(i)} B^{-k},\quad a_{-1}^{(i)} \neq 0        (19.274b)
a_{-k}^{(i)} = 0 \text{或} 1 \text{或} \dots \text{或} B-1,\ k>1\ (i=1,2)  (19.274c)

% 加法：B^{-1} \leqslant |m_1 + m_2 B^{-(E_1-E_2)}| < 2；若 \geqslant 1 则小数点左移一位、指数增 1   (19.275a,b)
% 减法：|m_1 - m_2 B^{-(E_1 - E^2)}| < 1 - B^{-t}；若 < B^{-t} 则小数点右移、指数相应减少           (19.276a,b)
% 乘法：指数相加尾数相乘；若 m_1 m_2 < B^{-1} 则小数点右移一位、指数减 1                            (19.277)
% 除法：指数相减尾数相除；若 m_1/m_2 \geqslant 1 则小数点左移一位、指数增 1                          (19.278)
% 无误差操作数下四则运算相对误差上限：
\frac{B}{2} B^{-t}                                                                                   (19.279)
```

## 算例复算

| 算例 | 原文结果 | 复算 | 判定 |
|---|---|---|---|
| 加法 $0.9604\cdot 10^3+0.5873\cdot 10^2$ | $0.1019\cdot 10^4$ | $0.9604+0.05873=1.01913\to 0.1019\cdot 10^4$ | ✓ |
| 减法 $0.1004\cdot 10^3-0.9988\cdot 10^2$ | $0.5200\cdot 10^0$ | $0.1004-0.09988=0.00052\to 0.5200\cdot 10^0$；末两位"00"为补零（临界情形） | ✓ |
| 乘法 $(0.1004\cdot 10^3)\cdot(0.2504\cdot 10^5)$ | $0.07952704\cdot 10^8=0.7953\cdot 10^7$ | $0.1004\times 0.2504=0.02514016$ **不符**；$0.3176\times 0.2504=0.07952704$ **恰合** | ✗（首因子疑讹） |
| 除法 $(0.3176\cdot 10^3)/(0.2504\cdot 10^5)$ | $1.2683706\cdot 10^{-2}=0.1268\cdot 10^{-1}$ | $0.3176/0.2504=1.268370\dots$；$0.2504\times 1.2683706\approx 0.31760$ | ✓ |

## 乘法算例疑点（复算证据最强的一处）

$0.1004\times 0.2504=0.02514016\neq 0.07952704$；而 $0.3176\times 0.2504=0.07952704$ 与所给结果尾数**精确**一致，指数 $3+5=8$ 亦合。旁证：紧随其后的除法算例恰好使用操作数 $0.3176\cdot 10^3$ 与 $0.2504\cdot 10^5$。故首因子疑为 $0.3176\cdot 10^3$，"0.1004"疑为上一减法算例操作数的串入。详见 [[queries/乘法算例首因子0-1004疑为0-3176之辨]]。

## 其他疑点

- (19.276a) 之 $E^2$ 疑为 $E_2$（下标转写讹）。
- (19.276b) 后“则将十进制小数点右移 的最大值位”脱移位位数说明。
- (19.279) 前文“对于位置为 基为 的数”脱 $t$ 与 $B$。
- 均见 [[queries/19-8-2全节系统性转写讹误清单]]。

## 结论

浮点表示与四则运算的判定条件（19.274–19.278）结构自洽；误差限 (19.279) $\frac{B}{2}B^{-t}$ 仅在“操作数无误差”假定下对四种基本运算成立（原文明确限定），不可外推到复合算法。流程整理见 [[methodology/浮点四则运算对阶与再规格化流程]]。
