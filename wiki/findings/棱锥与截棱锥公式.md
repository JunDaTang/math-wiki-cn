# 棱锥与截棱锥公式（式 3.127–3.132）

**直接证据**（源文 3.3.3(6)–(7)，图 3.57–3.59）。

**棱锥**（底为多边形、侧面为共顶点 S 的三角形）：

$$V = \frac{A_G h}{3} \tag{3.127}$$

正棱锥（直棱锥 + 正多边形底）的侧面积：

$$M = \frac{1}{2}\,p\,h_s \tag{3.128}$$

p 为底周长（转写脱落），h_s 为一个侧面的高。

**截棱锥**（顶被平行于底的平面截去；SO 为原棱锥的高）——截断相似比：

$$\frac{\overline{SA_1}}{\overline{A_1A}} = \frac{\overline{SB_1}}{\overline{B_1B}} = \frac{\overline{SC_1}}{\overline{C_1C}} = \ldots = \frac{\overline{SO_1}}{\overline{O_1O}} \tag{3.129}$$

两底面积之比（面积平方律）：

$$\frac{\text{面积}\ ABCDEF}{\text{面积}\ A_1B_1C_1D_1E_1F_1} = \left(\frac{\overline{SO}}{\overline{SO_1}}\right)^{2} \tag{3.130}$$

体积（A_D、A_G 为上、下底面积，h 为两底间距，a_D、a_G 为对应边）：

$$V = \frac{1}{3}h\left[A_G + A_D + \sqrt{A_G A_D}\right] = \frac{1}{3}h A_G\left[1 + \frac{a_D}{a_G} + \left(\frac{a_D}{a_G}\right)^{2}\right] \tag{3.131}$$

正截棱锥的侧面积：

$$M = \frac{p_D + p_G}{2}\,h_s \tag{3.132}$$

**独立核验（已复核）**：

- 3.131 两形式由 A_D = A_G(a_D/a_G)²（相似底）互相转换，代数恒等；
- 端点退化自洽：A_D → A_G 时 3.131 退化为柱 V = A_G h（式 3.116），A_D → 0 时退化为锥 A_G h/3（式 3.127）——「两端点 + 几何平均项」的结构与 [[findings/锥体族公式]] 的 3.154 同型；
- 3.129–3.130 与 [[findings/三角形相似定理四条与面积平方律]] 同构（截棱锥侧面梯形可剖分为相似三角形）。

**转写残留**：3.130 后的「成 $\underline{\vec{\mathbf{\Pi}}}$」为乱码残留，疑为「成比」。
