# 式 16.76–16.85 对数正态、指数与韦布尔分布转录复算

对 [[10-数学手册原书第10版--9-1624-连续分布--1ktbozm]] 16.2.4.3–16.2.4.5 的编号公式逐字转录并手工复算。结论：全部与标准结果一致，无数学性疑点；仅有纯转写讹误（「a=l」「r(x)」、页码粘连）。

## 对数正态分布（16.2.4.3）

```
(16.76)   Y = log X
(16.77a)  f(t) = 0 (t ⩽ 0);  (log e)/(t·σ_L·√(2π))·exp(−(log t − μ_L)²/(2σ_L²)) (t > 0)
(16.77b)  F(x) = 0 (x ⩽ 0);  1/(σ_L·√(2π))·∫_{−∞}^{log x} exp(−(t−μ_L)²/(2σ_L²)) dt (x > 0)
(16.78)   μ = exp(μ_L + σ_L²/2),  σ² = (exp σ_L² − 1)·exp(2μ_L + σ_L²)
(16.79)   F(x) = Φ((log x − μ_L)/σ_L)
```

复算：

- (16.77a,b)：由 Y = log X 的正态密度经变换可得 f_X(x) = f_Y(log x)·(1/(x·ln b))（b 为对数底）；因子 (log e) = log_b e = 1/ln b 正是底换算因子，自然对数时为 1，公式退化为标准形式——一致；
- (16.78)：与标准对数正态矩 E[X] = e^{μ+σ²/2}、Var[X] = (e^{σ²}−1)e^{2μ+σ²} 一致；
- (16.79)：F(x) = P(X ⩽ x) = P(Y ⩽ log x) = Φ((log x − μ_L)/σ_L)——一致。

## 指数分布（16.2.4.4）

```
(16.80a)  f(t) = 0 (t < 0);  λ·e^{−λt} (t ⩾ 0)
(16.80b)  F(x) = 0 (x < 0);  1 − e^{−λx} (x ⩾ 0)
(16.81)   μ = 1/λ,  σ² = 1/λ²
```

复算：密度归一、分布函数为密度的积分、矩由 [[Γ函数]] 可得 E = Γ(2)/λ = 1/λ、D² = Γ(3)/λ² − (1/λ)² = 1/λ²——均一致。

## 韦布尔分布（16.2.4.5）

```
(16.82a)  f(t) = 0 (t < 0);  (α/β)·(t/β)^{α−1}·exp[−(t/β)^α] (t ⩾ 0)
(16.82b)  F(x) = 0 (x < 0);  1 − exp[−(x/β)^α] (x ⩾ 0)
(16.83)   μ = β·Γ(1+1/α),  σ² = β²·[Γ(1+2/α) − Γ²(1+1/α)]
(16.84)   Γ(x) = ∫_{0}^{∞} t^{x−1}·e^{−t} dt (x > 0)
(16.85)   F(x) = 1 − exp[−((x−γ)/β)^α]   （三参数形式）
```

复算：

- (16.82a) 是 (16.82b) 的导数——一致；
- (16.83)：令 U = (X/β)^α 服从 Exp(1)，可得 E[X^k] = β^k·Γ(1+k/α)，故 μ = βΓ(1+1/α)、σ² = β²[Γ(1+2/α) − Γ²(1+1/α)]——与标准韦布尔矩一致；
- (16.84)：与 [[Γ函数]] 页所载定义一致；
- (16.85)：三参数形式为位置平移 γ——一致；
- α=1 退化：α=1 时 (16.82a) 为 (1/β)e^{−t/β}，即 λ=1/β 的指数分布——验证成立（原文「a=l」为「α=1」之转写讹误）。

## 转写讹误记录（不影响数学内容）

- 「a=l λ = 1/β 时」→「α=1、λ=1/β 时」；
- 「此处，r(x) 表示 函数」→「Γ(x) 表示 Γ 函数」；
- 页码回指粘连：「第 682 8.2.5, 6.」（Γ 函数）、「第 1071 b」（对数正态）。
