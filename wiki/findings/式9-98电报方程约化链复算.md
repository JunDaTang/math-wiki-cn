# 式 9.98 电报方程约化链转录复算

## 逐字转录

```
a u_tt + 2b u_t + cu = u_xx（a > 0，b、c 常数）                       (9.98a)
u = z e^{−(b/a)t} ⇒ z_tt = m²z_xx + n²z，m² = 1/a，n² = (b²−ac)/a²   (9.98b)
ξ = (n/m)(mt+x)，η = (n/m)(mt−x) ⇒ z_{ξη} − z/4 = 0                  (9.98c/d)
w = (ξ−ξ₀)(η−η₀)，v = f(w)：w f″ + f′ − f/4 = 0                      (9.98e/f)
w = α² ⇒ f″ + (1/α)f′ − f = 0（原文称“零阶贝塞尔微分方程”）           (9.98g)
v = I₀[√((ξ−ξ₀)(η−η₀))]                                             (9.98h)
z|_{t=0} = f(x)，z_t|_{t=0} = g(x)                                   (9.98i)
z(x,t) = ½[f(x−mt) + f(x+mt)]
  + ½∫_{x−mt}^{x+mt}[g(s)·I₀((n/m)√(m²t²−(s−x)²))/m
    − f(s)·nt·I₁((n/m)√(m²t²−(s−x)²))/√(m²t²−(s−x)²)]ds             (9.98j)
```

## 复算核验（约化链全部通过）

1. **消阻尼**：u = z e^{−(b/a)t} 代入 (9.98a)，一阶时间导数项相消，得 (9.98b)，其中 n² = (b² − ac)/a² ✓。
2. **化典范形式**：在 ξ = (n/m)(mt+x)、η = (n/m)(mt−x) 下方程化为 z_{ξη} − z/4 = 0（双曲第一典范形式）✓。
3. **黎曼函数**：w = (ξ−ξ₀)(η−η₀) 时 w f″ + f′ − f/4 = 0；w = α² 化为 f″ + (1/α)f′ − f = 0，即零阶**变形**贝塞尔方程，解 I₀(α) = I₀(√w)，且在 ξ = ξ₀、η = η₀ 处取值 1，满足黎曼函数条件 ✓。
4. **解式**：9.98j 中 I₀/I₁ 的宗量 (n/m)√(m²t² − (s−x)²) 与 (ξ−ξ₀)(η−η₀) 的变量换算一致 ✓，整体与经典电报方程解形式相符 ✓。

## 两点保留

1. **称谓**：(9.98g) 实为零阶变形贝塞尔方程（解 I₀），原文称“零阶贝塞尔微分方程”，与 [[贝塞尔微分方程]] 页需辨析；I₀/I₁ 见 [[变形贝塞尔函数与麦克唐纳函数]]。
2. **隐含假设**：n² = (b² − ac)/a² 可为负（ac > b² 时），此时 (9.98c) 的变换与 I₀ 均失效（I₀(iz) = J₀(z)，应换 J₀），原文未讨论，见 [[queries/电报方程n平方为负情形为何未讨论]]。
