# images-64 锚位哈希资产增至十一枚

images--64 锚位（"images--64"）下已登记 source 页的哈希图像资产，按现行维基索引的源页计数已达十一枚。本发现续接并更新 [[images-64锚位哈希资产增至五枚]] 的计数事实。

这一"十一枚"计数来自两次入库观察（分别随 sszxml 与 fn7e00 的入册/入库作出），两次观察对"第十一枚"的记载不同：

- **sszxml 入册观察**：本枚 `0d62a9611b17174c512f2f1c4bd025e0b7a27b41c67267d747d47fdc61270276.jpg`（短码 sszxml，source 页见 [[10-数学手册原书第10版--6-images--64-0d62a9611b17174c512f2f1c4bd025e0b7a27b41c67267d747d47fdc61270276--sszxml]]）入册后，锚位下已登记的 source 页哈希资产增至十一枚。
- **fn7e00 入库观察**：随着 `0d139d5f0fe109e57f43d15d732211e70bf6f932bc89c5452df2c146824dba9b.jpg`（短标识 fn7e00，source 页见 [[10-数学手册原书第10版--6-images--64-0d139d5f0fe109e57f43d15d732211e70bf6f932bc89c5452df2c146824dba9b--fn7e00]]）入库，锚位下的哈希图像资产按当前维基索引计已达十一枚。

两次观察共享同一批十枚存量资产，差异仅在第十一枚。

## 口径说明

- 两次观察均以现行 wiki 索引登记的 images-64 source 页为准，属直接证据；images 目录中是否尚有未入库资产，不在本计数能及范围。
- 既有 [[images-64锚位哈希资产增至五枚]] 题称"五枚"，与上述十枚存量不符，其计数口径（过期未更新，抑或仅计某子集）待人工核对；本发现的"十一枚"计数即是对该发现计数事实的续接与更新。
- 第十一枚之异见上方警示，须人工复核后方可定论。

## 哈希排序观察（弱推断，须与直接证据区分）

- 既有资产哈希按 0a→0b 顺序枚举，sszxml（0d62a961）的 0d 前缀表明入库序列继续推进；此为排序观察，不构成对图像内容的任何判断。（fn7e00 之 0d139d5f 亦为 0d 前缀，且在 fn7e00 入库观察的清单中列于 0b 序列之后。）

## 解读

- 锚位序号 64 是目录级锚位，被多枚互不相同的哈希共享，不具唯一性；唯一可靠的资产键是完整 SHA-256 哈希——这正是 [[插图资产哈希入库法]] 的现行做法，应坚持。
- 未鉴定图像持续积压，与 [[图像资产与文本对位]] 的最终目标形成工作量张力；集合层面追踪见 [[images目录图像未鉴定之辨]]，锚位共享现象另见 [[images-64锚位双哈希资产之辨]]。
