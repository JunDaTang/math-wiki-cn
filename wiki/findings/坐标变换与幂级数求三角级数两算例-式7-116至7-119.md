# 坐标变换与幂级数求三角级数两算例（式 7.116–7.119）

## 主张（依源转录）

第 1378 页的表 21.6 给出某些简单函数在某一区间上的傅里叶展开式。两种使用技巧：

1. **坐标变换的应用（7.4.5.1）**：改变坐标轴标度或平移原点，可把许多简单周期函数化简成表 21.6 中的形式。
2. **复函数级数展开式的应用（7.4.5.2）**：表 21.6 中许多展开式可利用复变量函数的幂级数展开得到。

```latex
% (7.116a/b) 偶函数方波（图 7.9）：f(x) = f(-x)，利用代换 a = 1（疑脱参数说明），
% 引入 Y = y - 1、X = 2pi x/T + pi/2 化为表 21.6 中的第 _ 种形式（序号脱漏），
% 再用恒等式 sin((2n+1)(2pi x/T + pi/2)) = (-1)^n cos((2n+1)·2pi x/T) 回代
y = 2   (0 < x < T/4),    y = 0   (T/4 < x < T/2)
y = 1 + (4/pi)(cos(2pi x/T) - (1/3) cos(3·2pi x/T) + (1/5) cos(5·2pi x/T) - ...)

% (7.117/7.118/7.119) 由 1/(1-z) 的幂级数展开取 z = a e^{i phi} 分离实虚部
1/(1 - z) = 1 + z + z^2 + ...   (|z| < 1),    z = a e^{i phi}
1 + a cos phi + a^2 cos 2 phi + ... + a^n cos n phi + ... = (1 - a cos phi)/(1 - 2a cos phi + a^2)
a sin phi + a^2 sin 2 phi + ... + a^n sin n phi + ... = a sin phi/(1 - 2a cos phi + a^2)    (|a| < 1)
```

## 复算（通过）

1. **三角恒等式**：sin((2n+1)(θ + π/2)) = sin((2n+1)θ + nπ + π/2) = (−1)^n·sin((2n+1)θ + π/2) = (−1)^n cos((2n+1)θ)。✅
2. **方波级数（7.116b）抽查**：设 θ = 2πx/T。
   - x = 0（连续点，f = 2）：级数 = 1 + (4/π)(1 − 1/3 + 1/5 − ⋯) = 1 + (4/π)(π/4) = 2。✅
   - x = T/2（连续点，f = 0）：cos nπ = (−1)^n，级数 = 1 − (4/π)(1 − 1/3 + 1/5 − ⋯) = 0。✅
   - x = T/4（跳跃点，左极限 2、右极限 0）：cos((2k+1)π/2) = 0，级数 = 1 = ½(2+0)，符合狄利克雷中值规则（与 [[findings/狄利克雷条件与间断点中值收敛]] 交叉印证）。✅
   - 常数项核对：一个周期内 y = 2 与 y = 0 各占半个周期，均值 = 1 = a_0/2。✅
3. **幂级数求和（7.119）**：1/(1 − ae^{iφ}) = (1 − ae^{−iφ})/[(1 − ae^{iφ})(1 − ae^{−iφ})] = [(1 − a cos φ) + i a sin φ]/(1 − 2a cos φ + a²)；其实部、虚部分别等于 Σ_{n≥0} aⁿcos nφ、Σ_{n≥1} aⁿsin nφ（|a| < 1 保证绝对收敛，可逐项取实虚部）。与式 7.119 两条公式逐一相符。✅
