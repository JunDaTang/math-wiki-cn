# 式 9.142–9.147 线性谐振子转录复算

## 转录

```latex
\nu=\frac{1}{2\pi}\sqrt{\frac{k}{m}},\quad \omega=\sqrt{\frac{k}{m}},\quad
E_{\mathrm{pot}}=\frac{1}{2}kx^{2}=\frac{\omega^{2}}{2}x^{2}            % ⚠ 9.142c
\frac{d^{2}\Psi}{dx^{2}}+\frac{2m}{\hbar^{2}}\Big[E-\frac{\omega^{2}}{2}mx^{2}\Big]\Psi=0                % 9.143a
y=x\sqrt{\frac{m\omega}{\hbar}},\qquad \lambda=\frac{2E}{\hbar\omega}                                    % 9.143b,c
\frac{d^{2}\Psi}{dy^{2}}+(\lambda-y^{2})\Psi=0                                                           % 9.143d
\Psi(y)=e^{-y^{2}/2}H(y)                                                                                 % 9.144a
\frac{d^{2}H}{dy^{2}}-2y\frac{dH}{dy}+(\lambda-1)H=0                                                     % 9.144c
H=\sum_{i=0}^{\infty}a_iy^{i}                                                                            % 9.145a
\sum_{i=2}^{\infty}i(i-1)a_iy^{i-2}-\sum_{i=1}^{\infty}2ia_iy^{i}+\sum_{i=0}^{\infty}i(\lambda-1)a_iy^{i}=0   % ⚠ 9.145b
(j+2)(j+1)a_{j+2}=[2j-(\lambda-1)]a_j                                                                    % 9.145c
a_{n+2}=\frac{2n-(\lambda-1)}{(n+2)(n+1)}a_n,\qquad 2n-(\lambda-1)=0,\ \lambda=\frac{2E}{\hbar\omega}=2n+1   % 9.146a,b
H_0=1,\ H_1=2y,\ H_2=-2+4y^{2},\ H_3=-12y+8y^{3},\ H_4=12-48y^{2}+16y^{4},\ H_5=120y-160y^{3}+32y^{5}    % 9.146c
\Psi_n=N_ne^{-y^{2}/2}H_n(y),\qquad N_n^{2}=\frac{1}{2^{n}n!}\sqrt{\frac{\alpha}{\pi}},\ \sqrt{\alpha}=\sqrt{\frac{m\omega}{\hbar}}  % 9.147a,b
E_n=\hbar\omega\Big(n+\frac{1}{2}\Big)\ (n=0,1,2,\dots)                                                  % 9.147c
x_{\max,qu}=\pm\frac{1}{\sqrt{\lambda}}=\pm\sqrt{\frac{\hbar}{m\omega}},\qquad
x_{\max,kl}=\pm a=\pm\sqrt{\frac{2E}{m\omega^{2}}}=\pm\sqrt{\frac{3\hbar}{m\omega}}                       % 9.147d,e
```

## 复算与核对

- **9.142a/b**：频率公式 ✓。
- **9.143a**：把修正后的势能 (mω²/2)x² 代入定常薛定谔方程，与 9.142b 的 ω² = k/m 一致 ✓。
- **9.143b/c → 9.143d**：链式代换复算：d²/dx² = (mω/ℏ)d²/dy²，整理即 Ψ″ + (λ−y²)Ψ = 0 ✓。
- **9.144a → 9.144c**：Ψ = e^{−y²/2}H 求二阶导（9.144b）代入 9.143d，逐项消去 ✓。
- **9.145c 递推**：比较 y^j 系数（由 9.145a 直接代入 9.144c）：(j+2)(j+1)a_{j+2} − 2ja_j + (λ−1)a_j = 0 ✓。
- **9.146b**：截止条件 a_{n+2} = 0 ⟹ 2n − (λ−1) = 0 ⟹ λ = 2n+1 ✓；Eₙ = ℏω(n+½) ✓。
- **9.146c**：H₀–H₅ 逐项代入 Hₙ″ − 2yHₙ′ + 2nHₙ = 0 验证（n = 0,…,5）全部通过 ✓（物理学家型）。
- **9.147b**：归一化系数与标准结果一致 ✓。
- **9.147d/e 数值**：n=1 时 |Ψ₁|² ∝ y²e^{−y²}（H₁ = 2y），极大在 y = ±1，即 x = ±√(ℏ/mω)，与 x_max,qu = ±1/√λ（此处 λ = α = mω/ℏ）一致 ✓；经典转折点 ±√(2E/mω²) = ±√(3ℏ/mω)（E = (3/2)ℏω）✓。

## 疑点（高置信，依据为内部矛盾）

1. **9.142c 末式 (ω²/2)x² 疑漏因子 m**（应为 (mω²/2)x²）：与 9.143a 中的 (ω²/2)mx² 内部矛盾 → [[queries/式9-142c势能末式疑漏因子m]]。
2. **9.145b 第三和 Σi(λ−1)aᵢyⁱ 疑多乘因子 i**：由 9.145c 反推，去掉 i 后自洽 → [[queries/式9-145b第三和疑多乘因子i]]。
3. **9.147d 前文概率密度 dw_qu = 2√(λ/π)e^{−λx²}dx 疑漏乘因子 λx²**：若无该因子，密度极大在 x = 0，与 x_max,qu = ±1/√λ 矛盾；修正为 2√(λ/π)·λx²·e^{−λx²} 后与 n=1 波函数复算一致 → [[queries/式9-147d概率密度疑漏因子λx平方]]。
4. **λ 记号冲突**：9.147d 的 λ 实为 α = mω/ℏ，与 9.143c 的 λ = 2E/ℏω 含义不同 → 同上查询。
5. **9.2.4.7.3 「对于 n=l」疑应为 n=1**（所配能量 E = (3/2)ℏω 对应 n=1）→ [[queries/谐振子对n等于l疑为n等于1]]。
6. **「把这些代入 (9.114a)」疑应为 9.113a** → [[queries/谐振子一节代入9-114a还是9-113a]]；另「级数 (9.143c) 的有尽条件」的回指疑应为 9.145a/9.146b。

## 结论

推导链（化归、递推、截止、归一化、能谱）完整闭合且复算通过；上述疑点均为局部系数/记号问题，不动摇结论。模型页见 [[concepts/量子线性谐振子]]。
