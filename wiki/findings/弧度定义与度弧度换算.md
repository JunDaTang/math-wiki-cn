# 弧度定义与度弧度换算（式 3.1–3.2 与算例 A/B）

原书 3.1.1.5：任意一个圆的圆心角 $\alpha$ 的大小由对应弧长 $l$ 与半径 $r$ 之比给定；弧度的度量单位是 rad，即与弧长 $l$ 等于半径 $r$ 的弧对应的圆心角。

$$\alpha = \frac{l}{r} \tag{3.1}$$

$$\alpha^{\circ} = \varrho \alpha = 180^{\circ}\frac{\alpha}{\pi}, \qquad \alpha = \frac{\alpha^{\circ}}{\varrho} = \frac{\pi}{180^{\circ}}\alpha^{\circ}, \qquad \varrho = \frac{180^{\circ}}{\pi} \tag{3.2}$$

换算常数与特殊值（原文转写）：

```text
1 rad = 57°17′44.8″ = 57.2958°
1°    = 0.017453 rad
1′    = 0.000291 rad
1″    = 0.000005 rad
特殊值：360° = 2π，180° = π，90° = π/2，270° = 3π/2
```

算例（原文转写；公式 (3.2) 涉及小数，算例表明如何用分和秒进行计算）：

```text
■ A:  52°37′23″ = 52·0.017453 + 37·0.000291 + 23·0.0000005 = 0.918447 rad
■ B:  5.645 rad = 323·0.017453 + 26·0.000291 + 5·0.0000005 = 323°26′05″
      该结果得自
      5.645 : 0.017453     = 323 + 0.007611
      0.007611 : 0.000291  = 26 + 0.000025
      0.000025 : 0.0000005 = 5
```

## 独立验算（区分直接证据与复算）

- 换算常数经复算全部正确：$1\,\mathrm{rad} = 57.29578^{\circ} \approx 57.2958^{\circ}$（即 57°17′44.8″）；$1^{\circ} = 0.0174533\,\mathrm{rad} \approx 0.017453$；$1' = 0.00029089\,\mathrm{rad} \approx 0.000291$；$1'' = 0.0000048481\,\mathrm{rad} \approx 0.000005$。
- 算例 B 最终结果正确：$5.645\,\mathrm{rad} = 323.4347^{\circ} = 323^{\circ}26'04.8''$，四舍五入为 $323^{\circ}26'05''$。
- 算例 A 最终结果基本正确但非精确：$52^{\circ}37'23''$ 的精确值为 $0.9184456\,\mathrm{rad}$（保留 6 位小数为 0.918446），原文印作 0.918447，末位相差约 $1.4\times10^{-6}$ rad（≈0.3″）。
- 两算例的**中间算式**均与所列系数不自洽：算例 A 按所列系数只得 0.918335（秒系数 0.0000005 与常数表 0.000005 差一个数量级，改用后者亦只得 0.918438）；算例 B 除法链三步的余数与除数均有出入。详见 [[算例A系数与结果不自洽是否为讹误]]、[[算例B除法链数字是否为讹误]]；逐级除法程序及其精度限制见 [[度与弧度互化的逐级除法]]。

## 证据性质

式 3.1–3.2 与常数为标准数学知识（直接证据）；「最终结果基本正确、中间算式有讹」为独立复算所得结论（已验证）。
