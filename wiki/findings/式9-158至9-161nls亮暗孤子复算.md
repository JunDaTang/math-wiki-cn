# 式 9.158–9.161 NLS 亮孤子与暗孤子转录复算

## (9.159) 亮孤子——验证成立（high）

```latex
u = 2η exp(−i[2ξx + 4(ξ² − η²)t − χ]) / cosh[2η(x + 4ξt − φ)]
```

经相位/包络拟设独立推导：载波系数条件（拟设记号下 c = 4η² − b²）、包络速度 v = −4ξ、相速度 2(η² − ξ²)/ξ 全部复现。参数陈述（4 个无量纲参数 η, ξ, φ, χ；振幅 2η 与速度 −4ξ 可独立选取）与解式一致。

## (9.160) 暗孤子——验证成立（high）

```latex
u = ( i v/2 + √(η² − v²/4) tanh[√(η² − v²/4)(x − v t)] ) exp[−i(2η² t + χ)],  v < 2η
```

v = 0 情形（黑孤子）直接代入散焦（「−」号）NLS 验证成立；一般 v 形式与文献标准形一致（源文引 [9.41]、[9.39]）。参数陈述（η, v, χ 三个参数；常数背景 |u| = η；速度 v < 2η）与解式一致。

## (9.161) 带背景速度 c 的通解——括号位置疑误（medium-high）

按转写，tanh 乘在整个 (iv/2 + √(η²−v²/4)) 括号上：

```latex
u = ( i v/2 + √(η² − v²/4) ) tanh[√(η² − v²/4)(x − v t − c t)]
    × exp[−i( 2η² t + χ − (c/2) x + (c²/4) t )]
```

其相位因子与 (9.160) 的伽利略提升 e^{i(cx/2 − c²t/4)} 完全一致；但提升后的 (9.160) 中 tanh 只乘 √(η²−v²/4) 项（iv/2 项在 tanh 之外），与转写不符。疑括号位置错置，候选正确形式为

```latex
u = ( i v/2 + √(η² − v²/4) tanh[√(η² − v²/4)(x − v t − c t)] ) × exp[−i(2η² t + χ − (c/2) x + (c²/4) t)]
```
