# 式 12.161–12.167 连续线性泛函与 L^p 对偶转录复算

## 逐字转录

```
f(x) = Σ_{k=1}^n c_k x(t_k);   ‖f‖ = Σ_{k=1}^n |c_k|           (12.161)
δ_t(x) = x(t)  (x∈C([a,b]))                                    (12.162)
f(x) = ∫_a^b φ(t)x(t)dt;   ‖f‖ = ∫_a^b |φ(t)|dt                (12.163)
f(x) = (x,y);   ‖f‖ = ‖y‖                                      (12.164)
A^⊥ = {f∈X : f(x)=0, ∀x∈A},  A*^⊥ = {x∈X : f(x)=0, ∀f∈A*}      (12.165) ⚠️
‖f‖=‖φ‖ = {(∫|φ|^q dt)^{1/q}, 1<p⩽∞;  ess sup|φ|, p=1}         (12.166)
f(x) = (x,y) = ∫ x(t)·conj(y(t))dt;   ‖f‖ = ‖y‖_q              (12.167)
```

## 复算判定

- **(12.161) 范数复算无误**：$|f(x)|\le\sum|c_k|\cdot\|x\|_C$；在诸 $t_k$ 处取值 $\operatorname{sign}c_k$ 的连续函数（经插值）逼近取等。
- **(12.163) 复算无误**：$\|f\|=\int|\varphi|$ 在 $\mathcal{C}([a,b])$ 与 $B([a,b])$ 上均成立。
- **(12.162)**：$\delta_t$ 为 (12.161) 的单点特例，$\|\delta_t\|=1$。
- **(12.164) 复算无误**：$\|f\|=\|y\|$ 由 Cauchy–Schwarz 不等式及在 $x=y/\|y\|$ 处取等。
- **(12.165) 两处转写讹误**：首式 $f\in X$ 应为 $f\in X^*$（$A^\perp\subset X^*$）；“分别称作 $A^*$ 的正交补”应为“分别称作 $A$ 与 $A^*$ 的正交补”。见 [[queries/12-5全节系统性转写讹误清单]]。
- **(12.166)–(12.167) 复算无误**（限 $1\le p<\infty$；$p=\infty$ 情形源本身谨慎移交 [12.18]）。转写噪声：源注“（关于 $\exp|\varphi|$ 的定义参见 (12.221)）”中 "exp" 应为 **ess sup**，其定义在未入库的 12.9.4。
- **同名异义警示**：本段依赖的“赫尔德积分不等式”（回指 1.4.2.12，未入库）≠ 库内 [[concepts/赫尔德条件]]（赫尔德连续性）。
