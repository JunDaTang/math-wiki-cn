# 微分与积分算例复算

## 微分算例（20.3.4.1，例 A–G，均吻合）

- **A**：D[√(x³E^(4x)Sin[x]), x] = [E^(4x)x³cos x + 3E^(4x)x²sin x + 4E^(4x)x³sin x]/(2√(E^(4x)x³sin x)) — 乘积/链式法则逐项复算吻合。
- **B**：D[(2x+1)^(3x), x] = (1+2x)^(3x)(6x/(1+2x) + 3Log[1+2x]) — 对数求导法复算吻合。
- **C**：Dt[x³+y³] = 3x²Dt[x] + 3y²Dt[y]；Dt[x³+y³, x] = 3x² + 3y²Dt[y,x] — 全微分/全导数语义吻合；后例中 y 视为 x 的未知函数，故导数第二部分以符号 Dt[y,x] 表示。「更可取的书写形式」一行公式转写错乱（见 [[queries/20-3全节系统性转写讹误清单]]）。
- **E**：D[x f[x]³, x] = f[x]³ + 3x f[x]² f′[x] — 乘积法则、符号函数导数保持 f′ 形式，吻合。
- **F**：D[f[u[x]], x] = f′[u[x]] u′[x] — 链式法则的形式应用，吻合。
- **G**：D[u[x]/v[x], x] = u′[x]/v[x] − u[x]v′[x]/v[x]² — 商法则，吻合；唯转写标号「In[17]」「Out[z]」讹误。

## 积分算例（20.3.4.2–20.3.4.3，输出均吻合，两例输入需重构）

- **有理函数例 A**：输出 5/3·Log[−1+x] − 3Log[x]/2 − 1/6·Log[2+x]；对输出求导得 (2x+3)/(x(x−1)(x+2))（通分验证：分子 10x(x+2) − 9(x−1)(x+2) − x(x−1) = 6(2x+3)），数值点核验吻合。输入行整体脱失，重构见 [[queries/有理积分例A脱In1之辨]]。
- **有理函数例 B**：输出 −1/(−1+x)² − 1/(−1+x) + 2Log[−1+x] − Log[x]（式 20.35）；对输出求导得 (x³+1)/(x(x−1)³)（通分验证：分子 2x + x(x−1) + 2x(x−1)² − (x−1)³ = x³+1），两点数值核验吻合。被积函数转写乱码，重构见 [[queries/积分例B被积函数疑为x三次方加1比x乘x减1三次方之辨]]。
- **三角积分 A**：∫sin²x cos⁵x dx = 5Sin[x]/64 − Sin[3x]/192 − 3Sin[5x]/320 − Sin[7x]/448 — 复算吻合。
- **三角积分 B**：∫sinx/√cosx dx = −2√cosx — 复算吻合。
- **定积分 A**：∫₀^∞ e^(−x²)dx = √π/2 — Gauss 积分，吻合。
- **定积分 B（发散）**：Integrate[1/x², {x,−1,1}] 触发 Integrate::idiv — 被积函数在 0 处发散，行为吻合。
- **二重积分**：Integrate[xy², {x,0,2},{y,x²,2x}] = 32/5 — 按从右到左次序先内后外逐层积分复算：∫₀² x[(2x)³−(x²)³]/3 dx = (1/3)∫₀²(8x⁴−x⁷)dx = 32/5，吻合。
- **Boole 区域积分**：Integrate[Boole[x²+y²≤1],{x,−1,1},{y,−1,1}] = π — 单位圆盘面积，吻合。
- **非初等积分**：∫x^x dx 原样返回输入 — 与书中评论一致。

## 证据性质

导数例为求导法则逐项重算；积分例为对输出求导（逆导）加数值点核验，属直接证据；两处输入重构属推断，已在相应疑辨页单独标注，不计入吻合统计。
