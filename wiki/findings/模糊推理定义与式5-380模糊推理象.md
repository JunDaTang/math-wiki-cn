# 模糊推理的定义与式 5.380 模糊推理象

**断言**（《数学手册(原书第10版)》5.9.4，第 594 页）：

1. 模糊推理是模糊关系的一个重要应用，其目的是对不明确信息获得模糊逻辑结论；「不明确信息」指**模糊信息而非不确知信息**（模糊 ≠ 不确知）。
2. 模糊推理也称作蕴涵，包含**一个或多个法则、一个事实和一个结论**。
3. [[entities/扎德]] 称模糊推理为**近似推理**。
4. **不可能用经典逻辑刻画**。
5. 最简情形的模糊蕴涵含一个 IF THEN 法则（IF 部分为前提、表示条件，THEN 部分为结论），其计算规定为

```
μ₂ = μ₁ ∘ R        (5.380)
```

μ₂ 是 μ₁ 在模糊关系 R 下的**模糊推理象**。

## 证据与核验状态

- 参考书定义性陈述，无证明、无数值算例可复算（replicated: null）。
- 交叉印证：本节广义格式中的关系 R 以 min 定义（式 5.381b），与 5.9.2 的 Zadeh 算子断言（[[findings/zadeh算子与and-or-not对应]]）在算子层面一致。
- 概念性注意事项：本节称模糊推理「也称作蕴涵」，但 R 以 min（合取型算子）定义，是合取型而非经典蕴涵型构造；源已声明不可能用经典逻辑刻画，故源内自洽。
