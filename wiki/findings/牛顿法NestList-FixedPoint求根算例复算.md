# 牛顿法 NestList-FixedPoint 求根算例复算

## 问题设定

在 3π/2（≈ 4.71239）的邻域中求方程 **x cos x = sin x** 的一个根。源文将其化为 f(x) = x − tan x = 0（方程两边除以 cos x，即 x = tan x；根处 cos x* ≈ −0.217 ≠ 0，变换合法），并用牛顿法迭代求根（源文回指「第 1234 页 19.1.1.2」，页码处疑脱「页」字，见 [[queries/参见第1234页19-1-1-2脱页字之辨]]）。

## 转录（verbatim，存疑处以注标出）

```
In[1] := f[x_] := x - Tan[x]
In[2] := f′[x]  →  Out[2] = 1 - Sec[x]^2
In[3] =  g[x_] := x - f[x]/f′[x]   （源文「In[3] =」疑为「In[3] :=」，见 [[queries/In3之等号疑为冒号等号之辨]]）
In[4] := NestList[g, 4.6, 4]
         → Out[4] = {4.6, 4.54573, 4.50615, 4.49417, 4.49341}
In[5] := FixedPoint[g, 4.6]  → Out[5] = 4.49341
```

## 复算（数值，独立重算）

**导数**：d/dx(x − tan x) = 1 − sec²x，与 Out[2] = `1 - Sec[x]^2` 一致 ✓

**牛顿步 g(x) = x − f(x)/f′(x)**，自 4.6 起：

| 迭代 | 输入 | g(输入)（独立重算） | 源文 Out[4] |
|---|---|---|---|
| 1 | 4.6 | ≈ 4.54573 | 4.54573 ✓ |
| 2 | 4.54573 | ≈ 4.50615 | 4.50615 ✓ |
| 3 | 4.50615 | ≈ 4.49417 | 4.49417 ✓ |
| 4 | 4.49417 | ≈ 4.49341 | 4.49341 ✓ |

**真值核对**：x = tan x 在 (π, 3π/2) 内的根 x* ≈ 4.4934095。Out[4] 末项与 FixedPoint 输出 4.49341 精确至 6 位有效数字 ✓。

**收敛形态**：误差 e_n = x_n − x* 依次约 0.10659 → 0.05232 → 0.01274 → 0.00076，满足 e_{n+1}/e_n² ≈ 4.6–4.7，与牛顿法平方收敛的理论常数 |f″(x*)/(2f′(x*))| ≈ 4.72 相符（f′(x*) = −tan²x* = −x*²，f″(x*) = −2x*(1+x*²)）。

- 本算例的全部数值经独立复算逐位吻合，replicated: true，confidence: high；NestList 输出 5 项（初值 + 4 次嵌套）亦与命令语义一致；
