# 双曲半角公式及定号规则

手册 2.9.3.7 给出半角的双曲函数（式 2.191–2.194），其中式 2.191 的平方根符号依 x 的正负确定。

$$
\sinh {\frac {x}{2}} = \pm \sqrt {\frac {1}{2} (\cosh x - 1)},\tag{2.191}
$$

$$
\cosh {\frac {x}{2}} = \sqrt {\frac {1}{2} (\cosh x + 1)},\tag{2.192}
$$

当 x > 0 时，式 2.191 中平方根的符号为正；当 x < 0 时，符号为负。

$$
\tanh {\frac {x}{2}} = \frac {\cosh x - 1}{\sinh x} = \frac {\sinh x}{\cosh x + 1},\tag{2.193}
$$

$$
\coth {\frac {x}{2}} = \frac {\sinh x}{\cosh x - 1} = \frac {\cosh x + 1}{\sinh x}.\tag{2.194}
$$

## 定号规则的来源（推断说明）

sinh(x/2) 与 x 同号（sinh 严格递增且 sinh 0 = 0），故式 2.191 的符号由 x 的正负决定；cosh(x/2) 恒正，故式 2.192 无条件取正根。与三角对照：sin(α/2)、cos(α/2) 的符号均依象限确定，而双曲的 cosh(x/2) 无条件为正、sinh(x/2) 仅依 x 正负——定号自由度更小。tanh(x/2) 与 coth(x/2) 的两个有理表达式（无根号）与三角半角正切公式的结构对应（三角侧为 tan(α/2) = (1 − cos α)/sin α = sin α/(1 + cos α)，符号细节见 [[comparisons/双曲函数与三角函数比较]]）。

## 核验（直接证据）

四条公式均经指数定义或由倍角公式（式 2.186–2.187）反解核验无误。示例：由 cosh x = cosh(2·(x/2)) = sinh²(x/2) + cosh²(x/2) 与 cosh²(x/2) − sinh²(x/2) = 1 联立，得 cosh²(x/2) = (cosh x + 1)/2、sinh²(x/2) = (cosh x − 1)/2，即式 2.191–2.192；式 2.193 的两式相等由 sinh²x = (cosh x − 1)(cosh x + 1) 保证；式 2.194 为式 2.193 的倒数。
