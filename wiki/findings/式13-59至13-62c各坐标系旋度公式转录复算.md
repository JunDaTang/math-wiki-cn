# 式 13.59–13.62c 各坐标系旋度公式转录复算

对《数学手册》13.2.5.2 四种坐标系旋度公式的复算。结论：四组公式在正交坐标系下全部正确；统一公式 (13.62b) 不适用于非正交坐标系——这是本节最重要的新发现。

## 转录

```latex
(13.59a) rot V⃗ = î(∂V_z/∂y − ∂V_y/∂z) + ĵ(∂V_x/∂z − ∂V_z/∂x) + k̂(∂V_y/∂x − ∂V_x/∂y)
          = det | î    ĵ    k̂  |
                | ∂/∂x ∂/∂y ∂/∂z |
                | V_x  V_y  V_z  |
(13.59b) rot V⃗ = ∇ × V⃗
(13.60b) rot_ρ V⃗ = (1/ρ) ∂V_z/∂φ − ∂V_φ/∂z
          rot_φ V⃗ = ∂V_ρ/∂z − ∂V_z/∂ρ
          rot_z V⃗ = (1/ρ) { ∂(ρV_φ)/∂ρ − ∂V_ρ/∂φ }
(13.61b) rot_r V⃗ = (1/(r sinϑ)) { ∂(sinϑ V_φ)/∂ϑ − ∂V_ϑ/∂φ }
          rot_ϑ V⃗ = (1/(r sinϑ)) ∂V_r/∂φ − (1/r) ∂(rV_φ)/∂r
          rot_φ V⃗ = (1/r) { ∂(rV_ϑ)/∂r − ∂V_r/∂ϑ }
(13.62b) rot_ξ V⃗ = (1/D)|∂r⃗/∂ξ| [ ∂/∂η(|∂r⃗/∂ζ| V_ζ) − ∂/∂ζ(|∂r⃗/∂η| V_η) ]
          （η、ζ 分量按 (ξ,η,ζ) 轮换得到）
(13.62c) r⃗(ξ,η,ζ) = x(ξ,η,ζ) î + y(ξ,η,ζ) ĵ + z(ξ,η,ζ) k̂
          D = |∂r⃗/∂ξ| · |∂r⃗/∂η| · |∂r⃗/∂ζ|
```

## 复算

1. **笛卡儿 (13.59a) ✓**：分量式与行列式记法一致；(13.59b) rot V⃗ = ∇×V⃗。对照标准形式（直接验证）。
2. **柱面 (13.60b) ✓**：与标准形式一致；本节无 13.2.2 节式 (13.37a) 那样的加号重复转写问题（对照 [[queries/式13-37a柱面梯度公式疑重复加号]]）。
3. **球面 (13.61b) ✓**：ϑ 为极角、φ 为方位角，与表 13.1 约定一致。
4. **统一公式 (13.62b)**：等价于 (rot V⃗)_i = (h_i/D)[∂(h_k V_k)/∂u_j − ∂(h_j V_j)/∂u_k]。
   - **退化验证**（直接计算）：柱面 h = (1, ρ, 1) 复得 (13.60b) ✓；球面 h = (1, r, r sinϑ) 复得 (13.61b) ✓。
   - **斜角坐标反例**（直接计算，本入库的单次显式计算，建议独立复核后正式结案相关查询）：取 r⃗ = (ξ+η) î + η ĵ + ζ k̂，h = (1, √2, 1)，坐标基非正交；取 V⃗ = (0, x, 0)，真值 rot_ζ = 1，而公式给出 rot_ζ = (1/√2)(2+1) = 3/√2 ≠ 1。
5. **结论**：“一般直角坐标系”（13.62）必须限定为正交坐标系。这为 [[queries/一般直角坐标系是否限于正交坐标系]] 增添独立的旋度侧反例，与梯度侧证据互补。统一流程见 [[methodology/旋度坐标系分量计算流程]]。

## 转写问题

(13.62c) 中 y(ξ,η,ζ)、z(ξ,η,ζ) 的函数名在转写中脱落（原文仅剩 (ξ,η,ζ) 系数），已按上下文复原。完整清单见 [[queries/13-2-5全节系统性转写讹误清单]]。
