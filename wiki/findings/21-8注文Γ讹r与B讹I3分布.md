# 21.8 注文 Γ 讹 r 与 B 讹 I 3 分布

手册 21.8 的行内注文（prose note）中，特殊函数记号发生系统性转写讹误，而同条展示公式（display math）内记号完好——转写非均匀的直接证据。

## 分布

- **Γ→r**：「Γ(x) 表示伽马函数」的行内注文在 21.7a、21.23、21.37、21.45、21.49 五处注文均作「r(x) 表示伽马函数」。
- **B→「I 3」**：21.45 注作「I 3(x,y) = Γ(x)Γ(y)/Γ(x+y) 表示 β 函数」，而 21.7a 注同位文本作 B(x,y) 完好。
- **衍字**：21.45 注「欧拉第一型欧拉积分」衍一「欧拉」（应为「第一型欧拉积分」）。

## 互证证据

- 同节展示式内 Γ 全部完好（如 21.7a、21.23a、21.45 本式）；
- 21.32 的平行 C 注文「C 为欧拉常数 (参见第 681 页 8.2.5, 2.)」完好（含 C 与「页」），说明讹误为行内文本的非均匀转写而非数学错误。

## 影响

r(x) 讹形削弱了注文对 8.2.5（第 682 页）定义与伽马函数表 21.10（第 1426 页）回指的可读性。勘正建议：Γ(x)、B(x,y)，删衍字。见 [[注文伽马符号讹为r之辨]]、[[21-8未入库回指缺口]]。
