# 表 8.2 不定积分计算的重要法则（逐字转录）

《数学手册(原书第10版)》8.1.2 于法则 4 与法则 5 之间插入表 8.2「不定积分计算的重要法则」，汇总全节法则。引言称「8.2 列出了最终要讨论的最重要的积分法则」（「最终要讨论」措辞存疑，或为「将要讨论」）。逐字转录如下：

| 法则 | 积分公式 |
|---|---|
| 积分常数 | $\int f(x)\mathrm{d}x = F(x)+C$（$C$ 为常数） |
| 积分和微分 | $F'(x)=\frac{\mathrm{d}F}{\mathrm{d}x}=f(x)$ |
| 常数倍乘法则 | $\int\alpha f(x)\mathrm{d}x = \alpha\int f(x)\mathrm{d}x$（$\alpha$ 为常数） |
| 和法则 | $\int[u(x)\pm v(x)]\mathrm{d}x = \int u(x)\mathrm{d}x \pm \int v(x)\mathrm{d}x$ |
| 分部积分 | $\int u(x)v'(x)\mathrm{d}x = u(x)v(x)-\int u'(x)v(x)\mathrm{d}x$ |
| 代换法 | $x=u(t)$ 或 $t=v(x)$；$u,v$ 互为反函数：$\int f(x)\mathrm{d}x=\int f(u(t))u'(t)\mathrm{d}t$ 或 $\int f(x)\mathrm{d}x=\int\frac{f(u(t))}{v'(u(t))}\mathrm{d}t$ |
| 被积函数的特殊形式 | (1) $\int\frac{f'(x)}{f(x)}\mathrm{d}x = \ln\|f(x)\|+C$（对数积分）；(2) $\int f'(x)f(x)\mathrm{d}x = \frac{1}{2}f^2(x)+C$ |
| 反函数积分 | $u,v$ 互为反函数：$\int u(x)\mathrm{d}x = xu(x)-F(u(x))+C_1$，其中 $F(x)=\int v(x)\mathrm{d}x+C_2$（$C_1,C_2$ 为常数） |

## 独家内容

- **反函数积分**：仅在表 8.2 出现，编号条目 1–8 未展开讨论，概念页见 [[concepts/反函数积分]]。
- **代换法第二形式** $\int f(x)\mathrm{d}x = \int\frac{f(u(t))}{v'(u(t))}\mathrm{d}t$：与第一形式并列给出，比较见 [[comparisons/代换法两种形式比较]]。
- **「对数积分」标签**：表中「被积函数的特殊形式 (1)」即式 8.6，被称为「对数积分」——与条目 8(1)A 的特殊函数 $\operatorname{Li}(x)$ 同名不同物，见 [[queries/对数积分术语撞名]]。

## 反函数积分公式复算

取 $u=\ln x$，其反函数 $v=e^y$，$F(y)=\int e^y\,\mathrm{d}y = e^y+C_2$：

$$
\int\ln x\,\mathrm{d}x = x\ln x - e^{\ln x} + C_1 = x\ln x - x + C,
$$

与直接分部积分结果一致。另对右端 $xu(x)-F(u(x))$ 求导，利用 $F'=v$ 与 $v(u(x))=x$ 得 $u(x)+xu'(x)-v(u(x))u'(x)=u(x)$，公式恒成立。**复算通过**。

## 结论

表 8.2 转录完整，反函数积分公式经代数复算成立。注意本表前两行隐含的不定积分基本关系（$\int f\,\mathrm{d}x=F+C$ 与 $F'=f$）的完整定义（式 8.1–8.2 推测）在未入库的 8.1.1，见 [[queries/8-1-1及8-2-5与8-1-4-3未入库回指缺口]]。
