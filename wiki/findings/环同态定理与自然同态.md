# 环同态定理与自然同态

数学手册 5.3.7.3.2 陈述环同态定理，并明确指出它由群同态定理「以理想替换正规子群」得到。

## 定理内容

- 环同态 $h: R_1 \to R_2$ 的核 $\ker h = \{a \in R_1 \mid h(a) = 0\}$ 是 $R_1$ 的一个理想；
- 商环 $R_1 / \ker h$ 同构于同态象 $h(R_1) = \{h(a) \mid a \in R_1\}$；
- 反之，$R_1$ 的每个理想给出一个同态映射 $\mathrm{nat}_I: R_1 \to R_1/I$，$\mathrm{nat}_I(a) = a + I$，映射 $\mathrm{nat}_I$ 称为**自然同态**。

（源文将 $\mathrm{nat}_I$ 的陪域写作 $R_2/I$，与 $a + I \in R_1/I$ 矛盾，高置信为转写讹误，见 [[queries/nat-i陪域是否应为r1-i]]。）

## 与群同态定理的类比

源文明示：「如果在群同态定理中用理想的概念代替正规子群的概念，那么就可得到环同态定理」。逐项对照：

| 群情形（5.3.3） | 环情形（5.3.7.3） |
|---|---|
| 同态保持一个运算 | 同态保持 $+$ 与 $*$ 两个运算 |
| $\ker h$ 是正规子群 | $\ker h$ 是理想 |
| 商群 $G/N$（陪集 $gN$） | 商环 $R/I$（加群陪集 $a + I$） |
| $G/\ker h \cong h(G)$ | $R_1/\ker h \cong h(R_1)$ |
| 每个正规子群给出自然同态 | 每个理想给出 $\mathrm{nat}_I(a) = a + I$ |

群情形的入库陈述见 [[findings/商群与同态定理及gln-sln实例]]；完整比较见 [[comparisons/群同态定理与环同态定理比较]]。
