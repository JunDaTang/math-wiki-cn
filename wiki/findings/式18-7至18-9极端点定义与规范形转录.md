# 式 18.7 至 18.9 极端点定义与规范形转录

对 18.1.2 中式 18.7（极端点定义）、式 18.8（算例及松弛扩展系统）与式 18.9a/18.9b（规范形与基本解）的逐字转录及一致性核验。公式本体完整可核；周边文字叙述存在系统性转写讹误，另行汇总于 [[18-1-2全节系统性转写讹误清单]]。

## 转录

式 18.7（极端点定义）：

```text
x ≠ λx₁ + (1−λ)x₂,   0 < λ < 1
```

式 18.8（算例）及引入 x₄,…,x₇ 后的扩展系统：

```text
OF: f(x) = 2x₁ + 3x₂ + 4x₃ = max!
CT: x₁ + x₂ + x₃ ⩾ 1,   x₂ ⩽ 2,   −x₁ + 2x₃ ⩽ 2,   2x₁ − 3x₂ + 2x₃ ⩽ 2.

引入 x₄,…,x₇ 后：
CT:  x₁ + x₂ + x₃ − x₄          = 1,
      x₂          + x₅           = 2,
     −x₁     + 2x₃     + x₆      = 2,
      2x₁ − 3x₂ + 2x₃     + x₇   = 2.
```

式 18.9a（规范形；末行编号在转写中讹作 "(18.96)"，应为 (18.9b)）：

```text
OF: f(x) = c₁x₁ + ⋯ + c_{n−m}x_{n−m} + c₀ = max!
CT: a_{1,1}x₁ + ⋯ + a_{1,n−m}x_{n−m} + x_{n−m+1}             = b₁,
    ⋮                                                          ⋮
    a_{m,1}x₁ + ⋯ + a_{m,n−m}x_{n−m}                   + xₙ   = b_m,
    x₁, …, x_{n−m}, x_{n−m+1}, …, xₙ ⩾ 0.
```

## 核验结论（本分析独立完成，全部通过）

- **式 18.7**：定义式完整无歧义；周边文字有脱落（“称作 的极端点”脱 M、“对千所”疑为“对于所有”、线段句疑脱“M 的”），不影响公式本体。
- **式 18.8**：OF 与四条 CT 转录完整；扩展系统与原约束逐条对应——约束 1（⩾）引入 x₄ 且带负号（剩余变量，b₁ = 1 > 0），约束 2–4（⩽）分别引入 x₅、x₆、x₇ 且带正号，核验一致。
- **式 18.9a**：系数矩阵最后 m 列为单位阵，线性无关成基；令非基变量为零即得基本解 (0,…,0,b₁,…,b_m)；b ⩾ 0 ⇔ 基本解可行且为极端点、目标函数取值 c₀——逻辑自洽，核验通过。
- **规范形可达性论断**（“(18.4a, 18.4b) 总能通过适当的变量重新排序转换成”该形式）为陈述性内容，本节内部无法复算，待 18.1.1 入库后核验（见 [[18-1-2未入库回指缺口]]）。
