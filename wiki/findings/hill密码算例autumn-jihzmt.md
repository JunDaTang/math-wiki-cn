# Hill 密码算例 AUTUMN → JIHZMT

本源 5.5.4.4：字母编号 a₀ = A, …, a₂₅ = Z，m = 3，明文 AUTUMN 分为区组 AUT = (0, 20, 19) 与 UMN = (20, 12, 13)，加密矩阵

```
S = ⎛14  8  3⎞
    ⎜ 8  5  2⎟ ，  gcd(det S, 26) = 1
    ⎝ 3  2  1⎠
```

原文给出：S·(0,20,19)ᵀ = (217,138,59)ᵀ ≡ (9,8,7)ᵀ (mod 26)；S·(20,12,13)ᵀ = (415,246,97)ᵀ ≡ (25,12,19)ᵀ (mod 26)；故 AUTUMN → JIHZMT。

## 复算（本 wiki 独立核验，全链吻合）

- 第一区组：14·0+8·20+3·19 = 217；8·0+5·20+2·19 = 138；3·0+2·20+1·19 = 59。
  217 mod 26 = 9（J），138 mod 26 = 8（I），59 mod 26 = 7（H）→ JIH。✓
- 第二区组：14·20+8·12+3·13 = 280+96+39 = 415；8·20+5·12+2·13 = 160+60+26 = 246；3·20+2·12+1·13 = 60+24+13 = 97。
  415 mod 26 = 25（Z），246 mod 26 = 12（M），97 mod 26 = 19（T）→ ZMT。✓
- 行列式：det S = 14·(5·1−2·2) − 8·(8·1−2·3) + 3·(8·2−5·3) = 14 − 16 + 3 = **1**，满足 gcd(det S, 26) = 1（S 模 26 可逆，解密良定义）。✓

## 原文讹误标注（不影响算例）

- 「s_ij ∈ {0, 1, …, m−1}」应为 {0, 1, …, n−1}（矩阵元取值域由模数 n 决定）。
- 「(m, n) 型非奇异矩阵」应为 m 阶方阵（式 5.274 左乘 m 维向量）。
- 「要求所有向量按模 算术确定分量」脱落「n」。
