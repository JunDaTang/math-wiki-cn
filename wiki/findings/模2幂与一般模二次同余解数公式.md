# 模 2^α 与一般模二次同余解数公式（式 5.258，抽查复算）

**来源**：[[sources/10-数学手册原书第10版--10-543-同余和剩余类--n0ce67]]（5.4.3.8 末两段）。

**陈述一（模 2^α）**：a 奇时，x² ≡ a (2^α) 可解，当且仅当 α = 2 时 a ≡ 1 (4)、α ≥ 3 时 a ≡ 1 (8)（α = 1 时恒可解）。条件满足时解数为：1 个（α = 1）、2 个（α = 2）、4 个（α ≥ 3）。

**陈述二（一般模，5.258a–b）**：m = 2^α·p₁^{α₁}⋯p_t^{α_t}、gcd(a, m) = 1 时，x² ≡ a (m) 可解的必要条件为

$$a \equiv 1\ (4)\ (\alpha=2);\quad a \equiv 1\ (8)\ (\alpha \geq 3);\quad (a/p_1) = \cdots = (a/p_t) = 1, \tag{5.258b}$$

条件全满足时可解，且解数为 2^t（α = 0 或 1）、2^{t+1}（α = 2）、2^{t+2}（α ≥ 3）。

**抽查复算**：

- x² ≡ 1 (2)：唯一解 x ≡ 1（α = 1，1 解）✓
- x² ≡ 1 (4)：解 x ≡ 1, 3（α = 2，2 解）✓；x² ≡ 3 (4) 无解（3 ≢ 1 (4)）✓
- x² ≡ 1 (8)：解 x ≡ 1, 3, 5, 7（奇数平方均 ≡ 1 (8)，α = 3，4 解）✓；x² ≡ 5 (8) 无解（5 ≢ 1 (8)）✓
- m = 15（α = 0, t = 2）、a = 4（4 为模 3 与模 5 的二次剩余）：解 x = 2, 7, 8, 13，共 4 = 2² 个（逐一验算 49 ≡ 64 ≡ 169 ≡ 4 (15)）✓

**证据类型**：定理陈述为源文直接证据；解数公式经上述抽查一致（间接印证）。注意陈述二的解数公式仅属 gcd(a, m) = 1 情形（源文设置即如此），不得外推到一般 a。

**转写备注**：源文「若 = 2)」「若 α ≥ 3)」等处符号脱落；「那么 2^α 有一个解」脱落「模」。
