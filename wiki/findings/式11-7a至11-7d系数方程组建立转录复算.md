# 式 11.7a–11.7d 系数方程组建立转录复算

**结论**：(11.7a)–(11.7d) 转录正确（含一处下标疑误），由解结构建立系数方程组的推导经独立复算吻合。

## 逐字转录

```latex
% (11.7a) 以 β_k(x) 乘 (11.6c) 并在 [a,b] 上积分
\int_a^b \beta_k(x)\varphi(x)\,\mathrm{d}x
= \int_a^b \beta_k(x)f(x)\,\mathrm{d}x
+ \lambda A_1\int_a^b \beta_k(x)\alpha_1(x)\,\mathrm{d}x + \dots
+ \lambda A_n\int_a^b \beta_k(x)\alpha_n(x)\,\mathrm{d}x

% (11.7b) 记号
b_k = \int_a^b \beta_k(x)f(x)\,\mathrm{d}x,\qquad
c_{kj} = \int_a^b \beta_k(x)\alpha_j(x)\,\mathrm{d}x

% (11.7c)
A_k = b_k + \lambda c_{k1}A_1 + \lambda c_{k2}A_2 + \dots + \lambda c_{kn}A_n
```

线性方程组 (11.7d)（逐字，第二行末项原文作 $A_2$）：

```text
(1 − λc₁₁)A₁ − λc₁₂A₂ − … − λc₁ₙAₙ = b₁
−λc₂₁A₁ + (1 − λc₂₂)A₂ − … − λc₂ₙA₂ = b₂
……
−λcₙ₁A₁ − λcₙ₂A₂ − … + (1 − λcₙₙ)Aₙ = bₙ
```

## 独立复算

- 以 $\beta_k(x)$ 乘 (11.6c)、对 $x$ 在 $[a,b]$ 上积分：左端 $\int\beta_k(x)\varphi(x)\,\mathrm{d}x$ 与 (11.6b) 的 $A_k$（哑变元 $y$ 换名 $x$）一致；代入记号 (11.7b) 整理即 (11.7c)，移项即 (11.7d)：对角元 $1-\lambda c_{kk}$、非对角元 $-\lambda c_{kj}$、右端 $b_k$。逐步吻合。
- (11.7d) 第二行末项转写作 $-\lambda c_{2n}A_2$，按方程组结构应为 $-\lambda c_{2n}A_n$，疑为下标讹误（已记入 [[queries/11-2-1全节系统性转写讹误清单]]，需原书核对）。

## 数值近似回指

原文：若 (11.7b) 中积分无法精确计算，须用第 19.3 节（转写中页码 "1252" 嵌入正文）的公式之一近似。该节未入库，见 [[queries/11-2-1未入库回指缺口]]。

"包含 个方程"漏 "n"；其余见 [[queries/11-2-1全节系统性转写讹误清单]]。均不影响推导。

## 直接证据与推断
