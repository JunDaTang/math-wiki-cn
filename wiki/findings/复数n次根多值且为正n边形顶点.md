# 复数 n 次根多值且为正 n 边形顶点（式 1.141）

《数学手册》1.5.3.6 断言：对 z = ρ(cos φ + i sin φ) ≠ 0，记号 z^{1/n} = ⁿ√z（n > 0 整数，式 1.141a）是 n 个不同值的简单记法（式 1.141b）：

ω_k = ⁿ√ρ [cos((φ + 2kπ)/n) + i sin((φ + 2kπ)/n)]，k = 0, 1, 2, …, n−1

关键点：

1. **多值性**：复数的加、减、乘、除和整数次幂都有唯一结果，而 n 次方根有 n 个不同的解 ω_k——这是 1.5 节中唯一的多值运算。
2. **几何分布**：点 ω_k 是中心在原点的正 n 边形的顶点，均匀分布于半径 ⁿ√ρ 的圆上（[[concepts/高斯平面]]）；手册图 1.11 给出 ⁿ√z 的 6 个值。

验证（推断性核验）：以 z = 1 为例（ρ = 1，φ = 0），ⁿ√1 的 n 个值为 e^{i·2kπ/n}，即单位圆内接正 n 边形的顶点，与公式一致。属定义性内容，核算无误。
