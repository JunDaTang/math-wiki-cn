# 数学手册(原书第10版) 20.2.4 列表

## 概述

本文件是《数学手册(原书第10版)》第 20 章 20.2「Mathematica 的重要结构要素」的第四子节 **20.2.4 列表**，系统介绍 [[mathematica]] 的列表机制。全节分四个小节：20.2.4.1 概念、20.2.4.2 嵌套列表、20.2.4.3 列表的运算、20.2.4.4 表格。本节上承 [[10-数学手册原书第10版--23-2021-mathematica的基本结构要素--86wfbe]]（20.2.1）建立的「完整形式—短形式」框架，把 `List[...]` 与 `{...}` 的关系落实为列表的构造与显示机制；父节 source 页为 [[10-数学手册原书第10版--22-202-mathematica的重要结构要素--1w5xyrj]]。

**本节全部主张仅针对 Mathematica，不得外推至 Matlab 或 Maple。**

## 核心主张

1. 列表是 Mathematica 处理整组量的重要工具，书称「后者在高维代数和分析中是重要的」（「高维代数」疑为「线性代数」之讹，低置信存疑，见 [[20-2-4全节系统性转写讹误清单]]）。
2. 列表是由几个对象汇集成的一个新对象，每个对象仅由其在列表中的位置来区分；若元素可以简单地枚举出来，构造由式 (20.9) 的两个等价形式确定；输出采用置于花括号中的短形式（式 20.10）。
3. 选取（表 20.3）、运算（表 20.4）、生成（表 20.5 及 Range、Array）三命令族构成列表操作的完整体系。
4. 嵌套列表支持 `Part[l, i, j]` ≡ `l[[i, j]]` 的两级寻址与 `l[[{i1,···}, {j1,···}]]` 的子块抽取，概念上可推广至三维及更高维。
5. Table 用函数值、Array 用函数本身、Range 用等差序列——三者语义分工互补（源文自身的对比，见 [[Table与Array与Range比较]]）。

## 逐字结构数据

### 表 20.3 选取列表元素的命令

| 命令 | 说明 |
|---|---|
| First[l], Last[l] | 选取第一个/最后一个元素 |
| Most[l], Rest[l] | 选取除最后一个/第一个元素以外的元素 |
| Part[l, n] 或 l[[n]] | 选取第 n 个元素 |
| Part[l, {n1, n2,···}] | 给出具有给定数目的元素的一个列表 |
| l[[{n1, n2,···}]] | 等价于前面的运算 |
| Take[l, m] | 给出 l 的前 m 个元素构成的列表 |
| Take[l, {m, n}] | 给出从第 m 个元素到第 n 个元素构成的列表 |
| Drop[l, n] | 给出没有前 n 个元素的列表 |
| Drop[l, {m, n}] | 给出没有从第 m 个元素到第 n 个元素的列表 |

（表题在转写中脱「表」字，讹作「20.3」。）

### 表 20.4 列表的运算

| 命令 | 说明 |
|---|---|
| Position[l, a] | 给出 a 在该列表中出现的位置的一个列表 |
| MemberQ[l, a] | 检验 a 是否是该列表的一个元素 |
| Select[l, crit] | 挑出该列表中满足特定条件的所有元素 |
| Cases[l, pattern] | 给出匹配该模式的元素的一个列表 |
| FreeQ[l, a] | 检验 a 是否不出现在该列表中 |
| Prepend[l, a] | 将 a 添加到前面改变该列表 |
| Append[l, a] | 将 a 添加到末尾改变该列表 |
| Insert[l, a, i] | 在该列表的第 i 个位置插入 a |
| Delete[l, {i, j,···}] | 从该列表删除位置 i, j, ··· 处的元素 |
| ReplacePart[l, a, i] | 将位置 i 处的元素替换为 a |

### 表 20.5 Table 运算

| 命令 | 说明 |
|---|---|
| Table[f, {imax}] | 创建 f 具有 imax 值: f(1), f(2),···, f(imax) 的一个列表 |
| Table[f, {i, imin, imax}] | 创建 f 具有从 imin 到 imax 的值的一个列表 |
| Table[f, {i, imin, imax, di}] | 和上面一个相同, 但增量为 di |

## 算例逐字转录

（「←」后为本次转录所加校勘注，非源文。）

```text
(20.9)   List[a1, a2, a3, ...]  或  {a1, a2, a3, ...}

(20.10)  In[1] := l1 = List[a1, a2, a3, a4, a5, a6]
         → Out[1] = {a1, a2, a3, a4, a5, a6}

—— 20.2.4.1 选取算例 ——
In[2] := First[l1]                → Out[2] = a1
In[3] := l1[[3]]                  → Out[3] = a3
In[4] := l1[[{2, 4, 6}]]          → Out[4] = {a2, a4, a6}
In[5] := Take[l1, 2]              → Out[5] = {a1, a2}

—— 20.2.4.2 嵌套列表 ——
In[1] := a1 = {b11, b12, b13, b14, b15}
In[2] := a2 = {b21, b22, b23, b24, b25}
In[3] := a3 = {b31, b32, b33, b34, b35}
（源文：类似地，对于 a4, a5 a6 做同样的事情 ←「a5 a6」脱顿号）
由 In[4] := l1[[3, 4]]  得到  Out[4] = b34
In[1] := l1[[{3, 5}, {2, 3, 4}]]
         → Out[1] = {{b32, b33, b34}, {b52, b53, b54}}

—— 20.2.4.3 列表的运算 ——
In[1] := l2 = Delete[l1, 6]       → Out[1] = {a1, a2, a3, a4, a5}
（源文随后：在输出中 ai 显示为它们的值 它们本身是列表 ←脱句读）

—— 20.2.4.4 表格 ——
In[1] := Table[Binomial[7, i], {i, 0, 7}]]    ←衍一右括号
         → Out[1] = {1, 7, 21, 35, 35, 21, 7, 1}

Table[f, {i, i1, i2}, {j, j1, j2}, ...]        （高维嵌套表）

In[2] := Table[Binomial[i, j], {i, 1, 7}, {j, 0, i}]
（源文：将得到直至 次的二项式系数 ←脱「7」）
         → Out[2] = {{1, 1}, {1, 2, 1}, {1, 3, 3, 1}, {1, 4, 6, 4, 1},
                     {1, 5, 10, 10, 5, 1}, {1, 6, 15, 20, 15, 6, 1},
                     {1, 7, 21, 35, 35, 21, 7, 1}}

Range[n] 产生列表 {1, 2, ..., n}
（源文：类似地 Range[nl, n2] Range[n1, n2, dn] ←脱「和」与「到」，「nl」为「n1」之讹）
Array[Exp, 5] 产生 {e, e², e³, e⁴, e⁵}
```

## 内部矛盾

1. Delete 算例的 Out[1] 以符号 a1–a5 显示，与紧随其后的「在输出中 ai 显示为它们的值，它们本身是列表」之说矛盾，见 [[Out1符号显示与ai显示为值之说矛盾之辨]]。
2. 子块抽取算例冠以「对于 20.2.4.1 中的例子」，而 b 元素实来自 20.2.4.2 的赋值；且回指例 In 编号回卷至 In[1]。
3. 「对于 (20.9) 中的列表 ll」——l1 实定义于 (20.10)，「ll」为「l1」之转写混写。
4. In/Out 编号跨子节回卷（20.2.4.1 编至 In[5]；20.2.4.2 重起 In[1]–In[3] 后续 In[4]，又回 In[1]），与 20.2.1 连续编号的会话习惯不一致。
