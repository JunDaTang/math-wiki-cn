# 数学手册(原书第10版) 12.8 非线性算子

## 定位与组织框架

本节是手册第 12 章（泛函分析）由线性理论（12.1–12.5）转入非线性理论的枢纽小节。开篇即点明方法论分野：非线性算子方程理论中最重要的方法基于四个原理：

1. **压缩映射原理、巴拿赫不动点定理**（源文回指 12.2.2.3–12.2.2.4；本库见 [[concepts/压缩映射]]、[[concepts/巴拿赫不动点定理]]、[[methodology/压缩映射迭代法]]）；
2. **牛顿方法推广至无穷维情形**（源文回指 18.2.5.2、19.1.1.2，均未入库）；
3. **绍德尔不动点原理**（12.8.4；见 [[concepts/绍德尔不动点定理]]）；
4. **勒雷–绍德尔理论**（12.8.5；见 [[concepts/勒雷-绍德尔定理]]）。

源文的分野论断：基于原理 (1)(2) 的方法导出解的存在性、唯一性、构造性等信息；基于原理 (3)(4) 的方法一般仅得到解的定性表述。若能获知算子的进一步性质，可进一步使用 12.8.6（正非线性算子）与 12.8.7（单调算子）的工具。该分野的展开见 [[comparisons/构造性与定性不动点原理比较]]。

另一全局性论断：12.5.1 中线性算子连续性与有界性的等价关系（见 [[concepts/有界线性算子与算子范数]]）对非线性算子不再成立——这是全节条件表述（如"连续且紧"）的底层原因。

## 各小节要点

### 12.8.1 非线性算子的例子

- [[entities/聂梅茨基算子]] $\mathcal{N}$：(12.190)；在 (12.191) 增长条件下 $\mathcal{N}: L^p(\Omega) \to L^q(\Omega)$（共轭指数）连续且有界；紧性仅在特殊情形；"f 连续即属此情形"一条疑缺增长条件。
- [[entities/哈默斯坦算子]] $\mathcal{H}$：(12.192)，结构分解 $\mathcal{H} = \mathcal{K}\mathcal{N}$；(12.194)+(12.191) 下的连续紧性陈述存在主语脱落与指数疑误。
- [[entities/乌雷松算子]] $\mathcal{U}$：(12.195)；紧性仅称"适当的条件"。
- 12.2 节的迭代方法可成功求解非线性积分方程（回扣 [[methodology/逐次逼近法]]）。

### 12.8.2 非线性算子的可微性

[[concepts/弗雷歇可微性与弗雷歇导数]]：(12.196)/(12.197) 定义及 ε-δ 复述、可微⟹连续、$T \in B(X,Y) \Rightarrow T' = T$（复算均通过）。

### 12.8.3 牛顿方法

[[methodology/无穷维牛顿迭代法]]：(12.198)–(12.200) 牛顿近似序列及局部收敛结果；误差估计一处内部矛盾；改进牛顿法仅给定义。随后给出 [[concepts/雅可比矩阵与雅可比行列式]]：(12.201)–(12.203)。

### 12.8.4 绍德尔不动点定理

[[concepts/绍德尔不动点定理]]：一维介值型 → [[concepts/布劳威尔不动点定理]]（有穷维）→ 绍德尔（任意巴拿赫空间，闭有界凸 + 连续且紧）。应用：仅假定右端连续，初值问题 (12.70) 总有局部解（不保证唯一性）。

### 12.8.5 勒雷-绍德尔理论

[[concepts/勒雷-绍德尔定理]]：边界条件形式与先验估计形式 (12.204)；本节刻意选择避免使用映射度概念的表述。

### 12.8.6 正非线性算子

[[concepts/正非线性算子与序区间不动点定理]]：保序增算子、序区间不动点定理（规范锥 + 全连续）、端点条件传递性、(12.205) 双侧单调迭代收敛至最小/最大不动点（条件 a) 规范锥+紧；b) [[concepts/正则锥]]）、上解与下解。源文在此使用"规范锥"译名，与 12.3 节的"正规锥"冲突（[[queries/规范锥与正规锥术语不一致]]）；"单调算子"一词在此为序意义，与 12.8.7 二义（[[comparisons/单调算子两种含义比较]]）。

### 12.8.7 巴拿赫空间中的单调算子

[[concepts/巴拿赫空间中的单调算子]]：对偶配对意义下的单调/强单调/强制、半连续（demicontinuous）、存在性定理（实可分 + 单调 + 半连续 + 强制 ⟹ 可解；强单调 ⟹ 唯一）、希尔伯特空间情形 $\operatorname{Im}(I+T)=H$、集值推广、伽辽金方法回指（19.4.2.2，未入库）。

## 公式转录

（编号与结构按源文；$\mathbb{R}$ 等符号为源文 OCR 损伤的规范化，损伤实录见下节）

```latex
% 12.8.1 三类非线性算子（𝒩：聂梅茨基；𝓗：哈默斯坦；𝓚：线性积分算子；𝓤：乌雷松）
(12.190)  (𝒩u)(x) = f(x, u(x))                                       (x ∈ Ω)
(12.191)  |f(x, s)| ⩽ a(x) + b|s|^{p/q},  a(x) ∈ L^q(Ω), b > 0, 1/p + 1/q = 1
(12.192)  (𝓗u)(x) = ∫_Ω K(x, y) f(y, u(y)) dy                         (x ∈ Ω)
(12.193)  (𝓚u)(x) = ∫_Ω K(x, y) u(y) dy                               (x ∈ Ω)
(12.194)  ∫_{Ω×Ω} |K(x, y)|^q dx dy < ∞
(12.195)  (𝓤u)(x) = ∫_Ω K(x, y, u(y)) dy                              (x ∈ Ω)

% 12.8.2 弗雷歇可微性（L ∈ B(X,Y)，依赖点 x）
(12.196)  T(x+h) − T(x) = Lh + ω(h),  ‖ω(h)‖ = o(‖h‖)
(12.197)  lim_{‖h‖→0} ‖T(x+h) − T(x) − Lh‖ / ‖h‖ = 0

% 12.8.3 牛顿方法与雅可比矩阵
(12.198)  T(x) = 0
(12.199)  x₁ = x₀ − [T′(x₀)]⁻¹ T(x₀)
(12.200)  x_{n+1} = x_n − [T′(x_n)]⁻¹ T(x_n)      (n = 0, 1, …)
          误差估计（源文疑误）：‖x_n − x₀‖ ⩽ ε^n ‖x₀ − x*‖
(12.201)  F(x) = (F₁(x), …, F_m(x))ᵀ ∈ ℝ^m,  x ∈ D ⊂ ℝ^n
(12.202)  F′(x) = (∂F_i/∂x_k)_{i=1..m, k=1..n}      （雅可比矩阵／泛函矩阵）
(12.203)  D(F₁,…,F_m)/D(x₁,…,x_n)                   （m = n：雅可比行列式／泛函行列式）

% 12.8.5 勒雷–绍德尔
(12.204)  x = λT(x)   (λ ∈ [0,1])
          边界条件：∀x ∈ ∂D, λ ∈ [0,1]: x + λT(x) ≠ y  ⟹  (I+T)(x) = y 至少一解
          先验估计形式：(12.204) 之解一致有界 ‖x‖ ⩽ c  ⟹  x = T(x) 有解

% 12.8.6 单调迭代（T 单调增，T(a) ⩾ a，T(b) ⩽ b）
(12.205)  x₀ = a, x_{n+1} = T(x_n) (n ⩾ 0)  与  y₀ = b, y_{n+1} = T(y_n) (n ⩾ 0)

% 12.8.7 单调算子（对偶配对 (·,·)；X 实巴拿赫空间，T: D → X*）
单调：     (T(x) − T(y), x − y) ⩾ 0,                 ∀x, y ∈ D
强单调：   (T(x) − T(y), x − y) ⩾ c‖x − y‖²,          c > 0
强制：     lim_{‖x‖→∞} (T(x), x)/‖x‖ = ∞
集值推广： (f − g, x − y) ⩾ 0,  ∀x, y ∈ D_T, f ∈ T(x), g ∈ T(y)
```
