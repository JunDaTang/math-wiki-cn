# 数学手册(原书第10版) 8.5 曲面积分

本页汇总《数学手册(原书第10版)》8.5 节「曲面积分」的内容。与线积分的三种类型（源回指第 684 页 8.3，未入库）平行，曲面积分分为**第一类曲面积分**（对面积微元 dS，与定向无关）、**第二类曲面积分**（又称投影积分，对坐标面上的有向投影，随定向变号）与**一般类型的曲面积分**（三个第二类积分之和）三类。全节按「概念—存在定理—化算—应用」展开，核心思想是把曲面积分化归为平面区域上的二重积分（回指第 694 页 8.4.1，未入库）。文末署名「（胡俊美译）」，转写中该署名被错插于式 (8.168b) 编号之前。

## 结构总览

- **8.5.1 第一类曲面积分**：概念（定义 8.148a–c、五步构造、存在定理）；计算（显式表示 8.149–8.150b、参数表示 8.151a–d、显式为参数特例 8.152、面积微元表 8.12）；应用（曲面面积 8.153、不均匀曲面质量 8.154）。
- **8.5.2 第二类曲面积分（投影积分）**：概念（有向曲面与投影正负规则、定义 8.155–8.156c、存在定理）；计算（显式 8.157–8.158c、参数 8.159–8.160c）。
- **8.5.3 一般类型的曲面积分**：定义 8.161、化算 8.162、性质 8.163–8.165、体积应用 8.166–8.167b 与球体算例 8.168a–b。

## 核心公式骨架

```latex
\int_S f\,\mathrm{d}S = \iint_{S'} f[x,y,z(x,y)]\sqrt{1+p^2+q^2}\,\mathrm{d}x\,\mathrm{d}y            % 8.150a 第一类·显式
\int_S f\,\mathrm{d}S = \iint_\Delta f[x(u,v),y(u,v),z(u,v)]\sqrt{EG-F^2}\,\mathrm{d}u\,\mathrm{d}v  % 8.151b 第一类·参数
\int_S f\,\mathrm{d}x\,\mathrm{d}y = \int_{\Pr_{xy}S} f[x,y,\varphi(x,y)]\,\mathrm{d}S_{xy}          % 8.158a 第二类·显式
\int_S f\,\mathrm{d}x\,\mathrm{d}y = \int_\Delta f[x(u,v),y(u,v),z(u,v)]\frac{D(x,y)}{D(u,v)}\,\mathrm{d}u\,\mathrm{d}v   % 8.160a 第二类·参数
\int_S (P\,\mathrm{d}y\,\mathrm{d}z + Q\,\mathrm{d}z\,\mathrm{d}x + R\,\mathrm{d}x\,\mathrm{d}y)
 = \int_\Delta \Big[P\frac{D(y,z)}{D(u,v)} + Q\frac{D(z,x)}{D(u,v)} + R\frac{D(x,y)}{D(u,v)}\Big]\mathrm{d}u\,\mathrm{d}v  % 8.162 一般类型
V = \tfrac{1}{3}\int_S (x\,\mathrm{d}y\,\mathrm{d}z + y\,\mathrm{d}z\,\mathrm{d}x + z\,\mathrm{d}x\,\mathrm{d}y)  % 8.166（与 8.167b 逐字相同！）
V = \int_S x\,\mathrm{d}y\,\mathrm{d}z = \int_S y\,\mathrm{d}z\,\mathrm{d}x = \int_S z\,\mathrm{d}x\,\mathrm{d}y  % 8.167a
```

各公式归属各自的积分类型，性质不可跨类迁移（详见 [[comparisons/三类曲面积分比较]]）。

## 表 8.12 曲面面积微元（逐字转录）

**标题脱字注记**：源文作「8.12 给出了曲面的面积微元／8.12 曲面面积微元」，脱「表」字，且编号与 8.5.2.1.1 中文献引用 **[8.12]**（单侧曲面文献）撞号，两处所指完全不同。

| 坐标 | 面积微元 |
|---|---|
| 笛卡儿坐标 $x, y, z = z(x,y)$ | $\mathrm{d}S = \sqrt{1 + \left( \frac{\partial z}{\partial x} \right)^2 + \left( \frac{\partial z}{\partial y} \right)^2}\,\mathrm{d}x\,\mathrm{d}y$ |
| 柱面侧面，$R$（常数，半径），坐标 $\varphi, z$ | $\mathrm{d}S = R\,\mathrm{d}\varphi\,\mathrm{d}z$ |
| 球面 $R$（常数，半径），坐标 $\vartheta, \varphi$ | $\mathrm{d}S = R^2 \sin\vartheta\,\mathrm{d}\vartheta\,\mathrm{d}\varphi$ |
| 任意曲线坐标 $u, v$（$E, F, G$ 参见 354 页弧微分） | $\mathrm{d}S = \sqrt{EG - F^2}\,\mathrm{d}u\,\mathrm{d}v$ |

复算与出处 → [[findings/表8-12曲面面积微元逐字转录与复算]]。

## 独立复算结果（分析阶段完成，均确认无误）

1. **式 8.152**：$EG - F^2 = (1+p^2)(1+q^2) - (pq)^2 = 1 + p^2 + q^2$，与显式公式 8.150a 的根号内表达式完全一致——显式表示确为参数表示的特例。
2. **法线与方向余弦**：法线方程 $(X-x)/p = (Y-y)/q = (Z-z)/(-1)$ 与 $\cos\gamma = 1/\sqrt{1+p^2+q^2}$（$\gamma$ 取锐角，故 $\cos\gamma > 0$）核对无误；表 8.12 四行面积微元均为标准正确结果。
3. **球体算例**：式 8.168a 的 $D(x,y)/D(\vartheta,\varphi) = R^2\cos\vartheta\sin\vartheta$ 逐元素验证无误；式 8.168b 得 $V = 2\pi R^3 \cdot \tfrac{2}{3} = \tfrac{4}{3}\pi R^3$。

**机制注记**：球坐标参数化诱导球面外侧定向（$\mathbf r_\vartheta \times \mathbf r_\varphi = R^2\sin\vartheta\,\hat{\mathbf r}$ 指向径向外），雅可比符号恰好编码上、下半球在 $xOy$ 面上投影的正负，而 $z\cdot D(x,y)/D(\vartheta,\varphi) = R^3\cos^2\vartheta\sin\vartheta \ge 0$，故按式 8.167a 单个积分 $V = \int_S z\,\mathrm{d}x\,\mathrm{d}y$ 即可给出全部体积。

## 转写疑点

- **式 8.166 与式 8.167b 逐字相同**（同一公式出现两次）→ [[queries/式8-166与8-167b完全重复是否原书原文]]
- **投影下标次序不一致**：图 8.46(d) 说明用 $\Pr_{xz}$（xOz 面），而 8.156c、8.158c、8.161 一律用 $\Pr_{zx}$（dz dx 次序）；第二类积分对坐标次序敏感（差一个符号），并非纯排版问题 → [[queries/投影下标xz与zx次序不一致问题]]
- 8.5.2.1.3「与第一类曲面积分的**计算方法**类似，但在**第三步**中……」——「第三步」属五步定义程序，「计算方法」疑应为「定义」
- 残句「(8.150a) (8.151b) 的特殊情况事实上，」疑脱字，原意约为「显式 (8.150a) 是参数 (8.151b) 的特殊情况」
- 记号漂移：8.150a 用 $S'$ 表投影域、8.150b 用 $S_{xy}$；存在定理措辞「定义曲面的方程也连续」欠严谨
- 系统性 OCR 讹误（笫→第、千→于、而→面、S 符号脱漏 ≥13 处、「页」字系统性脱漏、`\liminfits`→`\limits` 等）→ [[queries/8-5全节系统性转写讹误清单]]
