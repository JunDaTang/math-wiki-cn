# 数学手册(原书第10版) 6.1.3 高阶导数

本页是《数学手册(原书第10版)》6.1.3 节「高阶导数」的入库摘要。该节系统给出高阶导数的定义（式 6.21）、初等函数的封闭形式 n 阶导数表（表 6.3）、乘积求导的莱布尼茨公式（式 6.22–6.23，附两个算例）、参数形式函数的高阶导数（式 6.24）与反函数的高阶导数（式 6.25）。它是 [[sources/10-数学手册原书第10版--10-61-一元函数的微分--6vscw8]]（6.1 一元函数的微分）的子节，本次入库填充了 [[queries/6-1各子小节未入库缺口]] 所列缺口之一。

全节为手册式「定义—公式—算例」结构，无论证性主张。所有公式均为解析恒等式，入库时已逐条独立复算：表 6.3 全部 12 行、式 6.22–6.25 及算例 A、B 均已验证；其中算例 B 的源文转写损坏，正确结果经复算复原为 $e^{x}(x^{3}+18x^{2}+90x+120)$。

## 公式逐字转录

### 式 6.21（高阶导数的定义）

$$
y^{(n)} = \frac{\mathrm{d}^{n} y}{\mathrm{d} x^{n}} = f^{(n)}(x) = \frac{\mathrm{d}^{n} f(x)}{\mathrm{d} x^{n}} \quad \left(n = 0, 1, \dots ;\; y^{(0)}(x) = f^{(0)}(x) = f(x)\right).\tag{6.21}
$$

原文先定义二阶导数：$y' = f'(x)$ 的导数，即 $\left(y'\right)'$（与 $\frac{\mathrm{d}}{\mathrm{d}x}\left(\frac{\mathrm{d}y}{\mathrm{d}x}\right)$，此处连接符在转写中损坏），记为 $y'' ,\ \ddot y ,\ \frac{\mathrm{d}^{2} y}{\mathrm{d} x^{2}} ,\ f''(x)$ 或 $\frac{\mathrm{d}^{2} f(x)}{\mathrm{d} x^{2}}$。

### 表 6.3 某些初等函数的高阶导数（逐字转录，含表头讹误）

| 函数 | n阶函数（原文表头，疑应为「n 阶导数」） |
|---|---|
| $x^{m}$ | $m(m-1)(m-2)\cdots(m-n+1)x^{m-n}$（当 m 为整数,且 n>m 时,n 阶导数为 0） |
| $\ln x\ (x>0)$ | $(-1)^{n-1}(n-1)! \dfrac{1}{x^{n}}$ |
| $\log_{a} x\ (x>0)$ | $(-1)^{n-1} \dfrac{(n-1)!}{\ln a} \dfrac{1}{x^{n}}$ |
| $e^{kx}$ | $k^{n} e^{kx}$ |
| $a^{x}$ | $(\ln a)^{n} a^{x}$ |
| $a^{kx}$ | $(k \ln a)^{n} a^{kx}$ |
| $\sin x$ | $\sin\left(x + \dfrac{n\pi}{2}\right)$ |
| $\cos x$ | $\cos\left(x + \dfrac{n\pi}{2}\right)$ |
| $\sin kx$ | $k^{n}\sin\left(kx + \dfrac{n\pi}{2}\right)$ |
| $\cos kx$ | $k^{n}\cos\left(kx + \dfrac{n\pi}{2}\right)$ |
| $\sinh x$ | 当 n 为偶数时为 $\sinh x$，当 n 为奇数时为 $\cosh x$ |
| $\cosh x$ | 当 n 为偶数时为 $\cosh x$，当 n 为奇数时为 $\sinh x$ |

首行注记「当 m 为整数，且 n>m 时，n 阶导数为 0」仅在 m 为非负整数时成立，疑为原版「自然数」之误，追踪于 [[queries/表6-3的m为整数条件是否应为非负整数]]。

### 式 6.22–6.23（莱布尼茨公式）

$$
\begin{array}{rl}
D^{n}(uv) = & uD^{n}v + \dfrac{n}{1!}Du\,D^{n-1}v + \dfrac{n(n-1)}{2!}D^{2}u\,D^{n-2}v + \dots \\
& + \dfrac{n(n-1)\cdots(n-m+1)}{m!}D^{m}u\,D^{n-m}v + \dots + D^{n}u\,v,
\end{array}\tag{6.22}
$$

其中 $D^{n} = \dfrac{\mathrm{d}^{n}}{\mathrm{d}x^{n}}$。原文注：「若用 $D^{0}u, D^{0}v$ 分别代替 $u, v$，可得公式 (6.23)，它的结构与二项式公式对应（参见第 14 1.1.6.4)」——该交叉引用转写损坏（疑为「第 1 章 1.1.6.4」，亦不排除「第 14 页」）：

$$
D^{n}(uv) = \sum_{m=0}^{n}\binom{n}{m} D^{m}u\, D^{n-m}v.\tag{6.23}
$$

### 式 6.24（参数形式函数的高阶导数）

$$
\frac{\mathrm{d}^{2} y}{\mathrm{d} x^{2}} = \frac{\dot{x} \ddot{y} - \dot{y} \ddot{x}}{\dot{x}^{3}}, \quad \frac{\mathrm{d}^{3} y}{\mathrm{d} x^{3}} = \frac{\dot{x}^{2} \dddot{y} - 3\dot{x} \ddot{x} \ddot{y} + 3\dot{y} \ddot{x}^{2} - \dot{x} \dot{y} \dddot{x}}{\dot{x}^{5}}, \dots \quad (\dot{x}(t) \neq 0).\tag{6.24}
$$

其中 $\dot{y}(t) = \frac{\mathrm{d}y}{\mathrm{d}t}$、$\dot{x}(t) = \frac{\mathrm{d}x}{\mathrm{d}t}$、$\ddot{y}(t) = \frac{\mathrm{d}^{2}y}{\mathrm{d}t^{2}}$、$\ddot{x}(t) = \frac{\mathrm{d}^{2}x}{\mathrm{d}t^{2}}$ 等表示关于参数 t 的导数（原文「关千参数 的导数」有脱字）。

### 式 6.25（反函数的高阶导数）

$$
\frac{\mathrm{d}^{2} y}{\mathrm{d} x^{2}} = - \frac{\varphi''(y)}{[\varphi'(y)]^{3}}, \quad \frac{\mathrm{d}^{3} y}{\mathrm{d} x^{3}} = \frac{3[\varphi''(y)]^{2} - \varphi'(y)\varphi'''(y)}{[\varphi'(y)]^{5}}, \dots.\tag{6.25}
$$

原文设定（转写有脱字）：若 $y = \varphi(x)$ 是原函数 $y = f(x)$ 的反函数，则 $y = f(x) \iff x = \varphi(y)$（等价号脱落）；设 $\varphi'(y) \neq 0$，函数 f 的导数与反函数 φ 的导数满足关系 (6.15)（位于手册 6.1.2，尚未入库）。

## 算例

- **算例 A** $\left(x^{2}\cos ax\right)^{(50)}$：取 $v = x^{2}$、$u = \cos ax$，仅 3 项非零，结果 $a^{48}\left[(2450 - a^{2}x^{2})\cos ax - 100\,ax\sin ax\right]$，中间步骤与最终结果均已独立复算确认无误 → [[findings/算例A-x2cosax的50阶导数复算]]。
- **算例 B** $\left(x^{3}e^{x}\right)^{(6)}$：源文最终合并式转写损坏（「$= e^x(x^3+6)\cdot 11 e^x$ $18x^2+90x+120)$」），复算复原为 $e^{x}(x^{3}+18x^{2}+90x+120)$ → [[findings/算例B-x3ex的6阶导数复原-转写损坏]]、[[queries/例B式x3ex6阶导数转写损坏如何复原]]。
