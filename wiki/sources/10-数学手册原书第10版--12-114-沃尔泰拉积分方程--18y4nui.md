# 数学手册(原书第10版) 11.4 沃尔泰拉积分方程

本页是《数学手册(原书第10版)》第 11 章（积分方程）第 4 节“沃尔泰拉积分方程”的入库摘要。该节在 11.1 的分类框架与 11.2 的弗雷德霍姆理论之后，系统阐述沃尔泰拉方程的可解性理论与四类解法，并给出三个可复算的算例。本节与 11.2 各小节构成自觉的对照性叙述（原文明言“与弗雷德霍姆积分方程不同”）。版本信息未在本文档中给出，仅知为原书第 10 版的中译本。

## 小节结构与核心内容

- **11.4.1 理论基础**：第二类方程 (11.56)；存在唯一性定理（见 [[concepts/沃尔泰拉方程的存在唯一性定理]]）；第一类方程经微商或分部积分化归为第二类（均需 K(x,x)≠0），见 [[methodology/第一类沃尔泰拉积分方程化第二类流程]]。
- **11.4.2 通过微商得到的解**：对两类方程求导 (11.60a–d)；多项式核经 n+1 次求导化为线性微分方程，见 [[methodology/沃尔泰拉方程微商化微分方程法]]；两个算例分别得 φ(x)=x 与 φ(x)=(3/2)(1−cos 2x)=3sin²x。
- **11.4.3 诺伊曼级数解法**：核扩张 (11.62a) 将沃尔泰拉方程恒同为弗雷德霍姆方程；迭代核三角递推 (11.62d–e)；核心结论：**若有解，诺伊曼级数与 λ 的值无关地收敛**；指数核算例给出预解式 T(x,y;λ)=e^{(x−y)(λ+1)} 与闭式解。
- **11.4.4 卷积型方程**：差核 (11.63a)；拉普拉斯变换把两类方程化为代数方程 (11.64a–d)；H(p)=K(p)/(1−K(p)) 仅依赖核，其逆 h 为预解核，解为 φ=f+h∗f，见 [[methodology/拉普拉斯变换解卷积型沃尔泰拉方程]]。
- **11.4.5 数值方法**：求积区间 [a,x] 随 x 变化、插值节点须嵌套，因而**高斯求积不可用**；左矩形格式显式 (11.67b)、梯形格式隐式 (11.67e)、非线性方程用混合格式回避，见 [[methodology/沃尔泰拉积分方程数值解法]]。

## 核心结论（经复算确认）

1. 存在唯一性：f 在 I=[a,b] 或 [a,∞) 连续、K 在三角域 x∈I、y∈[a,x] 连续 ⇒ (11.56) 存在唯一连续解，且 φ(a)=f(a) (11.57)。
2. 第一类化归：微商路线 (11.58a–b) 与分部积分路线 (11.59a–c)，均以 K(x,x)≠0 为条件。
3. 多项式核微商化：核关于 x 最高次数为 n 时，求 n+1 次导后第一类化为 n 阶（转写缺字，据算例推断）、第二类化为 n+1 阶线性微分方程。
4. 诺伊曼级数：沃尔泰拉情形若有解则对任意 λ 收敛——与 11.2.2 弗雷德霍姆情形的 |λ| 型条件形成根本对照，见 [[comparisons/弗雷德霍姆与沃尔泰拉方程诺伊曼级数收敛性比较]]。
5. 卷积型方程：K(p)Φ=F（第一类）、Φ=F/(1−K)（第二类）；h=L⁻¹{K/(1−K)} 为预解核。
6. 数值解法：节点嵌套要求排除高斯求积；左矩形为显式步进、梯形为隐式；算例中梯形精度显著优于矩形（x=1.0 处误差 0.0010 对 0.1163，h=0.1）。

## 关键公式逐字转录

```
第二类沃尔泰拉积分方程及其存在唯一性：
  φ(x) = f(x) + ∫_a^x K(x,y) φ(y) dy                                    (11.56)
  φ(a) = f(a)                                                            (11.57)

第一类沃尔泰拉积分方程及其两条化归路线：
  f(x) = ∫_a^x K(x,y) φ(y) dy                                            (11.58a)
  f'(x) = K(x,x) φ(x) + ∫_a^x (∂K/∂x)(x,y) φ(y) dy                       (11.58b)
  ∫_a^x φ(y) dy = ψ(x)                                                   (11.59a)
  f(x) = K(x,x) ψ(x) − ∫_a^x (∂K/∂y)(x,y) ψ(y) dy                        (11.59b)
  ψ(x) = f(x)/K(x,x) + (1/K(x,x)) ∫_a^x (∂K/∂y)(x,y) ψ(y) dy             (11.59c)

微商化（第一类 11.60a、第二类 11.60b 分别求导得）：
  f'(x) = K(x,x) φ(x) + ∫_a^x (∂K/∂x)(x,y) φ(y) dy                       (11.60c)
  φ'(x) = f'(x) + K(x,x) φ(x) + ∫_a^x (∂K/∂x)(x,y) φ(y) dy               (11.60d)

诺伊曼级数解法（核扩张与迭代核）：
  K̄(x,y) = { K(x,y),  y ≤ x;  0,  y > x }                                (11.62a)
  φ(x) = f(x) + λ ∫_a^b K̄(x,y) φ(y) dy    （容许 b = ∞）                  (11.62b)
  φ(x) = f(x) + Σ_{n=1}^∞ λ^n ∫_a^b K_n(x,y) f(y) dy                      (11.62c)
  K_1(x,y) = K̄(x,y),  K_2(x,y) = ∫_y^x K(x,η) K(η,y) dη, …               (11.62d)
  K_n(x,y) = ∫_y^x K(x,η) K_{n−1}(η,y) dη                                (11.62e)

卷积型方程的拉普拉斯变换解法：
  K(x,y) = { k(x−y),  0 ≤ y ≤ x;  0,  0 ≤ x < y }                        (11.63a)
  ∫_0^x k(x−y) φ(y) dy = f(x)                                            (11.63b)
  φ(x) = f(x) + ∫_0^x k(x−y) φ(y) dy                                     (11.63c)
  K(p) Φ(p) = F(p)                                                        (11.64a)
  Φ(p) = F(p) + K(p) Φ(p)                                                 (11.64b)
  Φ(p) = F(p)/K(p)                                                        (11.64c)
  Φ(p) = F(p)/(1 − K(p))                                                  (11.64d)
  Φ(p) = F(p) + [K(p)/(1 − K(p))] F(p)                                    (11.64e)
  H(p) = K(p)/(1 − K(p))，其逆为 h(x)                                      (11.64f)
  φ(x) = f(x) + ∫_0^x h(x−y) f(y) dy                                      (11.64g)

数值方法（逐节点递推）：
  ∫_a^x K(x,y) φ(y) dy ≈ Q_{[a,x]}(K(x,·) φ(·))                           (11.66a)
  φ̄(x) = f(x) + Q_{[a,x]}(K(x,·) φ̄(·))                                    (11.66b)
  φ_0 = f(x_0) = f(a)                                                     (11.66c)
  φ_1 = f(x_1) + Q_{[a,x_1]}(K(x_1,·) φ̄(·))                                (11.66d)
  Q_{[a,x_1]}(K(x_1,·) φ̄(·)) = w_0 K(x_1,x_0) φ_0 + w_1 K(x_1,x_1) φ_1    (11.66e)
  φ_k = f(x_k) + Q_{[a,x_k]}(K(x_k,·) φ̄(·)),  k = 1,2,3,…                (11.66f)
  Q_{[a,x_k]}(K(x_k,·) φ̄(·)) = Σ_{j=0}^k w_{jk} K(x_k,x_j) φ_j           (11.66g)
  φ_k = f(x_k) + Σ_{j=0}^k w_{jk} K(x_k,x_j) φ_j                          (11.66h)
  w_{jk} = x_{j+1} − x_j (j < k)，且 w_{kk} = 0                            (11.66i)
  φ_k = f(x_k) + Σ_{j=0}^{k−1} (x_{j+1} − x_j) K(x_k,x_j) φ_j             (11.67b)
  ∫_a^b g(x) dx ≈ (h/2)[g(x_0) + 2Σ_{j=1}^{k−1} g(x_j) + g(x_k)]          (11.67c)
  φ_k = f(x_k) + (h/2)[K(x_k,x_0)φ_0 + K(x_k,x_k)φ_k + 2Σ_{j=1}^{k−1} K(x_k,x_j)φ_j]   (11.67e)
```
