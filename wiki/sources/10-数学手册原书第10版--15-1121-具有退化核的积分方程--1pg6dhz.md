# 数学手册(原书第10版) 11.2.1 具有退化核的积分方程

《数学手册(原书第10版)》第 11 章（积分方程）11.2.1 小节，处理**具有退化核的第二类弗雷德霍姆积分方程**。全节主线是一个化归：核的有限和分解把无穷维的积分方程压缩为 $n$ 维线性方程组，可解性与本征值问题由此完全由一个行列式 $D(\lambda)$ 控制；末节引入转置（伴随）积分方程，给出本征值处的正交可解性条件——这是全节唯一被明确声明对一般核也成立的结论。本节是 wiki 首批入库的第 11 章内容。

## 小节结构

1. 退化核情形的解（化归为有限维方程组，式 11.4–11.6）
2. 解的系数的计算（式 11.7a–d）
3. 解、本征值、本征函数的分析（式 11.8 与两种情形）
4. 转置积分方程（式 11.9a–b，正交可解性条件）
5. 算例 A（多项式核，$\lambda=1$）与算例 B（$\sin(x+y)$ 核）
6. 结尾方法声明：一般核可用退化核足够好地逼近以获得近似解

## 核心公式链（逐字转录）

```latex
% (11.4a) 第二类弗雷德霍姆积分方程
\varphi(x) = f(x) + \lambda \int_a^b K(x,y)\,\varphi(y)\,\mathrm{d}y

% (11.4b) 退化核（积核）
K(x,y) = \alpha_1(x)\beta_1(y) + \alpha_2(x)\beta_2(y) + \dots + \alpha_n(x)\beta_n(y)

% (11.5) 线性无关（最小性条件）：具常系数 c_k 的等式
\sum_{k=1}^{n} c_k\,\alpha_k(x) \equiv 0
% 对每个 x∈[a,b] 成立，仅当 c_1=…=c_n=0 时；否则 K(x,y) 可被表示成较小数目乘积的和

% (11.6a) 将 (11.4b) 代入 (11.4a)
\varphi(x) = f(x) + \lambda\alpha_1(x)\int_a^b \beta_1(y)\varphi(y)\,\mathrm{d}y + \dots
+ \lambda\alpha_n(x)\int_a^b \beta_n(y)\varphi(y)\,\mathrm{d}y

% (11.6b) 系数（积分后为常数）
A_k = \int_a^b \beta_k(y)\,\varphi(y)\,\mathrm{d}y,\qquad k = 1,\dots,n

% (11.6c) 解的结构
\varphi(x) = f(x) + \lambda A_1\alpha_1(x) + \lambda A_2\alpha_2(x) + \dots + \lambda A_n\alpha_n(x)

% (11.7a) 以 β_k(x) 乘 (11.6c) 并在 [a,b] 上积分
\int_a^b \beta_k(x)\varphi(x)\,\mathrm{d}x
= \int_a^b \beta_k(x)f(x)\,\mathrm{d}x
+ \lambda A_1\int_a^b \beta_k(x)\alpha_1(x)\,\mathrm{d}x + \dots
+ \lambda A_n\int_a^b \beta_k(x)\alpha_n(x)\,\mathrm{d}x

% (11.7b) 记号
b_k = \int_a^b \beta_k(x)f(x)\,\mathrm{d}x,\qquad
c_{kj} = \int_a^b \beta_k(x)\alpha_j(x)\,\mathrm{d}x

% (11.7c)
A_k = b_k + \lambda c_{k1}A_1 + \lambda c_{k2}A_2 + \dots + \lambda c_{kn}A_n,\qquad k=1,\dots,n

% (11.8) 行列式判据
D(\lambda) = \det\bigl(\delta_{kj} - \lambda c_{kj}\bigr)_{k,j=1}^{n} \neq 0

% (11.9a) 转置积分方程（复情形：伴随积分方程）
\psi(x) = g(x) + \lambda \int_a^b K(y,x)\,\psi(y)\,\mathrm{d}y

% (11.9b) 正交条件的出发点
\int_a^b \varphi(x)\psi(x)\,\mathrm{d}x
= \int_a^b f(x)\psi(x)\,\mathrm{d}x
+ \int_a^b \Bigl(\lambda\int_a^b K(x,y)\psi(x)\,\mathrm{d}x\Bigr)\varphi(y)\,\mathrm{d}y

% 齐次伴随方程代入即得正交条件
\psi(y) = \lambda\int_a^b K(x,y)\psi(x)\,\mathrm{d}x
\;\Longrightarrow\; \int_a^b f(x)\psi(x)\,\mathrm{d}x = 0

% D(λ)=0 时齐次方程的非零解（本征函数）
\varphi(x) = C\bigl(A_1\alpha_1(x) + A_2\alpha_2(x) + \dots + A_n\alpha_n(x)\bigr)

% 特征数约定
\mu = \frac{1}{\lambda},\qquad \mu\,\varphi(x) = \int_a^b K(x,y)\varphi(y)\,\mathrm{d}y
```

线性方程组 (11.7d)（第二行末项转写原文作 $A_2$，按方程组结构疑应为 $A_n$，见 [[queries/11-2-1全节系统性转写讹误清单]]）：

```text
(1 − λc₁₁)A₁ − λc₁₂A₂ − … − λc₁ₙAₙ = b₁
−λc₂₁A₁ + (1 − λc₂₂)A₂ − … − λc₂ₙA₂ = b₂
……
−λcₙ₁A₁ − λcₙ₂A₂ − … + (1 − λcₙₙ)Aₙ = bₙ
```

## 主要论证

1. **化归**：核取退化形式 (11.4b) 后，解若存在必具结构 (11.6c)，系数 $A_k$ 由 $n$ 维线性方程组 (11.7d) 决定。详见 [[findings/式11-4至11-6退化核定义与解结构转录复算]]、[[findings/式11-7a至11-7d系数方程组建立转录复算]]。
2. **可解性判据 (11.8)**：$D(\lambda)=\det(\delta_{kj}-\lambda c_{kj})$；$D(0)=1$ 故存在 $R>0$ 使 $|\lambda|<R$ 时唯一可解；$D(\lambda)$ 为次数不高于 $n$ 的多项式，至多 $n$ 个根。详见 [[findings/式11-8行列式判据与两情形转录复算]]。
3. **本征值与本征函数**：$D(\lambda)=0$ 的根为本征值，齐次方程非零解为本征函数，形如 $C\sum A_k\alpha_k$；$\alpha_k$ 线性无关保证其不恒为零；几个线性无关本征函数可属同一本征值。见 [[concepts/积分方程的本征值与本征函数]]。
4. **转置方程共享本征值 (11.9a)**：$\lambda$ 为原方程本征值则亦为伴随方程本征值（文中称"容易证明"，退化核情形可由 $\det(c_{jk})=\det(c_{kj})$ 补全）。见 [[concepts/转置积分方程与伴随积分方程]]。
5. **正交可解性条件 (11.9b)**：本征值处（两处"齐次"疑为"非齐次"之误，见 [[queries/转置方程段两处齐次是否应为非齐次]]）方程可解 $\iff$ 扰动函数 $f$ 与齐次伴随方程属于同一 $\lambda$ 的每个非零解正交。**文中明确声明此条对一般核也成立**——不应将其余结论（有限维化归、$D(\lambda)$ 判据）转嫁给一般核。见 [[findings/式11-9a至11-9b转置方程与正交条件转录复算]]、[[concepts/积分方程的正交可解性条件]]。

## 算例复算结果

- **算例 A**（$\lambda=1$，核 $x^2y+xy^2-xy$，区间 $[-1,1]$）：$\alpha_2=x$ 与 $\alpha_3=-x$ 线性相关，先合并为两项核 $x^2y+x(y^2-y)$——(11.5) 最小性条件的活用；逐项复算 $c_{kj}$、$b_k$ 全部吻合，解得 $\varphi(x)=\tfrac{10}{21}x^2+\tfrac{5}{7}x$，另验证 $D(1)=7/5\neq 0$ 与唯一可解性相符。见 [[findings/算例A线性相关退化核合并求解复算]]。
- **算例 B**（核 $\sin(x+y)=\sin x\cos y+\cos x\sin y$，区间 $[0,\pi]$）：复算 $D(\lambda)=1-\lambda^2\pi^2/4$；Cramer 解 $A_1=(\lambda\pi^2/2-2)/D$、$A_2=\pi(1-\lambda)/D$ 吻合；本征值 $\lambda_{1,2}=\pm 2/\pi$，本征函数 $\varphi_1=A(\sin x+\cos x)$、$\varphi_2=B(\sin x-\cos x)$ 经齐次组直接验证吻合。见 [[findings/算例B正弦退化核求解与本征值复算]]。

## 证据强度

- 化归推导、行列式判据与两算例经逐项独立复算全部吻合 — **高**。
- 转置方程共享本征值：退化核情形可由转置矩阵行列式不变补全证明 — **高**。
- 正交条件对一般核的推广：引用性断言，本节未证 — **中**。
- 退化核逼近一般核：仅一句方法性声明，无误差分析 — **低/未证**。
