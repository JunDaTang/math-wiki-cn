# 数学手册(原书第10版) 20.2.3 重要算子

## 概述

本页对应《数学手册（原书第10版）》20.2「Mathematica 的重要结构要素」之第 3 小节「重要算子」，母节页面见 [[sources/10-数学手册原书第10版--22-202-mathematica的重要结构要素--1w5xyrj]]。全节为定义性参考内容，所有论断**仅关于 [[entities/mathematica|Mathematica]] 一个系统**，不涉及 Matlab 或 Maple：先以表 20.2 汇集最常出现算子的中置形式与完全形式对照，继而解释具有头 Rule、Set 的表达式的求值语义，引入替换算子与延迟赋值算子（式 20.8a/b），最后给出 Equal 的恒等判定。

## 表 20.2 中置形式与完全形式（原文转录）

源文表题作「20.2 Mathematica 中的重要算子」（「表」字疑与前文连排脱失，应为「表 20.2」）。12 组对照逐格转录如下：

| 中置形式 | 完全形式 | 中置形式 | 完全形式 |
|---|---|---|---|
| a + b | Plus[a, b] | u == v | Equal[u, v] |
| a b 或 a * b | Times[a, b] | w! = v | Unequal[w, v] |
| a^b 或 aᵇ | Power[a, b] | r > t | Greater[r, t] |
| a/b | Times[a, Power[b, -1]] | r ≥ t | GreaterThan[r, t] |
| u->v | Rule[u, v] | s < t | Less[s, t] |
| r = s | Set[r, s] | s ≤ t | LessEqual[s, t] |

（「aᵇ」为原书上标排版形；「w! = v」为原书隔写形，标准记法为 `w != v`。）

本节的组织原则：无论哪种情形，中置记法 `symb1 op symb2` 的完整形式都是表达式 `op[symb1, symb2]`。实用警示：形如 `a b` 的乘法中，两个因子之间的空隙非常重要（`ab` 会被解析为单一符号而非乘积）。

逐行核对见 [[findings/表20-2算子与完全形式对应转录复算]]：12 行中 11 行与 Mathematica 实际语义一致（含 `a/b` 的完全形式确为 `Times[a, Power[b, -1]]`）；唯 `r ≥ t → GreaterThan[r, t]` 一行疑讹，应为 `GreaterEqual[r, t]`，见 [[queries/r大于等于t之完全形式GreaterThan疑为GreaterEqual之辨]]。

## Set 与 Rule 的即时求值语义

源文对「具有头 Rule、Set 的表达式」的解释（校正读法；原文讹误见 [[queries/20-2-3全节系统性转写讹误清单]]）：

- `r = s`（完全形式 `Set[r, s]`）把右手边表达式 s 求值（s 如一个数）后指派给左手边的表达式 r（例如一个变元）；由此开始 r 表示这个值，直到该指派改变为止。改变有三途：新指派、`x = .`（即 `Unset[x]`）、或 `Clear[x]`（去除到目前为止的所有指派）。
- `Rule[u, v]`（中置形式 `u -> v`）应被看成一种变换规则，与替换算子 `/.` 一同出现：`Replace[t, u->v]` 或 `t /. u->v` 意指表达式 t 中 u 的每个出现将被替换为表达式 v。此表述与 Mathematica 官方语义的出入（`/.` 实为 ReplaceAll）见 [[queries/Replace疑为ReplaceAll之辨]]。
- 对这两个算子来说，典型情况是进行指派或运用变换规则后，右手边即刻求出值来；因此后面每次调用时，左手边将被这个已算出值的右手边取代。

详见 [[concepts/Set指派与清除]]、[[concepts/Rule变换规则与替换算子]]。

## 替换算例（原文转录）

```
In[1]:= x + y^2 /. y -> a + b
Out[1] = (a + b)^2 + x
```

复算通过，见 [[findings/In1替换算例复算]]；此算例亦是 [[concepts/Mathematica输入输出行记法]] 的又一实例。

## 延迟赋值（式 20.8a–20.8b，原文转录）

```
u := v  的 FullForm 是 SetDelayed[u, v]     (20.8a)
u :-> v 的 FullForm 是 RuleDelayed[u, v]    (20.8b)
```

（`u :-> v` 为原书排版形，标准输入形式为 `u :> v`。）

语义：指派或变换规则在此同样有效，直到它被改变；尽管左手边总是被右手边取代，但只有当调用左手边的那一刻，右手边才第一次算出值来。复算见 [[findings/式20-8a至20-8b延迟赋值完全形式转录复算]]；与 Set/Rule 的逐项对照见 [[comparisons/即时赋值与延迟赋值比较]]。

## Equal 恒等判定

节末指出：如果 u、v 是恒同的，表达式 `u == v`（即 `Equal[u, v]`）回复 True；Equal 用于处理方程（原句「Equal 用千如处理方程中」有脱讹，「千」为「于」之讹）。概念页见 [[concepts/Equal恒等判定与方程表示]]。
