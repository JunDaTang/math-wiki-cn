### 21.7.4.1 双曲函数积分（426–446，连续完整）

- 426. $\int\sinh ax\,dx = \frac{1}{a}\cosh ax$
- 427. $\int\cosh ax\,dx = \frac{1}{a}\sinh ax$
- 428. $\int\sinh^2 ax\,dx = \frac{1}{2a}\sinh ax\cosh ax - \frac{x}{2}$
- 429. $\int\cosh^2 ax\,dx = \frac{1}{2a}\sinh ax\cosh ax + \frac{x}{2}$
- 430. $\int\sinh^n ax\,dx = \frac{1}{an}\sinh^{n-1}ax\cosh ax - \frac{n-1}{n}\int\sinh^{n-2}ax\,dx \quad (n>0)$；$= \frac{1}{a(n+1)}\sinh^{n+1}ax\cosh ax - \frac{n+2}{n+1}\int\sinh^{n+2}ax\,dx \quad (n<0,\ n\neq -1)$
- 431. $\int\cosh^n ax\,dx = \frac{1}{an}\sinh ax\cosh^{n-1}ax + \frac{n-1}{n}\int\cosh^{n-2}ax\,dx \quad (n>0)$；$= -\frac{1}{a(n+1)}\sinh ax\cosh^{n+1}ax + \frac{n+2}{n+1}\int\cosh^{n+2}ax\,dx \quad (n<0,\ n\neq -1)$
- 432. $\int\frac{dx}{\sinh ax} = \frac{1}{a}\ln\tanh\frac{ax}{2}$
- 433. $\int\frac{dx}{\cosh ax} = \frac{2}{a}\arctan e^{ax}$
- 434. $\int x\sinh ax\,dx = \frac{1}{a}x\cosh ax - \frac{1}{a^2}\sinh ax$
- 435. $\int x\cosh ax\,dx = \frac{1}{a}x\sinh ax - \frac{1}{a^2}\cosh ax$
- 436. $\int\tanh ax\,dx = \frac{1}{a}\ln\cosh ax$
- 437. $\int\coth ax\,dx = \frac{1}{a}\ln\sinh ax$
- 438. $\int\tanh^2 ax\,dx = x - \frac{\tanh ax}{a}$
- 439. $\int\coth^2 ax\,dx = x - \frac{\coth ax}{a}$
- 440. $\int\sinh ax\sinh bx\,dx = \frac{1}{a^2-b^2}(a\sinh bx\cosh ax - b\cosh bx\sinh ax) \quad (a^2\neq b^2)$
- 441. $\int\cosh ax\cosh bx\,dx = \frac{1}{a^2-b^2}(a\sinh ax\cosh bx - b\sinh bx\cosh ax) \quad (a^2\neq b^2)$
- 442. $\int\cosh ax\sinh bx\,dx = \frac{1}{a^2-b^2}(a\sinh bx\sinh ax - b\cosh bx\cosh ax) \quad (a^2\neq b^2)$
- 443. $\int\sinh ax\sin ax\,dx = \frac{1}{2a}(\cosh ax\sin ax - \sinh ax\cos ax)$
- 444. $\int\cosh ax\cos ax\,dx = \frac{1}{2a}(\sinh ax\cos ax + \cosh ax\sin ax)$
- 445. $\int\sinh ax\cos ax\,dx = \frac{1}{2a}(\cosh ax\cos ax + \sinh ax\sin ax)$
- 446. $\int\cosh ax\sin ax\,dx = \frac{1}{2a}(\sinh ax\sin ax - \cosh ax\cos ax)$

### 21.7.4.2 指数函数积分（447–464，含 Ei(x) 定义段）

- 447. $\int e^{ax}dx = \frac{1}{a}e^{ax}$
- 448. $\int xe^{ax}dx = \frac{e^{ax}}{a^2}(ax-1)$
- 449. $\int x^2 e^{ax}dx = e^{ax}\left(\frac{x^2}{a}-\frac{2x}{a^2}+\frac{2}{a^3}\right)$
- 450. $\int x^n e^{ax}dx = \frac{1}{a}x^n e^{ax} - \frac{n}{a}\int x^{n-1}e^{ax}dx$
- 451. $\int\frac{e^{ax}}{x}dx = \ln x + \frac{ax}{1\cdot 1!} + \frac{(ax)^2}{2\cdot 2!} + \frac{(ax)^3}{3\cdot 3!}+\cdots$
- 452（推定，脱号）. $\int\frac{e^{ax}}{x^n}dx = \frac{1}{n-1}\left(-\frac{e^{ax}}{x^{n-1}} + a\int\frac{e^{ax}}{x^{n-1}}dx\right) \quad (n\neq 1)$
- 453. $\int\frac{dx}{1+e^{ax}} = \frac{1}{a}\ln\frac{e^{ax}}{1+e^{ax}}$（原文作 $\dot{e}^{ax}$，OCR 伪影）
- 454. $\int\frac{dx}{b+ce^{ax}} = \frac{x}{b} - \frac{1}{ab}\ln(b+ce^{ax})$
- 455. $\int\frac{e^{ax}dx}{b+ce^{ax}} = \frac{1}{ac}\ln(b+ce^{ax})$
- 456（推定，脱号）. $\int\frac{dx}{be^{ax}+ce^{-ax}} = \frac{1}{a\sqrt{bc}}\arctan\left(e^{ax}\sqrt{\frac{b}{c}}\right) \ (bc>0)$；$= \frac{1}{2a\sqrt{-bc}}\ln\frac{c+e^{ax}\sqrt{-bc}}{c-e^{ax}\sqrt{-bc}} \ (bc<0)$
- 457. $\int\frac{xe^{ax}dx}{(1+ax)^2} = \frac{e^{ax}}{a^2(1+ax)}$
- 458. $\int e^{ax}\ln x\,dx = \frac{e^{ax}\ln x}{a} - \frac{1}{a}\int\frac{e^{ax}}{x}dx$（参见 451）
- 459. $\int e^{ax}\sin bx\,dx = \frac{e^{ax}}{a^2+b^2}(a\sin bx - b\cos bx)$
- 460. $\int e^{ax}\cos bx\,dx = \frac{e^{ax}}{a^2+b^2}(a\cos bx + b\sin bx)$
- 461（推定，脱号）. $\int e^{ax}\sin^n x\,dx = \frac{e^{ax}\sin^{n-1}x}{a^2+n^2}(a\sin x - n\cos x) + \frac{n(n-1)}{a^2+n^2}\int e^{ax}\sin^{n-2}x\,dx$（参见 447, 459）
- 462. $\int e^{ax}\cos^n x\,dx = \frac{e^{ax}\cos^{n-1}x}{a^2+n^2}(a\cos x + n\sin x) + \frac{n(n-1)}{a^2+n^2}\int e^{ax}\cos^{n-2}x\,dx$（注文「(参」截断，应为「(参见 447, 460)」）
- 463（推定，脱号）. $\int xe^{ax}\sin bx\,dx = \frac{xe^{ax}}{a^2+b^2}(a\sin bx - b\cos bx) - \frac{e^{ax}}{(a^2+b^2)^2}[(a^2-b^2)\sin bx - 2ab\cos bx]$
- 464（推定，脱号）. $\int xe^{ax}\cos bx\,dx = \frac{xe^{ax}}{a^2+b^2}(a\cos bx + b\sin bx) - \frac{e^{ax}}{(a^2+b^2)^2}[(a^2-b^2)\cos bx + 2ab\sin bx]$

### 21.7.4.3 含对数函数的积分（465–487，含 Li(x) 定义段）

- 465（推定，脱号）. $\int\ln x\,dx = x\ln x - x$
- 466（推定，脱号）. $\int(\ln x)^2 dx = x(\ln x)^2 - 2x\ln x + 2x$
- 467（推定；原文误标「461」）. $\int(\ln x)^3 dx = x(\ln x)^3 - 3x(\ln x)^2 + 6x\ln x - 6x$
- 468. $\int(\ln x)^n dx = x(\ln x)^n - n\int(\ln x)^{n-1}dx \quad (n\neq -1)$
- 469. $\int\frac{dx}{\ln x} = \ln\ln x + \ln x + \frac{(\ln x)^2}{2\cdot 2!} + \frac{(\ln x)^3}{3\cdot 3!}+\cdots$
- 470. $\int\frac{dx}{(\ln x)^n} = -\frac{x}{(n-1)(\ln x)^{n-1}} + \frac{1}{n-1}\int\frac{dx}{(\ln x)^{n-1}} \quad (n\neq 1)$（参见 469）
- 471. $\int x^m\ln x\,dx = x^{m+1}\left[\frac{\ln x}{m+1} - \frac{1}{(m+1)^2}\right] \quad (m\neq -1)$
- 472. $\int x^m(\ln x)^n dx = \frac{x^{m+1}(\ln x)^n}{m+1} - \frac{n}{m+1}\int x^m(\ln x)^{n-1}dx \quad (m\neq -1,\ n\neq -1)$（参见 470）
- 473. $\int\frac{(\ln x)^n}{x}dx = \frac{(\ln x)^{n+1}}{n+1}$（脱条件 $n\neq -1$）
- 474. $\int\frac{\ln x}{x^m}dx = -\frac{\ln x}{(m-1)x^{m-1}} - \frac{1}{(m-1)^2 x^{m-1}} \quad (m\neq 1)$
- 475（推定，脱号）. $\int\frac{(\ln x)^n}{x^m}dx = -\frac{(\ln x)^n}{(m-1)x^{m-1}} + \frac{n}{m-1}\int\frac{(\ln x)^{n-1}}{x^m}dx \quad (m\neq 1)$（参见 474）
- 476. $\int\frac{x^m dx}{\ln x} = \int\frac{e^{-y}}{y}dy \quad (y = -(m+1)\ln x)$（参见 451）
- 477. $\int\frac{x^m dx}{(\ln x)^n} = -\frac{x^{m+1}}{(n-1)(\ln x)^{n-1}} + \frac{m+1}{n-1}\int\frac{x^m dx}{(\ln x)^{n-1}} \quad (n\neq 1)$
- 478. $\int\frac{dx}{x\ln x} = \ln\ln x$
- 479. $\int\frac{dx}{x^n\ln x} = \ln\ln x - (n-1)\ln x + \frac{(n-1)^2(\ln x)^2}{2\cdot 2!} - \frac{(n-1)^3(\ln x)^3}{3\cdot 3!}+\cdots$
- 480. $\int\frac{dx}{x(\ln x)^n} = \frac{-1}{(n-1)(\ln x)^{n-1}} \quad (n\neq 1)$
- 481. $\int\frac{dx}{x^p(\ln x)^n} = \frac{-1}{x^{p-1}(n-1)(\ln x)^{n-1}} - \frac{p-1}{n-1}\int\frac{dx}{x^p(\ln x)^{n-1}} \quad (n\neq 1)$
- 482. $\int\ln\sin x\,dx = x\ln x - x - \frac{x^3}{18} - \frac{x^5}{900} - \cdots - \frac{2^{2n-1}B_n x^{2n+1}}{n(2n+1)!} - \cdots$（$B_n$ 表示伯努利数，参见第 623 页 7.2.4.2；原文「示」脱「表」字）
- 483. $\int\ln\cos x\,dx = -\frac{x^3}{6} - \frac{x^5}{60} - \frac{x^7}{315} - \cdots - \frac{2^{2n-1}(2^{2n}-1)B_n x^{2n+1}}{n(2n+1)!} - \cdots$
- 484（推定，脱号）. $\int\ln\tan x\,dx = x\ln x - x + \frac{x^3}{9} + \frac{7x^5}{450} + \cdots + \frac{2^{2n}(2^{2n-1}-1)B_n x^{2n+1}}{n(2n+1)!} + \cdots$
- 485. $\int\sin\ln x\,dx = \frac{x}{2}(\sin\ln x - \cos\ln x)$
- 486. $\int\cos\ln x\,dx = \frac{x}{2}(\sin\ln x + \cos\ln x)$
- 487（存疑，脱号）. $\int e^{ax}\ln x\,dx = \frac{1}{a}e^{ax}\ln x - \frac{1}{a}\int\frac{e^{ax}}{x}dx$（参见 451；与 458 逐字全同，见 [[queries/21-7-4末式与458重复之辨]]）

### 21.7.4.4 含反三角函数的积分（488–511）

- 488（推定，脱号）. $\int\arcsin\frac{x}{a}dx = x\arcsin\frac{x}{a} + \sqrt{a^2-x^2}$
- 489（推定，脱号）. $\int x\arcsin\frac{x}{a}dx = \left(\frac{x^2}{2}-\frac{a^2}{4}\right)\arcsin\frac{x}{a} + \frac{x}{4}\sqrt{a^2-x^2}$
- 490. $\int x^2\arcsin\frac{x}{a}dx = \frac{x^3}{3}\arcsin\frac{x}{a} + \frac{1}{9}(x^2+2a^2)\sqrt{a^2-x^2}$
- 491. $\int\frac{\arcsin\frac{x}{a}}{x}dx = \frac{x}{a} + \frac{1}{2\cdot 3\cdot 3}\frac{x^3}{a^3} + \frac{1\cdot 3}{2\cdot 4\cdot 5\cdot 5}\frac{x^5}{a^5} + \frac{1\cdot 3\cdot 5}{2\cdot 4\cdot 6\cdot 7\cdot 7}\frac{x^7}{a^7}+\cdots$
- 492. $\int\frac{\arcsin\frac{x}{a}}{x^2}dx = -\frac{1}{x}\arcsin\frac{x}{a} - \frac{1}{a}\ln\frac{a+\sqrt{a^2-x^2}}{x}$
- 493. $\int\arccos\frac{x}{a}dx = x\arccos\frac{x}{a} - \sqrt{a^2-x^2}$
- 494. $\int x\arccos\frac{x}{a}dx = \left(\frac{x^2}{2}-\frac{a^2}{4}\right)\arccos\frac{x}{a} - \frac{x}{4}\sqrt{a^2-x^2}$
- 495. $\int x^2\arccos\frac{x}{a}dx = \frac{x^3}{3}\arccos\frac{x}{a} - \frac{1}{9}(x^2+2a^2)\sqrt{a^2-x^2}$
- 496. $\int\frac{\arccos\frac{x}{a}}{x}dx = \frac{\pi}{2}\ln x - \frac{x}{a} - \frac{1}{2\cdot 3\cdot 3}\frac{x^3}{a^3} - \frac{1\cdot 3}{2\cdot 4\cdot 5\cdot 5}\frac{x^5}{a^5} - \frac{1\cdot 3\cdot 5}{2\cdot 4\cdot 6\cdot 7\cdot 7}\frac{x^7}{a^7} - \cdots$
- 497（推定，脱号）. $\int\frac{\arccos\frac{x}{a}}{x^2}dx = -\frac{1}{x}\arccos\frac{x}{a} + \frac{1}{a}\ln\frac{a+\sqrt{a^2-x^2}}{x}$
- 498. 严重乱码（逐字录文见下节），复原假说：$\int\arctan\frac{x}{a}dx = x\arctan\frac{x}{a} - \frac{a}{2}\ln(a^2+x^2)$
- 499. $\int x\arctan\frac{x}{a}dx = \frac{1}{2}(x^2+a^2)\arctan\frac{x}{a} - \frac{ax}{2}$
- 500. $\int x^2\arctan\frac{x}{a}dx = \frac{x^3}{3}\arctan\frac{x}{a} - \frac{ax^2}{6} + \frac{a^3}{6}\ln(a^2+x^2)$
- 501（推定，脱号）. $\int x^n\arctan\frac{x}{a}dx = \frac{x^{n+1}}{n+1}\arctan\frac{x}{a} - \frac{a}{n+1}\int\frac{x^{n+1}dx}{a^2+x^2} \quad (n\neq -1)$
- 502. $\int\frac{\arctan\frac{x}{a}}{x}dx = \frac{x}{a} - \frac{x^3}{3^2a^3} + \frac{x^5}{5^2a^5} - \frac{x^7}{7^2a^7}+\cdots \quad (|x|<|a|)$
- 503. $\int\frac{\arctan\frac{x}{a}}{x^2}dx = -\frac{1}{x}\arctan\frac{x}{a} - \frac{1}{2a}\ln\frac{a^2+x^2}{x^2}$
- 504. $\int\frac{\arctan\frac{x}{a}}{x^n}dx = -\frac{1}{(n-1)x^{n-1}}\arctan\frac{x}{a} + \frac{a}{n-1}\int\frac{dx}{x^{n-1}(a^2+x^2)} \quad (n\neq 1)$
- 505. $\int\arccot\frac{x}{a}dx = x\arccot\frac{x}{a} + \frac{a}{2}\ln(a^2+x^2)$
- 506. $\int x\arccot\frac{x}{a}dx = \frac{1}{2}(x^2+a^2)\arccot\frac{x}{a} + \frac{ax}{2}$
- 507. $\int x^2\arccot\frac{x}{a}dx = \frac{x^3}{3}\arccot\frac{x}{a} + \frac{ax^2}{6} - \frac{a^3}{6}\ln(a^2+x^2)$
- 508（推定，脱号）. $\int x^n\arccot\frac{x}{a}dx = \frac{x^{n+1}}{n+1}\arccot\frac{x}{a} + \frac{a}{n+1}\int\frac{x^{n+1}dx}{a^2+x^2} \quad (n\neq -1)$
- 509. $\int\frac{\arccot\frac{x}{a}}{x}dx = \frac{\pi}{2}\ln x - \frac{x}{a} + \frac{x^3}{3^2a^3} - \frac{x^5}{5^2a^5} - \frac{x^7}{7^2a^7} - \cdots$（尾部符号与微分复算不符，见 [[findings/公式509尾部符号与微分复算不符]]；另脱条件 $(|x|<|a|)$）
- 510. $\int\frac{\arccot\frac{x}{a}}{x^2}dx = -\frac{1}{x}\arccot\frac{x}{a} + \frac{1}{2a}\ln\frac{a^2+x^2}{x^2}$
- 511（推定，脱号）. $\int\frac{\arccot\frac{x}{a}}{x^n}dx = -\frac{1}{(n-1)x^{n-1}}\arccot\frac{x}{a} - \frac{a}{n-1}\int\frac{dx}{x^{n-1}(a^2+x^2)} \quad (n\neq 1)$

### 21.7.4.5 反双曲函数积分（512–515）

- 512. $\int\operatorname{Arsinh}\frac{x}{a}dx = x\operatorname{Arsinh}\frac{x}{a} - \sqrt{x^2+a^2}$
- 513. $\int\operatorname{Arcosh}\frac{x}{a}dx = x\operatorname{Arcosh}\frac{x}{a} - \sqrt{x^2-a^2}$
- 514（推定，脱号）. $\int\operatorname{Artanh}\frac{x}{a}dx = x\operatorname{Artanh}\frac{x}{a} + \frac{a}{2}\ln(a^2-x^2)$
- 515. $\int\operatorname{Arcoth}\frac{x}{a}dx = x\operatorname{Arcoth}\frac{x}{a} + \frac{a}{2}\ln(x^2-a^2)$
