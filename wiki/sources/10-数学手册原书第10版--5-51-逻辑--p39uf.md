# 数学手册(原书第10版) 5.1 逻辑

## 概述

本源为《数学手册(原书第10版)》第 5 章首节「5.1 逻辑」，含两个子节：**5.1.1 命题演算** 与 **5.1.2 谓词演算公式**。这是第 5 章首个入库小节，也是本 wiki 第一批逻辑学页面的来源。全节为数学中的推理（间接证明的形式化、量词的使用）提供逻辑基础，并多处交叉引用未入库的 5.7 布尔代数与 5.9.1 多值与模糊逻辑。

本页延续本书逐节摄入链，此前已入库 [[sources/10-数学手册原书第10版--8-362-空间曲线--efa6tv]]、[[sources/10-数学手册原书第10版--6-363-曲面--vqder3]]、[[sources/10-数学手册原书第10版--5-41-矩阵--1kmyh8y]]、[[sources/10-数学手册原书第10版--6-42-行列式--1vrx79f]]、[[sources/10-数学手册原书第10版--5-43-张量--165q8ul]]、[[sources/10-数学手册原书第10版--9-44-四元数及应用--1oshpaj]] 等节。

## 内容结构

**5.1.1 命题演算**：命题（二值性原理）→ 命题联结词（式 5.1–5.5）→ 真值表（表 5.1）→ 公式的归纳定义与优先规则（式 5.6–5.7）→ 真值函数（计数 2^(2^n)）→ 基本定律（式 5.8–5.18）→ NAND/NOR 函数（表 5.2、5.3）→ 重言式与数学推理（式 5.19–5.20）。

**5.1.2 谓词演算公式**：谓词 → 量词 → 公式（式 5.21–5.22，命题演算可嵌入）→ 自由/约束变元与闭公式 → 解释 → 逻辑有效公式（式 5.23–5.33）→ 约束谓词/受限量词（式 5.34–5.35）。

## 主要论点与强度评估

1. 五种联结词由真值表定义（表 5.1）——定义性内容，表值经核验无误，强度高。
2. 公式归纳定义与优先规则——定义性内容，强度高；但 (5.7) 转写中 ⇒、⇔ 符号脱落。
3. n 位真值函数共 2^(2^n) 个、二元者恰 16 个——标准计数结果，强度高（转写中两处「n」脱落）。
4. 化简例 A∨B̄ ⇒ AB∨C = B∨C（与 A 无关）——8 行真值表与化简链双重证据，本 wiki 已独立复算成立，强度高。
5. 基本定律组（式 5.8–5.18）——可经真值表或代数推导验证；已复算 5.18c/d（共识律）成立，强度高。
6. 蕴涵与等价可消去（5.17）；{¬,∨} 与 {¬,∧} 函数完备；谢费尔函数（NAND）与皮尔斯函数（NOR）各自单独完备——标准结果，强度高；原书对 NAND/NOR 的单独完备性只作陈述，未给出如 ¬A = A|A 之类的构造证明。
7. 换位律（5.19）与间接证明三形式（5.20a–c）均等价于 A⇒B——三式均已独立复算成立，强度高。
8. 命题演算可嵌入谓词演算（命题变量 = 零位谓词）——结构性主张，强度高。
9. 量词否定律（5.23–5.24）；同类量词可交换（5.25–5.26）；∧/∨ 对 ∀/∃ 的分配等价（5.27–5.28）；五条单向蕴涵（5.29–5.33）且逆不成立、∀ 与 ∃ 不可交换——标准结果，语义论证，强度高。
10. 受限量词简写（5.34–5.35）：5.34 正确；5.35 之 ⇒ 与标准语义矛盾（疑应为 ∧），见 [[queries/式5-35受限存在量词是否应为合取]]。

## 结构化数据（verbatim 保存）

**表 5.1 命题演算的真值表**（按 A、B 取值重排；原表按否定/合取/析取/蕴涵/等价分栏）：

| A | B | ¬A | A∧B | A∨B | A⇒B | A⇔B |
|---|---|----|-----|-----|-----|-----|
| F | F | T  | F   | F   | T   | T   |
| F | T | T  | F   | T   | T   | F   |
| T | F | F  | F   | T   | F   | F   |
| T | T | F  | T   | T   | T   | T   |

**表 5.2 NAND（谢费尔）函数**（转写标题误作「NANO 函数」）：

| A | B | A\|B |
|---|---|-----|
| F | F | T |
| F | T | T |
| T | F | T |
| T | T | F |

**表 5.3 NOR（皮尔斯）函数**：

| A | B | A↓B |
|---|---|-----|
| F | F | T |
| F | T | F |
| T | F | F |
| T | T | F |

**命题演算基本定律（式 5.8–5.18）**，依原书简写记法（Ā 代 ¬A、AB 代 A∧B）：

```latex
% (1) 结合律
(A B) C = A (B C),   (A ∨ B) ∨ C = A ∨ (B ∨ C)          % (5.8a/b)
% (2) 交换律
A B = B A,   A ∨ B = B ∨ A                              % (5.9a/b)
% (3) 分配律
(A ∨ B) C = A C ∨ B C,   A B ∨ C = (A ∨ C)(B ∨ C)       % (5.10a/b)
% (4) 吸收律
A (A ∨ B) = A,   A ∨ A B = A                            % (5.11a/b)
% (5) 幂等律（原书作「幕等性律」，幕为幂之讹）
A A = A,   A ∨ A = A                                     % (5.12a/b)
% (6) 排中律（原书标题如此；5.13a 通常称矛盾律）
A Ā = F,   A ∨ Ā = T                                     % (5.13a/b)
% (7) 德摩根法则
¬(A B) = Ā ∨ B̄,   ¬(A ∨ B) = Ā B̄                        % (5.14a/b)
% (8) 关于 T/F 的定律（原书标题中 T/F 脱落，作「对于 的定律」）
A T = A,  A ∨ F = A,  A F = F,  A ∨ T = T,  T̄ = F,  F̄ = T  % (5.15a–f)
% (9) 双重否定
Ā̄ = A                                                    % (5.16)
% 蕴涵与等价的消去
A ⇒ B = Ā ∨ B,   A ⇔ B = A B ∨ Ā B̄                       % (5.17a/b)
% (10) 其他变换（5.18c/d 即共识律，原书未命名）
A (Ā ∨ B) = A B,   A ∨ Ā B = A ∨ B                       % (5.18a/b)
(A ∨ C)(B ∨ C̄)(A ∨ B) = (A ∨ C)(B ∨ C̄)                   % (5.18c)
A C ∨ B C̄ ∨ A B = A C ∨ B C̄                              % (5.18d)
```

**推理定律（式 5.19–5.20）**：

```latex
A ⇒ B ⇔ B̄ ⇒ Ā,   A ⇒ B = B̄ ⇒ Ā                          % (5.19a/b)
A ⇒ B = A B̄ ⇒ Ā,   A ⇒ B = A B̄ ⇒ B,   A ⇒ B = A B̄ ⇒ F   % (5.20a/b/c)
```

**谓词演算公式组（式 5.21–5.35）**：

```latex
P(x₁,…,xₙ) 是公式（基本公式）                                % (5.21)
(¬A), (A∧B), (A∨B), (A⇒B), (A⇔B), (∀x A), (∃x A) 均为公式    % (5.22)
¬∀x P(x) = ∃x ¬P(x),   ¬∃x P(x) = ∀x ¬P(x)               % (5.23)
∀x P(x) = ¬∃x ¬P(x),   ∃x P(x) = ¬∀x ¬P(x)               % (5.24)
∀x∀y P(x,y) = ∀y∀x P(x,y),   ∃x∃y P(x,y) = ∃y∃x P(x,y)   % (5.25/5.26)
∀x P(x) ∧ ∀x Q(x) = ∀x(P(x) ∧ Q(x))                     % (5.27)
∃x P(x) ∨ ∃x Q(x) = ∃x(P(x) ∨ Q(x))                      % (5.28)
∀x P(x) ∨ ∀x Q(x) ⇒ ∀x(P(x) ∨ Q(x))                     % (5.29, 单向)
∃x(P(x) ∧ Q(x)) ⇒ ∃x P(x) ∧ ∃x Q(x)                      % (5.30, 单向)
∀x(P(x) ⇒ Q(x)) ⇒ (∀x P(x) ⇒ ∀x Q(x))                    % (5.31, 单向)
∀x(P(x) ⇔ Q(x)) ⇒ (∀x P(x) ⇔ ∀x Q(x))                    % (5.32, 单向)
∃x∀y P(x,y) ⇒ ∀y∃x P(x,y)                                % (5.33, 单向, 逆为假)
∀x∈X P(x) ≜ ∀x(x∈X ⇒ P(x))                               % (5.34)
∃x∈X P(x) ≜ ∃x(x∈X ⇒ P(x))   % (5.35) — 转写如此, 疑应为 x∈X ∧ P(x)
```

## 转写讹误与疑点

本节转写质量低于已入库的第 4 章各节（公式内符号脱落密度更高）。系统性讹误包括「千/于」（取决千、对千、用千、基千、对应千）、「旬/句」（语旬、一个旬子）、成片符号脱落（n、T/F、且/或/则、⇒/⇔、命题字母 A/B）、乱码（勹、日、\/）与页码节号粘连（「第 5285.7」「第554 5.9.1」「第 4445.2.3」）。这印证了既有 query [[queries/4-1节千于共扼与符号成片脱落是否为系统性转写丢字]] 与 [[queries/4-3全节系统性转写讹误]] 的系统性丢字判断。完整清单见 [[queries/5-1全节转写讹误清单]]。

实质性疑点：
- 式 (5.35) 之 ⇒ 疑应为 ∧（[[queries/式5-35受限存在量词是否应为合取]]）
- 式 (5.13a) 标题「排中律」通常应作「矛盾律」（[[queries/式5-13a应称矛盾律还是排中律]]）
- 化简链首项否定号脱落与 B̄/B 前后不一（[[queries/化简推导链转写讹误]]）
