# 数学手册(原书第10版) 19.2 方程组的数值解

## 概述

本节是《数学手册(原书第10版)》第 19 章数值分析中关于方程组数值解的总纲。开篇以方程个数 m 与未知量个数 n 的关系把一般方程组（19.23）分为超定（m>n）、通常（m=n）与不定（m<n）三类，随后按“线性（19.2.1）/非线性（19.2.2）”两线展开：线性部分依次为矩阵的三角分解（高斯消元法、LU 因子分解、主元选取）、对称正定系数矩阵的楚列斯基方法、超定系统的正交化方法（线性最小二乘、正规方程、QR 分解）与迭代方法（雅可比、高斯—塞德尔、松弛法/SOR）；非线性部分为不动点形式的一般迭代法、牛顿法与无导数高斯—牛顿法。本源首次将维基的采集范围从第 18 章优化扩展到数值代数。

## 核心主张（逐条归属主体）

1. **方程组分类**（19.23–19.24，属 [[concepts/超定方程组与不定方程组]]）：超定方程组通常可能没有解，于是在欧几里得空间中用最小二乘法求“最优”解 $\sum F_i^2=\min!$；不定方程组的解依赖 n−m 个参数，称 n−m 维流形解。
2. **直接法/迭代法二分**（19.2.1 开头）：直接法基于元素变换据此直接得到解；迭代法从初始近似值出发构造收敛序列，见 [[comparisons/直接法与迭代法比较]]。
3. **LU 分解定理**（19.31，属 [[concepts/三角分解与LU因子分解]]）：对每个（原文作“正规”，疑为“正则/非奇异”之讹，见 [[queries/正规矩阵疑为正则矩阵之辨]]）矩阵存在 PA=LR；对同系数矩阵、不同右端项的多个方程组尤为适用。
4. **主元选取**（19.33，属 [[concepts/主元选取]]）：列主元策略可证使累积舍入误差更小；另有对角策略。
5. **楚列斯基方法**（19.34–19.36，属 [[concepts/楚列斯基分解]]）：对称正定矩阵存在唯一 A=LLᵀ 分解；n 较大时计算量约为 LU 分解的一半——此论断仅属楚列斯基方法。
6. **正规方程与正交化方法之别**（19.42–19.47）：条件数困难**仅属于正规方程路线**（AᵀA 条件数过大时解的相对误差大，条件数见外引 [19.31]），故本源建议改用正交化方法；线性最小二乘实际问题多数用豪斯霍尔德变换求解，通常利用系数矩阵的带状结构，见 [[comparisons/正规方程法与正交化方法比较]]。
7. **迭代法收敛性**（19.48–19.54）：雅可比方法在列和（19.49）或行和（19.50）判据下对任意初值收敛（充分条件）；高斯—塞德尔方法“通常”更快但判据更复杂；松弛法仅当 0<ω<2 收敛（必要性表述），ω=1 退回高斯—塞德尔，ω>1 为 SOR。
8. **牛顿法（方程组）**（19.61–19.64，属 [[concepts/牛顿法（方程组）]]）：雅可比矩阵在解邻域可逆 ⇒ 局部平方收敛，收敛依赖初值；阻尼参数 γ>0（19.64）降低初值依赖，γ 的确定见外引 [19.31]。
9. **高斯—牛顿法**（19.65–19.68，属 [[concepts/高斯—牛顿法]]）：线性化后解线性最小二乘确定校正项，可加步长 γ；偏导数可用向前差商（19.68）近似使方法与导数无关；收敛性依赖初值准确性。

## 算例一：高斯消元 / LU 分解（19.2.1.1，按原样转录）

```
方程组：[[3,1,6],[2,1,3],[1,1,1]]·x = (2,7,4)ᵀ

第一步（消去第 1 列，乘数 l₂₁=2/3、l₃₁=1/3 就地存储于下三角位置；主元加框）：
[  3     1     6  |  2   ]
[ 2/3   1/3   −1  | 17/3 ]
[ 1/3   2/3   −1  | 10/3 ]

第二步（交换第 2、3 行取列主元 2/3，再以 l₃₂=1/2 消元）：
[  3     1      6   |  2   ]
[ 1/3   2/3   −1    | 10/3 ]
[ 2/3   1/2   −1/2  |  4   ]

P = [[1,0,0],[0,0,1],[0,1,0]]
L = [[1,0,0],[1/3,1,0],[2/3,1/2,1]]
R = [[3,1,6],[0,2/3,−1],[0,0,−1/2]]
解：x₁=19, x₂=−7, x₃=−8
```

复算结论：P、L、R 及解**全部正确**（LR 逐行乘回恰为 PA；回代得 (19,−7,−8)；代入原方程三行分别为 2、7、4），详见 [[findings/高斯消元3乘3算例LU分解复算]]。

## 算例二：高斯—塞德尔迭代（19.2.1.4，按原样转录）

```
10x₁−3x₂−4x₃+2x₄=14；−3x₁+26x₂+5x₃−x₄=22；
−4x₁+5x₂+16x₃+5x₄=17；2x₁+3x₂−4x₃−12x₄=−20
精确解 x=(1.5, 1, 0.5, 2)

x₁⁽μ⁺¹⁾=(1/10)(14+3x₂⁽μ⁾+4x₃⁽μ⁾−2x₄⁽μ⁾)
x₂⁽μ⁺¹⁾=(1/26)(22+3x₁⁽μ⁺¹⁾−5x₃⁽μ⁾+x₄⁽μ⁾)
x₃⁽μ⁺¹⁾=(1/16)(17+4x₁⁽μ⁺¹⁾−5x₂⁽μ⁺¹⁾−5x₄⁽μ⁾)
x₄⁽μ⁺¹⁾=(1/12)(−20+2x₁⁽μ⁺¹⁾+3x₂⁽μ⁺¹⁾−4x₃⁽μ⁺¹⁾)   ← 常数项按表格内证应为 +20
```

| | x⁽⁰⁾ | x⁽¹⁾ | x⁽⁴⁾ | x⁽⁵⁾ | x |
|---|---|---|---|---|---|
| x₁ | 0 | 1.4 | 1.5053 | 1.5012 | 1.5 |
| x₂ | 0 | 1.0077 | 0.9946 | 0.9989 | 1 |
| x₃ | 0 | 1.0976 | 0.5059 | 0.5014 | 0.5 |
| x₄ | 0 | 1.7861 | 1.9976 | 1.9995 | 2 |

复算结论：迭代表 x⁽¹⁾、x⁽⁴⁾、x⁽⁵⁾ 逐分量全部吻合（至 4 位小数）；系数矩阵行、列均严格对角占优，同时满足 (19.49)(19.50)。但 x₄ 迭代式常数项印作 −20，按 +20 计算方与表格吻合（转写符号讹误，表格为内证），详见 [[findings/高斯—塞德尔4乘4算例迭代复算]] 与 [[queries/高斯塞德尔算例x4式负20疑为正20之辨]]。
