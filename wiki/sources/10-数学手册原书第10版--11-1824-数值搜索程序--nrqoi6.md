# 数学手册(原书第10版) 18.2.4 数值搜索程序

## 小节定位

本小节隶属于 [[sources/10-数学手册原书第10版--11-182-非线性优化问题--1gv38ye|18.2 非线性优化问题]]，是已入库范围内该系列的首个数值算法小节：在 [[sources/10-数学手册原书第10版--14-1821-问题的提法理论基础--16xlwe7|18.2.1 问题的提法、理论基础]]（KT 条件、对偶理论）之后，补全 [[concepts/非线性优化]] 的计算侧面。

小节开篇的总纲性论断（原句有转写讹误，此为校订后大意）：使用非线性优化程序可以找到能接受的近似解，其依据是**基于函数值比较的原理**——即本节全部方法均为无导数方法。

小节结构：

- **18.2.4.1 一维搜索**：问题提法（[[concepts/单峰函数]]；寻找含全局极小点 x\* 且长度小于 ε 的子区间 [c, d]）、一致搜索（式 18.67）、黄金分割法与斐波那契法（式 18.68–18.70）。
- **18.2.4.2 n 维欧几里得向量空间中的极小搜索**：将 ℝⁿ 上的**无约束**问题 f(x) = min! 化为逐坐标的一列一维子问题（式 18.71a–c），即 [[concepts/坐标下降法]]；源文未使用该通用名称。

## 结构化转录（式 18.67–18.71）

以下按源文原样转录（明显的转写讹误已按上下文校订，逐条讹误见 [[queries/18-2-4全节系统性转写讹误清单]]）：

```text
(18.67)  n > 2(b−a)/ε − 1

(18.68a) λ₁ = a₁ + (1−τ)(b₁−a₁),   μ₁ = a₁ + τ(b₁−a₁)
(18.68b) τ = ½(√5−1) ≈ 0.618

(18.69a) f(λ₁) < f(μ₁)  ⇒  a₂ = a₁, b₂ = μ₁, μ₂ = λ₁
(18.69b) f(λ₁) ⩾ f(μ₁)  ⇒  a₂ = λ₁, b₂ = b₁, λ₂ = μ₁

(18.70)  ε > bₙ − aₙ = τⁿ⁻¹(b₁ − a₁)

(18.71a) x = x¹,  k = 1   （x¹ 为 x* 的适当初始近似）
(18.71b) φ(α_r) = f(x₁^{k+1}, …, x_{r−1}^{k+1}, x_r^k + α_r, x_{r+1}^k, …, x_n^k) = min!,  α_r ∈ ℝ
         ᾱ_r 为第 r 个一维问题的（精确或近似）极小点 ⇒ x_r^{k+1} = x_r^k + ᾱ_r
(18.71c) ‖x^{k+1} − x^k‖ < ε₁   或   |f(x^{k+1}) − f(x^k)| < ε₂
```

源文对式 18.71 的补充说明：若 18.71c 不满足，则以 k+1 代替 k 重复步骤 b)；b) 中的一维问题可用 18.2.4.1 给出的方法求解。

## 主要论断（按归属）

1. **一维搜索子问题框架**（关于 18.2.4.1 问题提法）：对 [a, b] 上单峰的 f，通常只需找到子区间 [c, d] ⊆ [a, b]，使 x\* ∈ [c, d] 且 d − c < ε。
2. **一致搜索估计**（仅关于 [[concepts/一致搜索]]，式 18.67）：所需格点数 n > 2(b−a)/ε − 1。复算见 [[findings/式18-67一致搜索函数值数目估计复算]]。
3. **黄金分割法性质**（式 18.68–18.70，仅关于 [[concepts/黄金分割法]]）：区间每步按因子 τ = ½(√5−1) ≈ 0.618 缩短；确定 [aₙ, bₙ] 共需 n 次函数值。复算见 [[findings/式18-68至18-70黄金分割区间套缩复算]]。
4. **黄金分割与斐波那契比较**（同时约束 [[concepts/黄金分割法]] 与 [[concepts/斐波那契法]]，**不得外推至一致搜索**）：使用黄金分割法与斐波那契法相比，至多多一个函数值要确定。此为手册引述的标准结果，源文未给推导。
5. **坐标下降格式**（仅关于 [[concepts/坐标下降法]]，式 18.71a–c）：ℝⁿ 极小搜索化为逐坐标一维问题，子问题用 18.2.4.1 的方法求解；停机准则为向量范数差或函数值差。源文**无任何收敛性论断**，停机为启发式。转录见 [[findings/式18-71a至c坐标下降迭代格式与停机准则转录]]。

## 内部矛盾：情形 a)/b) 已知函数值对调

紧随式 18.69 的正文称，从第 2 步起已知的函数值「在情形 a) 下是 f(λ₂)，而在情形 b) 下是 f(μ₂)」，这与式 18.69 **对调**：按 18.69a（μ₂ = λ₁），情形 a) 的已知值为 f(μ₂)；按 18.69b（λ₂ = μ₁），情形 b) 的已知值为 f(λ₂)。疑为原文或转写讹误，详见 [[queries/黄金分割已知函数值情形ab对调之辨]]。

## 范围限定（caveat）

18.2.4.2 处理的是**无约束**问题 f(x) = min!、x ∈ ℝⁿ，本节未交代约束处理（约束情形见 18.2.1 的 KT 理论，[[concepts/库恩—塔克条件]]）。区间套缩的一切保证均以单峰性为前提；坐标下降无收敛论断。将这些保证外推到其他方法、非单峰目标或约束问题，即属论断越界。
