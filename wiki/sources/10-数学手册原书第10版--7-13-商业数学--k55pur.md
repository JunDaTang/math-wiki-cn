# 数学手册(原书第10版) 1.3 商业数学

本源为《数学手册(原书第10版)》第 1 章第 3 节"商业数学"，主题是利息与百分率、复利、分期付款、年金与折旧的实用计算。手册指出：商业数学的计算基础是[[等差级数]]与[[等比级数]]的公式 (1.52a)–(1.52c)、(1.54a)–(1.54d)（见 [[有限级数]] 一节），但这些知识应用于银行业后变化很大且需要专业化，从而形成使用专门术语的专业学科。

## 学科定位与范围

- 涵盖：利息、百分率、复利、还款、偿还金、分期付款、年金、实际利率、投资年收益率的计算。
- 出界声明：保险数学和风险论运用概率论与数理统计方法，代表独立学科，本节不予讨论（原文附引用 [1.3]、[1.4]）。
- 手册建议欲细致研究金融数学须查阅专门文献（附引用 [1.2]、[1.9]）；本节未给出这些文献的书目信息，具体条目待查手册文献表。

## 公式体系（保留原文式号）

| 式号 | 公式 | 含义 |
|---|---|---|
| (1.70) | $p\% = \frac{p}{100}$ | 百分率定义 |
| (1.71) | $\widetilde{K} = K\left(1+\frac{p}{100}\right)$ | 增加 p% 后的新值 |
| (1.72) | $\tilde{p} = \frac{100p}{100+p}$ | 增量在新值中的含量 |
| (1.73) | $\widetilde{K} = K\left(1-\frac{p}{100}\right)$ | 降价 p% 后的折后价 |
| (1.74) | $\tilde{p} = \frac{100p}{100-p}$ | 折扣在新值中的含量 |
| (1.75) | 利息 $= K\frac{p}{100}$ | 单利息周期的利息 |
| (1.76) | $K_n = K\left(1+\frac{p}{100}\right)^n$ | 年复利终值 |
| (1.77) | $K_{m\cdot n} = K\left(1+\frac{p}{100m}\right)^{m\cdot n}$ | 年内分 m 周期的复利 |
| (1.78a) | $K_n = Eq\,\frac{q^n-1}{q-1}$ | 定期储蓄（期初存入） |
| (1.78b) | $K_n = E\,\frac{q^n-1}{q-1}$ | 定期储蓄（期末存入） |
| (1.79a) | $K_1 = E\left[m+\frac{(m+1)p}{200}\right]$ | 年内储蓄一年（期初） |
| (1.79b) | $K_1 = E\left[m+\frac{(m-1)p}{200}\right]$ | 年内储蓄一年（期末） |
| (1.80a) | $K_n = E\left[m+\frac{(m+1)p}{200}\right]\frac{q^n-1}{q-1}$ | 年内储蓄 n 年（期初） |
| (1.80b) | $K_n = E\left[m+\frac{(m-1)p}{200}\right]\frac{q^n-1}{q-1}$ | 年内储蓄 n 年（期末） |
| (1.81a) | $Z_n = \frac{pS}{100}\left[1-\frac{1}{N}\left(n-\frac{m+1}{2m}\right)\right]$ | 等额本金第 n 年利息 |
| (1.81b) | $Z = \frac{pS}{100}\left[\frac{N-1}{2}+\frac{m+1}{2m}\right]$ | 等额本金总利息闭式 |
| (1.82) | $S_n = Sq^n - a\left[m+\frac{(m-1)p}{200}\right]\frac{q^n-1}{q-1}$ | 等额年金剩余债务 |
| (1.83) | $A = a\left[m+\frac{(m-1)p}{200}\right]$（$A \geqslant ma$） | 年金与分期额的关系 |
| (1.84) | $A = Sq^N\frac{q-1}{q^N-1} = S\frac{q-1}{1-q^{-N}}$ | 等额年金公式（知三求一） |
| (1.85) | $R_n = R\,\frac{q^n-1}{q-1}$ | 普通年金终值 |
| (1.86) | $R_0 = \frac{R_n}{q^n}$ | 普通年金现值 |
| (1.87a) | $K_n = Kq^n - r\,\frac{q^n-1}{q-1}$ | n 次支付后的余额 |
| (1.87b) | $r = K\frac{p}{100} \Rightarrow K_n = K$ | 永久年金临界条件 |
| (1.87c) | $r > K\frac{p}{100}$ | 资金将于 N 期耗尽 |
| (1.87d) | $K = \frac{r}{q^N}\cdot\frac{q^N-1}{q-1}$ | 资金耗尽期限反解 |
| (1.88) | $a_n = \frac{A-R_N}{N} = a$ | 直线折旧年折旧额 |
| (1.89) | $R_n = A - n\,\frac{A-R_N}{N}$ | 直线折旧残值 |
| (1.90) | $a_n = a_1-(n-1)d$ | 算术递减折旧额 |
| (1.91) | $d = \frac{2[Na_1-(A-R_N)]}{N(N-1)}$ | 递减差额 d |
| (1.92) | $a_1 > \frac{A-R_N}{N} = a$ | d>0 的必要条件 |
| (1.93) | $\frac{A-R_N}{N} < a_1 < 2\frac{A-R_N}{N}$ | $a_1$ 的容许区间 |
| (1.94a) | $d = \frac{2(A-R_N)}{N(N+1)}$ | 数字递减的 d |
| (1.94b) | $a_1 = Nd,\ a_2 = (N-1)d,\ \ldots,\ a_N = d$ | 数字递减折旧额序列 |
| (1.95) | $R_n = A\left(1-\frac{p}{100}\right)^n$ | 几何递减残值 |
| (1.96) | $m > N - \frac{100}{p}$ | 几何转直线的时机 |

其中累积因子 $q = 1 + \frac{p}{100}$ 贯穿 1.3.2–1.3.4 的全部公式。结构性观察（分析推断，非手册原文）：$\frac{q^n-1}{q-1}$（[[等比级数]]部分和）是 (1.78)–(1.87) 全部复利类公式的公共骨架，详见 [[等比级数部分和贯穿商业数学公式体系]]。

## 中期计息的普代规则（原文）

> 若计算中期利息，且支付中期租金，最初的利息周期被分成 m 个等间隔，则在公式 (1.85)–(1.87a) 中，n 被 mn 代替，相应地，q = 1+p/100 被 q = 1+p/(100m) 代替。

## 算例一览（分析已独立复算核对，数值一致）

- 百分率：€200 加 15% 附加费 → €230，增量含量 13.04%；€300 打 10% 折扣 → €270，折扣含量 11.11%。
- 复利：€5000、名义年利率 7.2%、6 年 → 年复利 €7588.20、月复利 €7691.54。
- 定期储蓄：每月末存 €1000、年利率 5.2%，攒至 €500000 需 n = 22.42 年。
- 等额本金：债务 €60000、8%、60 个月（月还本金 €1000），各年利息 €4360/€3400/€2440/€1480/€520，总利息 €12200。
- 等额年金：€60000、8%、5 年 → A = €15027.39、a = €1207.99；例 B（€100000、7.5%、8 年、年末额外还款 €5000）→ a = €972.62。
- 年金现值：每年末 €5000、10 年、4% → R₀ = €40554.48。
- 月度年金：月利率 0.5%、240 期、每期收付 €2000 → 所需资金 K = €279161.54，对应月储蓄 R = €604.19（恰等于 2000/1.005²⁴⁰）。
- 几何折旧：€50000 按 10% 年率 → N = ln(10000/50000)/ln(0.9) = 15.27 年首次跌破 €10000。
- 混合折旧：15 年折旧至 0、前段按残值 14% 几何递减 → 由 (1.96) 得 m > 15 − 100/14 ≈ 7.86（原文作 7.76），故 m = 8 年后转直线。

## 勘误候选与翻译问题

1. 名义利率称谓：1.3.2.2 称 1+p/100 为"名义利率"、(1+p/(100m))^m 为"实利率"，与通行定义冲突，且与同节"q 为累积因子"的称谓自相矛盾，疑为翻译脱漏（详见 [[手册1.3名义利率称谓疑为翻译脱漏]]、[[手册1.3名义利率与实利率定义是否为翻译错误]]）。
2. 式 (1.96) 示例算术：15 − 100/14 = 7.857…，原文作 7.76，应为 ≈7.86；结论 m = 8 不受影响（详见 [[式1.96示例7.76应为约7.86]]、[[式1.96示例数值是否排印错误]]）。
3. 永久年金条件：1.3.4.1 中文表述"若支付的实际利息不超过租金"疑倒置，按 (1.87b)/(1.87c) 应为租金不超过利息（详见 [[永久年金定义条件表述疑倒置]]、[[永久年金定义条件是否倒置]]）。
4. 数字递减表取整：d = 2666.67 取整为 2667，五年残值 €9995 ≠ 设定的 €10000（详见 [[数字递减折旧表取整致残值偏离设定]]）。
5. 直线法表列名口径：列名"对折旧基数的累积折旧率"下的数值实为当期折旧额 ÷ 当期期初残值，并非累积口径（详见 [[直线折旧表累积折旧率列的口径是什么]]）。

## 排印瑕疵（不影响数学内容）

- 货币符号 € 多处误排为 ε（如 Z₂ = ε3400、S = ε100000）。
- (1.77) 处"经过 m 个利息周期"应为"经过 m·n 个利息周期"。
- (1.94b) "a_1 = N d a_2 = (N−1)d" 缺分隔符，应为 a₁ = Nd, a₂ = (N−1)d, …, a_N = d。
- 1.3.4.1 中"租金"（德语 Rente 的译文）兼指"分期付款"与"收款"两种资金流向，与日常语义的"租金"不同，阅读时须按上下文区分。
