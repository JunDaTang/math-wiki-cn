# 数学手册(原书第10版) 21.7.1 有理函数积分

## 概述

本源为 [[entities/数学手册(原书第10版)]] 21.7 节（积分表）的首个小节「有理函数积分」，属公式表文本而非论证性文本：按分母结构分七个小节，给出编号 1–108 的积分公式（式 29 缺位，实存 107 条；另有 36 条在转写中脱去编号，依位置与回指可全部推断）。全节已用 [[methodology/原函数逐项微分复算法]] 逐项复算：除式 102 系数一处实质数学讹误、式 107 系数脱漏无法核验外，其余全部相符（[[findings/21-7-1有理函数积分全表微分复算]]）。本页汇录小节结构、盒注与关键讹误条目原文、记号体系、复算结论、回指清单与转写疑点总览；细节分流至各概念、发现与辨正页。

## 盒注原文（逐字转录）

21.7.1.1：

```latex
\boxed {\text {注} X = a x + b}
```

21.7.1.1 末（两线性因子之积）：

```latex
\left| \text {注} \quad \Delta = b f - a g \right|
```

21.7.1.2：

```latex
\boxed {\text {注} \quad X = a x ^ {2} + b x + c; \Delta = 4 a c - b ^ {2}}
```

21.7.1.3（$Y$ 的定义注文，碎裂状态逐字录）：

```latex
X = a ^ {2} \pm x ^ {2},
\arctan \frac {x}{a}
^ {\prime \prime} + ^ {\prime \prime}
| x | > a
X = a ^ {2} + x ^ {2}
X = a ^ {2} - x ^ {2}, a > 0
```

21.7.1.4 注：

> 注 $a ^ {2} \pm x ^ {3} = X$ ；公式中的上下两个符号，分别指 $X = a ^ {3} + x ^ {3} , X = a ^ {3} - x ^ {3} .$

21.7.1.5 标题：`21. 7.1.5 $X = a ^ {2} + x ^ {2}$ 的积分`；21.7.1.6 标题：`21. 7.1.6 $X = a ^ {2} - x ^ {4 }$ 的积分（或 $X = a ^ {4 } - x ^ {4 }$ 型积分）`。

## 关键讹误条目（逐字转录）

式 102（全节唯一微分复算不符处）：

```latex
102. \int \frac {x \mathrm{d} x}{a ^ {4} - x ^ {4}} = \frac {1}{4 a ^ {3}} \ln \frac {a ^ {2} + x ^ {2}} {a ^ {2} - x ^ {2}}
```

式 30 及其通项替代规则（注文语序混乱，规则本身经核验正确）：

```latex
\text {30.} \int \frac {\mathrm {d} x}{x ^ {m} X ^ {n}} = - \frac {1}{b ^ {m + n - 1}} \sum_ {i = 0} ^ {m + n - 2} \binom {m + n - 2} {i} \frac {X ^ {m - i - 1} (- a) ^ {i}}{(m - i - 1) x ^ {m - i - 1}}.
若求和后面中的通项中分母为 0, 则这些项由 \binom {m + n - 2} {m - 1} (- a) ^ {m - 1} \ln \frac {X} {x} 代替．
```

式 107（$C$、$D$ 脱漏处）：

```latex
{\frac {1}{(x + a) (x + b) (x + c) (x + d)}} \equiv {\frac {A}{x + a}} + {\frac {B}{x + b}} + {\frac {C}{x + c}} + {\frac {D}{x + d}},
A = \frac {1}{(b - a) (c - a) (d - a)}, B = \frac {1}{(a - b) (c - b) (d - b)}
```

## 记号体系

- $X$：各小节内固定的分母多项式，逐节重定义（$ax+b$ → $ax^2+bx+c$ → $a^2\pm x^2$ → $a^3\pm x^3$ → $a^4\pm x^4$）。
- $\Delta$：**一名两义**。21.7.1.1 末定义为 $bf-ag$（两线性因子 $(ax+b)(fx+g)$ 的结式型量）；21.7.1.2 即重定义为 $4ac-b^2$（二次式判别量，控制式 40 三分支）。各自自洽但记号复用是使用陷阱，详见 [[comparisons/两类Δ判别量定义比较]]。
- $Y$：21.7.1.3 的辅助函数。$X=a^2+x^2$ 时 $Y=\arctan(x/a)$；$X=a^2-x^2$ 时为 Artanh/对数形式（依式 57 反推；注文原文碎裂，见 [[queries/21-7-1-3之Y定义注文脱漏之辨]]）。
- 上下符号约定：21.7.1.3、21.7.1.4 注文明示公式中上下两个符号（±/∓ 联动）分别指 $+$ 型与 $-$ 型。
- 式 31–34 用系数式 $(ax+b)(fx+g)$，式 35–39 突改为位移式 $(a+x)(b+x)^2$，$a,b$ 语义由系数变为根的平移；系原书体例而非转写之误，引用时须注意。

## 复算结论摘要

[[findings/21-7-1有理函数积分全表微分复算]]：以右端逐项求导还原被积函数之法复算全节——式 1–39、40–56、57–82、83–96 全部相符；式 97–101、103、104 相符；式 105、106、108 恒等式核验相符；式 107 因 $C$、$D$ 脱漏无法核验；**式 102 不符**。

[[findings/公式102系数与微分复算不符]]：微分复算、量纲分析与式 101–104 降幂格局三重证据表明系数应为 $\frac{1}{4a^2}$ 而非 $\frac{1}{4a^3}$；式 101、103、104 已独立复算确认无误，不应连带质疑。

[[findings/通用积分公式特化一致性与式28适用域复算]]：式 21、25、30 的特化一致；式 28（$n\geqslant3$）不能特化到式 27，说明其适用域为实质限定。
