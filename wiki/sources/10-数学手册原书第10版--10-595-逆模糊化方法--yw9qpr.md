# 数学手册(原书第10版) 5.9.5 逆模糊化方法

## 概述

本节是《数学手册(原书第10版)》5.9「模糊逻辑」章的一个小节，主题为**逆模糊化**：由（推理所得的）模糊集——即输出隶属函数 $\mu^{\text{输出}}_{x_1,\dots,x_n}$——得到单一清晰值 $\eta \in Y$ 的过程。它是模糊推理管线的收尾步骤：上游为 [[concepts/模糊逻辑推理]] 与 [[methodology/if-then模糊推理的复合计算流程]]（5.9.3 的 IF–THEN 推理产出 $\mu^{\text{输出}}$），本节将其压缩为一个数。

本节以列举方式给出 **8 种逆模糊化方法**，其中 7 种附公式（式 5.382–5.388），方法 8（LA）无公式。全节无算例、无证明、无方法间比较，属定义性内容。转写质量与本章前几节同样较差，存在系统性 OCR 讹误与一处数学性矛盾（见下文）。

## 公式逐字转录

以下按源文件原样转录（保留 OCR 讹误），供核对原书：

```latex
(5.382)  sup(μ^{输出}_{x₁,…,xₙ}) := { y ∈ Y | μ_{x₁,…,xₙ}(y) ⩾ μ_{x₁,…,xₙ}(y*), ∀y* ∈ Y }

(5.383)  η_MOM = [ ∫_{y ∈ sup(μ^{输出}_{x₁,…,xₙ})} y dy ] / [ ∫_{y ∈ sup(μ^{输出}_{x₁,…,xₙ})} dy ]

(5.384)  η_COG = [ ∫_{y_inf}^{y_sup} μ(y)·y dy ] / [ ∫_{y_inf}^{y_sup} μ(y) dy ]

(5.385)  η_PCOG = [ ∫_{y_inf}^{y_sup} μ(y)^γ·y dy ] / [ ∫_{y_inf}^{y_sup} μ(y)^γ dy ]

(5.386)  η_GCOG = [ ∫_{y_inf}^{y_sup} μ(y)^{γ(y)}·y dy ] / [ ∫_{y_inf}^{y_sup} μ(y)^{γ(y)} dy ]

(5.387)  ∫_{y_inf}^{η} μ(y) dy = ∫_{η}^{y_sup} μ(y) dy

(5.388)  ∫_{y_inf}^{η_PB} μ(y)^γ dy = ∫_{η_PF}^{y_sup} μ(y)^γ dy
```

## 原文关键语句（逐字摘录）

- 首句：「在许多情形我们得到清晰集这个过程称为逆模糊化．有多种方法得以达到此目的．」
- 方法 1：「在具有极大隶属等级的模糊集 $\mu_{x_1,\cdots,x_n}^{\#\bigoplus}$ 的区域中选取一个任意值 $\eta \in Y$.」（上标乱码疑为「输出」）
- 方法 2：「输出值是极大隶属等级值的平均值」；「即集合 是一个区间，它应是非空的并且由 (5.382) 刻画，由此可推出 (5.384):」（「集合」后脱记号；「(5.384)」疑应为 (5.383)）
- 方法 3：「在重心法中，我们取具有虚构的齐次密度值 的曲面的重心横坐标值：」（「密度值」后脱数值）
- 方法 4：「参数化方法使用指数 $\gamma\in$ 良：」；「(5.385) 可推出对千 $\gamma = 1$ $\eta_{\mathrm{PCOG}} = \eta_{\mathrm{COG}}$, 并且当 $\gamma \to 0$ 时, $\eta_{\mathrm{PCOG}} = \eta_{\mathrm{MOM}}$」（「对千」＝「对于」；γ→0 断言存疑，见下）
- 方法 5：「PCOG 方法中的指数 $\gamma$ 看作 的函数，那么显然可推出 …… GCOG 方法是 PCOG 方法的一般化，其中 $\mu(y)$ 以自身与 $y$ 有关的特殊的权 $\gamma$ 变化．」（「看作」后脱 y）
- 方法 6：「我们求出纵轴的平行线使得位千隶属函数图形下的区域在其左边和右边部分的面积相等」（「位千」＝「位于」）
- 方法 8：「选择有效子集合和上面定义的方法之一，例如，重心法 (COG) 或面积中心法(COA) 应用千这个子集」（「应用千」＝「应用于」）
