## 1.1.6.1 以多项式形式表示

任一整有理式通过单项式和多项式的加法、减法、乘法等基本变换，可转化为多项式形式。原书例题（经独立验算正确）：

$$
\begin{aligned}
& (- a ^ {3} + 2 a ^ {2} x - x ^ {3}) (4 a ^ {2} + 8 a x) + (a ^ {3} x ^ {2} + 2 a ^ {2} x ^ {3} - 4 a x ^ {4}) - (a ^ {5} + 4 a ^ {3} x ^ {2} - 4 a x ^ {4}) \\
&= - 4 a ^ {5} + 8 a ^ {4} x - 4 a ^ {2} x ^ {3} - 8 a ^ {4} x + 16 a ^ {3} x ^ {2} - 8 a x ^ {4} + a ^ {3} x ^ {2} + 2 a ^ {2} x ^ {3} - 4 a x ^ {4} - a ^ {5} - 4 a ^ {3} x ^ {2} + 4 a x ^ {4} \\
&= - 5 a ^ {5} + 13 a ^ {3} x ^ {2} - 2 a ^ {2} x ^ {3} - 8 a x ^ {4}.
\end{aligned}
$$

该论断坐实了 [[comparisons/代数式分类层级]] 中整有理式的位置：它介于 [[concepts/有理式]] 与 [[concepts/多项式]] 之间，且与多项式形式等同。

## 1.1.6.2 多项式的因式分解

原书指出：多项式通常可分解成单项式和多项式的乘积，可通过提取公因式、分组、利用方程的特殊公式和特殊性质完成分解（方法详解见 [[concepts/因式分解]]，三法对照见 [[comparisons/因式分解方法比较]]）：

- **A 提取公因式**：$8ax^{2}y - 6bx^{3}y^{2} + 4cx^{5} = 2x^{2}(4ay - 3bxy^{2} + 2cx^{3})$。
- **B 分组解法**：$6x^{2} + xy - y^{2} - 10xz - 5yz = 6x^{2} + 3xy - 2xy - y^{2} - 10xz - 5yz = 3x(2x+y) - y(2x+y) - 5z(2x+y) = (2x + y)(3x - y - 5z)$。
- **C 利用方程的性质**（前向引用第 56 页 1.6.3.1）：对 $P(x) = x^{6} - 2x^{5} + 4x^{4} + 2x^{3} - 5x^{2}$，先提取公因子 $x^{2}$；由 $\alpha_{1} = 1$、$\alpha_{2} = -1$ 是方程 $P(x)=0$ 的根，$P(x)$ 除以 $x^{2}(x-1)(x+1) = x^{4} - x^{2}$ 得商 $x^{2} - 2x + 5$；因 $p = -2,\ q = 5,\ \frac{p^{2}}{4} - q < 0$，商不能再分解为实因子（见 [[findings/手册以p方除4减q小于零判定二次因式无实分解]]），故最终分解式为

$$
x ^ {6} - 2 x ^ {5} + 4 x ^ {4} + 2 x ^ {3} - 5 x ^ {2} = x ^ {2} (x - 1) (x + 1) (x ^ {2} - 2 x + 5).
$$

## 1.1.6.3 特殊公式（乘法公式）

以下公式 (1.28)–(1.35) 逐条验证均成立，是 [[concepts/恒等式]] 的具体实例，详见 [[concepts/乘法公式]]：

$$
(x \pm y) ^ {2} = x ^ {2} \pm 2 x y + y ^ {2},\tag{1.28}
$$

$$
(x + y + z) ^ {2} = x ^ {2} + y ^ {2} + z ^ {2} + 2 x y + 2 x z + 2 y z,\tag{1.29}
$$

$$
(x + y + z + \dots + t + u) ^ {2} = x ^ {2} + y ^ {2} + z ^ {2} + \dots + t ^ {2} + u ^ {2} + 2 x y + 2 x z + \dots + 2 x u + 2 y z + \dots + 2 y u + \dots + 2 t u,\tag{1.30}
$$

$$
(x \pm y) ^ {3} = x ^ {3} \pm 3 x ^ {2} y + 3 x y ^ {2} \pm y ^ {3},\tag{1.31}
$$

$$
(x + y) (x - y) = x ^ {2} - y ^ {2},\tag{1.32}
$$

$$
\frac {x ^ {n} - y ^ {n}} {x - y} = x ^ {n - 1} + x ^ {n - 2} y + \dots + x y ^ {n - 2} + y ^ {n - 1} \quad (n \text{ 是整数，且 } n > 1),\tag{1.33}
$$

$$
\frac {x ^ {n} + y ^ {n}} {x + y} = x ^ {n - 1} - x ^ {n - 2} y + \dots - x y ^ {n - 2} + y ^ {n - 1} \quad (n \text{ 是奇数，且 } n > 1),\tag{1.34}
$$

$$
\frac {x ^ {n} - y ^ {n}} {x + y} = x ^ {n - 1} - x ^ {n - 2} y + \dots + x y ^ {n - 2} - y ^ {n - 1} \quad (n \text{ 是偶数，且 } n > 1).\tag{1.35}
$$

原书指出，计算 $(x \pm y)^{n}$ 可借助于二项式公式（参见 (1.36a)–(1.37a)）。公式 (1.33)–(1.35) 呈 [[concepts/有限级数]] 的有限和形态。

## 1.1.6.4 二项式定理

### 1. 两数代数和的幂（第一类二项式公式）

$$
(a + b) ^ {n} = a ^ {n} + n a ^ {n - 1} b + \frac {n (n - 1)} {2 !} a ^ {n - 2} b ^ {2} + \frac {n (n - 1) (n - 2)} {3 !} a ^ {n - 3} b ^ {3} + \dots + \frac {n (n - 1) \cdots (n - m + 1)} {m !} a ^ {n - m} b ^ {m} + \dots + n a b ^ {n - 1} + b ^ {n},\tag{1.36a}
$$

其中 $a$、$b$ 是实数或复数，$n = 1, 2, \cdots$。利用 [[concepts/二项式系数]] 可更简便地记为

$$
(a + b) ^ {n} = \binom {n} {0} a ^ {n} + \binom {n} {1} a ^ {n - 1} b + \binom {n} {2} a ^ {n - 2} b ^ {2} + \binom {n} {3} a ^ {n - 3} b ^ {3} + \dots + \binom {n} {n - 1} a b ^ {n - 1} + \binom {n} {n} b ^ {n},\tag{1.36b}
$$

或

$$
(a + b) ^ {n} = \sum_ {k = 0} ^ {n} \binom{n}{k} a ^ {n - k} b ^ {k}.\tag{1.36c}
$$

### 2. 两数代数差的幂（第二类二项式公式）

$$
(a - b) ^ {n} = a ^ {n} - n a ^ {n - 1} b + \frac {n (n - 1)} {2 !} a ^ {n - 2} b ^ {2} - \frac {n (n - 1) (n - 2)} {3 !} a ^ {n - 3} b ^ {3} + \dots + (- 1) ^ {m} \frac {n (n - 1) \cdots (n - m + 1)} {m !} a ^ {n - m} b ^ {m} + \dots + (- 1) ^ {n} b ^ {n},\tag{1.37a}
$$

或（源文此处记号排版残缺，写作 $\left(n\ k\right)$，按文意应为 $\binom{n}{k}$，见下文“勘误候选”）：

$$
(a - b) ^ {n} = \sum_ {k = 0} ^ {n} \binom{n}{k} (- 1) ^ {k} a ^ {n - k} b ^ {k}.\tag{1.37b}
$$

### 3. 二项式系数

对于非负整数 $n$ 和 $k$（$0 \leqslant k \leqslant n$）：

$$
\binom {n} {k} = \frac {n !} {(n - k) ! k !},\tag{1.38a}
$$

其中 $n!$ 是 1 到 $n$ 这 $n$ 个正整数的乘积，称为 $n$ 的 [[concepts/阶乘]]：

$$
n! = 1 \cdot 2 \cdot 3 \cdot \dots \cdot n, \quad \text{且定义 } 0! = 1.\tag{1.38b}
$$

**表 1.2 帕斯卡三角形**（按源文转录；列位为原表转录位置，奇偶行交错排布，列号不等于 $k$；$n=5$、$n=6$ 行疑被截断，见 [[queries/手册表1-2帕斯卡三角形是否截断]]）：

| n | ① | ② | ③ | ④ | ⑤ | ⑥ | ⑦ | ⑧ | ⑨ | ⑩ | ⑪ |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 0 | | | | | | 1 | | | | | |
| 1 | | | | | 1 | | 1 | | | | |
| 2 | | | | 1 | | 2 | | 1 | | | |
| 3 | | | 1 | | 3 | | 3 | | 1 | | |
| 4 | | 1 | | 4 | | 6 | | 4 | | 1 | |
| 5 | | | 1 | | 5 | | 10 | | 10 | | 5 |
| 6 | 1 | | 6 | | 15 | | 20 | | 15 | | |
| | ↑ | | ↑ | | ↑ | | ↑ | | ↑ | | |
| 6 | (6) | | (6) | | (6) | | (6) | | (6) | | |
| | (0) | | (1) | | (2) | | (3) | | (4) | | |
| ⋮ | ⋱ | ⋱ | ⋱ | ⋱ | ⋱ | ⋱ | ⋱ | ⋱ | ⋱ | ⋱ | |

构造规则（原书）：由表 1.2 的帕斯卡三角形易看出二项式系数。每行的第一个数和最后一个数等于 1；其余各数是其上一行左、右两数之和。详见 [[concepts/帕斯卡三角形]]。

系数的公式性质（原书称“通过简单计算即可证明”）：

$$
\binom{n}{k} = \binom{n}{n - k} = \frac {n !} {k ! (n - k) !},\tag{1.39a}
$$

$$
\binom{n}{0} = 1, \quad \binom{n}{1} = n, \quad \binom{n}{n} = 1,\tag{1.39b}
$$

$$
\binom{n + 1} {k + 1} = \binom{n} {k} + \binom{n - 1} {k} + \binom{n - 2} {k} + \dots + \binom{k} {k},\tag{1.39c}
$$

$$
\binom{n + 1} {k} = \frac {n + 1} {n - k + 1} \binom{n} {k},\tag{1.39d}
$$

$$
\binom{n} {k + 1} = \frac {n - k} {k + 1} \binom{n} {k},\tag{1.39e}
$$

$$
\binom{n + 1} {k + 1} = \binom{n} {k + 1} + \binom{n} {k}.\tag{1.39f}
$$

对任意实数值 $\alpha$（$\alpha \in \mathbb{R}$）和非负整数 $k$，可定义广义二项式系数：

$$
\binom{\alpha}{k} = \frac {\alpha (\alpha - 1) (\alpha - 2) \cdots (\alpha - k + 1)} {k !} \quad (k \text{ 是整数，且 } k \geqslant 1), \qquad \binom{\alpha}{0} = 1,
$$

$$
\binom{- \frac {1} {2}} {3} = \frac {- \frac {1} {2} \left(- \frac {1} {2} - 1\right) \left(- \frac {1} {2} - 2\right)} {3 !} = - \frac {5} {16}.\tag{1.40}
$$

### 4. 二项式系数的性质

- 二项式系数逐渐增大，直到二项式公式 (1.36b) 的中间；然后开始减小。
- 对于式子端点和末尾对称的项，其二项式系数相等。
- $n$ 次二项式的系数之和等于 $2^{n}$。
- 奇数项系数之和等于偶数项系数之和。

后两条的验算与限制条件见 [[findings/二项式系数之和等于2的n次方且奇偶项各半]]（奇偶项相等性质严格说需 $n \geqslant 1$，原书未注明）。

### 5. 二项式级数

二项式定理的公式 (1.36a) 也可以扩展到负分数指数情形。若 $|b| < a$，则 $(a + b)^{n}$ 有无穷收敛级数（原书指向第 1373 页 21.5，该章节尚未入库）：

$$
(a + b) ^ {n} = a ^ {n} + n a ^ {n - 1} b + \frac {n (n - 1)} {2 !} a ^ {n - 2} b ^ {2} + \frac {n (n - 1) (n - 2)} {3 !} a ^ {n - 3} b ^ {3} + \dots.\tag{1.41}
$$

详见 [[concepts/二项式级数]] 与 [[findings/二项式级数在b绝对值小于a时收敛]]。注意：收敛条件 $|b| < a$ 属于无穷级数推广，不属于有限形式的二项式定理 (1.36)–(1.37)。

## 1.1.6.5 求两个多项式的最大公因式

次数分别为 $n$ 和 $m$（$n \geqslant m$）的两个多项式 $P(x)$ 和 $Q(x)$，可能有含 $x$ 的公共多项式因子。原书措辞：“这些因子的最小公倍式是多项式的最大公因式”（非标准表述，见下文“表述张力”）。

■ $P(x) = (x - 1)^2 (x - 2)(x - 4)$，$Q(x) = (x - 1)(x - 2)(x - 3)$；最大公因式是 $(x - 1)(x - 2)$（经独立验算正确，见 [[findings/多项式最大公因式为辗转相除法最后非零余项]]）。

若 $P(x)$ 和 $Q(x)$ 没有任何公共因子，则称它们是互素的；此时它们的最大公因式是常数。详见 [[concepts/最大公因式]]。

两个多项式的最大公因式可由 [[concepts/辗转相除法]] 求出（原书接语：“需把它们分解成因式”）：

(1) $P(x)$ 除以 $Q(x) = R_0(x)$，商为 $T_{1}(x)$，余项为 $R_{1}(x)$：

$$
P (x) = Q (x) T _ {1} (x) + R _ {1} (x).\tag{1.42a}
$$

(2) $Q(x)$ 除以 $R_{1}(x)$，商为 $T_{2}(x)$，余项为 $R_{2}(x)$：

$$
Q (x) = R _ {1} (x) T _ {2} (x) + R _ {2} (x).\tag{1.42b}
$$

(3) $R_{1}(x)$ 除以 $R_{2}(x)$，商为 $T_{3}(x)$，余项为 $R_{3}(x)$，依此类推。两个多项式的最大公因式是最后的非零余项 $R_{k}(x)$。原书指出，这种方法“因自然数的算术而为大家熟知”（前向引用第 3 页 1.1.1.4）。

应用：当必须分离较高重数的根，或运用斯图姆法求解方程时，可使用最大公因式法（前向引用第 57 页 1.6.3.2）。

## 论断强度评估

各论断归属其主体，不互相转嫁：

- **整有理式可化为多项式形式**：构造性算法 + 已验证实例，强度强。
- **因式分解三途径（A/B/C）**：例题经独立验算正确，强度强。
- **乘法公式 (1.28)–(1.35)**：逐条验证均成立，强度强。
- **二项式定理与二项式系数性质**：标准恒等式，均验证成立；其中“奇偶项系数之和相等”需 $n \geqslant 1$。
- **二项式级数收敛性**：陈述性断言，收敛性证明不在本节（指向第 1373 页 21.5）。
- **最大公因式为辗转相除法最后非零余项**：算法命题，例题经验算正确，强度强。

## 勘误候选与表述张力

1. **(1.37b) 记号残缺**：源文写作 $\sum_{k=0}^{n} \left(n\ k\right) (-1)^{k} a^{n-k} b^{k}$，其中 $\left(n\ k\right)$ 显系 $\binom{n}{k}$ 的排版/转录丢失。
2. **表 1.2 疑似截断**：$n=5$ 行仅列 1, 5, 10, 10, 5（缺末项 1），$n=6$ 行仅列 1, 6, 15, 20, 15（缺 6, 1），与三角形首尾对称的构造规则自相矛盾；底部标注 $\binom{6}{0}$ 至 $\binom{6}{4}$ 仅索引到 $k=4$，佐证表格宽度截断。追踪页：[[queries/手册表1-2帕斯卡三角形是否截断]]。
3. **非标准表述**：“这些因子的最小公倍式是多项式的最大公因式”——在整除格意义上成立（全体公因子的最小公倍即最大公因式），但与通行的“各公共不可约因子取最低次幂之积”表述不同，宜按原书措辞记录。
4. **表述偏窄**：二项式级数一节称扩展到“负分数指数情形”，但广义系数 (1.40) 已对任意实数 $\alpha$ 定义，级数对任意实指数在 $|b| < a$ 时均收敛；手册措辞聚焦于非整数情形。
5. **未加限定的边角**：“奇数项系数之和等于偶数项系数之和”在 $n=0$ 时不成立（两侧分别为 0 与 1），手册未注明 $n \geqslant 1$。

与现有 wiki 内容无直接冲突；本节所有例题经独立验算均正确。
