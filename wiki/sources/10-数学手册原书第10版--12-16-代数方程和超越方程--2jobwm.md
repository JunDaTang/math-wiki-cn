# 数学手册(原书第10版) 1.6 代数方程和超越方程

《数学手册(原书第10版)》第 1.6 节是全书方程求解理论的枢纽：先把任意[[concepts/代数方程|代数方程]]（组）化归为多项式正规形式并处理由此产生的[[concepts/增根|增根]]，随后给出一次至四次方程的完整显式解法（含[[concepts/卡尔达诺公式|卡尔达诺公式]]与三次方程的三角／双曲辅助解法），继而建立 $n$ 次方程的一般理论（[[concepts/代数基本定理|代数基本定理]]、[[concepts/重根|重根]]、[[concepts/韦达定理|韦达定理]]、实根定位的[[concepts/斯图姆定理|斯图姆定理]]与[[concepts/笛卡儿符号法则|笛卡儿符号法则]]），最后讨论可化为代数方程的四类[[concepts/超越方程|超越方程]]。本节页脚署名“李文林 聂淑媛 译”。

## 章节结构

- **1.6.1 把代数方程变换为正规形式**：1.6.1.1 定义；1.6.1.2 $n$ 次代数方程组；1.6.1.3 增根。
- **1.6.2 不高于四次的方程**：1.6.2.1 一次方程（线性方程）；1.6.2.2 二次方程（手册称“平方方程”）；1.6.2.3 三次方程（手册称“立方方程”）；1.6.2.4 四次方程；1.6.2.5 高次方程。
- **1.6.3 $n$ 次方程**：1.6.3.1 一般性质（根、代数基本定理、韦达定理）；1.6.3.2 实系数方程（复根、根的个数、斯图姆定理、笛卡儿法则、数值方法定位）。
- **1.6.4 化超越方程为代数方程**：1.6.4.1 定义；1.6.4.2 指数方程；1.6.4.3 对数方程；1.6.4.4 三角方程；1.6.4.5 双曲函数方程。

## 核心内容

### 化归与增根（1.6.1）

任何代数方程可经代数变换化为正规形式 (1.143)，任何代数方程组可化为多项式方程组 (1.144)。原方程的根都含于正规形式的根中，但去分母（式 1.145）与对无理方程乘方等**非可逆变换**会引入增根，必须把正规形式的根代回原方程检验。示例：$\sqrt{x+7}+1=2x$ 的正规形式为 $4x^2-5x-6=0$，其中 $x_1=2$ 是真根、$x_2=-\tfrac34$ 是增根；$\dfrac{x^3}{x-1}=\dfrac{1}{x-1}$ 中 $x=1$ 是增根（使分式无意义）。

### 二次方程（1.6.2.2）

手册采用**反号判别式约定** $D=4ac-b^2$（或 $D=q-\tfrac{p^2}{4}$）：$D<0$ 两实根、$D=0$ 一个二重实根、$D>0$ 无实根（两复根）；求根公式 (1.153)、(1.154) 的被开方式 $b^2-4ac=-D$，与该约定自洽。详见 [[concepts/二次方程]]、[[concepts/判别式]]。

### 三次方程（1.6.2.3）

经替换 $y=x+\tfrac{b}{3a}$ 化为 $y^3+3py+2q=0$（式 1.155）；判别式 $D=q^2+p^3$（式 1.156）三分实根个数。解法：因式分解；[[concepts/卡尔达诺公式|卡尔达诺公式]]（推导中用韦达定理解预解二次方程 $w^2+2qw-p^3=0$，9 种立方根组合经 $uv=-p$ 约束为 3 根）；实方程查表 1.3 的三角／双曲辅助值；数值近似（手册第 1237 页 19.1.2、第 167 页 2.19.3.3 算图）。

### 四次方程（1.6.2.4）

实系数时根数为 0、2 或 4。特殊形式：双二次方程 $ax^4+cx^2+e=0$（式 1.162b）与对称系数型 $ax^4+bx^3+cx^2+bx+a=0$（$a=e$、$b=d$，式 1.162d，即通称的倒数方程型，手册未命名）。一般方程（$a=1$）经三次预解方程 (1.164b) 降次为二次方程 (1.164a)；该处存在两处疑转录缺漏（见“存疑之处”）。

### 高次方程（1.6.2.5）

一般的五次及以上方程不存在求根公式。

### $n$ 次方程（1.6.3）

代数基本定理：实或复系数 $n$ 次方程按重数计恰有 $n$ 个根，乘积形式 (1.166a)。去重根：$T(x)$ 是 $P(x)$ 与 $P'(x)$ 的最大公因式（显式引用 1.1.6.5 辗转相除法），$P/T$ 得到含全部根且均为单根的 $Q(x)$。韦达定理一般形式 (1.167)。实系数方程的复根成共轭对且同重数（式 1.168–1.169，条件 $\left(\tfrac{p_i}{2}\right)^2-q_i<0$），故奇次方程至少有一个实根；区间实根个数由斯图姆链 (1.170) 的符号变化数之差给出，正根个数上界由笛卡儿符号法则给出（配合 $x\to -x$、$x\to x+h$ 估计负根与根界）。$n>4$ 只能近似求解：求全部根（含复根）用布罗德斯基-斯米尔（Brodetsky-Smeal）方法（引文 [1.7]、[19.40]），求复根用贝尔斯托法（Bairstow，引文 [19.15]）。

### 超越方程（1.6.4）

$F(x)=f(x)$ 中 $F$ 或 $f$ 至少一个非代数时为超越方程，一般只能近似求解；四类特殊情形可经变量替换化为代数方程（指数、对数、三角、双曲），且解后必须做可行性检验（$y=k^x>0$、对数真数为正、$|\sin x|\le 1$ 等）。详见 [[concepts/超越方程化为代数方程的变量替换法]]。

% 正规形式与增根
F(x) = f(x)                                               (1.142)
P(x) = a_n x^n + a_{n-1} x^{n-1} + ... + a_1 x + a_0 = 0   (1.143)
P(x)/Q(x) = 0   -->   P(x) = 0                            (1.145a/b)

% 一次方程
ax + b = 0 (a != 0);   x_1 = -b/a                         (1.146/1.147)

% 二次方程（注意手册 D 为反号约定）
ax^2 + bx + c = 0 (a != 0);   x^2 + px + q = 0             (1.148a/b)
D = 4ac - b^2  (对 1.148a);   D = q - p^2/4  (对 1.148b)   (1.149)
x_1 + x_2 = -b/a = -p,   x_1 x_2 = c/a = q                (1.150)
x_{1,2} = (-b ± sqrt(b^2 - 4ac)) / (2a)                   (1.153a)
x_{1,2} = (-b/2 ± sqrt((b/2)^2 - ac)) / a                 (1.153b)
x_{1,2} = -p/2 ± sqrt(p^2/4 - q)                          (1.154)

% 三次方程
ax^3 + bx^2 + cx + d = 0;   y^3 + 3py + 2q = 0             (1.155a/b)
q* = 2q = 2b^3/(27a^3) - bc/(3a^2) + d/a,
p* = 3p = (3ac - b^2)/(3a^2)                               (1.155c)
D = q^2 + p^3                                             (1.156)
x_1+x_2+x_3 = -b/a,  x_1x_2+x_1x_3+x_2x_3 = c/a,
x_1 x_2 x_3 = -d/a                                        (1.157)
w^2 + 2qw - p^3 = 0                                       (1.159d)
y = cbrt(-q + sqrt(q^2+p^3)) + cbrt(-q - sqrt(q^2+p^3))   (1.159f)
y_2 = u_1(-1/2 + i*sqrt(3)/2) + v_1(-1/2 - i*sqrt(3)/2)   (1.159h)
y_3 = u_1(-1/2 - i*sqrt(3)/2) + v_1(-1/2 + i*sqrt(3)/2)   (1.159i)
r = ±sqrt(|p|),  r 的符号与 q 相同                         (1.160)

% 四次方程
ax^4 + bx^3 + cx^2 + dx + e = 0 (a != 0)                  (1.161)
ax^4 + cx^2 + e = 0:  x_{1,2,3,4} = ±sqrt(y),
  y = (-c ± sqrt(c^2 - 4ae))/(2a)                          (1.162a/b)
ax^4 + bx^3 + cx^2 + bx + a = 0 (a = e, b = d):

x^2 + (b + A) x/2 + (y + (by - d)/A) = 0,                  (1.164a)
A = ±sqrt(8y + b^2 - 4c), y 是三次方程
8y^3 - 4cy^2 + (2bd - 8e)y + e(4c - b^2) - d^2 = 0         (1.164b)
的一个实根, 且 B = b^3/8 - bc/2 ≠ 0。
当 B = 0 时, 借助变量替换 x = u - b/4, 可生成关于 u 且 a = 1 的
双二次方程 (1.162a)。

% n 次方程
P_n(x) = (x - α) P_{n-1}(x) + P_n(α)                       (1.165b)
P(x) = (x-α)^k (x-β)^l (x-γ)^m ...                         (1.166a)
T(x) = (x-α)^{k-1}(x-β)^{l-1}...,  Q(x) = (x-α)(x-β)...    (1.166c)
Σx_i = -a_{n-1};  Σ_{i<j} x_i x_j = a_{n-2};  ...;
x_1 x_2 ... x_n = (-1)^n a_0                               (1.167)
(x - α)(x - β) = x^2 + px + q,  p = -2a, q = a^2 + b^2     (1.168)
P(x) = (x-α_1)^{k_1}...(x-α_l)^{k_l}
       · (x^2+p_1x+q_1)^{m_1}...(x^2+p_rx+q_r)^{m_r},

| | p<0, q²+p³≤0 | p<0, q²+p³>0 | p>0 |
|---|---|---|---|
| 辅助量 | cos φ = q/r³ | cosh φ = q/r³ | sinh φ = q/r³ |
| y₁ | −2r cos(φ/3) | −2r cosh(φ/3) | −2r sinh(φ/3) |
| y₂ | +2r cos(60°−φ/3) | r cosh(φ/3) + i√3 r sinh(φ/3) | r sinh(φ/3) + i√3 r cosh(φ/3) |

## 数值示例与复核情况

本节示例在本 wiki 建档时经独立重算，全部核对无误：

- $y^3+6y+2=0$：$u=\sqrt[3]{2}=1.2599$、$v=\sqrt[3]{-4}=-1.5874$，实根 $y_1=-0.3275$，复根 $y_{2,3}=0.1638\pm 2.4659\,\mathrm i$。
- $y^3-9y+4=0$（表 1.3 路线）：$r=\sqrt3$，$\cos\varphi=\tfrac{2}{3\sqrt3}=0.3849$，$\varphi=67^\circ22'$，三实根 $-3.201$、$2.747$、$0.455$（校验：$y_1+y_2+y_3=0.001$ 可视为 0）。
- 斯图姆链示例 $x^4-5x^2+8x-8=0$ 在 $[0,2]$：链为 $P=x^4-5x^2+8x-8$、$P'=4x^3-10x+8$、$P_1=5x^2-12x+16$、$P_2=-3x+284$、$P_3=-1$；$x=0$ 处符号 $-,+,+,+,-$（2 次变化），$x=2$ 处 $+,+,+,+,-$（1 次变化），$A-B=1$，区间内恰一个实根。
- 笛卡儿法则示例 $x^4+2x^3-x^2+5x-1=0$：正根 3 个或 1 个、至多 1 个负根、正根均小于 1。
- 1.6.4 四例（$3^x=4^{x-2}\cdot2^x$、$2\log_5(3x-1)-\log_5(12x+1)=0$、$\sin x=\cos^2x-\tfrac14$、$3\cosh x=\sinh x+9$）及其可行性检验均复核正确。

## 存疑之处（转录/排印问题）

1. **式 (1.164a) 疑缺 $-A$ 支的伴随二次方程**：手册称 (1.163a) 的根与 (1.164a) 的根相同，但单个二次方程至多 2 个根；经因式分解验证应以 $\pm A$ 给出两个二次方程。见 [[queries/式1-164a是否缺负A支的伴随二次方程]]。
2. **式 (1.164) 处 $B$ 的定义疑漏 $+d$**：推导显示平移 $x=u-\tfrac b4$ 后一次项系数为 $\tfrac{b^3}{8}-\tfrac{bc}{2}+d$。见 [[queries/式1-164处B的定义是否漏加d项]]。
3. **增根示例与 (1.145) 程序不一致**：$x^3/(x-1)=1/(x-1)$ 按 (1.145) 应得 $x^3-1=0$，手册给的 $x^4-x^3-x+1=0$ 来自交叉相乘；结论不受影响。见 [[queries/增根示例的正规形式为何偏离式1-145程序]]。
4. **判别式反号约定**：$D=4ac-b^2$ 与通行 $\Delta=b^2-4ac$ 反号，手册内部自洽但与外部文献对照易误读，已记入 [[findings/二次方程判别式三分类与手册反号约定]]。
5. **三角方程通解 $k=1,2,3,\cdots$ 疑应为 $k=0,1,2,\cdots$**（否则漏掉 $x=\tfrac\pi6$ 本身）。见 [[queries/三角方程通解中k是否应从0开始]]。
6. 小项：“平方方程”“立方方程”为少见译名，记录备查。
