# 数学手册(原书第10版) 21.3 (公制)前缀表

## 概述

本页为《数学手册(原书第10版)》第 21 章小节 21.3「(公制)前缀表」的分节建档页。该小节为一页式参考表格：收录 20 个公制（SI）词头，指数自 $10^{-24}$（幺 y）至 $10^{24}$（尧 Y），每项给出中文名、科学记数法与拉丁缩写；表后另附一行单位换算算例。小节内无论证性主张，可核验内容即前缀表本体与尾部算例。

表格为双栏并排排版：左栏自 $10^{-24}$ 至 $10^{-1}$ 由小到大，右栏自 $10^{1}$ 至 $10^{24}$。同一行内左右两栏之间无数值对应关系，纯为排版合并，并非两表并列。

## 复原与验算

公式本体可复原为下列五式，数值均验算无误：

| 复原式 | 验算 |
|---|---|
| $10^{3} = 1000$ | ✓ |
| $10^{-3} = 0.001$ | ✓ |
| $10^{3}\,\mathrm{m} = 1\,\mathrm{km}$ | ✓ |
| $1\,\mu\mathrm{m} = 10^{-6}\,\mathrm{m}$ | ✓ |
| $1\,\mathrm{nm} = 10^{-9}\,\mathrm{m}$ | ✓ |

其中源文「um」之 u 为 μ 之 OCR 替身：表内微作词头作「μ」，尾块则以「u」代之，同一符号两种形态并存。

各复原式前之上划线字母（依次为 m、u、Ω、u、u）判定为非词头符号本体：其与所配指数不匹配（第二例 u 配 $10^{-3}$，若为 μ 应配 $10^{-6}$；第一例 m 配 $10^{3}$，若为词头 m 应配 $10^{-3}$），疑为重复出现的标记词（如「例如」或德文原文「z. B.」）之误读，追踪见 [[queries/21-3尾例上划线符号之辨]]。

## 范围注记（非讹误）

表内词头止于 y/Y（$10^{-24}$/$10^{24}$），不含 2022 年新增之 ronna（R, $10^{27}$）、quetta（Q, $10^{30}$）、ronto（r, $10^{-27}$）、quecto（q, $10^{-30}$），符合原书成书年代，属版本时点特征而非缺漏。（注：2022 年新词头信息为外部背景知识，非来源自述。）
