# 数学手册(原书第10版) 5.9.2 模糊集的连接(聚合)

## 概述

本节是《数学手册(原书第10版)》5.9「模糊集」域入库的第一份材料，主题为模糊集的连接（聚合），即把经典集合的并、交、补推广为模糊集上的运算。节首指出，关于如何推广通常的集合运算「有几个不同的建议」。全节总纲是**逐点局部性原理**：模糊并/交在任一点 x 处的隶属等级只与 μ_A(x)、μ_B(x) 有关，分别经二元聚合函数 s（并）与 t（交）映为新的隶属等级（式 5.343–5.345）。据此依次展开：

1. **5.9.2.1 聚合概念**：并/交的逐点定义；[[concepts/t-范数]] 与 [[concepts/s-范数]] 的公理化（E1–E4）及 min/max 上下界（式 5.349e–f）；
2. **5.9.2.2 实用聚合运算**：[[entities/扎德]] 的 min/max 缺省交并（式 5.350–5.351，图 5.72–5.75，对应 AND/OR）；代数和与代数积（式 5.352）；表 5.8 十二对范数族与序链；表 5.9 布尔—模糊运算对照；
3. **5.9.2.3 补偿算子**：介于 t/s 范数之间的 λ 算子与 γ 算子（式 5.353–5.356，含 n 元与加权形式）；
4. **5.9.2.4 扩张原理**：经典映射 Φ: Xⁿ→Y 到模糊映射 Φ̂: F(X)ⁿ→F(Y) 的类型级扩充；
5. **5.9.2.5 模糊补**：补函数公理 EK1–EK4 与三种补函数（缺省补 1−x、菅野补、Yager 补）。

除 [[entities/扎德]] 外，表 5.8 与 5.9.2.5 出现的署名者（Lukasiewicz、Hamacher、Einstein、Frank、Yager、Schweizer、Dombi、Weber、Dubois、Sugeno〔源文译名讹作「管野」，应为「菅野」；Yager 源文译作「耶格尔」〕）均为单表行或单处公式归属，不单独建页，其归属记录于 [[comparisons/t范数族与s范数族比较]] 与 [[concepts/模糊补]]。

## 公式与公理（逐字转录）

以下为源文式 5.343–5.358 的转录；〔讹〕标注处为已识别的转写问题，汇总见 [[queries/5-9-2全节系统性转写讹误清单]]。

```text
s, t: [0,1] × [0,1] → [0,1]                                          (5.343)
μ_{A∪B}(x) := s(μ_A(x), μ_B(x))                                       (5.344)
μ_{A∩B}(x) := t(μ_A(x), μ_B(x))                                       (5.345)

t 范数：t: [0,1] × [0,1] → [0,1]                                      (5.346)
(E1) 交换性   t(x,y) = t(y,x)                                         (5.347a)
(E2) 结合性   t(x, t(y,z)) = t(t(x,y), z)                             (5.347b)
(E3) 与中性元素及零元素的特殊运算
     t(x,1) = x，并且由于 (E1)，有 t(1,x) = x；t(x,0) = t(0,x) = 0    (5.347c)
(E4) 单调性   x ≤ v 并且 y ≤ w ⇒ t(x,y) ≤ t(v,w)                      (5.347d)

s 范数：s: [0,1] × [0,1] → [0,1]                                      (5.348)
(E1) 交换性   s(x,y) = s(y,x)                                         (5.349a)
(E2) 结合性   s(x, s(y,z)) = s(s(x,y), z)                             (5.349b)
(E3) 与中性元素及零元素的特殊运算
     s(x,0) = s(0,x) = x；s(x,1) = s(1,x) = 1                         (5.349c)
(E4) 单调性   x ≤ v 并且 y ≤ w ⇒ s(x,y) ≤ s(v,w)                      (5.349d)

min{x,y} ≥ t(x,y)，∀t∈T，∀x,y∈[0,1]                                 (5.349e)
max{x,y} ≤ s(x,y)，∀s∈S，∀x,y∈[0,1]                                 (5.349f)

C := A∩B，μ_C(x) := min{μ_A(x), μ_B(x)}，∀x∈X                        (5.350a)
min{a,b} := a（a ≤ b）；b（a > b）                                    (5.350b)
C := A∪B，μ_C(x) := max{μ_A(x), μ_B(x)}，∀x∈X                        (5.351a)
max{a,b} := a（a ≥ b）；b（a < b）                                    (5.351b)

C := A+B，μ_C(x) := μ_A(x)+μ_B(x)−μ_A(x)·μ_B(x)（对所有 x∈X）        (5.352a)
C := A·B，μ_C(x) := μ_A(x)·μ_B(x)（对每个 x∈X）                       (5.352b)

μ_{AλB}(x) = λ[μ_A(x)μ_B(x)] + (1−λ)[μ_A(x)+μ_B(x)−μ_A(x)μ_B(x)]，λ∈[0,1]   (5.353)
μ_{AγB}(x) = [μ_A(x)μ_B(x)]^{1−γ}·[1−(1−μ_A(x))(1−μ_B(x))]^γ，γ∈[0,1]       (5.354)
μ(x) = [∏_{i=1}^n μ_i(x)]^{1−γ}·[1−∏_{i=1}^n (1−μ_i(x))]^γ                  (5.355)
μ(x) = [∏_{i=1}^n μ_i(x)^{δ_i}]^{1−γ}·[1−∏_{i=1}^n (1−μ_i(x))^{δ_i}]^γ，
       x∈X，Σ_{i=1}^n δ_i = 1，γ∈[0,1]                                       (5.356)

补函数 c: [0,1] → [0,1]：
(EK1) 边界条件 c(O) = c(l) = 0〔讹：O/l 为 0/1 之 OCR 形；应为 c(0)=1, c(1)=0〕 (5.357a)
(EK2) 单调性   x < y ⇒ c(x) ≥ c(y)                                    (5.357b)
(EK3) 对合性   c(c(x)) = x                                            (5.357c)
(EK4) 连续性   c(x) 对每个 x∈[0,1] 连续                                (5.357d)

■ A: 最常用的（连续且对合的）补函数是
c(x) := 1 − x                                                         (5.358)
■ B: 其他连续且对合的补函数是管野(Sugeno)补〔译名应为「菅野」〕：
c_λ(x) := (1−x)(1+λx)^{−1}，λ∈(−1,∞)
以及耶格尔(Yager)补：
c_p(x) := (1−x^p)^{1/p}，p∈(0,1)〔参数区间疑应为 p>0〕
```

## 表 5.8　t 范数和 s 范数，p ∈ ℝ（逐字转录）

| 作者 | t 范数 | s 范数 |
|---|---|---|
| Zadeh | 交：t(x,y) = min{x,y} | 并：s(x,y) = max{x,y} |
| Lukasiewicz | 有界差：t_b(x,y) = max{0, x+y−1} | 有界和：s_b(x,y) = min{1, x+y} |
|  | 代数积：t_a(x,y) = xy | 代数和：s_a(x,y) = x+y−xy |
|  | 极端积：t_dp(x,y) = min{x,y}（x=1 或 y=1 时），否则 0 | 极端和：s_ds(x,y) = max{x,y}（x=0 或 y=0 时），否则 1 |
| Hamacher（p ≥ 0） | t_h(x,y) = xy / (p+(1−p)(x+y−xy)) | s_h(x,y) = (x+y−xy−(1−p)xy) / (1−(1−p)xy) |
| Einstein | t_e(x,y) = xy / (1+(1−x)(1−y)) | s_e(x,y) = (x+y)/(1+xy) |
| Frank（p>0, p≠1） | t_f(x,y) = log_p[1+(p^x−1)(p^y−1)/(p−1)] | s_f(x,y) = 1−log_p[1+(p^{1−x}−1)(p^{1−y}−1)/(p−1)] |
| Yager（p>0） | t_ya(x,y) = 1−min{1, ((1−x)^p+(1−y)^p)^{1/p}} | s_ya(x,y) = min{1, (x^p+y^p)^{1/p}} |
| Schweizer（p>0） | t_s(x,y) = max{0, x^{−p}+y^{−p}−1}^{−1/p} | s_s(x,y) = 1−max{0, (1−x)^{−p}+(1−y)^p−1}^{−1/p}〔疑讹〕 |
| Dombi（p>0） | t_do(x,y) = {1+[((1−x)/x)^p+((1−y)/y)^p]^{1/p}}^{−1} | s_do(x,y) = 1−{1+[(x/(1−x))^p+(y/(1−y))^p]^{1/p}}^{−1} |
| Weber（p ≥ −1） | t_w(x,y) = max{0, (1+p)(x+y−1)−pxy} | s_w(x,y) = min{1, x+y+pxy} |
| Dubois（0≤p≤1） | t_du(x,y) = xy/max{x,y,p} | s_du(x,y) = (x+y−xy−min{x,y,(1−p)})/max{(1−x),(1−y),p} |

注（源文原注）：对于表中所列的 t 范数和 s 范数，有下列顺序——
t_dp ≤ t_b ≤ t_e ≤ t_a ≤ t_h ≤ t ≤ s ≤ s_h ≤ s_a ≤ s_e ≤ s_b ≤ s_ds。
（维基注记：链中央的 t、s 即 Zadeh 的 min/max；「代数积/和」与「极端积/和」两行作者栏源文为空白；序链未标注 Hamacher 参数限定，见 [[queries/范数序链是否隐含hamacher参数限定]]。）

## 表 5.9　布尔逻辑和模糊逻辑中运算的比较（逐字转录）

源文此表标题脱落「表」字（印作「5.9 布尔逻辑和模糊逻辑中运算的比较」）。

| 算子 | 布尔逻辑 | 模糊逻辑（μ_A, μ_B ∈ [0,1]） |
|---|---|---|
| AND | C = A ∧ B | μ_{A∩B} = min{μ_A, μ_B} |
| OR | C = A ∨ B | μ_{A∪B} = max{μ_A, μ_B} |
| NOT | C = ¬A | μ_{A^C} = 1 − μ_A（μ_{A^C} 是 μ_A 的补） |

## 扩张原理（5.9.2.4）

经典映射 Φ: Xⁿ→Y 将清晰的函数值 Φ(x₁,…,xₙ)∈Y 指派给点 (x₁,…,xₙ)∈Xⁿ；概念的基础是「不明确语句的接受等级」（源文讹作「语旬」）。该映射可扩充到模糊变量：**模糊映射** Φ̂: F(X)ⁿ→F(Y) 将一个模糊函数值 Φ̂(μ₁,…,μₙ) 指派给由隶属函数 (μ₁,…,μₙ)∈F(X)ⁿ 给出的模糊向量变量 (x₁,…,xₙ)。手册仅给出这一类型级表述，未给通行文献中的 sup–min 隶属度公式，详见 [[concepts/扩张原理]] 与 [[findings/扩张原理的类型级表述]]。

## 转写讹误与张力（摘要）

详见 [[queries/5-9-2全节系统性转写讹误清单]] 与各专项 query：

- **内容性**：EK1 边界条件（应为 c(0)=1, c(1)=0）；Schweizer s_s 的 (1−y)^p 疑应为 (1−y)^{−p}（[[queries/schweizer-s范数指数是否应为负p]]）；式 5.351 段「交运算对应千逻辑 OR」应为「并运算」；Yager 补参数区间疑应为 p>0（[[queries/yager补参数区间是否应为p大于0]]）；序链与 Hamacher p ≥ 0 的张力（[[queries/范数序链是否隐含hamacher参数限定]]）；「(5.531a, 5.531b)」引用疑为 (5.351a, 5.351b) 之讹。
- **系统性 OCR**：千→于、入→λ、语旬→语句、「有儿个」→有几个、O/l↔0/1、「管野」→菅野；多处脱字（小节标题「范数的定义」脱 t/s、「情形入＝」脱 λ 值等）；表 5.9 标题脱「表」字；「有界聚合、代数聚合」疑为「有界和、代数和」；φ̂/Φ̂ 记号不一。
- **术语张力（非讹误）**：t_b 在表 5.8 名为「有界差」，正文另作「有界差分」「有界积」，通行中文文献多称「有界积/Łukasiewicz t 范数」。
