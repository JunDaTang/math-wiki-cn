# 数学手册(原书第10版) 11.2.2 逐次逼近法、诺伊曼级数

## 概述

本节是积分方程部分继 [[concepts/积分方程]] 定义与分类（11.1，见 [[sources/10-数学手册原书第10版--9-111-引论和分类--11tfgrq]]）之后的第一个求解方法节：以常微分方程的 [[concepts/皮卡迭代法]] 为类比原型，对第二类[[concepts/弗雷德霍姆积分方程]]建立逐次逼近迭代，由此生成关于参数 λ 的幂级数——[[entities/诺伊曼级数]]；其收敛性由优级数（Weierstrass 判别）保证，并可求和为[[entities/预解式]]，把解压缩为单次积分表示。节末给出 xy 核算例，并指出当 λ 超出收敛域时可用核分解法（[[concepts/退化核]] + 充分小的余核）处理，只要 λ 不是本征值。

全节数学内容经逐条复算通过，讹误集中于转写层（见 [[queries/11-2-2全节系统性转写讹误清单]]）。

## 核心公式组（转录，已清除转写噪声）

### 1. 迭代法

第二类弗雷德霍姆积分方程与迭代格式：

$$\varphi(x) = f(x) + \lambda \int_a^b K(x,y)\,\varphi(y)\,\mathrm{d}y \tag{11.10}$$

$$\varphi_n(x) = f(x) + \lambda \int_a^b K(x,y)\,\varphi_{n-1}(y)\,\mathrm{d}y \quad (n=1,2,\dots;\ \varphi_0(x)=f(x)) \tag{11.11a}$$

$$\varphi_1(x) = f(x) + \lambda \int_a^b K(x,y) f(y)\,\mathrm{d}y \tag{11.11b}$$

$$\varphi_2(x) = f(x) + \lambda\int_a^b K(x,y)\Big[f(y)+\lambda\int_a^b K(y,\eta)f(\eta)\,\mathrm{d}\eta\Big]\mathrm{d}y = f(x)+\lambda\int_a^b K(x,y)f(y)\,\mathrm{d}y+\lambda^2\int_a^b\!\!\int_a^b K(x,y)K(y,\eta)f(\eta)\,\mathrm{d}y\,\mathrm{d}\eta \tag{11.11c}$$

（转写文本此处有 "11.lld)" 空标签，无对应公式，见 [[queries/式11-11d空标签是否对应丢失公式]]。）

引进 $K_1(x,y)=K(x,y)$、$K_2(x,y)=\int_a^b K(x,\xi)K(\xi,y)\,\mathrm{d}\xi$，把哑元改回 y 后：

$$\varphi_2(x) = f(x)+\lambda\int_a^b K_1(x,y)f(y)\,\mathrm{d}y+\lambda^2\int_a^b K_2(x,y)f(y)\,\mathrm{d}y \tag{11.11e}$$

[[concepts/迭代核]] 递推与 n 次迭代函数的封闭形式：

$$K_n(x,y) = \int_a^b K(x,\xi)\,K_{n-1}(\xi,y)\,\mathrm{d}\xi \quad (n=2,3,\dots) \tag{11.11f}$$

$$\varphi_n(x) = f(x)+\lambda\int_a^b K_1(x,y)f(y)\,\mathrm{d}y+\dots+\lambda^n\int_a^b K_n(x,y)f(y)\,\mathrm{d}y \tag{11.11g}$$

### 2. 诺伊曼级数的收敛性

$$f(x)+\sum_{n=1}^{\infty}\lambda^n\int_a^b K_n(x,y)f(y)\,\mathrm{d}y \tag{11.12}$$

$$\vert K(x,y)\vert < M \ (a\leqslant x\leqslant b,\ a\leqslant y\leqslant b),\qquad \vert f(x)\vert < N \ (a\leqslant x\leqslant b) \tag{11.13a}$$

$$N\sum_{n=0}^{\infty}\vert\lambda M(b-a)\vert^n \tag{11.13b}$$

$$\vert\lambda\vert < \frac{1}{M(b-a)} \tag{11.13c}\qquad \vert\lambda\vert < \frac{1}{\sqrt{\int_a^b\!\!\int_a^b \vert K(x,y)\vert^2\,\mathrm{d}x\,\mathrm{d}y}} \tag{11.13d}$$

原文限定（逐字）：“对于 λ 的这个限制并不意味着对任意在由 (11.13d) 所规定的有界集合外的 λ 不存在解，而只是不能由该诺伊曼级数得到解。”

预解式与解公式：

$$\Gamma(x,y;\lambda)=\sum_{n=1}^{\infty}\lambda^{n-1}K_n(x,y) \tag{11.14a}$$

$$\varphi(x)=f(x)+\lambda\int_a^b \Gamma(x,y;\lambda)f(y)\,\mathrm{d}y \tag{11.14b}$$

### 3. 例题（K(x,y)=xy 于 [0,1]²，f(x)=x）

$$\varphi(x)=x+\lambda\int_0^1 xy\,\varphi(y)\,\mathrm{d}y$$

| n | K_n(x,y) | 复算 |
|---|---|---|
| 1 | xy | 通过 |
| 2 | xy/3 | 通过（∫₀¹ xξ·ξy dξ = xy/3；原文微分误作 dy，见 [[queries/例中K2积分微分dy应为dη]]） |
| 3 | xy/9 | 通过（归纳步 xy/3 · 1/3） |
| n | xy/3^(n−1) | 通过（归纳成立） |

$$\Gamma(x,y;\lambda)=xy\sum_{n=0}^{\infty}\frac{\lambda^n}{3^n}=\frac{xy}{1-\lambda/3},\qquad \varphi(x)=x+\lambda\int_0^1\frac{xy^2}{1-\lambda/3}\,\mathrm{d}y=\frac{x}{1-\lambda/3}$$

在 (11.13c) 限制下（|K| ≤ M = 1）诺伊曼级数对 |λ| < 1 必定收敛；预解式的几何级数甚至当 |λ| < 3 时都收敛。例中预解式符号排作 T(x,y;λ)/𝒯(x,y;λ)，与 (11.14a) 的 Γ 不一致，见 [[queries/例题预解式符号T与Γ不一致]]。

### 4. 核分解法（节末断言）

如果对于一个给定的 λ，关系式 (11.13d) 不成立，任一连续核可分解为两个连续核之和 $K(x,y)=K^1(x,y)+K^2(x,y)$，其中 $K^1$ 是[[concepts/退化核]]，$K^2$ 充分小使 (11.13d) 成立；用这种方法对不是本征值的任意 λ 也有一个明确的解法。

## 主要论断与证据强度

1. 迭代封闭形式 (11.11a)–(11.11g)：代入复算全部通过，双积分次序与 K₂ 定义自洽。强度高，见 [[findings/式11-10至11-11g迭代格式与迭代核转录复算]]。
2. 优级数收敛论证 (11.13a)–(11.13c)：由 |K| < M 归纳得 |Kₙ| ≤ Mⁿ(b−a)ⁿ⁻¹，(11.13b) 确为 (11.12) 的优级数；Weierstrass 判别给出绝对且一致收敛（“一致收敛”仅明确附着于 (11.13c) 情形）。强度高。
3. L² 界 (11.13d)：原文仅称“更精确的估计”，未给证明；xy 例中 ‖K‖²_{L²} = 1/9 ⇒ 收敛半径恰为 3，与真实收敛半径吻合，例证支持。强度中高。两者对比见 [[comparisons/诺伊曼级数两种收敛条件比较]] 与 [[findings/式11-12至11-13d诺伊曼级数两种收敛估计复算]]。
4. xy 核算例全链：Kₙ、预解式、φ 全部复算通过；解公式对一切 λ ≠ 3 成立（含 |λ| ≥ 3），精确印证“收敛域外的 λ 并非无解”。强度高，见 [[findings/xy核算例全链复算与本征值独立验证]]。
5. 核分解法：仅断言，无证明无算例；与 Fredholm 理论相符。强度中，见 [[concepts/退化核]]。
