# 数学手册(原书第10版) 18.1.3 单纯形法

本页是《数学手册(原书第10版)》18.1「线性规划」第 3 小节「单纯形法」的入库摘要。本节给出单纯形法的完整算法表述：单纯形表（18.1.3.1）、向新表的过渡与主元规则（18.1.3.2）、初始表的辅助规划/人工变量法（18.1.3.3）、修正单纯形法（18.1.3.4），以及线性规划中的对偶性（18.1.3.5）。与第 17 章各节大量出现数学家人名形成鲜明对比，本节为纯算法内容，未出现任何人名、机构名、产品名或工具名（也未提及单纯形法的提出者）。

本节全部算例均回指未入库的 18.1.2 示例问题（$\max f = 2x_1+3x_2+4x_3$，四条约束）与图 18.4 中的点 $P_5, P_6, P_7$，单纯形迭代路径为 $P_7 \to P_6 \to P_5$；回指缺口详见 [[queries/18-1-3未入库回指缺口]]。

## 核心论点

1. 单纯形法产生可行集的一列极端点，对应目标函数值单调不减；非退化情形经有限步终止（[[concepts/单纯形法]]）。
2. 规范形 (18.9a,b) 重排为单纯形表（表 18.2），$-c_0$ 置于右下端；每张表必属三情形之一（[[concepts/单纯形表]]）。
3. 主元变换 (18.16a–d) 与比值检验 (18.17) 保证 $\tilde c_0 \geqslant c_0$ 且 $\tilde{\underline b} \geqslant \underline 0$（[[concepts/主元选择与比值检验]]）。
4. 最小商不唯一 ⟺ 新表有退化极端点（凸多面体重合顶点、多基、循环风险）；可用小扰动 $\varepsilon^i$ 处理（[[concepts/退化极端点与扰动法]]）。
5. 含等式或带负 $b_i$ 的不等式时，借助人工变量构造辅助规划 (18.18) 生成初始可行表（[[concepts/人工变量与辅助规划]]）。
6. 当变量数远大于约束数（$n > 3m$）时，修正单纯形法只维护现时基逆 $A^*$，计算量相当小且精度较好（[[concepts/修正单纯形法]]）。
7. 每个线性规划问题都有对偶问题 (18.20/18.21)；对偶性定理 (18.22a–c) 给出弱对偶不等式、最优性判据、无界与不可行的对应以及互补松弛条件与解恢复方程组 (18.23)（[[concepts/线性规划对偶性]]）。

## 公式转录

### 单纯形表与规范形的对应（18.15）

$$x_{n-m+k} + a_{k,1}x_1 + \dots + a_{k,n-m}x_{n-m} = b_k, \tag{18.15a}$$

$$c_1 x_1 + \dots + c_{n-m}x_{n-m} = f(\underline{\boldsymbol x}) - c_0. \tag{18.15b}$$

### 三情形判别（每张表必属其一）

- a) $c_j \leqslant 0,\ j=1,\dots,n-m$：表最优，$(\underline{\boldsymbol x}_N,\underline{\boldsymbol x}_B)=(\underline{\boldsymbol 0},\underline{\boldsymbol b})$ 为极大点；若所有 $c_j$ 为负（转写作「正的」，疑误，见 [[queries/情形a唯一极大点cj正负之辨]]），则该顶点是唯一的极大点。
- b) 存在 $j$ 使 $c_j>0$ 且 $a_{ij}\leqslant 0\ (i=1,\dots,m)$：目标函数在可行集上无界，问题没有解。
- c) 对每个使 $c_j>0$ 的 $j$ 存在 $i$ 使 $a_{ij}>0$：可从极端点 $\underline{\boldsymbol x}$（转写作「尘」）移动到邻近极端点 $\underline{\tilde{\boldsymbol x}}$（转写作「竺」），使 $f(\underline{\tilde{\boldsymbol x}})\geqslant f(\underline{\boldsymbol x})$；在非退化极端点处「>」号总成立（转写为乱码「$^{66}>^{7}$」）。

### 主元变换与比值检验（18.16、18.17）

$$\tilde a_{pq} = \frac{1}{a_{pq}}; \tag{18.16a}$$

$$\tilde a_{pj} = a_{pj}\cdot\tilde a_{pq}\ (j\neq q),\qquad \tilde b_p = b_p\cdot\tilde a_{pq}; \tag{18.16b}$$

$$\tilde a_{iq} = -a_{iq}\cdot\tilde a_{pq}\ (i\neq p),\qquad \tilde c_q = -c_q\cdot\tilde a_{pq}; \tag{18.16c}$$

$$\tilde a_{ij} = a_{ij} + a_{pj}\cdot\tilde a_{iq}\ (i\neq p,\ j\neq q),\qquad \tilde b_i = b_i + b_p\cdot\tilde a_{iq}\ (i\neq p),$$

$$\tilde c_j = c_j + a_{pj}\cdot\tilde c_q\ (j\neq q),\qquad -\tilde c_0 = -c_0 + b_p\cdot\tilde c_q. \tag{18.16d}$$

（注：转写中 18.16d 第二式左端作 $b_i$，疑脱波浪号，应为 $\tilde b_i$。）

$$\frac{b_p}{a_{pq}} = \min_{\substack{1\leqslant i\leqslant m\\ a_{iq}>0}}\left\{\frac{b_i}{a_{iq}}\right\}. \tag{18.17}$$

（转写正文「计算商 $a_i/a_{iq}$」疑为 $b_i/a_{iq}$。）

### 辅助规划（人工变量，18.18）

$$\begin{aligned}
\mathbf{OF}^*:&& g(\underline{\boldsymbol x},\underline{\boldsymbol y}) &= -y_1-\dots-y_m = \max!\\
\mathbf{CT}^*:&& a_{1,1}x_1+\dots+a_{1,n}x_n+y_1 &= b_1,\\
&& \vdots\qquad\qquad\qquad &\ \ \vdots\\
&& a_{m,1}x_1+\dots+a_{m,n}x_n+y_m &= b_m,\\
&& x_1,\dots,x_n\geqslant 0;\quad y_1,\dots,y_m &\geqslant 0.
\end{aligned} \tag{18.18a}$$

（转写中另悬空编号「(18.18b)」，无对应内容。）

### 修正单纯形法的规范形（18.19）

$$\begin{aligned}
\mathbf{OF}:&& f(\boldsymbol x) &= c_1x_1+\dots+c_{n-m}x_{n-m}+c_0 = \max!\\
\mathbf{CT}:&& \alpha_{1,1}x_1+\dots+\alpha_{1,n-m}x_{n-m}+x_{n-m+1} &= \beta_1,\\
&& \vdots\qquad\qquad\qquad\qquad\ \vdots\qquad\qquad &\ \ \vdots\\
&& \alpha_{m,1}x_1+\dots+\alpha_{m,n-m}x_{n-m}+x_n &= \beta_m,\\
&& x_1,\dots,x_n &\geqslant 0.
\end{aligned} \tag{18.19a,b}$$

基本变量的系数向量 $\underline{\alpha}_{n-m+i}$ 是第 $i$ 个单位向量；换基只需用相应的基逆矩阵乘方程组 (18.19b)。

### 对偶性（18.20–18.23）

原始问题：

$$f(\underline{\boldsymbol x}) = \underline{\boldsymbol c}_1^{\mathrm T}\underline{\boldsymbol x}_1 + \underline{\boldsymbol c}_2^{\mathrm T}\underline{\boldsymbol x}_2 = \max! \tag{18.20a}$$

$$A_{1,1}\underline{\boldsymbol x}_1 + A_{1,2}\underline{\boldsymbol x}_2 \leqslant \underline{\boldsymbol b}_1,\quad A_{2,1}\underline{\boldsymbol x}_1 + A_{2,2}\underline{\boldsymbol x}_2 = \underline{\boldsymbol b}_2,\quad \underline{\boldsymbol x}_1\geqslant\underline{\boldsymbol 0},\ \underline{\boldsymbol x}_2\ \text{自由}. \tag{18.20b}$$

对偶问题：

$$g(\underline{\boldsymbol u}) = \underline{\boldsymbol b}_1^{\mathrm T}\underline{\boldsymbol u}_1 + \underline{\boldsymbol b}_2^{\mathrm T}\underline{\boldsymbol u}_2 = \min! \tag{18.21a}$$

$$A_{1,1}^{\mathrm T}\underline{\boldsymbol u}_1 + A_{2,1}^{\mathrm T}\underline{\boldsymbol u}_2 \geqslant \underline{\boldsymbol c}_1,\quad A_{1,2}^{\mathrm T}\underline{\boldsymbol u}_1 + A_{2,2}^{\mathrm T}\underline{\boldsymbol u}_2 = \underline{\boldsymbol c}_2,\quad \underline{\boldsymbol u}_1\geqslant\underline{\boldsymbol 0},\ \underline{\boldsymbol u}_2\ \text{自由}. \tag{18.21b}$$

对偶性定理：

$$f(\underline{\boldsymbol x}) \leqslant g(\underline{\boldsymbol u}),\quad \forall \underline{\boldsymbol x}\in M,\ \underline{\boldsymbol u}\in M^*; \tag{18.22a}$$

$$\underline{\boldsymbol x}\in M,\ \underline{\boldsymbol u}\in M^*\ \text{最优} \iff f(\underline{\boldsymbol x}) = g(\underline{\boldsymbol u}); \tag{18.22b}$$

$$\underline{\boldsymbol u}_1^{\mathrm T}(A_{1,1}\underline{\boldsymbol x}_1 + A_{1,2}\underline{\boldsymbol x}_2 - \underline{\boldsymbol b}_1) = 0,\qquad \underline{\boldsymbol x}_1^{\mathrm T}(A_{1,1}^{\mathrm T}\underline{\boldsymbol u}_1 + A_{2,1}^{\mathrm T}\underline{\boldsymbol u}_2 - \underline{\boldsymbol c}_1) = 0. \tag{18.22c}$$

由对偶最优解恢复原始最优解：

$$A_{2,1}\underline{\boldsymbol x}_1 + A_{2,2}\underline{\boldsymbol x}_2 - \underline{\boldsymbol b}_2 = \underline{\boldsymbol 0}; \tag{18.23a}$$

$$(A_{1,1}\underline{\boldsymbol x}_1 + A_{1,2}\underline{\boldsymbol x}_2 - \underline{\boldsymbol b}_1)_i = 0\ \ \text{当}\ u_i > 0; \tag{18.23b}$$

$$x_i = 0\ \ \text{当}\ (A_{1,1}^{\mathrm T}\underline{\boldsymbol u}_1 + A_{2,1}^{\mathrm T}\underline{\boldsymbol u}_2 - \underline{\boldsymbol c}_1)_i \neq 0. \tag{18.23c}$$

## 运行算例（18.1.2 示例在本节的三次使用）

**算例一（18.1.3.2，表 18.4）**：18.1.2 的规范形写成表 18.4(a)，因目标行有正系数而非最优；主列取 $x_4$ 列（亦可选 $x_3$ 列），该列唯一正元确定主行 $x_5$；逐步换基得 18.4(b)（$P_7$）、18.4(c)（$P_6$）、18.4(d)（最优，$P_5$），$\underline{\boldsymbol x}^*=(2,2,2,5,0,0,0)$，$f(\underline{\boldsymbol x}^*)=18$。

**算例二（18.1.3.3，表 18.6）**：仅第一个方程需要人工变量：

```text
OF*:  g(x, y) = −y₁ = max!
CT*:  x₁ + x₂ + x₃ − x₄ + y₁ = 1,
      x₂ + x₅ = 2,
      −x₁ + 2x₃ + x₆ = 2,
      2x₁ − 3x₂ + 2x₃ + x₇ = 2.
```

在 $g(\underline{\boldsymbol x}^*,y^*)=0$ 下表 18.6(b) 最优，略去 $y_1$ 列得原问题第一张表。

**算例三（18.1.3.4，表 18.8）**：同一规范形下先把 $x_4$ 变成基（主列 $r=\underline{\boldsymbol\alpha}_4$，初始 $A^*$ 为单位矩阵），对 $j=1,3,4$ 得 $\tilde c_j = c_j - 3\alpha_{2j}$，$(c_1,c_3,c_4)=(2,4,0)$；所得极端点 $(0,2,0,1,0,2,8)$ 即 $P_7$；下一主列 $q=3$，按上面的矩阵乘法求 $r$ 后继续。

**算例四（18.1.3.5）**：原问题与对偶问题（原问题 CT 第二条约束在转写中为空占位行，由对偶问题与表 18.6(a) 反推为 $x_2\leqslant 2$）：

```text
原问题                              对偶问题
OF:  f(x) = 2x₁+3x₂+4x₃ = max!     OF*: g(u) = −u₁+2u₂+2u₃+2u₄ = min!
CT:  −x₁−x₂−x₃ ⩽ −1,               CT*: −u₁−u₃+2u₄ ⩾ 2,
     x₂ ⩽ 2,                              −u₁+u₂−3u₄ ⩾ 3,
     −x₁+2x₃ ⩽ 2,                         −u₁+2u₃+2u₄ ⩾ 4,
     2x₁−3x₂+2x₃ ⩽ 2,                     u₁,u₂,u₃,u₄ ⩾ 0.
     x₁,x₂,x₃ ⩾ 0.
```

对偶最优解 $\underline{\boldsymbol u}^*=(0,7,2/3,4/3)$，$g(\underline{\boldsymbol u}^*)=18$；由 $(A\underline{\boldsymbol x}-\underline{\boldsymbol b})_i=0$（$u_i>0$ 处）解 $x_2=2$、$-x_1+2x_3=2$、$2x_1-3x_2+2x_3=2$ 得 $\underline{\boldsymbol x}^*=(2,2,2)$，$f(\underline{\boldsymbol x}^*)=18$。
