# 数学手册(原书第10版) 13.2.4 向量场的散度

本页对应《数学手册》(原书第10版) 第 13 章向量场理论、13.2“空间的微分算子”下的第四小节“向量场的散度”。小节以式 (13.48)–(13.56) 完整给出散度的定义（体积导数型极限）、流场中的物理意义（源与汇）、四种坐标系下的显式公式、平移旋转不变性、运算法则以及中心场的闭式结果；核心概念整理于 [[concepts/向量场的散度]]。本节体例为“只给结果、不给推导”，故未派生 methodology 页。

## 核心论断

1. **定义（13.2.4.1）**：对向量场 $\vec{V}(\vec{r})$ 可以指定一个标量场，称为该向量场的散度 (divergence)；散度被定义为向量场在点 $\vec{r}$ 处的空间导数（[[concepts/体积导数]]），即穿过闭曲面 $\Sigma$ 的通量对体积取极限 (13.48)。
2. **物理意义**：当 $\vec{V}$ 为流场 (stream field) 时，$\operatorname{div}\vec{V}$ 给出单位体积、单位时间内流经所考虑点处的流体量；$\operatorname{div}\vec{V}>0$ 的点称为源 (source)，$\operatorname{div}\vec{V}<0$ 的点称为汇 (sink)。
3. **坐标表示（13.2.4.2）**：依次给出笛卡儿 (13.49a–c)、柱面 (13.50a–b)、球面 (13.51a–b) 与“一般直角坐标系” (13.52a–d) 中的散度公式；式 (13.49c) 引入记法 $\operatorname{div}\vec{V}=\nabla\cdot\vec{V}$（$\nabla$ 为梯度算子），并断言 $\operatorname{div}\vec{V}$ 是平移和旋转不变的标量不变量（原书回指第 379 页 4.3.3.2）。
4. **运算法则（13.2.4.3）**：常向量场散度为零与线性性 (13.53)；标量–向量乘积法则 (13.54)（特例 $\operatorname{div}(\vec{r}\,\vec{c})=\vec{r}\cdot\vec{c}/r$，来源排印的 $r$ 疑漏向量箭头）；叉积散度与旋度的恒等式 (13.55)。
5. **中心场（13.2.4.4）**：$\operatorname{div}\vec{r}=3$，$\operatorname{div}(\varphi(r)\,\vec{r})=3\varphi(r)+r\varphi'(r)$ (13.56)。

## 结构化源数据（verbatim 转录）

```latex
% 13.2.4.1 散度的定义
(13.48)  \operatorname{div}\vec{V} = \lim_{V \to 0} \frac{\iint_{\Sigma} \vec{V} \cdot \mathrm{d}\vec{S}}{V}

% 13.2.4.2 不同坐标系中的散度
% 1. 笛卡儿坐标系
(13.49a) \operatorname{div}\vec{V} = \frac{\partial V_x}{\partial x} + \frac{\partial V_y}{\partial y} + \frac{\partial V_z}{\partial z}
(13.49b) \vec{V}(x,y,z) = V_x \vec{i} + V_y \vec{j} + V_z \vec{k}
(13.49c) \operatorname{div}\vec{V} = \nabla \cdot \vec{V}
%         附注：平移和旋转不变，即标量不变量（原书排印“参见第 379 4.3.3.2”，“页”字疑脱）

% 2. 柱面坐标系
(13.50a) \operatorname{div}\vec{V} = \frac{1}{\rho}\frac{\partial(\rho V_\rho)}{\partial \rho} + \frac{1}{\rho}\frac{\partial V_\varphi}{\partial \varphi} + \frac{\partial V_z}{\partial z}
(13.50b) \vec{V}(\rho,\varphi,z) = V_\rho \vec{e}_\rho + V_\varphi \vec{e}_\varphi + V_z \vec{e}_z

% 3. 球面坐标系
(13.51a) \operatorname{div}\vec{V} = \frac{1}{r^2}\frac{\partial(r^2 V_r)}{\partial r} + \frac{1}{r \sin\vartheta}\frac{\partial(\sin\vartheta\, V_\vartheta)}{\partial \vartheta} + \frac{1}{r \sin\vartheta}\frac{\partial V_\varphi}{\partial \varphi}
(13.51b) \vec{V}(r,\vartheta,\varphi) = V_r \vec{e}_r + V_\vartheta \vec{e}_\vartheta + V_\varphi \vec{e}_\varphi

% 4. “一般直角坐标系”（标题存疑，公式实为一般正交坐标系，见 queries/一般直角坐标系疑为一般正交坐标系）
(13.52a) \operatorname{div}\vec{V} = \frac{1}{D}\left\{ \frac{\partial}{\partial \xi}\left(\left|\frac{\partial \vec{r}}{\partial \eta}\right|\left|\frac{\partial \vec{r}}{\partial \zeta}\right| V_\xi\right) + \frac{\partial}{\partial \eta}\left(\left|\frac{\partial \vec{r}}{\partial \zeta}\right|\left|\frac{\partial \vec{r}}{\partial \xi}\right| V_\eta\right) + \frac{\partial}{\partial \zeta}\left(\left|\frac{\partial \vec{r}}{\partial \xi}\right|\left|\frac{\partial \vec{r}}{\partial \eta}\right| V_\zeta\right) \right\}
(13.52b) \vec{r}(\xi,\eta,\zeta) = x(\xi,\eta,\zeta)\vec{i} + y(\xi,\eta,\zeta)\vec{j} + z(\xi,\eta,\zeta)\vec{k}
(13.52c) D = \left|\left(\frac{\partial \vec{r}}{\partial \xi}\ \frac{\partial \vec{r}}{\partial \eta}\ \frac{\partial \vec{r}}{\partial \zeta}\right)\right| = \left|\frac{\partial \vec{r}}{\partial \xi}\right| \cdot \left|\frac{\partial \vec{r}}{\partial \eta}\right| \cdot \left|\frac{\partial \vec{r}}{\partial \zeta}\right|
(13.52d) \vec{V}(\xi,\eta,\zeta) = V_\xi \vec{e}_\xi + V_\eta \vec{e}_\eta + V_\zeta \vec{e}_\zeta

% 13.2.4.3 散度的运算法则
(13.53) \operatorname{div}\vec{c} = 0,\quad \operatorname{div}(\vec{V}_1 + \vec{V}_2) = \operatorname{div}\vec{V}_1 + \operatorname{div}\vec{V}_2,\quad \operatorname{div}(c\vec{V}) = c \operatorname{div}\vec{V}
(13.54) \operatorname{div}(U\vec{V}) = U \operatorname{div}\vec{V} + \vec{V} \cdot \operatorname{grad} U
%         特例（来源排印）：\operatorname{div}(r\vec{c}) = \frac{\vec{r} \cdot \vec{c}}{r}（r 疑漏向量箭头，应为 \vec{r}）
(13.55) \operatorname{div}(\vec{V}_1 \times \vec{V}_2) = \vec{V}_2 \cdot \operatorname{rot}\vec{V}_1 - \vec{V}_1 \cdot \operatorname{rot}\vec{V}_2

% 13.2.4.4 中心场的散度
(13.56) \operatorname{div}\vec{r} = 3,\quad \operatorname{div}\big(\varphi(r)\,\vec{r}\big) = 3\varphi(r) + r\varphi'(r)
```

注：式 (13.52c) 中的记号 $(\vec{a}\ \vec{b}\ \vec{c})$ 表示三个向量的混合积（标量三重积），该记号属早期向量代数章节回指，未入库。

## 复算与疑点

全部公式经解析推导复算通过，详见 [[findings/式13-48至13-56散度定义坐标系公式与运算法则转录复算]]（confidence: high）。本节唯一的实质性疑点不在公式而在术语：

1. **术语疑误（重要）**：13.2.4.2 第 4 条标题“一般直角坐标系”与公式内容不符——式 (13.52c) 的第二个等号（混合积之模等于各模长之积）仅在三个基向量相互正交时成立，且式 (13.52a) 是正交曲线坐标系散度的尺度因子通式；若按字面“一般直角（线性正交）坐标系”理解，公式应退化为 (13.49a)。故该小节实为**一般正交坐标系**，疑为原版措辞的转写讹误，见 [[queries/一般直角坐标系疑为一般正交坐标系]]。
2. **记号复用**：式 (13.48) 中 $V$ 同时表示向量场 $\vec{V}$ 与极限中的体积 $V$，属原书记号复用（与 13.2.1 体积导数定义一致），非转写错误。
3. **顺序缺口**：式 (13.54) 使用 grad、式 (13.55) 使用 rot，其定义所在小节 13.2.2（梯度）与 13.2.3（旋度）尚未入库，见 [[queries/13-2-4未入库回指缺口]]。
4. **系统性转写讹误**：正文层面存在“对千”→“对于”、“di V”→“div V”、“(diver-gence)” 连字符残留、“第 379 4.3.3.2”疑脱“页”字等问题，清单见 [[queries/13-2-4全节系统性转写讹误清单]]。
