# 数学手册(原书第10版) 7.1 数列

## 核心公式（逐字转录）

| 式号 | 内容 | 主题 |
|---|---|---|
| (7.1) | a₁, a₂, …, aₙ, … 或简记为 {aₙ}, n = 1, 2, … | 数列定义 |
| (7.2) | a₁ ⩽ a₂ ⩽ a₃ ⩽ ⋯ ⩽ aₙ ⩽ ⋯ | 单调递增 |
| (7.3) | a₁ ⩾ a₂ ⩾ a₃ ⩾ ⋯ ⩾ aₙ ⩾ ⋯ | 单调递减 |
| (7.4) | \|aₙ\| < K（对某 K > 0 的各项） | 有界（严格不等号） |
| (7.5a) | \|aₙ − A\| < ε, ∀ n > n₀(ε) | 极限的精确定义 |
| (7.5b) | aₙ > K（aₙ < −K）, ∀ n > n₀(K) | 极限为 +∞（−∞） |
| (7.6) | lim\_{n→∞} aₙ = A 或 aₙ → A | 收敛记号 |
| (7.7) | lim aₙ = ∞（aₙ > K, ∀ n > n₀）或 lim aₙ = −∞（aₙ < −K, ∀ n > n₀） | 真发散 |
| (7.8) | lim (aₙ + bₙ) = lim aₙ + lim bₙ | 和的极限（定理 a） |
| (7.9) | lim (aₙbₙ) = (lim aₙ)(lim bₙ) | 积的极限（定理 a） |
| (7.10) | lim (aₙ/bₙ) = (lim aₙ)/(lim bₙ)；条件：对每个 n 有 bₙ ≠ 0 且 lim bₙ ≠ 0 | 商的极限（定理 a） |
| (7.11) | aₙ ⩽ cₙ ⩽ bₙ（n > n₁）且 lim aₙ = lim bₙ = A ⇒ lim cₙ = A | 夹逼（定理 b，源文未命名；不等号损坏为「\~」） |

定理 c) 无式号：单调有界数列有有限极限，且极限等于最小上界／最大下界（见 [[concepts/单调有界收敛定理]]）。定理 a) 附注记（逐字）：「若 lim bₙ = 0，{aₙ} 有界，即使 {aₙ} 没有有限极限，仍有 lim (aₙbₙ) = 0」。

## A–J 十例（逐字转录）

```text
A: aₙ = n:                     1, 2, 3, 4, 5, …
B: aₙ = 4 + 3(n − 1):          4, 7, 10, 13, 16, …
C: aₙ = 3(−1/2)ⁿ⁻¹:            3, −3/2, 3/4, −3/8, 3/16, …
D: aₙ = (−1)ⁿ⁺¹:               1, −1, 1, −1, 1, …
E: aₙ = 3 − 1/2ⁿ⁻²:            1, 2, 2½, 2¾, 2⅞, …   (2¾ = 11/4)
F: n 为奇数: aₙ = 3⅓ − (1/3)·10^(−(n−1)/2)
   n 为偶数: aₙ = 3⅓ + (2/3)·10^(−n/2 + 1)
   aₙ: 3; 4; 3.3; 3.4; 3.33; 3.34; 3.333; 3.334; …
G: aₙ = 1/n:                   1, ½, ⅓, ¼, ⅕, …
H: aₙ = (−1)ⁿ⁺¹ n:             1, −2, 3, −4, 5, −6, …
I: n 为奇数: aₙ = −(n + 1)/2（源文「为奇数」前脱漏 n）
   n 为偶数: aₙ = 0
   aₙ: −1, 0, −2, 0, −3, 0, −4, 0, …
J: n 为奇数: aₙ = 3 − 1/2^(n/2 − 3/2)
   n 为偶数: aₙ = 13 − 1/2^(n/2 − 2)
   印值行（源文严重损坏，逐字）:
   "<sup>1</sup>\~,<sub>2</sub> 1 3 3 an: 1, 11, 2, 12, 2 12 2 12 2 4 4'"
```

逐项复算表明十例公式全部自洽；J 的复算值为 1, 11, 2, 12, 2½, 12½, 2¾, 12¾, …（复原假说见 [[queries/例J数列值转写损坏如何复原]]）。完整转录与复算见 [[findings/式7-1数列定义与A至J十例逐字转录]]。

## A–J 敛散性分类复算

「源文明示」指源文该句完整保留；其余为按通项公式逐项复算的推断，各论断严格绑定对应序列。

| 例 | 敛散性 | 单调性 | 有界性 |
|---|---|---|---|
| A | 真发散（→ +∞，源文明示） | 严格递增（源文明示） | 无界 |
| B | 真发散（→ +∞，源文明示） | 严格递增（源文明示） | 无界 |
| C | 收敛于 0（极限值在、字母脱漏） | 非单调 | 有界 |
| D | 假发散（字母脱漏，复算） | 非单调 | 有界（字母 D 存留） |
| E | 收敛于 3（极限值在、字母脱漏） | 严格递增（源文明示） | 有界 |
| F | 收敛于 3⅓（极限值在、字母脱漏） | 非单调 | 有界 |
| G | 收敛于 0（极限值在、字母脱漏） | 严格递减（字母脱漏，复算） | 有界 |
| H | 假发散（字母脱漏，复算） | 非单调 | 无界 |
| I | 假发散（奇子列 → −∞ 但偶项为 0，不满足 7.5b 的「一切 n」） | 非单调 | 无界 |
| J | 假发散（奇子列 → 3、偶子列 → 13，两个聚点） | 非单调 | 有界（K = 13） |

总表与判据见 [[comparisons/收敛真发散假发散三分比较]]、[[comparisons/有界与收敛关系比较]]。
