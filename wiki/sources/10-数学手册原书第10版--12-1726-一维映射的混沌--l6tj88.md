# 数学手册(原书第10版) 17.2.6 一维映射的混沌

## 概述

本节是 17.2「吸引子的量化描述」（[[sources/10-数学手册原书第10版--12-172-吸引子的量化描述--1xwtdfm]]）的子节，主题为**一维映射的混沌**：对紧区间到自身的连续映射，给出保证「存在混沌的不变集合」的若干条件，并列举三个定理——赛奈定理、沙可夫斯基定理与 Block-Guckerheimer-Misiuriewicz 定理。手册只陈述结果，不附证明。本节也是 17.2.2 熵概念（[[concepts/拓扑熵]]、[[concepts/测度熵]]）在一维情形的直接延伸：正拓扑熵在此升格为混沌判据。

## 原文逐字转录

（一切讹误原样保留，订正见下节。）

```text
对紧区间到自身的连续映射，有儿个充分条件可以保证存在混沌的不变集合．下面考虑三个例子

赛奈 {Sinai) 定理 $\varphi : I  I$ 为紧区间 $I = [ 0 , 1 ]$ 到自身的连续映射，则上系统 $\{ \varphi ^ { t } \}$ 在德瓦尼意义下是混沌的当且仅当 $\varphi$ 在 上的拓扑嫡 $h ( \varphi )$ ）是正的．

沙可夫斯基 {Sharkovsky) 定理 考虑如下方式的正整数排列：

$$3 \succ 5 \succ 7 \succ \dots \succ 2 \cdot 3 \succ 2 \cdot 5 \succ \dots \succ 2 ^ {2} \cdot 3 \succ 2 ^ {2} \cdot 5 \succ \dots \succ 2 ^ {3} \succ 2 ^ {2} \succ 2 \succ 1.\tag{17.60}$$

设 $\varphi : I  I$ 为紧区间到自身的连续映射， $\{ \varphi ^ { k } \}$ 在 上有一个 周期轨道，则对 $n \succ m$， $\{ \varphi ^ { k } \}$ 也有一个 周期轨道．

Block-Guckerheimer-Misiuriewicz 定理 $\varphi : I  I$ 为紧区间 到自身的连续映射，若 $\{ \varphi ^ { k } \}$ 有一个 $2 ^ { n } m$ 周期轨道 $( m > 1$ ，奇数），则 $h ( \varphi ) \geqslant { \frac { \ln 2 } { 2 ^ { n + 1 } } }$
```

## 三定理的订正读法

（恢复文字以〔〕标出，均为推断，须对原书核对。赛奈定理中区间取定 $I=[0,1]$，另两定理只称「紧区间」。）

**赛奈定理**：设 $\varphi: I \to I$ 为紧区间 $I=[0,1]$ 到自身的连续映射，则〔该〕系统 $\{\varphi^t\}$ 在德瓦尼意义下是混沌的，当且仅当 $\varphi$ 在〔$I$〕上的拓扑熵 $h(\varphi)$ 是正的。「当且仅当」措辞存疑，见 [[queries/赛奈定理当且仅当与德瓦尼混沌措辞之辨]]。

**沙可夫斯基定理**：按式 17.60 的沙可夫斯基序排列正整数。设 $\varphi: I \to I$ 为紧区间到自身的连续映射，$\{\varphi^k\}$ 在〔$I$〕上有一个〔$m$〕周期轨道，则对〔沙可夫斯基序中一切满足 $m \succ n$ 的 $n$〕，$\{\varphi^k\}$ 也有一个〔$n$〕周期轨道。脱落的字母与不等号方向有两种读法，见 [[queries/沙可夫斯基定理脱落周期字母与不等式方向之辨]]。

**Block-Guckerheimer-Misiuriewicz 定理**：设 $\varphi: I \to I$ 为紧区间到自身的连续映射，若 $\{\varphi^k\}$ 有一个 $2^{n} m$ 周期轨道（$m>1$，奇数），则

$$h(\varphi) \geqslant \frac{\ln 2}{2^{\,n+1}}.$$

「Guckerheimer」疑为「Guckenheimer」之转录讹，见 [[queries/Guckerheimer疑为Guckenheimer之辨]]。

## 核心主张与归属边界

- 三条定理均只针对**紧区间到自身的连续映射**（一维情形），不可移植到高维系统或流。
- 赛奈定理只断言德瓦尼混沌与拓扑熵正性的关系，不涉 [[concepts/遍历性]]、[[concepts/混合性]]（17.2.1 的测度论框架）或 [[concepts/李雅普诺夫指数]]（17.2.3）。
- 熵下界 $\ln 2/2^{\,n+1}$ 仅属 BGM 定理；周期强制仅属沙可夫斯基定理；两定理的主张不可互相转移。
- 「正熵 ⟺ 非 2 幂周期 ⟺ 混沌」的等价链是跨定理综合**推断**，非源文原话，见 [[concepts/一维映射的混沌]] 与 [[comparisons/一维映射三大混沌判据比较]]。
