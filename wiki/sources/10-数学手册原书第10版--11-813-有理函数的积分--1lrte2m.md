# 数学手册(原书第10版) 8.1.3 有理函数的积分

本页是 [[entities/数学手册原书第10版]] 第 8 章（积分学）8.1 节（不定积分）子小节 8.1.3 的来源摘要，母节来源页见 [[sources/10-数学手册原书第10版--7-81-不定积分--1fcvveq]]。本节开篇给出总纲断言：

> **有理函数的积分总可由初等函数表示。**

其依据是构造性算法而非存在性证明：化简（去公因子）→ 分离整部 → 分母分解为线性与不可约二次因式 → 提出首系数 aₙ → [[concepts/部分分式分解]]，而每一类部分分式都有初等原函数（对数、幂函数、arctan、有理函数）。主题概念见 [[concepts/有理函数的积分]]；操作流程见 [[methodology/有理函数积分五步流程]]。

**复算结论**：本节全部公式与四个算例经维护者复算**无一错误**；递推公式（式 8.18e）另经独立推导确认。这与 7.2 节式 7.70 被复算证伪的情况（[[findings/式7-70欧拉伯努利关系式复算证伪]]）形成对照。转写层面存在页码粘连与字符级损坏，不影响数学实质，系统清点见 [[queries/8-1-3全节系统性转写讹误清单]]。

## 章节结构

- **8.1.3.1 整有理函数（多项式）的积分**：逐项积分（式 8.13）。
- **8.1.3.2 分数有理函数的积分**：五步代数变换流程；分母标准分解为式 8.14a–b。
- **8.1.3.3 部分分式分解的四种情况**：按分母根的结构分四种情形（式 8.15–8.18），每种情形配一个算例。

## 核心公式（逐字转录）

多项式逐项积分（式 8.13）：

```latex
\int (a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0)\,\mathrm{d}x
= \frac{a_n}{n+1} x^{n+1} + \frac{a_{n-1}}{n} x^n + \dots + \frac{a_1}{2} x^2 + a_0 x + C
```

分母分解与不可约条件（式 8.14a–b）：

```latex
Q(x) = a_n (x-\alpha)^k (x-\beta)^l \dots (x^2+px+q)^r (x^2+p'x+q')^s \dots,
\qquad \frac{p^2}{4} - q < 0,\; \frac{p'^2}{4} - q' < 0
```

四种情形的积分公式（逐字）：

```latex
% 情形1（实单根，式8.15c–d）
A = \frac{P(\alpha)}{Q'(\alpha)},\quad \int\frac{A\,\mathrm{d}x}{x-\alpha} = A\ln|x-\alpha|
% 情形2（实重根，式8.16c）
\int\frac{A_k\,\mathrm{d}x}{(x-\alpha)^k} = -\frac{A_k}{(k-1)(x-\alpha)^{k-1}} \quad (k>1)
% 情形3（单复根，式8.17d）
\int\frac{(Cx+D)\,\mathrm{d}x}{x^2+px+q} = \frac{C}{2}\ln|x^2+px+q|
  + \frac{D - Cp/2}{\sqrt{q - p^2/4}} \arctan\frac{x + p/2}{\sqrt{q - p^2/4}}
% 情形4（多重复根，式8.18c–e）
C_m x + D_m = \frac{C_m}{2}(2x+p) + \left(D_m - \frac{C_m p}{2}\right)
\int \frac{C_m}{2}\frac{(2x+p)\,\mathrm{d}x}{(x^2+px+q)^m} = -\frac{C_m}{2(m-1)}\frac{1}{(x^2+px+q)^{m-1}}
\int\frac{\mathrm{d}x}{(x^2+px+q)^m} = \frac{x+p/2}{2(m-1)(q-p^2/4)(x^2+px+q)^{m-1}}
  + \frac{2m-3}{2(m-1)(q-p^2/4)}\int\frac{\mathrm{d}x}{(x^2+px+q)^{m-1}}
```

四种情形的完整分解形式（式 8.15b、8.16b、8.17c、8.18b）与各算例的逐步推导，见两页发现：[[findings/式8-13至8-16多项式与实根两情形及两算例复算]]、[[findings/式8-17至8-18复根两情形递推公式及两算例复算]]；四情形逐项对照见 [[comparisons/四种部分分式分解情形比较]]。

## 归属说明

- 以上论断与公式均属于手册 8.1.3 节本身。
- 式 8.15c 的 P(α)/Q′(α)（Heaviside 覆盖法型公式）隐含"单根"前提，仅在情形 1 语境下成立，不可外推至重根（重根处 Q′(α) = 0，公式失效）。
- 递推公式 8.18e 经独立推导（u = x+p/2 配平方后的标准降阶公式）确认无误。
- 本节**未发现数学错误**。

## 五步流程（8.1.3.2，校正转写脱字后的语义）

1. 用最大公因子化简，使 P(x)、Q(x) 无公因子（既约）；
2. 分离整部：若 m ≥ n，用 Q(x) 除 P(x)，得多项式整部与真分式（整部按式 8.13 积分）；
3. 将 Q(x) 分解为线性因式与二次因式之积（式 8.14a–b；手册回指 1.6.3.2，未入库）；
4. 将常系数 aₙ 提到积分号外；
5. 将真分式分解为部分分式之和（手册回指 1.1.7.3，未入库），每个部分分式都容易积分。

两处对第 1 章的回指暂无法闭合，见 [[queries/1-6-3-2与1-1-7-3未入库回指缺口]]。
