# 数学手册(原书第10版) 6.2.3 多元函数的微分法则

本页对应《数学手册(原书第10版)》第 6 章微分学中 6.2.3 小节「多元函数的微分法则」，是 [[sources/10-数学手册原书第10版--10-62-多元函数的微分--1necqq9]]（6.2 多元函数的微分）的子节。小节分两部分：**6.2.3.1 复合函数的微分**给出多元链式法则的两种形式（式 6.51–6.52）；**6.2.3.2 隐函数的微分**按"方程数 × 未知函数元数 × 自变量个数"给出六级递进的求导方法（式 6.53–6.57）。全节共 20 个子号公式标签（6.51a–6.57c，其中 6.52a 标签孤立错位）。本节入库落实了 [[queries/6-2各子小节未入库缺口]] 中的 6.2.3 一项。

## 隐函数求导的六级递进阶梯

| (1) | 1 | y(x) | x | 式 6.51b | 式 6.53a–f | 复算通过（一阶至三阶） |
| (2) | 1 | u(x₁,…,xₙ) | x₁,…,xₙ | 式 6.52b | 式 6.54a–b | 直接求导验证通过（一阶） |
| (3) | 2 | y(x), z(x) | x | 式 6.51b | 式 6.55a–c | 克莱姆法则复算通过（一阶） |

## 6.2.3.1 复合函数的微分（式 6.51–6.52）

**一元复合函数**（各中间变量是同一参数 ξ 的一元函数）：

$$u = f(x_1, x_2, \dots, x_n),\quad x_1 = x_1(\xi),\ x_2 = x_2(\xi),\ \dots,\ x_n = x_n(\xi), \tag{6.51a}$$

$$\frac{\partial u}{\partial \xi} = \frac{\partial u}{\partial x_1}\frac{\mathrm{d}x_1}{\mathrm{d}\xi} + \frac{\partial u}{\partial x_2}\frac{\mathrm{d}x_2}{\mathrm{d}\xi} + \dots + \frac{\partial u}{\partial x_n}\frac{\mathrm{d}x_n}{\mathrm{d}\xi}. \tag{6.51b}$$

**多元复合函数**（各中间变量是 ξ, η, …, τ 的多元函数；源文中 6.52a 标签孤立成行置于公式块之前，定义式与导数方程组被并入同一大括号块，以下按源文排版转录）：

$$\left. \begin{array}{c} u = f(x_1, x_2, \dots, x_n), \\ x_1 = x_1(\xi, \eta, \dots, \tau),\ x_2 = x_2(\xi, \eta, \dots, \tau),\ \dots,\ x_n = x_n(\xi, \eta, \dots, \tau), \\ \left. \begin{array}{c} \dfrac{\partial u}{\partial \xi} = \dfrac{\partial u}{\partial x_1}\dfrac{\partial x_1}{\partial \xi} + \dfrac{\partial u}{\partial x_2}\dfrac{\partial x_2}{\partial \xi} + \dots + \dfrac{\partial u}{\partial x_n}\dfrac{\partial x_n}{\partial \xi}, \\ \dfrac{\partial u}{\partial \eta} = \dfrac{\partial u}{\partial x_1}\dfrac{\partial x_1}{\partial \eta} + \dfrac{\partial u}{\partial x_2}\dfrac{\partial x_2}{\partial \eta} + \dots + \dfrac{\partial u}{\partial x_n}\dfrac{\partial x_n}{\partial \eta}, \\ \dots\ \dots \\ \dfrac{\partial u}{\partial \tau} = \dfrac{\partial u}{\partial x_1}\dfrac{\partial x_1}{\partial \tau} + \dfrac{\partial u}{\partial x_2}\dfrac{\partial x_2}{\partial \tau} + \dots + \dfrac{\partial u}{\partial x_n}\dfrac{\partial x_n}{\partial \tau} \end{array} \right\} \\ \end{array} \right.\tag{6.52b}$$

记号注记：式 6.51b 左端用偏导记号 ∂u/∂ξ，尽管此时 u 只是 ξ 的一元函数——原书记号选择，非讹误。详见 [[concepts/多元链式法则]] 与 [[findings/式6-51-6-52多元链式法则逐字转录]]。

## 6.2.3.2 隐函数的微分（式 6.53–6.57）

**(1) 单方程、一元隐函数**（"若一元函数 y = f(x) 由方程 F(x, y) = 0 给出，则利用 (6.51b) 可对 (6.53a) 进行微分"）：

$$F(x, y) = 0 \tag{6.53a}$$

$$F_x + F_y\, y' = 0, \tag{6.53b}$$

故

$$y' = -\frac{F_x}{F_y} \quad (F_y \neq 0). \tag{6.53c}$$

"用同样的方法可得 (6.53b) 的微分"：

$$F_{xx} + 2F_{xy}\, y' + F_{yy}\,(y')^2 + F_y\, y'' = 0. \tag{6.53d}$$

源文此处作"(6.53b) ，有"（脱漏动词，且引用编号疑应为 6.53d，见 [[queries/式6-53e前引用6-53b是否应为6-53d]]）：

$$y'' = \frac{2F_x F_y F_{xy} - (F_y)^2 F_{xx} - (F_x)^2 F_{yy}}{(F_y)^3}. \tag{6.53e}$$

"利用类似的方法可计算三阶导数"：

$$F_{xxx} + 3F_{xxy}\, y' + 3F_{xyy}\,(y')^2 + F_{yyy}\,(y')^3 + 3F_{xy}\, y'' + 3F_{yy}\, y' y'' + F_y\, y''' = 0, \tag{6.53f}$$

源文续作"巾此可把 y‴ 表示出来"（"巾此"为"由此"之讹）。

**(2) 单方程、多元隐函数**（u = f(x₁, x₂, …, x_i, …, xₙ) 由下式给出，"可用类似前面的方法来计算偏导数"）：

$$F(x_1, x_2, \dots, x_i, \dots, x_n, u) = 0 \tag{6.54a}$$

$$\frac{\partial u}{\partial x_1} = -\frac{F_{x_1}}{F_u},\quad \frac{\partial u}{\partial x_2} = -\frac{F_{x_2}}{F_u},\quad \dots,\quad \frac{\partial u}{\partial x_n} = -\frac{F_{x_n}}{F_u}, \tag{6.54b}$$

原文续作"但是此处将会用到 (6.52b)．按同样的方法可计算高阶导数"。

**(3) 两方程、两个一元函数**（y = f(x), z = φ(x)）：

$$F(x, y, z) = 0 \quad \text{和} \quad \Phi(x, y, z) = 0 \tag{6.55a}$$

"根据 (6.51b)，(6.55a) 的微分为"

$$F_x + F_y\, y' + F_z\, z' = 0,\quad \Phi_x + \Phi_y\, y' + \Phi_z\, z' = 0, \tag{6.55b}$$

故

$$y' = \frac{F_z \Phi_x - \Phi_z F_x}{F_y \Phi_z - F_z \Phi_y},\quad z' = \frac{F_x \Phi_y - F_y \Phi_x}{F_y \Phi_z - F_z \Phi_y}. \tag{6.55c}$$

原文续作"由 y′, z′，利用 (6.55b) 的微分，用同样的方法可计算二阶导数 y″ 和 z″"（未给显式公式）。

**(4) n 个方程、n 个一元函数**（源文开头转写脱损，作"(4) 个一元函数令 y₁ = f(x), y₂ = φ(x), ⋯, yₙ = ψ(x) 个方程"）：

$$F(x, y_1, y_2, \dots, y_n) = 0,\quad \Phi(x, y_1, y_2, \dots, y_n) = 0,\quad \dots,\quad \Psi(x, y_1, y_2, \dots, y_n) = 0 \tag{6.56a}$$

"由 (6.51b)，可得 (6.56a) 的微分"

$$\left.\begin{array}{c}
F_x + F_{y_1} y_1' + F_{y_2} y_2' + \dots + F_{y_n} y_n' = 0, \\
\Phi_x + \Phi_{y_1} y_1' + \Phi_{y_2} y_2' + \dots + \Phi_{y_n} y_n' = 0, \\
\vdots\ +\ \vdots\ +\ \vdots\ +\ \vdots\ +\ \vdots\ = 0, \\
\Psi_x + \Psi_{y_1} y_1' + \Psi_{y_2} y_2' + \dots + \Psi_{y_n} y_n' = 0
\end{array}\right\}. \tag{6.56b}$$

原文续作"(6.56b)，可得要求的导数 y₁′, y₂′, ⋯, yₙ′ 用类似的方法可计算高阶导数"（脱漏介词/动词；未给显式解）。

**(5) 两方程、两个二元函数**（u = f(x,y), v = φ(x,y)；源文"关千 x, y"为"关于"之讹）：

$$F(x, y, u, v) = 0 \quad \text{和} \quad \Phi(x, y, u, v) = 0 \tag{6.57a}$$

"利用 (6.52b)，(6.57a) 的关于 x, y 的微分为"

$$\left.\begin{array}{l}
\dfrac{\partial F}{\partial x} + \dfrac{\partial F}{\partial u}\dfrac{\partial u}{\partial x} + \dfrac{\partial F}{\partial v}\dfrac{\partial v}{\partial x} = 0, \\
\dfrac{\partial \Phi}{\partial x} + \dfrac{\partial \Phi}{\partial u}\dfrac{\partial u}{\partial x} + \dfrac{\partial \Phi}{\partial v}\dfrac{\partial v}{\partial x} = 0
\end{array}\right\} \tag{6.57b}$$

$$\left.\begin{array}{l}
\dfrac{\partial F}{\partial y} + \dfrac{\partial F}{\partial u}\dfrac{\partial u}{\partial y} + \dfrac{\partial F}{\partial v}\dfrac{\partial v}{\partial y} = 0, \\
\dfrac{\partial \Phi}{\partial y} + \dfrac{\partial \Phi}{\partial u}\dfrac{\partial u}{\partial y} + \dfrac{\partial \Phi}{\partial v}\dfrac{\partial v}{\partial y} = 0
\end{array}\right\} \tag{6.57c}$$

原文续作"分别从方程组 (6.57b) (6.57c) 中解出 ∂u/∂x, ∂v/∂x 和 ∂u/∂y, ∂v/∂y 即得一阶偏导数利用同样的方法可计算高阶偏导数"（标点脱漏；未给显式解）。

**(6) 一般情形**：源文作"(6) 个方程构成的方程组给出的 元函数 利用与前面类似的方法可计算一阶和高阶偏导数"——两处脱漏 n、整条无公式，不可复算，见 [[queries/第6条一般情形脱漏的n如何复原]]。

## 复算与验证记录

- [[findings/式6-53一元隐函数高阶导数公式复算]]：6.53d 由对 6.53b 沿曲线求导直接得出；6.53e 经代入 y′ = −F_x/F_y 逐项化简核对**完全一致**；6.53f 经全导算子 D = ∂ₓ + y′∂_y 逐项核对**完全一致**，其系数模式 (1,3,3,1) 与 [[concepts/莱布尼茨公式]] 的二项式系数同源（结构观察，非原书表述）。
- [[findings/式6-54多元隐函数偏导数公式]]：对 6.54a 逐自变量直接求导验证通过。
- [[findings/式6-55两隐函数方程组导数复算]]：用克莱姆法则解 6.55b 的 2×2 线性方程组，分子分母**完全一致**。注意：原书未使用"克莱姆法则""雅可比行列式"等名称，此为复算者所用工具（推断层面标注）。
- [[findings/式6-56n元隐函数方程组线性系统]]：仅结构验证（n×n 线性系统）。
- [[findings/式6-57两个二元隐函数偏导数方程组]]：仅方程组设定验证；原书未给显式解，**不得凭结构类推补写显式解为原文内容**。
- [[findings/临界点处式6-53e退化为负Fxx比Fy]]：跨节综合推断——临界点 F_x = 0 处 6.53e 退化为 y″ = −F_xx/F_y，可推导 [[findings/隐函数极值Fy与Fxx符号判据]]（6.1.5）的判据；原书两处均未明言此联系。

## 主张归属（严谨性边界）

各公式严格属于其所设情形：6.53e 仅属于"单方程一元隐函数"，不可移用于方程组；6.54b 属于"单方程多元隐函数"；6.55c 仅属于"两方程两一元函数"；6.57 仅有方程组设定而无显式解。条件标注不一致：6.53c 标明 (F_y ≠ 0)，而 6.54b、6.55c、6.56b 均未标分母非零条件，见 [[queries/式6-54b是否应补Fu不等于0条件]]。
