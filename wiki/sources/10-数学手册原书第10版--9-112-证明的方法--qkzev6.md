# 《数学手册(原书第10版)》1.1.2 证明的方法

## 概述

本页收录《数学手册(原书第10版)》第 1 章基础知识中小节 1.1.2 的内容，主题是数学证明的标准方法。手册将通常使用的证明方法列为三种——直接证明法、间接证明法（反证法）、数学归纳法——此外还补充了构造性证明法，并为每种方法给出定义、逻辑依据与典型例题。本节是 [[sources/10-数学手册原书第10版--9-11-基本运算法则--1yit8sw]]（1.1 基本运算法则）的后续小节，为手册后续章节（如集合论等）提供证明工具铺垫。

依据本节建立的概念页：[[concepts/直接证明法]]、[[concepts/反证法]]、[[concepts/数学归纳法]]、[[concepts/构造性证明法]]；各方法的横向比较见 [[comparisons/证明方法比较]]。

## 核心主张与结构

- **1.1.2.1 直接证明法**：从已被证明的定理（前提 $p$）出发推导新定理（结论 $q$）；最常用的逻辑步骤是蕴涵（implication）与等价（equivalence），据此分为借助蕴涵与借助等价两个子型。
- **1.1.2.2 间接证明法或反证法**：从否命题 $\bar{q}$ 出发导出假命题 $r$（即 $\bar{q} \Rightarrow r$），从而 $\bar{q}$ 为假、$q$ 为真。
- **1.1.2.3 数学归纳法**：证明依赖于自然数 $n$ 的定理；分归纳基础与归纳步骤，共四个步骤。
- **1.1.2.4 构造性证明法**：存在性定理的证明通常就是给出一个构造程序，即给出计算满足该存在性定理的解的方法。

## 例题与证明（保留原文推导）

### 例 1：借助蕴涵的直接证明——二元算术–几何平均不等式

证明 $\frac{a+b}{2} \geqslant \sqrt{ab}$，此处 $a > 0, b > 0$。前提是众所周知的二项式公式 $(a+b)^{2} = a^{2} + 2ab + b^{2}$。两边同减 $4ab$ 得到 $(a+b)^{2} - 4ab = (a-b)^{2} \geqslant 0$。如果仅限于正方根，因为 $a > 0, b > 0$，由上式即可获得结论命题。

### 例 2：借助等价的直接证明——几何级数部分和上界

证明 $1 + a + a^2 + \cdots + a^n < \frac{1}{1 - a}$，此处 $0 < a < 1$。以 $1-a$ 乘 $1+a+a^{2}+\cdots+a^{n}$ 得 $1-a+a-a^{2}+a^{2}-a^{3}\pm\cdots+a^{n}-a^{n+1}=1-a^{n+1}<1$。由假设 $0<a^{n+1}<1$，因此最后这个不等式成立。因为所有用到的算术运算皆唯一可逆，所要证明的不等式也成立。

### 例 3：反证法——$\sqrt{2}$ 是无理数

假设 $\sqrt{2}$ 是有理数，则等式 $\sqrt{2} = \frac{a}{b}$ 成立，$a, b$ 是整数且 $b \neq 0$。设 $a, b$ 互素（没有任何公因数），则可得 $\sqrt{2}^2 = 2 = \frac{a^2}{b^2}$ 或 $a^2 = 2b^2$，从而 $a^2$ 是一个偶数，但这仅当 $a = 2n$ 为偶数时才能成立。由此推得 $a^2 = 4n^2 = 2b^2$，因此 $b$ 也应为偶数。这显然与 $a, b$ 互素之假设相矛盾。

### 例 4：数学归纳法——裂项求和公式

命题：$s_n = \frac{1}{1 \cdot 2} + \frac{1}{2 \cdot 3} + \frac{1}{3 \cdot 4} + \cdots + \frac{1}{n(n+1)} = \frac{n}{n+1}$。

手册给出的归纳证明四步程序（步骤编号沿用原文）：

1. 归纳的基础：证明命题对 $n = n_0$ 成立，在多数情况下可以选取 $n_0 = 1$。本例 $n=1$ 时 $s_1 = \frac{1}{1 \cdot 2} = \frac{1}{1+1}$，公式显然成立。
2. 归纳假设：设命题对某个整数 $n$ 成立（前提 $p$）。
3. 归纳结论：形成对 $n+1$ 的命题（结论 $q$），本例即证 $s_{n+1} = \frac{n+1}{n+2}$。
4. 蕴涵证明：$p \Rightarrow q$。（步骤 (3)、(4) 一起称为归纳步骤，或从 $n$ 到 $n+1$ 的逻辑演绎。）

原文推导：

```
s_{n+1} = 1/(1·2) + 1/(2·3) + 1/(3·4) + … + 1/(n(n+1)) + 1/((n+1)(n+2))
        = s_n + 1/((n+1)(n+2))
        = n/(n+1) + 1/((n+1)(n+2))
        = (n² + 2n + 1)/((n+1)(n+2))
        = (n+1)²/((n+1)(n+2))
        = (n+1)/(n+2)
```

### 例 5：构造性证明法——三阶样条插值函数的存在性

三阶样条插值函数（参见手册第 1293 页 19.7.1.1）的存在性可以证明如下：证明满足存在性定理要求的样条函数的系数计算结果得到一个三对角的线性方程组，而该方程组有唯一解（参见第 1295 页 19.7.1.2）。注意：此为本节中的**引用级**论断，实质内容属于手册 19.7，本节未展开。

## 内部张力与采信说明

- **分类框架（"三加一"）**：正文先称"通常使用的证明方法有以下三种"，随后又补充构造性证明法。本 Wiki 相关页面按"三种标准方法 + 构造性证明法"表述，不把构造性证明法并入三种。
- **反证法原理表述不严谨**：原文"根据蕴涵法由假的假设必定推出假结论"在逻辑上不成立（假前提可推出任意结论）。严格依据是：蕴涵式 $\bar{q} \Rightarrow r$ 已被证明为真且 $r$ 为假，故前件 $\bar{q}$ 必假（否定后件式）。疑为翻译措辞问题；[[concepts/反证法]] 采用严格表述，未直接采信原文。
- **隐含前提**：例 2 中"所有算术运算唯一可逆"实际依赖 $1 - a > 0$（除以正数不改变不等号方向），原文未显式点明。
