# 数学手册(原书第10版) 1.1.3 和与积

《数学手册(原书第10版)》1.1.3 节"和与积"是纯定义性、规则性的内容，分两部分：1.1.3.1 以公式 (1.8) 定义求和号 $\sum$ 并给出六条计算法则 (1.9a–1.9f)；1.1.3.2 以公式 (1.10) 定义求积号 $\prod$ 并给出六条平行法则 (1.11a–1.11f)。公式编号 (1.8)–(1.11f) 是手册内部的引用锚点，本页完整保留全部编号与公式原文，已按勘误修正处另行标注。

## 1.1.3.1 和

**定义**：使用求和号 $\sum$ 缩写一个和

$$
a_1 + a_2 + \dots + a_n = \sum_{k=1}^{n} a_k.\tag{1.8}
$$

借助这一符号可以表示 $n$ 个被加项 $a_k\ (k=1,2,\dots,n)$ 的和，$k$ 称为变动指标或求和变量。

**计算法则**：

| 编号 | 法则 | 公式 |
|---|---|---|
| (1.9a) | 相等各项（$a_k = a$）之和 | $\sum_{k=1}^{n} a_k = na$ |
| (1.9b) | 各项与一常数相乘 | $\sum_{k=1}^{n} c\,a_k = c \sum_{k=1}^{n} a_k$ |
| (1.9c) | 分部求和 | $\sum_{k=1}^{n} a_k = \sum_{k=1}^{m} a_k + \sum_{k=m+1}^{n} a_k \quad (1 < m < n)$ |
| (1.9d) | 相同长度的和相加 | $\sum_{k=1}^{n} (a_k + b_k + c_k + \dots) = \sum_{k=1}^{n} a_k + \sum_{k=1}^{n} b_k + \sum_{k=1}^{n} c_k + \dots$ |
| (1.9e) | 重新编号 | $\sum_{k=1}^{n} a_k = \sum_{k=m}^{m+n-1} a_{k-m+1}$；$\sum_{k=m}^{n} a_k = \sum_{k=l}^{n-m+l} a_{k+m-l}$ |
| (1.9f) | 双重和中变换求和次序 | $\sum_{i=1}^{n} \left(\sum_{k=1}^{m} a_{ik}\right) = \sum_{k=1}^{m} \left(\sum_{i=1}^{n} a_{ik}\right)$ |

## 1.1.3.2 积

**定义**：积的缩写记号是求积号 $\prod$

$$
a_1 a_2 \cdots a_n = \prod_{k=1}^{n} a_k.\tag{1.10}
$$

借助这一符号可以表示 $n$ 个因子 $a_k\ (k=1,2,\dots,n)$ 的积，$k$ 称为变动指标。

**计算法则**（(1.11c) 左侧已按勘误修正，见下节）：

| 编号 | 法则 | 公式 |
|---|---|---|
| (1.11a) | 重合因子（$a_k = a$）之积 | $\prod_{k=1}^{n} a_k = a^{n}$ |
| (1.11b) | 各因子乘以一常数 | $\prod_{k=1}^{n} (c\,a_k) = c^{n} \prod_{k=1}^{n} a_k$ |
| (1.11c) | 分部求积 | $\prod_{k=1}^{n} a_k = \left(\prod_{k=1}^{m} a_k\right) \left(\prod_{k=m+1}^{n} a_k\right) \quad (1 < m < n)$ |
| (1.11d) | 乘积的积 | $\prod_{k=1}^{n} a_k b_k c_k \dots = \left(\prod_{k=1}^{n} a_k\right) \left(\prod_{k=1}^{n} b_k\right) \left(\prod_{k=1}^{n} c_k\right) \dots$ |
| (1.11e) | 重新编号 | $\prod_{k=1}^{n} a_k = \prod_{k=m}^{m+n-1} a_{k-m+1}$；$\prod_{k=m}^{n} a_k = \prod_{k=l}^{n-m+l} a_{k+m-l}$ |
| (1.11f) | 双重积中变换求积次序 | $\prod_{i=1}^{n} \left(\prod_{k=1}^{m} a_{ik}\right) = \prod_{k=1}^{m} \left(\prod_{i=1}^{n} a_{ik}\right)$ |

## 勘误记录

1. **(1.11c) 疑似排印错误（重要）**：原文左侧作 $\prod_{k=1}^{n} a^{k}$（上标 $k$），而同式右侧以及 (1.11a/b/d/e/f) 均用下标 $a_k$。若左侧按字面理解为幂，其值为 $a^{1+2+\dots+n} = a^{n(n+1)/2}$，等式一般不成立。故判定左侧为排版/转录错误，正确形式应为 $\prod_{k=1}^{n} a_{k}$；本页与 [[求积号]] 均按修正后的形式收录。
2. (1.9c)、(1.11c) 中条件 $(1 < m < n)$ 在原文中存在多余空格，属转录格式瑕疵，不影响内容。

## 结构性发现：Σ 与 Π 的对偶

两套法则逐条平行：定义↔定义、相等各项↔重合因子、分部求和↔分部求积、相同长度的和相加↔乘积的积、重新编号↔重新编号、双重和换序↔双重积换序。系统性差异仅两处：

1. 常数法则：和中提取一个 $c$（1.9b），积中提出 $c^{n}$（1.11b），因为常数因子在 $n$ 个因子中各出现一次；
2. 求积记号下不存在与 (1.9d)（把一个和逐项拆成多个和）直接对应的"加法拆分"类似物，(1.11d) 对应的是因子分组。

这一对偶结构源于对数函数把积映射为和。两套法则形式平行但不可跨记号挪用，例如不能把 (1.9b) 的提取 $c$ 直接搬到积的场合。

## 证据与证明状态
