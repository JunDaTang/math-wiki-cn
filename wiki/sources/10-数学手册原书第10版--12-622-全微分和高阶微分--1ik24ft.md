# 数学手册(原书第10版) 6.2.2 全微分和高阶微分

## 公式逐字转录

以下按源文顺序转录式 6.41–6.50（LaTeX，仅规整排版空格；样式性讹误在讹误清单中注明）。

### 6.2.2.1.1 可微性（式 6.41）

全增量：

```latex
\begin{array}{c}
\Delta u = f(x_{10} + \Delta x_1, x_{20} + \Delta x_2, \dots, x_{i0} + \Delta x_i, \dots, x_{n0} + \Delta x_n) \\
 - f(x_{10}, x_{20}, \dots, x_{i0}, \dots, x_{n0})
\end{array} \tag{6.41a}
```

所有变量的偏微分之和：

```latex
\left(\frac{\partial u}{\partial x_1}\,\mathrm{d}x_1 + \frac{\partial u}{\partial x_2}\,\mathrm{d}x_2 + \dots + \frac{\partial u}{\partial x_n}\,\mathrm{d}x_n\right)_{x_{10}, x_{20}, \dots, x_{n0}} \tag{6.41b}
```

距离（$\Delta x_i$ 与 $\mathrm{d}x_i$ 通用）：

```latex
\overline{P_0 P} = \sqrt{\Delta x_1^2 + \Delta x_2^2 + \cdots + \Delta x_n^2} = \sqrt{\mathrm{d}x_1^2 + \mathrm{d}x_2^2 + \cdots + \mathrm{d}x_n^2} \tag{6.41c}
```

定义：多元函数在 $P_0$ 可微，当且仅当全增量 (6.41a) 与偏微分之和 (6.41b) 相差为距离 (6.41c) 的高阶无穷小。附随论断（关于偏导数连续性条件，非关于全微分本身）：若多元函数的偏导数作为多元函数在一点的邻域内连续，则函数在该点可微——这是可微的**充分非必要**条件；且即使偏导数在一点存在，函数在该点也未必连续。

### 6.2.2.1.2 全微分与梯度（式 6.42）

若 $u$ 为可微函数，则和式 (6.41b) 称为函数的**全微分**：

```latex
\mathrm{d}u = \frac{\partial u}{\partial x_1}\,\mathrm{d}x_1 + \frac{\partial u}{\partial x_2}\,\mathrm{d}x_2 + \dots + \frac{\partial u}{\partial x_n}\,\mathrm{d}x_n. \tag{6.42a}
```

n 维向量（梯度）与微分向量：

```latex
\mathbf{grad}\,u = \left(\frac{\partial u}{\partial x_1}, \frac{\partial u}{\partial x_2}, \dots, \frac{\partial u}{\partial x_n}\right)^{\mathrm{T}}, \tag{6.42b}
```

```latex
\mathbf{d}\boldsymbol{r} = (\mathrm{d}x_1, \mathrm{d}x_2, \dots, \mathrm{d}x_n)^{\mathrm{T}}, \tag{6.42c}
```

则全微分可以表示为标量积：

```latex
\mathrm{d}\boldsymbol{u} = (\mathbf{grad}\,\boldsymbol{u})^{\mathrm{T}} \cdot \mathbf{d}\boldsymbol{r}. \tag{6.42d}
```

源文注：(6.42b) 中含 n 个变元的向量为**梯度**，其定义见第 926 页 13.2.2（未入库）。式 6.42d 的粗体 d**u** 疑为转写讹误（du 为标量）。

### 6.2.2.1.3 几何表示：切平面（式 6.43，图 6.15）

二元函数 $u = f(x,y)$ 在笛卡儿坐标系中表示一曲面；若 dx, dy 是 x, y 的增量，则 du 等于切平面（在同一点）竖坐标（前引第 281 页 3.5.3.1）的增量。由泰勒公式（前引第 602 页 6.2.2.3, 1.）：

```latex
f(x, y) = f(x_0, y_0) + \frac{\partial f}{\partial x}(x_0, y_0)(x - x_0) + \frac{\partial f}{\partial y}(x_0, y_0)(y - y_0) + R_1, \tag{6.43a}
```

忽略掉余项 $R_1$：

```latex
u = f(x_0, y_0) + \frac{\partial f}{\partial x}(x_0, y_0)(x - x_0) + \frac{\partial f}{\partial y}(x_0, y_0)(y - y_0), \tag{6.43b}
```

它给出了曲面 $u = f(x,y)$ 在点 $P_0(x_0, y_0, z_0)$ 的切平面方程。

### 6.2.2.1.4 全微分的基本性质（无编号陈述）

与一元函数中的公式 (6.38) 类似，全微分关于自变量也具有微分形式不变性。式 (6.38) 位于 6.1.6（未入库）；**该性质仅属一阶全微分**，不可外推至高阶微分（见 6.2.2.2.2）。

### 6.2.2.1.5 在误差计算中的应用（式 6.44）

在误差计算中，常常使用全微分 du 作为 $\Delta u$（参见 (6.41a)）的误差估计（具体例子前引第 1111 页 16.4.1.3, 5.，未入库）。由泰勒公式：

```latex
|\Delta u| = |\mathrm{d}u + R_1| \leqslant |\mathrm{d}u| + |R_1| \approx |\mathrm{d}u|, \tag{6.44}
```

即绝对误差 $|\Delta u|$ 可用 $|\mathrm{d}u|$ 作初步近似，du 是 $\Delta u$ 的线性近似。

### 6.2.2.2.1 二阶偏导数与施瓦茨交换定理（式 6.45）

二阶偏导数分两种：对同一个变量的（如 $\partial^2 u/\partial x_1^2$, $\partial^2 u/\partial x_2^2$, …；源文此处末项转写损坏，疑应为 $\partial^2 u/\partial x_n^2$）与对两个变量的混合偏导数（如 $\partial^2 u/\partial x_1\partial x_2$ 等）。若在一点混合偏导数连续，则对微分次序中独立的 $x_1, x_2$，有

```latex
\frac{\partial^2 u}{\partial x_1\,\partial x_2} = \frac{\partial^2 u}{\partial x_2\,\partial x_1} \quad (\text{施瓦茨交换定理}). \tag{6.45}
```

类似地可定义高阶偏导数，如 $\partial^3 u/\partial x_1^3$, $\partial^3 u/\partial x\,\partial y^2$, …

### 6.2.2.2.2 一元二阶微分的适用限制（陈述）

一元函数 $y = f(x)$：$\mathrm{d}^2 y = \mathrm{d}(\mathrm{d}y) = f''(x)\,\mathrm{d}x^2$ **仅当 x 为自变量时**才适于采用；若以 $x = z(v)$ 的形式给出，上述符号就不再适用。变元本身是其他变元的函数时的一般公式见第 606 页 6.2.4（未入库）。

### 6.2.2.2.3–5 高阶全微分（式 6.46–6.48）

```latex
\mathrm{d}^2 u = \mathrm{d}(\mathrm{d}u) = \frac{\partial^2 u}{\partial x^2}\,\mathrm{d}x^2 + 2\,\frac{\partial^2 u}{\partial x\,\partial y}\,\mathrm{d}x\,\mathrm{d}y + \frac{\partial^2 u}{\partial y^2}\,\mathrm{d}y^2, \tag{6.46a}
```

或象征性地写为

```latex
\mathrm{d}^2 u = \left(\frac{\partial}{\partial x}\,\mathrm{d}x + \frac{\partial}{\partial y}\,\mathrm{d}y\right)^2 u, \tag{6.46b}
```

```latex
\mathrm{d}^n u = \left(\frac{\partial}{\partial x}\,\mathrm{d}x + \frac{\partial}{\partial y}\,\mathrm{d}y\right)^n u, \tag{6.47}
```

```latex
\mathrm{d}^n u = \left(\frac{\partial}{\partial x_1}\,\mathrm{d}x_1 + \frac{\partial}{\partial x_2}\,\mathrm{d}x_2 + \dots + \frac{\partial}{\partial x_m}\,\mathrm{d}x_m\right)^n u. \tag{6.48}
```

### 6.2.2.3 多元函数的泰勒定理（式 6.49–6.50）

第一种表示形式（中心 $(a,b)$）：

```latex
f(x, y) = f(a, b) + \frac{\partial f(x, y)}{\partial x}\Bigg|_{(x,y)=(a,b)} (x - a) + \frac{\partial f(x, y)}{\partial y}\Bigg|_{(x,y)=(a,b)} (y - b)
```

```latex
\begin{array}{l}
+ \frac{1}{2!} \left\{ \frac{\partial^2 f(x, y)}{\partial x^2}\Big|_{(x,y)=(a,b)} (x-a)^2 + 2\,\frac{\partial^2 f(x, y)}{\partial x\,\partial y}\Big|_{(x,y)=(a,b)} (x-a)(y-b) \right. \\
+ \left. \frac{\partial^2 f(x, y)}{\partial y^2} \right|_{(x,y)=(a,b)} (y-b)^2 \Bigg\} + \frac{1}{3!}\{\dots\} + \dots + \frac{1}{n!}\{\dots\} + R_n,
\end{array} \tag{6.49a}
```

简写符号约定：把 $\frac{\partial f(x,y)}{\partial x}\Big|_{(x,y)=(x_0,y_0)}$ 简记为 $\frac{\partial f}{\partial x}(x_0, y_0)$。算子记号简写：

```latex
\begin{array}{rl}
& f(x, y) = f(a, b) + \frac{1}{1!} \bigg\{ (x-a)\frac{\partial}{\partial x} + (y-b)\frac{\partial}{\partial y} \bigg\} f(x, y) \bigg|_{(x,y)=(a,b)} \\
& \quad + \frac{1}{2!} \bigg\{ (x-a)\frac{\partial}{\partial x} + (y-b)\frac{\partial}{\partial y} \bigg\}^{2} f(x, y) \bigg|_{(x,y)=(a,b)} \\
& \quad + \frac{1}{3!} \{\dots\}^{3} f(x, y) \bigg|_{(x,y)=(a,b)} + \dots + \frac{1}{n!} \{\dots\}^{n} f(x, y) \bigg|_{(x,y)=(a,b)} + R_n.
\end{array} \tag{6.49b}
```

源文对算子记号语义的明说（转写讹误已校正）：利用二项式定理后微分符 $\frac{\partial}{\partial x}, \frac{\partial}{\partial y}$ 的幂表示函数 $f(x,y)$ 的高阶导数，然后让导数在点 $(a,b)$ 取值。第二种表示形式与余项：

```latex
\begin{array}{l}
f(x+h, y+k) = f(x, y) + \frac{1}{1!}\left(\frac{\partial}{\partial x}h + \frac{\partial}{\partial y}k\right) f(x, y) + \frac{1}{2!}\left(\frac{\partial}{\partial x}h + \frac{\partial}{\partial y}k\right)^{2} f(x, y) \\
\quad + \frac{1}{3!}\left(\frac{\partial}{\partial x}h + \frac{\partial}{\partial y}k\right)^{3} f(x, y) + \dots \\
\quad + \frac{1}{n!}\left(\frac{\partial}{\partial x}h + \frac{\partial}{\partial y}k\right)^{n} f(x, y) + R_n.
\end{array} \tag{6.49c}
```

```latex
R_n = \frac{1}{(n+1)!}\left(\frac{\partial}{\partial x}h + \frac{\partial}{\partial y}k\right)^{n+1} f(x+\Theta h,\, y+\Theta k) \quad (0 < \Theta < 1). \tag{6.49d}
```

m 元推广：

```latex
f(x+h, y+k, \dots, t+l) = f(x, y, \dots, t) + \sum_{i=1}^{n} \frac{1}{i!} \left(\frac{\partial}{\partial x}h + \frac{\partial}{\partial y}k + \dots + \frac{\partial}{\partial t}l\right)^{i} f(x, y, \dots, t) + R_n, \tag{6.50a}
```

```latex
\begin{array}{l}
R_n = \frac{1}{(n+1)!}\left(\frac{\partial}{\partial x}h + \frac{\partial}{\partial y}k + \dots + \frac{\partial}{\partial t}l\right)^{n+1} \\
\times f(x+\Theta h,\, y+\Theta k,\, \dots,\, t+\Theta l) \quad (0 < \Theta < 1).
\end{array} \tag{6.50b}
```
