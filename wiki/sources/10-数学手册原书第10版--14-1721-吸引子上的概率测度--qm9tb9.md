# 数学手册(原书第10版) 17.2.1 吸引子上的概率测度

## 定位与覆盖范围

本节是手册第 17 章由几何定性理论（17.1.x 谱系，见 [[sources/10-数学手册原书第10版--9-1711-动力系统--gads4o]]、[[sources/10-数学手册原书第10版--11-1713-离散动力系统--mieej8]]）迈向统计动力学与遍历理论的入口：先在[[concepts/吸引子]]上建立[[concepts/不变测度]]与[[concepts/自然测度]]，再依次引入[[concepts/遍历性]]、[[concepts/伯克霍夫遍历定理]]、[[concepts/SRB测度]]、[[concepts/混合性]]、[[concepts/自相关函数]]、[[concepts/功率谱]]、[[concepts/拓扑熵]]与[[concepts/测度熵]]，构成「几何吸引子 → 概率刻画 → 熵度量」的完整链条。

范围上有两点须注意：其一，文件名义为 17.2.1，实际内容跨至 17.2.2（17.2.2.1 拓扑熵、17.2.2.2 测度熵）；其二，「17.2.2」节标题本身脱文，按内容推断应为「熵」（见 [[queries/17-2-2节标题脱文之辨]]）。

## 核心公式保真转录

```latex
% ---- 17.2.1.1 不变测度 ----
% 不变测度定义（可逆系统有等价形式）
mu(phi^{-t}(A)) = mu(A)  (A in Borel, t > 0);  可逆时等价于 mu(phi^{t}(A)) = mu(A)

% (17.28a) 伯努利转移映射（倍增映射）
x_{l+1} = 2 x_l (mod 1)
% (17.28b)
phi(x) = { 2x,  0 <= x <= 1/2 ;  2x-1,  1/2 < x <= 1 }

% (17.29) 帐篷映射
Psi(y) = { 2y,  0 <= y < 1/2 ;  2(1-y),  1/2 <= y <= 1 }

% 逻辑斯谛映射 alpha=4 的共轭与不变密度
h(x) = (2/pi)*arcsin(sqrt(x)),   rho(x) = 1/(pi*sqrt(x(1-x)))
% 密度变换公式（源文脱导数撇号）
rho_1(y) = rho(h^{-1}(y)) * |(h^{-1})'(y)|

% 可逆离散系统稳定周期点（周期 T）的自然测度（狄拉克测度平均）
mu = (1/T) * sum_{i=0}^{T-1} delta_{phi^{i}(x_0)}

% (17.30) 自然测度
mu(A; x_0) := lim_{T->infty} t(T, A, x_0)/T

% ---- 17.2.1.2 遍历论基础 ----
% (17.31) 圆周旋转映射
x_{t+1} = x_t + Phi (mod 2 pi),  t = 0, 1, ...

% (17.32a) SRB 判据（源文衍 "d t"）
lim_{n->+infty} (1/n) * sum_{i=0}^{n-1} h(phi^{i}(x_0)) = int_M h d mu
% (17.32b) 经验测度
mu_n := (1/n) * sum_{i=0}^{n-1} delta_{phi^{i}(x)}

% (17.33) 流的混合（L^2 形式）
lim_{t->+infty} int_M [g(phi^{t}(x)) - g_bar][h(x) - h_bar] d mu = 0

% (17.34a/b) 自相关函数
C_h(tau) = lim_{T->infty} (1/T) int_0^T h(phi^{t+tau}(x)) h(phi^{t}(x)) dt - h_bar^2
C_h(tau) = lim_{n->infty} (1/n) sum_{i=0}^{n-1} h(phi^{i+tau}(x)) h(phi^{i}(x)) - h_bar^2

% (17.35a/b) 功率谱（源文 "2 _0^{i n f t y}" 为 "2 int_0^infty" 之讹）
P_h(omega) = int_{-infty}^{+infty} C_h(tau) e^{-i omega tau} d tau = 2 int_0^infty C_h(tau) cos(omega tau) d tau
P_h(omega) = C_h(0) + 2 * sum_{k=1}^{+infty} C_h(k) cos(omega k)

% 周期轨（omega_0 = 2 pi / T，时间平均为 0 的试验函数）
C_h(tau) = sum_k |alpha_k|^2 cos(k omega_0 tau),   P_h(omega) = 2 pi sum_k |alpha_k|^2 delta(omega - k omega_0)
% 拟周期轨（双基本频率）
C_h(tau) = sum_{k1,k2} |alpha_{k1 k2}|^2 cos((k1 omega_1 + k2 omega_2) tau)
P_h(omega) = 2 pi sum_{k1,k2} |alpha_{k1 k2}|^2 delta(omega - k1 omega_1 - k2 omega_2)

% ---- 17.2.2 熵 ----
% (17.36) n 步距离
rho_n(x, y) := max_{0<=i<=n} rho(phi^{i}(x), phi^{i}(y))
% 拓扑熵（N(eps, rho_n) 为 rho_n 意义下两两 eps-分离点集的最大基数）
h(phi) = lim_{eps->0} lim_{n->infty} (1/n) ln N(eps, rho_n)
% (17.37) 长度 N 符号序列的信息量
H_N = - sum_{(i_1,...,i_N)} p(i_1,...,i_N) ln p(i_1,...,i_N)
% 柯尔莫哥洛夫—赛奈熵
h_mu = lim_{eps->0} lim_{N->infty} H_N/(tau N)

% 熵的性质
h(phi^n) = n h(phi);  同胚时 h(phi^k) = |k| h(phi) (k in Z);  流取 h(phi^t) := h(phi^1)
h_mu <= h(phi) 恒成立；某些情形下 h(phi) = sup{ h_mu : mu 为支撑在吸引子上的概率测度 }
```

## 主要论断与复算结论（各主张严格归属其主体）

1. **[[concepts/伯努利转移映射]] (17.28)**：勒贝格测度不变；二进制表示下为数字左移去首位；是混合的；$h(\varphi)=h_\mu=\ln 2$。独立复算成立（两支各以斜率 2 均匀拉伸并映满；移位解释显然；ln 2 为标准结果）。证据：强。
2. **[[concepts/帐篷映射]] (17.29)**：勒贝格测度不变。两支斜率 ±2，复算成立。证据：强。
3. **[[concepts/逻辑斯谛映射]]（α=4）**：经 $h(x)=\frac{2}{\pi}\arcsin\sqrt{x}$ 共轭于帐篷映射，不变密度 $\rho(x)=\frac{1}{\pi\sqrt{x(1-x)}}$，满足密度变换公式。独立复算发现恒等式 $h'(x)=\rho(x)$，代入变换公式恰得 $\rho_1\equiv 1$，自洽闭环。证据：强。
4. **可逆离散系统的稳定周期点**：$\mu=\frac{1}{T}\sum_{i=0}^{T-1}\delta_{\varphi^i(x_0)}$ 为遍历自然测度；稳定平衡点 $h_\mu=0$。直接验证成立。证据：强。
5. **[[concepts/圆周旋转映射]] (17.31)**：$\lambda/2\pi$ 为不变概率测度；$\Phi/2\pi$ 无理 ⟹ 遍历，数学正确。但源文另断言其「**是混合的**」——旋转为等距映射，相关函数不衰减，绝不混合，判定为脱「不」字讹误（见 [[queries/旋转映射是混合的疑脱不字之辨]]，最高优先），且与本节「$C_h$ 指数衰减 ⟹ 混合」判据自相矛盾。
6. **[[concepts/埃农映射|埃农吸引子]]**：SRB 测度存在性「已被证明」（手册转述，SRB 命名引 [17.6]）。权威转述，证据：中（未给出处细节）。
7. **[[concepts/SRB测度]]**（17.32a/b 两种刻画）、**混合 ⟹ 遍历**（$\mu(A)^2=\mu(A)$ 论证）、**紧致度量空间同胚离散系统恒有遍历不变测度**（未具名的 Krylov–Bogolyubov 型结论）——均为标准结果，表述正确（个别文字讹误）。证据：强。
8. **谱型判据**：周期 → 等距脉冲；拟周期 → 基本频率整系数线性组合脉冲；宽带 → 混沌标志（源句「在宽带谱中出现奇异峰值」疑有脱讹）。周期轨与拟周期轨的 $C_h$、$P_h$ 公式复算成立（利用实值性 $|\alpha_{-k}|=|\alpha_k|$，虚部成对消去得 cos 形式）。证据：强。
9. **[[concepts/拓扑熵]]**：共轭不变、$h(\varphi^n)=nh(\varphi)$、流取 $h(\varphi^1)$；**[[concepts/测度熵]]**：$h_\mu\le h(\varphi)$ 恒成立，「某些情形」$h(\varphi)=\sup h_\mu$（变分原理，措辞偏保守，见 [[queries/变分原理在某些情形下措辞之辨]]）。证据：强。
