# 数学手册(原书第10版) 15.2.3 使用拉普拉斯变换求解微分方程

## 内容概要

本小节是手册 15.2 [[concepts/拉普拉斯变换]] 部分的应用篇，沿三条方法线展开：

1. **15.2.3.1 常系数线性常微分方程**：借助导数计算法则，把初值问题 (15.47a) 连同初始条件一次性化为像空间的代数方程 (15.47b)；其分母即 [[concepts/特征方程]] G(p)=0 的多项式。按一阶、二阶（三种判别情形）、n 阶单根情形分层给出解法，并配一个完整算例。
2. **15.2.3.2 变系数线性常微分方程**：当系数是 t 的多项式时，用 (15.16)（L{t·f} = −F′(p)）在像空间得到阶数更低的方程；零阶 [[concepts/贝塞尔微分方程]] 由此化为像空间一阶可分离方程，解出 F(p) = C/√(p²+1)。
3. **15.2.3.3 偏微分方程**：拉普拉斯变换只对一个变量积分，其余变量视为常数；对时间变换后在像空间得到常微分方程，边界条件与初始条件一并变换。以均匀介质内 [[concepts/一维热传导方程]] 为例，给出有限区间的 U₁、U₂ 叠加解与 l→∞ 时的卷积核解 (15.63b)。

本节是 [[methodology/算子方法三步求解流程]]（变换—像空间求解—逆变换）在 ODE/PDE 上的系统化实例，直接依赖 15.2.1.2 的计算法则（导数法则、(15.16)、第 11 条 [[concepts/卷积]] 法则，见 [[sources/10-数学手册原书第10版--10-152-拉普拉斯变换--12vbv4w]]）。

## 核心主张

1. 微分（连同初始条件）经拉普拉斯变换化为像空间的代数运算，从而把常系数线性 ODE 的初值问题代数化：初始条件自动进入像方程，无需先解齐次方程再定常数。
2. 二阶方程按 b 与 a² 的大小分三种情形给出显式核函数 q(t) = L⁻¹{1/G(p)}（(15.51b)(15.52b)(15.53b)）；解 y(t) = 分子原函数 ∗ q(t)，若右端可直接查表则可避免卷积。算例完整演示「部分分式分解（保留二次因子）＋逐项查表」路线。
3. n 阶单根情形：单位阶跃扰动（跳跃函数）的响应有闭式 (15.54b)；一般扰动经卷积求导公式 (15.55)（源文称「达朗贝尔公式」，疑为杜阿梅尔公式）获得。
4. 系数为 t 的一次多项式的变系数方程在像空间降为一阶方程；零阶贝塞尔方程由此解出 F(p) = C/√(p²+1)，即 f(t) = C·J₀(t)。
5. PDE 对单变量作拉普拉斯变换后化为像空间 ODE；一维热传导方程零初始温度情形的解由 U₁、U₂ 叠加构成，l→∞ 时退化为与边界函数卷积的 Poisson 型积分 (15.63b)。

## 结构化转录

15.2.3.1–15.2.3.2（% 注为讹误标注）：

```latex
(15.47a)  y^{(n)}(t) + c_{n-1} y^{(n-1)}(t) + ... + c_1 y'(t) + c_0 y(t) = f(t)
          初始值 y(+0)=y_0, y'(+0)=y_0', ..., y^{(n-1)}(+0)=y_0^{(n-1)}
(15.47b)  \sum_{k=0}^{n} c_k p^k Y(p) - \sum_{k=1}^{n} c_k \sum_{v=0}^{k-1} p^{k-v-1} y_0^{(v)} = F(p)  (c_n=1)
          特征方程 G(p) = \sum_{k=0}^{n} c_k p^k = 0

一阶：
(15.48a)  y'(t) + c_0 y(t) = f(t),  y(+0) = y_0
(15.48b)  (p + c_0) Y(p) - y_0 = F(p)
(15.48c)  Y(p) = [F(p) + y_0]/(p + c_0)
          特殊情形 f(t) = \lambda e^{\mu t}, F(p) = \lambda/(p-\mu)   % (15.49a) 仅存编号、无公式行
(15.49b)  Y(p) = \lambda/[(p-\mu)(p+c_0)] + y_0/(p+c_0)
(15.49c)  y(t) = \lambda/(\mu+c_0)\, e^{\mu t} + (y_0 - \lambda/(\mu+c_0))\, e^{-c_0 t}

二阶：
(15.50a)  y''(t) + 2a y'(t) + b y(t) = f(t),  y(+0)=y_0, y'(+0)=y_0'
(15.50b)  (p^2+2ap+b) Y(p) - 2a y_0 - (p y_0 + y_0') = F(p)
(15.50c)  Y(p) = [F(p) + (2a+p) y_0 + y_0']/(p^2+2ap+b)

a) b<a^2:  (15.51a) G(p)=(p-\alpha_1)(p-\alpha_2),  \alpha_1,\alpha_2 相异实根
(15.51b)  q(t)=L^{-1}{1/G(p)}=(e^{\alpha_1 t}-e^{\alpha_2 t})/(\alpha_1-\alpha_2)
b) b=a^2:  (15.52a) G(p)=(p-\alpha)^2
(15.52b)  q(t)=t\,e^{\alpha t}
c) b>a^2:  (15.53a) G(p) 有复根
(15.53b)  q(t)=L^{-1}{1/G(p)}=e^{-at}\,\sin(\sqrt{b-a^2}\,t)/\sqrt{b-a^2}

% 分子 Y(p) 的原函数与 q(t) 卷积得解；若能找到右端的直接变换则可避免卷积
% 算例: y''+2y'+10y = 37cos3t + 9e^{-t}, y_0=1, y_0'=0
Y(p) = (p+2)/(p^2+2p+10) + 37p/[(p^2+9)(p^2+2p+10)] + 9/[(p+1)(p^2+2p+10)]
     = -p/(p^2+2p+10) - 19/(p^2+2p+10) + p/(p^2+9) + 18/(p^2+9) + 1/(p+1)   % 保留二次因子的部分分式
y(t) = (-cos3t - 6 sin3t) e^{-t} + cos3t + 6 sin3t + e^{-t}    % 查表 21.13（第 1431 页）逐项逆变换

% 4. n 阶微分方程（源文题头「4. 阶」缺「n」）；特征方程只有单根 \alpha_1,...,\alpha_n 且均非零
(15.54a)  u(t) = 1 (t>0); 0 (t<0)          % 跳跃函数（单位阶跃）
(15.54b)  y(t) = 1/G(0) + \sum_{v=1}^{n} e^{\alpha_v t}/[\alpha_v G'(\alpha_v)]
(15.55)   \tilde{y}(t) = d/dt \int_0^t y(t-\tau) f(\tau) d\tau = d/dt [y*f]   % 源文称「达朗贝尔公式」，疑为杜阿梅尔公式

15.2.3.2 变系数（系数为 t 的多项式）：用 (15.16) 在像空间降阶；一次多项式系数 → 一阶像方程
% 零阶贝塞尔方程（源文缺「0」；参见 (9.52a) n=0，第 743 页）: t f'' + f' + t f = 0
  -d/dp[p^2 F - p f(0) - f'(0)] + pF - f(0) - dF/dp = 0
  =>  dF/dp = -p/(p^2+1) F  =>  F(p) = C/\sqrt{p^2+1}
% 结论行源文讹损为「J(t) = CJ (t)」，重建为 f(t) = C·J_0(t)（0 阶贝塞尔函数，参见 15.2.2.3，第 1019 页）
```

## 复算核验

全部公式经独立推导核验通过，详见三个 finding 页：

- [[findings/式15-47至15-55常系数方程拉普拉斯求解转录复算]]：(15.47b) 逐项推导相符；三个核函数互为解析延拓；算例通分核对、逐项逆变换、初值与方程代入（y(0)=1、y′(0)=0、y″+2y′+10y|₀ = 46 = 37+9）全部通过；(15.54b) 由 1/(pG(p)) 的部分分式留数导出。
- [[findings/零阶贝塞尔方程像空间降阶求解转录复算]]：像方程化简（f(0) 项相消）与分离变量求解通过；结论行源文讹损，重建为 f(t) = C·J₀(t)。
- [[findings/式15-56至15-63一维热传导方程拉普拉斯求解转录复算]]：U₁、U₂ 即 sinh((l−x)√p)/sinh(l√p) 与 sinh(x√p)/sinh(l√p)，边界条件核验通过；半无限核 x/(2√π)·τ^{−3/2}e^{−x²/4τ} 由对标准变换对求导独立推出。

## 主张归属与适用范围

- (15.51)–(15.53) 仅关于二阶方程 G(p) = p²+2ap+b；
- (15.54b) 仅关于「特征根全为单根且均非零」的 n 阶方程、单位阶跃扰动，且隐含零初始条件（见 [[queries/式15-54b隐含零初始条件之辨]]）；
- (15.60c) 起仅关于零初始温度 u₀(x)=0；(15.63) 进一步仅关于 l→∞ 的半无限情形；
- 贝塞尔算例仅关于 (9.52a) 取 n=0 的零阶情形。
