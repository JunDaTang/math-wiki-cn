# 《数学手册(原书第10版)》1.1.1 数

本页是《数学手册(原书第10版)》第 1.1.1 节“数”的源摘要。该节是全书第一节，为后续所有章节提供数系基础：ℕ/ℤ/ℚ/ℝ 的定义与性质、无理数与超越数的分类、连分数理论（本节最大子节与技术核心）以及可公度性。所属著作见 [[entities/数学手册(原书第10版)]]。

## 章节结构

- 1.1.1.1 自然数、整数和有理数（定义和记号、性质、算术运算、十进小数和连分数、几何表示）
- 1.1.1.2 无理数和超越数（代数无理数、超越数、二次无理数、黄金分割例）
- 1.1.1.3 实数（最重要的性质、算术运算、数区间）
- 1.1.1.4 连分数（有理数、无理数、实数的逼近）
- 1.1.1.5 可公度性

## 集合定义与记号（原文逐字）

```latex
自然数集: \mathbb{N} = \{0,1,2,3,\dots\}
整数集:   \mathbb{Z} = \{\cdots, -2, -1, 0, 1, 2, \cdots\}
有理数集: \mathbb{Q} = \left\{x \mid x = \frac{p}{q}, p \in \mathbb{Z}, q \in \mathbb{Z}, q \neq 0\right\}
```

注：手册取 ℕ∋0，自然数“也被称为非负整数”；相关符号参见第 439 页 5.2.1, 1.（前向引用，未编目）。

## 关键公式（原文逐字保留）

```latex
(1.1a)  x^{n}+a_{n-1}x^{n-1}+\cdots+a_{1}x+a_{0}=0
        (n>1 整数；方程系数均为整数) —— 非整数实根为代数无理数
        （首项系数为 1，故非整数根必为无理数）
(1.1b)  x^{2}+a_{1}x+a_{0}=0  (a_{1}, a_{0} 为整数) —— 非整数根为二次无理数，
        形如 (a+b\sqrt{D})/c (a,b,c 均为整数, c\neq0; D>0 为非平方数)
(1.2)   \frac{p}{q} = a_{0} + \frac{1}{a_{1} + \frac{1}{a_{2} + \frac{1}{\ddots + \frac{1}{a_{n-1} + \frac{1}{a_{n}}}}}}
        缩写为 [a_{0}; a_{1}, a_{2}, \cdots, a_{n}], 其中 a_{k} \geqslant 1 (k=1,\cdots,n)
(1.3a)  \frac{p}{q} = a_{0} + \frac{r_{1}}{q}  \left(0 < \frac{r_{1}}{q} < 1\right)
(1.3b)  \frac{q}{r_{1}} = a_{1} + \frac{r_{2}}{r_{1}}  \left(0 < \frac{r_{2}}{r_{1}} < 1\right)
(1.3c)  \frac{r_{1}}{r_{2}} = a_{2} + \frac{r_{3}}{r_{2}}  \left(0 < \frac{r_{3}}{r_{2}} < 1\right)
(1.3d)  \frac{r_{n-2}}{r_{n-1}} = a_{n-1} + \frac{r_{n}}{r_{n-1}}  \left(0 < \frac{r_{n}}{r_{n-1}} < 1\right)
(1.3e)  \frac{r_{n-1}}{r_{n}} = a_{n}  (r_{n+1} = 0)
(1.4)   \alpha_{k} = [a_{0}; a_{1}, a_{2}, \dots, a_{k}] = \frac{p}{q}   （k 阶逼近）
(1.5)   \alpha_{k} = \frac{p_{k}}{q_{k}} = \frac{a_{k}p_{k-1} + p_{k-2}}{a_{k}q_{k-1} + q_{k-2}}
        (k \geqslant 1; p_{-1} = 1, p_{0} = a_{0}; q_{-1} = 0, q_{0} = 1)
(1.6)   |\alpha - \alpha_{k}| = \left|\alpha - \frac{p_{k}}{q_{k}}\right| < \frac{1}{q_{k}^{2}}
        （手册归于“刘维尔逼近定理”，归属存疑，见 [[queries/刘维尔逼近定理归属是否准确]]）
(1.7)   由 a = mc, b = nc (m, n \in \mathbb{Z}) 可得 \frac{a}{b} = x  (x 是有理数)
```

## 算例（原文数据）

```latex
61/27 = 2 + 7/27 = 2 + 1/(3 + 6/7) = 2 + 1/(3 + 1/(1 + 1/6)) = [2; 3, 1, 6]
√2 = 1.4142135... = [1; 2, 2, 2, ...]
π = [3; 7, 15, 1, 292, ...]
黄金分割: x/a = (a-x)/x, a=1 ⟹ x² + x - 1 = 0, 解 x = (√5 - 1)/2   （1.1.1.2）
例 B:   x = a[1;1,1,...] 与 x = (a/2)(1+√5) = (a/2)(1 + [2;4,4,4,...])   （1.1.1.4）
        第一个表示式 α₄ 精确度 0.018a，第二个表示式精确度 0.000001a
```

## π 的渐近分数（原文数据，已复核）

| k | 渐近分数 αₖ | 误差上界 (1.6) | 手册给出的实际误差 |
|---|---|---|---|
| 1 | 22/7 | < 1/7² ≈ 2·10⁻² | < 1.3·10⁻³ |
| 2 | 333/106 | < 1/106² ≈ 9·10⁻⁵ | < 8.4·10⁻⁵ |
| 3 | 355/113 | < 1/113² ≈ 8·10⁻⁵ | < 2.7·10⁻⁷ |

手册结论：α₁、α₂、α₃ 是对 π 比相应位数的小数表示更好的逼近。详见 [[findings/π的渐近分数优于同位数小数]]。

## 主要论断（按主体归属）

1. **有理数集**：无限、有序、处处稠密；四则运算封闭但 a:0 无意义（a:0=∞ 仅为记号）；处处稠密却不能覆盖数轴——单位正方形对角线旋转落点 K 的坐标不是有理数。每个有理数表示为有限或无限循环十进小数、有限连分数。见 [[concepts/有理数]]、[[findings/有理数稠密但不覆盖数轴]]、[[findings/除以零无意义且无穷大仅为记号]]。
2. **无理数**：填充数轴上全部非有理点；每个无理数是无限不循环十进小数、无限连分数；二分为代数无理数（(1.1a) 的非整数实根）与超越数。见 [[concepts/无理数]]、[[findings/有理数与无理数的表示对偶]]。
3. **超越数**：π、e 是超越数；非 10ⁿ 整数的常用对数是超越数（强断言，手册未证明）。见 [[concepts/超越数]]、[[findings/非10的n次方整数的常用对数为超越数]]。
4. **二次无理数**：(1.1b) 的非整数根，形如 (a+b√D)/c；与循环连分数互相表示（双向论断）；例 √2=[1;2,2,2,…]。见 [[concepts/二次无理数]]、[[findings/二次无理数与循环连分数一一对应]]。
5. **实数集**：在 ℚ 三性质外增加封闭性（数轴每点对应一实数），手册明确指出有理数不具有此性质；正实数可求任意次方根、有以除 1 外任意正数为底的对数；进一步推广为复数（1.5 节）。见 [[concepts/实数]]、[[findings/实数集封闭性为有理数集所缺]]。
6. **连分数**：部分商由欧几里得算法 (1.3a–e) 逐次取整得出；渐近分数满足递推 (1.5) 与误差估计 (1.6)；逼近以渐增精度上下交替；aᵢ 数值大则收敛快，全 1（黄金数）收敛最差。见 [[concepts/连分数]]、[[findings/渐近分数的递推公式与误差估计]]、[[findings/连分数部分商全为1时收敛最慢]]。
7. **可公度性**：可公度 ⟹ 比值为有理数 (1.7)；正方形边与对角线（√2）、黄金分割线段（√5，推及正五边形边与对角线）不可公度。见 [[concepts/可公度性]]、[[findings/正方形对角线与黄金分割线段不可公度]]。

## 记号约定

本节引入：ℕ∋0、ℤ/ℚ/ℝ 记号、区间括号体系（方括号闭、圆括号开，端点可取 ±∞）、图示以圆箭头表开端、实点表闭端、a:0=∞ 仅为记号。汇总于 [[findings/数学手册记号约定-数系与区间]]，与 [[findings/数学手册记号约定-基本量参数指标字母分段]] 互补。

## 矛盾与存疑

1. **黄金分割内部数值矛盾（最重要）**：1.1.1.2 由 x/a=(a−x)/x（a=1）得 x=(√5−1)/2≈0.618；1.1.1.4 例 B 称同一公式可表为 x=a[1;1,1,…]=(a/2)(1+√5)≈1.618a，两值互为倒数（相差因子 φ）。例 B 数值自身自洽，矛盾仅在于与所引公式的解不符。见 [[findings/黄金分割连分数示例与方程解相差因子φ]]、[[queries/黄金分割连分数示例取值矛盾]]。
2. **定理归属疑问**：(1.6) 被归于“刘维尔逼近定理”；通常文献中 |α−pₖ/qₖ|<1/qₖ² 是渐近分数的基本性质，而刘维尔定理给出代数数逼近的下界。见 [[queries/刘维尔逼近定理归属是否准确]]。
3. **历史归因的保留**：希帕索斯发现无理数系于正五边形例（“现在认为”限定，弱证据），而传统叙事多与 √2 相连；本节例 A 恰以正方形对角线作算例、历史归因却附于例 B。
4. **严谨性注记（非数学错误）**：ℕ∋0 与部分文献不同；(1.2) 声明针对“大于 1 的正有理数”而一般论断覆盖全体有理数（a₀=0 情形未显式）；(1.7) 仅单向陈述，完整等价判据未显式给出；数区间一段中文表述生硬（“属内”疑为直译痕迹）。

## 证据强度

本源为参考工具书，定理类论断（二次无理数 ⟺ 循环连分数、超越性例子）均不附证明；但全部数值算例经复核成立（61/27=[2;3,1,6]；π 的三组渐近分数误差；[1;1,1,1,1]=8/5 对 φ 的误差恰为 0.018a；[2;4,4,…]=√5 的 α₄ 误差约 2.4·10⁻⁶ 与“0.000001a”量级吻合）。分类论断属经典数学，外部可佐证，置信高。希帕索斯归因带“现在认为”限定，弱证据。
