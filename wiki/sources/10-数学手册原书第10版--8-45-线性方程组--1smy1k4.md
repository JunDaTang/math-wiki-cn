# 数学手册(原书第10版) 4.5 线性方程组

《数学手册》第 4 章（线性代数）的第 5 节，主题为线性方程组：从线性系与选主元法的表格式算法（4.5.1）出发，经可解性的秩判据、克拉默法则与高斯算法（4.5.2），最后处理超定方程组、线性最小二乘问题及其数值解建议（4.5.3）。本节回溯依赖的 4.1（[[concepts/矩阵]]）与 4.2（[[concepts/行列式]]）均已入库，无回溯缺口。源文档转写质量差（「千/于」混淆、数字与符号成片脱落、粗体向量记号乱码），汇总见 [[queries/4-5全节系统性转写讹误清单]]。

- 4.5.1 线性系，选主元法：4.5.1.1 线性系；4.5.1.2 选主元法格式与法则；4.5.1.3 线性相关性；4.5.1.4 逆矩阵的计算。

## 核心公式（式 4.174–4.192）

线性系与线性方程组：

```
y = A x + a        （线性系，m 个线性型，A 为 (m,n) 矩阵）       (4.174a)
A x = a            （线性方程组）                                 (4.177a)
```

选主元格式（式 4.175，主元 a_ik 加框；第 m+1 行为辅助行）：

|      | x₁ | x₂ | ⋯ | x_k | ⋯ | x_n | 1 |
|------|----|----|---|-----|---|-----|---|
| y₁   | a₁₁ | a₁₂ | ⋯ | a₁k | ⋯ | a₁n | a₁ |
| ⋮    |  |  |  | ⋮ |  |  | ⋮ |
| y_i  | a_i1 | a_i2 | ⋯ | **a_ik** | ⋯ | a_in | a_i |
| ⋮    |  |  |  | ⋮ |  |  | ⋮ |
| y_m  | a_m1 | a_m2 | ⋯ | a_mk | ⋯ | a_mn | a_m |
| x_k（辅助行） | α_i1 | α_i2 | ⋯ | α_ik | ⋯ | α_in | α_i |

换轴后主行位置改标 x_k、主列位置改标 y_i，全部元素按四条选主元法则（式 4.176）重算为 α：

```
(1) α_ik = 1/a_ik                                                   （4.176a，转写脱落，据算例复原）
(2) α_μk = a_μk / a_ik                     (μ = 1,…,m; μ ≠ i)        (4.176b)
(3) α_iν = −a_iν / a_ik,  α_i = −a_i/a_ik  (ν = 1,…,n; ν ≠ k)        (4.176c)
(4) α_μν = a_μν − a_μk(a_iν/a_ik) = a_μν + a_μk·α_iν,
    α_μ  = a_μ + a_μk·α_i                   (ν ≠ k, μ ≠ i)           (4.176d)
```

可解性秩判据（增广矩阵 (A, a)）：

```
rank(A) = rank(A, a)  →  至少有一个解（相容）                         (4.178a)
r = rank(A) = n       →  唯一解                                      (4.178b)
r < n                 →  无穷多解，n − r 个未知数可作自由参数          (4.178c)
```

齐次方程组：

```
x₁ = x₂ = … = x_n = 0                  （平凡解，恒存在）             (4.179a)
x = k₁α₁ + k₂α₂ + … + k_l α_l          （一般解，l = n − r 个基本解） (4.179b)
x_ρ = x_ρ(x_{r+1}, …, x_n)             （以自由参数表示其余未知数）    (4.180)
第 j 个基本解在第 j 个自由参数处取 1、其余取 0                         (4.181)
```

选主元法解方程组的两情形：

```
A x = a  等价于  y = A x − a = 0                                     (4.182a–b)
情形 1：所有 y_μ 都可与某个 x_ν 换轴（线性无关）→ 有解
情形 2：某个 y_σ 不可换轴，y_σ = λ₁y₁ + … + λ_m y_m + λ₀  (4.183)
        λ₀ = 0 → 有解；λ₀ ≠ 0 → 无解（存在互相矛盾的方程）
```

克拉默法则（m = n 且 D = det A ≠ 0）：

```
x_ν = D_ν / D    (ν = 1,…,n)                                        (4.184c)
D_ν：以常数项 a_μ 替换 D 的第 ν 列元素 a_μν 所得行列式                (4.184d)
D = 0 且至少一个 D_ν ≠ 0 → 无解；
D = 0 且所有 D_ν = 0 → 可能有解但不唯一（源自我提示「参见第 417 页注」）
```

高斯消元法（行运算不改变 (A, a) 的秩）：

```
行阶梯形 (4.186)：前 r 行的对角主元 a_ρρ^(ρ−1)（ρ = 1,…,r）以下全为零，
其下各行仅在常数列可能有非零元 a_{r+1}^(r−1), …, a_m^(r−1)。
情形 1：某个 a_μ^(r−1) ≠ 0 (μ > r) → 无解
情形 2a：全为零且 r = n → 唯一解；情形 2b：r < n → n − r 个自由参数
```

超定组与最小二乘（m > n）：

```
A x = b                          （超定组，A 为 (m,n) 长方矩阵）      (4.187)
r = A x − b                      （残差向量）                         (4.188)
rᵀr = (Ax − b)ᵀ(Ax − b) = min!   （线性最小二乘问题）                 (4.189)
Aᵀ(Ax − b) = 0 ⇔ AᵀA x = Aᵀb    （正规方程组，维数 n；高斯变换）      (4.190)
rᵀr + α xᵀx = min!  (α > 0)      （正则化问题）                       (4.191)
(AᵀA + αI) x = Aᵀb               （正则化的正规方程）                 (4.192)
```

## 数值建议（各断言的归属须严格区分）

- 「数值上相当不稳定」是源针对**用楚列斯基方法解正规方程组**这一路径的断言（并称其在大残差 ‖r‖ 与小解 ‖x‖ 的情形实施尚可），不是对楚列斯基方法本身的一般评价，见 [[concepts/楚列斯基方法]]；
- 源推荐基于分解 A = QR 的正交化方法（[[concepts/豪斯霍尔德方法]]）；
- 秩亏（源作「秩亏格」，rank(A) < n）时正规方程组无唯一解、正交化方法给出无用结果，须转用 [[concepts/正则化问题]]（式 4.191–4.192），正则化参数选取困难（引文献 [4.7]，信息不透明）。
