# 数学手册(原书第10版) 20.1 引言

《数学手册（原书第10版）》第 20 章的引言小节，是本 wiki 入库的第一份第 20 章文献。本节给出计算机代数系统（CAS）的一般性描述，宣布第 20 章以 Mathematica 为参照系统，确立 In[n]:= / Out[n]= 的行式记法约定，并以两个算例——二次方程的符号求解与六次方程的数值求解——介绍 CAS 的两个基本应用领域。全部示例命令与输出均经独立复算无误，见 [[findings/式20-1至20-3c符号与数值求解算例转录复算]]。

## 内容概要

### 20.1.1.1 计算机代数系统的一般用途

计算机的发展使引入计算机代数系统来“做数学”成为可能：它们是能够**形式地**（按数学规则、在封闭形式域内）进行数学运算的软件系统。源文列举 Macsyma、Reduce、Derive、Maple、Mathematica、Matlab、Sage，并称它们也能在小型计算机（PC）上使用。能力清单：变换复杂表达式、计算导数与积分、解方程组、用图形表示一元与多元函数、按数学规则变换与简化（能以封闭形式处理的）数学表达式、提供具有所要求精度的数值解、以图形表示两个数据集之间的函数依赖关系、输入和输出数据。除每次启动时激活的基本定义与指令外，多数系统还提供来自专门数学领域的指令库与程序包，可按要求加载激活（源文引 [20.15]、[20.16]），并允许用户建立自己的程序包（引 [20.7]、[20.14]）。

源文同时给出规范性告诫：CAS 的潜在价值不应被高估——它们使我们摆脱乏味且耗时的机械计算与变换，但**不能代替我们思考**；对经常出现的错误，明文回指“第 1303 页，19.8.2”，即 [[sources/10-数学手册原书第10版--16-1982-计算机计算中的数值问题--zy026m]]。

### 20.1.1.2 限于 Mathematica

第 20 章将讨论 Mathematica（“包括与第 10 版兼容的各版本”，所指待辨，见 [[queries/与第10版兼容的各版本所指之辨]]），理由是该系统“似乎在用户中非常流行”且“其他系统的基本结构是类似的”；同时自认每一具体表述“仅反映一种暂时的状态”（版本语境限定）。本节不讨论安装，假定系统已启动，可经命令行或类似 Windows 的图形环境通信。输入输出按行、以区别于其他文本部分的形式表示（源文回指“第 1318 19.8.4.2, 1.”，页码与编号待核，见 [[queries/回指19-8-4-2与第1318页之辨]]）；系统专门符号（命令、类型符号等）用打字机字体；为节省空间，输入输出常写在同一行并用一个专门符号分隔（该符号在本转录中脱失，见 [[queries/输入输出同行分隔符脱失之辨]]）。

### 20.1.1.3 两个基本应用领域的实例介绍

**1. 公式操作**：最广义的数学表达式变换——化简或化为有用形式、用代数表达式表示方程（组）之解、微分、求不定积分、解微分方程、构造无穷级数等；示例为带参数二次方程的符号求解，见 [[concepts/公式操作]]。

**2. 数值计算**：CAS 提供的处理数值问题的程序——代数方程、线性方程组与超越方程求解、定积分、微分方程数值解、插值等，按所要求精度输出；示例为六次方程的数值求解，见 [[concepts/数值计算（计算机代数应用领域）]]。

## 结构化数据转录（式 20.1–20.3c）

```text
(20.1)    In[1] := Solve[3 x - 5 == 0, x]

(20.2a)   x² + a x + b = 0,  其中 a, b ∈ ℝ
(20.2b)   Solve[x² + a x + b == 0, x]
(20.2c)   In[1] := Solve[x² + a x + b == 0, x]
(20.2d)   Out[1] = {{x -> 1/2 (-a - √(a² - 4b))}, {x -> 1/2 (-a + √(a² - 4b))}}

(20.3a)   x⁶ - 2x⁵ - 30x⁴ + 36x³ + 190x² - 36x - 150 = 0
(20.3b)   In[1] := NSolve[x⁶ - 2x⁵ - 30x⁴ + 36x³ + 190x² - 36x - 150 == 0, x]
(20.3c)   Out[1] = {{x → -4.42228}, {x → -2.14285}, {x → -0.937347},
                   {x → 0.972291}, {x → 3.35802}, {x → 5.17217}}
```

注：源文 LaTeX 中 `= =` 为 `==` 的排印间距；式 (20.2d) 与 (20.3c) 的替换规则在源文分别排版为 `x ->` 与 `x →`。

## 主要论点与归属

1. **关于 CAS（一般）**：能按数学规则变换化简表达式、给任意精度数值解并作图形——属定义性陈述加两示例的描述性编辑论断，无基准测试；能力主张归于 [[concepts/计算机代数系统]]，不应逐字转嫁给名单中任一具体系统。
2. **关于本手册的编辑立场**：CAS“不能代替我们思考”，常见错误见 19.8.2——与已入库的 [[concepts/舍入与舍入误差]]、[[concepts/减法相消]]、[[concepts/数值稳定性三分类]] 误差分类互为印证。
3. **关于 Mathematica**：选其为参照系统的理由是“流行”与“其他系统结构类似”，且自认表述仅反映“暂时的状态”——流行度是未经证实的编辑判断，不转嫁给其他系统。
4. **关于 Solve（式 20.2）**：解以两子列表之列表的替换规则给出，与标准求根公式逐项一致（直接代数复核，强度高）。
5. **关于 NSolve（式 20.3）**：六次方程 (20.3a) 恰有六个互异单实根，(20.3c) 所列六值经精确整数变号分析逐一对号（强度高，见 finding）。警示：显示值 −2.14285 形似 −15/7，但 p(−15/7) = −195/7⁶ ≈ −0.00166 ≠ 0，真根为无理数 ≈ −2.142852。
