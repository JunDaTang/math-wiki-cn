# 数学手册(原书第10版) 19.3 数值积分

《数学手册(原书第10版)》第 19 章第 3 节「数值积分」的入库摘要，公式编号 19.69–19.92。本节处理定积分 $I(f)=\int_a^b f(x)\,\mathrm{d}x$ 的数值近似：当被积函数不能用初等微积分求积、计算太复杂，或仅在区间 $[a,b]$ 上有限个节点已知时，数值计算必然是近似的（19.3.1）。全节沿两条路线展开——等距节点的插值求积（19.3.2）与节点自由的高斯型求积（19.3.3）——压轴的龙贝格方法（19.3.4）以梯形和序列加外推加速统一前述内容，并以 $I=\int_0^1 \frac{\sin x}{x}\,\mathrm{d}x$（Si(1)，真值 0.9460830704…）为统一算例比较各方法，末尾附三条注释。本节是本维基收录的**首个第 19 章来源**（此前仅覆盖第 18 章）。

## 小节结构

- **19.3.1 一般求积公式**：求积公式一般形式 (19.70) 与误差恒等式 (19.71)；仅用节点值者称「均值公式」（术语存疑），用到导数值者称埃尔米特求积公式。
- **19.3.2 插值求积**：等距节点 (19.72)；四族公式：19.3.2.1 矩形、19.3.2.2 梯形、19.3.2.3 辛普森、19.3.2.4 埃尔米特梯形，均给出单区间与复化形式及 $|R|$ 上界（$M_\mu$ 为 $|f^{(\mu)}|$ 在整个区域的上界）。
- **19.3.3 高斯求积公式**：节点与系数皆为参数；19.3.3.1 Gauss–Legendre 节点系数表 (19.82) 与区间仿射变换 (19.83)；19.3.3.2 洛巴托求积公式 (19.84a/b)，n=2 即辛普森公式。
- **19.3.4 龙贝格方法**：19.3.4.1 算法（梯形和递归 (19.86)、外推 (19.87)、三角格式 (19.88)）；19.3.4.2 外推原理（渐近展开 (19.89)、组合 (19.90)–(19.91)、误差阶 (19.92)）。
- **算例**：Si(1) 的龙贝格三角表、梯形/辛普森/埃尔米特修正、高斯 n=1,2,3 五法对比。
- **注释 (1)–(3)**：周期函数积分与 FFT（回指 7.4.1.1、19.6.4、19.6.4.2）；特殊求积法则与收敛性/误差分析文献 [19.7]；多重积分数值方法文献 [19.34]。

## 核心断言（按主体归属）

- **梯形公式**：误差阶 2，复化误差界 $(b-a)h^2/12\cdot M_2$；不计舍入误差时 $h\to 0$ 收敛到定积分（收敛性断言仅对此公式陈述）。
- **辛普森公式**：误差阶 4，复化须 n 为偶数，对三次多项式准确。
- **埃尔米特梯形公式**：误差阶 4，对三次多项式准确，复化修正只需两端点导数 $(h^2/12)(y_0'-y_n')$。
- **高斯求积公式（Gauss–Legendre）**：节点取勒让德多项式之根（关于原点对称），对次数 ⩽ 2n+1 的多项式准确；一般区间经仿射变换 (19.83) 化到 [−1,1]。
- **洛巴托求积公式**：端点作节点，准确度降为 2n−1；n=2 即辛普森公式。
- **龙贝格方法**：$T_{k,i}=I+O(h_i^{2k+2})$；三角格式第二列 $T_{1,i}$ 恰为辛普森值；外推系数 $\alpha_1=-1/3$、$\alpha_2=4/3$。
- **效率断言（针对梯形公式）**：算例中达到 8 位精度需多于 1000 个函数值（复算估算 n≈1590–2240，断言成立）。

## 结构化数据转录（verbatim）

### 一般框架与等距节点

```latex
I(f) = ∫_a^b f(x) dx                                              (19.69)
Q(f) = Σ_{ν=0}^n c_{0ν} y_ν + Σ_{ν=0}^n c_{1ν} y_ν^{(1)} + ⋯ + Σ_{ν=0}^n c_{pν} y_ν^{(p)}   (19.70)
      （y_ν^{(μ)} = f^{(μ)}(x_ν), y_ν = f(x_ν), c_{μν} 为常数）
I(f) = Q(f) + R                                                    (19.71)
x_ν = x_0 + νh (ν = 0,1,…,n),  x_0 = a,  x_n = b,  h = (b−a)/n      (19.72)
```

### 插值求积四族（单区间 / 复化，误差界；M_μ 为 |f^{(μ)}| 上界）

```latex
左端矩形:    ∫_{x_0}^{x_0+h} f dx ≈ h·y_0,                    |R| ⩽ h²/2·M₁          (19.73a)
复化左矩形:  ∫_a^b f dx ≈ h(y_0+y_1+⋯+y_{n−1}),             |R| ⩽ (b−a)h/2·M₁      (19.73b)
复化右矩形:  ∫_a^b f dx ≈ h(y_1+⋯+y_n),                     |R| ⩽ (b−a)h/2·M₁      (19.74)
梯形:        ∫_{x_0}^{x_0+h} f dx ≈ (h/2)(y_0+y_1),           |R| ⩽ h³/12·M₂         (19.75)
复化梯形:    ∫_a^b f dx ≈ h(y_0/2+y_1+⋯+y_{n−1}+y_n/2),     |R| ⩽ (b−a)h²/12·M₂    (19.76)
辛普森:       ∫_{x_0}^{x_0+2h} f dx ≈ (h/3)(y_0+4y_1+y_2),    |R| ⩽ h⁵/90·M₄         (19.77)
复化辛普森(n 为偶数): ∫_a^b f dx ≈ (h/3)(y_0+4y_1+2y_2+⋯+2y_{n−2}+4y_{n−1}+y_n),
                                                            |R| ⩽ (b−a)h⁴/180·M₄   (19.78)
埃尔米特梯形: ∫_{x_0}^{x_0+h} f dx ≈ (h/2)(y_0+y_1)+(h²/12)(y_0′−y_1′),
                                                            |R| ⩽ h⁵/720·M₄        (19.79)
复化埃尔米特梯形: ∫_a^b f dx ≈ h(y_0/2+y_1+⋯+y_{n−1}+y_n/2)+(h²/12)(y_0′−y_n′),
                                                            |R| ⩽ (b−a)h⁴/720·M₄   (19.80)
```

### 高斯求积形式与区间变换

```latex
∫_a^b f(x) dx ≈ Σ_{ν=0}^n c_ν y_ν,  y_ν = f(x_ν)                    (19.81)
∫_a^b f(t) dt ≈ (b−a)/2 · Σ_{ν=0}^n c_ν f((b−a)/2·x_ν + (a+b)/2)     (19.83)
```

(19.82) Gauss–Legendre 节点与系数（区间 [−1,1]）：

| n | 节点 x_ν | 系数 c_ν |
|---|---|---|
| 1 | x₀ = −x₁；x₁ = 1/√3 = 0.577350269… | c₀ = 1；c₁ = 1 |
| 2 | x₀ = −x₂；x₁ = 0；x₂ = √(3/5) = 0.774596669… | c₀ = 5/9；c₁ = 8/9；c₂ = c₀ |
| 3 | x₀ = −x₃；x₁ = −x₂；x₂ = 0.339981043…；x₃ = 0.861136311… | c₀ = 0.347854854…⚠；c₁ = 0.652145154…；c₂ = c₁；c₃ = c₀ |

⚠ n=3 的 c₀ 与标准值 0.3478548451… 不符（末两位 45/54 疑互换），且 c₀+c₁ = 1.000000008 ≠ 1 破坏权和恒等式，见 [[queries/式19-82中n等于3系数c0末两位疑互换之辨]]。

(19.84a/b) Lobatto 节点与系数：

| n | 节点 x_ν | 系数 c_ν |
|---|---|---|
| 2 | x₀ = −1；x₁ = 0；x₂ = 1 | c₀ = 1/3；c₁ = 4/3；c₂ = c₀（即辛普森公式） |
| 3 | x₀ = −1；x₁ = −x₂；x₂ = 1/√5 = 0.447213595…；x₃ = 1 | c₀ = 1/6；c₁ = 5/6；c₂ = c₁；c₃ = c₀ |

### 龙贝格方法

```latex
h_i = (b−a)/2^i   (i = 0,1,…,m)                                       (19.85)
T(h_i) = ½T(h_{i−1}) + (h_{i−1}/2) Σ_{j=0}^{n−1} f(a + h_{i−1}/2 + j·h_{i−1}),
        (i = 1,…,m;  n = 2^{i−1})                                     (19.86)
T_{k,i} = T_{k−1,i} + (T_{k−1,i} − T_{k−1,i−1})/(4^k − 1)
        (k = 1,…,m;  i = k, k+1, ⋯)                                   (19.87)
三角格式:  T(h_0)=T_{00};  T(h_1)=T_{01} T_{11};  T(h_2)=T_{02} T_{12} T_{22}; ⋯   (19.88)
R(h) = I − T(h) = a₁h² + a₂h⁴ + ⋯ + a_m h^{2m} + O(h^{2m+2})          (19.89a)
T₁(h) = −⅓T(h) + ⅔T(h/2)·(4/3) = T(h/2) + (T(h/2) − T(h))/3          (19.91)
T_{k,i} = I + O(h_i^{2k+2})                                            (19.92)
```

### 算例 I = ∫₀¹ (sin x)/x dx（Si(1)）龙贝格三角表

| | k=0 | k=1 | k=2 | k=3 |
|---|---|---|---|---|
| T(h₀) | 0.92073549 | | | |
| T(h₁) | 0.93979328 | 0.94614588 | | |
| T(h₂) | 0.94451352 | 0.94608693 | 0.94608300 | |
| T(h₃) | 0.94569086 | 0.94608331 | 0.94608307 | **0.94608307** |

其余算例结果：埃尔米特修正 I ≈ 0.94569086 + 0.30116868/(64·12) = 0.94608301；高斯 n=1: 0.94604113，n=2: 0.94608313，n=3: 0.94608307；真值 10 位数字 0.9460830704。

## 复算验证总评

全节公式与算例经独立复算**几乎全部通过**（证据强度高）：梯形序列、龙贝格三角表 10 项、埃尔米特修正、高斯三档结果、误差阶检验 (1/8)⁸ = 5.96·10⁻⁸、以及「第二列即辛普森」（T₁,₃ = 0.94608331 与直接复化辛普森 h=1/8 完全相等）均一致。唯一数值错误是 (19.82) n=3 的 c₀ 一位数字讹误，且有权和恒等式作内部佐证。详见 [[findings/正弦积分Si(1)算例全表复算]] 及其余 findings。
