# 数学手册(原书第10版) 9.1 常微分方程

## 概要

本节是手册第 9 章的起点，以四个编号要点建立常微分方程的完整定义框架：方程形式（隐式/显式）、解的层级（通解→特解）、问题分类（初值问题/边值问题）。全节唯一编号公式为式 9.1，其余均为定义性陈述，并配三个可独立复算的算例。本节同时是第 9 章对第 8 章积分学的最直接延伸。

## 四个要点

### 1. 一般的 n 阶常微分方程

隐式 (implicit form) 形式：

```latex
F \big [ x, y (x), y ^ {\prime} (x), \dots , y ^ {(n)} (x) \big ] = 0.\tag{9.1}
```

如果从这个方程中解出了 y⁽ⁿ⁾(x)，那么它就是一个 n 阶常微分方程的显式 (explicit form)。

### 2. 解或积分

一个微分方程的解或积分是在一个区间 a ≤ x ≤ b（此区间也可以是无限的）上满足这个方程的每个函数。一个包含 n 个任意常数 c₁, c₂, …, cₙ 的解被称为通解 (general solution) 或通积分 (general integral)；如果这些常数的值被确定，就得到了一个特别积分 (particular integral) 或一个特解 (particular solution)。这些常数的值可以被 n 个附加条件所确定。若 y 及其直至 n−1 阶导数的值在区间 [a, b] 的一个端点处被指定，则称为初值问题；若在区间的两个端点都有给定的值，则称为边值问题。

算例：−y′ sin x + y cos x = 1 有通解 y = cos x + c sin x；对于条件 c = 0，得到特解 y = cos x。

### 3. 初值问题

详见 [[concepts/初值问题]]。在 x₀ 处给定了 n 个值 y(x₀), y′(x₀), …, y⁽ⁿ⁻¹⁾(x₀)，即构成一个初值问题；这些值称为初值 (initial value) 或初始条件 (initial conditions)，对通解的 n 个未知常数形成 n 个方程的方程组。

算例：一个特殊的弹性弹簧—质量系统的谐运动由具有初始条件 y(0) = y₀, y′(0) = 0 的 y″ + y = 0 建模，其解为 y = y₀ cos x。

### 4. 边值问题

详见 [[concepts/边值问题]]。如果一个常微分方程的解和/或其导数在其定义域中的几个点处被给出，那么这些值称为边界条件 (boundary conditions)；具有边界条件的一个微分方程被称为边值问题。

算例：端点固定和均匀负载的细棒形成的曲线由具有边界条件 y(0) = 0, y(1) = 0 的微分方程 y″ = x − x²（0 ≤ x ≤ 1）所描述，其解为 y = x³/6 − x⁴/12 − x/12。

## 三个算例（复算状态）

| 算例 | 方程 | 附加条件 | 手册给出 | 复算结论 |
|---|---|---|---|---|
| 通解→特解 | −y′ sin x + y cos x = 1 | c = 0 | 通解 y = cos x + c sin x；特解 y = cos x | ✓（代入得 sin²x + cos²x = 1） |
| 弹簧—质量系统谐运动（初值问题） | y″ + y = 0 | y(0) = y₀, y′(0) = 0 | y = y₀ cos x | ✓（A = y₀, B = 0） |
| 端点固定、均匀负载细棒（边值问题） | y″ = x − x²，0 ≤ x ≤ 1 | y(0) = 0, y(1) = 0 | y = x³/6 − x⁴/12 − x/12 | ✓（c₁ = −1/12, c₂ = 0） |

复算过程见 [[findings/9-1三算例复算]]；定义组逐字转录见 [[findings/式9-1与解概念定义组逐字转录]]。

## 与第 8 章的衔接（扩展关系，无冲突）

- 通解的 n 个任意常数是不定积分单一积分常数 +C 的推广（参见 [[concepts/定积分]] 与 [[comparisons/定积分与不定积分比较]] 所依托的第 8 章体系）。
- 「通积分」「特别积分」等术语直接沿用第 8 章的积分语言。
- 例 1 左端恒等于 −sin²x·(y/sin x)′，故方程即 (y/sin x)′ = −csc²x，与 [[concepts/换元积分法]] 的化归思路同构；例 3 的求解即两次不定积分加边界定常数。

## 已知问题与限制

- **系统性转写讹误**：主导模式为孤立斜体字母 n 的系统性脱漏（至少 6 处），另有形近字（对千→对于、儿个→几个）、脱字（边值问→边值问题）与衍字（「cₙ 你，」），全表见 [[queries/9-1全节系统性转写讹误清单]]。
- **定义层面张力**：初值问题被定义两次（要点 2 简述、要点 3 详述）；边值问题在要点 2 限定为「两个端点」、要点 4 放宽为「几个点处」；例 1 的「条件 c = 0」是对常数本身施加的条件，与点值条件不属同一层面，见 [[queries/例1条件c等于0与边值问题定义宽窄]]。
- 「n 个附加条件可确定 n 个常数」是经典启发式表述，本节未涉及存在唯一性条件（预计在 9.1.1 出现）；「含 n 个常数的解即通解」的经典定义未覆盖奇解情形。
- 各算例的性质（如弹簧系统固有频率为 1）只属于各自方程，不应外推。
