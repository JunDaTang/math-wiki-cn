# 数学手册(原书第10版) 12.9 测度和勒贝格积分

## 概述

本节是《数学手册(原书第10版)》第 12 章「函数空间」的测度论基石，在 12.1–12.6 已建立的向量空间、距离空间、赋范空间、希尔伯特空间、连续线性算子与伴随算子框架之上，系统给出「σ-代数与测度 → 可测函数 → 勒贝格积分 → L^p 空间 → 分布（广义函数）」的完整构造链。节末署名「（冯德兴译）」。引入测度的原始动机是推广区间长度、ℝ² 中区域面积、ℝ³ 中子集体积等概念，使尽可能多的集合可度量、尽可能多的函数可积。

## 小节结构与核心主张

- **12.9.1 集代数和测度**：σ-代数公理 (12.207)、测度三公理 (12.208)（附单调性与连续性推论）、例 A 计数测度、例 B 狄拉克测度与特征函数 (12.209)、例 C 勒贝格测度（四性质唯一刻画）、几乎处处。
- **12.9.2 可测函数**：定义（原像属 σ-代数）、(12.210) 特征函数可测性、闭包性质 a)–f)、基本函数与单调逼近。
- **12.9.3 积分**：五步定义 (12.211)–(12.215)、性质 (1)–(6)、与黎曼积分的关系、莱维定理 (12.216)、法图定理 (12.217)、控制收敛定理 (12.218)、拉东–尼科迪姆定理 (12.219)。
- **12.9.4 L^p 空间**：N_p (12.220)、ess sup (12.221)、𝓛^p 拟范数空间（向量格乃至 K 空间）、商空间 L^p 巴拿赫格、L² 希尔伯特空间、有限测度嵌入、(𝒞(Ω), ‖·‖_p) 的完备化。
- **12.9.5 分布**：分部积分 (12.222)、广义导数 (12.223)、测试函数收敛 (12.224)、分布定义 (12.225)、正则分布 (12.226) 与狄拉克分布、分布导数 (12.227)–(12.229)、赫维赛德函数 (12.230) 与冲击算例。

核心主张：测度公理仅三条即可导出单调性与下方连续性；勒贝格测度由四条性质**唯一确定**（本节最强刻画性断言）；可测性只依赖 σ-代数不依赖测度；勒贝格积分五步构造严格扩张黎曼积分；𝓛^p 经商空间化成为巴拿赫格 L^p；𝒟(Ω) 上的连续线性泛函即分布，δ_a 为非正则分布，DΘ = δ。

### 一、测度论公理与三类测度例（12.206–12.209b）

```latex
% n 维长方体 (12.206)
Q = {x ∈ ℝⁿ : a_k ⩽ x_k ⩽ b_k (k = 1, 2, …)}，体积 = ∏_{k=1}^n (b_k − a_k)

% σ-代数 (12.207)
a) A ∈ 𝒜 ⟹ X\A ∈ 𝒜
b) A₁, A₂, … ∈ 𝒜 ⟹ ⋃_{n=1}^∞ A_n ∈ 𝒜

% 测度 (12.208)   μ: 𝒜 → ℝ̄₊ = ℝ₊ ∪ {+∞}
a) μ(A) ⩾ 0, ∀A ∈ 𝒜
b) μ(∅) = 0
c) A_k ∩ A_ℓ = ∅ (k ≠ ℓ) ⟹ μ(⋃_{n=1}^∞ A_n) = Σ_{n=1}^∞ μ(A_n)
   % 原文 c) 式与编号被 OCR 残片「/勹:08:」覆盖
% 推论：A ⊂ B ⟹ μ(A) ⩽ μ(B)（单调性）
%       A₁ ⊂ A₂ ⊂ … ⟹ μ(⋃A_n) = lim_{n→∞} μ(A_n)（连续性）

% 例 A 计数测度：有穷集 {x₁,…,x_N}，μ(A) = Σ p_{n_k}（加权计数）
% 例 B 狄拉克测度与特征函数 (12.209)
δ_a(A) = 1 (a ∈ A);  0 (a ∉ A)                (12.209a)
χ_A(x) = 1 (x ∈ A);   0 (其他)                 (12.209b)
% δ_a(A) = δ_a(χ_A) = χ_A(a)（参见第 890 页 12.5.4）
% 例 C 勒贝格测度：唯一确定的 σ-代数 𝒜 与测度 λ 满足
%   a) B(ℝⁿ) ⊂ 𝒜   b) 完备性（零测集子集仍可测且零测）
%   c) λ(Q) = ∏(b_k − a_k)   d) 平移不变：λ(x + A) = λ(A)
```

### 二、可测函数与勒贝格积分五步定义（12.210–12.215）

```latex
% 可测性：∀α ∈ ℝ, f⁻¹((α, +∞]) ∈ 𝒜
χ_A⁻¹((α, +∞]) = {A, α ∈ (−∞, 1); ∅, α ⩾ 1}    (12.210)  % 分段疑误，见 query

% 积分五步定义
(1) f = Σ_{k=1}^n α_k χ_{A_k}（基本函数）:
      ∫ f dμ = Σ_{k=1}^n α_k μ(A_k)                                 (12.211)
(2) f ⩾ 0:
      ∫ f dμ = sup{∫g dμ : g 基本函数, 0 ⩽ g(x) ⩽ f(x), ∀x ∈ X}      (12.212)
(3) ∫ f dμ = ∫ f₊ dμ − ∫ f₋ dμ （右端至少一个有穷，避免 ∞−∞）        (12.213)
(4) f = g + ih（g, h 可积）:
      ∫ f dμ = ∫ g dμ + i ∫ h dμ                                    (12.214)
(5) ∫_A f dμ := ∫ f χ_A dμ                                           (12.215)
% 可积（可和）⟺ 可测且 ∫|f| dμ < ∞
```

### 三、收敛定理与拉东–尼科迪姆定理（12.216–12.219）

```latex
lim_{n→∞} ∫ fₙ dμ = ∫ lim_{n→∞} fₙ dμ    （莱维：a.e. 递增非负列）  (12.216)
∫ liminf fₙ dμ ⩽ liminf ∫ fₙ dμ           （法图：非负可测列）      (12.217)
|fₙ| ⩽ g a.e., g 可积 ⟹ f 可积且
lim ∫ fₙ dμ = ∫ lim fₙ dμ                  （控制收敛）              (12.218)
φ ≺ μ（绝对连续）, σ-有限 ⟹ φ(A) = ∫_A f dμ （f 唯一至 a.e. 等价）  (12.219)
```

### 四、L^p 空间构造（12.220–12.221 及正文断言）

```latex
N_p(f) = (∫ |f|^p dμ)^{1/p},  1 ⩽ p < ∞（可能 = ∞）              (12.220)
N_∞(f) = ess sup f = inf{a ∈ ℝ : |f(x)| ⩽ a μ-a.e.}               (12.221)
% 𝓛^p(μ)：N_p < ∞ 的可测函数全体；N_p 为准范数（零空间 = a.e. 为零函数）
% 𝓛^p 是向量格乃至 K 空间（回指 12.1.7.4）
% L^p(μ) := 𝓛^p / N_p^{-1}(0)（a.e. 等价类），‖f̂‖_p = N_p(f) 成为范数
% (L^p(μ), ‖·‖_p) 为巴拿赫格（1 ⩽ p ⩽ ∞）
% p = 2：L²(μ) 为希尔伯特空间，(f, g) = ∫ f ḡ dμ
% μ(X) < ∞, 1 ⩽ p₁ < p₂ ⩽ ∞ ⟹ L^{p₂} ⊂ L^{p₁}，‖x‖_{p₁} ⩽ C‖x‖_{p₂}
% L^p(Ω, λ) 是 (𝒞(Ω), ‖·‖_p)（1 ⩽ p < ∞）的完备化
```

### 五、分布理论（12.222–12.230）

```latex
∫_Ω f D^α φ dλ = (−1)^{|α|} ∫_Ω φ D^α f dλ,  |α| ⩽ k   （分部积分） (12.222)
∫_Ω f D^α φ dλ = (−1)^{|α|} ∫_Ω g φ dλ ⟹ g = D^α f      （广义导数）(12.223)
φ_k → φ ⟺ a) ∃紧集 K ⊂ Ω: supp(φ_k) ⊂ K, ∀k;
              b) D^α φ_k ⇉ D^α φ 于 K 上                              (12.224)
φₙ → φ ⟹ ℓ(φₙ) → ℓ(φ)                                     （分布连续性）(12.225)
ℓ_f(φ) = (f, φ) = ∫_Ω f(x) φ(x) dλ                        （正则分布） (12.226)
(D^α ℓ)(φ) = (−1)^{|α|} ℓ(D^α φ)                                        (12.227)
(D¹f, φ) = ∫_ℝ f′φ dx = −∫_ℝ f φ′ dx [= −(f, φ′)，末项原文疑漏负号]    (12.228a,b)
(D^α ℓ_f)(φ) = (−1)^{|α|} ∫_Ω f D^α φ dλ（= 索伯列夫广义导数）        (12.229)
Θ(x) = {1, x ⩾ 0; 0, x < 0},  DΘ = δ                                   (12.230)
% 应用算例：ẍ + ω²x = F δ_{t₀}, x(0) = ẋ(0) = 0
%           ⟹ x(t) = (F/ω) sin(ω(t − t₀)) θ(t − t₀)   （复算通过）
```
