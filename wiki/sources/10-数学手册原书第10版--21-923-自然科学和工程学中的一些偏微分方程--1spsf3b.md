# 数学手册(原书第10版) 9.2.3 自然科学和工程学中的一些偏微分方程

## 定位

本源为《数学手册（原书第10版）》9.2.3 小节，是 [[10-数学手册原书第10版--8-92-偏微分方程--qyf9rv]]（9.2 偏微分方程）的子节，父概念页为 [[偏微分方程]]。手册在本节只给结论、不给推导；本库对全部公式组做了独立复算（见下文与各 finding 页）。

## 内容概要

引言指出：经典理论物理学中为无结构或连续变动的介质（气体、液体、固体、经典物理场）建模会导致偏微分方程；量子力学是基于对介质与场之不连续性认同的另一重要领域，其最重要的关系是 [[薛定谔方程]]（本源仅此一句提及，无展开）；二阶线性偏微分方程出现最频繁，在当今自然科学中有特殊重要性。

- **9.2.3.1 问题和边界条件的叙述**：定解问题的两个基本要求（条件组合在一起唯一确定解；解对条件的微小扰动稳定）构成 [[问题的正确叙述]]；双曲型方程配柯西问题、椭圆型方程配边值问题（[[二阶偏微分方程的类型]]）；非齐次条件与非齐次方程的化归（式 9.103，见 [[非齐次线性偏微分方程的齐次化与杜哈梅尔型代换]]）。
- **9.2.3.2 波方程**：[[波方程]]（式 9.104a，双曲型）与初始条件（式 9.105）；n = 3/2/1 的齐次柯西问题解分别为 [[基尔霍夫公式]]（9.106a）、[[泊松公式]]（9.106b）、[[达朗贝尔公式]]（9.106c）；非齐次附加项为 [[推迟位势]]（9.107a）及 n = 2、n = 1 形式（9.107b、9.107c）。
- **9.2.3.3 均匀介质的热导方程和扩散方程**：[[热导方程]]（式 9.108a–d，抛物型；柯西问题的有界性要求、高斯核解、t < 0 方向不适定）与 [[扩散方程]]（式 9.109）。
- **9.2.3.4 位势方程**：[[位势方程]]（泊松微分方程，式 9.110a）与其齐次情形 [[拉普拉斯微分方程]]（式 9.110b）；解法回指原书 13.5.2（第 951 页，未入库）。

(9.104a)  \frac{\partial^{2} u}{\partial t^{2}} - a^{2}\Delta u = Q(x, t)
(9.104b)  \Delta u = \frac{\partial^{2} u}{\partial x_{1}^{2}} + \frac{\partial^{2} u}{\partial x_{2}^{2}} + \dots + \frac{\partial^{2} u}{\partial x_{n}^{2}}
(9.105)   u\big|_{t=0} = \varphi(x), \quad \left.\frac{\partial u}{\partial t}\right|_{t=0} = \psi(x)

```latex
% 9.2.3.2.1 齐次问题（Q = 0）的解（式 9.106；源文"在〔n〕= l, 2, 〔1〕时"）
(9.106a, n=3, 基尔霍夫公式)
  u(x_{1}, x_{2}, x_{3}, t) = \frac{1}{4\pi a^{2}} \left[ \iint_{S_{at}} \frac{\psi(\alpha_{1}, \alpha_{2}, \alpha_{3})}{t}\, \mathrm{d}\sigma
    + \frac{\partial}{\partial t} \iint_{S_{at}} \frac{\varphi(\alpha_{1}, \alpha_{2}, \alpha_{3})}{t}\, \mathrm{d}\sigma \right]
  S_{at}: (\alpha_{1}-x_{1})^{2} + (\alpha_{2}-x_{2})^{2} + (\alpha_{3}-x_{3})^{2} = a^{2}t^{2}
(9.106b, n=2, 泊松公式)
  u(x_{1}, x_{2}, t) = \frac{1}{2\pi a} \left[ \iint_{C_{at}} \frac{\psi(\alpha_{1}, \alpha_{2})\, \mathrm{d}\alpha_{1}\mathrm{d}\alpha_{2}}{\sqrt{a^{2}t^{2} - (\alpha_{1}-x_{1})^{2} - (\alpha_{2}-x_{2})^{2}}}
    + \frac{\partial}{\partial t} \iint_{C_{at}} \frac{\varphi(\alpha_{1}, \alpha_{2})\, \mathrm{d}\alpha_{1}\mathrm{d}\alpha_{2}}{\sqrt{a^{2}t^{2} - (\alpha_{1}-x_{1})^{2} - (\alpha_{2}-x_{2})^{2}}} \right]
  C_{at}: (\alpha_{1}-x_{1})^{2} + (\alpha_{2}-x_{2})^{2} \leqslant a^{2}t^{2}
(9.106c, n=1, 达朗贝尔公式)
  u(x_{1}, t) = \frac{\varphi(x_{1}+at) + \varphi(x_{1}-at)}{2} + \frac{1}{2a} \int_{x_{1}-at}^{x_{1}+at} \psi(\alpha)\, \mathrm{d}\alpha
```

(9.107a, n=3, 推迟位势)
  \frac{1}{4\pi a^{2}} \iiint_{K} \frac{Q\left(\xi_{1}, \xi_{2}, \xi_{3},\, t - \frac{r}{a}\right)}{r}\, \mathrm{d}\xi_{1}\mathrm{d}\xi_{2}\mathrm{d}\xi_{3}
  r := \sqrt{(\xi_{1}-x_{1})^{2} + (\xi_{2}-x_{2})^{2} + (\xi_{3}-x_{3})^{2}} \leqslant at
(9.107b, n=2)
  \frac{1}{2\pi a} \iiint_{K} \frac{Q(\xi_{1}, \xi_{2}, \tau)\, \mathrm{d}\xi_{1}\mathrm{d}\xi_{2}\mathrm{d}\tau}{\sqrt{a^{2}(t-\tau)^{2} - (\xi_{1}-x_{1})^{2} - (\xi_{2}-x_{2})^{2}}}
  K: 0 \leqslant \tau \leqslant t,\ (\xi_{1}-x_{1})^{2} + (\xi_{2}-x_{2})^{2} \leqslant a^{2}(t-\tau)^{2}
(9.107c, n=1)
  \frac{1}{2a} \iint_{T} Q(\xi, \tau)\, \mathrm{d}\xi\, \mathrm{d}\tau
  T: 0 \leqslant \tau \leqslant t,\ |\xi - x_{1}| \leqslant a|t-\tau|
```

(9.108a)  \frac{\partial u}{\partial t} - a^{2}\Delta u = Q(x, t)
(9.108b)  u(x_{1}, x_{2}, x_{3}, t) = \frac{1}{(2a\sqrt{\pi t})^{n}}
            \iiint_{\mathbb{R}^{3}} f(\alpha_{1}, \alpha_{2}, \alpha_{3}) \cdot
            \exp\!\left(-\frac{(x_{1}-\alpha_{1})^{2} + (x_{2}-\alpha_{2})^{2} + (x_{3}-\alpha_{3})^{2}}{4a^{2}t}\right)
            \mathrm{d}\alpha_{1}\mathrm{d}\alpha_{2}\mathrm{d}\alpha_{3}
(9.108c)  \int_{0}^{t} \left[ \iiint_{\mathbb{R}^{3}} \frac{Q(\alpha_{1}, \alpha_{2}, \alpha_{3})}{[2a\sqrt{\pi(t-\tau)}]^{n}}
            \cdot \exp\!\left(-\frac{(x_{1}-\alpha_{1})^{2} + (x_{2}-\alpha_{2})^{2} + (x_{3}-\alpha_{3})^{2}}{4a^{2}(t-\tau)}\right)

(9.108d)  \frac{\partial T}{\partial t} - D_{W}\Delta T = Q_{W}(\vec{r}, t)   % u = T(温度场), a^2 = D_W
(9.109)   \frac{\partial C}{\partial t} - D_{C}\Delta C = Q_{C}(\vec{r}, t)
```

## 核心论点（按归属主体）

- **关于二阶线性偏微分方程整体**：连续介质建模导致 PDE；量子力学（[[薛定谔方程]]）基于不连续认同，是另一重要领域；二阶线性 PDE 出现最频繁、地位特殊。
- **关于定解问题（[[问题的正确叙述]]）**：解须同时满足方程与初始/边界条件且被其唯一确定，并须对条件的微小扰动稳定；双曲型方程（振动过程）的正确形式是柯西问题——在初始流形（曲线或曲面）上给出函数及其沿非切向（通常法向）导数的值；椭圆型方程（定态/平衡问题）的正确形式是边值问题，无界域还须在自变量无限增长时满足给定性质。
- **关于非齐次化归（式 9.103）**：可用满足给定非齐次条件的二次可微函数作差代换实现条件齐次化；解可分解为零条件非齐次方程解与给定条件齐次方程解之和；式 9.103c 的代换把齐次初始条件的非齐次方程归约为齐次方程族。
- **关于 [[波方程]]**：双曲型；n = 3/2/1 的齐次柯西问题分别由球面、圆盘、区间上的积分公式解出；非齐次情形叠加推迟位势等项；a 为扰动的波速；解称为波函数 u。
- **关于 [[热导方程]]**：抛物型；柯西问题的有界解保证唯一性；齐次解为高斯核卷积；由 u(x,0) 不能确定 t < 0 的解（该方向不能正确形成柯西问题）——时间不可逆；引入温度场 T 与 D_W 得式 9.108d。
- **关于 [[扩散方程]]**：浓度传播与热传导由同一方程描述，D_W 换 D_C 即得其解。
- **关于 [[位势方程]]**：Δu = −4πρ 确定由标量点函数 ρ(x) 决定的标量场的位势；ρ ≡ 0 时为 [[拉普拉斯微分方程]]；解在原书 13.5.2 讨论。

## 独立复算结论

- 式 9.106a 经换算（∬_{S_at}(·)/t dσ 连同前因子 1/(4πa²) 化为 1/(4πa²t)∮_{S_at}(·)dσ，亦可化为球面平均形式 (t/4π)∮_{S²}(·)dω）与标准基尔霍夫公式逐项吻合；式 9.106b、9.106c 分别与标准 n = 2 泊松公式、d'Alembert 公式完全一致（[[式9-106a至9-106c三维二维一维齐次解复算]]）。
- 式 9.107a–c 的积分域（后向锥 r ⩽ at、锥域 K、三角形域 T）与核结构均正确（[[式9-107a至9-107c非齐次附加项复算]]）。
- 式 9.108b 前因子 1/(2a√(πt))ⁿ = 1/(4πa²t)^{n/2}，为标准热核（[[式9-108a至9-108d热导方程柯西问题复算]]）。
- 式 9.103 的代换经对积分上限求导验证成立，且“L[u] 可含 ∂u/∂t 但不含关于 t 的高阶导数”的限制恰为必要条件——否则求导产生的附加项无法被式 9.103e 的条件吸收（[[式9-103a至9-103e非齐次化归代换逐字转录与复算]]）。
- 式 9.108c 结构正确，但印刷的 Q(α₁, α₂, α₃) 疑缺 τ 变元。
