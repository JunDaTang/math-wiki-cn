# 数学手册(原书第10版) 17.1.3 离散动力系统

《数学手册(原书第10版)》第 17 章 17.1 节的第三个子节，系统陈述由迭代 $x_{t+1}=\varphi(x_t)$ 定义的离散动力系统的定性理论：双曲平衡点的 $(m,k)$ 分型与一阶近似稳定性定理、周期轨的乘子判据、$\omega/\alpha$ 极限集的性质、稳定与不稳定流形（阿达马—佩龙定理）、横截同宿点，以及拓扑共轭与格罗布曼—哈特曼定理。本节以 [[entities/埃农映射]] (17.23) 为唯一具名算例，完整演示双曲平衡点局部不变流形的幂级数确定法，并以 $\varphi(x)=-x$ 反例指出离散系统的 $\omega$ 极限集可以不连通。本页是 [[sources/10-数学手册原书第10版--12-171-常微分方程与映射--pd13pm]] 的子节延伸。

## 章节结构

- **17.1.3.1 稳态、周期轨和极限集**：1 平衡点类型；2 周期轨；3 $\omega$ 极限集的性质（含 $\varphi(x)=-x$ 反例）
- **17.1.3.2 不变流形**：1 分界面；〔2〕阿达马—佩龙定理（小节编号"2."转写脱落）；·埃农映射算例与图 17.11；3 横截同宿点
- **17.1.3.3 离散系统的拓扑共轭**：1 定义；2 格罗布曼—哈特曼定理

（源文本中以"·"起段的段落为算例/反例，随所属小节编排。）

## 主要论断

**关于一般离散系统 (17.3)**：

- 平衡点分类与稳定性：汇渐近稳定，源与鞍点不稳定（离散系统一阶近似的稳定性定理，见 [[concepts/双曲平衡点]]）；
- 周期轨渐近稳定判据：所有乘子 $|\rho_i|<1$（见 [[concepts/周期轨与乘子]]）；
- $\omega$ 极限集的闭性、$\omega(\varphi(x))=\omega(x)$、有界正半轨的非空不变性；$\alpha$ 极限集类似（见 [[concepts/ω极限集与α极限集]]）；
- 阿达马—佩龙定理与格罗布曼—哈特曼定理（见 [[concepts/阿达马—佩龙定理]]、[[concepts/格罗布曼—哈特曼定理]]）。

**关于埃农映射 (17.23) 的算例**（核心可复算内容，全部断言经独立复算核验通过）：两个双曲平衡点 $P_{1,2}=(\pm\sqrt2,\pm\sqrt2)$；$P_1$ 处特征值 $\lambda_{1,2}=\sqrt2\pm\sqrt3$、$E^s=\mathrm{span}\{a_2\}$、$E^u=\mathrm{span}\{a_1\}$；局部不稳定流形图像化 $\eta=\beta(\xi)$，$\beta(\xi)=(\sqrt3-\sqrt2)\xi+k\xi^2+\cdots$，$k<0$。复算补充：$P_1$、$P_2$ 均为 $(1,1)$ 型鞍点；$k=-b_1^3/(1+b_1^3)\approx-0.0311$；手册形式经 $(x,y)\mapsto(-x,-y)$ 共轭于经典参数 $a=2,\ b=1$ 的 Hénon 映射。详见 [[entities/埃农映射]] 与 [[findings/式17-23埃农映射平衡点与不变流形转录复算]]。

**关于 $\varphi(x)=-x$ 的反例**：$\omega(1)=\{1,-1\}$ 不连通，与微分方程情形不同——这是"离散映射 vs 连续流"的对照，不可移植到流的结论上。详见 [[findings/φx等于负x的ω极限集算例转录复算]]。

## 关键公式（逐字转录）

```text
17.1.3.1.1 平衡点类型（M ⊂ ℝⁿ，x₀ 为方程 (17.3) 的平衡点）
  变分方程:  y_{t+1} = Dφ(x₀) y_t,  t ∈ T
  双曲平衡点: Dφ(x₀) 没有特征值 λ_i 满足 |λ_i| = 1
  (m,k) 型:  Dφ(x₀) 在复单位圆周内恰有 m 个特征值（原文脱 m 字），
             在复单位圆周外恰有 k = n − m 个特征值
  汇: m = n，渐近稳定；  源: k = n，不稳定；  鞍点: m > 0 且 k > 0，不稳定
  （离散系统一阶近似的稳定性定理）

17.1.3.1.2 周期轨
  γ(x₀) = {φ^k(x₀), k = 0, ⋯, T−1},  T ⩾ 2
  双曲周期轨: x₀ 是映射 φ^T 的双曲平衡点（原文"双曲 64"为乱码）
  单值矩阵:  Dφ^T(x₀) = Dφ(φ^{T−1}(x₀)) ⋯ Dφ(x₀)
  乘子:  Dφ^T(x₀) 的特征值 ρ_i
  判据:  所有 |ρ_i| < 1 ⇒ γ(x₀) 渐近稳定

17.1.3.1.3 ω 极限集（M = ℝⁿ）
  任意 ω 极限集是闭集；ω(φ(x)) = ω(x)
  正半轨 γ⁺(x) 有界 ⇒ ω(x) ≠ ∅ 且 ω(x) 是 φ 的不变集
  α 极限集有类似性质

  反例: 在 ℝ 上（原文"在匣上"疑误）φ(x) = −x, x_{t+1} = −x_t, t = 0, ±1, ⋯
  ω(1) = {1, −1},  ω(φ(1)) = ω(−1) = ω(1),  φ(ω(1)) = ω(1)
  ω(1) 不是连通集，这与微分方程情形不同

17.1.3.2.1 分界面
  W^s(x₀) = {y ∈ M : φ^i(y) → x₀ 当 i → +∞}（原文作 |i| → +∞，疑误）
  W^u(x₀) = {y ∈ M : φ^i(y) → x₀, i → −∞}
  稳定流形和不稳定流形也称为分界面

17.1.3.2.2 阿达马—佩龙定理（M ⊂ ℝⁿ）
  x₀ 是 (m,k) 型双曲平衡点 ⇒
    W^s(x₀)、W^u(x₀) 分别是 m 维和 k 维（原文"和 维"脱 k 字）的
    广义 C^r 光滑曲面，其局部类似 C^r 光滑基本曲面
    若当 i → +∞（对应地 i → −∞）时轨道不收敛到 x₀，
    则当 i → +∞（对应地 i → −∞）时该轨道会离开 x₀ 的某个充分小的邻域
    W^s(x₀)、W^u(x₀) 在 x₀ 处分别相切于 y_{i+1} = Dφ(x₀) y_i 的
    E^s = {y ∈ ℝⁿ : [Dφ(x₀)]^i y → 0 当 i → +∞}
    E^u = {y ∈ ℝⁿ : [Dφ(x₀)]^i y → 0 当 i → −∞}

17.1.3.2.3 横截同宿点
  W^s(x₀) ∩ W^u(x₀) 横截 ⇒ 任意 y ∈ W^s(x₀) ∩ W^u(x₀) 称为横截同宿点
  可逆系统中轨道 {φ^i(y)} 仅由横截同宿点构成

17.1.3.3.1 拓扑共轭定义
  对照系统: x_{t+1} = ψ(x_t)  (17.24),  N ⊂ ℝⁿ, ψ: N → N 连续
  （M 可以是一般度量空间）
  拓扑共轭 ⇔ 存在同胚 h: M → N 使 φ = h⁻¹ ∘ ψ ∘ h
  ⇒ h 将 (17.3) 的轨道映射为 (17.24) 的轨道

17.1.3.3.2 格罗布曼—哈特曼定理
  φ: ℝⁿ → ℝⁿ 是同胚映射，x₀ 是双曲平衡点 ⇒ 在 x₀ 的某个邻域内
  系统 (17.3) 与其线性化 y_{t+1} = Dφ(x₀) y_t 拓扑共轭
```

### 埃农映射算例（17.1.3.2，逐字转录）

```text
x_{i+1} = x_i² + y_i − 2,  y_{i+1} = x_i,  i ∈ ℤ                     (17.23)

系统 (17.23) 的两个双曲平衡点: P₁ = (√2, √2), P₂ = (−√2, −√2)

P₁ 局部稳定流形和不稳定流形的确定:
  变量替换 x_i = ξ_i + √2, y_i = η_i + √2 ⇒
    ξ_{i+1} = ξ_i² + 2√2 ξ_i + η_i,  η_{i+1} = ξ_i  （平衡点 (0,0)）
  雅可比 Df((0,0)) 对应于特征值 λ_{1,2} = √2 ± √3 的特征向量:
    a₁ = (√2 + √3, 1),  a₂ = (√2 − √3, 1)
  E^s = {t a₂ : t ∈ ℝ},  E^u = {t a₁ : t ∈ ℝ}
  设 W^u_loc((0,0)) = {(ξ, η) : η = β(ξ), |ξ| < Δ, β: (−Δ, Δ) [原文"厌可微"]}
  β 的幂级数形式: β(ξ) = (√3 − √2) ξ + k ξ² + ⋯
  由 (ξ_i, η_i) ∈ W^u_loc ⇒ (ξ_{i+1}, η_{i+1}) ∈ W^u_loc
  可导出关于 β 展开系数的方程〔原文此处整体脱文〕其中 k < 0
  图 17.11(a) 给出了稳定流形和不稳定流形的形状
```
