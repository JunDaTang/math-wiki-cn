## 章首定义（原文逐字）

> (1) 一个微分方程 是一个或多个变量，这些变量的一个或多个函数，以及这些函数关千所出现的这些变最的导数的一个方程．一个微分方程的阶 (order) 等千其中出现的导数最高的阶数．

> (2) 常微分方程和偏微分方程 相互间的差别在千它们的自变量的数目；在第一种情形只有一个自变量，在第二种情形有几个自变量

转写注意：上引两段存在系统性形近讹替——「等千」应为「等于」、「关千」应为「关于」、「变最」应为「变量」、「在千」应为「在于」（千/于凡 3 处、最/量 1 处），且段 (2) 句末脱句号「．」；逐字引用会传播讹文。校改依据与置信评估见 [[第9章章首定义形近讹替复校]]，全部待复核条目汇总于 [[第9章全节系统性转写讹误清单]]。

## 例式（原文 LaTeX 逐字保留）

```latex
A: $\left( { \frac { \mathrm { d } y } { \mathrm { d } x } } \right) ^ { 2 } - x y ^ { 5 } { \frac { \mathrm { d } y } { \mathrm { d } x } } + \sin y = 0 .$

■ B: $x \mathrm { d } ^ { 2 } y \mathrm { d } x - \mathrm { d } y ( \mathrm { d } x ) ^ { 2 } = \mathrm { e } ^ { y } ( \mathrm { d } y ) ^ { 3 }$

■ C: $\frac { \partial ^ { 2 } z } { \partial x \partial y } = x y z \frac { \partial z } { \partial x } \frac { \partial z } { \partial y } .$
```

三例判读（依章首定义推得，非源文明言，属判读而非直接证据）：

- 例 A：一阶常微分方程——y 为 x 的函数，出现的最高阶导数为一阶。
- 例 B：以微分形式（dx、dy 的齐次微分式）书写的常微分方程；若各项除以 (dx)³，形式上对应 x y″ − y′ = e^y (y′)³，为二阶。但原文排印中 d²y 与 dx 的乘积归属及括号范围含混，「二阶」之判读属推断，须对原书核验（见 [[第9章全节系统性转写讹误清单]]）。
- 例 C：二阶偏微分方程——z 为 x、y 两个自变量的函数，方程含二阶混合偏导数 ∂²z/∂x∂y。

另，源文件中例 A 之前无「■」标记而 B、C 皆有，疑为转写脱落。
