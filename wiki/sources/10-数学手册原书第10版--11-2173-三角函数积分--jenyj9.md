## 特殊函数定义（条目 283、322）

```latex
% 283
\int \frac{\sin ax}{x}\,\mathrm{d}x = ax - \frac{(ax)^{3}}{3\cdot 3!} + \frac{(ax)^{5}}{5\cdot 5!} - \frac{(ax)^{7}}{7\cdot 7!} + \cdots
% 定积分 ∫₀ˣ (sin t)/t dt 称作正弦积分（参见第 681 页 8.2.5），写作 si(x)
\mathrm{si}(x) = x - \frac{x^{3}}{3\cdot 3!} + \frac{x^{5}}{5\cdot 5!} - \frac{x^{7}}{7\cdot 7!} + \cdots

% 322
\int \frac{\cos ax}{x}\,\mathrm{d}x = \ln(ax) - \frac{(ax)^{2}}{2\cdot 2!} + \frac{(ax)^{4}}{4\cdot 4!} - \frac{(ax)^{6}}{6\cdot 6!} + \cdots
% 定积分 −∫ₓ^∞ (cos t)/t dt 称作余弦积分，表示为 Ci(x)；C 为欧拉常数
\operatorname{Ci}(x) = C + \ln x - \frac{x^{2}}{2\cdot 2!} + \frac{x^{4}}{4\cdot 4!} - \frac{x^{6}}{6\cdot 6!} + \cdots
```

详见 [[concepts/正弦积分与余弦积分]]；C 即 [[concepts/欧拉常数C]]；si 的小写记法存疑（[[queries/si与Si记法之辨]]）。
