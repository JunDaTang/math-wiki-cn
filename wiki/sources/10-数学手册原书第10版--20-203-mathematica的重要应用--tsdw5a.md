# 数学手册(原书第10版) 20.3 Mathematica的重要应用

## 文献定位

本源为《数学手册（原书第10版）》第 20 章第 20.3 节，是 [[entities/mathematica]] 应用能力的核心章节。本节自述选材原则：所考虑问题的选择和组织依据它们在实践中出现的频率，以及用计算机代数系统求解它们的可能性；讲解方式为就函数、命令、运算和附加句法（原文「旬法」为「句法」之转写讹误）给出例子。本节上承 20.2「Mathematica 的重要结构要素」（[[sources/10-数学手册原书第10版--22-202-mathematica的重要结构要素--1w5xyrj]]），并与 19.8.4「交互程序系统和计算机代数系统的应用」（[[sources/10-数学手册原书第10版--22-1984-交互程序系统和计算机代数系统的应用--k25qkm]]）的跨系统数值比较互补。

> 注：本源前次入库的提取止于 20.3.4.1；本次重写补全 20.3.4.2–20.3.4.4（不定积分、定积分与重积分、微分方程）并整节校核。

## 小节结构

1. **20.3.1 对于代数表达式的操作**：表达式的乘法（20.3.1.1）、多项式的因式分解（20.3.1.2，含高斯整数环）、关于多项式的运算（20.3.1.3）、部分分式分解（20.3.1.4）、对于非多项式表达式的操作（20.3.1.5，Simplify、Trig 选项与 ComplexExpand）。另指出菜单项「面板 → 其他 → 代数操作」。
2. **20.3.2 方程和方程组的解**：作为逻辑表达式的方程（20.3.2.1）、多项式方程的解（20.3.2.2，Solve/NSolve）、超越方程的解（20.3.2.3，FindRoot）、方程组的解（20.3.2.4，表 20.11）。
3. **20.3.3 线性方程组与本征值问题**：Array/Thread 构造（式 20.30–20.32）、特殊情形 Inverse（式 20.33）与一般情形 LinearSolve/NullSpace、三算例、本征值命令。
4. **20.3.4 微积分**：导数的计算（20.3.4.1，Derivative/D/Dt）、不定积分（20.3.4.2）、定积分和重积分（20.3.4.3）、微分方程的解（20.3.4.4，DSolve）。

## 核心主张

1. **代数层**：实践中出现的代数表达式常需进一步运算（微分、积分、级数表示、求极限值或数值、变换等），通常在整数环或实数域上考虑，其中有理数域上多项式的代数运算特别重要。表达式的乘法总可进行，系数亦可为未定义的表达式；因式分解在整数环或有理数域上如有可能则进行，否则返回原表达式；能在高斯整数环上完全分解者可经 GaussianIntegers 选项得到；部分分式分解在有理数域上进行，任何部分的分子次数总小于分母的次数。
2. **方程层**：方程是逻辑（布尔值）表达式；Solve 在某种意义上相继进行了 Roots 与 ToRules 运算；四次以下多项式方程有代数表达式形式的符号解，较高次方程若能经代数变换（如因式分解）化为较简单形式亦给符号解（此时 Solve 内部尝试运用 Expand 与 Decompose）；超越方程一般来说不可能有符号解且常有无穷多解，应给出求解区域的一个估计，用 FindRoot[g, {x, xs}] 以初值 xs 寻根。方程若能明确地在代数数域中求解，则解借助根式表示；不能给出封闭形式解时，至少可找到给定精度的数值解。
3. **线性代数层**：n = m 且 det P ≠ 0 时非齐次方程组有唯一解 X = Inverse[P].B；一般情形用 LinearSolve 与 NullSpace 可处理所有可能的情形（先确定是否存在解，存在则算出）；RowReduce 判定方程左边的独立性；n > 4 的矩阵本征值无代数表达式（特征多项式次数大于四），应求数值本征值。
4. **微积分层**：能用初等函数表示成封闭形式的不定积分将被找出且不带积分常数，找不到则返回原输入；发散的定积分触发 Integrate::idiv；重积分求值从右到左进行；DSolve 给出具有任意常数 C[i] 的通解（可以纯函数形式），不能解时返回输入而没有任何评论，符号解过繁时回指 19.8.4.2 求数值解；甚至在复杂的多维区域 Mathematica 也能求某些偏微分方程的符号解和数值解。

## 命令表（原文转录）

### 表 20.9 用于操作代数表达式的命令

| 命令 | 释义 |
|---|---|
| `Expand[p]` | 用乘法展开一个多项式 p 的幂和积 |
| `Expand[p,r]` | 仅乘开 p 中包含 r 的部分 |
| `PowerExpand[a]` | 也展开积的幂以及幂的幂 |
| `Factor[p]` | 将一个多项式完全因式分解 |
| `Collect[p,x]` | 将多项式按 x 的幂排序 |
| `Collect[p,{x,y,···}]` | 与前面一个相同，针对多个变元 |
| `ExpandNumerator[r]` | 仅展开一个有理表达式的分子 |
| `ExpandDenominator[r]` | 仅展开分母 |
| `ExpandAll[r]` | 将分子和分母都完全展开 |
| `Together[r]` | 将表达式中具有同分母的项合并 |
| `Apart[r]` | 将表达式表示成部分分式 |
| `Cancel[r]` | 消去分式中的公因式 |

### 表 20.10 代数多项式的运算

| 命令 | 释义 |
|---|---|
| `PolynomialGCD[p1,p2]` | 确定 p1 和 p2 的最大公因式 |
| `PolynomialLCM[p1,p2]` | 确定 p1 和 p2 的最小公倍式 |
| `PolynomialQuotient[p1,p2,x]` | 用 p2 除 p1（作为 x 的函数），略去余式 |
| `PolynomialRemainder[p1,p2,x]` | 确定 p2 除 p1 时的余式 |
| `MonomialList[p]` | 给出多项式 p 中所有单项式的列表 |

### 表 20.11 用于解方程组的运算

| 命令 | 释义 |
|---|---|
| `Solve[{l1 == r1, l2 == r2, ⋯}, vars]` | 关于 vars 解给定的方程组 |
| `Eliminate[{l1 == r1, ⋯}, vars]` | 从方程组消去 vars |
| `Reduce[{l1 == r1, ⋯}, vars]` | 化解方程组并给出可能的解 |
| `FindInstance[expr, vars]` | 找出一个使 expr 为真的 vars 的例证 |

（表 20.11 的运算提供符号解而非数值解；与单个未知数情形类似，NSolve 将给出数值解。）

### 表 20.12 求导运算

| 命令 | 释义 |
|---|---|
| `D[f[x], {x, n}]` | 得到函数 f(x) 关于 x 的 n 阶导数 |
| `D[f, {x1, n1}, {x2, n2},···]` | 多重导数，关于 xi（i = 1,2,···）的 ni 阶导数 |
| `Dt[f]` | 函数 f 的全微分 |
| `Dt[f, x]` | 函数 f 的全导数 df/dx |
| `Dt[f, x1, x2,···]` | 多元函数的全导数 |

### 表 20.13 求解微分方程的命令

| 命令 | 释义 |
|---|---|
| `DSolve[deq, y[x], x]` | （如果有可能）对于 y[x] 求解微分方程；y[x] 可以用隐式给出 |
| `DSolve[deq, y, x]` | 以纯函数的形式给出微分方程的解 |
| `DSolve[{deq1, deq2,···}, y, x]` | 解常微分方程组 |
