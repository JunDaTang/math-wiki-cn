# 数学手册(原书第10版) 20.2.8 函数运算

## 主旨

本页对应源文件「数学手册(原书第10版)/20.2.8 函数运算.md」，即第 20 章「Mathematica 的重要结构要素」的 20.2.8 小节，主题为**函数运算**：Mathematica 中函数的名称作为表达式处理（参见 [[concepts/表达式（Mathematica）]]），因此函数本身也可以当作运算对象。源文开篇（校读后）：「函数对于数和表达式做运算。Mathematica 也可以对函数进行运算，因为函数的名称是作为表达式来处理的，所以它们也可以当作表达式来处理。」

## 条目与命令签名（结构化转录，校读处以文义补正并见讹误清单）

| 条目 | 命令 | 源文定义（校读后） |
|---|---|---|
| (1) 反函数、级数反演 | InverseFunction、InverseSeries | 确定一个已知函数 f 的反函数可以通过函数运算来进行（仅列名，无语法无算例） |
| (2) 微分 | `Derivative[1][f]` / `f′` | 函数的微分可看成函数空间中的一个映射；若定义了函数，其导数可由 f′ 得到 |
| (3) | `Nest[f, x, n]` | 函数 f 作用于 x 后被嵌套进自身 n 次，结果为 f[f[···f[x]···]] |
| (4) | `NestList[f, x, n]` | 显示列表 {x, f[x], f[f[x]], …}，最终的 f 被嵌套 n 次 |
| (4) | `FoldList[f, x, list]` | 对两个变元的函数做迭代（仅此一句） |
| (5) | `FixedPoint[f, x]` | 重复应用该函数直到结果不再改变 |
| (6) | `FixedPointList[f, x]` | 显示应用 f 后结果的连续列表，直到这个值不再改变 |
| (7) | `Apply[f, {a,b,c,…}]` | → f[a, b, c, …]（式 20.22） |
| (8) | `Map[f, {a,b,c,…}]` | → {f[a], f[b], f[c], …}（式 20.23） |

## 定义式（逐字转录）

```
Apply[f, {a, b, c, ...}]  →  f[a, b, c, ...]          (20.22)
Map[f,   {a, b, c, ...}]  →  {f[a], f[b], f[c], ...}  (20.23)
```

公式编号承接：20.2.5 止于式 20.11–20.12（[[sources/10-数学手册原书第10版--15-2025-作为列表的向量和矩阵--o3sbi7]]），本节直接从 20.22 起，中间的 20.13–20.21 应属尚未入库的 20.2.6、20.2.7（见 [[queries/20-2-8未入库回指缺口]]）。

## 会话转录（经复算校订，存疑处以注标出）

### (2) 微分与纯函数

```
In[1] := f[x_] := Sin[x] Cos[x]
In[2] := f′       →  Out[2] = Cos[#1]^2 - Sin[#1]^2 &
In[3] := %[x]     →  Out[3] = Cos[x]^2 - Sin[x]^2
```

注：源文 Out[3] 误作小写 `cos[x]^2 - sin[x]^2`，与 Out[2] 大小写不一致。复算见 [[findings/In1至In3导数纯函数算例复算]]；纯函数记法（`#1` 与 `&`）在本节首次出现，见 [[concepts/Mathematica函数运算与纯函数]]。

### (6) 牛顿法算例（NestList 与 FixedPoint）

源文（校读后）：「作为这种类型的函数运算的一个例子，我们将使用 NestList 运算根据牛顿法（参见第 1234 页，19.1.1.2）对方程 f(x) = 0 的根作逼近。在 3π/2 的邻域中求方程 x cos x = sin x 的一个根」：

```
In[1] := f[x_] := x - Tan[x]
In[2] := f′[x]    →  Out[2] = 1 - Sec[x]^2
In[3] := g[x_] := x - f[x]/f′[x]   （源文作「In[3] =」，疑脱「:」，见 [[queries/In3之等号疑为冒号等号之辨]]）
In[4] := NestList[g, 4.6, 4]
         → Out[4] = {4.6, 4.54573, 4.50615, 4.49417, 4.49341}
In[5] := FixedPoint[g, 4.6] → Out[5] = 4.49341
```

源文随后称「该结果还可以达到更高的精度」——无演示、未经验证，作弱化处理。复算见 [[findings/牛顿法NestList-FixedPoint求根算例复算]]。

### (7) Apply（头替换）

```
In[1] := Apply[Plus, {u, v, w}]                → Out[1] = u + v + w
In[2] := Apply[List, a + b + c]                → Out[2] = {a, b, c}
In[3] := FullForm[Apply[List, Plus[a, b, c]]]  → Out[3] = List[a, b, c]
```

源文结论：「函数运算 Apply 以所求的 List 来代替所考虑的表达式 Plus 的头。」

### (8) Map（逐元映射）

```
In[1] := f[x_] := x^2
In[2] := Map[f, {u, v, w}]      → Out[2] = {u^2, v^2, w^2}
In[3] := Map[f, Plus[a, b, c]]  → Out[3] = a^2 + b^2 + c^2
```

## 证据强度

核心主张（函数名是表达式，函数本身可被运算）由定义式 (20.22)(20.23) 与六组 In/Out 会话支撑；本维基已逐项独立复算，全部吻合（三条 findings，confidence: high，replicated: true）。

## 覆盖不对称与未验证陈述

- InverseFunction、InverseSeries 仅列名，无语法、无算例，且该句脱函数名（见 [[concepts/反函数与级数反演]]）；
- FoldList、FixedPointList 仅一句定义，无算例；
- FixedPoint「直到结果不再改变」未说明 SameTest 与精度控制；「更高精度可达」未验证；
- (8) 先称「Map 生成一个列表」，随即演示非列表输出 `Map[f, Plus[a,b,c]] → a²+b²+c²`，源文以「Map 可以被应用于更一般的表达式」自我调和，属表述张力而非讹误。
