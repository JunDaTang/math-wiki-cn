# 数学手册(原书第10版) 20.2.10 关于句法、信息、消息的补充

本节隶属 20.2 Mathematica 的重要结构要素（[[sources/10-数学手册原书第10版--22-202-mathematica的重要结构要素--1w5xyrj]]），是该组结构要素讲解的收尾补充，围绕 [[entities/mathematica]] 的四个主题展开：语境与符号全名（20.2.10.1）、符号属性（20.2.10.1）、信息查询（20.2.10.2）、消息系统（20.2.10.3）。本节未出现新的人物、组织或数据集（Wolfram Research 亦未在文中出现）；全部论断均针对 Mathematica，不可移用于 Maple 或 Matlab。

## 内容概要

### 语境与符号全名（20.2.10.1）

详见 [[concepts/语境与符号全名（Mathematica）]]。要点：符号完整名称 = 语境 + 短名称，以反引号相连（转写讹作撇号）；短名称即表达式头与元素的名称（拼写规则见 [[concepts/Mathematica符号命名规则]]）；启动时即有 `` System` `` 与 `` Global` `` 两语境——内置函数属前者，用户定义函数属后者；Contexts[] 列出其他可用语境；以 `<<NamePackage` 读入另一程序模块时其语境被打开并引入列表；同名遮蔽触发警告，可以 ``Remove[Global`name]`` 擦去旧名，或对新近载入的符号改用完整名称。

### 符号属性（20.2.10.1）

详见 [[concepts/符号属性（Mathematica）]]。符号除按定义具有的性质外可被指定一般性质（属性）：Orderless（无序/可交换）、Protected（值不可更改）、Locked（属性不可更改）等；Attributes[] 查询，Protect[] 保护（不得再引入其他定义），Unprotect[] 解除。

### 信息查询（20.2.10.2）

详见 [[concepts/信息查询（Mathematica）]]。四级手段：?symbol 基本信息、??symbol 详细信息、?模式*（名称匹配列表，本转写脱失）、?:= 等特殊算子查询（如查询 SetDelayed），以及光标置于符号处按 F1（原书称最实用）。

### 消息系统（20.2.10.3）

详见 [[concepts/消息系统（Mathematica）]]。消息在计算期间产生并显示，统一形式 symbol::tag，亦可由用户自建；Off[s::tag] 关闭单条、On[s::tag] 重开、Quiet 关闭所有、Messages[symbol] 重现与符号关联的全部消息。

## 算例逐字转录

（消息标记中的冒号间空格已按 symbol::tag 格式归一：「Power: :infy」→ Power::infy、「Log: :argt」→ Log::argt；「Mes sages」→ Messages；例 B 的「Out [1]」空格亦归一。）

```txt
■ A: In[1] := f[x_] := 1/x; In[2] := f[0]
Power::infy: Infinite expression 1/0 encountered.
Out[2] = ComplexInfinity
```

```txt
■ B: In[1] := Log[3, 16, 25]
Log::argt: Log called with 3 arguments; 1 or 2 arguments are expected.
Out[1] = Log[3, 16, 25]
```

例 A 为警告型：发出 Power::infy 后计算本身仍可执行，返回 ComplexInfinity；例 B 为错误型：对数函数按定义只接受 1 或 2 个自变量，3 个自变量不被允许，计算无法执行，Mathematica 对该表达式不能做任何事情，原样返回。二者构成刻意对照，见 [[comparisons/警告消息与错误消息后果比较]]，复算见 [[findings/算例A与B消息触发复算]]。

## 命令清单（转录）

| 命令 | 语义 |
|---|---|
| Contexts[] | 列出可用语境（程序模块） |
| ``Remove[Global`name]`` | 彻底移除符号，消解同名遮蔽 |
| Attributes[symbol] | 查询符号现有属性 |
| Protect[symbol] / Unprotect[symbol] | 设置 / 解除 Protected 保护 |
| ?symbol / ??symbol | 查询对象的基本 / 详细信息 |
| ?模式* | 列出名称匹配的对象（本转写脱失） |
| ?:= | 查询特殊算子（如 SetDelayed）的信息 |
| Off[s::tag] / On[s::tag] | 关闭 / 重开单条消息 |
| Quiet | 关闭所有消息 |
| Messages[symbol] | 重现与符号关联的全部消息 |

## 证据强度与局限

- 强证据：Power::infy 与 Log::argt 均为 Mathematica 真实消息标记，两算例行为与现行版本一致，可复算；语境、属性、消息诸机制为跨版本稳定语义。
- 局限：本转写文本 OCR 讹误极密集（千/于 系统性互讹、乱码、脱字、回指残缺等），凡措辞级断言须回查原书后方可在正文页定稿；讹误总汇见 [[queries/20-2-10全节系统性转写讹误清单]]，其中消息关闭命令乱码与撇号/反引号问题分别单列于 [[queries/消息关闭命令乱码疑为Off之辨]]、[[queries/System与Global撇号疑为反引号之辨]]。
