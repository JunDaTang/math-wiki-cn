# 数学手册(原书第10版) 18.2.6 演化策略

## 概述

本页收录《数学手册(原书第10版)》18.2 非线性优化系列第 6 分节「演化策略」。该分节系统引入**演化策略**——模拟自然演化的随机优化过程的方法族，以**突变、重组、选择**三个原理为骨架，依次给出通用演化算法（18.2.6.2）、策略分类记号（18.2.6.3）、正态随机数生成（18.2.6.4）、应用定位（18.2.6.5）、(1+1) 突变—选择策略及其步长控制（18.2.6.6）、种群策略（18.2.6.7）。式 18.87–18.94 为本节全部编号公式，本页逐式转录。

与 18.2.1–18.2.2 所代表的解析路径（[[库恩—塔克条件]]、[[拉格朗日函数]]、[[优化中的对偶性]]、[[凸优化]]）不同，演化策略属于**非微分（免导数）解法**：仅依赖目标函数值的比较，不要求目标函数可微或连续。本节由此把 18.2 系列的方法版图从确定性解析方法扩展到随机搜索方法，部分回应 [[18-2小节覆盖与开放问题待明]]（覆盖自 18.2.2 推进至 18.2.6）。

## 分节结构与要点

### 18.2.6.1 演化原理

演化策略基于三个原理：

1. **突变**（[[突变（演化策略）]]）：从亲本 $\underline{x}_P$ 通过随机变化形成后裔 $\underline{x}_O = \underline{x}_P + \underline{d}$，$\underline{d}$ 的分量为每次突变重新确定的正态随机变量（式 18.87）。正态分布下小变化概率很高、大变化很少出现，幅度受标准差 $\sigma_i$ 控制。
2. **重组**（[[中间重组与离散重组]]）：对有 μ 个亲本的种群，通过混杂随机选择的两个或更多个亲本信息获得后代；分中间形式（ρ 个亲本的加权平均，式 18.88）与离散形式（逐分量取自随机选中的亲本，式 18.89）。
3. **选择**：目标函数 $f(\underline{x})$ 作为比较个体适应性的度量，最适应的个体选作下一代。某些策略下仅子孙后代参与选择，有些策略亲本也参与选择（参见 [18.9]）。

### 18.2.6.2 演化算法

每一种演化策略都基于同一算法骨架（a)–d) 步），详见 [[演化策略基本迭代流程]]。

### 18.2.6.3 演化策略的分类

每个演化策略由一列参数刻画，最重要的参数是种群大小 μ、后代个数 λ、参与重组的亲本数 ρ，以及实施突变、重组和选择的规则。仅用突变产生后代的策略记 (μ+λ) 或 (μ,λ)，区别在选择类型：(μ,λ) 仅在子孙中选择新一代；(μ+λ) 中新一代的选择也涉及母体。使用重组的策略记 (μ/ρ+λ)、(μ/ρ,λ)，亲本数 ρ 体现于记号中。

### 18.2.6.4 生成随机数

数值评估需要均匀和正态分布随机变量：均匀随机变量的值可由手册 16.3.5.2（原文伴页码 1100）给出的方法得到；正态随机变量由 [[博克斯—穆勒方法]]（式 18.90）自两个 [0,1] 均匀随机数生成两个统计独立的 N(0,σ²) 随机数。

### 18.2.6.5 演化策略的应用

优化问题通常「高度复制」（疑为「高度复杂」之讹，见 [[高度复制疑为高度复杂之辨]]），常规优化过程（18.2.5，原文伴页码 1209）往往不适合。演化策略属于非微分解法，基于目标函数值的比较，对目标函数结构要求很简单——不需可微或连续——从而适于相当广泛的优化问题。应用不限于无约束连续优化：带约束问题可经在目标函数中添加惩罚项处理（前向引用 18.2.8 罚函数法与障碍函数法，原文伴页码 1221）；离散演化情形下，变量 x 的部分或全部分量可从某个离散集取值，一种突变机制是以等概率方式用某个相邻值取代离散分量值。

### 18.2.6.6 (1+1) 突变—选择策略

类似 18.2.5 中介绍的梯度法，差别在方向 $d^k$ 是正态分布的随机向量；种群由单个个体组成，每代只产生一个后代（详见 [[1+1突变—选择策略]]）。步长 α 反映收敛速度：太小导致滞止，太大引起过调。步长控制有两条路径：**1/5 成功法则**（式 18.93，c=0.8…0.85）与**扩展模型**（α 与 σᵢ 以等概率乘 c、1、1/c，c=1.1…1.5，细节见 [18.9]），详见 [[1-5成功法则]]。

### 18.2.6.7 种群策略

(1+1) 策略仅以十分简单的方式反映自然演化原理；推广到种群模型时可考虑演化过程的进一步性质——大量个体确保解空间的不同区域都会被搜索到。

- **(μ+λ) 演化策略**：是 (1+1) 策略的推广。从当前一代 μ 个亲本 $X_P^k$ 以等概率随机选择一组 λ 个母体（允许重复选择；μ < λ 时重复选择是必须的），经突变产生 λ 个后代 $X_O^k$；从候选组 $X_O^k \cup X_P^k$ 中选最佳 μ 个进入下一代。由于亲本也参与选择，种群代际质量不可能更差；能保持已找出的局部最优（逃离需大的突变，其概率非常小）；个体可能有无限寿命，可对亲本目标函数值加逐代递增的惩罚项以模拟个体变老。
- **(μ,λ) 演化策略**：与 (μ+λ) 相反，仅在 λ 个后裔中挑 μ 个作为下一代，亲本不再活下来，故必须有 λ > μ；后代目标函数值可能大于亲本的；这一程序可以从局部最优点开始。
- **选择压力**（[[选择压力]]，式 18.94）：参与选择的个体与种群大小之比。
- **带重组的 (μ/ρ+λ)、(μ/ρ,λ) 策略**：λ 个后代的每个成员都从一组亲本中以等概率独立选取 ρ 个亲本，后代是所选亲本的离散或中间重组，再经突变进入选择。无重组时每个体只是一系列突变应用于第 k 代亲本中一个成员的结果；采用重组可能出现更一般的演化方式，尤其当亲本彼此相隔遥远时，其后代会具有新的特性。
- **多种群演化策略**（[[多种群演化策略]]）：竞争不再在个体间而在种群间，演化过程包含两个层级，记号 $[\mu_2/\varrho_2 + \lambda_2(\mu_1/\varrho_1 + \lambda_1)]$。

## 核心公式转录（式 18.87–18.94）

突变算子（式 18.87）：

```latex
\underline{d} =
\begin{pmatrix} d_1 \\ d_2 \\ \vdots \\ d_n \end{pmatrix}
=
\begin{pmatrix} Z(0,\sigma_1^2) \\ Z(0,\sigma_2^2) \\ \vdots \\ Z(0,\sigma_n^2) \end{pmatrix}
=
\begin{pmatrix} Z(0,1)\cdot\sigma_1 \\ Z(0,1)\cdot\sigma_2 \\ \vdots \\ Z(0,1)\cdot\sigma_n \end{pmatrix}
\tag{18.87}
```

中间重组（式 18.88）与离散重组（式 18.89）：

```latex
\underline{x}_O = \sum_{i=1}^{\varrho} \alpha_i \underline{x}_{P_i},
\quad \sum_{i=1}^{\varrho} \alpha_i = 1, \quad 2 \leqslant \varrho \leqslant \mu
\tag{18.88}
```

```latex
x_{iO} = x_{iP_j}, \quad j \in \{1,\dots,\varrho\}, \quad i = 1,\dots,n
\tag{18.89}
```

博克斯—穆勒方法（式 18.90；$G_1$、$G_2$ 为 [0,1] 均匀随机数）：

```latex
Z_1(0,\sigma^2) = \sigma\sqrt{-2\ln G_1}\cos(2\pi G_2) \quad \text{和} \quad
Z_2(0,\sigma^2) = \sigma\sqrt{-2\ln G_1}\sin(2\pi G_2)
\tag{18.90}
```

(1+1) 策略的突变（式 18.91）与选择（式 18.92）：

```latex
\underline{x}_O^k = \underline{x}_P^k + \alpha \underline{d}^k
\tag{18.91}
```

```latex
\underline{x}_P^{k+1} =
\begin{cases}
\underline{x}_O^k, & f(\underline{x}_O^k) < f(\underline{x}_P^k),\\
\underline{x}_P^k, & \text{其他},
\end{cases}
\tag{18.92}
```

1/5 成功法则（式 18.93）：

```latex
\alpha_{k+1} =
\begin{cases}
c\cdot\alpha_k, & q < 1/5,\\
\dfrac{1}{c}\cdot\alpha_k, & q > 1/5,
\end{cases}
\quad c = 0.8,\dots,0.85
\tag{18.93}
```

选择压力（式 18.94）：

```latex
S = \begin{cases}
\dfrac{\lambda+\mu}{\mu}, & \text{对于 } (\lambda+\mu) \text{ 策略},\\[6pt]
\dfrac{\lambda}{\mu}, & \text{对于 } (\lambda,\mu) \text{ 策略},
\end{cases}
\quad 1 \leqslant S < \infty
\tag{18.94}
```

多种群记号：

```latex
[\mu_2/\varrho_2 + \lambda_2(\mu_1/\varrho_1 + \lambda_1)]
```

通用演化算法（18.2.6.2）：

| 步骤 | 内容 |
|---|---|
| a) | 确定由 μ 个个体组成的适当的初始种群，作为第 1 代亲本 $X_P^1 = \{\underline{x}_{P_1}^1, \dots, \underline{x}_{P_\mu}^1\}$ |
| b) | 在第 k 步中，通过当前一代亲本 $X_P^k$ 的突变和重组产生 λ 个后代 $X_O^k = \{\underline{x}_{O_1}^k, \dots, \underline{x}_{O_\lambda}^k\}$ |
| c) | 通过选择得到最佳的 μ 个个体作为下一代亲本 $X_P^{k+1} = \{\underline{x}_{P_1}^{k+1}, \dots, \underline{x}_{P_\mu}^{k+1}\}$ |
| d) | 重复步骤 b)–c)，直到满足停止规则：满足优化问题的最优判据、达到指定的代际数、超过给定的电脑时间等 |

## 定性行为主张与证据强度

以下断言在源中无证明或实验支撑（经验性断言，证据强度：中）：

- 关于 (μ+λ)：代际质量不可能更差；保持已找出的局部最优；个体可能无限寿命（可用递增惩罚项模拟衰老）。
- 关于 (μ,λ)：后代目标函数值可能劣于亲本；可从局部最优点开始（逃逸可能）。
- 关于步长：小步长致滞止，大步长致过调；最优步长依赖所研究的问题。
- 关于选择压力：S 接近 1 时选择几乎无影响；λ ≫ μ 导致很大选择压力。
- 参数推荐值 c=0.8…0.85 与 c=1.1…1.5 为经验取值，文中自承 1/5 法则「是一种粗略的选择」。

公式 18.87–18.94 为手册性陈述（证据强度：高），与演化策略标准文献一致，均可独立数学复算（式 18.90 可解析验证），复算记录见 [[式18-87至18-89三算子定义转录复算]]、[[式18-90博克斯—穆勒变换复算]]、[[式18-91至18-93（1+1）策略与1-5法则复算]]、[[式18-94选择压力公式转录]]。

## 转写讹误与内部疑点

转写存在系统性讹误（「千／于」「入／λ」「尘／x」等），完整清单见 [[18-2-6全节系统性转写讹误清单]]；回指缺口（18.2.5、18.2.8、16.3.5.2、[18.9]）见 [[18-2-6未入库回指缺口]]。单项立页之辨：

- [[λ+μ与μ+λ记号顺序之辨]]：18.2.6.3 与 18.2.6.7.1 主体用 (μ+λ)/(μ,λ)，而 18.2.6.7.1 末段与式 18.94 用 (λ+μ)/(λ,μ)。
- [[后代δx记号疑为x之辨]]：离散重组定义中后代记号 $\underline{\mathbf{\delta x}}_O$。
- [[高度复制疑为高度复杂之辨]]：18.2.6.5 首句。
- [[顶组疑为亲本组之辨]]：18.2.6.7.4 的「顶组」。

内部张力（非讹误，须留意）：

- 符号 α 双重含义：式 18.88 中 αᵢ 为重组权重，式 18.91 中 α 为突变步长。
- (μ+λ) 与 (μ,λ) 的权衡（保持局部最优 vs 允许劣化以逃逸）是设计权衡而非矛盾，由 [[选择压力]] 统摄，见 [[μ+λ与μ，λ演化策略比较]]。
- 18.2.6.6 终止条件「如果在达到指定的代际数时没有更好的后代，则此程序终止」句读含糊，代数上限与改进判据混述。
