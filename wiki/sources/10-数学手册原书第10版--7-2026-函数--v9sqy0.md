# 数学手册（原书第10版）20.2.6 函数

本页对应源文件「数学手册(原书第10版)/20.2.6 函数.md」，为手册第 20 章 20.2「Mathematica 的重要结构要素」（父节源页见 [[sources/10-数学手册原书第10版--22-202-mathematica的重要结构要素--1w5xyrj]]）之下的小节。全节以 [[entities/mathematica]] 为唯一论述对象，分三小节：20.2.6.1 标准函数、20.2.6.2 特殊函数、20.2.6.3 纯函数。其中纯函数（无名函数的双记法与 `#` 占位符机制）是本节真正的新知识点；两份函数表以原样保存为主。

**表 20.7 若干标准函数**（原表题脱「表」字，此处补足）：

| 函数类 | Mathematica 记号 |
|---|---|
| 指数函数 | `Exp[x]` |
| 对数函数 | `Log[x]`, `Log[b,x]` |
| 三角函数 | `Sin[x]`, `Cos[x]`, `Tan[x]`, `Cot[x]`, `Sec[x]`, `Csc[x]` |

## 20.2.6.3 纯函数

原文定义（句读按文义补正，讹误标注见 [[queries/20-2-6全节系统性转写讹误清单]]）：Mathematica 支持使用所谓的纯函数。一个纯函数是一个无名函数，一个没有赋予名称的运算。它们被记作 `Function[x, body]`：第一个自变量指定形式参数，第二个自变量是函数主体，即主体（body）是变元的函数的一个表达式（原文行内 body 与变元符号脱失）。

三例算例（式 20.13–20.15）原样转录：

```text
In[1] := Function[x, x^3 + x^2]  ⟶  Out[1] = Function[x, x^3 + x^2]   (20.13)
In[2] := Function[x, x^3 + x^2][c]  给出  Out[2] = c^2 + c^3           (20.14)
In[3] := (#^3 + #^2)&[c]   Out[3] = c^2 + c^3                          (20.15)
```

多变元与记号要点（原文转录）：也可以定义具有多个变元的纯函数：`Function[{x1, x2, ...}, body]` 或简化形式 `body&`，其中主体中的变元用元素 `#1, #2, ...` 表示。用于结束表达式的符号 `&` 非常重要，因为从这个符号可以看出前面的表达式应该被认作一个纯函数。要指出的是 `#&` 即恒等函数：对于任何自变量（原文此处变元符号脱失）它指派 x（原文作「X」，疑为小写 x 之误植）。类似地「＃ ＆」相应于在第一个坐标轴上的投影（疑脱「1」，即 `#1 &`，见 [[queries/纯函数投影记号疑脱1之辨]]）。

展开见 [[concepts/纯函数（Mathematica）]]；复算与考据见 [[findings/式20-13至20-15纯函数算例转录复算]]。

## 转写讹误概要

本节转写讹误共六类，逐条收录与考据见 [[queries/20-2-6全节系统性转写讹误清单]]：

1. 「千」代「于」共 6 处（列千表 20.7、对千实函数、对千以复数为自变量、列千表 20.8、对千任何自变量、相应千在第一个坐标轴上）。
2. 表 20.7、20.8 标题均脱「表」字。
3. 句读脱失 3 处（「…所谓的纯函数一个纯函数…」脱句号；「对于任何自变量 它指派 X」变元脱失；「…专门程序包加载」句末脱句号）。
4. 行内数学变量脱失：「即主体 是变元 的函数的一个表达式」中 body 与 x 脱失；「它指派 X」之 X 疑为 x 且大写误植。
5. 「类似地＃ ＆」中「＃ ＆」疑脱「1」（见 [[queries/纯函数投影记号疑脱1之辨]]）。
6. 全角＃、＆与半角 #、& 混用（正文全角、In[3] 半角）。

## 复核结论

- 表 20.7、20.8 记号经逐一核验，全部为合法 Mathematica 记号，表内未发现讹误（[[findings/表20-7与20-8函数名清单转录校勘]]）。
- 式 20.14、20.15 复算吻合；Out 的升幂项序（c^2 + c^3）恰合 Mathematica canonical 排序，为转录忠实性的旁证（[[findings/式20-13至20-15纯函数算例转录复算]]）。
- 式 20.13 的 Out[1] 显示形态与朴素复算不合，属推断性版本考据问题，不径断为讹误（详见该 finding 页）。
