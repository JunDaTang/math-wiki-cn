# 数学手册(原书第10版) 5.4.2 线性丢番图方程

本页是《数学手册（原书第10版）》5.4「初等数论」下第一个详录小节 **5.4.2 线性丢番图方程** 的入库摘要。该小节给出线性丢番图方程的标准形（式 5.240）、可解性判据（gcd 整除判据）、n=2 时的完整解法（除以 gcd、贝祖组合、通解公式 5.241b），以及 n>2 时逐次降元的归约方法（式 5.242a–d），并配三个算例：114x+315y=3、114x+315y=6、2x+4y+3z=3。父节概览见 [[sources/10-数学手册原书第10版--7-54-初等数论--lpefv4]]，主题概念见 [[concepts/初等数论]] 与 [[concepts/线性丢番图方程]]。

## 小节结构

1. **丢番图方程**：总纲定义与命名由来（纪念希腊数学家丢番图，约公元 250 年），并附知识现状——一般解迄今只对两个未知数、至多二次的方程已知。
2. **n 个未知数的线性丢番图方程**：标准形 (5.240)，只求整数解。
3. **可解性条件**：系数不全为零时可解 ⟺ gcd(a₁,…,aₙ) ∣ b；n>1 且 ℤ 为变量区域时，有解则有无穷多解、解集含 n−1 个自由变量。
4. **n=2 时的解法**：除以 gcd 后由贝祖组合得特解，通解为 (5.241b)。
5. **n>2 时的归约方法**：固定 xₙ，将可解条件归结为二元方程 (5.242d)，迭代降元。

## 公式原样保留

```text
(5.240)  a₁x₁ + a₂x₂ + ⋯ + aₙxₙ = b    (aᵢ ∈ ℤ, b ∈ ℤ)
(5.241a) a₁x₁ + a₂x₂ = b    (a₁, a₂) ≠ (0, 0)
(5.241b) {(x₁⁰ + t·a₂′, x₂⁰ − t·a₁′) | t ∈ ℤ}
(5.242a) a₁x₁ + a₂x₂ + ⋯ + aₙxₙ = b
(5.242b) a₁x₁ + a₂x₂ + ⋯ + aₙ₋₁xₙ₋₁ = b − aₙxₙ
(5.242c) gcd(a₁, a₂, ⋯, aₙ₋₁) ∣ b − aₙxₙ
(5.242d) gcd(a₁, a₂, ⋯, aₙ₋₁)·c + aₙ·cₙ = b
(5.243a) 2x + 4y + 3z = 3
(5.243b) 2x + 4y = 3 − 3z
(5.243c) x + 2y = −3 + 3t
```

## 主要内容与主张

- **可解性判据**（[[findings/线性丢番图方程可解性判据与无穷解结构]]）：系数不全为零时，(5.240) 可解当且仅当 gcd(a₁,…,aₙ) 是 b 的因子。算例 114x+315y=3 可解，因 gcd(114,315)=3（已复算：114=2·3·19，315=3²·5·7）。
- **无穷解与自由参数**：n>1、ℤ 为变量区域时有解 ⟹ 无穷多解，解集含 n−1 个自由变量；原文明示「对 ℤ 的子集，这个命题不正确」（该句转写脱字严重，语义为重构）。
- **n=2 解法**（[[findings/二元线性丢番图方程通解与114x315y6算例]]）：除以 gcd 得 a₁′x₁+a₂′x₂=b′（gcd(a₁′,a₂′)=1），由贝祖组合 a₁′c₁′+a₂′c₂′=1（出处：原书 5.4.1.4, 4.，未入库）得特解 (c₁′b′, c₂′b′)，通解为 (5.241b)。算例 114x+315y=6 中 38·47+105·(−17)=1 与特解 (94,−34) 均已复算通过。
- **n>2 归约方法**（[[methodology/多元线性丢番图方程归约求解流程]]、[[findings/三元线性丢番图方程归约算例2x4y3z3]]）：(5.242c) ⟺ (5.242d) 的双向蕴含已逐项复核；算例 2x+4y+3z=3 全程复算通过，最终解集 {(3−3t+2s, −3+3t−s, 3−2t) | s,t∈ℤ} 代入恒等于 3，且恰含 2 = n−1 个自由参数。

## 两处已验证疑点

1. **例题解集系数讹误**：书中给出 114x+315y=6 的解集为 {(94+315t, −34−114t) | t∈ℤ}，与通解公式 (5.241b) 所要求的约化系数 (a₂′, a₁′)=(105, 38) 矛盾；正确解集应为 {(94+105t, −34−38t) | t∈ℤ}。数学验证：反例 (199,−72) 满足方程（114·199−315·72=6）却不在书中集合内。该讹误仅归属本例题陈述，不波及定理本身。见 [[queries/例题解集94+315t是否应为94+105t]]。
2. **转写中间式不相容**：正文「2x+4y = 3−3(2t)」与其后的 x+2y=−3+3t 不相容；由 z=3−2t 代回应为 2x+4y = 3−3(3−2t) = −6+6t。最终结论不受影响。见 [[queries/式5-243中间式3-3-2t是否应为-6+6t]]。
