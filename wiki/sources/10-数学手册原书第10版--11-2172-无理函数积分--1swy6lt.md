# 数学手册(原书第10版) 21.7.2 无理函数积分

## 概述

本源是 [[数学手册(原书第10版)]] 21.7「不定积分」的无理函数子表（母节源页见 [[10-数学手册原书第10版--8-217-不定积分--jkzn21]]），收录编号公式 109–273 凡 **165 条**（其中 247、255 于转录中整条脱失，已重构），按根式类型分十个小节，是 [[不定积分表]] 的无理函数部分。全节方法论总纲为根式代换（见 [[无理函数积分]]）：线性根式族借 $\Delta = bf - ag$、二次根式族借 $\Delta = 4ac - b^2$ 与 $k = 4a/\Delta$ 实现紧凑表达；三族标准二次根式 $\sqrt{a^2-x^2}$、$\sqrt{x^2+a^2}$、$\sqrt{x^2-a^2}$（157–240）呈严格的 [[二次根式三族平行结构]]，并系统采用 [[反双曲函数与对数双形式]] 记法；末条 273 为 [[二项式微分递推公式]]。

本页转录十小节记号定义与全部公式（数学内容忠实转录，OCR 间距噪声已归一；已知转写讹误以 `%` 注记标示，汇总见 [[21-7-2全节系统性转写讹误清单]]）。

## 公式全录

### 21.7.2.1 含 $\sqrt{x}$ 和 $a^2 \pm b^2 x$ 的积分（109–116）

```latex
X = a^2 \pm b^2 x,\qquad
Y = \begin{cases}
\arctan\dfrac{b\sqrt{x}}{a}, & \text{取符号 “}+\text{”},\\
\dfrac{1}{2}\ln\dfrac{a+b\sqrt{x}}{a-b\sqrt{x}}, & \text{取符号 “}-\text{”.}
\end{cases}

109.\ \int\frac{\sqrt{x}\,\mathrm{d}x}{X} = \pm\frac{2\sqrt{x}}{b^2} \mp \frac{2a}{b^3}Y.
110.\ \int\frac{\sqrt{x^3}\,\mathrm{d}x}{X} = \pm\frac{2}{3}\frac{\sqrt{x^3}}{b^2} - \frac{2a^2\sqrt{x}}{b^4} + \frac{2a^3}{b^5}Y.
111.\ \int\frac{\sqrt{x}\,\mathrm{d}x}{X^2} = \mp\frac{\sqrt{x}}{b^2X} \pm \frac{1}{ab^3}Y.
112.\ \int\frac{\sqrt{x^3}\,\mathrm{d}x}{X^2} = \pm\frac{2\sqrt{x^3}}{b^2X} + \frac{3a^2\sqrt{x}}{b^4X} - \frac{3a}{b^5}Y.
113.\ \int\frac{\mathrm{d}x}{X\sqrt{x}} = \frac{2}{ab}Y.
114.\ \int\frac{\mathrm{d}x}{X\sqrt{x^3}} = -\frac{2}{a^2\sqrt{x}} \mp \frac{2b}{a^3}Y.
115.\ \int\frac{\mathrm{d}x}{X^2\sqrt{x}} = \frac{\sqrt{x}}{a^2X} + \frac{1}{a^3b}Y.
116.\ \int\frac{\mathrm{d}x}{X^2\sqrt{x^3}} = -\frac{2}{a^2X\sqrt{x}} \mp \frac{3b^2\sqrt{x}}{a^4X} \mp \frac{3b}{a^5}Y.
```

### 21.7.2.2 含 $\sqrt{x}$ 的其他积分（117–120）

```latex
117.\ \int\frac{\sqrt{x}\,\mathrm{d}x}{a^4+x^2}
= -\frac{1}{2a\sqrt{2}}\ln\frac{x+a\sqrt{2x}+a^2}{x-a\sqrt{2x}+a^2} + \frac{1}{a\sqrt{2}}\arctan\frac{a\sqrt{2x}}{a^2-x}.
118.\ \int\frac{\mathrm{d}x}{(a^4+x^2)\sqrt{x}}
= \frac{1}{2a^3\sqrt{2}}\ln\frac{x+a\sqrt{2x}+a^2}{x-a\sqrt{2x}+a^2} + \frac{1}{a^3\sqrt{2}}\arctan\frac{a\sqrt{2x}}{a^2-x}.  % 编号脱落
119.\ \int\frac{\sqrt{x}\,\mathrm{d}x}{a^4-x^2}
= \frac{1}{2a}\ln\frac{a+\sqrt{x}}{a-\sqrt{x}} - \frac{1}{a}\arctan\frac{\sqrt{x}}{a}.
120.\ \int\frac{\mathrm{d}x}{(a^4-x^2)\sqrt{x}}
= \frac{1}{2a^3}\ln\frac{a+\sqrt{x}}{a-\sqrt{x}} + \frac{1}{a^3}\arctan\frac{\sqrt{x}}{a}.
```

### 21.7.2.3 含 $\sqrt{ax+b}$ 的积分（121–145）

```latex
注：X = ax + b

121.\ \int\sqrt{X}\,\mathrm{d}x = \frac{2}{3a}\sqrt{X^3}.
122.\ \int x\sqrt{X}\,\mathrm{d}x = \frac{2(3ax-2b)\sqrt{X^3}}{15a^2}.
123.\ \int x^2\sqrt{X}\,\mathrm{d}x = \frac{2(15a^2x^2-12abx+8b^2)\sqrt{X^3}}{105a^3}.
124.\ \int\frac{\mathrm{d}x}{\sqrt{X}} = \frac{2\sqrt{X}}{a}.
125.\ \int\frac{x\,\mathrm{d}x}{\sqrt{X}} = \frac{2(ax-2b)}{3a^2}\sqrt{X}.
126.\ \int\frac{x^2\,\mathrm{d}x}{\sqrt{X}} = \frac{2(3a^2x^2-4abx+8b^2)\sqrt{X}}{15a^3}.  % 编号后句点脱落
127.\ \int\frac{\mathrm{d}x}{x\sqrt{X}} =
\begin{cases}
-\dfrac{2}{\sqrt{b}}\operatorname{Arcoth}\sqrt{\dfrac{X}{b}} = \dfrac{1}{\sqrt{b}}\ln\dfrac{\sqrt{X}-\sqrt{b}}{\sqrt{X}+\sqrt{b}}, & b>0,\\
\dfrac{2}{\sqrt{-b}}\arctan\sqrt{\dfrac{X}{-b}}, & b<0.
\end{cases}  % 原转录中编号 127 嵌于两行条件之间，版面错乱（数学内容验证无误）
128.\ \int\frac{\sqrt{X}}{x}\,x = 2\sqrt{X} + b\int\frac{\mathrm{d}x}{x\sqrt{X}}\quad(\text{参见 127}).  % 末「x」疑脱「d」，应为 dx（右端求导验证无误）
129.\ \int\frac{\mathrm{d}x}{x^2\sqrt{X}} = -\frac{\sqrt{X}}{bx} - \frac{a}{2b}\int\frac{\mathrm{d}x}{x\sqrt{X}}\quad(\text{参见 127}).
130.\ \int\frac{\sqrt{X}}{x^2}\,\mathrm{d}x = -\frac{\sqrt{X}}{x} + \frac{a}{2}\int\frac{\mathrm{d}x}{x\sqrt{X}}\quad(\text{参见 127}).
131.\ \int\frac{\mathrm{d}x}{x^n\sqrt{X}} = -\frac{\sqrt{X}}{(n-1)bx^{n-1}} - \frac{(2n-3)a}{(2n-2)b}\int\frac{\mathrm{d}x}{x^{n-1}\sqrt{X}}.
132.\ \int\sqrt{X^3}\,\mathrm{d}x = \frac{2\sqrt{X^5}}{5a}.
133.\ \int x\sqrt{X^3}\,\mathrm{d}x = \frac{2}{35a^2}\left(5\sqrt{X^7} - 7b\sqrt{X^5}\right).
134.\ \int x^2\sqrt{X^3}\,\mathrm{d}x = \frac{2}{a^3}\left(\frac{\sqrt{X^9}}{9} - \frac{2b\sqrt{X^7}}{7} + \frac{b^2\sqrt{X^5}}{5}\right).
135.\ \int\frac{\sqrt{X^3}}{x}\,\mathrm{d}x = \frac{2\sqrt{X^3}}{3} + 2b\sqrt{X} + b^2\int\frac{\mathrm{d}x}{x\sqrt{X}}\quad(\text{参见 127}).
136.\ \int\frac{x\,\mathrm{d}x}{\sqrt{X^3}} = \frac{2}{a^2}\left(\sqrt{X} + \frac{b}{\sqrt{X}}\right).
137.\ \int\frac{x^2\,\mathrm{d}x}{\sqrt{X^3}} = \frac{2}{a^3}\left(\frac{\sqrt{X^3}}{3} - 2b\sqrt{X} - \frac{b^2}{\sqrt{X}}\right).  % 编号脱落
138.\ \int\frac{\mathrm{d}x}{x\sqrt{X^3}} = \frac{2}{b\sqrt{X}} + \frac{1}{b}\int\frac{\mathrm{d}x}{x\sqrt{X}}\quad(\text{参见 127}).
139.\ \int\frac{\mathrm{d}x}{x^2\sqrt{X^3}} = -\frac{1}{bx\sqrt{X}} - \frac{3a}{b^2\sqrt{X}} - \frac{3a}{2b^2}\int\frac{\mathrm{d}x}{x\sqrt{X}}\quad(\text{参见 127}).  % 编号脱落
140.\ \int X^{\pm n/2}\,\mathrm{d}x = \frac{2X^{(2\pm n)/2}}{a(2\pm n)}.
141.\ \int xX^{\pm n/2}\,\mathrm{d}x = \frac{2}{a^2}\left(\frac{X^{(4\pm n)/2}}{4\pm n} - \frac{bX^{(2\pm n)/2}}{2\pm n}\right).
142.\ \int x^2X^{\pm n/2}\,\mathrm{d}x = \frac{2}{a^3}\left(\frac{X^{(6\pm n)/2}}{6\pm n} - \frac{2bX^{(4\pm n)/2}}{4\pm n} + \frac{b^2X^{(2\pm n)/2}}{2\pm n}\right).  % 编号脱落
143.\ \int\frac{X^{n/2}\,\mathrm{d}x}{x} = \frac{2X^{n/2}}{n} + b\int\frac{X^{(n-2)/2}}{x}\,\mathrm{d}x.
144.\ \int\frac{\mathrm{d}x}{xX^{n/2}} = \frac{2}{(n-2)bX^{(n-2)/2}} + \frac{1}{b}\int\frac{\mathrm{d}x}{xX^{(n-2)/2}}.
145.\ \int\frac{\mathrm{d}x}{x^2X^{n/2}} = -\frac{1}{bxX^{(n-2)/2}} - \frac{na}{2b}\int\frac{\mathrm{d}x}{xX^{n/2}}.
```

### 21.7.2.4 含 $\sqrt{ax+b}$ 和 $\sqrt{fx+g}$ 的积分（146–156）

```latex
注：X = ax + b,\ Y = fx + g,\ \Delta = bf - ag

146.\ \int\frac{\mathrm{d}x}{\sqrt{XY}} =
\begin{cases}
-\dfrac{2}{\sqrt{-af}}\arctan\sqrt{-\dfrac{fX}{aY}}, & af<0,\\
\dfrac{2}{\sqrt{af}}\operatorname{Artanh}\sqrt{\dfrac{fX}{aY}}, & af>0,\\
\dfrac{2}{\sqrt{af}}\ln\left(\sqrt{aY}+\sqrt{fX}\right), & af>0.
\end{cases}  % 案例 2、3 为等价冗余（相差常数），非矛盾
147.\ \int\frac{x\,\mathrm{d}x}{\sqrt{XY}} = \frac{\sqrt{XY}}{af} - \frac{ag+bf}{2af}\int\frac{\mathrm{d}x}{\sqrt{XY}}\quad(\text{参见 146}).  % 编号脱落
148.\ \int\frac{\mathrm{d}x}{\sqrt{X}\sqrt{Y^3}} = -\frac{2\sqrt{X}}{\Delta\sqrt{Y}}.
149.\ \int\frac{\mathrm{d}x}{Y\sqrt{X}} =
\begin{cases}
\dfrac{2}{\sqrt{-\Delta f}}\arctan\dfrac{f\sqrt{X}}{\sqrt{-\Delta f}}, & \Delta f<0,\\
\dfrac{1}{\sqrt{\Delta f}}\ln\dfrac{f\sqrt{X}-\sqrt{\Delta f}}{f\sqrt{X}+\sqrt{\Delta f}}, & \Delta f>0.
\end{cases}
150.\ \int\sqrt{XY}\,\mathrm{d}x = \frac{\Delta+2aY}{4af}\sqrt{XY} - \frac{\Delta^2}{8af}\int\frac{\mathrm{d}x}{\sqrt{XY}}\quad(\text{参见 146}).
151.\ \int\sqrt{\frac{Y}{X}}\,\mathrm{d}x = \frac{1}{a}\sqrt{XY} - \frac{\Delta}{2a}\int\frac{\mathrm{d}x}{\sqrt{XY}}\quad(\text{参见 146}).
152.\ \int\frac{\sqrt{X}\,\mathrm{d}x}{Y} = \frac{2\sqrt{X}}{f} + \frac{\Delta}{f}\int\frac{\mathrm{d}x}{Y\sqrt{X}}\quad(\text{参见 149}).
153.\ \int\frac{Y^n\,\mathrm{d}x}{\sqrt{X}} = \frac{2}{(2n+1)a}\left(\sqrt{X}Y^n - n\Delta\int\frac{Y^{n-1}\,\mathrm{d}x}{\sqrt{X}}\right).  % 编号脱落（155 之「参见153)」为内证）
154.\ \int\frac{\mathrm{d}x}{\sqrt{X}Y^n} = -\frac{1}{(n-1)\Delta}\left\{\frac{\sqrt{X}}{Y^{n-1}} + \left(n-\frac{3}{2}\right)a\int\frac{\mathrm{d}x}{\sqrt{X}Y^{n-1}}\right\}.  % 双 \tag 杂排
155.\ \int\sqrt{X}Y^n\,\mathrm{d}x = \frac{1}{(2n+3)f}\left(2\sqrt{X}Y^{n+1} + \Delta\int\frac{Y^n\,\mathrm{d}x}{\sqrt{X}}\right)\quad(\text{参见 153}).  % 双 \tag 杂排
156.\ \int\frac{\sqrt{X}\,\mathrm{d}x}{Y^n} = \frac{1}{(n-1)f}\left(-\frac{\sqrt{X}}{Y^{n-1}} + \frac{a}{2}\int\frac{\mathrm{d}x}{\sqrt{X}Y^{n-1}}\right).  % 编号后句点脱落
```

### 21.7.2.5 $\sqrt{a^2-x^2}$ 的积分（157–184）

```latex
注：X = a^2 - x^2

157.\ \int\sqrt{X}\,\mathrm{d}x = \frac{1}{2}\left(x\sqrt{X} + a^2\arcsin\frac{x}{a}\right).
158.\ \int x\sqrt{X}\,\mathrm{d}x = -\frac{1}{3}\sqrt{X^3}.
159.\ \int x^2\sqrt{X}\,\mathrm{d}x = -\frac{x}{4}\sqrt{X^3} + \frac{a^2}{8}\left(x\sqrt{X} + a^2\arcsin\frac{x}{a}\right).
160.\ \int x^3\sqrt{X}\,\mathrm{d}x = \frac{\sqrt{X^5}}{5} - a^2\frac{\sqrt{X^3}}{3}.
161.\ \int\frac{\sqrt{X}}{x}\,\mathrm{d}x = \sqrt{X} - a\ln\frac{a+\sqrt{X}}{x}.
162.\ \int\frac{\sqrt{X}}{x^2}\,\mathrm{d}x = -\frac{\sqrt{X}}{x} - \arcsin\frac{x}{a}.
163.\ \int\frac{\sqrt{X}}{x^3}\,\mathrm{d}x = -\frac{\sqrt{X}}{2x^2} + \frac{1}{2a}\ln\frac{a+\sqrt{X}}{x}.  % 编号后句点脱落
164.\ \int\frac{\mathrm{d}x}{\sqrt{X}} = \arcsin\frac{x}{a}.
165.\ \int\frac{x\,\mathrm{d}x}{\sqrt{X}} = -\sqrt{X}.
166.\ \int\frac{x^2\,\mathrm{d}x}{\sqrt{X}} = -\frac{x}{2}\sqrt{X} + \frac{a^2}{2}\arcsin\frac{x}{a}.
167.\ \int\frac{x^3\,\mathrm{d}x}{\sqrt{X}} = \frac{\sqrt{X^3}}{3} - a^2\sqrt{X}.
168.\ \int\frac{\mathrm{d}x}{x\sqrt{X}} = -\frac{1}{a}\ln\frac{a+\sqrt{X}}{x}.
169.\ \int\frac{\mathrm{d}x}{x^2\sqrt{X}} = -\frac{\sqrt{X}}{a^2x}.
170.\ \int\frac{\mathrm{d}x}{x^3\sqrt{X}} = -\frac{\sqrt{X}}{2a^2x^2} - \frac{1}{2a^3}\ln\frac{a+\sqrt{X}}{x}.
171.\ \int\sqrt{X^3}\,\mathrm{d}x = \frac{1}{4}\left(x\sqrt{X^3} + \frac{3a^2x}{2}\sqrt{X} + \frac{3a^4}{2}\arcsin\frac{x}{a}\right).
172.\ \int x\sqrt{X^3}\,\mathrm{d}x = -\frac{1}{5}\sqrt{X^5}.
173.\ \int x^2\sqrt{X^3}\,\mathrm{d}x = -\frac{x\sqrt{X^5}}{6} + \frac{a^2x\sqrt{X^3}}{24} + \frac{a^4x\sqrt{X}}{16} + \frac{a^6}{16}\arcsin\frac{x}{a}.
174.\ \int x^3\sqrt{X^3}\,\mathrm{d}x = \frac{\sqrt{X^7}}{7} - \frac{a^2\sqrt{X^5}}{5}.
175.\ \int\frac{\sqrt{X^3}}{x}\,\mathrm{d}x = \frac{\sqrt{X^3}}{3} + a^2\sqrt{X} - a^3\ln\frac{a+\sqrt{X}}{x}.
176.\ \int\frac{\sqrt{X^3}}{x^2}\,\mathrm{d}x = -\frac{\sqrt{X^3}}{x} - \frac{3}{2}x\sqrt{X} - \frac{3}{2}a^2\arcsin\frac{x}{a}.
177.\ \int\frac{\sqrt{X^3}}{x^3}\,\mathrm{d}x = -\frac{\sqrt{X^3}}{2x^2} - \frac{3\sqrt{X}}{2} + \frac{3a}{2}\ln\frac{a+\sqrt{X}}{x}.
178.\ \int\frac{\mathrm{d}x}{\sqrt{X^3}} = \frac{x}{a^2\sqrt{X}}.
179.\ \int\frac{x\,\mathrm{d}x}{\sqrt{X^3}} = \frac{1}{\sqrt{X}}.
180.\ \int\frac{x^2\,\mathrm{d}x}{\sqrt{X^3}} = \frac{x}{\sqrt{X}} - \arcsin\frac{x}{a}.
181.\ \int\frac{x^3\,\mathrm{d}x}{\sqrt{X^3}} = \sqrt{X} + \frac{a^2}{\sqrt{X}}.
182.\ \int\frac{\mathrm{d}x}{x\sqrt{X^3}} = \frac{1}{a^2\sqrt{X}} - \frac{1}{a^3}\ln\frac{a+\sqrt{X}}{x}.
183.\ \int\frac{\mathrm{d}x}{x^2\sqrt{X^3}} = \frac{1}{a^4}\left(-\frac{\sqrt{X}}{x} + \frac{x}{\sqrt{X}}\right).
184.\ \int\frac{\mathrm{d}x}{x^3\sqrt{X^3}} = -\frac{1}{2a^2x^2\sqrt{X}} + \frac{3}{2a^4\sqrt{X}} - \frac{3}{2a^5}\ln\frac{a+\sqrt{X}}{x}.
```

### 21.7.2.6 $\sqrt{x^2+a^2}$ 的积分（185–212）

```latex
注：X = x^2 + a^2  % 原转录以 | | 代「注」框

185.\ \int\sqrt{X}\,\mathrm{d}x = \frac{1}{2}\left(x\sqrt{X} + a^2\operatorname{Arsinh}\frac{x}{a}\right) + C
= \frac{1}{2}\left[x\sqrt{X} + a^2\ln\left(x+\sqrt{X}\right)\right] + C_1.
186.\ \int x\sqrt{X}\,\mathrm{d}x = \frac{1}{3}\sqrt{X^3}.
187.\ \int x^2\sqrt{X}\,\mathrm{d}x = \frac{x}{4}\sqrt{X^3} - \frac{a^2}{8}\left(x\sqrt{X} + a^2\operatorname{Arsinh}\frac{x}{a}\right) + C
= \frac{x}{4}\sqrt{X^3} - \frac{a^2}{8}\left[x\sqrt{X} + a^2\ln\left(x+\sqrt{X}\right)\right] + C_1.  % 原转录首字符「∫」讹为「\left\{」
188.\ \int x^3\sqrt{X}\,\mathrm{d}x = \frac{\sqrt{X^5}}{5} - \frac{a^2\sqrt{X^3}}{3}.
189.\ \int\frac{\sqrt{X}}{x}\,\mathrm{d}x = \sqrt{X} - a\ln\frac{a+\sqrt{X}}{x}.
190.\ \int\frac{\sqrt{X}}{x^2}\,\mathrm{d}x = -\frac{\sqrt{X}}{x} + \operatorname{Arsinh}\frac{x}{a} + C = -\frac{\sqrt{X}}{x} + \ln\left(x+\sqrt{X}\right) + C_1.
191.\ \int\frac{\sqrt{X}}{x^3}\,\mathrm{d}x = -\frac{\sqrt{X}}{2x^2} - \frac{1}{2a}\ln\frac{a+\sqrt{X}}{x}.
192.\ \int\frac{\mathrm{d}x}{\sqrt{X}} = \operatorname{Arsinh}\frac{x}{a} + C = \ln\left(x+\sqrt{X}\right) + C_1.
193.\ \int\frac{x\,\mathrm{d}x}{\sqrt{X}} = \sqrt{X}.
194.\ \int\frac{x^2\,\mathrm{d}x}{\sqrt{X}} = \frac{x}{2}\sqrt{X} - \frac{a^2}{2}\operatorname{Arsinh}\frac{x}{a} + C = \frac{x}{2}\sqrt{X} - \frac{a^2}{2}\ln\left(x+\sqrt{X}\right) + C_1.
195.\ \int\frac{x^3\,\mathrm{d}x}{\sqrt{X}} = \frac{\sqrt{X^3}}{3} - a^2\sqrt{X}.
196.\ \int\frac{\mathrm{d}x}{x\sqrt{X}} = -\frac{1}{a}\ln\frac{a+\sqrt{X}}{x}.
197.\ \int\frac{\mathrm{d}x}{x^2\sqrt{X}} = -\frac{\sqrt{X}}{a^2x}.
198.\ \int\frac{\mathrm{d}x}{x^3\sqrt{X}} = -\frac{\sqrt{X}}{2a^2x^2} + \frac{1}{2a^3}\ln\frac{a+\sqrt{X}}{x}.
199.\ \int\sqrt{X^3}\,\mathrm{d}x = \frac{1}{4}\left(x\sqrt{X^3} + \frac{3a^2x}{2}\sqrt{X} + \frac{3a^4}{2}\operatorname{Arsinh}\frac{x}{a}\right) + C
= \frac{1}{4}\left(x\sqrt{X^3} + \frac{3a^2x}{2}\sqrt{X} + \frac{3a^4}{2}\ln\left(x+\sqrt{X}\right)\right) + C_1.  % 编号脱落
200.\ \int x\sqrt{X^3}\,\mathrm{d}x = \frac{1}{5}\sqrt{X^5}.
201.\ \int x^2\sqrt{X^3}\,\mathrm{d}x = \frac{x\sqrt{X^5}}{6} - \frac{a^2x\sqrt{X^3}}{24} - \frac{a^4x\sqrt{X}}{16} - \frac{a^6}{16}\operatorname{Arsinh}\frac{x}{a} + C
= \frac{x\sqrt{X^5}}{6} - \frac{a^2x\sqrt{X^3}}{24} - \frac{a^4x\sqrt{X}}{16} - \frac{a^6}{16}\ln\left(x+\sqrt{X}\right) + C_1.  % 编号脱落
202.\ \int x^3\sqrt{X^3}\,\mathrm{d}x = \frac{\sqrt{X^7}}{7} - \frac{a^2\sqrt{X^5}}{5}.
203.\ \int\frac{\sqrt{X^3}}{x}\,\mathrm{d}x = \frac{\sqrt{X^3}}{3} + a^2\sqrt{X} - a^3\ln\frac{a+\sqrt{X}}{x}.

【重构（求导证实）】\int\frac{x^2\,\mathrm{d}x}{\sqrt{X^3}} = -\frac{x}{\sqrt{X}} + \operatorname{Arsinh}\frac{x}{a} + C = -\frac{x}{\sqrt{X}} + \ln\left(x+\sqrt{X}\right) + C_1.

```

### 21.7.2.7 $\sqrt{x^2-a^2}$ 的积分（213–240）

```latex
= \frac{x\sqrt{X^5}}{6} + \frac{a^2x\sqrt{X^3}}{24} - \frac{a^4x\sqrt{X}}{16} + \frac{a^6}{16}\ln\left(x+\sqrt{X}\right) + C_1.  % 编号脱落
```

### 21.7.2.8 $\sqrt{ax^2+bx+c}$ 的积分（241–267）

```latex
注：X = ax^2 + bx + c,\ \Delta = 4ac - b^2,\ k = \frac{4a}{\Delta}

241.\ \int\frac{\mathrm{d}x}{\sqrt{X}} =
\begin{cases}
\frac{1}{\sqrt{a}}\ln\left(2\sqrt{aX} + 2ax + b\right) + C, & a>0,\\
\frac{1}{\sqrt{a}}\operatorname{Arsinh}\frac{2ax+b}{\sqrt{\Delta}} + C_1, & a>0,\ \Delta>0,\\
\frac{1}{\sqrt{a}}\ln\left(2ax+b\right), & a>0,\ \Delta=0,\\
-\frac{1}{\sqrt{-a}}\arcsin\frac{2ax+b}{\sqrt{-\Delta}}, & a<0,\ \Delta<0.
\end{cases}  % 案例表看似缺「a<0, Δ>0」，但该情形下 X 恒负、根式无实值，覆盖实为完备
242.\ \int\frac{\mathrm{d}x}{X\sqrt{X}} = \frac{2(2ax+b)}{\Delta\sqrt{X}}.
243.\ \int\frac{\mathrm{d}x}{X^2\sqrt{X}} = \frac{2(2ax+b)}{3\Delta\sqrt{X}}\left(\frac{1}{X} + 2k\right).
244.\ \int\frac{\mathrm{d}x}{X^{(2n+1)/2}} = \frac{2(2ax+b)}{(2n-1)\Delta X^{(2n-1)/2}} + \frac{2k(n-1)}{2n-1}\int\frac{\mathrm{d}x}{X^{(2n-1)/2}}.
245.\ \int\sqrt{X}\,\mathrm{d}x = \frac{(2ax+b)\sqrt{X}}{4a} + \frac{1}{2k}\int\frac{\mathrm{d}x}{\sqrt{X}}\quad(\text{参见 241}).
246.\ \int X\sqrt{X}\,\mathrm{d}x = \frac{(2ax+b)\sqrt{X}}{8a}\left(X + \frac{3}{2k}\right) + \frac{3}{8k^2}\int\frac{\mathrm{d}x}{\sqrt{X}}\quad(\text{参见 241}).  % 双 \tag 杂排
247.【整条脱失，246 与 248 之间无任何残留。重构（由 248 取 n=2，求导证实）】
\int X^2\sqrt{X}\,\mathrm{d}x = \frac{(2ax+b)\sqrt{X^5}}{12a} + \frac{5}{6k}\int X\sqrt{X}\,\mathrm{d}x\quad(\text{参见 246}).
248.\ \int X^{(2n+1)/2}\,\mathrm{d}x = \frac{(2ax+b)X^{(2n+1)/2}}{4a(n+1)} + \frac{2n+1}{2k(n+1)}\int X^{(2n-1)/2}\,\mathrm{d}x\quad(\text{参见 241}).
249.\ \int\frac{x\,\mathrm{d}x}{\sqrt{X}} = \frac{\sqrt{X}}{a} - \frac{b}{2a}\int\frac{\mathrm{d}x}{\sqrt{X}}\quad(\text{参见 241}).

252.\ \int\frac{x^2\,\mathrm{d}x}{\sqrt{X}} = \left(\frac{x}{2a} - \frac{3b}{4a^2}\right)\sqrt{X} + \frac{3b^2-4ac}{8a^2}\int\frac{\mathrm{d}x}{\sqrt{X}}\quad(\text{参见 241}).  % 编号脱落
253.\ \int\frac{x^2\,\mathrm{d}x}{X\sqrt{X}} = \frac{(2b^2-4ac)x + 2bc}{a\Delta\sqrt{X}} + \frac{1}{a}\int\frac{\mathrm{d}x}{\sqrt{X}}\quad(\text{参见 241}).
254.\ \int x\sqrt{X}\,\mathrm{d}x = \frac{X\sqrt{X}}{3a} - \frac{b(2ax+b)}{8a^2}\sqrt{X} - \frac{b}{4ak}\int\frac{\mathrm{d}x}{\sqrt{X}}\quad(\text{参见 241}).  % 双 \tag 杂排
255.【整条脱失，254 之后仅存残句「（参见246).」。重构（由 256 取 n=1，求导证实）】
\int x\sqrt{X^3}\,\mathrm{d}x = \frac{\sqrt{X^5}}{5a} - \frac{b}{2a}\int X\sqrt{X}\,\mathrm{d}x\quad(\text{参见 246}).
256.\ \int xX^{(2n+1)/2}\,\mathrm{d}x = \frac{X^{(2n+3)/2}}{(2n+3)a} - \frac{b}{2a}\int X^{(2n+1)/2}\,\mathrm{d}x\quad(\text{参见 248}).

258.\ \int\frac{\mathrm{d}x}{x\sqrt{X}} =
\begin{cases}
-\frac{1}{\sqrt{c}}\ln\left(\frac{2\sqrt{cX}}{x} + \frac{2c}{x} + b\right) + C, & c>0,\\
-\frac{1}{\sqrt{c}}\operatorname{Arsinh}\frac{bx+2c}{x\sqrt{\Delta}} + C_1, & c>0,\ \Delta>0,\\
-\frac{1}{\sqrt{c}}\ln\frac{bx+2c}{x}, & c>0,\ \Delta=0,\\

\end{cases}  % 末行条件原转录作「c < , Δ < 0」，「c <」后脱「0」；「c<0, Δ>0」情形下 X 恒负，无需列入

262.\ \int\frac{X^{(2n+1)/2}}{x}\,\mathrm{d}x = \frac{X^{(2n+1)/2}}{2n+1} + \frac{b}{2}\int X^{(2n-1)/2}\,\mathrm{d}x + c\int\frac{X^{(2n-1)/2}}{x}\,\mathrm{d}x\quad(\text{参见 248、260}).  % 「参见248 260」疑脱「和」或顿号
263.\ \int\frac{\mathrm{d}x}{x\sqrt{ax^2+bx}} = -\frac{2}{bx}\sqrt{ax^2+bx}.
264.\ \int\frac{\mathrm{d}x}{\sqrt{2ax-x^2}} = \arcsin\frac{x-a}{a}.
265.\ \int\frac{x\,\mathrm{d}x}{\sqrt{2ax-x^2}} = -\sqrt{2ax-x^2} + a\arcsin\frac{x-a}{a}.
```

### 21.7.2.10 二项式微分型积分的递推公式（273，逐字）

```latex
273.\ \int x^{m}(ax^{n}+b)^{p}\,\mathrm{d}x
= \frac{1}{m+np+1}\left[x^{m+1}(ax^{n}+b)^{p} + npb\int x^{m}(ax^{n}+b)^{p-1}\,\mathrm{d}x\right]
= \frac{1}{bn(p+1)}\left[-x^{m+1}(ax^{n}+b)^{p+1} + (m+n+np+1)\int x^{m}(ax^{n}+b)^{p+1}\,\mathrm{d}x\right]
= \frac{1}{(m+1)b}\left[x^{m+1}(ax^{n}+b)^{p+1} - a(m+n+np+1)\int x^{m+n}(ax^{n}+b)^{p}\,\mathrm{d}x\right]
= \frac{1}{a(m+np+1)}\left[x^{m-n+1}(ax^{n}+b)^{p+1} - (m-n+1)b\int x^{m-n}(ax^{n}+b)^{p}\,\mathrm{d}x\right].
```
