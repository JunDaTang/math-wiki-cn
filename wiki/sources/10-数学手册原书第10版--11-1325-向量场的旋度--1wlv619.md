# 数学手册(原书第10版) 13.2.5 向量场的旋度

本节是 13.2「空间的微分算子」的第五小节，主题为向量场的旋度（rotation / curl）。手册在此给出旋度的两种定义——体积导数式（式 13.57）与环流面密度最大值式（式 13.58a/b）——以及笛卡儿、柱面、球面、一般直角（实为正交曲线）坐标系下的分量公式（式 13.59–13.62）、运算法则（式 13.63–13.65）与位势场的无旋性（式 13.66）。它与已入库的 [[sources/10-数学手册原书第10版--14-1321-方向导数和空间导数--1eb9exe]]（13.2.1）和 [[sources/10-数学手册原书第10版--13-1322-一个标量场的梯度--1amt5yk]]（13.2.2）构成同一微分算子系列。

## 章节结构

- **13.2.5.1 旋度的定义**：两种定义——(1) 体积导数式，旋度是向量场的“负空间导数”；(2) 环流面密度最大值式，经小曲面片上的环流极限（步骤 a)–e)）构造。随后定义旋度线（rot V⃗ 的向量线）。
- **13.2.5.2 不同坐标系中的旋度**：笛卡儿（13.59）、柱面（13.60）、球面（13.61）、一般直角坐标系（13.62，尺度因子统一公式）。
- **13.2.5.3 旋度的运算法则**：线性与数乘（13.63）、标量乘积法则（13.64）、叉积旋度展开（13.65）。
- **13.2.5.4 位势场的旋度**：rot(grad U) = 0⃗（13.66），并给出 rot r⃗ = 0⃗ 与 rot(φ(r) r⃗) = 0⃗。

## 公式转录（式 13.57–13.66）

以下为经复算校订的转录（OCR 讹误以注释标出，完整清单见 [[queries/13-2-5全节系统性转写讹误清单]]）：

```latex
% 13.2.5.1 定义
(13.57)  rot V⃗ = − lim_{V→0} (1/V) ∯_Σ V⃗ × dS⃗ = lim_{V→0} (1/V) ∯_Σ dS⃗ × V⃗
(13.58a) |rot V⃗| = lim_{S_max→0} (1/S_max) ∮_{C_max} V⃗ · dr⃗
(13.58b) l⃗ · rot V⃗ = rot_l V⃗ = lim_{S→0} (1/S) ∮_C V⃗ · dr⃗

% 13.2.5.2 各坐标系中的旋度
(13.59a) rot V⃗ = î(∂V_z/∂y − ∂V_y/∂z) + ĵ(∂V_x/∂z − ∂V_z/∂x) + k̂(∂V_y/∂x − ∂V_x/∂y)
          = det | î    ĵ    k̂  |
                | ∂/∂x ∂/∂y ∂/∂z |
                | V_x  V_y  V_z  |
(13.59b) rot V⃗ = ∇ × V⃗
(13.60a) rot V⃗ = rot_ρ V⃗ e⃗_ρ + rot_φ V⃗ e⃗_φ + rot_z V⃗ e⃗_z
(13.60b) rot_ρ V⃗ = (1/ρ) ∂V_z/∂φ − ∂V_φ/∂z
          rot_φ V⃗ = ∂V_ρ/∂z − ∂V_z/∂ρ
          rot_z V⃗ = (1/ρ) { ∂(ρV_φ)/∂ρ − ∂V_ρ/∂φ }
(13.61a) rot V⃗ = rot_r V⃗ e⃗_r + rot_ϑ V⃗ e⃗_ϑ + rot_φ V⃗ e⃗_φ
(13.61b) rot_r V⃗ = (1/(r sinϑ)) { ∂(sinϑ V_φ)/∂ϑ − ∂V_ϑ/∂φ }
          rot_ϑ V⃗ = (1/(r sinϑ)) ∂V_r/∂φ − (1/r) ∂(rV_φ)/∂r
          rot_φ V⃗ = (1/r) { ∂(rV_ϑ)/∂r − ∂V_r/∂ϑ }
(13.62a) rot V⃗ = rot_ξ V⃗ e⃗_ξ + rot_η V⃗ e⃗_η + rot_ζ V⃗ e⃗_ζ
(13.62b) rot_ξ V⃗ = (1/D)|∂r⃗/∂ξ| [ ∂/∂η(|∂r⃗/∂ζ| V_ζ) − ∂/∂ζ(|∂r⃗/∂η| V_η) ]
          （η、ζ 分量按 (ξ,η,ζ) 轮换得到）
(13.62c) r⃗(ξ,η,ζ) = x(ξ,η,ζ) î + y(ξ,η,ζ) ĵ + z(ξ,η,ζ) k̂   % 转写中 y(·)、z(·) 函数名脱落
          D = |∂r⃗/∂ξ| · |∂r⃗/∂η| · |∂r⃗/∂ζ|

% 13.2.5.3 旋度的运算法则
(13.63) rot(V⃗₁ + V⃗₂) = rot V⃗₁ + rot V⃗₂ ;  rot(cV⃗) = c rot V⃗
(13.64) rot(U V⃗) = U rot V⃗ + grad U × V⃗
(13.65) rot(V⃗₁ × V⃗₂) = (V⃗₂·grad)V⃗₁ − (V⃗₁·grad)V⃗₂ + V⃗₁ div V⃗₂ − V⃗₂ div V⃗₁

% 13.2.5.4 位势场的旋度
(13.66) rot V⃗ = rot(grad U) = 0⃗
```

## 关键表述

- **“负空间导数”**：式 (13.57) 把旋度定义为向量场的负空间导数；负号对应 ∯ V⃗×dS⃗/V 的书写次序，两个极限式因 dS⃗×V⃗ = −V⃗×dS⃗ 而恒等。符号约定经刚体旋转场显式积分验证，见 [[findings/式13-57至13-58b旋度两种定义转录复算]]。
- **旋度线**：向量场 rot V⃗ 的向量线称为 V⃗ 的旋度线（curl lines of the vector field），见 [[concepts/向量线]]。
- **“一般直角坐标系”**：式 (13.62) 实为正交曲线坐标系的尺度因子公式，D 为三个尺度因子之积；仅当坐标基正交时成立（斜角坐标下有显式反例），见 [[methodology/旋度坐标系分量计算流程]] 与 [[findings/式13-59至13-62c各坐标系旋度公式转录复算]]。
- **位势场无旋**：由斯托克斯定理（回指 13.3.3.2，第 946 页）或施瓦茨互换定理（回指 6.2.2.2，第 602 页）得 (13.66)；并给出 rot r⃗ = 0⃗、rot(φ(r) r⃗) = 0⃗（φ(r) 为可微函数）。

## 复算结论摘要

式 13.57–13.66 全部经独立复算验证，无数学性错误；本节所有问题均为 OCR 转写级。要点：

- (13.57) 符号约定经刚体旋转场 V⃗ = ω⃗×r⃗ 的球面积分显式验证（直接计算）。
- (13.62b) 仅对正交坐标系成立——斜角坐标反例给出 3/√2 ≠ 1（直接计算）。
- 运算法则与位势场无旋性逐项与标准恒等式一致。

详见 [[findings/式13-57至13-58b旋度两种定义转录复算]]、[[findings/式13-59至13-62c各坐标系旋度公式转录复算]]、[[findings/式13-63至13-66旋度运算法则与位势场旋度转录复算]]。
