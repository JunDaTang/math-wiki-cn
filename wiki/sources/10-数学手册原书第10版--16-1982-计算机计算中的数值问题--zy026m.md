# 数学手册(原书第10版) 19.8.2 计算机计算中的数值问题

## 概述

本页对应《数学手册（原书第 10 版）》第 19 章“数值方法”之 19.8.2 节“计算机计算中的数值问题”（媒体目录名 `10-数学手册原书第10版--16-1982-计算机计算中的数值问题--zy026m`，书页约第 1982 页起）。本节是第 19 章数值方法主线的收尾环节，专门讨论计算机浮点运算环境下的数值问题：误差的分类与控制、规范化浮点表示与舍入、减法相消、输入误差传播、方法误差与数值稳定性。

本节的核心立场是：计算机计算的一般性质与手工计算基本相同，但数的有限位浮点表示引入舍入，且计算机能执行远多于人工的计算步骤，因此存在如何影响和控制误差的问题——**在数学上等价的方法中选用最适当的数值方法**。这一原则与 [[synthesis/差分法与有限元殊途同归于五点格式]] 提炼的“数学等价、数值性态可不等价”主题一脉相承。

## 误差三分类

数值方法的最终总误差由三类误差累积而成（原文图 19.18）：

1. **输入误差**——由不准确的输入数据产生；输入数据的轻微不准确称为“扰动”；确定输入数据误差为误差计算的直接问题，其反问题为“输入数据可有多大的误差仍保证最终误差不超过允许值”。见 [[concepts/输入误差与误差传播]]。
2. **方法误差**——源于理论上的连续现象作为极限被数值逼近：极限过程中的**截断误差**（如迭代法）与连续现象离散化的**离散误差**（如数值积分）。见 [[concepts/方法误差（截断与离散误差）]]。
3. **舍入误差**——中间结果被舍入而产生。见 [[concepts/舍入与舍入误差]]。

三者的对照见 [[comparisons/三类误差来源比较]]；总误差随步数的性态给出强稳定/弱稳定/不稳定分类，见 [[concepts/数值稳定性三分类]]。

## 关键公式逐字转录

### 误差定义、规范化十进制数与舍入（式 19.268–19.273）

```latex
% 误差定义与记号 (19.268–19.270)
绝对误差  |\Delta x| = |x - \tilde{x}|
相对误差  |\Delta x / x| = |(x - \tilde{x})/x|
\varepsilon(x) = x - \tilde{x},  \varepsilon_{\mathrm{rel}}(x) = (x - \tilde{x})/x

% 规范化十进制数与舍入 (19.271–19.273)
x = \pm 0.b_1 b_2 \cdots 10^{E}  (b_1 \neq 0)
\tilde{x} = \begin{cases} \pm 0.b_1\cdots b_t\cdot 10^{E}, & b_{t+1} < 5\ (\text{舍}) \\ \pm(0.b_1\cdots b_t + 10^{-t})10^{E}, & b_{t+1} \geqslant 5\ (\text{入}) \end{cases}
|\Delta x| \leqslant 0.5\cdot 10^{-t}\,10^{E}
```

### 浮点表示、四则运算对阶与误差限（式 19.274–19.279）

```latex
% 浮点表示 (19.274a–c)
x = m_1 B^{E_1},\quad y = m_2 B^{E_2}
m_i = \sum_{k=1}^{t} a_{-k}^{(i)} B^{-k},\quad a_{-1}^{(i)} \neq 0,\quad a_{-k}^{(i)} \in \{0,\dots,B-1\}

% 加法：B^{-1} \leqslant |m_1 + m_2 B^{-(E_1-E_2)}| < 2；若 \geqslant 1 则小数点左移一位、指数增 1 (19.275a,b)
% 减法：|m_1 - m_2 B^{-(E_1-E_2)}| < 1 - B^{-t}；若 < B^{-t} 则小数点右移、指数相应减少 (19.276a,b)
% 乘法：指数相加、尾数相乘；若 m_1 m_2 < B^{-1} 则小数点右移一位、指数减 1 (19.277)
% 除法：指数相减、尾数相除；若 m_1/m_2 \geqslant 1 则小数点左移一位、指数增 1 (19.278)
% 无误差操作数下四种基本运算相对误差上限 (19.279)：
\frac{B}{2} B^{-t}
```

### 输入误差界与四则运算误差传播（式 19.280–19.286）

```latex
% 输入误差界（泰勒线性余项）(19.280)
|\Delta y| \leqslant \sum_{i=1}^{n} \Big(\max_{x}\Big|\frac{\partial f}{\partial x_i}(\underline{x})\Big|\Big)|\Delta x_i|

% 四则运算误差传播 (19.281–19.286)
\varepsilon(x \pm y) = \varepsilon(x) \pm \varepsilon(y)
\varepsilon(xy) = y\,\varepsilon(x) + x\,\varepsilon(y) + \varepsilon(x)\varepsilon(y)
\varepsilon(x/y) = \tfrac{1}{y}\varepsilon(x) - \tfrac{x}{y^2}\varepsilon(y) + \varepsilon\ \text{的高阶项}
\varepsilon_{\mathrm{rel}}(x \pm y) = \frac{\varepsilon_{\mathrm{rel}}(x) \pm \varepsilon_{\mathrm{rel}}(y)}{x \pm y}
\varepsilon_{\mathrm{rel}}(xy) = \varepsilon_{\mathrm{rel}}(x) + \varepsilon_{\mathrm{rel}}(y) + \varepsilon_{\mathrm{rel}}(x)\varepsilon_{\mathrm{rel}}(y)
\varepsilon_{\mathrm{rel}}(x/y) = \varepsilon_{\mathrm{rel}}(x) + \varepsilon_{\mathrm{rel}}(y) + \varepsilon\ \text{的高阶项}
```

### 扰动分析、梯形公式与辛普森寄生解（式 19.287–19.290b）

```latex
% 扰动分析 (19.287–19.288d)
y' = f(x,y),\quad f(x,y) = ay
u(x) = y(x) + \varepsilon\,\eta(x)
u'(x) = f(x,y) + \varepsilon\,\eta(x) f_y(x,y) + \text{高阶项}
\eta'(x) = f_y(x,y)\,\eta(x)
\eta(x) = \eta_0 e^{a(x-x_0)}

% 梯形公式 (19.289b–d)
\int_{x_i}^{x_{i+1}} y\,dx \approx \frac{y_i + y_{i+1}}{2}h
\tilde{y}_{i+1} = \frac{2-h}{2+h}\tilde{y}_i
\tilde{y}_i = \Big(\frac{2-h}{2+h}\Big)^{(x_i-x_0)/h}\tilde{y}_0 = \tilde{y}_0 e^{c(h)(x_i-x_0)}
c(h) = \frac{\ln\big(\frac{2-h}{2+h}\big)}{h} = -1 - \frac{h^2}{12} - \frac{h^4}{80} - \dots

% 初值稳定性与辛普森寄生解 (19.290a,b)
(\tilde{y}_{i+1} - y_{i+1}) \leqslant \Big(\frac{2-h}{2+h}\Big)^{i+1}(\tilde{y}_0 - y_0)
\tilde{y}_i = C_1 e^{-x_i} + C_2 (-1)^i e^{x_i/3}
```

## 数值算例（A–F）

- **例 A 二次方程的根**：$ax^2+bx+c=0$，$D=b^2-4ac\geqslant 0$；临界状态为 $|4ac|\ll b^2$ 与 $4ac\approx b^2$。推荐程序：$x_1=-\dfrac{b+\mathrm{sign}(b)\sqrt{D}}{2a}$，$x_2=\dfrac{c}{a x_1}$（韦达根定理，回指 1.6.3.1），避免直接法中的减法相消。见 [[methodology/二次方程稳定求根流程]]。
- **例 B 薄壳体积**：$h\leqslant r$ 时 $(r+h)\approx r$，$V=\dfrac{4\pi}{3}\big[(r+h)^3-r^3\big]$ 发生减法消去；改用展开式 $V=\dfrac{4\pi}{3}\big(3r^2h+3rh^2+h^3\big)$ 则无此问题。原文称“薄锥壳”而公式为球壳体积，疑为“薄球壳”，见 [[queries/例B薄锥壳疑为薄球壳之辨]]。
- **例 C 级数求和**：$S=\sum_{k=1}^{\infty}\frac{1}{k^2+1}=1.07667\cdots$，要求三位有效数字；原文称用 $t$ 位数字直接求和约需加 6000 项。经恒等变换 $\frac{1}{k^2+1}=\frac{1}{k^2}-\frac{1}{k^2(k^2+1)}$ 得 $S=\frac{\pi^2}{6}-\sum_{k=1}^{\infty}\frac{1}{k^2(k^2+1)}$，尾项按 $1/k^4$ 衰减，少量项即达精度。
- **例 D 避免 0/0**：$x=y=0$ 处 $z=\big(1-\sqrt{1+x^2+y^2}\big)\frac{x^2-y^2}{x^2+y^2}$，分子分母同乘 $\big(1+\sqrt{1+x^2+y^2}\big)$ 即可避免。
- **例 E 不稳定递推**：$y_{n+1}=a y_n+b y_{n-1}$ 稳定当且仅当 $\big|\tfrac{a}{2}\pm\sqrt{\tfrac{a^2}{4}+b}\big|<1$；特例 $y_{n+1}=-3y_n+4y_{n-1}$（特征根 $1$ 与 $-4$）不稳定，初值误差 $\varepsilon,-\varepsilon$ 传播为 $7\varepsilon,-25\varepsilon,103\varepsilon,-409\varepsilon,1639\varepsilon,\dots$
- **例 F 微分方程数值求积**：$y'=f(x,y)$，$f(x,y)=ay$。a) $a>0$ 时天然不稳定（扰动方程 $\eta'=f_y\eta$ 给 $\eta=\eta_0 e^{a(x-x_0)}$）；b) $a=-1$ 时梯形公式稳定（放大因子 $\frac{2-h}{2+h}$，$0\leqslant h<2$），且关于初值稳定；c) 而用辛普森方法求解同一方程会引入人为不稳定，$h\to 0$ 时数值解通解含寄生项 $C_2(-1)^i e^{x_i/3}$——问题是该格式使用了比相应微分方程更高阶的差分。对照见 [[comparisons/梯形公式与辛普森法则稳定性比较]]。

## 复算验证与转写疑点

Stage-1 复算（证据强度：高）确认：加法算例 $0.9604\cdot 10^3+0.5873\cdot 10^2=0.1019\cdot 10^4$、减法算例（尾数补零的临界情形）、除法算例 $0.3176\cdot 10^3/0.2504\cdot 10^5=0.1268\cdot 10^{-1}$ 均通过；$\sqrt{1985}-\sqrt{1984}$ 有理化 $=\frac{1}{\sqrt{1985}+\sqrt{1984}}=0.1122\cdot 10^{-1}$（真值 $\approx 0.011225$）通过；例 E 误差序列逐项复算全部通过；例 C 恒等变换复算 $1.644934-0.568263=1.076671$ 通过；例 F 的 $c(h)$ 展开系数与辛普森寄生特征根 $\lambda_2\approx-(1+h/3)$ 复算通过。

同时发现多处转写疑点（总目见 [[queries/19-8-2全节系统性转写讹误清单]]），其中复算证据最强者为乘法算例首因子疑为 $0.3176\cdot 10^3$（见 [[queries/乘法算例首因子0-1004疑为0-3176之辨]]）；式 (19.282)/(19.285)/(19.286) 的符号与式 (19.284) 的脱因子问题与 (19.270) 记号约定构成内部矛盾，待对照原书裁定。
