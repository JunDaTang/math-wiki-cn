# 数学手册(原书第10版) 17.2.7 由时间序列重新构造的动力系统

## 内容概要

本节是 17.2「吸引子的量化描述」的应用收官，论证**单一标量时间序列在理论上足以重构原动力系统的几何与动力学**。系统设定为由微分同胚 $\varphi \in \mathrm{Diff}_+^1(U)$（参见第 1138 页 17.1.4.2）或向量场 $f \in X_+^1(U)$（参见第 1137 页 17.1.4.1）生成的 $\{\varphi^t\}_{t \in T}$，$T \in \{\mathbb{Z}_+, \mathbb{R}_+\}$；以一个 $C^1$ 测量函数 $h: U \to \mathbb{R}$ 观测轨道，按固定时间间隔 $\{k\tau\} \subset T$（$\tau > 0$）采样，组成 $m$ 维时滞向量。

全节分两小节：17.2.7.1「基础，重构的基本性质」（测量函数与时间序列、浸入与嵌入、惠特尼定理、塔肯定理、重构空间上的动力系统）；17.2.7.2「具有普遍性质的重构」（普遍性、绍尔—约克—卡斯达格利定理、相关维数的估计）。

## 核心论证链

1. **几何基准（[[concepts/惠特尼嵌入定理]]）**：对有界开集 $U \subset \mathbb{R}^n$ 与 $m \ge 2n+1$，全体嵌入 $\Phi: U \to \mathbb{R}^m$ 构成 $C^1(U, \mathbb{R}^m)$ 的开稠子集。
2. **动力学基础（[[concepts/库普卡—斯梅尔定理]]；本源讹作「库普卡—阿迈勒」）**：周期点双曲且稳定/不稳定流形横截相交的微分同胚构成 $\mathrm{Diff}_+^1(U)$ 的贝尔第二纲集。
3. **重构定理（[[concepts/塔肯定理]]）**：对通有的配对，时滞坐标映射 (17.62)/(17.63) 为嵌入；$m \ge 2n+1$ 称嵌入维数。机制：典型的 $(\varphi, h)$ 使 $\Phi_{\varphi,h}$ 在周期点邻域为浸入，可延拓为整个 $U$ 上的嵌入。
4. **重构空间的共轭动力学**：$\psi = \Phi \circ \varphi \circ \Phi^{-1}$ 且 $\psi(x_k) = x_{k+1}$——时间序列本身完全决定重构映射；$\varphi$ 与 $\psi$ 的平衡点、周期轨道的拓扑性质及雅可比特征值相同，维数（如相关维数）可由相应不变测度的李雅普诺夫指数决定（参见第 1158 页 17.2.7.2）。
5. **普遍性改进（绍尔—约克—卡斯达格利）**：以吸引子容量维数 $\bar d_C(A) = d$ 取代 $n$，要求 $m > 2d$ 与周期轨有限性条件，则「好」测量函数 $h$ 在 $C^1(\bar U, \mathbb{R})$ 中不仅通有，而且**普遍**（[[concepts/普遍性]]）。
6. **相关维数可从时间序列估计**：重构向量 (17.65) 的 max 范数相关积分 (17.66) 给出 $d_K$ 的估计。

```latex
% (17.61) 阶为 m、方向 κ ∈ {−1,1}、步长 τ > 0 的时间序列
{ h(φ^{kτ}(p)), h(φ^{(k+κ)τ}(p)), …, h(φ^{(k+(m−1)κ)τ}(p)) }_{k=m−1}^{∞}

% (17.62) 微分同胚版重构映射（前向坐标）
p ∈ U ↦ Φ_{φ,h}(p) = ( h(p), h(φ¹(p)), …, h(φ^{m−1}(p)) )

% (17.63) 向量场版重构映射（前向坐标）
p ∈ U ↦ Φ_{f,h}(p) = ( h(p), h(φ¹(p)), …, h(φ^{m−1}(p)) )

% (17.64) SYC 重构函数（逆时序书写）
p ∈ U ↦ Φ_{f,h,τ}(p) = ( h(φ^{(m−1)τ}(p)), h(φ^{(m−2)τ}(p)), …, h(p) )

% (17.65) 重构向量（嵌入维数为 m+1），y_i = h(φ^i(p))
x_i = ( y_i, y_{i+1}, …, y_{i+m} ) ∈ ℝ^{m+1}

% (17.66) 相关积分与相关维数估计（源文左端记号 C^m(φ) 疑为 C^m(ε)）
dist(x_i, x_j) = max_{0 ≤ s ≤ m} | y_{i+s} − y_{j+s} |
C^m(ε) = limsup_{N→∞} (1/N²) · #{ (x_i, x_j) : i, j ∈ {1,…,N}, dist(x_i, x_j) < ε }
d_K(m) = lim_{ε→0} ln C^m(ε) / ln ε
```

## 一维算例（17.2.7.1.3）

区间 $(-1-\varepsilon, 1+\varepsilon)$（$\varepsilon > 0$ 充分小）上 $\dot x = -x \equiv f(x)$：由 $f$ 连续可微且 $f(-1) = 1 > 0$、$f(1) = -1$，有 $f \in X_+^1(U)$，$U = (-1,1)$；显示解 $\varphi^t(x) = x\mathrm{e}^{-t}$。

- $h_1(x) = x$：$\Phi_{f,h_1}(x) = (x, x\mathrm{e}^{-1}, x\mathrm{e}^{-1})$（源文如此；第三分量疑为 $x\mathrm{e}^{-2}$，见 [[queries/一维算例第三分量xe⁻¹疑为xe⁻²之辨]]）是 $\mathbb{R}^3$ 上的嵌入。
- $h_2$（源文定义脱文，由像反推 $h_2(x) = x^2$，见 [[queries/h₂定义脱文之辨]]）：$\Phi_{f,h_2}(x) = (x^2, x^2\mathrm{e}^{-2}, x^2\mathrm{e}^{-4})$ 不是单射，因而不是嵌入。

## 洛伦茨数值链（17.2.7.2.3）

洛伦茨系统 (17.2)（参见第 1118 页 17.1.1.1,2.）属于 $X_+^1(U)$，其中 $U = \{(x,y,z) \in \mathbb{R}^3 : \tfrac{1}{2}[x^2+y^2+(z-\sigma-r)^2] < c\}$（$c > 0$ 充分大）；吸引子 $\Lambda(\sigma=10, b=8/3, r=28)$ 落于 $U$ 中：

| 量 | 值 | 方法/出处 |
|---|---|---|
| $d_H(\Lambda)$ | $\le 2.421$ | 杜阿迪—厄斯特勒定理（第 1152 页 17.2.4.3） |
| $d_H(A)$ | $\approx 2.06$ | 数值积分的盒计算方法（标号存疑） |
| $d_K$ | $\approx 2.03$ | 逆向迭代时滞嵌入（$\tau \approx 0.12$），格拉斯贝格 [17.12] |

数值链内部自洽：$d_K \approx 2.03 \le d_H(A) \approx 2.06 \le 2.421$（测度维数 ≤ 集合维数 ≤ 解析上界）。复算见 [[findings/洛伦茨吸引子维数链复算]]。

## 主张归属与证据强度

- 塔肯定理的主张仅关于 $\mathrm{Diff}_+^1(U) \times C^1(U,\mathbb{R})$ 与 $X_+^1(U) \times C^1(U,\mathbb{R})$；库普卡—斯梅尔主张仅关于 $\mathrm{Diff}_+^1(U)$；SYC 主张仅关于容量维数为 $d$ 的紧集 $A$ 上的流及 $C^1(\bar U, \mathbb{R})$ 中的 $h$；$d_K \approx 2.03$ 仅关于洛伦茨自然测度，不可移植为吸引子的豪斯多夫维数，更不可推广至其他系统。
- 定理类主张（惠特尼、塔肯、库普卡—斯梅尔、SYC）为数学定理，强度高；但本节转写讹误密集，精确表述（尤其 SYC 的条件结构与普遍性定义）须对照 [17.13]、[17.23] 核验。数值主张（2.421、2.06、2.03）为数值实验结果，中等强度，未给复现细节。
