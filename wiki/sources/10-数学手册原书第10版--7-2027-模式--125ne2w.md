# 数学手册(原书第10版) 20.2.7 模式

## 概述

本节出自《数学手册（原书第10版）》第 20 章计算机代数部分的 20.2.7 小节，讲授 [[entities/mathematica]] 的模式（Pattern）机制：用户如何以空白符号 `_` 为基本元素定义代表整类表达式的模板，Mathematica 如何按结构（而非数学相等）进行匹配与替换，以及模式定义与字面定义在函数指派上的差异。核心概念整理于 [[concepts/模式（Mathematica）]]。

## 要点

1. **模式定义**（式 20.16）：`f[x_] := Polynomial[x]` 中，`x_`（读作“x 空白”）表示“具有名称 x 的某个东西”；由此定义之后，每当 `f[something]` 出现，Mathematica 即以该定义替换它。注意 `Polynomial` 并非 Mathematica 内置符号，此处系书中元记号（泛指变元的任意多项式），实际求值将得到字面的 `Polynomial[...]`。
2. **匿名空白幂模式**：`y^_`（即 `Power[y, _]`）代表 y 的具有任何指数的任意次幂，因而代表具有相同结构的表达式的整个类。
3. **结构匹配而非数学相等**（本节教学核心）：Mathematica 就模式检查表达式时，只将表达式元素的结构比作模式的元素，“不检查数学相等性”。式 20.17–20.19 中，`1` 与 `y` 虽满足 y^0=1、y^1=y，仍不被 `y^_` 替换；底数不同的 `2^y` 亦不替换。
4. **模式比较总在 FullForm 中进行**（式 20.20）：`b/y` 的 FullForm 为 `Times[b, Power[y, -1]]`，其第二个自变量与 `y^_` 结构等同，故 `b/y /. y^_ -> yes` 得 `b yes`。原文将 FullForm 讹作 `Times[b, Power[y, 1]]`，见 [[queries/Power-y-1疑为Power-y-负1之辨]]。
5. **模式定义与字面定义对照**（式 20.21a–e）：`f[x_] := x^3` 对任意变元生效，`f[x] := x^3` 仅对符号 x 本身生效，详见 [[comparisons/模式定义与字面定义比较]]。

## 原文 IO 记录（逐字转录）

按 20.2.x 各节惯例校录；原文空白记号等的 OCR 错乱形式汇总于 [[queries/20-2-7全节系统性转写讹误清单]]：

```mathematica
(* 20.16 *) In[1] := f[x_] := Polynomial[x]

(* 20.17 *) In[2] := l = {1, y, y^a, y^Sqrt[x], {f[y^(r/q)], 2^y}}

(* 20.18 *) In[3] := l /. y^_ -> yes
(* 20.19 *) Out[3] = {1, y, yes, yes, {f[yes], 2^y}}

(* 20.20 *) In[4] := b/y /. y^_ -> yes    →    Out[4] = b yes
(*          原文注：b/y 之 FullForm 为 Times[b, Power[y, 1]]
            （疑脱负号，应为 Times[b, Power[y, -1]]）*)

(* 20.21a *) In[5] := f[x_] := x^3
(* 20.21b *) In[6] = f[r]                 →    Out[6] = r^3, 等等
(* 20.21c *) In[7] := f[a] + f[x]         →    Out[7] = a^3 + x^3
(* 20.21d *) In[8] := f[x] := x^3；对于相同的输入 In[9] := f[a] + f[x]
(* 20.21e *) Out[9] = f[a] + x^3
```
