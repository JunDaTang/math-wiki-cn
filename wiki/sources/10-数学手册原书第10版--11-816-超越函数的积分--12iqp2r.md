# 数学手册(原书第10版) 8.1.6 超越函数的积分

## 来源概况

本页是 [[entities/数学手册原书第10版]] 第 8 章 8.1.6 节「超越函数的积分」的入库摘要。该节把 8.1.1–8.1.3 建立的积分体系（基本积分表、积分法则、[[concepts/有理函数的积分]]）延伸到指数函数、双曲函数等超越被积函数，是 8.1 不定积分体系的收官小节，末尾以对第 1382 页表 21.7 的回指收束（见 [[entities/表21-7超越函数积分表]]）。

## 小节结构与核心内容

### 8.1.6.1 指数函数的积分

本节唯一带编号公式的构造性结果：形如式 8.36a 的积分（$R$ 为其变元的有理函数，$m, n, \dots, p$ 为有理数）可经**两次连环代换**化为有理函数的积分——先 $t = \mathrm{e}^{x}$ 得式 8.36b，再作根式代换消去分数幂。方法页见 [[concepts/指数函数的有理化双代换]]，逐字转录与复算见 [[findings/式8-36指数函数积分双代换复算]]。

### 8.1.6.2 双曲函数的积分

纯文字陈述，无编号公式：被积函数含 $\sinh x, \cosh x, \tanh x, \coth x$ 时，若双曲函数能用相应的指数函数来代替，则可利用指数函数的积分来计算；对最常见的 $\int\sinh^{n}x\,\mathrm{d}x$、$\int\cosh^{n}x\,\mathrm{d}x$、$\int\sinh^{n}x\cosh^{m}x\,\mathrm{d}x$ 可用与三角函数积分类似的方法（回指第 654 页 8.1.5，该节尚未入库）。见 [[concepts/双曲函数的积分]] 与 [[comparisons/三角函数积分与双曲函数积分方法平行比较]]。

### 8.1.6.3 分部积分的应用

三类对象（均无编号公式）：

- **一次或多次分部**：被积函数为对数函数、反三角函数、反双曲函数，或 $x^{m}$ 与 $\ln x$、$\mathrm{e}^{\alpha x}$、$\sin ax$、$\cos ax$ 及其反函数的乘积。
- **循环情形**：$\int\mathrm{e}^{ax}\cos bx\,\mathrm{d}x$、$\int\mathrm{e}^{ax}\sin bx\,\mathrm{d}x$——两次分部积分重现同型积分，移项解关于该积分的代数方程；两步中须对同类因子作一致选择。
- **多项式情形**：$\int P(x)\mathrm{e}^{ax}\mathrm{d}x$、$\int P(x)\sin bx\,\mathrm{d}x$、$\int P(x)\cos bx\,\mathrm{d}x$（$P(x)$ 为多项式）——令 $u = P(x)$，每步多项式降次，有限步终止。

见 [[concepts/分部积分的循环法]] 与 [[findings/循环分部积分与多项式降次两情形]]。

### 8.1.6.4 超越函数的积分

仅一句回指：「1382 页的表 21.7 中有很多超越函数的积分。」小节标题与节标题完全同名、正文仅此一句——疑为原书体例，结构异常已记入 [[queries/8-1-6全节系统性转写讹误清单]]；表 21.7 已建占位页 [[entities/表21-7超越函数积分表]]。

## 结构化内容逐字转录

全节原文（转写文本原样，含全部讹误）：

```text
8.1.6.1 指数函数的积分

形如

$$
\int R (\mathrm{e} ^ {m x}, \mathrm{e} ^ {n x}, \dots , \mathrm{e} ^ {p x}) \mathrm{d} x\tag{8.36a}
$$

的指数函数的积分可以化简成有理函数的积分，其中 $m , n , \cdots , p$ 为有理数．计算该积分需要作两个代换：

(1) $t = \mathrm { e } ^ { x }$ ，有积分

$$
\int \frac {1}{t} R (t ^ {m}, t ^ {n}, \dots , t ^ {p}) \mathrm{d} t.\tag{8.36b}
$$

(2) $z = { \sqrt [ { e } ] { t } } ,$ 其中 是分数 $m , n , \cdots , p$ 的分母的最小公倍数，可以将其化为有理函数积分

8.1.6.2 双曲函数的积分

双曲函数的积分，即被积函数含有 sinh x, cosh x, tanh x, coth 的积分，若双曲函数能用相应的指数函数来代替，则可利用指数函数的积分来计算．对千最常见的积分 $\int \sinh ^ { n } x \mathrm { d } x , \int \cosh ^ { n } x \mathrm { d } x , \int \sinh ^ { n } x \cosh ^ { m } x \mathrm { d } x$ 可用与三角函数积分类似的方法进行计算（参见第 654 8.1.5).

8.1.6.3 分部积分的应用

若被积函数为对数函数、反三角函数、反双曲函数、 $x ^ { m }$ 与 $\ln x \mathrm { , ~ e ^ { \alpha x } \mathrm { , ~ } s i n \ : a x }$ cos ax 及其反函数的乘积，则可利用一次或多次分部积分进行计算．

有些情况下反复分部积分会得到与原积分相同类型的积分，此时必须解关千该表达式的代数方程例如对千积分 $\int \mathrm { e } ^ { a x } \cos b x \mathrm { d } x , \int \mathrm { e } ^ { a x } \sin b x \mathrm { d } x$ 可利用这种方法计算，要用两次分部积分不论指数函数还是三角函数，在上述两步中都要根据因子选择相同类型的函数

对千形如 $\int P \left( x \right) \mathrm { e } ^ { a x } \mathrm { d } x , \int P \left( x \right) \sin b x \mathrm { d } x$ 和 $\int P \left( x \right) \cos { b x } \mathrm { d } x$ 的积分，其中 $P \left( x \right)$ 为多项式也可用分部积分来计算（令 $u = P \left( x \right)$ ，在每一步多项式都会降次）

8.1.6.4 超越函数的积分

1382 页的表 21.7 中有很多超越函数的积分．
```

式 8.36a–b 与根式代换的整理形式（注意：「其中」后根指数字母在转写中脱字，原文记作 $e$，与欧拉常数 $\mathrm{e}$ 撞名，见 [[queries/根指数字母e是否原书记号]]）：

\int R (\mathrm{e}^{mx}, \mathrm{e}^{nx}, \dots, \mathrm{e}^{px}) \mathrm{d}x \tag{8.36a}
