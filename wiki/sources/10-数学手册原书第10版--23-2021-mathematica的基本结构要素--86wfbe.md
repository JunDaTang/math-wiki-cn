# 数学手册(原书第10版) 20.2.1 Mathematica的基本结构要素

本节出自《数学手册（原书第10版）》第 20 章 20.2.1 节，是 wiki 收录的首个第 20 章页面，给出 [[entities/mathematica]] 的语法地基：**表达式（expression）是 Mathematica 的基本结构要素**，全节围绕式 (20.4) 的统一句法展开。与 19.8.4（[[sources/10-数学手册原书第10版--22-1984-交互程序系统和计算机代数系统的应用--k25qkm]]）只做应用层算例不同，本节补上「语法/语义」一层，使 wiki 中 Mathematica 相关内容形成「应用 + 语法」两层结构；它也是 [[concepts/交互程序系统与计算机代数系统]] 自 19 章转入 20 章后的深入展开。

## 核心论断（全部归属 Mathematica，不外推至 Maple / Matlab）

1. **表达式是基本结构要素**（式 20.4）：对象由 `obj_0[obj_1, ..., obj_n]` 表示；obj₀ 为头（指派数 0），objᵢ（i = 1, …, n）为元素或自变量（以数 1, …, n 指称）。在许多情形中头是算子或函数，元素是头所作用的运算对象或变元；头本身也可以是表达式。方括号专门用来表示一个表达式，只能用于这种关系。
2. **一切数学算子均有内部前缀形式**：项 `x^2 + 2*x + 1`（或更漂亮也更可取的形式 x² + 2x + 1）的完整形式（FullForm）为 `Plus[1, Times[2, x], Power[x, 2]]`，其本身也是表达式；项（中缀）表示法只是 Mathematica 的一个方便功能。
3. **Part 部件提取**：`Part[expr, i]` 分离表达式的部分，i 为对应元的数；i = 0 时得到该表达式的头（源文此处脱「i = 0」，见 [[queries/Part之i等于0脱文之辨]]）。
4. **会话机制**：SHIFT 与 ENTER 键一起按下时触发求值；Mathematica 分析输入后将其复原为数学标准形式；如果输入以分号结束，则输出将被禁止；方括号中的符号 % 告诉 Mathematica 这次输入的自变量是上一次的输出。
5. **符号命名规则**：字母数字序列、不得以数字开始、允许专门记号 $、区分大小写；留作专用的符号以大写字母或 $ 开始；建议用户自建符号以小写字母开始。

## 逐字转录的结构化数据

式 (20.4)——表达式的句法（源文括注：再强调一下，目前的对象是由它们相应的符号和名称给定的）：

```
obj_0[obj_1, obj_2, ..., obj_n]
```

项 `x^2 + 2*x + 1` 的完整形式（FullForm）：

```
Plus[1, Times[2, x], Power[x, 2]]
```

会话转录（In[1]–In[3] / Out[1]–Out[3]；In[3] 行之「为」疑为「则」，见讹误清单）：

```
In[1] := x^2 + 2x + 1
Out[1] = 1 + 2x + x^2

In[2] := FullForm[%]
Out[2] = Plus[1, Times[2, x], Power[x, 2]]

In[3] := Part[%, 3] 为 Out[3] = x^2
```

符号命名规则（依源文表述整理）：

| 规则 | 内容 |
|------|------|
| 构成 | 可以是任何一列字母和数字，但一定不能以数字开始；也允许使用专门记号 $ |
| 大小写 | 字母区分大写和小写 |
| 保留符号 | 留作专用的符号要么以大写字母开始，要么以记号 $ 开始；在复合词中，如果第二个词具有单独意义，那么它也以大写字母开始 |
| 用户约定 | 建议用户创建他们自己的符号时以小写字母开始 |
