# 数学手册(原书第10版) 15.1 积分变换的概念

本 source 为《数学手册(原书第10版)》第 15 章“积分变换”的首节，给出积分变换的一般定义、逆变换、线性性质、多变量推广以及算子方法的应用框架，并以表 15.1 综述十二种单变量函数的积分变换。它是本 wiki 已入库的第 13、14 章 source 系列向第 15 章的延续（前一节见 [[sources/10-数学手册原书第10版--15-145-代数函数和初等超越函数--1sg4gs3]]）。

注：frontmatter 中的作者与出版信息按公开书目补记（源文件未载），待与系列既有 source 页核对统一。

## 小节结构

- **15.1.1 积分变换的一般定义**：见 [[concepts/积分变换]]。
- **15.1.2 特殊的积分变换**：不同的核 $K(p,t)$ 和不同的原始空间生成不同的积分变换；最广为人知的是拉普拉斯变换、拉普拉斯-卡森变换和傅里叶变换；顺带提及小波变换、加博变换、沃尔什变换（前向引用 15.6）。
- **15.1.3 逆变换**：见 [[concepts/逆变换]]。
- **15.1.4 积分变换的线性性质**：(15.3)，在可变换函数定义的集合 $T$ 上成立。
- **15.1.5 多变量函数的积分变换**：多重积分变换；二重拉普拉斯变换 (15.4)，见 [[concepts/二重拉普拉斯变换]]。
- **15.1.6 积分变换的应用**：算子方法三步框架，见 [[concepts/算子方法]] 与 [[methodology/算子方法三步求解流程]]。

## 关键公式（逐字转录）

$$F(p)=\int_{-\infty}^{+\infty}K(p,t)f(t)\,\mathrm{d}t \tag{15.1a}$$

$$F(p)=\mathcal{T}\{f(t)\} \tag{15.1b}$$

$$f(t)=\mathcal{T}^{-1}\{F(p)\} \tag{15.2a}$$

$$\mathcal{T}^{-1}\{\mathcal{T}\{f(t)\}\}=f(t) \tag{15.2b}$$

$$f(t)=\mathcal{T}^{-1}\{F(p)\} \tag{15.2c}$$

$$\mathcal{T}\{k_1 f_1(t)+k_2 f_2(t)\}=k_1\mathcal{T}\{f_1(t)\}+k_2\mathcal{T}\{f_2(t)\} \tag{15.3}$$

$$F(p,q)=\mathcal{L}^{2}\{f(x,y)\}\equiv\int_{x=0}^{\infty}\int_{y=0}^{\infty}\mathrm{e}^{-px-qy}f(x,y)\,\mathrm{d}x\,\mathrm{d}y \tag{15.4}$$

## 表 15.1 对单变量函数的积分变换综述（逐字转录）

| 变换 | 核 $K(p,t)$ | 符号 | 注 |
|---|---|---|---|
| 拉普拉斯变换 | $\left\{\begin{array}{ll}0,&t<0\\ \mathrm{e}^{-pt},&t>0\end{array}\right.$ | $\mathcal{L}\{f(t)\}=\int_0^{\infty}\mathrm{e}^{-pt}f(t)\,\mathrm{d}t$ | $p=\sigma+\mathrm{i}\omega$ |
| 双侧拉普拉斯变换 | $\mathrm{e}^{-pt}$ | $\mathcal{L}_{\mathrm{II}}\{f(t)\}=\int_{-\infty}^{+\infty}\mathrm{e}^{-pt}f(t)\,\mathrm{d}t$ | $\mathcal{L}_{\mathrm{II}}\{f(t)1(t)\}=\mathcal{L}\{f(t)\}$，其中 $1(t)=\left\{\begin{array}{ll}0,&t<0\\ 1,&t>0\end{array}\right.$ |
| 有限拉普拉斯变换 | 〔核行转写讹误，复原为 $\left\{\begin{array}{ll}0,&t<0\\ \mathrm{e}^{-pt},&0<t<a\\ 0,&t>a\end{array}\right.$〕 | $\mathcal{L}_{a}\{f(t)\}=\int_0^a\mathrm{e}^{-pt}f(t)\,\mathrm{d}t$ | |
| 拉普拉斯-卡森变换 | $\left\{\begin{array}{ll}0,&t<0\\ pe^{-pt},&t>0\end{array}\right.$ | $\mathcal{C}\{f(t)\}=\int_0^{\infty}pe^{-pt}f(t)\,\mathrm{d}t$ | 卡森变换也可以是双侧变换和有限变换 |
| 傅里叶变换 | $\mathrm{e}^{-\mathrm{i}\omega t}$ | $\mathcal{F}\{f(t)\}=\int_{-\infty}^{+\infty}\mathrm{e}^{-\mathrm{i}\omega t}f(t)\,\mathrm{d}t$ | $p=\sigma+\mathrm{i}\omega,\ \sigma=0$ |
| 单侧傅里叶变换 | $\left\{\begin{array}{ll}0,&t<0\\ \mathrm{e}^{-\mathrm{i}\omega t},&t>0\end{array}\right.$ | $\mathcal{F}_{\mathrm{I}}\{f(t)\}=\int_0^{\infty}\mathrm{e}^{-\mathrm{i}\omega t}f(t)\,\mathrm{d}t$ | $p=\sigma+\mathrm{i}\omega,\ \sigma=0$ |
| 有限傅里叶变换 | 〔核行与积分式混排、严重讹误，复原为 $\left\{\begin{array}{ll}0,&t<0\\ e^{-\mathrm{i}\omega t},&0<t<a\\ 0,&t>a\end{array}\right.$〕 | $\mathcal{F}_{a}\{f(t)\}=\int_0^a e^{-\mathrm{i}\omega t}f(t)\,\mathrm{d}t$ | $p=\sigma+\mathrm{i}\omega,\ \sigma=0$ |
| 傅里叶余弦变换 | $\left\{\begin{array}{ll}0,&t<0\\ \mathrm{Re}[e^{\mathrm{i}\omega t}],&t>0\end{array}\right.$ | $\mathcal{F}_{c}\{f(t)\}=\int_0^{\infty}f(t)\cos\omega t\,\mathrm{d}t$ | $p=\sigma+\mathrm{i}\omega,\ \sigma=0$ |
| 傅里叶正弦变换 | $\left\{\begin{array}{ll}0,&t<0\\ \mathrm{Im}[e^{\mathrm{i}\omega t}],&t>0\end{array}\right.$ | $\mathcal{F}_{s}\{f(t)\}=\int_0^{\infty}f(t)\sin\omega t\,\mathrm{d}t$ | $p=\sigma+\mathrm{i}\omega,\ \sigma=0$ |
| 梅林变换 | $\left\{\begin{array}{ll}0,&t<0\\ t^{p-1},&t>0\end{array}\right.$ | $\mathcal{M}\{f(t)\}=\int_0^{\infty}t^{p-1}f(t)\,\mathrm{d}t$ | |
| v 阶汉克尔变换 | $\left\{\begin{array}{ll}0,&t<0\\ tJ_{v}(\sigma t),&t>0\end{array}\right.$ | $\mathcal{H}_{v}\{f(t)\}=\int_0^{\infty}tJ_{v}(\sigma t)f(t)\,\mathrm{d}t$ | $p=\sigma+\mathrm{i}\omega,\ \omega=0$；$J_{v}(\sigma t)$ 是 v 阶第一类贝塞尔函数 |
| 斯蒂尔切斯变换 | $\left\{\begin{array}{ll}0,&t<0\\ \frac{1}{p+t},&t>0\end{array}\right.$ | $\mathcal{S}\{f(t)\}=\int_0^{\infty}\frac{f(t)}{p+t}\,\mathrm{d}t$ | |

注栏归属（严格按行，不跨主体转移）：$p=\sigma+\mathrm{i}\omega,\ \sigma=0$ 仅属傅里叶族五行；$\omega=0$ 仅属汉克尔行；“可双侧/有限”仅属卡森行；$1(t)$ 关系式仅连接双侧与单侧拉普拉斯变换。

## 算子方法三步骤（15.1.6，逐字转录）

运用算子方法求解常微分方程包括下述三个步骤：

1. 把关于未知函数的微分方程转化为其变换方程。
2. 求变换方程在像空间的解。变换方程通常不再是微分方程，而是代数方程。
3. 利用变换的逆变换 $\mathcal{T}^{-1}$ 回到原始空间，即确定初始问题的解。

算子方法的主要困难通常不是求解变换方程，而在于求函数的变换和逆变换（实践查表 21.13–21.15）。

## 转写讹误与内部张力

源文件为 OCR 转写，存在系统性讹误（详单见 [[queries/15-1全节系统性转写讹误清单]]）：

1. 行内符号系统性丢失（$t$、$\mathcal{T}$、$\mathcal{L}$ 等在正文中脱落）。
2. “(15.lb) 式称为 $\tau$ 变换”：编号 l/1 混淆，且 $\tau$ 疑为 $\mathcal{T}$ 之讹（[[queries/式15-1b之τ变换称谓疑为T变换]]）。
3. 15.1.4 可变换函数集合记号 $T$ 与算子 $\mathcal{T}$ 撞号，原文待校。
4. 表 15.1 有限拉普拉斯、有限傅里叶两行核栏损坏（[[queries/表15-1有限拉普拉斯与有限傅里叶核行转写讹误]]）。
5. “参见第 1052 15.6”页码与节号混排；“15.1 给出了…框架”疑缺“图”字。
6. $\mathcal{L}^{2}$ 记号歧义（二重变换 vs 算子平方），正文已自行澄清。
7. 一般式 (15.1a) 积分限 $(-\infty,+\infty)$ 与表中核在 $t<0$ 取 0 的约定相容但易误读；傅里叶核 $e^{-\mathrm{i}\omega t}$ 与余弦/正弦核取 $e^{+\mathrm{i}\omega t}$ 实部/虚部的符号方向不同，因 $\cos$ 偶、$\sin$ 奇而相容，非矛盾。
8. 多处“千”讹“于”（对千/关千/用千/在千）。
