# 数学手册(原书第10版) 13.2.6 梯度算子和拉普拉斯算子

## 概述

本节为 13.2「空间的微分算子」的第 6 小节（父节源页：[[sources/10-数学手册原书第10版--11-132-空间的微分算子--10s6yfu]]），主题有二：

1. **梯度算子（nabla 算子）∇**：以符号向量统一表达空间微分算子（[[concepts/梯度算子]]），并给出其线性性与乘积法则（[[concepts/梯度算子的运算法则]]、[[methodology/nabla形式乘法计算流程]]）；
2. **拉普拉斯算子 Δ = ∇·∇**：定义、刚体不变性与四种坐标系公式（[[concepts/拉普拉斯算子]]、[[comparisons/四种坐标系拉普拉斯公式比较]]），以及 ∇ 二次作用产生的恒等式（[[concepts/向量分析的二阶恒等式]]）。

小节结构：13.2.6.1 梯度算子；13.2.6.2 梯度算子运算法则（例 A、例 B）；13.2.6.3 向量梯度；13.2.6.4 作用两次的梯度算子；13.2.6.5 拉普拉斯算子。

## 关键公式（原文结构化转录）

### 13.2.6.1 梯度算子

```latex
\nabla = \frac{\partial}{\partial x}\vec{i} + \frac{\partial}{\partial y}\vec{j} + \frac{\partial}{\partial z}\vec{k} \tag{13.67}

\operatorname{grad} U = \nabla U \tag{13.68a}
\operatorname{grad} \vec{V} = \nabla \vec{V} \tag{13.68b}
\operatorname{div} \vec{V} = \nabla \cdot \vec{V} \tag{13.68c}
\operatorname{rot} \vec{V} = \nabla \times \vec{V} \tag{13.68d}
```

正文说明：∇ 的分量是偏微分算子（∂/∂x 意味着关于 x 的偏微商，其他变量视为常数）；空间微分算子的公式可由 ∇ 与标量 U 或向量 V⃗ 的形式乘法得到。四算子分别回指第 926 页 13.2.2（梯度）、第 928 页 13.2.3（向量梯度）、第 928 页 13.2.4（散度）、第 930 页 13.2.5（旋度）。

### 13.2.6.2 梯度算子运算法则

```latex
\nabla\left(\sum a_i X_i\right) = \sum a_i \nabla X_i \tag{13.69}

\nabla(XYZ) = \nabla(\overset{\downarrow}{X}YZ) + \nabla(X\overset{\downarrow}{Y}Z) + \nabla(XY\overset{\downarrow}{Z}) = (\nabla X)YZ + X(\nabla Y)Z + XY(\nabla Z) \tag{13.70}
```

例 A（↓ 标记按文义恢复；脚注 OCR 有搅乱）：

```latex
\textbf{A:}\ \operatorname{grad}(U\vec{V}) = \nabla(U\vec{V}) = \nabla(\overset{\downarrow}{U}\vec{V}) + \nabla(U\overset{\downarrow}{\vec{V}}) = \vec{V}\cdot\nabla U + U\,\nabla\cdot\vec{V} = \vec{V}\cdot\operatorname{grad} U + U\operatorname{div}\vec{V}
```

脚注：「原文将此式最左端的 grad 误为 div。译者注」——此处存在算子之辨，见 [[queries/例A左端算子grad与div之辨]]。

例 B（V⃗₁V⃗₂ 并置按手册惯例为标量积；↓ 标记在转写中被搅作「!」「\bar」）：

```latex
\textbf{B:}\ \operatorname{grad}(\vec{V}_1\vec{V}_2) = \nabla(\overset{\downarrow}{\vec{V}}_1\vec{V}_2) + \nabla(\vec{V}_1\overset{\downarrow}{\vec{V}}_2)

\text{由}\ \vec{b}(\vec{a}\vec{c}) = (\vec{a}\vec{b})\vec{c} + \vec{a}\times(\vec{b}\times\vec{c})\ \text{得}

\operatorname{grad}(\vec{V}_1\vec{V}_2) = (\vec{V}_2\nabla)\vec{V}_1 + \vec{V}_2\times(\nabla\times\vec{V}_1) + (\vec{V}_1\nabla)\vec{V}_2 + \vec{V}_1\times(\nabla\times\vec{V}_2) \\
= (\vec{V}_2\operatorname{grad})\vec{V}_1 + \vec{V}_2\times\operatorname{rot}\vec{V}_1 + (\vec{V}_1\operatorname{grad})\vec{V}_2 + \vec{V}_1\times\operatorname{rot}\vec{V}_2
```

### 13.2.6.3 向量梯度

```latex
\operatorname{grad}\vec{V} = \nabla\vec{V} \tag{13.71a}

2(\vec{a}\cdot\nabla)\vec{V} = \operatorname{rot}(\vec{V}\times\vec{a}) + \operatorname{grad}(\vec{a}\vec{V}) + \vec{a}\operatorname{div}\vec{V} - \vec{V}\operatorname{div}\vec{a} - \vec{a}\times\operatorname{rot}\vec{V} - \vec{V}\times\operatorname{rot}\vec{a} \tag{13.71b}

(\vec{a}\cdot\nabla)\vec{r} = \vec{a} \tag{13.71c}
```

(13.71b)(13.71c) 回指第 925 页 (13.32b)（属已入库的 13.2.1，见 [[concepts/向量场的方向导数]]、[[concepts/向量梯度]]）。

### 13.2.6.4 作用两次的梯度算子

```latex
\nabla(\nabla\times\vec{V}) = \operatorname{div}\operatorname{rot}\vec{V} \equiv 0 \tag{13.72}

\nabla\times(\nabla U) = \operatorname{rot}\operatorname{grad}U \equiv \vec{0} \tag{13.73}

\nabla(\nabla U) = \operatorname{div}\operatorname{grad}U = \Delta U \tag{13.74}
```

(13.72)(13.74) 首个 ∇ 后疑漏点乘「·」，见 [[queries/式13-72与13-74首nabla后疑漏点乘]]。

### 13.2.6.5 拉普拉斯算子

定义与四坐标系公式：

```latex
\triangle = \nabla\cdot\nabla = \nabla^{2} \tag{13.75}

\Delta U(x,y,z) = \frac{\partial^2 U}{\partial x^2} + \frac{\partial^2 U}{\partial y^2} + \frac{\partial^2 U}{\partial z^2} \tag{13.76}

\Delta U(\rho,\varphi,z) = \frac{1}{\rho}\frac{\partial}{\partial\rho}\left(\rho\frac{\partial U}{\partial\rho}\right) + \frac{1}{\rho^2}\frac{\partial^2 U}{\partial\varphi^2} + \frac{\partial^2 U}{\partial z^2} \tag{13.77}

\Delta U(r,\vartheta,\varphi) = \frac{1}{r^2}\frac{\partial}{\partial r}\left(r^2\frac{\partial U}{\partial r}\right) + \frac{1}{r^2\sin\vartheta}\frac{\partial}{\partial\vartheta}\left(\sin\vartheta\frac{\partial U}{\partial\vartheta}\right) + \frac{1}{r^2\sin\vartheta}\frac{\partial^2 U}{\partial\varphi^2} \tag{13.78}

\Delta U(\xi,\eta,\zeta) = \frac{1}{D}\left[\frac{\partial}{\partial\xi}\left(\frac{D}{|\partial\vec{r}/\partial\xi|^2}\frac{\partial U}{\partial\xi}\right) + \frac{\partial}{\partial\eta}\left(\frac{D}{|\partial\vec{r}/\partial\eta|^2}\frac{\partial U}{\partial\eta}\right) + \frac{\partial}{\partial\zeta}\left(\frac{D}{|\partial\vec{r}/\partial\zeta|^2}\frac{\partial U}{\partial\zeta}\right)\right] \tag{13.79a}

\vec{r}(\xi,\eta,\zeta) = x(\xi,\eta,\zeta)\vec{i} + y(\xi,\eta,\zeta)\vec{j} + z(\xi,\eta,\zeta)\vec{k} \tag{13.79b}

D = \left|\frac{\partial\vec{r}}{\partial\xi}\right|\cdot\left|\frac{\partial\vec{r}}{\partial\eta}\right|\cdot\left|\frac{\partial\vec{r}}{\partial\zeta}\right| \tag{13.79c}
```

∇ 与 Δ 的特殊关系：

```latex
\nabla(\nabla\cdot\vec{V}) = \operatorname{grad}\operatorname{div}\vec{V} \tag{13.80}

\nabla\times(\nabla\times\vec{V}) = \operatorname{rot}\operatorname{rot}\vec{V} \tag{13.81}

\nabla(\nabla\cdot\vec{V}) - \nabla\times(\nabla\times\vec{V}) = \triangle\vec{V} \tag{13.82}

\triangle\vec{V} = (\nabla\cdot\nabla)\vec{V} = \Delta V_x\,\vec{i} + \Delta V_y\,\vec{j} + \Delta V_z\,\vec{k}
= \left(\frac{\partial^2 V_x}{\partial x^2} + \frac{\partial^2 V_x}{\partial y^2} + \frac{\partial^2 V_x}{\partial z^2}\right)\vec{i} + \left(\frac{\partial^2 V_y}{\partial x^2} + \frac{\partial^2 V_y}{\partial y^2} + \frac{\partial^2 V_y}{\partial z^2}\right)\vec{j} + \left(\frac{\partial^2 V_z}{\partial x^2} + \frac{\partial^2 V_z}{\partial y^2} + \frac{\partial^2 V_z}{\partial z^2}\right)\vec{k} \tag{13.83}
```

正文性质陈述：拉普拉斯算子不是向量，表示二阶偏导数之和；既能作用于标量函数，也能作用于向量函数（对向量的作用是分量式的，结果为向量）；它是坐标平移和/或旋转下的不变量。

## 核心发现

### 发现一：(13.78) 球面拉普拉斯末项疑缺平方（最高优先级勘误候选）

(13.78) 末项系数 $\frac{1}{r^2\sin\vartheta}$ 应为 $\frac{1}{r^2\sin^2\vartheta}$。双重独立证据：

1. **标准公式**：球面坐标系拉普拉斯算子的 φ 项标准系数为 $\frac{1}{r^2\sin^2\vartheta}$；
2. **内部一致性检验**：将 (13.79a) 取球面度规 $h_r=1,\ h_\vartheta=r,\ h_\varphi=r\sin\vartheta$ 特化，r 项与 ϑ 项均与 (13.78) 吻合，唯 φ 项得 $\sin^2\vartheta$。

该错误仅属 (13.78)，不得归咎于 13.2.2 已复算无误的球面梯度公式 (13.38)（见 [[findings/式13-36至13-39各坐标系梯度公式转录复算]]）。疑为上标 2 的转写丢失或印刷脱漏，需核对纸质书，详见 [[queries/式13-78球面拉普拉斯末项sinϑ疑缺平方]]。后续位势、场论章节将用到球面 Δ，此勘误优先级最高。

### 发现二：例 A 左端算子 grad 与 div 之辨（考据发现）

按转写，例 A 为「grad(UV⃗) = V⃗·grad U + U div V⃗」，脚注称「原文将此式最左端的 grad 误为 div」（脚注文字本身被 OCR 搅乱作「叩……译者注■」）。类型检验：右端 $\vec V\cdot\operatorname{grad}U + U\operatorname{div}\vec V$ 为**标量**，故左端必须是 $\operatorname{div}(U\vec V)$——标准乘积法则 $\operatorname{div}(U\vec V) = \vec V\cdot\operatorname{grad}U + U\operatorname{div}\vec V$ 恰好成立；grad(UV⃗)（并向量型梯度）与右端类型不符。转写中间步骤 $\vec V\cdot\nabla U + U\,\nabla\cdot\vec V$ 中出现的显式点乘亦与 div 读法一致。由此产生张力：若译者确实把原书的 div「更正」为 grad，则该更正本身疑为误改——原书反而是对的；另一种可能是转写或脚注文字被 OCR 搅乱。需核对中文纸质书与德文原书，详见 [[queries/例A左端算子grad与div之辨]]。
