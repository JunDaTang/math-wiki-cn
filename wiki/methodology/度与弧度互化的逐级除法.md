# 度与弧度互化的逐级除法

这是《数学手册(原书第10版)》3.1.1.5 算例 B 示范的、把弧度值展开为度-分-秒表示的手算程序。其存在理由（why）：公式 (3.2) 的换算含无理数 $\pi$，直接相乘只能得到十进制小数度数；逐级除法无须十进制度小数即可直接读出六十进制的度、分、秒各位数字。

## 原理

度分秒是六十进制混合进制。设

$$u_1 = \frac{\pi}{180}\ (1^{\circ}\ \text{的 rad 值}), \qquad u_2 = \frac{\pi}{10800}\ (1'\ \text{的 rad 值}), \qquad u_3 = \frac{\pi}{648000}\ (1''\ \text{的 rad 值}),$$

则 $u_1 = 60u_2 = 3600u_3$，且待换算角 $\alpha = D u_1 + M u_2 + S u_3$（$0 \le M, S < 60$）。逐级除法即对该混合进制做数位展开：

1. $\alpha : u_1$ —— 整数商为度数 $D$，余数 $r_1 = Mu_2 + Su_3 < u_1$；
2. $r_1 : u_2$ —— 整数商为分数 $M$，余数 $r_2 = Su_3 < u_2$；
3. $r_2 : u_3$ —— 整数商为秒数 $S$。

因为相邻单位的 rad 值相差 60 倍，每级取整不会「跳位」——这正是逐级取余可行的原因：它等价于把以 rad 为单位的量按 60 进制逐位读出。反向（度 → rad，算例 A）则是把度、分、秒各乘以其 rad 值后相加。

## 程序（按原书常数表）

```text
输入：角 α（rad）
1) α : 0.017453   → 商 = 度数，余数 r1
2) r1 : 0.000291  → 商 = 分数，余数 r2
3) r2 : 0.000005  → 商 = 秒数
```

## 精度警示（重要）

常数表只给 5 位有效数字，误差随度数放大：仅 $1^{\circ}$ 系数的截断（$0.017453$ 对精确值 $0.0174533$）在 $323^{\circ}$ 上即累积约 $9\times10^{-5}$ rad ≈ 20″。用表中常数复算算例 B 的除法链会得到 $323^{\circ}26'23''$（$5.645 : 0.017453 = 323$ 余 $0.007681$；$0.007681 : 0.000291 = 26$ 余 $0.000115$；$0.000115 : 0.000005 = 23$），秒位完全失真——而精确值为 $323^{\circ}26'04.8''$。故用 5 位常数手算只能可靠到分位；要定秒位必须使用更多位系数。原书印出的中间数字与表中常数不自洽（疑为更多位系数的原文被截短或讹抄），但最终结果 $323^{\circ}26'05''$ 正确，详见 [[算例B除法链数字是否为讹误]] 与 [[算例A系数与结果不自洽是否为讹误]]。

## 适用范围

- 适用于任何弧度 ↔ 度分秒的互化；当上下文已表明单位为弧度时，rad 标记通常省略。
