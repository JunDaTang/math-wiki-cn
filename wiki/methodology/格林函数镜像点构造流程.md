# 格林函数镜像点构造流程

## 目的

对圆盘与球上的 [[拉普拉斯方程与拉普拉斯算子|拉普拉斯方程]] [[狄利克雷问题]] 构造满足“边界为零 + 对数（或 1/r）奇性”条件的 [[格林函数与格林方法|格林函数]]，进而得 [[泊松积分]]。镜像点法是少数可显式构造格林函数的情形（手册亦指出一般情形求格林函数特别困难）。

## 流程（以圆盘为例，式 9.101）

1. **放置镜像点**：对极点 M(ξ, η)（OM = ρ），在同一条自圆心 O 出发的射线上取点 M₁，使 OM · OM₁ = R²（式 9.101c）。
2. **写出格林函数**：G = ln(1/r) + ln(r₁ρ/R)（式 9.101b），r = MP、r₁ = M₁P。第一项提供所需的奇性（对应 U = 1），第二项在区域内部调和且专司边界归零。
3. **验证边界条件**：P 在圆周上时由相似三角形（OM·OM₁ = R²）得 r₁/r = R/ρ，故 r₁ρ/R = r，G = ln(1/r) + ln r = 0 ✓。
4. **求法向导数并代入表示公式**：外法向 ∂G/∂n_out = (ρ² − R²)/(Rr²)；代入 (9.99e) 时注意手册用**内法向**（即取 −∂G/∂n_out = (R² − ρ²)/(Rr²)），配合边界弧元 ds = R dφ 恰得泊松积分 (9.101d)。

## 球的情形（式 9.102）

镜像关系同为 OM · OM₁ = R²（M₁ = (Rξ/ρ, Rη/ρ, Rζ/ρ)），格林函数 G = 1/r − R/(r₁ρ)（式 9.102b），奇性部分 U/r + V；代入 (9.100e) 得球面泊松积分 (9.102c)。

## 勘误

转写在 9.102b 处将 ρ 写作 √(ξ² + ζ² + ζ²)，应为 √(ξ² + η² + ζ²)（η² 脱落），见 [[findings/式9-101至9-102圆盘与球格林函数复算]]。两维数的平行比较见 [[comparisons/圆盘与球的格林函数比较]]。
