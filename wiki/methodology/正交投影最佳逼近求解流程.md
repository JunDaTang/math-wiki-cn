# 正交投影最佳逼近求解流程

## 目的（为什么）

在希尔伯特空间 H 中求闭子空间 H₀（或闭凸非空子集）中距给定向量 x 最近的元。[[concepts/投影定理与逼近定理]] 保证该问题解的存在唯一性；本流程将其操作化：一旦掌握张成 H₀ 的正交规范系，最佳逼近元就是傅里叶部分和 (12.128)，误差与 H₀ 正交、误差范数可由毕达哥拉斯定理读出。

## 流程

1. **确定逼近集**：确认 H₀ 为闭子空间（或闭凸非空集；后者解仍存在唯一，但一般不再有线性展开公式）。
2. **选取正交规范系**：取 {e_k} ⊂ H₀ 使 H₀ = lin{e_k}‾（可由 [[methodology/格拉姆-施密特正交化构造流程]] 构造）。
3. **计算傅里叶系数**：c_k = (x, e_k)。
4. **构成逼近元**：σ_n = Σ_{k=1}^n c_k e_k（(12.128)）。对每个固定 n，σ_n 是 x 在 H_n = lin{e₁,…,e_n} 中的最佳逼近，且 x − σ_n ⊥ H_n。
5. **误差控制**：由毕达哥拉斯定理（(12.117)，见 [[concepts/正交性与正交补]]），‖x − σ_n‖² = ‖x‖² − Σ_{k=1}^n ∣c_k∣² ⩾ 0；n → ∞ 时受 [[concepts/贝塞尔不等式]] 控制，若 {e_k} 完备（见 [[concepts/完备正交系与希尔伯特基]]）则误差趋于 0。
