# 循环码生成多项式编码流程

## 目的与原理（为什么有效）

对循环 (n,k) 线性码（[[concepts/循环码]]）实现高效编码与码字判定。原理：码字与次数 ≤ n−1、系数属于 GF(2) 的多项式一一对应，循环移位对应「乘 x 后取模 x^n−1」（式 5.270），于是整个码由 x^n−1 的一个 n−k 次因子 g(x) 生成——这是 [[concepts/多项式环]] 与 [[concepts/带余除法与欧几里得算法]]（多项式情形）的直接应用。

## 步骤

1. **建立多项式表示**：码字 c_0c_1…c_{n−1} 对应 c(x) = c_0 + c_1x + … + c_{n−1}x^{n−1}。
2. **确定生成多项式**：取 x^n − 1 的 n−k 次因子 g(x)（k ∈ {1, 2, …, n−1}）；同时得到控制多项式 h(x)：g(x)h(x) = x^n − 1。
3. **编码**：信息字 a_1a_2…a_k 的多项式表示 a(x) 映射为 a(x) ↦ a(x)·g(x)（式 5.271）。
4. **码字判定**：d(x) 是码中元素 ⇔ g(x) | d(x) ⇔ d(x)h(x) ≡ 0 (mod x^n − 1)。

## 特例：BCH 码

BCH 码（[[concepts/bch码]]）的生成多项式取为 m_{α^b}(x), …, m_{α^{b+δ−2}}(x) 的 lcm（式 5.272），使 d_min ≥ δ 可事先保证。
