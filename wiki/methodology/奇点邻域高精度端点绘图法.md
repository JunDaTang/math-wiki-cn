# 奇点邻域高精度端点绘图法

## 目的（why）

在定义域端点附近存在奇点的函数（如 y = x + ArcCoth[x] 在 x = ±1 处，ArcCoth[x] 定义域为 |x| > 1），直接绘图会遇两类困难：跨奇点采样导致求值失败/发散；端点离奇点不够近时，曲线在给定值域窗口内过早截止，无法覆盖所要求的 y 值域。《数学手册（原书第10版）》20.4.5.2 的算例给出对策：**在 ±1 的闭域邻[近]内选取高精度的 x 值，是为了对所要求的 y 的值域得到足够大的函数值**（原句转写残缺，据算例复原）。

## 步骤（how）

1. 识别奇点与定义域分支（x > 1 与 x < −1 两支）；
2. 将绘图端点取在奇点的高精度邻域，如左支右端取 `1.000000000005`（小数点后 11 位逼近 1），对称地右支左端取 `-1.000000000005`：
   ```mathematica
   In[1] := f1 = Plot[x + ArcCoth[x], {x, 1.000000000005, 7}]
   In[2] := f2 = Plot[x + ArcCoth[x], {x, -7, -1.000000000005}]
   ```
3. 两支分别绘制，避免采样跨越奇点；
4. 以 `Show[{f1, f2}, PlotRange -> {-10, 10}, AspectRatio -> 1.2, Ticks -> ..., AxesOrigin -> {0, 0}]` 合并重显，并以手工 Ticks/AxesOrigin 标出关键刻度（图 20.4b）。

## 原理

端点越靠近奇点，端点处函数值越大（ArcCoth[x] 在 x→1⁺ 时发散），从而曲线在 PlotRange 窗口（此处 {-10, 10}）内延伸至上/下边界，呈现完整的渐近行为；若端点如 1.001 之类离奇点较远，近奇点一侧的曲线会在窗口边界前截止。

## 局限与注意

- 依赖浮点精度：1.000000000005 与 1 之差在机器精度下可分辨，但更高要求时需 `N[..., prec]` 或有理端点配合高精度；
- 该技巧与 [[符号解浮点代入的相消风险]] 同属「在病态点附近谨慎取值」的数值卫生（numerical hygiene）主题；
- 转写注意：原书 In[3] 的 Ticks 列表多一闭括号、`AxesOrigin → 0, 0` 脱花括号，复算前须先修正（[[式20-39至20-43函数绘图与Show复算]]）。
