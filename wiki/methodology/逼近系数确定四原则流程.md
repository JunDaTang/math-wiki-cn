# 逼近系数确定四原则流程

**目的与原理**：以函数逼近求边值问题 (19.118) 的解析形式近似解：y(x) ≈ g(x) = Σ a_i g_i(x)（式 19.121）或 g(x) = g₀(x) + Σ a_i g_i(x)（式 19.131，g₀ 满足边值、g_i 满足齐次边界条件，例 (19.133) 的线性 g₀）。将 g 代入微分方程得亏量 ε（式 19.122）；系数 a_i 由四种“消除亏量”的原则之一确定。

**步骤**：

1. 选取满足边界条件的线性无关基函数 g₀, g₁, …, g_n。
2. 形成亏量 ε(x; a₁,…,a_n) = g″ + p g′ + q g − f。
3. 按所选原则确定系数：
   - **配置法**（19.123）：ε(x_ν) = 0 于 n 个配置点；
   - **最小二乘法**（19.124）–（19.125）：∂/∂a_i ∫_a^b ε² dx = 0；
   - **伽辽金法**（19.126）：∫_a^b ε g_i dx = 0；
   - **里茨法**（19.127）–（19.128）：∂I/∂a_i = 0，I 为变分积分（自伴问题的 H 由 (19.130) 得到）。
4. 求解所得方程组：线性边值问题为线性方程组；非线性边值问题所得非线性方程组用 19.2.2（未入库）方法求解。
