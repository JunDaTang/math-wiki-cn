# 旋度坐标系分量计算流程

在任意坐标系中写出 rot V⃗ 分量的统一流程，依据《数学手册》13.2.5.2 式 (13.62)（手册标题为“一般直角坐标系中的旋度”），并明确其适用边界。

## 动机（为什么）

旋度的定义式（13.57 / 13.58b）与坐标无关，但实际计算需要具体坐标系下的分量公式。对每个坐标系从定义出发重新推导冗长且易错；式 (13.62) 给出以尺度因子表达的统一公式，一套公式覆盖笛卡儿、柱面、球面及一切（正交）曲线坐标系，且各坐标系公式之间可以互相退化验证。

## 流程（怎么做）

1. 写出坐标映射 r⃗(ξ,η,ζ) = x(ξ,η,ζ) î + y(ξ,η,ζ) ĵ + z(ξ,η,ζ) k̂。
2. 计算尺度因子：h_ξ = |∂r⃗/∂ξ|，h_η = |∂r⃗/∂η|，h_ζ = |∂r⃗/∂ζ|。
3. 计算 D = h_ξ · h_η · h_ζ。
4. 对目标分量 i，按轮换 (i, j, k) 代入统一公式：
   (rot V⃗)_i = (h_i/D) [ ∂(h_k V_k)/∂u_j − ∂(h_j V_j)/∂u_k ]
5. 用已知坐标系退化验证（强烈建议）：
   - 笛卡儿 h = (1, 1, 1) → 复得式 (13.59a)
   - 柱面 h = (1, ρ, 1) → 复得式 (13.60b)
   - 球面 h = (1, r, r sinϑ) → 复得式 (13.61b)（ϑ 极角、φ 方位角，与表 13.1 约定一致）

## 适用边界（关键限制）

本流程**仅对正交曲线坐标系成立**。斜角坐标反例：取 r⃗ = (ξ+η) î + η ĵ + ζ k̂（h = (1, √2, 1)，坐标基非正交）与场 V⃗ = (0, x, 0)（真值 rot_ζ = 1），公式给出 rot_ζ = (1/√2)(2+1) = 3/√2 ≠ 1。

因此手册标题“一般直角坐标系”实际指正交的曲线坐标系。这为 [[queries/一般直角坐标系是否限于正交坐标系]] 提供了旋度侧的独立反例，与梯度侧（13.2.2 式 13.38）的证据互补。复算细节见 [[findings/式13-59至13-62c各坐标系旋度公式转录复算]]。
