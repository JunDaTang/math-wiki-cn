# 素数幂逐级提升流程

**用途**：由 f(x) ≡ 0 (mod p) 的解构造 f(x) ≡ 0 (mod p^α) 的解。**出处**：5.4.3.9，式 (5.260)；即通称的 Hensel 提升算法（源文未命名）。配合互素模分解（式 5.259 / [[concepts/中国剩余定理]]）可解任意模多项式同余式。

## 前提

- 已有模 p 的解 x ≡ x₁ (p)；
- 非退化条件 p ∤ f′(x₁)——此时提升在每一级唯一（源文 b) 条款）。

## 步骤（由模 p 升到模 p^α）

1. 设当前解为 x ≡ x_j (mod p^j)。令 x = x_j + p^j t_j。
2. 解线性同余式（模 p）：

$$\frac{f(x_j)}{p^j} + f'(x_j)\, t_j \equiv 0 \pmod p.$$

（j = 1 时即式 5.260a，j = 2 时即式 5.260b。）由 p ∤ f′(x_j) 知其模 p 唯一可解，得 t_j ≡ t_j′ (p)。

3. 代回 t_j = t_j′ + p t_{j+1}，得 x = x_{j+1} + p^{j+1} t_{j+1}，其中 x_{j+1} = x_j + p^j t_j′。
4. 重复直至 j = α；x ≡ x_α (mod p^α) 即所求解。

## 为什么可行（机理）

x = x_j + p^j t 代入后 f(x) ≡ f(x_j) + p^j t f′(x_j) (mod p^{j+1})（高阶项含 p^{2j}，j ≥ 1 时被 p^{j+1} 整除），故要求 f(x_j)/p^j + f′(x_j) t ≡ 0 (mod p)——每级把「f(x_j) ≡ 0 (mod p^j)」的精度提高一个 p 的幂。（机理为复核推理，源文未推导。）

## 算例（已复算）

f(x) = x⁴ + 7x + 4 ≡ 0 (mod 27)：x₁ = 1（模 3 唯一解，f′(1) = 11 不被 3 整除）；4 + 11t₁ ≡ 0 (3) ⟹ t₁ = 1，x₂ = 4；32 + 263t₂ ≡ 0 (3) ⟹ t₂ = 2，x₃ = 22。f(22) = 234414 = 27·8682 ✓。见 [[findings/多项式同余分解与提升法算例]]。

## 退化情形

p | f′(x₁) 时提升不唯一或不存在，须另行分支处理——源文未展开。
