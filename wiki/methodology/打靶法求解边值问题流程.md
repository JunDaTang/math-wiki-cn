# 打靶法求解边值问题流程

**目的与原理**：将边值问题 (19.118) 化为初值问题族 + 一维参数求根，从而完全复用 19.4.1 的初值问题方法与 19.1 的求根方法。

**步骤**（单目标打靶法）：

1. 引入初始斜率参数 s，构造初值问题 (19.134)：y″ + p(x)y′ + q(x)y = f(x)，y(a) = α，y′(a) = s。
2. 定义失配函数（式 19.135）：F(s) = y(b, s) − β；y(x, s) 为 (19.134) 以参数 s 的解，已满足第一个边界条件。
3. 用试位法（割线法，即 [[concepts/试位法]]）求 F(s) = 0。
4. 每次 F(s) 求值 = 将初值问题 (19.134) 从 a 积分到 b（用 19.4.1 的方法）。
5. 所得 s* 对应的初值问题解即边值问题近似解。

**多目标变体**：将 [a,b] 分为子区间，每个子区间上独立打靶；须附加子区间端点连续过渡条件（更多条件），大多用于非线性边值问题，数值实现见 [19.31]。

见 [[concepts/打靶法]]；与其他两类边值方法比较见 [[comparisons/边值问题三类方法比较]]。
