# 命题公式经基本定律化简的流程

**原理（为何可行）**：利用命题演算基本定律（式 5.8–5.18，[[concepts/命题演算基本定律]]）作等价改写——每一步都不改变真值函数，故化简结果与原公式逻辑等价。

**流程**（以原书化简例 A∨B̄ ⇒ AB∨C = B∨C 为范式，[[findings/蕴涵公式化简例]]）：

1. **消去蕴涵/等价**（5.17a）：A∨B̄ ⇒ AB∨C = ¬(A∨B̄)∨AB∨C；
2. **德摩根内移否定**（5.14b）：¬(A∨B̄) = ĀB，得 ĀB∨AB∨C；
3. **逆向分配（提取公因子）**（5.10a 之逆）：ĀB∨AB = (Ā∨A)B；
4. **排中律**（5.13b）：Ā∨A = T，得 TB∨C；
5. **T 律**（5.15a）：TB = B，得 B∨C。

**交叉验证**：化简结果应与真值表法一致（[[methodology/真值表验证逻辑等价的流程]]）。

**替代路径**：共识律 (5.18c/d)、吸收律 (5.11)、幂等律 (5.12) 等亦常用于消去冗余项。

**转写警示**：原书该化简链的转写存在首项否定号脱落与 B̄/B 前后不一之讹（[[queries/化简推导链转写讹误]]），引用时应以复算版为准。
