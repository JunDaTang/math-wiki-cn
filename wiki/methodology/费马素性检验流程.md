# 费马素性检验流程

## 目的与原理（为什么有效）

在不知道 n 的素因子的情形下判定奇数 n > 1 是否为素数。原理是费马小定理的单向应用：素数必满足 a^(n−1) ≡ 1 (mod n)（gcd(a,n)=1），故该同余式不成立即可**确定地**判 n 为合数；成立时只是「通过该基的检验」，素性仍是或然的。

## 步骤

1. 选取 a ∈ ℤ_n∖{0}。
2. 计算 gcd(a,n)（可用 [[methodology/整数欧几里得算法求gcd流程]]）：
   - 若 gcd(a,n) > 1，则 n 不是素数（终止，确定性结论）。
3. 若 gcd(a,n) = 1，计算 a^(n−1) mod n（可用重复平方法）：
   - 若 a^(n−1) ≢ 1 (mod n)，则 n 不是素数（确定性结论）；
   - 若 a^(n−1) ≡ 1 (mod n)，则 n 通过对基 a 的检验；n 可能是素数，但必须对其他基（a 的其他值）复检。

## 误差控制

随机独立取 k 个互素基且全部通过时，若 n 是**非卡迈克尔**合数，错误水平 ≤ 1/2^k（因 ℤ_n∖{0} 中满足 gcd(a,n)=1 的数至少有一半使 a^(n−1) ≢ 1 (mod n)）。对卡迈克尔数（[[entities/卡迈克尔数]]）本流程整体失效。

## 算例

- n = 15：a = 4 通过（4^14 ≡ 1）、a = 7 不通过（7^14 ≡ 4 ≢ 1）⇒ 15 不是素数（已复算）。
- n = 341：对基 2 是伪素数、对基 3 不是。
- n = 561：对一切互素基通过，但 561 = 3·11·17 为合数（卡迈克尔数）。
