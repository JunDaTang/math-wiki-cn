# 复三角双曲函数值的欧拉关系计算流程

## 目的与理据

计算复变量 $z = x + \mathrm{i}y$ 处的 $\sin z$、$\cos z$、$\sinh z$、$\cosh z$ 值。理据（源文 14.5.2 第 4 条）：**实三角和双曲函数的变换公式（加法公式等）对复三角和双曲函数也成立**（源文回指手册 2.7.2、2.9.3，未入库），故可把复值计算化归为实值计算。

## 两条等价路径

- **路径 A（加法公式）**：对 $z = x + \mathrm{i}y$ 施行 $\sin(a+b)$、$\cos(a+b)$、$\sinh(a+b)$、$\cosh(a+b)$ 的实域公式。
- **路径 B（欧拉关系）**：借助 $e^{\mathrm{i}z} = \cos z + \mathrm{i}\sin z$（式 14.73a）等 [[concepts/欧拉关系式]] 直接展开。

## 流程（以源文示范的 cos z 为例）

1. 分解 $z = x + \mathrm{i}y$。
2. 施行加法公式：$\cos(x+\mathrm{i}y) = \cos x\cos\mathrm{i}y - \sin x\sin\mathrm{i}y$。
3. 用纯虚自变量关系（式 14.78b、14.79a：$\cos\mathrm{i}y = \cosh y$、$\sin\mathrm{i}y = \mathrm{i}\sinh y$）消去虚自变量。
4. 合并实虚部：$\cos(x+\mathrm{i}y) = \cos x\cosh y - \mathrm{i}\sin x\sinh y$（式 14.80；转写原为下标乱码，此为复原）。
5. 读出 $\operatorname{Re}(\cos z) = \cos\operatorname{Re}(z)\cosh\operatorname{Im}(z)$、$\operatorname{Im}(\cos z) = -\sin\operatorname{Re}(z)\sinh\operatorname{Im}(z)$（式 14.81a/b）。
