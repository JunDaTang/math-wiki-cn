# 尼斯特伦法

## 方法概述

尼斯特伦法（Nystrom method）是求解第二类弗雷德霍姆积分方程的数值方法：用[[concepts/高斯求积公式|高斯求积公式]]近似积分算子，在 $n$ 个求积节点处得到一个 $n\times n$ 线性方程组，解出节点值后由半离散关系式（11.25b）回代，得到任意 $x$ 处的近似解。它是 [[methodology/求积半离散化方法|求积半离散化方法]]在"矩形公式精度不足、又不想大幅增加方程组维数"情形下的升级路线。

## 方法步骤

1. 选取高斯求积节点与权值：节点 $x_k = \frac{a+b}{2} + \frac{b-a}{2}t_k$（11.28a），其中 $t_k$ 为第一类勒让德多项式（[[entities/勒让德多项式]]）$P_n(t)$ 的根；权值 $\omega_k = (b-a)A_k$（11.29），$A_k$ 由表 11.1 给出（$n=1,\dots,6$）。
2. 在节点处建立方程组（11.25c）：$\overline{\varphi}(x_k) = f(x_k) + \lambda\sum_{j=1}^n \omega_j K(x_k, y_j)\overline{\varphi}(y_j)$，$k=1,\dots,n$。
3. 解该 $n\times n$ 线性方程组得节点值。
4. 代回（11.25b）：$\overline{\varphi}(x) = f(x) + \lambda\sum_{k=1}^n \omega_k K(x, y_k)\overline{\varphi}(y_k)$，得任意 $x$ 处的近似值。

## 高斯求积的推导要点

推导链（式 11.27a–d）以拉格朗日插值基函数 $L_k(x)$（11.27b）构造插值多项式 $p(x)=\sum_k L_k(x)f(x_k)$，积分得 $\omega_k = \int_a^b L_k(x)\,\mathrm{d}x$；与一般插值型求积不同，高斯求积的节点不能任意选取，必须是 $P_n(t)$（Rodrigues 公式 11.28b）的根。详见 [[concepts/高斯求积公式]] 与 [[findings/式11-27a至11-29与表11-1高斯求积推导转录复算]]。

## 算例（$n=3$，核 $e^{xy}$）

对方程 $\varphi(x) = \cos\pi x + \frac{x}{x^2+\pi^2}(\mathrm{e}^x+1) + \int_0^1 \mathrm{e}^{xy}\varphi(y)\,\mathrm{d}y$（$\lambda=1$ 隐含），取 $n=3$：节点 $0.1127$（转写本缺录）、$0.5$、$0.8873$，权值 $0.2778$、$0.4444$、$0.2778$；解得 $(0.93651, -0.00144, -0.93950)$，与隐含精确解 $\varphi(x)=\cos\pi x$ 在节点处的值 $(0.93797, 0, -0.93797)$ 相比误差约 $1.5\times10^{-3}$。完整数据与独立复算见 [[findings/尼斯特伦法算例指数核复算]]。

## 使用注意

- **权值约定**：表 11.1 的 $A_k$ 恰为标准 Gauss–Legendre 权的一半（$\omega_k=(b-a)A_k$ 已吸收区间长度因子），跨文献对照时须注意。
- **转写缺录**：转写本算例数据列表缺 $x_1 = 0.1127$，且个别系统系数末位与复算有 $10^{-4}\sim10^{-5}$ 级出入，见 [[queries/尼斯特伦法算例x1缺录]]。
