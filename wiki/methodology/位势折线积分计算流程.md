# 位势折线积分计算流程

## 目的（为什么）

保守场中位势 $U$ 的线积分与路径无关（见 [[保守场与位势]]），因此可选取最便于计算的路径——三段平行于坐标轴且相连的直线段（原图 13.15）——把位势计算化为三个一元定积分。这是保守场路径无关性的直接算法化。

## 前提

- 笛卡儿坐标系中给定 $\vec V(\vec r)=V_x\vec i+V_y\vec j+V_z\vec k$；
- 系数 $V_x, V_y, V_z$ 满足可积性条件 (13.108)（即 $\operatorname{rot}\vec V=\vec 0$，且定义域单连通、偏导连续），保证位势存在。

## 步骤（13.3.1.6）

1. 写出位势函数的全微分：

$$\mathrm{d}U = V_{x}\,\mathrm{d}x + V_{y}\,\mathrm{d}y + V_{z}\,\mathrm{d}z.\tag{13.111a}$$

2. 由方程组

$$\frac{\partial U}{\partial x} = V_{x},\quad \frac{\partial U}{\partial y} = V_{y},\quad \frac{\partial U}{\partial z} = V_{z}\tag{13.111b}$$

确定 $U$（即 $\vec V=\operatorname{grad}U$，见 [[梯度]]）。
3. 从固定初始点 $(x_0, y_0, z_0)$ 出发，沿“平行于 $x$ 轴 → 平行于 $y$ 轴 → 平行于 $z$ 轴”的折线积分至 $(x, y, z)$：

$$U = U(x_{0}, y_{0}, z_{0}) + \int_{x_{0}}^{x} V_{x}(x, y_{0}, z_{0})\,\mathrm{d}x + \int_{y_{0}}^{y} V_{y}(x, y, z_{0})\,\mathrm{d}y + \int_{z_{0}}^{z} V_{z}(x, y, z)\,\mathrm{d}z.\tag{13.112}$$

4. $U(x_0, y_0, z_0)$ 为任意加性常数——位势仅确定到相差一个常数（物理学中另常取相反符号 $U^*=-U$，式 13.110）。

## 注意

- 每段积分中未积分的坐标固定为该段起点的相应坐标值（第一段固定 $y=y_0,\,z=z_0$；第二段固定 $z=z_0$；第三段不固定），这是 (13.112) 的关键结构。
- 若可积性条件不满足（或定义域非单连通），则不存在（单值）位势，本流程不可用。
