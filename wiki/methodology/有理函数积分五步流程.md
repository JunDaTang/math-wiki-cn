# 有理函数积分五步流程

## 目的与理据（why）

本流程出自 [[sources/10-数学手册原书第10版--11-813-有理函数的积分--1lrte2m]] 8.1.3.2。它回答的问题是：凭什么可以把"**有理函数的积分总可由初等函数表示**"当作可操作的事实来用？答案不在存在性证明，而在一条固定的代数化简链——把任意有理函数化归为有限类、每类都有闭式原函数的 [[concepts/部分分式分解]] 产物。流程每一步都是初等代数运算，故整条链是构造性的；这也是手册"算法即论证"的一个典型实例。

## 五步

1. **化简**：用最大公因子约分，使 P(x) 与 Q(x) 无公因子（既约）。
2. **分离整部**：若分子次数 m ≥ 分母次数 n，用 Q(x) 除 P(x)（带余除法），得"多项式整部 + 真分式"；整部按式 8.13 逐项积分。m < n 时跳过本步。
3. **分解分母**：将 Q(x) 分解为线性因式与不可约二次因式之积（式 8.14a，条件 8.14b；理论依据为手册 1.6.3.2，未入库）。
4. **提出首系数**：将 aₙ 提到积分号外。
5. **部分分式分解**：将真分式拆为部分分式之和（手册 1.1.7.3，未入库），随后按四情形逐项积分。

## 四情形分派决策（步骤 5 之后）

分解形状与积分公式由**分母根的结构**决定（体例对齐 [[methodology/正项级数审敛法选择流程]] 的决策树）：

```text
问：分母 Q(x) 的根是什么结构？
├── 全为实单根 ────────────── 情形 1（式 8.15）
│     系数：A = P(α)/Q′(α)（覆盖法；仅单根适用！）
│     积分：A·ln|x−α|
├── 全为实根，但含重根 ────── 情形 2（式 8.16）
│     系数：待定系数法
│     积分：k = 1 → A₁·ln|x−α|；k > 1 → −A_k/[(k−1)(x−α)^(k−1)]
├── 含单复根（实系数 ⇒ 共轭成对）→ 情形 3（式 8.17）
│     系数：待定系数法
│     积分：分子拆 (C/2)(2x+p) + (D − Cp/2)
│           → (C/2)·ln(x²+px+q) + (D−Cp/2)/√(q−p²/4)·arctan(⋯)
└── 含多重复根 ────────────── 情形 4（式 8.18）
      系数：待定系数法
      积分：分子变换（8.18c）⇒ 直接项（8.18d）+ 递推项（8.18e，降阶至 m = 1 后套情形 3）
```

其中"待定系数法"即 [[methodology/系数比较法]] 在部分分式语境的应用（列线性方程组比较系数）。四情形逐项对照见 [[comparisons/四种部分分式分解情形比较]]；公式与算例复算见 [[findings/式8-13至8-16多项式与实根两情形及两算例复算]] 与 [[findings/式8-17至8-18复根两情形递推公式及两算例复算]]。

## 注意事项与边界

- **覆盖法仅限单根**：P(α)/Q′(α) 只在情形 1 成立（重根处 Q′(α) = 0，公式失效）；情形 2–4 一律改用待定系数法。
- **整部分离是条件步骤**：m < n（真分式）时跳过步骤 (2)。
- **递推终止性**：式 8.18e 每用一次 m 降 1，有限步后归到 m = 1（情形 3 公式），故算法对任意重复度的复根封闭——这是"总可由初等函数表示"在情形 4 的闭合点。
- **常数处理**：各 ln 项可合并为单一 ln|C·⋯| 形式（手册算例的书写惯例）。
- **适用范围**：仅处理有理函数；其他类型的被积函数须先（例如经适当代换）化为有理函数，再套用本流程。
