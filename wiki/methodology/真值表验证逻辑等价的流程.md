# 真值表验证逻辑等价的流程

**原理（为何可行）**：命题演算中，[[concepts/逻辑等价]] A=B 的定义即「A 与 B 确定相同的真值函数」（原书 5.1.1.6），而 n 个命题变量的解释只有有限 2^n 种，故穷举真值组即可机械判定等价、[[concepts/重言式]] 与矛盾式。

**流程**：

1. 收集公式中的全部命题变量（设 n 个），列出 2^n 行真值表；
2. 按联结词优先级 ¬, ∧, ∨, ⇒, ⇔ 由内向外逐列计算子公式的真值（运算语义依表 5.1，[[findings/命题联结词真值表定义]]）；
3. 对比目标两公式的真值列：逐行相同则 A=B；
4. 若某公式一列恒为 T，则其为重言式（检验 A⇔B 是否重言式亦可判定 A=B）。

**范例**：原书以 8 行真值表验证 A∨B̄ ⇒ AB∨C = B∨C（[[findings/蕴涵公式化简例]]）。

**局限**：行数随变量个数指数增长；在谓词演算中解释族无穷（个体区域与谓词指派均任意），真值表方法失效，须改用语义论证——这解释了原书 5.1.2 只给量词恒等式与单向蕴涵（式 5.23–5.33）而不给真值表的体例差异（[[comparisons/命题演算与谓词演算比较]]）。
