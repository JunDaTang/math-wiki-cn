# DFP 方法矩阵修正与线搜索流程

依据 18.2.5.4（式 18.84–18.86）整理的 DFP 方法执行流程。

## 步骤

1. **初始化**：取 x¹ ∈ ℝⁿ 与对称正定矩阵 M₁（例如 M₁=I，I 为单位矩阵）。
2. **矩阵修正（k = 2, 3, …）**：以最新位移与梯度差 v^k := x^k−x^{k−1}、w^k := ∇f(x^k)−∇f(x^{k−1})，由 M_{k−1} 经秩修正得 M_k（18.85）。
3. **方向与步长（k = 1, 2, …）**：沿方向 −M_k∇f(x^k) 作线搜索：取 α_k ≥ 0 使 f(x^k−αM_k∇f(x^k)) 达到极小（18.86，[[concepts/线搜索]]）；更新 x^{k+1} := x^k − α_k M_k ∇f(x^k)（18.84）。
4. **停止**：同通用停止规则 ∇f(x)=0（[[concepts/平稳点]]）。

注：k=1 时用 M₁ 直接进入步骤 3；18.85 的 v^k、w^k 自 k=2 起可用（源文档标注 k=2,3,…）。

## 为什么这样设计

- **逼近逆黑塞**：f 二次时，逆黑塞矩阵由 M_k 逐步近似（源断言），兼得牛顿法的曲率信息与梯度法的低成本：绕开 [[concepts/牛顿法（无约束优化）]] 缺点 e（求 H⁻¹ 计算量大）。
- **保持对称正定**：源断言 M_k 对称正定（由对称正定 M₁ 出发经修正保持）。
- **二次退化**：f 二次时 DFP 变成 [[concepts/共轭梯度法]]（初始 M₁=I），故继承 n 步终止性质。

## ⚠ 式 18.85 的两处分母（照印存疑）

照印的 18.85（首分母 v^{kT}v^k、末分母 w^{kT}M_k w^k）不满足割线方程 M_k w^k = v^k，且末分母 M_k 自指。标准 DFP 形式应为：首分母 v^{kT}w^k、末分母 w^{kT}M_{k−1}w^k。执行本流程时应采用标准形式，疑点追踪见 [[queries/式18-85首分母vkTvk疑为vkTwk且末分母下标Mk疑为Mk-1之辨]]，反例核验见 [[findings/式18-84至18-86DFP更新公式转录复算]]。
