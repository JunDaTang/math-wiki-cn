# 渐近展开的分部积分流程

## 目的（为什么）

对含大参数 x 的积分（如 f(x) = ∫₀^∞ e^{−xt}/(1+t) dt），普通幂级数方法失效；而「反复分部积分」每次产生一个 1/x 因子，可系统生成关于 1/x 的渐近展开，并附带**显式余项的界**，从而把「发散级数」变成可靠的计算工具（渐近意义下的近似）。这是手册 7.3.5.2 例 B 的方法，也是渐近分析的标准技术。

## 步骤（怎么做）

以 ∫₀^∞ e^{−xt}g(t) dt（g(t) = 1/(1+t)）为例：

1. **反复分部积分**：每次对 e^{−xt} 积分（得 −e^{−xt}/x）、对其余因子求导，得到
   f(x) = 1/x − 1!/x² + 2!/x³ − 3!/x⁴ ± ⋯ + (−1)^{n−1}(n−1)!/x^n + R_n(x)。
2. **写出显式余项**：R_n(x) = (−1)ⁿ n!/xⁿ ∫₀^∞ e^{−xt}/(1+t)^{n+1} dt。
3. **界定余项**：利用 (1+t)^{n+1} ⩾ 1 放缩：|R_n| ⩽ n!/xⁿ ∫₀^∞ e^{−xt}dt = n!/x^{n+1}，即 R_n = O(1/x^{n+1})（[[朗道符号]]），恰为渐近幂级数定义（式 7.99）所要求。
4. **截断规则**：对交错型渐近级数，相邻部分和给出真值的上下界（例：x = 10 时 0.09152 < f(10) < 0.09164）；实用上取到最小项附近即止——截断过头误差反而增大。
5. **（诊断）收敛性**：相邻项比 (ν+1)/x → ∞，级数对每个固定 x 发散；发散不妨碍其作为渐近近似。

## 应用记录

式 7.100 与 x = 10 数值验证见 [[式7-98-7-100渐近幂级数与x10数值验证]]（复算通过：S₄(10) = 0.09164，S₅(10) = 0.09152，f(10) = e¹⁰E₁(10) ≈ 0.091563 落于界内）。

## 局限

余项界含 n!/x^{n+1}，对固定 x 而 n 增大时发散——故只能「固定 n、x 大」地使用，不能取 n → ∞。
