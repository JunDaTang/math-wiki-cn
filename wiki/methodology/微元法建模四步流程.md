# 微元法建模四步流程

把一个实际的几何量或物理量化为定积分的标准操作流程，源自《数学手册（原书第10版）》8.2.2.1（式 8.58–8.59），并以棱锥体积算例完整示范。

## 为什么可行（原理）

所求量 $A$ 必须具有**可加性**：能分解为部分量之和 $A = a_1+\dots+a_n$。关键一步是用"可由已知公式积分"的等价量 $\tilde a_i$ 替代真实部分量 $a_i$：只要误差 $\alpha_i = a_i-\tilde a_i$ 是 $a_i$（与 $\tilde a_i$）的高阶无穷小，在求和取极限时误差合计消失，和式极限便收敛到 $A = \int_a^b f(x)\,\mathrm{d}x$。"以易代难"（以直代曲、以柱代截头体、以窄扇形代窄条）的合法性完全由高阶无穷小的消失保证——这是本流程区别于单纯"套公式"的核心。

## 四步操作

1. **分解**：把要求的量分割成一系列很小的量（无穷小量）$a_i$（式 8.58）。
2. **等价替代**：为每个 $a_i$ 找可积的近似量 $\tilde a_i$，并校核误差为高阶无穷小。
3. **变量化**：引入自变量 $x$，把 $\tilde a_i$ 写成 $f(x_i)\Delta x_i$（$\Delta x_i\geqslant 0$），识别被积函数 $f$ 与积分限 $a,b$。
4. **取极限求积**：$A = \lim\sum f(x_i)\Delta x_i = \int_a^b f(x)\,\mathrm{d}x$（式 8.59），再行计算。

## 示范：棱锥体积（图 8.11）

- 分解：$V = v_1+\dots+v_n$（一系列平截头体）。
- 替代：同高、底面积取上底面的棱柱 $\tilde v_i$（体积之差为高阶无穷小）。
- 变量化：由相似性 $S_i:S = h_i^2:H^2$ 得 $\tilde v_i = \frac{Sh_i^2}{H^2}\Delta h_i$。
- 求积：$V = \int_0^H\frac{Sh^2}{H^2}\mathrm{d}h = \frac{SH}{3}$。

## 适用范围与在方法论序列中的位置

适用于一切具可加性的几何量（面积、弧长、旋转面、体积）与物理量（路程、功、压力、转动惯量、一阶矩/重心）。8.1 系列方法论（如 [[methodology/基本积分化归流程]]、[[methodology/被积函数结构识别与积分法则选择流程]]）解决"把积分算出来"；本流程解决其上游问题"把实际问题写成积分"，两者衔接为"建模—求积"两段式。复算记录见 [[findings/式8-58至8-59微元法原则与棱锥体积复算]]。
