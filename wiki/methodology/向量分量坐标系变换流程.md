# 向量分量坐标系变换流程

**目的**：在笛卡儿、柱面、球面三种坐标系之间换算同一向量 $\vec{V}$ 的分量。依据《数学手册(原书第10版)》13.1.3.4 的表 13.1 与式 (13.18)–(13.21)（经复算公式全部正确，表内一处讹误见下）。

**为什么需要专门流程**：柱面与球面坐标系的坐标单位向量（$\vec{e}_\rho, \vec{e}_\varphi, \vec{e}_z$；$\vec{e}_r, \vec{e}_\vartheta, \vec{e}_\varphi$）逐点切于坐标线、随点改变方向（见 [[向量场]]），因此分量变换不仅是坐标变量的替换，还包含基向量之间的旋转投影——这正是变换公式中出现 $\sin\vartheta, \cos\vartheta$ 混合项的原因。

## 步骤

1. **定位点与角坐标**：先求出所论点的柱面坐标 $(\rho,\varphi,z)$ 或球面坐标 $(r,\vartheta,\varphi)$；角度 $\varphi, \vartheta$ 决定基向量方向，是全部投影系数的来源。
2. **选用公式**（或查表 13.1 对应行）：
   - 柱面 → 笛卡儿：式 (13.18)；
   - 笛卡儿 → 柱面：式 (13.19)；
   - 球面 → 笛卡儿：式 (13.20)；
   - 笛卡儿 → 球面：式 (13.21)；
   - 柱面 ↔ 球面（直换）：$V_r = V_\rho\sin\vartheta + V_z\cos\vartheta$，$V_\vartheta = V_\rho\cos\vartheta - V_z\sin\vartheta$，$V_\varphi = V_\varphi$；反向为 $V_\rho = V_r\sin\vartheta + V_\vartheta\cos\vartheta$，$V_z = V_r\cos\vartheta - V_\vartheta\sin\vartheta$。
3. **代入计算**。
4. **校核**：
   - 长度不变：变换为正交变换，应满足 $V_x^2+V_y^2+V_z^2 = V_\rho^2+V_\varphi^2+V_z^2 = V_r^2+V_\vartheta^2+V_\varphi^2$；
   - 特例检验：如 $\vartheta = \pi/2$（点在 $xy$ 平面上）时，球面系结果应退化为柱面系结果；
   - 交叉核验：表 13.1 与式 (13.18)–(13.21) 相互对照。注意表 13.1 的 $V_\vartheta$ 行**笛卡儿列**有一处讹误（$-V_z\sin\varphi$ 应为 $-V_z\sin\vartheta$，见 [[表13-1的Vϑ行sinφ疑为sinϑ]]），该行的柱面列与球面列仍正确。

## 底层投影关系（推导备忘）

柱面 ↔ 球面直换隐含的单位向量关系：

$$\vec{e}_r = \sin\vartheta\,\vec{e}_\rho + \cos\vartheta\,\vec{e}_z,\qquad \vec{e}_\vartheta = \cos\vartheta\,\vec{e}_\rho - \sin\vartheta\,\vec{e}_z,\qquad \vec{e}_\rho = \sin\vartheta\,\vec{e}_r + \cos\vartheta\,\vec{e}_\vartheta,$$

且 $\vec{e}_\varphi$ 在两系中相同。全部变换公式均可由 $\vec{e}_r, \vec{e}_\vartheta, \vec{e}_\varphi$ 与 $\vec{i}, \vec{j}, \vec{k}$ 的点积重建。

完整公式与勘误归档见 [[笛卡儿柱面与球面坐标系向量分量表示比较]]；逐式复算见 [[表13-1与式13-18至13-25坐标系变换转录复算]]。
