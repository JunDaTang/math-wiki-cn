# 最速下降法迭代流程

依据 18.2.5.1（式 18.75–18.77）整理的最速下降法执行流程。方法属 [[concepts/下降法]]：每步沿负梯度方向作精确线搜索。

## 步骤

1. 给定初始点 x¹ ∈ ℝⁿ。
2. 在当前点 x^k 计算梯度 g^k := ∇f(x^k)；若满足停止规则 ∇f(x)=0（实用中以 ‖∇f(x^k)‖ 足够小代替，见 [[concepts/平稳点]]），停止。
3. 取方向 d^k := −∇f(x^k)（18.75a）。
4. 确定步长 α_k ≥ 0：
   - 一般情形：解一维问题 f(x^k+αd^k)=min!, α≥0（18.76，[[concepts/线搜索]]），源文档称可用 18.2.4 的方法求解（未入库）；
   - 二次情形 f(x)=xᵀCx+pᵀx：直接用闭式 d^k=−(2Cx^k+p)，α_k=d^{kT}d^k/(2d^{kT}Cd^k)（18.77a–b）。
5. 更新 x^{k+1} := x^k + α_k d^k（18.75b / 18.77a），回到步骤 2。

## 为什么这样设计（依据与核验）

- **方向**：源断言「从现时点 x^k 出发，函数下降最快速的方向是负梯度」（未给证明；一阶展开下 f 沿 d 的变化率为 ∇fᵀd，取 d=−∇f 使其最负）。
- **步长**：取一维极小保证 f(x^{k+1})<f(x^k)（18.74，下降法条件）。
- **二次精确步长复算**（维基独立推导，与 18.77b 一致 ✓）：令 φ(α)=f(x^k+αd^k)，则 φ′(α)=∇f(x^k+αd^k)ᵀd^k；由 ∇f(x)=2Cx+p 与 d^k=−∇f(x^k) 得

  φ′(α) = d^{kT}(−d^k + 2αCd^k) = −d^{kT}d^k + 2α·d^{kT}Cd^k，

  令 φ′(α*)=0 解得 α* = d^{kT}d^k/(2d^{kT}Cd^k)。详见 [[findings/式18-75至18-77最速下降法与二次精确步长复算]]。
