# 级数通项系数交叉复算法

## 动机（为何）

数表类源（如 [[sources/10-数学手册原书第10版--10-215-重要级数展开--1gmcxgd]]）的核心价值在于公式系数与收敛域的正确性，而电子转写会在「数学内容」之外引入「转写层」讹误（字符吞失、符号错位、单元格截断）。逐行复算可以把两层分开：复算一致者可放心引用；不一致者定位为疑点，再进一步区分转写讹误与刊本原误。本方法是 [[methodology/单位定义量纲复算法]] 与 [[methodology/常数表定义式交叉复算法]] 在级数数表上的同族扩展。

## 步骤（如何）

1. **通项 → 系数**：由行内通项公式（广义二项式系数 $\binom{m}{n}$、$B_n/E_n$ 取值）复算前若干项系数，与表载数值逐项比对。必须先确认记法约定（如 21.5 的 $B_n$ 紧缩编号），否则会产生假阳性不一致。
2. **奇点 → 半径**：由函数在复平面上距原点最近的奇点（零点、极点、支点）确定收敛半径，验证收敛域栏的数量部分。
3. **端点单独判定**：半径端点处逐点判别（绝对收敛 / 交错条件收敛 / 发散），据此判断表载域是否为保守表述——保守表述按原书照录并加注，不误标为讹误。
4. **行间恒等式交叉验证**：利用 $\ln\lvert\tan x\rvert=\ln\lvert\sin x\rvert-\ln\cos x$、$x\to\mathrm{i}x$ 代换、$\arcsin\leftrightarrow\Arsinh$ 等恒等关系使两行系数互相印证；单行内部的印刷错误无法通过这种交叉。
5. **讹误定界**：不一致处只对所在行下结论，不外推；区分「数学不自洽」（系数与通项矛盾）与「版式伪影」（单元格截断、标签并入等）。

## 应用与局限

- 应用：21.5 节产出 [[findings/21-5全表级数系数与通项复算]]（全表一致）、[[findings/Arcosh负六次方项系数不自洽复算]] 与 [[findings/1±x二分之五次方行尾符号不符复算]]（两处不自洽）、[[findings/21-5收敛域四格吞字分布与复原]]（截断复原）。
- 局限：复算只能发现「不自洽」，无法判定错误发生在转写层还是刊本层；复原值给出的是数学内容，具体措辞仍需刊本核验（[[queries/收敛域四格吞字复原待刊本确认之辨]]）。
