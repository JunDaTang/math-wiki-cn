# 泊松过程建模假设核对流程

**目的**：判断一个「信号/事件计数」场景能否用 [[concepts/泊松过程]] 建模，并解释/估计参数 λ。依据母书 16.2.6.2 的假设 a)–e) 与式 (16.116)–(16.117)。

**为什么这样核对（原理）**：(16.116) 的泊松分布并非假设而是**结论**——只要计数对象满足平稳增量、独立增量与小间隔稀有性三条结构性假设，分布 $P(X_t=x)=\frac{(\lambda t)^x}{x!}e^{-\lambda t}$ 就被确定（期望 = 方差 = $\lambda t$）。因此建模工作的实质是核对假设，而非直接选择分布。

## 核对清单

1. **明确计数对象（a, b)）**：$X_t$ = 区间 $[0,t)$ 内的信号数；$p_x(t)=P(X_t=x)$。
2. **平稳增量（c)）**：等长区间内计数同分布，只依赖区间长度、不依赖位置。核对场景是否存在日/季节节律或趋势（若有则假设至多「大概成立」）。
3. **独立增量（d)）**：相邻（不相交）区间内计数独立（[[concepts/随机变量的独立性]]）。核对是否存在自相关/触发效应（一个事件诱发后续事件则不独立）。
4. **小间隔稀有性（e)）**：短区间 $\Delta t$ 内至少一个信号的概率 $\approx\lambda\Delta t$（$\lambda>0$），即无穷小区间内同时多个事件可忽略。
5. **场景附加条件**：如放射性衰变——观察间隔须相对辐射物质的半周期较小。

## 通过后的使用

- **分布**：$X_t\sim\mathrm{Poisson}(\lambda t)$ (16.116)，[[concepts/期望]] = [[concepts/方差与标准差]] = $\lambda t$。
- **参数解释/估计**：$\lambda$ = 单位时间平均信号数；$1/\lambda$ = 两信号间平均间隔；可用单位时间计数的观察均值估计 $\lambda$。
- **转移语言**：$p_{i,i+1}\approx\lambda\Delta t$ (16.117)，λ 称转移率——由此接入 [[concepts/生灭过程]]（率依赖状态、允许死亡）与 [[concepts/排队论]]。
- **化归**：$t=1$ 时化为 [[concepts/泊松分布]]（母书 16.2.3.3）。

## 典型适用场景（母书所列）

放射性衰变（计数器记录并标注时间轴）；电话交换呼叫次数；可靠性检验中的可修复系统故障数；排队系统的到达人数。

## 失配时的出口

- 计数率依赖状态或允许减少 ⇒ 生灭过程 (16.118)。
- 到达间隔/服务时间须另选分布 ⇒ 排队论推广模型（多柜台、不同分布；母书引 [16.14], [16.27]）。
