# 沃尔泰拉方程微商化微分方程法

## 目的（why）

当核关于 x 是多项式（或经少数次求导后积分项可消去）时，反复对积分方程求微商可把它降为线性常微分方程的初值问题，从而用 ODE 方法求解。该法同时适用于第一类 (11.60a) 与第二类 (11.60b) 方程：求导一次分别得

$$f'(x) = K(x,x)\varphi(x) + \int_a^x K_x(x,y)\varphi(y)\,\mathrm{d}y, \tag{11.60c}$$

$$\varphi'(x) = f'(x) + K(x,x)\varphi(x) + \int_a^x K_x(x,y)\varphi(y)\,\mathrm{d}y. \tag{11.60d}$$

## 化归规则

设核关于 x 的最高次数为 n。对积分方程求 **n+1 次**导数后：

- 第一类方程 → **n 阶**线性微分方程（转写此处缺字，据算例结构应为 n，见 [[queries/第一类多项式核化归阶数缺字是否为n]]）；
- 第二类方程 → **n+1 阶**线性微分方程。

需假设 φ(x)、f(x) 具有所需阶数的可微性。**初值条件**由原方程及其各阶导数式在 x=a 处的取值给出（x=a 处积分区间退化为一点，积分项消失）。

## 算例一（三角核，第一类）

$$\int_0^x \cos(x-2y)\varphi(y)\,\mathrm{d}y = \tfrac{1}{2}x\sin x,\qquad x\in[0,\pi/2).$$

两次求导得 (IIa)、(IIb)；关键技巧是 (IIb) 中的积分 $\int_0^x\cos(x-2y)\varphi(y)\,\mathrm{d}y$ 与原方程左端**相同**，用 $\tfrac{1}{2}x\sin x$ 替换后积分项消去：

$$\varphi'(x)\cos x = \cos x \;\Rightarrow\; \varphi'(x)=1 \;\Rightarrow\; \varphi(x)=x+C.$$

x=0 代入 (IIa) 得 φ(0)=0 ⇒ C=0，故 **φ(x)=x**。

## 算例二（多项式核，第一类）

$$\int_0^x [2(x-y)^2+1]\varphi(y)\,\mathrm{d}y = x^3.$$

三次微商依次得 (II*a) $\varphi+4\int_0^x(x-y)\varphi\,\mathrm{d}y=3x^2$、(II*b) $\varphi'+4\int_0^x\varphi\,\mathrm{d}y=6x$、(II*c) $\varphi''+4\varphi=6$。通解 $\varphi=A\sin 2x+B\cos 2x+\tfrac{3}{2}$；x=0 代入 (II*a)(II*b) 得 φ(0)=φ′(0)=0 ⇒ A=0、B=−1.5，故

$$\varphi(x)=\tfrac{3}{2}(1-\cos 2x)=3\sin^2 x.$$

核关于 x 为 2 次，n+1=3 次求导后得 2 阶 ODE——此算例即“第一类 → n 阶”规则的直接佐证。

## 数值验证与关联

两算例的独立数值验证（x=π/4 处 ≈0.27774 对 ≈0.27768；x=0.5 处 ≈0.12588 对 0.125）见 [[findings/式11-60a至11-60d微商法与两算例复算]]。数值解算例 $\varphi=2+\int_0^x(x-y)\varphi\,\mathrm{d}y$ 的精确解 **2cosh x** 正是由本法推出（φ″=φ、φ(0)=2、φ′(0)=0），为 [[methodology/沃尔泰拉积分方程数值解法]] 提供了对照基准。与只求导一次的 [[methodology/第一类沃尔泰拉积分方程化第二类流程]] 相比，本法适用于 K(x,x)=0（如核 (x−y)）的情形。
