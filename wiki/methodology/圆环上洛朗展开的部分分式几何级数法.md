# 圆环上洛朗展开的部分分式几何级数法

在指定圆环上求函数洛朗展开式的手算流程，范式为《数学手册(原书第10版)》14.3.4 的算例 $f(z) = \frac{1}{(z-1)(z-2)}$（圆环 $1 < |z| < 2$）。

## 为什么用这个方法

洛朗系数的定义式 (14.50b) 是围道积分，直接计算繁琐；而对有理函数类，部分分式分解后每一项都可套用几何级数 $\frac{1}{1-w} = \sum_{n\ge0} w^n$（$|w| < 1$），把积分计算替换为代数操作，且在展开的同时显式给出每部分级数的收敛区域。

## 流程

1. **确认圆环与圆心**：确认函数在圆环 $r_1 < |z - z_0| < r_2$ 内解析，圆环边界由奇点位置决定（本例奇点 $z = 1, 2$，圆心 $z_0 = 0$）。
2. **部分分式分解**：$f(z) = \frac{1}{z-2} - \frac{1}{z-1}$。
3. **逐项匹配几何级数**：对每一项，按圆环内的不等式改写为 $\frac{1}{1-w}$ 形状并验证 $|w| < 1$：
   - 由 $|1/z| < 1$（即 $|z| > 1$）：$\frac{1}{z-1} = \frac{1}{z}\cdot\frac{1}{1-1/z} = \sum_{n\ge1} z^{-n}$，产生负幂（主部）；
   - 由 $|z/2| < 1$（即 $|z| < 2$）：$\frac{1}{z-2} = -\frac{1}{2}\cdot\frac{1}{1-z/2} = -\frac{1}{2}\sum_{n\ge0}\left(\frac{z}{2}\right)^n$，产生非负幂（正则部分）。
4. **合并并读出系数**：$f(z) = -\sum_{n\ge1} z^{-n} - \frac{1}{2}\sum_{n\ge0}\left(\frac{z}{2}\right)^n$，即 $a_n = -1$（$n \le -1$）、$a_n = -1/2^{n+1}$（$n \ge 0$）。
5. **核验收敛域**：两个几何级数都在整个圆环 $1 < |z| < 2$ 中绝对收敛，与“洛朗级数收敛域为含于定义域的最大圆环”一致。

## 适用边界

- 依赖被展函数可分解为几何级数可处理的项（有理函数、$\frac{c}{(z-z_0)^k}$ 型因子）；一般函数仍需 (14.50b) 或泰勒展开的复合；
- 每个圆环（由不同奇点组合围出）须分别展开，系数互不相同；
- 负幂项的收敛条件（$|z| > r_1$）与非负幂项（$|z| < r_2$）方向相反，这是圆环结构的手算体现。
