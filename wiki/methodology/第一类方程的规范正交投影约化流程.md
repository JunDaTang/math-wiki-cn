# 第一类方程的规范正交投影约化流程

把一般核的第一类弗雷德霍姆积分方程（式 11.41）投影为无穷线性方程组，并借此刻画齐次与伴随齐次解集。依据数学手册(原书第10版) 11.3.3–11.3.4。

## 流程步骤（非齐次方程）

1. **选取完全规范正交系**：[a,b] 上取 (β_n(y)) 承载解，[c,d] 上取 (α_n(x)) 承载右端。
2. **右端展开**：f = Σ f_iα_i，f_i = ∫_c^d α_i f dx（11.46a）。
3. **投影**：以 α_i 乘方程并在 [c,d] 上积分（交换积分次序）得 f_i = ∫_a^b K_i(y)φ(y)dy，其中 K_i(y) = ∫_c^d K(x,y)α_i(x)dx（11.46b,c）。
4. **双展开**：K_i = Σ_j K_ijβ_j、φ = Σ_k c_kβ_k（11.46d），由规范正交性得无穷方程组 f_i = Σ_j K_ij c_j（11.46f），系数矩阵即 [[concepts/核矩阵]]（11.46g）。
5. **求解无穷方程组**：手册指出这「通常并不比原始问题的解容易」，实践中配合 [[methodology/核矩阵双对角化构造流程]]（11.3.5）或 [[methodology/第一类方程的迭代法]]（11.3.6）获得特殊结构。

## 齐次与伴随齐次解集的刻画（11.3.4）

- **齐次方程**：每个解 φ^h 与每个 K_i(y) 正交（11.50c）。把 (K_n) 经 [[concepts/施密特正交化]] 化为 (K_n^*) 后条件不变（11.50d），再完备化：若 (K_n^*) 已完全 ⟹ 仅平凡解 φ^h = 0；否则解集为与完备化后全系正交的函数全体。
- **伴随齐次方程**（11.50e）：∫_c^d K(x,y)ψ(x)dx = 0，交换 x、y 角色后同法处理（参见 [[concepts/转置积分方程与伴随积分方程]]）。

## 算例

奇异核 (1/π)sin y/(cos y−cos x)（柯西主值）：核矩阵对角化 K_ij = −δ_ij、K₀j = 0 ⟹ 可解条件 f₀ = 0、c_j = −f_j 及显式反演公式（[[findings/式11-47与sin权奇异核算例对角化与反演公式复算]]，已独立验证）；齐次/伴随齐次解集刻画见 [[findings/式11-48a至11-50e齐次与伴随齐次解法及算例转录复算]]（含归属疑点 [[queries/11-3-4例题常数解属于原齐次还是伴随齐次方程]]）。

## 设计原理（why）

以完全规范正交系为「坐标基」，把算子方程化为坐标（傅里叶系数）方程；所得可解性条件（如 f₀ = 0）即 f 与伴随齐次解正交——[[concepts/积分方程的正交可解性条件]] 在第一类情形的直接体现。
