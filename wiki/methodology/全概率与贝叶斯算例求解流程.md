# 全概率与贝叶斯算例求解流程

## 目的与理由

当事件 $A$ 的概率难以直接计算，但样本空间可按「原因」$B_i$ 划分且各划分下 $A$ 的条件概率已知时，用全概率定理（16.42）聚合；当观察到 $A$ 已发生而需反推原因时，用贝叶斯定理（16.43）反演。手册三台机器次品率算例给出完整范式，本流程将其步骤化。

## 流程（以三台机器次品问题为原型）

1. **定义原因事件**：$A_i$ ＝ 产品由第 $i$ 台机器生产（$i = 1, 2, 3$）。
2. **验证完备事件组**（式 16.28–16.29）：$A_iA_j = O$ 且 $A_1 + A_2 + A_3 = I$；给出先验 $P(A_1) = 0.2$、$P(A_2) = 0.3$、$P(A_3) = 0.5$。
3. **定义结果事件**：$A$ ＝ 挑出的产品是次品；给出似然 $P(A|A_1) = 0.05$、$P(A|A_2) = 0.04$、$P(A|A_3) = 0.02$。
4. **全概率（16.42）**：

$$P(A) = \sum_i P(A|A_i)P(A_i) = 0.2\times0.05 + 0.3\times0.04 + 0.5\times0.02 = 0.032$$

5. **贝叶斯（16.43）**：对目标原因 $A_k$ 计算

$$P(A_k|A) = \frac{P(A|A_k)P(A_k)}{P(A)}$$

如 $P(A_1|A) = 0.2\times0.05/0.032 = 0.31$（精确 0.3125）。

6. **自洽检查**：诸后验之和应为 1（完备事件组的归一化）：$0.3125 + 0.375 + 0.3125 = 1$ ✓。

## 注意事项

- 前提检查：$P(B_i) > 0$（两定理共用），$P(A) > 0$（贝叶斯专用）；
- 先验与似然勿混淆：$P(A|B_i)$ 是「原因下出结果」，不是 $P(B_i|A)$；
- 手册记号 $P_A(B)$ 与 $P(B|A)$ 同义，读题时注意区分。
