# 插图资产哈希入库法

## 方法定位

本页统一记录《数学手册(原书第10版)》语料库处理插图资产的入库约定，避免在每个资产源页重复说明。约定要点为“**每资产一源页**”：语料库以 64 位十六进制哈希（SHA-256 长度）命名图像文件，每张图像生成一个独立的嵌入存根源页与专属 media 目录（内含 `001-<哈希>.jpg`）。先行两例为 [[10-数学手册原书第10版--6-images--64-0a74ffc61fad45e7409e3dd26e6364d6caaab09381343586f4dbdfe86982bd5b--8r4woa]] 与 [[10-数学手册原书第10版--6-images--64-0abd84587c0492e7b9edaa47a66c843a3cde250659450a2ac5ae7fb491c810de--exsc01]]。

## 理据（why）

- 插图资产与正文小节是两个独立的齐备性维度；分离入库使 [[第2章未入库回指缺口]] 一类回指缺口可逐项收敛、逐项核销。
- 哈希文件名不含语义信息，独立源页为每张图提供可回指、可记录锚位与规格（格式、体积、图数）的落点，母章节与母作品经由 `related` 承接。
- 结构层面的异常（如同一锚位出现多个哈希，见 [[images-64锚位双哈希资产之辨]]）只有在这种逐资产入库模式下才可被发现与追踪。

## 流程（how）

1. **哈希文件名**：图像存于书级 `images/` 目录，文件名为 `<64位十六进制哈希>.jpg`。
2. **嵌入存根**：每资产生成一个源文档，正文仅含图像引用，无可转写文本。
3. **专属 media 目录**：每资产对应 `media/10-数学手册原书第10版--<部号>-images--<锚位>-<哈希>--<后缀>/001-<哈希>.jpg`。
4. **源页命名**：`10-数学手册原书第10版--<部号>-images--<锚位>-<完整哈希>--<后缀>`；部号沿用正文源页的部号（如第 6 部对应第2章 函数）；标题格式为“数学手册(原书第10版) 第N章 images-<锚位> 插图资产（<哈希前8位>）”。
5. **回指**：源页 `related` 链接父章节源页、姊妹资产、相关 query 与母作品实体页。

## 适用边界与告诫

- 存根无文本，**不得**从存根直接产出 OCR/转写讹误类 finding。
- 图像内容级主张（具体函数、所属小节、标注讹误）一律以**目验**为前提，不得从姊妹资产或章节关键词类推。
- 锚位号语义（页位/图组/序号）尚未定谳，涉锚位唯一性或计数的论断须先核对 [[images-64锚位双哈希资产之辨]]。
- 已知张力：File 字段显示图像位于书根 `images/` 目录（全局作用域），而 slug 前缀 `<部号>-images` 暗示分部作用域，两者待语料库层面核查。
