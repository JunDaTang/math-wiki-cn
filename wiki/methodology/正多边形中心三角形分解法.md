# 正多边形中心三角形分解法

正多边形中心三角形分解法是把正凸 n 边形分解为 n 个环绕公共中心 M 的等腰全等三角形，从而将多边形问题化归为单个三角形（进而为直角三角形）求解的方法。《数学手册(原书第10版)》3.1.5.2 明确陈述「分解一个正凸 n 边形将得到 n 个环绕中心等腰全等三角形」，这是该节全部公式的推导根基。

## 为什么有效（原理）

- 每个等腰三角形的顶角为中心角 φₙ = 360°/n、底为边 aₙ、腰为外接圆半径 R、底边上的高为内切圆半径 r。
- 顶点—中心—边中点构成直角三角形，立即给出勾股关系 R² = r² + aₙ²/4 与全部三角函数关系（式 3.51–3.53）。
- n 个三角形面积相加即面积公式（式 3.56 的 (1/2)·n·aₙ·r 形式）；n 个顶角相加即 360°（式 3.47）。

## 推广形式

- **一般多边形**：无公共中心可用时，改为三角剖分得 n − 2 个三角形，推出内角和 180°·(n − 2)（式 3.45），见 [[findings/一般多边形角和对角线公式]]。
- **迭代程序**：边数加倍（n → 2n）的递推（式 3.55、3.57）可视为本方法的迭代使用——每次加倍后仍用同一中心直角三角形关系重算边长与面积，见 [[findings/正多边形倍边与倍面积递推]]。
