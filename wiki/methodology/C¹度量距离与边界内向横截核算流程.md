# C¹ 度量距离与边界内向横截核算流程

**目的与理由**：[[concepts/结构稳定性|结构稳定性]]的严格定义依赖 [[concepts/C¹度量|C¹ 度量]] ρ(f,g) = sup‖f−g‖ + sup‖Df−Dg‖ 与边界横截内向条件（X₊¹(U)）。要论证某系统属于定义所述的类、或计算两系统的距离，需要统一核算步骤。本流程来自 17.1.4.1 并经式 (17.26) 算例验证。

## 流程

1. **写出差向量场**：d(x) = f(x) − g(x)，在 U 上求 sup‖d(x)‖（注意 sup 可能在边界 ∂U 上取到，须代入边界约束）。
2. **写出雅可比之差**：Dd(x) = Df(x) − Dg(x)，求算子范数的 sup（欧几里得算子范数即最大奇异值；对纯量矩阵 αI 即 |α|）。
3. **求和**：ρ(f,g) = sup‖d‖ + sup‖Dd‖。
4. **边界横截**：在 ∂U = {h=0} 上验证 grad h(x)ᵀf(x) ≠ 0（f 与边界处处横截）。
5. **内向性**：验证 ∂U 上轨线不外逸——常用径向分量判据：边界上径向速度 < 0（即 ṙ|_{∂U} < 0，等价于 φᵗ(x) ∈ U, t>0）。

## 实例（式 17.26）

- d = g(·,α) − g(·,0) = (αx, αy)：sup_{x²+y²<2} ‖d‖ = |α|·√2（在 r=√2 处取到）；Dd = αI：‖αI‖ = |α|；故 ρ = |α|(√2+1)。
- 边界 r=√2 上 ṙ = r(α−r²) = √2(α−2) < 0（|α|<1）⟹ 内向 ⟹ g(·,α) ∈ X₊¹(U)。
