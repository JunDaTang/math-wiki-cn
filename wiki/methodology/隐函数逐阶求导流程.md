# 隐函数逐阶求导流程

## 方法概述与原理（为什么有效）

对约束方程（组）定义的隐函数逐阶求导的方法是：对每个约束方程按链式法则求导，得到关于未知函数当前阶导数的线性方程组，解出该阶导数；再对上一阶方程组求导，得到关于更高一阶导数的线性方程组，如此逐阶升阶。其原理在于：约束方程沿隐函数恒成立，故各阶全导数均为零；且每次求导时**最高阶导数只以线性形式出现**——单方程情形其系数为 F_y 或 F_u，方程组情形其系数矩阵为约束组对未知函数的偏导数矩阵（结构上即雅可比矩阵，原书未使用此名称）。因此每一阶都归结为解一个线性方程组，方法可以机械重复。《数学手册(原书第10版)》6.2.3.2 的条目 (1)–(5) 即此流程在各设定下的展开。

## 流程步骤

1. **明确设定**：写出约束方程（组）与未知隐函数及其自变量；确定欲求的导数阶数与自变量。
2. **选择链式法则形式**：自变量只有一个（各函数为一元）用全导数形式（式 6.51b）；有多个自变量用偏导数形式（式 6.52b），并对每个自变量各做一遍。
3. **一阶求导**：对每个约束方程应用链式法则，得关于一阶导数的线性方程组（式 6.53b、6.55b、6.56b、6.57b–c）。
4. **解线性方程组**：单方程直接移项（y′ = −F_x/F_y，式 6.53c；∂u/∂x_i = −F_{x_i}/F_u，式 6.54b）；2×2 情形可按克莱姆法则得显式解（式 6.55c；克莱姆法则为复算工具，原书未点名）；n×n 情形原书只说"可得要求的导数"。
5. **升阶**：对上一阶方程组两端再求导（沿曲线的全导算子 D = ∂ₓ + y′∂_y 或其多元对应物），新出现的更高阶导数仍线性出现，解新的线性方程组（式 6.53d → 6.53e → 6.53f 即此步骤的连续执行）。
6. **回代化简（可选）**：把低阶导数的显式表达式代入，消去低阶导数得纯偏导数表示，如将 y′ = −F_x/F_y 代入 6.53d 得 6.53e。

## 适用边界与注意事项

- 需要相应偏导数存在，且解方程组时分母（F_y、F_u 或行列式）非零。原书仅在 6.53c 标明 (F_y ≠ 0)，其余条目未标，见 [[queries/式6-54b是否应补Fu不等于0条件]]。
- 显式公式严格属于其所设情形：6.53e 属于单方程一元隐函数；6.55c 属于两方程两一元函数；不得跨情形移用（见 [[comparisons/单方程与方程组隐函数求导比较]]、[[comparisons/一元与多元隐函数求导比较]]）。
- 升阶时系数呈二项式模式（6.53d 的 (1,2,1)、6.53f 的 (1,3,3,1)），与 [[concepts/莱布尼茨公式]] 的系数同源——结构观察，可用于快速写出高阶方程。
