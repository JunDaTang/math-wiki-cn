# 多项式根定位流程

依据《数学手册（原书第10版）》19.1.2.2“根的位置”整理。目的：在数值求根（19.1.1 各迭代法）之前，先对根的个数与位置建立初始估计。

## 流程

1. **正/负根个数初判（笛卡儿符号法则）**：数系数序列 $(a_n, \dots, a_0)$ 的符号变化数得正根个数上界，数 $(a_0, -a_1, a_2, \dots, (-1)^n a_n)$ 得负根个数上界，实际个数为其少一偶数（式 19.19a,b；见 [[concepts/笛卡儿符号法则]]）。
2. **区间内精确计数（斯图姆序列）**：需给定区间 $(a,b)$ 内实根个数时用斯图姆序列（源文回指第 57 页 1.6.3.2，未入库，见 [[concepts/斯图姆序列]]）。
3. **图象扫描定位**：在均匀节点 $x_v = x_0 + vh$（$h$ 常数，$v = 0, 1, 2, \dots$）上以霍纳格式计算 $y_v = p_n(x_v)$，得函数图形和根位置的好的猜测；若 $p_n(c)$ 与 $p_n(d)$ 有不同的符号，则 $c$ 与 $d$ 之间至少存在一个实根（源文“在 $c$ 之间”脱“与 $d$”，见 [[queries/19-1全节系统性转写讹误清单]]）。
4. **根模上界（复根）**：解 $f^*(r) = \sum |a_k| r^k = |a_n| r^n$（式 19.20）的正根上界 $r_0$（系统试错），得全部根 $|x_k^*| \le r_0$（式 19.21；见 [[concepts/多项式根模上界]]）。
5. **负实部根计数（外延）**：确定带负实部的复根个数可用电子技术中的根轨迹理论检验稳定性（源文仅指称，见 [19.14][19.40]）。

## 设计理由（why）

迭代法只保证局部收敛，初值质量决定成败：个数判断（步骤 1–2）防止漏根，扫描异号（步骤 3）提供保根区间并给出初值，根模界（步骤 4）圈定复平面搜索范围。整个流程与 19.1.1 各求根迭代法构成“先定位、后逼近”的两阶段结构。

## 基准算例

- 笛卡儿（$p_5(x) = x^5 - 6x^4 + 10x^3 + 13x^2 - 15x - 16$）：重构为 3 或 1 个正根、2 或 0 个负根（源文数字脱落，见 [[queries/笛卡儿算例正负根个数数字脱落之辨]]）。
- 根模界（$p_4(x) = x^4 + 4.4x^3 - 20.01x^2 - 50.12x + 29.45$）：r = 6, 7, 8 试算 ⇒ $|x_k^*| < 8$，且源文断言 $-7 < x_1^* < -6$（复算通过）。

见 [[findings/式19-19至19-21笛卡儿符号法则与根模上界转录复算]]。
