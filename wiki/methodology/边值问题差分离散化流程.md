# 边值问题差分离散化流程

**目的与原理**：将连续边值问题 (19.118) 化为有限维代数方程组；以中心差分 (19.120a,b) 代替一、二阶导数，逼近误差均为 O(h²)。

**步骤**：

1. 等距剖分 [a,b]：x_ν = x₀ + νh（ν = 0,…,n；x₀ = a, x_n = b）。
2. 在内部节点 ν = 1,…,n−1 上，以 (19.120a) y′(x_ν) ≈ (y_{ν+1} − y_{ν−1})/(2h) 与 (19.120b) y″(x_ν) ≈ (y_{ν+1} − 2y_ν + y_{ν−1})/h² 代替导数，代入 (19.119)。
3. 代入边界条件 y₀ = α、y_n = β；边界条件包含导数时也须由有限差分代替。
4. 求解所得 n−1 元线性方程组，得节点近似值 y_ν ≈ y(x_ν)。
5. 特征值问题（如 y″ + λ²y = 0 型）：齐次差分方程组的系数行列式为零给出特征值条件，化为矩阵特征值问题（参见 4.6，未入库）。
6. 精度改进：减小 h／导数的高阶逼近／应用多步法（19.4.1.3）；非线性边值问题 ⟹ 非线性方程组，用 19.2.2（未入库）方法求解。

**警示**（源自算例复算）：离散特征值中仅最小者接近真值（9.37 对 π² ≈ 9.87），高阶特征值严重失真。见 [[concepts/差分法（边值问题）]]、[[findings/式19-118至19-120差分法与特征值算例复算]]。
