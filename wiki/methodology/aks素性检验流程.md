# AKS 素性检验流程

> ⚠ 转写受损警告：本流程依据的源文转写严重受损（r/n 条件疑颠倒、作者名讹误、若干字符脱落）。在对照 Agrawal–Kayal–Saxena 2002 原文核实前，本页应视为未定稿版本，见 [[queries/aks条件r的i次方模n是否应为n的i次方模r]]。

## 目的与原理（为什么有效）

确定性地判定自然数 n > 1 的素性，运行时间为多项式（源文以 m = ⌊(log₂n)^5⌋ 为规模尺度）。原理：若 n 满足关于素数 r 的一组条件（不被小素数整除、阶条件、批量多项式同余 (x+a)^n ≡ x^n + a (mod x^r−1, n)），则 n 是素数幂；再排除真幂即得素数。

## 步骤（按源文转写）

1. 设 m := ⌊(log₂n)^5⌋。
2. 若 n < 5,690,034，与已知素数表比较即可检验（表驱动路线）。
3. 对 n > 5,690,034 有 n > m（已复算：5,690,034 是 x = (log₂x)^5 的不动点，(log₂ 5690034) ≈ 22.442，其 5 次幂 ≈ 5.69×10^6 ✓）。
4. 核验 n 是否能被区间 [3, m] 中的自然数整除；若是，则 n 不是素数。
5. 取素数 r < n，使得 r^i ≢ 1 (mod n)（i = 1, 2, …, ⌊(log₂n)²⌋）；可以证明这样的素数 r 存在。（⚠ 此条件疑应为 n^i ≢ 1 (mod r)。）
6. 核验当 a = 1, 2, …, ⌊√r·log₂n⌋ 时，同余式 (x+a)^n ≡ x^n + a (mod x^r−1, n) 是否成立：
   - 不成立 ⇒ n 不是素数；
   - 成立 ⇒ n 是一个素数幂。
7. 检验是否存在自然数 k > 1 使 n = q^k；若不存在，则 n 是素数。

## 结果语义

与随机性算法不同，本检验结果可信，甚至没有可忽略的小错误概率。但源文评注：在密码学中拉宾-米勒检验（[[methodology/拉宾-米勒素性检验流程]]）更合适。见 [[findings/aks命题与检验流程]]、[[concepts/aks素数检验]]。
