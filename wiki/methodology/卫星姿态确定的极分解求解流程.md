# 卫星姿态确定的极分解求解流程

## 目的与理由（为什么这样做）

卫星姿态确定的核心困难：待求旋转受**正交性约束**（h ∈ ℍ₁ 或 R ∈ SO(3)），不能对残差平方和做无约束最小二乘。本流程（式 4.153–4.165）的三步设计分别化解三个障碍：

1. **李群切向导数**（式 4.155，∂_v h = vh）：把 ℍ₁ 上的极小化换成切空间上的变分，避免把旋转参数化为坐标（其病态可参照 [[concepts/常平架锁定]] 的讨论背景）。
2. **叉乘斜对称矩阵 K(a⃗)**（式 4.159–4.160）：把叉乘型临界点条件 Σᵢ Ra⃗ᵢ × b⃗ᵢ = 0 改写为矩阵方程，使解可用线性代数闭式表达；K(a⃗) 即 [[findings/轴向量与斜对称秩2张量的对应]] 的矩阵形式。
3. **极分解 P = R_pᵀS**（式 4.162）：把非线性方程 RP = PᵀRᵀ 的求解化归为一次矩阵分解与特征值判别。

## 流程

**输入**：n 对方向测量 (a⃗ᵢ, b⃗ᵢ)，i = 1…n（地球系与星载系中的单位向量）。

1. **构造姿态矩阵（cross-covariance）**：P = Σᵢ a⃗ᵢb⃗ᵢᵀ（并向量之和，见 [[concepts/并积]]）。
2. **极分解**：P = R_pᵀS，其中 S 对称、R_p 旋转矩阵。
3. **候选解**：R = R_p；以及 R = R_jR_p（j = 1,2,3），R_j 为绕 S 的第 j 个特征向量旋转 π 的矩阵（满足 R_jSR_j = S）。
4. **按 det P 选取极小解**（见 [[concepts/行列式]]）：
   - det P > 0：R = R_p；
   - det P < 0：R = R_{j₀}R_p，j₀ 对应 S 的绝对值最小特征值的特征向量；
   - det P = 0：书中未讨论（退化情形，实践需另行处理）。
5. **回代四元数**：由 R 反解单位四元数 h（经 4.4.2 的 ℍ₁ → SO(3) 对应）。

## 适用条件与限制

- 恒星须视为无穷远（方向在两坐标系中物理相同），测量误差进入最小二乘目标。
- 本书以 n 颗恒星的一般情形推导，未讨论最少恒星数，未给数值例。
- 该解法经分析者识别为正交 Procrustes / Wahba 问题的极分解（SVD 型）解法（书未命名）；其他外部解法（如特征值/迭代法）不在本书范围。
