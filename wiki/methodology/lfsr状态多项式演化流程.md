# LFSR 状态多项式演化流程

由数学手册 5.3.7.4.2 的状态转移公式提炼的流程：线性反馈移位寄存器（LFSR）的一步演化等价于「状态多项式乘 x 后模反馈多项式化简」。

## 流程

1. **输入**：反馈多项式 $f(x) = f_0 + f_1 x + \cdots + f_{r-1} x^{r-1} + x^r$，当前状态多项式 $s(x) = s_0 + s_1 x + \cdots + s_{r-1} x^{r-1}$（寄存器内容即其系数向量 $s_0 s_1 \cdots s_{r-1}$）。
2. **一步演化**：

   $$s_{\text{next}}(x) = s(x) \cdot x \pmod{f(x)},$$

   源文等价形式 $s(x) \cdot x - s_{r-1} \cdot f(x)$：乘 x 对应移位，减去 $s_{r-1} f(x)$ 同时消去溢出的 $x^r$ 项并实现反馈。
3. **迭代**：从 $s(x) = 1$ 出发，i 步后状态多项式为 $x^i \pmod{f(x)}$。
4. **周期判定**：序列达到极大周期 $2^r - 1$（遍历全部非零状态后回到初态）⟺ f 是 r 次本原多项式（[[concepts/本原多项式]]）。

## 为什么这样做

模 $f(x)$ 化简正是 GF($2^r$) 中的乘法（当 f 在 $\mathbb{Z}_2[x]$ 中不可约时），因此 LFSR 的状态演化就是乘法群中「反复乘 x」的轨迹；f 本原 ⟺ x 是乘法群生成元 ⟺ 轨迹遍历全部 $2^r - 1$ 个非零状态。这把移位寄存器与有限域对数表（[[findings/gf23对数表与分式算例]]）直接联系起来。
