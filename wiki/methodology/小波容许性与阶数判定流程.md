# 小波容许性与阶数判定流程

**目的（why）**：判定一个候选函数 ψ 能否作为 [[concepts/小波|小波]]、其阶数为何。阶数 n 决定 ψ 与多项式的正交范围（次数 ⩽ n−1），是刻画小波对低阶趋势不敏感程度的可复算指标。

**步骤（how）**：

1. **平方可积检验**：验证 ψ 二次可积（L²，通译平方可积）。
2. **容许性检验**：按 (15.143a) 计算 Ψ(ω)，检验积分 (15.147) 为正的有限值。注意：源式为 |Ψ| 一次幂，标准条件为平方，见 [[queries/式15-147容许条件Ψ模一次幂疑为平方]]。
3. **均值检验**：验证 $\int \psi(t)\,\mathrm{d}t = 0$（15.148）。
4. **矩序列计算**：计算 $\mu_k = \int t^k \psi(t)\,\mathrm{d}t$（15.149）。可利用对称性：偶函数的奇矩全为零。
5. **定阶**：找使 $\mu_n \neq 0$ 的最小正整数 n。若 ψ 紧支撑，可先断言有限阶（外部推断：多项式在紧区间上稠密）。
6. **交叉检验**：n 阶小波应与任何次数 ⩽ n−1 的多项式正交，可用低次单项式逐个内积复核。

**已验证算例**：

- [[concepts/哈尔小波]]：μ₀ = 0，μ₁ = −1/4 ⟹ n = 1（见 [[findings/式15-143至15-148信号与小波定义容许条件转录复算]]）。
- [[concepts/墨西哥草帽小波]]：偶函数 ⟹ μ₁ = 0，μ₂ = −2√(2π) ≠ 0 ⟹ n = 2（见 [[findings/式15-149至15-153矩阶小波变换与哈尔算例转录复算]]）。

**局限**：对无闭式表达的 [[concepts/多贝西小波]]，此流程只能借紧支撑性断言有限阶，无法显式计算矩。
