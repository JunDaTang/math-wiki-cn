# 德瓦尼混沌三条件核验流程

## 为什么用这套流程

德瓦尼定义（[[concepts/德瓦尼混沌]]）把「混沌」拆成三个**可分立核验**的条件，无需测度或微分结构，特别适合符号系统与具体映射的构造性验证；其判据式（17.59）是精确的 ε-δ 语句，可逐点检验。这使它成为与测度型判据（b) 型正李雅普诺夫指数）互补的纯拓扑核验路线。

## 步骤

1. **确认舞台**：度量空间 $(M, \rho)$、动力系统 $\{\varphi^t\}$、紧不变集 $\Lambda$（先核验不变性与紧性）。
2. **核验 a) 拓扑传递**（[[concepts/拓扑传递性]]）：构造一条正半轨使其在 Λ 中稠密。符号系统标准构造：按长度与字典序**拼接全部有限块**；一般系统：寻找 x 使 ω(x) = Λ。
3. **核验 b) 周期点稠密**：对任意 x ∈ Λ 与 ε > 0，在 $U_\varepsilon(x)$ 内找到一个周期点。符号系统标准构造：**截断 + 循环**（取前 J 位作循环序列）。
4. **核验 c) 敏感依赖（式 17.59）**：给出一致常数 ε > 0，并对任意 x、δ 找到近邻 y 与分离时刻 t。符号系统标准构造：**翻转一位再移位**（在第 J 位翻转使 ρ < δ，移位 J 次后首位相异、距离达 1）。
5. **记录冗余性注记**（独立背景）：在无限集上 a)+b) ⟹ c)（Banks 等 1992），故若 a)、b) 已验，c) 理论上必然成立；仍建议独立验证 c) 以获得具体 ε 的显式构造。

## 已应用实例

- 伯努利转移：[[findings/式17-59与Σ空间伯努利转移德瓦尼混沌复算]]（三条件构造性验证全部成立）。

## 边界

- 本流程核验的是德瓦尼型混沌；与 17.2.5 第 1 部分的 a)/b) 型敏感依赖、系统级紧不变集型定义之间的蕴含关系原文未给出，核验结论不可跨定义自动移植（见 [[comparisons/混沌的多种定义比较]]）。
