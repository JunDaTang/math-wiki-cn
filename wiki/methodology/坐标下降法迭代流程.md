# 坐标下降法迭代流程

## 适用前提与设计动机（为何如此设计）

无约束问题 f(x) = min!，x ∈ ℝⁿ。**为何化为一维**：本格式属于「基于函数值比较原理」的无导数方法，避开 n 维目标函数的导数与曲率信息，把难点下放到可用 18.2.4.1 工具求解的一维子问题上。

## 流程（依据式 18.71a–c）

1. **初始化**：取 x\* 的适当初始近似 x = x¹，置 k = 1。
2. **逐坐标一维极小化**：对 r = 1, …, n 依次求解一维问题

   ```text
   φ(α_r) = f(x₁^{k+1}, …, x_{r−1}^{k+1}, x_r^k + α_r, x_{r+1}^k, …, x_n^k) = min!,  α_r ∈ ℝ
   ```

   得（精确或近似）极小点 ᾱ_r，作替换 x_r^{k+1} = x_r^k + ᾱ_r。注意被固定分量的层次：r 之前用 k+1 层（已更新），r 之后用 k 层（未更新），即 Gauss–Seidel 式即时更新。
3. **停机检验**：若 ‖x^{k+1} − x^k‖ < ε₁（某种向量范数下）或 |f(x^{k+1}) − f(x^k)| < ε₂，则接受 x^{k+1} 为 x\* 的近似；否则以 k+1 代替 k 重复步骤 2。
4. **子问题求解器**：步骤 2 的一维问题用 18.2.4.1 的方法求解——[[concepts/一致搜索]]、[[concepts/黄金分割法]]（操作见 [[methodology/黄金分割搜索迭代流程]]）或 [[concepts/斐波那契法]]；若在区间上使用这些方法，需该方向上的目标满足 [[concepts/单峰函数|单峰性]]。

## 设计原理与局限

- **即时更新的动机**：每个新解出的坐标立刻进入后续子问题的固定分量，使同一轮内的信息最新化（Gauss–Seidel 式）。
- **双重停机准则**：范数准则控制解的空间精度，函数值准则控制目标改善幅度，二者任一满足即停。
- **局限（源文未证）**：源文无收敛性论断，停机为启发式；子问题允许近似极小化，误差对整体的累积影响未讨论。引用本流程时不得附会收敛保证。
