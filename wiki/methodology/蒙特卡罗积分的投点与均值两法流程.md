# 蒙特卡罗积分的投点与均值两法流程

本流程出自《数学手册(原书第10版)》16.3.5.3，用于求积分

$$I=\int_0^1 g(x)\,\mathrm{d}x \tag{16.171}$$

的近似值，是「模拟中应用均匀分布随机数的一个实例」。设计动机（why）：同一个积分可从**几何频率**（面积比例）与**统计均值**（期望的样本估计）两个等价视角逼近，后者即源文所称「普通蒙特卡罗方法」。

## 前提

设 0 ⩽ g(x) ⩽ 1（通过积分变换总可保证该条件成立，参见第 1103 页 (16.175)，即 [[methodology/积分标准化min-max变换流程]]）。

## 方法一：运用频率（投点法）

1. 把区间 [0,1] 内均匀分布随机数序列的数值**成对地**作为单位正方形内点的坐标，得到 n 个点 P_i（i=1,…,n）；
2. 数出位于积分区域（单位正方形内以 y=g(x) 围成的区域，图 16.16）内的点数 m；
3. 以频率估计面积：

$$\int_0^1 g(x)\,\mathrm{d}x \approx \frac{m}{n}. \tag{16.172}$$

频率逼近的依据回指第 1057 页 16.2.1.2，即 [[concepts/频数与相对频率]]。源文指出：使用 (16.172) 的比值，欲得到较好的精确度，**需要大量随机数**；这正是人们探究提高精度方法的原因，方法之一是下述均值逼近法，另一些方法见文献 [16.19]。

## 方法二：利用均值逼近

1. 从 n 个均匀分布随机数 ξ₁, ξ₂, …, ξ_n 出发，作为均匀分布随机变量 X 的实现；
2. 计算 g_i = g(ξ_i)（i=1,…,n），它是随机变量 g(X) 的实现；
3. 依据第 1063 页期望公式 (16.49a, 16.49b)（[[concepts/期望]]）：

$$E(g(X)) = \int_{-\infty}^{\infty} g(x)f_0(x)\,\mathrm{d}x = \int_0^1 g(x)\,\mathrm{d}x \approx \frac{1}{n}\sum_{i=1}^{n} g_i. \tag{16.173}$$

这种方法使用样本得到均值，也称为**普通蒙特卡罗方法**；以样本均值估计期望的依据见 [[concepts/样本均值]]。
