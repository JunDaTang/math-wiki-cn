# 二次曲线一般方程化简流程

## 为什么需要这个流程

一般二次方程 ax² + 2bxy + cy² + 2dx + 2ey + f = 0 含交叉项（2bxy）与一次项，无法直接读出曲线的形状与位置。流程的核心思想是：**判别式的取值决定变换路径**——δ≠0 说明曲线有中心，先平移到中心即可消去全部一次项；δ=0（抛物型）没有中心，只能平移到顶点消去部分一次项；最后的旋转消去交叉项，其角度由系数比完全确定。这样每一步变换都有明确目标，避免盲目尝试。

## 流程（原书表 3.19 / 表 3.20）

**第 0 步：计算不变量** Δ = |a b d; b c e; d e f|、δ = |a b; b c|、S = a + c（旋转下不变）。

**路径 A：δ≠0（有心曲线）**
1. 平移原点至中心 (x₀, y₀) = ((be−cd)/δ, (bd−ae)/δ)——消去一次项。
2. 旋转 α 角消去交叉项：tan 2α = 2b/(a−c)，**sin 2α 的符号必须与 2b 一致**；新 x′ 轴斜率 k = [c−a+√((c−a)²+4b²)]/(2b)。
3. 得标准形 a′x′² + c′y′² + Δ/δ = 0，其中 a′、c′ 是 u²−Su+δ=0 的两个根。

**路径 B：δ=0，Δ≠0（抛物线）**
1. 平移至顶点：x₀、y₀ 由两个线性方程 a·x₀+b·y₀+(ad+be)/S=0 与 (d+(dc−be)/S)·x₀+(e+(ae−bd)/S)·y₀+f=0 给出。
2. 旋转 α 角：tan α = −a/b，**sin α 的符号必须与 a 相异**。
3. 得标准形 y′² = 2px′，p = (ae−bd)/(S·√(a²+b²))。

**路径 C：δ=0，Δ=0（退化为直线对）**
仅旋转：S·y′² + 2(ad+be)/√(a²+b²)·y′ + f = 0，再分解为 (y′−y₀′)(y′−y₁′)=0。

**第末步：用表 3.19/3.20 的条件核对**所得标准形对应的曲线类型（δ、Δ（、S）与 d²−af 的符号组合）。

## 为什么符号约定重要

tan 2α = 2b/(a−c) 有两个相差 90° 的解；「sin 2α 与 2b 同号」（抛物型为「sin α 与 a 异号」）在两个解中唯一选定一个，保证 a′ 恰对应新 x′ 轴、标准形不发生 a′/c′ 对调。

## 验证状态

分类与变换公式已经试例抽查验证（见 [[findings/二次曲线不变量分类与化简流程]]）：x²+y²−1=0、x²+y²+1=0、x²−y²−1=0、xy=1、y²−x=0 及旋转 45° 的抛物线试例全部通过。
