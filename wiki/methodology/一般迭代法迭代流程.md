# 一般迭代法迭代流程

依据《数学手册（原书第10版）》19.1.1.1（式 19.1–19.5）整理。

## 流程

1. **化归不动点形式**：将给定方程化为 $x = \varphi(x)$（式 19.2；同一方程的化法不唯一，直接影响收敛性）。
2. **取初始近似**：可先用图解分离（$f_1(x) = f_2(x)$ 作图，见 [[concepts/零形式与不动点形式]]）得到 $x_0$；$x_0$ 须落在 $x^*$ 的合适邻域内。
3. **迭代**：$x_{n+1} = \varphi(x_n)$（式 19.3），逐次计算。
4. **收敛性核查**：在 $x^*$ 邻域内验证压缩条件 $\left| \frac{\varphi(x) - \varphi(x^*)}{x - x^*} \right| \le K < 1$（式 19.4）；$\varphi$ 可导时用 $|\varphi'(x)| \le K < 1$（式 19.5；源文疑脱绝对值，见 [[queries/式19-5脱绝对值之辨]]）。
5. **停机**：相邻迭代值之差小于容差即停（本源未给显式停机准则，此为流程整理时的常规补全）。

## 设计理由（why）

- 压缩条件保证迭代序列在 $x^*$ 邻域内局部收敛，是流程成立的唯一理论支柱；常数 $K$ 越小收敛越快，故化归 $\varphi$ 时应使 $|\varphi'|$ 在解附近尽量小。
- 若 $|\varphi'(x^*)| > 1$（尤其 $\varphi'(x) < -1$），基本迭代发散，应改用 [[concepts/斯特芬森方法]]。

## 基准算例

$x^2 = \sin x \Rightarrow x_{n+1} = \sqrt{\sin x_n}$，$x_0 = 0.87$，6 步收敛至 0.8767（复算通过，见 [[findings/式19-1至19-5零形式不动点形式与一般迭代法转录复算]]）。
