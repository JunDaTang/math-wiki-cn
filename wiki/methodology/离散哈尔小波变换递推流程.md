# 离散哈尔小波变换递推流程

**目的（why）**：把连续小波变换 (15.152b) 的冗余双重积分替换为不丢失信息的离散递推，得到可在测量序列上直接运行的快速算法（FWT 思想的哈尔实例）。

**步骤（how）**：

1. **输入**：信号值 $f_i$，i = 1, 2, …, N。
2. **第一层（15.155）**：对每对相邻值计算
   $$s_i = \tfrac{1}{\sqrt{2}}(f_{2i-1} + f_{2i}), \quad d_i = \tfrac{1}{\sqrt{2}}(f_{2i-1} - f_{2i})$$
   并**先存储** d 序列。
3. **递推层（15.156）**：把 (15.155) 中的 f 换成 s 继续执行：
   $$s_i^{(n+1)} = \tfrac{1}{\sqrt{2}}(s_{2i-1}^{(n)} + s_{2i}^{(n)}), \quad d_i^{(n+1)} = \tfrac{1}{\sqrt{2}}(s_{2i-1}^{(n)} - s_{2i}^{(n)})$$
4. **输出**：各层 $d_i^{(n)}$ 组成的向量列（细节向量；源译「具体向量」，见 [[queries/具体数值具体向量疑为细节之辨]]），每一层包含信号在相应尺度上的信息。

**校验（可复算）**：

- 每层能量守恒：$s_i^2 + d_i^2 = f_{2i-1}^2 + f_{2i}^2$（展开交叉项相消即得），故递推不损失 ℓ² 能量。
- 可逆性（直接推论，源内未明言）：$f_{2i-1} = \tfrac{1}{\sqrt{2}}(s_i + d_i)$、$f_{2i} = \tfrac{1}{\sqrt{2}}(s_i - d_i)$，逐层可反解，信号可重建。
- N 较大时结果收敛于积分小波变换 (15.152a)（源内启发式断言，未证）。
