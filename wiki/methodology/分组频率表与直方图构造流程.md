# 分组频率表与直方图构造流程

依据数学手册 16.3.2.1 的统计调查过程整理的分组频率表与直方图构造流程。

## 为什么（rationale）

测量序列的容量 n 可以很大（[[concepts/随机样本与无限总体]]），原始数据表难以直接读取分布信息；分组与频率表把 n 个数据压缩为 k 组的频数，直方图与实证分布函数进一步给出密度与分布函数的**实证近似**。这正是「探寻 X 的分布的某些参数或 X 的分布本身」的第一步，也是 [[concepts/描述性统计学]] 的核心操作。

## 流程

1. **记录**：把测量或观察值 $x_i$ 记入规则表（原文「记录在规则表中」表述存疑，见 [[queries/16-3-2全节系统性转写讹误清单]]）。
2. **定组**：选定组数 k 与等组距 h（通常 10~20 组）；核对总跨度 $\approx k\times h$。端点计数约定见 [[queries/等组距h20与分组端点宽度之辨]]。
3. **计数**：数出落在各组 $\Delta x_j$ 的数据个数，得绝对频率 $h_j$（[[concepts/频数与相对频率]]）；核对 $\sum_j h_j=n$。
4. **相对频率**：计算 $h_j/n$（用 % 表示）。
5. **直方图**：以矩形表示各组的 $h_j/n$，得频率分布的图形（[[concepts/直方图]]），读作密度 $f(x)$ 的实证数值。
6. **累计**：按 $F_j=F_{j-1}+h_j/n$ 递推累计频率（式 16.125），终值应为 100%；绘图得实证分布函数（[[concepts/累计频率与实证分布函数]]），读作未知分布函数的近似。

## 校验点（来自表 16.3 复算经验）

- 频数总和 = n；
- 相对频率总和 = 100%；
- 累计频率单调不减且终值 100%；
- 总跨度 = $k\times h$。

参考算例：n=125、区间 [50, 270]、k=11、h=20（表 16.3，复算见 [[findings/表16-3频率表转录复算]]）。分组统计量的后续计算见 [[methodology/分组数据统计量计算流程]]。
