# 复位势场元选用与叠加流程

## 目的

为 $x,y$ 平面上分量连续可微的向量场 $\vec V=(V_x,V_y)$ 构造复位势 $W=\Phi+\mathrm{i}\Psi$，把平面场问题化为解析函数问题。依据（为何可行）：无源（式 14.21）给出流函数 $\Psi$，无旋（式 14.22）给出位势函数 $\Phi$；两者皆成立时 $\Phi,\Psi$ 满足柯西–黎曼方程且调和，组合即解析的复位势（式 14.23）。

## 流程

1. **判定场型**：检验 $\operatorname{div}\vec V=0$ 与 $\operatorname{rot}\vec V=0$（源文 14.22a 记号 $\cot$ 疑为 $\operatorname{rot}$，见 [[queries/式14-22a旋度记号cot疑为rot]]）；两者皆满足才存在复位势。
2. **查场元目录选用基本复位势**（式 14.25–14.30，比较见 [[comparisons/基本复位势场元比较]]）：

| 场元 | 复位势（式号） |
|---|---|
| 齐次场 | $W=az$（14.25） |
| 源（$s>0$，位于 $z_0$） | $W=\frac{s}{2\pi}\ln(z-z_0)$（14.26） |
| 汇 | $W=-\frac{s}{2\pi}\ln(z-z_0)$（14.27） |
| 源–汇系统 | $W=\frac{s}{2\pi}\ln\frac{z-z_1}{z-z_2}$（14.28） |
| 偶极子（矩 $M$，角 $\alpha$） | $W=\frac{M\mathrm{e}^{\mathrm{i}\alpha}}{2\pi(z-z_0)}$（14.29） |
| 旋度（强度 $\Gamma$） | $W=\frac{\Gamma}{2\pi\mathrm{i}}\ln(z-z_0)$（14.30；复强度即旋度源） |

3. **叠加**：系统复位势 = 各场元复位势之和（流函数亦相加）；合法性由 $\Delta\Phi=\Delta\Psi=0$ 的线性性保证。
4. **连续分布**：曲线上密度 $\varrho(s)$ 的旋度分布改用柯西型积分（式 14.31）构造 $\frac{\mathrm{d}W}{\mathrm{d}z}$，见 [[concepts/柯西型积分]]。
5. **图解叠加**：两张位势线图的叠加用 [[methodology/麦克斯韦对角线方法]]。
6. **边界处理**：直线边界用 [[concepts/施瓦茨反射原理]] 反射延拓——流线边界（源映源、汇映汇、旋度反向）与位势线边界（源汇互换、旋度同向）规则相反（比较见 [[comparisons/流线边界与位势线边界反射规则比较]]）。
7. **读出场量**：$\frac{\mathrm{d}W}{\mathrm{d}z}=V_x-\mathrm{i}V_y$（式 14.24）；$\Phi$、$\Psi$ 等值线为正交网；物理/电工记号下 $-\Phi$ 为场的位势（13.3.1.6）。

## 注意

术语“旋度”在此指场元（点涡），非 13.2.5 的旋度算子（[[queries/旋度术语双重用法之辨]]）；“方向线”即流线。
