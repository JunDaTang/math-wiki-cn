# 球面三角形公式选择与精度规则

本方法论来自 [[sources/10-数学手册原书第10版--12-343-球面三角形的计算--170nm2t]] 3.4.3.1，回答「同一基本问题有多种解法时选哪一个」的问题（与 [[methodology/交会定位计算流程]] 并列，同属「已知—所测—所求—解」范式中的「解」环节的精度考量）。

## 规则内容

1. **正切优先**：包含正切函数的公式在数值上可以得到更精确的结果——尤其是相比于该量接近 90° 时用正弦函数确定它、以及该量接近 0° 或 180° 时用余弦函数确定它的情形。
2. **正弦定律双值**：对欧拉三角形（各边各角均 < 180°），用正弦定律计算的量有两个值（正弦函数在第一、二象限均取正），须另用「较大的角所对的边较大」或余弦型检验式判定象限；从其他函数得到的结果是唯一的。
3. **检验计算**：每个基本问题都配有检验手段——检验恒等式（如第一问题 tan(α/2)tan(β/2)tan(γ/2)·sin s = k）或同一量的双重计算（如第三、四问题关于 c 或 γ 的双重计算）。
4. **角的简化**：计算出的地理经度若落在 −180° < λ ⩽ 180° 之外，按式 (3.205) λ_red = 2 arctan(tan(λ/2))（λ ≠ ±k·180°）化回定义域。

## 为什么（rationale）

正弦函数在 90° 附近、余弦函数在 0°/180° 附近斜率趋于零，自变量的微小误差对函数值不敏感，反解时函数值误差被放大；正切函数在这些区间斜率大，反解良态。因此选择公式时应使所求量落在所用函数的高斜率区间。源的论证是函数斜率的定性论证（无量化误差分析），与标准数值分析的常识一致。

该规则贯穿 [[concepts/球面三角形六基本问题]] 的解法选择（表 3.9–3.12 中「解 1/解 2/…」的并列正是按精度与需求取舍），也适用于 [[concepts/直角球面三角形]] 的十条专门公式之间的选择。
