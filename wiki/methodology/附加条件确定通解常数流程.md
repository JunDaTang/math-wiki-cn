# 附加条件确定通解常数流程

## 目的与原理（为什么）

n 阶常微分方程的通解含 n 个任意常数 c₁, …, cₙ；n 个附加条件恰好提供 n 个方程，构成关于常数的 n 元方程组，解之即得特解。这一机制是 [[concepts/初值问题]] 与 [[concepts/边值问题]] 的统一框架：两者的差别只在附加条件的**取值位置与形式**（同一点 x₀ 处的各阶导数值 vs 定义域中若干点处的函数/导数值），定常数的机制完全相同。

## 流程（怎么做）

1. **求通解**：求出含 n 个任意常数的通解 y = φ(x; c₁, …, cₙ)。本节三个算例中通解均直接给出；一般解法自 9.1.1 起给出（未入库）。
2. **收集附加条件**：确认共 n 个条件——
   - 初值型：y(x₀), y′(x₀), …, y⁽ⁿ⁻¹⁾(x₀)；
   - 边值型：y 及/或其导数在定义域若干点处的给定值。
3. **代入生成方程组**：将每个条件代入通解；涉及导数的条件先对通解求相应阶导数再代入，得到关于 c₁, …, cₙ 的 n 个方程。
4. **解方程组**：定出 c₁, …, cₙ 的值。
5. **回写并验证**：写出特解，代回原微分方程与全部附加条件验证。

## 两算例对照（n = 2）

- **谐运动（初值型）**：通解 y = A cos x + B sin x；条件 y(0) = y₀ 代入得 A = y₀；条件 y′(0) = 0 代入 y′ = −A sin x + B cos x 得 B = 0；特解 y = y₀ cos x。
- **细棒（边值型）**：通解 y = x³/6 − x⁴/12 + c₁x + c₂；条件 y(0) = 0 得 c₂ = 0；条件 y(1) = 0 得 c₁ = −1/12；特解 y = x³/6 − x⁴/12 − x/12。

两例复算见 [[findings/9-1三算例复算]]。

## 适用边界与局限

- 「n 个附加条件可确定 n 个常数」是经典启发式表述：本流程假定所得方程组可解且解唯一，未涉及存在唯一性理论（预计 9.1.1 给出，届时回填）。
- 附加条件过少则常数保留（得一族解）；条件位置或形式不当则方程组可能不定或矛盾。
- 例 1 中「条件 c = 0」直接对常数本身施加条件，不经过点值代入，与本流程的常规输入不属同一层面，见 [[queries/例1条件c等于0与边值问题定义宽窄]]。
