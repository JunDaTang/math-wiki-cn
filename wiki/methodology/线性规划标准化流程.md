# 线性规划标准化流程

## 目的与理据（why）

线性规划问题在建模时自然呈现混合形态：目标可求极大或极小，约束可含「⩽」「⩾」「=」，变量可非负亦可自由。而手册指出，「在应用某些解法时」仅考虑非负变量与等式约束——即后续各节的解法（预期为单纯形法类）以[[concepts/线性规划标准形式]]为统一入口。标准化流程把任意线性规划问题归约为 max cᵀx s.t. Ax = b, x ⩾ 0，正是为对接这些解法而设。

## 流程（四步）

1. **符号统一（「⩾」→「⩽」）**：对带「⩾」号的约束乘以 (−1)，化为「⩽」形式。
2. **极小→极大**：极小问题 f(x) = min! 通过目标函数乘以 (−1) 化为等价的极大问题 −f(x) = max!（式 18.3）；最优解集合不变，最优值变号。
3. **自由变量分解**：每个自由变量 xₖ 分解为两个非负变量之差 xₖ = xₖ¹ − xₖ²（xₖ¹, xₖ² ⩾ 0）。
4. **松弛化**：对每个「⩽」不等式，在较大一侧增加非负[[concepts/松弛变量]]，化为等式。

## 收尾假定

标准化后一般可假定 m ⩽ n：否则方程组 Ax = b 会包含线性相关或相互矛盾的方程。（注：手册此处把两种情形并列，表述偏粗——相关方程仍可能相容；m > n 时至少有一方程可由其余表出，可先行剔除或判定矛盾。）

## 算例走查（生产计划算例）

原问题：

```text
max  20x₁ + 60x₂
s.t. 12x₁ +  6x₂ ⩽ 630
      8x₁ + 12x₂ ⩽ 620
     10x₂        ⩽ 350
      x₁         ⩾ 10
```

- 前三个「⩽」约束分别加松弛变量 x₃, x₄, x₅；
- 第四个「⩾」约束先乘 (−1) 得 −x₁ ⩽ −10，再加 x₆ 得 −x₁ + x₆ = −10。

结果：

```text
max  20x₁ + 60x₂ + 0·x₃ + 0·x₄ + 0·x₅ + 0·x₆
s.t. 12x₁ +  6x₂ + x₃                    = 630
      8x₁ + 12x₂      + x₄               = 620
     10x₂                 + x₅           = 350
     −x₁                      + x₆       = −10
```

解点 x* 的非松弛变量分量（本例即 (x₁, x₂)）构成原问题的解。
