# 拉宾-米勒素性检验流程

## 目的与原理（为什么有效）

检验奇自然数 n > 1 的素性，并消除费马检验对卡迈克尔数的失效。原理：素数 n 必满足命题 (＊)（n − 1 = 2^t·u，u 奇，gcd(a,n)=1 ⇒ 存在 j ∈ {0,…,t−1} 使 a^u ≡ 1 (mod n) 或 a^(2^j·u) ≡ −1 (mod n)），故检验序列中无满足 (＊) 的值即可确定地判 n 为合数。

## 步骤

1. 选取 a ∈ ℤ_n∖{0}。
2. 求出分解 n − 1 = 2^t·u（u 是奇数）。（源文此步误作「n − 2 = 2^t·u」，与命题 (＊) 及 561 算例 560 = 2^4·35 矛盾，见 [[queries/检验式中n减2是否应为n减1]]。）
3. 若 gcd(a,n) > 1，则 n 不是素数。
4. 若 gcd(a,n) = 1，由重复实施模 n 平方依次计算 a^u, a^(2u), …, a^(2^(t−1)u) (mod n)，检查是否出现满足 (＊) 的值（首项等于 1，或某项等于 −1）：
   - 不存在这样的值 ⇒ n 不是素数（确定性结论）；
   - 存在 ⇒ n 通过对基 a 的检验，须对其他基复检。

## 误差控制

随机且独立地选取 k 个不同的基值且全部通过检验时，第一类误差率 ≤ 1/4^k（对一切合数成立，无卡迈克尔例外）。实用中取 k = 25。

## 算例

n = 561：n − 1 = 2^4·35，a = 2：2^35 ≡ 263、2^70 ≡ 166、2^140 ≡ 67、2^280 ≡ [1]（源文作 421，讹）——序列中无项满足 (＊)，故 561 不是素数。见 [[findings/561拉宾-米勒算例与2的280次方讹误]]。
