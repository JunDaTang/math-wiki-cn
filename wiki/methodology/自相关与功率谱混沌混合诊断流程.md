# 自相关与功率谱混沌混合诊断流程

## 目的与理由

单条轨道的时间序列即可计算[[concepts/自相关函数]]与[[concepts/功率谱]]，从而在不重构测度的前提下对动力系统作「规则—混沌—混合」的统计分类。遍历性保证时间平均可替换空间平均（[[concepts/伯克霍夫遍历定理]]），使单轨口径合法。

## 流程

1. **选观测函数** $h$（连续测试函数），沿半轨 $\{\varphi^t(x)\}_{t\geqslant 0}$ 计算时间平均 $\bar{h}$（连续：$\lim_{T\to\infty}\frac{1}{T}\int_0^T h(\varphi^t(x))\,\mathrm{d}t$；离散：$\lim_{n\to\infty}\frac{1}{n}\sum_{i=0}^{n-1}h(\varphi^i(x))$）。
2. **计算自相关函数**（式 17.34a/b）：

$$C_h(\tau)=\lim_{T\to\infty}\frac{1}{T}\int_0^T h(\varphi^{t+\tau}(x))h(\varphi^t(x))\,\mathrm{d}t-\bar{h}^2$$

（离散情形将积分换为 $\frac{1}{n}\sum_{i=0}^{n-1}h(\varphi^{i+\tau}(x))h(\varphi^i(x))$）。负向 $\tau$ 由偶性延拓。
3. **按衰减行为分类**（本节判据）：
   - $C_h$ 周期/拟周期不衰减 → 周期/拟周期轨道；
   - 对任意测试函数 $h$，$C_h(\tau)$ 随 $\tau$ **快速减小** → **混沌**；
   - $C_h(\tau)$ 以**指数速率衰减** → **混合**。
4. **计算功率谱**（式 17.35a/b）：连续情形 $P_h(\omega)=\int_{-\infty}^{+\infty}C_h(\tau)e^{-\mathrm{i}\omega\tau}\mathrm{d}\tau=2\int_0^\infty C_h(\tau)\cos(\omega\tau)\,\mathrm{d}\tau$（需绝对可积；离散情形 $P_h(\omega)=C_h(0)+2\sum_{k\geqslant 1}C_h(k)\cos\omega k$；否则 $P_h$ 作分布理解）。
5. **按谱型分类**：等距脉冲 → 周期（$2\pi\sum_k|\alpha_k|^2\delta(\omega-k\omega_0)$）；基本频率整系数线性组合脉冲 → 拟周期；宽带谱 → 混沌标志（源句「宽带谱中出现奇异峰值」措辞疑讹）。

## 校验算例

周期轨与双频拟周期轨的 $C_h$、$P_h$ 闭式公式经独立复算成立（利用实值性 $|\alpha_{-k}|=|\alpha_k|$ 消去虚部），见 [[findings/式17-33至17-35混合自相关与功率谱转录复算]]。应用该判据可立即识别[[concepts/圆周旋转映射]]「是混合的」为讹误（等距系统相关不衰减），见 [[queries/旋转映射是混合的疑脱不字之辨]]。
