# 对称类型判定与系数计算流程

## 目的（为什么）

周期函数的对称性可使傅里叶系数计算量减半甚至减为四分之一，并预先排除恒为零的系数，避免无效积分。该流程是手册 7.4.2.1 四类对称公式（式 7.107–7.111）的操作化。

## 流程（怎么做）

1. **确认基本参数**：周期 T，基频 ω = 2π/T。
2. **检验奇偶性**：f(−x) = f(x)（偶）？f(−x) = −f(x)（奇）？
3. **检验半周期反号性**（第三类对称）：f(x + T/2) = −f(x)？
4. **组合判定第四类**：奇 ∧ 第三类（式 7.110）或 偶 ∧ 第三类（式 7.111）。
5. **按对称类型选公式**（查 [[concepts/对称函数的傅里叶系数]] 的表）：
   - 仅偶：a_k = (4/T)∫₀^{T/2} f cos(k·2πx/T)dx，b_k = 0；
   - 仅奇：b_k = (4/T)∫₀^{T/2} f sin(k·2πx/T)dx，a_k = 0；
   - 仅第三类：只算奇下标 a_{2k+1}、b_{2k+1}，前 4/T、积分限 [0, T/2]；
   - 第四类：只算奇下标，前 8/T、积分限 [0, T/4]。
6. **不满足任何对称**：退回欧拉公式（式 7.102）在 [0, T] 上积分。
7. **核验**：用帕塞瓦尔方程（式 7.106b）抽查系数平方和与函数平方平均是否吻合。

## 原理依据

- 偶（奇）函数乘偶核 cos（奇核 sin）得偶函数，负半周贡献与正半周相等（相消），积分限减半、系数加倍。
- 第三类对称使 ∫₀^T 合并为 [1 − (−1)^k]∫₀^{T/2}：偶下标自动为零，奇下标加倍。
- 第四类对称再利用被积函数关于 x = T/4 的（反）对称性，把积分限进一步减半到 [0, T/4]（「四分之一波对称」）。
- 证明细节见 [[findings/四类对称系数公式-式7-107至7-111]]；判定顺序的对照分析见 [[comparisons/四类对称系数公式比较]]。

## 适用边界

对称性判定必须对完整周期函数（含区间外延拓部分）进行；仅在 [0, T/2] 上给定的函数可先选择延拓方式（见 [[methodology/有限区间傅里叶展开形式选择流程]]）再套用本流程。
