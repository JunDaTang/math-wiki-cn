# 中国剩余定理构造解流程

**用途**：求解模数两两互素的联立线性同余式组 x ≡ b_j (m_j)，j = 1..t。**出处**：5.4.3.7，式 (5.254)。

## 步骤

1. **前提检验**：确认 m₁, …, m_t 两两互素（否则本构造不适用）。
2. **计算总量**：m = m₁·m₂⋯m_t。
3. **计算补模**：对每个 j，a_j = m/m_j。
4. **逐项解线性同余式**：a_j x_j ≡ b_j (mod m_j)。因 gcd(a_j, m_j) = 1（m_j 的素因子都不含于 a_j），每式唯一可解；用 [[methodology/线性同余式转丢番图方程求解流程|线性同余式解法]]（或直接试代表元）取一特解 x_j。
5. **组合**：x′ = a₁x₁ + a₂x₂ + ⋯ + a_t x_t。答案：x ≡ x′ (mod m)。

## 为什么可行（机理）

对固定的 j 与 i ≠ j：a_i 是 m_j 的倍数，故 x′ ≡ a_j x_j ≡ b_j (mod m_j)；两解之差被每个 m_j 整除，由两两互素得被 m 整除，故模 m 唯一。（机理为复核推理，源文未显式证明。）

## 算例（已复算）

x ≡ 1 (2)、2 (3)、4 (5)：m = 30；a₁ = 15、a₂ = 10、a₃ = 6；x₁ = 1、x₂ = 2、x₃ = 4；x′ = 59 ≡ 29 (mod 30)。验证 29 mod 2/3/5 = 1/2/4。✓ 见 [[findings/中国剩余定理构造解与算例]]。

## 局限

模数不两两互素时须先分解公因子并检验相容性——本节源文未处理该情形。
