# 分子对称群确定流程

这是 5.3.5.3 给出的、由已知对称元素确定分子对称群的操作程序（决策树）。

## 为什么这样做（rationale）

识别个体的每个对称元素本身需要做大量工作（原文指出文献 [5.21], [5.22], [5.27] 有详细讨论）；而一旦对称元素已知，决策树把「求群」化为有限步分类。分层的依据是群结构：**旋转轴的数目与阶**决定循环子群骨架（轴阶 $n$ → $\mathbb{Z}_n$ 型旋转部分），**附加的反射**决定与 $\mathbb{Z}_2$ 的直积或二面体式扩张——这正是 $C_n$、$C_{nv}\cong D_n$、$C_{nh}\cong\mathbb{Z}_n\times\mathbb{Z}_2$、$S_{2n}\cong\mathbb{Z}_{2n}$、$D_{2n}$ 诸同构的来源。

## 流程（决策树）

1. **没有旋转轴**
   - 无任何对称元素 → $G=\{\epsilon\}$（例：半缩醛）。
   - 有反射 $\sigma$ 或反演 $i$ → $C_s=\{\epsilon,\sigma\}$ 或 $C_i=\{\epsilon,i\}$（$\cong\mathbb{Z}_2$；例：酒石酸）。
2. **恰有一个旋转轴**
   - a) 可旋转任意角度（$C_\infty$，分子长条形）：
     - 无水平反射 → $C_{\infty v}$（例：NaCl）；
     - 有水平反射 → $D_{\infty h}$（例：O₂）。
   - b) 轴为 $n$ 阶（$C_n$），**不是** $2n$ 阶非正常轴：
     - 无其他对称元素 → $C_n\cong\mathbb{Z}_n$；
     - 加垂直反射 $\sigma_v$ → $C_{nv}\cong D_n$（例：H₂O，$n=2$，$\cong D_2\cong V_4$）；
     - 加水平反射 $\sigma_h$ → $C_{nh}\cong\mathbb{Z}_n\times\mathbb{Z}_2$（$n$ 奇时循环；例：H₂O₂ 随 $\delta$ 变化呈现三种情形）。
   - c) 轴为 $n$ 阶（$C_n$），**同时是** $2n$ 阶非正常轴：
     - 无垂直反射 → $S_{2n}\cong\mathbb{Z}_{2n}$（例：四羟基丙二烯 $C_3(OH)_4$，$n=2$）；
     - 有垂直反射 → $D_{2n}$（$4n$ 阶；$n=2$ → $D_4$，8 阶；例：丙二烯）。
3. **多个旋转轴（阶 $n\geqslant 3$）** → 多面体群：$T_d\cong S_4$（24 阶；例：甲烷）、$O_h\cong S_4\times\mathbb{Z}_2$（48 阶）、$I_h$（120 阶）。

## 输入与输出

- **输入**：分子的全部对称元素（旋转轴及其阶、反射平面相对于主轴的方位、反演中心、非正常轴）。
- **输出**：Schoenflies 记号标记的分子点群及其同构类型（对照表见 [[entities/分子点群]]、断言与复算见 [[findings/分子对称群分类决策树与同构类型]]）。

## 有效性边界

- 该流程针对空间中的分子（有界个体），故不含平移情形；晶体格的对称群需另走 5.3.5.4 的平移群／空间群构造（[[concepts/平移群]]、[[entities/空间群]]）。
