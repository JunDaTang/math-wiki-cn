# 牛顿法与修正牛顿法迭代流程

依据《数学手册（原书第10版）》19.1.1.2（式 19.6–19.9）整理。

## 牛顿法流程

1. **取初始值** $x_0$（可由图解分离得到）。
2. **迭代**：$x_{n+1} = x_n - f(x_n)/f'(x_n)$（式 19.6），每步计算 $f(x_n)$ 与 $f'(x_n)$。
3. **条件核查**：在 $x^*$ 及其邻域内所有迭代点满足 $f'(x) \neq 0$（19.7a，必要）与 $\left| f(x) f''(x)/f'^2(x) \right| \le K < 1$（19.7b，充分）。
4. **停机与收敛特征**：平方阶收敛——十进制下正确位数成倍增加；相邻值差小于容差即停（常规补全）。
5. **多项式特例**：$f(x) = p_n(x)$ 时 $f(x_n)$、$f'(x_n)$ 用 [[methodology/霍纳格式求值与求导流程]] 计算；$f(x) = x^2 - a$ 时得平方根迭代 $x_{n+1} = \frac12 (x_n + a/x_n)$（式 19.8）。
6. **复变量**：牛顿法对复变量的可微函数同样适用（源文断言）。

## 修正牛顿法分支

若迭代过程中 $f'(x_n)$ 数值几乎不变（一段时间内保持常数），冻结导数为 $f'(x_m)$（$m$ 给定，$m < n$）：$x_{n+1} = x_n - f(x_n)/f'(x_m)$（式 19.9）。源文称其“收敛阶几乎没有任何改变”——此说存疑（标准理论预期退化为线性收敛），见 [[queries/修正牛顿法收敛阶几乎不变之说之辨]]，使用该分支时应谨慎。

## 设计理由（why）

- 以切线（线性化）局部近似曲线，将非线性方程逐步化为线性方程求解，是“逐次线性化”思想的原型。
- 修正分支省去导数重算，代价是收敛性质可能改变——适用于导数计算昂贵且导数近乎常数的场合。

## 基准算例

$a = 2$、$x_0 = 1.5$：1.5 → 1.4166666 → 1.4142157 → 1.4142136（复算通过，见 [[findings/式19-6至19-9牛顿法与修正牛顿法转录复算]]）。
