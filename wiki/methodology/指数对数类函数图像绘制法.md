# 指数对数类函数图像绘制法

这是 [[数学手册原书第10版]] §2.6 展示的函数图像绘制方法论，与 [[多项式图像绘制法]]（§2.3）、[[有理函数图像绘制法]]（§2.4）构成同构系列的第三篇。

## 步骤

1. **要素清单**：对每个函数族逐一给出闭式公式——对称轴/对称性、与坐标轴交点、单调区间、[[极值]]、[[拐点]]、[[渐近线]]（含「无渐近线」情形）。
2. **符号情形分类**：按参数符号组合枚举行为模式。典型如 [[指数和]] 的四情形（a 与 c 同/异号 × b 与 d 同/异号），其存在性判据是纯符号运算：
   - 极值存在 ⇔ $\operatorname{sgn}(ab)$ 与 $\operatorname{sgn}(cd)$ 异号（由 $-\frac{ab}{cd} > 0$）；
   - 拐点存在 ⇔ $\operatorname{sgn}(a)$ 与 $\operatorname{sgn}(c)$ 异号（由 $-\frac{ab^{2}}{cd^{2}} > 0$，平方项不改变符号）。
3. **反射约化**：用反射把参数空间减半——
   - a < 0 时沿 x 轴反射（2.6.5、2.6.6 均明言「只需将前一图形沿 x 轴反射」，与 2.3.5 的反射句呼应）；
   - 依参数符号沿坐标轴反射（2.6.4）；
   - 反函数沿 y = x 反射（对数曲线 = 指数曲线的反射像，2.6.2），由此可从一族免费获得另一族的全部要素。
4. **特例退化校核**：用已知特例数值代入复核公式（如广义误差函数取 b = 0、c = −1 退化为误差曲线；误差曲线取 a = 1 得 e^{−x²}），这是发现转写疑误的主要手段——本节三处疑误中两处由此定位。

## 为何有效

指数类函数的 y′、y″ 与 y 本身同结构（$y'/y$、$y''/y$ 均为低次有理式），故特征点方程 y = 0、y′ = 0、y″ = 0 均可闭式求解，符号分析即可穷尽行为模式——这是「要素清单 + 符号分类」在指数族上完全可行的原因，也是该方法可迁移到后续章节的依据。
