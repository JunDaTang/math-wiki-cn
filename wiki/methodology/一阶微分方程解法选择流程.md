# 一阶微分方程解法选择流程

本流程把 9.1.1 的七类精确解法、隐式参数解法与近似方法整理为一棵决策树，回答「拿到一个一阶微分方程先做什么」的问题。

## 设计原则（why）

**先判类型，再动手**：有通用公式的类型（线性、恰当）优先；需化归的类型（齐次、伯努利、里卡蒂）其次；确无初等解时转近似。手册的编排次序（分离 → 齐次 → 恰当 → 积分因子 → 线性 → 伯努利 → 里卡蒂）本身就是一个「由特殊到一般、由免积分到需积分」的优先级序列，且第 2–4 步共享「恰当化」这一核心思想（齐次代换与线性积分因子本质都在制造恰当形式）。

## 流程

### 第 0 步：确认适定性

检查 $f(x,y)$ 在初始点邻域的连续性与关于 $y$ 的利普希茨条件（式 9.3），保证解存在唯一（见 [[一阶微分方程]]）。若区域含 $f$ 的极点，考虑交换变量 $\mathrm{d}x/\mathrm{d}y=1/f$（式 9.4）。

### 第 1 步：判断显式还是隐式

- **隐式** $F(x,y,y')=0$（式 9.14）→ 走 [[隐式微分方程的参数解法]]：若可写成 $x=\varphi(y,y')$ 或 $y=\psi(x,y')$，令 $y'=p$ 参数化；识别拉格朗日（式 9.15）与克莱罗（式 9.16）特殊情形——克莱罗有直线族通解 + 包络奇异解；最后用 $\partial F/\partial p=0$（式 9.17d）检查奇异解（见 [[奇异解奇异元素与奇异积分]]）。
- **显式** $y'=f(x,y)$ 或微分形式 $M\,\mathrm{d}x+N\,\mathrm{d}y=0$ → 继续。

### 第 2 步：显式方程按下列次序匹配

1. **变量可分离**（式 9.6a）→ [[分离变量法]]，通解式 9.7；**务必回查** $P(x)=0$、$N(y)=0$ 给出的常数奇异解。
2. **$M,N$ 同次齐次**（式 9.8）→ [[齐次微分方程]]：代换 $u=y/x$ 化归分离变量；回查 $x=0$。
3. **恰当性检验** $\partial M/\partial y=\partial N/\partial x$（式 9.9c）→ [[恰当微分方程]]：通解 $\Phi=C$，$\Phi$ 用折线积分式 9.9e（即 8.3.4.4 的 [[原函数折线构造法]]）。
4. **不恰当** → 试 [[积分因子]]：解式 9.10b 的偏微分方程比原方程更难，只试特殊形式 $\mu(x),\mu(y),\mu(xy),\mu(x^2+y^2)$。
5. **线性** $y'+P(x)y=Q(x)$（式 9.11a）→ [[一阶线性微分方程]]：积分因子 $e^{\int P\mathrm{d}x}$，套通解公式 9.11c；若已知一或两个特解，用式 9.11d/e 免积分组合。
6. **伯努利** $y'+Py=Qy^n$（式 9.12）→ [[伯努利微分方程]]：$z=y^{1-n}$ 化线性。
7. **里卡蒂** $y'=Py^2+Qy+R$（式 9.13a）→ [[里卡蒂微分方程]]：已知正规形式特解时走方法 1（化一阶线性）；否则方法 2（$y=-v'/(Pv)$ 化二阶线性，式 9.13h）。两法取舍见 [[里卡蒂方程两种化归方法比较]]。

### 第 3 步：无解析解时转近似

- [[皮卡逐次逼近法]]（式 9.20b 不动点迭代，存在性定理条件下收敛）；
- [[微分方程的级数解法]]（式 9.21 泰勒展开或待定系数，注意「级数可能不表示函数本身」的收敛性警示）；
- 方向场折线图解法（9.1.1.5.3，见 [[方向场与积分曲线]]）；
- 数值解（原书指向 19.4，未入库）：当方程不属于已知解析解的特殊情形，或 $f(x,y)$ 关于 $y$ 非线性、太复杂时使用。

### 第 4 步（可选）：奇点分析

若关心解在 $f$ 无定义点附近的行为，用特征方程式 9.18d 做六类奇点分类；一般函数之比用近似方程奇点保持定理（式 9.19c）判断，注意中心/焦点与 $ae-bc=0$ 两类例外。见 [[微分方程的奇点及其分类]]。
