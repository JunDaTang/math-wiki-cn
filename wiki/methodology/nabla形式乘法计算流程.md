# nabla 形式乘法计算流程

## 为什么用这个方法

∇ 形式乘法把向量分析恒等式的推导**归结为向量代数重排**：∇ 作为符号向量参与标量乘、点乘、叉乘，配以 ↓ 标记控制作用对象，即可避免逐分量展开的繁琐计算。数学手册(原书第10版) 13.2.6.2 的例 B 即用此法，从三重积分解 $\vec b(\vec a\vec c) = (\vec a\vec b)\vec c + \vec a\times(\vec b\times\vec c)$ 一步导出标量积梯度的四项展开。

## 步骤

1. **改写为 ∇ 形式**：按约定 (13.68a–d) 把 grad → ∇、div → ∇·、rot → ∇×（复合算子从右向左逐个替换）。
2. **乘积拆分**：若 ∇ 作用于乘积，按乘积法则 (13.70) 对每个因子轮流加 ↓ 标记，拆成诸项之和。
3. **向量代数重排**：在每一项中，用向量代数恒等式（如 $\vec b(\vec a\vec c)$ 的分解）重排乘积，使 ∇ 只作用于带标记的因子。
4. **施行形式微分**：按 ∇ 的定义 (13.67) 对被标记因子求偏导（其余变量视为常数）。
5. **删去标记并还原记号**：删去 ↓，把 ∇ 形式按 (13.68a–d) 还原为 grad/div/rot，得到目标恒等式。

## 示例（例 B 的推导）

目标：grad(V⃗₁V⃗₂)（V⃗₁V⃗₂ 并置为标量积）。

先拆分：∇(V⃗₁V⃗₂) = ∇(↓V⃗₁ V⃗₂) + ∇(V⃗₁ ↓V⃗₂)。对第一项，用 $\vec b(\vec a\vec c)$ 分解把 V⃗₂(∇V⃗₁) 重排为 (V⃗₂∇)V⃗₁ + V⃗₂×(∇×V⃗₁)；第二项同 理。合计四项：

$$\operatorname{grad}(\vec V_1\vec V_2) = (\vec V_2\operatorname{grad})\vec V_1 + \vec V_2\times\operatorname{rot}\vec V_1 + (\vec V_1\operatorname{grad})\vec V_2 + \vec V_1\times\operatorname{rot}\vec V_2.$$

复算无误，见 [[findings/式13-67至13-71c梯度算子与运算法则转录复算]]。

## 辅助核验：内部一致性检验法

对坐标系公式，可用一般正交系公式 (13.79a)（D 相当于拉梅系数乘积 h₁h₂h₃）**特化各坐标系度规**来核验：

- 笛卡儿：h_x = h_y = h_z = 1；
- 柱面：h_ρ = 1, h_φ = ρ, h_z = 1；
- 球面：h_r = 1, h_ϑ = r, h_φ = r sin ϑ。

本节即以此法确认 (13.76)(13.77) 逐项吻合，同时发现 (13.78) 球面末项系数疑缺平方（特化应得 $\frac{1}{r^2\sin^2\vartheta}$，转写本作 $\frac{1}{r^2\sin\vartheta}$），见 [[queries/式13-78球面拉普拉斯末项sinϑ疑缺平方]]。

## 局限

- 该流程是**形式演算**：∇ 的分量是偏导算子，与函数不可交换；重排时必须保持 ∇ 在被作用因子之前，且 ∇ 只作用于带 ↓ 标记的因子。
- ∇ 的笛卡儿定义 (13.67) 依赖笛卡儿坐标系；曲线坐标系中的 ∇ 分量式本手册本节未展开。
- 由此得到的向量恒等式在笛卡儿分量意义下成立；曲线坐标下分量式 ΔV⃗ 非协变。
