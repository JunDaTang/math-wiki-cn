# 线性方程组的不动点迭代解法

本方法是压缩映射原理（[[concepts/巴拿赫不动点定理]]）的第一个应用（手册 12.2.2.4 第 1 部分）：把 $(n,n)$ 线性方程组化为 $\mathbb{F}^n$（$\mathbb{R}^n$ 或 $\mathbb{C}^n$）上的不动点问题，从任意点出发迭代求解。其原型与手册 19.2.1（未入库）衔接。

## 步骤（式 12.62–12.65 转录）

给定线性方程组：

```
(12.62a)  a_j1 x_1 + a_j2 x_2 + ⋯ + a_jn x_n = b_j    (j = 1..n)
```

根据 19.2.1 变换成等价方程组（转写形式如下，疑有讹误，见下）：

```
(12.62b)  x_1 − (1−a_11)x_1 + a_12 x_2 + ⋯ + a_1n x_n = b_1
          x_2 + a_21 x_1 − (1−a_22)x_2 + ⋯ + a_2n x_n = b_2
          ⋯
          x_n + a_n1 x_1 + a_n2 x_2 + ⋯ − (1−a_nn)x_n = b_n
```

定义算子 $T:\mathbb{F}^n\to\mathbb{F}^n$：

```
(12.63)   Tx = ( x_1 − Σ_k a_1k x_k + b_1 , ⋯ , x_n − Σ_k a_nk x_k + b_n )ᵀ
(12.64)   Tx = x
```

于是方程组变成距离空间 $\mathbb{F}^n$ 中的不动点问题 (12.64)，其中赋以欧几里得距离 (12.43)、最大距离 (12.44) 或绝对值距离 (12.45)。如果三个数

```
(12.65)   √( Σ_{j,k=1}^n |a_jk|² )、  max_j Σ_k |a_jk|、  max_k Σ_j |a_jk|
```

中有一个小于 1，那么 $T$ 称为压缩算子（转写如此；下述复算表明判据对象疑应为 $\delta_{jk}-a_{jk}$，即 $I-A$）。根据巴拿赫不动点定理，方程组恰有一个不动点（即解），它是从 $\mathbb{F}^n$ 任意点出发的迭代序列的按分量收敛的极限。

## 复算警示：判据对象应为 $I-A$

由 (12.63)，$Tx-Ty=(I-A)(x-y)$。故在三种距离下 $T$ 为压缩的充分条件分别是（与距离的配对见 [[concepts/Rn上的三种距离]]）：

$$
\sqrt{\textstyle\sum_{j,k}\lvert\delta_{jk}-a_{jk}\rvert^2}<1,\qquad
\max_j\sum_k\lvert\delta_{jk}-a_{jk}\rvert<1,\qquad
\max_k\sum_j\lvert\delta_{jk}-a_{jk}\rvert<1,
$$

而非 (12.65) 转写所示的 $\lvert a_{jk}\rvert$ 型三数。**反例**：取 $A=-\varepsilon I$（$0<\varepsilon<1/\sqrt n$），转写版三数为 $\varepsilon\sqrt n<1$、$\varepsilon<1$、$\varepsilon<1$ 全部满足，但 $Tx=(1+\varepsilon)x+b$ 把任一上述距离放大 $1+\varepsilon$ 倍，迭代 $x_{n+1}=(1+\varepsilon)x_n+b$ 对 $x_0\neq-b/\varepsilon$ 发散。详见 [[findings/式12-62至12-65线性方程组压缩判据复算与反例]] 与 [[queries/式12-65压缩判据对象疑为I减A]]。

另：(12.62b) 转写各行经化简与原方程 (12.62a) 完全相同，作为「等价变换」疑丢失了「$x_j=$」的移项结构（应为 $x_j=(1-a_{jj})x_j-\sum_{k\ne j}a_{jk}x_k+b_j$），见 [[queries/式12-62b等号与符号转写疑误]]。
