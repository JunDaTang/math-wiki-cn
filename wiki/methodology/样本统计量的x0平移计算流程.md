# 样本统计量的 x₀ 平移计算流程

## 为何需要（rationale）

在较长的测量序列中，$x_i$ 常为多位数且只有最后几位数字不同（如扬声器算例的 0.98–1.02）。直接按定义计算 $\bar{x}$ 与 $s^2$ 需反复处理大数；若先减去一个接近均值的估计值 $x_0$，后续运算只涉及小数，显著简化算术。手册为此给出恒等式 (16.121c–d) 与 (16.122c)，均经代数验证（见 [[findings/式16-119至16-124样本随机向量与统计量定义转录复算]]）。

## 流程

1. **选取估计值 $x_0$**：可任意选取，但应尽可能接近平均值（如测量序列的代表性整数或整十分位）。
2. **平移**：计算 $z_i = x_i - x_0$（16.121c）。
3. **均值**：$\bar{x} = x_0 + \dfrac{1}{n}\sum z_i = x_0 + \bar{z}$（16.121d）。
4. **方差**：$s^2 = \dfrac{\sum z_i^2 - \bar{z}\sum z_i}{n-1} = \dfrac{\sum z_i^2 - n(\bar{x}-x_0)^2}{n-1}$（16.122c）。
5. **特例 $x_0 = \bar{x}$**：此时 $\bar{z} = 0$，交叉项 $\bar{z}\sum z_i$ 消失，公式最简。

## 舍入陷阱（实证警示）

若在第 4 步代入**舍入后的** $\bar{x} - x_0$，结果会偏离直接法。扬声器算例（$x_0 = 1.00$，精确 $\bar{z} = 0.04/15 = 0.002667$）中：

- 精确路径：$s^2 = 1.2095\cdot 10^{-4}$（与直接法一致）；
- 舍入路径（$\bar{x}-x_0$ 取 0.0027）：$s^2 = 1.2076\cdot 10^{-4}$——原文恰好以「或」并列了这两个值。

因此执行本流程时应使用未舍入的 $\bar{z} = \frac{1}{n}\sum z_i$ 或保留足够位数。复算细节见 [[findings/扬声器气隙感应样本统计量算例复算]]，矛盾追踪见 [[queries/扬声器算例方差双值1-2095与1-2076之辨]]。
