# 欧拉多边形法迭代流程

**目的与原理**：初值问题 (19.93) 的解满足积分表达式 (19.95)；对单步区间 [x₀, x₀+h] 以矩形公式近似积分（被积函数取左端点值，式 (19.96)）即得 (19.97)。几何上沿解曲线切线方向推进形成折线，用欧拉法可以快速看到解曲线的近似形状。

**步骤**：

1. 选定步长 h，生成等距节点 x_i = x₀ + ih（式 19.94）。
2. 置初值 y₀。
3. 对 i = 0, 1, 2, … 迭代：y_{i+1} = y_i + h·f(x_i, y_i)（式 19.97）。
4. 误差监控：单步误差为 h² 阶（对比泰勒展开 (19.98) 中被舍弃的 y″(ξ)h²/2 项）；源文经验：步长减半可使近似值的误差减半。

**适用与局限**：一阶方法（一阶收敛、一阶相容）；线性试验问题上绝对稳定区间 −2 ⩽ λh ⩽ 0；亦用于为多步法生成 k 个起步值。与四阶龙格—库塔法的对比见 [[comparisons/欧拉多边形法与四阶龙格—库塔法比较]]。概念页见 [[concepts/欧拉多边形法]]。
