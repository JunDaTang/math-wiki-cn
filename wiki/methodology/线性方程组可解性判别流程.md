# 线性方程组可解性判别流程

## 为何不止用秩判据

式 (4.178) 的秩判据（rank(A) = rank(A, a) 定相容；r = n 定唯一）理论上完备，但单独计算两个秩并不经济。高斯消元与选主元法在判定可解性的同时就完成解的构造：行运算与换轴都不改变 (A, a) 的秩（源明言高斯步骤「基本上是行运算，所以不影响矩阵 (A, a) 的秩」），因此算法终型与秩判据必然一致。

## 流程

1. **写出增广矩阵** (A, a)：常数项列向量 a 作为第 n + 1 列（注意源转写作「行」系讹误，见 [[queries/增广矩阵第n+1行是否应为第n+1列]]）。
2. **选择途径并执行**：
   - 途径 A（高斯消元）：逐列消元至行阶梯形（式 4.186）；
   - 途径 B（选主元法）：改写为 y = Ax − a 并换轴（式 4.182）。
3. **判定**：
   - 高斯：情形 1（某个 a_μ^(r−1) ≠ 0, μ > r）无解；情形 2a（r = n）唯一解；情形 2b（r < n）n − r 个自由参数；
   - 选主元：情形 1（所有 y 可换轴）有解；情形 2（y_σ = Σλ_μy_μ + λ₀）当且仅当 λ₀ = 0 有解。
4. **构造解**：高斯从行阶梯形的最后一行开始逐次回代；选主元代 y = 0、自由 x 取参数。
5. **齐次组**：平凡解恒存在；r < n 时按式 (4.180)–(4.181) 构造 n − r 个基本解（见 [[concepts/解的基本系]]）。
6. **超定组（m > n）**：一般无满足所有方程的精确解，转[[concepts/线性最小二乘问题]]；rank(A) = n 用正规方程组或 QR 正交化，rank(A) < n（秩亏）用正则化。
7. **验算**：解回代原方程组；参数解代入核验。
