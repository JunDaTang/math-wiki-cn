# 四阶龙格—库塔法单步计算流程

**目的与原理**：在 (x₀, y₀) 与 (x₀+h, y₁) 之间引入辅助点，以四个斜率的加权平均代替单一斜率（欧拉法），将单步误差从 O(h²) 提升到 O(h⁵)。辅助点的数目与排列决定龙格—库塔法的阶；本流程为四阶格式 (19.99)。

**步骤**（从 x₀ 到 x₁ = x₀ + h）：

1. k₁ = h·f(x₀, y₀)
2. k₂ = h·f(x₀ + h/2, y₀ + k₁/2)
3. k₃ = h·f(x₀ + h/2, y₀ + k₂/2)
4. k₄ = h·f(x₀ + h, y₀ + k₃)
5. y₁ = y₀ + (1/6)(k₁ + 2k₂ + 2k₃ + k₄)
6. 以 (x₁, y₁) 为新起点按同样格式进行下一步。

**验证算例**（本维基复算通过）：y′ = ¼(x² + y²)，y(0) = 0，h = 0.5：k₁ = 0、k₂ = 0.00781250、k₃ = 0.00781441、k₄ = 0.03125763，y₁ = 0.01041858（准确值 0.01041860）。

**注记**：对 y′ = f(x) 化为辛普森公式；高阶方程化为一阶方程组后各方程可并行推进（源文注记 3）。见 [[concepts/龙格—库塔法（四阶）]]、[[findings/式19-99四阶龙格—库塔格式与算例复算]]。
