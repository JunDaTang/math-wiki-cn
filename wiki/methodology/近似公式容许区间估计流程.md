# 近似公式容许区间估计流程

## 目的（为什么）

泰勒截断近似（如 sin x ≈ x、√(a²+x) ≈ a + x/(2a)）只在展开中心的邻域内有效；实际使用时需要回答「自变量在多大范围内，近似值的相对误差不超过给定精度（0.1%、1%、10%）」。表 7.3 就是按此流程批量制作的。它是 [[微分近似计算流程]]（一阶、绝对误差）向高阶、相对误差、系统化表格的推进。

## 步骤（怎么做）

1. **选定误差基准**：以**近似值**为基准定义相对误差：|f(x) − P(x)|/|P(x)| ⩽ δ（P 为近似多项式）。这与以真值为基准的定义在界值上有系统差异，必须先统一约定。
2. **建立精确界**：不能只用下一项（误差首项）近似误差，而应建立含全部高阶项的精确不等式（例如对 sin x ≈ x 解 |sin x − x|/|x| ⩽ δ；对 cos x ≈ 1 解 (1 − cos x)/1 ⩽ δ 即 cos x ⩾ 1 − δ）。
3. **解不等式**：得上、下容许界。注意界常不对称（√(a²+x)、1/√(a²+x)、eˣ、ln(1+x) 各行），原因是下一项符号固定而高阶项在两侧贡献不同。
4. **单位换算**：三角各行同时给出弧度与度数（乘以 180/π），供工程使用。
5. **交叉检验**：检查三档精度（0.1% → 1% → 10%）界值的单调相容性与「下一项」符号一致性；发现不相容即定位勘误——例如 cos x ≈ 1 的 10% 界：0.451 rad = arccos 0.9 ≈ 25.84° 与表中 25.8° 相容，而 0.415 rad ≈ 23.8° 不相容，故源文「0.415」判定为「0.451」之误。
