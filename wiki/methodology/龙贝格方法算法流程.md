# 龙贝格方法算法流程

依据《数学手册(原书第10版)》19.3.4.1（公式 19.85–19.88）整理。方法目标：以尽可能少的函数值计算达到高精度——步长折半复用旧函数值，外推在不增加函数值的前提下提升误差阶。

## 第一步：确定梯形和序列

对步长 $h_i = (b-a)/2^i$（i = 0,1,…,m）(19.85)，据复化梯形公式 (19.76) 计算近似梯形和 $T(h_i)$。利用递归关系 (19.86)：

```latex
T(h_i) = T(h_{i−1}/2) = (h_{i−1}/2)[½f(a) + f(a + h_{i−1}/2) + f(a + h_{i−1}) + f(a + (3/2)h_{i−1})
        + f(a + 2h_{i−1}) + ⋯ + f(a + (2n−1)/2·h_{i−1}) + ½f(b)]
      = ½T(h_{i−1}) + (h_{i−1}/2) Σ_{j=0}^{n−1} f(a + h_{i−1}/2 + j·h_{i−1})
        (i = 1,…,m;  n = 2^{i−1})
```

要点：由 $T(h_{i-1})$ 计算 $T(h_i)$ 仅需在**新增插值节点**上计算函数值，旧值全部复用。

## 第二步：三角格式外推

令 $T_{0,i} = T(h_i)$（i = 0,1,…），递归计算 (19.87)：

```latex
T_{k,i} = T_{k−1,i} + (T_{k−1,i} − T_{k−1,i−1})/(4^k − 1)   (k = 1,…,m;  i = k, k+1, ⋯)
```

数值按**逐列方式**计算，排成三角格式 (19.88)：

```latex
T(h_0) = T_{00}
T(h_1) = T_{01}  T_{11}
T(h_2) = T_{02}  T_{12}  T_{22}
T(h_3) = T_{03}  T_{13}  T_{23}  T_{33}
⋯
```

## 第三步：停机准则

格式持续下去（对于给定的列数），直到**右边最下面的数值几乎相同**为止（源文「儿乎」疑为「几乎」，见 [[queries/19-3多处脱字脱数字之辨]]）。

## 结果解释与理论依据

- 第二列 $T_{1,i}$（i = 1,2,⋯）相应于由辛普森公式计算得到的值（算例经数值强验证，见 [[findings/正弦积分Si(1)算例全表复算]]）。
- 第 k 列误差阶 2k+2：$T_{k,i} = I + O(h_i^{2k+2})$ (19.92)。
- 外推系数的理论来源是梯形和误差的偶次幂渐近展开与线性消元，详见 [[concepts/外推原理]]；k=1 时 (19.87) 与 (19.91) 一致（$\alpha_1=-1/3$，$\alpha_2=4/3$，$4^1-1=3$）。

## 设计原理（why）

- **为何从梯形公式出发**：梯形和有系统的误差渐近展开 (19.89)（偶次幂），这是外推可行的前提；且步长折半递归 (19.86) 使函数值全部复用。
- **为何按列计算**：每列消去一个误差项，列内自上而下精度递增；右下角收敛快，天然给出停机准则。
- **为何系数取 $1/(4^k-1)$**：由消去 $h^{2k}$ 项的线性方程组决定（k=1 时解 $\alpha_1+\alpha_2=1$、$\alpha_1+\alpha_2/4=0$）。

## 算例

$I=\int_0^1 \frac{\sin x}{x}\,\mathrm{d}x$：4 级三角格式（$h_3=1/8$，共 9 个函数值）得 $T_{3,3}=0.94608307$（8 位精度），误差阶 $O((1/8)^8)\approx 6\cdot 10^{-8}$ 经验证（[[findings/正弦积分Si(1)算例全表复算]]）。
