# 连续分布标准化与查表流程

本方法概括 [[10-数学手册原书第10版--9-1624-连续分布--1ktbozm]]（16.2.4）将连续分布概率计算归结为「标准化 + 查表」的通行流程。**为什么**：手册的定位是快速查用，把每种分布的概率/分位数计算都归结到少量数值表（Φ 表与 χ²/F/t 分位数表），避免逐题积分。

## 流程

### 第一步：判定分布类型与参数

按题设识别随机变量服从的分布及其参数：正态 (μ, σ²)、对数正态 (μ_L, σ_L²)、指数 λ、韦布尔 (α, β[, γ])、χ²(n)、F(m₁, m₂)、t(m)。

### 第二步：正态型分布——标准化到 Φ

1. 对 [[正态分布]]：作变量代换 τ = (t−μ)/σ，把 F(x) 的计算转化为 [[标准正态分布]] 函数 Φ 的计算，概率用 (16.72)：P(a ⩽ X ⩽ b) = Φ((b−μ)/σ) − Φ((a−μ)/σ)；
2. 对 [[对数正态分布]]：先取对数再标准化，F(x) = Φ((log x − μ_L)/σ_L)（(16.79)）；
3. 查第 1458 页表 21.17：表中只给 x > 0 的值，x < 0 时用对称性 Φ(−x) = 1 − Φ(x)（(16.74)）。

### 第三步：误差积分记号换算（如需）

- Φ₀(x) = Φ(x) − 1/2（(16.75a)）；
- erf 与 Φ₀ 的换算按 (16.75b)——**注意该式存疑**（见 [[式16-75b误差函数被积函数疑为e负t平方]]），引用前须先澄清。

### 第四步：抽样分布——直接查分位数表

χ²、F、t 分布不经过 Φ，而是直接查分位数表，分位数满足 P(X > q) = α 型定义：

- χ²：P(X > χ²_{α,m}) = α（(16.92)），查表 21.18（第 1460 页）；
- F：分位数 t_{α,m₁,m₂}，查表 21.19（第 1461 页）；
- t：单侧 P(T > t_{α,m}) = α（(16.99a)）、双侧 P(|T| > t_{α/2,m}) = α（(16.99b)），查表 21.20（第 1463 页）——须先区分单侧/双侧。

### 第五步（涉及正态变量平方和时）：标度到 χ²

若 X₁, …, Xₙ 独立同服从 N(0, σ²)：

- ΣXᵢ² 的密度为 (1/σ²)·f_χ²(t/σ²)（(16.89)）；
- (1/n)ΣXᵢ² 的密度为 (n/σ²)·f_χ²(nt/σ²)（(16.90)）；
- √((1/n)ΣXᵢ²) 的密度按 (16.91)——**该式疑脱因子 n**（见 [[式16-91均方根密度疑脱因子n]]），使用前须核验。

## 适用边界

- 分位数的一般定义（P(X > q) = α）在原书 16.2.2.2 第 3 条，未入库（见 [[16-2-4未入库回指缺口]]）；
- 本流程仅覆盖 16.2.4 所列八种连续分布。
