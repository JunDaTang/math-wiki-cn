# 福特-富尔克森标号算法流程

《数学手册（原书第10版）》5.8.7 节给出的极大流判定算法的可执行流程。源文档转录中 x/y/Q/S/G 符号大量脱落，以下步骤中 [ ] 内为据上下文补回的符号。

## 目的（为什么）

给定运输网络 G（[[concepts/运输网络]]）与一个与容量相容的强度为 v₁ 的流 φ，回答两个问题：φ 是否极大？若不极大，能改进多少？其机制是为每个新获标号的顶点附带一个数 ε——沿已发现的标号通路到达该顶点时强度尚可增加的量的上界：前向沿未饱和弧受剩余容量 c(uᵢ) − φ(uᵢ) 限制，后向沿正流量弧受可回撤量 φ(uᵢ) 限制，故取 min。若汇点 S 最终获得标号，ε(S) 即当前可实现的最小改进量；若标号过程终止而 S 未获标号，则流极大（手册以断言给出，未附证明——通行文献中此判定由极大流-极小割定理保证，该定理未收录于本源）。

## 步骤（转录 + 符号补全）

```
输入：运输网络 G（源点 Q、汇点 S、弧容量 c、特殊弧 u₁），与容量相容的强度为 v₁ 的流 φ
a) 对源点 Q 标号，并令 ε(Q) = ∞
b) 如果存在弧 uᵢ = (x, y)，其中 x 被标号而 y 未标号，并且 φ(uᵢ) < c(uᵢ)，
   那么给 y 标号，并且令 ε(y) = min{ε(x), c(uᵢ) − φ(uᵢ)}，
   然后重复步骤 b)，不然实施步骤 c)。
c) 如果存在弧 uᵢ = (x, y)，其中 x 未标号而 y 被标号，并且 φ(uᵢ) > 0 以及 uᵢ ≠ u₁，
   那么给 x 标号，令 ε(x) = min{ε(y), φ(uᵢ)}，
   并返回继续实施步骤 b)（如果此步骤可行），不然算法结束。
输出判定：
- 若 G 的汇点 S 被标号，则 G 中的流可以改进适当的量 ε(S)；
- 若汇点未被标号，则这个流是极大的。
```

## 转录疑点与解释

- **标号对象**：原文写作「给 (x,y) 标号」，但 ε 的定义分别是 ε(y)（步骤 b）与 ε(x)（步骤 c），故标号对象应为顶点（b 中为 y，c 中为 x），「(x,y)」当为弧指称的错位。
- **循环结构**：步骤 c) 末尾「并返回继续实施步骤 b)（如果此步骤可行），不然算法结束」表述含糊；据步骤 b) 的「不然实施步骤 c)」，两步构成 b↔c 交替循环，直至两步均无可标号的弧时结束。
- **u₁ 的排除**：步骤 c) 要求 uᵢ ≠ u₁。若采纳 u₁ = (S,Q) 回弧重构（见 [[queries/运输网络定义弧u1是否为s到q回弧]]），则不排除 u₁ 时汇点 S 会在首轮后向标号中被立即标号（φ(u₁) = 强度 > 0 时），判定失效——该排除是重构假设的关键内部证据（推断）。
- **前提句主语脱落**：原文「是运输网络，φ 是与容量相容的强度为 v₁ 的流」缺主语符号，据文意补为 G。
