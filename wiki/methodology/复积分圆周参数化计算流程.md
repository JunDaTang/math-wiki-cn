# 复积分圆周参数化计算流程

用圆周参数化 + 棣莫弗（de Moivre）公式把复闭路积分化为实三角积分并逐项求值的流程。适用于被积函数为 $(z-z_0)^n$ 型（$n\in\mathbb{Z}$）、路径为以 $z_0$ 为心的圆周的积分，以及一切可借同一化简完成的圆周积分。

## 为什么有效

当被积函数没有可用的原函数（如负幂情形）或需要直接验证时，参数化把 $\mathrm{d}z$ 换成 $r_0(-\sin t + \mathrm{i}\cos t)\,\mathrm{d}t$，幂 $(\cos t + \mathrm{i}\sin t)^n$ 由棣莫弗公式化为 $\cos nt + \mathrm{i}\sin nt$，整个被积式化为实三角函数的线性组合，可用初等积分逐项求值。该流程同时显式暴露「只有 $n=-1$ 项留下 $2\pi\mathrm{i}$」这一事实——它是留数定理（14.3.5.5，未入库）的特例预演。

## 步骤

1. **参数化圆周**（逆时针）：$z = z_0 + r_0(\cos t + \mathrm{i}\sin t)$，$0\leqslant t\leqslant 2\pi$。
2. **微分**：$\mathrm{d}z = r_0(-\sin t + \mathrm{i}\cos t)\,\mathrm{d}t$。
3. **化简幂**（棣莫弗公式）：$(z-z_0)^n = r_0^n(\cos nt + \mathrm{i}\sin nt)$。
4. **乘开被积式**：$(\cos nt + \mathrm{i}\sin nt)(-\sin t + \mathrm{i}\cos t) = \mathrm{i}\cos[(n+1)t] - \sin[(n+1)t]$。
5. **逐项积分**：$n\neq-1$ 时 $\int_0^{2\pi}\cos[(n+1)t]\,\mathrm{d}t = \int_0^{2\pi}\sin[(n+1)t]\,\mathrm{d}t = 0$；$n=-1$ 时被积式恒为 $\mathrm{i}$，积分值为 $2\pi\mathrm{i}$。

## 验证例（14.2.1.2 第 3 条例）

$I = \oint_{|z-z_0|=r_0} (z-z_0)^n\,\mathrm{d}z = 0$（$n\neq-1$）；$2\pi\mathrm{i}$（$n=-1$）。逐步复算通过，见 [[findings/式14-33a至14-43复积分定义定理与例题转录复算]]。

## 边界与注意

- 仅适用于可显式参数化的路径；一般曲线应按 [[concepts/复定积分]] 的 (14.38a) 化为两个实的第二型线积分。
- 定向反转（顺时针）会使结果变号；本流程默认逆时针，与 [[concepts/柯西积分定理]]、[[concepts/柯西积分公式]] 的定向约定一致。
