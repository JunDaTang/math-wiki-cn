# 上半平面围道留数计算流程

## 为什么（rationale）

计算 ∫_{−∞}^{+∞} f(x)dx 型实反常积分时，被积函数的原函数往往难以求得；把实轴区间用上半平面的大半圆弧闭合为围道后，可用 [[concepts/留数定理]] 把积分化为上半平面奇点处留数的有限和。闭合弧段的贡献由 f 的衰减条件控制——这正是 (14.56) 把「f(1/z) = 0 在 z = 0 有重数 m ⩾ 2 的根」列为前提的原因：该条件等价于 f 在无穷远处至少二阶衰减，使弧段积分趋于零。

## 流程（怎么做）

1. **检验衰减条件**：计算 f(1/z)，确认 z = 0 是其重数 m ⩾ 2 的根。例：f = 1/(1+z²)³ 时 f(1/z) = z⁶/(1+z²)³，z = 0 为六重根，通过。
2. **定位奇点**：找出上半平面的奇点 z₁, …, zₙ（应只有有限个），并判定各极点的阶数（判据见 [[concepts/解析函数的奇点]]）。
3. **计算留数**：一阶极点用极限式，m 阶极点用 (14.54b) 导数式（见 [[concepts/留数]]）。
4. **套用 (14.56)**：积分值 = 2πi × 留数和。

## 适用边界

- 实轴上有极点时本流程不适用，须改用 [[methodology/实轴极点缩进围道计算流程]]；
- 被积函数含振荡因子 e^{iαx} 时，弧段趋零改由 [[concepts/若尔当引理]] 保证，衰减条件相应放宽为 f 一致趋零即可；
- 围道需旋转（如菲涅耳型 e^{−z²}）时改用 [[methodology/扇形围道指数估计流程]]。

## 实例

14.4.2 例：∫_{−∞}^{+∞} dx/(1+x²)³ = 2πi·(−3i/16) = 3π/8。复算见 [[findings/式14-56至14-62及ez例复积分计算实积分转录复算]]。
