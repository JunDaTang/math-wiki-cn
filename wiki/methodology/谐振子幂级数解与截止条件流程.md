# 谐振子幂级数解与截止条件流程

## 目的（why）

说明「截止条件等价于能量量子化」：若幂级数不在某项截止，H(y) 在大 y 处按 e^{y²} 量级增长，会淹没 Ψ = e^{−y²/2}H 中的衰减因子，使解不平方可积、无物理意义；只有当级数截止为多项式（埃尔米特多项式）时解才可接受，而截止恰好迫使参数 λ 取离散值 2n+1，从而能量只能取 Eₙ = ℏω(n+½)。这是谐振子能级量子化的来源。

## 流程（依据 9.142–9.147）

1. 写出带二次势 kx²/2 的定常薛定谔方程（9.143a）。
2. 无量纲化：y = x√(mω/ℏ)、λ = 2E/ℏω（9.143b/c），化为韦伯微分方程简单形式 Ψ″ + (λ−y²)Ψ = 0（9.143d）。
3. 剥离高斯因子：设 Ψ = e^{−y²/2}H(y)，得 H″ − 2yH′ + (λ−1)H = 0（9.144c）。
4. 幂级数 H = Σaᵢyⁱ 代入（9.145a），比较 y^j 系数得递推公式

```latex
(j+2)(j+1)a_{j+2}=[2j-(\lambda-1)]a_j\quad(j=0,1,2,\dots)   % 9.145c
```

   y 偶次幂系数从 a₀ 出发、奇次幂从 a₁ 出发，a₀、a₁ 可任意选择。
5. 施加截止（有尽）条件：对某个 n 要求 aₙ ≠ 0 且 a_{n+2} = a_{n+4} = … = 0，另一条链取 a_{n∓1} = 0。由递推公式（j = n 时，9.146a），这等价于 2n − (λ−1) = 0，即 λ = 2n+1（9.146b）。
6. 取 aₙ = 2ⁿ、aₙ₋₁ = 0 得埃尔米特多项式（9.146c）；本征函数 Ψₙ = Nₙe^{−y²/2}Hₙ(y)，由 ∫Ψₙ²dy = 1 定出 Nₙ² = (1/2ⁿn!)√(α/π)（9.147a,b）。
7. 能谱：Eₙ = ℏω(n+½)，等距（9.147c）。
