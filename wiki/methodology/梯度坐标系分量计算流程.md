# 梯度坐标系分量计算流程

本流程依据《数学手册(原书第10版)》13.2.2.5，给出 [[concepts/梯度]] 在笛卡儿、柱面、球面与一般坐标系中的分量公式（式 13.36–13.39b），并说明度规因子的来历。

## 为什么需要度规因子（原理）

梯度是几何对象，其沿某单位方向 $\vec{e}_i$ 的分量等于「沿该方向**单位弧长**的变化率」。在曲线坐标 $q_i$ 下，坐标改变 $\mathrm{d}q_i$ 时沿坐标线的实际位移不是 $\mathrm{d}q_i$，而是

$$\mathrm{d}\ell_i = \left| \frac{\partial \vec{r}}{\partial q_i} \right| \mathrm{d}q_i = h_i\, \mathrm{d}q_i,$$

其中 $h_i = \left| \partial \vec{r} / \partial q_i \right|$ 为度规因子（拉梅系数）。因此

$$\operatorname{grad}_i U = \frac{1}{h_i} \frac{\partial U}{\partial q_i}, \qquad \operatorname{grad} U = \sum_i \operatorname{grad}_i U\, \vec{e}_i.$$

例如柱面坐标中 $\varphi$ 方向的弧长是 $\rho\,\mathrm{d}\varphi$ 而非 $\mathrm{d}\varphi$，故出现 $1/\rho$ 因子；球面坐标中 $\varphi$ 方向的弧长是 $r \sin\vartheta\,\mathrm{d}\varphi$，故出现 $1/(r\sin\vartheta)$ 因子。这解释了为何梯度分量不简单地等于偏导数。

## 流程

1. 写出坐标映射 $\vec{r}(q_1, q_2, q_3) = x(q_1,q_2,q_3)\,\vec{i} + y(q_1,q_2,q_3)\,\vec{j} + z(q_1,q_2,q_3)\,\vec{k}$；
2. 计算度规因子 $h_i = \left| \partial \vec{r} / \partial q_i \right|$，并取坐标线单位方向 $\vec{e}_i = \frac{1}{h_i} \frac{\partial \vec{r}}{\partial q_i}$（坐标系须正交，见下文警示）；
3. 按分量公式计算 $\operatorname{grad}_i U = \frac{1}{h_i} \frac{\partial U}{\partial q_i}$；
4. 组装 $\operatorname{grad} U = \sum_i \operatorname{grad}_i U\, \vec{e}_i$。

## 四套公式

**1. 笛卡儿坐标系**（$h_x = h_y = h_z = 1$）：

$$\operatorname{grad} U = \frac{\partial U(x,y,z)}{\partial x}\,\vec{i} + \frac{\partial U(x,y,z)}{\partial y}\,\vec{j} + \frac{\partial U(x,y,z)}{\partial z}\,\vec{k}. \tag{13.36}$$

**2. 柱面坐标系**（$x = \rho\cos\varphi,\ y = \rho\sin\varphi,\ z = z$；$h_\rho = 1,\ h_\varphi = \rho,\ h_z = 1$）：

$$\operatorname{grad} U = \operatorname{grad}_\rho U\,\vec{e}_\rho + \operatorname{grad}_\varphi U\,\vec{e}_\varphi + \operatorname{grad}_z U\,\vec{e}_z \tag{13.37a}$$

$$\operatorname{grad}_\rho U = \frac{\partial U}{\partial \rho}, \quad \operatorname{grad}_\varphi U = \frac{1}{\rho} \frac{\partial U}{\partial \varphi}, \quad \operatorname{grad}_z U = \frac{\partial U}{\partial z}. \tag{13.37b}$$

（原文 (13.37a) 作「+ +」，疑重复加号，见 [[queries/式13-37a柱面梯度公式疑重复加号]]。）

**3. 球面坐标系**（$x = r\sin\vartheta\cos\varphi,\ y = r\sin\vartheta\sin\varphi,\ z = r\cos\vartheta$；$h_r = 1,\ h_\vartheta = r,\ h_\varphi = r\sin\vartheta$）：

$$\operatorname{grad} U = \operatorname{grad}_r U\,\vec{e}_r + \operatorname{grad}_\vartheta U\,\vec{e}_\vartheta + \operatorname{grad}_\varphi U\,\vec{e}_\varphi \tag{13.38a}$$

$$\operatorname{grad}_r U = \frac{\partial U}{\partial r}, \quad \operatorname{grad}_\vartheta U = \frac{1}{r} \frac{\partial U}{\partial \vartheta}, \quad \operatorname{grad}_\varphi U = \frac{1}{r \sin\vartheta} \frac{\partial U}{\partial \varphi}. \tag{13.38b}$$

（原文坐标定义中「sin fJ」为 $\vartheta$ 的 OCR 误读，见 [[queries/13-2-2全节系统性转写讹误清单]]。）

**4. 一般直角坐标系**（$\vec{r}(\xi,\eta,\zeta) = x(\xi,\eta,\zeta)\,\vec{i} + y(\xi,\eta,\zeta)\,\vec{j} + z(\xi,\eta,\zeta)\,\vec{k}$）：

$$\operatorname{grad} U = \operatorname{grad}_\xi U\,\vec{e}_\xi + \operatorname{grad}_\eta U\,\vec{e}_\eta + \operatorname{grad}_\zeta U\,\vec{e}_\zeta \tag{13.39a}$$

$$\operatorname{grad}_\xi U = \frac{1}{\left| \frac{\partial \vec{r}}{\partial \xi} \right|} \frac{\partial U}{\partial \xi}, \quad \operatorname{grad}_\eta U = \frac{1}{\left| \frac{\partial \vec{r}}{\partial \eta} \right|} \frac{\partial U}{\partial \eta}, \quad \operatorname{grad}_\zeta U = \frac{1}{\left| \frac{\partial \vec{r}}{\partial \zeta} \right|} \frac{\partial U}{\partial \zeta}. \tag{13.39b}$$

**适用范围警示**：(13.39b) 隐含坐标系**正交性**假设。对非正交坐标系，梯度分量含交叉项，须借助（逆）度规张量表出，不等于各坐标方向偏导数的简单缩放。原文是否隐含正交性假设见 [[queries/一般直角坐标系是否限于正交坐标系]]。

## 验证方法

- **链式法则验证**：以柱面坐标为例，$\frac{\partial U}{\partial \rho} = \cos\varphi\, U_x + \sin\varphi\, U_y$ 恰为梯度在 $\vec{e}_\rho = \cos\varphi\,\vec{i} + \sin\varphi\,\vec{j}$ 上的分量；$\frac{1}{\rho}\frac{\partial U}{\partial \varphi} = -\sin\varphi\, U_x + \cos\varphi\, U_y$ 恰为在 $\vec{e}_\varphi = -\sin\varphi\,\vec{i} + \cos\varphi\,\vec{j}$ 上的分量。
- **方向导数一致性**：对任意单位向量 $\vec{c}^0$，用式 (13.34) 检验 $\vec{c}^0 \cdot \operatorname{grad} U$ 与坐标选取无关。
