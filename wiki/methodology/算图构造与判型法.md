# 算图构造与判型法

**目的与理由**：算图的用途是把公式求解变为图上读值，因此构造算图的第一问题是「给定方程，选哪种图」。《数学手册(原书第10版)》2.19 的隐含方法论是**由方程的代数形状判定算图类型**——能写成什么形式，就能用什么图；而标度与分度的选择决定图的可读性。本页把该节材料整理为判定流程。

## 判定流程

**第一步：变量个数。**

- 恰三个变量 → 第二步。
- 三个以上变量 → 先用**辅助变量分解**（2.19.4）：分解为若干三元公式，每个辅助变量恰含于两个新方程；全部以贯线算图表示，公共辅助变量共用同一标度（见 [[findings/多变量公式的辅助变量分解法]]）。分解出的每个三元公式回到第二步。

**第二步：三元方程的形式。**

1. 一般 $F(x, y, z) = 0$ → **网络算图**：等高线构造（式 2.292，图 2.108，见 [[findings/网络算图的等高线构造与欧姆定律算例]]）。
2. $x\,\varphi(z) + y\,\psi(z) + \chi(z) = 0$ 型（等分标度，式 2.293）→ 由**直线**组成的网络算图。
3. $f(z_2)\varphi(z_1) + g(z_3)\psi(z_1) + \chi(z_1) = 0$ 型（函数标度，式 2.294）→ 平行于坐标轴的两族曲线 + 任意一族直线（见 [[findings/标度化直原理与对数直线算图]]）。
4. 能化为行列式 (2.296) = 0 → **贯线算图**，进入第三步。

**第三步：贯线算图构型**（由化得的方程型决定，详见 [[comparisons/贯线算图三种构型比较]]）。

- $\sum_i C_i/\varphi_i(z_i) = 0$（$\sum C_i = 0$）→ 共点三直线标度（2.19.3.1，[[findings/共点三直线标度与调和平均关系]]）。
- $f(z_1) \cdot g(z_3) = h(z_2)$ → 两平行直线 + 一斜直线标度（2.19.3.2，[[findings/两平行一斜标度构型与极角算例]]）。
- $E_1 f(z_1) + E_2 g(z_2)\frac{E_1}{E_2} h(z_3) + E_1 k(z_3) = 0$ → 两平行直线 + 曲线标度（2.19.3.3，[[findings/两平行与曲线标度构型及三次方程算例]]）。

## 标度与分度的选择理由

标度（[[concepts/标度]]，手册 2.17.1）是全流程共享的设计自由度，2.19 各处给出的选择理由：

1. **化直**：对数标度把 $U = RI$ 化为 $x + y = \log U$ 的直线族（式 2.294 的特例）——直线比曲线易画、易插值。
2. **改域**：同一网络算图换定义域（如 $0 < I < 1$）时等高线标记相应调整（$U \to U/10$），无需重画整图。
3. **压缩与集中**：分度比 $E_2 : E_1$ 可使第三标度接近或集中于一点（式 2.300c），避免标度过长超出图面。
4. **避开极点**：两平行标度加居中第三标度（$m = 0$）时，两标度须**反向刻度**，否则第三标度位置 $\varphi_3 = d/(1 - \cot\varphi)$ 会在 $\varphi = 45^\circ$ 处出现极点（推证见 [[findings/两平行一斜标度构型与极角算例]]）。

## 与 2.16 的衔接

网络算图的现代注记——计算近似值、作**迭代初值**——与 [[methodology/经验曲线确定三步法]] 的拟合流程互补：先由算图图解出粗略初值（例如指数和拟合的初值，见 [[findings/指数和的两级修正]]），再交由最小二乘迭代精化，构成「图解初值 → 解析拟合」工作流。注意机制区分：2.19 的化直靠**标度变换**（坐标映射），2.16 的化归靠**变量代换**（如 [[findings/修正的线性化原理与判定]]），二者同属「变换以简化」的方法论主线但不可混同。
