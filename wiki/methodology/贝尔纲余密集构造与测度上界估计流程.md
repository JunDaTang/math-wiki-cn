# 贝尔纲余密集构造与测度上界估计流程

**目的与理由**：为说明「[[concepts/通有性|通有]]（贝尔纲/余密集意义下大）」与「勒贝格测度大」互不蕴含、「稠密 ≠ 通有」，需要构造既余密集又零测的集合。本流程把手册 17.1.4.3 的算例抽象为可复用步骤。

## 流程

1. **取可数稠密集**：选定可数稠密集 {aₙ}（如 ℚ = {aₙ}）作为构造骨架。
2. **套可缩小的开邻域**：对每个 k，令 B_k = ∪_n (aₙ − r_{k,n}, aₙ + r_{k,n})，半径 r_{k,n} = 1/(k·2ⁿ) 随 n 指数衰减、随 k 多项式缩小。
3. **验证开稠**：每个 B_k 开（开区间之并）且稠密（包含稠密集 {aₙ}）。
4. **交出余密集**：B = ∩_k B_k 即手册口径的第二贝尔纲集（余密集）。
5. **测度上界**：λ(B_k) ≤ Σₙ 2r_{k,n} = (2/k)·Σₙ 2^{−n} = 4/k。
6. **从上连续性**：B_k ⊃ B_{k+1} 且 λ(B₁) < ∞ ⟹ λ(B) = lim_k λ(B_k) ≤ lim 4/k = 0。
7. **结论组合**：B 余密集且零测；与 ℚ（稠密、第一纲、零测）、𝕀（余密集、满测）对照，得「稠密 / 纲 / 测度」三种大小概念的相互独立性。

## 适用与实例

应用于 ℝ（或 ℝⁿ 中围绕可数稠密集的球族，半径作同型缩放）。复算记录见 [[findings/贝尔纲集零测余密集算例复算]]。
