# 四阶曲线图像绘制法

本页总结《数学手册(原书第10版)》2.12 节处理四阶(四次)曲线的方法，以及本库在核验该节公式时使用的工具。核心思想：**参数比（l/a 或 a/c）是曲线形态的真正控制变量，图像绘制与公式引用都必须以“情形分支”为骨架**。

## 绘制原则

1. **情形分支先行**。先确定参数比落入哪个情形区间（蚌线：l < a / l = a / l > a；卡西尼：a > c√2 / a = c√2 / c < a < c√2 / a = c / a < c），不同情形的奇点类型、分支数与特征点公式不同，不可混用。
2. **分支感知的参数域选取**。多支曲线的参数方程按支拆分参数域：尼科梅德斯蚌线右支取 −π/2 < φ < π/2、左支取 π/2 < φ < 3π/2，两支共享渐近线 x = a（φ 趋于边界时 x → a、|y| → ∞）。
3. **极坐标法及其陷阱**。ρ = f(φ) 形式便于积分与求极值，但需注意：ρ² 形式双值（卡西尼式 2.239b 的 ±）；根号内约束（双纽线 ρ = a√(2cos 2φ) 只在 cos 2φ ≥ 0 的扇区内实存）；ρ 变号时点的实际方向翻转（蚌线左支、蜗线内环）。
4. **奇点情形作为分支点**。原点奇点（孤立点/尖点/二重点）是情形切换的标志：绘制前先判型，再决定原点附近如何落笔。判定可用隐式方程最低次项（给出切线条数与斜率）或极径零点分析（ρ(φ) = 0 的解数）。
5. **特征点核对清单**。顶点、极值点、拐点、二重切线、曲率半径、面积、弧长——手册为每个情形给出其中若干项，逐项核对后再连点成图。

## 核验工具（本库已实际使用）

- **极点曲率半径公式 r₀ = |ρ′(φ₀)|/2**（φ₀ 为曲线过极点的极角）：核验二重点处的 r₀。已用于两族蚌线：蜗线 ρ = a cos φ + l 给出 r₀ = ½√(a²−l²)；蚌线 ρ = a/cos φ − l 给出 r₀ = l√(l²−a²)/(2a)，均与手册吻合。
- **极坐标曲率分子 ρ² + 2ρ′² − ρρ″**：拐点条件。蜗线化简为 2a² + 3al cos φ + l² = 0，即手册拐点公式；蚌线参数式曲率分子 ẋÿ − ẏẍ 化简后即手册拐点三次方程（代换 u = x − a = l cos φ）。
- **面积公式 S = ½∫ρ² dφ**：已核验蜗线（πa²/2 + πl²）、心脏线（(3/2)πa²）、双纽线每环（a²）。
- **隐函数极值条件**：ẏ = 0（参数式）或 F_x = 4x(x²+y²−c²) = 0（卡西尼腰部极值点）。
- **最低次项分析**：奇点切线（双纽线 x²−y² = 0 ⟹ y = ±x；蚌线 (a²−l²)x² + a²y² = 0 ⟹ 二重点切线斜率）。
- **退化交叉验证**：特例公式应能由一般公式代入临界参数得到（双纽线 r = 2a²/(3ρ) ← 卡西尼曲率公式取 a = c；心脏线极值与隐式 ← 蜗线公式取 l = a）。

## 为何如此（方法论依据）

手册 2.x 系列的编写体例即“按参数比分情形给特征点公式”：三次曲线（[[findings/第II类三次曲线按判别式三情形的公式体系]]、[[findings/第III类三次曲线的六种行为模式与极值点配对]]）与指数和（[[findings/指数和四情形分类与特征点公式]]）已经采用同一骨架，2.12 节将其延伸到四次曲线。原因在于：代数曲线的拓扑（分支数、环、奇点）在参数比的临界值处发生突变，任何“一条公式走天下”的画法都会在临界情形失效。同族方法页：[[methodology/有理函数图像绘制法]]、[[methodology/双曲函数图像绘制法]]、[[methodology/三角函数类图像绘制法]]。
