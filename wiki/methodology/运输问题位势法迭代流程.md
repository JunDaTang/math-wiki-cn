# 运输问题位势法迭代流程

位势法（原文称乘子 $p_i$、$q_j$ 为「潜在乘子或单纯形乘子」，通行术语作「位势」；相应方法亦称修正成本矩阵法、MODI 法或 u-v 法）是《数学手册》(原书第10版) 18.1.4.1 给出的运输问题专用迭代算法（式 18.28a–h）。它在原文小节标题下表述为「采用单纯形法求解运输问题」：与单纯形法等价，但每步只涉及理论单纯形表的非零元。

## 为何需要专用算法（rationale）

若用通常的单纯形法求解[[concepts/运输问题|运输问题]]，会产生含有大量零元的十分庞大的表 $(m+n)\times(m\cdot n)$，且每一列中仅有两个等于 1 的元（约束矩阵极稀疏）。位势法通过在成本矩阵上定义乘子，把单纯形表的检验数运算压缩为对非零元的操作，避免显式构造大表。基变量在迭代过程中变换为非基变量，成本矩阵相应的元在每一步都需修改。

## 迭代步骤（18.28）

**a) 确定位势与修正成本矩阵。** 在成本矩阵 $C$ 中给现时基变量对应的元打上标记，令 $p_1=0$，其余 $p_i$、$q_j$ 由「带标记的成本 $c_{ij}$ 与 $p_i,q_j$ 之和为零」（即基变量处 $\tilde c_{ij}=0$，式 18.28b）确定；随后计算修正成本

```latex
% (18.28a)（原文如此；疑脱加号，应为 c_{ij}+p_i+q_j，见 queries/修正成本公式脱加号之辨）
\tilde{c}_{ij} = c_{ij}p_i + q_j
```

**b) 判优与入基。** 求 $\tilde c_{pq}=\min_{i,j}\{\tilde c_{ij}\}$（18.28d）。原文称「如果 $\tilde c_{pq}>0$，则分布是最优的」；但因基变量处 $\tilde c=0$，$\min\le 0$ 恒成立，该条件永假，而节末实际使用「$\tilde C$ 不包含任何负元」（即 $\min\ge 0$）判优——疑「>」应为「≥」，见 [[queries/位势法判据大于零疑为不小于零之辨]]。否则选 $x_{pq}$ 作为新的基变量。

**c) 删元找回路。** 在 $\tilde C$ 中给 $\tilde c_{pq}$ 以及与基变量相关的成本项打上标记；若某行或列至多含一个标记元，则删去该行或列；对剩余矩阵重复，直至不再需要删除。与剩下带标记元相关的 $x_{ij}$ 形成一个回路。

**d) 回路调整。** 新基变量 $x_{pq}$ 被调整到正值 $\delta$（原文「正值 8」为 $\delta$ 之误）；回路中其余相关变量由约束确定——实践中沿回路的元相间（每隔一元）交替减去/加上 $\delta$（原文「从回路第二元减去 δ，或将 δ 加到回路第二元」疑为「每隔一元」之误，见 [[queries/回路第二元疑为每隔一元之辨]]）。为保持变量非负，取

```latex
% (18.28f)
\delta = x_{rs} = \min\{x_{ij}:\ \tilde{x}_{ij} = x_{ij}-\delta\}
```

其中 $x_{rs}$ 将成为非基变量。

**e) 重复。** 取 $\tilde X$ 作为新的 $X$，重复 a)–d)，直至修正成本矩阵不含任何负元。
