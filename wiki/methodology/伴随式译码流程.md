# 伴随式译码流程

## 目的与原理（为什么有效）

利用 (n,k) 线性码（[[concepts/线性码]]）的校验矩阵 H（式 5.269）高效译码：伴随式 Hd^T 为零当且仅当 d 是码字；非零伴随式则定位差错位置。原理是线性代数中的核与方程组解空间关系（参见 [[concepts/核与象]]）：码 C 是由 H 定义的线性方程组的解空间，Hd^T 度量 d 偏离该解空间的方位。

## 步骤

设传输结果为字 d = d_1d_2…d_n，H 为该码的 (n−k)×n 校验矩阵：

1. 计算伴随式 Hd^T。
2. 若 Hd^T 是零向量，则 d 是码字，直接译出。
3. 否则，若 Hd^T 等于 H 的第 i [列]（源文作「行」，与 H 的形状矛盾，应为「列」，见 [[queries/校验矩阵的行是否应为列]]），则对应的码字是 d + e_i，其中 e_i = (0, …, 0, 1, 0, …, 0) 在第 i 个位置为 1。
4. 若 H 的[列]两两不同且非零，则该码为 [1-]纠错码——此条件保证任何单比特差错产生互异的伴随式，从而可被唯一定位。

## 适用范围

本流程为单错纠错情形的伴随式译码；一般情形需结合 MLD 译码思想（[[concepts/纠错码]]）。见 [[findings/线性码生成校验矩阵与伴随式译码]]。
