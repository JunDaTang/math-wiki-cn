# 实轴极点缩进围道计算流程

## 为什么（rationale）

被积函数在实轴上有极点（如 e^{iz}/z 的 z = 0）时，积分路径不能直接穿过极点。改为在极点处用小半圆**缩进**（indent）绕开：缩进方向决定极点被划入还是划出围道；小弧段在半径 r→0 时趋于一个确定的极限值，从而使围道保持闭合、[[concepts/留数定理]] 仍然可用，同时奇异点的影响被显式分离为小弧段贡献。

## 流程

1. **缩进**：将实轴路径在极点 x₀ 处以半径 r 的小半圆绕开——**向下**绕开则极点位于围道内部；**向上**绕开则极点位于围道外部。
2. **闭路积分**：= 2πi ×（围道内部极点的留数和）。
3. **分段取极限**：实轴段令 r→0、R→∞；小弧段的极限过程可在积分号下完成（被积函数关于参数 φ 一致收敛）。
4. **小弧段贡献**（一阶极点，留数记 Res）：向下绕开（参数 φ 自 π 增至 2π）时趋于 **+iπ·Res**；向上绕开时趋于 **−iπ·Res**（且极点被排除在围道之外）。
5. **大弧段**：由 [[concepts/若尔当引理]] 趋于零。
6. **联立**解出所求实积分。

## 实例（14.4.3）

- **[[concepts/正弦积分]] (14.59)**：e^{iz}/z，向下绕开原点，I = 2πi；小弧段 → iπ；得 2i∫₀^∞ sinx/x dx + iπ = 2πi。
- **[[concepts/阶梯函数]] (14.60)**：路径沿实轴（|R|→∞）向下绕开原点；t>0 时上半平面闭合（极点在内）得 1，t<0 时下半平面闭合（极点在外）得 0，t=0 时直接计算缩进路径（主值 0 + 小弧段 iπ）得 1/2。
- **[[concepts/矩形脉冲]] (14.61)**：同一路径上两个积分之差，三段取值由阶梯函数叠加得出。

复算见 [[findings/式14-56至14-62及ez例复积分计算实积分转录复算]]。

本 wiki 中该技术首见于 14.4；源文算例仅使用向下绕开的情形，向上绕开时小弧段贡献 −iπ 为依对称性的推断（标注为推断，非源文原文）。
