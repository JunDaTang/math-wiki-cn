# 微分近似计算流程

## 目的（why）

依据《数学手册(原书第10版)》6.2.1.4 性质 2（式 6.39）：Δy 与 dy 等价（lim Δy/dy = 1），且差 dy − Δy 是比 dx、dy、Δx 高阶的任意小量（除非 dy = 0）。原文由此指出「可以把对小增量的计算简化到计算它的微分，这个公式常用于近似计算」。why：计算增量 Δy = f(x+Δx) − f(x) 需要函数在两点的取值，而微分 dy = f′(x)dx 只需一点处的导数——用线性代替非线性，即得高阶精度的误差。

## 步骤（how）

1. **识别小增量场景**：问题形如「x 有微小改变 dx = Δx 时，y 改变多少」。
2. **求导**：算出 f′(x)（必要时用 [[concepts/微分法则]] 或 [[concepts/对数微分法]]）。
3. **取微分**：dy = f′(x)dx，其中 dx = Δx（式 6.37a–b）。
4. **以 dy 代 Δy**：Δy ≈ dy = f′(x)dx（式 6.39）。
5. **误差定位**：误差为 dy − Δy = o(Δx) 级的高阶小量；若 f′(x) = 0（dy = 0），此近似退化，需改用高阶方法（如 [[concepts/泰勒定理]] 的展开，见 [[findings/泰勒公式拉格朗日余项-式6-31]]）。

## 验证示例（自行构造，非源文算例）

以 y = x² 为例：dy = 2x·dx，而 Δy = 2x·dx + (dx)²，差 (dx)² 确为 dx 的高阶小量——与式 6.39 的「高阶」断言一致。

## 适用边界与注意事项

- 近似的良否取决于 dx 之小与 f′ 的变化；原文未给误差界，定量误差估计可循 [[methodology/微分中值定理误差估计流程]] 的思路。
- 「lim Δy/dy = 1」在 dy = 0 点失效，见 [[queries/式6-39极限是否隐含dy非零条件]]。
- 手册前向引用 6.1.4.4 与 16.4.2.1（近似计算专节）未入库，见 [[queries/6-2后续小节未入库缺口]] 与 [[queries/6-2-1交叉引用粘连讹误]]。
