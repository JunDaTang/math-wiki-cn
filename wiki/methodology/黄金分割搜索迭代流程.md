# 黄金分割搜索迭代流程

## 适用前提与设计动机（为何如此设计）

目标函数 f 在 [a₁, b₁] 上 [[concepts/单峰函数|单峰]]（见 [[concepts/单峰函数]]），给定精度 ε > 0。**为何要求单峰**：区间消去论证依赖「较小函数值一侧的外段不含极小点」，仅在单峰时成立。

## 流程（依据式 18.68–18.70）

1. **置初值**：区间 [a₁, b₁]，k = 1，τ = ½(√5−1) ≈ 0.618。
2. **放置试探点**：λ_k = a_k + (1−τ)(b_k − a_k)，μ_k = a_k + τ(b_k − a_k)（两试探点关于区间中点对称）。
3. **比较并套缩**：
   - 若 f(λ_k) < f(μ_k)：a_{k+1} = a_k，b_{k+1} = μ_k，μ_{k+1} = λ_k（复用已知值 f(μ_{k+1}) = f(λ_k)，只新算 λ_{k+1}）；
   - 若 f(λ_k) ⩾ f(μ_k)：a_{k+1} = λ_k，b_{k+1} = b_k，λ_{k+1} = μ_k（复用已知值 f(λ_{k+1}) = f(μ_k)，只新算 μ_{k+1}）。
4. **停机检验**：若 b_{k+1} − a_{k+1} < ε，输出含 x\* 的区间 [a_{k+1}, b_{k+1}]；否则 k ← k+1 回到步骤 3。
5. **步数预估（事前）**：由式 18.70 的 ε > τⁿ⁻¹(b₁ − a₁) 反解步数，得 n > 1 + ln((b₁ − a₁)/ε)/ln(1/τ)。注意：对数式为本维基推演，源文仅给出 τⁿ⁻¹(b₁ − a₁) 的原始形式。

## 设计原理

- **每步只新算一次函数值**：因 τ² = 1 − τ，旧试探点在新区间的黄金分割位置上恰好可复用（步骤 3 的替换规则），这是黄金分割法区别于 [[concepts/一致搜索]]（一次性算完全部格点）的效率来源。
- **对称放置**：两试探点关于中点对称，使两种比较结果的缩短因子相同（均为 τ），最坏情形有保证。

## 已知疑点

源文正文将两情形的复用值对调（「情形 a) 下是 f(λ₂)，情形 b) 下是 f(μ₂)」），与式 18.69 矛盾；本流程按式 18.69 采信，详见 [[queries/黄金分割已知函数值情形ab对调之辨]] 与 [[findings/式18-68至18-70黄金分割区间套缩复算]]。
