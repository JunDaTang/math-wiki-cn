# 分离变量法解题流程

## 目的

把线性偏微分方程定解问题化为一族常微分方程本征值问题，再用本征函数系的展开满足初始条件。适用前提：方程线性，边界条件可齐次化。

## 流程

1. **齐次化边界条件**：若边界条件非齐次（如棒振动例的 u_x|_{x=l} = kp），先作代换使其齐次化（z = u − kpx²/(2l)），代价通常是方程变为非齐次（z_tt = a²z_xx + a²kp/l）；再拆 z = v + w，用特解 w 吸收非齐次项（w = ka²pt²/(2l)）。此即 [[非齐次边值问题齐次化代换]] 在 PDE 的实例。
2. **乘积试探解**：设 u = φ₁(x₁)…φₙ(xₙ)（式 9.91），代入方程。
3. **分离**：令方程两侧各只依赖一个变量，得分离常数（常取 −λ²；弦振动例中非负常数只给平凡解）；写出各变量的常微分方程。
4. **解本征值问题**：结合（齐次）边界条件确定本征值与本征函数，谱型由边界条件与区域决定：
   - Dirichlet 双端 → sin(nπx/l)，n = 1, 2, …
   - Neumann 双端 → cos(nπx/l)，n = 0, 1, 2, …（注意 n = 0 项）
   - 周期条件（角变量）→ ν² = n²，n = 0, 1, 2, …
   - 奇异端（ρ = 0 有界）+ Dirichlet（ρ = R）→ Jₙ(μ_nk ρ/R)，带权 ρ 正交
   - 无界区域 → 连续谱，级数换为反常积分（傅里叶积分）
   理论依据是 [[斯图姆-刘维尔问题]] 的本征函数完全系与 [[按本征函数的傅里叶展开]]。
5. **叠加满足初始条件**：把初始函数按本征函数系展开定系数；带权正交时系数公式含权函数（圆膜例的 ρ dρ 与归一因子 2/(πR²J²_{n−1}(μ_nk))）。
6. **验证形式解**：确认级数/积分收敛、逐项可微、满足方程与边界条件、边界处极限存在。手册声明其算例在边界函数满足二阶导数连续等条件时收敛，但这一步**不可省略**。
