# 广田双线性方法（τ 函数）

**广田双线性方法**是构造孤子方程 N-孤子解的系统性方法：通过位势代换把非线性偏微分方程化为对 τ 函数（源文记 F）的双线性方程，再以指数多项式拟设逐项求解。本页依据源文式 (9.157) 的实质内容并结合复算重构；源文本身未以「双线性方法」之名展开（方法与其提出者广田 (Hirota) 同名，9.2.5.5.4 的广田方程亦以之定名——此为可独立核实的背景知识）。

## 为什么有效（rationale）

孤子方程的非线性项使线性叠加原理失效，但经位势代换后，方程对 F 呈「双线性」结构——F 的每个指数单项式至多出现两次——因此有限项指数多项式 F = 1 + e^{α₁} + e^{α₂} + A e^{α₁+α₂} + … 可以使方程逐项成立，从而一次性给出精确的 N-孤子解，并显式呈现**非线性叠加**（源文：「方程 (9.156) 和由 (9.157c) 得到的表达式是非线性叠加的例子」）。

## 步骤（KdV 情形）

1. **位势代换**：令 w = F_x/F、u = 2w_x，KdV 方程 (9.153) 化为位势方程

```latex
w_t + 6 (w_x)^2 + w_{xxx} = 0,   w = F_x/F,   2 w_x = u     (9.157a)
```

2. **单孤子**：取 F = 1 + e^{α}（源文 (9.157b)，具体形式在转写中丢失，见 [[queries/式9-157b至9-157c公式内容缺失]]），得 (9.154)。
3. **N-孤子**：取 F 为指数多项式（源文 (9.157c)，形式同样丢失），得如 (9.156) 的双孤子解。

## 复算中的应用

- **双孤子核验**：将 u = 2∂²ₓ ln F（F = 1 + e^{α₁} + e^{α₂} + Ae^{α₁+α₂}，A = ((k₁−k₂)/(k₁+k₂))²）展开，可定位 (9.156) 转写中的系数配对讹误（应为交叉配对 A(k₂²e^{2α₁+α₂} + k₁²e^{α₁+2α₂})），见 [[queries/式9-156指数定义与系数交叉配对疑误]]。
- **KP lump 核验**：F = 1/k² + (x − 3k²t)² + k²y² 满足双线性方程 (D_xD_t + D_x⁴ − 3D_y²)F·F = 0（D 为广田双线性微分算子），由此判定 (9.179b) 是 (u_t + 6uu_x + u_{xxx})_x = 3u_{yy} 的精确解，见 [[queries/式9-179a右端是否漏因子3]]。
