# 选主元法换轴计算流程

## 为何用换轴

选主元法把「判线性相关性、求逆矩阵、解方程组」统一为同一张格式表上的变量角色交换：每步只做四则运算，且换轴可逆、不改变线性型组所含的信息，因此终表可同时读出可解性、自由参数与相关关系。源明言该框架还可用于（例如）线性最优化问题。

## 流程

1. **列格式**：将线性系 y = Ax + a（解方程组时用 y = Ax − a）排成表：行标 y₁, …, y_m，列标 x₁, …, x_n 与常数列 1。
2. **选主元**：任取非零元素 a_ik ≠ 0（画框），其所在行 y_i 称主行、所在列 x_k 称主列。
3. **换轴**：y_i 调换为独立变量、x_k 调换为相关变量——格式中主行位置改标 x_k、主列位置改标 y_i。
4. **按四条法则填新表**：

```
(1) α_ik = 1/a_ik                         （x_k 行与 y_i 列交点）
(2) α_μk = a_μk/a_ik                      （新 y_i 列的其余行；μ ≠ i）
(3) α_iν = −a_iν/a_ik,  α_i = −a_i/a_ik   （新 x_k 行的其余列；ν ≠ k）
(4) α_μν = a_μν + a_μk·α_iν,  α_μ = a_μ + a_μk·α_i   （其余交叉元素）
```

5. **写第 m + 1 辅助行**：法则 (4) 的每个新元素都要用到新主行的 α_iν；将其抄在格式最低行（第 m + 1 行），使 α_μν = a_μν + a_μk·α_iν 可像查表一样逐格计算——这是源为「使计算容易些（法则 4)」给出的明确理由。
6. **判停与读表**：
   - 判线性无关/秩：若每个 y_μ 都已换轴，线性型组线性无关（可确定矩阵的秩）；若某 y_σ 行在所有 x 列的元素均为 0，则不可继续换轴，读该行得相关关系 y_σ = Σλ_μy_μ + λ₀；
   - 解方程组：完成换轴后代 y = 0；情形 1（全部 y 换轴）有解，情形 2 由 λ₀ 是否为零判定（式 4.183）；
   - 求逆：n 阶正则矩阵实施 n 次换轴后，按 y_i 下标重排列、按 x_k 下标重排行得 A⁻¹。
7. **校验**：解回代原方程组；求逆后验 A·A⁻¹ = I（4.5 各算例均已如此复算）。
