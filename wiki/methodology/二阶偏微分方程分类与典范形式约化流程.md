# 二阶偏微分方程分类与典范形式约化流程

## 目的与原理

[[二阶线性偏微分方程]] 的求解策略由其类型决定：类型在（非退化）自变量变换下不变，而 [[典范形式]] 把二阶主部化为最少项，使方程落入可识别的标准形状并匹配相应积分法。本流程合并手册 9.2.2.1 与 9.2.2.2 的操作步骤。

## 流程（两变量情形）

1. **识别主部系数**：写出 (9.82a) 形式，读出 A、B、C（注意混合项系数为 2B）。
2. **计算判别式** δ = AC − B²（手册约定：δ < 0 双曲、δ = 0 抛物、δ > 0 椭圆、变号混合；与通行 B² − AC 约定方向相反，见 [[comparisons/判别式两种符号约定比较]]）。
3. **解特征方程** A dy² − 2B dx dy + C dx² = 0，即 dy/dx = (B ± √(−δ))/A，得特征线族。
4. **选新自变量并约化**：
   - 双曲型：两族特征作 ξ₁ = φ、η₁ = ψ → 第一典范形式 u_{ξ₁η₁} + … = 0；需要 9.84b 形式时再作 ξ = ξ₁ + η₁、η = ξ₁ − η₁。
   - 抛物型：唯一特征族取 ξ = 常数；η 取任一不依赖 ξ 的函数 → u_ηη + … = 0。
   - 椭圆型：系数解析时取复共轭特征 φ、ψ，作 ξ = φ + ψ、η = i(φ − ψ) → u_ξξ + u_ηη + … = 0。
5. **整理低阶项**：变换后重新归并一阶项与零阶项。

## 流程（常系数情形的附加步骤）

1. 经线性齐次变换化为 Σ κᵢ ∂²u/∂xᵢ² + … = 0，κᵢ ∈ {−1, 0, +1}；按符号模式定类型（全同号椭圆、恰一异号双曲、两符号各≥2 超双曲、恰一零余同号抛物）。
2. 若一阶导系数 b_k 亦为常数，作消一阶导代换 u = v exp(−½ Σ (b_k/κ_k) x_k)（对 κ_k ≠ 0 求和），得 Δv + kv = g（椭圆）或 v_tt − Δv + kv = g（双曲）。

## 何以如此（rationale）

- 特征线正是二阶导数项退化的方向：以特征为坐标线，相应的二阶导数项消失——这解释了典范形式的形状、双曲型第一典范形式的存在，以及抛物型无混合导数项的事实。
- 消一阶导代换的机制可用单变量模型核验：κv″ + bv′ = 0 经代换化为 v″ − (b²/4κ²)v = 0，一阶项确被消去。
- 应用实例：[[电报方程]] 经“消阻尼 → 化典范形式 → 求黎曼函数”三步走完本流程。复算记录见 [[findings/式9-82至9-85分类特征与典范形式转录复算]]、[[findings/式9-86至9-90多变量与常系数约化复算]]。
