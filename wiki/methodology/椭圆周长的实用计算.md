# 椭圆周长的实用计算

## 为什么需要专门的方法

椭圆弧长的被积函数 √(1−e²sin²ψ) 没有初等原函数，周长必须借助第二类完全椭圆积分 L = 4a·E(e)（式 3.329a）。手册为此给出四条实用途径，各有适用场景与精度特征——选择依据是手头工具（数表、级数、计算器/计算机）与所需精度。

## 四条途径

### 1. 级数展开

```
e 幂级数:  L = 2πa[1 − (1/2)²e² − ((1·3)/(2·4))²·e⁴/3 − ((1·3·5)/(2·4·6))²·e⁶/5 − …]   (3.329b)
λ 幂级数:  L = π(a+b)(1 + λ²/4 + λ⁴/64 + λ⁶/256 + 25λ⁸/16384 + …),  λ = (a−b)/(a+b)   (3.329c)
```

λ 级数以 (a−b)/(a+b) 为小参数，对扁平椭圆收敛更快；e 级数在 e 接近 1 时收敛慢。

### 2. 近似公式

```
L ≈ π[1.5(a+b) − √(ab)]                     (3.329d)
L ≈ π(a+b)·(64 − 3λ⁴)/(64 − 16λ²)           (3.329e)
```

(3.329e) 是有理逼近，精度高于 (3.329d)，适合手算。

### 3. 查表

原书第 1424 页表 21.9（第二类完全椭圆积分表）——按 e（或 k）查 E(e) 后乘 4a。

### 4. 数值积分

对 (3.329a) 的积分直接做数值积分（如 Simpson 法），可达到任意精度。

## 精度对比（a = 1.5, b = 1，即 e = √5/3 ≈ 0.745、λ = 0.2）

| 途径 | 结果 |
|---|---|
| (3.329e) 有理近似 | L ≈ 7.9327 |
| 表 21.9（两位有效） | L ≈ 7.94 |
| 数值积分（基准） | L ≈ 7.932721 |

(3.329e) 与数值积分基准在 5 位有效数字内一致；级数 (3.329c) 与 (3.329e) 展开至 λ⁴ 互相吻合。复算细节见 [[findings/椭圆面积周长级数与算例]]。

## 使用建议（据本源算例归纳）

- 精度要求不高或手算：用 (3.329e)。
- 有数表：查 E(e) 表（注意表的有效位）。
- 需要高精度或批量计算：数值积分或 λ 级数多取几项。
