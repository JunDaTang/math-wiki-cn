# NestList 实现牛顿迭代流程

## 目的与理据

以 Mathematica 的函数迭代命令实现牛顿法求根。选用迭代命令而非手写循环的理据（源自 20.2.8 (6) 的示范）：

- **NestList** 列出从初值起的全部中间迭代值——可检视收敛速率、诊断是否震荡或发散；
- **FixedPoint** 自动重复迭代「直到结果不再改变」——只需终值时免于指定迭代次数。

该流程在源文中用于求方程 x cos x = sin x 在 3π/2 邻域的根，数值经独立复算逐位吻合（[[findings/牛顿法NestList-FixedPoint求根算例复算]]）。

## 流程（五步，可复现）

1. **化标准形**：把方程写成 f(x) = 0。本例 x cos x = sin x ⇔ f(x) = x − tan x（两边除以 cos x；须确认根处 cos x ≠ 0，本例 x* ≈ 4.4934 处 cos x* ≈ −0.217，合法）。
2. **求导**：`f′[x]` → `1 - Sec[x]^2`（Mathematica 自动给出）。
3. **定义牛顿迭代函数**：`g[x_] := x - f[x]/f′[x]`。
4. **列轨迹**：`NestList[g, 4.6, 4]` → `{4.6, 4.54573, 4.50615, 4.49417, 4.49341}`（初值 4.6 取自 3π/2 ≈ 4.7124 的邻域且与根相近）。
5. **求不动点**：`FixedPoint[g, 4.6]` → `4.49341`（真值 ≈ 4.4934095，6 位有效数字）。

完整会话（转录自源文，In[3] 之「=」据文义校为「:=」）：

```
In[1] := f[x_] := x - Tan[x]
In[2] := f′[x]            → Out[2] = 1 - Sec[x]^2
In[3] := g[x_] := x - f[x]/f′[x]
In[4] := NestList[g, 4.6, 4]
         → Out[4] = {4.6, 4.54573, 4.50615, 4.49417, 4.49341}
In[5] := FixedPoint[g, 4.6] → Out[5] = 4.49341
```

## 结果判读

误差序列满足 e_{n+1} ≈ 4.7·e_n²（核算见 findings 页），呈牛顿法特有的平方收敛；4 步即达 6 位有效数字。

## 局限与注意

- **终止判定**：源文未说明 FixedPoint 的 SameTest 与精度控制机制；「该结果还可以达到更高的精度」源文无演示，未验证；
- **初值依赖**：本例初值 4.6 与根相近故收敛顺利；牛顿法对初值的一般要求属手册 19.1.1.2（未入库，[[queries/20-2-8未入库回指缺口]]）；
- **等价变形的前提**：除以 cos x 的变形在 cos x = 0 处引入差异，须如步骤 1 先行核查；
- 可与 [[methodology/迭代法安全实施五准则]]（19.8.2）互参：该准则从误差控制角度约束迭代法实施，本流程是其 CAS 实现的一个干净样例。
