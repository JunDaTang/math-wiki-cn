# 扇形围道指数估计流程

## 为什么（rationale）

当被积函数是 e^{−z²} 这类全平面解析、但需要把积分路径旋转到斜射线才有用的函数时（菲涅耳积分需把实轴旋转到 π/4 射线），大弧段上 |e^{−z²}| = e^{−R²cos2φ} 在弧段两端（φ 近 0 或 π/4）并不小，整段一致放大失效。解决办法是把弧段积分按角度分割：在靠近零点的段用 cosφ 的下界放大，在其余段用 sinφ/sinα ⩾ 1 换元后可直接积分，得到随 R→∞ 趋于零的显式上界。这是 [[concepts/复积分的绝对值估计]] 的精细化应用，也是若尔当引理标准形式之外的一种弧段控制手段。

## 流程

以菲涅耳积分的扇形围道（张角 π/4，图 14.48）为例：

1. **闭路积分为零**：e^{−z²} 全平面解析，由 [[concepts/柯西积分定理]] 得 I = I_I + I_II + I_III = 0。
2. **实轴段**：I_I = ∫₀^R e^{−x²}dx，R→∞ 时 → ½√π（高斯积分，独立已知）。
3. **大弧段的 α-分割估计**（源文原式，0 < α < π/2）：
   - 上界：|I_II| ⩽ R∫₀^{π/4} e^{−R²cos2φ}dφ；
   - 换元 2φ → φ，积分区间变为 [0, π/2]，在 α 处分割；
   - [0, α] 段用 cosφ ⩾ cosα 放大：⩽ (αR/2)e^{−R²cosα}；
   - [α, π/2] 段用 sinφ/sinα ⩾ 1 放大，再利用原函数 ∫sinφ·e^{−R²cosφ}dφ = [e^{−R²cosφ}/R²] 直接积分：⩽ (1 − e^{−R²cosα})/(2R sinα)；
   - 合计 |I_II| < αR/2·e^{−R²cosα} + (1 − e^{−R²cosα})/(2R sinα) → 0。
4. **射线段参数化**：沿 π/4 射线 z = re^{iπ/4}，z² = ir²，被积函数为 e^{−ir²}（源文此处疑漏负号，见 [[queries/式14-62菲涅耳III指数疑漏负号]]）。
5. **取极限并分离实虚部**：由 I_I + I_III → 0 解出两个实积分。
