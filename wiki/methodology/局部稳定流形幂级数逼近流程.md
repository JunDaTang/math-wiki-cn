# 局部稳定流形幂级数逼近流程

## 为什么

阿达马—佩龙定理保证双曲平衡点的局部稳定流形存在且是 $C^r$ 图像 $y=h(x)$，但不给出显式式。不变性条件把 $h$ 转化为一个一阶微分方程，幂级数比较系数可逐项确定 $h$，且首项由切空间 $E^s$ 的斜率控制。

## 流程（以 (17.19a) 为模板）

1. **设图像形式**：$W^s_{\mathrm{loc}}((0,0))=\{(x,y):y=h(x),\ |x|<\varDelta\}$，$h$ 可微、$h(0)=0$。
2. **写不变性条件**：轨线留在流形上 ⟹ 对靠近 0 的 $s$ 有 $y(s)=h(x(s))$；对 $s$ 求导并以方程的 $\dot x,\dot y$ 代入，得 $h$ 的微分方程。对 (17.19a)：$h'(x)(-x)=h(x)+x^2$，$h(0)=0$。
3. **幂级数代入**：设 $h(x)=\frac{a_2}{2}x^2+\frac{a_3}{3!}x^3+\cdots$（由切于 $E^s$ 知 $h'(0)=0$，无线性项）。
4. **比较系数**：逐次解出 $a_2=-\frac23$、$a_k=0\ (k\geqslant 3)$，即 $h(x)=-x^2/3$。
5. **与精确解对照**：若流显式可解（如 (17.19b)），用 $W^s=\{y_0+x_0^2/3=0\}$ 验证幂级数结果。
6. **截断使用**：一般系统只能得有限项，作为局部近似。

## 边界

- 仅适用于双曲平衡点（非双曲时 $E^s$ 无定义或退化）。
- 收敛半径 $\varDelta$ 一般未知，需另行估计。
