# 勒让德符号化简流程

**用途**：计算勒让德符号 (a/p)（判定 a 是否为模 p 二次剩余），进而套用式 (5.258b) 判定一般模二次同余的可解性。**依据**：性质组 E1–E6（式 5.257）。

## 步骤

1. **化小（E1）**：把 a 换成模 p 的代表元（必要时取绝对最小剩余）。
2. **分解（E4）**：把分子分解为素因子乘积，(a/p) 拆成各因子的符号之积；平方因子直接由 (ab²/p) = (a/p) 消去。
3. **处理 −1（E3）**：(−1/p) = (−1)^{(p−1)/2}，即 p ≡ 1 (4) 时 +1、p ≡ 3 (4) 时 −1。
4. **处理 2（E5）**：(2/p) = (−1)^{(p²−1)/8}，即 p ≡ ±1 (8) 时 +1、p ≡ ±3 (8) 时 −1。
5. **翻转（E6）**：对奇素数因子 q，用二次互反律 (q/p) = (−1)^{((p−1)/2)((q−1)/2)}(p/q)；当 q ≡ 1 (4) 或 p ≡ 1 (4) 时无符号修正。翻转后分母变小，回到步骤 1–2 递归。
6. **终止**：所有符号化到 (±1/p)、(2/p) 或小素数表值，相乘得结果。

## 算例（已复算）

(65/307)：65 = 5·13；(5/307) = (307/5) = (2/5) = −1（E6 无修正 + E1 + E5：(2/5) = (−1)³）；(13/307) = (307/13) = (8/13) = (2/13)³ = (2/13) = −1（E5：13 ≡ 5 (8)，(−1)²¹）；乘积 = 1。65 是模 307 二次剩余。见 [[findings/勒让德符号性质组与65-307算例]]。
