# 双曲函数图像绘制法

本页从手册 2.9.2 对 sinh、cosh、tanh、coth 的刻画次序中，提炼出一套可复用的双曲函数曲线绘制/校核流程。它与 [[methodology/三角函数图像绘制法]] 平行；差异在于：双曲函数无周期性可利用，取而代之的是指数增长/衰减的端点行为与渐近线控制。

## 为什么需要专门流程

双曲函数由 e^±x 定义，曲线在两端呈指数行为，中段由对称性与拐点控制；若不先定奇偶与渐近线，容易把有界函数（tanh）画成无界，或遗漏 coth 的竖直渐近线。手册对每个函数恰好按「奇偶 → 单调区间（含端点行为）→ 渐近线 → 对称中心/拐点与切线角 → 辅助曲线控制」的次序给出全部要素，这一刻画次序本身就是绘图的最短路径，故值得提炼为方法。

## 流程

1. **写出定义**：由式 2.166–2.171 写出指数形式，确定定义域（coth、csch 需挖去 x = 0）。
2. **定奇偶**：用负角公式 2.178–2.181（或定义的对称性）判定奇偶；奇函数只需画一半再作中心对称。
3. **定渐近线**：水平渐近线看 x → ±∞ 的指数极限（tanh/coth 的 y = ±1）；竖直渐近线看定义域边界（coth 的 x = 0）。
4. **分单调区间**：按区间记录每段的起止值（cosh 的 +∞ → 1 → +∞；coth 两支的 −1 → −∞ 与 +∞ → 1）。
5. **定对称中心、拐点与切线角**：sinh 与 tanh 的原点为对称中心兼拐点，切线倾角 π/4（即斜率 1：sinh′(0) = cosh(0) = 1、tanh′(0) = sech²(0) = 1，推断性核验）；coth 无拐点无极值。
6. **辅助曲线控制位置**：cosh 用抛物线 y = 1 + x²/2 作下界控制（恒在其上方、于 A(0,1) 相切）。
7. **校核**：用若干恒等式（如 cosh²x − sinh²x = 1）抽查图像上点的自洽性。
