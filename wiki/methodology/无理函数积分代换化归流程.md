# 无理函数积分代换化归流程

本流程整理数学手册 8.1.4 对无理函数积分 $\int R(x,\text{根式})\,dx$ 的代换化归决策链（表 8.3 → 配方三标准形 → 表 8.4）。**原理（为什么可行）**：有理函数的积分总可用初等方法（部分分式等）完成，故化归的最终目标是“有理化”——消去根式、化为有理函数的积分。

## 决策链

1. **判别根式类型**：
   - **线性分式根式** $\sqrt[n]{\frac{ax+b}{cx+e}}$：令 $\sqrt[n]{\frac{ax+b}{cx+e}}=t$，反解 $x=\frac{t^ne-b}{a-ct^n}$ 为 $t$ 的有理函数。若同时出现多个根指数 $m,n,\cdots$，取 $r=\mathrm{lcm}(m,n,\cdots)$，令 $\sqrt[r]{\frac{ax+b}{cx+e}}=t$。
   - **二次根式** $\sqrt{ax^2+bx+c}$：先排除退化情形——若 $a<0$ 且多项式有复根，根式恒虚，积分无意义；否则二选一：
     - 路径 A：三种 [[concepts/欧拉代换]] 之一（按条件 $a>0$ / $c>0$ / 有互异实根选取）；
     - 路径 B：配方化为三种标准形（式 8.19a–c），再用表 8.4 代换——$\sqrt{x^2+\alpha^2}$ 配 $x=\alpha\sinh t$ 或 $x=\alpha\tan t$；$\sqrt{x^2-\alpha^2}$ 配 $x=\alpha\cosh t$ 或 $x=\alpha\sec t$；$\sqrt{\alpha^2-x^2}$ 配 $x=\alpha\sin t$ 或 $x=\alpha\cos t$。
   - **二项被积函数** $x^m(a+bx^n)^p$：转 [[methodology/二项被积函数可初等性判定流程]]（切比雪夫三查）。
   - **三次/四次根式**：转 [[concepts/椭圆积分]] 路径（规范化为式 8.23 → 勒让德形式式 8.24 → 查表 21.9.1–21.9.3 或数值积分）。
2. **反解与代入**：把 $x$ 连同 $\mathrm{d}x$ 表为 $t$ 的函数代入，使被积式化为 $t$ 的有理函数；三角/双曲代换后经 $u=\tan\frac{t}{2}$ 或 $u=e^t$ 可进一步有理化。
3. **有理积分并回代**：完成有理函数积分后回代 $t$ = 原根式。

## 已复算的算例

- 配方算例 A：$4x^2+16x+17=4[(x+2)^2+(\frac12)^2]$（8.19a 型）；B：$x^2+3x+1=(x+\frac32)^2-(\frac{\sqrt5}{2})^2$（8.19b 型）；C：$-x^2+2x=1-(x-1)^2$（8.19c 型）——复算全部正确，见 [[findings/配方三标准形与A至C算例复算-式8-19]]。

## 局限

- 本流程只覆盖书中“最简单的情况”；大量无理函数积分结果需查第 1382 页表 21.7（未入库，见 [[queries/表6-1与表21-7未入库回指缺口]]）。
- 二项被积函数三查皆非整数时流程终止于“非初等”，须转椭圆积分/数值路径或查表；该判定不可外推至其他积分。
