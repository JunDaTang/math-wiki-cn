# 非齐次线性偏微分方程的齐次化与杜哈梅尔型代换

本方法用于把“非齐次初始/边界条件 + 非齐次线性偏微分方程”的求解归约为齐次方程（族）的求解，从而只需解齐次问题。源（9.2.3.1.3）未使用“杜哈梅尔（Duhamel）”之名；式 9.103c 型代换在标准理论中通称 Duhamel 原理（独立可验证背景）。它是 [[非齐次边值问题齐次化代换]]（ODE 版）在 PDE 语境下的对应物，两者构成 ODE/PDE 方法族。

## 步骤

1. **条件齐次化（差代换）**：用原始函数与任一满足给定非齐次条件的二次可微函数之差替代原始函数，得到一个与原方程差别仅在于自由项（不再包含未知函数）且具有齐次条件的方程。
2. **叠加分解**：具有给定非齐次初始/边界条件的非齐次线性 PDE 的解 = 具有零条件的同一个微分方程的解 + 具有给定条件的相应齐次微分方程的解。这是 [[叠加原理与分解定理]] 的 PDE 版本。
3. **杜哈梅尔型代换（式 9.103c）**：对具有齐次初始条件 (9.103b) 的非齐次方程 (9.103a)，作代换 u = ∫₀ᵗ φ(x, t; τ) dτ，其中 φ(x, t; τ) 是齐次方程 (9.103d) 的解，满足“以 τ 为初始时刻”的条件 (9.103e)：u|_{t=τ} = 0，∂u/∂t|_{t=τ} = g(x, τ)。

## 公式组（逐字转录）

```latex
(9.103a)  \frac{\partial^{2} u}{\partial t^{2}} - L[u] = g(x, t)
(9.103b)  u\big|_{t=0} = 0, \quad \left.\frac{\partial u}{\partial t}\right|_{t=0} = 0
(9.103c)  u = \int_{0}^{t} \varphi(x, t; \tau)\, \mathrm{d}\tau
(9.103d)  \frac{\partial^{2} u}{\partial t^{2}} - L[u] = 0
(9.103e)  u\big|_{t=\tau} = 0, \quad \left.\frac{\partial u}{\partial t}\right|_{t=\tau} = g(x, \tau)
```

其中 x 表示 n 维问题的所有 n 个变量 x₁, ⋯, xₙ（转写中 x、n、t 等符号被 OCR 丢弃，见 [[9-2-3全节系统性转写讹误清单]]）。

## 适用前提（复算确认为必要条件）

L[u] 为线性微分表达式，可包含导数 ∂u/∂t，但**不包含关于 t 的高阶导数**。独立复算表明这一限制恰为必要条件：对式 9.103c 关于上限 t 求导时，若 L 含 t 的高阶导数，求导产生的附加项无法被式 9.103e 的条件吸收（见 [[式9-103a至9-103e非齐次化归代换逐字转录与复算]]）。

## 应用实例（本源内）

- [[波方程]]非齐次柯西问题的附加项（式 9.107a–c）；
- [[热导方程]]非齐次附加项（式 9.108c）——两者均呈“对 τ 积分 × 以 (t − τ) 为参数的齐次解核”的卷积结构。

## 转写注记

源文“该方程与原始方程的差别仅在于其自由项不包含未知函数”一句语义滞涩（自由项本就不含未知函数），疑译文有损，指的应是“条件被齐次化、仅自由项改变”之意，需对原书核对（见 [[9-2-3全节系统性转写讹误清单]]）。
