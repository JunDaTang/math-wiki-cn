# 高阶微分方程求解方法选择流程

本流程整理 9.1.2 全节的方法体系为决策树，回答"拿到一个 n 阶方程（或方程组）先试什么"。设计根据：本源的理论顺序本身就是"一般 → 特殊"的漏斗（一般理论最弱但适用面最广，特殊方法假设最强但计算最简）。

## 决策树

```
n 阶方程 f(x, y, y', …, y⁽ⁿ⁾) = 0
│
├─ 线性？（式 9.32 形式）
│   ├─ 是 ── 系数是常数？
│   │   ├─ 是 ── 常系数路线
│   │   │      ① 齐次：特征方程 Pₙ(r)=0，重根配 xᵏ⁻¹e^{rᵢˣ}（式 9.40）
│   │   │      ② 非齐次：右端特殊？
│   │   │         ├─ Ae^{αx} / Qₙ(x)e^{αx}：待定系数公式（式 9.42–9.43）
│   │   │         └─ 一般右端：常数变异法 或 柯西方法
│   │   │      ③ 欧拉型 Σaₖ(cx+d)ᵏy⁽ᵏ⁾？代换 cx+d=eᵗ 化常系数（式 9.44）
│   │   │      ④ 只问稳定性？赫尔维茨定理 Dₖ>0（式 9.41）
│   │   └─ 否（变系数）
│   │          ① 已知一个特解 y₁？
│   │             ├─ n 阶：y = y₁u 降阶（式 9.36）
│   │             └─ 二阶：刘维尔公式得第二解（式 9.49d）
│   │          ② 系数解析？
│   │             ├─ 常点：幂级数 y=Σaₖ(x−x₀)ᵏ（式 9.50）
│   │             └─ 正则奇点：Frobenius 型 y=xʳΣaₖxᵏ，定义方程
│   │                r(r−1)+p(0)r+q(0)=0 定 r（式 9.51）
│   │          ③ 特殊函数方程对号：
│   │             贝塞尔(9.52)→J,Y / 虚变量→I,K / 勒让德(9.60)→P,Q
│   │             超几何(9.63)→F / 拉盖尔(9.65)→L / 埃尔米特(9.66)→He,H
│   └─ 否（非线性）
│       降阶四情形（式 9.27–9.31）：
│       ① 缺 x：y'=p, y''=p·dp/dy
│       ② 缺 y：y'=p（或 y⁽ᵏ⁺¹⁾=p）
│       ③ 齐次：z=y'/y
│       ④ y⁽ⁿ⁾=f(x)：n 次累次积分（Cauchy 公式 9.31c）
│       （结果仍是一阶方程 → 转入 9.1.1 一阶方法）
│
└─ 方程组？
    ├─ 常系数线性：正规组/一般组/二阶组 → 特征方程 det(…)=0
    │   单根给常数向量；m 重根看对称性：
    │   对称阵 → 只需常数；非对称可能亏缺 → 多项式系数（式 9.45–9.48）
    └─ 一般组：化一阶组（式 9.22）+ 存在唯一性条件（式 9.24）
```

## 设计原则

1. **先问结构性、后问解析性**：线性/常系数/特殊右端这类"结构"特征比系数的解析性质更先检验，因为对应的方法计算量最小。
2. **已知信息的利用优先**：已知一个特解（降阶 9.36 / 刘维尔 9.49d）比从头幂级数展开便宜得多。
3. **特殊函数对号入座**：二阶变系数方程先与五大族方程比对（贝塞尔/勒让德/超几何/拉盖尔/埃尔米特），命中即直接引用已建档函数（见相关实体页），避免重新推导级数。
4. **理论兜底**：全部方法失效时，存在唯一性（9.24）保证数值/定性讨论的合法性；首次积分（9.26d）给出通解的 PDE 表示。

## 本源算例在流程中的位置

- $yy''-y'^2=0$：非线性 → 情形①/③（两路均通）
- $y''-xy'''+(y''')^3=0$：非线性 → 情形② → 克莱罗方程
- 9.37d：线性变系数 → 已知一解 → 刘维尔 → 常数变异/柯西
- 9.40/9.42/9.43：常系数 → 特征方程 + 特殊右端
- 9.44：欧拉型 → 代换化常系数
- 9.45–9.47：常系数组 → 特征方程（含亏缺处理）
- 9.50：常点幂级数；9.52 起：正则奇点 Frobenius
