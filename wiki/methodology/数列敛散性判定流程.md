# 数列敛散性判定流程

本流程把 7.1 的定义（式 7.1–7.5、7.7）与四条定理（式 7.8–7.11 及定理 c)）组织成一个可操作的判定程序。其存在理由：手册对发散采取三分法（收敛 / 真发散 / 假发散），仅判断「发散与否」并不完整，还须区分发散类型；而单调性与有界性是两条最便宜的先行判据——定理 4c) 表明二者合用即可断言收敛并给出极限的确界刻画，无需先猜极限值。

## 流程

```text
第 0 步  写出通项 aₙ（若存在公式），计算首几项以获得直观。
第 1 步  单调性：检验相邻项不等式 aₙ ⩽ aₙ₊₁（式 7.2）或 aₙ ⩾ aₙ₊₁（式 7.3）；
         等号恒不成立 ⟹ 严格单调。
第 2 步  有界性：寻找 K > 0 使一切项满足 |aₙ| < K（式 7.4，注意为严格不等号）；
         找不到 ⟹ 无界。
第 3 步  收敛判定（按成本从低到高）：
         3a. 单调 + 有界 ⟹ 收敛，极限 = 最小上界 / 最大下界（定理 4c)）。
         3b. 极限候选 A 已知 ⟹ 用 ε–n₀ 定义（式 7.5a）验证。
         3c. 可拆为收敛列的和 / 积 / 商 ⟹ 四则运算法则（式 7.8–7.10，
             商需 bₙ ≠ 0 且 lim bₙ ≠ 0）。
         3d. 被两个同极限列夹逼 ⟹ 夹逼定理（式 7.11）。
第 4 步  发散分类（第 3 步全部失败时）：
         4a. aₙ > K（或 aₙ < −K）对一切 n > n₀(K) 成立 ⟹ 真发散，
             极限 ±∞（式 7.5b / 7.7）。
         4b. 存在两个极限不同的子列，或振荡而不满足 4a ⟹ 假发散。
```

## 用 A–J 十例演示

- 3a 路径：E（递增有界 → 3）、G（递减有界 → 0）。
- 3b/3c 路径：C（公比绝对值小于 1 的几何列 → 0）、F（10/3 的十进双侧逼近 → 3⅓）。
- 4a 路径：A、B（→ +∞）。
- 4b 路径：D（子列 ±1）、H（子列 ±∞）、I（奇子列 → −∞、偶项恒 0）、J（子列 3 与 13，即交错(E, E+10)）。

## 适用范围与限制

- 本流程只使用 7.1 已入库的工具；柯西收敛准则、子列定理等未见于本节转写，是否在原书后续部分待核（[[queries/第7章后续小节未入库缺口]]）。
- 3a 的极限刻画依赖「所有可能 K₁ 的最小值」存在，这是实数完备性的体现；手册未在本节展开其依据。
- ε–N 验证（3b）需要先有候选 A；对「先猜后证」失败的情形（如假发散判定），须退回第 4 步的子列分析。
