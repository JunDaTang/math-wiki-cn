# 原函数折线构造法

## 目的与理由

当 $P\,\mathrm{d}x+Q\,\mathrm{d}y(+R\,\mathrm{d}z)$ 满足可积条件（式 8.127 / 8.129c，见 [[concepts/线积分与积分路径无关]]）时，原函数 $U$ 可由线积分本身给出：

$$U = \int_{\widehat{AP}} (P\,\mathrm{d}x + Q\,\mathrm{d}y), \tag{8.131}$$

其中 $A(x_0,y_0)$ 为任意固定基点、$P(x,y)$ 为动点。由于路径无关，可特意选取**平行于坐标轴的折线**作为积分路径，使每个积分段上被积函数退化为单变量函数，从而把构造 $U$ 化为两（或三）次一元定积分。该式与 [[concepts/变上限积分]] 结构相类比。

## 二维：两条折线（图 8.28）

**折线 AKP**（先沿 x 轴方向、后沿 y 轴方向）：

$$U = C + \int_{x_0}^{x} P(\xi, y_0)\,\mathrm{d}\xi + \int_{y_0}^{y} Q(x, \eta)\,\mathrm{d}\eta, \tag{8.132a}$$

**折线 ALP**（先纵后横）：

$$U = C + \int_{y_0}^{y} Q(x_0, \eta)\,\mathrm{d}\eta + \int_{x_0}^{x} P(\xi, y)\,\mathrm{d}\xi, \tag{8.132b}$$

其中 $C=U(x_0,y_0)$ 为任意常数。

## 三维：折线 AKLP（图 8.29）

$$U = \int_{x_0}^{x} P(\xi, y_0, z_0)\,\mathrm{d}\xi + \int_{y_0}^{y} Q(x, \eta, z_0)\,\mathrm{d}\eta + \int_{z_0}^{z} R(x, y, \zeta)\,\mathrm{d}\zeta + C. \tag{8.133}$$

（转写本第三积分的哑变量误作 $\xi$，例 B 实用 $\zeta$，上式已按例 B 订正。）沿平行于坐标轴的方向，三维共有 $3!=6$ 条可能的积分路径（转写本脱漏路径条数，应为「还有其他 5 条」），由此可得进一步的等价公式。

## 基点选取：避开奇点

基点 $(x_0,y_0(,z_0))$ 必须取在可积条件成立的区域内并避开被积函数的奇点：8.3.4.4 例 A 中 $P$、$Q$ 在 $(0,0)$ 不连续，故取 $(x_0,y_0)=(0,1)$ 而非原点。这正是 [[queries/单连通前提与例A去心平面的失效边界]] 追踪的问题。

## 验证算例（复算吻合）

- **例 A**（$P=-\frac{y}{x^2+y^2},\ Q=\frac{x}{x^2+y^2}$，基点 $(0,1)$，用式 8.132b）：$U=-\arctan\frac{x}{y}+C=\arctan\frac{y}{x}+C_1$。
- **例 B**（三元，基点 $(1,1,0)$，用式 8.133）：$U=\arctan\frac{z}{x}-\frac{z}{xy}+C$。

复算细节（含 $U_x=P$、$U_y=Q$、$U_z=R$ 的逐项回代）见 [[findings/式8-131至8-133原函数折线构造与两算例复算]]。
