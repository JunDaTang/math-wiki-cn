# 数制转换四则算法流程

本流程出自《数学手册（原书第10版）》19.8.1.1「转换」，给出数制间换算的四条确定性算法。**理据（why）**：数按表示律 (19.259) 展开为基数 $B$ 的幂级数（见 [[concepts/数制与表示律]]），同一数值在不同数制下只是展开不同，故转换可化为对展开系数（数码）的机械操作——除基取余、乘基取整分别利用 (19.261)、(19.262) 把最低位数码从数中「剥离」出来；分组法则利用 $8 = 2^3$、$16 = 2^4$ 的幂次包含关系。若同时使用不同数制，用不同下标标记基数以避免混乱。

## 算法一：二进制 → 八进制/十六进制（分组法）

从小数点出发向左、向右分别按**三位**（转八进制）或**四位**（转十六进制）构成一组，确定各组之值，这些值就是八进制或十六进制的数字。

## 算法二：十进制整数 → 其他进制（除基取余）

设 $G$ 为十进制整数，对基数为 $B$ 的数制有构造律 (19.260)；将 $G$ 除以 $B$（原文此处脱符号 B），由 (19.261) 得整数部分（高位数码的缩减展开）与余数 $z_0/B$，故余数 $z_0 \in \{0, 1, \dots, B-1\}$ 即所求数的**最低位**数字；对商重复此法即得其余数字（由低位到高位）。

## 算法三：十进制小数 → 其他进制（乘基取整）

设 $g$ 为真分数，由 (19.262)，乘积 $gB$ 的整数部分即**下一位**数字 $z_{-1}$；对剩余小数部分重复即得 $z_{-2}, z_{-3}, \dots$（由高位到低位）。

## 算法四：二/八/十六进制 → 十进制（表示律求值 + 霍纳法则）

按 (19.263) 求幂级数值（十进制小数点在 $z_0$ 的后边；原文该式脱等号）；转换计算用**霍纳法则**（原文回指「参见第 1237 页 19.1.2.1」，该节尚未入库，见 [[queries/19-8-1未入库回指缺口]]）。

## 算例（原文转录，两例前脱例号）

**算例 1**：将十进制数 139 转化为二进制数（算法二）：

```text
139 : 2 = 69   余数 1   (1 = z₀)
 69 : 2 = 34   余数 1   (1 = z₁)
 34 : 2 = 17   余数 0   (0 = z₂)
 17 : 2 = 8    余数 1
  8 : 2 = 4    余数 0
  4 : 2 = 2    余数 0
  2 : 2 = 1    余数 0
  1 : 2 = 0    余数 1   (1 = z₇)

139₁₀ = 10001011₂
```

**算例 2**：将小数 0.8125 转化为二进制数（算法三）：

```text
0.8125 · 2 = 1.625   (1 = z₋₁)
0.625  · 2 = 1.25    (1 = z₋₂)
0.25   · 2 = 0.5     (0 = z₋₃)
0.5    · 2 = 1.0     (1 = z₋₄)
0.0    · 2 = 0.0

0.8125₁₀ = 0.1101₂
```

**组合结果**（含算法一分组验证）：$139.8125_{10} = 10001011.1101_2 = 213.64_8 = 8\mathrm{B}.\mathrm{D}_{16}$。

**算例 3**：霍纳法则求值（算法四）：$11101_2 = 1 \cdot 2^4 + 1 \cdot 2^3 + 1 \cdot 2^2 + 0 \cdot 2^1 + 1 = 29$，霍纳格式为

```text
      1   1   1   0   1
  2       2   6  14  28
  —————————————————————
      1   3   7  14  [29]
```

（自左向右：当前部分值乘 2 加下一位数码，得 1→3→7→14→29。）
