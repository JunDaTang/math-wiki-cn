# 共轭梯度法迭代与 n 步重启流程

依据 18.2.5.3（式 18.81–18.83）整理的共轭梯度法执行流程。

## 步骤（对应源文档 a/b/c）

- a) **初始化**：取 x¹ ∈ ℝⁿ 作为 x* 的适当初始近似，d¹ := −∇f(x¹)（18.82）。
- b) **主循环（k = 1, …, n）**：
  1. 沿 d^k 作精确线搜索：取 α_k ≥ 0 使 f(x^k+αd^k) 达到极小（18.83a，[[concepts/线搜索]]）；
  2. 更新 x^{k+1} := x^k + α_k d^k；
  3. 若 k < n，构造新方向 d^{k+1} := −∇f(x^{k+1}) + μ_k d^k（18.83b），系数

     μ_k = ‖∇f(x^{k+1})‖² / ‖∇f(x^k)‖²（18.83c，梯度模平方比）。
- c) **n 步重启**：以 x^{n+1} 与 d^{n+1} := −∇f(x^{n+1})（18.83c 末式）代替 x¹、d¹，重复步骤 b。
- 停止规则同通用规则 ∇f(x)=0（[[concepts/平稳点]]）。

## 为什么这样设计

- **n 步有限终止**：两两 C-共轭的方向组 d¹,…,dⁿ 配最优步长可在 n 步内解出凸二次问题 q(x)=xᵀCx+pᵀx（源断言，依据 [[concepts/共轭向量（C-共轭）]]；n 个两两共轭方向构成 ℝⁿ 的一组基——此句为维基补充说明）。
- **无须黑塞矩阵**：一般 f 在 x* 邻域近似二次，C ≈ ½H(x*)（Hess(xᵀCx+pᵀx)=2C，自洽 ✓），故为二次目标研发的方法可推广至一般 f 而无须显式使用 H(x*)——相对 [[concepts/牛顿法（无约束优化）]] 缺点 e（求逆代价）的优势。
- **重启**：n 步后方向组用尽，以负梯度重启以维持共轭性与下降性。
