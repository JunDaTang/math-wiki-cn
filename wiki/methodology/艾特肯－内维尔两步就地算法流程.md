# 艾特肯－内维尔两步就地算法流程

## 目的与原理（why）

在计算机上实施 [[艾特肯－内维尔插值]] 时，不必存储二维三角表格 (19.166)：只需引进有 n+1 个分量的向量 $\underline{\boldsymbol{p}}$（源引文献 [19.7]），根据规则依次取 (19.166) 中的列值——第 k 列的值 $p_{i-k,i-k+1,\cdots,i}$（$i=k,k+1,\cdots,n$）正是 $\underline{\boldsymbol{p}}$ 的第 i 个分量 $p_i$。由于必须**向下**计算 (19.166) 的列（每列的新值用到其左边及左上的数值），一个向量即可包含所有必要的数值，就地覆盖生成，最终分量 $p_n$ 即为给定点 x 处所求的函数值 $p_n(x)$。

## 流程（how）

```
步骤 (1)  初始化（对应 (19.168a)；原文乱码「Ẇ n = y_i」复原为 p_i = y_i）:
          i = 0, 1, …, n:      p_i = y_i

步骤 (2)  递推（对应 (19.168b)；内层循环下界 k 原文脱落，此处复原）:
          k = 1, 2, …, n:
            i = n, n−1, …, k:
              p_i ← p_i + (x − x_i)/(x_i − x_{i−k}) · (p_i − p_{i−1})
```

结束步骤 (2) 的计算后，元素 $p_n$ 即为在给定点 x 处要求的函数值 $p_n(x)$。

## 关键条件：内层循环必须自 n 递减至 k

这是本算法自洽的核心。原文 (19.168b) 脱落了下界 k（见 [[式19-168b之i循环下界脱k之辨]]），复原依据有二：

1. **下标意义**：第 k 列的值 $p_{i-k,\dots,i}$ 要求 $i\ge k$；若 i < k，则更新式分母中的 $x_{i-k}$ 下标为负，无意义。故 i 的取值恰为 $k, k+1, \dots, n$。
2. **就地覆盖安全**：更新 $p_i$ 时要用到 $p_{i-1}$ 在**上一列**（第 k−1 列）的旧值 $p_{i-k,\dots,i-1}$（对照 (19.167b)：$p_{123}$ 的计算用到 $p_{12}$）。若 i 自小到大递增，则计算后面的分量之前 $p_{i-1}$ 已被本列新值覆盖，旧值丢失；自 n 递减至 k 则每次取用的 $p_{i-1}$ 尚未被本列触碰。

（分量 $p_0,\dots,p_{k-1}$ 在第 k 阶段不更新，恰好为后续阶段保留所需的低列值。）

## 与表格 (19.166) 的对应

- 步骤 (1) 对应首列 $y_i = p_i$。
- 第 k 阶段对分量 i 的更新即 (19.167) 型递推：$p_{i-k,\dots,i}=p_{i-k+1,\dots,i}+\dfrac{x-x_i}{x_i-x_{i-k}}\left(p_{i-k+1,\dots,i}-p_{i-k,\dots,i-1}\right)$，其中分母 $x_i-x_{i-k}$ 与 (19.167a) 的 $x_3-x_2$、(19.167b) 的 $x_3-x_1$、(19.167c) 的 $x_4-x_1$ 逐一同型。逐项一致性验证通过，见 [[式19-164至19-168艾特肯内维尔递推与两步算法复算]]。
