# 沃尔泰拉积分方程数值解法

## 目的与结构约束（why）

对区间 $I=[a,b]$ 上第二类方程 (11.65)（λ=1 形式；含 λ 时同理）的解，用求积公式逼近**随 x 变化**的积分区间 [a,x] 上的积分 (11.66a)(11.66b)。与弗雷德霍姆情形（[[methodology/尼斯特伦法]] 一步形成全局线性方程组，见 [[concepts/半离散问题]]）根本不同：若 ξ 是 $Q_{[a,x]}(K(x,\cdot)\overline{\varphi}(\cdot))$ 的插值节点，则 $\overline{\varphi}(\xi)$ 必须已知，这要求先在 x=ξ 处求解——即**节点必须嵌套**（先算得的 φ 值才能作节点）。由此得出结构性结论：**高斯求积公式不可用**（其节点随区间端点变化且不嵌套；对照 [[concepts/高斯求积公式]] 在 11.2.4 中是弗雷德霍姆数值解的高精度首选——这是方法分化而非矛盾，不应把 11.2.4 的结论迁移到沃尔泰拉情形）。

## 一般递推格式

取插值节点 $a=x_0<x_1<\cdots$，记 $\varphi_k=\overline{\varphi}(x_k)$：

- **起点**：$\varphi_0=f(a)$ (11.66c)——即存在唯一性定理的 φ(a)=f(a)（原书回指 11.3.1，未入库）；
- **递推** (11.66f)：$\varphi_k=f(x_k)+Q_{[a,x_k]}(K(x_k,\cdot)\overline{\varphi}(\cdot))$，k=1,2,3,…；
- **求积形式** (11.66g)(11.66h)：$\varphi_k=f(x_k)+\sum_{j=0}^{k}w_{jk}K(x_k,x_j)\varphi_j$。

## 左矩形格式（显式）

系数 (11.66i)：$w_{jk}=x_{j+1}-x_j$（j<k）、$w_{kk}=0$；递推 (11.67a)(11.67b)：

$$\varphi_k = f(x_k) + \sum_{j=0}^{k-1}(x_{j+1}-x_j)\,K(x_k,x_j)\,\varphi_j.$$

右端只含已算得的 $\varphi_j$（j<k），是**显式步进**格式——类比 ODE 的显式 Euler 法（与 [[methodology/初值问题积分化流程]] 的 IVP↔沃尔泰拉对偶相呼应）。正式定义在手册 19.3.2.1（未入库）。

## 梯形格式（隐式）

等距节点 $x_k=a+kh$，复合梯形公式 (11.67c)；代入得 (11.67e)：

$$\varphi_k = f(x_k) + \frac{h}{2}\Big[K(x_k,x_0)\varphi_0 + K(x_k,x_k)\varphi_k + 2\sum_{j=1}^{k-1}K(x_k,x_j)\varphi_j\Big].$$

未知值 $\varphi_k$ 也出现在右端（隐式）；线性方程时易于显式解出。正式定义在 19.3.2.2（未入库）。

**非线性方程的回避方案（混合格式）**：用梯形公式确定 φ_k 须解一个非线性方程；可在 $[a,x_{k-1}]$ 上用梯形公式、在 $[x_{k-1},x_k]$ 上用矩形公式，h 足够小时求积误差对解无显著影响。

## 算例与精度

$\varphi(x)=2+\int_0^x(x-y)\varphi(y)\,\mathrm{d}y$，等距节点 $x_k=0.1k$（h=0.1）：φ₀=2，φ₁=2+0.1·0.1·2=2.02，φ₂=2+0.1(0.2·2+0.1·2.02)=2.0602，等等。数值表与逐行复算见 [[findings/式11-65至11-67e数值格式与算例表格复算]]；x=1.0 处矩形误差 0.1163、梯形误差 0.0010，精度比较见 [[comparisons/左矩形与梯形公式沃尔泰拉数值精度比较]]。

两点注意（原书未点明）：

- 本例 $K(x,x)=x-x=0$，梯形格式的“隐式”项消失，**实际退化为显式**；
- 表中“精确值”可识别为 **2cosh x**（由 [[methodology/沃尔泰拉方程微商化微分方程法]]：φ″=φ、φ(0)=2、φ′(0)=0），属推断。
