# 二项分布逼近选用流程

依据《数学手册(原书第10版)》16.2.3 整理的二项概率计算路径选择流程。

## 动机（why）

n 大时直接计算 C(n,k)p^k(1−p)^{n−k} 涉及大组合数与大数乘幂，手算与查表皆不便；手册提供两条逼近路线与一条递推路线，各有明确适用域。误用域外条件（如对 p 居中的二项分布套用泊松逼近）会显著损失精度，故须先判别 (n,p) 所处区域再选路径。

## 流程

给定 B(n, p)：

1. **判断 p 的量级**（以手册转写条件为据，存疑处见下）：
   - 若 **p 小**（手册实用判据：p ≤ 0.08 且 n ≥ 1500p，转写存疑）→ 走**泊松逼近**（第 3 步）；
   - 若 **n 大且 p 居中**（手册判据：np > 4 且 n(1−p) > 4，且 p 越接近 0.5、n 越大越好）→ 走**正态逼近**（第 4 步）；
   - 介于两者之间或 n 不大 → **直接递推计算**（第 2 步）。
2. **直接递推**：从 W_p^n(0) = (1−p)^n 出发，用 (16.65d) 逐点递推
   $$W_p^n(k+1) = \frac{n-k}{k+1}\cdot\frac{p}{q}\cdot W_p^n(k),$$
   一次遍历得到整个分布列；该递推已独立复算验证。
3. **泊松逼近**：取 λ = np，按 P(X=k) = λ^k e^{−λ}/k! 计算，用 (16.69c) 递推 P(k+1) = (λ/(k+1))·P(k)，或查手册第 1456 页表 21.16（未入库）。理论依据：n→∞、p→0、np=λ 常数的极限（[[concepts/二项分布的泊松逼近]]）。
4. **正态逼近**：取 μ = np、σ² = np(1−p)，用正态分布（16.2.4.1，未入库）计算概率；理论依据为 (16.65c)——标准化变量依分布收敛于 N(0,1)（[[concepts/二项分布的正态逼近]]）。

## 注意事项

- 两条逼近路线**适用域不同且互斥**：泊松逼近针对稀有成功（p 小），正态逼近针对成功与失败皆不稀有；同一组 (n,p) 不可同时套用两套条件。
- 手册两处判据（np>4 且 n(1−p)>4；p≤0.08 且 n≥1500p）转写均存疑（[[queries/泊松逼近条件n不小于1500p之辨]]、[[queries/1减p很小与p不大于008表述之辨]]），引用为该手册主张时应注明「待核原文」。
- 若问题本身是不放回抽样（[[concepts/超几何分布]]），先判断能否退化为二项：M 与 N−M 均远大于 n 时，按本流程以 p=M/N 处理。
