# 一阶偏微分方程解法选择流程

依据《数学手册（原书第 10 版）》9.2.1 的理论结构整理的解法分流流程。核心思想：每一条求解路线都是把偏微分方程问题**化归为常微分方程问题**（特征组、特征带方程组或典范组），因此方法选择的本质是判断方程属于哪个可化归类。本页是 [[methodology/一阶微分方程解法选择流程]]（ODE 侧）的 PDE 对应页，两页以 [[concepts/首次积分]] 为枢纽。

## 决策流程

1. **是否为全微分形式 dz = Σfᵢdxᵢ（9.81a）？** 是 → 检验完全可积条件：一般形式用 (9.81b) 的 n(n−1)/2 个等式，对称形式 Σfᵢdxᵢ = 0 用 (9.81d)（Frobenius 型条件）。完全可积时解归结为含 n−1 个参数的常微分方程；不可积则不属于本流程，需改写方程。
2. **是否线性齐次（9.71a 且 Y ≡ 0）？** 是 → 解特征组 (9.72a)（两种参数化：取使 Xₖ ≠ 0 的 xₖ 为自变量得 9.72b，或引入 t 得 9.72c），求 n−1 个无关首次积分 φ₁,…,φₙ₋₁，通解 z = Φ(φ₁,…,φₙ₋₁)（9.72e）。
3. **是否线性非齐次或拟线性（9.71a）？** 是 → 引入 V(x₁,…,xₙ,z)，解由 V = C 隐式给出，化为 n+1 个自变量的齐次方程 (9.73a)，解其特征组 (9.73b)（比齐次情形多一维 dz/Y）。
4. **非线性（9.76a）**，按可化归性依次尝试：
   - **克莱罗形式**：可写成 z = Σxᵢpᵢ + f(p₁,…,pₙ)（9.78a）→ 完全积分一步写出：z = Σaᵢxᵢ + f(a₁,…,aₙ)（9.78b）。
   - **典范组（HJ 型）**：方程不显含未知函数（或经 9.77a 的代换化为 p + H = 0 型，9.77b）→ 求完全积分 V = φ(…, a₁,…,aₙ) + a（9.77e），由 ∂φ/∂aᵢ = bᵢ 与 pᵢ = ∂φ/∂xᵢ 得典范组 (9.77c) 的 2n 参数通解（Jacobi 定理）。力学问题（如二体问题 9.79）优先走此路线。
   - **一般情形**：特征带（9.76d–f）——解带约束 F = 0 的 Charpit 型特征组。
5. **柯西问题的处理**（初始流形上取给定值 ψ，9.75c）：
   - 线性/拟线性：初始曲线处处有切线且处处不与特征相切 → 曲线邻域内唯一解；先解特征再拼积分曲面（曲面由与初始曲线相交的全部特征组成）。
   - 非线性：沿初始曲线可能有多个相容的 (p, q)，须额外指定满足 F = 0 与 pdx + qdy = dz 的连续函数 p、q；或用完全积分的单参数族取包络。
6. **几何检验**：解曲面应为积分曲面，由特征组成（9.74）；其法向量 (z_x, z_y, −1) 与向量 (P, Q, R) 垂直。

## 为什么这样分流（rationale）

- 等价性定理（特征组的首次积分 ⟺ 齐次线性 PDE 的解）保证第 2 步是完全化归，无信息损失。
- 非齐次/拟线性通过**升维**（n+1 个自变量）吸收右端项 Y，回到齐次框架——这是"把源项并入特征方向"的系统做法。
- 非线性方程的解**不能**再用首次积分组合（第 2 步的等价性不成立），必须同时在 (x, z, p) 空间追踪导数——这就是特征带；约束 F = 0 沿特征带守恒，保证化归自洽。
- 典范组是特征带在「方程不显含 z」特殊情形下的对称化形式；完全积分与典范组通解的对应（Jacobi 定理）依赖完全积分的雅可比非退化条件，是力学中哈密顿方法（源文称哈密顿函数、典范组/正规组）的基础。
- 全微分形式方程是唯一不需要特征线思想的类：其可积性由 Frobenius 型条件直接判定，解归结为低一维的常微分方程组。

## 边界与注意

- 一阶柯西问题的唯一性条件（初始曲线不与特征相切）是一阶特有的，不得移植到二阶方程（如波方程）的柯西问题；反之亦然。
- 本流程不覆盖二阶方程的典范形式约化，那属于 [[methodology/二阶偏微分方程分类与典范形式约化流程]]。
