# 多值函数主值化流程

## 目的与理据

初等复函数中，$e^z$ 的周期性（相差 $2k\pi\mathrm{i}$）经反演传递给对数，再传递给一般指数函数与全部反三角/反双曲函数，造成系统性多值。源文（14.5.2）以统一约定处理：**多值函数用大写记号（$Ln$、$Arcsin$……），主值用小写记号（$\ln$、$\arcsin$……）**。

## 流程

1. **识别多值源**：检查函数是否含 $Ln$、平方根或周期函数的反演。
2. **多值表示**：以 $Ln$（及 $\sqrt{\,}$）写出完整多值式，如 $Ln z = \ln\rho + \mathrm{i}(\varphi + 2k\pi)$（14.74b）、$a^z = e^{z\,Ln a}$（14.75a）、$Arcsin z = -\mathrm{i}\,Ln(\mathrm{i}z + \sqrt{1-z^2})$（14.83a）。
3. **主值化**：将 $Ln$ 换为主值 $\ln$（辐角限于 $-\pi < \varphi \leqslant \pi$，式 14.74d），得到小写主值式：$\ln z$、$e^{z\ln a}$（14.75b）、$\arcsin z = -\mathrm{i}\ln(\mathrm{i}z + \sqrt{1-z^2})$（14.87a）。
4. **核对**：主值式与多值式形式相同、仅对数记号降级；若源文在多值语境出现小写 $\ln$（如转写文本 14.74c、14.83a、14.84a），应怀疑转写/排印讹误（见 [[queries/式14-83a与14-84a多值式ln疑为Ln]]）。

## 适用范围

本流程在本源中覆盖三层：对数层（14.74）、指数层（14.75）、反函数层（14.83–14.90）。成对结构见 [[comparisons/多值函数与其主值表示比较]]。

## 边界

源文未讨论主值支的解析性/分支切割问题（如 $\ln z$ 在负实轴上的不连续），该主题超出本源范围。
