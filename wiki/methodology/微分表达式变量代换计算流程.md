# 微分表达式变量代换计算流程

本流程整理《数学手册(原书第10版)》6.2.4 的方法，用于把含各阶（偏）导数的微分表达式 F 在变量代换或坐标变换下系统改写。其**为何可行**的根源有二：一元情形是链式法则与商法则的逐阶迭代；二元情形是一阶偏导数关系对任意函数成立，因而可提升为算子恒等式并递推（见 [[concepts/偏导数算子变换]]）。

## 一元流程

1. **识别代换类型**（对照 [[comparisons/四种变量代换情况比较]]）：
   - 自变量显式代换 x = φ(t) → 情况 1a，套式 6.59；
   - 自变量隐式代换 Φ(x,t) = 0 → 情况 1b，同套式 6.59，φ 的各阶导数改按隐函数法则求（式 6.60）；
   - 因变量代换 y = φ(u) → 情况 2，套式 6.61；
   - 自变量与因变量同时代换 x = φ(t,u), y = ψ(t,u) → 情况 3，套式 6.62。
2. **检查正则性条件**：φ′(t) ≠ 0（情况 1a/1b）、隐函数定理条件（情况 1b）、B ≠ 0（情况 3）。源文未声明，须自查。
3. **代入与消元**：把各阶导数公式代入 F；若式中残留旧变量（如 x），用代换关系消去（情况 1b 用式 6.60）。
4. **已知讹误修正**：引用式 6.59c 时末项因子改为 dy/dt（[[findings/式6-59c末项因子讹误复算判定]]）；式 6.62 的编号链按内容定位而非编号（[[queries/式6-62c-d编号错位如何复原]]）。

## 二元流程

1. **写出代换** x = φ(u,v), y = ψ(u,v)，确认 J = φ_uψ_v − φ_vψ_u ≠ 0（局部可逆；源文未声明）。
2. **列一阶方程组**（式 6.65b，链式法则），解出 ω_x = Aω_u + Bω_v、ω_y = Cω_u + Dω_v（式 6.65c）；需要显式系数时用 A = ψ_v/J、B = −ψ_u/J、C = −φ_v/J、D = φ_u/J（复算补全，源文未给出，见 [[findings/二元代换偏导数方程组与系数-式6-65]]）。
3. **算子递推高阶**：把 ∂/∂x = A∂/∂u + B∂/∂v、∂/∂y = C∂/∂u + D∂/∂v 当作算子恒等式，逐次作用于已得的低阶偏导数；乘积求导时勿漏 A、B、C、D 自身的偏导数项（式 6.66 即第一次递推的结果，见 [[findings/二阶偏导数算子递推-式6-66]]）。
4. **坐标变换特例**：极坐标下 ∂/∂x = cos φ ∂/∂ρ − (sin φ/ρ) ∂/∂φ、∂/∂y = sin φ ∂/∂ρ + (cos φ/ρ) ∂/∂φ；曲线导数直接用式 6.63（[[findings/极坐标一二阶导数公式-式6-63]]），拉普拉斯算子用式 6.67c（[[findings/拉普拉斯算子极坐标形式-式6-67]]）。注意 ρ = 0 奇异。

## 为何算子递推可行（rationale）

式 6.65c 之所以可以「对 ω 任意替换」，是因为它对**每一个**（ sufficiently 可微的）函数都成立——这是代换关系本身的性质，与具体 ω 无关。因此把 ω 换成 ω_x、ω_y 或任何低阶偏导数，等式依然成立；这正是源文「用同样的公式计算二阶偏导数」「用同样的方法计算高阶偏导数」的合法依据。一元情形的四组公式同理：它们都是恒等变换，可反复迭代到任意阶（源文展至三阶并以「…」示意更高阶）。

## 适用边界

- 源文仅覆盖一元（四种情况）与二元；含两个以上变量的情形仅有「可得到类似的代换公式」的断言，无公式无证明。
- 各正则性条件失效点（φ′ = 0、B = 0、J = 0、ρ = 0）附近公式不适用，须另行处理。
