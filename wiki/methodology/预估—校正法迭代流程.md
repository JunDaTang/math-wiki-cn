# 预估—校正法迭代流程

**目的与原理**：隐式多步法在相同精度下允许大得多的步长（源文断言），但每步需求解关于 y_{i+k} 的（一般非线性）方程 (19.105)。预估—校正法以显式公式提供迭代初值（预估子），再以不动点迭代 (19.106) 校正——这是 [[concepts/一般迭代法]] 在微分方程数值解中的直接应用，(19.105) 即 [[concepts/零形式与不动点形式]] 的不动点化。

**步骤**（以 (19.107) 对为例）：

1. **预估**：y_{i+1}^{(0)} = y_i + (h/12)(5f_{i−2} − 16f_{i−1} + 23f_i)（式 19.107a）。
2. **校正迭代**：y_{i+1}^{(μ+1)} = y_i + (h/12)(−f_{i−1} + 8f_i + 5f_{i+1}^{(μ)})，μ = 0, 1, …，直至收敛（式 19.107b）。
3. 置 f_{i+1} = f(x_{i+1}, y_{i+1})，i ← i+1，回到步骤 1。

**变体**：(19.108a,b) 对（预估子 (19.108a) + 辛普森型校正子 (19.108b)）；因源文称辛普森校正子数值不稳定，可用稳定化格式 (19.109) 替换校正子。复算结论：(19.107) 对为三阶，(19.108a) 与 (19.109) 均为四阶，见 [[findings/式19-105至19-109预估—校正公式复算]] 与 [[comparisons/预估—校正两对公式比较]]。
