# 第一类退化核方程求解流程

适用于具有退化核的第一类弗雷德霍姆积分方程（式 11.38a），依据数学手册(原书第10版) 11.3.1。

## 流程步骤

1. **可解性判定**：写出 f(x) = A₁α₁(x) + … + A_nα_n(x)（11.38c，其中 A_j = ∫_a^b β_jφ dy）。方程有解 ⟺ f 是 α₁,…,α_n 的线性组合；若满足，先定出 A₁,…,A_n。
2. **待定系数假设**：设解形如 φ = c₁β₁ + … + c_nβ_n（11.39a），系数 c₁,…,c_n 未知。
3. **建立 Gram 型方程组**：代入 (11.38b) 得 (11.39b–d)，系数 K_ij = ∫_a^b β_iβ_j dy 为 β 组的 Gram 矩阵。β₁,…,β_n 线性无关 ⟹ 系数矩阵非奇异（判据见第 858 页 12.1.3），方程组唯一解出 c_j。
4. **叠加齐次解**：齐次方程的全部解 = 与所有 β_j 正交的函数全体（11.40）。通解 = 第 3 步特解 + 任意齐次解 φ^h。

## 设计原理（why）

第一类方程中积分算子只通过核的 β 因子「看见」未知函数，故右端 f 必须落在 α 因子张成的空间内（可解性受限）；而正交于所有 β_j 的函数方向对积分完全「不可见」，构成无穷维齐次解集——这正是退化核第一类方程**解不唯一**的根源。对照第二类退化核流程 [[methodology/退化核求解流程]]：其系数方程组含 φ(x) 自身项、按行列式判据分两种情形，且 λ 非本征值时解唯一，与本流程的结构性结论根本不同。

## 限制

- 仅当核为退化核（有限项分离和）时可直接使用；
- 「齐次方程总有非平凡解」是退化核特有结论，不可外推到一般核（反例见 [[findings/式11-47与sin权奇异核算例对角化与反演公式复算]] 与 [[findings/式11-48a至11-50e齐次与伴随齐次解法及算例转录复算]]）。
