# 核矩阵双对角化构造流程

对给定核 K(x,y) 构造两个特殊的规范正交系 (α_n)、(β_n)，使 [[concepts/核矩阵]] 的系数 K_ij 仅当 i = j 与 i = j+1 时非零（分块双对角，式 11.52），从而化简无穷方程组的求解。依据数学手册(原书第10版) 11.3.5。

## 预备

先用 11.3.4 的方法确定齐次积分方程解组 (β_n^h(y)) 与伴随齐次积分方程解组 (α_n^h(x)) 的规范正交系——这两个系**不是完全的**，本流程将它们一步一步完备化。

## 流程步骤

**起步**：确定一个归一化函数 α₁(x)，它正交于每个 α_n^h。再对 j = 1,2,… 交替施行：

(1) 由下式确定 β_j(y) 与数 ν_j（ν_j ≠ 0 且 β_j 归一化，正交于此前所有 β 与 (β_n^h)）：

$$
\nu_1\beta_1(y)=\int_c^d K(x,y)\alpha_1(x)\,\mathrm{d}x\tag{11.51a}
$$
$$
\nu_j\beta_j(y)=\int_c^d K(x,y)\alpha_j(x)\,\mathrm{d}x-\mu_{j-1}\beta_{j-1}(y)\quad(j\neq1)\tag{11.51b}
$$

(2) 由下式确定 α_{j+1}(x) 与数 μ_j：

$$
\mu_j\alpha_{j+1}(x)=\int_a^b K(x,y)\beta_j(y)\,\mathrm{d}y-\nu_j\alpha_j(x)\tag{11.51c}
$$

两种可能：(a) μ_j ≠ 0，α_{j+1} 正交于此前所有 α 与 (α_n^h)；(b) μ_j = 0，α_{j+1} 不唯一——若系已完全则过程结束（此时 (β_n^h) 连同 β₁,…,β_j 亦完全），否则任取一个与此前所有函数正交的 α_{j+1} 重启。过程重复至系完全为止；若情形 (b) 可数步内不出现而系仍不完全，可由正交于此前全系的 α̃₁ 重新开始。

**产物**：核矩阵呈分块双对角形式

$$
\boldsymbol{K}=\begin{pmatrix}0&0&0&\dots\\0&\boldsymbol{K}^1&0&\dots\\0&0&\boldsymbol{K}^2&\dots\\\vdots&&\dots&\vdots\end{pmatrix},\qquad
\boldsymbol{K}^m=\begin{pmatrix}\nu_1^{(m)}&0&0&\dots\\\mu_1^{(m)}&\nu_2^{(m)}&0&\dots\\0&\mu_2^{(m)}&\nu_3^{(m)}&\dots\\\vdots&\ddots&\ddots&\vdots\end{pmatrix}\tag{11.52}
$$

零行与零列的数目分别相应于 (α_n^h) 与 (β_n^h) 中函数的数目；若某块只含单个数 ν₁^(m) = ν_m（所有 μ 为零），则该情形「非常简单」。

## 解公式（11.53）及警示

在 α_j ∈ (α_n^h) ⟹ f_j = 0 的假设下，手册给出

$$
c_j=\begin{cases}\dfrac{f_j}{\nu_j},&\beta_j(y)\notin\big(\beta_n^h(y)\big),\\[4pt]\text{任意},&\beta_j(y)\in\big(\beta_n^h(y)\big).\end{cases}\tag{11.53}
$$

⚠️ 复算注记：递推等价于 T*α_j = ν_jβ_j + μ_{j−1}β_{j−1}、Tβ_j = ν_jα_j + μ_jα_{j+1}，故 K_ij = ν_jδ_ij + μ_jδ_{i,j+1}；一般双对角块的求解需**向前代入** c_j = (f_j − μ_{j−1}c_{j−1})/ν_j，转写 (11.53) 的 c_j = f_j/ν_j 仅在 μ ≡ 0 的「非常简单」情形成立——见 [[queries/式11-53解公式与双对角向前代入的关系]]。

## 设计原理（why）

直接投影所得无穷方程组不比原问题容易；本流程通过构造性地选择基对，把算子的矩阵表示压成最稀疏的双对角结构，使方程组可逐分量递推求解。齐次/伴随齐次解组在矩阵中表现为零行/零列，可解性条件（α_j ∈ (α_n^h) ⟹ f_j = 0）与解的自由度（β_j ∈ (β_n^h) ⟹ c_j 任意）在矩阵结构中一目了然。
