# 梅尔尼科夫

梅尔尼科夫（Melnikov；可独立核验的背景：苏联数学家，以 1960 年代提出的、用于判定受扰哈密顿系统稳定与不稳定流形横截相交的梅尔尼科夫方法闻名）。在数学手册 17.3.2.3 之 3 中，他是 [[concepts/梅尔尼科夫方法]] 及梅尔尼科夫函数 M(t₀)（式 (17.92)）的冠名者。

## 在本源中的内容

- 方法设定：平面哈密顿系统 ẋ=f(x) 加周期小扰动 εg(t,x)（式 (17.90)），未扰动系统关于鞍点有同宿轨（或异宿轨）。
- 核心判据：M(t₀) = ∫ f(φ(t−t₀))∧g(t, φ(t−t₀)) dt 有单根 ⇔ 充分小 ε>0 时 W^s(p_ε) 与 W^u(p_ε) 横截相交；M 无根则无同宿点。
- 单摆算例可复算：M(t₀) = ∓2π sin(ωt₀)/cosh(πω/2)，见 [[findings/式17-90至17-92梅尔尼科夫方法与单摆算例复算]] 与 [[methodology/梅尔尼科夫函数计算与横截相交判别流程]]。

## 关联

判据确立横截同宿点后，可接斯梅尔定理（[[entities/斯梅尔]]）得到马蹄与混沌；与什尔尼科夫定理（[[entities/什尔尼科夫]]）的比较见 [[comparisons/同宿分岔三定理比较]]。
