# C_n（循环点群）

**$C_n$ 是正 $n$ 边形绕垂直于图形平面且通过其中心的轴旋转角度 $\varphi_k = 2\pi k/n$（$k = 0, 1, \dots, n-1$）后与自身重合的全部旋转所构成的点群**：它是 $n$ 阶阿贝尔循环群，由单个生成元 $R_1$ 生成，$R_1^n = e$（式 5.98a）：

$$C_n = \{e, R_1, R_1^2, \dots, R_1^{n-1}\}, \quad R_1^n = e.$$

## 在本来源中的内容（5.3.4.1 例 A）

取等边三角形（$n=3$，中心为原点），旋转角 $\varphi_0 = 0$、$\varphi_1 = 2\pi/3$、$\varphi_2 = 4\pi/3$（式 5.98b），顶点轮换为（式 5.98c）

- $R_0 = e$: A→A, B→B, C→C
- $R_1$: A→B, B→C, C→A
- $R_2$: A→C, B→A, C→B

满足 $R_2 = R_1^2$、$R_1\cdot R_2 = R_1^3 = e$（式 5.98d），构成 $C_3$。（转写注：式 5.98c 第三行标签「R₃」应为 $R_2$，$C_3$ 中不存在 $R_3$。）

## 二维表示（式 5.98e–g）

旋转矩阵 $R(\varphi)=\begin{pmatrix}\cos\varphi & -\sin\varphi\\ \sin\varphi & \cos\varphi\end{pmatrix}$（式 5.98e）代以 (5.98b) 的角度，给出 $C_3$ 的忠实二维表示：

```text
D(e)  = R(0)    = [[1, 0], [0, 1]]
D(R₁) = R(2π/3) = [[-1/2, -√3/2], [√3/2, -1/2]]
D(R₂) = R(4π/3) = [[-1/2,  √3/2], [-√3/2, -1/2]]
```

已复算：三矩阵行列式均为 +1（纯旋转）；$D(R_1)^2 = D(R_2)$、$D(R_1)D(R_2) = D(e)$，与群关系 (5.98d) 一致。详见 [[findings/c3二维旋转表示算例]]。转写警示：式 (5.98h) 内部不一致，见 [[queries/式5-98h首项是否应为D-R1的平方]]。

## 与其他页面的联系

- $C_n$ 的旋转矩阵是平面旋转群（嵌入 SO(3)）的有限子群实例，参见 [[entities/so3三维旋转群与-so3]]。
- 加入 $n$ 个反射得到非阿贝尔的二面体群；$n=3$ 情形即 [[entities/d-3二面角群]]，比较见 [[comparisons/c3与d3比较]]。
