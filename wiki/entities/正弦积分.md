# 正弦积分 Si(x)

正弦积分 Si(x) 是由积分 ∫₀ˣ (sin t)/t dt 定义的特殊函数：被积函数 (sin t)/t 虽为初等函数，其原函数却非初等，故以积分本身定义新函数，并在全实轴 |x| < ∞ 上有意义。本书 8.2.5 给出其定义、余积分恒等式与交错幂级数（式 8.95）。

## 定义与级数（式 8.95）

```latex
\operatorname{Si}(x) = \int_{0}^{x} \frac{\sin t}{t}\,\mathrm{d}t = \frac{\pi}{2} - \int_{x}^{\infty} \frac{\sin t}{t}\,\mathrm{d}t
= x - \frac{x^{3}}{3 \cdot 3!} + \frac{x^{5}}{5 \cdot 5!} - + \dots + \frac{(-1)^{n} x^{2n+1}}{(2n+1) \cdot (2n+1)!} + \dots \tag{8.95}
```

第二恒等式 Si(x) = π/2 − ∫ₓ^∞ (sin t)/t dt 依赖狄利克雷积分 ∫₀^∞ (sin t)/t dt = π/2（复算一致）；级数由 sin t/t 的泰勒展开逐项积分得到，对一切 x 收敛（|x| < ∞）。
