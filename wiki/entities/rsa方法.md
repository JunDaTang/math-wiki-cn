# RSA（RSA 码与 RSA 方法）

RSA 是一种基于欧拉-费马定理（本手册记法，即 [[concepts/费马-欧拉定理]]）的公开密钥（非对称）加密方法，由 Rivest、Shamir、Adleman 三人发展（本源因转写讹误作「vest, Shamir Adleman」，疑脱「Ri」），名称取自三人姓氏首字母。其核心特征是解密所需的密钥部分（模数 m 与加密指数 r）可以公开而不危害消息的机密性，故本手册亦称之为「公开密钥码」；手册并称 RSA 方法为「最普及的非对称加密方法」。

## 机制

```
RSA 码：选取大素数 p, q；m = pq；取 r 使 gcd(r, φ(m)) = 1，φ(m) = (p−1)(q−1)，1 < r < φ(m)；公布 m 与 r。
加密:  N^r ≡ R (mod m)                                              (5.276a)
解密:  解线性同余式 rs ≡ 1 (mod φ(m)) 得 s，则
       R^s ≡ (N^r)^s ≡ N^{1+kφ(m)} ≡ N·(N^{φ(m)})^k ≡ N (mod m)      (5.276b)

RSA 方法（n = pq，d·e ≡ 1 (mod (p−1)(q−1))）：
E(x) := x^e mod n                                                    (5.277a)
D(x) := x^d mod n                                                    (5.277b)
于是 D(E(m)) = E(D(m)) = m
```

明文先转换为数字串并分裂成若干等长区组（每区组小于 100 个十进制数位），逐组加密；解密后再转回文本。式 (5.276b) 的推导直接引用 N^{φ(m)} ≡ 1，严格说需 [[concepts/费马-欧拉定理]] 的前提 gcd(N, m) = 1，原文未声明（见 [[queries/rsa模幂需gcd条件缺失]]）。

## 算例（p=29, q=37, r=5, s=605，全链已复算）

B 选 p = 29、q = 37（原文明言「实际上这对于实用目的太小了」）：m = 29·37 = 1073，φ(m) = 28·36 = 1008，取 r = 5（gcd(1008, 5) = 1），将 m 与 r 传给 A。A 加密 N = 8：8⁵ = 32768 ≡ 578 (mod 1073)，发送 R = 578。B 解 5s ≡ 1 (mod 1008) 得 s = 605，于是 578⁶⁰⁵ ≡ 8 (mod 1073)。

**模数讹误判定**：原文正文两处印作 m = 29·37 = 1037，但 29×37 = 1073；且若 m = 1037（= 17×61）则 φ = 960 ≠ 1008、8⁵ ≡ 621 (mod 1037) ≠ 578。算例内部所有计算均与 1073 一致，故 1037 为数字倒置讹误。详见 [[findings/rsa算法与算例]] 与 [[queries/rsa算例模数1037是否应为1073]]。

## 参数选取准则与安全性（原书版次年代观点，部分表述脱落）

- 素数 p、q 应至少有 100 个十进制数位；原书估计当代计算机分解 m 需约 74 年。
- p 与 q 的十进制数位相差应是一个小的数；「相差不太大」的表述疑有转写之误（见 [[queries/pq约10-2048与n大于10-200量级问题]]）。
- p−1 与 q−1 应含相当大的素因子，且 gcd(p−1, q−1) 应相当小。
- 当 n > 10²⁰⁰ 时，加密函数成为候选的陷门单向函数（陷门＝分解 n 的知识，见 [[concepts/陷门单向函数]]）。
- 缺点：密钥相对较大；与 DES 相比的速度表述（「RSADES 1000」）疑为截断脱落，未对照原书前不作断言。

RSA 的安全性系于分解 m = pq 的难度，而非密钥穷尽搜索——与 DES 的 2⁵⁶ 穷尽可破性质不同类，二者结论不可相互转移。
