# 高斯误差积分 Φ(x)

高斯误差积分 Φ(x) 是标准正态分布的分布函数（原书明确标注「参见第 1070 页 16.2.4.2」），定义为 (1/√(2π)) ∫₋∞ˣ e^{−t²/2} dt；其零中心变体 Φ₀(x) = Φ(x) − 1/2 与误差函数满足 erf(x) = 2Φ₀(x√2)，构成积分论与统计学之间的桥梁。数值可查原书 1458 页的表 21.17（未入库）。

## 定义（式 8.99）

```latex
\varPhi(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{x} \mathrm{e}^{-\frac{t^{2}}{2}}\,\mathrm{d}t, \qquad \lim_{x\to\infty} \varPhi(x) = 1 \tag{8.99a,b}

\varPhi_{0}(x) = \frac{1}{\sqrt{2\pi}} \int_{0}^{x} \mathrm{e}^{-\frac{t^{2}}{2}}\,\mathrm{d}t = \varPhi(x) - \frac{1}{2} \tag{8.99c}
```

被积函数 e^{−t²/2} 为偶函数且 ∫₋∞^∞ e^{−t²/2} dt = √(2π)，故 Φ₀ = Φ − 1/2 且 lim Φ = 1（复算一致）。

## 与误差函数的关系

erf(x) = 2Φ₀(x√2)（式 8.100a，经代换 t = u√2 复算一致）；反之 Φ(x) = 1/2 + (1/2)erf(x/√2)（由 8.99c 与 8.100a 导出，非原书原式）。换算细节见 [[高斯误差积分与误差函数比较]] 与 [[误差函数]]。
