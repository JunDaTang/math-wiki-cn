# 角动量算子 l̂

角动量算子 l̂ 是量子力学中表示（轨道）角动量的矢量算符，由位置算子 r̂ 与动量算子 p̂ 的叉积定义：l̂ = r̂ × p̂，其直角分量为作用于波函数的一阶微分算子（9.115）：

```latex
\hat{\vec{l}} = (\hat{l}_x,\hat{l}_y,\hat{l}_z) = \hat{\vec{r}}\times\hat{\vec{p}}
\hat{l}_x = \hat{y}\hat{p}_z - \hat{z}\hat{p}_y = \frac{\hbar}{\mathrm{i}}\Big(y\frac{\partial}{\partial z} - z\frac{\partial}{\partial y}\Big)      % 9.115a
\hat{l}_y = \hat{z}\hat{p}_x - \hat{x}\hat{p}_z = \frac{\hbar}{\mathrm{i}}\Big(z\frac{\partial}{\partial x} - x\frac{\partial}{\partial z}\Big)
\hat{l}_z = \hat{x}\hat{p}_y - \hat{y}\hat{p}_x = \frac{\hbar}{\mathrm{i}}\Big(x\frac{\partial}{\partial y} - y\frac{\partial}{\partial x}\Big)      % 9.115b
```

## 物理意义与中心场中的角色

- 手册以 l̂ 为「算子控制经典表达的结构」的典型例子：经典 l⃗ = r⃗ × p⃗ → 把 r⃗、p⃗ 换成相应算子。
- 其平方的本征值为（9.137f）：

```latex
\vec{l}^{2} = l(l+1)\hbar^{2},\qquad |\vec{l}| = \hbar\sqrt{l(l+1)}
```

  这是中心对称场分离变量中分离常数取 l(l+1) 的物理来源（见 [[concepts/中心对称场中的粒子运动]]）。
- 由此产生离心位势 V_l = l(l+1)ℏ²/(2mr²)（9.137d），与经典转动能类比（9.137e）：E_rot = ½Θω⃗² = l⃗²/(2Θ) = l⃗²/(2mr²)，其中 Θ = μr² 为转动惯量。角动量算子的这一物理意义与转动粒子的经典转动能相似。
- 角动量属于可观察量，对应算子满足厄米性（[[concepts/可观察量与厄米算子]]）。

## 勘误

原书 9.137f 将 |l⃗| 误排为 |l⃗²|，源内译者注已明确指出——这是已证实的原书印刷错误，而非本次转写引入。
