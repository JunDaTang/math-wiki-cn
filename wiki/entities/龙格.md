# 龙格

龙格（Carl Runge，1856—1927）是德国数学家与物理学家，数值分析与数学物理中的多个概念以其命名（此为可独立查证的公共背景信息，非本源文档所载）。

在本源文档中，龙格是龙格—库塔法 (19.99) 的冠名者之一（另一冠名者为 [[entities/库塔]]）。归属于该方法的论断（均出自数学手册 19.4.1.2 与 19.4.1.5）：

- 四阶计算格式 (19.99)：在起点与下一插值点之间引入“辅助点”，依赖辅助点的数目与排列有不同阶的龙格—库塔法；四阶格式每步误差为 h⁵ 阶。
- 四阶收敛（p = 4）、四阶相容（p = 4）。
- 对特殊方程 y′ = f(x) 化为辛普森公式（19.3.2.3，未入库）。
- 高阶方程化为 一阶方程组后可依 (19.99) 并行计算。
