# 二元布尔代数 B（B = {0,1}）

二元布尔代数 $B$ 是定义在两元素集 $\{0,1\}$ 上的布尔代数：$\sqcap$ 即逻辑「与」，$\sqcup$ 即逻辑「或」，补运算交换 $0$ 与 $1$；$1$ 是 $\sqcap$ 的中性元素，$0$ 是 $\sqcup$ 的中性元素。手册 5.7.3 以三张运算表定义它（转写完整，已逐项核对），并在 5.7.3 与 5.7.5 两处反复使用：既是全部有限布尔代数的基本构件，又是布尔函数的取值域。

## 运算表（式见 5.7.3）

```
⊓ | 0 1        ⊔ | 0 1        补 | 值
--+---        --+---        --+----
0 | 0 0        0 | 0 1        0 | 1
1 | 0 1        1 | 1 1        1 | 0
```

## 结构角色

- **有限布尔代数的构件**：$B^n$（$n$ 重直接积，按分量运算）含 $2^n$ 个元素，给出所有有限布尔代数（不计同构者），见 [[concepts/有限布尔代数]]。
- **布尔函数的值域**：$n$ 重布尔函数即映射 $B^n\to B$，见 [[concepts/布尔函数]]。

## 与 ℤ₂ / GF(2) 的关系

$B$ 的载体集 $\{0,1\}$ 与 [[comparisons/素域q与zp比较]]、[[comparisons/gf-pn与zp-n比较]] 中的 ℤ₂ = GF(2) 相同；$\sqcap$ 的运算表即 ℤ₂ 乘法，而表 5.6 中 XOR 的记号 $a\oplus b$ 在 $\{0,1\}$ 上的取值恰为 ℤ₂ 加法（此对应为推断，源未陈述）。但 $(B,\sqcap,\sqcup,\bar{\ })$ 作为布尔代数与 ℤ₂ 作为域是不同类型的结构：$\sqcup$（或）不是 ℤ₂ 的环加法（$1\sqcup 1=1\ne 0$）。
