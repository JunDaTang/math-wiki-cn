# 达朗贝尔公式

达朗贝尔公式（d'Alembert 公式，式 9.106c）是一维（n = 1）齐次波方程柯西问题解的显式公式：解等于初始位移 φ 在 x₁ + at 与 x₁ − at 两点值的平均，加上初始速度 ψ 在区间 [x₁ − at, x₁ + at] 上的积分乘以 1/(2a)。它是 [[波方程]] n = 1 情形的解公式，与前因子结构不同的 n = 3 [[基尔霍夫公式]]、n = 2 [[泊松公式]] 并列，是三者中最常被单独引用的一个。

## 公式（逐字转录）

```latex
u(x_{1}, t) = \frac{\varphi(x_{1} + at) + \varphi(x_{1} - at)}{2} + \frac{1}{2a} \int_{x_{1}-at}^{x_{1}+at} \psi(\alpha)\, \mathrm{d}\alpha \tag{9.106c}
```

初始条件同式 9.105；a 为扰动的波速。

## 结构与复算

- 与标准 d'Alembert 公式完全一致（独立复算，见 [[式9-106a至9-106c三维二维一维齐次解复算]]）。
- 积分区间端点 x₁ ± at 正是一维波方程特征线的位置（“特征线”为标准术语，独立可验证背景；源未使用该词）。
- 非齐次问题（Q ≠ 0）时须叠加式 9.107c 的附加项：三角形域 T（0 ⩽ τ ⩽ t，|ξ − x₁| ⩽ a|t − τ|）上的二重积分 (1/(2a))∬_T Q(ξ, τ) dξ dτ。
- 源文“情形n=l”中的"l"为"1"的 OCR 之讹（见 [[9-2-3全节系统性转写讹误清单]]）。

“d'Alembert”在本源中仅作冠名出现，无任何生平叙述。
