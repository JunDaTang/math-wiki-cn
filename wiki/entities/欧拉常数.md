# 欧拉常数 C

欧拉常数是一个数学常数，数值 C = 0.577215665…；本书在 8.2.5 以其积分定义引入（式 8.96b），并记作字母 C。通行文献多记作 γ——此为本书记号约定，入库时不予改写。

（可独立验证的公共背景，非本源原文：欧拉常数通常定义为 γ = lim_{n→∞}(1 + 1/2 + ⋯ + 1/n − ln n)，与下述积分定义等价。）

## 本书给出的定义（式 8.96b）

```latex
C = -\int_{0}^{\infty} \mathrm{e}^{-t} \ln t \,\mathrm{d}t = 0.577215665\dots \tag{8.96b}
```

数值与通行值 γ ≈ 0.5772156649… 一致（复算核对）。

## 在本源中的角色

- 作为公共常数项同时出现在三组级数中：[[余弦积分]] Ci（式 8.96a）、[[对数积分Li]] Li（式 8.97）、[[指数积分]] Ei（式 8.98a）；三者共享的「C + ln|·| + Σ·ⁿ/(n·n!)」骨架见 [[Ci-Li-Ei三函数级数结构比较]]。
- 记号旁证：本书既以 C 记欧拉常数，则 8.1.6 转写文本根指数位置出现的字母 e 更不应理解为欧拉常数，见 [[根指数字母e是否原书记号]]。
