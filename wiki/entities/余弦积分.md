# 余弦积分 Ci(x)

余弦积分 Ci(x) 是由反常积分 −∫ₓ^∞ (cos t)/t dt 定义的特殊函数（定义域 0 < x < ∞）：被积函数 (cos t)/t 在 t = 0 处发散，积分从 x 起向无穷延伸。其级数表示以欧拉常数 C 为公共常数项，并与正弦积分构成 sin/cos 对偶。

## 定义与级数（式 8.96a）

```latex
\operatorname{Ci}(x) = -\int_{x}^{\infty} \frac{\cos t}{t}\,\mathrm{d}t = C + \ln x - \int_{0}^{x} \frac{1-\cos t}{t}\,\mathrm{d}t
= C + \ln x - \frac{x^{2}}{2 \cdot 2!} + \frac{x^{4}}{4 \cdot 4!} - + \dots + \frac{(-1)^{n} x^{2n}}{2n \cdot (2n)!} + \dots \tag{8.96a}
```

## 欧拉常数（式 8.96b）

```latex
C = -\int_{0}^{\infty} \mathrm{e}^{-t} \ln t \,\mathrm{d}t = 0.577215665\dots \tag{8.96b}
```

本书记作 C（通行文献多记作 γ），详见 [[欧拉常数]]。C 同时出现在 Li 与 Ei 的级数中，三者的共同骨架见 [[Ci-Li-Ei三函数级数结构比较]]。
