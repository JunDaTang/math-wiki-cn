# ℓ^p 空间

ℓ^p 空间是由所有使级数 $\sum_{n=1}^{\infty}|\xi_n|^p$ 收敛的序列 $x = \{\xi_n\}_{n=1}^{\infty}$（ξₙ ∈ 𝔽）组成的向量空间，加法与数乘按逐项（逐坐标）方式定义。它是泛函分析中最基本的序列空间之一，《数学手册(原书第10版)》12.1.2 例 G 将其作为向量空间的中心例子引入，后续 12.x（赋范空间等）章节将反复复用。

## 定义与封闭性

序列 x 属于 ℓ^p 当且仅当 Σ|ξₙ|^p < ∞。两个 ℓ^p 序列之和仍在 ℓ^p 中，这一封闭性由**闵可夫斯基不等式**保证（12.1 回指 1.4.2.13，该节未入库，见 [[queries/12-1未入库回指缺口]]）。

## 在包含链中的位置（式 12.12）

```
φ ⊂ ℓ^p ⊂ ℓ^q ⊂ c₀，   1 ≤ p < q < ∞
```

即：有限支撑序列（[[entities/典型序列空间]] 中的 φ）均属 ℓ^p；p 越大空间越大；一切 ℓ^p 序列都收敛于零，故含于 [[entities/c0空间]]。完整链及与函数空间链的比较见 [[comparisons/序列空间包含链与函数空间包含链比较]]。

## 维数

按 12.1.3 的断言序列空间均为无穷维，但正文表述为「例 B∼E」，ℓ^p（例 G）是否在所指范围内存疑，见 [[queries/例b至e范围是否应为b至g]]。（复算补充：{e₁, e₂, …} 在任意序列空间中线性无关，可直接证实 ℓ^p 无穷维，见 [[findings/式12-15至12-18线性无关凸集与锥转录复算]]。）

## 序结构

序列空间的自然逐坐标序通过与锥 C = {{ξₙ} : ξₙ ≥ 0 ∀n}（式 12.31，转录缺下标 n）之交诱导；ℓ^p 中的正元即具非负分量的序列。见 [[concepts/有序向量空间与锥诱导偏序]]。

## 球集 (12.18)：凸但非锥（注意主体区分）

给定 a > 0、1 ≤ p < ∞，集合

$$C = \Big\{\{\xi_n\} \in \ell^p : \sum_{n=1}^{\infty}|\xi_n|^p \leq a\Big\} \tag{12.18}$$

是凸集但**不是锥**（正齐次性失效：若 Σ|ξₙ|^p = a > 0，则 Σ|2ξₙ|^p = 2^p a > a）。**该断言仅关于此球集**，与 ℓ^p 空间本身的性质无关，不得外推。见 [[concepts/凸锥]]。
