# SE(3)（三维刚体运动群）

SE(3) 是 ℝ³ 中刚体运动的群：《数学手册（原书第10版）》4.4.3.6 表述为「刚体运动（旋转和平移相互交替）」构成的群。本节的核心断言是：单位「八元数」——即对偶四元数，见 [[concepts/对偶四元数]]——按式 (4.173) 参数化后给出 SE(3) 的**双重覆盖**。

## 在本源中的内容

```latex
ĥ = h₀ + h₁ ε = (1 + ½ t̲ ε) r = r + ½ t̲ r ε,    t̲ ∈ ℍ₀, r ∈ ℍ₁        (4.173)
```

按表 4.1：旋转由单位四元数 r ∈ ℍ₁ 表示；平移 t̲ 由 1 + ½t̲ε 表示，且平移可加：(1 + ½t̲ε)(1 + ½t′ε) = 1 + ½(t̲+t′)ε（分析者复核，用 ε² = 0）。因 ĥ 与 −ĥ 刻画相同的刚体运动，单位对偶四元数 → SE(3) 是二对一覆盖（核为 {±ĥ}）。

## 独立可核验的背景（非本源内容）

（公共数学常识，供核验：SE(3) 即特殊欧氏群 special Euclidean group，是 ℝ³ 的保距、保定向变换群，同构于半直积 SO(3) ⋉ ℝ³；机器人学与机构学中常用对偶四元数（motor 代数）表示其元素。）
