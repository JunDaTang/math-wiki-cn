# SO(3)（三维旋转群）与 so(3)

SO(3) 是三维空间的旋转群，即全体 3×3 旋转矩阵在矩阵乘法下构成的群——《数学手册（原书第10版）》4.4.3.2 以「3×3 旋转矩阵（即群 SO(3) 的元素）」界定。so(3) 是与之相伴的斜对称矩阵全体（SO(3) 的李代数）：4.4.3.2 把 SO(3) 元素的对数定义为满足 e^r = R 的斜对称矩阵。**注意**：本节正文称 so(3) 为「李群」，这是误称——so(3) 是李**代数**而非群（疑转写或原书之误，见 [[queries/4-4-3全节转写讹误清单]]）。

## 在本源中的角色

**矩阵版 Slerp（式 4.151）**：对旋转矩阵 R₀, R₁ ∈ SO(3)，插值定义为

```latex
R(t) = R₀ (R₀⁻¹ R₁)^t = R₀ exp( t log(R₀⁻¹ R₁) )                           (4.151)
```

其中 log 为 SO(3) 元素的对数（值在 so(3)）。见 [[findings/旋转矩阵的Slerp插值公式]]。

**姿态确定的解空间（4.4.3.4）**：待求的相对旋转矩阵 R ∈ SO(3)；极分解候选 R_p 与 R_jR_p（j = 1,2,3）均为 SO(3) 元素，极小解按 det P 的符号选取（式 4.161–4.165）。见 [[findings/卫星导航最小二乘姿态确定解全链]]。

**与四元数的关系**：单位四元数 h ∈ ℍ₁ 经三明治作用 h a⃗ h̄ = R a⃗ 实现 SO(3) 的旋转（式 4.153 即用此），ℍ₁ → SO(3) 为双重覆盖（4.4.2 已述）——勿与 4.4.3.6 对偶四元数对 [[entities/SE3]] 的双重覆盖混同。so(3) 与叉乘的联系由 K(a⃗)（式 4.159）实现：K(a⃗)b⃗ = a⃗×b⃗，即 [[findings/轴向量与斜对称秩2张量的对应]] 的矩阵形式。

## 独立可核验的背景（非本源内容）

（公共数学常识，供核验：旋转矩阵即行列式为 +1 的正交矩阵，故 SO(3) 是 [[concepts/正交矩阵]] 所述正交群的保定向子群；so(3) 在交换子括号 [r, s] = rs − sr 下同构于带叉乘的 (ℝ³, ×)。）
