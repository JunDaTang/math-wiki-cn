# 薛定谔方程

**薛定谔方程**（Schrödinger equation）是非相对论量子力学的基本动力学方程：关于空间坐标为二阶、关于时间为一阶的线性偏微分方程，其解——波函数 ψ——完全描述量子力学系统（粒子态）的性质。

> **背景注**：该方程由物理学家 Erwin Schrödinger 于 1926 年建立，描述量子系统状态（波函数）随时间的演化，是量子力学的核心方程。此为独立可验证的公共背景知识，并非本次导入来源的内容。

本页正文的实质论述依据手册 9.2.4「薛定谔方程」子节整理；该方程在 9.2 目录中的章节结构证据见下文「在手册中的结构位置」。

## 含时薛定谔方程（9.111）

```latex
\mathrm{i}\hbar \frac{\partial\psi}{\partial t} = -\frac{\hbar^{2}}{2m}\Delta\psi + U(x_1,x_2,x_3,t)\psi = \hat{H}\psi   % 9.111a
\hat{H} \equiv \frac{\hat{p}^{2}}{2m} + U(\vec{r},t),\quad \hat{p} \equiv \frac{\hbar}{\mathrm{i}}\nabla                   % 9.111b
```

- ℏ = h/2π 为约化普朗克常数，i 为虚单位，Δ 为拉普拉斯算子，∇ 为梯度算子。
- Ĥ 即 [[哈密顿算子]]：动能算子 p̂²/2m 与势能算子 U(r⃗,t) 之和，与经典力学的哈密顿函数（手册第 758 页二体问题，未入库）作用相同，表示分为动能与势能的系统总能量。
- 描述质量 m 的无自旋粒子在与位置有关的含时位势场中的一般非相对论情形（v ≪ c）。
- 虚单位显式出现在薛定谔算子中，故波函数是复函数；基于波粒二象性，它是关于德布罗意物质波的波方程；自由粒子的冲量（动量）与波长满足 λ = h/p。
- 除位势外，每个特解还依赖于初始条件与边界条件；一般是线性二阶边值问题，只有对本征值才有有物理意义的解，其绝对值平方处处唯一、正规且在无穷远处趋于零。

## 波函数条件与定态（9.112）

波函数须满足：a) 有界连续；b) 三个一阶偏导连续；c) |ψ|² 可积（9.112a），乘适当常数可归一化使总概率为 1。能量取固定值 E 时解具有形式

```latex
\psi(x_1,x_2,x_3,t) = \Psi(x_1,x_2,x_3)\exp\Big(-\mathrm{i}\frac{E}{\hbar}t\Big)   % 9.112b
\mathrm{d}\omega = |\psi|^{2}\,\mathrm{d}V = \psi\psi^{*}\,\mathrm{d}V               % 9.112c
```

即角频率 ω = E/ℏ 的时间周期函数；此时粒子位于空间元 dV 中的概率与时间无关，称为平稳态（定态）。详见 [[波函数与统计诠释]]。

## 定常薛定谔方程（9.113）

位势 U 与时间无关时，含时方程约化为空间本征值方程

```latex
\Delta\Psi + \frac{2m}{\hbar^{2}}(E-U)\Psi = 0   % 9.113a
```

满足它的波函数是本征函数，仅对某些能量值（本征值）存在；本征值全体形成能谱。若 U 是有限深度位势且在无穷远处趋于零，则负本征值形成离散谱。边界条件：区域为全空间时要求勒贝格意义下平方可积（手册 12.9.3.2，未入库）；区域有限（如球体、圆柱体）时可要求边界上 Ψ = 0（第一边界条件问题，参见 [[狄利克雷问题]]）。

U = 0 的特殊情形给出 [[亥姆霍兹微分方程]]（9.114a/b），本征值 λ = 2mE/ℏ²。

## 三个标准算例

- [[无限深方势阱]]（方块中的自由运动，9.132–9.134）：直角坐标分离变量，能级 E ∝ (nₓ/a)²+(n_y/b)²+(n_z/c)²，零点平移能 9.134h。
- [[中心对称场中的粒子运动]]（9.135–9.141）：球坐标分离变量，径向方程含离心位势，角解为 [[球面调和函数]]，宇称 P = (−1)^l。
- [[量子线性谐振子]]（9.142–9.147）：化为 [[韦伯微分方程]]，幂级数截止条件给出等距谱 Eₙ = ℏω(n+½)。

三算例的比较见 [[量子力学三算例比较]]；三者的推导链均经独立复算（见各 finding 页）。

- 结构上「时间一阶+空间二阶+虚系数」，与 [[热传导方程]] 形式平行，但因虚系数并非抛物型实方程（参见 [[二阶偏微分方程的分类]]、[[含时与定常薛定谔方程比较]]）。
