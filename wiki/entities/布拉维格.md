# 布拉维格

**布拉维格**（Bravais 格；原文表 5.5 题名又作「布拉瓦格」，译名不一）是晶体学中三维格结构的 14 种类型：先按基本（单位）胞腔的三个基向量 $\vec a_i$ 的相对长度与两两夹角（特别地 $90^\circ$ 与 $120^\circ$ 角）的可能组合得 7 种本原类型，再借助面心／体心／全面心（单侧面中心化、体中心化、全侧面中心化）的非本原胞腔扩充而成。

## 表 5.4 本原布拉维格（原文原样）

| 基本胞腔 | 基向量长度关系 | 基向量夹角 |
|---|---|---|
| 三斜晶 | $a_1 \neq a_2 \neq a_3$ | $\alpha \neq \beta \neq \gamma \neq 90^\circ$ |
| 单斜晶 | $a_1 \neq a_2 \neq a_3$ | $\alpha = \gamma = 90^\circ \neq \beta$ |
| 菱形晶 | $a_1 \neq a_2 \neq a_3$ | $\alpha = \beta = \gamma = 90^\circ$ |
| 三角晶 | $a_1 = a_2 = a_3$ | $\alpha = \beta = \gamma < 120^\circ (\neq 90^\circ)$ |
| 六方晶 | $a_1 = a_2 \neq a_3$ | $\alpha = \beta = 90^\circ, \gamma = 120^\circ$ |
| 正方晶 | $a_1 = a_2 \neq a_3$ | $\alpha = \beta = \gamma = 90^\circ$ |
| 立方晶 | $a_1 = a_2 = a_3$ | $\alpha = \beta = \gamma = 90^\circ$ |

## 译名疑点

表 5.4「菱形晶」行的数据（$a_1\neq a_2\neq a_3$、全 $90^\circ$）按标准晶体学对应**正交晶**（orthorhombic），而「三角晶」行（$a_1=a_2=a_3$、$\alpha=\beta=\gamma<120^\circ\neq 90^\circ$）对应**菱方／三方**（rhombohedral／trigonal）——中文译名与标准命名疑似错位，且表 5.4 与表 5.5 的三角／六方行序不同，见 [[queries/表5-4菱形晶与三角晶译名是否错位]]。
