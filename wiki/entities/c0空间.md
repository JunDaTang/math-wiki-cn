# c₀ 空间（零序列空间）

c₀ 空间是所有**零序列**（收敛于零的序列）组成的向量空间，即收敛序列空间 c 中极限 ξ₀ = 0 的子空间；加法与数乘逐项定义。《数学手册(原书第10版)》12.1.2 例 F 引入，是两条序列包含链的汇点。

## 两条包含链的汇点（式 12.12）

```
φ ⊂ c₀ ⊂ c ⊂ m ⊂ s，   φ ⊂ ℓ^p ⊂ ℓ^q ⊂ c₀（1 ≤ p < q < ∞）
```

c₀ 同时是「幂可和」链（[[entities/lp空间]]）的终点与「收敛型」链的中点：一切 p 幂可和序列都收敛于零。另一侧承接有限支撑序列空间 φ（[[entities/典型序列空间]]），通向 [[entities/m空间]] 与 s。

## 记号辨析：c₀ 与 c₀₀

- c₀ = 零序列空间（本页）；
- c₀₀ = φ = 有限支撑序列空间。

二者不同（复算补充：{1/n} ∈ c₀ 但既不属于 φ 也不属于 ℓ¹，可一次区分三个空间）。

## 维数

c₀ 为序列例 F，不在 12.1.3「例 B∼E」的字面范围内；其无穷维性依赖「B∼E」应为「B∼G」的疑改，见 [[queries/例b至e范围是否应为b至g]]。{e₁, e₂, …} 线性无关同样给出独立证实。

## 序结构

与其他序列空间一致，自然逐坐标序由非负序列锥诱导（式 12.31 语境），见 [[concepts/有序向量空间与锥诱导偏序]]。
