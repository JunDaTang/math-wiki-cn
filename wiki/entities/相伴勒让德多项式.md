# 相伴勒让德多项式 P_l^m(cosϑ)

相伴勒让德多项式 P_l^m(cosϑ)（本源 9.2.4 称「相关的勒让德多项式」，corresponding Legendre polynomials；通行译名亦作「缔合勒让德多项式」「连带勒让德多项式」）是中心场极方程（9.136g，缔合勒让德型方程）的有限、单值、连续解，由 Rodrigues 型微分公式定义（9.138c），构成 [[entities/球面调和函数]] 的极角部分。

## 定义与归一化

```latex
P_l^{m}(\cos\vartheta) = \frac{(-1)^{m}}{2^{l}l!}(1-\cos^{2}\vartheta)^{m/2}\frac{d^{l+m}(\cos^{2}\vartheta-1)^{l}}{(d\cos\vartheta)^{l+m}}   % 9.138c
\varTheta_l^{m}(\vartheta) = \sqrt{\frac{2l+1}{2}\cdot\frac{(l-m)!}{(l+m)!}}\,P_l^{m}(\cos\vartheta) = N_l^{m}P_l^{m}(\cos\vartheta)          % 9.138d
```

复算核对：9.138c 与含 Condon–Shortley 相因子 (−1)^m 的标准 Rodrigues 公式一致（✓）。

## 参数约束与特例

- 极方程仅当 l(l+1) = 0, 2, 6, 12, … 时存在有限、单值、连续的解；l = 0, 1, 2, …，|m| ⩽ l（9.138a），m 共可取 2l+1 个值（9.138b）。
- m = 0 的特殊情形退化为第一类勒让德多项式 Pₗ(x)（手册第 748 页 9.60c，见 [[entities/勒让德多项式]]、[[concepts/勒让德微分方程]]）。注：源文此处条件写作「(l = 0, m = n)」，疑为「m = 0」之误，见 [[queries/式9-138c前特殊情形条件疑为m等于0]]。
- 极方程与方位方程（9.136g/h）与位势无关，对每个有心对称位势场都成立。

## 称谓问题

手册对 associated Legendre 函数/多项式的译名前后不一：9.1.2 用「相伴勒让德函数」，9.2.4 用「相关的勒让德多项式」，与通行译名「缔合/连带勒让德多项式」均不同，见 [[queries/相伴勒让德函数称谓问题]]。

## 用途

作为 Θ_l^m(ϑ) 出现在中心对称场分离变量解 Ψ = R_l(r)·Θ(ϑ)·Φ(φ) 中（[[concepts/中心对称场中的粒子运动]]）；与方位函数 Φ_m = (1/√(2π))e^{imφ} 相乘构成球面调和函数（9.140a）。
