# 哈密顿算子 Ĥ

哈密顿算子（Hamilton operator，又称 Hamiltonian）Ĥ 是量子力学中代表系统总能量的算符：定义为动能算子 p̂²/2m 与势能算子 U(r⃗,t) 之和，作用于波函数便构成含时薛定谔方程 iℏ∂ψ/∂t = Ĥψ 的右端，其本征值是系统可能的能量值。

```latex
\hat{H} \equiv \frac{\hat{p}^{2}}{2m} + U(\vec{r},t),\qquad \hat{p} \equiv \frac{\hbar}{\mathrm{i}}\frac{\partial}{\partial\vec{r}} \equiv \frac{\hbar}{\mathrm{i}}\nabla   % 9.111b
```

## 手册 9.2.4 中的论述

- 出现在 (9.111a)(9.111b) 中的算子 Ĥ 被称为哈密顿算子；它与经典力学中的哈密顿函数（手册第 758 页关于二体问题的例子，未入库）有相同的作用，表示分为动能和势能的系统总能量。Ĥ 中的第一项是关于动能的算子，第二项是关于势能的算子。
- 手册注记 a)：量子力学中对每个可测量都配以一个算子——「量子力学中的算子控制着经典表达的结构」原则的体现。
- 能量是可观察量（位置、动量、角动量、能量之一），与之相配的算子即 Ĥ，满足厄米性要求 Â⁺ = Â（见 [[concepts/可观察量与厄米算子]]）。
- 位势 U 与时间无关时，定常薛定谔方程 ĤΨ = EΨ 即能量本征值方程，其本征值全体构成能谱（见 [[entities/薛定谔方程]]）。

## 显式形式

位置表象中 p̂ = (ℏ/i)∇，故 Ĥ 的显式微分形式为 −(ℏ²/2m)Δ + U；这正是含时薛定谔方程 (9.111a) 右端的写法。
