# C[a,b]（区间 [a,b] 上的连续实函数空间）

$C[a,b]$ 是定义在闭区间 $[a,b]$ 上的全体连续实函数所成的集合，按逐点定义的加法与实数乘法（式 5.190）构成实向量空间；配上式 (5.204) 的积分型标量积后，它进一步成为承载长度、夹角与正交性概念的函数空间。原书指出，函数空间在泛函分析中起着基本作用（参见第 12 章）。

## 作为向量空间（5.3.8.1 例 C）

区间 $[a,b]$ 上的连续实函数对运算

```latex
(f+g)(x) = f(x)+g(x),  (kf)(x) = k·f(x)      % 式 5.190
```

形成实向量空间。按 5.3.8.2 的维数理论，$C[a,b]$ 是**无限维**的（三个初始例子中维数分别为 n、m·n 与无限维的最后一个）。

## 作为线性泛函的定义域（5.3.8.3 例 A）

映射 $fu := \int_\alpha^\beta u(t)\,dt$ 将连续实函数空间 $C[\alpha,\beta]$ 变换到实数空间，是线性的。当 $W=\mathbb{R}^1$ 时，线性变换称为**线性泛函**——积分泛函是其典型实例（原书此处记号用 $C[\alpha,\beta]$，与 $C[a,b]$ 并用）。

## 积分标量积与正交性（5.3.8.5）

在 $C[a,b]$ 中，公式

```latex
f·g = ∫_a^b f(x) g(x) dx      % 式 5.204
```

定义一个标量积。特例 $C[0,2\pi]$ 中，三角函数系 $\sin kx$、$\cos lx$（$k,l\in\mathbb{N}$）两两正交（式 5.205–5.207，已复算，见 [[findings/三角函数正交性算例]]）；原书指出这一正交性在调和分析（7.4.1.1，第 634 页）中用来计算傅里叶系数。
