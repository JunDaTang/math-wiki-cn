# 指数积分 Ei(x)

指数积分 Ei(x) 是由反常积分 ∫₋∞ˣ eᵗ/t dt 定义的特殊函数：被积函数 eᵗ/t 在 t = 0 处有奇点，故当积分区间穿越 0（即 x > 0）时其取值按柯西主值理解。其级数表示与 [[余弦积分]]、[[对数积分Li]] 共享「C + ln|·| + Σ·ⁿ/(n·n!)」骨架，并通过 Ei(ln x) = Li(x) 与对数积分直接打通。

## 定义与级数（式 8.98）

```latex
\operatorname{Ei}(x) = \int_{-\infty}^{x} \frac{\mathrm{e}^{t}}{t}\,\mathrm{d}t
= C + \ln|x| + x + \frac{x^{2}}{2 \cdot 2!} + \dots + \frac{x^{n}}{n \cdot n!} + \dots \tag{8.98a}

\operatorname{Ei}(\ln x) = \operatorname{Li}(x). \tag{8.98b}
```

## 定义域与柯西主值

括注复原读法：−∞ < x < 0（通常情形）；当 0 < x < ∞ 时为柯西主值（穿越奇点 t = 0）。转写原文的标点/连词错乱及复原依据见 [[8-2-5全节系统性转写讹误清单]] 与 [[柯西主值]]。

## 与对数积分的关系

Ei(ln x) = Li(x)（式 8.98b，经代换 t = e^u 复算一致）：Li 即 Ei 与对数函数的复合，详见 [[对数积分Li]] 与 [[Ci-Li-Ei三函数级数结构比较]]。
