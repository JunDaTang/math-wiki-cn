# 福特-富尔克森算法

福特-富尔克森算法（Ford–Fulkerson 极大流算法）是作用于运输网络上的顶点标号算法：给定一个与容量相容的流 φ，算法交替执行前向标号（沿未饱和弧把标号从已标号顶点传向未标号顶点）与后向标号（沿流量为正的弧逆向传播标号），用以判定 φ 是否为极大流——若标号过程终止时汇点 S 已获标号，则流可改进量 ε(S)；若 S 未获标号，则 φ 是极大的。（独立可核验的背景：该算法在通行文献中以 L. R. Ford 与 D. R. Fulkerson 命名，是网络流理论的奠基性算法，其终止判定正确性的标准依据是极大流-极小割定理。）

本 wiki 收录该算法的来源是《数学手册（原书第10版）》5.8.7 节（[[sources/10-数学手册原书第10版--8-587-运输网络--wez537]]），手册将其作为 5.8 章继克鲁斯卡尔算法（[[entities/克鲁斯卡尔算法]]）、丹齐格算法（[[entities/丹齐格算法]]）之后的第三个具名图算法引入，定位是「应用极大流算法我们可以确认给定的流 φ 是否极大」。

## 手册中的算法表述

手册设定：G 是运输网络，φ 是与容量相容的强度为 v₁ 的流。算法给顶点标号，每个标号附带一个数值 ε（强度可改进量的上界）：

- 起始（步骤 a）：对源点 Q 标号，ε(Q) = ∞。
- 前向标号（步骤 b）：弧 uᵢ = (x, y) 上 x 已标号、y 未标号且 φ(uᵢ) < c(uᵢ) 时，给 y 标号，ε(y) = min{ε(x), c(uᵢ) − φ(uᵢ)}。
- 后向标号（步骤 c）：弧 uᵢ = (x, y) 上 x 未标号、y 已标号且 φ(uᵢ) > 0 及 uᵢ ≠ u₁ 时，给 x 标号，ε(x) = min{ε(y), φ(uᵢ)}。
- 终止判定：汇点 S 被标号 ⇒ 流可改进量 ε(S)；S 未被标号 ⇒ 流是极大的。

完整步骤（含脱落符号的补回）与循环结构讨论见 [[methodology/福特-富尔克森标号算法流程]]。

## 手册表述的特点与缺口

- **回弧约定**：手册的运输网络带一条容量 ∞ 的弧 u₁（据文意重构为 S→Q 回弧，属假设，见 [[queries/运输网络定义弧u1是否为s到q回弧]]），守恒条件（式 5.325a）对所有顶点成立；这与通行教科书中「仅中间顶点守恒、不设回弧」的表述不同。
- **u₁ 的排除**：后向标号明确要求 uᵢ ≠ u₁。重构推断：若 u₁ = (S,Q) 且不排除其后向标号，则汇点 S 会在首轮后向标号中被立即标号（φ(u₁) = 强度 > 0 时），使判定失效；该排除条款是回弧假设的关键内部证据。
- **无正确性证明**：手册未陈述极大流-极小割定理，「汇点未标号 ⇒ 流极大」以断言形式给出，未附证明。
- **转录残缺**：源文档中步骤 b)/c) 的 x/y、Q/S、G 等符号大量脱落；「给 (x,y) 标号」的标号对象据 ε(y)/ε(x) 的定义应分别为顶点 y 与顶点 x。
