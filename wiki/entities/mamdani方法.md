# Mamdani 方法

**Mamdani 方法**是一种模糊控制设计方法：IF–THEN 法则的后件为模糊集，控制过程按「法则基础 → 模糊化 → 聚合 → 决策（逆模糊化）」四步进行并反复迭代，直至系统偏差及其变化达到最小。它在数学手册 5.9.6.1 中作为基于知识的模糊系统的第一种标准方案给出，并在 5.9.6.3 的逆摆算例中被完整示范（见 [[逆摆]]）。

（独立可核背景：Mamdani 方法以 E. H. Mamdani 命名，他与 S. Assilian 于 1970 年代中期在一台实验室蒸汽机/锅炉装置上首次用语言模糊法则实现控制，是模糊控制的开创性工作。）

## 四步控制流程

（源文 5.9.6.1；另见 [[mamdani四步控制流程-式5-389]] 与 [[mamdani模糊控制计算流程]]。）

1. **法则基础**：第 $i$ 个法则形如

$$
R^{i}:\ \text{如果 } e \text{ 是 } E^{i} \text{ 并且 } \dot{e} \text{ 是 } \Delta E^{i},\ \text{那么 } u \text{ 是 } U^{i}.\tag{5.389}
$$

其中 $e$ 为误差、$\dot e$ 为误差变化、$u$ 为输出值的变化；各量在区域 $E\times\Delta E\times U$ 上以语言描述模糊化。

2. **模糊化**：将清晰测量值与法则前提比较，判定哪些法则起作用及其权（见 [[模糊化]]）。
3. **聚合**：把具有不同权的起作用法则以代数运算结合，供逆模糊化使用（见 [[模糊关系的复合]]；控制中的聚合即式 5.394 的极大-极小复合）。
4. **决策（逆模糊化）**：从可能值（清晰量的集合）中确定控制量的清晰值（见 [[逆模糊化]]），使偏差及其变化保持极小。

模糊控制意味着步骤 (1)–(4) 被重复执行，直至取得最小的偏差及其变化。

## 在逆摆算例中的使用

5.9.6.3 以 Mamdani 方法控制 [[逆摆]]：分区后取 19 条法则（49 个可能中）；初值 $(36^\circ, -2.25^\circ\mathrm{s}^{-1})$ 下仅 $R_1$（权 0.4）与 $R_2$（权 0.6）激发，分别以 [[α切割]] 得输出集（式 5.392/5.393），再以极大运算聚合（式 5.394–5.395），最后重心法得 $F=3.95$、极大值准则法得 $F=5.0$。完整数值链见 [[逆摆mamdani算例-式5-392-395]]（已复算）。

## 与菅野方法的差别

两者共享法则基础与模糊化两步；差别集中在后件形式与输出确定方式：Mamdani 后件为模糊集、须逆模糊化，[[菅野方法]] 后件为清晰线性函数、以加权平均直接输出。详见 [[mamdani与菅野方法比较]]。
