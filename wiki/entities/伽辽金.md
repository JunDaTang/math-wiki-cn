# 伽辽金

伽辽金（Boris Galerkin，1871—1945）是俄国/苏联工程师与力学家，伽辽金法以其命名（此为可独立查证的公共背景信息，非本源文档所载）。

在本源文档中，伽辽金法是边值问题逼近系数确定四原则之一：要求所谓误差正交性

```latex
(19.126)  \int_a^b \varepsilon(x; a_1,\dots,a_n)\, g_i(x)\, dx = 0   (i = 1,\dots,n)
```

其中 ε 为亏量 (19.122)、g_i 为基函数，由此得到未知系数的线性方程组。见 [[concepts/伽辽金法]]、[[concepts/亏量（残量）]]、[[comparisons/逼近系数确定四原则比较]]。
