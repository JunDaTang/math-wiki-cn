# C([a,b]) 连续函数空间

C([a,b]) 是闭区间 [a, b] 上所有（实值或复值）**连续函数**组成的向量空间，加法与数乘按逐点方式定义（式 12.13）。《数学手册(原书第10版)》12.1.2 函数空间例 C 引入（回指 2.1.5.1，未入库）。

## 在包含链中的位置（式 12.14）

```
C^(k)([a,b]) ⊂ C([a,b]) ⊂ B([a,b]) ⊂ F([a,b])
```

上层与下层的空间见 [[entities/函数空间层级]]。

## 子空间例子

对任意给定点 t₀ ∈ [a,b]，集合 {x ∈ C([a,b]) : x(t₀) = 0} 构成一线性子空间（12.1.2 函数空间例 E）。（复算补充：它是「在 t₀ 取值」这一线性泛函的核，余维 1，见 [[concepts/线性算子与线性泛函]]。）

## 锥与序结构

[a,b] 上非负值连续函数的集合 C₊ 是 C([a,b]) 中的凸锥（12.1.4.2 例 B），诱导逐点自然序 x ≥ y ⟺ x(t) ≥ y(t) ∀t；且 C₊ = F₊([a,b]) ∩ C([a,b])。见 [[concepts/凸锥]]、[[concepts/有序向量空间与锥诱导偏序]]。

## 向量格性质

C([a,b]) 是向量格：两函数的上确界逐点计算，(x∨y)(t) = max{x(t), y(t)}（式 12.34）。算例见式 (12.35)（其中正文 x(t) 系数含一处讹误，见 [[findings/式12-35正文xt系数与式内不一致之判定]]）；函数的正部、负部、模由 (12.39a–c) 给出。见 [[concepts/向量格与K空间]]、[[comparisons/向量格与非向量格有序空间比较]]。

## 线性无关例子（在 C([0,π]) 中）

函数组 1, sin nt, cos nt（n = 1, 2, 3, …）线性无关；而 1, cos 2t, cos²t 线性相关，因 cos²t = (1 + cos 2t)/2（可复算验证，见 [[concepts/线性无关性]]）。另 lin({1, t, t²}) 为三维（12.1.3）。

## 作为第 11 章的工作空间

C([a,b]) 是第 11 章积分方程的隐性工作空间：积分算子是 C([a,b]) 上的线性算子（[[concepts/线性算子与线性泛函]]），[[concepts/第二类弗雷德霍姆积分方程]] 的求解、[[concepts/皮卡迭代法]] 的逐次逼近均在其上进行。12.1 为这些构造提供代数上层框架。
