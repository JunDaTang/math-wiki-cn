# 表 8.7 曲线微元

**表 8.7** 是《数学手册（原书第10版）》8.3.1.4 中列出的「曲线微元」表，给出四种坐标/参数形式下弧长微元 $\mathrm{d}s$ 的表达式，是 [[concepts/第一类线积分]] 化为定积分（式 8.108–8.109）时被积函数所乘根式因子的来源。以下为逐字转录：

| 曲线 | 坐标/参数形式 | ds |
|---|---|---|
| xOy 面中的平面曲线 | 笛卡儿坐标 $x,\ y=y(x)$ | $ds=\sqrt{1+[y'(x)]^2}\,dx$ |
| | 极坐标 $\varphi,\ \rho=\rho(\varphi),\ x=\rho(\varphi)\cos\varphi,\ y=\rho(\varphi)\sin\varphi$ | $ds=\sqrt{\rho^2(\varphi)+[\rho'(\varphi)]^2}\,d\varphi$ |
| | 笛卡儿坐标系下的参数形式 $x=x(t),\ y=y(t)$ | $ds=\sqrt{[x'(t)]^2+[y'(t)]^2}\,dt$ |
| 空间曲线 | 笛卡儿坐标系下的参数形式 $x=x(t),\ y=y(t),\ z=z(t)$ | $ds=\sqrt{[x'(t)]^2+[y'(t)]^2+[z'(t)]^2}\,dt$ |

## 与 8.2.2 弧长公式的互证

本表四式与 8.2.2 的弧长公式（式 8.61a–d，见 [[concepts/弧长与弧微分]]）完全一致，构成两个独立小节之间的互证；本表另以极坐标 $\varphi,\rho$ 与空间参数形式统一呈现，是第一类线积分计算的枢纽。

## 使用注意

代入式 8.108a/b 时须保证参数方向满足 $t_0<T$（见 [[methodology/线积分化定积分计算流程]]）。
