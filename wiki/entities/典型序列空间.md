# 典型序列空间（s、φ、c、𝔽ⁿ）

本页为枢纽页，汇集《数学手册(原书第10版)》12.1.2 序列例子族中的四个基本序列空间：𝔽ⁿ（例 A）、s（例 B）、φ = c₀₀（例 C）、c（例 E）。有界序列空间 m 与零序列空间 c₀ 另设专页（[[entities/m空间]]、[[entities/c0空间]]），p 幂可和序列空间见 [[entities/lp空间]]。

## 𝔽ⁿ（例 A）：n 维标准模型

n 个标量构成的有序数组全体 {(ξ₁, …, ξₙ) : ξᵢ ∈ 𝔽}，运算逐分量进行：

$$x + y = (\xi_1 + \eta_1, \dots, \xi_n + \eta_n), \qquad \alpha x = (\alpha\xi_1, \dots, \alpha\xi_n). \tag{12.11a/b}$$

𝔽ⁿ 是 n 维空间（12.1.3）；线性空间 ℝ 与 ℂ 是 n = 1 情形的特例（转写「线性空间良和」疑为「ℝ 和 ℂ」，见 [[queries/12-1全节系统性转写讹误清单]]）。

## s（例 B）：所有序列的向量空间

无穷序列 x = {ξₙ}（ξₙ ∈ 𝔽）全体，运算仿 (12.11) 逐项定义。s 是包含链中最大的序列空间。

## φ = c₀₀（例 C）：所有有穷序列的向量空间

仅含有限个非零分量（非零分量个数依赖各元而不同）的序列全体组成的子集，构成向量空间。

## c（例 E）：所有收敛序列的向量空间

x ∈ c 当且仅当存在 ξ₀ ∈ 𝔽 使得 ∀ε > 0，存在标号 n₀ 满足 |ξₙ − ξ₀| < ε 对一切 n > n₀ 成立（回指 7.1.2，未入库）。

## 单位序列 e_k

第 k 个分量为 1、其余分量皆为 0 的序列 e_k 属于 φ，从而属于任意一个序列空间；集合 {e₁, e₂, …} 在任意序列空间中都是线性无关的（12.1.3，见 [[concepts/线性无关性]]）。

## 维数

𝔽ⁿ 为 n 维；s、φ、c 无穷维（12.1.3「例 B∼E」字面范围内）。m 亦在字面范围内；c₀ 与 ℓ^p 的无穷维性见 [[queries/例b至e范围是否应为b至g]]。

## 包含链（式 12.12）

```
φ ⊂ c₀ ⊂ c ⊂ m ⊂ s；   φ ⊂ ℓ^p ⊂ ℓ^q ⊂ c₀（1 ≤ p < q < ∞）
```

与函数空间包含链的比较见 [[comparisons/序列空间包含链与函数空间包含链比较]]。
