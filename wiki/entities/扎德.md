# 扎德（Zadeh）

**扎德（Lotfi A. Zadeh，1921–2017）** 是模糊集（模糊集合）理论与模糊逻辑的创立者。

> **公共背景注记（非源文内容）**：扎德于 1965 年发表论文 Fuzzy Sets，提出以隶属函数 μ: X → [0,1] 刻画边界不清晰的集合，由此开创模糊数学。以上生平与论文信息为可独立核验的公共背景知识，并非出自本次入库的源材料。

在《数学手册(原书第10版)》已入库的 5.9 各小节中，他是唯一具名人物，其名字与以下内容绑定。

## 在 5.9.2 模糊集的连接（聚合）中

- **表 5.8 首行署名（Zadeh 算子）**：交 t(x,y) = min{x,y}、并 s(x,y) = max{x,y}；以 min/max 定义、与 AND/OR/NOT 对应的算子称为 **Zadeh 算子**（式 5.350–5.351，其中 5.350a 与 5.351a 以 min/max 定义模糊交并；表 5.8、表 5.9），是 [[模糊集的聚合]] 的缺省实现，也是本节全段的缺省聚合算子。
- **与逻辑运算的对应**：min/max 分别对应 AND/OR（表 5.9，图 5.72–5.75），见 [[zadeh算子与and-or-not对应]] 与 [[布尔逻辑与模糊逻辑运算比较]]。
- **序链中央参照**：表 5.8 注的序链 t_dp ≤ t_b ≤ t_e ≤ t_a ≤ t_h ≤ t ≤ s ≤ s_h ≤ s_a ≤ s_e ≤ s_b ≤ s_ds 中，t、s 即 Zadeh 的 min/max，是衡量其他范数族位置的参照点。
- **边界元地位**：min 是最大的 [[t-范数]]、max 是最小的 [[s-范数]]，即 min/max 分别是 t-范数与 s-范数的边界元（式 5.349e–f；源文断言，维基独立推导确认）。

## 在 5.9.4 模糊推理（近似推理）中

扎德称模糊推理为**近似推理**——这是 5.9.4 的实质性命名归属断言，见 [[模糊推理]] 与 [[模糊推理定义与式5-380模糊推理象]]。该命名与「模糊推理不可能用经典逻辑刻画」的定位相呼应。

## 背景注记（非源文内容）

通行文献中，扩张原理亦以 Zadeh 命名（Zadeh 扩张原理，含 sup–min 隶属度公式），但已入库的 5.9.2.4 未署名且仅给类型级表述，见 [[扩张原理]]。
