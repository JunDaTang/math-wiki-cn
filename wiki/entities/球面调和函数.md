# 球面调和函数 Y_l^m(ϑ,φ)

球面调和函数（手册称「表面球面调和函数」，surface spherical harmonics）Y_l^m(ϑ,φ) 是中心对称场问题中仅依赖于两个角度的波函数解：由归一化的相伴勒让德多项式（极方程之解）与归一化的方位指数函数相乘而成（9.140a），在分离变量解 Ψ = R_l(r)·Y_l^m(ϑ,φ) 中承载全部角度依赖。

## 定义

```latex
Y_l^{m}(\vartheta,\varphi) = \varTheta(\vartheta)\varPhi(\varphi) = \frac{1}{\sqrt{2\pi}}N_l^{m}P_l^{m}(\cos\vartheta)\,\mathrm{e}^{\mathrm{i}m\varphi}   % 9.140a
```

- 构成：Θ_l^m = N_l^m P_l^m(cosϑ) 来自极方程（9.136g）之解（9.138d，[[entities/相伴勒让德多项式]]）；Φ_m(φ) = (1/√(2π))e^{imφ}（9.139d）来自方位方程（9.136h），其单值性条件 Φ(φ+2π) = Φ(φ)（9.139b）要求 m = 0, ±1, ±2, …（磁量子数），归一化 ∫₀^{2π}|Φ|²dφ = 1（9.139c）定出系数。
- 对 Ψ 的整体要求（9.136a 后文）：r → ∞ 时趋于零、单值、在球面上平方可积。

## 宇称变换性质

径向量关于原点反射 r⃗ → −r⃗ 时，(ϑ, φ) → (π−ϑ, φ+π)，Y_l^m 的符号可能改变：

```latex
Y_l^{m}(\pi-\vartheta,\varphi+\pi) = (-1)^{l}Y_l^{m}(\vartheta,\varphi)   % 9.140b
```

独立复算：P_l^m(−x) = (−1)^{l+m}P_l^m(x) 与 e^{imπ} = (−1)^m 联乘得 (−1)^l，验证通过（✓）。由此中心场波函数的宇称 P = (−1)^l（9.141a，见 [[concepts/宇称]]）。

## 用途

是 [[concepts/中心对称场中的粒子运动]] 分离变量的角部分通解；由于极方程与方位方程均与位势无关，Y_l^m 对每个有心对称位势场通用。
