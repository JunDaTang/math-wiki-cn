# 米尔恩

米尔恩（William Edmund Milne，1890—1971）是美国数学家，以数值分析研究与经典教材闻名（此为可独立查证的公共背景信息，非本源文档所载）。

本源文档中，米尔恩冠名于米尔恩法则 (19.103)：

```latex
(19.103)  y_{i+2} - y_i = \frac{h}{3}(f_i + 4f_{i+1} + f_{i+2})
```

即积分表达式 (19.95) 中的积分由辛普森公式在 [x_i, x_{i+2}] 上近似所得的隐式多步法。见 [[concepts/米尔恩法则]]。

推断性关联（源文未直接命名）：预估—校正对 (19.108a,b) 在文献中通常称米尔恩对，但源文 (19.108a) 的预估子 y_{i+1}^{(0)} = y_{i−2} + 9y_{i−1} − 9y_i + 6h(f_{i−1}+f_i) 与经典米尔恩预估子 y_{i+1}^{(0)} = y_{i−3} + (4h/3)(2f_{i−2} − f_{i−1} + 2f_i) 形式不同（前者经复算亦为四阶），见 [[queries/式19-108a预估子与经典米尔恩预估子形式之辨]]。源文另明言辛普森型校正子 (19.108b) 数值不稳定，见 [[concepts/预估—校正法]]。
