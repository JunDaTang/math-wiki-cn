# 菅野方法（Sugeno 方法）

**菅野方法**（Sugeno 方法；数学手册 5.9.6.2 标题作「管野方法」、正文作「营野 (Sugeno) 方法」，两者均为转写讹变体，见 [[管野营野菅野译名问题]]）是一种模糊控制设计方法：IF–THEN 法则的后件不是模糊集，而是清晰的（线性）函数；系统输出由各法则输出的加权平均直接算出，因而**省去逆模糊化**。它与 [[mamdani方法]] 的差别集中在法则基础与逆模糊化方法两处，并在 5.9.6.4 作为「基于知识的插值系统」的简单实例被复用（见 [[基于知识的插值系统]]）。

（独立可核背景：该方法以日本模糊理论学者菅野道夫（Michio Sugeno）命名；含线性函数后件的法则形式在文献中通常与高木英行（Takagi）的名字连用，称为 Takagi–Sugeno（T-S）模糊模型。）

## 法则形式与输出

（源文 5.9.6.2；另见 [[菅野方法函数后件与加权平均-式5-390-391]]。）

法则基础由下列形式的法则组成：

$$
R^{i}: \text{如果 } x_1 \text{ 是 } A_1^{i},\ \dots,\ \text{并且 } x_k \text{ 是 } A_k^{i},\ \text{那么 } u_i = p_0^i + p_1^i x_1 + p_2^i x_2 + \dots + p_k^i x_k.\tag{5.390}
$$

其中 $A_j^i$ 为由隶属函数确定的模糊集，$x_j$ 为清晰输入值（如误差 $e$ 与误差变化 $\dot e$，它们有时告诉我们关于系统动力学的一些信息），$p_j^i$ 为 $x_j$ 的权，$u_i$ 为属于第 $i$ 个法则的输出值。

三步流程：(1) 建立如式 5.390 的法则基础；(2) 模糊化——对每个法则 $R^i$ 算出 $\mu_i\in[0,1]$；(3) 决策——非模糊值的量由 $u_i$ 的加权平均计算，权是模糊化中的 $\mu_i$：

$$
u = \sum_{i=1}^{n} \mu_i u_i \left(\sum_{i=1}^{n} \mu_i\right)^{-1}.\tag{5.391}
$$

与 Mamdani 方法不同，这里不进行逆模糊化；代价在于须确定有效的权参数 $p_j^i$，源文指出这些参数可用机器学习方法（例如人工神经网络 ANN）确定，但未给出学习细节。

## 作为插值控制器

5.9.6.4 把 Sugeno 控制器当作研究模糊系统插值性质的最简单系统：法则形如 $R_i$: IF $\xi_1$ 是 $A_1^{(i)}$，…，THEN $y=f_i(\xi_1,\dots,\xi_n)$（式 5.396），输出为加权和 $y=\sum_i \alpha_i f_i/\sum_i\alpha_i$（式 5.397，实现等级 $\alpha_i$ 由 [[t-范数]] 从单个输入的隶属等级合成）。一维三角形隶属函数情形下的三条件与凸组合界见 [[sugeno插值三条件与凸组合界-式5-396-400]]。
