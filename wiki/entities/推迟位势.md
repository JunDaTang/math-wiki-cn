# 推迟位势

推迟位势（retarded potential，式 9.107a）是三维（n = 3）非齐次波方程柯西问题解中叠加在齐次解（[[基尔霍夫公式]]，式 9.106a）之上的附加项：对源项 Q 在以 (x, t) 为顶点的锥形域 K（r ⩽ at）上作体积分，且 Q 取带时滞 t − r/a 的值——即空间中距离 r 处的源的影响以波速 a 传播、延迟 r/a 时间后到达。

## 公式（逐字转录）

```latex
\frac{1}{4\pi a^{2}} \iiint_{K} \frac{Q\left(\xi_{1}, \xi_{2}, \xi_{3},\, t - \frac{r}{a}\right)}{r}\, \mathrm{d}\xi_{1}\mathrm{d}\xi_{2}\mathrm{d}\xi_{3} \tag{9.107a}
```

其中 r := √((ξ₁−x₁)² + (ξ₂−x₂)² + (ξ₃−x₃)²) ⩽ at。

## 结构与复算

- 积分域 K 为以 (x, t) 为顶点的后向锥（“后向光锥”为标准术语，独立可验证背景）；核 1/r 与时滞 t − r/a 的结构经独立复算正确（见 [[式9-107a至9-107c非齐次附加项复算]]）。
- 平行的低维附加项：n = 2 为式 9.107b（(ξ₁, ξ₂, τ) 空间中由 0 ⩽ τ ⩽ t、(ξ₁−x₁)² + (ξ₂−x₂)² ⩽ a²(t−τ)² 定义的锥域 K 上的三重积分，前因子 1/(2πa)，核含平方根权）；n = 1 为式 9.107c（三角形域 T: 0 ⩽ τ ⩽ t、|ξ−x₁| ⩽ a|t−τ| 上的二重积分，前因子 1/(2a)）。
- 三维情形 Q 显式含时滞变元 t − r/a，而 n = 2、n = 1 情形改为对 (ξ, τ) 的积分——降维后时滞隐含在积分域内（独立复算观察）。

## 转写缺损

源文“对于由 r := √(…) ⩽ at 给出的域〔K〕，正确的项是”中积分域名 K 在不等式断裂处被 OCR 丢失（见 [[9-2-3全节系统性转写讹误清单]]）。
