# 表 8.6 第一类线积分的应用

**表 8.6** 是《数学手册（原书第10版）》8.3.1.4「第一类线积分的应用」中列出的公式表，汇总第一类线积分在弧长、质量、重心与转动惯量等几何/力学量上的应用，与 [[entities/表8-7曲线微元表]]（曲线微元 $\mathrm{d}s$）配套使用。以下为逐字转录（$\varrho=f(x,y,z)$ 为密度函数）：

| 应用 | 公式 |
|---|---|
| 曲线段 C 的长 | $L=\int_{(C)} \mathrm{d}s$ |
| 质地不均匀的曲线段 C 的质量 | $M=\int_{(C)}\varrho\,\mathrm{d}s$（$\varrho=f(x,y,z)$ 为密度函数） |
| 重心的坐标 | $x_C=\frac{1}{L}\int_{(C)}x\varrho\,\mathrm{d}s,\quad y_C=\frac{1}{L}\int_{(C)}y\varrho\,\mathrm{d}s,\quad z_C=\frac{1}{L}\int_{(C)}z\varrho\,\mathrm{d}s$ |
| 平面曲线在 xOy 面的转动惯量 | $I_x=\int_{(C)}x^2\varrho\,\mathrm{d}s,\quad I_y=\int_{(C)}y^2\varrho\,\mathrm{d}s$ |
| 空间曲线关于坐标轴的转动惯量 | $I_x=\int_{(C)}(y^2+z^2)\varrho\,\mathrm{d}s,\quad I_y=\int_{(C)}(x^2+z^2)\varrho\,\mathrm{d}s,\quad I_z=\int_{(C)}(x^2+y^2)\varrho\,\mathrm{d}s$ |
| （注） | 对于质地均匀的曲线，令 $\rho=1$ |

## 与既有公式的对应

- 第一行 $L=\int_{(C)}\mathrm{d}s$ 即 [[concepts/弧长与弧微分]] 的线积分表述（8.2.2 式 8.61 的对弧长积分形式）。
- 第三行曲线重心坐标是 [[concepts/重心的积分公式]]（8.2.2 版）之外的「第五情形」，与 [[comparisons/重心公式四情形比较]] 所列四情形并列。
- 第四、五行是 [[concepts/转动惯量的积分公式]] 的细线（曲线）版本。

## 存疑：平面行的下标约定

平面行写作 $I_x=\int x^2\varrho\,\mathrm{d}s$、$I_y=\int y^2\varrho\,\mathrm{d}s$，而同表空间行采用「到轴距离平方」约定（$I_x$ 配 $y^2+z^2$）——同表内部不一致，且与力学标准约定（对 $x$ 轴的转动惯量用 $y^2$，此为独立可验证的标准背景）相悖，疑似 $I_x/I_y$ 互换。详见 [[queries/表8-6平面曲线Ix与Iy是否互换]]；引用本表计算平面曲线转动惯量时须先解决该疑点（空间行不受影响）。
