# 洛伦茨系统

**洛伦茨系统**是由气象学家 [[entities/洛伦茨]] 提出的三个耦合非线性常微分方程，因其在经典参数下的奇怪吸引子而成为确定性混沌的标志性例子（独立可核实背景：原始论文 1963 年发表，研究大气对流的极端简化模型）。在本手册中以编号 (17.2) 出现，定义处为第 1118 页 17.1.1.1,2.。

作为独立可核实的背景，其方程为：

$$\dot{x} = \sigma(y - x),\qquad \dot{y} = rx - y - xz,\qquad \dot{z} = -bz + xy$$

## 本源（17.2.7.2.3）中的记录

- 洛伦茨系统属于 $X_+^1(U)$，其中吸收域（吸收椭球）
  $$U = \{(x,y,z) \in \mathbb{R}^3 : \tfrac{1}{2}\,[x^2 + y^2 + (z - \sigma - r)^2] < c\},\quad c > 0 \text{ 充分大}.$$
- 经典参数 $(\sigma, b, r) = (10,\; 8/3,\; 28)$ 下，洛伦茨吸引子 $\Lambda$ 落于 $U$ 中。
- 维数数值（均关于该参数组）：

| 量 | 值 | 方法/出处 |
|---|---|---|
| $d_H(\Lambda)$ | $\le 2.421$ | 杜阿迪—厄斯特勒定理（第 1152 页 17.2.4.3；见 [[findings/式17-53至17-54杜阿迪—厄斯特勒定理与洛伦茨上界复算]]） |
| $d_H(A)$ | $\approx 2.06$ | 数值积分的盒计算方法（标号存疑，见 [[queries/盒计算方法标d_H疑为d_C之辨]]） |
| $d_K$ | $\approx 2.03$ | 逆向迭代时滞嵌入（$\tau \approx 0.12$），[[entities/格拉斯贝格]] [17.12]；关于自然测度 |

数值链内部自洽：$d_K \approx 2.03 \le d_H(A) \approx 2.06 \le d_H(\Lambda) \le 2.421$（测度维数 ≤ 集合维数 ≤ 解析上界）。**注意归属边界**：$d_K \approx 2.03$ 仅关于洛伦茨自然测度，不可移植为洛伦茨吸引子的豪斯多夫维数，更不可推广至其他系统。
